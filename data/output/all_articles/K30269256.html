K30269256: Max-duration of Password Policy is locally affected unconditionally on BIG-IQ

Type
Support Solution
Published
2022-02-11
Updated
2025-02-06
Status
Legacy Content
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K30269256

Description
In an HA deployment of BIG-IQ CM system, the max-duration of local password policy for the local user is being enforced arbitrarily regardless of enabling or disabling the policy enforcement. In addition, this setting will not be synced between the HA members.

Environment

  • BIG-IQ CM in an HA environment
  • Max-duration setting of local user password policy

Cause
None

Recommended Actions

  1. If  max-duration of password policy is in use, make sure it is configured properly on all of the HA members manually. Don't rely on the sync mechanism.
  2. Keep in mind that this setting is independent for the HA members, so make sure to double check it on each HA member for the consistency of the security policy deployment.
