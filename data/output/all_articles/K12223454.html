Known Issue

The Route Advertisement setting for a virtual address changes from Selective to Disabled after updating.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured for dynamic routing.
  • The Route Advertisement setting is set to Selective for a virtual address within the Configuration utility.

Impact

The Route Advertisement setting is reset to Disabled (default) and may affect traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to set the Route Advertisement setting to Selective, the selection does not save upon updating.

Workaround

To work around this issue, you can use the TMOS Shell (tmsh) to update the Route Advertisement setting. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To enable the Route Advertisement setting for a virtual address, use the following command syntax:

    modify /ltm virtual-address /<partition>/<ip address> route-advertisement selective

    For example:

    modify /ltm virtual-address /Common/172.16.1.157 route-advertisement selective

  3. Repeat step 2 for each virtual address for which you would like to enable the Route Advertisement setting.
  4. Save the configuration changes by typing the following command:

    save /sys config partitions all
