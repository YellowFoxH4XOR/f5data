K000154595: Why don't failed health checks for my load balancer generate an alert?

What Happened?

  • Why don't failed health checks for my load balancer/origin pool generate an alert?
  • I setup alert policy on "ServiceEndpointHealthcheckFailure" alert name and I'm not receiving an alert notification when health check fails.

 

Environment

  • F5® Distributed Cloud Console
  • HTTP Load Balancer
  • Origin Pool
  • Health Check
  • Alerts

Resolution/Answer

There will be one alert generated when health check changes from healthy to unhealthy and a second alert generated when it reverts from unhealthy to healthy. This change was implemented recently (as of aug-2025) to reduce noise for health check failures. There were too many notifications before this change was implemented.

If the health check is constantly failing and showing red in performance dashboard for the LB, no alerts will be generated. An alert will only be generated when state changes from healthy to unhealthy or vice versa.
