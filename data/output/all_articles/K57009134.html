Issue

Error Message

An error occurred while adding the BIG-IQ Device: Permission denied (publickey,keyboard-interactive,hostbased) when deploying a BIG-IQ HA Pair on Microsoft Azure.

Message Location

You may encounter this message in the following location:

  • In the BIG-IQ user interface

Description

This message occurs when all of the following conditions are met:

  • You deploy BIG-IQ Virtual Edition (VE) systems in a Microsoft Azure cloud environment.
  • You attempt to configure the BIG-IQ systems for high availability (HA).

When you deploy BIG-IQ VE systems in Microsoft Azure, the root account is disabled by default.   This is intentional and is considered to be best practice for cloud deployments.  However, to create a BIG-IQ HA pair, you must have root access because you need the use of the root account to deploy the HA functionality.

Impact

Adding the BIG-IQ VE system to the HA configuration fails.

 

Recommended Actions

To work around this issue, you can enable the root account on the BIG-IQ VE instance. 

Important: The root account must be enabled on both BIG-IQs, the active BIG-IQ and the soon to be standby BIG-IQ, when establishing the HA pair.

Impact of procedure: Performing the following procedure may provide external access to the BIG-IQ system, depending on your security-group policies.  Be sure to create a strong password for the root account.

  1. Log in to the BIG-IQ system using SSH with a terminal emulator such as PuTTY.
  2. To access the TMOS Shell (tmsh), type the following command:

    tmsh

  3. Enable the root account by typing the following command:

    modify /sys db systemauth.disablerootlogin value false

  4. Modify the password for the root account by typing the following command:

    modify /auth password root

  5. Type your new password and press Enter.

    Note: Choose a strong password for the root account.

  6. Re-type the new password and press Enter.
  7. Save the changes by typing the following command:

    save /sys config
