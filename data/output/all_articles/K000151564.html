K000151564: Unable to assign the 2nd certificate to a SSL Profile using AS3

Type
Support Solution
Published
2025-05-28
Updated
2025-05-28
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000151564

Description

You are unable to enable Server Name Indication (SNI) when applying two certificates to the same SSL Profile. Attempts to configure this setting using the Automated Service Discovery (AS3) tool result in failure. This issue typically manifests with the inability to successfully configure or deploy the intended behavior for SSL certificates using AS3.

Environment

  • Using AS3 for configuration management
  • BIG-IP Local Traffic Manager (LTM)
  • AS3 version is 3.23

Cause

This issue occurs because the AS3 version being used (version 3.23) does not support the necessary functionality to enable SNI with multiple certificates for a single SSL Profile. The feature or fix to support this was introduced in a later version.

Recommended Actions

Follow these steps to resolve the issue:

  1. Upgrade AS3 to version 3.44 or later.
  2. Re-deploy the configuration declaration after upgrading AS3.

Upgrading to the latest version ensures compatibility with features and functionality required to enable SNI for multiple certificates within the same SSL profile.

Additional Information

For detailed information on using multiple SSL/TLS certificates in a single profile, refer to the official documentation: TLS Encryption: Using Multiple SSL/TLS Certificates in a Single Profile
