Description

The system logs the following messages in /var/log/audit:

<hostname> notice tmsh[47755]: 01420002:5: AUDIT - pid=47755 user=root folder=/ module=(tmos)# status=[Command OK] cmd_data=cd / ;
<hostname> notice tmsh[47755]: 01420002:5: AUDIT - pid=47755 user=root folder=/ module=(tmos)# status=[Command OK] cmd_data=list cm device recursive

Environment

  • BIG-IP versions 14 and 15
  • At the rate of 3 times a minute
  • /var/log/audit

Cause

This occurs in normal operation.
 

Recommended Actions

To Workaround this you could create a log filter by running below commands:

  1. Login to BIG-IP and enter tmsh
  2. Run the command to suppress the log messages:

    modify sys syslog include 'filter f_audit { facility(local0) and match("AUDIT") and not match("cmd_data=list cm device recursive|cmd_data=cd /"); };'
     
  3. Save the change: save sys config
