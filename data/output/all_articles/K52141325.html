Description

You may see the following under qkview's Diagonstic tool:

H52145254-5 - Indicators of Compromise (IoCs) are found on the system.Environment

Cause

The issue is a false positive, for some reason while the admd_admdb_cleaner script was running, the BIG-IQ may pick it up and mark it with H52145254-5. However, this should not be a security concern.

You can open and compare the contents of the python script that the BIG-IQ found running:

# cd /etc/adm/
cat admd_admdb_cleaner

And if you compare the contents they should be the same.

Recommended Actions

This can safely be ignored

None
