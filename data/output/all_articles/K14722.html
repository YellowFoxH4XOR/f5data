Known Issue

BIG-IP users who are assigned the Manager role cannot use the BIG-IP Configuration utility to create or update HTTPS monitors.

This issue occurs when all of the following conditions are met:

  • You are assigned the Manager role on the BIG-IP system
  • You attempt to use the BIG-IP Configuration utility to create or update an HTTPS monitor

Impact

BIG-IP users assigned the Manager role are unable to use the BIG-IP Configuration utility to create or update an HTTPS monitor.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to create or update an HTTPS monitor, the following error message displays in the Configuration utility:

    General database error.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to create or update HTTPS monitors.

Note: This option is only available if the user assigned the Manager role has tmsh enabled for Terminal Access.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
