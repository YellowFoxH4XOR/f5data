K26097326: After adding NTP server suddenly encountered ''X-F5-Auth-Token has expired'' error on some GUI pages

Type
Support Solution
Published
2021-02-19
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 15.1.2, 15.1.2
Source
https://my.f5.com/manage/s/article/K26097326

Description

Once you've added an NTP server on the BIG-IP. You suddenly encounter an error  "X-F5-Auth-Token has expired" on some of the BIG-IP GUI pages (ex. Devices > Device Management > Traffic Groups)

Environment

  • BIG-IP
  • Logged-in to the Configuration Utility or GUI
  • Updated device date/time manually or added a NTP server.

Cause

When you log in, system will create a token that will expire within 20 minutes. When the time is adjusted for several hours, the token will expire. The change in system time causes this error message.

Note: The user should experience this only once.

Recommended Actions

Log out on the BIG-IP system and re-login. The error should be gone in the new and succeeding sessions.
If it persist, please generate a new qkview and escalate the issue to F5 Support.

Additional Information

None.
