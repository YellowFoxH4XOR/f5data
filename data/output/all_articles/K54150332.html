Security Advisory Description

An attacker may be able to evade ASM detections by including the x-up-devcap-post-charset header when sending requests to an ASP.NET application, to craft a request payload with language encoding that is not supported by BIG-IP ASM/Advanced WAF, and is different to that specified by the Content-Type header.

This issue occurs when all of the following conditions are met:

  • Failed to convert character setting options are not selected (Security > Application Security > Policy Building > Learning and Blocking Settings > General Settings).
  • The BIG-IP ASM system protects an ASP.NET application.

Note: Failed to convert character setting options are not selected by default in Application security policies derived from Policy Template SharePoint 2007, SharePoint 2003, OWA Exchange 2003, OWA Exchange 2007, and OWA Exchange 2010.

Impact

An attacker may be able to compromise a protected ASP.NET application.
