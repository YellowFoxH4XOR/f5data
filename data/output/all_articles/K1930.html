K1930: Broadcom SSL cards are not compatible with the motherboard included in some versions of the BIG-IP Enterprise (F35) platform

Topic

When using Broadcom cards for SSL decryption, BIG-IP will lock up and you may receive an error similar to the following in the /var/log/messages log file, or when you run the dmesg -N /bsd command:

ubsec0 at pci0 irq 9 maddr 0xe1800000-0xe180ffff : BCM5820
ubsec: *** FAILED *** due to incompatible system board
ubsec: InitDevice() failed
system_type Server Appliance:
CPU: Pentium III (551 MHz)
Memory: 127 MB
BIG-IP Kernel 4.1.1 Build13Cpu-0 = Pentium III (551.25 MHz)

This situation occurs because the Broadcom SSL decryption cards are not compatible with ASUS P3B-F motherboards. Since the card is not recognized by the motherboard, it is never used for the decryption process; instead all decryption is done using system resources. On older systems with minimal amounts of memory and processor speed, this can cause the unit to lockup or crash.
