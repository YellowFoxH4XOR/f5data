Description

Security policy changed to Automatic Learning Mode, after import and sync from peer with Disabled Learning Mode.

Environment

  • Policy import
  • ASM sync
  • Learning Mode

Cause

Bug ID 1033017

Recommended Actions

There is no permanent fix for bug ID 1033017 at the time of this article's publication.

A workaround is to change the Learning Mode to Disabled on the destination device, then sync again from the source device. The policies should be in sync at this point and both should have Disabled Learning Mode.
