Source

Description

Unable to ssh access to BIG-IQ devices via remote (LDAP) account but able via GUI


Environment

-Remote-user ssh access issue

-GUI access is ok


Cause

Configuring ldap settings in the GUI but these changes are not saved into /etc/nslcd.conf. It is an expected behavior.


Recommended Actions

-Ensure that /etc/nslcd.conf (this file is not available in the qkview) is correctly configured with the LDAP server details, including:


URI: LDAP server URI

Base DN: Correct distinguished name

Bind DN: Valid credentials


Additional Information

any change on LDAP settings in GUI cannot affect /etc/nslcd.conf
