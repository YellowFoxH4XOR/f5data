Known Issue

This is the result of a known issue. If you configure a pre-logon sequence using the Check OS pre-logon inspector, and a Windows Vista client connects to the FirePass controller using Firefox 3, FirePass incorrectly detects the client operating system as Windows NT instead of Windows Vista. When this issue occurs, FirePass sets the value of the session.os.platform session variable to WinNT instead of WinVI.

F5 Networks Product Development tracked this issue as CR105051 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in cumulative hotfix HF-602-6 issued for FirePass version 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
