Description

  • Unable to deploy Web Application Security changes to BIG-IPs from BIG-IQ
  • Deployment task fails complaining about Attack signature
  • A message similar to the following  can be seen on /var/log/restjavad.0.log

    Starting task [Not able to deploy Web Application Security to BigIP 02] for 1 device(s)

Environment

  • BIG-IQ CM
  • Multiple BIG-IPs with ASM provisioned managed by BIG-IQ

Cause

Seen behaviour is caused by a known issue tracked with the Bug ID 1117521

Recommended Actions

As a workaround, a save operation from BIG-IQ is needed. It will not require a change to the signature as an example below:

  1. Open a Signature for Edit.
  2. In the Description field type some text like "abc" so that the save option is enabled and then remove the entered text("abc")
  3. Save the Signature. This will remove the md5

The above steps will remove the parameter causing the issue and will not change the Signature data as a result when a deployment is triggered only the changes which the user wants to push will be existing. If the user does not have any changes to push then it will not show any changes as the Signature contents were not updated by Step 2.
