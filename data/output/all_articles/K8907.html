Known Issue

This is the result of a known issue. When you configure intra-cluster mirroring for the VIPRION system, the system mirrors connection and session persistence records between blades in the cluster. When intra-cluster mirroring is enabled for a FastL4 virtual server, the VIPRION system counts each connection twice, resulting in skewed connection statistics.

For example, if a FastL4 virtual server with intra-cluster mirroring enabled is processing 100 concurrent connections, the virtual server statistics will indicate that it is processing 200 concurrent connections.

In addition, if connection limits are enabled for the virtual server, the VIPRION system will only allow 50 percent of the concurrent connections specified in the connection limit setting. For example, if the connection limit setting for the virtual server is 100, the virtual server allows 50 concurrent connections if intra-cluster mirroring enabled.

F5 Product Development is tracking this issue as ID 221921 (formerly CR100679).
