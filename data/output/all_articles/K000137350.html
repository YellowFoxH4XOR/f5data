Description

$curl -s -k --cert-type PEM --cacert ca_certificate.pem --cert client_certificate.pem --key client_key.pem https://<IP address>:30881/status | jq

Environment

  • SPK 1.7.x,
  • SPK 1.8.x
  • OpenShift 4.12

Cause

The config report during activation license could not be download due to inconsistence in CWC pod.

Recommended Actions

  1. Delete CWC, rabbit pods and dedicated namespace for them - spk-telemetry
  2. Delete tmm pod in case it was installed
  3. Create spk-telemetry namespace
  4. Apply rabbit and CWC pods
Important: Wait till both pods will be running -> (oc get pod -n spk-telemetry) 
# oc get pod -n spk-telemetry
NAME                          READY   STATUS    RESTARTS   AGE
f5-rabbit-7b94b6ffbb-kcsdq    1/1     Running   0          48d
f5-spk-cwc-75b9c9c956-7lfmt   2/2     Running   0          48d
  1. Activate license
  2. Apply TMM pod
