Topic

The Datagram Transport Layer Security (DTLS) protocol provides communication security and privacy for datagram protocols. DTLS is based on the stream-oriented TLS protocol and provides similar security. This article discusses the DTLS support on the BIG-IP system.

Description

Beginning in BIG-IP 10.1.0, F5 has added support for DTLS.

DTLS support in versions prior to BIG-IP 16.0.0 is limited to DTLS 1.0 (DTLSv1.0) as defined in RFC4347.

DTLS 1.2 (DTLSv1.2), based on RFC6347, is supported beginning in BIG-IP 16.0.0. For more information about support for DTLSv1.2, refer to K52355764: BIG-IP support for DTLS 1.2.

Note: Currently, there are two versions of DTLS. DTLSv1.0 is based on TLS 1.1, while DTLSv1.2 is based on TLS 1.2. There is no DTLSv1.1 since it was skipped to align DTLS version numbers with the corresponding TLS version number, per RFC6347.

Note: The BIG-IP system supports DTLS for use with UDP encapsulation, as defined in RFC4347; the BIG-IP system does not support DTLS for use with DCCP encapsulation, as defined in RFC5238.
