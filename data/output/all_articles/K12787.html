K12787: Users with security role of Operator are unable to save custom terminal settings

Topic

You can use the terminal command to customize terminal settings for an ARX CLI session. You can use the save profile command to save the customized terminal settings for future CLI sessions.

The save profile command is a priv-exec mode command, and it is not available if you have a security role of operator; the command requires that you have a security role of crypto-officer, storage-engineer, network-engineer, or network-technician.

As a result, if you have a security role of operator, you can customize your terminal settings for the current CLI session using the terminal command, but you cannot save those settings for a future CLI session.

Note: The default security role for a new user is operator.

F5 Product Development is tracking a request for enhancement (RFE) as ID 353610 to allow users with a security role of operator to save their terminal settings.

Workaround

To save the terminal settings for an operator user, perform the following procedures:

  • Log in as an admin user (crypto-officer) and temporarily add the operator user to the network-technician group.
  • Log in as the operator user, configure and save the desired terminal settings.
  • Log in as an admin user (crypto-officer) and remove the operator user from the network-technician group.
  • Log in as the operator user and confirm that the system applied the desired terminal settings.

Log in as an admin user (crypto-officer) and temporarily add the operator user to the network-technician group

  1. Log in to the ARX CLI with the crypto-officer security role (admin).
  2. Enable privileged mode by typing the following command:

    enable

  3. Enter global configuration mode by typing the following command:

    global

  4. Enter configuration mode for the network-technician group by typing the following command:

    group network-technician

  5. Add the affected user to the network-technician group by using the following command syntax, and replacing <user_name> with the username of the affected operator user:

    user <user_name>

  6. Exit the global configuration mode by typing the following command:

    end

Log in as the operator user, configure and save the desired terminal settings

  1. Log in to the ARX CLI as the affected operator user.
  2. Set the desired terminal settings using the terminal command.

    Note: For information about the terminal command, refer to the ARX CLI Reference Guide.

  3. Save the configured terminal settings by typing the following command:

    save profile

  4. Exit the CLI session by typing the following command:

    exit

Log in as an admin user (crypto-officer) and remove the operator user from the network-technician group

  1. Log in to the ARX CLI with the crypto-officer security role (admin).
  2. Enable privileged mode by typing the following command:

    enable

  3. Enter global configuration mode by typing the following command:

    global

  4. Enter configuration mode for the network-technician group by typing the following command:

    group network-technician

  5. Remove the affected user from the network-technician group by using the following command syntax, and replacing <user_name> with the username of the affected operator user:

    no user <user_name>

  6. Exit the global configuration mode by typing the following command:

    end

Log in as the operator user and confirm that the system applied the desired terminal settings

  1. Log in to the ARX CLI as the affected operator user.
  2. Display the configured terminal settings by typing the following command:

    show terminal
