Description

Uploading large files using SCP or SFTP into a BIG-IP tenant management interface IP on an rSeries appliance may become very slow specially when the round-trip time (RTT) between the SCP/SFTP client and the tenant is high. 

Environment

  • rSeries host
  • BIG-IP tenant
  • Uploading large files (ie. ISO) towards BIG-IP tenant management interface IP over a link with high RTT.

Cause

Generic receive offload (GRO) feature on the rSeries host causes smaller segments to be queued behind larger aggregated segments resulting in segments arriving out of order in the tenant. PD has assigned ID2707301 (F5OS) and ID2711641 (BIG-IP) for this issue.

Answer/Recommended Actions

1. For the r2k host, execute these commands on Bash: 

    nmcli connection modify mgmt ethtool.feature-gro off 
    nmcli connection up mgmt 

  To verify: 

  nmcli connection show mgmt | grep gro 

  Note: This setting will survive reboots and upgrades. 

2. For the tenant, there are 2 parts: 

    2.1. For eth0, execute this command: 

      echo 'ETHTOOL_OPTS="-K ${DEVICE} gro off"' >> /etc/sysconfig/network-scripts/ifcfg-eth0 

    To verify: 

      ethtool -k eth0 | egrep "generic-receive" 

     Note: This setting survives reboots, but not upgrades. This particular step will need to be performed when the BIG-IP tenant is upgraded.

    2.2. For mgmt, a script needs to be created so that /config/startup calls it every time that the tenant reboots. Create a script (ie. /config/startup_script_ID2711641.sh) on the BIG-IP similar to the following: 

#!/bin/bash 
# Filename: /config/startup_script_ID2711641.sh 
# Workaround for ID2711641 

source /usr/lib/bigstart/bigip-ready-functions 
wait_bigip_ready 

/sbin/ethtool -K mgmt gro off

 
    Make the script executable. 

      chmod +x /config/startup_script_ID2711641.sh 
 
    Add the script into /config/startup: 

# 
# NOTE: 
# This file will be installed in /config/startup and it will 
# be called by /etc/rc.local. 
# 
# - /config/startup is for customer config additions and 
# will be saved in UCS 
# 
# - /etc/rc.local should *not* be used by customers and 
# can/will be changed by F5 
# 

/config/startup_script_ID2711641.sh &

    Note: This setting will survive reboots and upgrades.  

    To have the setting take effect immediately without rebooting the tenant, execute the following from the tenant's Bash CLI: 

      /sbin/ethtool -K mgmt gro off 

    To verify: 

      ethtool -k mgmt | egrep "generic-receive" 
 
Note: PD recommends to only use these workaround steps for devices affected when transferring files going to the tenant.
