Description

Importing APM to BIG-IQ fails with error:

Failed to copy configuration to working-config; reason: Failed copying from source subcollections to target subcollections: java.lang.IllegalArgumentException: Device does not belong to an Access Group to update virtual.

Environment

  • BIG-IQ 6.x,7.x
  • BIG-IP APM upgrade
  • Rediscover/Reimport of APM service on BIG-IQ

Cause

Reimport shared does not check if the Access Group config version and the device version matches. This can happen if the device is upgraded after it has been added to the group.

Recommended Actions

Remove the device from the group and place it in a new group after the upgrade and before re-discovering/importing APM configuration as in manual:

  • Remove a device from an Access group

NOTE: If the device was already imported in the same group, then the rest of the devices in the group need to be moved to a new group.
