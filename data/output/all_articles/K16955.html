Description

Starting in BIG-IP AFM 11.5.0, you can configure denial-of-service (DoS) sweep and flood prevention through the Device DoS profile, where the vectors are configurable based on packet types to detect and prevent floods and sweeps of Internet Control Message Protocol (ICMP), User Datagram Protocol (UDP), Transmission Control Protocol (TCP), SYN without ACK, or any IP packets that originate from a single source address. The vectors support both IPv4 and IPv6 internet protocols.

The Device DoS profile is configurable by navigating the Configuration utility to Security > DoS Protection > Device Configuration.

The table lists packet types available for the DoS-related vectors configuration and a brief description about the characteristics of the packet.

Note: The packet types supported may differ across BIG-IP AFM versions. The following list contains the packet types available for configuring the DoS vectors based on BIG-IP AFM 11.6.0.

suspiciousA suspicious packet can be any of the following:
1. IPv4 packet is not multicast and ttl is lower than user-set db variable:
dos.IPLowTTL.
2. If IGMP router alert packet processing is disabled or protocol is not IGMP, and the IPv4 packet header has the options bits set even though options are not enabled (by default).
3. Too many IPv6 extension headers. (By default this is set to 4 and can be changed using the sys db variable: dos.maxipv6exthdrs.)
4. IPv6 extension header size is too big. (Either the individual header size exceeds default 128 bytes, or the total header size exceeds 336 bytes. The individual header size can be changed using the sys db variable: dos.maxipv6extsize)
5. IPv6 packet is not multicast, not sent to a link local address, and exceeds the default 1 hop. (The default hop limit can be changed using the sys db variable: Dos.IPV6LowHopCnt.)
6. TCP packet has at least one unknown option set.
7. TCP packet has at least one option that exceeds the system defaults:
   Any option with a length < 2 or a Known Option with an illegal length. Allowed lengths are:
   0 EOL: Not checked
   1 NOP: Not checked
   2 MSS: Length == 4
   3 WNS: Length == 3
   4 SACK Permitted: Length == 2
   5 SACK: Length == {10, 18, 26 or 34}
   8 Timestamp: Length == 10
   19 Signature: Length == 18
   20 SCPS: Length == 4
   21 SNACK: Length == 6
   34 MPTCP: Not checked
   128 DETECT: Length == {8, 20}
8. TCP packet total option size exceeds > (TCP Header Length-5) 4
9. TCP header has bad URG flag (flag set && urgent pointer = 0)
10. IPv4 packet has an unknown option set.
11. Tsunami SYN flood attack (dos.maxsynsize can be configured)

Recommendations

The supported packet types vary across the DoS vectors. To find the supported packet types configured on a target DoS vector, you can use the following Traffic Management Shell (tmsh) command syntax:

tmsh list /security dos device-config dos-device-config dos-device-vector { <DoS-Vector-Name> }

For example, to view the packet types configured for the DoS vector named flood, type the following command:

tmsh list /security dos device-config dos-device-config dos-device-vector { flood }
