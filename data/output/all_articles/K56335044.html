Description
Unable to delete an expired certificate on F5 Load balancer

A message similar to the following is displayed in the GUI:
   01071349:3: File object by name (/Common/default.crt) is in use.
   01071349:3: File object by name (/Common/default.key) is in use.

Environment

  • Trying to delete an Expired SSL certificate

Cause
Certificate is still applied to one or more SSL Profiles
The BIG-IP will not allow you to delete an SSL certificate that is in use, therefore we will need to detach it from them first.

Recommended Actions
Modify the SSL Profiles using the expired certificate, and remove or replace  the expired certificate.
To detach the certificate:

  1. Open the GUI and navigate to
    Local Traffic  ››  Profiles : SSL : Client
  2. Click on the affected profile
    Note: "System  ››  Certificate Management : Traffic Certificate Management : SSL Certificate List  ››  (certificate_name) >> Instances" shows which SSL profiles are using the Certificate and Key pair
  3. Replace any entries in the "Certificate Key Chain" list showing the expired certificate with a new certificate
  4. Repeat for any other affected SSL profiles
  5. You can now go and delete the certificate in question
