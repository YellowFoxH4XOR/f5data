Known Issue

This is the result of a known issue. If you configure an Active Directory (AD) dynamic resource group mapping method on the Users > Groups > Master Groups page under the Mapping Methods tab and select the Use settings from Active Directory authentication check box, AD dynamic resource group mapping fails for that master group if you change the AD authentication settings for that master group under the Authentication tab. 

Note: This issue only occurs in FirePass 6.0.2 after installing cumulative hotfix HF-602-6, HF-602-7, HF-602-7.2, or HF-602-8.

Note: This issue only occurs when configuring the AD mapping method for a single master group. This issue does not affect global dynamic resource group mapping.
 
F5 Product Development tracked this issue as CR113861 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-603-1 issued for FirePass 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround
 
You can work around this issue by performing the following procedure:
 
  1. Log on to the FirePass Administrative Console.
  2. Click Users.
  3. Click Groups.
  4. Click Master Groups.
  5. In the Group Name column, select the name of the master group you want to configure.
  6. Click the Mapping Methods tab.
  7. Clear the Use settings from Active Directory authentication check box.
  8. Select the Use settings from Active Directory authentication check box.
  9. Click Update.
