Known Issue

This is the result of a known issue. When a BIG-IP WebAccelerator-enabled virtual server is processing a moderate load of requests for pages that are eligible for Edge Side Includes (ESI), the pvac process may core and restart.

F5 Product Development tracked this issue as CR137471 and CR137472, and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
