K26030584: Failed to get getRPM build response within timeout for f5-cloud-failover

Type
Support Solution
Published
2022-07-28
Updated
2026-02-20
Applies to
  • Public Cloud
Source
https://my.f5.com/manage/s/article/K26030584

Description

A cloud environment has been successfully deployed.
UCS backups can be created without problems. Then, the Cloud Failover Extension, CFE, is used to create a High Availability environment.
After that, the below logs start appearing in the LTM logs when you attempt to create a UCS.

<Timestamp> <hostname> warning tmsh[5445]: 01420013:4: [api-status-warning] sys/ecm/cloud-provider is deprecated
<Timestamp> <hostname> info iAppsLX_save_pre[5574]: Exporting: f5-cloud-failover - /var/config/rest/iapps/f5-cloud-failover
<Timestamp> <hostname> err iAppsLX_save_pre[5574]: Failed to get task response within timeout for: /shared/iapp/build-package/44267c22-48ae-4cde-b2d5-c5ad24fb8f00
<Timestamp> <hostname> err iAppsLX_save_pre[5574]: Failed to get getRPM build response within timeout for f5-cloud-failover

Environment

  • Azure
  • AWS
  • iAppLX
  • Cloud Failover Extension

Cause
Certain iAppLX packages are not saved in a UCS and are not rolled forward after a BIG-IP upgrade or restoring a UCS file generated from an affected system and will be unavailable for use.

  1. f5-cloud-failover-1.4.0-0.noarch.rpm
  2. f5-service-discovery-1.2.9-2.noarch.rpm
  3. f5-telemetry-1.12.0-3.noarch.rpm

Recommended Actions

Follow the recommended actions in K04548517.
