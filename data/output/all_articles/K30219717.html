Description
This procedure can be used for any scenario where the BIG-IP or BIG-IQ swap memory is too small for the device. For instance, BIG-IQ heavily uses java components, which in turn means heavy usage of swap memory. 

Environment

  • BIG-IP or BIG-IQ
  • swap memory

Cause
F5 Support recommends that the swap memory be sized to at least one-eighth of the total memory available. BIG-IQ, for example, makes heavy usage of swap memory and may need additional swap memory allocated. For instance, if you have 32 GB of memory provisioned for your BIG-IQ deployment, you may want to have the swap volume sized to 4 GB.

Recommended Actions

  1. Get the UUID for the swap volume.

    blkid

    Example output:

    /dev/sda1: SEC_TYPE="msdos" LABEL="DAT.BOOT.1" UUID="D105-C608" TYPE="vfat"
    /dev/sda2: UUID="649a5bb6-98ea-41eb-b145-17f310964867" TYPE="swap"
    /dev/sda3: UUID="IRNyeJ-Wdo5-hKSO-D0co-wdRC-ZPoL-7QL1Jo" TYPE="LVM2_member"
    /dev/mapper/vg--db--vda-dat.maint.1: LABEL="dat.maint.1" UUID="38e7b250-af66-4d8a-8080-c67ab27ec0d3" SEC_TYPE="ext2" TYPE="ext3"
    /dev/mapper/vg--db--vda-dat.share.1: LABEL="dat.share.1" UUID="bd000880-7b14-4690-b771-d34d82eae069" TYPE="ext4"
    /dev/mapper/vg--db--vda-dat.log.1: LABEL="dat.log.1" UUID="5b9537df-55a2-42d4-89a8-56a9279825f3" TYPE="ext4"
    /dev/mapper/vg--db--vda-dat.swapvol.1: UUID="28fda451-050b-4021-983c-067f64ebb84b" TYPE="swap"   <<<<<<<< We are interested in this UUID

  2. Remove all current swap provisioning. It may take a while to drain swap.

    swapoff -a 

  3. Use the top command to monitor swap drainage.

    top

  4. Double check that you have the correct device name (UUID)

    file -s -L /dev/mapper/vg--db--vda-dat.swapvol.1

    Example output:

    /dev/mapper/vg--db--vda-dat.swapvol.1: Linux/i386 swap file (new style), version 1 (4K pages), size 262143 pages, no label, UUID=28fda451-050b-4021-983c-067f64ebb84b

    Note: BIG-IQ devices will display the UUID with the above command output. On other BIG-IP devices, verify the UUID with the blkid command.

  5. Resize the swap volume.

    lvresize --size <desired size in GB (append G to integer)> /dev/mapper/vg--db--vda-dat.swapvol.1

    For example:

    lvresize --size 4G /dev/mapper/vg--db--vda-dat.swapvol.1

    Example output:

      Size of logical volume vg-db-vda/dat.swapvol.1 changed from 1.00 GiB (256 extents) to 4.00 GiB (4096 extents).
      Logical volume vg-db-vda/dat.swapvol.1 successfully resized.

  6. Execute the resizing and activate the newly resized swap file system: 

    mkswap -U <UUID> /dev/mapper/vg--db--vda-dat.swapvol.1

    For example:

    mkswap -U 28fda451-050b-4021-983c-067f64ebb84b /dev/mapper/vg--db--vda-dat.swapvol.1

    Example output:

    mkswap: /dev/mapper/vg--db--vda-dat.swapvol.1: warning: wiping old swap signature.
    Setting up swapspace version 1, size = 16777212 KiB
    no label, UUID=28fda451-050b-4021-983c-067f64ebb84b

  7. Add swap back

    swapon /dev/mapper/vg--db--vda-dat.swapvol.1
