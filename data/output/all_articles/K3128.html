K3128: Loading changes to CRL files

Topic

When you edit a CRL file for a certificate (including the intermediate-ca.crt) from the command line or the Configuration utility, the BIG-IP system does not immediately use the new version because it does not automatically check for newer versions of configuration files.

The BIG-IP system is designed this way so that you can make several changes to the configuration file and then choose a time to activate all the changes.

In the case of certificates or CRL files, you must execute the b load or proxyd command to instruct the BIG-IP system to use the new information. If you plan on using an automated process to update CRL files or certificates, keep this design in mind.

In contrast, if you make a change to an SSL proxy structure (for example, changing the certificate that it uses) from the command line, the BIG-IP system will use the new information immediately; however, the new information is not saved to the disk until you manually save the configuration using the b save command.

If you make a change to an SSL proxy structure from the Configuration utility (for example, changing the certificate that it uses) the BIG-IP system will use the new configuration immediately and save the configuration to the disk, because the system automatically restarts proxyd when you click Apply.

F5 recommends that you use the Configuration utility when you make changes to the SSL proxy structure.
