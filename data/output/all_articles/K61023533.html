Known Issue

A BIG-IP system licensed with the carrier-grade network address translation (CGNAT) module may display a Provisioning Warning message.

This issue occurs when all of the following conditions are met:

  • You have licensed the CGNAT module (standalone CGNAT only) for your BIG-IP system.
  • You have configured resource provisioning with required CGNAT and BIG-IP LTM modules.

Impact

The Configuration utility displays a resource provisioning warning message. This message is cosmetic and does not impact the underlying functionality of the product.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After provisioning the CGNAT and BIG-IP LTM modules, the upper-left corner of the Configuration utility displays the following message:

    Provisioning Warning

  • When accessing the command line of the affected system, the command line prompt displays the following message:

    [<username>@<hostname>:ModuleNotLicensed:<state>:<deployment type>] <directory> #
