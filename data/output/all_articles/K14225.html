Known Issue

A place-rule interruption may fail to generate a report, or the generated report includes an inaccurate reason for the interruption.

This issue occurs when one of the following conditions are met:

  • The ARX system reboots.
  • The ARX system has a scheduled update.
  • A configuration has been updated.

Impact

You receive a message that indicates a failure, but the message does not indicate what the failure was, or does not include a report.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The system does not generate a report.
  • When the system generates a failure report, the text in the report appears similar to one of the following messages:

    % WARNING: RULE_INTERRUPTED (36372512):

      The execution of the rule was interrupted by a configuration change, scheduled update or system reboot. Ensure the schedule evaluation rate is not shorter than the time it takes for the rule to run. The rule may also take longer to complete a run because of failures. Check the syslog for warnings from the policy subsystem. The event that caused the interrupt was 'Update Complete'.

    % WARNING: RULE_INTERRUPTED (36372512):

      The execution of the rule was interrupted by a configuration change, scheduled update or system reboot. Ensure the schedule evaluation rate is not shorter than the time it takes for the rule to run. The rule may also take longer to complete a run because of failures. Check the syslog for warnings from the policy subsystem. The event that caused the interrupt was 'Reset'.
