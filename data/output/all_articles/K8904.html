Known Issue

This is the result of a known issue. When creating a new policy using the Microsoft Outlook Web Access (OWA) Exchange 2007 security policy template, the domains value in the Policy Builder is pre-populated with the following value:

https://10.4.0.65:443 (10.4.0.65), Encryption=Yes

You can safely remove the URL, as it was initially used as a place holder value when the policy was created.

F5 Product Development tracked this issue as CR100977 and it was fixed in BIG-IP ASM 9.4.6. For information about upgrading, refer to the BIG-IP ASM release notes.
