After obtaining the new NIC from F5, perform the following steps:

Note: NICs received from a source other than F5 are not certified to work with BIG-IP Server Appliances.

  1. Install the card in the BIG-IP Server Appliance.
  2. Power up the system.
  3. Run the First-Time Boot utility (FTBU)/Setup Utility and do the following:
    • For BIG-IP and 3-DNS 4.0 through 4.6.4, assign the cards to the appropriate VLAN.
    • For BIG-IP 2.1 through 3.3.1 PTF-06 and 3-DNS 2.0 through 4.0.2, assign an IP address to each card.

      The kernel will load the appropriate device driver for the cards.

Important: If you are replacing previously installed NICs, or if you are running BIG-IP or 3-DNS 4.0 or later, you may need to re-license your unit. For more information, refer to K524: Re-licensing a BIG-IP or 3-DNS Controller after replacing network interface cards (NICs).
