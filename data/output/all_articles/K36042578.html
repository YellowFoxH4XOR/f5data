K36042578: BIG-IP LTM 12.1.5 Pool health monitors down, hours after upgrading to 12.1.5.3

Applies to

Source

Description

  • Pool health monitors down, after upgrading to 12.1.5.3.
  • bigd process is leaking memory.

Environment

  • TMOS 12.1.5.3
  • Configuration contains HTTPS health monitors.

Cause

A memory leak in the bigd process exists in TMOS 12.1.5.3. 
Bug ID 625156: Bigd memory leak

Recommended Actions

  • To work around this, you can switch to a non-HTTPS health monitor, until the engineering hotfix can be applied.After switching to the non-HTTPS monitors, restart the bigd process, to release the leaked memory (bigstart restart bigd)
  • There is an engineering hotfix available HotFix-BIGIP-12.1.5.3.0.16.5-EHF16 :: https://downloads.f5.com/esd/product.jsp?sw=BIG-IP&pro=big-ip_v12.x&ver=12.1.5
