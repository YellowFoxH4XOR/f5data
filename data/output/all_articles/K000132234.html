Description

How to change the member order in you GTM/DNS for the Global availability load balancing method. 
In Global Availability load balancing method, the member with lowest order will be preferred first to serve the traffic.
In your current case, the member with order 0 will serve the traffic first. If the member with order 0 is unavailable, then the traffic will go to next lowest order member (i.e., order 1 here). 
In general case also pool member order is 0(Lowest) will be consider first to serve traffic connection but we can change the order preference.

Environment

-BIG-IP versions 13.x and later
-BIG-IP DNS
-Global Availability Load Balancing

Cause

Need to change the order of preference for DNS to other pool member in Global Availability

Recommended Actions

There can two ways as per below 

1. via GUI 

- Go to respective pool and click on the pool member. There is one option to change the member order as shown on the below example.

Example:
You have pool (test pool with two VS as serv1 and serv2 with Global availability load balancing method)

Go to this Path in the GUI: DNS ››  GSLB : Pools : Pool List  ››  Members : test_pool : A

- As per above screenshot you can change the member order from 0 to 1 by selecting Manage. Then select the member you want to change the order and select either Up or Down. Select Finished to apply the respective changes.

 

2. via CLI 

- Login to command line or CLI
- Enter tmos shell by running command below:

# tmsh

- Run the tmsh command below to change the member order

(tmos)# modify gtm pool <record type> <pool name > load-balancing-mode global-availability members modify { <Virtual server > { member-order 0 } }

Example:

You have pool (test pool with two VS as serv1 and serv2 with Global availability load balancing method)

(tmos)# modify gtm pool a test_pool load-balancing-mode global-availability members modify { serv1:serv1 { member-order 1 } }

- Save config by running below tmsh command:

(tmos)# save sys config
