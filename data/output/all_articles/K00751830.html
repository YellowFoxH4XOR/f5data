Description

  • You have upgraded a device and some feature fails. The issue is limited to specific Virtual Servers, however the Virtual Server may be performing any function.

Environment

  • You are using iRules LX (iLX) on the Virtual Server.
  • The iLX is failing. A message similar to this is in /var/log/ltm 
    TCL error: /irulename EVENT- ILX timeout.     invoked from within "ILX::call $RPC_HANDLE

Cause

  • The version of node.js has changed. The installed NPM packages are not compatible with the new version.

Recommended Actions

  1. Reinstall  your NPM packages.
