K000157257: BIG-IP VE on AWS: Outbound traffic unavailable for ~26 minutes following initial boot

Type
Support Solution
Published
2025-10-31
Updated
2025-10-31
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000157257

Description

After creating a new BIG-IP VE instance in AWS, you can connect to it over SSH, but the BIG-IP can’t reach the internet.

Environment

BIG-IP VE on AWS

17.5.x

Cause

F5 is tracking this issue as ID 1938345.

Recommended Actions

As a workaround, you can update the DHCP lease by restarting dhclient service on the BIG-IP.


# bigstart restart dhclient

Additional Information

Bug ID 1938345: F5 on AWS : Unable to Launch F5 BIG-IP instance with latest firmware 17.5.0 in AWS
