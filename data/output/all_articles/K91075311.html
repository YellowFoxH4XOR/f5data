Description

After changing Provisioning, the CLI may display "REBOOT REQUIRED"

Environment

  • Provisioning is changed, either by adding or removing a Module.

Cause


When Provisioning is changed, the BIG-IP may require a reboot, as changing the Provisioned Modules, changes the memory provisioning requirements, which may require the reboot.

Recommended Actions

 

  1. The reboot can either be done from the CLI or the GU
  2. CLI: Simply run the tmsh command
    (tmos) # reboot
  3. GUI: System -› Configuration -› Device -› General
    and click the Reboot button
