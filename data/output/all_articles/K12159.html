Note: For information about the requirements to configure RADIUS authentication for the ARX, refer to the Configuring RADIUS section of the CLI Network Management Guide.

When the ARX system is configured to use a RADIUS server for authentication, the user configuration on the RADIUS server must define the Cisco-Account-Info attribute with a valid group for successful authentication. However, if the Cisco-Account-Info attribute is not present, or if a valid group is not defined for the attribute, users are allowed to log in to the ARX Manager GUI but are not allowed to make configuration changes or affect the ARX system operation.

Note: Clients are not allowed to access the ARX CLI via SSH or Telnet if the Cisco-Account-Info attribute is not defined. For more information, refer to K12158: Error Message: AUTH_SSH-0-ERR-MSG3:: error: Radius group not configured at server.
