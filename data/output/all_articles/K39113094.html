Description

For DNS query resolution on the SSLO, you can choose to either send it out directly to a public DNS on the internet (such as 8.8.8.8) or to a local forwarding DNS server in your network.


Environment

  • SSL Orchestrator doing DNS resolution


Cause

None


Recommended Actions

To configure DNS query resolution on the SSLO:
  1. Navigate to the SSL Orchestrator  ››  Configuration page.
  2. Click the 'gear' icon on the upper right-hand corner (next to the version).
  3. Click on the 'pencil' icon to edit. This will take you to the 'System Settings' page.
  4. Select the IP family (IPv4, IPv6, both IPv4 and IPv6) you'll be using for this deployment
  5. From the DNS Query resolution dropdown, select either Internet Authoritative Nameserver or Local Forwarding Nameserver (you can only choose one). 
Note: Direct resolution can be more reliable than using forwarders but requires outbound UDP+TCP port 53 access to the Internet.
  1. Specify the IP address/es of the DNS servers you'd like to use
  2. From the Gateways list, you can choose to use the Default Route or Create a new gateway
Select Default route if you want outbound/Internet traffic to use the default route on the BIG-IP system.
Select Create new gateway if you want to define a list of gateways (routers) to handle outbound SSL traffic (and control the share of traffic each is given)

8. click Save & Next, and then Deploy


Additional Information

By configuring this via the SSLO Configuration menu, the iApp will automatically configure the relevant IPs under System  ››  Configuration : Device : DNS page for both 'DNS Lookup Server List' and 'BIND Forwarder Server List' settings. So no need to manually configure those.
