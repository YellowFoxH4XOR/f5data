Description

What web browser versions are supported for accessing the F5OS WebUI / GUI?

Environment

  • F5OS
  • VELOS
  • rSeries
  • GUI

Cause

None

Recommended Actions

None

Additional Information

The F5OS WebUI supports the latest versions of the Chrome, Firefox, and Edge browsers at the time of each F5OS release.

You may experience unusual or broken GUI behaviour when using very old browser versions which are no longer supported by Google, Mozilla or Microsoft.
