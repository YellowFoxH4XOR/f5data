Known Issue

If you created a monitor using the Configuration utility, the configuration load may fail.

This issue occurs when all of the following conditions are met:

  • You create a custom monitor using the Configuration utility.
  • The monitor contains a receive string that includes a single backslash (\) character.
  • You attempt to load the system configuration.

Impact

You are unable to load the configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H612367 on the Diagnostics > Identified > High screen.
  • When you attempt to load the system configuration, you observe an error message similar to the following example:

    01070753:3: Monitor /<partition>/<monitor name> recv parameter contains an invalid regular expression (Invalid preceding regular expression). Unexpected Error: Loading configuration process failed.

Resolution

Status

F5 Product Development has assigned ID 605175 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can set the receive string to use a double backslash (\\). This action allows the configuration to load, and the monitor checks for a single backslash in the received content.

Impact of workaround:  Performing the suggested workaround should not have a negative impact on your system.
