Known Issue

The Traffic Management Microkernel (TMM) may produce a core file on a BIG-IP Policy Enforcement Manager (PEM) system when policy change events apply to active connections.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP PEM system to use a bandwidth control policy.
  • The BIG-IP PEM system is processing active connections.
  • A PEM policy change event occurs, which applies to the active connections.

Impact

The BIG-IP PEM system fails to process traffic for a brief period of time.

The BIG-IP PEM system fails over to another host in the device group.

TMM generates a core file in the /var/core directory.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to process traffic for a brief period of time.
  • The BIG-IP system fails over to another host in the device group.
  • TMM generates a core file in the /var/core directory.

Workaround

To work around this issue, you can attach the bandwidth controller to the PEM policy after the PEM policy change event, or avoid PEM policy changes while the BIG-IP PEM system is processing live traffic.

Impact of workaround: The workaround should not have a negative impact on your system.
