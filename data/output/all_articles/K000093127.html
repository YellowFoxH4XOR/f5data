K000093127: [F5OS-C] Radius NAD-IP-Address is taking from NAS-IP, and the NAS-IP is set Internal IPv6 IP automatically.

Type
Support Solution
Published
2022-12-08
Updated
2023-02-07
Applies to
  • F5OS
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000093127

Description

RADIUS server see NAS-IP address and take it to NAD-IP, and failing authentication. We do not set IPV6, but VELOS is sending NAS-IP as IPv6.

For example:

RADIUS Protocol
    Code: Access-Request (1)
    Packet identifier: 0x40 (64)
    Length: 98
    Authenticator: 7acbac01c62b7ae844349f4561517b51
    Attribute Value Pairs
        AVP: t=User-Name(1) l=9 val=foouser
        AVP: t=User-Password(2) l=18 val=Encrypted
        AVP: t=NAS-IPv6-Address(95) l=18 val=fe80::42:64ff:fe41:3202   <---
        ...

How can we set NAS-IP?
 

Environment

  • F5OS-C
  • VELOS
  • v1.x
  • RADIUS authentication

 

Cause

  • Bug ID 1205345

System sends an IPv6 RADIUS attribute in access requests towards the RADIUS, even when only configured for IPv4.

This should NOT prevent successful authentication in most cases.
 

Recommended Actions

The expected NAD-IP should be able to set by the RADIUS server side, so please configure your RADIUS server to use IP address VELOS sends.

NOTE: NAS-IP can not be changed by manually and It is set IPV6 which is not configured by admin due to Bug ID 1205345.
