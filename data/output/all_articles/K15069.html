Known Issue

Embedded Packet Velocity Acceleration (ePVA) may not function for Last Hop Pool connections.

This issue occurs when the following conditions are met:

  • The tm.lhpnomemberaction DB variable is set to 2.
  • The last hop pool contains a single member.

The tm.lhpnomemberaction DB variable allows you to control how the BIG-IP system responds to client traffic that originates from an address other than those defined in the last hop pool. When the variable is set to 2, the system only routes the client traffic back through a member defined in the last hop pool.

Impact

The BIG-IP system fails to accelerate affected connections.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Traffic Management Shell (tmsh) show /sys connection command shows that acceleration is not functioning for the affected connection.

    For example:

    # show sys connection all-properties
    Sys::Connections
    10.1.1.200:40567 - 10.1.1.100:22 - 10.10.10.173:40123 - 10.10.10.3:22
    TMM 11
    Type any
    Acceleration none
    Protocol tcp
    ...
    Total records returned: 1
