Topic

You can restore the BIG-IP ASM database to a default or clean configuration using the tsconfig.pl script. This script starts the BIG-IP ASM configuration, which creates the necessary settings and entries and re-initializes the BIG-IP ASM database. To restore the BIG-IP ASM database to a default configuration, perform the following procedure:

Impact of procedure: This procedure stops ASM traffic processing, restores the BIG-IP ASM MySQL database to default settings and erases all existing BIG-IP ASM policy data. It does not affect or restore BIG-IP LTM configuration objects. For more information, refer to K13127: Restoring the BIG-IP configuration to factory default settings (11.x - 13.x).

  1. Log in to the BIG-IP ASM command line.
  2. To stop the BIG-IP ASM module, type the following command:

    tmsh stop /sys service asm

  3. To run the tsconfig.pl script, type the following command:

    /usr/share/ts/bin/tsconfig.pl

  4. To restart the BIG-IP ASM module, type the following command:

    Note: BIG-IP ASM security policies that weren't deleted prior to running the tsconfig.pl script are automatically re-created when the BIG-IP ASM service is restarted. To completely remove BIG-IP ASM policies from the system, run the tmsh delete asm policy '*' command in administrative partitions containing security policies.

    tmsh start /sys service asm

The BIG-IP ASM database is now cleared of previous configuration information and ready for a new configuration.
