Description

Clarifies that for SNMP TRAP messages sent from system controllers running F5OS-C 1.8.1 and later, the source IP address used is the static management IP of each controller, not the floating management IP. This affects network monitoring, firewall rules, and SNMP manager configuration in environments with both static and floating management IPs.

Environment

  • Product: F5OS-C
  • Version: 1.8.1 and later
  • Configuration:
    • System controllers with static management IPs and a floating management IP
    • SNMP TRAPs sent to remote receivers

Cause

System controllers are designed to send SNMP TRAP messages using their respective static management IP addresses rather than the floating management IP address.

Recommended Actions

  • Configure SNMP managers, firewall rules, and monitoring systems to accept TRAPs from the static management IP addresses of the system controllers.
  • To verify the source IP address used for SNMP TRAPs, use the following CLI command:
    ip route get to 10.0.0.1
  • Example output:

    • 10.0.0.1 via 10.154.81.254 dev mgmt-fixed src 10.154.81.6

    cache

  • Do not expect SNMP TRAPs to originate from the floating management IP address.
