K41708017: Tag-based failover not working in Cloud Failover Extension with addressGroupDefinitions set

Type
Support Solution
Published
2022-04-19
Updated
2025-02-06
Applies to
  • Public Cloud
  • BIG-IP
  • F5 Automation and Orchestration
  • F5 BIG-IP Cloud Failover
  • Amazon Web Services
Source
https://my.f5.com/manage/s/article/K41708017

Description
Elastic IP is not failing over based on tags.

You are using F5 Cloud Failover Extension (CFE) in a cross-Availability Zone (AZ) configuration, with Elastic IPs configured with required tags for tag-based discovery and failoverAddresses.addressGroupDefinitions set in the CFE declaration.

Environment

  • BIG-IP
  • Amazon Web Services
  • F5 Cloud Failover Extension version 1.7.0 or higher
    • addressGroupDefinitions included under failoverAddresses in the declaration

Cause
Cloud Failover Extension does not support using both statically-configured addressGroupDefinitions and tag-based discovery.

Recommended Actions

Either remove all addressGroupDefinitions and ensure that all resources are tagged correctly, or statically configure all resources in the CFE declaration.

Additional Information
None.
