Issue

Error Message

notice mcpd[<PID>]: 010719e7:5: Virtual Address <name> general status changed from <orig_value> to <new_value>

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <name> is the partition and name of the virtual address.
  • <orig_value> is the general status the virtual address changed from.
  • <new_value> is the general status the virtual address changed to.

For example:

notice mcpd[4353]: 010719e7:5: Virtual Address /Common/10.10.10.10 general status changed from BLUE to GREEN

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The BIG-IP system detects a general status change for a virtual address.

For example, the general status of a virtual address may change from BLUE (Unknown) to GREEN (Available) during the normal BIG-IP boot process. Similarly, the general status may change to RED (Offline) due to a user-initiated action, such as when forcing a pool member offline for maintenance.

Impact

This message is a notification of a status change for a virtual address. Unexpected status changes could be the result of a configuration error or a lack of resource availability.

Recommended Actions

If an unexpected RED status is reported, you should verify the virtual address configuration and the availability of the associated pool members. The general status for a virtual address typically depends on one-or-more pool members and the associated configuration of the virtual address itself. For example, a pool of four members might be associated with a virtual address, and require a minimum of two pool members to be available for the virtual address to be marked up.
