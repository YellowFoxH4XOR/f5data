K47312264: View and manage service requests owned by others on MySupport

Type

Published
2021-04-07

Applies to

Source

Description

By default, a user can only view and manage Service Requests created under their own user account.
If a user needs to view and manage Service Requests owned by others, they will need special permission.

Environment

  • MySupport
  • View service request
     

Cause

None
 

Recommended Actions

For special permission requests,  please approach your F5 Account Managers.
