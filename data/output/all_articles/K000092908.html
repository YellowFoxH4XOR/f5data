K000092908: Tenants cannot be deployed when F5OS-A is upgraded to 1.3.1

Type
Support Solution
Published
2022-12-01
Updated
2022-12-05
Source
https://my.f5.com/manage/s/article/K000092908

Description

You should consider using these procedures under the following conditions:

  • You have upgraded F5OS-A from 1.2.0 or earlier to 1.3.1.
  • In F5OS-A 1.2.0 or earlier, you have provisioned a tenant using the default value for Virtual Disk Size/Storage ( 76 GB ).
  • In F5OS-A 1.3.1, from the Management CLI you encounter the following error when the tenant is deployed:
Appliance-1(config)# tenants tenant <tenant name> config running-state deployed
Appliance-1(config-tenant-<tenant name>)# commit and-quit
Aborted: 'tenants tenant <tenant name> config': Storage size(76) must be greater than or equal to 77G

Environment

  • F5OS-A
  • F5OS upgrade to 1.3.1
  • Management CLI
  • Tenant provisioning

Cause

1169193

Recommended Actions

Run the following procedures from Management CLI to modify and deploy the tenant:
1. Access the configuration mode terminal from Management CLI:
Appliance-1# configuration terminal
Entering configuration mode terminal
2. Change the tenant's storage size to a value equal or greater than 77 GB:
Appliance-1(config)# tenants tenant <tenant name> config storage size 77
3. Deploy the tenant:
Appliance-1(config-tenant-<tenant name> )# config running-state deployed
4. Commit the changes and exit the configuration mode terminal:
Appliance-1(config-tenant-<tenant name> )# commit and-quit
