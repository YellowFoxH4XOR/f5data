Topic

You should consider using this procedure under the following condition:

  • You attempt to assign iRules to virtual servers using the BIG-IP Controller in standard Kubernetes and OpenShift environments.

Description

The BIG-IP Controller can deploy any iApp on a BIG-IP device using an F5 ConfigMap and virtual server. When you create an F5 ConfigMap, you can use the iappVariables definition to specify iRules that you want to assign to the virtual server.

The parameters you use to configure iappVariables correspond to fields in the Presentation section of the iApp template. When you create or customize an iApp template, you can create an iApp variable for your iRules, and then later insert existing iRules in the F5 ConfigMap.

Notes:

  • The iApp and iRules must exist on your BIG-IP before the BIG-IP Controller attempts to deploy the iApp. F5 recommends you create the iApp and iRules in a partition that the BIG-IP Controller does not manage. This approach enables you to manually modify the iApp and iRules independently of the BIG-IP Controller at a later time, if needed.
  • For more information about iApp templates, refer to the About iApps templates section of The Parts of iApps chapter in the BIG-IP iApps Developer's Guide.
  • For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You are running compatible versions of Kubernetes, OpenShift, and BIG-IP Controller, as indicated in the BIG-IP Controller/Platform compatibility matrix on the F5 Container Ingress Services Releases and Versioning page.

Procedures

Assigning iRules using the 'iappVariables' definition of a ConfigMap

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Create your iRules in a partition not managed by the BIG-IP Controller. For more information, refer to the BIG-IP System: iRules Concepts manual.

    Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

  2. In the F5 ConfigMap, in the variable designated to contain iRules as specified in the iApp template Presentation section, type a parameter value.

    For example, the following f5.http template provides a variable for iRules with the parameter irules__irules.

    kind: ConfigMap
    apiVersion: v1
    metadata:
      name: k8s.http
      namespace: default
      labels:
        f5type: virtual-server
    data:
      # See the f5-schema table for schema-controller compatibility
      # https://clouddocs.f5.com/containers/latest/releases_and_versioning.html#f5-schema
      schema: "f5schemadb://bigip-virtual-server_v0.1.7.json"
      data: |
        {
          "virtualServer": {
            "backend": {
              "serviceName": "myService",
              "servicePort": 80
            },
            "frontend": {
              "partition": "k8s",
              "app": "/Common/f5.http",
              # Output removed for brevity  …
              # Output removed for brevity  …
              # Output removed for brevity  …
              "iappVariables": {
              # Output removed for brevity  …
              # Output removed for brevity  …
              # Output removed for brevity  …
                "pool__pool_to_use": "/#create_new#",
                "pool__port": "4430”,
                "irules__irules": “/Common/irule1 /Common/irule2”
              }
            }
          }
        }
