K88212483: An error has occurred while trying to process your request while accessing Platform under System menu

Type
Support Solution
Published
2023-04-08
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K88212483

Description

When trying to access the System > Platform page in the WebUI, you encounter an error message stating "An error has occurred while trying to process your request."

Environment

  • Configuration utility
  • Platform page
  • BIG-IP High Availability (HA) pair

Cause

The GUI page encountered an error when trying to retrieve the following information without the required configuration:

  • General Properties
  • Management Port Configuration (Automatic (DHCP) or Manual)
  • Management Port
  • IP Address[/prefix]
  • Network Mask
  • Management Route
  • Host Name
  • Host IP Address
  • Time Zone

The issue is related to a static metadata route that needs to be removed for the DHCP management address to be applied correctly.

Recommended Actions

To resolve this issue, perform the following steps on both devices in the HA pair:

  1. Log in to the BIG-IP Command Line Interface (CLI).
  2. Delete the static metadata route by running the command: 
    tmsh delete sys management-route metadata-route
    Save the configuration changes with the command: 
    tmsh save sys config
  3. Reboot the device by running the command: 
    reboot

After completing these steps, the DHCP management address should be applied correctly, and you should be able to access the System > Platform page without encountering the error.
