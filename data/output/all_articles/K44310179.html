Description

BIG-IP devices went active/active after upgrade software to 15.X

Environment

Units setup in High Availability for Active-Standby

Cause

HA Self-IP's configured with port-lockdown set to Allow None.

Recommended Actions

Use one of the following actions to address the topic covered in the description.

  • Change the HA configured Self-IP's port-lockdown to Default
  • Change the HA configured Self-IP's port-lockdown to Allow Custom and add UDP 1026
