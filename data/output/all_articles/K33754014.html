Known Issue

Dynamic route information may be temporarily lost after you modify the system hostname.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with dynamic routing.
  • You modify the BIG-IP system hostname.

Impact

Dynamic routing is temporarily disrupted.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The configured routing protocol loses leaned dynamic route information and must relearn it.
  • Routing that relies on the dynamic router is not routed correctly.

Resolution

Status

F5 Product Development has assigned ID 639039 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases, point releases, or hotfixes that resolve this issue, refer to the following table.

Type of fixFixes introduced inRelated articles
Release13.1.0K2200: Most recent versions of F5 software
Point release/hotfix12.1.3.2K9502: BIG-IP hotfix and point release matrix

Workaround

To work around this issue, you can modify the BIG-IP hostname during a scheduled maintenance window. To do so, perform the following procedure:

Impact of workaround: F5 recommends that you perform the following procedure during a scheduled maintenance window.

  1. Log in to the Configuration utility.
  2. Navigate to System > Platform.
  3. In the Host Name box, type the new hostname.
  4. Click Update.

    Important: If your BIG-IP system is a member of a device service clustering (DSC) device group, refer to K15700: Changing the BIG-IP hostname does not update the device name when the device is a member of a DSC device group.
