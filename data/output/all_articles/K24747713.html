Description

In some situation, Virtual IPs configured on Virtual Big-IP are not able be seen on upstream Switch.
No traffic (including ARP) was passing at all via VLANs.

Environment

  • Virtual Big-IP (VMWare Edition)
  • Floating Virtual IP
  • Cisco VM networking in the ACI fabric

Cause

F5 recomendation for Virtual Edition BIG-IP is set vlan per interface (access mode).
If you trying to configure multiple vlans per one NIC - this could require enable additional option on Hypervisor to allow interface pass tagged packets.

Recommended Actions

Enable Promiscuous Mode in the Hypervisor (VMWare KB: 1004099)
  1. Log into the ESXi/ESX host or vCenter Server using the vSphere Client.
  2. Select the ESXi/ESX host in the inventory.
  3. Click the Configuration tab.
  4. In the Hardware section, click Networking.
  5. Click Properties of the virtual switch for which you want to enable promiscuous mode.
  6. Select the virtual switch or portgroup you wish to modify and click Edit.
  7. Click the Security tab.
  8. From the Promiscuous Mode dropdown menu, click Accept.
Enable Forget Transmits in the Hypervisor - when the Forged transmits option is set to Accept, ESXi does not compare source and effective MAC addresses. To protect against MAC impersonation, you can set the Forged transmits option to Reject.
  1. Log into the ESXi/ESX host or vCenter Server using the vSphere Client.
  2. Select the ESXi/ESX host in the inventory.
  3. Click the Configuration tab.
  4. In the Hardware section, click Networking.
  5. Click Properties of the virtual switch for which you want to enable promiscuous mode.
  6. Select the virtual switch or portgroup you wish to modify and click Edit.
  7. Click the Security tab.
  8. In the Policy Exceptions pane, select whether to accept the Layer 2 Security policy exceptions.
