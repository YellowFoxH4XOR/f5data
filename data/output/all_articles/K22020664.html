Description

How to export BIG-IP AFM Firewall rules in csv format.

Environment

  • BIG-IP device provisioned with BIG-IP AFM
  • BIG-IP AFM Firewall rules
  • iControl

Cause

None

Recommended Actions

  1. We recommend to use rest-API. To view all the configured network firewall rules recursively use the following syntax: Run below command in BIG-IP AFM device via ssh.

    <GET> /mgmt/tm/security/firewall/rule-list?"expandSubcollections=true" | jq -M
    Example:   curl -s -k -u admin:admin  -H "Content-Type: application/json" -X GET https://<ip address>/mgmt/tm/security/firewall/rule-list?"expandSubcollections=true" | jq -M

    Replace <ip address> with the management IP of the BIG-IP device

  2. It is not possible to export the BIG-IP AFM firewall rules in a csv format since there is no available option in GUI.

    It can be viewed in the ucs archive in the bigip_base.conf along with seeing the rule set by running the below command via ssh that can be copied out.


    you can run below command 


    tmsh show running-config security firewall

  3.  Also you can use the following commands to see and copy the Firewall Policies and Rules from one BIG-IP to another device.

    To get the firewall policy rules from one BIG-IP AFM device via tmsh

    tmsh list security firewall policy <policy_name>
    tmsh list security firewall rule-list
    tmsh  list security firewall one-line
    tmsh  show security firewall rule-stat
    tmsh show security firewall policy


    You can use above command output and combine for your firewall rules audit review
