Issue

Error Message

err tmm[PID]: 01aa0004:3: ICAP (<client_IP:port> -> <virtual_server_IP:port>): Parsing ICAP chunked response body failed

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • <client_IP:port> is the client IP address and port where the request originates.
  • <virtual_server_IP:port> is the virtual server IP address and port being used on the BIG-IP system.

For example:

err tmm[28484]: 01aa0004:3: ICAP (192.168.5.5:82017 -> 10.10.0.5:443): Parsing ICAP chunked response body failed

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The BIG-IP system is unable to parse the chunked Internet Content Adaptation Protocol (ICAP) response body from the remote ICAP server.

Impact

The BIG-IP system stops processing the ICAP response and terminates the connection on the internal virtual server. The associated parent virtual server performs the service-down-action configured in the request-adapt or response-adapt profile.

Recommended Actions

The message indicates that the ICAP response received from the back-end server is not RFC-compliant. To address the issue, you can review and modify the back-end ICAP server settings and ensure the response is in the correct format.
