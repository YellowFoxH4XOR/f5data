Topic

An application can be configured in multiple ways to launch at the beginning of a Network Access session. Mac OS X users can perform one of the following three methods:

To pass a parameter (URL) to Firefox

To pass a parameter (URL) to Firefox, use the following Application Path and Parameter:

  • AppPath: /Applications/Firefox.app/Contents/MacOS/firefox
  • Param: http://some.site

Note: If Firefox is already running, you will receive a pop-up message announcing that Firefox is already running and only one instance can be open. Other applications may have the same limitation as Firefox; however, Safari will let you have more than one instance of the application open.

To use Firefox and not pass a URL

To use Firefox and not pass a URL, use the following Application Path and Parameter:

  • AppPath: /usr/bin/open
  • Param: /Applications/Firefox.app

Note: You cannot use this configuration, and then pass an argument to Firefox; this behavior will open an instance of Firefox, but will not direct your users to a specific site.

To use a default browser and pass a URL

To use a default browser and pass a URL, use the following Application Path and Parameter:

  • AppPath: /usr/bin/open
  • Param: http://some.site

Note: The open command is built into Mac OS X. The open command opens the requested file or location with the user's preferred application. For this example, Safari would be used by default unless the user has configured Firefox as the default.

Configuring an application to launch at the beginning of a Network Access session

To configure an application to launch at the beginning of a Network Access session, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to the Network Access : Resources page.
  3. Click the Launch Application tab.
  4. Add the path for an application and the parameters you would like that application to use.
  5. In the OS drop-down menu, select Mac.
  6. Click Add. 

Java AppTunnel

Starting in FirePass version 6.0.3, you may also create a Java AppTunnel. To do so, perform the following procedure:

  1. Log in to the Administrative Console.
  2. Navigate to Application Access: App Tunnels: Resources.
  3. Click on Add New Favorite.
  4. In the Name field, enter the name you want to call the Favorite.
  5. Click on the box next to Java based tunnel.
  6. Click Add Favorite.
  7. Click on the + next to Static Tunnels to expand that section.
  8. Click on the Add New Static Tunnel button.
  9. Select http from the New Static Tunnel drop-down menu.
  10. Add the fully qualified domain name or IP Address in the Remote host field that you want to connect to.
  11. In the Local Host field, enter the following:

    127.0.0.1
  12. Change the Local Host port to the following: 

    2222
  13. In the Application field, use the full path for the application.

    For example:
     
    /usr/bin/open "http://127.0.0.1:2222"
  14. Click on the Add New Static Tunnel button.
