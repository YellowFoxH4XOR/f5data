K000129976: SDC virtual service impacted/restart when related interface is shutdown

Type
Support Solution
Published
2022-12-13
Updated
2022-12-13
Source

Description

Shutting down of interface used by TRIPO configuration cause services to restart, impacting Traffic.
  • Virtual Servers restarted

Environment

  • SDC CF5.1
  • Interfaces which are defined in TRIPO configuration are shutdown
  • Physical interface is not cabled.

Cause

TRIPO software require interface which configured to enable on O.S level even though there is no physical cabling wired physically. For example, disabling the interface found in Additional Information Section below, will cause service impact.err,

 Recommended Actions

  1. Do not attempt to shutdown interface on Operating System level if the interface was found within TRIPO configuration.
