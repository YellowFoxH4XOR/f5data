K000158849: Differences Between .qcow2.zip.bundle and .tar.bundle Files for F5OS Tenant Images

Description

You may encounter both .qcow2.zip.bundle and .tar.bundle files when downloading tenant images for the same release, which can cause confusion regarding their intended use and compatibility.

Environment

  • F5OS platform (including F5OS-A and F5OS-C)
  • Tenant_F5OS image downloads
  • Both .qcow2.zip.bundle and .tar.bundle formats available

Cause

The .tar.bundle format was introduced to replace the deprecated .qcow2.zip.bundle format, primarily to improve image signing, verification, and support for secure key rotation using Public Key Infrastructure (PKI).

Recommended Actions

  • Use the .tar.bundle format for all new F5OS tenant image deployments, as it is recommended and supported from F5OS-A version 1.8.0 onward.
  • Deploy .tar.bundle files in environments requiring enhanced security or multi-blade support (e.g., Chiron chassis, Rseries).
  • When selecting an image file, note that the contents are functionally identical; however, the .tar.bundle includes additional metadata enabling PKI-based signature validation.

Additional Information

  • Tenants deployed from either format operate identically from a functional perspective.
  • The primary difference is in how each format handles digital signing:
    • .tar.bundle: Uses PKI-based signature validation supporting both old and new keys.
    • .qcow2.zip.bundle: Relies on preinstalled public keys without PKI support; not compatible with future key rotations.
  • The .tar.bundle format is not supported on versions of F5OS-A prior to 1.8.0.
  • Future enhancements will further expand PKI-based digital signing across F5 products.
