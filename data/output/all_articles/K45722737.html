Description

You notice the restnoded daemon is restarting and the bash terminal shell is printing such log continuously :

logger[<pid>]: Re-starting restnoded

The restnoded user does not exist in /etc/passwd and the following lines are filling /var/tmp/restnoded.out:

Error: setuid user id does not exist

The journald log is reporting failure adding user, restnoded.
For example:
journalctl | grep restnoded

logger[<pid>]: Re-starting restnoded
useradd[<pid>]: failed adding user 'restnoded', exit code: 10

Environment

  • BIG-IP
  • restnoded daemon

Cause

The restnoded init script useradd command is not able to create the restnoded user due to issue updating the /etc/group file. The restnoded daemon requires user, restnoded, to be created prior to starting the process. There may be existence of /etc/group.lock or /etc/gshadow.lock files causing the useradd command to fail.

Recommended Actions

  1. Delete any existing /etc/group.lock or /etc/gshadow.lock
