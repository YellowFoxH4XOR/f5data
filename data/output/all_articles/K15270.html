Topic

You should consider using this procedure under the following condition:

  • You want to configure a BIG-IP redundant pair in which only one of the units is licensed and provisioned for the BIG-IP DNS module.

Description

Beginning in BIG-IP 11.x, you can configure a redundant pair configuration in which only one of the units is licensed and provisioned for BIG-IP DNS (in previous versions you must provision BIG-IP DNS on both redundant pair members). This allows you to deploy a mixed redundant pair configuration in which the BIG-IP DNS system responds to DNS queries whether the system is in active or standby mode. Before deploying a mixed redundant pair configuration for a BIG-IP DNS system, you should consider the following information:

  • It is only necessary to license/provision the BIG-IP DNS module on one of the units
  • ConfigSync operations do not synchronize the provisioning configuration to the redundant pair member
  • A mixed pair configuration, in which BIG-IP DNS is licensed on only one system, does not provide redundancy in the event that the BIG-IP DNS system fails

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have defined the device clustering, failover, and configuration synchronization (ConfigSync) components for the systems.
  • You can access the Configuration utility.

Procedures

Licensing and provisioning the BIG-IP DNS module

You must license and provision the BIG-IP DNS module on one of the BIG-IP units (you can select either the active or standby). To license and provision the BIG-IP GTM module, refer to the following articles:

  • K7752: Overview of licensing the BIG-IP system
  • K12111: Provisioning licensed BIG-IP modules

Defining the BIG-IP DNS configuration

After you license and provision the BIG-IP DNS module on one of the BIG-IP systems, you can define the BIG-IP DNS configuration. To do so, perform the following procedures:

Configuring the Data Center

To create a new data center, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > GSLB > Data Centers.

    Note: In BIG-IP GTM 11.4.1 or earlier, navigate to Global Traffic > Data Centers.

  3. Click Create.
  4. Enter the settings for the data center.
  5. Click Finished.

You can now create server objects and assign them to this data center.

Configuring the BIG-IP server object

BIG-IP 13.x

After you configure the data center, you can define a BIG-IP server object that represents both the BIG-IP LTM/DNS system and the BIG-IP LTM system. To do so, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > GSLB > Servers.
  3. Click Create.
  4. In the Name option, type a unique name for the server object.
  5. From the Data Center list, select the data center that you created in the previous procedure.
  6. From the Devices list, select Add.
  7. In the Device Name field, type a name of the BIG-IP LTM/DNS system.
  8. In the Address field, type the non-floating self IP address of the BIG-IP LTM/DNS system.
  9. In the Link field, select the appropriate ink. Use the default Auto-Select value if you are unsure.
  10. Click Add.
  11. In the Device Name field, type a name of the BIG-IP LTM system.
  12. In the Address field, enter the non-floating self IP address of the BIG-IP LTM system.
  13. In the Link field, select the appropriate link. Use the default Auto-Select option if you are unsure.
  14. Click OK.
  15. From the Health Monitors > Available list, select and assign the bigip monitor.
  16. From the Virtual Server Discovery list, select an option for how you want virtual servers to be added to the system.
  17. Click Finished.

BIG-IP 11.x and 12.x

After you configure the data center, you can define the BIG-IP server object that represents the newly provisioned BIG-IP LTM/DNS system, and peer BIG-IP LTM system. To do so, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > GSLB > Servers.

    Note: In BIG-IP GTM 11.4.1 or earlier, navigate to Global Traffic > Servers.

  3. Click Create.
  4. In the Name box, type a name for the server object.
  5. From the Product list, select BIG-IP System (Redundant).
  6. In the Address List section, enter the non-floating self IP address of the BIG-IP LTM/GTM system.
  7. In the Peer Address List section, enter the non-floating self IP address of the BIG-IP LTM-only system.
  8. From the Data Center list, select the data center that you created in the previous procedure.
  9. In the Health Monitors section, assign the bigip monitor to the server.
  10. From the Virtual Server Discovery list, select an option for how you want virtual servers to be added to the system.
  11. From the Link Discovery list, select the appropriate option for how you want links to be added to the system.
  12. Click Create.

Configuring the Listener

You must define one or more listener objects to control what protocols are available for the BIG-IP DNS system to process DNS requests. A listener is assigned to a specific IP address and protocol User Datagram Protocol (UDP) or TCP on which the BIG-IP DNS system receives and processes traffic. To create the listener object on the BIG-IP DNS system, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > Delivery > Listeners > Listeners List.

    Note: In BIG-IP GTM 11.4.1 or earlier, navigate to Global Traffic > Listeners.

  3. Click Create.
  4. In the Destination box, enter the non-floating self IP address of the BIG-IP LTM/GTM system.
  5. Complete the remaining configuration for the listener object.
  6. Click Finished.

Running the bigip_add script

After adding the BIG-IP DNS configuration, you must run the bigip_add script on the BIG-IP DNS system. The bigip_add script exchanges Secure Socket Layer (SSL) certificates so that each system is authorized to communicate with the other. To run the bigip_add script, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP DNS system.
  2. Run the following command:

    bigip_add

  3. When prompted, enter the root password for the systems.
