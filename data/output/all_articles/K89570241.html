K89570241: High memory triggering aggressive mode sweeper: /Common/default-eviction- policy

Type
Support Solution
Published
2022-06-14
Updated
2025-05-13
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP LTM: 13.1.3
Source
https://my.f5.com/manage/s/article/K89570241

Description
BIG-IP may experience memory utilization spikes and trigger the aggressive mode sweeper during periods of sustained high TMM memory utilization.

You might experience error messages like these:

Aggressive mode sweeper: /Common/default-eviction- policy (0) (global memory) 3 Connections killed

Environment

  • BIG-IP VE 
  • LTM
  • Large number of configuration objects (over 10k Virtual Servers/Pools/Nodes/Monitors)
  • Sustained high TMM Memory usage (60%+), persisting through a reboot
  • Spikes in traffic volume

Cause
A Virtual Edition with a large number of configuration objects may be under-provisioned for memory resources.  If the TMM memory in use is consistently greater than 60%, any traffic volume spike could potentially drive memory utilization over the low-water aggressive sweeper activation threshold, causing connections to be killed.

Recommended Actions
Allocate additional memory to the Virtual Edition to accommodate the large configuration and reduce the TMM memory usage percentage.

Information on how to do this can be found here:

K68488650: How to add CPU and Memory resources to the BIG-IQ or BIG-IP on the VMWare ESX hypervisor
