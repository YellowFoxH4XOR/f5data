Known Issue

Configuration changes made using the Configuration utility may not synchronize to peer members of the device group.

This issue occurs when all of the following conditions are met:

  • You have multiple BIG-IP systems in a high availability (HA) configuration.
  • You have provisioned the BIG-IP LTM module and one additional module.
  • BIG-IP LTM objects synchronize using a Sync-Failover device group, and additional module objects synchronize using a Sync-Only device group.
  • You delete and re-create the Sync-Failover device group.
  • You use the BIG-IP Configuration utility to modify the value of a database object, such as Link Down Time on Failover or Cluster Options.
  • You perform a configuration synchronization (ConfigSync).

Impact

The system does not synchronize configuration changes to peer members of the device group, and the BIG-IP system's Sync Status does not change.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Sync Status does not change after you modify the BIG-IP configuration using the Configuration utility.
  • Peer devices in the device group do not have the same configuration after you perform a ConfigSync.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to synchronize the configuration. To do so, perform one of the following procedures:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Using tmsh to synchronize configuration changes that you made using the Configuration utility

  1. Log in to the Configuration utility.
  2. Make the necessary modification to the configuration.
  3. To log in to tmsh on the same BIG-IP system type the following command:

    tmsh

  4. To set the BIG-IP system as synchronization leader, use the following command syntax:

    modify cm device-group <device group name> devices modify { <device name> { set-sync-leader } }

    For example, to set the BIG-IP system named example.com as synchronization leader for the device group named example, type the following command:

    modify cm device-group example devices modify { example { set-sync-leader } }

  5. If the device group is not automatically synchronized, use the following command syntax to manually synchronize the configuration:

    run cm config-sync to-group <device group name>

    For example, to synchronize the configuration to all peer members in the device group named example, type the following command:

    run cm config-sync to-group example

Using tmsh to change the value of a database variable and synchronize configuration changes

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To modify the db variable, use the following command syntax:

    modify sys db <variable name> value <new value>

    For example, to change the Link Down Time on Failover option to 10 seconds, type the following command:

    modify sys db failover.standby.linkdowntime value 10

  3. To save the configuration, type the following command:

    save sys config

  4. To synchronize the configuration to all peer members in the device group, use the following command syntax:

    run cm config-sync to-group <device group name>

    For example, to synchronize the configuration to all peer members in the device group named example, type the following command:

    run cm config-sync to-group example
