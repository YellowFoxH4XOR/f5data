Description

When you try to create a CSR for the Management Interface, on F5OS, it will fail if a TLS Key does not already exist.

You may see an error like:
Error: Unable to create CSR. /system/aaa/tls/config/key is not configured.

Environment

F5OS Appliance or Velos

Configuration Utility or CLI

Cause

This is due to the following BZID:
Bug ID 1496393 Allow creation of key during create-CSR


Recommended Actions

You can workaround this issue, by first creating a Self-Signed Certificate with the option store-tls set to true.
Then creating the CSR will work as expected.


At the time of publication this issue was not fixed, so if you would like a fix for this issue, please open a case with support requesting an EHF to resolve ID1496393
