Issue

Error Message

err mcpd[<PID>]: 01071cf9:3: The provision module <Module Name> requires TurboFlex profile <Profile Name>. Please either un-provision the module or choose the required profile. For more information, please see 'tmsh help sys turboflex' on the command line, or look at the 'Help' tab on the TurboFlex page under Resource Provisioning.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <Module Name> is the name of the module the system is reporting.
  • <Profile Name> is the name of the profile the system is reporting.

For example:

err mcpd[7433]: 01071cf9:3: The provision module afm requires TurboFlex profile turboflex-security. Please either un-provision the module or choose the required profile. For more information, please see 'tmsh help sys turboflex' on the command line, or look at the 'Help' tab on the TurboFlex page under Resource Provisioning.

Message Location

You may encounter this message in the following locations:

  • /var/log/ltm
  • The Configuration utility

Description

This message occurs when the following condition is met:

  • You did not activate the TurboFlex profile that the system requires to provision the module you want.

This error displays when one of the following happens:

  • You attempt to provision a module without activating the required TurboFlex profile.
  • You provision a module while the required TurboFlex profile is active, but when you attempt to switch to a different TurboFlex profile, the second profile does not allow the module you provisioned while the first profile was active.

Impact

You cannot provision a module.

Recommended Actions

Do one of the following:

  • Navigate to System ›› Resource Provisioning : TurboFlex Try selecting a turboflex profile
  • Change the TurboFlex profile using the following command:
    • tmsh modify sys turboflex profile-config type <profile>
  • Un-provision the module that is preventing you from changing TurboFlex profiles using the following command:
    • modify sys provision <module> level none
