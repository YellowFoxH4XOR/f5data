K000092979: Wide ip traffic, is not forwarded to the next available pool when the current pool goes down

Type
Support Solution
Published
2022-12-05
Updated
2026-03-04
Applies to

  • BIG-IP DNS: 21.X.X, 17.X.X, 21.0.X, 21.0.0, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.3, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0
Source
https://my.f5.com/manage/s/article/K000092979

Description

Multiple pools are assigned on a wide ip and when the current pool goes down traffic is not forwarded to the next available pool.

Environment

  • BIG-IP GTM / DNS
  • Preffered, Alternate or Fallback load balancing methods in the pool option is set to Drop Packet or Return to DNS

Cause

None. It is an expected behavior.

Load balancing methods which do not depend on member availability, such as "Drop Packet" or "Return to DNS" will render the pool available even when all the pool members are marked down.

Recommended Actions

Set the load balancing method to an option which depends on member availability and not "Drop Packet" or "Return to DNS".
