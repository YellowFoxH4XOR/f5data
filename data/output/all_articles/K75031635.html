Known Issue

A file object and reference that are deleted within the same batch mode transaction may fail.

This issue occurs when the following condition is met:

  • You perform delete operations on a File object (for example, an ssl key) and the object that it references (for example, a ClientSSL profile), within the same transaction using one of the following methods:
    • You perform the task using iControl.
    • You perform the task using the Traffic Management Shell (tmsh).
    • You perform the task by reconfiguring an iApp, and attempt to perform an incremental configuration synchronization (ConfigSync) operation.

Impact

The ConfigSync operation or batch mode transaction fails.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • A device group ConfigSync operation or a batch mode transaction fails with an error message similar to the following example:

    01071349:3: File object by name (/Common/pair1) is in use.

Workaround

To work around this issue, you can perform a full ConfigSync instead of an incremental ConfigSync after you reconfigure an iApp. To perform a full ConfigSync, refer to K13920: Performing a ConfigSync using the Configuration utility. In the case of iControl and the tmsh utility, you can perform the delete operations in separate transactions by first deleting the object reference (for example, a Client SSL profile) before performing a second transaction to delete the associated SSL key.

Impact of workaround: Performing the recommended procedure should not have a negative impact on your system.
