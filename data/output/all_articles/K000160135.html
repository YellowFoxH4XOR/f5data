Description

After upgrading BIG-IP APM, the OIDC provider discovery process may fail with the error: "URI path /tm/access/oidc/discover not registered. Please verify URI is supported and wait for /available suffix to be responsive." The automatic discovery under Access ›› Federation : OAuth Client / Resource Server : Provider stops working and must be performed manually.

Environment

  • BIG-IP APM

  • Access ›› Federation : OAuth Client / Resource Server : Provider with automatic discovery

  • Issue occurs after upgrade

Cause

Insufficient allocated memory for java/restjava processes after upgrade caused service instability, leading to failed OIDC provider discovery.

Recommended Actions

Increase management memory allocation using the following commands:

tmsh modify sys db provision.extramb value 2048
tmsh modify sys db provision.restjavad.extramb value 1024
tmsh modify sys db provision.tomcat.extramb value 256

Restart services:

tmsh restart sys service restjavad restnoded httpd tomcat

Save configuration:

tmsh save sys config

Impact of workaround: Schedule these changes during a maintenance window due to risk of traffic interruption and possible HA failover.
