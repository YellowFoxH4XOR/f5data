Known Issue

BIG-IP APM configurations that use many access profiles with advanced customizations may fail to load.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with 1,000 or more access profiles.
  • Many access profiles are customized with thousands of related customization objects.
  • You attempt to load the configuration.

Impact

The BIG-IP APM configuration cannot be loaded.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing CPU usage during the configuration load, you notice that the mcpd process can use 90-100% of CPU resources.
  • Minutes after initiating the configuration load, log messages appear in the /var/log/ltm file similar to the following example:

    warning overdog[<pid>]: 01140029:4: HA daemon_heartbeat mcpd fails action is restart all.
    crit overdog[<pid>]: 01140106:2: Overdog daemon calling bigstart restart.
    notice sod[<pid>]: 010c0044:5: Command:  go standby overdog.
    notice logger: /usr/bin/overdog  ==> /usr/bin/bigstart restart

  • Additional repeating log messages appear in the /var/log/ltm file similar to the following example:

    notice sod[27745]: 010c0063:5: Waiting for Mcpd without a response. Try again...
    notice sod[27745]: 010c0063:5: Waiting for Mcpd without a response. Try again...
    notice sod[27745]: 010c0063:5: Waiting for Mcpd without a response. Try again...

Workaround

To work around this issue, you can disable the mcpd watchdog heartbeat, load the configuration, and re-enable the mcpd watchdog heartbeat. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure temporarily disables state monitoring of the mcpd process.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Disable the mcpd process watchdog heartbeat by typing the following command:

    modify /sys daemon-ha mcpd heartbeat disabled

  3. Load the system configuration by typing the following command:

    load /sys config all-partitions

  4. When the configuration load has completed, re-enable the mcpd watchdog heartbeat by typing the following command:

    modify /sys daemon-ha mcpd heartbeat enabled

  5. To exit tmsh, type the following command:

    quit
