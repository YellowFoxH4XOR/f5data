K48238302: Unable to view ASM reports on BIG-IQ v7

Applies to

Source

Description

  • When navigating to Monitoring > Reports > Security > Web Application Security > Reporting in BIG-IQ the browser fails to load or the menu doesn’t display properly
  • ASM reporting menu shows BIG-IQ menu instead

Environment

  • BIG-IQ v7.x
  • ASM Reports

Cause

The seen behavior is caused by a known issue tracked with the bug ID761873

Recommended Actions

Edit webd.conf file following below procedure to correct the issue

  1. Locate the file in the following path: /etc/webd/webd.conf
  2. Copy the following code to insert into the file:

         location ^~ /ui/asm/reporting {
            root /usr/local/www;

            rewrite ^/ui/asm/reporting(/.*)?$               /ui/asm/reporting$1 break;
         }

  3. Edit the file and paste the code in the order shown in the example below:

        # handle default JSON files loaded presets
        location ^~ /ui/asm/stubData {
           root /usr/local/www;

           rewrite ^/ui/asm/stubData(/.*)?$                /ui/asm/stubData$1 break;
        }

        location ^~ /ui/asm/reporting {
           root /usr/local/www;

           rewrite ^/ui/asm/reporting(/.*)?$               /ui/asm/reporting$1 break;
        }

       # handle pre-7.0 URLs
       #access needs a special redirect because we load .json files under the /ui/access/ URL
       location ~* /ui/access/?(accessReporting|swgReporting)?/?$ {
          return 301 /ui/system;
       }

  4. Restart webd to load the changes:

        bigstart restart webd
