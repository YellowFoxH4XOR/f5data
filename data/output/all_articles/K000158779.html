K000158779: VELOS blade turned off unexpectedly and tenant would not deploy: "Node 1, which was running tenant instance..., is unresponsive "

Description

Tenants unable to deploy on VELOS blades, with a message similar to the following in show tenants:

Node 1, which was running tenant instance ltm1, is unresponsive

The show cluster output in the partition reveals the blade in question is powered off:

cluster nodes node blade-1
 state enabled      true
 state virtual-slot 1
 state assigned     true
 state node-running-state running
 state present      single
 state power        off
 state platform-id  BX110
 state slots        [ 1 ]
 state platform node-status "blade powered off"
 state slot-number  1

Environment

  • VELOS blade
  • Tenant deployment

Cause

This can happen if the blade is powered off due to a thermal fault event.

Recommended Actions

Review the output of show system events to determine when and why the blade shut down.

Output similar to the following indicates the blade was shut down due to a thermal fault event where inlet temperature reached 49 degC:

65546 blade-1 thermal-fault ASSERT EMERGENCY "Thermal fault detected in hardware" "2025-12-01 02:17:55.356792739 UTC"
65546 blade-1 thermal-fault EVENT NA "inlet at +49.0 degC" "2025-12-01 02:17:55.357163402 UTC"

Review the environment temperature and ensure inlets to the chassis are not blocked.
