Description

We may notice a significant difference in "Current Connections" between Virtual Server and its respective Pool. With a large number of connections in the 'time_wait' state on the client side, it is a possible reason why more connections on the Client side than the Server side.


# tmsh show sys connection" shows numerous connections in time_wait as below

Environment

  • BIGI-IP LTM
  • Current connections
  • Pool

Cause

This is an Expected Behavior

Recommended Actions

It is recommended to monitor "Total Connections" instead of Current Connections for better troubleshooting the issue. Under proper load balancing with LTM, we could see the "Total Connections" count would almost end up matching on the Client and Server Side.

# tmctl -D . virtual_server_stat name="/Common/xxxxx" -s clientside.cur_conns,clientside.tot_conns,serverside.cur_conns,serverside.tot_conns
