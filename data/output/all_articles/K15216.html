Issue

Old Behavior

In versions prior to BIG-IP 11.5.0, the default cipher for SSL profiles is ordered by speed.

New Behavior

Beginning in BIG-IP 11.5.0, the default cipher for SSL profiles is now ordered to optimize BIG-IP hardware performance.

For example, BIG-IP 11.5.0 through 11.5.1 uses the list of default client ciphers as follows:

!SSLv2:!SSLv3:!MD5:!EXPORT:RSA+AES:RSA+3DES:RSA+RC4:ECDHE+AES:ECDHE+3DES:ECDHE+RC4

Impact

Default SSL ciphers are now sorted to optimize BIG-IP hardware performance.

Recommended Actions

For more information about the default cipher strings in each version, refer to K13156: SSL ciphers used in the default SSL profiles (11.x).

You can view the order of the cipher list by typing the following commands:

  • Client ciphers order:

    tmm --clientciphers DEFAULT
  • Server ciphers order:

    tmm --serverciphers DEFAULT
