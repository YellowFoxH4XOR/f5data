Known Issue

This is the result of a known issue. The passwd utility fails to update the password for the root user when a connection to the MCP daemon cannot be established. When this issue occurs, the passwd utility returns the following error message:

BIGpipe: 012e0033:3: Connecting to MCP failed.
Failed to change user's password.  Exiting.

The primary result of this issue is that a BIG-IP Administrator will not be able to reset a lost or forgotten root password when the BIG-IP system is booted in single-user mode.

This issue is a consequence of recent changes in the way the BIG-IP system stores the password for the root user. Beginning in BIG-IP version 10.1.0, the authoritative source for the root password is the /config/bigip_sys.conf file. When the configuration is loaded, the root password is transferred from the /config/bigip_sys.conf file to the /etc/shadow file. Therefore, the passwd utility sets the root password through MCP so that it gets written to the /config/bigip_sys.conf file. This change was necessary in order to accommodate enhancements to the VIPRION platform.

Note: This issue affects the root account only.

Note: Beginning in BIG-IP version 10.1.0, the f5passwd symbolic link is no longer present. For more information, refer to K11189: Beginning in BIG-IP version 10.1.0, the f5passwd symbolic link is no longer present.

F5 Product Development tracked this issue as CR135445, and it was fixed in BIG-IP version 10.2.0 and Enterprise Manager version 2.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WAN Optimization, or Edge Gateway release notes.

Workaround

If you can access the Configuration utility using an account with administrator privileges, then you may reset a lost or forgotten root password from the Configuration utility. You can perform this operation by navigating to System, Platform.

Alternatively, you can perform the following procedure:

  1. Boot the BIG-IP system into single-user mode.

    Note: For specific instructions, refer to K4178: Booting BIG-IP in single-user mode.
  2. Enter the passwd.bin root command.
  3. When prompted, enter the new password for the root user.
  4. Using a text editor of your choice, edit the /config/bigip_sys.conf file.
  5. Find the user root { } block and locate the line that appears similar to the following example:

    password crypt "$1$UDzbEvC9$GbsJDlKaPuLou1wX5vN4B/"
  6. Replace the line from Step 5 with the following, where new_password is the new password for the root user that you have already entered in Step 3:

    password none "new_password"
  7. Save the file and quit the editor.
  8. Type exit or reboot to return to the normal operating mode.
  9. In order to re-encrypt the root password in the /config/bigip_sys.conf file, once the BIG-IP system has completed rebooting into the default runlevel, log on to the BIG-IP system command line and save the base configuration by entering the following command:

    bigpipe save

Note: On the VIPRION platform, this workaround will only affect the current blade.
