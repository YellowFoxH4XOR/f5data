Known Issue

This is the result of a known issue. The wildcard character (*), when used in the User-Agent: field of the New Browsers feature, will fail to correctly map a matching User-Agent string to the value of the Type: field, when the type is set to i-mode phone. This failure affects only the Pre-logon Sequence feature's use of the User-Agent string and browser type. The Logon page, Webtop, and User Experience customization are not affected.

FirePass can automatically present users with an interface that is appropriate for the type of device and browser they are using to log in to FirePass. On the Device Management: Configuration: New Browsers page, you can configure FirePass to detect the User-Agent string sent by a web browser using the User-Agent: field, and map the string to the type of interface that FirePass presents using the Type: field. The wildcard character can be used in the User-Agent field to match one or more characters.

Pre-logon Sequences can use the browser type mapped from the User-Agent to provide customization and security for user logons. The Pre-logon Sequence editor contains a predefined action, UI mode, which allows actions based on that value. You can also define your own actions.

If you use the wildcard character in the User-Agent: field, and set the Type: field to i-mode phone, FirePass will incorrectly map User-Agent strings that match the expression in the User-Agent field, for Pre-logon Sequences. Any Pre-logon Sequence, such as one that uses the UI mode predefined action, will instead map the User-Agent to the type Minibrowser.

The incorrect mapping occurs only for Pre-logon Sequences. When used to determine the style of logon page or Webtop to present to a user, or which Favorites to present through the User Experience tab settings from the Users: Groups: Master Groups page, the mapping for i-mode phones works correctly, and the user is presented with the correct pages for an i-mode device.

F5 Product Development tracked this issue as CR72595, and it was fixed in version 6.0.1. For information about upgrading, refer to the FirePass release notes.

Additionally, Cumulative Hotfix HF-552-4 has been issued for FirePass version 5.5.2 and Cumulative Hotfix HF-600-9 has been issued for FirePass version 6.0.0. You may download these hotfixes or later versions of the Cumulative Hotfixes from the F5 Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
