Description

You may encounter a thermal fault alert in your hardware when running the command 'show system alarms' 
# show system alarms
ID     RESOURCE   SEVERITY  TEXT                                TIME CREATED
---------------------------------------------------------------------------------------------------
65546  appliance  CRITICAL  Thermal fault detected in hardware  2023-09-11 02:49:07.406406097 UTC


Environment

Applies to r2000 and r4000 systems running F5OS-A 1.5.0 or lower
 

Cause

 The cause of this issue is a known bug (BUG ID 1326541) where the alarm is cleared from BMC but not cleared in ConfD.
 
 

Recommended Actions

Upgrade the Base and Service version to F5OS-A 1.5.1
