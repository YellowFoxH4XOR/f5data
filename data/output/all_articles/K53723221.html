Known Issue

The BIG-IP APM apd process may exit and produce a core file on chassis platforms.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access on a chassis platform.
  • The BIG-IP APM system is processing the user's authentication.

Impact

Users are unable to connect to application resources while the apd process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The apd process exits and generates core files to the /shared/core directory.
  • The BIG-IP system fails over to the standby system, if configured as part of a high-availability system.
  • In the /var/log/apm file, messages appear similar to the following example:

    err apd[<pid>]: 0149013e:3: 31e4cfda: Allow agent: Logon denied due to validation error, Error Code: 3009 (Nonexistent ACL assigned)
    notice apd[<pid>]: 01490000:5: ** SIGSEGV **
    ...
    notice apd[<pid>]: 01490000:5: /usr/bin/apd [0x82e6e73]
