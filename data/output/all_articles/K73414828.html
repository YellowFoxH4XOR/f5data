Automated scripts do not run after upgrade

Description

The automated scrips in /etc/cron.* do not run, and the logs are growing.

Environment

  • After an upgrade
  • Automated scripts

Cause

Bug ID 813517: The cron daemon not running after upgrade from pre-v14.1.0 versions to 15.0.x

Recommended Actions

Execute command:

systemctl status crond.service

If the output is similar to:

* crond.service - Command Scheduler
   Loaded: loaded (/usr/lib/systemd/system/crond.service; disabled; vendor preset: enabled)
   Active: inactive (dead)

Execute commands:

systemctl enable crond

systemctl start crond
