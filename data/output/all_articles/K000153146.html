K000153146: High disk usage observed on the /usr partition of BIG-IP LTM systems

Type
Support Solution
Published
2025-08-24
Updated
2025-08-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000153146

Description:


High disk usage observed on the /usr partition of BIG-IP LTM systems. Typical output:


# df -h /usr

Filesystem            Size Used Avail Use% Mounted on

/dev/mapper/vg--db--vda-set.1._usr 6.0G 5.4G 326M  95% /usr

Top directories consuming space include:


/usr/lib: 1.4G

/usr/share: 804M

/usr/lib64: 648M

/usr/local: 644M

/usr/bin: 575M

Environment:


Product: BIG-IP LTM

Version: 17.1.1

Platform: F5-BIG-BR-R12800-DS, C138

Partition: /usr (mounted read-only)

Cause:


The /usr partition is designed to be highly utilized (>90%) after installation and during normal operation on BIG-IP systems. It is mounted read-only and contains only system files; high usage does not impact performance or service.


Recommendations:


No action required for high /usr partition usage; this is expected behavior.

Monitoring for /usr can be disabled or alert thresholds adjusted to prevent unnecessary notifications.

If desired, expand the /usr partition using LVM tools during a maintenance window:

Check available space in the volume group (vgdisplay)

Remount /usr as read-write (mount -o remount,rw /usr)

Resize the partition (e.g., lvresize -L +200M -r <raw path for /usr partition>)

Remount /usr as read-only (mount -o remount,ro /usr)

Manual cleanup of files in /usr is not recommended.

Adjust monitoring tools to ignore or suppress alerts for this partition if needed.
