Description

The following BIG-IP log message appears in the /var/log/apm file:
Access to <Portal-Name> rejected because it points to reserved address.

Environment

  • BIG-IP APM
  • Portal Access
  • DNS
  • Localhost

Cause

The error is due to the BIG-IP system DNS Search Domain List containing localhost.

Recommended Actions

Remove the localhost from the system DNS configuration:

Impact of procedure: If you have domain names in your environment that end in localhost (for example host1.localhost) any feature on BIG-IP that is configured to not use an FQDN to resolve names (for example resolving simply host1) would not work.

  1. Navigate to System > Configuration > Device > DNS.

  2. Remove localhost from the DNS Search Domain List.

  3. Click Update to save the changes.
