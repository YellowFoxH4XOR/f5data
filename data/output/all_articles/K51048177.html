K51048177: Cannot authenticate onto BIG-IP instance on the Azure

Description

  • Unable to access BIG-IP deployed on the Azure due to misplaced password

Environment

  • BIG-IP
  • BIG-IQ
  • Azure
  • SSG template 

Cause

  • BIP-IP instance deployed on Azure using SSG template
  • Original credentials applied to the BIG-IP at a time of  BIG-IP creation lost or misplaced 

Recommended Actions

  • An alternate way in achieving a console access is to use "nested virtualization" to mount the BIG-IP VM disk image to a "rescue VM" in Azure and then load the disk image in a hyper-v instance on the "rescue VM".
  • By doing this one should be able to access console in hyper-v on the "rescue VM".
