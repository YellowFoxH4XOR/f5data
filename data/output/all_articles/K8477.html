K8477: Migration of a 4100 platform license with non-FIPS SSL acceleration to a 4300 platform

Topic

If you have migrated a license from a FirePass 4100 platform that included the license option for a non-FIPS SSL accelerator card to a FirePass 4300 platform, the license option for the non-FIPS SSL card is no longer valid or needed for the 4300 platform. The FirePass 4300 platform is currently only offered with an option for FIPS SSL acceleration hardware, so the new license will not include this option. The increased performance of the FirePass 4300 platform eliminates the benefit from the SSL acceleration hardware, which is shipped in the 4100 platform.

A FIPS-compliant SSL accelerator card is available as a factory-installed option on 4300 platforms.
