Description

When trying to add the Route Domain ID (%ID) for a new Virtual Server using FAST (F5 Application Services Template), you get an error similar to:

Value must validate against exactly one of the provided schemas. It currently validates against 0 of the schemas.. Value must be a valid IPv4 address in the form of 4 numbers between 0 and 255, separated by dots.

Environment

  • Route Domain ID for VS
  • Using FAST
  • FAST RPM Version: 3.25.3, 3.26.1
  • FAST Template Version: 1.60

Cause

This issue is being tracked internally with ID MYSTIQUE-343 , details here.

Recommended Actions

Solution to this issue is being worked on, and should be available soon. Please open a case with F5 support for current status or fix.
