Description

How to clear the history of TMSH CLI commands

Environment

BIG-IP

Cause

Expected behavior

Recommended Actions

You can clear the history by following these steps:

1.  Log in to your BIG-IP system using SSH or through the console.

2.  The history file for TMSh CLI commands is usually stored in the user's home directory. For example, if you're logged in as `root`, the file is typically located at `~/.tmsh-history-root`.

3.  You can use the `rm` command to remove the history file, here is an example to clear the history file while logged in the root command

# rm ~/.tmsh-history-root

This will delete the history file, and it will be recreated the next time you use TMSH.
