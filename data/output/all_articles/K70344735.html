Topic

This article describes the role of the F5 Helper Applications mac_f5epi.pkg and mac_f5vpn.pkg when you connect to a BIG-IP APM virtual server through a browser on macOS.

Description

On macOS, you can connect to a BIG-IP APM virtual server through supported browsers such as Firefox, Safari, or Chrome. Beginning in BIG-IP 13.0.0, F5 Helper Applications replace browser plugins when you connect to a BIG-IP APM virtual server using a browser. Browser plugin support has largely been discontinued by browser manufacturers and is not supported on BIG-IP 13.1.x or later. Only BIG-IP APM 12.x and earlier versions support browser plugins. For more information, refer to K15326: Browser plug-in support for BIG-IP APM features and browser remediation options.

Two F5 Helper Applications you may need when using a browser to connect to a BIG-IP APM virtual server are Endpoint Inspector application and F5 VPN application, described as follows.

Endpoint Inspector application

You install the Endpoint Inspector application on a Mac when the administrator of the BIG-IP APM system configures client-side Endpoint Security through the Visual Policy Editor of the BIG-IP APM system. These client-side checks include Anti-virus, Firewall, Mac file check, Mac process check, hard disk encryption, and so on. This application is a browser protocol handler for the f5-epi protocol, handling URIs that take the following form:

f5-epi://<URI>

The installer is a separate package file, mac_f5epi.pkg, that installs in the following location:

~/Applications/F5 Endpoint Inspector

This application does not require the administrator permission-level because it installs under user domain rights. 

F5 VPN application

You install the F5 VPN application when connecting to a network access VPN from a browser. This application is a browser protocol handler for the f5-vpn protocol. The URI takes the following form:

f5-vpn://

On the macOS, the application is a separate package file, mac_f5vpn.pkg, that installs in the following location:

/Applications/F5 VPN

You install it for all users on the system and must have the administrator permission-level to install it. 

Download the F5 Helper packages

You can download the Endpoint Inspector and F5 VPN application using the following three methods:

Note: After downloading the packages, you can distribute them to your Mac users.

  • Download from the BIG-IP Configuration utility
  • Download from the BIG-IP command line
  • Download when connecting to the BIG-IP APM virtual server

Download from the BIG-IP Configuration utility

  1. Log in to the Configuration utility.
  2. Go to Access > Connectivity / VPN > Connectivity > Client Downloads.
  3. In the Browser Components for Mac OS and Linux section, select the appropriate package to download.

Download from the BIG-IP command line

On the command line of your remote client system, use a file transfer application to download the files. For example, use the scp application with the following command syntax:

Note: The . character at the end of the command is required.

scp root@<big-ip ip address>:/var/sam/www/webtop/public/download/mac_f5* .

Download when connecting to the BIG-IP APM virtual server

When a user connects from a browser to the BIG-IP APM virtual server for the first time and the F5 Helper Applications are not installed on the client system, the user is presented with the option to download the packages, when required, directly from the virtual server. 

  1. When prompted by the browser, select Download.
  2. On the Mac filesystem, select the package.
  3. Follow the prompts to install.

Recommendations

When downloading and installing the F5 Helper Applications, consider the following:

  • Install the packages using the appropriate permissions as described in this article.
  • You may observe a message similar to the following when installing the packages:

    "mac_f5epi.pkg" can't be opened because it was not downloaded from the App Store.
    Your security preferences allow installation of only apps from the App Store.

    This is a security prompt from the macOS system. Select the question mark (?)  icon to view the cause and resolution from the macOS User Guide:

    If you see a dialogue stating “The app is not from the Mac App Store”, the app you tried to open wasn’t downloaded from the Mac App Store and hasn’t been reviewed. This doesn’t necessarily mean that there is something wrong with the app.

    You can choose to override your security settings and open the app anyway.

    Perform the following procedure on your macOS system to install the packages:

  1. In the Finder on your Mac, locate the app you want to open.
  2. Select Open.

    The app is saved as an exception to your security settings, and you can open it in the future by double-clicking it, just as you can any authorized app.

Alternatively, you can change the criteria for opening apps in Security & Privacy preferences.

  1. Select Apple menu > System Preferences.
  2. Select Security & Privacy.
  3. Select General.
  4. Select Click the lock to make changes.
  5. Under the section Allow apps download from:, select the appropriate option.

For more information, refer to your macOS documentation and view the document: Safely open apps on your Mac.
