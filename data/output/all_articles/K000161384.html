K000161384: Unable to install Falcon Sensor on 17.5.1.6 - installing package falcon-sensorXXX needs 4KB on the /usr filesystem - Error on line 128

Source

Description

Falcon Sensor installation fails on BIG-IP LTM 17.5.1.6 with the error:

installing package falcon-sensor-XXX needs 4KB on the /usr filesystem

Error on line 128

The installation cannot proceed because the /usr filesystem is at or near 100% capacity. If Falcon Sensor was previously installed on an older BIG-IP version, it persists after upgrade, but a fresh installation fails due to lack of space.

Environment

  • Product: BIG-IP LTM
  • Version: 17.5.1.6
  • Feature: CrowdStrike Falcon Sensor installation
  • Fresh Falcon Sensor installation attempted

Cause

The /usr filesystem is full, preventing the Falcon Sensor RPM from being installed. This is due to increased space usage in the system image. Even after applying the available fix, the partition may remain near full utilization, leaving insufficient space for the installation.

Answer/Recommended Actions

  1. Verify /usr filesystem utilization and note down the filesystem path. For example:

    If /usr shows 0 bytes free, installation cannot proceed.
  2. Remount /usr with read-write attribute: 
    mount -o remount,rw /usr 
  3. Resize the /usr partition, using the previously noted path: lvresize -L +500M -r <your-usr-lv-path> For example:
    lvresize -L +500M -r /dev/mapper/vg--db--vda-set.1._usr 
  4. Remount /usr with read-only attribute: 
    mount -o remount,ro /usr
  5. Install the Falcon Sensor. Instructions in the following article: K000156881: Install Falcon sensor for F5 BIG-IP on the BIG-IP system or F5 hardware platforms
