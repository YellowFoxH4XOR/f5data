Description

You recently integrated Anti-Virus Protection (ICAP) server with the BIG-IP ASM/advanced WAF referring to the steps of K70941653: Configuring BIG-IP ASM antivirus protection. You need to verify if the integration works properly or not. 

Environment

  • BIG-IP ASM
  • Anti-Virus (ICAP) Integration

Cause

None

Recommended Actions

  1. Assign the ASM security policy

    1. Attach the ASM security policy to the virtual server that handles file upload requests.

    2. Ensure that virus scanning is enabled in the policy as specified in the referenced article.

  2. Run either of below tcpdump captures

    1. Example 1: If BIG-IP communicates to ICAP server via tmm ports

      tcpdump -envi 0.0:nnn -s0 -w /var/tmp/icaptest.pcap host <ICAP_Server_IP_Address> and port 1344

      i.e if the ICAP server IP address is 192.168.10.100 then the command would be,

      tcpdump -envi 0.0:nnn -s0 -w /var/tmp/icaptest.pcap host 192.168.10.100 and port 1344

    2. Example 2: If BIG-IP communicates to ICAP server via mgmt port

      tcpdump -evni mgmt -s0 /var/tmp/icaptest.pcap host <ICAP_Server_IP_Address> and port 1344

      i.e if the ICAP server IP address is 192.168.10.100 then the command would be,

      tcpdump -evni mgmt -s0 /var/tmp/icaptest.pcap host 192.168.10.100 and port 1344

  3. Upload few files from the application (i.e PDF/PNG/a binary file)
  4. Stop the Capture (Ctrl + C)
    1. The resulting pcap file will be created in the /var/tmp directory. 
    2. Use a pcap analysis tool like tshark (CLI based) or Wireshark (UI based) to check the ICAP requests and responses.
