Description

After re-licensing the unit  you unable to access GUI with remote credentials but only able to access with local credentials.

GUI may show following error message as banner 

This BIG-IP system has encountered a configuration problem that may prevent the Configuration utility from functioning properly.

When you try to verify config from CLI with tmsh load sys config verify you see below error message 

Configuration error: <error message> (/Common/<application service name>.app/<object name>) folder does not exist

Environment

  • BIG-IP LTM
  • Application services / iApp

Cause


It could be because one of the two following reasons
 
  • Based on the configuration in bigip_base.conf or bigip.conf, BIGIP is referencing to an object called application service/iApp folder that doesn't exist in either bigip_base.conf or bigip.conf file.
  • The error message can also be present when previous iapp configuration is removed but some of the config is still available and when re-licensing or manually loading a config , BIGIP would reference to an object iApp folder which is no longer present.

Recommended Actions

If an iApp folder is missing for an existing config you can add the iApp folder config using any of the text editor such as vi or nano in bigip_base.conf referencing any other iApp folder available on unit.

If error message is for the application service /iApp that is removed from BIG-IP but some of the config is still present in either bigip_base.conf / bigip.conf and referencing to an iApp folder that doesn't exist any longer comment those line from either bigip_base.conf or bigip.conf

This modification may be unique to each individual config and if you need any assistance please reach out to F5 support.
