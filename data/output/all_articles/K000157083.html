K000157083: Unhealthy system health due to unhealthy "Disk Encryption"

Type
Support Solution
Published
2025-10-22
Updated
2025-10-23
Applies to
  • F5OS
  • F5OS-A: 1.8.3
Source
https://my.f5.com/manage/s/article/K000157083

Description

After an upgrade to F5OS-A 1.8.3, the appliance may report system health as "unhealthy" and the following snippets of the "show system health" output can be seen:

R5900# show system health
COMPONENT        COMPONENT  COMPONENT  ATTRIBUTE  ATTRIBUTE    ATTRIBUTE  ATTRIBUTE  ATTRIBUTE  UPDATED  
NAME       NAME  HEALTH     SEVERITY   NAME       DESCRIPTION  HEALTH     SEVERITY   VALUE      AT       
---------------------------------------------------------------------------------------------------------
appliance  -     unhealthy  error                                                                        
fantray    -     ok         info                                                                         
lcd        -     ok         info                                                                         
m.2-slot1  -     ok         info                                                                         
psu-1      -     ok         info                                                                         
psu-2      -     ok         info   

 hardware appliance/hardware/drives
  state name Drives
  state health unhealthy
  state severity error                    

 hardware appliance/hardware/drives/disk-encryption
  state name "Disk Encryption"
  state health unhealthy
  state severity error

 

Environment

  • r5k, r10k, r12k
  • F5OS-A
  • Upgraded to 1.8.3

Cause

ID2137577

Recommended Actions

  1. Run the following command in an administrative BASH session. The expected output is displayed below:  
    [root@appliance-1:Active] ~ # docker exec -it diag-agent psf run POST:components/reset component=appliance/hardware/drives/disk-encryption
  component                                 | previousSeverity | previousStatus | severity | status
--------------------------------------------+------------------+----------------+----------+----------
  appliance/hardware/drives/disk-encryption | Error            | Unhealthy      | Info     | Ok
--------------------------------------------+------------------+----------------+----------+----------
                                                                                  summary  | 1/0.01s
                                                                                -----------+----------
  2. Check that the system health no longer indicates that there is an error with the "Disk Encryption" and that the "show system health summary" does not indicate any indication of "unhealthy": 
    R5900# show system health components component hardware appliance/hardware/drives
COMPONENT                                     COMPONENT  COMPONENT                                                             ATTRIBUTE  ATTRIBUTE  ATTRIBUTE
NAME       KEY                        NAME    HEALTH     SEVERITY   ATTRIBUTE NAME                 ATTRIBUTE DESCRIPTION       HEALTH     SEVERITY   VALUE      UPDATED AT
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
appliance  appliance/hardware/drives  Drives  ok         info       drives:capacity                Drive Capacity              ok         info       30         2025-10-22T08:00:00+08:00
                                                                    drives:disk-usage-growth-rate  Drive capacity Growth Rate  ok         info       -0         2025-10-22T08:00:00+08:00
    R5900# show system health summary
COMPONENT        COMPONENT  COMPONENT  ATTRIBUTE  ATTRIBUTE    ATTRIBUTE  ATTRIBUTE  ATTRIBUTE  UPDATED  
NAME       NAME  HEALTH     SEVERITY   NAME       DESCRIPTION  HEALTH     SEVERITY   VALUE      AT

Additional Information

There are no reported or known impact to production traffic for this workaround.
