Known Issue

BIG-IP APM rewritten iframe content may not function correctly.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with an Access Portal.
  • Users connect to the Access Portal using the Internet Explorer 11 browser.
  • Content rewritten by the BIG-IP APM contains HTML iframe(s) that reference JavaScript code in the source attribute.

Impact

The rewritten iframe content does not function correctly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Expected content does not appear in the user's browser.
  • Applications dependent on the rewritten iframe content do not function.
  • The user's browser returns JavaScript errors.
  • When using a different browser or different version of Internet Explorer, the rewritten content functions correctly.
