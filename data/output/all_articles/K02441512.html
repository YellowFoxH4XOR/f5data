Description

When using the BIG-IP Configuration utility for automatic license update feature an error messages similar to one of the following is displayed.

  • Unable to reach the licensing server 
  • Internal Server Error
    The server encountered an internal error or misconfiguration and was unable to complete your request.
    Please contact the administrator at support@f5.com to inform them of the time this error occurred, and the action you performed just before this error.
    More information about this error may be available in the server error log.
     

Environment

  • BIG-IP
  • Automatic license activation and reactivation

Cause

The BIG-IP to establish a connection with the licensing server.

 

Recommended Actions

Reactivate the license using the "Manual" activation method by following the steps below:

Impact of procedure: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. When licensing redundant BIG-IP systems, F5 recommends that you activate the license on your BIG-IP devices while they are in standby mode.

  1. Log in to the Configuration utility.
  2. Select Activate.

    Note: If the BIG-IP system is already licensed, navigate to System > License and select Re-activate. 

  3. Select Manual.
  4. Select Next.
  5. Copy the dossier and connect to the F5 Product Licensing page at secure.f5.com.
  6. On the F5 Licensing Tools page, select Activate F5 product registration key for BIG-IP 9.x and later.
  7. Paste the dossier into the Enter Your Dossier box, and then select Next.

    The F5 Product Licensing page produces your license.

  8. Copy the license and paste it into the License box in the Configuration utility.
  9. Select Next and wait for the configuration to reload.

    Important: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration.

 

Additional Information

For more information about licensing the BIG-IP system, refer to K7752: Licensing the BIG-IP system.
