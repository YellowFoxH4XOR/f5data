K000136950: FCP Hardware, when activating additional add-on license keys "Unable to grant license key: Error 51086, Add-on Module Key is not a valid option for the Base Registration Key"

Type
Support Solution
Published
2023-09-22
Updated
2023-09-22
Source
https://my.f5.com/manage/s/article/K000136950

Description

You are unable to provision an Add-On key to your FCP Hardware.
You may see a similar error message:
Unable to grant license key: Error 51086, Add-on Module Key is not a valid option for the Base Registration Key - Product Platform make / model  does not allow the Add-On module to be included: XXXXXXX-YYYYYYY (add on key / sku name)

In the example below, the platform is a Velos CX410-AC and we are trying to add SSLO sku LIC-PKG-VEL-ADD-SSLO-CX410 

Unable to grant license key: Error 51086, Add-on Module Key is not a valid option for the Base Registration Key - Product VEL-CX410-AC does not allow the Add-On module to be included: XXXXXXX-YYYYYYY (LIC-PKG-VEL-ADD-SSLO-CX410)

Environment

  • Hardware sold under FCP / ELA 
  • IP intelligence, Threat Campaign, PEM URL filtering, URL filtering and SSL Orchestrator add on keys 

Cause

For the ELA / FCP program, specific add on SKU were created for the various hardware platforms.

 Recommended Actions

If possible collect the information provided in the steps below and share these to your Customer Success Manager
Please contact your Customer Success Manager directly or reach the wider Customer Success team: customersuccess@f5.com.
  1. Review your existing license, this can be found in the BIG-IP GUI under System--License or from the command line /config/bigip.license
  2. Locate "Module List" and ensure you have "active module: ELA Software, Enterprise" this confirms you are using an ELA / FCP base license
  3. Scroll down and locate "optional module" There will be several lines with all of the available add on modules listed.
  4. In our example we are looking for the SSL Orchestrator module, which looks like this  "optional module : SSL Orchestrator, i10XXX/i11XXX, FCP"
  5. The correct sku name is "SSL Orchestrator, i10XXX/i11XXX, FCP" and not the one which is seen above "LIC-PKG-VEL-ADD-SSLO-CX410" Please provide this information to your Customer Success manager and they will order the correct replacement add on keys for you.
