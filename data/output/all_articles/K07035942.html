Description

This is to show know changes in the default tcp profile that might cause differences in traffic behavior when upgrading from 12.x to 14.x.

  • Upgrade software from 12.x to 14.x
  • Latancy, non-standard traffic

Cause

Profile defaults are subject to change between major software releases.

Recommended Actions

None
