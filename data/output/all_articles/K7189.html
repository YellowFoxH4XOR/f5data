K7189: Configuring the standalone BIG-IP ASM system to insert, erase, or allow an HTTP header

Topic

The standalone BIG-IP ASM system does not provide the following functions when creating an HTTP profile:

  • Request Header Insert
  • Request Header Erase
  • Response Header Allowed

These functions are part of the BIG-IP LTM functionality, which requires a specific license. However, the desired functionality can be achieved on the standalone BIG-IP ASM using an iRule.

Note: For information about the specific iRule syntax, refer to the DevCentral website. A DevCentral login is required to access this content.

Creating an iRule that inserts an HTTP header in a request

To create an iRule that inserts an HTTP header in a request sent from a client to the server, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic Manager > iRules.
  3. Click Create.
  4. Type a name for the iRule.
  5. In the Definition box, paste the following iRule:

    when HTTP_REQUEST {
    HTTP::header insert <name> <value>
    }

    - Replace <name> with the desired name for the HTTP header to be inserted.

    - Replace <value> with the desired value for the HTTP header to be inserted.

  6. Click Finished.

Creating an iRule that erases an HTTP header in a request

To create an iRule that erases an HTTP header in a request sent from a client to the server, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic Manager > iRules.
  3. Click Create.
  4. Type a name for the iRule.
  5. In the Definition box, paste the following iRule:

    when HTTP_REQUEST {
    HTTP::header remove <name>
    }

    - Replace <name> with the desired name for the HTTP header to be removed.
  6. Click Finished.

Creating an iRule that allows an HTTP header in a response

To create an iRule that allow an HTTP header in a response sent from the server to a client, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic Manager > iRules.
  3. Click Create.
  4. Type a name for the iRule.
  5. In the Definition box, paste the following iRule:

    when HTTP_RESPONSE {
    HTTP::header sanitize <header name> <header name>
    }

    - Replace <header name> with the desired name for the HTTP headers to be allowed.
  6. Click Finished.
