Description

High CPU and swap memory usage can be seen constantly on the BIG-IP.
Top command outputs shows high CPU and RES memory consumption by syslogd process.

For example:
PID USER  PR NI VIRT   RES  SHR S  %CPU %MEM  TIME+     COMMAND
2319 root 20 0 2504208 2.1g 2872 S 48.5 10.3 838:03.32 /usr/sbin/syslog-ng -F -p /var/run/syslogd.pid

Environment

  • BIG-IP
  • High CPU and memory usage by syslog-ng
  • TOP
  • May be seen after an upgrade

Cause

We do not believe that this is related to upgrade.
Logging BigDB variables are set to non-default level.

For example:

list /sys db all-properties
sys db log.layer4.level {
default-value "Notice"
scf-config "false"
value "Debug" <===
value-range "Debug Informational Notice"
}

Recommended Actions

Check if the logging BigDB variables are set to non-default level.

list /sys db all-properties

Modify the log level to their default values, restart the syslog-ng daemon, and compare the CPU and other memory usage.

For example:

tmsh modify sys db log.layer4.level value Notice
tmsh save sys config
tmsh restart sys service syslog-ng
