Description

  • A security advisory states that there is a fix in BIG-IP 17.1.2 or BIG-IP 17.1.2.2; since BIG-IP 17.5.0 is an incrementally later minor version, can I assume the issue is also fixed in BIG-IP 17.5.0?

Environment

  • BIG-IP 17.1.0 - 17.5.0
  • Security advisory

Cause

The release of BIG-IP 17.5.0 has increased the number of Long-Term Stability Releases in the BIG-IP 17.x software branch.

Recommended actions

After the BIG-IP 17.1.x Long-Term Stability Release, F5 introduced the BIG-IP 17.5.x series, starting with BIG-IP 17.5.0. Like BIG-IP 17.1.x, it is a Long-Term Stability Release, but with a different standard support phase duration. For more information, refer to K5903: BIG-IP software support policy.

The BIG-IP 17.5.x and BIG-IP 17.1.x minor releases are separate releases, which are individually maintained; therefore, software fixes included in a maintenance or point release from one minor version are not guaranteed to be included in the other minor version. For example, if a security advisory states that there is a fix in BIG-IP 17.1.2.2, that same issue is not guaranteed to be fixed in BIG-IP 17.5.0.

When evaluating a security advisory, use the following steps to determine whether BIG-IP 17.5.0 is affected by the issue described:

  1. Review the Evaluated products list to determine whether F5 Product Development has evaluated the issue for BIG-IP 17.5.0.

    If 17.5.0 has been evaluated, proceed to the next step to determine whether it is vulnerable. If the issue was fixed in BIG-IP 17.1.0 or a previous version, BIG-IP 17.5.0 will not be listed in the Evaluated products list.

  2. Review the Versions known to be vulnerable column of the BIG-IP and BIG-IQ status table.

    If BIG-IP 17.5.0 is in the Evaluated products list, but not in the Versions known to be vulnerable column, BIG-IP 17.5.0 is not affected.

  3. Review the Fixes introduced in column of the BIG-IP and BIG-IQ status table.

    Fixes will not be listed for BIG-IP 17.5.x, unless one of the following is true:

    1. BIG-IP 17.5.x is listed in the Versions known to be vulnerable column.
    2. BIG-IP 17.1.x is affected, but no previous fix has been provided by BIG-IP 17.1.x. For example:
      1. BIG-IP 17.1.0 - 17.1.2 are affected and a fix is introduced in BIG-IP 17.1.2.2; BIG-IP 17.5.0 will not be listed in the Fixes introduced in column.
      2. BIG-IP 17.1.0 - 17.1.2 are affected and there is no fix provided by BIG-IP 17.1.x; BIG-IP 17.5.0 may be listed in the Fixes introduced in column, if a fix is available.
