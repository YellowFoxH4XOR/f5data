Description

The Advanced Shell option is not available for locally defined users including the user 'admin'.
In the GUI, navigate to System > Users > User List > (user/admin) > Terminal Access.
The only available options are tmsh and disable.

If you attempt to modify the existing user or create a new user with tmsh, you will see the below error message in /var/log/ltm log file despite having 'Appliance Mode' under 'Optional Module' section in the license file:

notice mcpd[PID]: 0107072a:5: Advanced shell not available in Appliance Mode


Environment
  • BIG-IP Users
  • Advanced Shell

Cause

The systemauth.disablebash database value is set to true, which disables Bash (Advanced Shell) access:

    (tmos)# list sys db systemauth.disablebash all-properties

sys db systemauth.disablebash {
    default-value "false"              <----
    scf-config "true"
    value "true"                       <---- !!!!
    value-range "false true"
}

Recommended Actions

Revert the systemauth.disablebash database key to its default value from command line:
  1. Set systemauth.disablebash to false:

    modify sys db systemauth.disablebash value false

  2. Save the configuration change:

    save sys config partitions all


Additional Information

This behaviour can also occur when Appliance Mode is enabled in the License file:

(tmos)# tmsh show sys license detail
..
Active Modules
  ..
  App Mode (TMSH Only, No Root/Bash) 

When attempting to create a user in TMSH:

(tmos)# create auth user test1 shell bash

The following message will occur in the terminal:

There were warnings:
WARNING! Role no-access will lockout the user test1.

The user will be created with TMSH shell access:

(tmos)# list auth user test1 shell
auth user test1 {
    shell tmsh
}

And the following messages will appear in /var/log/ltm:

warning mcpd[PID]: 01071859:4: Warning generated : WARNING! Role no-access will lockout the user test1.
notice mcpd[PID]: 0107072a:5: Advanced shell not available in Appliance Mode

Contact F5 Support and work with a Licensing Specialist if you wish the Appliance Mode feature to be removed.
