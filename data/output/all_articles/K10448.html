Known Issue

This is the result of a known issue. TMM may core if a virtual server that is passing a large amount of traffic is configured with a rate class with the following attributes:

  • a low base and ceiling rate
  • a large burst rate

For example:

Base Rate: 1 Megabit(s)/second
Ceiling Rate: 2 Megabit(s)/second
Burst Size: 100 Megabytes

F5 Product Development is tracking this issue as CR124125.

This issue was fixed in Hotfix-BIGIP-10.0.1-342.0-HF1 issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
