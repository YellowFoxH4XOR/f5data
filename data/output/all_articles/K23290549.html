Description
Using VPN with capabilty for DTLS traffic, with TLS and DTLS Virtual Servers configured to Preserve Strict Source Port and the Network Access profile is properly configured with DTLS enabled, traffic keeps changing source port regardless of the configuration.
 

Environment

  • TLS Virtual server listening on port 443 with Source Port set to Preserve Strict 
  • DTLS Virtual server listening on port 4443 with Source Port set to Preserve Strict
  • BIG-IP APM Network resource configured with DTLS enabled
  • The BIG-IP is configured with a BIG-IP LTM Forwarding Performance (Layer 4) wildcard virtual server

Cause
The BIG-IP LTM forwarding Performance (Layer 4) virtual server processes traffic that is intended for processing by BIG-IP APM (depending your deployment scenario): 

ltm virtual /Common/vs-forwarding {
    destination /Common/0.0.0.0:0
    ip-forward
    mask any
    profiles {
        /Common/fastL4 { }
    }
    source 0.0.0.0/0
    translate-address disabled
    translate-port disabled
}
 

Recommended Actions

Configure the BIG-IP LTM forwarding Performance (Layer 4) virtual server Source Port to Preserve Strict using one of the following options:  

Using the Traffic Management Shell (tmsh)
  1. Log on to the Traffic Management Shell (tmsh).
  2. Use the following command syntax to modify the Source Port configuration of the virtual server. 
    modify /ltm virtual <virtual server name> source-port preserve-strict 
    Note: Replace <virtual server name> with the affected Performance (Layer 4) virtual server name.
     
  3. Save the configuration change with the following command:
    save /sys config partitions all
???????
Using the BIG-IP APM Configuration utility
  1. Log on to the BIG-IP APM Configuration utility.
  2. Go to Local Traffic > Virtual Servers > Virtual Server List.
  3. Click the affected BIG-IP LTM Forwarding Performance (Layer 4) virtual server.
  4. Select Configuration > Advanced.
  5. Set Source Port to Preserve Strict.
  6. Click Update.
