Issue

Error Message

notice tmm[<PID>]: 1010013:5: database size increased by <value> bytes, <size> total

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • <value> is the number of bytes the database was increased by.
  • <size> is the new size of the database, in bytes.

For example:

notice tmm[11558]: 1010013:5: database size increased by 4194304 bytes, 58256736 total

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • Through an automated process, the BIG-IP system extends the amount of memory for the binary configuration database.

The mcpd process periodically monitors the remaining memory for the configuration database. If the remaining memory falls below a minimum threshold, the database memory is extended and this message is logged.

Impact

None. This notification does not indicate an error.

Recommended Actions

None. The maximum size for the configuration database is controlled by the mcpd.maxdbsize database variable. The default maximum size is set to 512 megabytes.
