Known Issue

This is the result of a known issue. The ARX system manages snapshots on Windows servers through Windows Remote Management (WinRM). ARX-managed snapshots will fail for a Windows server running WinRM version 2.0.

Important: WinRM version 2.0 is installed by default with Windows Server 2008 R2, and is an optional upgrade for the following Windows versions:

  • Windows Server 2008 with Service Pack 1 
  • Windows Server 2008 with Service Pack 2 
  • Windows Server 2003 with Service Pack 2

Note: For information about WinRM, refer to http://msdn.microsoft.com/en-us/library/aa384426(VS.85).aspx. This link takes you to a resource outside of AskF5, and it is possible that the information may be removed without our knowledge.

Note: For information about snapshots failing for Windows servers running WinRM versions prior to 1.1, refer to K10647: The ARX may be unable to create Microsoft Visual SourceSafe (VSS) snapshots.

F5 Product Development tracked this issue as ID 37182 and it was fixed in ARX version 5.1.5. For information about upgrading, refer to the ARX release notes.
