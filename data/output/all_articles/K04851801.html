Issue

Old Behavior

In versions prior to 11.5.0, the BIG-IP system allocates a certain amount of disk space (typically about 20 GB) to the vg_reserved volume, and the disk space is not available for other modules to use.
When you attempt to provision multiple licensed modules, which requires intense disk resource allocation on a BIG-IP Virtual Edition (VE) system or a BIG-IP Virtual Clustered Multiprocessing (vCMP) guest, the system may display a provisioning error that reports a disk space limitation, similar to the following example:

01071008:3: Provisioning failed with error 1 - 'Disk limit exceeded. 40088 MB are required to provision these modules, but only 32660 MB are available.'

New Behavior

Beginning in BIG-IP 11.5.0, the value of the vg_reserved volume is set to 0 (zero) by default.

F5 Product Development tracked this change as ID 423769.

Impact

The entire free disk space is now available, by default, for module provisioning.
