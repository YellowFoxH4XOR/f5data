Known Issue

This is the result of a known issue. You can use the bigpipe persist command to view and manage the persistence table entries on the BIG-IP system. Running the bigpipe persist show command on a system with a large number of persistent connections (such as one million persistence entries) can cause the system to become unstable or fail over.

F5 Product Development is tracking this issue as ID 222127 (formerly CR113322).

Workaround

You can work around this issue by using the bigpipe persist client <client_addr> show command to display individual persistence records. For example, the following command displays all persistence records for client 1.1.1.10:

bigpipe persist client 1.1.1.10 show
