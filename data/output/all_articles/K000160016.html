K000160016: ASM security policy blocks illegal file types when CSV content is embedded in the URL as a query string in an HTTP GET request

Description

BIG-IP ASM may block HTTP GET requests for CSV file downloads with an "illegal file types" violation if the application embeds the entire CSV file content within the query string of the URL, rather than referencing a discrete file path. This results in unusually long and malformed URLs, causing ASM to interpret the request as suspicious and block it as a false positive.

Example:

GET /my/report/path/DownloadTransactions/Transaction ID,Customer Name,Product Type,Product Name,Product Code,Action Type,Quantity,Unit Price ($),Total Amount ($)"TXN12345","Customer A","Equity","Tech Growth Fund","TGF9876","Buy","500","25.50","12,750.00","""TXN12346","Customer B","Bond","Corporate Bond Fund","CBF5432","Sell","1000","15.75","15,750.00","""TXN12347","Customer A","Cash","Money Market","CASH01","Buy","","","5,000.00""TXN12348","Customer C","Equity","International Fund","INTL2468","Buy","250","42.80","10,700.00","""TXN12349","Customer B","Equity","Tech Growth Fund","TGF9876","Sell","300","26.10","7,830.28" HTTP/1.1

The ASM detected it as an "illegal file types" violation because of the ".28" at the end of the requested URL.

Environment

  • BIG-IP ASM
  • Application constructs HTTP GET requests for CSV downloads by embedding file content in the query string
  • Security policy enforces file type restrictions

Cause

Improper application behavior generates HTTP GET requests with the entire CSV file content in the query string instead of referencing a file path. This malformed URL structure triggers ASM to block the request due to an "illegal file types" violation.

Answer/Recommended Actions

  • Update application logic to use discrete file paths in URLs for file downloads, avoiding embedding file content in the query string.
  • Use correct URL formatting for CSV downloads.
  • Do not include file content or large data payloads in the query string.
  • Review ASM event logs for "illegal file types" violations and inspect URL structure.
  • Correcting the application to use proper URL formatting will prevent false positive blocks for legitimate CSV downloads.
