Description

  • Application policy, so long as it is configured to auto learn and apply what is learnt automatically, it will learn this changes without human intervention
  • Traffic Learning with 100% confidence will automatically qualify and it may only require a single request for this qualification if the request comes from a trusted IP.

Environment

  • ASM
  • Policy-builder

Cause

  • Automatic application/implementation/alteration of security policy following auto learnt suggestion

Recommended Actions

  • Auto learning is convenient, especially form a known IP address, but has also cost as in terms of the application of learnt suggestion is applied automatically. 
  • This in turn can result in some unexpected outcome, especially if what is learnt is not thought through carefully. 
  • One way of improving this is to increase the number of requests from trusted IP address from one to say five, this may give one a chance to interrogate/inspect  the change about to be applied.
  • Also,  Policy Builder can learn from server responses,; these responses are counted as trusted sources and use the trusted traffic thresholds configured in the learning and blocking settings for ASM to apply changes
