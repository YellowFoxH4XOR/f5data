Issue

Description

You observe the following symptoms:

  • The base configuration fails to load.

You observe errors similar to the following:

  • emerg load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all base " - failed. -- 01070734:3: Configuration error: Can't associate Tunnel (/Common/example.app/example_connect) folder does not exist Unexpected Error: Loading configuration process failed.
  • err mcpd[1234]: 01070734:3: Configuration error: Can't associate Tunnel (/Common/citrix.app/citrix_connect) folder does not exist

Environment

  • Post upgrade

Cause

  • You configured an iApp application service and then removed it, leaving behind some tunnel configuration in bigip_base.conf.

Recommended Actions

To resolve this issue, manually remove the lines from the configuration that relate to the object you removed, and then reload the configuration.

Perform the following procedures:

  • Backing up the bigip_base.conf file
  • Identifying the items of configuration that reference the deleted application service
  • Editing the bigip_base.conf file
  • Reloading the configuration
  • Verifying the configuration is loaded

Backing up the bigip_base.conf file

Create a backup of the existing bigip_base.conf file using the following command:

cp /config/bigip_base.conf /config/bigip_base.conf.backup

Identifying the configuration items that reference the deleted application service

Review the contents of the bigip_base.conf file to determine which items relate to the tunnel that the deleted application service used and the load error message references.

In the following examples, the emphasized lines in the configuration show route domain references of the deleted application service (tunnel), forwarding database (FDB) tunnel, and tunnel configuration objects that you must remove from the configuration:

net route-domain /Common/0 {
id 0
vlans {
/Common/vs
/Common/http-tunnel
/Common/socks-tunnel
/Common/HA
/Common/internal
/Common/external
/Common/example.app/example_connect
}
}
net fdb tunnel /Common/example.app/example_connect {
app-service /Common/example.app/example 
} 
net fdb tunnel /Common/http-tunnel { }
net fdb tunnel /Common/socks-tunnel { }
net fdb vlan /Common/HA { }
net fdb vlan /Common/external { }
net fdb vlan /Common/internal { }
net fdb vlan /Common/vs { }
net tunnels tunnel /Common/example.app/example_connect {
app-service /Common/example.app/example
profile /Common/ppp 
} 
Important: When deleting an object from the configuration file, pay attention to the open and close braces ({ }) for the configuration section.

Editing the bigip_base.conf file

Edit the bigip_base.conf file using a text editor such as VI or Pico to remove the lines identified previously.

Reloading the configuration

Reload the configuration using the following command:

tmsh load sys config

Verifying the configuration is loaded

Verify the configuration loaded successfully using the following command:

tmsh show sys mcp-state

For example, the following output shows that the configuration loaded successfully:

--------------------------------------------------------
Sys::mcpd State:
--------------------------------------------------------
Running Phase                   running
Last Configuration Load Status  full-config-load-succeed
End Platform ID Received        true
