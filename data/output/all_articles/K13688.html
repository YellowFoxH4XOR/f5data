Topic

The ARX license limits for direct shares are configurable beyond support with current ARX software architecture.

Description

ARX is configurable to a maximum of 8192 direct shares. However, the current ARX software architecture is unable to support this configuration size. When you configure more than 1024 direct shares, system commands, such as show namespace, will experience degraded performance and longer execution times. A configuration that exceeds 3000 direct shares may cause the ARX system to no longer be effectively administrated.

Recommendations

F5 recommends limiting the number of direct shares per ARX system to no more than 1024.
