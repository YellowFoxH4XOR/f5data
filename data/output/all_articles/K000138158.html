Description

You are wanting to create an AD query within an Access Policy that requires the Employee ID attribute to exist. If it does not exist, you want to fallback.

 

Environment

AD Query

APM

Cause

Requirement to ensure an Employee ID attribute exists.

Recommended Actions

  1. Add a branch rule to the AD Query from the Branch Rules tab.
  2. Click on change under the Expression field and go to the Advanced tab.
  3. Add the expression below, click finished, and save changes:

           expr { [mcget {session.ad.last.attr.employeeID}] != "" }

Note: Click Apply Access Policy to update any changes when finished.
