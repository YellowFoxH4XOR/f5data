Topic

Starting in BIG-IP 11.1.0, you can use the Configuration utility or Traffic Management Shell (tmsh) to create Secure Socket Layer (SSL) certificates, keys, and certificate signing requests (CSRs) that contain the Subject Alternative Name (SAN) extension for DNS names when configuring the SAN SSL certificates, keys, and CSRs.

In BIG-IP 11.5.0, F5 added the option to allow you to add other identities to the SAN field.

Per RFC5280, the SAN extension allows certain values, such as email addresses, DNS names, IP addresses, and URIs, to be bound to the subject of the SSL certificate. For example, a SAN SSL certificate allows you to specify multiple DNS names in a single SSL certificate to avoid the cost of purchasing multiple similar certificates.
