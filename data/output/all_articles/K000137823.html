Description

This is a corner case for Trunk with only one interface.

Environment

F5OS-C and F5OS-A R5R10 rSeries Platforms

Trunk is Configured on F5OS-C/ F5OS-A R5R10 platform with only ONE Interface.

 

What Expected

Even there is only one interface in the trunk, Trunk LAG-Type can still be configured as STATIC or LACP, and the Trunk status will still be impacted by switch side port LACP configuration.

 

In the example below: interface 3.0 is UP, Trunk-gslab has only one Interface (3.0), lag-type is configured as LACP, and switch side port LACP is not enabled.

Cause

LACP configuration and Status does not impact a trunk with only one Interface.

 

Recommended Actions

  1.  Do not need to enable LACP if there is only one interface in a trunk. And it will introduce unnecessary confusions about Trunk Status.
