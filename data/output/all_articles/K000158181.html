K000158181: Missing hourly tmstat snapshots stored in /shared/tmstat/snapshots/blade0/public/3600

Source

Description

On BIG-IP LTM systems, hourly tmstat snapshot log files may intermittently disappear from the directory /shared/tmstat/snapshots/blade0/public/3600`. This results in incomplete statistical data, impacting troubleshooting and root cause analysis. Symptoms include a gradual decrease in the number of hourly snapshot files over time—sometimes leaving only one file present. Restarting the merged process temporarily restores file generation, but the issue recurs.

Environment

  • Redundant pairs (Active/Standby)
  • tmstat snapshots stored in /shared/tmstat/snapshots/blade0/public/3600`

Cause

Bug ID 2131861
