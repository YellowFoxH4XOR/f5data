Topic

You should consider using this procedure under the following condition:

  • You want to use the iControl REST API to accept, delete or ignore traffic learning suggestions for your BIG-IP Advanced WAF / ASM security policy.

Description

As a BIG-IP administrator, you can use the iControl REST API to manage the policy builder learning suggestions for your security policy. This article shows you how to use the iControl REST API to accept, delete or ignore traffic learning suggestions for a security policy. When you accept a learning suggestion, the policy builder edits the policy as described in the suggestion. For example, if you accept the suggestion to enable the Apache whitespace evasion technique, the policy builder enables that violation in the policy. When you delete a suggestion the policy builder removes the suggestion from the Learning screen, but the suggestion reappears (with a reset score) if another request triggers the suggestion. When you choose the ignore option, the suggestions no longer appear in the Learning screen (even if the suggestion is triggered by another request) but you can still view ignored suggestions using the filter.

For more information about the iControl REST API, refer to the iControl REST user guide that applies to your BIG-IP version, available on iControlREST Home.

curl and jq utilities

Performing the following procedure requires command-line access to a system with the curl utility and, optionally, the jq (command line JSON processor) utility installed. These utilities are commonly available on Linux systems but can also be installed on Microsoft Windows and Mac OS X systems. Additionally, you can perform this procedure on a BIG-IP system.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have command line access to a system with the curl and jq utilities installed.
  • You have administrative access to the BIG-IP Configuration utility.

Procedures

Locate the security policy MD5 hash identifier

BIG-IP ASM security policies have a unique MD5 hash identifier that represents the policy name. You must determine the MD5 hash identifier for the policy before you can modify or display the security policy configuration using the iControl REST API. After you have located the policy MD5 hash identifier, you include the hash value when you define the URI to modify the learning suggestions. To determine the MD5 hash identifier for the specific policy, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to determine the MD5 hash identifier for the policy name:

    curl -sku <username:password> https://<BIG-IP hostname or management IP address>/mgmt/tm/asm/policies?\$select=name,id | jq '.'

    For example, the following command returns two security policies, parent_policy and child_policy1, and related MD5 hash identifiers (id) for host bigip.example.com:

    curl -sku admin:admin https://BIGIP.example.com/mgmt/tm/asm/policies?\$select=name,id | jq '.'

    {
          "kind": "tm:asm:policies:policystate",
          "selfLink": "https://localhost/mgmt/tm/asm/policies/2fFJIXo8nnfwGG9O78o3ig?ver=17.1.1",
          "name": "parent_policy",
          "id": "2fFJIXo8nnfwGG9O78o3ig"
        },
        {
          "kind": "tm:asm:policies:policystate",
          "selfLink": "https://localhost/mgmt/tm/asm/policies/FYHvhp8R1wYalvLTjXeKoA?ver=17.1.1",
          "name": "child_policy1",
          "id": "FYHvhp8R1wYalvLTjXeKoA"
        }

Display the current learning suggestions for the policy

To display learning suggestions for the security policy, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to list the learning suggestions for the security policy:

    curl -sku <username:password> https://<BIG-IP hostname or IP address>/mgmt/tm/asm/policies/<MD5hash>/suggestions | jq '.'

    For example, the following command lists the learning suggestions for the security policy (child_policy1 from above) with the MD5 hash identifier of FYHvhp8R1wYalvLTjXeKoA for host bigip.example.com:

    curl -sku admin:admin https://bigip.example.com/mgmt/tm/asm/policies/FYHvhp8R1wYalvLTjXeKoA/suggestions | jq '.'

  3. Review the learning suggestion properties and determine the action you want to take for the suggestions.

Display a summarized list of properties for the learning suggestions

After you have reviewed the learning suggestion properties, you can display a list of summarized properties for the suggestions. Doing so will help you to specify the desired action to assign to a suggestion. The following procedure uses the iControl REST API to display the following information for each learning suggestion:

  • score: The score is calculated by the system and indicates how near the suggestion is to being ready to be enforced.
  • description: Specifies the suggested change or action.
  • entityName: Specifies the detected risk or attack.
  • status: Specifies the current learning suggestion status.
  • id: Specifies the suggestion hash id.

To display the summarized properties for the suggestions, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to display the summarized list of properties with the jq utility in the list of learning suggestions:

    curl -sku <username:password> https://<BIG-IP hostname or IP address>/mgmt/tm/asm/policies/<MD5hash>/suggestions | jq '.items[] | .<property>,.<property>' etc.

    For example, the following command lists the learning score, description, entityName, status and id for each learning suggestion for the security policy with the MD5 hash identifier of FYHvhp8R1wYalvLTjXeKoA on host bigip.example.com:

    curl -sku admin:admin https://bigip.example.com/mgmt/tm/asm/policies/FYHvhp8R1wYalvLTjXeKoA/suggestions | jq '.items[] | .score,.description,.entityName,.status,.id'

    For example, the summarized output for one suggestion appears similar to the following, where the learning score is 49, followed by the description, entityName, status and id:

    49
    "Enable Evasion Technique"
    "Apache whitespace"
    "ignored"
    "faphKN6RNq61bwfDQjRcew"

  3. Review the summarized output and note the learning suggestion ids for which you want to accept, delete or ignore.

Use the iControl REST API to accept a learning suggestion

When you accept a learning suggestion, you allow the policy builder to edit the policy as described in the suggestion. To use the iControl REST API to accept a learning suggestion, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to accept a learning suggestion:

    curl -sku <username:password> --request PATCH https://<BIG-IP hostname or IP address>/mgmt/tm/asm/policies/<MD5hash>/suggestions/<suggestion id> -d '{"status": "accept"}' | jq '.'

    For example,

    curl -sku admin:admin --request PATCH https://bigip.example.com/mgmt/tm/asm/policies/FYHvhp8R1wYalvLTjXeKoA/suggestions/faphKN6RNq61bwfDQjRcew -d '{"status": "accept"}' | jq '.'

  3. Repeat step 2 for each learning suggestion you want to accept.
  4. Apply the changes. Refer to the Apply the changes to the security policy section below.

Use the iControl REST API to delete a learning suggestion

When you delete a learning suggestion, the policy builder removes the suggestion from the Learning screen. To use the iControl REST API to delete a learning suggestion, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to delete a learning suggestion:

    curl -sku <username:password> --request DELETE https://<BIG-IP hostname or IP address>/mgmt/tm/asm/policies/<MD5hash>/suggestions/<suggestion id> | jq '.'

    For example,

    curl -sku admin:admin --request DELETE https://bigip.example.com/mgmt/tm/asm/policies/FYHvhp8R1wYalvLTjXeKoA/suggestions/faphKN6RNq61bwfDQjRcew | jq '.'

  3. Repeat step 2 for each learning suggestion you want to delete.

Use the iControl REST API to ignore a learning suggestion

When you ignore a learning suggestion, the suggestions no longer appear in the Learning screen, even if the suggestion is triggered by another request. Ignored suggestions can still be viewed using the filter. To use the iControl REST API to ignore a learning suggestion, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to ignore a learning suggestion:

    curl -sku <username:password> --request PATCH https://<BIG-IP hostname or IP address>/mgmt/tm/asm/policies/<MD5hash>/suggestions/<suggestion id> -d '{"status": "ignored"}' | jq '.'

    For example,

    curl -sku admin:admin --request PATCH https://bigip.example.com/mgmt/tm/asm/policies/FYHvhp8R1wYalvLTjXeKoA/suggestions/faphKN6RNq61bwfDQjRcew -d '{"status": "ignored"}' | jq '.'

  3. Repeat step 2 for each learning suggestion you want to ignore.

Apply the changes to the security policy

After you modify the learning suggestion, apply the policy changes by performing the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to accept a learning suggestion:

    curl -sku <username:password> https://<BIG-IP hostname or IP address>/mgmt/tm/asm/tasks/apply-policy -X POST -d '{"policyReference": {"link": "<BIG-IP hostname or IP address>/mgmt/tm/asm/policies/MD5hash"}}'

    For example,

    curl -sku admin:admin https://bigip.example.com/mgmt/tm/asm/tasks/apply-policy -X POST -d '{"policyReference": {"link": "bigip.example.com/mgmt/tm/asm/policies/"FYHvhp8R1wYalvLTjXeKoA}}'

  3. The policy changes are now in effect.
