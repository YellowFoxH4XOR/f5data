Known Issue

This is the result of a known issue. If you configure a pre-logon sequence with the Windows antivirus checker, users may receive a pop-up window during the pre-logon sequence with an error message that appears similar to the following example:

You are using TRIAL AVSDK License. Please visit www.opswat.com to purchase the license.

This issue occurs when the following two conditions are met:

  • You installed OPSWAT 2.5.7 (hotfix-99074 or hotfix-99915) on the FirePass controller
  • The user has Webroot AntiSpyware version 3.5 installed on the client system, or similar anti-spyware software

F5 Product Development is tracked this issue as CR100042 and was determined that Webroot AntiSpyware and older are not supported by OPSWAT. Upgrade to a current version of Webroot AntiSpyware

Workaround

Users can work around this issue by clicking the OK button in the error message pop-up window until the pop-up window stops appearing. The pop-up window typically appears 5 to 10 times during the pre-logon sequence.

Alternately, users can work around this issue by uninstalling the conflicting anti-spyware software from the client system.

You can work around this issue by uninstalling OPSWAT 2.5.7 (hotfix-99074 and/or hotfix-99915) from the FirePass controller. Additionally, after you uninstall the hotfix, affected clients must use the Windows Control Panel to remove the OPSWAT AntiVirus and FirePass Integration Libraries program before connecting to the FirePass controller. For more information about removing programs using the Windows Control Panel, refer to your Microsoft Windows documentation.
