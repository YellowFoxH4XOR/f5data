Description

How to get a list of Loadbalancers or Domains configured in a tenant?

Environment

  • F5® Distributed Cloud Console

Answer/Recommended Actions

  1. Go to Web App & API protection tile
  2. Select System Namespace > click on Performance. At the bottom of the Dashboard, one should be able to see the list of all LB's
  3. Select Settings () and add the Domain field to see the domains, and then Download CSV file.
