Known Issue

Application Visibility and Reporting (AVR) displays HTTP profiles from only the Common partition when you use display all.

This issue occurs when the following condition is met:

  • You view the HTTP Analytics profiles from within the All [Read Only] partition.

Impact

When you view all partitions in read-only mode, the system does not display analytics profiles from the non-Common partition.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • If you have HTTP Analytics profiles configured in multiple partitions, the system will not display them when you look at all profiles from within the Common partition.
  • Only the HTTP Analytics profiles from the Common partition are shown in the All [Read Only] view.

Resolution

Workaround

To work around this issue, you can use the Configuration utility to switch to the partition and view the Analytic profiles within that partition, or you can use the TMOS Shell (tmsh) from the command line to view all of the profiles.

Impact of workaround: Performing the suggested  workaround should not have a negative impact on your system.
