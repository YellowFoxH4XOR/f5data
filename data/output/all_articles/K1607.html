Topic

Beginning with BIG-IP version 4.2, F5 Network supplies an ISAPI filter to transform IIS server HTTP redirect responses to https instead of http. This filter is sometimes needed when using the BIG-IP SSL Proxy.

This Solution describes how ISAPI filtering works and how, if necessary, to configure an alternative port.

If you have IIS servers, we recommend that you use ISAPI filtering to transform HTTP redirect responses rather than using the BIG-IP redirect rewrite feature. ISAPI filtering provides better performance and it allows you to correct any potential problems at the source (that is, the webserver).

The new ISAPI filter file is called redirectfilter.dll and is located in the /usr/contrib/f5/redirect directory.

Note: For specific instructions about how to install your IIS server, refer to the BIG-IP Reference Guide.

Without ISAPI filtering, the IIS server redirects a client who requests https://www.foo.com/bar to http://www.foo.com/bar/. Note the change from https to http. Because we want the client to remain on an SSL-secured channel (https), the desired behavior would be to rewrite the redirect to https://www.foo.com/bar/.

Additionally, if the IIS webserver generating the redirect is listening on a non-standard port (for example, 8080) and if the port value has been configured in the Windows registry (See the following section in this Solution titled, Configuring an alternate port value), the port number in the redirect response is changed to that value. For example, if the registry has been configured to use port 443, the redirect response will be redirected to https://www.foo.com:443/bar/.

If a port number has not been configured in the registry, the default behavior of the ISAPI Filter is to strip the port number from the redirect response, such that the redirect response will now be https://www.foo.com/bar/.

Configuring an alternate port value

To configure an alternate port value to be substituted in the redirect response, create a registry key as follows:

  1. From the Start menu, select Run.

    The Run dialog box opens.

  2. In the Open box, type regedit, and click OK.
  3. Expand the HKEY_LOCAL_MACHINE registry key folder.
  4. Right-click SOFTWARE, select New and Key, and type F5.
  5. Right-click on F5, select New and Key, and type RedirectRewriteFilter.
  6. Right-click on RedirectRewriteFilter, select New and DWORD value, and type Port.
  7. Set the DWORD value to the port number that will be used to rewrite the redirect response.
