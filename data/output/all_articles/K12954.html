K12954: The inline notify setting will affect volume scan behavior when a policy is resumed after being paused

Topic

When you enable a policy rule for a managed volume, the system starts a volume scan in order to discover files that it will migrate according to the policy rule. However, if you pause and then resume the policy rule, the volume scan behavior differs depending on whether the inline notify setting is enabled or disabled.

When you resume a paused policy rule:

If inline notify is disabled, the system starts a new volume scan. The system continues to migrate files discovered by the new volume scan that match the policy rule.

If inline notify is enabled, the system does not start a new volume scan. The system migrates only modified files, processed inline, that match the policy rule.

This is the intended behavior and is not indicative of a failure.

Note: This behavior does not affect the placement of new files or directories; the rule causes the system to create these entries on the target storage, so no migrations are necessary.

Supplemental Information:

  • For information about the inline notify setting, refer to the ARX CLI Reference Guide.
