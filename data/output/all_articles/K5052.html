Known Issue

This is the result of a known issue. An SSL proxy will attempt to reconnect to an LDAP server twice after failing to connect. If the proxy cannot reconnect to the LDAP server, it will not attempt to connect again unless proxyd is restarted. When this situation occurs, the following message is logged in the /var/log/proxyd file:

Error during connect to authz ldap server.  Setting to DENY_ALL.

F5 Networks Product Development tracked this issue as CR48598 and CR48599 and it was fixed in BIG-IP version 4.5.13 for the 4.5 software branch. For information about upgrading, refer to the BIG-IP Release Notes.

This problem still exists in the 4.6 software branch.
