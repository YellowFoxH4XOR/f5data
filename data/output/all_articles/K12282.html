Known Issue

This is the result of a known issue. A packet capture using the proxy-all option fails to capture all proxy IP address traffic.

Note: For information about the capture session command or the proxy-all option, refer to the ARX CLI Reference Guide.

F5 Product Development tracked this issue as ID 39118 and it was fixed in ARX version 5.2.0. For information about upgrading, refer to the ARX release notes.

This issue was fixed in ARX hotfix release version 5.1.5 HF4 (build 11974). Customers affected by this issue can download this hotfix or a later version of the hotfix from the F5 Downloads site.

This issue was also fixed in ARX hotfix release version 5.0.6 HF10 (build 39118). Customers affected by this issue can request this hotfix or a later version of the hotfix from F5 Technical Support by referencing ID 39118 and this Solution.
