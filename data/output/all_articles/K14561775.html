Recommended Actions

How to monitor and start SDC essential processes.        

Monit is a daemon used to monitor/start essential process per SDC node

  1. To verify the processes are running run the following command. 
    # [root@B-SDC-1 aim]# date; monit summary
    Thu Mar 12 16:15:38 +08 2020
    The Monit daemon 5.14 uptime: 510d 12h 2m
    System 'system-B-SDC-1'            Running
    Program 'B-SDC-1_WEB-UI'           Status ok
    Process 'B-SDC-1_TRIPO'            Running
    Process 'B-SDC-1_tomcat'           Running
    Process 'B-SDC-1_splunkforwarder'  Not monitored
    Process 'salt-minion'              Running
     
  2. To start a process that is not running run the below command.
    # monit start <process_name>
    Example: monit start B-SDC-1_CPF

To view peer/pool member status from GUI 

  1. Access the GUI/Web UI
  2. Navigate to Topology >>  Global properties >> peers or pools 
    Note: If pools are up, the status shows in green
     

To view the reports for various statistics 

  1. Access the GUI/Web UI
  2. Navigate to Reports >> Transactions Summary ( per hour resolution )
  3. Navigate to Reports >> Transactions Summary ( per day resolution )
  4. Navigate to Reports >> Session Repository Entries ( per hour resolution )
  5. Navigate to Reports >> Session Repository Entries ( per day resolution )
    Note: The healthy status should show greener which indicates successful transactions if there is more red status further analysis is required.  

 
 

 
 

To view CPU and Memory utilization from GUI 

  1. Access the GUI/Web UI
  2. Navigate to Reports >>  Machine Summary 
     

To collect logs for troubleshooting

  1. Access the CLI or SSH to the device 
  2. Run the below command to collect the logs
    # /opt/traffix/scripts/./tta-ng.sh -n 10 
  3. After the script completes running, the process will provide the tar logs location. 
  4. Access the logs to review or provide to F5 support for analysis.
