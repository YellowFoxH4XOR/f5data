Issue

If a Windows Vista client attempts to access Protected Workspace using Internet Explorer 7 (IE7), FirePass may report an error message similar to the following example:

Some Windows updates are required to run Protected Workspace. Please click on the following link for more details: Windows Update for IE7 and non-default desktop on Vista.

OR contact your system administrator for assistance.

OR click here to continue.

This issue occurs when one of the following conditions are met:

  • The Windows Vista client does not have Service Pack 1 (SP1) or KB935855 installed.
  • The Windows Vista client has SP1 installed and the FirePass controller is running version 6.0.1 or 6.0.2 of FirePass software.

For Windows Vista clients who do not have SP1 installed, users can work around this issue by installing KB935855. For more information about KB935855, including a download link, refer to http://support.microsoft.com/kb/935855.

Windows Vista SP1 natively supports Protected Workspace, so users running Windows Vista with SP1 should not be prompted to install KB935855. If FirePass is running versions 6.0.1 or 6.0.2 and prompts Windows Vista SP1 clients to install KB935855, a FirePass hotfix is required to resolve the issue. For more information about this issue, refer to K8361: Windows Vista SP1 clients incorrectly prompted to install KB935855 to access Protected Workspace.
