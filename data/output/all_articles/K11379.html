Known Issue

This is the result of a known issue. Clients accessing NFS/TCP shares may observe the connections abruptly disconnect with the RPC: Timed out error message. This issue may occur even if there are no network connectivity issues between the client and the ARX system or between the ARX system and the back-end filer. When this issue occurs, the ARX system logs error messages to the ARX syslog that appear similar to the following example:

2010-02-10T13:07:39.000+0000:ARX01:2-3-NSM-3808:NET_NFS-0-ERR-NSM_NFS_TCP_ERROR:: NFS/TCP GETATTR Error-Closed Connection: Internal (cleanup). XID 0x73636301 0.0.0.0:0 => at 0.0.0.0:0. Client XID 0x495bd8b3 192.168.1.58:572.

2010-02-21T13:25:41.000+0000:ARX01:2-2-NSM-3792:NET_NFS-0-ERR-NSM_NFS_TCP_ERROR:: NFS/TCP FSSTAT Error-Closed Connection: DNAS (aged out). XID 0x2abb5562
169.254.226.65:719 => at 169.254.204.82:2052. Client XID 0x812661b4
192.168.1.57:798.

F5 Product Development tracked this issue as ID 37890 and it was fixed in ARX version 5.2.0. For information about upgrading, refer to the ARX release notes.

Additionally, this issue has been fixed in a hotfix issued for ARX versions 4.1.3, 5.0.6, and 5.1.5. To request the hotfix, contact F5 Technical Support, referencing this Solution number and the associated ID number.
