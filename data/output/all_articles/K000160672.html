K000160672: Revoke license BIG-IP via BIG-IQ fails with "f5networks.f5_modules.bigiq_utility_license_assignment onPatch Not implemented" for ansible

Type
Support Solution
Published
2026-05-07
Updated
2026-05-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000160672

Description

When using the Ansible module f5networks.f5_modules.bigiq_utility_license_assignment to revoke licenses from BIG-IP devices managed by BIG-IQ, the following error occurs:

{"code":400,"message":"onPatch Not implemented","originalRequestBody":"{\"timeout\": 120}","kind":":resterrorresponse"}

This error prevents successful license revocation via Ansible playbooks.

Environment

  • BIG-IQ Centralized Management managing BIG-IP LTM
  • Ansible core 2.19.2 with Python 3.13.5
  • Licensing
  • Provider block includes "timeout" value

Cause

Unknown

Answer/Recommended Actions

Remove the timeout parameter from the provider block in your Ansible playbook when targeting BIG-IQ.

Additional Information

    None
