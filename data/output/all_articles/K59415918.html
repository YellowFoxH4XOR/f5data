Known Issue

When you edit or create an iRule that has regular expressions, the system may report an incorrect warning in the BIG-IP LTM log file.

This issue occurs when the following condition is met:

  • You create an iRule that uses metacharacters in a regular expression.

    For example:

    \s for whitespaces, \d for digits, etc.

Impact

The system logs a warning that suggests an incorrect resolution. However, you can safely ignore the warning message. The iRule will operate correctly.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/ltm file, you observe a message similar to the following example:

    warning mcpd[PID]: 01071859:4: Warning generated : /Common/test_regex:4: warning: ["\d" has no meaning. Did you mean "\\d" or "d"?][{number=(\d+)}].
