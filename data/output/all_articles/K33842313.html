Known Issue

The BIG-IP DNS pool member search list matches only the beginning of the pool member name.

This issue occurs when the following condition is met:

  • You attempt to manage pool members using the following procedure:
    1. From the BIG-IP DNS Configuration utility, navigate to DNS > GSLB > Pools.
    2. Click the pool Name.
    3. Click the Members tab.
    4. Click the Manage button.
    5. In the Member List section, begin typing your pool member name in the Virtual Server box.

Impact

In the Virtual Server box, items are not sorted in alphanumeric order, and long virtual server names are truncated, making it difficult to locate similarly named pool members.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you use the BIG-IP DNS Configuration utility, it may be difficult to locate a specific virtual server to add as a pool member.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to manage the pool members. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Note: When performing this procedure, you still must know the first part of the virtual server name; however, the system does not truncate long names as it does when you use the Configuration utility.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To modify a pool, use the following command syntax:

    modify /gtm pool <record type> <pool name> members add { <member name> }

    For example, to add a pool member named vs-one from the server test_server to an A record-type pool named test_pool, type the following command:

    modify /gtm pool a test_pool members add { test_server<press the tab key> }

    Note: You can continue to press the tab key until you complete the full name of the pool member. Continue adding pool members until you are finished, then complete the command with a closing brace character (}).
