Description

You are seeking assistance in creating a user with restricted privileges for password management purposes for the admin and root users. Upon reviewing the User Manager role, you observed that it doesn't allow for the modifications of admin and root users. The aim is to establish a user capable of handling the passwords of admin and root users without authorisation for any other tasks. 

Environment

  • BIG-IP
  • Authentication
  • User Manager role
  • Admin and root users

Cause

Working as expected. The User Manager role does not allow the modifications of the admin and root users. RFE (Request For Enhancement) with bug ID1561197 was raised in order to create a separate role that would allow for the password management of the admin and root users.

Recommended Actions

None.

Additional Information

The User Manager role in the BIG-IP system grants the ability to manage user accounts. Those with this role can create and modify user accounts, assign roles across various partitions, and manage passwords, including their own. User Managers can access the TMSH (Traffic Management Shell) but not the advanced shell. Their management capabilities can be specific to certain partitions or applicable across all partitions, depending on the access level assigned. This role is focused on user account administration rather than direct system configuration or management of other resources.
