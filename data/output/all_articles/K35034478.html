Description

Do you still need to verify the software images uploaded to BIG-IQ for upgrading BIG-IQ/BIG-IP?

Environment

BIG-IQ with managed BIG-IPs

Cause

Manual image (md5/checksum) verification is no longer required when you upload software images to BIGIQ.

Recommended Actions

The md5 checksum is automatically verified you upload software using the BIG-IQ GUI:
    Devices > Software Images (for upgrading BIG-IPs)
    System > Software Management (for upgrading BIG-IQ)


To view the md5 checksum status use the tmsh shell command:

    tmsh list sys software all-properties

Here is an example run with the status highlighed:
#tmsh list sys software all-properties
sys software image BIG-IQ-8.1.0.1-0.0.30.iso {
    build 0.0.30
    build-date "Fri Aug 6 09 51 34 PDT 2021"
    checksum caf6b9e7a8dd10f01306e8ea0568504a
    file-size "3172 MB"
    last-modified "Wed Aug 18 20:33:09 2021"
    product BIG-IQ 
    verified yes 
    version 8.1.0.1
}
sys software image BIGIP-16.1.0-0.0.19.iso {
    build 0.0.19
    build-date "Tue Jun 22 23 52 22 PDT 2021"
    checksum f095497b698e6f5d37d95d759f10ea84
    file-size "2440 MB"
    last-modified "Wed Aug 18 20:35:14 2021"
    product BIG-IP <<<
    verified yes 
    version 16.1.0
}

To manually verify the checksum to see that it matches see:
  • K8337: Verifying the MD5 checksum for the downloaded F5 software file
Note:If the image appears not verified under the GUI, make sure you upload the image without renaming it after downloading it from the F5 portal. Renaming the software image filename could cause the BIG-IQ to fail to verify the checksum for an iso file.
