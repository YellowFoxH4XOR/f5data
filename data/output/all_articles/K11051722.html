Known Issue

The Configuration utility may erroneously allow the BIG-IP system to download compressed management information base (MIB) files in an uncompressed format.

This issue occurs when the following condition is met:

  • You attempt to download any of the following SNMP MIB files from the BIG-IP system using a Google Chrome browser:
     
    • F5-specific MIB files (included in the mibs_f5.tar.gz file on the BIG-IP system).
    • MIB files that are not specific to F5 (included in the mibs_netsnmp.tar.gz file on the BIG-IP system).

Note: For more information about the MIB download procedure, refer to K13322: Overview of BIG-IP MIB files.

You should be able to use the Configuration utility to download SNMP MIB files in the compressed format to your SNMP management station and then manually decompress and extract the files to a file location in accordance with your SNMP management station software documentation. Because the Google Chrome web browser decompresses the files during download, this issue may cause confusion.

You can use the file utility to determine the file type of the downloaded SNMP MIB files. The following output example from running the file utility shows that the downloaded mibs_f5.tar.gz file is having a file-type of POSIX tar archive (.tar) instead of the gzip compressed data file-type (.gz).

mibs_f5.tar.gz: POSIX tar archive (GNU)

For a compressed file with a file extension of .gz, the expected output from the file utility should appear similar to the following example:

mibs_f5.tar.gz: gzip compressed data, was "mibs_f5.tar", from Unix, last modified: Tue Oct 25 18:07:49 2016

Impact

An error message displays when you attempt to manually decompress the SNMP MIB files.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you review the file properties of downloaded SNMP MIB files, you observe that decompressed files erroneously retain the .gz compressed file format extension.
  • When you attempt to decompress an SNMP MIB file, you receive an error message indicating the file is not in the correct format.

    For example, if you use the gunzip utility to attempt to decompress the file, you receive an error similar to the following:

    gunzip mibs_f5.tar.gz
    gunzip: mibs_f5.tar.gz: not in gzip format

Workaround

To work around this issue, you can either use another browser (for example, Internet Explorer or Firefox) to download the MIB files or rename the files (for example, mibs_f5.tar.gz) to be consistent with the uncompressed file format (for example, mibs_f5.tar) before attempting to untar the files.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
