Known Issue

Using the Citrix RDP web interface portal may cause failures when establishing access to additional portals.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access profile webtop contains multiple portals.
  • The access profile webtop includes a portal for a Citrix RDP web interface.
  • The Citrix portal is the first established portal connection for the client's session.
  • The client that initially opened the Citrix portal attempts to open another (non-Citrix) portal session.

Impact

Access to the configured non-Citrix portals fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Portal access does not function when you attempt to open additional portals after initially opening the Citrix portal.

Workaround

To work around this issue, you can create an iRule and apply it to the affected portal virtual server to ensure that the virtual server sends an HTTP connection close for the Citrix portal. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Creating the Connection Close iRule for Citrix portal connections

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Click iRules.
  4. Click iRules List.
  5. Click Create.
  6. Enter a name for the iRule.
  7. In the Definition box, copy and paste the following iRule:

    when HTTP_REQUEST {
    if { [string tolower [HTTP::path]] starts_with "/f5vdi/citrix/" } {
    HTTP::header replace "Connection" "Close"
    }
    }
  8. Click Finished.
  9. Assign the newly-created iRule to the affected virtual server.
