Topic

The output for the bigpipe tcp stats show and bigpipe udp stats show commands provides detailed information about the traffic that the BIG-IP system receives and processes. You can use this information to troubleshoot issues that the BIG-IP system encounters when passing traffic.

The bigpipe tcp stats show command

The bigpipe tcp show or bigpipe tcp stats show command provides global statistics about TCP traffic that has been handled by the BIG-IP LTM.

Output of the bigpipe tcp show or bigpipe tcp stats show command is displayed in the following format:

BIG-IP versions 9.0 through 9.4.8

GLOBAL TCP STATISTICS -- (open, close-wait, fin-wait, time-wait) = (0, 0, 0, 0) (accept, accept fail) = (0, 0) (connect, connect fail) = (0, 0) (expire, abandon, rxrst) = (0, 0, 0) (rxooseg, rxbadseg, rxbadsum, txrexmit) = (0, 0, 0, 0) (syncacheover, rxcookie, rxbadcookie) = (0, 0, 0)

BIG-IP versions 9.6.0 and later

GLOBAL TCP STATISTICS
| Conn (open, CLOSE-WAIT) = (0, 0)
| Conn (FIN-WAIT, TIME_WAIT) = (0, 0)
| Conn (accept, not accept) = (0, 0) (estab, fail) = (0, 0)
| Conn (abandon, expire) = (0, 0) Resets = 0 Bad cksm = 0
| (rxbadseg, rxooseg, txrexmits) = (0, 0, 0)
| SYN cache overflow = 0 (rxcookie, rxbadcookie) = (0, 0)

The bigpipe tcp show or bigpipe tcp stats show output includes the following messages:

Global TCP StatisticInformation displayed by the statistic
openThis statistic displays the number of connections that have completed a TCP 3-way handshake but have not yet been closed.
close-waitThis statistic displays the number of connections in the close process that are waiting for response from the remote system.
fin-waitThis statistic displays the number of connections waiting for acknowledgement for a FIN request.
time-waitThis statistic displays the number of connections waiting to close after sending acknowledgement of the FIN to the remote systems.
acceptThis statistic displays the number of incoming connections for which BIG-IP has successfully opened a socket.
accept failThis statistic displays the number of incoming connections for which BIG-IP has failed to open a socket.
connectThis statistic displays the number of outgoing connections for which the destination successfully opened a socket.
connect failedThis statistic displays the number of outgoing connections for which BIG-IP could not open the connection or the destination failed to open a socket.
expireThis statistic displays the number of connections that were closed because the timeout value was reached.
abandonThis statistic displays the number of attempted connections that received no response.
rxrstThis statistic displays the number of connections that received a reset (RST).
rxoosegThis statistic displays the number of connections that received an out of order TCP segment.
rxbadsegThis statistic displays the number of connections that received a bad TCP segment.
rxbadsumThis statistic displays the number of connections that received a TCP segment with a bad checksum.
txrexmitThis statistic displays the number of connections on which a TCP segment was retransmitted.
syncacheoverThis statistic displays the number of times the outstanding number of syncookie responses was larger than the threshold specified in the Connection.SynCookies.Threshold configuration database variable.
rxcookieThis statistic displays the number of valid syncookie responses received by the BIG-IP system.
rxbadcookieThis statistic displays the number of invalid syncookie responses received by the BIG-IP system.

The bigpipe udp stats show command

The bigpipe udp show or bigpipe udp stats show command provides global statistics about UCP traffic that has been handled by the BIG-IP LTM system.

Output of the bigpipe udp show command is displayed in the following format:

BIG-IP versions 9.0 through 9.4.8

GLOBAL UDP STATISTICS -- Conn (curr, accept, not) = (0, 0, 0) (estab, not, timed out) = (0, 0, 0) Datagrams (rx, tx, bad) = (0, 0, 0) Checksums (bad, none) = (0, 0) Unreachable ICMP = 0

BIG-IP versions 9.6.0 and later

GLOBAL UDP STATISTICS
| Conn (open, accept, not accept) = (0, 0, 0)
| (estab, fail, expire) = (0, 0, 0)
| Datagrams (rx, tx, rxbad) = (0, 0, 0)
| Checksums (bad, none) = (0, 0) Unreachable ICMP = 0

The bigpipe udp show or bigpipe udp stats show output includes the following messages:

Global UDP StatisticInformation displayed by the statistic
currThis statistic indicates the number of concurrent UDP sessions that are being treated as a connection and persisted to the same destination.
acceptThis statistic indicates the number of UDP datagrams that BIG-IP has matched to a traffic-processing feature.
(accept) notThis statistic indicates the number of UDP datagrams that BIG-IP was not able to match to a traffic-processing feature and dropped.
estabThis statistic indicates the number of UDP connections the BIG-IP system has processed and sent to a node.
(estab) notThis statistic indicates the number of UDP connections the BIG-IP system accepted, but was not able to send to a node.
timed outThis statistic indicates the number of UDP connections that were closed due to a UDP timeout.
rxThis statistic indicates the number of UDP datagrams that the BIG-IP system received.
txThis statistic indicates the number of UDP datagrams that the BIG-IP system sent.
badThis statistic indicates the number of incorrectly formatted UDP datagrams that the BIG-IP system received and that were dropped as a result.
badThis statistic indicates the number of UDP datagrams with incorrect checksums that the BIG-IP system received and that were dropped as a result.
noneThis statistic indicates the number of UDP datagrams without a check sum that the BIG-IP system received.
ICMPThis statistic indicates the number of times that the BIG-IP system received an ICMP Destination Unreachable packet in response to a UDP datagram that it sent.
