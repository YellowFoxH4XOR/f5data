Known Issue

The BIG-IP system may fail to relay Dynamic Host Configuration Protocol (DHCP) traffic.

This issue occurs when the following conditions are met:

  • The BIG-IP system is configured as a DHCP relay agent.
  • The BIG-IP DHCP relay agent fails to initialize a flow_key input variable and experiences a route lookup failure.

Impact

The BIG-IP system fails to relay an IP address from the DHCP server to the DHCP client.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The DHCP client cannot obtain an IP address from the DHCP server.
