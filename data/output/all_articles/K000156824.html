Description

Diffie-Hellman groups supporting BRAINPOOL elliptic curve are elliptical curve cryptographic groups used for secure key exchange. BRAINPOOL curves are particularly designed to offer high security and efficiency in cryptographic protocols.

The BRAINPOOL curve refers to a family of elliptic curves designed for cryptographic use, standardized in the BRAINPOOL standard released in 2005. These curves were created using a verifiably pseudorandom process, aiming to offer an alternative to other widely used curves like NIST P-256, amid concerns over potential backdoors or opaque parameter choices in existing standards. Brainpool curves are available in a range of bit-lengths (160, 192, 224, 256, 320, 384, and 512), each denoted by brainpoolPXXXr1 (and their isomorphic versions brainpoolPXXXt1). They are specified by RFC 5639, which details all domain parameters. Despite their intention for transparency, some researchers have noted minor statistical anomalies in parameter selection, though no practical weaknesses have been found. BRAINPOOL curves remain a supported option for elliptic curve cryptography in various protocols.

If you're using F5 BIG-IP, you may want to verify if these curves are enabled and actively applied to your Virtual Server configuration.

Environment

  • BIG-IP platform
  • SSL/TLS Virtual Server
  • Version: compatible with DH group BRAINPOOL curves

Cause

None

Answer/Recommended Actions

  1. Log in to your BIG-IP system using the Configuration Utility or command-line interface (CLI).
  2. Navigate to the relevant SSL profile associated with your Virtual Server.
  3. Inspect the cipher string configuration in the SSL profile settings to determine if BRAINPOOL curves are included. Look for terms such as brainpoolP256r1, brainpoolP384r1, or similar entries within the cipher list.

     

  4. If using CLI, deploy the command tmsh list /sys ssl profile and search for BRAINPOOL-specific curves.
  5. Ensure that your BIG-IP system is running a version that supports DH group BRAINPOOL curves.

Additional Information

The BRAINPOOL elliptic curves were invented by Johannes Merkle and Manfred Lochter. Their work, documented in RFC 5639 and the associated Brainpool standard, was developed as part of the German research project “Elliptic Curve Cryptography Brainpool” to provide transparent, pseudorandomly-generated domain parameters for cryptography. The standardization effort was led by these researchers to address potential concerns of parameter manipulation found in other widely deployed curves.
