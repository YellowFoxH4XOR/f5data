Known Issue

BIG-IP AFM may not log dropped traffic.

This issue occurs when all of the following conditions are met:

  • You have licensed and provisioned the BIG-IP system with the AFM module.
  • You configure the default action for the global rule by selecting the Drop option.
  • You configure the default action for the virtual server and self IP default rule by selecting the Drop or Reject options.
  • You enable logging for the global default rule.
  • The BIG-IP system processes traffic that does not match a virtual server or self IP address.

Impact

Traffic is correctly dropped, but the system fails to log the dropped traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Traffic that does not match a virtual server or self IP address is dropped, but not logged as expected.
