Issue

Old Behavior

In versions prior to BIG-IP 11.0.0, newly-available pool members are immediately counted toward the minimum-up member requirement for a pool.

This behavior may result in load balancing failures when a pool member in a priority group becomes newly available. For more information, refer to K13100: Load balancing may fail when the Slow Ramp Time pool setting is enabled with priority groups.

New Behavior

Beginning in BIG-IP 11.0.0, newly-available pool members in a priority group are not counted toward the minimum-up member requirement for a pool until after the Slow Ramp Time for the pool member has expired.

F5 Product Development tracked this change as ID 348217.

Impact

Lower-priority pool members in a priority group will remain available until the Slow Ramp Time has expired for a newly-available pool member.
