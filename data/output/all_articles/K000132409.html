Description

Duplicate MAC addresses observed for VELOS LAGs on upper stream switch

Environment

  • VELOS chassis with two tenants on a single partition
  • 2 LAGs consisting of 4 ports for first tenant and 4 ports for second tenant on single partition
  • Same VLAN used in two different trunks / LAGs

Cause

The same VLAN on multiple LAGs interfaces in single partition could result in a Layer 2 loop depending on upstream topology. 

If a loop exists without spanning tree to break it, duplicate MAC or constant topology changes could occur.

 

Recommended Actions

Option 1: Create two separate partitions for each tenant.

Option 2: Having same VLANs on multiple interfaces / LAGs is a common redundancy topology. However, loop free Layer 2 topology and / or spanning tree, need to be part of the network design.
