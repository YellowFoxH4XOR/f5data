Known Issue

Sensitive XML data may not be masked in the BIG-IP ASM violation reporting screen.

This issue occurs when all of the following conditions are met:

  • An XML profile has Sensitive Data Configuration enabled
  • Your BIG-IP ASM system receives a request that causes the Malformed XML Data violation, and it also contains the sensitive data element or attribute defined in the XML profile

Impact

XML content defined as sensitive data is visible in the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The violation details screen of a Malformed XML Data violation will display sensitive XML data in clear text, not masked as a string of asterisks.
