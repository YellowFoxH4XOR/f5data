Description

  • What is F5 Distributed Cloud AS number ?
  • What is your ASN ?

Environment

  • F5® Distributed Cloud DDoS 

Answer/Recommended Actions

F5 Distributed Cloud ASN is 35280

Peer ASN you should use while configuring GRE and BGP to Distributed Cloud is 55002, you can find it under Routed DDOS -> Manage -> Tunnels, in the upper right.
