Description

Connections are failing.

Observing error messages similar to the following in /var/log/ltm:

warning tmm1[13145]: 01260009:4: 10.10.10.1:8080 -> 10.10.10.5:25593: Connection error: ssl_null_parse:3655: alert(10) invalid record type
warning tmm1[13145]: 01260013:4: SSL Handshake failed for TCP 10.10.10.1:8080 -> 10.10.10.5:25593

Environment

  • SSL/TLS handshake
  • Client or server SSL enabled
  • TCP connection

Cause

The BIG-IP received an unexpected message, i.e. not the expected SSL/TLS message.

One example where this could occur:

  1. BIG-IP sends a Client Hello to the backend server

  2. Backend server responds with 400 Bad Request (it may not be configured for SSL/TLS)

  3. BIG-IP receives this, as a non-SSL/TLS message, resets the connection, and logs:

    Connection error: ssl_null_parse:3655: alert(10) invalid record type

Recommended Actions

As this message indicate an issue with the SSL/TLS handshake, investigate where and why the handshake is failing. It is typically a misconfiguration somewhere.

The following article is a useful reference:

  • K15292: Troubleshooting SSL/TLS handshake failures
