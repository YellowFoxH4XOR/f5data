Known Issue

This is the result of a known issue. A TCP-enabled virtual server configured with a rate shaping profile that is using Stochastic Fair Queue (SFQ) terminates connections after five minutes.

When the connection is terminated, BIG-IP LTM immediately removes the connection from the connection table.

In BIG-IP LTM 9.3.0, the connection will appear to hang and BIG-IP LTM may issue an RST to both the client and the server side.

In BIG-IP LTM 9.4.x and later, BIG-IP LTM issues an RST to both the client and server side.

F5 Product Development tracked this issue as CR84243 and it was fixed in BIG-IP 10.0.0. For information about upgrading, refer to the BIG-IP LTM and Link Controller release notes.
