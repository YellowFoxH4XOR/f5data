K000140392: Menu empty on NGINX Instance Manager

Type
Support Solution
Published
2024-07-19
Updated
2025-02-07
Applies to
  • NGINX Products
  • NGINX Instance Manager
Source
https://my.f5.com/manage/s/article/K000140392

Description

The menu options under Instance Manager is blank so there's no option to view instances, certificates and key, configurations, etc.

Environment

  • NGINX Plus

  • NGINX Management Suite

  • Instance Manager

Cause

The NGINX Management Suite needs to be activated.

Recommended Actions

Activate the NGINX Management Suite using a JSON Web Token or License.

  1. Log onto the MyF5 customer portal and download the NGINX Management Suite JSON Web Token (.jwt) or License (*.lic) file from Subscriptions.
  2. On the server, log onto NGINX Management Suite.
  3. From the NGINX Management Suite Launchpad, open Instance Manager.
  4. Choose settings from the drop down menu.
  5. Click Licenses then Get Started.
  6. Drag and drop the JWT or *.lic file collected in step one.
    Note: The JWT is recommended per F5 NGINX Management Suite: Add a license.
  7. Press Add to complete this process.
  8. Click Done when it shows the SMIME successfully uploaded
  9. Now the menu along the left side should be populated with options such as Instances, Certificates and Keys, etc. The results will vary according to the license.
