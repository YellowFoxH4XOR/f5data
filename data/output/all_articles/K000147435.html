Description

  • A legitimate request has been blocked by the WAF for violation VIOL_HTTP_RESPONSE_STATUS

 

Environment

  • F5® Distributed Cloud HTTP Load Balancer
  • Application Firewall (WAF)

Cause

  • VIOL_HTTP_RESPONSE_STATUS matches on certain response codes that you may not want actioned

Answer/Recommended Actions

The VIOL_HTTP_RESPONSE_STATUS violation is not tuned in WAF Exclusion Rules as with signatures or other violation modules.

 

  • Review the request logs to identify the upstream_rsp_code when a valid request has been identified for the VIOL_HTTP_RESPONSE_STATUS violation.

  • To allow the response code, select the custom option within the Allowed Response Status Codes section of the Advanced configuration in the App Firewall, and enter the desired response code.

 

Additional Information

  • The VIOL_HTTP_RESPONSE_STATUS violation cannot be tuned in WAF Exclusion Rules or Service Policies.
  • To disable response code enforcement entirely, set Allowed Response Status Codes to Default in the App Firewall.
