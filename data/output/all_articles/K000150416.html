Description

A UCS backup is initiated via API, but the backup never completes and no UCS archive is produced.

Environment

  • BIG-IP LTM
  • Disk Full
  • UCS

Cause

The /shared/tmp directory is full and contains remnants of previously attempted UCS backups in the form of directories whose names start with 'im', each occupying over 1Gb of space.

Recommended Actions

1. remove /shared/tmp/im* directories

2. also remove old epsec files if APM is provisioned and older files are present.

None
