Description

Tomcat process may not start after reboot if /var directory is 100% full

  • Tomcat process may not start after reboot if the /var directory on the device is full.
  • You may see error such as: diskmonitor: 011d004: Disk partition /var has only 0% free.
  • Configuration Utility web GUI will fail to load in such an event.

Environment

  • /var directory is 100% full.
  • The device has been rebooted.
Cause

Tomcat process will not have the proper space to be able to process/write log information, and will fail to start.

Recommended Actions

Clear space within /var directory.

Restart tomcat service:
bigstart restart tomcat
