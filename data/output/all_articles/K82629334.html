Description

You may want to enable an IP Intelligence policy on a virtual server only. The virtual server is blocking traffic using IP Intelligence policy as expected but there is no log entry in local logging database: Security >> Event Logs >> Network >> IP Intelligence. You've confirmed a local logging profile has been assigned to this virtual server already, in which IP Intelligence logging is enabled.

Environment

  • IP Intelligence policy
  • Logging Profiles

Cause
There is a duplicate IP Intelligence policy on global context level and IP Intelligence is not enabled in global-network logging profile.

Recommended Actions

You may disable the IP Intelligence policy on global context level if it only needs to apply the policy on some specific virtual servers. The global IP Intelligence policy uses the global-network logging profile, which may not enable the IP Intelligence logging. To simplify the configuration, please disable the global  IP Intelligence policy as below:
  1. Go to Security > Network Firewall > IP Intelligence > Policies.
  2. From the Global Policy list, select the IP Intelligence policy to None. This disables IP Intelligence policy on global context.
  3. Select Update.
