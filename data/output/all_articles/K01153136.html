Description

The Big-IP resets return traffic on port 8443. This is relevant because the Configuration Utility is listening on port 8443.

  • Virtual server traffic selects ephemeral source port 8443 to send traffic to pool member
  • Pool returns this traffic on port 8443 (as expected)
  • Big-IP Configuration Utility is listening on port 8443 & receives this traffic which is not part of a Configuration Utility flow so is reset

Environment

  • Single-NIC BIG-IP Virtual Edition
  • Version 13.0 or higher

Cause

ID 1182069: The Big-IP tmm process chooses port 8443 as its ephemeral, source port when forwarding virtual server traffic to a pool member.

Recommended Actions

Until a fix is available:

  1. Check available non-ephemeral ports on the Big-IP from the command line.
    • netstat -panot | grep LISTEN
       
  2. Set httpd to use a non-ephemeral source port (0 - 1024).
    • tmsh modify sys httpd ssl-port <port>
    • tmsh save sys config
