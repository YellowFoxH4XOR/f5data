Description

BIG-IP rebooted and the following error messages seen in /var/log/auditd/audit:

type=SYSTEM_RUNLEVEL msg=audit(date:time): pid=<pid> uid=0 auid=<auid> ses=<session> subj=unconfined_u:unconfined_r:shutdown_t:s0-s0:c0.c1023 msg='old-level=3 new-level=6 exe="/sbin/shutdown" hostname=? addr=? terminal=pts/0 res=success'
type=SYSTEM_SHUTDOWN msg=audit(date:time): pid=<pid> uid=0 auid=<auid> ses=<session> subj=unconfined_u:unconfined_r:shutdown_t:s0-s0:c0.c1023 msg='init exe="/sbin/shutdown" hostname=? addr=? terminal=pts/0 res=success'

Environment

  • BIG-IP LTM
  • Reboot
  • System Shutdown
  • Audit logs

Cause

These error messages indicate it is a user-initiated reboot.

The following CLI commands would generate those error messages:

  1. # reboot
  2. # cat /var/log/ltm |reboot
  3. # /sbin/shutdown -r

Recommended Actions

To investigate who initiated the command, you will need to analyze the /var/log/audit logs during the time of the reboot incident.

You can also run the history command to view which account initiates any of the commands.
