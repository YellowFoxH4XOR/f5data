In a high availability configuration, a failover unit may be converted to a standalone unit if it has a full license. If the unit has a failover-only license, you must contact your F5 Networks sales representative to purchase a full license before proceeding.

To determine whether you have a full license or failover-only license installed, navigate to the Device Management: Maintenance: Activate License page and select the Click here to view license details link. A table appears with a variety of licensing options. If the Failover-Only Node option is set to Enabled, you have a failover-only license. If the Failover-Only Node option is set to Disabled, you have a full license.

To convert a failover unit to a standalone unit, perform the following procedure:

  1. Log on to the FirePass Administrative Console of the unit you want to convert.
  2. Navigate to the Device Management: Configuration: Clustering and Failover page.
  3. Clear the Enable Failover Configuration check box.
  4. Click the Apply Clustering/Failover Settings button at the bottom of the page.

    You will be prompted to run the Quick Setup wizard.

    Note: Your FirePass controller does not have a full license if you instead receive an error message that appears similar to the following example:

    FirePass failover-only licensed nodes cannot be reconfigured for standalone operation.

    Contact your F5 Networks sales representative to purchase a full license.
     
  5. Run the Quick Setup wizard to set up the network configuration for the FirePass controller, or navigate to the Device Management: Configuration: Network Configuration page to manually configure the settings.

    Note: For detailed information about configuring the FirePass network settings, refer to the FirePass Controller Administrator Guide.
  6. When the Quick Setup is complete, restart the FirePass controller when prompted.

    Alternately, if you manually configured the network settings on the Device Management: Configuration: Network Configuration page, finalize the changes to restart the FirePass controller.
 
After the FirePass controller restarts, it will be a standalone device.
