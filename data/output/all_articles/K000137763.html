Description

Rename the existing iApp Application Services name to a new name.

 

Environment

  • BIG-IP
  • LTM
  • iApp
  • Renaming
  • GUI
  • CLI
 

Cause

This is by design that it is not allowed to rename or duplicate existing iApp application services.
 

Recommended Actions

1. Create a new "Application Services" with the same templates used by the existing "Application Services" that needed to be renamed
Notes: Assign a temporary VIP address as it is not allow to duplicate the same IP address with the same port as per the existing "Application Services" that needed to be renamed.

2. Open a new browser windows and browse to "BIG-IP Configuration Utility (GUI) > iApp > Application Services > Application Service List > Existing Application Service > Reconfigure" for easy reference to copy the exact configuration to the new "Application Service" (Recommended)

3. Alternatively, SSH into the BIG-IP and run below tmsh command to view the existing Application Service

"# tmsh list sys application service /Common/staffing.bain.com-4434.app/staffing.bain.com-4434"
