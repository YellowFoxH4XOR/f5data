Description

Detailed troubleshooting steps to configure TOP to troubleshoot high CPU

Environment

  • BIG-IP
  • High CPU
  • Top

Cause

Informational


Recommended Actions

Follow these steps to run a script that collects the output of the top command every 10 seconds for a 10 minutes interval.

  1. Run top command.
  2. In the top output hit "1" (number one)
  3. Hit "f",
  4. Arrow down to P = Last Used CPU (SMP) and PPID = Parent Process pid and then toggle it on with d or space to turn on (*) PPID and P columns.
    * PPID = Parent Process pid
    * P = Last Used Cpu (SMP)
  5. Press q or escape to return to the main screen.
  6. Press "shift + h" in order to see CPU usage per Threads.

 You should see the top output like below, if not, follow steps 1 to 6 again

7. Press "shift + w" to save the format.
 
Note: CPU usage per Threads settings done at step 6 will not be saved.

8. Run the following while loop to collect periodic top output at 10 seconds interval for a 10 minutes duration
 
while :; do date >> /var/tmp/top1.out; top -cbn 1 >> /var/tmp/top1.out; tmsh show sys tmm-info >> /var/tmp/top1.out; echo "###################" >> /var/tmp/top1.out; sleep 10; done

 

9. The file will be saved in the following path /var/tmp/ under the name top1.out.

10. Once you have collected the data, verify which process is constantly consuming high CPU usage and verify the objects that are related to the process
