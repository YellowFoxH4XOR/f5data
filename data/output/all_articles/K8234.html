K8234: Windows standalone VPN client starts and then immediately closes when the config.f5c file is either missing or corrupt

Topic

The config.f5c file is a required configuration file for the FirePass Windows standalone VPN client, located in the %PROGRAMFILES%\F5 VPN\ directory on the Windows client system. If a user launches the Windows standalone VPN client and the config.f5c file is either missing, incorrectly formatted, or corrupt, the standalone VPN client will close immediately. Additionally, the standalone VPN client logs an error message to the trace log that appears similar to the following example:

Tue Dec 04 17:38:28 2007 GMT (Standalone:3620,2380)  CStandaloneDoc::OnNewDocument: Cannot init profile from (null)
Tue Dec 04 17:38:28 2007 GMT (Standalone:3620,2380)  CStandaloneApp::InitInstance:ProcessShellCommand failure. Abort
Tue Dec 04 17:38:28 2007 GMT (Standalone:3620,2380)  CStandaloneApp::InitInstance:Intialization failure. Abort

Note: The trace log file is located at %USERPROFILE%\Local Settings\Temp\logterminal.txt on the client system.

If the config.f5c file is missing or corrupt, users can work around this issue by reinstalling the standalone VPN client on the client system.
