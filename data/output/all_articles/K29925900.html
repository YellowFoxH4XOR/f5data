Description

If you try and create a FQDN node in a route domain other than 0 it will fail with invalid FQDN 
tmsh create net route-domain 100 
tmsh create ltm node test fqdn { name test.com%100 }
0107189a:3: Invalid FQDN: test.com%100.
 

Environment

  • BIG-IP
  • v12.1, 13.1 and later
  • Route domain
  • FQDN node
     

Cause

This is currently not supported.
 

Recommended Actions

There is no way to implement this currently.
