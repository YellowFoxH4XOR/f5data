Description

This article explains the licensing challenges for F5OS rSeries devices (such as the 10600 platform) when using the Closed-Circuit Network (CCN) portal in secure or air-gapped environments. Users may encounter errors such as "invalid entry" for platform fields or "Invalid Unique Identifier" when submitting required information (e.g., F5_Probes, UUID) to the CCN portal, preventing successful license activation.

Environment

  • F5OS rSeries devices (e.g., F5-BIG-BT-R10600, C128)
  • F5OS software version 1.8.1 and similar
  • Licensing attempted via CCN portal in a closed/secure environment without external connectivity

Cause

The CCN licensing portal is not currently compatible with F5OS rSeries devices, resulting in errors when entering required fields and preventing successful license generation.

Recommended Actions

  1. Do not use the CCN portal for F5OS rSeries licensing:
    The CCN portal does not support these platforms at this time.
  2. Use manual license activation as a workaround:
    • Generate the dossier on your F5OS device using the recommended script (see KB K000135801: Generate CCN Dossier for F5-OS unit)
    • Submit the dossier to F5 Support for manual license file creation.
    • Apply the provided license file to your device using the F5OS GUI or CLI.
  3. If UUID is missing or all zeros:
    • Check cat /sys/class/dmi/id/product_uuid` on your device for a valid UUID.
    • If blank or all zeros, inform F5 Support; this will prevent successful dossier generation.
  4. Monitor for updates:
    Future updates may add support for licensing these platforms via CCN.

Additional Information

  • If you cannot transfer files due to security restrictions, notify F5 Support so they can assist with alternative methods.
  • When entering version strings, note that only content before the third period is considered by the license server.
