Description

The Report Constraints functionality under Custom Reports in APM function as AND operator.


Environment

  • BIG-IP APM


Cause

When custom reports are generated, the Report Constraints option can be used to search for an individual entry. However, when more than one entry is added, this field acts as an "AND" operator while displaying the results.


Recommended Actions

If you want to create a custom report on an Individual user basis then the same needs to be created individually, for each user. We can not club multiple specific users in to the Report Constraints.

Example: When a custom report is created for obtaining user details, Report Constraints can be used to get details about a specific single user. As user details are tied to a session ID, so when two entries are created in Report constraint for two different users, the outcome of the report is empty. The function is working as AND operator.
