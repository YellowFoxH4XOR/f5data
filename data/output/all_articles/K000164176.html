Description

The R37.0 CentOS 9 x86_64 RPM repository contains many app-protect packages with similar build strings, so it is not clear which package corresponds to F5 WAF for NGINX release 5.14.3.

Environment

  • Product: F5 WAF for NGINX
  • Affected release line: 5.14.x
  • Package format: RPM, CentOS 9 / el9, x86_64, R37.0 repository
  • Reference documentation: F5 WAF for NGINX Changelog
    • Note: This link takes you to a resource outside of MyF5, and the third party could remove the document without our knowledge.

Cause

F5 WAF for NGINX package builds.

Answer/Recommended Actions

Mapping of 5.14.x releases to package build strings:

  • 5.14.0 = build 5.690.0
  • 5.14.1 = build 5.690.1
  • 5.14.2 = build 5.690.6
  • 5.14.3 = build 5.690.12-1
  • 5.14.3 (latest) = build 5.690.12-2

Steps:

  1. Identify the package by its 5.690.x build string. The release series 5.14.x maps to build 5.690.x.
  2. Use the mapping above to match the build string to the release.
  3. Install the latest 5.14.3 build, 5.690.12-2, which F5 recommends. Both 5.690.12-1 and 5.690.12-2 contains F5 WAF for NGINX release 5.14.3, and 5.690.12-2 is the most recent 5.14.3 build.

Additional Information

  • In the package version string, 37.0 is the NGINX Plus R37.0 release train. The 5.690.x portion is the build identifier used to map to the F5 WAF for NGINX 5.14.x release line. Use the mapping in the Answer/Recommended Actions section rather than reading the numbers as a semantic version.
  • Builds in the 5.635.x series are not part of the 5.14.x mapping above. Do not use them to meet the 5.14.3 requirement.
  • The specific changes in 5.690.12-2 are not documented in the source information for this article.
