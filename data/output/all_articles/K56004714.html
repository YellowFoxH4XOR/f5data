Issue

Error Message

01180010:3: [license processing][error]: <error_message>

In this error message, note the following:

  • <error_message> is a message describing the problem encountered when parsing the license.

For example:

01180010:3: [license processing][error]: license verification failed

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility
Description

This message occurs when the following condition is met:

  • The BIG-IP system is unable to parse the license file because the file contains errors or the parser malfunctions.

    For example, this error may be generated if there is an error when copying the license file during manual license installation.

Impact

The BIG-IP system fails to function until the license file can be parsed and evaluated.

Recommended Actions

  • You may be able to work around this issue by re-licensing the BIG-IP system. For more information about licensing the BIG-IP system, refer to K7752: Licensing the BIG-IP system.
  • If this message occurs after re-licensing, there may be a problem with the license file or the parsing mechanism on the BIG-IP system.
