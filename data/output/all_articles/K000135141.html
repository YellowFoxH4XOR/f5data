K000135141: UnSynced SDC Components

Type
Support Solution
Published
2023-06-25
Updated
2024-10-01
Applies to
  • Traffix SDC: 5.2.X, 5.2.0, 5.1.0
Source
https://my.f5.com/manage/s/article/K000135141

Description

  • GUI Topology > Site > SDC Components shows a component Configuration Sync Status as Not Synced
  • Configuration Sync Status indicates if the component’s configuration data is currently synced with the configuration manager’s data.

Environment

  • Traffix SDC 5.x
  • Config Manager

Cause

  • Unsync may be caused due to many reasons as stated below :

1. Network problems ( connectivity EMS<->SDC )

2. \"OutofVirtualMemory\" for CM or other component processes

3. Garbage Collector ( GC ) can not release Java Virtual Memory

 

 Recommended Actions

  1. Workaround is to restart CM and other component processes.
  2. Permanent fix is to Replace GC to G1GC (on all servers) and add Java Virtual Memory to CM and other component JVM processes.

Additional Information

None.
