Known Issue

This is the result of a known issue. Assigning an SNMP monitor to a generic host server causes the gtmd process to crash on a remote synchronization group member. For example, this issue can occur when two BIG-IP GTM systems are defined in a synchronization group, and a generic host server is added to one of the systems. If an SNMP monitor is created and associated with the generic host server, the gtmd process on the remote synchronization group member will crash.

F5 Networks Product Development tracked this issue as CR79146, and it was fixed in BIG-IP GTM versions 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP GTM Release Notes.
