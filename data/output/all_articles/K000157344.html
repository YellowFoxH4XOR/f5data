Description

When visiting the application website there are generic error messages like: "site can’t be reached" or "connection reset".

Additionally, the packet captures show no HTTP response from BIG-IP to clients - and, you can see a TCP RST. 

Note: BIG-IP has a TCP RST cause feature, to enable this see the article "K13223: Configuring the BIG-IP system to log TCP RST packets"

On the packet capture taken from the BIG-IP you see that the TCP RST cause was due to an iRule - scroll all the way down on the packet (TCP RST) and expand the "F5 Ethernet Trailer Protocol".

And during that same time you should find log message that starts with "TCL error: " in the /var/log/ltm* logs, this error message will tell which iRule is faulty and give some indications on what is the issue.

 

Environment

Any BIG-IP module

 

Cause

iRule or related objects are misconfigured.

 

Recommended Actions

Correct, or remove the iRule
