K7325: BIG-IP GTM incorrectly reports the virtual server status when the BIG-IP LTM pool has no monitor configured

Known Issue

This is the result of a known issue. If the BIG-IP LTM virtual server references a load balancing pool with no configured monitor, the BIG-IP GTM system reports the virtual server status as down (red). If no monitor is configured for the BIG-IP LTM pool, the BIG-IP GTM system should mark the virtual server as up (green).

F5 Product Development tracked this issue as CR76025 and it was fixed in BIG-IP GTM 9.1.3, 9.3 and 9.4.1. For information about upgrading, refer to the BIG-IP GTM Release Notes.
