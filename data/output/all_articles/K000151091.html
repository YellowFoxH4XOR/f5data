Description

When accessing an AI web server (like Open WebUI application) through F5 BIG-IP APM Portal Access, the web page fails to render or function correctly. This issue does not occur when accessing the application directly or via VPN Tunnel mode. The problem is isolated to Portal Access mode, where dynamic content and JavaScript-based features do not load or operate as expected. The browser may show different symptom, but cannot show the expected result.

Environment

  • BIG-IP APM
  • Virtual server
  • Access profile
  • Portal Access

Cause

F5 BIG-IP APM Portal Access uses a content rewrite engine to proxy internal web applications for remote users. Modern web applications leveraging advanced JavaScript features (such as ES8+) are not fully compatible with this rewrite engine. As a result, the engine cannot properly parse or rewrite these scripts, leading to incomplete page rendering or broken functionality in Portal Access mode.

Recommended Actions

The workaround for this issue:

  • Access the AI web server in the VPN tunnel.
  • Configure the LTM+APM mode to access the AI web server.
  • Provide the RDP object, user access the RDP server, then access the AI web server.

Additional Information

If the web server contains JavaScript ES6/7, you can follow the article below, configure the modern rewrite mode for the special web server / URI.
