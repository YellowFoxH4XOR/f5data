K000149784: GUI error "Unable to get data from stream streams/platform-stats/json" when attempting to see CPU stats from one controller

Type
Support Solution
Published
2025-02-13
Updated
2025-03-27
Applies to
  • F5OS
  • F5OS-C: 1.8.X, 1.8.0
Source
https://my.f5.com/manage/s/article/K000149784

Description

After switching over the active controller role to the second controller, it is no longer possible to view CPU visualizations on the controller GUI dashboard. The following message appears:

Generating data, please wait.

Followed by the following error after waiting some time:

Unable to get data from stream streams/platform-stats/json. Please try again later. If the problem persists, contact Technical Support for further assistance.

Environment

  • Velos
  • F5OS-C v1.8.0
  • Controller
  • Configuration Utility
  • GUI

Cause

Bug ID 1814809

Recommended Actions

To restart the platform-monitor docker services run the following steps:

  1. Connect to the system controller CLI with root credentials.
  2. Execute the following from the Bash shell. Note: The command should not affect the status of any running tenants.

    docker restart platform-monitor
