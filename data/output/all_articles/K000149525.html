Description

ConfigSync shows Disconnected state between BIG IP peers in High-Availability environment - In some cases, it might be related to a license.

From ltm log, it shows repeatedly:

01260008:3: SSL transaction (TPS) rate limit reached

Environment

  • BIG IP
  • HA environment
  • License

Cause

License missing TPS definition (limited or unlimited).

Recommended Actions

Please contact Project\Sales manager and ask to correct the license.

Additional Information

To check license ssl TPS:

show /sys license detail
