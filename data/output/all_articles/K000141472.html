K000141472: Extract hosts from event logs, filter by violation

Description

You can use rest API requests to extract specific information from the ASM event logs.

We have seen that customers are struggling to export ALL event logs filtered by violation in the case where these event logs spans multiple pages (as the even logs page is limited to 100 -200 requests).

Environment

  • ASM
  • Event logs

Cause

None

Recommended Actions

Instead of stepping through each request at a time, you can make a request to the rest API and filter per violation you want to analyze.

Let us say you have thousands of "Cookie not RFC-compliant" requests in your event logs, and you want to see from what host these are coming, in that case follow the steps below:

1) SSH to the BIG-IP

2) Run the following from the bash CLI:

mysql -t -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e 'select description,viol_name,bd_icontrol_name from PLC.VIOLATIONS';

... this will give you the violations for which you can filter

In our case, we are filtering by: Cookie not RFC-compliant = VIOL_COOKIE_MALFORMED

3) Now you can make a request with the specific filter to:

restcurl tm/asm/events/requests | jq '.items[] | select(.violations[].violationReference.name == "VIOL_COOKIE_MALFORMED") | {host: .host, violations: [.violations[].violationReference.name]}'

This should give you a JSON response with all the unique hosts and occurrences that hit the "Cookie not RFC-compliant" violation.
