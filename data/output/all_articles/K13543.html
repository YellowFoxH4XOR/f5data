Known Issue

Description

The BIG-IP LTM system may report an error message when creating a custom cipher list.

This issue occurs when the following condition is met:

  • You try to configure a custom cipher list for a Client or Server SSL profile using one or more of the following strings:

    • AES128-SHA256
    • AES256-SHA256
    • TLSv1_2

BIG-IP 10.2.3 introduced support for the TLS 1.2 protocol, the SHA2, AES128, and AES256 ciphers, and the SHA256 hash. However, the BIG-IP system does not recognize the keywords associated with the new protocol, ciphers, or hash.

Note: The DEFAULT cipher string still allows the use of TLS 1.2 ciphers.

Impact

The BIG-IP system may prevent you from configuring an SSL profile cipher string containing one or more of the following: AES128-SHA256, AES256-SHA256, or TLSv1_2.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You may see one of the following error messages, either in the BIG-IP Configuration utility or the tmsh command line:

    01070312:3: Invalid keyword 'aes128-sha256' in ciphers list for profile <profile name>

    01070312:3: Invalid keyword 'aes256-sha256' in ciphers list for profile <profile name>

    01070312:3: Invalid keyword 'tlsv1_2' in ciphers list for profile <profile name>
