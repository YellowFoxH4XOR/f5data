K000148854: LACP trunks flapping through virtual wire after upgrade to v16 or later

Description

LACP configured trunks are flapping UP & DOWN

Environment

  • BIP-IP that has been upgraded to v16 or later
  • Virtual-wire configured with LACP trunks

Cause

Via change ID788757 added to v16 and later, BIG-IP with virtual-wire and LACP enabled can now bridge LACP end-to-end rather than terminate LACP locally on the BIG-IP trunks.

Sys db l2.virtualwire.multicast.bridging has been added and is enabled by default.  This might cause the LACP enabled interfaces to flap.

Recommended Actions

Disable sys db l2.virtualwire.multicast.bridging via

  tmsh modify sys db l2.virtualwire.multicast.bridging value disable

  tmsh save sys config
