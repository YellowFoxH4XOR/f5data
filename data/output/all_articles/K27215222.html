Topic

You should consider using this procedure under the following conditions:

  • You want to use the REST API to view BIG-IP configured components across all administrative partitions or for a specific administrative partition.

Description

When administering a BIG-IP LTM system, it is useful to be able to recursively view the configuration for a specific component type of an administrative partition.

The following procedure outlines the steps required to view configured components of an administrative partition using the iControl REST API (REST) across all configured partitions or specific to a singular partition.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP Configuration utility.

Procedures

  • Viewing configured administrative partitions of a BIG-IP device
  • Viewing the configuration for a specific component type across all partitions
  • Viewing the configuration for a specific component of a specific partition

Note: Viewing objects with a REST command can produce verbose JSON output. To format the JSON output to a more user-friendly format, use the jq command line JSON processor command. If the workstation you are using does not have the jq utility installed, you can omit that portion of the command by removing the | jq -M . that ends each command string.

The jq command -M flag sets the formatted JSON output to use monochrome when displaying the JSON output.  The period parameter (.) is optional in jq 1.5 and later.

Viewing configured administrative partitions of a BIG-IP device

Use the following REST command to list the configured partitions of the destination BIG-IP device:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

curl -sku <username>:<password> -X GET "https://<big-ip ip address>/mgmt/tm/auth/partition" | jq -M .

Note: Locate the partition name following the name: JSON output from the command.

Note: Replace <username> with the administrative user name and <password> with the administrative user's password.

Replace <big-ip ip address> with the IP address of the destination BIG-IP device.

Viewing the configuration for a specific object type across all partitions

Use the following REST command to recursively list the configuration for a specific LTM component across all partitions:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

curl -sku <username>:<password> -X GET "https://<big-ip ip address>/mgmt/tm/<module>/<component>?options=recursive" | jq -M .

Note: Replace <username> with the administrative user name and <password> with the administrative user's password.
Replace <big-ip ip address> with the IP address of the destination BIG-IP device.
Replace <module> with the BIG-IP module (for example: afm, am, apm, asm, avr, fps, gtm, ilx, lc, ltm, pem, swg, or vcmp).
Replace <component> with the configuration object type.
Example BIG-IP LTM components: default-node-monitor, rule-profiler, eviction-policy, snat, ifile, snat-translation, nat, snatpool, node, traffic-class, policy, traffic-matching-criteria, policy-strategy, virtual, pool, virtual-address, or rule.

Viewing the configuration for a specific component of a specific partition

Use the following REST command syntax to list the configurations of an object type for a specific partition:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

curl -sku <username>:<password> -X GET "https://<big-ip ip address>/mgmt/tm/<module>/<component>?\$filter=partition+eq+<partition name>" | jq -M .

Important: When you run the command from the Linux command line, the backslash (\) preceding the dollar sign character ($) must be included.

Note: Replace <username> with the administrative user name and <password> with the administrative user's password.
Replace <big-ip ip address> with the IP address of the destination BIG-IP device.
Replace <module> with the BIG-IP module (for example: afm, am, apm, asm, avr, fps, gtm, ilx, lc, ltm, pem, swg, or vcmp).
Replace <component> with the configuration object type.
Example BIG-IP LTM components: default-node-monitor, rule-profiler, eviction-policy, snat, ifile, snat-translation, nat, snatpool, node, traffic-class, policy, traffic-matching-criteria, policy-strategy, virtual, pool, virtual-address, rule.
Replace <partition name> with the case sensitive partition name.
