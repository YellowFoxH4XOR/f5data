Security Advisory Description

ImageMagick before 7.0.8-50 has an integer overflow vulnerability in the function TIFFSeekCustomStream in coders/tiff.c. (CVE-2019-13136)

Impact

BIG-IP (AAM, Edge Gateway, WebAccelerator)

This issue affects BIG-IP systems only when WAM or AAM is provisioned. If exploited, this vulnerability may result in partial violation of BIG-IP integrity and loss of information and access.

BIG-IP (LTM, AFM, Analytics, APM, ASM, DNS, FPS, GTM, Link Controller, PEM), BIG-IQ Centralized Management, Enterprise Manager, F5 iWorkflow, Traffix SDC

There is no impact; these F5 products are not affected by this vulnerability.

Security Advisory Recommended Actions

If you are running a version listed in the Versions known to be vulnerable column, you can eliminate this vulnerability by upgrading to a version listed in the Fixes introduced in column. If the table lists only an older version than what you are currently running, or does not list a non-vulnerable version, then no upgrade candidate currently exists.

BIG-IP (AAM, Edge Gateway, WebAccelerator)

To mitigate this vulnerability, you can disable Image Optimization in your Web Acceleration policy. To do so, perform the following procedure.

For more information, refer to the Accelerating Images with Image Optimization chapter of the BIG-IP Acceleration: Implementations manual.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation. 

Impact of procedure: When you disable image optimization, you may use more bandwidth because you are sending less optimized images to clients; however, you may also lower CPU usage because you are not reprocessing images.

  1. Log in to the Configuration utility.
  2. Go to Acceleration  >  Web Application > Policies.
  3. Select the name of your user-defined acceleration policy.
  4. Select the name of your node in the policy tree.
  5. For Matching Rules, select Acceleration Rules.
  6. Select Assembly.
  7. Under Image Optimization Settings, for Optimize image, select No Optimization.
  8. Select Save.
  9. Publish the acceleration policy.
    1. Select Publish.
    2. For Comment, enter a description.
    3. Select Publish Now.
  10. Repeat the procedure to disable Image Optimization for other policies and nodes.
