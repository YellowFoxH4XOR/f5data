Topic

Starting in FirePass version 6.0.2, you can configure individual SSL web services to request client certificates instead of enabling or disabling this feature globally. Prior to FirePass version 6.0.2, the Request client certificate during logon feature was a global setting, configured on the Device Management: Security: Certificates page in the FirePass Administrative Console.

If you want FirePass to prompt certain users for client SSL certificates, configure two SSL web services on the Device Management: Configuration: Network Configuration page under the Web Services tab. Configure one web service with the Request Client Certificate check box not selected, and provide that URL to users who will not use a client certificate for logon.

For example:

https://firepass.siterequest.com

Configure a second web service with the Request Client Certificate check box selected, and provide that URL to the users who will use a client certificate for logon.

For example:

https://cert.firepass.siterequest.com

For instructions about configuring a web service to request client certificates, refer to K8138: Change in Behavior: Request client certificate feature is now configured through individual web services.

For information about creating a new web service, refer to the FirePass Controller Administrator Guide, or the online help page on the Device Management: Configuration: Network Configuration page under the Web Services tab.
