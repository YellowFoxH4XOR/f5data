Description

A Client Side TLS connection can negotiate ALPN. This does not result in ALPN being offered by the BIG-IP  on the Server side TLS connection.

Environment

You have a Virtual Server with Client and Server side SSL profiles.

You are attempting to pass the Client side TLS ALPN options to the Pool member.

Cause

BIG-IP does not offer generic ALPN passthrough.

Recommended Actions

BIG-IP will offer ALPN Server side if:

  • HTTP Profiles are applied.
  • HTTP/2 Profiles are applied.
  • HTTP MRF Router Function is enabled. (Virtual Server Acceleration section, under HTTP/2 profile)
