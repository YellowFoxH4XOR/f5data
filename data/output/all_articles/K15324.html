Known Issue

The source code for the F5RealServerPlugin.dll is missing from BIG-IP distributions.

Impact

None

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • There are no adverse effects from this omission.

Resolution

Status

F5 Product Development has assigned ID 429231 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles
Release11.5.0K2200: Most recent versions of F5 software
HotfixNoneNone

Workaround

To work around this issue, you can retrieve the source code from the BIG-IP 11.5.0 or later ISO images.

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

Retrieve the source code in the following directory on BIG-IP 11.5.0 or later ISO images:

/downloads/rsplug-ins/F5RealMon.src.tar.gz
