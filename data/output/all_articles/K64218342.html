Description

  • You want to disable HTTP methods at global level for BIG-IQ management IP

Environment

  • BIG-IQ CM
  • Management IP allowing unwanted HTTP methods

Cause

Unwanted HTTP methods are allowed on the management IP.

Recommended Actions

Modify the /etc/webd/webd.conf file, adding instructions to permit only specific HTTP methods, then restart webd:

Impact of procedure: It's possible that the BIG-IQ user interface or the iControl REST API may become inaccessible. F5 recommends testing configuration changes in an appropriate environment before deploying to production.

ALLOWING ONLY POST AND GET IMPACTING  BIG-IQ SERVICES AND FUNCTIONALITIES

 

  1. Log in to the CLI of the BIG-IQ CM.
  2. Using a text editor open /etc/webd/webd.conf file to edit it.
  3. Locate the following lines in the file:
        server {
            listen [::]:443 ipv6only=on ssl;
            listen *:443 ssl;
     
  4. Under that section add the following configuration syntax:
    # Only allow the following methods:
        if ($request_method !~ ^(<methods to allow>)$ ){
            return 405;
        }
     
    For example the code would look like the following if you only want to permit the GET PUT PATCH DELETE POST methods:
     server {
            listen [::]:443 ipv6only=on ssl;
            listen *:443 ssl;

     # Only allow the following methods:
       if ($request_method !~ ^(GET|PATCH|PUT|DELETE|POST)$ ){
    return 405;
    }

  5. Save the changes.
  6. Execute the following command:
    webd -t

    You should observe the below messages. If you don't get them, the syntax is incorrect.

    webd: the configuration file /etc/webd/webd.conf syntax is ok
    webd: configuration file /etc/webd/webd.conf test is successful

  7. Restart webd by executing the following command:
    bigstart restart webd

    Important: these changes won't survive an upgrade. So, you have to execute them again after an upgrade.
