K41658112: Incoming SYNs are dropped and the connection does not time out.

Description

If the number of SYNs on a single connection reaches this limit, subsequent incoming SYNs are dropped and the connection might not time out.

Environment

  • SYN forwarding on FastL4 connections.
  • The number of SYNs on a single connection reaches the hard-coded limit.

Cause


Bug ID 742078 : Incoming SYNs are dropped and the connection does not time out.

Recommended Actions

  • The following command enables the forwarding of an unlimited number of SYNs:

tmsh modify sys db tm.dupsynenforce value disable

  • Upgrade the fixed version: 15.0.0, 14.1.0.6, 14.0.0.5, 13.1.1.5, 12.1.4.1
