K000153890: Unable to install yum package 'nc' in Nginx server - Bad GPG signature.

Type
Support Solution
Published
2025-08-29
Updated
2025-08-29
Applies to
  • NGINX Products
  • NGINX Plus: R32
Source
https://my.f5.com/manage/s/article/K000153890

Description

You are unable to install 'nc' package on your Nginx Plus server, you get the following error:
Error: Failed to download metadata for repo 'agent': repomd.xml GPG signature verification error: Bad GPG signature

Environment

-Nginx Plus R32
-'nc' package
-Nginx-agent

Cause

Nginx agent was not installed correctly (missing sslclientcert=/etc/ssl/nginx/nginx-repo.crt and sslclientkey=/etc/ssl/nginx/nginx-repo.key in nginx-agent.repo).

Recommended Actions

1) If you need to keep Nginx agent, you have to reinstall it following this article:

Installing NGINX Agent on RHEL, CentOS, Rocky Linux, AlmaLinux, and Oracle Linux
https://docs.nginx.com/nginx-agent/installation-upgrade/installation-plus/#installing-nginx-agent-on-rhel-centos-rocky-linux-almalinux-and-oracle-linux

2) If you don't need Nginx agent, you can delete the file '/etc/apt/sources.list.d/nginx-agent.repo' so that your OS stops looking for upgrades for the NGINX agent:

rm -f /etc/apt/sources.list.d/nginx-agent.repo

Additional Information

NGINX Agent runs as a companion process on a system running NGINX. It provides gRPC and REST interfaces for configuration management and metrics collection from the NGINX process and operating system. NGINX Agent enables remote interaction with NGINX using common Linux tools and unlocks the ability to build sophisticated monitoring and control systems that can manage large collections of NGINX instances. If you do not provide correct certificates and add them to nginx-agent.repo file, you wont be able to download any other packages because of Bad GPG verification for Nginx Agent.
