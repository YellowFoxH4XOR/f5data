Description

You wish to Log Client IP addresses/paths that are being replied by an HTTP 404 error code.  

    Environment

    • BIG-IP LTM v11.6.x and later

    Cause

     

    Recommended Actions

    Use this iRule when trying to Log and find out which IP address(es) is requesting the pages that are being replied with an HTTP code: 404 Not Found
    1. Use the following code to create a new iRule and save it.
    2. On GUI, apply it the iRule on the 'Resources' page for the Virtual Server that you are debugging. 

    iRule code:

       when HTTP_REQUEST {
           set PATH [HTTP::path]
           set CLIENT_ADDR [IP::client_addr]
       }
        when HTTP_RESPONSE {
         if { [HTTP::status] contains "404" } {log local0. "Client Source Address:$CLIENT_ADDR  $PATH "
        }
       }
    Additional Information

    None
