K000132796: TUNNEL_ERROR (no more gateway sessions are available)

Type
Support Solution
Published
2023-06-23
Updated
2026-09-25
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000132796

Description

  • VMware View connections fail.
  • Symptoms
  • You observe the following error in /var/log/apm:

<apm_hostname> info vdi[15844]:<session_id> /Common/<access_policy_name>:Common:<session_id>: {bc6a9.C} View broker: bad tunnel connection response: error - TUNNEL_ERROR (no more gateway sessions are available)


Environment

  • APM (Access Policy Manager)
  • VMWare Connection Servers

Cause

The VMWare Connections Server(s) are reached their connection limit.


 Recommended Actions

  1. Add more Connection Servers to the Pool of servers.
