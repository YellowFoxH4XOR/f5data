Known Issue

Network access sessions may unexpectedly terminate due to route table change detection.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a network access profile.
  • The network access profile has Client Side Security > Prohibit routing table changes during Network Access connection enabled.
  • A user establishes a network access session with the access profile.
  • The user device encounters a brief disruption in the local network connectivity.

Impact

The access session is terminated.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the user device encounters a brief disruption in the local network connectivity, and the local network connectivity is re-established, BIG-IP Edge Client displays an error message similar to the following example:

    Routing tables have unexpectedly changed during Network Access operation. As this represents a potential security threat, Network Access connection is terminated.

Workaround

To work around this issue, you can have BIG-IP Edge Client attempt to establish a new access session.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
