K000090535: Error Message: ReloadKeepalived: reloading keepalived configuration

Type
Support Solution
Published
2021-10-19
Updated
2022-08-25
Source
https://my.f5.com/manage/s/article/K000090535

Description

The following error messages will appear in the agent.log of the NGINX+ instance, when NGNIX Controller Agent fails to push configuration to the instance:


time="Aug 12 2021 12:22:59.151" level="info" msg="Got streaming event: nginx_config_apply" feature="configurator"

time="Aug 12 2021 12:26:29.221" level="info" msg="ReloadKeepalived: reloading keepalived configuration" feature="configurator/runner" task="config_apply"

time="Aug 12 2021 12:26:29.225" level="info" msg="Keepalived: is not running; perform start" feature="configurator/runner" task="config_apply"

time="Aug 12 2021 12:26:29.226" level="error" msg="Action failed" config_mode="managed" feature="configurator/runner" message="Waiting for new workers took too long" message_id="12241" task="config_apply"


 Environment

NGINX Controller 3.18.2

NGINX+ R24

Centos 7.8

On NGINX+ instance in /var/log/nginx-controller/agent.log


Cause

This error will appear any time the configuration fails to load on the NGINX+ instance. This does not represent the cause of the failure. The Keepalived will attempt to restart any time the config_apply process fails.

 Recommended Actions

Investigate other errors to determine the cause of the failed configuration. In the example above, the error, "Waiting for new workers took too long" is a clue to the actual problem for this example.


 Additional Information

This error does not indicate an issue with Keepalived, the NGINX Controller Agent will attempt to reload the Keepalived configuration even if Keepalived is not configured and will fail with the above message.
