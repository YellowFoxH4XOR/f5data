Known Issue

If a Border Gateway Protocol (BGP) neighbor is configured with default originate, the nexthop advertised for the default route may be incorrect.

This issue occurs when all of the following conditions are met:

  • You have BGP routing configured.
  • The BGP neighbor is configured with default originate.

Impact

The default route advertised by way of BGP is not acceptable to peers until the BGP session is cleared.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The advertised nexthop will be an invalid address 0.0.0.0.

Workaround

To work around this issue, you can clear the BGP session to the affected neighbor. To do so, perform the following procedure:

Impact of workaround: BGP routing may be temporarily affected.

  1. Log in to the bash shell command prompt as the root user.
  2. Run the following IMI Shell (imish) command:

    imish -e "clear ip bgp <address>"

  3. Replace <address> with the affected neighbor address.
