Description

This article intends to give insight into how you can generate a qkview with full snaplen (-s0) flag, which is at times essential to ensure the configuration and log files are not truncated. The default behavior is to truncate these files if any of them are greater than 5MB in size. Generating a qkview with full snaplen (-s0) flag ensures that they are not truncated. 

Environment

Generating a qkview via REST API and looking to generate it while specifying the -s0 flag.

Cause

The API endpoint for qkview generation described in K04396542: Generating a QKView diagnostic file using the iControl REST API is an asynchronous endpoint and this endpoint doesn't offer the ability to generate a qkview with -s0 flag. In order to generate a qkview with the -s0 flag via REST API, leverage the synchronous call in /mgmt/tm/util/qkview API endpoint.

Recommended Actions

  • Qkview generation via asynchronous API call
  • Qkview generation via synchronous API call

Qkview generation via asynchronous API call
The API endpoint for qkview generation described in K04396542: Generating a QKView diagnostic file using the iControl REST API is an asynchronous endpoint. This endpoint lacks an option to generate a qkview with -s0 flag.
 

Qkview generation via synchronous API call
In order to generate a qkview via API using a synchronous call, you can leverage /mgmt/tm/util/qkview endpoint. This endpoint allows utilization of the utilCmdArgs field to specify the necessary flags and that's where we have the ability to specify unlimited snaplen (-s0) for qkview generation. For example:
 

# curl -sku admin:admin -H "Content-Type: application/json" -X POST https://localhost/mgmt/tm/util/qkview -d '{ "command" : "run", "utilCmdArgs" : "-s0 -f qkview_API.qkview" }' | jq -M .
{
  "kind": "tm:util:qkview:runstate",
  "command": "run",
  "utilCmdArgs": "-s0 -f qkview_API.qkview",
  "commandResult": "Gathering System Diagnostics: Please wait ...\nDiagnostic information has been saved in:\n/var/tmp/qkview_API.qkview\nPlease send this file to F5 support.\n"
}
