K000092658: Identifying expired SSL certificates on the BIG-IP system via CLI or REST API

Type
Support Solution
Published
2022-11-18
Updated
2022-11-18
Source

Description

This article offers insight into what CLI TMSH command and REST API endpoints can be helpful in pulling the list of expired certificates on the system, so appropriate measures can be taken to identify them and replace or remove them.

Environment

  • BIG-IP device containing SSL certificates with an expired "Validity" date.

Cause

N/A

Recommended Actions

  • Retrieving list of expired SSL certificates via CLI
  • Retrieving list of expired SSL certificates via API

Retrieving list of expired SSL certificates via CLI

The following tmsh command helps return the expiration status of SSL certificates on the system::

# run /sys crypto check-cert verbose disabled ignore-large-cert-bundles enabled


For example, the following output indicates that "/Common/www.example.com_2021" certificate is expired:

root@(johnsmith-bigip1)(cfg-sync Standalone)(/Common)(tmos)# run sys crypto check-cert verbose disabled ignore-large-cert-bundles enabled
emailAddress=john.smith@f5.com,CN=www.example.com,OU=Global Services,O=F5 Inc.,L=Seattle,ST=WA,C=US in file /Common/www.example.com_2021 expired on Dec 24 08:16:06 2021 GMT
root@(johnsmith-bigip1)(cfg-sync Standalone)(/Common)(tmos)#

To return a list of expired certificates in a non-Common partition, you can navigate to that partition from the TMOS prompt using cd /<partition-name> and then run the above command.


Retrieving list of expired SSL certificates via API

The following API call helps return the expiration status of SSL certificates on the system:
 

# curl -k -u [username]:[password] "https://localhost/mgmt/tm/sys/crypto/check-cert" -H 'Content-Type: application/json' -X POST -d '{"command": "run", "utilCmdArgs": "verbose disabled ignore-large-cert-bundles enabled"}' 2> /dev/null | jq .


For example, the following output indicates that "/Common/www.example.com_2021" certificate is expired:

# curl -k -u admin:admin "https://localhost/mgmt/tm/sys/crypto/check-cert" -H 'Content-Type: application/json' -X POST -d '{"command": "run", "utilCmdArgs": "verbose disabled ignore-large-cert-bundles enabled"}' 2> /dev/null | jq .
{
  "kind": "tm:sys:crypto:check-cert:runstate",
  "command": "run",
  "utilCmdArgs": "verbose disabled ignore-large-cert-bundles enabled",
  "commandResult": "emailAddress=john.smith@f5.com,CN=www.example.com,OU=Global Services,O=F5 Inc.,L=Seattle,ST=WA,C=US in file /Common/www.example.com_2021 expired on Dec 24 08:16:06 2021 GMT\n"
}
