Description

F5OS does not work with TACACS+ authentication for Controller / Appliance.
(TACACS+ for Partition has NO issue with same config.)

The below log shows similar messages:

/var/log/secure

sshd[<PID>]: tac_connect_single: connection to 192.168.1.49:4950 failed: Permission denied
sshd[<PID>]: PAM-tacplus: connection failed srv x: Permission denied

 

/var/log/audit/audit.log

type=AVC msg=audit(1660900553.672:632): avc:  denied  { name_connect } for  pid=<PID> comm="sshd" dest=4950 scontext=system_u:system_r:sshd_t:s0-s0:c0.c1023 tcontext=system_u:object_r:munin_port_t:s0 tclass=tcp_socket permissive=0


Tcpdump shows no "Q: Authentication" packet from Active Controller IP.

Expect to see the below packet from active controller IP.
No.  Time                         Source                     Destination              Info
---------------------------------------------------------------------------------------------------------
6    2022-08-19 10:59:51.189031    <active_controller_IP>    <tacacs_server_IP>       Q: Authentication

 

Environment

  • F5OS
  • TACACS+ Authentication
  • custom port (not 49)

Cause

  • Bug ID1143841

Recommended Actions

If you can not use TACACS+ port 49, please follow the workaround described in the BugTracker for ID1143841
