K000153109: How to serve a specific page as the homepage using a Simple Route and Prefix Rewrite

Description

You want visitors who open your domain's root URL to see a specific page, such as /service.html or /team.html, without a Redirect Route. The browser should keep showing the root URL, not the full page path.
 

Environment

  • F5® Distributed Cloud Console
  • Web App & API Protection 

Answer/Recommended Actions

This can be done this with Request/Response Manipulation. Create a Simple Route that matches the root path with a Regex, then set Prefix Rewrite to the target page. Requests to the root path are forwarded to the target page, and the URL in the browser does not change.

Example : Suppose you want the domain https://example.com to show the page https://example.com/team.html as its homepage, while the address bar still shows only the domain.

Steps :

  1. Create a Simple Route.
    • Select the required HTTP method.
    • Set Path Match to Regex and enter /  as the value.
    • Add the host header for your domain.

  2. Open Advanced Options for the Simple Route.
      • Under Request/Response Manipulation, enable Prefix Rewrite.
      • Enter the target path, for example /team.html.

  3. Save the Changes
