Known Issue

The standby BIG-IP system may incorrectly advertise its self IP address as a default route.

This issue occurs when all of the following conditions are met:

  • Your system is licensed with the BIG-IP Advanced Routing Module (BIG-IP ARM).
  • The BIG-IP system is configured to use Open Shortest Path First (OSPF).
  • The BIG-IP system is currently the standby in a high availability (HA) group.
  • The BIG-IP HA group is deployed in a OSPF Not-So-Stubby-Area (NSSA) with designated and backup Autonomous system boundary routers (ASBR).

Impact

The standby BIG-IP system advertises its self IP address as a default route into the OSPF NSSA.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe the standby BIG-IP system sending OSPF link-state advertisement (LSA) (type-7) with its self IP address as a default route into the OSPF NSSA.
  • Traffic is incorrectly directed to the standby BIG-IP system.
