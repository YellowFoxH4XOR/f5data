K82804555: APM AAA General Database Error

Type
Support Solution
Published
2020-08-25
Updated
2026-01-27
Applies to
  • BIG-IP
  • BIG-IP APM: 17.0.0, 17.1.0, 17.0.X, 21.X.X, 17.X.X, 21.0.X, 21.0.0, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.3, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K82804555

Description

When creating an APM AAA Server Object, the GUI displays a General database error.

Important: There are multiple reasons as to why you may see this database error when browsing the GUI. Unless this article fits your case exactly, it is recommended to start with General Database Error Retrieving Information in the BIG-IP Configuration Utility , which helps you discover the right article for you.

Environment

  • BIG-IP APM
  • AAA Server password contains a semi-colon (;)

Cause

When the APM AAA Server Object is created, a password containing a semi-colon results in the error.

Recommended Actions

Use a password that does not contain a semi colon.

Additional Information
F5 Product Development is now tracking this issue with ID 940757

K2873: Characters that should not be used in passwords on F5 products

This article states that a lot of characters should not be used, but from testing, APM works with all characters except for the semi colon (:), and a the bash character (!). Further to this, the bash character works, except if it is as the end of the password.
