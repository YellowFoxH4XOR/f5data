K33352132: Auto-save large configuration objects while editing is not available for BIG-IQ

Type
Support Solution
Published
2020-09-04
Updated
2025-02-06
Status
Legacy Content
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K33352132

Description
An auto-save option is not available while editing BIG-IQ policies and profiles, this may cause to loose policy configuration objects if they are not committed.

Environment

  • Updating complex configurations
  • BIG-IQ 
  • Configuration objects

Cause

Complex configurations can take a long time to plan, edit, and test. If there is a timeout or some other interruption during the editing process there is a risk of losing work.
If the configuration is automatically saved regularly, loss of work would be minimized.

Recommended Actions

Manually save configuration periodically to avoid losing work.

Additional Information
None.
