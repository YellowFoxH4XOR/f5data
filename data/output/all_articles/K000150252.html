Description

When you set up Origin Pool on specific sites, there is an option named "Select Network on the site":

 

Environment

  • F5® Distributed Cloud (SaaS)
  • F5® Distributed Cloud Load Balancer
  • CE
  • SLO/SLI interface

 

Answer

This option allows you to choose CE/site interface that will be in use to forward customer traffic to origin pool.

When we select the interface such as inside/outside/segment, it simply tells which interface to use as the egress interface for the traffic to origin pool and which IP to use as the source IP. This settings does not create any routing entries. CE/site will NOT add a route entry for the origin pool subnet. 
CE/Site cannot force traffic out of the interface if there is no route and doesn't automatically create routes for origin pool networks.

To summarize:

  • we specific CE/site interface in origin pool which is responsible for traffic handling
  • packets are forwarded to the interface and based on routing table records correlated with that interface, we forward them
  • if there is no route to origin pool on selected interface, we drop such packets.
