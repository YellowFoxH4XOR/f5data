Known Issue

This is the result of a known issue. When you are using the Citrix Java ICA (JICA) client to connect to a Citrix Presentation Server through a FirePass Portal Access Favorite, pop-up windows appear with error messages. As a result, the connection to the Citrix server fails.

When you use a Portal Access Favorite to access a Citrix resource on a Citrix web portal, such as Citrix Web Interface, and the link for the resource launches the JICA applet, the applet will request a Citrix ICA configuration file from the Citrix portal. When you access the Citrix server through the Portal Access Favorite, the FirePass Java Patcher rewrites the ICA file so the JICA applet can make the ICA connection to the FirePass, which then proxies the ICA connection to the Citrix server. However, the ICA file is not correctly rewritten by the Java Patcher before being returned to the JICA applet. As a result, the JICA applet displays a Warning dialog box, with an error message that appears similar to the following example:

Error in ICA file:
The line '<html><body>' was encountered before a section was found.
Please contact your MetaFrame administrator.

After you click the OK button, the Java applet displays an Error dialog box with an error message that appears similar to the following example:

The address of an application server must be specified

F5 Product Development tracked this issue as CR80600 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Additionally, Cumulative Hotfix HF-601-5 has been issued for FirePass version 6.0.1. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Downloads site.

For instructions about how to obtain a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
