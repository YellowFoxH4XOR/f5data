K000138550: [F5OS] How to show the command result without pagination

Type
Support Solution
Published
2024-02-09
Updated
2024-02-09
Applies to
  • F5OS
  • F5OS-A
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000138550

Description

When you use show command in F5OS, you can see the result pagination ("More" in the end of the page) which you need to press SPACEBAR to continue the result.

Environment

  • F5OS-A or F5OS-C
  • Software version - 1.0 and later
  • Commands which display the result more than 1 page

Cause

The default setting of the command display is pagination.

Recommended Actions

Apply the option "| nomore" after the command to suppress pagination, for the example.
 

show system health | nomore

Or

show components | nomore


You can apply this option to other commands which show the result more than 1 page in F5OS.

Additional Information

In TMOS, we can use the same option by using command "tmsh modify cli preference pager disabled".
