Known Issue

The Event Correlation feature may cause heavy MySQL usage.

This issue occurs when all of the following conditions are met:

  • You license and provision the BIG-IP ASM module on your BIG-IP system.
  • You configure the Event Correlation feature.
  • You perform a DELETE query in the MySQL database related to the Event Correlation feature.

When the BIG-IP system discovers a potential incident and the Event Correlation feature converts it to an actual incident, related processes in the MySQL database may consume a large percentage of CPU.

Impact

The BIG-IP ASM system experiences a performance impact due to high resource usage by the MySQL database.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system performance graphs show higher than expected CPU utilization.
  • Output for the top command shows high CPU usage for the mysqld process.
  • Your BIG-IP ASM system performance degrades over time.
