K000140616: vCMP Guest shows incomplete ASM configuration and/or "Could not communicate with the system. REST Framework is not available"

Type
Support Solution
Published
2024-08-27
Updated
2024-08-27
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000140616

Description

When using the WebGUI/Configuration Utility you are observing the error message "Could not communicate with the system,
REST Framework is not available" or you are seeing an incomplete or missing ASM configuration within the vCMP guest.

For example, when navigating to the ASM Policy list it comes up empty. 

 

Environment

BigIP Viprion with the same vCMP guests spanned over multiple blades.  

 

Cause

Accessing the vCMP management from a non-primary cluster member IP address.

Verifying and modifying the ASM configuration within a vCMP guest on a Viprion should NOT be done from a non-primary blade.

 

Recommended Action 

Please configure and use the cluster IP address which will always connect to the primary blade where the configuration can be correctly verified and modified.

The cluster IP address "floats" between primary blades.

Remind that the cluster IP address (floating) is NOT the same as the cluster member IP address (Non-floating and assigened to the blade).

Please refer to article K15690 on how to configure these IP addresses 

You can use the following command on a viprion blade from any management IP to verify the basic cluster configuration:

# tmsh show sys cluster

In a QKview this same basic cluster configuration can be shown using the following qktm command:

<qkviewnumber>$ qktm show sys cluster
