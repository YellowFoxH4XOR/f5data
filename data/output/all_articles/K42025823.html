Description

You cannot download SSL certificates, keys and CSR via Configuration Utility.

Environment

  • BIG-IP version 14.x - 16.x
  • SSL Certificates
  • Configuration Utility does not show the option "export" 
  • Configuration utility shows "No certificate" in the Certificate Subject(s)  field.
  • SSL certificate name starts with * and ends with .crt
  • Certificates are available via CLI or TMSH

Cause
This is caused by the known issue assigned with ID 876809

Recommended Actions

Download the certificates or keys using CLI or SCP

Additional Information
Bug ID 876809: GUI cannot delete a cert with a name that starts with * and ends with .crt
