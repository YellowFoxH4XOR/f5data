Known Issue

The pvac process manages HTTP and HTTPS traffic for the BIG-IP WebAccelerator. In WebAccelerator version 9.4, pvac messages are logged directly to the /var/log/wa/pvacLog file. In a future version of the BIG-IP WebAccelerator, the pvac process will be modified to direct output to the syslog-ng utility instead of the /var/log/wa/pvacLog file.

F5 Networks Product Development tracked this issue as CR74857 and it was fixed in BIG-IP WebAccelerator version 9.4.1. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.
