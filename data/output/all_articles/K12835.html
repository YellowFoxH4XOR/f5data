Known Issue

Description

The show chassis command output indicates <45 C as the normal operating temperature for both ARX 2000 and ARX 4000 platforms. However, beginning in ARX version 5.1.0, the temperature threshold was increased from 45 to 62 degrees Celsius.

Impact

None. F5 Product Development did not update the command output when they increased the threshold, so this issue is merely a typographical error.

Symptoms

As a result of this issue, the Chassis Environment section of the show chassis command displays (<45 C) as the normal operating temperature. The output appears similar to the following example:

Chassis Environment:
 Base MAC Address    Power            Fan(setting)    Temperature
 -----------------   --------------   -------------   -------------
 00:0a:49:27:25:00   Online           Online          Normal(<45 C)
