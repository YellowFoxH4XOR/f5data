Known Issue

This is the result of a known issue. Several issues have been identified in version 5.1.x of the ARX Secure Agent software. As a result, F5 removed the original 5.1.x version from the F5 Downloads site. The original versions of Secure Agent still exist as part of the ARX 5.1.0 and 5.1.5 releases, but they should not be used.

ARX Secure Agent version 5.1.x includes the following identified issues:

  • High CPU usage
  • Flagged by antivirus software as malware
  • Does not support usernames that include multibyte Unicode characters
  • Repeated failed to authenticate error messages in the Secure Agent log
  • Domain controller may experience random reboots

F5 Product Development tracked these issues as ARX ID 37865, 38450, 38108, 20831, 37998, 38142, 38854, and 38139. These issues were fixed in ARX version 5.1.7 for the ARX 5.1.x software branch and in version 5.2.0 for the ARX 5.2.x software branch. For information about upgrading, refer to the ARX release notes.

Additionally, these issues have been fixed in ARX Secure Agent version 5.1.0 Build-11972 (Hotfix 2) and 5.1.5 Build-11972 (Hotfix 2). You may download these versions or later versions of ARX Secure Agent from the F5 Downloads site.

Note: For information about displaying the version information for the ARX Secure Agent, refer to K11713: Displaying the software version for the ARX Secure Agent.

Additionally, the fixed versions of the ARX Secure Agent are included in the following ARX hotfix releases:

  • ARX version 5.1.0 Build-11936 (HF6)
  • ARX version 5.1.5 Build-11974 (HF4)

Customers can contact F5 Technical Support to request the ARX hotfix release that contains a hotfix version of ARX Secure Agent. When contacting F5 Technical support, include the CR number and the Solution number in your correspondence.

Note: For information about installing the ARX Secure Agent software, refer to the ARX Secure Agent Installation Guide for the version you are installing.
