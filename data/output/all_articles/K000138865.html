K000138865: Portal Access fails with a TCP Reset for "Internal error (demangle, More data required)"

Type
Support Solution
Published
2024-03-08
Updated
2024-03-08
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000138865

Description

This solution will explain the reason(s) you might see this Reset Cause.

  • Portal Access fails with a Reset
  • In a packet capture you see a Reset with the following Reset Cause:

140.215.112.91 140.216.160.9 TCP 80 0.000633000 441 OUT s1/tmm2 : 55036 → 80 [RST, ACK] Seq=1157192529 Ack=3463292717 Win=0 Len=77 [F5RST(peer): Internal error (demangle, More data required)] /Common/<name_of_virtual_server>


Environment

  • Portal Access/Rewrite
  • Rewrite Profile
  • APM

Cause

This Reset Cause means the server sent incomplete or missing data in the HTTP Response. For example missing Headers.

Recommended Actions

Verify the server Response has correct and complete data per the Hypertext Transfer Protocol.


Additional Information

None
