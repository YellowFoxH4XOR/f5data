K64070176: BIG IQ Web GUI loading slow. Error: I/O reactor has been shut down

Type
Support Solution
Published
2021-10-27
Updated
2023-08-15
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.0.0, 8.0.X, 8.1.0, 8.1.X, 8.2.0, 8.2.X, 8.3.0, 8.3.X, 8.X.X
Source
https://my.f5.com/manage/s/article/K64070176

Description

When logging into BIG-IQ, you may be unable to log in or it may be very slow.
While navigating the UI you may experience this error:

The system returned an unexpected error (400 Bad Request). I/O reactor has been shut down

Environment

  • BIG-IQ
  • Slow access to GUI

Cause

ID1041689

Recommended Actions

  1. Restart restjavad:
    tmsh restart sys service restjavad

  2. Disable usage data collection by navigating to System > Usage Data and deselect the Usage Data Collection check box.

Additional Information

None
