Description
When attempting to sync, this error may arise:

Remote transaction for device group /Common/device-group-failover to commit id 134 6755956824815218891 /Common/myBigIP 0 failed with error 01070294:3: The profile (/Common/udp) is a parent of one or more profiles, can't delete..

Environment

  • 2 or more BIG-IPs in a device group

Cause
If the default udp profile was modified and then a child profile was created from the modified default profile and deleted all prior to syncing the HA group, the sending unit has an action to delete the udp profile from bigip.conf. 
The receiving unit does not have a udp profile in bigip.conf.  The receiving unit still has a default udp profile (unmodified).  

Recommended Actions

Manually remove profile from bigip.conf

  1. Log in to the command line of the sending BIG-IP instance

  2. Backup the /config/bigip.conf file
    # cp /config/bigip.conf /config/bigip.conf_backup

  3. Type this command at the bash shell prompt: 
    # vi /config/bigip.conf

  4. Search for this stanza in the conf file:
    ltm profile udp /Common/udp {
    allow-no-payload disabled
    app-service none
    datagram-load-balancing enabled
    idle-timeout 60
    ip-df-mode
    pmtu ip-tos-to-client 0
    ip-ttl-mode proxy
    link-qos-to-client 0
    proxy-mss enabled
    }
    and delete all of it.

  5. Save changes and exit vi

  6. Load the updated config file  
    # tmsh load sys config

  7. Repeat these steps on the peer unit, if present.
