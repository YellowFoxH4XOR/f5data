Issue

For information about the supported protocols for the DEFAULT SSL ciphers that the Secure Socket Layer (SSL) profiles use in versions prior to BIG-IP 11.5.0, refer to K13156: SSL ciphers used in the default SSL profiles (11.x).

Old Behavior

In versions prior to BIG-IP 11.5.0, the DEFAULT SSL ciphers used by BIG-IP SSL profiles allow the SSLv3 (SSL3) protocol.

New Behavior

Beginning in BIG-IP 11.5.0, the DEFAULT SSL ciphers that the BIG-IP SSL profiles use, only allow TLS protocols and do not allow the SSLv3 protocol.

In BIG-IP 11.5.0, the default Client and Server SSL profiles allow the following SSL ciphers and protocols:

F5 Product Development tracked this change as ID 416991.

Impact

Clients and servers that do not support TLS are unable to negotiate SSL with BIG-IP virtual servers that use SSL profiles configured with the DEFAULT SSL ciphers.

Recommended Actions

None. For security reasons F5 recommends that you do not enable SSLv3 for SSL profiles.
