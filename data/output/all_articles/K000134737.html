Description

Viewing Native SSL stack connections with telemetry streaming via the f5_currentNativeConnections metric

 

Environment

BIG-IP

Telemetry Streaming

Cause

The statistic f5_currentNativeConnections measures current connections using the native SSL stack which are SSL algorithms that are hardware accelerated.
