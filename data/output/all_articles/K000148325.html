K000148325: WideIP Alias configured through the GUI is truncated to 64 characters

Type
Support Solution
Published
2024-10-30
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP DNS
Source
https://my.f5.com/manage/s/article/K000148325

Description

When configuring a WideIP in BIG-IP DNS through the GUI, if the configured Alias length exceeds 64 characters, the GUI will truncate the input Alias name, retaining only 64 characters.

Environment

BIG-IP DNS

Cause

GUI's HTML text limits the WideIP Alias name to a maximum length of 64 characters.

Recommended Actions

If the configured Alias name exceeds 64 characters in length, please set the Alias through TMSH.
