Description

  • BIG-IP configuration is missing with visible GUI error on top of the screen:

The configuration has not yet loaded. If this message persists, it may indicate a configuration problem. is displayed after license re-activation with the automatic method.

  • You get following error message when trying to load configuration on BIG-IP unit:

011c0003:3: Rule checker ::tclCheck::checkScript did not complete: save_profile_dep: invalid profile type

Environment

  • BIG-IP LTM
  • iRule using SPDY:: commands
  • Loading the configuration
  • After upgrade to version 14.1.x or later

Cause

If you have configured an iRule which use SPDY:: commands, you may encounter loading config issues during software upgrades.

 Recommended Actions

Remove SPDY:: iRule commands from your configurations before upgrade to 14.x. releases.

Additional Information

SPDY:: iRule commands were intentionally removed since 14.1.x version, because the SPDY profile was deprecated.
K58959262: SPDY, IIOP, and MSSQL profile types are not available in BIG-IP 13.x

If problem remains after modifying configuration, or its not applying to your setup, please open Service Order by contacting F5 Networks Support.
