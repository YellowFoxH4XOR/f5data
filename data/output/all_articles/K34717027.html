Description

Edge Client and MacOS (10.15) are getting Error message in the Edge Client's edge.log file:

Profile Controller, Failed, Incorrect external profile

Environment

  • MacOS
  • Edge Client
Cause

Bug ID 756540

Recommended Actions

The fix for this is a 1 line addition to the APM missing.php file.  See the following procedure to implement the fix:

  1. SSH into the box
  2. Edit the /var/sam/www/webtop/missing.php file
  3. Add the following after "200 OK":

    header("Cache-Control: no-cache, no-store");

    so the file content will be looking like:

    #--- Start not part of the file
    <?
    header("HTTP/1.1 200 OK");
    header("Cache-Control: no-cache, no-store");    #<---------
    ?>
    The requested file was not found on the server. Please contact system administrator!
    #--- End not part of the file

  4. Save changes to file and exit editor
  5. Delete existing RamCache content:

    tmsh delete ltm profile ramcache all
