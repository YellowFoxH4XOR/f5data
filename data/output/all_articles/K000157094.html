Description

To access the Traffic Groups page of the BIG-IP GUI there is a fast and direct way which is by simply clicking the "Active" or "Standby" line in the top left corner of the GUI, near the F5 logo.
However, clicking on "Active" or "Standby" does not load the traffic groups page.
Instead a blank page is displayed

Environment

  • After upgrading to v17.1.3 or v17.5.1.x
  • Wanting to access the Traffic Groups

Cause

Bug ID 2119173

Recommended Actions

See the Workaround in the Bug Tracker for Bug ID 2119173
