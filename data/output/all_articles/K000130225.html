K000130225: Can you poll /mgmt/shared/pipeline/manager/shared-index-config endpoint in BIG-IQ?

Type
Support Solution
Published
2023-03-20
Updated
2023-05-25
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000130225

Description

BIG-IQ GUI uses /mgmt/shared/index/config to display virtual servers and SSL profiles but there is no documentation on how to use this endpoint. 

 

Environment

-BIG-IQ

-REST Framework

 

Cause

Unfortunately, pipeline manager is not publicly documented.

 

Recommended Actions

You need to use mulistage query to take this data from pipeline manager:

 

{

"multiStageQueryRequest": {

"queryParamsList": [

{

"description": "stage1",

"managedPipelineWorkerName": "query-processor-pipe",

"jsonContext": {

"filterProcessorUri": "https://localhost/mgmt/cm/adc-core/working-config/ltm/virtual/?$filter=profileClientsslReference/link%20eq%20%27*%27%20&searchKind=cm:adc-core:working-config:ltm:virtual:adcvirtualstate&referenceDepth=4&inflate=true&$expand=profilesCollectionReference,poolReference"

}

}

]

},

"infoLogThresholdMillis": 4000,

"warnLogThresholdMillis": 6000

}

 

To list VSes which has clientssl profile attached we can use the following query:

 

curl -ksu admin:admin https://10.171.218.200/mgmt/shared/pipeline/manager -d @multistageclientssl | jq '.items[].name'
