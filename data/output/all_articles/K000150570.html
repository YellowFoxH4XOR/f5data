Description

This article addresses the mitigation of CVE-2025-24813, a vulnerability in Apache Tomcat related to serialized Java payloads. The vulnerability can lead to remote code execution or unrestricted file uploads if exploited.

Environment

Product: BIG-IP ASM

Cause

CVE-2025-24813 exploits a path equivalence issue in Apache Tomcat, allowing attackers to execute serialized Java payloads remotely or upload files without restrictions.

Recommended Actions

F5 has released new attack signatures to mitigate CVE-2025-24813. These signatures are included in the live update file ASM-AttackSignatures_20250319_141028.im. The relevant attack signatures are:

  • 200204010 – Apache Tomcat Path Equivalence Remote Code Execution
  • 200020223 – Apache Tomcat Path Equivalence Unrestricted File Upload

To apply these updates:

  • Download the latest attack signature update from F5 Downloads.
  • Import and apply the update on your BIG-IP ASM system following standard procedures for updating attack signatures.

Additional Information

For backend server protection against CVE-2025-24813, ensure that Apache Tomcat instances are updated with patches provided by the vendor and follow best practices for securing serialized Java objects.
