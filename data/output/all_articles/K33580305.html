Description

When accessing System > Resource Provisioning page on the GUI, you see the following error when trying to change MGMT provisioning to LARGE (or other values) or provision another module:
The resources required for the selected modules is likely greater than those available

Environment

  • BIG-IP VE
  • Changing MGMT provisioning or provisioning another module

Cause

This issue is tracked with ID706269: Provisioning UI is not aware of appdata volume changes

Recommended Actions

This error shows in the GUI but can be ignored by clicking on 'Submit', alternatively you can provision the modules or change the MGMT provisioning via CLI.

Additional Information

None
