Description
vCMP rebooted unexpectedly. 
There is no reason logged before it rebooted  in /var/log/ltm.

Some of daemons may have generated core files just before it rebooted.
but /var/log/kern.log  often has similar to below log before reboot occured, but may not have it.

err kernel: INFO: rcu_sched detected stalls on CPUs/tasks
 

Environment

  • BIG-IP
  • v13.1.3 and later
  • vCMP Host system
     

Cause

Bug ID 929173
 

Recommended Actions

There is no workaround.
 

Additional Information

/var/log/ltm may have the similar to below log when it is rebooting: 

chmand[9372]: 012a0004:4: Host Watchdog timeout count: 1

However this is generic message so that this only does not indicate this is hissing this bug.
If your platform is iSeries, then /var/log/sel may have some log indicate the cause of the reboot:

K38103003: iSeries was unexpectedly reboot and /var/log/sel has SMI Memory #08 Uncorrectable ECC, DIMM

When you see above message and no other indication why it is rebooted, then please contact F5 Support to investigate the cause.
