Topic

This article applies to BIG-IP 12.x - 13.x. For information about other versions, refer to the following articles:

  • K08342311: Single-user mode now requires the root password (14.1.x and later)
  • K14720: Configuring user authentication for single-user mode access (10.x - 11.x)

You should consider using this procedure under the following condition:

  • You want to restrict access to single-user mode on your BIG-IP host.

Description

Booting into single-user mode allows a user with console access to a BIG-IP system to bypass standard authentication and may be considered a security risk. It is possible to configure the BIG-IP host to require entering the root password before single-user mode is activated.

Note: F5 recommends enabling Appliance mode for devices that require strict administrative access to match that of a typical network appliance and not a multi-user UNIX device. For information about Appliance mode, refer to K12815: Overview of Appliance mode.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the BIG-IP root password.

Procedures

Configuring single-user mode authentication

You should perform the following procedure on each slot and boot location on which you want to restrict single-user mode access.

Impact of procedure: Root password recovery will not be possible after implementing this change.

  1. Log in to the BIG-IP command line as the root user.
  2. Use a text editor to edit the /etc/sysconfig/init file.
  3. Locate the following text:

    # Set to '/sbin/sulogin' to prompt for password on single-user mode # Set to '/sbin/sushell' otherwise SINGLE=/sbin/sushell

  4. Replace SINGLE=/sbin/sushell with SINGLE=/sbin/sulogin as shown in the following example:

    # Set to '/sbin/sulogin' to prompt for password on single-user mode # Set to '/sbin/sushell' otherwise SINGLE=/sbin/sulogin

  5. Save your changes.

Subsequent boots into single-user mode will require the user to enter the root password.
