K000154612: A device may appear offline in CLI but online in WebUI

Description

On F5 BIG-IP systems, a device may appear offline in CLI while being online in the WebUI after restoring from a UCS archive.

 

Environment

  • Product: F5 BIG-IP
  • UCS archive restore performed
  • Masterkey reset may have occurred before the issue

 

Cause

After a UCS archive restoration, the device remains offline in CLI until the configuration loading is complete. If the device stays offline, it typically indicates a configuration load failure or an issue with the promptstatusd process or its status file. The WebUI may report the device as online if management services are running; however, CLI accurately reflects the traffic processing state.

 

Recommended Actions

1. Verify Configuration Load:

      • Run tmsh load sys config verify
      • Resolve any reported errors by correcting files in /config. Repeat until no errors remain.

2. Check Device State:

      • For standalone systems:
        tmsh run sys failover online
      • For clusters:
        tmsh modify sys cluster default state online

3. Restart promptstatusd Process:

      • Run kill -HUP `pidof promptstatusd`
