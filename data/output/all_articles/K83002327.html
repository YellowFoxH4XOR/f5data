Description
Creating a certificate bundle for use as a chain certificate or as a device certificate

Environment

  • Chain certificate for use in a client_ssl profile
  • Or Device certificate bundle for use with iquery

Recommended Actions

Creating a certificate bundle from individual intermediate and root certificates

Continue stacking your intermediate certificates all the way down to the root certificate. It is common to only have 1 or 2 intermediates and a root certificate. Stack the certs in the order that they were issued.
You will be able to tell which certificate is next by looking at them. The main certificate has a subject section, and an issuer section. The issuer section of the main cert will match the subject section of the intermediate, and so on.

Once all of the certs have been stacked, select all and copy.

Using the BIG-IP Configuration Utility,

  1. Navigate to System > Certificate Management.
  2. Click Import.
  3. From the menu SSL Certificate/Key Source, at Import Type, select Certificate.
  4. Enter a certificate name, and select New or Overwrite Existing option according to your environment.
  5. From Certificate Source, select Paste Text, and paste the entire block of certs that was created earlier in your text editor, then click Import.

The Certificate Subject(s) section should now have multiple certificates that you can select.
Please note that if this is for a 3rd party device certificate, the device certificate should be 1st followed by the intermediate and root certificates. Using this method for connectivity to a GTM will allow the bigip_add command to automatically pull the entire chain and trust it instead of just the main device certificate.
