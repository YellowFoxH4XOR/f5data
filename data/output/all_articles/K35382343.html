K35382343: Virtual Server with Manual Configuration (Advanced) in GUI

Type
Support Solution
Published
2022-06-15
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP ASM: 12.1.3
Source
https://my.f5.com/manage/s/article/K35382343

Description

"Manual Configuration (Advanced)" is displayed under securities policy tab. When this happens the GUI doesn't allow user to update ASM policy for virtual server directly.

Environment

  • BIG-IP ASM
  • Virtual Server
  • Local Traffic Policy
  • ASM Policy

Cause

The same Local Traffic Policy is used by two different virtual servers. As a result, any changes made in the Local Traffic Policy on one of the virtual servers will affect the config on the other virtual server as well.

Recommended Actions

Use a separate Local Traffic Policy for each individual virtual server.

Additional Information

None
