Topic

You should consider using this procedure under the following condition:

  • You want to list the SSL protocols or ciphers allowed when accessing Configuration utility using iControl REST.
  • You want to change the SSL protocols or ciphers allowed when accessing Configuration utility using iControl REST.

For other methods of managing the SSL protocols and ciphers allowed by BIG-IP Configuration utility, refer to the following:

  • K02321234: Managing the SSL protocols and ciphers allowed by Configuration utility
  • K000140870: Managing the SSL protocols and ciphers allowed by Configuration utility for a managed BIG-IP device using BIG-IQ

Description

SSL protocols and ciphers allowed by Configuration utility are configured independently of local traffic objects, such as SSL profiles.

The default protocol and ciphers vary from version to version. You can list the SSL protocols and ciphers configured and change them to meet your requirements if needed.

The REST procedures provided in this article are examples of common BIG-IP maintenance tasks. You can use the iControl REST API to perform most of the BIG-IP system management and configuration tasks that you can perform using the TMOS Shell (tmsh). For more information about the iControl REST API, refer to the iControl REST User Guide that applies to your BIG-IP version, available on F5 Cloud Docs.

curl and jq utilities

Performing the following procedures requires command-line access to a system with the curl utility and, optionally, the jq (command line JSON processor) utility installed. These utilities are commonly available on Linux systems but can also be installed on Microsoft Windows and Mac OS X systems. Additionally, you can perform this procedure from an alternate BIG-IP system; however, the jq utility is not available on systems running versions earlier than BIG-IP 12.0.0. You can still use the curl portion of commands, but the resulting output is a single string rather than formatted JSON. For more information about the jq utility, refer to https://stedolan.github.io/jq.

Prerequisites

You must meet the following prerequisite to use this procedure:

    • Your BIG-IP system is licensed, provisioned, and configured with a management IP address.
    • You have administrative access the BIG-IP Configuration utility.
    • You have command-line access to a local workstation with the curl utility and, optionally, the jq utility installed. From more information, refer to curl and jq utilities in this article.

Procedures

    • Listing the SSL protocols and ciphers allowed by Configuration utility using iControl REST
    • Changing the SSL protocols allowed by Configuration utility using iControl REST
    • Changing the SSL ciphers allowed by Configuration utility using iControl REST

Listing the SSL protocols and ciphers allowed by Configuration utility using iControl REST

You can view the list of SSL protocols and ciphers allowed by Configuration utility on the BIG-IP system by performing the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

    1. Log in to the command line of a local workstation with the curl and jq utilities installed.
    2. Use the following command syntax to view the list of SSL protocols and ciphers allowed by Configuration utility on the BIG-IP system:

      curl -sku admin:<password> -H "Content-Type: application/json" -X GET https://<BIG-IP hostname or mgmt IP address>/mgmt/tm/sys/httpd | jq -M .

      For example,

      curl -sku admin:admin -H "Content-Type: application/json" -X GET https://192.168.81.63/mgmt/tm/sys/httpd | jq -M .

Changing the SSL protocols allowed by Configuration utility using iControl REST

You can change the list of SSL protocols allowed by Configuration utility using iControl REST. To do so, perform the following procedure:

Impact of procedure: Clients that do not support the specified SSL protocols are not able to access the Configuration utility.

    1. Log in to the command line of a local workstation with the curl and jq utilities installed.
    2. Use the following command syntax to change the list of SSL protocols allowed by Configuration utility on the BIG-IP system:

      curl -sku admin:<password> -H "Content-Type: application/json" -X PATCH https://<BIG-IP hostname or mgmt IP address>/mgmt/tm/sys/httpd -d '{ "sslProtocol": "<allowed protocols>" }' | jq -M .

      Note: Acceptable values include SSLv2, SSLv3, TLSv1, TLSv1.1, TLSv1.2, ALL, or None.

      For example,

      curl -sku admin:admin -H "Content-Type: application/json" -X PATCH https://192.168.81.63/mgmt/tm/sys/httpd -d '{ "sslProtocol": "all -SSLv2 -SSLv3 -TLSv1 -TLSv1.1" }' | jq -M .
