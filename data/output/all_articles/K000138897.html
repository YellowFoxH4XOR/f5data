Description

You would like to know the number of configurable route domains for each F5OS tenant.

Environment

  • F5OS tenant with any software version
  • Route domains

Cause

Need to know the number of configurable route domains for each F5OS tenant.

Recommended Actions

On tenant the level, F5OS acts the same as traditional TMOS where the configurable route domain IDs are between 1 and 65534.
