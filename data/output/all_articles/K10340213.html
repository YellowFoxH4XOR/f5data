Description

ECDSA not being shown at SSLabs test. When running a SSLabs test the ciphers being negotiated does not show any ECDSA cipher, but when running a tmm test the BIG-IP shows every cipher being offered. 

Example:

# tmm --clientciphers '!TLSv1_1:!TLSv1:!SSLv3:!DTLSv1:!RC4-SHA:!DES-CBC3-SHA:!ECDHE-RSA-DES-CBC3-SHA:!AES256-SHA256:!AES256-SHA:!AES128-SHA256:!AES128-SHA:!ECDHE-RSA-AES256-CBC-SHA:!ECDHE-RSA-AES128-CBC-SHA:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES128-GCM-SHA256:!DHE-RSA-AES256-GCM-SHA384:!DHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-SHA384:ECDHE-ECDSA-AES128-SHA256:ECDHE-RSA-AES256-SHA384:ECDHE-RSA-AES128-SHA256'

Environment

  • BIG-IP LTM
  • Cipher string with ECDSA ciphers.

Cause

The ECDSA ciphers require a DSA key, and will not work with (default) RSA key.

Recommended Actions

Add a ECDSA certificate/key to the SSL profile.
K21239684: Hybrid cipher configuration with ECDSA and RSA certificates
