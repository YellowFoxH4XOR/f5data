Description

The SSM agent lets a third party change the BIG-IP software.

 

Environment

Amazon AWS.

 

Cause

yum is not available on the BIG-IP.

Changing BIG-IP software is a violation of the EULA.

 

Recommended Actions

This is not supported. Specifically if you install it and the device needs support, the solution offered will be to:

 

Delete the instance entirely.

Create a new instance without SSM.

See if the issue persists.

 

Changing BIG-IP software is a violation of the EULA.
