Known Issue

You may see an error message when attempting to add a host to your peer or subordinate device trust list.

This issue occurs when the following conditions are met:

  • You attempt to add a peer or subordinate peer trusted device.
  • You use the percent (%) character in the Device IP Address, Username, or Password boxes.

Impact

You are unable to add a peer or subordinate peer using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Configuration utility page displays an error message similar to the following example:

    java.lang.NullPointerException:value is null

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to add a peer or subordinate host. To do so, perform the following procedures:

  • Adding a trusted device peer using the tmsh utility
  • Adding a trusted device subordinate using the tmsh utility

Impact of workaround: Performing the following procedures should not have a negative impact on your system.

Adding a trusted device peer using the tmsh utility

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To add a trusted peer host, use the following command syntax:

    modify cm trust-domain <trust domain> ca-devices add { <IP-Address> } name <hostname> username <username> password <password>

    For example:

    modify cm trust-domain Root ca-devices add { 172.29.21.46 } name host.domain.com username admin password per%ent

Adding a trusted device subordinate using the tmsh utility

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To add a trusted peer host, use the following command syntax:

    modify cm trust-domain <trust domain> non-ca-devices add { <IP-Address> } name <hostname> username <username> password <password>

    For example:

    modify cm trust-domain Root non-ca-devices add { 172.29.21.46 } name host.domain.com username admin password per%ent
