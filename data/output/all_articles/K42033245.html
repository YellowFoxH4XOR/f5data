Description

In some environments it may be necessary to do an AD Query with a Client Certificate from an On-Demand action.

Environment

  • BIG-IP APM 
  • On Demand Certificate Authentication
  • AD Query

Cause

Expected Behavior

Recommended Actions

Create an Access Policy with the flow outlined below:

  1. On-Demand Certificate Authentication
    See Manual in link below for assistance configuring On-Demand Certificate Authentication
     
  2. Variable assign:
    Single Variable Assign using the following two in this order:

Custom Variable:

        session.custom.cert.upn

Custom Expression:

        set extension [string tolower [mcget {session.ssl.cert.x509extension}]]; return [string range $extension [expr {[string first "othername:upn<" $extension] +14}] [expr {[string last ">" $extension] -1}] ];

Custom Variable:

        session.logon.last.username

Customer Expression:

        set upn [mcget {session.custom.cert.upn}]; if { $upn contains "@" } { return [string range $upn 0 [expr { [string first "@" $upn] - 1 } ] ]; } else { return $upn; }

  1. AD Query

Additional Information

You can check the session variables assigned to an active user with sessiondump:

# sessiondump -allkeys |grep <session_id> > /shared/tmp/session_variables.txt

Example:
# sessiondump -allkeys |grep asdf4652 > /shared/tmp/session_variables.txt
