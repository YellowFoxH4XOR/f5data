Known Issue

This is the result of a known issue. If you configure the RSTP profile's Idle Timeout setting to a value greater than 300 seconds, the BIG-IP system applies the default idle timeout of 300 to RTSP connections. Similarly, if you configure the TCP profile's Idle Timeout setting to a value greater than 300 seconds, the BIG-IP system applies the default idle timeout of 300 to FTP data channel connections.

Note: The FTP profile inherits its idle timeout value from the TCP profile.

F5 Product Development is tracking this issue as ID 241420 and ID 332998 (formerly CR121329).

Note: This issue does not affect BIG-IP versions 10.2.0 and later.

This issue has been fixed in cumulative hotfix BIGIP-9.4.8-396.1-HF3, which has been issued for BIG-IP version 9.4.8. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
