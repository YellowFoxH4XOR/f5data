K000156618: irule cannot be deleted

Type
Support Solution
Published
2025-09-24
Updated
2025-09-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.0
Source
https://my.f5.com/manage/s/article/K000156618

Description

iRule deletion fails with error "01070265:3: The rule cannot be deleted because it is in use by a rule" even though the referencing iRule was already deleted.

 

Environment

BIGIP LTM

 

Cause

none

 

Recommended Actions

reloaded the configuration as suggested in bug tracker ID767217, which cleared the orphaned iRule reference and allowed deletion.
