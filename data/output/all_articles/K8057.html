Known Issue

This is the result of a known issue. Installing a UCS file with a version that is more recent than your BIG-IP system is not supported and can cause system instability. For example, a BIG-IP 9.4.1 system allows a version 9.4.2 UCS file to be installed from the command line using the bigpipe config install command; however, this installation is not supported and will cause system instability.

F5 Product Development tracked this issue as CR85604 and it was fixed in BIG-IP 9.4.2. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller or WebAccelerator Release Notes.

Workaround

If you have installed a version 9.4.2 UCS file on a 9.4.1 system, you can work around this issue by installing a backup UCS version 9.4.1 file, such as the cs_backup file, if one exists.

To install a backup UCS file, perform the following procedure:

  1. Log in to the command line.
  2. Change directories to the location of the backup UCS version 9.4.1 file on the system.

    For example, if your backup UCS version 9.4.1 file is located in the /var/local/ucs directory, you would type the following command:

    cd /var/local/ucs
  3. Install the backup UCS version 9.4.1 file using the bigpipe config install command.

    For example, if the name of the backup UCS file is cs_backup.ucs, you would type the following command:

    bigpipe config install cs_backup.ucs
