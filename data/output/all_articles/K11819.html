Known Issue

This is the result of a known issue. In rare instances, TMM may not terminate a Network Access connection properly. As a result, TMM may core when the memory from that connection is reallocated to a new Network Access connection.

Important: Whether the Network Access connection terminates properly is due to event calls in the BIG-IP APM code, and not due to the manner in which the user terminates the connection.

F5 Product Development is tracked this issue as ID 225870 (formerly CR140350) and it was fixed in BIG-IP 11.0.0. For more information about upgrading, refer to the BIG-IP APM and Edge Gateway release notes.

This issue has been fixed in Hotfix-BIGIP-10.2.2-911.0-HF2 issued for BIG-IP 10.2.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.
