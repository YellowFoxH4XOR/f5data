Issue

Old Behavior

In versions prior to APM Clients 7.1.9, captive portal support is built-in to the Edge Client for macOS and provides captive portal authentication. The user interface in these versions of Edge Client for macOS also utilize a main browser window that contains connect buttons and a scrolling speed graph.

New Behavior

Beginning in APM Clients 7.1.9, built-in captive portal support is removed from the Edge Client for macOS. The client now relies on the macOS operating system to provide captive portal authentication, which provides a more consistent experience.

Further enhancements include streamlining the user interface with the incorporation of a context menu in favor of a main window. The context menu is available by selecting the Edge Client icon in the menu bar. Edge Client now performs user authentication using a detached window that appears when required for multi-factor authentication (MFA) and forms logon.

Impact

The improvements to the BIG-IP Edge Client for macOS provide a more consistent and streamlined experience.

Recommended Actions

In BIG-IP APM 13.1.0 and later, you can update the APM Clients components independently from BIG-IP software. For more information, refer to K52547540: Updating the BIG-IP Edge Client for the BIG-IP APM system.
