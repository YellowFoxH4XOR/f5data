Description

NIM logs (/var/log/nms/nms.log) report the following error messages or similar:

(date/time) nginx-im <COR>[120065]: 2025-07-01T14:02:23.784+0200 ERROR 031e9c8e-4cb7-4a30-8092-e97a3552d610 errors/http.go:76 http failure with code '20048': secrets not found
(date/time) nginx-im <INT>[120044]: 2025-07-01T14:02:24.354+0200 ERROR nms-integrations telemetry/controller.go:420 invalid response from telemetry registration api. 401 Unauthorized, {"errors":["Registration failed"]}"

Environment

NGINX Instance Manager

Cause

These error messages indicate failed connections to TEEM endpoints. NIM will attempt to connect to TEEM for various reporting reasons, periodically. These connections will fail from time to time for various reasons such as missing secrets or TEEM endpoints unavailable. The error messages can be safely ignored and the product should function as normal.

Recommended Actions

If NIM is experiencing functional issues then open a support case.
