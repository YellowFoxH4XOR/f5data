Description

This article explains how to configure FIPS on a vCMP guest running on an i5820-DF (FIPS) or i7820-DF (FIPS) platform. The instructions are applicable for any F5 BIG-IP device that has a built-in Federal Information Processing Standards Hardware Security Module (FIPS HSM) and also supports virtual Clustered Multi-Processing (vCMP).

Environment

  • F5 BIG-IP device with built-in FIPS HSM
  • vCMP enabled system

Configuring FIPS on a vCMP-enabled system is divided into the configuration of the vCMP Host hardware and the configuration of the vCMP guest, including the assigned FIPS partition.

Recommended Actions

  1. On the vCMP Host system:

    a. Provision the host for vCMP if needed. Please see the following KB article on vCMP provisioning considerations: K14727: BIG-IP vCMP hosts and guests configuration options
    b. Log into the command line. Note that you may need to run these commands from within tmsh depending on your license and access rights.
    c. Run fipsutil reset (This will erase any data on the FIPS HSM)
    d. Run fipsutil init (No domain will be requested. This is different from running fipsutil init on a non-vCMP system, where you will be asked for a Security Domain)
    e. Run fipsutil ptnresize (Make PARTITION_1 smaller to allow room for your new partitions)
    f. Run fipsutil ptncreate (Create a partition for your guest(s). You will need one partition per guest)

  2. On the vCMP Guest:

    a. Create a new guest or move the existing guest you wish to assign the FIPS HSM to, configure and assign the correct FIPS partition
    b. Deploy the vCMP guest
    c. Log into the command line of the vCMP guest. Note that, as above, you may need to use tmsh to run these commands
    d. Run fipsutil init (This is where you set the security domain)

At this point, you can continue as if you were using a hardware FIPS HSM on a standard appliance.
