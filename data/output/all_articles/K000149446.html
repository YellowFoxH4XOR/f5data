Description

Local and remote apm logging have stopped functioning properly, the /var/log/apm file may be empty or contain similar messages:

Jan 22 10:40:46 apm.localhost.com err apmd[21514]: 01490000:3: ApmD.cpp func: "process_apd_request()" line: 2094 Msg: Error 3 reading/parsing response from socket 60. strerror: Success, queue size 0, time since accept 0

Environment

BIG-IP APM

Cause

This can be cause by a remote syslog server becoming unavailable

Recommended Actions

To resolve this issue please try the following:

1. Change the logging profile back to "default-log-setting" in the GUI under Access -> Profiles/Policies -> Access Profiles -> <policy in question -> Logs

2. If step does not resolve the issue, force mcpd process to reload the BIG-IP configuration per K13030: Forcing the mcpd process to reload the BIG-IP configuration

Additional Information

K03912652: Enable Log Publisher to log when a logging destination becomes unavailable
