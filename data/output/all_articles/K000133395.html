Description

You deploy APM VPN solutions to users, through connections made over the browser.

You have deployed some F5 software to the clients.

Upon clicking the VPN icon from the APM WebTOP, nothing happens.


Environment

  • BIG-IP APM
  • VPN, browser based sessions

Cause

This may be due to the option "HTTP Only" being activated, to the Access Profile.

Such option is not supported with VPN sessions: "HTTP Only: For BIG-IP APM deployments with connectivity resources (such as Network Access, Portal Access, etc.), do not set BIG-IP APM cookies with the HTTP Only flag."


Recommended Actions

Please uncheck the option "HTTP Only" to the Access Profile:

Note: F5Support suggests you perform the following set of actions out of working hours or during downtime.

  • With using the Configuration Utility, navigate to Access ›› Profiles / Policies : Access Profiles (Per-Session Policies)
  • Click the name of the relevant AccessProfile
  • From the top of the page, click the tab "SSO / Auth Domains"
  • Uncheck the checkbox "HTTP Only" from the parameter "Cookie Options"
  • Click the "Update" button
  • Click the link "Apply Access Policy" from the top left of the page.
