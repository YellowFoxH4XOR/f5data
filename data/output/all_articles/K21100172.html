Known Issue

You cannot manage the BIG-IP ASM system from BIG-IP Enterprise Manager systems.

This issue occurs when the following condition is met:

  • You attempt to discover or manage a BIG-IP ASM system, when using an Enterprise Manager system.

The ASM portion of iControl on the affected BIG-IP ASM system prevents communication with the Enterprise Manager system that is attempting to manage the BIG-IP ASM system.

Impact

You cannot manage the BIG-IP ASM system with Enterprise Manager systems.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/em file of the Enterprise Manager system that is attempting to manage the BIG-IP ASM system, you may observe error messages similar to the following example:

    err emdeviced[1234]: 04070a04:3: Device uid 5 failed refresh: getAsmPolicies: iControl error: 'iControl::OperationFailed - primary code:0(0x0) secondary code: 0(0x0) string: Unset policy'
    err emdeviced[1234]: 04010564:3: Could not get ASM sig file version for device with access address : getAsmPolicies: iControl error: 'iControl::OperationFailed - primary code:0(0x0) secondary code: 0(0x0) string: Unset policy'
    err emdeviced[1234]: 04010568:3: Error found on device 5 (UID: 5): getAsmPolicies: iControl error: 'iControl::OperationFailed - primary code:0(0x0) secondary code: 0(0x0) string: Unset policy'
