K80391959: Preventing the BIG-IP ASM system from sending XML requests with sensitive data to an ICAP server

Topic

You should consider using these procedures under the following condition:

  • You want to configure the BIG-IP ASM system to stop sending XML requests that contain sensitive data to an Internet Content Adaptation Protocol (ICAP) server.

Description

The BIG-IP ASM system allows an XML profile configuration to mask one or more elements using the Value Masking (BIG-IP 14.0.0 and later) or Sensitive Data Configuration (prior to BIG-IP 14.0.0) feature.

When a security policy is configured to mask sensitive elements in an XML profile, and the BIG-IP ASM system is configured to perform ICAP traffic inspection (the Anti-Virus Protection feature), the BIG-IP ASM system forwards the XML requests containing these sensitive elements to the ICAP server even though the XML profile is disabled in the ICAP configuration.

Starting in BIG-IP 16.0.0, 15.1.0.2, 15.0.1.4, 14.1.2.5, 13.1.3.4, 12.1.5.2, and 11.6.5.2, you can prevent the BIG-IP ASM system from sending XML requests that contain sensitive data to the ICAP server. To do so, modify the send_xml_sensitive_entities_to_icap internal parameter and set its value to 0. To revert to the original behavior, you can change the value of this internal parameter back to its default value of 1.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have administrative access to the command line and the Configuration utility.
  • Your BIG-IP ASM system is running any of the following BIG-IP versions:
    • 16.0.0 or later
    • 15.1.0.2 or later
    • 15.0.1.4 or later
    • 14.1.2.5 or later
    • 13.1.3.4 or later
    • 12.1.5.2 or later
    • 11.6.5.2 or later

Procedures

  • Using the command line to configure the internal parameter
  • Using the Configuration utility to configure the internal parameter

Using the command line to configure the internal parameter

Impact of procedure: Performing the following procedure temporarily disrupts traffic while the BIG-IP ASM service restarts. You should perform this procedure only during a scheduled maintenance period.

  1. Log in to the BIG-IP ASM command line.
  2. To stop the BIG-IP ASM system from sending XML requests that contain sensitive data to an ICAP server, enter the following command:

    /usr/share/ts/bin/add_del_internal add send_xml_sensitive_entities_to_icap 0

  3. To restart the BIG-IP ASM process, enter the following command:

    tmsh restart /sys service asm

Using the Configuration utility to configure the internal parameter

Note: Adding a BIG-IP ASM internal system variable from the Configuration utility is available in BIG-IP 13.1.0 and later.

Impact of procedure: Performing the following procedure temporarily disrupts traffic while the BIG-IP ASM service restarts. You should perform this procedure only during a scheduled maintenance period.

  1. Log in to the Configuration utility.
  2. Go to Security > Options > Application Security > Advanced Configuration > System Variables.
  3. Select Create.
  4. For Parameter Name, enter send_xml_sensitive_entities_to_icap.
  5. For Parameter Value, enter the numeric zero (0).
  6. Select Create.
  7. Log in to the command line.
  8. To restart the BIG-IP ASM process, enter the following command:

    tmsh restart /sys service asm
