Description

When you try to upload OpenAPI (Swagger) File to an API Security Policy, you got following error:

Failed to import OpenAPI(Swagger) file: Failed to run task

 

You are login with a local or remote user without 'All' or 'Common' partition access.

In /var/log/ts/asm_config_server.log, you see such log:

asm_config_server.pl|INFO|Jan 07 09:50:27.509|25188|F5::ASMConfig::Handler::handle_error,,Code: 502, Error message = User repro_00765581 does not have permission to call add_import_open_api_task on partition Common

Environment

  • BIG-IP ASM

Cause

Require Common partition access

Recommended Actions

Add Common partition access for user

None
