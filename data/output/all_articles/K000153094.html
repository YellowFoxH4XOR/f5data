Description

You need to configure a maintenance page for specific client IP Addresses.

Environment

  • F5® Distributed Cloud
  • HTTP Load Balancer
  • Service Policy
  • Custom Error Responses

Resolution/Answer

Create a Service Policy for your HTTP LB that denies client IP addresses of your choice. Attach the Service Policy to the LB. Refer to screenshots below and Service Policy documentation.

 

Setup the maintenance page on your LB. Go to HTTP Load Balancer Other Settings -> More Options -> Configure Custom Error Response Options. Refer to screenshot below. Make sure to specify response code 403 so that the intended client IP addresses are served the maintenance page when your previously created Service Policy blocks them. For response body, you can paste plain text or HTML.
