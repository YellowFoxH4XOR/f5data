Description

The BIG-IP ASM Configuration utility allows a security policy attached to a virtual server to be deleted without displaying an attachment-specific warning. The deletion dialog displays only a generic confirmation message:


"Are you sure you want to delete the selected items?"


Environment

- BIG-IP ASM

- Security policy attached to a virtual server

- Policy deletion performed through the BIG-IP GUI

 

Cause

This behavior is documented in ID1028129


Answer/Recommended Actions

Before deleting an ASM security policy:


1. Open the **Security Policies** list.

2. Review the **Virtual Server(s)** column for the policy.

3. Identify any virtual servers associated with the policy.

4. Confirm that policy deletion is intended.

5. Proceed with deletion only after evaluating its effect on the associated virtual servers.


Additional Information

Earlier BIG-IP versions required the policy to be deactivated before deletion and displayed a warning that Application Security would be disabled on associated virtual servers.


In affected versions, the GUI displays only a generic deletion confirmation. The associated virtual servers remain listed in the **Virtual Server(s)** column, which should be checked before deleting the policy.
