Description
Disabling "Enable Signature Staging" in ASM/Adv WAF Security Policy sets Attack Signature to "Enforced" Status

Environment

  • BIG-IP ASM/Adv WAF provisioned
  • Disable Enable Signature Staging in BIG-IP ASM/Adv WAF Security Policy

Cause

None

Recommended Actions

Ensure that you are aware of the behavior of attack signature updates as a result of disabling Enable Signature Staging.

Disabling "Enable Signature Staging" can be done from the Configuration Utility, Security  ››  Application Security : Policy Building : Learning and Blocking Settings, select in the dropdown list the security policy
go to attack signature, check/uncheck the "Enable Signature Staging" option

The Enable Signature Staging in the Security policy, if unchecked/disabled, all attack signatures will be in "Enforced" State unless they are in "Disabled" state.

In the ASM Configuration Utility for version 15.1.x and later,
Security  ››  Application Security : Security Policies : Policies List  ››  <asm_policy_name>

Go to Attack Signatures, review the status column, if Enable Signature Staging is unchecked/disabled in the asm policy, the status should be "Enforced"
An attack signature Status can only be "Enforced" or "Disabled" when selected

If Enable Signature Staging in the Security policy is unchecked/disabled, new and updated attack signatures will be in "Enforced" state

Additional Information

From the Configuration Utility, Security  ››  Application Security : Policy Building : Learning and Blocking Settings, Enable Signature Staging Online Help:

Enable Signature Staging:

Specifies, when checked (enabled), that the staging feature is active, and the system places all newly assigned and newly updated signatures in staging (using the Signatures Update feature). The system does not enforce signatures in staging. Instead, the system records the request information and keeps it for a period of time (the Enforcement Readiness Period whose default time period is 7 days).

Specifies, when cleared (disabled), that the staging feature is not in use, and that the system enforces (Enforced status) the signatures’ Learn/Alarm/Block settings immediately. (Blocking is performed only if the security policy’s enforcement mode is Blocking.)
