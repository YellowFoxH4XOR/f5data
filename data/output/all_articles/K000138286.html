K000138286: After upgrade, missing recent changes.

Description

After upgrade, recent config changes are missing.

 

Environment

  • BIG-IP
  • Upgrade
  • missing configuration
 

Cause

 

  • config change was not saved in to file before the installation.

Or

  • config change was not saved in to file before the installation.
 

Recommended Actions

Possible reasons

1. If you changed config in memory but did not save config before installation (tmsh save sys config), then when it is booted, the config in memory will be lost.

2. Installed and booted day and time is different.

When later version is installed to new boot location or existing boot location, by default it will move config to installed location on that time/day.

NOTE: Please read further details: K13438 : Controlling configuration import when performing software upgrade/installation

In this case, booted without using "Install Configuration" option on a different day from the installation, you may think recent changes lost.
If you boot back from original version config should be intact, use "Install Configuration" option to let it copy over to the newly booting location.
 

Additional Information

You may want to check what had happend in the past with the below log.

  • /var/log/audit*               : to check activity by who.
  • /var/log/liveinstall.log* : to check when it is installed/rebooted from which boot location.
  • /config/.diffVersions/*  : to check which config is changed
  • /var/log/webui.log        : long time ago's boot time.
