Description

  • Getting error when updating existing sys log profile
  • GUI error message
"cannot select remote log facility while remote storage type is not remote."

Environment

  • ASM
  • SYS-log

Cause

  • Original log profile writes log to local syslog. The profile is also used by BOT and DOS, in addition to  ASM policy logs.  
  • Log profile is associated with multiple policies, including BOT and DOS profiles

Recommended Actions

  • Bot and Dos use the same syslog configurations as the rest of the remote logging setup.
  • By default, a publisher in the security logging profile points to a local-syslog destination.
  • We are required to alter the publisher to point to the remote syslog destination.
