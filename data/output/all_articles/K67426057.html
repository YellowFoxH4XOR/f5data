Description

By default, if Client SSL profile is not applied and cookie persistence is applied in a Virtual Server, BIG-IP will not set "secure" attribute for persistence cookie.
If sometimes BIG-IP is behind an SSL offload device, no SSL profile is applied in the Virtual Server, we can apply an iRule to add this attribute.

Environment

  • BIG-IP LTM
  • Cookie persistence profile is applied
  • Without Client SSL profile in the Virtual Server

Cause

If a cookie is set with "secure" attribute, this cookie can only be used in HTTPS site.
For Virtual Server without Client SSL profile, BIG-IP will not set this attribute for persistence cookie.

Recommended Actions

Please follow this article K50565834: How to add an iRule to a Virtual Server, create an iRule like following and attach it to the Virtual Server:

when HTTP_RESPONSE_RELEASE {
    foreach mycookie [HTTP::cookie names] {
      if { $mycookie starts_with "BIGipServer" } {
        HTTP::cookie secure $mycookie enable
     }
   }
}
