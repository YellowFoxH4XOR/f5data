K000162244: BIG-IP ASM BD Process Crash Caused by a Wildcard Parameter with “Ignore Value”

Type
Support Solution
Published
2026-08-13
Updated
2026-08-13
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000162244

Description

A BIG-IP ASM security policy can cause the bd process to crash when a wildcard parameter (*) configured with Ignore Value processes large JSON POST requests. The wildcard may expand against every parsed JSON key, creating excessive runtime list expansion and causing ASM and MCPD communication failures followed by a controlled restart.

Environment

  • BIG-IP LTM, version 17.1.3
  • ASM module 
  • ASM policy containing a wildcard parameter (*) with "Ignore Value" for HTTPS URLs
  • "Illegal parameter" violation not enabled in the policy
  • Large JSON POST requests sent to application endpoints

Cause

The wildcard parameter configured with Ignore Value caused BIG-IP ASM BD to expand the wildcard against every parameter extracted from large JSON POST bodies. The runtime list grew excessively for a single transaction, causing the bd process to crash.

Answer/Recommended Actions

  1. Verify that the Illegal parameter violation remains disabled under the BIG-IP ASM security policy blocking settings.

  2. Remove the wildcard parameter (*) configured with Ignore Value from the HTTPS URL configuration in the affected security policy.

  3. Retain only the explicit parameters required by the application, such as password, username, upload, and __viewstate.

  4. Apply the updated security policy.

  5. Monitor the following after the change:

    • BIG-IP ASM security event logs
    • Blocking events
    • bd process stability
    • ASM and MCPD status
    • Tenant restart or failover events

  6. If legitimate application requests are blocked after the change:

    1. Restore the previous security policy version.
    2. Review the BIG-IP ASM event logs to identify the affected requests and violations.
    3. Confirm that the Illegal parameter violation remains disabled.
    4. Do not reintroduce the wildcard unless the policy requires it and its impact has been evaluated.
