Description

12.1.0 introduced Automatic Thresholds for DOS Vectors. Part of this new functionality is the sys db variable dos.auto.threshold.learnalways.
The variable has True/False (enabled/disabled) values and determines if traffic history should be learned and stored. It also calculates the auto-thresholds, even when in Manual-Threshold mode. It defaults to True (which means the feature is enabled).

Environment

  • Version 12.1.0 or later

Cause

This variable is found on all BIG-IP deployments version 12.1.0 and later, regardless of which modules are or have been provisioned on it.

Recommended Actions

The variable can be safely left at it's default of True with no impact if running modules besides AFM. If running AFM, administrators will want to determine if the feature should be enabled or disabled, depending on what functionality best suits their environment.
