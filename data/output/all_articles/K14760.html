Topic

This article discusses high density Virtual Clustered Multiprocessing (vCMP) on supported hardware platforms.

Description

Beginning in BIG-IP 11.4.1, the BIG-IP vCMP host introduces support for high density vCMP. This feature is available only on supported hardware platforms that are equipped with high-powered CPUs, have a greater amount of memory, and have solid state drives (SSDs), such as the following:

  • VIPRION B2150 blade
  • VIPRION B2250 blade
  • BIG-IP 5250 platform
  • BIG-IP 7250 platform
  • BIG-IP 10250 platform
  • BIG-IP 10350 platform
  • BIG-IP 12250 platform
  • BIG-IP i5800 platform
  • BIG-IP i7800 platform
  • BIG-IP i10800 platform
  • BIG-IP i11800 platform
  • BIG-IP i15800 platform

With high density vCMP, you can configure more vCMP guests on a blade by provisioning one vCPU for a vCMP guest. For example, you can configure a maximum of eight single vCPU guests on a B2150 blade, compared to a maximum of four dual vCPU guests on a B2100 blade. To provision one vCPU for a vCMP guest, you must select 1 for both the Cores Per Slot setting and Number of Slots setting when you configure the vCMP guest.

Note: For information about the maximum number of vCMP guests you can configure on these blades, refer to K14218: vCMP guest memory/CPU core allocation matrix.

Recommendations

When you make plans for high density vCMP, you should consider the following factors:

  • The single-core vCPU guest is limited in provisioning the number of software modules, and only supports the following products or product combinations:
    • LTM standalone
    • GTM standalone
    • LTM and GTM combination
  • The vCMP host allocates a limited amount of memory to each guest using the following formula:

    (total_GB_memory_per_blade - 3 GB) x (cores_per_slot_per_guest / total_cores_per_blade)

    For a single vCPU guest on a VIPRION B2150 blade with eight vCPUs and 32 GB memory, the provisioned memory for the guest is approximately 3.6 GB. As a result, the single vCPU guest can support provisioning on only the LTM software module or the LTM and GTM software module combination.
