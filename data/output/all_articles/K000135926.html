Source

Description

  • This document explain how to disable QKView upload to ihealth from config utility

Environment

  • BIG-IP Config utility
  • Ver 16

Cause

Default setting is enable to upload to ihealth

 Recommended Actions

 

You can change to disable by this command

tmsh

modify sys diags ihealth no-ihealth true

 

===

root@(gallery-big-ip-16-1-3-4)(cfg-sync Standalone)(TimeLimitedModules::Active)(/Common)(tmos)# modify sys diags ihealth no-ihealth true

 

root@(gallery-big-ip-16-1-3-4)(cfg-sync Standalone)(TimeLimitedModules::Active)(/Common)(tmos)#

 From GUI

You can see

System  ››  Support  ››  Support

Support Snapshot

Health Utility

  • Generate and Upload QKView to ihealth <=== Then change to gray ( Can't select)
  • Generate QKView
  • Generate TCPdump

 

 

 

root@(gallery-big-ip-16-1-3-3)(cfg-sync Standalone)(/Common)(tmos)# list sys diags ihealth

sys diags ihealth {

expiration 30

no-ihealth true <== After change

options none

password none

user none

}
