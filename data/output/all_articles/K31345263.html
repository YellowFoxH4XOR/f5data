Description

How to configure and verify sysName configuration on VELOS system controller.

Note: In F5OS versions F5OS-C 1.6.0, F5OS-A 1.7.0 and later, the hostname that you configure for the F5OS system is automatically reflected in SNMP and the below procedure is not required. For more information, refer to Bug ID 1190321: F5OS - "system config hostname" change not reflected in SNMP MIB.

Environment

  • F5OS
  • SNMPv2-MIB sysName configuration

Cause

The command 'show SNMPv2-MIB' in user (operational) mode will not show sysName by default:

syscon-1-active# show SNMPv2-MIB

SNMPv2-MIB system sysDescr "Tail-f ConfD agent"
SNMPv2-MIB system sysObjectID 1.3.6.1.4.1.24961
SNMPv2-MIB system sysUpTime 185658779
SNMPv2-MIB system sysServices 72
SNMPv2-MIB system sysORLastChange 0
SNMPv2-MIB snmp snmpInPkts 0
SNMPv2-MIB snmp snmpInBadVersions 0
SNMPv2-MIB snmp snmpInBadCommunityNames 0
SNMPv2-MIB snmp snmpInBadCommunityUses 0
SNMPv2-MIB snmp snmpInASNParseErrs 0
SNMPv2-MIB snmp snmpSilentDrops 0
SNMPv2-MIB snmp snmpProxyDrops 0
SNMPv2-MIB snmpSet snmpSetSerialNo 58299900

Recommended Actions

1. Log in to the command line interface (CLI) of the system controller using an account with admin access.
When you log in to the system, you are in user (operational) mode.

2. Change to config mode.
config

The CLI prompt changes to include (config)

3. Configure "Example" as SNMPv2-MIB system sysName 
(config)# SNMPv2-MIB system sysName Example

4. Commit the configuration changes.
(config)# commit

5. Verify the configuration in config mode.
(config)# show full-configuration SNMPv2-MIB
SNMPv2-MIB system sysName Example

6. Leave config mode.
(config)# exit

7. Verify the configuration in user (operational) mode.
show running-config
...
...
SNMPv2-MIB system sysName Example
