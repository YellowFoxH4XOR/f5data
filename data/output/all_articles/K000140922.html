Description

rmonsnmpd servivce does not exist on BIG-IP.

Environment

BIG-IP version 13.0.0 later

Cause

rmonsnmpd package is not installed.

Recommended Actions

If you do not use RMON-MIB, rmonsnmpd service is not necessary.

If you use RMON-MIN, Partial loss of SNMP functionality occurs.

You can install the rmonsnmpd rpm package.

To install the rmonsnmpd rpm package, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP system
  2. Create mount point
    # mkdir /shared/tmp/iso
  3. Mount the F5 BIG-IP image which is installed
    Note: If the installed F5 BIG-IP image does not exist under /shared/images directory, download the F5 BIG-IP image to /shared/images directory.
    # mount -O loop /shared/images/<the F5 BIG-IP image file name> /shared/tmp/iso
     for example, the F5 BIG-IP image name is BIGIP-17.1.0.2-0.0.2.iso, perform the following,
    # mount -O loop /shared/images/BIGIP-17.1.0.2-0.0.2.iso /shared/tmp/iso
  4. Install rmonsnmp rpm package
    for example, the F5 BIG-IP image name is BIGIP-17.1.0.2-0.0.2.iso, perform the following:
    # cd /shared/tmp/iso/BIGIP17102/x86_64
    # rpm -i rmonsnmpd-17.1.0.2-0.0.2.x86_64.rpm
  5. Unmount the F5 BIG-IP images
    # umount /shared/tmp/iso
  6. To start rmonsnmpd service, restart snmpd service
    # bigstart restart snmpd

To confirm rmonsnmpd service is running, perform the following procedure:

# tmsh show sys service rmonsnmpd

rmonsnmpd       run (pid 3603) 4 minutes, 1 start
