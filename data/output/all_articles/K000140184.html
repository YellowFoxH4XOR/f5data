K000140184: All pools are down after an upgrade.

Type
Support Solution
Published
2024-06-28
Updated
2024-06-28
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000140184

Description

All pools are in an unknown state after an upgrade. When running tcpdump you can see that the BIGIP is not sending any health checks to servers.

Environment

Upgrade

Pools are down

Cause

Pools stay in an unknown state after the upgrade of the BIGIP device that was forced offline.

Recommended Actions

Release offline so that the BIGIP can start sending monitor traffic to pool members.

https://my.f5.com/manage/s/article/K15122
