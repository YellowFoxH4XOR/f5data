Known Issue

The Traffic Management Microkernel (TMM) may produce a core file and restart when processing a Secure Sockets Layer (SSL) handshake cancellation.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is running 11.5.4 HF3.
  • Your BIG-IP virtual server is configured with a Client or Server SSL profile.
  • An SSL connection to the virtual server sends a handshake cancellation during the SSL handshake.

Impact

The BIG-IP system temporarily fails to process traffic while the TMM process restarts. If the BIG-IP system is configured for high availability (HA), the system fails over to a peer system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM generates a core file in the /shared/core directory.
  • Your BIG-IP system logs a SIGSEGV to the /var/log/tmm file at the same time TMM produces a core file and restarts.
