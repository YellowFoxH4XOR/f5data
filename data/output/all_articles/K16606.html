Known Issue

Re-deploying an iApp template may cause mcpd to repeatedly restart on secondary blades.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system runs on a platform configured with one or more secondary blades.
  • You re-deploy an iApp template to a system with the same SSL cert/key/chain files that were locally cached from the previous deployment.

Impact

The mcpd process on the secondary blades restarts and traffic may be interrupted. If the affected system is configured with a high-availability (HA) redundancy, the system may fail over.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The mcpd process repeatedly restarts on all secondary blades with validation errors similar to the following example:

    Client SSL profile must have RSA certificate/key pair.
