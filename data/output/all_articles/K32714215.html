K32714215: API Authentication resets all connections on pre-iSeries hardware

Type
Support Solution
Published
2019-10-11
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 14.1.2
Source
https://my.f5.com/manage/s/article/K32714215

Description

  • API protection is only supported on iSeries and newer hardware or BIG-IP Virtual Editions.
  • Attempting to use API protection on older hardware will result in socket resets on all connections.

Environment

  • Pre-iSeries hardware
  • API protection
  • BIG-IP Access Policy Manager (APM)

Cause

API protection is not supported on Pre-iSeries hardware.

Recommended Actions

If API protection is required, use newer hardware.
