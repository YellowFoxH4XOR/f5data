Description

Environment

  • VELOS or rSeries
  • Advanced Routing or Routing bundle licensed via addon key

Cause

This is a cosmetic issue tracked by ID2291233, due to duplicate entries in the license file.

Recommended Actions

No action is required, as the issue is cosmetic.

Reactivating the license should remove the duplicate entries.
