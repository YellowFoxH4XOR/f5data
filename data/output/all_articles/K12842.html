Known Issue

ARX VE (Virtual Edition) allows you to specify a remote logging destination using the following command syntax:

logging destination <remote_logging_server_IP>

However, by default, the ARX system attempts to use a non-existent, out-of-band (OOB) management interface to communicate with the remote logging server. As a result, the ARX system has no source interface defined and is unable to send messages to the specified remote logging destination.

Additionally, the system disables the management source command for ARX VE because there is no OOB management interface. Therefore, you cannot use the management source command to define an alternate source interface for the system to use for the remote logging destination.

Impact

The ARX VE system is unable to send messages to a remote logging system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You are unable to send messages to the remote logging system.
  • The show logging destination command indicates that you still need to configure the Source Interface. The output of the show logging destination command appears similar to the following example:

    Source Interface:   No source IP defined.  Remote logging may not occur.


    External Syslog Destination(s)
    ------------------------------
    192.168.10.20
