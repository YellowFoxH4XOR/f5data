K000092980: Retrieve the qps on a BIG-IP GTM / DNS system

Type
Support Solution
Published
2022-12-05
Updated
2025-02-27
Source
https://my.f5.com/manage/s/article/K000092980

Description

Retrieve the DNS queries , responses , responses per second per DNS profile / per listener via the Configuration Utility, tmctl commands and SNMP

Environment

  • BIG-IP GTM / DNS

Cause

None

Recommended Actions

1 . Configuration Utility ( GUI )

In order to retrieve the DNS queries , responses , responses per second per DNS profile / per listener from the GUI ( Configuration Utility )

 

Navigate to: Statistics ›› Module Statistics : DNS : Delivery

From the "Statistics Type" select "Listeners"

Select the listener in question, then select the "Statistics" tab and on the "Profiles" section and under "Select Profile" drop down select the DNS profile in question.

 

2 . TMCTL command

The following tmctl command shows the statistics ( queries , responses , rps ) per DNS profile / per listener.

 

tmctl profile_dns_stat -s name,vs_name,queries,responses,rps

 

Example output from a lab system:

 

  [root@GTM-A:Active:Standalone] config # tmctl profile_dns_stat -s name,vs_name,queries,responses,rps

  name            vs_name                 queries

  -------------------------- --------------------------------------- -------

  /Common/custom_dns_profile /Common/GTM-A_Listener_TCP_192.168.1.13    0

  /Common/custom_dns_profile /Common/GTM-A_Listener_UDP_192.168.1.13   1720

  /Common/custom_dns_profile _listener                   0

  /Common/dns        _listener                   0

  dns            _listener                   0

  

  responses rps

  --------- ---

      0  0

     1709 106

      0  0

      0  0

      0  0

  ----------------

 

  The previous output can be translated as below:

 

  The DNS profile under name "custom_dns_profile" is applied on virtual server under name: "GTM-A_Listener_UDP_192.168.1.13" and this DNS profile / listener have received a total of 1720 queries has sent 1709 responses and the current requests per second ( rps ) are 106

  

 

3 . SNMP

 

  snmpwalk -v2c -c public localhost ltmDnsProfileStatQueries

 Shows the total requests of the respective DNS profile

  

  snmpwalk -v2c -c public localhost ltmDnsProfileStatResponses

Shows the total responses of the respective DNS profile

  

  snmpwalk -v2c -c public localhost ltmDnsProfileStatResponsesPerSec

Shows the responses per second.

 

Example output from a lab system:

 

  [root@GTM-A:Active:Standalone] config # snmpwalk -v2c -c public localhost ltmDnsProfileStatQueries

 

  F5-BIGIP-LOCAL-MIB::ltmDnsProfileStatQueries."/Common/custom_dns_profile" = Counter64: 1720

  

  [root@GTM-A:Active:Standalone] config # snmpwalk -v2c -c public localhost ltmDnsProfileStatResponses

  

  F5-BIGIP-LOCAL-MIB::ltmDnsProfileStatResponses."/Common/custom_dns_profile" = Counter64: 1709

  

  [root@GTM-A:Active:Standalone] config # snmpwalk -v2c -c public localhost ltmDnsProfileStatResponsesPerSec

 

  F5-BIGIP-LOCAL-MIB::ltmDnsProfileStatResponsesPerSec."/Common/custom_dns_profile" = Counter64: 106
