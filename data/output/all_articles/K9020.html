K9020: SSL private keys for Web Management, Enterprise Manager, and iQuery cannot be stored on FIPS

Topic

The BIG-IP system supports a FIPS hardware security module (HSM). The module stores private keys used by SSL profiles to process SSL traffic.

However, the private keys used to encrypt Web Management, Enterprise Manager, and iQuery access cannot be stored in the HSM. The digital certificates and keys used for this communication must be accessible to processes outside of Traffic Management Microkernel (TMM). Processes outside of TMM do not have access to information stored on the HSM.

In BIG-IP LTM versions prior to 9.4, the Web Management interface incorrectly provided the Convert to FIPS option for the Web Management, Enterprise Manager, and iQuery SSL keys. The conversion of these keys failed. The Convert to FIPS option for these SSL keys was removed from the Web Management GUI.

F5 Product Development tracked this change as CR66272, and it was changed in BIG-IP version 9.4.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, and WebAccelerator release notes.
