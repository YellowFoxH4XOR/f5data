Description


Synchronizing Active config to Standby device fails with two mcpd error logs on Standby:


01071a35:3: Security log profiles '/Common/Log illegal requests' and '/Common/Log Only illegal Requests' cannot be associated simultaneously with a virtual server '/Common/<vs-name>', since they both have local logging enabled.


01071488:3: Remote transaction for device group /Common/Sync-Failover to commit id 19 7451964590946262049 /Common/<device> 0 failed with error 01020057:3: The string with more than 65535 characters cannot be stored in a message..


 

Environment


BIG-IP with High Availability


Cause


Changes on Standby that Active didn't know about. Incremental syncs can't take care of the condition because Active doesn't tell Standby to delete the existing profile.


Recommended Actions


Delete all security-log-profiles from the Standby Virtual Servers.


# tmsh modify ltm virtual all security-log-profiles none


Sync Active to Standby.


(tmos)# run cm config-sync to-group Sync-Failover force-full-load-push


Verify that the Virtual Server configs are the same on both devices, once the device group is in sync.
