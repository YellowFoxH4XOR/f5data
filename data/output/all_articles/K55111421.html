Description

Login fails after TACACS configuration.

Log message similar to the following observed in /var/log/ltm for local user auth failure:

01071a55:4: The system auth source type (local) does not support fallback to local auth

Environment

  • Remote Authentication
  • TACACS

Cause

Bug ID398683 [TACACS+ secret with a '#' character breaks remote auth].

Recommended Actions

Do not use the # character in the TACACS secret.

Additional Information

The bug is fixed in version 16.0.1.1, 16.1.0, 15.1.9
