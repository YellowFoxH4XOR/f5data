Topic

To pass Windows domain authentication traffic through the BIG-IP, you must configure a forwarding virtual server or enable IP forwarding. NATs, SNATs, and normal virtual servers will make modifications to the packets that cause domain authentication to fail.
 
Note: For more information about configuring a forwarding virtual server, refer to the BIG-IP Reference Guide.
