Issue

Error Message

Error Message: Cumulative log rate exceeded! Throttling all non-debug logs

For example:

00020000:6: Cumulative log rate exceeded! Throttling all non-debug logs.
00020000:6: Re-enabling general logging; held 22 messages.

Note: The second log message occurs after logging has been restored.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when a single BIG-IP module produces more than 20 log messages over a period of two seconds and throttles further log messages as a result.

  • For example:

    01010029:5: Clock advanced by 2500 ticks
    00020000:6: Cumulative log rate exceeded! Throttling all non-debug logs.
    00020000:6: Re-enabling general logging; held 17 messages.

Impact

The BIG-IP system does not log further messages from the module until the amount of logging produced falls back below the threshold. This throttling mechanism is designed to protect the BIG-IP system from an increased amount of disk write operations that may have otherwise impacted the system due to the increased amount of logging.

Recommended Actions

To limit the impact of these messages, refer to the following articles:

  • Do not leave debug logging enabled for an extended periods of time:

    K15530: Debug logging and BIG-IP system resource utilization

    K5532: Configuring the level of information logged for TMM-specific events

  • Prevent the BIG-IP system from reaching the maximum processing capacity:

    K16419: Overview of BIG-IP memory usage

    K15740: Overview of adaptive connection reaping (11.6.0 and later)

  • Confirm that iRules are not configured to log connection information, such as HTTP headers too verbosely.
