Known Issue

This is the result of a known issue. If you delete a non-existent network time protocol (NTP) server using the bigpipe ntp servers <IP> delete command, that server is added as an NTP server. For example:

root@B3410:Active] config # bigpipe ntp servers
NTP - NTP Servers: none
[root@B3410:Active] config # bigpipe ntp servers 10.0.0.1 delete
[root@B3410:Active] config # bigpipe ntp servers
NTP - NTP Servers:
10.0.0.1
[root@B3410:Active] config #

F5 Product Development tracked this issue as ID 248342 (formerly CR85137), and it is fixed in BIG-IP 10.2.1.

Workaround

To prevent this issue from occurring, run the bigpipe ntp servers command before and after you delete an NTP server using bigpipe to ensure that the correct NTP server is deleted.
