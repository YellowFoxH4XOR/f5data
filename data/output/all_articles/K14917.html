Known Issue

Client systems that disconnect from BIG-IP APM network access may lose network connectivity.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with the network access feature.
  • The network access Force all traffic through tunnel setting is enabled in Network Settings.
  • The client system's gateway IP address resides in a different network than the interface IP address.

Impact

After disconnecting from BIG-IP APM network access, you cannot locate the gateway IP address route on the client system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The client system cannot connect to network resources after disconnecting from BIG-IP APM network access.
  • You must restore the previously configured gateway IP address because it no longer appears in the route table.

Workaround

While there is no workaround in the BIG-IP APM system for this issue, you may be able to restore the gateway and client connectivity by disabling and re-enabling the client network ethernet adapter.
