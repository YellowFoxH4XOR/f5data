Known Issue

The monpd process can produce a core file on VIPRION systems, when the primary blade is unable to produce a report using BIG-IP Analytics (AVR).

This issue occurs when all of the following conditions are met:

  • Your VIPRION system uses multiple blades.
  • The primary blade has a corrupted MySQL database.
  • An AVR query is executed from the Configuration utility.

Impact

Users cannot view AVR data, and the monpd process restart does not impact traffic processing.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • AVR does not produce any data from the Configuration utility.
  • The monpd process restarts and creates a core file in the /var/core directory.
