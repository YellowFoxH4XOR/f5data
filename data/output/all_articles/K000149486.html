K000149486: Hebrew language is not supported in Edge Client

Type
Support Solution
Published
2025-03-06
Updated
2025-03-06
Applies to
  • BIG-IP
  • APM Clients
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000149486

Description

When attempting to establish a VPN connection using the BIG-IP Edge Client on Windows, users with Hebrew usernames (written in the SI-1452 keyboard standard) encounter an "Unknown RAS Error" and are unable to connect. The issue is observed when the Windows local profile or Active Directory username contains Hebrew characters. Logs may show errors such as:

RasSetEntryProperties returned 123 (0x7b)

The connection works without issues when:

  • The username is written in English.
  • The program is run under a different identity where the home folder is written in English.

Environment

  • Edge Client for Windows
  • Username containing Hebrew characters.

Cause

The current implementation of the Edge Client does not support the Hebrew language.

  1. The RasSetEntryProperties function fails with an error code 123 (0x7b) when processing input parameters that include Hebrew characters.
  2. This results in invalid entries not being found in RAS profiles, causing VPN connection failures.

A Request for Enhancement (RFE ID: 1788821) has been created internally to address this limitation by adding support for Hebrew characters within Network Access functionality. Monitor future release notes or bug tracker updates for progress on this enhancement.

    Recommended Actions

    Use an English alphabet username for both local and cloud-hosted accounts when connecting via VPN. If possible, create a new user profile with an English name and ensure its home folder path does not contain Hebrew characters.
