Known Issue

Running tmsh show commands causes the mcpd process to leak memory.

This issue occurs when the following condition is met:

  • You periodically run tmsh show commands.

Impact

 The mcpd process leaks memory, which may cause the mcpd process to restart.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe that mcpd process memory usage increases.
  • When the mcpd process restarts, it affects traffic and a failover occurs.
