Topic

After installing the BIG-IP system in your network, the servers residing behind the BIG-IP system may attempt to perform a DNS reverse name lookup on client IP addresses. If the servers do not have DNS configured, or if the servers were previously configured to use an external DNS server and DNS traffic management has not been configured on the BIG-IP system, the servers will not be able to perform the DNS lookup. If a server must wait for a DNS request to time out, the client making the request will experience extreme latency.

You can avoid this issue by configuring the DNS resolver on the servers to use a local DNS server. Alternatively, if the nodes need to reach an external DNS server, you can create a default SNAT or a DNS virtual server on the BIG-IP system.
