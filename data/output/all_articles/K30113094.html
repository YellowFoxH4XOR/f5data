Description

When loading configuration from a previous version of BIG-IP (upgrade, restore), from the command line an error message similar to the following is generated:
01020036:3: The requested parent profile (/Common/wam-tcp-wan-optimized) was not found

Note: When using the Configuration utility (GUI) an error banner may that the configuration failed to load.

Environment

  • Upgrade or restore a configuration from BIG-IP version 15.x
  • The configuration references either of the following profiles wam-tcp-wan-optimized and/or wam-tcp-lan-optimized.

Cause

Bug ID 941961
BIG-IP 16.x finished the decommissioning of the web optimization (acceleration) module.  However, some parent profiles still carry the prefix 'wam' in their title and are missing from version 16.x base profiles.

Recommended Actions

Perform either one of the following methods:

  • Use your preferred text editor to edit /config/bigip.conf and replace references to wam-tcp-wan-optimized with tcp-wan-optimized.
  • You can use the following commands to make the edits directly to the file without a text editor:
    sed -i 's/wam-tcp-lan-optimized/tcp-lan-optimized/g' /config/bigip.conf
    sed -i 's/wam-tcp-wan-optimized/tcp-wan-optimized/g' /config/bigip.conf
    Note: The above commands will replace all instances of "wam-tcp-lan-optimized" with "tcp-lan-optimized" (same for wan) in the /config/bigip.conf file. 
  • Alternatively, include a copy of the definition of wam-tcp-wan-optimized from /defaults/wam_base.conf into /config/bigip.conf.

After performing one of the previous methods, load the configuration with the following command:

tmsh load sys config
