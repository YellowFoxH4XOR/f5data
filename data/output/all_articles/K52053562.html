Description

vCMP guest can not be created even there is enough resources. 
/var/log/ltm contains below logs when it fails,

crit vcmpd[<PID>]: 01510003:2: Guest (<guest_name>):  Install failed.
err vcmpd[<PID>]: 01510004:3: Guest (<guest_name>): Failure - VDisk install process failed.
err vcmpd[<PID>]: 01510004:3: Guest (<guest_name>): Install to VDisk /shared/vmdisks/<guest_name>.img FAILED: Child exited with non-zero exit code: 255
 

Environment

  • vCMP
  • v12.1.0-14.0.* (except 12.1.5 and 13.1.1.2 and above)
     

Cause

Bug ID 707509
 

Recommended Actions

Upgrade system to fixed versions.
