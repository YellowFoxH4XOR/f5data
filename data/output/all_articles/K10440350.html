Description

You are trying to use the command line to find out all the BIG-IPs that have been imported into the BIG-IQ.

Environment
  • BIG-IQ
  • CLI
  • Imported BIG-IP
Cause

None

Recommended Actions

To list the BIG-IPs that are currently imported, being managed by the BIG-IQ, run the following command from the BIG-IQ command line:

restcurl -u <admin user>:<admin user password> /mgmt/shared/resolver/device-groups/cm-adccore-allbigipDevices/devices/

None
