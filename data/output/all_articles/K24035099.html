Topic

You should consider using these procedures under the following condition:

  • You want to export the BIG-IQ alert history using the BIG-IQ user interface or the iControl REST API.

Description

The BIG-IQ system can alert its administrators about various device conditions such as device availability and disk usage. The alerts apply to the BIG-IQ Centralized Management system itself, Data Collection Devices (DCDs), and managed devices. The procedures in this article walk you through exporting the alert history using the BIG-IQ user interface or using the iControl REST API.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have administrative access to the BIG-IQ user interface or iControl REST API.
  • If using the iControl REST API, you have access to a workstation with a RESTful client you can use to access the API.

Procedures

  • Use the BIG-IQ user interface to export alert history
  • Use the iControl REST API to export alert history

Use the BIG-IQ user interface to export alert history

From the BIG-IQ user interface, you can export alerts in the CSV format individually or in a group. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ user interface.
  2. To display the Alerts page, go to Monitoring > ALERTS & NOTIFICATIONS.
  3. In the Availability list, select alerts to display.
  4. In the Type list, select the alert type to display.
  5. Choose one of the following options:
    • Select the check box next to an alert to include it in the export.
    • Select all alerts by selecting the check box in the header row of the table.
  6. Select Export.
  7. In the pop-up window, select the option to save the CSV file to your workstation.

    Note: The file is named alerts_<UTC date and time in ISO 8601 format>.csv. For example: alerts_2021-08-25T22 30 41.948Z.csv.

Use the iControl REST API to export alert history

You can retrieve alerts using the iControl REST API and process the JSON output into a format of your choosing. The following procedure describes how to use the curl utility to get the data; however, you can access the same URL endpoints shown to obtain the authorization token and retrieve the alerts with any RESTful client.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system that has the curl utility and optionally, the jq utility installed.
  2. Obtain a BIG-IQ authentication token. For more information, refer to K04452074: Overview of using the BIG-IQ system authentication token.
  3. Create a shell variable named f5token to store the BIG-IQ ACCESS type authentication token by using the following syntax:

    f5token=<BIG-IQ authentication token obtained in step 2>

    Note: The authentication token has a timeout of 300 seconds, so you may need to repeat the previous two steps during the procedure.

    Note: Alternatively, if you have the jq utility installed on the client system, you can use command substitution to assign the f5token variable. For example:

    f5token=$(curl -ks -X POST -d '{"username":"admin", "password":"admin"}' https://192.0.2.210/mgmt/shared/authn/login|jq .token.token)

  4. To display all alerts, use the following curl utility syntax to access the /mgmt/cm/shared/event/alerts endpoint:

    Note: The pipe to jq (| jq .) at the end of the command is optional.

    curl -ks -H "X-F5-Auth-Token: $f5token" https://<BIG-IQ IP address>/mgmt/cm/shared/event/alerts [| jq .]

    For example:

    curl -ks -H "X-F5-Auth-Token: $f5token" https://192.0.2.210/mgmt/cm/shared/event/alerts | jq .

  5. Process the JSON output into a format of your choosing.
