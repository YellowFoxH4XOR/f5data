Known Issue

This is the result of a known issue. Beginning in BIG-IP 10.2.0, 4096 bit keys are supported. However, if you configure a Server SSL profile to use a 4096 bit SSL key, the SSL handshake with the server will fail silently.

F5 Product Development tracked this issue as ID 225448 (formerly CR139406), and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Note: Beginning in BIG-IP 10.2.0, it is possible to configure the Client SSL profile to use a 4096 bit SSL key. For more information about supported key sizes, refer to K10580: Maximum supported key size for BIG-IP Client SSL and Server SSL profiles.

Workaround

To work around this issue, you can use a key that is 2048 bits or smaller when configuring the BIG-IP Server SSL profile.
