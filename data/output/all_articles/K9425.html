Known Issue

This is the result of a known issue. Adobe Reader 9.0 fails to open if the user has entered Protected Workspace. This issue appears to be pervasive in the Japanese versions of Windows 2000 Server with SP4, and Windows XP Professional with SP2 or SP3; other platforms may also be affected.

Note: Adobe Reader is a PDF file reader. For more information, refer to http://www.adobe.com.

F5 Networks Product Development tracked this issue as CR111311 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue has been fixed in cumulative hotfix HF-602-10 issued for FirePass version 6.0.2 and cumulative hotfix HF-603-3 issued for FirePass version 6.0.3. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

Users can work around this issue by running an earlier version of Adobe Reader, such as Adobe Reader 8.
