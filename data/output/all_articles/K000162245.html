K000162245: SNMP IF-MIB ifAlias and IP-MIB ipAddress OIDs Unavailable on F5OS-C 2.0.0 System Controller

Type
Support Solution
Published
2026-07-14
Updated
2026-07-14
Applies to
  • F5OS Products
  • F5OS: 2.0.0
Source
https://my.f5.com/manage/s/article/K000162245

Description

  • On F5OS-C 2.0.0 (VELOS), SNMP queries to the system controller do not return IF-MIB ifAlias and IP-MIB ipAddress OIDs. 
  • Error messages observed include "IF-MIB::ifAlias = No Such Instance currently exists at this OID" and "IP-MIB::ipAddressTable = No Such Object available on this agent at this OID".
  • SNMP queries to the partition SNMP agent return ifAlias entries as expected. 

Environment

  • F5OS-C 2.0.0 (VELOS platform)
  • F5-VEL-LTM-CX410-AC, F101 hardware
  • SNMP monitoring of IF-MIB OIDs (ifAlias, ipAddress) required for deployment

Cause

The root cause is that the F5OS-C system controller SNMP agent does not support ifAlias because interface descriptions are not configurable at the controller level. The ifAlias fix for Bug 1497385 was implemented only at the partition SNMP agent level, not at the system controller level, due to this technical limitation.

Answer/Recommended Actions

Use the partition SNMP agent to access ifAlias and ipAddress OIDs on F5OS-C 2.0.0.
