Known Issue

New connections are dropped after modifying the TCP profile's Verified Accept setting.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration includes a virtual server with an associated TCP profile.
  • You modify the TCP profile's Verified Accept setting while the virtual server is processing TCP connections.

Impact

All new TCP connections will be dropped by the virtual server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • New client TCP connections to a single virtual server are unexpectedly failing.

Workaround

There is no workaround. Avoid modifying the TCP profile's Verified Accept setting while processing traffic. To recover from this condition, you can perform the following procedure:

Impact of procedure: Performing the following procedure will cause all traffic processing to stop while the system is rebooted.

  1. Log in to the command line of the affected BIG-IP system.
  2. To reboot the system, type the following command:

    reboot
  3. Optional: For VIPRION systems only, to reboot all blades, type the following command:

    clsh reboot
