Description

Trying to import Qualys Web Application Scanning xml export into ASM. Import Error Message similar to the following:

 

Vulnerabilities file doesn't contain Vulnerabilities Found and Verified by Qualys

Environment

  • QualysGuard
  • BIG-IP ASM
  • Vulnerability assessment template for ASM

Cause

None

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. In QualysGuard choose the WAS module.
  2.  Go to the Web Applications tab.
  3. Pick the relevant web application, and from the Actions menu click "View Report".
  4. Click the Download button.
  5. Choose the XML format and click Save.
    Note:  The downloaded XML report should start with "WAS_WEBAPP_REPORT" and have no issues when importing to ASM.
  6. Import into ASM
