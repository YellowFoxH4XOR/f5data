What Happened?

When a Header value matches a pattern (that is in the middle of the header) you want the request to be sent to a defined Origin Pool.

Environment

  • F5®Distributed Cloud
  • Origin Pool

Answer

Yes, it is possible.

 

Additional Information

You have to be sure that the regex is correct. For example, you want to match this pattern x-im-a-duck=1 will be redirected to a specific origin server. You have to use this pattern:

(?i).*x-im-a-duck=1.*

  • (?i): This is a flag that makes the regex case-insensitive. It means the pattern will match letters regardless of whether they are in uppercase or lowercase.
  • .*: This matches any character (except for line terminators) zero or more times. The dot . matches any character, and the asterisk * signifies "zero or more times".
  • x-im-a-duck=1: This is the specific string that the regex is designed to find.
  • .* (again): This, as before, matches any character zero or more times following the specific string.
