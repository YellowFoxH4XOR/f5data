K65109405: DNS topology region changes not reflected in LB decision

Type
Support Solution
Published
2020-05-13
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP DNS: 14.1.2
Source
https://my.f5.com/manage/s/article/K65109405

Description

DNS topology LB mis-behavior after change the region configuration. When you test the query, the response may not be stable to reflect to the new configuration.

Environment

  • You are using topology for DNS LB.
  • You just changed region, remove or add subnet to it.

Cause

Issue may be caused by ID864797.

Recommended Actions

  1.  Query the object from another source ip.

Additional Information

None.
