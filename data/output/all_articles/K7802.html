Known Issue

This is the result of a known issue. If a user attempts to access an Adobe Presentation through a Portal Access Web Application Favorite, the presentation may fail to load. This issue is caused by the manner in which the Portal Access reverse proxy engine processes the components.swf file, which users may be prompted to download in order to view the presentation.

F5 FirePass Development tracked this issue as CR79891 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Additionally, cumulative hotfix HF-600-15 has been issued for FirePass version 6.0.0 and cumulative hotfix HF-601-4 has been issued for FirePass version 6.0.1. You may download these hotfixes or later versions of these cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
