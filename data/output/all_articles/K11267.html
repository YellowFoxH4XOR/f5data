Topic

This article applies to BIG-IP 10.x. For information about other versions, refer to the following articles:

  • K13438: Controlling configuration import when performing software installations (11.x - 12.x)

Beginning in BIG-IP 10.0.0, you can install software using the Software Management section of the Configuration utility, or the bigpipe command, or the image2disk utility. These installation methods allow you to image an inactive boot location with a BIG-IP 10.x release or hotfix. Additionally, beginning in BIG-IP 10.1.0, you can install software using the Traffic Management Shell (tmsh) utility.

When you perform an installation using any of the described methods, by default, the BIG-IP system installs the configuration of the currently-active boot location on the target boot location.

Note: The behavior described in this article does not apply to software installations performed in the Maintenance Operating System (MOS) environment.

It is generally desirable for the BIG-IP system to run the same configuration on all its boot locations. However, there may be cases (for example in a test environment) in which you want to run a different configuration on each boot location.

You can control whether the BIG-IP system should import any configuration during an installation by adjusting the value of the following bigpipe database keys:

Database keyDefault valuePossible valuesDescription
LiveInstall.MoveConfigenableenable
disable		Specifies whether to install the saved configuration on the target boot location.
LiveInstall.SaveConfigenableenable
disable		Specifies whether to save the existing configuration before installing.

The following table explains all possible configurations:

ConfigurationBehaviorNotes
LiveInstall.MoveConfig = enable LiveInstall.SaveConfig = enableThe configuration of the currently-active boot location is installed on the target boot location. This is the default behavior.This is the equivalent of performing an installation using the image2disk utility invoked without either the --nosaveconfig or --nomoveconfig option.
LiveInstall.MoveConfig = disable
LiveInstall.SaveConfig = enable		The configuration of the target boot location (if any is present) is re-installed on the target boot location after re-imaging is complete.This is the equivalent of performing an installation using the image2disk utility invoked with the --nomoveconfig option.
LiveInstall.MoveConfig = enable
LiveInstall.SaveConfig = disable		No configuration is installed on the target boot location.This is the equivalent of performing an installation using the image2disk utility invoked with the --nosaveconfig option.
LiveInstall.MoveConfig = disable
LiveInstall.SaveConfig = disable		No configuration is installed on the target boot location.This is the equivalent of performing an installation using the image2disk utility invoked with both the --nosaveconfig and --nomoveconfig options.

To change the value of a bigpipe database key, enter the following command at the BIG-IP system command line:

bigpipe db <key> <value>

For example:

bigpipe db LiveInstall.MoveConfig disable

After you have modified the bigpipe database keys according to your needs, enter the bigpipe save command to save the configuration.
