K000147469: Why I am getting an HTTP 400 error when a "Trusted Client" is getting blocked?

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Multi-Cloud Network Connect
Source
https://my.f5.com/manage/s/article/K000147469

Description

You have a Client IP on a "Trusted Clients" list but it is getting blocked with an HTTP 400 error.

Environment

  • F5® Distributed Cloud
  • Service Policy 

Cause

This can happen when HTTP 429 or any other response code is configured as a "disallowed" response code in AppFirewall.

Resolution/Answer

WAF replaces the original response coming from the upstream with HTTP 400 which you configured in the service policy as blocking response code and generated a WAF security event with the action "block".

The Original response code will still appear in the WAF security event.
