Known Issue

BIG-IP APM Network Access connections may intermittently fail to establish.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with a Network Access profile.
  • The BIG-IP APM system processes several Network Access PPP tunnel reconnections.

Impact

The BIG-IP system fails to establish a network access tunnel.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system logs messages to the /var/log/apm file that appear similar to the following example:

    <device name> notice tmm[<pid>]: 01490505:5: 81cb84a5: Dynamic IPv4 Addr collision: Old: tmm.uuid./<partition_name>/<network_access_name>.ram ac4226f83e4ff22a844474bf40372496 New: tmm.uuid./<partition_name>/<network_access_name>.a1 a8f67d0bb5dd1863697b81b181cb84a5

  • Establishing a Network Access connection is only successful after several attempts.
  • Network Access clients are frequently disconnected, and automatic reconnection attempts fail with various error messages that may appear similar to the following examples:

    internal error

    failed to download configuration
