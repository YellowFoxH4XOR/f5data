Known Issue

Security Assertion Markup Language (SAML) assertion consumer service (ACS) may not display in the Configuration utility.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured as a SAML Identity Provider (IdP).
  • You attempt to import an external service provider (SP) connector from metadata using the Configuration utility.

Impact

Although the SP connector is created, the ACS does not display in the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • ACS does not display in the Configuration utility after a successful import of an external SP connector from metadata.
  • The ACS configurations are visible using the Traffic Management Shell (tmsh), but not using the Configuration utility.
