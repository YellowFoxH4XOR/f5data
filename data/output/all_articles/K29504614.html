Issue

Error Message

err tmm[<pid>]: 01aa0001:3: ICAP (<IP>): Unexpected status code <code> received from server

In this error message, note the following:

  • <pid> is the process ID of the Traffic Management Microkernel (TMM)
  • <IP> is the source and destination IP address and ports
  • <code> is the Internet Control Message Protocol (ICAP) status code

For example:

err tmm[12345]: 01aa0001:3: ICAP (192.0.2.1:55174 -> 198.51.100.1:80): Unexpected status code 400 received from server

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • An unexpected ICAP status code has been received.

Impact

The ICAP transaction on the internal virtual server is aborted. The parent virtual server performs the service-down-action configured in the request-adapt or response-adapt profile.

Recommended Actions

Investigate why the ICAP server is returning an unexpected status code.
