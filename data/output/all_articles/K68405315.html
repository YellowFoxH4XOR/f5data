K68405315: Status of Script execution remains running although the task is completed

Type
Support Solution
Published
2020-08-19
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K68405315

Description

When running a script in WebUI, the status of the script stuck in Running state even though the script finishes. To observe the actual timestamp of the Start and Finish of the script, the WebUI needs to be manually refreshed.

Environment

  • BIG-IP
  • BIG-IQ

Cause

This behaviour is by design. It is cosmetic and has no operational impact.

Recommended Actions

If you would like to see this behaviour improved in the upcoming versions in the future, please feel free to open a service request with F5 support, reference this article, and request to link your SR with bug ID 936489.

Additional Information

To observe the issue:

  1. Create a simple script
  2. Navigate to Devices >> Script Logs >> Run Script
  3. Observe Status option and you will see it remains in Running state despite logs shows the script finished.

Demonstration

The script name is 2ndAttemptTimeout60s. The script runs the command tmsh show sys cpu.
