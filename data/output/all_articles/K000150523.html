K000150523: F5OS is not honoring the configured LACP interval

Type
Support Solution
Published
2025-03-25
Updated
2025-03-25
Applies to
  • F5OS
  • rSeries Platforms
  • VELOS Platforms
Source
https://my.f5.com/manage/s/article/K000150523

Description

 

F5OS is not honoring the configured LACP interval.

 

Environment

  • F5OS-A
  • F5OS-C
  • LACP
  • LAG

 

Cause

 

F5 LACP interval may be dependent on the received LACP partner's interval setting. This is designed in order to avoid any unexpected LACP timeout due to a misconfigured partner.

 

Recommended Actions

 

Set the LACP interval to be the same for both ends of an LACP enabled LAG.
