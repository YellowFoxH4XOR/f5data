Known Issue

The BIG-IP system may unexpectedly reach the Secure Sockets Layer (SSL) transactions per second (TPS) rate limit.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a virtual server for SSL offload.
  • The virtual server is processing traffic.
  • The system clock time is adjusted.

Impact

For a brief period of time, the system may drop some virtual server SSL connections.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/ltm file, you observe log messages similar to the following examples:

    warning tmm1[<pid>]: 01010040:4: Clock has unexpectedly adjusted by 985 ms
    warning tmm[<pid>]: 01010040:4: Clock has unexpectedly adjusted by 985 ms
    warning tmm1[<pid>]: 01010040:4: Clock has unexpectedly adjusted by 985 ms
    warning tmm[<pid>]: 01010040:4: Clock has unexpectedly adjusted by 985 ms
    err tmm[<pid>]: 01260008:3: SSL transaction (TPS) rate limit reached
    err tmm[<pid>]: 01260008:3: SSL transaction (TPS) rate limit reached
