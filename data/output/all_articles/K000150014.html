K000150014: UCS fails to generate from both GUI and CLI on vCMP guest

Type
Support Solution
Published
2025-02-28
Updated
2025-02-28
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150014

Description

When attempting to generate a UCS archive on a vCMP guest, it fails with "Internal Server Error". The following common fixes do not resolve the issue:

  • Waiting for the configuration utility to generate the file
    Does not ever resolve, the process fully hangs and does not generate the archive.
  • Using TMSH to generate the file
    Using TMSH with the following command generates the following error:

     

    tmsh save /sys UCS </path/to/ucs>
admin@(hostname)(cfg-sync In Sync)(/S1-green-P::Active)(/Common)(tmos)# save sys ucs filename

Saving active configuration...

Unexpected Error: action canceled

Error during config save.

Unexpected Error: UCS saving process failed.
  • Restarting syscalld
    Attempting to restart the syscalld daemon with the following command has no effect on the issue
    bigstart restart syscalld

Environment

Taking a UCS archive on GUI fails after 5 minutes and returns "Internal Server Error"
Taking a UCS archive on CLI (tmsh) does not complete forever
Common fixes that normally work have no effect

Cause

Unknown at time of writing

Recommended Actions

Restart the guest by changing the state to Configured or Provisioned, then back to deployed. For step-by-step instructions, refer to K20081511: Shutting down and restarting the vCMP guest from the vCMP host

Note: If the Guest is in the Active state, this will cause a failover event and some amount of traffic disruption. F5 recommends you perform these steps in a maintenance window.
