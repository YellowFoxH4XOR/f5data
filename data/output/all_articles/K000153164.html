Description

Guidance for upgrading BIG-IP LTM from version 16.x to a stable v17.x release, including considerations for selecting the appropriate target version and applying necessary hotfixes. A specific issue (Bug ID 1983185) may affect REST API queries between BIG-IQ and BIG-IP v17.5.1.

Environment

  • Affected by Bug ID 1983185
  • Current Version: 16.x
  • Target Version: 17.x
  • BIG-IP managed by BIG-IQ

Cause

A known bug (ID 1983185) in BIG-IP v17.5.1 causes REST API queries sent from BIG-IQ to fail if they use the v17.5.0 API version.

Recommended Actions

  • Upgrade to the latest available maintenance release in the desired branch (e.g., 17.1.x or 17.5.x), as these releases contain cumulative fixes and enhancements.
  • Review release notes for your selected version to confirm compatibility and address any environment-specific issues.
  • To avoid issues when BIG-IQ is accessing BIG-IP, upgrade to a release where ID 1983185 is fixed (17.5.1.2 and above).
  • Verify that your device license supports v17.x; upgrade your license if it is currently at v16 or lower before installing v17.x.
  • Ensure your upgrade path is supported and system resources meet requirements for the target version.
  • Test upgrades in a pre-production environment prior to production deployment.
  • Follow F5’s documented procedures for upgrading HA pairs or standalone systems.
