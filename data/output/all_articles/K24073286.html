K24073286: Live Update Available prompt constantly even with latest attack signature update installed

Type
Support Solution
Published
2020-07-02
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.X.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.X, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K24073286

Description

You observe that the top-left portion of the GUI reports Live Update Available, despite having the latest attack signature update installed.

Environment

  • Version 15.x
  • Updates are being uploaded and installed manually

Cause

Bug ID 868053

Recommended Actions

This issue is only known to occur when the signature update files are uploaded manually to the BIG-IP.

You can verify if your system is affected by this issue by reviewing the output of the following commands:

curl -sku admin:<password> "https://localhost/mgmt/tm/live-update/" | jq .

curl -sku admin:<password> "https://localhost/mgmt/tm/live-update/asm-attack-signatures/availability" | jq .

Here is some example output from a system affected by the issue:

{
  "reference": {
    "link": "https://localhost/mgmt/tm/live-update/asm-attack-signatures"
  },
  "name": "ASM Attack Signatures",
  "canRead": true,
  "canWrite": true,
  "canWriteGenesis": true,
  "isUpdateAvailable": true     <----------
}
  
{
  "lastCheckDateTime": "2020-06-19T10:23:50Z",
  "status": "no-update-available",    <-----------
  "lastCheckUpdateFile": "ASM-AttackSignatures_20200618_101132.im",
  "kind": "tm:live-update:asm-attack-signatures:availabilitystate",
  "selfLink": "https://localhost/mgmt/tm/live-update/asm-attack-signatures/availability"
}

Note that /mgmt/tm/live-update reports an update is available, but /mgmt/tm/live-update/asm-attack-signatures/availability shows no update is available.

This is a cosmetic issue, but an engineering hotfix may be requested by opening a service request with F5 Support and referencing this article.
