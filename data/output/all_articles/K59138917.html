K59138917: Database error (60) when syncing HA cluster

Type
Support Solution
Published
2020-05-28
Updated
2023-02-21
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 12.0.X, 12.0.0
Source
https://my.f5.com/manage/s/article/K59138917

Description

After changes made on standby box,HA cluster sync failed due to Database error

  • Error message similar to :
    Database error (60), Error loading object from cursor, status: 60
    Recommended action: Review the error message and determine corrective action on the device.

Environment

  • IApp deployment was created on Standby BIG-IP and then immediately deleted
  • After that Sync from Standby to Active was performed

Cause

 The behavior is connected to ID527562 and ID540456

Recommended Actions

As a workaround:

  • If possible, Overwrite Configuration during Sync from Active box to Standby 

    -- or --
     
  • Proceed with mcpd forceload on Standby box and then synchronize.
    K13030: Forcing the mcpd process to reload the BIG-IP configuration
