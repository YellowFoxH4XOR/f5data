Known Issue

This is the result of a known issue. If the installer script finds multiple versions of the same package to install, the installation or upgrade will abort and display messages similar to the following example:

====Transferring====
package set: LTM.dat
repository: /shared/repository
name: BIG-IP
version: 9.1.2
local tmp product repository: /shared/repository/BIGIP912
ERROR: Multiple EUD packages -
/mnt/tmp/install/shared/repository/BIGIP912/i386/hsibj-eud-1.0-9.4.0.40.5.i386.rpm
/mnt/tmp/install/shared/repository/BIGIP912/i386/hsibj-eud-1.0-9.4.0.40.0.i386.rpm.
Contact support.

This issue occurs when a previous installation or upgrade attempt of a different version fails prior to cleaning up the temporary installation packages.

F5 Product Development tracked this issue as CR64231 and it was fixed in BIG-IP LTM 9.1.3. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

You can work around this issue by deleting the rpm files listed in the error message.

To delete the rpm files, perform the following steps:

  1. Log in to the command line.
  2. Delete the rpm files by typing the following commands:

    rm <filename>rm <filename>

    For example:

    Note: The following commands have been split into multiple lines for formatting purposes only.

    rm /mnt/tmp/install/shared/repository/BIGIP912/
    i386/hsibj-eud-1.0-9.4.0.40.5.i386.rpm

    rm /mnt/tmp/install/shared/repository/BIGIP912/
    i386/hsibj-eud-1.0-9.4.0.40.0.i386.rpm

Once you have removed the rpm files, you can proceed with the installation or upgrade.
