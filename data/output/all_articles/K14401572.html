Description

You are reviewing the status of services running on your BIG-IP's Configuration Utility (GUI) and see that the ntpd service has a very long description under it's history column, starting with the test below:
* ntpd.service - LSB: start and stop ntpd Loaded: loaded (/etc/rc.d/init.d/ntpd; bad; vendor preset: disabled) Active: active (running) since...

Environment

  • BIG-IP
  • Configuration Utility - System >> Services :: Services List

Cause

This behavior is caused by ID 948705. It is cosmetic and doesn't affect traffic processing or system services.

Recommended Actions

  • Check the status of ntpd from the command line using tmsh show sys service ntpd
  • Upgrade to an unaffected software version if one is available Note: Refer to Related Content

None
