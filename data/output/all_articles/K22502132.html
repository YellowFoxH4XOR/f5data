Description

Version information of maintenance release should display edition as 'FINAL', however, BIG-IP 15.1.1 shows 'Point Release 0' for the command output 'cat /VERSION' or 'tmsh show sys version' as shown below.

[root@LTM.Example.com] config # cat /VERSION
Product: BIG-IP
Version: 15.1.1
Build: 0.0.6
Sequence: 15.1.1-0.0.6.0
BaseBuild: 0.0.6
Edition: Point Release 0  
Date: Thu Oct  8 02:52:59 PDT 2020
Built: 201008025259
Changelist: 3410580
JobID: 1234958

Environment

  • BIG-IP  15.1.1
  • View Release information 

Cause

This is cosmetic and  It has no impact. This version is a maintenance release .

Recommended Actions

None

Additional Information
Version information for BIG-IP 15.1.2 displays correctly. 

[root@LTM.Example.com] tmp # cat /VERSION
Product: BIG-IP
Version: 15.1.2
Build: 0.0.9
Sequence: 15.1.2-0.0.9.0
BaseBuild: 0.0.9
Edition: Final    
Date: Tue Nov 10 20:09:04 PST 2020
Built: 201110200904
