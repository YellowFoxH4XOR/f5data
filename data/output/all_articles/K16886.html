Issue

Error Message

info: RPM: /usr/sbin/load_policy: Can't load policy: No such file or directory.

This error message may be accompanied by any the following error messages:

info: RPM: libsepol.policydb_write: Discarding booleans and conditional rules
info: RPM: libsepol.context_read_and_validate: invalid security context
info: RPM: libsepol.policydb_to_image: new policy image is invalid
info: RPM: libsepol.policydb_to_image: could not create policy image
info: RPM: libsemanage.semanage_reload_policy: load_policy returned error code 2.
info: RPM: semodule: Failed!

Message Location

You may encounter this message in the following location:

  • The /var/log/liveinstall.log file

Description

This message occurs when the following condition is met:

  • You are installing a hotfix.

Impact

None. These messages may be safely ignored.

Recommended Actions

None
