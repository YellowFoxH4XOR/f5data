Known Issue

Under rare conditions, virtual servers that reference a Web Acceleration profile may cause the Traffic Management Microkernel (TMM) to produce a core file.

This issue occurs when the following condition is met:

  • The BIG-IP system experiences low memory conditions.

Impact

BIG-IP systems that are part of a high-availability configuration will fail over to a peer system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The TMM process produces a core file with a SIGABRT message.
  • A BIG-IP system in a high-availability configuration fails over to the peer system.
  • The BIG-IP system generates a TMM core file in the /var/core directory.
