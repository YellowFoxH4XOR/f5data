Description

Can we create a new custome column in Active Session table? 

 

Environment

  • BIG-IP
  • APM
  • Active Session Table
  • Customize

 

Cause

  • It is not supported.

 

Recommended Actions

New column can not be added, but you can change the value of existing columns.

 

Using technique written in: K31721063: SAML authenticated users do not display username in active sessions

 

To overwrite one of text formatted columns, like Virtual Server (session.server.listener.name), Profile Name (session.access.profile)..

e.g

(Custome Variable) session.access.profile = (Session Variable) session.custom.Your_Variable

NOTE: Then column name can not be modified, in above case Profile Name column 's name stays Profile Name, but value can be changed to your variable's value. If the valiable value is text, the customizing columns must support the text.
