Description

You wish to specify the name of the VPN Adapter that appears in the Windows Network Connections list.

Environment

  • Network Access VPN
  • Routing and Remote Access service (RRAS)

Cause

Windows uses the Routing and Remote Access service (RRAS) subsystem to create and maintain the SSL VPN tunnel. The BIG-IP Edge Client invokes the RRAS using the dial-up entry to configure the VPN driver, initiate the VPN adapter call, and configure the adapter with the IP address, protocol bindings, and other settings.

The default Windows RRAS dail-up entry naming convention is as follows : 
    _<BIGIP_PARTITION_NAME>_<NETWORK_ACCESS_RESOURCE> - Go to <VIRTUAL_SERVER> instead of dialing directly

With the aid of a properly configured Variable Assign agent in the Access Policy used to provide the Network Access VPN connection, the name that appears in the Windows Registry and Network Connections list for the APM or Edge Client VPN connection can be customized.

Recommended Actions

The dial up entry name can be customized by creating a Variable Assign agent in an Access Policy that specifies the Name of the APM or Edge Client VPN connection that appears in the Windows Registry and Network Connections list:

  1. Add a Variable Assign agent to the per-session access policy.  Place it before the resource assignment agent.
  2. Set the Unsecure Custom Variable name (left pane) to:
        config.connectivity_resource_network_access./partition/Network_Access_ressource_name.client.ConnectionTrayIcon

    For example (see also image in step 3), if the Network Access resource name is "TEST_VPN" and it is in the "Common" Administrative Partition:
        config.connectivity_resource_network_access./Common/TEST_VPN.client.ConnectionTrayIcon
     
  3. Set the Custom Expression (right pane) to:
        return "</ConnectionTrayIcon><connection_name_txt>custom_dail_up_entry_name</connection_name_txt><ConnectionTrayIcon>"

    For example:
        return "</ConnectionTrayIcon><connection_name_txt>TEST VPN connection</connection_name_txt><ConnectionTrayIcon>"

         

  4. Save the Variable Assign configuration, then Apply the access policy

The next time a Client establishes the VPN connection with the BIG-IP, the Windows RRAS dial-up adapter will be updated to the name provided in the Variable Assign agent.
