K000152708: License Reactivation prior to upgrade does not seem to take effect

Type
Support Solution
Published
2025-07-28
Updated
2025-07-28
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000152708

Description

  • You had done license re-active before software upgrade. After booting into new boot location with the upgraded software image, you see banner to re-active license once again.
  • You are wondering why you had to re-activate license twice (before and after upgrade).

Environment

  • BIG-IP
  • Software upgrade
  • License re-activation

Cause

If license reactivation is performed after installing the new software image (i.e., after creating a new boot location), the updated license information is not included in the configuration copied to the new boot location. As a result, when booting into the upgraded partition or boot location, the system uses outdated license data, which can trigger prompts for license reactivation or cause configuration load failures.

Recommended Actions

  • Always reactivate your BIG-IP license before installing a new software image in a new boot location. This ensures that updated licensing information is included in the configuration copied to the newly created boot location.
  • Follow F5’s recommended upgrade procedures and ensure that license reactivation is completed as one of the first steps before any software installation or upgrade process.
