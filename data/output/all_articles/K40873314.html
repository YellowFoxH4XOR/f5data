Description

This article is about how the BIG-IP manages DNS hosts in System > Device > DNS > DNS LookUp Server List.

Environment

  • BIG-IP
  • DNS

Cause

N/A

Recommended Actions
To configure DNS on BIG-IP systems refer to: K13205: Configuring the BIG-IP system to resolve DNS hostnames (11.x and later)

Additional Information

Note: Information based on https://man7.org/linux/man-pages/man5/resolv.conf.5.html.

  1. What is the potential downtime from switching DNS hosts within "DNS LookUp Server List" to prioritize the newly added individual DNS servers/nodes.
    Switching DNS hosts should not have a negative impact on your system, as long as the new ones are reachable and responding accordingly to the DNS queries.
     
  2. How does the BIG-IP determine if a DNS server is down?
    Resolver will query DNS servers one by one according to the order in list. Because BIG-IP is built on top of Linux:
    Up to MAXNS (currently 3, see <resolv.h>) name servers may be listed, one per keyword.  If there are multiple servers, the resolver library queries them in the order listed.
     
  3. Is there a time-out grace period before trying the next one on the list?
    The default time is 5 seconds  RES_TIMEOUT (currently 5, see <resolv.h>).
