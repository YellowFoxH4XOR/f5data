Description

Not able to provision LTM module as dedicated in a Viprion that previously had VCMP provisioned
Although the LTM module is successfully provisioned, not enough disk space might be available


Environment

  • Viprion was previously provisioned with VCMP Host and Guests
  • VCMP Guests, virtual disks removed using the GUI utility
  • VCMP module deprovisioned in order to dedicate the whole Viprion Chassis to LTM
  • GUI Disk management still shows the VCMP module is taking out most of the Hard Drive Space

Cause

The vmdisks application volume is still configured

Recommended Actions

Delete the vmdisks application volume from the disk using tmsh:           
tmsh delete /sys disk application-volume vmdisks
  

 Example:

  Before:

  tmsh list /sys disk application-volume vmdisks
        sys disk application-volume vmdisks {
        logical-disk HD1
        owner vcmp
        preservability precious
        size 826068
        volume-set-visibility-restraint none

Delete the vmdisks application volume:      
  tmsh delete /sys disk application-volume vmdisks

 
After:

  tmsh list /sys disk application-volume vmdisks
        01020036:3: The requested application volume (0 vmdisks) was not found.
