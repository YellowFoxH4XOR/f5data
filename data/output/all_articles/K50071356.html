Description
BIG-IP systems may fail to pass responses from servers on to clients if MSS advertised by the client is smaller than that is advertised from the BIG-IP system to the server.

Environment

  • BIG-IP v12.1 prior to 12.1.5.1
  • BIG-IP v13.1 prior to 13.1.3.2
  • BIG-IP v14 prior to 14.1.2.1
  • BIG-IP v15.0 prior to 15.0.1.1
  • A virtual server is configured with OneConnect profiles
  • Proxy MSS setting is enabled in TCP profiles

Cause
This defect is caused by ID773421.

Recommended Actions

  1. Upgrade to a software release listed in the above link that isn't affected by this defect.
  2. Disable proxy-mss in the configured TCP profile as a workaround.
