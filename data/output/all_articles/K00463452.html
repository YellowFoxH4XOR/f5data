Known Issue

When you perform an upgrade, the system may alter the virtual address route advertisement configuration.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured for dynamic routing.
  • You have configured virtual addresses with route advertisement enabled.
  • Your BIG-IP system is running BIG-IP 13.0.0 or earlier.
  • You upgrade your BIG-IP system to BIG-IP 13.0.0 HF2 or later.

Impact

Virtual addresses are no longer configured with route advertisement enabled.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Before you perform an upgrade, you compare virtual address configurations, and after you perform the upgrade, route advertisement is disabled.
  • Virtual addresses no longer advertise their Route Health Injection (RHI) availability.
  • The system cannot route to the virtual addresses.

Workaround

To work around this issue, you can re-enable route advertisement for the affected virtual addresses. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To enable route advertisement for a virtual address, use the following command syntax:

    modify /ltm virtual-address /<partition>/<ip address> route-advertisement selective

    For example:

    modify /ltm virtual-address /Common/172.16.1.157 route-advertisement selective

  3. Repeat step 2 for each virtual address for which you want to enable route advertisement.
  4. Save the configuration changes by typing the following command:

    save /sys config partitions all
