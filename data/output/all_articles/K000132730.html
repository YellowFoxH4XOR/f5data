K000132730: Can not select IPv4 management address for configsync if IPv4 and IPv6 mgmt addresses are configured

Type
Support Solution
Published
2023-02-22
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000132730

Description

BIG-IP with sys db configsync.allowmanagement value enable cannot configure IPv4 management address for config sync if configured for dual stack management (IPv4 and IPv6 addresses both configured).

 

Environment

All 3 conditions exist:

  • Product BIG-IP all versions that do not have a fix for ID1215613 (currently all versions affected)
  • sys db configsync.allowmanagement value enable
  • both IPv4 and IPv6 management addresses are configured

 

Cause

Defect ID1215613

 

Recommended Actions

Contact F5 support for further assistance. 

 

Additional Information

None
