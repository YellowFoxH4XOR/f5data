Description

Webservice Request Failed (Malformed XML Data) violation seen in the Event logs and /var/log/asm shows:

Cannot allocate 6464 more bytes for XML parser. current memory size xxxxxxxxx (in bytes)
 

Environment

  • ASM policy with a XML profile with an associate validation wsdl scheme
  • Violation: Malformed XML data


Cause

This occurs to due the lack of XML memory allocation.

K16576: Symptoms of XML processing engine memory exhaustion
 

Recommended Actions

To determine how much additional memory is needed to add to the total_xml_memory, refer to the article K10803: Customizing the amount of memory allocated to the BIG-IP ASM XML processing engine
 

Additional Information

  • Wen the ASM BIG-IP system is configured with large or many XML schemas, the XML processing engine may run out of memory.
  • When not enough memory is available to parse the XML request, and only a portion is parsed, it becomes malformed and hence the violation is triggered.
