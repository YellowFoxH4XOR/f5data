Description

Licensing a BIGIP in Azure fails while trying to use Declarative Onboarding in the BIG-IQ. It fails when clicking Onboard with:

Please confirm Declarative Onboarding (DO) is running on BIG-IQ. See log for details.

Environment
  • BIG-IQ 7.0.0

Cause

Unknown at time of publication.

Recommended Actions

Restart the restnoded service with the following command:

bigstart restart restnoded

Additional Information

The following logs may appear in /var/log/restjavad.log

Task failed at step FORWARD_DECLARATION with message: Failed to complete onboarding task: Unexpected response from declarative onboarding: code: 404, message: Please confirm Declarative Onboarding (DO) is running on BIG-IQ. See log for details.
