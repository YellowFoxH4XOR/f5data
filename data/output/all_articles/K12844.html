Issue

Error Message

01310053:6: RRD file:/ts/var/rrd/overview_asm_<#>.rrd should be recreated because of illegal attempt to update. Previous data will be lost.

where:

  • <#> is a number identifying the name of a specific iterated log file

Example:

01310053:6: RRD file:/ts/var/rrd/overview_asm_8.rrd should be re-created because of illegal attempt to update. Previous data will be lost.

Message Location

You may encounter this message in the following location[s]:

  • /var/log/asm

Description

This message may occur when either of the following conditions are met:

  • The system time on the BIG-IP ASM device has been set backward
  • The BIG-IP ASM module has been started up for the first time

Impact

In the case of the first bullet, when you have set the system time backward, the system recreates the file named in the error message and loses any rrd data that the system previously logged in the file. 

In the case of the second bullet, this error is benign, as the BIG-IP ASM system has not previously written to the rrd file, so there is no data to lose when the system recreates the file.

Recommended Actions

None
