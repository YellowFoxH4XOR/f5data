  • BIG-IP LTM
Source

Description

AS3 Declaration fails for "Can't parse script, missing close-brace line:0\"


Environment

BIG-IP LTM

AS3 v3.54.1

iRules


Cause

AS3 v3.54.1 does not properly parse the declaration when multiple iRules are defined.


https://github.com/F5Networks/f5-appsvcs-extension/issues/920

iRule parsing error when multiple iRules are passed in AS3 declaration




Recommended Actions

This issue is fixed in AS3 v3.54.2


Additional Information

This error is not seen on v3.53.0 or earlier
