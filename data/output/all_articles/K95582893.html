Description

Can the IP Intelligence database can be exported from BIG-IP in a human-readable format?

Environment

  • BIG-IP ASM
  • BIG-IP AFM 
  • IP intelligence subscription

Cause
None

Recommended Actions

The IP Intelligence Database cannot be exported from BIG-IP in a human-readable format.

Additional Information
The IP Intelligence database is a list of IP addresses with questionable reputations. IP addresses gain a questionable reputation and are added to the database as a result of having performed exploits or attacks, or these addresses might represent proxy servers, scanners, or systems that have been infected. The IP Intelligence database is maintained online by a third party. The BIG-IP® system can connect to an IP intelligence database, download the contents, and automatically keep the database up to date.
