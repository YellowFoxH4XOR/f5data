Description

An error message, "Configuration error: Invalid Devicegroup Reference," may appear when attempting to update Bot Profiles within partitions. 

Environment

  • BIG-IP WAF
  • Bot Profile configured under a partition and only has sync-only Device Group

Cause

Bot Profiles requires access to Common partition

 

Recommended Actions

This error occurs because the partition cannot access objects residing in the /Common partition. 

To resolve this:

  • Utilize a sync-failover Device Group.
  • Set the traffic group to "none" in the /Common folder.

Additional Information

None
