Description

How to provision an FCP license to a BIG-IP Virtual Edition (VE) that is not reachable from a BIG-IQ. This BIG-IP VE could be on a closed network, in a remote data centre, or disconnected from the same network as the BIG-IQ.

Environment

  • BIG-IQ
  • Flex Consumption Program (FCP)
  • CAT License Offerings
  • BIG-IP VE unreachable from BIG-IQ

Cause

BIG-IQ traditionally expects to be able to connect to any BIG-IP VE to license it. This code creates a license file from the Big-IQ/CAT license offerings which can be applied directly to the "Unreachable" BIG-IP VE.

Recommended Actions

Copy the python code from our Dev Central "code Snippet" and run it on your BIG-IQ device. This will prompt you for several pieces of information about the BIG-IP being relicensed. Once this is created, copy the license to the BIG-IP VE then reload the license.
Important: Relicensing the BIG-IP VE is traffic impacting as its services restart to process the license update.

  1. SSH into the BIG-IP device to be licensed and run the following command to obtain the MAC address of its Management Interface:
    tmsh list cm device base-mac
  2. In the BIG-IQ GUI, Devices > License management > Licenses, note the CAT license name (in blue) from which the BIG-IP license is to be generated. 
  3. Click into this CAT license name link to access the list of License Offerings.
  4. From these lists, take note of the CAT License Offering to be applied to the BIG-IP VE. 
  5. Now SSH into the BIG-IQ
  6. Move into the /shared directory (cd /shared)
  7. Copy over the Create-license.py python script and run it by typing: 
    python Create-license.py

    Note: For the Python code, which can be run on your BIG-IQ, please refer to "Additional Information" at the end of this article and the link to our Dev Central "Code Snippet"

  8. The script runs and will prompt you for the following information. This works for CAT license offerings. 

    Enter BIG-IQ user ID: admin
Enter BIG-IQ Password:
Enter Management IP address of BIG-IQ: vv.yyy.xx.zz
Enter Management IP address of BIG-IP to be licensed: vv.xx.yyy.zz
Enter Management MAC address of BIG-IP to be licensed: aa:bb:cc:dd:ee:ff
Enter the name of the License Pool from which to take BIG-IP license: <CAT-License-Name>
Enter the license name to be assigned to the BIG-IP: <CAT-License-Offering-Name> 
Enter hypervisor used, valid options are: aws, azure, gce, hyperv, kvm, vmware, xen
Optional: Enter chargeback tag if required: <chargeback_tag>
Optional: Enter tenant name if required: <Company-B, POC, project, etc>
  9. Once these details have been filled in, the script authenticates to the BIG-IQ and generates the license (should take approximately 30 seconds)
  10. If everything went well, you will be presented with a success message.
  11. The license file is saved as "<IP-address_bigip>.license" in the same directory as you ran the script.

On the Unreachable Big-IP:

Important: Relicensing restarts services on the BIG-IP and causes downtime / service interruption.

  1. Using SCP, copy this new license file from the BIG-IQ to your desktop.
  2. Back up the current license file on the BIG-IP: cp /config/bigip.license /config/bigip.license.bak
  3. Copy the new license file from your desktop to the /config directory of the BIG-IP device to be licensed.
  4. Rename the file to "bigip.license"
  5. Reload the license by typing "reloadlic"

In the BIG-IP device CLI, the services will show as active after the restart. Via the WebUI, confirm the license status and provision modules as needed.
