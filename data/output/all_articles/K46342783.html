Description

BIG-IP ASM Risk Engine is currently available to Early Access customers only and requires a special license. You want to determine whether a BIG-IP license contains Risk Engine.

Environment

  • BIG-IP AWAF/ASM
  • Risk Engine

Cause

None

Recommended Actions

Type the following command from the BIG-IP system command line to determine if your BIG-IP license contains Risk Engine:

tmsh show /sys license | grep -i "Risk Engine"
