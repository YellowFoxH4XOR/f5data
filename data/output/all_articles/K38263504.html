Description

Multiple copies of the same log are sent to remote logging server.


Environment

  • Splunk configured in logging profile
  • The peer device when made active working as expected


Cause

Undetermined.

Note: The solution in Recommendation Actions will likely resolve the problem, however, the opportunity to finding the root cause will be lost. 

Should you wish for f5 Support to determine the root cause before implementing the recommended action, please open a technical support ticket. 


Recommended Actions

To recover form this behaviour, process "asm" can be restarted.

Impact of workaround: Restarting the asm process causes the BIG-IP ASM system to fail over to the remaining members of the device group.

  1. Log in to the BIG-IP via CLI
     
  2. Restart the asm process using the command:

    bigstart restart asm
