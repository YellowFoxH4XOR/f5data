Description

Fixed BIG-IP software version is installed, however the users are still blocked instead of seeing CAPTCHA.

Environment

  • Brute Force Protection with a maximum number of attempts allowed
  • Mitigation method is CAPTCHA
  • When attempts are exceeded, user is blocked instead of seeing the CAPTCHA
  • BIG-IP software version 13.1.1 installed
  • Bug ID 686108 indicates 'Fixed'
Cause

In versions 13.1.0, 13.1.0.1, when Client side Integrity or CAPTCHA is configured, but the login URL is not yet qualified for challenge injection, a blocking page is returned.

Recommended Actions

To resolve this issue of seeing a blocking page, there are two workaround options provided that can be found in BugTracker article Bug ID 686108.
