K000150695: iHealth poller when trace is "true" does not create a trace file under /var/temp/telemetry

Description

Enabling the trace for iHealth Poller using the provided telemetry declaration does not create the expected trace file under /var/tmp/telemetry/

Environment

  • Telemetry
  • IhealthPoller
  • Trace enabled

Cause

Trace under iHealthPoller is disabled and can't be started

Recommended Actions

  • Avoid enabling trace for iHealthPoller
  • Use debug enabled and /var/log/restnoded/restnoded.0.log to troubleshoot issues with qkviews iHealth upload
