Description
Starting v14.1, you can attach and detach a security policy to desired virtual server with Application Security Administrator user role. This would be in addition to being able to manage ASM policy configuration objects.

Environment

  • ASM security policy and virtual server configured
  • Advanced WAF is licensed

Cause
An enhancement introduced in v14.1 allows for users with Application Security Administrator role to attach the desired security policy to a particular virtual server under Security > Overview > Summary section within Configuration Utility. Similarly, you can also detach the security policy from any virtual server. It is essential to detach an existing policy from the virtual server before attaching a different security policy. 

Recommended Actions

  • Attaching security policy to virtual server
  • Detaching security policy from virtual server

Attaching security policy to virtual server

You can attach a security policy to a virtual server with the following steps:

  1. Navigate to Security > Overview > Summary section within Configuration Utility.
  2. Select the desired Virtual Server.
  3. Select Attach and then the desired security policy to associate it to the virtual server 

With the above steps, it will result in BIG-IP automatically creating a LTM policy with a naming convention such as asm_auto_l7_policy__<virtual-server-name> that has a default ASM rule enabled with the above security policy invoked for all incoming requests. This LTM policy would automatically be associated to the virtual server.

Detaching security policy from virtual server

You can attach a security policy to a virtual server with the following steps:

  1. Navigate to Security > Overview > Summary section within Configuration Utility.
  2. Select the desired Virtual Server.
  3. Select Detach and then the desired security policy to remove it from the virtual server
