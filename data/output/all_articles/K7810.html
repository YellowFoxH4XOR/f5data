Known Issue

This is the result of a known issue. When you view user session information on the Reports: Sessions page, the reported session duration is longer than the actual session duration. This issue occurs when the timezone you configured on the Device Management: Configuration: Time page does not have a full-hour offset to GMT.

For example, the Asia/Katmandu timezone has a +5:45 GMT offset, and is affected by this issue. The Australia/Sydney timezone has a +10:00 GMT offset, and is not affected by this issue.

F5 Product Development tracked this issue as CR83091 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Additionally, Cumulative Hotfix HF-601-5 has been issued for FirePass version 6.0.1. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
