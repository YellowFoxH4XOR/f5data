Issue

Description

This article highlights the different methods to gather diagnostic data to troubleshoot VPN access issues while connecting with the F5 Access client on Windows 10. These steps will guide you through enabling debug logging and collecting and reviewing the relevant log messages. 

Environment

  • Client computer running Windows 10.
  • F5 Access client is installed and configured.
  • User is experiencing failure to connect to BIG-IP APM network access.

Cause

Common VPN connection issues include network connection, SSL certificate trust, third party applications and so on.

Recommended Actions

You can use the following procedures to gather diagnostic data from the F5 Access client on Windows 10.

  • Increasing the log level
  • Viewing logs
  • Exporting logs

You should match the log entries on the client side to those on the BIG-IP APM when troubleshooting.

Increasing the log level

In order to troubleshoot VPN issues, it may be necessary to increase the log level. The available log levels are listed in the following table.

ValueDescription
defaultThis is the default log level.
minimumSpecifies the minimum log level for events.
info  Messages that contain useful information, but may be ignored.
debugSpecifies maximum level for log entries.

The log levels are configured through a custom XML parameter using Powershell. To set the debug log level, perform the following procedure:

  1. Open Powershell by clicking Start and entering Powershell.
  2. Use the following command syntax in Powershell to set the logging level.

    Set-VpnConnection -Name <ConnectionName> -CustomConfiguration "<f5-vpn-conf><log-level><value></log-level></f5-vpn-conf>"
    Note: <ConnectionName> is the rasdial name for the network VPN connection <value> is the log level setting.

    For example, to set the log level to debug for the connection name vpn_example.com, type the following command in Powershell:

    Set-VpnConnection -Name vpn_example.com -CustomConfiguration "<f5-vpn-conf><log-level>debug</log-level></f5-vpn-conf>"

  3. To set the log level back to default, type the following command:

    Set-VpnConnection -Name vpn_example.com -CustomConfiguration "<f5-vpn-conf><log-level>default</log-level></f5-vpn-conf>"

Viewing logs

F5 Access logs can be viewed via the Windows Event Viewer. To do so, perform the following procedure:

  1. Open Windows Event Viewer by clicking Start and entering Event Viewer
  2. Navigate to the following logs
  • Event Viewer→Applications and Services Logs→Microsoft→Windows→Vpn Plugin Platform→OperationalVerbose
  • Event Viewer→Applications and Services Logs→Microsoft→Windows→Vpn Plugin Platform→Operational

Note: Depending on the system defaults and user permissions, you may first need to enable the logs in the event viewer. You can enable logs can by right clicking on Operational or OperationalVerbose view and then selecting Enable logs. 

Exporting Logs

The log files may contain a large number of entries, and you may find it useful to export the logs to a CSV file before analyzing them using Notepad or WordPad. Both the Operational and OperationalVerbose log views can be exported through the Event View by following the following procedure:

  1. Right-click the log file. For example, Operational and Operational Verbose.
  2. Click Save All Events As.
  3. Click.csv.

    Note: Save as and upload CSV files when submitting your log files to F5 support.

  4. Click Save.
