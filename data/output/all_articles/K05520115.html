Known Issue

The BIG-IP Edge Client for Mac is unable to establish a network access Virtual Private Network (VPN) connection after an OS X 10.12.5 update.

This issue occurs when all of the following conditions are met:

  • The user is running BIG-IP Edge Client on a MacBook Pro 2016 with the iBridge interface (for example, a MacBook Pro with a Touch Bar).

    Note: You can locate the iBridge interface on a MacBook Pro in the Network Utility under the Info tab.

  • The MacBook Pro is running OS X 10.12.5.
  • The BIG-IP APM network access configuration has both the Force all traffic through tunnel option and the Prohibit routing table changes during Network Access connection option enabled in the Network Settings.

Impact

Users are unable to establish a VPN connection to the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • MacBook users are unable to establish a network access session to the BIG-IP APM system using the Edge Client.
  • Messages similar to the following are logged to the Edge Client's svpn.log file:

    16637,16638,svpn, 1, , 870, CMacOSXRouteTable::UpdateIpForwardEntry2(), EXCEPTION - write failed, 22, Invalid argument.

Workaround

To work around this issue, you can reconfigure one of the following Client Settings options in the Network Settings page of the network access configuration:

Impact of workaround: Performing the suggested workaround may impact the availability of resources on the network, and you should perform the workaround during a maintenance window.

  • Clear the Prohibit routing table changes during Network Access connection setting.
  • Select the Allow Local Subnet setting.
  • Select and configure the Use split tunneling for traffic option, rather than using full tunneling.
