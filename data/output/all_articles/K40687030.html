K40687030: Error when running snmpwalk command ''Authentication failure (incorrect password, community or key)''

Type
Support Solution
Published
2022-03-04
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.1.X, 13.0.X, 13.1.5, 13.1.4, 13.1.3, 13.X.X, 13.1.0, 13.0.1, 13.0.0, 13.1.1
Source
https://my.f5.com/manage/s/article/K40687030

Description

After configuring SNMPv3 Access, when running the snmpwalk command, an error message similar to the following is displayed:

admin@BIGIP:Active:Standalone] log # snmpwalk -v3 -u testuser -l authPriv -a SHA -A "<password>" -x AES -X "<password>" localhost F5-BIGIP-SYSTEM-MIB::sysSystemNodeName
snmpwalk: Authentication failure (incorrect password, community or key)

At the same time a log messages similar to the following is logged to /var/log/snmpd.log:
Authentication failed for testuser
Authentication failed for testuser

Environment

  • BIG-IP
  • SNMPv3 configured 
  • snmpwalk
     

Cause

Due to special characters in password. 
 

Recommended Actions

When you have special characters in the SNMP password (for example: $) quote the password with single quotes (') instead of double quotes (").

Example:

[admin@BIGIP:Active:Standalone] log # snmpwalk -v3 -u testuser -l authPriv -a SHA -A '<password>' -x AES -X '<password>' localhost F5-BIGIP-SYSTEMiMIB::sysSystemNodeName

F5-BIGIP-SYSTEM-MIB::sysSystemNodeName.0 = STRING: abc.xyz.com
