Known Issue

If you fail to successfully create a route domain, the Configuration utility display may become corrupted.

This issue occurs when all of the following conditions are met:

  • You have configured your BIG-IP system with a partition in addition to the default Common partition.
  • The non-default partition is populated with configuration objects such as Virtual Local Area Networks (VLANs), self IPs, pools, and virtual servers.
  • You create a new partition.
  • You change Partition to the newly created partition.
  • You create a route domain with the following configuration settings.
    • General Properties > Name
    • General Properties > ID is empty.
    • Configuration > Parent Name is set to 0 (Partition Default Route Domain).
  • You click Finished.

    Note: The Configuration utility displays an error message similar to the following:

    General Database error

  • You navigate to Network > Route Domains.
  • You switch the Partition to the first original non-default partition.
  • You attempt to view the configuration objects of the partition.

Impact

The partition configuration objects are missing.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Configuration utility does not display previously configured objects in non-default partitions.

    Note: This is an issue with the Configuration utility's ability to display the configured objects.

Workaround

To work around this issue, when you create the partition route domain, you can ensure that the General Properties ID box for the route domain is populated before you click Finished. To correct the issue, restart the tomcat service. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the tomcat service, type the following command:

    restart /sys service tomcat

  3. Exit tmsh by typing the following command:

    quit
