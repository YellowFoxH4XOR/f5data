Description

When a BIG-IP Next instance is added to Central Manager, the instance is reported as green and healthy but the device will not pass traffic.

Environment

Relevant environmental factors specific to the topic
  • A BIG-IP Next instance is managed by Central Manager
  • Instance health is green
  • The instance will not pass application traffic

Cause

The BIG-IP Next instance is not licensed. 

Recommended Actions

  1. Follow the instructions for licensing a BIG-IP Next instance from Central Manager.

Additional Information

None
