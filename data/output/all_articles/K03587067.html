Known Issue

The BIG-IP system does not add dynamic Equal Cost Multipath (ECMP) routes to the Linux host.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is licensed with BIG-IP Advanced Routing Module (BIG-IP ARM).
  • Your BIG-IP system is configured to use dynamic routing.
  • Your BIG-IP system discovers dynamic ECMP routes from a neighboring device.

Impact

The BIG-IP ARM system sends traffic originating from the Linux host out the wrong interface, sends traffic using an incorrect route, or fails to send traffic altogether.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system sends local process traffic originating from the Linux host out the wrong interface, sends traffic using an incorrect route, or fails to send traffic altogether.
  • Monitor traffic fails, causing the BIG-IP system to incorrectly mark resources as unavailable.

Workaround

To work around this issue, you can disable ECMP in the dynamic routing configuration. To do so, use the IMI Shell (imish) command to set the maximum paths value to 1.

Impact of workaround: The impact of the suggested workaround will depend on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.
