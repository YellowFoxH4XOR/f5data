Known Issue

Insert mode cookie persistence can fail when all of the following conditions occur:

  • The client connects to a virtual server that has an existing BIG-IP persistence cookie.
  • The virtual server uses an idle HTTP node-side connection to load balance the client to the node that is specified by the cookie.
  • The virtual server sends the response and a FIN to the BIG-IP system.
  • All or part of the response is lost before the BIG-IP system receives the FIN.
  • The FIN is relayed to the client.
  • The client retransmits the request.
  • The node resends the response, but in a different number of packets than it originally sent.

It is extremely rare that all of these conditions are met; however, if these conditions do occur, the BIG-IP system sends the response to the client, but fails to insert the persistence cookie.

F5 Product Development is tracking this issue as CR29475 and CR41764.
