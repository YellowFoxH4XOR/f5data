Topic

You should consider using this procedure under the following condition:

  • You want to use a custom logo image on the BIG-IP APM access profile login page.

Description

One of the BIG-IP APM customization features that is immediately noticeable by users who access a BIG-IP APM access profile is the logo image on the login page. By performing the following procedure, you can easily update this logo image to fit the corporate theme of the access profile. Consider the file size and the dimensions of the replacement logo image and how this impacts the presentation of the login page (the default F5 logo image size is 80 pixels by 80 pixels).

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to the BIG-IP APM system.
  • You verified that the BIG-IP APM system is configured with a functioning access profile.
  • You have a replacement logo image (JPG, JPEG, GIF, PNG) residing on the device that is administering the BIG-IP APM system.

Procedures

Modifying the BIG-IP APM access profile login page logo image

Impact of procedure: The original access profile login page no longer displays the default F5 logo.

  1. Log in to the Configuration utility.
  2. Navigate to the Quick Start page:

    13.0.0 and later

    Access > Profiles / Policies > Customization > Quick Start/Basic

    11.x - 12.x

    Access Policy > Customization > Quick Start/Basic

  3. Under Access Profiles, in the Available Profiles list, click the access profile that you want to have a custom logo image.
  4. In the Select Language list, click the language preference of the access profile.

    Note: To replace the login page logo image for all languages, click All Languages.

  5. To maintain the positioning of the logo, leave the Page Alignment and Page Width settings at the default settings of Center and 100%, respectively.
  6. Click Upload New Image.
  7. From the local device, select the replacement logo image and click Open.

    The new logo image is uploaded to the BIG-IP APM system.

  8. To save the new image, click Save.

    Note: To see the new logo image, some users may need to clear their browser cache before they log in.

For more information about customization of the BIG-IP APM system, refer the manuals in the Supplemental Information section.
