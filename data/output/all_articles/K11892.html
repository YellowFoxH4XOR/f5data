Known Issue

This is the result of a known issue. In rare circumstances, TMM may stop responding and produce a core dump file when data is appended to the session table using the table append iRule command.

F5 Product Development tracked this issue as ID 242841 and ID 328280 (formerly CR135005), and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3402.0-HF2, issued for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.
