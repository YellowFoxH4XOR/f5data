K12659: The BIG-IP ASM may write misrepresentative startup messages to the /var/log/asm file

Known Issue

This is the result of a known issue. When the internal communication channels between sub-processes of the BIG-IP ASM system open and close, the BIG-IP ASM system may incorrectly log a message to the /var/log/asm/ file, similar to the following example:

Feb 28 23:46:56 10.91.111.248 notice dcc[5690]: 01310022:5: ASM started successfully

Although the content of this message is the same as content that the system logs when the entire BIG-IP ASM system starts up, in this instance the message does not reflect a complete ASM start-up event.

You can verify whether the logged event is valid by comparing the time stamp of the log message against the uptime of the BIG-IP ASM process. To do so, perform the following procedure.

  1. Log in to the BIG-IP ASM command line.
  2. To determine the current system time, type the following command to determine the current system time and note the result:

    date

    The system displays a value that appears similar to the following example:

    Tue Mar 1 14:03:25 PST 2011

  3. To determine the BIP-IP ASM process uptime, type the following command and note the result.

    bigstart status asm

    The system displays a value that appears similar to the following example:

    asm run pid 3323) 19 hours

  4. Take the current system time displayed in step two and subtract the number of hours displayed for the BIP-IP ASM uptime in step three. If the resulting time precedes the time stamp on the log message you received, then you can conclude that the message does not correlate to a full BIG-IP ASM system start-up event and is likely the result of the known issue described in this article.

    For example, using the previous data:

    • Take the system time: Mar 1 14:03:25
    • Subtract the uptime: 19 hours
    • The result is: Feb 28 20:03:25

The time stamp on the message is Feb 28 23:46:56. Since the time stamp is later than the resulting time you calculated (Feb 28 20:03:25), you can conclude that the message does not correlate to a full BIG-IP ASM start-up event.

F5 Product Development tracked this issue as ID 336173 and it was fixed in BIG-IP ASM 10.2.1. For information about upgrading, refer to the BIG-IP ASM release notes.
