Description

APM Kerberos SSO fails in some environments after upgrading to v14.x or newer

 

Environment

BIG-IP APM 14.x and newer

Kerberos SSO used in a multi-forest environment

 

Cause

The kerberos library used in BIG-IP was upgraded in v14.1 and requires modified configuration for cross realm support.

 

Recommended Actions

Modify the account name setting in the Kerberos SSO object to match the sAMAccountName of the delegation account in Active Directory.

None
