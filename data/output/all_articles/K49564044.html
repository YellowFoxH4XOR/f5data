Description

When you have a non-F5 optical module plugged in to the F5, an Unsupported Optic alert will be displayed on the LCD panel.

Running tmsh show sys alert command, it shows the same:
root@(bigip1)(cfg-sync Standalone)(Active)(/Common)(tmos)# show sys alert

----------------------------------------------------------------
Sys::LCDAlerts
Slot Timestamp Priority Id Description
----------------------------------------------------------------
0 03/23/22 01:56:57 warning 0x12c0021 Unsupported Optic.


You can clear this alert/alarm following the steps in K11094 but it will continue to persist even after rebooting the device.

Environment

  • non-F5 optical module
  • LCD alerts

Cause
None

Recommended Actions

Note: While F5 doesn't recommend using non-F5 optics on F5 devices as per K8153: F5 support of third-party hardware components, the following procedure is provided to give you the option to disable the Unsupported Optic alert on the LCD panel. Please note that disabling this alert might possibly affect the F5 device's ability to recognize an F5-supported optic, should you decide to switch to an F5-branded optic in the future.

1. Log in to the command line of the BIG-IP.

2. Backup the existing user_alert.conf file. You can use the below command:
    # cp /config/user_alert.conf /config/user_alert.conf.bak

3. Open the /etc/alertd/alert.conf file and copy the following alerts:

alert BIGIP_BCM56XXD_BCM56XXDERR_NON_F5_OPTICS {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.162";
    lcdwarn description="Unsupported Optic." priority="0"
}
alert BIGIP_BCM56XXD_BCM56XXDERR_DISABLE_NON_F5_OPTICS {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.165";
    lcdwarn description="Unsupported Optic." priority="0"
}
alert BIGIP_BCM56XXD_BCM56XXDERR_DISABLE_NON_F5_OPTICS {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.165";
    lcdwarn description="Unsupported Optic." priority="0"
}

4. Using a text editor of your choice, open the user_alert.conf file and add the lines you copied in step #3 above.

5. Comment out the "lcdwarn" lines in the 3 alerts. They should look like this:

alert BIGIP_BCM56XXD_BCM56XXDERR_NON_F5_OPTICS {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.162";
#    lcdwarn description="Unsupported Optic." priority="0"
}
alert BIGIP_BCM56XXD_BCM56XXDERR_DISABLE_NON_F5_OPTICS {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.165";
#    lcdwarn description="Unsupported Optic." priority="0"
}
alert BIGIP_BCM56XXD_BCM56XXDERR_DISABLE_NON_F5_OPTICS {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.165";
#    lcdwarn description="Unsupported Optic." priority="0"
}

6. Save the changes you made to the user_alert.conf file

7. Restart the alertd process using this command:
    # bigstart restart alertd
