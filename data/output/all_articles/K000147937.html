K000147937: How do I use the XC API to create, update, or delete single DNS Resource Records?

Description


This article explains how to use the F5 Distributed Cloud (XC) API to individually create, update, or delete DNS resource records (RRsets) within a DNS zone.
Customers may need to automate DNS record management or integrate DNS changes into their workflows using the XC API.

Environment

 

  • F5 Distributed Cloud (XC) DNS
  • API access with valid API Token
  • DNS zones configured in XC
  • Tenant shortname required for API endpoint construction
  • JSON payloads for record data

 

Cause


None

Answer/Recommended Actions

  1. Obtain an API Token for authentication (instructions here).
  2. Identify your XC Tenant short name and use it in the API endpoint URL.
  3. Prepare a JSON payload for the DNS record (example provided below).
  4. Use the following API endpoints and methods:
     
    • Create a DNS RRset:
      POST /api/config/dns/namespaces/system/dns_zones/{dns_zone_name}/rrsets/{group_name}
      Example curl command: 
      curl -H 'Content-Type: application/json' -H "Authorization: APIToken YOURTOKEN" https://TENANT_NAME.console.ves.volterra.io/api/config/dns/namespaces/system/dns_zones/example.com/rrsets/nico -X POST -d @zone.json
    • Update/Replace a DNS RRset:
      PUT /api/config/dns/namespaces/system/dns_zones/{dns_zone_name}/rrsets/{group_name}/{record_name}/{type}
      Example curl command: 
      curl -H 'Content-Type: application/json' -H "Authorization: APIToken YOURTOKEN" https://TENANT_NAME.console.ves.volterra.io/api/config/dns/namespaces/system/dns_zones/example.com/rrsets/nico/www/A -X PUT -d @zone.json
    • Delete a DNS RRset:
      DELETE /api/config/dns/namespaces/system/dns_zones/{dns_zone_name}/rrsets/{group_name}/{record_name}/{type}
      Example curl command: 
      curl -H 'Content-Type: application/json' -H "Authorization: APIToken YOURTOKEN" https://TENANT_NAME.console.ves.volterra.io/api/config/dns/namespaces/system/dns_zones/example.com/rrsets/nico/www/A -X DELETE
  5. Refer to the DNS Zone RRSet API documentation for full details.

Additional Information

  • Example JSON payload 

 

{
  "dns_zone_name": "example.com",
  "group_name": "name",
  "rrset": {
    "ttl": 180, 
      "a_record": {
        "name": "wwww",
        "values": [
          "10.10.10.10"
      ]
    },
    "description": "some description"
  }
}
