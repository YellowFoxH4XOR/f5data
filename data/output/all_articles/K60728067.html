Description

When viewing large number of Recourse Records (RRs) in GUI, high CPU could be seen.
This issue happens when you navigate to 

DNS  ››  Zones : ZoneRunner : Zone List

And search in a zone with large number of RRs.

Environment

  • GTM is provisioned
  • There are many RRs in BIND

Cause

None

Recommended Actions

To avoid this issue, please query only a portion of the RRs of the zone by default when visiting this GUI page
To recover from this issue, please restart httpd and tomcat process by following command:

bigstart restart httpd tomcat
