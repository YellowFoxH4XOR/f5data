K000150351: The BIG-IP system supports a maximum of four TACACS servers in its configuration

Type
Support Solution
Published
2025-03-12
Updated
2025-03-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.5
Source
https://my.f5.com/manage/s/article/K000150351

Description

The BIG-IP system support a maximum of four TACACS severs in its configuration. If more that four are defined, the fifth and subsequent servers will be skipped during authentication attempts. You may see the following error message in the /var/log/sercure logs: 

 

err httpd[<PID>]: pam_tacplus: maximum number of servers (4) exceeded, skipping

 

Environment

  • BIG-IP
  • Multiple TACACS servers configured

Cause

None

Recommended Actions

Ensure that no more than four TACACS servers are defined in the BIG-IP configuration.
