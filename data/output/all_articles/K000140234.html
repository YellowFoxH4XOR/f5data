Description

Follow the procedure in this article if you want to map certificates to SSL profiles on the BIG-IP.

Prerequisites

You have command line access to the BIG-IP system.

Procedures

If you want to list all SSL certificates and map those to SSL profiles or If you know the common name of your SSL certificate, such as such as www.example.com or simply the certificate configuration object name, you can use the commands below to find out what SSL profiles the certificate is used on.

  1. Log into the BIG-IP command line
  2. To see all SSL certificates in all partitions, enter the following command:
    tmsh -c "cd /; list sys file ssl-cert recursive subject"
  3. If you're looking for a specific certificate by common name, you can use the following syntax (both the configuration object name and common name are displayed):
    tmsh -c "cd /; list sys file ssl-cert recursive subject" | grep -B 1 <common name>
    For example:

    tmsh -c "cd /; list sys file ssl-cert recursive subject" | grep -B 1 www.example.com

    If you're looking for a specific certificate by configuration object name, you can use the following syntax:
    tmsh -c "cd /; list sys file ssl-cert recursive subject" | grep <object name>
    For example:

    tmsh -c "cd /; list sys file ssl-cert recursive subject" | grep example

  4. Then cross reference that list with the certificates in use on SSL profiles. To view all SSL profiles in all partitions, enter the following command:
    tmsh -c "cd /; list ltm profile client-ssl recursive cert" ; tmsh -c "cd /; list ltm profile server-ssl recursive cert"
  5. Use the configuration object name to find which SSL profile a specific certificate belongs to. Use the following syntax:
    (tmsh -c "cd /; list ltm profile client-ssl recursive cert" ; tmsh -c "cd /; list ltm profile server-ssl recursive cert") | grep <certificate configuration object name>
    For example:

    (tmsh -c "cd /; list ltm profile client-ssl recursive cert" ; tmsh -c "cd /; list ltm profile server-ssl recursive cert") | grep example
