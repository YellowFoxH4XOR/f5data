K11304: App Tunnel favorites may not work correctly through proxies

Topic

Static and Dynamic App Tunnel favorites may not work correctly if the client's browser is configured to send traffic to a proxy server. When a proxy server is configured, the proxy server settings can take precedence over the App Tunnel configuration, which will cause the App Tunnel favorite to fail. The client machine may send the App Tunnel traffic to the proxy server rather than the FirePass controller. When that happens, the proxy server sends the traffic to the target machine as the client rather than as the application. Consequently, the target machine does not know how to handle the traffic from a client and will not function correctly.

If your clients use a proxy server for all of their web traffic, you can allow them access to the target machine with either a Network Access favorite or a Portal Access favorite. For information about configuring Network and Portal Access favorites, refer to the FirePass Controller Administrator Guide.
