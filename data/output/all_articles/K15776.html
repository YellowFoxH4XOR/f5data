Known Issue

If you install the BIG-IP Edge Client, the Windows 8.1 system may fail.

This issue occurs when all of the following conditions are met:

  • You installed, and then uninstalled the BIG-IP Edge Client on a Windows 8.1 device.
  • You attempt to reinstall the BIG-IP Edge Client on a Windows 8.1 device.

Impact

If you attempt to reinstall the BIG-IP Edge Client, the Windows operating system fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you reinstall the BIG-IP Edge Client, the Windows 8.1 device displays a blue screen and becomes unresponsive.

Workaround

To work around this issue, you must first uninstall the BIG-IP Edge Client VPN adapter before attempting to reinstall the BIG-IP Edge Client. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Windows 8.1 device.
  2. Click the Settings icon.
  3. Navigate to PC Info > Device Manager.
  4. Select View > Show hidden devices.
  5. Expand Network adapters.
  6. Right-click F5 Networks VPN Adapter.
  7. In the pop-up menu, select Uninstall.
  8. In the window that follows, to delete the driver software for this device, check Delete.
