Known Issue

The BIG-IP GTM FTP monitor checks only the first 3 bytes in the status code, and does not account for the hyphen character for multi-line replies. As a result, the BIG-IP GTM FTP monitor does not correctly process multi-line replies.

This issue occurs when all of the following conditions are met:

  • The BIG-IP GTM system is monitoring a BIG-IP Virtual Server using an FTP monitor.
  • The FTP server status-code response spans multiple lines.

An FTP reply consists of a three-digit status code followed by some text. In the event that the text is longer than one line, RFC640 allows the server to respond with a status code followed by a hyphen ( - ) character. The hyphen character is a signal to the client to expect an additional line and text. For example, the following output shows an FTP command-reply sequence where the server sends a multi-line reply:

$ ftp ftp.bogusftp.com
Connected to bogusftp.com.
220 bogusftpd.com BogusFTPd Server (licensed copy) ready.
Name (ftp.bogusftp.com:anonymous): ftp
331 Guest login ok, send your complete e-mail address as password.
Password:
230-You are user #4 of 16 simultaneous users allowed.
230-
230 Logged in anonymously.
Remote system type is UNIX.
Using binary mode to transfer files.

Impact

This issue may cause the FTP monitor to incorrectly mark resources down.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The system logs error messages to the /var/log/gtm file that appear similar to the following example:

    gtmd[1269]: 011ae0f2:1: Monitor instance FTP 10.10.10.1:21 DOWN --> UP from 192.168.2.1 (state: success)
    gtmd[1269]: 011ae0f2:1: Monitor instance FTP 10.10.10.1:21 UP --> DOWN from 10.1.1.2 (state: timeout)
    gtmd[1269]: 011ae0f2:1: Monitor instance FTP 10.10.10.1:21 DOWN --> UP from 10.1.1.2 (state: success)
    gtmd[1269]: 011ae0f2:1: Monitor instance FTP 10.10.10.1:21 UP --> DOWN from 10.1.1.2 (state: timeout)
    gtmd[1269]: 011ae0f2:1: Monitor instance FTP 10.10.10.1:21 DOWN --> UP from 10.1.1.2 (state: success)

  • The BIG-IP virtual server frequently changes state.
