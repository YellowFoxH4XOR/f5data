Description

After adding a blade to a chassis, guests do not start and display a message similar to the following on the vCMP host guest list:

Waiting for product image (BIG-IP 13.1.0.4)

Note: BIG-IP version in the above message may differ depending on your configuration.

Environment

  • VIPRION
  • vCMP

Cause

Base image for guest is missing from the system.

After adding a new blade, the guest will be replicated to the new blade if configured to run on that slot. The system will first attempt to install the base image, even if the guest is currently active on a different software version. If the base image is missing, installation cannot progress until it is added.

Note: By default, guests run on all available blades.

Recommended Actions

  1. Determine which image or images are missing by reviewing the vCMP host guest list.
  2. Download the missing images from downloads.f5.com.
  3. Upload the missing images to the vCMP host under System >> Software Management >> Image List, or to the /shared/images directory.

After completing the above steps, the VIPRION will begin replicating the vCMP guest to the new blade. This process may take some time, and you can monitor the progress with the tmsh show vcmp guest command on the host.
