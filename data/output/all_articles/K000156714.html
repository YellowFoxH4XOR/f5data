Description

This article shows an example of how you can use iRules to detect problem conditions and trigger a diagnostic tmm core dump.

 

Environment

A tmm diagnostic corefile can provide good information about the conditions of a fault or unexpected behavior. It can provide the stack trace of the last part of code that was being executed, and it provides a snapshot of the memory state when the core file was dumped.

 

However, some problem conditions can come and go very quickly. For example, when tmm seems to stall or stop processing a connection, the connection will eventually time out and will be deleted. By that time, the problem condition that shows why the connection was stuck would have gone away, even if you produce a diagnostic core manually ( as described in K15569543 ).

 

For some of these problems, you might be able to use an irule to detect the problem condition and trigger a core dump.

 

The following iRules allow you to trigger a tmm core dump by issuing the "DIAG::panic {panic!}" TCL command.

 

Syntax for DIAG commands:

 

DIAG::panic <message>

-> Cores tmm and never returns

 

DIAG::error <message>

-> Returns a TCL error

 

Example

In this example, the iRule tries to detect if there is any HTTP response after a certain timeout, and triggers a core if there is no response.

# iRule to trigger a core dump when there is no HTTP response after a POST message to /my.policy_host

when HTTP_REQUEST {
  if { [HTTP::uri] starts_with "/my.policy_host" }{
    if { [HTTP::method] equals "POST" }{
      set connid "[IP::client_addr]:[TCP::client_port]"
      set pktnum 0
      log local0. "$connid URI: [HTTP::uri] Content-Length: [HTTP::header content-length]"
      set cl [HTTP::header "Content-Length"]
      HTTP::collect $cl

      set monitor_id [\
        after 5000 {
        log local0. "after timer $connid HTTP::collect collected length: [HTTP::payload length]"
        # If HTTP::payload is still empty after 15 seconds, trigger a diagnostic panic
        if {[HTTP::payload] < $cl} {
          log local0. "$connid PANIC: HTTP::collect has been blocked for more than 15 seconds!"
          # Trigger the diagnostic panic
          set crash "DIAG::panic {panic!}"
          eval $crash
          }\
        }\
      ]
    }
  }
}

when HTTP_REQUEST_DATA {
  set payload [HTTP::payload]
  # Log the payload for debugging
  set max [string length [HTTP::payload]]
  log local0. "$connid Received payload $max: $payload"
  for {set i 0; set j 0} {$i < $max} {incr i 900} { 
     set j [expr {($i + 900) - 1}] 
     log local0. "$connid [string range [HTTP::payload] $i  $j]" 
  } 
  HTTP::release
}

when HTTP_RESPONSE {
    set svrconnid "[IP::client_addr]:[TCP::client_port] -> [IP::server_addr]:[TCP::server_port]"
    if {[info exists monitor_id]} {
        # log local0. "$svrconnid Canceling after script with id $monitor_id"
        after cancel $monitor_id
    }
}
