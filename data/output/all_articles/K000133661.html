K000133661: How to change the instance type in AWS of a running BIG-IP VE

Type
Support Solution
Published
2023-04-27
Updated
2023-04-27
Applies to
  • Public Cloud
  • Amazon Web Services
Source
https://my.f5.com/manage/s/article/K000133661

Description

Migrating an existing AWS BIG-IP VE instance to a different supported instance type.

 

Environment

  • BIG-IP VE
  • AWS

Cause

Behavior by design

 

Recommended Actions

Prerequisites

  • AWS CLI installed and set-up.
  • Ensure sufficient permission to perform the following actions
  • Please read and understand the articles listed in 'Related Content section' before making any changes

1. Check the instance information

 

aws ec2 describe-instances --filters "Name=instance-type,Values=m5.large" --query "Reservations[*].Instances[*].{PublicIP:PublicIpAddress,Name:Tags[?Key=='Name']|[0].Value,Status:State.Name,InstanceID:InstanceId,InstanceType:InstanceType}" --output table

| i-0611713b4dd07315d | m5.large  | Big-IP: Girireeprocase | 52.20.53.175 | running |

2. Stop the instance

aws ec2 stop-instances --instance-ids i-0611713b4dd07315d

3. Verify the instance status

aws ec2 describe-instances --filters "Name=instance-type,Values=m5.large" --query "Reservations[*].Instances[*].{PublicIP:PublicIpAddress,Name:Tags[?Key=='Name']|[0].Value,Status:State.Name,InstanceID:InstanceId,InstanceType:InstanceType}" --output table
 

----------------------------------------------------------------------------------------------

|                   DescribeInstances                  |

+----------------------+---------------+--------------------------+---------------+----------+

+----------------------+---------------+--------------------------+---------------+----------+

 

4. Change the instance type to one of the supported instance listed here.

aws ec2 modify-instance-attribute --instance-id i-0611713b4dd07315d --instance-type r4.large

5. Start the instance

aws ec2 start-instances --instance-ids i-0611713b4dd07315d                                                                        

 

6. Verify the instance type

aws ec2 describe-instances  --query "Reservations[*].Instances[*].{PublicIP:PublicIpAddress,Name:Tags[?Key=='Name']|[0].Value,Status:State.Name,InstanceID:InstanceId,InstanceType:InstanceType}" --output table

| i-0611713b4dd07315d |  r4.large  | Big-IP: Girireeprocase | 52.20.53.175 | running |
