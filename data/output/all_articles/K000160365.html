K000160365: GUI inaccessible after BIG-IQ upgrade from 8.4.0 to 8.4.1

Type
Support Solution
Published
2026-03-16
Updated
2026-08-03
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.1, 8.4.0
Source
https://my.f5.com/manage/s/article/K000160365

Description

The web UI is not reachable after upgrade from BIG-IQ 8.4.0 to 8.4.1. A browser may indicate a message that it cannot connect

Environment

BIG-IQ

Cause

Bug ID 2228901 BIG-IQ upgrade to 8.4.1 breaks single-NIC deployments causing UI access loss

Answer/Recommended Actions

  1. Boot back to the 8.4.0 volume:tmsh reboot volume HD1.x
  2. Delete the 8.4.1 upgrade volume:tmsh delete sys software volume HD1.x
  3. Force disable single-NIC auto-detection before initiating the upgrade:
    tmsh modify sys db provision.1nic value forced_disable
  4. Retry the upgrade to 8.4.1

Additional Information

None
