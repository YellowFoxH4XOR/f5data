K03961132: Preserving fragment identifier (#) during Access Policy completion

Type
Support Solution
Published
2025-07-01
Updated
2025-07-01
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K03961132

Description

  • The fragment identifier part of the URI gets lost when connecting via APM:
            original request:  https://host.domain/path/to/file#fragmentIdentifier=here
            redirect received by client after AP completion: https://host.domain/path/to/file
  • When connecting to APM, the client is redirected to /my.policy and at the end of Access Policy the client is redirected back to the original URI.
    If the first request contained a URI with fragment identifier (#), the browser will only send the URI part BEFORE the "#" and the redirect URI will be different from what the client originally entered. Normally this is not a problem, but some applications rely on the fragment identifier to be preserved.

Environment

Relevant environmental factors specific to the topic

  • BIG-IP APM
  • Browser access (any web browser)
  • First request contains "#" (fragment identifier)

Cause

The cause of the issue is that the fragment identifier only has meaning for the browser and is not send to the web server (or APM).

Recommended Actions

  • An iRule can be used to work-around this issue.

    when HTTP_REQUEST {
        if { ( ! [HTTP::cookie exists "X-FragID"] ) and ( ! [ ACCESS::session exists -state_allow -sid [HTTP::cookie MRHSession] ] ) and ! ( [HTTP::method] equals "POST" ) } {
            HTTP::respond 200 content {
     <!DOCTYPE html>
            <html>
                <body>

            <script type="text/javascript">
              var my_hash = window.location.hash.substring(0,1)
              if (my_hash = "#") {
                window.location.replace(window.location.pathname + window.location.search + encodeURIComponent(window.location.hash.substring(0,1)) + "C3169452" + window.location.hash.substring(1))
              } else {
                window.location.replace(window.location.pathname + window.location.search + encodeURIComponent(window.location.hash.substring(0,1)) + window.location.hash.substring(1))
              }
            </script>

                </body>
            </html> } Set-Cookie "X-FragID=yes;Max-Age=2;path=/"
        }
    }

    when ACCESS_SESSION_STARTED {
        if { [HTTP::uri] contains "%23" } {
            set firstmatch [string first "%23" [HTTP::uri]]
            set my_string1 [string range [HTTP::uri] 0 [expr {$firstmatch - 1}]]
            set my_string2 [string range [HTTP::uri] [expr {$firstmatch + 3}] end]
            ACCESS::session data set session.server.landinguri $my_string1#$my_string2
            }
    }
