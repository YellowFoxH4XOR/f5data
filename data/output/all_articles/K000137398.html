Description

In the show details tab of the Windows Edge Client the 8 character APM session ID is listed and can be used to report a problem session to the local APM administrator. How do I report a problem session with the MacOS Client?

Environment

  • APM Access
  • Network Access session from Edge Client

Cause

The display of the session ID seems to have been removed when the MacOS client was rewritten with version 7.1.9 

Recommended Actions

At the MacOS  terminal a user can run the command

grep 'session ID' ~/Library/Logs/F5Networks/edge.log

Additional Information

The logs will show the start time of recent sessions

2023-10-27,21:10:14:560, 2361,20656,edge, 48, /SessionController.mm, 380, SessionController, Starting pending session ID:, 658eefd2
2023-10-28, 8:08:30:244, 2361,20656,edge, 48, /SessionController.mm, 380, SessionController, Starting pending session ID:, df89f4eb

The APM network Administrator can use the session ID to lookup the details of the connection from the APM perspective.
The actual session ID is a longer string, that is regularly rotated as the session progresses, the 8 character value is just a 'pointer' to the full session. For more details see the Security section of the operations guide below.
