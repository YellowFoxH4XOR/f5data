K5038: BIG-IP may remove data from an HTTP 304 (redirect) message

Published

Topic

The HTTP standard (RFC2616) stipulates that 304 (redirect) messages should not contain a body. Some applications, such as Microsoft Sharepoint, are not compliant with RFC2616 and include a body in a 304 message. BIG-IP 9.0.0 through 9.0.5 and version 9.1.0 remove the body from these messages before passing them to the client. This may cause problems with non-compliant applications.

To provide greater compatibility with non-compliant applications, BIG-IP 9.1.1 and later versions of the BIG-IP 9.1.0 software branch, and BIG-IP 9.2.0 and later versions of the BIG-IP 9.2.0 software branch, pass HTTP 304 messages that contain a body without modification to the messages.

F5 Product Development tracked this change in behavior as CR47663, CR50997, and CR51267. For information about upgrading, refer to the BIG-IP LTM Release Notes.
