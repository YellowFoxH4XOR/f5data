Known Issue

Note: This issue only affects the ARX500 platform.

This is the result of a known issue. When a virtual server configured on VLAN 1 is deleted, the IP address of the virtual server is not completely removed from the ARX system. The IP address remain in the ARP table, and is visible in the output of the show arp all and show fastpath resources commands.

F5 Product Development tracked this issue as ID 38186, and it was fixed in ARX versions 5.1.7 and 5.2.0. For information about upgrading, refer to the ARX release notes.

Additionally, this issue was fixed in ARX version 5.1.5 hotfix 2. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

Workaround

To completely remove the IP address of the deleted virtual server, reboot or failover the ARX system.
