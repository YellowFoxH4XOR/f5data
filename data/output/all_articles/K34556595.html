Topic

You should consider using this procedure under the following condition:

  • You want to manage login failures for a local user account authenticated by the BIG-IP system.

Description

With the secure password policy, you can deny access to a user after a specified number of failed authentication attempts. You can enable this feature by specifying a value for the Maximum Login Failures setting in the secure password policy. For more information about configuring the Maximum Login Failures setting, refer to K15497: Configuring a secure password policy for the BIG-IP system (11.x - 16.x).

This article discusses how you can view and reset the locked-out user account to re-enable the access for the user.

Note: The administration and root accounts are excluded from the Maximum Login Failures setting.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the Configuration utility with administrator credentials.
  • You have TMOS Shell (tmsh) access with administrator credentials to your BIG-IP system.
  • (BIG-IP 15.x and later) You have not enabled the BIG-IP system to automatically reinstate users after a configured number of seconds. For more information, refer to K15497: Configuring a secure password policy for the BIG-IP system (11.x - 16.x).

Procedures

Resetting login failures using the Configuration utility

To reset login failures using the Configuration utility, perform the following procedure:

Impact of procedure: Before you reset the login failures of a user account, you may want to perform an evaluation on the cause of login failures on the user account and ensure that the user is aware of the secure password policy enforcement.

  1. Login to the Configuration utility.
  2. Navigate to System > Users > User List.
  3. You can review the Locked Out column to find out which user has reached the maximum login failures enforced on the BIG-IP system.
  4. To reset the login failures, select the check box next to the user account name. Repeat this step if you have more than one user account to reset the login failures.
  5. To reset the failure counter and unlock the selected user(s), click Unlock.

Resetting login failures using tmsh

To use tmsh to reset login failures, perform the following procedure:

Impact of procedure: Before you reset the login failures of a user account, you may want to perform an evaluation on the cause of login failures on the user account and ensure that the user is aware of the secure password policy enforcement.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To view the list of user(s) with login failures, type the following command:

    show /auth login-failures

  3. Review the Locked out column to find out which user has reached the maximum login failures enforce on the BIG-IP system.
  4. To reset the login failures and unlock the user(s), use the following command syntax:

    reset-stats /auth login-failures <User1> <User2> ...

    For example, to reset the user account name myuser1, type the following command:

    reset-stats /auth login-failures myuser1

    Optional: If you need to reset more than one user account, leave a space between the desired user account names in the reset-stats command.
