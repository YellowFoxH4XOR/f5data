Description
You want to use F5-cloud-libs onboard.js script to license BIG-IP VE using the FCP license on the BIG-IQ.

Environment

  • BIG-IQ VE
  • BIG-IP VE
  • F5-Cloud-libs

Cause
It is not obvious which options are needed to successfully license a BIG-IP device from a BIG-IQ with an FCP license .

Recommended Actions
The example below is one continuous line of code. For FCP licenses it is important to set the following parameters:
 --unit-of-measure yearly
--license-pool-name This is the name of the FCP pool on the BIG-IQ
--sku-keyword-1 This is the first part of the license type / name under the FCP pool
--sku-keyword-2 This is the second unique part of the license type / name under the FCP pool
--no-unreachable This ensures the license type is not set to unreachable

f5-rest-node /config/cloud/f5-cloud-libs/scripts/onboard.js -o /var/log/onboard.log --no-reboot --host localhost --user temp_admin --password temp_admin 
--hostname test-hostname.example.com --license-pool --license-pool-name FCP CAT --sku-keyword-1 VNF2 –sku-keyword-2 16 --unit-of-measure yearly 
--big-iq-host 10.10.10.33 --big-iq-user admin --big-iq-password 'xxxx' --big-ip-mgmt-address 10.10.10.110 --no-unreachable --cloud KVM
