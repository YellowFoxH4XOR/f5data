Known Issue

The system does not save the security policy description and enforcement mode when you deploy the security policy from a template.

This issue occurs when all of the following conditions are met:

  • You modify an existing security policy by populating the Security Policy Description field and setting the Enforcement Mode to Blocking.
  • You then save the policy as a template by selecting the policy in the Application Security > Security Policies > Active Policies page and clicking Save as Template.
  • You create a new HTTP Class and then create a new security policy using the template you just saved.

Impact

The description is not saved to the new security policy, and the Enforcement Mode is changed to Transparent.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Security policies created using customized templates do not retain the description text.
  • Security policies are created in Transparent mode when you use customized template.
