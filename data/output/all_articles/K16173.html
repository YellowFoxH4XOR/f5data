Known Issue

Deleting a virtual server does not delete the accompanying ZoneRunner Type A resource record (RR).

Note: When a wide IP is created, the BIG-IP GTM system also creates a Type A RR for each virtual server in the GTM pool.

This issue occurs when all of the following conditions are met:

  • From a BIG-IP GTM server object, you discover or add a virtual server.
  • You create a BIG-IP GTM pool that contains the virtual server.
  • You create a wide IP that contains the pool.
  • You delete the virtual server from the BIG-IP GTM server object.

Impact

The BIG-IP GTM system responds to DNS queries using the ZoneRunner RR of the deleted virtual server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP GTM system responds to client DNS queries using the RR of a deleted virtual server.

Workaround

To work around this issue, you can delete the ZoneRunner Type A RR. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Locate the ZoneRunner RR list by going to DNS > Zones > ZoneRunner > Resource Record List.
  3. From the Type menu, select A.
  4. Select Search.
  5. Under RDATA, locate the IP address of the deleted virtual server.
  6. Select the check box next to the Name for the IP address.
  7. Select Delete.
