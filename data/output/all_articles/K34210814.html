Description

Cipher Rule and Cipher Group have been configured and applied to a Server SSL profile.

According to the rule audit, this should send only a small number of cipher suites.

Observing a large number of cipher suites in Client Hello packets towards pool member; the BIG-IP appears to be ignoring the configuration of the Cipher Group.

Environment

  • HTTPS
  • Server SSL profile

Cause

Captured Client Hello packets are from a HTTPS monitor - which does offer a lot of cipher suites by default.

Recommended Actions

Capture the virtual server traffic in order to determine which cipher suites are offered by the BIG-IP. Excluding monitor traffic, this should match what is configured in the Server SSL profile.
