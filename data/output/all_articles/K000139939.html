Description

Is license re-activation required prior to a F5OS hypervisor software upgrade?

Environment

  • F5OS hypervisor software upgrade
  • License re-activation

Cause

N/A

Recommended Actions

It's currently not required to re-activate the license when upgrading only the F5OS hypervisor software.

Additional Information

The tenants pull the license it uses from the host. The Service Check Date of that license must still comply with requirements for the tenant version you upgrade to. Thus, if you have not reactivated license on the hypervisor, and the Service Check Date on the hypervisor/host does not align with what is needed for the new tenant version then the upgrade of the tenant will fail.

A good practice would be to re-activate the license prior to every F5OS software upgrade, and to check the date of the license prior to any upgrade of a tenant. K7727: License activation may be required before a software upgrade for BIG-IP

Important: It is best to shutdown all tenants the F5OS has before you proceed to activate/re-activate the license on the F5OS hypervisor software.
