Known Issue

This is the result of a known issue. If you configure a Microsoft Terminal Server favorite and clear the Enable persistent cache (bitmap caching) check box, bitmap caching is not disabled. The correct behavior is for FirePass to disable bitmap caching when the Enable persistent cache (bitmap caching) check box is cleared. 

The Terminal Server bitmap caching feature was introduced in FirePass version 6.0.3, and it is enabled by default. Bitmap cache files are stored in the folder %HOMEPATH%\Local Settings\Application Data\Microsoft\Terminal Server Client\Cache on the client system.
 
Note: Terminal Server favorites are configured on the Application Access: Terminal Servers: Resources.
 
Note: The bitmap caching feature applies to the ActiveX version of the Microsoft Terminal Server (RDP) client. The Java client does not support bitmap caching.
 
F5 Product Development tracked this issue as CR118797 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-603-2.1, which has been issued for FirePass 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.
