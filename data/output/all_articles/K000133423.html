Description

System suffers from network connectivity issues due to the nf_conntrack values.

/var/log/kern.log show the message:

kernel: nf_conntrack: table full, dropping packet

 

Environment

  • i5800
  • 14.x.x
  • 15.x.x
  • 16.x.x
  • 17.x.x

 

Cause

You can check the maximum value with the following command:

cat /proc/sys/net/nf_conntrack_max

[root@-bigip:Active:Standalone] config # cat /proc/sys/net/nf_conntrack_max

131072

 

Recommended Actions

nf_conntrack_max: This value defines the maximum size of a netfilter connection tracking table. This table keeps a record of all live connections and deletes them when a connection is closed.

We can see the versions the default value is 131072 for versions above 14.x.x and later.
