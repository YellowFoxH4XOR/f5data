K000151787: Encrypting BGP neighbor password

Type
Support Solution
Published
2026-08-31
Updated
2026-08-31
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000151787

Description

The neighbor password is showing as plain text in the configurations files. You would like to encrypt the BGP neighbor password so it's will be encrypted and no longer shown as a plain text.

Environment

  • BIG-IP LTM
  • BGP dynamic routing

Cause

By default, BGP neighbor passwords are stored in clear text in the BIG-IP configuration. The platform does not natively encrypt or obfuscate.

Recommended Actions

In order to encrypt the password, we need to add "service password-encryption" to the configuration using the steps below:

1. SSH to the device via the CLI

2. Run the below commands:

# imish

# enable

# config terminal

# service password-encryption

 

3. Make sure to be on the router level in order to configure the password:

# router bgp <AS Number>

 

4. To configure the password:

# neighbor x.x.x.x password <password>

 

5. After configuring the password verify that it's encrypted using the below command:

# show running-config

 

- The password should appear same as the below example:

neighbor x.x.x.x password 1 iSVmJh0URN/LszbCEo38RlyT8aQtRF9e

 

- Where "1" indicates that the password is stored in an encrypted format, this is automatically set by the system when "service password-encryption" is enabled in your configuration.

 

6. Exit configuration mode and save the changes:

# end

# write
