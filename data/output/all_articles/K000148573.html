Description

  • I want to request a WAF assessment, what do I need to do?

Environment

  • F5®  Distributed Cloud (XC) Managed WAAP
  • App Firewall
  • HTTP Load Balancer

Cause

None

Answer/Recommended Actions

Background information:

  • A WAF Violation Assessment is a group of violations that are filtered and submitted for evaluation to XC Support to determine whether violations need to be tuned or resolved
  • This enables both you (the customer) and XC Support to begin focusing on violations that match very specific criteria. For example, if violations occur from a source IP address that you find acceptable, you can exclude it from the query
  • The exact details of the query you (the customer) provide during the refinement process are saved and sent with your assessment request to our XC Support analysts to evaluate

Assessment Process Overview:

  • The Assessment process in Distributed Cloud is designed to focus on the heavy hitting false positive violations and clear those up prior to moving to blocking mode
  • The first pass is meant to clean up the "big-ticket items" that generate false positives. This helps clean up the violation logs and allows for an easier review of violations that may have smaller counts to stand out in future passes/assessments
  • After the first pass is completed, it is recommended to wait at least one week before another pass is performed

Assessment Request Limitations:

  • We kindly request you to submit one ticket per Load Balancer. This approach ensures better tracking and enables us to provide more focused and accurate recommendations.

  • Only F5®  Distributed Cloud (XC) Managed WAAP Customers are eligible for an Assessment, Self-Service Customers will not be provided with a WAF Assessment
  • XC Support will only assess the last 7 days of WAF Violation Logs
  • This is to allow XC Support to compare violation traffic to traffic that did not trigger a violation (due to the Access Logs having a 7-day retention period)
  • Custom report format requests will not be accepted (e.g. CSV, Excel Spreadsheets, etc)

To request a WAF Assessment from XC Support, please submit a ticket following either of these options:

Option 1 - Open a Ticket with XC Support and provide the following information:

  1. Requested time range for assessment (we will only be accepting assessment requests looking at the last 7 days max, this is to allow XC Support to compare violations to requests within the Access Logs)
  2. Name of Load Balancer to assess
  3. Any other filters for traffic you would like to have assessed

Option 2 - Filter for the desired logs within the Distributed Cloud Console and Share the URL with the XC Support:

  1. Go to the Web App and API Protection Tile in the Console
  2. Under Overview, Select Security
  3. Select the Load Balancer you with to have assessed
  4. Select the Security Analytics Tab
  5. Add any Filters you wish to have as part of your assessment
  6. After applying your filters, copy the URL from your browser's address bar and share it with the SOC via a Ticket
