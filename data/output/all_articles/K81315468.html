K81315468: AGC 6.0 API Protection fails with multiple custom providers BIG-IP APM 15.1.0

Type
Support Solution
Published
2020-06-30
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.0
Source
https://my.f5.com/manage/s/article/K81315468

Description

Cannot deploy API Protection through the APM Guided Configuration (ACG) with multiple custom providers 

  • Error: transaction failed:01071b42:3: URI is required for request 'scope-data-request'

Environment

With multiple custom providers, one of them being custom, will result in an error when deploying API Protection

  • ACG v6.0

Cause

This is caused by a known issue where you cannot deploy API Protection through ACG with multiple custom providers

Recommended Actions

  1. Deploy the API Protection through ACG with a single provider
  2. Disable Strict-Updates
  3. Manually add additional custom providers

Additional Information
