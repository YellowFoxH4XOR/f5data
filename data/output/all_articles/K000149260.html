Note: Known issues with "resultReference" file use:
  1. The syntax of the resultsReference results file name is "bulk-results-${taskID}.json" and allows for easy automation
  2. The resultsReference results file is appended to during the creation of the commands[] sub-task(s)
  3. The resultsReference results file will contain an incomplete json structure prior to all commands[] sub-task(s) creation
  4. The resultsReference results file uses the same download API endpoint as other Advance WAF downloads
