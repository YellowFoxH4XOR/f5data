Topic

This article explains F5OS-C, F5OS-A, BIG-IP Next, BIG-IP, and BIG-IQ software file verification using the MD5 checksum. For information about BIG-IP image verification using signature (SIG) and privacy enhanced mail (PEM) files, refer to K24341140: Verifying BIG-IP software images using SIG and PEM files.

Note: F5 recommends using SIG and PEM files to perform software image verification.

You should consider using this procedure under any of the following conditions:

  • You want to verify the integrity of the downloaded F5 software file using the md5sum utility on any of the following systems:
    • BIG-IP
    • BIG-IQ
    • F5OS
    • Linux
  • You want to verify the integrity of the downloaded F5 software file using the CertUtil utility on a Windows system.
  • You want to verify the integrity of the downloaded F5 software file using the md5 utility on a Mac OS system.

Description

When you download software from F5, F5 recommends that you download the associated MD5 checksum file along with the F5 software. The F5 software may be an installation, an upgrade or a firmware in the format of iso, ova, im, tgz, or zip. After downloading the software file and the associated MD5 checksum file, and before using the downloaded files, F5 recommends that you test the integrity of the downloaded files.

For example, if you plan to upgrade to BIG-IP 17.0.0 and you have downloaded the BIGIP-17.0.0-0.0.22.iso file, you should also download the corresponding BIGIP-17.0.0-0.0.22.iso.md5 MD5 checksum file.

Note: Software files, point releases, and patches on the MyF5 Downloads page have a corresponding MD5 checksum file that you can download along with the software. To access the MD5 file for a given software file or patch, select the software name from the product container list and download the MD5 file.

Important: To properly verify the MD5 checksum of the installation file, you must perform the verification procedure immediately after you download the F5 software files on the respective systems, but before you use the installation file to perform an installation. For more information about the changes that may occur to the BIG-IP ISO image and the MD5 value, refer to K11657: The size and MD5 value of a BIG-IP ISO image may change after performing a clean installation.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • If you are planning to perform this procedure on a BIG-IP, BIG-IQ, or F5OS system, you should ensure you have Advanced Shell (bash) access on these systems. For other systems, you should have access to the respective utilities on those systems, for example CertUtil on Windows, md5 on Mac OS, md5sum on Linux.
  • You have transferred the downloaded F5 software files and associated MD5 files to the respective system.

Procedures

The md5sum utility is included on the BIG-IP, BIG-IQ, and F5OS system, and may be used on the bash shell command line to verify the integrity of files after they have been transferred to the BIG-IP, BIG-IQ, or F5OS system. To verify the MD5 checksum of the downloaded F5 software files, you can perform one of the following procedures:

  • Using the md5sum --check command
  • Using the md5sum <filename> command
  • Optional: Verify the checksum on a Windows system
  • Optional: Verify the checksum on a Mac OS system

Using the md5sum --check command

To verify an MD5 checksum against the downloaded software file on a BIG-IP, BIG-IQ, F5OS, or a Linux system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP, BIG-IQ or Linux bash shell's command line prompt. For F5OS, log in as the root user.
  2. Change directories to the directory of the downloaded software file and the corresponding .md5 file.

    Note: When you import the files using the BIG-IP Configuration utility, change directories to /shared/images with the following command: cd /shared/images

  3. To check the integrity of the downloaded file using md5sum command against the .md5 file, use the following command syntax:

    md5sum --check <filename.md5>

    Note: The <filename.md5> and <filename.iso> files are required to be residing in the same directory. The installation file and the MD5 checksum file are of the same base file name.

    For example, to check the BIGIP-17.0.0-0.0.22.iso installation file against the BIGIP-17.0.0-0.0.22.iso.md5 file, enter the following command:

    md5sum --check BIGIP-17.0.0-0.0.22.iso.md5

    The output may appear similar to the following example:

    BIGIP-17.0.0-0.0.22.iso: OK

Using the md5sum <filename> command

To verify the MD5 checksum of the downloaded F5 software files on a BIG-IP, BIG-IQ, F5OS, or a Linux system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP, BIG-IQ or Linux bash shell's command line prompt. For F5OS, log in as the root user.
  2. Change directories to the directory of the downloaded software file and the corresponding .md5 file.

    Note: When you import the files using the BIG-IP Configuration utility, change directories to /shared/images with the following command: cd /shared/images

  3. To check the integrity of the downloaded file using the md5sum command against the downloaded file, use the following command syntax:

    md5sum <filename>

    For example, run the md5sum command against the BIGIP-17.0.0-0.0.22.iso file by typing the following command:

    md5sum BIGIP-17.0.0-0.0.22.iso

    The output may appear similar to the following example:

    6b3ea069e638edc1f95ab0c56859c181 BIGIP-17.0.0-0.0.22.iso

  4. To display the downloaded MD5 checksum file, use the following command syntax:

    cat <filename.md5>

    For example, if the downloaded MD5 checksum file is BIGIP-17.0.0-0.0.22.iso.md5, enter the following command:

    cat BIGIP-17.0.0-0.0.22.iso.md5

    The output may appear similar to the following example:

    6b3ea069e638edc1f95ab0c56859c181 BIGIP-17.0.0-0.0.22.iso
