Known Issue

A Windows stop error (Blue Screen of Death [BSOD]) appears during an established network access VPN session. 

This issue occurs when all of the following conditions are met:

  • Your local device is running the Microsoft Windows operating system.
  • The BIG-IP Edge Client and/or Edge Client browser components are installed.
  • You start Windows Driver Verifier Manager.
  • You attempt to establish a network access VPN session using the BIG-IP Edge Client or browser-based access.

Impact

The access session fails to establish, and the Windows device encounters a stop error.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Windows device presents a BSOD stop error.
  • You successfully run the Windows Driver Verifier when the access session is not started. 
  • You successfully establish an access session when the Windows Driver Verifier is not running.

Workaround

To work around this issue, if you must run Windows Driver Verifier Manager, do so only on testing and debugging computers that do not require a VPN access session when you start the system. 

Impact of workaround:  Performing the workaround should not have a negative impact on your system.

When using Driver Verifier, consider the following:
  • Microsoft recommends exercising caution when running the driver verifier as it may cause the computer to crash. Do so only on computers that you are using for testing and debugging. For more information including how to stop/reset Driver Verifier, refer to Driver Verifier on Microsoft.
  • Driver Verifier is not included with Windows 10 S and is not distributed as a separate download package. F5 recommends testing driver behavior in Windows 10 instead.
