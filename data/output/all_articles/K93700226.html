Description

The BIG-IP is not logging LTM changes like pool member health checks, pools, or virtual servers going up or down that are normally logged in /var/log/ltm

Environment

  • BIG-IP LTM
  • Remote HSL
  • Local logging

Cause

You have configured an HSL with a remote high-speed log destination, but, the publisher does not include any local destination.

Recommended Actions

Edit or create a new Log publisher and ensure you add a local destination with the steps below:

  1. On the Main tab, click System ›› Logs ›› Configuration ›› Log Publishers. The Log Publishers screen opens.
  2. Click Create or Edit the Publisher previously created.
  3. In the Name field, type a unique, identifiable name for this publisher.
  4. For the Destinations setting, select the previously created destination from the Available list and move the destination to the Selected list,  make sure you add a local destination as well.
  5. Click Finished or update.

For more information on HSL (log destination and publisher) configuration, refer to the Comparing remote logging and remote high-speed logging configurations section of K15521451: Log files and alerts | BIG-IP TMOS operations guide.

Additional Information

Options for step 4:

  • local-syslog: Causes the system to store log messages in the local Syslog database. When you choose this log destination, the BIG-IP Configuration utility displays the log messages in these categories: System, Local Traffic, Global Traffic, and Audit.
  • local-db: Causes the system to store log messages in the local MySQL database. When you choose local-db, the BIG-IP Configuration utility does not display the log messages.
