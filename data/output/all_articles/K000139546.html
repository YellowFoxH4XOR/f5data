Description

There is a log generated when you are doing a migration or loading the config into the device.

 

/Common/Persist_iRule:3: warning: [The following errors were not caught before. Please correct the script in order to avoid future disruption. "invalid IP address:persist_test"51 33][persist source_addr persist_test]

 

Upon reviewing the reported iRule:

ltm rule Persist_iRule {
when HTTP_REQUEST {         
    pool web_pool
    persist source_addr persist_test
}
}

 

Looking at the persistence profile mentioned in the iRule:

 

ltm persistence source-addr persist_test {
    app-service none
    defaults-from source_addr
    timeout 60
}

Environment

  • LTM
  • iRule
  • Persistence

Cause

This is due to a wrong syntax used for the source_addr persistence in the iRule.

Recommended Actions

The correct syntax for using source_addr in an iRule is:

 

persist source_addr [<mask>] [<timeout>]

 

In correspondence with the syntax and persistence profile, the correct iRule should be:

ltm rule Persist_iRule {
when HTTP_REQUEST {         
    pool web_pool
    persist source_addr 255.255.255.255 60
}
}
