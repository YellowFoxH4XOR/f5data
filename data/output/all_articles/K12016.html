Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator system fails to process client requests with a chunked body. When a client sends a request with a chunked body to a BIG-IP WebAccelerator virtual server, the system will calculate an incorrect content length, causing the body of the request to be stripped out on the way to the server. The pool member will receive a request containing the HTTP headers only, causing the request to fail.

F5 Product Development tracked this issue as ID 337530 and it was fixed in BIG-IP WebAccelerator 11.0.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, F5 Product Development has issued an engineering hotfix that resolves this issue for BIG-IP 10.2.0. To obtain this hotfix, contact F5 Technical Support, referencing this article number and ID 337530.

Workaround

You can work around this issue by using an iRule to bypass the BIG-IP WebAccelerator for client requests with a chunked body. For more information, refer to K10127: Bypassing the BIG-IP WebAccelerator with an iRule in version 10.x.
