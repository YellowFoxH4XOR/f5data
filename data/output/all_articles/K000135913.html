K000135913: Unable to add new device into DNS sync group with error - "Unable to find value_list"

Support Solution

Source

Description

The gtm_add script is able to run and it returns a "Done" message. However, the configuration from the older BIG-IP DNS device is not copied into the new one which ran gtm_add command.

The new BIG-IP DNS device contains error logs similar to:

01070151:3: Rule [/Common/test_irule] error: Unable to find value_list (Test-List) referenced at line 3: [class match [ IP::client_addr ] equals Test-List

01070151:3: Rule [/Common/test_irule] error: Unable to find value_list (Test-List) referenced at line 5: [class match [IP::remote_addr] equals Test-List

01071488:3: Remote transaction for device group /Common/dns_test_group to commit id 20 7263187523840361035 /Common/bigip_dns_02.test.com failed with error 01070151:3: Rule [/Common/pool_1.test.com] error: Unable to find value_list Test-List) referenced at line 5: [class match [IP::remote_addr] equals Test-List

Environment

  • BIG-IP DNS
  • Data Groups referred by iRules.

Cause

The configuration to be copied contain iRules referring(s) to a Data group that does not exist in the BIG-IP DNS configuration.

Recommended Actions

Before running gtm_add, please manually copy the Data Groups from the configuration of the older BIG-IP DNS system.
