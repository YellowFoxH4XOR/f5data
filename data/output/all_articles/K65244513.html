Known Issue

The Traffic Management Microkernel (TMM) may restart during iRules LX processing.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured to use the iRules LX feature.
  • During traffic processing, the connection flow closes before the remote procedure call (RPC) returns.

An RPC is used to facilitate communication between TMM and the Node.js processes. If the BIG-IP system is experiencing high traffic loads, the iRules LX plug-in may time out, causing the TMM process to exit.

Impact

Traffic processing is disrupted while the TMM process restarts. The BIG-IP system fails over to a standby system if configured for high availability (HA).

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM generates a core file to the /shared/core/ directory.
  • The iRules LX plugin is terminated, and a message similar to the following example is generated to the /var/log/ltm file:

    01220001:3: TCL error: /Common/plugin_example_ilx/rule_example_ilx <HTTP_REQUEST> - ILX timeout. invoked from within "ILX::call $ilx_init $method -timeout 100000"

  • Output of the tmsh show ilx plugin command shows that the iRules LX plugin extension has stopped. For example, output may appear similar to the following example:

      -------------------------------
      | Extension: ilx_example
      -------------------------------
      | Status                stopped
