Description

i2600 Series devices are experiencing random device hangs with nothing logged.  Device is completely inaccessible via ssh, GUI or console until after a full device power cycle.

Environment

  • i2600 Platform
  • Cisco Console Server - ISR4321/K9

Cause

The reason is that the Kernel experienced a fatal Panic when writing information to the serial console port due to a Null Pointer Reference. This appears to be an underlying CentOS issue which is tracked in Centos BugID14265 and currently does not have a root cause known or mitigation available. F5 tracks this issue with ID1076557.

Note: The above, Centos BugID, link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge

Recommended Actions

On Cisco Console server add the following command to the console port where BIG IP is connected:

no flush-at-activation
