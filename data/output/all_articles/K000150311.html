K000150311: Configuring Site Local Inside Interface on F5 Distributed Cloud App Stack Sites

Description

When deploying an App Stack site on VMware, users may encounter limitations regarding network interface configuration. Specifically, only a single network interface (Site Local Outside, SLO) is supported, and there is no option to add a second interface (Site Local Inside, SLI) such as eth1 for internal network segmentation. Attempts to select multi-NIC hardware profiles during App Stack site creation are not supported.

Environment

  • Product: F5 Distributed Cloud
  • Feature: App Stack Site
  • Deployment Type: VMware-based App Stack Site

Cause

App Stack is designed as a standard Kubernetes cluster and supports only a single network interface (SLO). Additional interfaces, such as SLI, are not supported.

Answer/Recommended Actions

  • App Stack sites support only the Site Local Outside (SLO) interface.
  • There is no supported method to add or configure a Site Local Inside (SLI) interface on an App Stack site.
  • Multi-NIC hardware profiles are not available for App Stack site creation.
  • For dual-interface configurations, deploy a Customer Edge (CE) site instead.

Additional Information

  • App Stack is intended for Kubernetes workload hosting and differs from CE deployments in networking capabilities.
  • CE sites support both SLO and SLI interfaces for network segmentation; App Stack sites do not.
