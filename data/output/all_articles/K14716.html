Known Issue

Configuring a BIG-IP GTM monitor timeout greater than 65535 may set an unexpected value.

This issue occurs when the following condition is met:

  • You configure a BIG-IP GTM monitor timeout with a value between 65536 and 86400.

Impact

The BIG-IP GTM monitors may timeout prematurely.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The resulting timeout value shown in the BIG-IP GTM configuration is different than the value you expected to see.

Workaround

To work around this issue, you can set the BIG-IP GTM monitor timeout value to 65535 or less.

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility as the admin user.
  2. Navigate to Global Traffic > Monitors.
  3. Click the monitor you would like to modify.
  4. Change the Timeout setting to a value of 65535 or less.
  5. Click Update.
