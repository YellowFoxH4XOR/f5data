Known Issue

The BIG-IP ASM bd process may restart when you attempt to log security violations remotely.

This issue occurs when all of the following conditions are met:

  • An FTP or SMTP profile with Protocol Security enabled is assigned to a virtual server.
  • A logging profile that is configured with remote logging is enabled for the virtual server.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from the BIG-IP ASM restarting. Systems configured for high availability (HA) may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to process traffic.
  • The BIG-IP system generates a bd core file to the /shared/core/ directory.
