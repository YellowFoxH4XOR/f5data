Known Issue

This is the result of a known issue. When viewing performance reports on the BIG-IP WebAccelerator for an extended period of time using a frequent refresh rate, the server may respond with an HTTP status code of 500 Internal Server Error. The root cause is a lack of sufficient memory available to the Apache Tomcat process.

F5 Product Development tracked this issue as CR92513 and it was fixed in BIG-IP WebAccelerator version 10.0.0.  For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Workaround

To recover from the internal server error, you must restart the tomcat process. To restart the tomcat process, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Stop the tomcat process by typing the following command:

    bigstart stop tomcat4
  3. Start the tomcat process by typing the following command:

    bigstart start tomcat4

If the issue persists under normal usage, you may be able to resolve the issue by provisioning additional memory to the tomcat process. For more information, refer to K9719: Error message: java.lang.OutOfMemoryError.
