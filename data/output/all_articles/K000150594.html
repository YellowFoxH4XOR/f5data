Description

Mitigate IngressNightmare vulnerabilities (CVE-2025-1097, CVE-2025-1098, CVE-2025-24514, CVE-2025-1974) with Attack signatures.

 

Note: These vulnerabilities are related to Ingress NGINX for Kubernetes, also known as ingress-nginx. F5 NGINX product of similar name and functionality, NGINX Ingress Controller is NOT vulnerable.

For information about F5's response to IngressNightmare Vulnerabilities, refer to K000150538: Kubernetes ingress-nginx vulnerabilities CVE-2025-1097, CVE-2025-1098, CVE-2025-1974, and CVE-2025-24514.

 

Environment

  • BIG-IP ASM
  • BIG-IP Advanced WAF
  • Nginx App Protect WAF
  • Distributed Cloud WAF & WAAP

 

Cause

None.

 

Recommended Actions

In order to protect against these vulnerabilities, it is recommended to enforce signature ID: 200103569 in recent signature updates (available from 20250327 update release.) 

 

BIG-IP ASM / Advanced WAF

The update files may be found by navigating through the link: https://my.f5.com/manage/s/downloads

  • Select the appropriate Product Line (for example “BIG-IP v17.x”)
  • Select the "ASM-AttackSignaturesUpdates" container
  • Download the latest ASM-AttackSignatures update files in the container:

Information on how to install the update can be found in the following article:

  • K82512024: Managing BIG-IP ASM Live Update (14.1.x and later)

 

NGINX App Protect WAF

Please follow the instructions for each OS type in the following article:

  • K32139972: Updating NGINX App Protect Attack Signatures

 

Distributed Cloud WAF & WAAP

Signature ID 200103569 check is available. Please search in Attack Signatures page.
