Description
Connection limit does not exist in GUI when using APM only license.
The following message appears when trying to change connection limit setting via CLI: 
(tmos) # modify ltm virtual <vs name> connection-limit <value>
01070356:3: Connection limits feature not licensed.

Environment

  • Connection limit
  • APM only license
  • Configuration Utility

Cause
This is by design.

Recommended Actions

None

Additional Information
If you would like to use connection limit feature, please make sure LTM and APM license both present.
