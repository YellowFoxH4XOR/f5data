Description

BIGIP administrator may need to test the connection using cURL utility against APM SWG setup (aka forward proxy setup). This article shows the syntax which can be used for such testing.

Environment

  • APM
  • SWG
  • cURL

Cause

None

Recommended Actions

Use the below cURL command. Replace <forward-proxy-vs:port> with IP of forward proxy virtual server and port (typically, 3128 or 8080):

curl -kv -x <forward-proxy-vs:port> <testing-site>

For example, in lab 10.1.20.99:3128 is the forward proxy virtual server with port 3128 and https://example.com is the testing site:

curl -kv -x 10.1.20.99:3128 https://example.com
