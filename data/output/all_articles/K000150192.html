K000150192: Combine X-forwarded-for, X-forwarded-host, X-forwarded-proto to retrieve client information, using the same http header

Description

You want to combine the following original client's details when the load balancer forwards traffic to the target server containing information about the original client. However, the GUI only permits you to enable the X-forwarded-for field, and use the 'Insert X-Forwarded-For' for either x-forwarded-host or x-forwarded-proto, but not both

 

X-Forwarded-For

X-Forwarded-Host

X-Forwarded-Proto

 

Environment

BIG-IP LTM

You have configured BIG-IP for load balancing functions. You would like to receive the host name, protocol, and the IP address of the original client in the same HTTP header.

 

Cause

None

 

Recommended Actions

In the HTTP profile properties, only the 'Insert X-Forwarded-For' is possible by default. If your environment requires that you receive the host name, and protocol used by the original client, in addition to its IP address, you will have to do this through the use of an iRule. However, for optimal performance, 

 

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Log in to the Configuration utility.

Navigate to Local Traffic > Profiles > Services > HTTP.

Click Create.

In the Name box, type a name for the profile.

In the Parent Profile menu, select http.

For the Insert 'X-Forwarded-For', select the Custom check box.

From the 'Insert X-Forwarded-For' dropdown, select Enabled.

Enable the Insert X-Forwarded-For setting,

In the 'Request Header Insert' field, select the Custom check box and type 'X-Forwarded-Proto:https'

Click Finished.

 

To enable the Insert X-Forwarded-host in the HTTP profile

Create an iRule with the following rules

 

when HTTP_REQUEST {

HTTP::header insert X-Forwarded-Host [HTTP::host]

}

Additional Information

F5 recommends that you enable the 'Insert X-Forwarded-For' in the property of the HTTP profile and use iRule to add the protocol and the host name to reduce the iRule processing time.
