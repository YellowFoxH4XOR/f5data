Known Issue

MAC masquerade does not function on the Intel X520 network adapter when using X520 virtual functions via Single Root I/O Virtualization (SR-IOV). This issue is due to a lack of functionality in the underlying hardware.

This issue occurs when all of the following conditions are met:

  • You use an Intel X520 network adapter with SR-IOV virtual functions as an interface in BIG-IP Virtual Edition (VE).
  • You configured MAC masquerading with a shared MAC address that should follow the active system after traffic group failovers.

The Intel X520 network adapter supports SR-IOV, which enables you to create multiple lightweight virtual functions per physical adapter port as part of Intel Virtualization Technology (VT). The virtual functions are PCIe functions that contain a minimal set of configuration resources to send and receive data.

Impact

MAC masquerade does not function, which may result in traffic disruptions after a high availability (HA) failover event.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You experience traffic disruptions after an HA failover event.
  • You observe incorrect failover behavior for the traffic group that has MAC masquerading configured.
