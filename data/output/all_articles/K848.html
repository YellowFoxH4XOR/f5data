Known Issue

This is the result of a known issue. The beholder script sends log messages to the rmon.log file, which is included in log rotation. When the log rotation process runs, it attempts to use the beholder-ctrl bigstart script to stop and restart beholder; however, the beholder-ctrl bigstart script does not include the stop and start command functions. As a result, these commands do not work and the script logs the following error message to the daily.out log file.

bigstart: start script beholder not found

F5 Networks Product Development tracked this issue as CR26612 and CR41892.
