Known Issue

This is the result of a known issue. When BIG-IP sets up a connection using SYN cookies, it ignores the first data packet that it receives from the client, which prompts the client to retransmit the packet. The connection proceeds normally, but the performance is reduced due to the client retransmission.

F5 Networks Product Development tracked this issue as CR46624, CR46625, and CR48564 and it was fixed in BIG-IP version 4.5.13 for the 4.5 software branch. For information about upgrading, refer to the BIG-IP Release Notes.

This issue still exists in the 4.6 software branch.
