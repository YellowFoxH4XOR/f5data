Topic
The F5OS system uses SSL certificates and keys for administrative tasks and tenant management. 
This article provides information about SSL certificates and keys. 

Description
The F5OS system uses SSL certificates to secure connections when using the Configuration utility to perform 
administrative tasks and tenant management. 
For successful authentication and secure communication, you should be aware of the following factors:

  • Device certificates must be valid and must not be expired.
  • Device certificates must be maintained and renewed.

While BIG-IP TMOS product use SSL certificate for HA device group, F5OS system acts differently.
There is no redundancy between F5OS platform layer. 
F5OS system themselves are unaware of the other appliance and there is no HA communication at this level.
HA communication is formed between Tenant Level across appliances.

The F5OS system uses the device certificates for HTTPS connections to the Configuration utility. 
You can view the Configuration utility device certificate and key in the location shown in the following table.

File name

Configuration utility location

Description
/var/system/httpd/ssl/f5os.crt

F5OS 1.x and later

SYSTEM SETTING / Certificate Management

The f5os.crt is a certificate used for HTTPS connections to the Configuration utility.
/var/system/httpd/ssl/f5os.key

F5OS 1.x and later

SYSTEM SETTING / Certificate Management

The f5os.key is the corresponding key used for HTTPS connections to the Configuration utility.
