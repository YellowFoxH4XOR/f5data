K000135209: Remote Logging Failure After Upgrading to 17.1.0 or 17.1.1 versions

Type
Support Solution
Published
2023-06-23
Updated
2025-01-10
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.0, 17.1.1
Source
https://my.f5.com/manage/s/article/K000135209

Description

After upgrading to 17.1.0 or 17.1.1 versions, the Adv. WAF remote logging functionality stops working. As a result, BD attempts to resolve the modified logging destination name but fails. The bd.log file captures errors similar to the following:

BD_MISC|ERR |Jun 06 08:39:35.615|21037|LoggingAccount.cpp:4323|getaddrinfo error: unknown name or service

Environment

  • Adv. WAF
  • Non-default route domain

Cause

This is due to remote logging with a non-default route domain no longer working. the misbehavior is tracked in ID1307449.

Recommended Actions

As a workaround, configure a logging profile in the /Common partition, which is associated with the default route domain 0, and apply that logging profile to the virtual servers in other partitions.
