Issue

Error Message

notice mcpd[<PID>]: 01071047:5: Removing <#> <object> local objects from slot <#>

In this error message, note the following:

  • <PID> is the process ID for the mcpd process
  • <#> is the number of objects and the slot number

For example:

notice mcpd[7289]: 01071047:5: Removing 10 Interfaces/Trunk Working Members local objects from slot 2

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • BIG-IP configuration objects associated with a chassis slot are removed.

The mcpd process generates this message in response to removing configuration objects associated with a chassis slot. This behavior occurs as the result of a cluster member being disabled or going down. As a result, interfaces and trunk working members that are associated with the cluster member are removed.

Impact

There is no impact; this is expected behavior. The removed configuration objects are unavailable for the slot until the slot is restored.

Recommended Actions

None
