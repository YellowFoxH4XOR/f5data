Source
https://my.f5.com/manage/s/article/K000148975

Description

After reboot (any reasons like License activation, software upgrade, maintenance), rSeries r2000/r4000 went to offline. 
The console does not respond and GUI/ssh has no access.
LCD status says "Host is not available / System is powered on" and it was shutdown status.

This issue does not happen every reboot.

 

Environment

  • F5OS-A v1.4.x-1.7.x
  • rSeries r2000/r4000
  • Occasionally, reboot becomes shutdown

 

Cause

  • Bug ID 1253717

 

Recommended Actions

This issue is fixed in v1.8.

If you encounter this issue, then Please use AOM menu (you will need to have Console Access) to boot it up.

  • Overview of Always-on management section in F5 r2000/r4000 Series platform guide
