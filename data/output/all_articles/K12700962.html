Description

When an attack is detected and logged, the dos_detection_threshold value does not match the detection threshold configured manually on the DoS profile.

Environment

  • ASM
  • DoS profile
  • Remote logging
  • Device running software versions 13.x or 14.x

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 682959

Recommended Actions

Upgrade to a non affected version 15.x or above

Additional Information

None
