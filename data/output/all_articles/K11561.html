K11561: BIG-IP ASM no longer sends WhiteHat headers for non-blocking entities

Type
Knowledge
Published
2010-05-25
Updated
2023-02-21
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP ASM: 10.2.0, 10.1.0
Source
https://my.f5.com/manage/s/article/K11561

Issue

BIG-IP ASM no longer sends WhiteHat headers for non-blocking entities, such as when a signature set is in staging. Only signature sets that are in blocking mode will send WhiteHat headers when the BIG-IP ASM flags a signature.

Note: For more information about WhiteHat integration with the BIG-IP ASM, refer to K9254: Integrating the WhiteHat Sentinel Scanner with BIG-IP ASM.

F5 Product Development tracked this enhancement as CR134491 and it was introduced in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Additionally, this enhancement has been included in BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP 10.x systems.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.
