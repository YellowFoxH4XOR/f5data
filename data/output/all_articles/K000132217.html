Description

  • When the base BIG-IP system is upgraded, the APMclients package version can also be automatically upgraded to the natively supported (built-in)  APMclients package version for the given BIG-IP version.

Environment

  • Relevant environmental factors:
  • BIG-IP version 13.1 & higher, with APM provisioned.

Cause

Starting in BIG-IP version 13.1 and higher, the APMclients package can be upgraded independently of the BIG-IP OS. But, when the BIG-IP is upgraded, the APMclients package version may also be upgraded to the version native to the BIG-IP version.

 

 Recommended Actions

  1. Upgrade the BIG-IP OS version (preferably to most recent security release).
  2. Always check the APMclients package version that is been distributed as "bundled", to read its release notes.
  3. Upgrade the APMclients package version to any more recent available release, if desired.

Additional Information

The active APMClients version cannot be set to a lower version than the built in version.
