Issue

Error Message

01160004:3:MainEventHandler.cpp:103 - MCP connection lost

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The Link Aggregation Control Protocol Daemon (LACPD) has encountered an unexpected I/O error when communicating with the Master Control Program Daemon (MCPD).

LACPD creates link aggregation groups, or trunks using IEEE 802.3ad, and implements the high availability (HA) feature switchboard failsafe.

Impact

While LACPD restarts, link aggregation and switchboard failsafe are not functional.

Recommended Actions

None
