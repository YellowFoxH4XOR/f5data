Description

You may observe the following messages in /var/log/liveinstall.log .

warning: tm_install::VolumeSet::choose_filesystem_plan -- Selected <name> plan (disk = <disk_size>, sz_standard = <value>, sz_vadc_large = <value>) 

Example:

info: Creating target filesystems. 

info: Installing packages. 

warning: tm_install::VolumeSet::choose_filesystem_plan -- Selected vadc_large plan (disk = 52428800, sz_standard = 14875024, sz_vadc_large = 13826448) 

info: Creating new location vda, 2...

warning: tm_install::VolumeSet::choose_filesystem_plan -- Selected vadc_large plan (disk = 52428800, sz_standard = 14875024, sz_vadc_large = 13826448) 

warning: tm_install::VolumeSet::choose_filesystem_plan -- Selected vadc_large plan (disk = 52428800, sz_standard = 14875024, sz_vadc_large = 13826448) 

Environment

  • BIG-IP VE
  • upgrade or downgrade

Cause

This is an expected behavior. The messages are purely informational and do not indicate any issue. They can be safely ignored.

Recommended Actions

None

Additional Information

An improvement Bug ID 1813885 was raised to change the log level of this message from "warning" to "info".
