K15419693: mptscsih: ioc0: attempting task abort

Type
Support Solution
Published
2023-06-20
Updated
2025-04-02
Applies to
  • Virtual Editions
  • BIG-IP
  • Xen Project
  • Vmware ESXI and vCloud Director
  • Microsoft Hyper-V
  • KVM
  • Citrix Xenserver
Source
https://my.f5.com/manage/s/article/K15419693

Description

  • BIG-IP is unstable
    • Multiple failovers.
    • Not processing traffic as expected.

Environment

  • Virtual Edition
  • /var/log/kernlog has message similar to
 mptscsih: ioc0: attempting task abort! (sc=ffff880197eca4c0)
 sd 2:0:0:0: [sda] CDB: Write(10) 2a 00 01 0c 28 a8 00 00 18 00
 mptscsih: ioc0: task abort: SUCCESS (rv=2002) (sc=ffff880197eca4c0)
 mptscsih: ioc0: attempting task abort! (sc=ffff880197ecbd40)
 sd 2:0:0:0: [sda] CDB: Write(10) 2a 00 01 12 ea 30 00 00 08 00
 mptscsih: ioc0: task abort: SUCCESS (rv=2002) (sc=ffff880197ecbd40)
  • /var/log/ltm may also log:
 Clock advanced by 1990 ticks
Cause
  • The hypervisor is not presenting a stable virtual disk to the VE

Recommended Actions

  1. Check the infrastructure. Some causes are:
  • Taking a backup or snapshot of the VE
  • Problematic Nic driver/firmware combination
  • Faulty host hardware
  • Flapping port in the network from host to datastore
  • Problem with the datastore.

Additional Information

The hypervisor can report a low latency connection to the datastore and still have issues.
