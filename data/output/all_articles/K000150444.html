K000150444: DCD being marked "Unavailable" on the CM

Support Solution

Source

Description

The DCD in the BIG-IQ cluster is constantly being marked "Unavailable" on the BIG-IQ CM

 

In the LTM logs of the BIG-IQ CM device, logs similar to the below can be seen:

Mar  9 03:30:41 BIGIQ-CM.local info logger[23290]: "BIG-IQ Peer Device Available Peer device BIGIQ-DCD2.local (172.17.253.136:443) marked available"
Mar  9 03:40:41 BIGIQ-CM.local warning logger[8635]: "BIG-IQ Peer Device Unavailable Peer device BIGIQ-DCD2.local (172.17.253.136:443) marked unavailable"

 

Similarly, in the restjavad logs, there are a lot of "java.util.concurrent.TimeoutException" logs referencing the IP address of the affected DCD. Below is a sample log:

[INFO][09 Mar 2025 04:04:11 WIB][/cm/shared/stats-mgmt/dcd-forwarder DCDForwarder] forwardRequest failed on device 172.17.253.136: java.util.concurrent.TimeoutException: Request timed out. 

 

 

On the affected DCD,  there are "java.lang.OutOfMemoryError: Java heap space" logs.

 

There might be times when there is a HeapDumpOnOutOfMemoryError_xxx file present in the /var/core/ directory. Although it may not be related, it would be good to provide this file to F5 Support, for further investigation.

 

Environment

  • BIG-IQ CM
  • DCD

 

Cause

The Java process on the DCD is running out of memory and is constantly timing out. This, in turn, is causing the said DCD to be marked "Unavailable" on the CM.

 

Recommended Actions

Restart restjavad on the affected DCD using this command:

  # bigstart restart restjavad
