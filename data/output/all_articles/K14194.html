Issue

You should consider using this procedure under the following condition:

  • The BIG-IP ASM MySQL database is unable to start successfully.

Symptoms

A corrupted BIG-IP ASM MySQL database may cause issues similar to the following:

  • The BIG-IP ASM system process fails to start properly.
  • The BIG-IP ASM MySQL database fails to start and logs a message.

Recommended Actions

If the BIG-IP ASM MySQL database fails to start successfully, the BIG-IP ASM system fails to start properly. When this issue occurs, you can attempt to determine the overall health of the BIG-IP ASM MySQL database using the mysqlcheck utility.

Procedures

When experiencing BIG-IP ASM MySQL database startup issues, you can use the following troubleshooting procedures:

  • Determining the status of the BIG-IP ASM process
  • Determining MySQL status by verifying the MySQL processes
  • Determining overall health of MySQL database and table contents
  • Repairing tables in the MySQL database
  • Verifying MySQL status by reviewing the database messages
  • Resetting MySQL database

Determining the status of the BIG-IP ASM process

As a first step, you can determine if the BIG-IP ASM process is running properly. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected BIG-IP ASM system.
  2. To determine the status of the BIG-IP ASM process, type the following command:

    bigstart status asm

  3. If the BIG-IP system fails to start due to the BIG-IP ASM MySQL database failure to start, the output from the command appears similar to the following example:

    asm down, waiting for mysqld to begin

Determining MySQL status by verifying the MySQL processes

You can determine the status of the BIG-IP ASM MySQL database by verifying the MySQL processes are running as expected. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected BIG-IP ASM system.
  2. To verify that the MySQL processes are running as expected, type the following command:

    ps awfux | grep mysql

Determining overall health of MySQL database and table contents

If the MySQL processes are not running, you should skip this procedure and proceed to Verifying MySQL status by reviewing the database messages. If the MySQL processes are running as expected, you can determine the overall health of the BIG-IP ASM MySQL database and its table contents by using the mysqlcheck utility. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected BIG-IP ASM system.
  2. To check the overall health of the BIG-IP ASM MySQL database and its table content, type the following command:

    mysqlcheck -p`perl -MF5::Cfg -e 'print F5::Cfg::get_mysql_password(user => q{root})'` -A

  3. Check for errors in the output.

Repairing tables in the MySQL database

For MySQL tables that support the option, you can attempt to repair corrupt table content using the -r option to the mysqlcheck command.  To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected BIG-IP ASM system.
  2. To repair corrupt table content in the BIG-IP ASM MySQL database, type the following command:

    mysqlcheck -p`perl -MF5::Cfg -e 'print F5::Cfg::get_mysql_password(user => q{root})'` -A -r

  3. Review the output for the status of the operation.

Verifying MySQL status by reviewing the database messages

You can verify the BIG-IP ASM MySQL database startup failure by reviewing the database log messages. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected BIG-IP ASM system.
  2. To search for log messages indicating the starting of MySQL database in the /var/log/mysql.out file, type the following command:

    grep "Starting MySQL" /var/log/mysql.out

  3. If the BIG-IP ASM MySQL database has failed to start due to database corruption, you may observe a log message that appears similar to the following example:

    Starting MySQL... ERROR! Manager of pid-file quit without updating file.

Resetting MySQL database

If after performing the previous procedures and you are unable to determine the issue, you may consider the following:

  • If the BIG-IP ASM database is responsive, but there are other issues with the BIG-IP ASM MySQL tables, you should consider resetting the BIG-IP ASM database to a default configuration. To do so, perform the steps described in K6992: Resetting the BIG-IP ASM database to a default configuration.
  • If the BIG-IP ASM database is not responsive, you must reinstall the BIG-IP ASM system. To do so, refer to the article appropriate for your version:
    • BIG-IP 11.x - 14.x: K13117: Performing a clean installation of BIG-IP 11.x - 14.x or Enterprise Manager 3.x.
    • BIG-IP 10.x: K10819: Performing a clean installation of BIG-IP 10.x or Enterprise Manager 2.x
