Description

GUI stops responding after 15-20 seconds. Restart of GUI services is not fixing the issue. In top command you can observe high CPU usage caused by syslog.

 

Environment

BIG IP

 

Cause

Bug ID 1040277

 

Recommended Actions

Ensure syslog-ng server configuration is valid, and configuration does not contain unreachable syslog servers. If a remote server is not reachable remove it from the BIG-IP syslog configuration. That should fix the GUI issue.

None
