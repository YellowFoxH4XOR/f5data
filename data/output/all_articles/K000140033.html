Description

When Antivirus check fails due to definition age or last scan date, is there any way to report it to user?

 

Environment

  • BIG-IP APM
  • Access policy
  • Anti Virus check

 

Cause

  • n/a

 

Recommended Actions

Use message box after Antivirus check in the Access Policy.

If you want to know how many days ago it is full scanned or DB update, then need to set custom variable.

NOTE: setting "logging" rule for antivirus after AntiVirus rule will help you to know what session valuable can be utilized for your custom variable.
