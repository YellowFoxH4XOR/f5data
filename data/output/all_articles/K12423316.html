Known Issue

VMware View HTML5 clients fail to connect to Horizon VCS 7.4 resources.

This issue occurs when all of the following conditions are met:

  • You configure your BIG-IP APM system for VMware Horizon View 7.4.
  • Users establish an access session with the access profile.
  • Users attempt to launch a View resource from the BIG-IP APM webtop using the Horizon View HTML5 client.

Impact

Users cannot access the VMware resource.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • F5 iHealth lists Heuristic H712495 on the Diagnostics > Identified > Low page.
  • The system presents the VMware View resource to the BIG-IP APM webtop; however, the connection to the resource fails.
  • When you attempt to launch the VMware resource using the HTML5 client and the Chrome browser, the client displays an error message similar to the following example:

    This site can’t be reached

  • When you attempt to launch the VMware resource using the HTML5 client and the Internet Explorer browser, the system redirects users to the initial BIG-IP APM login page.

Workaround

To work around this issue, you can instead use the native View client, or if you are running BIG-IP APM 13.1.0, you can apply the following iRule to the virtual server that handles HTML5 connections. To apply the iRule to the virtual server, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Local Traffic > iRules.
  3. Click Create.
  4. In the Name box, type a name for the iRule, similar to the following example:

    html5_horizon74_K12423316

  5. In the Definition box, type the following iRules syntax:

    when HTTP_REQUEST {
        if { ([info exists tmm_apm_view_uuid]) &&
             ([HTTP::method] == "GET") &&
             ([HTTP::uri] ends_with "/portal/webclient/sessiondata")} {
            HTTP::cookie remove "sessionDataServiceId"
        }
    }

    when HTTP_RESPONSE {
        if { ([info exists tmm_apm_view_uuid]) } {
            set cookieNames [HTTP::cookie names]
            foreach aCookie $cookieNames {
                set path [HTTP::cookie path $aCookie]
                if {[string length $path] > 0} {
                    HTTP::cookie path $aCookie "/f5vdifwd/vmview/$tmm_apm_view_uuid$path"
                }
            }
        }
    }

  6. Click Finished.
  7. To assign the new iRule to the virtual server, navigate to Local Traffic > Virtual Servers.
  8. Click the virtual server that is processing HTML5 connections.
  9. Click the Resources tab.
  10. In iRules, click Manage.
  11. In the Available list, click html5_horizon74_K12423316, and then click Move Left (<<).
  12. Click Finished.

Notes:

  • The iRules workaround is for BIG-IP APM 13.1.0; older BIG-IP releases do not support the workaround.
  • After you apply the iRule and before you attempt to connect, clear all cache and cookies from the client systems.
