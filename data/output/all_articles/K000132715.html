K000132715: New peer link not working as expected due to ABORT after Heartbeat request

Type
Support Solution
Published
2023-02-22
Updated
2023-02-22
Source
https://my.f5.com/manage/s/article/K000132715

Description

  • New peer links having problems with ABORT from SDC after getting Heartbeat request from secondary multihomed address on remote side.

Environment

  • SDC 5.1

Cause

IP's provided in the INIT_ACK by the remote side are in the wrong format and/or not translated with NAT. This causes the SDC to do immediate ABORT on the Heartbeat request.


 Recommended Actions

Configure SCTP IP configuration in the remote side correctly to make sure its a valid IP when it arrives in the SDC.

Additional Information

None.
