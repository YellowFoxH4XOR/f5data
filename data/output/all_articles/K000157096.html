K000157096: After upgrading BIG-IP to 17.5.1.3 EHF, selecting packages in Package Management LX redirects to Application Services

Type
Support Solution
Published
2025-11-02
Updated
2025-11-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000157096

Description

After upgrading your BIG-IP to 17.5.1.3 EHF, you observe that when you select to uninstall or anything in the package in Package Management LX, the page gets re-directed Application Services.

Environment

  • BIG-IP LTM
  • 17.5.1.3 Engineering Hotfix 0.1.19
  • Edge or Chrome browser

Cause

Cosmetic issue.

Recommended Actions

Try to use Firefox as this issue is not observed there. Possibly update your Edge or Chrome browser

Additional Information

None
