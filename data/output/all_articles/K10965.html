Topic

The bigip_link and snmp_link monitors are used to gather metrics and performance data for link objects.

bigip_link monitor

The bigip_link monitor gathers statistics metrics, such as throughput. The metrics are obtained from Traffic Management Microkernel (TMM) using the Master Control Program Daemon (mcpd) process. Therefore, no external probes are associated with this monitor type. The bigip_link monitor determines the status of the Link object by querying the status of the pool members defined under the default_gateway_pool pool. The pool members have addresses matching that of the router-addresses configured in the Link object. As a result, you must ensure that adequate monitors are assigned to monitor the default_gateway_pool pool.

snmp_link monitor

You can use the snmp_link monitor to check the performance of links that are running a SNMP agent.

When you assign the snmp_link monitor to a link object, the monitor retrieves the general in/out bytes and packet counts from the remote router using the following object identifiers (OIDs):

1.3.6.1.2.1.1.1 - sysDescr
1.3.6.1.2.1.1.3 - sysUpTime
1.3.6.1.2.1.1.4 - sysContact
1.3.6.1.2.1.1.5 - sysName
1.3.6.1.2.1.1.6 - sysLocation
1.3.6.1.2.1.4.3 - ipInReceives
1.3.6.1.2.1.4.10 - ipOutRequests
1.3.6.1.2.1.6.4 - tcpMaxConn
1.3.6.1.2.1.6.5 - tcpActiveOpens
1.3.6.1.2.1.6.6 - tcpPassiveOpens
1.3.6.1.2.1.6.9 - tcpCurrEstab

Next, the monitor uses the following object identifiers (OIDs) from RFC 1573 Interfaces Group of MIB-II to perform a router specific query related to the BIG-IP device and the configured router:

1.3.6.1.2.1.2.2.1.10 - ifInOctets
1.3.6.1.2.1.2.2.1.11 - ifInUcastPkts
1.3.6.1.2.1.2.2.1.16 - ifOutOctets
1.3.6.1.2.1.2.2.1.17 - ifOutUcastPkts
1.3.6.1.2.1.4.20.1.2.<ip addres of router>* - ipAdEntIfIndex.
1.3.6.1.2.1.31.1.1.1.1.<interface number> - ifName

The snmp_link monitor then selects an IP address on the router to use for its target interface. The monitor uses an uplink address if one is defined for the link. If no uplink address is defined for the link object, the monitor uses the target IP address defined for the link.

Note: When the bigip_link and snmp_link monitors are configured, the gtmd process looks at the load-balancing mode on the gateway_pool. If the load-balancing mode is pool member dynamic ratio, gtmd sets the pool name in the request and sets the dynamic ratio value for the gateway pool members. If the load-balancing mode is node-based dynamic ratio, gtmd will set the dynamic ratio value for the nodes. When load-balancing multiple pools containing gateway pool members, you should use node-based dynamic ratio as the load-balancing mode.

Note: For information about configuring an uplink addresses, refer to K6785: Configuring an uplink address for BIG-IP DNS, BIG-IP GTM and Link Controller link definitions.

Note: You can configure either SNMP V1 or V2; V2 has the advantage of 64-bit counters.
