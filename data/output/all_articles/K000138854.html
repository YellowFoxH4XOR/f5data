K000138854: No stats under Monitoring > Secure Web Gateway - Timeout

Type
Support Solution
Published
2024-03-25
Updated
2024-03-25
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.1
Source
https://my.f5.com/manage/s/article/K000138854

Description

You do not see any stats under Monitoring > Secure Web Gateway

Additionally you get a timeout error message

Environment

  • BIG-IP
  • BIG-IQ
  • SWG

Cause

One or several ports are not allowed on the discovery address of CM or DCD.

Recommended Actions

Additional to the default ports, ports 9997 and 9090 needs to be configured on the discovery address of the BIG-IQ CM and DCD.

Run the following on CM and DCD:

tmsh modify net self <IP address of the Discovery Address> allow-service replace-all-with { default tcp:9997 tcp:9090 }

 

To find out the discovery address of your device, run the following command:

cat /var/config/rest/service.config.json | grep discovery
