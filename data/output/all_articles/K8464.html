K8464: An impersonated webtop does not display any resources when the Treat user's logon name as case sensitive setting is enabled

Source

Known Issue

This is the result of a known issue. If you impersonate a user on the Users: Impersonate User page, and the Treat user's logon name as case sensitive check box is selected on the Users: Global Settings page, FirePass does not display any resources on the impersonated webtop.

F5 Networks Product Development is tracking this issue as CR94099.

Workaround

You can work around this issue by clearing the Treat user's logon name as case sensitive check box on the Users: Global Settings page in the FirePass Administrative Console.
