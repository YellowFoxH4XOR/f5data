K000147116: I am receiving a message "Error creating AwsVpcSite"

Type
Support Solution
Published
2024-11-08
Updated
2025-02-19
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147116

Description

  • You're using F5® Distributed Cloud Services' Terraform provider
  • You are trying to create an assisted AWS site
  • You get the error: "Error creating AwsVpcSite: Creating object: Converting json to response protobuf message: FromJSON: json: cannot unmarshal number into Go value of type string"

Environment

  • F5® Distributed Cloud Services (SaaS)
  • Terraform

Cause

  • You might be using an older version of the Terraform provider

Answer/Recommended Actions

  • Get the latest version - You can validate it here

  • Upgrade to the latest version
