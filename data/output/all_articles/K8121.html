Known Issue

This is the result of a known issue. Version 6.2.5 of the qkview utility does not gather the necessary configuration files based on license.

The qkview utility gathers different configuration files based on the license configured on a system. The following scenarios specify which information is not included when the qkview utility is run on a specific system:

  • The qkview utility is run from the Configuration utility on a BIG-IP GTM-only system

    When the qkview utility is run from the Configuration utility, it does not correctly identify the system, which prevents qkview from gathering the BIG-IP GTM configuration information located in the /config/gtm directory, or the ZoneRunner information located in the /var/named directory.
  • The qkview utility is run from the Configuration utility or command line on a Link Controller-only system

    The qkview utility does not properly identify the system when it is licensed for BIG-IP Link Controller only. As a result, the qkview utility does not gather the wideip.conf file stored in the /config/gtm/ directory.
  • The qkview utility is run from the Configuration utility on a BIG-IP ASM-only system

    When the qkview utility is run from the Configuration utility, it does not correctly identify the system, which prevents qkview from launching the asmqkview specific utility to gather the BIG-IP ASM configuration information.
  • The qkview utility is run from the Configuration utility on a BIG-IP WebAccelerator-only system

    When the qkview utility is run from the Configuration utility, it does not correctly identify the system, which prevents qkview from gathering the specific BIG-IP WebAccelerator information:

    ls -lasR /etc/httpd/conf
    ls -lasR /etc/tomcat4
    ls -lasR /var/wa
    ls -lasR /usr/local/wa
    cat /etc/httpd/conf/workers2.properties
    cat /etc/tomcat4/server.xml
    cat /config/wa/pvsystem.conf
    cat /config/wa/globalfragment.xml
    cat /usr/local/wa/config/policies/localhost*/sys_config.xml
    cat /var/tmp/wa_db.sql.cstmp
    cat /var/log/wa/comm_srv.log
    cat /var/log/wa/pvac.log

F5 Networks Product Development tracked this issue as CR89474 and it was fixed in BIG-IP version 9.4.4. For information about upgrading, refer to the BIG-IP GTM, Link Controller, ASM or WebAccelerator Release Notes.    

Workaround

You can work around this issue by performing one of the following two procedures, depending on whether you are running the qkview utility on a BIG-IP GTM or a BIG-IP Link Controller.

Running qkview version 6.2.5 on a system licensed only for BIG-IP GTM

If you run qkview version 6.2.5 on a system licensed only for the BIG-IP GTM, you must do so from the command line. To run qkview from the command line, perform the following procedure:
  1. Log in to the command line.
  2. Type the following command:

    qkview
  3. Press Enter.
  4. Wait for the qkview process to finish.
  5. Send the tech.out file located in the /var/tmp folder to support.

    The file will be in the following format:

    <hostname>-tech.out

    Note: For more information about uploading a tech.out file for support to review, refer to K2486: Providing files to F5 Networks Technical Support.
 
Running qkview version 6.2.5 on a system licensed only for BIG-IP Link Controller

If you run qkview version 6.2.5 on a system licensed only for the BIG-IP Link Controller, you must do so from the command line.

Note: If you want to include the wideip.conf file in the in the tech.out file, you must manually append the wideip.conf file to the end of the tech.out file after the qkview script has completed.

To run qkview from the command line and manually append the wideip.conf file to the end of the tech.out file, perform the following procedure:
  1. Log in to the command line
  2. Type the following command:

    qkview
  3. Press Enter.
  4. Wait for the qkview utility to complete gathering information.
  5. To append the wideip.conf file to the end of the tech.out file, type the following command:

    cat /config/gtm/wideip.conf >> /var/tmp/<hostname>-tech.out

    Note: Replace <hostname> with the Fully Qualified Domain Name (FQDN) of your system.
  6. Press Enter.
  7. Send the tech.out file located in the /var/tmp directory to support.

    The file will be in the following format:

    <hostname>-tech.out

Note: For more information about uploading a tech.out file for support to review, refer to K2486: Providing files to F5 Networks Technical Support.


Running qkview version 6.2.5 on a system licensed only for BIG-IP ASM or BIG-IP WebAccelerator

To run the qkview utility version 6.2.5 on a system licensed only for the BIG-IP ASM or WebAccelerator, perform the following procedure:

  1. Log in to the command line.
  2. Type the following command:

    qkview
  3. Press Enter.

    Note: The qkview utility will automatically run asmqkview for BIG-IP ASM only devices, and gather the correct files for BIG-IP WebAccelerator devices.
  4. Wait for the qkview utility to complete gathering information.
  5. Send the tech.out file located in the /var/tmp directory to support.

    The file will be in the following format:

    <hostname>-tech.out

Note: For more information about uploading a tech.out file for support to review, refer to K2486: Providing files to F5 Networks Technical Support.
