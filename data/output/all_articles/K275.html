Streaming media server considerations

BIG-IP is capable of load balancing traffic for streaming media servers, including RealServer from Real Networks; however the following streaming media servers concepts must be taken into consideration:

  • The majority of traffic on a streaming media server is outbound; while clients do make connection requests to the server, once a request begins to be served almost all the subsequent communication is sent from the server to the client.
  • Compared to an HTTP connection, streaming media connections are usually very high-bandwidth and are typically long in duration.
  • Some streaming media software vendors have changed the configuration setup and protocols as their products matured; therefore, it is difficult to provide exact configuration procedures for use with BIG-IP.

Pertinent BIG-IP features

BIG-IP provides features for special cases that are presented by load balancing streaming media servers. Following are some examples:

  • You can set up a special network configuration called nPath mode, which causes return connections from servers to bypass the BIG-IP.
  • You can load balance outbound connections through multiple egress routers.
  • You can reap idle connections, which is especially useful when you have users with slow connections (such as a modem) that hang.
  • You can ensure that new connections are sent to healthy servers by performing health checks on the media servers.

Before configuring BIG-IP for streaming media servers

Before configuring BIG-IP for streaming media servers, ask the following questions:

  • What ports are used to stream media? Are media streams being encapsulated in HTTP packets on port 80? Is TCP or UDP being used, or both?
  • Are you using the Akamai network to place content geographically closer to the users?
  • Are clients connecting through a wide variety of methods such as modem or broadband, or are the bulk of the clients connecting through a corporate LAN?

For specific information about the streaming media server software you are running, refer to the documentation provided by your vendor.

For more information about configuring streaming media servers for BIG-IP load balancing, refer to the BIG-IP Reference Guide and the BIG-IP Solutions Guide.
