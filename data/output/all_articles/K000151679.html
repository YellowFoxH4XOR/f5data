K000151679: Not able to update the ASM Attack Signatures. Also, unable to save the configuration when setting up the option "Installation of Automatically Downloaded Updates" in System ›› Software Management ›› Live Update.

Description

Installing ASM Attack Signatures updates via Live Update fails, and attempts to set the "Installation of Automatically Downloaded Updates" option in System ›› Software Management ›› Live Update fail with error "Failed to save configuration". Browser developer tools can show HTTP 403 Forbidden errors for installing the signature update and setting the option "Installation of Automatically Downloaded Updates" request. System logs (httpd_errors) may contain entries such as:  

[access_compat:error] [pid xxxx] [client <IP>:<port>] AH01797: client denied by server configuration: proxy:<URL>, referer: <URL>


 

Environment

  •  BIG-IP ASM  
  •  Custom httpd configuration restricting HTTP methods for GUI access
     

Cause

A custom httpd configuration is present that restricts allowed HTTP methods for GUI access to only GET and POST. The Live Update installation and certain configuration changes require additional HTTP methods (such as PATCH), which are blocked by this restriction:

<Location />
  <LimitExcept GET POST>
    order deny,allow
    deny from all
  </LimitExcept>
</Location>

This causes requests using other methods (e.g., PATCH) to be denied, resulting in "Failed to save configuration" errors and HTTP 403 responses.


 

Recommended Actions

To resolve this issue:

1. Connect to the BIG-IP system via SSH or console.
2. Remove the restrictive httpd include configuration by running:
   
   #tmsh modify sys httpd include none
   #tmsh save sys config
   
3. Retry the Live Update installation or save the desired configuration.

If your require method restrictions for security reasons, ensure that required methods, such as PATCH, are not blocked for management operations.
