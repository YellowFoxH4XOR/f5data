Known Issue

The BIG-IP ASM system may erroneously trigger Modified domain cookie violations.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM system is configured with more than 127 security policies.
  • At least one of the security policies is configured to enforce Modified domain cookies.

Impact

The Modified domain cookie violation is triggered on non-enforced domain cookies.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the event request logs, domain cookies not configured with Modified domain cookie enforcement trigger the Modified domain cookie violation.
  • When the security policy Modified domain cookie violation is set to block, requests are erroneously blocked due to a false positive Modified domain cookie violation.

Workaround

To work around this issue, you can configure the security policy Learning and Blocking settings to not block on the Modified domain cookie violation. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure will cause the security policy to no longer block on Modified domain cookie violations.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. Set the Current edited security policy to the security policy that is configured for Modified domain name cookie enforcement
  4. In the Policy Building Settings screen, expand the Cookies section.
  5. Remove the check box selection for Modified domain name cookie(s).
  6. Click Save.
  7. Repeat steps 2 through 6 on each security policy configured to block on Modified domain name cookie violations.
  8. Click Apply Policy.
