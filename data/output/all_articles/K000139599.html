K000139599: BIG-IP Next AS3 deployment error when referencing a VLAN in allowVLANs

Type
Support Solution
Published
2024-05-14
Updated
2025-09-02
Status
Legacy Content
Applies to
  • BIG-IP Next
  • BIG-IP Next LTM
  • BIG-IP Next Central Manager: 20.2.0
Source
https://my.f5.com/manage/s/article/K000139599

Description

Error message running declaration:

   "message": "AS3-0007: AS3 Deploy Error: Failed to deploy on BIG-IP Next instance Deployment failed with reason: AS3-0007: AS3 Deploy Error: Failed to accept request on BIG-IP Next instance: {\"code\":422,\"message\":\"declaration is invalid\",\"errors\":[\"<virtual-server-path>/allowVlans/0: must contain path pointing to a reference that exists on the system\"]} : - ",

 

 

Environment

BIG-IP Next

 

Cause

"allowVlans" accepts a list of L3Networks but the customer used a VLAN name.

 

Customers may want to use allowNetworks which takes an L3Network/VRF value.

 

When you set Default VRF on one or more of the VLANs, the system will create a “Default L3-Network” VRF.

 

"allowNetworks": [

{

"bigip": "Default L3-Network"

}

],

 

Recommended Actions

Until Next has enhanced VRF support in future versions, we recommend not worrying about the VLAN selection. For basic use cases using the "default VRF" (appearing in the 20.2.0 UI) would be possible.
