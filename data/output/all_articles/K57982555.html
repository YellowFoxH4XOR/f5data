Known Issue

When creating a virtual server using the NT LAN Manager (NTLM) profile, you view the following error message in the /var/log/ltm file that appears similar to the following example:

01220001:3: TCL error: bad option "serverside": must be require or preclude while executing "constrain NTLM require clientside {HTTP} serverside {CONNPOOL} preclude FTP"

This issue occurs when the following condition is met:

  • You attempt to create a virtual server using the NTLM profile.

Impact

There is no impact; The error is benign and may be safely ignored.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You view the following error message in the /var/log/ltm file that appears similar to the following example:

    01220001:3: TCL error: bad option "serverside": must be require or preclude while executing "constrain NTLM require clientside {HTTP} serverside {CONNPOOL} preclude FTP"
