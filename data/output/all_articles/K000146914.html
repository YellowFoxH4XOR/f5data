K000146914: Can I modify "Email Contact" field on SOA Register?

Type
Support Solution
Published
2024-11-08
Updated
2025-01-09
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud DNS Management
Source
https://my.f5.com/manage/s/article/K000146914

Description

  • I am configuring a zone in F5 Distributed Cloud DNS Service - Primary DNS
  • I am moving the on-premise DNS configuration to F5 Distributed Cloud DNS Service
  • When I try to configure the SOA Register , I couldn't find the field Email Contact
  • I don't see the option to change the field Email Contact

Environment

  • F5® Distributed Cloud Console
  • F5 Distributed Cloud DNS

Resolution/Answer

No, you cannot modify email on SOA record. F5 Distributed Cloud DNS is the DNS administrator now and not you. On-premise DNS is different than a SaaS service.
