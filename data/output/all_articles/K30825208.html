Description

On upgrading a vCMP guest, the secondary blade is offline, while the host blade is online.  On the guest, tmsh show /sys cluster reports 

Quorum: mcpd config not yet sent, HA TABLE offline

Using vconsole to connect to the offline blade reveals:

halStorageRead: unable to read storage on this platform.
Loading keys from the file.
Symmetric Unit Key decrypt failure - decrypt failure
Symmmetric Unit Key decrypt
Master key OpenSSL error: 1533922216:error:06065064:digital envelope routines:EVP_DecryptFinal_ex:bad decrypt:evp_enc.c:601: [
Secondaries couldn't load master key from the file.

Environment

vCMP

Cause

It is unclear why the key is corrupted on the secondary blade.

Recommended Actions


Use vi or the editor of your choice to replace all of the password or passphrases in the configuration file with their plain text equivalents.
vi /config/bigip.conf
tmsh load sys config 

This will allow the BigiIP to load the configuration, permitting the secondary blade to join quorum.  At this point the primary should push the most recent configuration to the secondary guest.
