K000149913: Impact of Moving External SVI on CE Nodes

Description

This article explains the implications of moving the SVI (Switched Virtual Interface) used for the CE (Customer Edge) internal interface from one firewall to another. Specifically, it addresses whether the CE nodes will recognize the change and update their forwarding table automatically or if manual intervention is required.

Environment

  • Multi-Cloud Network Connect

Cause

None

Recommended Actions

When moving the external SVI associated with the CE internal interface no action is required if IP addresses remain unchanged, i.e. if the nodes' IP addresses remain the same, the CE nodes will automatically recognize the new SVI location, and no additional updates are required.
