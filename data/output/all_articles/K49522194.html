Known Issue

Policy Sync may fail due to stale dynamic resources.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM configuration uses the Policy Sync feature.
  • Policy Sync dynamic resources reference resources that were previously deleted.

Impact

BIG-IP APM Policy Sync functionalities and operations on access profiles fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Attempts to export an access profile fail, and the system displays an error message similar to the following example:

    01020036:3: The requested unknown (<partition_name>/<access_profile_name>) was not found.
  • Policy Sync functionalities and operations on access profiles fail.
