Description

When enabling ssh access via the BIG-IP GUI (System -> Platform -> Check 'SSH Access' -> Update), you may observe GUI disconnections, SNMP timeouts, and iQuery interruptions, among other possible symptoms.

 

 

Environment

- Enabling ssh access via BIG-IP Configuration Utility (GUI)

- WEBUI showing 'Receiving configuration data from your device.' or 'Unable to contact BIG-IP device' for an extended period of time

- MCPD timeouts

 

 

Cause

This is due to ID2197289. When enabling ssh access via the GUI, MCPD becomes blocked for ~90 seconds, which can cause a myriad of issues including GUI disconnections.

 

 

Answer/Recommended Actions

Upgrade to a version that contains a fix for ID2197289. If the fix is not available in the most recent GA version, open a support case requesting an EHF for ID2197289.
