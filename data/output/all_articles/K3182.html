Note: For information about BIG-IP version 9.x compatibility with redundant network interface cards, refer to K3009: Configuring BIG-IP to load balance traffic to nodes that use redundant network interface cards (NICs).
 
The BIG-IP system is not compatible with redundant NICs.

Redundant NICs implement failover by using a one shared IP address for two NICs. When the BIG-IP system load balances traffic, it tracks the incoming traffic?s last hop MAC address so that it can send return traffic to the same MAC address. As a result, the BIG-IP system may continue to send traffic to the inactive NIC after a failover occurs between the two NICs.

F5 Networks recommends that you use the 802.3ad protocol for load balancing and link aggregation, rather than the proprietary redundant NIC features.
