Description

You notice that a node that is monitored with ICMP is down, and the Pool Member is returning a valid response
If you use tcpdump to capture the ICMP Messages to the Node, you may see that the Node does receive a valid ICMP Reply, but the Node is still marked as down.

Environment

  • Two or more devices in a sync/failover device group
  • The config sync from-device has marked nodes down
  • A config sync occurs, this can occur on both incremental and full config sync.

Cause

Bug ID 1035121: Configsync syncs the node's monitor status

Recommended Actions

If a device is in this state, you can work around this issue by doing one of the following:

  • Save and reload the configuration on the device with the bad state
    • tmsh save sys config && tmsh load sys config
  • Perform a full-load sync from the peer device to the affected device:
    • (On the peer) tmsh run cm config-sync force-full-load-push to-group <group-name>
