Known Issue

SSL handshakes that use the Elliptic Curve Digital Signature Algorithm (ECDSA) ciphers may fail on BIG-IP 2000 and BIG-IP 4000 platforms.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server with a Client SSL profile.
  • The BIG-IP platform is a 2000 or 4000 series platform.
  • The client connecting to the virtual server is using the ECDSA cipher suite.

Impact

The SSL handshake may fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In some circumstances, ECDSA signatures are not properly processed by the BIG-IP 2000 and BIG-IP 4000 series crypto hardware during verification, causing SSL handshakes with ECDSA cipher suites to fail.
  • In the /var/log/ltm log file, the system reports an error message similar to the following example:

    01260013:6: SSL Handshake failed for TCP <source IP address:port> -> <destination IP address:port>
