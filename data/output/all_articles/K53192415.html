Source

Description

There is an error when trying to perform a ConfigSync:

Sync error on <hostname>: Load failed from <hostname> 01070712:3: Caught configuration exception (0), Values (/Common/bot-defense-device-id-generate-after-access) specified for Bot Defense Profile Javascript Injection Whitelist (/Common/bot-defense-device-id-generate-after-access apple_touch_1): foreign key index (profile_FK) do not point at an item that exists in the database..

Environment

  • BIG-IP LTM
  • HA pair

Cause

Unknown at the time of publication.

Recommended Actions

There are 2 different ways to resolve this error message:

Perform a configuration reload on both devices. Then attempt a new ConfigSync:
  1. Save the current configuration

# tmsh save sys config partitions all

  1. Reload the configuration

# tmsh load sys config partitions all

  1. Repeat steps 1 and 2 on the secondary device
  2. Attempt the ConfigSync
Note: Performing a configuration reload will cause a temporary traffic disruption.
 
Perfom a comparison of both configuration files (bigip.conf) in the HA cluster:
  1. Download or copy the entire content of the bigip.conf files in every device that the cluster may have.
  2. Compare the information of those files by using a comparing tool, there some objects and attributes that are not synchronized between devices, check K21259300: BIG-IP items that are not synchronized between device group members during a ConfigSync operation you may found some elements that are present in the Standby device but aren't in the Active device.
  3. Delete those extra objects or attributes that shouldn't be present in the Standby BIG-IP, you can try to manually delete them either in GUI or in CLI.
  4. After those extra objects are completely deleted please try to make another ConfigSync operation.
