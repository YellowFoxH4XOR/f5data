K000149868: MUD: How Malicious User Detection works in API Security Events?

Description

You want to know how the counter of Malicious User Detection works in API security events

Environment

  • API Security

Answer

  • If API validation policy is configured in "Report" mode, the API security event won't be counted by Malicious User Detection.
  • If API validation policy is configured in "Blocking" mode, the API security event will be counted by Malicious User Detection.

Cause

When there is an API validation in Report mode it is not considered as forbidden activity (403) and so it is not taken into account in MUD.
