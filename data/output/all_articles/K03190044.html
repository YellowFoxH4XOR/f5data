Description

By default the BIG-IP LTM will not log http and https connections.

This article will explain how to configure your BIG-IP LTM to log all connections for your http or https Virtual Server locally.

Environment

  • BIG-IP LTM
  • http or https Virtual Server
  • log connections locally (no syslog server)

Cause

None.

Recommended Actions

You will need to create an iRule to log the http and https connection. This iRule must be attached on a Virtual Server.

  1. Loging to the BIG-IP GUI
  2. Navigate to Local Traffic > iRules > iRule List
  3. Click Create
  4. In Name, enter an iRule name
  5. In Definition, use the following iRule
    when HTTP_REQUEST {
           log local0. "Client [IP::client_addr] request to [HTTP::host]"
    }
  6. Click Finished
  7. Navigate to Local Traffic > Virtual Servers > Virtual Server List
  8. Click on the Virtual Server
  9. Click on the Resource tab
  10. Under iRules, click Manage
  11. Under Available, select the iRule which was created
  12. Click << and the iRule will be moved from Available to Enable
  13. Click Finished
Once you have finish configuring the iRule and enabling it to the Virtual Server, the http or https connection logs will be logged in /var/log/ltm. An example of the log is as below:
big-ip-ltm info tmm[12062]: Rule /Common/iRule-log <HTTP_REQUEST>: Client 10.10.10.10 request to www.example.com
