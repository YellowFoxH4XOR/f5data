K000151311: BIG-IQ Upgrade script does not check database backup and restoration

Description

When upgrading BIG-IQ from version 8.3.0 to 8.4.0, the upgrade process may fail during the database migration phase with errors related to missing tables in PostgreSQL.

Typical error messages include:

ERROR: Migration of schema "public" to version 4 - asm drop policy signatures differencer tables failed! Changes successfully rolled back.

ERROR: Migration V4__asm_drop_policy_signatures_differencer_tables.sql failed

SQL State : 42P01

Message : ERROR: table "asm_reports_policy_signatures_difference_reference_parts" does not exist

Location : /var/config/rest/postgres/upgrade/migrations/version-8.0.0/V4__asm_drop_policy_signatures_differencer_tables.sql

Line : 3

Statement : DROP TABLE bigiqliveobjects.asm_reports_policy_signatures_difference_reference_parts

Caused by: org.postgresql.util.PSQLException: ERROR: table "asm_reports_policy_signatures_difference_reference_parts" does not exist

pg_restore: [custom archiver] could not read from input file: end of file

pg_restore: [parallel archiver] a worker process died unexpectedly

Restored 0 tables.

Failed to upgrade database.

Command '['/usr/bin/update-rest-storage']' returned non-zero exit status 1

 

Environment

  • BIG-IQ CM
  • Software Upgrade
  • Postgres Database

Cause

The upgrade fails because the migration script attempts to drop a database table (asm_reports_policy_signatures_difference_reference_parts) that does not exist in the current schema, resulting in an SQL error and rollback of the migration process.

Recommended Actions

Always perform full system and database backups before starting any upgrade procedure

After a failed upgrade attempt, collect all relevant logs (including QKView) for troubleshooting. Provide F5 Support with complete log files and QKView outputs for further analysis.
