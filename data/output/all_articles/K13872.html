Known Issue

The filter function in the BIG-IP GTM Wide IP List menu returns no results.

This issue occurs when the following condition is met:

  • You are using the Filter option to search for a specific wide IP or range of wide IPs.

Impact

You may need to manually search for the wide IP object you require.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When using the wide IP filter, the system displays the following message:

    No records to display

Note: You may see similar symptoms as a result of the known issue documented in K13871: The wide IP filter is case sensitive.

Resolution

Status

F5 Product Development has assigned ID 370962 to this issue, and has confirmed that this issue exists in the products listed in the Applies To box. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can select Show All in the page selection menu at the bottom right-hand side of the screen and use your browser search function to locate the wide IP you require.
