Description

APM kerberos authentication fail.
Get the log below in the apm log file /var/log/apm:

debug apd[pid]: 01490000:7: modules/Authentication/Kerberos/KerberosAuthModule.cpp func: "display_status_1()" line: 84 Msg: 1a2b3c4d : GSS-API error gss_acquire_cred: d0000 : Unspecified GSS failure.  Minor code may provide more information
debug apd[pid]: 01490000:7: modules/Authentication/Kerberos/KerberosAuthModule.cpp func: "display_status_1()" line: 84 Msg: 1a2c3d4d : GSS-API error gss_acquire_cred: 186a5 :

Environment

  • APM
  • Kerberos authentication

Cause

The clock is not synced between APM, KDC and client.

Recommended Actions

Sync the clock between the APM, KDC and clients via NTP, or sync the clock manually, make sure the clock gap is shorter than 1 minutes (shorter than 1 minutes should work). Sync the clock via NTP is recommended.

Additional Information

none.
