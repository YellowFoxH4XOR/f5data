Description

CVE-1999-0511 states that, IP forwarding is enabled on a machine which is not a router or firewall. 

Environment

  • BIG-IP
  • CVE

Cause

Vulnerability scan on BIG-IP may report "IP Forwarding Enabled" on IPs of virtual servers, because of CVE-1999-0511. 
However, a virtual server is one of the most important components of any BIG-IP system configuration, and a primary purpose of a virtual server is to distribute traffic.

Recommended Actions

Refer to K16430721: IP forwarding vulnerability CVE-1999-0511
