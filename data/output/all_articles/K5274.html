Known Issue

This is the result of a known issue. The Explicit IP and Drop Packet load balancing methods are intended for use as fallback load balancing methods only. Because these methods are always successful, they are inappropriate for use as alternate load balancing methods. The fallback load balancing method is never used if you configure Explicit IP or Drop Packet as an alternate load balancing method.

Explicit IP and Drop Packet cannot be used as alternate load balancing methods on the BIG-IP Link Controller.

F5 Product Development tracked this issue as CR27399.
