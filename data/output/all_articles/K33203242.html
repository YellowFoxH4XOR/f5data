K33203242: 01071769:3: Decryption of the field (passphrase) for object (/Common/f5_api_com.key) failed while loading configuration that is encrypted with a different master key

Type
Support Solution
Published
2023-04-28
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K33203242

Description

  • You are trying to load a UCS file and get the below error:
      01071769:3: Decryption of the field (passphrase) for object (/Common/f5_api_com.key) failed while loading configuration that is encrypted with a different master key


Environment


  • UCS
  • BIG-IP LTM


Cause


Not known at the time of publication


Recommended Actions


1.-  Take a copy of the bigip.conf

2.- Using a text editor, open bigip.conf and remove f5_api_com.key and f5_api_com.crt from the config file.

3.- Verify the configuration with the following command:
     #tmsh load sys config verify

4.- If there are no errors, save the configuration:
     #tmsh save sys config
