Description

Virtual address responding for ICMP when pool members are forced offline
When the problem occurs, if the device in question is active (or becomes active), TMM will respond to incoming icmp echo requests for the virtual-address, even though all vips using that virtual-addres are down. (This isn't supposed to happen for vip addreses with icmp-echo set to "selective").

Environment

  • Virtual Server configured with pool
  • The HA pair has the device-group set to auto-sync
  • The pool members are forced down on the peer device
  • Virtual address configured with: icmp-echo selective
Cause

One of the following could have caused this behavior:

  • ID787853
  • ID756088
  • ID753805

Recommended Actions

Upgrade BIG-IP systems to 15.1

or

Change virtual-address to enabled and back to disabled
  1. Go to Local Traffic > Virtual Servers > Virtual Address List
  2. Chose interesting Virtual address and click enabled
  3. Change back to disabled
