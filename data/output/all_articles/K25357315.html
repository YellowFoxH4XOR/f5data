Description

System is offline, all TMM interfaces are down.

Repeated messages printed at command line:

emerg kernel: BUG: soft lockup - CPU#1 stuck

Messages observed in /var/log/ltm:

crit tmm[21597]: 01010025:2: Device error: hsbe2 hsb_lbb0 tre2_crc_errs count 65535.

Messages observed in /var/log/sel:

INF CPU 0 Nonfatal Error: Port 2a PCIe* logical port has detected an error.
INF CPU 0 PCI/DMI Error B:D:F 0x10: rperrsts: error_fatal_nonfatal_received
INF CPU 0 PCI/DMI Error B:D:F 0x10: rperrsts: multiple_error_fatal_nonfatal_received
INF CPU 0 PCI/DMI Error B:D:F 0x10: rperrsts: non_fatal_error_messages_received
INF CPU 0 PCI/DMI Error B:D:F 0x10: uncerrsts: completion_time_out_status
INF CPU 0 PCI/DMI Error B:D:F 0x10: xpglberrsts: pcie_aer_non_fatal_error

Environment

  • System offline
  • iSeries

Cause

HSB (high speed bridge connecting the TMM ports) fell off the PCI bus. This can be caused by hardware or software conditions.

Recommended Actions

Perform the following troubleshooting steps and recover the system by rebooting:

  1. First generate a qkview for future reference:

    qkview -s0 -f hsb_lockup_pre_reboot.qkview

  2. Reboot the system to clear the condition:

    reboot

    If the reboot does not clear the condition, generate another qkview, and open a Service Request with F5 Support, providing both qkviews. There may be a hardware failure.

    qkview -s0 -f hsb_lockup_post_reboot.qkview

  3. Assuming the reboot clears the offline condition, run an EUD test:

    • K7172: Overview of the End User Diagnostics software

    If the EUD fails, open a Service Request with F5 Support, provide the qkview and EUD output. There may be a hardware failure.

  4. If the reboot clears the condition and the EUD passes all tests, continue to monitor the system for a recurrence of the issue.

    Note: Ensure that the system is running a recent software release.

    If the problem does not happen again, it was likely a one-off glitch.

    If the problem does happen again, it is more indicative of a hardware issue, but further investigation would be needed. Open a Service Request with F5 Support, provide all of the data collected previously, and a new qkview.

Additional Information

Recent software versions will automatically reboot the system when this issue occurs, due to the fix for:

  • Bug ID 762073: Continuous TMM restarts when HSB drops off the PCI bus

This prevents the system from being stuck in an offline state.
