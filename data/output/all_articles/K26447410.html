Description
You have upgraded to version 14.1 or later.
The configuration does not load with /var/log/ltm  logging:

 Configuration error: Invalid classification application modification. A application id change from <A> to <B> is not supported

<A> and <B> are integers.

Environment

  • You are using Traffic (IP) Intelligence. This can be found in AFM and PEM.

Cause
The product categorises traffic and assigns it an Application name and an ID number.
New applications are constantly released and updated definitions are distributed  See  K22180795: Updating the BIG-IP classification signatures and engine which we call "IM" files.
However it is also possible to create manual application definitions. They exist in bigip.conf with the form

  ltm classification application /Common/snapchat_voice {
      application-id 16383
      category /Common/VoIP
      description "This app-id classifies VoIP traffic of snapchat application. You just know this will cause problems"
  }
However the IM files have already defined  snapchat_voice  with a different application-id. This conflict cannot be resolved and the configuration will not load.

Recommended Actions

  1.  Edit the bigip.conf file to remove the conflicting information.

Additional Information
Version 14.1 brings some internal changes to how IM files are loaded. Prior to this the configuration would load, but would not necessarily work correctly.
