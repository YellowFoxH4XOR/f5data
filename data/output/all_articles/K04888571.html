K04888571: Unable to delete iApp profiles from BIG-IQ

Type
Support Solution
Published
2020-10-16
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K04888571

Description
Upon deleting an iApp from managed BIG-IP, some objects are found to still be on the BIG-IQ that cannot be deleted.

Environment

  • BIG-IQ
  • BIG-IP with LTM imported to BIG-IQ
  • iApp deployment with strict updates set

Cause
Shared objects will not be deleted at the BIG-IQ.
Deleting the iApp at the BIG-IP and re-importing the LTM configuration leaves the shared objects on the BIG-IQ.

Recommended Actions

Steps to remove the orphaned objects from the BIG-IQ

On BIG-IQ CLI:
  1. Set iApp name in a variable. This is usually the part before the first underscore in the object name.
    eg. decade-uat_wan-optimized_tcp_profile would be "decade-uat"

            IAPP_NAME=decade-uat

        Set variable:

            IAPP_NAME=<iApp name>
  2. Make a backup of BIG-IQ
    tmsh save sys ucs b4_clean_iapp_${IAPP_NAME}_objects
     
  3. Identify the unique identifier for the iApp
    restcurl cm/adc-core/working-config/sys/application-service?\$filter=name%20eq%20%27${IAPP_NAME}%27\&\$select=name,id

    Sample output:

    {
      "totalItems": 1,
      "items": [
        {
          "name": "decade-uat",
          "id": "a70c8c44-d957-3803-a7de-a9bf01ed5b49"
        }
      ],
      "generation": 1,
      "kind": "cm:adc-core:working-config:sys:application-service:adcapplicationservicecollectionstate",
      "lastUpdateMicros": 1614110413915485,
      "selfLink": "https://localhost/mgmt/cm/adc-core/working-config/sys/application-service"
    }
     
  4. Using the id from the above output, modify the strict update setting of the iApp to allow removal from Big-IQ GUI
    restcurl -X PATCH -d '{"strictUpdates":"disabled"}' cm/adc-core/working-config/sys/application-service/a70c8c44-d957-3803-a7de-a9bf01ed5b49
     
  5. Using the Big-IQ GUI, find and remove all of the objects associated with this iApp
  6. Once all associated objects in the UI are removed, remove the iApp definition
    restcurl -X DELETE cm/adc-core/working-config/sys/application-service/a70c8c44-d957-3803-a7de-a9bf01ed5b49
