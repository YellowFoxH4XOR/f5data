K000135157: Incorrect detected keyword highlight in the ASM event log

Type
Support Solution
Published
2023-06-29
Updated
2023-06-29
Source
https://my.f5.com/manage/s/article/K000135157

Description

When a signature violation happens, You may find the ASM event log detected keyword highlight is not match the signature value content, it usually happens at the detected keyword is non-ASCII characters.

Environment

  • Detected keyword
  • Event log
  • Signature violation

Cause

This is a cosmetic issue, it does not cause an exception.

 Recommended Actions

If the signature blocks legitimate requests, it is advisable to examine the content of the URL request to determine whether it is a file or characters.
Typically, We recommended disable signature checks for binary files, refer to K10602137: Requests are blocked with content type application/octet-stream.
And in some cases, it may need to disable the signature check for this particular URL, refer to K8866: Disabling attack signature checks for specific entities.
