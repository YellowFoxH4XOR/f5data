Description

Beginning in version 13 you can configure Auto-fail back feature for an HA-Group

Environment

  •   Device service clustering (DSC)
  •  Auto failback feature

Cause

None

Recommended Actions

You must configure Failover Method for Failover using Preferred Device Order and then Load Aware if you would like to use the Auto Failback feature.

  1. Log in to the Configuration utility. Device Management => Traffic Groups => select your Traffic Group.
  2. From the Failover Method list, select a failover method: Failover using Preferred Device List and then Load Aware
  3. Then enable Always Fallback to First Device if it is Available.
  4. Once Auto Failback is selected, then in the Auto Failback Timeout field, type the number of seconds that you want the system to wait before failing back to the specified device. The range in seconds is from 0 to 300. The default is 60. A value of 40 to 60 seconds allows for state mirroring information to be re-mirrored for traffic groups.
  5. For the Failover Order setting, in the Load Aware box, select a device name and, using the Move button, move the name to the Preferred Order box. Repeat for each device that you want to include in the ordered list.
    1. This setting is optional. Only devices that are members of the relevant Sync-Failover device group are available for inclusion in the ordered list. If you have enabled the auto-failback feature on the traffic group, ensure that the first device in the ordered list is the device to which you want this traffic group to fail back to when that first device becomes available.
    2. If auto-failback is enabled and the first device in the Preferred Order list is unavailable, no auto-failback occurs and the traffic group continues to run on the current device. Also, if none of the devices in the list is currently available or there are no devices in the list when failover occurs, BIG-IP system performs load-aware failover instead, using the HA Load Factor setting. 

Important: If you configure this setting, you must configure the setting on every traffic group in the device group.
