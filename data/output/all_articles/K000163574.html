K000163574: AFM FQDN entries exceed system-wide firewall object limit

Type
Support Solution
Published
2026-10-06
Updated
2026-10-06
Source
https://my.f5.com/manage/s/article/K000163574

Description

In BIG-IP AFM 17.1.3, there is a hard system-wide limit of 256 configured FQDNs across all firewall objects, including address-lists and IP Intelligence custom categories. When this limit is reached, attempts to add additional FQDNs fail with error 01070734:3: Configuration error: The maximum number of configured FQDNs in firewall objects must not exceed 256. Adding FQDNs through IP Intelligence custom categories does not provide a separate pool; these entries count toward the same 256 limit. After reaching the limit, additional FQDNs added via tmsh may appear to succeed but are not actually loaded.

Environment

  • BIG-IP AFM 17.1.3

  • AFM firewall objects using FQDN entries, including address-lists and IP Intelligence custom categories

  • DNS resolver configured for FQDN handling

  • Requirement to block more than 500 domains

Cause

Architectural limitation in BIG-IP AFM 17.1.3. The maximum number of configured FQDNs is 256 system-wide across all firewall objects, including IP Intelligence custom categories. 

Answer/Recommended Actions

  • The 256 FQDN limit cannot be increased in BIG-IP AFM 17.1.3.

  • To verify current usage, use tmsh list security firewall fqdn-entity and tmsh list security ip-intelligence fqdn-entity to review the configured FQDN entities and confirm the combined count.

  • If more than 256 domains must be blocked, consider these alternatives:

    • Pre-resolve domains to IP addresses and use static IP address-lists in AFM (requires ongoing updates if domain-to-IP mappings change).

    • Perform domain blocking upstream at the DNS layer, such as with Response Policy Zones, before traffic reaches BIG-IP.

    • Use URL classification or categorization features if available, instead of FQDN-based firewall objects.

Additional Information

The expected separate 1,024-FQDN capacity for IP Intelligence custom categories does not apply in BIG-IP AFM 17.1.3; all FQDN entries are counted toward the same 256-entry ceiling. When the limit is exceeded, MCPD logs may show 01070734:3. When adding FQDNs through IP Intelligence after the limit is reached, tmsh may return success without actually loading the new entries. Administrators should validate the resulting configured entity counts rather than relying only on command completion status.
