Known Issue

This is the result of a known issue. If a user accesses a Microsoft Outlook Web Access (OWA) server through Portal Access, and the user forwards an email message containing embedded images through OWA, the images may not be displayed in the Microsoft Office Outlook email client when viewed by the recipient. The images in the same forwarded message may be displayed in OWA when viewed by the recipient using a browser.

Note: This issue occurs when using the default reverse-proxy engine for FirePass version 6.0.2. If you are running FirePass version 6.0.2 and the Compatibility Mode check box is selected on the Portal Access: Web Applications: Content Processing page under the Global Settings tab, you are not using the default reverse-proxy engine.

F5 Networks Product Development tracked this issue as CR92052 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-602-3 has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
