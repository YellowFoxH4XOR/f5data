Known Issue

This is the result of a known issue. If one of the reports on the ARX contains an invalid XML structure or corrupted content, the ARX CLI daemon will crash when executing the show reports command, or the ARX GUI will crash while clicking the Reports button. As a result, the CLI session will close or the ARX GUI will stop responding.

This issue does not affect client access. However, when encountered via the CLI, an error message similar to the following example will display:

cli_daemon: XmlScanner.cc:698: static char* XmlScanner::scanBackwardForElementValue(IndexedBuffer&, const char*, bool&): Assertion `isBeginTag' failed.
Connection to 172.30.10.10 closed.

F5 Product Development tracked this issue as ID 38714, and it was fixed in ARX version 5.1.7. For information about upgrading, refer to the ARX Release Notes.

Additionally, this issue was fixed in ARX versions 5.0.6 HF8 (build 11774), 5.1.0 HF3 (build 11932), and 5.1.5 HF3 (build 11970). Customers affected by this issue should contact F5 Technical Support, referencing this Solution number and the associated ID number, to request the hotfix.

Workaround

To verify whether you are affected by this issue, you can examine the backtrace of the core file using the show cores command. For example:

#0  0xb7dea7c7 in raise () from /lib/tls/libc.so.6
#1  0xb7dec06b in abort () from /lib/tls/libc.so.6
#2  0xb7de3735 in __assert_fail () from /lib/tls/libc.so.6
#3  0x710bcbd1 in XmlScanner::scanBackwardForElementValue (buffer=@0x6e431c00,
    tagName=0x7177098f "", isEmptyTag=@0x6e431b08)
    at XmlScanner.cc:743

Note: For more information about using the show cores command, refer to the ARX CLI Reference Guide.

When this issue is encountered via the ARX GUI, you must restart the ARX system. When this issue is encountered via the CLI session, you will need to reconnect to continue managing your ARX system.

Note: Customers affected by this issue can contact F5 Technical Support and request assistance restarting the ARX Manager GUI from the CLI without requiring the ARX system to be restarted.
