Description

You can observe certain SNMP OIDs not reflecting correct values after upgrade to 15.1.0 or later.

Environment

  • BIG-IP
  • Running software 15.1.0 or later
  • SNMP

Cause

The behavior changed due to ID 934501:
Bug ID 934501: SysClientsslStatCurConns and sysClientsslStatMaxConns have been deprecated

 Recommended Actions

Reported OIDs are deprecated and you should use different one as listed below:
Old OID:New OID:
F5-BIGIP-LOCAL-MIB::ltmClientSslStatCurConnsF5-BIGIP-LOCAL-MIB::ltmClientSslStatCurNativeConns
F5-BIGIP-LOCAL-MIB::ltmClientSslStatMaxConnsF5-BIGIP-LOCAL-MIB::ltmClientSslStatMaxNativeConns
F5-BIGIP-LOCAL-MIB::ltmServerSslStatCurConnsF5-BIGIP-LOCAL-MIB::ltmServerSslStatCurNativeConns
F5-BIGIP-LOCAL-MIB::ltmServerSslStatMaxConnsF5-BIGIP-LOCAL-MIB::ltmServerSslStatMaxNativeConns
 
Below presented example of failing and working OID.
Old OID:
snmpwalk -v 2c -c public localhost F5-BIGIP-LOCAL-MIB::ltmClientSslStatCurConns
F5-BIGIP-LOCAL-MIB::ltmClientSslStatCurNativeConns."/Common/clientssl" = Gauge32: 0

New OID:
snmpwalk -v 2c -c public localhost F5-BIGIP-LOCAL-MIB::ltmClientSslStatCurNativeConns
F5-BIGIP-LOCAL-MIB::ltmClientSslStatCurNativeConns."/Common/clientssl" = Gauge32: 6
