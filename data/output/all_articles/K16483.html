Known Issue

Kerberos single sign-on (SSO) may fail when the Key-Distribution Center (KDC) field is undefined.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured to provide Kerberos SSO authentication.
  • The KDC field in the Kerberos SSO configuration is undefined (blank).

You normally specify an IP address or the host name of the KDC for the server's realm when configuring Kerberos SSO. Specifying an IP address results in the fastest Kerberos SSO processing. If you leave the KDC field undefined in the configuration, Kerberos SSO processing is slowest and users may be unable to authenticate properly.

Impact

Users are unable to authenticate to the BIG-IP APM system using Kerberos SSO.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H518520 on the Diagnostics > Identified > Medium screen.
  • Authentication using Kerberos SSO fails.
  • You may view a message in the /var/log/apm file that appears similar to the following example:

err websso.0[29236]: 014d0005:3: Kerberos: can't get TGT for host/svc.example.corp.com@EXAMPLE.CORP.COM - Cannot contact any KDC for realm 'EXAMPLE.CORP.COM' (-1765328228)

Workaround

To work around this issue, you can edit the /etc/krb5.conf file and set the dns_lookup_kdc value to true. To do so, perform the following procedure:

Impact of procedure: Incorrectly editing the krb5.conf file may prevent the Kerberos daemon from loading and cause the Kerberos authentication to fail. This change is not synchronized across clusters and may revert during upgrades or other maintenance operations.

  1. Log in to the BIG-IP APM command line.
  2. Create a backup of the /etc/krb5.conf file by typing the following command:

    cp /etc/krb5.conf /etc/krb5.conf.sol16483
  3. Using a text editor, open the /etc/krb5.conf file for editing.
  4. In the [libdefaults] stanza, locate the dns_lookup_kdc setting.

    The following example shows the default setting of false:

    [libdefaults]
    default_realm = EXAMPLE.COM
    dns_lookup_realm = false
    dns_lookup_kdc = false
    ticket_lifetime = 24h
    forwardable = yes

  5. Using the text editor, change the dns_lookup_kdc setting from false to true.

    For example:

    [libdefaults]
    default_realm = EXAMPLE.COM
    dns_lookup_realm = false
    dns_lookup_kdc = true
    ticket_lifetime = 24h
    forwardable = yes

  6. Save the file and exit the text editor.
