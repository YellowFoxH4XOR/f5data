Known Issue

This is the result of a known issue. When 200 or more monitors are configured on a BIG-IP LTM system using the default five second interval, it can take 30 seconds or more for the BIG-IP LTM to mark nodes down or up when network connectivity is lost.

Note: The average observed time is about 30 to 60 seconds to mark all objects down and log the information, and 45 to 120 seconds to mark all objects up and log the information. This time can increase as the number of monitor instances increases; the time is also affected by the interval used. The greater the interval, the longer it takes for the monitor to perform the necessary checks and notify the system of the status. Sampling is based on a network condition in which the link is removed or connectivity has been lost for a period of up to 20 seconds.

F5 Networks Product Development tracked this issue as CR87872 and it was fixed in BIG-IP LTM version 9.4.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.
