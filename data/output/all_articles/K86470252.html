K86470252: BIG-IQ Centralized Management Monitoring >> EVENTS >> DoS >> DoS Summary >> attack ID page some columns are empty

Support Solution
Published

2023-02-21
Applies to

  • BIG-IQ Centralized Management: 8.X.X
Source
https://my.f5.com/manage/s/article/K86470252

Description

When a BIG-IP device with AFM and ASM module is managed by BIG-IQ, and on BIG-IQ, collecting statistics is enabled, we failed to see some columns in Centralized Management Monitoring >> EVENTS >> DoS >> DoS Summary >> attack ID page. To be more specific, refer to below screenshot.
  

  • 'Mitigation Action', 'Mitigation Reason', 'EPS', 'Detection Threshold', 'Baseline EPS' and 'Attack Latency' etc are empty for  Network DoS event.
  • In the orange rectangle, the 'Action' is 'None' when DoS Mode is 'enforced'.
  • there is no error messages in logs

Environment

  • BIG-IQ Centralized Management
  • BIG-IP AFM module
  • BIG-IP ASM module
  • DoS summary

Cause

This is by design and BIG-IQ is working as expected.

Recommended Actions

  1. For Network DoS event, the aforementioned columns are expected to be empty.

  2. For Layer7 DoD event, these columns will show. Below is one taken from lab device

            

  1. The mitigation action will be 'drop' during attack. Once the attack stopped, it will become 'None'.
