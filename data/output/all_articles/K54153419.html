Description

Observing error events in /var/log/httpd/httpd_error

  • err httpd[<PID>]: [error] [client 10.10.10.10] File does not exist: /usr/local/www/<Location>
  • <PID> - Process ID
  • <Location> - Requested URI

Environment

  • BIG-IP Configuration Utility

Cause

Making a request to a non-existing location to the F5 Configuration Utility
Example: https://<BIGIP>/_status
                                   <BIGIP> - Hostname or IP address of F5 Configuration Utility

Recommended Actions

  • Identify client system making requests and either stop or correct the requests.

Additional Information

  • REST Clients making requests to non-existing locations
  • Scanners probing Big-IP Configuration Utility
  • Admins making requests to non-existing URLs
