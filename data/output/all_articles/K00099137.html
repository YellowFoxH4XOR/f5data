Description

In BIG-IP GTM/DNS topology configuration we can put multiple region records into one region.
For example:

gtm region no_not {
    region-members {
                    not subnet 192.0.2.0/24 { }
                    not subnet 192.168.0.0/16 { }
                    state CN/Beijing { }
                    state CN/Shanghai { }
    }
}

 To determine if a LDNS IP matches this region, both conditions must be met:

  • At least one match of a positive item (“is” items)
  • Match for all negated items (“not” items)
For the example above, the logic is: ( not in subnet 192.0.2.0/24 and not in subnet 192.168.0.0/16) and (in state CN/Beijing or in state CN/Shanghai).

Environment

  • BIG-IP GTM/DNS
  • Multiple region-members defined in topology region configuration.

Cause

None

Recommended Actions

Please fully understand the behavior and work out the proper configuration.
