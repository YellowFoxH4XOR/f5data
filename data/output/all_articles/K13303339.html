Description
There might be cases where an SNMP alert cannot be created in the production environment. This test is helpful for such scenarios, to verify if BIG-IP is generating emails to the mail hub defined in outbound SMTP settings.

Environment

  • BIG-IP generating emails
  • Outbound SMTP 
  • Bash mode in CLI

Cause
SNMP alert cannot be created in a production environment.

Recommended Actions

  1. Login to CLI
  2. Change to bash mode from tmos mode by entering the command
    #bash
  3. To test sending an email, run the below command
    # echo "Subject:<subject>" | sendmail -vs <email address>

   For example:
   echo "Subject: Smtp test mail" | sendmail -vs j.smith@example.com 
   Output:
