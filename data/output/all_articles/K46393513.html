Topic

You should consider using this procedure under the following condition:

  • You want to filter DNS requests based on a group of allowlisted fully qualified domain names (FQDNs) and send approved requests to a pool of DNS resolvers.

Description

In some cases, you may want the BIG-IP system to intercept DNS requests from the client and apply security filtering controls. This kind of implementation can be used to protect internal clients from connecting to malicious servers and accessing undesirable content. For example, you can configure the BIG-IP system to transparently filter internal DNS requests based on the FQDN and send approved requests to a pool of DNS resolvers while returning the desired DNS response, such as NXDOMAIN, for unapproved requests.

To filter DNS requests by FQDN and send approved requests to a pool of DNS resolvers, perform the following procedures:

  • Create the data group with the domain names to be allowlisted
  • Create the iRule
  • Create a pool of DNS servers
  • Create the DNS profile
  • Create the virtual server

Prerequisites

You must meet the following prerequisite to use this procedure:

  • The client or client’s LDNS is configured to send DNS requests through the BIG-IP system.

Procedures

Create the data group with the domain names to be allowlisted

Note: F5 is working to eliminate exclusionary language in our products and documentation. For more information, refer to K34150231: Exclusionary language in F5 products and documentation.

To filter the DNS requests, you should first create a data group containing the list of domain names to be allowlisted. If you plan to add a large number of domain names to the data group, you should use an external data group. For more information about external data groups, refer to the Supplemental Information section. To create the data group with the domain names to be allowlisted, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > iRules > Data Group List.
  3. Select Create.
  4. For Name, enter a name for the data group.

    For example, Allowlist_Domains.

  5. For Type, select String.
  6. In the Records section, enter the domain name to be allowlisted in the String field.

    For example, .example.com

  7. Select Add.
  8. Repeat steps 6-7 for each domain name to be allowlisted.
  9. Select Finished.

Create the iRule

After creating the data group, create the iRule to intercept DNS requests from the client and apply security filtering controls. To create the iRule, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to DNS > Delivery > iRules > iRule List.
  3. Select Create.
  4. For Name, enter a name for the iRule.
  5. For Definition, enter the desired DNS iRule code.

    For example, the following iRule code sends a NXDOMAIN response and logs request information when the requested domain name does not match an FQDN listed in the Allowlist_Domains data group:

    when DNS_REQUEST {
    set fqdn_name .[DNS::question name]
    if { [class match $fqdn_name ends_with Allowlist_Domains] } {
        #log local0. "Request for Good Domain from: [IP::client_addr] Question: [DNS::question name]"
    }
    if { not [class match $fqdn_name ends_with Allowlist_Domains] } {
        DNS::header rcode NXDOMAIN
        DNS::return
        log local0. "Request for Bad Domain from: [IP::client_addr] Question: [DNS::question name]"
    }
    }

  6. Select Finished.

Create a pool of DNS servers

To create a pool of DNS servers that will manage the approved DNS requests, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Pools > Pool List.
  3. Select Create.
  4. For Name, enter a name for the pool.

    For example, DNS_resolvers.

  5. For Load Balancing Method, select the desired method.

    For example, Round Robin.

  6. In the New Members section, define the following settings:
    • For Node Name, enter the name of the node.
    • For Address, enter the IP address of the DNS resolver.
    • For Service Port, enter the DNS service port number.

      For example, 53

  7. Select Add.
  8. Repeat steps 6-7 for each DNS resolver to be added to the pool.
  9. Select Finished.

Create the DNS profile

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > Services > DNS.
  3. Select Create.
  4. For Name, enter a name for the DNS profile.
  5. Select the Custom check box.
  6. For Use BIND Server on BIG-IP, select Disabled.
  7. Select Finished.

Create the virtual server

To create the virtual server that will intercept DNS requests from the client, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Virtual Servers > Virtual Server List.
  3. Select Create.
  4. For Name, enter a name for the virtual server.

    For example, DNS_allowlist.

  5. For Type, select Standard.
  6. For Destination Address/Mask, enter an IP address for the virtual server.

    For example, if the BIG-IP system is the default gateway for the client requests, you can specify a wildcard virtual server address, such as 0.0.0.0/0, to match all DNS requests.

  7. For Service Port, enter the DNS service port, 53.
  8. For Protocol, select UDP.
  9. For DNS Profile, select the DNS profile you created in the previous procedure.
  10. In the Resources section, define the following settings:
    • For iRules, move the DNS allowlist iRule you previously created from Available to Enabled.
    • For Default Pool, select the pool of DNS servers that you previously created.
  11. Select Finished.
