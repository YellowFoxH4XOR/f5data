K8454: Upgrading to BIG-IP version 9.4.4 disables the advanced routing module

Known Issue

This is the result of a known issue. When the BIG-IP system is licensed for the advanced routing module (ARM), and an upgrade is performed from a previous version to BIG-IP version 9.4.4, the BigDB keys used to enable the routing protocols are disabled.

For example, if your BIG-IP system is licensed for the ARM, and you upgrade to version 9.4.4, you will likely receive the following message when starting the vtysh shell:

# vtysh
% Connection is closed!

F5 Networks Product Development tracked this issue as CR93364 and it was fixed in BIG-IP LTM version 9.4.5. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

To workaround this issue, perform the following procedure:

  1. Log in to the command line.
  2. To enable each routing protocol, type the following command:

    bigpipe db tmrouted.<protocol> enable

    For example, if your BIG-IP system is licensed for the BGP routing daemon, you would type the following command:

    bigpipe db tmrouted.bgp enable
  3. To enable tmrouted and ensure that the service starts at boot, type the following command:

    bigstart add tmrouted
