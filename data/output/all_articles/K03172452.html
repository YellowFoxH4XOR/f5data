Issue

Error Message

01490107:3: <session_ID>: AD module: change password for '<user>' failed: Requested effective lifetime is negative or too short, principal name: <user>@<domain>. Please verify Active Directory and DNS configuration.

In this error message, note the following:

  • <session_ID> is the unique MRH Session Cookie assigned to this session
  • <user> is the username associated with the password
  • <domain> is the domain to which the user is attempting to authenticate

For example:

err apd[13744]: 01490107:3: 11ca7acd: AD module: change password for 'user_test' failed: Requested effective lifetime is negative or too short, principal name: user_test@EXAMPLE.COM. Please verify Active Directory and DNS configuration.
 

Message Location

You may encounter this message in the following location:

  • The /var/log/apm file
     
Description

This message occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with an access policy using an Active Directory server for its AAA configuration.
  • The BIG-IP APM access policy is configured to facilitate an Active Directory password reset.
  • There is a significant time difference between the BIG-IP APM and the Active Directory server.

Impact

Users are unable to successfully complete an Active Directory password update.

Recommended Actions

To mitigate this issue, you should ensure an NTP server is configured on the BIG-IP APM system and the Active Directory server, and that the time is correctly synchronized the between the systems.
