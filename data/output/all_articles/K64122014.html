Description

When using Outlook web (OWA) users are getting "Something went wrong =(" error in the browser after logging in and are unable to proceed further.

  • The issue happens across all browsers.
  • Checking the request using browser developer tools, the request https://webmail.domain.com/owa/auth/errorfe.aspx?**** failed with a HTTP 500.
  • The query string in the above URL has owaError=SrvErr:null,ClientErr:

Environment

Using iApp for load balancing back-end Exchange servers.

  • BIG-IP v14.1.0
  • Exchange server 2016 used in back-end
  • Exchange server 2016 v1.0.2 iApp is being used.

Cause

This is likely caused by BIG-IP caching a response and serving it from cache instead of going back to the back-end server to serve the client.

Recommended Actions

This can be resolved by disabling caching profile which is automatically created by iApp deployment.

  1. Go to: Local Traffic  ››  Virtual Servers : Virtual Server List  ››  <Exchange-Server-iApp-VS>
  2. Under Acceleration, set the Web Acceleration Profile to "None" from the profile set by iApp.

    Note: If iApp is using "Strict Updates", then this profile can't be modified. Follow: K51033596: Error Message: 010715bc:3: The application service (<iApp name>) has strict updates enabled, the object (<iApp object>) must be updated using an application management interface to disable strict updates and then re-try the steps in this Article again.
