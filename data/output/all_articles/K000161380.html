Topic

Microsoft Azure is introducing the Microsoft Azure Network Adapter (MANA) across multiple existing and new virtual machine (VM) families. MANA is a next-generation network interface designed to improve performance, latency, and reliability of Azure virtual machines. At present, BIG IP VE does not support MANA. Support is planned for future BIG IP long-term support (LTS) releases. In the meantime, customers running BIG IP VE on Azure can follow recommended configurations to ensure a smooth and reliable networking experience.

Description

As part of Azure infrastructure modernization, Microsoft is gradually enabling MANA on a wide range of VM families, including both existing and newer instance types. For BIG IP VE deployments:

  • When placed on MANA-enabled hardware, BIG IP cannot leverage the MANA interface.
  • Networking falls back to the legacy NetVSC adapter, with existing BIG-IP drivers continuing to work on TMOS.
  • This fallback behavior should work seamlessly.

A significant number of VM families are impacted, including:

  • Dv2, Dv3, Dv4, Dv5 series
  • Esv3, Esv4, Esv5 series
  • Fs, Fsv2, Bsv2, Av2 • Ls, G, GS
  • Newer Cobalt 100-based v6 families (e.g., Dpsv6, Epsv6)

Recommended actions

F5 recommends the following options for customers running BIG IP VE in Azure:

  • Option 1: Use Legacy VM Placement (Recommended – Short Term)
    Apply the LegacyVMNVA tag to your virtual machines or Virtual Machine Scale Sets (VMSS).
    • Prevents placement on MANA-enabled hardware
    • Ensures continued use of supported networking behavior
    • Serves as a temporary mitigation during transition

    For implementation details, refer to Microsoft documentation on MANA opt-out. 

    Important: The LegacyVMNVA tag must be applied by July 31, 2026. VMs that are created or tagged after this date may be placed on MANA-capable hardware. After May 31, 2027, the tag is ignored and all MANA-eligible VM series will be placed on MANA-capable hardware.

  • Option 2: Allow Placement on MANA-enabled Hardware
    If the LegacyVMNVA tag is not applied:
    • VM instances may be placed on MANA-enabled infrastructure
    • BIG IP VE will fallback to NetVSC
    • Networking functionality continues but without MANA benefits.

    F5 is currently conducting a comprehensive evaluation to determine whether BIG-IP Virtual Editions deployed on MANA-enabled virtual machines may experience any performance degradation. The findings will be communicated to customers once the assessment is complete and validated.

July 31, 2026

  • Upgrade to MANA-supported OS or

Opt-out mitigation (LegacyVMNVA) will be retired
