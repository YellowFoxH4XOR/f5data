Issue

Error Message

Error Message: 01070601:3: A self IP matching the old network / mask <IP address>  / <subnet> still exists in the configuration

For example:

01070601:3: A self IP matching the old network / mask 10.10.10.0 / 255.255.255.0 still exists in the configuration

Message Location

You may encounter this message in the following locations:

  • /var/log/webui.log file
  • Configuration utility
Description

This message may occur when the following conditions are met:

  • You attempt to change the subnet mask of a self IP address when there is another self IP address configured with the same subnet mask.

Impact

You will not be able to change the subnet mask until you perform the steps within the recommended actions.

Recommended Actions

In order to change the subnet mask for the below listed Self-IP's you will need to perform the following procedure.

Impact of procedure: Changing the subnet mask of a Self IP address could result in unexpected routing conditions. 

net self external_floating {
    address 10.10.10.1/24
    allow-service all
    floating enabled
    traffic-group traffic-group-1
    unit 1
    vlan external_vlan
}

net self external_self {
    address 10.10.10.2/24
    allow-service {
        default
    }
    traffic-group traffic-group-local-only
    vlan external_vlan
}

Note: It is recommended that you create a UCS archive of the system before performing this procedure. K13132: Backing up and restoring BIG-IP configuration files with a UCS archive. You should also perform this procedure on the standby unit of an HA pair first.
  1. Log in to the BIG-IP configuration utility or the standby unit and navigate to Network > Self IPs.
  2. Delete the floating self IP address.
  3. Next select the non-floating Self IP address.
  4. update the subnet mask.
  5. click update.
  6. Recreate the floating self IP address with the updated subnet mask.
  7. Next you will want to failover to the standby unit and test the changes.
  8. If all is good, then you can repeat the above procedure on the previously active unit.
