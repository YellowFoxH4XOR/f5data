Known Issue


This is the result of a known issue. The bigpipe pool <pool> persist dump command should display persistence records for all persistence modes; however, SIP persistence was omitted.

F5 Product Development tracked this issue as CR27607 and CR43900 and it was fixed in BIG-IP version 4.5.13 for the 4.5 software branch. For information about upgrading, refer to the BIG-IP release notes.

This issue still exists in the 4.6 software branch.
