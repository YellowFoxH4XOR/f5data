K22400527: Remove a BIG-IP from BIG-IQ after BIG-IP IP address change

Type
Support Solution
Published
2022-11-04
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K22400527

Description
Error Message
BIG-IQ cannot remove the selected device because the device has service configurations on it or services are in the process of being removed.

Environment

  • BIG-IQ
  • BIG-IP where management IP has been changed after discovery by BIG-IQ

Cause
Change in BIG-IP management IP locally

Recommended Actions

[BIG-IP]
If the BIG-IP shows as managed by BIG-IQ, use these instructions to clear up the BIG-IP:
K39233324: BIG-IP systems report being managed by the BIG-IQ system after being removed from the BIG-IQ system's device inventory
Alternate set of instructions are here: K01131523: Removing a managed device from BIG-IQ using REST API and UUID

[BIG-IQ]
On the BIG-IQ, to remove references to a BIG-IP, use the commands here
An alternate set of instructions on the BIG-IQ are here

Once the issue is cleared up at both the BIG-IP and BIG-IQ, you can discover and import the devices.
