Description

 

Central Policy Building doesn't work

errors in restjavad logs:

/var/log/restjavad.0.log

[/cm/asm/tasks/allocate-cpb/bf8d5a53-18fd-481e-9291-aac6980befa0/worker AllocateCPBTaskWorker] No available Central-Policy-Building node

Elasticsearch cluster state:

# curl -s -u admin:admin --insecure https://localhost:9200/_cluster/health?pretty

{

"cluster_name" : "427511cf-20d0-4795-9eaa-35719624f2a7",

"status" : "red", <<====== !!!!

....

 

 

Environment

  • BIG-IQ CM DCD Cluster
  • Stats Collection enabled
  • Central Policy Building enabled

Cause

DCD Cluster status is RED causing DCDs unavailable for Central Policy Building

Recommended Actions

1. Make sure that cluster state is GREEN by rerouting unassigned shard or removing them if re-route process fails.

  • for re-route :

curl -sk "https://localhost:9200/_cluster/reroute?retry_failed=true" -X POST

  • for removing unassigned shards:

K81715478: Error Message: At least one primary shard (and all of its replicas) are missing. This means that you are missing data; searches will return partial results, and indexing into that shard will return an exception

2. Verify retention policy for statistics and events and set it to match disk capacity of DCD nodes:

K000136164: Setting Statistics retention on BIG-IQ

K53943550: Setting log events retention on BIG-IQ
