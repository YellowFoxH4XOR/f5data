K05431125: The probe pool cannot work, the BIG-IP did not send out monitor traffic

Type
Support Solution
Published
2021-03-29
Updated
2023-02-21
Status
Legacy Content
Applies to

  • BIG-IP DNS: 12.1.5
Source
https://my.f5.com/manage/s/article/K05431125

Description

The probe pool was configured, and the pool member (BIG-IP DNS) did not send out the monitor traffic.
Enable debug log for gtmd, on the BIG-IP DNS which should do the probe task, find the log like below:

debug gtmd[<PID>]: 011ae039:7: Check probing of IP:Port <IP>:<port> in DC /Common/<Data center>
debug gtmd[<PID>]: 011ae03a:7: Will not probe <IP>:<port> in DC /Common/<Data center> because will be done by other GTM (/Common/<BIG-IP name>:<IP>)

The debug log indicates that other BIG-IP DNS will do the probe task. And on the other BIG-IP DNS, the debug log indicate this BIG-IP DNS will do the probe task. It is a loop.

Environment

  • BIG-IP DNS
  • Probe pool

Cause

The iQuery connection between BIG-IP DNS is not fully mesh.

Recommended Actions

Fix the iQuery connection between BIG-IP DNS devices, make sure they create fully mesh iQuery connection.

Additional Information

None.
