K000157113: Certificate at host activate.f5.com is not trusted

Type
Support Solution
Published
2025-10-23
Updated
2025-10-23
Source
https://my.f5.com/manage/s/article/K000157113

Description

When attempting to automatically reactivate a CAT license on BIG-IQ, its status changes to pending and returns "Certificate at host activate.f5.com is not trusted. Please verify the host is correct, and set up SSL Certificate Verification settings for the server certificate or one of its trust chain certificates." The license offerings don't update and the Reactivate option is greyed out/inaccessible.

Environment

  • BIG-IQ

  • Flexible Consumption Program (FCP)
  • Catalog (CAT) license
  • Reactivate CAT
  • Internet access from BIG-IQ

Cause

This issue is caused by Bug ID 1966341: License Reactivation fails on BIG-IQ with SSL Exception.

Recommended Actions

Perform the workaround in Bug ID 1966341.

Additional Information

None
