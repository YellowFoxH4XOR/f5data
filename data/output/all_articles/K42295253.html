Known Issue

The TMOS Shell (tmsh) may erroneously log an [api-status-warning] message when you list the configuration of a BIG-IP system.

This issue occurs when all of the following conditions are met:

  • You perform an upgrade to the affected software version listed in the Applies to (see versions) box, located in the upper-right corner of this article.
  • You attempt to list the BIG-IP configuration using the tmsh list command.

Impact

There is no impact. The BIG-IP system performs the list operation successfully, but logs additional warning messages to the /var/log/ltm file and the console output.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you run the tmsh list command, you notice warning messages in the /var/log/ltm file and the console output that appear similar to the following example:

    [api-status-warning] ltm/profile/fastl4, properties : deprecated : software-syn-cookie

    Note: You should expect this warning message when you query the specific BIG-IP object.

Resolution

Status

F5 Product Development has assigned ID 652056 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases, point releases, or hotfixes that resolve this issue, refer to the following table.

Note: There is a similar issue with a different cause, which affects later BIG-IP versions. For more information, refer Bug ID 804309.

Workaround

To work around this issue, you can disable deprecated API warnings. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Disable deprecated API warning messages by typing the following command:

    modify /mgmt shared settings api-status log resource-property deprecatedApiAllowed false

  3. Save the change by typing the following command:

    save /sys config
