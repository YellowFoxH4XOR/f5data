Known Issue

This is the result of a known issue. When a software installation is initiated from the Configuration utility, the system immediately displays a progress bar with the word Complete in it. The progress bar does not indicate that the installation is complete; because the progress bar is not filled with any color, it indicates that the installation has not yet begun.

The use of the word Complete inside the progress bar may be confusing if the BIG-IP system is not configured to automatically refresh the page. In this case, the BIG-IP administrator will never see the progress bar fill and the Configuration utility will continue to display the progress bar indefinitely.

Due to this issue, a BIG-IP administrator may believe that an installation is complete while in reality it is not.

F5 Product Development is tracking this issue as ID 333358 (formerly CR138864).

Workaround

When performing a software installation using the Configuration utility, select an auto refresh interval from the drop-down menu and then click the Refresh button. Performing this action will ensure that you have correct knowledge of the installation progress. An installation is not complete until the task is removed from the Image Installation Status table.

Additional Information

Because of this issue, a BIG-IP administrator may decide to reboot the BIG-IP system while an installation is still running. Performing this operation may produce unexpected results. For example, if a BIG-IP system is rebooted during a hotfix installation, the system may no longer boot from the target boot location, requiring that location to be re-imaged.
