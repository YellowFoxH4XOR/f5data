Description

One of the BIG-IP appliance's LED is showing as Amber/Orange.

Environment

  • iSeries device (e.g., i2000, i4000 series)
  • TMOS version 15.x onwards

Cause

Depending on which LED is showing Amber, it might indicate different causes.

Recommended Actions

Please observe which of the four LEDs available (Status, Alarm, Power 1, and Power 2) is showing Amber status.

Status

If Status LED is Amber, one common reason is that device is in Standby mode. Otherwise, it could mean that device is either:

  • in the standby power state, or
  • powered on and in the process of booting to TMOS, or
  • is powered on, but offline, such as when booted to the End-User Diagnostic (EUD).

Alarm

If Alarm LED is lit, please run the following command:

tmsh show /sys alert

and investigate further any recent events. To clear the Alarm LED, you may refer to Clear LCD alarms on iSeries device.

Power

If Power 1 or 2 LED is Amber, it could indicate that one of the PSU units is not operating normally.

You may run the following command, and see the "PSU" status section:

tmsh show /sys hardware

If one of the PSU units is showing as "down", you may refer to Troubleshooting BIG-IP power supply issues.
