K000138797: System allowed-ips profiles with dash ("-") are automatically removed after upgrading to F5OS-A 1.7.0

Type
Support Solution
Published
2024-03-03
Updated
2024-03-03
Applies to
  • F5OS
  • F5OS-A: 1.7.X, 1.5.X, 1.4.X, 1.7.0, 1.5.1, 1.5.0, 1.4.0
Source
https://my.f5.com/manage/s/article/K000138797

Description

System allowed-ips profile name that contains one or more dash ("-") will be removed after upgrading to F5OS-A 1.7.0.

Environment

  • F5OS-A
  • Upgrading to F5OS-A 1.7.0

Cause

1536413

Recommended Actions

After upgrading, reinstate the missing allow-ip configuration.
