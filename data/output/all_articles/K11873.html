Known Issue

This is the result of a known issue. If you configure a CIFS profile, the BIG-IP WOM may core when transferring a large file using the CIFS protocol.

F5 Product Development tracked this issue as ID 324356 (formerly CR141350) and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP WOM release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.2.0-1755.1-HF1, which has been issued for BIG-IP 10.2.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
