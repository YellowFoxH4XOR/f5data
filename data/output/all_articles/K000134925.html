K000134925: F5 Endpoint Inspector is not getting launched successfully on MacOS 13.x client

Type
Support Solution
Published
2023-06-06
Updated
2023-06-06
Applies to
  • BIG-IP
  • APM Clients
  • BIG-IP APM: 15.1.8, 16.1.3, 17.1.0, 14.1.5
Source
https://my.f5.com/manage/s/article/K000134925

Description

When connecting to the VPN using BIG-IP Edge Client on a MacOS 13.x client, the F5 Endpoint Inspector.app does not launch. Eventually, the session times out due to inactivity; and the user is denied logon to the APM.

Environment

  • MacOS 13.x client running a BIG-IP Edge Client version with the fix for the epi issue (K000132932) applied
  • Access policy VPE with an endpoint inspection check (such as Antivirus, Firewall) configured

 

Cause

There is a 3rd-party software on the MacOS client that is doing SSL inspection. This, in turn, is blocking the F5 Endpoint Inspector.app from launching/running. One such example is the Zscaler Client Connector.

 

 Recommended Actions

Disable the 3rd-party software doing SSL inspection on the affected MacOS client
