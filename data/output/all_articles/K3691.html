BIG-IP versions 4.5.11 and 4.6.3 introduce the following new command for displaying routes:

show_route

The output displays as follows:

destination          next hop      interface       flags
--------------------------------------------------------------------------------
default            172.16.101.21   external        <UP,GATEWAY,DONE,STATIC>
127.0.0.0/8        127.0.0.1       lo0             <UP,GATEWAY,REJECT,DONE,STATIC>
172.16.102.0/24    <direct>        internal        <UP,DONE,CLONING>
172.16.101.0/24    <direct>        external        <UP,DONE,CLONING>
192.168.101.132    <direct>        external        <UP,HOST,DONE,LLINFO,CLONED>

Where:

  • The destination column indicates the destination network for the route.
  • The next hop column indicates the router used as the next hop and <direct> indicates that the network is directly attached.
  • The interface column indicates the BIG-IP interface or VLAN with which the route is used.
  • The flags column provides system route characteristics. The most import of these flags is the first, which indicates if the route is up or down.

The show_route command replaces the netstat -r command used in previous versions of BIG-IP and, by default, prints the entire routing table.

To limit the output, you can use the following options in conjunction with the show_route command:

OptionOutput
-hPrints a help screen.
-qSuppresses the display header.
-cPrints only cloned routes.
-dPrints only routes created by a ZebOS routing module.
-pPrints only routes created by a gateway pool.
-sPrints only kernel static routes.

You can also use the <prefix> option as follows to filter using a partial address:

show_route [options] <prefix>

For example, the following command will print only those IP addresses that begin with 192:

show_route -q 192
