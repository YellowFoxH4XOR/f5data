To optimize the flow of traffic upon failover of a redundant BIG-IP pair, you can configure a feature known as MAC masquerading. MAC masquerading takes advantage of a shared media access control (MAC) address. Upon failover, the shared MAC address(es) float to the newly active BIG-IP along with the shared IP addresses.

Note: For information about choosing a locally unique hardware address, refer to K3523: Configuring a unique Media Access Control (MAC) address for MAC masquerade.

Note: MAC masquerading is not synchronized between BIG-IP systems. You must manually configure MAC masquerading identically on both the active and the standby system in a redundant pair.

Important: When you activate MAC masquerading on a VLAN, it can temporarily disrupt traffic on that VLAN while the surrounding network devices learn the new hardware address association.

After you have chosen a unique Media Access Control (MAC) address for to be used for MAC masquerade, you can assign the MAC masquerade address to the VLAN from the command line or the Configuration utility by performing one of the following procedures:

Command line

To configure MAC masquerading from the command line, type the following command, where the <vlan name list> variable is the name of the VLAN(s) and <MAC> variable is the MAC address the BIG-IP is going to masquerade as:

bigpipe vlan <vlan name list> mac_masq <MAC>

Repeat this procedure for all VLANs on which MAC masquerading is required.

When finished modifying the configuration, save the resulting configurations by typing the following command:

bigpipe save

Configuration utility

To activate MAC masquerading from the Configuration utility, perform the following procedure:

  1. From the menu, click Network.
  2. Click the VLAN on which you want to configure MAC masquerading.
  3. Type the unique MAC masquerade address selected earlier in the MAC masquerade field.
  4. Click Apply.

Repeat this procedure for all VLANs on which MAC masquerading is required.
