Description

Older versions of K33373310: Accessing an F5 rSeries tenant console directed users to run the command /usr/share/omd/kubevirt/virtctl to access a tenant's virtual console, which may sometimes return the following error message:

Can't connect to websocket: dial tcp [::1]:8080: connect: connection refused

Environment

  • F5OS-A
  • rSeries
  • Tenant serial console

Cause

virtctl requires the kubernetes proxy to be running first, which is not always the case. For example, on a freshly booted system.

Recommended Actions

On F5OS-A platforms, rather than running the virtctl binary directly from the /usr/share/omd/kubevirt directory, users should use the virtctl command from the system PATH which is located in the /usr/local/bin directory. The /usr/local/bin/virtctl file is a shell script that automatically starts the kube proxy if required, then runs the virtctl binary.

The virtctl syntax is virtctl console <tenant-name>

For example, to connect to tenant named tenant-1, use the following command:

virtctl console tenant-1

Additional Information

The virtctl script is not installed on current versions of the F5OS-C (VELOS) platform.
