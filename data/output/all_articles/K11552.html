Known Issue

This is the result of a known issue. When an NTLM profile is applied to a BIG-IP WebAccelerator enabled virtual server processing traffic using ESI (Edge Side Includes), TMM may crash and dump core.

F5 Product Development tracked this issue as CR137543, and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
