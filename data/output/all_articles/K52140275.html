Known Issue

The TMOS Shell (tmsh) allows you to configure mirrored persistence when no mirroring configuration exists.

This issue occurs when the following condition is met:

  • You use tmsh to create a persistence profile with mirroring enabled.

Impact

When no mirroring configuration exists, tmsh does not hide the mirror option for the persistence profile. This situation allows a user to configure the mirror option within the persistence profile, which may lead to a memory leak and degrade performance.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When no mirroring configuration exists, tmsh does not hide the mirroring option within a persistence profile, or prevent you from configuring mirroring.
  • When the mirroring configuration is not enabled, degraded performance or a memory leak may occur after you configure the mirroring option.

Workaround

To prevent accidentally configuring persistence mirroring when no mirroring configuration exists, F5 recommends that you use the Configuration utility, because the Configuration utility correctly hides the mirroring option within the persistence profile when no mirroring configuration exists.

To work around this issue, you can locate persistence profiles with mirroring enabled, and then disable mirroring for those profiles using tmsh. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To list the persistence profiles, type the following command:

    list ltm persistence

  3. Examine the persistence profiles to identify the ones with mirror enabled.
  4. To disable mirroring for each persistence profile, use the following command syntax:

    modify ltm persistence <persistence_type> <profile_name> mirror disabled

    For example:

    modify /ltm persistence ssl my-example-ssl-prof mirror disabled

  5. Save the changes by typing the following command:

    save sys config
