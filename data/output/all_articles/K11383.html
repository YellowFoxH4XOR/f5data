K11383: Java Application Tunnels are not supported in the Windows standalone client

Published
2010-04-12

Status
Legacy Content
Applies to

  • FirePass: 6.0.3, 6.1.0
Source

Topic

When connecting to FirePass through the Windows standalone client, Java Application Tunnels do not appear in the Application Tunnels folder. This behavior is by design as the Windows standalone client does not currently support Java Application Tunnels.

Note: Java Application Tunnels were introduced in FirePass version 6.0.3

Note: For more information about configuring FirePass Application Tunnels, refer to the FirePass Controller Administrator Guide.
