Description

Citrix sessions fail after enabling Duo MFA integration with BIG-IP APM with similar error messages as below:


_oauth_client_ag: OAuth Client: failed for server '/<partition name>/Oauth_Server_Test' using 'authorization_code' grant type (client_id=XXXXXX12345XXXXX), error: Invalid json.

Environment

  • Product: BIG-IP APM
  • Version: 16.X or 17.X
  • Configuration:
    • Citrix integrated with BIG-IP APM.
    • Duo MFA enabled for authentication.
    • Route domain configured for traffic routing.

Cause

The root cause of this issue can be twofold:

  1. A known limitation in BIG-IP APM where OAuth token requests are always routed through the default route domain (route domain 0), regardless of other configurations.
  2. Misconfiguration in DNS forward zones caused DNS queries to be directed to an incorrect resolver.

Recommended Actions

  1. Routing Configuration Workaround:

    • Configure traffic to route via the default route domain (route domain 0) for OAuth token requests as per system limitations described in K20465715.

  2. Firewall Rules Adjustment:

    • Ensure that traffic from BIG-IP to the Duo portal is allowed through the firewall.
    • Use commands like ip route get <duo security URL> and curl -vvk <duo security URL> to verify connectivity.

  3. DNS Resolver Fix:

    • Re-add forward zones using "." instead of specific names if DNS lookup queries are failing.
