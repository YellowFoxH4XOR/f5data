Topic

You should consider using this procedure under the following condition:

  • You need to license your BIG-IQ system.

To watch a video demo of this procedure, go to Licensing the BIG-IQ system.

Description

Before you can configure and use the BIG-IQ Centralized Management system, you must activate a valid license on the system. Starting in version 7.1.0, if you are setting up a Data Collection Device in BIG-IQ Centralized Management, you don't need to activate a valid license. If you are setting up a Data Collection Device running versions prior to BIG-IQ 7.1.0, you must activate a valid license on the device.

If you are setting up the BIG-IQ device as License Manager, refer to the Use BIG-IQ as a License Manager for BIG-IP Subscription and Enterprise License Agreement Programs chapter of the Deploy BIG-IQ to manage licenses for BIG-IP VE devices manual.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Before you can activate the license for the BIG-IQ system, you must obtain a base registration key. The base registration key is a 28-character string that indicates to the license server what F5 products you can license. The base registration key is pre-installed on new BIG-IQ systems. When you connect to the user interface, the Licensing page opens and displays the registration key.

    If you do not have a base registration key, contact your F5 Sales representative, or F5 Support.

    The format of the BIG-IQ base registration key is as follows:

    AAAAA-BBBBBB-CCC-DDDDDDD-EEEEEEE

  • The F5 License Server requires a dossier to create a license for the BIG-IQ system. The dossier is an encrypted list of key characteristics used to identify the platform.

    Your F5 product generates the dossier after you choose a license activation method. When choosing the Automatic activation method, the system automatically generates the dossier and submits it to the F5 License Server. When choosing the Manual activation method, the system generates and displays the dossier, so you can copy it and manually submit it to the F5 License Server.

  • Access to the F5 License Server

    The Automatic activation method requires that the BIG-IQ system has Internet access to automatically access the F5 License Server.

    The Manual activation method requires that you have Internet access from a management workstation. This is the workstation that you use to access the BIG-IQ user interface and generate the dossier. However, if required, you can transfer the dossier to an independent system that has Internet access.

Procedures

To activate the license on the BIG-IQ system using the user interface, you can use either the Automatic activation method or the Manual activation method. The activation method specifies the method by which you want the system to communicate with the F5 License Server.

Note: Starting in BIG-IQ 7.1.0, if you are setting up a Data Collection Device, you don't need to activate a valid license on the device.

  • Activate the license using the automatic activation method
  • Activate the license using the manual activation method
  • Activate an Add-On module

Activate the license using the automatic activation method

You can use the automatic method if the BIG-IQ management port is configured to route traffic to the Internet to access the F5 License Server. If the BIG-IQ management port is not configured to route traffic to the Internet, use the manual method.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ system as Administrator.
  2. If you connect to the user interface, and your BIG-IQ system is not yet licensed, you are prompted to license the system.

    In the Base Registration Key box, enter the base registration key.

  3. In the Add-On Registration Key List box, certain systems may require you to enter add-on registration keys for additional modules.
  4. Select Automatic.
  5. Select Activate.

    Note: If your license contains both Central Management and Logging Node features, the BIG-IQ system will require you to choose one of those features when you select Next. To change this selection after you have completed the BIG-IQ system setup, refer to K15886: Restoring the BIG-IQ system to factory default settings.

  6. The BIG-IQ system automatically connects to the F5 License Server and activates the license.

Activate the license using the manual activation method

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ system as Administrator.
  2. If you connect to the user interface and your BIG-IQ system is not licensed yet, you are prompted to license the system.

    In the Base Registration Key box, enter the base registration key.

  3. In the Add-On Registration Key List box, certain systems may require you to enter add-on registration keys for additional modules.
  4. Select Manual.
  5. Select Get Dossier.
  6. Copy the dossier and connect to the F5 Product Licensing page at the following address:

    https://secure.f5.com

  7. On the F5 Product Licensing page, in the row that lists BIG-IQ, select Activate License.
  8. Paste the dossier into the Enter your dossier box and select Next.
  9. Copy the license returned by the F5 Product Licensing page and paste it into the License box in the BIG-IQ system.
  10. Select Activate License.

    For BIG-IQ 5.0.0 and later, if the license contains both BIG-IQ Central Management and Logging Node features, the system opens the License Feature Selection menu; select your required feature and select OK.

    Note: If your license contains both Central Management and Logging Node features, the BIG-IQ system will require you to choose one of those features when you select Next. To change this selection after you have completed the BIG-IQ system setup, refer to K15886: Restoring the BIG-IQ system to factory default settings.

Activate an Add-On module

For additional functionality, you can add BIG-IQ feature modules to the BIG-IQ system. To add a feature module, you must obtain an Add-On registration key and re-activate the license. After you have obtained an Add-On registration key, you can activate the feature using the BIG-IQ user interface.

The format of the BIG-IQ Add-On registration key is as follows:

AAAAAAA-BBBBBBB

To use the manual activation method to re-activate the license with the Add-On registration, perform the following procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

BIG-IQ 5.2.0 and later

  1. Log in to the BIG-IQ system as Administrator.
  2. Select System.
  3. Select THIS DEVICE.
  4. Select Licensing.
  5. Select Reactivate.
  6. In the Add-On Key box, paste the Add-On registration key.
  7. Optional: To add an Add-On key, select the plus (+) symbol to get another Add-on Key box.
  8. Select Manual.
  9. Select Generate Dossier.
  10. Copy the dossier and connect to the F5 Product Licensing page at the following address:

    https://secure.f5.com

  11. On the F5 Product Licensing page, in the row that lists BIG-IQ, select Activate License.
  12. Paste the dossier into the Enter your dossier box and select Next.
  13. Copy the license returned by the F5 Product Licensing page and paste it into the License box in the BIG-IQ system.
  14. Select Activate.

BIG-IQ 5.0.0 and 5.1.0

  1. Log in to the BIG-IQ system as Administrator.
  2. Select System Management.
  3. Select BIG-IQ HA.
  4. Select the Device Name of the device to which you want to enter the Add-On key.
  5. Select Licensing.
  6. Select Reactivate.
  7. In the Add-On Key box, paste the Add-On registration key.
  8. Optional: To add an additional Add-On key, select the plus (+) symbol to get another Add-on Key box.
  9. Select Manual.
  10. Copy the dossier and connect to the F5 Product Licensing page at the following address:

    https://secure.f5.com

  11. On the F5 Product Licensing page, in the row that lists BIG-IQ, select Activate License.
  12. Paste the dossier into the Enter your dossier box and select Next.
  13. Copy the license returned by the F5 Product Licensing page and paste it into the License box in the BIG-IQ system.
  14. Select Activate.

BIG-IQ 4.x and Cloud and Orchestration 1.0.0

  1. Log in to the BIG-IQ system as Administrator.
  2. Select System.
  3. Perform the following steps for your version:
    • 4.5.0 and later and Cloud and Orchestration 1.0.0
      1. Select Configuration.
      2. Under BIG-IQ Systems, select HA Peer Group to expand the menu and double-click localhost.
      3. Select the Licensing tab.
    • 4.4.0
      1. Select Configuration.
      2. Under BIG-IQ Systems, select Management Group to expand the menu and select localhost.
      3. Select the gear symbol for localhost and choose Properties.
      4. Select the Licensing tab.
    • 4.3.0 and earlier:
      • Select Overview.
  4. Select Reactivate.
  5. Paste the Add-On registration key into the Add-On Key box.
  6. Optional: If you want to add an additional Add-On key, select the plus (+) symbol to get another Add-on Key box.
  7. Select Manual.
  8. Copy the dossier and connect to the F5 Product Licensing page at the following address:

    https://secure.f5.com

  9. On the F5 Product Licensing page, in the row that lists BIG-IQ, select Activate License.
  10. Paste the dossier into the Enter your dossier box and select Next.
  11. Copy the license returned by the F5 Product Licensing page and paste it into the License box in the BIG-IQ system.
  12. Select Activate.
