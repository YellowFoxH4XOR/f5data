K61305540: BIG-IP LTM 15.1.4 Could not allocate vCMP guest

Applies to

Source
https://my.f5.com/manage/s/article/K61305540

Description

Creating a virtual guest and get an error  because fragmented resources.

Environment

  • LTM
  • i11800
  • BIG-IP v15.1.4

Cause

This is a known issue do to below bug:

Bug ID 1020789 - PDEs are not assigned contiguously on i11800 vCMP host

Recommended Actions

Apply EFH that contains a fix for Bug ID 1020789, and check the HSB to ensure the interfaces were assigned correctly.
  1. Upgrade devices to 15.1.4 and apply EHF that includes the fix
  2. Boot in to upgraded partition
  3. Check for HSB
       #tmsh show sys hardware
       #tmsct interface_stats -s name
  4. Provision vCMP
  5. Check for HSB again
       #tmsh show sys hardware
       #tmsctl interface_stats -s name
  6. Deploy guests
