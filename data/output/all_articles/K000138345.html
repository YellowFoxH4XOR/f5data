Description

You may have experienced issues with the formatting of the BIG-IP APM logs, such as the timestamp missing when forwarding them to a remote HSL logging server. You may see something similar to this:

<3<.....U.F/Common/policy_example:Common:ba2aebb6: Session deleted (no_hostname) ................

`6:11:58.068616 IP 172.16.1.1.56884 > lecv3_1.custix: UDP, length 77

E..i0.@....@..K.

Environment

  • F5 BIG-IP APM.

  • High-Speed Logging (HSL).

Cause

A common cause cause of the missing timestamps in the BIG-IP APM logs is a misconfiguration in the syslog settings. Specifically, in many cases, the "Syslog Format" is set to 'Syslog' instead of 'BSD Syslog'.

Recommended Actions

To fix this issue, please follow the steps desribed above:

  1. Navigate to System ›› Logs: Configuration: Log Destinations and create a new log destination with the following settings:
    1. Name: the new log destination
    2. Type: select Remote Syslog
    3. Syslog Format: BSD Syslog (Default)
    4. Forward To: Existing remote HSL destination (e.g., /Common/example-syslog-dst)
  2. Create a new log publisher under System ›› Logs: Configuration: Log Publishers with the new syslog destination created in step 1 as the destination.
  3. Associate the new log publisher with the APM logging profile under Access ›› Overview: Event Logs: Settings.

These steps should ensure that the logs forwarded to the remote Syslog server are correctly formatted with timestamp information. To verify that BSD is now the format run this command...

tmsh list sys log-config destination remote-syslog <name of log destination> all-properties

Example:

root@(big-ip)(pid-15463)(cfg-sync Standalone)(Active)(/Common)(tmos)# list sys log-config destination remote-syslog whatthe_rfc3164 all-properties
sys log-config destination remote-syslog whatthe_rfc3164 {
    app-service none
    default-facility local0
    default-severity info
    description none
    format rfc3164
    remote-high-speed-log hsl_logging_dest
}

rfc3164 denotes BSD format. If the Syslog Format is changed to just 'Syslog' it reverts rfc5424.

Additional Information

For further guidance on configuring log messages and understanding the differences in message formats for remote HSL logging, please refer to K57555038: remote HSL logging message format
