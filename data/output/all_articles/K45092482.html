Description

The F5 iWorkflow system daemons perform a variety of functions, such as managing Cloud, Device and Security resources and role-based access control. These resources can be located on BIG-IP devices in a private local network, a public third-party cloud service, or a combination of both.

Managing iWorkflow processes

You can use the command line to manage the daemons on the iWorkflow system, either using the bigstart command or the Traffic Management Shell (tmsh).

Using tmsh to manage the iWorkflow processes

  • To stop, start, restart, or view the status of an iWorkflow daemon, use the following command syntax:

    tmsh <action> /sys service <daemon>

    In the previous syntax, note the following:

    • <action> refers to the action for the iWorkflow process, such as stop, start, restart, show, or list
    • <daemon> is the name of the iWorkflow process

    For example, to view the status of the webd daemon, type the following command:

    tmsh show /sys service webd

  • To restart all iWorkflow processes, type the following command:

    Important: Stopping or restarting all iWorkflow processes will disrupt all the services of the iWorkflow system.

    tmsh restart /sys service restjavad

Using the bigstart command to manage the iWorkflow processes

  • To restart all iWorkflow processes, type the following command:

    Important: Stopping or restarting all iWorkflow processes will disrupt all the services of the iWorkflow system.

    bigstart restart restjavad

  • To stop, start, restart, or view the status of a iWorkflow daemon, use the following command syntax:

    bigstart <action> <daemon>

    In the previous syntax, note the following:

    • <action> refers to the action for bigstart, such as stop, start, restart, or status
    • <daemon> is the name of the BIG-IQ process

    For example, to view the status of the webd daemon, type the following command:

    bigstart status webd
