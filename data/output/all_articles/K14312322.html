K14312322: Unable to view application requests under event logs.

Type
Support Solution
Published
2020-05-18
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.1.2
Source
https://my.f5.com/manage/s/article/K14312322
Description

ASM events logs stop appearing 

Following messages in  var/log/ts/asmlogd.log

asmlogd|INFO|Mar 27 18:18:30.032|19470|F5::RequestLog::__ANON__,,Pipe close received
asmlogd|INFO|Mar 27 18:18:30.043|19470|F5::IO::LrnPipe::close,,Closing pipe
asmlogd|INFO|Mar 27 18:18:30.045|19470|F5::IO::LrnPipe::init,,Pipe (type: PBRQL) could not be opened (error code = -1)
asmlogd|INFO|Mar 27 18:18:35.439|19470|F5::IO::LrnPipe::init,,Pipe (type: PBRQL) could not be opened (error code = -1)

Environment

  • ASM
  • events log 
Cause

None.

Recommended Actions

Connect to CLI:

Restart pabnagd
# pkill -f pabnagd

Wait for around 15 seconds

Restart asmlogd
# pkill -f asmlogd

Note: Traffic on the device is not impacted when restarting these services for ASM.

Additional Information

K14020: BIG-IP ASM daemons (11.x - 16.x)
