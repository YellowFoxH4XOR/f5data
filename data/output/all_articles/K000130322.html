K000130322: F5 High disk usage /opt/.sdbm/ excedeed 83%

Type
Support Solution
Published
2026-06-08
Updated
2026-10-13
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000130322

Description

Third-party monitoring tool is reporting high disk usage of the following directories:

 

  • /opt/.sdm/usr
  • /opt/.sdm/lib
  • /opt/.sdm/lib64

Environment

  • SolarWinds
  • /usr partition

Cause

This is expected as /usr partition is high in disk usage since its creation. The /usr partition is created upon installation for system files and it is mounted as read-only. The amount of free space should not change during normal operation.

 

 Recommended Actions

 Ignore the alerts or increase the alert threshold to be >90% utilized.

Not applicable.
