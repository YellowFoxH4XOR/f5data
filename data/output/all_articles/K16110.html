Known Issue

The BIG-IP Edge Command Line Client for Linux may fail to establish a session.

This issue occurs when the following condition is met:

  • The BIG-IP APM access policy contains an iRule event agent prior to the assignment of resources.

Impact

The access session fails to establish.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After launching, the BIG-IP Edge Command Line Client for Linux may fail to establish a session and the session state never changes to session established.
