Description
Unable to show iControl REST output when querying BGP stats via curl command

Example:
[root@BIG-IP1:Active:In Sync] config # curl -sk -u admin:password https://localhost/mgmt/tm/net/routing/bgp/stats | jq .
{
  "kind": "tm:net:routing:bgp:bgpcollectionstats",
  "selfLink": "https://localhost/mgmt/tm/net/routing/bgp/stats?ver=14.1.4"
}

[root@(BIG-IP)(cfg-sync Standalone)(Active)(/Common)(tmos)# show net routing bgp neighbor
[api-status-warning] net/routing/bgp is early_access

Environment

  • BGP configuration
  • ZebOS
  • IMISH
  • Command line access
  • TMOS
  • iControl REST
  • v14.x and v15.x and later

Cause
You cannot use legacy ( a.k.a imsh/vtysh ) and still get stats via the rest API.

Recommended Actions
ZebOS IMI will still exist in read-only mode, but IMI and tmsh/iControl® REST are mutually exclusive, you can choose one of the method below:

  • Migrate your ZebOS configuration

    OR
     
  • Configure BGP via tmsh in order to get the stats.

    Please refer to this below article for more information:
    Manual Chapter : Configuring BGP with tmsh

Additional Information

  • Currently BGP and BFD are the only supported protocols available for configuration in tmsh
