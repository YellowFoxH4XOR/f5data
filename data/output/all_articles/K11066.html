Topic

PDF linearization prepares the PDF file for byte serving, which enables the BIG-IP system to provide individual pages to a client when it receives byte-range requests. For a list of PDF linearization libraries by version, refer to the following table:

VersionsPDF linearization library
BIG-IP AAM 14.1.0 and laterqpdf, version 5.0.1
BIG-IP AAM 11.4.0 through 14.0.0qpdf, version 2.2.2
BIG-IP WebAccelerator 11.0.0 through 11.3.0qpdf, version 2.2.2
BIG-IP WebAccelerator 10.1.0 through 10.2.4ESP Ghostscript 8.15.2 (2006-04-19)
BIG-IP WebAccelerator 9.4.7 through 9.4.8, 10.0.0 through 10.0.1GPL Ghostscript 8.63 (2008-08-01)
BIG-IP WebAccelerator 9.4.0 through 9.4.6PDF Tools, version 2.34

Note: BIG-IP 10.1.0 uses an older version of Ghostscript than BIG-IP 10.0.1.
