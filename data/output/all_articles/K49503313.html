Description

You are getting the following error message when viewing Zone List:
RCODE returned from query: 'REFUSED'

To view the Zone List, navigate DNS > Zones > ZoneRunner > Zone List.

You also have subnet 127.0.0.0/8 configured in the View List. Refer to the example below:

view "internal" {
    match-clients {
        127.0.0.0/8;                  Note the 127.0.0.0/8 subnet
        "zrd-acl-000-001";
    };

To view the Zone List, navigate DNS > Zones > ZoneRunner > View List.

Environment
  • BIG-IP DNS/GTM
  • Error: RCODE returned from query: 'REFUSED'
  • Subnet 127.0.0.0/8 configured in View List

Cause

Zonerunner adds the special acl zrd-acl-###-### to each created view, and associates that acl with the source IP 127.10.###.###.

Since you have added subnet 127.0.0.0/8 it will conflict with zrd-acl-###-###.

Recommended Actions

You will need to delete or comment out subnet 127.0.0.0/8.

  1. Login to the Configuration Terminal
  2. Navigate to DNS > Zones > ZoneRunner > View List
  3. Click the View Name which has subnet 127.0.0.0/8
  4. Delete the line which consist 127.0.0.0/8
    For example, based on the View List in Description above, after removing subnet 127.0.0.0/8 the View Configuration will look like this:
    view "internal" {
        match-clients {
            "zrd-acl-000-001";      Note: 127.0.0.0/8 has been removed
        };
  5. Click Update
