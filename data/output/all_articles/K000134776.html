K000134776: Cannot Change Partition when in ASM Security tab

Type
Support Solution
Published
2023-06-02
Updated
2024-03-26
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000134776

Description

 

  • When using certain versions of Chrome or Microsoft Edge to access the BIG-IP GUI, a user cannot change the partitions from the "Security  ››  Protocol Security" tab.
  • The Partition Selector is greyed out and the dropdown option is disabled on this page.

Environment

  • BIG-IP ASM Version 17.1.x

Cause

  • This is a known issue being tracked as ID 1301081

 

Recommended Actions

  • Workaround for this issue either use Firefox, or incognito mode in chrome/Edge, to navigate the BIP-IP GUI

      OR

  • Change the partition before accessing the Security Protocols menu. 

 

Additional Information

  • Bug ID 1301081
