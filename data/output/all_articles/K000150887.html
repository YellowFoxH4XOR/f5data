Description

Custom http monitor with HTTP POST request in send string is not working as expected. Pool member responses with 400 Bad request.

Environment

  • BIG-IP LTM
  • http monitor with send string

Cause

Content length in send string has incorrect value. In the example below it should be set to 10, as this value matches the length of message body "0123456789"

Example: 

POST /MyApp.cgi HTTP/1.1\r\nHost: host.domain.com\r\nContent-Length:20\r\nConnection: Close\r\n\r\n0123456789

Recommended Actions

Modify the send string and update the Content Length value according to the length of the sent payload.

Exmple:

POST /MyApp.cgi HTTP/1.1\r\nHost: host.domain.com\r\nContent-Length:10\r\nConnection: Close\r\n\r\n0123456789
