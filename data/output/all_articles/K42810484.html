Description

Usually after an upgrade or restart, only one device in a HA pair shows changes pending in GUI.

  • Recently device was restarted or upgraded.
  • Only one device shows "Changes Pending" from GUI but when clicked, it shows config is in sync.
  • The other device in HA pair, shows "In Sync"

Environment

  • BIG-IP
  • Units have High availability configured
  • BIG-IP ASM is not provisioned, only LTM/GTM is provisioned.
  • A force sync has been performed from both sides but the issue is still not resolved.

Cause

This can happen if there is a drift between system clock and hardware clock in either of the devices.

Recommended Actions

Impact: There should be no impact to traffic when the commands in the above steps are run.

Follow the steps below to sync the system clock with hardware clock

  1. Check both devices can reach NTP server using ntpq -pn.
  2. Verifying there are non-zero values for jitter and other fields.
  3. Run the command on both devices: 
    hwclock --systohc
  4. After running the command above, proceed with a force sync from the device which shows changes pending. (Article - K13887 can help on this step)
  5. After the force sync is complete, both devices should show they are in sync.
