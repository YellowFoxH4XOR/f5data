K13892: The NSM serial number no longer displays eight digits, it now displays six

Type
Knowledge
Published
2012-10-01
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • ARX: 5.2.0, 6.2.0, 6.1.1, 5.2.2, 6.0.0, 5.3.1, 6.1.0
Source
https://my.f5.com/manage/s/article/K13892

Issue

Old Behavior

In ARX versions prior to 5.2.0, when you run the show chassis command, the Module sections serial numbers are displayed as eight digits.

For example:

ARX1#Show chassis

 Module:
 Slot Ports Procs Card           Xeon                    Sibyte                  Serial
 ----  -----  -----  --------       -----------------             -----------------             ------------
  1    13    5    ACM       2.2 GHz  12032 MB  1.2 GHz  4096 MB   02006541

New Behavior

Beginning in ARX version 5.2.0, when you run the show chassis command, the Module sections serial numbers are displayed as six digits; the leading two digits have been truncated and are no longer viewable.

For example:

ARX1#Show chassis

 Module: 
 Slot Ports Procs Card             Xeon                   Sibyte                Serial
 ----   -----  -----  --------        -----------------            -----------------           ------------
  1    13    5    ACM       2.2 GHz  12032 MB  1.2 GHz  4096 MB   006541

F5 Product Development tracked this change as ID 387525.

Impact

The change does not affect the stability or usability of the ARX system.

Recommended Actions

None
