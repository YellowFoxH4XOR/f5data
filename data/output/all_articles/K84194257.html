Description

TMOS is monitored and maintained by operation teams who usually collect status information about the unit via SNMP. When setting up F5 products to monitor for its health status via SNMP, you may often have to go through hoops to search for a specific SNMP OID number to monitor. This article walks through an example procedure where you can easily search for their desired OIDs on a TMOS system.

Environment

  • BIG-IP
  • SNMP

Cause

None

Recommended Actions

You must have TMOS bash command-line access.

Ensure that SNMP is allowed to be accessed from 127.0.0.0/8

# tmsh list sys snmp allowed-addresses
sys snmp {
    allowed-addresses { 127.0.0.0/8 }
}

Run snmpwalk to go through the standard snmp modules:

# snmpwalk -c public localhost > /var/tmp/snmpnames.txt

This will create a file in /var/tmp with contents that show all available SNMP counters from the public tree that looks like this:

SNMPv2-MIB::sysObjectID.0 = OID: F5-BIGIP-SYSTEM-MIB::bigipVirtualEdition
DISMAN-EVENT-MIB::sysUpTimeInstance = Timeticks: (123809999) 14 days, 7:54:59.99
SNMPv2-MIB::sysContact.0 = STRING: Customer Name <admin@customer.com>
...

Run snmpwalk enterprise to walk through F5 specific modules:

# snmpbulkwalk -c public localhost enterprise > /var/tmp/snmpnames_enterprise.txt

This will create a file in /var/tmp with contents that show all available SNMP counters from the enterprise tree:

...
F5-BIGIP-SYSTEM-MIB::sysGlobalTmmStatMemoryTotal.0 = Counter64: 2688548864
F5-BIGIP-SYSTEM-MIB::sysGlobalTmmStatMemoryUsed.0 = Counter64: 271434824
F5-BIGIP-SYSTEM-MIB::sysGlobalTmmStatDroppedPackets.0 = Counter64: 0
...

You may then search the available OIDs for the information you are interested in. For example, here we search for information on the existing "my_gateway_pool" ServerPkts.

# grep -i my_gateway_pool /var/tmp/snmpnames_enterprise.txt | grep -i ServerPkts
F5-BIGIP-LOCAL-MIB::ltmPoolStatServerPktsIn."/Common/my_gateway_pool" = Counter64: 9
F5-BIGIP-LOCAL-MIB::ltmPoolStatServerPktsOut."/Common/my_gateway_pool" = Counter64: 8
F5-BIGIP-LOCAL-MIB::ltmPoolMemberStatServerPktsIn."/Common/my_gateway_pool"."/Common/10.11.65.1".0 = Counter64: 9
F5-BIGIP-LOCAL-MIB::ltmPoolMemberStatServerPktsOut."/Common/my_gateway_pool"."/Common/10.11.65.1".0 = Counter64: 8

Once you find the information you are looking for, you may want to look up its numeric OID to enter into your SNMP management software. For example, let's try to find the numeric OID for F5-BIGIP-LOCAL-MIB::ltmPoolStatServerPktsIn."/Common/my_gateway_pool":

# snmpget -On -c public 127.0.0.1 'F5-BIGIP-LOCAL-MIB::ltmPoolStatServerPktsIn."/Common/my_gateway_pool"'
.1.3.6.1.4.1.3375.2.2.5.2.3.1.2.23.47.67.111.109.109.111.110.47.109.121.95.103.97.116.101.119.97.121.95.112.111.111.108 = Counter64: 12

Note: The -On option instructs snmpwalk to print the numeric OID. Ensure that the SNMP name is enclosed in single quotes '...' so the bash shell does not reinterpret the OID.
