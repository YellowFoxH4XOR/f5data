Description

SNMP MIB files on F5 VELOS (F5OS) platforms are bundled with the running F5OS software. The build date of these files reflects the software version in use. This article explains how to determine the version or age of SNMP MIB files to ensure compatibility with monitoring systems and resolve issues related to outdated or conflicting MIBs.

Environment

  • F5 VELOS (F5OS)
  • MIB files

Cause

How to Check the MIB Version on F5 VELOS (F5OS) Systems

Answer/Recommended Actions

Note: MIB files do not contain an explicit version string. The build date and the F5OS software version are the authoritative indicators.

To check the MIB version on F5 VELOS (F5OS):

A. WebUI Method (Recommended)

  1. Log in to the System Controller webUI.
  2. Navigate to System Settings > File Utilities.
  3. From the Base Directory drop-down, select mibs.
  4. Check the MIB files:
    • mibs_f5os_controller.tar.gz
    • mibs_netsnmp.tar.gz
  1. The file listing will show the date and size, which indicates the MIB's build date and its alignment with the installed F5OS software.
  2. Repeat the process by logging into a Chassis Partition webUI to download mibs_f5os_partition.tar.gz.
  3. Review the output for file names, dates, and sizes. The date field shows when the MIB was built, matching the F5OS software version installed.

Note: To check your F5OS software version installed, got to the F5 Download page and find your F5OS version, it will show you the F5OS's build date which should be similar to the MIB file date.

 B. CLI Method

  1. SSH to the System Controller or Chassis Partition.
  2. Run: file list path mibs/
  3. Review the output for file names, dates, and sizes. The date field shows when the MIB was built, matching the F5OS software version installed.
syscon-1-active# file list path mibs/
entries {
name mibs_f5os_controller.tar.gz
date Thu Jan 25 07:29:49 UTC 2024
size 7.2KB
}
entries {
name mibs_netsnmp.tar.gz
date Thu Jan 25 07:29:49 UTC 2024
size 110KB
}
syscon-1-active#

Additional Information

  • To ensure you have the latest MIBs, upgrade your F5OS software to the latest supported version and re-download the MIBs.
