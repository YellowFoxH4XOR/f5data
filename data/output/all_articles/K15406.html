Security Advisory Description

The built-in web servers for multiple networking devices do not set the Secure attribute for sensitive cookies in HTTPS sessions, which could cause the user agent to send those cookies in plaintext over an HTTP session with the same server. (CVE-2004-0462)

Impact

A remote attacker may be able to intercept a secure cookie sent over an HTTP session. This impact is low for BIG-IP and ARX systems, as their Configuration utility is not accessible over HTTP.

Security Advisory Status

F5 Product Development has assigned ID 243295 (BIG-IP and Enterprise Manager) and ID 4655041 (ARX) to this vulnerability, and has evaluated the currently supported releases for potential vulnerability. Additionally, BIG-IP iHealth may list Heuristic H470755 on the Diagnostics > Identified > Low screen.
