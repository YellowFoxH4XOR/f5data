Issue

Error Message

01070330:3: Static route gateway <IP_address> is not directly connected via an interface.

In this error message, note the following:

  • <IP_address> is the IP address of the route gateway.

For example:

01070330:3: Static route gateway 192.168.10.1 is not directly connected via an interface.

Message Location

You may encounter this message in the following locations:

  • The Configuration utility (when adding a static route)
  • The console (when adding a static route)
  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • You attempt to define a static route that points to a gateway, and the system does not have a self IP address in the same subnet as the gateway.

Impact

The static route is not created.

Recommended Actions

When defining a static route, the system must have a self IP address in the same subnet as the gateway IP address, so that the system is reachable using Layer 2 (L2)/Address Resolution Protocol (ARP) for the address.
