K64744125: Manually Uninstalling BIG IP EDGE CLIENT on macOS

Type
Support Solution
Published
2022-05-02
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K64744125

Description

With MacOS there is very limited customisation available for the installer that is downloaded from the APM.
This installer configures optional start-up items (Launch Agents and Launch Daemons in Apple terminology) and also a script for deleting those items on removal of the Edge Client. That uninstall script will fail on MacOS 12.3 and newer with the error 
env: python: No such file or directory

With the release of apmclients 7.2.2.2 and 7.2.3 the installer PKG for Edge Client now creates a bash script uninstaller, and provides a compiled binary fwctl

Environment

MacOS Edge Client Instalation 

  • APM Network Access VPN
  • Customised Always Connected or startup settings
  • Upgraded to MacOS 12.3 (Monterey) or greater

Cause

With the release of MacOS version 12.3, Apple no longer provides a python runtime environment, so the the previous provided script is not effective.
To remove Edge Client instead of running the script as directed by the manual, a set of bash commands below are recommended.

Recommended Actions

The following actions should be perform to manually remove Edge Client from a MacOS device.

  1. To confirm the possible device users that could have Edge Client (not the System Accounts). Open a terminal window and run the following command:
    dscl . list /Users | grep -v '^_\|daemon\|root\|nobody'

    This uses the "Directory Service command line utility" to list the non- system accounts on the Device, for most MacOS installations there will only be a single normal user account, and there will be a single Edge Client installed in /Applications
    The following commands should be run as that user, and where admin access is required, prefixing the command with "sudo" will result in that users password being required.
     
  2. Uninstall the Edge Client and daemons owned by the system
    sudo rm -rf /Applications/BIG-IP\ Edge\ Client.app/
    Uninstall any user installed Edge Client (if present)
    sudo rm -rf /Users/<user>/Applications/BIG-IP\ Edge\ Client.app/
     
  3. Stop and then Uninstall the Edge Client related daemons and startup items
    launchctl unload ~/Library/LaunchAgents/com.f5.edgeclientagent.plist
    sudo launchctl unload /Library/LaunchDaemons/com.f5.fwctl.plist
    sudo rm /Library/LaunchDaemons/com.f5.edgeclientagent.uninstallhelper.plist
    sudo rm /Library/LaunchDaemons/com.f5.fwctl.plist
    rm ~/Library/LaunchAgents/com.f5.edgeclientagent.plist
     
  4. If you want to optionally purge any of the configuration files to have a clean re-installation
    sudo rm /Library/Application\ Support/F5Networks/config.f5c
    sudo rm /Library/Application\ Support/F5Networks/f5fwctl.xml
     
  5. To optionally purge all the Edge Client logs from the device
    rm ~/Library/Logs/F5Networks/* 
    sudo rm /Library/Logs/F5Networks/*
     
  6. Then reboot the device and re-install if Edge Client (with its associated configuration) if needed
     

Additional Information

Installing a newer version of Edge Client should overwrite the older version and maintain the existing settings. It is not necessary to manually delete the older version.

Note that the man pages of recent MacOS versions contain the warning 

Note that per-user configuration files (LaunchAgents) must be owned by root (if they are located in /Library/LaunchAgents) or the user loading them (if they are located in $HOME/Library/LaunchAgents).  All system-wide daemons (LaunchDaemons) must be owned by root. Configuration files must disallow group and world writes. These restrictions are in place for security reasons, as allowing writability to a launchd configuration file allows one to specify which executable will be launched.

Note that allowing non-root write access to the /System/Library/LaunchDaemons directory WILL render your system unbootable.
