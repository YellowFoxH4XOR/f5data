Known Issue

You may be unable to access Citrix and VMware View resources by way of the BIG-IP APM system.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP APM system to provide access to Citrix or VMware View applications or desktops.
  • You have configured a layered virtual server with the Citrix or VMware View resource pool residing in a non-zero route domain.

Layered virtual servers allow the BIG-IP APM system to provide access to pools of servers with remote resources. Starting in BIG-IP APM 11.4.0, you can configure the pools directly in the remote resource configuration, rather than using a layered virtual server. However, the f5.citrix_presentation_server and f5.citrix_xen_app iApp templates still configure a layered virtual server, by default. If the layered virtual server is configured in a non-zero route domain, the BIG-IP APM system is unable to route traffic to the remote resources.

Impact

Users are unable to access Citrix and VMware View resources by way of the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H451459 on the Diagnostics > Identified > Medium screen.
  • Citrix and VMware View resources are not published to the BIG-IP APM Webtop.
  • Connections to Citrix and VMware View remote applications fail.

Workaround

To work around this issue, you can configure the Destination in the remote desktop settings to reference the remote pool directly. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Navigate to Access Policy > Application Access > Remote Desktops.
  3. Click the name of the affected remote desktop profile.
  4. In the Destination section, click the Pool button, and from the drop-down menu, select the pool used in the layered virtual server.
  5. Click Update.
  6. Apply the changes by clicking the Apply Access Policy link and clicking Apply Access Policy on the screen that follows.
