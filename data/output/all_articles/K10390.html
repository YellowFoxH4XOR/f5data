Topic

You can limit the length of messages the BIG-IP ASM system sends to remote logging servers using the Maximum Entry Length setting.

Description

The BIG-IP ASM system internally limits the messages it generates and sends to the syslog utility to 2 kilobytes. Of the 2 kilobyte maximum message size, 128 bytes are reserved to record the request that generated the message.

Note: This limit applies only to local logging facilities.

For remote servers that support TCP, you can configure this limit by using the Maximum Entry Length setting.

The following values are allowed:

  • 2 kilobytes
  • 10 kilobytes
  • 64 kilobytes

Note: The maximum entry length for remote servers that support User Datagram Protocol (UDP) is 1 kilobyte, by default, in versions prior to 12.1.0 and that has been addressed via ID387204. Therefore, in 12.1.0 and later releases, you can select all the options (1k, 2k, 10k 64k) even using UDP protocol.

Procedures

Configure the Maximum Entry Length setting

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Go to Security > Event Logs > Logging Profiles.
  3. Select the name of the profile.
  4. In the Application Security section, next to Configuration, select Advanced.
  5. Ensure Remote Storage is selected for the Storage Destination setting.

    Note: For BIG-IP ASM 11.x, ensure the Remote Storage setting is Enabled.

  6. Select the desired value for the Maximum Entry Length setting.
  7. Select Update.
