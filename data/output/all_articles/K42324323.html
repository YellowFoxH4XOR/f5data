Description
Warning messages like below may be generated when customer upgrades the software version from 12.1.2 or earlier version to 12.1.3 or later version.

warning mcpd[<PID>]: 0107185a:4: Warning generated, for version 13.0.0 or greater: setting 'tag-mode' to 'none' for vlan member <vlan-name> for vlan /Common/<vlan-name>

Environment

  • BIG-IP
  • VLAN
  • Q-in-Q

Cause

In earlier version there is no validation for Q-in-Q tagging configure, the system allows you to configure QinQ tag-mode and an invalid value on non-supported platforms, but the configuration has no effect, and there are no negative impacts to the system functionality. After you upgrade to newer version which has this issue fixed, the system detect this change and issue the alert, it is just cosmetic.

Recommended Actions

The warning can be ignored.

Additional Information
Only on the following platforms can configure  the QinQ tag-mode:
BIG-IP 5050s and 5250v
BIG-IP 7050s and 7250v
BIG-IP 10050s and 10250v
BIG-IP VIPRION Blade B2150 SSD based model
