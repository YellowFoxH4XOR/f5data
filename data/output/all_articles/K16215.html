Known Issue

Network access lease pool address assignment may fail.

This issue occurs when all of the following conditions are met:

  • The network access profile is configured with a full webtop that references a single destination resource.
  • Network access sessions exceed the configured timeout value.

When access sessions time out, a race condition may cause the system to fail to release the assigned lease pool IP address, making the address unavailable for reassignment.

Impact

The system is unable to assign addresses from the lease pool.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H509521 on the Diagnostics > Identified > High screen.
  • To establish an access session, you are prompted to enter your credentials multiple times.
  • When you connect to the access profile by using BIG-IP Edge Client, the Edge Client displays the following looping connection states:

    Authenticating...

    Disconnecting from server...

  • When you connect to the access profile by using BIG-IP Edge Client, the Edge Client displays an error message similar to the following example:

    Internal Error!

  • In the /var/log/apm file, you observe error messages similar to the following example:

    notice tmm[11937]: 01490505:5: cf6d91f7: IPv4 Addr collision: Old: dc6ee6892ac40025a1b33bfd95e4b310 New: tmm.uuid./<partition>/<network access profile name>

  • In the /var/log/ltm file, you observe error messages similar to the following example:

    notice address <lease pool ip address> in leasepool /<partition>/<network access profile name> is not assigned - can't touch
    notice address <lease pool ip address> in leasepool /<partition>/<network access profile name> is unassigned - can't release

  • In the /var/log/tmm file, you observe error messages similar to the following example:

    notice tmm1[8153]: 01490549:5: f44b4058: Assigned PPP IPv4: <source ip address of user> Tunnel Type: VPN_TUNNELTYPE_TLS NA Resource: /<partition>/<network access profile name> - Reconnect
    notice tmm1[8153]: 01490505:5: f44b4058: PPP tunnel 0x570043e61700 started.
    notice tmm1[8153]: 01490505:5: f44b4058: PPP tunnel 0x570065cc8200 closed.
    notice tmm[30320]: 01490505:5: d771ed6c: VPN Cleanup: failed to release IPv4 ERR_ARG
