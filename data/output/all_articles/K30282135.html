K30282135: Unable to delete old failed Server Technologies updates

Type
Support Solution
Published
2022-09-09
Updated
2023-02-21
Applies to
  • VIPRION Platforms
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP ASM: 15.1.5
Source
https://my.f5.com/manage/s/article/K30282135

Description

Some Server Technologies updates which failed to install previously are still present and unable to delete it. It shows error:
"Installation Error" 

You observe messages similar to the following in /var/log/asm:

01310027:2: ASM subsystem error (apply_asm_attack_signatures,F5::LiveUpdate::PayloadHandler::clean_fail): Fail load update files: Fail to update Server Technologies at /usr/local/share/perl5/F5/LiveUpdate/PayloadHandler/ServerTechnologies.pm line 69.

Environment

  • Tried installing new Server Technologies update
  • Old update files are still present with installation error
     

Cause

Undetermined 
 

Recommended Actions

You can run below commands to clean the files:
Impact of procedure: Performing the following procedure should not have a negative impact on your system.

tmsh stop sys service tomcat

rm -f /var/lib/hsqldb/live-update/liveupdatedb.*

tmsh start sys service tomcat

After this, the genesis file should show Currently installed, and old files will be removed.
