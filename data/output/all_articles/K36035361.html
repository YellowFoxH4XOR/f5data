K36035361: BIG-IQ is not able to generate UCS backup for managed BIG-IP

Type
Support Solution
Published
2021-05-10
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K36035361

Description
Several BIG-IPs are having issues not able to generate UCS backup from the BIG-IQ.

Viewing /var/log/restjavad.*.log on the BIG-IQ, you will see the following error message.
[ERROR][ RestFileReceiver] java.net.ProtocolException: status:404, body:{"code":404,"message":"Public URI path not registered: /shared/file-transfer/ucs-downloads/BIG-IP _ucsbackup.ucs","referer":"com.f5.rest.common.RestFileReceiver","restOperationId":88888888,"kind":":resterrorresponse"}

Environment

  • BIG-IQ is generating BIG-IP UCS
  • UCS back is not successful
  • This issue might happen on a few BIG-IP devices only
  • BIG-IP was recently upgraded

Cause

Unknown at the time of publication.

Recommended Actions

Rebooting the impacted BIG-IP will resolve the issue.

Additional Information

None.
