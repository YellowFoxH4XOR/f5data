K01244819: Configure BIG-IQ system to exclude inode information from Etags

Published
2021-08-05
Updated
2023-02-21
Applies to

  • BIG-IQ Centralized Management: 8.0.0, 8.1.X, 8.1.0, 8.0.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.X.X
Source
https://my.f5.com/manage/s/article/K01244819

Description

You want to configure your BIG-IQ 8.0.0 system to exclude inode information from Etags when connecting to the Configuration utility.

Environment

  • BIG-IQ 8.0.0 and later
  • Apache 2.4.6

Cause

None.

Recommended Actions

BIG-IQ is currently running Apache server version 2.4.6, which defaults the FileETag Directive to FileETag MTime Size.
Hence you do not need to apply procedures in K14206 for BIG-IQ 8.0.0 and later.

Additional Information

None.
