Issue

Error Message

0107098a:3: The ip address (ip addr%rd) for a virtual server in partition (partition name) references a route domain (rd number) in a different partition (partition name). Objects may only reference objects in the same or the 'Common' partition

In this error message, note the following:

  • <ip addr%rd> is the IP address of a WAN Self IP Address and route domain.
  • <rd number> is the number of a specific route domain.
  • <partition name> is the name of a specific partition.

For example:

0107098a:3: The ip address (10.10.1.10%100) for a virtual server in partition (Common) references a route domain (100) in a different partition (partition_rd100). Objects may only reference objects in the same or the 'Common' partition

Message Location

You may encounter this message in the following location:

  • The Acceleration > Quick Start > Symmetric Properties page in the Configuration utility

Description

This message occurs when all of the following conditions are met:

  • You have configured an additional route domain.
  • You have attempted to configure a new endpoint using a non-default route domain.

Impact

You are unable to configure BIG-IP WOM / BIG-IP AAM objects using route domains other than the default.

Recommended Actions

There are no recommended actions. F5 does not support configuring BIG-IP WOM / BIG-IP AAM objects on non-route domains.
