Known Issue

Description

When you are logged in to the BIG-IP command line as a user with the resource-admin role, the tmsh shell does not return a confirmation prompt when you run the tmsh load sys config default command to reset the configuration to factory default settings.

This issue occurs when the following conditions are met:

  • A user with the resource-admin role is logged in to the BIG-IP command line.
  • The user runs the tmsh load sys config default command.

The tmsh load sys config default command restores the BIG-IP configuration to factory default settings. The tmsh shell should return a confirmation prompt that appears similar to the following example when you run the tmsh load sys config default command:

(tmos)# load sys config default
Reset the system configuration to factory defaults? (y/n)

Note: For more information about restoring the BIG-IP system to factory default settings, refer to K13127: Restoring the BIG-IP configuration to factory default settings (11.x).

Impact

The system restores the BIG-IP configuration to factory default settings without returning a confirmation prompt.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • If you are logged in as a resource-admin user, and you run the tmsh load /sys config default command, the system restores the configuration without warning and generates a message that appears similar to the following example:

    (tmos)# load sys config default
    The connection to mcpd has been lost, try again.

Workaround

If you have inadvertently loaded the factory default settings on the BIG-IP system, you can work around this issue and restore the previous configuration by loading the backup.scf file. To do so, perform the following procedure:

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Load the backup.scf file by typing the following command:

    load /sys config file /var/local/scf/backup.scf

  3. Save the change by typing the following command:

    save config
