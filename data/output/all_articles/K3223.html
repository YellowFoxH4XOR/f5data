K3223: Reasons why connection statistics for a pool and the nodes that comprise the pool may be different

Topic

The differences in the sums are caused when OneConnect aggregates connections.

The pool only has new connections counted against it when a connection cannot be aggregated into an existing connection. If you add the counter's packets or bits, the sums match.

For example, if you leave the web aggregate global variable at the default setting of IP, the BIG-IP system will aggregate all the connections from the same IP address into existing connections on the back end servers. Therefore, a client could make a connection that sends 5 GET requests from different source ports, but the BIG-IP system will aggregate them into 1 connection on the back end server. In this event, the pool connection count would display 1, while the node count would display 5.

For more information about OneConnect, refer to K1548: Overview of the OneConnect? (web aggregation) feature.
