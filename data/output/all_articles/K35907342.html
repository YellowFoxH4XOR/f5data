Known Issue

After upgrading to BIG-IP ASM 14.1.2.8 or 15.1.1, you can no longer upgrade Secure Guided Configuration.

This issue occurs when all of the following conditions are met:

  • You are running BIG-IP ASM 14.1.2.8 or 15.1.1.
  • You attempt to upgrade Secure Guided Configuration by navigating to Security > Guided Configuration in the Configuration utility and selecting Upgrade Guided Configuration.

Impact

You are not able to upgrade Secure Guided Configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After an upgrade attempt, the Configuration utility displays a message similar to the following example, for each RPM Package Manager (RPM) package:

    Failed to load IApp artifacts from f5-iappslx-waf-bot-protection: java.lang.IllegalStateException: Failed to post template to block collection

Workaround

F5 recommends that you do not upgrade to BIG-IP ASM 14.1.2.8 or 15.1.1 when you are using Guided Configuration. To work around this issue, if you already installed BIG-IP ASM 14.1.2.8 or 15.1.1, you can delete the old version of Guided Configuration from the system and manually install the latest version. 

Alternatively, you can reboot the BIG-IP system to the previous boot location.

Manually install the latest version of Guided Configuration

To delete the old version of Guided Configuration from your system and manually install the latest version, perform the following procedure.

Note: You need to open two separate browser windows or tabs to perform this procedure.

Impact of workaround: This procedure requires you to delete any pre-existing iAppLX templates.

  1. Download the latest Guided Configuration package from F5 Downloads (https://downloads.f5.com). For specific instructions, refer to K167: Downloading software and firmware from F5.
  2. Log in to the Configuration utility.
  3. Go to Security > Guided Configuration.
  4. Open a second browser window or tab, and do the following:
    • Go to iApps > Templates > Templates LX.
    • Select all templates, and then select Delete.
    • Go to iApps > Package Management LX.
    • Select all existing RPM packages, and then select Uninstall.
  5. In the first browser window or tab, select Upgrade Guided Configuration.
