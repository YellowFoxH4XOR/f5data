Topic

This article explains the pay-as-you-grow (PAYG) offerings for the F5 r5000 and r10000 series platforms. For information about other F5 rSeries platforms, refer to the following articles:

  • K000148971: PAYG license support for F5 r12000 series platform
  • K44442211: PAYG license support for F5 r2000 and r4000 series platforms

Description

The F5 r5000 and r10000 series platforms offer upgradable three-tier PAYG licensing.

  • For the r5000 series platforms, licenses include r5600, r5800, and r5900.
  • For the r10000 series platforms, licenses include r10600, r10800, and r10900.

The assigned PAYG license defines the data-plane performance of the rSeries platforms. This is achieved by limiting the number of available vCPU, number of tenants, and number of SSL transactions per second (TPS).

The r5000 and r10000 series platforms each have a three-tier PAYG offering starting with the r5600 and r10600 respectively. Through license upgrades, you can unlock more performance on the same hardware platform. For example, to increase performance on an r5000 series platform, you can upgrade the r5600 license to an r5900 license. The published data sheet numbers are based on these newer PAYG strategies.
