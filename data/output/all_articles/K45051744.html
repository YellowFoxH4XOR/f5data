Description

When running "tmsh show gtm iquery" command Server Type value can be "BIGIP-DNS" or "BIGIP".

This article aims to explain the difference.

Environment

  • GTM devices in iQuery mesh.

Cause

When building iQuery mesh for the first time and running "bigip_add" command from 192.168.1.1 to 192.168.1.2 the second device will be added initially with BIGIP server type. 

# tmsh show gtm iquery
-----------------------------------------------------------
Gtm::IQuery: 192.168.1.1

-----------------------------------------------------------
Server                                                 b100
Server Type                                       BIGIP-DNS
Data Center                                             DC1
--------------------------------------------------
Gtm::IQuery: 192.168.1.2

--------------------------------------------------
Server                                        b101
Server Type                                  BIGIP
Data Center                                    DC1


Subsequently setting up GTM sync group parameters and adding 192.168.1.2 to the existing GTM Sync Group using "gtm_add" command will change the Server type to BIGIP-DNS:

# tmsh show gtm iquery

-----------------------------------------------------------
Gtm::IQuery: 192.168.1.1

-----------------------------------------------------------
Server                                                 b100
Server Type                                       BIGIP-DNS
Data Center                                             DC1

 

-----------------------------------------------------------
Gtm::IQuery: 192.168.1.2

-----------------------------------------------------------
Server                                                 b101
Server Type                                       BIGIP-DNS
Data Center                                             DC1


"BIGIP-DNS" server type is for a device added both to iQuery mesh and GTM Sync Group.

Recommended Actions

None.

Additional Information

None.
