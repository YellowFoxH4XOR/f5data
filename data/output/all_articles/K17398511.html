Issue

Error Message

0107167d:3: Data publisher not found or not implemented when processing request <message_name>.

In this error message, note the following:

  • <message_name> is the name of the request message to be processed.

For example:

0107167d:3: Data publisher not found or not implemented when processing request route_static_entry.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The statsd process is not running.
  • The mcpd process receives a malformed or improper request message.
  • There is no statistics publisher available to process a request for data. For example, when a blade_voltage_stat query is made to the Master Control Program Daemon (MCPD) on a BIG-IP platform with no blades, no publisher exists for the query and the BIG-IP system generates the error message.

Impact

BIG-IP system statistics used to create performance graphs are unavailable.

Recommended Actions

If the message is generated due to a stopped process, you can workaround the issue by restarting the process. To do so, perform the following procedure:

  1. Verify the needed processes are running by typing the following command:

    bigstart status

    Locate the statsd, merged, and tmm processes in the command output to confirm they appear in a run state:

    statsd       run (pid 5922) 17 days
    merged       run (pid 6719) 17 days
    tmm          run (pid 11380) 17 days

  2. If any of these processes are not in a running state, start them using the following tmsh syntax:

    tmsh start /sys service <service_name> <service_name>

    For example, to start statsd and merged, type the following tmsh command:

    tmsh start /sys service statsd merged
  3. Confirm the processes are running by typing the bigstart status command again.
