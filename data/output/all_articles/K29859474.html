Issue

Error Message

debug zxfrd[<PID>]: 01531025:7: Serials equal (<#>); transfer to zone <name> complete.

In this error message, note the following:

  • <PID> is the process ID for the zxfrd process
  • <name> is the name of the zone for the transfer

For example:

debug zxfrd[11478]: 01531025:7: Serials equal (2017040302); transfer to zone example.com complete.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • Debug logging is enabled for the zxfrd process.
  • This message occurs whenever the zxfrd process requests a zone transfer from a master nameserver and there have been no changes to the zone since the last successful zone transfer.

Note: Beginning in 11.3.0, the log level for this message was changed from notice to debug.

Impact

None, there is no negative impact to the system.

Recommended Actions

The debug log level should only be used when troubleshooting. Once troubleshooting is complete, you should restore the log level for the zxfrd process to the default setting. To so so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To restore the log level for the zxfrd process to the default value, type the following command:

    modify /sys db log.zxfrd.level value notice
