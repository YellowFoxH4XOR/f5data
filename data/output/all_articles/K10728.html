K10728: The Advanced Session Variable 'Condition' field may not be evaluated properly if it contains other Advanced Session Variables

Known Issue

This is the result of a known issue. When configuring an Advanced Session Variable (ASV), the conditional statement you enter in the Condition field is not evaluated properly if it contains two or more ASVs separated by AND or OR logical operators.

For example:

session.asv.test1 OR session.asv.test2

If you configure an ASV with the example condition, FirePass does not match the condition, even if the %session.asv.test1% and %session.asv.test2% variables contain values.

Note: For more information about ASVs, refer to K10108: Overview of Advanced Session Variables.

F5 Product Development tracked this issue as CR125522 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative hotfix HF-603-5 issued for FirePass 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.
