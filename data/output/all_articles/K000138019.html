K000138019: Windows 10 EdgeClient with Google ReCaptcha triggers javascript errors

Type
Support Solution
Published
2023-12-22
Updated
2024-03-22
Applies to
  • BIG-IP
  • APM Clients
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000138019

Description

You have configured BIG-IP APM logon page with Google reCAPTCHA v2 and your users connect using the standalone Edge client.

Users are reporting Javascript errors.

Environment

  • BIG-IP APM
  • Logon page with CAPTCHA
  • Windows Edge client

Cause

Google reCAPTCHA does not support Internet Explorer which Edge Client uses internally: https://support.google.com/recaptcha/answer/6223828?hl=en

Microsoft lists some of the limitation of the Webview component that MS Office also uses: https://learn.microsoft.com/en-us/office/dev/add-ins/develop/support-ie-11?tabs=ie.

Recommended Actions

Create a separate logon page for Edge client users which does not use CAPTCHA.

Additional Information

Note: F5 is considering implementing an updated version of the Webview component into a future software release.
