Known Issue

A BIG-IP APM rewrite of custom Dojo JavaScript go functions may not work as expected.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access policy provides access to a destination web application resource(s).
  • The destination web application implements custom Dojo JavaScript go functions.

Impact

Access to the web application functionality may be limited.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When attempting to access the destination resource, the page stops responding.
  • The destination resource web page contents may not render correctly.

Workaround

To work around this issue, you can disable the BIG-IP APM JavaScript go rewrite functionality by editing the 01000-rules.js file located on the BIG-IP APM system. To do so, perform the following procedure:

Impact of workaround: F5 recommends that you perform this procedure during a scheduled maintenance window.

  1. Log in to the BIG-IP APM command line.
  2. Create a backup copy of the 01000-rules.js file that you want to edit by typing the following command:

    cp -a /var/sam/www/webtop/private/fm/01000-rules.js /var/tmp/01000-rules.js-sol15451
  3. Using a text editor, open the following file:

    /var/sam/www/webtop/private/fm/01000-rules.js
  4. Locate the following line in the 01000-rules.js file (approximately line 231):

    go: { replace: "F5_Invoke_go(", embed: 1, special: 0, minarg: 1, maxarg: 1, func: F5_Invoke_go },
  5. Insert three forward slashes (///) in front of the go: line.

    For example:

    /// go: { replace: "F5_Invoke_go(", embed: 1, special: 0, minarg: 1, maxarg: 1, func: F5_Invoke_go },
  6. Save the modified /var/sam/www/webtop/private/fm/01000-rules.js file.
  7. Repeat these steps for all peer BIG-IP APM devices.

    Note: The 01000-rules.js file is not synchronized between BIG-IP APM peer devices and may be overwritten when applying a code upgrade or hotfix.
