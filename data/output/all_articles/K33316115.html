Description

DNS transparent cache, caches NXDomain/No Error dns response with zero answer in the response.

  • Client performing recusive query against GTM(with DNS transparent cache configured), is getting dns response without answer as as result of the transparent cache.
  • This is an expected behaviour of transparent caches(DNS/GTM)

Environment

  • BIG-IP DNS/GTM 
  • Transparent cache
  • External DNS server

Cause

External DNS server that provide DNS response that provide response to client DNS query did not include an answer in their DNS response.

Example: (When client perform dig/nslook, cache will return the similar output below with "Answer:0"
; <<>> DiG 9.11.13-RedHat-9.11.13-5.el8_2 <<>> @192.5.6.30 abcd.example.com
; (1 server found)
;; global options: +cmd
;; Got answer:
;; ->>HEADER<<- opcode: QUERY, status: NOERROR, id: 24948
;; flags: qr rd; QUERY: 1, ANSWER: 0, AUTHORITY: 4, ADDITIONAL: 9   <--------------- this is no answer.
;; WARNING: recursion requested but not available

Recommended Actions

The actions or steps required to address the topic covered in the description as it is not possible to prevent External DNS to return response without Answer.

  • As a temporary measure, include deleting such record from GTM/DNS transparent cache and allow client query to be send to another external DNS cache that response with Answer.
  • Use Resolver cache instead of transparent cache
