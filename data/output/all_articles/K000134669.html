K000134669: b64decode error within iRule

Type
Support Solution
Published
2025-04-15
Updated
2025-04-15
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000134669

Description

 

Error is shown when b64decode command is used within an iRule.

 

b64decode command returns a string that is base64 decoded from an initial base64 encoded string.

 

 

 

Environment

 

BIG-IP

iRules

b64decode command

 

 

Cause

 

b64decode command works with limited length when used within an iRule; around 76 characters in string.

 

Configuring a longer string (more than 76 characters) will give error:

 

"TCL error: /Common/iRule_Log_Headers <HTTP_REQUEST> - conversion error (line 1) invoked from within "b64decode $token" "

 

 

Recommended Actions

 

Use a 76 character or shorter string when using b64decode command in an iRule

 

Example:

 

when RULE_INIT {
   set ::key [AES::key]
}
when HTTP_RESPONSE {
   set decrypted [HTTP::cookie "MyCookie"]
   HTTP::cookie remove "MyCookie"
   set encrypted [b64encode [AES::encrypt $::key $decrypted]]
   HTTP::cookie insert name "MyCookie" value $encrypted
}
when HTTP_REQUEST {
   set encrypted [HTTP::cookie "MyCookie"]
   HTTP::cookie remove "MyCookie"
   set decrypted [AES::decrypt $::key [b64decode $encrypted]]     <<<<<<< $encrypted string value must be 76 characters or less
   HTTP::cookie insert name "MyCookie" value $decrypted
}
