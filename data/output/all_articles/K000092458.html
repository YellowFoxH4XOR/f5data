K000092458: NGINX proxy_cookie_flags directive replaces set_cookie_flag directive

Type
Support Solution
Published
2022-10-19
Updated
2025-04-02
Applies to
  • NGINX Products
  • NGINX Plus: R23, R24, R25, R26
Source
https://my.f5.com/manage/s/article/K000092458

Description

The set_cookie_flag directive was deprecated in NGINX R23 and removed in R26. The proxy_cookie_flags directive implements native support for setting cookie flags and replaces the old directive.

Environment

  • NGINX Ingress Controller
  • NGINX Plus R26
  • Kubernetes

Cause

Starting in NGINX Plus R26, the third party Cookie-Flag module was completely removed from NGINX, along with the set_cookie_flag directive.

Recommended Actions

Use the new proxy_cookie_flags directive, which implements native support for setting cookie flags.
