Description

Large bigdlog files filing up /var/log disk space causing disk partition error

Error:
warning diskmonitor: 011d0005:4: Disk partition /var/log has less than 20% free

Environment

  • BIG-IP file system management
  • Monitor log files
  • Error messages related to limited disk space available

Cause

/var/log is filing up due to bigdlog debug is enabled

Example:
# tmsh list sys db bigd.debug
sys db bigd.debug {
    value "enable"
}

Recommended Actions

  1. List all bigdlog files
    # ls -lh /var/log/bigdlog*
    Example output:
    -rw-------. 1 root      root      3.0G May 31 03:38 /var/log/bigdlog
    -rw-------. 1 root      root      320M May 29 03:38 /var/log/bigdlog.2.gz
    -rw-------. 1 root      root       17M May 30 19:56 /var/log/bigdlog.1
  2. Disable bigd debug
    # tmsh modify sys db bigd.debug disable
  3. Backup any bigdlog files to your local drive that you need to archive
  4. Delete the other bigdlog files except for bigdlog.
    # rm /var/log/bigdlog.*
     Important: Ensure you do not delete the primary bigdlog, only the older logs.
  5. Empty the primary bigdlog
    # cat /dev/null > /var/log/bigdlog
