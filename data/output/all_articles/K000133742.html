Environment

  • NGINX Management Suite
  • RHEL 8.7

Cause

  • NGINX Instance Manager, NGINX Management Suite, and NGINX App Protect are not supported on ARM architecture.

Recommended Actions

  • Use alternative architecture.

Additional Information

  • NGINX Plus supports aarch64 (the 64-bit version of the ARM architecture is formally known as AArch64) for various Linux options. NGINX Agent also supports aarch64. For more information, refer the following pages:
    • NGINX Plus Technical Specs
    • NGINX Agent Technical Specifications
  • NGINX Instance Manager, NGINX Management Suite, and NGINX App Protect are not supported on ARM architecture. For more information, refer to the NGINX Management Suite Technical Specifications page.
