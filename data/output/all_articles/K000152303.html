K000152303: [F5OS] User required to change their password after the next login when password is updated via API

Type
Support Solution
Published
2025-07-01
Updated
2025-07-01
Applies to
  • F5OS
Source
https://my.f5.com/manage/s/article/K000152303

Description

After a username's password is updated via the set-password command in the /restconf/data/openconfig-system endpoint, after the next login, the username is prompted to change their password again. 

This is seen as an inconvenience.

Environment

  • Password update via API
  • User is prompted to update the password at the next login.

Cause

None. This is Function as Designed. This is designed to prevent the new password from being a simple or default password that could compromise the user's security.

Recommended Actions

None.
