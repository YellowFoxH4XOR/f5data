K000133091: Unable to generate snapshot prior to an upgrade

Type
Support Solution
Published
2023-03-29
Updated
2023-03-29
Applies to
  • Network Function Virtualization
  • F5 VNF Manager
Source
https://my.f5.com/manage/s/article/K000133091

Description

Attempting to generate a snapshot fails

The following log message is observed:
ERROR: Snapshot creation failed: 'NoneType' object has no attribute '_add_contained_node_instance'

Environment

  • Network Function Virtualization
  • VNF Manager

Cause

The command in use is missing the --exclude-credentials option

Recommended Actions

add the --exclude-credentials option to the snapshot creation command
See SNAPSHOTS

Additional Information

Although --exclude-credentials may seem to indicate credentials are excluded, this option basically includes all credentials or users that have been created including the admin account. It also allows all permissions to be set correctly in the backup.
