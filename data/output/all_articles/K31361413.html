K31361413: Understanding Memory Usage graph in BIG-IQ Metrics

Description

The BIG-IP system statically assigns memory resources to services depending on the total amount of system memory and its role as Configuration Manager (CM) or Data Collection device (DCD).

For the main BIG-IQ process this are the values assigned by default:

 16GB32GB64GB128GB
CM6GB16GB30GB30GB
DCD2GB2GB2GB2GB

Environment

  • BIG-IQ
  • High memory usage
  • Statistics

Cause

Memory Usage graph in BIG-IQ Metrics only shows memory in use by this java process that runs the main BIG-IQ application. By design Java programs tend to use all memory available because it allows them to be more efficient about garbage collecting. So values near 100% for this graph are not unusual and don't mean that the device is under memory pressure.
