Known Issue

The BIG-IP ASM system may not include URL and HTML Rewrite features.

This issue occurs when the following condition is met:

  • The BIG-IP system is configured with an ASM standalone license.

Impact

BIG-IP URL and HTML Rewrite features cannot be implemented.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you configure the Rewrite profile and assign it to a virtual server, you notice that traffic is not rewritten.
  • When upgrading from BIG-IP 11.4.1 to 11.6.0, the URL Rewrite functionality is lost. Additionally, when you access the Rewrite profile in the Configuration utility, the system reports an error message similar to the following example: 

    URI Translation (Not Licensed)
