Topic

You should consider using this procedure under the following condition:

  • You want to gather real-time statistics of the CIFS/SMB round trip time between the ARX system and a managed filer.

Description

The expect script sysstat filer was introduced in ARX 6.1.0, and you can use it to monitor CIFS/SMB real-time statistics to the backend filers.

With the sysstat filer expect script, you can track the CIFS/SMB Round Trip Times (cifs-rtt) live on the ARX system as it communicates to the filer. The output gives you an idea of what the round trip time is for the filer response to CIFS/SMB calls that the ARX makes. You may locate the expect script sysstat filer on the ARX system by running the show scripts command.

The most common use of this script is when there are suspected CIFS/SMB performance issues between the ARX system and a filer.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have administrative access to the ARX CLI.

Procedures

To gather real-time statistics of the CIFS/SMB round trip time using the sysstat filer script, perform the following procedure:

Impact of procedure: None

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable

  3. Gather the filer statistics by typing the following command syntax:

    expect sysstat filer <ARX External-Filer Name> cifs-rtt

    For example:

    expect sysstat filer lwlnetapp04 cifs-rtt

             Read  Write  Create       Find- Find- Query Query   Query    Tree-  Tree-  Session
    Time     -AndX -Andx -Andx  Close  First Next FSInfo PathInf FileInf  ConnX  DConn  Setup
    ----     ----- ----- ------ -----  ----- ----- -----  -----  -------  -----  ------ -------

    19:38:48    -     -     -     -      -     -     -     0.21     -      -      -      -
    19:38:53    -     -     -    0.15    -     -     -     0.24     -      -      -      -
    19:38:58    -     -     -    0.24    -     -     -     0.24     -      -      -      -
    19:39:03    -     -     -    0.22    -     -     -     0.22     -      -      -      -
    19:39:08    -     -     -    0.16    -     -     -     0.35     -      -      -      -

Note: The command output refreshes on the screen every five seconds. The data reflects the average of the cifs-rtt requests that the system collected during the five second intervals.
