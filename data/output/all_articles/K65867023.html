Issue

Error Message

010c006c:5: proc stat: [0] <process information>

In this error message, note the following:

  • <process information> is information regarding system process values such as memory size, process ID, start time, up time, etc. 

For example:

010c006c:5: proc stat: [0] pid:12345 comm:(bigd) state:S utime:6 stime:2 cutime:13 cstime:5 starttime:7709247 vsize:47583232 rss:6415 wchan:18446744071579502277 blkio_ticks:1 [-1] pid:3648 comm:(bigd) state:S utime:1920 stime:604 cutime:12 cstime:10 starttime:176428 vsize:50548736 rss:6472 wchan:18446744071581059260 blkio_ticks:15 [-2] pid:3648 comm:(bigd) state:S utime:1920 stime:604 cutime:12 cstime:10 starttime:176428 vsize:50548736 rss:6472 wchan:18446744071581059260 blkio_ticks:15 

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The Switch Over Daemon (sod) has stopped monitoring a system process. This typically happens when the Traffic Management Microkernel (TMM) is restarting.

Note: sod causes the unit to become active or standby, and provides failover capability through a high availability table.

Impact

There is no impact; this message is informational.

Recommended Actions

None
