Description

When using the GUI to enable TLS 1.3.

While trying to configure the required cipher group on the default client ssl profile, you are unable to save the config, on the GUI you will be seeing an error similar to this one:

A cipher group must be configured when TLS 1.3 is enabled.


Environment

  • BIG-IP LTM
  • Enable TLS 1.3
  • Default clientssl profile

Cause

You are trying to change this option on the default clientssl profile, this change is not allowed on the default profile.

Recommended Actions

  1. Create a child client SSL profile using the default as a parent.
  2. You can follow the instructions in the following article: K10251520
  3. Make sure you enable the cipher group option on the new ssl profile and associate it to the desired virtual server.
