Description

This article describes how you can grant access to the client certificate/key to F5 Access on MAC OS, so you do not have to keep providing your credentials when prompted. On your MAC OS client, you may experience numerous prompts for credentials when managing F5 Access configurations and connecting to BIG-IP APM network access VPN. You observe a prompt similar to the following:

PacketTunnel wants to makes changes. Enter an administrator's name and password to allow this. 
PacketTunnel wants to use the "System" keychain

The security prompt is needed to get your permission to access the client certificate and key to connect to the VPN server. 

Environment

  • BIG-IP APM network access
  • F5 Access on MAC OS

Cause

You get the prompts because the F5 Access plugin does not have access to the client certificate and key on MAC OS.

Recommended Actions

Note: This process is not necessary for F5 Access macOS 7.2.6 or later.

To provide the F5 Access plugin access to the client certificate and key, perform the following procedure:

  1. Create a symbolic link to the F5 Access plugin on your user's desktop by enter the following command:
    ln -s /Applications/F5Access.app/Contents/PlugIns/PacketTunnel.appex  /Users/taccount/Desktop/PacketTunnel.appex

    Observe on your MAC desktop that a new F5 Access icon, PacketTunnel.appex is created.

  2. Use Keychain Access to provide the F5 Access plugin access to the client certificate and key.
    1. Launch Keychain Access on your MAC
    2. On the left panel, select login.
    3. On the right, select the Keys tab.
    4. Double click the key to open a new window to it.
    5. Select Access Control.
    6. Select +.
    7. Select Desktop on the left and the PacketTunnel.appex icon you created in the step 1.
    8. Select Add.
    9. Select Save Changes.
    10. Provide your credentials if prompted to do so.

If you need to grant access to other Apps such as BIG-IP Edge Client, F5 Endpoint Inspector and so on to other certificates and keys, repeat step 2.
