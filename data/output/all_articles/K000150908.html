Description

  • User experiences an issue accessing an internal application.
  • You implemented OAuth authentication with Microsoft Entra ID as the OAuth provider.
  • You configure your BIG-IP APM system as an OAuth Client/Resource server.
  • Your BIG-IP APM system is unable to obtain an access token from the OAuth provider.
  • You observe the following log entry in /var/log/apm:

<bigip_hostname> err apmd[16274]: 01490290:3: <partition>/<access_polic>:454c7108:<partition>/<OAuth_client_object>_act_oauth_client_ag: OAuth Client: failed for server '<partition>/<OAuth_server>' using 'authorization_code' grant type (client_id=exampleID), error: HTTP error 400, Error: interaction_required: AADSTS53003: Access has been blocked by Conditional Access policies. The access policy does not allow token issuance. Trace ID: <trace_id> Correlation ID: <correlation_id> Timestamp: YYYY-MM-DD HH:MM:SSZ

Environment

  • BIG-IP APM
  • MS Entra ID
  • OAuth

Cause

This issue does not originate from the BIG-IP APM system. Microsoft Entra ID Conditional Access policy is preventing the BIG-IP APM system from obtaining an access token, blocking the completion of the OAuth flow.

Recommended Actions

Investigate which Conditional Access policy in Microsoft Entra ID is blocking token issuance.
