K000136895: License installation fails on BIG-IQ

Type
Support Solution
Published
2023-09-20
Updated
2023-09-20
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0
Source
https://my.f5.com/manage/s/article/K000136895

Description

You try to install AWS license on a BIG-IP device using the BIG-IQ license manager but licensing failed and you get similar errors on BIG-IQ and BIG-IP.
BIG-IQ:

Error installing: Failed to install license to device 10.20.30.40 (Not a valid F5 License): com.f5.rest.workers.device.license.LicenseException: Failed to install license to device 10.20.30.40 (Not a valid F5 License)

 

BIG-IP:

warning chmand[4223]: 012a0004:4: CHMAN request (from DossierValidator) for tag:19 failed

Environment

  • BIG-IQ
  • BIG-IP
  • License

Cause

 

Bug ID 810925: Regkey Pool cannot be use to license AWS BIG-IP VE

Recommended Actions

Use following commands restart restjavad process on BIG-IQ and BIG-IP devices:
 

tmsh restart sys service restjavad

Additional Information

None
