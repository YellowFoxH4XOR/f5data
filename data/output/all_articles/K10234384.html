Description

Where to see the total memory and CPU and the utilization of memory and  CPU for a BIG-IQ.

Environment

  • BIG-IQ 

Cause

None

Recommended Actions

  1. From the GUI you can only see the Memory Usage:

    System >> This Device >> Statistics >> Memory Usage
    System >> This Device >> Statistics >> CPU Usage

    System >> This Device >> Statistics >> BIG-IQ Metrics >> Memory Usage
    System >> This Device >> Statistics >> BIG-IQ Metrics >> CPU Usage
     
  2. From the command line:  tmsh show sys memory
    [root@BIG-IQ-8A:Active:Standalone] config # tmsh show sys memory
