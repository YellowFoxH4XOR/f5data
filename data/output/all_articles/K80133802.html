Description

IP address of new virtual server is not accessible until the ARP table on the upstream router updates

  • When a new Virtual Server is created, the BIG-IP does not send GARP's on the network

Environment

  • BIG-IP LTM 14.1+

Cause

Bug ID 901929: GARPs not sent on virtual server creation

Recommended Actions

After creating the virtual server, disable and re-enable the ARP setting on the corresponding virtual address.

None
