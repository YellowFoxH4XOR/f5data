Description

Management access is lost after upgrade/reboot BIG-IP deployed in Azure.

Environment

  • BIG-IP
  • Azure
  • IP configured via DHCP

Cause

During upgrade, management IP address configured via DHCP may be wiped or not reassigned by Azure, resulting in loss of management access.

 

Recommended Actions

1. Change management IP configuration from DHCP to Manual before performing an upgrade; fill IPv4 settings as needed.



2. For future upgrades, proactively set management IP to Manual.

3. To verify current management access i.e. via console, you can use below commands:

# list /sys management-ip
sys management-ip x.x.x.x/x { }
    description configured-by-dhcp
}

# list /sys management-route
sys management-route default {
    description configured-by-dhcp
    gateway x.x.x.x
    network default
}

4. The management address can also be found in the Azure BIG-IP settings.
