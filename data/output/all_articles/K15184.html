Known Issue

BIG-IP APM access policy AAA AD password updates may fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with an access policy using AD AAA.
  • The BIG-IP APM access policy is configured to execute an AD query prior to authenticating the user.
  • During authentication to the BIG-IP APM system, the user enters an invalid password and meets one of the following conditions:
    • The user authentication password expiration warning is enabled on the BIG-IP APM system.
    • The user's AD password is expired.

      Impact

      Users are unable to complete an update of their AD password.

      Symptoms

      As a result of this issue, you may encounter the following symptoms:

      • The BIG-IP APM system prompts the user multiple times to enter their new AD password.
      • When the user attempts to update their password, they may receive an error message similar to the following example:

        (error: Preauthentication failed, principal name: APMUSER1@SOMECORP.NET. Invalid user credentials.)
      • The BIG-IP APM system logs messages to the /var/log/apmd file that appear similar to the following examples:

        err apd[22650]: 01490107:3: fdd91b2f: AD module: change password for 'APMUSER1@SOMECORP.NET' failed: Preauthentication failed, principal name: APMUSER1@SOMECORP.NET. Invalid user credentials. (-1765328360)

        info apd[22650]: 01490019:6: fdd91b2f: AD agent: Query: query with '(sAMAccountName=APMUSER1)' failed

      Resolution

      Status

      F5 Product Development has assigned ID 435719 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article.       Workaround

      To work around this issue, you can restart the access profile session. To do so, close the browser or the browser tab of the BIG-IP APM access session, then re-open the browser or open a new browser tab and enter the access profile URI.

      Impact of workaround: None
