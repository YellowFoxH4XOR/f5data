Topic

Beginning from 25th October 2025, to support any ProtocolInspection-LatestUpdate IM release (for example, pi_updates_17.1.0-20251029.1701.im), the CA bundle file for the IPS signature update on the BIG-IP system needs to be updated before IM packages can be uploaded and verified by the system as trusted. This article describes the procedures needed to update the CA bundle file on the BIG-IP system.

Description

To update the CA bundle on the BIG-IP system so that IM packages can be verified and trusted, perform the following procedures:
Note: You need to perform these 2 procedures only once. Once you have installed the CA bundle, you can perform future IPS signature update as per usual by downloading, installing, and deploying a new IM package.

  • Download the latest CA bundle from MyF5 downloads
  • Install the CA bundle on the BIG-IP system

Download the latest CA bundle from MyF5 downloads

To download the latest CA bundle ca_bundle_oct_2025.pem, perform the following procedure:

  1. Go to MyF5 Downloads.
  2. For the Group container, select BIG-IP.
  3. Select the appropriate Product Line.
  4. Select your Product Version.
  5. Select ProtocolInspection-LatestUpdate.
  6. Select ca_bundle_oct_2025.pem.
  7. Select your download location.
  8. Select Download.

Install the CA bundle on the BIG-IP system.

To install the CA bundle on the BIG-IP system, concatenate two PEM files, name the new certificate file as 2.f5_sirr_cabundle.crt, and rename the original .crt file for backup. To do so, perform the following procedure:

  1. Upload the CA bundle downloaded from the previous procedure to the BIG-IP system.
  2. Login to the BIG-IP.
  3. Change to the ips directory:
    Note: BIG-IP AFM needs to be provisioned.
    cd /shared/lib/ips
  4. Create the new CA bundle file:
    cat 1.f5_sirr_cabundle.crt ca_bundle_oct_2025.pem > 2.f5_sirr_cabundle.crt
  5. Create a backup of the original CA bundle:
    mv 1.f5_sirr_cabundle.crt 1.f5_sirr_cabundle.crt_backup

Additional Information

You need to perform the 2 procedures in the Description section only once. Once you have installed the CA bundle, you can perform future IPS signature update as per usual by downloading, installing, and deploying a new IM package.
