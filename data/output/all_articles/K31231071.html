Description

SSL connection failes. 
tcpdump shows backend server sends below alert and terminating connection.

Alert (Level: Fatal, Description: Internal Error)
 

Environment

  • BIG-IP
  • any version
  • SSL/TLS
     

Cause

One of the reasons backend server send that alert may be due to lack of SNI (Server Name Indication) information.
 

Recommended Actions

Check backend server requirement for SSL/TLS.
  1. If the Virtual server has Server SSL profile attached, set SNI  to the Server SSL profile or iRule. Please refer further details how to set below articles.
    K13452: Configuring a virtual server to serve multiple HTTPS sites using the TLS Server Name Indication feature
    Clouddocs >> SSL::sni iRule command
     
  2. If the Virtual server does not have SSL profiles, Client needs to sends required SNI.
     

Additional Information

If Virtual server is sending the alert, please refer K99024503: SSL Handshake terminated by Virtual server with "Fatal, Description: Internal Error" when client-ssl or iRule enforcing client authenticate.
