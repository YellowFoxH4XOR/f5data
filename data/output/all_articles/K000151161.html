Description

  • What does Endpoint quota object in XC Console actually represent?

Environment

  • XC Console
  • Quota

Answer

Endpoint object represents the actual endpoint that provides the service (Origin Server). Sometimes due to dynamic discovery of the endpoints, single endpoint object may result in multiple actual discovered endpoints.
