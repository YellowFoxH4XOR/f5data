Known Issue

The BIG-IP ASM system may incorrectly trigger ASM cookie hijacking violations. This issue occurs when all of the following conditions are met:

  • The affected security policy is configured to block ASM cookie hijacking violations, and is enabled with CSRF protection.
  • The BIG-IP ASM system receives a client request containing a cookie header that has an empty value cookie between the ASM CSRF cookie and the ASM main cookie.

    The following example cookie headers illustrate the empty value cookie myemptycookie that resulted in the ASM cookie hijacking violation false positive:

    Cookie: TSe42e2a_75=b52bdd6906070fd7dc7babea690a30bb:ebac:u727tpM4:612850247; SESSION=424b9bd80f4cddfc79ded8306e971eee; myemptycookie=; TSe42e2a=db174d5cebcf9b579d389eff019b2dcb25563eb49987faef51c01a9f82238be676d87dc87
    ff3255c76d87dc88d3c77d87739529e6569e3ed76d87dc8; Path=/

This issue occurs because the BIG-IP ASM cookie parser incorrectly acts as though the BIG-IP ASM main cookie has the value of the empty value cookie, and flags the ASM CSRF cookie as a hijacked cookie, since the cookie parser cannot find the ASM main cookie in the client request.

Impact

The BIG-IP ASM system may report false positive ASM cookie hijacking violations.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP ASM system triggers the ASM cookie hijacking violation, although the ASM cookies have not been tempered.
