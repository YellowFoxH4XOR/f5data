Known Issue

The BIG-IP 11000 and 11050 platforms cannot be provisioned with the BIG-IP LTM and Link Controller module combination.

This issue occurs when the following conditions are met:

  • The BIG-IP system is licensed for both LTM and Link Controller.
  • You are attempting one of the following scenarios:

    • Provisioning a BIG-IP 11000 or 11050 new installation with both the LTM and Link Controller modules.
    • Upgrading a BIG-IP 11050 version 10.x platform already provisioned with both the LTM and Link Controller modules.

The Link Controller module is not listed as an available provisioning option for the BIG-IP 11000 or 11050 platforms running an affected version.

Impact

Link Controller functionality is not available.

Additionally, if you upgrade a BIG-IP 11050 platform from a version 10.x system that is already provisioned for both LTM and Link Controller modules, to an affected version, the Link Controller module is no longer provisioned.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Link Controller module is not listed as an available provisioning option for BIG-IP 11000 or 11050 platforms that are running an affected version.
  • After upgrading a BIG-IP 11050 platform from a version 10.x system that was already provisioned for both LTM and Link Controller modules, to an affected version, the Link Controller module is no longer provisioned.

Workaround

None. However, for a BIG-IP 11050 10.x platform that is already provisioned with both the LTM and Link Controller modules, you can upgrade directly to a fixed version to ensure that the Link Controller module does not get deprovisioned.
