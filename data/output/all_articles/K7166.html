If idle connections are allowed to remain in the BIG-IP connection table for extended periods, they continue to consume system memory, which reduces the amount of memory available for new connections. To address this, you can adjust the idle timeout setting for the relevant protocol profile for a virtual server. The idle timeout setting specifies the length of time that a connection is idle before it is eligible for deletion by the BIG-IP LTM system.

You can change the protocol profile idle timeout by changing the existing profile, or create a new profile that uses a different timeout value.

Note: As with all profile customizations, F5 recommends that you do not edit the supplied default profiles on the BIG-IP system. Instead, create new custom profiles based on the default profile of the desired type. If some non-default profile settings (such as idle timeout values) are used for all custom child profiles, you should consider first creating a new custom profile with these non-default base settings, then use the new custom profile as the parent for a second generation of custom child profiles.

Change the idle timeout for an existing protocol profile

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles.
  3. Select the Protocol tab.
  4. Select the relevant protocol profile. For example, FastL4.
  5. Select the profile to modify.
  6. Enter the new Idle Timeout value, in seconds.
  7. Select Update.

Note: Changing the idle timeout value for an existing protocol profile does not alter the timeout used for existing virtual server connections; existing connections continue to use the previous idle timeout value. To force an existing connection to use the new timeout value, you must manually remove the existing connection from the connection table using the tmsh delete sys connection command.

Create a new protocol profile that uses a different timeout value

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles.
  3. Select the Protocol tab.
  4. Select the relevant protocol profile. For example, FastL4.
  5. Select Create.
  6. Enter a name for the new profile.
  7. For Parent Profile, select the parent profile you want to use.
  8. For Idle Timeout, select the Custom check box.
  9. Enter the new Idle Timeout value, in seconds.
  10. Select Finished.
  11. Go to Local Traffic > Virtual Servers.
  12. Select the virtual server to modify.
  13. For Configuration, select Advanced.

    Note: For BIG-IP 11.5.0 and later versions, selecting Advanced is no longer necessary.

  14. In the Protocol Profile (Client) box, select the new profile you created.
  15. Select Update.

The virtual server now uses the new idle timeout setting.
