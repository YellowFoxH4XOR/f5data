K3086: Reasons why the BIG-IP system may report higher memory usage after upgrade to version 4.5 PTF-04 or later

Topic

Starting in version 4.5 PTF-04, OpenSSL (upon which the SSL Proxy is based) was upgraded from 0.9.6 to 0.9.7a. This upgrade includes a number of fixes and addresses multiple security vulnerabilities; however, the new version increases memory utilization by approximately 20%. On very busy systems, system memory can become completely exhausted and generate an error similar to the following:
bigmsg2_switch: out of memory

If you are consistently receiving low memory messages, you may require a memory upgrade. For information about purchasing additional memory, contact your local F5 Sales representative.
