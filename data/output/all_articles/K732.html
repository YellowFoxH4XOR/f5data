Topic

The scan level option affects only HTTP type ECV health monitors. These options control whether host headers are added to the ECV request. You may require a host header if your servers host multiple sites and serve content based on the host header that is included in the request.

The three ECV scan level options are defined as follows:

  • first
    When you choose first, the ECV will run once per interval against each server and virtual server in the wide IP. The ECV will perform a health check that includes an HTTP host header, using the wide IP name as the host.
  • all
    When you choose all, the ECV will run multiple times per interval against each server and virtual server. The ECV will perform a health check that includes an HTTP host header, using the wide IP name as the host. In addition, the ECV will perform a check for each wide IP alias name that includes an HTTP host header, using the alias name as the host.

    Important: There is no limit to the number of ECV checks that will be run when you choose this all. This option can result in excessive load on your servers if you have a large number of aliases.

  • none
    When you choose none, the ECV will run once per interval against each server and virtual server in the wide IP. The ECV will not include an HTTP host header.
