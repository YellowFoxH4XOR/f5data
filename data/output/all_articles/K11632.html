Known Issue

Interface 3.1 may be reported as an incompatible trunk member after a restart.

This issue occurs when all of the following conditions are met:

  • You restarted a BIG-IP 8900 platform running 10.1.0 (either following the upgrade to 10.1.0 or a reboot).
  • The system has a configuration with an interface trunk consisting of interface members 3.1 and 3.2.

A firmware timing issue in BIG-IP 10.1.0 may cause the 3.1 interface on the BIG-IP 8900 platform to temporarily fail to be detected when you restart the system. As a result, a configuration containing an interface trunk with 3.1 as a member will fail to load and cause the mcpd process to stop loading the configuration.

Impact

The configuration will fail to load. If the BIG-IP system is the active system it will fail to process traffic until you manually reload the configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After upgrading to 10.1.0 (or rebooting a system currently running 10.1.0), the configuration fails to load and the system logs error messages to the /var/log/ltm file that appear similar to the following example:

    mcpd[4877]: 01070619:3: Interface 3.1 media type is incompatible with other trunk members
    bigpipe[5790]: 012e0006:3: Shell: BIGpipe trunk member creation error: 01070619:3: Interface 3.1 media type is incompatible with other trunk members
    bcm56xxd[4867]: 012c0015:6: Link: 3.1 is UNPOPULATED
    bcm56xxd[4867]: 012c0015:6: Link: 3.1 is DOWN
    bcm56xxd[4867]: 012c0015:6: Link: 3.1 is UP
    bcm56xxd[4867]: 012c0015:6: Link: 3.1 is DOWN

Note: The Interface 3.1 media type is incompatible with other trunk members error message may also be logged for another condition. For information refer to K17077: Error Message: 01070619:3: Interface <3.x> media type is incompatible with other trunk members.

Resolution

Status

F5 Product Development has assigned ID 247859 (formerly CR136102) to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles
Release10.2.0K2200: Most recent versions of F5 software
Hotfix10.1.0 HF1K9502: BIG-IP hotfix matrix

Workaround

To work around this issue, you can you can reload the configuration with the bigpipe load command.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system. However, the issue may occur again if you reboot the system.
