Issue

Old Behavior

Prior to BIG-IP 13.1.0, the TMOS Shell (tmsh) show sys connection command returns all current active flows/connections, regardless of the number of connections. In some scenarios, this behavior negatively impacts the system when the connection table contains a large number of connection records. There is no property for the command to indicate the number of connection records to display and the command requests a confirmation similar to the following example:

Really display all connections?

New Behavior

Beginning in BIG-IP 13.1.0, the show sys connection command now returns the first 1,000 currently active flows/connections by default. Additionally, the new max-result-limit property allows you to specify together with an integer to change the number of connection records returned. The command syntax appears similar to the following example:

show sys connection max-result-limit <number of connection records to be returned>


Similar to previous behavior, the command continues to request a confirmation similar to the following example:

Really display <X> connections?

In this example, note the following

  • <X> is either the default value of 1,000 or a user-specified value.

Impact

The show sys connection command now limits the number of returned connection records to the first 1,000 records. If you want to change the number of records returned, you must specify a specific value.

Recommended Actions

Use the max-result-limit option to display the desired number or connection records.  

For example, if you want the command to display the first 300 connection records, you would type the following command:

show sys connection max-result-limit 300

If you do not specify the max-result-limit property, the command uses the default value of 1,000. You can use the max-result-limit property with other properties, such as cs-client-addr. For example:

show sys connection max-result-limit 300 cs-client-addr 192.168.62.64

If you want to display all connection records (similar to previous behavior), specify infinite in place of the integer value. For example:

show sys connection max-result-limit infinite

Important: You should use the infinite value with caution. Depending on your environment and BIG-IP platform, your BIG-IP system may restart some processes, such as the Traffic Management Microkernel (TMM) or mcpd if a large number of connection records are returned.
