Description:

While importing the user from CSV file there may be chances of duplicate user ID entries in Local DB which can cause problem during authentication.

 

Environment:

  • BIG-IP APM
  • Local DB
  • CSV File

 

Cause:

Duplicate user ID entries in Local DB.

 

Recommended Action:

Find duplicate user ID entries with the help of below command

ldbutil --list | perl -ane 'print "$F[0]\n";' | sort | uniq -c | sort -nr -k 1 | head

 

Additional Information:

None.
