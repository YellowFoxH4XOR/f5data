K000091623: When ASM policy is applied to Virtual Server, connection resets

Type
Support Solution
Published
2022-06-13
Updated
2022-08-17
Source
https://my.f5.com/manage/s/article/K000091623

Description

Whether the ASM policy is in Transparent mode or Blocking, when applied to Virtual Server, the connection is reset.


The packet captures shows:

Internal error (ASM requested abort (plugin abort error))]

 

Environment

  • POST Request Method

  • Response contains header Transfer-Encoding: chunked

  • Without ASM policy, it function properly


Cause

This behaviour occurs due to Bug ID 1017557: ASM Plugin Abort reset for chunked response without proper terminating 0 chunk followed by FIN

 

 Recommended Actions

Refer to the workaround options specified in Bug ID 1017557.

 

Additional Information

None.
