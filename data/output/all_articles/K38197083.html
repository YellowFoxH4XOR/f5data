Description

After upgrade the BIG-IP from v12.x to v13.x or later. Users in Resource-Admin group can directly access to bash shell after logging in. 

Environment

  • BIG-IP
  • The previous version is v12.x
  • The upgraded version is v13.x or later

Cause

Users with non-administrator roles (for example, Guest or Resource Administrator) with TMOS Shell (tmsh) access can run arbitrary commands with elevated privilege using a crafted tmsh command. (CVE-2020-5858)

Recommended Actions

  1. Login to BIG-IP
  2. Disable the tmsh for the Resource-Admin group users, refer to K36814487 (GUI and CLI).
  3. Change the Resource-Admin permission back to tmsh, this will append a new configuration to the BIG-IP.
  4. Save the configuration

    # tmsh save /sys config
     
  5. Verifying by logging in to the BIG-IP again using the user in Resource-Admin group, it will directly reach to tmsh shell.
