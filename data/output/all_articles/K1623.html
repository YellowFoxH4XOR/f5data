Topic

For BIG-IP to load balance decrypted traffic from ECCs to nodes, the ECCs must be configured in a one-armed configuration that directs traffic back to a port 80 virtual IP address on the BIG-IP, which then load balances the traffic.

For this configuration, you will need to perform the following tasks:

Note: For specific instructions about how to create pools and virtual servers, refer to the BIG-IP Reference Guide.

  1. Create a pool that includes all the proxy addresses for the ECCs and the relevant Web sites.

    Note: F5 Networks recommends that you use SSL persistence for these addresses with simple persistence as a backup method. You can do this by placing a timeout in the simple persist timeout field and leaving the SSL option button selected for the active persistence method. For more specific information about configuring simple persistence, refer to the BIG-IP Reference Guide.

  2. Create a virtual server on port 443 that points to the pool of ECCs that you created.
  3. Create another pool of HTTP servers.
  4. Create a virtual server on port 80 that resides only on the network on which the ECCs are connected. For this virtual server, disable all other VLANs and point it to the pool of HTTP servers.
  5. On each ECC, create a proxy that will coincide with the addresses for the BIG-IP ECC pool. Verify that the proxy is a non-local destination address and service that matches the virtual server that you created on port 80. (These are the addresses that will be in the pool you created in step 1.)

    Note: As long as auto_lasthop is enabled, a NAT or SNAT is not required to ensure that return traffic is sent to the correct ECC.

Example configurations

Following are example configurations.

BIG-IP configuration

virtual 192.168.14.37:https unit 1 {
use pool ecommerce_pool
}
pool ecommerce_pool {
member 172.16.0.111:https
member 172.16.0.112:https
member 172.16.0.113:https
}
virtual 172.16.0.222:http unit 1 {
use pool X_pool
}
pool X_pool {
member 172.16.10.33:http
member 172.16.0.150:http
}

ECC configuration

Note: This configuration is for the first ECC. Additional ECCs will have the same Proxy definition except for the IP address, which will change as in the pool definition for the BIG-IP configuration.

# constants
global open_ssh_port enable
global open_corba_ports enable
global webadmin_port 443
# services
service 443 tcp enable
# default gateway pool
pool default_gateway_pool {
member 172.16.0.254:*
}
default_gateway use pool default_gateway_pool
# proxies
proxy 172.16.0.111:https unit 1 {
target server 172.16.0.222:http
clientssl enable
clientssl key www.vapornetworks.net.key
clientssl cert www.vapornetworks.net.crt
}
# monitors
node * monitor use icmp
