Description

When attempting to add a BIG-IP Next instance to Central Manager, an error occurs:

Instance 10.152.0.108 could not be added. Reason: DEVICE-0206: BIG-IP Next instance 
discovery error: Failed to update network config: unable to create instance L3 Network 
for instance 10.152.0.108: BIG-IP Next instance 10.152.0.108 rejected create L3-network 
request with status: 400, response: {"_errors":[{"id":"181e6fcd-a87e-4d2c-bd19-079528ff0784",
code":"13158-00095", "title":"","detail":"Failed to read request Query Param Error at: properties. 
Reason: property \"isDefault\" is unsupported","status":"400"}]}

Environment

  • BIG-IP Next Central Manager 20.2.1

  • Adding a BIG-IP Next instance. The instance has already been onboarded.

  • The BIG-IP Next instance is running version 20.2.0

Cause

The BIG-IP Next instance's L3-Networks has an L3-Network defined that contains an "isDefault": true parameter.

Recommended Actions

If you are trying to add a brand new BIG-IP Next instance, it is easiest to delete the instance running 20.2.0 and bring up an instance running version 20.2.1.

If you wish to preserve the instance running 20.2.0 and have the ability to run API commands, first issue a GET request to /api/v1/L3-networks. Look for the L3-network that contains the "isDefault" parameter

{
    "name": "L3Network-internal",
    "isDefault": true,
    "l2Networks": ["L2Network-internal"]
}

You can then issue a PUT request to the affected L3-Network at /api/v1/L3-networks/{id}, removing the isDefault property. Then you can attempt to add the device again.
