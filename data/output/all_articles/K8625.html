Known Issue

This is the result of a known issue. The BIG-IP ASM system limits object type wildcard expressions to eight characters. For example, if you try to define an object type in the BIG-IP ASM Configuration utility using the [a-f][x-z] expression, the object type is not created and the following error message is generated by the Configuration utility:

«Object Type» is limited to 8 characters.

F5 Product Development tracked this issue as CR70165 and it was fixed in BIG-IP LTM 9.4.5. For information about upgrading, refer to the BIG-IP ASM Release Notes.
