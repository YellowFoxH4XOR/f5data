K000159808: After upgrade, unable to reorder rules under AFM policies while Inline Rule Editor Firewall option is disabled.

Type

Published
2026-01-28
Updated

Source

Description

After software version upgrade, reordering firewall rules under AFM policy on GUI no longer works. This happens only when Inline Rule Editor Firewall option is disabled (default enabled).

Before software version upgrade, it was possible to reorder rules by dragging each rule and dropping it to the desired place, as shown below.

Figure: Firewall rules under AFM policy screen

 

While reordering does not work, browser debug console may show similar errors as shown below.

Environment

- Running software version 17.1.3 or later (17.1.x branch), software version 17.5.1.1 or later (17.5.1.x branch), or software version 21.0.0.
- Inline Rule Editor Firewall option ("afm.inlineruleeditor" db key) is disabled (default enabled).

 

Figure: Firewall Inline Rule Editor option

 

Cause

Bug ID2217793.

 

Answer/Recommended Actions

Enable BIG-IP AFM Inline Rule Editor.

  1. On GUI, go to "Security >> Options : Network Firewall >> Firewall Options".
  2. Click the check box on "Inline Rule Editor".
  3. Click Update.

None.
