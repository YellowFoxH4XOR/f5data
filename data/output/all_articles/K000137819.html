Description

You are attempting to install the agent on an Instance to be managed by NMS (NGINX Instance Manager)

The installation script is similar to this, where nms.example.com is the FQDN of the NMS server:

 

Adding public key https://nms.example.com/packages-repository/nginx-signing.key...

Finished adding public key.

Adding NGINX Agent apt repository...

Creating apt config: /etc/apt/apt.conf.d/80agent

Adding nginx-agent.list to /etc/apt/sources.list.d

Adding packages URL to /etc/apt/sources.list.d/nginx-agent.list

Updating permissions for /etc/apt/sources.list.d/nginx-agent.list to 644

Public key to repository added.

Hit:1 http://us-east-1.ec2.archive.ubuntu.com/ubuntu jammy InRelease

Get:2 http://us-east-1.ec2.archive.ubuntu.com/ubuntu jammy-updates InRelease [119 kB]

Hit:3 http://us-east-1.ec2.archive.ubuntu.com/ubuntu jammy-backports InRelease

Get:4 http://security.ubuntu.com/ubuntu jammy-security InRelease [110 kB]

Hit:5 https://dist.scaleft.com/repos/deb jammy InRelease

Get:6 https://nms.example.com/packages-repository/deb/ubuntu jammy InRelease [7388 B]

Hit:7 https://repo.cloudlinux.com/kernelcare/kernelcare-debian/11 kcare InRelease

Err:6 https://nms.example.com/packages-repository/deb/ubuntu jammy InRelease

 The following signatures couldn't be verified because the public key is not available: NO_PUBKEY C53A5949ADAC7D41

 

Environment

Install the Agent on NMS according to the documentation

https://docs.nginx.com/nginx-management-suite/nginx-agent/install-nginx-agent/

 

Cause

The permissions on the keyring file copied to the Instance are incorrect.

Recommended Actions

Fix the permissions on the Instance. Run as root or sudo

 

# chmod 644 /usr/share/keyrings/nginx-signing.gpg 

 

Additional Information

This issue is resolved in NMS 2.15
