K000149942: The file ssmtp.conf doesn't save changes after rebooted

Type
Support Solution
Published
2025-02-24
Updated
2025-03-14
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000149942

Description

The ssmtp.conf file reverts to its default configuration after a system reboot. This likely occurs when manually making changes to the file.

 

Environment

  • BIG-IP LTM
  • Configuring ssmtp on BIG-IP

 

Cause

The root cause of this issue is that the changes made to the ssmtp.conf file are not persisted because the save /sys config command was not executed after modifying the configuration. Without saving the system configuration, any unsaved changes will be lost upon reboot, and the device will reload its default settings.

 

Recommended Actions

To ensure that changes to the ssmtp.conf file persist through reboots, follow these steps:

 

  1. Modify the ssmtp.conf file as needed.
  2. After making your changes, execute the following command in the terminal:
    1. save /sys config

If possible, reboot the device to confirm that your changes persist.
