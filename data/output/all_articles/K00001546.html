Description

Hardware Error messages are logged in /var/log/kernel.log:

 emerg kernel: mce: [Hardware Error]: CPU 0: Machine Check: 0 Bank 11: 8c00004a000800c2

Environment

  • BIG-IP
  • Hardware error logged in /var/log/kernel.log

Cause

Bug ID 1041865
 

Recommended Actions

If running BIG-IP software version where ID1041865 has not been fixed, correctable errors are logged which can be ignored.

  1. Run the following command to check for correctable and non-correctable errors:

    zcat -f -- /var/log/kern.* 2>/dev/null | awk '{if($0 ~ /Machine Check:/){printf($1 " " $2 " " $3);if($4 ~/slot/){printf(" " $4);}printf(": " $(NF -2) " " $(NF -1 ": "));mce=gensub(/(.{8})(.{4})(.*)/, "[\\1][\\2][\\3]","g",$NF);printf(mce);if(mce ~ /\[0008\]/){print(" : Correctable : Action > None")}else{print(" : Non-Correctable : Action > Further analysis required")}}else if($0 ~ "boot_marker"){print($1,$4)}}'

  2. Example output for non-slotted devices:

    2021-07-27T04:27:34+03:00 boot_marker
    Jul 27 06:02:49: Bank 7:[8c000040][0001][0092] : Non-Correctable : Action > Further analysis required
    2021-07-27T06:12:28+03:00 boot_marker
    Jul 27 07:55:46: Bank 11:[8c00004e][0008][00c2] : Correctable : Action > None
    Jul 27 07:55:46: Bank 11:[cc00048e][0008][00c2] : Correctable : Action > None
    Jul 27 12:41:56: Bank 7:[8c000040][0001][0092] : Non-Correctable : Action > Further analysis required

  3.  In the previous output:
    Correctable -  no further action needed
    Non-Correctable - run EUD for further analysis and open F5 support case for investigation
    boot_marker - Boot Marker timestamp. These typically accompany Non-Correctable errors
