Known Issue

Important: This issue only applies to systems that were upgraded to ARX version 5.0.0 and a firmware upgrade was performed. Additionally, the ARX version 5.0.0 software was only available for a short period of time.

This is the result of a known issue. After upgrading to ARX version 5.0.0 and performing a firmware upgrade, the show firmware update verbose command incorrectly indicates that an upgrade is available for the NSM Exp ROM firmware. The show firmware update verbose command output will appear similar to the following example:

Show Firmware Update Verbose
----------------------------

Slot  Firmware     Running         Current         Status          
--------------------------------------------------------------------

1    NSM Boot      5.00.000.11645  5.00.000.11645  Up to date   
1    NSM Diag      5.00.000.11645  5.00.000.11645  Up to date   
1    NSM BootLdr   5.00.000.11645  5.00.000.11645  Up to date   
1    Macau         11              11              Up to date   
1    NSM Exp ROM   5.00.000.11645  5.00.000.11602  Upgrade available

F5 Networks Product Development tracked this issue as ARX ID 34612 and it was fixed in ARX version 5.0.1. For information about upgrading, refer to the ARX Release Notes.
