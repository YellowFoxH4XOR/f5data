Description

When examing traffic statistics on vCMP Host and Guest using AVR you may notice discrepancies. For example, when logged on Guest, AVR statistics for Active Connections is showing about 80k connections. At the same time, when checking statistics for the same Guest but from vCMP Host level, you may notice the value for Average Concurrent Connections showing about twice more (160k connections).

Environment

  • vCMP Host and Guest environment
  • AVR traffic statistics

Cause

The issue was identified as a Bug ID 1084885. At this moment there is no fix or workaround for this issue.

Recommended Actions

You should consider traffic statistics from the Guest level as the correct ones.

None.
