K25620552: UCS load fails with Syntax Error:(/config/bigip_base.conf at line: 1) '''' unexpected argument

Description

UCS archive is failing to load due to a syntax error in /config/bigip_base.conf file. 

Environment

  • After loading UCS file, getting this error message:
    load_config_files[<PID>]: "/usr/bin/tmsh -n -g -a load sys config partitions all base " - failed. -- Syntax Error:(/config/bigip_base.conf at line: 1) "" unexpected argument
    ERROR: UCS installation failed.
    Operation aborted.

  • Loading and verifying the configuration with tmsh load sys config verify results with the same message: 
    Syntax Error:(/config/bigip_base.conf at line: 1) "" unexpected argument

  • The bigip_base.conf file doesn't have any special character.
  • Changing the first line, adding or removing spaces, the unexpected argument message keeps showing up with a different line or argument.

Cause

The bigip_base.conf file is saved as a Windows-style line endings

Recommended Actions

  1. Back up your /config/bigip_base.conf file, type the following command:
cp /config/bigip_base.conf /config/user_alert.conf.v2
  1. Copy the content of the bigip_base.conf file into your clipboard
Note. This can be done with the aid of software such as WinSCP
  1. Remove the bigip_base.conf file from /config
  2. Open Notepad++
  3. Paste the content from bigip_base.conf from step 2
  4. At the menu select View > Show Symbol > Show all Characters
At the end of each line, you'll see CR LF
  1. At the menu select Edit > EOL Conversion > Unix (LF)
The end of each line will be changed to LF only
  1. Save in your local machine as .txt and named bigip_base.conf
  2. Move this file to your BIG-IP at the /config directory
  3. Run the following command to validate the configuration files
tmsh load sys config verify
  1. If the error message is not shown anymore, load the configuration:

    tmsh load sys config
