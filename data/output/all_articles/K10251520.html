Topic

In BIG-IP 14.0.0, the BIG-IP system adds limited support for Transport Layer Security (TLS) 1.3. Starting in BIG-IP 14.1.0.1 and later, this support was updated to provide production level support for TLS 1.3.

Description

TLS 1.3 introduces major changes to the TLS protocol. The new version adds security features and performance enhancements, such as downgrade protection and one round trip time (1-RTT) handshakes. In addition, TLS 1.3 removes obsolete features, such as static RSA handshakes and renegotiation.

Note: You may encounter issues if one side of the SSL connection is using the draft version and the other side is using the TLS 1.3 RFC 8446.

Important: For support of TLS 1.3 on vCMP guests, both the guest and host must be running BIG-IP 14.1.0.1 or later.

Beginning in BIG-IP 21.1.0, TLS 1.3 is enabled by default. Prior to that, TLS 1.3 is disabled by default. To enable TLS 1.3, perform the following procedure:

Impact of procedure: The impact depends on the specific environment. F5 recommends that you test any such changes during a maintenance window.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > SSL > Client or Server.
  3. Select Create or choose an existing profile.
  4. If necessary, for Configuration, select Advanced.
  5. For Ciphers, select the Custom check box.
  6. Select Cipher Group, and then select a group such as f5-default, which is equivalent to the DEFAULT cipher string from the list.
    Note: When TLS 1.3 is enabled, you must configure a cipher group.
  7. For Options, select the Custom check box.
  8. In the Enabled Options list, select No TLSv1.3 and then select Disable.
  9. Configure other properties as needed.
  10. Select Finish or Update.

You can view a list of TLS 1.3 supported ciphers and groups using the following TMOS Shell (tmsh) commands:

Note: For more information about tmsh, refer to K12029: Accessing the TMOS Shell.

  • To view the supported client-side ciphers, use the following command:

    tmsh run util clientssl-ciphers TLSv1_3

  • To view the supported server-side ciphers, use the following command:

    tmsh run util serverssl-ciphers TLSv1_3

Refer to the following sections, by version, to review TLS 1.3 support enhancements:

  • BIG-IP 21.1.x
  • BIG-IP 17.5.x
  • BIG-IP 15.0.0 - 17.1.x
  • BIG-IP 14.1.0.1 - 14.1.2.x
  • BIG-IP 14.0.0 - 14.1.0

BIG-IP 21.1.x

  • Beginning in BIG-IP 21.1.0, TLS 1.3 is enabled by default.
  • Beginning in BIG-IP 21.1.0.1 supports the TLS13_AES_128_CCM and TLS13_AES_128_CCM_8 cipher suites. For more information, refer to Bug ID 2201145.

BIG-IP 17.5.x

  • Beginning BIG-IP 17.5.1.6 for the BIG-IP 17.5.x branch, the BIG-IP system supports the TLS13_AES_128_CCM and TLS13_AES_128_CCM_8 cipher suites. For more information, refer to Bug ID 2201145.

BIG-IP 15.0.0 - 17.1.x

  • The BIG-IP system supports TLS 1.3 Client Certificate Authentication.
  • The BIG-IP system supports TLS 1.3 client side session resumption.
  • The BIG-IP system supports Early data (0-RTT) in the Client SSL profile and is disabled by default.
  • SSL Orchestrator supports TLS 1.3 for inbound SSL/TLS traffic.
  • The following BIG-IP platforms support RSA-PSS padding for FIPS HSMs:
    • i7820-DF (C126)
    • i5820-DF (C125)
    • 10350v-F (D112)

BIG-IP 14.1.0.1 - 14.1.4.x

  • The BIG-IP system supports TLS 1.3 and provides production level support for RFC 8446.
  • The BIG-IP system supports TLS 1.3 for Server and Client SSL profiles.
  • The BIG-IP system supports TLS 1.3 Client Certificate Authentication in 14.1.0.1 and later.
  • The BIG-IP system supports TLS 1.3 client side session resumption (starting in BIG-IP 14.1.0.1).

BIG-IP 14.0.0 - 14.1.0

Important: F5 recommends that you use TLS 1.3 with BIG-IP 14.0.0 through 14.1.0 only for testing purposes.

TLS 1.3 support has the following limitations for BIG-IP 14.0.0 through 14.1.0:

Note: Beginning in BIG-IP 14.0.0, you can enable TLS1.3 in an SSL profile with a prerequisite that you have a cipher group associated with the profile. The cipher group configuration is expanded with cipher rules to include Elliptic Curve Diffie-Hellman key exchange algorithm (DH) groups and signature algorithms as required by TLS 1.3. For more information, refer to K75675154: Error Message: 01b40001:3: A cipher group must be configured when TLS 1.3 is enabled (profile /<partition>/<ssl_profile>)

  • The BIG-IP system supports TLS 1.3 draft 26.
  • The BIG-IP system supports the following ciphers:
    • BIG-IP 14.0.0
      • TLS13-AES128-GCM-SHA256 {0x13, 0x01}
      • TLS13-AES256-GCM-SHA384 {0x13, 0x02}
    • BIG-IP 14.1.0 adds
      • TLS13-CHACHA20-POLY1305-SHA256 {0x13, 0x03}
  • The BIG-IP system has the following SSL profile limitations:
    • In the Client SSL profile, TLS 1.3 is disabled by default and not available for client connections. You can enable TLS 1.3 in the client SSL profile by removing the No TLSv1.3 option in the Enabled Options list; however, you should use TLS 1.3 only for testing and not in a production environment.
    • TLS 1.3 is not currently supported for the Server SSL profile.

      Note: The No TLSv1.3 option appears in the Server SSL profile; however, the feature is not yet enabled for use.

  • There is no support for session resumption.
  • There is no support for client authentication.
