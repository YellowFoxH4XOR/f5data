Description

This solution will explain why LTM Policies will not function on a APM enabled Virtual Server.

  • LTM Policies on a APM enabled Virtual Server do not execute.

Environment

  • LTM Policies, Access Policy, Virtual Server.
  • APM, LTM.

Cause

HTTP_RESPONSE event is executed on the server side where HTTP_RESPONSE_RELEASE is executed on the client side (as well as HTTP_REQUEST). LTM Policies only execute on HTTP_RESPONSE (or HTTP_REQUEST) events.

Recommended Actions

Use iRule(s) on the Virtual Server that use the HTTP_RESPONSE_RELEASE or HTTP_REQUEST_RELEASE events.

Additional Information

HTTP_RESPONSE is typically used to handle HTTP response data within the context of a server response in a load balancing scenario. With APM policy execution, the BIG-IP itself is APM's server and the request/response comes from within BIG-IP itself. Because of this, HTTP_RESPONSE event is not raised and cannot be used.
