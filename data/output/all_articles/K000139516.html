Description

Virtual server created using FAST Template.

Creating a virtual server using FAST template requests you to create a tenant name.  This is a grouping in AS3 declaration and deploys all virtual server configuration in a BIG-IP partition with same name as Tenant

However nodes created in virtual server are in Common partition rather than in a newly created BIG-IP partition.

 

Environment

  • F5 Application Service Templates - FAST
  • Virtual server using FAST template
  • Tenant/Partition

Cause

None. Working as designed.

Recommended Actions

Need to uncheck - 'Shared Node' in Pool Members settings.

 

If  'Shared Node' box is checked, then pool members are created in specified partition and nodes in Common partition. This is because the nodes has to be shared between different partitions.
