K000135211: With F5OS, the tenants have all their VLAN configured with the same MAC addresses

Type
Support Solution
Published
2023-06-24
Updated
2023-06-24
Applies to
  • F5OS
  • F5OS-A: 1.3.X, 1.4.X, 1.5.X, 1.5.0, 1.4.0, 1.3.2, 1.3.1, 1.3.0
Source
https://my.f5.com/manage/s/article/K000135211

Description

While the tenant is not configured to assign a unique MAC address to all VLAN ...

  • System ›› Configuration : Local Traffic : General -> Share Single MAC Address is disabled
  • sys db vlan.macassignment -> configured as "unique"

... it appears all VLAN share the same MAC address

Environment

  • F5OS
  • rSeries

Cause

This may be because the host has allocated a unique MAC to the tenant(s).

Recommended Actions

We'd need to tell the host to extend the size of the pool of MAC address.

This is achievable with updating the parameter "mac-pool-size" for each tenant:

  • Host(config)# tenants tenant tenant1 config mac-data mac-block-size <small|medium|large>
  • Host(config)# commit
