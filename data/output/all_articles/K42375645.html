Description

  • There is a server (pool member) that uses the websocket protocol.
  • If the application connects to the server directly, it works correctly.
  • If the application connects to a Virtual Server hosting that server, it fails.

Environment

  • BIG-IP
  • Virtual Server with HTTP and Websocket profiles applied.

Cause

The HTTP profile changes the Response Chunking.

Recommended Actions

  • For BIG-IP versions prior to 15.0.0, in the HTTP profile set Response Chunking to  "Preserve".
  • For BIG-IP versions 15.0.0 and later, in the HTTP profile set Response Chunking to "Sustain".

Additional Information

The default setting of the "Response Chunking" option in the HTTP profile on F5 BIG-IP depends on the software version:

  • For BIG-IP versions 15.0.0 and later, the default is Sustain.
  • For BIG-IP versions prior to 15.0.0, the default is Selective.
