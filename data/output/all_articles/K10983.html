Known Issue

This is the result of a known issue. Mac OS X users may not be able to connect to Network Access favorites if the Force all traffic through tunnel option has been enabled on the Dynamic Tunnels/Web Application Tunnels tab on the Application Access : App Tunnels : Master Group Settings page, and the Allow local subnet access option has been enabled on the Resources: Client Settings tab on the Network Access page. This issue occurs when the FirePass controller fails to add a default route to the Mac OS X client, or adds a default route incorrectly.

F5 Product Development tracked this issue as CR134093 and it was fixed in FirePass 7.0.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-610-1, which has been issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
