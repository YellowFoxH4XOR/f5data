K11491: The default settings for BIG-IP ASM policies created using the Rapid Deployment security policy template

Type
Knowledge
Published
2011-08-11
Updated
2023-02-21
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP ASM: 9.4.8, 10.0.1, 10.0.0, 9.4.7, 9.4.6, 9.4.5, 9.4.4, 9.4.3, 10.1.0, 9.4.1, 9.4.0, 10.2.2, 10.2.1, 10.2.0, 9.4.2
Source
https://my.f5.com/manage/s/article/K11491

Topic

Web developers responsible for an application hosted behind the BIG-IP ASM system may not have access to the system due to their company network policy. However, it is important that web developers are aware of how the BIG-IP ASM policy is configured, which determines the requests that are blocked and allowed by the BIG-IP ASM system.

Beginning in BIG-IP ASM 10.1.0, security policies can be exported as an XML human-readable file that can then be distributed to web developers. However, this behavior is not possible in BIG-IP ASM versions prior to 10.1.0. As a result, web developers must rely exclusively on published documentation or information received from the BIG-IP administrator to determine how a certain security policy is configured.

F5 recommends creating a security policy using the Rapid Deployment security policy template as the quickest way to start using the BIG-IP ASM system. Therefore, this Solution lists the default settings that the BIG-IP ASM system uses for rapid deployment policies. You can refer this solution to web developers and inform them of whether you have changed any of the default values. Refer to one of the following sections for your version of the BIG-IP ASM system:

  • BIG-IP ASM 10.x
  • BIG-IP ASM 9.4.x

Note: The configurable metacharacters list length will differ depending on the Web Application Language selected. For more information, refer to K11667: The Meta Character list differs depending on the Application Language.
