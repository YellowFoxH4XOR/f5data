Topic

FirePass supports the SNMP coldStart trap message for SNMPv1 and SNMPv2, and the SNMP coldStart inform message for SNMPv3. The object identifier (OID) for this message is 1.3.6.1.6.3.1.1.5.1.

If you configured an SNMP host on the Device Management: Configuration: SNMP page, FirePass sends a coldStart message when the SNMP agent is initialized at system startup.

For more information about configuring the FirePass SNMP Agent, refer to the FirePass Controller Administrator Guide.
