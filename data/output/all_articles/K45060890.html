Topic

You should consider using this procedure under the following condition:

  • You want to determine if the BIG-IP system that you are logged in to is a vCMP guest.

Description

When you perform common administrative tasks as a BIG-IP administrator, you should know whether you are logged in to a BIG-IP vCMP guest or a BIG-IP system that is not running the vCMP module. Performing administrative tasks on vCMP systems may require more planning because you need to know which administrative tasks to perform on the vCMP host system and which tasks to perform on the vCMP guests. For example, you perform license activation perform on the vCMP host, not the guest; each vCMP guest inherits the license of the host.

To determine if the BIG-IP system you are logged in to is a vCMP guest, perform one of the following procedures:

  • Determine if you are logged in to a vCMP guest using the Configuration utility
  • Determine if you are logged in to a vCMP guest using tmsh

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the Configuration utility or TMOS shell (tmsh).

Procedures

Determine if you are logged in to a vCMP guest using the Configuration utility

To determine if you are logged in to a vCMP guest using the Configuration utility, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Device Management > Devices.
  3. Select the name of the local device.

    For example,

    BIG-IP1.internal.local (Self)

  4. For General Properties, review the Platform Name designation.
  5. The following designation represents the BIG-IP vCMP guest platform:

    Platform Name: BIG-IP vCMP Guest

Determine if you are logged in to a vCMP guest using tmsh

To determine if you are logged in to a vCMP guest using tmsh, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh on the vCMP guest you are migrating by entering the following command:

    tmsh

  2. To display the platform name designation, use the following syntax:

    list /cm device <device_name> marketing-name

    For example,

    list /cm device BIG-IP1.internal.local marketing-name

  3. The following designation represents the BIG-IP vCMP guest  platform:

    cm BIG-IP1.internal.local {
        marketing-name "BIG-IP vCMP Guest"
    }
