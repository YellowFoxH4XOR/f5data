Known Issue

The BIG-IP system writes a large Domain Name System (DNS) Message Cache Size value incorrectly to the configuration.

This issue occurs when the following condition is met:

  • You enter a large value in the Message Cache Size box when creating or editing a DNS cache.

When you set the Message Cache Size value of a DNS cache with a value that exceeds than the predetermined limit of 4,294,967,295 bytes, the update process completes without warning. However, the entered value for the Message Cache Size is replaced with a reduced, random number in the configuration. For example, typing a value of 10000000000 in the Message Cache Size box results in a configuration similar to the following:

    ltm dns cache resolver /Common/dnscache_large {
         msg-cache-size 1377017k
         route-domain /Common/0
    }

Impact

The system saves a reduced, random value for the Message Cache Size value in the DNS cache configuration.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The cache-hit percentage is reduced and the cache has a higher eviction rate.
  • The DNS cache configuration does not contain the intended Message Cache Size value.

Workaround

To work around this issue, you can configure the Message Cache Size option with a lower value.
