Known Issue

This is the result of a known issue. The WMI monitor produces skewed results for Dynamic Ratio load balancing on servers with multiple CPUs.

The WMI monitor sums the total load percentage for all CPUs on a server, when it should produce an average load percentage for all of the CPUs. As a result, a server with 8 CPUs can appear to have double the load of a server with 4 CPUs, when they are handling the same load. Additionally, CPU load percentages is reported as greater than 100 percent, causing an incorrect Dynamic Ratio value to be assigned to the server.

F5 Networks Product Development tracked this issue as CR93234, and it was fixed in BIG-IP LTM versions 9.4.5 and 9.6.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue is fixed in HOTFIX-BIG-IP-9.3.1-HF2 issued for BIG-IP version 9.3.1. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
