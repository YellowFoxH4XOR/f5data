Description

Article describes what key types are currently supported in JSON Web Key Set (JWKS).

Environment

  • JSON Web Key Set (JWKS)
  • JWT validation 

Cause

Not all key types ("kty") are currently supported by Distributed Cloud platform.

Recommended Actions

Use key types ("kty") that are supported:

  • RSA
  • oct

 

Unsupported key types ("kty"):

  • EC
  • OKP

Additional Information

 If you try to use unsupported key type (e.g. "kty": "EC"), during LB save you will see an error: "kty not implemented".
