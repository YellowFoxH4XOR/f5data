Description

After installing a new add-on key to replace an expired one, there are issues with the new add-on features not working correctly.

 

Environment

Licensing renewal

 

Cause

The issue can be due to both the old and new add-on keys being present in the license, which is not standard behavior.

The expected behaviour is that when applying a new add-on key, it should remove the old key for you, however this can sometimes fail to happen.

 

 

Recommended Actions

Manually remove the old add-on key first and then apply the new add-on key.

You can then proceed with license re-activation..

None.
