Known Issue

Attempting to remove a peer address from a BIG-IP DNS redundant server object fails.

This issue occurs when all of the following conditions are met:

  • A server object under DNS > GSLB > Servers > Server List with the product type of BIG-IP System (Redundant) is configured with an address in the Peer Address List.
  • You attempt to remove the peer address from the BIG-IP DNS redundant server object using the Configuration utility.

Impact

Configuration utility users cannot remove peer addresses from BIG-IP DNS redundant server objects.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After you highlight the Peer Address List and click Remove, the peer address remains.

Workaround

To work around this issue, you can us the Traffic Management Shell (tmsh) to remove a peer address from a BIG-IP DNS redundant server object. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Remove the peer address from the BIG-IP DNS redundant server object by typing the following command:

    modify /gtm server <server_name> addresses delete {<peer_address_to_be_removed>}

    For Example:

    modify /gtm server example addresses delete {172.16.1.2}

  3. Save the changes by typing the following command:

    save /sys config gtm-only

    Note: By default, the BIG-IP DNS configuration is automatically saved after 15 seconds.
