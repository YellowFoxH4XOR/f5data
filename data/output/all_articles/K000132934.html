Description

The following command examples show you how to use REST commands to generate a self signed certificate and key
And then to import the certificate / key pair for use on BIG-IP
 

Environment

Administrative access through REST API

Prerequisites

You must meet the following prerequisites to use these procedures:
  •     Your BIG-IP system is licensed, provisioned, and configured with a management IP address.
  •     You have administrative access to the BIG-IP LTM Configuration utility.
  •     You have command line access to a Linux system (or an alternate BIG-IP system) with the curl and jq (command line JSON processor) utilities installed.

Cause

none

Recommended Actions

Create new SSL certificate and key using iControl REST
Note: The cert details like organization  are truncated due to a too long error
System will use the default values 
<POST> /mgmt/tm/util/bash -d "{\"command\":\"run\", \"utilCmdArgs\":\"-c 'openssl req -x509 -nodes -days 3650 -newkey rsa:2048 -keyout /config/ssl/ssl.key/<name>.key -out /config/ssl/ssl.crt/<name>.crt -subj /CN=mybigip.local.com/L=Seattle/ST=Washington'\"}"

Import the certificate and key from files already on the system 
<POST> /mgmt/tm/sys/crypto/cert -d '{"command":"install","name":"<name>","from-local-file":"/config/ssl/ssl.crt/<name>.crt"}'
<POST> /mgmt/tm/sys/crypto/key -d '{"command":"install","name":"<name>","from-local-file":"/config/ssl/ssl.key/<name>.key"}'
