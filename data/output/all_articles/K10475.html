Known Issue

This is the result of a known issue. You should be able to change the default SNMP community of public by modifying the monitorCommunity parameter in the /config/wa/pvsystem.conf file. However, changing the monitorCommunity parameter does not change the SNMP community as expected. SNMP queries using the new SNMP community will fail and SNMP queries using the default public community string will continue to succeed.

For example, after changing the monitorCommunity parameter to topsecret, the following SNMP query using the new SNMP community will fail:

snmpwalk -v 2c -c topsecret localhost:12406 .1.3.6.1.4.1.3375.14.1
Timeout: No Response from localhost:12406

However, the following SNMP query using the default public SNMP community will succeed:

snmpwalk -v 2c -c public localhost:12406 .1.3.6.1.4.1.3375.14.1
F5-BIGIP-COMMON-MIB::f5.14.1.1.0 = STRING: "Thu, 27 Aug 2009 07:48:23 GMT"
F5-BIGIP-COMMON-MIB::f5.14.1.2.0 = STRING: "02202009_100627_build16_Release"
F5-BIGIP-COMMON-MIB::f5.14.1.3.0 = ""
F5-BIGIP-COMMON-MIB::f5.14.1.4.0 = ""
F5-BIGIP-COMMON-MIB::f5.14.1.5.0 = STRING: "9.4"
F5-BIGIP-COMMON-MIB::f5.14.1.6.0 = Gauge32: 3

F5 Networks Product Development is tracking this issue as CR113396.

Note: For more information, refer to K8484: The WebAccelerator MIB file is not loaded with other BIG-IP SNMP MIB files.

Note: The BIG-IP WebAccelerator system processes use SNMP ports 12400 and 12406. For information about the SNMP ports used to monitor the BIG-IP WebAccelerator, refer to the Administrator Guide for the BIG-IP WebAccelerator System for version 9.x, or the Configuration Guide for the BIG-IP WebAccelerator System for version 10.x.
