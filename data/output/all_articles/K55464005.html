Description

This article outlines the process to remove or eradicate all Advanced Routing configuration from the BIG-IP system

Environment

  • Advanced Routing configured
  • /config/zebos/*/ZebOS.conf

Cause

  • Advanced routing is configured
  • Advanced routing is not used or required

Recommended Actions

Impact of procedure: The following procedure will remove all Advanced Routing configuration from your BIG-IP system.
Note: As a precaution, ensure that a recently generated UCS archive from this device is gathered and downloaded externally from the device. This can also be useful if you ever want to revert back this configuration.

  1. Remove Advanced Routing protocol configured for all Route Domains:
    Warning: The following will remove all Advanced Routing configuration from all Route Domains.

    find /config/ -xdev -type f -name ZebOS.conf -exec sh -c ">|  {}" \;
bigstart restart tmrouted

  2. Verify only the following config statements are listed via imish:

    #imish
#sh running-config
!
no service password-encryption
!
line con 0
 login
line vty 0 39
 login
!
end
  3. Disable all Dynamic Routing Protocols for each Route Domain.
    1. Navigate to TMUI > Network > Route Domains
    2. Click the desired route domain
    3. Move each Dynamic Routing Protocol from Enabled to Available
    4. Click Update
