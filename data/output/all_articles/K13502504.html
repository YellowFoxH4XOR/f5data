Known Issue

Network access components may fail to install.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM access policy includes the Protected Workspace agent and network access resources.
  • You use a Windows 8 or 8.1 device to establish an access session.
  • You have not installed BIG-IP APM Virtual Private Network (VPN) components on your device.
  • You attempt to launch a network access session from within the Protected Workspace environment.

Impact

The network access session fails to initiate and the necessary components cannot be installed.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When launching the network access session, the network access download of VPN components stops responding.

Workaround

To work around this issue, you can establish a network access session from your device when the Protected Workspace agent is not configured in the access policy. When the session is not in the Protected Workspace environment, the ability to install the necessary components for a network access session cannot initiate completely.

Impact of workaround: Performing the suggested workaround requires your device to launch a network access session outside of the Protected Workspace environment.
