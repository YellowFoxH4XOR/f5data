Known Issue

This is the result of a known issue. Learning suggestions are logged as violations when only the Learning setting is selected for a violation. The BIG-IP ASM sends the Learning events to syslog, which are then logged as violations. This issue occurs when the following two conditions are met:

  • Remote logging is configured and enabled
  • Learning is enabled for a violation, and the Alarm and Blocking options are disabled

The correct behavior when only the Learning setting is enabled for a violation is to add the information to Forensics and to the Learning tables of the system.

F5 Product Development tracked this issue as CR99872 and it was fixed in BIG-IP ASM 9.4.6. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.5-HF2, issued for BIG-IP 9.4.5, for the BIG-IP 9.4.x software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
