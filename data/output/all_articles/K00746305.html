Description

An attempt to deploy AFM config ends with "Task Status: QUEUED" - The deployment can't be cancelled and no more deployments are allowed

  • Unable to push policy changes from BIG-IQ to BIG-IP AFM
  • Deployments are showing the status as "Queued"
  • Error messages

Environment

  • BIG-IQ
  • BIG-IP AFM
  • Deployments of multiple policies

Cause

If you're running several deployment evaluations at the same time (or very near in time) and cancel one of the queued evaluations, the cancelled evaluation will get stuck in 'Cancelling' status.
ID822225

Recommended Actions

At this moment there are 2 possible solution for this issue:

  1. Restart Restjavad on BIG-IQ  
     tmsh restart /sys service restjavad
  2. Upgrade BIG-IQ to 8.1.x version
