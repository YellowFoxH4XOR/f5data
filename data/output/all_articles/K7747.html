Issue

Error Message

err tmm<instance>[<pid>]: 01260008:3: SSL transaction (TPS) rate limit reached

In this error message, note the following:

  • <instance> is the notifying Traffic Management Microkernel (TMM) instance number.
  • <pid> is the process ID of the notifying TMM.

For example:

err tmm3[8133]: 01260008:3: SSL transaction (TPS) rate limit reached

Note: The log message does not indicate the number of transactions per second (TPS) by which the licensed limit is exceeded.

Message Location

You may encounter this message in the following location:

  • /var/log/ltm

Description

This message occurs when the following condition is met:

  • The BIG-IP system is handling a large number of Secure Socket Layer (SSL) connections and the number of SSL TPS connections reaches or exceeds the licensed limit.

Performance Graphs

BIG-IP LTM performance graphs display information that allows you to view current or historical information about the performance of the various BIG-IP system monitors.

The SSL Transactions/Sec performance graph provides a visual representation of the number of SSL transactions the system is handling each second. The calculations shown in the performance graph do not match real-time statistics and you should use them only as a gauge. This behavior is expected and reduces the amount of polling the system performs to collect and display the graph data. As a result, when the SSL TPS limit specified in the license is reached, the information is not reflected on the SSL Transactions/Sec graph.

Impact

The BIG-IP system does not accept new SSL connections until the SSL TPS rate falls below the licensed limit. For more information about SSL TPS enforcement in the BIG-IP system, refer to the following article:

  • K6475: Overview of SSL TPS licensing limits

Recommended Actions

F5 recommends that you monitor traffic volumes to proactively manage the license limit. You can configure the BIG-IP system to send an email message to a specified address or to send SNMP traps whenever the TPS rate limit message is logged. For more information about these configuration options, refer to the following articles:

  • K3727: Configuring custom SNMP traps
  • K3667: Configuring alerts to send email notifications

Note: If your rate TPS rate limit is reached, contact to your F5 account manager or sales partner.
