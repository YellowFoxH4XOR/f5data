Description

  • How to configure machine certificate authentication for use with F5 Machine Tunnel

Environment

  • Windows clients
  • Use case: establish VPN connection before Windows logon to allow domain logon and authenticate clients with their machine certificate

Cause

When using F5 Machine Tunnel the client cannot execute Client endpoint / AV inspectors. This means that the Machine Cert Auth VPE object cannot be used.
Instead use the On-Demand Cert Auth object. While the F5 Machine Tunnel tries to connect Certificate Request packets coming from the BIG-IP/APM are being intercepted by the F5 Machine Tunnel service, which then returns the certificate configured in HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\F5MachineTunnelService\Parameters "ClientCertStoreLocation" and "ClientCertStoreName".
 

Recommended Actions

  1. Install and configure F5 Machine Tunnel as per "Manual Chapter : BIG-IP Edge Client for Windows"
  2. Configure a "On-Demand Cert Auth" object in the Access Policy

Additional Information

You can check the current configuration settings on the client using C:\Windows\SysWOW64\F5MachineTunnelInfo.exe -c
By default the certificate is retrieved from the F5 Machine Tunnel service account store location and store name "F5MachineTunnelService\MY". To retrieve the certificate from the Local Machine change "ClientCertStoreLocation" to "system" and "ClientCertStoreName" to "MY".
