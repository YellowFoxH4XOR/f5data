Known Issue

Session Initiation Protocol (SIP) custom persistence keys may corrupt messages and cause call timeouts.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration includes a virtual server with an associated SIP session profile.
  • The SIP session profile's persistence setting is set to Custom.

    Note: The Custom setting requires a custom key specified in an iRule.

  • The custom key specified in the iRule is not a multiple of three.

Impact

Corrupted SIP messages cause call timeouts.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • SIP calls fail to establish due to connection timeouts.

Workaround

To work around this issue, you can ensure the custom persistence key in the iRule is padded to a multiple of 3 bytes in length.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
