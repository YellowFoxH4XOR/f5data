K000133119: Error message on ltm logs "Unable to send to any Host_CHman address"

Type
Support Solution
Published
2023-03-22
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.5
Source
https://my.f5.com/manage/s/article/K000133119

Description

After upgrading Viprion device the following error messages can be seen on /var/log/ltm:

err bcm56xxd[40321]: 01290003:3: HalmsgTerminalImpl_::sendMessage() Unable to send to any Host_CHman address
warning bcm56xxd[40321]: 012a0004:4: HalOpen: sendMessage failed
err fpdd[40686]: 01290003:3: HalmsgTerminalImpl_::sendMessage() Unable to send to any Host_CHman address
warning fpdd[40686]: 012a0004:4: HalOpen: sendMessage failed
err fpdd[40686]: 00010018:3: Cannot open HAL

Environment

Viprion
Multi blade system
Platform: B4400 Blade (BIG-IP VPR-B4450N) (A114)

Cause

The messages reported by bcm56xxd and fpdd indicates a hardware connection issue on the blade/slot in question during the boot process.

Recommended Actions

Reboot the device. If issue persist then open a case with F5 support to request a replacement of the affected unit.

Additional Information

None
