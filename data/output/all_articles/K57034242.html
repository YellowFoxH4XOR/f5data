Known Issue

Fully-qualified domain name (FQDN) nodes may change state after the system loads the configuration.

This issue occurs when all of the following conditions are met:

  • You create an FQDN node with or without an assigned monitor and save the configuration.
  • You observe that the node state is Available after you create the node.
  • You load the system configuration.

Impact

You can safely ignore this issue; the new node's state is Unknown.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After the system loads the configuration, the newly created FQDN nodes fluctuate from an Available state to an Unknown state.
