Description

When ASM's XML processing engine runs out of memory, you may seeing log entries like this within /var/log/asm:
ASM out of memory error: event code X<###> Exceeded maximum memory assigned for XML/JSON processing

As per K22526837: Error Message: ASM out of memory error: event code X242 Exceeded maximum memory assigned for XML/JSON processing we see this within /var/log/ts/bd.log in such situations:
xml_validation.cpp:0244`Cannot allocate 19393899 more bytes for XML parser. current memory size 471020861 (in bytes)

For example, if you have a device with 32GB, you can check the available system RAM info with this command:
# tmsh show sys memory
Sys::Host Memory (bytes)
  Total    31.3G

By default, the XML processing engine is allocated 300 MB of memory on platforms with less than 16 GB of RAM, 450 MB of memory on platforms with at least 16 GB of RAM but less than 32 GB, and 1 GB on platforms with 32 GB of RAM or more (before 12.0.0, larger systems used the 450 MB default).  For example, for a platform with 32GB RAM, the default XML allocation is expected to be 1GB. However, you always have slightly less available system RAM than what's specified and this article covers the ramification of that when it comes to XML allocation on the device.

Environment

  • ASM module is provisioned
  • Out of memory error
Cause

ASM is ignoring memory reserved by BIOS and kernel when computing default XML allocation. Therefore, since the total memory available will be less than the specified system RAM, that has implications in the amount of memory allocated for XML processing engine. Using the example from previous section, a 32GB device has 31.3GB available system RAM after accounting for memory reserved by BIOS and kernel. Thus, ASM allocates 450MB for XML processing engine rather than 1GB.

F5 Product Development is tracking this as a known issue at ID928997

Recommended Actions

Increase allocation for XML processing engine to a desired value through total_xml_memory or additional_xml_memory_in_mb system variables using the suggestion provided within K10803: Customizing the amount of memory allocated to the BIG-IP ASM XML processing engine
