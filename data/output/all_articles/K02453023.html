K02453023: DoS protection profiles are not being shown in GUI after upgrade

Type
Support Solution
Published
2019-10-14
Updated
2024-11-22
Status
Legacy Content
Applies to

  • BIG-IP ASM: 14.1.2
  • BIG-IP AFM: 14.1.2
Source
https://my.f5.com/manage/s/article/K02453023

Description

BIG-IP AFM or ASM DoS Protection profiles are no longer listed in the GUI (Configuration utility) under Security -> DOS Protection -> Protection Profiles, but are visible via tmsh or elsewhere in the Configuration Utility (such as the Dos Protection Profile options in iApp configuration page).

Environment

  • BIG-IP AFM or ASM
  • DoS Protection Profiles
  • Recent upgrade to 14.1.2.1

Cause

Issue may be caused by Bug ID 802865.

Recommended Actions

Verify Bug ID 802865 from the command line:

  1. The following TMSH command will show the configured dos profiles as expected:
    tmsh list security dos profile
     
  2. The following REST command will return an empty list:
    curl -u admin:admin -k https://localhost/mgmt/tm/security/presentation/tmui/profile-list | jq

If you are able to validate that you are affected by Bug ID 802865, please upgrade to an unaffected software version.
