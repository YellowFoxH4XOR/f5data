Description

During re-import of LTM configuration on BIG-IQ, task fails with the following error message:

Failed to synchronize clustered devices; reason: Worker http://localhost:8100/cm/adc-core/working-config/ltm/virtual failed validation with status 500: java.lang.IllegalArgumentException: /Common/vs must set destination address, or specify a destination address list.

 

Environment

  • BIG-IQ
  • Internal Virtual Server
  • Re-import of LTM config fails

Cause

ID1270253

Internal virtual server configured on BIG-IP does not have a virtual address resulting in an error on BIG-IQ. 

Recommended Actions

The workaround is to configure virtual address 0.0.0.0 on BIG-IP.
 

Steps for import of Internal Virtual Server with Destination Address 

1. Create a Dummy Virtual Server with Type Standard and Destination Address as 0.0.0.0/0 so that a Virtual Address 0.0.0.0 is created (Local Traffic -> Virtual Servers -> Virtual Address List)

2. Update the "Description" in the existing Internal Virtual Server so that the Virtual Address is associated with this object.

3. Discover and Import the LTM Services to have the Internal Virtual Server imported with the destination address 0.0.0.0
