K51010941: Users unable to login with the correct password when using localDB authentication

Type
Support Solution
Published
2022-02-25
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K51010941

Description
Users are unable to login when using the correct password when the authentication method is using local user DB
When the login fails, there use is not offered a 2nd chance to retry, but is is directed instantly to the "Your session could not be established" screen. 

Environment

  • BIG-IP APM
  • Local User DB

Cause
The local user database has become corrupted. The most probable reason is an error while restoring users from a CSV file.
 

Recommended Actions

It will be necessary to clear the local user database. The following procedure will erase all users from the local database and you can restore them using a valid CSV backup. If you do not have a valid CSV backup, then you will need to restore users manually.
 
  1.  Log on to the BIG-IP APM command line.
  2. Stop the local user database manager using the following command:
    tmsh stop sys service localdbmgr
     
  3. Enter the database command line management utility:
    /usr/bin/mysql -uroot -p`perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw` --database=f5authdb
     
  4. Use the following commands to remove the 3 user tables: 
    mysql>  drop table auth_user;
    mysql>  drop table auth_user_data;
    mysql>  drop table auth_user_details;
     
  5. Verify that the tables have been removed:
     
  6. mysql>  show tables;
     
  7. And exit the utility:
    mysql>  quit;
     
  8. Restart the local user database manager:
    tmsh start sys service localdbmgr
     
  9. Reenter the database command line management utility:
    /usr/bin/mysql -uroot -p`perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw` --database=f5authdb
     
  10. check that the user tables have been recreated:
    mysql>  show tables;
     
  11. And exit the utility:
    mysql>  quit;
     
  12. Log on to the Configuration utility.
  13. Go to Access > Authentication > Local User DB > Users.
  14. If you have a valid CSV backup file of the users.
    Click Import from CSV, and choose the CSV to upload.
    Note: If you do not have a CSV file you can created each user by clicking  Create New User  and adding users manually.
