K000157147: 01020056:3: Error computing object status for pool

Type
Support Solution
Published
2025-10-27
Updated
2025-10-27
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000157147

Description

BIG-IPs can not sync, sync fail with error:

Load failed from /Common/bigip1.local 01020056:3: Error computing object status for pool (/Common/test).


Environment

BIG-IP LTM

DSC

Sync fail


Cause

Configuration exist only on the standby and not on the active and you are trying to sync from active to standby


Recommended Actions

Remove the existing pool or objects from the standby and then re-try the sync from active to standby.
