Known Issue

The ARX system will not use the out-of-band (OOB) management network to connect to the F5 license server for an automatic license activation. An in-band (VLAN) management interface is required for an automatic license activation to succeed. If an in-band management IP address and default gateway route are not configured, automatic activation will fail.

This issue occurs when all of the following conditions are met:

  • You perform an automatic license activation.
  • The ARX system is not configured with an in-band management IP address and default gateway route.

Impact

Unable to perform an automatic license activation.

Note: An unlicensed ARX system will not load the configuration and will be non-operational until the license is activated.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Automatic license activation fails with an error message that appears similar to the following example:

    % ERROR: LICENSE_SERVER_DNS_LOOKUP_FAILED (46334047):
    Could not look up IP address for license server 'server1.example.com'.

Workaround

To work around this issue, you can perform a manual license activation or configure in-band (VLAN) management interface. To do so, perform one of the following procedures:

Impact of workaround: Performing the suggested workarounds should not have a negative impact on your system.

Manually activating a license

For information about the manual license activation process, refer to K12800: Overview of ARX licensing.

Configuring in-band management interface

You can configure an in-band management interface for a VLAN using the interface vlan command. For information about the interface vlan command, refer to the ARX CLI Reference Guide.
