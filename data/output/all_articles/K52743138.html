Description

How to determine the number of VPN and Portal Access sessions the BIG-IP APM will allow
Note: The following article describes which APM features use CCU: K13267: BIG-IP APM connectivity license use

Environment

  • CCU (User Connectivity License)
  • VPN
  • Portal Access
Cause

To see how many CCU the BIG-IP APM is licensed to allow, check below in /config/bigip.license file:
Note:  CCU, VPN Users, apm_sessions, and Connectivity Sessions are all terms that essentially mean same thing

# APM Base, VE, 3G, (500 CCU, 10000 Access Sessions) apm_sessions 500 key ABCDEFG-TUVWXYZ
# APM-VE, 2500 VPN Users apm_sessions 2500 key ABCDEFG-TUVWXYZ
#
apm_sessions : 3000   <------- 500 + 2500 = 3000 CCU (VPN / Portal Access / AppTunnel)


The current CCU capacity of the device can be checked by running the following command in the bash mode of your APM device:

tmsh show apm license

For Example:

[root@bigip1:Active:Standalone] config # tmsh show apm license
 total access sessions: 10000        <------------- 10000 Access Sessions
 current active sessions: 0
 current established sessions: 0
 access sessions threshold percent: 75
 total connectivity sessions: 3000   <------------- 3000 CCU (VPN / Portal Access / AppTunnel)
 current connectivity sessions: 0
 connectivity sessions threshold percent: 75

total access sessions : The total licensed access session database entries that can be created on the BIG-IP APM system.
Note: Access session licenses are consumed when a user starts any new session

total connectivity sessions  : The total number of allowed simultaneous access sessions that can be assigned connectivity resources (SSLVPN, Application Tunnel, Portal Access).
Note: User connectivity licenses (VPN/CCUs), are consumed when a user is assigned one or more BIG-IP APM resources with tunnel-type access as with a Network Access VPN session. This number is based on the BIG-IP APM license and platform type.

Refer K15032: Determining license limits of the BIG-IP APM system for more information

Recommended Actions

You can augment the BIG-IP APM Base licensing with Add-on licenses for CCU (SSL-VPN).
If more VPN and Portal Access sessions are needed, contact your F5 Account Manager or Partner to request more.

Additional Information

Alternatively this can be checked using below commands :

CCU (VPN / Portal Access / AppTunnel):
   tmsh show /sys license detail | grep apm_sessions
The command output appears similar to the following example:
   apm_sessions [500]
 
Access Sessions:
   tmsh show /sys license detail | grep apm_access_sessions
The command output appears similar to the following example:
   apm_access_sessions [2500]
