Known Issue

Connections that the system routes using the iRules nexthop command may fail after you modify the BIG-IP routing table.

This issue occurs when all of the following conditions are met:

  • Your configuration includes one or more virtual servers that have an associated iRule using the nexthop command. For example:

    nexthop <vlan> <IP address>

  • The system routes a new client connection using the iRules nexthop command.
  • You modify the BIG-IP routing table by adding, removing, or modifying a route during the lifetime of the client connection.

Impact

Client connections fail because the BIG-IP system chooses an unexpected routing table entry.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Client connections fail after you modify the BIG-IP routing table.
  • The system routes client connections to unexpected destinations.
