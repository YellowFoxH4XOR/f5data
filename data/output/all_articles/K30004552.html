Description

Not able to create iRule code via tmsh, syntax error is received, for example, the following command:

create ltm rule /Common/example_rule { when HTTP_REQUEST { if { [class match [HTTP::uri] contains example_uri] } { pool example_pool } else { pool default_pool }}}

Will produce the following error:

"Syntax Error: Unexpected {"

Environment

  • iRule code
  • TMSH CLI command

Cause

iRule code creation is an interactive procedure, using the GUI or the TMSH CLI

There's not a provision to create iRule code via a single line TMSH command (non-interactive)

Via TMSH what the create command does is to enter the text editor (vim by default for admin user; nano by default for non-admin users) where you can edit and then save the iRule

Even via TMSH creating the iRule is an interactive process, from the documentation:

F5 TMSH REFERENCE - ltm rule 

"Note: When using tmsh, you can only create iRules using the editor, which starts when you use the create or edit commands. You cannot create an iRule directly on the command line. The vim editor applies the autoindent and smartindent options. You can toggle on/off paste mode using the F12 key."

Recommended Actions

  1. Create or Edit the iRule code by entering the following command syntax:

    create ltm rule <iRule path/name>

    For example,

    create ltm rule /Common/example_rule

  2. The text editor vim or nano opens prefilled with:

    create rule example_rule { 
    }

  3. Add the code within the brackets, for example:

    when HTTP_REQUEST { if { [class match [HTTP::uri] contains example_uri] } { pool example_pool } else { pool default_pool }}

  4. Save the changes and exit the text editor:

    For vim, the key sequence: ESC, :, wq will save the irule code directly into the bigip.conf file.
    For nano, the key sequence: Control(^)+X to exit nano; the text editor then prompts you to save the changes before exiting and the tmsh prompts again to save changes.

Additional Information

If you want to change the default text editor to nano for an admin user, you can do so by entering the following command in the tmsh utility:

modify cli preference editor nano

Then save the change by entering the following command:

save sys config
