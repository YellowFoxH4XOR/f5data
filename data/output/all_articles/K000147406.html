K000147406: Does Domain Registrar have to update same Root DNS Server?

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147406

What Happened?

  • I have multiple root servers set to for example ns1.f5xyz.com and ns2.f5xyz.com and want to update it to ns1.f5abc.com. Do I need to go and ask the registrar to update it?

Environment

  • DNS Notify
  • F5® Distributed Cloud DNS
Resolution/Answer 
  • When the Root DNS Server is pointing to the same DNS Server, you can ask the registrar to update the Root DNS Server but it is not mandatory.
  • Nothing will stop working if you do not request the update.
