K000138382: Want to know the serial number of transceivers on a BIGIP

Type
Support Solution
Published
2024-01-28
Updated
2024-01-29
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000138382

Description

You want to see the serial numbers of the installed transceivers on a host.

Environment

BIGIP LTM
Interfaces

Cause

Your desire to know what the serial number of the transceivers on a host are.

Recommended Actions

from the command line run the following command:

tmsh list /net interface all-properties -hidden


example output:
 
net interface 1.2 {
...
serial <serial-number>
...
vendor F5 NETWORKS INC.
vendor-partnum OPT-0016
}

Additional Information

NOTE: on a VE the output will have none for the serial number:

tmsh list /net interface all-properties -hidden

 
net interface 1.2 {
...
serial none
...
vendor none
vendor-oui none
vendor-partnum none
vendor-revision none
}
