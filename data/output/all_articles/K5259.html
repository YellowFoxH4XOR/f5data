Known Issue

This may be the result of a known issue. Beginning in version 4.5, BIG-IP and 3-DNS can use a larger size iQuery message. When BIG-IP or 3-DNS versions 4.5 and later communicate with BIG-IP and 3-DNS 4.2 versions, 3-DNS must create an iQuery message that is compatible with the older version. In some instances, 3-DNS creates an iQuery message that is too long, and it is subsequently rejected by the older version.

When this occurs, 3-DNS will log the following error message to /var/log/3dns file:

<time stamp> <host name> 3dnsd: NOTICE:IQMessageRead: failed in recvfromstream() Socket is not connected:iqm.c:2037

Shortly after this message is logged, the 3dnsd process will crash.

F5 Network Product Development is tracking this issue as CR39967 and CR41926.

Workaround

To work around this issue, copy new versions of the big3d agent to all BIG-IP and 3-DNS systems, by performing the following steps:

  1. Log in to the command line.
  2. Start the 3-DNS maintenance menu, by typing the following command:

    3dnsmaint

  3. Select Install and Start big3d.
  4. Follow the instructions provided.

Once new copies of big3d are installed on all of the BIG-IP and 3-DNS systems that communicate with the affected 3-DNS system, the problem should be resolved.
