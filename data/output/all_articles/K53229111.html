Description

This article explains how to resolve the "Protocol daemon is not running" error when the BGP routing protocol is enabled in the CLI.

The error appears as the following output:

    > enable
    # configure terminal
    (config)# router bgp 100
    % Protocol daemon is not running

Environment

  • BIG-IP LTM.
  • BGP routing protocol.
  • Command-line.
  • Advanced Routing Module (ARM).

Cause

By default, the BGP routing protocol is not enabled in the Configuration utility interface.

Recommended Actions

Important: Make sure that you meet the below prerequisites

  • The BIG-IP system is licensed for the BIG-IP Advanced Routing Module (BIG-IP ARM).
  • You have administrative access to the BIG-IP command line.

Using the Configuration utility to enable BGP routing protocol.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Network > Route Domains.
  3. Click in the route domain for which you want to enable the BGP routing protocol.
  4. In the Dynamic Routing Protocols section, move the BGP protocol to the Enabled box.
  5. Click Update.
