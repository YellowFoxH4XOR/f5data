Description

The Request Queue Depth and Request Queue Timeout of pools are limited to maximum value of 4294967295.
You can configure pool properties between 0 - 4294967295.

If you attempt to set a value that is out of range via GUI, the following error will be shown:
"Value out of range. Correct Range: 0 - 4294967295"

Environment

  • BIG-IP system
  • Configuring the pool
  • TCP Request queuing

Cause

This is by design.

Recommended Actions

On GUI:
Go to Local Traffic  ›  Pools  ›  <Pool-Name>  ›  Request Queue Depth or Request Queue Timeout

On CLI:
tmsh modify ltm pool <Pool-Name> queue-depth-limit <value>
or
tmsh modify ltm pool <Pool-Name> queue-time-limit <value>
