Description

LTM DNS queries fail on the 'LTM to Best Bundle' license despite having unlimited rate limit module enabled.
Log messages similar to the following are logged to /var/log/ltm:
Oct 2 11:01:21 BIG-IP-ASM-1F warning statsd[7583]: 011b090f:4: DNS Services request rate limiter engaged.
Oct 2 11:01:31 BIG-IP-ASM-1F warning statsd[7583]: 011b0910:4: DNS Services request rate limiter disengaged.

Environment

  • DNS-Lite

Cause

This issue is related to the End-Of-Life for 'DNS-Lite' module since 2016. 
For more information refer to: K03503468: End of Life announcement for DNS-Lite on BIG-IP appliances.

Recommended Actions

If you are using DNS-Lite for testing and evaluation, F5 recommends a replacement with a 30-day trial BIG-IP Evaluation License.
For any questions please contact your local F5 Partner Business Manager or Inside Sales Representative.

To determine if your are using DNS-Lite run the following command:

tmsh show sys license all-properties

In the command output locate active module:

Example:
active module : DNS Rate Limit, Unlimited QPS

To confirm that the DNS profile is rejecting request run the following command:

tmsh show /ltm profile dns 
Example:
-------------------------------------------------------
Ltm::DNS Profile: /Common/dns
-------------------------------------------------------
<...>
Licensed Service Rates                DNS        GTM
  Effective Rate Limit (RPS)            0          0               
  Configured Object Count               0          0
  Rate Rejected Requests                1          0
