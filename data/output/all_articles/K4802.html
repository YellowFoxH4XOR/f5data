Topic

This article applies to BIG-IP 9.x. For information about other versions, refer to the following articles:

  • K13369: Performing a first-time configuration from the command line (11.x - 12.x)
  • K10371 - Performing a first-time configuration for BIG-IP from the command line (10.x)

Important: This article contains numerous steps, which must be performed correctly. If you make an error while following the instructions in this article, you may cause issues that are not immediately apparent. F5 recommends that you only use this article when it is not possible to perform a first-time configuration from the Configuration utility.

To perform a first-time configuration from the command line, perform the following two procedures:

  • Licensing the BIG-IP system
  • Completing a basic configuration

Licensing the BIG-IP system

  1. Connect a serial terminal to the console port.
  2. Log in as root with the default password, default.
  3. Create a dossier, using the following command syntax:

    get_dossier -b "<regkey>"

    Replace <regkey> with your registration key.

    Note: The registration key is printed on a paper certificate that was included in the box with the BIG-IP system.

    The dossier is displayed.

  4. Highlight and copy the dossier, starting with the section that begins on the line after the command you issued, and ending just before the next command prompt.
  5. Open a web browser and connect to the following URL:

    http://activate.f5.com
  6. Follow the instructions to submit your dossier.

    Your product license is displayed.
  7. Highlight and copy the entire license.
  8. Return to the BIG-IP command line.
  9. Using a vi text editor, open the /config/bigip.license file by typing the following command:

    vi /config/bigip.license
  10. Enable the vi insert mode by pressing the i key.
  11. Paste the license file that you copied in Step 7.
  12. Press the Esc key to exit vi insert mode.
  13. Save the file and exit vi by typing the following command and pressing Enter:

    :wq
  14. Restart the BIG-IP system services by typing the following command:

    bigstart restart

The BIG-IP system is now licensed.?

Completing a basic configuration

  1. Type the following command from the command line:

    config
  2. When prompted, enter the IP address that you will use to access the BIG-IP management port.
  3. When prompted, enter the netmask for the IP address that you entered in Step 2.
  4. If you want to access the BIG-IP system from the network, enter a management route. Unless you have reason to do otherwise, accept the default setting.
  5. Assign a hostname, using the following command syntax depending on the configuration of your BIG-IP system:
    • For BIG-IP 9.4.2 and later:

      bigpipe system hostname <hostname>

      Replace <hostname> with the fully qualified hostname for the BIG-IP system.

      For example:

      bigpipe system hostname askbig9n1.askf5.com
    • For BIG-IP 9.0.0 through 9.4.1:

      bigpipe db HostName <hostname>

      Replace <hostname> with the fully qualified hostname for the BIG-IP system.

      For example:

      bigpipe db HostName askbig9n1.askf5.com
  6. Type one of the following two commands, depending on the configuration of your BIG-IP system:
    • If the BIG-IP system is a member of a redundant pair, type the following command:

      bigpipe db Failover.IsRedundant true
    • If the BIG-IP system is not a member of a redundant pair, type the following command:

      bigpipe db Failover.IsRedundant false
  7. Set the BIG-IP unit ID, depending on the configuration of your BIG-IP system:
    • If the BIG-IP system that you are configuring is the first unit in a redundant pair, type the following command:

      bigpipe db Failover.UnitID 1
    • If the BIG-IP system that you are configuring is the second unit in a redundant pair, type the following command:

      bigpipe db Failover.UnitID 2
  8. Change directories to the /usr/share/zoneinfo directory by typing the following command:

    cd /usr/share/zoneinfo
  9. List the files in the directory by typing the following command:

    ls

    A number of directories that match geographical regions are displayed.
  10. Find the geographical region in which the BIG-IP system you are configuring is installed.
  11. Change directories to the directory for the geographical region you selected, using the following command syntax:

    cd <directory>

    Replace <directory> with the region you selected in Step 11.

    For example:

    cd America
  12. List the files in the directory by typing the following command:

    ls

    A number of directories that match states and cities are displayed.
  13. Find the closest match to the time zone in which the BIG-IP system you are configuring is installed.
  14. Set the time zone by typing the following command syntax, depending on the configuration of your BIG-IP system:
    • For BIG-IP 9.4.2 and later

      bigpipe ntp timezone <directory>/<timezone>

      Replace <directory> with the region you chose in Step 11 and replace <timezone> with the location that you selected in Step 14.

      For example:

      bigpipe ntp timezone America/Los_Angeles
    • For BIG-IP 9.0.0 through 9.4.1

      bigpipe db NTP.TimeZone <directory>/<timezone>

      Replace <directory> with the region you chose in Step 11 and replace <timezone> with the location that you selected in Step 14.

      For example:

      bigpipe db NTP.TimeZone America/Los_Angeles
  15. Set the root password by typing the following command:

    passwd root
  16. Set the administrative password by typing the following command:

    passwd admin

    If you want to allow F5 Technical Support to log in to your BIG-IP system when you call in for support, set a password for the support account by typing the following command:

    passwd support
  17. In BIG-IP versions 9.0 through 9.4.1, use a text editor to edit the /etc/hosts file.

    Important: If you are running BIG-IP 9.4.2 or later, skip steps 17 through 20. Starting in BIG-IP 9.4.2, the /etc/hosts file is auto-generated and should not be manually edited. The bigpipe system hostname command from Step 5 populates the /etc/hosts file.
  18. Locate the line that appears as follows:

    127.0.0.1 localhost.localdomain localhost

    At the end of the line, add the fully qualified host name that you chose in Step 5.

    For example:

    127.0.0.1 localhost.localdomain localhost askbig9n1.askf5.com
  19. Locate the line that appears as follows:

    127.2.0.2 bigip

    Replace bigip with the fully qualified host name that you chose in Step 5.

    For example:

    127.2.0.2 askbig9n1.askf5.com
  20. Add a new line to the end of the file, using the following format:

    <address> <hostname>

    Replace <address> with the management IP address of the BIG-IP system that you are configuring.

    Replace <hostname> with the fully qualified host name that you selected in Step 5.

    For example:

    172.16.62.2 askbig9n1.askf5.com
  21. Set the db key that indicates that the setup has run by typing the following command:

    bigpipe db Setup.Run false
  22. Type the following command to save the configuration:

    bigpipe save
  23. Restart all BIG-IP services by typing the following command:

    bigstart restart

    Note: If the BIG-IP system is running the BIG-IP ASM module, it may be necessary to manually restart the BIG-IP ASM process by typing the following command:

    bigstart restart asm

You have finished the basic configuration for the BIG-IP system. You can continue configuring the BIG-IP system using the Configuration utility or the command line.
