Description

You may see the following log message in /var/log/ltm

warning diskmonitor[11436]: 011d0002:4: Skipping net:[4026532451]. Stat returned message: /usr/bin/stat: cannot read file system information for net:[4026532451]: No such file or directory Environment

Environment

  • BIG-IP 14.1.x
  • Route Domain

Cause

ID760468

Recommended Actions

You can work around this issue by creating a syslog-ng filter
  1. Log into the TMOS shell (tmsh) by typing the following command:
    tmsh
  2. Edit syslog by typing the following command:
    edit /sys syslog
  3. When syslog configuration opens in the vi text editor, copy and paste the entire entries below:

    modify syslog {
    include "
    # Workaround for ID760468 to remove diskmonitor messages
    filter f_no_audit {
    not message(\"AUDIT|diskmonitor.*Skipping net:\");
    };"
    }
     
  4. Exit the text editor by typing the following key sequence:
    :wq!
  5. Save the configuration by typing the following command:
    save sys config
 

Additional Information

There is no functional impact. The message logged does not indicate functional issues, and can be safely ignored if desired.
