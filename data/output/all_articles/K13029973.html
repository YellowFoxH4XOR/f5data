Description
When you want to have a particular security check, etc. for a specific subnet, you can add IP Subnet Match in the VPE of the Access Policy to have a branch for the specific IP subnet.

Environment

  • BIG-IP APM.
  • Access Policy.
  • Client IP subnet checking

Cause
None

Recommended Actions

  1. On the Configuration Utility, go to Access > Profile / Policies > Access Profiles (Per-Session Policies) > [Access Policy Name] > Edit
  2. Click the + mark where you want to check the client's IP subnet
  3. Go to the Endpoint Security (Server-Side) tab, check IP Subnet Match and click the Add Item button
  4. Click IP Subnet Match and go to the Branch Rules tab
  5. Enter a subnet (e.g., 10.0.0.0/24) you want to have a separate branch on the Access Policy
  6. Click the Finish button and then click the Save button

Additional Information
You can apply additional policy rules in the fallback branch to write actions for non-matching IP subnets.
