Description

The request is blocked due to a validation issue of the content of the request based on the configured JSON content profile schema. The system checks that the incoming request contains JSON data that matches the schema file that is part of a JSON profile configured in the security policy.

Example content:

{
"ferryId": "6923",
"data": {
"caseState": "Open",
"ferryNumber": null,
}
}

The JSON schema used has the following format:

"ferryNumber":{
"format":"int32",
"x-nullable":true,
"type":"integer"
}

Environment

  • JSON schema
  • OpenAPI

Cause

The x-nullable extension is a non-standard feature used in the Swagger 2.0 specification. It is not part of the official OpenAPI specification, but it was used in Swagger 2.0 to indicate that a parameter or property could be null.

Recommended Actions

Modify the schema file and replace "x-nullable" with "nullable". This can be done on the JSON schema file or the swagger file.
