Known Issue

This is the result of a known issue. The configsync daemon (cssd) does not honor the configsync.peeripaddr db key added in BIG-IP 9.4. This db key allows cssd to be performed over a different set of IP addresses, rather than with the connection mirroring configuration using the statemirror.peeripaddr db key.

As a result, cssd overrides the configured configsync.peeripaddr db key, and uses the IP addresses specified in the statemirror.peeripaddr db key.

F5 Product Development tracked this issue as CR87402 and it was fixed in BIG-IP LTM 9.4.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.3-HF4, issued for BIG-IP 9.4.3. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing BIG-IP product hotfixes (9.x).
