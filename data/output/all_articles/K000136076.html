K000136076: Error Message: After upgrade of BIG-IP APM Edge Client to v7.2.4.3 or later, you get a 'Edge Client Configuration Data Corrupted' Message.

Type
Support Solution
Published
2023-09-02
Updated
2023-11-14
Applies to
  • BIG-IP
  • APM Clients
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000136076

Description

  • After upgrading the APM Client to version v7.2.4.3 or later, the edge client launches the auto-upgrade tool, and the 'Edge Client Configuration Data Corrupted' message pops up.
  • The full message is 'Your configuration data appears to be corrupted. Would you like to reset them to their default value?'. You are given a Yes and No option.

 

Environment

  • APM client upgrade to v7.2.4.3 or later
  • client.f5c file
  • Auto-upgrade option in the Edge Client

Cause

Bug 1324053. Edge Client configuration settings defined in client.f5c will be overwritten with the settings defined in config.f5c if the auto-upgrade is enabled.

Recommended Actions

The client's Administrators can define the desired configuration, especially the APM Server list and the DNS List in the connectivity profile before the upgrade so that Edge Client Installer copies the settings to client.f5c file, and the updated configuration is installed on the client computer. For example, if the APM administrator wants the clients to have two servers (test1.server.com, test2.server.com) to be pushed to the client, connectivity profile (GUI: Access  ››  Connectivity / VPN : Connectivity : Profiles -> Select connectivity profile assigned to the virtual server -> Edit Profile -> Win/Mac Edge Client -> Server List):

 

The config.f5c file can usually be found in the below path.

Windows: C:\ProgramData\F5 Networks\Secure Access Client or C:\Program Files (x86)\F5 VPN directory

MacOS: /Library/Application Support/F5Networks directory

 

Once you click on the 'Yes' option, the Corrupted data message should be gone for good. This is a one-time message.

 

NOTE: If you have customized the client.f5c file and you do not add the customized values to the connectivity profile, you will need to manually customize it again after it reverses to the default values.
