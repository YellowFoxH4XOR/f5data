Description

When using curl to get a token from the login provider you receive an error message:

curl: (35) LibreSSL SSL_connect: SSL_ERROR_SYSCALL

 

Example:

curl -k -X POST https://<mgmt_ip_address:<port>/mgmt/shared/authn/login -H "Content-Type: application/json" -d '{

"username":"<username>",

"password":"<password>".

"loginProviderName":"tmos"

}'

curl: (35) LibreSSL SSL_connect: SSL_ERROR_SYSCALL in connection to <ip_address>:<port>

Environment

LibreSSL

FIPS

API

Cause

The BIG-IP device has FIPS enabled. LibreSSL's SSL library is not FIPS complaint.

 

Recommended Actions

Ensure the client being used to make API calls is using OpenSSL.
