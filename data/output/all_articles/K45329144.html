Description

A log message similar to the following appears in /var/log/ltm:

 err iprepd[]: 015c0004:3: query reply parser exception: Schema item license_blob.object_id not found

Environment

  • BIG-IP

Cause

No specific conditions are currently known that would trigger this message.

Recommended Actions

These messages may appear in the logs even if IP Intelligence is not licensed on the BIG-IP. To check if your BIG-IP is licensed for IPI, refer to K13776: Determining the IP intelligence subscription expiration date

As these messages do not indicate a functional issue with the system, they can be safely ignored.

If however, you want to stop these messages from being logged in the LTM logs, and you are not using IP Intelligence on the BIG-IP, you can follow these procedures to disable iprepd:

Note: the below procedure shouldn't have any impact if customer does not use IP Intelligence

1. Manually stop the iprepd daemon

          # bigstart stop iprepd

2.  Once stopped, proceed to disable it

          # bigstart disable iprepd

3. Running bigstart status iprepd command returns the following output :

          iprepd       down, manually disabled


Note: If you need to activate the iprepd service in the future, you could do that with:

          # bigstart enable iprepd
          # bigstart start iprepd

Additional Information

iprepd is the daemon that is responsible for interaction with 3rd parties (Webroot/BrightCloud), to bring IP Intelligence functionality to the BIG-IP system. This daemon connects to the BrightCloud server, downloads the IP reputation database, and shares it with the Data plane of different modules, like LTM, ASM, AFM, etc.
