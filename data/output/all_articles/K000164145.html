K000164145: USB clean install of F5OS 2.0.0 fails on rSeries with 64GB or larger USB flash drive

Type
Support Solution
Published
2026-11-06
Updated
2026-11-06
Applies to
  • F5OS Products
  • F5OS: 2.0.0
Source
https://my.f5.com/manage/s/article/K000164145

Description

A USB clean install of F5OS 2.0.0 fails on rSeries if a USB flash drive that is 64GB or larger is used.

The installer will show a failure similar to the following:

Setting up the installation environment
Setting up com_redhat_kdump addon
Setting up org_fedora_oscap addon
..
Configuring storage
Creating lvmpv on /dev/sda1

An unknown error has occured, look at the /tmp/anaconda-tb* file(s) for more details

The log file in /tmp/anaconda-tb* will show:

Cannot use /dev/sda1: device has a signature

Environment

  • rSeries
  • F5OS 2.0.0
  • Clean install with 64GB or larger USB flash drive

Cause

  • Bug ID 2694009

This is not a hardware issue or defect that requires RMA. It is a software issue.

Recommended Actions

Use a USB flash drive that is 32GB or smaller to perform the clean installation.
