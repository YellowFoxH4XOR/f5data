Known Issue

This is most likely the result of a known issue. If you change the wide IP address to an invalid address, such as a broadcast address, network mask, or an address outside the defined network, 3dsconf.cgi will crash when you load the configuration.

F5 Networks Product Development tracked this issue as CR21176 and CR41887.

Workaround

To work around this issue, edit the wideip.conf file and change the self IP address for the wide IP to a valid address.
