K000153116: BIG-IP APM SAML SLO Does Not Terminate Local APM User Session When Using Custom Logout URI

Type
Support Solution
Published
2025-08-21
Updated
2025-08-21
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000153116

Description

APM SAML Single Logout does not terminate user session on APM side, only on IdP; session remains active and MRH cookie is still served after SLO process.

Environment

SAML SLO

Custom Logout URI

Cause

A custom logout URI does not natively trigger "local" APM session deletion; only specific URIs like /vdesk/hangup.php3 do.

Recommended Actions

Implement LTM policy to redirect custom logout URI requests to /vdesk/hangup.php3, ensuring proper session termination on the local APM side. The same can be accomplished with the below iRule.

when HTTP_REQUEST {
if { ([HTTP::uri] contains "CUSTOMLOGOUTURI") } {
HTTP::respond 302 Location "https://[HTTP::host]/vdesk/hangup.php3"
}
}

Alternatively, configure your application’s logout action to point directly to /vdesk/hangup.php3 if possible.
Ensure that all logout requests are sent to the same VIP that set the MRHSession cookie so APM can correctly identify and delete the user’s session.
