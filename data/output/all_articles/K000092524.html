Description

You observe the ASM triggers the Generic buffer overflow attempt 27 (ID 200011026) violation for legitimate requests such as uploading files.

Environment

  • Uploading files such as PDF, DOCX, JPEG etc.

Cause

The attack signature, Generic buffer overflow attempt 27 (ID 200011026) is applied to the headers, URI, and request body.

This can be seen in the Violation Details; Context:



Recommended Actions

If false positives are preventing legitimate uploads and your environment can allow a security exception, you can disable the attack signature at the URL level (on the upload URL). To do so refer to K8866: Disabling attack signature checks for specific entities.

Additional Information

This attack signature will trigger regardless of parameters created with Upload Data Type (and Attack Signature checked disabled).
