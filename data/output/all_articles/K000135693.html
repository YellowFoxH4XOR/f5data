Environment

Aspen Mesh 1.14.x

Cause

Istio default configuration.

Recommended Actions

Telemetry API can be used to filter the access logs that the istio-proxy sidecar needs to show.
In the following example, Istio-proxy should only collect access logs with code >= 503.

apiVersion: telemetry.istio.io/v1alpha1
kind: Telemetry
metadata:
  name: filter-log
  namespace: default
spec:
  accessLogging:
  - providers:
    - name: envoy
    filter:
     expression: "response.code >= 503"
