K000150487: VMware Site Admin State Stuck in "Provisioning" Due to Misconfigured Syslog Server in F5 Distributed Cloud

Description

Site admin state remains stuck in "Provisioning" during VMware site deployment in F5 Distributed Cloud. Error messages in logs include:

Some k8s objects from app fluentbit are not ready yet, sleeping...

Object from app fluentbit: fluentbit *k8s.DaemonSetObject is in status: Failed, replicas are not in desired state, required replicas: 1, current replicas: 0, updated replicas: 1

[ warn] net]: getaddrinfo(host='sysng1'): System error

Fluent Bit logging component fails to start due to log receiver configuration issues.

Environment

  • F5 Distributed Cloud (SaaS)
  • VMware site deployment
  • Fluent Bit logging component

Cause

Syslog server was configured incorrectly. The syslog server name was not a fully qualified domain name (FQDN) or an IP address reachable from the Customer Edge (CE).

Answer/Recommended Actions

  • Review syslog server configuration under Site Management.
  • Specify the syslog server as a full FQDN or an IP address resolvable and reachable from the CE.
  • Remove or correct the syslog server name if incorrect or unreachable.
  • After correcting the configuration, Fluent Bit should start and the site admin state should progress beyond "Provisioning".

Additional Information

Debug logs showed Fluent Bit failing to resolve the syslog server name. The issue is specific to log receiver configuration.
