K15500154: Warning message: Configured certificates are incompatible with TLS 1.3, so TLS 1.3 will not be negotiated.

Type
Support Solution
Published
2024-01-19
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.0.0, 14.X.X, 14.1.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.0, 14.0.X, 14.0.1
Source
https://my.f5.com/manage/s/article/K15500154

Description
warning mcpd[<PID>] 01071d6b:4: Client SSL profile (/<partition>/<ssl_profile>): Configured certificates are incompatible with TLS 1.3, so TLS 1.3 will not be negotiated.

Environment

  • BIG-IP LTM
  • SSL profile

Cause

  • TLS 1.3 is enabled on the ssl profile referenced in the log message
  • The ssl profile in question uses a RSA key stored in FIPS

Recommended Actions

 Depending on your platform, you may fix this issue by upgrading to version 15.0.0 or above. Please refer to K10251520 for the list of platforms that supports RSA-PSS padding for FIPS in version 15.0.0.             
 If your current platform uses the NGFIPS HSM card , the only option is to disable TLS1.3 on the ssl profile, since this platform does not support TLS 1.3.
