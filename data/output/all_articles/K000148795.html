K000148795: The Tag PLUGIN shows instead of iAPP when installing the telemetry RPM.

Type
Support Solution
Published
2024-12-05
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000148795

Description

When following the CloudDoc to install Telemetry into a Big IP device there is a tag that says PLUGIN. the expected tag was iApps

Environment

  •  BIG-IP LTM
  • Telemetry
  • RPM

Cause

In the new RPM versions, the Tag iAPP was replaced with the PLUGIN. 

Recommended Actions

  1.  Download RPM 
  2. Import to BIG-IP via GUI
  3. You will see on section Tags PLUGIN instead iAPP.
  4. Validate RPM package
