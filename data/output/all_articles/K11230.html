K11230: The Configuration utility fails to save an object type when one of its MIME-types contains a plus sign

Known Issue

This is the result of a known issue. The Configuration utility incorrectly behaves as if the plus sign (+) is an invalid character for MIME-types. As a result, it is not possible to edit an object type using the Configuration utility when one of its MIME-types contains a plus sign. If you attempt to do so, the Configuration utility does not save the object type and displays the following error message:

The field MIME-type cannot contain invalid characters.

F5 Product Development tracked this issue as ID 243390 (formerly CR136562) and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Workaround

You can work around this issue by performing any necessary modifications to the object type from the command line. To do so, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Change directories to the /config/wa directory by typing the following command:

    cd /config/wa
  3. Create a backup of the globalfragment.xml file by typing the following command:

    cp globalfragment.xml globalfragment.xml.orig
  4. Using a text editor, open the globalfragment.xml file.
  5. Search for the object type that you want to modify. For example, if you require modifying the Html object type, you may search for the following entry:

    displayName="Html"

    The entire entry will appear similar to the following example:

    <objType
        type="html"
        group="pages"
        category="common"
        displayName="Html"
        ext="htm, html, jsp, asp, aspx, wml, xhtml"
        mimeType="text/html, text/vnd.wap.wml, text/wml, text/wap,
            application/vnd.wap.wmlc, application/vnd.wap.xhtml+xml,
            application/xhtml+xml"
        compressToClient="policyControlled"
        predefined="true"
    />
  6. Edit the object type as required. For example, you may add or remove file extensions or MIME-types.
  7. Save your changes to the globalfragment.xml file.

    Note: Any changes will take effect immediately.

    Note: If you need to create a new object type that will include a MIME-type containing a plus sign, create the new object type using the Configuration utility and then add the MIME-type in question from the command line using the aforementioned procedure. The Configuration utility will require you to enter at least one extension or one MIME-type for the new object type. At this stage you can enter a dummy MIME-type, for example none/none. If you require help in configuring a new MIME-type from the command line, contact F5 Technical Support.
