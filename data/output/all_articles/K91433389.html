Topic

You should consider using this procedure under the following condition:

  • You want to analyze the traffic distribution across the data plane cores of your BIG-IP system.

Description

The BIG-IP system includes a traffic acceleration feature called Clustered Multiprocessing (CMP). When CMP is enabled, the system creates separate Traffic Management Microkernel (TMM) instances for each CPU, sharing the workload among all CPUs. For more information, refer to K14358: Overview of Clustered Multiprocessing (11.3.0 and later).

There may be times when you want to understand the traffic distribution between the data plane cores and TMM of your BIG-IP system. For example:

  • You want to optimize and configure the number of vCPUs to allocate to your BIG-IP vCMP guests or VELOS tenants.
  • You want to optimize and configure the right CMP Hash setting in the Advanced section of a VLAN configuration.
  • You want to troubleshoot a performance issue in a virtual server.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the BIG-IP Configuration utility and command- line interface (CLI).

Procedures

To fully understand the distribution of traffic across the data plane cores and TMM of your BIG-IP system, you need to analyze a variety of data and statistics. Perform the following procedures to do so:

Impact of procedure: Performing the following procedures should not have a negative impact on your system.

  • Use the tmsh command to display TMM statistics
  • Use the tmctl command to display traffic statistics
  • Analyze the graphs from a QKView file on F5 iHealth
  • Analyze the tmctl statistics from a QKView file on F5 iHealth

    Note: For more information on generating a QKView file and uploading it to F5 iHealth, refer to K12878: Generating diagnostic data using the qkview utility

Use the tmsh command to display TMM statistics

You can use tmsh commands to display a variety of traffic statistics. For example, to display TMM statistics, perform the following procedure:

  1. Log in to the command line.
  2. Enter the following command:

    tmsh show sys tmm-traffic

Use the tmctl command to display traffic statistics

You can use the tmctl command to display a variety of traffic statistics. For example, to display total client connections for each virtual server on the BIG-IP system for a particular TMM, perform the following procedure:

  1. Log in to the command line
  2. Change directory to /var/tmstat/blade by entering the following command:

    cd /var/tmstat/blade

  3. To display total client connections for each virtual server, use the following command syntax:

    tmctl -f <tmm number> virtual_server_stat --select=name,clientside.tot_conns --sortby=name

  4. For example to display the the client connections processed by TMM0, enter the following command:

    tmctl -f tmm0 virtual_server_stat --select=name,clientside.tot_conns --sortby=name

  5. To display the statistics for TMM0 and TMM1, enter the following command:

    paste <(tmctl -f tmm0 virtual_server_stat --select=name,clientside.tot_conns --sortby=name) <(tmctl -f tmm1 virtual_server_stat --select=clientside.tot_conns --sortby=name)

    The following illustrates an example where the second column displays the output for TMM0 and the third column displays the output for TMM1. Traffic is unevenly distributed between the 2 TMMs since the start of the system.

    name                        clientside.tot_conns  clientside.tot_conns
    -------------------------   -------------------   --------------------
    /Common/exampleNA_vs                         219                432620
    /Common/exampleNA_vs_2                    216974                216406

Analyze the graphs from a QKView on F5 iHealth

The graphs from a QKView on iHealth provides historical traffic statistics over a period of time. You can custom set this time to view the amount of detail you need. For example, to view the traffic distribution to each CPU from Graphs, perform the following procedure:

  1. Go to your QKView file on iHealth.
  2. Go to Graphs.
  3. Select the graphs you want to display. For example, select Blade 1 CPU Usage By Core.
  4. Select View Selected.
  5. Select the time range to view the most appropriate amount of detail.

Analyze the tmctl statistics from a QKView on F5 iHealth

Your QKView file can also display historical tmctl statistics. For example, to view the tmctl (TMM) statistics, perform the following procedure:

  1. Go to your QKView on iHealth.
  2. Go to Commands > UNIX > TMOS.
  3. Select tmctl (TMM).
  4. Observe the number of connections handled by each CPU since the start of the system.
