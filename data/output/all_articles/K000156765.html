K000156765: Can BIG-IP Orchestrator profile and Distributed Cloud Bot Defense profile be applied to the same Virtual Server?

Type
Support Solution
Published
2025-10-02
Updated
2025-10-02
Applies to
  • F5 App Protect
  • BIG-IP SSL Orchestrator: 17.5.0
Source
https://my.f5.com/manage/s/article/K000156765

Description

You encounter the following configuration error when attempting to combine a BIG-IP SSL Orchestrator profile with an XC Bot Defense profile from the Distributed Cloud Services tab on the same BIG-IP LTM virtual server:

01b40017:3: Configuration error: Virtual Server (/Common/<VS_name>) with Access Profile of type sslo is not compatible with profile of type (<bd_profile_name>).

Environment

BIG-IP SSLO

Distributed Cloud Bot Defense

Cause

Unsupported configuration. BIG-IP system does not support applying both a BIG-IP SSL Orchestrator profile and a Distributed Bot Defense profile to the same virtual server due to product design limitations. SSL Orchestrator service only inserts AWAF security policies (application security, DoS, and Bot defense) directly within the decrypted service chain.
