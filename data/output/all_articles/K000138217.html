Description

You notice that iAppLX package f5-telemetry-streaming is missing after you upgrade the BIG-IP SW.

 

Environment

f5-telemetry-streaming is installed on the BIG-IP.

You upgraded the BIG-IP SW.

 

Cause

ID 929213

 

Recommended Actions

ID 929213 is fixed in 17.0.0, 16.1.2, 15.1.4.1 and 14.1.4.4 by adding a variable for adjusting the timeout associated with the generation of the UCS configuration file.

Once upgraded, you will need to adjust this new variable, iapplxrpm.timeout and restart restjavad to avoid the issue in the future.

 

# tmsh modify sys db iapplxrpm.timeout value 300

# tmsh restart sys service restjavad

 

Impact of action: Increasing the db key and restarting restjavad should not be traffic impacting.
