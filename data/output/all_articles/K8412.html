Topic

The Real Time Streaming Protocol (RTSP), defined in RFC2326, is an application-level protocol used by streaming media systems. RTSP allows a client system to remotely control content on the streaming media server.

If your BIG-IP system load balances RTSP traffic, you may need to create a health monitor on the BIG-IP LTM system to monitor your RTSP servers. If your RTSP server is configured to use TCP as the transport protocol, a TCP health monitor can be created by using the TCP Extended Content Verification (ECV) to send RTSP methods such as DESCRIBE or OPTION to the server.

Creating an RTSP health monitor for TCP

To create an RTSP health monitor for TCP, perform the following two procedures:

  • Constructing a request to your RTSP server
  • Defining the health monitor on the BIG-IP system

Constructing a request to your RTSP server

When you construct a request to the RTSP server, the request and server response can then be used in the TCP monitor. To construct and test a request that your RTSP server understands, you can use the telnet utility. For example, you can use the telnet utility to test a request to your RTSP server using the OPTIONS or DESCRIBE RTSP methods.

To use the telnet utility to test a request to your RTSP server, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Use the telnet command to open a connection to the RTSP server by typing the following command:

    telnet <RTSP_server> 554

  3. At the prompt, type the following string:

    OPTIONS / RTSP/1.0\r\n\r\n

    Note: You can also use the DESCRIBE method, which retrieves a description of the media object identified by the request URL. For example, the following string retrieves a description of the Sample_Broadcast media file from the RTSP server:

    DESCRIBE /Sample_Broadcast RTSP/1.0\r\n\r\n

  4. Press the Enter key twice.

    You should receive a response from the RTSP server that appears similar to the following example:

    RTSP/1.0 200 OK

  5. Exit the telnet prompt.

Defining the health monitor on the BIG-IP system

After you have constructed and tested a request to your RTSP server, you can define the TCP monitor on the BIG-IP system. To define the TCP monitor, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Monitors.
  3. Click Create.
  4. Type a name for the monitor.
  5. From the Type menu, select TCP.
  6. In the Send String field enter the following string:

    OPTIONS / RTSP/1.0\r\n\r\n

    Note: If you want to check a specific resource on the RTSP server, you can also use the DESCRIBE method as in the following example:

    DESCRIBE /<rtsp_object> RTSP/1.0\r\n\r\n

  7. In the Receive String field, enter the following string:

    RTSP/1.0 200 OK

  8. Click Finished.
  9. Associate the monitor with the RTSP pool.
