K000138798: AOM SSH user creation error "Unable to set AOM ssh username and password"

Type
Support Solution
Published
2024-03-03
Updated
2025-05-27
Applies to
  • F5OS
  • F5OS-A: 1.7.X, 1.7.0
Source
https://my.f5.com/manage/s/article/K000138798

Description

When creating AOM SSH users, you may encounter the following error:
appliance-1(config)# system aom set-ssh-user-info username <USERNAME>
Value for 'password' (<string>): *******
Error: Unable to set AOM ssh username and password

Environment

  • F5OS-A 1.7.0 onwards
  • New AOM SSH user creation
  • r2x00
  • r4x00

Cause

ID 1394905

Recommended Actions

Ensure that the password configured for the new AOM SSH user account does not match the password of any existing user account in F5OS.

You may also wish to reset the AOM SSH user configuration to default by running the following command in system management CLI:
appliance-1(config)# system aom clear-data

Additional Information

None
