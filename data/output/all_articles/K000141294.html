Description

There are issues with establishing iQuery connection.

  • The gtm_add command fails with the following error:

IQuery connection to 10.0.0.1 failed.
Is big3d running?
Is tcp port 4353 access allowed?

  • The iqdump command shows: 

SSL return code: SSL_ERROR_SYSCALL.

  • After collecting packet captures on both BIG-IP devices, you can see that Client Hello is sent by one device, but never reaches its destitation.
  • In /var/log/gtm on both devices there are logs similar to:

011ae114:3: iqmgmt_ssl_connect: SSL error: Connection reset by peer (104) from connection 10.0.0.2
011ae0fa:3: iqmgmt_ssl_connect: SSL error: SSL connect (5)

Environment

  • BIG-IP DNS
  • DNS Sync Group

Cause

There is a firewall between BIG-IP devices that is allowing TCP 4353 at layer 3, but is denying layer 7 connection on same port.

Recommended Actions

Allow port 4353 for TLS traffic on all devices between BIG-IPs.
