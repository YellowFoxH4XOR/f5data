Topic

You should consider using these procedures under the following condition:

  • You want to display or configure the management IP address for your BIG-IP system.

Important: This article does not apply to F5OS platforms such as VELOS or rSeries. You cannot set the management IP address with the LCD screen on a VELOS system. For information on VELOS, refer to the platform administration guide for your system.

Prerequisites

You must meet at least one of the following prerequisites to use these procedures:

  • You have administrative privileges in the Configuration utility.
  • You have command line access to your BIG-IP system.
  • You have physical access to the LCD panel on your BIG-IP system.
  • You are not using an F5OS system such as VELOS or rSeries.

Description

The management port on a BIG-IP system provides administrative access to the system out-of-band of the application traffic, which enables you to restrict administrative access to an internal secure network. You can display and configure the management IP address for the BIG-IP system using the Configuration utility, the command line, and the LCD panel.

Note: In versions prior to BIG-IP 11.2.0, you must assign an IPv4 address to the management port. In BIG-IP 11.2.0 through BIG-IP 13.x, you can assign either an IPv4 or IPv6 address to the management port, but you cannot assign both IPv4 and IPv6 addresses. Beginning in BIG-IP 14.0.0, you can assign both IPv4 and IPv6 addresses to the management port. For more information. refer to K12430: IPv4 and IPv6 dual-stack support for the management interface.

Note: Chassis platforms can use separate management IP addresses for the cluster and for each blade. For more information about configuring management IP addresses on chassis platforms, refer to K15690: Changing the cluster IP or cluster member IP addresses for VIPRION platforms.

Procedures

  • Displaying the management IP address using the Configuration utility, command line, iControl REST interface or LCD panel
  • Configuring the management IP address using the Configuration utility, command line, iControl REST interface or LCD panel

Displaying the management IP address using the Configuration utility, command line, or LCD panel

You can display the currently-configured management IP address if you have administrative access or physical access to the BIG-IP system. To do so, perform one of the following procedures.

To watch a video demo of this procedure, go to  Displaying the management IP address using the Configuration utility or command line.

Impact of procedure: Performing the following procedures should not have a negative impact on your system.

Displaying the management IP address using the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to System > Platform.
  3. In BIG-IP 15.0.0 and later, you can view the configured IPv4 and/or IPv6 management IP address(es), network mask(s), and management route(s) in the IPV4 Config Details and/or IPV6 Config Details settings. In BIG-IP 14.x, you can view the configured IPv4 and/or IPv6 management IP address(es), network mask(s), and management route(s) in the Management Port 1 and/or Management Port 2 settings. In versions prior to BIG-IP 14.0.0, you can view the configured management IP address, network mask, and management route in the Management Port setting.

Displaying the management IP address using tmsh 

  1. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  2. To display the configured management IP address, enter the following command:

    list /sys management-ip

    The output appears similar to the following example:

    sys management-ip 192.168.1.245/24 {
    description configured-statically
    }

  3. To display the management route, enter the following command:

    list /sys management-route

    The output appears similar to the following example:

    sys management-route default {
    description configured-statically
    gateway 192.168.1.254
    network default
    }
     

Displaying the management IP address using the iControl REST interface

  1. Use the following iControl REST interface syntax to view the configured management ip address of the BIG-IP device:

    curl -sk -u <username>:<password> -H "Content-Type: application/json" -X GET https://<big-ip ip address>/mgmt/tm/sys/management-ip  | jq -M .

    Note: Replace <username>:<password> with the administrative username and password for your BIG-IP device, and replace  <big-ip ip address> with the IP address of your BIG-IP device.

    Note: Viewing objects with a REST command can produce verbose JSON output. To format the JSON output to a more user-friendly format, use the jq command line JSON processor command. The jq command -M flag sets the formatted JSON output to use monochrome when displaying the JSON output. The '.' (period) parameter is optional in jq versions 1.5 and later.

  2. To display the management route, use the following iControl REST interface syntax:

    curl -sk -u <username>:<password> -H "Content-Type: application/json" -X GET https://<big-ip ip address>/mgmt/tm/sys/management-route  | jq -M .

    Note: Replace <username>:<password> with the administrative username and password for your BIG-IP device, and replace  <big-ip ip address> with the IP address of your BIG-IP device.

Displaying the management IP address using the LCD panel

  1. To activate Menu mode for the LCD, press X.
  2. Use the arrow keys to select System, and press Check.
  3. To select Management, press Check.
  4. Use the arrow keys to select Mgmt IP, Mgmt Mask, or Mgmt Gateway, and press Check to display the item.

Displaying the management IP address using the LCD panel (iSeries platforms)

  1. Touch the screen to activate Menu mode for the LCD.
  2. Tap Setup.
  3. Tap Management.
  4. Tap IP Address to view the management IP address.
  5. Tap Back when finished.
  6. Scroll down and tap Gateway to view the management route.
  7. Tap Back when finished.

Configuring the management IP address using the Configuration utility, command line, or LCD panel

You can configure the management IP address using the Configuration utility, tmsh, the config command, or the LCD panel. To do so, perform one of the following procedures.

To watch a video demo of this procedure, go to Configuring the management IP address using the Configuration utility or command line.

Impact of procedure: When you are connected through the management port, changing the management IP address disconnects you from the BIG-IP system. If you are changing the management IP address after the initial deployment of the BIG-IP system, refer to the impacts noted in the section covering this topic in K7312: Overview of the management interface (port).

Configuring the management IP address using the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to System > Platform.
  3. Perform one of the following steps for your BIG-IP version:
    • BIG-IP 15.0.0 and later

      For IPV4 Config Details, configure IPv4 address, Network Mask, and Management Route.

      If there is an existing IP address in the IPV4 Config Details setting and you want to configure an alternate management IPv6 address, for IPV6 Config Details, configure IP address, Network Mask, and Management Route.

    • BIG-IP 14.x

      For Management Port 1, configure IP address, Network Mask, and Management Route.

      If there is an existing IP address in the Management Port 1 setting and you want to configure an alternate management IP address, for Management Port 2, configure IP address, Network Mask, and Management Route.

      If the existing IP address for Management Port 1 is an IPv4 address, you can only configure an IPv6 address for Management Port 2.

      If the existing IP address for Management Port 1 is an IPv6 address, you can only configure an IPv4 address for Management Port 2.

    • BIG-IP 13.x and earlier

      For Management Port, configure IP Address, Network Mask, and Management Route.

  4. Select Update.

Configuring the management IP address using tmsh (IPv4)

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To configure the management IP address, use the following syntax:

    create /sys management-ip [ip address/netmask]

    or

    create /sys management-ip [ip address/prefixlen]

    For example:

    create /sys management-ip 192.168.1.245/255.255.255.0

    or

    create /sys management-ip 192.168.1.245/24

  3. To configure a default management gateway, use the following syntax:

    create /sys management-route default gateway <gateway ip address>

    For example:

    create /sys management-route default gateway 192.168.1.254

  4. Save the changes by entering the following command:

    save /sys config partitions all

Configuring the management IP address using tmsh(IPv6)

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To configure the management IP address, use the following syntax:

    create /sys management-ip [ip address/netmask]

    or

    create /sys management-ip [ip address/prefixlen]

    For example:

    create /sys management-ip 2001:db8::2/FFFF:FFFF:FFFF:FFFF:0000:0000:0000:0000

    or

    create /sys management-ip 2001:db8::2/64

  3. To configure a default management gateway, use the following syntax:

    create /sys management-route default-inet6 gateway <gateway ip address>

    For example:

    create /sys management-route default-inet6 gateway 2001:db8::1

  4. Save the changes by entering the following command:

    save /sys config partitions all

Configuring the management IP address using the config command

  1. Log in to the command line of the BIG-IP system.
  2. Enter the F5 Management Port Setup Utility by entering the following command:

    config

  3. To configure the management port, enter the appropriate IP address, netmask, and management route in the screens that follow.

Configuring the management IP address using the iControl REST interface

Use the following iControl REST interface syntax to configure the management IP address of the BIG-IP device:

curl -sk -u <username>:<password> -H "Content-Type: application/json" -X POST https://<big-ip ip address>/mgmt/tm/sys/management-ip -d '{"name":"<ip address>/<netmask>"}' 

Note: Replace <username>:<password> with the administrative username and password for your BIG-IP device, and replace  <big-ip ip address> with the IP address of your BIG-IP device.

Replace <ip address> with the BIG-IP management IP address, and <netmask> with the network mask of the management network.

Configuring the management IP address using the LCD panel

  1. To activate Menu mode for the LCD, press the X button.
  2. Use the arrow keys to select System, and press Check.
  3. To select Management, press Check.
  4. To select Mgmt IP, press Check.
  5. Enter your management IP address using the arrow keys, and press Check.
  6. Use the arrow keys to select Mgmt Mask, and press Check.
  7. Enter the netmask using the arrow keys, and press Check.
  8. Use the arrow keys to select Mgmt Gateway, and press Check.
  9. Enter your default route using the arrow keys, and press Check.

    If you do not have a default route, enter 0.0.0.0.

  10. Use the arrow keys to select Commit, and press Check.
  11. To select OK, press Check.

Configuring the management IP address using the LCD panel (iSeries platforms)

  1. Touch the screen to activate Menu mode for the LCD.
  2. Tap Setup.
  3. Tap Management.
  4. For the Type setting, tap to select IPv4 or IPv6.
  5. Tap IP Address.
  6. Use the arrows on the screen to configure the management IP address and the prefix length.
  7. Tap Commit to save your changes.
  8. Scroll down and tap Gateway.
  9. Use the arrows on the screen to configure the default management route.

    If you do not have a default route, enter 0.0.0.0.

  10. Tap Commit to save your changes.
