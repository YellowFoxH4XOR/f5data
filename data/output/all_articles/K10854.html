Known Issue

This is the result of a known issue. When viewing the Chassis Summary page of the ARX Manager Configuration utility, the first two characters of the serial number are not displayed.

Note: The ability to view the serial number using the ARX Manager Configuration utility was introduced in ARX version 4.0.1.

F5 Product Development tracked this issue as ID 35738 and it was fixed in ARX version 5.1.0. For information about upgrading, refer to the ARX release notes.

Workaround

You can see the complete ARX serial number from the ARX CLI by using the show chassis chassinfo command. For information about the show chassis chassinfo command, refer to the ARX CLI Reference Guide.

Note: For information about finding the ARX serial number, refer to K8239: Finding the serial number for your ARX system
