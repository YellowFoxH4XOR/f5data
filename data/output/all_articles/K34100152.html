Topic

F5 modifies the base host operating system and responds to all reported vulnerabilities for that base operating system. You must install only the patches that F5 supplies. For more information about the latest available versions of F5OS software and patch releases, refer to the following articles:

  • K2200: Most recent versions of F5 software
  • K21501912:  Software lifecycle policy for F5OS

Description

F5OS software provides the operating system for F5 platforms that use a microservices platform layer. All F5OS software versions run a base operating system. In some versions, F5OS software uses components from multiple CentOS versions. The F5OS custom Linux kernels are built based on 64-bit kernels only. Base host operating system support lifecycle

F5 provides support for the base host operating system integrated into F5OS software. It includes responses to updates, bug fixes, and vulnerability resolutions for the base operating system through F5OS releases.

The F5 support lifecycle for the base host operating system is directly aligned with each F5OS release with which the base host operating system is integrated. In the case that the base host operating system reaches its end of support or end of life before its F5OS counterpart, F5 will continue to offer support for the base host operating system under the corresponding F5OS release support lifecycle.
