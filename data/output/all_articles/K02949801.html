Description

  • ASM policy cannot be applied to a Performance (Layer 4) virtual server.
  • In GUI:
Could not update policy due to ASMConfig exception: [603] MCP Validation error - 01070095:3: Virtual server <virtual_server_name> lists incompatible 
  • In /var/log/ltm :  
    01070095:3: Virtual server /Common/<virtual_server_name> lists incompatible profiles

Environment

  • BIG-IP ASM
  • Performance (Layer 4) virtual server with HTTP profile
  • 11.3.0 onwards

Cause

You can't assign ASM policy to a performance (Layer 4) virtual server. Since 13.1.0, you can assign ASM policy to a performance (Layer 4) virtual server with http profile, but only in transparent mode for passive monitoring. Please refer to this link in details: Manual Chapter: Working with Passive Monitoring

Recommended Actions

Use a standard virtual server to apply ASM policy.

Additional Information

For more information, please refer to the Manual Working with Passive Monitoring.
