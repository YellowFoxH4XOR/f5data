K5041: The Configuration utility only allows IP addresses that end in .255 to be used as broadcast addresses

Known Issue

This is the result of a known issue. The Configuration utility treats all networks as if they are class C (/24). In a class C network, the IP address that ends in .255 is the default broadcast address. As a result, 3-DNS will not allow you to enter a host IP address that ends in .255.

If your network is larger than a class C, there are multiple addresses that end in .255. The Configuration utility will not allow you to use any of these addresses for a host.

F5 Networks Product Development tracked this issue as CR34737 and CR42101.

Workaround

To work around this issue, you can enter hosts with IP addresses that end in .255 in the wideip.con file. 3-DNS will allow you to use these hosts, but the Configuration utility will not display them.
