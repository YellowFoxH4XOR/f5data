K000147834: How to download LBs configuration from XC portal

Type
Support Solution
Published
2024-11-08
Updated
2025-02-23
Applies to

  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147834

Description

  • You require a report or list of your load balancers (LBs) along with the associated configurations.

Environment

  • F5® Distributed Cloud
  • WAF Managed Service
  • DDoS Managed Service

 

Answer/Recommended Actions

1- Navigate to Web App & API Protection > Performance Dashboard.

2- Select the Namespace

3- Scroll down to the Add HTTP Load Balancer section.

 

4- Click on the gear icon, then select all the desired configuration objects.

5- Click the Download CSV button to download the report.
