K000134891: Packet Analysis Emulator TLS bad certificate

Type
Support Solution
Published
2023-06-01
Updated
2023-07-18
Applies to
  • Aspen Mesh: 1.X.X, 1.14, 1.11
Source
https://my.f5.com/manage/s/article/K000134891

Description

Packet analysis emulator logs shows the following error after Citadel renews the certificate.

INFO: 2023/06/01 02:38:34 http: TLS handshake error from 10.244.1.3:42642: remote error: tls: bad certificate


Environment

Aspen Mesh 1.x.x, Citadel, Packet Inspector
 

Cause

Packet analysis emulator does not rotate the certificates after Citadel renews the certificate.
 

Recommended Actions

Bounce the packet analysis emulator pod to force it to start using the certificate that was renewed by Citadel. For example:

kubectl delete pod -n analysis-emulator packet-inspector-1-analysis-emulator-c6bfccdf4-lvlk6


Additional Information

The Aspen Mesh analysis emulator is intended to be used in non-production environments to demonstrate or test Packet Inspector. A third-party network analysis tool, such as Gigamon, should be used in production environments to analyze captured data.
