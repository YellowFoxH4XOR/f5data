Description

Use this article when you want to manage your account, contact, or asset groups. For information about how to use account, contact, and asset groups and required user roles, refer to K000139988: About account, contact, and asset groups.

Prerequisites

F5 creates account groups and assigns the Asset Manager user role for account groups. Asset Managers manage account, contact, and asset groups. For more information, contact your Service Delivery Manager (SDM) or F5 Support. For information about MyF5 user roles, refer to K000136095: About MyF5 account user roles and permissions.

You must have an account group and the Asset Manager role for the account group to use the procedures in this article, except for the following procedure:

  • View the cases in your contact groups

To view the cases in your contact group, you must have the Case Manager role.

Procedures

Manage account groups

View your account groups

You must have an account group and the Asset Manager role for the account group to use this procedure.

  1. Go to MyF5.
  2. In the upper right, select Profile (person icon), and then select Account Management.

    Note: The Account Management option displays only when you have the Asset Manager role for an account group.

  3. To search for a specific account group, in the search box, enter the account group name, and then select Search (magnifying glass icon).
  4. Select the account group you want to view.

    The account group details page displays and has the following sections:

    • Associated Accounts—Accounts within the account group.
    • Asset Managers—Individuals with the Asset Manager role for the account group.
    • Asset Groups—Asset groups groups created by an Asset Manager for the account group.
    • Contact Groups—Contact groups created by an Asset Manager for the account group.

Manage contact groups

View your contact groups

You must have an account group and the Asset Manager role for the account group to use this procedure.

  1. Go to MyF5.
  2. In the upper right, select Profile (person icon), and then select Account Management.

    Note: The Account Management option displays only when you have the Asset Manager role for an account group.

  3. To search for a specific account group, in the search box, enter the account group name, and then select Search (magnifying glass icon).
  4. Select the account group that contains the contact group you want to view.
  5. Under Contact Groups, select the contact group you want to view.

    The contact group details page displays and has the following sections:

    • Contact Group Users—Users who are members of the contact group.
    • Available Users—Users you can add to a contact group. This list is comprised of users who are users on all of the the accounts in the account group. 

Create or delete a contact group

You must have an account group and the Asset Manager role for the account group to use this procedure.

After you create a contact group, you must add users to it.

  1. Go to MyF5.
  2. In the upper right, select Profile (person icon), and then select Account Management.

    Note: The Account Management option displays only when you have the Asset Manager role for an account group.

  3. To search for a specific account group, in the search box, enter the account group name, and then select Search (magnifying glass icon).
  4. Select the account group that you want to add or delete a contact group from.
  5. Do one of the following:
    • To delete a contact group, complete only step 6.
    • To add a contact group, skip to step 7.
  6. To delete a contact group, under Contact Groups, next to the group you want to delete, select the check box, and the select Delete Contact Group.
  7. To add a contact group, under Contact Groups, select Create Contact Group.
  8. In Contact Group Name, enter a name for the contact group.

    Note: You must use a contact group name that is unique to this account group.

  9. In Description, enter a description of the contact group.
  10. Select Save.

    Under Contact Groups, the group you added displays in the list.

Add or remove users from a contact group

You must have an account group and the Asset Manager role for the account group to use this procedure.

You can add to contact groups only those users who are users on all of the the accounts in the account group. When a user is not on all of the accounts in the account group, they do not appear in the list of users that you can add to a contact group.

  1. Go to MyF5.
  2. In the upper right, select Profile (person icon), and then select Account Management.

    Note: The Account Management option displays only when you have the Asset Manager role for an account group.

  3. To search for a specific account group, in the search box, enter the account group name, and then select Search (magnifying glass icon).
  4. Select the account group that contains the contact group you want to add or remove user from.
  5. Under Contact Groups, select the contact group you want to add or remove users from.
  6. Do one of the following:
    • To remove users from a contact group, complete only step 7.
    • To add users to a contact group, skip to step 8.
  7. To remove users from a contact group, under Contact Group Users, next to the names of the users you want to remove from the group, select the check boxes, and then select Remove from Contact Group.

    The users you selected no longer display under Contact Group Users and now display under Available Users.

  8. To add users to a contact group, under Available Users, next to the names of the users you want to add to the group, select the check boxes, and then select Add to Contact Group.

    Note: Under Available Users, only users who are users on all the accounts in the account group display.

    The users you selected display under Contact Group Users and no longer display under Available Users.

Assign or unassign the Case Manager role in a contact group

You must have an account group and the Asset Manager role for the account group to use this procedure.

  1. Go to MyF5.
  2. In the upper right, select Profile (person icon), and then select Account Management.

    Note: The Account Management option displays only when you have the Asset Manager role for an account group.

  3. To search for a specific account group, in the search box, enter the account group name, and then select Search (magnifying glass icon).
  4. Select the account group that contains the contact group you want to assign or unassign a Case Manager from.
  5. Under Contact Groups, select the contact group you want to assign or unassign a Case Manager from.
  6. Do one of the following:
    • To remove a Case Manager from a contact group, complete only step 7.
    • To assign a Case Manager to a contact group, skip to step 8.
  7. To remove a Case Manager from a contact group, under Contact Group Users, next to the name of the user you want to remove the role from, select the check box, and then select Unassign as Case Manager.

    In the user's row, in the Role column, Case Manager no longer displays.

  8. To assign a case manager to a contact group, under Contact Group Users, next to the name of the user you want to assign the role to, select the check box, and then select Assign as Case Manager.

    In the user's row, in the Role column, Case Manager now displays.

View the cases in your contact groups

You must have the Case Manager role for one or more contact groups to use this procedure.

  1. Go to MyF5.
  2. Go to Support > Case Management.

For more information about the cases displayed on the Case Management page, refer to About the Case Management page in K000090256: View or edit your support cases on MyF5.

Manage asset groups

View your asset groups

You must have an account group and the Asset Manager role for the account group to use this procedure.

  1. Go to MyF5.
  2. In the upper right, select Profile (person icon), and then select Account Management.

    Note: The Account Management option displays only when you have the Asset Manager role for an account group.

  3. To search for a specific account group, in the search box, enter the account group name, and then select Search (magnifying glass icon).
  4. Select the account group that contains the asset group you want to view.
  5. Under Asset Groups, select the asset group you want to view.

    The asset group details page displays and has the following sections:

    • Perpetual Assets—F5 hardware and software that you own outright are perpetual assets, as opposed to subscriptions, which enable you to use assets for a period of time. This list is comprised of perpetual assets that have active entitlement and belong to at least one account in the account group.
    • Subscriptions—Subscriptions that you added to the asset group.
    • Available Subscriptions—Subscriptions you can add to the asset group. This list is comprised of subscriptions that have an Active status and belong to at least one account in the account group.
    • Assigned Contact Groups—Contact groups that you added to the asset group.
    • Available Contact Groups—Contact groups you can add to the asset group. This list is comprised of contact groups that are part of this account group.

Create or delete an asset group

You must have an account group and the Asset Manager role for the account group to use this procedure.

After you create a asset group, you must add assets and contact groups to it.

  1. Go to MyF5.
  2. In the upper right, select Profile (person icon), and then select Account Management.

    Note: The Account Management option displays only when you have the Asset Manager role for an account group.

  3. To search for a specific account group, in the search box, enter the account group name, and then select Search (magnifying glass icon).
  4. Select the account group that you want to add or delete an asset group from.
  5. Do one of the following:
    • To delete an asset group, complete only step 6.
    • To add an asset group, skip to step 7.
  6. To delete an asset group, under Asset Groups, next to the group you want to delete, select the check box, and the select Delete Asset Group.
  7. To add an asset group, under Asset Groups, select Create Asset Group.
  8. In Asset Group Name, enter a name for the contact group.

    Note: You must use an asset group name that is unique to this account group.

  9. In Description, enter a description of the asset group.
  10. Select Save.

    Under Asset Groups, the group you added displays in the list.

Add or remove perpetual assets from an asset group

You must have an account group and the Asset Manager role for the account group to use this procedure.

F5 hardware and software that you own outright are perpetual assets, as opposed to subscriptions, which enable you to use assets for a period of time. You can add to asset groups only perpetual assets that have active entitlement and belong to at least one of the the accounts in the account group.

  1. Go to MyF5.
  2. In the upper right, select Profile (person icon), and then select Account Management.

    Note: The Account Management option displays only when you have the Asset Manager role for an account group.

  3. To search for a specific account group, in the search box, enter the account group name, and then select Search (magnifying glass icon).
  4. Select the account group that contains the asset group you want to add or remove perpetual assets from.
  5. Under Asset Groups, select the asset group you want to add or remove perpetual assets from.
  6. Do one of the following:
    • To remove perpetual assets from an asset group, complete only step 7.
    • To add perpetual assets to an asset group, skip to step 8.
  7. To remove perpetual assets from an asset group, under Perpetual Assets, next to the assets you want to remove from the group, select the check boxes, and then select Remove from Asset Group.

    The perpetual assets you selected no longer display under Perpetual Assets.

  8. To add perpetual assets to an asset group, under Perpetual Assets, in the box, enter the serial number or registration key for the asset you want to add, and then select Add.

    Note: You can add up to 20 product numbers at a time, separated by commas.

Add or remove subscriptions from an asset group

You must have an account group and the Asset Manager role for the account group to use this procedure.

You can add to asset groups only subscriptions that belong to at least one of the the accounts in the account group. When a subscription is not on one of the accounts in the account group, it does not appear in the list of subscriptions that you can add to an asset group.

  1. Go to MyF5.
  2. In the upper right, select Profile (person icon), and then select Account Management.

    Note: The Account Management option displays only when you have the Asset Manager role for an account group.

  3. To search for a specific account group, in the search box, enter the account group name, and then select Search (magnifying glass icon).
  4. Select the account group that contains the asset group you want to add or remove subscriptions from.
  5. Under Asset Groups, select the asset group you want to add or remove subscriptions from.
  6. Do one of the following:
    • To remove subscriptions from an asset group, complete only step 7.
    • To add subscriptions to an asset group, skip to step 8.
  7. To remove subscriptions from an asset group, under Subscriptions, next to the subscriptions you want to remove from the group, select the check boxes, and then select Remove from Subscriptions.

    The subscriptions you selected no longer display under Subscriptions and now display under Available Subscriptions.

  8. To add subscriptions to an asset group, under Available Subscriptions, next to the subscriptions you want to add to the group, select the check boxes, and then select Add to Subscriptions.

    Note: Under Available Subscriptions, only subscriptions that have an Active status and belong to at least one account in the account group display.

    The subscriptions you selected display under Subscriptions and no longer display under Available Subscriptions.

Add or remove contact groups from an asset group

You must have an account group and the Asset Manager role for the account group to use this procedure.

You can add to an asset group only contact groups that you created for the account group.

  1. Go to MyF5.
  2. In the upper right, select Profile (person icon), and then select Account Management.

    Note: The Account Management option displays only when you have the Asset Manager role for an account group.

  3. To search for a specific account group, in the search box, enter the account group name, and then select Search (magnifying glass icon).
  4. Select the account group that contains the asset group you want to add or remove contact groups from. 
  5. Under Asset Groups, select the asset group you want to add or remove contact groups from.
  6. Do one of the following:
    • To remove contact groups from an asset group, complete only step 7.
    • To add contact groups to an asset group, skip to step 8.
  7. To remove contact groups from an asset group, under Assigned Contact Groups, next to the names of the contact groups you want to remove from the asset group, select the check boxes, and then select Remove from Contact Groups.

    The contact groups you selected no longer display under Assigned Contact Groups and now display under Available Contact Groups.

  8. To add contact groups to an asset group, under Available Contact Groups, next to the contact groups you want to add to the asset group, select the check boxes, and then select Add to Assigned Contact Groups.

    Note: Under Available Contact Groups, only contact groups that you created for the account group display.

  9. In the Assign Contact Group Role window, select the role you want the group members to have while working with the cases or assets in the asset group, and the select Save.

Change the role for a contact group in an asset group

You must have an account group and the Asset Manager role for the account group to use this procedure.

  1. Go to MyF5.
  2. In the upper right, select Profile (person icon), and then select Account Management.

    Note: The Account Management option displays only when you have the Asset Manager role for an account group.

  3. To search for a specific account group, in the search box, enter the account group name, and then select Search (magnifying glass icon).
  4. Select the account group that contains the asset group in which you want to change the user role for a contact group.
  5. Under Asset Groups, select the asset group in which you want to change the user role for a contact group.
  6. Under Assigned Contact Groups, next to the name of the contact groups you want to change the role for, select the check box, and the select Edit Role.
  7. In the Assign Contact Group Role window, select the role you want the group members to have while working with the cases or assets in the asset group, and the select Save.
