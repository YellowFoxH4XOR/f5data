Description
NGINX Plus, as part of the ELA / FCP, is charged per installed device and consumed from the annual commit value.
F5 Requires that you share an accurate count of NGINX Plus instances at least once a quarter.
This solution shows how to install the F5 Second Sight script in Docker for NGINX Instance Manager.

Environment

  • Docker
  • NGINX Instance Manager (NIM)
  • NGINX Plus

Cause
You need to create a NGINX Plus Instance count and send it to F5.
You want to run the script in Docker

Recommended Actions

You will Download and install the F5 Second Sight script, configure, and execute it.
Second Sight script will create docker containers to help run the script and collect the output. 
You will then send the results by email to your Customer Success Manager.
  1. SSH into your Linux environment
  2. Download the F5 Telemetry Tracker from GitHub

    git clone https://github.com/F5Networks/SecondSight

  3. Change directory to SecondSight/contrib/docker-compose

    cd /SecondSight/contrib/docker-compose

  4. Run the script

    ./f5tt-compose.sh -c start -t nim -s https://<NGINX_INSTANCE_MANAGER_ADDRESS> -u <username> -p <password>

  5. Query the instance count by running the curl command below

    curl -s http://127.0.0.1:5001/instances | jq

  6. Observe the output under “instances”

    "instances": {
        "nginx_plus": {
          "managed": 3,
          "online": 2,
          "offline": 1
        },
        "nginx_oss": {
          "managed": 5,
          "online": 2,
          "offline": 3
        }
      },
      "modules": {},

  7. Please create a file with the above output and email this to customersuccess@f5.com and your Customer Success manager for processing.

    curl -s http://127.0.0.1:5001/instances | jq > nginx.json
