Known Issue

The Configuration utility incorrectly displays BIG-IP LTM policy rule conditions using the in datagroup type.

This issue occurs when all of the following conditions are met:

  • You configure a BIG-IP LTM policy rule condition type other than in datagroup. For example, you use the any of type.

    Note: You can configure these rules using either the Configuration utility or the TMOS Shell (tmsh).

  • You use the Configuration utility to view the BIG-IP LTM policy rule.

Impact

The previous BIG-IP LTM policy rule conditions display using the in datagroup type and associated values.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP LTM policy rule conditions display incorrectly when using the Configuration utility, but they display correctly when using tmsh.

Workaround

To work around this issue, use tmsh to view and modify BIG-IP LTM policy rules.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
