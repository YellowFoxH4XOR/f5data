Known Issue

In rare conditions, the BIG-IP ASM bd process may restart when response logging is enabled

This issue occurs when the following condition is met:

  • BIG-IP ASM response logging is enabled.

Impact

BIG-IP ASM traffic processing is temporarily interrupted.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM system fails to process traffic for a brief period of time.
  • The BIG-IP ASM system logs a bd core file to the /var/core directory.
