Known Issue

Menu selections for creating a new remote desktop virtual desktop infrastructure (VDI) profile may be impaired.

This issue occurs when all of the following conditions are met:

  • You manage the BIG-IP APM system using Microsoft Internet Explorer 11.
  • You attempt to create a new remote desktop VDI profile.

Impact

Menu selections for the VDI profile are truncated.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to create a new remote desktop VDI profile, the VDI profile configuration's pop-up menu items are truncated and display only part of the first character of the menu selections.
  • When you use an alternate vendor's browser to create a new remote desktop VDI profile, the browser displays the full text of the VDI profile configuration menu.

Resolution

Status

F5 Product Development has assigned ID 610248 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles
Release12.0.0K2200: Most recent versions of F5 software
Hotfix11.6.1 HF2K9502: BIG-IP hotfix matrix

Workaround

To work around this issue, you can use an alternate browser to configure new remote desktop VDI profiles.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
