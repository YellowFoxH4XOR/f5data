Known Issue

The firewall rule logs actions as "Accept Decisively," which is incompatible with some remote logging systems.

This issue occurs when all of the following conditions are met:

  • The BIG-IP AFM ACL rule action is set to Allow Final, and logging is enabled.
  • In the Security Logging profile, custom (selective) field logging is enabled and one of the log destination formats is set to syslog format RFC5424.

Impact

The BIG-IP AFM system logs messages with "Accept Decisively" actions, which is incompatible with some remote logging systems.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • For a firewall rule with the action set to Allow Final, the firewall ACL log message shows the action as "Accept Decisively" (which is a BIG-IP specific implementation).
  • The rule action logged as "Accept Decisively" is not compatible with the remote log destinations.
  • With custom field logging enabled, the BIG-IP AFM system still generates the ACL match logs with all fields for syslog format RFC5424.
