K54947301: BIG-IQ warning message: Alert logs are currently not being replicated to other devices

Type
Support Solution
Published
2021-10-19
Updated
2025-04-01
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K54947301

Description

When check BIG-IQ CM Configuration Utility "System --> BIG-IQ DATA COLLECTION --> BIG-IQ Data Collection Cluster-->SUMMARY-->Status", the health shows warning message:

Alert logs are currently not being replicated to other devices. This may be due to having only a single device configured or issues with other devices. To resume replication, either add additional devices or resolve any issues that exist on existing devices.

Environment

  • BIG-IQ CM
  • BIG-IQ DCD

Cause

The warning message is expected if the deployment only have 1 BIG-IQ DCD.

Recommended Actions

Add more DCD can eliminate the warning.

Additional Information

None
