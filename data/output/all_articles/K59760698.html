Description
When running "tmsh list gtm monitor" you don't see any monitors listed which is expected behavior.

Environment

  • BIG-IP GTM
  • BIG-IP DNS

Cause
Expected behavior

Recommended Actions

You must specify a monitor type. 
Note, in the TMOS shell, you can type "list gtm monitor" then hit the TAB key to see a list of gtm monitor types to choose from.

Examples:
# tmsh
# list gtm monitor tcp
# list gtm monitor http
