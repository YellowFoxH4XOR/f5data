Topic

The CAPTCHA technology integrated into FirePass presents the user with an image depicting distorted text and asks the user to type the text, along with their username and password. If the typed text is correct, the user is granted access to FirePass. CAPTCHA helps protect against automatic logon attempts on the FirePass logon page. This technology eliminates multiple logon attempts that may increase CPU usage on FirePass and degrade performance.

Enabling the CAPTCHA system

To enable the CAPTCHA system, perform the following procedure:

  1. Navigate to USERS : Global Settings.
  2. Select the Enable CAPTCHA for Landing URI or Virtual Host check box.
  3. If using a custom landing URI or virtual host, select the URI to enable CAPTCHA from the Enable CAPTCHA for Landing URI or Virtual Host drop-down menu.
  4. Enter the number of failed logon attempts before enabling CAPTCHA in the Display CAPTCHA after this number of logon failures: text box.

    Note: Entering 0 (zero) will show the CAPTCHA for all logon attempts.

    Note: The CAPTCHA interface pre-generates static images to improve the performance of FirePass.
  5. Enter the number of images to generate per regeneration pass in the Number of images to be generated (100 - 10,000): text box.
  6. Enter the frequency of generating new images in the Image regeneration frequency: drop-down menu.
     
    Note: The regeneration process always runs at 02:30 local system time at the frequency interval specified.

Creating custom prompts for the CAPTCHA fields

Optionally, you can create custom prompts for the CAPTCHA fields displayed by performing the following procedure:

  1. Navigate to Device Management : Customization.
  2. Enter your text for the CAPTCHA prompt displayed to users in the CAPTCHA prompt: text box.
  3. Enter your text for the CAPTCHA refresh message displayed to users in the CAPTCHA refresh prompt:  text box

Note: Enabling CAPTCHA also enables it on the administrative interface.
