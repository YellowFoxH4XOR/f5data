Topic

3-DNS Controller supports both active-active and active-standby configurations.

An active-standby configuration provides more reliability if one system fails; an active-active configuration sacrifices the failover aspect in exchange for more capacity. The 3-DNS Controller will listen on all self IP addresses and respond to DNS queries regardless of whether it is the active system or the standby system. A single 3-DNS Controller can handle thousands of requests per second, so generally an active-standby configuration is preferred.

If you are running in an active-standby configuration there is typically one shared IP address for the active system. This allows for a seamless failover.

If you are running in an active-active state, it requires that you use the individual IP addresses of each 3-DNS Controller. If one of the systems fails, the IP address to that system will no longer respond to DNS queries. In that case, service will be interrupted for all systems that are using the IP address of the failed system as their DNS server.
