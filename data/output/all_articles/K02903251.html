Description

Configuring the TLS Version used by the big3d process and BIG-IP Configuration utility for PCI Compliance.

Environment

  • PCI scan failed
  • Requirements for TLSv1.2 
  • Requirements for moduli of 2048 bits or greater.
  • BIG-IP Configuration utility (GUI)
  • The big3d process

Cause

The big3d process and Configuration utility, which utilizes the Management IP, are configured to use TLSv1.

Recommended Actions

In order to configure the Management IP to only use TLSv1.2 or above, follow all of the steps below.

  1. Run below TMSH command to update the Configuration utility to use TLSv1.2 or above:

    tmsh modify sys httpd ssl-protocol "all -SSLv2 -SSLv3 -TLSv1 -TLSv1.1"
     
  2. Run below TMSH command to update the Configuration utility to use moduli of 2048 or greater:

    tmsh modify sys httpd ssl-ciphersuite AESGCM:AES:-ADH:-DHE:-AES128:-SHA1
     
  3. Run below TMSH command to save the configuration changes made to sys httpd:

    tmsh save sys config
     

In order to configure big3d to only use TLSv1.2 or above, follow all of the steps below.

  1. Run below TMSH command to update big3d to use TLSv1.2 or above:

    tmsh modify sys db big3d.minimum.tls.version value tls1.2
     
  2. Run below TMSH command to update big3d to use moduli of 2048 or greater:

    tmsh modify sys db big3d.ssl.cipherlist value AESGCM:AES:-ADH:-DHE:-AES128:-SHA1
     
  3. Restart big3d. This should not be traffic impacting:

    tmsh restart sys service big3d

Additional Information

The Configuration utility listens on port 443 and the big3d process listens on port 4353.
