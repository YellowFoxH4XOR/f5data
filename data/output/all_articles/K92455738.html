K92455738: How to edit Hostname on BIG-IQ

Description
You need to edit the Hostname on BIG-IQ, this can be caused by Cloud providers such as AWS setting Hostname to a generic name.
Hostname changes after few minutes when Changing Hostname IN GUI > System > This Device > General properties> Edit ( upper right corner) or changing it from https://<BIG-IQ-IP>/ui/system/setup

Environment

  • AWS Cloud Deployment
  • BIG-IQ VE

Cause
AWS generates a host name for each deployed BIG-IQ VE instance and uses the private IP address of each instance as part of the host name for the instance. For example, ip-10-0-0-172.ec2.internal. If you attempt to change the host name of the BIG-IQ VE instance, the BIG-IQ VE instance reverts to the AWS-generated host name.

Recommended Actions
There are two methods to change the Hostname. Both require you to delete the hostname using the command line then saving the configuration and finally resetting and restarting the dhclient.
The first method then requires you to connect to the GUI and modify the Hostname in the system > This device > General properties (upper right corner)
The second method requires you to connect to the GUI providing the setup URL (https://<BIG-IQ-IP>/ui/system/setup), choosing option 5 (management address) and modifying the Hostname on that page, clicking on point 7  then clicking on Launch

  1. Connect to BIG-IQ via SSH
  2. Log in to the TMOS Shell (tmsh)
  3. Remove the host-name option from the DHCP configuration
  4. modify /sys management-dhcp sys-mgmt-dhcp-config request-options delete { host-name }
  5. Save the configuration
  6. save /sys config
  7. Reset and restart the dhclient:
  8. dhclient -r && bigstart start dhclient
  9. Connect to GUI to modify hostname
  10. Go to : Changing Hostname  IN GUI  > System > This Device > General properties> Edit ( upper right corner)
  11. Modify hostname to one which You need
