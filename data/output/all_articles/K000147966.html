Description

Environment

Answer/Recommended Actions

You can view the quota levels and usage configured by searching for quotas in the main page to get to the quotas list: 

Or you can get to the quota dashboard by navigating to:

  1. Administration
  2. Tenant Settings
  3. Quotas 
  4. You will see the list of the currently configured quotas
