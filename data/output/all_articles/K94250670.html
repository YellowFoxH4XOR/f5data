Known Issue

During startup, the tmm process does not use the current BIG-IP host name for logging purposes until it has fully initialized.

This issue occurs when the following condition is met:

  • You start the BIG-IP system.

Impact

Determining the source of a specific TMM startup log entry in consolidated remote logs, from many BIG-IP systems, may not be possible.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Log entries contain the name of the tmm process instead of the current host name.
  • After the system is fully initialized, the BIG-IP host name is used with all subsequent TMM log entries.
