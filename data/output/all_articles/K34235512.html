Description

This article covers the various methods to enforce attack signatures starting in version 15.1.0 and later.

Environment

  • ASM licensed and provisioned
  • Enforcing Attack Signatures

Cause

Beginning with the release of version 15.1.0, there are a number of options available for the enforcement of attack signatures.

  1. Enforce a single signature
  2. Enforce multiple signatures
  3. Enforce all staged signatures

Recommended Actions

  1. Login to the BIG-IP Configuration utility.
  2. Navigate to Security > Application Security > Security Policies > Policies List.
  3. Click on the security policy which you want to enforce the attack signatures. The Configuration utility displays the security policy configuration page.
  4. Click Attack Signatures.
  5. Depending on whether you want to enforce a single signature, multiple signatures or all staged signatures, perform the following as needed:

    Enforce a single signature:

    • This is done by selecting the box to the left of an attack signature names and then clicking on the Enforce button.  This will then show a verification pop-up window that should be reviewed for any unexpected results and then click Enforce to submit the modification.  Clicking the Cancel button will cancel the modification.

    Enforce multiple signatures:

    • This is done by selecting as many of the boxes to the left of the attack signature names, as needed, and then clicking the Enforce button.  This will then show a verification pop-up window that should be reviewed for any unexpected results and then click Enforce to submit the change.  Clicking the Cancel button will cancel the modification.
    • Additionally, you can also select the Select all signatures box to the left of the Signature Name column heading.  This will then show a verification pop-up window that should be reviewed for any unexpected results and then click Enforce to submit the change.  Additionally, on the verification pop-up window, is the option to Apply changes to all <number> filtered signatures.  Selecting this box, and clicking Enforce, will enforce all of the signatures available under your current filter. Clicking the Cancel button will cancel the modification.

    Enforce all staged signatures:

    • This option is found by clicking the "..." button to the right of the Enforce button.  This method enforces all signatures currently in a "Staged" status.  This will effect all signatures in this status and not just what is currently filtered.  Any signatures in the "Enforced" or "Disabled" status will not be modified.

    Important: ID1037253 is currently being used to track an issue in which the verification pop-up does not appear when using the Enforce all staged signatures button.  Please verify the affected signatures before selecting this option.
