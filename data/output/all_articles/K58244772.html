Description

It can be challenging to manage TLS Certificates in a BIG-IP DNS environment. This allows you to remove expired TLS Certificates and eliminate duplicates.

Environment

  • BIG-IP DNS connected in an iQuery mesh
  • Duplicate Certificates in any of the following locations:
    • /config/gtm/client.crt
    • /config/big3d/server.crt

Cause

Each time the bigip_add or gtm_add script is executed, TLS Certificates are exchanged between the initiating BIG-IP and the remote BIG-IP. The certificates are appended to the existing certificate store, causing duplicate certificates.

Recommended Actions

Leverage openssl and bash scripting 

  1. SSH to log into the Advanced Shell (bash) of the BIG-IP

  2. Create a backup of your existing certificate stores:


    cp /config/big3d/client.crt /config/big3d/client.crt.K58244772
    cp /config/gtm/server.crt /config/gtm/server.crt.K58244772

  3. Create the /var/tmp/splitcerts.sh using your favorite text editor such as VIM:
    #!/bin/bash
#
# USAGE
# splitcerts.sh 
# For Example
# /var/tmp/splitcerts.sh /config/httpd/conf/ssl.crt/server.crt
# /var/tmp/splitcerts.sh /config/big3d/client.crt
# /var/tmp/splitcerts.sh /config/gtm/server.crt
ITERATION=0
TMPDIR=/var/tmp/splitcerts
mkdir -p ${TMPDIR}
while read line
do
   # Write a new file if this is the start of a cert.
   if [ "x$line" == "x-----BEGIN CERTIFICATE-----" ]
   then
      ITERATION=$(($ITERATION+1))
      CERTFILE="${TMPDIR}/$(echo $1 | sed 's/\//_/g').$ITERATION.crt"
      echo -e "\nStarting to write: ${CERTFILE}"
      echo $line > $CERTFILE
   elif [ "x$line" == "x" ]
   then
      # Do not write blank lines.
      continue
   elif [ "x$line" == "x-----END CERTIFICATE-----" ]
   then
      # Write the end of the $CERTFILE
      echo "${line}" >> $CERTFILE
      # Then update the name to something sane.
      FINAL_CERTFILE=${TMPDIR}/$(openssl x509 -in $CERTFILE -subject -noout -enddate | grep -o -P '(CN=)(.*)|notAfter(.*)' | cut -d'=' -f2 | sed -r 's,[ /],_,g' | cut -d'_' -f1,2,4,5 | sed ':a;N;$!ba;s/\n/_/g' | sed 's/\/emailAddress//g').crt

      # option 1: This adds the issuer to the filenames 
      FINAL_CERTFILE=${TMPDIR}/$(openssl x509 -in $CERTFILE -subject -noout -enddate -issuer | grep -o -P '(CN *= *)(.*)|notAfter(.*)' | cut -d'=' -f2 | sed -r 's,[ /],_,g' | cut -d'_' -f1,2,4,5,6 | sed ':a;N;$!ba;s/\n/_/g' | sed 's/\/emailAddress//g').crt 

      # Comment out the above and uncomment one of the following if the above does not work 
      # option 2: This is the older version. It doesn't work if 'CN=' does not exactly match. 
      # FINAL_CERTFILE=${TMPDIR}/$(openssl x509 -in $CERTFILE -subject -noout -enddate | grep -o -P '(CN=)(.*)|notAfter(.*)' | cut -d'=' -f2 | sed -r 's,[ /],_,g' | cut -d'_' -f1,2,4,5 | sed ':a;N;$!ba;s/\n/_/g' | sed 's/\/emailAddress//g').crt

      # option 3: This is the corrected version from the original which allows matching 'CN =' with longer descriptions 
      # FINAL_CERTFILE=${TMPDIR}/$(openssl x509 -in $CERTFILE -subject -noout -enddate | grep -o -P '(CN *= *)(.*)|notAfter(.*)' | cut -d'=' -f2 | sed -r 's,[ /],_,g' | cut -d'_' -f1,2,4,5 | sed ':a;N;$!ba;s/\n/_/g' | sed 's/\/emailAddress//g').crt

      mv $CERTFILE $FINAL_CERTFILE
      echo " ...moved to: $FINAL_CERTFILE"
   else
      # Append cert contents to $CERTFILE
      echo "${line}" >> $CERTFILE
   fi
done < $1
  4. Clean up the Trusted Server Certificate store: [BIG-IP DNS Only]

    bash /var/tmp/splitcerts.sh /config/gtm/server.crt

    1. List all of the certificates:

      ls -l /var/tmp/splitcerts

    2. Remove any expired certs from the output directory (/var/tmp/splitcerts/...)

      For Example:
      rm /var/tmp/splitcerts/localhost.localdomain_Jul__00:22:10_2024.crt

    3. Cat all of the desired certs back into the desired certificate store:
      cat /var/tmp/splitcerts/* > /config/gtm/server.crt

    4. Remove all of the temporary certificates:

      rm -f /var/tmp/splitcerts/*

  5. Clean up the Trusted Device Certificate store: [ALL BIG-IP DNS AND LTM DEVICES]

    bash /var/tmp/splitcerts.sh /config/big3d/client.crt

    1. List all of the certificates:

      ls -l /var/tmp/splitcerts

    2. Remove any expired certs from the output directory (/var/tmp/splitcerts/...)

      For Example:
      rm /var/tmp/splitcerts/localhost.localdomain_Jul__00:22:10_2024.crt

    3. Cat all of the desired certs back into the desired certificate store:

      cat /var/tmp/splitcerts/* > /config/big3d/client.crt

    4. Remove all of the temporary certificates:

      rm -f /var/tmp/splitcerts/*

Additional Information

While this can be a very effective method to clean up your duplicate and expired TLS Certificates, you must take caution to test this functionality in a test/lab environment to fully under the repercussions of this script.
