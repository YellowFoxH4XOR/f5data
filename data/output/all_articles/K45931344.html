Description

TMSH commands in the command line are not working, with similar error:

config # tmsh save sys ucs
exception: (Can't create temp directory, /var/system/tmp/tmsh/YNSLxv, errno 28] No space left on device) (framework/TempDir.cpp, line 216), exiting...

Checking the inode usage with df -i shows space full for /var:

df -i
Filesystem                              Inodes  IUsed    IFree IUse% Mounted on
devtmpfs                               2029703    476  2029227    1% /dev
tmpfs                                  2038470    156  2038314    1% /dev/shm
tmpfs                                  2038470    936  2037534    1% /run
tmpfs                                  2038470      2  2038468    1% /sys/fs/cgroup
/dev/mapper/vg--db--sda-set.1._var      196608 196608        0  100% /var  → Note!

Environment

  • Saving UCS file
  • Entering any tmsh commands
  • Disk Space
  • ASM provisioned
  • ASM signature updates

Cause

When updating the different ASM signatures, TC, browser challenges, server tech, etc, tomcat creates temporary files under /var/cache/tomcat/temp/ which should be cleaned up following each update install.

As each install is completed the directory is removed. These files are created during each update / installation and orphaned files can be removed. They will be recreated by the update/install process from the original *.im file during next run.

If an update has failed temporary files may become orphaned. Checking the relevant logs for Live Update, tomcat and ASM to see what errors or information is available to explain the disruption could be done for more information.

Recommended Actions

We need to clean up the /var files to resolve, specifically the /var/cache/tomcat/temp/ files. From bash run these commands:

rm -rf /var/cache/tomcat/temp/Live-Update*

bigstart restart tomcat

Additional Information

  • The system running out of diskspace could be due to ID 907025. In this known issue, you may observe the following logs in /var/log/tomcat/liveupdate.log:

    ERROR Update:256 - java.nio.file.FileSystemException: /var/cache/tomcat/temp/Live-Updatexxxxxxx No space left on device ...
    ERROR Persist:115 - Update of object "com.f5.liveupdate.entity.Installation@1b384ef" using statement "UPDATE INSTALLATION SET ERRORMESSAGE=?,LASTUPDATEMICROS=?,STATUS=? WHERE ID=?" failed : java.sql.SQLException: File input/output error: /var/lib/hsqldb/live-update/liveupdatedb.log in statement [UPDATE INSTALLATION SET ERRORMESSAGE=?,LASTUPDATEMICROS=?,STATUS=? WHERE ID=?]

    Verify if the system has hit ID 907025 and perform the workaround as needed.
