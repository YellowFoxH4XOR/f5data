Known Issue

An HTTP GET request to the iControl representational state transfer (REST) application programming interface (API) may return partial properties of file objects.

This issue occurs when the following condition is met:

  • An HTTP GET request is sent to access file object configuration properties, such as the tm/sys/crypto/key configuration.

Impact

Users cannot view properties of some file objects when using the iControl REST API.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the HTTP GET operation is performed, you observe missing properties for a file object.

    For example, the iControl REST API does not return all the properties for the /data-group/test file object in the following HTTP GET output:

    curl -s -k -u admin:admin-test -H "Content-Type: application/json" -X GET https://192.168.1.1/mgmt/tm/sys/file/data-group/test | python -m json.tool
    {
    "fullPath": "test",
    "generation": 36187,
    "kind": "tm:sys:file:data-group:data-groupstate",
    "name": "test",
    "selfLink": "https://localhost/mgmt/tm/sys/file/data-group/test?ver=11.7.0",
    "separator": ":=",
    "sourcePath": "file:/config/dg.dat"
    }

    The following tmsh list /sys file data-group test command output displays more properties for the same file object:

    sys file data-group test {
    checksum SHA1:8:0a6563abc6492e98a2a94e92a90cb3cc062b1f21
    create-time 2014-11-10:16:47:08
    created-by root
    last-update-time 2014-11-10:16:47:08
    mode 33152
    revision 1
    size 8
    source-path file:/config/dg.dat
    type string
    updated-by root
    }
