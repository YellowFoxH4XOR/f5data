Topic

The BIG-IP ASM /usr/sbin/asmqkview script has two options for which no documentation or explanation is included within the BIG-IP ASM product. However, the asmqkview -h command output displays the options. For example:

Usage: asmqkview [--add-proxy-log] [--include-traffic-data]

When you run the asmqkview script with either of the above options enabled, the script produces a snapshot file that includes additional data from the requests log and forensics database. F5 Support might find this information useful when they assist you in troubleshooting an issue.

You should use these options only when instructed to do so by your F5 Support representative.

F5 Product Development is tracking this issue as ID225363 (formerly CR139186) and ID225364 (CR139187).

Note: For more information about the asmqkview script, refer to K6824: Overview of the asmqkview script.
