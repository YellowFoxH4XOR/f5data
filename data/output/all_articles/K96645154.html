Description

  • ASM blocks non browser requests
  • No learning suggestions are generated for this specific requests
  • The suggestion for violation is "None"
  • Accepting the request on Security > Event Logs > Application > Requests does nothing to the policy

Environment

  • ASM Security policy
  • Learn only from non-bot traffic is Enabled

Cause

Seen behavior is expected when "Learn only from non-bot traffic" is enabled

Recommended Actions

Disable "Learn only from non-bot traffic", if you want to see the learning suggestions from that source.

  1. On GUI go to Security > Application Security > Policy Building > Learning and Blocking Settings
  2. Select the ASM security policy in question
  3. Expand Policy Building Process
  4. Uncheck "Learn only from non-bot traffic"
  5. Click Save
  6. Apply policy
