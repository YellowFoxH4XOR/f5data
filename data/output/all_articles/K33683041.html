Description

After re-activating the license on BIG-IP device, below message displayed on the Configuration Utility (GUI).

"The configuration has not yet loaded. If this message persists, it may indicate a configuration problem."

When running command 'tmsh show sys config verify', you will see below error in the output: 

01070712:3: Failed: name (/Common/certificate.crt) Cache path (/config/filestore/files_d/Common_d/certificate_d/:Common:certificate.crt_51905_1) does not exist and there is no copy in trash-bin to restore from.

You will also notice that the certificate files under SSL Certificate List are all removed.

  • For BIG-IP 13.x and later, go to System > Certificate Management > Traffic Certificate Management > SSL Certificate List. 
  • For BIG-IP 12.x and earlier, go to System > File Management > SSL Certificate List
Certificate files are no longer present under /config/filestore/files_d/Common_d/certificate_d. Similar behaviour is observed for key files under /config/filestore/files_d/Common_d/certificate_key_d 
 

Environment

  • License re-activate on the device
  • Certificate and key files are removed after license re-activation. 
     

Cause

Unknown

Recommended Actions
Since the certificate and key files are removed from the device, we cannot edit the bigip.conf file to comment out the object causing the issue. In this case the solution would be to restore the UCS archive taken earlier if any. 

  1. Check if any previously take UCS archive file is available to restore under System > Archives from GUI and under /var/local/ucs through CLI. 
  2. Restore the ucs file using below command:

    tmsh load /sys ucs <path/to/UCS> no-license

    For example, you use the following code to install the UCS archive named MyUCS:

    tmsh load /sys ucs /var/tmp/MyUCS.ucs no-license

  3. Verify the certificate and key files on the device and verify the GUI is giving the error any more/ 

     

Additional Information

It is recommended to generate UCS archive before license re-activation or upgrade:
K7727: License activation may be required before a software upgrade for BIG-IP
