Description

  • This is the process of configuring an application with the Bot Defense Cloudflare Connector on the Distributed Cloud (XC) Console and deploying it on Cloudflare. 

Environment

  • Distributed Cloud Bot Defense
  • Cloudflare Connector
  • F5 Distributed Cloud

Procedure

On the XC Console

  1. Go to the Bot Defense tile
  2. Navigate under Manage > Applications > Add Application
  3. Provide a Name, Application Region, and for Connector Type choose Cloudflare
  4. Click on Configure
      1. Select to enable or disable Mobile SDK under Mobile Settings (more information on this section here)
      2. Under More Options select the toggle to Show Advanced Fields and configure Trusted Clients Rules by referencing this documentation
  5. Click Save and Exit after applying all the above configuration
  6. Click on Actions (...) and download the following:
    1. Config File
    2. Template

On the Cloudflare dashboard

NOTE: These are the steps once the site is already created in Cloudflare and that the DNS setup (record creation and Nameservers changed to Cloudflare's) is already completed. If you need additional instructions for that you can find them in the Add Site to Cloudflare guide.

Create the Service Worker

  1. Go to the Workers tab and click Create a Service
  2. Provide a Service Name
  3. Select HTTP router as your starter 
  4. Click Create Service

Configure Route

  1. Go to the Service Worker page (you should be redirected automatically after creating the service)
  2. Under Routes click View
  3. Click Add Route to pop up the Routes section below
  4. Provide the Route value (e.g. your hostname/*)
  5. Click Add route

Add the configuration files into the Service Worker

  1. In the Service Worker page click on Quick edit
  2. Remove the existing code
  3. Add the template code into the worker (copy the content of the JavaScript file downloaded from the console in step 6)
  4. Add the configuration code into the worker (copy the content of the JSON file downloaded from the console in step 6)
    • Code before:  
      const CONFIG = "__CONFIG__"
    • Code after:  
      const CONFIG = <code copied from the JSON file here>
    • NOTE: Don't forget to remove the quotes!
  5. Click Save and deploy twice (on the bottom of the page and on the pop-up window)

View Real-time event logs - Optional

  1. Go to the Service worker page
  2. Click on the Logs tab
  3. Click Begin log stream
