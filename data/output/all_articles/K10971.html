Topic

Starting in FirePass version 6.0.3 and 6.1.0, you can enforce an SSL cipher strength policy. You can either reject SSL sessions that do not comply with the cipher strength policy that you have configured, or you can send a notification to the user via an HTML page that their browser does not comply with your organization's SSL cipher strength requirement. This option can be leveraged to address security concerns that may result from security auditing tool reports, as discussed in K7939: Security scans report that administrative URL access is possible when using low-strength SSL ciphers.

If you decide to reject sessions, any SSL connections from a web browser that do not comply with the configured SSL cipher strength policy will be rejected immediately. Depending on the user's browser implementation, a browser that does not support the cipher strength may only report a connectivity problem without a clear explanation of why the connection to FirePass failed. Most recent Web browsers support high-grade security by default. For most deployments, this option should not cause rejections of SSL connections to FirePass. Enabling this option removes the redundant SSL cipher verification when a user logs on. Without this option enabled, SSL connections with weaker ciphers than the selected policy can connect to the FirePass logon page, and FirePass will enforce stronger ciphers after the user has authenticated, as specified by the selected policy.

Notifying the users may provide better usability depending on the types of browsers your users typically use to connect to the FirePass controller. This option will perform a redundant verification of SSL ciphers policy when connecting to FirePass' logon page. During authentication it provides users a notification via an HTML page if the browser's SSL cipher does not comply with FirePass' configured policy. The message that they receive will be similar to the following example:

SSL ciphersuite EXP1024-RC4-SHA not permitted. Please see your system admin.

Configuring the cipher strength policy and enforcement method

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Device Management : Security : User Access Security.
  3. Under the SSL Cipher Security section, select the policy that meets your organization's requirements.
    Note: Refer to the online help for an explanation of each option.
  4. Under the SSL Ciphers Policy Enforcement, select the action you want the FirePass to perform if the connecting user's cipher strength does not comply with the policy you selected.

Note: Changes made to Device Management : Security : User Access Security will require a services restart.
