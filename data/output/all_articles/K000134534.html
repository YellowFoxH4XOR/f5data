K000134534: [F5OS] Restoring backup failed with the error: Database config-restore failed

Source

Description

When restoring the F5OS configuration, the following error may be encountered:

system database config-restore name <backup file name>

A clean configuration is required before restoring to a previous configuration.
Please perform a reset-to-default operation if you have not done so already.
Proceed? [yes/no]: yes
Error: Database config-restore failed.

Followed: K32216501 [F5OS-A] Restoring backup failed with the error: Database config-restore failed, still failing.

Environment

  • F5OS-A / F5OS-C
  • rSeries / Velos
  • Restore

Cause

  • Bug ID 1132937

Recommended Actions

Older version may exclude PSU data in empty in backup file.

Determine the installed PSU(s) on the Appliance that you are restoring the managment CLI backup file by referring to K90310819: Display the number of installed power supply units . You will need to either remove or add the following lines if the the Appliance that you are restoring the managment CLI backup file has a missing PSU or contains an additional PSU:

F5OS-A (rSeries) must have this component stanza:

    <component>
      <name>psu-1</name>
      <config>
        <name>psu-1</name>
      </config>
    </component>
    <component>
      <name>psu-2</name>
      <config>
        <name>psu-2</name>
      </config>
    </component>


F5OS-C (velos) Controller must have this 

<component><name>psu-1</
name><config><name>psu-1</name></config></component><component><name>psu-2</name><config><name>psu-2</name></config></component><component><name>psu-3</name><con
fig><name>psu-3</name></config></component><component><name>psu-4</name><config><name>psu-4</name></config></component><component><name>psu-controller-1</name><c
onfig><name>psu-controller-1</name></config></component><component><name>psu-controller-2</name><config><name>psu-controller-2</name></config></component></compo
nents>

Paste above appropriate place in your backup file.
