Known Issue

This is the result of a known issue. At logon, PowerPC Mac users running Safari 3 are redirected to a page asking them to Click here to install the plugin. However, when the user clicks on the link, the plugin does not install and the error message does not appear.

This behavior occurs because the InspectionHost plugin fails to install. As a result, users are unable to successfully log in to FirePass if a pre-logon Check Files (MacOSX) feature has been created and enabled.

Note: This behavior only occurs when using a PowerPC Mac. This issue does not occur if the user is using an Intel platform Mac.

F5 Networks Product Development tracked this issue as CR106763 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

This issue was fixed in FirePass cumulative HF-602-8 for FirePass version 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.
