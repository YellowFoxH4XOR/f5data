Description

On GUI on Security > Overview > Application > Action Items you can see the following message "ASM service restart is required"

Environment

ASM

Cause

Seen message is generally caused by a modification of an ASM system variable.

Recommended Actions

Restart the asm process during a maintenance window.

  1. Connect to CLI
  2. Restart ASM

    bigstart restart asm

Additional Information

You can run the following commands to identify the date and time the modification that triggered the "ASM service restart is required" message

  1. Connect to CLI
  2. Run

    mysql -t -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e 'select * from PLC.ACTION_ITEMS'

    Example output:
    +----------------+------------------+--------------+-------------------+--------------+----------+---------------------------------+------------------------+
    | action_item_id | action_item_type | created_time | next_display_time | last_updated | severity | message                         | rest_uuid              |
    +----------------+------------------+--------------+-------------------+--------------+----------+---------------------------------+------------------------+
    |              1 |               14 |   1616967539 |        1616967539 |   1616967539 |        3 | ASM service restart is required | qrMjiSK8wlpvYG61Jf_cVg |
    +----------------+------------------+--------------+-------------------+--------------+----------+---------------------------------+------------------------+
  3.  The date can be converter to human readable format with:

    date -d @<machine_time>

    Example:

    date -d @1616967539

    Output:

    Sun Mar 28 14:38:59 PDT 2021
