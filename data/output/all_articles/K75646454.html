Description

In certain environments, it has been found that users will need to log out twice from Outlook Web Application OWA even though the session is removed from the BIG-IP APM. The following iRule will ensure the session is removed and the user is redirect to the logout page.

Environment

  • BIG-IP LTM + APM virtual servers
  • Outlook Web Application

Cause

Undetermined

Recommended Actions

Create iRule and apply the following iRule to your Exchange Virtual Server.

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. Click iRules.
  4. Click iRule List.
  5. Click Create to create a new iRule.
  6. In the Name field, enter a name for the iRule.
For Example:
owa_logout_iRule
  1. In the Definition field, enter the iRule with the proper values.

    when HTTP_REQUEST {
        set apm_cookie [HTTP::cookie value MRHSession]

    if { ([HTTP::uri] contains "logoff") } {
        log local0. "logoff triggered"
            HTTP::respond 302 noserver "Location" "/vdesk/hangup.php3" "Content-Type" "text/html" "Cache-Control" "no-cache, must-revalidate" Set-Cookie "MRHSession=deleted;expires=Thu, 01-Jan-1970 00:00:10 GMT;domain=[HTTP::host];path=/" Set-Cookie "LastMRH_Session=deleted;expires=Thu, 01-Jan-1970 00:00:10 GMT;domain=[HTTP::host];path=/"
            log local0. "Session removed"
        if { ([ACCESS::session exists -sid $apm_cookie]) } {
            ACCESS::session remove
            log local0. "Access Session Removed"
            }
        }
    }  
  1. Click the Finished button to save the iRule.
  2. Under Local Traffic, click Virtual Servers.
  3. Click the name of the virtual server to which the access policy will be applied.
  4. Select the Resources tab.
  5. Next to iRules, click Manage.
  6. In the Available box, highlight the name of the iRule you just created.
  7. Click the << button.

    The iRule moves to the Enabled box.

  8. Click Finished.

    Additional Information

    This solution is designed for stand alone LTM+APM configurations with OWA to correct unexpected logout behavior. For Federate configurations (SAML/OAuth), this may have adverse affects with the logout procedure and additional configuration or an alternate iRule may be needed.
