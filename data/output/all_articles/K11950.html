K11950: FirePass writes log files containing multibyte characters as ASCII

Known Issue

This is the result of a known issue. FirePass writes log files with the standard ASCII character set, regardless of the interface language. As a result, when users access FirePass using a multibyte character set, such as Japanese or Chinese, FirePass writes the log entries that use session data, such as logon name, to the log files as the ASCII representations of the hexadecimal value of the character encoding.

For example:

logon=&#x3084;&#x3059

F5 Networks Product Development is tracking this issue as ID 337722.
