Description

Unable to load configuration on BIG-IP LTM using UCS backup files. Ran TMSH command "load sys ucs ucs_backup.ucs", and got prompted with error message similar to below.

Unexpected Error: Configuration cannot be saved unless mcpd is in the running phase. Save was canceled. See "show sys mcp" and "show sys serivce" indicates that mcpd is in the run state, but "show sys mcp" is not in phase running, issue the command "load sys config" to further diagnose the problem.

Environment

  • BIG-IP
  • Restore using UCS backup file

Cause

File "crt_cert_filename.crt" were found missing from "Cache path (/config/filestore/files_d/Common_d/certificate_d/".
Recommended Actions

  1. Create a backup the current /config/bigip.conf
  2. Modify the /config/bigip.config file with bash command
     #vim /config/bigip.conf
     
  3. Either remove or hash out (#)  the entry similar to below example:
    # sys file ssl-cert /Common/blog.easyroomate.com...
    # cache-path /config/filestore/files_d/Common_d/certificate_d/:Common:crt_cert_filename.crt_xxxx_x
    ...
    # }
     
  4. Reload the configuration with tmsh command
    # tmsh load /sys config
