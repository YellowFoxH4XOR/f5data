Known Issue

The BIG-IP system may log additional message for remotely authenticated users.

This issue occurs when all of the following conditions are met:

  • Remote authentication is enabled and configured on the BIG-IP system.
  • The remote user account exists while there is no corresponding local user account in the system.
  • The remote user attempts to log in to the system.

Impact

The system logs an additional, unnecessary message.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • A remote user successfully logs in to the system, but in the /var/log/secure file, the system logs an error message similar to the following example:

    Dec 28 22:41:58 localhost alert sshd[868]: pam_unix(sshd:account): could not identify user (from getpwnam(testuser))
