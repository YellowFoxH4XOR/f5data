K4575: BIG-IP will allow you to specify an auth model group that contains an asterisk, but will omit the asterisk

Known Issue

This is the result of a known issue. When you create an auth model group from the command line, bigpipe will prevent you from entering an invalid character, with the exception of an asterisk (which is an invalid character). If you include an asterisk in the name of an auth model group, bigpipe will create the group name that you specify, but will omit the invalid asterisk character.

For example, if you attempt to create a group named Auth*Group, bigpipe will create a group named AuthGroup.

F5 Networks Product Development tracked this issue as CR47221 and CR47722 and it was fixed in BIG-IP version 4.5.13 for the 4.5 software branch. For information about upgrading, refer to the BIG-IP Release Notes.

This issue still exists in the BIG-IP version 4.6 branch.
