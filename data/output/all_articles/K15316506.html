K15316506: How to send logs via high-speed logging to Splunk

Description

Configuring formatted high-speed logging in BIG-IP for remote Splunk server.

Environment

  • Splunk
  • Highspeed logging
  • Publisher

Cause

None

Recommended Actions

To watch a video demo of these procedures using the Configuration utility, go to Configure the BIG-IP system high speed remote logging to send logs to Splunk .

Create a pool of remote log servers to which the BIG-IP system can send log messages

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Pools.
  3. Select Create.
  4. Enter a unique name for the pool.
  5. For New Members, add the IP address for each remote logging server that you want to include in the pool:
    1. For Address, enter an IP address or select a node address from the Node List.
    2. For Service Port, enter a service number or select a service name from the list.

      Note: Typical remote logging servers require port 514.

  6. Select Add.
  7. Select Finished.

Create a remote high-speed log destination

  1. Go to System > Logs > Configuration > Log Destinations.
  2. Select Create.
  3. Enter a unique, identifiable name for this destination.
  4. For Type, select Remote High-Speed Log.

    Note: Splunk requires log data to arrive in a specific format. To meet this requirement, you must create an additional log destination of the appropriate type and associate it with a Remote High-Speed Log destination. This configuration enables the BIG-IP system to format and deliver data to the Splunk server correctly.

  5. For Pool Name, select the pool of remote log servers to which you want the BIG-IP system to send log messages.
  6. For Protocol, select the protocol used by the high-speed logging pool members.
  7. Select Finished.

    Note: With this configuration, the BIG-IP system sends log data to the log servers as a plain, unformatted text string.

Create a formatted remote high-speed log destination for Splunk

  1. Go to System > Logs > Configuration > Log Destinations.
  2. Select Create.
  3. Enter a unique, identifiable name for this destination.
  4. For Type, select Splunk.
  5. For Forward To, select remote high-speed log destination to which you want the BIG-IP system to send log messages.
  6. Select Finished.

Create a Publisher

  1. Go to System > Logs > Configuration > Log Publishers .
  2. Select Create.
  3. Enter a unique, identifiable name for this publisher.
  4. For Destinations, select the Splunk destination from the Available list and move it to the Selected list.
  5. Select Finished.

Create a logging filter

  1. Go to System > Logs > Configuration > Log Filters.
  2. Enter a unique, identifiable name for this filter.
  3. For Severity, select the level of alerts that you want the system to use for this filter.
  4. For Source, select the system processes from which messages will be sent to the log.
  5. For Message ID, enter the first eight hex-digits of the specific message ID that you want the system to include in the log. Use this field when you want a log to contain only each instance of one specific log message.
  6. For Log Publisher, select the publisher that includes the destinations to which you want to send log messages.
  7. Select Finished.
