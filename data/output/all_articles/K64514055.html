Description
Images and icons fail to load on your application after applying the workaround Irule in K31100432

Environment

  • BIG-IP
  • Stream Profile
  • Irule
  • Image format SVG

Cause

  • ???Image format SVG is text based 
  • The stream expression in the irule is matching the content from the SVG file and modifying it

Recommended Actions

  1. Replace the SVG image file with a Raster graphic such as PNG or JPEG.
  2. If it's not possible to replace the SVG image file, modify the irule stream expression to avoid matching on the SVG file content.
    K04347914: When accessing web application images don't load - SVG image/icon failed to load
