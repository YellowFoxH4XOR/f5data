Description

  • This device was previously part of an High Availability (HA) configuration.
  • The device has since been removed from the HA config.
  • Now that the BIG-IP is currently standalone yet continues to try and connect to old peer on port 443.

 
Note: This can be seen when performing tcpdump and filtering the capture by the Self IP address. 

Environment

  • Previously configured for High Availability
  • Version 14

Cause
Undetermined at this time.

Recommended Actions

 
  1. Please create a ucs backup of the systems per K13132: Backing up and restoring BIG-IP configuration files with a UCS archive before beginning and saving the backups off box just in case
     
  2. Check the logs from /var/log/restjavad.0.log, you should see something like:

    [8100/shared/device-availability DeviceAvailabilityRefreshWorker] https://192.168.1.5 is now considered unavailable after missing 1 checks
    [8100/shared/device-availability DeviceAvailabilityRefreshWorker] https://192.168.1.5 is now considered unavailable after missing 3 checks
    [8100/shared/device-availability DeviceAvailabilityRefreshWorker] https://192.168.1.5 is now considered unavailable after missing 1 checks
    [8100/shared/device-availability DeviceAvailabilityRefreshWorker] https://192.168.1.5 is now considered unavailable after missing 3 checks
     
  3. Check the logs from /var/tmp/storage_text_dump.txt and get the uuid.

    i.e. There are three endpoints that still reference that system:

    /shared/resolver/device-groups/cm-bigip-allBigIpDevices/devices/0af46f46-af6f-43ef-b8d3-774d5a72d570
    /shared/resolver/device-groups/cm-bigip-allDevices/devices/0af46f46-af6f-43ef-b8d3-774d5a72d570
    /shared/resolver/device-groups/tm-shared-all-big-ips/devices/0af46f46-af6f-43ef-b8d3-774d5a72d570
     
  4. Run the following command and replace the uuid accordingly:

restcurl -X DELETE /shared/resolver/device-groups/cm-bigip-allBigIpDevices/devices/0af46f46-af6f-43ef-b8d3-774d5a72d570
restcurl -X DELETE /shared/resolver/device-groups/cm-bigip-allDevices/devices/0af46f46-af6f-43ef-b8d3-774d5a72d570
restcurl -X DELETE /shared/resolver/device-groups/tm-shared-all-big-ips/devices/0af46f46-af6f-43ef-b8d3-774d5a72d570
