Issue

Error Message

notice mcpd[<PID>]: 01071cfc:5: <FIPS Compliance Message> changing OpenSSL FIPS flag from (<Value>) to (<Value>). Reboot is required for changes to take full effect.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <FIPS Compliance Message> is a message indicating FIPS Compliance has changed.
  • <Value> is the value of the flag changing from and to.

For example:

notice mcpd[7555]: 01071cfc:5: FIPS 140 Compliance license changing OpenSSL FIPS flag from (-1) to (1). Reboot is required for changes to take full effect.

Message Location

You may encounter this message in the following location:

  • /var/log/ltm

Description

This message occurs when one or more of the following conditions is met:

  • You enable or disable either FIPS 140-2 compliance mode.
  • Modifying the Common Criteria DB variable (Security.CommonCriteria) changes the OpenSSL FIPS flag.

Impact

The log message and the prompt change to 'Reboot Required' to remind the user to reboot for all FIPS changes to take effect.

Recommended Actions

Reboot the BIG-IP system to initialize all processes correctly in compliant mode.
