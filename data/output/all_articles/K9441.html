K9441: An ''A'' code in the X-PvInfo header does not match any of the nodes in the policy tree

Note: For information about the X-PvInfo header information, refer to the Viewing X-PvInfo response headers section of the Using HTTP Headers chapter in the BIG-IP WebAccelerator Policy Management Guide.

The A code in an X-PvInfo HTTP header indicates the node in the policy tree that was used. However, the BIG-IP WebAccelerator may add an X-PvInfo HTTP header with an A code that does not match any of the nodes in the policy tree. This behavior may occur in the following two situations:

  • Unmatched requests did not match any nodes in the policy
  • Redirected requests were redirected to the origin website because of the reroutedExtensions served by the WebAccelerator

You can find out if the A code indicates either of these conditions by exporting the policy and searching for the A code number. To do so, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator Configuration utility.
  2. Click WebAccelerator.
  3. Click Policies.

    A New Policies Configuration window opens.
  4. Click the Export link for the policy that you want to export.

    Note: The C code in the X-PvInfo header idicates the policy matched for the request.
  5. Click the Export button.
  6. Save the exported file when prompted by your browser.
  7. Use a text editor to open the file saved in step 6.
  8. Search for the A code number.

    The A code number will be listed as an entityId for a requestClass entry in the file.

If the A code matches the entityId for a request class with a type='UNMATCHED' entry, the request did not match any of the nodes in the policy.

If the A code matches the entityId for a request class with a type='REROUTED' entry, the request was redirected to the origin website because of the reroutedExtensions configuration in the pvsystem.conf file.
