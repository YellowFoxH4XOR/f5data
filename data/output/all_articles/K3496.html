Topic

You can configure transparent health monitors to check the status of transparent devices, such as routers and firewalls, using the command line or the Configuration utility.
 

Using the command line to configure a transparent health monitor

  1. Define a new monitor, with the destination address of a reliable service that only the transparent device can access, by typing the following command:

    bigpipe monitor <name> '{ use <existing_monitor> dest <address> }'

    Note: Transparent devices do not always have a destination address available, so it is generally better to configure a monitor to check the availability of a service available through the transparent device. This will avoid a situation where the destination address continues to respond even though the device has stopped passing traffic.

    Whenever possible, you should base new monitors on an existing monitor for the protocol that you are checking.

    For example, the following new monitor is based on the HTTPS monitor:

    bigpipe monitor transparent1 '{ use https dest 10.190.100.21:443 }'

  2. Assign the monitor to the nodes that you want to mark as down when the health check fails.

    For example:

    bigpipe node 10.1.1.1 monitor use transparent1

    In most cases, this will include all of the nodes that can be accessed only with the transparent device.

Using the Configuration utility to configure a transparent health monitor

  1. From the Configuration utility, click Monitors.
  2. Click the Monitors Tab.
  3. Click Add.
  4. In the Name field, type the name of the monitor.

    For example:

    transparent1
  5. From the Inherits from menu, select an appropriate monitor.
  6. Click Next.
  7. In the Interval and Timeout fields, type the desired values.

    Note: The default values are usually the best values. You can increase these values, if desired, but you should not set them lower.

  8. Click Next.
  9. Leave the default values in the following fields:
    • Send String
    • Receive Rule
    • User Name
    • Password
  10. Do not select the Reverse check box.
  11. Click Next.
  12. Enter a reliable service that is accessed only by the transparent device for the Destination IP and Destination Service values.

    Note: Transparent devices do not always have a destination address available, so it is generally better to configure a monitor to check the availability of a service available through the transparent device. This will avoid a situation where the destination address continues to respond even though the device has stopped passing traffic.

  13. Click Done.
  14. Click Monitors.
  15. Click the Monitors Tab.
  16. Click the Node Associations tab.
  17. From the Choose Monitor menu, click the monitor that you created.
  18. Click the >> button to move the monitor to the Monitor Rule field.
  19. Click the Associate Current Monitor Rule check box for the router or firewall that you want to associate with the new transparent health monitor.
  20. Click Apply.
