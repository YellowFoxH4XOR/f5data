Description

Device was offline due to memory pressure, some processes were invoked oom-killer.

You may see these errors in /var/log/ltm
 
notice sod[6545]: 010c003e:5: Offline
notice sod[6545]: 01140041:5: Killing /usr/bin/mcpd pid 4613.
warning kernel: : [13808550.532178] mysqld invoked oom-killer: gfp_mask=0x201da, order=0, oom_score_adj=0
err kernel: : [13795663.498732] Killed process 942 (java) total-vm:726648kB, anon-rss:567148kB, file-rss:136kB, shmem-rss:0kB

Environment

  • Device offline
  • oom-killer

Cause

Bug ID 723790: Idle asm_config_server handlers consumes a lot of memory

Idle asm_config_server handlers needlessly uses a large amount of memory.

Recommended Actions

Follow the workaround in Bug ID 723790: Idle asm_config_server handlers consumes a lot of memory
