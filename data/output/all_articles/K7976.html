Known Issue

This is the result of a known issue. Java applets fail when launched inside Protected Workspace on Microsoft Vista clients using User Account Control (UAC). UAC is enabled by default in Microsoft Vista.

Note: FirePass version 6.0.1 requires cumulative Hotfix HF-601-6 or a later to support Protected Workspace on Vista clients. Previous versions of FirePass software do not support Microsoft Vista clients.

When a user enters Protected Workspace, logs in to the FirePass controller, and launches a Portal Access Web Application Favorite for a web application that contains a Java applet, an Application Error pop-up window displays the following error message:

Security Exception

java.security.PriviledgedActionException: java.io.IOException: Access is denied

If you click the OK button, a second Application Error pop-up window displays an error message that appears similar to the following:

Security Exception

java.lang.NullPointerException

After you click the OK button, the applet fails to run.

F5 Product Development tracked this issue as CR86209, and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Additionally, Cumulative Hotfix HF-601-8 has been issued for FirePass version 6.0.1. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by disabling Microsoft Vista's User Account Control, which permits the Java applet to run inside Protected Workspace.  For instructions about how to disable UAC, refer to Microsoft Vista documentation.
