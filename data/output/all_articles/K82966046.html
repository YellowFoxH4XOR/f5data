K82966046: After upgrade of GTM from 11.5 to 13.x Data Center and Wide-IP using generic server types, all marked down.

Type
Support Solution
Published
2024-03-01
Updated
2024-03-01
Source
https://my.f5.com/manage/s/article/K82966046

 

Description:

After GTM upgrade from 11.5.x to 13.x Data Center will all GTM server objects defined has type generic host marked down.

/var/log/GTM

notice gtmd[13764]: 011ae108:5: Prober Selection: no preferred or fallback probers are available    

 

Environment:

  • GTM Server type Generic Host
  • Prober pool assigned to Data Center
  • GTMs with service checking disabled

 

Cause:

  •  In 11.5.x and 12.x its possible for GTM service objects to perform service checking even though it has been disabled in the GTM server object.

The following is an example of service checking turned off.

You can issue the following command to verify: tmsh show gtm server <server name>

    iq-allow-path no

    iq-allow-service-check no

    iq-allow-snmp no

 

  • This behavior has been corrected in 13.x when service checking is set to no, the GTM server object will no longer probe and will log the following messages if no probers are available.

notice gtmd[13764]: 011ae108:5: Prober Selection: no preferred or fallback probers are available    

  

Recommended actions

Enable Service check.

 

Additional Information:

If you need to determine which GTM Server Objects were probing on 11.x or 12 you can enable the following debug:

  • Enable the following commands for five minutes:

tmsh modify sys db log.gtm.level value debug

tmsh modify sys db gtm.debugprobelogging value enable

 

  • Disable after five minutes:

tmsh modify sys db log.gtm.level value notice

tmsh modify sys db gtm.debugprobelogging value disable
