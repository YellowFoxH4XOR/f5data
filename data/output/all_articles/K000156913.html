Description

Combining IPv4 & IPv6 destination addresses for the same virtual server (VS)

Environment

  • Requirement to use the same VS for IPv4 and IPv6 traffic

  • Not wishing to duplicate each VS and apply changes twice

Cause

This is supported using traffic matching criteria (TMC)

Recommended Actions

Configure VS using TMC

Sample configuration:

ltm virtual /Common/ipv4-ipv6-vip {
    ip-protocol tcp
    profiles {
        /Common/tcp { }
    }
    serverssl-use-sni disabled
    traffic-matching-criteria /Common/ipv4-ipv6-vip_VS_TMC_OBJ
    translate-address disabled
    translate-port disabled
}
security protected-servers traffic-matching-criteria /Common/ipv4-ipv6-vip_VS_TMC_OBJ {
    destination-address-inline 0.0.0.0
    destination-address-list /Common/ipv4-ipv6-dest-list
    destination-port-inline 80
    protocol tcp
    source-address-inline 0.0.0.0
    source-address-list /Common/any-src-list
}
net address-list /Common/ipv4-ipv6-dest-list {
    addresses {
        10.16.1.210 { }
        2001::10:16:1:210 { }
    }
}
net address-list /Common/any-src-list {
    addresses {
        0.0.0.0/0 { }
    }
}

Additional Information

Note that example contains workaround for ID749051
