K000150597: The Reconfigure option is empty in iApps from the GUI.

Type
Support Solution
Published
2025-03-28
Updated
2025-03-28
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000150597

Description

The reconfigure option in iApps is not loading or is empty, and the iApp for automated UCS backups is failing. Logs indicate errors such as "No space left on device" and a scriptd daemon crash. The following error messages are observed in the LTM logs:

mv: error writing '/var/local/ucs/<filename>.ucs': No space left on device
WARNING: There are error(s) during saving. Not everything was saved.
Error creating package
Error during config save.
Script (/Common/f5.automated_backup__F5_BKP) generated this Tcl error: script did not successfully complete: (UCS saving process failed.)

 

Environment

iApp for automated UCS backups

 

Cause

The issue occurs due to insufficient disk space in certain partitions (e.g., /var) and a crash of the scriptd daemon caused by Bug ID 842193 when generating UCS archives takes longer than the configured max-script-run-time value.

 

Recommended Actions

1.- Increase Disk Space Monitoring:

  • Check disk usage using df -h from bash shell and ensure that there is sufficient free space in the /var partition.
  • Delete any unnecessary files to free up disk space with the rm command.

 

2.- Restart the Scriptd Daemon:

bigstart restart scriptd

 

3.- Restart the GUI services to recover the Reconfigure Tab:

bigstart restart httpd tomcat restjavad restnoded

Impact: The GUI will not be accessible during the restart of the services mentioned above.
