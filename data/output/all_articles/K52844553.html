Description
BIG-IQ scheduled backups failing for BIG-IP device with error:

Error in GUI:
There was a failure when creating a backup. Additional information: UCS backup with id <ID>, name testtest_f5.localhost_20201221083159.ucs, and referer http://localhost:8100/shared/group-task failed: status:404, body:{"code":404,"message":"Public URI path not registered: /shared/file-transfer/ucs-downloads/testtest_f5.localhost_20201221083159.ucs","referer":"com.f5.rest.common.RestFileReceiver","restOperationId":93631338,"kind":":resterrorresponse"}

Not all of the devices Managed by BIG-IQ are facing this issue

On affected BIG-IP /var/log/icrd.log contains:

Dec 21 12:02:56 f5.localhost notice icrd_child[22243]: 22243,22248,    iControl REST Child Daemon,WARNING,[api-status-warning]: cm/traffic-group: no status; properties: deprecated: cm/traffic-group/ha-group
Dec 21 12:23:19 f5.localhost notice icrd_child[22243]: 22243,22247, RestServer,   INFO,Connection idle too long fd:12

Environment

  • BIG-IQ Centralized Management
  • Scheduled Backups for BIG-IP configured via BIG-IQ
  • No connectivity issues BIG-IQ - BIG-IP
  • No free space issues on /var partition
  • UCS creation working localy on BIG-IP (System -> Archives -> Create)

Cause
ICRD process hanged

Recommended Actions

Restart restjavad service on BIG-IP device
  • In BIG-IP CLI(bash):
    bigstart restart restjavad

Additional Information
None.
