Topic

This article applies to BIG-IP 11.x and later. For information about other versions, refer to the following article:

  • Archived - K11267: Controlling configuration import when performing software installations (10.x)

You should consider using this procedure under the following condition:

  • You want to specify if and where the BIG-IP system should import the configuration during a software installation (this includes Engineering Hotfixes).

Description

When you perform a software installation (including Engineering Hotfixes), by default, the BIG-IP system installs the configuration of the currently active boot location on the target installation location. However, if you perform the software installation using the image2disk utility, you can specify the behavior by using the --nomoveconfig and --nosaveconfig options.

Note: The behavior and the procedures described in this article do not apply to software installations performed in the Maintenance Operating System (MOS) environment.

This behavior was chosen because it is generally desirable for the BIG-IP system to run the same configuration on all of its boot locations. However, there may be cases (for example, in a test environment) in which you want to run a different configuration on each boot location.

You can control if and where the BIG-IP system should import the configuration during a software installation performed using the Configuration utility or Traffic Management Shell (tmsh) by adjusting the value of the following database keys.

Database keyDefault valuePossible valuesDescription
liveinstall.moveconfigenableenable
disable		Specifies whether to install the saved configuration on the target boot location.
liveinstall.saveconfigenableenable
disable		Specifies whether to save the existing configuration before installing.

The following table explains all possible combinations.

Database key combinationBehaviorimage2disk equivalent
liveinstall.moveconfig = enable
liveinstall.saveconfig = enable		The configuration of the currently active boot location will be installed on the target boot location. This is the default behavior.This is the equivalent of performing an installation using the image2disk utility invoked without either the --nosaveconfig or --nomoveconfig option.
liveinstall.moveconfig = disable
liveinstall.saveconfig = enable		The configuration of the target boot location (if any is present) will be re-installed on the target boot location after re-imaging is complete.This is the equivalent of performing an installation using the image2disk utility invoked with the --nomoveconfig option.
liveinstall.moveconfig = enable
liveinstall.saveconfig = disable		No configuration will be installed on the target boot location.This is the equivalent of performing an installation using the image2disk utility invoked with the --nosaveconfig option.
liveinstall.moveconfig = disable
liveinstall.saveconfig = disable		No configuration will be installed on the target boot location.This is the equivalent of performing an installation using the image2disk utility invoked with both the --nosaveconfig and --nomoveconfig options.

You can determine the current values of the two database keys by typing the following tmsh commands in the command line:

tmsh list /sys db liveinstall.moveconfig
tmsh list /sys db liveinstall.saveconfig

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You can access tmsh.

Procedures

  • Specifying the configuration import to use the configuration from the target boot location
  • Specifying no configuration import
  • Specifying the configuration import to use the configuration from the currently active boot location

Specifying the configuration import to use the configuration from the target boot location

To import the configuration from the target installation location (if it exists) during an installation, perform the following procedure prior to performing the software installation:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To specify the configuration import to use the configuration from the target installation location during an installation, type the following commands:

    modify /sys db liveinstall.moveconfig value disable
    modify /sys db liveinstall.saveconfig value enable

  3. Save the change by typing the following command:

    save /sys config

  4. Proceed with performing the software installation using the Configuration utility.

Specifying no configuration import

To specify that no configuration should be imported to the target installation location during an installation, perform the following procedure before you perform the software installation:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To specify no configuration import to the target installation location during an installation, type the following two commands:

    modify /sys db liveinstall.moveconfig value disable
    modify /sys db liveinstall.saveconfig value disable

  3. Save the change by typing the following command:

    save /sys config

  4. Proceed with performing the software installation using the Configuration utility.

Specifying the configuration import to use the configuration from the currently active boot location

By default, the BIG-IP system imports the configuration of the currently active boot location to the target installation location during a software installation. If the database keys have been changed from their default values and you want to import the configuration of the currently active boot location to the target installation location, perform the following procedure before you perform the software installation:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To specify the configuration import to use the configuration from the currently active boot location during an installation, type the following two commands:

    modify /sys db liveinstall.moveconfig value enable
    modify /sys db liveinstall.saveconfig value enable

  3. Save the change by typing the following command:

    save /sys config

  4. Proceed with performing the software installation using the Configuration utility.
