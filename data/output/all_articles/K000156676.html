K000156676: DNS Queries for CAA records fails when configured in irule

Applies to

Source

Description

Attempts to use iRules on BIG-IP DNS to construct and respond to DNS CAA (Certification Authority Authorization, type 257) queries are unsuccessful.

While iRules can generate responses for MX and A record types using the DNS::rr command, this approach does not work for CAA records.

Environment

  • BIG-IP DNS
  • iRules utilizing the DNS_REQUEST event and DNS::rr command to construct dynamic DNS responses

Cause

The DNS::rr command in iRules does not support constructing or returning CAA (type 257) records. There are only certain record types (such as A, MX, etc.) are supported for dynamic response construction via iRules.

Full list of resource records types supported are available at DNS::rr irule page

Recommended Actions

Currently constructing or returning CAA records via iRules using DNS::rr on BIG-IP DNS is not supported. However one can create CAA record type for a zone via Zonerunner.
