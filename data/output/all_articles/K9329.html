Known Issue

This is the result of a known issue. The VIPRION default temperature threshold for the platform.blade.main2.temperature.threshold db key is incorrectly configured for 40C, which is within operating specifications. As a result, the VIPRION reports that the temperature is too high for the blades, although the system is operating within operating temperature specifications.

Note: For more information about technical and operating specifications, refer to the VIPRION Platform Guide.

F5 Product Development is tracking this issue as CR96936.

This issue has been fixed in hotfix BIGIP-9.6.1-HF2, which has been issued for BIG-IP version 9.6.1, for the BIG-IP 9.6 software branch. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 Networks hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.

For information about how to manage F5 Networks product hotfixes, refer to K6845: Managing F5 Networks product hotfixes.

Workaround

Important: Only perform the following procedure after the hotfix has been applied.

After you have applied the hotfix, you can reset the default threshold values to the new default value of 55C. To do so, perform the following procedure:

  1. Log in to the command line.
  2. Reset the platform.blade.main2.temperature.threshold db key by typing the following command:

    bigpipe db platform.blade.main2.temperature.threshold 0

  3. Run the system_check command to update and set the platform.blade.main2.temperature.threshold db key to the new threshold value by typing the following command:

    system_check

  4. Verify the change made to the platform.blade.main2.temperature.threshold db key by typing the following command:

    bigpipe db platform.blade.main2.temperature.threshold

    Output will appear similar to the following example:

    platform.blade.main2.temperature.threshold = 55
