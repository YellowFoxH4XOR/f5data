Description

You want to upgrade your BIG-IP deployed in a cloud environment. For example, the BIG-IP is on an AWS or Azure cloud platform.
This article will explain the high-level steps to take to get your BIG-IP on a new version.

Environment

  • Upgrade BIG-IP
  • BIG-IP is on a cloud platform such as AWS

Cause

 None

Recommended Actions

Before the upgrade, you will need to confirm if the cloud BIG-IP license has 1 boot location or 2 boot location. Refer to this article to identify the license K49243459.

2 boot location

  • Proceed to upgrade the BIG-IP cloud like any BIG-IP by first downloading the ISO file from MyF5 downloads. 

1 boot location

  • BIG-IP with 1 boot location cannot be upgraded. You will need to prepare to deploy a new BIG-IP image with the latest version.
  • You will need to obtain the AWS or Azure BIG-IP image from MyF5 downloads or the respective marketplaces.
  • Refer to chapters 13 through 20 of the BIG-IP upgrade guide K84205182.
  • Deploy the BIG-IP instance in your cloud environment.​​​​​​​

Additional Information

For steps to download the ISO file, refer to this article: K44114313: How to download an F5 ISO file.
