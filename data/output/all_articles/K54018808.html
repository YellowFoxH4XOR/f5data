Known Issue

The Simple Mail Transfer Protocol (SMTP) Test Connection button in the Configuration utility erroneously reports that the SMTP server is available.

This issue occurs when the following condition is met:

  • To validate that the SMTP server is available, you click the Test Connection button in the SMTP configuration section of the BIG-IP Configuration utility.

When you click the Test Connection button, the Configuration utility always displays a green OK response, even when there is no network connectivity or the DNS response is NXDOMAIN.

Impact

The Configuration utility reports incorrect information regarding the availability of the SMTP server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When using the Test Connection button, you observe that a packet capture displays NXDOMAIN results, yet the Configuration utility reports that the SMTP server is available.

    For example:

Workaround

To work around this issue, you can test the SMTP server from the BIG-IP command line. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Send a test email to the SMTP server using the following command syntax:

    echo -e "Subject: Test message\n\nTest message" | ssmtp -v <valid recipient email address>

    For example, to send a test message to the email address user@example.com, type the following command:

    echo -e "Subject: Test message\n\nTest message" | ssmtp -v user@example.com
