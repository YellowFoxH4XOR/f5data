Description

dwbld log showing "Invalid blacklist category name format" and may not be acting on the specified entry to block or allow traffic

Example:
/var/log/dwbl/dwbld.log
...
dwbld| err|<date/time>|<pid>|BLOB|process_line|(null)|Discarded line <IP address>,,wl,<list name with whitespace>; error: Invalid blacklist category name format
dwbld| err|<date/time>|<pid>|BLOB|process_line|(null)|Discarded line <IP address>,,wl,<list name with whitespace>; error: Invalid blacklist category name format

Environment

  • BIG-IP
  • IP Intelligence Feedlist

Cause

The fourth element in the feedlist entries is intended to identify which blacklist category the entry should be associated with. Using values other than the blacklist category names may result in a validation failure.
Note: Refer to Related Content for more information on valid blacklist category names

Recommended Actions

Review feedlist entry and verify that the value in the last field is either blank or is a valid blacklist category name
