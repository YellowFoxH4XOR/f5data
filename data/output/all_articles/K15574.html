Known Issue

The Traffic Management Microkernel (TMM) process may produce a core dump and restart. This issue occurs when all of the following conditions are met:

  • Denial-of-service (DoS) sweep and flood attack prevention is enabled on the affected BIG-IP system.
  • The affected BIG-IP system supports the multi-threaded TMM model. For a list of BIG-IP platforms that support the multi-threaded TMM model, refer to K14358: Overview of Clustered Multiprocessing (11.3.0 and later)

This issue occurs because one TMM thread may attempt to access the memory released by another TMM thread, due to a race condition. As a result, the TMM process cores dump and restart.

Impact

The BIG-IP system may temporarily fail to process traffic, and fail over if configured as part of a high-availability pair.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system fails over to another system in the device group.
