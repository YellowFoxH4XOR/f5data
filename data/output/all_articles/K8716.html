Known Issue

This is the result of a known issue. The alertd process will crash when parsing log files with characters appended to the .gz extension.

For example:

log.gz_foo

The alertd process will crash if it attempts to parse the example .gz_foo extension.

Log files are routinely rotated in an effort to save space. When the log file rotates, it is compressed using the gzip utilty. If a user creates a log file, compresses the log, and adds additional information to the extension, the alertd process will crash when it attempts to parse the log file.

F5 Product Development tracked this issue as CR90332 and it was fixed in BIG-IP 9.4.4. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, Link Controller, and WebAccelerator Release Notes.
