K604: After initial configuration of the 3-DNS Controller, auto-configuration may not add all virtual servers

Type
Knowledge
Published
2006-02-12
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • 3-DNS: 4.6.4
Source
https://my.f5.com/manage/s/article/K604

Topic

This is the result of a known issue. If you do not run auto configuration when you configure 3-DNS for the first time, but run it after the initial configuration is complete, auto configuration may not add all of the virtual servers on the associated BIG-IP.

F5 Product Development tracked this issue as CR33161 and CR41847.
