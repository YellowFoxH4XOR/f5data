Topic

Microsoft Windows XP Service Pack 2 includes a number of changes that affect the FirePass controller's features and performance.

Changes were introduced in Service Pack 2 that affected the handling of network connections to the loopback interface. Previously, Windows XP permitted connections to loopback IP addresses from 127.0.0.1 to 127.255.255.255. With Service Pack 2, however, only connections to 127.0.0.1 are permitted.

Two types of FirePass Applications Access favorites, App Tunnels and Terminal Servers, use loopback addresses from 127.0.0.1 to 127.255.255.255. After installing Service Pack 2, App Tunnels and Terminal Servers favorites will fail to launch, and will instead display a pop-up with the error text configured on the Application Access: Global Settings page.

Additionally, if you are using a version of FirePass software prior to version 5.2, Network Access, App Tunnels and Terminal Servers favorites will also fail when launched, and a generic error message will be displayed.

If you experience these symptoms after installing Service Pack 2, you will need to obtain the Update for Windows XP Service Pack 2 (KB884020) from Microsoft, and install the Update on each Windows XP SP2 client system that uses FirePass. For detailed information about this update, refer to the following Microsoft Knowledge Base article:

http://support.microsoft.com/?id=884020

The update contains a single file, Tcpip.sys. The version number of the updated Tcpip.sys file is 5.1.2600.2505.

Note: You may not need to install this update if additional updates will be applied to the Windows XP SP2 clients. A number of updates available through the Windows Automatic Update Service (or available as manual updates similar to the KB884020 update ) contain the version of the Tcpip.sys file that is required to resolve this issue.

To determine which version of the Tcpip.sys file is on your system, perform the following steps:

  1. Open a Windows Explorer window.
  2. Navigate to the %windir%\SYSTEM32\DRIVERS directory.
  3. Right-click on the Tcpip.sys file and select Properties.
  4. Click on the Version tab, and locate the File Version field to determine which version of the Tcpip.sys file is on your system.

If the version of the Tcpip.sys file is a number greater than 5.1.2600.2505, and you are not experiencing the error messages described, you do not need to install the KB884020 update.

If you experience the symptoms described above even if you have installed the KB 884020 update, or if you have a newer version of the Tcpip.sys file, contact F5 Networks Technical Support.
