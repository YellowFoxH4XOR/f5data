Description
This document describes a method to compute the rest_uuid from the ASM policy name.

Environment
  • BIG-IP ASM
  • Security Policies
  • Administrator access to the iControl REST interface

Recommended Actions

Manually Generating the rest_uuid for a Given Policy

The rest_uuid name can be computed in the following manner:
  1. Create the binary-represented MD5 digest from the policy name (yields 128 bits of data)
  2. Encode it using base64 (yields 24 characters)
  3. Trim the last two "==".
  4. Replace "+" and "/" to "-" and "_" respectively (to make the string URI-safe).

The following bash example converts the policy name /Common/sat to rest_uuid.

echo -n /Common/sat | openssl dgst -md5 -binary | base64 | cut -c-22 | sed 'y/+\//-_/'
9afAWDUoawpiNnfSfSGtMQ

Additional Information

To manipulate an ASM policy using iControl REST, you need to specify the hashed ID called rest_uuid instead of the Policy Name.
To obtain the configuration of the policy /Common/sat (equivalent to tmsh list asm policy sat), you need to execute the following curl command:

curl -sku <user>:<passwd> https://<hostname>/mgmt/tm/asm/policies/9afAWDUoawpiNnfSfSGtMQ
Note: The rest_uuid is 22 characters long, consisting of alphanumerics ([A-Za-z0-9]), "+" and '_'.

You can find the mappings between policy name and rest_uuid from a GET request to the /mgmt/tm/asm/policies endpoint.
The call yields an array of policies (items:[ ...]).
Each element contains versionPolicyName and id properties, which represent the policy name and rest_uuid  respectively.

An example curl call is shown below:

curl -sku <user>:<passwd> https://<hostname>/mgmt/tm/asm/policies?\$select=id,versionPolicyName
{
    "items": [
        {
            "id": "9afAWDUoawpiNnfSfSGtMQ",
            "kind": "tm:asm:policies:policystate",
            "selfLink": "https://localhost/mgmt/tm/asm/policies/9afAWDUoawpiNnfSfSGtMQ?ver=13.1.1",
            "versionPolicyName": "/Common/sat"
        }
    ],
    "kind": "tm:asm:policies:policycollectionstate",
    "selfLink": "https://localhost/mgmt/tm/asm/policies?$select=id%2CversionPolicyName&ver=13.1.1",
