Description

There is a while loop process running in the background. This will/might cause high CPU utilization or a file to increase in size.

Stopping the process will resolve the high CPU utilization and file size increase.

For example, below is a TOP snapshot while loop script to capture TOP output and several other output /var/tmp/top1.out. This will cause /var/tmp/top1.out to increase in size.
while :; do date >> /var/tmp/top1.out; top -cbn 1 >> /var/tmp/top1.out; tmsh show sys tmm-info >> /var/tmp/top1.out; echo "###################" >> /var/tmp/top1.out; sleep 10; done

Environment

  • BIG-IP
  • while loop is running in the background
  • Might cause high CPU utilization or file size to increase

Cause

None.

Recommended Actions

You will need to find the PPID of the while loop script and kill it. After killing the while loop stop the high CPU and the file size increment.

  1. A while loop will consist of one or more command execution. You will need to identify the while loop PPID from these commands execution. As per the while loop in the Description, these are the executed commands:
    - date
    - tmsh show sys tmm-info
    - echo "###################"
    - sleep 10

    For an example, we will check for PPID based on sleep command.
     
  2. To view the PPID, you will need to run the following command and refer to column four.
    ps alx

    Refer below for the output:
    ps alx | head
    F   UID   PID  PPID PRI  NI    VSZ   RSS WCHAN  STAT TTY        TIME COMMAND        Note: PPID
    4     0     1     0  20   0   2900   988 -      Ss   ?          0:01 /sbin/init
    1     0     2     0  20   0      0     0 -      S    ?          0:00 [kthreadd]
    1     0     3     2 -100  -      0     0 -      S    ?          0:02 [migration/0]
    1     0     4     2  20   0      0     0 -      S    ?          0:58 [ksoftirqd/0]
    1     0     5     2 -100  -      0     0 -      S    ?          0:00 [migration/0]
    5     0     6     2 -100  -      0     0 -      S    ?          0:00 [watchdog/0]
    1     0     7     2 -100  -      0     0 -      S    ?          0:02 [migration/1]
    1     0     8     2 -100  -      0     0 -      S    ?          0:00 [migration/1]
    1     0     9     2  20   0      0     0 -      S    ?          3:10 [ksoftirqd/1]
     
  3. Login to the BIG-IP Command Line.
     
  4. To view the PPID which is executing sleep command, run command:
    ps alx | grep -i sleep
    0     0 13412 13389  20   0   5212   520 -      S    pts/1      0:00 sleep 10            Note the 'sleep' process
    0     0 13414  6959  20   0   5564   812 -      S+   pts/0      0:00 grep -i sleep

    The output above shows that sleep command's PPID is 13389.
    Since the executed command is within a loop, it might not appear immediately as the while loop might be executing another command. You might need to run the ps alx command several times until the command you want appears.
     
  5. Kill the PPID with the command below:
    kill -9 <PPID>

    To kill PPID 13389, run the following command:
    kill -9 13389

None.
