Description

You may want to send a test trap for SNMPv1.

Environment

  • BIG-IP LTM

Cause

None

 Recommended Actions

Use the following command syntax to send a SNMP trap from the BIG-IP to a destination device:

snmptrap -v 1 -c public <host> '' '' '' '' '' netSnmpExamples s "test"

Note: Replace <host> with the destination host IP address that you want to send the snmp trap.
