K72536100: IPI is not dropping malicious traffic and logs are not logged locally after BIG-IP software upgrade

Type
Support Solution
Published
2022-08-02
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.X, 15.1.8, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 15.1.7
  • BIG-IP AFM: 15.1.0, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.X
Source
https://my.f5.com/manage/s/article/K72536100

Description
IPI (IP Intelligence) is not dropping malicious traffic as per IPREP database and IPI logs are not logged locally in the device after BIG-IP software upgrade.

Environment

  • Active IPI Subscription License in BIG-IP device
  • BIG-IP AFM or BIG-IP ASM 
  • IP intelligence logs are not logged locally
  • Issue is noted after upgrade from previous version such as v13.x, v14.x

Cause

Bug ID 1107689

Recommended Actions

Upgrade BIG-IP device to 15.1.6.1 to resolve this issue

Additional Information

None
