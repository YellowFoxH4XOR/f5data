Description

Unable to configure hard disk encryption check for MacOS clients using FileVault

Environment

  • MacOS 11.x onwards 
  • APM client 7.2.x or greater (required for Big Sur support)
  • OPSWAT epsec versions
  • Hard disk encryption check is configured in the Access Policy

Cause


Client Devices using MacOS 12 or later always have their boot disk encrypted at rest. Enabling or disabling FileVault now only changes how the encryption keys are managed on the device or in the Cloud.

Clients running macOS 11 (Filevault version 11.x) and older APM OPSWAT versions do not give option to configure Hard disk encryption check for Filevault 11.x (only 10.x) so as a result users were not able to connect when this was set.


Recommended Actions

OPSWAT always reports the disks as encrypted and ignores the FileVault setting for supported MacOS clients. The disk encryption check now provides no useful value and can be removed from the MacOS branch of your Access Policy.

Upgrading to the latest epsec version is always recommended.

Additional Information

Recent OPSWAT versions can be downloaded from MyF5
