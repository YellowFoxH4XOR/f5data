K000162428: Missing API protection dashboard on BIG-IQ

Type
Support Solution
Published
2026-08-27
Updated
2026-08-27
Applies to
  • BIG-IQ
  • F5 Distributed Cloud Services
Source
https://my.f5.com/manage/s/article/K000162428

Description

API Protection metrics, including rate-limit statistics, server health, proxy rejections, and response-time ranges, were visible on BIG-IP but were not available after the device was onboarded to BIG-IQ. You are able to view policy logs in BIG-IQ but could not find an equivalent API Protection dashboard.

Environment

  • BIG-IQ
  • BIG-IP devices onboarded to BIG-IQ
  • API Protection enabled through BIG-IP APM

Cause

Missing API Protection metrics are by-design architectural limitatio. BIG-IQ does not provide an equivalent API Protection dashboard or ingest these BIG-IP APM proxy metrics.

Answer/Recommended Actions

Use the BIG-IP APM interface to view API Protection metrics such as rate limits, server health, proxy rejections, and response-time ranges.
