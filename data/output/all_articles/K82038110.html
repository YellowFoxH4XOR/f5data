Topic

The /defaults/BigDB.dat file includes descriptions for many BIG-IP BigDB database keys.

Description

The BigDB database contains a set of BigDB configuration keys that define the behavior of various aspects of the BIG-IP system. When you work with BIG-IP devices, and you want more information about a specific database key, you can review the /defaults/BigDB.dat file. Many of the database key entries include a short description.

Example

For more information about the TM.TCPSackGlobalMaxHoles database key, you can locate the key in the /defaults/BigDB.dat file by using a Linux utility such as less or grep as displayed in the following example:

Note: In the BigDB.dat file, the description of the key precedes the key. The following grep example uses -B to print (5) lines before the matching line.

grep -i -B 5 TCPSackGlobalMaxHoles /defaults/BigDB.dat
#
# Global maximum number of selective acknowledgement holes
# allowed in the TCP SACK scoreboard.
# This may be increased to handle LFP deployments.
#
[TM.TCPSackGlobalMaxHoles]

Recommendations

F5 recommends that you avoid modifying BIG-IP database keys unless you are instructed to do so by F5 Support, or you are doing so for troubleshooting purposes.
