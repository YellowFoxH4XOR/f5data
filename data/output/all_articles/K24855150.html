K24855150: BIG-IQ config validation fails if Citrix client bundle includes filenames with ''@'' character

Type
Support Solution
Published
2020-07-09
Updated
2025-02-06
Status
Legacy Content
Applies to

  • BIG-IP
Source
https://my.f5.com/manage/s/article/K24855150

Description
BIG-IQ import of BIG-IP APM configuration fails validation when the configuration contains a Citrix client bundle that includes files with the "@" character

Environment

  • BIG-IP APM Citrix client bundle configuration containing files with the "@" character
  • BIG-IQ import and validation of the BIG-IP APM Citrix client bundle configuration 

Cause
This is due to a bug with the BIG-IQ failing configuration validation if filenames contain "@" character. F5 is tracking this as bug ID 913121.

Recommended Actions

Either exclude, remove, or rename files containing the "@" character from the Citrix client bundle.
