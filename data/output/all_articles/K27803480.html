Description

An iRule can be used to select a specific Pool or Pool-member based on the client's HTTP Request URI contents. This can be helpful when you want to direct certain client HTTP Requests to a different Pool than the Virtual Server's configured Default Pool, or to a specific Pool-member of a Pool, whether a member of the Default Pool or a different Pool.

Environment

  • BIG-IP
  • You want to direct specific client HTTP request to a specific non-default pool or specific pool member.
  • iRules

Cause

You need to select a non-default Pool or Pool-member for certain client HTTP Request URI's instead of sending to the default pool configured for the virtual server.

Recommended Actions

  1. Create a new iRule similar to one of the two iRules below, depending on whether Pool or Pool-member selection is needed:

    Note: The iRule examples described below are meant to redirect traffic to a specific pool or pool member when the HTTP URI matches the criteria. If the HTTP URI does not match the criteria, the traffic will be directed to the pool or pool member in the final else statement.

    • Pool selection iRule example:

    ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
    when HTTP_REQUEST {
          if { [HTTP::uri] contains "*.css*" }{
        pool css_pool
      } elseif { [HTTP::uri] contains "*.jpg*" }{
        pool jpg_pool
      } else {
        pool html_pool
      }
    }
    ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

    • Pool-member selection iRule example:

    ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
    when HTTP_REQUEST {
      if { [HTTP::uri] contains "*.css*" }{
        pool css_pool member 10.10.10.10 80
      } elseif { [HTTP::uri] contains "*.jpg*" }{
        pool jpg_pool member 10.10.10.20 80
      } else {
        pool html_pool member 10.10.10.30 80
      }
    }
    ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

    Note: The Port# follows the Pool-member IP above.

  2. Assigned the new iRule to the pertinent Virtual Server.

Additional Informational

For pool selection predictability, F5 recommends that you always apply a OneConnect profile to the virtual server assigned with the pool or pool member selection iRules. For more information, refer to K9800: Using an iRule to load balance HTTP requests to multiple pools.
