K000134784: How to get the Device management IP, Device Groups and Device Group names of each big-ip device managed by BIG-IQ via Rest API

Type
Support Solution
Published
2023-05-25
Updated
2023-05-25
Source

Description

Get via Rest API Device management IP, Device Groups and Device Group name of each BIG-IP device managed by BIG-IQ CM

Environment

  • BIG-IQ CM
  • BIG-IP
  • Rest API

Cause

None

Recommended Actions

If the BIG-IP devices were discovered on BIG-IQ CM on Devices -> BIG-IP CLUSTERS -> DSC Groups, you can get the device-group details running the following request on Postman

GET request on Postman to: https:///mgmt/cm/device/dsc-group

Additional Information

None
