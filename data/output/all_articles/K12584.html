Issue

In BIG-IP 9.0.0 through 10.0.1, the bigdbd process communicates the initial values from the BigDB.dat configuration database to the mcpd process, and pushes any changes to the bigdb values to the BigDB.dat database.

Starting in BIG-IP 10.1.0, the mcpd process has taken over the bigdbd functionality, and the bigdbd process was removed from BIG-IP software.

This change was made as a result of ID 205344.
