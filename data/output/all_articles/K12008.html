Issue

When a user employing RSA SecurID authentication fails to present any password, or an invalid password during the login process, the following error message will appear in the /var/log/apm file:

SECURID Agent: getSecuridUserInput(): invalid user password ciphertext

You can correct this error message by asking the user to confirm their credentials with their RSA SecurID administrator, and attempt to log in again.
