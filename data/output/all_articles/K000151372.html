K000151372: Nginx App Protect generates an error message "Could not add the '/policy/login-pages' element. A valid URL must be specified" when a login URL is defined

Type
Support Solution
Published
2025-05-15
Updated
2025-09-30
Source
https://my.f5.com/manage/s/article/K000151372

Description

Nginx App Protect generates an error message "Could not add the '/policy/login-pages' element. A valid URL must be specified" when a login URL is defined in the policy.

Environment

  • Nginx App Protect configured and enabled

  • Login URL is defined in the policy.

  • Reloading Nginx

  • Error Message: nginx: [error] APP_PROTECT {"error_message":"Failed to import policy 'BruteForcePolicy' from '/etc/app_protect/conf/bruteforce.json': Could not add the '/policy/login-pages' element. A valid URL must be specified","softwareVersion":"4.14.0","event":"configuration_load_failure","completed_successfully":false,"componentVersions":{"wafEngineVersion":"11.336.0","wafNginxVersion":"5.342.0"},"error_line_number":20}

Cause

The policy has a login URL defined but is missing a user-defined URL in the policy.

Answer/Recommended Actions

A user defined URL is configured under the policy json key and looks like the following example:

{
  "policy": {
    "name": "BruteForcePolicy",
    "template": {
      "name": "POLICY_TEMPLATE_NGINX_BASE"
    },
    "applicationLanguage": "utf-8",
    "enforcementMode": "blocking",
    "urls": [
      {
        "method": "*",
        "name": "/html_login",
        "protocol": "http",
        "type": "explicit"
      }
    ]
  }
}

A login URL is configured under the policy json key and looks like the following example:

    "login-pages": [
      {
        "accessValidation": {
          "responseContains": "Success"
        },
        "authenticationType": "form",
        "url": {
          "method": "*",
          "name": "/html_login",
          "protocol": "http",
          "type": "explicit"
        },
        "usernameParameterName": "username",
        "passwordParameterName": "password"
      }
    ]

 

The following example is a well defined policy that includes the login page and user-defined URL objects above.
Both the user-defined URL and login URL must have the same name.

{
  "policy": {
    "name": "BruteForcePolicy",
    "template": {
      "name": "POLICY_TEMPLATE_NGINX_BASE"
    },
    "applicationLanguage": "utf-8",
    "enforcementMode": "blocking",
    "urls": [
      {
        "method": "*",
        "name": "/html_login",
        "protocol": "http",
        "type": "explicit"
      }
    ],
    "login-pages": [
      {
        "accessValidation": {
          "responseContains": "Success"
        },
        "authenticationType": "form",
        "url": {
          "method": "*",
          "name": "/html_login",
          "protocol": "http",
          "type": "explicit"
        },
        "usernameParameterName": "username",
        "passwordParameterName": "password"
      }
    ]
  }
}
