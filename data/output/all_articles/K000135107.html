K000135107: systemd-private-* files populate /var/tmp directory

Type
Support Solution
Published
2023-06-23
Updated
2023-06-23
Source
https://my.f5.com/manage/s/article/K000135107

Description

After upgrade to 16.1.2.2 you may notice that directories like below started appearing in /var/tmp directory:

systemd-private-16c4aa6e4e1c4e089392328b9d330da1-jitterentropy-rngd.service-TifiAG
systemd-private-7719ed51c7c842d289248a264090008f-jitterentropy-rngd.service-FHfN9z
systemd-private-954bfef8f50046e192as2sb8d643e16e-jitterentropy-rngd.service-IuY09A

Environment

  • BigIP filesystem
 

Cause

After upgrade to 16.1.2.2 jitterentropy-rngd service started using systemd private tmp directories as a security improvement. During normal operation these directories should be cleaned up by systemd if there are not needed e.g. process shutdown. However you might notice some orphaned directories if systemd had no chance to clean up e.g. unexpected reboot.
 

Recommended Actions

No action required.
 

Additional Information

For additional information about this systemd security improvement please see "PrivateTmp" description in https://man7.org/linux/man-pages/man5/systemd.exec.5.html
