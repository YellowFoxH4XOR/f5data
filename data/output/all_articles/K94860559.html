Description

When scanning a BIG-IP appliance with Qualys the following vulnerability is reported:
Deprecated SSH Cryptographic Settings, Qualys Vulnerability: QID: 38739

Environment

  • Qualys vulnerabilities scan

  • SSH ciphers

Cause

3DES needs to be disabled in order to overcome this "Deprecated SSH Cryptographic Settings" vulnerability.

Recommended Actions

If you determine that 3DES is not needed in your environment, you can disabled it by following the next steps.

  1. Check the output of the below command and see if 3des-cbc is listed:

egrep -i 'MACS|Ciphers' /config/ssh/sshd_config


If 3des-cbc is listed, follow next steps to disable 3DES.

For example, the following output indicates 3des-cbc is being used:
MACS hmac-sha1
# This set of ciphers should be consistent with 'SSHD_CIPHERSTRING' defined in
Ciphers aes128-cbc,aes256-cbc,aes128-ctr,aes192-ctr,aes256-ctr,aes192-cbc,3des-cbc

  1. Log in to command line tmsh.

  2. Use the following command to edit sshd settings (the interface uses vi):

edit /sys sshd all-properties

  1. Modify the include lines to remove 3des-cbc cipher, same as the following example:

include "Ciphers aes128-cbc,aes256-cbc,aes128-ctr,aes192-ctr,aes256-ctr,aes192-cbc"

  1. Save the changes for the sys sshd configuration and exit the vi editor.

  2. Respond y to the prompt asking to save the changes.

  3. To save the configuration to disk, type the following command:
    save /sys config

Additional Information

As specified in the /config/ssh/sshd_config file, entries such as 'Ciphers' or 'Protocol' may appear more than once within the file, however only the first instance (from the top-down) are honored:
