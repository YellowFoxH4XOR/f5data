Description

How to export a list of all configured HTTP Load Balancers (LB) in a tenant as a CSV file from the F5 Distributed Cloud Console.

Environment

  • F5® Distributed Cloud (XC) Console

Cause

You need to export a list of all configured HTTP Load Balancers in a tenant.

Answer/Recommended Actions

To generate a CSV file containing the current configuration details of your HTTP Load Balancers:

  1. Navigate to Web App & API Protection within your tenant.

  2. Select the system namespace.

  3. Go to the Performance tab.

  4. Scroll to the bottom of the dashboard to locate the HTTP Load Balancer section.

  5. Click the LB List button.

  6. Use the Download CSV option to export the list of Load Balancers.
