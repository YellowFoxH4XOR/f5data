K000151632: API Endpoint shows Authentication state as [Unknown]

Published

Updated

Description

Why does the API endpoint show an Authentication state as [Unknown] in the XC console dashboard?

  

 

Environment

  • F5® Distributed Cloud (SaaS)
  • F5® Distributed Cloud Load Balancer
  • API Discovery
  • API Protection

 

Cause

  1. If insufficient legitimate traffic has been observed, the engine can't yet determine the authentication status of the API endpoint.
  2. An endpoint may remain "unknown" state for an extended period due to sampling or truncation of request data.

 

Answer/Recommended Actions

"Unknown" authentication state means that the discovery process could not determine if the API endpoint requires authentication or not, which can be caused by not having sufficient amount of valid samples for authentication detection, or time for making the decision.

API Endpoint Discovery is a heuristic engine that qualifies requests as legitimate before using content for discovery purposes.  Due to this and other factors, there is no static threshold of minimum requests to qualify the authentication discovery.  If the endpoint remains in [Unknown] authentication state for an extended period, try generating more legitimate traffic to it.
