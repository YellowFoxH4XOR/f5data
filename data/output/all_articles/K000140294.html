Description

The Open Web Application Security Project (OWASP) Top 10 defines the most serious web application security risks, and it is a baseline standard for application security. For more information refer to the OWASP Top 10 - 2021.

The BIG-IP Advanced WAF / ASM system includes the OWASP Compliance Dashboard utility. The OWASP dashboard allows you to view your configured security policies along with the policy's coverage for each of the OWASP Top 10 web application vulnerabilities, improve coverage for the policy and perform configuration changes. When you use the OWASP dashboard you can select a security policy and view details about the policy's current compliance statistics. You can then choose to enforce or ignore each web application security risk component according to your security requirements for each policy.

Prerequisites

You have access to the BIG-IP configuration utility.

Procedures

View the OWASP compliance score for each security policy

The OWASP compliance score is a numeric scale from 0 (non-compliant) to 10 (fully compliant) assigned to each policy on the system. In general, a newly created policy have a low compliance score, such as 0 / 10, whereas an established policy may have a higher compliance score. The score gives you an overview of the compliance status for each of your policies. To view the current OWASP compliance score for your security policies, perform the following steps:

  1. Log into the Configuration utility.
  2. Go to Security > Overview > OWASP Compliance.
  3. Review the Compliance Rate column and the score assigned to each security policy.
  4. If one or more of your policies has a low compliance score, proceed to the next procedure for information about improving the score.

Improve the OWASP compliance score for your security policies

Each OWASP vulnerability lists relevant policy components. A vulnerability lists one or more of the following components that may require attention:

  • Required Attack Signatures Types: The number of attack signatures in staging and enforced are listed.
  • Required Protections: Informative only.
  • Required Policy Entities: Each entity includes a link to where it is configured in the security policy.
  • Required Virtual Server Protection: Each virtual server reference includes a link to where it is configured on the system.
  • Best Practices: Informative only.

To improve the current OWASP compliance score for your security policies, perform the following steps:

  1. Log into the Configuration utility.
  2. Go to Security > Overview > OWASP Compliance.
  3. Select the name of a security policy.
  4. On the right-hand side of the dashboard, select a OWASP vulnerability (for example, A1 Broken Access Control) and review the following:
    • A description of the OWASP vulnerability.
    • The current compliance score.
    • One or more of the following policy mitigations:
      • Required Attack Signatures Types
      • Required Protections
      • Required Policy Entities
      • Required Virtual Server Protection
      • Best Practices
  5. Hover over the right of the mitigation and choose either Ignore Requirement or Enforce Requirement.
  6. Note that the compliance score updates after selecting a mitigation.
  7. Repeat steps 4-5 for each OWASP vulnerability.
  8. Select Review and Update.
  9. Select Save and Apply.
