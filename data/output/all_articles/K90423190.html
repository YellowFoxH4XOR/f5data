Known Issue

Memory corruption may occur when using BIG-IP APM Security Assertion Markup Language (SAML) single sign-on (SSO).

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured as a SAML service provider (SP).
  • An external Identity Provider (IdP) sends a single logout (SLO) request.

Impact

As a result of memory corruption, the BIG-IP APM system may experience traffic disruptions or a failover event if configured for high availability (HA).

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Traffic is disrupted while the Traffic Management Microkernel (TMM) restarts.
  • The BIG-IP APM system fails over if configured for HA.
  • The system generates a core file in the /shared/core/ directory.
