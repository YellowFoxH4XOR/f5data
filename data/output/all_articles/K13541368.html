Description

You configured Virtual server with HTTP/2, HTTP, and client/server SSL profiles (with renegotiation disabled)
Later, you modify the client/server SSL profiles with 'TLS Renegotiation' enabled and got configuration load fails with an error:

0107186b:3: Invalid "enforce-tls-requirements" value for profile <http2 profile name>. In Virtual Server <virtual server name> an http2 profile with enforce-tls-requirements enabled is incompatible with client-ssl/server-ssl profile with renegotiation enabled. Value must be disabled

Environment

  • HTTP/2 profile with enforce-tls-requirements enabled
  • Server SSL profile or Client SSL profile with renegotiation enabled

Cause
Bug ID 1008017: Validation failure on Enforce TLS Requirements and TLS Renegotiation

Recommended Actions

If the Enforce TLS Requirements is enabled in the HTTP/2 profile of a virtual server, ensure that Renegotiation is disabled in the Client/Server SSL profiles of the virtual server. For example to disable Renegotiation in the Client SSL profile:

1. On the BIG-IP GUI, navigate to Local Traffic > Profiles > SSL > Client
2. Click on the desired Client SSL profile
3. Under Renegotiation, select the custom check box and deselect the Enabled checkbox to disable.
