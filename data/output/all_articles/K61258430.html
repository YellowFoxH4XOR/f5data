Known Issue

The BIG-IP system may fail to create a node using the FQDN (Fully Qualified Domain Name) option

This issue occurs when all of the following conditions are met:

  • The BIG-IP system has a DNS Lookup Server entry configured.
  • The BIG-IP system does not have a default management route configured.

Impact

You cannot create a BIG-IP node using the FQDN option.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You fail to create a node on the BIG-IP system using the FQDN option, and the system displays an error message similar to the following example:

    01070734:3: Configuration error: Please configure a default gateway.

Resolution

Status

F5 Product Development has assigned ID 490171 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Note: This issue was fixed in 11.6.0 HF5. However, there is another known issue in 11.6.0 HF5 pertaining to FQDN node creation; for more information, refer to K17537: The BIG-IP system fails to create node IP addresses when choosing the FQDN option

To work around this issue, you can temporarily create a default management route, and delete the route after performing the required task. To do so, perform the following procedure:

Impact of workaround: F5 recommends that you perform this procedure using serial console access to the BIG-IP system, as making changes to the management gateway setting may cause you to lose connectivity.

  1. Log in to the Traffic Management Shell (tmsh) utility by typing the following command:

    tmsh

  2. Create a default management route by using the following command syntax, where <x.x.x.x> is the IP address of the management gateway:
    create /sys management-route default gateway <x.x.x.x>
  3. Create an FQDN node by using the following command syntax, where <mydomain.com> is the FQDN node name:
    create /ltm node <mydomain.com> fqdn { name <mydomain.com> }
  4. Remove the temporary management route by typing the following command:
    delete /sys management-route default
