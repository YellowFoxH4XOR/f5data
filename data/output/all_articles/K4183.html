K4183: Configuring BIG-IP to limit connections to a node based on the rate of requests rather than the number of concurrent requests

Topic

In previous versions, BIG-IP was able to limit connections based only on the number of concurrent connections to a node. Starting in version 4.6.3, you can configure BIG-IP to limit connections to a node based on the rate of incoming connections. This feature is known as connection rate dynamic ratio.

When you use connection rate dynamic ratio, you configure a rate limit for each pool. When any member node in a pool reaches the rate limit, BIG-IP stops sending connections to it.

You should use connection rate dynamic ratio if your server's optimal performance is achieved when the number of connections it handles is less than the maximum it can handle.

Connection rate dynamic ratio is disabled by default.

Enabling connection rate dynamic ratio

You can enable connection rate dynamic ratio using the Configuration utility or the command line.

Configuration utility

To enable connection rate dynamic ratio using the Configuration utility, perform the following steps:

  1. From the Configuration utility menu, click System.
  2. Click the Advanced Properties tab.
  3. In the BIG-IP section, click the checkbox next to measure_conn_rate.
  4. From the Configuration utility menu, click Pools.
  5. Click the pool you want to modify.
  6. From the Load Balancing Method menu, click Connection Rate Dynamic Ratio.
  7. In the resources section, remove each member from the pool and then re-add each member, specifying the connection limit for that node in the Rate Limit field.

Connection rate dynamic ratio is now configured.

Command line

To enable connection rate dynamic ratio using the command line, perform the following steps:

  1. Enable the connection rate load balancing global variable, by typing the following command:

    bigpipe global measure_conn_rate enable

  2. Enable connection rate dynamic ratio for the pool, by typing the following command:

    bigpipe pool <pool name> lb_method conn_rate_dynamic_ratio

    For example:

    bigpipe pool AskF5Pool lb_method conn_rate_dynamic_ratio

  3. Set the connection limits for each node, by typing the following command:

    bigpipe pool <pool name> add { member <ip:port> conn_rate_limit <value> }

    For example:

    bigpipe pool AskF5Pool { member 10.90.100.1:80 conn_rate_limit 10 }

Connection rate dynamic ratio is now configured.

Displaying connection rate limits

To view the connection rate limit information for pools use the bigpipe virtual show or bigpipe pool show command.

For example, for the bigpipe pool show command, the output appears similar to the following:

POOL AskF5Pool LB_METHOD conn_rate_dynamic_ratio
|        (cur, max, limit, tot) = (0, 0, 0, 0)
|        (pckts,bits) in = (0, 0), out = (0, 0)
|        (rate, rate_limit) = (0, 20)
+-- MEMBER 10.90.100.1:http              ACTIVE,UNCHECKED  DYNAMIC RATIO 20
(cur, max, limit, tot) = (0, 0, 10, 0)
(pckts,bits) in = (0, 0), out = (0, 0)
(rate, rate_limit) = (0, 20)
