Known Issue

This is the result of a known issue. Web Application Tunnel favorites that use the Locked Browser feature fail when launched inside Protected Workspace on Microsoft Vista clients. The Locked Browser feature is enabled by selecting the Locked Browser check box in the Web Application Tunnel's configuration section, on the Application Access: App Tunnels: Resources page.

The Locked Browser feature starts the Web Application Tunnel favorite in a minimal-function browser, which prevents navigation to sites outside the target of the favorite. When using this feature on a Microsoft Vista client inside Protected Workspace, the Locked Browser appears, but does not load the web page that is configured in the favorite. Instead, the window is blank.

F5 Networks Product Development tracked this issue as CR85859 and it was fixed in FirePass version 6.0.2.  For information about upgrading, refer to the FirePass Release Notes.

Additionally, cumulative hotfix HF-601-7 has been issued for FirePass version 6.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Note: Version 6.0.1 of FirePass software requires cumulative hotfix HF-601-6 or a later version of the cumulative hotfix to support Protected Workspace on Vista clients. Previous versions of FirePass software do not support Microsoft Vista clients.
