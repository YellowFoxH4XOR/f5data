K42021374: FEC (forward error correction) feature of Broadcom internal switches on the newer BIGIP devices cannot be completely disabled

Type
Support Solution
Published
2022-02-23
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K42021374

Description

The 'tmsh modify net interface <key> forward-error-correction enabled | disabled' command affects the auto-negotiation aspect of RS-FEC on 100Gb-SR links. 
There is apparently no clear way to disable FEC (forward error correction) on bcm56xxd for FEC compatible optics - the 'disable' disables AUTO-NEG (auto negotiation) which may lead to link flapping with 3rd party optics.

Environment

BIG-IP

Cause

By default, the FEC admin state is AUTO. Operational state for all optics except QSFP-100G-LR4 transceiver modules will be negotiated to cl91 (ON). For QSFP, by default, the FEC operational state will negotiate to OFF. In a FEC set up, if one side of the link is set to AUTO and the other side of the FEC link is set to OFF, it can cause link failure (link down).

Recommended Actions

Do not attempt to disable FEC via "tmsh modify net interface <key> forward-error-correction disabled"
