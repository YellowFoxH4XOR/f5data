K000158781: Newly installed attack signatures not showing up in Security Policy

Type
Support Solution
Published
2025-12-16
Updated
2025-12-16
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000158781

Description

After installing a new ASM attack signature update, specific newly added attack signatures (IDs: 200012097 and 200009348) appeared in the system-wide attack signature list but did not show up under any Security Policy’s attack signatures tab. The customer sought clarification on why these signatures were missing from the policies despite being present on the system.


Environment

BIG-IP ASM module, version 17.5.1

Platform: F5-BIG-BT-I4800, C115

Attack signature set update installed: ASM-AttackSignatures_20251211_163605.im

Security Policies configured on the BIG-IP ASM


Cause

The root cause was that the Security Policies did not have the relevant signature sets (e.g., Low Accuracy Signatures) assigned. Only attack signatures belonging to the signature sets assigned to a policy will appear in that policy’s attack signature list. The customer confirmed this explanation resolved their issue


Recommended Actions

Assign the appropriate signature sets (containing the desired attack signatures) to the relevant Security Policies.
