Issue

Error Message

<code>: N3FIPS(mem): <string>

In this error message, note the following:

  • <code> is error message code.
  • <string> is the observed error message.

    The error message varies according to different triggering conditions as described in the Description section table.

For example:

01960043: N3FIPS(mem): Couldn't create octet string for key %PRId64

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

The N3FIPS(mem) message has multiple message variations. The following table lists error messages based on the observed message, description, and recommended actions.

Message stringDescriptionRecommended action
01960043: N3FIPS(mem): Couldn't create octet string for key %PRId64This error is caused by insufficient memory. The user cannot export an ECDSA public key from the NITROX III FIPS device.To resolve these messages, attempt to free up memory on the system. To do so, perform one or more of the following tasks:
  • Look for processes occupying excessively large amounts of memory by running the tmsh show /sys memory, ps, or top commands.
  • If necessary, restart non-critical processes that are using excessive memory.
  • Attempt to reboot the system. If the problem is not resolved, contact F5 Technical Support.
01960044: N3FIPS(mem): Couldn't export key %PRId64This error is caused by insufficient memory. The user cannot export an ECDSA public key from the NITROX III FIPS device.
01960045: N3FIPS(mem): Couldn't create ec key for key %PRId64This error is caused by insufficient memory. EC key creation fails.
01960047: N3FIPS(mem): Couldn't create memory BIO.This error is caused by insufficient memory. The N3FIPS hardware security module (HSM) cannot create bio_key.
01960048: N3FIPS(mem): Couldn't generate a PEM buffer.Not enough memory. PEM_write_bio_EC_PUBKEY() failed and returned a NULL value. The user cannot export an ECDSA public key.
01960049: N3FIPS(mem): Failed to allocate PEM string of %zu bytes.This error is caused by insufficient memory. The user cannot export an ECDSA public key.
01960050: N3FIPS(mem): Couldn't duplicate ec_key for label '%s'This error is caused by insufficient memory. The user cannot import the ECDSA private key.
01960052: N3FIPS(mem): Couldn't allocate bio_key for label '%s'This error is caused by insufficient memory. The N3FIPS hardware security module (HSM) might not be able to import the ECDSA private key.
01960051: N3FIPS(mem): Couldn't allocate pkey for label '%s'This error is caused by insufficient memory. The user cannot import an ECDSA private key.
01960053: N3FIPS(mem): Couldn't allocate bin_key for label '%s'There is insufficient memory. The N3FIPS hardware security module (HSM) user might not be able to import an ECDSA private key.
01960054: N3FIPS(mem): Couldn't allocate a FIPS request record.This error is caused by insufficient memory. The N3FIPS hardware security module (HSM) user cannot sign using an ECDSA key.

Impact

The system may be experiencing insufficient memory.

Recommended Actions

Refer to the Recommended action column of the previous table.
