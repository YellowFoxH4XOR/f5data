Description

  • Trying to create a route or self-IP object using CIDR notation as name
  • Example for route name:  0.0.0.0%3/0
  • Error message in TMUI (WebUI/GUI):
        01070734:3: Configuration error: Can't associate static route (/Common/0.0.0.0%3/0) folder does not exist

Environment

  • BIG-IP with LTM

Cause

TMUI interprets "/" as part of a folder reference. An exception has been made for CIDR notations used for self-IP and route objects.

Recommended Actions

F5 recommends you avoid using custom characters when creating BIG-IP objects and configurations. Refer to the Custom characters for the BIG-IP system section of K6869: Reserved words that should not be used in BIG-IP configurations. If you must include the "/" character in your object name, use one of the following:

  • Use "_" in TMUI name reference: 

    For example, to create an object with the name "0.0.0.0%3/0", enter the following in the Configuration utility:

    0.0.0.0%3_0

      The resulting object name will be "0.0.0.0%3/0".

  • Use TMSH to create the object. For example: 
    create net route /Common/0.0.0.0%3/0 { gw 10.10.10.10%3 mtu 1500 network default%3 }
    or
    create net route /Common/0.0.0.0%3_0 { gw 10.10.10.10%3 mtu 1500 network default%3 }
