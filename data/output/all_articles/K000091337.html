Description

How to configure the BIG-IP ASM device to send the Application event logs to ELK (Elasticsearch-Logstash-Kibana)

 Environment

  • BIG-IP ASM Logging profile
  • Sending Logs to remote ELK server

 Cause

None

 Recommended Actions

1. Create the logging profile under Security ›› Event Logs : Logging Profiles with new profile name. Choose Application security and  remote storage. Then choose key value pair as logging format

2. Assign the logging profile to the virtual server

3. Also make sure ASM policy is also attached to virtual server

4. Configure in ELK for the required configuration.

 Additional Information

None
