Description

Client SSL virtual server may generate following errors on /var/log/ltm and TLS handshake may be terminated with handshake alert.

Jan 25 13:35:01 bigip1.local warning tmm4[12061]: 01260009:4: 10.1.1.60:41124 -> 10.1.1.201:443: Connection error: ssl_hs_rxhello:11648: alert(47) No ciphers presented or an invalid cipher size was detected.
Jan 25 13:35:01 bigip1.local warning tmm4[12061]: 01260013:4: SSL Handshake failed for TCP 10.1.1.60:41124 -> 10.1.1.201:443

Packet capture shows BIG-IP receives client hello packet with 0 length cipher suites.
 
Figure: Wireshark invalid client hello packet screen
 

Environment

  • Virtual server with client-ssl profile.
 

Cause

The log can be generated when incoming client hello packet does not have any valid cipher suites.

 

Recommended Actions

To take packet capture, you can use find_error.pl script with the error message.

[root@bigip1:Active:Standalone] tmp # /usr/share/ts/bin/find_error.pl -t 'No ciphers presented or an invalid cipher size was detected.' -l '/var/log/ltm' -p 100 -o /var/tmp/capture.tar.gz --zip
