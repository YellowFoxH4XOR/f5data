Issue

Old Behavior

In versions prior to BIG-IP 11.3.0, the tmsh save /sys config command saves configurations in the current administrative partition only. Similarly, the tmsh load /sys config command loads configurations in the current administrative partition only.

To save configurations in all administrative partitions, you must use the tmsh save /sys config partitions all command. Similarly, you must use the tmsh load /sys config partitions all command to load configurations in all administrative partitions.

New Behavior

Beginning in BIG-IP 11.3.0, the tmsh save /sys config command now saves configurations in all administrative partitions. Similarly, the tmsh load /sys config command now loads configurations in all administrative partitions.

The tmsh [save/load] /sys config partitions all command remains unchanged and continues to save/load configurations in all administrative partitions.

Additionally, the current-partition option has been introduced for the tmsh [save/load] /sys config command to save/load configurations for a specific partition.

F5 Product Development tracked this change as ID 394728.

Note: When you use the TMOS Shell (tmsh) to save and load configurations for a BIG-IP system with multiple administrative partitions, you must use the appropriate syntax depending on whether you want to save and load the configuration in all partitions or in a specific partition.

Impact

Loading the configuration should not impact processing established connections in most configuration environments.

Recommended Actions

When you use tmsh to save/load configuration changes for a BIG-IP system that has multiple administrative partitions, F5 recommends that you consider the following information:

  • Saving configuration changes for a specific partition

    When you use tmsh to perform a configuration save in a specific administrative partition, you can use either the new current-partition option or the partitions option. For example, if you are in the /MyExamplePartition administrative partition and you want to save the configuration for /MyExamplePartition partition only, you would type the following command:

    tmsh save /sys config current-partition

    In another example, if you are in the /Common administrative partition and you want to save the configuration for /MyExamplePartition administrative partition only, you can type the following command:

    tmsh save /sys config partitions { MyExamplePartition }

  • Loading configuration changes for a specific partition

    When you use tmsh to perform a configuration load in a specific administrative partition, you can also use either the new current-partition option or the partitions option. For example, if you are in the /MyExamplePartition administrative partition and you want to load the configuration for /MyExamplePartition partition only, you would type the following command:

    tmsh load /sys config current-partition

    Similarly, if you are in the /Common administrative partition and you want to load the configuration for /MyExamplePartition partition only, you can type the following command:

    tmsh load /sys config partitions { MyExamplePartition }
