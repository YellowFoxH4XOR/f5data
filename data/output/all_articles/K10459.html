Known Issue

This is the result of a known issue. Mac OS X users may be continually prompted to install the FirePass client plugins when connecting with a Firefox browser. Even if the user appears to successfully install the necessary plugins, when they try to connect they will be prompted to install the plugins. This issue occurs because the .dat file is not updating correctly. When FirePass checks the .dat file, FirePass behaves as though the plugins are missing.

F5 Product Development tracked this issue as CR110135 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative hotfix HF-603-3 issued for FirePass version 6.0.3 and HF-602-10 issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
