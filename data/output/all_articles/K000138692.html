Description

How can we access/download/transfer files in the blades of the Velos?
 

Environment

Cause

Recommended Actions

Traffic blade is accessible from System Controller only.

How to download/transfer files from blade to client machine.

1. log in to System Controller's CLI as root

NOTE: recommend to use Floating IP.

2. ssh to blade

ssh blade-<blade_ID>

3. from blade, scp to the System Controller's internal IP

scp <full/pass/to_file> root@100.65.3.50:</full/pass>

NOTE: 100.65.3.50 is floating System controller's internal IP.
If you need to specify system controller, you may need to change the internal IP for the system controller.
by default

System Controller 1: 100.65.7.51
System Controller 2: 100.65.7.52

If you customized Internal Network range, then you can check the internal IP address by

ip route | grep ccpeer
 

4. scp to the System Controller, and download/transfer data to your local machine
 

How to transfer files from blade to blade (you should not transfer config files, it may cause unexpected issue)

1. Check if the partition's (where the targeted blade belongs to) root account status, by logging in to the partition CLI

show system aaa authentication users user root
          AUTHORIZED  LAST    TALLY        EXPIRY
USERNAME  KEYS        CHANGE  COUNT  ROLE  STATUS
----------------------------------------------------
root      -           0       0      root  enabled

 

Expiry status must be enabled.
Last change must have more than 0. (The default value is 0 (zero), which indicates that the user must change the password at their next log in.)


To change the settings,

config

 

  • (i)  to enable root account

system aaa authentication users user root config expiry-status enabled 
exit

 

  • to set password

system aaa authentication users user root config set-password
Value for 'password' (<string>): <type_password>
then [enter] to confirm
exit

 

  •  to set last change second

system aaa authentication users user root config last-change 1
exit

to save change

commit and-quit

2. log in to System Controller's CLI as root

3. ssh to the blade which hold the file

ssh blade-<blade_ID>


4.then scp to desired blade.

scp <full/pass/to_file> root@100.65.3.<blade ID>:</full/pass/>

NOTE: by default, blade-x: 100.65.3.x (e.g. blade-8 is 100.65.3.8)
If you have changed the Internal Network IP, then check with

ip route | grep 3\.0\/24
