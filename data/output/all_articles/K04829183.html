Source
https://my.f5.com/manage/s/article/K04829183

Description
An "Unknown SSL Protocol" error is returned when running the following command from the steps in KB article "K03011490 Verifying connectivity for the IPI Subscription service": 

curl -skvv 'https://api.bcti.brightcloud.com/1.0/ip/getthreatlist?oemid=F5&deviceid=<DEVICEID>&uid=<UID>' | jq 

For example:

curl -skvv 'https://api.bcti.brightcloud.com/1.0/ip/getthreatlist?oemid=F5&deviceid=IPIntelligence-EVAL-Z100&uid=123456789' | jq .

* Trying 34.214.145.84...
* Connected to api.bcti.brightcloud.com (34.214.145.84) port 443 (#0)
* ALPN, offering h2
* ALPN, offering http/1.1
* Cipher selection: ALL:!EXPORT:!EXPORT40:!EXPORT56:!aNULL:!LOW:!RC4:@STRENGTH
* successfully set certificate verify locations:
* CAfile: /etc/pki/tls/certs/ca-bundle.crt
  CApath: none
* TLSv1.2 (OUT), TLS header, Certificate Status (22):
} [5 bytes data]
* TLSv1.2 (OUT), TLS handshake, Client hello (1):
} [512 bytes data]
* Unknown SSL protocol error in connection to api.bcti.brightcloud.com:443
* Closing connection 0

Note: Additionally, a tcpdump shows BIG-IP sent client hello packet but received reset packet back.

Environment
Your BIG-IP system fails to update the IP Address Intelligence Service (IPI Subscription) database

Cause
Firewall between BIG-IP management interface and IPI Subscription service update server is blocking SSL connections.

Recommended Actions
Please allow the below three URLs thought firewall, 

  • api.bcti.brightcloud.com (default)
  • localdb-ip-daily.brightcloud.com (base file)
  • localdb-ip-rtu.brightcloud.com (updates)
