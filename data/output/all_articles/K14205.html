Known Issue

Uploading large files over a BIG-IP APM virtual server with the HTTP Basic Auth single sign-on (SSO) method may fail.

This issue occurs when the following conditions are met:

  • The access policy uses HTTP Basic Auth SSO method.
  • A large file (~500 MB) is uploaded over the virtual server.

Impact

The file upload fails. In addition, the BIG-IP APM system may experience memory utilization issues.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The file upload fails after all file content is sent to the BIG-IP APM system.
  • A server-side packet capture indicates that the BIG-IP APM system sends only a few packets to the backend server.
  • Traffic Management Microkernel (TMM) memory consumption increases during the file upload.

    For example, the tmsh show /sys mem command may indicate an increase in TMM memory utilization during the file upload, as displayed in the following example:

    Before the file upload:

    -----------------------
    Sys::TMM Memory (bytes)
    -----------------------
    TMM: 0.0
    Available 1.5G
    Used 68.1M

    Near the end of the file upload:

    -----------------------
    Sys::TMM Memory (bytes)
    -----------------------
    TMM: 0.0
    Available 1.5G
    Used 712.8M
