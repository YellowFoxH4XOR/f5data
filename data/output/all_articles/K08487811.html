K08487811: tmipsecd continually restarts

Type
Support Solution
Published
2021-01-07
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K08487811

Description

  • tmipsecd keeps restarting

Environment

  • failover event occurs
  • racoon has a PID file but there is not process running

Cause

in rare cases, ID 893181 causes the tmipsecd service to restart when the racoon PID exists but contains a process id that tmipsecd cannot kill. It can contain 0 for a process ID - which should mean there is none, but tmipsecd tries to kill it anyways.

Recommended Actions

Manually remove the racoon.pid fie with this command: 
rm -f /var/run/racoon.pid
Note: No other actions are required.
