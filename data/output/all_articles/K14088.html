Topic

The tables in this article list the BIG-IP vCMP host (hypervisor) versions and the compatible Virtual Clustered Multiprocessing (vCMP) guest versions for each of the VIPRION and BIG-IP platforms that support vCMP.

Description

Starting in BIG-IP 11.0.0, the system supports vCMP, a feature that allows you to run multiple instances of the BIG-IP software on a single hardware platform. The hypervisor allows you to allocate hardware resources to each BIG-IP vCMP guest instance.

The vCMP host allows you to run a vCMP guest software version, which can be either the same version or a different version than the host, which is BIG-IP 11.0.0 and later. This functionality allows customers to run multiple versions of BIG-IP code simultaneously for testing, migration staging, or environment consolidation.

Important: The following tables list only the guest versions that are compatible with the hypervisor versions. For information about the currently supported BIG-IP versions, refer to K5903: BIG-IP software support policy.

Important: There is a known issue that could cause packet drops when working with a vCMP devices when Host runs a TMOS version ≥17.1 and AFM Guest run a TMOS version lower than 17.1, refer to K000140382: AFM DoS feature could drop packets if vCMP Host run TMOS v17.1.x and Guest TMOS version is lower

Note: Your vCMP host point-release version does not change the compatibility of the guest versions. For example, you should be able to run BIG-IP 12.1.3 through 15.1.0-compatible guest versions when your vCMP host is running the BIG-IP 13.1.1.2 point-release version.

The BIG-IP 10200v platform does not support hypervisor versions prior to 11.3.0 HF5. BIG-IP 15.1.3 and later is only supported for the 10200v-SSL and 10200v-FIPs platforms.

BIG-IP 10250v

F5 introduced support for the BIG-IP 10250v platform in BIG-IP 11.4.1 HF3. Beginning in BIG-IP 11.4.1 HF3, you can license and provision vCMP on a 10250v platform. The BIG-IP 10250v platform does not support hypervisor versions prior to 11.4.1 HF3. BIG-IP 15.1.3 and later does not support the 10250v platform.

Recommendations

F5 recommends that you run the most recent version of BIG-IP software for both the vCMP host (hypervisor) and guest instances, as the latest version contains the latest fixes and general improvements.
Plan the order for host/guest upgrades according to the following guidance:

  • When to upgrade the vCMP guest instance first
    • If you are upgrading the vCMP system to a version that would temporarily result in the vCMP host and guest running incompatible versions, F5 recommends that you upgrade the guest instance first and then activate the boot location for the newly upgraded guest. Next, on the vCMP host, set the upgraded guest to the Provisioned state. You can then safely upgrade the vCMP host to the new, compatible version. Once you have rebooted the host to the new version, set the vCMP guest to Deployed.
  • When to upgrade the vCMP host first
    • If you are upgrading the vCMP system to a version that would not temporarily result in the vCMP host and guest running incompatible versions, F5 recommends that you upgrade the host first.
