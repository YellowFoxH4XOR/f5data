K000152413: "postgres" and "tomcat" User Accounts on BIG-IP LTM

Description

"postgres" and "tomcat" user accounts may be observed in system logs or user listings on BIG-IP LTM systems. These accounts may appear in files such as /etc/passwd and /etc/shadow, or in the Configuration utility under System → Users. There are no associated error messages or security alerts by default.

 

Environment

BIG-IP

 

Cause

The "tomcat" and "postgres" accounts are default service users created by the BIG-IP system.
- The "tomcat" user is used by the underlying Linux OS to run the Tomcat service, which provides the BIG-IP Configuration utility (GUI).
- The "postgres" user is used to run the PostgreSQL database service, which is utilized by BIG-IP for internal data management.
These accounts are required for normal system operation and are not indicative of unauthorized access or malicious activity.

 

Recommended Actions

- The presence of "tomcat" and "postgres" service accounts in /etc/passwd,, /etc/shadow,, or the user list is expected and normal on BIG-IP systems.
- These accounts should not be used for direct login or administrative access.
- To review all local user accounts, navigate to: Main tab → System → Users in the Configuration utility.
- If there are concerns about unauthorized access or if these accounts appear outside their expected context, review system logs and user activity for anomalies.
- For a comprehensive review, generate and analyze a qkview file using F5 iHealth.
- No further action is required if these accounts are only present as service users and are not being used for interactive logins.
