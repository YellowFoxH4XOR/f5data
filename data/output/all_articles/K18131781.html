Known Issue

The Secure Web Gateway (SWG) explicit forward proxy may reject HTTP POST requests.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with an SWG explicit forward proxy configuration.
  • The first request received by the policy evaluation is an HTTP POST request where the POST body size exceeds 64 KB.

    Note: After the policy evaluation is complete, subsequent large HTTP POST requests are not affected.

Impact

The policy evaluation cannot process the request and the request is rejected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing the HTTP level connection information, the BIG-IP APM system responds to the POST request with an HTTP/1.1 100 Continue followed by a Recv failure: Connection reset (TCP reset).
  • At the time of the event, the system logs a message to the /var/log/apm file:

    err tmm[19951]: 01490514:3: (null):Common:00000000: Access encountered error: ERR_NOT_SUPPORTED. File: ../modules/hudfilter/access/access.c, Function: hud_access_process_ingress, Line: 2765

Workaround

To work around this issue, you can modify the tmm.access.maxrequestbodysize system database variable to a value larger than the maximum post body size you would like to support. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure may increase the memory used the BIG-IP system while processing the POST request.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To modify tmm.access.maxrequestbodysize system database variable, type the following command:

    modify /sys db tmm.access.maxrequestbodysize value <total bytes>

    For example, to set the system database variable to 5 MB, type the following command:

    modify /sys db tmm.access.maxrequestbodysize value 5000000

    Note:  The default value for tmm.access.maxrequestbodysize is 64000 bytes, and the maximum supported value is 25000000 (25 MB).

  3. Save the configuration changes by typing the following command:

    save /sys config

  4. To exit tmsh, type the following command:

    quit
