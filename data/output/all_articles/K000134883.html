Description

The following log messages are being generated in /var/log/ltm:

DNSSEC: flow shutdown (11) for zone <zone name> during pkt completion

Environment

  • BIG-IP DNS
  • DNSSEC

Cause

Client has closed the TCP connection before BIG-IP is able to respond

Recommended Actions

This is a warning to indicate that a client has closed the TCP connection before BIG-IP is able to respond to the dns query.

If BIG-IP is suspected to be misbehaving then a packet capture analysis is required to further investigate the client and BIG-IP communication.

Additional Information

This message can be triggered when a client sends a tcp reset shortly after sending a dns query, so BIG-IP is unable to generate a response before the tcp connection closes.

Use the following wireshark filter to analyse the traffic:

((!dns.response_in) && (dns.flags.response == 0) && (dns.resp.z.do == 1) and tcp ) && (dns.qry.name contains "example.com")
