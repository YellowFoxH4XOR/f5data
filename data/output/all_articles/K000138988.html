Description

When the BIG-IP APM is configured as both SAML SP and SAML IDP along with an external SAML IDP, if the SAML Single Logout is initiated, APM will suspend IdP SLO processing to perform SLO with external IdP first.

The below log message is seen under /var/log/apm:

Successfully read logout URL 'BIGIP_IDP_SUSPEND_SLO_RESP_FOR_SP' from session db

Environment

  • BIG-IP APM as SAML SP and SAML IDP 
  • External SAML IDP

Cause

Since SAML Single Logout has to be performed with the External IDP first, APM suspends the SLO in the BIG-IP.

Recommended Actions

None
