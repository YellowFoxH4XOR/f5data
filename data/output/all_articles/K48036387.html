Description

While having established an APM session on a Windows shared terminal server, another user is trying to establish another one.

An example is when 2 users (A and B) are logged in through Windows remote desktop on a Windows shared terminal server. A VPN connection is already established with user "A" and user "B" tries to establish another session while "A"'s session is ongoing.

The Edge Client prompts the error message:

An instance of the application is already running in another user session

Environment

Relevant environmental factors:

  • BIG-IP APM
  • Access Policy providing Network Access VPN support
  • Windows device shared is with 2 or more users.

Cause

This is expected, as the Windows operating system does not differentiate the network stack used between different users.

Recommended Actions

BIG-IP APM does not support Windows Server operating system or Remote Desktop Windows server where multiple users are able to login and establish network access VPN sessions at the same time. Users should connect directly from a supported Windows Client such as Windows 11, establishing a single network access session from the client.
