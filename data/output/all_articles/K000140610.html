Description

How to view or change the rentention of the bash shell commands or tmsh history file on a BIG-IP

 

Environment

BIG-IP

 

Cause

The bash shell history is stored in the ~/.bash_history file.

The number of commands retained is controlled by the HISTSIZE and HISTFILESIZE environment variables.

HISTSIZE: Determines the number of commands to remember in the current session. By default, this is set to 1000 commands.

HISTFILESIZE: Determines the number of commands to save in the ~/.bash_history file. By default, this is also be set to 1000 commands.

The TMSH history is stored in the  ~/.tmsh-history-root file

The maximum number of commands stored in this file by default is 10000

Recommended Actions

To verify or change the HISTSIZE, you can check your shell configuration file ~/.bashrc or use the following command in your terminal:

# echo $HISTSIZE


If you want to change the `HISTSIZE`, you can add or modify the following line in your ~/.bashrc file:

# export HISTSIZE=2000


After making changes, apply them by running:

# source ~/.bashrc

 

To view the history-file-size and history-size run the following command:

# tmsh list cli preference history-file-size history-size

cli preference {
    history-file-size 10000
    history-size 500
}

To modify the history-file-size or history-size run the following command:

# tmsh modify cli preference history-file-size 20000

After making changes be sure to save the configuration with the following command:

# tmsh save sys config
