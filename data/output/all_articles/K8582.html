Known Issue

This is the result of a known issue. When a user launches a Citrix MetaFrame Portal Terminal Server favorite, FirePass sets the screen resolution to 800 x 600 regardless of the Screen resolution setting you configured for the Terminal Server favorite.

Note: Terminal Server favorites are configured on the Application Access: Terminal Servers: Resources page in the FirePass Administrative Console.

F5 Networks Product Development tracked this issue as CR90148 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-602-1 has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
