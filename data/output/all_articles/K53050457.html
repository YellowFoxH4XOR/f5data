Description
You are upgrading blades in a Viprion chassis to later models.
You are following  Manual Chapter : Migrating the Configuration on B2000 Series Blades
After running chassisConfigUpgrade.pm both the old and new blades are offline. 

Environment

  • A chassis with more than one B2100 or B2150 blades. You are replacing the blades with a later model (B2250)

Cause
In a chassis a blade can be added. The new blade is often a replacement for a failed blade and in this case the new blade will synchronise itself to the other blades.
In particular, it will

  1. Copy the installation media from /shared/images  on the primary blade
  2. Retrieve the software installation status (versions and boot locations) and update itself so that version and boot locations are consistent for all blades in the cluster.

This can take some time.
However when you add a different model blade, this will not occur, as the hardware must be identical in a cluster.
This is why chassisConfigUpgrade.pm is provided. The issue is that the new blade must still have the correct software version and boot locations, but is unable to copy the installation images.
The new device will show "waiting for media"   when running   show sys software
As part of the script, it sets the source blade offline, so the effect is that both source and new blades are not working.

Recommended Actions

  1.  Login to the new device as root and run:
    scp slotn:/shared/images/*.iso  /shared/images   
    where slotn is the slot of the source blade.
  2. When these installation images are available the device will continue with its installation process. It will likely reboot.
  3. When the device has the correct software installed, reboot the chassis and start the procedure from the beginning.
    With the correct software preinstalled it will complete correctly.

Additional Information

We recommend not having  more than two boot locations with software installed (running version and prior version). Each location must be synchronised and installed on a hardware change. This can take some time to complete.
If a blade updates its version from the shipping version it will update its flash firmware and reboot.
