Topic

You should consider using this procedure under the following condition:

  • You want to access a BIG-IP tenant console running on the F5 rSeries system.

Description

You can access the console of a BIG-IP tenant running on an rSeries system using the following two methods:

  • The virtctl command
  • SSH

The virtctl command

You can access the BIG-IP tenant console from the rSeries system using the virtctl command. The virtctl command on rSeries systems requires the tenant name.

ObjectLocation 
tenant nameIn the rSeries webUI, go to TENANT MANAGEMENT > Tenant Deployments and verify the tenant name.

SSH

When you deploy a tenant on an F5 rSeries platform, the F5 rSeries platform automatically creates a user account using the same name as the tenant and assigns the tenant-console role to the account. The purpose of this user account is to provide remote access to the tenant’s console using the F5 rSeries platform management address and port 7001. By default, the F5 rSeries system disables the tenant console user account. If you want to access the tenant’s console remotely over SSH, you must enable this user account with an administrative user, such as the admin account.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • Root access to the F5 rSeries system (for using virtctl)
  • Administrative access to the F5 rSeries platform management CLI

Procedures

  • Access the tenant console using virtctl
  • Access the tenant console using SSH

Access the tenant console using virtctl

To access the BIG-IP tenant console using the virtctl command, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the F5 rSeries system as the root user.
  2. Execute the virtctl command at the bash prompt to access a tenant console, using the following syntax: 
    virtctl console <tenant_name>-1
    For example, if the tenant name is bigip-example, enter the following command:

    virtctl console bigip-example-1

    Once connected to the virtual console, you should be greeted with the following message:

    Successfully connected to bigip-example-1 console. The escape sequence is ^]

    Note: The virtctl command being run above is a shell script located in the PATH at /usr/local/bin/virtctl, not the kubernetes binary at /usr/share/omd/kubevirt/virtctl.  The script automatically starts the kube proxy, if it is not running, then runs the virtctl binary. The script should always be used instead of running the virtctl binary directly.

  3. You are now connected to the virtual console of the tenant. Press enter to re-display the tenant's prompt. To exit the tenant console, enter Ctrl - ] (control plus the right square bracket, per the "The escape sequence is ..." message above)

Access the tenant console using SSH

To enable the tenant console user account and SSH to the tenant console, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the F5 rSeries platform CLI as the administrative user.
  2. Display the list of user accounts on the F5 rSeries platform by typing the following command:

    show system aaa authentication users

    The the command output appears similar to the following example:

    F5OS-A 1.5.1 and later

              AUTHORIZED  LAST        TALLY                  EXPIRY  
    USERNAME  KEYS        CHANGE      COUNT  ROLE            STATUS  
    ------------------------------------------------------------------
    admin     -           2023-08-29  0      admin           enabled 
    mytenant  -           0           0      tenant-console  locked  
    root      -           2023-08-29  0      root            enabled  

    F5OS-A 1.5.0 and earlier

                                      LAST        TALLY  EXPIRY                 
    USERNAME                          CHANGE      COUNT  DATE    ROLE           
    -----------------------------------------------------------------------------
    admin                             2022-05-26  0      -1      admin          
    mytenant                          0           0      1       tenant-console 
    root                              2022-05-26  0      -1      root            

    The username should be the same name as the tenant. In this example, the tenant’s name is mytenant and the username for the tenant console user account is also mytenant.

  3. Enter the configuration mode by typing the following command:

    config

  4. Set a password for the tenant console user account using the following command syntax:

    system aaa authentication users user <tenant console user account> config set-password

    The system then prompts you for a password to set for the user account. Using the previous example, type the following command for the mytenant user account:

    system aaa authentication users user mytenant config set-password

  5. For F5OS-A 1.5.1 and later, set the expiry status to either enabled or an expiry date in the YYYY-MM-DD format for the tenant console user account; for F5OS-A 1.5.0 and earlier, set the expiry date to negative one (-1) for the tenant console user account using the following command syntax:

    F5OS-A 1.5.1 and later

    system aaa authentication users user <tenant console user account> config expiry-status <enabled | YYYY-MM-DD>

    F5OS-A 1.5.0 and earlier

    system aaa authentication users user <tenant console user account> config expiry-date -1

    Using the previous example, type the following command for the mytenant user account:

    F5OS-A 1.5.1 and later

    system aaa authentication users user mytenant config expiry-status enabled

    F5OS-A 1.5.0 and earlier

    system aaa authentication users user mytenant config expiry-date -1

  6. Save and confirm the changes by typing the following command:

    commit

  7. Exit configuration mode by typing the following command twice:

    exit

  8. Verify your changes by listing the user accounts again. To do so, type the following command:

    show system aaa authentication users

    F5OS-A 1.5.1 and later

    Ensure that the EXPIRY STATUS column is displaying either enabled or the expiry date for the tenant console user account. Using the previous example, the command output should appear as follows:

              AUTHORIZED  LAST        TALLY                  EXPIRY  
    USERNAME  KEYS        CHANGE      COUNT  ROLE            STATUS  
    ------------------------------------------------------------------
    admin     -           2023-08-29  0      admin           enabled 
    bip1710   -           0           0      tenant-console  enabled 
    root      -           2023-08-29  0      root            enabled  

    F5OS-A 1.5.0 and earlier

    Ensure that the LAST CHANGE column is set to the date you effected the change and the EXPIRY DATE column now displays -1 for the tenant console user account. Using the previous example, the command output should appear as follows:

                                      LAST        TALLY  EXPIRY                 
    USERNAME                          CHANGE      COUNT  DATE    ROLE           
    -----------------------------------------------------------------------------
    admin                             2022-05-26  0      -1      admin          
    mytenant                          2022-06-20  0      -1      tenant-console 
    root                              2022-05-26  0      -1      root            

  9. You can now access the tenant console over SSH from a client desktop using the following command syntax:

    ssh <tenant console user account>@<F5 rSeries platform management IP> -p 7001

    Using the previous example, type the following command to connect to the mytenant console using the rSeries platform management IP address 192.168.85.35 port 7001:

    ssh mytenant@192.168.85.35 -p 7001

    The system should prompt you for the password. Enter the password you have set for the tenant console user account in step 4. You may be prompted to change the password upon your first login. Once you connect successfully, the system should return a message similar to the following example:

    Successfully connected to mytenant-1 console. The escape sequence is ^]

    To reveal the tenant console, press the Enter key. To exit the tenant console over SSH, you must hold the CONTROL and ] key sequence simultaneously.
