K000093017: TCL error: can't read "<variable>": no such variable while executing when multiple iRules are attached to a virtual server

Type
Support Solution
Published
2022-12-06
Updated
2022-12-06
Source
https://my.f5.com/manage/s/article/K000093017

Description

iRules are not working as expected and there are TCL errors in the logs. It is possible that it previously worked and might work as expected on the HA peer after failing over.

err tmm[12345]: 01220001:3: TCL error: /Common/<iRule name> <iRule Event> - can't read "<variable name>": no such variable while executing "<my TCL commands>"

Environment

  • BIG-IP
  • Variable shared between iRules in same event where it is created

Cause

This issue occurs when iRules in the same event do not have priority commands but share a variable. An iRule attempts to use a variable before it is created by another iRule during the same event. Without priority commands, the order of execution of the iRules may be unexpected

Recommended Actions

Set iRule event priority appropriately when reading a variable that is created in another iRule in the same event

Additional Information

There are factors that affect the order of different iRules triggering within the same event, but if some iRules need to trigger first or last then it is recommended to explicitly set priority.
