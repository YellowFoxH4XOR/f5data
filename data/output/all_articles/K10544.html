Topic

FirePass versions prior to 7.0 only support a limited number of builds of 64-bit browsers and several 64-bit browsers if they are running in 32-bit compatibility mode. For a full overview of which operating systems and browsers running in 64-bit mode are supported, refer to the Compatibility Matrix and select your FirePass version.

Note: For full 64-bit browser compatibility, the FirePass device must be running version 7.0 or later.
