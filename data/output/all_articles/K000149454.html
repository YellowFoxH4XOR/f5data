K000149454: Remove CBC ciphers from port 4353

Type
Support Solution
Published
2025-02-07
Updated
2025-02-07
Applies to
  • F5 Distributed Cloud Services
Source
https://my.f5.com/manage/s/article/K000149454

Description

Security scan reported that the BIGIP is vulnerable due to CBC mode cipher encryption detected on port 4353. Since CBC ciphers have been considered obsolete, they need to be disabled.

Environment

  • CBC ciphers
  • port 4353

Cause

As informed in K13431424, all ciphers currently supported on BIG-IP are CBC mode except for AES-GCM.

Recommended Actions

Configure the cipher list to use only AES-GCM for gtmd and big3d using the following commands:

 

Impact of procedure: Changing the cipher list may cause iQuery connections to fail if the remote BIG-IP system is not compatible with the modified cipher strength.

 

# tmsh modify gtm global-settings general iquery-cipher-list AESGCM

# tmsh modify gtm global-settings general iquery-minimum-tls-version TLSv1.2

# tmsh modify sys db big3d.ssl.cipherlist value AESGCM

# tmsh modify sys db big3d.minimum.tls.version value TLSv1.2

# tmsh save sys config 

# restart sys service big3d

Additional Information

After you have disabled CBC ciphers you may want to test the cipher list currently offered by the BIG-IP system using a nmap utility. To do so, log into a Linux system that has access to the BIG-IP and use the following command:

nmap --script ssl-enum-ciphers -p 4353 <management_IP>
