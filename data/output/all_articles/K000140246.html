Description

  • What's the purpose of the f5_api_com.crt?

The f5_api_com.crt is an SSL certificate used by the BIG-IP system for secure communication with various F5 services such as Phone Home feature, Auto Protocol Inspection signature update (AFM), Auto Traffic Intelligence Classification Signature Update (PEM) etc., It allows the BIG-IP system to establish communication with the API servers. The certificate is used to authenticate and encrypt the communication between the BIG-IP system and the API servers.

The certificate is essential for ensuring the integrity and security of the communication between the BIG-IP system and F5 services, without this certificate, the BIG-IP system cannot make successful API calls to F5 services which will disrupt the auto-update software checks and connectivity with other F5 services. 

The f5_api_com.crt is crucial in validating license. When performing tasks like software upgrades or license renewals, the BIG-IP system may contact F5's API servers for license verification and activation. The f5_api_com.crt ensures that this communication is secure and authenticated. The expired f5_api_com.crt certificate prevents the BIG-IP system from securely connecting to the F5 licensing API and the process will fail, resulting in errors like "license validation errors" or "license check failed". Once the certificate is updated, the system can establish secure communication, resolve the licensing issue, and proceed with the upgrade.

Note: ASM components (Attack Signatures, Server Technologies, Browser Challenges, Bot Signatures, Threat Campaigns) don't rely on "f5_api_com.crt" and hence there is no relevance of this certificate in the context of ASM components update. 

Environment

  • BIG-IP LTM
  • Certificate - /config/ssl/ssl.crt/f5_api_com.crt

Cause

None

Recommended Actions

Renew the expiring api.f5.com certificate by following the recommended steps found in K000137950: How to renew an expiring api.f5.com certificate

Reactivating your BIG-IP license will create a new replacement api.f5.com certificate.

Important:  When renewing license, AUTOMATIC License activation process must be used. Manual License activation will not generate the needed cert/key pair. BIG-IP license reactivation process temporarily interrupts traffic processing as the system reloads the configuration. Please follow this procedure during a planned maintenance window.

Note: An expired f5_api_com.crt certificate does not impact user traffic.
