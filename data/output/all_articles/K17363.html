Known Issue

The BIG-IP system resets the ingress Stream Control Transmission Protocol (SCTP) Stream ID (SID) value to zero.

This issue occurs when all the following conditions are met:

  • You have an SCTP profile associated with a virtual server.
  • The BIG-IP system receives SCTP data with multiple streams.

Impact

Applications that require multiple streams will not function correctly.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • A packet trace of ingress and egress SCTP data on the BIG-IP system will show that non-zero SID values on ingress are set to zero on egress.

Workaround

You may be able to work around this issue by modifying the SCTP profile and setting the maximum input and output streams to 1. To do so, perform the following procedure:

Impact of workaround: The following procedure may cause clients that expect to send or receive data on multiple streams to fail, which may not be applicable to all environments. F5 recommends that you test any such changes during a maintenance window with consideration to the possible impact on your specific environment.

  1. Log in to the Configuration utility as the administrative user.
  2. Navigate to Local Traffic > Profiles > Protocol > SCTP.
  3. Click the name of the affected SCTP profile.
  4. In the In Streams box, type a value of 1.
  5. In the Out Streams box, type a value of 1.
  6. Click Update.
