Known Issue

This is the result of a known issue. If a Windows Vista client attempts to access documents on a Share Point 2007 server through Portal Access, the documents may fail to load.

 This issue occurs when all of the following conditions are met:
  • Microsoft Office 2007 is installed on the client system
  • The user connects to the FirePass controller using Internet Explorer 7 (IE7) for Windows Vista
  • Protected Mode is enabled in IE7
  • The URL of the FirePass controller has not been added to the IE7 Trusted Sites zone
 
Protected Mode is a security feature introduced in IE7 for Windows Vista. This issue occurs due to the way Protected Mode handles cache locations and persistent cookies. For more information, refer to the following location:
 
http://support.microsoft.com/kb/932118
 
F5 Networks Product Development is tracking this issue as CR102212.
 
Workaround
 
The user can work around this issue by performing one of the following four procedures:
  • Add the URL of the FirePass controller to the IE7 Trusted Sites zone

    Note: For information about configuring the Trusted Sites zone, refer to Microsoft IE7 documentation.

    Important: By default, Protected Mode is disabled in IE7 for the Trusted Sites zone. If Protected Mode is enabled for this zone, use an alternate workaround.
     
  • Connect to the FirePass controller using an alternate browser, such as Firefox
  • If the user has administrator privileges on the Windows Vista system, the user can right-click on Internet Explorer and select the Run as administrator option when launching Internet Explorer. The Run as administrator setting bypasses Protected Mode
  • If the user does not have administrator privileges on the Windows Vista system, the user can disable Protected Mode in Internet Explorer

    Important: F5 Networks does not recommend this workaround, as it may decrease the security of the Window Vista system.

    Note: For information about disabling Protected Mode, refer to the Microsoft IE7 documentation.
