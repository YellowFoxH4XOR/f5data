Known Issue

The BIG-IP system may reject Session Initiation Protocol (SIP) messages that contain separator characters within quotation marks.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server with SIP Message Routing Framework (MRF) functionality.
  • The virtual server receives a SIP message.
  • A SIP header contains a sequence of multiple commas (,) or semi-colon (;) attribute separators within quotation marks in an attribute.

Instead of ignoring the sequence of commas (,) or semi-colons (;) within the quotation marks in an attribute, the BIG-IP system incorrectly treats the characters as separators and therefore rejects the message as invalid.

The following example shows a header that would trigger the issue:

P-Access-Network-Info: undefined;dsl-location=";;;;;"

Impact

SIP request messages are rejected by the BIG-IP system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • SIP connections fail.
  • If reset cause logging is enabled and the SIP virtual server uses TCP, messages similar to the following example are logged to the /var/log/ltm file:

    err tmm[1234]: 01230140:3: RST sent from 192.168.1.1:5060 to 10.1.1.1:5060, [0x1e98bac:2355] SIP error (Illegal value)
