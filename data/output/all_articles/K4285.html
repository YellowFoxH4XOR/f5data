K4285: Configuring BIG-IP to connect to a node using the same source port that the client used to connect to BIG-IP

Topic

When using a delayed binding connection, you cannot configure BIG-IP to preserve the client's source port for presentation to the node.

Depending on the configuration, BIG-IP will select the lowest available ephemeral port for the source port, or it will cycle through the entire ephemeral port range.
