Topic

Summary

The BIG-IP Configuration utility displays an inactive Mobile App Manager configuration page.

Description

The BIG-IP APM 11.4.1 Configuration utility incorrectly displays a configuration subsection for Mobile App Manager. Configuration settings on the Mobile App Manager page are inactive and will not be applied to the BIG-IP APM system.

The Mobile App Manager subsection was removed from the Configuration utility in BIG-IP APM 11.4.1 HF2.

Impact

Configuration settings on the Mobile App Manager page are inactive and will not be applied to the BIG-IP APM system.
