Known Issue

BIG-IP systems configured with an external hardware security module (HSM) may truncate certificate signing requests (CSR) and certificate fields with long names.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured to use an external HSM such as SafeNet or Thales.
  • You use the Traffic Management Shell (tmsh)or the fipskey.nethsmutility to create the certificate signing request (CSR) and the certificate.
  • You populate the following fields with values longer than 15 characters, or values that consist of strings that are separated by the space character:
     
    • Organization name
    • State or Province name
    • Locality name
    • Common name

Impact

The affected certificate may not be signable.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system truncates field content, limiting the characters to 15, or limiting the string to the characters up to the first space character.
  • The openssl utility displays, as truncated, names that are longer than 15 characters, or strings that are separated by a space character.

    For example, you could generate the following key/certificate using the tmsh command:

    tmsh create sys crypto key www7.example.com { security-type nethsm gen-certificate country US state "New York" city "New York City" organization "123456789abcdefghijklmnopqrstuvwxyz" common-name www7.example.com }

    The openssl output for the previous command may appear similar to the following example:

    subject=/C=US/ST=New/L=New/O=123456789abcdef/CN=www7.example.com

Workaround

To work around this issue, you can use strings shorter than, or equal to, 15 characters without spaces. When using a string that contains spaces is required, you can add quotation marks around the entire string and delimit spaces with a backslash character (\).

For example, to use "F5 Networks Inc" with spaces, you can enter the value as follows:

F5\ Networks\ Inc

Note: The delimiting slash character is included in the field's character counts.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
