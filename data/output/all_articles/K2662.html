Note: A redundant pair of 3-DNS Controllers is defined as a failover pair of 3-DNS Controllers with a floating IP address. This is not the same as primary/secondary DNS or 3-DNS synchronization groups; it is a specific kind of redundant configuration, identical to the BIG-IP failover mechanism.

This Solution assumes the following:

  • You have already set up and configured your first 3-DNS Controller and that it is currently running and active.
  • The new 3-DNS Controller is physically installed and has not been powered up.
  • A failover cable is connected between the failover ports on the two 3-DNS Controllers.

Configuring the new 3-DNS Controller

On the new (inactive/standby) 3-DNS Controller, perform the following steps:

  1. Power up the new 3-DNS Controller and connect to the command line through the console or using SSH.

    This will initiate the Setup Utility.

  2. Select R for Redundant System options.
  3. Identify the new 3-DNS Controller as Unit 2.
  4. When prompted, provide the appropriate VLAN, self-floating IP address information, and the IP address of the peer (existing/active) 3-DNS Controller.

On the existing (active) 3-DNS Controller

On the existing (active) 3-DNS Controller, perform the following steps:

  1. Run the following command to save the existing 3-DNS Controller's configuration:

    bigpipe config save

  2. Run the Setup utility by typing the following command:

    config

  3. Select R for Redundant System options.
  4. Choose to make this a part of a redundant pair and identify it as Unit 1.
  5. When prompted, provide the appropriate VLAN, self-floating IP address information, and the IP address of the peer (new/standby) 3-DNS Controller.
  6. If a synchronization group already exists, add the new 3-DNS Controller to the group. If one does not exist, create a new synchronization group and add both 3-DNS Controllers to it.

    Note: There will only be one 3-DNS name displayed in the synchronization group to represent both the active and standby systems in the 3-DNS pair. Both systems will automatically synchronize within the synchronization group; you do not need to manually synchronize the 3-DNS redundant pair using the bigpipe configsync command.

You should now have a properly configured 3-DNS redundant system.
