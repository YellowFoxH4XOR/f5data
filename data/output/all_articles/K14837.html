Known Issue

The BIG-IP APM system may send a TCP reset when processing multiple session requests.

This issue occurs when all of the following conditions are met:

  • An access profile with multi-domain SSO has been applied to a virtual server.
  • A user initiates a session that uses the access profile.
  • The user initiates a subsequent session to the access profile before the original session request has processed.

Impact

The user's session initiation fails.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H434244 on the Diagnostics > Identified > High screen.
  • The BIG-IP APM system unexpectedly terminates the session initiation with a TCP reset.
  • An error message similar to the following example is logged in the /var/log/apm file:

    Internal error (APM::RBA requested abort (trans end error))
