Description

When query the SNMP OID sysIfName, the value will change after interface up/down event.
For example:

# snmpwalk -v2c -c public localhost sysIfName

F5-BIGIP-SYSTEM-MIB::sysIfName.1 = STRING: mgmt

F5-BIGIP-SYSTEM-MIB::sysIfName.2 = STRING: 1.1      ---------> sysIfIndex.2 is 1.1.

F5-BIGIP-SYSTEM-MIB::sysIfName.3 = STRING: 1.2

F5-BIGIP-SYSTEM-MIB::sysIfName.4 = STRING: 1.3

After interface state change, like make interface 1.1 from UP to DOWN, then the sysIfName order changed:

# tmsh modify net interface 1.1 disabled

# snmpwalk -v2c -c public localhost sysIfName

F5-BIGIP-SYSTEM-MIB::sysIfName.1 = STRING: mgmt

F5-BIGIP-SYSTEM-MIB::sysIfName.2 = STRING: 1.2

F5-BIGIP-SYSTEM-MIB::sysIfName.3 = STRING: 1.3

F5-BIGIP-SYSTEM-MIB::sysIfName.4 = STRING: 1.1     ---------> 1.1 changed to sysIfName.4.

Environment

  • BIG-IP
  • SNMP

Cause

Under investigation.

 Recommended Actions

Please choose other OID instead of sysIfName, for example:

sysInterfaceName
sysInterfaceStatName
sysIfIndex

Additional Information

None.
