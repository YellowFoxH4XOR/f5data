Source

Description

All virtual servers are marked down od gtm server representing one LTM from HA pair. On gtm server representing peer LTM from the same Sync-Failover group, statuses of virtual servers are correct - same as on the LTM itself.

Environment

  • BIG-IP DNS
  • LTM Active-Standby pair

Cause

Given LTMs were added as a separate gtm servers on the BIG-IP DNS.

Recommended Actions

To add LTMs in Active-Standby pair, create one gtm server representing the HA pair with 2 devices configured - 1 for LTM Active and 1 for LTM Standby.

Example:

gtm server DC1_LTM {
    addresses {
        192.168.1.2 {
            device-name DC1_LTM1
        }
        192.168.1.3 {
            device-name DC1_LTM2
        }
    }
    datacenter DC1
    devices {
        DC1_LTM1 {
            addresses {
                192.168.1.2 { }
            }
        }
        DC1_LTM2 {
            addresses {
                192.168.1.3 { }
            }
        }
    }
    monitor bigip
    product bigip
    virtual-server-discovery enabled
    virtual-servers {
