The Validation Configuration section of the XML profile is used to upload user-defined schema files and WSDL documents. You can use the User-defined Schema for SOAP drop-down option to upload a self-contained SOAP schema file into the XML profile. This option should be used when you want the BIG-IP ASM to inspect XML-based messages transfered using the SOAP protocol. When you upload the schema file using the User Defined Schema for SOAP option, the BIG-IP ASM can extract the XML messages from the SOAP container and apply the schema to the XML message.

Configuring a User-defined Schema for SOAP in the XML profile

To configure a User-defined Schema for SOAP in the XML profile, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Application Security.
  3. Click Web Applications.
  4. Click the relevant security policy.
  5. Click XML Profiles.
  6. Click the relevant XML profile.
  7. In the Validation Configuration section, select User-defined Schema for SOAP.
  8. Click Browse, and browse to the location of the SOAP schema file.
  9. Click Upload.
  10. Click Update.
  11. Click Apply Policy.
