Description

BIG-IP DNS WideIP is not responding to AAAA query.

Environment

  • BIG-IP DNS
  • AAAA query
  • No IPv6 address returned

Cause

Configuration/wideip not available

Recommended Actions

Follow these steps to verify the configuration and troubleshoot further:

1. Check the AAAA wideip configuration:

tmsh list gtm wideip aaaa

2. Use dig command against the dns listener IP configured on BIG-IP DNS:

dig @<dns listener> ipv6.example.com aaaa +short

In the above example there should be a gtm wideip aaaa object called "ipv6.example.com". If not then an object needs to be created in order to respond to the query.

Continue to next step if object has been created but still not responding.

3. Check the status of this object:

tmsh show gtm wideip aaaa ipv6.example.com

If the status is unavailable, follow troubleshooting steps:

K15408: Troubleshooting BIG-IP DNS monitors
