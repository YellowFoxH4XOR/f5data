Description

Unclear documentation regarding which command to use to shut down an F5 rSeries appliance via CLI. Error: uncertainty about shutdown procedure.

Environment

  • Product: F5OS
  • Version: 1.8.4
  • Access method: CLI (Bash shell, logged in as the admin user)

Cause

None

Answer/Recommended Actions

To shut down an F5 rSeries appliance via CLI, log in as the root user and use any of the following standard Linux commands from the Bash shell:

  • halt
  • poweroff
  • shutdown -H now

The poweroff command is a straightforward and commonly used option.

Powering the Device Back On:

After issuing a shutdown command, the device will not automatically restart. You must manually power the device back on using one of the following methods:

  1. Use the LCD front panel menu.
  2. Use the AOM (Always-On Management) subsystem.

Additional Information

  • These are standard Linux commands available in the Bash shell on F5OS-based rSeries appliances.
  • Manual power-on action is required after shutdown; ensure physical or out-of-band (AOM) access is available before issuing a shutdown command remotely.
