Topic

The following procedure configures a static Application Tunnel (App Tunnel) for access to one or more Microsoft Windows file shares. Additionally, the net use command is configured to automatically map a network drive after the App Tunnel opens.

Note: You cannot map a network drive using a dynamic App tunnel. For more information, refer to K7952: Dynamic App Tunnels do not support the Microsoft Windows net use command.

Before you begin, determine whether you will specify a hostname or IP address for the Windows file server (Step 10 in the FirePass version 6.x procedure and Step 6 in the FirePass version 5.x procedure). If you configure a hostname instead of an IP address, the static App Tunnel will not work in the following instances:

  • The user is running Windows Vista

    Note: For more information, refer to K7183: Drive mapping with a static App Tunnel does not support Microsoft Windows Vista clients.
     
  • The user is running Windows XP, and the user has a Limited User account

    Note: For more information about Limited User accounts, refer to http://www.microsoft.com/protect/computer/advanced/useraccount.mspx.
     
  • The user does not have the required Windows permissions to modify the system Hosts file

    Important: This condition applies to all supported Windows systems, not just Windows XP or Windows Vista.

If you are running FirePass version 6.0.3, you can work around these issues by installing the DNS Relay Proxy service on the Windows client. You can download the DNS Relay Proxy client component on the Device Management: Client Downloads: Windows (x86) page in the FirePass Administrative Console.

If you are running FirePass version 6.0.2 or earlier, the App Tunnel configured in the following procedure will not support users running Windows Vista, or users with limited privileges on the client system.

Configuring an App Tunnel

To configure an App Tunnel for accessing a Microsoft Windows file share, perform the following procedure based on the version of your FirePass controller:

FirePass versions 6.0.0 and later

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Application Access: App Tunnels: Resources page.
  3. Click the Add New Favorite link.
  4. In the Name field, enter a name for the favorite.
  5. In the Allow List field, enter a list of hosts, networks, and ports that users are allowed to access.

    For example:

    172.30.11.0/27:139,445
    192.168.120.32:139,445
  6. Click the Add Favorite button.

    The App Tunnel favorite is created, and additional configuration options appear.
  7. Click the plus ( + ) sign next to Static Tunnels to expand the Static Tunnels section.
  8. Click the Add New Static Tunnel button.
  9. In the New Static Tunnel menu, select MS File Shares.
  10. In the Remote Host field, enter the hostname or IP address of the Windows file server.

    Important: If you are entering a hostname, refer to the Prerequisites section for potential client compatibility issues.
  11. Note the values listed in the Local Host: Port or Range fields, but do not change them.
  12. In the Application field, enter the net use command you want to run on the client system, or the path to the batch script containing one or more net use commands.

    For example:

    net use s: \\fs1.example.com\public %password% /user:MYDOMAIN\%username% /persistent:no

    Important: If you specify an IP address instead of a hostname in the net use command, ensure you use the IP address listed in the Local Host field (Step 11) and not the actual IP address of the remote file server.
     
    Note: In the example above, the FirePass %username% and %password% session variables pass the user's FirePass logon credentials to the remote server. If the user's logon credentials for the remote server are not the same as the user's FirePass logon credentials, do not use the %username% and %password% session variables.
  13. Click the Add New Static Tunnel button.

FirePass versions 5.5.2 and earlier

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Application Access: App Tunnels: Resources page.
  3. Click the Add New Favorite link.
  4. In the Name field, enter a name for the favorite.
  5. In the Add new menu, select MS Terminal Services.
  6. In the Add new text field, replace Remote Host with the hostname or IP address of the Windows file server.

    Important: If you are entering a hostname, refer to the Prerequisites section for potential client compatibility issues.
  7. Click the Add New button.

    FirePass creates the App Tunnel and displays its configuration settings.
  8. Note the values listed in the Local Host: Port or Range fields, but do not change them. 
  9. In the Command Line field, enter the net use command you want to run on the client system, or the path to the batch script containing one or more net use commands.

    For example:

    net use s: \\fs1.example.com\public %password% /user:MYDOMAIN\%username% /persistent:no

    Important: If you specify an IP address instead of a hostname in the net use command, ensure you use the IP address listed in the Local Host field and not the actual IP address of the remote file server.
     
    Note: In the example above, the FirePass %username% and %password% session variables pass the user's FirePass logon credentials to the remote server. If the user's logon credentials for the remote server are not the same as the user's FirePass logon credentials, do not use the %username% and %password% session variables.
  10. Click the check mark icon to the right of the Command Line field to save the change.
