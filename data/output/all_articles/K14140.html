Known Issue

The VIPRION system may experience an unexpected reboot when you select a new boot image from the GRUB menu.

This issue occurs when all of the following conditions are met:

  • The VIPRION chassis has two or more blades.
  • You access the VIPRION blade using a serial console.
  • When the blade boots up, you select a new boot image location from the GRUB menu.

When a blade from a VIPRION cluster uses a different boot image location from the cluster's default boot image location, the VIPRION system reboots the blade to use the matching boot image location so it can join the VIPRION cluster following the reboot.

Impact

The blade that was connected to the console experiences an additional reboot.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The blade that was connected to the console experiences an additional reboot without user intervention.
  • The VIPRION cluster default boot image location and the affected blade's boot image location do not match.

Workaround

None. To avoid this issue, F5 recommends that you change the boot image location of a VIPRION system using the Configuration utility. For more information, refer to K9296: Changing the default boot image location on VIPRION platforms.
