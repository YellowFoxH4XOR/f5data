Description

After upgraded one of BIG-IP in Sync / Sync-Failover group, the configsync status may become disconnected status.

 

Environment

  • BIG-IP HA pair
  • Sync status
     

Cause

Configuration sync may not supported between different versions.
 

Recommended Actions

When it is displayed, run following command on CLI, it may show incompatible version
 
show /cm sync-status
--------------------------------------------------------
CM::Sync Status

--------------------------------------------------------
Color    red
Status   Disconnected
Mode     sync-only
Summary
Details
         bigip1.f5.com: incompatible version
         bigip2.f5.com: incompatible version
         Optional actions:
          - Add a failover device group with this device


Complete the upgrade on the peer device in the HA pair, to restore configuration sync functionality.
