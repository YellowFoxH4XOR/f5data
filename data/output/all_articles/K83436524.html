Description
When selecting the Instances tab on a specific LTM Health Monitor, it is possible for Tomcat's Java process to consume 100% of CPU, causing the GUI to become completely unresponsive for an unreasonable period of time (in excess of five minutes).  While the GUI does return after a time, the instances tab never loads.  

Environment

  • LTM Health monitor

Cause
Unknown.

Recommended Actions

Please use tmsh for viewing monitor instances if you observe this behavior:

tmsh show ltm monitor <type> <name> instances

For instance to show the default http monitor instances, we would use:

tmsh show ltm monitor http http instances
