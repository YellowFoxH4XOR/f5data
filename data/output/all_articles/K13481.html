Known Issue

When using the Configuration utility, some pop-up windows may appear as a black box.

This issue occurs when all of the following conditions are met:

  • You are using Internet Explorer 8 (IE8)
  • IE8 is configured to render the BIG-IP web interface in Compatibility View mode

Impact

You cannot view and modify certain pages in the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When opening one of the affected Configuration utility pages, you see a dark screen.
  • Pages that are affected may include, but are not limited to the following:
    • Managing device groups
    • Managing traffic groups
    • Initiating a software installation

Resolution

Status

F5 Product Development has assigned ID 368069 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of the article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

Disabling Compatibility View mode in IE8

Impact of workaround: Websites outside of the Configuration utility that require Compatibility View may not function correctly.

  1. From the IE8 Tools menu, select Compatibility View Settings.
  2. If the Display all websites in Compatibility View option is selected, clear this option.
  3. Confirm that no other options allow your BIG-IP system to be included in Compatibility View mode.
  4. Click Close.

You may want to re-enable Compatibility View mode after using the Configuration utility.

Note: Internet Explorer 9 and Mozilla Firefox have not been reported to exhibit this issue.
