Known Issue

The monpd process may log error messages during system startup.

This issue occurs when the following condition is met:

  • You install a new image on an inactive volume, and then later reboot the system to the same volume.

    For example, if you run the BIG-IP Analytics or AFM modules (on volume-1) with reporting working properly, and then you install a new image on an alternate volume (volume-2), the system logs monpd messages after rebooting to the initial volume (volume-1).

Impact

None. The error messages are harmless, and do not impact system performance.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/ltm and /var/log/avr/monpd.log files, you observe messages similar to the following example:

    err DB[6249]: monpd|ERR|Jul 09 12:23:36.328|8809| [DB::mysql_query_safe, query failed] Error (error number 1493) executing SQL string : CALL AddPartitionAVR_STAT_ENFORCED_ACL_D', NULL, 1372258801, 'D')  Because : VALUES LESS THAN value must be strictly increasing for each partition.
