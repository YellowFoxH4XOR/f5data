Description

How do I enable AES128 and AES256 encryption types for Kerberos SSO or Kerberos Auth in krb5.conf on BIG-IP?

Environment

  • BIG-IP APM (any version supporting Kerberos SSO or Kerberos Clientside Auth)
  • Kerberos SSO profile configured: Overview of Kerberos constrained delegation
  • Kerberos Client side auth configured: Configuring Kerberos end-user logon authentication for multiple applications by merging keytab files

Answer/Recommended Actions

Enable AES128 and AES256 encryption types for Kerberos SSO in krb5.conf:

  1. Edit the /etc/krb5.conf file on your BIG-IP system using nano or VI.
  2. Add or update the following lines under the `[libdefaults]` section (add it if it doesn't exist):
[libdefaults]
default_tkt_enctypes = aes256-cts-hmac-sha1-96 aes128-cts-hmac-sha1-96
default_tgs_enctypes = aes256-cts-hmac-sha1-96 aes128-cts-hmac-sha1-96
permitted_enctypes = aes256-cts-hmac-sha1-96 aes128-cts-hmac-sha1-96
  1. Save the file.
  2. Restart the websso daemon to apply changes immediately
     
    bigstart restart websso
