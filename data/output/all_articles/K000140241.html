K000140241: FQDN Ephemeral Pool Member Monitors Stuck at Unknown/Checking after Sync

Type
Support Solution
Published
2024-07-03
Updated
2024-07-03
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000140241

Description

  • FQDN node status changes to Unknown/Unchecked on peer device after config sync
  • If you enable all the FQDN nodes and then sync the configuration, the to-be synced unit shows its FQDN ephemeral pool members on unknown state.

Environment

  • BIG-IP LTM.
  • FQDN node.
  • FQDN ephemeral pool member.

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 1297257.

Recommended Actions

Apply workaround for Bug ID 1297257 each time the conditions are met.

At the time of creation of this article, there is no fix available on a stable release yet, but if required an EngHF with the fix can be provided.

None
