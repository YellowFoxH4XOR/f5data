K000133779: BIG-IQ disk partition is full

Source
https://my.f5.com/manage/s/article/K000133779

Description

BIG-IQ disk partition /var is 100% full and users are unable to login.

Environment

  • BIG-IQ
  • /var disk space filling up

Cause

Audit log database consuming disk space

Recommended Actions

You can manage the archive setting for each by going to Monitoring tab -> Audit Logs -> -> Archive Settings.
By default, the database table is configured to retain entries for a period of 30 days.
If the retaining period is reduced, it can result in a reduction of the table size over time.

See also:

K18484011: BIG-IQ Reclaim unused disk space from postgres

Additional Information

Use the following commands to monitor database and disk usage:

df -h | egrep '_var|Filesystem'

psql -U postgres -d bigiq_db -c "SELECT pg_size_pretty( pg_database_size('bigiq_db') );"

du -sh /var/lib/pgsql/data/
