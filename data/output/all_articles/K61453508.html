Description

Configuration failed to load on upgrade or configuration reload, with an error similar to:

emerg load_config_files[18905]: "/usr/bin/tmsh -n -g -a load sys config partitions all base " - failed. -- 01070712:3: Values (/Common/nh-pool) specified for security nat policy rule (/Common/nat-pol nat-rule): foreign key index (next_hop_pool_FK) do not point at an item that exists in the database.

Pool in question does exist in the configuration file.

Environment

  • NAT Policy
  • Rule referencing next-hop pool
  • Upgrade
  • Full configuration reload

Cause

ID1067393

Recommended Actions

Bug ID1067393 has no fix at the time of this article's publication.

To work around the issue, reload the configuration:

tmsh load sys config

The configuration will load successfully. No changes to the configuration are needed.
