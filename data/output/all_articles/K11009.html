Known Issue

This is the result of a known issue. RFC2616 specifies that the Vary header can include any HTTP header or even a list of headers that the origin web server (OWS) can use to provide guidance to proxy servers in the management of their local caches. However, the HTTP cache will only honor User-Agent and Accept-Encoding as valid entries for the Vary header. If the Vary header includes entries other than User-Agent or Accept-Encoding, the BIG-IP system ignores the headers.

Note: The Vary header allows the OWS to specify an HTTP header in a response that helps determine which resource a proxy server returns from its cache. For more information about the HTTP cache and HTTP Vary header functionality, refer to K5157: BIG-IP HTTP cache and HTTP Vary header functionality.

F5 Product Development is tracking this issue as ID 221995 (formerly CR107224).
