Description

Merging Multiple NGINX Plus Container Images into One Image.

This article describes how to combine multiple NGINX Plus Docker images into a single image using a multi-stage Docker build. While this example demonstrates merging the OpenTelemetry (**otel**) dynamic module into the base NGINX Plus image, the same approach can be applied to other NGINX Plus dynamic modules as needed.

Environment

- NGINX Plus Docker Images
- Alpine Linux
- Docker BuildKit enabled for secure build-time secrets

    Cause

    In some cases, you may need to combine the NGINX Plus base image with additional dynamic modules (such as OpenTelemetry) that are provided as separate module images. Docker does not provide a built-in method to merge two images, so a multi-stage build is used to consolidate the required components into a single container image.

    Recommended Actions

    1. See the command examples below to get the image tags for Alpine Linux and the OpenTelemetry module used in this article:
    # curl -s https://private-registry.nginx.com/v2/nginx-plus/agent/tags/list --key nginx-repo.key --cert nginx-repo.crt | jq |grep '"alpine' 
    "alpine",
# curl -s https://private-registry.nginx.com/v2/nginx-plus/modules/tags/list --key nginx-repo.key --cert nginx-repo.crt | jq | grep alpine | grep otel
    "otel-alpine",
     ...
    2. Add the OpenTelemetry module by using the `load_module` directive in the main context of your `nginx.conf`:
    load_module modules/ngx_otel_module.so;
    3. Use this Dockerfile example to merge the two images:
    FROM private-registry.nginx.com/nginx-plus/modules:otel-alpine AS otel
FROM private-registry.nginx.com/nginx-plus/agent:alpine
COPY --from=otel / /

# Optional: copy your nginx.conf
COPY nginx.conf /etc/nginx/nginx.conf
    4. Ensure that the following files are present in your build directory:
    # ls
Dockerfile  license.jwt  nginx.conf  nginx-repo.crt  nginx-repo.key
    5. Build the image using Docker BuildKit and your NGINX Plus repository credentials:
    docker build --no-cache \
  --secret id=nginx-key,src=nginx-repo.key \
  --secret id=nginx-crt,src=nginx-repo.crt \
  -t nginxplus_otel_enabled .
    6. Run the container with the license.jwt file mounted as described in the official documentation:
     
    Run the NGINX Plus container
     

    Additional Information

    • Please refer to this guide to see the list of all tags
    • This process works for any other NGINX Plus dynamic module images, not just OpenTelemetry.
    • Always include the load_module directive for each module you add.
    • Keep your license.jwt file mounted at runtime instead of adding it into the image for security and easier license updates.
