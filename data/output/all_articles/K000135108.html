Description

Observing the following log a lot in /var/log/ts/bd.log

/var/log/ts/bd.log:IO_PLUGIN|NOTICE|Jun 12 22:58:59.894|15990|io_plugin.c:0988|Invoke Plugin tm_soft_reset.

/var/log/ts/bd.log:IO_PLUGIN|NOTICE|Jun 12 22:58:59.919|15991|io_plugin.c:0988|Invoke Plugin tm_soft_reset.

Environment

  • BIG-IP ASM 

Cause

This occurs when certain configuration changes are made and the ASM plugin configuration needs to be adjusted.

Recommended Actions

A high occurrence of these messages would indicate lots of configuration changes, but the messages are considered to be benign in nature.
