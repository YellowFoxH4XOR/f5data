Known Issue

The pimd process may produce a core file and restart on a standby BIG-IP device.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is part of a high availability (HA) device group.
  • Your BIG-IP configuration uses dynamic routing.
  • The dynamic routing configuration uses PIM Sparse Mode (PIM-SM) or Source Specific Multicast (SSM) for multicast routing.
  • A failover event occurs.

Impact

The pimd process restarts.

Note: This issue does not affect dynamic routing.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The pimd process generates a core file in the /shared/core directory of the standby device.
