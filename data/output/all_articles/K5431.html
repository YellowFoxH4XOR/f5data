Topic

You can configure BIG-IP DNS monitors to monitor the status of servers, links, virtual servers, pools, and individual pool members.

When applying monitors in the BIG-IP DNS system, F5 recommends the following configuration to maximize availability, assurance, and scalability:

  • Apply gateway_icmp and bigip_link monitors to links. For information, refer to K6848: Monitoring link objects on a BIG-IP GTM or BIG-IP Link Controller system.
  • Use bigip monitors for the following purposes:
    • To monitor BIG-IP servers
    • To monitor a BIG-IP virtual server with a virtual address that overlaps a non-floating IPv6 or IPv4 self IP address
  • Apply content-specific monitors to pools or pool members; avoid applying monitors to each individual virtual server.
  • When you configure BIG-IP DNS Extended Application Verification (EAV) monitors, make sure that you installed the monitor script on all F5 devices that reside in the same data center as the BIG-IP DNS system.

    Note: For more information, refer to K8154: The BIG-IP GTM EAV monitor considerations.

Important: When all members of a BIG-IP DNS pool are BIG-IP LTM virtual servers, you do not need to associate a monitor with the DNS pool. The health monitors on the BIG-IP LTM system provide the status for those virtual servers, and the BIG-IP LTM system's big3d agent uses iQuery to report the BIG-IP LTM virtual server status to the BIG-IP DNS system.

When you apply monitors to both the BIG-IP LTM virtual server object and its corresponding BIG-IP DNS virtual server object, the system runs both monitors. The system may generate excessive monitor traffic when using both monitors in the configuration, potentially overwhelming the resources that the system is monitoring and the monitoring agents. When this behavior occurs, some monitors may result in false negatives, and the system may incorrectly mark down objects.
