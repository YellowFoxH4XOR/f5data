K000150210: The GSLB pool Limit Settings function is not working

Type
Support Solution
Published
2025-03-17
Updated
2025-03-17
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150210

Description

The GSLB pool configuration includes a Limit Settings feature, which allows you to set limits based on bits, packets, and current connections to control pool availability. When one or more limit settings are enabled, the system evaluates the cumulative virtual server load and adjusts pool availability accordingly.

However, if you enable Limit Settings and specify values for bits, packets, and current connections, you may notice that the limits do not take effect as expected. When the Limit Settings feature is functioning, the GTM will generate the following log entries.

gtm.test.com alert gtmd[14816]: 011a1005:1: SNMP_TRAP: Pool /Common/gslb_pool state change green --> yellow (Pool limit(s) exceeded on GTM)
gtm.test.com alert gtmd[14816]: 011a1004:1: SNMP_TRAP: Pool /Common/gslb_pool state change yellow --> green

Environment

  • GSLB
  • Limit Settings
  • Pool limit(s) exceeded on GTM

Cause

Enabling the GSLB pool configuration Limit Settings alone is not sufficient for the feature to work. It relies on the GSLB snmp_gtm monitor, which requires the target server to have an SNMP agent running. The snmp_gtm monitor sends OID queries to retrieve data on interface throughput, total packets, and current connections from the server.

The related OIDs:

Bits:

1.3.6.1.2.1.2.2.1.10 ifInOctets Total number of bytes received (including headers)
1.3.6.1.2.1.2.2.1.16 ifOutOctets Total number of bytes transmitted (including headers)

Packets:

.1.3.6.1.2.1.4.3.0	ipInReceives	Total number of received IP packets
.1.3.6.1.2.1.4.10.0	ipOutRequests	Total number of sent IP packets

Current connection:

.1.3.6.1.2.1.6.9.0	tcpCurrEstab	Number of currently ESTABLISHED TCP connections

Recommended Actions

Please refer https://techdocs.f5.com/kb/en-us/products/big-ip_gtm/manuals/product/gtm-implementations-11-6-0/19.html attach the snmp_gtm monitor for GTM server.
