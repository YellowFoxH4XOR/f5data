Issue

Old Behavior

In BIG-IP APM versions prior to 11.0.0, the BIG-IP system uses the adminreports.pl command line utility to view reports.

New Behavior

Beginning in BIG-IP APM 11.0.0, the adminreports.pl utility has been removed.

The adminreports.pl utility uses bigpipe commands for its functionality. Starting in BIG-IP 11.0.0, the bigpipe command line interface has been replaced by the Traffic Management Shell (tmsh), rendering the adminreports.pl utility inoperable.

F5 Product Development tracked this change as ID 359191.

Impact

Any report generation that relies on the adminreports.pl utility will fail.

Recommended Actions

The reporting capability of the adminreports.pl utility has been replaced by enhanced reporting in the BIG-IP Configuration utility. You can access the reports by navigating to Access Policy > Event Logs > Access System Logs. For versions prior to 12.0.0, navigate to Access Policy > Reports.
