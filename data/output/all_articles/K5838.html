Topic

When saving a Support Snapshot file, the suggested file name is as follows:

case_number_###_support_file[1].tar.gz

However, if your Microsoft OS workstation is configured to use the Hide extensions for known file types setting, and you are using Microsoft Internet Explorer, the suggested file name does not include the .gz extension. The suggested file name is as follows:

case_number_###_support_file[1].tar

Some applications may not handle the file properly without the .gz extension. To ensure that the application can handle the file properly, you can rename the file and add the .gz extension.

You can prevent future Support Snapshot files from being saved without the .gz file name extension by deselecting the Hide extensions for known file types setting on your workstation. For more information, consult your Microsoft OS documentation.

Note: Starting in BIG-IP 11.4.0, the qkview file extension has changed from .tar.gz to .qkview. F5 Product Development tracked this change in ID 382974.
