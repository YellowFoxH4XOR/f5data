Topic

Starting in FirePass version 7.0.0, you can specify high and true color resolution when creating a Java terminal server favorite. In FirePass versions 6.1.0 and earlier the Java version of the Microsoft Terminal Services (Remote Desktop) client supported 256 colors (8-bit resolution). If you configured a Microsoft Terminal Server favorite and select the Java client check box, the Java client used 8-bit resolution even if you selected a higher resolution in the Color Depth menu.

Note: The Microsoft Terminal Services Java client was introduced in FirePass version 6.0.3

Note: You can configure Terminal Server favorites on the Application Access: Terminal Servers: Resources page in the FirePass Administrative Console.

The ActiveX version of the Microsoft Terminal Services ActiveX client does support higher resolutions. The ActiveX client is used when you do not select the Java client check box. However, the ActiveX client only supports Microsoft Window systems.

F5 Networks Product Development tracked this request for feature enhancement as CR109713 and it was added in FirePass version 7.0.0. For information about upgrading, refer to the FirePass Release Notes.
