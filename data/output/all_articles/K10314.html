Known Issue

This is the result of a known issue. If you install cumulative hotfix HF-603-4, Active Directory authentication and Active Directory dynamic group mapping may fail. This issue occurs because the memberOf attribute returned by the Active Directory server may contain multiple Common Name (CN) values, but FirePass inspects only the first CN.

For Active Directory authentication, the memberOf attribute is used when you configure a group name in the User must belong to Domain group (optional) field under the Authentication tab in the master group configuration.

For dynamic group mapping, the memberOf attribute is used when you select the primaryGroupId and memberOf or memberOf only option in the Mapping attribute field in the Active Directory mapping group method.

Important: An additional issue was introduced in cumulative hotfix HF-603-4. For more information, refer to K10341: After installing cumulative hotfix HF-603-4, Active Directory authentication and group mapping may fail when nested groups are enabled.

F5 Product Development tracked this issue as CR125518 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-603-4.2 issued for FirePass version 6.0.3. You may download these hotfixes or later versions of the cumulative hotfix from the F5 Downloads site.
