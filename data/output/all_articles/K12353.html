Known Issue

If an object matches one node in the Policy Tree for the request and a different node for the response, and the object is eligible for Intelligent Browser Referencing (IBR), the BIG-IP WebAccelerator system may fail to append the pv tag to the object.

F5 Product Development is tracking this issue as ID 343422.
