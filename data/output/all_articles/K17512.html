Known Issue

BIG-IP ASM Security Policy import modifies the policy options of the imported policy.

This issue occurs when all of the following conditions are met:

  • Your Security Policy is configured with HTTP Protocol Compliance options disabled and you perform one of the following tasks:

    • You upgrade your BIG-IP ASM system to 11.6.0.
    • You import a Security Policy that was created on a BIG-IP ASM system running a version prior to 11.6.0, to a BIG-IP ASM 11.6.0 system.

Impact

The Security Policy is imported with HTTP Protocol Compliance options enabled.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you review the security policy before upgrading your BIG-IP ASM system to 11.6.0, HTTP Protocol Compliance options are disabled.
  • When you review the security policy after upgrading your BIG-IP ASM system to 11.6.0, HTTP Protocol Compliance options are enabled.
  • When you review the security policy before importing to a BIG-IP ASM 11.6.0 system, HTTP Protocol Compliance options are disabled.
  • When you review the security policy after importing to a BIG-IP ASM 11.6.0 system, HTTP Protocol Compliance options are enabled.

Workaround

To work around this issue, you can disable the HTTP Compliance options after import or upgrade. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Security > Application Security > Blocking > Settings.
  3. Ensure that the Current edited policy is the affected policy.
  4. In the RFC Violations section of the Violations List, locate HTTP protocol compliance failed.
  5. Remove the appropriate checked Enforcement mode settings to the right (for example: Learn, Alarm, Block).

    Note: For advanced modification, you can expand the tree level view of the HTTP protocol compliance failed section and modify individual compliance settings.

  6. Click Save.
  7. Click Apply Policy.
