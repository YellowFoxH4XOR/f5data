Topic

The BIG-IP Edge Client for Windows has a feature that can establish a VPN tunnel to BIG-IP APM prior to Windows Logon. This feature is called Windows Logon Integration. The following procedure configures Windows Logon Integration on a Windows client system. The Windows Logon Integration component allows users to establish a VPN connection when they logon to their Windows systems without modifying Microsoft GINA components. The connection that users receive appears as a dial-up connection on the Windows client system, and the Windows Logon Integration component provides support for logon scripts, such as drive mappings. For more information about the Windows Logon Integration and other components, refer to K14045: The BIG-IP Edge Client components for Windows

Important: The Windows Logon Integration component does not support all pre-logon inspectors. For more information, refer to K8097: Windows Logon Integration support for pre-logon inspectors.

Important: You can configure FirePass Windows Logon Integration on Microsoft Windows 2000 and Windows XP, or later. In order to use the Windows Logon Integration component on a Windows client system, the Log on using dial-up connection check box must be present on the Windows logon screen. The Log on using dial-up connection feature is not supported on all versions of Microsoft Windows. For example, Windows XP Professional Edition supports this feature but Windows XP Home Edition does not. To verify whether your version of Microsoft Windows supports this feature, refer to your Windows system documentation.

You can configure Windows Logon Integration by performing the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Device Management : Client Downloads : Windows (x86) page.
  3. Select the Windows Logon Integration check box.
  4. Clear all other check boxes, unless there are additional components you want to include in the installation package.
  5. Click the Update button.
  6. Click the Download tab.
  7. Click the Download customized package link, and save the package locally when prompted by your browser.
  8. Log on to the Windows client system.
  9. Install the package you downloaded in Step 7.

    This will create a Windows dial-up adaptor named Network Access.

    Note: Installing this package may require administrator privileges on the client system.

  10. Launch the Network Access adaptor, and log on to the FirePass controller using the end-user’s credentials.

    If you can successfully log on, proceed to the next step. Otherwise, troubleshoot the issue until you can log on to the FirePass controller using the end-user’s credentials.

  11. Log out from the Windows client system.
  12. At the Windows logon screen, enter the end-user’s Windows credentials and select the Log on using dial-up connection check box.

    Note: If the Log on using dial-up connection check box does not appear on the Windows logon screen, the feature may not be supported on your version of Microsoft Windows.

  13. In the Network Connections pop-up window, select Network Access from the Choose a network connection: drop-down menu.
  14. Click the Connect button.
  15. If the Network Connections pop-up Window reappears requesting logon credentials, enter the end-user’s FirePass logon credentials and click the Connect button.

    The user is logged on to Windows, and the Network Access dial-up adaptor is connected.

Starting in FirePass version 6.0.2, you can use Client Certificate Two-Factor Authentication with the FirePass Windows Logon Integration component. For more information, refer to K8095: Overview of Windows Logon Integration and Client Certificate Two-Factor Authentication.
