K13890213: Failed to add a BIG-IP LTM to BIG-IQ when having the default ''admin'' account disabled.

Type
Support Solution
Published
2021-10-04
Updated
2024-06-12
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K13890213

Description

A BIG-IP with a default "admin" account disabled may get an error when adding it to BIG-IQ.

  • Logs on BIG-IP: 
icrd_child[12447]: 01420002:5: AUDIT - Cannot load user credentials for user "admin"
  • Logs on BIG-IQ: 
Authentication Failure to host <BIG-IP MGMT IP>. Please check the credentials provided.

Environment

  • BIG-IP with default "admin" account disabled.
  • BIG-IQ

Cause

None

Recommended Actions

When seeing the error, restart the restjavad on the BIG-IP should help to work around the issue.
This command should not have a negative impact on the device.
# tmsh restart sys service restjavad

Additional Information

None.
