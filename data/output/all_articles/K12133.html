Known Issue

Description

The BIG-IP bcm56xxd process does not support all of the media options for the small form-factor pluggable (SFP) or small form-factor pluggable plus (SFP+) transceiver. Instead, the BIG-IP system will only publish the SFP and SFP+ media defaults.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system has interfaces populated with SFP or SFP+ media devices.
  • The BIG-IP SFP ports are connected to a device that does not support the default media types 1000baseT full, 1000baseLX full, and 1000baseSX full.
  • The BIG-IP SFP+ ports are connected to a device that does not support the default media types 10GbaseSR full, 10GbaseLR full, and 10baseER full.

Impact

Network connectivity on the SFP or SFP+ port(s) may fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system will report that the SFP/SFP+ port is down.
