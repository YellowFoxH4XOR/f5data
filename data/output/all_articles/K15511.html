Summary

This article provides a non-exhaustive list of commonly used Perl-Compatible Regular Expressions (PCREs) that you can configure in the BIG-IP ASM Data Guard feature to mask various kinds of sensitive data.

Description

When a web application does not adequately mask certain sensitive data, such as credit card numbers or social security numbers, you can configure the BIG-IP ASM Data Guard feature to mask some of this data by using the appropriate PCRE in the Custom Pattern setting of the Data Guard page. For information about configuring Data Guard to mask sensitive data, refer to the appropriate guides listed in the Supplemental Information section. For a list of PCREs that are commonly used for masking various kinds of sensitive data, refer to the following table:

Important: This list is non-exhaustive and might not be applicable to your application environment. F5 recommends that you perform an appropriate evaluation of the desired PCRE in your application test environment before you enable changes to your application production environment.
