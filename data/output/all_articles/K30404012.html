Known Issue

The BIG-IP system ignores Internet Control Message Protocol (ICMP) fragmentation requests.

This issue occurs when all of the following conditions are met:

  • A large ICMP Echo Request directs to a virtual address on the BIG-IP system.

    Note: A large request is one that exceeds the maximum transmission unit (MTU) of the network traversed.

  • The ICMP Echo Reply is larger than the upstream network MTU, which causes an ICMP Fragmentation Needed (Type 3 Code 4) message.

Impact

The requestor does not receive the ICMP Echo Reply.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The client sends a large ICMP Echo Request whose size exceeds the MTU of the network the packet traverses, requiring the ICMP Echo Response to be fragmented. The BIG-IP system ignores the fragmentation request and continues sending ICMP Echo Replies that exceed the network MTU.
