Issue

Error Message

01071918:3: CMI device <name> has a different version <version> from this device <version>.

In this error message, note the following:

  • <name> is the host name of the remote device
  • <version> is the version of BIG-IP software

For example:

01071918:3: CMI device (/Common/bigip1.example.com) has a different version (12.1.1) from this device (12.1.2).

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all the following conditions are met:

  • A remote BIG-IP system attempts to establish a centralized management infrastructure (CMI) connection to the local BIG-IP system.
  • The remote system is running a different BIG-IP software version than the local system

Note: CMI is also referred to as device service clustering (DSC).

Impact

The BIG-IP systems are unable to sync configurations when running different versions of software.

Recommended Actions

You normally view this message when upgrading member BIG-IP systems in a trust domain. Once the upgrade process is complete for all member systems, they are able to establish CMI communication and sync configurations.
