Description

rSeries platform 'show component' displaying details of non-existing PSU

Environment

  • F5OS-A
  • rSeries
  • PSU

Cause

Bug ID 1411157

Recommended Actions

The available workaround to delete the non-existing PSU from system manager:

  1. Verify condition as user admin:

# show components component psu-2

components component psu-2

state serial-no <serial number>

state part-no PWR-XXXX-XX

state empty false

 

    2. Log in as root user and remove psu-2 from system manager:

# docker exec system_manager confd_cmd -c "mdel /components/component{psu-2}"

 

    3. Log in again as admin to verify workaround after removing from system manager:

# show components component psu-2

-----------------------------------------^

syntax error: unknown element

Additional Information

The workaround persists after a reboot, but if one needs later to put in psu-2, reboot is needed after psu-2 is inserted for the confd to resume reporting on it.
