Issue

This error occurs when BIG-IP cannot read a certificate. The most common reasons for this error are:

  • Corrupted certificate
  • Certificate contains a passphrase
  • Invalid certificate format

Corrupted certificate

Due to a copying error or filesystem problem, the certificate may have been corrupted or truncated. Compare the copy of the certificate that you installed to the original. If there are differences, replace the installed certificate.

Certificates can also become corrupted when you copy them from a Windows system to BIG-IP. Certificates saved on a Windows system may contain ^M characters inserted due to text formatting differences.

To fix this problem, open the file with pico and save it. This will automatically remove any ^M character sequences.

 

Certificate contain a passphrase

Prior to version 9.0, BIG-IP does not support password-encrypted private keys. If the error is not due to a corrupted certificate, it probably occurred because you attempted to use a password-encrypted key.

Important: In versions prior to 4.5.11, the genkey command line utility will prompt for a password when you create a public/private key pair. Do not enter a password when you use this utility.

To confirm that a password-encrypted key is the cause of the error, perform the following steps.

  1. Log in to the command line.

  2. Change to the /config/bigconfig/ssl.key/ directory, by typing the following command:

    cd /config/bigconfig/ssl.key/

  3. Check for a password, by typing the following command:

    openssl rsa -noout -text -in <filename>

    For example:

    openssl rsa -noout -text -in mykey.key

    If the key contains a password, it will prompt for you to enter the password.

    To remove the password, refer to K3671: Removing password encryption from an SSL private key.

 

Invalid certificate format

BIG-IP only accepts certificates that use PEM format. PKCS formatted certificates will not work on BIG-IP and will cause an error.

To convert PKCS certificates to PEM format, refer to SOL2323: Converting PKCS certificates to PEM format for use with the BIG-IP SSL proxy.
