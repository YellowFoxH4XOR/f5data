Issue

Error Message

err mcpd[<PID>]: 010717e2:3: Client SSL profile (/<partition>/<ssl_profile>): must have at least one set of certificate/key.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process
  • <partition> is the partition in which the SSL profile is located
  • <ssl_profile> is the name of the SSL profile

For example:

err mcpd[8484]: 010717e2:3: Client SSL profile (/Common/example_ssl): must have at least one set of certificate/key.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You attempt to configure a Client SSL profile.
  • The Client SSL profile configuration is not associated with a certificate/key pair.

Impact

Changes to the Client SSL profile configuration are not saved.

Recommended Actions

To work around this issue, you can verify that a certificate/key pair is associated with the Client SSL profile before updating the configuration. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > SSL > Client.
  3. Click the SSL profile for which you want to modify.
  4. Select the Custom check box.
  5. If no certificate/key pair is configured in the Certificate Key Chain, click Add.
  6. For Certificate, select a certificate from the list.
  7. For Key, select a key that is paired with the certificate from the list.
  8. Click Add.
  9. Verify that the correct certificate/key pair is added to the Certificate Key Chain configuration.
  10. Click Update.
