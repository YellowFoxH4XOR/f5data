By using a virtual server as the target virtual server for the encrypted/unencrypted connection, the connection is actually an unencrypted HTTP connection for the BIG-IP kernel. This allows node selection and layer 7 parsing functions (including web aggregation) to occur before the connection is passed back to the proxy for re-encryption.

Web aggregation cannot be applied if a proxy is used to send re-encrypted connections to a target server, rather than a target virtual server that is configured on the BIG-IP, such as when using the BIG-IP SSL-to-Server proxy option. Instead, the connection is sent directly to a destination address (server) that is not load balanced by the BIG-IP.

Note: For additional information about the web aggregate functionality, refer to K1548: Overview of the web aggregation (OneConnect) feature.
