Description
When running host command to resolve a Wide IP address the output may return "not found: 3(NXDOMAIN)" error. The output may come with one or two of these error lines.

# host www.domain.com. nameserver.domain.com.
Using domain server:
Name: nameserver.domain.com.
Address: 10.1.1.53#53
Aliases:

www.domain.com has address 10.1.100.100
Host www.domain.com not found: 3(NXDOMAIN)
Host www.domain.com not found: 3(NXDOMAIN)

 

Environment

  • BIG-IP DNS (GTM)

Cause
The host command requests three records:

  • A Record
  • AAAA Record
  • MX Record


If there is no AAAA record and IPv6 NoError Response is not enabled you will see one of this error lines.
The second error line with "not found: 3(NXDOMAIN)" will show if there is no MX record.

Recommended Actions

  1. Use the -t flag in the host command so it only queries the A record
# host -t www.domain.com. nameserver.domain.com.
Using domain server:
Name: nameserver.domain.com.
Address: 10.1.1.53#53
Aliases:

www.domain.com has address 10.1.100.100
  1. Enable IPv6 NoError Response to avoid one error returned.
  2. Add an AAAA and a MX to your records.
