Known Issue

Persistence records may time out unexpectedly for FastL4 connections.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP virtual server is configured with a FastL4 profile.
  • The virtual server is also configured with source address persistence.
  • The virtual server processes traffic that matches one of the following types:

    • Stream Control Transmission Protocol (SCTP)
    • Encapsulating Security Payload (ESP)
    • User Datagram Protocol (UDP) with a packet checksum value of 0 (zero)

Impact

The persistence timer is not updated by traffic flow, and times out prematurely.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Traffic processed by the virtual server persists for connections until the configured persistence profile timeout value is reached.
