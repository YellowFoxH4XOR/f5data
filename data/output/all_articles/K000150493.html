Description

Assigning Static SNAT Addresses per Client IP Using iRules

Environment

  • LTM
  • SNAT
  • iRule

Cause

The pool member needs to identify which specific client IP is connected via its SNAT address

Recommended Actions

Example scenario:

  • 10.18.10.16 >> translated to 172.16.99.10
  • 10.18.10.23 >> translated to 172.16.99.20
  • Any other ip >> translated to automap  (10.18.10.9 >> translated to 172.16.97.2)
  • Connecting to VS : 10.18.10.111 with two pool members (172.16.20.101 and 172.16.20.104)
when CLIENT_ACCEPTED {
  if { [IP::addr [IP::client_addr] equals 10.18.10.16/32] }{
    snat 172.16.99.10
  }
  elseif { [IP::addr [IP::client_addr] equals 10.18.10.23/32] }{
    snat 172.16.99.20
  }
  else {
    snat automap
  }
}

Additional Information

You can check the show sys connection table to verify the SNAT per client ip address:

tmsh show sys connection cs-client-addr 10.18.10.0/24
