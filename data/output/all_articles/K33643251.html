Description

F5 technical support no longer provides technical support for Oracle Access Manager (OAM) .

As Oracle no longer supports OAM 10g and 11g, the support for OAM as AAA server in BIG-IP APM is also deprecated for all BIG-IP versions. For more information, refer to the following on Oracle:

  • Deprecated Features in Oracle Application Server 10g Release 3 (10.1.3)
  • Oracle Database 11gR2 (11.2) Lifetime Support Changes

Note: These links take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.
 

Environment

  • BIG-IP APM
  • Oracle Access Manager (OAM)

Cause

None

Recommended Actions

  1. Use a different AAA server (such as SAML) in BIG-IP APM
