Known Issue

This is the result of a known issue. If you use the Configuration utility to make changes to copper small form-factor pluggable (SFP) interfaces, the BIG-IP system may not save the changes to the configuration file.

Any change you make to the interface could revert back to the previous configuration after you reboot the system.

Note: This known issue happens only if you use the Configuration utility; if you use the command line you will not encounter this issue.

F5 Product Development is tracking this issue as ID 227138.

Workaround

To work around this behavior and prevent the BIG-IP system from reverting any changes you made to the copper SFP interfaces back to the previous interface configuration, type the following save command from the command line after you have made the change in the Configuration utility:

bigpipe save all
