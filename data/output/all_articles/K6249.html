Known Issue

This is the result of a known issue. The alert section in the syslog-ng.conf file is not present in BIG-IP 9.2.3.

F5 Product Development tracked this issue as CR60829 and it was fixed in BIG-IP 9.3. For information about upgrading, refer to the BIG-IP LTM, GTM, or Link Controller Release Notes.

Workaround

If upgrading is not an option, you can work around this issue by performing the following steps:

  1. Log in to the command line.
  2. Using a file editor, edit the /etc/syslog-ng/syslog-ng.conf file.

    Append the following entries to the end of the file:

    # *.* |/var/run/alert.pipe
    filter f_catchall {
    level(debug..emerg);
    };
    destination d_alertd {
    pipe("/var/run/alert.pipe");
    };
    log {
    source(local);
    filter(f_catchall);
    destination(d_alertd);
    };

  3. Save the file.
  4. Restart syslog-ng by typing the following command:

    bigstart restart syslog-ng
