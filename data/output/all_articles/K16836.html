Known Issue

Portal access sessions may become unresponsive.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with portal access.
  • BIG-IP APM portal access uses a rewrite profile.
  • Destination resources utilize session cookies that exceed a total of 32 KB.

Impact

BIG-IP APM portal access becomes inaccessible.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users are temporarily unable to connect to portal access resources through the BIG-IP APM system.
  • You notice log messages in the /var/log/rewrite file that correlate with the time of the incident, similar to the following example:

    notice *** glibc detected *** rewrite.0: malloc(): memory corruption: 0x000000000ef172a0 ***

  • The BIG-IP system generates a rewrite process core file to the /shared/core directory, similar to the following example:

    /shared/core/rewrite.0.bld2419.0.core.gz

  • Shortly after the rewrite process exits, in the /var/log/rewrite file, the system displays error messages that appear similar to the following example:

    notice rewrite - cookie.cpp:543 : updateCookieSessionStore : expiring cookie ...

  • When viewing BIG-IP APM CPU utilization at the time of the incident, you notice that CPU utilization is maximized.
