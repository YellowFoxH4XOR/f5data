Known Issue

iControl calls may cause the BIG-IP system to leak memory.

This issue occurs when the following condition is met:

  • The iControl call uses the Management::KeyCertificat::get_certificate_lsitv2() method.

    Note: Enterprise Manager uses this method when performing discovery and refresh functions.

Impact

A slow memory leak occurs, which may eventually cause the BIG-IP system to experience memory exhaustion.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The amount of memory used by the iControl portal process increases over time.

Workaround

There is no workaround for this issue. However, you can help mitigate the issue by occasionally restarting the httpd service. To do so, perform the following procedure:

Impact of workaround: The Configuration utility will be temporarily unavailable until the httpd process has restarted successfully.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Restart the httpd process by typing the following command:

    restart sys service httpd
