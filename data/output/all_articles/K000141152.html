K000141152: List of data collected by FCP usage script

Type

Published
2024-09-24
Updated
2024-09-24
Source

Description

This document provides a detailed list of the information collected by the FCP usage script bigIQCollect.sh 

Environment

  • BIG-IQ Version: 8.3
  • FCP usage script

Cause

This document shares the list of data fields collected by the FCP usage script bigIQCollect.sh 

Recommended Actions

The FCP usage script, bigIQCollect.sh, creates a tar.gz file which contains several json / plain text files. These are generated from the script by calling 4 API calls.

Table 1: API Call for 1.bigIQCollect.json

API CallHeaders
/mgmt/shared/resolver/device-groups/cm-bigip-allBigIpDevices/deviceskind, uuid, build, slots, state, address, edition, product, version, hostname, selfLink, deviceUri, groupName, httpsPort, isVirtual, machineId, generation, properties, isClustered, mcpDeviceName, isLicenseExpired, lastUpdateMicros, managementAddress, restFrameworkVersion, platformMarketingName

Table 2: API Call for 2.bigIQCollect.json

API CallHeaders
/mgmt/cm/shared/current-config/sys/provisionkind, name, deviceReference, level, partition, generation, baseMac, chassisId, slots, devices, partitionLink, mac, selfLink, fqdn, serialNumber, activeModules, managementIp, networkInterfaces, provisionedModules, vcmpHostName

Table 3: API Call for 3.bigIQCollect.json

API CallHeaders
/mgmt/cm/device/tasks/device-inventorykind, id, selfLink, generation, devices, lastUpdateMicros, resultsReference, devicesQueryUri, startDateTime, currentStep, status

Table 4: API Call for 4.bigIQCollect.json

API CallHeaders
/mgmt/cm/device/reports/device-inventory/<inventory_id>/resultsid, kind, selfLink, infoState, cpu, time, build, slots, baseMac, edition, halUuid, hostMac, license, product, version, hostname, icrdPort, platform, selfLink, deviceUri, isVirtual, machineId, generation, interfaces, isClustered, mcpDeviceName, physicalMemory, managementAddress, chassisSerialNumber, restFrameworkVersion, platformMarketingName, isIControlRestSupported, hypervisorType
