Description

This article provides the command-line procedure for Exporting Application Security Manager (ASM) policies from BIG-IP systems in either 'XML', 'JSON' or 'Binary (PLC)' format. This method is useful for bulk exports, automation, and integration with backup or configuration management systems.

Environment

  • BIG-IP ASM / AWAF
  • Exporting All ASM Policies at once
  • SSH/CLI Access to BIG-IP system

Cause

By design, It's not possible to Export ALL the ASM Policies at once from WebUI. In other words, to Export ASM Policies from GUI, you need choose each ASM Policy one-by-one and then Export it based on your desired Format. For further details, you can review the reference Article K13905104.

Answer/Recommended Actions

As a sample workaround to Export All ASM Policies in 'XML' Format via CLI, you can follow the below steps:

 

  1. Connect to the BIG-IP system via SSH, and create a sub-directory for this purpose like 'Exported-ASM-Policies' under the "/var/tmp/" directory, and then navigate to '/var/tmp/':
    # mkdir /var/tmp/Exported-ASM-Policies
# cd /var/tmp/
  2. List All the ASM Policies and Save their Names into a 'txt' file, named as 'policies.txt':
    # tmsh list asm policy all one-line | cut -d " " -f 3 > policies.txt
  3. Export All the ASM Policies in 'XML' format using a simple loop with below Script:
    for i in $(cat policies.txt); do
  echo $i
  tmsh save asm policy $i xml-file $i.xml
done
  4. Once completed, now you can move All the Exported ASM Policies in 'XML' format into your desired sub-directory, as created in the Step-1:
    # mv *.xml Exported-ASM-Policies/

  5. Now, you can Download the Exported 'XML' files using SCP or another file Transfer method on your local system.

 

Note: To Export the ASM Policies in other available Formats like 'JSON' or 'Binary (PLC)', you can follow the same steps as above, but try to modify the Script in Step-3 by replacing the "xml-file" with either "json-file" for JSON Format followed with the ".json" extension at the end of line, or "bin-file" followed by the ".plc" extension for the Binary Format. Needless to say that, you need to modify the filter mentioned in the Step-4 based on your desired Exported Format, as well.
