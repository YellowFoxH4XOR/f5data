K9665: Radius Dynamic group mapping will fail when the default language is set to Vietnamese

Known Issue

This is the result of a known issue. Radius Dynamic group mapping will fail if the default language/character set configured on the FirePass controller is set to Vietnamese, and the class attribute does not end with a digit.

When logging through the login page, users will receive an error message that appears similar to the following example:

Either Username or Password do not match!  Please try again.

F5 Networks Product Development is tracking this issue as CR114845.

Workaround

To work around this issue, and allow Radius Dynamic group mapping to work correctly, choose one of the following three methods:

  • Change the user's ID on the Radius server to end in a digit
  • Set the default language to English
  • Give the users the option of choosing which language they want to use at login

Setting the default language to English

To set the default language to English, perform the following procedure:

  1. Log in to the Administrative Console.
  2. Click Device Management.
  3. Click Customization.
  4. Click Advance Customization.
  5. Click Show Advanced Customization.
  6. Select English from the drop-down menu.
  7. Click Update.

    You will be prompted to confirm the change.

Giving users the option of choosing which language they want to use at login

To give users the option of choosing which language they want to use at login, perform the following procedure:

  1. Log in to the Administrative Console.
  2. Click Device Management.
  3. Click Customization.
  4. Click Advance Customization.
  5. Click Show Advanced Customization.
  6. Select the Choice of language on logon page check box.
  7. Click Update.

Important: Instruct your users to select English when they log in from the drop-down menu if their user ID does not end in a digit.
