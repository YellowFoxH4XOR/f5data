K45445450: Cannot load user credentials for user ''f5hubblelcdadmin''

Source

Description
You see log messages in /var/log/audit similar to the following:

Jul 10 21:25:05 localhost.local notice icrd_child[29462]: 01420002:5: AUDIT - Cannot load user credentials for user "f5hubblelcdadmin"

Environment

  •  F5 hardware platforms

Cause

LCD panel accesses tmos to get information about the system even if a user did not touch the panel. It does so through the local loopback addresses (127.4.2.1 and 2), hence the channel should be secure enough. LCD accesses the tmos using the user "f5hubblelcdadmin" via iControl REST (hence via httpd server), and the error suggests that it failed to access tmos most likely because the iControl REST processes were not fully available at that point.

Recommended Actions

When the log message continuously appear in /var/log/audit you can restart the restjavad service:
Note: If the log message does not continuously appear you can safely ignore the message.
tmsh restart sys service restjavad
