Description

Error message: 01070734:3: Configuration error: Node name /<Partition_name>/<Node_Name> encodes IP address <IP_Address> which differs from supplied address field <IP_Address%Route-Domain ID>

Example:
01070734:3: Configuration error: Node name /TEST1/192.168.1.1 encodes IP address 192.168.1.1 which differs from supplied address field 192.168.1.1%10

  • Config-sync failed.
  • Run command "tmsh load sys config verify" shows the above error too.


Environment

BIG-IP
Multiple route-domain.


Cause

BIG-IP failed to apply the route domain ID for the node.


Recommended Actions

Ensure the default route domains for partitions are matching on both Active and Standby. In the above example partition TEST1 should be configured for default route domain 10. Check in GUI: System  ››  Users : Partition List

If partitions are configured the same on both Active and Standby and the issue persists, then proceed with the following steps:

Two workarounds for this issue: (Perform either of the following)

1. Re-create the pool member with a custom node name.
  • Delete the pool member and node.
  • Re-create the pool member and specify a custom node name for it.
2. Modify the /config/bigip.conf file and manually append the route-domain ID to the pool name.
  • Use vim or nano from bash shell.
  • Manually append the route domain ID, for example %10 for route-domain 10, after the node name.
Example:
ltm node /Common/192.168.1.1 { <---Node name without route-domain ID.
address 192.168.1.1%10 }

Modify to:
ltm node /Common/192.168.1.1%10 { <---Put route-domain ID for it.
address 192.168.1.1%10 }
  • Once the config file has been modified, manually load the config.
tmsh load sys config
