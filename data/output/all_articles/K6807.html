Note: For information about SSL ciphers supported in later BIG-IP versions, refer to K8802: Using SSL ciphers with the BIG-IP Client SSL and Server SSL profiles.

BIG-IP LTM platforms support native and compat SSL stacks. Each SSL stack supports a different set of SSL ciphers.

Native SSL stacks

The native SSL stack is faster than the compat SSL stack, and supports SSL ciphers that address most SSL connections.

Note: The BIG-IP LTM does not currently support the SHA-2 cryptographic hash functions, which include SHA-224, SHA-256, SHA-384, and SHA-512. This suite of cryptographic hash functions is still in draft form, as it relies on specifications detailed in TLS version 1.2, which is also still in draft form.

The following list represents ciphers supported in the native SSL stack:

SSL CipherBitsProtocol
RC4-MD5128SSLv3, TLSv1.0
RC4-SHA128SSLv3, TLSv1.0
AES128-SHA128SSLv3, TLSv1.0
AES256-SHA256SSLv3, TLSv1.0
DES-CBC3-SHA192SSLv3, TLSv1.0
DES-CBC-SHA64SSLv3, TLSv1.0

Compat SSL stacks

The compat SSL stack is a variant of OpenSSL 0.9.7. It supports the ciphers that the native SSL stack supports, in addition to ciphers from the OpenSSL suite. The compat stack is slower than the native SSL stack, and requires more memory per connection than the native stack. The compat SSL stack also makes minimal use of hardware acceleration.
