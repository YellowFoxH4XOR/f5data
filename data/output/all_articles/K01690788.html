Description

  • Unable to view ASM Event logs on Configuration utility (GUI)
  • When accessing the page  Security  ››  Event Logs : Application : Requests a pop-up with the following message "Failed to load requests" appears
  • Similar log may appear in /var/log/asm:

    crit perl[1830]: 01310027:2: ASM subsystem error (asmlogd,): asmlogd ended unexpectedly
    crit perl[1830]: 01310027:2: ASM subsystem error (asmlogd,): Can't call method "execute" on an undefined value at /usr/local/share/perl5/F5/DbUtils.pm line 206.
    info perl[13944]: 01310053:6: ASMConfig change:   [add]: IncidentType was set to Session Hijacking.
    crit perl[4770]: 01310027:2: ASM subsystem error (asm_start,F5::NwdUtils::Nwd::log_failure): Watchdog detected failure for process. Process name: asmlogd, Failure: Insufficient number of threads (required: 1, found: 0).

  • Similar log may appear in /var/lib/mysql/mysqld.err:

    210126  8:09:17 [ERROR] mysqld: Table './PRX/REQUEST_LOG#P#p81900001' is marked as crashed and last (automatic?) repair failed

Environment

  • ASM provisioned
  • Logging profile
  • ASM event logs

Cause

The PRX table is corrupted beyond repair.

Recommended Actions

Review the following article for information about troubleshooting the MySQL database:

  • K14194: Troubleshooting the BIG-IP ASM MySQL database

If the above troubleshooting steps do not resolve the issue, the safest way to recover from the current state is by clearing out the remnants of the PRX.REQUEST_LOG table and recreating the PRX.REQUEST_LOG table.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Connect to CLI
  2. Clear out the remnants of the PRX.REQUEST_LOG table:

    mysql -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e "DROP TABLE PRX.REQUEST_LOG;"

  3. Clear out old protobufs:

    rm -f /var/asmdata1/request_log/*

  4. Recreate the PRX.REQUEST_LOG table:

    sed -n '/^CREATE TABLE REQUEST_LOG (/,/^);/ p' /var/ts/install/prx.sql | mysql -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -D PRX -B

  5. Restart the ASM logging daemons:

    pkill -f asmlogd
    pkill -f pabnagd
