K000153014: After BIG-IP software upgrade, SSLO displays "Invalid BIG-IP HA Setup"

Type
Support Solution
Published
2025-08-14
Updated
2025-08-14
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0
Source
https://my.f5.com/manage/s/article/K000153014

Description

  • BIG-IP SSLO displaying Invalid BIGIP-HA Setup
  • Banners show following under the SSL Orchestrator:

    • "Invalid BIG-IP HA setup. Wait 2 minutes for self-recovery. If HA remains invalid, select HA-Status for more details to correct. Any configuration changes are not allowed until resolved."
  • And this error also shows for HA-Status:

    • "Mismatch between the SSL Orchestrator block and MCP application service. Please resolve the issues before you proceed. You can review the errors in /var/log/restnoded/restnoded.log"

Environment

  • BIG-IP SSLO
  • Invalid BIG-IP HA Setup banner
  • /var/log/restnoded/restnoded.log shows missing files:

Recommended Actions
