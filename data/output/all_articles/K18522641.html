Topic

This article applies to BIG-IP 14.x. For information about other versions, refer to the following articles:

  • K21520582: Overview of the DNS profile (11.x - 13.x)

The DNS profile allows you to configure various DNS attributes that a virtual server or DNS listener object applies to DNS traffic. For example, when you enable the DNS Express setting in the DNS profile, the BIG-IP system acts as an authoritative secondary DNS server and performs actions such as zone transfers from multiple primary DNS servers or zone transfers from the local BIND server on the BIG-IP system.

Description

You can associate the DNS profile with the following objects:

  • Virtual servers (Standard type)
  • DNS / GTM listener objects

Notes:

  • When you configure a DNS profile and associate it with a virtual sever or listener object, disable the unused profile settings. For more information, refer to the Recommendations section of this article.
  • You cannot add a DNS profile to a virtual server that has a ClientSSL or ServerSSL profile.

The DNS profile is located in the following locations in the Configuration utility:

  • Local Traffic > Profiles > Services > DNS
  • DNS > Delivery > Profiles > DNS

The DNS profile contains the following settings:

General Properties

SettingDefaultDescription
NameNoneSpecifies the name of the profile.
Parent ProfilednsIndicates the profile from which this profile inherits settings.

Denial of Service Protection

SettingDefaultDescription
Rapid Response ModeDisabledYou can configure the DNS Rapid Response mode in the DNS profile to protect the network from DNS flood attacks. Rapid Response mode works by performing a designated action when a DNS query does not match a DNS Express Zone. When you enable Rapid Response mode, if the query name matches a wide IP name and you enabled global server load balancing (GSLB) on the profile, the DNS query bypasses Rapid Response. Be aware of the following when you enable the Rapid Response feature in the DNS profile:
  • When you enable the Rapid Response Mode for a Rapid-Response profile, only the GSLB and DNS Express features function in the DNS profile; other configured DNS profile options, such as DNS Cache, DNSSEC, DNS IPv6 to IPv4, do not run.
  • Configuring the Rapid Response feature may result in system validation errors and warnings. For more information, refer to K16618: Limitations of the DNS Rapid-Response feature.
Rapid Response Last ActionDropIndicates the action the BIG-IP system takes when you enable Rapid Response Mode and the incoming DNS query does not match a DNS Express Zone. The available options are:
  • Allow: Sends non-matching DNS queries along the regular packet processing path.
  • Drop: Drops non-matching messages without sending a response to the client.
  • No Error: Returns a NOERROR response to the client.
  • NX Domain: Returns a non-existent name response to the client.
  • Refuse: Returns a REFUSED response to the client.
  • Truncate: Truncates the response to the client.

Hardware Acceleration

SettingDefaultDescription
Protocol ValidationDisabledOn supported platforms, indicates whether the hardware accelerates query validation.
Response CacheDisabledOn supported platforms, indicates whether the hardware caches responses.

DNS Features

SettingDefaultDescription
DNSSECEnabledWhen you configure DNSSEC on the BIG-IP system, you must enable DNSSEC in the DNS profile, create DNSSEC key-signing and zone-signing keys, and create a DNSSEC zone. Doing so ensures that all responses to DNS-related traffic comply with the DNSSEC security protocol.
Note: For performance reasons, if you did not configure any DNSSEC zones, and you are not using the DNSSEC feature, disable the DNSSEC setting in the DNS profile.
GSLBEnabledIndicates whether the system uses BIG-IP DNS or GTM features to manage DNS responses.
Note: For performance reasons, if you are not using BIG-IP DNS or GTM features, such as wide IPs, to manage DNS responses, disable the GSLB setting in the DNS profile.
DNS ExpressEnabledSpecifies whether you enabled the DNS Express setting. The DNS Express feature receives zone transfers from the authoritative DNS server for the zone. If you also enable the Zone Transfer setting on this profile, the DNS Express feature also responds to zone transfer requests made by the nameservers that you configured as zone transfer clients for the DNS Express zone.
Note: For performance reasons, if you do not have any DNS Express zones configured and are not using the DNS Express feature, disable the DNS Express setting in the DNS profile.
DNS CacheDisabledSpecifies whether the system caches DNS responses.
  • Enabled: The BIG-IP system caches DNS responses handled by the virtual servers associated with the DNS profile. When you enable the DNS Cache setting, you must also select a cache from the DNS Cache Name list.
  • Disabled: The BIG-IP system does not cache DNS responses handled by the virtual servers associated with the DNS profile. However, the profile retains the association with the DNS cache in the DNS Cache Name list. You can disable this setting when you want to debug the system.
DNS Cache NameNoneSpecifies the user-created cache that the system uses to cache DNS responses. When you select a cache for the system to use, you must also enable the DNS Cache setting.
DNS IPv6 to IPv4DisabledSpecifies whether you want the BIG-IP system to convert IPv6-formatted IP addresses to IPv4-formatted IP addresses. When you select Secondary, Immediate, or v4 Only, you must also provide a prefix in the IPv6 to IPv4 Prefix box that displays, and make a selection in the IPv6 to IPv4 Additional Section Rewrite list. The following options are available:
  • Disabled: The BIG-IP system does not map IPv4 addresses to IPv6 addresses.
  • Secondary: The BIG-IP system receives an AAAA query and forwards the query to a DNS server. Only if the server fails to return a response does the BIG-IP system send an A query. If the BIG-IP system receives an A response, it prepends a 96-bit user-configured prefix to the record and forwards it to the client.
  • Immediate: The BIG-IP system receives an AAAA query and forwards the query to a DNS server. The BIG-IP system then forwards the first good response from the DNS server to the client. If the system receives an A response first, it prepends a 96-bit prefix to the record and forwards it to the client. If the system receives an AAAA response first, it simply forwards the response to the client. The system disregards the subsequent response from the DNS server.
  • v4 Only: The BIG-IP system receives an AAAA query, but forwards an A query to a DNS server. After receiving an A response from the server, the BIG-IP system prepends a 96-bit user-configured prefix to the record and forwards it to the client. Select v4 Only only if you know that all DNS servers are IPv4-only servers.
IPv6 to IPv4 Prefix0:0:0:0:0:0:0:0.Specifies the prefix to use for the IPv6-formatted IP addresses that the system converts to IPv4-formatted IP addresses.
Unhandled Query ActionsAllowSpecifies whether the system uses the local BIND server on the BIG-IP system.
  • Allow: The BIG-IP system forwards queries to a DNS server or pool member. If you did not associate a pool with a listener and the Use BIND Server on BIG-IP setting is set to Enabled, the system forwards requests to the local BIND server.
  • Drop: The BIG-IP system does not respond to the query.
  • Reject: The BIG-IP system returns the query with the REFUSED return code.
  • Hint: The BIG-IP system returns the query with a list of root name servers.
  • No Error: The BIG-IP system returns the query with the NOERROR return code.
Use BIND Server on BIG-IPEnabledSpecifies whether the system forwards non-wide IP queries to the local BIND server on the BIG-IP system. For best performance, disable this setting when you use a DNS cache.
Insert Source Address into Client Subnet OptionDisabledSpecifies whether the system sets the edns0 Client Subnet option to the source address for queries that do not already contain a client subnet option. Also specifies whether the system removes the Client Subnet option from responses to clients that do not send a client subnet option in their most recent query. 

DNS Traffic

SettingDefaultDescription
Zone TransferDisabledIndicates whether the system answers zone transfer requests for a DNS zone created on the BIG-IP system. The DNS Express and Zone Transfer settings on a DNS profile affect how the system responds to zone transfer requests. The system processes zone transfer requests as follows:
  • When the DNS Express and Zone Transfer settings are both Enabled, if a zone transfer request matches a DNS Express zone, then DNS Express answers the request.
  • When the DNS Express setting is Disabled and the Zone Transfer setting is Enabled, the BIG-IP system processes zone transfer requests based on the last action and answers the request from local BIND or a pool member.
DNS SecurityDisabledIndicates whether DNS firewall capability is enabled. You must create a DNS security profile before you configure this option in the DNS profile.
DNS Security Profile NameNoneSpecifies the DNS security profile the system uses. The DNS security profile allows you to filter DNS to allow or deny specific DNS query types, and to deny specific DNS opcodes.
Process Recursion DesiredEnabledSpecifies whether to process client-side DNS packets with Recursion Desired set in the header. If set to Disabled, processing of the packet is subject to the unhandled-query-action option.

Logging and Reporting

SettingDefaultDescription
LoggingDisabledSpecifies whether the system enables high speed logging for DNS queries and responses. When it is set to Enabled, you must also specify a logging profile.
Logging ProfileNoneSpecifies the DNS logging profile you want to use to configure which events the system logs and their message format. These are the DNS Logging profiles you create using the Other option under Profiles.
AVR Statistics Sample RateNoneSets the AVR DNS statistics sampling rate. A value of 0 indicates that the system does not send a query to the analytics database. A value of 1 means that the system sends every query. A value of n means that the system sends every nth query, and the analytics database counts that query n times. The default is 0. When the sampling rate is greater than one and traffic volume is low, the statistics are inaccurate. However, when the traffic volume is high, the system performance benefits from sampling and the inaccuracy is negligible. DNS statistics contain query name, query type, virtual server IP, and client IP.

Recommendations

When configuring the DNS profile, consider the following factors:

  • For performance reasons, disable the following settings in the relevant DNS profile:
    • When you do not configure any DNSSEC zones and you are not using the DNSSEC feature—disable the DNSSEC setting.
    • When you are not using BIG-IP DNS or GTM features to manage DNS responses, such as wide IPs—disable the GSLB setting.
    • When you do not configure any DNS Express zones, and you are not using the DNS Express feature—disable the DNS Express setting.
