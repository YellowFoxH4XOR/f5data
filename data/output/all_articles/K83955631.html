Known Issue

If you change the HTTP profile, the system does not trigger a validation for the virtual servers using that profile.

This issue occurs when the following condition is met:

  • The system is using an HTTP profile with a virtual server that uses profiles that have settings that are mutually exclusive to those of the HTTP profile.

Impact

The system is in an invalid state. One way you can see this is when the system is syncing to a peer, the sync operation does not complete as expected.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Changing the HTTP profile does not trigger a validation for virtual servers, so the system does not check any inter-profile dependencies.
