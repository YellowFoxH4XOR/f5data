Topic

This article applies to BIG-IP ASM 11.x - 16.x. For information about other versions, refer to the following article:

  • K7018: Overview of BIG-IP ASM user role permissions (9.4.x - 10.x)

This article discusses the different access levels to various BIG-IP ASM system objects for each BIG-IP user role.

Description

A BIG-IP user has restricted access to various BIG-IP ASM system objects depending on the BIG-IP user role assigned. The system grants each BIG-IP user role a set of access levels to specific BIG-IP ASM system objects. The system sets access levels and you cannot configure them.

When you create users on the BIG-IP ASM system, you should assign the appropriate user role based on the individual's need to access the required BIG-IP ASM system objects.

Creating a new remote role group grants users permission based on a variable used by a remote authentication server, such as RADIUS or TACACS+.

If the remote authentication server sends the variable as part of authenticating a user, the BIG-IP system uses the value of the variable as the user's role. For example, for a variable of user-role, if authentication then includes the value user-role Operator, the system sets the remote user's role as Operator.
