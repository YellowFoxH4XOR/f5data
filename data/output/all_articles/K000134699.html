K000134699: BIG-IP silently reboots due to power events

Type
Support Solution
Published
2023-05-22
Updated
2023-05-22
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000134699

Description

BIG-IP silently reboots due to power events


Environment

BIG-IP

Cause

In /var/log/sel you may discover logs similar to the following


0158 04/21/23 01:10:23 INF BMC System Event #ff - 6f [05 80 ff]

0159 04/21/23 07:10:23 INF EFI System Event #00 - 6f [05 80 ff]

015a 04/21/23 01:10:31 INF Updating LCD FRU Cache

015b 04/21/23 01:10:37 INF EFI System Firmware #00 POST Error 6f [c0 09 ff]

015c 04/21/23 01:10:37 INF EFI System Firmware #00 POST Error 6f [c0 09 ff]

015d 04/21/23 01:10:41 INF EFI System Firmware #00 POST Error 6f [c0 09 ff]

015e 04/21/23 01:10:49 INF BIOS Handoff Event Code: 0xa2

015f 04/21/23 01:13:05 INF Set MFG Mode Lockout

0160 04/21/23 01:13:05 INF BMC System Event #ff - 6f [05 00 ff]

0161 04/21/23 07:13:05 INF BMC System Event #ff - 6f [05 80 ff]

Recommended Actions

1. Perform an EUD test on the unit (will require a full reboot into single user mode), instructions are at https://techdocs.f5.com/kb/en-us/products/big-ip_ltm/releasenotes/related/eud-sf.html please run option "A Run All (Non-Interactive) Tests"


2. For precaution run an fsck on the next system restart, instructions are at https://my.f5.com/manage/s/article/K73827442


3. If the unit is a VCMP host connect a device to the console port and keep logging the output of the console port turned on permanently so we may have further information if this issue happens again, https://techdocs.f5.com/kb/en-us/products/big-ip_ltm/manuals/product/f5-plat-hw-essentials/1.html
