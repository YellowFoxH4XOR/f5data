Topic

You should consider using these procedures under the following condition:

  • You want to determine the maximum allowed throughput rate on your BIG-IP Virtual Edition (VE) system.

Description

The BIG-IP VE product license determines the maximum allowed throughput rate. You can view this rate limit by performing one of the procedures in the following section.

You may want to adjust the default threshold according to your application environment. For information, refer to K15377: Configuring the BIG-IP VE system to log a notification when the throughput rate exceeds a configured threshold.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • Your BIG-IP VE system has a valid license installed.
  • Your BIG-IP VE system is running a version listed in the Applies to (see versions) box, located in the upper-right corner of this article.
  • You have tmsh access or Advanced Shell (bash) access on the BIG-IP VE system.

Procedures

To determine the maximum allowed throughput rate on the BIG-IP VE system, perform one of the following procedures:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Use tmsh

  1. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  2. To display the maximum allowed throughput rate, enter the following command:

    show /sys license detail | grep perf_VE_throughput_Mbps

    The command output may appear similar to the following example:

    perf_VE_throughput_Mbps [10]

    This output illustrates that the BIG-IP VE system has a 10 Mbps maximum allowed throughput rate.

  3. To exit tmsh, enter the following command:

    quit

Use the bash command line

To display the maximum allowed throughput rate using the bash command line, enter the following command:

grep "perf_VE_throughput_Mbps" /config/bigip.license

The command output may appear similar to the following example:

perf_VE_throughput_Mbps : 10

This output illustrates that the BIG-IP VE system has a 10 Mbps maximum allowed throughput rate.
