Description
Fallback to local with remote TACACS authentication is not working. 

Environment

  • BIG-IP platform
  • BIG-IP running TMOS ver. 14.x, 15.x or 16.x
  • TACACS remote authentication configured

Cause
Fallback to local authentication doesn't work if the TACACS server secret contains special characters like '\' or '#'.

Recommended Actions
To fix this issue, change the TACACS server secret so it doesn't contain any special characters. The secret needs to be changed on the TACACS server and the BIGIP and as this is a shared secret between them, it shouldn't impact any other servers using the same TACACS server for authentication.
