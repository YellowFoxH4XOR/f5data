K84040825: TMM core dumps leading to failover after upgrade to 15.1.2.1 when using HTTP/2 profiles

Type
Support Solution
Published
2021-03-24
Updated
2026-07-16
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.2
Source
https://my.f5.com/manage/s/article/K84040825

Description

After an upgrade to 15.1.2.1, you find that TMM is coring semi-frequently with SIGABRT crash dumps.

Environment

  • Upgrade to 15.1.2.1 (no similar issue observed, before upgrade took place)
  • Existing VIP(s) with HTTP/2 profiles

Cause

TMM crash occurs due to an issue processing HTTP/2 traffic because of Bug ID 943081.

Recommended Actions

Upgrade to fixed BIG-IP versions listed in K90603426: TMM with HTTP/2 vulnerability (CVE-2021-23009) or later

None
