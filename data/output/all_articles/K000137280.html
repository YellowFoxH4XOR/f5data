Description

You see the error message "java.lang.illegalstateexception: out of retries. task not completed" on the GUI of the BIG-IQ.

Environment

  • BIG-IQ
  • Scheduled Backup / UCS tasks failed
  • low or out of disk space /var /shared

Cause

This issue can be caused by failing to complete a scheduled backup task or the hard disk being full

 Recommended Actions

Checking for backup failing to complete
Note: The changes below do not survive any GUI config changes to scheduled backups, a reboot or upgrade.
  1. Review log file /var/log/restjavad and each of its iterations and look for "timeout waiting for task to finish" 
  2. From the BIG-IQ command line, get scheduled task ID
restcurl /shared/task-scheduler/scheduler/?\$select=name,id | grep -B1 \"<backup name>\"
  1. Apply the change and specify the timeoutInMillis
 
restcurl /shared/task-scheduler/scheduler/<id from above no quotes> -X PATCH -d  '{"timeoutInMillis": 3600000}'
  1. check the above command worked​​​​​​​
​​​​​​​restcurl /shared/task-scheduler/scheduler/7fe3a825-c85e-321b-b3a8-6b7a7ea42837 | jq '{name,timeoutInMillis}'


Checking hard drive space
  1. review log file /var/log/ltm for the error message "no space left on device"
  2. df -h and look at how much free space is on /var and /shared
