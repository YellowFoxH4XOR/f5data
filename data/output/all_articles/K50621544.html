Description
Base registration key is applied to an incorrect physical device, the license needs to be revoked (Allow Move) so that it can be used on the correct device.

Environment

  • Base registration key
  • License activation

Cause
After you activate a base registration key for a device, you cannot activate the same key on another device.

Recommended Actions

Contact F5 Technical Support and request an Allow Move.

Additional Information
None
