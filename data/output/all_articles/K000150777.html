Description

When accessing a hosted website behind an F5 BIG-IP LTM VE platform, the following error message was encountered:

"Internal Server Error – Read. The server encountered an internal error or misconfiguration and was unable to complete your request."

 

 

This issue occurred after changes were made to SSL certificates, specifically switching from "wildcard certificates" to "dedicated certificates". Attempts to roll back the certificate change did not resolve the problem.

 

Environment

  • BIG-IP LTM VE
  • SSL profiles (server-side)
  • Certificates

Cause

The root cause of the issue was incompatibility between the backend server's updated certificate configuration and the serverssl-insecure-compatible profile on F5 BIG-IP LTM VE. The new certificates likely introduced stricter security requirements that were not supported by the serverssl-insecure-compatible profile.

 

Recommended Actions

To resolve this issue Switch SSL Profile:

  1. Assign the serverssl profile for backend (server-side) SSL connections whenever possible. This ensures use of secure protocols (TLS 1.2/1.3) and strong cipher suites compatible with modern servers.
  2. Understand Profile Different:
    • Use serverssl for secure communication with servers that support modern SSL/TLS protocols (e.g., TLS 1.2 or higher). This ensures strong encryption and eliminates vulnerabilities.
    • Use Use serverssl-insecure-compatible only when connecting to legacy systems requiring older or insecure protocols/ciphers. Avoid using this profile unless absolutely necessary due to its potential security risks.

 

Additional Information

The actual cipher and protocol settings can be viewed using below commands:
 # tmsh list ltm profile serverssl serverssl  
 # tmsh list ltm profile serverssl serverssl-insecure-compatible
