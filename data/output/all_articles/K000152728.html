K000152728: [F5OS] Backup File Download Fails When File Name Contains Spaces

Description

When attempting to download a backup file from an F5OS-A and F5OS-C Partition using the File Utilities feature in the F5OS GUI, the operation may fail if the backup file name contains "spaces". 

1. On F5OS-A version 1.5.x, there will be an error prompt when downloading from F5OS-A GUI >> SYSTEM SETTINGS >> File Utilities >> Base Directory: Configs


Figure: F5OS-A File Utilities Download 

2. On F5OS-A version 1.8.x, the download won't start and there will be no error prompt either from SYSTEM SETTING >> "File Utilities" or "Backup Configuration"

3. On F5OS-C, this issue only affecting the partition

Environment

  • F5OS-A
  • F5OS-C Partition
  • GUI
  • CLI Bash Mode

Cause

The F5OS GUI File Utilities does not support file names containing "spaces". "Spaces" in file names can cause issues with web server handling, URL encoding, or browser compatibility, resulting in failed downloads or errors.

Recommended Actions

You may follow either of the below to resolve the F5OS GUI download issue on file with "spaces" in the naming.

  1. Best Practices for File Naming
    • To ensure successful backup and download operations from the F5OS GUI:
      • Do not use "spaces" in backup file names. Use underscores (_) or hyphens (-) instead to replace the required "spaces".
      • Good: backup_2024-07-09.xml
      • Bad: backup July 9 2024.xml
    • Use only alphanumeric characters, underscores, hyphens, and periods.
    • Try avoiding special characters such as ! @ # $ % ^ & * ( ) [ ] { } ; : ' " , < > ? / \ |.
    • Keep file names concise and meaningful.

  2. If you have already created a backup file with "spaces" in the name:
    1. Use the F5OS CLI (bash mode) to rename the file, replacing "spaces" with underscores or hyphens.
      # cd /var/F5/system/configs/
      # mv test\ download test-download

    2. Retry the download from the GUI.

      Additional Information

      • This limitation applies to the F5OS GUI File Utilities and may also affect other file operations in the GUI.
      • Always test your backup and restore procedures in a non-production environment to ensure compatibility.
