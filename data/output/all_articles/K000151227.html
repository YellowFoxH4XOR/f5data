Description

Is the OClmoOot cookie set by from F5?

i.e.

Cookie: OClmoOot=A9Z6F7WJAQXXXXXXXXXXXXX...

Environment

WAAP

Bot Defense

Cause

By design

Recommended Actions

Yes, the "OClmoOot" is a Bot Defense cookie set by F5.

This should be the only cookie from Bot Defense.

Additional Information

None
