Known Issue

This is the result of a known issue. If you configure the Windows antivirus checker in a pre-logon sequence, the FirePass client-side component may fail to detect a running instance of antivirus software on Microsoft Windows Vista clients. FirePass may direct Windows Vista clients to the other branches of the pre-logon sequence, such as the Logon Denied page, even if the antivirus software is running.

This issue occurs when both of the following conditions are met:

  • The user connects to the FirePass controller using Microsoft Internet Explorer 7 (IE7) for Windows Vista.
  • Protected Mode is enabled in IE7.


The FirePass Windows antivirus checker uses software libraries from a software development kit (SDK) created by OPSWAT, Inc. OPSWAT provides a vendor-independent framework for endpoint security management. User Account Control (UAC) is a security feature introduced in Windows Vista, and UAC integrates with Protected Mode in IE7 for Windows Vista. The OPSWAT SDK is not currently compatible with UAC, which causes the FirePass client-side component to fail to detect antivirus software when Protected Mode is enabled in IE7.

More information about Protected Mode is available at the following location:

http://windowshelp.microsoft.com/Windows/en-US/Help/95211ecc-19b5-439a-b6c5-e2aefd8013031033.mspx.

F5 Networks Product Development tracked this issue as CR93536 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Workaround

The user can work around this issue by performing one of the following four procedures:

  • Add the URL of the FirePass controller to the IE7 Trusted Sites zone. For information about configuring the Trusted Sites zone, refer to the Microsoft IE7 documentation.

    Important: By default, Protected Mode is disabled in IE7 for the Trusted Sites zone. If Protected Mode is enabled for this zone, use one of the alternate workarounds listed below.
  • Connect to the FirePass controller using an alternate browser, such as Firefox.
  • If the user has administrator privileges on the Windows Vista system, the user can right-click on Internet Explorer and select the Run as administrator option when launching Internet Explorer. This setting bypasses Protected Mode, which allows the FirePass client-side component to detect antivirus software
  • If the user does not have administrator privileges on the Windows Vista system, the user can disable Protected Mode in Internet Explorer. F5 Networks does not recommend this workaround, as it may decrease the security of the Window Vista system. For information about disabling Protected Mode, refer to the Microsoft IE7 documentation.
