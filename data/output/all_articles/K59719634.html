Topic

You should consider using this procedure under the following condition:

  • You want to display the BIG-IP Next instance software version using the BIG-IP Next Central Manager.

Description

You can use the BIG-IP Next Central Manager to display the software version running on a BIG-IP Next instance. 

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to BIG-IP Next Central Manager.
  • You have command line access to a client system that has the curl utility and the jq utility installed.
  • You have access to F5 Cloud Docs to review REST API documentation.

Procedures

  • Use the BIG-IP Next Central Manager webUI
  • Use the BIG-IP Next Central Manager API

Use the BIG-IP Next Central Manager webUI

To display the running software version for a BIG-IP Next instance using the BIG-IP Next Central Manager webUI, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Next Central Manager.
  2. Go to Manage Instances.
  3. The running software version for the BIG-IP instance is listed in the row for each managed instance.

Use the BIG-IP Next Central Manager API

To display the running software version for a BIG-IP Next instance using the BIG-IP Next Central Manager API, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the client system that has the curl and jq utilities installed.
  2. To display the running BIG-IP Next instance software version, you first need to get a login token from the BIG-IP Next Central Manager. You can get the token from the login endpoint and save it to a shell variable for future reference using the following syntax:

    token=$(curl -sk -H "Content-Type:application/json" -X POST https://<bigip_next_cm_mgmt_address>/api/login -d'{"username": "<nextcm_admin_user>", "password": "<nextcm_admin_password>"}' | jq -r '.access_token')

    For example, use this command to request a login token and save it to a variable named token:

    token=$(curl -sk -H "Content-Type:application/json" -X POST https://nextcm.example.com/api/login -d'{"username": "admin","password": "admin"}' | jq -r '.access_token')

    You can use the echo $token command to view the value of the token variable.
  3. Now you can use the token variable to authenticate to BIG-IP Next Central Manager. To display the BIG-IP Next instance details, including the BIG-IP Next instance software version, enter the following command where <bigip_next_cm_mgmt_address> is the management address of the BIG-IP Next Central Manager:

    curl -sk -X GET -H "Content-Type: application/json" -H "Authorization: Bearer ${token}" "https://<bigip_next_cm_mgmt_address>/api/v1/spaces/default/instances" | jq
