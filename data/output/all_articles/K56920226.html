K56920226: Error message: ''An error has occurred in the script on this page'' with ''Error: Invalid charactor''

Type
Support Solution
Published
2021-09-23
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.0, 15.1.2, 15.1.1, 15.1.3
Source
https://my.f5.com/manage/s/article/K56920226

Description

The BIG-IP Edge client access the VPN server, get the error message like below:

                        An error has occurred in the script on this page.
Line: xx
Char: yy
Error: Invalid charactor
Code: 0
URL: https://vpn.example.com/public/include/js/common.js           <<< the URL is variable
Do you want to continue running script on this page?
       Yes     No

Environment

  • BIG-IP APM Virtual Edition
  • Virtual server
  • Access profile
  • Network Access
  • BIG-IP Edge client / Browser

Cause

Under investigation.

Recommended Actions

The BIG-IP APM server should not send the invalid charactor to the client. To troubleshooting the issue, the steps:

  1. Capture the packet on the BIG-IP APM and the client, decrypt it, review the HTML code, verify the invalid charactor is from APM server or not. Please refer to K12783074: Decrypting SSL traffic using the SSL::sessionsecret iRules command (12.x and later) to decrypt the packets and decrypt it.

  2. Please check the BIG-IP APM server, make sure it is not a security compromise device. For the detail, please refer to K11438344: Considerations and guidance when you suspect a security compromise on a BIG-IP system.

  3. If BIG-IP APM server send out invalid charactor, but the device status is normal, please contact F5 support.

Additional Information

None.
