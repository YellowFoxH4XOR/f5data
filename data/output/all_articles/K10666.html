The FirePass controller's Endpoint Security feature allows administrators to detect the presence and state of third-party security software, such as personal firewalls, antivirus, anti-spam, anti-spyware, or integrated packages. To perform this detection, the Windows antivirus checker and Windows firewall checker Endpoint Inspectors, which are listed on the Users: Endpoint Security: Endpoint Inspectors page, use software libraries from a software development kit (SDK) created by OPSWAT, Inc.

To view the version of the OPSWAT SDK installed on the FirePass controller, perform the following procedure:

  1. Log in to the FirePass Administrative console.
  2. In the top right corner of the page, click the Help link.
    The FirePass online help opens.
  3. In the left navigational menu, click Users.
  4. Click Endpoint Security.
  5. Click Inspectors.
  6. Click Antivirus Support Chart.
  7. Click Antivirus Support Chart.
  8. The OPSWAT SDK version appears at the top of the page.

    For example:

    OPSWAT Antivirus Integration SDK 2.5.10.1

    Additionally, the page contains a table of supported antivirus products. To view a table of supported firewall products, click Firewall Support Chart in the left navigational menu.

Note: For more information about OPSWAT SDK hotfixes, including obtaining the latest OPSWAT hotfix, refer to K6664: Obtaining and installing OPSWAT hotfixes.
