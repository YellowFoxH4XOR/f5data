Known Issue

Auto Last Hop does not work for Point-to-Point Tunneling Protocol (PPTP) Generic Routing Encapsulation (GRE) traffic.

This issue occurs when all of the following conditions are met:

  • Carrier-grade network address translation (CGNAT) is configured with an application layer gateway (ALG) PPTP profile.
  • A virtual server is configured for PPTP and references the configured CGNAT.
  • The ingress Virtual Local Area Network (VLAN) used by the virtual server has Auto Last Hop enabled, which is the default setting.

Impact

The PPTP tunnel fails to establish.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system incorrectly routes PPTP traffic and the tunnel fails to establish.

Workaround

You can work around this issue by creating static routes to return PPTP GRE traffic back to the client network. For information about static routes, refer to the TMOS Routing Administration Guide for your version.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
