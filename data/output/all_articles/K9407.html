Known Issue

This is the result of a known issue. Mobile email users do not have a link to attach a file to an email. In addition, the Browse button does not work (if the user has this option to attach a file). Many older mobile devices do not support attaching a file. Windows Mobile 5 and 6 support this functionality if the Internet Explorer version is 5 or newer. If your device supports this functionality, hotfix HF-602-8 is required.

F5 Product Development tracked this issue as CR88893 and it was fixed in FirePass 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in FirePass HF-602-8, which has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.
For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
