Description

APM decision box requires mouse to take decision, by clicking the hyperlink in the decision box. Visually impaired users may find it difficult to use mouse to click the hyperlink. Typically they use keyboard, which is not possible with the decision box menu.

Environment

  • BIG-IP APM

Cause

None

Recommended Actions

Decision box code can be modified to change the focus to the decision box hyperlink. Customer can tab through the options using keyboard and make the decision. 

Make the following changes under Access  ››  Profiles / Policies : Customization : Advanced

Go to relevant access policy  ›› Access Policy  ›› Decision Pages ›› Decision Box  ›› decision_box.inc

Add the code marked in red below.

[..]
function OnLoad()
{
  try{
    if ( externalWebHost.hasWebLogonNotifyUser() ){
      externalWebHost.WebLogonNotifyUser();
    }
  }catch(e){};
  window.sessionTimeout = new APMSessionTimeout(sessionTimedOut);
  var denyLink = document.getElementById("deny");
  if (denyLink) {
    denyLink.focus();
  }
}
