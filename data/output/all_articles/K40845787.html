Description

After upgrading an HA Pair within Azure, the devices both become Active. Forcing one device to Standby does not work. Symptoms include:

  • # tmsh list sys management-ip does not return a value
  • # tmsh list sys management-route returns 169.254.169.254

Environment

  • BIG-IP HA-pair
  • Microsoft Azure cloud platform

Cause

The static metadata route prevents a DHCP management route from being applied causing the Active/ Standby relationship not to be setup correctly during the Azure HA configuration steps.

Recommended Actions

The static metadata route needs to be removed for the DHCP management address to get applied

  1. Delete DHCP management address
    # tmsh delete sys management-route metadata-route

  2. Save the configuration changes
    # tmsh save sys config

  3. Reboot the device
    # reboot

Note: These steps need to be performed on both devices.
