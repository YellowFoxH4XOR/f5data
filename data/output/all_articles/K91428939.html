Known Issue

Border Gateway Protocol (BGP) with Equal Cost Multipath (ECMP) results in learned routes that use an incorrect nexthop Virtual Local Area Network (VLAN).

This issue occurs when all of the following conditions are met:

  • You configure two or more VLANs with global IPv6 addresses in the same route domain where the routing protocol is running.
  • You peer BGP with ECMP, with an active IPv6 BGP neighbor.
  • You configure BGP with max-paths.

Impact

The system incorrectly routes BGP traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system randomly sends the traffic using the incorrect nexthop VLAN.
