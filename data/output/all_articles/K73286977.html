Description

When an update of the Browser Challenge is needed for the Bot Defense Profile Browser Verification feature a sync will be required for the datasync-global-dg Device Service Cluster Group.

Environment

  • Update the Browser Challenges via System >> Software Management : Live Update
  • Bot Defense Profile using the Browser Verification setting
  • Application Security Module (ASM)

Cause

The datasync-global-dg DSC group is created automatically when ASM is provisioned. Its purpose is to synchronize system client-side scripts as well as system cryptographic keys. When an update is done for the Browser Challenge an update to the system cryptographic keys is done. By default the datasync-gloabl-dg DSC group is set to only use manual update (In versions prior to 13.1.x it was visible in the GUI and changes could be made under Device Management >> Device Group List. This was removed in later versions and it can only now be seen in the GUI at Device Management >> Overview) requiring a sync of datasync-global-dg.

Recommended Actions

There are 2 ways this can be dealt with...

  1. Go to Device Management >> Overview and manually sync datasync-gloabl-dg.
  2. Use the steps in K40253074: Applying BIG_IP ASM Browser Challenges Immediately
