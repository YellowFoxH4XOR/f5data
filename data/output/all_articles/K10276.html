Known Issue

This is the result of a known issue. BIG-IP systems that are managed by Enterprise Manager are susceptible to a memory leak. When Enterprise Manager discovers or refreshes a managed device, Enterprise Manager imports the SSL certificates used by the device. After importing the certificates, the managed BIG-IP system may fail to deallocate all of the memory previously allocated to the iControlPortal.cgi process. As a result, memory consumption on the managed BIG-IP system may increase over time and eventually result in memory exhaustion.

To determine whether your BIG-IP system is affected by this issue, you can use the top utility to examine the amount of memory used by the iControlPortal process. A continuously increasing value in the %MEM column may indicate the BIG-IP system is affected.

F5 Product Development tracked this issue as CR121199 and it was fixed in BIG-IP versions 9.4.8 and 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, or WebAccelerator release notes.

This issue was fixed in Hotfix-BIGIP-10.0.1-402.7-HF4 issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
