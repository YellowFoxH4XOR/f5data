K34131289: Not able to delete Attack Signature Update files with status 'Previously installed'

Type
Support Solution
Published
2022-02-18
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K34131289

Description
When you try to delete older Attack Signature Update files that have status 'Previously Installed' on the GUI, the Delete option is greyed out.
If you try to delete the same file from CLI, following  recommended actions of article K43843616, it fails with following message:

{
 "code": 500,
"message": "Could not delete the update file, an installation with status previously-installed exists and references this update file",
"referer": "Unknown",
"restOperationId": 12435065,
"kind": ":resterrorresponse"
}

Environment

  • BIG-IP ASM/WAF
  • Attack Signature Update

Cause
Attack Signature Update files with status 'Previously Installed' are not able to be deleted.  

Recommended Actions
This is an expected behavior.
