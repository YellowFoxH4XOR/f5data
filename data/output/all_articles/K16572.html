Topic

You should consider using this procedure under the following conditions:

  • You want to enable the REST API extension on your BIG-IP ASM system.
  • You want to use the BIG-IQ system to manage your BIG-IP ASM system.

Description

For a BIG-IQ system to discover a BIG-IP system, you must enable the REST API extension. The REST API extension on the BIG-IP ASM system is disabled by default, which may prevent the BIG-IQ system from discovering the BIG-IP ASM system.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Your system is running BIG-IQ system 4.5.0 HF1 or later.
  • Your system is running BIG-IP ASM 11.5.2 HF1 or later.

    Note: This procedure is not necessary for BIG-IP 11.6.0 because the REST API extension is natively supported in that BIG-IP version.

  • You have administrator credentials to access the BIG-IP ASM system Configuration utility and command line.

Procedures

To enable the REST API extension of the BIG-IP ASM system, perform the following procedure:

Impact of procedure: The following procedure disrupts service for the BIG-IP ASM system. F5 recommends that you perform this procedure during a scheduled maintenance window.

  1. Log in to the Configuration utility on the BIG-IP ASM system.
  2. Navigate to Security > Options > Application Security > Advanced Configuration > System Variables.
  3. Locate the rest_api_extensions system variable and change the value from 0 to 1.

    Note: By default, the value for the rest_api_extensions system variable is set to 0, which means the REST API extension is disabled on the BIG-IP system.

  4. Click Save.
  5. Log in to the BIG-IP ASM system command line.
  6. Restart the ASM and HTTP services by typing the following command:

    tmsh restart sys service asm httpd
