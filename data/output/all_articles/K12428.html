Known Issue

This is the result of a known issue. In BIG-IP versions 10.1.0 and 10.2.0, if C or C++ style comments are used in the /config/user_alert.conf file and the file contains only commented lines, the alertd process will continuously restart. When this issue occurs, error messages logged to the /var/log/ltm file will appear similar to the following example:

local/102 notice root: -bash ==> /usr/bin/bigstart restart alertd

For example, this issue will occur in the following two situations:

  • The contents of the /config/user_alert.conf file are commented out with C style comments:

    /*alert BIGIP_SYSTEM_CHECK_E_CHASSIS_POWER_BAD {
    * snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.9";
    * lcdwarn priority="4"
    *}
    */
  • The contents of the /config/user_alert.conf file are commented out with C++ style comments:

    //alert BIGIP_SYSTEM_CHECK_E_CHASSIS_POWER_BAD {
    // snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.9";
    // lcdwarn priority="4"
    //}

F5 Product Development is tracking this issue as ID 345947.

Workaround

If at least one valid alert definition is present in the /config/user_alert.conf file and is not commented out, you can use C and C++ style comments to comment out other lines in the file.

For example:

alert BIGIP_SYSTEM_CHECK_E_CHASSIS_FAN_BAD {
/* snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.8"; */
lcdwarn priority="3"
}
/*alert BIGIP_SYSTEM_CHECK_E_CHASSIS_POWER_BAD {
* snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.9";
* lcdwarn priority="4"
*}
*/

Note: The snmptrap OID definition within the alert definition may still be commented out, as long as the alert definition is not commented out. For more information about commenting out snmptrap OID definitions within alert definitions, refer to K11234: Disabling default SNMP traps.

If you require the entire /config/user_alert.conf file to be commented out, you may also work around this issue by using UNIX shell style comments to disable all lines.

For example:

#alert BIGIP_SYSTEM_CHECK_E_CHASSIS_POWER_BAD {
# snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.9";
# lcdwarn priority="4"
#}
