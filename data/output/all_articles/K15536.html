Known Issue

If a device group is configured for auto-sync with incremental synchronization enabled, and a number of configuration changes cause a rapid sequence of auto-sync operations, synchronizations may fail.

This issue occurs when all of the following conditions are met:

  • You have BIG-IP 11.4.0 HF3 or later installed.
  • You have enabled the Auto-Sync feature with incremental synchronization.
  • Several sequential configuration changes trigger a rapid sequence of auto-sync operations.

Note: Starting with BIG-IP 11.4.0, you can set a device group to automatically synchronize, with either an incremental synchronization or a full synchronization. For more information, refer to the Managing Configuration Synchronization chapter in the BIG-IP Device Service Clustering: Administration guide.

Impact

BIG-IP systems in a device group may not be synchronized.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Attempts to synchronize fail.
  • In the /var/log/ltm file, you observe an error similar to the following example:

    0107168e:5: Unable to do incremental sync, reverting to full load for device group
