Description

When you try to create a Certificate Signing Request (CSR) for Management on F5OS, there is no option to include any Subject Alternative Names (SANs).

Environment

  • F5OS Appliance or VELOS
  • Configuration Utility or CLI
  • F5OS 1.7.x and previous versions

Cause

This lack of functionality is documented in Bug ID 1496397. The issue is fixed in F5OS 1.8.0.

Recommended Action

Upgrade to F5OS 1.8.0 or manually request the Certificate Signing Authority to add the required Subject Alternative Names (SANs).
