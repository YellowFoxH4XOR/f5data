Known Issue

BIG-IP Edge Client for Mac OS may fail to reconnect.

This issue occurs when all of the following conditions are met:

  • You use BIG-IP Edge Client for Mac OS to establish your network access session through a BIG-IP APM system that redirects BIG-IP Edge Client to another BIG-IP APM system.
  • The second BIG-IP APM system does not have servers configured in the Server List settings of the Connectivity Profile.

Impact

BIG-IP Edge Client fails to re-establish network access sessions.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP Edge Client fails to re-establish network access sessions.

Resolution

Status

F5 Product Development has assigned ID 643053 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of fixFixes introduced inRelated articles
Release13.1.0K2200: Most recent versions of F5 software
HotfixNoneNone

Workaround

There is no work around for this issue; however, you can avoid it by configuring the second BIG-IP APM system with at least one server in the Server List settings of the Connectivity Profile.
