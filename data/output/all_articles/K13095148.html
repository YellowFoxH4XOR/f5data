Topic

You should consider using this procedure under the following condition:

  • You want to review BIG-IP APM access logs.

Description

You can use the Configuration utility to review BIG-IP APM access logs.

To watch a video demo of this procedure, go to  Reviewing BIG-IP APM access logs.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the Configuration utility.

Procedures

Reviewing access logs

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Access > Overview > Access Reports.
  3. Under Restrict by Time, select the appropriate options.
  4. Select Run Report.

    Note: By default, the generated report displays a summary of all sessions.
