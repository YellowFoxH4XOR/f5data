Description

Connection reset with TCP RST "No connection auth for HTTP2" or HTTP/2 RST_STREAM "HTTP_1_1_REQUIRED"

 

Environment

- HTTP/2 Virtual Server

- Kerberos Authentication ("WWW-Authenticate: Negotiate" header in HTTP response)

- TCP RST with cause "No connection auth for HTTP2"

- RST_STREAM "HTTP_1_1_REQUIRED"

 

Cause

BIG-IP does not support Kerberos authentication on the HTTP/2 Virtual Server.

 

Recommended Actions

Don't use HTTP/2 VS when there's Kerberos authentication between the client and pool member.
