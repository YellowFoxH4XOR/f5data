Known Issue

Oracle Access Manager (OAM) API exception may cause the BIG-IP APM eam process to exit and produce a core file.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with an OAM AAA Server.
  • The OAM API experiences an exception when obtaining the redirect URL during authentication.

Impact

Users are unable to authenticate while the eam process restarts, and rebooting the BIG-IP APM system may be required to recover.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H475526 on the Diagnostics > Identified > High screen.
  • Users are unable to authenticate when using the BIG-IP APM system to access applications.
  • The system generates an eam core file to the /shared/core directory.
