K000139415: Modifying iFiles via AS3 using Base64 encoding

Type
Support Solution
Published
2024-04-26
Updated
2024-04-26
Applies to
  • F5 Automation and Orchestration
  • F5 Application Services 3 Extension
Source
https://my.f5.com/manage/s/article/K000139415

Description

When a new Base64 value for an iFile of the same name is POSTed to a device the old iFile content is still used.

 

Environment

AS3 is used for iRules deployment referencing iFiles.

 

"example_ifile.html": {

"class": "iFile",

"iFile": {

"base64": "[new base64 value]"

}

}

 

Cause

 

As long as an iFile name is not changed the AS3 treats the file as an existing one and not modifying its content.

 

Recommended Actions

Need to either DELETE the existing iFile and then deploy under the same name with a new Base64 value or rename the iFile in the declaration.

 

Additional Information

None.
