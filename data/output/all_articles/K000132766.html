Description

The following error occurs when attempting a manual "Check for updates" for ASM Attack Signatures:

Check for updates failed for the following modules:
ASM Attack Signatures - Could not retrieve latest file for asm-attack-signatures
Browser Challenges - Could not retrieve latest file for browser-challenges
Server Technologies - Could not retrieve latest file for server-technologies

You can also observed the following error message in /var/log/tomcat/liveupdate.log showing the BIG-IP is communicating to callhome.f5.com through proxy “null”.

 

liveupdate 2023-02-06 05:39:57.000 +07:00 Unknown ERROR Download:75 - Curl failure

liveupdate 2023-02-06 05:39:57.000 +07:00 Unknown ERROR Curl:53 - Curl fail: exit = 5, /usr/bin/curl -X POST -H Content-Type: text/xml;charset=UTF-8 -H SOAPAction: SoftwareUpdate --user dpi@f5.com:DPIautoSIGupdate -H User-Agent: bigip/14.1.4 -d @- --proxy https://<null>:8080 https://callhome.f5.com/soa/softwareupdate/ , with error: % Total % Received % Xferd Average Speed Time Time Time Current

liveupdate 2023-02-06 05:39:47.000 +07:00 Unknown INFO Curl:32 - Curl command: "/usr/bin/curl" "-X" "POST" "-H" "Content-Type: text/xml;charset=UTF-8" "-H" "SOAPAction: SoftwareUpdate" "--user" "dpi@f5.com:DPIautoSIGupdate" "-H" "User-Agent: bigip/14.1.4" "-d" "@-" "--proxy" "https://<null>:8080" "https://callhome.f5.com/soa/softwareupdate/"

 

Environment

  • BIG-IP AWAF
  • Manual “Check for updates”
  • Direct access to internet

 

Cause

Reverted the db proxy to default by setting the proxy.host value to "null" instead of reset-to-default in BIG-IP.

 

Recommended Actions

Reset the following db proxy settings below to reset-to-default.

 

1. Login to BIG-IP command line.
2. Enter the commands below to reset the db proxy settings to default:

#tmsh modify sys db proxy.username reset-to-default
#tmsh modify sys db proxy.protocol reset-to-default
#tmsh modify sys db proxy.port reset-to-default
#tmsh modify sys db proxy.password reset-to-default
#tmsh modify sys db proxy.host reset-to-default


3. Save the configuration:

 

#tmsh save sys config


4. Restart tomcat service:

 

#bigstart restart tomcat
