Issue

Error Message

01020062:3: IP Address <IPv4 link-local Addresses> is invalid, link-local address not allowed.

In this error message, note the following:

  • <IPv4 Link-Local Addresses> is an IP subnet that belongs to the 169.254.0.0/16 range.

For example:

01020062:3: IP Address 169.254.100.0 is invalid, link-local address not allowed.

Message Location

You may encounter this message in the following locations:

  • Configuration utility
  • Command line

Description

This message occurs when one of the following conditions is met:

  • You attempt to add an IP address within the 169.254.0.0/16 subnet range of the IPv4 link-local address definition in the Configuration utility
  • You attempt to add an IP address within the 169.254.0.0/16 subnet range of the IPv4 link-local address definition in the command line using the bigpipe command or TMOS Shell (tmsh)

IPv4 link-local addresses are addresses suitable for communication with devices directly connected to the same physical or logical link. The range and usage of the IPv4 link-local address is defined in RFC 3927 - Dynamic Configuration of IPv4 Link-Local Addresses.

Starting with BIG-IP 11.4.1, 11.3.0 HF8, and 11.2.1 HF10, you can use the IPv4 link-local addresses to configure any of the BIG-IP system data plane addresses by setting the system database key config.allow.rfc3927 to enable. By default, the database key is not enabled. Without modifying the database key, if you configure a BIG-IP object with an IP address within the range of IPv4 link-local addresses, you will observe this error message.

Note: The database key is not applicable to the management plane of the BIG-IP system. You can configure the management IP address with IPv4 link-local addresses, but only with a /16 netmask.

Impact

The BIG-IP system is unable to add routes to IP subnets with addresses from the IPv4 link-local address definition.

Recommended Actions

F5 recommends that you do not use the IP ranges from the IPv4 link-local address definition. However, you can set the config.allow.rfc3927 database key to enable if you are required to use the IPv4 link-local addresses.
