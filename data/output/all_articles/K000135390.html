K000135390: Pools in unknown state on standby device after the upgrade of BIG-IP devices

Type
Support Solution
Published
2023-07-13
Updated
2026-10-22
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0, 17.1.1, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.3, 17.1.2, 16.1.3
Source
https://my.f5.com/manage/s/article/K000135390

Description

After upgrading BIG-IP devcies, the standby BIG-IP device marks nodes and pools as an Unknown state where they are available on the active BIG-IP.

Environment

  • BIG-IP LTM
  • BIG-IP device upgrade
  • High availability configuration

Cause

The affected device remained in the ForcedOffline state after the upgrade instead of transitioning to Standby.

Recommended Actions

  1. If the affected device is in the ForcedOffline state, release it from Offline so that it transitions to Standby.
  2. If the nodes and pools remain in an Unknown state on the standby device, remove and re-add the monitors from the affected pools.
