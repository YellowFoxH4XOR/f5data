Description

  • FPS alert and notification can be monitored locally using local BIG-IQ or remotely on F5's managed system.
  • You would like to know you Account ID so that you can start receiving alerts and notifications on the bigIQ FPS dashboard.

Environment

  • BIG-IQ Dashboard
  • FPS
  • BIG-IP

Cause

  • Lack of account ID to configure BIG-IQ dashboard to receive FPS alert

Recommended Actions

  • Need to have account ID and this Account ID can be obtained from F5 SOC team
  • Access to both system can be attained by calling the F5 SOC team following K2633: Instructions for submitting a support case to F5
