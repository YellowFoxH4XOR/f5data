Description

  • Enable HSTS globally to all the VirtualServers in Nginx Ingress Controller
  • No related configMap key is available

Environment

  • Nginx Ingress Controller

Cause

HSTS is not allowed in a configMap when using Virtual Servers according to the official document.

 Recommended Actions

  1. Adding add_header via HTTP Snippets in configMap, data block
  2. Example
data:
    http-snippets: |
         add_header Strict-Transport-Security "max-age=63072000; includeSubDomains" always;

None.
