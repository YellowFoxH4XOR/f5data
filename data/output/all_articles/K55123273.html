Description

Config sync will fail with the following error message:
Sync Failed

A validation error occurred while syncing to a remote device

Sync error on ltm-01.example.com: Load failed from /Common/ltm-02.example.com 01070920:3: Application error for confpp: Syntax OK The certificate does not match the key. To change them try 'tmsh modify sys httpd { ssl-certfile /etc/httpd/conf/ssl.crt/server.crt ssl-certkeyfile /etc/httpd/conf/ssl.key/server.key }'

Recommended action: Review the error message and determine corrective action on the device

It is also noticed that you are not able to access the GUI (Configuration Utility) of the peer device. Device certificate of the peer might have been changed recently.

Environment
  • BIG-IP HA
  • Is not able to access the peer's GUI (Configuration Utility)
  • Recently changed the device certificate of the peer.

Cause

The issue is that the peer's certificate and key do not match. This could be caused by either conditions:

  • Not importing both certificate and key correctly
  • Generating a certificate without the key

Recommended Actions

To resolve the issue, you would need to ensure that the device certificate and key matches. Follow one of the following steps below to resolve the issue.

  • Renewing the self-signed device certificate using the command line. K6353
  • Replacing the Configuration utility's self-signed SSL certificate with a CA-signed SSL certificate. K42531434

Additional Information

None.
