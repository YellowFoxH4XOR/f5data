K000089463: Instance Group feature is not enabled by default

Type
Support Solution
Published
2021-07-13
Updated
2022-07-17
Source
https://my.f5.com/manage/s/article/K000089463

Description

NGINX Controller 3.18 released Instance Group feature, but this may not be enabled by default.

Instance Group feature is not showing in NGINX Controller UI, so it can not be configured.

 

 Environment

  • NGINX Controller 3.18
  • Instance Group feature

 

 Cause

Instance Group may need to be enabled first.

 

 Recommended Actions

You need to enable Instance Group feature from NGINX Controller CLI with this command:

$ /opt/nginx-controller/helper.sh setfeature ENABLE_INSTANCE_GROUP true

 

 Additional Information

An Instance Group is a logically grouped set of instances that can be used as a placement for a Gateway, rather than a single instance.
