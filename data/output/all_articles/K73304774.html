Description
How is it possible to block requests using X-Forwarded-for IP address in a AFM/IP Intelligence setup

Environment

  • AFM
  • IP Intelligence (IPI)
  • X-Forwarded-For

Cause
 AFM can not read layer 7 headers, it can read L3/L4 headers .
 So it is not possible to block using X-forwarded-For header using AFM/IP Intelligence setup

Recommended Actions
There are two possible options to achieve this :

Option 1 :
ASM/IP Intelligence setup can block using X-Forwarded-For
To do that, "Enable" Trust XFF Header option under   Security  ››  Application Security : Security Policies : Policies List

Option 2 :
Following iRule is a example but this need to be tested according to the requirement
 when HTTP_REQUEST {
    set ip_reputation_categories [IP::reputation [HTTP::header X-Forwarded-For]]
    set is_reject 0
    if {($ip_reputation_categories contains "Windows Exploits")} {
       set is_reject 1
    }
    if {($ip_reputation_categories contains "Proxy")} {
           set is_reject 1
    }
    if {($is_reject)} {
        log local0. "Attempted access from malicious IP address [HTTP::header X-Forwarded-For]
        ($ip_reputation_categories), request was rejected"
        HTTP::respond 200 content "<html><body><h1>Rejected </h1></body></html>" Content-Type "text/html"
    }
}
