Description

You may refer K60612439: Manually updating the BIG-IP default CA certificate bundle file try update default CA certificate bundle file on GUI System > Certificate Management > Traffic Certificate Management > Bundle Manager List. but it is failed, and you get following log on file /var/log/ltm.

Mar 19 15:35:39 Hostname notice keymgmtd[5548]: 01a40000:5: Download failed: https://cdn.f5.com/product/ca-bundle/blended-bundle.crt - Couldn't connect to server
Mar 19 15:35:39 Hostname notice keymgmtd[5548]: 01a40000:5: BundleMgr /Common/ca-bundle import aborted. No change to ca-bundle /Common/ca-bundle.crt

Environment

  • Ca-bundle
  • keymgmtd
  • 01a40000:5

Cause

There are network connectivity issues between BIG-IP and server cdn.f5.com, when through GUI update the Ca-bundle file, the BIG-IP will try to connect to server cdn.f5.com and download the Ca-bundle file, when the BIP-IP is unable to download the file and will generate above log.

Recommended Actions

You can use the ping/telnet command to check the network connectivity between the BIG-IP and server cdn.f5.com then fix it, Or manually download the Ca-bundle file and update it on CLI.
