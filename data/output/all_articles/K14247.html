Known Issue

Using the Traffic Management Shell (tmsh) to swap pool members between pools may cause configuration synchronization (ConfigSync) to fail.

This issue occurs when all of the following conditions are met:

  • You have two or more devices in a sync group.
  • You have two or more pools configured.
  • You use the tmsh utility to swap pool members between pools and assign the same monitor to the swapped members, which are assigned to the parent pool.

    Note: This issue does not appear when using the BIG-IP Configuration utility.

Impact

BIG-IP hosts in the device group will be out of synchronization.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The /var/log/ltm file of the target device displays error messages that appear similar to the following example:

    err mcpd[<pid>]: 01070712:3: Caught configuration exception (0), Can't load monitor instance for /Common/<monitor_name>:31 - ltm/validation/MonitorRule.cpp, line 1606.

    err mcpd[<pid>]: 01071488:3: Remote transaction for device group /Common/<device_group> to commit id 7 5868669933750114560 /Common/<hostname> 0 failed with error 01070712:3: Caught configuration exception (0), Can't load monitor instance for /Common/http:31 - ltm/validation/MonitorRule.cpp, line 1606.
  • The tmsh command prompt displays a message that appears similar to the following example:

    (cfg-sync Sync Failed) (Active) (/Common) (tmos) #
  • When using the show cm sync-status tmsh command, the sync status displays a message that appears similar to the following example:

    Color red
    Status Sync Failed
    Summary A validation error occurred while syncing to a remote device
  • The BIG-IP Configuration utility displays a Sync Failed message.

Workaround

To work around this issue, you can use the tmsh utility to reset the default pool monitors inherited from the parent. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Setting the pool member monitor using the tmsh utility

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh utility, you can skip this step.
  2. Set all pool members in a pool to inherit the default pool monitor:

    modify ltm pool <pool_name> members modify { all { monitor default } }

    Replace <pool_name> with the name of the affected pool. Repeat this command for each affected pool.

    Note: To set a different monitor for members than the default pool monitor, replace default with the monitor you want to use.
  3. Save the change by typing the following command:

    save /sys config
