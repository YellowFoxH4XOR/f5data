Topic

If your Outlook Web Access (OWA) 2003 server uses forms-based authentication, and you want to configure single sign-on (SSO) using a FirePass Portal Access favorite, perform the following procedure:

Important: To log on using SSO with OWA 2003, the user’s FirePass username and password must be identical to the user’s Microsoft Exchange username and password.
 
Note: If your OWA 2003 server uses basic authentication, and you want to configure SSO using a FirePass Portal Access favorite, refer to the Deploying Microsoft Exchange Server/Outlook Web Access and F5's FirePass Controller Deployment Guide.

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Portal Access: Web Applications: Resources page.
  3. Click the Add New Favorite link.
  4. In the Name field, enter a name for the favorite.

    For example:

    OWA_2003
  5. In the URL field, enter the URL for the owaauth.dll file on the OWA 2003 server.

    Note: Typically, this file is located at /exchweb/bin/auth/owaauth.dll under the root URL.

    For example:

    http://mail.siterequest.com/exchweb/bin/auth/owaauth.dll
  6. Connect users to OWA 2003 as either a public computer with the full OWA web client, a private computer with the full OWA web client, or to the OWA server as a private computer with the OWA light web client. To do so, select one of the following four options:

    • Connecting to OWA 2003 as a public computer with the full OWA web client

      Enter the following content in the URL variables field where [OWA_Root_URL] is the root URL of the OWA server:

      destination=[OWA_Root_URL]/exchange&flags=0&username=%username%&password=
      %password%&SubmitCreds=Log+On&forcedownlevel=0&trusted=0

      For example:

      https://mail.siterequest.com
       
    • Connecting to OWA 2003 as a private computer with the full OWA web client

      Enter the following content in the URL variables field where [OWA_Root_URL] is the root URL of the OWA server:

      destination=[OWA_Root_URL]/exchange&flags=4&username=%username%&password=
      %password%&SubmitCreds=Log+On&forcedownlevel=0&trusted=4

      For example:

      https://mail.siterequest.com
       
    • Connecting to the OWA server as a private computer with the OWA Light web client

      Enter the following content in the URL variables field where [OWA_Root_URL] is the root URL of the OWA server:

      destination=[OWA_Root_URL]/exchange&flags=5&username=%username%&password=
      %password%&SubmitCreds=Log+On&forcedownlevel=1&trusted=4

      For example:

      https://mail.siterequest.com
       
    • Connecting to the OWA server as a public computer with the OWA Light web client

      Enter the following content in the URL variables field where [OWA_Root_URL] is the root URL of the OWA server:

      destination=[OWA_Root_URL]/exchange&flags=1&username=<username>&password=
      <password>%21&SubmitCreds=Log+On&forcedownlevel=1&trusted=0

      For example:

      https://mail.siterequest.com

      Note: For information about the security implications of connecting as a public or private computer, or for information about the OWA Light client, refer to your Microsoft Exchange 2003 documentation.
  7. Select the Use POST for URL variables check box.
  8. Optionally, select the Open in New Window check box.
  9. In the Allow list field, enter a list of URLs required for accessing the OWA 2003 server.

    For example:
    • http://mail.siterequest.com/*
    • https://mail.siterequest.com/*
  10. Click the Add New button.
