Description

You filtered an IP address in a packet capture with src filter and you are unable to decrypt the traffic even though you enabled TLS Session Secret Ethernet Trailers and used --f5 ssl flag.

Environment

  • Packet Capture
  • Tcpdump

Cause

Using src filter in tcpdump may result in collecting only one side of the conversation between the client and the server. Both sides of the TLS handshake need to be captured in order to decrypt the traffic.

Recommended Actions

Check if your packet capture contains the traffic from both the client and the server. If you can only see one side of the conversation, collect the packet capture once again, filtering IP addresses with host instead of src.
