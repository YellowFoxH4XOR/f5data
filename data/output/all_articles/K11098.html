Known Issue

This is the result of a known issue. If a server stops responding to an open CIFS session, and the NSM processor with the CIFS session has an increasing number of client queries for the server, the NSM processor may fail.

Note: This issue could result in multiple NSM processor failures.

F5 Product Development tracked this issue as ARX ID 36187 and it was fixed in ARX versions 4.1.1 and 5.0.6. For information about upgrading, refer to the ARX release notes.

Workaround

To recover a failed NSM you must reload the ARX system. Additionally, you should determine why the filer stopped responding.
