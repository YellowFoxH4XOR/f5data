Description

What is Software Rebroadcaster ?

Environment

  • F5OS
  • Software Rebroadcaster
     

Cause

The software Rebroadcaster creates a Rebroadcast Listener (rbcast-listener) when tenants share VLANs. 

There are configuration objects called 'vlan-listeners' which are automatically created for tenants when they are assigned vlan tags. When a single tenant exists, the vlan-listener matches incoming traffic on a vlan to a tenant (more precisely, the tenant's service-ID).

When subsequent tenants are created that share a vlan, incoming broadcast packets (like ARP requests) need to go to each tenant on the shared vlan, not just one. To handle this, the vlan-listener marks the packets to be delivered to the Software Rebroadcaster, a process running on each blade. The Software Rebroadcaster only handles packets that need to be broadcast/flooded to each tenant. It receives incoming ARP requests and makes copies of these packets for each tenant on the vlan.
