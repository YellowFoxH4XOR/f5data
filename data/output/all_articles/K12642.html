Known Issue

This is the result of a known issue. Creating a gateway pool member that does not reside on a directly connected network results in a TMM heartbeat timeout. The behavior occurs when TMM attempts to send out traffic through the route specified by the gateway pool. As a result, TMM enters a state in which it stops responding to heartbeat requests and reboots the system.

Note: The issue described within this article is not intended behavior; this is not a valid configuration and the Configuration utility should not allow this type of configuration.

F5 Product Development tracked this issue as ID 343056 and it was fixed in BIG-IP 10.2.2 and 11.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.
