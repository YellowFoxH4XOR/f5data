K000160850: BIG-IP GUI Update Check Displays Edge GeoIP Database Updates Instead of Pulse

Type
Support Solution
Published
2026-04-16
Updated
2026-04-16
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000160850

Description

When using the BIG-IP LTM system with the Pulse geolocation database installed, the GUI's Update Check feature (System > Software Management > Update Check) displays available updates for the Edge geolocation database, not Pulse. This can cause confusion for administrators expecting the GUI to reflect Pulse updates. Despite the GUI notification, the Pulse database remains active for traffic processing if installed. Administrators must manually manage Pulse database updates.

Environment

  • Product: BIG-IP LTM
  • Version: 17.1.3
  • Configuration: Pulse geolocation database installed and in use
  • Feature: GUI Update Check (System > Software Management > Update Check)
  • High Availability (HA): Database updates are not synchronized between HA peers

Cause

The BIG-IP GUI Update Check subsystem is hardcoded to display Edge geolocation database updates, regardless of which database variant (Edge or Pulse) is installed. There is no current configuration option or workaround to make the GUI display Pulse-specific update notifications.

Answer/Recommended Actions

  • Disregard the GUI notification for Edge updates if you are using the Pulse database.
  • To verify the active geolocation database:
  1. Log in to the BIG-IP bash shell.
  2. Run the following commands:

    • ls -ltr /shared/GeoIP/v2/
    • rpm -qa | grep -i geo
  • geoip_lookup <any_valid_IP_address>
  1. The RPM package name and file sizes will confirm the Pulse variant is installed (Pulse requires at least 900 MB and will show significantly larger files than Edge).
  • To update the Pulse database:
  1. Log in to MyF5 Downloads and navigate to Resources > Downloads.
  2. Select BIG-IP as the Group and your product version (e.g., 17.x).
  3. Under Select a product container, choose GeoLocationUpdates_Pulse (not Edge).
  4. Download the .zip and .md5 files and transfer them to /shared/tmp on the BIG-IP.
  5. Verify the MD5 checksum, then unzip and install the RPMs as described in KB K11176.
  6. Load the updated database: tmsh load sys geoip
  7. For HA environments, repeat the update process on each device, as updates are not synchronized.
  • Be aware of Bug ID 1642301: Loading a single large Pulse GeoIP RPM can cause a TMM core on BIG-IP 17.1.3, resulting in traffic disruption during TMM restart. Plan maintenance accordingly.

Additional Information

  • The GUI Update Check behavior is a known product limitation. Enhancement requests (RFEs) exist to improve this functionality.
  • Only one geolocation database (Edge or Pulse) can be active at a time.
  • The Pulse database remains active for traffic processing if installed, regardless of GUI notifications.
