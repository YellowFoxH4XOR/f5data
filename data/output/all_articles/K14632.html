Known Issue

Your configuration may fail to load after upgrading to BIG-IP 11.0.0 - 11.3.0.

This issue occurs when all of the following conditions are met:

  • The bigpipe audit logging option is set to either Verbose, Debug, or All in a BIG-IP 10.x configuration.
  • You have upgraded from BIG-IP 10.x, or are attempting to load a 10.x UCS file on an 11.x system.

Impact

The BIG-IP configuration will fail to load and the BIG-IP system remains in an inoperable state.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H427311 on the Diagnostics > Identified > High screen.
  • The BIG-IP Configuration utility displays an error similar to the following:

    The configuration has not yet loaded. If this message persists, it may indicate a configuration problem.

  • When attempting to load the configuration from tmsh, you may see an error similar to the following:

    Loading configuration...
    /config/bigip_base.conf
    Syntax Error:(at line: 6) "audit" invalid value "}", expected one of the following: "disabled" "enabled"  

  • The /var/log/ltm file may contain an error similar to the following:

    01420006:3: "audit" invalid value "}", expected one of the following: "disabled" "enabled"

Workaround

To work around this issue, you can make manual changes to the auditing configuration. To do so, perform the following procedure:

Impact of workaround: None

  1. Log in to the BIG-IP system as the root user.
  2. Using a text editor such as vi, edit the /config/bigip_base.conf file, and locate the following lines:

    cli global-settings {
    audit
    }

  3. Modify the previous lines as follows:

    cli global-settings {
    audit enabled
    }

  4. Re-load the BIG-IP configuration by typing the following command:

    tmsh load sys config
