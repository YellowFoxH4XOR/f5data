Known Issue

When a User Datagram Protocol (UDP) request is close to the default maximum payload size, and the response is larger than the maximum default payload size, responses may not reach the client.

This issue occurs when all of the following conditions are met:

  • The Datagram Load Balancing setting is enabled in the UDP profile.
  • The client has a non-standard maximum UDP payload size greater than 4096 bytes.
  • The responding pool member increases the size of the UDP response above 4096 bytes.

This may be seen when a Domain Name System Security Extensions (DNSSEC) request is signed by a DNSSEC pool member, increasing the response above 4096 bytes.

Impact

The client might receive a fragmented response that it may not be able to process, or a firewall might drop the response between the BIG-IP system and the client.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • DNSSEC or large UDP responses may not reach the client.
