Description

Starting in BIG-IP version 11.5.0, the system automatically checks the F5 Downloads server for available software updates on a weekly basis under GUI menu System > Software Management > Update Check. However, you might also need to manually check the F5 Downloads server for available software updates for your system. This article explains how to do that from the command line.

Environment

BIG-IP

Cause

None

Recommended Actions

To manually check the F5 Downloads server for software updates for your BIG-IP system, perform the following steps:

  1. Log in to the BIG-IP system via SSH or the console as a user with root-level permissions.
  2. Run the following command to check for software updates: 
    updatecheck -d -f
    This command checks the F5 Downloads server for available software updates, and the -d option enables debug output. The -f option forces the command to execute and ignore the auto-check-enabled setting.
  3. After the command completes, it displays the available software updates, similar to the following example: 
    Discovered versions:
        Release: 15.1.2-0.0.9
        GEOLOC-Region2: 2.0.0-20201026.472.0
        GEOLOC-ISP: 2.0.0-20201026.472.0
        GEOLOC-v6: 2.0.0-20201026.472.0
The command also generates debug output, which includes a SOAP message. This message is used to communicate with the F5 Call Home service to check for software updates.
