K000134731: BIG-IQ 8.3 - privateKey and certificate options are missing when attempting to create an AS3 application using an AS3 template

Type
Support Solution
Published
2023-05-22
Updated
2023-05-22
Source
https://my.f5.com/manage/s/article/K000134731

Description

You are trying to deploy an AS3 application using an application template on BIG-IQ and you need to add the privateKey or certificate.
There are no "Private key Schema Type: Advanced Schema" and "Private key Schema Type: Advanced Schema" under Applications > Application Templates > Certificate

Environment

BIG-IQ
AS3 version 3.43.0 and 3.44.0

Cause

The issue is from the AS3 library (f5-appsvcs). Version 3.43.0 and 3.44.0 are affected and you will be unable to add the certificate or privateKey to the template while running these AS3 versions.
This is tracked with ID1295309


Recommended Actions

To workaround this issue you can install a non affected AS3 version, we suggest installing version 3.42.0

1. Download the v3.42.0 rpm file https://github.com/F5Networks/f5-appsvcs-extension/releases/download/v.3.42.0/f5-appsvcs-3.42.0-5.noarch.rpm and copy to /shared/tmp/ of BIG-IQ System

2. Mount the /usr partition with rw permissions
  > mount -o remount,rw /usr

3. Copy the rpm downloaded to the directory using the below command
  > cp /shared/tmp/f5-appsvcs-3.42.0-5.noarch.rpm /usr/lib/dco/packages/f5-appsvcs/

4. Mount the /usr partition with ro permissions
  > mount -o remount,ro /usr

5. Uninstall the existing rpm package using the below command
  > rpm -e --nodeps f5-appsvcs-3.44.0-3.noarch

6. Install the respective rpm (v3.42.0)
  > rpm -Uv /usr/lib/dco/packages/f5-appsvcs/f5-appsvcs-3.42.0-5.noarch.rpm
