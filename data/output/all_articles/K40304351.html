Description

This article provides details about the internal browser the Edge Client used prior to 7.2.5.0 and how Java is related.

Environment

  • APM edge client
  • Client device

Cause
You're exploring the APM Edge Client and its capabilities.

Recommended Actions

  1. What internal browser does Edge Client leverage?
    • It's not Internet Explorer, but rather an operating system referred to as WebBrowser Control. It's not a full browser and some features are intentionally restricted for security purposes.
    • WebBrowser Control Overview
  2. What version does WebBrowser Control leverage?
    • Mozilla/5.0 (Windows NT 10.0; WOW64; Trident/7.0; rv:11.0)
  3. Is there an option within this browser to debug?
    • In APM version 16 and Edge Client 721x there is an option to turn off "browser control" by using OIDC mode. This enables access to the browser for debug purposes. Refer to the following article on configuring this access.
    • BIG-IP Edge Client for Windows: About OIDC Support in Edge Client for Windows
  4. What happened when IE reached out of support?
    • Refer to APM Edge Client Compatibility Matrix for latest information on the web browser compatibility.
  5. What version of Java does the Edge client use?
    • The Java version is dependent on the operating system of the device and the installed version of java, not the Edge Client.
    • Manual : BIG-IP APM Client Compatibility Matrix: Java™ Compatibility Matrix
  6. What version of Javascript does the Edge Client use? Does this change with the Edge Client version?
    • Javascript is not packaged with the Edge Client. The Javascript version is dependent on the client's device and web browser, not the Edge Client.
