K000161372: Software versions mismatch between system controllers after PXE clean Install

Type
Support Solution
Published
2026-05-22
Updated
2026-05-22
Applies to
  • F5OS
  • F5OS-C: 1.8.X, 1.8.2, 1.8.1, 1.8.0
Source
https://my.f5.com/manage/s/article/K000161372

Description

After performing a VELOS system controller replacement via PXE boot, the output of the show system version command on the replacement system controller does not match the version running on the Active Controller.

 

### Active Controller

# show system version
system version os-version 1.8.2-28324
system version service-version 1.8.2-28324
system version product F5OS-C
 
### Standby Controller
# show system version
system version os-version 1.8.1-26929
system version service-version 1.8.1-26929
system version product F5OS-C

 

Environment

F5OS-C

Replacement of a Standby System Controller using PXE boot

 

Cause

ID1993457

 

 

Answer/Recommended Actions

Reboot the replacement system controller.

 

 

Additional Information

This issue is a display inconsistency and does not affect the actual running software.
