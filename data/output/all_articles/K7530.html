Topic

By default, SNMPv1 traps use the IP address associated with the BIG-IP host name as the agent-addr address, which is the IP address from which SNMP traps originate.

In the BIG-IP system, the management port IP address is typically associated with the system's host name. However, in some cases, the management port is not used, or remote SNMP systems reside on an IP network reachable through an interface other than the management port. In those cases, an alternate trapsource address must be configured.

Note: If you associate the agent-addr address with an address other than the management IP address, you must use a self IP address configured on the local BIG-IP system. F5 recommends using a unique non-floating self IP address on each unit of a redundant pair, allowing each unit to send an SNMP trap whether it is in an active or standby state.

Workaround

You can work around this issue by specifying the source IP address that the agent-addr uses for SNMPv1 traps. To specify the trapsource IP address, perform the following procedure that applies to your version of BIG-IP:

BIG-IP 11.0.0 and later

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  2. Specify the trapsource address by typing the following command:

    modify /sys snmp trap-source <IP address>

    Where <IP address> is the IP address you wish to specify as the trap-source
  3. Save the changes to the snmp trapsource setting by typing the following command:

    save /sys config
  4. Restart the alertd process by typing the following command:

    bigstart restart alertd

Note: You can reverse this change by repeating the procedure using the string none in place of the IP address.

BIG-IP 9.4.2 through 10.x

  1. Log in to the command line as a root user.
  2. Specify the trapsource address by typing the following command:

    bigpipe snmpd trapsource <IP address>
  3. Save the new configuration by by typing the following command:

    bigpipe save
  4. Restart the alertd process by typing the following command:

    bigstart restart alertd

Note: You can reverse this change by repeating the procedure using the string none in place of the IP address.

Important: To prevent the undesired synchronization of the trapsource address between members of a redundant pair, you must also perform the appropriate procedure from K9749: SNMP trap source address is synchronized between units of a redundant pair on both systems in the pair. By default, the SNMP trapsource address is synchronized between units in a high availability pair during a configsync operation. If you have configured a unique trapsource address for each system in the redundant pair, the trapsource address should not be synchronized between units.

BIG-IP 9.0.0 through 9.4.1

  1. Log in to the command line as a root user.
  2. Change directories to the to /config/snmp/ directory by typing the following command:

    /config/snmp/

  3. Back up the snmpd.conf file by typing the following command:

    cp snmpd.conf snmpd.conf.sol7530

  4. Using a text editor, edit the snmpd.conf file.
  5. Add the following syntax to the end of the file:

    trapsource <IP address>

  6. Save the changes to the file.
  7. Restart the alertd process by typing the following command:

    bigstart restart alertd

Note: You can reverse this change by restoring the original configuration file and restarting the alertd process.
