K000138342: How to disallow HTTP Method on BIG-IP Next WAF using BIGIP-Next Central Manager

Description:

There are number HTTP Methods, some are required for an application to work in production, where as some are there for troubleshooting purpose. If unwanted HTTP Methods are allowed in production application, malicious actors may use it to exploit the application. Based on the environment and requirement, you may want to disallow some HTTP Methods. In this article, HTTP DELETE Method is used as an example, you may choose any HTTP Method as per your requirement and disallow it in the WAF policy. 
 

Environment

  • You have at least admin privileges.
  • You have GUI access of BIG-IP Next Central Manager
  • You already know the WAF policy name for which you would like to perform the changes.
  • You already know the HTTP Method which you would like to disallow.

Cause

Disallow HTTP Methods

 

Recommended Actions

  1. Login to the GUI of BIG-IP Next Central Manager
  2. Under Manage Security Policies, click on Go to security workspace.
  3. Select policies under WAF and then select the policy for which you would like disallow the HTTP Method.
  4. A new window pane will open, scroll down and look for Header on the left side of the pane.
  5. Click on Header and you will see all the currently allowed HTTP Methods.
  6. Select the method you would like to disallow, in our case its DELETE method. Select it and click on delete on upper right side of the pane and confirm delete again on the pop up window.
  7. Next click on Violations on the upper right side and make sure it is set to ‘Alarm and Block’, then save it.
  8. Click on Deploy and click Deploy on the pop window again. You may add a comment if you wish to.
  9. Once the policy deployment is done, HTTP Method DELETE will be disallowed/blocked
