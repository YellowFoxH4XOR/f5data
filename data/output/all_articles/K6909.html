Known Issue

This is the result of a known issue. Multiple segment HTTP requests in conjunction with authorization causes the connection to hang. This issue occurs when an authorization profile such as LDAP or RADIUS is used with a virtual server that is handling multi-segment HTTP requests, in which the the segments arrive without the Authorization header. BIG-IP LTM returns a 401 Authorization Required response as soon as the first set of headers is processed. When the client issues the requests again with the correct authorization on the same TCP connection, the browser session hangs and no authorization is performed.

No error message is reported and no information is returned to the client.

F5 Product Development tracked this issue as CR72220 and CR71902, and it was fixed in BIG-IP LTM 9.2.5, 9.3.0, and 9.4.0. For information about upgrading, refer to the BIG-IP LTM release notes.
