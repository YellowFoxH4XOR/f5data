Description
When using the certificate inspection agent in an APM policy and using Edge Client to connect, the user might receive several prompts to select the correct certificate

Environment

  • BIG-IP Access Policy
  • Edge Client
  • Certificate Inspection agent

Cause
The virtual address or hostname is not added to the Trusted sites configuration 

Recommended Actions

  1. In Windows Control Panel, click Internet Options, and then click the Security tab.
  2.  Click Trusted Sites, and then click Sites.
  3. Add the FQDN of the virtual server that has the Access Policy attached
