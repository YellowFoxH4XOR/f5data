Description

Data group lists provide a way to include lists of information for reference by iRules in the BIG-IP system's configuration.

Environment

 

  • BIG-IP LTM
  • iRules using External Datagroup
  • CLI
  • WebUI

Cause

Internal classes are defined in the /config/bigip.conf file along with the data they contain.
External classes are also defined in the /config/bigip.conf file, but the data they contain is stored in a separate file that is referenced from the external class definition.

External class format is different depending on whether the class is internal or external, and is also different based on the class type: address, integer, or string.
 

Recommended Action

When you use the GUI to create key/value pairs in a internal data-group, GUI will format properly.
When you want to create external data-group, following following requirement.

  • Files should be text, with unix-style (linefeed) line termination
  • The record separator is a comma and should be present after each record
  • It is possible to have multiple records on a line, but not typical practice 
  • The last line requires a linefeed terminator
  • String data is formatted as multiple lines of
 "<string>" := "<value>",
  • Address data is formatted as multiple lines of 
    host "<ip address>" := "<optional value>",

network "<network CIDR>" := "<optional value>",
  • Integer data is formatted as multiple lines of
<integer> := "<value>",
