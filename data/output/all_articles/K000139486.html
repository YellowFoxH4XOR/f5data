Description

On BIG-IP DNS system, objects (virtual-servers) configured in GSLB GTM Servers showing UP status from Active DNS/LTM, and DOWN status from standby DNS/LTM.

For example, 2 LTMs working as Active/Standby configured in DNS GSLB as separate GTM Servers:

gtm server /Common/LTM1.example.com { # LTM Active
    datacenter /Common/DS1
    devices {
        LTM1.example.com {
            addresses {
                198.51.100.1 { }
            }
        }
    }
    monitor /Common/bigip
    product bigip
    virtual-server-discovery enabled
    virtual-servers...
 
gtm server /Common/LTM2.example.com { # LTM Standby
    datacenter /Common/DS1
    devices {
        LTM2.example.com {
            addresses {
                198.51.100.2 { }
            }
        }
    }
    monitor /Common/bigip
    product bigip
    virtual-server-discovery enabled
    virtual-servers...

Environment

  • BIG-IP DNS
  • BIG-IP LTM

Cause

LTMs HA (Active/Standby) pair is not reflected in DNS GSLB config under the same GTM Server, but configured as two separate, standalone systems.

Recommended Actions

Configure the Active/Standby LTMs in GSLB and group them under the same GTM Server, to reflect the LTM HA topology.

For example:

gtm server /Common/LMTs_HA_group { # Active/Standby LTMs grouped under the same gtm server
    datacenter /Common/DS1
    devices {
        LTM1.example.com { # Active LTM
            addresses {
                198.51.100.1 { }
            }
        }
        LTM2.example.com { # Standby LTM
        addresses {
                198.51.100.2 { }
            }
        }
    }
    monitor /Common/bigip
    product bigip
    virtual-server-discovery enabled
    virtual-servers...
