Description

You would like to know how to allow a meta character that has caused the illegal meta character in value violation.

Environment

  • Security Policy
  • Parameters
  • Meta characters

Cause

A legitimate parameter value has been blocked due to a disallowed character. This is considered a false positive.

Recommended Actions

To allow a meta character value at the parameter level:

  1. Go to Security >> Application Security : Parameters : Parameters List >> <parameter> >> Value Meta Characters
  2. Ensure the Check characters on this parameter value is checked.
  3. Select the meta character you want from the list of Meta Characters on the right. Then select << to move the selected meta character to the Overridden Security Policy Settings.
  4. Change the state to Allow for that meta character.
  5. Repeat steps 3 and 4 for any remaining meta characters you want to allow.
  6. Select Update to save the change.
  7. Select Apply Policy to effect the change.

Alternatively, for all parameters, this may be configured at:

  1. Go to Security >> Application Security : Parameters : Character Sets : Parameter Value
  2. Ensure the policy in the security policy list is the one you want to modify.
  3. Ensure the View setting is set to Meta characters only.
  4. Select Allow for the State setting of the meta character you want to allow.
  5. Repeat step 3 for any remaining meta characters you want to allow.
  6. Select Save to save the change.
  7. Select Apply Policy to effect the change.
