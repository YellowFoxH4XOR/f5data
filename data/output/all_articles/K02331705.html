Known Issue

The TMOS Shell (tmsh) is unable to list NT LAN Manager (NTLM) profiles if they reside in a different root folder or partition.

This issue occurs when the following condition is met:

  • You attempt to list an NTLM profile that exists in another folder or partition.

    For example:

    • The active folder or partition is /Common.
    • The NTLM profile my_ntlm exists in the /NTLM_Profile folder or partition.
    • You run a command similar to the following example to show details of an NTLM profile:

      list ltm profile ntlm /NTLM_Profile/my_ntlm

Impact

You are unable to display NTLM profiles that reside outside of the active folder or partition.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Attempting to run a tmsh command to list an NTLM profile that resides in a different folder or partition from the current active folder or partition results in an error message similar to the following example:

              Error in ntlm: "/<folder name>/<NTLM profile name>" not found.
              01020036:3: The requested Config Instance ( /<folder name>/<NTLM profile name>) was not found.

              For example:

             # tmsh list ltm profile ntlm /Test/test_ntlm_profile

             Error in ntlm: "/Test/test_ntlm_profile" not found.
             01020036:3: The requested Config Instance ( /Test/test_ntlm_profile profile_ntlm) was not found.

Workaround

To work around this issue, you can use the  tmsh change directory (cd) command to switch into the correct partition to list the NTLM profile.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

From the tmsh command line, use the following syntax:

cd /<Partition Name> before attempting to list any NTLM profiles that reside in the partition
