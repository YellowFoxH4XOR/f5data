K53293228: BIGIQ Login may list the same LDAP provider multiple times

Type
Support Solution
Published
2021-09-08
Updated
2026-08-12
Status
Legacy Content
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K53293228

Description

The BIG-IQ Login screen is misleading.

  • For authentication, the same LDAP server is listed multiple times.

Environment

Relevant environmental factors specific to the topic

  • While configuring LDAP authentication, it takes several attempts to save it.
  • Login prompt for BIG-IQ shows too many choices.
  • BIG-IQ CM

Cause

Unknown Cause.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. List out the LDAP servers from the BIG-IQ:
    1.  restcurl -u admin:<password> /mgmt/cm/system/authn/providers/ldap| jq .
  2. Look for the same server listed with different self-links:
    1.   "servers": [ { "host": "example.com", "port": 636 } ], "bindUser": "cn=userproxy,ou=example,dc=com", "isHidden": false, "selfLink": "https://localhost/mgmt/cm/system/authn/providers/ldap/3c6c0e6e-bb8c-4371-962d-ff3f0f8c95bc",
  3. Use restcurl to remove the additional server entries:
    1.  restcurl -X DELETE -u admin:<password> /mgmt/cm/system/authn/providers/ldap/3c6c0e6e-bb8c-4371-962d-ff3f0f8c95bc

Additional Information

None.
