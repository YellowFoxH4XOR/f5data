K2060: Error message: no nodes available

Source

Issue

The BIG-IP system logs this error message if it cannot connect to a virtual server because there are no nodes available to service the request.

Nodes may become unavailable when they have failed, reached their connection limit, or been disabled by an administrator.

The BIG-IP system logs this message after 10 unsuccessful attempts.
