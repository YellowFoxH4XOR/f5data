Topic

SSL Orchestrator configurations created and deployed on systems prior to SSL Orchestrator 14.0.0-4.0 cannot be rolled forward or imported when upgrading to version 14.0.0-4.0 or later.

Description

Due to changes implemented in SSL Orchestrator 14.0.0-4.0, configurations created and deployed on previous versions of SSL Orchestrator cannot be imported into SSL Orchestrator 14.0.0-4.0 and will not be rolled forward during the upgrade process to 14.0.0-4.0. When upgrading to SSL Orchestrator 14.0.0-4.0 or later from a previous version, you should first export the configuration and un-deploy the currently deployed applications. The export feature is introduced in SSL Orchestrator 13.1.0-3.0 and 13.0.0-2.3 and allows you to export the configuration to a JSON file.  If you are upgrading from a version prior to either of these, SSL Orchestrator guides you though the steps needed to complete the upgrade process.

To view the recommended instructions for upgrading to SSL Orchestrator 14.0.0-4.0, refer to the Installing and Configuring the System for F5 SSL Orchestrator chapter of the SSL Orchestrator: Setup manual for SSL Orchestrator 14.0.0.
