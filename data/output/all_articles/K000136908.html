Description

When attempting to generate and upload a qkview file from BIG-IQ to iHealth, you are getting a 400-415 HTTP response code, and you are unable to complete the upload. "Unexpected response when testing authentication"

Environment

BIG-IQ 8.x

Cause

In March 2023, the F5 iHealth team released iHealth2, which is iHealth with a new identity and authentication provider. Due to this change, we've noticed issues while uploading qkviews from BIG-IQ to iHealth.

Recommended Actions

We recommend upgrading to the latest version of BIG-IQ 8.3.x and follow the article K000133527: Failed to authenticate to https://identity.account.f5.com/oauth2. Login failed.

If after doing this, you are still unable to upload the qkview to iHealth, we will need to update the endpoint where the BIG-IQ is authenticating to do so. Please run the following command on the BIG-IQ CLI.

restcurl -u admin:a mgmt/cm/device/ihealth/config -d '{"iHealthEndpoint": "https://ihealth2-api.f5.com/qkview-analyzer/api/","iHealthAuthEndpoint": "https://identity.account.f5.com/oauth2/ausp95ykc80HOU7SQ357/v1/token"}' -X PUT
