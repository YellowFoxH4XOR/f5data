Known Issue

BIG-IP APM system might send an incorrect Issuer element for single logout (SLO) requests.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured as an Identity Provider (IdP).
  • The BIG-IP APM system is configured with multiple IdP configuration objects.
  • Each IdP configuration object is bound to at least one Service Provider (SP) connector.
  • Multiple IdP objects are assigned as resources to the same BIG-IP APM Access Policy.
  • The client initiates SLO on the BIG-IP APM IdP.

Impact

Some recipient (SP) implementations will reject the SLO request message causing the logout to fail.

Symptoms

As a result of this issue, you might encounter the following symptoms:

  • The Issuer element in the SLO request message incorrectly references the name of the last IdP service that the user has accessed.
  • The user is not logged out from all applications for which they have established a connection.
