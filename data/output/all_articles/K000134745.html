Description

Virtual server status is up on the LTMs

Pool member status is different on BIG-IP DNS sync group devices.

 

Environment

  • BIG-IP DNS
  • 1000+ virtual server objects in gtm.conf
  • virtual-server-discovery enabled

Cause

gtmd or big3d is overloaded

Recommended Actions

Follow the recommended actions in K15894475: The list processing time (32 seconds) exceeded the interval value. There may be too many monitor instances configured with a 30 second interval.
