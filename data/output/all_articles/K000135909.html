Description

The article explains how to configure the BIG-IP system to upload Qkview files to iHealth via a proxy server. The system by default reaches iHealth servers based on the routing table.

Environment

  • BIG-IP
  • Qkview upload
  • iHealth
  • Proxy server

Cause

None

Recommended Actions

Proxy settings are stored in system DB variables. They can only be modified via tmsh commands.

To configure proxy IP, port, and protocol (HTTP or HTTPS are only supported) as well as the proxy username and password if needed, perform the following procedure:

  1. Add the proxy host IP address:
    tmsh modify /sys db proxy.host value <IP>
  2. Add the proxy port:
    tmsh modify /sys db proxy.port value <port>
  3. Add the proxy protocol:
    tmsh modify /sys db proxy.protocol value <http|https>
  4. To determine if the proxy requires authentication (only basic authentication is supported), perform the following:
    proxy authentication can be verified with the curl utility, for example:
    curl -u username:password http://10.10.110.10:2020
    If the response says Authentication Required, then proxy.username and proxy.password need to be configured accordingly. Otherwise skip to step 7.
  5. Add the proxy username:
    tmsh modify /sys db proxy.username value <username>
  6. Add the proxy password
    tmsh modify /sys db proxy.password value <password>
  7. Save the configuration changes with the following command:
    tmsh save /sys config

Additional Information

The proxy server must be able to reach the following iHealth domains:

  • api.f5.com
  • ihealth-api.f5.com
  • ihealth2-api.f5.com
  • identity.account.f5.com

For more information refer to K15202: IP addresses for F5 hosted services.
