Description

After Rebooting a BIG-IP Virtual Edition, the configuration fails to load with the following symptoms:

  • Error message displayed: "The configuration has not yet loaded. If this message persists, it may indicate a configuration problem."
  • Running "tmsh load sys config partitions all" produces a syntax Error
  • Error message: Syntax Error:(/config/bigip_base.conf at line: 178) "1.1" unexpected argument
  • System remains inaccessible due to configuration load failure

Environment

  • Product: BIG-IP LTM
  • Platform: Virtual Edition
  • Configuration File: /config/bigip_base.conf
  • Recent Action: System Reboot / Manual Config Load Attempt

Cause

Malformed comment syntax in the STP configuration section of the "/config/bigip_base.conf" file. Specifically, inconsistent commenting where the opening braces lines (# net stp and # interfaces {) contain leading comment characters (#), while subsequent configuration blocks are parsed as active configuration. This creates a syntax error when the parser encounters the next valid interface configuration (1.1) unexpectedly.

Answer/Recommended Actions

  1.  Back up the current configuration file, under the same directory with different extension: 
    # cp /config/bigip_base.conf /config/bigip_base.conf.backup
  2. Edit "/config/bigip_base.conf" file:
    # vi /config/bigip_base.conf
  3.  Locate the STP configuration section which led to syntax Error:
    ...
# net stp /Common/cist {
# interfaces {
# 1.0 {
# external-path-cost 200000
# internal-path-cost 200000
# }
1.1 {
external-path-cost 200000
internal-path-cost 200000
}
...
  4. Remove the leading # comment character from the first two lines ( "# net stp ..." and "# interfaces {..." ). The corrected structure should appear as below. In below sample config block, we assume that there is no need to have the active config for Interface "1.0", so we can still have it as commented, while removing the comment from the main config blocks to have the correct expected block opening and closing:
    ...
net stp /Common/cist {
interfaces {
# 1.0 {
# external-path-cost 200000
# internal-path-cost 200000
# }
1.1 {
external-path-cost 200000
internal-path-cost 200000
}
...
  5. Save the changes, by pressing 'ESC' on your keyboard, followed by typing :wq and then pressing ENTER to quit.
  6. Verify the configuration loads successfully:
    # tmsh load sys config partitions all
     
  7. Monitor the output for any additional Errors, while you can Ignore warnings. After successful configuration load, the system should become fully operational within a few minutes.
