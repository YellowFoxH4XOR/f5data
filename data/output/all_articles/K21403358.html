Description

When you access the Statistics > Dashboard > ACTIONS menu in GUI and click Download Data (CSV) CSV file will not be downloaded using Internet Explorer 11.

Environment

  • Dashboard under statistics
  • Internet Explorer 11

Cause

The Statistics dashboard uses the method Object.assign() causes the download failure when using Internet Explorer 11

Recommended Actions

Microsoft announced the end of support for Internet explorer on June 15, 2022 and so support for it has also ended on BIG-IP.

Use alternative browser such as Microsoft Edge, Chrome, Firefox etc.
