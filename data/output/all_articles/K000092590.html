K000092590: Value of High and Low Watermark in v5.1

Type
Support Solution
Published
2022-11-26
Updated
2022-11-26
Source
https://my.f5.com/manage/s/article/K000092590

Description

  • SDC v4.4 calculates the watermarks based on queue message count, SDC 5.1 calculates it based on the queue bytes.
  • In SDC 5.1 the highwater mark level is 10,000 messages and the low watermark level is 2000 messages.

Environment

  • SDC 5.1

Cause

By design.

 Recommended Actions

None.

Additional Information

None.
