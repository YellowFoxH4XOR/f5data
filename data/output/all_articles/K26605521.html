Description

When trying to reactivate license, you observed the dossier is blank on Configuration Utility, and / or the below error message is showing in CLI after running the get_dossier command per K2595: Activating and installing a license file from the command line:

01170003:3: halGetDossier returned error (1): Dossier generation failed.

and /var/log/ltm shows:

err chmand[5896]: Curl request to metadata service failed with error(22): 'HTTP response code said error'
err chmand[5896]: 012a0003:3: DossierReq exception: VirtDossier Service: Instance identity retrieval from the metadata failed. Check network connectivity to the instance metadata before retrying

BIG-IP instance fails to be licensed and remains non-operational after reboot.

Environment

  • Amazon Web Services (AWS) metadata service
  • Virtual Edition
  • LTM log
  • License reactivation error

Cause

F5 AWS instances were unable to talk to AWS metadata service on IMDSV2 (Version 2). 
By default BIGIP AWS is using IMDS V1, changing IMDS from V1 to V2 may cause issues.
 

Recommended Actions

Check the supported BIG-IP VE versions for IMDSv2 via BIG-IP Virtual Edition > Check the metadata service for IAM role
If the version could not support IMDSv2, change BIG-IP AWS instance to use IMDSV1
