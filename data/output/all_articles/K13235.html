Known Issue

An IP tunnel object temporarily fails to pass traffic each time the tunnel attributes are changed using the TMSH utility.

This issue occurs when the following conditions are met:

  • The BIG-IP configuration contains at least one IP tunnel object
  • A user changes the tunnel attributes using the TMSH utility

For example, if the configuration contains an IP tunnel object and you modify the tunnel attributes using the tmsh modify /net tunnels tunnel command, the tunnel temporarily fails to pass traffic during the modify operation.

Impact

The IP tunnel temporarily fails to pass traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The IP tunnel temporarily fails to pass traffic just after the tunnel attribute was changed
