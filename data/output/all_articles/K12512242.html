Description
Log messages similar to the following are logged to /var/log/apm:

err tmm[<PID>]: 01490514:3: (null):Common:00000000: Access encountered error: ERR_NOT_FOUND. File: ../modules/hudfilter/access/access_license.c, Function: access_license_session_callback, Line: <access session>

  • <PID> is the process ID number of the reporting Traffic Management Microkernel (TMM) process.
  • <access session> is the line number of access_session.c code that processed the event.

Example:
Aug 13 21:54:09 slot3/BIG-IP-1 err tmm[20351]: 01490514:3: (null):Common:00000000: Access encountered error: ERR_NOT_FOUND. File: ../modules/hudfilter/access/access_license.c, Function: access_license_session_callback, Line: 1017
 

Environment

  • BIG-IP APM
  • Access

Cause
This message occurs when Access tries to refresh, or touch the license subkey for the session but failed to find it.
However, the error will not affect the access session, as Access will not look at the license status for a session once it passed policy evaluation.

Recommended Actions
None
