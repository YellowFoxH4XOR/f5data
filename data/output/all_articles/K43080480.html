Description

When the BIG-IP system encounters silent reboot, the system may log the below messages when it boot up again:

/var/log/ltm
chmand[4273]: 012a0005:5: CPLD indicates prior Host CPU subsystem power-off
chmand[<PID>]: 012a0005:5: Host CPU subsystem power-off caused by power button
chmand[4273]: 012a0004:4: Host CPU subsystem power-off event caused by Super IO

Environment

  • BIG-IP Hardware platforms
  • Silent reboot

Cause

This issue is either due to a PSU/power cable/power cord failure, or a user initated reload.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Check the power supply status.
  2. Check the power cable/power cord.
  3. Run EUD test if the same issue happens again on the same unit
