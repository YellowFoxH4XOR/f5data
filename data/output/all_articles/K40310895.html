Issue

Error Message

notice sod[<PID>]: 010c0044:5: Command: <description>

In this error message, note the following:

  • <PID> is the process ID of the sod process
  • <description> is a message describing the command that was executed and which administrative access method was used

For example:

notice sod[8842]: 010c0044:5: Command:  go offline all GUI.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • You execute a failover command using the Configuration utility, the TMOS Shell (tmsh), or iControl.

For example, if you execute the tmsh run /sys failover offline command from the BIG-IP command line, the BIG-IP system will generate the following message:

notice sod[8842]: 010c0044:5: Command:  go offline all tmsh.

If you subsequently use the Configuration utility to release the offline state, the BIG-IP system will generate the following message:

notice sod[8842]: 010c0044:5: Command:  release offline all GUI.

Impact

None. This message is a notification.

Recommended Actions

None
