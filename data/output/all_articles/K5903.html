Policy Information

Note: The BIG-IP software support policy described in this article also applies to Virtual Edition (VE) releases of the software.

Note: The F5 software support policy described in this article does not apply to the F5 BIG-IP Edge Client application software delivered through the Apple App Store or Android Market. F5 will support only the latest versions of these client applications.

Note: F5 has made the strategic decision to stop development of BIG-IP Next and instead modernize its BIG-IP TMOS software. BIG-IP Next 20.3 was the final version of BIG-IP Next, and this version reached end of life on April 30, 2025. For more information, refer to K000152956: BIG-IP strategic update: Modernizing BIG-IP TMOS and discontinuing BIG-IP Next.

Note: F5 will ensure continuity of BIG-IP TMOS software with future releases of BIG-IP 17.x. F5 will continue to invest in hardware through the rSeries and VELOS platforms, which will support BIG-IP 17.x and future versions of BIG-IP TMOS including 21.x.

Software version support of BIG-IP software

The BIG-IP Standard Support phase is characterized by the introduction of new features, as well as security updates, stability improvements, and new hardware support.

Starting with BIG-IP 12.0.0, F5 adopted an alternating Major Release and Long-Term Stability Release model:

For Major Releases (x.0.0) up to and including BIG-IP 17.0.0, the Standard Support phase begins with the first customer ship date of the release and continues for 15 months. For Major releases (x.0.0) beyond BIG-IP 21.0.0, the Standard Support phase begins with the first customer ship date of the release and continues for 9 months. When this milestone is reached, the Major Release has reached its End of Software Development (EoSD) and End of Technical Support (EoTS) milestone. BIG-IP ASM attack signature files are updated for major releases until the release reaches its EoSD milestone.

Each x.1.0 release marks the start of the Long-Term Stability Release. The initial release (x.1.0) contains new features, stability improvements, and new hardware support. Subsequent maintenance releases (x.1.1 to x.1.n) address product defects, security fixes, diagnostic and supportability improvements, minor functional improvements, and new hardware support. Software Development support activities will occur only on the latest maintenance release of each Long-Term Stability Release (x.1.latest) while the Long-Term Stability Release is within the Standard Support phase. The Standard Support phase for the Long-Term Stability Release begins with the first customer ship date of the x.1.0 release and extends for the following duration:

  • Five years - BIG-IP versions prior to 16.1.0
  • Four years - BIG-IP version 16.1.0 to 17.5.x
  • Three years - BIG-IP version 21.1.0 and subsequent x.1.0 releases

After the 17.1.x Long-Term Stability Release, F5 introduced the 17.5.x series, starting with 17.5.0. Like 17.1.x, it is a Long-Term Stability Release, but with a different standard support phase duration, as outlined in the following table.

BIG-IP ASM attack signature files are updated for maintenance releases until the associated Long-Term Stability Release reaches its EoSD milestone.

Note: For more information about Major, Feature, and Maintenance release numbering, refer to K8986: F5 product support policies.

At the end of a release’s Standard Support phase, the release enters its EoSD and EoTS milestone. Software versions that have reached their EoSD date are no longer supported with active software development. F5 will not provide software fixes (hotfixes) or consulting services for a version that has reached the EoSD milestone.

For software releases, unless specifically declared and announced by F5, the EoTS date marks the end of the software version’s support phase.
