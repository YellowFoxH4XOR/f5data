Description

Installing new version caused losing connection to GUI and CLI due to 

  • high memory usage
  • high load average
  • unexpected reboot due to above
Also you may have intermittent issue generating qkviews or UCS archive.
 

Environment

  • BIG-IP
  • v14 and later
  • Installing later version
     

Cause

Bug ID 829277


Recommended Actions

  1. check disk usage in /config directory with the below command:
    df -h /config/
    Filesystem                             Size  Used Avail Use% Mounted on
    /dev/mapper/vg--db--sda-set.1._config             3.2G  1.6G  1.5G  51% /config
     
  2. If the used is nearly or more than 1GB, check what is occupying the /config directory with below command:
    du -shc /config/*
    10K     config/aaa
    23K     config/api_settings
    8.0K    config/big3d
    107K    config/BigDB.dat
    245K    config/bigip
    15K     config/bigip_base.conf
    15K     config/bigip_base.conf.bak
    ...
    This will list file and folder size under /config directory, and check the largest folder in there. 
    If you can not find it ,then follow K14403: Maintaining disk space on the BIG-IP system and remove unnecessary files. 
     
  3. If it is not possible to find unnecessary files, take ucs backup and save it to remote location
    How to take ucs backup, please refer to: K13132: Backing up and restoring BIG-IP configuration files with a UCS archive
     
  4. disable db value liveinstall.moveconfig with the below command
    tmsh modify /sys db liveinstall.moveconfig value disable
    NOTE: for further information about this database key, please refer to K13438: Controlling configuration import when performing software installations
     
  5. Restore the config when it is booted from new boot location.
    How to restore ucs backup please refer to: K13132: Backing up and restoring BIG-IP configuration files with a UCS archive
 

Additional Information

if APM is provisioned, old EPSEC files would occupy /config/filestore/files_d/Common_d/epsec_package_d/, then delete those unused following K21175584: Removing unnecessary OPSWAT EPSEC packages from the BIG-IP APM system
