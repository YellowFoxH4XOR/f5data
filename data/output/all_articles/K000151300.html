Description

Config not loading post upgrade with the following error,

01070755:3: SIP monitor '/Common/Sip_monitor_01' has invalid parameter value 'options'

Environment

  • sip monitor configured with 'headers' field defined
  • Explicit Montor configured 

Cause

Change in behavior

Recommended Actions

The value in the headers field must end with a colon :


Example:-

Before:

ltm monitor sip /Common/Sip_monitor_01 {

cipherlist DEFAULT:+SHA:+3DES:+kEDH

compatibility enabled

debug no

defaults-from /Common/sip

destination *:*

filter 200

headers OPTIONS

interval 1

mode udp

time-until-up 0

timeout 4

}

 

After:

 

ltm monitor sip /Common/Sip_monitor_01 {

cipherlist DEFAULT:+SHA:+3DES:+kEDH

compatibility enabled

debug no

defaults-from /Common/sip

destination *:*

filter 200

headers OPTIONS:

interval 1

mode udp

time-until-up 0

timeout 4

}
