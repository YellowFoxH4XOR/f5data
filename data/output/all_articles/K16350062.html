Topic

You should consider using this procedure under the following condition:

  • You need to change the password for a SafeNet hardware security module (HSM) partition.

Description

To change the SafeNet HSM partition password, you must change the password on both the SafeNet HSM device and in the BIG-IP configuration.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Your BIG-IP system uses a SafeNet HSM device.
  • You have administrative access to the SafeNet HSM device.
  • You have administrative access to the TMOS shell (tmsh).

Procedures

Changing the SafeNet HSM partition password

To change the SafeNet HSM partition password, you must change the password on both the SafeNet HSM device and in the BIG-IP configuration. To do so, perform the following procedure:

Impact of procedure: This procedure requires you to stop the pkcs11d process. While the pkcs11d process is stopped, Secure Sockets Layer (SSL) connections cannot be established for any virtual server that is associated with an SSL profile that references a certificate/key pair stored on the HSM device. F5 recommends that you perform this procedure during a scheduled maintenance window.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Stop the pkcs11d process by typing the following command:

    stop /sys service pkcs11d

  3. Perform one of the following procedures, as appropriate, for your SafeNet Luna Network HSM version:
    • SafeNet Luna HSM 7.x:

      Note: Beginning in HSM 7.x, the Partition Security Office (SO) and Crypto Officer roles exist. Once it is created, a partition is handed over completely to its new owner (the Partition SO) and the HSM SO has no further contact with it or control over it, except to delete it from the HSM at some future time. A Partition SO creates to Crypto Office role. Client applications connect to a registered Partition (authenticating with the Crypto Officer Password) in order to generate and manipulate cryptographic objects in the Partition.

    1. Log in to the SafeNet HSM device as either the Partition SO or the Crypto Officer using the following command syntax:

      role login -name < po | co >

      For example, to log in as the Crypto Officer, enter the following command:

      role login -name co

    2. Change the password by using the following command syntax:

      role changepw -name < po | co >

      For example, to change the password for the Partition SO role, enter the following command:

      role changepw -name po

    3. To log out from the role, enter the following command:

      role logout

    • SafeNet Luna HSM 6.x:
    1. Log in to the SafeNet HSM device.
    2. Change the partition password on the SafeNet HSM device using the following command syntax:

      partition changePw -partition <name> [-cu] [-oldpw <old_password>] [-newpw <new_password>

  4. Log in to the tmsh utility by typing the following command:

    tmsh

  5. Enter the following command to list the HSM passwords configured in your BIG-IP system:

    Note: Beginning in BIG-IP 14.1.0, you can create vendor agnostic partitions for your HSM devices. As a result, you observe the nethsm-partition in your tmsh configuration and output.

    list sys crypto fips

    You may observe output similar to the following for BIG-IP 14.1.0 and later:

    sys crypto fips external-hsm {
        num-threads 24
        password $M$En$agCda7sXZJjxcGXRmSaRjw==
        vendor safenet
    }
    sys crypto fips nethsm-partition part1 {
        password $M$Av$8OhvI+r/jHtB+SpzIbnp2Q==
    }
    sys crypto fips nethsm-partition part2 {
        password $M$ms$4BpIMzVR9achyWe7GDWBng==
    }

  6. Perform one of the following procedures, as appropriate, for your BIG-IP version:

    Note: Perform the procedure on the BIG-IP system.

    • BIG-IP 14.1.0 and later:

      To change the specific SafeNet partition password, and use the following tmsh command syntax:

      modify sys crypto fips nethsm-partition <partition_name> password <new_password>

    • Prior to BIG-IP 14.1.0:

      To change the SafeNet HSM password, and use the following tmsh command syntax:

      modify sys crypto fips external-hsm vendor safenet password <new_password

  7. Save the BIG-IP configuration by typing the following command:

    save sys config

  8. Start the pkcs11d process by typing the following command:

    start /sys service pkcs11d
