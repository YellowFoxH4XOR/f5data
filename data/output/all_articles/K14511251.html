Description

  • You want to give permissions to users so that they can only edit FPS Alerts under Monitoring tab on the BIG-IQ
  • On the BIG-IQ, there are four IAMs specific to FPS
  • The roles are App Security / fraud protection on the bigiq
    •  Deployer
    •  Editor
    •  Manager
    •  Viewer

Environment

  • BIG-IQ
  • FPS
  • Alert Dashboard 

Cause

  • Currently, there are no specific role that allows the manipulation or modification of FPS alerts on the BIG-IQ
