Known Issue

Processing an ICMPv6 error message packet may cause the Traffic Management Microkernel (TMM) to restart and produce a core file.

This issue occurs when all of the following conditions are met:
  • The system is licensed and provisioned with the BIG-IP AFM module.
  • The BIG-IP system is running any of the following versions or hotfix level builds:

    • BIG-IP 11.6.0 HF5
    • BIG-IP 11.5.3 HF1
    • BIG-IP 11.5.3
  • The incoming ICMPv6 error message packet is forwarded after being processed by the Access Control List classification.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from TMM restarting, and failover may occur if the system is configured as part of a high availability (HA) group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The affected ICMPv6 packet is not initialized properly by the BIG-IP AFM system, and TMM may restart and produce a SIGSEGV core file.
  • The BIG-IP system generates the TMM core file to the /shared/core directory, with a time stamp that correlates to the traffic interruption.
  • The BIG-IP system unexpectedly fails over to another system in the device group.
