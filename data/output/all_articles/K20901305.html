Description

Deploying RDS Web Gateway using F5 iApp but SSO fails

  • Default SSO Configuration fails to log user into Remote Resource

Environment

  • Big-IP APM
  • SSO
  • f5.microsoft_rds_remote_access.v1.0.4 iApp

Cause

Default Domain variable, session.logon.last.domain, does not contain the correct domain information.

Recommended Actions

To modify the domain session variable, follow the steps below:

  1. From the Configuration Utility, navigate to: Access >> Connectivity / VPN >> VDI / RDP >> <Resource Name>
  2. Next to 'Enable SSO' check the enable box if it is not already
  3. In the 'Domain Source' set the value to 'session.ad.last.actualdomain'
