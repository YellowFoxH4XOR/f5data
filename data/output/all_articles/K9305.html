Known Issue

This is the result of a known issue. You cannot upload the Citrix XenApp version 11 client to FirePass.

The Citrix XenApp version 11 client comes in an MSI package format. However, FirePass only accepts a CAB package format, which is a security measure to ensure that only the appropriate file type is uploaded. If you attempt to upload the Citrix XenApp version 11 client to the FirePass, you will receive the following error message:

Can't install CAB file

F5 Networks Product Development tracked this issue as CR108839 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in cumulative hotfix HF-603-5 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by configuring the Custom URL option to point to a URL of the CAB package that you own. The Custom URL option is located under Application Access: Terminal Servers: Global Settings. If you have Citrix Web Interface installed on one of your servers, you can use the location of the Citrix client on the Web Interface as the URL. The client path is located under the C:\Program Files\Citrix\Web Interface directory on the server with Web Interface installed.

For example, the Web Interface 4.5 URL appears as follows if Web Interface 4.5 is running on a server located at 10.10.10.1:

http://10.10.10.1/Citrix/AccessPlatform/Clients_common/ica32/icaweb.cab

Note: This workaround only applies if you have a server running Citrix Web Interface as a separate product provided by Citrix.
