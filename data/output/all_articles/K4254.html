Known Issue

This is the result of a known issue. BIG-IP reports that the network interface on an IBM HS20 blade server is actually the hardware interface that connects the blade to the blade server switch module. BIG-IP will always report the media type as 1000BaseSX (a fiber interface), although the blade server may actually be equipped with a copper interface. To avoid any problems due to the mismatch in media types, always set the media type to auto.

F5 Networks Product Development tracked this issue as CR45018.
