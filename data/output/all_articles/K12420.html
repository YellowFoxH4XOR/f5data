Known Issue

This is the result of a known issue. When the BIG-IP system is configured to send logs to the remote syslog server, the checkcert utility sends debug log messages similar to the following example:

f5km_initialize_context(fs <no user> <no partition> /config/ssl 1): 0x09da7320
f5km_list_next DONE
f5km_shutdown(0x09da7320, 0): /config/ssl/

These debug log messages are benign and do not affect the operational status of the BIG-IP system.

F5 Product Development tracked this issue as ID 243494 (formerly CR136913), and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Note: For more information about the checkcert utility and its usage, refer to K7574: Monitoring SSL certificate expiration on the BIG-IP system (9.x - 10.x).
