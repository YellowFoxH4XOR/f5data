K000148576: Unable to create device trust, error message "This device is not found" is seen

Type
Support Solution
Published
2024-11-19
Updated
2024-12-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148576

Description

When attempting to create device trust (Device Trust >> Device Trust Members >> Add), in preparation for establishing a CMI config sync group, the error message "This device is not found" is seen after entering the IP address and credentials for the remote device and clicking on "Retrieve Device Information".

 

Environment

  • Initial creation of a device trust group
  • BIG-IP

Cause

The observed error message is the result of a generic failure condition while making an HTTPS request to the remote device, and indicates that the https request failed in some manner. In nearly all cases investigated by F5 support staff, the underlying cause was a network connectivity issue between the two BIG-IP devices, and often an MTU limitation, where large packets were being dropped mid-path.

 

Recommended Actions

Verify network connectivity between the two devices is good, particularly for full-length packets, for example by using the command "ping x.x.x.x -M do -s 1472" to produce a 1500 byte ICMP echo request.
