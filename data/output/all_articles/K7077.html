K7077: Error Message: The number of concurrent sessions exceeds the limit for this group

Issue

When the concurrent session limit for a master group has been reached, users in that master group are unable to logon, and receive an error message that appears similar to the following example:

The number of concurrent sessions exceeds the limit for this group!

No additional logons to that master group will be permitted until a current user in that master group logs off.

Additionally, the Reports: System Logs page displays a message that appears similar to the following example, where <GroupName> is the name of the master group and <#> is the concurrent session limit configured for that master group:

The number of concurrent sessions exceeds the limit of <#> for group '<GroupName>'.

Note: The log level must be set to the Error severity or to a lower severity in order for this message to be logged. If you set the log level to a higher severity (such as Critical), the message will not be logged. FirePass logs are configured on the Device Management : Maintenance : Logs page.

For local logging, set the Maintenance log to Error or to a lower severity in the Logging Options section. For remote logging, set the Log level option to Error or to a lower severity in the System Logs section.

The concurrent session limits for the FirePass master groups can be seen on the Users: Groups: Master Groups page, under the Max concurrent sessions column. Clicking on the number of sessions in the row of the master group will open the General tab, under which you can set the Limit the number of concurrent sessions for this group check box and the maximum number of sessions for the master group.
