Description

You would like to know if it's possible to secure ICAP traffic from your BIG-IP to the ICAP server, with SSL/TLS.

Environment

  • ICAP
  • Request/Response Adapt profile, or BIG-IP Advanced WAF/ASM antivirus protection feature

Cause

None

Recommended Actions

It is not possible for BIG-IP Advanced WAF/ASM because the BIG-IP Advanced WAF/ASM implementation of antivirus protection does not support securing the ICAP traffic with SSL/TLS. For information about BIG-IP Advanced WAF/ASM antivirus protection feature, refer to K70941653: Configuring BIG-IP ASM antivirus protection.

It is possible for BIG-IP LTM to secure ICAP traffic with SSL/TLS if you use the Request/Response Adapt profiles and apply a ServerSSL profile to the internal virtual server. Additionally, the ICAP server itself must be able to terminate and decrypt SSL/TLS traffic. For more information, refer to the Configuring Content Adaptation for HTTP Requests and Responses chapter of the BIG-IP Local Traffic Manager: Implementations guide.

Note: Standalone ASM and AWAF licenses do not support use of the Request/Response Adapt profiles.
