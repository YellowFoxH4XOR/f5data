Known Issue

This is the result of a known issue. If a FastL4 profile has PVA acceleration enabled, the bigpipe and bigtop commands display the wrong idle timeout for virtual servers using that profile. The BIG-IP system reports the idle timeout value as eight times the idle timeout value you configured in the FastL4 profile. For example, if you configured the value 30 for the idle timeout, BIG-IP reports the idle timeout as 240.

This is a cosmetic issue only; the BIG-IP system uses the correct idle timeout value.

Note: This issue only occurs if the Reset on timeout setting is disabled in the FastL4 profile.

F5 Networks Product Development tracked this issue as CR44261 and it was fixed in BIG-IP version 9.4. For information about upgrading, refer to the BIG-IP LTM, ASM, or Link Controller Release Notes.
