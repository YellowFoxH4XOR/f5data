Description
Command line utility Secure Copy Protocol (SCP) connectivity to BIG-IP results in one or more of the following errors:

  • relative addresses not allowed
  • path not allowed

Environment

  • SCP
  • CLI

Cause
SCP write access is limited only to folders listed in /config/ssh/scp.whitelist (security enhancement).

/config
/var/core
/var/log
/shared/images
/var/tmp
/var/local/ucs
/var/local/wam
/var/local/scf
/var/ilx/workspaces
/etc/alertd

Refer to the 'Fixes introduced in' column under K82814400.

Recommended Actions

When using SCP to copy files to BIG-IP, you must specify an allowed target directory in the URL path, like so:

$ scp <filename1> <user>@x.x.x.x:/var/tmp/
