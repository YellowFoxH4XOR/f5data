Description
High-Speed Bridge internal interface(s) is reporting interface flapping in logs.  The High-Speed Bridge (HSB) is the interface used on certain BIG-IP platforms to connect the switch fabric to the host subsystem. On those platforms that employ this technology, one or more HSBs may be present.

The following log messages will be seen in /var/log/ltm:

    Apr 27 11:01:51 slot7/example info bcm56xxd[13585]: 012c0015:6: Link: 7/9.2 is DOWN
    Apr 27 11:01:51 slot7/example info bcm56xxd[13585]: 012c0012:6: HSB 37 HGM 1 LBB address 0x90000008 XLMACs status updated to 0x80000001

    Apr 27 11:01:55 slot7/example info bcm56xxd[13585]: 012c0015:6: Link: 7/9.2 is UP
    Apr 27 11:01:55 slot7/example info bcm56xxd[13585]: 012c0012:6: HSB 37 HGM 1 LBB address 0x90000008 XLMACs status updated to 0x80000003

Errors on the HSB interface that is flapping will also be seen in the show net interface command:

    show /net interface all-properties -hidden
    Name    Interface Status    Mac-Addr            Errs In   Errs Out
    7/9.1    up                 0:a:49:a5:25:aa     36        0        
    7/9.2    down               0:a:49:a5:25:ab     2.4M      0        <<<<<<

Environment

  • BIG-IP
  • Platform that utilizes HSB interfaces, such as Viprion or iSeries

Cause
The HSB interface flapping is related to interface errors.

Recommended Actions
Viprion
Rebooting the blade that is experiencing the errors should clear the errors and return the blade to normal functionality.

To reset a single blade in a VIPRION system, perform the following procedure:
  1. Log in to the command line of the VIPRION blade.
  2. To verify the slot number of the blade to which you are connected, type the following command:
bladectl -g slot
  1. To reset the blade, use the following command syntax:
bladectl -b <blade#> -r

For example, if you are logged in to blade1 and want to reset blade7, type the following command:

bladectl -b 7 -r
 
iSeries
Reboot the system to clear the errors and restore functionality
  1. Log in to the command line of the BIG-IP
  2. Reboot the system
    reboot
