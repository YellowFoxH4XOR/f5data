Description

When creating a CSR via the configuration utility and asuming the Subject Alternative Name (SAN) field contains information in the correct format, the system displays the error Invalid Subject Alternative Name. This happens when there is more than one email address in the E-mail Address field.

Environment

  • Creating a CSR
  • More than one address in the E-mail Address field

Cause

A semicolon or space is required between addresses in the E-mail Address field.

Recommended Actions

You can either separate each email address with a semicolon or a space. For example,

john.doe@example.local; jane.doe@example.local

Additional Information

If you continue to observe the error Invalid Subject Alternative Name even after ensuring the E-mail Address field is in the right format, you may want to refer to K13471: Creating SSL SAN certificates and CSRs using the Configuration utility or tmsh for the correct format for the Subject Alternative Name (SAN) field.
