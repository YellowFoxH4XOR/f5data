Known Issue

This is the result of a known issue. If multiple cluster nodes use the same fully qualified domain name (FQDN), synchronizing to those devices may fail. The primary server in the cluster uses the FQDN of its secondary nodes in the file name that it generates for tracking synchronizations. If multiple servers use the same FQDN, the primary server is unable to track which servers have been updated.

F5 Product Development is tracking this issue as ID 294371 (formerly CR137524).

This issue was fixed in cumulative hotfix HF-610-3-1 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
