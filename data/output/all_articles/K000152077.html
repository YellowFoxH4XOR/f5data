Description

  • I'm seeing packet loss, what do I do?
    • ICMP requests are dropped/lost
    • TCP requests are failing 

Environment

  • Distributed Cloud WAF
  • Distributed Cloud Routed DDoS
  • Load Balancers
  • GRE Tunnels

Answer

Open a ticket with the SOC.

  • How are you measuring the data loss 
    • ICMP?
      • ICMP traffic can be de-prioritized in our carrier network and Distributed Cloud ingress network. Thus, it's possible during heavy load ICMP traffic can be dropped. 

Include at least the following information in your ticket:

  • Source IP (Single or multiple regions)
  • Destination IP
  • TRACEROUTE from Source to Destination
    • Linux Example  
      • traceroute -n 12.3.1.10
        ...
         9 108.170.233.152 (108.170.233.152) 19.919 ms
        10 108.170.233.157 (108.170.233.157) 33.956 ms 13.041 ms
        11 216.239.46.114 (12.3.1.1) 34.857 ms
        ...
    • Windows Example 
      • tracert 11.1.0.1
