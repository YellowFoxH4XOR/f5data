To set up host-based access control to the Configuration utility:

  1. Open the server configuration file.

    Depending on the version you are using, this file is /var/f5/httpd/conf/httpd.conf or /config/bigconfig/httpd.conf.

  2. Find the following section of the httpd.conf file:

    <Directory /var/f5/www>

    Within this section, find the following entry:

    # Controls who can get stuff from this server.

    order allow,deny
    allow from all

  3. Change the order directive to the following:

    order deny,allow

    This command establishes the order in which the BIG-IP Controller evaluates two access directives: deny and allow.

  4. After the order directive, insert the deny directive, as in the following example:

    deny from all

    This directive denies access to all hosts.

  5. Modify the allow directive as follows:

    allow from 207.17.117
    allow from 192.168

    This directive allows requests from any host within the 207.17.117 and 192.168 subnets.

    If you prefer, you can also specify domain names. For example:

    allow from yourhost.com

    This directive allows requests from any host within the yourhost.com domain, such as host1.yourhost.com and host2.yourhost.com. Note that you would have to perform name resolution configuration.

  6. Save the modified configuration file.
  7. Restart the the web server by typing the following command:

    Note: For international BIG-IP Controllers, you must exclude the letters ssl from this command.

    /usr/local/bin/apachectl stop && /usr/local/bin/apachectl startssl
