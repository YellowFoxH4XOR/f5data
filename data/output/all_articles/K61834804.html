Known Issue

The BIG-IP ASM system may fail to load a security policy with a large number of user-defined attack signatures.

This issue occurs when the following condition is met:

  • The security policy contains hundreds of attack signatures, many of which are user-defined signatures.

Impact

The BIG-IP ASM configuration fails to load and you are unable to apply policy changes.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM security policy fails to load.
  • After you apply the security policy, the top command indicates that the asm_config_server_rpc_handler.pl process is using a large amount of memory, as shown in the following example:

    PID USER PR NI VIRT RES SHR S %CPU %MEM TIME+ COMMAND
    28061 root 20 0 2203m 2.1g 1204 D 3.6 26.6 0:39.72 asm_config_server_rpc_handler.pl

  • The asm_config_server_rpc_handler.pl process is terminated with a SIGSEGV signal, and produces a core file.

Workaround

To work around this issue, you can use fewer attack signatures in the policy or remove unused attack signatures.
