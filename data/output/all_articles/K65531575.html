Known Issue

Learning suggestions for wildcard URLs may not match manually configured wildcard URLs.

This issue occurs when all of the following conditions are met:

  • Your security policy is configured with URL learning mode set to ALWAYS.
  • The Policy Builder feature is enabled.
  • You accept the policy builder Traffic Learning suggestion to add the following wildcard URLs to the Allowed URLs List:

    "*.[Pp][Nn][Gg]"
    "*.[Jj][Pp][Gg]"
    "*.[Gg][Ii][Ff]"

  • You add a wildcard URL to the Allowed URLs List.

    For example:

    /images/*

  • The security policy processes traffic that matches the wildcard URL you created and the accepted Traffic Learning suggestion.

    For example:

    /images/picture.png

  • You attempt to view the Traffic Learning suggestions for /images/*.

Impact

Traffic Learning suggestions are not mapped to the wildcard URL that you manually added.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Traffic Learning suggestions for the wildcard URL that you manually added are mapped to a less specific wildcard URL.

    For example:

    URL: /images/picture.png
    Expected mapping: [HTTP]/images/*
    Actual mapping: [HTTP]*.[Pp][Nn][Gg]

Workaround

To work around this issue, you can modify the wildcard URL match order. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Policy Building > Learning and Blocking Settings > URLs.
  3. Locate the section File types for which wildcard HTTP URLs will be configured (e.g., *.jpg).
  4. Select the wildcard URL file type to which the system is mapping learning suggestions.
  5. Click Delete.
  6. Click Save.
  7. Navigate to Security > Application Security > URLs > Wildcards Order > HTTP URLs.
  8. Select the specific wildcard URL you added to the security policy.
  9. Using the Up button, ensure that your wildcard URL precedes similar but less specific wildcard URLs.

    For example, the following is a Wildcard URLs List:

    [HTTP]/images/*
    [HTTP]*.[Pp][Nn][Gg]
    [HTTP]*.[Jj][Pp][Gg]
    [HTTP]*.[Gg][Ii][Ff]

  10. Click Apply Policy.
