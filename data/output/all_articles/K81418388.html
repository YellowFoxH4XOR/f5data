As seen above, /var/log/restjavad.0.log will show java.lang.OutOfMemoryError message.

BIG-IQ is used to automate the UCS backup for the BIG-IP.

Environment

  • BIG-IP UCS backup error
  • BIG-IQ is used to initiate BIG-IP UCS backup
  • IndexWriter error message seen in BIG-IP /var/log/ltm
  • java.lang.OutOfMemoryError seen in /var/log/restjavad.0.log

Cause

Limited allocated java memory for BIG-IP is causing the issue.

Recommended Actions

Resolution is to be done on the BIG-IP. For short term resolution, restart the restjavad process and for long term resolution, increase java memory allocation.

Restart restjavad

  1. Login to BIG-IP Command Line.
  2. Restart restjavad with command:
    bigstart restart restjavad
Increase java memory allocation
  1. Login to the BIG-IP Command Line.
  2. Follow article K9719 to increase java memory allocation.
  3. The command to increase the java memory allocation is:
    tmsh modify /sys db provision.tomcat.extramb value <value>

    Start with allocating 100mb additional memory by running the command:
    tmsh modify /sys db provision.tomcat.extramb value 100
     
  4. If that does not resolve the issue, increase the value incrementally.
