Known Issue

A local traffic policy using a default rule may not work as expected.

This issue occurs when the following condition is met:

  • The configuration contains a virtual server with a local traffic policy that consists of either one of the following:
    • The local traffic policy consists of only a default rule.
    • The local traffic policy consists of a default rule comprised of both request and response actions.

Impact

The actions on the default rule are not working as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • If a default rule is the only rule in a policy, the actions may be executed more than once. In some cases this is harmless, in other cases, such as http-reply, the second execution may fail with an error message.
  • If a default rule has both request and response actions, only the response actions are executed.

Workaround

For a policy with only a default rule, you can work around this issue by adding the following condition:

http-uri starts-with values { / }

This condition will always match, and it will keep the rule as the default rule.

For a policy that has default rule with actions in both request and response, you can work around this issue by splitting the rule into two default rules in which one will contain the request action and the other contains the response action.
