Note: ARX VE 5.3.1 was not a Trial Ware release and follows the same software support policy as other ARX 5.x versions. For information about the End of Software Development (EoSD) for ARX 5.x, refer to K12918: End of Software Development for ARX 5.x.

F5 is announcing that the End of Software Development (EoSD) for ARX VE (Virtual Edition) Trial Ware 5.3.0 is effective June 28, 2011.

As of June 28, 2011, F5 no longer provides security updates, software fixes (hotfixes), or consulting services for ARX VE Trial Ware 5.3.0.

During the Extended Support phase, F5 only offers configuration support. Defect correction is not provided. All configuration support for ARX VE Trial Ware 5.3.0 is considered reasonable effort.  'Reasonable effort' is defined to include technical phone support and hardware support, and is limited to system configuration support. No response time targets, guarantees, or SLAs shall apply. No escalations to Engineering Services or Product Development shall be allowed.

The effective End of Technical Support (EoTS) date is June 28, 2012 for the ARX VE Trial Ware 5.3.0 software, completing its End of Life (EoL) cycle.

Customers should view the corresponding software release notes to determine if a particular software release is suitable for their platform or software version. Access to, and compatibility of, these software updates are not guaranteed and will be made under F5 reasonable effort support guidelines.

Additionally, if a platform is not compatible with the latest General Sustaining (GS) software release, the platform may be restricted from operating that version through the F5 software licensing process.
