Description
You observing that Virtual Server IP is responding to telnet even though the Virtual Server IP has been disabled from Virtual Address list

GUI > Local Traffic > Virtual Servers > Virtual Address List > check Virtual Address > click Disable

Environment

  • LTM
  • Virtual Server
  • Virtual Address

Cause
This issue affecting v13.1.4.1 and onward for v13 software branch.

Recommended Actions

Consider to software upgrade to non-v13 software branch.
Otherwise, you could consider to disable the Virtual Server instead of Virtual Address from GUI.

GUI > Local Traffic > Virtual Servers > Virtual Server List > check appropriate Virtual Server > click Disable

None
