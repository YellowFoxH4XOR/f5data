Description

AFM NAT incorrectly matching policy rule of non-matching route domain.

For example, the following packet:

+----------------+
|SRC:10.10.10.1%9|
|DST:10.10.50.5%9|
+----------------+

Incorrectly matches the following NAT policy rule:

snat_main {
    destination {
        addresses {
            0.0.0.0%2/0 { }
        }
        proxy-arp enabled
    }
    ip-protocol any
    source {
        addresses {
            0.0.0.0%2/0 { }
        }
    }
    translation {
        source /Common/snat_source
    }
}

Note: As the rule applies to route domain 2, it should not match connections originating from route domain 9.

Environment

  • AFM NAT
  • Route Domains
  • Single NAT Policy with rules configured for multiple route domains

Cause

Bug ID 1021737

Recommended Actions

Configure separate NAT policies per route domain to avoid this issue.
