Known Issue

This is the result of a known issue. Running the qkview script on a redundant pair system with Detect ConfigSync Status enabled incorrectly causes the Configsync.LocalConfigTime db key to be updated. As a result, the system detects a timestamp change and incorrectly reports that the system should be synchronized.

Note: This message is reported in the upper-left corner in the Configuration utility on both systems in the redundant pair as Sync Recommended.

F5 Product Development tracked this issue as CR82268 and it was fixed in BIG-IP version 9.3.1. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, Link Controller, or WebAccelerator release notes.

Note: This issue is cosmetic and does not affect system performance or usability.

Workaround

You can work around this issue by clearing the Sync Recommended status and synchronizing the systems from the active unit. This action will clear the message and allow you to monitor the synchronization status.
