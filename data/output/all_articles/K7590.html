Known Issue

This is the result of a known issue. If you enter incorrect login credentials when you are accessing a Portal Access Windows File Favorite, FirePass does not display an error message. Instead, FirePass continues to prompt for a username and password until the user enters valid login credentials.

F5 Product Development tracked this issue as CR77100 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Additionally, hotfixes have been issued for certain versions of the FirePass software. For FirePass version 6.0.0, the issue was fixed in cumulative hotfix 600-13. For FirePass version 6.0.1, the issue was fixed in cumulative hotfix 601-2. You may download this hotfix or a later version of the cumulative hotfix from the F5 Downloads site.

For instructions about how to obtain a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
