K4557: BIG-IP and 3-DNS now allow the question mark (?) in a trap string

Published
2006-02-17

Status

Applies to

  • BIG-IP 4.X: 4.6.4
Source
https://my.f5.com/manage/s/article/K4557

Topic

Starting in version 4.6.3, the checktrap.pl script allows you to use the question mark (?) in trap strings.

Prior to version 4.6.3, you could not use a question mark in a trap string and BIG-IP would send a trap alerting the administrator that they used an invalid character.
