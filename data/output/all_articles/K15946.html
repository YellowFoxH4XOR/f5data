Known Issue

Forwarding virtual servers, with mirroring enabled, may cause a standby Traffic Management Microkernel (TMM) to produce a core file.

This issue occurs when all of the following conditions are met:

  • You have BIG-IP 11.2.1 HF10 installed.
  • You have a forwarding virtual server configured.
  • You have connection mirroring enabled.

Impact

The standby BIG-IP system temporarily fails to mirror traffic, and is unavailable for failover.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The standby BIG-IP system temporarily becomes unavailable and fails to mirror traffic.
  • TMM generates a core file in the /var/core directory.

Workaround

To work around this issue, you can temporarily disable connection mirroring on forwarding virtual servers.

Impact of workaround: In the event of a failover to the standby system, existing connections will be reset.
