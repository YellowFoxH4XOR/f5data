K000150734: Beyond Trust Application issue with F5

Type
Support Solution
Published
2025-04-05
Updated
2025-11-05
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150734

Description

Beyond Trust no longer working with BIG-IP after upgrading to the latest version.

Environment

Virtual Server with SSL profiles configured for Beyond Trust.

Cause

Beyond Trust made a change to the SSL requirements which caused the client SSL profile that worked on previous versions to now be rejected by the client after the handshake completes (SSL handshake completes and client immediately sends a RST to the BIG-IP).

Recommended Actions

Remove the SSL profiles from the virtual server to allow the Beyond Trust appliance to handle the encryption. When SSL profiles are removed the BIG-IP is not decrypting traffic and therefore you cannot use any layer 7 functionality such as security policies, iRules, or cookie insertion.

Additional Information

None.
