Description

Starting from version 14.0.0, you can now manage Elliptic Curve Digital Signature Algorithm (ECDSA) keys on F5 platforms containing a CAVIUM NITROX III hardware security module (HSM).

Environment

  •  ECDSA key management on hardware

Cause

Following F5 platforms containing a CAVIUM NITROX III hardware security module (HSM), you can now manage Elliptic Curve Digital Signature Algorithm (ECDSA) keys. Note that the supported key exchange method for ECDSA keys on these platforms is Elliptic Curve Diffie-Hellman Ephemeral (ECDHE).
