K3431: Client performance may decrease after upgrading to Microsoft Windows XP SP2

Applies to

Topic

This performance degradation is most likely the result of the new Microsoft Internet Explorer pop-up blocker that is provided in Windows XP SP2.

The pop-up blocker prevents the FirePass cache cleanup process from running. When blocked, FirePass attempts to correct the problem by disabling gzip compression. This will adversely affect performance.

You can resolve issue by configuring the Internet Explorer pop-up blocker to ignore pages from FirePass. To do this, perform the following steps:

  1. From the Microsoft Internet Explorer menu, click Tools.
  2. Click Pop-up Blocker.
  3. Click Configure Pop-up Blocker.
  4. Type the name of your FirePass system (for example: firepass.askf5.com).
