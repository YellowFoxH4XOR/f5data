Known Issue

The BIG-IP APM console displays a coapi error message when you view access session information.

This issue occurs when the following condition is met:

  • Using the Configuration utility, you view details about an active access session. For example, you view the details in the Access Policy > Manage Sessions Configuration utility path and click a Session ID.

Impact

The BIG-IP APM console displays a coapi error message. This issue is cosmetic and does not impact the functionality of the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you view access session information with the Configuration utility, the device console displays an error message that appears similar to the following example:

    err coapi: [error] [client <client ip address>] PHP Warning:  date(): It is not safe to rely on the system's timezone settings. You are *required* to use the date.timezone setting or the date_default_timezone_set() function. In case you used any of those methods and you are still getting this warning, you most likely misspelled the timezone identifier. We selected the timezone 'UTC' for now, but please set date.timezone to select your timezone. in /var/sam/www/admin/reports/index.php on line 8, referer: https://<big-ip apm ip address>/tmui/Control/jspmap/tmui/overview/reports/current_sessions.jsp
