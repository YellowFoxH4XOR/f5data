Known Issue

The Configuration utility shows an incorrect number of pool members in a high availability (HA) group after the pool configuration is synchronized from a peer unit.

This issue occurs when all of the following conditions are met:

  • You have automatic and incremental synchronization configured on a sync-failover device group.
  • Your BIG-IP system has been synchronized from a peer unit.
  • Using the Configuration utility of the synchronized system, you navigate to System > High Availability  > HA Group to view the number of pool members.

Impact

There is no impact; you can safely ignore this issue.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Configuration utility shows an incorrect number of pool members in an HA group.

Workaround

To work around this issue, you can reload the saved configuration. To do so, perform the following procedure:

Impact of workaround: The following procedure loads the saved configuration, so any in-memory changes that have not been saved to disk will be lost. If the affected device is a sync target, and no other changes have been made, it should be safe to run this command.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Type the following command:

    load sys config
