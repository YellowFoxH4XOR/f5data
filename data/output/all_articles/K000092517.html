Description

You can use your existing OpenAPI (Swagger) specification file to quickly create an Application Security Manager security policy from the BIG-IP GUI. This article discusses the steps to automate the creation of OpenAPI security policy using REST API.

If you have already created a policy and need to update it with a newer OpenAPI (Swagger) specification file, refer to K000140233: Update an existing API security policy with a newer swagger file

Environment

  • OpenAPI (Swagger) specification file.
  • REST API.
  • Application Security Manager.

Cause

Like to automate the process of creating an OpenAPI security policy using REST API.

Recommended Actions

Upload the OpenAPI (Swagger) specification file

Create an OpenAPI security policy

Upload the OpenAPI (Swagger) specification file

The data serialization language type of the OpenAPI (Swagger) can be either JSON or YAML, the file can be uploaded into the BIG-IP using this REST API command:

curl -sk -u <admin>:<password> -X POST "https://x.x.x.x/mgmt/tm/asm/file-transfer/uploads/<OpenAPI specification file>" --header 'Content-Type: application/octet-stream' --header 'Expect: ' --header 'Content-Range: <range-start>-<range-end>/<size>' --data-binary "@<OpenAPI specification file>"

Note: Update the above command by replacing <admin>:<password> with the correct user credentials, x.x.x.x with the IP/Hostname of the BIG-IP, and Content-Range header value with correct ranges.

Sample output:

{
  "remainingByteCount": 0,
  "usedChunks": {
    "0": <size>
  },
  "totalByteCount": <size>,
  "localFilePath": "/ts/var/rest/admin\~<OpenAPI specification file>",
  "temporaryFilePath": "/ts/var/rest/tmp/admin\~<OpenAPI specification file>",
  "generation": 0,
  "lastUpdateMicros": 1666998530765736
}

Create an OpenAPI security policy

Once the OpenAPI (Swagger) specification file is uploaded into the BIG-IP, you can use it to create an OpenAPI security policy using this REST API command:

curl -sk -u <admin>:<password> -X POST "https://x.x.x.x/mgmt/tm/asm/tasks/import-open-api" --header 'Content-Type: application/json' --data-raw '{"policyName":"<Policy Name>","filename": "<OpenAPI specification file>"}'

Note: Update the above command by replacing <admin>:<password> with the correct user credentials, x.x.x.x with the IP/Hostname of the BIG-IP, and other needed fields.

Sample output:

Additional Information

Starting in v16, the BIG-IP can import a policy directly from a remote repository.
