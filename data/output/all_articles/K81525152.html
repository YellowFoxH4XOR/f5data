K81525152: Unable to login to the active BIG-IQ ''Waiting for BIG-IQ services to become available...''

Type
Support Solution
Published
2021-10-22
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X
Source
https://my.f5.com/manage/s/article/K81525152

Description

User unable to logon to the active BIG-IQ with the following observations/symptoms:

  • No login screen is presented
  • The GUI is displaying "Waiting for BIG-IQ services to become available..."
  • The Postgres log file /var/log/postgres/postgresql-2021-08-24.log contain a FATAL message similar to the following :

    2021-08-24 11:16:51.421 BST [11285] FATAL: the database system is shutting down

Environment

  • BIG-IQ CM with an HA peer

Cause

This GUI inaccessibility can be caused by the database replication between the HA peers failing to complete

Recommended Actions

  1. Break HA between the devices:
    Note: run the command below on both BIG-IQ CMs

      ha_reset -f <local discovery addr>

  2. Add the Standby device back to the preferred Active device

Additional Information

If Automatic failover is configured and the former Standby is now Active, and the former Active BIG-IQ has the GUI showing "Waiting for BIG-IQ services to become available...", it is likely the result of an automatic failover that occurred. When an automatic failover event occurs, restjavad is stopped on the former Active CM to prevent it from interacting with devices until HA can be reestablished. To reestablish HA see section Reestablishing a BIG-IQ auto failover HA configuration after failover of the following manual page:

  • Troubleshooting BIG-IQ High Availability Auto Failover Issues
