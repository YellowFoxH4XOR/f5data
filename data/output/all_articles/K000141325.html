K000141325: Unable to set the flow type to Implicit Flow with APM as Client in OAuth

Type
Support Solution
Published
2024-10-03
Updated
2024-10-03
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000141325

Description

"The OpenID Connect Flow Type" menu in APM only lists the Authorization Code and Hybrid flow types, and Implicit cannot be chosen.


Environment

Implicit flow

Cause

This is a limitation.

Recommended Actions

While APM, when acting as an Identity Provider (IdP), does support the Implicit Flow, this support does not extend to scenarios where APM acts as the client. In such cases, the Implicit Flow option is not available in the "OpenID Connect Flow Type" menu, limiting the configuration to either the Authorization Code or Hybrid flows.
