Issue

Error Message

Error binding socket; addr='AF_UNIX(/dev/log)', error='Address already in use (98)

For example:

Error binding socket; addr='AF_UNIX(/dev/log)', error='Address already in use (98)'
Error initializing source driver; source='local'
Starting syslog-ng: [FAILED]

Message Location

You may encounter this message in the following locations:

  • /var/log/confpp.log file
  • /var/log/webui.log file
  • TMOS Shell (tmsh) 
  • Configuration utility
Description

This message may occur when the syslog-ng utility is unable to open a socket to the /dev/log file for unknown reasons, and you attempt to perform one of the following actions:

  • You attempt to add a syslog server.
  • You attempt to restart the syslog-ng utility.
  • You attempt to perform a configuration synchronization (ConfigSync) on the configuration to the high availability (HA) peer in an HA configuration.

Impact

You are unable to start the syslog-ng utility or make modifications to the syslog-ng configuration through the Configuration utility or the tmsh commands.

Recommended Actions

To recover from this issue, you can remove the /dev/log file. To do so, perform the following procedure:

Impact of workaround: The system automatically recreates the /dev/log file after you complete the procedure and restart the syslog-ng process.

  1. Log in to the command line of the affected BIG-IP device.
  2. Stop the syslog-ng utility by typing the following command:

    bigstart stop syslog-ng

  3. Remove the /dev/log file by typing the following command:

    rm /dev/log

  4. Start the syslog-ng utility by typing the following command:

    bigstart start syslog-ng
