Description

Disk usage showing that /var directory is getting full after upgrade.

/dev/mapper/vg--db--vda-set.1._var                3.0G  3.0G     0 100% /var

Environment

  • BIG-IP
  • After upgrade

Cause

Bug ID 802421: The /var partition may become 100% full requiring manual intervention to clear space

Recommended Actions

Run the following commands, in sequence: 

bigstart stop restjavad 
rm -rf /var/config/rest/storage*.zip 
rm -rf /var/config/rest/*.tmp 
bigstart start restjavad

None
