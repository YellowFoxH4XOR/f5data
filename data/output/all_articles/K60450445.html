Topic

You should consider using this procedure under the following condition:

  • You want to modify the maximum allowed URL length for an HTTP request.

Description

The BIG-IP ASM system checks the URL length of HTTP requests as part of HTTP protocol compliant enforcement. The system uses the ecard_max_http_req_uri_len system variable to define the maximum URL length that the system can support in its internal buffers. The default value of ecard_max_http_req_uri_len is 2048 bytes.

If a client request is sent with a URL length greater than the value configured in the ecard_max_http_req_uri_len system variable, the BIG-IP ASM system issues an HTTP protocol compliance failed violation in the event logs with a detail report that appears similar to the following table.

NameDescription
Violation NameHTTP protocol compliance failed
HTTP ValidationUnparsable request content
DetailsURL length: 2096 exceeded maximum limit of: 2048

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP ASM Configuration utility.

Procedures

Configuring the maximum allowed limit of URL length for an HTTP request

To watch a video demo of this procedure, go to  K000159711: Configure the maximum allowed URL length for an HTTP request using the Configuration utility.

Impact of procedure: Performing the following procedure causes a temporary traffic disruption while the BIG-IP ASM service restarts. You should perform this procedure only during a scheduled maintenance window.

  1. Log in to the Configuration utility.
  2. Go to Security > Options > Application Security > Advanced Configuration > System Variables.
  3. Select the parameter name ecard_max_http_req_uri_len.
  4. Change the BIG-IP ASM maximum allowed URL length by modifying the Parameter Value.
  5. Select Update.

    Note: For BIG-IP ASM 13.0.0 and earlier, scroll to ecard_max_http_req_uri_len on the System Variable page, enter the appropriate value for Parameter Value, and select Save.

  6. Log in to Advanced Shell (bash).
  7. Restart the BIG-IP ASM services by entering the following command:

    tmsh restart /sys service asm

    To restart multi-slot devices, use the following command:

    clsh bigstart restart asm
