K000159872: Address-List and Port-List Configuration Changes in BIG-IP v17.5.1 and later

Issue

Beginning in BIG-IP 17.5.1, configuration loading for security shared-objects address-list or security firewall address-list through SCF merge is no longer supported. This change significantly improves upgrade performance and reduces configuration file size for systems with large address-list or port-list configurations

Old Behavior

In versions prior to BIG-IP 17.5.1,  creating an address-list or port-list using any CLI command resulted in three redundant entries being written to the bigip_base.conf configuration file.

For example:

Address-List:
net address-list /Common/test-addrlist {
    addresses {
        10.0.0.0/8 { }
    }
}
security firewall address-list /Common/test-addrlist {
    addresses {
        10.0.0.0/8 { }
    }
}
security shared-objects address-list /Common/test-addrlist {
    addresses {
        10.0.0.0/8 { }
    }
}

Port-List:
net port-list /Common/test-port-list {
    ports {
        80 { }
        443 { }
    }
}
security firewall port-list /Common/test-port-list {
    ports {
        80 { }
        443 { }
    }
}
security shared-objects port-list /Common/test-port-list {
    ports {
        80 { }
        443 { }
    }
}

This redundancy of net, security firewall, and security shared-objects occurrs regardless of which address-list or port-list creating command was used.

New Behavior

Beginning in BIG-IP 17.5.1, only one configuration entry is saved regardless of which CLI command is used.

For example, all of following commands now result in a single entry:

create net address-list /Common/test-addrlist addresses add { 10.0.0.0/8 }
create security firewall address-list /Common/test-addrlist addresses add { 10.0.0.0/8 }
create security shared-objects address-list /Common/test-addrlist addresses add { 10.0.0.0/8 }

Result in bigip_base.conf (single entry):

net address-list /Common/test-addrlist {
    addresses { 10.0.0.0/8 { } }
}

Note: All CLI commands continue to work as before for interactive operations. Only the storage mechanism has changed.

Impact

Beginning in BIG-IP 17.5.1, the following CLI commands cannot be used in SCF file merge/merge from terminal operations:

security firewall address-list
security shared-objects address-list
security firewall port-list
security shared-objects port-list

As a result, the following operations will fail if the SCF file contains the above syntax:

tmsh load sys config merge file /path/to/config.scf
tmsh load sys config merge from-terminal

With error messages similar to the following examples:

Syntax Error: "fw-ip-address-list" component cannot be loaded because it is not a valid component.
Syntax Error: "fw-port-list" component cannot be loaded because it is not a valid component.

Note: If the system already has these address-list configurations present in versions prior to BIG-IP 17.5.1, the upgrade process correctly preserves and handles them. The issue occurs only when attempting to newly merge such configurations via SCF files after upgrading to BIG-IP 17.5.1 and later.

Recommended Actions

To avoid the errors, use the supported net CLI syntax exclusively in SCF files for SCF File Merge Operations/Load or merge config from terminal.

For example:

net address-list /Common/blacklist {
    addresses {
        10.0.0.0/8 { }
    }
}

net port-list /Common/web-ports {
    ports {
        80 { }
        443 { }
    }
}
