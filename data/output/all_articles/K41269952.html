K41269952: ''tmsh show /sys connection'' and ''tmsh show /ltm persistence'' have different output

Type
Support Solution
Published
2020-12-14
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K41269952

Description

When running tmsh show /sys connection and tmsh show /ltm persistence the connection displayed are not consistent.

Connection is tmsh show /ltm persistence is still present even though it has been removed in tmsh show /sys connection.

In summary running tmsh show /ltm persistence will show more connections than tmsh show /sys connection.

Environment

  • BIG-IP
  • Specific connection has been removed from tmsh show /sys connection
  • The same connection can still be see in tmsh show /ltm persistence

Cause

tmsh show /sys connection will display the connection table which are for the existing running connections. Closed connection will not be displayed.

tmsh show /ltm persistence will display a persistence table and not the connection table. Persistence table connection will be removed after the connection has timeout. If the connection has been closed but before the timeout, it will still be present in the persistence table.

This is an expected behavior.

Recommended Actions

None.
