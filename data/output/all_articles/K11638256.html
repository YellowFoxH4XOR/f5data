K11638256: After TMOS Upgrade to 14.1.x DNS monitor may fail

Description
After TMOS Upgrade, DNS monitor receive string no longer support \d.
For example the following regex in receive string: 
^http\/\d\.\d[23]\d\d

Environment

  • BIGIP DNS
  • DNS monitor
  • Software upgrade 

Cause

When BIGIP DNS is upgraded to  14.1.x, DNS monitor receive string  "format ^http\/\d\.\d[23]\d\d" is not supported and the monitor fails. 

Recommended Actions

Update DNS monitor receive string as shown below.

^HTTP/[0-9][.][0-9] [23][0-9]{2}
