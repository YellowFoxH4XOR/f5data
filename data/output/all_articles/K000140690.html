K000140690: Backup&Restore option not available in BIG-IP Next CM 20.2.1 after upgrade from 20.2.0 version

Type
Support Solution
Published
2024-08-13
Updated
2025-09-03
Status
Legacy Content
Applies to
  • BIG-IP Next
  • BIG-IP Next Central Manager: 20.2.0, 20.2.1
Source
https://my.f5.com/manage/s/article/K000140690

Description

Backup&Restore in System tab is not available in BIG-IP Next CM 20.2.1 after upgrade from 20.2.0 version. So, system have no possibility to perform backup and restore for CM.

The option from CLI which  was available in BIG-IP Next CM 20.2.0, in BIG-IP Next CM 20.2.1 is not available any more:

admin@big-ip-next:~$ /opt/cm-bundle/cm backup
2024-08-13T10:06:31+00:00 Executing /opt/cm-bundle/cm backup
2024-08-13T10:06:31+00:00 error: CM backup is deprecated. Use CM UI/API
admin@big-ip-next:~$ /opt/cm-bundle/cm

2024-08-13T10:09:07+00:00 Executing /opt/cm-bundle/cm
Usage: cm [OPTIONS] [COMMANDS] [ARGS]
Options:
    -h, --help                  Show usage information
    -v, --verbose               Produce verbose output

Environment

  • BIG-IP Next CM 20.2.0
  • Upgrade BIG-IP Next CM to 20.2.1

Cause

Problem with refreshing System tab for BIP-IP Next CM GUI page 

Recommended Actions

It is require to refresh in bowser BIP-IP Next GUI page for System tab.

Additional Information

Backup&Restore on the System tab is available in BIG-IP Next CM 20.2.1 right away when the installation is performed from scratch.
