Description

You activated the catalog (CAT) key for the Flexible Consumption Program (FCP) and need to decide which license offering to apply to your BIG-IP Virtual Edition.

Environment

  • Big-IQ
  • FCP
  • Catalog (CAT) key
  • License offerings
  • Big-IP Virtual Edition

Cause

The FCP uses Catalog (CAT) keys that include a bundle of license offerings. Once the CAT key is activated on the BIG-IQ, you can view its license offerings.

Here is a snippet from a list of license offerings on the BIG-IQ > Devices tab > License Management > Licenses > [Relevant CAT name]
