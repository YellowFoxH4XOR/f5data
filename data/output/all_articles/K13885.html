Topic

This article applies to BIG-IP 11.x and later. For information about other versions, refer to the following article:

  • K9156: Setting the baud rate of the serial console port (9.x - 10.x)

You can change the baud of the serial console port using one of the following three methods:

  • Setting the baud of the serial console port using the LCD panel
  • Setting the baud of the serial console port using the command line
  • Setting the baud of the serial console port using the SCCP or AOM command menu

Important: For systems with multiple BIG-IP versions installed, all boot locations must use the same baud.

Setting the baud of the serial console port using the LCD panel

  1. On the LCD panel, press X to enter the menu.
  2. Using the Down Arrow key, select Setup.
  3. Press the Check Mark key.
  4. Using the Down Arrow key, select Serial Speed.
  5. Press the Check Mark key.
  6. Using the Down Arrow key, select the desired baud speed.
  7. Press the Check Mark key.
  8. Press X twice to exit the menu.

Setting the baud of the serial console port using the command line

  1. Log in to the command line.
  2. To view the current Baud Rate value, enter the following command:

    tmsh show sys console

    The output of the command appears similar to the following example:

    Sys::Console
    ----------------
    Baud Rate 19200

  3. To set the new baud, enter the following command:

    tmsh modify sys console baud-rate <value>

    For example:

    tmsh modify sys console baud-rate 9600

    Note: The BIG-IP serial console supports the following bauds: 9600, 19200, 38400, and 115200. The default baud of the serial console is 19200. 38400 is only supported in the 1500, 3400, 6400, and 6800 platforms.

  4. Save the changes by entering the following command:

    tmsh save sys config

Setting the baud of the serial console port using the SCCP or AOM command menu

Note: To determine whether a specific BIG-IP platform has a Switch Card Control Processor (SCCP) subsystem or an Always-On Management (AOM) subsystem, refer to K9476: The F5 hardware/software compatibility matrix.

  1. Connect the serial console to the CONSOLE port.
  2. To display the SCCP or AOM Command Menu, enter the following key sequence:

    Esc (

    For BIG-IP 2000, 4000, 5000, 7000, and 10000 series platforms, the following AOM Command menu displays:

    AOM Command Menu:
    B --- Set console baud rate
    I --- Display platform information
    P --- Power on/off host subsystem
    R --- Reset host subsystem
    N --- Configure AOM network
    S --- Configure SSH Server
    A --- Reset AOM
    E --- Error report
    Q --- Quit menu and return to console

    For other BIG-IP platforms, the AOM Command Menu opens as displayed below:

    AOM Command Menu

    1 --- Connect to Host subsystem console
    2 --- Reboot Host subsystem (sends reboot command)
    3 --- Reset Host subsystem (issues hardware reset--USE WITH CARE!)
    4 --- Reset AOM subsystem (issues hardware reset--USE WITH CARE!)
    5 --- Power off Host subsystem (issues hardware shutdown--USE WITH CARE!)
    B --- AOM baud rate configurator
    L --- AOM subsystem login
    N --- AOM network configurator
    P --- AOM platform information

    For SCCP-based platforms, the SCCP Command Menu opens, as displayed below:

    [hostconsh] Command Menu:

    1 --- Connect to Host subsystem console
    2 --- Select Host subsystem boot mode: boot from local drive
    3 --- Select Host subsystem boot mode: netboot manufacturing test
    4 --- Select Host subsystem boot mode: netboot from external server
    5 --- Reboot Host subsystem (sends reboot command)
    6 --- Halt Host subsystem (sends halt command)
    7 --- Reset Host subsystem (issues hardware reset--USE WITH CARE!)
    8 --- Reboot SCCP subsystem (issues hardware reset--USE WITH CARE!)
    9 --- Halt SCCP subsystem (issues hardware shutdown--USE WITH CARE!)
    D --- Run Diagnostics
    I --- Run BIG-IP Installer (issues hardware reset--USE WITH CARE!)
    B --- SCCP baud rate configurator
    L --- SCCP login
    N --- SCCP network configurator

  3. Press B to run the baud rate configurator.
  4. When prompted, enter the new baud.

    For example, you would enter 9600 at the prompt to set the new baud to 9600.
