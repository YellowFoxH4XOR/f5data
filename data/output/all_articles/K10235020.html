Description

The configuration fails to load fails with an error similar to the following:
Syntax Error:(/config/bigip_base.conf at line: 619) "ip-protocol" unknown protocol "icmpv6"

Environment
  • BIG-IP
  • Upgrade done by BIG-IQ

Cause

Bug ID 863285: Incorrect value (icmpv6) is used when Rule List/Rule/Protocol is set to ICMPv6 via GUI.

The value icmpv6  is not recognized by the BIG-IP configuration parser.
Example bad configuration:

security firewall rule-list /Common/Rule_List_Self_IPs {
    rules {
[...]
        Allow_Self_IP_ICMPV6 {
            action accept-decisively
            ip-protocol icmpv6    <<== Should be ipv6-icmp
            destination {
                address-lists {
                    /Common/F5_Self_IPs
                }
            }
        }

Recommended Actions

  1. Boot back to the prior version volume.
  2. Locate the Firewall rule configuration that utilizes the erroneous icmpv6 reference.
  3. Modify the rule stanza to use: ipv6-icmp.
  4. example for rule "test" :  tmsh  modify security firewall rule-list test rules modify { test { ip-protocol ipv6-icmp } }
  5. Boot to the new version and set "Install Configuration:  yes"
Alternatively if you are familiar with editing config files you can edit the bigip_base.conf file directly.
  1. You can use the line number that is presented in the error to locate the offending syntax /config/bigip_base.conf.
  2. Log on to the command line of the BIG-IP.
  3. Using a text editor such as vi or pico modify references to icmpv6 to use ipv6-icmp.
  4. Save the modifications
  5. Load the configuration:
    tmsh load sys config
  6. Restart the system services:
    bigstart restart
