K57833853: Cannot enable pool member to autopopulate, node (*) has autopopulate set to disabled

Applies to

Source

Description
Configuration fails to load after attempting to add FQDN node to a pool with autopopulate set to enabled.

Environment

  • FQDN node with autopopulate set to disabled (default)
  • Pool with autopopulate set to enabled (default)

At the node level, autopopulate "disabled" means that only the first ephemeral IP returned by DNS will be used. Autopopulate "enabled" means that all ephemeral IPs returned by DNS will be used. 

Cause
The auto-populate setting needs to match at both the node and pool level.

Recommended Actions

  • Create all FQDN nodes with auto-populate set to enabled.

tmsh create ltm node example.com fqdn { name example.com autopopulate enabled }

  • Check the logs for any existing errors associated with autopopulate

zgrep -i autopopulate /var/log/ltm*
