K71645482: L2 transparency fails on v15.x and above

Source

Description

Under version 15 and above L2 transparency may fail out of the box.

Environment 

DDoS Hybrid Defender configured in  L2 transparent or "bump-in-the-wire" mode

Cause

This is caused by the introduction of the connection.vgl2transparent database key in version 15 and above.

Recommended Actions

To enable the DHD to pass traffic in an L2 transparent configuration you must change two database keys.

  1. tmsh modify sys db connection.vgl2transparent value enable
  2. tmsh modify sys db connection.vlankeyed value disable
Depending on your configuration you may need to disable vlangroup.forwarding.override
  1. tmsh modify sys db vlangroup.forwarding.override value disable

Additional Information

These values should be changed automatically if deploying in L2 wire mode via the TMUI, but may not be, depending on which options you select.
