K42325076: NGINX Server Crashing with OCSP Verify Error

Type
Support Solution
Published
2020-12-07
Updated
2025-04-02
Applies to
  • NGINX Products
  • NGINX Plus: R21, R20, R19, R18, R17, R22, R15, R14, R13, R16
Source
https://my.f5.com/manage/s/article/K42325076

Description

Site crashes until NGINX is restarted.

  • NGINX server service restarting
  • NGINX Error Log
  • OCSP_basic_verify() failed (SSL: error:27069065:OCSP routines:OCSP_basic_verify:certificate verify error:Verify error:unable to get issuer certificate) while requesting certificate status, responder: <ocsp_provider>, peer: <ocsp peer ip:port>, certificate: "<server certificate being checked>"
Note:
      <ocsp_provider> would be your OCSP provider hostname. Example: ocsp.entrust.net
      <server certificate being check> would be the certificate that utilizes the OCSP provider. Example: /etc/ssl/certs/server.crt
      <ocsp peer ip:port> DNS resolved IP from <oscp_provider> above

Environment

  • NGINX utilizing OCSP Verify
  • ssl_stapling_verify on;
  • OCSP Server accessed through Firewall
  • OCSP Port defined in server.crt

Cause

Firewall disrupting communication to OCSP Servers. NGINX unable to verify certificate validity cause service to fail.

Recommended Actions

Allow communication through Firewall for OCSP verification communication

Additional Information

None at time of publication.
