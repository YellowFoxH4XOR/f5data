Known Issue

This is the result of a known issue. If a BIG-IP platform contains a switch card control processor (SCCP), the following error is logged to the serial console when the system is rebooted or the bigstart restart command is run:

Using bigstart to shutdown BigIP: terminate called after throwing an instance of 'std::logic_error'

what(): Dead Reference Detected

You can safely ignore this error message.

The following BIG-IP platforms contain an SCCP:

1500
3400
4100
6400
6800
8400
8800

Note: For more information about the SCCP, refer to K3454: Overview of the SCCP.

F5 Product Development is tracking this issue as ID 222963 (formerly CR126193).
