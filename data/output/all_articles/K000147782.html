K000147782: Can I change CE size, instance type, or other critical attributes after CE is deployed?

Description

 

  • How do I verify my CE hardware is sized properly (including storage, memory, and CPU compute resources)?
  • If my CE isn't sized properly, can I change CE size, instance type, or other critical attributes after CE is deployed?

Environment

  • F5® Distributed Cloud (XC)
  • Customer Edge

Answer/Recommended Actions

  • You can verify your CE hardware is sized properly by referencing this document. Compare the requirements to your current CE resource specifications by checking in XC Console MCNC (multi-cloud network connect) > infrastructure (left pane) > sites > click your site name > infrastructure (top toolbar) > click your preferred node name > hardware information.
  • If your CE isn't sized properly, AWS Instance types unfortunately cannot be changed after the CE is deployed. The same is true for any CE resource such as storage, memory, CPU, etc.
  • The only way to change any of these is to redeploy the CE with the new type/resources.

Additional Information

  • The amount of resources specified at CE provisioning is the amount of resources that can be used, so always plan accordingly.
