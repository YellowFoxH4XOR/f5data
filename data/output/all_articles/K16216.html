Known Issue

The Traffic Management Shell (tmsh) no-platform-check option may not function as expected.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is running one of the following versions:
    • 11.6.0
    • 11.6.0 HF1
    • 11.6.0 HF2
    • 11.6.0 HF3
  • You attempt to load a user configuration set (UCS) archive file from a dissimilar BIG-IP hardware platform, using the tmsh no-platform-check option.

By default, the BIG-IP system includes a platform check that prevents the UCS archive created on one BIG-IP platform type from being installed on a different BIG-IP platform type. Under normal conditions, you can use the tmsh utility to bypass this platform check. However, under the aforementioned conditions, the platform check is not bypassed, which prevents the UCS archive file from loading. For more information about the tmsh no-platform-check option, refer to: K14906: Overview of the UCS no-platform-check tmsh option.

Impact

Users are unable to load the UCS archive file.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice an error message similar to the following example when you attempt to load a UCS archive file from a different BIG-IP hardware platform:

    ERROR: The platform on the system is different from the platform in the UCS. Can't install the UCS. To bypass platform check, use no-platform-check option.

  • You are unable to install a UCS archive file from a different BIG-IP platform type.

Workaround

To work around this issue, you can modify the ucs.platformcheck sys db value before installing the UCS archive file. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Modify the ucs.platformcheck sys db value by typing the following command:

    modify sys db ucs.platformcheck value false

  3. Install the UCS archive file you want to use by typing the following command syntax:

    load sys ucs <filename>.ucs

    For example:

    Note: If the UCS archive file is not located in the /var/local/ucs/ directory, you must specify the path to the UCS archive file, in addition to the file name.
    For example:

    load sys ucs /var/tmp/config.ucs

  4. Save the change by typing the following command:

    save /sys config
