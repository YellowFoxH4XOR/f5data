Known Issue

This is the result of a known issue. If you use a pre-logon sequence that requires real-time protection (RTP) to be enabled, and requires a specific age of the antivirus database, clients running Avira Antivir Personal software fail the antivirus check. The OPSWAT client inspector is unable to correctly read the age of the database.

Note: RTP corresponds to the Monitor is running rule in the pre-logon sequence.

The Windows antivirus checker uses software libraries from a software development kit (SDK) created by OPSWAT. OPSWAT provides a vendor-independent framework for endpoint security management. OPSWAT is aware of the issue described in this Solution and is working on a resolution. Once a resolution is available from OPSWAT, F5 Networks will issue a hotfix to address this issue.

F5 Networks Product Development is tracking this issue as CR133710.

Additionally, this issue was fixed in hotfix-134290-1 (OPSWAT 3.4.7.1 Update) issued for all supported FirePass versions. You may download this hotfix or later versions of the OPSWAT hotfix from the F5 Networks Downloads site.

For instructions about obtaining and installing an OPSWAT hotfix, refer to K6664: Obtaining and installing OPSWAT hotfixes.
