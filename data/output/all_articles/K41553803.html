Issue

Error Message

011ae201:5: CRL file <filename> removed, disabling CRL validation on all remote iQuery connections.

In this error message, note the following:

  • <filename> is the name of the CRL file used for iQuery connections.

For example:

011ae201:5: CRL file /config/revoked_certs.crl removed, disabling CRL validation on all remote iQuery connections.

Message Location

You may encounter this message in the following location:

  • The /var/log/gtm file.

Description

This message occurs when the following condition is met:

  • The CRL file (/config/revoked_certs.crl) is removed.

Starting in BIG-IP 16.x, you can configure the system to check for revoked SSL certificates for components that use the iQuery communication mechanism, such as BIG-IP DNS synchronization. If you configured CRL validation for iQuery communication and the /config/revoked_certs.crl is removed or damaged, the system logs the previous error message.

Impact

CRL validation is disabled for all remote iQuery connections.

Recommended Actions

Re-install the /config/revoked_certs.crl file and make sure the file contains a valid entry for the SSL certificate used by iQuery.
