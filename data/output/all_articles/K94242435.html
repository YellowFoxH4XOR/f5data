Description

Running keyswap.sh -genkeys following K26031800, but not able to update the SSH Host RSA keys to 2048-bit, they remain 1024-bit.

Disconnected from SSH session while running the script.

Environment

  • keyswap.sh
  • Command line
  • Multi-bladed system

Cause

Bug ID 1036645: Running keyswap.sh on a VIPRION or VCMP platform may not complete successfully

Recommended Actions

Use one of the workarounds described in Bug ID 1036645.

If that does not resolve the issue, troubleshoot further with:

bash -x /usr/bin/keyswap.sh -genkeys

None
