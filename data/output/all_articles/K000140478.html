Description

When you apply a JWT for a trial license to a BIG-IP Next instance via BIG-IP Next central manager, a licensing error occurs:

LICENSING-1120: Could not initialize product, the provided digitalAssetid is unavailable

Environment

  • BIG-IP Next
  • Enabling a trial license on BIG-IP Next

Cause

A trial license has already been previously applied to the BIG-IP Next instance. A BIG-IP Next instance can only have a trial license applied once.

Recommended Actions

Apply the JWT for a trial license to a freshly installed BIG-IP Next instance that has not been previously activated.

None
