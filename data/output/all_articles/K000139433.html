K000139433: Capturing VELOS Out-of-band management traffic

Type
Support Solution
Published
2024-04-29
Updated
2026-08-26
Applies to
  • F5OS
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000139433

Description

This article describes how to capture out-of-band management traffic on VELOS system based on either System Controller, chassis partition or tenant. K12313135 provides details on how to capture data plane traffic traversing the front panel ports on the chassis blades in the chassis partition as well as backplane traffic for the chassis partition.

You may refer to the related content section for more details about VELOS out-of-band management network.

Environment

  • Capture out-of-band management traffic on VELOS
  • F5OS-C

Cause

None

Recommended Actions

To capture out-of-band management related to system controller:

  1. Identify the active system controller. From system controller F5OS CLI, run command: show system redundancy 
    # show system redundancy
system redundancy state mode auto
system redundancy state current-active controller-1
NAME          NAME
--------------------
controller-1  -
controller-2  -
  1. Access active system controller bash shell, run tcpdump utility specifying interface team0 : tcpdump -nni team0 <filter expression> 
    @controller-1 config]# tcpdump -nni team0 -c 5 port 443

  3. Download controller-mgmt-capture.pcap from active controller WebGUI via "File Utilities > diags/shared/"
