Description

The BIG-IP / BIG-IQ management hostname changes with each system restart.

Environment

  • BIG-IP or BIG-IQ
  • Azure, Amazon, or Google Cloud Platforms

Cause

If the management network settings are configured with DHCP, the configured hostname will be overwritten at each system restart. To keep the configured hostname, the host-name option should be removed from the dhcp request-options.

Recommended Actions

From the BIG-IP / BIG-IQ tmsh shell command line, enter the following:
  1. To remove the host-name from the dhcp requests:
    modify sys management-dhcp sys-mgmt-dhcp-config request-options delete { host-name }
  2. To set the desired hostname:
    modify sys global-settings hostname <desired hostname>
  3. Save the configuration:
    save sys config
  4. To verify that the new setting has taken effect, disable and re-enable the mgmt dhcp service:
    modify sys global-settings mgmt-dhcp disabled
    modify sys global-settings mgmt-dhcp enabled
