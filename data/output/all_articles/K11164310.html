Description
BIG-IP silently reboots and LTM logs indicate an error 'CPU 1 Catastrophic Error event' like below.

Error messages: 
ltm  2019-03-06 11:09:47.000 -06:00   Info    012a0006: f5lb01 chmand[7597] Latched Event:0x7: Host was reset by platform reset event   
ltm  2019-03-06 11:09:47.000 -06:00   Info    012a0006: f5lb01 chmand[7597] Latched Event:0x2: CPU 1 Catastrophic Error event           
ltm  2019-03-06 11:09:46.000 -06:00   Info    012a0006: f5lb01 chmand[7597] Installing all supported LOP commands
ltm  2019-03-06 11:09:36.000 -06:00   Info    012a0006: f5lb01 chmand[5872] <<<********** LOP **********<<<
ltm  2019-03-06 11:09:36.000 -06:00   Info    012a0006: f5lb01 chmand[5872] LOP version update not required.
ltm  2019-03-06 11:09:36.000 -06:00   Info    012a0006: f5lb01 chmand[5872] >>>********** LOP **********>>>
ltm  2019-03-06 11:09:31.000 -06:00   Notice  013d0006: f5lb01 lopd[5493] Connected to LOP

Environment

  • BIG-IP reboot
  • Interfaces are marked as unpopulated
  • Latched events in LTM logs

Cause
The latched events are captured by the CPLD, harvested by the LB hardware and TMOS. The 'CPU 1 Catastrophic Error event' message means that the CPU asserted the CATERR# pin and the CPLD latched it. The CATERR# (Catastrophic Error) pin indicates that an MCERR (Machine check error) class error or an IERR (internal error) class error has occurred. Both of these errors are normally an indication of a hardware problem, but there are occasions when these can occur as the indirect result of software action.

Recommended Actions
1. Run EUD test during downtime to avoid any business impact.
2. An EUD report log is stored as the text file under /shared/log/eud.log, collect a fresh Qkview, and upload to iHealth for further analysis. 
3. Contact F5 Support for further investigation.
 

Additional Information
Manual Chapter : Running the EUD Tests
IERR is a Processor Internal Error, a signal that indicates a Processor unrecoverable error
MCERR signal is asserted when the processor is experiencing a Machine Check event.
