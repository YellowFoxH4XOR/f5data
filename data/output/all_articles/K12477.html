K12477: The CSRF protection feature will append an href attribute to HTML anchors that do not already contain an href attribute

Known Issue

This is the result of a known issue. If the BIG-IP ASM CSRF protection feature is enabled, it will add the href=null attribute to an anchor element that does not already include an href attribute. This issue may cause the anchor element to function incorrectly.

For example, the following anchor does not contain an href attribute:

<a onclick="document.forms['my_form'].submit">SUBMIT</a>

With the CSRF protection feature enabled, the element will be given the following href attribute:

<a href=null onclick="document.forms['my_form'].submit">SUBMIT</a>

As a result, the user is forwarded to a null URI rather than the form being submitted when the user clicks the SUBMIT link.

F5 Product Development tracked this issue as ID 345895 and it was fixed in BIG-IP 10.2.2 and 11.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
