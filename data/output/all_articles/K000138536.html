K000138536: Virtual F5 system (VE) does not boot after migration from VMware ESxi to Nutanix AHV hypervisor.

Type
Support Solution
Published
2024-02-08
Updated
2026-07-24
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000138536

Description

Customer attempted to migrate BIG-IP VE from VMWare ESXI, to Nutanix AHV, by using the Nutanix "MOVE" utility.

Environment

BIG-IP VE migrated to Nutanix AHV hypervisor

Cause

The root cause remains undetermined, as F5 support is unable to assist with a 3rd party Virtual Machine migration tool, however, it appears that the Nutanix MOVE utility may not be properly converting the VMWare ESXI image to the format expected by Nutanix AHV

Recommended Actions

Instead of migrating with the Nutanix MOVE utility, simply deploy a new BIG-IP VE virtual machine to the Nutanix AHV system, then load the UCS config backup file obtained from the original BIG-IP system to the new BIG-IP VE
