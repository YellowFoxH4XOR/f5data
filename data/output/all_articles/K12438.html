Known Issue

This is the result of a known issue. If a BIG-IP system is configured with an SSL profile that references a parent profile from a different partition, the Enterprise Manager system will mark the BIG-IP system as impaired in the Configuration utility with an error message that appears similar to the following example:

04010568:3: Error found on device <managed device IP address> (UID: 0): get change control dependency info: iControl error: 'iControl::OperationFailed - primary code:0(0x0) secondary code: 16908342(0x1020036) string: MCP call failed: MCP error 0x1020036: 01020036:3: The requested client SSL profile (<parent profile referenced by SSL profile>) was not found.'

For example, if a BIG-IP system with IP address 172.28.26.17 is configured with SSL profile clientssl-part-132980 that resides in partition Part-132980, and clientssl-part-132980 is configured with a parent profile set to the clientssl-common profile that resides in the Common partition, Enterprise Manager will mark the BIG-IP system impaired with the following error message:

04010568:3: Error found on device 172.28.26.17 (UID: 0): get change control dependency info: iControl error: 'iControl::OperationFailed - primary code:0(0x0) secondary code: 16908342(0x1020036) string: MCP call failed: MCP error 0x1020036: 01020036:3: The requested client SSL profile (clientssl-common) was not found.'

F5 Product Development tracked this issue as ID 242103 (formerly CR132980) and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, Link Controller, WebAccelerator, PSM, APM, WOM, Edge Gateway, or Enterprise Manager release notes.

Workaround

You can work around this issue by configuring the SSL profile to use a parent profile from the same partition. For example, if you configure the SSL profile to reside in the Common partition, the parent profile must reside in the Common partition.
