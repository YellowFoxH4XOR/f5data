Known Issue

Small form-factor pluggable (SFP) interfaces may incrementally report Frame Check Sequence (FCS) errors after you install a hotfix image.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP platform SFP interfaces are populated with a Finisar 100G LR4 optic.
  • You install BIG-IP HF12.1.1 HF1.

Impact

The SFP interface populated with the Finisar 100G LR4 optic reports a high level of FCS errors.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view interface statistics for the interface that is populated with the Finisar 100G LR4 SFP, the error count for FCS continually increments.
  • When you view interface statistics for the next hop upstream device, the device interface notes a continually incrementing amount of Cyclic Redundancy Check (CRC) errors.

Resolution

Status

F5 Product Development has assigned ID 644135 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article.
