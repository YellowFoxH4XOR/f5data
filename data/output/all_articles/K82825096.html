Issue

Error Message

err vcmpd[PID#]: 01510004:3: attemptStateEntry failed: Cannot deploy guest due to license limit. Maximum number of deployed guests is:0
err vcmpd[PID#]: 01510004:3: Guest ([vcmp-guest_name]): Failure -  Cannot deploy guest due to license limit. Maximum number of deployed guests is:0

In this error message, note the following:

  • [PID#] is the process ID.
  • [vcmp-guest_name] is the name of the affected vCMP Guest.

For example:

err vcmpd[5923]: 01510004:3: attemptStateEntry failed: Cannot deploy guest due to license limit. Maximum number of deployed guests is:0
err vcmpd[5923]: 01510004:3: Guest (test): Failure -  Cannot deploy guest due to license limit. Maximum number of deployed guests is:0

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file on the vCMP Host system

Description

This message occurs when all of the following conditions are met:

  • VCMP Enabled is not listed in the Active Modules section of the License General Properties page on the vCMP Host system.
  • The upper-left corner of the Configuration utility displays a Provisioning Warning yellow status indicator. If you place your cursor on the warning message, the following message displays:

    Provisioned yet unlicensed: VCMP

  • The vCMP Host system attempts to deploy the vCMP Guests from a Configured or Provisioned status.

vCMP Guests were deployed with a vCMP Enabled license, then the license was activated without VCMP Enabled on the vCMP Host system. If the vCMP Host system reboots or attempts to deploy the vCMP Guests from a Configured or Provisioned status, the attempt fails with this error message.

Impact

Deployment of the vCMP Guests fails.

Recommended Actions

First, activate the license with the vCMP Enabled license on the vCMP Host system. Next, change the state of the vCMP Guest to Provisioned or Configured, and then attempt to deploy it.

Impact of procedure: The system briefly interrupts traffic processing while the vCMP Host system reloads the configuration. When licensing redundant vCMP Host systems, F5 recommends that you activate the license on your vCMP Host devices while they are in standby mode.

  1. Log in to the host system's Configuration utility.
  2. On the vCMP Host system, go to System > License > Summary, and on the General Properties page, see if VCMP Enabled is listed in the Active Modules section. If VCMP Enabled is not listed in the Active Modules section, re-activate the license as a vCMP-enabled license. 

    For more information, refer to K7752: Licensing the BIG-IP system.

  3. Go to vCMP > Guest List.
  4. Select the name of the guest system you want to deploy.
  5. For Requested State, select Configured or Provisioned.
  6. Select Update.
  7. Select the name of the guest system you want to deploy.
  8. For Requested State, select Deployed.
  9. Select Update.
