Known Issue

Description

The BIG-IP system may erroneously log critical messages about the failure to load SSL certificate and key files (for details of the critical level messages, refer to the Symptoms section).

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is running any of the following versions:
    • 11.6.0 through 11.6.0 HF3
    • 11.4.0 through 11.5.1 HF5
    • 11.3.0 HF6 through 11.3.0 HF10
    • 11.2.1 HF8 through 11.2.1 HF13
  • You deleted and recreated an SSL certificate or SSL key referenced by an SSL profile on the affected BIG-IP system.
  • You then performed a full configuration synchronization from that BIG-IP system to peer devices belonging to the same device group.

Impact

You can safely ignore these critical level messages.

Note: For BIG-IP 11.5.0 and later, due to another issue that logs the same critical log message described in this article, the BIG-IP system may experience SSL traffic disruption to affected virtual servers. For more information, refer to K15851: Virtual servers with Client SSL profiles may not respond to SSL handshakes after a ConfigSync. If your BIG-IP system is already installed with the fix for the issue described in SOL15851, but is still logging this critical level message, then your BIG-IP system is experiencing the issue described in this article and you can safely ignore the critical level message.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H499533 on the Diagnostics > Identified > Medium screen.
  • In the /var/log/ltm file, you may observe a critical level message similar to the following example for BIG-IP systems running 11.5.0 and later:

    crit tmm3[<PID>]: 01260000:2: Profile /Common/<SSL profile>: could not load key/certificate

  • In the /var/log/ltm file, you may observe a critical level message similar to the following example for BIG-IP systems running versions earlier than 11.5.0:

    crit tmm3[<PID>]: 01260000:2: Profile /Common/<SSL profile>: could not load key file.
    crit tmm3[<PID>]: 01260000:2: Profile /Common/<SSL profile>: could load neither certificate nor chain file
