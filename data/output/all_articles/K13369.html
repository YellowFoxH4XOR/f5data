Topic

This article applies to BIG-IP 11.x through 17.x. For information about other versions, refer to the following articles:

  • K10371: Performing a first-time configuration for BIG-IP from the command line (10x)
  • K4802: Performing a first-time configuration for BIG-IP from the command line (9.x)

Purpose

You should consider using this procedure under the following condition:

  • You want to configure a BIG-IP device running BIG-IP 11.x or later for the first time, but you only have access to the serial console.

Important: This article contains numerous steps that you must perform correctly. If you make an error while following the instructions in this article, you may cause issues that are not immediately apparent. F5 recommends that you use this article only when you cannot perform a first-time configuration from the Configuration utility.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • BIG-IP 11.x or later is already installed on the device.
  • You have a serial console connection to the device.

    Note: You can obtain SSH access to the BIG-IP device after it has automatically obtained a management IP address from a local network DHCP server. To view the DHCP address of the BIG-IP device from the console, use the following command: ifconfig mgmt | grep broadcast

  • You are familiar with the vi text editor.

Note: For more information about installing BIG-IP 11.x or later, and connecting a serial console to the BIG-IP system, refer to the links in the Supplemental Information section of this article.

Description

If you do not have access to the Configuration utility, you can use the serial console connection to perform the following configurations:

  • Licensing the BIG-IP system
  • Configuring management interface properties
  • Setting the device host name
  • Configuring the system time zone
  • Changing the default system maintenance account passwords
  • (Optional) Disabling the BIG-IP Setup utility  

Licensing the BIG-IP system

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in as root with the default password, default.
  2. To create a dossier, use the following command syntax:

    get_dossier -b "<regkey>"

    In the command syntax, note the following:

    • Replace <regkey> with your registration key.

    Note: The registration key is printed on a paper certificate that was included in the box with the BIG-IP system.

    The dossier is displayed.

  3. BLock and then copy the dossier, starting with the section that begins on the line after the command you issued, and ending just before the next command prompt.
  4. Open a web browser and connect to the following URL:

    http://activate.f5.com

  5. Click Activate License.
  6. Follow the instructions to submit your dossier.

    Your product license is displayed.

  7. Block and then copy the entire license.
  8. Return to the BIG-IP command line.
  9. Using the vi text editor, open the /config/bigip.license file by typing the following command:

    vi /config/bigip.license

  10. Enable the vi insert mode by pressing the i key.
  11. Paste the license file that you copied in step 7.
  12. Press the Esc key to exit vi insert mode.
  13. Save the file and exit vi by typing the following command and pressing Enter:

    :wq

  14. To restart the BIG-IP system services, type the following command:

    bigstart restart

The command prompt will change from INOPERATIVE to Active. The BIG-IP system is now licensed.

Configuring management interface properties

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Type the following command from the command line:

    config

  3. Continue through the Configuration utility banner by clicking OK.
  4. Click the IP address family type IPv4 or IPv6.
  5. If you want the BIG-IP device to obtain the management IP address from DHCP, click Yes. Otherwise click No.

    Note: If you configure the management interface to obtain the IP address from DHCP, you can skip steps 6 through 10.

  6. For a non-DHCP management IP configuration, when prompted, enter the IP Address to access the BIG-IP management port.
  7. For a non-DHCP management IP configuration, when prompted, enter the Netmask for the IP Address that you entered in step 6.
  8. For a non-DHCP management IP configuration, to add a Management Route to the management interface default route click Yes.
  9. Enter the management route IP address and click OK.
  10. Confirm configuration of the management network interface by clicking Yes.

Setting the device host name

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To assign a host name, use the following command syntax:

    tmsh modify /sys global-settings hostname <newhostname>

    In this command syntax, replace <newhostname> with the desired fully qualified host name for the BIG-IP system.

    For example, to change the system to a new host name, askbig9n1.askf5.com, type the following command:

    tmsh modify /sys global-settings hostname askbig9n1.askf5.com

  3. To save the changes to the host name, type the following command:

    tmsh save /sys config

Configuring the system time zone

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To change directories to the /usr/share/zoneinfo directory, type the following command:

    cd /usr/share/zoneinfo

  3. To list the files in the directory, type the following command:

    ls

    A number of directories that match geographical regions are displayed.

  4. Find the geographical region in which the BIG-IP system you are configuring is installed.
  5. To change directories to the directory for the geographical region you selected, use the following command syntax where <directory> is the region you selected in step 4:

    cd <directory>

    For example:

    cd America

  6. To list the files in the directory, type the following command:

    ls

    The system displays a number of time zone files that match states and cities.

  7. Find the closest match to the time zone in which the BIG-IP system you are configuring is installed.
  8. To set the time zone, type the following command syntax :

    tmsh modify /sys ntp timezone "<directory>/<timezone>"

    In this command syntax, note the following:

    • Replace <directory> with the region you chose in step 4.
    • Replace <timezone> with the location that you selected in step 8.

    For example:

    tmsh modify /sys ntp timezone "America/Los_Angeles"

  9. To save the changes, type the following command:

    tmsh save /sys config

Changing the default system maintenance account passwords

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: After running the following commands, the first time that you log into the Configuration utility from your internet browser, you will still be forced to change the root and admin passwords. To prevent this behavior, perform the optional Disabling the BIG-IP Setup utility procedure.

  1. To set the password for the command line only, user root, type the following command:

    tmsh modify /auth password root

  2. Enter the desired password for the root account each time you are prompted.
  3. To set the password for the Configuration utility administrative user admin, type the following command:

    tmsh modify /auth password admin

  4. Enter the desired password for the admin account each time you are prompted.

  5. To save the changes, type the following command:

    tmsh save /sys config

(Optional) Disabling the BIG-IP Setup utility

The first time that you log in to the Configuration utility, the Setup utility will prompt you for initial system configuration, including setting passwords for the local root and admin users (even if you have followed the previous procedure to change the default system maintenance account passwords). To bypass the Setup utility, perform the following procedure. For more information about the Setup utility, refer to K7037: Overview of the BIG-IP Setup utility.

Impact of procedure: Disabling the Setup utility prevents the BIG-IP system from prompting you for initial system configuration. You will need to manually configure module provisioning, device certificates, device service clustering (DSC), base networking (including VLANs and IP addresses), and DNS. For more information about these steps, refer to the BIG-IP System: Essentials manual.

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

  1. Log in to the BIG-IP command line.
  2. To disable the Setup utility, type the following command:

    tmsh modify /sys global-settings gui-setup disabled

  3. To save the changes, type the following command:

    tmsh save /sys config

You have finished the basic configuration for the BIG-IP system. You can continue configuring the BIG-IP system using the Configuration utility or the command line.

Note: If your BIG-IP system contains multiple modules, you must provision the appropriate resources to each module using the Configuration utility or the tmsh sys provision command. For more information, refer to the online help in the Resource Provisioning menu of the Configuration utility, and the Traffic Management Shell (tmsh) Reference Guide. For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.
