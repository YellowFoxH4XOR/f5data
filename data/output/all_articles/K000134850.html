K000134850: Modifying size of username and password text box in an Standard Logon Page

Type
Support Solution
Published
2023-06-05
Updated
2023-06-05
Source
https://my.f5.com/manage/s/article/K000134850

Description

You want to modify the size of user and password text box in a Standard Access Policy's Logon Page
 

Environment

BIG-IP APM
Logon Page
 

Cause

You want to personalize the logon page. However, the GUI option called "Field width (%)" only works when selecting "Label Position: Left" if you select "Above" the size doesn't change
 

Recommended Actions

You need to use advanced customization to make the change in the size of the text box. 
  1. Navigate to Access  ››  Profiles / Policies : Customization : Advanced
  2. Locate the apm_full.css file inside your Access Profile.
  3. Locate and edit the following block and change the value of "width" to the desired value.
  4. table#main_table table#credentials_table input.credentials_input_password, input.credentials_input_password_disabled, input.credentials_input_text, input.credentials_input_text_disabled
{
    height: 21px;
    width: 85%;
    font-size: 13px;
    border: 1px solid #808080;
}
  5. Save it as a draft in the upper right corner of the editor.
  6. Save and finally Apply the Policy.
