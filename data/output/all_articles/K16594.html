Known Issue

Attempts to create a BIG-IP user account, using the iControl representational state transfer (REST) API, may fail.

This issue occurs when the following condition is met:

  • You attempt to create a BIG-IP user account, in a non-Common partition, using the iControl REST API.

Impact

Administrators cannot use the iControl REST API to create BIG-IP user accounts in non-Common partitions.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You cannot create BIG-IP user accounts in non-Common partitions using the iControl REST API.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) or the Configuration utility to create users in non-Common partitions.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
