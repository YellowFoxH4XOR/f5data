K000163531: HTTPS Monitor Fails to Load a DER-Encoded CA Certificate

Type
Support Solution
Published
2026-10-21
Updated
2026-10-21
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000163531

Description

An HTTPS health monitor fails to load its configured CA certificates in the Server SSL profile, causing the monitored pool members to appear down. Example monitor log:
Cannot load CA certificates from /config/filestore/files_d/Common_d/certificate_d/:Common:<CA_certificate_reference>

Environment

  • BIGIP LTM
  • HTTPS monitors using a Server SSL profile with certificate validation
  • CA certificate format: DER

Cause

 The CA certificate used in the Server SSL profile was stored in DER format. The monitor could not load the DER-encoded certificate from the BIG-IP certificate filestore for certificate validation.

Answer/Recommended Actions

Converting a DER certificate file to a PEM certificate file
Impact: Converting DER formatted certificate should not negatively impact your BIG-IP system.

  1. Log in to the command line of the BIG-IP system.
  2. Copy the DER file to the /var/tmp directory on the BIG-IP system. 
  3. Use the openssl utility to convert the DER certificate file to a PEM certificate file using the following command syntax: 
    openssl x509 -inform der -in <certificate file name>.der -out <certificate file name>.crt
     Note: For more information, refer to K04040195: Converting DER format certificates to PEM format certificates and keys for BIG-IP import
  4. Update the Server SSL profile to reference the PEM-formatted CA certificate.

Importing the new PEM certificate file to the BIG-IP system 

  1. Log in to the Configuration utility.
  2. Navigate to System > Certificate Management > Traffic Certificate Management > SSL Certificate List.
  3. Click Import.
  4. For Import Type, click Certificate.
  5. For Certificate Name, type the certificate name.
  6. For Certificate Source, click Choose File.
  7. Locate the certificate file copied to your computer in the previous procedure and choose that file.
  8. Click Import.
  9. Update the Server SSL profile to reference the PEM-formatted CA certificate.

Additional Information

Starting from version 17.1.3.5, 17.5.1.9 or 21.1.0.2, HTTPS monitors now honor the certificate verification as configured in the Server SSL profile.  For more details, refer to Bug ID 2333277: BIGD HTTPS monitors now honor the certificate verification
