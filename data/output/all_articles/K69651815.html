Description

When browsing some SSO objects from the BIG-IP configuration utility, you may get prompted with the following error message:
General database error retrieving information. 

Important: There are multiple reasons as to why you may see this database error when browsing the GUI. Unless this article fits your case exactly, it is recommended to start with General Database Error Retrieving Information in the BIG-IP Configuration Utility , which helps you discover the right article for you.

Environment

  • You're using BIG-IP APM;
  • The session opened to the Configuration Utility is using an account assigned a "guest" role.

Cause

This is due to ID1001337

Recommended Actions

  • Either using the TMSH CLI interface, to display the SSO object properties;
  • Or connect to the Configuration Utility with a user configured a wider role.

Additional Information
