K000157973: rSeries 2000/4000 10GBase-T RJ45 port may flap when connected to CISCO C9300X-48TX

Type
Support Solution
Published
2025-11-26
Updated
2026-05-29
Applies to
  • F5OS
  • F5OS-A: 1.8.3
Source
https://my.f5.com/manage/s/article/K000157973

Description

When rSeries 2000/4000 10GBase-T RJ45 port is connected to CISCO C9300X-48TX, interface flap may be observed occasionally on port of rSeries platform.

  • Operation status of interface will change from UP to DOWN.
  • If interface is a member of a LAG, LACP STATE shows LACP_DOWN.
  • It could be seen more frequently when even-numbered interfaces are used at the Cisco switch side.

Note: this is not limited to interfaces where a LAG configuration is present. 

Environment

  • rSeries 2000/4000 10GBase-T RJ45 port
  • CISCO C9300X-48TX
  • CISCO C9300X-24HX

Cause

Bug ID 1612605

Recommended Actions

Follow the guidelines of K000138830 to workaround the interface flap event.
