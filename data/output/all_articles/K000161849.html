K000161849: HTTP Load Balancer - Errors: Download large files get interrupted

Description

When downloading large files through a Load Balancer with CDN enabled on F5 Distributed Cloud, the transfer may be interrupted before completion. Affected users typically encounter browser-side errors such as NS_ERROR_NET_PARTIAL_TRANSFER, and the downloaded file arrives incomplete or corrupted. The issue is most pronounced with sizeable documents or assets whose transfer time exceeds the configured connection timeout.

Environment

  • HTTP Load Balancer
  • CDN & CDN Rules

Cause

The timeout value configured on the HTTP Load Balancer itself or the route settings was set too low to accommodate the full duration of large file transfers. A
s a result, the CDN terminated the connection before the complete object could be delivered to the client.

These options can be found:

  • HTTP Load Balancer Option:  (HTTP Load Balancer > Other Settings > More Options > Miscellaneous Options > Idle Timeout)
  • Route Option:  (HTTP Load Balancer > Routes > Route > Advanced Options > Miscellaneous Options > Timeout)

Recommended Actions

Increase the timeout value on the affected route or HTTP Load Balancer itself so that it allows sufficient time for large files to transfer fully. Set the timeout based on the largest expected object size and typical client download speeds, allowing reasonable headroom for slower connections. After applying the change, validate by downloading a representative large file end-to-end and confirming the transfer completes without the partial-transfer error.

Additional Information

A recommendation here is to create a route that will point to the document because it is not a good idea to raise the timeout of the hole HTTP Load Balancer because it weakens the defense agains slow HTTP attacks. Slowloris-style attacks work by opening connections and trickling data to hold them open as long as possible, tying up the connection pool until legitimate clients can't get through. The longer the timeout, the more connections an attacker can hold and the cheaper the attack becomes.
