Known Issue

This is the result of a known issue. If you configure a Citrix MetaFrame Terminal Server favorite and select Full Screen from the Screen resolution menu, the Citrix MetaFrame Terminal Server favorite does not launch in full screen. This issue occurs if you have enabled the Java version of the Citrix client by selecting the Java client check box in the Terminal Server favorite configuration.

This issue does not affect the ActiveX version of the Citrix client. The ActiveX Citrix client is enabled by default, and replaced by the Java Citrix client when the Java client check box is selected in the Terminal Server favorite configuration.

F5 Product Development tracked this issue as CR114256 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-603-1 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by enabling the ActiveX Citrix client. To do so, perform the following procedure:

Important: The ActiveX Citrix client supports only Windows clients. Performing the following procedure will prevent Linux and Mac OS X clients from using the Citrix MetaFrame Terminal Server favorite.

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Application Access : Terminal Servers : Resources page.
  3. Select the Citrix MetaFrame Terminal Server favorite you want to configure.
  4. Clear the Java client check box.
  5. Click Update.
