Description

AS3 Package Management LX Active device Tags shows "PLUGIN", when on Standby it is "IAPP" after installation and syncing config to second big-ip.




Environment

  • AS3 installation performed on one box
  • Auto-sync enabled


Cause

Cosmetic Issue occurs when doing installation of AS3 on one box and syncing config to another BIG-IP unit. Durring process of sync both systems have AS3 rpm installed but tags are different. Issue is managed under ID1474125

https://cdn.f5.com/product/bugtracker/ID1474125.html


Recommended Actions

This is cosmetic issue however there is workaround to make tag the same on both units:


  1. Change autosync to Manual.
  2. Uninstall AS3 rpm on BIG-IP where is tagged as iapp
  3. install AS3 rpm directly on the device again
  4. Re-enable autosync
