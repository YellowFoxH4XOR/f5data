Description

When navigating to Shared Objects > Address list, you see the following error message:

One of the following features must be licensed / provisioned for the URI security / shared objects: afm asm dos.

Environment

BIG-IP version 14.1 or later

Cause

This is a cosmetic issue with the GUI and should not impact performance or any functionalities within the system.

Recommended Actions

Clear your browser cache.

Additional Information

None
