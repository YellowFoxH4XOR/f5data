Topic

You should consider using this procedure under the following condition:

  • You want to force the active member of a traffic group into standby mode while you are logged in to the command line of a standby device in the same traffic group.

Description

You can use the watch-trafficgroup-device utility to force any traffic-group member into online, offline, or standby mode.

Note: You can also use the watch-trafficgroup-device utility to display dynamic traffic group data. For more information, refer to K06093700: Viewing dynamic traffic group data.

Note: The BIG-IP system may experience a memory leak when running a centralized management infrastructure (CMI) watch script for an extended period of time. For more information, refer to K21473530: CMI watch scripts experience a memory leak.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the TMOS Shell (tmsh).

Procedures

Forcing a the active device into standby mode

To use the watch-trafficgroup-device utility to force a device into standby, perform the following procedure:

Impact of procedure: Performing the following procedure causes a failover event and forces the active device into standby mode, which means it no longer passes traffic.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To run the watch-trafficgroup-device utility, enter the following command:

    run /cm watch-trafficgroup-device

  3. Use the Up and Down arrow keys on your keyboard to highlight the device on which you want to make changes.
  4. Press Enter to open the configuration menu.

    The following example output shows the device example-01.local as standby and example-02.local as active, with the configuration menu open for example-02.local:

    devices     traffic_group     device_name          failover_state
    1 2         traffic-group-1   example-01.local     HA_STANDBY
    1 2         traffic-group-1   example-02.local     HA_ACTIVE
                ^  set failover for /Common/example-02.local
                x offline                                        x
                x online                                         x
                x standby                                        x

    Note: The previous example is truncated to show only the relevant output.

  5. Use the Up and Down arrow keys on your keyboard to highlight standby.
  6. Press Enter to commit the action.
  7. Press Ctrl+C to exit the watch-trafficgroup-device utility.
