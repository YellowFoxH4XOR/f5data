Topic

When you install BIG-IP 10.x using the Configuration utility, the bigpipe utility or the Traffic Management Shell (tmsh), the system logs the progress of the installation to the /var/log/liveinstall.log file.

If you inspect the /var/log/liveinstall.log file while a live installation is in progress, you may notice a discrepancy between the progress reported in the file and the progress advertised by the utility used for the installation.

For example:

  • You have initiated an installation from the System > Software Management screen in the Configuration utility.
  • The progress bar in the Configuration utility reports the installation is 68 percent complete.
  • You inspect the /var/log/liveinstall.log file by executing the following command:

    tail -f /var/log/liveinstall.log

    The command output appears truncated and reports the installation is only 30 percent complete:

    progress: 30/100
    info: RPM: e2fsprogs-1.39-23.el5.3341.0
    info: RPM:

This behavior is expected. The BIG-IP system writes the progress of live installations to a buffer in memory, and only dumps the contents of the buffer to the /var/log/liveinstall.log file when the buffer is full. Because of this behavior, the data in the /var/log/liveinstall.log file may be stale.

Note: The /var/log/liveinstall.log file always contains the full log of the installation once the installation is complete.
