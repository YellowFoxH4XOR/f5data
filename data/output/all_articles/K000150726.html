Description

  • Status of BIG-IP VE in Azure does not reach "Ready" state after a reboot.
  • Error messages logged reporting WireServer not found.
  • Error messages logged in var/log/waagent.log

INFO Daemon Daemon Retry detect protocol: retry=<number>

INFO Daemon Daemon WireServer endpoint is not found. Rerun dhcp handler

INFO Daemon Daemon Test for route to 168.63.129.16

WARNING Daemon Daemon No route exists to 168.63.129.16

INFO Daemon Daemon Send dhcp request

WARNING Daemon Daemon Failed to send DHCP request: [DhcpError] timed out

WARNING Daemon Daemon Failed to send DHCP request: [DhcpError] timed out

WARNING Daemon Daemon Failed to send DHCP request: [DhcpError] timed out

WARNING Daemon Daemon Failed to send DHCP request: [DhcpError] timed out

WARNING Daemon Daemon Failed to send DHCP request: [DhcpError] timed out

NFO Daemon Daemon Protocol endpoint not found: [ProtocolError] [DhcpError] Failed to receive dhcp response.

 

Environment

  • BIG-IP VE in Azure
  • IPv4 DHCP was initially enabled then disabled after full deployment but no route to 168.63.129.16 statically created.
  • BIG-IP VE rebooted 

 

Cause

IPv4 DHCP disabled for the management interface and there is no static management route to Azure guest management host 168.63.129.16.

Recommended Actions

  1.  Enable management interface DHCP
  2. If DHCP is not desired then add a static management route to 168.63.129.16 via the management gateway.
