Topic

This article applies to BIG-IP 9.x. For information about other versions, refer to the following articles:

  • K13117: Performing a clean installation of BIG-IP version 11.x - 13.x or Enterprise Manager 3.x
  • K10819: Performing a clean installation of BIG-IP version 10.x or Enterprise Manager 2.x

Important: Do not use these installation procedures to re-image the VIPRION platform with BIG-IP 9.6.1. (The VIPRION platform shipped with BIG-IP 9.6.1 pre-installed.) For an alternative procedure, refer to K10289: Reinstalling BIG-IP LTM 9.6.1 software on the VIPRION platform.

BIG-IP 9.x offers the following installation methods for all other platforms:

  • IM installation

    Supported versions: BIG-IP 9.0.0 through 9.1.0
  • Local installation

    Supported versions: BIG-IP 9.1.1 and later
  • Remote installation

    Supported versions: BIG-IP 9.0.2 and later
  • USB CD-ROM installation method

    Supported versions: BIG-IP 9.0.0 and later
  • USB mass storage installation

    Supported versions: BIG-IP 9.3.0 and later
  • PXE installation

    Supported versions: all BIG-IP 9.x releases
  • Windows hosted installation

    Supported versions: BIG-IP 9.3.0 and later

The following sections provide details to help you choose the most appropriate method for your installation or upgrade. The methods listed first are simpler and more reliable, and you should consider them in preference to those methods listed later.

Important: Before starting any upgrade for which you want to retain the existing configuration, you must create a backup copy (also known as a configuration archive or user configuration set (UCS) archive) of the BIG-IP system you are upgrading. For BIG-IP LTM 9.1.1 and later, regardless of the installation method used, all configuration data and software on the target slot chosen for installation will be discarded unless you first create a configuration archive named config.ucs and place it in the / directory, then choose to roll forward your configuration when prompted by the installation utility. If the /config.ucs archive file is not present, you will not be presented with a Saved Configuration option while performing the installation and the existing configuration will not be rolled forward. 

Important: Depending on your hardware platform and partitioning scheme, the /shared partition, which contains your logs, USC archives, and data from /var/tmp, may not be reformatted. For instructions about backing up configuration files, refer to K3499: Backing up and restoring BIG-IP 9.x configuration files. For more information about choosing a partition scheme for the system, refer to K7608: Choosing a partition scheme while upgrading to BIG-IP 9.3.1 or 9.4.2 through 9.4.8.

Note: For more information, refer to the following articles:

  • K3621: Reinstalling BIG-IP LTM, ASM, GTM, PSM, APM, WOM, Link Controller, WebAccelerator, or Edge Software
  • K7473: Downgrading BIG-IP software (9.x)

IM installation method and the location installation method

Note: The local installation method was referred to as the IM installation method in BIG-IP 9.0.0 through 9.1.0.

The local installation method provides the ability to install or upgrade a local BIG-IP software image. This method is the simplest way to install the BIG-IP software, and is the preferred installation method for functional version 9.x systems.

The installation process consists of downloading an Install Manager (IM) local installation package to the BIG-IP system's hard drive and installing it locally with the IM program included with the BIG-IP system.

You may only use this method to install, reinstall, or upgrade BIG-IP software on a system with a pre-existing functional BIG-IP 9.x installation. For new installations, upgrades from BIG-IP 4.x, and re-installations on non-functional BIG-IP 9.x systems, you must choose a different installation method.

Important: This installation method requires between 80 and 150 MB of free drive space, depending on the software release. Some platforms may lack the disk space needed for this installation method. In these cases, you must choose a different installation method.

Note: For more information about this installation method, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, or WebAccelerator release notes.

Remote installation method

The remote installation method provides you the ability to install the software from another system that is accessible from the BIG-IP system. This method is the preferred installation method for functional BIG-IP 9.x systems when limited disk space prevents the use of the local installation method.

The installation process consists of downloading an ISO image, burning a boot CD from it, and booting a remote host from it to serve as the installation server. You then download an IM remote install package to the BIG-IP's hard drive and run the IM program included with BIG-IP to extract the install image from the remote host.

You may only use this method to install, reinstall, or upgrade BIG-IP software on a system with a pre-existing functional BIG-IP 9.x installation. For new installations, upgrades from BIG-IP 4.x, and reinstallations on non-functional BIG-IP 9.x systems, you must choose a different installation method.

Important: This installation method requires between 15 and 30 MB of free drive space, depending on the software release.

Note: The remote installation method requires a CD-bootable system residing on the BIG-IP management network, which will be temporarily dedicated to the installation process.

Note: For more information about this installation method, refer to the Remote Installation: Upgrading the BIG-IP software release notes.

USB CD-ROM installation method

The USB CD-ROM installation method provides you the ability to install the software from a USB CD-ROM drive that is connected to the BIG-IP system's USB port. F5 also recommends this method when limited disk space prevents the use of the local installation method.

The installation process consists of downloading an ISO image and burning a bootable CD from it, then booting BIG-IP from the CD using a supported USB CD-ROM drive and following the installation prompts.

You may use this method when performing a reinstallation or a clean installation of BIG-IP software, recovering a non-functional BIG-IP installation, or upgrading an existing system from any version.

Note: USB CD-ROM installation is not supported on the BIG-IP 1000, 2400, 5100, 5110, and 4100 series platforms. Additionally, the BIG-IP 8400 and 8800 platforms may fail to boot to USB CD-ROM. For more information, refer to K9399: BIG-IP 8400 and 8800 systems may not allow booting from some USB devices.

Note: For more information about this installation method, refer to K9589: Installing BIG-IP software from a USB CD-ROM drive.

USB mass storage installation method

The USB mass storage installation method provides you the ability to install the BIG-IP software from a locally connected USB mass storage device onto a BIG-IP system.

This installation process consists of downloading a bootable ISO image, loading it onto the USB device, then booting the BIG-IP system from it and following the installation prompts.

You may use this method when performing a reinstallation or a clean installation of BIG-IP software, recovering a non-functional BIG-IP installation, or upgrading an existing system from any version.

Note: Some flash drives may not be compatible with the BIG-IP BIOS.

Note: While smaller capacity devices are supported, F5 recommends that you use a device with at least 1 GB capacity.

Important: The USB storage device will be formatted before the install boot image is loaded on it.

Important: To ensure proper formatting of the USB storage device, F5 recommends that you use the BIG-IP system, rather than a Windows system, to transfer the installation image to the USB storage device.

Note: For more information about this installation method, refer to the Installing BIG-IP software from a USB Mass Storage Device release note.

PXE installation method

The Pre-Boot Execution Environment (PXE) installation method provides you the ability to automatically configure another system that is accessible from the BIG-IP system as a temporary PXE boot server hosting the BIG-IP LTM installation image, and install the software from the PXE boot server.

The installation process consists of downloading an ISO image, burning a boot disk, then using it to temporarily boot another system as the image server. Once the image server is available on the network, the BIG-IP system is configured to boot from the network, and automatically installs the PXE-supplied image.

You may use this method when performing a reinstallation or a clean installation of BIG-IP software, recovering a non-functional BIG-IP installation, or upgrading an existing system from any version. This method is supported on all platforms, and multiple systems can be upgraded at one time from the same image.

Note: Platforms running AOM 1.0 must be running a functional version of BIG-IP software to use the PXE installation method. For more information, refer to K9599: Configuring AOM based BIG-IP platforms to boot from a network boot server.

Note: The PXE installation requires a system with a supported network card. This system must be on the same network as the BIG-IP system, and must be temporarily dedicated to the installation process. For more information, refer to K3469: Hardware requirements for the BIG-IP network boot server.

Note: For information about configuring the BIG-IP system to boot from the PXE server, refer to K3525: Configuring SCCP-based BIG-IP platforms to boot from a network boot server.

Note: For more information about this install method, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, or WebAccelerator release notes.

Windows hosted installation

The Windows hosted installation method provides the ability to install the BIG-IP software from the CD-ROM drive of a Windows XP host machine onto a BIG-IP system.

The installation process consists of downloading an ISO image, burning the image onto a CD, mounting the CD in a Windows host, running big-ip_setup.exe, and following the installation prompts.

You may only use this method to install, reinstall, or upgrade BIG-IP software on a system with a pre-existing functional BIG-IP 9.x installation. For new installations, upgrades from BIG-IP 4.x, and reinstallations on non-functional BIG-IP 9.x systems, you must choose a different installation method.

Note: Several ports may need to be allowed in Windows Firewall for this installation method to succeed.

Note: For more information about this installation method, refer to Windows Hosted Installation: Upgrading the BIG-IP software release note.
