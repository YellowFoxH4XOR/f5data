Known Issue

SmartAccess filters in the BIG-IP APM system may not activate some Citrix policy options.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is integrated with Citrix XML Brokers and presents Citrix published applications on a webtop.
  • Your BIG-IP APM access policy is configured with SmartAccess filters which control ICA session behavior.

The BIG-IP APM system supports Citrix SmartAccess filters when integrating with Citrix Web Interface sites and XML Brokers. Citrix uses SmartAccess filters to control access to the application and control ICA session behavior when the application is launched. When integrating the BIG-IP APM system with Citrix XML Brokers (replacement mode) to display Citrix published applications on a webtop, SmartAccess filters may not enforce Citrix policy options used to control ICA session behavior.

Impact

Citrix policy options used to control ICA session behavior, such as client clipboard, are not enforced.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Application access control based on SmartAccess filters works properly but ICA session behaviors based on SmartAccess filters fail to function properly.
  • Citrix policy options available for use with XenApp or XenDesktop fail to function properly.

    For example, users are unable to cut and paste between the local desktop and the ICA session.

Workaround

To work around this issue, you can use an iRule to add SessionContextEntry attributes to the session.citrix.smart_access variable. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules > iRule List.
  3. Click Create.
  4. In the Name box, type ID435455.
  5. In the Definition box, paste the following rule:

    when ACCESS_POLICY_COMPLETED {
    ACCESS::session data set session.citrix.smart_access {
    <SessionContextEntry name="Citrix.SessionProductType">MSAM</SessionContextEntry>
    <SessionContextEntry name="Citrix.Condition">wi-direct</SessionContextEntry>
    }
    }

  6. Click Finished.
  7. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
  8. Click the Edit link under Resources for the affected virtual server.
  9. In the iRules section, click Manage.
  10. Select the newly created iRule and move it to the Enabled box.
  11. Click Finished.
