Topic

You can update the predefined browser strings in the BIG-IP WebAccelerator Policy Editor by manually specifying a regular expression for the User Agent setting. 

For example, you may need to update the User Agent list to include all versions of Internet Explorer and Firefox.

To update the User Agent list, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator Configuration utility.
  2. Edit a policy.

    The Matching Rules screen appears.
  3. Select User Agent from the Add Parameter drop-down box.
  4. Click the Add button.
  5. In the Value(s) section, click the arrow next to Enter a regular expression.
  6. Modify the the list of User Agents to include a regular expression for the desired User Agent values.
  7. To save changes to the policy, click Update.
