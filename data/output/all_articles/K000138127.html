K000138127: Number of boot locations supported on F5OS-A tenants

Source

Description

You would like to know the number of supported boot locations for F5OS-A tenants.

Environment

  • F5OS
  • Tenant
  • Boot location

Cause

T1 Tenant image types - Only one software volume or boot location is available.
T2 Tenant image types - This image size supports two software volumes or boot locations.
ALL Tenant image types - This image size supports two software volumes or boot locations.
T4 Tenant image types - This image size supports two software volumes or boot locations.

Recommended Actions

Although you can create more than two boot locations, only two are supported for T2, ALL, and T4.

These images can only support two boot locations due to the size of the images and the growth of the tenants. For example, additional disk space might be needed for things like logs after they have been running for a while.
