Known Issue

When using the GENERICMESSAGE iRule, the BIG-IP system experiences a high CPU load if the virtual server receives multiple responses while an asynchronous Tool Command Language (Tcl) command is running.

This issue occurs when all of the following conditions are met:

  • You have associated a virtual server with an iRule that uses the GENERICMESSAGE command and asynchronous Tcl commands.
  • The virtual server receives multiple responses.

Impact

The system might experience a high CPU load, as multiple responses are assigned the same request_sequence_number.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You observe the system experiencing a high CPU load when you use the GENERICMESSAGE iRule if the virtual server receives multiple responses while an asynchronous Tcl command is running.
