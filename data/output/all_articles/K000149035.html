Description

  • In Security  ››  Event Logs : Application : Requests, few or no event logs are shown.
  • Relevant event logs are only shown when log filters are keyed in.
  • GUI Message is shown after the log search: "This request is not shown in the list because it was stored only for Traffic Learning"

Environment

  • ASM module is enabled.
  • Logging profile is configured in Virtual Servers.
  • Policy Learning is enabled.

Cause

This is caused by having too many learning suggestions, which reserved logs for traffic learning.

Recommended Actions

  1.  Remove/Make decisions on learning suggestions on ASM policies.

Additional Information

None.
