Topic

When editing iRules at the command line, it may be difficult to properly represent special characters or to enter a long iRule using the bigpipe rule command. As an alternative, you may use the bigpipe merge command to export and import standard text files containing the literal iRule code.

To export, edit, and import an existing iRule at the command line, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. To export the existing iRule, use the following command syntax, replacing <longrule> with the name of the iRule you want to edit:

    bigpipe rule <longrule> list > /var/tmp/longrule_edit.irule
  3. Edit the iRule in the text file and save it.
  4. To re-import the modified iRule, type the following command:

    bigpipe merge /var/tmp/longrule_edit.irule
  5. To save the modified configuration, type the following command:

    bigpipe save all
