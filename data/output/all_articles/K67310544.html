Issue

Description

  • When using Security Assertion Markup Language (SAML) on the BIG-IP as Identity Provider (IdP) or Service Provider (SP), for SAML sessions to be properly and completely removed from both the IdP and SP, single logout URLs need to be configured.
  • Single logout behaves the same as SAML login; there is a SAMLRequest and a SAMLResponse containing logout information for that user.

Environment

  • BIG-IP APM configured as SAML IdP or SP

Cause

When single logout must be configured or sessions will not be removed properly from SAML Sessions. The single logout binding method must match the URL action: POST binding must use the POST URL and redirect binding must use the redirect URL.

Recommended Actions

Configure the single logout URLs on the BIG-IP APM system as follows:

Service Provider settings for SLO

Redirect Binding URLs for SLO:

  • Settings for SP Single Logout Request:

    https://idp.hostname.com/saml/idp/profile/redirect/sls
      
  • Settings for SP Single Logout Response:

    https://idp.hostname.com/saml/idp/profile/redirect/slr


POST Binding URLs for SLO:

  • Settings for SP Single Logout Request:

    https://idp.hostname.com/saml/idp/profile/post/sls
  • Settings for SP Single Logout Response:

    https://idp.hostname.com/saml/idp/profile/post/slr


BIG-IP as Identity Provider settings for SLO

Redirect Binding URLs for SLO:

  • Settings for IdP Single Logout Request:

    https://sp.hostname.com/saml/sp/profile/redirect/sls
     
  • Settings for IdP Single Logout Response:

    https://sp.hostname.com/saml/sp/profile/redirect/slr


POST Binding URLs for SLO:

  • Settings for IdP Single Logout Request:

    https://sp.hostname.com/saml/sp/profile/post/sls
     
  • Settings for IdP Single Logout Response:

    https://sp.hostname.com/saml/sp/profile/post/slr


Additional Information

BIG-IP SAML services must configure a Logout URI Include to trigger single logout in the access policy
