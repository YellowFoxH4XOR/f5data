K7327: Closing the FirePass Webtop when running Network Access produces a pop-up warning

Type
Knowledge
Published
2007-05-02
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 6.0.1, 6.0.0
Source
https://my.f5.com/manage/s/article/K7327

Issue

In FirePass 6.0.0 and later, when you run Network Access from the FirePass Webtop, then close the browser window that runs the Webtop, you will receive a warning pop-up message similar to the following example:

You closed the window containing the Firepass webtop. Do you want to close current application tunnel/VPN connection?

Clicking Cancel will allow you to continue using Network Access. Clicking Ok will close the Network Access connection.

In FirePass 5.x, closing the browser with the Webtop would not generate a warning pop-up message, and the Network Access tunnel would continue to run.
