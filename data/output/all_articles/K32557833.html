Description

UDP port 4353 is opened on self IP address which has been configured as Allow Default for its Port Lockdown.

Environment

  • BIG-IP
  • Allow Default for the Port Lockdown on the Self IP address.

Cause

None.

Recommended Actions

When you have chosen Allow Default for the Port Lockdown of a Self IP address, you can use Packet Filter option to block UDP port 4353.
Note: This option will block UDP port 4353 for all Self IP addresses.
Important: Enabling packet filtering can impact system performance.

  1. Login to the F5 BIG-IP GUI.
  2. Navigate to Network  >  Packet Filters > General.
  3. Change Packet Filtering option to Enable.
  4. Navigate to Network  >  Packet Filters > Rules.
  5. Click Create.
  6. In Name, enter Block_UDP_4353.
  7. In Order, select any option. This can be changed later.
  8. In Protocols, select UDP in the selected Protocols.
  9. In Destination Port, type 4353 and click Add.
  10. Click Finished.
  11. You will go back to the Packet Filters Rule screen and see Block_UDP_4353.
  12. Click Block_UDP_4353 to confirm if UDP port 4353 is configured.
Alternatively, you can use the Traffic Management Shell (tmsh) command-line utility.
 
  1. Open the Traffic Management Shell (tmsh).
    tmsh
     
  2. To remove a configured protocol and port from the default self-allow list, use the following command syntax:
    tmsh modify /net self-allow defaults delete { <PROTOCOL>:<PORT> }
    For example, use the following command to block UDP port 4353:
    modify /net self-allow defaults delete { udp:4353 }
     
  3. Save the configuration:
    save sys config

None.
