K000092506: Unable to change the Netmask of management IP

Type
Support Solution
Published
2022-10-27
Updated
2023-02-16
Source
https://my.f5.com/manage/s/article/K000092506

Description

When you want to keep the same management IP address and change just Netmask using tmsh commands, you will receive below error:

 

[root@DC06F5B:Active:In Sync (Sync Only)] config # tmsh create /sys management-ip 10.119.6.5/28

01020037:3: The requested management IP (10.119.6.5) already exists.

 

Environment

  • BIG-IP command line
  • Running config command

 

Recommended Actions

You can change the netmask from F5 Management Port Setup Utility option. Please follow below instructions:

  1. Log in to the command line of the BIG-IP system, type 'config', you'll get a blue screen that says 'Configuration Utility'.
  2. select 'OK'.
  3. Select IPv4.
  4. Select 'NO' for 'Use automatic configuration of IP address?'
  5. Skip the IP address configuration since this does not require a change.
  6. You'll see the 'Configure Netmask' option. Modify the netmask and then click 'OK'. Everything else should stay as is since the only thing you need to modify is the netmask.
  7. Accept the settings and validate that the netmask is correct now by running below command:

tmsh list /sys management-ip

 

Note: In some cases when you have management routes present on the device, you might receive below error when changing the Netmask:

 

ERROR: route_mgmt_entry count is greater than 2:x

 

x represents the total number of management routes which has been configured. For example, if you have 8 management route configured, the error message is:

 

ERROR: route_mgmt_entry count is greater than 2:8

 

In this case, please refer the steps provided in article: K53323542: Not able to access BIG-IP "config" tool with meesage ERROR: route_mgmt_entry count is greater than 2:x
