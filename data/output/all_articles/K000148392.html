K000148392: How to install a specific NGINX version on Ubuntu

Type
Support Solution
Published
2024-11-05
Updated
2024-11-05
Applies to
  • NGINX Products
  • NGINX Plus: R26, R29, R28, R27, R31, R30, R32
  • NGINX Instance Manager
Source
https://my.f5.com/manage/s/article/K000148392

Description

  • You have Ubuntu/Debian as the underlying Linux distribution.
  • You follow NGINX installation guide to install NGINX Plus.
  • But, you want to install a specific NGINX version as opposed to the latest. 

Environment

  • Ubuntu
  • NGINX Plus
  • Instillation

Cause

  • None

Recommended Actions

  • To install or downgrade to a specific NGINX version
  • Implement step 1 (one) to 10 (ten) as described in NGINX installation guide
  • With steps 10 completed and repository updated
    • You should now be able to list all available Nginx version that can be installed on your Ubuntu instance. To do so follow command
                    sudo apt-cache madison nginx-plus
  • To install a specific version, append NGINX version with "apt install" command as shown below
                    sudo apt install nginx-plus=<nginx-version>

Example

  • To install say version R30, use apt install command as shown below
                    sudo apt install nginx-plus=30-2~jammy

Additional Information

  • The procedure to install a specific version is NOT specific to NGINX but rather dependent to the underlying operating system.
