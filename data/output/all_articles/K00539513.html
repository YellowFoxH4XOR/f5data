Known Issue

The Master Control Program Daemon (MCPD) may log benign error messages when Enterprise Manager discovers a BIG-IP LTM device.

This issue occurs when all of the following conditions are met:

  • You are using Enterprise Manager to manage one or more remote BIG-IP LTM devices.
  • The devices are running BIG-IP 11.6.0 through 11.6.3.
  • One of the following actions occurs:
    • Enterprise Manager discovers a BIG-IP LTM device for the first time.
    • A BIG-IP LTM device undergoes a periodic refresh or rediscovery.
    • Enterprise Manager notices a BIG-IP LTM configuration change.

Impact

There is no impact. The benign error messages should not impact system performance.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/ltm file, you observe error messages that appear similar to the following example:

    0107167d:3: Data publisher not found or not implemented when processing request (unknown request), tag (234567).
