Description

Unable to find the Dowloads location during the BIG-IP software download at https://my.f5.com/manage/s/downloads

The dropdown does not display any server download locations.

Environment

  • Software Download at https://my.f5.com/manage/s/downloads

Cause

This problem could be due to the browser configuration.

Recommended Actions

  • Download the file using a different browser.
  • Try downloading the file using incognito mode.
  • Try accessing the page without any extension enabled in your browser.
  • Wait an hour and try downloading the software image again if it persists. 
  • If the downloads location box is not populated after the above recommendations. Contact F5 Support K000135931: Contact F5 Support
