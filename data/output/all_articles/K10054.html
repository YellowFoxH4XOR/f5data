Topic

The BIG-IP system supports the certificate revocation list (CRL) file sizes listed in the following table.

BIG-IP versionMaximum PEM file sizeMaximum DER file size
17.0.0 - 17.1.x192 MB192 MB
16.0.0 - 16.1.x192 MB192 MB
15.0.0 - 15.1.x192 MB192 MB
14.0.0 - 14.1.x48 MB48 MB
13.0.0 - 13.1.x48 MB48 MB
12.0.0 - 12.1.x48 MB48 MB
11.4.0 - 11.6.x48 MB48 MB
11.0.0 - 11.3.x24 MB24 MB
10.0.0 - 10.2.x3 MB2.25 MB

Note: A known issue exists where the BIG-IP system may only partially read a large CRL file that you upload resulting in unexpected results when users connect to a virtual server that has the affected SSL profile. For more information, including the workaround, refer to ID 1316481 on bug tracker.

Recommendations

When installing CRL files on your BIG-IP system, consider the following:

  • If you attempt to load an SSL profile with a CRL file larger than the aforementioned limits, an error message that appears similar to the following example is logged to the /var/log/ltm file:

    01260018:3: OpenSSL: error:0906D041:PEM routines:PEM_read_bio:malloc failure

  • The BIG-IP system must have sufficient memory available to allocate the CRL file into memory. 

    Note: 85,000 serial numbers use approximately 4 MB of a CRL file.

  • You can use the following tmsh commands to install CRLs on the BIG-IP system. For large CRL files, F5 recommends you use the first command to install, using from-local-file.
    • To install the CRL from the local path where the CRL is present locally on the system, enter the following command:

      install sys crypto crl <crl.tmp> from-local-file <filepath>

    • To download the CRL and install it from the URL provided, enter the following command:

      install sys crypto crl <crl.tmp> from-url <URL of CRL>

      Note: When using this method, especially for large (around 45 MB or more) CRL files, you should consider external factors that could affect the CRL maximum file size, such as network bandwidth, connectivity and BIG-IP CPU usage, and other system resources.
