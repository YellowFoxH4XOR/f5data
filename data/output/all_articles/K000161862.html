K000161862: BIG-IQ or BIG-IP local “root” fails to login via SSH with Putty Fatal Error

Type
Support Solution
Published
2026-06-23
Updated
2026-06-23
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.1
Source
https://my.f5.com/manage/s/article/K000161862

Description

When trying to SSH into BIG-IQ or BIG-IP using local “root” via SSH you may see an error similar to No supported authentication methods available (server sent: publickey,keyboard-interactive,hostbased)

 

 

Environment

  • BIG-IQ or BIG-IP
  • SSH using local “root”
  • Disabled “root” login via sys db systemauth.disablerootlogin
# tmsh list /sys db systemauth.disablerootlogin
 sys db systemauth.disablerootlogin {
 default-value "false"
 scf-config "true"
 value "true" <----- this is going to prevent "root" from logging in
 value-range "false true"
}

Cause

This is by design.

Answer/Recommended Actions

To check the current setting:

# tmsh list /sys db systemauth.disablerootlogin

If value is "true" and you want to be able to login using “root” then set the value back to the default value of “false”

# tmsh modify sys db systemauth.disablerootlogin value false
# tmsh save sys config

If sys db systemauth.disablerootlogin value is “false” then check the sshd allow list:
K5380: Specify allowable IP ranges for SSH access
