Description

When the ipother protocol profile is applied to a virtual server that processes TCP or UDP traffic, it may result in slow traffic through the virtual server.

Environment

A virtual server configured with the following:

  • Protocol is set to any protocol, e.g. 1344 for ICAP, or to *All Protocols
  • Any IP Profile is set to ipother

Cause

The ipother profile is for use only with non-TCP and non-UDP traffic; it is not intended nor optimized for TCP or UDP traffic.

Recommended Actions

Configure the protocol on the virtual server to what matches the traffic that will be passing through. If you need to load balance both TCP and UDP traffic you will need to create separate virtual server; the BIG-IP allows for virtual servers to have the same IP and port but a different protocol.
