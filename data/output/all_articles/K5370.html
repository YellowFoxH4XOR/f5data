Known Issue

This is the result of a known issue. If you have a single virtual server and you enter the VS Dependencies page in the Configuration utility and click the add button, you will receive the following error message:

Line 52
Error:  Object doesn't support this property or method

This error occurs when you attempt to add a virtual server that does not exist as a virtual server dependency. This error is cosmetic and does not impact the performance of the 3-DNS Controller.

F5 Networks Product Development tracked this issue as CR18859.
