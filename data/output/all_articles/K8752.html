K8752: Clustered Multi-Processing is automatically disabled for CMP capable platforms licensed and enabled with BIG-IP WebAccelerator 9.x

Note: This article applies only to the following BIG-IP platforms running version 9.x code:

  • BIG-IP 1600
  • BIG-IP 3600
  • BIG-IP 3900
  • BIG-IP 4500
  • BIG-IP 6900
  • BIG-IP 8400
  • BIG-IP 8800
  • BIG-IP 8900

Note: For more information, refer to K7751: Overview of Clustered Multi-Processing.

Clustered Multi-Processing (CMP) is automatically disabled globally for a CMP capable platform when all of the following conditions are met:

  • The BIG-IP system is licensed for the BIG-IP WebAccelerator
  • The BIG-IP WebAccelerator module is enabled

When this issue occurs, the highest numbered CPU is reserved for exclusive use by the TMM process, and the remainng processors are reserved for use by the host operating system and the BIG-IP WebAccelerator processes. You can identify this behavior using the top command. For example, on a BIG-IP 3600 platform that has two CPU cores, the top command shows the TMM process is assigned exclusively to CPU 1 while the main BIG-IP WebAccelerator pvac process is sharing CPU 0 with the rest of the host operating system processes:

Note: The top output is truncated for brevity.

  PID USER     PRI  NI  SIZE  RSS SHARE STAT %CPU %MEM   TIME CPU COMMAND
 1962 root      25   0 2961M 2.9G 2956M R    50.2 78.6   5:01   1 /bin/tmm -m -s 2944
 1963 root      15   0 18316  17M  9164 S     0.0  0.4   0:00   0 /usr/bin/pvac -f /config/wa/pvsystem.conf
 1590 root      15   0  1336 1336   876 S     0.0  0.0   0:00   0 /usr/sbin/syslog-ng -p /var/run/syslog-ng.pid
 1756 ntp       15   0  2564 2564  2192 S     0.0  0.0   0:00   0 ntpd -c /config/ntp.conf -U ntp -p /var/run/ntpd.pid -g

Note: The BIG-IP system does not disable CMP if the WebAccelerator module is disabled on a BIG-IP system licensed with BIG-IP WebAccelerator.

You can re-enable CMP by disabling the WebAccelerator module. To do so, perform the following procedure:

Impact of procedure: Disabling the WebAccelerator module will prevent the WebAccelerator from performing any web acceleration. Rebooting the system will disrupt traffic processing until it is up.

Disabling the WebAccelerator module using the Configuration utility

  1. Log in to the BIG-IP Configuration utility.
  2. Click System.
  3. Click License.
  4. Click Modules.
  5. Select Disabled from the WebAccelerator box.
  6. Click Update.
  7. Reboot the BIG-IP system.

Disabling the WebAccelerator module using the command line

  1. Log in to the command line.
  2. Type the following command to disable the WebAccelerator module:

    bigpipe db Module.WA disable

  3. Type the following command to reboot the BIG-IP system:

    reboot
