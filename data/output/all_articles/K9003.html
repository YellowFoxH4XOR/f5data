Topic

If you use dynamic group mapping with an Active Directory (AD) mapping method, you can optionally configure FirePass to synchronize its local user database with the AD server. When you enable this feature, FirePass queries the AD server at an interval you configure, and deactivates or deletes local accounts that are no longer present on the AD server. For this feature to work properly, you must configure at least one master group that uses local users and AD authentication. 

Important: If you configure FirePass to synchronize the local user database with AD, FirePass only deactivates or deletes local accounts that were created by AD authentication.
 
You can configure FirePass to synchronize the local user database with an AD server by performing one of the following two procedures, depending on which version of FirePass you are running:

Note: This procedure assumes that you already configured dynamic group mapping with an AD mapping method. For information about configuring dynamic group mapping with an AD mapping method, refer to the FirePass Controller Administrator Guide.
 
FirePass version 6.x:
 
  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users : Groups : Dynamic Group Mapping page.
  3. Click the Group mapping methods tab.
  4. Next to Active Directory, click the Configure link.
  5. Select the Synchronize FirePass user database with Active Directory check box.
  6. Click the Update button.

    The page refreshes, and displays additional options.
  7. Under the Synchronize FirePass user database with Active Directory check box, select the action appropriate for your environment in the Action menu.

    For example:

    Deactivate FirePass account if user is not in Active Directory
     
  8. Optionally, if you want FirePass to notify users when their accounts are deactivated or deleted, select the Notify by e-mail check box.
  9. In the Check interval (min) field, enter the frequency (in minutes) with which FirePass should query the AD server.
  10. Click the Update button.
  11. Optionally, if you want FirePass to synchronize user information (such as name and email address) with the AD server, select the Update user information from Active Directory check box.

    If you do not want FirePass to synchronize user information with the AD server, this procedure is complete.
     
  12. Click the Update button.

    The page refreshes, and displays additional options.
  13. Under the Update user information from Active Directory check box, select the account options you want FirePass to synchronize.

    For example:

    Map first name
    Map last name
    Map e-mail
  14. Click the Update button.
 
FirePass version 5.5.x
 
  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users: Groups: Dynamic Group Mapping page.
  3. Click the Request configuration tab.
  4. In the Select method to configure request menu, select Active Directory.
  5. Click the Switch button.
  6. Select the Synchronize FirePass user database with Active Directory check box.
  7. Click the Update button.

    The page refreshes, and displays additional options.
  8. Under the Synchronize FirePass user database with Active Directory check box, select the action appropriate for your environment in the Action menu.

    For example:

    Deactivate FirePass account if user is not in Active Directory
  9. Optionally, if you want FirePass to notify users when their accounts are deactivated or deleted, select the Notify by e-mail check box.
  10. In the Check interval (min) field, enter the frequency (in minutes) with which FirePass should query the AD server.
  11. Click the Update button.
