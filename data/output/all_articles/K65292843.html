Topic

You should consider using this procedure under the following conditions:

  • You want to configure a custom cipher group for an SSL profile.
  • You want to perform the related tasks using the TMOS Shell (tmsh).

Note: To perform these tasks using the Configuration utility, refer to K10866411: Creating a custom cipher group using the Configuration utility.

Description

Beginning in BIG-IP 13.0.0, you can use cipher groups to specify which cipher suites are allowed when the BIG-IP system negotiates new SSL connections. Cipher groups allow you to select from cipher rules, or sets of cipher suites, to allow, restrict, or exclude those sets of cipher suites used by SSL profiles when processing new SSL connections. If the cipher rules provided by F5 do not meet your configuration requirements, you can create custom cipher rules. Understanding the following terms can be helpful when managing cipher groups and cipher rules:

  • Cipher suite

    A set of authentication, encryption, media access control (MAC), and key exchange algorithms used when negotiating a new SSL connection.

  • Cipher rule or Cipher string

    A configuration object representing a list of cipher suites.

  • Cipher group

    A configuration object representing a list of cipher rules.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have basic knowledge of SSL cipher suites and protocols.
  • You have access to the tmsh utility.

Procedures

  • Allowing ciphers
  • Restricting ciphers
  • Excluding ciphers
  • Creating cipher rules
  • Viewing cipher suite lists

Allowing ciphers

When creating a custom cipher group, you must first add one or more cipher rules to the Allow list. To do so, perform the following procedure:

Important: F5 strongly recommends adding the f5-default cipher rule prior to allowing or excluding additional cipher suites.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To create a new custom cipher group that allows cipher suites from one or more cipher rules, use the following command syntax:

    Important: To add a custom cipher rule, use the Creating cipher rules procedure.

    create ltm cipher group <name> allow add { <cipher_rule1> <cipher_rule2> }

    For example, to create a cipher group named example_cipher_group that allows cipher suites from the f5-default and f5-ecc cipher rules, type the following command:

    create ltm cipher group example_cipher_group allow add { f5-default f5-ecc }

  3. Verify the cipher group configuration by using the following command syntax:

    list ltm cipher group <cipher_group>

    For example, to verify the cipher rule configuration for a cipher group named example_cipher_group, type the following command:

    list ltm cipher group example_cipher_group

    ltm cipher group example_cipher_group {
        allow {
            f5-default { }
            f5-ecc { }
        }
    }

  4. Save the configuration by typing the following command:

    save sys config

Restricting ciphers

When you restrict cipher suites from the allowed ciphers list, the BIG-IP system chooses only cipher strings that the Allow and Restrict lists have in common. The following table demonstrates the effect of restricting ciphers:

Allow the followingRestrict the Allowed List to the followingAllowed ciphers
AES256-SHA/TLS1.2
AES256-SHA/TLS1.1
CAMELLIA256-SHA/TLS1.2
CAMELLIA256-SHA/TLS1.1		AES256-SHA/TLS1.2
AES256-SHA/TLS1.1		AES256-SHA/TLS1.2
AES256-SHA/TLS1.1

To restrict cipher suites from the allowed ciphers list, perform the following procedure:

Impact of procedure: If the cipher group is not yet associated with an SSL profile, performing the following procedure should not have a negative impact on your system. If the cipher group is associated with an SSL profile, remote clients will be unable to use excluded ciphers for negotiation.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Restrict the cipher suites of a cipher group's allowed ciphers list by using the following command syntax:

    Important: To add a custom cipher rule, use the Creating cipher rules procedure.

    modify ltm cipher group <name> require add { <cipher_rule1> <cipher_rule2> }

    For example, to restrict the allowed cipher suites for a cipher group named example_cipher_group using cipher suites from the f5-aes cipher rule, type the following command:

    create ltm cipher group example_cipher_group require add { f5-aes }

  3. Verify the cipher rule configuration by using the following command syntax:

    list ltm cipher group <name>

    For example, to verify the cipher rule configuration for a cipher group named example_cipher_group, type the following command:

    list ltm cipher group example_cipher_group

    ltm cipher group example_cipher_group {
        allow {
            f5-default { }
            f5-ecc { }
        }
        require {
            f5-aes { }
        }
    }

  4. Save the configuration by typing the following command:

    save sys config

Excluding ciphers

When you exclude cipher suites from the allowed ciphers list, the BIG-IP system removes all cipher suites that appear in the Exclude list from the Allow list. The following table demonstrates the effect of excluding ciphers:

CAMELLIA256-SHA/TLS1.1		CAMELLIA256-SHA/TLS1.2
CAMELLIA256-SHA/TLS1.1		AES256-SHA/TLS1.2
AES256-SHA/TLS1.1

To restrict cipher suites from the allowed ciphers list, perform the following procedure:

Impact of procedure: If the cipher group is not yet associated with an SSL profile, performing the following procedure should not have a negative impact on your system. If the cipher group is associated with an SSL profile, remote clients will be unable to use excluded ciphers for negotiation.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Exclude cipher suites from a cipher group's allowed ciphers list by using the following command syntax:

    Important: To add a custom cipher rule, use the Creating cipher rules procedure.

    modify ltm cipher group <name> exclude add { <cipher_rule1> <cipher_rule2> }

    For example, to exclude the allowed cipher suites for a cipher group named example_cipher_group using cipher suites from the f5-hw_keys cipher rule, type the following command:

    create ltm cipher group example_cipher_group require add { f5-hw_keys }

  3. Verify the cipher rule configuration by using the following command syntax:

    list ltm cipher group <name>

    For example, to verify the cipher rule configuration for a cipher group named example_cipher_group, type the following command:

    list ltm cipher group example_cipher_group

    ltm cipher group example_cipher_group {
        allow {
            f5-default { }
            f5-ecc { }
        }
        exclude {
            f5-hw_keys { }
        }
        require {
            f5-aes { }
        }
    }

  4. Save the configuration by typing the following command:

    save sys config

Creating a custom cipher rule

F5-provided cipher rules are based on the following cipher strings:

Cipher ruleCipher string
f5-aesAES
f5-defaultDEFAULT
f5-eccECDHE:ECDHE_ECDSA
f5-hw_keysECDHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-SHA384:ECDHERSA-AES256-CBC-SHA:DHE-RSA-AES256-GCM-SHA384:DHE-RSA-AES256-
SHA256:DHE-RSA-AES256-SHA:ECDH-RSA-AES256-GCM-SHA384:ECDHRSA-AES256-SHA384:ECDH
f5-secureECDHE:RSA:!SSLV3:!RC4:!EXP:!DES

If the F5-provided cipher rules do not meet your configuration requirements, you can create a custom cipher rule. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Create a new custom cipher rule by using the following command syntax:

    create ltm cipher rule <name> cipher '<cipher_string1>:<cipher_string2>'

    For example, to create a cipher rule named example_cipher_rule using the SSLv3 and TLSv1 cipher strings, type the following command:

    Note: This cipher rule can be used in a cipher group to exclude all cipher suites using the SSLv3 and TLSv1 SSL protocols.

    create ltm cipher group example_cipher_rule cipher 'SSLv3:TLSv1'

  3. Verify the cipher rule configuration by using the following command syntax:

    list ltm cipher rule <name>

    For example, to verify the cipher rule configuration for a cipher group named example_cipher_rule, type the following command:

    list ltm cipher rule example_cipher_group

    ltm cipher rule example_cipher_rule {
        cipher SSLv3:TLSv1
    }

  4. Save the configuration by typing the following command:

    save sys config

Viewing cipher suite lists

When creating a custom cipher group or cipher rule, it is helpful to view the specific list of allowed cipher suites. To view the list of cipher suites, you can use the standard or filtered methods. The standard method is easier to perform, but more difficult to read, while the filtered method is more difficult to perform, but easier to read. To view the list of cipher suites for a cipher group or cipher rule, perform one of the following procedures:

Impact of procedures: Performing the following procedures should not have a negative impact on your system.

Standard listing

  1. Log in to tmsh by typing the following command:

    tmsh

  2. View the list of cipher suites for a cipher group or cipher rule by using the following command syntax:

    show ltm cipher <group | rule> <name>

    show ltm cipher rule f5-default

Creating an SSL profile

The SSL profile Cipher option allows you to associate a cipher group to specify which ciphers will be allowed when negotiating new SSL connections. To create a new Client SSL profile with an associated cipher group, perform the following procedure:

Impact of procedure: If the SSL profile is not yet associated with a virtual server, performing the following procedure should not have a negative impact on your system. If the SSL profile is associated with a virtual server, remote clients will negotiate using the Allowed ciphers.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To create a new custom Client SSL profile that allows cipher suites from a cipher group, use the following command syntax:

    create ltm profile client-ssl <name> cipher-group <name>

    For example, to create a Client SSL profile named example_client_ssl that uses a cipher group named example_cipher_group, type the following command:

    create ltm profile client-ssl example_client_ssl cipher-group example_cipher_group ciphers none

  3. Verify the cipher group configuration for the Client SSL profile by using the following command syntax:

    list ltm profile client-ssl <name> cipher-group

    For example, to verify the cipher group configuration for an SSL profile named example_client_ssl, type the following command:

    list ltm profile client-ssl example_client_ssl cipher-group

    ltm profile client-ssl example_client_ssl {
        cipher-group example_cipher_group
    }

  4. Save the configuration by typing the following command:

    save sys config
