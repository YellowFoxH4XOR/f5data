Source

Description

  • Remote authenticated users cannot login using SSH or GUI
  • When trying to login using SSH messages are logged in /var/log/secure

... pam_radius_auth: pam_radius_auth: user ... successfully authenticated

... error: PAM: User account has expired for ... from x.x.x.x

 

Environment

  • BIG-IP with management access configured using remote authentication (e.g. Radius, TACACS, ...)

Cause

Under "External Users" the "Role" was left with "No Access" setting.

Recommended Actions

  1. Configure a "Remote Role Groups" to allow access based on parameters received from the authentication server
    or
  2. Change the "External Users" the "Role" setting to a role to be used by all authenticated users
