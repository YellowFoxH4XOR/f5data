K000149847: How can I deploy a new F5 LTM standalone, but specifying exact availability zone in Azure cloud ?

Description

You need to deploy a new F5 BIG-IP instance in a specific availability zone within the Azure cloud environment. This ensures high availability, redundancy, or adherence to specific workload placement requirements.

Environment

  • Azure Cloud

Cause

The need to deploy a Big-IP instance in a specific availability zone often arises from requirements related to workload segregation, disaster recovery strategies, or compliance with organizational or regulatory policies. Azure provides availability zones as physically separate data centers within a region, ensuring additional fault tolerance for critical applications. Users may not find the availability zone option intuitive or enabled by default unless they are working within a supported region.

Recommended Actions

F5 BIG-IP instances are generally deployed via the Azure Marketplace.

1) Go to Azure Marketplace :

  • Search for "F5 BIG-IP Virtual Edition" or "F5 LTM."

2) Choose Standalone Deployment :

  • Select the standalone version of F5 LTM. This could be BYOL (Bring Your Own License), hourly subscription, or a different licensing model.

3) Configure VM Basics :

  • Provide details such as the virtual machine name, region, and availability zone (e.g., Zone 1, Zone 2, Zone 3) .
    • The "Availability Zone" option appears during the deployment wizard under the Basics tab when enabled in a supported region.
    • Select your preferred zone.
