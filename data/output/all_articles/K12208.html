Known Issue

Note: This issue affects only clustered BIG-IP systems, such as VIPRION systems.

This is the result of a known issue. The VLAN group Proxy Exclusion List configuration stanza is synchronized over to the /config/bigip_base.conf file on all secondary blades. However, the Proxy Exclusion List does not load on secondary blades when configured on a VIPRION cluster with two or more blades. As a result, if a primary blade is removed from the cluster due to a reboot or going offline and any secondary blades take over as the primary blade, the Proxy Exclusion List will appear to be missing from the running configuration.

Note: If a new blade has become primary and the Proxy Exclusion List is missing from the running configuration, you can reload the Proxy Exclusion List by reloading the BIG-IP configuration on the new primary blade. To do so, type the following command while connected to the primary blade:

bigpipe load

F5 Product Development tracked this issue as ID 341404, and it was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP LTM release notes.
