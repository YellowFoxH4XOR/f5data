Known Issue

This is the result of a known issue. The Logic Operation setting for logging profiles specifies whether requests must meet all criteria in the Storage Filter (AND), or only one of the criterion in the Storage Filter (OR) in order for the system to log the requests.

When the OR logic operator setting is defined in a remote logging profile, all requests are logged to the remote logging server instead of the requests defined in the Storage Filter setting.

F5 Product Development tracked this issue as CR97336 and it was fixed in BIG-IP ASM 9.4.7 and 10.0.0. For information about upgrading, refer to the BIG-IP ASM Release Notes.
