Known Issue

This is the result of a known issue. You cannot configure the Windows Remote Management (WinRM) port for a file server using the ARX Manager GUI. However, you can configure the WinRM port for a file server from the command line using the filer-type windows port <port> command.

Note: For more information about the filer-type command, refer to the ARX CLI Reference Guide.

Note: This behavior may result in a related issue in which editing and saving a file server configuration using the ARX Manager GUI causes the port used for WinRM to be set to the default port (80). For information, refer to K12145: The custom port specified for Windows Remote Management is not retained after editing and saving the file server configuration using the ARX Manager GUI.

F5 Product Development tracked this issue as ID 339599 and it was fixed in ARX version 5.2.0. For information about upgrading, refer to the ARX release notes.

Workaround

Customers can work around this issue by using the command line to edit file server (external-filer) configurations.
