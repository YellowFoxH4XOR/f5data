Topic

The BIG-IP DNS system does not support the Sender Protection Framework (SPF) resource record type. The SPF resource record type is defined in RFC 7208, where it is noted that this resource record type is considered deprecated and you should use the TXT record type instead.

Description

You can create a TXT record that contains the required SPF information as specified in RFC 7208. To do so, perform the following procedure:

Adding a TXT record to the ZoneRunner utility

  1. Log in to the Configuration utility.
  2. Navigate to DNS > Zones > ZoneRunner > Resource Record List.
  3. Click the appropriate View Name and Zone Name.
  4. To enter a record for the zone itself, in the Name box, type @.
  5. In the TTL box, type the TTL for the resource record.
  6. In the Type box, click TXT.

    Note: You cannot create the TXT record type in reverse zones under in-addr.arpa.

  7. In the Text box, enter the SPF policy for the domain, enclosed in double quotation marks. The syntax for SPF is described in RFC 7208.
  8. Click Create.

You can test the new TXT record using either of the following procedures:

  • Using dig to test the new TXT record
  • Using nslookup to test the new TXT record

Using dig to test the new TXT record

  1. Log in to the command line of the client system.
  2. To test the record, use the following command syntax:

    dig @<address of BIG-IP DNS server> <domain to be tested> TXT

    For example:

    dig @192.0.2.1 test.example.com. TXT

    Output appears similar to the following:

    ;; ANSWER SECTION:
    test.example.com. 1D IN TXT "v=spf1 mx ptr -all"

Using nslookup to test the new TXT record

  1. Log in to the command line of the client.
  2. To test the record, use the following command syntax:

    nslookup -querytype=TXT <domain to be tested> <address of BIG-IP DNS server>

    For example:

    nslookup -querytype=TXT test.example.com. 192.0.2.1

    Output appears similar to the following:

    Server:   192.0.2.1 Address:  192.0.2.1#53 Non-authoritative answer: test.example.com text = "v=spf1 include:_spf.test.example.com ~all"
