Topic

This article applies to BIG-IP 11.x through 21.x. For information about other versions, refer to the following article:

  • K10635: Determining the BIG-IP model and platform type (9.x - 10.x)

You should consider using this procedure under the following condition:

  • You want to determine the BIG-IP model name and platform type.

Description

BIG-IP platforms are identified by a model name and platform type. The model name and platform type are defined as follows:

  • Model name: The model name identifies the BIG-IP marketing name and is usually a four- or five-digit number. For example, 8900 and 11050 are BIG-IP model names.
  • Platform type: The platform type identifies the BIG-IP chassis, and is usually a letter followed by a two- or three-digit number. For example, D106 and E102 are BIG-IP chassis types.

You can determine the model and type of BIG-IP hardware platform by using the TMOS Shell (tmsh), Simple Network Management Protocol (SNMP), the iControl REST API, the Configuration utility, or by physically inspecting the system. To do so, perform one of the following procedures.

Prerequisites

You must meet one of the following prerequisites to use this procedure:

  • You can access tmsh.
  • You can access the Configuration utility.
  • You have access to another system with the curl and jq utilities installed.
  • You have physical access to the system.

Procedures

  • Determine the BIG-IP model name and platform type using tmsh
  • Determine the BIG-IP model name and platform type using SNMP
  • Determine the BIG-IP model name and platform type using the iControl REST API
  • Determine the BIG-IP model name and platform type using the Configuration utility (GUI) (video)
  • Determine the BIG-IP model by physical inspection

Important: For VIPRION systems, to determine the model and type for each blade, you must log into to each blade individually before using tmsh or SNMP commands.

Determine the BIG-IP model name and platform type using tmsh

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To display the BIG-IP model and platform type, enter the following command:

    show /sys hardware

    The command output displays the model and platform type.

    For example:

    Platform
      Name           BIG-IP 3900
      BIOS Revision  F5 Platform: C106 OBJ-0314-03 BIOS (build: 008) Date: 12/28/09
      Base MAC       0:1:d7:e9:e2:80

    System Information
      Type                       C106
      Chassis Serial             f5-jfkw-gcwy
      Level 200/400 Part         200-0322-03 REV C
      Switchboard Serial
      Switchboard Part Revision
      Host Board Serial
      Host Board Part Revision

    This example of command output indicates that the marketing name is BIG-IP 3900, and the platform type is C106.

    Note: You can also use the tmsh command with the field-fmt option to grep for the information.

    For example:

    (tmos)# show /sys hardware field-fmt | grep -e platform -e marketing

    sys hardware platform {
        marketing-name BIG-IP 3900
        platform C106

Determine the BIG-IP model name and platform type using SNMP

The following MIB OIDs, located in the F5-BIGIP-SYSTEM-MIB file, can be used to query the system for the Platform ID and Platform Name:

  • sysGeneralHwName - Displays the name of the system hardware model.
  • sysPlatformInfoMarketingName - Displays the system name used by marketing.

Determine the BIG-IP model name and platform type using the iControl REST API

Performing the following procedure requires command-line access to a system with the curl utility and, optionally, the jq (command line JSON processor) utility installed. These utilities are commonly available on Linux systems, but can also be installed on Microsoft Windows and Mac OS X systems. Additionally, you can perform this procedure from an alternate BIG-IP system; however, the jq utility is not available on systems running versions prior to BIG-IP 12.0.0. You can still use the curl portion of commands, but the resulting output is a single string, rather than formatted JSON.

For more information about the jq utility, refer to https://stedolan.github.io/jq.

Note: This link takes you to a resource outside of AskF5. The third party could remove the document without our knowledge.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. To view the model name and platform type for the specified BIG-IP system, use the following command syntax:

    curl -sku <username>:<password> -X GET https://<BIG-IP hostname or mgmt IP address>/mgmt/tm/sys/hardware/ | jq '.entries."https://localhost/mgmt/tm/sys/hardware/platform", .entries."https://localhost/mgmt/tm/sys/hardware/system-info"'

    For example, to view the model name and platform type on a BIG-IP system with a host name of LTM1.example.com, an administrative username admin, and administrative password testing, enter the following command:

    curl -sku admin:testing -X GET https://LTM1.example.com/mgmt/tm/sys/hardware/ | jq '.entries."https://localhost/mgmt/tm/sys/hardware/platform", .entries."https://localhost/mgmt/tm/sys/hardware/system-info"'

    The output appears similar to the following example:

  3. Optionally, you can extend the jq filters to narrow the resulting output. For example, using the BIG-IP information provided in step 2, to return only the model name and platform type, enter the following command:

    curl -sku admin:testing -X GET https://LTM1.example.com/mgmt/tm/sys/hardware/ | jq '.entries."https://localhost/mgmt/tm/sys/hardware/platform".nestedStats.entries."https://localhost/mgmt/tm/sys/hardware/platform/0".nestedStats.entries.marketingName, .entries."https://localhost/mgmt/tm/sys/hardware/system-info".nestedStats.entries."https://localhost/mgmt/tm/sys/hardware/system-info/0".nestedStats.entries.platform'

    The output appears similar to the following example:

    {
      "description": "BIG-IP 3900"
    }
    {

    }

    Note: To see all information from the /mgmt/tm/sys/hardware API endpoint, use jq '.' with no additional filters.

Determine the BIG-IP model name and platform type using the Configuration utility (GUI)

To watch a video demo of this procedure, go to  Determine the BIG-IP platform type and model name using the Configuration utility.

  1. Log in to the Configuration utility.
  2. Go to Device Management > Devices.
  3. Select the local device with the (Self) designation.
  4. The Platform ID field indicates the platform type.

    For example:

    C106

  5. The Platform Name field indicates the model name.

    For example:

    BIG-IP 3900
