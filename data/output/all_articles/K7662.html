Known Issue

This is the result of a known issue. By default, the BIG-IP GTM system waits five seconds for a response when making DNS queries to external DNS servers. However, if the BIG-IP GTM system is configured to allow recursive DNS lookups, the BIG-IP GTM system waits 35 seconds for a response. If the response takes longer than the timeout, the BIG-IP GTM system will forward its response, such as a SERVFAIL response, to the requestor using the source IP address of 127.0.0.1. For example, if a client makes a DNS request to the BIG-IP GTM system and the wide IP configuration or DNS zone files do not contain the answer, BIG-IP GTM can send a query to external DNS servers as the root name servers. If the response from the external DNS server exceeds the 5-second timeout period, BIG-IP GTM sends its response to the requesting client with a source IP address of 127.0.0.1.

F5 Product Development is tracking this issue as ID 227268 (formerly CR81705).

Resolution

Workaround

You can work around this issue by increasing the timeout value for the BIG-IP GTM Listener DNS profile. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. Click Profiles.
  4. From the Protocols menu, select UDP.
  5. Click the udp_gtm_dns profile.
  6. Change the Idle Timeout setting to the required number of seconds, such as 35.
  7. Click Update.

If you are running a standalone BIG-IP GTM system, you can increase the timeout value for the BIG-IP GTM Listener DNS profile using either the Traffic Management Shell (tmsh) or bigpipe commands. To do so, perform one of the following procedures:

tmsh commands

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.

  2. To increase the timeout value for the BIG-IP GTM Listener DNS profile, type the following command:

    modify /ltm profile udp udp_gtm_dns idle-timeout xx

    In this command, note the following:

    • Replace xx with the required timeout in seconds
  3. Save the change by typing the following command for your version:
    • BIG-IP 10.1.0 and later:

      save sys config

    • BIG-IP 10.0.x:

      save config

bigpipe commands

  1. Log in to the BIG-IP command line.
  2. To increase the timeout value for the BIG-IP GTM Listener DNS profile, type the following command:

    bigpipe profile udp udp_gtm_dns idle timeout xx

    In this command, note the following:

    • Replace xx with the required timeout in seconds
  3. To save the configuration, type the following command:

    bigpipe save
