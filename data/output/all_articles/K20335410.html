Description

The following logs appear in /var/log/ltm after system upgrade:

012a0000:0: kernel.pti changed from 0 to 1

Environment

  • /var/log/ltm
  • kernel

Cause

The log means a certain feature of kernel is set to the value. For example, the kernel.pti DB variable is enabled by setting its value from 0 to 1, as part of mitigating the vulnerability CVE-2017-5754 (please see K91229003).  You may also see other similar examples such as:

012a0000:0: kernel.ibrs changed from 2 to 0

Recommended Actions

These logs can be safely ignored since it indicate a specific kernel db key is set to a value during BIG-IP initialization.

However please be aware of the following KB and set kernel.pti to disable on AMD platform:

K55001345: BIG-IP platforms running AMD processors may unexpectedly restart due to watchdog timeout or Southbridge system reset
