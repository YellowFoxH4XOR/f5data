Known Issue

This is the result of a known issue. The BIG-IP LTM system does not properly update the ARP table for a node monitored by a transparent monitor. This behavior causes the transparent monitor to intermittently mark the node as down. When the ARP table is updated, the monitor marks the node back up.

F5 Networks Product Development tracked this issue as CR92443 and it was fixed in BIG-IP LTM version 9.4.4. For information about upgrading, refer to the BIG-IP LTM or ASM Release Notes.

Workaround

You can temporarily work around this issue by creating a static MAC address entry for the node. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Network.
  3. Click ARP.
  4. Click Create.
  5. Enter the IP address of the node in the IP Address field.
  6. Enter the MAC address of the node in the MAC Address field.
  7. Click Finished.
