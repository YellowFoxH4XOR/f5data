Topic

When using some versions of the Firefox browser, such as 3.5.5, the BIG-IP Configuration utility may render slowly. Analysis of the traffic reveals that the sixth parallel connection that the browser opens has a 17-second delay between the time in which the TCP connection has established, and when the SSL handshake begins. During this delay, the page element that Firefox intended to request with the connection is held up. When this issue occurs, a user will see the Configuration utility begin rendering and then stall for approximately 17 seconds. Eventually, the SSL handshake will complete and Firefox will download the remaining page element. As a result, the Configuration utility will finish rendering.

This issue is due to an increase of the number of parallel connections that are opened by default to any given server. While this change aims at improving page load performance, it also triggers protections built into the httpd process of the BIG-IP system that prevent the Configuration utility from becoming overwhelmed.

To accommodate this change, you may increase the value of the MaxClients variable as described in K9588: Error Message: httpd: [error] server reached MaxClients setting. You can safely raise the MaxClients limit to 20.

Note: The default value of the MaxClients variable is 5. However, if the BIG-IP system is licensed for BIG-IP ASM or WebAccelerator, the default value of the MaxClients variable is 10. Therefore, this issue is less likely to occur if the BIG-IP system is licensed for BIG-IP ASM or WebAccelerator.

Alternatively, to reduce the number of concurrent connections your Firefox browser makes to any website, including the BIG-IP Configuration utility, perform the following procedure:

  1. Launch the Firefox browser.
  2. In the URL bar, type the following location:

    about:config
  3. In the Filter box, type http.
  4. Double-click on network.http.max-connections to edit its settings.
  5. Modify the value to a smaller number. For example, change the value from 24 to 3.
  6. Click OK.
  7. Close the browser window.
