Topic

A non-blocking switch refers to the mechanism that allows a path to be established from any input to any output. It does this without requiring a change of state for any routing elements that have already been set to provide a path from a different input to a different output.

To accomplish this, the speed of the switch fabric needs to be as fast as the product of the number of inputs, times the number of outputs (typically the same), times the speed of an individual input/output channel (assuming input and output ports run at the same speed).

This eliminates the possibility of input queuing in the system, but there is a possibility of having to buffer on the output side. In this case, congestion on one port does not affect any other port.
