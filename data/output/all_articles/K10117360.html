Description

HTTP policy's "Replace-x-forwarded-for" does not replace client's spoofed IP address, when the HTTP profile's "Insert X-Forwarded-For" is enabled(default disabled).

Environment

  • HTTP profile with "Insert X-Forwarded-For" enabled
  • BIG-IP versions 12.1.2 - 12.1.5

Cause

Unknown at time of publication

Recommended Actions

To work around this issue, and have the HTTP policy replace the spoofed IP address as expected, you can disable "Insert X-Forwarded-For" in the HTTP profile
