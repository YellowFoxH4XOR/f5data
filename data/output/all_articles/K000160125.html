Description

You would like to know the modules available before you apply for a BIG-IP free trial license. 

Environment

  • MyF5 portal
  • BIG-IP Virtual Edition
  • Trial license

Cause

 None

Answer/Recommended Actions

These are the modules that are available in the BIG-IP free trial license.

1. Traffic Management (LTM)

  • Rate Shaping - Traffic rate limiting and shaping capabilities
  • BIG-IP VE, Multicast Routing - Multicast routing support for virtual edition
  • Routing Bundle, VE - Advanced routing protocols (BGP, OSPF, RIP, etc.)
  • Max Compression, VE - HTTP compression for bandwidth optimization

2. SSL/TLS

  • SSL, VE - Basic SSL/TLS offloading and encryption
  • SSL, Forward Proxy, VE - SSL forward proxy for outbound traffic inspection
  • Crypto Offload, VE, Tier 1 (25M - 200M) - Hardware-accelerated crypto operations (25M-200M throughput tier)

3. Security Modules

i. Web Application Firewall

  • ASM, VE - Application Security Manager (legacy WAF)
  • Advanced Web Application Firewall, VE - Advanced WAF (newer generation of ASM)

ii. Network Security

  • AFM, VE - Advanced Firewall Manager (network firewall, DDoS protection)
  • Anti-Virus Checks - Anti-virus validation for endpoint security
  • Firewall Checks - Endpoint firewall status validation

iii. DNS Security

  • DNSSEC - DNS Security Extensions for authenticated DNS responses
  • DNS (1K QPS), VE - DNS services with 1,000 queries per second capacity

4. Access Policy Manager (APM) 

i. APM Core

  • APM, Limited - Limited version of Access Policy Manager
  • APM, Web Application - Web application access control

ii. APM - Endpoint Security

  • Base Endpoint Security Checks - Basic endpoint compliance checking
  • Machine Certificate Checks - Device certificate validation
  • Secure Virtual Keyboard - Protected keyboard input for sensitive data

iii. APM - Access Methods

  • Network Access - Full network layer VPN access
  • App Tunnel - Application-level tunneling
  • Remote Desktop - Remote desktop protocol support
  • Protected Workspace - Secure workspace/cache cleaning

5. Service Provider / Carrier Grade

  • PSM, VE - Policy Enforcement Manager (service provider traffic management)
  • VE, Carrier Grade NAT (AFM ONLY) - Large-scale NAT for service providers (requires AFM)

6. Integration & Orchestration

  • SDN Services, VE - Software-Defined Networking integration
  • External Interface and Network HSM, VE - External hardware security module support
