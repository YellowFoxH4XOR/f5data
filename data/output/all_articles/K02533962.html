Known Issue

The Deterministic NAT (DNAT) utility (dnatutil) is unable to parse high-speed logging (HSL) data sent from the VIPRION B4300 blade.

This issue occurs when all of the following conditions are met:

  • You have a VIPRION system with one or more B4300 blades installed.
  • You have configured the BIG-IP system to use HSL.
  • You use the dnatutil utility to calculate reverse source address and port mapping of DNAT pool connections.

Impact

The dnatutil utility is unable to calculate the reverse source address and port mapping for DNAT pool connections.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When using the dnatutil utility to calculate reverse source address and port mapping, you view an Unparseable line error message.

Workaround

Use non-HSL or default LTM logged deterministic NAT state information.

Impact of workaround: Performing the workaround may increase both disk space utilization and CPU processing.
