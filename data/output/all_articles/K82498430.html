Description

This article is related to SNMPv3 support for SHA2 and AES256 on the BIG-IP.

Environment

  • BIG-IP 15.1.0.4 and above
  • BIG-IP 16.0.0 and above

Cause

  • All BIG-IP that uses Net-SNMP 5.8 provides support for SNMPv3 to use SHA2 and AES256.
  • Previous BIG-IP software are using Net-SNMP 5.7.2 which does not support SHA2 and AES256.
     

Recommended Actions

The use of Net-SNMP 5.8 is tracked by ID858769.

TMSH Command to apply SHA256 and AES 256 to SNMPv3:

1.) Log into TMSH:

tmsh 

2.) Use the following command syntax:

modify /sys snmp users add { <user> { access rw security-level auth-privacy auth-protocol sha256 auth-password defaultPassword privacy-protocol aes-256 privacy-password defaultPassword username <user> } }

-Example using username snmp-user

modify /sys snmp users add { snmp-user { access rw security-level auth-privacy auth-protocol sha256 auth-password defaultPassword privacy-protocol aes-256 privacy-password defaultPassword username snmp-user } }
