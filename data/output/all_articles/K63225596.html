Known Issue

Mismatched serial speeds may corrupt console access.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system serial console port is configured for a specific baud rate (for example, 19200).
  • You connect to the BIG-IP serial console port with a terminal device configured with a baud rate that is different than the BIG-IP system configured baud rate (for example, the terminal is set with the baud rate of 9600).
  • On the connected terminal device, you press the Enter/Return key several times.

    Note: The connected terminal displays garbled characters.

  • You modify the terminal device baud rate to match the BIG-IP system configured baud rate.
  • You attempt to enter key commands on the terminal.

Impact

You are unable to use the terminal connection.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the terminal display, characters are garbled.
  • The serial console port displays garbled characters regardless of the terminal device or the baud rate you use.

Workaround

To work around this issue, you can reboot the BIG-IP device, or when secure shell (SSH) access to the BIG-IP device is available, you can restart the TTY process and stop the agetty process, allowing the serial console to use the correct serial line settings. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Disconnect the terminal device from the BIG-IP serial console port.
  2. Log in to the BIG-IP command line with administrative privileges.
  3. To stop the agetty process, type the following command:

    stty -F /dev/ttyS0 -parenb ; killall agetty

    Note: Run this command only when no users are logged on to the serial console port.

  4. Connect the terminal device configured with Baud 19200, Parity none, Data bits 8, Stop bits 1 to the BIG-IP serial console port.
