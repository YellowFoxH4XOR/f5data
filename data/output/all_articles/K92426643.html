Description

Credential Stuffing is not listed in Updates Configuration of Live Update.

Environment

  • Advanced WAF
  • Live Update

Cause

To list Credential Stuffing in Live Update, asm.credential_stuffing_service has to be enabled.

Recommended Actions

  1. enable db key asm.credential_stuffing_service (disabled by default)
    # tmsh modify sys db asm.credential_stuffing_service value enable

Additional Information

If the issue still persists, re-activating license may help to solve.
