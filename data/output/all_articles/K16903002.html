Description

Viewing memory usage on BIG-IP.

Environment

  • Reviewing memory
  • BIG-IP

Cause

None.

Recommended Actions

Commands to view memory usage via SSH:

  1. free -  will give memory output of the device.
  2. tmctl memory_usage_stat | less - will give an output of memory usage on the device
  3. tmsh show sys mem -  will give output of memory used on the device
  4. top then Shift H to show all threads for memory and CPU usage on BIG-IP
  5. Performance graphs - Statistics ›› Performance Reports


Additional Information
Note: Memory usage can be reviewed in iHeath with a qkview and must have an iHealth account.
