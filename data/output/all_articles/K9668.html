Known Issue

This is the result of a known issue. If a Windows Vista or Windows 7 client enters Protected Workspace, the user can perform the following tasks:

  • Create files and folders outside of the Protected Workspace temporary folders

    Note: The user must have the necessary Windows permissions to create the file or folder before entering Protected Workspace. For example, if the user does not have the Windows permissions to create a file in C:\ before entering Protected Workspace, the user cannot create a file in C:\ after entering Protected Workspace.

  • Move files and folders located outside of the Protected Workspace temporary folders to other locations outside of the Protected Workspace temporary folders

    Note: The user must have the necessary Windows permissions move the file or folder before entering Protected Workspace. For example, if the user does not have the Windows permissions to move a file from C:\public1 to C:\public2 before entering Protected Workspace, the user cannot move the file from C:\public1 to C:\public2 after entering Protected Workspace.

The user cannot move files from the Protected Workspace temporary folders to locations outside of the Protected Workspace temporary folders. Similarly, the user cannot move files located outside of the Protected Workspace temporary folders to the Protected Workspace temporary folders.

F5 Product Development tracked these issues as CR82451 and CR82452, and they are fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.
