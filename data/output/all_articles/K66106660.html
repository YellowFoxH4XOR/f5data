Description

F5 Edge Client cannot recover the PAC proxy declared in the Network Access configuration on the first try.
Instead, it uses a PAC proxy declared in a workstation registry.
However, after a second attempt in the same session, the client manages to establish a VPN connection with the correct PAC proxy.

Error message in %temp%/logterminal.txt on Windows client machine:
4760,676,DIALER, 1, , 784, WritePACFileFromURL, Failed to connect for downloading a PAC file (URL: http://pac.example.com/proxy.pac)

Environment

  • Network Access (VPN)
  • Proxy PAC file
  • Computer already has local PAC file configured
Cause

Use Local Proxy Settings option was Disabled in the Network Access Resource > Network Settings

Recommended Actions

Enable the Use Local Proxy Settings option the Network Access Resource > Network Settings to enable the proxy on the NA to be applied

Additional Information

The Use Local Proxy Settings option instructs the computer to use the Network Access Proxy configuration, doesn't merge or overwrite the local Proxy configuration.
