K44048253: GUI showing error ''The requested monitor parameter (/Common/xxx 2 RECV_STATUS_CODE=) was not found''

Type
Support Solution
Published
2021-03-10
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP DNS: 15.1.X, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.8, 15.1.1, 15.1.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K44048253

Description
Update the DNS monitor "Send String"  configuration may encounter below error message on GUI,

The requested monitor parameter (/Common/xxx 2 RECV_STATUS_CODE=) was not found.

Environment

  • DNS
  • Monitor send string

Cause
Bug ID 935945: GTM HTTP/HTTPS monitors cannot be modified via GUI 

Recommended Actions

  1. Change the receive string with a status code from CLI,
    # tmsh modify gtm monitor http xxx recv-status-code 200

  2. Change the "Send String" from GUI, if you want to modify the send string. 

  3. Click "Update" button from GUI.

  4. Revert the monitor value as none from CLI to bypass the error. 
    # tmsh modify gtm monitor http xxx recv-status-code none

Note: This receive status code need to be reverted only if there is no expected receive status code for your monitor configuration. 

Additional Information
None.
