Known Issue

This is the result of a known issue. A non-contiguous network mask can be used to specify a range of addresses in one or more octets of an IP address.

In order to improve performance, the search for class matches was changed from a linear method to a hashed method in BIG-IP version 4.5.11. As a result, rules that use classes that specify non-contiguous network masks will fail.

F5 Networks Product Development tracked this issue as CR53245 and CR54026, and it was fixed in BIG-IP version 4.5.14 for the version 4.5 branch. For information about upgrading, refer to the BIG-IP Release Notes.

This issue still exists in the BIG-IP version 4.6 branch.
