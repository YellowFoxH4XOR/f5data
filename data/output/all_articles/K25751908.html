Known Issue

The BIG-IP system may ignore a custom maximum transmission unit (MTU) or maximum segment size (MSS) value for the management route.

This issue occurs when the following condition is met:

  • You configure a custom MTU or MSS value for the management network.

    For example, the following tmsh command creates a management route with an MTU of 1200:

    tmsh create /sys management-route 10.2.3.4/32 mtu 1200 gateway 10.0.0.1

You can create a management route and use the Traffic Management Shell (tmsh) to set the MTU value, however, the setting is not propagated to the Linux kernel.

Impact

Client connections to the management interface may fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Client connections to the management interface may fail when a lower MTU value is specified for the management network.
