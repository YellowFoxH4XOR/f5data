K000092562: F5 DNS relay proxy server is conflicting with Cisco Umbrella DNS Server

Type
Support Solution
Published
2022-11-30
Updated
2022-11-30
Source
https://my.f5.com/manage/s/article/K000092562

Description

You want to disable the DNS Relay Proxy Service so it will not interfere with Cisco Umbrella DNS Server. You create a custom client package with DNS Relay Proxy Service unchecked but all the other components are selected. After installing the custom client package, you notice that the DNS Relay Proxy Service is running.


Environment

  • Custom Windows Client Package with DNS Relay Proxy unchecked
  • Client machine running Windows OS

Cause

In the below 3 scenarios DNS relay proxy will be included.


1. It is installed when selected from the connectivity profile UI for creating Windows package.

2. Machine Tunnels Service component is selected in the package UI.

3. Optimized tunnels are enabled in Network Access resource.


Recommended Actions

This is expected behavior if any of the 3 conditions above are met.

None
