Description
After performing a software upgrade, the sync state is showing "Awaiting Initial Sync" in Configuration Utility (GUI). 

Environment

  • Software Upgrade
  • Sync state 
  • BIG-IP LTM States

Cause
This is expected behaviour after performing a change or software upgrade.

Recommended Actions

Perform the following steps to fix the issue:
  1. Log in to the  Configuration Utility (GUI)
  2. Go to  Device Management > Overview 
  3. For Device Group, select the name of the device group you want to synchronize
  4. For Devices, select the appropriate device
  5. Select the synchronization operation
  6. Select Sync.
