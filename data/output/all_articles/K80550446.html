Known Issue

The localdbmgr process may repeatedly produce core files and restart.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM configuration uses the local user database for access policy authentication.
  • Local user database data, which has been stored in memory, becomes corrupted.

Impact

BIG-IP APM authentication attempts fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users cannot authenticate to the BIG-IP APM system.
  • Repeating messages are logged to the /var/log/apm file, similar to the following example:

    notice localdbmgr[19586]: 01490000:5: starting MCPD subscriber
    notice localdbmgr[19586]: 01490000:5: Query string [SELECT count(*) FROM auth_user WHERE auth_user.deleted > 0]
    notice localdbmgr[19586]: 01490000:5: Query num_fields [1]
    notice localdbmgr[19586]: 01490000:5: Number of record mark deleted [0]
  • Core files for the localdbmgr process appear in the /shared/core directory, similar to the following example:

    localdbmgr.bld2440.0.core.gz
