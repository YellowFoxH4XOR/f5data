K81592011: TMM restart loop, core files generated

Type
Support Solution
Published
2022-02-18
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K81592011

Description

TMM keeps restarting and there are core files generated by the signal SIGSEGV.

Environment

  • BIG-IP 16.x.
  • HTTP profile without fallback host.
  • iRules.

Cause

Bug ID 968929.

Recommended Actions

There are two options:

  1. Follow the workaround for Bug ID 968929.
  2. Contact F5 support to request an Engineering HotFix for this bug.

Additional Information
