K000149463: After upgrading to version 17.1.2 user are seeing a Blank Webtop when connecting via the APM using the Edge Browser in Compatibility mode.

Description

After upgrading to version 17.1.2 user are seeing a Blank Webtop when connecting via the APM using the Edge Browser in Compatibility mode.

Environment

  • BIG-IP APM
  • Blank Webtop
  • Standard customization Access Policy
  • Edge Browser
  • Compatibility mode

Cause

This is a result of an incompatibility between compatibility mode and standard customization and is being tracked as Bug ID 1789501.

Recommended Actions

See the BugTracker for Bug ID 1789501 for mitigation and resolution information
