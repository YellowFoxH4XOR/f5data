K000135081: Unable to allow port 162 on rSeries using allowed-ips command

Type
Support Solution
Published
2023-06-19
Updated
2023-06-20
Applies to
  • F5OS
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000135081

Description

Users may encounter an error when attempting to add port 162 to the list of allowed IPs for SNMP on F5 rSeries appliances. The error message returned is as follows:

 

appliance-1(config)# system allowed-ips allowed-ip snmp config ipv4 address 192.168.0.1 port 162

appliance-1(config-allowed-ip-snmp)# commit

﻿

Aborted: 'system allowed-ips allowed-ip snmp config ipv4 port' (value "162"): Invalid port configuration. Allowed

ports are tcp/udp (8888), SNMP(161),

VCONSOLE(7001), SSH(22), HTTP(80)

and HTTPS(443)

 

 

Environment

F5 rSeries

Cause

Port 162 is typically used for outgoing SNMP trap messages from the SNMP agent (here, the F5 rSeries device) to an SNMP manager (such as SolarWinds), not for incoming connections to the F5 device. The 'system allowed-ips' command is designed to configure which IPs are allowed to connect to the F5 device on specified ports, for incoming connections only.

Recommended Actions

This is by design and no action is required as the outgoing traffic on port 162 is permitted by default.
