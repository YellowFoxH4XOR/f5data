Description

On Viprion on systems with multiple blades you may see an error message similar to:

tmm[14743]: 01340004:3: HA Connection detected DAG discrepancy: local pg 2, remote pg 3, local pu 0, remote pu 0. Connection will be retried.

Environment

  • Viprion
  • vCMP
  • High Availability
  • Connection Mirroring

Cause

'HA connection' mean's the mirroring channel. In order for mirroring to function correctly, DAG has to function the same on both devices - They need to have the same number of tmm's and be running on the same slots (if in a cluster).

In this case the error is quite simple to understand:

Guest on vCMP Host 1

vcmp guest Example01.F5.com {
    allowed-slots { 3 4 }
    app-service none
    assigned-slots { 4 }         <-----------  1 slot
    cores-per-slot 12


Guest on vCMP Host 2

vcmp guest Example02.F5.com {
    allowed-slots { 3 2 }
    app-service none
    assigned-slots { 2 3 }       <----------- 2 slots
    cores-per-slot 12
 

Recommended Actions

  1. Configure the guests with the same slot configuration, and running in the same slots on both hosts.
  2. Or remove the mirroring config between the devices
