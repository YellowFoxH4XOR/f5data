Topic

The BIG-IP ASM system does not have a feature that allows you to directly compare two different policies, or compare a single policy for differences from the default settings of that policy. However, it is possible to compare differences between two web application policies using the policy export and policy merge features.

The policy merge feature merges two policies into one. The policy merge feature will also produce a merge report file that contains comprehensive information about differences between the two policies.

If you merge a configured policy with a policy containing only default settings, the resulting merge report file would contain the settings of the configured policy. If you merge two configured policies, the resulting merge report file would contain the differences between the two configured policies.

You can compare two policies by performing the following procedure:

Important: This procedure will modify the policy selected in step 10. You must select the Backup Target Policy check box in step 15 to ensure that an unmodified copy of the merged policy is received.

  1. Log in to the Configuration utility.
  2. Click Application Security.
  3. Click Web Applications.
  4. Click the name of the Web Application with the policies to compare.

    The Web Application Properties page is displayed.
  5. Under the Policies List section, click the option button of the first policy to compare.
  6. Click Export.

    The File Download window will open.
  7. Click Save.
  8. Select a location to save the file and click Save.

    The Download complete window will open.
  9. Click Close.
  10. Under the Policies List section, click the option button of the second policy to compare.
  11. Click Merge.

    The Merge Policies page is displayed.
  12. Click Browse next to the Policy To Be Merged field.

    The Choose file window will open.
  13. Select the file created when the first policy was exported in step 7.
  14. Click Open.
  15. Ensure the Backup Target Policy check box is selected.
  16. Click Merge.
  17. Click Download Full Report.

    The File Download window will open.
  18. Click Save.
  19. Select a location to save the file and click Save.

    The Download complete window will open.
  20. Click Close.

The resulting merge report file contains comprehensive information about differences between the two policies.
