Topic

You can configure a pre-logon sequence that detects Microsoft Windows 7 clients, and then perform a series of actions based on the requirements of your environment. For example, if your version of FirePass software does not support Windows 7, you can direct Windows 7 clients to a Logon Denied page with a customized message.
 
Note: For information about support for Windows 7, refer to K10053: FirePass support for Microsoft Windows 7.

The following procedure configures a pre-logon sequence that directs Microsoft Windows 7 users to the Logon Denied page, while displaying the standard logon page to all other users. You may customize the Logon Denied page with instructions or links for Windows 7 users to take appropriate actions, or choose any other set of actions for Windows 7 clients. You may also allow Windows 7 users to log on to the FirePass controller, instead of presenting the Logon Denied page.

  1. Log in to the FirePass Administrative console.

  2. Navigate to the Users: Endpoint Security: Pre-Logon Sequence page.

  3. In the Create new sequence field, enter a name for this Pre-Logon Sequence.

    For example:

    Win7 Detection

  4. In the Based on menu, select template: Empty.

  5. Click the Create button.

    The Win7 Detection sequence appears in the Select Sequence to Use section.

  6. Click edit next to the pre-logon sequence that you created.

    The Pre-Logon Sequence Editor opens.

  7. Mouse over the Go action.

    A + (plus) link appears to the right of the Go action.

  8. Click the + link.

    The Change Sequence panel opens.

  9. In the Change sequence menu, select Insert action.

  10. In the Using menu, select One from the list.

  11. Click the button next to Extended Windows and IE info.

  12. Click the Apply changes button at the bottom of the page.

    The Extended Windows and IE info inspector appears in your pre-logon sequence.

  13. Mouse over the fallback rule to the right of the Extended Windows and IE info box in the updated sequence.

    A + link appears to the left of the fallback rule.

  14. Click the + link.

    The Insert Rule panel opens.

  15. Type a name In the name field.

    For example:

    check-for-win7

  16. Below the name field, type the following rule:

    session.os.platform=="Win7"

    Note: You can create a check-for-win7 rule and insert it into any existing pre-logon sequence you may have already configured.

    Note: The session.os.platform session variable may be used in a Protected Configuration to deny access to resources not appropriate for Microsoft Windows 7 users.

  17. Click the Insert Rule button at the bottom of the page.

    The check-for-win7 rule appears in your pre-logon sequence. Also, the Logon Denied Page option appears directly behind the rule, and the Logon Allowed Page option is now directly behind the fallback rule.

  18. Click the Update button at the bottom of the page.

  19. Click the Back to Console link at the top right corner of the page.

    The Pre-Logon Sequence main page appears.

  20. Click the button next to the Win7 Detection sequence you have just created.

  21. Click the Apply button.

Users running Windows 7 will now be directed to the Logon Denied page when they attempt to logon to the FirePass controller.
