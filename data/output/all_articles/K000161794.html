Description

TCP window size advertised in SYN packets from BIG-IP LTM may appear lower than the maximum value configured in the TCP profile. For example, a TCP profile with receive window and send buffer size set to 262140 (window scale factor 2) can show an initial window size of 13360 in the SYN packet, even if the client requests 65535. This can cause concern that the configuration change has not taken effect or that BIG-IP is not operating correctly.

Environment

  • Product: BIG-IP LTM
  • Version: 17.1.3
  • Standard TCP profile applied to the affected virtual server
  • TCP receive window and send buffer size set to 262140 (window scale factor 2)
  • Application server configured with TCP window scale factor of 3

Cause

The lower initial TCP window size is due to the standard operation of TCP slow start and congestion avoidance algorithms, as implemented by BIG-IP LTM. These algorithms intentionally limit the initial advertised window size to prevent network congestion, regardless of the maximum window size configured in the TCP profile. This behavior is compliant with RFC 5681 and F5 documentation.

Answer/Recommended Actions

  • No changes are required to the BIG-IP configuration; the system is operating as designed.
  • If higher throughput is required, review and adjust TCP profile parameters (e.g., window scaling, buffer sizes) within the limits of network and application requirements. Note that the initial window size will still be governed by TCP slow start.
  • Continue to monitor application performance and packet captures to ensure expected behavior.
  • Refer to RFC 5681 for further details on TCP slow start and congestion avoidance behavior.

Additional Information

  • The initial TCP window size advertised by BIG-IP may be lower than the configured maximum due to TCP slow start and congestion avoidance mechanisms.
  • The calculated window size increases over time during the connection, as expected per TCP standards.
  • This is expected and standards-compliant behavior, not a misconfiguration or bug.
