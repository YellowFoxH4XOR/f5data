Topic

BIG-IP APM has the ability to launch applications based on dynamic data in an access policy. By configuring an access policy to launch applications you have the ability to perform tasks such as pass custom parameters to an application, or selectively launch an application based on various rules like group membership.

The syntax for specifying the application is in XML format, defined as follows:

<application_launch>
  <item>
     <path>path to application</path>
     <parameter>parameters to pass to application</parameter>
     <os_type>WINDOWS</os_type>
  </item>
</application_launch>

Note: For information about other operating system session variables, refer to K11053: Overview of the session.os.platform variable.

Launching an application using a session variable as a parameter

Note: This procedure assumes that you have a working access policy for network access. For information about configuring an access policy, refer to the Configuration Guide for BIG-IP Access Policy Manager. For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

  1. Log in to the Configuration utility.
  2. From the navigation pane, expand Access Policy.
  3. Click on Access Profiles.
  4. Click Edit... in the Access Policy column that is in the same row as your network access policy you want to add the application launch to.

    The Visual Policy Editor (VPE) will launch.
  5. Click the + to the left of your resource assign object.

    The Add Item list will appear.
  6. Click the Variable Assign radio button.
  7. Click Add Item.

    The Variable Assign Properties window will appear.
  8. Click Add new entry.

    A new entry labeled empty will show below the Assignment section.
  9. Click change next to the empty label.

    A new window appears.
  10. In the left pane select Configuration Variable from the drop-down menu.
  11. Select Network Access from the Type: menu.
  12. Select the appropriate network access resource from the Name: menu.
  13. Select application_launch from the Property: menu.
  14. In the right pane select select Custom Expression from the drop-down menu.
  15. Under Custom Expression, type the desired text.

    For example:

    expr { “<application_launch>
              <item>
                <path>example.app</path>
                <parameter>[mcget { example session variable } ]</parameter>
                <os_type>WINDOWS</os_type>
               </item>
             </application_launch>”
          }
  16. Click Finished.
  17. Click Save.
  18. Click Apply Access Policy.
  19. Click Close.
