Known Issue

This is the result of a known issue. When a Linux client launches a Network Access favorite for the first time, a pop-up window appears which prompts the user to install the Network Access client components. If the user selects the Click here for manual installation instructions link in the pop-up window, the bottom half of the pop-up window refreshes and displays a blank page.

F5 Networks Product Development is tracking this issue as CR112775.

Workaround

For instructions about manually installing the Linux client components, refer to K9438: Manually installing the FirePass Network Access client components on a Linux client.
