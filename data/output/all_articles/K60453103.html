Description

sysGlobalDiametersessionStatResetStats (.1.3.6.1.4.1.3375.2.1.1.2.35.1) is a writable OID that reset statistics data in sysGlobalDiametersessionStat.

 snmptranslate -Td -On F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatResetStats
.1.3.6.1.4.1.3375.2.1.1.2.35.1
sysGlobalDiametersessionStatResetStats OBJECT-TYPE
  -- FROM       F5-BIGIP-SYSTEM-MIB
  SYNTAX        INTEGER
  MAX-ACCESS    read-write
  STATUS        current
  DESCRIPTION   "The action to reset resettable statistics data in sysGlobalDiametersessionStat.
                 Setting this value to 1 will reset statistics data.
                 Note, some statistics data may not be reset including data that are incremental counters."


Environment

  • Reset statistics data in sysGlobalDiametersessionStat using SNMP SET request

Cause

None

Recommended Actions

  1. Check the current sysGlobalDiametersessionStat Group stats on the BIG-IP.

snmpwalk -v 2c -c public localhost .1.3.6.1.4.1.3375.2.1.1.2.35
F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatResetStats.0 = INTEGER: 0
F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatTotCapExcReq.0 = Counter64: 3
F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatTotCapExcAns.0 = Counter64: 3
F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatTotDeviceWatchdogRequests.0 = Counter64: 30
F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatTotDeviceWatchdogAnswers.0 = Counter64: 30
F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatTotDisconnectPeerRequests.0 = Counter64: 0
F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatTotDisconnectPeerAnswers.0 = Counter64: 0

  1. Reset sysGlobalDiametersessionStat stat using snmpset command on OID sysGlobalDiametersessionStatResetStats.0. Please ensure the SNMP write community string has been set on BIG-IP.

snmpset -v 2c -c private localhost F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatResetStats.0 = 1
F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatResetStats.0 = INTEGER: 1

  1. Verify that stats are reset.

snmpwalk -v 2c -c public localhost .1.3.6.1.4.1.3375.2.1.1.2.35
F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatResetStats.0 = INTEGER: 0
F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatTotCapExcReq.0 = Counter64: 0
F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatTotCapExcAns.0 = Counter64: 0
F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatTotDeviceWatchdogRequests.0 = Counter64: 1
F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatTotDeviceWatchdogAnswers.0 = Counter64: 1
F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatTotDisconnectPeerRequests.0 = Counter64: 0
F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatTotDisconnectPeerAnswers.0 = Counter64: 0
F5-BIGIP-SYSTEM-MIB::sysGlobalDiametersessionStatTotAccountingRequests.0 = Counter64: 0
