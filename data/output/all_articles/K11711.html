Issue

When creating an LDAP AAA server in the BIG-IP APM Access Policy section, the BIG-IP system uses port 389 by default. If that port is manually changed to a port that the LDAP server is not listening on, or your LDAP server is using a non-standard port and the port configuration has not been manually changed, users may receive the following error message when they attempt to authenticate:

The username or password is not correct. Please try again. (error: Can't contact LDAP server)

The first part of the error message may erroneously lead users to believe that they have supplied incorrect credentials. However, this error message actually indicates that the BIG-IP system was unable to contact that LDAP server. If you have confirmed that the BIG-IP system has a usable network path to the LDAP server, you may also want to confirm that the port number configured in the AAA properties is correct.
