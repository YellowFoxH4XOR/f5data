Known Issue

BIND configuration options are not modified properly when you add a server to the BIND Forwarder Server List.

This issue occurs when the following conditions is met:

  • You add a DNS server to the BIND Forwarder Server List using the Configuration utility.

When you use the Configuration utility to add a DNS server to the (System > Configuration > Device > DNS) BIND Forwarder Server List, the recursion and forward options in the named.conf configuration file are not properly updated. The recursion option will remain set the the default value of no, and the forward option is not set.

Impact

The BIG-IP system does not forward DNS requests as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system does not forward DNS requests as expected.
  • The BIG-IP system provides non-recursive answers to DNS requests, or it returns a Query Refused error in response to DNS requests.
  • In the /var/named/config/named.conf file, the recursion option has a value of no, and the forward option is missing.

Resolution

Workaround

To work around this issue, you can manually configure the recursion and forward options. To do so, perform the following procedure:

Impact of workaround: Depend on the specific environment, enabling recursion may impact the BIG-IP performance. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.

  1. Log in to the BIG-IP command line.
  2. Change directories to the /var/named/config directory by typing the following command:

    cd /var/named/config

  3. Create a backup of the named.conf file by typing the following command:

    cp named.conf named.conf.orig

  4. To edit the named.conf file, locate the recursion option.

    For example:

    recursion no;

  5. Change the recursion option to yes.

    For example:

    recursion yes;

  6. Add the forward only option statement directly below the changed recursion statement.

    For example:

    recursion yes;
    forward only;

    Note: The following two steps are optional. You can can create an access control list (ACL) to limit which IP addresses or network addresses are allowed to make recursive queries to the BIG-IP DNS system.

  7. Create an access list below the options section of the file, containing the relevant IP addresses or network addresses for which you want the BIG-IP DNS system to provide recursive DNS queries.

    For example, the following internal access list contains the 172.16.65/24 network:

    acl "internal" { 172.16.65.0/24;};

  8. Add the following allow-recursion statement to the options section of the file, where internal matches the name of the access list:

    allow-recursion { internal;};

  9. Save the changes to the named.conf file.
  10. Restart named to allow the changes to reload by typing the following command:

    tmsh restart /sys service named
