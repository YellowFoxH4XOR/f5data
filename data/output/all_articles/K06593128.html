Cause
misconfiguration in syslog-ng settings 

Recommended Actions

  • For workaround please run the following commands.
# tmsh modify sys syslog include none
# tmsh save sys config
# bigstart restart restjavad restnoded httpd tomcat
  • Check the syslog configuration e.g list /sys syslog all-properties and compare and correct as per per below mention article.    
Defining a syslog filter rule that references the remote server
