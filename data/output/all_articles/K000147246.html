K000147246: How do I disable default error pages?

Type
Support Solution
Published
2024-11-08
Updated
2026-10-13
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147246

Description

You want to display a specific error page depending on the HTTP response code or return the original response from the origin server.

Environment

  • F5® Distributed Cloud HTTP Load Balancer 

Cause

By default, for 4xx and 5xx errors, XC will return the default F5 error page.

Answer/Recommended Actions

After configuring the allowed codes for the error response on HTTP Load Balancer > More Options > Configure Error Response Options you have to enable the option Disable Default Error Pages
