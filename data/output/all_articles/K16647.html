Known Issue

The Traffic Management Microkernel (TMM) process may produce a core file and restart when using the BIG-IP DNS cache.

This issue occurs when all of the following conditions are met:

  • You configure a validating resolver cache on the BIG-IP system.
  • The resolver caches DNS key records.
  • You run the show ltm dns cache records key cache <cache-name> Traffic Management Shell (tmsh) command.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from TMM restarting. If you have configured the system as a member of a redundant configuration, the device may fail over.

Symptoms

As a result of this issue, after you run the show ltm dns cache records key cache <cache-name> tmsh command, you may encounter one or more of the following symptoms:

  • The BIG-IP system temporarily fails to process traffic.
  • The BIG-IP system fails over to another host in the device group.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
