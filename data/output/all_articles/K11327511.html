Known Issue

Advanced customization of an access policy that you created using an iApp template may fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is deployed in a high availability (HA) pair.
  • Your create an access profile for Microsoft Exchange using an iApp template.
  • Using the Configuration utility, you modify the access profile by navigating to Customization > Advanced.
  • You attempt to save the customization.

Impact

The system fails to save the customized access profile and produces an error.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you save the access profile customizations, you may observe an error message similar to the following example:

    01020066:3: The requested Customization Template File (/<partition>/Exchange.app/<object type> <object file>) already exists in partition Common.

Workaround

To work around this issue, you can manually rename the affected object name before customizing the access profile. To do so, perform the following procedure:

Impact of workaround:  F5 recommends that you perform the following procedure during a scheduled maintenance window.

  1. Log in to the command line of the affected BIG-IP APM device.
  2. Create a backup copy of /config/bigip.conf by typing the following command:

    cp /config/bigip.conf /config/bigip.conf_627972
     
  3. Using a text editor, open the file /config/bigip.conf.
  4. Locate the affected access profile template object name.

    Following are a couple of examples:

    apm policy customization-group /<partition>/<access profile name.app>/<object> {
        templates {
            logon.inc {
                name /<partition>/<access profile name.app>/<object>:<object file>
            }
        }
    }

    apm policy customization-group /Common/Exchange_2010.app/exch_custom_logon_ag {
        templates {
            logon.inc {
                name /Common/Exchange_2010.app/exch_custom_logon:logon.inc
            }
        }
    }
     
  5. Modify the access profile object name by adding the _ag suffix to the name.

    For example:

    name /<partition>/<access profile name>/<object>_ag:<object file> 

    name /Common/Exchange_2010.app/xyz_logon_ag:logon.inc     

  6. Save the configuration changes to the /config/bigip.conf file.
  7. Load the configuration by typing the following TMOS Shell (tmsh) command:

    tmsh load /sys config

    Note: You can now use the Configuration utility to customize the access profile.
