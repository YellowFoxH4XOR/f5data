Description

Unable to SSH using root account details.
You able to access SSH session using admin credentials and logged into TMSH but you cannot go to bash mode from tmsh. 
When you try to input 'bash' while in tmsh you see below error, rather than taking you to bash mode.
bash access has been disabled
when modifying any admin account via tmsh using below command to allow bash mode, you don't see any errors but still it doesn't take you to bash mode
modify auth user <username> shell bash

Environment

  • BIG-IP License
  • Appliance mode enabled 

Cause

This is due to licensing where your unit license is enabled with appliance mode.

Recommended Actions

This is working as per design.

By default, appliance mode disable 'bash' shell logins and would access to only 'TMSH' and 'GUI'.

Please refer below knowledge guide for an overview of appliance mode.

K12815 : Overview of Appliance mode

If you want to disable appliance mode, you need to request for a new license key that doesn't have appliance mode enabled and need to perform clean install.

Additional Information

Also, while in appliance mode when you navigate to System ›› Platform in GUI,you will not see an option for 'root' account under - user administration.
