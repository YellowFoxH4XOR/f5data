Source
https://my.f5.com/manage/s/article/K40505725

Description
DNS response is still received for disabled Wide IP ftp.example.com

Environment

  • BIG-IP DNS
  • DNS
  • Wide IP

Cause
Found the listed A records for ftp.example.com are in the Zonerunner -- these are automatically created when the Wide IP is created. 

Recommended Actions

  1. Resolved after deleting the mentioned A records for ftp.example.com in the Zonerunner.

None
