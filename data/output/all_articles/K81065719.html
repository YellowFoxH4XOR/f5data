Recommended Actions

    1. ssh to the system using root 
    
    2. change the shell if it defaults to tmsh, by running "run /util bash"

    3. run any of these options:
    
    #pkill -f [process name]
    #pkill -f 'tmsh -q -c cd .. ; show running-config recursive'  

    NOTE: This will kill multiple instances of the same program running or processes being continuously spawned.

    #kill -9 [pids]
    #kill -9 24655 30786 4166 11537 16773 23052  

   NOTE: This command will kill immediately all listed pids.

 

    4. monitor the output of the top command to make sure "tmsh -q -c cd .. ; show running-config recursive" is no longer running.

    

Additional Information

This appears to have been triggered by an external tool. You may need to work with that vendor.
