Description

After a new Install of BIG-IP VE on a hypervisor that has 40G interfaces, tmsh show sys interface shows the interface at 10G

Using ethtool command on CLI does confirm 40G interface.

Environment

BIG-IP VE

Cause

PCI passthrough of physical functions is not supported; however, SR-IOV for XL710 and related boards are supported.

If you attempt to use PCI passthrough of physical functions, the BIG-IP VE will use the sock driver (displayed in the device_probed command output) instead of ixlv. This means that the Linux kernel's driver (interrupt based rather than poll mode) is being used and TMM is getting the packets via raw socket. This will be significantly lower throughput and connections per second than using SR-IOV with a virtual function, have higher jitter and latency, and higher CPU and memory consumption.

Recommended Actions

Use SR-IOV for XL710 and related boards

To see which driver is being used run the following command:

tmctl -d blade tmm/device_probed

or check the tmctl data in QKView for tmm.device_probed
