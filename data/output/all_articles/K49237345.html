Security Advisory Description

F5 BIG-IP Advanced WAF, BIG-IP ASM, or NGINX App Protect WAF incorrectly handles certain requests.

This issue occurs when the following condition is met:

  • Advanced WAF, BIG-IP ASM, or NGINX App Protect WAF handles a malicious request with XML content type and XML request body.

Impact

The attack signature check fails to detect and block such requests, as expected of a security policy.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The back-end server receives requests that should have been blocked by Advanced WAF, BIG-IP ASM, or NGINX App Protect WAF.
