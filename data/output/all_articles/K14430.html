Known Issue

The Enterprise Manager system may list a managed BIG-IP system as an incompatible LogIQ source.

This issue occurs when the following condition is met:

  • The managed BIG-IP system is running 11.3.0 or later

LogIQ source devices can be configured to send all logs to the Enterprise Manager LogIQ server for the purpose of log aggregation. The Enterprise Manager system supports managed devices running BIG-IP 11.3.0 and later as a LogIQ source device.

Impact

The Enterprise Manager system is unable to configure the managed BIG-IP device as a LogIQ source device.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Enterprise Manager lists managed devices running BIG-IP 11.3.0 and later as incompatible on the LogIQ Source Device page.
