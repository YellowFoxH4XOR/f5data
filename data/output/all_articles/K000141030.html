K000141030: Make the Edge Client window topmost (focused) if an action is needed

Type

Published

Applies to

Source

Description

In a scenario where a given user is actively interacting with any other application while Edge Client connects, even if Edge Client requires the user to input credentials / do any other action in the access policy, the VPN app will stay in the background. At this point, if the Edge Client is in a minimised state it displays an Action Required user notification for some time, which may go unnoticed.


Environment

APM

Edge Client

Cause

N/A

Recommended Actions

A Maximise Edge Client When Credentials Required option is introduced to allow the Edge Client login window to maximize itself and prompt for user credentials if required. If you want Edge Client in maximized status while reconnecting or when credentials are required instead of showing Action Required notification, select this option otherwise you can leave the option cleared which is its default behavior. This feature is only supported for Windows Edge Client.


To change the default settings, you can add below XML tags in config.f5c file until the BIG-IP 17.1.0 release which will have respective UI settings:


<MAXIMISE_EDGE_CLIENT_WHEN_CREDENTIALS_REQUIRED>YES</MAXIMISE_EDGE_CLIENT_WHEN_CREDENTIALS_REQUIRED>


This line should be added between the <PROFILE VERSION= X> ... </PROFILE> tags inside that XML file.
