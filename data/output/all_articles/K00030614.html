Known Issue

Memory and performance issues occur when iRules use certain ASN.1 decoding formats.

This issue occurs when the following condition is met:

  • Your BIG-IP system uses iRules that contain calls to ASN1::decode with "a" or "B" characters in the format string.

Impact

The BIG-IP system experiences degraded performance due to memory leaks, and the system may stop responding.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system leaks memory because memory is not being freed.
  • BIG-IP system performance is degraded due to memory consumption.
  • The BIG-IP system runs out of memory and stops responding.

Workaround

Because this issue is associated with a memory leak, there is no workaround to prevent or mitigate the memory leak. To avoid the memory leak, F5 recommends that you avoid using calls to ASN1::decode with "a" or "B" characters in the format string.
