Description

An ASM signature configured in multiple signature sets is not performing the configured action for one of the signature sets
•    Signature set 1 the ASM signature is configured to 'Block'
•    Signature set 2 the ASM signature is configured to 'Alarm'
However, the signature is Blocking in both signature sets

Environment

•    Multilple ASM Attack Signature sets
•    The same ASM signature configured in multiple signature sets
•    The ASM signature configured with different actions (Block / Alarm) in the different signature sets

Cause

None.

Recommended Action

To bypass a specific attack signature, please refer to the following KB articles:
  • K8866: Disabling attack signature checks for specific entities
  • K65408955: Disabling an attack signature for a URL using an iRule

Additional Information

This is expected behavior. ASM will match a request with all of the signature sets in a policy. If any one of the matched signature sets is set to block, the request will be blocked.
