Description

File arg_ex_out found in /var directory.

Environment

  • External Monitors created for monitoring

Cause

arg_ex_out is a logging file.

When external monitors are created using the arg_example sample script, it writes the outcomes of monitoring in the file arg_ex_out.

The script saves the file arg_ex_out in /var directory.
 

Recommended Actions

None.

None.
