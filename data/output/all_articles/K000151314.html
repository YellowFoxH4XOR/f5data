Description

You want to enable the inactivity timeout introduced from K12300: Overview of access policy timeout settings, but you have doubt on the setting of Session Update Threshold. 

Environment

  • Inactivity timeout
  • Session Update Threshold
  • Session Update Window

Cause

Behavior explain.

Recommended Actions

According to the K13395: Network Access session update threshold does not update session expiration time, for Session Update Threshold, enter the number of bytes, multiplied by five, for the threshold.

For example, if your desired threshold is 1000 Bytes/second, you should configure the Session Update Threshold to 5 × 1000, which equals 5000 Bytes/second.

Additional Information

According to K13395: Network Access session update threshold does not update session expiration time, you must also set the Session Update Window value to 2 or greater.
