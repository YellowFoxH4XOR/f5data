Known Issue

Protected Workspace users may be unable to write to a USB flash drive. This issue affects Windows Vista and Windows 7 users, but other operating systems may also be affected. This issue may occur even when the Allow write access to USB flash drive configuration option is enabled and the All USB flash drives option is selected. When the user is connected to Protected Workspace, files that the user copied to a USB flash drive will appear as though they have copied correctly; however, the files will be missing after the user disconnects from Protected Workspace.

F5 Product Development tracked this issue as ID 294191 (formerly CR132955-2) and it was fixed in FirePass 7.0.0, and as ID 242093 (formerly CR132955-1) and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the FirePass, BIG-IP APM, or Edge Gateway Release Notes.

F5 Product Development is tracking this issue as ID 315142 (formerly CR132955) for BIG-IP 10.1.0.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3402.0-HF2 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
