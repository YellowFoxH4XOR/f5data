Description

When trying to perform a config-sync, you may encounter the below error from the configuration utility (GUI).

  •    "Sync failed with error "01070712:3: Caught configuration exception (0), basic_ios::clear."

Environment

  • BIG-IP 
  • HA
  • Config-Sync

Cause

  • This error is normally displayed when both or either of the BIG-IP HA pair member is experiencing disk issue

Recommended Actions

  • Tried performing the actions suggested in K05806090.
  • If above step not solved the problem then please try increasing the disk space of root (/) partition by running below commands from bash of CLI:
    • lvextend -L +50M /dev/mapper/vg--db--sda-set.1.root
    • Note: Replace the partition name (/dev/mapper/vg--db--sda-set.1.root) as per your device configuration.
    • resize2fs /dev/mapper/vg--db--sda-set.1.root
  • Post extending the size on the root partition sync issue should get resolved on both devices.
