K000159574: Unable to replace expired certificate on HTTP Load Balancer

Type
Support Solution
Published
2026-01-24
Updated
2026-01-24
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000159574

Description

 The expired certificate is unable to be replaced or removed from the HTTP LB.

Error: "ReplaceResource: Failed transaction handling http_loadbalancer: STM Error: Applying transaction function: rpe error: code = InvalidArgument desc = Certificate is invalid: certificate 0"

 

Environment

  •  F5 Distributed Cloud HTTP Load Balancer

Cause

When saving an LB after adding a new cert, there is an out of order certificate check in the LB update workflow. This triggers validation on the old cert, causing the LB save to fail.

Answer/Recommended Actions

To address this issue:

  1. Create a new certificate configuration with the exact same name as the old certificate.
  2. Add the new certificate to the LB.
  3. Rename the new certificate to reflect the desired naming convention.

If this solution does not work for you because changes have already been made, the certificate has been deleted, or it is not possible to make the adjustments, you can resolve the issue by recreating the Load Balancer with the new certificate.
