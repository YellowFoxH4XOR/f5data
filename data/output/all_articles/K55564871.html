K55564871: FAST templates not loading after upgrade to v1.7.1

Type
Support Solution
Published
2021-04-07
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K55564871

Description

After upgrading FAST to v1.7.1 there are no templates displayed.

  • Spinning animated gif never stops.
  • Templates are never loaded.

Environment

  • FAST RPM Version: f5-appsvcs-templates-1.7.1-1.noarch

Cause

This is a known issue, experienced when upgrading to v1.7.1 of FAST - which is documented here:

https://github.com/F5Networks/f5-appsvcs-templates/issues/46

Recommended Actions

Uninstall FAST 1.7.1 and install 1.7.0 after restarting restjavad and restnoded.

  1. Download FAST v1.7.0

    https://github.com/F5Networks/f5-appsvcs-templates/releases/tag/v1.7.0

  2. Uninstall FAST v1.7.1
  3. Restart restjavad and restnoded with this command:

    bigstart restart restjavad restnoded

  4. Install FAST v1.7.0
