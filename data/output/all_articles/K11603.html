Known Issue

This is the result of a known issue. When the BIG-IP WebAccelerator is experiencing a temporary overload, such as memory exhaustion, it may send an HTTP "503 Service Not Available" response. When this behavior occurs, the BIG-IP WebAccelerator inserts two Connection headers into the response, similar to the following example:

HTTP/1.1 503 Service Unavailable
Connection: Keep-Alive
Content-Length: 123
Connection: Close

This issue is cosmetic, and does not adversely affect client-side connections.

F5 Product Development tracked this issue as CR136482 and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
