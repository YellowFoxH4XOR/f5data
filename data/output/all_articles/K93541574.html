Description

When looking to deploy a BIG-IQ 8.0.0 AMI from within the EC2 console using BYOL licensing scheme, you are unable to find the right AMI.

Environment

  • BIG-IQ 8.0.0
  • BYOL type license
  • Amazon Machine Image from AWS
  • EC2 Console

Cause

A naming error caused the AMIs to be incorrectly tagged as 'Hourly' instead of BYOL. Both BIG-IQ 8.0.0 Hourly AMIs are actually BYOL, with the difference described below.

F5 BIG-IP Cloud Edition - (BYOL)

F5 Hourly BIG-IQ-8.0.0-0.0.594-standard-Best 1Gbps-210219144151-00f98f15-2c69-43be-b345-e2f93a28b189

"The BIG-IP Cloud Edition is comprised of two components; BIG-IP Per-App VEs & BIG-IQ Centralized Management" "This listing launches both a BIG-IQ console and a BIG-IQ DCD (Data Collection Device) which are able to sync and connect with Per-App VE instances. LTM-only Per-App VE instances can be launched from the Marketplace at https://aws.amazon.com/marketplace/pp/B07G5NQRKM, while LTM & Advanced WAF Per-App VE instances can be provisioned using this listing, https://aws.amazon.com/marketplace/pp/B07G5MT2KT."


F5 BIG-IQ Virtual Edition - (BYOL)

F5 Hourly BIG-IQ-8.0.0-0.0.594-standard-Best 1Gbps-210219144151-fcdf1c42-4c83-4a33-abbe-5fe79a3f1f7d

"F5 BIG-IQ provides a central point of control for F5 physical and virtual devices and for the solutions that run on them. It simplifies management, helps ensure compliance, and gives you the tools you need to deliver your applications securely and effectively."


Recommended Actions

From the AWS Management Console, Go to Services > Compute:EC2 > Images:AMIs. Search under 'Public Images' and filter using the following tags:
  • F5
  • BIG-IQ
  • 8.0.0
The result should show these 2 options, which are both BYOL AMIs.

AMI Name: F5 Hourly BIG-IQ-8.0.0-0.0.594-standard-Best 1Gbps-210219144151-00f98f15-2c69-43be-b345-e2f93a28b189
AMI Name: F5 Hourly BIG-IQ-8.0.0-0.0.594-standard-Best 1Gbps-210219144151-fcdf1c42-4c83-4a33-abbe-5fe79a3f1f7d

NOTE: The AMI-ID will vary depending on the AWS Regional endpoint you are using.
