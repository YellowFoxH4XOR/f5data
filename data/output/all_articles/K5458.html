Topic

The port_lockdown option enables or disables connections to the BIG-IP system through the specified VLAN. You can lock down a particular VLAN to prevent direct connection to the BIG-IP system through that VLAN from the Configuration utility or the command line. For an overview of port lockdown behavior, refer to K7163: Overview of port lockdown behavior.

Enabling or disabling port lockdown from the Configuration utility

To enable or disable port lockdown on a VLAN using the Configuration utility, perform the following steps:

  1. In the navigation pane, click Network.

    The VLAN screen opens.

  2. Click the VLAN name you wish to lock down in the list.

    The properties screen for that VLAN opens.

  3. To enable port lockdown, check the Port Lockdown box.

    To disable port lockdown, uncheck the Port Lockdown check box.

  4. Click Done.

Enabling or disabling port lockdown from the command line

To enable port lockdown from the command line, type the following command:

bigpipe vlan <vlan_name> port_lockdown enable

To disable port lockdown from the command line, type the following command:

bigpipe vlan <vlan_name> port_lockdown disable

Overriding port lockdown for specific services

You can override port lockdown for specific services by enabling the corresponding global variable for that service.

For example, to open SSH ports to the BIG-IP system by way of a VLAN that has port_lockdown enabled, you would enable the open_ssh_port global setting, by typing the following command:

bigpipe global open_ssh_port enable

The following list displays specific services and their default settings on a BIG-IP system running version 4.5.14:

  • bigpipe global open_ssh_port enable
  • bigpipe global open_telnet_port disable
  • bigpipe global open_failover_ports disable
  • bigpipe global open_ftp_ports disable
  • bigpipe global open_ssh_port enable
  • bigpipe global open_rsh_ports disable
  • bigpipe global open_corba_ports enable
  • bigpipe global open_3dns_ports disable
  • bigpipe global open_dnsproxy_ports enable
  • bigpipe global open_snmp_port disable
  • bigpipe global open_radius_ports disable
  • bigpipe global open_securid_port disable

For a list of specific services available on other versions of BIG-IP, refer to the manual for that specific version, or use the bigpipe global show command from your BIG-IP system.
