Topic

If you run the wipedisk utility to recover a BIG-IP system from a corrupt drive partition, and then attempt to re-install BIG-IP software using the PXE installation method, the installation may fail with the following error messages:

sfdisk: ERROR: sector 0 does not have an msdos signature
error: Filesystem mount err for boot/hdc
info: BACKUP HD1.1::otcu.ucs

sfdisk: ERROR: sector 0 does not have an msdos signature

sfdisk: hdc1: bad access: block=0, count=1
ERROR: sector 0 hdc1: bad access: block=0, count=1
does not have an msdos signature

sfdisk: ERROR: sector 0 does not have an msdos signature
error: Could not mount hdc.1
error: An installation error has occurred; code 1
/dev/hdc1: Invalid argument
mount: you must specify the filesystem type
error: Could not save install log.

This issue may occur if you run the wipedisk utility on a BIG-IP platform and you fail to run the command on both the hard disk and CF card. You must run the wipedisk command on both the hard disk and CF card for the following platforms, which contain both media:

  • BIG-IP 3400 (C62)
  • BIG-IP 3410 (C100)
  • BIG-IP 3600 (C103)
  • BIG-IP 6400 (D63)
  • BIG-IP 6800 (D68)
  • BIG-IP 6900 (D104)
  • BIG-IP 8400 (D84)
  • BIG-IP 8800 (D88)
  • BIG-IP 8900 (D106)

Note: If you received the above error message when performing a PXE installation, you can attempt to recover the system by following the procedure in K6346: Recovering from a corrupt drive partition.
