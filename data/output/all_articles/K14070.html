Known Issue

BIG-IP Analytics may cause the Traffic Management Microkernel (TMM) process to fail. This issue occurs when all of the following conditions are met:

  • A virtual server is configured with an Analytics profile.
  • The Analytics profile is configured to perform Traffic Capturing Logging internally or gather the Page Load Time metric.
  • The affected virtual server receives HTTP responses with large payloads.

Impact

The TMM process may fail, resulting in a temporary service disruption for standalone systems, or trigger a failover for a system in a high-availability configuration.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H379921 on the Diagnostics > Identified > Medium|High screen.
  • The BIG-IP system fails over in a high-availability configuration.
  • The TMM process may fai and produce a core file in the /var/core/ directory.
  • The TMM memory usage increases to a level that may cause the system to become unresponsive and the TMM process to fail. You can monitor the TMM memory usage by entering the following command:

    tmsh show sys memory | grep Sys::System -A 8
  • The xfrag memory increases to a level that may trigger the connection sweeper entering aggressive mode. You can monitor the xfrag memory by entering the following command:

    tmsh show sys memory | grep xfrag
  • The connection sweeper may enter aggressive mode and log messages to the /var/log/ltm file that appear similar to the following example:

    011e0002:4: sweeper_update: aggressive mode activated. (213390/250880 pages)

Workaround

To work around this issue, you can turn off the Traffic Capturing Logging and/or Page Load Times settings in the Analytics profile. To do so, perform the following procedure:

Impact of workaround: You may not be able to fully track the virtual server performance when these settings are disabled.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Analytics.
  3. Click the name of the affected Analytics profile.
  4. If selected, clear the check boxes for the Traffic Capturing Logging Type setting.
  5. If selected, clear the Page Load Time check box.
  6. Click Update.
