To configure BIG-IP or 3-DNS to send mail messages to remote email accounts, you must perform the following procedures:

  • Configure the mail server address
  • Add an alias for the root account
  • Test email delivery

Configure the mail server address

Before you use email to send syslog messages or other information from BIG-IP or 3-DNS, you must enable email delivery and add the name of your mail server to the sendmail configuration file.

To enable email delivery and add the name of your mail server to the sendmail configuration file, perform the following steps:

Note: The BIG-IP or 3-DNS must be able to resolve DNS names before this Solution will work. For information about configuring DNS name resolution, refer to K3624: Configuring DNS name resolution.

  1. Log in to the command line.
  2. Change directories to the /config directory, by typing the following command:

    cd /config

  3. Copy the disabled sendmail config file, by typing the following command:

    cp sendmail.cf.off sendmail.cf

  4. Using a text editor, such a vi or pico, edit the sendmail.cf file.
  5. Locate the following lines:

    # "Smart" relay host (may be null)
    DS

  6. Replace the line that begins with DS with the following syntax, replacing <yourmailserver> with the fully qualified host name of your mail server:

    DS<yourmailserver>

    For example:

    DSmail.askf5.com

  7. Save the file and exit the editor.

Add an alias for the root account

Mail messages are normally delivered to the root account on BIG-IP and 3-DNS, since the root user is generally the only command line account. If you add an alias to the root account, BIG-IP will send messages to the alias and to the root account.

To add an alias, perform the following steps:

  1. Back up the existing aliases file, by typing the following command:

    cp /config/aliases /config/aliases.original

  2. Add an alias entry to the /config/aliases file, using the following command syntax:

    echo 'root: <address>' >>/config/aliases

    Replace <address> with the remote email address to which you want to send messages.

    For example:

    echo 'root: admin@askf5.com' >>/config/aliases

  3. Compile the aliases database, by typing the following command:

    newaliases

    This command can take up to a minute to complete if the aliases database is large.

Now messages that are sent to the root user will also be delivered to the remote account.

Test email delivery

To test email delivery, perform the following steps:

  1. Send an email to the root account, by typing the following command:

    echo 'This is a test' |mail -s 'Test' root

  2. Check email from the remote account. A copy of the email should have been delivered there.
