Description

The article describes a traffic issue occuring after upgrading the BIG-IP from an affected Bug ID 1008077 (CVE-2022-23029) software version to an unaffected one. The device had the FastL4 Profile and Asymmetric Routing configured before the upgrade.

Environment

  • BIG-IP
  • Bug ID 1008077
  • Upgrade to 13.1.5 and higher, 14.1.4.4 and higher, 15.1.4.1 and higher, 16.1.0 and higher
  • Asymmetric Routing / nPath Routing / DSR
  • FastL4 Profile

Cause

This kind of issue is caused by a wrong configuration prior to upgrading. It is worth noting that the Asymmetric Routing requires a custom FastL4 Profile "loose-close" option to be enabled. The reason why it could have worked without it previously is bug ID 1008077 (CVE-2022-23029) as it causes the connections to be erroneously passed by the BIG-IP.

Recommended Actions

You are advised to go through your configuration, look for any FastL4 Virtual Servers with the Asymmetric Routing configured and enable the "loose-close" option on a respective FastL4 profile attached to it.
