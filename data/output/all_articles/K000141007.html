K000141007: Procedure to change the CLI Admin password in BIG-IP Next Central Manager

Published
2024-09-09

Legacy Content
Applies to

Source

Description

The CLI password for admin and the GUI password are not the same. The default GUI password is admin/admin. If you set the CLI password for admin, it does not change the GUI password.

Environment

BIG-IP Next Central Manager

Cause

N/A.

Recommended Actions

SSH into the BIG-IP Next CM and run: passwd

N/A.
