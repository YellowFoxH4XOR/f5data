Known Issue

This is the result of a known issue. The LCD display freezes when you shut down the BIG-IP 11050 (E102) platform using the Always-On Management (AOM) Command Menu. When the 11050 platform crashes or you shut the platform down using an AOM menu option, the LCD screen freezes and continues to display the information that was on the LCD at the time the system was running.

For example, if you use the AOM menu option 5 to power off the Host subsystem while the LCD screen displays the Information menu, the screen continues to display the Information menu until the system powers on and loads the BIG-IP operating system.

Note: When a BIG-IP platform crashes or is shut down, the LCD menu should change to show that the system is powered off or shutting down.

F5 Product Development is tracking this issue as ID 225024 (formerly CR138348).
