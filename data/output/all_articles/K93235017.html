K93235017: BIG-IP APM Windows cache and session control is deprecated

Published
2020-08-25
Updated

Applies to

Source

Topic

The Windows cache and session control client-side check feature is deprecated beginning in BIG-IP 15.1.x. F5 Product Development assigned ID 755136 to this.

 Description

Windows cache and session control is a client-side check that you configure using the BIG-IP APM VPE to provide clean-up actions on the client after APM session termination. This feature works with Internet Explorer on Windows XP and Windows 7, but it does not work with the BIG-IP Edge Client.

Since the development of the Windows cache and session control, changes in web security practices have occurred and support for the feature has become increasingly limited with each BIG-IP release. For example:

  • The Chromium project, Chrome, and Mozilla ends support for plug-in APIs. Therefore, for BIG-IP APM 13.0.0 and later, Windows cache and session control is not supported on Mozilla Firefox, Google Chrome, or Microsoft Edge browsers.
  • Web apps now have much better in-browser cache control.
  • Modern browsers now provide the InPrivate browsing feature.
  • All secure web applications now implement only session cookies instead of persistent cookies, which do not have to be deleted.
  • Microsoft announced the end of support for Internet Explorer on June 15, 2022. As a result, BIG-IP systems no longer support Internet Explorer.

These security improvements, along with others, supersede Windows cache and session control.

Recommendation

Support for the Windows cache and session control feature is limited for BIG-IP APM versions. You should avoid configuring the feature in your BIG-IP APM VPE.
