Issue

Description

BIG-IP APM Network Access has a few reserved IP addresses that should be considered when configuring your lease pool.

Environment

  • BIG-IP APM
  • Network Access
  • Lease pool addresses

Cause

Unknown at time of publication.

Recommended Actions

When planning your IP lease pools, you should consider there are certain addresses that are reserved by the system for the Point-to-Point Protocol (PPP) connection. The following addresses are reserved by the system:

  • The lowest numbered IP address is the network address.
  • The second lowest numbered IP address is the PPP interface address.  
  • The highest numbered IP address is the broadcast address.

For example:

  1. The IP pool is assigned the addresses 10.10.10.1 - 10.10.10.254.
  2. The IP address 10.10.10.1 is reserved for the network address.
  3. The IP address 10.10.10.254 is reserved as the subnet broadcast address.   

Clients cannot access or be assigned these IP addresses. The number of IP addresses in an IP pool that are available to clients is always three less than the total number of IP addresses in the subnet.

F5 recommends that you assign lease pool addresses with a range like 10.10.10.1 - 10.10.10.254

Sample lease pool addresses with multiple ranges:

[root@BIG-IP-01:Active:Standalone] config # tmsh list apm resource leasepool example_lease_pool-2
apm resource leasepool example_lease_pool-2 {
    members {
        10.10.10.1 - 10.10.10.254{ }
        11.11.11.1 - 11.11.11.254 { }
    }
}
 

On FirePass controllers, the IP address 192.168.1.1 is assigned to the PPP tunnel. On a BIG-IP APM system, the PPP tunnel is assigned the IP address of 1.1.1.1
