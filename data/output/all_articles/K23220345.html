Description

How to recover the root password on RAID-capable BIG-IP platforms.

Environment

  • BIG-IP 14.1.0 and later
  • BIG-IP platforms: 6900, 7000s, 7200v, 7055, 7255, 8900, 8950, 10000s, 10200v, 11000, 10055, 10255, or 11050
  • CLI access to BIG-IP

Cause

You should consider using this procedure under the following conditions:

  • You need to reset the password for an administrative account, such as the root account on BIG-IP v14.1.0 and later.
  • You have a RAID-capable BIG-IP platform.

Recommended Actions

  1. Connect a terminal to the BIG-IP serial console port.
  2. Using switchboot or tmsh, find the volume to recover the root password

Note: Access to switchboot and tmidiag are not required for this procedure. If you do not have access to TMOS, simply take note of the relevant boot location when using GRUB.

  1. Restart the BIG-IP system
reboot

During boot the BIG-IP pauses at the GRUB menu and counts down before continuing the boot process.
  1. Before the countdown expires, use the Up Arrow and Down Arrow to select the appropriate boot image.
  2. Press e to edit the current entry. A new GRUB menu screen displays.
  3. Use the Up Arrow and Down Arrow to select the line that appears similar to the following
module /boot/2/vmlinuz ro root=UUID=c90e3f25-57a4-4370-aac3-xxxxxxxxxxxxx console=ttyS0 panic=1 platform=C117 quiet
  1. Press the keyboard Ctrl-E to start editing at the end of the line.
  2. Append rd.break to the end of the line. For the C117 platform, the line may appear similar to the following
module /boot/2/vmlinuz ro root=UUID=c90e3f25-57a4-4370-aac3-xxxxxxxxxxxxx console=ttyS0 panic=1 platform=C117 quiet rd.break
  1. Press the Ctrl-x keyboard sequence to boot to the modified config.
  2.  After the boot sequence completes, the following command-line prompt appears:
switch_root:\#
  1. Mount /sysroot/config and /sysroot/var partitions. Depending on the platform, the mount command may appear similar to the following example:
switch_root:/# mount /dev/md125 /sysroot/config
switch_root:/# mount /dev/md126 /sysroot/var
  1. For any partitions mounted as "ro" (read only) you must remount with read write mode enabled. To remount /sysroot and /sysroot/usr partitions to read write:
mount -o remount,rw /sysroot
mount -o remount,rw /sysroot/usr
  1. Change the root file system to / using chroot
chroot /sysroot
The prompt displays 
sh-4.2#
  1. Change root password using passwd  
passwd

Changing password for user root.
New BIG-IP password:
Retype new BIG-IP password:

passwd.bin 2  : all authentication tokens updated successfully.
  1. Force SELinux to relabel context on next boot
touch /.autorelabel
  1. Type exit twice to allow leave to the shell environments
sh-4.2# exit
switch_root:/# exit

Note: When performing the procedure on a VIPRION with more than one blade installed ensure the password is changed on the primary blade. Do this by logging in to the secondary blade after rebooting and resetting the password there. After you are logged in, use ssh primary (which is key-authenticated and doesn't prompt for a password), and then using the passwd root command again to change the password.
