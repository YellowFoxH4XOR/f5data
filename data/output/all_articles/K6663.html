Known Issue

This is the result of a known issue. Some Traditional Chinese language versions of Trend Micro security software (antivirus, personal firewall, or integrated security suites) are not detected by the OPSWAT libraries that are used by the FirePass controller's Windows Anti-virus Endpoint Inspector. Trend Micro Officescan 6.5 is one version known not to be detected; earlier versions of this product may also not be detected.

If you have configured a pre-logon sequence to check for anti-virus software, and clients with Trend Micro Officescan are not passing the pre-logon sequence check, you can check the session variable that represents the number of detected anti-virus software programs to see if you are experiencing this issue.

If you are running FirePass version 5.5.x or earlier, you can configure the FirePass controller to display pre-logon data and look for the value of the session.av.summary.count variable. A result that contains 0 (zero), such as the example below, indicates no anti-virus software was detected:

[av] => Array
                (
   [list] => Array
       (
       )
   [summary] => Array
       (
           [count] => 0
           [monitor] => 0
       )
                )

Note: For more information about configuring this check and interpreting the results, refer to K6358: Displaying pre-logon data for a FirePass client.

If you are running FirePass versions 6.0.0 or later, you can obtain the pre-logon data by selecting the Save user's session variables to Logon Reports check box on the Device Management: Maintenance: Troubleshooting Tools page. You can view the data on the Reports: Logons page, by clicking on the link of the appropriate username in the Logon column.

The following result indicates that no anti-virus software was detected:

Session Variable %session.av.summary.count%= ' 0 '
Session Variable %session.av.summary.monitor%= ' 0 '

F5 Product Development tracked this issue as CR65903 and CR69869, and it was fixed in FirePass version 5.5.2 and 6.0.1. For information about upgrading, refer to the FirePass release notes.

This issue has been fixed in OPSWAT hotfix 2.2.4 issued for FirePass versions 5.5.0 and 5.5.1, and OPSWAT hotfix 2.2.7 issued for FirePass versions 5.5.2 and 6.0.0. You may download these hotfixes or later versions of the OPSWAT hotfixes from the F5 Downloads site.

For instructions about obtaining and installing an OPSWAT hotfix, refer to K6664: Obtaining and installing OPSWAT hotfixes.
