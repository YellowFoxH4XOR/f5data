Description

01020036:3: The requested profile (/Common/<wam_profile_name>) was not found.

Environment

  • The BIG-IP LTM device was upgraded to BIG-IP version 14.x or above 
  • The BIG-IP device is configured with a Web Acceleration profile
  • Configuration fails to load.
  • When running the following TMSH command: load /sys config verify you got the a message similar to this:
    01020036:3: The requested profile (/Common/<wam_profile_name>) was not found.
    Note: <wam_profile_name> is the name of the WAM that is invalid or does not exist on the target BIG-IP LTM device.

Cause
Configuration objects are validated during the configuration load. When a referenced configuration object does not exist in the BIG-IP configuration and error is produced and the configuration load is aborted. For this particular error, WAM profiles are coming from AAM features but beginning in BIG-IP version 14.x these are removed because are already covered under LTM profiles.

Recommended Actions
Remove the WAM profiles from the virtual servers prior the upgrade, use  'f5-tcp-lan' and 'f5-tcp-wan' instead. To do so perform the following:

  1. Log on to the BIG-IP Configuration utility (gui).
  2. Go to Local Traffic > Virtual Server > Virtual Server List.
  3. Click the Name link of the affected virtual server.
  4. In the Configuration section locate Protocol Profile (Client).
  5. From the Protocol Profile (Server) pull-down menu select f5-tcp-wan.
  6. In the Configuration section locate Protocol Profile (Server).
  7. From the Protocol Profile (Client) pull-down menu select f5-tcp-lan.
  8. Click Update.

If error message occurs after upgrade, and changing WAM profile for virtual server is not preferred. 

  1. Log into BIG-IP CLI
  2. Create backup for /config/bigip.conf
    # cp /config/bigip.conf /config/bigip.conf-K31000030
  3. Open /defaults/wam_base.conf using preferred text editor, and search for <wam_profile_name>
  4. Copy <wam_profile_name>  profile and close /defaults/wam_base.conf.
  5. Open /config/bigip.conf and paste the profile copied.
    Example:

    ltm profile tcp wam-tcp-lan-optimized {
        defaults-from /Common/tcp-lan-optimized
        init-cwnd 16
        init-rwnd 16
        slow-start enabled
    }
  6. Save and close /config/bigip.conf.
  7. Reload the configuration. Ensure configuration is able to load correctly.
    # tmsh load sys config verify
  8. If no other error message, run the command to load the configuration
    # tmsh load sys config
  9. Save the configuration
    # tmsh save sys config
