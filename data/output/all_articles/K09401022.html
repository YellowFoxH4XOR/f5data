Topic

You should consider using this procedure under the following condition:

  • You want to configure the maximum boundary length of HTTP multipart headers.

Description

The HTTP Content-Type header for multipart entities requires a boundary header, which is used to define the encapsulation boundary. The BIG-IP ASM system uses the internal system max_boundary_length variable to set the maximum length of the multipart boundary from HTTP request headers. If a request is made with a boundary length longer than the configured maximum limit, an Unparsable request content subviolation is issued. The default maximum value of the multipart boundary length is 70.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP system.

Procedures

Configuring the maximum boundary length from the BIG-IP ASM command line

Impact of procedure: Performing the following procedure causes a temporary traffic disruption while the BIG-IP ASM service restarts. You should perform this procedure only during a scheduled maintenance period.

  1. Log in to the BIG-IP ASM command line.
  2. To specify the maximum length for the multipart boundary by modifying the max_boundary_length variable, use the following command syntax:

    /usr/share/ts/bin/add_del_internal add max_boundary_length <value>

    For example, to set the boundary maximum length to 100, type the following command:

    /usr/share/ts/bin/add_del_internal add max_boundary_length 100

  3. To restart the BIG-IP ASM process, type the following command:

    tmsh restart /sys service asm

Configuring the maximum boundary length from the Configuration utility

Note: Adding a BIG-IP ASM internal system variable from the Configuration utility is available on BIG-IP 13.1.0 and later.

Impact of procedure: Performing the following procedure causes a temporary traffic disruption while the BIG-IP ASM service restarts. You should perform this procedure only during a scheduled maintenance period.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Options > Application Security > Advanced Configuration > System Variables.
  3. Click Create.
  4. For the Parameter Name, type max_boundary_length.
  5. For the Parameter Value, specify the maximum length value for the multipart boundary you wish to set.
  6. Click Create.
  7. Log in to the command line.
  8. To restart the BIG-IP ASM process, type the following command:

    tmsh restart /sys service asm
