Topic

You should consider using this procedure under the following condition:

  • You want the BIG-IP system to respond (with a maintenance page) if the virtual server resources (pool or pool members) are unavailable.

Description

When the BIG-IP system receives a request for a virtual server that does not have available resources (for example, the pool is marked down with no available pool members) you can configure an iRule to send an HTTP response, such as a maintenance page, to the client. To do so, perform the following procedure:

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Have a virtual server configured with an HTTP profile applied.
    • HTTPS virtual servers for encrypted traffic require a Client SSL profile in addition to the HTTP profile.
  • The virtual server is configured with resources that are monitored with a BIG-IP health monitor.

Procedures

To watch a video demo of this procedure, go to Use an iRule to display a maintenance page when the pool is down.

Impact of procedure: There should be no negative impact from following these procedures. However, F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > iRules > iRule List.
  3. Click Create.
  4. In the Name field, type a name for the iRule.
  5. In the Definition section, use the following command syntax:

    when HTTP_REQUEST {
        if { [active_members [LB::server pool]] == 0 } {
            HTTP::respond 200 content "<content>"
        }
    }

    Replace <content> with the HTTP content you want to display. For example, to display a simple page that displays "Sorry, this page is not currently available", use the following iRule definition: 

    when HTTP_REQUEST {
        if { [active_members [LB::server pool]] == 0 } {
          HTTP::respond 200 content "Sorry, this page is not currently available."
        }
    }

    However, you can also replace <content> with a formatted HTML response, similar to the following iRule definition: 

    when HTTP_REQUEST { 
       if { [active_members [LB::server pool]] == 0 } { 
         HTTP::respond 200 content "
          <html>
             <head>
                <title>Maintenance Page</title>
             </head>
             <body>
                We are sorry, but the site you are looking for is temporarily out of service.
                If you feel you have reached this page in error, please try again.
             </body>
          </html>
          "
       }
    }

    For more information about the available HTTP::respond iRule command syntax, refer to the HTTP::respond article on F5 Cloud Docs.

  6. Click Finished.
  7. Associate the iRule with the virtual server you want by performing the following procedure:
    1. Go to Local Traffic > Virtual Servers.
    2. Click the name of the virtual server you want.
    3. Select the Resources tab.
    4. In the iRules section, click Manage.
    5. In the Available column, select the iRule you just created.
    6. Click << to move the selected iRule to the Enabled column.
    7. Click Finished.
