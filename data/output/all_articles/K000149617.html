K000149617: F5OS-C Cannot import 1.6.2 image and delete any other images

Type
Support Solution
Published
2025-02-04
Updated
2025-11-13
Applies to
  • F5OS
  • F5OS-C: 1.5.X, 1.6.X, 1.6.2, 1.6.1, 1.6.0, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000149617

Description

  • Unable to import new image and delete old images
  • Error messages similar to the following can be seen on sw-mgmt.debug

    ERROR: sw-mgmt: priority=error msgid=0x3501000000000153 msg=Unexpected error importing partition services 1.6.0-18695: Failed to receive partition services 1.6.0-18695 port assignment from active peer.
    |
    DEBUG: Failed to receive partition services 1.6.0-18695 port assignment from active peer.
    |
    ERROR: sw-mgmt: priority=error msgid=0x3501000000000117 msg=Failed to import /var/export/chassis/import/iso/F5OS-C-1.6.2-26579.PARTITION.EHF-3.iso.

Environment

  • Velos
  • F5OS-C
  • Controller or Partition Image

Cause

Unknown

Recommended Actions

To recover from the current status, you can perform the following steps:

  1. Reboot both controllers one by one
  2. Restart sw-mgmt service on both controller

    systemctl restart sw-mgmt
    systemctl status -l sw-mgmt

  3. Run on both controllers

    touch /var/import/staging/*.iso
  4. Via GUI delete old images one-at-a-time.
