Description

  • vCMP guest stuck in Stopping status
  • The vCMP host may log the following, related messages:

    01510014:1: vCMP guest <guestname> heartbeat timeout at the halfway mark.
    01510013:1: vCMP guest vcmp-guest lost heartbeat
    01510011:1: vCMP guest <host_name> powered off
    01510007:6: Guest (vcmp-guest): VS_RUNNING->VS_STOPPING
    01510006:5: Guest (vcmp-guest): Stopping VM

Environment

  • vCMP system
  • vCMP guest
  • vCMP Host

Cause

Seen behaviour is caused by a known issue tracked with the Bug ID 486997

Recommended Actions

To recover the guest or guests, you can will need to reboot the vCMP host

  1. Connect to Host CLI
  2. Reboot the Host

    reboot
