Known Issue

Description

The ARX system may deny access to clients.

This issue occurs when all of the following conditions are met:

  • The client has an established connection to a share in a CIFS only namespace
  • The client renamed the exported directory by changing the case of the characters

For example, this issue would occur if the exported directory was renamed from FOO to foo.

Impact

The ARX system may deny access to clients.

Symptoms

As a result of this issue, you may encounter the following symptom:


  • The ARX system will log a LINKNOTREE error message in the syslog file. The error message appears similar to the following example:
VCIFS-1-NOTE-LINKNOTREE:: The dereferenced path '/ntfs/foo' from the symlink '/ntfs/FOO' lies outside the share 'foo' where the user is connected. The ARX will reply with an access denied error.

Note: If the namespace is multi-protocol, the LINKNOTREE message might be valid if the referenced path is a symlink that lies outside the subtree of the share to which the client is connected. For more information about the LINKNOTREE message, type the show doc linknotree command.

Workaround

To work around this issue, clients affected by this issue should disconnect from the share and reconnect.
