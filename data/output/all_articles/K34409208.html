Known Issue

Beginning with the following versions of BIG-IP VE Public Cloud BEST (200M, 1G, 5G, 10G), images in AWS and Azure come with FIPS mode are enabled by default:

  • 14.1.2

Note: Only the BIG-IP 14.1.2 is FIPS 140-2 validated.

However, the FIPS license does not show up in the BIG-IP Configuration utility as an active module when you go to System > License.

This issue occurs when the following conditions is met:

  • You are running a BIG-IP VE Public Cloud BEST image with pre-licensed FIPS feature.

Impact

None. This issue is cosmetic and does not affect FIPS functionality.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In pre-licensed PAYG Best images, the FIPS feature does not show up by default as an Active Module in the BIG-IP VE Configuration utility output when you go to System > License.
  • In the BIG-IP command line, the FIPS license does not show up when you run the TMOS (tmsh) command show sys license | grep FIPS

Workaround

You can validate that the FIPS is licensed and enabled by checking the license and log file manually. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To confirm if FIPS 140-2 Compliant mode is activated, enter the following command:

    tmsh list sys db security.fips140.compliance

    FIPS 140-2 Compliant mode is activated if the return value is true. The output should appear similar to the following example:

    sys db security.fips140.compliance {
        value "true"
    }

  3. To validate if the FIPS feature has been successfully initialized in the tmm logs, enter the following command:

    zgrep -i FIPS /var/log/tmm*

    If the FIPS feature is initialized successfully, the output should appear similar to the following example:

    notice TMM initializing OpenSSL in Common Criteria or FIPS-mode.
    debug bigip1 tmm[18484]: OpenSSL is initialized in FIPS mode.
    debug ip-10-10-5-84 tmm[18484]: OpenSSL is initialized in FIPS mode. 
    notice FIPS 140 Compliance is licensed
