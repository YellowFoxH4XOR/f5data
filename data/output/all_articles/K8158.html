Topic

Using a Portal Access Web Application Favorite to access a URL that contains a percent character may generate the following error message in the web browser:

Security exception
Access to <http://10.0.0.10/Report/Forms/Edit.aspx?index=1&query=%20where%20Loginname
like\\\'myname\\\'%andVendorTypelike\\\'%W\\\'> is denied. 
Reason: Ambiguous URL. Invalid escape sequence or %00 is present.

According to RFC 1738, a percent character that is not part of the standard URL encoding scheme (also called percent encoding) is an unsafe character. URL encoding consists of the percent character, followed by two hexadecimal characters that represent the character's US-ASCII value. A percent character not followed by two hexadecimal characters is unsafe. Therefore, the percent character must be encoded.

This error message is generated when the reverse proxy engine of the FirePass controller encounters an invalid percent character in a URL.

Workaround

URLs that contain percent characters can be found in applications that use percent characters to indicate variable strings, such as those used for database queries. If the URL being accessed is a static URL that can be configured as a webtop favorite, you may be able to rewrite the URL using URL encoding on the percent characters. The URL encoding for the percent character is %25.  Substitute %25 for each occurrence of %. The success of this method will depend on the server-side application software performing the decoding appropriately.
