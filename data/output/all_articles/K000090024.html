K000090024: Unnecessary NUL string in NAP log

Type
Support Solution
Published
2021-08-29
Updated
2021-08-30
Source
https://my.f5.com/manage/s/article/K000090024

Description

  • Log messages contain "NUL" character in first position

Environment

  • NGINX
  • NAP

Cause

This is a known issue tracked as WAFMC-4332

 Recommended Actions

As a workaround, you can send logs to netcat and write them to the desired destination.

 

  1. # from nginx.conf
    1. app_protect_security_log "/etc/app_protect/conf/log_default.json" syslog:server=localhost:10123;
  2. # start netcat
    1. ncat -vlkp 10123 > /var/log/app_protect/security_default.log 2>&1 &
