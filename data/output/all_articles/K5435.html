K5435: The UDP Protocol is no longer supported for iQuery communications

Type
Knowledge
Published
2006-05-11
Updated
2023-02-21
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP GTM: 9.2.3, 9.2.2
Source
https://my.f5.com/manage/s/article/K5435

Issue

In 3-DNS 4.x, iQuery communication using the UDP Protocol was a valid configuration option.

However, beginning in BIG-IP GTM 9.2.2, iQuery communication exclusively uses TCP port 4353, which is SSL encrypted.

Therefore, iQuery communication using the UDP Protocol is no longer a valid configuration option.
