K25042015: APM Client alerts: Revocation information for the security certificate for this site is not available. Do you want to proceed?

Type
Support Solution
Published
2020-06-10
Updated
2023-11-14
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K25042015

Description

The BIG-IP Edge client alerts:

Environment

  • BIG-IP Edge Client or Endpoint Inspector in the browser
  • Client SSL profile
  • Certificate / intermediate certificate contain the CRL

Cause

Edge client or Endpoint Inspector cannot download the CRL of the certificate / intermediate certificate.

Answer/Recommended Actions

Find the CRL information for the certificate / intermediate certificate, make sure the client can access the CRLDP.

  1. Click View Certificate.
  2. The window Certificate popup.
  3. Click the tab Details.
  4. Click the field CRL Distribution Points, get the value, find the CRL location. For example:
[1]CRL Distribution Point
     Distribution Point Name:
          Full Name:
               URL=http://crl.entrust.net/level1k.crl
Client will try to download the file http://crl.entrust.net/level1k.crl, verify the certificate was revocated or not.
  1. Click the tab Certificate Path.
  2. If the intermeditae certificate existed, click the intermediate certificate, then click View Certificate, repeat the steps 2-4, find the CRL information.
  3. Check the client network environment, make sure it can download the CRL information.

Additional Information

The browser will check the CRL information too, but maybe not popup the Security Alert above, it is depending on the browser.

Note: Beginning BIG-IP Edge Client for Windows and Mac OS, APM Clients 7.2.4.1, BIG-IP Edge Client will prevent connection to BIG-IP APM Servers with untrusted (invalid or self signed) SSL certificates. Please refer to K000133271 and K000136970 for more details.
