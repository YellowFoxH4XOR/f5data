K000150450: WAF related files in qkview are prone to be a false positive with Anti-Virus software

Type
Support Solution
Published
2025-08-08
Updated
2025-08-08
Source
https://my.f5.com/manage/s/article/K000150450

Description

3rd party Anti-Virus system might detect suspicious files in qkview like the presence of PHP/Masqshell.E!dha 

Environment

  • BIG-IP ASM
  • Public Cloud
  • Microsoft Defender for Cloud
  • Suspicious activity

Cause

/var/tmp/asm_tables_dump/conf.tgz is the file in a qkview that contains ASM/AdvWAF configurations including matching rules that are used to detect malicious patterns seen in HTTP transactions. In order for ASM/AdvWAF to detect malicious activities in transactions, the matching rules itself contain keywords and strings in regex patterns that are often to be used by attacker who is attempting exploit vulnerabilities. Due to the nature of the files, qkview stored in your computer might prone to be a false positive if 3rd party Anti-Virus detection system scans the qkview.

Recommended Actions

None. Files are not malicious and can be safely ignored.
