K000162186: F5OS image signature verification process and October 2025 implications

Type

Published
2026-07-22
Updated
2026-07-22
Applies to

Source

Description

F5OS ISO images are cryptographically verified when imported into the system, this process is always enforced by default and not configurable.

Since October 2025, on newer versions, there's an explicit check on the certificates/keys used to sign versions prior to October 2025, preventing the image to be imported with a “Signature verification failed”.

Environment

Product: F5OS

Cause

The service that imports F5OS images is the sw-mgmt. Some considerations on the verification process:

  • F5 ISO images contain a chain of certificates that are verified against a root CA present on all F5OS versions.
  • Each ISO image also contains an embedded signature that was signed by the key of the certificate included on the ISO.
  • Only if the verification of the certificates and the embedded signature are both successful the image is imported into the system.

After October 2025, the rotation of the certificates and keys have introduced changes on this internal process:

  • A new explicit check that denies some certificate fingerprints of the old certificates has been added, versions signed before October 2025 will not be imported.
  • Some versions released after October 2025 included certificates incorrectly generated with 6 months of validity. This is related with Bug ID 2227221. On F5OS 2.0.0 or later, versions affected by this defect won't be allowed to be imported.

The failure can be seen on:

  • GUI: at Software Management as “Signature verification failed”.
  • /var/log/sw-mgmt.debug:
ERROR: sw-mgmt: priority=error msgid=0x3501000000000111 msg=Signature verification failure <ISO_path>
INFO: sw-mgmt: priority=info msgid=0x3501000000000196 msg=File <ISO_path> removed from disk. Reason signature.

Answer/Recommended Actions

This process fails only when importing an old version, if the image is already installed, the downgrade is possible directly. When upgrading to newer versions, specially F5OS 2.0.0 from those versions discussed in K000157005, keep the last version installed until it is clear that no downgrade is required.

Note: It will only be possible to upgrade to unified F5OS 2.X versions from specific patch releases. Refer to K21501912: Software lifecycle policy for F5OS or K000161884: F5OS-A and F5OS-C are unified in F5OS 2.0.0 to obtain more information.

Versions higher than the following list for each version train, will be importable on any F5OS version, including F5OS 2.0.0 or later.

  • F5OS-A 1.5.4, 1.8.3.
  • F5OS-C 1.6.4, 1.8.2.

Additional Information

For information related with the certificate and key rotation of October 2025, please refer to K000157005: F5 signing certificate and key rotation, October 2025.

For information related with F5OS BIG-IP tenant signing, please refer to K000157194: F5OS Tenant Image Installation Fails with 'Verification Failed'.
