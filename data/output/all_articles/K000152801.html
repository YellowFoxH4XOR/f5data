K000152801: Unable to create qkview stuck at 'Executing /usr/sbin/drd --readlong=/usr/sbin/readlong --all'

Type
Support Solution
Published
2025-07-29
Updated
2025-07-30
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000152801

Description

You are trying to generate a qkview on the BIG-IP, but it gets stuck, and the qkview is not generated. When you run qkview with the -v option, it gets stuck at 'Executing /usr/sbin/drd --readlong=/usr/sbin/readlong --all'.

 

[bigip:Active:In Sync] config # qkview -v

<snip>

Executing Module: [qkafm.so]

  Executing /usr/bin/du -h /var/lib/mysql/logdb/ ...

  Result: [0] Elapsed: 0.021784

  Executing /usr/sbin/drd --readlong=/usr/sbin/readlong --all ...  

Environment

BIG-IP

Running qkview command

Cause

F5 tracks the issue as ID 747823.

Recommended Actions

As a workaround, you can modify the drd script by following the steps outlined below and run qkview command again.

 

# mount -o remount,rw /usr

# cp -pv /usr/sbin/drd /shared/drd_bck

# sed -i 's|return output.stdout.readlines()|return output.communicate()[0].splitlines()|' /usr/sbin/drd

# mount -o remount,ro /usr

 

To revert the change, you can follow the steps outlined below

 

# mount -o remount,rw /usr

# cp -pv /shared/drd_bck /usr/sbin/drd

# mount -o remount,ro /usr
