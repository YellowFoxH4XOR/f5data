K000137127: After upgrade cannot log in to SSH (command line)

Type
Support Solution
Published
2023-10-05
Updated
2024-07-01
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4, 17.1.1, 17.1.X, 17.1.0
Source
https://my.f5.com/manage/s/article/K000137127

Description

After software upgrade to BIG-IP 16.1.4+ or 17.1.0.1+ cannot log in to SSH (command line), getting the following error:
no hostkey alg

Environment

  • BIG-IP 17.1.x or 16.1.4
  • SSH (command line) connection using ssh-rsa host key algorithm

Cause

ID 1269593

Recommended Actions

Use an SSH client that supports rsa-sha2-256 or better. 
If it is not possible, please contact F5 Support and request Engineering Hotfix for ID 1269593 .

Additional Information

To create verbose output of ssh connection use ssh -vvv
