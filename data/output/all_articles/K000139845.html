K000139845: Unable to access CLI using Admin user for BigIQ

Applies to

Source

Description

Unable to access CLI using Admin user

 

Environment

BigIQ

Cause

Command line by default does not allow Admin to log in, only the Root user.

 

Recommended Actions

To allow Admin to log into to CLI:

You will need to log into cli as root first, and then you can modify the admin account to allow just tmsh or full bash.

 

This allows admin to use CLI and has full access to bash and tmsh:

#tmsh modify auth user admin shell bash

 

This allows admin to use CLI and only has access to tmsh:

#tmsh modify auth user admin shell tmsh
