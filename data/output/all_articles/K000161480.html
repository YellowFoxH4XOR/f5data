K000161480: Velos Tenant creation difference between UI and CLI

Description

When creating a tenant on F5 VELOS using the CLI, the "nodes" field is required and refers to the number of physical blades (slots) assigned to the tenant. In the WebUI, this field is abstracted as "allowed slots" under Tenant Deployments, and the "slot" label in Resource Provisioning is informational only and not directly configurable. The WebUI does not currently provide an option to set the "max-nodes" value, which can only be configured via CLI. 

Environment

  • Platform: F5 VELOS
  • Software Version: F5OS 1.8.2

Cause

This behavior is tracked under Bug ID2199785: "The default max-nodes per tenant cannot be set via webUI."

The WebUI abstracts the assignment of blades/slots and does not expose the "max-nodes" configuration option due to a product limitation. The "nodes" field in the CLI corresponds to the physical blades (slots) in the VELOS chassis assigned to the tenant. In the WebUI, this is abstracted as "Allowed Slots" under the Tenant Deployments screen. The "Slot" label under Resource Provisioning in the WebUI is informational only and not directly configurable.

Answer/Recommended Actions

  • Use the CLI to set the "nodes" value when creating tenants on VELOS if you need to specify the number of blades/slots.
default-1(config)# tenants tenant <tenant_name> config image <image_name> nodes [ <node_IDs> ] vcpu-cores-per-node <number_of_cores> management-ip <IP_address> prefix-length <subnet_mask_prefix> gateway <gateway_ip> vlans [ <vlan_ids> ]
  • In the WebUI, use the "allowed slots" field under Tenant Deployments to assign blades, but note that "max-nodes" cannot be set.
  • Refer to F5 documentation for further details on tenant deployment and resource provisioning.

Key Points:

  • The nodes field specifies the number of physical blades (slots) to assign to the tenant. In this example, nodes 1 assigns the tenant to one blade.
  • The other parameters (image, mgmt-ip, etc.) should be set according to your deployment requirements.
