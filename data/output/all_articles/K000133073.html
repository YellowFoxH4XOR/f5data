K000133073: /shared full - large mgmt_acld.out file

Type
Support Solution
Published
2023-05-26
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000133073

Description

The /shared partition is full and the below error message is being logged:
011d0004:3: Disk partition /shared has only 0% free
 
Running the following command we can determine that mgmt_acld.out is the largest file:

# find /shared/ -xdev -type f -exec du {} \; | sort -rn | head -20
361110 /shared/tmp/mgmt_acld.out
14433 /shared/vadc/azure/waagent/custom-script/download/0/f5-appsvcs-3.20.0-3.noarch.rpm
7949 /shared/vadc/azure/waagent/Microsoft.Azure.Extensions.CustomScript-2.0.7/bin/custom-script-extension
6338 /shared/rrd.1.2.perm/endpisession
 

Environment

  • BIG-IP
  • AFM not provisioned
     

Cause

N/A
 

Recommended Actions

If you are not utilizing AFM it is safe to delete the file. You can also restart the mgmt_acld process to reset the file size.

  1. Make a backup copy of the /shared/tmp/mgmt_acld.out file.
  2. Changed the sys db variable to reduce log noise level. The default value is Informational.
tmsh modify sys db log.mgmt_acld.level value Warning
 
      3. Restart mgmt_acld process to reset the file size:
 
bigstart restart mgmt_acld
