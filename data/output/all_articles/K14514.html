Known Issue

MAC masquerade is not applied to EtherIP tunnel packets.

This issue occurs when all of the following conditions are met:

  • The VLAN uses a tunnel configured to use EtherIP encapsulation.
  • The tunnel local endpoint uses a floating self IP address.
  • The device group associated with the floating self IP address is configured with a MAC masquerade address.

Impact

The BIG-IP system may experience traffic interruptions following a failover event.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H424883 on the Diagnostics > Identified > High screen.
  • The BIG-IP system may experience traffic interruptions following a failover event.
  • Following a failover, the EtherIP tunnel packets from the newly active BIG-IP system continue using the BIG-IP system's non-floating MAC address for the VLAN.
