Known Issue

Connection mirroring fails when a FastL4 virtual server references an HTTP or BIG-IP PEM profile.

This issue occurs when all of the following conditions are met:

  • You have multiple BIG-IP systems in a high-availability configuration.
  • You have configured a FastL4 virtual server.
  • You have associated an HTTP or a BIG-IP PEM profile with the FastL4 virtual server.
  • You have enabled connection mirroring on the FastL4 virtual server.

Impact

The BIG-IP system will not maintain connections after a failover event.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Client connections fail after a failover event.
