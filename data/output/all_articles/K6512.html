K6512: The BIG-IP GTM system always creates the parent zone for a wide IP

Known Issue

The BIG-IP GTM system will not allow you to create a wide IP that uses the same domain name as a zone. If you create a wide IP that uses the same domain name as an existing zone, the BIG-IP GTM system attempts to create a parent zone.

If you wish to configure the BIG-IP GTM system to be the authoritative DNS server only for a sub-zone, while other DNS servers remain authoritative for the parent zone, a conflict will ensue.

F5 Product Development tracked this issue as CR67992 and it was fixed in BIG-IP GTM 9.2.4 and 9.3. For information about upgrading, refer to the BIG-IP GTM Release Notes.
