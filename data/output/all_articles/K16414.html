Description

The Firefox browser versions 36.0.1 and 37.0.1 are unable to connect to the BIG-IQ 4.5.0 system. The affected browser navigating to the BIG-IQ user interface appears to load the page, but fails to connect.

Note: This also affects BIG-IQ 4.5.0 HF1.

This issue is caused by the Firefox certificate cert8.db file in the local system that was installed with the affected Firefox version. This is not an F5 product issue.

Recommendations

When you access the BIG-IQ system using the affected Firefox browser version, consider the following options:

  • Use another browser that the BIG-IQ system supports. For more information, refer to the BIG-IQ system release notes.
  • Review the workaround options discussed in the Mozilla Support Forum.

    Note: The Mozilla Support Forum link is not maintained by F5, and could be removed without our knowledge.

  • Alternatively, you can work around this issue by renaming your Firefox profile's cert8.db file to another name, and let Firefox recreate a new one. Renaming the cert8.db file causes you to lose all your personal certificates in your Firefox profile. If this is a valid option for you, perform the following procedure:

    Impact of the procedure: Performing the following procedure indirectly removes all of your Firefox profile's personal certificates, which includes all Intranet and Internet site certificates that you have previously accepted and stored. Be sure to export the stored Firefox certificates that you want to keep before you perform this procedure. You cannot reverse this procedure, or recover the removed certificates.

    1. On the affected Firefox browser, type the following URL:

      about:support

    2. Locate Profile Folder, and click Show Folder.
    3. Close the Firefox application.

      If the application is not closed, you cannot rename the cert8.db file in the following step.

    4. From the folder view, locate the file named cert8.db, and rename it to another file name (for example, cert8.db.removed).
    5. Restart the Firefox browser application, and you should be able to access to the BIG-IQ user interface.
