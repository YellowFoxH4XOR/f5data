K000158200: Duplicate logs are streamed to HTTP Receiver

Type

Published
2025-12-15
Updated
2026-06-21
Applies to

  • F5 Distributed Cloud
Source

Description

Duplicate logs are seen in your HTTP Receiver

 

Environment

  • F5® Distributed Cloud (SaaS)
  • F5® Distributed Cloud Global Log Receiver

Cause

  • If the log receiver is not accessible at times, our infrastructure will attempt to resend data. This happens in response to 500 errors, like a 504. So duplicate requests may be expected. If the log receiver is down for a short period of time, the GLR will cache the logs. When the receiver becomes available again, all the cached logs should be sent to the log receiver, ensuring there is no missing data. If the system sends some logs but the connection is broken during the transmission, you might receive duplicates on the next attempt.
  • Our HTTP GLR expects an HTTP response from the endpoint, otherwise it counts it as a failure. We will retry as previously discussed and you will see the duplicates.

Answer/Recommended Actions

  1. Please ensure that the log receiver is consistently up and running.
  2. Please ensure that the HTTP log receiver accept HTTP protocol and will returen the HTTP response.
