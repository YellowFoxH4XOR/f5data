K04271835: The monitor test address field is grayed out on the GUI

Type
Support Solution
Published
2021-03-02
Updated
2023-01-03
Applies to
  • BIG-IP Platforms
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K04271835

Description

Using the GUI on, Local Traffic ›› Monitors ›› Monitor_Name, and trying to use the Test tab, the address field is grayed out and can not be used/accessed.

Environment

  • GUI
  • All monitors in Test tab should be affected
  • This is not happening on versions previous to v15

Cause

Bug ID 926085: GUI: Node/port monitor test not possible in the GUI, but works in tmsh

Recommended Actions

To workaround the issue you can use this tmsh syntax, which will get the same results, as test button on GUI:

tmsh run ltm monitor <service> <Monitor_Name> destination <IP address>:<port>

For example, running the following tmsh command, will let you use the test button on GUI once:

tmsh modify ltm monitor http Monitor_Name destination *:*

Note: This only works once. You will need to repeat the command, in order to use the test button on GUI again.

Additional Information

The monitor in question might look like this example:

ltm monitor http /Common/Monitor_Name {
    app-service none
    defaults-from /Common/http
    description none
    destination *:*
    interval 5
    manual-resume disabled
    partition Common
    recv 200
    recv-disable none
    reverse disabled
    send "GET /healthcheck\r\n"
    time-until-up 0
    timeout 16
    transparent disabled
    up-interval 0
    username none
}
