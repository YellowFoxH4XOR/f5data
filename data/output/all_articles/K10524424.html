Description

  • Oracle monitor is failing
  • Error message seen in /var/log/DBDaemon.log 
    numeric parameter is non-numeric
java.lang.numberformatexeption: for input string

Environment

  • BIG-IP
  • Oracle DB 12.2

Cause

  • A carriage return in the configs is causing the error.
  • Do not include a carriage return on the monitor's configuration.

Recommended Actions

  1. On the bigip.conf, locate the monitor that may have a carriage return.
    Below is an example of a monitor string with a carriage return.

    ltm monitor oracle /partitionname/monitorname {
    count 0
    database "(DESCRIPTION=(ADDRESS=(PROTOCOL=TCP)(HOST=%node_ip%)(PORT=%node_port%))  
    (CONNECT_DATA=(SERVER=DEDICATED)(SERVICE_NAME=orclpdb)))"
     
  2. Remove the carriage return. The monitor string should not include a carriage return. 
Additional Information
  • You may also utilize the GUI to configure the monitor.
