Topic

The FirePass controller is factory equipped with a unique code, called a base registration key. When you purchased the controller, a record was created on the F5 licensing server, indicating what features you purchased. To operate the FirePass controller, you must activate your license. The activation process connects the controller’s base registration key with the licensing server record.

To activate your FirePass license, perform the following procedure:

Note: For information about installing and activating add-on module keys, refer to K10464: Installing module registration keys on the FirePass controller.

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Device Management : Maintenance : Activate License page.
  3. The base registration key is displayed in the Base Registration Key field. If this field is empty, enter the base registration key provided by F5 .
  4. In the Registration Method field, select Automatic or Manual.

    Note: If the FirePass controller can resolve and connect to the F5 licensing server through TCP port 443, select the Automatic method. Otherwise, select the Manual method.

  5. Click the Request License button.
  6. If you selected the Automatic registration method, perform the following procedure, otherwise, proceed to Step 7.
    1. Accept the End User License Agreement, and provide your business email address and contact details, if prompted.

      A screen opens, displaying your license file.
    2. Click the Continue button to activate and install your license.
    3. Log out of the FirePass Administrative Console, and log in again.

      The FirePass controller presents the newly licensed features.
  7. If you selected the Manual registration method, perform the following procedure:
    1. At the Activate License screen, select and copy all of the contents in the Product Dossier field.

      Important: Many programs, such as Microsoft Outlook and Word automatically enter non-echoing characters into the Dossier. Make sure to use a plain text editor, such as Notepad.

    2. Click the Click here link here to access F5 Licensing Server link.

      The Activate F5 License screen opens in a new browser window.
    3. Paste the dossier you copied in Step 7a into the Enter your dossier field on the Activate F5 Product page.
    4. Click the Next button.
    5. Accept the End User License Agreement, and provide your business email address and contact details, if prompted.

      After a few moments, the licensing server displays your new license file.
    6. Select and copy the license from the Activate F5 Product page.
    7. Return to the FirePass Administrative Console browser window.
    8. Paste the license file into the License File field.
    9. Click the Install License button.

      A confirmation messages appears.
    10. Click the Continue button to activate and install your license.
    11. Log out of the FirePass Administrative Console, and then log in again.

      The FirePass controller presents the newly licensed features.
