Known Issue

This is the result of a known issue. If a user running Mac OS X opens a Java-based Microsoft Terminal server favorite, the favorite opens correctly the first time. If the user attempts to open another Java-based Microsoft Terminal server favorite, or if the user closes and re-opens the same Java-based Microsoft Terminal server favorite, the connection may fail with an error message that appears similar to the following example:

Java applet cannot be started. Please make sure that a required version of Java is installed

Additionally, if the Java console is open, an error message that appears similar to the following example displays:

java.lang.IllegalArgumentException: Width (0) and height (0) cannot be <= 0

Note: The Microsoft Terminal server Java client was introduced in FirePass 6.0.3. For more information, refer to K9189: Change in Behavior: Microsoft Terminal Server and Citrix MetaFrame Terminal Servers favorites are now supported for Mac OS X clients.

F5 Product Development tracked this issue as CR113305 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-603-1 issued for FirePass 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
