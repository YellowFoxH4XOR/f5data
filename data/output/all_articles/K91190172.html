Description

Cannot get small file from BIG-IP Web Accelerator

Environment

  • BIG-IP AAM
  • Small object cache is configured.
  • Response is a few bytes less than the small object threshold.
  • No valid cache for it, AAM get it from original web server.

Cause

It is caused by the ID 792045.

Recommended Actions

Refer to the ID 792045

Additional Information

None.
