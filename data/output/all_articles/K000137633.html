Description

This article is for you if you are trying to deploy a tenant on the F5OS and receive the following error:

The tenant stuck in running state: Not ready: containers with unready status: [compute]

 

Environment

Relevant environmental factors specific to the topic

  • F5OS
  • DNS search domain list, has domain with mixed lowercase and UPPERCASE letters

Cause

This is a known issue (bug ID 1328921)

Recommended Actions

 

  1.  Modify the DNS search domain list so that all entries contain only lowercase letters.
  2. Reboot the system

Additional Information

None
