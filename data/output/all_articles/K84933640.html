K84933640: The BIG-IP fips-card-sync command prompts for remote password

Type
Support Solution
Published
2022-04-08
Updated
2025-03-19
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K84933640

Description
You are attempting to synchronize FIPS as part of hardware replacement by following the F5 Platforms: FIPS Administration Guide, and when you run the following command your password does not work: 

run util fips-card-sync <hostname>

Environment

BIG-IP with FIPS Hardware.

Cause

The guide is slightly unclear when it says:

  • You must have the root password for the target (RMA) F5 device.

  • Log on to the command line of the source (Active) device using an account with root access.

Using a non-admin or non-root account which has Administrator role fulfills this. However when bringing up a new target Appliance, it will only have root and admin accounts configured. In addition, it will have different passwords, and you must be able to ssh from the source to target Appliances for the fips-card-sync command to work.

Recommended Actions

  1. Log in to the source appliance with either root or admin.

  2. Know what the matching password is on the target device, optionally to set it to same password.

  3. Run command run util fips-card-sync <hostname>
