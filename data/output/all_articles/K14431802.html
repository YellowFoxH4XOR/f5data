Source

Description

Missing Download Package when Integrating F5  ACI and CISCO APIC

  • When configuring Cisco APIC to integrate with F5, device package is required on CISCO APIC for configuration to be saved. However, device package is no longer available from F5 thus configuration is unable to proceed with the next step due to the missing file

Environment

  • F5 ACI
  • CISCO APIC

Cause

F5 APIC static package has reached EOL and EOS and thus the needed download package is no longer available. Refer to: K92393298: End of Life announcement for the F5 APIC static device package.

Recommended Actions

  • Use BIG-IQ Cloud and Orchestration to integrate with Cisco APIC
  • For new integration, contact account manager or email consulting.sales@f5.com.
