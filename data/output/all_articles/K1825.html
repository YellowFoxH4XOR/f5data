BIG-IP version 4.2 PTF-06 introduced two new features to support passing traffic to Intrusion Detection Systems (IDS):

  • VLAN mirroring
  • Clone pools

Important: Starting in version 4.5, BIG-IP includes a much more refined version of IDS load balancing. F5 Networks suggests that all customers interested in this feature upgrade to the most recent version of BIG-IP. Refer to the BIG-IP Release Notesa for information about upgrading.

For specific details about this feature, including configuration instructions, refer to the Mirroring to an Inspection Device chapter of the BIG-IP Solutions Guide.
