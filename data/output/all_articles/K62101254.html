Description

  • ASM validation error seen at Security >> Application Security : Policy : History
  • "Parameters with specific data types are defined, but 'illegal parameter data type' violation is not enforced"
  • When applying security policy, warning message "Parameters with specific data types are defined, but 'Illegal parameter data type' violation is not enforced" is displayed.

Environment

  • After upgrade or after importing ASM policy
  • ASM security policy
  • ASM

Cause

  • The warning message relates to a parameter entry
  • This parameter in the policy does not have any effect as 'Learning and Blocking Settings' is not selected.
  • The validation warning is stating that you have a configuration defined that can experience violations but there is no learn/alarm/block flags set for that violation.

Recommended Actions

Either ignore the warning or proceed with the steps below.

  1. Navigate to Security ›› Application Security : Policy Building : Learning and Blocking Settings
  2. Switch to Advanced view
  3. Expand Parameters tree.
  4. Next to "Illegal parameter data type" check at least one of Learn/Alarm/Block (you can check one or all three dependent on how you want your policy to behave)
  5. Save and Apply the policy change
