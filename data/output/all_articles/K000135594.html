K000135594: BIG-IP: how to review the certificate bundle in CLI

Type
Support Solution
Published

Applies to

Source

Description

This article shows how to review the certificate bundle content on BIG-IP using CLI and openssl tool.

Environment

  • BIG-IP
  • Certificate bundle
  • openssl

Cause

BIG-IP Administrator may need to review the certificate bundle content in CLI.

Recommended Actions

BIG-IP Administrator can review the certificate bundle content in CLI using the below command, replace '<replace_with_certificate>' with the actual certificate location:

# openssl crl2pkcs7 -nocrl -certfile <replace_with_certificate> | openssl pkcs7 -print_certs -text -noout | less

 

For example, if we want to review the content of ca-bundle.crt:

[root@bigip.local:Active:Standalone] config # openssl crl2pkcs7 -nocrl -certfile /config/filestore/files_d/Common_d/certificate_d/\:Common\:ca-bundle.crt_86256_1 | openssl pkcs7 -print_certs -text -noout | less
