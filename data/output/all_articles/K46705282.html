Description

After upgrading device, you find that TCL expressions in the http fallback option in your HTTP profiles no longer functions properly

Environment

  • BIG-IP LTM
  • Recent upgrade
  • HTTP profile with TCL expression in http fallback host field

Cause

Issue is caused by Bug ID 947937

Recommended Actions

You can work around the issue by adding an iRule to the affected virtual server that provides an equivalent redirect
If you are not able to make configuration changes to the device but require the lost functionality, contact Support to see if an engineering hotfix is available for your software version

None
