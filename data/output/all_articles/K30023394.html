Description

The iRule command RESOLV::lookup performs a DNS query, returning one or more addresses (A records) for a hostname, a domain name (PTR record) for an IP address, or optionally one or more values for records of other types.
The DNS server may receive the DNS query with characters case randomized queries.
For example:
when an iRule performs lookup for www.example.com with command:

RESOLV::lookup  -a "www.example.com"

You may find following query on DNS server: 

Question: A Www.eXaMPLE.COM.

Environment

  • BIG-IP
  • Virtual Server
  • iRule command RESOLV::lookup

Cause

Please note this is expected bahavior. To against DNS cache poisoning, BIG-IP will randomize query character case. By randomize query character case, an attacker must not only match the source port and transaction ID but also guess the correct case of each character in the name, which makes it more difficult to forge a DNS response.

Recommended Actions

This behavior can not be disabled in iRule.
If you need to disable this feature, use DNS cache resolver instead of iRule command 'RESOLV::lookup'.
