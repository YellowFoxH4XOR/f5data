Known Issue

BIG-IP APM local user database entries may not synchronize with the device group.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM is configured as part of a high-availability (HA) device group.
  • You have configured a local user database.
  • You have modified or deleted an entry in the local user database.

Impact

Changes to the local user database entries are not synchronized to the other members of the HA device group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you modify entries of the local user database on an HA device group member, changes are not reflected on the other members of the HA device group.
  • You have to manually repeat modifications to the local user database on the other members of the HA device group.
