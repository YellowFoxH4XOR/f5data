Known Issue

Description

When you reset the statistics for TCP virtual servers, counters for Open Connections, CLOSE_WAIT, FIN_WAIT, TIME_WAIT, and Accepted may not reset and can continue to increment, even though those corresponding connections no longer exist.

Note: This behavior provides misleading information for TCP connection statistics, but does not impact the actual performance of the BIG-IP system.

You can view the statistics by running the following Traffic Management Shell (tmsh) command:

tmsh show ltm profile tcp tcp

Impact

TCP statistics are unreliable.


Symptoms

As a result of this issue, you may encounter the following symptom:

  • Counter values continue to increase instead of resetting to zero.
