Description

  • Fallback IP option not available for 'Load Balancing Method' under Link Controller 'Inbound Wide IP' configuration.
  • Fallback IP tab to input the fallback IP address missing.

 

Environment

  • Link Controller v15.0.0 and above.
  • Inbound wideip configuration to load balance inbound applications.

 

Cause

Known issue tracked as ID1320589.
 

 Recommended Actions

1. Create inbound wideip via the configuration utility.

 

# tmsh list gtm wideip a lcwip.example.lab

 

gtm wideip a lcwip.example.lab {

 pools {

 lcwip.example.lab {

 order 0

 }

 }

}

 

2. Identify the pool associated with the wideip.

 

# tmsh list gtm pool | grep lcwip.example.lab

 

gtm pool a lcwip.example.lab {

 

# tmsh list gtm pool a lcwip.example.lab

 

gtm pool a lcwip.example.lab {

 members {

 linkcontroller:/Common/http_vs {

 member-order 0

 }

 }

}

 

3. Add fallback IP address to pool associated with the wideip.

 

# tmsh modify gtm pool a lcwip.example.lab { fallback-mode fallback-ip fallback-ip 192.0.0.10 }

 

# tmsh list gtm pool a lcwip.example.lab

 

gtm pool a lcwip.example.lab {

 fallback-ip 192.0.0.10

 fallback-mode fallback-ip

 members {

 linkcontroller:/Common/http_vs {

 member-order 0

 }

 }

}

 

# tmsh save sys config
