Description

All users will lose access to BIG-IP via GUI and SSH after deleting all contents in /var/log/

Note: F5 does not recommend deleting any files or sub-directories in /var/log/

Environment

  • BIG-IP
  • Deleting contents of /var/log/
  • Unable to access GUI and SSH

Cause

Some files and sub-directories are essential for the operation of BIG-IP and should not be deleted.

Recommended Actions

Reboot the system to regenerate the necessary files and sub-directories.
Access to BIG-IP will be restored.

Additional Information

K14403: Maintaining disk space on the BIG-IP system
K13367: Managing log files on the BIG-IP system (11.x - 16.x)
