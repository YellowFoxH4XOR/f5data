Known Issue

Local Domain Name System (DNS) resolution may fail for Mac OS X users.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for Network Access with the Allow Local DNS Servers setting enabled.
  • The Network Access configuration uses the Split tunneling setting with an IPV4 LAN Address Space of 0.0.0.0/0.0.0.0.
  • The Network Access configuration’s Allow Local Subnet setting is disabled.
  • Mac OS X users, with a single network adapter enabled, establish Network Access connections.

Impact

DNS resolution fails on the client machine and users cannot access applications.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • DNS resolution fails on the client machine and Mac OS X users cannot access applications.

Workaround

To work around this issue, you can specify a wildcard (*) to forward all DNS traffic over the tunnel. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > Network Access.
  3. Select the network access resource to edit.
  4. Click Network Settings.
  5. In the DNS Address Space: DNS text box, type an asterisk.
  6. Click Add.
  7. Click Update.
  8. Click Apply Access Policy.
