Topic

This article applies to BIG-IP 9.3.0 through 10.x. For information about other versions, refer to the following articles:

  • K13539: Disabling the watchdog process to perform a core dump (11.x - 12.x)
  • K4136: Disabling the watchdog process to perform a core dump (9.0.0 - 9.1.3)

The watchdog process ensures that the BIG-IP system will reboot in the event of a system lock-up, prompting a failover. If you are forcing the BIG-IP system to produce a core file for diagnostic purposes, you must disable the watchdog process to allow the core file to write to disk before the system reboots.

In BIG-IP 9.3.0 and later, you can disable or enable the watchdog process as follows:

Important: Always enable the watchdog feature once the core dump has completed.

Disabling watchdog

Type the following command:

bigpipe db watchdog.state disable

Enabling watchdog

Type the following command:

bigpipe db watchdog.state enable
