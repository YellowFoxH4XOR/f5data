K000135459: HTTP 400 unexpected argument when trying to access REST API

Type
Support Solution
Published
2023-07-12
Updated
2023-07-12
Source
https://my.f5.com/manage/s/article/K000135459

Description

REST API call fails with HTTP 400 code with the message "unexpected argument". For example:


curl -sku test:test https://10.155.255.20/mgmt/tm/sys/crypto/cert

{"code":400,"message":"\"cert\" unexpected argument","errorStack":[],"apiError":26214401}%


User "test" is configured with the Guest role so it has no access to /mgmt/tm/sys/crypto/cert URI.


Switching the user role to Certificate Manager makes the curl work:


curl -sku test:test https://10.155.255.20/mgmt/tm/sys/crypto/cert | jq '.items[] | {certname: .name, CertExpiry: .apiRawValues.expiration}'

{

 "certname": "/Common/ca-bundle.crt",

 "CertExpiry": "Dec 31 23:59:59 2029 GMT"

}

{

 "certname": "/Common/default.crt",

 "CertExpiry": "Jul 8 12:36:04 2033 GMT"

}

{

 "certname": "/Common/f5-ca-bundle.crt",

 "CertExpiry": "Dec 7 17:55:54 2030 GMT"

}

{

 "certname": "/Common/f5-irule.crt",

 "CertExpiry": "Jul 18 21:00:13 2027 GMT"

}


Note: jq '.items[] | {certname: .name, CertExpiry: .apiRawValues.expiration}' was used for better readability.


Environment

  • REST API

Cause

Wrong user permissions.

 Recommended Actions

Make sure the user is configured with the correct user role to access the given API URI.

Additional Information

You may want to review user roles in the documentation, for example: https://techdocs.f5.com/en-us/bigip-15-0-0/big-ip-systems-user-account-administration/user-roles.html
