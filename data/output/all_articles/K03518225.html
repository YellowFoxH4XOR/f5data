K03518225: VPN Client not passing Windows Login Credentials after Windows upgrade

Type
Support Solution
Published
2019-10-25
Updated
2025-01-09
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.3
Source
https://my.f5.com/manage/s/article/K03518225

Description
 

Users attempting to connect to the VPN with EdgeClient after a Windows upgrade get prompted for credentials despite an enabled 'Reuse windows credentials' setting in connectivity profile

F5CredMgrSrv.txt in Edgeclient Client Troubleshooting Utility (CTU) contains messages similar to the following:

2019-07-01,20:39:39:813, 4344,13104,, 1, , 407, GetCredentials, (0x6e1) EXCEPTION - Credentials not found for <GUID>
2019-07-01,20:39:39:813, 4344,13104,, 1, , 424, GetCredentials, EXCEPTION caught: GetCredentials - EXCEPTION

Environment

  • After Windows 10 major version upgrade
  • 'Reuse Windows Login Session & Credentials' setting enabled in connectivity profile
  • APM
  • EdgeClient

Cause

Windows 10 OS upgrade removes the F5 Networks Credentials Management Service's ability to capture Windows User Logon credentials This is a known issue (See Related Content below).

Recommended Actions

Re-installation of the Edge Client is the only way to resolve the issue. 

Additional Information

When you perform an in-place upgrade to Windows 10, version 1809, version 1709, version 1703, or version 1607, the third-party network provider settings are removed from the computer.
After the upgrade, the Provider list (HKLM\SYSTEM\CurrentControlSet\Control\NetworkProvider) is reset, and the third-party provider registry settings (under HKLM\System\CurrentControlSet\Services\) are removed.

When you query the registry on a working client it should look like this:

reg query "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\NetworkProvider" /s

HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\NetworkProvider\HwOrder
  ProviderOrder    REG_SZ    f5netprov,RDPNP,LanmanWorkstation,webclient

HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\NetworkProvider\Order
  ProviderOrder    REG_SZ    f5netprov,RDPNP,LanmanWorkstation,webclient
