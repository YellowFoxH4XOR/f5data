Description

Part of parameter value in URL is identified incorrectly as a new parameter after &.

 

Example:

param3=hello%20&%20world

%20world is identified as a new parameter name in ASM

 

Environment

  • BIG-IP ASM
  • Parameter
  • &

Cause

& is used in a url as a parameter separator

Recommended Actions

Use url encoding if you want & to be part of the parameter value

The url encoded value for & is %26

eg.

param3=hello%20%26%20world

Additional Information

http://example.com/?param1=value1&param2=value2&param3=hello%20&%20world

Since the & is used as a separator for the parameters, it is correct that %20world will be identified as a new parameter name.
