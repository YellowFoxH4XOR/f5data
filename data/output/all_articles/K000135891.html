K000135891: Failover process on SDC system

Type
Support Solution
Published
2023-09-28
Updated
2024-10-01
Applies to
  • Traffix SDC: 5.2.X, 5.2.0, 5.1.X, 5.1.0
Source
https://my.f5.com/manage/s/article/K000135891

Description

  • You may want to failover application on SDC
  • For example
    • Gx component from FEP01 > FEP02
    • Gy component from FEP01 > FEP02


Environment

SDC
 

Cause

You may want to failover fep component on SDC system
 

Recommended Actions

  • Verify the virtual ip address of the component, then look for the word "secondary" on node01
    • Command: ip addr

4: eth2: mtu 1500 qdisc mq state UNKNOWN qlen 1000
link/ether 00:50:56:93:6a:93 brd ff:ff:ff:ff:ff:ff
inet 172.16.106.143/25 brd 172.16.106.255 scope global eth2
inet 172.16.106.150/25 brd 172.16.106.255 scope global secondary eth2

  • Verify the process ID.
    • Command: jps -m

10545 CacheManagerDistributionManager -backupRootDir /data/backup -configurationPath /opt/traffix/components/CM/config//clusterManager.xml

8980 CpfApplication -name SDC-ELK-01_fep-sctp
22397 Jps -m
7661 NmsApplication -name SDC-ELK-01_NMS -ipAddresses SDC-ELK-01-ic-eth1-v4
8493 CpfApplication -name SDC-ELK-01_fep-tcp
6975 Bootstrap start
