Description

ASM masking Credit card numbers in Transparent mode

Environment

ASM

Cause

This is by design

Recommended Actions

Data guard feature will mask the ID card number in responses even when the ASM policy is in Transparent mode, provided the "Mask Data" option is enabled.

This masking action is by design and is not limited to Blocking mode.

The purpose of Transparent mode is to allow detection and logging of violations without blocking, but Dataguard’s masking is considered a modification of the response, not a block, and therefore occurs in both Transparent and Blocking modes if enabled.

If Dataguard feature to only log and not mask or disrupt application responses in Transparent mode, you will need to disable the "Mask Data" setting in your ASM policy. This will prevent the masking action and allow the application to function without disruption.
