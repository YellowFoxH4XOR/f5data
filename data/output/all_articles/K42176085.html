Topic

You should consider using this procedure under the following condition:

  • You want to validate and manage MQTT traffic using topic names.

Description

MQTT is a TCP based messaging protocol that allows communication between IoT devices. In a typical MQTT connection scenario, a client publishes data, which is forwarded to one or more subscribers by the MQTT broker. In this scenario, MQTT messages contain a variable header and topic name. Subscribers use the topic name to identify the MQTT channel on which they want to receive published information. For example, a car publishes data for a specific topic, such as brake pressure information, which is forwarded to a subscribing application by the MQTT broker.

You can use an iRule and Data Group to validate MQTT topic data; if the topic data isn't defined in the Data Group, you can configure the iRule to discard the MQTT message and prevent DDoS attacks.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have defined a virtual server and pool to process MQTT connections.

Procedures

Configuring the Data Group containing the MQTT topic names

To configure the Data Group containing the MQTT topic names, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules > Data Group List.
  3. Click Create.
  4. Type a name for the Data Group.

    For example, MQTT-data-group.

  5. From the Type menu, select String.
  6. In the String box, enter the appropriate MQTT topic name.
  7. Click Add.
  8. Repeat steps 6 and 7 for each MQTT topic name you want to add to the Data Group.
  9. Click Finished.

Configuring the MQTT iRule

To configure the iRule that discards MQTT messages that do not contain the relevant topic names, perform the following steps:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules List.
  3. Click Create.
  4. Type a name for the iRule.

    For example, MQTT-iRule.

  5. Enter the iRule code in the Definition box.

    For example, the following iRule drops MQTT traffic when the topic name in the request is not defined in the Data Group named MQTT-data-group:

    when MQTT_CLIENT_INGRESS {
        if {[MQTT::type] eq "PUBLISH" } {
            # Check data group for allowed topics.
            if { ![matchclass [MQTT::topic] eq MQTT-data-group] } {
                # Log invalid topic
                log local0. "   Topic is Invalid. Potential DDoS Attack"
                drop
            }
        }         
    }

  6. Click Finished.
  7. Associate the iRule with your MQTT virtual server.
