Known Issue

Server SSL virtual servers may fail to complete SSL/TLS renegotiation handshakes.

This issue occurs when all of the following conditions are met:

  • The virtual server is configured with a Server SSL profile.
  • The BIG-IP system or server attempt to renegotiate the SSL/TLS handshake.
  • The server requires the SSL/TLS version that is specified in the ClientHello message (both Record layer and Handshake protocol) to be the same in both the initial and renegotiated handshakes.

Impact

The SSL/TLS server rejects the renegotiation handshake, causing the connection to fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The initial SSL/TLS handshake is successful, but the renegotiation handshake fails, causing the connection to fail.
  • Packet captures indicate that the SSL/TLS server replies with a TCP RST instead of a ChangeCipherSpec message.
