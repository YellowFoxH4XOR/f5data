Description

When generating APM Access Reports from the BIG-IP Configuration utility, there might be some sessions whose fields (i.e., State, Country, Continent, Client Host Name and AP Result) are not getting populated / displaying as 'blank'.

Environment

  • BIG-IP with the APM module provisioned
  • using either the built-in report or a custom report to generate Access Reports from the web GUI

Cause

This functions as designed.

APM Access reports rely on log messages and extract those reporting fields such as Logon, State, Country from various log messages. The problem is, it will only query the messages that are within the query window, so if the log message that contains the field is not within the query window, then we won't be able to get that field's value and as a result, that field won't get populated and will appear as 'blank' in the APM Access reports.

In order for all fields to be displayed in the APM Access reports, it is necessary that the session start time to fall inside of the time duration specified in the 'Report Parameters' dialog when the report is run.

Recommended Actions

Workaround is to expand the window to be big enough to include log messages that contain those reporting fields

For example: if previously, you've used Recent 1 Hours in the Report Parameters and the APM Access report contained sessions with 'blank' fields; consider using a 'bigger' window (i.e., Recent 1 Days) when running the APM Access reports.
