Description
How to make sure the active BIG-IP configuration is the configuration that gets synced between newly added BIG-IPs in a device group.

Environment

  • Migrating from a BIG-IP platform to another BIG-IP platform
  • Adding a new BIG-IP system to a new Device Service Clustering group (DSC)

Cause
None

Recommended Actions

Disabling auto sync, adding the new devices to the sync-group, and pushing the active configuration to the new device group members is the best way to ensure that the correct configuration is synced.

To migrate a BIG-IP configuration to a new platform, refer to K15496: Migrate a device group member to a new BIG-IP platform

None
