Known Issue

You cannot configure an existing iApp application using the Configuration utility.

This issue occurs when one of the following conditions is met:

  • You open an existing iApp application using the Configuration utility.
  • You create a new iApp application and try to configure it using the Configuration utility.

Impact

You are unable to configure an existing iApp application using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You are unable to use the Configuration utility to open and modify an existing iApp application.  The Configuration utility reports the following database error:

    General database error retrieving information.

Resolution

Status

F5 Product Development has assigned ID 465555 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) utility to configure the iApp application.
