K1627: F5isapi.dll compatibility with international versions of Windows 2000 Server

Type
Knowledge
Published
2006-02-17
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • BIG-IP 4.X: 4.6.4
Source
https://my.f5.com/manage/s/article/K1627

Topic

Microsoft does not currently provide the API or the libraries for data collections on international versions of the Windows 2000 server; therefore, the BIG-IP F5isapi.dll portion of the WMI collection facilities will not work with the international version of my Windows 2000 server.
