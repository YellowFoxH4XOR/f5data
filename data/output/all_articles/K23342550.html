K23342550: How to manage the whitelist settings within a bot profile using REST APIs

Type
Support Solution
Published
2021-11-04
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K23342550

Description

Please consider the information of this article if you wish to create/modify/delete the whitelist settings within a bot profile using BIG-IP REST APIs.

Environment

  • BIG-IP ASM
  • Bot Profile

Cause

Like to automate the process of managing whitelist settings within a bot profile.

Recommended Actions

Here's a list of common commands related to whitelist settings within a bot profile:

To obtain the name of all available bot profiles
To view the current whitelist setting within a bot profile
To create a new whitelist rule
To modify an existing whitelist rule
To delete a whitelist rule
  • To obtain the name of all available bot profiles

curl -s -k --user user:passwd -H "Content-Type: application/json" -X GET https://x.x.x.x/mgmt/tm/security/bot-defense/profile?%24select=name,selfLink
Note: update the above command with correct credentials and IP/hostname of the BIG-IP in question.

  • To view the current whitelist setting within a bot profile

curl -s -k --user admin:admin -H "Content-Type: application/json" -X GET https://x.x.x.x/mgmt/tm/security/bot-defense/profile/~Common~bot-defense/whitelist
Note: update the above command with correct credentials and IP/hostname of the BIG-IP in question.

The output should be similar to:
{
  "kind": "tm:security:bot-defense:profile:whitelist:whitelistcollectionstate",
  "selfLink": "https://localhost/mgmt/tm/security/bot-defense/profile/~Common~bot-defense/whitelist?ver=x.x.x.x",
  "items": [
    {
      "kind": "tm:security:bot-defense:profile:whitelist:whiteliststate",
      "name": "acl_1",
      "fullPath": "acl_1",
      "generation": 2706,
      "selfLink": "https://localhost/mgmt/tm/security/bot-defense/profile/~Common~bot-defense/whitelist/acl_1?ver=x.x.x.x",
      "disableMitigation": "yes",

      "matchOrder": 1,
      "sourceAddress": "::/32",
      "url": "/apple-touch-icon*.png"
    }
  ]
}

  • To create a new whitelist rule:
For example, to create a new rule named ACL_2:
curl -s -k --user admin:admin -H "Content-Type: application/json" -X POST https://x.x.x.x/mgmt/tm/security/bot-defense/profile/~Common~bot-defense/whitelist/ACL_2 -d '{ "sourceAddress": "4.4.4.4/32", "url": "*", "matchOrder":"2" }'
Note: update the above command with correct credentials and IP/hostname of the BIG-IP in question.

The output should be similar to:
{
  "kind": "tm:security:bot-defense:profile:whitelist:whiteliststate",
  "name": "ACL_2",
  "fullPath": "ACL_2",
  "generation": 2711,
  "selfLink": "https://localhost/mgmt/tm/security/bot-defense/profile/~Common~bot-defense/whitelist/ACL_2?ver=x.x.x.x",
  "disableMitigation": "yes",
  "disableVerification": "yes",
  "matchOrder": 2,
  "sourceAddress": "4.4.4.4/32",
  "url": "*"
}
  • To modify an existing whitelist rule:
For example, to modify the IP address within ACL_2 whitelist rule:
curl -s -k --user admin:admin -H "Content-Type: application/json" -X PATCH https://x.x.x.x/mgmt/tm/security/bot-defense/profile/~Common~bot-defense/whitelist/ACL_2 -d '{ "sourceAddress": "5.5.5.5/32" }'
Note: update the above command with correct credentials and IP/hostname of the BIG-IP in question.

The output should be similar to:
{
  "kind": "tm:security:bot-defense:profile:whitelist:whiteliststate",
  "name": "ACL_mohsen",
  "fullPath": "ACL_mohsen",
  "generation": 2712,
  "selfLink": "https://localhost/mgmt/tm/security/bot-defense/profile/~Common~bot-defense/whitelist/ACL_2?ver=x.x.x.x",
  "disableMitigation": "yes",
  "disableVerification": "yes",
  "matchOrder": 2,
  "sourceAddress": "5.5.5.5/32",
  "url": "*"
}
  • To delete a whitelist rule:
For example, to delete ACL_2 whitelist rule:
curl -s -k --user admin:admin -H "Content-Type: application/json" -X DELETE https://x.x.x.x/mgmt/tm/security/bot-defense/profile/~Common~bot-defense/whitelist/ACL_2
Note: update the above command with correct credentials and IP/hostname of the BIG-IP in question.
