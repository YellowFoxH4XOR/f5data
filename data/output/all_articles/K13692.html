Known Issue

Importing a BIG-IP APM access policy may fail.

This issue occurs when the following conditions are met:

  • The access policy is configured with a pool containing an AAA server
  • The access policy pool is configured with a health monitor

Impact

You cannot import the desired access policies.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Importing the access policy displays the following error message:

    Import Error: 01070022:3: The monitor template <partition>/<monitor name> was not found. Unexpected Error: Loading configuration process failed.

    In this error message, note the following:
    • <partition> is the partition in which the monitor is located
    • <monitor name> is the name of the monitor configured on the AAA server pool

Workaround

To work around this issue, you can remove the Server Pool Monitor from the access policy export file. To do so, perform the following procedure:

Impact of workaround: None.

  1. Use a text editor to open the export file.

    For example:

    notepad.exe access-policy.conf
  2. Locate the AAA ltm pool section in the export file.

    For example:

    ltm pool /@partition/@name-aaa-pool {
  3. Locate the monitor entry in the ltm pool section.

    For example:

    monitor Common/gateway_icmp
  4. Remove the monitor entry.
  5. Save the export file.
  6. Close the text editor.

You can now import the export file into the BIG-IP APM system.

Note: After importing the file, you will need to add the pool monitor back in the AAA server configuration.
