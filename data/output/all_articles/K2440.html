Topic

The global variable, open_3dns_ports, instructs BIG-IP to accept return packets from big3d probes BIG-IP sends to LDNS servers. If you are running a 3-DNS in your environment, F5 recommends that you enable this feature.

Note: BIG-IP will communicate with 3-DNS regardless of whether this setting is enabled. This setting only affects BIG-IP's ability to accept the response to probes that it sends out on behalf of 3-DNS.

To enable this variable, type the following command:

b global open_3dns_ports enable

To save this setting enter:

b save
