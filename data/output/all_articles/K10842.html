Issue

Occasionally, the following error message may be logged to the /var/log/ts/ts_debug.log file:

DBD::mysql::db do failed: Can't find any matching row in the user table at /usr/lib/perl5/site_perl/F5/ChangeReplPass.pm line 33.

This error message is benign and can be safely ignored.

In versions prior to 9.4.5, the BIG-IP ASM performed MySQL replication between the active and standby devices of a BIG-IP high availability pair. By design, the details of the replication user were kept in sync with those of the configsync user.

Beginning in BIG-IP ASM 9.4.5, MySQL replication was disabled and the replication user deleted. However, the process responsible for maintaining the details of the replication user was retained and still runs in later BIG-IP ASM versions, as this process also performs other duties. The error message documented in this Solution is logged every time the password of the configsync user is changed; the replication user no longer exists, and therefore, its password cannot be updated.
