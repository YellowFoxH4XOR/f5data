K13709: FirePass option for running the fsck utility

Issue

Old Behavior

Previously, FirePass performed a fsck operation when booting, but did not check file systems that were marked as clean.

New Behavior

Beginning in FirePass 6.1.0 HF-610-6.1 and FirePass 7.0.0 HF-70-4.1-1, the Force fsck on boot option forces the fsck utility to run when you boot the FirePass controller, even if the file system is reported as clean.

The fsck utility checks and repairs file system inconsistencies.

F5 Product Development is tracking this change as ID 355228.

Impact

The FirePass controller may take longer to boot while it completes the fsck operation.

Recommended Actions

You can schedule the fsck operation to run when you boot the FirePass controller by performing the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Device Management > Maintenance > Restart Services.
  3. Click Restart Controller. Optionally, you can click Shutdown Controller.
  4. Click Force fsck on boot.
  5. If you want to perform the fsck operation immediately, you can click Restart or Shutdown. Otherwise, the fsck utility will run the next time you boot the FirePass controller.
