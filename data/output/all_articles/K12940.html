Known Issue

BIG-IP Edge Portal application for Apple iOS devices may intermittently fail to authenticate properly when a virtual server is configured to either request or require client certificates for authentication. Users may be able to successfully authenticate several times with only intermittent failures. These failures occur when the session.ssl.cert.* variable is not properly generated as a result of a timing conflict with TMM. Users may be able to successfully connect to the desired resource on subsequent connection attempts without making any changes to their client certificate.

This issue occurs when all of the following conditions are met:

  • User attempts to connect to a resource using the BIG-IP Edge Portal application
  • User is connecting with an Apple iOS device
  • The virtual server the user is attempting to connect uses an SSL Client profile that either requests or requires a client certificate

    Note: You can view the SSL Client profile configuration that the virtual server is using from the Configuration utility. To do so, navigate to Local Traffic >> Profiles >> SSL >> Client, click on the correct profile, and view the Client Certificate section.

Impact

Users will experience intermittent authentication failures when accessing resources that either require or request a client certificate for authentication.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • User may receive an HTTP 401 Unauthorized page
  • User may receive an HTTP 403 Forbidden page
  • User may receive a Logon Failed pop-up window
  • User may receive other authentication failure messages
  • User may be able to successful authenticate before and after receiving an authentication failure for the same resources without making any changes

Workaround

To work around this issue, you can disable Clustered Multi-Processing (CMP) globally. Disabling CMP globally will prevent the timing conflict with TMM. For an overview of CMP and instructions on disabling CMP globally, refer to K7751: Overview of Clustered Multi-Processing.

Impact of workaround: Disabling CMP globally will decrease system performance.
