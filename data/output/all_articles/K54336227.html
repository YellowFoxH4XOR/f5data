Issue

Error Message

Too many elements in the version string 

Message Location

You may encounter this message in the following locations:

  • Configuration utility of the F5 Enterprise Manager
Description

This message occurs when the following condition is met:

  • You attempt discover a BIG-IP LTM or BIG-IP GTM system running a seventh-element point release (for example, 12.1.3.1.0.0.8) or eighth-element point release (for example, for example, 12.1.3.1.0.0.8.1) with Enterprise Manager.

Impact

Enterprise Manager shows the device as impaired and fails to discover the device.

Recommended Actions

You should upgrade to Enterprise Manager 3.1.1 HF8 or later.
