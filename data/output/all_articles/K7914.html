K7914: The TMM does not forward a TCP FIN packet sent from the web server to the bd process

Known Issue

This is the result of a known issue. When the web server sends a FIN packet in the middle of response to close the connection, the TMM does not forward the FIN packet to the BIG-IP ASM bd process. This issue causes the BIG-IP ASM and the client to wait for the response to complete.

F5 Product Development tracked this issue as CR64120, and it was fixed in BIG-IP versions 9.3.1 and 9.4. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.3.0-HF3 issued for BIG-IP version 9.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
