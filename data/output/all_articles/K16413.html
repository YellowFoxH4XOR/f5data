Description

You need to give a local user account terminal access to the Advanced Shell (bash) or the TMOS Shell (tmsh) on the BIG-IQ system.

If the user does not have administrator credentials, the system prompts the following error message when you attempt to grant bash access to the user:
01070825:3: Access denied - Administrators only: Custom shells are only available to administrators not <user>

Environment

  • TMSH/Bash access
  • BIG-IQ local user account with "Administrator" role

Cause

User account has no assigned privilege access to the Advanced Shell (bash) or the TMOS Shell (tmsh).

Recommended Actions

To enable a user access to bash or tmsh, perform the following procedure:
Note:  You must be logged into the BIG-IQ with a user who already has TMSH/Bash access

  1. Log in to tmsh on the BIG-IQ system.
  2. To enable user access for tmsh, use the following command syntax:

    modify /auth user <UserID> shell tmsh

    To enable user access for bash, use the following command syntax:

    modify /auth user <UserID> shell bash

    For example, to enable the adm_emp2 user access to tmsh, type the following command:

    modify /auth user adm_emp2 shell tmsh

  3. Save your changes by typing the following command:

    save /sys config

  4. To exit tmsh, type quit and press Enter.

Additional Information

By default, prior to v8.x, local default admin user account has access to tmsh.
By default, a new user account with the Administrator role in the BIG-IQ system does not have access to bash or tmsh.
