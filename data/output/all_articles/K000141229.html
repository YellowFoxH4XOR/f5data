Description

When you try to adjust the tenant memory on F5OS hypervisor, it fails with the similar following error messages.

/tenants/tenant{<tenant_name>}/config: Cannot modify <tenant_name> memory. Changes are invalid in current state.

Hide Details
error-type : application
error-tag : malformed-message
error-path : /f5-tenants:tenants/tenant[name='<tenant_name>']/config
error-message : /tenants/tenant{<tenant_name>}/config: Cannot modify <tenant_name> memory. Changes are invalid in current state.

Environment

  • F5OS hypervisor, every software version
  • Tenant memory setting

Cause

The tenant is still in Deployed state during the memory adjustment. The adjustment is blocked due to the tenant is still running.

Recommended Actions

We need to Shutdown or Power off the tenant prior the memory adjustment, refers to the following procedure.

  1. Since you're already in side the tenant setting, select Provisioned for the State, then Save & Close. Select OK to confirm the change.
  2. Page will return to Tenant Deployments, wait until the tenant state shows as Provisioned.
  3. Navigate into the tenant which you prefer to adjust the memory.
  4. Adjust the new memory allocation and select Deployed, then Save & Close. Select OK to confirm the change.
  5. Page will return to Tenant Deployments, wait until the tenant state shows as Running.

Additional Information

  1.  Prior this change, please make sure that the tenant status is Standby since this procedure will shutdown the tenant.
  2. This process is also applicable with other tenant settings such as modifying the tenant CPU cores.
