Description

Swap memory usage increases to higher levels than previously seen within a few days of upgrading to BIG-IP version 13.x or later from version 12.1 or earlier.

Environment

  • BIG-IP version 13 or later
  • Swap memory is noticeably higher than prior version

Cause

  • This is normal behavior particularly with multiple modules provisioned
  • Beginning in version 13.0, BIG-IP uses the CentOS 7.x Linux kernel, which more aggressively pages out to swapfile compared to CentOS 6.X kernel used in version 12.1 and earlier.

Recommended Actions

None

Additional Information

Since version 13.0, the Linux kernel used in the BIG-IP has started using a more aggressive swap algorithm for memory pages that are idle.
This means that the swap use is often much higher than in previous versions of BIG-IP. However, this high swap use is for pages that are not being actively referenced, and paging to/from disk is not actually occurring at a significant rate.
On these versions of BIG-IP, the important figure to review is the MemAvailable result from /proc/meminfo:

# cat /proc/meminfo
MemTotal 16423848 kB
MemFree 232632 kB
MemAvailable 880620 kB
