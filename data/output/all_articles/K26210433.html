Description

You have added new blade to the chassis. While checking status of slot 3 from Host everything looks fine. But there is an issue with software installation on the guests for slot 3:

# tmsh show sys software status

--------------------------------------------------------------------------------------------------------------
Sys::Software Status
Volume  Slot  Product   Version    Build  Active                                       Status  Allowed Version

--------------------------------------------------------------------------------------------------------------
HD1.1      1   BIG-IP  14.1.2.6    0.0.2      no                                     complete                              yes
HD1.1      2   BIG-IP  14.1.2.6    0.0.2      no                                     complete                              yes
HD1.1      3   BIG-IP    11.5.1  8.0.175     yes                               upgrade needed                              yes
HD1.3      1   BIG-IP  15.1.2.1   0.0.10     yes                                     complete                              yes
HD1.3      2   BIG-IP  15.1.2.1   0.0.10     yes                                     complete                              yes
HD1.3      3     none      none     none      no  waiting for product image (BIG-IP 15.1.2.1)                              yes

Status of installation on one volume is "upgrade needed" and on another "waiting for product image" even if the image for the version 15.1.2.1 is visible in /Shared/Images on the guest slot 3.

Environment

  • VIPRION Blade
  • BIG-IP

Cause

The software on HD1.1 is stuck with upgrade needed, because the system cannot proceed with installation on HD1.3. Installation on HD1.3 is stuck due to base image for the guest on the new slot is 11.5.1, which is affected by Bug ID 497234, and sync of images bigger than 2GB is getting stuck.

Recommended Actions

To resolve this issue, you need to trigger sync of software image to the guest slot 3. You can do so with following steps:

1. Connect to the guest slot 3, you can use command vconsole from Host:

    # vconsole <vcmp guest name> slot 3

2. Run below command to manually add the software image to the 'sys software' configuration:

    # imagemgr -a /shared/images/<name of ISO>

This should manually add the image and the installation on HD1.3 should start. Once done, system should automatically change boot location and finish installation on HD1.1

If above solution will not work, additional steps might be needed:

1. bigstart stop csyncd
2. imagemgr -a /shared/images/15.1.2.1-0.0.10.iso
3. Confirm "tmsh list sys software image" now lists 15.1.2.1
4. Confirm "tmsh show sys software" shows that the system starts performing an install of software.
