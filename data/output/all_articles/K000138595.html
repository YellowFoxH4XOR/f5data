K000138595: [F5OS-C] Unable to ping a running tenant from blades

Type
Support Solution
Published
2024-02-14
Updated
2024-03-01
Applies to
  • F5OS
  • VELOS Platforms
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000138595

Description

Unable to ping from a blade to any tenant's management IP.

  • The blades are assigned to the partition where the tenants reside.
  • From other devicee, ping to the tenant's management IP is successful.

Applied the workaround in Bug ID 1064701, however not able to ping.

 

Environment

  • F5OS-C
  • Velos
  • Tenant
  • Blade
  • management IP

 

Cause

  • By design. There is no route set from blade to the management IP, and should not create the route.
NOTE: Bug ID 1064701 is for F5OS-A

 

Recommended Actions

Check if you can ping from other device after checking the route to the tenant's management IP.
Usually it should be possible to ping from controller.

NOTE: Partition CLI support only ConfD with two mode

  • Operational mode
  • Configure mode

There is no access to Linux utilities on the Partition CLI
