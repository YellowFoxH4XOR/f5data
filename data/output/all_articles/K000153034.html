K000153034: Multiple HSL log-config filters fail to send log messages to more than one receiver

Description

A common scenario for logging involves sending all logs to one remote log receiver, while a subset of these logs is sent to a different remote log receiver. However, when multiple HSL filters are configured to accomplish this task via the sys log-config filters command, the BIG-IP system forwards log messages using only one of the defined HSL filters.

Environment

  • LTM

Cause

This is functioning as designed. Each log message emitted by the BIG-IP system can only be matched and forwarded by a single log-config filter at a time.

Recommended Actions

To send different, overlapping subsets of log messages to more than one log receiver, you can leverage the local syslog-ng forwarder as follows:

  1. First configure log-config filters to send the larger superset of logs (for example, by matching logs at a lower severity) to the first remote log receiver as well as to the local syslog-ng instance.
  2. Configure syslog-ng filters to further filter the messages on the desired subset (for example, by matching higher severity logs) and then forward them to the second remote log receiver.
