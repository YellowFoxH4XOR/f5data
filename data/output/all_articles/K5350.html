Known Issue

This is the result of a known issue. When you perform an upgrade, the IM process attempts to shut down the NameSurfer process by running a bigstart script that locates the NameSurfer process ID file and then kills the process.

If the BIG-IP is not licensed to run 3-DNS, or if NameSurfer is disabled, the bigstart script will report the following error messages:

cat: /usr/local/namesurfer/run/ns.pid: No such file or directory
cat: /usr/local/namesurfer/run/webui.pid: No such file or directory
usage: kill [-s signal_name] pid ...
kill -l [exit_status]
kill -signal_name pid ...
kill -signal_number pid ...
bigstart: namesurfer exited abnormally, status = 1

These error messages are not detrimental, although they should not be printed to the screen. They indicate that the bigstart script attempted to shut down the NameSurfer process, but NameSurfer was not running.

F5 Networks Product Development tracked this issue as CR22200, CR23562, CR24784, CR26582, and CR26345.
