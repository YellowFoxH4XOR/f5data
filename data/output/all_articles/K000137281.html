Description

Within Central Manager it is possible to change the WAF provisioning of a Next instance with a toggle button. When toggled on (blue), WAF is enabled although the description attached to this toggle button may lead administrators to be confused about the actual state.

Toggling this button on (blue) or off will cause a provisioning process to start.

Note: When a Next instance is currently using a WAF policy, this option is greyed out.

If the Next devices are in HA then the following things will happen:

  1. The Standby will reprovision.
  2. HA failover will occur.
  3. The new Standby will reprovision.

When HA is in a healthy state and mirroring is setup, there will be no impact to traffic flow.

If no HA is setup then the reprovisioning will cause a network disruption while reprovisioning happens on the standalone unit.

Environment

BIG-IP Next with Central Manager

Cause

Changing provisioning.

Recommended Actions

While reprovisioning a healthy HA system should be a safe operation, perform this activity during a maintenance window in particular when the Next instance is standalone.
