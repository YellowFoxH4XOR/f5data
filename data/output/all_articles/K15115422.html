Known Issue

With some combinations of rules using the HTML profile, the TMM process could get stuck in an infinite loop.

This issue occurs when all of the following conditions are met:

  • You have the HTML profile configured on a virtual server.
  • You are using any combination of Append HTML or the Prepend HTML rules within the HTML profile.

Impact

The BIG-IP system stops processing requests and fails over to a standby host, if a standby host is configured.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system shows 100% CPU usage.
  • The BIG-IP system may show degraded performance, or experience temporary traffic processing interruptions.
  • The TMM process may produce a core file in the /var/core directory.
  • The BIG-IP system may fail over to a standby host in a device group.
