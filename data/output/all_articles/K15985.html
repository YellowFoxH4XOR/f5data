Known Issue

The Traffic Management Microkernel (TMM) may produce a core file on a BIG-IP Virtual Edition (VE) system when it forwards a network packet to another TMM.

This issue occurs when all of the following conditions are met:

  • The BIG-IP VE system is configured with tagged interfaces in VLANs.
  • TMM receives a packet on a tagged VLAN that needs to forward a received packet to another TMM. For example, on a Clustered Multiprocessing (CMP) demoted virtual server.

Impact

TMM may produce a core file and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H499784 on the Diagnostics > Identified > Medium|High screen.
  • The BIG-IP VE system may fail to process traffic for a brief period.
  • The BIG-IP VE system may fail over to another host in the device group.
  • TMM generates a core file in /var/core.

Workaround

There is no work around for this issue. However, you can avoid this issue by disabling the VLAN tags if the network environment is suitable.
