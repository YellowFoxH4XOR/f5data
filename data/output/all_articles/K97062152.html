Issue

Error Message

01b6000b:3: At least one ds-algorithm must be specified.

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The TMOS Shell (tmsh) 

Description

This message occurs when the following condition is met:

  • You attempt to remove the only algorithm in the Delegation Signer (DS) Record Hash Algorithms list for the Domain Name System Security Extensions (DNSSEC) zone.

The DS Record Hash Algorithm list is the list of hash algorithms the system uses to create DS resource records for a DNSSEC zone. Each DNSSEC zone configured on the system must have at least one DS algorithm configured. When a new DNSSEC zone is created but no DS algorithm is specified, it defaults to the DS algorithm SHA1.

Impact

There is no impact. The DNSSEC zone remains unchanged.

Recommended Actions

You should specify at least one DS algorithm when modifying the DNSSEC zone DS Record Hash Algorithms list.

For example, the following tmsh command replaces all DS Record Hash Algorithms with sha256 for the zone MySite.org:

tmsh modify /ltm dns dnssec zone MySite.org ds-algorithms replace-all-with { sha256 }
