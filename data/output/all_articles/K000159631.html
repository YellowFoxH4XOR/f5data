Description

BIG-IP DNS may display virtual servers as down (unavailable) even though the virtual servers are up and available on the associated LTM server or generic host or generic Load Balancer.

Environment

  • BIG-IP DNS running version 16.1.0 or later
  • BIG-IP any version with virtuals server configured on BIG-IP DNS
  • Generic host with virtuals server configured on BIG-IP DNS
  • Generic Load Balance with virtuals server configured on BIG-IP DNS

Cause

The observed status is correct and is due to change in behaviour introduced in BIG-IP DNS 16.1.0 through RFE ID808829. When a virtual server is disabled on the DND server object or related pool then the BIG-IP DNS will stop monitoring the virtual server even if it is available on the BIG-IP, generic host or generic Load Balancer. This change helps to reduce resource usage as the disabled objects will cease to be monitored.
