Description

You are seeing messages similar to the one below in /var/log/ltm:

err bcm56xxd[34151]: 012c0018:3: DDM interface:<blade>/<interface> transmit power too high alarm. Power(mWatts) <value> <value> <value> <value>
err bcm56xxd[34151]: 012c0018:3: DDM interface:<blade>/<interface> transmit power too high warning. Power(mWatts) <value> <value> <value> <value>
err bcm56xxd[34151]: 012c0020:3: DDM interface:<blade>/<interface> transmit power too high alarm cleared
err bcm56xxd[34151]: 012c0020:3: DDM interface:<blade>/<interface> transmit power too high warning cleared

Environment

  • BIG-IP with DDM enabled

Cause

Digital Diagnostics Monitoring (DDM) is a feature used in optical transceiver modules that enables you to view real-time information about transceivers, such as optical output and input power. An error may be logged if the transceiver sends or receives using voltage that is either too high or too low.

Recommended Actions

Any of the following options should help you identify whether the issue is with the SFP, the socket, or the next hop device:

  • Reseat the transceiver
  • Replace the cable
  • If you have spare SFPs available, test with another SFPs on the indicated interface
  • Move the suspicious SFP in another port on the BIG-IP and see if the error follows the SFP or the port
  • Change ports on F5 side, and next hop side, and both
  • Ensure you are using F5 supported hardware

If you identify a hardware issue with either the SFP or Appliance, please contact Support for assistance. If an issue is identified with the next hop device, please contact that vendor for assistance.
