Issue

Error Message

notice statsd[<PID>]: 011b0816:5: Statistical collection has ALREADY been started.

In this error message, note the following:

  • <PID> is the process ID for the statsd process

For example:

notice statsd[7211]: 011b0816:5: Statistical collection has ALREADY been started.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • Statistical data collection is reinitiated after the initiation process has already begun.

This condition may occur when a device in a clustered environment transitions from the high availability (HA) failover state of primary, to backup, and then back to primary within the statistical collection period. Statistics collection is initiated on the primary device within an HA clustered environment.

Impact

There is no impact; this message is a notification.

Recommended Actions

None
