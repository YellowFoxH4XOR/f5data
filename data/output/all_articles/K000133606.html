Description

Article describes what to do to extend date up to 90 days of auto-renewal of External CA certificate.

Current available options are 7 15 30

 

Environment

  • BIG-IQ CM
  • CA Certificate Auto-renewal

Cause

ID1288097

Recommended Actions

Manually add option for auto-renewal  in configuration files:

Step#1: Remount the usr folder in the server

mount -o remount, rw /usr

 

Step#2: Move to js file location

 

cd /usr/local/www/ui/js/

 

Step#3: Take a backup of app.js file

 

cp app.js app.orig.js

 

Step#4: Open the app.js file in VI editor

vi app.js

 

Step#5: Search for thirdPartyEdit.renewOptions

Esc + / thirdPartyEdit.renewOptions

 

Step#6: Replace the existing code with the new code and save the app.js file (using Esc +:wq!).

Existing Code:
thirdPartyEdit.renewOptions = [7, 15, 30];

New Code:
thirdPartyEdit.renewOptions = [7, 15, 30, 90];

 

Step#7: Gzip the app.js file

gzip -c app.js > app.js.gz

Step#8: Mount the usr folder in the server

mount -o remount, ro /usr

 

Note: Change does not preserve upgrades
