Description

How to monitor Rseries Interfaces / Link state chanege in logs 

Environment

  • Rseries running F5OS

Cause

Where to find the logs that show the physical interfaces going up/down 

Recommended Actions

file tail -f log/system/platform.log

Additional Information

You should see logs similar to
