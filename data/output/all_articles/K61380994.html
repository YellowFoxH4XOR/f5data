Description
In a particular condition, persistence does not work and BIG-IP distributes traffic to next available pool member even though the request is on a same connection.

  1. oneconnect profile is configured
  2. destination pool member is marked force offline
This is because PERSIST_DOWN event triggers and persistence to the forced offline pool member is not honored anymore.

Environment

  • BIG-IP LTM

Cause
This is by design.
