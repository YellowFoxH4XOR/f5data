Description

Cron job that will log error to /var/log/ltm if TMM is impacted by CVE-2021-23007

  • TMM can get into a bad state that will result in dropped IP fragments
  • Custom cron job can be configured to log errors to /var/log/ltm if TMM is dropping IP fragments due to CVE-2021-23007
  • Example Error message
    Mar 19 17:40:01 [hostname] err root[31030]: tmm impacted by CVE-2021-23007 - dropping all fragmented IP traffic

Environment

  • All data plane (TMM) traffic is vulnerable to this issue
  • All modules on version 14.1.4 or 16.0.1.1

Cause

TMM vulnerability CVE-2021-23007 / F5 bug ID 1002561


Recommended Actions

Upgrade to non-affected version per Ask F5 article K37451543.

If immediate upgrade is not possible. The following steps will configure a custom cron job to detect and log errors if TMM becomes impacted by CVE-2021-23007 and starts dropping IP fragmented traffic.
 

  1.   Create script in /config to evaluate the frag assembler looking for evidence of CVE-2021-23007 impact:
    /config/cve-2021-23007-test.sh
     
    #!/bin/sh
    #check if frag bytes used has an impossibly large value
    thresh=1800000000000000000
    val=$(tmctl -q ip_stat -s frag_bytes_used)
    python - $thresh $val<<EOF
    if ($val > $thresh):
        print "1"
    EOF
     
  2. Make the script executable:
    chmod 755 /config/cve-2021-23007-test.sh
     
  3.  Edit root cron to add the following entry:
    crontab -e
    */10 * * * * if [ $(/config/cve-2021-23007-test.sh) ]; then /bin/logger -p local0.err "tmm impacted by CVE-2021-23007 - dropping all fragmented IP traffic"; fi
