K000130017: Error 01070712:3: while trying to create SSL key or update file object: file (/var/system/tmp/tmsh/<folder name>/xxx) expected to exist

Type
Support Solution
Published
2022-12-14
Updated
2025-02-12
Source
https://my.f5.com/manage/s/article/K000130017

Description

Creating new SSL key or updating a file object via tmsh fails with an error message similar to one of the following:

  • 01070712:3: file (/var/system/tmp/tmsh/<folder name>/ssl.key/xxx) expected to exist
  • 01070712:3: file (/var/system/tmp/tmsh/<folder name>/data) expected to exist

    In /var/log/ltm, there is a configuration exception log message similar to:

    • err mcpd[7080]: 01070712:3: Caught configuration exception (0), file (/var/system/tmp/tmsh/RFUVFc/ssl.key/xxx) expected to exist..

    And in /var/log/auditd/audit.log, there is denied error:

    • type=AVC msg=audit(2022-12-14T08:19:11UTC:30884): avc: denied { getattr } for pid=7080 comm="mcpd" path="/var/system/tmp/tmsh/RFUVFc/ssl.key/xxx" dev="dm-12" ino=6584 scontext=system_u:system_r:mcpd_t:s0 tcontext=unconfined_u:object_r:tomcat_cache_t:s0 tclass=file

    Environment

    • BIG-IP
    • using tmsh to create SSL key or update a file object

    Cause

    The SElinux context was incorrectly set on the directory "/var/system/tmp/tmsh".

    Expected SElinux context:

    # ls -ldZ /var/system/tmp/tmsh

    drwxrwxrwt. root root system_u:object_r:var_t:s0    /var/system/tmp/tmsh

    Problematic SElinux context:

    # ls -ldZ /var/system/tmp/tmsh

    drwxrwxrwt. root root system_u:object_r:tomcat_cache_t:s0 /var/system/tmp/tmsh

     Recommended Actions

    Restore the default SELinux context by running the following command:

    # restorecon /var/system/tmp/tmsh

    Additional Information

    None.
