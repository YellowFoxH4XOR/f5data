Known Issue

This is the result of a known issue. When a cached document's age is updated by the origin server, and the new age has fewer digits than the current age, the BIG-IP system corrupts the Age header when sending a response containing the document from the RAM Cache. This issue occurs because the new age does not overwrite the current age completely, and the trailing digits of the current age are included in the new age.

F5 Product Development tracked this issue as CR129601 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, or WebAccelerator Release Notes.

Additionally, this issue was fixed in BIGIP-10.0.1-378.0-HF3 issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
