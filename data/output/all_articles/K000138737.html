K000138737: rSeries / F5OS-A platform-monitor process experiencing memory leak

Type
Support Solution
Published
2024-02-27
Updated
2024-02-27
Applies to
  • F5OS
  • F5OS-A: 1.5.0, 1.4.X, 1.3.X, 1.2.X, 1.4.0, 1.3.2, 1.3.1, 1.3.0, 1.2.0
Source
https://my.f5.com/manage/s/article/K000138737

Description

The platform-monitor process is observed to be growing in size when reviewed with tools such as ps, top or docker stats.

The process will grow to a very large size over time. For example, the platform-monitor process has a resident size of ~2.7GB in the below example of ps aux output.

USER       PID %CPU %MEM      VSZ     RSS TTY   STAT START     TIME COMMAND
root     10038  6.2  2.0 13609380 2743616   ?   Ssl   2023 16477:14 /app/platform-monitor

Environment

  • platform-monitor
  • F5OS-A version prior to v1.5.1

Cause

Bug ID 1328729: Slow memory leak when processing tenant telemetry

This issue occurs on F5OS-A versions prior to v1.5.1 when BIG-IP tenants are running v15.1.7 or earlier.

Recommended Actions

Upgrade to a fixed version. This issue is fixed in F5OS-A v1.5.1 and later.

As an immediate workaround, you can restart the platform-monitor container to free up memory:

docker container restart platform-monitor
