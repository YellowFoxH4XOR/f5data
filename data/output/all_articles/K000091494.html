K000091494: Unable to establish IPSec tunnel connection between F5 & AWS

Type
Support Solution
Published
2022-04-18
Updated
2022-04-18
Source
https://my.f5.com/manage/s/article/K000091494

Description

  • VPN to AWS does not establish
  • Phase 1 does not come up
  • AWS responds with "No proposal chosen"

Environment

  • BIG-IP with LTM provisioned
  • AWS configured to use "SHA1" as IKE peer authentication algorithm


Cause

After configuring the AWS end of the VPN, AWS provides an option to export the matching BIG-IP config. If the AWS end was configured with "SHA1" as the IKE peer authentication algorithm, this config will contain no value for the IKE peer authentication algorithm because the matching "SHA-1" setting used to be the default on the BIG-IP. This default changed and is now "SHA-256".


 Recommended Actions

  1. Check the settings used on AWS
  2. Configure the BIG-IP settings to match


Additional Information

None.
