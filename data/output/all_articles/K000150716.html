K000150716: Status 'Challenge' CSI not showing in remote WAF logs

Type
Support Solution
Published
2025-04-04
Updated
2025-04-04
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150716

Description

Brute Force CSI challenges are showing a request_status of 'blocked' in remote logs, but 'Challenged' in local logs.


Environment

ASM Remote logging

CSI challenges configured


Cause

The "request_status" field has only 3 values when sending remotely: "blocked", "alerted", and "passed". Due to this, challenged requests are sent off as "blocked".


Recommended Actions

You can configure the remote logging profile to use CSV and include the "enforcement_action" field to differentiate between CSI challenges and true blocks.
