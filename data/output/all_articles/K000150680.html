K000150680: Unable to Associate JSON Web Token with NGINX Instance Manager

Type
Support Solution
Published
2026-08-27
Updated
2026-08-27
Applies to
  • NGINX Products
  • NGINX Instance Manager: 2.19.X, 2.21.X, 2.20.X, 2.20.1, 2.20.0, 2.19.2, 2.19.1, 2.19.0, 2.19.3, 2.21.1, 2.21.0
Source
https://my.f5.com/manage/s/article/K000150680

Description

  • You have completed fresh instillation of NGINX Instance Manager
  • You have access to NIM UI
  • However, you are unable to license

Environment

  • NGINX Instance Manager
  • License
  • Instillation

Cause

  • Routing issue - NIM unable to connect to licensing server (product.connect.nginx.com)

Recommended Actions

-- modified nms.conf file for disconnected environment

  • integrations:
  • license:
  • mode_of_operation: disconnected

-- restarted service nms and nginx

-- offline license activation

- from NIM UI downloaded usage report

- Submit the usage report to F5 for verification

curl --location 'https: // product.apis.f5 . com/ee/v1/entitlements/telemetry/bulk' \
--header "Authorization: Bearer $(cat /path/to/jwt-file)" \
--form 'file=@"<path-to-report>.zip"'

- Check the status of the usage acknowledgement

curl --location 'https://product.apis.f5.com/ee/v1/entitlements/telemetry/bulk/status/<report-id>' \
--header "Authorization: Bearer $(cat /path/to/jwt-file)"

- Download the usage acknowledgement from F5

curl --location 'https://product.apis.f5.com/ee/v1/entitlements/telemetry/bulk/download/<report-id>' \
--header "Authorization: Bearer $(cat /path/to/jwt-file)" \
--output <path-to-acknowledgement>.zip

-- Using NIM UI, uploaded usage acknowledgement

-- verified and reverted disconnected mode to connected

-- restarted nms and nginx service

-- verified NIM UI and NIM features
