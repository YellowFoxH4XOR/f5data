K8199: Installing an F5 Network Access client on locked Windows Mobile smartphones

Topic

Many telecommunications service providers of mobile devices issue their smartphones, PDAs and similar devices with an application lock applied to the operating system that prevents users from installing software. If you install the F5 Network Access client software on a Windows Mobile device that has an application lock, the client will fail to run even though the installation may appear successful.

For devices with an application lock, F5 Networks recommends contacting your service provider to determine if you can bypass the lock to install the F5 Network Access client.
