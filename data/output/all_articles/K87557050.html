Known Issue

ConfigSync operations may fail after you create a partition.

This issue occurs when the following condition is met:

  • You attempt to create a folder and an object that will reside in the folder in a single transaction.

Creating a folder and an object that will reside in the folder may be accomplished by explicitly using the Traffic Management Shell (tmsh) or iControl transaction mechanisms, or as a result of an incremental BIG-IP APM synchronization.

Impact

ConfigSync operations fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • ConfigSync operations fail.
  • The Configuration utility generates an error message that appears similar to the following example:

    Configuration error: Can't associate (/P1/pool1) with folder (/P1) folder does not exist.

Workaround

To work around this issue, you can perform the following actions when creating partitions / folders:

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

  • Create partitions/folders in a separate transaction from the objects that will reside in the folder.
  • Use the Overwrite Configuration option to perform a full BIG-IP APM synchronization.
