K6955: The Use Legacy Logon Prompt setting of the standalone VPN Client is not compatible with pre-logon checks and post-logon actions

Topic

Starting in FirePass version 6.0.0, the FirePass standalone VPN client uses a new logon mechanism that supports pre-logon checks and post-logon actions. You can enable the legacy logon mechanism by enabling the Use Legacy Logon Prompt setting in the standalone VPN client. However, the legacy logon mechanism is not compatible with pre-logon checks and post-logon actions.

If you enable a pre-logon sequence in the FirePass controller, and the Use Legacy Logon Prompt setting is enabled in the standalone VPN client, the standalone VPN client fails to log on and reports an error message that appears similar to the following example:

Your device does not comply to current client security policies.

If you enable a post-logon sequence in the FirePass controller, and the Use Legacy Logon Prompt setting is enabled in the standalone VPN client, the standalone VPN client will log on, but no post-logon actions are performed.

Note: Pre-logon sequences are configured on the Users: Endpoint Security: Pre-Logon Sequence, and post-logon actions are configured on the Users: Endpoint Security: Post-Logon Actions page.

Enabling and Disabling the Use Legacy Logon Prompt setting

To enable or disable the Use Legacy Logon Prompt setting in the FirePass standalone VPN client, perform the following procedure:

  1. Start the FirePass standalone VPN client.
  2. Click the Settings button.
  3. Click Session Settings.
  4. Clear the Use Legacy Logon Prompt check box to disable the legacy logon mechanism, which enables support for pre-logon checks and post-logon actions.
    Select the Use Legacy Logon Prompt check box to enable the legacy logon mechanism, which disables support for pre-logon checks and post-logon actions.
  5. Click the OK button.

Note: The Use Legacy Logon Prompt setting is a configurable option for the FirePass standalone VPN client installer package. You can pre-set this setting for users by selecting or clearing the Use Legacy Logon Prompt check box on the Device Management: Client Downloads: Windows (x86) page under the Customize Client Components tab.
