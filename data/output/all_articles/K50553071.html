Known Issue

Querying the master control program daemon (mcpd) process for CPU information statistics may cause the mcpd process to leak memory.

This issue occurs when the following condition is met:

  • The rare possibility of a mcpd memory leak was found during a code inspection. However, a specific condition known to trigger the leak has not been identified.

Impact

Memory exhaustion may result in degraded performance and cause the system to become unresponsive. Devices configured as a high availability (HA) pair may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe a progressive increase in the amount of memory that the mcpd process uses.
  • System performance degrades or the system becomes unresponsive.
  • The mcpd process restarts and an mcpd core file appears in the /shared/core directory.
  • In an HA configuration, your BIG-IP system unexpectedly fails over to another system in the device group.
