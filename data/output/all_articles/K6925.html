Known Issue

This is the result of a known issue. The x-wap-profile extension headers are used to transport CC/PP (Composite Capabilities/Preference Profiles) data in W-HTTP (Wireless HTTP) sessions. The BIG-IP LTM will send a TCP reset to close the connection when the BIG-IP LTM receives a multi-line x-wap-profile-diff HTTP header that is split across multiple packets.

F5 Product Development tracked this issue as CR72283 and CR72367, and it was fixed in BIG-IP LTM versions 9.3 and 9.4. For information about upgrading, refer to the BIG-IP LTM release notes.
