Description

You may find the following messages on the serial console log after rebooting BIG-IP;

umount /lib/bootchart/tmpfs/proc: Invalid argument
unlinking /lib/bootchart/tmpfs/kmsg: No such file or directory

Environment

  • BIG-IP
  • After reboot
  • Reviewing the serial console log

Cause

The exact root cause is unknown. 

Recommended Actions

There is no impact to the system because bootchart is only meant to collect metrics. 

Additional Information

For more information about bootchart, refer to:

  • bootchart2(1) [debian man page]
