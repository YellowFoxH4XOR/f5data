K000134822: The trunk interface doesn't show in VLAN edit page via configuration utility (WebUI)

Type
Support Solution
Published
2023-06-29
Updated
2023-07-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000134822

Description

The trunk interface doesn't show in the vlan edit page via the configuration utility (WebUI).
This may be related to the browser that cannot show all of the dropdown-list.

 

Environment

  • LTM v16.1.3.1
  • Trunk interface
 

Cause

The trunk interface doesn't show in the vlan edit page via the configuration utility (WebUI).


Recommended Actions

Manually add the vlan to the trunk via the command line.

Impact of workaround: This should not have any impact on the system.
modify net vlan <vlan_name> interfaces add { <interface_name> { tagged } } tag <tag_id>

For example:
modify net vlan <vlan_name> interfaces add { <interface_name> { tagged } } tag <tag_id>
