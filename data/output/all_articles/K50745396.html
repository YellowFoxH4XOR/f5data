Known Issue

Data transfers sourced from the BIG-IP self IP address may be slow or even fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP self IP address interface, processes large data transfers.
  • The router adjacent to the BIG-IP system does not process IP fragments with the Don't Fragment (DF) and More Fragment (MF) bits set.
  • TCP segmentation offload (TSO) is enabled. TSO is enabled by default.

TCP traffic on a BIG-IP system using a self IP address may not correctly honor the MSS size specified during the connection establishment. The result is IP fragmentation of TCP segments sent out on the wire. The expected behavior is for TSO to package the TCP segments in a way that does not require fragmentation.

Impact

Users experience slowness or failure when data transfers are sourced from the BIG-IP self IP address.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system sets the DF and MF bits on egress fragmented IP packets.
  • TCP traffic from the self IP address of a BIG-IP may not correctly honor the MSS size specified during the connection establishment resulting in unexpected IP fragmentation of TCP segments.
  • Users experience slowness when data transfers are sourced from the BIG-IP self IP address.

Note: Setting both bits is Request for Comment (RFC) compliant. However, some routers drop such packets, resulting in retransmissions and low throughput.

Workaround

To work around this issue, you can disable TCP segmentation offload (TSO) by typing the following command from the BIG-IP command line:

ethtool -K tmm tso off

For example:

alert tmmready "Tmm ready" {
    exec command="/sbin/ethtool -K tmm tso off"
}

Note: This command has a different outcome from setting the tm.tcpsegmentationoffload database key to disable, which is not a workaround for the issue.

To persist the effect of this command across reboots, perform the procedure in K14397: Running a command or custom script based on a syslog message.
