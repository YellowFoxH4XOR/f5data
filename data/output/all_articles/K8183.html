K8183: The Forest mode option and Require user logon in form DOMAIN\\username option are mutually exclusive

Topic

When configuring a FirePass master group to authenticate with an Active Directory server, the Forest mode option and the Require user logon in form DOMAIN\username option are mutually exclusive. Forest mode permits users to authenticate with a username that is in User Principal Name (UPN) format.

For example:

joe@dom1.us.siteconfig.com

The DOMAIN\username format for the same user would appear as follows:

DOM1.US.SITECONFIG.COM\joe

Active Directory authentication is configured on the Authentication tab of the Users: Groups: Master Groups page.

In the Administrative Console, selecting the check box next to one option will gray out the other option's check box, making it unselectable (inactive). To switch between the options, deselect the active option's check box, then select the other option's check box.

Note: Support for UPN format was introduced in version 6.0.2. Hotfix HF-69104-1-1 and later versions of this hotfix add support for UPN for version 6.0.1.
