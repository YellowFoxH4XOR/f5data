Description
Learning Suggestion on Active BIG-IP ASM is missing after a Manual Sync from Standby unit to Active.

Environment

  • HA Pair
  • ASM in a Sync Group with Manual Sync
  • Manual Sync from Standby to Active

Cause

This is functioning as designed.

Recommended Actions

None

Additional Information

In an HA pair, when a manual configuration sync is done from the standby to the active, the learning suggestions on active will be cleared and this is by design.

Learning suggestions are considered "ephemeral" data and are NOT exported as configuration data during Policy Export (XML or Binary), Upgrade, or CMI Sync. The important thing to understand from Policy Building (PB) perspective is that the underlying statistics of the lost suggestions are saved in a persistence file on the active machine (where PB operates). Thus in the next traffic sample following pabnagd restart and persistence load on the active machine the suggestion will appear in the traffic learning screen with a higher score (higher than what was saved in the persistence file).
