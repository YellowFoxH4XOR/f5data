K54271240: Reject all ACL is not affecting RDP resource traffic

Description

Deny ACL does not work when applied to RDP

Environment

  • APM
  • RDP
  • ACL
Cause

This is the expected behaviour.
ACLs are not applied to the RDGSP protocol.
There are currently no iRules that would serve as a workaround.

Recommended Actions:

A Windows Group Policy rule on the client's computer, or a rule in the corporate network firewall, can be used to block port 3389 traffic.

None
