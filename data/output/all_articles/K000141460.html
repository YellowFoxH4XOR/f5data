Description

The physical interfaces from the F5OS host should be passed through to tenants on r2000/r4000 series platforms, but some interfaces may not be passed through when configured in a LAG on the host.

 

Environment

  • rSeries r2000/r4000 platform
  • Interfaces in a Link Aggregation Group (LAG)

Cause

The LAG name can be up to 32 characters, but if the LAG name is over 30 characters the interfaces associated with the LAG will not be passed through.

 

Recommended Actions

Shorten the LAG names to be under 30 characters.
