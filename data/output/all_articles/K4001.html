K4001: Reasons why aggregated connections may fail, particularly when there is packet loss on the network

Topic

When using web aggregation, BIG-IP will close out connections to nodes using a reset (RST) rather than a FIN. This is more expedient than closing with a FIN, but can cause a problem if the reset packet is dropped or ignored by the node. If this occurs, the connection will remain open on the node. BIG-IP may then attempt to open another connection to the node, using the same source port. If the node has not timed out its side of the connection, a conflict will occur, because the node will reject new connections from source ports that are already in use.
