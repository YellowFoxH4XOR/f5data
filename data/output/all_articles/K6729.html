Known Issue

This is the result of a known issue. Persistence records created using an iRule may result in a Tool Command Language (TCL) string object memory leak in instances where all of the pool members are marked as down, or the connection fails.

F5 Product Development tracked this issue as CR70058 and CR70119 and it was fixed in BIG-IP LTM 9.1.3, 9.2.5, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.
