Known Issue

The iControl REST application programming interface (API) command may return an error message when creating a new pool member.

This issue occurs when the following condition is met:

  • You use the iControl REST API command to create a new pool member on an existing pool.

Impact

None. Pool members are successfully created, even though the system reports a “404” error message.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • iControl REST returns a “404” error response similar to the following example, even though the system has created the 172.16.1.1:80 example pool member:

    {
        "code": 404,
        "message": "Object not found - 172.16.1.1:80",
        "errorStack": []
    }
