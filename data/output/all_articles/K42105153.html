Known Issue

The Configuration utility may erroneously prevent a user from modifying an existing address record of a data group.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with an internal data group using the Address type.
  • The address records of the data group can be either in the IPv4 or IPv6 format.
  • Using the Configuration utility, you attempt to modify the value on one of the address records of the internal data group.

Impact

You are unable to modify an existing address record of an internal data group using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you use the Configuration utility to update the value field of an address record by specifying a valid IP address, you notice an error message similar to the following example:

    Error parsing IP address: <IP address>:<netmask>

Workaround

To work around this issue, you can use the TMOS Shell (tmsh) to update the value field of an address record in the data group. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To update the address record of an existing data group, use the following command syntax:

    modify /ltm data-group internal <data-group name> records modify { <IP address>/<netmask> { data <IP address>} }

  3. Save the change by typing the following command:

    save /sys config
