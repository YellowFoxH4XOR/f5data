Known Issue

This is the result of a known issue. After generating a new SSL server certificate request on the Device Management: Security: Certificates page and clicking on the link to download the certificate request, the downloaded zip file only includes the readme file and the certificate key. This zip file does not include the CSR file.

This issue was introduced in FirePass cumulative hotfix HF-610-1.

F5 Networks Product Development is tracking this issue as ID 294235 (formerly CR134563-1) for FirePass version 7.0.0, and as ID 317691 (formerly CR134563) for FirePass version 6.1.0.

This issue was fixed for ID 317691 (formerly CR134563) in cumulative hotfix HF-610-3-1 for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.
