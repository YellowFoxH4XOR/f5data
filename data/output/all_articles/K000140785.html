Description

BIG-IP Failover using Cloud Failover Extension (CFE)  in Google Cloud is not working. 

 

Following errors are observed in /var/log/restnoded/restnoded.log 

severe: [f5-cloud-failover] Failover initialization failed: Filtered bucket does not exist

 

Environment

  • BIG-IP device deployed in Google Cloud
  • Failover is not working 
  •  Cloud Failover Extension (CFE) 

 

Cause

GCP Identity and Access Management (IAM) service account with insufficient access 

Recommended Actions

 

1. Confirm  storage bucket is in the same project with a tag applied as per declaration

"f5_cloud_failover_label": ""

 

2. Check permission for cloud storage buckets 

Refer https://clouddocs.f5.com/products/extensions/f5-cloud-failover/latest/userguide/gcp.html#create-and-assign-an-iam-role

 

3. Configure GCP Identity and Access Management (IAM) service account with sufficient access  and perform failover test again
