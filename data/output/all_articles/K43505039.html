Description

Following errors are noted when running the command  tmsh load sys config verify and configs are not loaded in the device.

01b90026:3: Bot defense profile (/Common/bot-defense) error: match-order should be unique.
Unexpected Error: Validating configuration process failed.

This issue occurs when performing the software upgrade from 15.1.x to 16.x or upgrade within same branch of 15.1.x.

Environment
  • BIG-IP ASM
  • Bot Defense Profiles
  • Software upgrade from 15.1.x to 16.x or upgrade within same branch of 15.1.x.
  • Configuration are not loaded after upgrade

Cause

Bug ID 994013

Recommended Actions

  1. SSH to log into the bash prompt of the BIG-IP device
  2. Perform the backup of bigip.conf 

    #cp bigip.conf bigip.conf_beforemodification
     
  3. Edit the /config/bigip.conf in text editor ( for example VI)

    01b90026:3: Bot defense profile (/Common/bot-defense) error: match-order should be unique.
    Unexpected Error: Validating configuration process failed.

    Note: In the above error we need to modify /Common/bot-defense profile to load the config successfully. It could be other profiles like 'bot-defense-device-id-generate-before-access' could cause the same error. Note the name of bot-defense profile for modification.
     
  4. For example in below bot-defense profile, delete the whitelist entries in the profile. After loading the config successfully, if they are default entries these whitelist entries will be auto-created. If these are custom whitelist entries, add the whitelist in bot-defense profile after loading the configuration.

    security bot-defense profile /Common/bot-defense {
        allow-browser-access enabled
        api-access-strict-mitigation disabled
        app-service none
        ...
         whitelist {           <===== delete the whitlelist entry. Start delete from here.
            apple_touch_1 {
                match-order 2
                source-address ::/32
                url /apple-touch-icon*.png
            }
            favicon_1 {
                match-order 1
                source-address ::/32
                url /favicon.ico
            }
        }                        <====== to here
    }
    ...
  5. Save the config and exit from text editor.
     
  6. Perform tmsh load sys config verify to ensure that there are no errors are reported again.
     
  7. If there are no errors, load the configuration using below command

      # tmsh load sys config

    Note: load sys config can cause traffic interruption. Perform in standby if the device is active-standby setup
     
  8. Once the configuration is loaded successfully, navigate to  Security ›› Bot Defense: Bot Defense Profiles ››Select bot-defense profile ›› Whitelist. Default entries in the whitelist which are deleted from step 4, will be created automatically after loading the config.
