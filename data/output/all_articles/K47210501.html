K47210501: BIG-IQ EC2 Instance deployed on AWS accessed using admin account

Type
Support Solution
Published
2020-12-31
Updated
2026-08-12
Status
Legacy Content
Applies to
  • Public Cloud
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K47210501

Description

  • BIG-IQ VE EC2 instance deployed in AWS market place requires admin credentials for SSH and Config Utility access

Environment

  • BIG-IQ VE
  • AWS/EC2
  • Putty or any other SSH client

Cause

  • Root account is disabled for BIG-IQ VE AMI SSH access
  • ID477524: Enable ssh for admin account and disable ssh for root account for Amazon deployments

Recommended Actions

  1. To access the EC2 BIG-IQ instance using SSH and the private key use the syntax below:

    ssh -i "example.pem" admin@ec2.example.compute.amazonaws.com

Additional Information

  • Connecting to deployed BIG-IQ VE instance on AWS includes root account in example syntax to SSH
  • This account is disabled and attempting to use root account to access instance after launch will fail
