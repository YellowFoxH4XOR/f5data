Description

BIG-IP ASM event logs are not received by BIG-IQ Centralized Management.

After performing packet capture in BIG-IQ DCD, it is noted that BIG-IQ Data Collection Device (DCD) is not responding to incoming TCP SYN packets on the logging port (such as 8514). Packet capture shows TCP SYN packets reaching the BIG-IQ DCD, but no TCP SYN-ACK responses are sent back to BIG-IP ASM device, even though the port appears to be listening.

Error messages such as  "io.netty.channel.unix.Errors$NativeIoException: readAddress(..) failed: Connection reset by peer"  may be observed in BIG-IQ Data Collection Device (DCD)

This is often caused by the logging service being enabled on a non-listener self IP address instead of the correct listener self IP for log ingestion.

Environment

  • Product: BIG-IP ASM, BIG-IQ Centralized Management, BIG-IQ Data Collection Device
  • Logging Configuration: BIG-IP ASM configured to send event logs to BIG-IQ DCD over port 8514
  • DCD with multiple self IP addresses (e.g., one for cluster operations, one as listener for logs)

Cause

Port 8514 was enabled on a non-listener self IP address of the DCD, preventing proper receipt of log traffic from BIG-IP ASM.

Recommended Actions

  • Disable port 8514 service on all non-listener self IP addresses of the affected DCD.
  • Wait for 5 minutes
  • Re-enable port 8514 specifically on the correct listener self IP address designated for receiving logs from BIG-IP ASM in BIG-IQ  Centralized Management
  • Verify connectivity by checking that event logs are received at BIG-IQ Centralized Management after making this change.
