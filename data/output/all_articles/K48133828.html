Known Issue

The RADIUS profile option is missing when you use the Configuration utility to create a UDP-based virtual server when only the BIG-IP LTM system is provisioned.

This issue occurs when all of the following conditions are met:

  • You create a UDP-based virtual server using the Configuration utility.
  • Neither BIG-IP PEM nor BIG-IP AFM are provisioned.

Impact

You cannot use the Configuration utility to assign a RADIUS profile to a virtual server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The RADIUS profile option is missing from the virtual server configuration page.

Workaround

To work around this issue, you can use the TMOS Shell (tmsh) to assign a RADIUS profile to a virtual server. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Assign the RADIUS profile to the virtual server using the following tmsh syntax:

    tmsh modify ltm virtual <virtual server name> profiles add { radius profile name }

    For example:

    tmsh modify ltm virtual udp-virtual profiles add { radiusLB }

  3. Save the changes by typing the following tmsh command:

    tmsh save sys config

  4. To display help regarding the tmsh ltm virtual command, type the following command:

    tmsh help ltm virtual
