Issue

In BIG-IP LTM versions prior to 10.0.0, it was possible to use the Tcl lindex command to access the elements of a data group list. Beginning in LTM 10.0.0, you must use the new iRules class command to access the elements of a data group list.

Note: Data group lists are also referred to as classes.

Note: For all of the commands in the examples below, the index is zero-based, meaning the first element of the class is element 0.

Prior to version 10.0.0, the following syntax extracts the class member at the specified index from the specified class:

lindex $::<classname> <index>

For example, the following command returns the first member of the class named images:

lindex $::images 0

In version 10.0.x, the following syntax extracts the class member at the specified index from the specified class:

class element -name <index> <classname>

For example, the following command returns the first member of the class named images:

class element -name 0 images

In version 10.1.0 and above, the format of classes was changed to support class members whose elements consist of name / value pairs. You can extract the name, the value, or the entire element consisting of the name / value pair.

The following syntax extracts the name of the class member at the specified index from the specified class:

class element -name <index> <classname>

For example, the following command returns the name of the first member of the class named images:

class element -name 0 images

The following syntax extracts the value of the class member at the specified index from the specified class:

class element -value <index> <classname>

For example, the following command returns the value of the first member of the class named images:

class element -value 0 images

Note: If no value has been assigned to the class member, a null string is returned. 

The following syntax extracts the name / value pair of the class member at the specified index from the specified class:

class element -element <index> <classname>

For example, the following command returns the name / value pair of the first member of the class named images:

class element -element 0 images

Note: If no value has been assigned to the class member, only the name of the class member is returned. 

For more information, refer to the DevCentral iRules wiki page for the class command.
