Known Issue

The BIG-IP 12250v platform may erroneously allow users to install BIG-IP 11.5.4, which is an unsupported software version for this platform.

Note: The current supported versions for the BIG-IP 12250v platform are 11.6.0 HF2 and 12.0.0. For additional updates, refer to K9476: The F5 hardware/software compatibility matrix.

Impact

Users cannot license the BIG-IP platform.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Software installation is successful; however, software license activation fails when the device runs on the unsupported software version.

Resolution

Status

F5 Product Development has assigned ID 588946 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

There is no workaround for this issue. To install the supported software version for your BIG-IP platform, refer to K9476: The F5 hardware/software compatibility matrix.
