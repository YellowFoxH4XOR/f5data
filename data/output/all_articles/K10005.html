Known Issue

This is the result of a known issue. A high volume of network traffic on the management network may cause a Switch Card Control Processor (SCCP) watchdog timeout event, leading the BIG-IP system to reboot. The following platforms contain the (SCCP):

  • BIG-IP 1500 (C36)
  • BIG-IP 3400 (C62)
  • BIG-IP 4100 (D46)
  • BIG-IP 6400 (D63)
  • BIG-IP 6800 (D68)
  • BIG-IP 8400 (D84)
  • BIG-IP 8800 (D88)

When this issue occurs an error message is logged to the /var/log/ltm file. The error message appears similar to the following example:

012a0004:4: *** SCCP Watchdog timer expired ***

F5 Product Development tracked this issue as ID 204541 (formerly CR110551) and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, or WebAccelerator release notes.

Workaround

For BIG-IP 9.4.6 through 10.0.1, you may be able to upgrade the SCCP software to version 12.0.8. However, there is currently an issue with SCCP version 12.0.8 that affects establishing outgoing connections. If your system is currently configured to establish outgoing connections on the management interface, it is important to evaluate SCCP version 12.0.8 before upgrading the SCCP to prevent any disruption in establishing outgoing management traffic. For more information, refer to K11146: The SCCP version 12.0.8 cannot establish outgoing connections.
