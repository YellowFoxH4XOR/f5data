Source

Description

Under some circumstances, sometimes it is necessary to restart daemons.

Environment

F5OS

Daemon restart


Cause

None. It works as designed.

Recommended Actions

In order to restart a daemon in F5OS, run either of these commands:

  • docker restart httpd

Or

  • systemctl restart httpd
