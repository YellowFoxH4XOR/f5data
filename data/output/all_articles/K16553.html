Known Issue

The Virtual Server page in the Configuration utility may stop responding when you view the list of virtual servers.

This issue occurs when all of the following conditions are met:

  • The Display Host Names When Possible setting is enabled.
  • The configured DNS servers return a ServFail response or are unreachable.

Impact

Users may be unable to perform administrative tasks from the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Configuration utility becomes slow and unresponsive.

Workaround

To work around this issue, you can disable the Display Host Names When Possible setting. To do so, perform the following procedure:

Impact of workaround: Host names will not be resolved or displayed in the Configuration utility.

  1. Log in to the Configuration utility as the admin user.
  2. Navigate to System > Preferences.
  3. Clear the Display Host Names When Possible check box.
  4. Click Update.
