Description

How to set Network Time Protocol (NTP) Authentication and what is the passphrase criteria for MD5 and SHA1?

Environment

  • BIG-IP or BIG-IQ
  • NTP

Cause

None

Recommended Actions

You cannot use the following characters in an ASCII key: " " (space), "#" (number sign), "," (comma).

Details of NTP key format and MD5 generation

Format of key file in NTP configuration (/etc/ntp/keys)

1   M      f294faO                                         # MD5 key
2   MD5    BtdW/<gj2*2M;!'~qAIN                            # MD5 key
3   SHA1   094c533b614d9e4bcb6e18a97a7b0e4d459025bd        # SHA1 key

  • The 1st column is the unique key ID number in the range 1 - 65535.
  • The 2nd column is the key type, which can be “M” or “MD5” for an MD5 key, or “SHA1” for an SHA1 key.
  • The 3rd column the key string.

Allowed characters for key

  • MD5 - 20-character printable ASCII string.
  • SHA1 - 40-character HEX string as the key itself.

NOTE: Passphrase and Type must match between BIG-IP and NTP Server.

NOTE: SHA2 and AES-128 CMAC is not currently supported

A 128-bit MD5 hash is computed over the key by the NTP packet header and extensions fields. NTP Packet header and extensions fields will contain alphabets,digits and some special characters like ‘.’.

Step to configure NTP Authentication

  1. Log in to the BIG-IP command line.
  2. Add key to /etc/ntp/keys with text editor, such as vi.

    NOTE: Key ID and password needs to match on remote NTP server

  3. Delete the current ntp server configuration using the following command:

    tmsh modify sys ntp servers none

  4. Confirm the change using the following command:

    tmsh list sys ntp

    The output should appear similar to the following example:

    sys ntp { }

  5. Edit the NTP configuration using the following command:

    tmsh edit sys ntp all-properties

    Replace the include none section with the following example syntax:

    modify ntp {
        description none
        include "server <ntp_server_ip> key <key_ID> iburst
        trustedkey <key_ID>"
        restrict none
        servers none
        timezone <your_time_zone>
    }

    Save and exit the editor by pressing [ESC], then typing :wq!

    Enter y at the following prompt

    save changes (y/n/e) y

  6. Confirm the changes using the following command:

    tmsh list sys ntp all-properties

    The output should appear similar to the following example:

    sys ntp {
        description none
        include "server <ntp_server_ip> key <key_ID> iburst
        trustedkey <key_ID>"
        restrict none
        servers none
        timezone America/Los_Angeles
    }

  7. Restart ntpd using the following command:

    tmsh restart sys service ntpd

  8. Check NTP status and confirm authentication is enabled, using the following command:

    ntpq -c as

    The output should appear similar to the following example:

    ind assid   status  conf  reach  auth  condition  last_event cnt
    =================================================================
      1 <assID> f424    yes   yes    ok    candidate  reachable  2

Additional Information

If you are adding more than one NTP server for authentication in Step 5, use the following format:

sys ntp {
    description none
    include "server <ntp_server_ip_1> key <key_ID_1> iburst
    trustedkey <key_ID_1>
    server <ntp_server_ip_2> key <key_ID_2> iburst
    trustedkey <key_ID_2>
    server <ntp_server_ip_3> key <key_ID_3> iburst
    trustedkey <key_ID_3>"
    restrict none
    servers none
    timezone America/Los_Angeles
}

This ensures each server and it's settings are on new lines in the "include" string. For more information, refer to K14120: Defining advanced NTP configurations on the BIG-IP system
