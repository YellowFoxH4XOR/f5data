Issue

Error Message

warning mcpd[<PID>]: 01071859:4: Warning generated : SSLv2 is no longer supported and has been removed. The 'sslv2' keyword in the cipher string of the ssl profile (/<partition>/<ssl_profile>) has been ignored.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <partition> is the partition and directory in which the SSL profile is located.
  • <ssl_profile> is the name of the SSL profile.

For example:

warning mcpd[8484]: 01071859:4: Warning generated : SSLv2 is no longer supported and has been removed. The 'sslv2' keyword in the cipher string of the ssl profile (/Common/sslv2_profile) has been ignored.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You configure an SSL profile in which SSLv2 keyword is specified in the Ciphers setting.
  • You attempt to save/reload the BIG-IP configuration or upgrade your system to BIG-IP 13.1.x.

Impact

There is no impact if the cipher string was build to exclude SSLv2 in the Ciphers setting such as !SSLv2, otherwise, client connections that rely on SSLv2 may fail unexpectedly.

Recommended Actions

The SSLv2 protocol is an obsolete version of SSL and the error message indicates that it has been ignored in the cipher string. To stop the message, review SSL profiles on the BIG-IP system and remove 'SSLv2' from the cipher string. For information about adjusting cipher string in the SSL profile, refer to K17370: Configuring the cipher strength for SSL profiles (12.x - 13.x).
