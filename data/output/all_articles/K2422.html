Topic

Higher number values for nodes indicate greater weight or priority for traffic load balancing.

The nodes with the highest priority setting are the only members that receive traffic from the virtual server. If the highest priority group falls below the Minimum Active Members number for a specific pool, the BIG-IP system load balances to the next highest priority group that is above its minimum.

For example, if you have Minimum Active Members for a pool set to 1 and there are three nodes in the pool (two that have a priority value of 5 and one with the default priority value of 1), the BIG-IP system load balances traffic across the servers with the higher weight of 5. The server with a weight of 1 will receive traffic only if both servers with the priority weight of 5 are down.
