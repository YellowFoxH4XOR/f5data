K24532424: HTTP/2 full proxy iRule local variable scope

Type
Support Solution
Published
2023-01-18
Updated
2023-06-14
Source
https://my.f5.com/manage/s/article/K24532424

Description

Local variables are not preserved across different HTTP/2 streams.

Environment

  • LTM
  • HTTP/2 full proxy (http/2 profiles on client-side and server-side)
  • iRule

Cause

In HTTP/2 full proxy setup, each HTTP/2 stream has it's own TCL context which means that each stream has its own set of variables. This is by design to avoid concurrent access to the same set of variables by different streams.

Recommended Actions

If necessary and table session variables can be used instead of local variables.
https://clouddocs.f5.com/api/irules/table.html

Table session variables are preserved across different HTTP/2 streams within the same TCP session.
