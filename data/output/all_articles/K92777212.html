K92777212: No GUI or SSH access after upgrade to version 8

Type
Support Solution
Published
2021-11-03
Updated
2026-01-09
Applies to
  • Virtual Editions
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.0.0
Source
https://my.f5.com/manage/s/article/K92777212

Description
After upgrading to BIG-IQ version 8, there is no access to the Configuration Utility or through SSH

Environment

  • BIG-IQ upgrade to version 8
  • No default management route configured

Cause
If no default management route is configured in the BIG-IQ, the system will no longer reply to the requests to the management interface.
This is because auto last hop does not work on the management interface in version 8.

Recommended Actions

  • Log in to the console of the Hypervisor and configure a default management route per K13284

Additional Information

K13284: Overview of management interface routing (11.x - 16.x)

K55225090: BIG-IP VE no longer supports Auto Last Hop for management connections
