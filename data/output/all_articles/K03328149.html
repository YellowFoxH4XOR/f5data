Description
Virtual server is dropping packets and tmm memory is increasing over time. Doing a failover momentarily fixes the issue. TMM memory usage resets

Environment

  • BIG-IP LTM
  • HSL is configured or a request-log profile
  • Failover (or rebooting) fixes the issue temporarily.
  • Memory graphs shows an steady increase of tmm memory usage over time
  • TMM will core when not enough memory is available

Cause

 Bug ID 668048
 

Recommended Actions

  1. Perform an upgrade to a fixed version as documented in the provided BUG article
