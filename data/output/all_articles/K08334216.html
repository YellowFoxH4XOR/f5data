K08334216: "Accept" button gets stuck when applying an ASM policy.

Type
Support Solution
Published
2021-05-27
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 13.X.X, 13.1.X, 13.0.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.0, 13.0.1, 13.0.0
Source
https://my.f5.com/manage/s/article/K08334216

Description

On Security >> Event logs >>  Application Request >> Request, when clicking on the Apply policy button, the changes are not applied and it just spins.

Environment

  • BIG-IP ASM
  • Apply Policy

Cause

Corrupted iControl REST task.

Recommended Actions

Run the following command:

DELETE https://<BIGIP>/mgmt/tm/asm/tasks/apply-policy?$filter=status eq NEW

Additional Information

None.
