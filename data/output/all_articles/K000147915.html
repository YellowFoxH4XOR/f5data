K000147915: Do I need to switch my DNS service entirely to F5 Distributed Cloud in order to use the DNS Load Balancer?

Type

Published
2024-11-08
Updated
2024-11-08
Applies to

  • F5 Distributed Cloud DNS Load Balancer
Source

Environment

  • F5 Distributed Cloud DNS Load Balancer

Answer

No, you don't necessarily have to.

  • You can do it if you want the whole DNS zone to be managed through F5 Distributed Cloud
  • Otherwise, you can continue to manage DNS through your current provider and:
    • delegate a subdomain for which F5 Cloud Services will issue responses.
    • you would then create CNAME records on the primary DNS nameserver for any FQDNs you want to load balance, pointing to A records in the delegated subdomain.
    • the process is more or less the same as with F5’s self-hosted product, BIG-IP DNS, and more instructions can be found here: https://support.f5.com/csp/article/K277
