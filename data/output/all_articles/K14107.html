  • The Network Settings chapter of the F5 rSeries Systems: Administration and Configuration manual
  • The Network Settings chapter of the VELOS Systems: Administration and Configuration manual

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching MyF5 and finding product documentation.

You should consider using this procedure under the following condition:

  • You are having interoperability issues with link-speed auto-negotiation on Ethernet devices connected to the BIG-IP system.

By default, the BIG-IP interfaces are configured to auto-negotiate the media settings. Ethernet devices which do not implement auto-negotiation in the same way may cause issues when attempting to negotiate the correct media settings.

To avoid this issue, you can manually configure the media settings for all interfaces.

Important: Fiber and copper gigabit interfaces use a different auto-negotiation mechanism and should be left at the auto setting.

Media speed setting options

You can configure the media speed setting on BIG-IP systems equipped with 10Mbps, 100Mbps, 10/100Mbps, 1000Mbps, 12000Mbps, 16000Mbps, 20000Mbps, and 40000Mbps interfaces to one of the following options:

  • 10baseT
  • 100baseTX
  • 1000baseT
  • 1000baseSX
  • 1000baseLX
  • 1000baseCX
  • 10GbaseT
  • 10GbaseSR
  • 10GbaseLR
  • 10GbaseER
  • 10GbaseSFPCU
  • 12G
  • 16G
  • 20G
  • 40G
  • 40GbaseLR4
  • 40GbaseSR4
  • auto
  • no-phy
  • none

Duplex setting options

The options for the duplex setting for BIG-IP systems equipped with 100Base-TX interfaces are full and half.

Prerequisites

You must meet one of the following prerequisites to use this procedure:

  • You have access to the management port of the BIG-IP system.
  • You have access to the console port of the BIG-IP system.

Procedures

Viewing the existing media settings

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  2. View the existing media settings for an interface by using the following command syntax:

    list net interface <interface> media-active

    For example:

    list net interface 1.1 media-active

    net interface 1.1 {
    media-active 1000T-FD
    }

If the output matches your desired media settings, you do not need to manually configure the media settings.

Manually configuring the media settings

Important: F5 recommends that you connect to the management or console port when you make any changes to the media setting.

To manually configure the media settings for an interface, perform the following procedure:

Impact of procedure: If you make an error while changing this setting, it is possible that you will interrupt service to the affected interface.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To set media speed and duplex settings for the interface, use the following command syntax:

    Note: You can list examples of different interface speeds available by entering the TAB character after entering modify net interface <interface> media on tmsh .

    modify net interface <interface> media <speed-duplex>

    For example:

    modify net interface 1.1 media 1000T-FD

  3. Confirm that the system is working properly with the new settings.
  4. Save the change by entering the following command:

    save /sys config

The system is now configured to use the new media speed and duplex settings upon boot up.
