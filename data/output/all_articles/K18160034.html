K18160034: BIG-IP DNS response policy zone blocks a domain even though RR for this FQDN is not created

Type
Support Solution
Published
2022-02-23
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • VIPRION Platforms
  • BIG-IP
  • BIG-IP DNS: 15.1.5
  • BIG-IP GTM
Source
https://my.f5.com/manage/s/article/K18160034

Description

The BIG-IP DNS response policy zone feature matches the DNS request even if a Resource Record for such FQDN is not created.

Environment

  • BIG-IP DNS
  • RPZ (response policy zone) configured
  • NXDOMAIN or Walled Garden domain returned

Cause

A Resource Record for the wildcard domain was created.

Recommended Actions

Verify the zone configuration in order to eliminate the potential wildcard domain match. Check if there are any wildcard resource records like *.org | *.com | *.gov etc. that could match your FQDN.

Additional Information

None.
