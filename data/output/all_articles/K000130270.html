K000130270: Limiting data of F5Telemetry_system_CL table BIG-IP sends Azure Log Analytics

Type
Support Solution
Published
2022-12-19
Updated
2022-12-19
Source
https://my.f5.com/manage/s/article/K000130270

Description

The article shows an example of how to exclude data from the F5Telemetry_system_CL table that BIG-IP sends via Telemetry Streaming to Azure Log Analytics.

 

Test Telemetry declaration:

 

{

  "class":"Telemetry",

  "My_System":{

   "class":"Telemetry_System",

   "systemPoller":{

     "interval":60,

     "actions":[

      {

        "excludeData":{},

        "locations":{

         "system":{

           "provisioning":true,

           "diskStorage":true,

           "diskLatency":true

         }

        }

      }

     ]

   }

  },

  "My_Listener":{

   "class":"Telemetry_Listener",

   "port":6514

  },

  "My_Consumer":{

   "class":"Telemetry_Consumer",

   "trace":true,

   "type":"Generic_HTTP",

   "host":"xx.xx.xx.xx",

   "protocol":"http",

   "port":80,

   "path":"/",

   "method":"POST"

  }

}

 

With trace=true under My_Consumer, debug trace file is created under /var/tmp/telemetry on the BIG-IP:

Telemetry_Consumer.f5telemetry_default::My_Consumer

 

This is to show what logs will be sent to the Consumer.

 

After POST'ing the above declaration, the "system" data is being logged in the output file, but is shortly overwritten. 

ref: https://clouddocs.f5.com/products/extensions/f5-telemetry-streaming/latest/output-example.html#system-information to see all output associated with "system"

 

Environment

  • Telemetry Streaming
  • Azure Log Analytics

Cause

BIG-IP sends this data by default. It needs to be excluded in the Telemetry Streaming declaration.

 

 Recommended Actions

Add the following to "actions", as this is part of the documentation examples when doing Data Modifications. 
 

          "setTag": {

             "tenant": "`T`",

             "application": "`A`"

           },
 

After POST'ing the updated declaration, the trace debug log file continuously contains the "system" output. You can verify that the expected excluded data is not being sent to the Consumer.

 

Additional Information

Documentation of exclude option: https://clouddocs.f5.com/products/extensions/f5-telemetry-streaming/1.20/data-modification.html#using-the-excludedata-property
