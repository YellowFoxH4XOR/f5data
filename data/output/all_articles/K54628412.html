Description

Observing error when attempting to load configuration after upgrade, or when trying to create a virtual server for QUIC, for example by following K60235402.

[root@ltm1-bigip:Active:Standalone] config # tmsh create ltm virtual quic_vs ip-protocol udp destination 10.10.10.10:4433 source-address-translation {type automap} profiles add { udp { context clientside } tcp { context serverside } clientssl-quic { context clientside } serverssl {context serverside } quic { context clientside } http3 { context clientside } http httprouter }

01070734:3: Configuration error: A virtual server (/Common/quic_vs) is not allowed to have TCP, UDP and HTTP together with Client or Server SSL Profiles.

This configuration should be valid.

Environment

  • 14.1.4.6, 15.1.5, 16.1.2.2 or 16.1.3

Cause

ID1080581

Recommended Actions

Upgrade to a fixed version.

ID1080581 is not fixed in 16.1.x at the time of this article's publication, but an engineering hotfix is available.
