To reconfigure the BIG-IP Controller, type the version-specific command from the command line.

BIG-IP and 3-DNS versions 4.2 - 4.6.4

To reconfigure the BIG-IP using the Setup utility, perform the following steps:

  1. Type the following command:

    config

  2. Choose option A.
  3. Modify the configuration information as desired.

BIG-IP versions 2.0.1 - 4.1.1 PTF-06 and 3-DNS versions 4.0 - 4.1.1 PTF-06

To reconfigure the BIG-IP using the First-Time Boot utility, perform the following steps:

  1. Type the following command:

    config

    This initates the First-Time Boot utility.

  2. Modify the configuration information as desired.
