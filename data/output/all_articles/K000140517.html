Description

After deploying a OTEL-collector container, excessive logging is observed by the container.

Environment

F5 SPK

  • Version 1.7.x, 1.8.x
  • Version 1.9.0, 1.9.1, 1.9.2, 1.9.3
  • Default logging level configured for OTEL-collector container

Cause

The OTEL-collector container has debug logging enabled by default.

Bug ID1619845 has been opened to change the default logging level to 'info'.

Recommended Actions

To work around this issue, under the 'otel-collector-conf' section of the 'f5-ingress-otel-collector-config.yaml' file, change the logging level to a level other than debug.

Example setting the logging level to 'info':

otel-collector-conf: |
...
   logging:
    loglevel: info
