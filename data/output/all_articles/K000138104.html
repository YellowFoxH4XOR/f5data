Description

During software image installation, there's no drop down on "Volume set name". After typing "HD1.3" in "Type or select a name" textbox, it prompts the following error message:

Unable to install image to volume “HD1.3”, containing invalid characters.


Figure: Example of invalid characters on volume set name

Environment

  • GUI
  • Upgrade
  • Volume

Cause

Only single boot location available. Volume set name needs to be in any combination of 32 lowercase alphanumeric characters and hyphen. 

Recommended Actions

  • Volume names can only include lower case letters, numbers, or hyphens. Example: new, 123, or -
  • To install in HD1.3, you need to type "3" on the volume set name. Example below:


Figure: Example of valid characters on volume set name
