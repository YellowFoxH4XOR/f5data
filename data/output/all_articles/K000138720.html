K000138720: Failed Upgrade from 15.1.x to 17.1.x

Support Solution

Source

Description

After upgrading from 15.1.x to 17.1.x the configuration fails to load with error: dont-insert-empty-fragments conflicts with Proxy SSL (both cannot be enabled) in profile /Common/<profile_name>

 

Environment

SSL profiles

Upgrade

Cause

15.1.x does not validate SSL profile features dont-insert-empty-fragments setting and proxy ssl being enabled together.

Recommended Actions

Ensure SSL profiles do not have dont-insert-empty-fragments and proxy ssl features enabled at the same time prior to the upgrade. Disabling the 'Don't insert empty fragments' option when Proxy SSL is enabled guards against a particular type of cryptographic attack.
