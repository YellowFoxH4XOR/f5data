Description
vCMP guest configuration parameters is present in the vCMP host's configuration, not in the vCMP guest's configuration. Without access to the vCMP host it is still possible to determine the number of CPU cores assigned to the vCMP guest.

Environment

  • vCMP provisioned
  • Access to vCMP guest but not vCMP host

Cause
N/A

Recommended Actions

The information can be gathered via TMSH or from a QKView.
  1. If there is access to the vCMP guest command line
    1. issue the below read-only command:
      tmsh show sys hardware
      Output Examples:
        Name        cpus
        Type        base-board
        Model       Intel(R) Xeon(R) CPU E3-1230 V2 @ 3.30GHz
        Parameters  --                --
                    cache size        4096 KB
                    cores             2  (physical:1) 
                    cpu MHz           3300.020
                    cpu sockets       1
                    cpu stepping      9

        Name        cpus
        Type        base-board
        Model       Intel(R) Xeon(R) CPU E3-1230 V2 @ 3.30GHz
        Parameters  --                --
                    cache size        4096 KB
                    cores             4  (physical:2)
                    cpu MHz           3300.020
                    cpu sockets       1
                    cpu stepping      9
    2. Review the "cores" line of the output
      In the first example there were 2 cores, corresponding with the 2 cores provisioned for the vCMP guest. In the second example there were 4 cores, corresponding to the 4 provisioned for it.
  2. If there is access to a QKView
    1. Upload the QKView to iHealth
    2. On the Status page go to the System section
    3. In the System section locate the CPU Totals line
      Output Examples:
      CPU Totals1 Blade(s) / 1 CPU(s) / 2 Cores

      CPU Totals1 Blade(s) / 1 CPU(s) / 4 Cores

      In the first example there are 2 cores, corresponding with the 2 cores provisioned for the vCMP guest while in the second example there are 4 cores as the second was provisioned with 4 cores.
