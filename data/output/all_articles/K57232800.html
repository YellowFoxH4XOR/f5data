Known Issue

The BIG-IP system may leak memory. This issue occurs when all of the following conditions are met:

  • A Secure Sockets Layer (SSL) profile is configured but not directly associated with a virtual server.
  • The SSL profile is dynamically selected by the SSL::profile command in an iRule associated with a virtual server.

Impact

Due to excessive memory usage, the tmm process may produce a core dump. As a result, the BIG-IP system may temporarily fail to process traffic and fail over if configured as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H576060 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP system generates a Traffic Management Microkernel (TMM) core file to the /shared/core directory.
  • The BIG-IP system fails over to the standby system if configured as part of a high-availability system.
  • The memory usage of the ssl (variable) subsystem increases over time. To determine the memory usage of the ssl (variable) subsystem, you can use the tmsh show sys memory | grep -i "ssl (variable)" command. Command output should appear similar to the following example:

    ssl (variable) 900.1M 901.1M 1
