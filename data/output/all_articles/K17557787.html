K17557787: When renewing or assigning a new SSL certificate to an SSL profile existing connections use the old certificate

Type
Support Solution
Published
2023-05-22
Updated
2023-05-22
Source
https://my.f5.com/manage/s/article/K17557787

Description

When you renew an SSL certificate, or assign a new SSL certificate to an SSL profile the existing connections will not be affected.  They will continue their duration uninterrupted by the changes being made.  New connections will begin to use the SSL certificate which you have updated or assigned.

Environment

BIG-IP

Cause

When changes are made to most BIG-IP configuration object options, the new parameters or options defined by the configuration change only apply to new connections that are established to the BIG-IP system after the change is made. Existing connections continues to use the configuration options that were defined at the time the connection was established.

Recommended Actions

Close the client browser connecting to the virtual server and reconnect.

Alternatively you can delete the connection via tmsh using instructions in K53851362: Displaying and deleting BIG-IP connection table entries from the command line.

None
