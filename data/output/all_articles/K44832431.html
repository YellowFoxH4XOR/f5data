Description

Getting certificate revoked error when accessing virtual server in all browsers. The similar works in mobile browsers. 
For e.g. error received in chrome is below 

Your connection is not private
NET::ERR_CERT_REVOKED
 
If TCPDUMP is taken, SSL handshake fails with client sending below alert to virtual server:
Alert (Level: Fatal, Description: Certificate Unknown)

Environment

  • BIG-IP
  • Virtual server with Clientssl profile 
  • Successful connection when testing with Openssl and curl commands. 
  • Certificate is correctly installed and browser shows correct certificate. 

Cause

One of the causes for the error presented is that the certificate being used in the ssl profile for that virtual server has been revoked. This would appear to be part of the Microsoft and Mozilla graduated distrust of Symantec roots, discussed by the Qualys team here: https://blog.qualys.com/ssllabs/2017/09/26/google-and-mozilla-deprecating-existing-symantec-certificates
This is due to the revocation/distrust of the Symantec signed certificate and will probably need to be replaced by a different certificate signed by a different CA.
Note: This link takes you to a resource outside of AskF5, and the third party could remove the document without our knowledge.

Recommended Actions

After verifying all the above conditions & environment, you can take below action: 

  1. Contact your SSL/TLS certificate provider and know what’s the cause behind it (Only if you haven’t requested certificate revocation).
  2. Buy a new SSL/TLS certificate and install it onto your website.
