Description

You may encounter the following error when executing a playbook that uses F5's ansible module reboot command after upgrading to v14.1.x and later.

Ansible playbook example:
---
  tasks:
    - name: reboot
      bigip_command:
        commands: reboot
        provider:
          server: 
          password: 
          user: 
          validate_certs: no
      register: result

    - name: display result
      debug:
       msg: "{{ result }}"
---

Error message example:
An exception occurred during task execution. To see the full traceback, use -vvv. The error was: Exception urllib2.URLError: URLError
 

Environment

  • BIG-IP version 14.1.x or later
  • Ansible bigip_command: reboot exists in playbook

Cause

This is because of change in behavior of BIG-IP reboot command.
BIG-IP will not accept subsequent command after reboot in v14.1.x and later.

Prior to 14.1
#  ls -larht /sbin/reboot
-rwxr-xr-x. 1 root root 15K 2019-08-02 20:31 /sbin/reboot

In v14.1.x and later, reboot script is symbolic link of /bin/systemctl
# ls -larht /sbin/reboot
lrwxrwxrwx. 1 root root 16 Jan  5 19:21 /sbin/reboot -> ../bin/systemctl

Recommended Actions

You can ignore the error message because reboot command is executed successfully.
