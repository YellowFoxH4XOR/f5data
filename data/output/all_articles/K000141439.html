Description

The HA self ip and management ip are both configured for the HA network failover, but when the HA self ip disconnected somehow, the HA became to active/active mode. Looks like it's the network failover on management port didn't work.

Checking the mgmt ip for active and standby devices, you found they were in different subnets, and only default route configured on management port.

Environment

  • BIG-IP HA
  • Different subnet for mgmt
  • Only default route on mgmt
  • Default route on TMM

Cause

As the mgmt ip for A/S were in different subnets, and there was only default route on management port, the system proceeded the heartbeat packets on management level through the TMM default route.

Recommended Actions

Configure the specific routes for peer ip on management interface.

Additional Information

When the destination address does not match the management interface subnet, the system uses the default gateway of TMM unless there is a more specific route configured on the management interface. When there is no default route specified in TMM, the system uses the default route specified for the management interface.
