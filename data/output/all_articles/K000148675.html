Description

You need to configure DNS name resolution for ASM/F5 WAF related objects like Bot defense protections

 

Symptoms

Without the "." forwarding zone configured in the default DNS resolver "f5-aws-dns" certain features may not work.

 

Environment

BIG-IP ASM

F5 WAF for BIG-IP

 

Cause

DNS resolution is required for Bot defense protections and other features in ASM/F5 WAF to function as designed.

 

Recommended Actions

Add "." forwarding zone to the default DNS resolver "f5-aws-dns" in the Network tab. This has to be configured in the default DNS resolver "f5-aws-dns". When configuring the forwarding zone the quotations need to be left out of the name ".". See below screenshots.
