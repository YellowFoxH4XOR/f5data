Known Issue

Flow-based statistics in the Configuration utility and BIG-IP PEM format script do not match.

This issue occurs when the following condition is met:

  • Your system uses flow statistics reporting for a BIG-IP PEM session, enabled with the PEM format script.

In BIG-IP PEM 11.6.0, new fields were added; however, the new fields were not incorporated in the PEM format script for reporting.

For session attributes, the following new fields were added in BIG-IP 11.6.0:

  • last-sent-msec
  • report-id
  • report-version
  • timestamp-msec

For flow attributes, the following new fields were added in BIG-IP 11.6.0:

  • flow-start-milli-seconds
  • flow-end-milli-seconds
  • report-id
  • route-domain
  • report-version
  • timestamp-msec
  • vlan-id

Impact

The BIG-IP PEM session report, which uses the format script, may report flow statistics discrepancies or misinterpret the collected statistics.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Several fields are missed in the BIG-IP PEM format script reporting.
  • Several fields in the format script incorrectly use microseconds, instead of the expected milliseconds.
