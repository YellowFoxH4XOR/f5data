K000147850: How do I prompt a JavaScript challenge or a Captcha to specific requests (source IPs, countries, ASNs…)?

Applies to

Source

Description

I want the load-balancer to return a JavaScript challenge or a Captcha only to requests coming from specific countries, IPs, ASNs or many other criteria. Respectively, I can use the same method if I want to prompt a challenge to all of the requests coming to a load-balancer unless they come from specific countries, IPs, ASNs (so that legitimate bots are not blocked by a challenge, for example).

 

Environment

  • Service Policies
  • F5® Distributed Cloud Console

Cause

None

Answer/Recommended Actions

If you want to prompt a Javascript challenge or a Captcha to only specific requests (and not to all of them) you have to define a Policy Based Challenge. This will require you to:
  • define the default behavior of the load-balancer (for example, not prompting a challenge)
  • define exceptions to this default behavior (for example, return a challenge to requests from a specific country)

Process

To prompt a JavaScript challenge or a Captcha to specific requests:

  1. Go under the configuration of the selected Load Balancer > Common Security Controls > Malicious User Mitigation And Challenges > Policy Based Challenge.
    1. Don't forget to switch the Show Advanced Fields button to on)
  2. In the Policy Based Challenge configuration form, choose the default behavior using the Challenge type option.
  3. In the Rules menu, create one rule for each exception you need to this default behavior. For each one of them:
    1. set an action (choose which challenge needs to be returned)
    2. add at least one parameter to identify the client (source IP, ASN…) or the request (specific domain, header, HTTP method or path)
  4. Save your changes.

Additional Information

To add exception for below marked options: 

You need to use "Policy Based Challenge" and set up desired policy and exceptions. That's the only way to add exceptions.
If you enable "JavaScript Challenge" or "Captcha Challenge", there is no way to add an exception. All clients will receive challenges.

Trusted client rules (e.g. Skip Malicious User) or service policy exceptions (e.g. Malicious User Mitigation Action: Skip Processing) will not change anything and clients with such exceptions will still receive challenge.
