Description
Azure Backup Agent in BIG-IQ Virtual Edition (VE) is supported. However, you may see a false error message in Azure backup environment that reads:

Unsupported Operating System for backup

Environment

  • BIG-IQ VE installed in Azure environment
  • Azure Backup Agent

Cause

Cause of the Azure error message is unknown at this time

Recommended Actions
1. Verify waagent and python are present and running:

 # ps aux | grep waagent

2. Ignore the error message in Azure, and try the backup process again

Additional Information

  • To see what tmsh version BIG-IQ is running on, use the following command:
    # tmsh -v
     
  • To find the version of the waagent installed on BIG-IQ:
    K55345119: Support of Microsoft waagent versions on BIG-IP VE in Azure cloud
