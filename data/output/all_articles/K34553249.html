ClientSideNetworkLatencyMetric (Milliseconds)Total "Client Side Network Latency" of all transactions. The Network latency is the round-trip-time of a packet between two machine, it can also be viewed at the ping time.
This information is derived from the TCP connection handshaking.
ClientTtfbMetric (Milliseconds)Total "Time to First Byte" of all transactions. Time to First Byte stands for the time it took from the moment a client started to send the request till it got the first byte of response.
ClientTtfbHitcountMetric (Transaction Count)Number of counted HTTP transactions, that have relevant information for Time to First Byte (At least one packet of response reached the client)

errdefs_msgnoUnique Message IdentifierHas a constant value of "22282245" for this message type
globalBigiqConfTextual Dimension, special formatAVR will read the configuration from a file that BigIQ will create on the BigIP under /var/config/rest/downloads/app_mapping.json

Related to global devices
HitCountMetric (Transaction Count)Number of counted HTTP transactions
HostnameTextual DimensionName of the BIG-IP
IsAttackingIpBoolean DimensionValues can be 0 or 1.
Tells whether DoS mechanism suspects this client-ip to be part of a DDoS attack.
IsInternalActivityBoolean DimensionValues can be 0 or 1.
Internal activity means a transaction that was generated by JS that was injected by BIG-IP.
It is useful in differentiating between traffic that the client asked to perform, vs traffic that was generated by BIG-IP own tools.
LatencyHistogramMetric, special formatThis is a histogram of transaction hitcount per various values of server latency.
The information of this field consists of 2 arrays of information. The first one is a list of server latency ranges. The second one is a list of transaction hitcount, per each range in the first array. The character "|" is a delimiter between the first and second array.
For example:
"0,2,4,7,12,22,40,74,136,252,465,858,1585,
2929,5412,10001,300000|116,3,0,0,0,0,5,0,
0,0,0,0,0,0,0,1"
This means that there were 116 transactions in the range of 0-2 milliseconds (for server latency)

ResponseDurationMetric (Milliseconds)Total "Response Duration" of all transactions. A response duration stands for the amount of time it took to send the entire response payload, it is 0 in case that the entire response consists of only 1 packet, but in case there are multiple packets then it tells the amount of time passed from the first packet to the last packet.
