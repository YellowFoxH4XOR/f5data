Known Issue

The Traffic Management Microkernel (TMM) may restart when a load balancing failure occurs.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system receives a new connection request and attempts to select a pool member.
  • All pool members are unresponsive. This may be due to one of the following reasons:
    • The pool members have reached their configured connection limit.
    • There is no route to the pool members.

Impact

Traffic processing is interrupted while TMM restarts, and a failover event occurs if the BIG-IP system is in a high-availability (HA) configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to process traffic for a brief period.
  • The BIG-IP system fails over to another system in the device group.
  • TMM produces a core file in the /var/core directory.
