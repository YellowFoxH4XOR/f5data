Description

When creating a virtual server that has a wildcard source or a wildcard destination address and sharing a port-list with another virtual server, and when we try to attach the port-list to both virtual servers, it fails with an error similar to the following:

01b90011:3: Virtual Server /Common/vs2 Traffic Matching Criteria /Common/vs2_TMC_OBJ illegally shares destination address, source address, service port, and ip-protocol with Virtual Server /Common/vs1 destination address, source address, service port.

Example to trigger the error:

1st VS: Destination: 1.1.1.1, source: 0.0.0.0/0 > Port-list 1
2nd VS: Destination 0.0.0.0/0, source: 2.2.2.2 > Port list 1
 

Environment

  • Port lists are used. 
  • The first virtual server uses a wildcard source or destination address, for example, 0.0.0.0/0.

Cause

Bug ID 1133881

 Recommended Actions

Upgrade to version 17.1.0 or 15.1.9

Additional Information

None.
