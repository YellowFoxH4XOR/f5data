K000138013: AS3 patch declaration changes other virtual servers configuration

Type
Support Solution
Published
2023-12-22
Updated
2023-12-28
Source
https://my.f5.com/manage/s/article/K000138013

Description

Manual changes done on a BIG-IP device are rewritten after an AS3 declaration submitted via BIG-IQ


Environment

  1. AS3 declaration is deployed from BIG-IQ which contains a configuration for several VS
  2. A manual change on the BIG-IP is then done to one of the deployed VS
  3. A subsequent declaration patching to another VS is then pushed from the BIG-IQ
  4. The manual change will be rewritten even though the patching concerned a totally separate VS


Cause

Working as designed.


Once the declaration is patched the entire declaration is then pushed to the end device rewriting all manual changes done to original declaration objects.


Recommended Actions

When configuration is deployed via BIG-IQ no manual changes should be done directly on the device.
