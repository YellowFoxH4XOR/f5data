K000139730: How to configure security policy on BIG-IP Next WAF using BIG-IP Next Central Manager to hide sensitive data of a Parameter.

Published

Description

 

BIG-IP Next WAF stores incoming requests in plain text format. Some requests may have sensitive data in parameters, such as an account number, passwords, etc, that you want to hide from system users. You can create a sensitive parameters  or modify an existing parameter to sensitive by following the steps as described in the Recommended Actions. When you create sensitive parameters, or make existing parameter sensitive, the system replaces the sensitive data, in the stored request and in logs, with asterisks (***).

 

 

Environment

 

  • BIG-IP Next WAF
  • BIG-IP Next Central Manager
  • Ver 20.1.1
  • You already know the sensitive parameter, data of which is getting logged in plain text
  • Parameter is already configured in the policy

 

 

Cause

 

Sensitive information getting logged in logs.

 

 

Recommended Actions

 

 

  1. Login to the GUI of BIG-IP Next Central Manager
  2. Under Manage Security Policies, click on “Go to security workspace”.
  3. Select “Policies” under WAF and select the policy for which you would like to change the parameter to sensitive parameter.
  4. Once you select the policy, scroll down and look for “Parameters” under Application Elements.
  5. Click on the name of the parameter for which you would like its data to be logged with asterisks (***) instead of plain text.
  6. Under Parameters Properties, scroll down and enable “Mask Value in Logs”.
  7. Once done, click save and then Deploy the policy.
