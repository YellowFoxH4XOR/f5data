Description

Always Connected Mode refers to an installation option of BIG-IP Edge Client that allows an Administrator to define the connection behaviour of the Edge Client. This functionality is implemented through the use of the F5 Networks Traffic Control Service and the F5 Networks Stonewall service.

Environment

  • APM
  • Always Connected Mode
  • Stonewall service logs

Cause

BIGIP APM Administrator may want to review the logs related to Stonewall service during troubleshooting activities.

Recommended Actions

  1. On Windows OS machine, go to C:\Windows\Temp\ folder and locate 'logterminal.txt' file.

None
