Description

After upgrade, a red color "Expired Certificate Alert" status showing on the top left corner of the WebUI. 

Environment

  • After upgrading to 15.1.0 or later
  • If there is any expired certificate is in use

Cause

Behavior change tracked in  ID707276

Recommended Actions

This is a new feature in BIG-IP starting version 15.1.0. Although this behavior has no functional impact, you may need to check the certificate that has already expired and if it is being referenced in a client SSL profile configured on a virtual server: 

  1.  Click the "Expired Certificate Alert" status
  2.  It takes the user to "System  >> Certificate Management : Traffic Certificate Management : SSL Certificate List" page to show all in use expired certificates. 

Additional Information

If this warning is not desired it may be disabled with:

  1. Log in to tmsh by typing the following command:
    # tmsh
  2. Run the command below to disable GUI expired cert alert:
    # modify sys global-settings gui-expired-cert-alert disabled

  3. Save your changes by typing the following command:

    # save /sys config
