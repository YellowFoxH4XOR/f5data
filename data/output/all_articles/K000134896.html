Description

After performing BIG-IP upgrade via BIG-IQ and running Comparison Assessment task user is unable to view Pool Member and Pool status when changes are detected.



Console error in Dev tools of browser:


Error: Token Not Found: ~RD-1-TEST~test1-lab-f5-dev-server1.dev.f5.local_80_pool/RD-1-TEST/10_1_1_1:8080.state

Environment

  • BIG-IQ CM
  • Upgrade BIG-IP via BIG-IQ
  • Performed Comparison Assessment is hanging on view Pool Member and Pool status

Cause

Unique Pool contains . (dot) in name

ID1297333

Recommended Actions

Reconfigure BIG-IQ to replace .(dot) with _(underscore) in Unique Pool name


Step#1: Remount the usr folder in the server


mount -o remount, rw /usr


Step#2: Move to js file location


cd /usr/local/www/ui/js/


Step#3: Take a backup of app.js file


cp app.js app.orig.js


Step#4: Open the app.js file in VI editor


vi app.js


Step#5: Search for object.pool and append replace ( .replace(/\./g, "_")) function to object.pool


Esc + / object.pool


Step#6: Replace the existing code with the new code and save the app.js file (using Esc +:wq!).


Existing Code: return"tm:ltm:pool:members:membersstate"==object.kind?object.pool+full_path:full_path


New Code: return"tm:ltm:pool:members:membersstate"==object.kind?object.pool.replace(/\./g, "_")+full_path:full_path


Step#7: Gzip the app.js file


gzip -c app.js > app.js.gz


Step#8: Mount the usr folder in the server


mount -o remount, ro /usr


Note: Change does not preserve upgrades of BIG-IQ
