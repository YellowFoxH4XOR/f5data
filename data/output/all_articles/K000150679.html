K000150679: Edge Client fails to establish VPN connection when using Edge as the default Browser for authentication

Type
Support Solution
Published
2025-04-02
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP APM: 16.0.0, 16.1.0, 16.0.1, 16.1.X, 16.0.X, 17.1.X, 17.0.X, 17.1.2, 17.1.1, 17.1.0, 17.0.0, 16.1.5, 16.1.4, 16.1.3, 16.1.2, 16.1.1
Source
https://my.f5.com/manage/s/article/K000150679

Description

When the Windows client is set to use Edge as the default browser and BIG-IP Edge Client is configured to use the default browser for authentication, an issue occurs, causing the Edge Client to connect to the VPN. During authentication, the browser remains stuck on "Connecting to server," while the Edge Client stays on "Authenticating in browser."
While establishing the connection, you observed that "IE" appears in the Edge browser's address bar, indicating the browser is running in Internet Explorer mode.

Environment

  • BIG-IP APM
  • Edge Client
  • SSL-VPN
  • Windows
  • Edge Browser

Cause

APM Virtual Server is listed in the Internet Explorer mode site list.

Recommended Actions

  • Remove the APM Virtual Server from the IE mode site list to ensure it opens in standard Edge mode.
  • Alternatively, set a different browser, such as Chrome, as the default browser on the Windows client to bypass IE mode.
