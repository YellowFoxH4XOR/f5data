Description

Virtual servers didn't work properly with Automap and SNAT POOL assigned.
SYN Retransmission seen on server side of the connection.
No response to SYN transmissions.

Environment

  • BIG-IP LTM
  • Virtual Server With SNAT Pool configured
  • Floating Self-IP not configured for all VLANS
  • Pool members not in directly connected network reachable thought different VLAN than address of SNAT pool or Floating Self-IP
  • SNAT Pool from range of one directly connected network

Cause

Possible Asymmetric Routing issue, Return back traffic from backend servers is not sent via the same route as requests were coming

Recommended Actions

  • Add additional SNAT POOL which will resides in VLAN, which is used as a outbound interface to backend server

    or
     
  • Configure Floating Self-IP for each VLAN and use SNAT Automap in virtual server configuration

Additional Information

None
