K000149811: Attack Signature Update Fails with Timeouts Errors

Type
Support Solution
Published
2025-02-14
Updated
2025-02-14
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.0.X, 17.1.0, 17.1.1, 16.0.X, 16.1.0, 16.1.1, 16.1.2, 16.1.3, 16.1.4, 15.0.X, 17.0.0, 16.0.1, 16.0.0, 15.0.1, 15.0.0
Source
https://my.f5.com/manage/s/article/K000149811

Description

Attack signature updates may time out, and the Apply Policy button can get stuck spinning. Logs indicate errors such as:

apply_asm_attack_signatures|INFO|<timestamp>|<process_id>|F5::LiveUpdate::PayloadHandler::upload,,Start Negative Signatures
apply_asm_attack_signatures|ERR|<timestamp>|<process_id>|F5::LiveUpdate::PayloadHandler::clean_fail,,Fail load update files: TSocket: timed out reading 1024 bytes from 127.0.0.1:9781

Environment

  • BIG-IP Advanced WAF
  • Attack Signature Updates

Cause

This issue is caused by a known bug (ID1295057).

Recommended Actions

Upgrade to a version where Bug ID1295057 has been addressed and resolved.
