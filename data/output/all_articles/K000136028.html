K000136028: Filenames ending with tilde (~)

Type
Support Solution
Published
2023-09-05
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP DNS: 14.1.5
Source
https://my.f5.com/manage/s/article/K000136028

Description

Files with the tilde "~" may be encountered in the F5 filesystem and these files might be confusing.

For example, the original ZoneRunner file (named.conf) is empty, and proper configuration data are saved in a backup file (named.conf~). This situation may produce ZRD restarting in a loop and an error message:

Unable to parse named.conf file

 

Environment

  • BIG-IP DNS
  • files with tilde character "~"
 

Cause

Typically files ending with the "~" are backups or temporary files created by editors like emacs, nano or vi.
Such files will not be synchronized in DNS.
 

Recommended Actions

Once the original file is filled correctly, the file with the tilde may be deleted.

 

Additional Information

None.
