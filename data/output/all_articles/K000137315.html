Security Advisory Description

The BGP daemon (bgpd) in ZebOS through 7.10.6 allows remote attackers to cause a denial-of-service (DoS) by sending crafted BGP update messages containing a malformed attribute. (CVE-2023-45886)

Impact

This vulnerability may allow a remote unauthenticated attacker to cause a DoS on the BGP peering process.

Note: CVE-2023-45886 is a vulnerability in ZebOS software, a third-party component licensed by F5 as part of the BIG-IP Advanced Routing Module. This module is not enabled by default and requires a separate license. To determine if your system is actively running BIG-IP Advanced Routing Module, refer to K10168: Overview of BGP on the BIG-IP system.

Mitigation

CVE-2023-45886 is a vulnerability in ZebOS software, a third-party component licensed by F5 as part of BIG-IP Advanced Routing Module. This module is not enabled by default and requires a separate license. To determine if your system is actively running BIG-IP Advanced Routing Module, refer to K10168: Overview of BGP on the BIG-IP system.

Note: To fully resolve this vulnerability, the ZebOS software component must be updated by the software vendor to align with the RFC-7606 standard. This would address the identified vulnerability by improving how BGP errors are handled, thereby enhancing the resilience of the ZebOS software against similar threats in the future. Until an update is available, F5 wants to reassure you that if your deployment does not use BGP, your system remains secure against this vulnerability. F5 also recommends implementing monitoring for unusual BGP messages and malformed attributes as a precautionary measure.

If you have configured the BIG-IP Advanced Routing Module functionality, F5 recommends ensuring that any BGP peers upstream of the BIG-IP system that can support RFC-7606 are configured accordingly to mitigate the potential impact of CVE-2023-45886. This approach allows upstream routers to intelligently handle malformed BGP messages (discarding or correcting them as needed) without severing the BGP session. Implementing this strategy can significantly bolster a network's defenses against DoS attacks aimed at exploiting this vulnerability. Additionally, you should ensure your self IP addresses are accessible only to trusted BGP peers. For more information, refer to K54334475: Configuring the BIG-IP system for basic BGP connectivity.
