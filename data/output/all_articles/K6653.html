K6653: The connection fails when accessing a virtual server with a Client SSL profile using the Mozilla FireFox browser with TLSv1 disabled

Known Issue

This is a result of a known issue. When accessing a virtual server with a Client SSL profile using the Mozilla Firefox browser with TLSv1 disabled, the connection may fail. This issue occurs when the browser is limited to SSLv3.

The first request succeeds; however, during the second request, the following sequence of events takes place:

  • The client browser (Mozilla Firefox) reuses the SSL Session ID and fails.
  • The Mozilla Firefox browser sends data, such as a GET request, that is included in the same packet as the finished handshake record.
  • The BIG-IP LTM discards the data and no connection is opened to the back-end server.
  • The connection times out.

F5 Product Development tracked this issue as CR63808 and CR68149 and it was fixed in BIG-IP LTM 9.2.4, 9.3.0, and 9.4.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

You can work around this issue by enabling TLSv1 within the Mozilla Firefox browser.
