Known Issue

The Simple Network Management Protocol (SNMP) reports invalid data for server-side current connection 5-second, 1-minute, and 5-minute averages.

This issue occurs when the following condition is met:

  • You query the BIG-IP system for the following SNMP Object IDs (OIDs):
     
    • sysStatServerCurConns5s (.1.3.6.1.4.1.3375.2.1.1.2.1.72.0)
    • sysStatServerCurConns1m (.1.3.6.1.4.1.3375.2.1.1.2.1.86.0)
    • sysStatServerCurConns5m (.1.3.6.1.4.1.3375.2.1.1.2.1.100.0)

The BIG-IP system will always return a result of zero ( 0 ) for SNMP queries of the 5-second, 1-minute, and 5-minute averages of server side current connections, even when there are known current connections.

Impact

The BIG-IP system always returns a value of zero for the affected SNMP OIDs.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • SNMP queries for the 5-second, 1-minute, and 5-minute averages of server-side current connections will always return a result of zero.

    For example, you enter the following query command:

    snmpget -c public -v2c localhost sysStatServerCurConns.0 sysStatServerCurConns5s.0 sysStatServerCurConns1m.0 sysStatServerCurConns5m.0

    The command output appears similar to the following example:

    F5-BIGIP-SYSTEM-MIB::sysStatServerCurConns.0 = Gauge32: 8
    F5-BIGIP-SYSTEM-MIB::sysStatServerCurConns5s.0 = Gauge32: 0
    F5-BIGIP-SYSTEM-MIB::sysStatServerCurConns1m.0 = Gauge32: 0
    F5-BIGIP-SYSTEM-MIB::sysStatServerCurConns5m.0 = Gauge32: 0
