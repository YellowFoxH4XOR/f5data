K000132658: The VPN client routing table does not get updated of the resolved IPs from Dynamic DNS Address.

Type
Support Solution
Published
2023-02-18
Updated
2023-02-18
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000132658

Description

With the Network Access object configured to make use of the "Dynamic Address Spaces" objects, you notice that the client's traffic may not flow as expected.

Typically: the traffic is not going over the VPN when you expect it not.


Environment

  • BIG-IP APM
  • APM VPN (with using either the EdgeClient software or a browser based solution)
  • Dynamic Address Spaces

Cause

This is because the DNS Relay Proxy does not support to update the client routing table with the IPs being resolved.

This feature is not supported yet.


Recommended Actions

Alongside with the names we put to the "Dynamic Address Spaces" object, we'ed need to also add the associated IP addresses or ranges.


Additional Information

None.
