Description

You would like to add an NTP server to an F5OS device with iburst enabled.

Environment

  • F5OS-A
  • F5OS-C

Cause

Use 'iburst' option. It helps making more reliable synchronization and initial accuracy with the server. 

Recommended Actions

1. Connect using SSH to the management IP address.

2. Log in to the command line interface (CLI) of the system using an account with admin access. When you log in to the system, you are in user (operational) mode.

3. Change to config mode.

# config

4. Enable NTP.

# system ntp config enabled

6. Add an NTP server and enable iburst. In this example we will use pool.ntp.org:

# system ntp servers server pool.ntp.org config iburst true

7. Commit the configuration changes.

# commit

8. Return to user (operational) mode.

# end

9. Verify that NTP is enabled and a server is configured.

# show system ntp
system ntp state enabled
system ntp state enable-ntp-auth false
