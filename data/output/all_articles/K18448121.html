Known Issue

The Windows 10 October 2018 update may break network access functionality.

This issue occurs when all of the following conditions are met:

  • Your client device is running Windows 10.
  • You apply the October 2018 update to the client device. Note that the original 1809 update was pulled in favor of a new version.
  • You have configured the BIG-IP APM network access profile to use split tunneling.
  • You attempt to establish a network access session using BIG-IP Edge Client or an Internet browser from the client device.

This issue is a result of a regression bug in Windows 10. For more information, refer to January 22, 2019—KB4476976 (OS Build 17763.292).

Note: This link takes you to a resource outside of AskF5, and the third party could remove the document without our knowledge.

Impact

All network requests from the client PC to destinations outside of the VPN tunnel fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to access Internet resources after establishing a network access session, the browser displays an error message similar to the following:

    Hmm…can’t reach this page

  • When you use the command line ping utility on the affected device, ping fails with a "General failure" error message.

Workaround

To work around this issue you can use either of the following methods:

  • You can use F5 Access to establish the network access session. Network access sessions established using F5 Access are not affected by this issue. F5 Access is a native Windows 10 app in the Microsoft Store.
  • You can disable split tunneling for the network access resource. To do so, perform the following Disabling split tunneling procedure.

Disabling split tunneling

To disable split tunneling, you can modify the network access profile and change the Use split tunneling for traffic setting to Force all traffic through tunnel. To do so, perform the following procedure:

Impact of workaround: This procedure removes split tunneling functionality from the network access profile. When users establish a network access session, the system routes all requests through the network access tunnel.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Navigate to Access > Connectivity / VPN > Network Access (VPN) > Network Access Lists.
  3. Click the network access profile and click the Network Settings tab.
  4. For Client Settings, click Advanced.
  5. For Traffic Options, click Force all traffic through tunnel.
  6. Click Update.
