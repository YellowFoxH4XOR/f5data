K14355981: BIG-IQ downgrades previously installed AS3 when upgrading

Type
Support Solution
Published
2021-12-17
Updated
2026-08-10
Status
Legacy Content
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management
Source
https://my.f5.com/manage/s/article/K14355981

Description

During upgrade from 8.0 to 8.1 BIG-IQ installs AS3 version 3.28 and overwrites any upgraded versions already installed such as version 3.30.

If there is a later version already installed it installs the earlier version, does not update the restjavad.properties.json in the link, and impacts declarations in two ways

  • Declarations fail with an indication that the RPM file is not accurate in /var/config/rest/config/restjavad.properties.json: "rpmFilePath": "/usr/lib/dco/packages/f5-appsvcs/f5-appsvcs-3.30.0-5.noarch.rpm"
  • It fails to allow declarations that would use the later version schema

Environment

  • BIG-IQ that has had AS3 upgraded to version 3.30
  • AS3 in use

Cause

BIG-IQ installer does not detect or keep the upgraded version of AS3

Recommended Actions

The there are two workarounds.
  1. Edit the json file, which leaves the system using AS3 3.28 (earlier version) and may causes other software version related issues.
  2. Reinstall AS3 3.30, which corrects the issue.
