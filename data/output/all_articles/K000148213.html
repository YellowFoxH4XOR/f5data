Description

I want to access F5® Distributed Cloud (XC) managed Prometheus service (in monitoring namespace) from a user Pod

Environment

  • Distributed Cloud (SaaS) 
  • F5® Distributed Cloud (XC) App Stack site (Managed k8s)

Answer/Recommended Actions

Console

Open F5® Distributed Cloud Console, Cloud and Edge Sites

1. Go to Manage > Manage K8s > K8s Clusters, and choose your Cluster Name
2. Click "･･･" in Actions field, > Manage Configuration

 

3. Click Edit Configuration around right top
4. Scroll down to Cluster Wide Applications configuration section and click Edit Configuration

 

5. Select "Add Item"

 

6. Add items by following steps

a) Select Prometheus from the pull down menu

b) click Apply to add into Cluster Wide Application List
c) Select K8s Metrics Server from the pull down menu

d) click Apply to add into Cluster Wide Application List

 

7. Click Apply to save the route configuration
8. Scroll down and click to Save and Exit to save the changes

Verification

  1. Enter your User Pod via Local Kubeconfig in CLI (skip the detail about creation)

    $ kubectl exec -it  user-pod -- bash

     

  2. Run curl command for prometheus.monitoring.svc:9090, JSON response is seen

    root@user-pod:/# curl -s 'http://prometheus.monitoring.svc:9090/api/v1/query?query=up'

    {"status":"success","data":{"resultType":"vector","result":[{"metric":{"__name__":"up",
    "app":"coredns","instance":"192.168.10.11:9153","job":"kubernetes-pod","k8s_app":"coredns",
    "k8s_ns":"kube-system","kubernetes_namespace":"kube-system","kubernetes_pod_name":" ...

 

[Note] In general, Grafana or some other 3rd Party Service will be deployed to use Prometheus metrics effectively.
