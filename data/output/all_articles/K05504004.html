Known Issue

The rate class feature may not honor the ceiling rate setting.

This issue occurs when all of the following conditions are met:

  • You create a rate class object with a specified ceiling rate.
  • You create additional rate class objects using the aforementioned rate class object as the parent class.
  • The specific ceiling rate of each child class object does not exceed the ceiling rate specified in the parent class.
  • You associate each of the child class objects with a virtual server.
  • Each virtual server simultaneously processes traffic that reaches the bandwidth configured ceiling rate specified in the parent class.

Impact

The ceiling rate for a parent rate class object is not enforced.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You observe that the sum of the bandwidth of the child rate class objects exceeds the configured ceiling rate of the parent rate class.
