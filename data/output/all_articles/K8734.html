Known Issue

This is the result of a known issue. Binary data that contains certain patterns may cause the SIP message parser to loop. As a result, TMM may crash.

The SIP profile uses the SIP message parser to handle SIP traffic. When the SIP message parser accepts binary data that contains certain patterns of spaces, tabs, and newline characters, the SIP parser may loop. This behavior may eventually cause the TMM heartbeat to fail.

F5 Product Development tracked this issue as CR98076 and it was fixed in BIG-IP LTM 9.4.5. For information about upgrading, refer to the BIG-IP LTM Release Notes.
