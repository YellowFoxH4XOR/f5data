Known Issue

This is the result of a known issue. In rare cases, if the final line of an HTTP monitor send string is terminated with only a line feed (LF) character, TMM may enter an infinite loop and terminate with a SIGABRT.

The BIG-IP system expects HTTP monitor requests to conform to the WC3 HTTP 1.1 specification as defined in RFC2616. RFC2616 specifies that each HTTP header line must be terminated by a single CR/LF sequence, and the final header line must be followed by an additional CR/LF sequence, creating a blank line following the last header. As a result, the headers in a properly formatted HTTP request appear to be terminated by a double CR/LF sequence (CR/LF/CR/LF). When the final CR character in this sequence is not present, BIG-IP is unable to determine the end of the HTTP headers and cannot complete its processing of the request.

F5 Product Development tracked this issue as CR138049 and it was fixed in version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, WebAccelerator, APM, WOM, or Edge Gateway release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

Workaround

You can work around this issue by ensuring your HTTP monitor Send strings are properly terminated.

Note: When constructing HTTP monitor Send strings, the line feed character is represented by the escape sequence \n, and the carriage return (CR) character is represented by the escape sequence \r. For more information about constructing HTTP monitors, refer to K2167: Constructing HTTP requests for use with the HTTP or HTTPS application health monitor.
