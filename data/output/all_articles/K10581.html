Known Issue

This is the result of a known issue. BIG-IP ASM will chunk HTTP responses for which there is no body content and no defined Content-Length. For example, HTTP 304 Not Modified responses are chunked. This behavior may cause some applications, such as browsers and other end user applications, to not display the page properly or display a blank page.

F5 Product Development tracked this issue as ID 220730 (formerly CR85643) and it was fixed in BIG-IP version 10.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-9.4.8-407.0-HF4, which was issued for BIG-IP version 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing a hotfix for version 9.x systems, refer to K6845: Managing F5 product hotfixes for BIG-IP version 9.x systems.

Workaround

You can work around this issue by changing the Response Chunking setting of the HTTP profile to Unchunk. To do so, perform the following procedure:

Note: When setting Response Chunking to Unchunk, any response that was originally chunked by the back-end webserver will be buffered and unchunked on the BIG-IP LTM before passing the information to the BIG-IP ASM. For more information about the Response Chunking option behavior, refer to the Managing Application Layer Traffic chapter in the Configuration Guide for BIG-IP Local Traffic Management.

Note: Setting Response Chunking to Preserve may result in high CPU utilization for the BIG-IP ASM when dealing with gzipped responses and responses that are chunked by the originating web server. For more information, refer to K11040: HTTP Profile Response Chunking set to Preserve interferes with BIG-IP ASM and WebAccelerator processing.

  1. Select Local Traffic.
  2. Select Profiles.
  3. Select Services.
  4. Select HTTP.
  5. Click the HTTP profile that you want to modify.
  6. Locate Response Chunking under Settings for the HTTP profile.
  7. Select Unchunk from the drop-down menu.
  8. Click the Finished button.
