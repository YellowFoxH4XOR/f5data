Topic

For BIG-IP devices, you can assign one media access control (MAC) masquerade address to each Virtual Local Area Network (VLAN) of a traffic group.

Description

To optimize traffic flow during failover events, you can configure MAC masquerade addresses for any defined traffic groups on the BIG-IP system. A MAC masquerade address is a unique, floating MAC address that you create. You can assign one MAC masquerade address to each traffic group on a BIG-IP device. By assigning a MAC masquerade address to a traffic group, you associate that address with any floating IP addresses associated with the traffic group.

Beginning in BIG-IP 11.2.0, a tm.macmasqaddr_per_vlan database key was introduced to allow each VLAN in a traffic group to have a unique MAC masquerade address.

Note: The MAC masquerade address per VLAN feature is not compatible with VLAN Groups or ePVA accelerated traffic.

When the tm.macmasqaddr_per_vlan database key is set to false, which is the default value, the egress traffic uses a common source MAC masquerade address associated with the traffic group.

When the tm.macmasqaddr_per_vlan database key is set to true, the egress traffic uses the MAC masquerade address of the traffic group as a base, and generates a unique source MAC masquerade address for each VLAN. A MAC address consists of six hexadecimal bytes. The uniqueness of the MAC masquerade address comes from the last two hexadecimal bytes, which are derived from the VLAN ID. For example:

tmsh list cm traffic-group traffic-group-1 mac
cm traffic-group traffic-group-1 {
mac 02:23:e9:f6:f7:85
}

The last two hexadecimal bytes are derived from the VLAN ID. The process is as follows:

  1. The VLAN ID is converted to the hexadecimal equivalent. For example, VLAN ID 580 will translate to 0244 (hex).
  2. The output forms the last two hexadecimal bytes when placed in a reversed order. For example, VLAN ID 0244 (hex) will translate to 44:02.
  3. The translated digits from step 2 replace the last two hexadecimal bytes of the base MAC masquerade address to form the unique MAC masquerade address by adding the translated VLAN ID and add "1" to the last byte. For example, the MAC masquerade address for egress traffic coming from VLAN ID 580 should have a unique MAC masquerade address of 02:23:e9:f6:3b:88.

Recommendations

To configure the tm.macmasqaddr_per_vlan database key, perform the following procedure:

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To specify the new value for the database key, use the following command syntax:

    modify /sys db tm.macmasqaddr_per_vlan value <true|false>

    For example:

    modify /sys db tm.macmasqaddr_per_vlan value true

  3. Save the configuration by typing the following command:

    save /sys config
