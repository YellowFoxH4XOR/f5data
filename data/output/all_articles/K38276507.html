Description
When /shared/tmp is full, you could observe below similar error message from mysqld on GUI.

Disk full (/var/tmp/#sql_412b_1);waiting for someone to free some space...

Environment

  • BIG-IP LTM
  • /shared directory

Cause
During the creation of UCS backup, if the UCS process was interrupted then temporary files such as /var/tmp/im23224 will be left in /shared/tmp

config # ll /var/tmp/im23224
total 28536
-rw-r--r--. 1 root root 29184000 Aug 11 15:38 configsync-2.0-1-Linux-3.10.0862.14.4.7..8664.im

Recommended Actions

  1. Make sure UCS process is saved and completed properly so that those temporary files could be removed automatically.
  2. Manually remove /var/tmp/imXXX files.

Additional Information

By default, /var/tmp is mounted under /shared
