Known Issue

The virtual address may send an unexpected Internet Control Message Protocol (ICMP) response.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a UDP virtual server, and is assigned a pool of UDP members.
  • All the members in the pool are marked as unavailable.
  • You send an ICMP (ping) request to the virtual server IP address.

Impact

The virtual server ICMP responds with an ICMP Type 13 packet (Communication Administratively Prohibited).

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When encountering the same scenario for BIG-IP 11.3.0 through 11.4.1, the BIG-IP silently drops the ICMP request.
  • When encountering the same scenario for BIG-IP 11.2.1 and later, the BIG-IP system responds with an ICMP Type 3 Port Unreachable packet.
