To configure NameSurfer, perform the following steps:
  1. From the command line, type the following command:

    config

    This opens a menu of configuration options.
  2. To select the Configure NameSurfer option, type N.

    This option allows you to set up the initial NameSurfer configuration.
  3. Follow the prompts to complete the NameSurfer configuration.

Note: If you plan to run the NameSurfer utility, F5 recommends that you use NameSurfer as the primary method for configuring DNS.
