K000148817: User-defined variables not added when using F5 Ansible bigip_monitor_external module to create external monitor in non-Common partition

Type
Support Solution
Published
2024-12-03
Updated
2024-12-18
Applies to
  • F5 Automation and Orchestration
  • F5 Modules for Ansible
Source
https://my.f5.com/manage/s/article/K000148817

Description

When configuring external monitor in non-Common partition using F5 Ansible bigip_monitor_external module, user-defined variables not added even though the ansible-playbook completes successfully without error.

Sample playbook showing the only the tasks of creating the external monitor:

  tasks:
    - name: Create external monitor
      bigip_monitor_external:
        name: "foo_demo"
        external_program: external_mon_curl_demo
        partition: demo
        timeout: 10
        variables:
          DOMAIN: "www.example.io"
          URI: "test"
          RECV: "OK"
        state: present
        provider: "{{ provider }}"
      delegate_to: localhost
 
    - name: Update external monitor
      bigip_monitor_external:
        name: "foo_demo"
        partition: demo
        timeout: 10
        variables:
          DOMAIN: "www.example.io"
          URI: "prod"
          RECV: "OK"
        state: present
        provider: "{{ provider }}"
      delegate_to: localhost

The user-defined variables configuration of the external monitor are not added:

bigip)(cfg-sync Standalone)(Active)(/demo)(tmos)# list ltm monitor external foo_demo all-properties
ltm monitor external foo_demo {
    app-service none
    args none
    defaults-from /Common/external
    description none
    destination *:*
    interval 5
    manual-resume disabled
    partition demo
    run /demo/external_mon_curl_demo
    time-until-up 0
    timeout 10
    up-interval 0
}

 

Environment

  • F5 Ansible Module, bigip_monitor_external

Cause

In a non-common partition, the configuration deployed continues to use "folder=/Common" when attempting to add user-defined variables to the external monitor. 

Recommended Actions

Install f5networks.f5_modules collection version 1.33.0 or higher on the Ansible Control node.
