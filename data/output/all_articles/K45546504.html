Topic

F5 is deprecating F5 iApps. For the following F5 iApp templates, F5 recommends that you use F5 Guided Configuration to deploy your BIG-IP APM applications:

  • Microsoft Exchange 2016
  • Microsoft SharePoint 2016
  • Microsoft ADFS

For all other iApp templates not listed above, they will be replaced by F5 Application Services Templates (FAST). You can also find more information on FAST in F5 Application Services Templates (FAST) on F5 Cloud Docs.

For more information on iApps deprecation, refer to K13422: F5-supported and F5-contributed iApp templates.

Description

Beginning in BIG-IP 13.1.0.8, F5 introduced Guided Configuration 3.0.0 to provide a way to deploy configurations for BIG-IP APM and Advanced WAF. Guided Configuration provides different configuration templates that cover common BIG-IP APM use-case scenarios, including integration with your Microsoft applications. 

  • ADFS Proxy: Use this to set up the BIG-IP system for Microsoft Active Directory Federation Services 2.0, 3.0, and 4.0 deployments. You can configure the BIG-IP system for Microsoft AD FS deployments as follows:
    • Use the BIG-IP LTM system to load balance AD FS servers.
    • Use the BIG-IP LTM system to load balance AD FS proxy servers.
    • Use the BIG-IP APM system to secure AD FS traffic without the need for proxy servers.
  • Azure AD application: Use this to set up the BIG-IP APM system as a Security Assertion Markup Language (SAML) Service Provider (SP), and Azure AD as an Identity Provider (IdP) for your mission-critical, on-premise application, including SharePoint.
  • Exchange Proxy:  You can deploy Microsoft Exchange proxy for Exchange on-prem and Exchange hybrid configurations. Use this to set up the BIG-IP APM system to authenticate and load balance Exchange clients.

To access Guided Configuration to deploy applications for your Microsoft applications, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Go to Access > Guided Configuration.
  3. Select Microsoft Integration.
  4. Select the appropriate use case (ADFS Proxy, AD application, or Exchange Proxy).
  5. Refer to the right panel for the required information to complete the deployment.
  6. Follow the guide to complete your deployment.
