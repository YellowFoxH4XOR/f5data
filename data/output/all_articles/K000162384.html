K000162384: HTTPs monitor not working with non-default cmp hash and in-tmm monitoring enabled

Type
Support Solution
Published
2026-09-01
Updated
2026-09-01
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000162384

Description

After enabling in-tmm monitoring, you may observe that monitoring is failing for HTTPs monitors with non-default cmp-hash.

Environment

  • BIG-IP

  • In-tmm monitoring enabled
  • HTTPs monitors

Cause

This is caused by bug ID 2395641.

Answer/Recommended Actions

Unless specific cause for using non-default cmp-hash is present, set cmp-hash setting to default.

Additional Information

None
