K45414423: Search of virtual servers by IP doesn't show shared objects

Source

Description
In the GUI, when searching for virtual servers by IP address, or part of an IP address, virtual servers configured with traffic-matching-criteria (shared objects) will not be listed. This behavior can result in inaccurate searches.
Searching by name, or part of a name, will return correct virtual servers names.

Environment
  • Virtual Server using Address Lists 
  • Virtual Server using Port Lists
Cause
The GUI does not look inside traffic-matching-criteria objects when filtering for virtual server IP addresses or Ports.

Recommended Actions
There is currently no workaround (when searching by ip address) or fix.

Optional workaround is to search by name, or partial name.

Additional Information
This issue is being tracked as BUG ID 958601
