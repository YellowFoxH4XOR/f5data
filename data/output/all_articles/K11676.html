Issue

When attempting to establish a Virtual Private Network (VPN) connection, your Windows client connection may display the following error message:

error:The local computer does not support the required data encryption type.

This is the result of the Windows client network adapter configuration set to force an unsupported data encryption type. FirePass, BIG-IP APM and Edge Gateway use Secure Sockets Layer (SSL) for data encryption, and Microsoft does not list SSL in the encryption protocols for Point-to-Point Protocol (PPP) connections.

To fix this error, you can perform the following procedure:

Configuring a data encryption type

  1. From the Windows client computer desktop, click Start button.
  2. Click the Connect To menu option.
  3. Right-click your F5 VPN Adapter.
  4. Click Properties.

    The adapter properties window will open.

  5. Click the Security tab.
  6. Select Advanced (custom settings).
  7. Click Settings.
  8. Select Optional encryption (connect even if no encryption) from the Data encryption: drop-down menu.
  9. Click OK.
  10. Click Yes on the Network Connections pop-up window.
  11. Click OK.
  12. Click OK.

Note: For more information about configuring PPP connections, refer to the Administrator Guide for your device platform.
