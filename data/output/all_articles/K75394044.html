K75394044: On-Demand Cert Auth not working for older Microsoft Edge browser

Type
Support Solution
Published
2022-04-04
Updated
2023-02-21
Applies to
  • BIG-IP
  • Virtual Editions
  • BIG-IP APM: 15.1.4
Source
https://my.f5.com/manage/s/article/K75394044

Description

On Windows 10 clients, the older version of Microsoft Edge browser does not prompt user for certificate selection when using On-Demand Cert Auth.

Environment

  • Older Microsoft Edge browser versions (tested v44 and v42)
  • On-Demand Cert Auth

Cause

Unknown

Recommended Actions

Updating the Edge to a newer version (v99) or higher

Additional Information

https://techdocs.f5.com/en-us/bigip-15-1-0/big-ip-access-policy-manager-visual-policy-editor/access-policy-item-reference/about-authentication-items/about-on-demand-cert-auth.html
