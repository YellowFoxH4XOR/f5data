Description

The OAS is a vendor-neutral, open-source standard. Because it is maintained by an external community, F5 does not dictate the features or options included in new releases.
We ensure our products align with the standard, but we have no direct influence over development roadmap or the specific attributes the maintainers choose to publish.

We recommend use ASM/WAF declaration : https://clouddocs.f5.com/products/waf-declarative-policy/schema_v17_1.html which is part of our official documentation. 

Edit ASM : parameters: "Allow Repeated Occurrences"by RESTAPI: 

Environment

  • ASM/WAF/AWAF system
  • RESTAPI  

Cause

None

Answer/Recommended Actions

RESTAPI is third-party vendor.F5 do not take action on open source third-party vendor. The options available are:

1./ Use ASM/WAF declarative

2./ or POST the change by RESTAPI PATCH.

Here is an example how you can modify the "Allow Repeated Occurrences" by RESTAPI: 

1./ Collect the policy id: 

curl -sku <username>:<password> https://<bigip_ip>/mgmt/tm/asm/policies?\$select=name,id | jq '.'
 
example:

 Note: You can also obtain the parameter_id to edit specific parameter. In this example, -2_gsUlB6BuGhulKfEuo5Q

3./ Enable "Allow Repeated Occurrences" setting: 

curl -sk -u admin:admin -X PATCH "https://10.171.137.210/mgmt/tm/asm/policies/pNIILkCAY2to-65FhBGZog/parameters/" -H "Content-Type: application/json" -d '{"allowRepeatedParameterName": true }'
