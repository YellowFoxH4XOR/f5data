Description

This is caused due to the management route not in the same subnet as the management IP address.

 

Prior to 14.1.0 version, SSH and GUI sessions can still be established due to an old feature called "Auto Last Hop on the management interface".

Refer to: K52592992: Overview of the Auto Last Hop feature on the management interface

 

You should see a similar log under /var/log/ltm

 

ltm <date> Error <BIG-IP hostname> mcpd[6341]: 01071a95:3: Admin IP (<AdminIP>/<AdminNetMask>): Gateway (<AdminGateway>) for management route (<Route>) is not in a connected network.

 

 

Environment

BIG-IP LTM

This is a common issue when upgrading to version 14.1.0 or later.
 

Cause

Management IP is not in the same subnet as the management route.

 

Recommended Actions

1. Change the management route IP by deleting the current management route to one that matches the management-IP subnet

2. Modify the netmask of the management IP to be in the same subnet as the management route.
