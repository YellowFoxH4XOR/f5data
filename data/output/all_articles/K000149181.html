K000149181: License Assignment Failed error while generating unreachable license on BIG-IQ

Type
Support Solution
Published
2025-01-03
Updated
2025-02-07
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K000149181

Description

On the BIG-IQ, after running the script to create a license for an unreachable BIG-IP, it returns "***** License Assignment Failed. Most likely a valid license already exists for device, revoke it before applying a new license *****"

Environment

  • Flexible Consumption Program (FCP)
  • BIG-IQ
  • Catalog (CAT) license offerings
  • License script for unreachable BIG-IPs

Cause

Either an unreachable license already exists for this BIG-IP on the BIG-IQ or the license offering assigned isn't activated yet.

Recommended Actions

Determine whether there is a pre-existing license for this unreachable BIG-IP and confirm that the necessary license offering is activated within the CAT.

  1. Verify whether an unreachable license already exists for this BIG-IP.
    1. On the BIG-IQ navigate to Devices tab > License Management > Assignments
    2. Search for the IP of the BIG-IP to confirm whether an unreachable license already exists
    3. Revoke it by checking the box to the left and click Revoke. Click revoke and submit to confirm
  2. Verify that the license offering is activated.
    1. On the BIG-IQ navigate to Devices tab > License Management > Licenses > Catalog
    2. Click the relevant Catalog link
    3. Check the list for the relevant license offering
    4. If it's not activated, copy its Device Dossier and paste it into Activate F5 Product
    5. Once the license posts, copy and paste it into License Text for this license offering on the BIG-IQ
    6. Click Activate
    7. Re-run the script to generate the license for the unreachable BIG-IP per K69187707: How to license a BIG-IP which is not reachable by BIG-IQ using FCP.
