Topic

Starting in version 4.6.3, 3-DNS allows you to allocate connections to BIG-IP virtual servers based on the connection rate defined for the pool that is used by the BIG-IP virtual server. This new feature is known as available connection rate.

3-DNS monitors the connection rate limit for the virtual server and the current connection rate and uses a dynamic load balancing ratio based on the difference between these two values. 3-DNS will assign the highest weight to those virtual servers with the greatest ratio difference.

You can use available connection rate as a load balancing method or as a coefficient for Quality of Service (QoS) load balancing.

Important: Before you can use available connection rate load balancing on 3-DNS, you must configure connection rate dynamic ratio load balancing on BIG-IP. For specific instructions, refer to K4183: Configuring BIG-IP to limit connections to a node based on the rate of requests rather than the number of concurrent requests.

Configuring available connection rate load balancing

To configure available connection rate load balancing, perform the following steps:

  1. From the Configuration utility, click Wide IP.
  2. From the list, click the wide IP for which you want to enable the available connection rate.
  3. Click the Modify Pool tab.
  4. From the list, click the pool that you want to modify.
  5. In the Load Balancing Modes section, use the menu to change the Preferred method to Connection Rate.
  6. Click the Update button.

3-DNS will now use available connection rate load balancing for the wide IP that you modified.

Configuring QoS with an available connection rate coefficient

To configure available connection rate as a QoS coefficient, perform the following steps:

  1. From the Configuration utility, click Wide IP.
  2. From the list, click the wide IP for which you want to enable the available connection rate.
  3. Click the Modify Pool tab.
  4. From the list, click the pool that you want to modify.
  5. In the Quality of Service section, change the value in the Connection Rate field to the weight you want to assign.

    Note: For more information about QoS, including ranges and limits, refer to the Working with Quality of Service chapter of the Administration Guide.

  6. Click the Update button.

QoS load balancing is now configured with the available connection rate coefficient that you assigned.
