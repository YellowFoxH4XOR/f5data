Topic

Use this procedure when you want to use MyF5 to download and license a new instance of NGINX Controller for an existing subscription.

Prerequisites

You must have a subscription for NGINX Controller on MyF5 to use this procedure.

Procedure

  1. Go to My Products and Plans > NGINX Controller.
  2. Select the NGINX Controller subscription you want to add an instance to.
  3. Select Instance.
  4. In the Instance (License) panel, select Copy and then record the association token in an accessible place.

    You need the association token to license your new NGINX Controller instance after you install it. The download includes the instructions for installing and licensing the instance.

  5. Select Download the latest version.
  6. Under NGINX, select NGINX Controller.
  7. Under Choose your files to download, select the version you want.
  8. In the product description, select Install NGINX Controller to open the instructions for installing and licensing your new instance.
  9. Download the files that display.
