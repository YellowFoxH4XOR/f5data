K000137660: Modifying bigd.numprocs on systems with BIG-IP monitors using external HSM key requires restarting pkcs11d

Topic

You need to restart the pkcs11d daemon when either one of the following conditions are met:

  • when you configure a BIG-IP monitor to use an external HSM key.
  • when you have a BIG-IP monitor that uses an external HSM key, you modify the DB variable bigd.numprocs to a non zero (default) value.

Description

To configure a BIG-IP monitor to use a HSM key, you need the following components:
  • bigd.tmm DB variable: Disable the DB variable bigd.tmm. This is required to disable In-TMM monitoring. For more information, refer to K11323537: Configuring In-TMM monitoring
  • Server SSL profile with NetHSM Key: You require a server SSL profile that uses a HSM key. For more information on generating an external HSM certificate/key and creating a SSL profile to use it, refer to the following manuals as appropriate for your BIG-IP version:

    • BIG-IP 16.1.0 and later: BIG-IP System and SafeNet Luna SA HSM: Implementation

    • BIG-IP 15.1.0: BIG-IP System and SafeNet Luna SA HSM: Implementation

  • BIG-IP HTTPS monitor: You create a BIG-IP HTTPS monitor and associate the server SSL profile with NetHSM key to it. Note K51131340: SSL settings used by an HTTPS monitor are now configured using a Server SSL profile .
When you have created the required components, you need to restart the pkcs11d daemon. To do so, enter the following command: 
tmsh restart sys service pkcs11d

You have configured a BIG-IP HTTPS monitor to use an external HSM key.

At this point, if you modify the value of the DB variable bigd.numprocs to a non zero (default) value, you need to run the same command to restart the pkcs11d daemon.
