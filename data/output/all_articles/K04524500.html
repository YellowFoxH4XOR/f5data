Description

Topology is a proximity based load balancing mode that allows you to direct traffic by defining topology records and selecting the Topology load-balancing mode for the wide IP or pool. The Topology mode bases the distribution of requests on the topology records and the weighted scores configured for each record. The topology records direct DNS queries to the closest virtual server, based on geographical information. The BIG-IP DNS system is designed to support an unlimited number of topology records. The only limit is the amount of memory available to the gtmd process.

Topology Decision making Process
  •     Scan Topology Records
  •     Assign Scores
  •     Choose Destination Object
If the longest match is enabled and Topology records are configured with the same score. Also there are two matching records even one with same specific IP 

Example :
gtm topology ldns: subnet 0.0.0.0/0 server: subnet x.x.x.x/32 {
    order 77
    score 100
}
gtm topology ldns: subnet 10.0.0.2/32 server: subnet x.x.x.x/32 {
    order 5
    score 100
}

Both records are given the same score of 100, and the DNS answer round-robins between them. This is by design, *but* it is unintuitive to a customer who expects that second record would win as it has more specific IP. When using topology load balancing all gtm pools (or pool members) are evaluated and given a score, based on the configured topology records.  Order is only important when multiple records with different scores match the DNS request", and then go on to give examples. 

Environment

  • BIGIP-DNS
  • Topology Records with longest match enabled

Cause

By Design

Recommended Actions

If the Scores are same the by design the request will be going to all the matches in round robin manner. if need to only send to specific record change the record score as per below 

  • Login to F5 device and then navigate to DNS  ››  GSLB : Topology : Records
  • Select the respective record for which order needs to be changed 
  • Change the Weight to the higher value respective to similar record.
