Known Issue

BIG-IP APM portal processing of Flash AS2 (Adobe Flash ActionScript 2.0) content may trigger a connection reset.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP APM system with a portal access profile.
  • The portal processes content includes Flash AS2 content.
  • The BIG-IP APM portal rewrites the AS2 instruction byte code, increasing the length to over 32000 bytes.

Impact

The user session fails with a connection reset from the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Users who use the portal to access Flash AS2 content may have their session sporadically reset.
  • The BIG-IP APM log file /var/log/rewrite may contain error messages similar to the following:

    notice rewrite - RewritePlugin.cpp:2602 : ERROR: Null patchInfoPtr
    notice rewrite - RewritePlugin.cpp:2916 : ERROR Occurred : ERROR: ERR_ABRT
    notice rewrite - RewritePlugin.cpp:2919 : ERROR Occurred with operation: tm_abort

  • The BIG-IP APM log file /var/log/ltm may contain error messages similar to the following:

    info tmm2[14266]: 01220009:6: Pending rule event HTTP_REQUEST aborted for <client ip address:port>-><apm portal virtual address:port> (listener: /<partition>/<portal access profile name>)

    info tmm6[14270]: 01220009:6: Pending rule event HTTP_REQUEST aborted for <client ip address:port>-><apm portal virtual address:port> (listener: /<partition>/<portal access profile name>)
