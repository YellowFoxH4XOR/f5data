Description

Front Port LED Test on BIG-IP iSeries platforms, the LCD buttons are unresponsive.
During EUDSF3.9.1 Front Port Led Test on Big-IP i2600, the LCD buttons are unresponsive.

EUD Interactive test:

  • 20 LED Test - Front Port LED test
  • 21 LCD Keypad Test - LCD test

After starting the test, the LCD buttons don't work, the test times out after 300 seconds, and reports "EUD Failed"
The BIG-IP must be rebooted to get the LCD buttons working again

Environment

  • iSeries Platforms
  • EUD ver 3.9.1
  • Big-IP 13.x
Cause

Can not execute the EUDSF3.9.1 Front Port Led Test on Big-IP iSeries platform.
This is due to Bug ID838713
Effecting EUDSF3.9.1 on iSeries platforms only
EUDSF3.9.1 is only required for iSeries i10010 where the test does not have this issue.

Recommended Actions
 

  • Use EUD ver. 3.7.0 or 3.8.0
    K93403310: Running EUD from a USB thumb drive
    --or--
  • Use Ver. 3.9.1 and avoid the LCD tests
    Administrator can safely ignore the EUDSF3.9.1 installed on their platform.
Additional Information

We see following in /var/log/eud.log:
ERROR: Timeout: LCD Mode waited 300 sec to finish test
ERROR: The start button on the LCD screen was not clicked
Test Complete: Front Port LED Test: FAILED
Test Complete: LED Test (interactive): FAILED
