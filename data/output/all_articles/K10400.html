Known Issue

This is the result of a known issue. SNMP queries to an ARX 500 may result in the following syslog error message:

 :1-1-ACM-2176:LIP_LIB-0-ERR-MSG3:: get_pip: Argument check failed.

These errors do not indicate a failure. The message is a result of a query for an SNMP OID not supported on the ARX 500 platform.

For example, when performing a walk of the SNMP agent, the error message is received when the ARX is queried for each of the following sysInfo OIDs:

.1.3.6.1.4.1.13544.2.6.3.1.1.1.1.3
.1.3.6.1.4.1.13544.2.6.3.1.1.2.1.3
.1.3.6.1.4.1.13544.2.6.3.1.1.3.1.3
.1.3.6.1.4.1.13544.2.6.3.1.1.4.1.3
.1.3.6.1.4.1.13544.2.6.3.1.1.5.1.3
.1.3.6.1.4.1.13544.2.6.3.1.1.6.1.3
.1.3.6.1.4.1.13544.2.6.3.1.1.7.1.3
.1.3.6.1.4.1.13544.2.6.3.1.1.8.1.3
.1.3.6.1.4.1.13544.2.6.3.1.1.9.1.3

F5 Product Development tracked this issue as ID 34961 and it was fixed in ARX version 5.1.0. For information about upgrading, refer to the ARX release notes.
