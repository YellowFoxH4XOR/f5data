Description

After upgrading to BIG-IP LTM 15.1.0 and later, the tmm.http.rfc.enforcement database key is no longer present on new systems, but may still appear in the configuration database on systems upgraded from older versions. The presence or absence of this DB key does not affect traffic processing, as it is obsolete and ignored by the system. RFC compliance enforcement is now controlled only by the "Enforce RFC Compliance" checkbox in the HTTP profile.

Environment

  • Product: BIG-IP LTM
  • Version: 15.1.0 and later
  • Feature: HTTP Profile — "Enforce RFC Compliance" setting
  • Condition: Systems upgraded from older BIG-IP versions where tmm.http.rfc.enforcement was previously configured

Cause

The tmm.http.rfc.enforcement DB key was deprecated starting in BIG-IP LTM 15.1.0. It may remain in the configuration database on upgraded systems as a legacy artifact, but it has no functional effect.

Answer/Recommended Actions

  • The tmm.http.rfc.enforcement DB key is obsolete in BIG-IP LTM 15.1.0 and later. Its presence in the configuration database is ignored by the system and has no effect on traffic processing or RFC enforcement.
  • There is no supported or necessary method to manually remove this DB key from the configuration database after upgrading to BIG-IP LTM 15.1.0 and later.
  • In BIG-IP LTM 15.1.0 and later, RFC compliance enforcement is controlled exclusively by the HTTP profile setting:
    • Use the "Enforce RFC Compliance" checkbox in the HTTP profile to enable or disable RFC enforcement.
  • No action is required regarding the legacy tmm.http.rfc.enforcement DB key. Its presence does not impact system behavior.

Additional Information

  • On systems that were not upgraded from older versions (fresh installations of 15.1.0 and later), the tmm.http.rfc.enforcement DB key is not present or settable — this is expected behavior.
  • On systems upgraded from older BIG-IP versions (14.1.x), the key may still appear in the configuration database as a legacy artifact. This is also expected and does not indicate a misconfiguration.
  • To ensure consistent RFC enforcement behavior across all systems, rely solely on the "Enforce RFC Compliance" checkbox within the HTTP profile.
