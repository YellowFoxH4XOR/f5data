Description

Description of SSL TPS versus connection rate

 

Environment

BIG-IP LTM v15.1.5

TPS

Connection rate

SSL

 

Cause

A a connection can have multiple SSL TPS within. SSL session resumes would be considered another transaction within the same TCP connection. Many SSL transactions can keep coming until either the client or server FIN/ACKs the connection. This is governed by the application for any HTTPS resources that require this.

 

Recommended Actions

For information about SSL transactions, refer to K6475: Overview of SSL TPS licensing limits
