K000137384: Generate BIG-IP APM report showing user access over a specific time range.

Type
Support Solution
Published
2023-10-26
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP APM: 14.X.X, 14.1.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.0, 14.0.X, 14.0.1, 14.0.0
Source
https://my.f5.com/manage/s/article/K000137384

Description

You would like to generate a list of users who have accessed a BIG-IP APM access policy within a specific time range.

Environment

  • BIG-IP APM

Cause

Avoid BIG-IP APM connectivity sessions (CCU) license restrictions by monitoring active user access.

Recommended Actions

  1. Log onto the BIG-IP APM Configuration utility.
  2. Go to Access > Overview > Access Reports
  3. Click Custom Reports
  4. Right click Create New Report
  5. Enter the report name.
  6. Select the details you would like to populate in the report.
  7. For example:
    In Available Fields > User > select the following items: Login user name
    In Available Fields > Resources > select the following items: Connectivity resources
    In Available Fields > Session > select the following items:  Session creation time, Bytes in, Bytes out, Access Profile
    In Selected Fields (Select reorder) order the selections as (or as you prefer) Login user name, Session creation time, Access Profile, Bytes in, Bytes out, Connectivity resources
  8. Click Save
  9. Click the report name and select Run Report
  10. Set Restrict by Times start date and time range
  11. Click Run Report
Note: You can save a CSV export of the report data for external processing by clicking Export to CSV File.
