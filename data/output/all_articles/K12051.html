Known Issue

This is the result of a known issue. If a virtual server that uses SNAT has the Source Port option set to Change, the BIG-IP system frequently reuses the same source ports when communicating with the destination servers. As a result, the BIG-IP system may reuse a source port before the destination server is ready to accept another connection from that source port. For example, the destination server may still be in a TIME_WAIT state from a previous connection when the BIG-IP system attempts a new connection using the same source port.

F5 Product Development tracked this issue as ID 243899 (formerly CR138303) and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, WebAccelerator, APM, or Edge Gateway release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
