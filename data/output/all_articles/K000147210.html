Description

This article explains the required format for the connection string when integrating F5 Distributed Cloud (XC) with Azure Sentinel SIEM for log streaming.
Customers configuring the Global Log Receiver (GLR) to send logs to Azure Sentinel need to provide a connection string in a specific format.

Environment

  • F5® Distributed Cloud
  • Integration with Azure Sentinel SIEM
  • Configure Global Log Receiver

Cause

None

Answer/Recommended Actions

The required connection string format is:

DefaultEndpointsProtocol=[http|https];AccountName=<AccountName>;AccountKey=<AccountKey>
  • Azure should provide the connection string in this exact format.
  • Replace <AccountName> and <AccountKey> with your actual Azure storage account details.
  • Use either http or https as appropriate for your environment.
