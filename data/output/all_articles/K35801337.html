Known Issue

The Configuration utility may produce an error message regarding bad characters.

This issue occurs when the following condition is met:

  • You create or modify one of the following HTTP service profile fields and include the tilde character (~) as part of the context:

    • Encrypt Cookies
    • Response Headers Allowed

Impact

When using the Configuration utility, users cannot add the tilde character (~) to certain HTTP service profile fields.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you use the Configuration utility to modify the Response Headers Allowed or Encrypt Cookies HTTP service profile fields, then you enter the tilde character (~) as part of the context and click Finished, the system displays error messages similar to the following examples:

    Some fields below contain errors. Correct them before continuing.

    Bad Characters. Only the following special characters are allowed: dash and underscore (-_). Multiple arguments should be separated by spaces.

  • When you use the Traffic Management Shell (tmsh) to modify the Response Headers Allowed or Encrypt Cookies fields, adding the tilde character (~) is successful.

Workaround

To work around this issue, you can use the tmsh utility to create or modify HTTP service profile fields that contain the tilde character (~).

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
