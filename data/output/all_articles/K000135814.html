Description

Nginx Controller Cluster installation procedure with NFS server for Postgres DB, backups and logs.

Environment

  • NFS server
  • Nginx Controller

Cause

 Instruction for installation Nginx Controller Cluster with NFS server for Postgres DB, backups and logs.

Recommended Actions

  • Preparation steps before install Nginx Controller

  1. Install NFS server according the procedure
  2. Create and install Ubuntu version 20.04 for Nginx Controller
  3. Stop apache2 servise to release port 80
sudo systemctl stop apache2
sudo systemctl status apache
  1. Install nfs-common, jq packages
sudo apt update
sudo apt install nfs-common
sudo apt-get install jq
  1. Add to /etc/hosts IP and hostname for NFS server
e.g.
vi /etc/hosts
127.0.0.1 localhost
10.155.207.26 nfs-server-ubuntu-server
  1. Download Nginx Controller package from MyF5 portal

  • Install Nginx Controller

  1. Upload Nginx Controller package (controller-installer-3.22.x.tar.gz) to admin user home folder and unpack package
cd ~
tar xvf controller-installer-3.22.x.tar.gz
  1. Start installation process
cd ~/controller-installer
./install.sh
