K13060: ARX 1500 and 2500 platform will reboot when enabling an interface that is a member of VLAN 4009

Known Issue

After enabling an interface, the ARX system may continuously reboot until the three reboot bounce limit is reached.

This issue occurs when all of the following conditions are met:

  • The ARX software is running on the ARX 1500 or 2500 platform.
  • The enabled interface is a member of VLAN 4009.

Impact

The ARX system services will be unavailable.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  •  Enabling the interface will fail with the following error message:

    A system failure occurred requiring this switch to reboot. Reason: Resource 'RON Route Table Manager' has failed/exited.

  • The ARX system will continuously reboot until the system reaches the three-reboot bounce limit.

Workaround

You can prevent this issue or recover from this issue by performing the appropriate procedure:

Impact of workaround: None

Preventing this issue

To prevent this issue, you can use a VLAN ID lower than 4009 when configuring the VLAN.

Note: The range of supported VLAN IDs is 1 to 4009.

Recovering from this issue

If your ARX system has encountered this issue, you must remove the VLAN 4009 configuration, and configure the interface to use a VLAN ID lower than 4009. To do so, perform the following procedure:

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable

  3. Enable configuration mode by typing the following command:

    config
  4. Delete the interface configuration for VLAN 4009 by typing the following command:

    no interface vlan 4009

  5. Delete VLAN 4009 by typing the following command:

    no vlan 4009

  6. Create the desired VLAN using the following command syntax:

    vlan <vlan_ID>

    Replace <vland_ID> with the desired VLAN ID (less than 4009).

    For example:

    vlan 4008

  7. Configure the desired interface to be a member of the VLAN using the following command syntax:

    members <slot/port>

    Replace <slot/port> with the desired interface port.

    For example:

    members 1/3

  8. Exit the VLAN configuration mode by typing the following command:

    exit

  9. Enable the interface configuration mode by typing the following command syntax:

    interface vlan <vlan_ID>

    Replace <vland_ID> with the VLAN ID configured in Step 6.

    For example:

    interface vlan 4008

  10. Specify an IP address for the interface by typing the following command syntax:

    ip addresses <x.x.x.x> <m.m.m.m>

    Replace <x.x.x.x> with the IP address, and <m.m.m.m> with the IP mask for interface.

    For example:

    ip address 192.168.10.11 255.255.255.0

  11. Enable the interface by typing the following command:

    no shutdown

  12. Exit the interface configuration mode by typing the following command:

    exit
