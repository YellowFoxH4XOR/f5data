Known Issue

This is the result of a known issue. Under rare conditions, the BIG-IP system may abort slow client connections when transferring large documents.

F5 Product Development tracked this issue as CR116570 and it was fixed in BIG-IP version 10.0.1. For information about upgrading, refer to the BIG-IP LTM, GTM, Link Controller, ASM, PSM, WebAccelerator, or WOM release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.0.0-5460.0-HF1, which has been issued for BIG-IP version 10.0.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about installing version 10.x hotfixes on systems with a partitioned disk-formatting scheme, refer to K9819: Installing a BIG-IP version 10.x hotfix on a partitioned system.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.
