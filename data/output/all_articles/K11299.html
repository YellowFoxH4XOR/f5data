Known Issue

This is the result of a known issue. When a client sends two or more requests over the same TCP connection to the BIG-IP ASM before the server response and both requests are blocked by the policy, the second request will be processed by the BIG-IP ASM as a new connection that does not have a valid server context. As a result, when the BIG-IP ASM bd process calls the SSL::disable iRule command to disable server-side SSL processing, the following TCL error message is logged to the /var/log/ltm file:

01220001:3: TCL error: Unknown error (line 1)     invoked from within "SSL::disable serverside"

Note: The issue does not affect BIG-IP ASM functionality.

F5 Product Development is tracking this issue as ID 327801 (formerly CR136687).

This issue does not affect the BIG-IP ASM version 10.x software branch.
