K000141334: Compatibility issues with Juniper and some Arista switches when connected to an F5 device using SFP transceivers (OPT-0010-00 and OPT-0011-00).

Description

Compatibility issues when connecting a switch to an F5 device, as the i4000/i2000 series SFP transceivers (OPT-0010-00 and OPT-0011-00) work with older i4000/i2000 series devices but not with the newer i4600/i2800 series, and this problem has been observed with Juniper QFX5120-48Y and EX4400-48T switches as well as some Arista switches

Environment

  • i4600
  • i2600
  • OPT-0010-00: Removable 1.25GB 850NM SFP optics
  • OPT-0011-00: Removable 1.25GB 1310NM SFP optics
  • Juniper switch models QFX5120-48Y, EX4400-48T
  • Some Arista switch models

Cause

Unknown communication error occurs between this SFP (OPT-0010-00 && OPT-0011-00) and various Juniper / Arista enterprise level switches

Recommended Actions

Use a 1Gb OPT-0051-XX copper SFP or use a branded multi-mode 10Gbit SFP+ like OPT-0016-XX. This is being tracked by ID1311113
