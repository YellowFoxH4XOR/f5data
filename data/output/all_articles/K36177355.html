Description

Edge Client Windows Logon Integration allows customers to pass the Windows Login details to the Edge Client, so the User does not need to login a second time. However, the user is still required to supply the Login Details manually to the Edge Client.
  • You may see an error similar to this in the Edge Client log file logterminal.txt:

CStandaloneProfile::IsWinlogonSessionReuseEnabled, Dynamic profile not trusted
 

Environment

  • BIG-IP APM
  • Windows Logon Integration configured
  • User machine with a Group Policy assigned
  • checking Internet Explorer Settings shows Security Tab is greyed out 

Cause

The Group Policy assigned to the user's machine blocks access to the Internet Explorer Security Page. This can block the login details from being passed to the Edge Client. In Group Policy Editor we see this as:

Administrative Templates/Windows Components/Internet Explorer/Internet Control Panel
Policy = "Disable the Security page"
Recommended Actions

Microsoft announced the end of support for Internet explorer on June 15, 2022 and so support for it has also ended on BIG-IP APM. You should review your existing Group Policies that sets Internet Explorer settings to use alternative supported configurations.

The Group Policy needs to be disabled or set as not configured. You can run the following command on the user machine's terminal to verify:

gpresult /Scope User /v

the output will be similar to the following:

GPO: Software: Internet Explorer User Settings
                Folder Id: Software\Policies\Microsoft\Internet Explorer\Control Panel\SecurityTab
                Value:       1, 0, 0, 0
                State:       Enabled
 
Enabled state means that the Security Tab is disabled.
