Description

After a thermal shutdown, on some hardware platforms with specific BIOS or AOM versions the LCD may prompt the admin to confirm that the temperature has returned to normal before proceeding with the normal boot up sequence.

 

Environment

BIG-IP I2600 (C117)

 

Cause

This is a safety feature on affected BIOS versions on some HW platforms to prevent automatic power-on after AC failure from continuously cycling the box into a thermal shutdown state, for the case when an environmental factor leading to thermal shutdown has not yet been resolved.

 

Recommended Actions

If the admin is sure that the environmental factor has been dealt with and the box is now within normal safe operating temperatures, they should select Yes to continue to boot up normally. There should be no other adverse effects of this prompt.
