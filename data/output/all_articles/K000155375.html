K000155375: Tomcat constantly restarting due to full java connection pool

Type
Support Solution
Published
2025-09-16
Updated
2025-09-16
Applies to
  • BIG-IP
  • BIG-IP LTM
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K000155375

Description

You may observe GUI cannot be accessed due to tomcat constantly restarting. In the /var/log/tomcat/catalina.out, you could find the following message before tomcat restarts

Error trying to get a connection in connection pool java.lang.NullPointException
current connection size = 10
 

Environment

  • BIG-IP

Cause

The abnormal REST framework caused the Java connection pool to reach its maximum capacity, which consequently led to a Tomcat restart

Recommended Actions

To restore the REST framework to normal status, execute the following commands. 

clear-rest-storage 

 

Additional Information

None.
