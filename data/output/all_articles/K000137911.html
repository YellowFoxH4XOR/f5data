Description

You've disabled the Virtual Server address immediately while you are pinging it, the ping didn't drop even when it has been disabled. What might cause this?

 

Environment

  • BIG IP LTM
  • Using Ping to test the VIP

Cause

As expected

Recommended Actions

Set 'ICMP ECHO' to disabled in virtual address list

Additional Information

By default, virtual servers are always pingable, that doesn't mean it will still allow traffic, however. You can see the settings in the GUI under:

Local traffic > Virtual servers > virtual address list

Click on the virtual address matching your virtual server IP.
Under 'Configuration' part, you can set 'ICMP echo' to 'disabled', in case you never want to be able to ping the virtual server.
By default, it is set to "always".
