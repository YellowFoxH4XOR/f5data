Issue

Error Message

01071912:3: <command> in rule (<name>) requires an associated <object> profile on the <object> (<name>)

In this error message, note the following:

  • <command> is the iRule command experiencing a configuration related issue
  • <name> is the name of the iRule
  • <object> is the missing, but required BIG-IP system configuration object
  • <object> is the BIG-IP configuration object to which the iRule is applied
  • <name> is the name of the configuration object to which the iRule is applied

For example:

01071912:3: UDP::payload in rule (/Common/irule_example) requires an associated UDP profile on the virtual-server (/Common/example)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • You are attempting to apply an iRule to a BIG-IP system configuration object, such as a virtual server or wide IP.
  • The system configuration object is missing one or more additional configuration objects necessary for the iRule to execute.

For example, you must apply an iRule using the UDP::payload command to a virtual server with an associated UDP profile.

Impact

There is no impact; this message should supply enough information to resolve the issue.

Recommended Actions

None
