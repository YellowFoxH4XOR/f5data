Known Issue

The mcpd process on all secondary blades restarts on a VIPRION system. This issue occurs when all of the following conditions are met:

  • The affected VIPRION system has two or more blades installed.
  • The affected VIPRION system is managed by an Enterprise Manager system running version 1.8.0 and later.
  • The Enterprise Manager system is configured to enable Statistics Collection for the affected VIPRION system.

Impact

The VIPRION system may temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H380342 on the Diagnostics > Identified > Medium page.
  • Traffic processing is disrupted temporarily on the affected VIPRION system.
  • The mcpd process on all secondary blades restarts and logs error messages to the /var/log/ltm file. For example:

    01070734:3: Configuration error: Invalid folder name (/[All])
    01070734:3: Configuration error: Configuration from primary failed validation: 01070734:3: Configuration error: Invalid folder name (/[All])

  • The Availability for the secondary blades from the tmsh show sys cluster command report as unavailable. For example:

Workaround

To work around this issue, you can disable Statistics Collection for the affected VIPRION system on the Enterprise Manager system. To do so, perform the following procedure:

Impact of workaround: No statistics will be collected for the affected VIPRION system.

  1. Log in to the Enterprise Manager Configuration utility.
  2. Click Enterprise Management.
  3. Click Devices.
  4. Click Device List.
  5. Click the name of the affected VIPRION system.
  6. Click Statistics.
  7. Click Configure.
  8. For the Collect Statistics Data menu, select Disabled.
  9. Click Save Changes.
