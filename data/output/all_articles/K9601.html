Known Issue

This is the result of a known issue. The bigpipe shell utility displays unavailable options for the bigpipe syslog remote server command. The invalid options are displayed when using tab completion from the bigpipe shell utility.

For example, when configuring a remote syslog server using the bigpipe shell utility, the bigpipe shell utility displays the following options for configuring a remote syslog server:

  • <ip addr>
  • any
  • any6
  • none
  • show
  • *

However, the following command options are invalid:

  • any
  • any6
  • *

F5 Product Development is tracking this issue as ID 249191 (formerly CR104466).
