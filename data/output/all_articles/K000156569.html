Description

When using the iStats feature in BIG-IP iRules, the following error may be observed in the logs:

01220001:3: TCL error: /Common/iRule_example <HTTP_REQUEST> -
Error: iStats key has an odd number of elements: 'class.object' (line 1) 
invoked from within "ISTATS::set "class.object" $count" 

This error occurs when the ISTATS::set command is used with an incorrectly formatted key.

Environment

  • BIG-IP LTM
  • Configuration: iRule using ISTATS::set to expose custom statistics

Cause

The ISTATS::set command requires the key to be composed of an even number of whitespace-separated elements, following this format:

class object measure_type measure_name

Using a single string with periods or underscores (e.g., "class.object") is treated as a single element, resulting in an odd number of elements and triggering the error.

Recommended Actions

  • Use the correct key format for ISTATS::set by splitting the key into at least four whitespace-separated elements:

ISTATS::set "class object measure_type measure_name" <value>

  • For example, to track active sessions:

ISTATS::set "classname global type sessions" $count

  • classname = class
  • global = object (can be customized as needed)
  • type = measure type (alternatives include counter or string)
  • sessions = measure name
  • Values for these statistics $count should be integers and do not require quotes.
