Known Issue

The DNAT utility (dnatutil) may report incorrect reverse mappings for F5 BIG-IP Carrier-Grade NAT (CGNAT) virtual server connections.

This issue occurs when the following condition is met:

  • The platform contains two High-Speed Bridge (HSB) devices.

For platforms with two HSB devices, the number of HSBs for TMM0 is incorrectly set to 1 and the number of HSBs for all other Traffic Management Microkernels (TMMs) is correctly set to 2.

You can determine if your platform contains two HSB devices by using the following Traffic Management Shell (tmsh) command:

tmsh show sys hardware

For a system with two HSB devices, the output of this command will list the devices similar to the following example:

Name hsb_lbb0
Type net
Model F5 High Speed Bridge LBB device
Parameters -- --
version Build: 1.9.23 lab 5

Name hsb_lbb1
Type net
Model F5 High Speed Bridge LBB device
Parameters -- --
version Build: 1.9.23 lab 5

Impact

dnatutil reports incorrect reverse mappings for BIG-IP CGNAT addresses processed by TMM0.

As a result of this issue, you may encounter one or more of the following symptoms:

  • dnatutil reports incorrect reverse mappings.
  • The nhsbs column of the tmctl command output indicates 1 HSB for TMM0 and 2 HSBs for all other TMMs, similar to the following example:
