Description

APM Session logs not showing the user State, Country & Region Code.

Environment

  • APM
  • HSL Logging

Cause

When the Log setting for the Access policy is configured with Remote HSL and the HSL pool members are down, the APM session logs are not printing the first line which contains the client details such as client IP, location, etc.

The 'missing' log line looks similar to this:
May 30 04:23:36 APM notice tmm4[17904]: 01490506:5: /Common/access_vpn:Common:a77dcca8: Received User-Agent header: Mozilla%2f5.0%20(Windows%20NT%2010.0%3b%20Win64%3b%20x64)%20AppleWebKit%2f537.36%20(KHTML%2c%20like%20Gecko)%20Chrome%2f78.0.3904.108%20Safari%2f537.36.
 

 Recommended Actions

  1. Make sure the HSL pool members are UP or remove HSL config from the APM log settings. 

Additional Information

 None.
