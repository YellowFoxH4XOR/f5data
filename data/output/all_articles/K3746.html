Topic

Starting in BIG-IP version 4.5.11 and 4.6.3, you can use the bigpipe vlan fdb show command to display the forwarding database arranged by VLAN.

Workaround

For BIG-IP versions 4.0 through 4.5.10 and 4.6 through 4.6.2, the output of bigpipe vlan fdb show command is not arranged by VLAN. This can make it difficult to read when the configuration contains several VLANs. To work around this issue, filter the output of the bigpipe vlan fdb show command to display data for specific ports that are members of a particular VLAN. To do this, use the following command syntax:

bigpipe vlan fdb show |grep <port>

For example:

bigpipe vlan fdb show |grep 1.1

Using this filter, you can view all of the ports that are members of a particular VLAN.
