Issue

In rare instances, a BIG-IP 9.4.x system may log error messages to the /var/log/ltm file that appear similar to the following example:

bigstart_wb[15916]: 010f0001:3: Could not open lockfile: No such file or directory

The error message is benign and may be safely ignored.
