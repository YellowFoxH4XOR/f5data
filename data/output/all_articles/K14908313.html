Description

In BIG-IP ASM 15.x and later, the following sub-violations under the HTTP protocol compliance failed violation in the microservice configuration are no longer present:

  • Unparsable request content
  • No Host header in HTTP/1.1 request
  • Bad host header value
  • Multiple host headers

Environment

  • BIG-IP ASM
  • Security policy violations
  • microservices

Cause

The sub-violations in question are unlearnable in the context of a microservice as the bd daemon is unable to detect them for a microservice and therefore cannot trigger.

To improve functionality of the microservice override, the violations have been removed as the enforcer did not support it.

Recommended Actions

None

Additional Information

For more information about bd and other ASM daemons, refer to K14020: BIG-IP ASM daemons (11.x - 17.x).
