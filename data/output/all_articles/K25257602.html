Description
I've tried to change the limitalert value to 10 but it doesn't seem to work with the following command:

tmsh modify sys db platform.diskmonitor.limitalert.shared_vmdisks value 10

Environment

  • vCMP 
  • VirtualDisk
  • Viprion

Cause

Customer has used the wrong DB key

Recommended Actions

Use the following command instead:

tmsh modify sys db platform.diskmonitor.limitalert.vmdisk value 10

Additional Information

K8865: Overview of the diskmonitor utility
