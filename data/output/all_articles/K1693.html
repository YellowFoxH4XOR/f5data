Topic

P3P1.0 is a specification developed by the W3 Consortium in the P3P Specification Working Group. The P3P1.0 specification is a way for web sites to state their privacy practices in a standard format that can be automatically retrieved and easily interpreted by user agents (browsers that support P3P). This enables user agents to formulate automated decisions based on these standard practices.

Note: This solution assumes you have a functioning P3P policy (and policy reference) in place on your web servers. If you do not have a current P3P policy, there are several commercial applications that you can use to generate one. For more information about setting up a P3P policy and reference for your web server, contact a web server vendor.

Although P3P is not specific to HTTP cookies, cookies are the only area of P3P that directly involves the BIG-IP, therefore only the P3P information regarding cookies is discussed in this solution. For example, P3P1.0 allows a browser to automatically accept certain web site content (such as, cookies) based on the security policy of specific web sites.

HTTP server response header example

Following is an HTTP server response header example that includes a P3P policy and cookie inserted by the BIG-IP:

HTTP/1.1 200 OK
Set-Cookie: BIGipServerMyCookieName=184549386.20480.0000; 
expires=Wed, 20-Mar-2002 12:22:56 GMT; path=/
Server: Microsoft-IIS/4.0
p3p: policyref='http://www.mysite.com/w3c/p3p.xml', 
CP='ALL DSP COR TAIi OUR IND STA'

For BIG-IP to insert cookies in the policy reference, you must configure the p3p.xml file so that one of the following is true:

  • All cookies are covered under the security policy.
  • Specific cookies for each BIG-IP pool are covered under the security policy.

Shorthand policy reference example

Following is an example of a shorthand policy reference that includes all web site content and all cookies:

<META xmlns='http://www.w3.org/2000/12/P3Pv1'>
<POLICY-REFERENCES>
    <POLICY-REF about='/w3c/policy.p3p'>
      <INCLUDE>/*</INCLUDE>
      <COOKIE-INCLUDE/>
    </POLICY-REF>
</POLICY-REFERENCES>
</META>

Full policy reference example

Following is an example of a full policy reference that includes all content and all cookies:

 
<META xmlns='http://www.w3.org/2000/12/P3Pv1'>
<POLICY-REFERENCES>
    <POLICY-REF about='/w3c/policy.p3p'>
 <INCLUDE>/*</INCLUDE>
 <COOKIE-INCLUDE name='*' value='*' domain='*' path='*'/>
    </POLICY-REF>
</POLICY-REFERENCES>
</META>

Following is an example of a policy reference that only includes a BIG-IP cookie for a pool named MyPoolName. Notice that the pool name is prefixed with BIGipServer. This is true for all cookies inserted by the BIG-IP:

<META xmlns='http://www.w3.org/2000/12/P3Pv1'>
<POLICY-REFERENCES>
    <POLICY-REF about='/w3c/policy.p3p'>
	<INCLUDE>/*</INCLUDE>
	<COOKIE-INCLUDE name='BIGipServerMyPoolName' value='*' domain='*' path='*'/>
    </POLICY-REF>
</POLICY-REFERENCES>
</META>
