K68414359: Import of ASM to BIG-IQ fails with error: Failed calculating configuration differences; reason: Unable to post difference subcollection results; too many differences

Type
Support Solution
Published
2021-05-19
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K68414359

Description

  • Unable to discover/import ASM from BIG-IQ
  • The following error message can be seen on GUI:
     Failed calculating configuration differences; reason: Unable to post difference subcollection results; too many differences
  • You also observe that /var/log/restjavad.0.log has logged the below for worker AsmDifferenceTaskWorker:
    Difference result for bigip.example.com with item count 50000 and size 178700520 (170 MB) exceeds total size limit of 134217728 (128 MB); cannot handle


Environment

  • BIG-IQ CM running software version 7.x, 8.x
  • Importing of BIG-IP ASM Service with large policies

Cause
Configuration import failure occurs when several large policies are imported for the same device and exceeded the total size limit of 128MB. 

Recommended Actions


For the error during import, increase the size for difference comparison in ASM preferences. 

  1.  Run this command from BIG-IQ console to increase the default value from 128MB to 256MB.
    From bash:
    # restcurl -X PATCH /cm/asm/preferences/diff-parts-limit-mb -d "{value: 256}"
     
  2.  Re-discover and  re-import the ASM configuration.

Additional Information

To avoid such issue in the future, it is recommended to discover/import ASM from the managed ASM more frequently to avoid large differences of the polices between CM and ASM.
