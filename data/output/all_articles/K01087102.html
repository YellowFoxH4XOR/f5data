K01087102: Cannot find the logon.inc file when customizing the APM profile

Type
Support Solution
Published
2021-10-22
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 16.X.X, 16.1.X, 16.0.X, 15.1.X, 15.0.X, 15.1.0, 15.0.1, 15.0.0, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 15.X.X, 16.0.0, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 16.0.1
Source
https://my.f5.com/manage/s/article/K01087102

Description
When customize the logon page using Advanced Customization, however, cannot find the logon.inc file even there is a logon page in the APM profile.

Environment

  • BIG-IP APM access policy with logon page
  • Advanced Customization

Cause
From v15, a new option 'Customization Type' is introduced when creating APM profile and the default value is "Modern"

Recommended Actions

  1. Change the 'Customization Type' from "Modern" to "Standard" when creating a new APM profile; And for existing APM profile(s), the 'Customization Type' is unchangeable

Additional Information
None
