K73277322: BIG-IQ must create the logging nodes and pool on BIG-IP APM

Description

When enabling APM logging in BIG-IQ, it fails.

  • Create nodes and pool that reference the BIG-IQ DCD's on the BIG-IP APM as per the guide.
  • Logging setup fails with a similar error to:
  • [ERROR][22 Sep 2021 10:01:59 PDT][/cm/access/tasks/remote-log-config/cca1edf6-7db7-42ee-a5a3-ebe21bf2cbf3/worker AccessRemoteLogConfigTaskWorker] Exception java.net.ProtocolException: status:400, body:{"code":400,"message":"transaction failed:0107176c:3: Invalid Node, the IP address x.x.x.x already exists.","errorStack":[],"apiError":2}

Environment

  • BIG-IQ with DCD cluster and APM managed devices
  • Setting up APM logging on DCD

Cause

When following the setup guide, it appears to suggest a manual creation of the DCD nodes and pool on the BIG-IP APM

Recommended Actions

  1. Delete/remove the DCD nodes/pool that were manually configured on the BIG-IP APM
  2. Enable APM logging again on the BIG-IQ DCD.
  3. DCD nodes and pool are auto-created on the BIG-IP APM with the naming convention of /Common/access-remote-syslog-node
