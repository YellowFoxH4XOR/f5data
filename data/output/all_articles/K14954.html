Topic

This article covers the BIG-IP software build number schema. You will see this versioning in the ISO file and the output of tmsh show sys version.

Description

The build number consists of three mandatory components and one optional component.

The digits in the build include:

  • Hotfix rollup level. Zero denotes no hotfix installed. For example, 1 denotes that hotfix 1 is installed.
  • Engineering hotfix index. Zero denotes no engineering hotfix installed.
  • Primary build number. This is the equivalent to the build number in previous BIG-IP versions and is incremented with every hotfix and engineering hotfix release.
  • Point build number (optional).

For example, the following is the output from the tmsh show sys version command:

Sys::Version
Main Package
Product BIG-IP
Version 17.1.1.1
Build 0.0.2
Edition Point Release 1
Date Tue Nov 28 23:06:08 PST 2023

Additionally, BIG-IP ISO image files will contain all components of both the version and build numbers.

For example:

BIGIP-17.1.1-0.0.6.iso
BIGIP-17.1.1.1-0.0.2.iso
