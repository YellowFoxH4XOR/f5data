Known Issue

A local traffic policy may fail to decompress HTTP traffic.

This issue occurs when all of the following conditions are met:

  • The virtual server is configured with a local traffic policy that contains a decompress action.
  • The virtual server processes compressed HTTP traffic.

Impact

The BIG-IP system fails to decompress HTTP traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP LTM system fails to decompress gzipped HTTP requests.

Resolution

Status

F5 Product Development has assigned ID 419217 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can implement an iRule to execute the DECOMPRESS::enable and DECOMPRESS::disable commands.
