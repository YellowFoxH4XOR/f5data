Issue

Description

Mac OS browser appears to freeze on initialization, then the the browser window closes unexpectedly.

You may observe the following error messages in the ~/Library/Logs/F5Networks/vpn.log file:

2019-03-15,11:54:17:340, 2432,138519,, 1, /BrowserController.cpp, 696, void f5::qt::BrowserController::ReportErrorToUser(bool, const QString &, const QString &, const QString &), Failure occurred:, Failed to establish tunnel /Common/Split, Connection to remote server cannot be established

Environment

  • BIG-IP APM Network Access in Full or Split Tunnel mode
  • macOS browser VPN

Cause

During the VPN connection setup, an intermediate device or BIG-IP sends a TCP reset (RST).

Recommended Actions

  • Enable TCP RST logging on the BIG-IP system to determine if the BIG-IP system initiated the TCP RST. For more information, refer to K13223: Configuring the BIG-IP system to log TCP RST packets.
  • Perform a simultaneous network packet capture on the BIG-IP system and the Mac client to determine the cause of the network reset. For more information, refer to K50501944: Gathering data to troubleshoot BIG-IP APM Network Access tunnels (11.x).
