Known Issue

The Configuration utility network map displays incorrect host names for pool members.

This issue occurs when all of the following conditions are met:

  • Pool members are defined as fully-qualified domain name (FQDN) nodes.
  • In the Configuration utility network map, you hover the mouse over FQDN pool members.

When configuring pool members on the BIG-IP system, members can be defined by either IP address or FQDN. When hovering the mouse over FQDN pool members, in the Configuration utility network map, multiple members may incorrectly display the same FQDN. This is a cosmetic issue, and does not affect traffic processing. Pool members defined by IP address are not affected.

Impact

None. This is a cosmetic issue only.
