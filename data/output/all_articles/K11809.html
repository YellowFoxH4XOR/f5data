Known Issue

This is the result of a known issue. Restarting the pvad process on a PVA capable platform causes the system to view the returning UDP packets as containing bad checksums.

This behavior will cause pvad to drop UDP packets for any configured UDP monitor.

F5 Product Development tracked this issue as ID 226409 (formerly CR141426), and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP LTM or GTM release notes.

Additionally, this issue has been fixed in BIGIP-10.1.0-3402.0-HF2, which has been issued for BIG-IP 10.1.0, and Hotfix-BIGIP-10.2.0-1755.1-HF1 issued for version 10.2.0. You may download hotfixes or later versions of hotfixes from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
