Known Issue

This is the result of a known issue. If you use the Configuration utility to disable SNMP traps, the authtrapenable entry in the snmpd.conf file is set to 0.

SNMP traps are disabled by setting the value to 2; 0 is not a valid value. This invalid value prompts BIG-IP and 3-DNS to log the following error to the /var/log/snmpd.log file:

/etc/snmpd.conf: line 28: Error: authtrapenable must be 1 or 2

F5 Networks Product Development tracked this issue as CR26610, CR41819, and CR41820.

Workaround

To work around this issue, perform the following steps:

  1. Log in to the command line.
  2. Using a text editor, such as vi or pico, edit the /etc/snmpd.conf file.
  3. Locate the line that begins with authtrapenable.
  4. Change the line to appear as follows:

    authtrapenable 2

  5. Save the file and exit the editor.
  6. Restart bigsnmpd, by typing the following command:

    bigstart restart snmpd
