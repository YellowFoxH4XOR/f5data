Description

After reloading the configuration with the command tmsh load sys config the unit suddenly reboots.

You observe log messages similar to below in the /var/log/ltm file

notice chmand[7086]: 012a0005:5: removed /var/db/mcpdb.* FPGA current disk firmware updated to: /L7_PERFORMANCE_FPGA type: 2
notice chmand-fpga-pnp[23796]: FPGA firmware upgrading...
warning mprov.postcommit[24129]: Reboot is required for [ fpga ]
Warning mprov:18972:[18972]: 'mprov.postcommit requested a reboot'

 

Environment

  • iSeries platform
  • TurboFlex Profile configured

Cause

A combination of factors can lead to the issue:

1. The FPGA firmware type prior to the configuration reload is not matching the configured TurboFlex Profile.

ID1011217   can be a reason for the unit getting into this state.

In the example below, the TurboFlex Profile type is 'turboflex-security' whereas the FPGA firmware type is 'standard-balanced-fpga', therefore not matching.

sys turboflex profile-config {
type turboflex-security 
}
sys fpga firmware-config {
type standard-balanced-fpga
}

2. The configuration has not been reloaded or the unit rebooted since the last upgrade.

Recommended Actions

  •  There is nothing to do on the affected unit, the FPGA firmware should have been upgraded correctly as part of the reboot.
  • Upgrading to a version where ID1011217 is fixed should limit the chances of a similar issue affecting other devices in your environment.
