Topic

The Configuration utility uses CGI scripts for various display settings. For security reasons, the webserver process on F5 Networks products is usually running as the user, nobody; however, the majority of the CGI files need to execute commands as the user, root. For the commands to execute as root, a special UNIX file execution flag (the SUID bit) must be set on the CGI script files.

If the SUID bit becomes unset, you will receive a display error because the script will run as the user, nobody, rather than as the user, root. This will cause problems in the Configuration utility, because the appropriate page elements cannot be displayed.

To troubleshoot the display issue, check the following in the CGI files:

  • Verify that the owner of the file is root
  • Verify that the SUID bit is set

Both of these items must be true in order for the CGI file to work correctly within the Configuration utility.

Following are the specific files, per product, that must have the SUID bit set and be owned by user, root.

Important: Some CGI files should not have the SUID bit set and should not be owned by the user, root. For this reason, do not change every file with a *.cgi extension.

BIG-IP

Version 4.5 through 4.6.4

  • /usr/local/www/bigipgui/bigconf.cgi
  • /usr/local/www/bigipgui/ftcw.cgi
  • /usr/local/www/seeit/mgmt/bigipprovider.cgi

Version 4.1.1 through 4.3 PTF-02

  • /usr/local/www/bigipgui/ac2000.cgi
  • /usr/local/www/seeit/mgmt/bigipprovider.cgi
  • /usr/local/www/bigipgui/bigconf.cgi

Version 2.0 through 4.1

  • /var/f5/www/seeit/ac2000.cgi

3-DNS Controller

Version 4.2 though 4.6.4

  • /usr/local/www/3dns/3dnsconf.cgi
  • /usr/local/www/3dns/mgmt/3dnsprovider.cgi

Checking the SUID bit

To determine if the SUID bit is set on the specified files, type the following command from the directory in which the CGI file is located:

ls -la

Example

The /usr/local/www/bigipgui/bigconf.cgi file mode should appear as follows:

-rwsr-xr-x 1 root wheel 1712128 May 15 15:25 bigconf.cgi*

The lowercase s in the executable bit indicates that when the file executes, it will run as the file's owner. Since the owner of this file is root, the file will properly execute as the user, root.

Setting the SUID bit

If the SUID bit is not set for the file, you will need to reset it. To do this, use the chmod command with file mode settings of 4755 (which means that users can read and execute, but only the owner can write).

Important: If used improperly, the chmod command can cause problems. For more information about chmod, refer to the UNIX man pages or contact F5 Networks Technical Support.

Example

chmod 4755 /usr/local/www/bigipgui/bigconf.cgi

Changing the file owner

If the file's owner is not root, use the chown command to set the file owner to root. For example:

chown root:wheel /usr/local/www/bigipgui/bigconf.cgi

Important: If used improperly, the ch chown command can cause problems. For more information on the chown command, refer to the UNIX man pages or contact contact F5 Networks Technical Support.

This command will set the owner for the bigconf.cgi file to root and set the group to wheel.
