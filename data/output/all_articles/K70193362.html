Description

  • The Administrator wants to setup Access Policy where on AD / LDAP and other Authentication failures on fallback go to Local DB Auth.
  • But users never reach Local DB Auth agent. Local authentication doesn't take place for the user.

Environment

  • Authentication 
  • Local DB

Cause

  • Generally, AD / LDAP and other Authentication agent have option "Max Logon Attempts Allowed" set to 3. This is the default value
  • The user needs to fail remote authentication 3 times in order to be passed to Local DB Auth agent

Recommended Actions

  • Change "Max Logon Attempts Allowed"  to 1 in the AD / LDAP Authentication agent within the Access Policy
