Description
You would like to consider remove TACACS+ remote authentication from BIGIP.
Newly created user on BIGIP will be authenticated locally instead of TACACS+.

Environment

  • BIGIP
  • TACACS+
  • Remote authentication

Cause
None

Recommended Actions

  1. Login into BIGIP GUI
  2. GUI > System > Users > Authentication
  3. Scoll down to bottom then External Users > click Change... button
  4. Then Authentication: > User Directory > Local > Click Finished button
  5. Newly create user on BIGIP will be authenticated locally
