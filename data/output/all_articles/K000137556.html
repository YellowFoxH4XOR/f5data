Description

BIG-IP upgrade failed, with errors similar to the following observed in /var/log/liveinstall.log:

info: Loading ASM configuration...
info: mkdir /ts/var/install//ts/dms/policy/policy_versions/128: No space left on device at /usr/local/share/perl5/F5/Utils/File.pm line 263.
info: ERROR: Failed during loading ASM configuration.
info:
info: WARNING: There were one or more errors detected during installation.
info:          Check the error messages and take the proper actions if needed.
info: ERROR: UCS installation failed.
info: Operation aborted.
info: >----
Terminal error: UCS application failed; unknown cause.

Environment

  • ASM provisioned
  • Upgrading BIG-IP

Cause

This issue can happen when the size of the UCS to be installed in the target boot location is very large, due to the accumulated size of the ASM policy history files. This is more common with moderate to large ASM configurations (many policies, frequent changes).

Recommended Actions

Use the following command to determine if the policy history files are using a lot of disk space (in excess of ~500MB):

du -sh /var/ts/dms/policy/policy_versions

You can usually reduce the size of this directory significantly by following the steps in K15125052:

  • K15125052: Huge UCS backup file due to /var/ts/dms/policy/policy_versions

Additional Information

UCS files may become large due to other factors. In some cases you will need to extract the UCS file and inspect the contents to determine which files are consuming a lot of disk space.
