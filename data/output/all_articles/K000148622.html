Description

AV check fails even with the latest EPSEC.

CTU report (K12444: Overview of the Client Troubleshooting Utility for Windows) says "is not registered" or "not found" in Component Information section

 

Environment

  • BIG-IP APM
  • Edge Client 7246
  • CTU report shows "is not registered" or "not found" in Component Information

 

Cause

Edge client needed to be clean installed.

 

Recommended Actions

Uninstall current version properly, and re-install or clean install later version.
