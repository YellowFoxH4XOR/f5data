Known Issue

This is the result of a known issue. If you use the NameSurfer application to remove a remote secondary name server from a zone, NameSurfer may delete the zone. This problem can occur even if an authoritative name server is defined.

There is no work around for this issue. If you plan to remove a remote secondary name server, you should also prepare to recreate the zone associated with the secondary name server.

F5 Networks Product Development tracked this issue as CR46027.
