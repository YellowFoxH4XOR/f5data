Known Issue

This is the result of a known issue. The snap-recon.pl snapshot reconstitution script does not read .rpt snapshot report files. The snap-recon.pl script should find both .xml and .rpt snapshot report files. However, the script only finds .xml files.

Note: The collect reports command will collect snapshot reports in XML format and save them with an .rpt filename extension.

F5 Networks Product Development tracked this issue as ARX ID 37771 and it was fixed in ARX version 5.1.5. For information about upgrading, refer to the ARX Release Notes.

Note: F5 Networks Product Development is tracking another issue under ARX ID 37771. For information refer to K11172:The snap-recon.pl snapshot reconstitution script does not read .rpt report files.

Workaround

You can work around this issue by renaming the .rpt snapshot reports with an *.xml extension. In addition, you can modify the snap-recon.pl script to use .rpt files by performing the following procedure:

  1. Open the snap-recon.pl script in a text editor.
  2. Near line 139 of the script, locate the following line:

    push @files, $File::Find::name if(/\.xml$/i);
  3. Edit the line to find .rpt files using the following syntax:

    push @files, $File::Find::name if(/\.rpt$/i);
  4. Save the snap-recon.pl script file.

The script will now find the .rpt files.
