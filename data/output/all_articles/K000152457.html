K000152457: STP/MSTP Loop Detection and Network Loop Prevention Behavior on F5OS-C (VELOS) Platforms

Applies to

Description

On F5OS platforms, including VELOS, Spanning Tree Protocol (STP) is disabled by default.

When multiple VELOS interfaces are interconnected in a manner that could create a network loop, the platform does not provide STP passthrough or built-in loop protection.

This can result in MSTP (Multiple Spanning Tree Protocol) loop detection events on connected switches, potentially leading to network instability, heartbeat loss, or failover events.


Environment

  • F5OS - Chassis (VELOS Platform)
  • VELOS interfaces connected to external switches with MSTP/STP enabled


Cause

F5OS platforms do not support STP or MSTP and do not forward STP BPDUs. If two or more VELOS interfaces are connected in a way that forms a loop, the platform relies entirely on the external switch infrastructure to detect and prevent network loops. Without proper STP configuration on the switches, loops may occur, resulting in network disruptions.


Recommended Actions

  • Ensure that STP (Spanning Tree Protocol) or MSTP is properly configured and enabled on all external switches connected to F5OS/VELOS platforms.
  • Do not rely on F5OS/VELOS to provide loop prevention or STP passthrough.
  • Regularly review switch configurations to confirm that loop prevention mechanisms are active and functioning as intended.
  • Avoid connecting VELOS interfaces in a topology that could create a loop unless the switch infrastructure is fully protected by STP/MSTP.
