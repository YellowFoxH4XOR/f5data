Description

With BIG-IP Application Security Manager (ASM), you will find /Common/bot_defense_asm_aggregated in profiles of Virtual Server.

Environment

  • BIG-IP ASM 

  • Virtual Server has multiple Security profile belonging to LTM policy.

Cause

This is by design. 
The bot_defense_asm_aggregated profile is read only (you should not be able to create it or change it), only to view it.
It is considered as a "hidden component" and won't have a manual entry.

Recommended Actions

None
