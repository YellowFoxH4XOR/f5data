K000139907: Local admin cannot login to F5OS via SSH

Type
Support Solution
Published
2024-06-06
Updated
2024-06-06
Applies to
  • rSeries Platforms
  • rSeries 2000
  • rSeries 4000
  • rSeries 5000
  • rSeries 10000
  • rSeries 12000
Source
https://my.f5.com/manage/s/article/K000139907

Description

Unable to login via SSH with certain local admin account but GUI login works. Delete and recreating the same local admin account will get the same issue.

Environment

  • SSH
  • Authentication
  • Local admin account
  • F5OS-A

Cause

None

Recommended Actions

Run the following command in CLI bash mode:

faillock --user <admin> --reset

Replace <admin> with the local admin username

Additional Information

None
