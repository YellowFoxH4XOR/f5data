Description

BIG-IP is responding to ARP requests for non-configured ip addresses. As a result of that, intermediate network devices will have incorrect ARP entries into their ARP cache. 

Environment

  • ARP resolution
  • Virtual Address

Cause

A virtual server with a subnet mask is configured and the ARP option is enabled on the corresponding virtual server address.

By default, the BIG-IP system responds to ARP requests for a virtual address, regardless of the state of any virtual servers associated with the virtual address.

Recommended Actions

Disable ARP requests for the virtual address in question.

  1. Navigate to: Local Traffic > Virtual Servers > Virtual Address List
  2. Select the Virtual Address in question
  3. Clear the ARP check box
  4. Select Update
