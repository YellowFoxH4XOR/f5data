Description

Pre upgrade checks on BIG-IQ devices may fail on step:

Network Interface Card check primary: NOK

Environment

Pre upgrade check for BIG-IQ 7.x and prior - CM and DCD instances

Cause

BIG-IQ 8.x requires more than one interface added to BIG-IQ instance from hypervisor.

Recommended Actions

Follow recommended steps in article:

K95712472: Workaround for single NIC configuration on BIG-IQ 8.0.0/8.1.0
