Known Issue

Description

The BIG-IP system may fail to process changes when you create or modify addresses for a Network Firewall address list.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system runs BIG-IP 11.4.1 HF2 or a later version.
  • Your BIG-IP system is licensed and provisioned with Advanced Firewall Manager (AFM).
  • You attempt to use the Configuration utility to add an IP address, with a netmask, to the Network Firewall address list.

Impact

Users cannot add or modify IP addresses in the Network Firewall address list.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H446801 on the Diagnostics > Identified > Medium screen.
  • When you attempt to add an IP address with a netmask to the Network Firewall address list, the Configuration utility displays an error similar to the following example:

    Some fields below contain errors. Correct them before continuing.

    Invalid IP Address.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to add or modify addresses in Network Firewall address lists. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

Creating or modifying the address of a Network Firewall address list

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. To create a new Network Firewall address list and add an IP address with a netmask, use the following command syntax:

    create /security firewall address-list <new-address-list-name> addresses add { <network ip address>/<netmask> }

    For example, to create the Network Firewall address list XYZ and add the IP address range 192.168.0/24, type the following command:

    create /security firewall address-list XYZ addresses add { 192.168.0.0/24 }

    To add an IP address with a netmask to an existing Network Firewall address list, use the following command syntax:

    modify /security firewall address-list <existing-address-list-name> addresses add { <network ip address>/<netmask> }

    For example, to modify an existing Network Firewall address list XYZ and add the IP address range of 10.10/16, type the following command:

    modify /security firewall address-list XYZ addresses add { 10.10.0.0/16 }

  3. Save the change by typing the following command:

    save /sys config
