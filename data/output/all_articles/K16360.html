Known Issue

The SSL Forward Proxy feature does not fully support the SSL Forward Proxy Bypass option.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration uses the SSL Forward Proxy feature.
  • You have enabled the SSL Forward Proxy Bypass option on the Client and Server SSL profiles.
  • You have applied an upper-layer protocol profile, such as an HTTP profile, to the virtual server.

Impact

Attempts to connect through SSL Forward Proxy may fail, and the Traffic Management Microkernel (TMM) may restart and temporarily fail to process all traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Client connections through the SSL Forward Proxy feature are failing.
  • The BIG-IP system fails to process all traffic for a brief period of time.
  • The BIG-IP system fails over to another host in the device group.
  • TMM generates a core file in the /var/core directory.
