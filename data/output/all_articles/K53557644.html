Description

The purpose is to explain the expected status of a vCMP guest(s) after the Hypervisor (Host) has been upgraded.

Environment

  • Upgrading vCMP Host (hypervisor).
  • vCMP guest(s) status after Host upgrade.

Cause

The expected behavior is that the guest will be in the state it was in when you installed the software on the hypervisor.  

The expected behavior is that the guest will be in the state it was "at the time" you installed the software on the hypervisor.

For example:
Lets say you installed version 14.1.0.0. on the hypervisor but did not yet boot into this volume.  At the time if your guests were in a deployed state (when you actually selected 14.1.0.0 and install) then after booting into the new volume the guest would assume that same status. Even if you gracefully shut down the guests just prior. Therefore it may appear the vCMP guest has restarted or deployed itself. 

The reason for this is, as part of the upgrade process a UCS archive is created of the vCMP host and guest(s) in order to migrate the configurations to the new volume. These UCS archives are used as part of the upgrade, unless you choose to Install configuration at the time of choosing your boot location. This can result in your guest(s) coming back in an unexpected state.

Recommended Actions

Prior to installing the new version of software on the hypervisor you should configure the guest state (deployed, provisioned, Configured) as desired.

Additional Information

Recommended verification steps for the upgrade via the Command Line

Using tmsh commands to verify version information of the host prior to upgrade

  1. Log on to the vCMP host command line.
  2. To view the vCMP host version:
    tmsh show sys version

    Example command output (vCMP Host is version 12.1.3):
    Sys::Version
    Main Package
      Product     BIG-IP
      Version     12.1.3
      Build       0.0.378
      Edition     Final
      Date        Mon Nov 27 16:41:03 PST 2017
     
  3. To view the status of the vcmp guest during the upgrade

    tmsh show vcmp guest <vcmp guest name>
    Note: Replace <vcmp guest name> with the name of your vcmp guest instance.

    Example command output:
    -------------------------------------------------------------------------------
    Vcmp::Guest
    Name           Status  Requested   Request  Retries             Uptime  Comment
                               State  Complete

    -------------------------------------------------------------------------------
    test04112019  running   deployed      true        0  04/11/19 16:13:45

     
  4. View the version after the upgrade is completed

    tmsh show sys version

    Example command output (upgrade to 13.1.1.4):
    Sys::Version
    Main Package
      Product     BIG-IP
      Version     13.1.1.4
      Build       0.0.4
      Edition     Point Release 4
      Date        Wed Jan 16 18:04:36 PST 2019
     
  5. Confirm the vcmp guest has completed the upgrade
    show vcmp guest <vcmp guest name>
    Note: Replace <vcmp guest name> with the name of your vcmp guest instance.

    Example command output:
    ---------------------------------------------------------------------
    Vcmp::Guest
    Name            Status  Requested   Request  Retries  Uptime  Comment
                                State  Complete

    ---------------------------------------------------------------------
    <vcmp guest name> starting   deployed     false        0    None
     
  6. To view the status of the vCMP guest instance.

    tmsh show vcmp guest <vcmp guest name>
    Note: Replace <vcmp guest name> with the name of your vcmp guest instance.

    Example command output:
    -------------------------------------------------------------------------------
    Vcmp::Guest
    Name           Status  Requested   Request  Retries             Uptime  Comment
                               State  Complete

    -------------------------------------------------------------------------------
    <vcmp guest name> running   deployed      true        0  04/11/19 16:31:15  <------------------------ Status running deployed State
