Description

vCMP guest may not respond to traffic intermittently

  • Services work for only some of the clients
  • Pool members may go down or state may flap

Environment

  • Trunks
  • A port was removed from trunk or disabled on the BIG-IP or the adjacent switch

Cause

Bug ID 758604
BIG-IP continues using the disabled/removed port for traffic processing

Recommended Actions

The bug has been fixed in version 15.0.0.
Upgrade the vCMP host to the latest supported version.
