Topic

This is the result of a change in the alert notification behavior in BIG-IP 9.x. Alarm LED alert notifications are no longer triggered when a node or member is marked down. However, you can enable Alarm LED alert notifications. The following table provides information about alert levels and their associated Alarm LED behaviors:

Alert levelAlarm LED behavior
0 - WarningSolid Yellow
1 - ErrorBlink Yellow
2 - AlertSolid Red
3 - CriticalSolid Red
4 - EmergencyBlink Red

Once configured, the Alarm LED remains lit, even if the affected node or member is later marked up. You must manually clear Alarm LED indications using the LCD panel, or by using the appropriate clearlcd command line utility.

For example:

  • clearlcd_warning
  • clearlcd_error
  • clearlcd_alert
  • clearlcd_critical
  • clearlcd_emergency

It is possible to have multiple levels of alerts. With multiple levels, you need to clear each alert level separately. Therefore, once the current alert level is cleared, the Alarm LED starts to indicate the next alert level.

To enable Alarm LED alert notifications, use one of the following two procedures, depending on your BIG-IP version:

Note: The entries in the following procedures use Alert Level (priority) 1 - Error, indicated by a blinking yellow alarm LED.

Enabling Alarm LED notifications on BIG-IP 9.0.0 through 9.0.5

Note: These steps include configuration entries to correct a related issue in K4534: BIG-IP does not send an SNMP trap when nodes are marked up or down, and will enable SNMP traps to be sent if a node or member is marked DOWN or UP.

  1. Log in to the command line.
  2. Change directories to the /etc/alertd directory by typing the following command:

    cd /etc/alertd

  3. Using a text editor, edit the alert.conf file.

    Add the following lines at the end of the file:

    alert BIGIP_MCPD_MCPDERR_POOL_MEMBER_MON_DOWN "Pool member (.*?):(.*?) monitor status down."
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.10";
    lcdwarn description="Member Down" priority="1"
    }
    alert BIGIP_MCPD_MCPDERR_POOL_MEMBER_MON_UP "Pool member (.*?):(.*?) monitor status up." {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.11"
    }
    alert BIGIP_MCPD_MCPDERR_NODE_ADDRESS_MON_DOWN "Node (.*?) monitor status down." {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.12";
    lcdwarn description="Node Down" priority="1"
    }
    alert BIGIP_MCPD_MCPDERR_NODE_ADDRESS_MON_UP "Node (.*?) monitor status up." {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.13"
    }

  4. Save the file and exit the editor.

The BIG-IP system now sends SNMP traps when a node or member are marked down or up, and the front panel Alarm LED indicates when a node or member is marked down.

Enabling Alarm LED notifications on BIG-IP 9.1.0 through 9.4.8

  1. Log in to the command line.
  2. Change directories to the /etc/alertd directory by typing the following command:

    cd /etc/alertd

  3. Using a text editor, edit the alert.conf file.

    Locate the following entries in the file:

    alert BIGIP_MCPD_MCPDERR_POOL_MEMBER_MON_DOWN "Pool member (.*?):(.*?) monitor status down."
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.10"
    }
    alert BIGIP_MCPD_MCPDERR_NODE_ADDRESS_MON_DOWN "Node (.*?) monitor status down." {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.12"
    }

  4. Modify the entries to include a semi-colon at the end of the snmptrap line, and add the appropriate lcdwarn line:

    alert BIGIP_MCPD_MCPDERR_POOL_MEMBER_MON_DOWN "Pool member (.*?):(.*?) monitor status down." {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.10";
    lcdwarn description="Member Down" priority="1"
    }
    alert BIGIP_MCPD_MCPDERR_NODE_ADDRESS_MON_DOWN "Node (.*?) monitor status down." {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.12";
    lcdwarn description="Node Down" priority="1"
    }

  5. Save the file and exit the editor.

The BIG-IP front panel Alarm LED now indicates when a node or member is marked down.
