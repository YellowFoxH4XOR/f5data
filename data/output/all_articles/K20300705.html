Known Issue

The Traffic Management Shell (tmsh) delete ltm profile ramcache command behaves unexpectedly.

This issue occurs when one of the following conditions is met:

  • You attempt to delete a specific RAMCache.
  • You attempt to delete multiple URIs.
  • You attempt to delete an entry that does not exist.
  • You attempt to delete a specific URI but forget to specify the URI syntax in the command.
  • You attempt to delete a specific URI and host.
  • You attempt to delete a RAMCache name that does not exist.

Delete a RAMCache profile

For the following example, there are six entries within the RAMCache:

Note: The entries are shown as duplicates due to there being two Traffic Management Microkernels (TMMs), as each TMM maintains its own RAMCache.

# tmsh show ltm profile ramcache webacceleration | egrep 'URI|Total' | sort
Total records returned: 6
URI : /
URI : /
URI : /cookie.html
URI : /cookie.html
URI : /index.html
URI : /index.html

Scenario 1

You type the following command:

# tmsh delete ltm profile ramcache testcache

The command executes correctly and, as expected, deletes all entries for the specified RAMCache.

Scenario 2

You type the following command:

tmsh delete ltm profile ramcache testcache uri coo

The command deletes just /cookie.html since it matches coo. The system treats the request entry as a regular expression instead of an exact match.

Scenario 3

You type the command:

tmsh delete ltm profile ramcache testcache uri foo

Nothing is deleted since there is no match with any of the entries. However, nothing is returned indicating there is no match; the command executes and returns to the command prompt.

Scenario 4

You type the following command:

tmsh delete ltm profile ramcache testcache foo

Note: The command is missing URI syntax

The command deletes all entries. It should also return an error indicating missing syntax.

Scenario 5

You type the following command:

tmsh delete ltm profile ramcache testcache exact uri coo host 192.168.1.1

The command executes correctly and does not delete anything as the URL does not match.

Scenario 6

You type the following command:

tmsh delete ltm profile ramcache foo

Nothing is deleted because the cache name does not exist; however, there is no error message indicating the specified ramcache name does not exist or is not found.

Impact

Some commands execute as expected, other commands do not execute as expected, fail to indicate the command executed, or fail to report any errors encountered.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Unexpected behavior may cause confusion about whether a command executed as expected.
