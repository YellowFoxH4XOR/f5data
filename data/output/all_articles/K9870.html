K9870: The BIG-IP WebAccelerator module is not enabled when the system boots from a compact flash drive

Topic

The BIG-IP WebAccelerator module will not be enabled if the system boots from a compact flash (CF) drive. The BIG-IP WebAccelerator requires the hard disk to work properly.

To ensure that the BIG-IP WebAccelerator module is enabled properly, use the switchboot command to configure the default boot image to use one of the hard disk image slots.

Note: For more information about the switchboot command, refer to K5658: Overview of the switchboot utility.

Note: The BIG-IP 3600, 6400, 6800, 8400, 8800 and 8900 platforms contain the compact flash drive.
