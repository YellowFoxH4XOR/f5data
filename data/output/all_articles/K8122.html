Topic

You should consider using this procedure under the following conditions:

  • You want to configure a DNS Wide IP to resolve to a Punycode.
  • You want to configure a DNS Resource Record to resolve to a Punycode.

Description

The BIG-IP DNS (formerly BIG-IP GTM) system supports the use of Internationalized Domain Names (IDN) through the use of Punycode.

Punycode is an encoding syntax that uniquely and reversibly transforms a hostname or fully-qualified domain name (FQDN) of a specific language in Unicode into a format able to be resolved as a DNS Resource Record.

Important: Encoded host-name translation occurs through the application, such as a web browser. BIG-IP DNS does not translate the encoded information into Punycode.

For more information about Punycode specifications, refer to Internet Engineering Task Force (RFC 3492).

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have access to the BIG-IP Configuration utility.
  • You have one or more IDNs to configure.

Procedures

  • Creating a wide IP with Punycode
  • Creating a resource record with a Punycode through ZoneRunner

Creating a wide IP with Punycode

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > GSLB > Wide IPs.

    Note: In BIG-IP 11.5.0 and earlier, navigate to Global Traffic > Wide IPs.

  3. Click Create.
  4. Under General Properties, type or enter the IDN you want to resolve in the Name box.

    Note: You can use two different wildcard characters in the wide IP name: asterisk (*) to represent several characters and question mark (?) to represent a single character. This reduces the number of aliases you have to add to the configuration.

  5. In the Type list, click a record type for the wide IP.
  6. Under Pools, for Pool, click the pools that this wide IP uses for load balancing.

    Note: The system evaluates the pools based on the wide IP load balancing method configured.

  7. In the Pool list, click a pool name.

    Note: A pool can belong to more than one wide IP.

  8. Click Add.
  9. Click Finished.

Creating a resource record with a Punycode through ZoneRuner

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > Zones > Zonerunner.

    Note: For BIG-IP 11.5.0 and earlier, navigate to Global Traffic > ZoneRunner.

  3. In the View Name list, click the appropriate view.
  4. In the Zone Name list, click the appropriate zone name.
  5. Click Create.
  6. Under Record Configuration, for Name, type or enter the IDN.
  7. Configure the remaining required settings related to the resource record type.
  8. Click Finished.
