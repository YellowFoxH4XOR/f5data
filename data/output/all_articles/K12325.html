Known Issue

This is the result of a known issue. When using the Application Templates feature in BIG-IP version 10.2.0, a configuration based on Microsoft Office Outlook Web Access (OWA) may fail to deploy if the drop-down box that enables BIG-IP ASM is set to Yes.

When this failure occurs, error messages may display in the Configuration utility or in the /var/log/webui.log file that appear similar to the following example:

An error occurred during Template-based configuration:
Exception caught in ASM::urn:iControl:ASM/WebApplication::set_language_extended()
Exception: Common::OperationFailed
primary_error_code : 2 (0x00000002)
secondary_error_code : 0
error_string : Undefined subroutine &F5::ASMReady::is_asm_ready called at /usr/lib/perl5/site_perl/F5/Acc/WebAppServices.pm line 117.

F5 Product Development tracked this issue as ID 343575 and it was fixed in BIG-IP ASM version 10.2.2. For information about upgrading, refer to the BIG-IP ASM release notes.

In addition, BIG-IP iHealth may list Heuristic H787216 on the Diagnostics > Identified > Low screen.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
