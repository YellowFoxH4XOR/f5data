Known Issue

This is the result of a known issue. After installing or removing a Hotfix IM package on the BIG-IP system, the ZebOS routing module is no longer configured to start up at system boot. For example, if you are running BIG-IP LTM version 9.3.1 with ZebOS enabled, and you install the version Hotfix-BIG-IP-9.3.1-HF1 IM package, the ZebOS routing module will be disabled following the system reboot.

F5 Networks Product Development tracked this issue as CR93633 and it was fixed in BIG-IP version 9.4.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, Hotfix-BIG-IP-9.3.1-HF2 has been issued for BIG-IP version 9.3.1. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

For information about the F5 Networks hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.

For information about managing F5 Networks product hotfixes, refer to K6845: Managing F5 Networks product hotfixes.

Workaround

You can work around this issue by starting the ZebOS routing module, and configuring it to start up at boot time. To do so, perform the following procedure:

  1. Log in to the command line.
  2. To configure the ZebOS routing module, type the following command:

    bigstart start zebosd
  3. To enable ZebOS at boot time, type the following command:

    bigstart add zebosd
