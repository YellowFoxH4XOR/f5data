Description
License reactivation is failing with the following error message:

Unable to grant license key: Error 51092, This license has already been activated on a different unit. Please contact technical support for assistance.

Environment

This message occurs when one of the following conditions is met:

  • You attempt to license a physical device using an incorrect base registration key.
  • You attempt to license a BIG-IP Virtual Edition (VE) instance with a base registration key that was previously used for a BIG-IP VE instance with a different MAC address or UUID.
  • You attempt to license a replacement device for an RMA, and an allow move was not performed on the base registration key through the RMA process.
  • You attempt to license a vCMP from the vCMP guest in the Command Line (CLI).
  • On certain BIG-IP iSeries platforms, the Always-on Management (AOM) stops responding after an upgrade and the license activation attempt fails.

Cause
There are a few different reasons this behavior can occur.  Additional data and troubleshooting may be needed to confirm what was the cause. 

Recommended Actions

  1. Verify that you are using the correct base registration key.
  2. If you are licensing a BIG-IP VE instance and the MAC address or UUID has changed, or if you are licensing an RMA replacement device, contact F5 Technical Support.
  3. If you are licensing a vCMP, you need to license from the vCMP host. Virtual Clustered Multiprocessing (vCMP) guests inherit the license from the vCMP Host. The host license must include all BIG-IP modules that you plan to provision on vCMP guest instances.
  4. If you are using a BIG-IP iSeries platform that you've recently upgraded, refer to K00415052: AOM may stop responding during an upgrade on iSeries platforms.

Additional Information
For additional information on vCMP licensing considerations go to  vCMP licensing considerations.
