K000093131: BIG-IQ SSH authentication fails for remote RADIUS users

Type
Support Solution
Published
2022-12-08
Updated
2022-12-08
Source
https://my.f5.com/manage/s/article/K000093131

Description

The article describes an issue that could be encountered while trying to authenticate with non-local RADIUS users via SSH into BIG-IQ. It unexpectedly fails.

Environment

  • BIG-IQ 7.0.0

  • SSH

  • RADIUS authentication

Cause

The issue is caused by bug ID844605.

Recommended Actions

The solution is to upgrade the BIG-IQ device to a 7.0.0.1 fixed version.
