Description
While issuing an iControl REST API call to /mgmt/tm/sys/hardware to retrieve the BIG-IP device inventory information, it can result in a 500 Internal Server Error response being returned similar to the following:
{
    "code": 500,
    "message": "Input length = 1",
    "referer": "xxx.xxx.xxx.xxx",
    "restOperationId": 3208881,
    "kind": ":resterrorresponse"
}

Environment
  • BIG-IP platforms being used.
  • Software version: 11.5.x, 11.6.x, 12.x or 13.x
  • REST API query initiated to /mgmt/tm/sys/hardware to obtain BIG-IP inventory information

Cause
The REST API query to /mgmt/tm/sys/hardware endpoint can fail if the response consists of non-UTF-8 characters. F5 Product Engineering team is tracking this as a known issue at Bug ID 602193.

Recommended Actions

  • Versions 14.1.0 or later
  • Versions 14.0 or earlier

To address this issue, either of the following approaches can be chosen:

Versions 14.1 or later:
Bug ID 602193 is fixed, as of 14.1.0.

Versions 14.0 or earlier:
Within affected releases, you can obtain the inventory information using an alternate approach by going through the following steps:

  1. Create a bash script that executes an equivalent command to obtain hardware information from tmsh, after sanitizing the non-UTF-8 characters, and then issue a POST call for it from the /mgmt/tm/sys/bash endpoint. Here's an example of such a script:
    #/bin/bash
    tmsh show sys hardware | /usr/bin/strings -n8

  2. Change permissions for this bash script so that it has executable permissions. Assuming the script is stored within /shared/tmp/, you can use a command such as the following to change permissions:
    chmod +x /shared/tmp/hardware.sh

  3. Once the script has executable permissions, you can issue a POST request to /mgmt/tm/util/bash endpoint in the following manner to retrieve the hardware information.
    # curl -sku [username]:[password] -X POST -H "Content-Type: application/json" -d "{\"command\":\"run\", \"utilCmdArgs\":\"-c '/shared/tmp/hardware.sh'\"}" https://[mgmt-IP]/mgmt/tm/util/bash
