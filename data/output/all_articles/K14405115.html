Description

UCS or other files are not able to create due to no space on inodes.

In /var/log/ltm Received a similar error like this one:
exception: (Can't create temp directory, /var/system/tmp/tmsh/yCS97r, errno 28] No space left on device) (framework/TempDir.cpp, line 216), exiting
 
Environment
  • BIG-IP  LTM
  • inodes
 
Cause

There is no free inodes on the system so no file will be able to be created.
 
Recommended Actions
 
  1. Review space on inodes with df -i
