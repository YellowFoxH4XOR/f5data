K20020445: GTM/DNS sync not working eventhough iquery showing all the devices are connected

Type
Support Solution
Published
2021-12-17
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP DNS: 13.1.3
Source
https://my.f5.com/manage/s/article/K20020445

Description
GTM/DNS synchronization not working for some of the GTM/DNS devices.

Environment

  • DNS
  • iQuery

Cause

  • gtm1, gtm2, gtm3 and gtm4 are 4 GTM/DNS devices in the same sync group.
    • tmsh show gtm iquery showing that all the the state are Connected.
    • gtm1 has 2 self-ip addresses configured on GTM/DNS listener vlan.
      • 10.10.10.1/24
      • 10.10.10.2/24
    • gtm1 server is configured as 10.10.10.1 on bigip_gtm.conf
    • gtm2 has 2 self-ip addresses configured on GTM/DNS listener vlan.
      • 10.20.20.1/24
      • 10.20.20.2/24
    • gtm2 server is configured as 10.20.20.1 on bigip_gtm.conf
    • gtm3 has 2 self-ip addresses configured on GTM/DNS listener vlan.
      • 10.30.30.1/24
      • 10.30.30.2/24
    • gtm3 server is configured as 10.30.30.1 on bigip_gtm.conf
    • gtm4 has 1 self-ip addresses configured on GTM/DNS listener vlan
      • 10.40.40.1/24
    • gtm4 server is configured as 10.40.40.1 on bigip_gtm.conf
  • Only GTM/DNS sync could work from gtm4 server.
  • This is documented as known issue ID 751540


Recommended Actions
You could consider to perform one of the action below

  • Remove unnecessary self-ip addresses from those listener vlan
  • Create additional gtm server for those additional self-ip
