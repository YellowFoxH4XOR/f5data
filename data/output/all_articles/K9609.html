Topic

The FirePass controller’s Endpoint Security feature allows administrators to detect the presence and state of third party security software, such as personal firewalls, antivirus, anti-spam, anti-spyware, or integrated packages. To perform this detection, the Windows antivirus checker and Windows firewall checker endpoint inspectors, which are listed on the Users: Endpoint Security: Endpoint Inspectors page, use software libraries from a Software Development Kit (SDK) created by OPSWAT, Inc.

For the Windows antivirus checker, a list of supported software is located on the Users: Endpoint Security: Inspectors: Antivirus Support Chart: Antivirus Support Chart page in the FirePass online help. For the Windows firewall checker, a list of supported software is located on the Users: Endpoint Security: Inspectors: Firewall Support Chart: Firewall Support Chart in the FirePass online help. These charts reflect the software supported by the current OPSWAT SDK library installed on the FirePass controller. If you install a new version of the OPSWAT SDK, the Antivirus and Firewall Support Charts are also updated.

The Antivirus and Firewall Support Charts primarily list the English versions of antivirus and firewall software products, not the localized versions (for example, the Japanese, Chinese, or Korean versions). Most localized versions of software use the same engines and APIs as the English versions. Therefore, if the English version is supported, typically the localized version is also supported. However, in rare instances, the localized version may have significant differences to the English version and may not be properly detected by the endpoint inspector. If the localized version of your of antivirus or firewall software is listed as supported in the Antivirus or Firewall Support Chart, the localized version has been tested and is supported.

If the English version of your antivirus or firewall software is listed as supported in the FirePass online help, but the localized version of software is not detected properly by the Windows antivirus checker or the Windows firewall checker, you may want to download and install the latest OPSWAT SDK library.

Note: For more information, refer to K6664: Obtaining and installing OPSWAT hotfixes.

If this step does not resolve the issue, or if you do not want to install the latest version of the OPSWAT SDK, contact F5 Networks Technical Support to determine whether the localized version of your antivirus or firewall software is supported. When you contact support, ensure that you provide the version of the OPSWAT SDK installed on your FirePass controller, which is displayed at the top of the Antivirus and Firewall Support Charts.

If your localized version antivirus or firewall software is not supported, you can create custom pre-logon checks to detect your software.

Note: For more information, refer to K7661: Options for security products not supported by OPSWAT. Additionally, you can create a Request for Enhancement (RFE) with F5 Networks Technical Support to request that future versions of the OPSWAT SDK support your localized antivirus or firewall software.
