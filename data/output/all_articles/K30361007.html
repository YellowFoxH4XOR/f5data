Topic

You should consider using this procedure under the following condition:

  • You created or modified a BIG-IP APM access policy.
  • Your want to apply the access policy changes to the running configuration using the iControl representation state transfer (REST) application programming interface (API).

Description

You can use the iControl REST API to apply a new or modified access policy, placing the policy in the running configuration of the BIG-IP APM system.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access credentials for the Configuration utility.
  • You know the access policy name and partition name where the access policy resides.
  • You have some familiarity with the cURL command-line tool.

Procedures

Applying an access policy

The following procedure applies a new or modified access policy into the running configuration of your BIG-IP APM system using the cURL command-line tool to interact with the BIG-IP APM iControl REST API.

Impact of procedure: Performing the following procedure should not have a negative impact on your system, however modified access policies will apply the configuration modifications to access session initiated after the policy is applied.

To apply the access policy, enter the following command syntax:

curl -sk -u admin:<password> -H "Content-Type: application/json" -X PATCH  https://<big-ip apm address> /mgmt/tm/apm/profile/access/~<partition>~<access policy name> -d '{"generationAction":"increment"}'

Note: Replace <big-ip apm address> with the BIG-IP APM management interface IP address or hostname.
Replace <partition> with the partition location for the object (default is Common).
Replace <access policy name> with the base name used for the access profile and policy configuration.

For example:

curl -sk -u admin:p@ssWord! -H "Content-Type: application/json" -X PATCH  https://192.168.1.90/mgmt/tm/apm/profile/access/~Common~Corp-VPN -d '{"generationAction":"increment"}'
