K000157336: In the BIG-IP WAF, create an XML Profile and configure it to parse XML files against a specific XML schema for compliance validation.

Type
Support Solution
Published
2025-11-08
Updated
2025-11-08
Applies to
  • BIG-IP
  • F5 Distributed Cloud Services
  • BIG-IP ASM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000157336

Description

To configure a new XML profile that parses XML requests and validates the XML schema for compliance.

Environment

  • XML profile
  • ASM policy
  • XML schema

Cause

None

Recommended Actions

Use this procedure to create the necessary XML profile and validate your XML schema.

  • Create a new XML profile and upload the schema file. Note: The XSD namespace prefix of the schema or WSDL file you are uploading must comply with the W3C XML schema specifications and point to the https://www.w3.org/XML/Schema namespace.

  • Create a new allowed URL , and create new Header-based content profile and choose your new XML profile. 

  • Enable " XML data does not comply with schema or WSDL document" violation.

  • Perform a new test
