Known Issue

This is the result of a known issue. When you load a large BIG-IP GTM configuration, the command prompt may temporarily change to ?Active?.

For example, if you use the gtmparse or gtmload commands to parse and/or load a larger BIG-IP GTM configuration, the command prompt may change from Active to ?Active?. Pressing the Enter key on the keyboard resets the prompt as expected.

F5 Product Development is tracking this issue as CR106291.
