Topic

SNMP (Simple Network Management Protocol) is an industry-standard protocol that gives a standard SNMP management system the ability to remotely manage a BIG-IP system installed on the network.

The following SNMP versions are supported by the BIG-IP 9.x code branch:

  • SNMP v1
  • SNMP v2c
  • SNMP v3

The following SNMP versions are supported by the BIG-IP 10.x - 11.x code branches:

  • SNMP v1
  • SNMP v2c
  • SNMP v3

Note: While SNMP v1 is supported, it is not compatible with OIDs that utilize 64 bit counters. SNMP v1 is considered a legacy version. SNMP v2c or later is considered the standard.
