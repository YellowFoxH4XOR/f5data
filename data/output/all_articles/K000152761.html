K000152761: diag-agent logging "LOP Analog Alert Handler - RX Unknown Alert" every 10 seconds

Type
Support Solution
Published
2025-07-27
Updated
2025-07-27
Applies to
  • F5OS
  • F5OS-A: 1.5.X, 1.5.3, 1.5.2, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000152761

Description

The following log is written once every 10 seconds:

2023-07-02T07:11:47.913186+09:00 appliance-1 diag-agent[8]: priority="Info" msg="LOP Analog Alert Handler - RX Unknown Alert" objectId=0x0076 subObject=0x00 slotId=0xef alert="inlet at +25.8 degC" interface="psf-diag-agent"
2023-07-02T07:11:47.914351+09:00 appliance-1 alert-service[9]: priority="Notice" version=1.0 msgid=0x2201000000000029 msg="Received event." event="65538 appliance unknown-alarm EVENT NA "inlet at +25.8 degC" "2025-07-01 22:35:47.912867405 UTC"".
2023-07-02T07:11:47.914505+09:00 appliance-1 diag-agent[8]: priority="Err" msg="HAL Remote Call Error" index=0 error="parameter validation error, name='destSlot', Inner -> 'Unknown is not a valid 'Slot' value'" interface="psf-diag-agent"

The system management command "show system event" shows the following:

65538 appliance unknown-alarm EVENT NA "inlet at +25.8 degC" "2023-07-03 01:49:56.928940915 UTC"
65538 appliance unknown-alarm EVENT NA "inlet at +25.8 degC" "2023-07-03 01:50:06.929148734 UTC"
65538 appliance unknown-alarm EVENT NA "inlet at +25.8 degC" "2023-07-03 01:50:16.779844438 UTC"
65538 appliance unknown-alarm EVENT NA "inlet at +25.8 degC" "2023-07-03 01:50:28.929363191 UTC"
65538 appliance unknown-alarm EVENT NA "inlet at +25.8 degC" "2023-07-03 01:50:37.843140000 UTC"

If SNMP is configured, SNMP traps similar to the above logs may be sent at the same interval.

Environment

  • F5OS-A

Cause

Unknown

Recommended Actions

If the slotID value is not "0xff", run the following command to reset the AOM:

docker exec -it platform-hal psf call POST:lop/object/reset-device device=Aom
