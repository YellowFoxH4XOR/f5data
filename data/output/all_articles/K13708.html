Known Issue

The Configuration utility and command line incorrectly allow users to create hybrid disk volumes (HDx.x and MDx.x together).

This issue occurs when the following conditions are met:

  • The BIG-IP platform is a 6900, 8900, 8950, or 11050
  • You attempt to create a non-mirrored volume

BIG-IP systems containing multiple hard drives that ship with version 10.1.0 or later feature mirrored volume sets exclusively (for example MD1.1 and MD1.2). The Configuration utility and bigpipe commands incorrectly allow users to create hybrid disk volumes by defining non-mirrored volumes (for example HD1.1 and HD1.2) that exist with the mirrored volume sets. The new non-mirrored volumes are not useable.

Impact

The system fails to create a useable non-mirrored volume.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The system displays HDx.x as a volume, but does not allow any images to be installed to that volume.
  • If you attempt to install software on the volume, the tmsh command indicates that the installation failed.

    For example:

    # tmsh show /sys software

    -----------------------------------------------------------------------------
    Sys::Software Status
    Volume Product Version Build Active Status
    -----------------------------------------------------------------------------
    HD1.shouldfail BIG-IP 10.2.0 3033.0 no failed (Failed to install.)
    MD1.1 BIG-IP 10.2.0 3033.0 yes complete
    MD1.2 BIG-IP 10.2.0 3033.0 no complete
