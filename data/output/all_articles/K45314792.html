Description

After upgrading to v14.1.x you see the error:
“sod[<pid>]: 010c0063:5: Waiting for Mcpd without a response. Try again...”

Environment

  • In /var/log/ltm
  • Upgrading from v12 to v14
  • You have VLAN and or /tunnels named 'default' or 'all'

Cause

Bug ID701529
Starting in v13 and v14 'default' or 'all' became reserved words and cannot be used anymore

Recommended Actions

  1. Login as root user to the Advanced Shell (bash)
  2. Edit the /config/bigip_base.conf
  3. Delete or rename the vlan/tunnel named 'default' or 'all'

    net route-domain /Common/0 {
    id 0
    vlans {
    /Common/vlan1
    /Common/External
    /Common/http-tunnel
    /Common/socks-tunnel
    /Common/default        <------------- edit/delete this line
    }
     
  4. It might be required to reboot the unit after following the steps above.
