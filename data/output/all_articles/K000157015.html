Topic

This article provides an overview of CrowdStrike's Falcon sensor for F5's BIG-IP offering, which is now Generally Available (GA).

Description

F5 and CrowdStrike have partnered to provide endpoint detection and response (EDR) by integrating CrowdStrike's Falcon sensor with BIG-IP. For supported BIG-IP environments, refer to Important Information.

This integration delivers a SaaS-based, next-generation workload security solution that provides advanced detection, monitoring and search capabilities, allowing analysts to defend against sophisticated threats and adversaries. It offers remote visibility across endpoints throughout an environment, enabling instant access to the "who, what, when, where, and how" of an attack. It collects and analyzes more than 1 trillion events each day from millions of sensors deployed across the globe.

Falcon Sensor 7.39 and Later

Customers upgrading existing Falcon Sensor deployments on BIG-IP systems to Falcon Sensor version 7.39 or later may be required to perform an F5-provided migration procedure using the script migrate.sh before upgrading the sensor. For more information on the issues this script resolves, determine if you need it, and the complete procedure to use it, refer to K000162324: CrowdStrike Falcon Sensor 7.39 on BIG-IP fails to download files.

For new Falcon Sensor deployments, there are updated install instructions using version 2.0 or later of the install.sh script to avoid this migration requirement.

Determining Falcon Sensor version

Regarding updates to the Falcon Sensor:

  • The version of sensor RPM you installed may not match the version of CrowdStrike that's currently running. To confirm, run /opt/CrowdStrike/falconctl -g --version as root.
  • If deployed during the EA, consult the CrowdStrike documentation and confirm you've enabled an appropriate sensor update policy. 

Installing Falcon sensor on BIG-IP systems with a FIPS license

F5 has tested the installation and operation of the CrowdStrike Falcon sensor on BIG-IP systems licensed for Platform Federal Information Processing Standards (FIPS) for the following versions and platforms:

  • 17.5.1.4 on VE, rSeries, and VELOS platforms
  • 17.1.3.1 on VE, rSeries, and VELOS platforms
  • 21.0.0.1 on VE, rSeries, and VELOS platforms
  • rSeries appliances running F5OS-A 1.8.3
  • VELOS chassis controllers running F5OS-C 1.8.2

During testing, F5 did not observe degradation to BIG-IP functionality or performance when the Falcon sensor was installed on these systems. F5 Support will assist with Falcon sensor installation and common connectivity issues on FIPS-licensed BIG-IP systems in the configurations listed directly above in accordance with the existing support policy outlined in K000157014: F5 Support for Falcon for BIG-IP.

Important: The Falcon sensor is a CrowdStrike product that operates on supported BIG-IP platforms but is not an F5 product and is not part of BIG-IP software. In highly regulated environments, CrowdStrike Falcon is designed to support FIPS compliance by utilizing the host's underlying FIPS-validated cryptographic modules. Note that F5's NIST FIPS validation applies solely to the out-of-the-box BIG-IP software and hardware. Because the Falcon sensor is a third-party application, it exists outside the scope of F5's specific FIPS certification. Customers who are required to maintain strict FIPS-validated configurations should evaluate how installing third-party software impacts their overall compliance scope before proceeding with installation.

For questions or issues related to the Falcon sensor after installation, contact CrowdStrike Support as described in K000157014: F5 Support for Falcon for BIG-IP.

Technical requirements

In order to ensure proper operations with Falcon sensor for BIG-IP, make sure that you adhere to the following guidelines:

  • The BIG-IP TMOS must run a Linux kernel supported by the Falcon sensor, specifically BIG-IP VE versions mentioned above. F5OS must run a Linux kernel supported by Falcon sensor, specifically the versions mentioned above.
  • The Falcon sensor must have outbound network connectivity with the Falcon Cloud. You must permit an outbound TLS connection from the BIG-IP to the CrowdStrike cloud using HTTPS port 443 or by using an HTTP proxy. The Falcon sensor outbound traffic to Falcon/CrowdStrike cloud follows routing logic as described in K13284: Overview of management interface routing
  • Only one Falcon sensor can be installed for each Linux kernel of a BIG-IP and each F5OS tenant. The Falcon sensor can be installed concurrently on the hypervisor (F5OS-A or F5OS-C) and tenant (BIG-IP) software.

This offering includes a Falcon Insight XDR subscription and an OverWatch subscription, with a 7-day search retention period:

  • Insight XDR continuously monitors all endpoint activity and analyzes the data in real time to automatically identify threat activity, enabling it to detect advanced threats in real-time.
  • Falcon OverWatch is CrowdStrike's managed threat hunting solution that proactively hunts adversaries across attack surfaces.
  • 7-day search retention lets you scan recent events swiftly and easily with the ability to run a free text search or complex queries with regular expressions.

Licensing requirements

Effective October 15, 2026, customers deploying CrowdStrike Falcon on the BIG-IP system must obtain an F5 BIG-IP EDR Enablement add-on license for each target system, in addition to their CrowdStrike Falcon sensor subscription. A single BIG-IP EDR Enablement license authorizes the installation and operation of CrowdStrike Falcon sensors across:

  • All BIG-IP tenants hosted on that BIG-IP device
  • The devices underlying F5OS platform layer, where applicable (F5 Series and VELOS systems)

These licenses are available as an annual subscription and can be purchased directly from F5 or from F5 channel partners. They are add-on licenses applied to your existing base BIG-IP registration key. For step-by-step instructions on activating and attaching add-on registration keys to your base BIG-IP system, refer to K7752: Licensing the BIG-IP system.

Getting started with Falcon sensor for BIG-IP

New and existing CrowdStrike customers can benefit from using this offering. Use the following steps to get started with Falcon sensor for BIG-IP:

New CrowdStrike Customers

  1. Fill out the form at www.f5.com/go/contact/request-crowdstrike-falcon-sensors-for-big-ip to request access. Along with key contact information, you will need to state your organization and the number of sensors needed for your BIG-IP estate.
  2. After review and approval, you will receive an email with instructions for logging into the CrowdStrike cloud using your new Customer ID (CID).
  3. Follow the steps in K000156881: Install Falcon sensor for F5 BIG-IP on the BIG-IP system or F5 hardware platforms to deploy the Falcon sensor to your BIG-IP VE or hardware environment. To configure policies to correspond with the appropriate settings and monitor and manage telemetry and detections, refer to CrowdStrike's Falcon Sensor for F5 BIG-IP documentation (US-1, US-2, or EU-1).

    Note: You must be an active CrowdStrike customer to view documentation on CrowdStrike.

Existing CrowdStrike Customers

  1. Follow the steps outlined at www.f5.com/go/contact/request-crowdstrike-falcon-sensors-for-big-ip to request access. Along with other information, you will need to state your organization and the number of sensors needed for your BIG-IP estate.
  2. After review and approval, your account team will provide additional information.
  3. Follow the steps in K000156881: Install Falcon sensor for F5 BIG-IP on the BIG-IP system or F5 hardware platforms to deploy the Falcon sensor to your BIG-IP VE or hardware environment. To configure policies to correspond with the appropriate settings and monitor and manage telemetry and detections, refer to CrowdStrike's Falcon Sensor for F5 BIG-IP documentation (US-1, US-2, or EU-1).

    Note: You must be an active CrowdStrike customer to view documentation on CrowdStrike.

    Note: Existing customers receive a new CID for F5 BIG-IP deployments. CrowdStrike is unable to add this offering to existing CIDs.

    • If you have only one CID today, you will receive a new CID plus a parent CID to manage your original and new CID.
    • If you have multiple CIDs, you will receive a new CID that can be managed by the existing parent CID.
    • If you have multiple CIDs across multiple CrowdStrike clouds, please consult with your account team regarding which cloud to use for your new CID.
