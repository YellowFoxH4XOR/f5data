Known Issue

This is the result of a known issue. In rare circumstances, TMM may crash and dump core when using an iRule that invokes the SSL::renegotiate command from within an HTTP_REQUEST event. This issue occurs if the command is invoked after the client connection has started shutting down and the SSL profile has already been freed from memory.

F5 Product Development tracked this issue as ID 223625, ID 247729, ID 323717, and ID 328276 (formerly CR130850) and it was fixed in BIG-IP version 10.2.2. For information about upgrading, refer to the BIG-IP LTM release notes.

In addition, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.1.0-3402.0-HF2 issued for BIG-IP version 10.1.0 and cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1 issued for BIG-IP version 10.2.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
