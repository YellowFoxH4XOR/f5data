Description

You want to log an iRule error when an iRule command has a problem.

Environment

  • Using an iRule
  • An unexpected iRule command error occurs.
  • Because the error occurs rarely, you can't capture the traffic.

Cause

iRule (TCL) runtime errors.

Recommended Actions

You can use catch command to detect an iRule error and record a log.

For example, the following iRule records a log when HTTP::path has a problem.

when HTTP_REQUEST priority 500 {
  if {[catch {class match [HTTP::path] equals AllowedPath} errmsg]} {
    log local0. "Catch_err: ${errmsg}"
    log local0. "HTTP Request: [HTTP::request]"
    drop
  }
}

 

Additional Information

The above iRule works by providing a varName (errmsg) argument to the catch command. If catch encounters an error it returns a value of 1 (TCL_ERROR) and sets the value of varName to an error message. See catch on the TCL Wiki for more information.
