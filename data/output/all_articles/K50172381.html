K50172381: SNMPv3 failed to get data when using special character in the Privacy Password

Type
Support Solution
Published
2024-08-30
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K50172381

Description

When you create an SNMPv3 user via the GUI, if it contains a special character in the Privacy Password like '!', your SNMP client may not get data from BIG-IP device.  When you are testing in local device using snmpwalk, you may see this error message "Timeout: No Response from localhost".

For this command example

#snmpwalk -v3 -e 0x80001f88801c96d8107f282961 -l authPriv -u net-infra-snmp-2 -a SHA  -A 'P@sSW0rd!' -x AES -X "P@sSW0rd\!" localhost

The output is: Timeout: No Response from localhost

Environment

  • BIG-IP LTM
  • SNMPv3
  • Special Character

Cause

Unknown

Recommended Actions

  1. Do not use the special characters for the Privacy Password.
  2. If you really want to use the special character for Privacy Password, you have to create the user through TMOS.
    • Refer to K15731024: How to create a SNMPv3 user via TMOS to learn how to create SNMPv3 user via TMOS.
