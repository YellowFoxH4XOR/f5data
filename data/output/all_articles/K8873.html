Known Issue

This is the result of a known issue. If you configure a Network Access connection to map a drive or launch an application, the Network Access Connection established message appears after the FirePass client-side component performs drive mappings and launches applications. Additionally, if you configure a Static Application Tunnel (FirePass 6.x) or an Application Tunnel (FirePass 5.x) to launch an application, the Application Tunnel Connection established message does not appear until after the FirePass client-side component launches the application.

The correct behavior is for FirePass to display the Connection established message at the time the Network Access connection or Application Tunnel is established, which occurs prior to launching applications and mapping drives.

F5 Product Development tracked this issue as CR100361 and it was fixed in FirePass 6.0.3. For information about upgrading, refer to the FirePass release notes.

This issue still exists in the FirePass 5.x branch.

Additionally, Cumulative Hotfix HF-602-6 has been issued for FirePass 6.0.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
