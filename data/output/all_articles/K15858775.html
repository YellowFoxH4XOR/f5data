Description
The syslog-ng application can store fractions of a second in the timestamps. 

BIG-IP tmsh allows you to configure the syslog timestamp to include fractions of a second in either milliseconds or decimal format.

Environment

  • tmsh
  • syslog

Recommended Actions

Fractions of a second in milliseconds
 To configure syslog-ng to store millisecond in syslog timestamp, perform the following procedure:

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Configure syslog-ng to store millisecond in syslog timestamp, by typing the following command:

            modify sys syslog iso-date enabled

The BIG-IP system will now include millisecond fractions in syslog timestamps.

For example:  2020-03-05T11:11:08.018+13:00 bigip1.local info audit_forwarder[8956]: audit_forwarder started.  



Fractions of a second in decimal
To configure syslog-ng to store decimal fractions in syslog timestamp, perform the following procedure:
  1. Log in to tmsh by typing the following command:

    tmsh

  2. To define the desired syslog filter that references the remote server, type the following command:

    edit /sys syslog all-properties

    The syslog configuration opens in the vi text editor and appears similar to the following example:

    modify syslog {
        auth-    priv-from notice
        auth-    priv-to emerg
        cron-from warning
        cron    -to emerg
        daemon-from notice
        daemon-to emerg
        description none
        include none
        iso-date disabled
        kern-from notice
        kern-to emerg
        mail-from notice
        mail-to emerg
        messages-from notice
        messages-to warning
        remote-servers none
        user-log-from notice
        user-log-to emerg
    }

  3. Replace the include none line with the desired option.
    For example, to configure syslog-ng to store microsecond in syslog timestamp, use the following syntax:
        include "
        options {
        frac-digits(6);   
        };
        "             

  4. Exit the text editor by typing the following key sequence:

    :wq!

  5. At the Save changes prompt, type y to save the changes to the file:

    Save changes? (y/n/e)

    The tmsh utility prompt returns.

    Note: If the syslog filter contained syntax errors, the tmsh utility returns the following prompt:

    There were errors. Continue editing (y) or discard changes (n) (y/n)

  6. Save the configuration by typing the following command:

    save /sys config

The BIG-IP system will now include decimal fractions in syslog timestamps.

For example: 2020-03-05T12:28:39.515308+13:00 bigip1.local info audit_forwarder[8956]: audit_forwarder started.
