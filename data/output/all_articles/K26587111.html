Description

The Enterprise Manager 3.1.1 HF7 release was posted to the F5 Downloads site on May 16 and subsequently removed on May 17 due to a build system issue. This issue should not impact your Enterprise Manager installation if you have already installed HF7.

Enterprise Manager 3.1.1 HF8 will be available soon on on the F5 Downloads site. There is no functional difference between HF7 and HF8. The issue in HF7 will have no negative impact when installed on a system. However, it may prevent F5 Technical Support from comprehensively diagnosing the Enterprise Management system in the event of an issue requiring a support case. If you have installed HF7, please upgrade to HF8 when it becomes available on downloads.f5.com.
