Description

You want to redirect clients to a custom page when a web server returns a 404 response.

Environment

  • HTTP traffic
  • Responses

Cause

None

Recommended Actions

You may use an iRule or traffic policy to redirect to a custom page if a 404 status is found in a response.

Here is an example iRule:

when HTTP_RESPONSE {
    if { [HTTP::status] == "404" } {
        HTTP::respond 302 noserver Location "https://support.f5.com"
    }
}

Note: It is assumed that the custom page already exists at the destination URL.

Important: If the custom page is served by the same virtual server, ensure it does not also return a 404 status code, or the iRule logic can result in a loop. It would need to be modified in such a scenario.
