Source

Description

  • Where the MIB files can be downloaded from when using F5OS. 

Environment

  • F5OS

Cause

none.
 

 Recommended Actions

  1. Navigate to : SYSTEM SETTINGS > File Utilities
  2. Set the Base directory to : mibs
  3. Download the tarball of F5OS MIB files from this location.

none.
