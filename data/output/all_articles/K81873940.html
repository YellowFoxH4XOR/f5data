Known Issue

The bgp neighbor <peer IP> update-source <IP> command may apply a change to all peers in the peer group.

This issue occurs when all of the following conditions are met:

  • You are using Border Gateway Protocol (BGP) with peer groups.
  • You run the bgp neighbor <peer IP> update-source <IP> command, where <peer IP> is an IP address of a peer in a peer group.

Impact

The changes you made may apply to all peers in the peer group.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you run the bgp neighbor <peer IP> update-source <IP> command to a single peer, if the peer IP belongs to a peer group, the BIG-IP system may apply the changes to all peers in the peer group.

Workaround

Depending on the network setup, you may be able to work around the issue by using the interface version of the following command:

bgp neighbor <peer IP> update-source <vlan name>
