Known Issue

This is the result of a known issue. A policy-age-fileset configuration created with the ARX Manager Configuration utility Tiered Storage wizard may use the from command, which F5 Product Development removed in ARX version 5.1.0.

When using the Tiered Storage wizard in the ARX Manager Configuration utility to generate a policy-age-fileset configuration, an optional page of the wizard allows you to select an additional fileset that the policy uses to further restrict file selection.

The policy-age-fileset configuration that theTiered Storage wizard creates uses the from command for the additional fileset. However, when you load the policy-age-fileset configuration, the ARX system quietly ignores the from command and provides no indication that the system is not using the additional fileset.

Additionally, if you use the ARX command line interface to attempt to load the policy-age-fileset configuration, as configured by the Tiered Storage wizard, the from command fails. The command displays output that appears similar to the following example:

ARX1(gbl-fs-age[fs_test_tier-1])# from fileset fs_test_path
 % ERROR: Invalid input detected at '^' marker

F5 Product Development tracked this issue as ID 352000 and it was fixed in ARX version 6.0.0. For information about upgrading, refer to the ARX release notes.

Note: F5 Product Development removed the from command in ARX version 5.1.0 as part of a change in behavior referenced in K11358: Change in Behavior: The policy-simple-age-fileset and simple-age-fileset commands have been renamed.

Workaround

If the system requires multiple filesets to restrict file selection for a policy, you should use a policy-intersection-fileset command instead of a policy-age-fileset command. For information about the policy-age-fileset or policy-intersection-fileset commands, refer to the ARX CLI Reference Guide or the ARX CLI Storage-Management Guide.
