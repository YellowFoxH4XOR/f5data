Description

The Dashboard (Configuration Utility > Main > Statistics > Dashboard) has been redesigned in v14 to utilize REST API calls to retrieve data for populating the data points in the Dashboard.  This necessitates a good network connection between the client (web browser) and BIG-IP to facilitate the continuous data transfer.  You may find that a network connection through a VPN or with low bandwidth, will prevent the BIG-IP Dashboard from loading up correctly or take a long time to populate data.

Due to the redesign of the Dashboard, the BIG-IP system will also experience increased CPU utilization on the control plane as the REST API requests are processed.

Environment

  • BIG-IP Dashboard
  • v14 and above
  • Low bandwidth network
  • Increased CPU

Cause

ID956293

Recommended Actions

For optimal performance, follow these recommendations: 
  1. To meet the bandwidth requirements of the Dashboard, you may access the BIG-IP Configuration from another system within your organization with a high bandwidth connection to BIG-IP.
  2. Close the Dashboard when not in use to reduce the CPU on BIG-IP.

Additional Information

To further troubleshoot the Dashboard performance, you may review the REST API calls and responses using the developer tools on your web browser.  See the following article for details on how to access the developer tools on your web browser:

K10370211: Generating an HTTP Archive using a browser
