K000149609: Pod on VELOS controller or blade in ImageInspectError state

Source

Description

The openshift-ansible-service-broker pod was in ImageInspectError state.

For example, qkview shows lines similar to below.

The command is: /usr/bin/oc get all -o wide --all-namespaces --config=/opt/app-root/src/.kube/config >> /tmp/omd_qkview.log

openshift-ansible-service-broker    pod/asb-1-x5lgr                                     0/1       ImageInspectError   0          63d       100.76.0.240   controller-2.chassis.local   <none>

Environment

  • VELOS (observed on CX1610 controller)

Cause

Container image is corrupted.

Recommended Actions

This command would recover the corrupted docker cache on chassis controller and blade. During boot up, platform-deployment script copies required files over to /var/lib/docker.

  1. Run the following command on chassis controller to find where the pod is deployed.
    kubectl get pods -o wide --all-namespaces
  2. Make sure you go in the controller or blade where the pod with ImageInspectError state exists.
    ssh <controller-1|controller-2|blade-1|blade-2|blade-n>
    mv /var/lib/docker /var/lib/docker.deleteme
    reboot
