Known Issue

Files downloaded through the FirePass Windows Files portal may have the file extension changed to .zip. 

This issue occurs when a subset of the following conditions are met:

  • FirePass is being accessed by Internet Explorer 9 or later. 
  • FirePass is being accessed by Firefox 4 or later. 

This occurs when Windows Files portal access does not recognize the browser as a supported browser. When the browser is not recognized, the FirePass controller inserts a ContentType:application/x-zip-compressed header into the HTML data that is returned to the browser. The browser interprets this header and changes the file extension to .zip.

Note: Only the name of the file is changed, the contents are not changed. If the file is opened by a compression program, the program sees the file as corrupt. 

Impact

  • The proper program for the file type cannot open downloaded files. In addition, files with the same name but differing extensions are overwritten.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The web browser converts a downloaded file extension to .zip.

    For Example:

    If you click download and save locally on the file readme.doc, the system downloads the file as readme.zip.
  • The proper program for the file type cannot open downloaded files. 
  • If you download two files with the same name but different extensions, both file extensions change to .zip, and the second file you downloaded overwrites the first file you downloaded.

    For example:

    If you download the file readme.doc, and then download the file readme.txt, both file extensions change to .zip, causing the second download to overwrite the first download.

Workaround

To work around this issue, after the file is downloaded, you can rename the file to the original file name.

Impact of workaround: None
