Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following article:

  • K13405: Restricting Configuration utility access to clients using high encryption SSL ciphers (11.x)

High encryption Secure Sockets Layer (SSL) ciphers include those with key lengths larger than 128 bits, and some cipher suites with 128-bit keys.

By default, the BIG-IP Configuration utility allows for a large range of SSL ciphers to be used in order for SSL clients to connect to the Configuration utility. If you require a smaller, more secure list of SSL ciphers for Configuration utility access, you can modify the cipher list to only allow access to SSLv3, TLSv1 and keys that are 128 bits or higher.

For example, the following default cipher string for the BIG-IP 10.2.0 Configuration utility allows SSLv2 cipher suites, low key lengths that include 56 and 64 bits, and export cipher algorithm that include 40 and 56 bits:

ALL:!ADH:!EXPORT56:!eNULL:!MD5:RC4+RSA:+HIGH:+MEDIUM:+LOW:+SSLv2:+EXP

The following replacement string allows only high and medium (128 bits or larger) key lengths—no SSLv2 cipher suites are allowed (only SSLv3 or TLSv1 cipher suites), and no export or null cipher suites are allowed.

SSLCipherSuite ALL:!SSLv2:!EXPORT40:!EXP:!LOW

Disabling low encryption and anonymous ciphers and SSLv2 access to the BIG-IP Configuration utility

You can disable low encryption and anonymous ciphers, and SSLv2 access to the BIG-IP Configuration utility by performing one of the following procedures, depending on which version of the BIG-IP system you are running:

BIG-IP 9.4.2 through 10.x

Note: Beginning in BIG-IP 10.1.0, SSLv2 is disabled at the protocol level. Therefore, it is not necessary to disable the SSLv2 cipher in 10.1.0 and later.

To disable low encryption and anonymous ciphers, and SSLv2 access to the BIG-IP Configuration utility, perform the following procedure:

  1. Type the following command:

    bigpipe httpd sslciphersuite 'ALL:!ADH:!SSLv2:!EXPORT40:!EXP:!LOW'

  2. To save the configuration, type the following command:

    bigpipe save all

BIG-IP 9.0.0 through 9.4.1

To disable low encryption and anonymous ciphers, and SSLv2 access to the BIG-IP Configuration utility, perform the following procedure:

  1. Log in to the command line.
  2. Change directories to the /config/httpd/conf directory by typing the following command:

    cd /config/httpd/conf.d/

  3. Create a backup copy of the ssl.conf file by typing the following command:

    cp ssl.conf ssl.conf.original

  4. Using a text editor, edit the ssl.conf file.
  5. Locate the following entry:

    # SSL Cipher Suite: # List the ciphers that the client is permitted to negotiate. # See the mod_ssl documentation for a complete list. SSLCipherSuite ALL:!ADH:!EXPORT56:RC4+RSA:+HIGH:+MEDIUM:+LOW:+SSLv2:+EXP:+eNULL

  6. Comment out the following line:

    SSLCipherSuite ALL:!ADH:!EXPORT56:RC4+RSA:+HIGH:+MEDIUM:+LOW:+SSLv2:+EXP:+eNULL

  7. Add the following line after the line you commented out in step 6:

    SSLCipherSuite ALL:!ADH:!SSLv2:!EXPORT40:!EXP:!LOW

  8. Save the changes to the file.
  9. Restart httpd by typing the following command:

    bigstart restart httpd
