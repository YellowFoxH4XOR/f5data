K74410253: Management IP is not access able from only one device of a HA pair

Type
Support Solution
Published
2021-04-25
Updated
2025-02-07
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP LTM: 14.1.2
Source
https://my.f5.com/manage/s/article/K74410253

Description

You are not able to access management IP of one BIG-IP device in a HA pair. GUI access, SSH access and ping would fail on this management IP.

However you are able to access this management IP via any device within the same subnet.

The is no issue with the peer HA pair device. You are able access the GUI and SSH the peer device via its management IP.

There is no network related issue reported by your network team.

When running an arp output, there is no entry for the gateway. For example, if your gateway IP is 10.10.10.1, run the following command but no arp entry is seen:

arp | grep 10.10.10.1

Environment

  • BIG-IP
  • No connectivity with the BIG-IP's management IP
  • No issue with management IP of the HA pair peer BIG-IP
  • No network related issue
  • Gateway arp entry is not seen

Cause

arp entry for the gateway is not populated.

Recommended Actions

A mcpd reboot will resolve the issue.

  1. Log in to the Advanced Shell (bash).
  2. To create a null file with the file name forceload in the /service/mcpd directory, enter the following command:

    touch /service/mcpd/forceload

    On VIPRION systems, enter the following command to run this command on all blades:

    clsh touch /service/mcpd/forceload

  3. To restart the BIG-IP system, enter the following command:

    reboot

    On VIPRION systems, enter the following command to run this command on all blades:

    clsh reboot

Additional Information

None.
