K1457: Error messages: big3d: CFG:bcastTraverseMember: sendtostream No route to host:bcast.cpp:405 or big3d: CFG:bcastTraverseMember: sendtostream No route to host:bcast.cpp:405

Topic

The following error messages may appear in the 3-DNS Controller logs:

big3d: CFG:bcastTraverseMember: sendtostream No route to host:bcast.cpp:405

big3d: CFG:CProber::Send: send error for target <address>: No route to host:CProber.cpp:400

These messages occur when the big3d agent receives an ICMP No route to host message back from an intermediate device along the path of big3d to the device it is probing. This is a common occurrence, because an LDNS server might be a Unix client that connects with a dial-up and is then disconnected.

These errors can also occur when a router or firewall does not have a route configured to each of the devices that the big3d agent is probing. This will cause an ICMP message to be returned.

The returned ICMP messages are typically harmless; however, if the messages begin to fill up the log files, determine which devices are sending the ICMP messages and then verify the configuration of those devices.

Note: For information about configuring routers, refer to the 3-DNS manuals.
