Known Issue

This is the result of a known issue. When performing a subsequent re-installation of a BIG-IP 9.4 hotfix after uninstalling a previous hotfix version, the hotfix re-installation will fail and the following soft link creation error is received:

ln: `/etc/cron.hourly/wa_logrotate': File exists
error: %post(WA-1.0.F5-9.4.0.529.0) scriptlet failed, exit status 1

F5 Product Development tracked this issue as CR79275 and it was fixed in BIG-IP 9.4 HF4, and in BIG-IP 9.4.1. For information about upgrading, refer to the LTM, GTM, ASM, Link Controller, or WebAccelerator Release Notes.
