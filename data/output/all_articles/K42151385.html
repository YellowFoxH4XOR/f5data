Description

When sending logs using telemetry to Azure, you got an error similar to this from Operation table query results:

"Data of type F5Telemetry_* was dropped because number of fields * is above the limit of 500 custom fields per data type."

Running a query on Operation table under LogManagement category of Azure Monitor allow you to retrieve activities related to Azure Log Analytics workspace.

Environment

  • AS3
  • Telemetry
  • Azure

Cause

The Azure Log Analytics Consumer only supports sending 500 items. Each configuration item (such as virtual server, pool, node) uses part of this limit.

Recommended Actions
 

You can perform either one of the following actions:

  • Limit the number of fields sent in each data type in the telemetry declaration, using the Actions Chain. The example below will include just only the data specified in the declaration, for more information, you can review the following link (https://clouddocs.f5.com/products/extensions/f5-telemetry-streaming/latest/data-modification.html).

        "actions": [
     {
        "includeData": {},
        "locations": {
            "system": {
               "version$": true,
               "hostname": true
            },
            "iRules": true,
            "virtualServers": true,
            "pools": true
        }
      }
      ]

  •  Upgrade to Telemetry version 1.24.0 and add the following to your Telemetry declaration.
    {
      "class": "Telemetry",
      "My_Consumer": {
        "class": "Telemetry_Consumer",
        "type": "Azure_Log_Analytics",
        "workspaceId": "workspaceid",
        "passphrase": {
            "cipherText": "sharedkey"
        },
        "useManagedIdentity": false,
        "region": "westus",
        "format": "propertyBased" <<<<<<<<<<<<<<<<<<<
      }
    }

Additional Information

  • Azure added some items in version 1.24 to reduce the number of columns in the output which prevents a potential Azure error
