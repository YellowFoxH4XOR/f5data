Description

When submitting an ELA / FCP report from BIG-IQ to F5 automatically you get a pop-up box saying:
Unable to submit license report. Report generated but submission failed for “license key” (task): Report submission failed: curl: (58) could not load PEM client certificate, OpenSSL error error:0906D064:PEM routines:PEM_read_bio:bad base64 decode, (no key found, wrong pass phrase, or wrong file format?).
 

You may also see Scheduled reports have failed with an error message:
Report submission failed: curl: (58) could not load PEM client certificate, OpenSSL error error:0906D064:PEM routines:PEM_read_bio:bad base64 decode, (no key found, wrong pass phrase, or wrong file format?). It occured at Sep 20, 2021 15:19:55(BST). 
 

Or
Report submission failed: curl: (58) unable to set private key file: '/tmp/key12344321.key' type PEM. It occured at Sep 20, 2021 15:19:55(BST).
 

Environment

  • BIG-IQ
  • ELA / FCP Load / CAT licenses

Cause

When manually licensing a catalogue or Load license, it is not uncommon to do a bad copy and paste by accident.
The BIG-IQ does not valid the certificate or key segments of the license file, however this is used to communicate with api.f5.com during automatic report submissions.
If the Certificate or the key sections are corrupted, you will get the error message.
Note: this does not impact Being able to license Virtual BIG-IP devices.

Recommended Actions

Reactivate the registration key. You can either follow Reactivate a registration key with License Manager (automatic method) or Reactivate a registration key with License Manager (manual method).

If issue still persist even after re-activating registration key:

  1. Please raise a support case via https://support.f5.com
  2. State the error message and provide screenshot
  3. Share all license registration key(s) in the support ticket.
  4. Ask in the support case to do an "allow move" on each of the license registration keys
  5. Once the "allow move" has been done you can do the license reactivation process: How to reactivate an ELA license in BIG-IQ

Note: For urgent requests please reach out to your Customer Success manager.
