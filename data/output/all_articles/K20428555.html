Description

  • How to configure SAML SSO with Thomson Reuters OneSource

Environment

  • BIG-IP APM
  • SAML federation/SSO (BIG-IP as IdP)

Cause

SAML with Thomson Reuters One Source uses the Relay-State to match a SAML assertion with a configured customer/application. This is different from other SAML implementations, which use the configured Identity ID.

Recommended Actions

  • Configure Relay-State in Endpoint Settings of External SP Connector config

    apm sso saml-sp-connector /Common/SP_TR_Law_EXAMPLE {
        assertion-consumer-services {
            {
                is-default true
                uri https://trtasso.thomson.com/sp/ACS.saml2
            }
        }
        description "External SP Connector Thomson Reuter One Source"
        entity-id trtasso.thomson.com
        relay-state https://trtasso.thomson.com/sp/startSSO.ping\?PartnerIdpId=https://uat-login.zyx.com.au/TR_Law_QA&TargetResource=https%3A%2F%2Fwww.xyz.com.au
        signature-type rsa-sha256
        single-logout-uri https://trtasso.thomson.com/sp/SLO.saml2
        sp-certificate /Common/SP_TR_Law_PROD__saml_sp_metadata_sig_cert.crt
    }
