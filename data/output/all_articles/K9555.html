K9555: Static hostnames are not added to Mac OS X or Linux clients

Knowledge
Published
2009-07-06
Updated
2023-02-21
Status

Applies to

  • FirePass: 6.0.3, 6.0.2, 6.0.1, 6.0.0
Source

Topic

If static host names are configured in the Network Access: Resources: Hosts tab, the host names will only work on Windows clients. FirePass does not currently support this feature for Linux or Mac OS X clients. If a Windows client connects, the host names will be added to the host file at the following location:

C:\WINDOWS\system32\drivers\etc\hosts

Because Linux and Mac OS X clients' host files are located in a different path, the FirePass Controller currently does not write to this host file.

If possible, add the needed records to your client's DNS. If you do not have access to add such records, you can instruct your users to manually add the records to their /etc/hosts file. To manually add the records, the users must have root privileges.

Important: Records added to the /etc/hosts file will supercede DNS even if they are no longer connected to FirePass.
