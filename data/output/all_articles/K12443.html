Topic

Occasionally, some antivirus software may identify various BIG-IP Edge Client components or plug-ins as malware or a virus. This issue typically occurs with third-party companies that implement a network heuristics solution with their antivirus software.

In the event that the antivirus software solution you are using identifies a BIG-IP Edge Client component or plug-in as malicious, you can report the false positive to your antivirus software vendor and to F5 Technical Support. The antivirus software vendor will need to update the antivirus client libraries to correct the issue.
