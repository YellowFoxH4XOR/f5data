Known Issue

The Traffic Management Microkernel (TMM) may restart when rapidly deleting and creating external Data Groups.

This issue occurs when all of the following conditions are met:

  • A virtual server is configured with an iRule that references an external Data Group.
  • The external Data Group is deleted and re-created in rapid succession.

This issue may occur, for example, if you use scripts for Data Group management. If you use Traffic Management Shell (tmsh) commands within a bash script, the system allows automated Data Group management. However, using scripts to delete and immediately re-create the same Data Group repeatedly may cause TMM to restart.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from TMM restarting. If the BIG-IP system is configured as part of a high-availability system, a device failover may occur.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system fails over to the standby system if configured for high-availability.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.

Workaround

To work around this issue, after deleting an external Data Group, you can re-create it with a different name using the Configuration utility or the tmsh utility. To do so, perform one of the following procedures:

Note: If you removed the iRule that references the Data Group from the virtual server, be sure to add the iRule back to the virtual server after completing the procedure.

Importing an external Data Group using the Configuration utility

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > File Management > Data Group File List.
  3. Click Import.
  4. From the File Contents box, select the file to import and the type of content.
  5. Type a different name into the Name box than the one previously used.
  6. To create the external Data Group, click Import.

Importing an external Data Group using the tmsh utility

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Create the external Data Group using the following command syntax:

    create ltm data-group external <dg-name> external-file-name <file-name>

    For example, if the Data Group name is dg_external and the external file is named ext_dg_file, the command would be the following:

    create ltm data-group external dg_external external-file-name ext_dg_file

  3. Save the change by typing the following command:

    save /sys config

  4. To exit the tmsh utility, type quit and press Enter.
