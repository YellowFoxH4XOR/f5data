Known Issue

This is the result of a known issue. When you configure a Reauthentication Timeout on the Device Management : Security : Timeouts page, users receive a Reauthentication Timeout pop-up window five minutes before logout, indicating that their session will be terminated. However, if you configure a separate Inactivity Timeout and a separate Reauthentication Timeout for a master group, users in that master group may be logged out of FirePass without receiving the Reauthentication Timeout pop-up window.

Note: For more information about Inactivity Timeouts and Reauthentication Timeouts, refer to K3106: Configuring server-side session timeouts.

F5 Product Development is tracking this issue as ID 266703 (formerly CR70439).

This issue has been fixed in cumulative hotfix HF-610-5, which has been issued for FirePass version 6.1.0 and cumulative hotfix HF-70-4.1 for FirePass version 7.0.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
