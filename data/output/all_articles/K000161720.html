K000161720: High Swap Memory Usage on BIG-IP ASM Virtual Edition

Type
Support Solution
Published
2026-07-06
Updated
2026-07-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000161720

Description

Persistently high swap memory utilization is observed on BIG-IP ASM Virtual Edition systems, often ranging between 80% and 90%, even when physical memory appears available. This can lead to performance degradation and potential system instability.


Symptoms include:

  • Swap memory at or near 100% utilization (e.g., SwapFree: 520 kB out of SwapTotal: 1023996 kB)
  • High control plane memory pressure is visible in the memory usage graphs
  • Elevated load averages and increased system resource consumption
  • free -m output showing swap fully consumed with minimal free physical memory


Environment

Product: BIG-IP ASM

Version: 17.1.3 (may apply to other versions)

Module: ASM provisioned and active

Platform: Virtual Edition

Configuration: Default or suboptimal values for the following system DB variables:

  • provision.extramb
  • provision.restjavad.extramb
  • provision.tomcat.extramb


Cause

High swap memory usage is caused by insufficient memory allocation to management and control plane processes (provision.extramb, provision.restjavad.extramb, provision.tomcat.extramb). The default values do not meet the requirements for ASM, which is resource-intensive, resulting in persistent swap usage and potential performance degradation.


Answer/Recommended Actions

Increase the memory allocation for management and control plane processes:


Log in to the TMSH shell:

  • tmsh

Modify the provisioned memory values:

  • modify /sys db provision.extramb value 2048
  • modify /sys db provision.restjavad.extramb value 1024
  • modify /sys db provision.tomcat.extramb value 256

Note: It will depend on how much free memory you have. You can check with the command show /sys memory.


Save the configuration:

  • save /sys config partitions all

Restart the relevant services:

  • tmsh restart sys service httpd restjavad restnoded

Monitor swap and memory usage after the changes to confirm improvement.


If operating in a High Availability (HA) pair, apply the same configuration changes to both devices.


Additional Information

Traffic impact considerations:

  • Changing provision.restjavad.extramb and restarting httpd, restjavad, and restnoded services affects only the GUI and REST API functionality—no traffic disruption is expected.
  • Changes to provision.extramb may trigger control plane service restarts and could cause a temporary traffic interruption. Devices in an HA pair may fail over. F5 recommends applying this change during a scheduled maintenance window.

For HA environments, it is possible to apply the provision.restjavad.extramb change to the standby device first without requiring a maintenance window, as it does not affect traffic.


Continuous high swap usage on BIG-IP is not normal behavior and indicates memory pressure, particularly when resource-intensive modules such as ASM or AVR are provisioned.


After applying the recommended values, a significant reduction in swap utilization should be observed in the memory usage graphs.
