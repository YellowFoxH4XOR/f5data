Known Issue

Description

Adding entries to the BIG-IP session table from within an iRule may use up to double the memory than expected to store objects.

This issue occurs when either of the following conditions is met:

  • You are using the session add command from within an iRule.
  • You are using the table add command from within an iRule.

For example, if you have loaded 1 GB of data into a session table, the BIG-IP system may use up to 2 GB of memory to store this data. This unexpected extra memory usage may be larger than the total memory allocated for TMM.

Impact

System instability may occur, including poor performance and possible system restarts.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Higher than expected TCL variable memory usage

You can monitor TCL variable memory usage by entering the following command:

tmsh show sys memory

The TCL variable database memory is located under the tcl (variable) section.
