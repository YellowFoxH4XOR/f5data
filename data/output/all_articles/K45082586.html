K45082586: Login fail for local and remote authentication methods

Type
Support Solution
Published
2020-11-10
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K45082586

Description

Login to an BIG-IP box may fail

  • Both local and remote authentication methods are affected.
  • Build-in root and admin accounts are affected as well
  • In TMUI (Configuration Utility) following error is observed
    Login Failed
  • Following message is observed while trying to SSH to the affected box
    The client has disconnected from the server. Reason:
    Unable to authenticate using any of the configured authentication methods.

Environment

There is not specific environment for the issue to be occure

Cause

The issue can be caused due to number of reasons

  • File system error
  • Disk overfill
  • Disk errors
  • For Virtual Editions underlying hard drives or file system errors

Recommended Actions

To get access to the box, restart is required.
To prevent issue from occurring in the future, main issue need to be solved. The steps are depends on the root cause. Please follow Related Content section to find more details.

Additional Information

In case if disk failure is suspected, run EUD tests. Please follow your platform manual to know more about EUD test
