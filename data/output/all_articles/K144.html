Known Issue

This is the result of a known issue. BIG-IP switch appliances use internal hidden interfaces to communicate between the system motherboard and the switchboard. The statistics for these interfaces do not normally display unless you use the bigpipe vlan <vlan> fdb show command, which displays the internal interfaces, as well as the interfaces that are included in the VLAN.

F5 Networks Product Development tracked this issue as CR35906 and CR51441, and it was fixed in BIG-IP version 4.5.14. For information about upgrading, refer to the BIG-IP Release Notes.

This issue still exists in the 4.6 software branch.
