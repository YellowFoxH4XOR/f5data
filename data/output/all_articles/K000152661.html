Description

Publishing an NGINX [Plus] configuration fails with one of the following UI error messages:

"<instance_name>: failed building config payload: secret not found"
"<instance_name>: failed building config payload: failed to retrieve secret"

Environment

NGINX Instance Manager

Cause

This issue may occur when NIM fails to retrieve one or more Managed certificates that are referenced in the NGINX [Plus] configuration being published.

Recommended Actions

Navigate to Manage > Certificate and Keys and re-upload the certificate and key on each Managed certificate that is referenced in the configuration that fails to publish.
