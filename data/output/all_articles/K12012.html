Topic

Starting in BIG-IP APM and Edge Gateway 10.1.0 with Hotfix-BIGIP-10.1.0-3402.0-HF2 installed and in BIG-IP 10.2.0, the link for Windows Mobile 2003 has been removed from the Access Policy: Connectivity Profiles: Components Download tab. F5 no longer supports handheld devices using Windows Mobile 2003, and these devices will be unable to successfully connect to a BIG-IP APM or Edge Gateway device. The link was legacy from when F5 supported Windows Mobile 2003.

Note: To view a full list of currently supported software, refer to the the BIG-IP Access Policy Manager Client Compatibility Matrix.

Additionally, this feature was added in Hotfix-BIGIP-10.1.0-3402.0-HF2 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.
