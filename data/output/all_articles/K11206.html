K11206: Network Access and Application Tunnel favorites may fail with an 'Error downloading required components' error message on Windows 7 clients

Topic

When launching a Network Access or Application Tunnel favorite on a Windows 7 client, the favorite may fail to connect, and the system may display an error message that appears similar to the following example:

Error downloading required components.
Access is denied.

This behavior occurs when all of the following conditions are met:

  • User Account Control (UAC) is enabled on the Windows client.
  • The user’s Windows account does not have administrator rights.
  • The FirePass Component Installer is not installed on the Windows client.

Currently, users that run Windows 7 must log in to Windows as a local administrator in order to install the FirePass or Edge client components required for Network Access and Application Tunnel favorites. Alternately, if a Windows administrator installs the FirePass or Edge Component Installer, all users on the Windows 7 system can install and update FirePass or Edge client components regardless of their privilege levels.

Note: You can download the Component Installer on the Device Management: Client Downloads: Windows (x86) page in the FirePass Administrative Console or on the Overview: Welcome page in the BIG-IP APM Configuration Utility.

F5 Product Development tracked this RFE as ID 294318 (formerly CR136512) and it was added starting in BIG-IP APM 10.2.0 and FirePass 7.0.0. Users that run Windows 7 and know the local administrator password are now able to install the FirePass and Edge client components even when they are logged in as a user with limited privileges. For information about upgrading, refer to the BIG-IP APM or FirePass release notes.
