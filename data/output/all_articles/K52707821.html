Known Issue

When you use tab completion in the TMOS Shell (tmsh), the force-full-load-push option is not available.

This issue occurs when the following condition is met:

  • You attempt to perform tmsh tab completion using a command similar to the following:

    run cm config-sync to-group <group> <TAB>

    In this command syntax, <group> is the name of your device group and <TAB> is pressing the TAB key to perform tab completion.

Impact

You cannot use tab completion to perform a configuration synchronization (ConfigSync).

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you press the TAB key after typing the run cm config-sync to-group <group> command, the system fails to display force-full-load-push as an option.

Workaround

To work around this issue, you can type the full command without using tab completion.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
