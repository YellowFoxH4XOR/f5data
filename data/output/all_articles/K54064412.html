Description

When deploying an iApp and changing the configuration directly from the Local Traffic main menu of the Configuration Utility, the iApp reconfigure tab settings do not match with the configurated virtual server objects or the components of the iApp.

Environment

  • BIG-IP
  • Deployment with an iApp template

Cause

The virtual server deployed through iApps was modified directly via the Local Traffic main menu of the Configuration Utility instead of iApps.

Recommended Actions

To avoid this behavior, it is recommended to always do modifications directly from the iApps reconfigure menu.

Additional Information

In order to make modifications to the application service is required to uncheck the "Strict Updates" setting of the properties tab.
F5 recommends that you leave the Strict Updates setting enabled, and make any changes to the iApp's configuration by modifying the template.
