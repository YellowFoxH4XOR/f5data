Known Issue

Description

Virtual address ICMP Echo and ARP-enabled settings may not be honored when loading a configuration.

This issue occurs when all of the following conditions are met:

  • You enable ICMP Echo and/or ARP settings for a virtual address that matches a network prefix (network virtual server).
  • You save the configuration.
  • You delete and reload the virtual address from the saved configuration file.

Note: When a virtual address matches a network prefix, the default setting for ICMP Echo and ARP is disabled.

If you delete a virtual address that matches a network prefix, and then load a configuration file to restore the virtual address, the ICMP Echo and ARP settings reset to the default setting of disabled even if the settings were enabled in the saved configuration.

Impact

ICMP Echo and ARP behavior are no longer enabled for the virtual address.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H436972 on the Diagnostics > Identified > Low screen.
  • After you load the configuration, the ICMP Echo and ARP properties for the affected virtual server are set to disabled.
  • ICMP Echo and ARP behavior stop for the affected virtual address.

Workaround

To work around this issue, you can re-enable the ICMP Echo and/or ARP properties for the affected virtual address after you load the configuration. To do so, perform one of the following procedures:

Impact of workaround: Performing the following procedures should not have a negative impact on your system.

Using the tmsh utility to enable ICMP Echo and ARP

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Configure the desired ICMP Echo setting for a virtual address by using the following command syntax:

    modify ltm virtual-address <nnn.nnn.nnn.nnn> icmp-echo enabled|disabled

    For example, to enable ICMP Echo for virtual address 10.10.10.0, type the following command:

    modify ltm virtual-address 10.10.10.0 icmp-echo enabled

  3. Configure the desired ARP setting for a virtual address using the following command syntax:

    modify ltm virtual-address <nnn.nnn.nnn.nnn> arp enabled|disabled

    For example, to enable ARP for virtual address 10.10.10.0, type the following command:

    modify ltm virtual-address 10.10.10.0 arp enabled

  4. Save the change by typing the following command:

    save /sys config

Using the Configuration utility to enable ICMP Echo and ARP

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Click the Virtual Address List tab.
  4. Select the name of the affected virtual address.
  5. Select the ARP Enabled check box.
  6. Select the ICMP Echo Enabled check box.
  7. Click Update.
