Topic

You should consider using this procedure under the following condition:

  • You want to modify the encryption ciphers, the key exchange (KEX) algorithms, or the Message Authentication Code (MAC) algorithms used by the secure shell (SSH) service on the BIG-IP system or the BIG-IQ system.

Description

You can configure the SSH service (also known as sshd) to use a desired set of encryption ciphers, KEX algorithms, and MAC algorithms to meet the security policy enforced in your environment. This article discusses how to accomplish this by modifying the SSH service configuration using the TMOS shell (tmsh).

By default, the TMOS sys sshd configuration does not include a specific set of ciphers or MAC algorithms for BIG-IP and BIG-IQ systems. The default sys sshd configuration for BIG-IP 15.0.1 appears similar to the following example:

sys sshd {
    allow { ALL }
    banner disabled
    banner-text none
    description none
    fips-cipher-version 0
    inactivity-timeout 0
    include none
    log-level info
    login enabled
    port 22
}

The include statement is the line in the TMOS sys sshd configuration where you can include a list of specific encryption ciphers, KEX algorithms, or MAC algorithms into the /config/ssh/sshd_config configuration file. The keywords Ciphers, KexAlgorithms, and MACs are used with the include statement when you specify a list of desired ciphers, KEX algorithms, or MACs. These override pre-existing keywords in the /config/ssh/sshd_config configuration file.

Note: F5 does not support editing the /config/ssh/sshd_config file directly.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrator access to tmsh.
  • You are familiar with the vi text editor.

Procedures

Displaying the configuration of the SSH service

To display the current configuration of the SSH service, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To display the list of ciphers, KEX algorithms, and MAC algorithms used by the SSH service, type the following command:

    list /sys sshd all-properties

  3. To exit tmsh, type q and press Enter.

Modifying the list of ciphers, KEX algorithms, and MAC algorithms used by the SSH service

Note: Incoming SSH sessions are handled by the settings in the /config/ssh/sshd_config file. The available KEX algorithms, MAC algorithms, and ciphers for each software version are found in the sshd_config man page.

To modify the encryption ciphers, KEX algorithms, or the MAC algorithms for the SSH service, perform the following procedure. You can configure one, two or all three cryptographic keywords.

Important: On a VIPRION system, at least one Cipher, one KEX algorithm, and one MAC from the ciphers used by the ssh client must be included for blade-to-blade communication to allow SSH between slots and qkview collection. For the list of ciphers, refer to the /config/ssh/ssh_config file.

Impact of procedure: Performing the following procedure should not have a negative impact on your system. The currently connected SSH sessions will not be interrupted, however, they will not be able to use the revised list of ciphers/MACs that are requested in this procedure until you establish a new SSH connection.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To modify the sshd configuration, type the following command to start the vi editor:

    edit /sys sshd all-properties

  3. To change the list of ciphers, you can navigate to the line that starts with the include statement, and use the keyword Ciphers to add or modify the list of ciphers for the SSH service.

    For example, take the following list of ciphers:

    aes128-cbc,aes128-ctr,aes192-ctr,aes256-ctr,arcfour128,arcfour256,arcfour

    To use that list of ciphers, modify the include statement to appear similar to the following example:

    include "Ciphers aes128-cbc,aes128-ctr,aes192-ctr,aes256-ctr,arcfour128,arcfour256,arcfour"

  4. To change the list of MACs, you can append a new line with the keyword MACs on the same include statement where you have added the keyword Ciphers.

    For example, take the following list of MACs:

    hmac-sha1,hmac-ripemd160,hmac-ripemd160@openssh.com

    To use that list of MACs, you can append the selected MACs to the include statement, together with the list of ciphers in the earlier example, using the MACs keyword, and adding the list of desired MACs to the 2-line include statement. The include statement appears similar to the following example:

    include "Ciphers aes128-cbc,aes128-ctr,aes192-ctr,aes256-ctr,arcfour128,arcfour256,arcfour
    MACs hmac-sha1,hmac-ripemd160,hmac-ripemd160@openssh.com"

  5. To change the list of KEX algorithms, you can append a new line with the keyword KexAlgorithms on the same include statement where you have added the other keywords.

    For example, take the following list of KEX algorithms:

    ecdh-sha2-nistp256,ecdh-sha2-nistp384

    To use that list of KEX algorithms, you can append them to the include statement, together with the lists in the earlier example, using the KexAlgorithms keyword, and adding the list of desired algorithms to the 3-line include statement. The include statement appears similar to the following example:

    include "Ciphers aes128-cbc,aes128-ctr,aes192-ctr,aes256-ctr,arcfour128,arcfour256,arcfour
    MACs hmac-sha1,hmac-ripemd160,hmac-ripemd160@openssh.com
    KexAlgorithms ecdh-sha2-nistp256,ecdh-sha2-nistp384"

    After you complete the modification, the full sys sshd configuration may appear similar to the following example:

    sys sshd {
    allow { ALL }
    banner disabled
    banner-text none
    description none
    inactivity-timeout 0
    include "Ciphers aes128-cbc,aes128-ctr,aes192-ctr,aes256-ctr,arcfour128,arcfour256,arcfour
    MACs hmac-sha1,hmac-ripemd160,hmac-ripemd160@openssh.com
    KexAlgorithms ecdh-sha2-nistp256,ecdh-sha2-nistp384"
    log-level info
    login enabled
    port 22
    }

  6. Save the changes for the sys sshd configuration and exit the vi editor.
  7. Respond y to the prompt asking to save the changes.
  8. To save the configuration to disk, type the following command:

    save /sys config

  9. To exit tmsh, type q and press Enter.

    Note: You do not need to restart the sshd service; the new changes are active once you save the configuration.


Deploying sshd include settings which require multiple lines, via Bash

tmsh does not intuitively allow multiple lines for the sshd include statement. The Ctrl+v, Ctrl+j key sequence can be used while in the TMOS shell which allows multiple lines (see ^J instances below):
     root@(bigip1)(tmos)# modify sys sshd include "Ciphers aes128-ctr ^J MACs hmac-sha2-256 ^J KexAlgorithms ecdh-sha2-nistp256"

The above translates to the below sshd include modification:

[root@bigip1] config # tmsh list sys sshd
sys sshd {
    include "Ciphers aes128-ctr
MACs hmac-sha2-256
KexAlgorithms ecdh-sha2-nistp256"
}

We can emulate the above in Bash by calling tmsh in command mode:
     tmsh -c " $(echo -e "modify sys sshd include \"$(echo "\n") <line 1> $(echo "\n") <line 2> $(echo "\n") <line 3> $(echo "\n")\"") "

Example:
tmsh -c " $(echo -e "modify sys sshd include \"$(echo "\n") Ciphers aes128-ctr $(echo "\n") MACs hmac-sha2-256 $(echo "\n") KexAlgorithms ecdh-sha2-nistp256 $(echo "\n")\"") "

[root@bigip1] config # tmsh list sys sshd
sys sshd {
    include "
 Ciphers aes128-ctr
 MACs hmac-sha2-256
 KexAlgorithms ecdh-sha2-nistp256
"
}

For different formatting, adjust the echo or add tab (/t):
tmsh -c " $(echo -e "modify sys sshd include \"Ciphers aes128-cbc,aes128-ctr $(echo "\n\t") MACs hmac-sha2-256 $(echo "\n\t") KexAlgorithms ecdh-sha2-nistp256\"") "

[root@bigip1] config # tmsh list sys sshd
sys sshd {
    include "Ciphers aes128-cbc,aes128-ctr
         MACs hmac-sha2-256
         KexAlgorithms ecdh-sha2-nistp256"
}

Save the config to apply the changes.

 tmsh save sys config


Restoring the include setting of the SSH configuration to the default value

To restore the include setting of the SSH configuration to the default value, perform the following procedure.

Impact of procedure: Performing the following procedure will remove any custom values for the include setting of the SSH configuration.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To restore the include setting to the default value, type the following command:

    modify /sys sshd include none

  3. To view the sys sshd configuration to confirm the changes, type the following command:

    list /sys sshd all-properties

    The output will appear similar to the following example:

    sys sshd {
        allow { ALL }
        banner disabled
        banner-text none
        description none
        inactivity-timeout 0
        include none
        log-level info
        login enabled
    }

  4. Save the configuration by typing the following command:

    save /sys config

  5. To exit tmsh, type q and press Enter.

    Note: You do not need to restart the sshd service; the new changes are active once you save the configuration.
