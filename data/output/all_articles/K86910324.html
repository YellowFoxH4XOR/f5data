Description

Error message displayed when trying to access the WebUI:

This BIG-IP system has encountered a configuration problem that may prevent the Configuration utility from functioning properly. To prevent adverse effects on the system, F5 Networks recommends that you restrict your use of the Configuration utility to critical tasks only until the problem is resolved. Beware that attempting to modify your configuration in this state with the Configuration utility may cause your configuration to be overwritten.

Environment

  • WebUI
  • Configuration utility

Cause

Unknown

Recommended Actions

Restart the httpd and tomcat daemons with the following command:

tmsh restart sys service tomcat httpd

This command will not impact the network traffic.

Additional Information

This message can also come up after an upgrade on an iSeries platform running into this separate issue: K22559295: BIG-IP iSeries platform LCD panel displays "Firmware update in Progress may take up to 30 minutes" indefinitely after an upgrade.
