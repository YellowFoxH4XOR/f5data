K000152997: How to Generate a Support Package for NGINX Products Deployed in a Kubernetes Cluster

Type
Support Solution
Published
2025-08-13
Updated
2025-08-13
Applies to
  • NGINX Products
  • NGINX Ingress Controller: 3.7.X, 5.X.X, 4.X.X, 5.1.X, 5.1.0, 5.0.X, 5.0.0, 4.0.X, 4.0.0, 3.7.1, 3.7.0
  • NGINX Open Source
  • NGINX Plus: R35, R34, R33, R32, R31, R30
  • NGINX Gateway Fabric: 2.X.X, 2.0.X, 2.0.0, 2.0.1
Source
https://my.f5.com/manage/s/article/K000152997

Description

  • You are using one of NGINX products deployed in a Kubernetes cluster.
  • You want to collect diagnostic data for the this NGINX product

Environment

  • NGINX Ingress Controller
  • NGINX Gateway Fabric
  • NGINX Plus
  • NGINX OSS
  • Kubernetes
  • Kubectl
  • Krew

Cause

  • None

Recommended Actions

  1. Install Kubernetes Plugin Manager 'krew' if not installed (for instructions check the 'Additional Information' section)
  2. Verify 'krew' installation:
    # kubectl krew version

Expected Output: 

OPTION            VALUE
GitTag            v0.4.5
GitCommit         e7e5b61
IndexURI          https: //github .com/kubernetes-sigs/krew-index .git
BasePath          /root/.krew
IndexPath         /root/.krew/index/default
InstallPath       /root/.krew/store
BinPath           /root/.krew/bin
DetectedPlatform  linux/amd64

     

  3. Install nginx-supportpkg plugin:
    kubectl krew install nginx-supportpkg
  4. Verify nginx-supportpkg installation:
    # kubectl krew list
   PLUGIN            VERSION
   krew              v0.4.5
   nginx-supportpkg  v0.1.7  <--
  5. Generate a support package:  
    kubectl nginx-supportpkg -n <NAMESPACE> -p <NGINX PRODUCT>

    Example:

    kubectl nginx-supportpkg -n my-namespace -p nic

Additional Information

  • To install 'krew', follow instructions provided here (This link is not maintained by F5)
