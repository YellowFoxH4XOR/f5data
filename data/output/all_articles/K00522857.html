Description

Each BIG-IP instance requires its own license; each license contains attributes unique to that specific BIG-IP instance. If a BIG-IP instance is configured as part of a high availability (HA) configuration with other BIG-IP instances, its license is unchanged and is not sync between its HA peers.

Environment

  • BIG-IP high availability
  • BIG-IP license

Cause

None.

Recommended Actions

If you are planning to setup a BIG-IP HA pair, you should ensure you have a separate license for each of the BIG-IP instance in the HA pair and activate the appropriate license on each of them. For information on licensing your BIG-IP instances using different methods, refer to the following articles:

  • K2595: Activating and installing a license file from the command line
  • K7752: Licensing the BIG-IP system

If you are planning to upgrade your BIG-IP HA pair, you should ensure you reactivate the licenses for each of the BIG-IP instance in the HA pair prior to upgrading them. For more information, refer to K7727: License activation may be required before a software upgrade for BIG-IP.

Additional Information

None.
