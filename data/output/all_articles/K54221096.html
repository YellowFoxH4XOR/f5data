K54221096: A single NIC configuration is not supported prior to BIG-IQ VE 8.0

Description

Prior to BIG-IQ 8.0.0, creating a BIG-IQ virtual edition (VE) instance using a single network interface card (NIC) is not supported. Two or more NICs are required for BIG-IQ VE 7.x and earlier versions. For more information about single NIC support, refer to the Behavior Changes in BIG-IQ Version 8.0.0 section of the BIG-IQ Centralized Management Release Notes: 8.0.0.

Upgrading BIG-IQ VE from versions earlier than 8.0.0 that have a single NIC configuration results in unexpected failures. To avoid the upgrade issues, ensure that the BIG-IQ VE instance has at least two NICs; add an additional NIC if it has only one.

For information about BIG-IQ VE installation and setup, refer to the various Setup guides on the BIG-IQ Centralized Management Knowledge Center.
