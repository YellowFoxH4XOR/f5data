K000154599: Despite the ICMP Echo and ARP options being disabled, the virtual address still replies to ICMP and ARP requests.

Description

On BIG-IP LTM systems, when virtual addresses are configured with a /32 netmask, disabling the ICMP and ARP response options in the virtual address settings does not take effect as intended. The BIG-IP device continues to respond to ICMP Echo (ping) and ARP requests on these /32 virtual addresses even after these options are disabled. This may cause unexpected behaviour, such as the BIG-IP responding directly to ping and traceroute requests that should otherwise be forwarded through the network.
 

Environment

BIG IP LTM

Configuration: Virtual addresses using a /32 netmask with ICMP Echo and ARP response options disabled

 

Cause

BUG ID 1987405
 

Recommended Actions

Workaround:

 

If it is critical to disable ICMP/ARP responses on /32 virtual addresses, perform a TMM restart after making the configuration change:

 

Command:

#bigstart restart tmm

 

Warning: Restarting TMM will interrupt data plane traffic; schedule this action during a maintenance window.
