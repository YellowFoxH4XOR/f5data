Known Issue

Viewing BIG-IP persistence records may cause memory to leak.

This issue occurs when the following condition is met:

  • You use the Traffic Management Shell (tmsh) to view persistence records.

    For example:

    tmsh show ltm persistence persist-records mode source-address key <ip address> all-properties

Impact

A small amount of memory is used to gather and display the persistence record that is not returned to the system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing persistence records repeatedly, the amount of utilized memory steadily increases.
  • In extreme memory utilization scenarios (viewing persistence records thousands or millions of times), your BIG-IP system experiences performance degradation over time and reboots.
