Known Issue

When faced with an out of memory condition, the BIG-IP ASM bd process may stop responding.

This issue occurs when the following condition is met:

  • The BIG-IP ASM bd process is unable to allocate new memory.

Impact

The BIG-IP ASM system may temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system logs an error message to the /var/log/ts/bd.log file that appears similar to the following example:

    Failed to allocate memory for converted key and value

  • The BIG-IP ASM bd process logs a core file in the /var/core directory.
