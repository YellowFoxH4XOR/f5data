Description

Is NGINX vulnerable to Insecure Transport: SSLv3/TLS Renegotiation Stream Injection CVE-2009-3555?


Environment

NGINX


Cause

Security Vulnerability


Recommended Actions

The TLS renegotiation MITM attacks vulnerability identified with CVE-2009-3555 has been patched since early NGINX Open Source versions 0.7.64 and 0.8.23.

Refer to the release notes located in https://nginx.org/en/CHANGES-0.7 and https://nginx.org/en/CHANGES-0.8 and security advisory located in https://nginx.org/en/security_advisories.html (the fourth advisory counting from the bottom of the page).


Additional Information

Version R31 is the most recent NGINX Plus version and is based on NGINX Open Source 1.25.3.

You can refer to the R31 release notes in this link https://docs.nginx.com/nginx/releases/#nginxplusrelease-31-r31
