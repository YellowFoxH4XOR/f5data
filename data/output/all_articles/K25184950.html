Topic

You should consider using this procedure under the following condition:

  • You have F5 Access installed on your MAC client system and want to remove it and all of its components.

Description

BIG-IP F5 Access is an app available for download and install from the Apple App Store. F5 Access for Mac OS app has the following two components bundled together in a single package: 

  • Container App (com.f5.access.macos): This component provides the user interface for triggering and managing VPN connections, handles VPN configuration management and VPN state monitoring, and provides diagnostic information.
  • App Extension (com.f5.access.macos.PacketTunnel): This component is built on top of Network Extension framework, which establishes the actual connection to VPN, performs BIG-IP APM authentication, and handles tunnel network traffic. 

To completely remove F5 Access from your Mac OS, you need to remove these two components from the file system.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative privileges to remove applications and directories on the Mac OS.

Procedures

To completely remove F5 Access from your Mac OS system, perform the following procedures:

  • Uninstalling the F5 Access app
  • Removing the Container App and App Extension components

Uninstalling the F5 Access app

To uninstall the F5 Access app, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. On the Mac client system, open Launchpad from the dock or from your Applications folder.
  2. Press and hold the Option (?) key, or select and hold on the F5 access app icon it begins to jiggle.
  3. Select the X next to the F5 Access app.
  4. Select Delete to confirm.

Removing the Container App and App Extension components

To remove the F5 Access components from the client system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. On the Mac client system, open Terminal from the dock or from your Applications folder.
  2. To find the directories where the components are located, enter the following command:

    mdfind -name "f5.access"

    You may observe an output similar to the following:

    $ mdfind -name "f5.access"
    /Users/example_user/Library/Group Containers/57P38MF5GS.group.com.f5.access.macos
    /Users/example_user/Library/Containers/com.f5.access.macos
    /Users/example_user/Library/Application Scripts/com.f5.access.macos
    /Users/example_user/Library/Containers/com.f5.access.macos.PacketTunnel
    /Users/example_user/Library/Application Scripts/com.f5.access.macos.PacketTunnel

  3. To remove a directory from the output using the following command syntax:
    Impact of procedure: The sudo rm -rf command is dangerous when not used properly. The rm command does its job to delete, but a typing mistake or not knowing what is being deleted can make it dangerous. It is advised to backup your system before hand and use caution when using rm -rf command.

    sudo rm -rf <directory to remove>

    For example, to remove the directory that contains the log files, application caches and preferences, enter the following command:

    sudo rm -rf /Users/example_user/Library/Group\ Containers/*group.com.f5.access.macos

  4. Repeat step 2 for the remaining directories from the output.
