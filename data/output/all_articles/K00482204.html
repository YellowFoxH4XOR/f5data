Description

When attempting to access the BIG-IP using the iControl REST api you are unable to retrieve auth token for Active Directory users when using "loginProviderName":"tmos" in the body.
  • The Authorization Token is not returned and a 400 response code returned from the BIG-IP similar to the following:
    { "code": 400, "message": "loginProviderName is invalid.", "originalRequestBody": "{\"username\":\"{username}\",\"loginProviderName\":\"tmos\",\"generation\":0,\"lastUpdateMicros\":0}", "referer": "{IP_address}", "restOperationId": 5078278, "kind": ":resterrorresponse" }[8100/shared/authn/login AuthnWorker] Failed to lookup auth provider https://localhost/mgmt/cm/system/authn/providers/tmos: java.util.concurrent.TimeoutException: remoteSender:http://localhost:8100/shared/authn/login, method:GET [RestRequestReceiver] Rest worker uri not found: /forwarder/available
     
  • When accessing the BIG-IP using Ansible, you receive an error message similar to the following: 
    AttributeError: 'HTTPError' object has no attribute 'headers'
     
  • Log messages similar to the following are logged to /var/log/restjavad.0.log:
    [I][262955][05 Aug 2021 06:35:52 UTC][ForwarderPassThroughWorker {"user":"local/null","method":"POST","uri":"http://localhost:8100/mgmt/shared/authn/login","status":400,"from":"10.0.0.1"}

Environment

  • REST
  • Authorization token

Cause
On startup the restjavad service did not start correctly which results in REST calls not returning properly for remote authorized users. 

Recommended Actions

  1. Log on to the command line of the BIG-IP.
  2. To restart the restjavad service type the following command: 
    tmsh restart sys service restjavad
