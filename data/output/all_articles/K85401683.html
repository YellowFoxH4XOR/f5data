Description

Some attack signatures aren't present even after checking for the latest updates.

  • Attack signatures missing. Ex: 200104768 & 200104769 for detecting the Log4j2 CVE-2021-44228.
  • These signatures are available in other versions of BIG-IP like 13.x, 14.x, 15.x etc

Environment

  • BIG-IP with ASM running 11.x or 12.x
  • Application Security updates

Cause

This can happen if the software version has reached EoSD (End of Software Development). Article K5903: BIG-IP software support policy can be used to find out if a version has reached EoSD. Not all signatures are released for versions that have reached EoSD.

Recommended Actions

Update to a software version that has not reached EoSD and this version should receive all the latest attack signatures.
