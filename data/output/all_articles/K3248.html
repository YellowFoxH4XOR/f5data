K3248: Writing to the root file system while in single user mode

Topic

When a BIG-IP or 3-DNS system boots in single user mode, it mounts the file systems in a soft read state, which does not allow a user to edit or write to a file in the / directory.

To gain access to write to the / directory, you must mount the file system in read/write mode by performing the following steps:

  1. Reboot the system.

  2. When the press any key to interrupt the boot process message appears, press the space bar.

  3. At the boot: prompt, type the following:

    bsd

  4. Press the Enter key.

  5. At the Root device prompt, type the following:

    wd0

  6. When prompted Enter pathname of shell or RETURN for sh, press the Enter key.

    The # prompt displays.

  7. Type the following commands to assign read/write privileges to the / directory:
    mount -a
mount -uw /dev/wd0a /
  8. If you need to mount other file systems, such as /config for editing BIG-IP configuration files, you must determine what mount point is assigned to that file system by typing the following command:

    mount

    The output will appear similar to the following:

    /dev/wd0a on / (local, noaccesstime, read-only, soft read-only, writes: sync 684
async 470)
/dev/wd0h on /usr (local, noaccesstime, read-only, soft read-only, writes: sync
354 async 254)
/dev/wd0g on /var (local, noaccesstime, writes: sync 12152 async 38435)
/dev/wd0f on /config (local, noaccesstime, read-only, soft read-only, writes: sync
5768 async 1781)

    This output indicates that /dev/wd0h is mounted as /usr, /dev/wd0f is mounted as /config, and so forth.

    To mount the /config file system in read/write mode for this example, you would type the following command:

    mount -uw /dev/wd0f /config
