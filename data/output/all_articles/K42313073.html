Topic

The BIG-IP virtual server configuration currently does not support a SPDY profile over Transport Layer Security (TLS).

Description

If the BIG-IP system is configured with a virtual server that uses the following profiles, the SPDY profile may not function as expected.

  • a Client SSL profile, where the available ciphers are limited to TLS
  • a SPDY profile

Note: For more information about configuring a SPDY profile, refer to the Managing HTTP Traffic with the SPDY Profile chapter of the BIG-IP LTM BIG-IP Local Traffic Manager: Implementations guide. For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Beginning in BIG-IP 13.0.0, the SPDY profile is removed in favor of the HTTP/2 profile which resolves this issue.
