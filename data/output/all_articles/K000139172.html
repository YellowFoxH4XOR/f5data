Description

1. Collect the top output by following the article below. This will collect the top output for 10 secs interval for 10 minutes.

https://my.f5.com/manage/s/article/K32264816

Environment

  • LTM
  • Telemetry

Cause

A high CPU utilization observed in intervals can be caused by doing Telemetry streaming targeted to the BIGIP device. 

 

Recommended Actions

You can consider configuring customized endpoints for your declaration to just collect the needed data. This will help alleviate the CPU usage on the device.

https://clouddocs.f5.com/products/extensions/f5-telemetry-streaming/latest/custom-endpoints.html

 

Additional Information

 

What is icrd_child? The iControl Rest Child daemon (icrd_child) is used for mapping TMOS Shell (tmsh) commands to and from REST API requests. (https://my.f5.com/manage/s/article/K48615077)

 

Telemetry streaming is using REST API to collect data/events from the BIGIP endpoint.
