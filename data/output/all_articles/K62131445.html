K62131445: Error when configuring an ASM Policy Type Parent with a Policy Template Fundamental

Type
Support Solution
Published
2022-02-24
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K62131445

Description
When creating a Web Application Security Policy, you want to use the Policy Type as Parent Policy with a Policy Template of type Fundamental. However, as soon as you select Fundamental under Policy Template, the Policy Type reverts to Security Policy and the field becomes grayed out.

Environment
  • BIG-IQ
  • Web Application Security Policy
  • Parent Policy
  • Policy Template

Cause
The field gets grayed out because the Application Language auto toggles back to Auto-Detect after changing Policy Template to Fundamental.

Recommended Actions

  1. Configure a policy using the policy type of Fundamental.
    Note: This disables the Policy Type field.
    Note: The Application Language parameter will be selected as Auto Detect.
     
  2. Change Application Language to Unicode (utf-8) or anything else, other than Auto Detect.
    Note: This will enable the Policy Type field.
     
  3. Select Policy Type as Parent Policy.

Additional Information
None.
