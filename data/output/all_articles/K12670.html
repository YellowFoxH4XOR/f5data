Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator may incorrectly calculate the Content-Length for web server responses containing Edge Side Includes (ESI). This issue occurs for ESI fragments matching a node in the BIG-IP WebAccelerator policy in which response rewriting is configured. This issue results in missing web page content or truncated pages.

F5 Product Development is tracking this issue as ID 348025.

Note: This issue does not affect BIG-IP version 11.x.

Workaround

You can work around this issue by disabling Response Rewriting in the policy for the node that is matching the ESI fragment. To do so, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator Configuration utility.
  2. From the Main tab, click Policies.
  3. Click the appropriate policy.
  4. Select Acceleration Rules from the drop-down menu.
  5. Click the Assembly tab.
  6. From the Content Assembly Options drop-down menu, select Advanced.
  7. In the Response Rewriting section, select Do No Rewrite from the Rewrite proxied data using drop-down menu.
  8. Click Save.
  9. Click Publish.

Note: You can also work around this issue by writing an iRule to replace the response rewriting functionality. For more information, refer to DevCentral. A DevCentral login is required to access this content; you will be redirected to authenticate or register (if necessary).
