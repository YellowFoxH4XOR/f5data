K000136209: Unable to delete old image 1.5.0 on F5 OS software manager after upgrade to 1.5.1

Type
Support Solution
Published
2023-09-22
Updated
2023-09-25
Applies to
  • F5OS
  • F5OS-A: 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000136209

Description

Customer may find they cannot remove 1.5.0 image after upgrade to 1.5.1.

There will be error logs in /var/F5/system/log/platform.log

image-agent[<PID>]: priority="Info" version=1.0 msgid=0x2006000000000014 msg="Looks like we can delete the image" APPLIANCE="appliance_iso" VERSION="1.5.0-5781".

image-agent[<PID>]: priority="Err" version=1.0 msgid=0x2006000000000013 msg="Error unexpected response back from API:" RES="1".

image-agent[<PID>]: priority="Err" version=1.0 msgid=0x2006000000000009 msg="Error number : unable to get response from sw mgmt API." ERRORNO=111.

image-agent[<PID>]: priority="Err" version=1.0 msgid=0x2006000000000007 msg="Error Image is part of ISO" VERSION="1.5.0-5781" ISO="1.5.0-5781".

image-agent[<PID>]: priority="Err" version=1.0 msgid=0x2006000000000007 msg="Error Image is part of ISO" VERSION="1.5.0-5781" ISO="1.5.0-5781".

/var/log/sw-mgmt.debug

INFO: sw-mgmt: priority=info msgid=0x3501000000000181 msg=Removal of R2R4 iso 1.5.0-5781 failed checks, blocking removal. Reason: component is base for imported patch services

 

Environment

  • F5OS

Cause

This is expected behavior, 1.5.0 is the dependency image for 1.5.1, so 1.5.0 can not be removed after upgrade.

Recommended Actions

Keep the old image 1.5.0 as it is.

Additional Information
