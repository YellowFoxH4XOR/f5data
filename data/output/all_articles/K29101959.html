K29101959: Virtual Edition Management IP not reachable

Type
Support Solution
Published
2023-09-21
Updated
2025-04-01
Applies to
  • Virtual Editions
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K29101959

Description

  • You cannot contact the device by the Configuration utility or SSH using the Management Address.
  • The devices can ping the Management Route gateway.
  • If the devices are configured as HA, then each device can ping the other's Management Address.
  • Access via a Self IP with the correct port lock down works.

Environment

  • Virtual Edition

Cause

  • The Device was snapshotted while running.
  • The Snapshot was restored.

Recommended Actions

  1. Reboot the Device

Additional Information

  • If possible snapshot a Virtual Edition while it is stopped.
  • If not possible, the restored Virtual Edition may be impaired in some minor way. This is not a limitation of the BIG-IP product.
