Policy Information

Common Criteria Certification for BIG-IP 13.1.1

Description

CSEC has certified the following:

  • BIG-IP LTM+AFM 13.1.1 + engineering hotfix Hotfix-BIGIP-13.1.1.0.100.4-ENG for Common Criteria against the Firewall collaborative Protection Profile
  • BIG-IP LTM+APM 13.1.1 + engineering hotfix Hotfix-BIGIP-13.1.1.0.100.4-ENG for Common Criteria against the Network Device collaborative Protection Profile

For more information about the security target and related information, refer to the following CSEC and NIAP websites:

  • LTM+AFM Certificate
  • LTM+APM Certificate
  • LTM+AFM NIAP PCL listing
  • LTM+APM NIAP PCL listing

Common Criteria is an international initiative to standardize security functionality and assurance measures. For more information about Common Criteria Certification, refer to the following Common Criteria website:

http://www.commoncriteriaportal.org

Note: This document, along with the Common Criteria Guidance Supplement, provides guidance on the secure installation and secure use of the TOE for the evaluated configuration. These documents provide clarifications and changes to the standard documentation and should be used as the guiding documents for the configuration and administration of the TOE in the Common Criteria evaluated configuration. Official product documentation should be referred to and followed only as directed within these guiding documents.

Installation

To install BIG-IP in accordance with the evaluation's expectations, refer to the following document in the document ISO:

  • Guidance Supplement: AGD_PRE and AGD_OPE 
This document contains information on ensuring that you have the correct software version of BIG-IP as well as describing how to configure that system to be Common Criteria-compliant. This document is included in the ISO described below.

Product documentation

The following ISO contains the product and guidance documentation for the 13.1.1 Common Criteria evaluation:

  • CommonCriteriaDocumentation-13.1.1.iso - F5 Downloads 
  • CommonCriteriaDocumentation-13.1.1.iso.sha256  - F5 Downloads 

To verify the ISO file against the checksum, use the Linux sha256sum command with the –check option:

sha256sum –check CommonCriteriaDocumentation-13.1.1.iso.sha256
