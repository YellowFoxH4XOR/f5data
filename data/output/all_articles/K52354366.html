Topic

You should consider using this procedure under the following conditions:

  • Your BIG-IP is licensed and provisioned with the BIG-IP APM module.
  • You want to restrict access to a virtual server using Lightweight Directory Access Protocol (LDAP) authentication.

Description

You can configure the BIG-IP APM system to prompt users for their LDAP authentication credentials when accessing a virtual server.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • The BIG-IP is configured with the virtual server to which you want to apply LDAP authentication.
  • You have previously deployed LDAP server(s) in your environment, and the BIG-IP system can access them.

Procedures

  • Creating a custom LDAP monitor
  • Creating the LDAP authentication profile
  • Creating the access profile
  • Creating the access policy
  • Applying the access profile to the virtual server

Creating a custom LDAP monitor

The following procedure outlines the steps to create a new BIG-IP APM LDAP authentication profile that references existing LDAP servers of your environment.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

For example:

cn=Admin,cn=Users,dc=example,dc=com

  1. Log in to the BIG-IP APM Configuration utility.
  2. Go to Local Traffic > Monitors.
  3. Select Create.
  4. Enter a name for the monitor.
  5. Select Type LDAP.
  6. Leave Parent Monitor at the default setting of ldap.
  7. For User Name, enter a user name DN that can authenticate to the LDAP servers.
  8. For Password, enter the user's LDAP password.
  9. For Base, enter the base search DN.

    For example:

    cn=Users,dc=example,dc=com

  10. For Filter, enter the LDAP filter.

    For example:

    objectclass=*

  11. Set Security to the secure protocol encryption type the LDAP servers use or leave the setting at the default, None, if the LDAP server does not use it.
  12. For Chase Referrals, select Yes.
  13. Select Finished.

Creating the LDAP authentication profile

The following procedure outlines the steps to create a new BIG-IP APM LDAP authentication profile that references existing LDAP servers of your environment.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Go to Access > Authentication > LDAP.

    Note: For BIG-IP 11.6.x through 12.x, go to Access Policy > AAA Servers > LDAP.

  3. Select Create.
  4. Enter a name for the LDAP authentication profile.
  5. For Server Connection, select Use Pool.

    Note: For a singular LDAP server you can also select Direct.

  6. For Server Pool, enter a name and IP address of the LDAP server.
  7. Select Add.
  8. Repeat steps 6 and 7 to add the rest of the LDAP pool members.
  9. For Server Pool Monitor, select the custom LDAP monitor you created in the first procedure.
  10. Select the protocol Mode used by the LDAP servers.

    Note: Ensure that you select a server pool monitor that is compatible with the protocol.

  11. For Admin DN, enter the LDAP server specific configuration details and the admin password.

    For example:

    cn=Administrator,CN=Users,DC=example,DC=com

  12. Select Finished.

Creating the access profile

The following procedure outlines the steps to create a new BIG-IP APM access profile and configure the associated access policy to present a logon page and authenticate users to existing LDAP server or servers in your environment.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to Access > Profiles/Policies.
  2. Select Create.
  3. Enter a name for the access profile.
  4. For Profile Type, select LTM-APM.
  5. For Profile Scope, select Virtual Server or Profile.
  6. For Customization Type, leave at the default of Modern.

    Important: If you are configuring an application access control scenario where you are using an HTTPS virtual server to authenticate and then sending the user to an existing HTTP virtual server to use an application, clear the check box for the SSO Across Authentication Domains > Secure setting.

  7. For Language Settings, for Factory BuiltIn Languages, select the languages you want to use and move them to Accepted Languages.
  8. Select Finished.

Creating the access policy

The following procedure outlines the steps to create a new BIG-IP APM access profile and configure the associated access policy to present a logon page and authenticate users to existing LDAP server or servers in your environment.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to Access > Profiles/Policies.
  2. Next to your access profile, select Edit to open the Virtual Policy Editor (VPE).
  3. In VPE, select the Add icon (+).
  4. Select Logon Page.
  5. Select Add Item.
  6. Modify the Form Header Text.
  7. Select Save.
  8. After the Logon Page agent, select the Add icon (+).
  9. Select the Authentication tab.
  10. Select LDAP Auth.
  11. Select Add Item.
  12. For Server, select the LDAP server profile created in the previous procedure.
  13. Complete the SearchDN and SearchFilter to match the configuration of the LDAP servers.

    For example:

    cn=Users,dc=example,dc=com

    Example SearchFilter:

    (sAmAccountName=%{session.logon.last.username})

  14. Select Save.
  15. Select the Deny ending of the Successful branch.
  16. Select Allow.
  17. Select Save.
  18. Select Apply Access Policy.
  19. Select Close to exit VPE.

Applying the access profile to the virtual server

The following procedure outlines the steps to apply the newly create access profile and the associated access policy to an existing virtual server.

Impact of procedure: Performing the following procedure requires users to present their LDAP credentials when accessing a virtual server that is configured with the BIG-IP APM access profile/policy.

  1. Go to Local Traffic > Virtual Servers > Virtual Server List.
  2. Select the name of the virtual server to which you want to apply the LDAP authentication access profile.
  3. For Access Policy, select the recently created access profile.
  4. Select Update.
