Description

Windows updates released on or after October 10, 2023 will do the following: 

  • Removes support for the registry subkey KrbtgtFullPacSignature.

  • Removes support for Audit mode.

  • All service tickets without the new PAC signatures will be denied authentication

    Microsoft changes are described in KB5020805: How to manage Kerberos protocol changes related to CVE-2022-37967

    Note: This link takes you to a resource outside of AskF5, and the third party could remove the document without our knowledge.

 Environment

  • BIG-IP APM
  • Kerberos
  • Microsoft
  • Windows

 Cause

After installing the Windows updates that are dated on or after November 8, 2022, the following registry key is available for the Kerberos protocol:

  • KrbtgtFullPacSignature

    This registry key is used to gate the deployment of the Kerberos changes. This registry key is temporary, and will no longer be read after the full Enforcement date of October 10, 2023.

 Recommended Actions

No action is required from the end user.

 Additional Information

BIG-IP supports Kerberos mandatory PAC signatures changes.
