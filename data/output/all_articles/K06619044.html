Known Issue

Internal High-Speed Bridge (HSB) HiGig interfaces may experience a high number of accumulated Frame Check Sequence (FCS) errors, causing link instability.

This issue occurs when following condition is met:

  • You observe unexplained traffic failure on some virtual servers or self IP addresses.

Impact

This issue may severely affect system performance and link stability.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Link instability, frame loss, and HSB lockup
  • TMOS Message Passing Interface (MPI) and Cisco Discovery Protocol (CDP) packet loss
  • Internal blade communication issues
  • Accumulated FCS errors
