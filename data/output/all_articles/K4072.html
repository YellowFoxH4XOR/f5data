Topic

The snmp_dca monitor sends messages to syslog using the user facility. By default, BIG-IP does not direct messages from the user facility to a log file.

To enable snmp_dca logging, use the following steps:

  1. Log in to the command line.
  2. Edit the /etc/syslog.conf file.
  3. Add the following line at the end of the file: 
    user.*           /var/log/snmpdca
  4. Save the file and exit the editor.
  5. Reload the syslogd configuration by typing the following command:

    kill -HUP `pidof syslogd`

Note: The tics (`) in the above line are back-tics, which are found on the same key as the tilde (~) character.

Once syslogd reloads, all snmp_dca monitor messages will be logged to the /var/log/snmpdc file.
