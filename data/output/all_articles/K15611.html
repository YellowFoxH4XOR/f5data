Issue

Error Message

AOM2 auth.info /usr/sbin/sshd[<pid>]: WARNING: /etc/ssh/moduli does not exist, using fixed modulus

In this error message, note the following:

  • <pid> is the sshd process ID

For example:

AOM2 auth.info /usr/sbin/sshd[21188]: WARNING: /etc/ssh/moduli does not exist, using fixed modulus

Message Location

You may encounter this message in the following location:

  • The /var/log/messages file on the AOM subsystem

Description

This message occurs when the following condition is met:

  • The /etc/ssh/moduli file does not exist on the AOM subsystem

You may observe this error message when reviewing the /var/log/messages file on the AOM subsystem. When generating prime numbers for use by sshd, the Diffie-Hellman (D-H) algorithm can either use the /etc/ssh/moduli file or use a standard, fixed modulus. The /etc/ssh/moduli file is not required, and when the file does not exist, the D-H algorithm uses the standard modulus for all Diffie-Hellman operations.

Impact

None. This error message is benign.
