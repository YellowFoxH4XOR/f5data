K000150047: APM: Citrix ICA connections fail when using a LTM Policy

Type
Support Solution
Published
2025-02-27
Updated
2025-02-27
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150047

Description

Citrix ICA connections fail when using an LTM policy on a Virtual Server targeting Virtual Server Configuration where the LTM Virtual targets the APM Virtual Server.

  • In a packet capture you will see the request for the ICA traffic, but no actual ICA traffic on port 1494 or port 2598.
  • The vdi logs located in /var/log/apm with display no error messages.

Environment

  • A Virtual Server targeting Virtual Server Configuration where the LTM Virtual targets the APM Virtual Server
  • LTM Virtual Server and a APM Virtual Server
  • LTM Policy applied to the LTM Virtual Server
  • APM, LTM
  • Citrix Client

Cause

This happens because the ICA traffic is not HTTP compliant, i.e. the traffic is not HTTP so it does not send headers, etc.

Recommended Actions

Create the following iRule


  1. Login to the Admin GUI
  2. On the Main tab, click Local Traffic > iRules.
  3. Click Create.
  4. In the Name field, type a name, such as my_irule. The full path name of the iRule cannot exceed 255 characters.
  5. In the Definition field, type the syntax for the iRule:

# iRule for disabling HTTP for CCGP/ICA ssl tunnelled app traffic 


when CLIENTSSL_HANDSHAKE {

 log local0. "DEBUG: SSL HANDSHAKE - COLLECTING DATA"

  SSL::collect

  set is_ica 0

}


when CLIENTSSL_DATA {

   if { $is_ica==0 }{

  set payload [SSL::payload]

  

  if { [regexp -indices "CGP" $payload firstmatch] } {

    set is_ica 1

    log local0. "DEBUG: CGP detected, disabling HTTP"

    HTTP::disable

    virtual /Common/Citrix.app/Citrix_webui_https

  }

  }

   

 SSL::release

}

  1. Click Finished.

Apply the following iRule to the LTM Virtual Sever:

  1. Login to the Admin GUI
  2. Navigate to Local Traffic>Virtual Servers : Virtual Server List
  3. Click on the Virtual Server
  4. Click on the Resources tab
  5. Click on Manage for iRules
  6. Move the iRule from Available to Enabled
  7. Click Finished
