Description

DoS Protection and Bot Defense dashboards on BIG-IP are are not displaying data

 

Environment

  • AVR
  • AFM, ASM or BIG-IQ DCD
  • Dashboards

 

Cause

This is expected behavior.
The /config/bigip.conf file shows BIG-IP unit is configured to send AVR data off box (to DCD):

analytics global-settings {
    avrd-interval 30
    ecm-port 443
    enable-bigiq-configuration enabled
    offbox-protocol https
    offbox-tcp-addresses { 10.0.0.1 10.0.0.2 }
    offbox-tcp-port 443
    source-id 62038ca1-07bd-4bb4-9e93-c697b00c37d1_10.0.0.3
    use-offbox enabled
}

When BIG-IQ is enabled, AVR is pointed to the BIG-IQ and therefore all reporting gets sent off box to a BIG-IQ DCD. 

 

Recommended Actions

Stats may also be recorded locally by enabling avrd-debug-mode:

modify analytics global-settings avrd-debug-mode enable

Important: avrd-debug-mode should only be enabled for troubleshooting purposes, and should not be left enabled.
