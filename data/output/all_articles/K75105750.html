Known Issue

The BIG-IP system does not display DNS graphs in the Configuration utility.

This issue occurs when the following condition is met:

  • You have licensed the BIG-IP system for the GTM module (mod_gtm) instead of the DNS module (mod_dnsgtm). This might occur when you upgrade the system from an earlier release, such as BIG-IP 10.2.4 (where the module is GTM) to a later release, such as BIG-IP 12.1.1 (where the module is DNS).

Impact

You cannot access the DNS graphs in the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After you upgrade from an earlier release, you cannot view the DNS graphs in the Configuration utility. When you navigate to Statistics > Performance > DNS, the system reports an error message similar to the following example:

    Error trying to access the database
