Known Issue

Description

After configuring the CLI setting to display services by number, the subsequent tmsh commands listing the virtual server configuration displays the service by name instead of by number.

This issue occurs when the following condition is met:

  • You attempt to change the CLI setting to display the service by number, using either the tmsh or bigpipe command, as follows:

    Using tmsh

    tmsh modify cli global-settings service number

    Using bigpipe

    bigpipe cli service number

Impact

The subsequent tmsh commands listing the virtual server configuration displays the service by name instead of by number.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you use the tmsh utility to list a virtual server configuration, the output displays the service by name instead of by number.

    For example:

    List the virtual server configuration for my_virtual using the following tmsh command:

    tmsh list ltm virtual my_virtual

    You receive the output showing the http service with its service name, http, instead of its service port number, 80, as shown in the following example:

    ltm virtual my_virtual {
    destination 10.10.10.100:http
    ip-protocol tcp
    mask 255.255.255.255
    pool my_pool
    profiles {
    fasthttp { }
    }
    snat automap
    }

Workaround

To work around this issue, you can use the bigpipe utility to list the configuration of a virtual server. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. List the service numbers using the following bigpipe command syntax:

    bigpipe virtual <name of virtual server> list

    For example:

    bigpipe virtual my_virtual list

    The system displays the my_virtual virtual server configuration that appears similar to the following example, showing the http service with its service number, 80:

    virtual my_virtual {
    snat automap
    pool my_pool
    destination 10.10.10.100:80
    ip protocol 6
    profiles fasthttp {}
    }
