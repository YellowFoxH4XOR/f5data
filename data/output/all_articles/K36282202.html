Description

On VIPRION platforms, after installing the new version image, when trying to boot into the new version from Configuration Utility: 
System  ›› Software Management ›› Boot Locations ››  HD1.x, the “Install Configuration” drop-down menu is greyed out / disabled.

The system will continue the process loading the configurations into the new location. If you have configuration changes since the creation of the new boot location, you need to use clsh cpcfg to distribute configurations among all the blades correctly.

Environment

  • Viprion platform
  • Configuration Utility
  • Boot partitions

Cause

This is by design. Although the partition is non-default, the install config option is disabled.

Recommended Actions

This behavior is expected and if you do not have any configuration change since the creation of the boot location, you can ignore it. However, if you have configuration changes after creating the boot location you may follow the K14724 and copy the configuration to the new boot location.
