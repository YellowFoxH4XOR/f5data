Description

Software installation may fail with errors while looking at the liveinstall.log files, we noticed below errors 

error: tm_install::MultiVolume::MultiVolume_uuid -- no device found for cpmirror.dat.boot error: Could not find device for cpmirror.dat.boot error: unlink /mnt/tm_install/24623.tQLTGQ/VERSION failed; No such file or directory Terminal error: Failed to install.

Upgrading software versions will create and mount partitions for the new volumes but also update the boot partition with new grub settings, kernel, ramdisk, etc and this is the device /dev/vg-db-up mirror/dat.boot.

lvscan should show a list in the list of volumes but if you see the above errors it will likely be missing from this list

lvscan

ACTIVE '/dev/vg-db-sdb/mdm.dat.share' [60.00 GB] inherit .

ACTIVE '/dev/vg-db-cpmirror/dat.boot' [928.00 MB] inherit

Environment

  • BIG-IP LTM
  • Software upgrade
  • Disk partition
  • CLI

Cause

The issue is due to disk corruption

Recommended Actions

Note: Please do not reboot the device as it may fail to boot back up if the boot partition is too badly damaged. 

1. Ensure you take a UCS backup before going any further.

K13132: Backing up and restoring BIG-IP configuration files with a UCS archive

2. Prepare a USB key with the current software version as covered in K13164: Creating a bootable USB thumb drive

3. Remove the USB key.

4. Attempt to recover with below command using CLI
image2disk --format=volumes /shared/images/BIGIP-<current version>.iso

5. If this fails clean install from the USB key as covered in K13117: Performing a clean installation of BIG-IP 11.x - 17.x
