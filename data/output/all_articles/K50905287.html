Known Issue

HTTP Class profiles configured to use a host match type may not upgrade properly.

This issue occurs when all of the following conditions are met:

  • You have configured an HTTP Class profile to classify traffic based on HTTP host headers.
  • Your BIG-IP system is running a software version earlier than 11.4.0.
  • You upgrade the BIG-IP system to BIG-IP 11.4.0 or later.

Impact

Client connections may not be classified properly, and as a result, may be forwarded incorrectly or dropped.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H621676 on the Diagnostics > Identified > Medium screen.
  • After you upgrade to BIG-IP 11.4.0 or later, client HTTP connections with specific host headers are either forwarded to the wrong destination or fail.

Workaround

To work around this issue, you can manually modify the upgraded local traffic policy. To do so, perform the following procedure:

Note: HTTP Class profiles are referred to as Local Traffic policies after 11.4.0. For more information, refer to K14409: The HTTP Class profile is no longer available in BIG-IP 11.4.0 and later.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Advanced shell (bash).
  2. Use a preferred text editor to open the /config/bigip.conf file.
  3. Locate the local traffic policy object with the same name as the HTTP Class profile. For example, the HTTP Class profile object named httpclass-example_8080 would convert to the following local traffic policy object after upgrading:

    ltm policy httpclass-example_8080

  4. Within the local traffic policy, locate the conditions section where http-host is configured.

    conditions {
         1 {
             http-host
             host
             contains
             values { examle.com:8080 }
         }

  5. Change the conditions http-host section to match the following:

    conditions {
         1 {
             http-host
             values { example.com:8080 }
         }

  6. Save the changes to the /config/bigip.conf file.
  7. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  8. Load the modified configuration by typing the following command:

    load sys config

  9. Save the configuration by typing the following command:

    save sys config
