Description

  • Virtual Server (VIP) created with wrong name and operative as it should.
  • You wish to rename the VIP.

Environment

  • Virtual Server created with wrong VIP name 

Cause

Though this is possible, this is not something we support nor recommend.

The reason that the virtual server cannot be renamed once it is deployed is that this configuration object now has dependencies and all those dependencies will be impacted when you change the name.

Recommended Actions

It is easier and more straightforward to delete this virtual server, deploy a new one with the correct name and set the rest of the parameters as the same with your previous one.

Note: This should be done during a maintenance window, while less traffic may be affected.
