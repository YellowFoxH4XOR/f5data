Topic

This article discusses F5 support for Falcon for BIG-IP, which is now Generally Available.

Policy Information

Falcon for BIG-IP Support

For BIG-IP systems with a valid Support contract, F5 will assist with verifying Falcon Sensor installation on the BIG-IP system and resolving common issues such as connectivity to the Falcon Platform Cloud.

F5 support will extend to BIG-IP–specific functional concerns but will stop post installation and will not provide Falcon Sensor troubleshooting. Any questions or issues that occur on the Falcon Sensor post installation will need to be raised with CrowdStrike.

F5 support will not extend to cover CrowdStrike OverWatch. Customers using CrowdStrike OverWatch must contact CrowdStrike support for assistance.

For information about prerequisites and instructions for installing the CrowdStrike Falcon Sensor on the BIG-IP system, refer to K000156881: Install Falcon for BIG-IP on the BIG-IP system or F5 hardware platforms.

To contact CrowdStrike support, refer to https://supportportal.crowdstrike.com, or use the following numbers:
