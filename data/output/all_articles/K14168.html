Known Issue

The BIG-IP ASM system may fail to display parameter names configured for an allowed URL. This issue occurs when all of the following conditions are met:

  • You have configured an allowed URL
  • You have configured a parameter either under the URL Parameters tab or the Advanced Extractions tabs for the allowed URL
  • You are running BIG-IP ASM 11.2.1 and later, and using Internet Explorer (IE) 8 or 9. Or, you are running BIG-IP ASM 11.2.0 and using a supported browser other than IE 9.

Note: For a list of supported browsers, refer to the BIG-IP ASM release notes for your version.

Impact

You may not be able to identify the parameter name configured for an allowed URL.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The parameter name field is blank on the Application Security > URLs > Allowed URLs > URL Parameters page.
  • The parameter name field is blank on the Application Security > URLs > Allowed URLs > Advanced Extractions page.

Workaround

To work around this issue, you can use a different browser type or version to access the Configuration utility. To access the Configuration utility, you can use IE 9 for BIG-IP ASM 11.2.0 and use Firefox or Chrome for BIG-IP ASM 11.2.1 or later.
