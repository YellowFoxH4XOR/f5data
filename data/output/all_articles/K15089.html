Topic

You should consider using this procedure under the following condition:

  • You want to change your existing PEM listener's Forwarding IP virtual server to a Standard virtual server and apply the Any IP (ipother) profile.

Description

When you upgrade to BIG-IP 11.5.0 or later versions, the configuration that rolls forward of any PEM listener's virtual server is not automatically modified to use the new ANY IP (ipother) profile. You can use the following procedure to manually change the Forwarding IP virtual server to a Standard virtual server, and apply the ANY IP (ipother) profile.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the Configuration utility.

Procedures

To change the configuration of the existing Forwarding IP virtual server to a Standard virtual server and apply the Any IP profile to the configuration, perform the following procedure:

Impact of procedure: This modification involves changing the configuration that affects the PEM listener and indirectly affects the network traffic classification. F5 recommends that you perform this procedure only during a maintenance window.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
  3. Select the name of the affected Forwarding IP virtual server that is part of the PEM listener configuration.
  4. Under General Properties, in the Type menu, select Standard.
  5. In the Configuration menu, select Advanced. 
  6. In the Protocol menu, select *All Protocols.
  7. In the Any IP Profile menu, select ipother.
  8. Optional: In the Classification menu, select Enabled.
  9. Optional: In the Policy Enforcement Profile menu, select the name of the required PEM profile.
  10. Click Update.
