Description

I would like to completely disable the iControl REST/SOAP services.

Is this possible?

Environment

  • iControl

Cause

None

Recommended Actions

There is currently no supported way to disable iControl on the BIG-IP.

Furthermore, stopping services such as restjavad will impact functionality, since iControl is used internally. GUI pages may become unavailable, for example.

To restrict and limit access to iControl, ensure that Apache (httpd) is only exposed to trusted networks and devices.

  • K13092: Overview of securing access to the BIG-IP system
  • K46122561: Restricting access to the management interface using network firewall rules
  • K17333: Overview of port lockdown behavior

Note: Utilising the httpd allow list does not restrict access to iControl.
