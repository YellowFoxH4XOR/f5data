K000148054: Is F5® Distributed Cloud Console using dynamic or static IP addresses?

What Happened?

  • I am integrating the Distributed Cloud (XC) Portal access with another platform and would like to know if our F5XC tenant uses Static or Dynamic IP Addresses

Environment

  • F5® Distributed Cloud Console

 

Resolution/Answer

  • F5® Distributed Cloud Console uses dynamic IP address and it may change over time.

 

Additional Information

  • We currently don't have static IP's for Distributed Cloud console
  • Only ORGANIZATION tiers have a dedicated (static) IP.
    • You can acquire a VIP by request. More information on the official documentation of Public IPs.
