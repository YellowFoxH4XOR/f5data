Description

The Bandwidth Control Policy does not work with PVA enabled Virtual Servers.

Incorrect values reported when executing the command tmsh show net bwc policy.

Environment

  • Fastl4
  • PVA enabled

Cause

This is the correct behaviour. The Bandwidth Control Policy does not work with PVA enabled, as BWC policy only work on the tmm, that is it requires CPU to make bandwidth calculation.

Recommended Actions

None

None
