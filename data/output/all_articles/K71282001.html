Security Advisory Description

An undisclosed traffic pattern received by a BIG-IP Virtual Server with TCP Fast Open enabled may cause the Traffic Management Microkernel (TMM) to restart, resulting in a Denial-of-Service (DoS). (CVE-2016-9249)

Impact

If the Fast Open option is enabled in a TCP profile assigned to a BIG-IP virtual server, an attacker could cause the Traffic Management Microkernel (TMM) to restart, resulting in a denial-of-service (DoS).

Note: The Fast Open option was added in BIG-IP 12.0.0 and specifies, when enabled, that the system reduces latency by allowing a client to include the first packet of data with the SYN. The TCP Fast Open option in the TCP profile is disabled by default.

Security Advisory Recommended Actions

If you are running a version listed in the Versions known to be vulnerable column, you can eliminate this vulnerability by upgrading to a version listed in the Versions known to be not vulnerable column. If the table lists only an older version than what you are currently running, or does not list a non-vulnerable version, then no upgrade candidate currently exists.

Mitigation

There is no mitigation. F5 recommends that you leave the TCP Fast Open option in the TCP profile disabled wherever possible, when using a vulnerable BIG-IP version. To determine whether the option is enabled, perform one of the following procedures:

Using the Configuration utility to determine if the Fast Open option is enabled

Impact of action: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Protocol > TCP.
  3. Click the Name of the TCP profile you want.
  4. In the Connection Setup section, observe whether the Fast Open option is selected (if the box is checked, the option is enabled).
  5. Optional: Clear the box to disable the Fast Open option.

Using the tmsh utility to determine if the Fast Open option is enabled

Impact of action: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Use the following command syntax to determine whether the Fast Open option is enabled:

    list /ltm profile tcp <profile name> fast-open

    For example, to observe whether the option is enabled for a TCP profile named pr-tcp-test, type the following command:

    list /ltm profile tcp pr-tcp-test fast-open

    The output displays either disabled or enabled.

    For example:

    ltm profile tcp pr-tcp-test {
        fast-open disabled
    }

  3. Optional: If the option is set to enabled, and you wish to set it to disabled, type the following command:

    modify /ltm profile tcp pr-tcp-test fast-open disabled

  4. If you modified your TCP profile configuration, save your changes by typing the following command:

    save /sys config
