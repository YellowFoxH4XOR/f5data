Known Issue

Description

Enabling a share for a volume with filer subshares enabled fails if the filer has a share with the same name as a hidden share (with a dollar sign [ $ ] appended to the end of its name).

For example:

A share named test and a duplicate hidden share named test$

Note: Shares with a $ character at the end of a share name are hidden shares.

Impact

The share is not enabled.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The ARX system logs an error message to the error.log and syslog files that appears similar to the following example:
A record insertion into the configuration database failed. Record result code [keyAlreadyExists [2]] Record name [SubShareMappingRecord] Debug string [_acopia_share$_f5$].

Workaround

To enable the share, you must remove one of the duplicate shares from the filer.

Supplemental Information

  • For further information on what commands to use to remove shares, refer to the ARX CLI Reference Guide.
