K000149381: What self IP does the BIG-IP use to communicate with the OCSP responder

Description

The BIG-IP will check the route table and determine the most appropriate egress vlan when communicating with an OCSP responder.

Environment

  • BIG-IP LTM
  • TCPDUMP
  • SSH
  • OCSP

 

Cause

None

 

Recommended Actions

To determine the actual IP you can run the following packet capture by the port that OCSP is using.  Default is port 80.

Log into the BIG-IP using SSH and run the following command -

# tcpdump -v -ni 0.0:nnnp -w /var/tmp/$(getHostName).$(date +%H%M).pcap dst port <OCSP port>

Review the tcpdump in Wireshark and filter by the OCSP protocol.
