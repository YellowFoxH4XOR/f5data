Issue

Error Message

Member interface (%s) of trunk (%s) not found

In this error message, note the following:

  • <%s1> is the trunk interface
  • <%s2> is the name of the trunk

For example:

Member interface 1.2 of trunk test-trunk not found

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following conditions is met:

  • The trunk interface does not exist.

Impact

You are unable to create a trunk.

Recommended Actions

A misconfiguration of relevant trunk and interface configuration may cause this error message. You can delete the existing trunk and recreate a new one on the BIG-IP system. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Network > Trunks > Trunk List.
  3. Select the name of the existing trunk you want to replace.
  4. To remove the selected trunk, click Delete.
  5. To confirm the removal, click Delete.
  6. To initiate the process of creating a new trunk, click Create.
  7. Type the name of the new trunk in the Name box.
  8. Select the appropriate interfaces and move them to the Members box by clicking <<.
  9. Configure the options, such as LACP, Link Selection Policy, and Frame Distribution Hash, that are appropriate for your environment.
  10. To save the changes, click Finished.
