K000092348: Configure ap-policies for virtualservers

Published
2022-08-31
Updated
2022-08-31
Source

Description

  • You successfully deployed Nginx Ingress Controller with APP-Protect onto your Kuberenetes cluster.
  • The above deployment, by default, would have come with prebuilt policies that can be referenced by base template "POLICY_TEMPLATE_NGINX_BASE"  
  • These policies are NginxApiSecurityPolicy.json, NginxDefaultPolicy.json and NginxStrictPolicy.json
  • Also by default, when creating the APPolicy from within the Kuberenetes cluster, template "POLICY_TEMPLATE_NGINX_BASE" points to policy NginxDefaultPolicy.json
  • You wish to force template "POLICY_TEMPLATE_NGINX_BASE" uses policy NginxStrictPolicy.json

 Environment

  • Nginx Ingress Controller
  • Nginx AWAF
  • App-policies

 Cause

  • None

 Recommended Actions

  • We can alter the policy base template references to "NginxStrictPolicy.json" through the use of ConfigMap and http snippet.
  • to do so, please modify the configMap used by the Nginx Controller as shown below and include "app_protect_policy_file" under "data" section, as shown below
  • Please note, use of configMap is a global event and therefore alters the policy to strict for all other policy which uses the default base template
apiVersion: v1
data:
  http-snippets: |
    app_protect_policy_file "/etc/app_protect/conf/NginxStrictPolicy.json";
kind: ConfigMap
metadata:
  name: nginx-example-configmap
  namespace: nginx-ingress

 Additional Information

  • There are a few difference in the implementation of a standalone NAP WAF and Nginx Ingress with NAP
  • App protect can be configured using annotation at the ingress resource level reference
  • Defining app-protect at the ingress resource level removes the application of WAF on all configured objects/locations
  • Example, how to initiate and include WAF for a specific ingress resource
   apiVersion: networking.k8s.io/v1
   kind: Ingress
   metadata:
     name: nginx-nap-ingress
     annotations:
       appprotect.f5.com/app-protect-policy: "default/my-waf"
       appprotect.f5.com/app-protect-enable: "True"        
       appprotect.f5.com/app-protect-security-log-enable: "True"
       appprotect.f5.com/app-protect-security-log: "default/logconf"    
   spec:
     rules:
     - host: my-nginx.example.local
       http:
         paths:
         - path: /
           pathType: Prefix
           backend:
             service:
               name: svc-nginx
               port:
                 number: 80
