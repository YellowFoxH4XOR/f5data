Description

JavaScript returns the following error when Edge Client is used to access to VPN.

Script Error
An error has occurred in the script on this page.
Line: XXX
Char: Y
Error: Unable to set property 'value' of undefined or null reference   /// or other error, this is only an example.
Code: 0
URL: https://<SAML iDP server or Oauth server>/path              ///It is not the URL for the APM
Do you want to continue running scripts on this page?
Yes No

When we use web browser, no error and works fine.

Maybe Array.from() function in JavaScript is the cause of the problem.

Maybe Silverfort's MFA script is configured in the iDP.

Environment

  • BIG-IP APM
  • Virtual server
  • Access profile
  • SAML auth or Oauth
  • Edge Client

Cause

Edge Client uses webview and some code from the server is not supported.

K000132344: Mini-browser versions used by the BIG-IP Edge Client

Recommended Actions

The suggested solution is, apply the Procedure in K000141526: BIG-IP Edge Client Windows uses default browser for authentication.

More idea is, for Yubikey, you may want to use Oauth instead of SAML.
