Description

You need to rename a GTM configuration object such as GTM server object
For example you have two GTM server objects named DC1_BIGIP and DC2_BIGIP and you need to change the device names.

Environment

  • DNS/GTM server object name change

Cause

None

Recommended Actions

From CLI run
(tmos)# modify gtm server <current_device_name> addresses modify { <ip_address> { device-name <new_device_name> } }
(tmos)# save sys config

For example, to change the names for devices DC1_BIGIP & DC2_BIGIP:
(tmos)# modify gtm server DC1_BIGIP addresses modify { 10.10.1.1 { device-name DC1_BIGIP_New } }
(tmos)# modify gtm server DC2_BIGIP addresses modify { 172.16.2.2 { device-name DC2_BIGIP_New } }
(tmos)# save sys config
