Known Issue

Note: This issue only effects the BIG-IP 1500 platform.

This is the result of a known issue. An IP forwarding virtual server configured on a BIG-IP 1500 changes TCP packets with computed checksums of 0x0000 to 0xffff. As a result of the checksum change, some TCP stacks may drop the packet.

F5 Product Development tracked this issue as CR71330, and it was fixed in BIG-IP LTM 9.1.3, 9.3, and 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.
