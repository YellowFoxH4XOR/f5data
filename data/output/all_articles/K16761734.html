Description

BIG-IP can use external monitor capability to monitor pop3 server. We use curl command to authenticate for monitoring pop3 server on external monitor script. The sample script is explained in details on K10048302.
If colon is included on the specifying username, curl parses it a a delimiter and not a string. As a result, your script might be end up with authentication failure and monitor marks down.
Instead of specifying colon as special character, you can specify URL encoding character, %3A as a replacement.
 

Environment

  • BIG-IP system

Cause

This is by design

Recommended Actions

  1. Do not use colon on your username
  2. Replace colon with URL encoding character
