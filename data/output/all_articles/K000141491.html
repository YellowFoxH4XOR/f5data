Description

Central Manager may appear to show stale pages. In particular after an upgrade, aspects of the pre-upgrade may look exactly the same in the new software version, where new features and options do not appear on the web UI at all.

Environment

  • BIG-IP Central Manager
  • Often post-upgrade.

Cause

Central Manager allows browsers to cache content. The browser will keep and re-use cached content when it perceives the page to be static.

Recommended ActionsAlways after an upgrade, or in any situation where a page appears to be rendering incorrectly, clear the browser cache for the "site" Central Manager.
