K000149897: Can't see access sessions older than a month anymore

Description

Access sessions older than one month are not visible in the APM overview menu. This issue occurs due to limitations in the SQL database (logdb) used by BIG-IP APM for storing session data. The database has a fixed size, and once it reaches its capacity, older logs are purged automatically to make room for new entries.

Environment

  • Product: BIG-IP APM VE
  • Version: 16.1.3
  • LogDB
  • Report

Cause

The SQL database (logdb) used by BIG-IP APM for storing session data has a fixed size limit (default: 1 million records). As session volume increases or logging levels are set higher than default, the database fills up more quickly, causing older logs to be purged sooner. This behavior is expected and designed to maintain database performance and prevent overutilization of disk space.

Recommended Actions

Option 1: Offload Logs to an External Syslog Server (Recommended)

To retain access session logs for a longer period without being constrained by the local database size:

  1. Configure remote syslog servers for log offloading.
  2. Use external tools or systems for long-term log storage and reporting.

Option 2: Adjust Logging Levels to Reduce Data Volume (Recommended)

Lowering logging verbosity can reduce the amount of data written to the local SQL database, thereby extending retention time:

Review current logging levels using commands like:

tmsh list sys db log.ssl.level

Set logging levels back to defaults if they have been modified unnecessarily:

tmsh modify sys db log.ssl.level value Warning
