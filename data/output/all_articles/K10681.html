K10681: The 3900 platform does not support BIG-IP 10.0.x

Topic

The 3900 platform does not support BIG-IP 10.0.0 and 10.0.1. Attempts to install these versions will fail, and could leave your system in an unusable state. If you use the wipedisk utility prior to using the image2disk utility to install the software, a warning message that appears similar to the following example is displayed on the console:

--------------------------------------------------------------------------------
WARNING! 
Errors occurred on the following disks:

HD1.1 v
HD1.2 v 

Product images on these disks will not be shown in
the upcoming installation planning, and will be
discarded during the installation session. It may be
possible to fix these errors by rebooting.

Are you sure you want to continue?
--------------------------------------------------------------------------------

If you attempt to continue the installation, the system is unable to locate the installation image, and the software installation fails. As a result, the system will be unable to find a bootable TMOS partition, and boots by default to the Maintenance Operating System (MOS) located on the flash drive.

If you have attempted this installation and your 3900 platform is unresponsive or does not boot properly, re-initialize the hard drive by following the Clearing the MBR for systems running BIG-IP versions 10.0.0 through 10.0.1 procedure described in K6346: Recovering from a corrupt drive partition. Once the drive is re-initialized, install BIG-IP 9.4.8, or BIG-IP 10.1.0 or later.
