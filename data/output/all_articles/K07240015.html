Topic

You should consider using this procedure under the following condition:

  • You have configured the Topology load balancing mode for a wide IP, and the topology records are configured so that load balancing results occasionally match multiple pools.

Description

When using the Topology load balancing mode to distribute requests to multiple wide IP pools, the system may load balance requests in an unequal or unexpected manner under certain conditions. This may occur when more than one wide IP pool shares the highest assigned score for a particular load balancing decision. For example, if you have configured the topology records so that the region/pool combinations create multiple matches for incoming requests, the system may load balance the requests in an unequal manner. You can configure the BIG-IP DNS system to randomly select a pool when Topology load balancing results in multiple pools with the same score by enabling the gtm.wideiptoporandom database variable.

Note: To implement more granular load balancing, reducing the possibility of multiple match scenarios, refer to: K14284: Overview of the longest match algorithm (BIG-IP DNS 11.x - 13.x)

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You can access the TMOS Shell (tmsh).

Procedures

  • Enabling random pool selection when Topology load balancing results in multiple pools with the same score
  • Disabling the gtm.wideiptoporandom database variable

Enabling random pool selection when Topology load balancing results in multiple pools with the same score

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Configure random pool selection when Topology load balancing results match multiple pools, by typing the following command:

    modify /sys db gtm.wideiptoporandom value enable

  3. Save the configuration by typing the following command:

    save /sys config

Disabling the gtm.wideiptoporandom database variable

To return the gtm.wideiptoporandom database variable to the default setting, and disable random pool selection when Topology load balancing results match multiple pools, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Configure random pool selection when Topology load balancing results match multiple pools, by typing the following command:

    modify /sys db gtm.wideiptoporandom value disable

  3. Save the configuration by typing  the following command:

    save /sys config
