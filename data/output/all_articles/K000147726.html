Description

I need guidance on how to configure and test the API of Distributed Cloud (XC).

 

Environment

  • F5® Distributed Cloud
  • XC SaaS
  • XC API

Resolution/Answer

In order to make an API call to XC services, you would need the following information:

  • Request URL
  • Authorization header/API Token

To retrieve your API token:

  1. Navigate to Administration > Personal Management
  2. If an API token has not already been created, please follow the Generate API Tokens part of this doc: https://docs.cloud.f5.com/docs/how-to/user-mgmt/credentials 
  3. Copy the API token from Credentials or Service Credentials list:

     

How to test API using curl

  1. Find the API you want to test or execute, for example, if we want to get the Load Balancer list of our namespace refer to https://docs.cloud.f5.com/docs/api/views-http-loadbalancer#operation/ves.io.schema.views.http_loadbalancer.API.List 
  2. There are the descriptions of this API 
  3. The host is the host of your portal like {teant-name}.console.ves.volterra.io
  4. Add the API token to the header and the curl command is like the below: 
    curl --location 'https://{teant-name}.console.ves.volterra.io/api/config/namespaces/{namespace_name}/http_loadbalancers' \

    --header 'Authorization: APIToken {API_Token}'
