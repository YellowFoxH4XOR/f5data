Description

You may find multile filestore symlink for default.crt and default.key under /config/filestore/files_d/Common_d/certificate_d or /config/filestore/files_d/Common_d/certificate_key_d after BIG-IP upgrade following.

# ls -l /config/filestore/files_d/Common_d/certificate_key_d
/\:Common\:default.key_*
lrwxrwxrwx. 1 root root 31 Dec  3 23:48 /config/filestore/files_d/Common_d/certificate_key_d/:Common:default.key_33687_1 -> /config/ssl/ssl.key/default.key
lrwxrwxrwx. 1 root root 31 Dec  3 23:48 /config/filestore/files_d/Common_d/certificate_key_d/:Common:default.key_33994_1 -> /config/ssl/ssl.key/default.key
lrwxrwxrwx. 1 root root 31 Dec  3 23:48 /config/filestore/files_d/Common_d/certificate_key_d/:Common:default.key_34113_1 -> /config/ssl/ssl.key/default.key
lrwxrwxrwx. 1 root root 31 Dec  3 23:48 /config/filestore/files_d/Common_d/certificate_key_d/:Common:default.key_34200_1 -> /config/ssl/ssl.key/default.key
lrwxrwxrwx. 1 root root 31 Dec  4 01:02 /config/filestore/files_d/Common_d/certificate_key_d/:Common:default.key_34292_1 -> /config/ssl/ssl.key/default.key

This article describes what triggers the default.crt and default.key symlink increase, and which is in use.

Environment

BIG-IP All version

Cause

The filestore file name revision number increments during an upgrade. This is by design.

The system default certificate and key information is not saved in the configuration file /config/bigip.conf.

Recommended Actions

You can find current active cache path following

1. Log into BIG-IP command line.
2. Run following tmsh command with -hidden option

# tmsh list sys file ssl-cert default.crt -hidden | grep cache-path
cache-path /config/filestore/files_d/Common_d/certificate_d/:Common:default.crt_34288_1
