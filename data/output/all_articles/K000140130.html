Description

When configuring AFM SSH Proxy, the connection is reset after entering the SSH Username in the terminal.

The following error message maybe observed in /var/log/sshplugin:

  • err sshplugin[pid]: SSHPLUGIN: sshplugin_1|SSHPlugin|ssh_setup_serverside|Core|the backend ssh server does not have a public key that matches the configuration! (3) Erroring out of this connection.

The following Reset Reason maybe observed in a tcpdump taken from the BIGIP:

  • Internal error (AFM::SSH requested abort (error during the key_exchange_thread (or reex

Environment

Relevant environmental factors specific to the topic

  • BIGIP AFM
  • SSH Proxy
  • SSH Server

Cause

The incorrect Public SSH key from the SSH Server is configured in the SSH Proxy Key Management "Real Server Auth" section.

Recommended Actions

Locate the appropriate SSH Public key from the SSH Server under /etc/ssh/ssh_host_*.pub

From the SSH Server, you can use the following command to list the available .pub files:

  • ls /etc/ssh/ssh_host_*.pub

From the SSH Server, you can use the following command to list the contents of the file; for example the ecdsa public key:

  • cat /etc/ssh/ssh_host_ecdsa_key.pub
