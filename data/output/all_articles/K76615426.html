Summary

Common Criteria Certification for BIG-IP 16.1.3.1

Description

CSEC has certified the following:

  • BIG-IP LTM+AFM 16.1.3.1 for Common Criteria against the Network Device collaborative Protection Profile and collaborative Protection Profile Module for Stateful Traffic Filter Firewalls,
  • BIG-IP LTM+APM 16.1.3.1 for Common Criteria against the Network Device collaborative Protection Profile, and
  • BIG-IP SSLO 16.1.3.1 for Common Criteria against the Network Device collaborative Protection Profile and PP-Module for SSL/TLS Inspection Proxy.

For more information about the Security Target and related information, refer to the following CSEC and NIAP websites:

  • LTM+AFM Certificate
  • LTM+APM Certificate
  • SSLO Certificate
  • LTM+AFM NIAP PCL listing
  • LTM+APM NIAP PCL listing
  • SSLO NIAP PCL listing

Common Criteria is an international initiative to standardize security functionality and assurance measures. For more information about Common Criteria Certification, refer to the following Common Criteria website:

http://www.commoncriteriaportal.org

Note: This document, along with the Common Criteria Guidance Supplement, provides guidance on the secure installation and secure use of the Target of Evaluation (TOE) for the evaluated configuration. These documents provide clarifications and changes to the standard documentation and should be used as the guiding documents for the configuration and administration of the TOE in the Common Criteria evaluated configuration. Official product documentation should be referred to and followed only as directed within these guiding documents.

Installation

To install the BIG-IP system in accordance with the evaluation's expectations, refer to the following document:

  • BIG-IP Common Criteria Evaluation Guide

This document contains information to ensure that you have the correct software version of the BIG-IP system and describes how to configure that system to be Common Criteria-compliant. This document is included in the ISOs described below.

Product documentation

The following ISOs contain the product and guidance documentation for the 16.1.3.1 Common Criteria evaluation:

  • CommonCriteriaDocumentation-16.1.3.1.iso from F5 Downloads
  • CommonCriteriaDocumentation-16.1.3.1.iso.sha256 from F5 Downloads
  • CommonCriteriaDocumentationSSLO-16.1.3.1.iso from F5 Downloads
  • CommonCriteriaDocumentationSSLO-16.1.3.1.iso.sha256 from F5 Downloads

To verify the ISO file against the checksum, use the Linux sha256sum command with the –check option:

sha256sum –check CommonCriteriaDocumentation-16.1.3.1.iso.sha256
