Known Issue

This is the result of a known issue. When you click the Clear Performance Data button from a detailed graph page, the BIG-IP system clears data for all performance graphs, rather than clearing data for only the specified graph.

For example, if you navigate to Statistics > Performance > Memory Used > View Detailed Graph, the System Memory Utilization detailed graph displays in the Configuration utility. If you click the Clear Performance Data button from this page, the BIG-IP system clears data for all performance graphs, rather than clearing only the System Memory Utilization graph.

Note: In BIG-IP 10.x, the path to the performance page is Overview > Performance.

F5 Product Development is tracking this issue as ID 246825 (formerly CR102918).
