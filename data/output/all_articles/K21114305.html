Description

  • Site not accessible (page doen't load) after upgrade to software version 15.x or 16.x
  • If ASM TS cookies are deleted from browser site starts working
  • The following error message can be seen on /var/log/asm

    Aug 13 04:22:13 asm1.example.com err perl[22670]: 01310001:3: event code I4556 Cookie building failed

Environment

  • ASM
  • After upgrade

Cause

Seen behaviour is caused by a known issue tracked with the bug ID 910253.

Recommended Actions

An EngHF with the fix for ID 910253 can be provided. Please open a case with F5 support and reference this ID

None.
