K85232431: GRE tunnel stopped working

Type
Support Solution
Published
2019-10-03
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.1.1
Source
https://my.f5.com/manage/s/article/K85232431

Description

  • GRE Tunnel stopped working

Environment

  • GRE Tunnel

Cause

Self IP configuration does not allow GRE.

Recommended Actions

Allow GRE in port lockdown configuration of the Self IP.

Additional Information

If a GRE tunnel is previously established, and port lockdown is later changed to exclude GRE (for example, a change from 'All' to 'None'), then the GRE tunnel is able to remain established. If the GRE tunnel drops at any point, it will not be able to re-establish.
