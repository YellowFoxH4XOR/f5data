Description

This article shows how to automate archival of user configuration set (UCS) backup files on the BIG-IP system and store a copy to a SFTP remote system.

Environment

  • Automating UCS Backup
  • SFTP remote system

Cause

None

Recommended Actions

You can use the F5 supplied script to create a UCS file on the BIG-IP system and then copy the UCS file to your SFTP server. Optionally, you can delete the UCS file on the BIG-IP system to save disk space.

 

  1. Ensure that you have public key-based authentication set up between the BIG-IP system and the remote system so the sftp program can automatically log in. For more information about how to do this refer to K13454: Configuring SSH public key authentication on BIG-IP systems. F5 recommends using SSH public key authentication for automation, as it is the only secure and supported method for non-interactive SFTP/SCP operations in scripts. There is no supported or secure way to pass a password to the SFTP command in a script on BIG-IP. Tools like sshpass are not available or supported on BIG-IP, and using expect scripts is not recommended due to security risks and lack of support.
  2. Log in to the command line as the root user.
  3. Create a directory for storage of the UCS files in /var/ucs, by entering the following command: 
    mkdir /var/ucs

     

  4. Use a text editor to create the backup script ~/backupscript.sh file. Copy and paste the following contents in the file:

     

    #!/bin/bash

tmsh save /sys ucs /var/ucs/$(/bin/hostname)-$(date +\%Y-\%m-\%d).ucs

## Replace the <remote_user_name>, <sftp_IP_address> and <sftp_directory> as needed
sftp <remote_user_name>@<sftp_IP_address>  <<EOF
cd /<sftp_directory>/
put /var/ucs/$(/bin/hostname)-$(date +\%Y-\%m-\%d).ucs
bye
EOF

## Optional: Uncomment the following line to delete the ucs file
#tmsh delete /sys ucs /var/ucs/$(/bin/hostname)-$(date +\%Y-\%m-\%d).ucs
  5. Save the backupscript.sh file under /var or /root directory and exit the text editor.
  6. Enable executable mode for the backupscript.sh file by typing following command: 
    chmod +x ~/backupscript.sh
  7. Schedule execution of the script using the crontab utility depending on the frequency you need. Refer to K13418: Archiving UCS files using the logrotate and crontab utilities for examples of how to edit the crontab file.

Additional Information

If your remote system is using SCP, refer to the related article instead: K13418: Archiving UCS files using the logrotate and crontab utilities
