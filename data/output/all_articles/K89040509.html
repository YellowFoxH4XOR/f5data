Source

Description

  • Unable to discover and import ASM configuration onto BIG-IQ
  • When discovering or importing ASM configuration from BIG-IQ an error message appears in the GUI:
Discovery Error for ASM Service - (java.lang.NullPointerException) while adding
  • 'Failed to process module tasks for device' error message is also logged in /var/log/restjavad.0.log

[ERROR][26 Apr 2019 22:30:36 PDT][/cm/asm/tasks/discover-config/e37098d7-ad4e-1111-aa11-aaaaa11111/worker AsmDiscoveryTaskWorker] no message: java.lang.NullPointerException
[ERROR][26 Apr 2019 22:30:37 PDT][/cm/global/tasks/device-discovery/374db383-1736-1111-aa11-aaaaa11111/worker DiscoverySuperTaskWorker] Failed to process module tasks for device <BIG-IP hostname> (10.10.10.10): At least one module has failed

Environment

  • BIG-IQ
  • ASM
  • Azure - Service Scaling Group (SSG)

Cause

  • A service scaling group (SSG) created with BIG-IP VE devices running the WAF service in an Azure environment sometimes fails in a Pause state.
  • SSG is created but not functional

Recommended Actions

  • The workaround is to recreate SSG.
Alternatively
  • try initial build out with minDevices=2. Wait for the build out to complete and do a manual scale-in by updating the SSG with minDevices=1
