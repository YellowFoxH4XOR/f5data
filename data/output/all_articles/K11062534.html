Issue

Error Message

alert vcmpd[<PID>]: 01510011:1: vCMP guest <Name of Guest> powered off.

In this error message, note the following:

  • <PID> is the process ID for the vcmpd process.
  • <Name of Guest> is the name of the guest that was shut down.

For example:

alert vcmpd[12954]: 01510011:1: vCMP guest My_LTM_Guest powered off.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • This message is logged whenever the vCMP guest is shut down.

Impact

The guest is no longer available for use.

Recommended Actions

None
