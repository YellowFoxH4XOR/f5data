Description

Your requests are being blocked or flagged with an Illegal URL violation, for a URL that was previously in allowed list. Audit logs indicate that the Automatic Policy Builder has removed this allowed URL recently. You would like to understand the reason behind this behaviour.

Environment

  • BIG-IP ASM
  • Automatic learning enabled
  • Learn only from non-bot traffic enabled in the security policy

Cause

The Policy Builder, when set to Automatic mode, adds or removes entities based on statistical analysis of traffic. If a URL has not been observed in traffic for a certain period, it may be suggested for deletion and, if accepted (which happens automatically in Automatic learning mode), removed from the policy.

Additionally, when the “Learn only from non-bot traffic” option (enabled by default) is active, traffic originating from bot sources is excluded from the learning process. As a result, entities such as URLs that only receive requests from bot sources may be considered obsolete and suggested for removal.

Recommended Actions

If you wish to keep automatic learning enabled for a policy and ensure that these requests from bots are included in the learning process, you should disable the “Learn only from non-bot traffic” option in the policy configuration.

Navigate to Security  ››  Application Security : Policy Building : Learning and Blocking Settings : Policy Building Process, click on checkbox to disable the attribute. 

Additional Information

By default, policy entities that have not received any traffic for 90 days are suggested for removal. This value can be modified by navigating to Security ›› Application Security : Policy Building : Learning and Blocking Settings : Policy Building Process, and adjusting the setting “Suggest to delete policy entity if it was not observed in traffic for more than X days.”
