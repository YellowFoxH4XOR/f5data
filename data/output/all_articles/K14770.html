Known Issue

On rare occasions, the BIG-IP system may experience a kernel panic when it starts or reboots.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is running on any of the following versions:
    • BIG-IP 10.2.3
    • BIG-IP 10.2.3 HF1 through HF2
    • BIG-IP 10.2.4
    • BIG-IP 10.2.4 HF1 through HF7
  • A user initiated a number of sequential reboot operations.

Note: This issue does not affect the following BIG-IP platforms:

  • BIG-IP 2000s/2200s (C112)
  • BIG-IP 4000s/4200v (C113)
  • BIG-IP Virtual Edition
  • BIG-IP vCMP Guest environment

Impact

The system posts an error message and experiences an additional reboot.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system experiences a kernel panic state when it starts or reboots.
  • An error message may display on the console screen. The error message appears similar to the following example:

    Kernel BUG at mm/slab.c:2650
    invalid opcode: 0000 [1] SMP
  • The BIG-IP system posts the kernel panic error message and automatically reboots. This reboot will bring the BIG-IP system back to its operational state.
