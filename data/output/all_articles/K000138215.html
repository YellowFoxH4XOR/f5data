Description

If you no longer need a wide IP on a BIG-IP system, you can use the Configuration utility or command line to remove the configuration. This article describes how to do that.

Depending on how you are decommissioning the application associated with the wide IP, you may need to review the TTL of the attached pools and if necessary shorten the TTL so the resource records will no longer be cached by resolvers. If you are delegating a subdomain per K277: Delegating a subdomain to a BIG-IP DNS or BIG-IP Link Controller system from another DNS server, you may also need to shorten the TTL on the CNAME. To view the pool TTL from the TMOS shell, use the following syntax: tmsh list gtm pool <record type> <name> ttl. To view the pool TTL on the Configuration utility go to DNS > GSLB > Pools > Pool List and select the pool name link.

Prerequisites

You have administrative privileges on the BIG-IP system

Procedures

  • Removing wide IP and associated configuration using the Configuration utility
  • Removing wide IP and associated configuration using the command line

Removing wide IP and associated configuration using the Configuration utility

You must remove all elements of the wide IP configuration in the order listed below.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Remove wide IP configuration

  1. Log in to the BIG-IP Configuration utility.
  2. Go to DNS > GSLB > Wide IPs > Wide IP List.
  3. Select the check box next to the Wide IP.
  4. Select Delete.
  5. Select Delete again to confirm the action.

Remove GSLB pools associated with the wide IP

  1. Go to DNS > GSLB > Pools > Pool List.
  2. Select the check box next to the pool.
  3. Select Delete.
  4. Select Delete again to confirm the action.
  5. Repeat for any other pools.

Remove virtual servers associated with the pool

  1. Go to DNS > GSLB > Servers > Server List.
  2. Select the server name link.
  3. Go to Virtual Servers.
  4. Select the check box next to the virtual server you want to remove.
  5. Select Remove.
  6. Select OK to confirm.
Removing wide IP and associated configuration using the command line

You must remove all elements of the wide IP configuration in the order listed below.
Note: TMSH GTM (DNS) changes are automatically saved to the bigip_gtm.conf file.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Remove wide IP configuration

  1. Log in to the TMOS shell of the BIG-IP using the following command:
    tmsh
  2. To delete a wide IP, use the following syntax:

    delete gtm wideip <record type> <name>

    For example:

    delete gtm wideip a wip.example.com

Remove GSLB pools associated with the wide IP

  1. To delete a GSLB pool use the following syntax:

    delete gtm pool <record type> <name>

    For example:

    delete gtm pool a mypool1

Remove virtual servers associated with the pool

  1. To delete a virtual server from a GSLB server object use the following syntax:

    modify gtm server <server> virtual-servers delete { <virtual server> }

    For example:

    modify gtm server myserver virtual-servers delete { myvs1 }

    Note: If the server is a BIG-IP and Virtual Server Discovery is enabled, then the virtual server will reappear.
