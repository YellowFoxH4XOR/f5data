K98118235: BIG-IP ASM generates same device id for different mobile devices fused by Anti-Bot Mobile SDK

Type
Support Solution
Published
2021-05-27
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP ASM: 13.X.X, 13.0.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.X, 13.0.1, 13.0.0, 13.1.0
Source
https://my.f5.com/manage/s/article/K98118235

Description

You may observe BIG-IP ASM generates same device id for different mobile devices that are fused by Anti-Bot Mobile SDK.

Environment

  • 13.1.x
  • Anti-Bot Mobile SDK

Cause

Anti-Bot Mobile SDK is lack of entropy.

Recommended Actions

You may use either one of the following method to fix the issue:

  1. Use the latest version of SDK on Appdome to fuse the mobile application again

  2. Modify the db key on BIG-IP:

    tmsh modify sys db did.match_mode value "simple"

Additional Information

None.
