Policy Information

The APM Client software lifecycle support policy defines the client software lifecycle from initial release through retirement. This policy describes the levels of support available for customers with a purchased Support Agreement. The intent of this policy is to provide consistent documentation that aids customers in planning and preparing for their organization's support needs.

About APM Client software

BIG-IP APM offers remote connectivity using either standard browsers or a variety of client software.

  • BIG-IP Edge Client offers endpoint inspection and VPN capability with a rich set features on desktop operating system, distributed from the BIG-IP system as an installable client package. BIG-IP Edge Client also includes optional F5VPN and F5EPI desktop apps, which provide browser-based VPN and inspection.
  • F5 Access is available on both mobile and desktop operating systems. F5 Access is a more lightweight VPN connectivity app with fewer features and is installed using Mobile Device Management (MDM) or manually from an app store.

BIG-IP Edge Client lifecycle policy

Prior to 13.1.0, BIG-IP Edge Client was bundled with BIG-IP APM. Each BIG-IP version contained a static BIG-IP Edge Client version. To upgrade BIG-IP Edge Client, administrators were forced to upgrade the BIG-IP system. For these client versions, F5 Support offers assistance to customers with a valid support contract and a currently supported BIG-IP APM version. F5 provides software fixes as needed.

Starting with BIG-IP APM 13.1.0, BIG-IP Edge Client is available as a standalone package that can be installed on BIG-IP APM running 13.1.0 or later. BIG-IP Edge Client versions are not statically tied to a specific BIG-IP version. As F5 releases new client versions, you can install them to an existing BIG-IP system.

APM Clients

For APM Client versions, F5 Support offers assistance for customers with a valid support contract and a currently supported BIG-IP APM version. F5 provides software fixes and technical support in the current latest major released version and one version prior. For example, with the release of APM Clients 7.2.5, only 7.2.5 and 7.2.4 are supported. APM Clients 7.2.3 and earlier versions have reached End of Software Development and End of Technical Support.

F5 Access Client lifecycle policy

F5 Access support is available for customers with a valid BIG-IP support contract for any version currently under active support. Because F5 Access is distributed from third-party app stores, F5 provides software fixes in a future version release. F5 works closely with app store vendors to expedite the app publishing process to resolve issues quickly.

Support policy limitations

F5 supports the listed operating systems releases, with the latest service pack or service pack equivalent, if they are supported by the OS vendor.

Microsoft’s policy of Servicing Channels with Windows 11 has changed the F5 support policy for Windows 11 as follows:

  • F5 will support Microsoft Windows 11 Annual Channel for 36 months from the date of release. The Annual Channel replaces the Current Semi-Annual releases and Current Branch for Business (CBB) concepts.
  • F5 will support Windows 11 Long-Term Servicing Channel releases if such a release is within the 'mainstream support' period of Microsoft. The Long-Term Servicing Channel replaces the Long-Term Servicing Branch (LTSB) concept.

    Windows 10

    Support for Windows 10 Enterprise LTSC 2021 is extended until Jan 12, 2027, following Microsoft's extended Windows 10 support timelines.

    F5 supports the listed browser releases, with the latest service pack or service pack equivalent, for up to three years from the time of initial release. The listed browsers must still be supported by the vendor.

    If a browser vendor ends mainstream support before the end of that three-year period for a release or service pack, F5 will also end support at the same time. Once a browser surpasses the three-year date from release, F5 will continue to monitor the user base of the browser release. When a release reaches a usage level that can no longer justify development, test, and support resources, F5 issues an End of Life (EoL) solution at least three months prior to the planned End of Development Support (EoDS).
