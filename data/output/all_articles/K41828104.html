Description

This issue occurs when using your BIG-IP system is configured with BGP dynamic routing and a route-map is used to filter BGP advertisements, changes to the route-map that affect the filtered routes will not trigger an update to the affected routes.

Environment

  • BIG-IP LTM with Advanced Routing Module provisioned
  • Route Domain with BGP routing-protocol enabled
  • eBGP neighbor configuration (BIG-IP has different Autonomous System Number from router network) 
  • LTM virtual-addresses configured with Route Health Injection (RHI), or route-advertisement selective
  • Router BGP configuration with route-map and prefix-list in ZebOS configuration

Cause

Bug ID605966: BGP route-map changes may not immediately trigger route updates. ID605966 is fixed in BIG-IP version 17.1.2 and 16.1.5, but the issue is present in older releases. 

Recommended Actions

  1. To workaround this issue on affected versions of BIG-IP, run the following command:
    clear ip bgp <neighbor> soft out
  2. To confirm BIG-IP is now advertising the updated route-map policy, run the following command:
    show ip bgp neighbor x.x.x.x advertised-routes
