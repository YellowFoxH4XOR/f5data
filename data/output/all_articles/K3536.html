Topic

To ping nodes on an external network, BIG-IP must be configured to allow ICMP traffic to pass. You can achieve this using one of the following methods:
  • Virtual server
    A wildcard virtual server with the any_ip option enabled will allow ICMP traffic to pass, enabling you to ping through BIG-IP to any address.

  • NAT
    NATs and SNATs will pass ICMP packets in BIG-IP version 4.0 and later.

  • IP Forwarding
    IP Forwarding will allow any traffic to pass through BIG-IP; however, F5 Networks does not recommend this method, because it is less secure than using virtual servers or NATs. For more information, refer to K1473: Configuring BIG-IP to use simple persistence when a persistence cookie is not presented by the client.
