Description

Can´t generate and install a third-party SSL certificate 2048 bytes CSR on the management interface.

Environment

  • Configuration Utility
  • You are required to create a CSR with a size of 2048 bytes
  • The Configuration Utility only shows the option to create a key with size 1024 bytes.

Cause

None

Recommended Actions

You can manually create a CSR via CLI with the desired key size. To do so, follow these steps:
  1. Login into the BIG-IP
  2. Run the following openssl command.
    openssl req -new -nodes -days 365 -newkey rsa:<key size> -keyout <key name>.key -out <CSR name>.csr

    Note: Available key lengths are 512, 1024, 2048, and 4096 bytes. The default is 2048.

    For example:
    openssl req -new -nodes -days 365 -newkey rsa:2048 -keyout new.key -out newcert.csr
     
  3. After running the command, the CSR and they key will be saved on the directory where you ran the command.
     
  4. Follow the steps of article K16951115: Changing the BIG-IP system device certificate using the Configuration utility to change the device certificate.
