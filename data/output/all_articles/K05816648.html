You should consider using this procedure under the following conditions:

  • You are a BIG-IP APM administrator.
  • You want to provide end users with access to download the installation file for the BIG-IP Edge Client (Windows, Mac, Linux) directly from the BIG-IP APM system. 

Download notice to VPN end users: Your organization's BIG-IP APM system administrator uses the instructions in this article to download the BIG-IP Edge Client desktop application from the BIG-IP APM system and distribute it to VPN end users. This requirement is based on the BIG-IP Edge Client configuration objects of the installation package are specific to the intended access configuration for your organization. You must either refer to your organization's documentation or contact your IT department for details about how to download the BIG-IP Edge Client desktop application from your organization's internal resources.

Description

For BIG-IP administrators, there are multiple mechanisms to distribute the BIG-IP Edge Client package to your VPN end users. The following procedures allow end users to independently download the installation files through a direct download link or through a webtop link.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP Configuration utility.
  • You have an existing access policy that allocates a webtop.
  • You previously downloaded the BIG-IP Edge Client (Windows, Mac, Linux) installation files.

Procedures

Uploading the BIG-IP Edge Client installation file to hosted content

To upload a BIG-IP Edge Client installation file to the BIG-IP hosted content, perform the following procedure. You will need to perform this procedure for each OS version of the BIG-IP Edge Client that you plan to make available.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Go to Access > Webtops > Hosted Content > Managed Files.
  3. Select Upload.
  4. Select Browse and select the BIG-IP Edge Client installation file.

    Note: The filename is automatically applied, but you can modify it.

  5. Select the secure level.
    LevelDescription
    PolicySpecifies that the file is available only to users who have successfully completed an access policy, with an Allow ending result, and an access profile associated with the hosted content repository. You can assign this to display an HTML file that only a verified user can see.
    PublicSpecifies that the file is available to anyone with an access profile associated with the hosted content repository. You might use this to allow access to an installation package that a user needs to start an access session.
    SessionSpecifies that the file is available only to users with an active per-session policy session and an access profile associated with the hosted content repository. You may use this to allow a user with an active session access to a required logon component.
    ​​​​​​
  6. Select OK.
  7. (Optional) Repeat this procedure for each OS version you plan to make available.

Once you upload the BIG-IP Edge Client installation file to hosted content, perform one of the two following procedures:

  • Creating a direct download link
  • Creating a webtop download link

Creating a direct download link

You can create a direct link to allow end users to access the hosted content for download through an existing access policy. To do so, perform the following procedure:

Impact of procedure: The following procedure will make the client download file publicly available.

  1. Log in to the BIG-IP Configuration utility.
  2. Go to Access > Webtops > Hosted Content > Manage Access.
  3. On the Edit Sandbox Profile Access prompt, select the Retain Public Access check box for the access policy.
  4. Select OK.

Once applied, the hosted content will be available through a link under the following format:

https ://<access-policy-url>/<Publicly-Accessible-URI>

For example:

https://example.com/public/share/example-download.exe

Creating a webtop download link

An existing access policy and webtop is required. To create a direct link to allow end users to directly access the hosted content for direct download, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Go to Access > Webtops > Webtop Links.
  3. Select Create.
  4. Enter a Name for the download file.
  5. On the Link Type drop down, select Hosted Content.
  6. On the Hosted File drop-down, select the Hosted Content file.
  7. Enter a Caption for the file.

    Note: This content will be the visible name for the webtop link.

  8. Select Finished.

    Note: Repeat steps 3 through 8 for additional clients.

  9. Go to Access > Profiles / Policies.
  10. Select Edit for the desired access policy.
  11. Select Advanced Resource Assign.
  12. Select Add/Delete for the desired webtop.
  13. Under the Webtop Links tab, select the newly created Webtop Links.
  14. Select Update.
  15. Select Save.
  16. Select Apply Access Policy.
