K000140122: Events are not shown in GUI Alarms & Events page on rSeries or VELOS, but are visible with 'show system events' command

Type
Support Solution
Published
2024-06-25
Updated
2024-06-25
Applies to
  • F5OS
  • F5OS-A: 1.7.X, 1.5.X, 1.7.0, 1.5.2, 1.5.1, 1.5.0
  • F5OS-C: 1.6.X, 1.5.X, 1.6.2, 1.6.1, 1.6.0, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000140122

Description

Cannot see events (for example, blade reboots) in the GUI's Alarms & Events page.

The only events visible are those from firmware-update-status.

Environment

  • rSeries or VELOS
  • GUI Alarms & Events page

Cause

Events in question are set to NA severity, while the GUI requires you to select a severity from EMERGENCY through to DEBUG.

For example:

326781 controller-2 reboot EVENT NA "reboot - controller-2.chassis.local F5OS-C controller version 1.6.2-22734" "2024-06-18 08:08:20.426413343 UTC"

An option will be added in a future release to view ALL events in the GUI.

Recommended Actions

As an immediate workaround, use SNMP, API, or show system events output to review the system events.
