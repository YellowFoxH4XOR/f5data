Known Issue

This is the result of a known issue. When you set up a hash persistence profile, you can configure the Override Connection Limit option. If the option is enabled, the BIG-IP system overrides pool member connection limits for persisted clients. However, the hash persistence profile currently always overrides pool member connection limits, even if the Override Connection Limit option is disabled.

F5 Product Development tracked this issue as ID 223930 (formerly CR132849) and it was fixed in BIG-IP 11.0.0. For information about upgrading, refer to the BIG-IP release notes.
