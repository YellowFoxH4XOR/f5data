Note: Using a self-signed SSL certificate with an extended expiration date increases the vulnerability window for the certificate because self-signed SSL certificates cannot be revoked through methods, such as Certificate Revocation List (CRL).

In BIG-IP 9.x, the default expiration time for a self-signed certificate created using the Configuration utility is 10 years. You must use the openssl command to create a self-signed certificate that expires in a different value than the default value of 10 years.

To do so, you must perform the following procedure:

  • Create a private key and self-signed certificate using the openssl command.

Note: Beginning in BIG-IP 10.x, you can specify an expiration time for self-signed certificates using the Configuration utility.

Creating a private key and self-signed certificate using the openssl command

The openssl command provides an option to specify an expiration time when creating a self-signed certificate. To create a new private key and self-signed certificate with an alternate expiration time, use the following openssl command syntax:

openssl req -x509 -nodes -days <# of days> -newkey rsa:<keysize> -keyout /config/ssl/ssl.key/<key_name>.key -out /config/ssl/ssl.crt/<cert_name>.crt

In this command, note the following:

  • Replace <# of days> with the number of days in year increments for which you want the certificate to be valid.

For example:

openssl req -x509 -nodes -days 365 -newkey rsa:1024 -keyout /config/ssl/ssl.key/f5test.key -out /config/ssl/ssl.crt/f5test.crt

Note: You will be prompted to enter the certificate attributes.

The previous command will create a key and certificate called f5test.key and f5test.crt, and will store them in the /config/ssl/ssl.key/ and /config/ssl/ssl.crt/ directories, respectively. The expiration time of the certificate created will be 1 year.

Additionally, you can use the following quick reference table to select the number of years for which you want the certificate to be valid:

For example, to make the certificate valid for two years, you would type the following command:

openssl req -x509 -nodes -days 730 -newkey rsa:1024 -keyout /config/ssl/ssl.key/f5test.key -out /config/ssl/ssl.crt/f5test.crt

The newly created self-signed certificate with a longer validity date will be stored in the /config/ssl/ssl.crt/ directory.

Note: For more information about the openssl req command and options, refer to the openssl req man page.
