K10893: Symantec AntiVirus software may falsely detect the TunnelServer.exe file as malware

Source

Topic

The TunnelServer.exe file is a FirePass client component used to manage Network Access and Application Tunnel connections. A virus definition update issued by Symantec in November of 2009 caused the TunnelServer.exe file to be incorrectly detected as the Backdoor.Delf Trojan virus. As a result, users running Symantec AntiVirus software could not connect to Network Access and Application Tunnel favorites.

Symantec has corrected the virus detection mechanism that produced this false positive. Users running Symantec AntiVirus should install the latest virus definitions and remove the TunnelServer.exe file from the antivirus quarantine (if applicable) to correct this behavior. If users continue to experience connection issues after installing the latest virus definitions (for example, if the antivirus software deleted the TunnelServer.exe file), the affected users should remove the F5 Networks Dynamic Application Tunnel Control client component. This component will automatically be reinstalled the next time the user launches a Network Access or Application Tunnel favorite.

Note: For instructions about removing FirePass client components, refer to K8253: Removing FirePass client components from Windows 2000, 2003, XP, and Vista systems.

Note: If you are using the FirePass Components Troubleshooting Utility (CTU), right-click the TunnelServer component located under the Application Tunnels sub-menu and select Remove component.
