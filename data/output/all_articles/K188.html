BIG-IP version 4.0 through 4.6.4

For BIG-IP versions 4.0 through 4.6.4, you can determine if IP forwarding is enabled by typing the following command:

bigpipe global show | grep ipforward

Look for the value of ipforwarding. The value is either disabled or enabled.

BIG-IP version 1.8.3 through 3.1.1 PTF-06

For BIG-IP versions 1.8.3 through 3.1.1 PTF-06, you can determine if IP forwarding is enabled by typing the following command:

sysctl -a | grep forw

Look for the value of net.inet.ip.forwarding. This value is defined as follows:

  • A value of 0 indicates that IP forwarding is disabled.
  • A value of 1 indicates that IP forwarding is enabled.
