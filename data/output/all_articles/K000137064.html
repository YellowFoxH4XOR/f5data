Description

You are noticing that the syslog messages from the TMM interface are utilizing the management IP address.

Environment

  • BIG-IP system
  • Remote syslog configuration

Cause

This behavior is due to Syslog-ng starting up before all the interfaces and routes are up during system startup.

Recommended Actions

If this behavior is not desired, you can modify the system startup configuration. You need to add the line 'bigstart restart syslog-ng' in the /config/startup file. Here's an example:

# cat /config/startup
==================================================
#
# NOTE:
# This file will be installed in /config/startup and it will
# be called by /etc/rc.local.
#
# - /config/startup is for customer config additions and
# will be saved in UCS
#
# - /etc/rc.local should *not* be used by customers and
# can/will be changed by F5
#
 bigstart restart syslog-ng
==================================================
