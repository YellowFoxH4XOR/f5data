K000139249: Which MFA factor was set for MyF5 access?

Type
Support Solution
Published
2024-05-03
Updated
2024-05-03
Applies to
  • Support Portal
Source
https://my.f5.com/manage/s/article/K000139249

Description

The 2-step verification (MFA) requires that each time you sign in to your F5 account, you'll need your password and a verification code. For the verification code, you can opt for Google Authenticator App or Email authentication. 

 

Environment

  • MyF5 Access
  • MFA
  • 2-step verification
  • Email Authentication
  • Google Authentication

Cause

None.

Recommended Actions

There are 2 ways to find which MFA you opted for. 

1. Upon signing in, you will see below prompt. It will either say Email Authentication or Google Authentication. Below screen shows that the person opted for Email Authentication and the partial detail of the email ID will be shows. 

 

2. Click on the "human" icon > Select User profile > Manage Security preference > It will also show you the MFA that was opted for.
