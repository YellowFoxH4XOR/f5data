Description

Features available with AAM limited license.

Environment

  • AAM limited license

Cause

None

Recommended Actions

None

Additional Information

  • The AAM limited license has these features available:
    • Rate Shaping
    • Bandwidth Controller
    • Symmetric Optimization (WOM)

It does not include Forward Error Correction (FEC) or DeDuplication, but you can still use compression and encryption between the endpoints.

  • The AAM full license has these features available:
    • Rate Shaping
    • Bandwidth Controller
    • Symmetric Optimization (WOM) including Forward Error Correction (FEC) and DeDuplication
    • Web applications
    • Acceleration profiles

RAMCache is included with a standard LTM license, it does not need AAM to be provisioned.
