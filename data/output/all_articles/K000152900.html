K000152900: Modifying certificate/key pair associated to SSL profiles via REST API

Type
Support Solution
Published
2025-08-06
Updated
2025-08-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000152900

Description

This article contains information on how to modify SSL certificate and key pair associated to SSL profiles via REST API

Environment

  • BIG-IP LTM provisioned
  • SSL profile (client or server) using certificate/key pair

Cause

None

Recommended Actions

The approach via REST API involves a HTTP PATCH request with the payload containing the desired cert/key (and chain) info. That would automatically update the relevant cert, key or chain references within the SSL profile's configuration. The procedure documented in this section can be used to accomplish this and make sure to replace the credentials and device hostname or management IP in these commands respectively:

(1) Query the SSL profile to see the certificate/key pair that is currently utilized:

$ curl -sk -u ${BIGIP_USER}:${BIGIP_PASS} -H "Content-Type: application/json" "https://${BIGIP_MGMT}/mgmt/tm/ltm/profile/client-ssl/~Common~test_clientssl" | jq '{name, cert, key, chain, certKeyChain}'

Note: Replace "~Common~test_clientssl" with the appropriate partition and SSL profile name. In case of a server SSL profile, the URI can be modified to include "server-ssl" instead of "client-ssl".

(2) To modify the certificate/key pair associated to this SSL profile, you can issue an API call with a HTTP PATCH request in the following manner:

$ curl -sk -u ${BIGIP_USER}:${BIGIP_PASS} -H "Content-Type: application/json" "https://${BIGIP_MGMT}/mgmt/tm/ltm/profile/client-ssl/~Common~test_clientssl" -X PATCH -d '{"cert": "example_ssl", "key": "example_ssl"}' | jq '{name, cert, key, chain, certKeyChain}'

Note: Replace "~Common~test_clientssl" with the appropriate partition and SSL profile name. Also, replace "example_ssl" with the respective name of your certificate and key pair in the above command, without the .crt or .key extension. In case of a server SSL profile, the URI can be modified to include "server-ssl" instead of "client-ssl".
