The following table contains the base operating system information for F5 Traffix Signaling Delivery Controller (SDC):

SDC versionPre-configured base operating system
5.2.0RedHat Enterprise Linux Server 8.8
5.1.0RedHat Enterprise Linux Server 6.8
5.0.0RedHat Enterprise Linux Server 6.8
4.4.0RedHat Enterprise Linux Server 6.8
4.0.5RedHat Enterprise Linux Server 6.7

Important: SDC has pre-configured the base operating system to match the requirements, and has added packages required to run SDC. Therefore, you must install only F5 supplied patches.
