Known Issue

This is the result of a known issue. When the BIG-IP system boots up, the system may log a ti_interrupt_callback error to the console and to the /var/log/kern.log file that appears similar to the following example:

ti_usb_3410_5052.c: ti_interrupt_callback - DATA ERROR, port 0, data 0x6C

This issue has been reported to affect the following BIG-IP platforms:

  • BIG-IP 1600 (C102)
  • BIG-IP 3600 (C103)
  • BIG-IP 3900 (C106)

This error message is benign and does not affect BIG-IP functionality.

F5 Product Development is tracking this issue as ID 222004 (formerly CR107830).
