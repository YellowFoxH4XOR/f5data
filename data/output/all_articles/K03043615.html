K03043615: Edge Client may fail to establish connection to BIG-IP APM on certain versions of Windows 10

Type
Support Solution
Published
2019-11-18
Updated
2025-01-09
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 13.X.X, 13.0.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.X, 13.0.1, 13.0.0, 13.1.0
Source
https://my.f5.com/manage/s/article/K03043615

Description
Versions of Windows 10 prior to build 1809 can sometimes have issues connecting to BIG-IP APM

Environment

  • Windows 10 prior to build 1809
  • BIG-IP APM
  • VPN configured Virtual Server

Cause
The Windows RAS adapter may not allow proper connection and results in this error:
DIALER, CURDialer::OnRasCallback(), RAS error (state=RASCS_AuthNotify, error=720: A connection to the remote computer could not be established. You might need to change the network settings for this connection.)

Recommended Actions

  1. Update Windows 10 to build 1809 later
Additional Information
None
