Description

Can BIG-IQ be used as High-Speed Logging destination for GTM logs?

Environment
  • BIG-IQ
  • BIG-IP with GTM provisioned.
Cause

BIG-IQ cannot be set up as HSL destination for GTM logs stored locally in /var/log/gtm on a BIG-IP device.

Recommended Actions

None.

None.
