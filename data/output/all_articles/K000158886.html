Description

A particular user has ASM policy hung indefinitely at “Applying policy” and unable to apply any other policies. The problem does not apply to other ASM users.

Environment

  • BIG-IP ASM

Cause

The affected user has staled/orphaned apply-policy tasks

Recommended Actions

You can run the following to list and remove staled apply-policy tasks

  1.  Filter apply-policy task list with the following command:
    curl -k -S -u '<affected user's username>:<affected user's password>' https://localhost/mgmt/tm/asm/tasks/apply-policy | jq '.items[] | select(.status == "NEW")'
