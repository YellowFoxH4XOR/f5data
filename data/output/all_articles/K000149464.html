Description

ASM event logs are missing in the GUI, which could indicate that the protobuf limit has been reached.

Environment

ASM event logs

Cause

The protobuf has reached the limitation. 

Recommended Actions

To prevent the protobuf from reaching its limit, we recommend following one of the steps below:

1- Avoid using "log all requests" profiles; 

2- Replace "log all requests" by "illegal log request profiles"

3- Solve pending suggestions on each ASM policy. This will alleviate the pressure over asmlogd, however, keep under consideration that this might not help at all.

4- Export the ASM event logs to an external server (BIG-IQ system, SPLUNK, SIEM, QRadar). The ASM system is not designed to store ASM event logs locally and that could cause lost data.

5- Lastly, remove some logging profiles of several virtual servers in order to release the pressure and start logging in to a few virtual servers.

6- Security ›› Application Security : Policy Building : Learning and Blocking Settings : Policy Building Process

  • Untick the option "Learn from responses"
  • Save
  • Apply the change to the policy
