K000135803: After updating Edge Client to version 7.2.4.2 or higher versions, the syntax previously applied by following K000133271 on version 7.2.4.1 is no longer works

Description

You have implemented the K000133271 to use the self-signed SSL certificate on BIG-IP APM servers on BIG-IP APM Edge Client 7.2.4.1.

But when you upgrade to BIG-IP APM Edge Client 7.2.4.2 or higher, you will still find the BIG-IP Edge Client is prevented from connecting to BIG-IP APM servers with a popup window warning that the connection is being established with a BIG-IP APM Server that uses untrusted SSL certificates.

By checking the Client Report generated on the BIG-IP APM Edge Client 7.2.4.2 or higher, you can find the current registry key is 0x0:

HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\F5 Networks\RemoteAccess AskAboutUntrustedSSLCert  REG_DWORD  0x0

 

Environment

  • BIG-IP APM Virtual Server using untrusted SSL certificates
  • Upgrade to BIG-IP APM Edge Client for Windows from version 7.2.4.1 to 7.2.4.2 or higher.
  • You implemented the K000133271  on BIG-IP APM Edge Client 7.2.4.1 on Windows before the upgrade.

 

Cause

  • Bug ID 1324741

 

Recommended Actions

To workaround this bug, you may choose either one of the three options.


Option 1:
Upgrade Edge Client to fixed versions (v7245 and later)


Option 2:
The current workaround is that, after you have upgraded the BIG-IP APM Edge Client to 7.2.4.2 or higher, you need to change the below registration value from the current 0x0 to 0x1:

HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\F5 Networks\RemoteAccess AskAboutUntrustedSSLCert  REG_DWORD  0x1

Option 3:
You can remove your current version of BIG-IP APM Edge Client 7.2.4.1 by following K8253, then perform a fresh installation of the BIG-IP APM Edge Client version 7.2.4.2 or higher by following K13710, and finally update the syntax by following K000133271 to the upgraded BIG-IP APM Edge Client.



Additional Information
