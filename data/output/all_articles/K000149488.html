Description

Can I change offbox IP address in analytics global-settings section in bigip.conf configuration file.

Environment

  • BIG-IQ with self-ip for discovery and data collection.

Cause

None

Recommended Actions

You cannot change the discovery IP address of a running BIG-IQ DCD, you need to remove the DCD and configure it to use the new discovery IP address and then add it back to the CM.

Note:

If you only have one DCD this will cause data to be lost so you should do a snapshot or add an additional DCD first.
