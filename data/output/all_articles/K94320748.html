K94320748: Radius authentication fails (shared secret is not correct)

Description

  • Radius authentication fails even though shared secret was configured to match
  • If Radius server replies with "Access-Challenge" packet, error in /var/log/apm similar to the one below:
     bigip err apd[6431]: 01490108:3: adfccfb1: RADIUS module: authentication with 'john.smith' failed: packet verification failed, most likely the shared secret is not correct (-1)

Environment

  • APM
  • v11.6.x and v12.1.x
  • APM VPE item "RADIUS Auth" used for authentication
  • Configuration Utility (WebUI/GUI) is used to configure Radius AAA object

Cause

The shared secret starts with a "!" character and the BIG-IP is not handling this correctly by the Configuration Utility.

Recommended Actions

  • Use a shared secret with a different first character
    or
  • Use TMSH to configure/modify shared secret, for example to change the shared secret to "!testing"
      tmsh
      modify apm aaa radius <Radius_AAA_instance> { secret !testing }
      modify apm profile access <name_of_access_profile> generation-action increment

Additional Information

F5 Product Development has assigned ID 553023 to this issue.
v13.1.x and above are not affected.
