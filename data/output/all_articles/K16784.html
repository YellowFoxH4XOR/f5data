Known Issue

Portal JavaScript rewrite may fail to declare a local variable.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a Portal Access access profile.
  • The application accessed through the Portal Access uses JavaScript.
  • The JavaScript local variable "r" is declared in the code returned by the application.

Impact

The application content does not render correctly.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • JavaScript content produces an error or is not displayed correctly.
