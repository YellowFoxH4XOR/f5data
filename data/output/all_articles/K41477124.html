Description
Any of the GTM pool member monitor set to none will result in big3d timeout. Pool members were unable to respond to the DNS queries from the clients, As a result of these the services will be impacted.
 

Environment

  • BigIP DNS
  • BigIP LTM
  • DNS Pool

Cause
This issue is caused due to the monitor type set to "none" under the GTM pool member.

Recommended Actions

Set the monitor type to either "Select monitors" (or) "Inherit from pool" under the GTM pool member to resolve the issue.

  1. Navigate to DNS>>GSLB>>Pools>>Pool List>>members:<select the desired pool member>
  2. Under Health Monitors select the drop-down, and change it to "Select monitors" (or) "Inherit from pool" option depending on your configuration.
