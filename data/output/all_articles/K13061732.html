Description
Network Access resources can be configured to use split tunneling to reduce the amount of traffic sent over the VPN tunnel.  Some customers prefer to have Internet accessible SaaS resources like Microsoft Office 365 traffic egress a client's local interface instead of the corporate network via the VPN tunnel. However, some SaaS providers have an extensive list of endpoints and update them occasionally, adding administrative overhead to manage the solution. 

Environment

  • BIG-IP APM 
    • Access profile that assigns a Network Access resource with Split tunneling enabled
    • Allow Local DNS is enabled in the Network Access resource
  • DNS Relay Proxy installed on Microsoft Windows clients

Cause
Microsoft Office 365 endpoints are occasionally changed requiring modification to the split tunnel configuration. 

Recommended Actions

F5 Professional Services has published a scripted solution to update Network Access Address lists using iCall: SSL VPN Split Tunneling and Office 365

Additional Information
There are other Office 365 applications that you may also find yourself wanting to review for similar behavior.  For example:
K91493443: Network Access - Microsoft Teams application not honoring split tunneling exclusion address space

In addition, Microsoft offers a list of Office 365 URLs and IP address ranges.
