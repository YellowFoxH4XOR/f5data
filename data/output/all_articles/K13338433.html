Known Issue

When a Secure Sockets Layer (SSL) server sends an untrusted certificate to the server-side BIG-IP profile, the Traffic Management Microkernel (TMM) may produce a core file.

This issue occurs when all of the following conditions are met:

  • A Server SSL profile is attached to a virtual server.
  • The SSL server sends an untrusted certificate to the BIG-IP system.

Impact

Traffic is disrupted while the TMM process produces a core file and restarts. Systems configured as part of a high availability (HA) device group may fail over to a peer device.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The TMM process generates a core file to the /shared/core directory.
  • The BIG-IP system generates a SIGSEGV fault message in the /var/log/tmm log file.
