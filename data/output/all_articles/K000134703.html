Description

When upgrading the Edge Client, you would want to check what modules are currently included in the installer package to ensure that you select the same modules for the new Edge Client installer package.

 

 

Environment

  • BIG-IP APM
  • Edge Client Upgrades

 

 

Cause

n/a

 

Recommended Actions

  1. Download and run the CTU (Client Troubleshooting Utility) as described in article K12444
  2. Upon running the CTU, you will be presented with a screen showing all the components that can be installed for the Edge Client, and a green checkmark indicates that its installed and working.
  3. The image shows the relationship between the options available in the customizable installer package and what you currently have installed.
