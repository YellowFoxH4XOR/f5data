Known Issue

This is the result of a known issue. The ARX system may prematurely report a snapshot as completed. As a result, attempting to view the snapshot immediately after creation will fail.

F5 Product Development tracked this issue as ID 37904 and it was fixed in ARX versions 5.1.7 and 5.2.0. For information about upgrading, refer to the ARX release notes.

Additionally, this issue was fixed in a hotfix release for ARX versions 5.0.6 and 5.1.5. Customers affected by this issue can request the hotfix from F5 Technical Support, referencing this Solution number and ID number.
