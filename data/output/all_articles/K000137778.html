Description

You observe similar request examined by ASM
  
GET /sample/url HTTP/1.1
Accept-Encoding:
Host: sample.com
Connection: keep-alive
  • The request is examined by ASM and contains headers with empty value
  • Request is not blocked by ASM

Environment

  • ASM provisioned
  • Security policy enabled on virtual server in Blocking Mode
  • Attack signatures enforced 
  • Header name with no header value violation set to enabled in Learning and Blocking settings

Cause

According to RFC7231 Accept-Encoding header with no header value is RFC compliant.
https://datatracker.ietf.org/doc/html/rfc7231#section-5.3.4

Recommended Actions

This is expected behavior.
