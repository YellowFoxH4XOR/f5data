Known Issue

Description

Using the copy nfs or copy cifs commands to copy a release file from a namespace to the ARX system fails.

This issue occurs when one of the following conditions are met:

  • The copy nfs command is used to copy a release file from an NFS managed volume.
  • The copy cifs command is used to copy a release file from a CIFS managed volume.

Impact

The release file is not copied to the ARX system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The copy command fails with an error message that appears similar to the following example:

    # copy cifs namespace1 /volume1 12345.rel releases 12345.rel
        % ERROR: FILE_COPY_SRC_NOT_REL (40960079):
         The source file '12345.rel' must have a '.rel' extension.

Workaround

To work around this issue, you can copy the release file to the ARX system using an alternate copy method such as FTP, SCP, or TFTP. For information about the copy ftp, copy scp or copy tftp commands, refer to the ARX CLI Reference Guide.

Impact of workaround: None
