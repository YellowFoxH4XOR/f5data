Topic

You can use this fully supported iApp template for configuring the BIG-IP system to provide additional security, performance, and availability for Microsoft Exchange 2016 Mailbox servers.

Note: F5 will soon replace this iApp template with F5 Application Services Templates (FAST). For more information about the deprecation plan, refer to K13422: F5-supported and F5-contributed iApp templates.

Description

When you configure the BIG-IP system using an iApp template, or manually, the system performs as a reverse proxy for Microsoft Exchange 2016 Mailbox servers, and also performs functions such as Secure Sockets Layer (SSL) offload, load balancing, compression, encryption, caching, and pre-authentication.

When used with BIG-IP APM, this iApp template supports proxy authentication and secure remote access for all Client Access Server HTTP-based protocols without requiring a Virtual Private Network (VPN) client. This iApp template supports running BIG-IP APM on the same system as BIG-IP LTM, or using BIG-IP APM to forward traffic to BIG-IP LTM on a different system.

Additionally, you can use BIG-IP AFM, the F5 high-performance, stateful, full-proxy network firewall, to help secure and protect your Microsoft Exchange deployment.

For instructions to use this template and configure your Microsoft Exchange 2016 Mailbox server environment, refer to the Deploying F5 with Microsoft Exchange 2016 Mailbox Servers manual. F5 recommends that you review settings you have configured with a non-default value so as to minimize the risk of potential issues that may occur.

To download and install the iApp template, perform the following procedures:

  • Download the iApp template
  • Install the iApp template

Download the iApp template

Important: You must download the file; do not copy and paste the contents.

  1. Go to the F5 Downloads site.
  2. From the Downloads Overview page, select Find a Download.

    The Select a Product Line page displays.

  3. From the Product Line column, select iApp-Templates.
  4. Read the End User Software License Agreement and either accept the license by selecting I Accept, or cancel the process by selecting Cancel.

    If you accept the End User Software License Agreement, the Select a Download page appears, which shows a table with the file name, product description, and file size details.

    Note: After you accept the End User Software License Agreement, the system does not present the agreement again for subsequent downloads that you perform during the same browser session.

  5. From the Filename column of the table, select the file named iapps-x.x.x.x.x.zip. For example, the file for the July 2017 iApp release is named iapps-1.0.0.468.0.zip.

    The Select a Download Method page appears.

  6. F5 supports the FTP, HTTP, and HTTPS protocols for downloading files from F5. Select one of the three supported protocols listed by selecting the down arrow.

    A pop-up window appears, prompting you to either open or save the file.

    Note: Some browsers save the file to a default location. You can review your specific browser's documentation to change the default location of where you want to save files.

  7. Select the option to save the file.

Install the iApp template

  1. Unzip the zip file to a location accessible from your BIG-IP system.
  2. Log in to the Configuration utility.
  3. From the iApp tab, select Templates.
  4. Select Import.
  5. Select the Overwrite Existing Templates check box.
  6. Select Browse.
  7. Browse to the location where you saved the iApp file.
  8. Select the file that corresponds to the iApp version you want to install. For example, the file for the July 2017 release of this iApp is named f5.microsoft_exchange_2016.v1.0.2.tmpl.

    Note: To select the most current supported template for your BIG-IP software version, refer to the previous Support Matrix table.

  9. Select Upload.

When the upload completes, the iApp is available for use.
