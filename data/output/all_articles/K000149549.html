K000149549: How to upload TLS Certificate to the F5 XC?

Description

This article provides instruction on how to upload certificate into F5 Distributed Cloud.

 

Environment

  • F5® Distributed Cloud 
  • Distributed Cloud Web Application and API Protection (WAAP)
  • Certificate Management

Cause

None

 

Recommended Actions

  1. Go to Web Application and API Protection (WAAP)
  2. Scroll down to Certificate Management (on the left side)
  3. Select TLS certificates
  4. Click on 'Add TLS Certificate'

  5. Enter Name and click on 'Import from File'.
  6. Upload Certificate and the Key.
  7. Select existing or add new intermediate Certificate.
  8. Click on save and exit.

    Now certificate is uploaded and you can use it for your Load Balancer.

 

 

Additional Information

  • After uploading, the TLS certificate can be assigned to HTTP Load Balancers or other services requiring SSL/TLS termination within F5 Distributed Cloud.
  • Both the certificate and its corresponding private key must be provided during the upload process.
  • Intermediate certificates can be selected from existing entries or uploaded as new intermediates to ensure proper certificate chain validation.
