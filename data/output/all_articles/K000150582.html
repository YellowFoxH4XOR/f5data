K000150582: TMM returned error for crypto operation 'Signature element of SAML response is invalid'

Type
Support Solution
Published
2025-03-27
Updated
2026-05-26
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.0
Source
https://my.f5.com/manage/s/article/K000150582

Description

SAML not working and getting these errors:

 

Mar 25 15:47:22 BIG-IP.APM.com err apmd[1898]: 01490321:3: /Common/bigip-apm:Common:3b556834:/Common/bigip.apm_act_saml_auth_ag: TMM returned error for crypto operation 'Signature element of SAML response is invalid'

Mar 25 15:47:22 BIG-IP.APM.com debug apmd[1898]: 01490266:7: /Common/bigip-apm:Common:3b556834: modules/Authentication/Saml/SamlSPAgent.cpp: 'processAssertionResponseFromTmm()': 2348: OUT: err 94

 

Environment

  • BIG-IP APM
  • SAML

 

Cause

Bad configuration.
The SAML assertion was signed with a different certificate than the one configured in the IdP connector.

 

Recommended Actions

1) export metadata from azure

2) create the connector using option "From Metadata" and it will automatically add the cert from the metadata and assign it.

     Access ›› Federation : SAML Service Provider : External IdP Connectors >> Create connector

3) unbind the current IdP connector and bind the newly created IdP connector


Alternatively, the correct certificate can be obtained from the SAML assertion itself. This certificate can then be imported to the BIG-IP and used in the IdP connector.
