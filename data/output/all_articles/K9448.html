Topic

If the ZebOS daemon (zebosd) exits abnormally and its PID file is not removed, the zebosd process will not be able to start again until the old PID file is removed from the filesystem.

The primary symptom of this issue is the failure of the dynamic routing functions the zebosd process perfoms. Running bigstart status zebosd shows the process continuously restarting, and the BIG-IP log repeatedly displays messages indicating the zebosd process is restarting constantly.

This issue does not affect BIG-IP versions 9.4.4 and later.

To correct this issue, delete the stale PID file by running the following command from the BIG-IP command line:

# rm -f /var/run/zebosd.pid
