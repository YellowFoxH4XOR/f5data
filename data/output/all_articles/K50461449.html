K50461449: Obtained Auth Token can not be used by other hosts

Type
Support Solution
Published
2022-07-27
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K50461449

Description

Currently, there are two authentication methods supported: standard HTTP basic authentication and an F5 proprietary token scheme.

Prior to v15.1.5.1 Authentication Token obtained from a host, could be used to execute API calls by any other host.

This behaviour is changed together with the introduction of  a new db variable httpd.matchclient, which is set to true by default.


Environment


Token based authentication used for REST API calls.


Cause


A new db variable httpd.matchclient, which is set to true by default, will prevent token obtained from a host being used from another host.


Recommended Actions
 

If you want to use the token with API calls executed from different hosts :

# modify sys db httpd.matchclient value false
# save sys config
# list sys db httpd.matchclient
sys db httpd.matchclient {
    value "false"
}
# bigstart restart httpd

In order for the variable change to take affect, httpd must be restarted.
