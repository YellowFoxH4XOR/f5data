Topic

If the configuration synchronization (ConfigSync) process fails, it may still be possible to manually synchronize the configuration from one device to another. To do so, perform the following procedure:

  1. Log in to the BIG-IP command line on the source device.
  2. To create the configuration archive, type the following command:

    bigpipe config save $HOSTNAME-`date +%F`.ucs

    Note: This command creates a file in the /var/local/ucs directory. The file name is a combination of the host name and the current date.
  3. To transfer the configuration archive to the target device, use the following command syntax:

    scp /var/local/ucs/<filename>.ucs peer:/var/local/ucs/

    Note: Replace <filename> with the name of the file you created in step 2.
  4. Log in to the command line on the target device.
  5. To install the configuration archive, use the following command syntax:

    bigpipe config install /var/local/ucs/<filename>.ucs

    Note: Replace <filename> with the name of the file you created in step 2 and transferred in step 3.

Note: For more information, refer to K7024: Overview of the ConfigSync process (9.x - 10.x).

Note: For more information, refer to K3499: Backing up and restoring BIG-IP 9.x configuration files or K11318: Backing up and restoring BIG-IP configuration files (10.x).
