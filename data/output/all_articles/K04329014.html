Issue

Error Message

01670020:3: DNAT connection: <nat_mapping>

In this error message, note the following:

  • <nat_mapping> is the following carrier-grade network address translation (CGNAT) subscriber connection mapping information:
    • External address and port (the address and port visible to the destination server)
    • Destination address and port (the service accessed by the subscriber)
    • Time

For example:

01670020:3: DNAT connection: dnat: start=1505119951 end=1505229950 remote_port=123 local=192.168.10.1,34567 proto=6 client=10.10.10.1

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following conditions are met:

  • The network address translation (NAT) source translation setting for a Large Scale NAT (LSN) pool is set to Deterministic mode.
  • The LSN pool configuration is changed with active subscriber flows.

This logging information is used by the Deterministic NAT (DNAT) utility (dnatutil) to identify subscribers using a calculation of reverse source address and port mapping of deterministic-mode LSN pools.

Impact

There is no impact; this message is informational.
