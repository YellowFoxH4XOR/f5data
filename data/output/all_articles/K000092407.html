Description

Kerberos Authentication fails with an errror:

GSS-API error gss_accept_sec_context: 70000 : No credentials were supplied, or the credentials were unavailable or inaccessible

GSS-API error gss_accept_sec_context: 0 : Unknown error


Performing the article https://support.f5.com/csp/article/K52921535 doesn't help.


 Environment

  • BIG-IP APM
  • Multiple Kerberos AAA servers
  • Multiple keytab files
  • Multiple service accounts in the same auth realm


 Cause

Wrong keytab file imported to the BIG-IP.

 Recommended Actions

If you have more than one Kerberos AAA Server in the same auth realm, ensure you have the service account for the one in use. Create the keytab file from the service account in use in you APM Policy.
