Topic

The Connection Limit setting for pool member and/or node objects specifies the maximum number of concurrent connections allowed for the pool member or node. The BIG-IP system sends a TCP RST packet in response to a connection attempt when a pool member or node connection limit is reached, and there are no alternate members available in the pool. When the connection limit is reached for a pool member or node, the device's status changes to Unavailable.

Note: For more information about why the BIG-IP LTM system sends TCP RST packets, refer to K9812: Overview of BIG-IP TCP RST behavior.

Note: Beginning in BIG-IP 11.0.0, F5 added the TCP Request Queuing in Pools feature to the product, which enables you to queue connection requests that exceed the capacity of connections per pool, pool member, or node, as determined by the connection limit. Consequently, instead of dropping connection requests that exceed the connection limit, TCP Request Queuing enables those connection requests to reside within a queue in accordance with defined conditions until capacity becomes available. For more information, refer to the Preventing TCP Connection Requests From Being Dropped chapter of the BIG-IP Local Traffic Manager: Implementations manual. For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Description

Defining pool member connection limits

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Pools.
  3. Click the pool for which you want to define the connection limit.
  4. Click the Members tab.
  5. Click the pool member for which you want to define the connection limit.
  6. Enter the maximum number of concurrent connections that the pool member can accept in the Connection Limit box.
  7. Click Update.

Defining node connection limits

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Nodes.
  3. Click the node for which you want to define the connection limit.
  4. Enter the maximum number of concurrent connections that the node can accept in the Connection Limit box.
  5. Click Update.
