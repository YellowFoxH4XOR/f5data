Description

You want to set up multiple LDAP servers for BIG-IP device remote authentication and manage their priority.  

Environment

  • Multiple LDAP servers
  • Device remote authentication
  • BIG-IP
  • GUI
  • TMSH

Cause

This GUI functionality was available in versions 13 or before but has removed this capability for BIG-IP versions 14 and later.

Recommended Actions

This function is still valid on TMSH from BIG-IP versions 14 or later, for details you can read the TMSH manual here on the F5 Cloud Docs.

To replace all existing LDAP servers with a new set: 

# tmsh modify auth ldap system-auth system-auth servers replace-all-with { <LDAP_SERVER_IP> | <Server FQDN> ...} 

The following references show the items configured on the LDAP servers in your environment:

  • <LDAP_SERVER_IP> | <Server FQDN> is the IP address or FQDN of the LDAP server(s) that the BIG-IP system must use to obtain authentication information. To add more than one entry, use a space to separate the multiple IP addresses or FQDN entries. 

Note: There is a default priority for the configured LDAP servers, the first server in the list is always picked first, followed by the second server if the first is not available.

For example, you can add two LDAP servers from the commands below:

  • For the LDAP servers in IP: # tmsh modify auth ldap system-auth system-auth servers replace-all-with { 192.168.1.1 192.168.1.2 } 
  • For the LDAP servers in FQDN: # tmsh modify auth ldap system-auth system-auth servers replace-all-with { test1.com test2.com } 

Additional Information

You can also configure the BIG-IP APM to manage the multiple LDAP servers, for details you can refer to the following article: K11199: Creating an HA LDAP authentication configuration
