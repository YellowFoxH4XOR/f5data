Description

If a security policy is exported as JSON Format with Include Learning Suggestions, some settings of the policy may be changed due to import.

Environment

  • BIG-IP ASM/Advanced WAF
  • Export/Import Security Policy
  • JSON Format
  • Learning Suggestions

Cause

This is by design.

If you select Include Learning Suggestions for either export option, the learning suggestions will be considered as Accepted when the policy is imported, even if they are not accepted in the original policy before Export.
If a security policy has learning suggestions, you will see Include Learning Suggestions option when exporting the policy.
The learning suggestions will be applied to the security policy when using Include Learning Suggestions.

Recommended Actions

None
