Description

The following procedure provides the steps to decrypt traffic of the Configuration utility (GUI) of an F5OS-A (rSeries).

Environment

F5OS-A

Configuration Utility (GUI)

Cause

You would like to capture and decrypt Configuration utility network level packets to troubleshoot connection and/or performance issues.

Recommended Actions

1. Login to the admin cli of the F5OS-A host.

2. Print the configured cipher suite used by the Configuration utility. 

  show system security services service httpd

 

Important. Be sure to note the configured cipher suite as this will be modified by a subsequent procedure. 

 

3. To modify the cipher suite to use the AES128-SHA cipher suite use the following command syntax:

 

  #config

  (config)# system security services service httpd config ssl-ciphersuite AES128-SHA   

 

4. To apply the configuration change to the Configuration utility (GUI), save the configuration and restart the http service:

  (config-service-httpd)# commit and-quit                             

The following warnings were generated:

 'system security services service httpd config ssl-ciphersuite': Configuring HTTP ciphersuite will restart the HTTP service.

Proceed? [yes,no] yes

Commit complete.

 

5. Logout of any active Configuration utility (GUI) sessions.

 

6. Logon to the command line as root of the F5OS-A Host and start the tcpdump using the following command syntax. 

  tcpdump -vnni mgmt0-system -s0 port 443 -w <capture file name>

Note: Replace <capture file name> with the desired name for the tcpdump capture. For instance, running command below will create a capture_file.pcap under /var/F5/system/shared/tcpdump/ directory

 tcpdump -vnni mgmt0-system -s0 port 443 -w /var/F5/system/shared/tcpdump/capture_file.pcap 

 

7. To stop the tcpdump packet capture enter the following command syntax:

Ctrl-C

 

8. To revert the cipher suite change of the Configuration utility to the original cipher suite (as noted in procedure step 2), log back in as admin again use the following command syntax:

 

# config

(config)# system security services service httpd config ssl-ciphersuite <original cipher suite> 

 

9. save the configuration and restart the http service:

(config-service-httpd)# commit and-quit

The following warnings were generated:

 'system security services service httpd config ssl-ciphersuite': Configuring HTTP ciphersuite will restart the HTTP service.

Proceed? [yes,no] yes

Commit complete.

 

10. To decrypt the packet capture you will need the f5os.key file.

  • If you are using a manually-configured server cert/key, grab the key from /etc/auth-config/certs/f5os.key
  • If you are not using a custom key, grab the automatically-generated one from /var/system/httpd/ssl/f5os.key

11. Use the grabbed f5os.key to decrypt by either:

a. Creating a Pre-Mastered Secret (pms) file. Copy the capture and the key files to another linux system and run command like:

  ssldump -n -k <ssl key> -r <tcpdump capture file> -M <pre-mastered secret file name> 

Note: Replace <tcpdump capture file> with the tcpdump capture file name used in the procedure step #6, and replace <pre-mastered secret file name> with the desired PMS file name.

Example: 

 ssldump -n -k f5os.key -r capture_file.pcap -M /shared/tmp/capture_file.pms

b. Using wireshark:

  K19310681: Decrypting SSL/TLS traffic using Wireshark and private keys
