Description

  • User observer DNS response from zonerunner without "Answer" flag
  • User configured Bind directly


# dig @10.128.10.56 ns1.minion.guru.com


; <<>> DiG 9.11.4-P2-RedHat-9.11.4-9.P2.el7 <<>> @10.128.10.56 ns1.minion.guru.com

; (1 server found)

;; global options: +cmd

;; Got answer:

;; ->>HEADER<<- opcode: QUERY, status: NOERROR, id: 51901

;; flags: qr rd; QUERY: 1, ANSWER: 0, AUTHORITY: 1, ADDITIONAL: 3

;; WARNING: recursion requested but not available


;; OPT PSEUDOSECTION:

; EDNS: version: 0, flags:; udp: 4096

;; QUESTION SECTION:

;ns1.minion.guru.com. IN A


;; AUTHORITY SECTION:

ns1.minion.guru.com. 69 IN NS ns1.minion.guru.com.


;; ADDITIONAL SECTION:

ns1.minion.guru.com. 69 IN A 192.168.1.1

ns1.minion.guru.com. 69 IN A 1.1.3.1


;; Query time: 1 msec

;; SERVER: 10.128.10.56#53(10.128.10.56)

;; WHEN: Fri May 12 10:15:49 +08 2023

;; MSG SIZE rcvd: 94



Environment

  • DNS
  • BIND


Cause

BIND zone file is mis-configured.


 Recommended Actions

  1. update zone file effected (please refer to guide in additional informationl)
