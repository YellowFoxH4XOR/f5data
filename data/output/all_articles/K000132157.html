K000132157: xdr33 malware infecting BIG-IP devices

Type
Support Solution
Published
2023-01-20
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000132157

Description

A blog published recently by third-party researchers (360Netlab) has documented an instance of a BIG-IP being compromised by an unnamed vulnerability in order to deliver malware, dubbed xdr33, onto the device.

Environment

  • BIG-IP (all modules)

Cause

The researchers have confirmed that the initial exploitation was via CVE-2022-1388, disclosed by F5 in May 2022 and fixed in 13.1.5, 14.1.4.6, 15.1.5.1, 16.1.2.2, 17.0.0 and later versions. (See the Security Advisory linked below for the full list of affected and fixed versions and other details)

Recommended Actions

We recommend customers run the most current applicable version of their F5 system to ensure known issues and vulnerabilities are addressed.
