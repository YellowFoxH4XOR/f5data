K000149404: Nginx App Protect does not support creating custom bot signatures

Type
Support Solution
Published
2025-01-21
Updated
2025-08-26
Source
https://my.f5.com/manage/s/article/K000149404

Description

  • Nginx App Protect does not support creating custom bot signatures
  • An error message will be displayed if a non-factory bot signature name is configured in the bot-defense > mitigations configuration block: "error_message": "Failed to import Policy 'ap_prd_waf_policy' from '/etc/app_protect/conf/ap_prd_waf_block.json': Could not add the Policy Bot Signature 'UNNAMED'. Failed on insert to PLC.PL_BOT_SIGNATURES (DBD::SQLite::db do failed: NOT NULL constraint failed: PL_BOT_SIGNATURES.bot_signature_id)"

Environment

Modifying the Nginx App Protect policy bot-signature section using a custom bot-signature name.

    "bot-defense": {
      "settings": {
        "isEnabled": true
      },
      "mitigations": {
        "signatures": [
          {
            "name": "zgrab",
            "action": "block"
          },
          {
            "name": "mycustombot",  <----- 
            "action": "block"  <-----
          },

Cause

Nginx App Protect does not support creating custom bot signatures.

A list of valid, built-in, bot signatures name can be found at /opt/app-protect/var/update_files/bot_signatures/included_bot_signatures.

The error message is not clear, this is being tracked via bug ID 12200.

Recommended Actions

Create a custom browser defined via User-Defined Browser Control Enforcement

Example:

1. Create your user defined browser in the "browser-definitions" section, can be near the top of the policy:

  • Detect (allow) all browsers except for browsers with action set to block in browsers section.
  • Alarm if no browser was detected.
{
  "policy": {
    "name": "ap_prd_waf_policy",
    "template": {
        "name": "POLICY_TEMPLATE_NGINX_BASE"
       },
    "browser-definitions": [
            {
                "name": "mycustombot",
                "matchString": "mycustombot"
            }
    ],
    "applicationLanguage": "utf-8",
    "enforcementMode": "blocking",

2. Configure the browser blocking behavior:

    "bot-defense": {
      "settings": {
        "isEnabled": true
      },
      "mitigations": {
        "classes": [
          {
            "name": "browser",
            "action": "detect"
          },
          {
             "name": "unknown",
             "action": "alarm"
          }
        ],
        "browsers": [
          {
            "name": "mycustombot",
            "action": "block"
          }
        ],
        "signatures": [
          {
            "name": "zgrab",
            "action": "block"
          },

Additional Information
Bot Signatures Update File

Bot Signatures Update File
Starting with NGINX App Protect WAF release 4.7, the bot signature file included_bot_signatures, is located at the following path: /opt/app-protect/var/update_files/bot_signatures/included_bot_signatures. This will be part of the app-protect-bot-signatures package.

This file contains an up-to-date list of all bot signatures that have been updated with the new bot signature package. This list is automatically generated as a part of the app-protect-bot-signatures package and follows a format similar to the README-style text file found in the attack signature. This file contains essential information which includes:

Bot name
Bot type
Bot classification/catego

User-Defined Browser Control

User-Defined Signatures

Override Rules
