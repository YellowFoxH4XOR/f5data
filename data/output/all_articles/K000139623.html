K000139623: AGC: Not able to deploy: Unable to process request/tm/sys/provision/apm Service is unavailable

Type
Support Solution
Published
2025-08-28
Updated
2025-08-28
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000139623

Description

When navigating to the following GUI menus, 

Access ›› Guided Configuration

Select the Deployment

Click Deploy

 

You may see the following error message  "Unable to process request/tm/sys/provision/apm. Service is unavailable." .

 

On the iApp blocks for the deployment, you will see the below error.

ERROR : Error reading provision response: Unable to process request /tm/sys/provision/apm. Service is unavailable.

Environment

  • BIG-IP APM

Cause

For some unknown reason AGC is unable to read the provision correctly.

Recommended Actions

Perform mcpd forceload to correct the provision error.

K13030: Forcing the mcpd process to reload the BIG-IP configuration

 

Additional Information

None
