K000092340: File upload issue when using Nginx Ingress Controller, error:- client intended to send too large body: <content-size> bytes, client: <IP address>, server: app1.example.com,

Type
Support Solution
Published
2022-08-25
Updated

Source

Description

  • You have successfully deployed Nginx Ingress Controller 
  • And have successfully proxying your applications traffic through the ingress Controller
  • However, users are unable to upload files greater than the default one megabyte client request body size. 
  • And the controller logs error like below in /var/log/nginx/error.log file
[error] 1020#1020: *127198 client intended to send too large body: <content-size> bytes, client: 192.168.1.10, server: app1.example.com, request: "POST /my-document/to-files HTTP/1.1", host: "app1.example.com"

 Environment

  • Nginx Ingress Controller
  • Ingress resource
  • Nginx Plus

 Cause

  • File upload exceeded the maximum allowed default client request body size

 Recommended Actions

  • You can increase client request body size using "client_max_body_size" directives
  • At either http context using configmap, which is a global event and affects all configuration as shown below
  • This solution is the least preferred as it affects all config and should consider the alternatives below
apiVersion: v1
data:
  allow-snippet-annotations: "True"
  client-max-body-size: 100m
kind: ConfigMap
metadata:
  name: example-ingress-controller 
  namespace: default
  • You can be more specific through the use of annotation with Ingress resource.
  • As such, you can access the complete ingress example given below here
  • But before proceeding, please identify the exact affected ingress resource [host] which resulted in the above error message 
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: cafe-ingress-with-annotations
  annotations:
    nginx.org/proxy-connect-timeout: "30s"
    nginx.org/proxy-read-timeout: "20s"
    nginx.org/client-max-body-size: "100m"
  • Or if using VirtualServer, refer example here  

Example

apiVersion: k8s.nginx.org/v1
kind: VirtualServer
metadata:
  name: cafe-ingress-with-annotations
  namespace: default
spec:
  host: app1.example.com
  ingressClassName: nginx 
  routes:
  - action:
      pass: my-service
    path: /
  upstreams:
  - client-max-body-size: 500m
