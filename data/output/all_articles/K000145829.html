Description

After upgrading NGINX Plus and NGINX App Protect (NAP) then NGINX Plus fails to start. An error similar to the following is reported when testing NGINX Plus configuration:

{  
  "completed_successfully": false,  
  "event": "configuration_load_failure",  
  "error_message": "Policy Bundles \"/etc/nms/NginxDefaultPolicy.tgz\" version (10.447.0) is older than the local version (11.133.0)",  
  "error_line_number": 24,  
  "softwareVersion": "4.11.0",  
  "componentVersions": {    
    "wafEngineVersion": "11.133.0",
    "wafNginxVersion": "5.144.0"  
  }
}
nginx: configuration file /etc/nginx/nginx.conf test failed

Environment

NIM

NGINX Plus

NAP

Cause

NIM NAP compiled policy, e.g. /etc/nms/NginxDefaultPolicy.tgz, does not match version of NAP installed on the NGINX Plus instance

Recommended Actions

On the NGINX Plus instance ensure NAP is started:

sudo systemctl restart nginx-app-protect.service

sudo systemctl status nginx-app-protect.service

 

On NIM:

  • Install the NAP compiler that is compatible with the version of NAP running on the NGINX Plus instance. See the NIM NAP Compiler documentation for assistance. For example, in the example above the NAP version, indicated by "softwareVersion", is 4.11.0, which correlates to NIM NAP Compiler version nms-nap-compiler-v5.144.0.

sudo apt-get install nms-nap-compiler-v5.144.0 -o Dpkg::Options::="--force-overwrite"

  • Edit the configuration of NGINX Plus instance and Publish the existing configuration. This should trigger NIM to create a new compiled version of the NAP policy or policies and replace the existing, older compiled versions of the NAP policy or policies on the NGINX Plus instance.

If the above procedures do not resolve the issue, then do the following:

On NGINX Plus instance:

  • Stop NGINX Agent: sudo systemctl stop nginx-agent.service
  • Edit all NGINX Plus configuration that implements NAP
  • Comment out 
    app_protect_enable on;
    i.e. 
    #app_protect_enable on;
  • Restart NGINX Plus: sudo systemctl restart nginx.service
  • Restart NGINX Agent: sudo systemctl stop nginx-agent.service

On NIM:

  • Edit the configuration of the NGINX Instance in question
  • Enable NAP by uncommenting 
    #app_protect_enable on;
    i.e. 
    app_protect_enable on;
  • Publish the configuration
