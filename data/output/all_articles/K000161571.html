K000161571: AFM Event Log Action field reference for "Established" and "Closed"

Description

You may notice the Established and Closed log entries from AFM event logs.

Environment

  • AFM logging profile

Cause

The Established and Closed entries in the AFM Event Log Action field are generated when the Log TCP Events option is enabled in the AFM logging profile.

These entries represent TCP session events:

  • Established indicates a TCP session has been opened.
  • Closed indicates the session has been closed.

security log profile global-network {
    built-in enabled
    description "Default logging profile for network events"
    network {
        global-network {
            filter {
                log-acl-match-accept enabled
                log-acl-match-drop enabled
                log-acl-match-reject enabled
                log-tcp-events enabled ---> !!!!!
            }
            publisher local-db-publisher
        }
    }

Recommended Actions

To log TCP session events (Established and Closed), ensure the Log TCP Events option is enabled in the AFM logging profile.
