K01481205: RDP fails with ''The connection cannot proceed because authentication is not enabled and the remote computer requires that authentication be enabled to connect'' error message

Description

RDP connections through the BIG-IP APM fail and the below error message is displayed on the user's computer:
The connection cannot proceed because authentication is not enabled and the remote computer requires that authentication be enabled to connect

Environment

  • BIG-IP APM running 13.x or earlier version
  • Remote Desktop resource on the APM configured as either ActiveX or Java RDP
  • RDP resource is either Windows 10 or Windows Server 2016

Cause

The issue is due to Microsoft changing RDP’s default setting for “SecurityLayer” from 0 to 2, in Windows 10 and Windows Server 2016.

Recommended Actions

There are two ways to fix this:

  1. If you are running 12.x or earlier, upgrade your BIG-IP APM to version 13.x or later and use Native RDP instead of ActiveX or Java.
  2. If you are running version 13.x or later, change type of your RDP object to Native RDP. Native RDP does not have this issue.
