Description

The number of Occurrences is much greater than the Requests Count for a learning suggestion.

What is the reason for this?

Environment

  • Learning suggestions

Cause

None

Recommended Actions

None

Additional Information

The occurrence count is the number of times a given violation occurred, triggering the suggestion. It is possible to have a violation occur multiple times in a single request (for example, attack signature or meta character violations), so it can be normal for the occurrences count to be higher than the overall requests count. This is not cause for concern.
