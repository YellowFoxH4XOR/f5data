Known Issue

Email alerts that are generated by SNMP traps may not include all the information specified by the alert definition.

This issue occurs when all of the following conditions are met:

  • Alert definitions in the /etc/alertd/alert.conf file are configured to generate email.
  • The alert definition contains data in the value of the body variable.

Alert definitions in the /etc/alertd/alert.conf file that are configured to send email appear similar to the following example:

alert BIGIP_MCPD_MCPDERR_POOL_MEMBER_MON_STATUS_UP {
snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.11";
email toaddress="demo@askf5.com"
fromaddress="root"
body="The test of this Solution worked!"
}

In the case of the previous example definition, the value The test of this Solution worked! is affected by the issue.

Impact

SNMP trap alert emails may contain a blank message body.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • SNMP trap alert emails may contain a blank message body.
