Description

While deploying an application by adding web acceleration profile to a VS with SSL profile (with PorxySSL enabled) then you get this error message:

  • Configuration error: Proxy SSL is not compatible with Web Acceleration profile on Virtual Server
  • on versions prior to 14.0.0  F5 is serving cached files to the client 

Environment

  • Web Acceleration Profiles
  • Proxy SSL

Cause

ID985401

Recommended Actions

Avoid using ProxySSL virtual servers with web acceleration (ramcache) profiles attached.

None
