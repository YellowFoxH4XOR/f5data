Topic

Starting in FirePass version 6.0.0, the FirePass standalone VPN client uses a new logon mechanism which supports pre-logon checks and post-logon actions. If you prefer to use the legacy logon mechanism, also called Legacy Mode, you can enable it using the procedure below. However, pre-logon checks and post-logon actions are not supported for Legacy Mode.

Note: For more information, refer to K6955: The Use Legacy Logon Prompt setting of the standalone VPN Client is not compatible with pre-logon checks and post-logon actions.

Enabling and Disabling Legacy Mode

To enable or disable Legacy Mode in the FirePass standalone VPN client, perform the following procedure:

  1. Start the FirePass standalone VPN client.
  2. Click the Settings button.
  3. Click Session Settings.
  4. Perform one of the following two actions:

    • To disable Legacy Mode, clear the Use Legacy Logon Prompt check box, which enables support for pre-logon checks and post-logon actions.
    • To enable Legacy Mode, select the Use Legacy Logon Prompt check box, which disables support for pre-logon checks and post-logon actions.
  5. Click the OK button.

Note: The Use Legacy Logon Prompt setting is a configurable option for the FirePass standalone VPN client installer package. You can pre-set this setting for users by selecting or clearing the Use Legacy Logon Prompt check box on the Device Management : Client Downloads : Windows (x86) page under the Customize Client Components tab.
