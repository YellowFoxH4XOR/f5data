Known Issue

This is the result of a known issue. If a user connects to the FirePass controller using Internet Explorer (IE), and then launches a Network Access connection, the FirePass client-side component clears the Include all sites that bypass the proxy server check box in the IE Local intranet zone.

F5 Networks Product Development tracked this issue as CR76237 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.
 
Additionally, this issue was fixed in cumulative hotfix HF-601-6 issued for FirePass version 6.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads page.
 
For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.
 
For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
