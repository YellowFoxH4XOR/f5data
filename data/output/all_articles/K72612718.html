Description

You observe messages similar to the following in /var/log/restjavad.0.log:

[WARNING][425709][10 May 2022 08:50:04 UTC][DieOnUncaughtErrorHandler] Continuing after uncaught Exception. Thread id 501209, 'Lucene Merge Thread #103141': org.apache.lucene.index.CorruptIndexException: checksum failed (hardware problem?) : expected=3d203ccd actual=20756a28 (resource=BufferedChecksumIndexInput(NIOFSIndexInput(path="/var/config/rest/storage/_2acq.fdt")))

The actual file path will vary.

Environment

  • BIG-IP

Cause

Unknown. This happens rarely.

Recommended Actions

The REST storage file is corrupted. You can rectify the issue with the following procedure.

Impact of Procedure: It is safe to run it on the active device. It will not impact traffic. Only restnoded & restjavad will be temporarily unavailable.

  1. Login to the BIG-IP CLI via SSH
     
  2. Run the command:
    # clear-rest-storage

    This command will take care to stop related services (restnoded & restjavad) and start them after storage is cleared.
