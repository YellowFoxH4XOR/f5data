K43855900: RTSP traffic is not forwarded by BIGIP when applying HTTP profile on the virtual server

Type
Support Solution
Published
2021-12-20
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP PEM: 14.1.2
Source
https://my.f5.com/manage/s/article/K43855900

Description
The RTSP traffic is not forwarded by BIGIP when applying HTTP profile on the virtual server

Environment

  • RTSP
  • HTTP profile.  

Cause
BIGIP is able to forward OPTIONS method for RTSP, however, other methods are unable to forward

RTPS headers:
OPTIONS, DESCRIBE, SETUP, TEARDOWN, PLAY, PAUSE, RECORD, ANNOUNCE, TEARDOWN, GET_PARAMETER, SET_PARAMETER, REDIRECT, Embedded (Interleaved) Binary Data

The OPTIONS method can be forwarded by BIG-IP because the HTTP method and RTSP method are in the same packet structure like below for the OPTIONS, however, other methods cannot be read using HTTP profile since it's not the same protocol.

Recommended Actions

You could consider one of the following recommended actions
  1. Remove HTTP profile from the virtual server
  2. Add Known Methods on HTTP profile.
