Description

When attempting to attach the client ssl profile to a virtual server in WebUI system reports errors to /var/log/ltm:
 

crit tmm[10545]: 01260030:2: Profile <profile_name> - cannot load key/cert/chain: /config/filestore/files_d/Common_d/certificate_key_d/<name_of_key>//config/filestore/files_d/Common_d/certificate_d/<name_of_certificate>//config/filestore/files_d/Common_d/certificate_d/<name_of_certificate_chain: Not found.
 

When affected SSL profile is attached to VIP processing data-plane traffic following log entry is reported to /var/log/ltm:

warning tmm3[25848]: 01260009:4: <client_ip>:<port> -> <vip_ip>:<port>: Connection error: hud_ssl_handler:1311: alert(40) invalid profile unknown on VIP <vip_name>

 

Environment

BIG-IP
SSL Virtual Server configured with affected SSL profile.

 

Cause

Issue appears similar to: Bug ID 1110485 (f5.com)

 

Recommended Actions

Please follow workaround section from bugtracker article.

In case if issue is still present - please verify if certificate and key referenced in error are not corrupted by following steps from article: Verifying SSL certificate and key pairs from the command line (11.x - 16.x) (f5.com)

In case if no certificate/key corruption is found - please proceed with Forcing the mcpd process to reload the BIG-IP configuration (f5.com) to fix the issue.
