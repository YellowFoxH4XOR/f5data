K000151109: Applying NGINX Instance Manager JWT license fails

Type
Support Solution
Published
2025-04-30
Updated
2025-07-18
Applies to
  • NGINX Products
  • NGINX Instance Manager: 2.18.X, 2.19.0, 2.18.0, 2.19.X, 2.19.1
Source
https://my.f5.com/manage/s/article/K000151109

Description

Attempting to apply JWT license fails. The following errors may occur.

  • UI error:
failed to register token. already registered

or

upstream unavailable
  • Error messages from NIM logs (/var/log/nms/nms.log):
(date) (nim_host_name) <COR>[8826]: (date) ERROR 2ed932f9-260e-4b2d-ab71-71cb1e6b65db errors/http.go:76 http failure with code '20048': secrets not found
(date) (nim_host_name) <INT>[8801]: (date) ERROR nms-integrations telemetry/controller.go:420 invalid response from telemetry registration api. 401 Unauthorized, {"errors":["Registration failed"]}

Environment

NGINX Instance Manager

Cause

The license database is in a failed state

Recommended Actions

The following commands will reset the license database and may resolve the issue

sudo rm -rf /var/lib/nms/dqlite/license
sudo rm -rf /var/lib/nms/secrets/secret/secureString/dataEncryptionKey /var/lib/nms/secrets/secret/secureString/certificateChain /var/lib/nms/secrets/secret/secureString/certs \
/var/lib/nms/secrets/secret/secureString/csr /var/lib/nms/secrets/secret/secureString/customId /var/lib/nms/secrets/secret/secureString/dataEncryptionKey \
/var/lib/nms/secrets/secret/secureString/LicenseKey /var/lib/nms/secrets/secret/secureString/privateKey
sudo find /var/lib/nms/secrets/secret/secureString -type f -name 'previous*' -delete
sudo find /var/lib/nms/secrets/secret/secureString -type f -name 'digital*' -delete
sudo /etc/nms/scripts/dqlite-client sql query -s "DELETE FROM secrets WHERE (file LIKE '%dataEncryptionKey') OR (file LIKE '%digital%') 
OR (file LIKE '%csr') OR (file LIKE '%customId') OR (file LIKE '%privateKey') OR (file LIKE '%certs') OR (file LIKE '%certificateChain') 
OR (file LIKE '%previous%') OR (file LIKE '%LicenseKey')" --db-name core
sudo systemctl restart nms
