K000092999: Re-assigning blade between Partitions will remove tenants from previous Partition

Type
Support Solution
Published
2022-12-06
Updated
2025-04-28
Source
https://my.f5.com/manage/s/article/K000092999

Description

Re-assigning blades between Partitions will not preserve the tenants running on the blades. Once the blade is removed from the Partition, all tenants running on the blade will be removed.

Environment

  • F5OS-C
  • VELOS
  • Migrating blades between Partitions

Cause

None

Recommended Actions

If needed, you can save a copy of the BIG-IP tenant configuration using the steps from K13132: Backing up and restoring BIG-IP configuration files with a UCS archive

  • Manual Chapter: Migrating a Blade from One Chassis Partition to Another
