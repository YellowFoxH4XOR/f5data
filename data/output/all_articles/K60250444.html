Known Issue

BIG-IP PEM deletes an existing PEM subscriber session after the lease time expires.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured in Forward mode.
  • The gateway IP address (giaddr) field in the unicast Dynamic Host Configuration Protocol (DHCP) renewal packet is set to the IP address of the relay agent. Typically, the DHCP client sets the field to 0 (zero).

Impact

The PEM subscriber session ages out.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the BIG-IP system is in DHCP Forward mode, if the giaddr field in the unicast DHCP renewal packet is set to the DHCP relay agent IP address, the DHCP server sends the ACK to the relay agent IP (giaddr), instead of the client IP address (ciaddr). The DHCP does not process the ACK and update the lease time, which causes the PEM subscriber session to age out.
