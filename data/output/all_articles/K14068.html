Known Issue

The BIG-IP ASM services may fail to start when the system DNS is enabled with IP version 6. This issue occurs when the following condition is met:

  • The system is configured with options inet6 for the DNS configuration.

When the DNS configuration includes the options inet6 setting, the BIG-IP ASM system attempts an AAAA query before trying an A query. However, the BIG-IP ASM system is not fully compatible with DNS AAAA queries. As a result, the BIG-IP ASM processes may fail to initialize properly.

The options inet6 DNS setting can be configured using the include command for the sys.dns module in the Traffic Management (tmsh) utility.

Impact

The BIG-IP ASM system fails to process application traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Some BIG-IP ASM processes may fail to start properly.
  • The BIG-IP ASM system produces a perl core file in the /var/core directory.
  • When you attempt to access the BIG-IP ASM configuration options in the Configuration utility, the system reports the following error message:

    No authorization - access denied

Workaround

You can recover from this issue by removing the options inet6 DNS setting and restarting the BIG-IP ASM system. To do so, perform the following procedure:

Impact of workaround: The BIG-IP system will not perform AAAA queries when the options inet6 DNS setting is removed.

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  2. Remove the options inet6 DNS setting by entering the following command:

    modify /sys dns include none

    If you have other include options configured, you can remove the options inet6 setting by entering the edit mode with the following command:

    edit /sys dns

    Note: This command starts a session of the vi editor to edit the DNS configuration.
  3. Save the change by typing the following command:

    BIG-IP 10.1.0 and later:

    save /sys config

    BIG-IP 10.0.x:

    save config
  4. Restart the BIG-IP ASM system by typing the following command:

    restart sys service asm
