Known Issue

An error message reporting an authentication failure will display if a user accesses a BIG-IP APM web application through the BIG-IP Edge Client application for the Apple iPhone, iPad, and iPod touch under the following circumstances:

  • The BIG-IP Edge Client application Web Logon setting is set to Off

    Note: Enabling Web Logon will disable local username and password entry, the use of a client certificate, and require web-based logon configured on the connecting server.

  • The BIG-IP APM access policy uses the Landing URI action

The error message will appear similar to the following example:

Authentication Failed. Please check your credentials or configuration.

This issue is caused by the BIG-IP Edge Client application appending a NULL (\0) to the VHOST cookie entry.

F5 Product Development tracked this issue as ID 347917 and it was fixed in the iOS Edge Client 1.0.1.

You can download the latest BIG-IP Edge Client for Apple iOS from the following link:

http://itunes.apple.com/us/app/f5-big-ip-edge-client/id411062210

Workaround

You can work around this issue by using the following iRule, which will remove any information after the trailing slash (/) character when applied to your BIG-IP APM virtual server.

Note: This workaround only works if the landing URI ends with the slash (/) character.

Creating the VHOST iRule

  1. Log in to the BIG-IP Configuration utility.
  2. In the navigation pane, expand Local Traffic.
  3. Click iRules.
  4. Click Create.
  5. Enter a name for your iRule.

    For example:

    vhost-fix
  6. In the Definition text box, enter the following information:

    when HTTP_REQUEST {
    if { [HTTP::cookie exists "VHOST"] } {
    set Original_Cookie [HTTP::cookie "VHOST"]
    set New_Cookie [substr $Original_Cookie 0 "/"]
    HTTP::cookie "VHOST" $New_Cookie
    }
    }
  7. Click Finished.

Attaching the iRule to the virtual server

  1. Log in to the BIG-IP Configuration utility.
  2. In the navigation pane, expand Local Traffic.
  3. Click Virtual Servers.
  4. Click the name of the virtual server of which you want to add the iRule.
  5. Click the Resources tab.
  6. In the iRules section, click Manage.
  7. In the Available list, click the name of iRule created above.
  8. Click <<.
  9. Click Finished.
