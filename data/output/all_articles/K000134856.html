K000134856: License Management report generation is failing

Description

When navigating the BIG-IQ UI's Devices > License Management > Reports, a banner appears on top of the page that says "fail running task on restart".

Environment

  • BIG-IQ
  • Reports

Cause

Failed report task that was running when restjavad restarted.

Recommended Actions

You should be able to get rid of the error banner by identifying the failed report task and then deleting it.

Find the failed report ID using the following command:

restcurl /cm/device/tasks/licensing/report-schedules/ | jq '.items[] | "\(.id),\(.status)"'

Delete the report using the report task ID:

restcurl -X DELETE /cm/device/tasks/licensing/report-schedules/<TASK_ID>

Where <TASK_ID> is the task number from the previous command.

You would need to create a new scheduled report after that.
