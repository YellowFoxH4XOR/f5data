Description

Unable to access BIG-IP via GUI after upgrade. The Command Line Interface (CLI) works.

Environment

  • BIG-IP
  • Upgrade
  • GUI/Configuration Utility

Cause

Unknown

Recommended Actions

Try to restart httpd and tomcat services (K63740790: The Management GUI is not accessible or pages in the GUI do not load properly).

If does not help then follow K000133532: Troubleshooting BIG-IP GUI loading issues.
