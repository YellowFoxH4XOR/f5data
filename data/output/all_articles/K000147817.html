What Happened?

  • I would like to know the difference between SLI and SLO nodes

Environment

  • F5® Distributed Cloud Sites
  • AWS VPC Site

Resolution/Answer

  • SLO means  Site Local Outside --> use for external (eth0 interface)
  • SLI means  Site Local Inside --> use for internal (eth1 interface)
