K1662: Commands may fail when they are executed remotely on the peer unit in a redundant pair

Topic

The remote user's login shell, which is set by default to root user and bash shell, must include the /sbin directory in its path. Commands from the peer BIG-IP will fail if the remote user has an inadequate path statement.

To see if the user's path contains the /sbin directory, type the following command on the peer BIG-IP:

echo $PATH

The path statement will display in the following format:

/bin:/usr/bin:/sbin:/usr/sbin:/usr/contrib/bin:/usr/contrib/sbin:
/usr/local/bin:/usr/local/sbin:/usr/libexec

At a minimum, it should contain the following paths:

/bin
/usr/bin
/sbin
/usr/sbin
/usr/contrib/bin
/usr/contrib/sbin
/usr/local/bin
/usr/local/sbin
/usr/libexec

Adding the /sbin directory to the user's path

If the user's path does not contain the /sbin directory, perform the following steps:

  1. To retain the path statement and add the /sbin directory, type the following command:

    PATH="$PATH:/sbin"

  2. To make the change permanent, use a text editor (such as vi or pico) and edit the /root/.bash_profile file.

    It should appear similar to the following:

    # .bash_profile
#
# DO NOT EDIT THIS FILE
# Add environment settings in /root/.bash_profile.local instead
#
# shell vars
#
PS1='\h:\w# '
PS2='\h:\w## '
CDPATH=".:..:/:~:/usr:/var"
/libexec:/var/tmp/Q/wamu"
HISTCONTROL=ignoreboth
PAGER=less

    Note: You can ignore the warning to not edit the .bash_profile file.

  3. Locate the shell vars section of the file.
  4. After PATH=, add the corrected path statement.

    Important: Changing the following files can result in system downtime. If you need assistance making these changes, contact F5 Networks Technical Support.

    For example:

    PATH="/bin:/usr/bin:/sbin:/usr/sbin:/usr/contrib/bin:/usr/contrib/sbin:
/usr/local/bin:/usr/local/sbin:/usr/libexec"

    The newly edited /root/.bash_profile file should now appear similar to the following:

    #
# .bash_profile
#
# DO NOT EDIT THIS FILE
# Add environment settings in /root/.bash_profile.local instead
#

# shell vars
#
PS1='\h:\w# '
PS2='\h:\w## '
CDPATH=".:..:/:~:/usr:/var"
PATH="/bin:/usr/bin:/sbin:/usr/sbin:/usr/contrib/bin:/usr/contrib/sbin:
/usr/local/bin:/usr/local/sbin:/usr/libexec"
HISTCONTROL=ignoreboth
PAGER=less
