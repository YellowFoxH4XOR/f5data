Issue

Error Message

0107183b:3: Cannot disable LDNS cache when a Wide IP has persistence enabled.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • A wide IP in the configuration has persistence enabled.
  • The mcpd process receives a message to set the Local Domain Name System (LDNS) cache to disabled during a configuration load or while processing a configuration modification.

Impact

The LDNS cache remains enabled.

Recommended Actions

In order to disable the LDNS cache, you must disable persistence for the wide IPs in your configuration. To do so, perform the following procedure:

Impact of procedure: Performing this procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To modify the current wide IP configuration of a specified record type, use the following command syntax:

    tmsh modify gtm wideip <wideip_record_type> all persistence disabled

    For example:

    tmsh modify gtm wideip aaaa all persistence disabled
