Topic

Digital SSL certificates are part of the normal HTTP data and will work through the BIG-IP system; however, a common reason for receiving a warning dialog while viewing a site is that you are accessing it using a URL that does not match the certificate. Since certificates are created for a specific URL, if the certificate does not match the URL, you will receive an invalid message.

For example, if a certificate is created specifically for www.acme.com and you access the site by typing www.acme.com in the browser, the connection is made to the web site, the certificate is sent to the browser, and the browser compares the address entered with the certificate. Since they match, you will not receive an error message.

If the actual IP address of www.acme.com is 207.17.117.50, you can access the same site by entering the address in the browser as either www.acme.com or 207.17.117.50; however, if you use the IP address, the browser indicates the certificate does not match the requested URL and you will receive a message indicating that the SSL certificate is not valid.

If you are certain that the certificate is valid for the site, you can acknowledge the warning and continue viewing the site.
