Description

F5 Container Ingress Services (CIS) support timelines for OpenShift 4.19 and 4.20.

Environment

  • F5 Container Ingress Services (CIS) Operator version 2.20.2
  • Planned upgrade target: Red Hat OpenShift 4.19 (based on Kubernetes 1.32)
  • CIS documentation indicates Kubernetes support up to version 1.33 

Cause

CIS Operator v2.20.2 has not yet been validated or certified for Red Hat OpenShift versions 4.19 and 4.20. Validation and operator support for these versions are planned for a future CIS release (CIS 2.20.4).

Recommended Actions

CIS version 2.20.4 release, which will include validation and operator support for OpenShift 4.19, 4.20, 4.21, 4.22.

Estimated availability of this release is May 2026 tentatively at the time of publishing this article
