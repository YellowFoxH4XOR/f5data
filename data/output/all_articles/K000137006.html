Description

PAYG VE halts upon FIPS integrity check failure after HSM-related configuration change

Environment

  • AWS public cloud
  • PAYG license

Cause

In a use case where customer uses PAYG VE and installs AWS CloudHSM client, there is a need to configure HSM IP address for client to reach out to. This results in HSM client configuration files modification.
Since FIPS is included as a part of PAYG licensing, upon reboot there is a built-in integrity check running to confirm unexpected security-related files modifications. If such modification is discovered, the system halts and won't boot (by design).
HSM client configuration files are part of the integrity checking and since HSM IP address is modified, the system will halt and become unusable following standard HSM configuration routine.

Workaround

Use BYOL VE and not license FIPS.

Additional Information

In public cloud there are 2 types of VE subscription types:
PAYG - this type includes all possible basic licensing options (including FIPS).
BYOL - this type includes no licensing at all and customer can buy those separately according to his needs.
