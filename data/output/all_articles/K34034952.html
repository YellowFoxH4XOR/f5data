K34034952: Unable to obtain global lock

Type
Support Solution
Published
2022-03-26
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K34034952

Description

Error message when trying to increase directories for BIG-IQ that have reach capacity (they are completely full):

resizevol /var 20000000
/var/lock/lvm/V_vg-db-sda:aux: open failed:
No space left on device Can't get lock for vg-db-sda
Skipping volume group vg-db-sda
var/lock/lvm/P_global:aux: open failed:
No space left on device Unable to obtain global lock.

Environment

  • BIG-IQ VE
  • /var is 100% full

Cause
BIG-IQ VE is locked since /var is completely full nothing can be done.

Recommended Actions

  1. Log on to the command line of the BIG-IQ device.
  2. Using a text editor (vi,pico,nano) edit the file /etc/lvm/lvm.conf.
  3. Change the value for locking_type = 1  to locking_type = 0.
  4. Increase the directory size for /var with the following command:
    resizevol /var 20000000
  5. Edit the file /etc/lvm/lvm.conf and revert the value for locking_type back to the default of 1 (locking_type = 1).
