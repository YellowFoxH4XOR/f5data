Description

After a software upgrade, the network map does not display your traffic objects. Instead, the following message is shown:

No objects in this partition

You may also observe the following error in the GUI:

Error getting auth token from login provider

Environment

  • Upgrade
  • GUI
  • Network map

Cause

Bug ID 717174

Recommended Actions

Execute the following command:

tmsh restart sys service restjavad restnoded tomcat httpd

Note: There is no impact to traffic.

Additional Information

If your system is in forced offline mode after the upgrade, the availability of traffic objects in the network map might differ to those shown on the peer. This is because no monitoring is being done while forced offline.
