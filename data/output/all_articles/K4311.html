Topic

The BIG-IP system uses the admin account to perform a configuration synchronization. Every 30 seconds, the system verifies whether a configuration synchronization is necessary. If the admin password is not the same on both systems in the redundant pair, the BIG-IP system will log the following error message in the /var/log/messages file:

httpd(pam_unix)[#] [client <address>] PAM: user 'admin' - not authenticated: Authentication failure

Note: The hash mark (#) will be replaced by the process ID of the httpd daemon, and <address> will be replaced by the IP address of the BIG-IP system that initiated a configuration synchronization check.

To resolve this issue, ensure that the admin password is the same on both BIG-IP units in a redundant pair. For more information, refer to K3350: Changing system maintenence account passwords (9.x - 10.x)
