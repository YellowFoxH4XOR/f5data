Type
Support Solution
Published

Updated
2025-03-19
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source

Description

You observe the following error in the LTM logs:

err mcpd[9223]: 01070711:3: Caught runtime exception, FileOps error: No such file or directory at FileOps.cpp:158.

Environment

-Recently performed an upgrade to 17.1.1

-Device is part of an HA configuration

Cause

-Provisioning on HA devices does not match after upgrade

Recommended Actions

-Address provisioning issues on standby device

-Reboot device

-Confirm error is not present

Additional Information

Provision licensed BIG-IP modules
