Description
While connecting to an APM AccessPolicy that performs anti-virus checks on the client machine, users cannot successfully log in.
The client machine starts performing checks but those later never end.
When reviewing the logTerminal log file we have on the client machine, you can notice a message such as:

2020-01-01,12:00:00:123, 13536,6388,EPCHECK, 1, , 91, , wWinMain, boost::interprocess_exception::library_error
2020-01-01,12:00:00:123, 13536,6388,EPCHECK, 48, , 93, wWinMain, Endpoint check server process finished (res), -1

Environment

  • BIG-IP APM
  • The Access Policy is setup with an "AV Check" agent
  • The client machines are using the F5Helpers programs (f5epi.exe)

Cause
Bug ID 848353 Endpoint check fails to start on Windows in some cases

Recommended Actions

Upgrade to APM Clients v7.2.x or above.

Additional Information
APM Clients packages can be downloaded from: APM Client download page.
