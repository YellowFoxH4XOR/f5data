K85333513: PAOS Endoint without ECP profile in IdP doesn't trigger error 01070734:3

Description

When and sp-connector is configured with PAOS binding, the IdP service requires an ECP profile. If an IdP service is bound to an SP Connector and the admin changes the binding to PAOS binding, MCP does not validate that an ECP profile is applied to the IdP service.
Then, any process that reloads the config fails because of the following error:

  • 01070734:3: Configuration error: IdP Service/sso_config_saml (/Common/myIdP have 'ecp' profile configured because SP Connector (/Common/MyConnector) has 'paos' binding configured on Assertion Consumer Service

Environment

  • The IdP service doesn't have an ECP profile.
For example:
apm sso saml EXAMPLE{
entity-id EXAMPLE
IdP-certificate default.crt
IdP-host myserver.me
IdP-signkey default.key
saml-profiles { web-browser-sso } <<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<< NO ECP profile
}
  • Then the IdP service is bound to an sp-connector that is configured with PAOS binding.

Cause

ID1077241

Recommended Actions

Add an ECP profile to the IdP service and load the config.
