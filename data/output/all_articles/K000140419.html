Description

On older System Controller software, you may receive a false alert from F5OS, indicating "PSU Fault detected".

Environment

F5OS-A System Controller

version < 1.5.2

Cause

Several bugs exist in older System Controller software, which may cause the system to incorrectly report that a PSU has failed, when the PSU may in fact be healthy.

Bug ID 1441425: The rSeries appliance log shows "PSU voltage out value < lower limit, value=0". (fixed in 1.5.2)

Bug ID 1314917: Command "show system health components component psu-2" results in errors (fixed in 1.5.2)

Recommended Actions

Upgrade the System Controller to 1.5.2 or newer. Downloads can be found at MyF5 Downloads
