Topic

You should consider using this procedure under the following conditions:

  • You want to filter the BIG-IP ASM Attack Signature List by a specific Common Vulnerabilities and Exposures (CVE) number.
  • You want to view the associated ASM attack signature ID for a CVE.

Description

In some cases you may need determine the ASM attack signature ID for a specific CVE. Beginning in BIG-IP 13.1.0, you can filter the Attack Signature List in the Configuration utility by the CVE listed in the attack signature references.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have access to the BIG-IP Configuration utility.
  • You know the CVE number you want to use to filter the list.

Procedures

BIG-IP ASM 16.x and later

You can filter the Attack Signature List by the associated CVE. To do so perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Options > Application Security > Attack Signatures > Attack Signature List.
  3. Click Show Filter Details.
  4. Click Advanced.
  5. For References , type the CVE number. For example: CVE-2016-3081. You can leave the Reference list set to All to search all references that contain the CVE string, or you can click CVE to search only the CVE references.
  6. Click Apply.
  7. In the signature list, click the arrow next to the signature and select See More to show the details. The CVE is listed in the References section.
  8. (Optional) Click the CVE URL link in the References row to view the vulnerability information.

BIG-IP ASM 14.x - 15.x

You can filter the Attack Signature List by the associated CVE. To do so perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Options > Application Security > Attack Signatures > Attack Signature List.
  3. Click Show Filter Details.
  4. For References , type the CVE number. For example: CVE-2016-3081. You can leave the Reference list set to All to search all references that contain the CVE string, or you can click CVE to search only the CVE references.
  5. Click Go.
  6. In the signature list, click the arrow next to the signature to show the details. The CVE is listed in the References row of the details table.
  7. (Optional) Click the CVE URL link in the References row to view the vulnerability on the cve.mitre.org site.
