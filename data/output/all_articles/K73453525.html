Known Issue

BIG-IP Oracle monitors may fail when the OJDBC driver reads a time zone file that it cannot process.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system uses ojdbc6.jar, as supplied by Oracle for Java 6, to monitor an Oracle database.
  • The Coordinated Universal Time (UTC) time zone is configured.
  • In the /usr/share/zoneinfo directory, the UTC file is not the first file in the list.
Note: This issue may also affect other time zones, such as GMT.

Impact

The BIG-IP system fails to perform Oracle monitoring and may mark members down.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Affected members are marked down.
  • Oracle monitor traffic that is captured using a utility such as tcpdump shows that the OJDBC driver is negotiating the time zone for the session, and instead of "UTC" the driver attempts to change the time zone to "Universal," "Zulu," "Etc/Universal," or "Etc/Zulu."
