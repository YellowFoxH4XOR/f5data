K000138223: Unable to ping management interface after upgrade

Type
Support Solution
Published
2024-01-13
Updated
2025-04-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4, 15.1.10
Source
https://my.f5.com/manage/s/article/K000138223

Description

After upgrade to 15.1.9 and above management IP address may stop responding on ICMP requests. 
This happens when management interface network firewall rules are used, deny-all rule is created and no explicit firewall rule is created to allow ICMP.

Environment

  • BIG-IP management network
  • Management interface firewall rules

Cause

This is related to Bug ID 760355 being fixed in v15.1.9. This ID was created due to ICMP traffic not being blocked on the management interface even when there is a rule created to either explicitly or implicitly (deny any) block it.
From v15.1.9 and above ICMP is now blocked unless explicitly allowed (the same as UDP and TCP).

Recommended Actions

If you would like to allow ICMP on management interface, you will need to add firewall rule to allow ICMP (System  ››  Platform  ››  Security: Management Port)
