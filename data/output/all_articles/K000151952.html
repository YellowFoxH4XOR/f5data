Description

HTTP Analytics Overview page displays statistics for multiple virtual servers even though only one has an HTTP Analytics profile assigned.

Environment

  • Some virtual servers may have L7 DoS profiles assigned
  • AVR
  • ASM

Cause

The Analytics Overview page displays statistics for any virtual server that has either an HTTP Analytics profile or an L7 DoS profile attached. When an L7 DoS profile is present on a virtual server, AVR collects and displays its statistics in the overview—even if no HTTP Analytics profile is applied. This behavior is expected but not explicitly documented.

Recommended Actions

This is expected behavior.
