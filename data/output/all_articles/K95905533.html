Description: 
IRule for HTTPS virtual server not working.
iRule is sending a redirect response for a new location.

Environment:
  • BIG-IP 
  • LTM
  • iRules

Cause:
Virtual server is using SSL passthrough.
The HTTPS virtual server must have a client SSL profile.


Recommended Actions:
A Client SSL profile and a server SSL profile must be added to the virtual server if you intend to use an iRule that does HTTP inspection, or makes changes to the content.

Additional Information:
Even though a HTTP profile has been added to a HTTPS virtual server, the iRule will not work if it makes reference to the HTTP content, until the appropriate SSL profiles have been applied.
The reason for this is because the BIG-IP will not be able to determine the content of the encrypted connection without the appropriate SSL profiles, and the HTTP profile that has been applied will be ignored as the encrypted content passes through.
