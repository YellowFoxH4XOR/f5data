Description
Updating client profile certificate on application fails with an error message similar to the following when attempting to modify any configuration object in an iApp:

010715bc:3: The application service (/Common/test.app/test) has strict updates enabled, the object (Persistence Profile /Common/test.app/test_cookie-persistence) must be updated using an application management interface.
 

Environment

  • Application configured using iApps
  • Profiles
  • Virtual Server and Virtual Address
  • Pools and Pool members
  • Nodes
  • iRules

Cause
It is not possible to modify configuration objects directly when they were created by an iApp due to the Strict Updates setting.
This is the default setting and can be disabled for each deployed application service.

Recommended Actions

  1. Go to iApps > <Application Services > <Application name> > Properties > Advanced.
  2. Clear the Strict Updates checkbox.
  3. Select Update.
  4. Make the changes you want to the configuration object.
  5. Re-enable strictness by selecting the Strict Updates checkbox again.

Additional Information
Note: It is advised to make changes to an iApp from the template and avoid making changes directly to the objects after disabling strict updates.
