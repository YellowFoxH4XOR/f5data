Known Issue

This is the result of a known issue. The BIG-IP ASM does not support the use of character references to restrict content through an XML profile. For example, Perl regular expressions such as \x00 through \xAA would not be supported.

Attempting to restrict incoming XML data to a specific character set using a Perl regular expression with a custom scheme or WSDL may trigger a WSDL violation or result in blocked content.

For example:

<xs:pattern value="[^A-Za-z0-9]{1,20}" />
and
<xs:pattern value="\p{IsHebrew}"/>

Using the example pattern to restrict XML element content to the Hebrew character set may result in the BIG-IP ASM blocking the content. If another character set is contained within the XML data, the example pattern could also prevent a WSDL document violation from being triggered.

F5 Product Development tracked this issue as CR92511 and it was fixed in BIG-IP ASM 9.4.5. For information about upgrading, refer to the BIG-IP ASM Release Notes.
