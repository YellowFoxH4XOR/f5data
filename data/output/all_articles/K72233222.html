Description
When deploying DNS objects to a BIG-IP the deployment target must be a DNS Sync Group. This is for objects that will be added to the bigip_gtm.conf file of the BIG-IPs. If a device(s) is selected the evaluation will not consider the DNS objects and these objects will not show as differences. 

Environment
LTM DNS configuration is being modified via the BIG-IQ and being deployed to managed devices

Recommended Actions
Target Deploy to Sync Groups when deploying a DNS object
  • In Deployment -> EVALUATE & DEPLOY -> DNS Evaluations, click Create
    • In the Target section select Deploy to Sync Groups
    • Move the desired sync_group from the Available column into the Selected column
    • Click Create
Cause
This is the expected behavior
  • Objects that will be stored in bigip_gtm.conf on the BIG-IP should target the Deploy to Sync Groups
  • Objects that will be stored in bigip.conf on the BIG-IP should target Deploy to Devices
