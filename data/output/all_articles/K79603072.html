K79603072: [F5OS] Downloading a binary file or any large file (qkview, tcpdump) from F5OS systems GUI can corrupt it

Type
Support Solution
Published
2022-05-18
Updated

Applies to
  • VELOS Platforms
  • F5OS
  • rSeries Platforms
  • F5OS-C: 1.3.X, 1.2.X, 1.1.X, 1.1.1, 1.1.0, 1.3.2, 1.3.1, 1.3.0, 1.2.1, 1.2.0, 1.1.4, 1.1.3, 1.1.2, 1.2.2
  • F5OS-A: 1.0.1, 1.0.0, 1.0.X
Source

Description

Downloading binary file and large files (such as qkview and tcpdump) is from F5OS GUI can corrupted the file.

Environment

  • F5OS-C / F5OS-A
  • Velos / rSeriese
  • Configuration utility / GUI
  • File download

Cause

  • Bug ID 1092257
    NOTE: This is fixed in F5OS-C v1.5.x

Recommended Actions

Download from CLI on VELOS Controller or F5 rSeries appliance.

Location of the qkviews are:

PlatformDirectory
rSeries
Velos Controller		/var/shared/qkview/<filename>
Velos Partition/var/F5/partition<Partition_ID>/shared/qkview/<filename>
For example:
/var/F5/partition2/shared/qkview/myQkview.tar
 

NOTE: downloading qkview through SCP or SFTP can be done only with root account.  admin account is only for confd command

NOTE: Partition ID can be found by running the show partition commmand.

For example:
