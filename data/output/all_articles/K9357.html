Issue

When a BIG-IP system is licensed with BIG-IP Link Controller, the following error message is occasionally logged to the /var/log/ltm file when creating a virtual server:

Unexpected proxy reply from %zrd

This error message is benign and does not indicate failure or negative system performance.

F5 Product Development tracked this issue as ID 283493 (formerly CR99087) and it was fixed in BIG-IP version 10.0.0. For information about upgrading, refer to the BIG-IP Link Controller release notes.
