Description

Unable to reach BIG-IP management IP after upgrading

Environment

  • BIG-IP version 14.1.0 and below
  • Virtual Edition
  • Upgrade to above 14.1.0
  • Attempting to access Configuration Utility from outside the configured Management IP's subnet
  • Attempting to access the command line via SSH from outside the configured Management IP's subnet
     

Cause

Change in behavior described in K55225090: BIG-IP VE no longer supports Auto Last Hop for management connections

Recommended Actions

Configure a management route for return traffic (preferably BEFORE upgrade). For information about configuring management routes, refer to K13284: Overview of management interface routing

Additional Information

If connecting from within the subnet of the defined management IP, connections will work as expected.

If connecting from outside the subnet of the defined management IP, connections will simply be dropped (i.e. tcp SYN request will NOT be answered with a SYN/ACK)
