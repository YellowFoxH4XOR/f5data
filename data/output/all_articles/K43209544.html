Description

In secure environments, such as government dark sites, licensing a BIG-IP using the traditional method is often not allowed. In many instances the BIG-IP does not have internet access and/or exporting/copying data out of the dark site environment is not allowed. For these situations, F5 provides the Secured Environment License Utility. This utility will allow BIG-IP administrators to request a license using the Closed Circuit Network (CCN) method instead of the typical automatic or manual methods used for license activation or re-activation.

For information about CCN licenses refer to the following content:

  • CCN Program Overview
  • How to use the License Utility
  • Secured Environment License Utility
  • Reporting Problems with a License

Environment

  • BIG-IP installed in secure dark site environment where Internet access and data export are not allowed.

Cause

None

Recommended Actions

  1. Review the previous documents and decide on the method that best fits your network.
  2. Gather the information needed to license your BIG-IP using one of these methods.
    1. Both Method 1 and 2 are similar. You will need to acquire the clear text dossier with either get_ccn_dossier or get_dossier -c -b <regkey> depending on the version your BIG-IP is running per the CCN help page.
    2. For Method 3 you will need the MAC address of the BIG-IP, the platform ID, and the OS version in use.
      1. Log on to the CLI and enter the TMOS shell. To do so, run the command: tmsh
        1. To find the MAC address run this command from the (tmos) shell:  show sys mac-address | grep mgmt
        2. The platform ID can be found by running this command from (tmos) and finding the Type in the section titled System Information: show sys hardware
        3. The OS version will need to contain the version and the build. To obtain both the current running version and build run this command in the (tmos) shell: show sys version detail
          Important: There is a known issue when using the MAC Address Method 3 Step 2 (Software Version*). The example shows using the the proper build number. If you experience an issue then in place of the build number simply type '123' (no single quotes). If the issue persists please contact F5 Support.
