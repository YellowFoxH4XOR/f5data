Topic

This article applies to BIG-IP 11.x through 17.x. For information about other versions, refer to the following article:

  • K7215: Configuring multiple default routes on the BIG-IP system (9.x - 10.x)

You should consider using these procedures under the following condition:

  • You want to configure multiple default gateways on the BIG-IP system.

Description

The BIG-IP system has the ability to configure multiple default gateways. Configuring multiple default gateways for the BIG-IP system allows the flow of traffic to continue, even if one of the gateway routers is unable to pass traffic.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You must have administrator or resource administrator access to the Configuration utility.

Procedures

To configure multiple default gateways on the BIG-IP system, you must configure a default gateway pool that contains the IP addresses of the routers that the BIG-IP system will use as gateways, including a gateway monitor. You can then configure that pool as the default gateway pool for the BIG-IP system. To do so, perform all of the following procedures:

  • Configuring the gateway monitor
  • Configuring the default gateway pool
  • Configuring the pool as the default gateway for the BIG-IP system

Configuring the gateway monitor

For information about creating a transparent gateway Internet Control Message Protocol (ICMP) monitor, refer to the Transparent gateway ICMP monitors section of K8971: Creating transparent ICMP health monitors.

Impact of procedures: Performing the suggested procedures should not have a negative impact on your system.

Configuring the default gateway pool

To configure the default gateway pool that contains the IP addresses of the routers that the BIG-IP system will use as gateways, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Using the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Pools.
  3. Select Create.
  4. Enter a name for the pool, such as Default_GW_Pool.
  5. For Health Monitors, select the transparent gateway ICMP monitor you created in the previous steps and move it to the Active box.
  6. For Load Balancing Method, select a load balancing method for the pool.
  7. For Address, enter the IP address of one of the default gateway addresses.
  8. For Service Port, select * All Services.
  9. To add the default gateway to the New Members table, select Add.
  10. Repeat steps 7 through 9 for each default gateway address.
  11. Select Finished.

Using the tmsh utility

  1. Log in to the TMOS Shell (tmsh)
  2. Create the default gateway pool by entering the following command syntax:

    create /ltm pool <pool name> monitor <monitor name> load-balancing-mode <load balance method> members add { <node name/IP:port> ... }

    For example,

    create /ltm pool Default_GW_Pool monitor my_gw_icmp_mon load-balancing-mode fastest-node members add { 192.168.40.254:any 192.168.50.254:any }

  3. Save the change by entering the following command:

    save /sys config

Configuring the pool as the default gateway for the BIG-IP system

To assign the pool you created as the default gateway for the BIG-IP system, perform the following procedure:

Impact of procedure: Performing the following procedure may change the destination for packets that have no specific route.

Using the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to Network > Routes.
  3. Select Add.
  4. Enter a name for the route, such as Default_GW_Route.
  5. Enter 0.0.0.0 for the Destination.
  6. Enter 0.0.0.0 for the Netmask.
  7. For Resource, select Use Pool.
  8. Select the default gateway pool you created in the previous procedure.
  9. Select Finished.

Using the tmsh utility

  1. Log in to the TMOS Shell (tmsh)
  2. Configure the pool you have created in the previous procedure as the default gateway by entering the following command syntax:

    create /net route <route name> network default pool <pool name>

    For example,

    create /net route Default_GW_Route network default pool Default_GW_Pool

  3. Save the change by entering the following command:

    save /sys config
