Description

The BIG-IP GTM/DNS is marking Wide IP down because it's marking the pool members down.

  • Wide-IP's fail to resolve.
  • /var/log/gtm - shows alert certificate expired
  • iQdump to the LTM shows handshake failing with certificate expired and ssl alert number 45

Environment

  • The Virtual Sever in LTM itself is actually up.
  • iQuery mesh is not connected.
  • BIG-IP GTM/DNS and LTM.
  • The LTM has in fact a valid certificate.
  • bigip_add is successful but the iQuery mesh is still not connected.

Cause

This can happen if the BIG-IP GTM/DNS device's certificate itself has expired.

Recommended Actions

Follow the steps to verify and fix the issue.

  1. Check the validity of the certificate  used by BIG-IP GTM/DNS. If this has an expired certificate, this is what is causing the issue.
  2. Renew the BIG-IP GTM/DNS certificate and then re-add the BIG-IP LTMs back to re-establish the iQuery mesh.
  3. Once done, use command below to verify that the iQuery connection is up and running.
    # tmsh show gtm iquery
Note: In some occasions, a restart of gtmd and big3d may be required for the GTM to use the new certificate. This can be done by:
# bigstart restart gtmd big3d
The above command can cause DNS disruption based on the configuration. It's recommended to perform it during a maintenance window.

Additional Information
