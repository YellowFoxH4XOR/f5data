K000151144: BIG-IQ Fails to Import ASM Services from BIG-IP – HTTP 405/404 Errors and Discovery Failures

Description

When importing ASM (Advanced WAF) services from a BIG-IP device into BIG-IQ, the process may fail with errors such as:

  • Error Getting resource provisioning from /mgmt/tm/sys/provision Status 405
  • Error querying 'ASM Policy - Signature' from path '/mgmt/tm/asm/policies/<policy_id>/signatures', network communication failed due to protocol error
  • HTTP 404 or 405 status codes observed in logs or GUI during device discovery or service import
  • Intermittent failures or timeouts when BIG-IQ queries BIG-IP REST endpoints, especially for ASM policy signature collections

Environment

  • Bigiq ASM service import
  • Management interface

Cause

This issue is caused by instability or communication failures between BIG-IQ and BIG-IP when using the management interface for device discovery and service import. The restjavad daemon on BIG-IP may not respond to some requests from BIG-IQ, resulting in HTTP 405 or 404 errors. This can be exacerbated by:

  • Network instability, packet loss, or flapping connectivity on the management interface
  • Aggressive log rotation causing loss of critical debug data needed for troubleshooting
  • Resource constraints on the management interface under high-volume REST API operations (such as large ASM policy signature imports)

Using the management interface for these operations is not recommended.

Recommended Actions

Use a self IP address for discovering and managing BIG-IP devices in BIG-IQ, as recommended in K15612. Self IPs provide more robust and higher-bandwidth connectivity than the management interface.
