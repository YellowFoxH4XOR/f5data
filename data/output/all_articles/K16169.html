Known Issue

The mcpd process may log benign error messages when you use the qkview utility.

This issue occurs when the following condition is met:

  • You run the qkview utility from either the command line or the BIG-IP Configuration utility.

Impact

None. The specific error messages are benign and should not impact system performance.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system logs messages to the /var/log/ltm file that appear similar to the following example:

    err mcpd[9108]: 0107167d:3: Data publisher not found or not implemented when processing request route_static_entry.
    err mcpd[9108]: 0107167d:3: Data publisher not found or not implemented when processing request route_dynamic_entry.
