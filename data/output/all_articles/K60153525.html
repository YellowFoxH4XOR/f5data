Description

  • New DNS Express deployment is not working as expected
  • NOTIFY message seems to be ignored by the BIG-IP
  • BIG-IP does not initiate IXFR for the zone

Environment

  • DNS Express
  • NOTIFY message is not sourced from the master DNS server IP

Cause

The dns-express-allow-notify field may be misconfigured.
You should only specify an IP address or list of IP addresses.

Examples:

ltm dns zone /Common/example.com {
    dns-express-allow-notify { 10.0.0.0%1/24 }  <------------  Not Valid
    dns-express-notify-tsig-verify no
    dns-express-server /Common/master-dns
}

ltm dns zone /Common/example.com {
    dns-express-allow-notify { 10.0.0.0/24 }  <------------  Not Valid
    dns-express-notify-tsig-verify no
    dns-express-server /Common/master-dns
}

Here's a working example:

ltm dns zone /Common/example.com {
    dns-express-allow-notify { 10.0.0.1 } <------------ Valid
    dns-express-notify-tsig-verify no
    dns-express-server /Common/master-dns
}

Recommended Actions

Use an explicit list of IP addresses in the "Allow NOTIFY From" field  

Additional Information

More information can be found in the manual section entitled Creating a DNS zone to answer DNS queries: DNS Express Implementation Manual
