K000137235: F5OS Tenant restarted after VELOS system controller upgrade

Type
Support Solution
Published
2023-10-13
Updated
2025-09-15
Applies to
  • F5OS
  • F5OS-C: 1.8.X, 1.8.1, 1.8.0, 1.6.2, 1.6.1, 1.5.1, 1.5.0, 1.6.X, 1.5.X, 1.6.0
Source
https://my.f5.com/manage/s/article/K000137235

Description

Performed rolling upgrade of VELOS system controllers, but did not upgrade partition.

Tenants restarted shortly after the upgrade. Is this expected?

Environment

  • F5OS-C
  • Controller upgrade

Cause

This is expected if the Kubevirt version is upgraded as part of the controller upgrade. Future F5OS versions may improve this behaviour.

Recommended Actions

None

None
