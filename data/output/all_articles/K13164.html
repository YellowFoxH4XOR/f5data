Topic

You should consider using this procedure under either of the following conditions:

  • You want to install or upgrade your BIG-IP system to 11.x through 17.x but do not have the installation image on the system's hard drive.
  • You already have a BIG-IP 11.x through 17.x installation but cannot access the hard drive.

    For more information regarding installation of BIG-IP software refer to: K13117: Performing a clean installation of BIG-IP 11.x - 17.x

    Note: This procedure is applicable only to BIG-IP base image releases. Installation of a hotfix release is not possible using a bootable USB thumb drive.

Important: You should not perform the procedures described in this article on F5OS hardware products such as rSeries and VELOS systems. F5OS hardware products do not run the same operating system as the BIG-IP and VIPRION platforms, and do not have the mkdisk utility. For information about creating a bootable USB thumb drive for clean installation on F5OS hardware products, refer to the following:

  • F5 VELOS, F5OS-C 1.8.x clean installation: https://techdocs.f5.com/en-us/velos-1-8-1/velos-systems-installation-upgrade/title-install-upgrade-software.html#clean-install
  • F5 VELOS, F5OS-C 1.6.x clean installation: https://techdocs.f5.com/en-us/velos-1-6-1/velos-systems-installation-upgrade/title-install-upgrade-software.html#clean-install
  • F5 rSeries, F5OS-A 1.8.x clean installation: https://techdocs.f5.com/en-us/f5os-a-1-8-0/f5-rseries-systems-installation-upgrade/title-install-upgrade-software.html#clean-install-usb
  • F5 rSeries, F5OS-A 1.5.x clean installation: https://techdocs.f5.com/en-us/f5os-a-1-5-3/f5-rseries-systems-installation-upgrade/title-install-upgrade-software.html#clean-install

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have a USB mass storage device with storage capacity that exceeds the size of the BIG-IP ISO file for the version you want.
  • You have a BIG-IP version ISO file or the BIG-IP installation DVD of the version you want.
  • You have a BIG-IP system or a GNU/Linux workstation that meets the following requirements:

    A GNU/Linux workstation must contain the following software components and third-party utilities:

    • The Linux 2.6.x kernel.
    • Perl 5.8 or later.
    • GNU cpio, which manages CPIO archive files.
    • RPM Package Manager (RPM) tool's rpm2cpio, which converts RPM packages to a standard CPIO archive.
    • The Library for WWW in Perl (LWP) package.

      For downloading and other information about the LWP Perl module collection, search the Comprehensive Perl Archive Network (CPAN) programming library, or use other sources, such as a Red Hat Package Manager (RPM) file, or the Advanced Packaging Tool apt-get program.

      Note: The previous links take you to resources outside of AskF5, and it is possible that the documents may be removed without our knowledge.

    The required utilities for disk and image manipulation depend on the BIG-IP platform on which you plan to perform the thumb-drive installation.

    For BIG-IP platforms 6400, 6800, 8400, and 8800, the workstation must have the following utilities:

    • sfdisk, which changes disk partitioning.
    • mformat, which creates a FAT32 file system.
    • syslinux, which represents a lightweight bootloader that starts computers with the Linux kernel.
    • mkisofs, which creates an ISO9660 file system image.
    • implantisomd5, which implants an MD5 checksum in an ISO9660 image.

    For VIPRION-4400 platforms, the workstation must have the following utilities:

    • sfdisk, which changes disk partitioning.
    • mke2fs, which creates a Linux ext2 file system.
    • mkelfImage, which makes an Executable and Linkable Format (ELF) boot image for Linux kernel images.

    For all other BIG-IP and VIPRION platforms, the workstation must have the following utilities:

    • mke2fs, which creates a Linux ext2 file system
    • extlinux, which represents a lightweight bootloader that starts computers with the Linux kernel

Description

The BIG-IP installation ISO file and installation DVD contain the mkdisk utility. You can use the mkdisk utility to create a bootable USB thumb drive that contains a software installation image. You can then use that thumb drive as the installation source to install the software and recover the system.

Note: Some BIG-IP platforms may not be listed in the mkdisk utility. For the list of affected platforms, refer to K44991533: The mkdisk utility may not list all supported BIG-IP platforms.

Procedures

Creating a bootable thumb drive

Impact of procedure: All information on the USB device will be destroyed.

  1. Log in to the Linux workstation or the BIG-IP system as root.
  2. Mount the BIG-IP installation image as a loopback device using one of the following two methods:

    Note: In this step, F5 assumes that the ISO or DVD drive is mounted at /mnt/cd. If you do not have this directory, you must create it. If you create it, use the exact name /mnt/cd.

    For example, on a Linux system, you would use the mkdir /mnt/cd command.

    • If you are using an ISO file, mount the image using the following command syntax:

      mount -o loop <directory file path>/<.iso image file> /mnt/cd

      For example, if the BIG-IP ISO image is located in the /var/tmp directory and the ISO image is named BIGIP-11.5.1.0.0.110.iso, type the following command:

      mount -o loop /var/tmp/BIGIP-11.5.1.0.0.110.iso /mnt/cd

    • If you are using a BIG-IP DVD, insert the DVD into the DVD drive.
  3. Insert a 4 GB or larger thumb drive in a USB port on the Linux workstation or BIG-IP system.
  4. To change to the root directory of the mounted image, type the following command:

    cd /mnt/cd

  5. To start the mkdisk script, type the following command:

    ./mkdisk

    The operation prompts you with a series of questions, and provides options. Choose the options appropriate to your configuration. The script checks for the required tools and creates the thumb drive, which can take up to 45 minutes on a BIG-IP 1600 system. The interval on other systems varies.

    Note: Ensure that your terminal emulator's scrollback buffer is configured for at least 2048 lines to see all of the options.

  6. When the operation is complete, exit the /mnt/cd directory and unmount the loopback device by typing the following command:

    cd ~ ; umount /mnt/cd

  7. Remove the USB mass storage device and use it to boot BIG-IP devices, as needed.
