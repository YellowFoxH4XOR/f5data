K000150584: Error message: 010719cd:3: The property 'parent-label' must be set in <AVP> when the property 'parent-avp' of <AVP> is set.

Source

Description

Configuration is failing to load due to the error below


Feb 5 16:12:22 bigip1.local emerg load_config_files[8979]: "/usr/bin/tmsh -n -g -a load sys config partitions all " - failed. -- 010719cd:3: The property 'parent-label' must be set in (/Common/gy-session, init, 3gpp-rat-type) when the property 'parent-avp' of (/Common/_diameter_3gpp_rat_type) is set.



Environment

BIG-IP PEM


Cause

Missing parent-label value in grouped AVP definition in PEM prevents configuration from loading


Recommended Actions

Use a command line editor to open the /config/bigip.conf file and manually change "parent-label" value from "none" to a dummy text in the configuration element referenced in the error message. This will allow the configuration to load successfully.

For example, you may set the "parent-label" to match the name of the parent AVP. Below are the steps to do this from the UI


After the configuration loads successfully, you may use the UI to make further updates to the "parent-label".


  • In the UI navigate to "Subscriber Management ›› Profiles ›› Protocol ›› Diameter ›› gy-session ›› init"
  • In the AVP list, click on "3gpp-rat-type"
  • Set the Parent label field to "ps-information" and click "Replace"
  • Repeat previous step for "called_station_id" and "sgsn_mcc-mnc"
  • Click "Update" to save the changes.


I have tested with both the UI and tmsh and confirmed that the Big-IP will not allow the user to submit the configuration without setting the value for "parent-label" for child AVPs.
