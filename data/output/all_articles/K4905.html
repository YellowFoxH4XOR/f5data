Topic



In FirePass version 5.5, F5 Networks discontinued the Desktop Access feature set. To replace this functionality, F5 Networks recommends that you use Virtual Network Client (VNC).

VNC is open source software that is available in a number of both freeware and commercial versions.

To use VNC with FirePass, you can use either an SSL VPN session, or an Application Tunnel.

To configure an Application Tunnel, you must know the ports used by VNC. By default, VNC will listen on a TCP port in the range 5900 - 5999. Refer to the manual for your VNC software to learn how to display or control the port used by VNC.
