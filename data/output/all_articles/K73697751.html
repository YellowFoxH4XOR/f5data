Description

GUI is not accessible and no logs generated in the device

Environment

  • No log messages recorded in any log file of the BIG-IP
  • syslog-ng is running

Cause

The syslog-ng process silently fails without notice and is not able to restart automatically. This issue is being tracked as Bug ID 1040277

Recommended Actions

As a workaround, the following steps can be performed:

  1. Restart the syslog-ng service:  
    # bigstart restart syslog-ng
