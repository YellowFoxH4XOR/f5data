Known Issue

Attempts to import FIPS keys to the FIPS hardware security module (HSM) using the Traffic Management Shell (tmsh) may fail.

This issue occurs when the following condition is met:

  • The key name contains a colon character.

    For example, the system fails to import keys similar to the following:

    Common:test-export1.exp

Impact

The BIG-IP system cannot properly import affected keys to the FIPS HSM.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system logs an error message to the /var/log/ directory that appears similar to the following example:

    01070712:3: Caught configuration exception (0), file(/config/ssl/ssl.key/:Common:<key_name>) expected to exist. - sys/validation/FileObject.cpp, line 3196.
  • The BIG-IP system imports the key, but the corresponding file object is not created.

Workaround

To work around this issue, you can remove the colon character from the key name.
