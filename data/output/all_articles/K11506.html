Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator system does not allow multiconnect to be disabled for certain content within a policy. As a result, administrators cannot configure multiconnect on a per content basis for embedded items, which is typically allowed by the Content Assembly feature.

F5 Product Development tracked this issue as CR119845 and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.
