K37651514: ASM configuration not synchronizing, but devices are in sync

Type
Support Solution
Published
2021-02-24
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.1.2
Source
https://my.f5.com/manage/s/article/K37651514

Description

ASM configuration is not synchronized between HA peers, but devices are in sync.

Error in /var/log/ts/asm_config_server.log looking similar to this:

asm_config_server.pl|INFO|Feb 18 08:00:09.283|16740|F5::ASMConfig::Handler::handle_error,,Code: 406, Error message = Process size (207482880) has exceeded max size (200000000)

Environment

  • ConfigSync

Cause

Unknown at time of publication. PD is investigating this issue under ID885765.

Recommended Actions

As a workaround, increase asm_config_server process memory:

  1. Create a copy of configuration file:

    cp /etc/ts/tools/asm_config_server.cfg /etc/ts/tools/asm_config_server.cfg.orig

  2. Increase memory:

    echo 'AsyncMaxMemorySize=300000000' >> /etc/ts/tools/asm_config_server.cfg

  3. Verify the change:

    diff /etc/ts/tools/asm_config_server.cfg.orig /etc/ts/tools/asm_config_server.cfg

    Apply change by restarting asm_config_server:

  4. pkill -f asm_config_server

    Note: Restarting asm_config_server should not interrupt traffic processing.
