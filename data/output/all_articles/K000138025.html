Description

Adding a data plane route to a BIG-IP Next instance

Environment

BIG-IP Next
BIG-IP Central Manager

Cause

Currently data plane routes can only be modified by using the L3-Forwards API endpoint on the Next instance.

Recommended Actions

The BIG-IP Next postman collection has some examples of how the default route can be set. If you need to create additional routes you would need to create additional L3-Forwards.

The Postman collection can be downloaded from https://clouddocs.f5.com/bigip-next/latest/install/next_introduction.html

In the collection it is under Virtual Edition Onboarding -> Create Static Route

Here is an example of the JSON:

{
    "name": "staticroute",
    "l3Network": "Default L3-Network",
    "config": {
        "l3ForwardType": "L3RouteGateway",
        "destination": "192.168.10.0/24",
        "gateway": "192.168.10.1",
        "interface": "1.2"
    }
}

Additional Information

If you have already onboarded the instance onto Central Manager you would need to change the username in the postman collection to match the username used by Central Manager (i.e. admin-cm) and the password that you used when creating the instance.

To remove routes you can use the following example:

GET https://{{bigip_next_1_mgmt_ip}}:{{bigip_next_mgmt_port}}/api/v1/L3-forwards

{
    "_embedded": {
        "L3Forwards": [
        {
            "_links": {
                "self": "/L3-forwards/047ab3c2-2a3e-4e72-8bb1-b0fdd0a857e6"
            },
            "config": {
                "destination": "192.168.10.0/24",
                "gateway": "192.168.10.1",
                "interface": "1.2",
                "l3ForwardType": "L3RouteGateway"
            },
            "id": "047ab3c2-2a3e-4e72-8bb1-b0fdd0a857e6",    <-------
            "l3Network": "Default L3-Network",
            "name": "staticroute"
        }
        ]
        },
        "_links": {
        "self": "/L3-forwards?"
        },
    "count": 1,
    "total": 1
}
Then copy the id attribute and send a DELETE like this:

DELETE https://{{bigip_next_1_mgmt_ip}}:{{bigip_next_mgmt_port}}/api/v1/L3-forwards/047ab3c2-2a3e-4e72-8bb1-b0fdd0a857e6
