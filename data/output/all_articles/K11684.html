Topic

F5 has recently discovered and corrected a number of critical issues that affect customers running BIG-IP 9.4.8. F5 recommends that all customers currently running 9.4.8 install Hotfix-BIGIP-9.4.8-407.0-HF4, or a later version of the cumulative hotfix rollup, as soon as possible.

The following CRs are fixed in Hotfix-BIGIP-9.4.8-407.0-HF4 for BIG-IP 9.4.8:
