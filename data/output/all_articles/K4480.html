Known Issue

This is the result of a known issue. When power is supplied to the BIG-IP 3400 system, it will remain in Standby Power Mode until the user presses Enter on the LCD key pad. This functionality is by design. However, some BIG-IP 3400 units will ignore the Always Off feature in the BIOS. As a result, when power is applied, the system will automatically begin booting without any user interaction.

For approximately 60-90 seconds during power up, the user will not be able to control the LCD. The LCD will indicate that the system is in Power Standby Mode, and the Power and Status LED lights will appear normal. Immediately prior to the BIG-IP system loading, the LCD will function normally.

After the BIG-IP system has completed booting, the system will function as expected, with no impact on performance or functionality.

This issue may affect 3400 units built in 2004 and 2005.
