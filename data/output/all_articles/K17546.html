Known Issue

BIG-IP ASM virtual server requests may time out under heavy load.

This issue occurs when the following conditions are met:

  • The virtual server is configured with the BIG-IP Fraud Protection Service (FPS) profile.
  • The BIG-IP system is passing a high number of requests per second. For example, the system is passing 400 requests per second.

Impact

Client requests time out and are not processed as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Client requests time out and are not processed as expected.
  • Packet captures may show that the BIG-IP system fails to close the connection following a FIN-ACK packet from the client.
