K000156576: ARP for SNAT Pool IP is not resolved on gateway device

Type
Support Solution
Published
2026-02-05
Updated
2026-02-05
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000156576

Description

A SNAT pool IP address configured on BIG-IP LTM does not appear in the ARP table of the gateway, causing connectivity failures for traffic using this SNAT IP. Other SNAT pool IPs operate normally. Packet captures indicate that ARP requests are sent for the problematic SNAT IP, but BIG-IP does not respond to these requests.

Environment

  • BIG-IP LTM
  • SNAT pool configured

Cause

If a SNAT pool IP is also set up as a virtual address with ARP disabled, BIG-IP will not reply to ARP requests for that IP address. This prevents the MAC address from being published in the upstream gateway’s ARP table and results in failed traffic for that specific SNAT IP.

Recommended Actions

  • Remove the virtual address configuration for any SNAT pool IPs where it is not required.
  • Ensure ARP is enabled for all SNAT pool IPs that need to be reachable at Layer 2.
