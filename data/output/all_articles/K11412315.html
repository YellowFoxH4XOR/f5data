Topic

You should consider using this procedure under the following condition:

  • You want to configure a Bot Defense logging profile.

Description

The Bot Defense feature categorizes client requests and performs mitigation actions for certain types of requests, depending on how you configure the profile. When you configure a Bot Defense profile and a Bot Defense logging profile, the system identifies a threat pattern from a bot, performs the mitigation, and logs the information locally or to a remote log publisher. Enabling a Bot Defense logging profile allows the administrator to check why a certain request was challenged or blocked, and helps the administrator understand where to refine the Bot Defense profile and minimize false positives.

The following logging options are available for the Bot defense logging profile:

Bot defense log settingDescription
Local PublisherEnables the local log publisher.
Remote PublisherSpecifies a remote log publisher. F5 recommends that you use a remote log publisher for Bot Defense logging.

Note: For Bot Defense logging profile, only Splunk is supported as the remote log publisher. For more information, refer to K17899005: Unable to select Arcsight publisher for bot defense remote logging. For information about configuring Splunk as a remote publisher, refer to K15316506: How to send logs via High Speed Logging to Splunk.

Log Requests by Classification     
  • Human Users:
    • Browser
    • Mobile App
  • Bots:
    • Trusted Bot
    • Untrusted Bot
    • Suspicious Browser
    • Malicious Bot
  • Unknown:
    • Enabled
Specifies which sources generate Bot Defense logging. For example, if you select Suspicious Browser, the system generates a log entry when certain browser anomalies are detected in the request. If you select Unknown, the system generates a log entry for requests that are of an undetermined category.
Log Requests by Mitigation Action     
  • None
  • Alarm
  • CAPTCHA
  • Rate Limit
  • Block
  • TCP Reset
  • Honeypot Page
  • Redirect to Pool
Specifies which mitigation actions generate Bot Defense logging. For example, if you select CAPTCHA, the system generates a log entry when the system uses a CAPTCHA as the mitigation action for a request.
Log Requests by Browser Verification ActionSpecifies whether the system logs requests corresponding to browser verification flow.
Log Device ID Collection RequestSpecifies whether the system logs requests corresponding to the production of a Device ID.
Log Challenge Failure RequestsSpecifies whether the system logs requests corresponding to a failed browser challenge.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have configured a Bot Defense profile and associated the profile with a virtual server. For more information refer to K42323285: Overview of the unified Bot Defense profile.

Procedures

Configuring a Bot Defense logging profile

When you configure a Bot Defense logging profile, you select the logging options depending on the log details you want to capture. For example, you can configure the system to log requests based on the mitigation action performed on the request. To configure a Bot Defense logging profile, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to Security > Event Logs > Logging Profiles.
  2. Select Create.
  3. Type a name for the Bot Defense logging profile.
  4. For Bot Defense select Enabled.
  5. Select a log publisher. F5 recommends that you configure a remote log publisher.

    Note: For Bot Defense logging profile, only Splunk is supported as the remote log publisher. For more information, refer to K17899005: Unable to select Arcsight publisher for bot defense remote logging. For information about configuring Splunk as a remote publisher, refer to K15316506: How to send logs via High Speed Logging to Splunk.

  6. Configure the following options depending on the log details you want to capture:
    • Log Requests by Classification
    • Log Requests by Mitigation Action
    • Log Requests by Browser Verification Action
    • Log Device ID Collection Request
    • Log Challenge Failure Requests
  7. Select Create.

Assigning a Bot Defense logging profile to a virtual server

To assign the Bot Defense logging profile to a virtual server, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to Local Traffic > Virtual Servers > Virtual Server List.
  2. Select the virtual server to which you want to assign the Bot Defense logging profile.
  3. Select Policies from the Security tab.
  4. In the Log Profile section, select the Bot Defense profile from the Available list and move it to the Selected list.
  5. Select Update.

Viewing Bot Defense requests

To view the Bot Defense log messages, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to Security > Event Logs > Bot Defense > Bot Requests.
  2. In the Bot Requests section, select the individual request to review the request details.
  3. In the Request Details section, select All Details to review expanded details about the individual request.
