K000141490: F5OS remote authenticated login fails when using Group ID 0

Type
Support Solution
Published
2024-10-17
Updated
2024-10-17
Applies to
  • F5OS
  • rSeries Platforms
  • VELOS Platforms
Source
https://my.f5.com/manage/s/article/K000141490

Description

Remote user cannot login with GID=0


sshd[<pid>]: Adding buf/value pair (F5-F5OS-GID,0)

sshd[<pid>]: Adding buf/value pair (F5-F5OS-HOMEDIR,/tmp)

sshd[<pid>]: pam_loginuid(sshd:session): error: login user-name 'my_user' does not exist

sshd[<pid>]: pam_namespace(sshd:session): user unknown 'my_user'

sshd[<pid>]: pam_keyinit(sshd:session): Unable to look up user "my_user"

sshd[<pid>]: pam_unix(sshd:session): session opened for user my_user by (uid=0)

sshd[<pid>]: error: PAM: pam_open_session(): Cannot make/remove an entry for the specified session

sshd[<pid>]: fatal: login_init_entry: Cannot find user "my_user"


Environment

F5OS

Remote Authentication (TACACS+, LDAP, AD, RADIUS)

Cause


This functions as designed

Recommended Actions

Set the Group ID and use a value other than 0.

The gidNumber attribute needs to either be on the user or on a group the user is a member of. [The root role is not externally accessible via remote authentication.]


Role Group ID

admin 9000

operator 9001

resource-admin 9003

tenant-console 9100
