Description

You would like to know if the SameSite attribute can be configured for ASM TS cookies.

Environment

  • ASM cookies

Cause

None

Recommended Actions

The SameSite attribute can be added to ASM TS cookies from version 16. Refer to:

  • Bug ID 875909: Added internal parameter to address Chrome samesite default change

There are some community offerings for modifying BIG-IP cookies to add the SameSite attribute, for example:

  • iRule to set SameSite for compatible clients and remove it for incompatible clients (LTM|ASM|APM) DevCentral

The iRule referenced in the article above will not work for ASM cookies that are generated by JavaScript.

Note: iRule solutions are not explicitly supported by F5 Support, and should be thoroughly tested before implementation in a production environment.

Additional Information

The SameSite attribute allows for declaring whether a cookie should be restricted to a first-party / same-site context by browsers. This is effective in mitigating cross-site request forgery (CSRF) attacks that involve cookies.

From version 14 onwards, the SameSite attribute can already be added for cookies set by the application if those cookies are added to the ASM security policy.
