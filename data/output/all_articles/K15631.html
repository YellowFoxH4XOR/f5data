Known Issue

The BIG-IP system may log an error message for every request. This issue occurs when all of the following conditions are met:

  • A virtual server is passing long-lived connections.
  • A local traffic policy that enables the BIG-IP ASM system is associated with the virtual server.
  • The same local traffic policy is then removed from the virtual server.

When you associate a local traffic policy that enables the BIG-IP ASM system with a virtual server, the system automatically assigns a corresponding websecurity profile. Similarly, when you remove the local traffic policy from the virtual server, the system automatically removes the websecurity profile. When this issue occurs, the system applies the local traffic policy to the virtual server but fails to properly apply the websecurity profile to the long-lived connections. When the local traffic policy is subsequently removed from the virtual server, the system continues to partially apply the websecurity profile. As a result, the system logs an error message for every request.

Impact

An error message is logged for every request. Performance may be impacted depending on the intensity of the logging.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H460166 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP system logs an error message similar to the following example to the /var/log/ltm file for every request:

    016e0002:3: Execution of action 'asm enable policy=/Common/myasmtestpolicy rule=catchall_asm action-id=0 policy=/Common/mypolicy' failed, error ERR_UNKNOWN'.
