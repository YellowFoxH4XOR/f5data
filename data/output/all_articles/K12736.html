K12736: The ARX system requires an ICMP response from the default gateway

Topic

When you configure a default route on an ARX system, the ARX system sends an ICMP Echo (ping) request to the IP address that the system configured as a default route. The ARX system expects an ICMP Echo (ping) reply from the default route device. If the ARX system does not receive an ICMP response, the system deletes the default route from the route table.
