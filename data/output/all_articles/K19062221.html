Description

When observing high throughout across the system, you can view the throughput statistics with the approach described within K50309321: Viewing BIG-IP system throughput statistics. However, there may be a further desire to identify which virtual server has the highest throughput and this article covers what options offer that capability. 

Environment

  • Virtual Servers configured to process traffic
  • BIG-IP versions: 12.x - 16.x

Cause
None.

Recommended Actions

  • Using the bigtop utility
  • Using SNMP MIBs

Using bigtop utility
The bigtop utility offers some level of insight on a per-VS basis and you can view it by running the following command from the bash prompt:
bigtop

For more insight into the bigtop utility: K7318: Overview of the bigtop utility

Using SNMP MIBs
There are some MIBs within /usr/share/snmp/mibs/F5-BIGIP-LOCAL-MIB.txt file that consists of the desired information. The F5-BIGIP-LOCAL-MIB.txt file contains several MIBs and the following queries returns the desired throughput related information:

Note: To obtain the virtual server throughput statistics using the below OIDs, use the approach described in the Use SNMP to view throughput statistics section of K50309321: Viewing BIG-IP system throughput statistics.

snmpwalk 127.0.0.1 -c public -v2c F5-BIGIP-LOCAL-MIB::ltmVirtualServStatClientBytesIn
snmpwalk 127.0.0.1 -c public -v2c F5-BIGIP-LOCAL-MIB::ltmVirtualServStatClientBytesOut

For example, here is what the query looks like when running it locally from the device:

[johnsmith@bigip:Active:Standalone] config # snmpwalk 127.0.0.1 -c public -v2c F5-BIGIP-LOCAL-MIB::ltmVirtualServStatClientBytesIn
F5-BIGIP-LOCAL-MIB::ltmVirtualServStatClientBytesIn."/Common/HTTP_Virtual" = Counter64: 101034634
F5-BIGIP-LOCAL-MIB::ltmVirtualServStatClientBytesIn."/Common/Test_Virtual" = Counter64: 104974407
[johnsmith@bigip:Active:Standalone] config #

[johnsmith@bigip:Active:Standalone] config # snmpwalk 127.0.0.1 -c public -v2c F5-BIGIP-LOCAL-MIB::ltmVirtualServStatClientBytesOut
F5-BIGIP-LOCAL-MIB::ltmVirtualServStatClientBytesOut."/Common/HTTP_Virtual" = Counter64: 2614623602
F5-BIGIP-LOCAL-MIB::ltmVirtualServStatClientBytesOut."/Common/Test_Virtual" = Counter64: 2705177361
[johnsmith@bigip:Active:Standalone] config #

You can retrieve the corresponding numeric OID value for the above string names with the following snmptranslate command:

[johnsmith@bigip:Active:Standalone] config #snmptranslate -On F5-BIGIP-LOCAL-MIB::ltmVirtualServStatClientBytesIn
.1.3.6.1.4.1.3375.2.2.10.2.3.1.7
[johnsmith@bigip:Active:Standalone] config #

[johnsmith@bigip:Active:Standalone] config #snmptranslate -On F5-BIGIP-LOCAL-MIB::ltmVirtualServStatClientBytesOut
.1.3.6.1.4.1.3375.2.2.10.2.3.1.9
[johnsmith@bigip:Active:Standalone] config #

There are other fields such as ltmVirtualServStatClientPktsIn, ltmVirtualServStatClientPktsOut etc that can be utilized, if desirable. Moreover, the above test was ran locally from the BIG-IP itself; however, you can change that depending on what device you are polling from in order to give you the throughput information.
