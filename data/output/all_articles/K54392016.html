K54392016: Querying BIG-IQ for a list of managed devices using iControl REST

Type
Knowledge
Published
2020-03-10
Updated
2025-04-02
Applies to
  • BIG-IQ
Source

Topic

You should consider using this procedure under the following condition:

  • You want to query the BIG-IQ system for a list of managed devices using the iControl REST API.

Description

You can use the iControl REST API to perform many tasks on the BIG-IQ system. For example, you may want to query the BIG-IQ system for a list of BIG-IP devices it manages. You can do so by sending a request to the /mgmt/shared/resolver/device-groups/cm-bigip-allBigIpDevices endpoint. The BIG-IQ system returns a list of managed devices that includes many attributes of these managed devices. You can limit the attributes that you want to display by specifying the attributes using the jq utility.

curl and jq utilities

Performing the following procedure requires command line access to a system with the curl utility and optionally, the jq (command line JSON processor) utility installed. These utilities are commonly available on Linux systems, but you can install them on Microsoft Windows and Mac OS X systems. Additionally, you can perform this procedure from a BIG-IQ system.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Your BIG-IQ system is licensed and configured with a management IP address.
  • You have administrative access to the BIG-IQ system interface.
  • You have command line access to a system with the curl and jq utilities. If you do not have one, you will need to use the BIG-IQ command line to perform the procedure.

Procedures

Querying the BIG-IQ system for a list of managed BIG-IP devices

You can use the iControl REST API to query the BIG-IQ system for a list of managed BIG-IP devices. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Obtain a BIG-IQ authentication token. For more information, refer to K04452074: Overview of using the BIG-IQ system authentication token.
  3. To store the BIG-IQ authentication token, create a shell variable named f5token using the following command syntax:

    f5token=<BIG-IQ authentication token obtained in step 2>

    Note: The authentication token has a timeout of 300 seconds, so you may need to repeat this step. Alternatively, you can use the following command substitution syntax to assign the f5token variable:

    f5token=$(curl -ks -X POST -d '{"username":"admin", "password":"<password>"}' https://<BIG-IQ IP address>/mgmt/shared/authn/login | jq .token.token)

    • Replace <password> with the BIG-IQ system admin user password.
    • Replace <BIG-IQ IP address> with the BIG-IQ system management IP address.
  4. To query for a list of devices managed by the BIG-IQ system, use the curl utility:

    curl -ks -H "X-F5-Auth-Token: $f5token" https://<BIG-IQ IP address>/mgmt/shared/resolver/device-groups/cm-bigip-allBigIpDevices/devices/ | /usr/bin/jq -M .

    • Replace <BIG-IQ IP address> with the BIG-IQ management IP address.

  5. If you want to limit the displayed attributes, you can specify the attributes using the jq utility. For example, if you want to display only the hostname, managementAddress, version and machineId of the managed devices, you can modify the query from step 4 as follows:

    curl -ks -H "X-F5-Auth-Token: $f5token" https://<BIG-IQ IP address>/mgmt/shared/resolver/device-groups/cm-bigip-allBigIpDevices/devices/ | /usr/bin/jq '.items[] | {hostname: .hostname, managementIP: .managementAddress, version: .version, machineID: .machineId}'

    • Replace <BIG-IQ IP address> with the BIG-IQ management IP address.
