Topic

This article applies to BIG-IP 9.x - 10.x. For information about other versions, refer to the following article:

  • K13083: Configuring syslog settings from the command line (11.x - 13.x)

The BIG-IP LTM Configuration utility supports basic syslog configurations, such as defining system log levels.

In BIG-IP 9.0.0 - 9.4.1, you may use the Configuration utility to configure basic logging. To perform more extensive syslog-ng customizations, you may use a text editor to manually edit the /etc/syslog-ng/syslog-ng.conf file. To load the new syslog configuration into system memory, you must run the bigstart restart syslog-ng command.

Starting in BIG-IP 9.4.2 - 10.x, you may use the Configuration utility to configure basic logging. To perform more extensive syslog-ng customizations, you may use the bigpipe syslog command.

Note: BIG-IP 9.4.2 and later do not support manually editing most UNIX configuration files, such as the syslog-ng.conf file. For more information, refer to K8436: Overview of UNIX configuration files (9.x - 10.x).

Note: For a list of configurable syslog settings, refer to the syslog man page or the BIG-IP Command Line Interface Guide. For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Examples of bigpipe syslog commands

  • To list the current syslog configuration, type the following command:

    bigpipe syslog list all

    Note: The log levels displayed in the output of the bigpipe syslog list all command do not apply to remote syslog servers. For more information, refer to K11723: Filtering log messages sent to remote syslog servers (9.4.x - 10.x).

  • To list the lowest level of cron messages to include in the system log, type the following command:

    bigpipe syslog cron from

  • To list the highest level of cron messages to include in the system log, type the following command:

    bigpipe syslog cron to

  • To display the syslog help page, type the following command:

    bigpipe syslog help

  • To configure the IP address of a remote server to which syslog sends messages, use the following command syntax for BIG-IP 9.x:

    bigpipe syslog remote server <IP_addr>

    Note: Beginning in BIG-IP 10.0.0, the bigpipe syslog command syntax was modified to permit the management of multiple remote syslog servers. For more information, refer to K10057: Syntax change for the 'bigpipe syslog remote server' command.

    For example, to configure the BIG-IP system to send syslog messages to a remote server with the IP address of 1.1.1.1, type the following command:

    bigpipe syslog remote server 1.1.1.1

    Note: In BIG-IP 9.x, the bigpipe syslog command allows the addition of only one remote syslog server. However, the syslog-ng facility allows for multiple remote syslog servers. For more information, refer to K8259: The bigpipe syslog remote server command may only be used to add a single remote UDP syslog server.

  • To remove all configured syslog servers in BIG-IP 9.x and 10.x, type the following command:

    bigpipe syslog remote server none

  • To remove a single syslog server in BIG-IP 10.x, type the following command, where <name> is the object name you specified when adding the remote syslog server:

    Note: The following command applies to only BIG-IP 10.x, since the bigpipe syslog command allows the addition of only one remote syslog server in BIG-IP 9.x.

    bigpipe syslog remote server <name> delete

  • To configure the port number of a remote server to which syslog sends messages, use the following command syntax:

    bigpipe syslog remote port <port_number>

    Note: The default port number is 514.

  • You must save any changes you made with the bigpipe syslog command in order for the changes to persist after a configuration reload. To save changes you made to the syslog configuration, use the following commands:

    BIG-IP 9.4.2 - 10.2.1:

    bigpipe save

    BIG-IP 10.2.2 and later:

    bigpipe save all
