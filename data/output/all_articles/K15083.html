Known Issue

The BIG-IP system may generate extraneous Deterministic NAT (DNAT) log messages.

This issue occurs when all of the following conditions are met:

  • Your system uses a carrier-grade network address translation (CGNAT) virtual server with a Large Scale NAT (LSN) pool that is configured for Deterministic mode.
  • The CGNAT virtual server processes connections.

Impact

The BIG-IP system generates extraneous DNAT log messages.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system generates extraneous DNAT log messages.
  • You observe DNAT log messages that indicate a configuration change without any corresponding DNAT configuration change. For example:

    DNAT configuration: lsn: time=1234567890 name=/Common/NAT44 min=1234 max=65000 why=change
