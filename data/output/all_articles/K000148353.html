K000148353: Unable to restore UCS from vCMP guest into multi blade tenant

Type
Support Solution
Published
2024-11-01
Updated
2024-11-01
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148353

Description

You are experiencing an issue trying to restore a UCS (User Configuration Set) archive from a BIG-IP vCMP (Virtual Clustered Multiprocessing) guest that has only one blade allocated. When attempting to restore this UCS into a new BIG-IP tenant with multiple blades allocated, unexpected errors occur, and the UCS will not successfully load.

Environment

  • Restoring UCS from a single-blade vCMP guest
  • Attempting to load UCS into a multi-blade tenant

Cause

  • Not supported

Recommended Actions

  • When using a UCS to migrate a configuration from a vCMP guest that only has one blade, try restoring the UCS to a tenant with a single blade.
