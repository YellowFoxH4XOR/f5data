Description

Edge Client version is not available in logs.
Variable session.client.version is not populated.

Environment

  • Edge Client is used for VPN connections
  • APM log level is set to "notice"

Cause

Variable session.client.version is not populated in logs while APM log level is set to "notice".
This is expected behavior. 

Recommended Actions

Setting the log level to Debug can adversely impact system performance.
If you want to know what is Edge Client version, follow below steps:

  1.  Create iRule and attach it to Virtual Server. Below iRule example will also collect User-Agent information:

    # This event fires once per session
    when ACCESS_SESSION_STARTED {
      log local0. "Setting User-Agent based on HTTP data - [HTTP::header User-Agent]"
      ACCESS::session data set session.custom.useragent [HTTP::header User-Agent]
      #Use this variable in the VPE to make some decision
    }

  2. Add Message Box in VPE, ex:

    Your User-Agent and Edge Client information is %{session.custom.useragent}

  3. All information gathered by iRule will be displayed before connecting to VPN.
