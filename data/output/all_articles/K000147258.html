Description

  • How much can I customize custom block pages?
  • Can I pull in style sheets and other things?
  • Can I do a mail to link with the support ID?
    • This would make it possible to just click on the support ID and it opens up an email with the Support ID in it.

Environment

  • F5 Distributed Cloud Load Balancer
  • F5® Distributed Cloud Console

Answer/Recommended Actions

  • We support two formats of blocking pages: HTML and JSON.
    • If you use the HTML format, you can design it like any other HTML page. Just note that we have 4kb size limit.

  • You can create inline styles or even provide a link to the external css file assuming that css file is accessible through the web. We don't let you upload files as a part of Custom blocking page configuration.

  • You can do a mail to link with the support ID by customizing my blocking page to be:

    • <html><head><title>Request Rejected</title></head><body>The requested URL was rejected. Please consult with your administrator.<br/><br/><a href = "mailto:my-user@example.com?subject=Feedback&body=Why my request is rejected, request id is {{request_id}}%0D%0AThanks,%0D%0AJohnDoe">
Send Feedback...
</a></body></html>
    • %0D%0A in above custom page is the line break. 
    • We replace only first occurrence of request id placeholder {{request_id}}.
    • If you want to use it more than once, please, define javascript variable.
