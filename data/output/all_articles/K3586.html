Topic

Note: To configure SSL persistence, you must configure a pool, or use a previously configured pool, that contains SSL nodes.

You can configure SSL persistence using the Configuration utility or the command line.

Configuration utility

To configure SSL persistence from the Configuration utility, perform the following steps:

  1. From the menu, click Pools.
  2. Click the pool name for you want to configure persistence.
  3. Click the Persistence tab.
  4. Click the SSL button.
  5. In the timeout field, enter the a desired timeout.
  6. Click Apply.

Command line

To configure SSL persistence from the command line, type following command:

bigpipe pool <pool_name> {persist ssl ssl_timeout }

For example:

bigpipe pool AskF5Pool {persist ssl ssl_timeout 900}

For more information on SSL Persistence, refer to the BIG-IP Reference Guide and K3245: Best practice: Using SSL (Session ID) persistence.
