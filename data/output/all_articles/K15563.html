Known Issue

The Large Scale NAT (LSN) pool port translation configuration is not honored for CGNAT (carrier-grade network address translation) RTSP (Real Time Streaming Protocol) ALG connections.

This issue occurs when the following condition is met:

  • A CGNAT virtual server is associated with an RTSP ALG profile and an LSN pool.

Impact

RTSP media flow connections may use port translations outside of the configured port range for the LSN pool.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H473334 on the Diagnostics > Identified > Medium screen.
  • Established RTSP media connections use ports that are not consistent with the CGNAT LSN pool configuration.
  • You receive incorrect or no results when reverse-mapping an RSTP media flow.
