Description

  • Customer unable to License the F5 Viprion Appliance due to swap of the faulty primary blade
  • This license has already been activated on a different unit. Please contact technical support for assistance
  • Error 51092

Environment

  • F5 Viprion had primary blade replaced via RMA due to being faulty.
  • Big-IP LTM

Cause

The root cause was that the base registration key for the BIG-IP LTM device was still associated with another device or previous instance (Faulty Blade), resulting in an error that prevented re-licensing.

Recommended Actions

  1.  Raise case with Support team to release key for re-licensing.

Additional Information

Issue occurs when Master blade is faulty and gets replaced via RMA.
