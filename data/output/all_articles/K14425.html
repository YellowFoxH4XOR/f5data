Issue

Error Message

crit smartd[PID]: Device: /dev/<sda|sdb>, <#> Currently unreadable (pending) sectors

In this error message, note the following:

  • [PID] is the smartd process ID
  • <sda|sdb> is the affected drive identifier
  • <#> is the number of unreadable sectors

For example:

crit smartd[4652]: Device: /dev/sda, 1 Currently unreadable (pending) sectors

Message Location

You may encounter this message in the following location:

  • The /var/log/daemon.log file

Description

This message occurs when one of the following conditions is met:

  • A drive encounters a fully-recoverable read error
  • A drive has a bad sector or experiences a failure

This error message is not always indicative of a true disk failure, but more often indicates a period when the disk is too busy to service an active read request.

Impact

Disk errors may be incorrectly interpreted as a sign of disk failure.

Recommended Actions

If you suspect a possible disk failure, you can perform the End-User Diagnostic (EUD) SMART test to test the drive. For information about the EUD utility and links to the latest release notes, refer to K7172: Overview of the End User Diagnostics software.

Additionally, BIG-IP 11.4.0, 11.3.0 HF-6, 11.2.1 HF-8, and 10.2.4 HF-7 include improvements to hard drive error detection and correction, and improved messaging to identify uncorrectable errors that are indicative of a disk failure. F5 tracked these improvements as ID 405839.
