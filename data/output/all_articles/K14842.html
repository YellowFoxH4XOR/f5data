Known Issue

Access profile availability time restriction may not be enforced as expected.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP APM access profile Advanced Resource Assign setting to use time-based restrictions, based on the days of the week.
  • You select Sunday as part of the time-based access restrictions for the Advanced Resource Assign setting.

Impact

The BIG-IP APM access profile time-based restrictions are not enforced as expected.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You can access the access profile resources on Sundays, when the configuration is set to restrict access on Sundays.
  • You cannot access the access profile resources on Sundays, when the configuration specifically allows access on Sundays.

Workaround

To work around this issue, you can use the visual policy editor to manually modify the time-based expression to correctly identify Sundays. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Click Access Policy.
  3. Click Access Profiles.
  4. Locate the affected access policy.
  5. In the Access Profile column, click Edit.
  6. Click the Advanced Resource Assignment box that contains the time-based access restriction configuration.
  7. Click the Branch Rules tab.
  8. To the right of the time-based expression, click the change link.
  9. Click the Advanced tab.

    A time-based expression displays, similar to the following example:

    expr { [clock format [mcget {session.user.starttime}] -format %u] == 6 || [clock format [mcget {session.user.starttime}] -format %u] == 0 }

  10. For the expression [clock format [mcget {session.user.starttime}] -format %u] == 0 modify the value of 0 (zero) to 7.

    For example, a modified expression appears similar to the following:

    expr { [clock format [mcget {session.user.starttime}] -format %u] == 6 || [clock format [mcget {session.user.starttime}] -format %u] == 7 }

  11. Click Finished.
  12. Click Save.
  13. In the upper-left corner, click the Apply Policy notification.
