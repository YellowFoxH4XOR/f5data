Description

In certain situations you must reinitialize the Big-IQ Postgres database.

Important: This should only be performed when directed to by a prior article or by F5 Support.

Environment

  • Big-IQ ≥ 7.1

 

Procedure

Important: This Procedure removes Postgres database in which BIG-IQ stores configuration, managed devices etc. Please use it carefully! and doublecheck with support if you are not sure if this is potential resolution of your problem  

  1. Login to the device as root 
    # ssh root@<device ip>
  2. Stop PostgreSQL daemon 
    # tmsh stop sys service postgres
  3. Delete PostgreSQL database files 
    # /bin/rm -rf /var/lib/pgsql/data
  4. Start PostgreSQL service. This step also re-creates the data directory. 
    # tmsh start sys service postgres
  5. Check PostgreSQL service 
    # tmsh show sys service postgres
  6. Confirm PostgreSQL is allowing SSL connection 
    # export PGSSLMODE=require; pg_isready -h localhost
  7. Regenerate cert for the device 
    # ha_generate_certs -f <Discovery IP / Self IP>
  8. Clear the REST database 
    # clear-rest-storage
