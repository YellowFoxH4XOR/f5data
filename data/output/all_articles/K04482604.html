Description

  • At a time of SSL VPN tunnel creation, DNS server records get updated with local IP

Environment

  • APM
  • Edge Client 
  • Windows machine
  • DNS server 

Cause

  • DNS update is not triggered by the BIG-IP, it's triggered by the client machine - Windows
  • The Edge Client only enables the option for the client to register the lease pool address in the DNS server.
  • In fact, there are no options on the BIG-IP Edge Client relating to local Interface IP and DNS server.
  • Meaning, it is the Windows client that controls whether or not the client registers it's local Interface IP's to the DNS server.

Recommended Actions

  • Consult Windows Administrator
    -- or --
  • Disable the Register this connection's addresses option on the client machine

Additional Information

Should a new DNS entry be created referencing local IP address and client's FQDN?

  • The feature responsible for dynamically registering new name/IP address entry on the DNS server is called "Register this connection's addresses in DNS" (also know as, dns-register-connection true)
  • If enabled/checked then the DNS server will register the lease pool address in the DNS server.
  • You can locate Register this connection's addresses in DNS on the server by navigating to
    1. Control Panel > Network and Internet  > Network Connection > right click on the interface
    2. Click Properties
    3. Select Internet Protocol Version 4 (TCP/IPv4) > Advanced
    4. Under DNS suffix for this connection you find the option to enable or disable the Register this connection's addresses in DNS feature

Important: We only enable the option for the client to register the lease pool address in the DNS server
