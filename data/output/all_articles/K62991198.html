K62991198: BIG-IQ DCD Warning: Statistics overflow protection detected

Support Solution
Published
2021-08-20
Updated

Source
https://my.f5.com/manage/s/article/K62991198

Description
A Data Collection Device (DCD) can display a warning message of "statistics overflow protection detected."

Environment

  • BIG-IQ CM and associated DCDs

Cause
The number of indices on a DCD are above the configured retention policy, meaning that the post-aggregator service may not be running properly.  Rather than allowing indices to accumulate beyond acceptable rates, the DCD has stopped writing statistic files until the problem can be investigated.

Recommended Actions

Resolving the ES cluster and indices to a healthy state would resolve the issue.
  1. If the ES cluster status is red, refer to article K05058711 to delete the red indices.
  2. If the ES cluster status is green but the issue still persist, open a case with F5 Network Support.

Additional Information
When the warning appears, check to see if the ES Cluster Health status is red and multiple ES Indices are also red. Run the following commands on the BIG-IQ CM to view the status:

BIG-IQ 8.0.0 and later:
curl -k -u admin:admin https://localhost:9200/_cluster/health?pretty
curl -k -u admin:admin https://localhost:9200/_cat/indices?v

BIG-IQ 7.1.0 and earlier:
curl -s localhost:9200/_cluster/health?pretty
curl -s localhost:9200/_cat/indices?v
