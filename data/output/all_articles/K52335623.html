Known Issue

Reloading the IP reputation database may cause the Traffic Management Microkernel (TMM) to restart and produce a core file with a SIGABRT message.

This issue occurs when all of the following conditions are met:

  • The IP Address Intelligence Service is enabled.
  • The IP reputation database is reloaded.
Reloading the IP reputation database may cause the sod process to miss a failover heartbeat. As a result, the sod process signals the TMM process to abort and restart.

Impact

The BIG-IP system may temporarily fail to process traffic while TMM restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The TMM process produces a core file with a SIGABRT message.
  • A BIG-IP system in a high-availability configuration fails over to the peer system.
  • The BIG-IP system generates a TMM core file in the /var/core directory.
  • The system logs daemon heartbeat action error messages to the /var/log/ltm file that appear similar to the following example:

    notice sod[PID]: 01140029:5: HA daemon_heartbeat tmm1 fails action is go offline down links and restart.
  • The BIG-IP system logs an error message to the /var/log/tmm file that appears similar to the following example:

    notice ** SIGABRT **
