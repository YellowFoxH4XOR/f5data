K000140409: How to configure Memory Hugepages for DNS Express to support large DNS zones

Type
Support Solution
Published
2024-07-23
Updated
2024-07-23
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000140409

Description

The support for large DNS zones is not enabled by default, and requires tuning a number of related database variables.

 

Environment

  • BIG-IP DNS
  • Large DNS Zones
  • Memory Huge pages

Cause

You want the DNS Express to store the large DNS zone data in huge memory pages of 2MB each instead of regular memory page sizes.

 

Recommended Actions

Note: F5 recommends performing the change during a scheduled maintenance window appropriate for your environment.

  1. Check the size of the large zone file. 
    du -sh /shared/zxfrd
  2. Stop the ZXRFD process 
    bigstart stop zxfrd
  3. Use the command below to verify free hugepages. 
    cat /proc/meminfo | grep --ignore-case -e 'huge' -e 'filepmd' | grep --invert-match 'Shmem'

    AnonHugePages:     0 kB

    HugePages_Total:  10254

    HugePages_Free:    0      <<<===---!!!

    HugePages_Rsvd:    0

    HugePages_Surp:    0

    Hugepagesize:    2048 k

     

  4. Make sure the hugepages (RAM) usage location is zero. 
    du -sh /dev/mprov/zxfrd/
    1. Free up hugepages if its occupied/used. 
      rm -f /dev/mprov/zxfrd/*
  5. Refer to K54670218 to calculate the the hugepages needed based on the large DNS zone file.

    For example: Based on 1.8G large DNS zone file, we round up to 2G to cater for growth.

       2 * 2.5 = 5

       (5 * 1024) / 2 = 2560

  6. Modify DNS Express Hugepages db key.  
    tmsh modify sys db dnsexpress.hugepages value 2560
tmsh modify sys db dnsexpress.persisthugepages value true
tmsh save sys config
bigstart restart tmm
  7. Start the ZXRFD process. 
    bigstart start zxfrd
  8. Verify free hugepages using the command below. 
    cat /proc/meminfo | grep --ignore-case -e 'huge' -e 'filepmd' | grep --invert-match 'Shmem'

    AnonHugePages:     0 kB

    HugePages_Total:  10254

    HugePages_Free:    1773  <<<===--- This shouldn't reach zero (0). Else zxfrd will restart. 

    HugePages_Rsvd:    0

    HugePages_Surp:    0

    Hugepagesize:    2048 k

     

    Note: In future, if the zone file size increases, the next action is to repeat all the steps again with higher dnsexpress.hugepages value.
