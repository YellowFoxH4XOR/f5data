Description

  • imish daemon crashes when checking the help strings of "(no) neighbor x.x.x.x fall-over bfd ?"
  • Once the '?' question mark is typed, there's a few second pause, with no help output.
  • There may be a core file for imish in the /var/core/ directory.
Note : This should not impact traffic.
 

Environment

  • BigIP running Advanced Routing Module (ARM)
  • BGP is enabled
  • Bidirectional Forwarding Detecting (BFD) is to be queried

Cause

It is triggered by requesting the help info for the following command (example Neighbour IP Address of 192.168.1.10):

(config-router)# neighbor 192.168.1.10 fall-over bfd ?
or
(config-router)# no neighbor 192.168.1.10 fall-over bfd ?
 

Recommended Actions

  1. Avoid using '?' while entering the above sub command
