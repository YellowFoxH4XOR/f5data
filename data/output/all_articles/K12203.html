Known Issue

This is the result of a known issue. A BIG-IP system licensed with a Load Balancer Limited (LBL) license does not publish its virtual server, profile, or pool configurations when queried by the Enterprise Manager system. As a result, the Enterprise Manager Configuration Viewer will not display the virtual servers, profiles, or pools for this BIG-IP system. When this issue occurs, the log entries in the /var/log/em file may appear similar to the following example:

err emdeviced[PID]: 04010539:3: WARNING: Dependency Local Traffic / Pool / <pool name> not found in any partition
err emdeviced[PID]: 04010538:3: WARNING: Dependency Local Traffic / Pool / <pool name> that should be in the Common partition not found

F5 Product Development tracked this issue as ID 337660, and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue was fixed in hotfixes issued for BIG-IP versions 9.4.7 and 9.4.8. Customers affected by this issue should contact F5 Technical Support, referencing this Solution number and the associated ID number, to request the hotfix.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.
