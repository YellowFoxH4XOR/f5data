Description

F5 publishes a document called "F5OS Error Catalog Reference" for f5os-a-1.5.1-errors, to allow evaluation of log messages.

Some log messages in this document may indicate it has "impact: None" and "recommended_action: None."
Customers may notice these types of message in system logs and seek clarification regarding its impact and recommended actions. 
According to the F5OS error catalog, some of these message can be logged at the LOG_ERR level, but is documented as having no impact on system operation.

Environment

  • Product: F5OS (F5 Operating System), specifically referenced in the rSeries platform
  • Version: F5OS-A 1.5.1 (as per error catalog reference)
  • Related Product: BIG-IP LTM 17.1.1 (in this specific document)
  • Log Message marked as "recommended_action: None."
  • No specific configuration changes or actions required to trigger this message

Cause

The specific log messages are an informational, minimally-impactful event even though is sent to syslog as an LOG_ERR. It is generated when specific condition is reported, but this does not affect the overall operation or functionality of the system. It is expected that some of these logs will happen under normal operation.

Recommended Actions

  • The error message required no specific action, but should be evaluated in conjunction with any other log messages or counters.

Additional Information

The F5OS error catalog explicitly states that this error has "impact: None" and "recommended_action: None."

  • These log messages can be at LOG_ERR level because the particular issue is individualy an error, but does not indicate a system fault or result in service disruption and may be mitigated by normal operation.
  • Users can safely ignore this message unless additional symptoms or issues are observed.
  • When evaluating these messages you should consider associated log messages and counters. If there are specific combinations or errors (or higher failure logs) that are of concern, then the specific logs, the particular configurations and environment be escalated for support.
