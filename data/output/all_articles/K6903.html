Known Issue

This is the result of a known issue. The BIG-IP LTM iRule utility functions are commands that transform information and return the result in the desired format. Under certain conditions, the iRule utility function, sha1, returns partial hash values. This causes iRules that use the sha1 function,which verify data integrity, to return incorrect values.

F5 Product Development tracked this issue as CR70115 and CR70114, and it was fixed in BIG-IP LTM version 9.1.3 and 9.3.0. For information about upgrading, refer to the BIG-IP LTM release notes.
