Known Issue

If the LDAP server that is used for authentication does not support the pagedResultsControl extension, users will be unable to successfully authenticate. For example, the Sun Directory Server Enterprise Edition does not support the pagedResultsControl extension; other LDAP servers may have the same issue. When a user attempts to authenticate, they may receive the following error message:

unavailable critical extension

The authentication failure occurs because the BIG-IP APM system marks the pagedResultsControl extension for criticality to true by default. If the LDAP server does not support the extension, the LDAP query is unsuccessful. In accordance with RFC2696, the default value for criticality should be set to false.

F5 Product Development tracked this issue as ID 226444 (formerly CR141503) and was fixed in BIG-IP APM 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

This issue has been fixed in Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
