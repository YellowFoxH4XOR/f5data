K000147205: Troubleshooting HTTP 408: request_overall_timeout

Description

You received an an HTTP 408 error with the name of "request_overall_timeout".

Environment

  • F5® Distributed Cloud HTTP Load Balancer

Cause

A 408 error response code is returned if a client is subject to Slow DDoS Mitigation that has been enabled on the load balancer.

Answer/Recommended Actions

This HTTP error can only be seen if you have enabled the option Slow DDoS Mitigation on your HTTP Load Balancer. And the default timeout is 60s.

Additional Information

  • This specific detail (request_overall_timeout) implies that there is a timeout setting on the proxy server dictating how long it should wait for a complete client request to be received.
  • If the client fails to send a request within this allotted time frame — for example, if the client starts to send a request but then pauses or sends data too slowly (this can be also applicable to large Downloads) — the proxy will terminate the attempt and return an HTTP 408 error, indicating that the client took too long to complete the request.
