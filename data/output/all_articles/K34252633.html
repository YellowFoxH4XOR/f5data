Issue

Description

You try to connect to BIG-IP APM Network Access using F5 Access on Windows, but your attempts fail. You receive an error from F5 Access similar to the following:

Can't connect to vpn.example

Failed to establish VPN connection

To enable debug logging and gather diagnostic data in the Windows Event Viewer log, navigate to the following location:

  • Event Viewer > Applications and Services Logs > Microsoft > Windows > Vpn Plugin Platform > OperationalVerbose

    Note: For more information, refer to  K52136253: Enabling debug logging and gathering diagnostic data for F5 Access client on Windows 10.

After you do so, the system displays errors similar to the following:

  • Message 1, \UHTTPClientStoreApp.h, 230, AppStoreHttpClient::makeRequest, AppStoreHttpClient::makeRequest EXCEPTION, 0xffffffff80072f06, The text associated with this error code could not be found. The host name in the certificate is invalid or does not match
  • Information, Microsoft-Windows Networking VPN Plugin Platform,2004,None,"Message from VPN App: [vpn.example.com] 1, [...] The text associated with this error code could not be found. The certificate authority is invalid or incorrect
Note: You may find it easier to view the logs in Windows Event Viewer if you save them as a text file by navigating to the OperationalVerbose logs and then selecting Save All Events As.

Environment

  • Connecting to BIG-IP APM Network Access with F5 Access on Windows

Cause

  • The hostname/URL configured in the certificate in the Client SSL profile of the BIG-IP virtual server does not match the Server name or address configured in F5 Access.
  • The certificate configured in the Client SSL profile of the BIG-IP virtual server is not trusted on the Windows client.

Recommended Actions

  • The Issued to: value of the certificate used in the Client SSL profile of the BIG-IP virtual server must match or include the server name or address value in the F5 Access configuration. On the Windows client device, do the following:
    1. Open F5 Access by clicking Start and typing the following: F5 Access.
    2. Click Manage VPN Connections.
    3. Select the appropriate VPN connection profile.
    4. Click Advanced options.
    5. Click Edit.
    6. In Server name or address, enter a value that matches or is included by the certificate used in the Client SSL profile of the BIG-IP virtual server.

      For example, if the certificate is issued to *.example.com, you enter: host.example.com

  • The certificate configured in the Client SSL profile of the BIG-IP virtual server must be trusted by the Windows client. On the Windows client device, do the following:
    1. Copy the certificate or certificate authority certificate configured in the Client SSL profile of the BIG-IP virtual server to the client device.
    2. Right click on the certificate.
    3. Select Install Certificate.
    4. Select Current User and click Next.
    5. Select Place all certificates in the following store.
    6. Click Browse.
    7. Select Trusted Root Certification Authorities.
    8. Click OK.
    9. Click Next and Finish.

For more information about how to generate certificates, refer to K14499: Using OpenSSL to create CA and client certificates (11.x - 14.x).

Additional Information

  • When the same VPN URL is accessed from the web browser, the user should not see an SSL warning.
  • The list of certificates in the Trusted Root Certification Authorities store can be verified by performing the following steps on the Windows client device:
    1. Click Start
    2. Type the following: certmgr.msc.
    3. Click certmgr.msc.
    4. Navigate to Certificates - Current User > Trusted Root Certification Authorities > Certificates.
