Known Issue

This is the result of a known issue. A memory leak may occur when the BIG-IP ASM processes HTTP 100 Continue traffic and one of the packets triggers a blocking violation.

The BIG-IP ASM stalls while closing the event that triggered the blocking violation, and does not not immediately release the resources. This behavior results in a memory leak, which may eventually cause the BIG-IP ASM bd process to core.

F5 Product Development tracked this issue as CR124349 and it was fixed in BIG-IP ASM 9.4.8 and 10.1.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, Hotfix-BIGIP-10.0.1-342.0-HF1, has been issued for BIG-IP 10.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
