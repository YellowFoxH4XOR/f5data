Known Issue

This is the result of a known issue. When you configure a Foundry host and then configure SNMP probing to detect the virtual servers, 3-DNS detects and adds additional virtual servers. These additional virtual servers use the same IP addresses as the actual virtual servers, but use port 65535.

These additional virtual servers are harmless, and are caused by hidden configuration items on the Foundry host.

F5 Networks Product Development tracked this issue as CR27667 and CR42071.
