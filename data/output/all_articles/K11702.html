K11702: Last header value for a Web Application resource item cannot be deleted through the web interface

Known Issue

When deleting headers from a web application resource item, you are unable to remove the last header in the list using the web administrator interface.

F5 Product Development is tracking this issue as ID 226716 (formerly CR142034).

Workaround

You can remove the header information from a web application resource item by performing the following procedure:

  1. Log on to the BIG-IP APM command line interface. You will need to log in using an account with sufficient permissions to delete resource items.
  2. Type the following command:

    #bigpipe connectivity resource web application mywebapp list

    The command output will appear similar to the following example:

    connectivity resource web application mywebapp {
    description "my web app"
    scheme patching enable
    items {
    item {
    host "www.example.com"
    ip 0.0.0.0
    mask 0.0.0.0
    order 3
    headers {
    name item1-header1
    value "1"
    }
    }
    item0 {
    host "www.example2.com"
    ip 0.0.0.0
    mask 0.0.0.0
    order 3
    headers {
    name item2-header
    value "1"
    }
    }
    }

    There are two items listed in the items group above, item and item0. Your web application may have a different number of items.

  3. From your screen, note the name of the item in which you want to delete the headers.
  4. To remove the header from the item, type the following command:

    #bigpipe connectivity resource web application mywebapp items item0 headers none

You can repeat the command in step 2 to verify that the header has been removed.
