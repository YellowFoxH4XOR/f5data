Known Issue

This is the result of a known issue. The last file in the archive file is missing when you use the Configuration utility to import an archive UCS file.

F5 Networks Product Development tracked this issue as CR53534, and it was fixed in BIG-IP LTM versions 9.1.3, 9.2, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.
