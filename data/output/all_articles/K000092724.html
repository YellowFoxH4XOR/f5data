K000092724: FEP OutOfDirectMemoryError caused by message buffers with null values.

Type
Support Solution
Published
2022-11-26
Updated
2022-11-26
Source
https://my.f5.com/manage/s/article/K000092724

Description

  • These errors are seen in the FEP logs : 

2020-11-24 06:11:49,475 WARN [10505] Internal warning: exception caught - Channel is [id: 0x7c67347d, L:/10.1.1.1:55387 - R:site-IC-bond0-eth0-eth4-v4/<CPF_IP>:13868], peer is CPFInternalPeer(site_cpf1 C Connecting_43304782707877313 Disconnected). [Silo-EventLoop-thread-3-4_23] [DestinationHandler_netty4.exceptionCaught()] io.netty.util.internal.OutOfDirectMemoryError:

 failed to allocate 16777216 byte(s) of direct memory (used: 939524096, max: 943718400)


Environment

  • SDC 5.1
  • CF versions before CF27

Cause

Message buffers with null values caused an OutOfDirectMemoryError exception. This is described in CPF-25175.


 Recommended Actions

Fixed in 5.1 CF27

None.
