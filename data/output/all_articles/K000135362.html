K000135362: iControl REST error message "DAG adjustment is not supported on this platform"

Type
Support Solution
Published
2023-07-03
Updated
2023-07-03
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000135362

Description

LTM device might issue error message "DAG adjustment is not supported on this platform", while using PUT command modifying a vlan configuration.


Environment

  • iControl REST
  • PUT command


Cause

Disaggregator (DAG) Adjustment was introduced for F5 VELOS tenants and this option is not available on other platforms. Using the PUT command, which requires strict validation of all fields, the LTM might issue the follow error message "DAG adjustment is not supported on this platform".


Recommended Actions

Do one of the following:

  • Simply add '"dagAdjustment" : "none"' to vlan json modification

Or

  • Use the PATH command instead of PUT
