Description

DNS Type 65 is a proposed standard RFC9460 for HTTPS binding. Starting from BIG-IP 17.5.0, the BIG-IP DNS system supports the configuration of Service Binding (SVCB) (Type 64) and HTTPS RR (Type 65) resource records exclusively for enabling the Oblivious DNS over HTTPS (ODoH) Target service discovery.

For information about configuring type 65 for ODoH protocol, refer to the Configuring Oblivious DNS Over HTTP (ODoH) protocol chapter of the BIG-IP DNS: Implementations guide.

There are currently no options to configure a specific response to a type 65 record for non-ODoH protocol. The following table outlines Bind Type 65 request processing responses that can be expected.

BIG-IP DNS Bind Type65 request handling
Expected Response
Existing A record in bind for requested zone
NOERROR
No A record exists in bind for the requested zone
NXDOMAIN
If there is an Alias
