Description

Article describes what is "Automatic Attack Signatures Tuning" and how it works behind the scenes.

You can find that option in APP Firewall policy details
App Firewall > Manage Configuration > Security Policy Settings:

 

Environment

  • F5® Distributed Cloud
  • Application Firewall 
  • Automatic Attack Signatures Tuning

Resolution/Answer

  • What is Automatic Attack Signatures Tuning?
    • Automatic Attack Signatures Tuning is a probabilistic learning model that identifies and suppresses (unblocks) likely false positives triggered by signature match, based on current and historical request patterns.

  • Are there any special requirements?
    • No, it's a standard configuration option available on all App Firewall objects.

  • Does this involve Heuristics or Machine Learning?
    • It's an ML model that automatically builds a dedicated heuristic for each application according to traffic patterns observed through the HTTP LB.

  • Does Auto Tune enact permanent changes to the WAF policy?
    • No, suppression of triggered signatures and unblocking apply only to discrete requests.

  • What factors are considered by the engine when making a suppression decision?
    • The engine evaluates the characteristics of the request in context of historical traffic patterns on the HTTP LB and the wider dataset on which it's trained.

  • Does it work in monitoring mode or in blocking mode?
    • It works on both monitoring and blocking mode, though its function is relevant only in blocking mode.

  • To what degree of certainty is a suppressed violation a false positive?
    • By definition, an heuristic model's determined outcome is based on probability not certainty.  As such, that a suppressed WAF violation is a false positive is highly probable but not absolute.

  • Is it possible to review exception list that is created by Automatic Attack Signatures Tuning?
    • No, currently exception list is not available in console.  

  • Is it possible to manually block requests (true negative) that were allowed by Automatic Attack Signatures Tuning?
    • No, currently we don't have an option to modify rules created by Automatic Attack Signatures Tuning.
