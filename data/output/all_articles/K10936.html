Issue

If the standalone client software becomes corrupted, users may view the following error message when launching the FirePass standalone client:

Your configuration data appears to be corrupted. Would you like to reset them to their default values?

Users must select Yes to correct the corrupted file, which empties the user's controllers list. The user must then manually reenter either the fully qualified domain name or IP address of the FirePass controller to which they want to connect. If the user selects No, the error message will appear each time they attempt to connect until they select Yes.
