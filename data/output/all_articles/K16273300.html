Known Issue

The visual policy editor may fail to render due to an access policy orphaned macrocall.

This issue occurs when all of the following conditions are met:

  • Using the BIG-IP APM visual policy editor, you create an access policy that includes a macrocall item on one of the branches.
  • Using the visual policy editor, you delete the branch that contains the macrocall of the access policy.
  • The macrocall is not referenced by any other branches of the access policy.
  • You apply the access policy and exit the visual policy editor.
  • You attempt to edit the same access policy using the visual policy editor.

Impact

The visual policy editor does not render the access policy.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to edit the access policy using the visual policy editor, the system displays an error that appears similar to the following example:

    this.pluslmg is undefined
    Loading stopped, Please refresh

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to remove access policy orphaned macrocalls. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To remove all macrocalls associated with an access policy, use the following command syntax:

    modify /apm policy access-policy <access policy name> macros replace-all-with { }

  3. To remove a specific macrocall or macrocalls, use the following tmsh command syntax:

    edit /apm policy access-policy <access policy name>

    Note: The access policy configuration will be opened in the vi text editor.

  4. Locate the following configuration line that starts with macros replace-all-with:

    For example:

    macros replace-all-with { </partition>/<macro name </partition>/<macro name> </partition>/<macro name> }

  5. Remove any orphaned macrocalls </partition>/<macro name> from the macrocalls list.
  6. Save the configuration changes by typing the following command:

    Esc :wq

  7. When the system delivers the following prompt, press y:

    Save changes? (y/n/e)

  8. Use the visual policy editor to view and edit the access policy.
