K05132534: 01070608:0: License is not operational (expired or digital signature does not match contents).

Type
Support Solution
Published
2022-02-10
Updated
2025-04-02
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K05132534

Description

Getting the following errors when applying a new registration key and activating the license:

Jan 25 10:31:42 BIG-IQ1 err tmsh[16132]: 01180001:3: License validation fails.
Jan 25 10:31:42 BIG-IQ1 err tmsh[16132]: 01180010:3: [license processing][error]: license verification failed
Jan 25 10:36:45 BIG-IQ1 emerg mcpd[4989]: 01070608:0: License is not operational (expired or digital signature does not match contents).

Environment

  • BIG-IQ or BIG-IP
  • License file bigip.license

Cause

When for some reason the license file is not copied and pasted entirely.

Recommended Actions

Verify if the license has been copied and pasted entirely and be sure that there is not missing any line, for this scenario we were missing the first 3 lines:

#
Auth vers :                        5b
#

Additional Information

K7752: Licensing the BIG-IP system
