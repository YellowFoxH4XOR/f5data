K41321052: Geolocation Database Failed to update on BIG-IQ: Failed updating devices: All subtasks failed

Type
Support Solution
Published
2022-01-25
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K41321052

Description
 

  • Not able to update Geolocation database on BIG-IP using BIG-IQ 
  • BIG-IQ Configuration Utility: Devices > GEO-IP DATABASE MANAGEMENT > Update History >  Failed.  Failed updating devices.
    Status:  Failed    Error message:  All subtasks failed
  • Same BIG-IP device updated Geolocation database successfully before.
  • May see similar log entries in /var/log/restjavad.log

    [WARN][06 Jan 2022 12:30:25 CST][/cm/device/geoip/task/push-update/cfb80236-87e2-46e9-852f-a54bd4cf98bd/worker DeviceGeoIpPushUpdateTaskWorker] GeoIP Message: DeviceGeoIpPushUpdateTaskWorker: Task [cfb80236-87e2-46e9-852f-a54bd4cf98bd] failed at step INSTALL_NEW_DB_FILES: com.f5.rest.common.CommandExecuteException: GeoIP Update Database task: Failed during remote action: Installing the new GeoIP database.
    at com.f5.rest.workers.device.geoip.task.pushupdate.DeviceGeoIpUpdateDbTask.lambda$null$6(DeviceGeoIpUpdateDbTask.java:397)
    at com.f5.rest.workers.device.subtask.tasks.SingleStepTask.executeStep(SingleStepTask.java:54)
    at com.f5.rest.workers.device.subtask.tasks.ChainedTask.beginTailTask(ChainedTask.java:182)
     

Environment

  • BIG-IQ Centralized Management
  • BIG-IQ Configuration Utility: Devices > GEO-IP DATABASE MANAGEMENT > Update History

Cause

Unknown at the time of publication.

Recommended Actions

  1. On BIG-IP:  
    bigstart restart restjavad
  2. On BIG-IQ: Rediscover devices
  3. On BIG-IQ: Update Geo-IP Database
