Description
After a reboot, license reload, or upgrade, the configuration does not load. 
In the /var/log/ltm logs, there is is entry.

01071212:3: Access Policy Item (/Common/Policy_Name_Component_Name) must have a caption.
01420006:3: Loading configuration process failed.


In the /config/bigip.conf, the configuration looks like this.

apm policy policy-item /Common//Common/Policy_Name_Component_Name {
    caption none  <<<<
    color 1
    item-type terminal-out
}

Environment

  • Access Policy
  • BIG-IP APM
  • Configuration Error

Cause
All the branches for all the components in the Virtual Policy Editor, VPE, must have a caption.

Recommended Actions

Impact of workaround: The following procedure requires editing the bigip.conf configuration file, and you should perform the procedure during a maintenance window.
  1. Log in to the Advanced shell (bash).
  2. Create a backup copy of the /config/bigip.conf file by typing the following command:
cp /config/bigip.conf /config/bigip.conf_K00954242
  1. Using a text editor such as the vi utility, open the /config/bigip.conf file for editing.
  2. Locate the line that reads caption none 
  3. Change to caption test_caption
  4. Save the changes and exit the editor.
:wq!
  1. Load the configuration by typing the following command:
tmsh load /sys config
