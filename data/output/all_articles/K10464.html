Topic

The base registration key installed on your FirePass controller enables the features you selected as part of your initial purchase. If you decide at a later time to purchase additional features, such as the Antivirus/Firewall inspector or additional concurrent user seats, F5 Networks will issue you a module registration key (add-on license) which must be installed and activated on the FirePass controller.

To install and activate a module registration key, perform the following procedure:

Note: For instructions about activating the FirePass base license, refer to K10476: Licensing the FirePass controller.

  1. Logon to the FirePass Administrative Console.
  2. Navigate to the Device Management : Maintenance : Activate License page.
  3. In the Module Registration Keys field, enter the module registration key provided by F5 Networks.
  4. Click the Add button.
  5. Repeat Steps 3 and 4 for each additional module registration key you purchased.
  6. In the Registration Method field, select Automatic or Manual.

    Note: If the FirePass controller can resolve and connect to the F5 Networks licensing server through TCP port 443, select the Automatic method. Otherwise, or if you are unsure, select the Manual method.
     
  7. Click the Request License button.
  8. If you selected the Automatic registration method:
    1. Accept the End User License Agreement, and provide your business email address and contact details if prompted.
      A screen opens, displaying your license file.
    2. Click the Continue button to activate and install your license.
    3. Log out of the FirePass Administrative Console, and then logon again.
      The FirePass controller presents the newly licensed features.
  9. If you selected the Manual registration method:
    1. On the Activate License screen, select and copy all of the contents in the Product Dossier field.
    2. Click the Click here link here to access F5 Licensing Server link.
      The Activate F5 License screen opens in a new browser window.
    3. Paste the dossier you copied in Step 12 into the Enter your dossier field on the Activate F5 Product page.
    4. Click the Next button.
    5. Accept the End User License Agreement, and provide your business email address and contact details if prompted.
      After a few moments, the licensing server displays your new license file.
    6. Select and copy the license from the Activate F5 Product page.
    7. Return to the FirePass Administrative Console browser window.
    8. Paste the license file into the License File field.
    9. Click the Install License button.
      A confirmation messages appears.
    10. Click the Continue button to activate and install your license.
    11. Log out of the FirePass Administrative Console, and then logon again.
      The FirePass controller presents the newly licensed features.
