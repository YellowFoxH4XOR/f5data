K000138377: High CPU after upgrading to 16.1.3

Type
Support Solution
Published
2024-02-06
Updated
2024-02-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.0, 16.1.2, 16.1.1, 16.1.X, 16.1.4, 16.1.3
Source
https://my.f5.com/manage/s/article/K000138377

Description

High CPU usage after upgrading to 16.1.3.2

Environment

  • upgrade to 16.1.0 and later
  • Virtual server has a CACHE_REQUEST iRule which does a SessionDB lookup

Cause

This is caused by bug ID 1481889

Recommended Actions

Remove CACHE_REQUEST iRule.
or
Disable below variable

#tmsh modify sys db ramcache.gzipconsolidate value disable
#tmsh save sys config

With this DB key disabled, ramcache will process gzip and deflate separately. It will have no impact on the traffic flows.
