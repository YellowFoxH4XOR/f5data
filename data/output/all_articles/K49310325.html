Issue

Error Message

01010251:3: Virtual <name> exceeded configured rate limit

In this error message, note the following:

  • <name> is the name of the virtual server.

For example:

01010251:3: Virtual /Common/vs_example exceeded configured rate limit

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The number of new connections to the virtual server per second exceeds the value configured for the virtual server's Connection Rate Limit setting.

Impact

The number of new connections to the virtual server is limited based on the value configured for the Connection Rate Limit setting.

Recommended Actions

This message may indicate a period of high traffic levels or the possibility of a denial-of-service (DoS) attack. You can adjust both the Connection Limit and Connection Rate Limit settings for the virtual server, accordingly, based on your environment. For more information, refer to the Setting Connection Limits chapter of the BIG-IP Local Traffic Manager: Implementations guide.
