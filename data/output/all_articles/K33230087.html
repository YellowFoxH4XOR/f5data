Description

LCD Displays Message "Blocking DOS attack".

Environment

  • Websites are inaccessible
  • TMM memory utilisation very high
  • Stats show no change in traffic volume
  • In /var/log/ltm, the following shows connections killed:

    Jan 01 21 12:00:00 bigip1 warning tmm[11111]: 011e0003:4: Aggressive mode sweeper: 2 Connections killed

Cause

The LCD display message "Blocking DOS attack" is displayed when an adaptive reaping event has been triggered.

When TMM memory reaches the threshold Connection.AdaptiveReaper.Hiwater, aggressive sweeper is triggered to reap the connections.

For more information, refer to the Manual Chapter : Mitigating Denial of Service Attacks

Note: The message will be displayed regardless even if there is a no actual attack happening.


Recommended Actions

As mentioned the cause is low memory, therefore, for further investigation, please open a f5 technical support case.
