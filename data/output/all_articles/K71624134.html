Which browsers can you use for endpoint inspection?

The BIG-IP Edge Client opens a browser control object, which then opens the Inspection Host Plug-in to perform endpoint inspection checks. The checking operation is very similar to that performed by BIG-IP Edge Client.

BIG-IP APM 13.0 and later also have a browser-activated checking mechanism that works in most web browsers. However, F5 supports only Chrome, Firefox, Safari, and Microsoft Edge browsers.

What app must you install for endpoint inspection to work?

BIG-IP Edge Client package provides required Endpoint Inspector components. You can preinstall the package on client PCs. For more information, refer to 07: Deployment options.

Can any site perform endpoint inspection on client PCs?

No, it is not possible for malicious sites to perform checks on client PCs. The client PC maintains an allowed list of sites. In Internet Options, on the Security tab, sites listed in the Trusted Sites zone are allowed for inspection. Other sites can be allowed manually by the user.

Linux and Macintosh components maintain their own trusted sites list.
