Issue

The BIG-IP GTM Synchronization Time Tolerance setting specifies the number of seconds that the system clock on one BIG-IP GTM system in a synchronization group can be out of sync with the system clock on another BIG-IP GTM system in the same synchronization group. The default Synchronization Time Tolerance setting is 10 seconds. If the variance between the clock times is higher than the Synchronization Time Tolerance setting, the system resets the clock that is running behind to match the clock with the most recent time and logs an error message that appears similar to the following example to the /var/log/gtm file:

Setting my time ahead by XX seconds to match GTM

Important: F5 recommends that all BIG-IP GTM synchronization group members are configured to use an NTP server. For more information about configuring BIG-IP to use a public NTP server, refer to K3122: Configuring BIG-IP to use a public NTP server.

You can adjust the Synchronization Time Tolerance setting by performing the following procedure:

  1. Log in to the Configuration utility.
  2. Click System.
  3. In version 9.x, click General properties; in version 10.x click Configuration.
  4. From the Global Traffic menu, select General.
  5. Set the Synchronization Time Tolerance setting to the desired value.

    Note: Synchronization needs to be enabled for the Synchronization Time Tolerance setting to be visible.
  6. Click Update.
