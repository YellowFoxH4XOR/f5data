Description

Inquiry into ASM signature protection for CVE-2023-23956, which is a XSS vulnerability in Symantec SiteMinder WebAgent that is related to improper handling of user input. It allows an attacker to supply malicious HTML and execute arbitrary JavaScript code in the client browser.

Environment

  • ASM provisioned
  • WAF policy utilized with ASM signature protection

Cause

N/A.

Recommended Actions

The following three existing signatures would help mitigate CVE-2023-23956:

  • Signature ID 200001049 - onfocus (Parameter)
  • Signature ID 200101566 - alert() (2) (Parameter)
  • Signature ID 200001088 - alert() (Parameter)

These signatures are part of the built-in Cross-site Scripting (XSS) signature set, which can be applied to the security policy, or these signatures can be explicitly added to a user-defined signature set that's part of the security policy.

Additional Information

Update the Attack Signature Update (ASU) file to the latest available version to get the most updated version of any signature(s).
