K46414144: LDAP login keeps failing

Type
Support Solution
Published
2021-09-13
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
Source
https://my.f5.com/manage/s/article/K46414144

Description

Remote authentication using keeps failing. Local users are able to login just fine.

  • After a reboot or a restart of nslcd daemon, the LDAP login is working fine.
  • But after sometime, LDAP login starts failing.
  • err nslcd[2867]: accept() failed: Too many open files is seen in /var/log/secure

Environment

  • BIG-IP LTM.
  • Remote authentication with LDAP is configured.
  • LDAP setting has user-template configured in BIG-IP.

Cause

This happens due to a know bug 908517

Recommended Actions

  1. Upgrade to a fixed versions (Fixed in 16.1.0, 16.0.1.1, 15.1.3, 14.1.4)
  2. Though there is no permanent workaround, a temporary workaround is to restart the nslcd daemon using the command below:
    # systemctl restart nslcd
