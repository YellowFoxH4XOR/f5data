Issue

Environment

This error message occurs on BIG-IP iSeries platforms.

Error Message

crit chmand[<PID>]: 012a0043:2: <PSU_number> Status <PSU_status>

In this error message, note the following:

  • <PID> is the process ID of the chmand process.
  • <PSU_number> is the power supply unit slot number.
  • <PSU_status> is the power supply unit status.

For example:

crit chmand[8484]: 012a0043:2: PSU2 Status config mismatch
crit chmand[8484]: 012a0043:2: PSU2 Status output lost
crit chmand[8484]: 012a0043:2: PSU2 Status PSU unidentified

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The LCD screen

Description

This message occurs when one of the following conditions is met:

  • A power supply unit (PSU) is insufficiently powered or malfunctioning.
  • An internal power fault occurred within the hardware unit.

Impact

The power supplied to the PSUs is insufficient to power the system, or the PSU is malfunctioning. Power redundancy for the BIG-IP system may be compromised.

Recommended Actions

To troubleshoot BIG-IP power supply issues and determine the PSU status, refer to K52015891: Troubleshooting BIG-IP power supply issues.
