Topic

The BIG-IP system uses the auto_lasthop variable only when no last hop pool is defined for a virtual server. If a last hop pool is defined, then the auto_lasthop entries are ignored and the last hop pool members that you configured are used instead.

If you want only connections specified with a last hop pool to have last hop capabilities, you can disable the auto_lasthop variable from the command line or from the Configuration utility.

Disabling auto_lasthop from the command line

To disable the auto_lasthop variable from the command line, type the following command:

bigpipe global auto_lasthop disable

Disabling auto_lasthop from the Configuration utility

To disable the auto_lasthop variable from the Configuration utility, perform the following procedure:

  1. From the navigation pane of the Configuration utility, click System.
  2. Click the Advanced Properties tab.
  3. In the BIG-IP section, uncheck the box next to the auto_lasthop variable.
  4. Click Apply. 

Note: When auto_lasthop is disabled, responses from virtual servers without a defined last hop pool will be forwarded according to the contents of the BIG-IP routing table.
