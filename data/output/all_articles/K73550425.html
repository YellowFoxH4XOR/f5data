Description

  • After upgrade, the below message is observed on the Configuration Utility (GUI):

    The configuration has not yet loaded. If this message persists, it may indicate a configuration problem.

  • From CLI, verify the configuration by using the command "tmsh load /sys config verify" and the below error is observed: 
Failed: name (/Common/dtdi.crt) Cache path (/config/filestore/files_d/Common_d/trust_certificate_d/:Common:dtdi.crt_<Revision ID>) does not exist and there is no copy in trash-bin to restore from. Unexpected Error: Validating configuration process failed.

 

Environment

  • LTM
  • bigip_base.conf
  • dtdi.crt

Cause

When the system attempts to load the bigip_base.conf after upgrade or license re-activation, the referenced file cannot be found in the configuration.

Recommended Actions

Option 1:

Copy the equivalent file from an HA peer to the directory identified in the error and rename the file if necessary.

Option 2:

Remove the certificate reference from configuration and reload configuration by following the steps below:

  1. Make a copy of bigip_base.conf.
    cp bigip_base.conf bigip_base.conf.backup
  2. Using the error message as a reference, (/<Partition>/<Filename>), open the bigip_base.conf file in the partition referenced in nano or vi.
  3. Using your the editor's find function, locate the certificate object that references the filename.
  4. Delete or comment out the object.
    Example, if the object that is causing the issue is as below:
    cm cert /Common/dtdi.crt {
        cache-path /config/filestore/files_d/Common_d/trust_certificate_d/:Common:dtdi.crt_64202_1
        checksum SHA1:1220:4bfb0b4d558c0b50c3fff886b6f469d4eb7745fc
        revision 1
    }

    You can comment it out and it will look like this:
    #cm cert /Common/dtdi.crt {
    #    cache-path /config/filestore/files_d/Common_d/trust_certificate_d/:Common:dtdi.crt_64202_1
    #   checksum SHA1:1220:4bfb0b4d558c0b50c3fff886b6f469d4eb7745fc
    #    revision 1
    #}
     
  5. Delete or comment out the reference.
Example, the dtdi.crt reference is inside the device info as below
cm device /Common/LTM1.Example.com {
    base-mac 00:00:5E:00:53:00
    build 0.0.10
    cert /Common/dtdi.crt  <<<<
}
You can comment it out and it will look like this:
cm device /Common/LTM1.Example.com {
    base-mac 00:00:5E:00:53:00
    build 0.0.10
#    cert /Common/dtdi.crt  <<<<------
}
  1. Save your edit.
  2. Verify the configuration by using the command "tmsh load /sys config verify".
  3. Reload the configuration by using the command 'tmsh load /sys config'.
