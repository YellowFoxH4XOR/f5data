Description

Not able to add DCD when debug logging for restjavad enabled.


You may observe the following logs in /var/log/restjavad.0.log


[WARN][10 Aug 2022 09:24:22 ][ElasticSearchClient] GET request to http://127.0.0.1:9200/_cluster/health from com.f5.rest.workers.shared.esmgmt.ESHealthWorker$1 with body null failed: Connection refused


[WARN][10 Aug 2022 09:24:22 ][ElasticSearchClient] GET request to http://127.0.0.1:9200/_cluster/health from com.f5.rest.workers.shared.esmgmt.ESHealthWorker$1 with body null failed: Format specifier '%s'



 Environment

BIG-IQ

Debug logging enabled for restjavad

 Cause

None

 Recommended Actions

Disable debug logging for restjavad. Refer to K22244445: Enabling debug logging for restjavad in BIG-IQ
