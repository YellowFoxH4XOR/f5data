Topic

You can create an IP filter that prevents the administrator from connecting to the Configuration utility or the SSH terminal. For information about how to create IP filters, refer to K454: Limiting access to a BIG-IP virtual server with IP Filters.

To disable the IP filters, and enable access to the Configuration utility or SSH terminal, perform the following steps:

  1. Attach a serial terminal to BIG-IP or 3-DNS.
  2. Log in as root.
  3. Disable the IP filters by typing the following command:

    ipfw pre-input -popall
