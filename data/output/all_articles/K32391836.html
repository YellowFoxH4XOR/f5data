Known Issue

Creating a child monitor from a custom parent monitor may cause inconsistent settings in the child.

You may observe inconsistent settings in a child monitor when you create it from a parent monitor that has custom settings.

This issue occurs when all of the following conditions are met:

  • You have a monitor on your BIG-IP system that contains one or more of the following variables:

    • Time Until Up (default 0).
    • Up Interval (default Disabled).
  • You modify the monitor to set custom values for these variables.
  • You use the Configuration utility to create a child monitor based on the custom monitor.

Impact

The Configuration utility fails to correctly display the child monitor's inherited settings during the creation process, and once created, the child monitor does not inherit the correct Time Until Up value from the parent monitor.

Symptoms

As a result of this issue, you may encounter all of the following symptoms:

  • When you create the child monitor, you assign the custom monitor as the parent and notice that the child's inherited Up Interval and Time Until Up values are different from the parent's.
  • If you leave the child monitor's values unchanged and click Finish, the system creates the child monitor and you observe that its Up Interval value is correctly inherited from the parent monitor, but its Time Until Up value is erroneously set to 0.

Workaround

To work around this issue, you can use the Configuration utility to manually modify the Time Until Up variable of the child monitor. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Monitors.
  3. Click the name of the new child monitor.
  4. On the monitor's Properties screen, for Configuration select Advanced.
  5. Enter a new value in the Time Until Up box.
  6. Click Update.
