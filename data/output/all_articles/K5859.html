K5859: BIG-IP may crash and reboot when you use the Reset all Statistics function in the Configuration utility

Known Issue

This is the result of a known issue. When BIG-IP is configured with a large number of SNATs, or when a large number of connections are active through a SNAT, using the Reset all Statistics function in the Configuration utility may take too long to complete, causing BIG-IP to panic and reboot.

F5 Networks Product Development tracked this issue as CR53664 and CR53665, and it was fixed in BIG-IP version 4.5.14. For information about upgrading, refer to the BIG-IP Release Notes.
