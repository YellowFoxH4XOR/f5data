K000140269: Applying Telemetry Streaming data modification setTag function on system location, only observed tag on some system metrics

Description

Telemetry Streaming (TS) data modification has been declared to add a tag called facility with value of 'northdc' on system location. However, the tag is only appearing in some system metrics.

Example of extracted section of TS declaration:

        "actions": [
          {
            "enable": true,
            "setTag": {
              "facility": "northdc"
            },
            "locations": {
              "system": true
            }
          }
        ],

Environment

  • TS tag property

Cause

The system stats are defined into top and sub level objects.

Top level objects:

system.cpu

system.swap

system.memory

system.tmmCpu

system.tmmMemory

Sub level objects:

system.throughputPerformance

system.connectionsPerformance

system.diskStorage

system.diskLatency

system.networkInterfaces

system.tmmTraffic

The declaration shown in the above example will add tag to the top level objects and it is working as expected.

Recommended Actions

To include system metrics that are at the sub level objects, the declaration must specify the exact locations.

"actions": [
          {
            "enable": true,
            "setTag": {
              "facility": "northdc"
            },
            "locations": {
              "system": {
                "cpu": true,
                "networkInterfaces": {
                  ".*": true
                },
                "diskStorage": {
                  ".*": true
                },
                "throughputPerformance": {
                  ".*": true
                }
              }             
            }
          }
        ],
