Known Issue

This is the result of a known issue. When attempting to access a BIG-IP APM or BIG-IP Edge Gateway virtual server, the virtual server may intermittently fail to display on the logon page. If a request without a cookie is sent to the virtual server, the virtual server should send the appropriate response; however, the virtual server waits for additional data and appears unavailable to the user.

F5 Product Development tracked this issue as ID 328336 and ID 324370 (formerly CR141736) and it has been fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

In addition, this issue has been fixed in BIGIP-10.1.0-3402.0-HF2 issued for BIG-IP version 10.1.0, and in Hotfix-BIGIP-10.2.0-1755.1-HF1 issued for BIG-IP version 10.2.0. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing version 10.x hotfixes on systems, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
