Description

Explain BGP aggregate-address


Environment

Big-IP Zebos


Cause

The aggregate-address is an advertised route that summarizes other, more specific, routes. For instance, if a BIG-IP has routes for 10.0.1.0/24 and 10.0.2.0/24 it might advertise 10.0.0.0/16 rather than advertising the two more specific routes. Aggregate-address is only useful in situations where you have multiple routes on the BIG-IP (or other BGP neighbor) that are able to be aggregatable. So in our example above, you would not use 10.0.1.0/24 as an aggregate-address because it is a single address, and does not cover other routable networks. If you had 10.0.1.0/25 and 10.0.1.128/25, 10.0.1.0/24 would be an acceptable aggregate-address, as it aggregates the two network routes available under it.
