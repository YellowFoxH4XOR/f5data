Known Issue

The BIG-IP GTM system may report incorrect pool statistics.

This issue occurs when the following condition is met:

  • The Maximum Addresses Returned pool setting value is greater than 1 for the affected pool.

When the Maximum Addresses Returned pool setting value is greater than 1 for a pool, and the BIG-IP GTM system returns multiple addresses in the wide IP response, the system only increases the pool statistics for the pool member associated with the first address.

Impact

The BIG-IP GTM system reports incorrect pool statistics for affected pools.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP GTM system reports incorrect pool statistics for affected pools.
