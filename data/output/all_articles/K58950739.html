Description

Starting in BIG-IP 15.0.0, the BIG-IP AFM IP intelligence feature supports fully qualified domain name (FQDN) host entries, as well as GEO entries.

To enable the BIG-IP AFM IP intelligence feature for FQDN entries, you must first configure the BIG-IP AFM system with a DNS resolver with a forward zone entry (Network > DNS Resolvers). Next, configure IP intelligence to use the DNS resolver (Security > Options > Network Firewall). In addition, configuring this feature permits FQDNs in Network Firewall rules.

The following example configuration stanza shows a DNS resolver with three forward zones defined; the zone indicated with a period ( . ) acts as a wildcard:

net dns-resolver 192.168.101.200 {
    forward-zones {
        . {
            nameservers {
                192.168.10.10:domain { }
            }
        }
        example.com {
            nameservers {
                192.168.12.12:domain { }
            }
        }
        example.org {
            nameservers {
                192.168.11.11:domain { }
            }
        }
    }
    route-domain 0
}

Procedures

  • Create a DNS resolver and forward zones
  • Configure IP intelligence to use the DNS resolver

Create a DNS resolver and forward zones

You can create the DNS resolver and forward zones using either the Configuration utility or the TMOS Shell (tmsh). To do so, perform one of the following procedures:

Impact of procedure: Performing this procedure should not have an impact on the system.

Create the DNS resolver and forward zones using the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to Network > DNS Resolvers > DNS Resolver List.
  3. Select Create.
  4. For Name setting, enter a name for the DNS resolver.

    For example:

    192.168.101.200.

  5. Configure the remaining settings as desired, otherwise leave them in their default values.
  6. To save the new entry, select Finished.

    The Configuration utility returns to the DNS Resolver List page.

  7. Select the name of the new DNS resolver you created in step 4.
  8. Select Forward Zones.
  9. Select Add.
  10. For the Name setting, enter a name for the forward zone.
  11. For the Address setting, enter the name server address.
  12. Change the Service Port as appropriate for your application environment. Otherwise, leave it as default DNS port 53.
  13. To add the name server address to the Nameservers list, select Add.

    Note: To add additional forward zones, select Repeat and repeat steps 8 through 14.

  14. Select Finished.

Create the DNS resolver and forward zones using tmsh

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Create the DNS resolver and forward zones using the following command syntax:

    create /net dns-resolver <DNS resolver name> { forward-zones add { <zone name> { nameservers add { <name server address>:<DNS port> } } } }

    In this command syntax, note the following:

    • <DNS resolver name> is the name you want to use for the DNS resolver configuration.
    • <zone name> is the zone name. In the example stanza at the beginning of the article, a period character ( . ) signifies a wildcard.
    • <name server address> is the IP address of the DNS name server.
    • <DNS port> is the port to which the DNS server listens (typically 53).

    Using the example configuration described at the beginning of the article, enter the following command:

    create /net dns-resolver 192.168.101.200 { forward-zones add { . { nameservers add { 192.168.10.10:53 } } example.org { nameservers add { 192.168.11.11:53 } } example.com { nameservers add { 192.168.12.12:53 } } } }

  3. Save the configuration change by entering the following command:

    save /sys config

Configure IP intelligence to use the DNS resolver

You can configure the BIG-IP AFM IP intelligence to use the DNS resolver using either the Configuration utility or tmsh. To do so, perform the following procedure:

Impact of procedure: Performing this procedure should not have an impact on the system.

Configure IP intelligence to use the DNS resolver using the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to Security > Options > Network Firewall > Firewall Options.
  3. Select the desired DNS resolver from the Global Context setting under the FQDN Resolver section.
  4. To save the change, select Update.

Configure IP intelligence to use the DNS resolver using tmsh

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To configure the FQDN Resolver Global Context setting, use the following command syntax:

    modify security firewall global-fqdn-policy dns-resolver <DNS resolver name>

    Using the previous example, enter the following command:

    modify security firewall global-fqdn-policy dns-resolver 192.168.101.200

  3. Save the configuration change by entering the following command:

    save /sys config
