Known Issue

Important: This issue has been observed with some versions of IE and Chrome, but may not be limited to these browsers.

This is the result of a known issue. When attempting to import hotfix ISO images through the Configuration utility, the following error message is reported when the upload of the hotfix images reaches 99 percent:

em.error.ErrorReadingISO

The /var/log/tomcat4/catalina.out log file also reports the following error message:

ERROR [Thread-23] sw_updates.SoftwareUploadHandlerBS3:error - java.lang.Exception: Unable to move file Hotfix-<name of hotfix>.iso"

F5 Product Development is tracking this issue as ID 333351 (formerly CR131088).

Workaround

If you encounter this error message, F5 recommends that you use another browser or import the hotfix using the command line.
