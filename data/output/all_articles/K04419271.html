Description

Users unable to delete, modify, create or assign to Virtual Servers Address Lists and Port lists.

  • Error returned:
01070822:3: Access Denied: user (user_name) does not have create access to object (traffic_matching_criteria) when trying to delete
Environment
  • Trying to delete, modify, create or assign to Virtual Servers Address lists and Port lists by a user that is not an Administrator.

Cause

Only users configured with an Administrator role have permission to delete, modify, create or assign to Virtual Servers  Address lists and  Port lists.

Recommended Actions

  1. Log into the GUI using a user configured with the Administrator role. 
  2.  While using the Administrator user you will be able to delete, modify, create or assign to Virtual Servers. 
Note: You might encounter the following error message when trying to add the Address/Port List to the Virtual Server even if an Administrator user is being used:
0107176c:3: Invalid Virtual Address, the IP address x.x.x.x%x already exists.
If so it would be required to delete the Virtual Server and re-configure the TMC virtual server.
 

Additional Information

Manual Chapter : User Roles
