Topic

The FirePass controller's Endpoint Security feature allows administrators to detect the presence and state of third party security software, such as personal firewalls, antivirus, anti-spam, anti-spyware or integrated packages. To perform this detection, the Windows antivirus checker and Windows firewall checker Endpoint Inspectors, which are listed on the Users: Endpoint Security: Endpoint Inspectors page, use software libraries from a software development kit (SDK) created by OPSWAT, Inc.
 
 
Note: To use the Windows antivirus checker or Windows firewall checker in a pre-logon sequence, you must install the Anti-Virus/Firewall Inspector license on the FirePass controller. This license can be obtained from your F5 Networks sales representative or reseller.

OPSWAT provides a vendor-independent framework for endpoint security management. The FirePass controller incorporates OPSWAT's Endpoint Security Integration SDK libraries in the Endpoint Inspectors.

To view the third-party antivirus products supported by the OPSWAT SDK libraries installed on your FirePass controller, view the Users : Endpoint Security : Inspectors : Antivirus Support Chart : Antivirus Support Chart page in the FirePass online help.
 
Important: If an antivirus product is listed in the Antivirus Support Chart, but there is no plus sign (+) or asterisk character (*) in the corresponding Check Realtime Protection State (monitor) column, the antivirus product is not supported by the version of OPSWAT SDK libraries installed on the FirePass controller.
 
To view the third-party firewall products supported by the OPSWAT SDK libraries installed on your FirePass controller, view the Users : Endpoint Security : Inspectors : Firewall Support Chart : Firewall Support Chart in the FirePass online help.
 
Important: If a firewall product is listed in the Firewall Support Chart, but there is no plus sign (+) or asterisk character (*) in the corresponding Check Firewall State (monitor) column, the firewall product is not supported by the version of OPSWAT SDK libraries installed on the FirePass controller.
 
If the antivirus software used by your organization is not listed in the Antivirus Support Chart, or if the firewall software used by your organization is not listed in the Firewall Support Chart, you can obtain and install the latest OPSWAT SDK hotfix for your version of FirePass software. For more information, refer to K6664: Obtaining and installing OPSWAT hotfixes.
 
If you are already running the latest OPSWAT SDK hotfix for your version of FirePass software, and the antivirus or firewall software used by your organization is not supported by that hofix, you can configure other pre-logon inspectors to construct endpoint security checks. For example, you could configure the following pre-logon inspectors, which may satisfy your organization's security requirements:
  • Process checks (Windows only)
  • Registry checks (Windows only)
  • File checks (Windows, Mac OS X, Linux)

Process checks

You may check for a running process on a Windows host using the Windows process checker. You must first identify the correct name of the process that runs when the third party software starts. To determine the name of the process, you can run the Windows Task Manager, or consult the vendor of your software to determine the correct name. For example, Network Associates McAfee VirusScan runs the mcshield.exe process.

Creating a pre-logon sequence check

To create a pre-logon sequence check for a process, such as mcshield.exe, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Click Users.
  3. Click Endpoint Security.
  4. Click Pre-Logon Sequence.
  5. In the Create new sequence field, enter a name for this pre-logon sequence.

    For example:

    Check McAfee
  6. From the drop-down menu for the Based on field, select template: Empty.
  7. Click Create.

    The Check McAfee sequence appears in the Select Sequence to Use section.
  8. Click edit next to the pre-logon sequence that you created.

    The Pre-Logon Sequence Editor opens.
  9. Position your curser on the Go action.

    A plus (+) link appears to the right of the Go action.
  10. Click the plus (+) link.

    The Change Sequence panel opens.
  11. From the Change sequence drop-down menu, select Insert action.
  12. From the Using drop-down menu, select One from the list.
  13. Click the button next to Check Processes.
  14. Click Apply changes.

    The Check Processes Inspector appears in your pre-logon sequence.
  15. Click the Check Processes link in your pre-logon sequence.

    The Edit Action panel opens.
  16. Click the Windows process checker link.

    The Endpoint Inspector Details page opens.
  17. On the Endpoint Inspector Details page, enter mcshield.exe in the Processes to be present field.
  18. Click Update.
  19. Click the Back to Console link at the top right corner of the page.

    The Pre-Logon Sequence main page appears.
  20. In the Select Sequence to Use section, select the option button next to the sequence you just created.

    For example:

    Check McAfee
  21. Click Apply.

 

Registry Checks

You can check for a Registry entry on a Windows host using the Windows registry checker. Registry entries can indicate the presence of the required software, but they do not usually indicate whether the software is running. When used in conjunction with a process check, the registry entry may provide added verification, such as ensuring that a process check has not found an unrelated process of the same name, or determining additional details, such as the software version. You can run the windows program regedit to determine the name of the appropriate process, or consult the vendor of your software to determine the needed registry keys and values.

You can create a pre-logon sequence check for a registry by performing the procedure in the Creating a pre-logon sequence check section. To do so, select Check Registry in Step 13.

File Checks

File checks can determine the presence of a file on the file system, such as a program, a configuration file, or an anti-virus signature file. File checks can also determine file characteristics, such as size, MD5 hash, or modification time (Windows only). The Check Files Inspector has versions for Windows, Linux, and Mac OSX operating systems.

You can create a pre-logon sequence check for a files by performing the procedure in the Creating a pre-logon sequence check section. To do so, select Check Files in Step 13.
