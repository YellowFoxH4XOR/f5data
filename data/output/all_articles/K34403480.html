Description

Adding a large expression to the Access Policy Visual Policy Editor (VPE) results in the following Error Message:

Unable to execute transaction because of: 010200363: The requested user role partition(admin Common) was not found.

Environment

  • BIG-IP Access Policy Manager (APM)
  • Expressions used within the Visual Policy Editor

Cause

The maximum expression size for visual policy editor has been exceeded.

Recommended Actions

Use a smaller expression. The maximum size for an expression in the visual policy editor is 64 KB. The visual policy editor cannot save an expression that exceeds this limit.
