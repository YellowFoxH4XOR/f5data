Known Issue

In rare instances, the Traffic Management Microkernel (TMM) may restart when modifying a virtual server with an associated Secure Sockets Layer (SSL) profile.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is processing SSL traffic using an associated SSL profile.
  • The virtual server configuration is being modified.

Note: To date, the issue has only occurred on a VIPRION system configured to use a network hardware security module (HSM).
Impact

Traffic processing is interrupted while TMM restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:
  • The BIG-IP system fails to process traffic for a brief period of time.
  • The BIG-IP system fails over to another host in the device group.
  • TMM generates a core file in the /var/core directory.
