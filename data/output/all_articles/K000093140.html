K000093140: AD Auth fails with KDC_ERR_ETYPE_NOTSUPP

Type
Support Solution
Published
2022-12-08
Updated
2022-12-08
Source
https://my.f5.com/manage/s/article/K000093140

Description

The KDC_ERR_ETYPE_NOTSUPP error specifically means that the client device has requested a ticket from the KDC and the algorithms that the client supports for this ticket do not match the algorithms that the KDC can offer. This causes the following error message on the BIG-IP:

AD module: authentication with 'a.user' failed: KDC has no support for encryption type, principal name: a.user@APMSUPPORT.LOCAL. Please verify Active Directory and DNS configuration.  (-1765328370)

Environment

  • BIG-IP APM
  • AD Authentication
  • Recent Microsoft Server Security update

Cause

While processing an AS request for target service krbtgt, the account Administrator did not have a suitable key for generating a Kerberos ticket 

Recommended Actions

To resolve the issue on the BIG-IP, add a supported Kerberos Preauthentication Encryption Type within the AAA Object

  1. Login to the BIG-IP
  2. Navigate to: Access  ››  Authentication  ››  <aaa_ad>
  3. Change the Kerberos Preauthentication Encryption Type to a supported type between the MS Server
