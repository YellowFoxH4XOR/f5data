K10554: Network drives periodically disconnect on Windows XP clients

Topic

When a Windows XP Service Pack 2 (SP2) client does not have Microsoft hotfix KB968389 installed, network drives mapped through ARX may periodically disconnect with an error message that appears similar to the following example:

A specified logon session does not exist. It may already have been terminated.

This issue is caused by the client’s handling of Kerberos session keys, and not by an issue with the ARX software. To prevent or resolve this issue, Windows XP SP2 clients should install KB968389 or XP Service Pack 3 (SP3).

Note: For information about KB968389, including download information, refer to http://support.microsoft.com/kb/968389.

Note: For information about Windows XP SP3, including download information, refer to http://support.microsoft.com/kb/936929.
