Description
When setup HA trust on GUI, on Retrieve Device Credentials (Step 1 of 3), after input the peer's IP address and click the button "Retrieve Device Information", error "java.lang.NullPointerException" will be shown up.
The input peer's IP address can be pingable however.

Environment

  • BIG-IP HA
  • Configuring Device Trust

Cause

  • The error indicates the peer device is not a BIG-IP system
  • The input IP address is a duplicate IP

Recommended Actions

  • Please verify the MAC address of the input peer IP address on CLI:

    • ping <input_IP>

    • tmsh show net arp | grep <input_IP>

  • Verify the MAC address on the peer device
  • Correct the duplicate IP and try to setup HA again

Additional Information

K14135: Defining network resources for BIG-IP HA features (11.x - 16.x)
