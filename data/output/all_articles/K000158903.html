K000158903: BIG-IP may not warn on invalid certificate in PEM bundle and may skip importing subsequent valid certificates

Type
Support Solution
Published
2025-12-24
Updated
2025-12-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000158903

Description

When importing a certificate bundle (multi-certificate PEM) into BIG-IP, if one certificate within the file is malformed due to unexpected whitespace, BIG-IP may:


  • Import only the certificates that appear before the malformed entry
  • Skip the malformed certificate
  • Fail to import any valid certificates that appear after the malformed certificate
  • Not present a clear warning/error in the GUI about the skipped/aborted portion of the import


Environment

  • BIG-IP LTM
  • Importing Certificate Bundle


Cause

Bug ID 2141365


Recommended Actions

None

None
