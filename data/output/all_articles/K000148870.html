Description

BIG-IP in HA pair doesn't communicate via cisco switch but both BIG-IP are accessible on management IPs

Cisco switch ports connected to both BIG-IP management interfaces are enabled with protected port feature.

Environment

  • BIG-IP LTM
  • High Availability ( HA )
  • protected port is enabled on cisco switch

Cause

This is due to the Protected Port feature configured on the Cisco switch 

When this is configured, Cisco switch doesn't forward any layer 2 traffic between protected ports causing initially generated big-ip arp request being dropped or not forwarded.

Recommended Actions

One should either need to make sure traffic is routing through the gateway device so no layer 2 traffic ( like initial arp request ) are forwarded through the protected ports on switch

or

Disable protected port feature on Cisco switch
