Known Issue

The restjavad process may run out of memory due to many inactive sockets.

This issue occurs when all of the following conditions are met:

  • The affected BIG-IP system receives inbound REST API socket connections.
  • The restjavad process responds to the inbound socket connections for a period of time, until an out of memory state occurs.

Impact

The restjavad process becomes inoperative.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/restjavad.0.log file, you notice out of memory messages which appear similar to the following example:

    [SEVERE][<pid>][<date> <time> UTC][RestServer][completed] java.lang.OutOfMemoryError: Java heap space

Workaround

To work around this issue, you can restart the restjavad process. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system, as the restjavad process is no longer responsive.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the restjavad process, type the following command:

    tmsh restart /sys service restjavad
