Description

You recently migrated the BIG-IP to a new environment with CloudFlare between the clients and BIG-IP, everything is working fine but seems like BIG-IP is ignoring cookie persistence and sending traffic to different servers within the same pool.

Environment

  • All BIG-IP v15.x to v17.x
  • Using CloudFlare in front of BIG-IP
  • Cookie Persistence

Cause

It is possible that CloudFlare sends HTTP requests from different clients in the same TCP connection. However, BIG-IP by default makes load balancing decision at the start of TCP connection, based on the cookie value of the first HTTP request in that connection. Hence, any subsequent cookie value will be ignored.

This behavior is described in: K7964: The BIG-IP system may appear to ignore persistence information for Keep-Alive connections.

Recommended Actions

Perform workaround described in: K7964: The BIG-IP system may appear to ignore persistence information for Keep-Alive connections.

Use either OneConnect, or configure an iRule to detach the server side after each request.
