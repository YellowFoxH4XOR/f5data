Description

After an upgrade the BigIP is unable to load the configuration, and the following error message is displayed:

Can't associate ASM device sync (/Common/device_failover_group_asm_sync/folder_name) folder does not exist

Environment

BigIP

ASM

Cause

This issue occurs when a folder referenced in the configuration is not found in from the filesystem.

Recommended Actions

This can be resolved by manually creating the folder and reloading the configuration.

tmsh create sys folder /Common/device_failover_group_asm_sync/folder_name

tmsh load sys config
