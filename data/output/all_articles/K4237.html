Known Issue

This is most likely the result of one of two known issues that cause iQuery communication to fail between 3-DNS version 4.x and BIG-IP LTM version 9.x. When these issues occur, the following operations will fail:

  • When BIG-IP LTM version 9.x is defined with translated virtual servers on a 3-DNS version 4.x system, 3-DNS reports the status of the virtual server as unknown.
  • When 3-DNS version 4.x accesses BIG-IP version 9.x through a defined route, 3-DNS reports the status of the virtual server as unknown.
  • The 3-DNS big3d ICMP probing for BIG-IP version 9.x fails.

Other failure symptoms may also occur; therefore, if you are using a 3-DNS Controller to monitor a BIG-IP version 9.x system using any of these methods, you should apply the hotfix detailed in the Workaround section.

F5 Networks Product Development tracked these issues as CR44804 and CR44805 and they were resolved in BIG-IP LTM version 9.0.5. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

If upgrading is not an immediate option, you can apply the following hotfix to BIG-IP version 9.0.3.

Note: This hotfix is applicable for BIG-IP version 9.0.3 only.

To obtain and install this hotfix, perform the following steps:

  1. Download the Hotfix-BIG-IP-9.0.3-CR44804.im file to the /var/tmp directory.
  2. Verify the md5sum of the hotfix, by typing the following command:

    md5sum Hotfix-BIG-IP-9.0.3-CR44804.im

    This should produce the following result:

    md5sum: 54f3c2eec2f4da1206f2cc787f780aea Hotfix-BIG-IP-9.0.3-CR44804.im

  3. Install the hotfix, by typing the following command:

    im /var/tmp/Hotfix-BIG-IP-9.0.3-CR44804.im

  4. To verify installation of the hotfix, change directories to the /hotfix directory, by typing the following command:

    cd /hotfix

  5. List the files in the directory, by typing the following command:

    ls

    A list of files with .def extensions should display Verify that the file includes CR44804 and CR44805.

  6. Restart big3d and big3dshim, by typing the following commands: 
    bigstart restart big3dbigstart restart big3dshim

The hotfix is now installed and iQuery communications between BIG-IP version 9.x and 3-DNS version 4.x should work correctly.
