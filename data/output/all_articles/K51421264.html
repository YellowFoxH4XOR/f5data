Description

After updating the geolocation database on your BIG-IP, TMM starts crashing and leaving core files. Upon investigating /var/log/ltm, it appears that TMM did not send heartbeat to SOD which caused TMM core.

Mar 13 04:55:04 bigip.local notice sod[6488]: 01140041:5: Killing tmm.0 pid 8909.
Mar 13 04:55:04 bigip.local warning sod[6488]: 01140029:4: HA daemon_heartbeat tmm2 fails action is go offline down links and restart.

And before that, Clock Advanced occurred:

Environment

  • BIG-IP
  • Recent update to geolocation database

Cause

Issue may be caused by ID938165 or ID1642301.

Recommended Actions

  1. To validate ID938165 is causing the issue and a temporary workaround, you may reinstall the older version of the geolocation database if it is still present on your device. This will stabilize the device. If your device becomes stable, upgrade to a fixed version.

  2. The IP geolocation database in available in two flavors: Edge and Pulse. The size of the Pulse database is much bigger than the Edge. Use Edge database to update with most recent geolocation information. Install Pulse database if no geolocation database has been installed. When you intend to install Pulse database, perform the installation in maintenance window and put the device in standby mode before the installation. This will prevent ID1642301.

    Note: Refer to the Related Content for more information on downloading and installing updates to the IP geolocation database.
