Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator Configuration utility allows you to create a regular expression in an acceleration policy that is too long for the pvac daemon to parse, causing the pvac daemon to restart.

The BIG-IP WebAccelerator pvac daemon cannot parse a regular expression that is longer than 510 characters. However, the BIG-IP WebAccelerator Configuration utility will allow a regular expression longer than 510 characters to be created in an acceleration policy without reporting an error message. If an acceleration policy contains a regular expression that is longer than 510 characters, and the policy is associated with an application, the pvac daemon will continuously restart.

In some cases, the pvac daemon may log to the /var/log/wa/pvac.log file error messages that appear similar to the following example:

RegExp::compile - Error Compiling Regular Expression

F5 Product Development is tracking this issue as ID 319273 (formerly CR113397).

Workaround

You can work around this issue by breaking up the excessively long regular expression into smaller expressions, then applying them separately using multiple matching rules.
