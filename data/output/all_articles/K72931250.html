Known Issue

The system license is not operational on Microsoft Azure after you upgrade to 12.0.0 HF4, 12.1.0 HF1 or 12.1.1.

This issue occurs when all of the following conditions are met:

  • You have upgraded a BIG-IP Virtual Edition (VE) Bring Your Own License (BYOL) instance on Azure.
  • You have upgraded the BIG-IP VE system to one of the following versions: 12.0.0 HF4, 12.1.0 HF1, EHF1, or 12.1.1.

Impact

The BIG-IP VE system license is not operational, and relicensing the system creates an invalid license.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you upgrade the BIG-IP VE system, the Azure license becomes non-operational and is invalidated.
  • Attempts to renew the BIG-IP VE license fail.

Workaround

To work around this issue, you can boot back into the previous boot volume and upgrade to one of the BIG-IP releases listed in the Fixes Introduced In column. To reboot the BIG-IP system to the previous volume, perform the following procedure:

Impact of workaround: The following workaround will halt the traffic process and should be performed only during a planned maintenance window.

  1. Log in to the Traffic Management Shell (tmsh) using the following command:

    tmsh

  2. To list the current software images, type the following command:

    show sys software

  3. To boot the BIG-IP system to a desired volume, or software image, use the following command syntax:

    reboot volume <volume_number>

    For example, to boot the BIG-IP system to volume HD1.2 running BIG-IP VE 12.0.0, type the following command:

    reboot volume HD1.2

  4. Once the BIG-IP system has rebooted into the previous boot volume, perform the software upgrade to one of the BIG-IP releases listed in the Fixes Introduced In column.

    Note: See the Supplemental Information section for assistance with downloading and installing BIG-IP software and hotfixes.
