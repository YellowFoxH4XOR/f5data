Issue

Error Message

01070734:3: Configuration error: vmw-compat: vlan member type must be an interface

Message Location

You may encounter this message in the following locations:

  • The Configuration utility or command line
  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You have configured a trunk in the BIG-IP Virtual Edition (VE) system.
  • You attempt to configure a Virtual Local Area Network (VLAN) with the trunk in the BIG-IP VE system.

While it is still possible to create a trunk in the BIG-IP VE system, the trunk cannot be added to a VLAN using the Configuration utility or the command line. When you create a VLAN, the trunk appears as an available interface. However, attempts to use the trunk fail.

Impact

Users cannot configure trunks as VLAN interfaces in the BIG-IP VE system.

Recommended Actions

Software version should be on 13.1.0 or next versions as trunking is supported on BIG-IP Virtual Edition (VE) from BIG-IP version 13.1.0 and later. Earlier versions of BIG-IP Virtual Edition do not support trunking and the error is expected. 

For more information on trunking refer, K1689: Overview of trunks on BIG-IP platforms
