Issue

You will receive this error while you are upgrading if the product license is missing, has expired, or is corrupted.

After you have completed the upgrade process, examine your license as follows to determine the exact reason for the error:

  • Verify that the /config/bigip.license file exists. If it does not exist, contact F5 Network Technical Support for assistance.
  • View the /config/bigip.license file and check the expiration date. If the license has expired, it most likely means that it was an evaluation license. In this event, contact your local F5 Networks Sales Representative.
  • Compare the /config/bigip.license file against your backup copy (if one exists). If they are significantly different, it may indicate that the license file is corrupted. In this event, contact F5 Network Technical Support for assistance.
