Known Issue

The DNS Express daemon, zxfrd, cannot start if its binary cache fills the /var directory.

This issue occurs when all of the following conditions are met:

  • DNS Express is configured and in use.
  • The DNS Express binary cache fills the /var directory.

Impact

The zxfrd process continually restarts and does not serve DNS requests.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The zxfrd process continually restarts.
  • DNS Express requests are not answered.

Workaround

There is no workaround for this issue. You can mitigate this issue by deleting the /var/db/tmmdns.bin file and restarting the zxfrd process. To do so, perform the following procedure:

Note: This mitigation option is a short-term fix. To prevent this issue, F5 recommends either applying a hotfix if you are running an affected version or updating to a fixed version.

  1. Log in to the command line.
  2. Delete the tmmdns.bin file by typing the following command:

    rm -rf /var/db/tmmdns.bin

  3. Restart the zxfrd process by typing the following command:

    bigstart restart zxfrd

    DNS Express will rebuild the binary cache file.
