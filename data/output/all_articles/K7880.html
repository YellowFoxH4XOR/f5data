Topic

F5 has recently discovered and corrected a number of critical issues that affect customers running BIG-IP 9.4.1. F5 recommends that all customers currently running 9.4.1 install Hotfix-BIG-IP-9.4.1-HF1, or a later version of the cumulative hotfix rollup, as soon as possible.

The following CRs are fixed in HF1 for BIG-IP version 9.4.1:

CR77126K7348The browser workarounds check is skipped if the User-Agent header is larger than 128 bytes
CR77233K7349The HTTP parser stalls on the HTTP CONNECT method
CR78695K7491The BIG-IP LTM does not update the counters for content type compression statistics
CR79616K7515Disabling the DEFAULT or native ciphers in a ServerSSL profile causes TMM to crash
CR79708K7516The ServerSSL profile does not reply with an empty certificate when it receives a request for a certificate
CR80120K7567Failed connections to a FastL4 virtual server with connection mirroring enabled can cause a memory leak
CR80154K7576The topology load balancing method fails when the destination is set to a region of pools
CR80412K7884Known Issue: The f5passwd utility does not update the user's password correctly
