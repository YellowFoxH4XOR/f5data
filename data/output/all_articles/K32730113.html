Topic

This article applies to F5OS software on VELOS and rSeries hardware systems as well as the BIG-IP tenants deployed on them. For information about other systems, refer to the following article:

  • K12815: Overview of Appliance mode

You can run VELOS and rSeries systems including the BIG-IP tenants deployed on them in Appliance mode. Appliance mode increases security for the system by disabling root access and restricting access to the Advanced Shell (bash). 

Description

Appliance mode provides added security by disabling root access to the system and disabling access to the bash shell for all users. For VELOS and rSeries systems, you can enable and disable Appliance mode using the F5OS webUI and CLI without the need for a special license.

Appliance mode is disabled by default. However, if you run the VELOS Setup wizard or the rSeries Appliance Setup wizard to completion when performing the initial system configuration, Appliance mode is automatically enabled.

  • VELOS systems
  • rSeries systems

VELOS systems

You can enable Appliance mode at the following levels on VELOS systems:

  • System controllers
  • Chassis partitions
  • Tenants 

System controllers

When you enable Appliance mode at the system controller level the following restrictions take effect:

  • The root user cannot log in to either system controller by any means.
  • Users can log in to the system controllers through the system controller webUI or CLI.
  • The AOM menu on the system controllers is unavailable.
  • Root or bash access is disabled on the system controller console. Users can log in to the system controller CLI from the console using an admin account.

Chassis partitions

By default, VELOS chassis partitions have the following restrictions in place (Appliance mode disabled):

  • The root user cannot log in to the chassis partition by any means.
  • Bash access is disabled for all users. Users are only able to access the chassis partition webUI or CLI.
  • Bash access is disabled on the console of each member blade in the chassis partition.

When you enable Appliance mode for a chassis partition, the following additional restriction takes effect:

  • The AOM menu is unavailable on member blades of the chassis partition.

Tenants

When you enable Appliance mode at the tenant level, the following restrictions take effect:

  • The root user cannot log in to the tenant by any means, including the tenant console.
  • Access to the bash shell on the tenant is disabled for all users. Users can access the BIG-IP tenant through the Configuration utility (webUI) or tmsh.
  • Bash access is disabled on the tenant console. BIG-IP users with Terminal Access (tmsh) privileges can access tmsh using the tenant console.

rSeries systems

On rSeries systems, you can enable Appliance mode at the system level or at the tenants level.

Important: When running F5OS-A 1.1.0 or earlier, if you power down the rSeries system from Linux using the halt -p, poweroff, or shutdown -h now commands while in Appliance mode, the device becomes permanently disabled. For more information, refer to K22954168: The rSeries appliance fails to boot in certain circumstances.

System

When you enable Appliance mode at the system level on rSeries systems, the following restrictions take effect:

  • The root user cannot log in to the rSeries system by any means.
  • Users can access the system using the webUI or CLI.
  • Root or bash access is disabled on the system console. Users can log in to the CLI from the system console using an admin account.

Tenants
 
When you enable Appliance mode at the tenant level on rSeries systems, the following restrictions take effect:

  • The root user cannot log in to the tenant by any means, including the tenant console.
  • Access to the bash shell on the tenant is disabled for all users. Users can access the BIG-IP tenant through the Configuration utility (webUI) or tmsh.
  • Bash access is disabled on the tenant console. BIG-IP users with Terminal Access (tmsh) privileges can access tmsh using the tenant console.

Procedures

  • Verify if Appliance mode is enabled on VELOS system controllers, VELOS chassis partitions, or rSeries systems using the webUI
  • Verify if Appliance mode is enabled on VELOS system controllers, VELOS chassis partitions, or rSeries systems using the CLI
  • Enable or disable Appliance mode on VELOS system controllers, VELOS chassis partitions, or rSeries systems using the webUI
  • Enable or disable Appliance mode on VELOS system controllers, VELOS chassis partitions, or rSeries systems using the CLI
  • Verify if Appliance mode is enabled for a BIG-IP tenant running on a VELOS or rSeries system using the webUI
  • Verify if Appliance mode is enabled for a BIG-IP tenant running on a VELOS or rSeries system using the CLI
  • Enable or disable Appliance mode on a BIG-IP tenant running on a VELOS or rSeries system using the webUI
  • Enable or disable Appliance mode on a BIG-IP tenant running on a VELOS or rSeries system using the CLI

Verify if Appliance mode is enabled on VELOS system controllers, VELOS chassis partitions, or rSeries systems using the webUI 

Impact of procedure: Performing the following procedure should not have a negative effect on your system.

  1. Log in to the webUI for the VELOS system controllers, VELOS chassis partition, or rSeries system.
  2. Go to SYSTEM SETTINGS > System Security (SYSTEM SETTINGS > General in previous versions).
  3. For Appliance Mode, either Enabled or Disabled will be selected indicating the current Appliance mode state on the VELOS system controllers, VELOS chassis partition, or rSeries system.

Verify if Appliance mode is enabled on VELOS system controllers, VELOS chassis partitions, or rSeries systems using the CLI

Impact of procedure: Performing the following procedure should not have a negative effect on your system.

  1. Log in to the CLI for the VELOS system controllers, VELOS chassis partition, or rSeries system as admin.
  2. To verify the current Appliance mode state, type the following command:

    show system appliance-mode

    The following example output indicates Appliance mode is disabled:

    system appliance-mode state disabled

Enable or disable Appliance mode on VELOS system controllers, VELOS chassis partitions, or rSeries systems using the webUI 

Impact of procedure: Enabling Appliance mode disables root access and access to the bash shell.

  1. Log in to the webUI for the VELOS system controllers, VELOS chassis partition, or rSeries system.
  2. Go to SYSTEM SETTINGS > System Security (SYSTEM SETTINGS > General in previous versions).
  3. To enable or disable Appliance mode, next to Appliance Mode, select either Enabled or Disabled.
  4. Select Save, then OK to confirm.

Enable or disable Appliance mode on VELOS system controllers, VELOS chassis partitions, or rSeries systems using the CLI

Impact of procedure: Enabling Appliance mode disables root access and access to the bash shell.

  1. Log in to the CLI for the VELOS system controllers, VELOS chassis partition, or rSeries system as admin.
  2. Type the following command:

    config
     
  3. To enable or disable Appliance mode, use the following syntax:

    system appliance-mode config <enabled | disabled>

    For example, to enable Appliance mode, type the following command:

    system appliance-mode config enabled
     
  4. To commit the change and exit, type the following command:

    commit and-quit


Verify if Appliance mode is enabled for a BIG-IP tenant running on a VELOS or rSeries system using the webUI

Impact of procedure: Performing the following procedure should not have a negative effect on your system.

  1. Log in to the webUI of the VELOS chassis partition or rSeries system where the tenant is running.
  2. Go to TENANT MANAGEMENT > Tenant Deployments.
  3. Select the name of the tenant.
  4. The Appliance Mode setting shows the current state, either Enabled or Disabled.


Verify if Appliance mode is enabled for a BIG-IP tenant running on a VELOS or rSeries system using the CLI

Impact of procedure: Performing the following procedure should not have a negative effect on your system.

  1. Log in as admin to the CLI of the VELOS chassis partition or rSeries system where the tenant is running.
  2. To view the Appliance mode status for a tenant, type the following command where <tenant_name> is the name of the tenant:

    show tenants tenant <tenant_name> state appliance-mode

    The following example output indicates Appliance mode on the tenant is disabled:

    state appliance-mode disabled


Enable or disable Appliance mode on a BIG-IP tenant running on a VELOS or rSeries system using the webUI

Impact of procedure: Enabling Appliance mode disables root access and access to the bash shell on the tenant.

  1. Log in to the webUI of the VELOS chassis partition or rSeries system where the tenant is running.
  2. Go to TENANT MANAGEMENT > Tenant Deployments.
  3. Select the name of the tenant.
  4. If the tenant is currently Deployed, select either Configured or Provisioned for the State setting, then select Save & Close and OK to confirm.
  5. If you changed the running state in step 4, select the name of the tenant again.
  6. For the Appliance mode setting, select either Enabled or Disabled.
  7. Select Save & Close.
  8. Select OK to confirm.
  9. To re-deploy the tenant, select the name of the tenant again.
  10. Select Deployed for the State setting, then select Save & Close and OK to confirm.


Enable or disable Appliance mode on a BIG-IP tenant running on a VELOS or rSeries system using the CLI

Impact of procedure: Enabling Appliance mode disables root access and access to the bash shell on the tenant.

  1. Log in as admin to the CLI of the VELOS chassis partition or rSeries system where the tenant is running.
  2. Type the following command:

    config

  3. If the tenant is currently Deployed, change the running-state to either configured or provisioned using the following syntax where <tenant_name> is the name of the tenant:

    tenants tenant <tenant_name> config running-state <configured | provisioned>

    For example, to change the running-state of the tenant named bigip-example to provisioned, type the following command:

    tenants tenant bigip-example config running-state provisioned

  4. To commit the change, type the following command:

    commit

  5. Type the following command:

    exit

  6. To enable or disable Appliance mode for the tenant, type the following command where <tenant_name> is the name of the tenant:

    tenants tenant <tenant_name> config appliance-mode <enabled | disabled>

    For example, to enable Appliance mode for the tenant named bigip-example, type the following command:

    tenants tenant bigip-example config appliance-mode enabled

  7. To commit the change, type the following command:

    commit

  8. Type the following command:

    exit

  9. To re-deploy the tenant, type the following command where <tenant_name> is the name of the tenant:

    tenants tenant <tenant_name> config running-state deployed

  10. To commit the change and exit, type the following command:

    commit and-quit
