K8336: Settings for Compatibility Mode may not reflect the current state of the Web Applications engine

Type

Published
2008-01-29
Updated
2023-02-21
Status
Legacy Content
Applies to

  • FirePass: 6.0.1, 6.0.0, 6.0.2
Source

Topic

Depending on the version of your FirePass controller, up to three generations of the Portal Access Web Applications engine are available. Beginning in FirePass software version 5.4, settings that select the version of Web Applications engine are available from the Web Applications Global Settings section, under the Global Settings tab on the Portal Access: Web Applications: Content Processing page. The Compatibility Mode check box (along with the option buttons in version 6.0.2 for each of the two prior Applications engines) is cleared up to the most current version, or selected to use a prior version. In order for the Portal Access Web Applications engine to take effect, a service restart must be performed.

Prior to a service restart, you can change the setting of the Compatibility Mode check box, navigate away from the Portal Access: Web Applications: Content Processing page, and return to the page without losing the change to the Compatibility Mode check box. This behavior allows you to perform other configuration tasks before restarting services after all configuration tasks are complete. Therefore, the check box does not necessarily reflect the state of the FirePass controller, with reference to which Web Applications engine is currently in use.

F5 Networks recommends that FirePass administrators perform a service restart soon after making a change to the Compatibility Mode settings, so that no confusion results from settings that are not reflective of the currently running Web Applications engine.
