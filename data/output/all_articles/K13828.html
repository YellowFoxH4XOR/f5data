Issue

Error Message

01340004:3: HA Connection detected dissimilar peer: local npgs <# of local blades>, remote npgs <# of remote blades>, local npus <# of local TMMs per blade>, remote npus <# of remote TMMs per blade>. Connection will be aborted.

In this error message, note the following:

  • local npgs <# of local blades> is the total number of blades reported on the local chassis.
  • remote npgs <# of remote blades> is the total number of blades reported on the remote chassis.
  • local npus <# of local TMMs per blade> is the total number of Traffic Management Microkernels (TMMs) running per blade on the local system.
  • remote npus <# of remote TMMs per blade> is the total number of TMMs running per blade on the remote system.

Note: n = number of instances
pg = processor group = blade - add 1 to get blade number
pu = TMM instance ID (example: 0 = tmm0, 1 = tmm1)
s = pluralization of statement

For example:

01340004:3: HA Connection detected dissimilar peer: local npgs 1, remote npgs 1, local npus 4, remote npus 12. Connection will be aborted.

Number of local processor groups = 1 (blade number 2)
Number of remote processor groups = 1 (blade number 2)
Number of local TMM instances = 4
Number of remote TMM instances 12

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • Both devices have a mirroring IP configured.
  • Both devices are set up to be in the same sync-failover device group.
  • The devices use dissimilar platforms.

    For example, the following are considered dissimilar platforms:

    • Non-identical platforms.
    • One system has HT Split disabled and the other system has HT Split enabled.
    • vCMP Guest HA cluster members are configured on different vCMP host slots.
    • A hardware failure has caused the number of blades or TMM instances on a system to change.
    • BIG-IP Virtual Edition has different type of network adapters such as E1000 and VMXNET3.

You may see this error message when a peer unit is restarted.

Impact

The devices in the same device group are not able to mirror their connections. In the event of failover, existing connections that are not mirrored may not be processed by the new active BIG-IP system.

Recommended Actions

Follow F5 recommendations for hardware parity in high availability (HA) configurations, especially for connection mirroring.
