Description

  • SSL/TLS

Cause

  • n/a

Recommended Actions

From Linux client you can run command below

  • curl https:// --verbose --tlsv1.0 --tls-max 1.0
  • curl https:// --verbose --tlsv1.1 --tls-max 1.1
  • curl https:// --verbose --tlsv1.2 --tls-max 1.2
