Description

You face a problem that the configuration including VIPs, Pools, Monitors is marked as a down after rollback to the previous version.

Environment

  • BIG-IP
  • Upgrade
  • Rollback

Cause

BIG-IP loading a corrupted or incorrect configuration from unknown source.

Recommended Actions

Restore the UCS backup file with the correct configuration. 

Additional Information

None
