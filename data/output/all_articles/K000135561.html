K000135561: SSL client profile statistic's Session Cache showing 0 value for Lookups

Source

Description

SSL client profile statistic's Session Cache showing 0 value for Lookups, even though TLS connectivity has been established.


config # date;tmsh show ltm profile client-ssl C*|grep "Session Cache" -A5

Wed Jul 5 20:38:39 PDT 2023

Session Cache

Current Entries 1

Hits 0

Lookups 0

Overflows 0

Invalidations 0



Environment

  • SSL client profile
  • Session cache

Cause

This is expected, if client send the Client Hello has no Session ID.

Recommended Actions

You could use tshark command below to verify the Session ID of Client Hello (assuming packet number 5 is Client Hello) in a packet capture,


config # tshark -r /var/tmp/1.pcap -Y frame.number==5 -O ssl|grep "Session ID"

Running as user "root" and group "root". This could be dangerous.
