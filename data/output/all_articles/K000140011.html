K000140011: DHCP relay virtual server not using the correct source ip address.

Type
Support Solution
Published
2024-06-13
Updated
2024-06-13
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000140011

Description

The DHCP Relay virtual server is using the wrong self-IP address when forwarding the client's DHCP request to the DHCP server.

 

Example of non-working flow.

DHCP Client is on VLAN 1

DHCP Server is on VLAN 2

The DHCP relay virtual server should forward the request using the self-ip address of vlan 1 to the DHCP server on vlan 2.

 

Environment

  • BIG-IP LTM
  • BIG-IP DHCP Relay Virtual Server

Cause

Unknown

Recommended Actions

  • To determine which self-IP the BIG-IP uses as a source, you must take a tcpdump on the BIG-IP. 
  • Rebooting the BIG-IP device fixes the issue.

Additional Information

None
