K03151105: An APM session is deleted after sending a redirect to users when Access Policy Redirect Ending triggers.

Type
Support Solution
Published
2019-08-07
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K03151105

Description
After APM redirects users to the FQDN configured in the Redirect Ending, the session is deleted.
Once the APM "Redirect Ending redirects the users to the configured FQDN the session is marked for deletion by default.

Environment

  • BIG-IP APM

Cause
Expected behavior.

Recommended Actions

  1. To avoid the session to be marked for deletion, the following setting needs to be unchecked on the configuration utility : 

    Access Policy > Edit VPE--->EDIT ENDINGS---> Uncheck "Close session after redirect"
     

Additional Information
None
