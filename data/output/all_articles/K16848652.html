Description

The GUI is missing "Local Traffic" in the sidebar or not showing all options in the Local Traffic menu

  • Virtual Servers, Profiles, Monitors, Ciphers are missing from the Local Traffic menu

Environment

  • BIG-IP
  • "Local Traffic" missing from Sidebar
  • GUI items missing (Virtual Servers, profiles,...)
  • LTM module not provisioned

Cause

The Local Traffic menu is missing or not fully populated due to LTM not being provisioned.
The behaviour is expected.

Recommended Actions

Confirm Local Traffic (LTM) provisioning status from GUI: System  ››  Resource Provisioning 

Additional Information

Changes to provisioning will restart daemons and can cause service outages.
