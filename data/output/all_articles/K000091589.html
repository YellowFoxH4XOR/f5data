Description

You want to use the iControl RESTful API to disable the DNS GSLB Pool. However, when you sent the request like the below example, you observe that it does not take effect at all.

curl -k -u <user>:<pass> -X PUT https://localhost/mgmt/tm/gtm/pool/a/\~Common\~example_pool -H 'Accept: \*/\*' -H 'Content-Type: application/json' -d '{"enabled": true}'

Environment

  • BIG-IP DNS
  • GSLB POOL
  • iControl RESTful API

Cause

This is by design, you should use the disabled knob to disable the GSLB Pool.

Recommended Actions

By design, using {"enabled": false} should have no effect on disabling the GSLB pool. Instead, you should use the {"disabled": true} to achieve this purpose, for example:

curl -k -u <user>:<pass> -X PUT https://localhost/mgmt/tm/gtm/pool/a/\~Common\~example_pool -H 'Accept: \*/\*' -H 'Content-Type: application/json' -d '{"disabled": true}'

Additional Information

As per the design of the RESTful API, enabled is used for enabling the GSLB pool ONLY while disabled is used for disabling the GSLB pool ONLY. You may read more on the documentation here: APIRef_tm_gtm_pool_a.
