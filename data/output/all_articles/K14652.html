Known Issue

You are unable to change the HA Group pool weight using the Configuration utility.

This issue occurs when all of the following conditions are met:

  • You have enabled the HA Group feature.
  • You are attempting to change the pool weight in the HA Group configuration.

Impact

You are unable to change the pool weight using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to change the pool weight using the Configuration utility, the Configuration utility accepts the changes. However, the changes revert back to the original value.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to manually make the change. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Modifying an HA Group pool weight using the tmsh utility

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To modify the weight for a given pool in a high availability (HA) group, use the following command syntax:

    modify sys ha-group <ha_group_name> pools modify { <pool_name> { weight <weight> } }

    In this command, note the following:

    • <ha_group_name> is the name of the high-availability group you want to modify
    • <pool_name> is the name of the pool listed in the high-availability group
    • <weight> is the weight you want to associate with this pool

    For example:

    modify sys ha-group ha-group-test pools modify { p1 { weight 30 } }

  3. Save the change by typing the following command:

    save /sys config
