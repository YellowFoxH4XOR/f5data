Known Issue

If you enable a disabled network interface on BIG-IP Virtual Edition (VE), the interface may still appear disabled.

This issue occurs when all of the following conditions are met:

  • Your system is running BIG-IP VE.
  • You use the Configuration utility or the Traffic Management Shell (tmsh) to disable and re-enable a network interface.
  • You use the Configuration utility or the tmsh utility to view the state of the network interface.

Impact

The system continues to display the network interface as disabled.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you set the network interface to disabled, no network traffic is passed through the disabled interface.
  • When you set the network interface to enabled, network traffic passes through the interface.
  • When you view the state of the network interface with the Configuration utility or the tmsh utility, the system displays the state as disabled.

Workaround

To work around this issue, you can reboot the affected device to reset the displayed interface state.

Note: F5 recommends that you synchronize all devices of the associated device group before you reboot the affected device.

Impact of workaround: F5 recommends that you perform this procedure during a scheduled maintenance window.

  1. Log in to the Configuration utility.
  2. Navigate to System > Configuration.
  3. In the Operations section, click Reboot.
