Issue

Error Message

01070333:3: virtual server <Partition/Virtual_Server1> illegally shares destination address, source address, and service port with virtual server <Partition/Virtual_Server2>

In this error message, note the following:

  • <Partition/Virtual_Server1> is the partition and name of the virtual server you are attempting to create.
  • <Partition/Virtual_Server2> is the partition and name of the virtual server with the same destination address, source address, and service port.

For example, in BIG-IP 11.3.0 and later, the system logs an error message that appears similar to the following example:

01070333:3: virtual server /Common/MyVip illegally shares destination address, source address, and service port with virtual server /Uncommon/MyVip2.

In BIG-IP 11.0.0 through 11.2.1, the system logs an error message that appears similar to the following example:

01070333:3: virtual server /Common/MyVip illegally shares both address and vlan with virtual server /Uncommon/MyVip2

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The BIG-IP Configuration utility

Description

This message occurs when the following condition is met:

  • You attempt to create a virtual server that shares the same destination address, source address, and service port as an existing virtual server.

Impact

Users may need to plan accordingly when creating virtual servers that share resources.

Recommended Actions

If it is not possible to create the virtual server so that it does not share the same resources with another virtual server, you may be able to specify different VLANs for which the virtual servers are enabled.

For example, in the following configuration, wildcardvip1 and wildcardvip2 are configured in different administrative partitions, but the virtual servers share the same destination address, source address, and service port. The configuration is legal because the virtual servers are enabled on different VLANs:

ltm virtual wildcardvip1 {
    destination 0.0.0.0:any
    ip-protocol tcp
    mask 255.255.255.255
    profiles {
        tcp { }
    }
    source 0.0.0.0/0
    translate-port disabled
    vlans {
        VLAN1
    }
    vlans-enabled
    vs-index 19
}

ltm virtual wildcardvip2 {
    destination /Common/0.0.0.0:any
    ip-protocol tcp
    mask 255.255.255.255
    partition Uncommon
    profiles {
        /Common/tcp { }
    }
    source 0.0.0.0/0
    translate-port disabled
    vlans {
        /Common/VLAN2
    }
    vlans-enabled
    vs-index 26
}
