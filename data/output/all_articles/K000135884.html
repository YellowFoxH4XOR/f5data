Description

This is a guide for enabling LDAP authentication debugging for F5OS-A platform (F5 rSeries system).

Environment

  • F5OS-A
  • rSeries CLI

Cause

None

Recommended Actions

1. Determine whether or not nslcd debug is already enabled, indicated by "-dd" in the nslcd runtime options.

# ps faux |grep "/usr/sbin/[n]slcd"

nslcd 5462 0.3 0.0 443824 3252 ? Sl 20:12 0:00 | | \_ /usr/sbin/nslcd

2. To initiate the debug:

# echo "-dd" > /etc/auth-config/nslcd_debug

3. Search for nslcd again and notice that "-dd" is now added indicating it's in debug:

# ps faux |grep "/usr/sbin/[n]slcd"

nslcd 5462 0.3 0.0 443824 3252 ? Sl 20:12 0:00 | | \_ /usr/sbin/nslcd -dd


You should now see debug messages of nslcd in /var/log/messages

4. To disable debug:

# echo > /etc/auth-config/nslcd_debug


Rerunning the ps command should no longer show "-dd" indicating debug is turned off

Additional Information

  • debug option is available from F5OS-A 1.3.0 and above
  • commands are ran outside of the name-service-ldap container
  • nslcd process is available only if you configure ldap auth
