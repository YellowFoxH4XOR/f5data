Topic

The umdinstall utility was introduced in BIG-IP 9.4.0 for the purpose of loading BIG-IP installation images onto a USB mass storage device, such as a USB thumb drive, from Windows-based systems or BIG-IP systems.

Beginning in BIG-IP 9.4.7, the umdinstall utility is no longer supported and has been removed from the BIG-IP installation image files. F5 recommends using the mkdisk utility on a BIG-IP system or a Linux-based system to load a BIG-IP installation image onto a USB mass storage device.

Note: For more information, refer to the Creating a Bootable USB Thumb Drive chapter in the BIG-IP Systems: Getting Started Guide for BIG-IP 10.x. For BIG-IP 9.4.7 and 9.4.8, refer to the Installing BIG-IP software from a USB Thumb Drive chapter in the BIG-IP LTM, GTM, Link Controller, or WebAccelerator release notes. Alternatively, if a BIG-IP system or a Linux-based system is not available, you may use a third party product, such as UNetbootin. For more information about UNetbootin, refer to the UNetbootin website.
