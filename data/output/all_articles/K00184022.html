Description

While navigating in Configuration Utility to Security  ››  Network Firewall : Active Rules you may see no or limited rules only

Environment

Relevant environmental factors specific to the topic

  • AFM is provisioned
  • Version 13.1.0 or higher is installed

Cause

There is no "Context all" for diplaying AFM rules in version 13.1.0 or higher. It is expected due to new design has been implemented since version 13.1.0 and introducing Inline Rule Editor functionality on "  Active Rules " page

By default, the page *no longer* displays the policies for all available contexts. However, there is a flag, available under "Security  ››  Options : Network Firewall : Firewall Options", called  "Inline Rule Editor" that can be de-selected to revert to the old version of the active rules page.

Important: Please note that disabling the Inline Rule Editor can negatively impact rule logic when you create or edit firewall rules, and may cause the edited firewall policy to be unusable. F5 recommends that you leave the Inline Rule Editor setting in the enabled state, which is the default.

Recommended Actions

As part of the new design, you need to select the context first (using the context filter at the top of the page) to view the rules associated with that context. For that selected context, the Global and associated Route domain policies are displayed along with the context policy.
