K54388110: TCP FTPS Connections May Fail After Upgrade to 14.1.x

Type
Support Solution
Published
2019-09-13
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.0
Source
https://my.f5.com/manage/s/article/K54388110

Description

TCP FTPS connection not going through the BIG-IP

  • FTPS connections fail from the initiating client.
  • AUTH TLS is not being send out of the BIG-IP

Environment

  • Upgrade to BIG-IP 14.1.x code from BIG-IP 12.x - 13.x
  • Virtual server with FTP profile and "Allow FTPS" checked.

Cause
Bug ID 760206

Recommended Actions

  1. Use tmsh to set the correct setting:
    tmsh modify ltm profile ftp <ftp_profile_here> ftps-mode allow
    tmsh save sys config

    For Example:
    tmsh modify ltm profile ftp ftp_profile ftps-mode allow
    tmsh save sys config

Additional Information

FTPS mode syntax in v14 has changed, creating an invalid entry.

In BIG-IP 14.1.0  for FTP profile (Local Traffic ›› Profiles : Services : FTP), "Allow FTPS" (Check box) setting is removed and "FTPS Mode"  (Dropdown) is introduced.
In 13.x  “allow_ftps”  attribute of FTP profile in TMUI object is used for storing the “enabled/disabled” value of "Allow FTPS" (Check box)  and this is deprecated in 14.1.x
For storing  "FTPS Mode"  in 14.1.x “ftps_mode” attribute is introduced.
