Description

AGC configuration may throw an error such as:
Operation to the configProcessor timed out after waiting 180 seconds. Please increase the timeout or contact the iApp writer for further instructions.
Very likely this is because the BIG-IP configuration is making use of IP(s) with non default route domain.

Environment

  • BIG-IP using Guided Config to deploy Access use cases
  • route domains

Cause

Access Guided Config validation was preventing configuration with virtual server using route domain from loading.

Recommended Actions

Please request an AGC Hotfix from F5 Support referencing bug ID 1066813.
