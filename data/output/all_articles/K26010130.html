Description

You may encounter following error message when you attempt to import ASM policies using Traffic Management Shell (tmsh):

Data Input Error: ASMConfig exception: [203] Could not update the Policy '/Common/test'.  Parent and Child policies cannot have different Differentiate between HTTP and HTTPS URLs

Environment

  • BIG-IP ASM
  • Parent and Child policies

Cause

The issue happens when child policy does not match the parent policy for the "Differentiating between HTTP and HTTPS URLs" setting. Both (policies) should be set to the same setting either enabled or disabled for the "Differentiating between HTTP and HTTPS URLs" setting.

Recommended Actions

You should import backup child policy which matches the parent policy using BIG-IP ASM GUI. Once child policy is imported, you can use TMSH to test your policy. To workaround this issue, you can perform the following steps:

  1. Export the child policy as XML file
  2. Edit to change the setting to match the parent policy for the "Differentiating between HTTP and HTTPS URLs" setting
  3. Import the modified child policy through ASM GUI
