K43631080: BIG-IQ is Unable to import BIG-IP config with error ''Invalid name: [LTP name]:[rule name]. Invalid address ([LTP name]:[rule name]). Address is incomplete''

Description

  • Getting error when importing BIG-IP config to BIG-IQ.
  • Example of error:

    Failed to copy configuration to working-config; reason: Failed copying from source subcollections to target subcollections: java.lang.IllegalArgumentException: Invalid name: myrule:app1. Invalid address (myrule:app1). Address is incomplete

Environment

  • BIG-IQ 
  • BIG-IP with LTM policy configured

Cause
LTM Policy has a ":" in the Policy Rule name

Recommended Actions

Note : To be done in BIG-IQ Central Management
  1. Remove all services for the clustered managed BIG-IP.
  2. Remove this cluster of BIG-IP's from the device list.
After removing the BIG-IP from BIG-IQ, do the following below :

Note : To be done in BIG-IP.
Note : Perform the following on the standby unit first. 
  1. Backup a copy of the bigip.conf.
    Example:
    # cp bigip.conf bigip.conf.backup
     
  2. Remove all ":" from the Policy rule.
    Example:

    # nano bigip.conf
    }
    ltm policy /Common/Drafts/<Policy_Name> { <------------ this is your policy name
    controls { forwarding }
    published-copy /Common/<Policy_Name>
    requires { http tcp }
    rules{
    "<Name>:<Name>" { <---------- this is the name of the rule in the policy above, you have to remove the ":" from the name
     
  3. After removing all ":" from Rule name save the edits and exit from nano.
     
  4. Apply the changes made to the config.
    # tmsh load sys config
     
  5. Sync selected device config to the group.
     
  6. Once all devices are sync to the group you can go to each device and verify if the config was successfully copied by using the command below:
    # less bigip.conf to exit press "q"
     
  7. Go back to the BIG-IQ and try adding back the devices that you removed.
