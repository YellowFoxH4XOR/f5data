Description

Vlan double-tagging (QinQ / 802.1ad) is not currently supported for Virtual Wire deployments. This article previously described how to configure Big-IP SSLO to use a VLAN group using "double-tagged" frames (QinQ / 802.1ad) in a Virtual Wire SSLO setup, however this has been confirmed by PE not to be currently supported (as of 31 January 2025).

 

Environment

BIG-IP SSLO with Virtual Wire


Cause

Vlan double-tagging (QinQ / 802.1ad) is not currently supported for Virtual Wire deployments.

None
