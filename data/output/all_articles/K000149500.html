Description

Welcome to the F5 Flex Consumption Program (FCP), which enables you to manage license keys for BIG-IP Virtual Editions. This article outlines the changes in FCP license management. 

Environment

Before January 13, 2025:

  • Requires BIG-IQ License Manager/Central Manager
  • License bundles offered through LOAD SKUs or Catalog (CAT) SKUs.
  • The BIG-IQ manages functions including:
    • Activate licenses
    • Assign licenses
    • Revoke licenses
    • Report license status

After January 13, 2025 (First time FCP customers):

  • No longer requires the use of BIG-IQ for license management and reporting.
  • Customers can manage licenses directly through the MyF5 Self Service portal, including:
    • Generate license keys
    • Unassign license keys
    • Reassign license keys
    • Terminate license keys

After January 13, 2025 (Customers renewing existing FCP):

  • Customers will be able to run both environments until fully migrated from BIG-IQ licensing (CAT SKUs) to license keys from MyF5 Self Service portal.

Additional Option:

  • BIG-IQ remains available for automation and scripting purposes with licenses generated through MyF5 Self Service portal.
  • This provides flexibility for users who prefer or require the continued use of BIG-IQ in their operations.

Recommended Actions

During this migration from LOAD/CAT SKUs on the BIG-IQ to MyF5 Self Service license keys, there are different procedures, reference articles, and/or processes depending on your FCP environment. Select the appropriate articles based on the criteria listed below each article.
Note: Your environment may include both options until you fully migrate to MyF5 Self Service portal.

K000148267: Welcome to the MyF5 Self Service Flex Consumption Program (FCP)

  • FCP contract renewed after January 13, 2025
