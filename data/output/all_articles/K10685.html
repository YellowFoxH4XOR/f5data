Known Issue

This is the result of a known issue. The FirePass Windows antivirus checker cannot detect PCSecurityShield The Shield Deluxe 20xx. If you configure a pre-logon sequence that uses the Windows antivirus checker, users running PCSecurityShield The Shield Deluxe 20xx will fail the antivirus check.

The FirePass Windows antivirus checker uses software libraries from a software development kit (SDK) created by OPSWAT, Inc. OPSWAT provides a vendor-independent framework for endpoint security management. OPSWAT has provided updated software to resolve this issue.

F5 Product Development tracked this issue as ID 295748 (formerly CR130981) and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

This issue was fixed in hotfix-133186-1 for all supported FirePass versions. You may download this hotfix or later versions of the OPSWAT hotfix from the F5 Downloads site.

For instructions about obtaining and installing an OPSWAT hotfix, refer to K6664: Obtaining and installing OPSWAT hotfixes.
