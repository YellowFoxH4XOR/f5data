Description

After enabling the interface using GUI in BIG-IP VIPRION device, still the interface shows as disabled state for interface and interface is not enabled. The same applies to enabling/disabling interface using tmsh command.

 

Environment

  • BIG-IP VIPRION device
  • Command tmsh list net interface -list the SFP details for the affected interface correctly
  • BIG-IP platform is using F5 qualified transceiver modules K8153
  • tmsh show /sys cluster all-properties shows all blade are running
  • No BIG-IP VIPRION backplane error after following K14764

Cause

Unknown

Recommended Actions

1. Restart service bcm56xxd in the BIG-IP VIPRION device

tmsh restart sys service bcm56xxd

 

Impact of procedure: BIG-IP system traffic processing is interrupted while the restarting service bcm56xxd.

 

If the still issue is not resolved, proceed to the next step

 

2.  Follow the procedure Force the mcpd process to reload the configuration (BIG-IP 10.x and later) mentioned in K13030

 

Impact of procedure: BIG-IP system traffic processing is interrupted while the system restarts.

 

If the still issue is not resolved, please create case with F5 support for further check
