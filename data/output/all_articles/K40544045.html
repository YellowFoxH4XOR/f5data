Issue

Error Message

warning tmm<#>[<PID>]: 01200017:4: Warning, pool member IP <IP_addr> port <port_number> for pool <pool_name> has reached its connection limit

In this error message, note the following:

  • <#> is the number of the Traffic Management Microkernel (TMM) process that generated the message.
  • <PID> is the process ID for the tmm process.
  • <IP_addr> is the pool member IP address.
  • <port_number> is the pool member port number.
  • <pool_name> is the name of the assigned pool for the pool member.

For example:

warning tmm3[18484]: 01200017:4: Warning, pool member IP 10.10.10.1 port 80 for pool /Common/example_pool has reached its connection limit.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You configure the Connection Limit setting for a pool member on the BIG-IP system.
  • The number of concurrent connections to the pool member exceeds the configured limit.

The BIG-IP system divides the configured connection limit for a given object by the number of TMMs running on the system and distributes the remainder among the lower-ordered TMMs.

Note that connections may not be distributed evenly, and, if the number of the running TMMs is high, the configured connection limit on each single TMM may be easier to reach. For more information on how the connections are distributed, refer to: K14358: Overview of Clustered Multiprocessing (11.3.0 and later)

Impact

Subsequent connections processed by this TMM process to pool members are rejected until the number of connections falls below the limits configured for the pool.

Recommended Actions

To mitigate this issue, you can increase the connection limit for the pool member to an appropriate value for your environment. To do so, perform the following procedure:

Impact of procedure: The following procedure increases the the allowed number of connections to the BIG-IP system, which may impact resources. You should perform testing in order to determine an appropriate connection limit value for your environment.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Pools.
  3. Select the pool for which you want to define the connection limit.
  4. Select the Members tab.
  5. Select the pool member for which you want to define the connection limit.
  6. Under Configuration, for Connection Limit, enter an appropriate value.
  7. Select Update.
