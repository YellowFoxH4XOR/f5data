Description

When trying to restart the BIG-IP Tomcat server via CLI command "bigstart restart tomcat", the BIG-IP prompted below error.

(tmos)# bigstart restart tomcat
Syntax Error: unexpected argument "bigstart"

Environment

  • BIG-IP
  • CLI TMOS
  • CLI Bash
  • Bash Command "bigstart"

Cause

CLI command "bigstart" is a bash command and not TMOS command

Recommended Actions

  1. Run the bash command "bigstart" via bash mode instead of TMOS.
    (tmos)# bash
    bigstart restart tomcat

  2. Alternatively, may also restart the tomcat service with tmos command "restart /sys service tomcat"
    (tmos)# restart /sys service tomcat
