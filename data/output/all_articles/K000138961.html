K000138961: Management GUI not accessible and high CPU usage on BIG-IP system

Description

You are seeing high CPU usage, especially by some Virtual Server. Additionally, the Management GUI is not accessible.

Environment

  • BIG-IP LTM
  • GUI
  • logging

Cause

The virtual server that consumes a lot of CPU is configured with profile security-log-profiles, in which options such as local-syslog and local-db are enabled. These options cause a large volume of logs to be directed locally to the machine, resulting in device overload.

Recommended Actions

Detach the profile from the Virtual Server or disable local-syslog and local-db options. If necessary configure the profile to send logs to a remote syslog server.
