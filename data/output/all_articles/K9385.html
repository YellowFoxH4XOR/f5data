You can configure a Network Access connection to automatically run a Windows domain logon script once the connection is established. To do so, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Network Access: Resources page.
  3. Click the Launch Application tab.
  4. In the Resource Group menu, select the name of the resource group you want to configure.
  5. In the App Path field, enter the following:

    logon

  6. In the Parameters field, enter the following, where <domain_controller_ip_address> is the IP address of the Windows domain controller and <domain_name> is the name of the Windows domain:

    \\<domain_controller_ip_address>  %username%

    or

    <domain_name> %username%

  7. In the OS menu, select Windows.
  8. Click the Add button.

In order for the domain logon script to correctly execute on a remote client system, the following six requirements must be met:

  • The client system is running Microsoft Windows 2000, Windows XP, or later.
  • The client system is a member of the specified domain.
  • The user’s Windows domain logon name is identical to the user’s FirePass logon name.
  • When the user logged on to the client system, the user logged on to the specified domain using the cached domain credentials.
  • On the domain controller, the logon script is configured in the user’s profile.

    • Important: Logon scripts configured in a Group Policy will not execute.

    Important: If no logon script in configured in the user’s profile on the domain controller, the FirePass client-side component opens the Netlogon share in Windows Explorer after the Network Access connection establishes, but no script is executed. The Netlogon share is typically mapped to the %SystemRoot%\SYSVOL\sysvol\<domain DNS name>\scripts directory on the domain controller.

  • The user has the necessary Windows file permissions to execute the logon script
