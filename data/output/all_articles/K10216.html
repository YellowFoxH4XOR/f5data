Known Issue

This is the result of a known issue. The BIG-IP ASM policy merge feature allows you to merge two security policies into one policy. The policy merge feature also produces a merge report file that contains comprehensive information about differences between the two policies. When attempting to use the policy merge feature to merge two security policies, the Configuration utility may become unresponsive. When this issue occurs, no errors are logged on the system, and the merge operation does not complete.

F5 Product Development tracked this issue as CR104227 and it was fixed in BIG-IP ASM 10.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Workaround

If you attempt to merge BIG-IP ASM security policies and the Configuration utility is unresponsive, you can work around the issue by terminating the policy_merge.pl process from the command line. To do so, type the following command:

kill `ps | grep policy_merge.pl | grep -v grep | awk '{print $1}'`

The Configuration utility becomes responsive immediately after terminating the merge process.
