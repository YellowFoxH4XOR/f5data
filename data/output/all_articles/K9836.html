Topic

When using the BIG-IP LTM SSL client certificate LDAP authentication profile, the User Key setting allows you to specify the field in the LDAP database to be searched for the user ID that is presented in the client certificate. Only one database field name may be entered as the User Key value.

F5 Product Development is tracking a request for enhancement to allow more than one field name in the User Key field as CR108187.
