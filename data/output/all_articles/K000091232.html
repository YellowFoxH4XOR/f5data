K000091232: Authorization error (403) creating or editing Security Strategies

Type
Support Solution
Published
2022-01-21
Updated
2022-03-01
Source
https://my.f5.com/manage/s/article/K000091232

SYMPTOM
In UI, creating or editing a Security Strategies object fails with error "Error Fetching Security Strategy API Error (403): unauthorized"

CAUSE
Security Strategies objects implement Security Policies

RESOLUTION
Update/Create user_role and include FULL access to /security/strategies and /security/policies
