Known Issue

When a Network Access session is interrupted and then resumes (for example, during a brief network outage), BIG-IP APM does not renew the lease on the client’s lease pool IP address. As a result, the lease may expire while the client is still connected and BIG-IP APM may attempt to reassign that IP address to a new Network Access connection.

F5 Product Development tracked this issue as ID 225874 (formerly CR140361) and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3402.0-HF2, issued for BIG-IP version 10.1.0, and Hotfix-BIGIP-10.2.0-1755.1-HF1, issued for version 10.2.0. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.
