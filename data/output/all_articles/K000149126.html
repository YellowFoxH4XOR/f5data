Description

How you can collect F5 BIG-IP Local Traffic Manager (LTM) logs by using a Google Security Operations forwarder | Filtering log messages sent to Google Cloud

Environment

  •  BIG-IP LTM
  •  Google Cloud

Cause

You want to collect F5 BIG-IP Local Traffic Manager (LTM) logs by using a Google Security Operations forwarder.

*Note: LTM event logs such as ssl_acc and ssl_req aren't supported by the collector, so these log types must be filtered out on the device.

Recommended Actions

Perform the following actions:

1. Sign in to SSH using BIG-IP root credentials.

2. Sign in to the Traffic Management Shell (tmsh) with the following command: tmsh

3. Send filtered log messages to remote syslog servers with the following command: modify /sys syslog remote-servers none

4. Verify there's a syslog include statement that defines a filter rule and the remote server using the next command: list /sys syslog all-properties.

5. Replace the include none statement with the following information, using the next tmsh command:

modify /sys syslog include "filter f_remote_loghost {level(debug..emerg);};filter f_ssl_acc {not match(\"ssl_acc\");};filter f_ssl_req {not match(\"ssl_req\");};destination d_remote_loghost {udp(\"<IP*>\",port(<port*>));};log {source(s_syslog_pipe);filter(f_remote_loghost);filter(f_ssl_acc);filter(f_ssl_req);destination(d_remote_loghost);};"

*Confirm that you're adding the correct IP and port.

6. Save the configuration with the following command: save /sys config

Additional Information

Configure Google Security Operations forwarder and syslog to ingest F5 BIG-IP LTM logs

  1.    Go to SIEM Settings > Forwarders.
  2.    Click Add new forwarder.
  3.    In the Forwarder Name field, enter a unique name for the forwarder.
  4.    Click Submit. The forwarder is added and the Add collector configuration window appears.
  5.    In the Collector name field, type a name.
  6.    Select F5 BIGIP LTM as the Log type.
  7.    Select Syslog as the Collector type.
  8.    Configure the following mandatory input parameters:
  9.    Protocol: specify the protocol.
  10.    Address: specify the Google Security Operations forwarder IP address.
  11.    Port: specify the port.
  12.    Click Submit
