Description

A remote authenticated user with CLI access can only access TMSH by default and will not be able to access the advanced shell directly.

Environment

  • BIG-IP
  • Using remote authentication (TACACS+, Radius, LDAP)

Cause

This behavior is by design, that the remote-authenticated users won't be able to access advanced shell (bash) directly.

Recommended Actions

You may use the below command to switch to bash shell after login.
# tmsh run util bash

Additional Information

K40947119: Configuring TACACS+ remote role group on BIG-IP from configuration utility
Note: In the above article, the remote-authenticated user configuration in the TACACS server only contains the ability to enable the CLI for a user or not, it does not allow you to choose between TMSH shell and advanced shell for that user.

auth remote-role {
  role-info {
    adm {
      attribute F5-LTM-User-Info-1=adm
      console %F5-LTM-User-Console  <=====!!!
      line-order 1
      role %F5-LTM-User-Role
      user-partition %F5-LTM-User-Partition
    }
