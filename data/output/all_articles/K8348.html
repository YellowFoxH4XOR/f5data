Known Issue

This is the result of a known issue. Specifying multiple close commands within an iRule may result in a TMM crash.

For example:

when HTTP_REQUEST {

HTTP::redirect "http://www.somesite.com"
catch HTTP::close
catch TCP::close
}

The TCP::close command is unnecessary and may result in TMM attempting to close a connection that has already been closed. As a result, TMM may crash.

F5 Networks Product Development tracked this issue as CR91738 and it was fixed in BIG-IP version 9.4.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in hotfix BIGIP-9.4.3-14.3-HF3 issued for BIG-IP version 9.4.3. You may download this hotfix or a later version of this hotfix from the F5 Networks Downloads site.
