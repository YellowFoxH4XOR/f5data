K000138796: User change of password is required on first successful authentication attempt

Type
Support Solution
Published
2024-03-03
Updated
2024-09-09
Applies to
  • F5OS
  • F5OS-A: 1.5.1, 1.5.2, 1.7.X, 1.7.0
  • F5OS-C: 1.6.X, 1.6.2, 1.6.1, 1.6.0
Source
https://my.f5.com/manage/s/article/K000138796

Description

The default behaviour in F5OS-A 1.5.1 and F5OS-C 1.6.0 onwards requires all new users to change their password on their first successful login.

Environment

  • F5OS-A
  • F5OS-C
  • New user configuration and authentication/login

Cause

This enforcement is the resultant of F5OS FIPS certification requirement.

Recommended Actions

None

Additional Information
