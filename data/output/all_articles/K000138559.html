K000138559: Idle Enforcer does not activate

Type
Support Solution
Published
2024-02-09
Updated
2024-02-13
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000138559

Description

The Idle Enforcer functionality remains inactive when the CPU usage on the Data Plane surpasses 80%.

Environment

  • ASM 
  • APM

Cause

TMM plugin processes function on the management CPUs, and the BIG-IP system incorporates code to inhibit the Idle Enforcer from triggering when TMM identifies plugins operating on the management CPUs. This is to avoid depriving the management core of CPU resources when TMM is actively processing tasks with plugins.

Note: TMM Plug-ins refer to proprietary Linux processes outside of TMM so that the TMM process can work to accomplish additional traffic related options. For example, iLXplug-in, SSH plug-in, XML routing feature, NTLM, and also BIG-IP APM, BIG-IP ASM and BIG-IP PEM features.

Recommended Actions

None

Additional Information

If the idle enforcer detects any activity occurring with one or more Control Plane TMM plugins, it will not activate; otherwise, it will activate.
