Topic

FirePass offers the capability for organizations to sign the ActiveX and Java applets distributed dynamically to webtop clients. This functionality is configured on the .CAB files on the Device Management: Customization: Code Signing page. You may also use this same method to add digital signatures to the device driver by modifying the contents of the URXVPN.CAB file.

Note: If you would like the device driver installer to not use the default name of F5 Networks, you will need to resign the URXVPN.CAB file with your company's signing key. For more information about signing the individual file, refer to documentation provided by your key vendor.

Due to new driver code signing restrictions in Windows Vista, installation warning messages appear even for valid authenticode signed drivers.To eliminate this warning message, you must add your company's signing certificate into the Trusted Publishers List in the certificate store of any computer connecting to the FirePass device.

Adding a digital signature to the device driver

  1. Log in to FirePass Administrative Console. 
  2. Navigate to Device Management: Customization: Code Signing .
  3. Right-click and download the urxvpn.cab file.
  4. Extract the urxvpn.cab file.
  5. Within the urxvpn.cab file, extract the urvpn.exe file.
  6. Within the urvpn.exe file, the driver catalog (CAT) files exist. Locate the covpndrv.cat file.
  7. Resign the covpndrv.cat file with your authenticode signature tool of choice.
    Note: The required driver for 6.0.3 is the covpndrv.cat file. In prior versions to 6.0.3, the required driver is the urvpndrv.cat file.
  8. Open the urvpn.exe file with a tool that can replace files in packed EXE files.
  9. Replace the covpn.cat file in urvpn.exe with your resigned file.
  10. Use a .CAB packing tool to re-build the urxvpn.cab file with your new urvpn.exe file.
    Note: The other files should be left unchanged.
  11. Sign your new URXVPN.CAB file with your signature.
  12. Use Device Management: Customization to upload the new URXVPN.CAB to Firepass.

The VPN Device Driver installation warning for fresh clients should now have the details from the signature you've added to the driver catalog.

Adding the certificate to the trusted publisher list in the computer's certificate store in Windows Vista

If you do not want your users to receive the Device Driver installation warning, perform the following procedure:

  1. Open the certmgr.msc mmc snap in.    
  2. Navigate to View: Options.
  3. Below Show the following, select the Physical certificate stores check box.
  4.  Click OK.
  5. Navigate to Trusted Publishers:  Local Computer.
  6. Right-click Local Computer.
  7. Click All Tasks: Import.
  8. Follow the wizard instructions to import your certificate used to sign the .CAT file.
