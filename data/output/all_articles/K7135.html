Known Issue

This is the result of a known issue. In rare cases, the AHA compression card firmware version 8.2.3 may cause data corruption. Refer to the AHA firmware update Release Note below if you have one of the following BIG-IP platforms with the AHA compression card:
  • BIG-IP 6400 (D63)
  • BIG-IP 6800 (D68)
  • BIG-IP 8400 (D84)

F5 Product Development tracked this issue as CR72557 and it was fixed in BIG-IP 9.3 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, Link Controller, or WebAccelerator Release Notes.

For information about installing the firmware update, refer to the AHA firmware update Release Note.
