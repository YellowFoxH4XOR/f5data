Description

When security scan performed against a virtual server, it fails with below result:
This server does not support Authenticated encryption (AEAD) cipher suites. 

The scan also shows below weak ciphers listed in scan result:
TLS_ECDHE_RSA_WITH_AES_128_CBC_SHA (0xc013)
TLS_ECDHE_RSA_WITH_AES_128_CBC_SHA256 (0xc027)
TLS_ECDHE_RSA_WITH_AES_256_CBC_SHA (0xc014)
TLS_ECDHE_RSA_WITH_AES_256_CBC_SHA384 (0xc028)
TLS_ECDHE_RSA_WITH_3DES_EDE_CBC_SHA (0xc012)
TLS_RSA_WITH_3DES_EDE_CBC_SHA (0xa) WEAK

Environment

  • Virtual server on HTTP with Client SSL profile
  • Security scan performed against virtual server 
  • Customer cipher string configured in Client SSL profile. 

Cause

AES-GCM cipher support AEAD cipher suit. This issue occurs when customer cipher string is configured with weak cipher suits and AES-GCM ciphers are not enabled. 

Recommended Actions

Follow below actions to resolve the issue:
  1. Verify currently configure cipher string in Client SSL profile which is attached to the virtual server. 
     
  2. To see the list of ciphers supported by current cipher string, use below command:
    tmm --clientciphers '<cipher_string>'

  3. Configure Client SSL profile with a string something like below which has AES-GCM ciphers enabled and most weak ciphers disabled including the ones listed in scan.

    'DEFAULT:!SSLv3:!MD5:!EXPORT:!RC4:!DH:!DHE:ECDHE+AES:!CAMELLIA:!ECDHE-RSA-AES128-CBC-SHA:!ECDHE-RSA-AES256-CBC-SHA:!AES128-SHA'

  4. You can use below command to check the ciphers available for above string.

    tmm --clientciphers 'DEFAULT:!SSLv3:!MD5:!EXPORT:!RC4:!DH:!DHE:ECDHE+AES:!CAMELLIA:!ECDHE-RSA-AES128-CBC-SHA:!ECDHE-RSA-AES256-CBC-SHA:!AES128-SHA'

  5. Run the SSL scan again to confirm the good rating.
