K000130619: Debugging log level of ipsec ike-daemon may lead to the TMM process restarting and producing a core file

Type
Support Solution
Published
2023-01-16
Updated
2023-03-22
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.2
Source
https://my.f5.com/manage/s/article/K000130619

Description

  • Due to iowait|high disk access by enabled ipsec ike-daemon debugging log level may lead to the TMM process restarting and producing a core file.
  • Default log level of ipsec ike-daemon is info.

Environment

  • LTM
  • IPsec

Cause

Leaving a debugging log level of ipsec ike-daemon may lead to the TMM process restarting and producing a core file due to iowait|high disk access.

Recommended Actions

  • To view current ipsec ike-daemon log level
tmsh list net ipsec ike-daemon ikedaemon log-level
  • To revert to the default debug level:

tmsh modify net ipsec ike-daemon ikedaemon log-level info

tmsh save sys config

Impact of workaround: Performing the following procedure should not have a negative impact on your system. 

Additional Information

None.
