Description

Vlan name had over 31 characters and hit Bug ID 1183901.

After shortening the vlan name, rebooted. Then numbers of daemons crashed, after reboot.

 

Environment

  • BIG-IP tenant
  • Bug ID 1183901
  • Modify vlan names
  • Reboot

 

Cause

  • Bug ID 1183901 could lead to unexpected situation.

 

Recommended Actions

Vlan name should be set with maximum 31 characters. 
When vlan name is modified and rebooted/reloaded the configuration, it can lead unexpected status, however re-reboot should fix the issue.
