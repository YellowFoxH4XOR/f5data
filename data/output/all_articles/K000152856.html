Description

Config analysis in NIM web ui invalidates an instance's configuration and the following error message is reported:

Error: premature end of file in <file>:<number>

Environment

NGINX Instance Manager

Cause

This issue can occur when the offending file in an instance's configuration has invalid NGINX [Plus] configuration, such as a certificate, and the file was created before all other files in the configuration.

Recommended Actions

In the NIM web ui, edit the instance's configuration, delete and re-add the offending file.

If the offending file is the only file in the configuration, delete it, add a blank file and then re-add the original file.
