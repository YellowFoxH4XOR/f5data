Description

The OESIS Engine SDK has been changed in v14.1 onwards. The OESIS SDK is used to perform endpoint inspection (epsec) checks for APM Access Policy tests.

Environment
  • BIG-IP APM
  • OESIS/OPSWAT version engine

Cause

Starting in BIG-IP APM builds >=14.1.0 OESIS V4 native libraries are implemented to provide endpoint inspection tests,
APM builds  before 14.1.0 will keep use V3V4 bridge SDK to be able to use the v3 code to match the newer v4 data with the old codebase.

Recommended Actions

  • To create OESIS report on BIG-IP v14.1 or later, use OESISv4
  • To create OESIS report on BIG-IP v14.0 and earlier, use OESISv3v4

Additional Information

The v4 native libraries were first included in epsec build 489.
