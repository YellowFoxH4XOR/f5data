K000135201: Not able to remove devices from the BIG-IQ

Type
Support Solution
Published
2023-06-23
Updated
2024-02-01
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0, 7.1.X, 7.1.0, 7.0.0, 7.0.X
Source
https://my.f5.com/manage/s/article/K000135201

Description

Unable to remove device from BIG-IQ.

The following message is shown after clicking "Remove Device" button from BIG-IQ GUI Devices tab:

BIG-IQ cannot remove the selected device because the device has service configurations on it or services are in the process of being removed

Environment

  • BIG-IQ
  • Remove device

Cause

Services are enabled for BIG-IP device

Recommended Actions

  1. Select BIG-IP device and click on "Remove All Services"
  2. Wait a few minutes for process to complete
  3. Attempt to remove device again
  4. If this process fails, review error message and see Additional Information.

Additional Information

K42012148: Failed to delete BIG-IQ applications in Configuration Utility
