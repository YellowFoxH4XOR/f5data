Description

After upgrade the Configuration Utility will only stay up for a few moments.

When logged into console (or ssh), multiple services are restarted every 30 seconds or so.

Device may say Standby or Active but due to services restarts is not functional.

Each restart is correlated to OutOfMemory errors in kern.log

Behavior did not occur on previous version.

Environment

Upgrade of LTM instance in vSphere (with or without modules)
Provisioning for MGMT is small
Number of objects in configuration is greater than 2000

Cause

Larger memory footprint for MGMT control plane in 15.1.3 causes memory allocation to be greater than 100% causing the continual OutOfMemory conditions.

Recommended Actions

There are at least three potential ways around this:

  1. Provision extramb on the command line (Configuration Utility is unavailable/unusable), see K26427018: Overview of Management provisioning. Note: you will  have to do this despite the continual OutOfMemory conditions and console messages about restarting services.  Be aware that taking memory from TMM in this way can have adverse impacts to traffic processing (i.e. capacity may be reduced).  Please check your traffic requirements when making such a change.
or
  1. Shutdown the VM
  2. Add more RAM to the instance
  3. Restart the VM
or
  1. Boot back into previous version
  2. Use the Configuration Utility to increase the memory provisioned for MGMT (Medium or Large depending on current setting), make sure to save the change.
  3. Delete previous upgrade attempt
  4. Preform the upgrade again
