Known Issue

The Simple Mail Transfer Protocol (SMTP) monitor may mark the server down, even if the server answers the HELO message.

This issue occurs when one or more of the following conditions are met:

  • The monitored server does not close the TCP connection (does not send a FIN) after receiving a QUIT command from the client.
  • The server does not include the word Bye in the 221 message in response to the QUIT sent by the BIG-IP system.
  • The server issues an RST packet for any reason after the BIG-IP system successfully receives the 250 response to the HELO message.

Impact

The SMTP monitor marks the monitored server down.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The monitor marks the server down.
  • The system reports the following messages if the Debug option is enabled for the monitor:

    Note: Debug mode logs to the /var/log/monitors directory and uses the following name format: <Partition Name>_<Monitor Name>-<Partition>_<Node IP Address>-<Port>.log.

    -- ERROR: failed to complete the transfer, error code: 28 error message: Time-out.

    -- ERROR: failed to complete the transfer, error code: 56 error message: Recv failure: Connection reset by peer.
