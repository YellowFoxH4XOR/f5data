Topic

You should consider using this procedure under the following condition:

  • You want to upgrade the LineRate Operating System (LROS) software to a later release.

Description

You can use the upgrade command to upgrade LROS software to a new version. When you upgrade LineRate to a new version, the system retains the previous version, including all configuration settings at the time of the upgrade. This allows you to roll back to the previous LineRate version if required.

The LineRate system may be installed as a single instance, or as part of a cluster in a high availability (HA) configuration. Common Address Redundancy Protocol (CARP) is used to provide HA, and allows for failover between members. For more information, refer to the CLI Reference Guide > Configure Commands > Interface Mode Commands > carp documentation for your version of LROS.

Note: You can use the existing license (registration key) when upgrading the LineRate system. To review your license, refer to the Try LineRate page.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have downloaded the relevant LineRate software from F5 Downloads.

Procedures

When upgrading clusters of LineRate systems, you should first upgrade standby systems, and then fail active systems over to standby, prior to performing upgrades to those systems.

  • Upgrading a standby or standalone LineRate instance
  • Promoting a LineRate system from standby (passive) to active (master)

Upgrading a standby or standalone LineRate instance

Impact of procedure: The LineRate system will be unavailable to process traffic during the upgrade process.

  1. To create a backup copy of the LineRate system, use the following command syntax:

    backup <uri> [full] [encrypt <key>]

  2. Copy the upgrade file to the /home/linerate directory on the LineRate system.

    For example, to copy the upgrade file from a remote Linux host to the LineRate system, you would use the following command syntax:

    scp <local_image.upg.gz> admin@<LineRate_IP>:/home/linerate/.</local_image.upg.gz>

  3. To upgrade the system, use the following upgrade command syntax:

    upgrade "<local_image.upg.gz>"

    Note: The upgrade command uses /home/linerate as the default directory.

  4. If the upgrade is successful, the LineRate system reboots.
  5. After the system has finished rebooting, to confirm that the new version is installed, type the following command:

    show version

Promoting a LineRate system from standby (passive) to active (master)

For redundant clusters, you can fail the active system over to perform the upgrade procedure.

Impact of procedure: The newly promoted active LineRate system will begin advertising itself as master. Current client connections must be re-established.

  1. Log in to the LineRate command line for the standby device you wish to promote to active.
  2. To enter configuration mode, type the following command:

    configure

  3. To select the interface you wish to configure, use the following command syntax:

    interface <interface_name>

    For example, to configure interface em1, type the following command:

    interface em1

  4. To select the CARP group you wish to configure, use the following command syntax:

    carp <group_number>

    For example, to configure CARP group 1, type the following command:

    carp 1

  5. To select the lowest available priority number in the CARP group, use the following command syntax:

    priority <number>

    For example, to configure the interface with a CARP priority of 1, type the following command:

    priority 1

    Note: CARP priority is lowest to highest, with 23 being the lowest possible priority.

  6. Save the configuration by typing the following command:

    write

  7. Use the show carp command to confirm failover.

    Output appears similar to the following example:

    nodeA# show carp
    em1 - Group 1
    State is Master since Wed Jan 7 13:22:55 2015
    Administrative state is up
    Shared CARP IP address is 192.168.99.1/32
    Virtual MAC is 0000.5e00.0101
    Priority 1
    Master is 192.168.99.133 (local), priority is 1


    nodeB# show carp
    em1 - Group 1
    State is Backup since Thu Jan 8 08:53:00 2015
    Administrative state is up
    Shared CARP IP address is 192.168.99.1/32
    Virtual MAC is 0000.5e00.0101
    Priority 2
    Master is 192.168.99.133 (remote), priority is 1

  8. You can now perform the upgrade procedure on the standby LineRate system.
