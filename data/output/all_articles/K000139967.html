Description

When viewing a QKView file in iHealth for an F5OS Chassis or Appliance, the top banner shows the version as 1.0 - regardless of the current version the device is running. 

Environment

  • F5OS
  • iHealth

Cause

Unknown at time of publication

Recommended Actions

  1. Open an F5OS QKView file in iHealth.
  2. Select Commands on the left side; it should default to Standard.
  3. From the list of commands, select system_manager.
  4. From that list, select system_manager - /confd/scripts/f5_confd_run_cmd show system image.
  5. This displays the currently running version, as shown in the following image.
