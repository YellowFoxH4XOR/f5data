Description

How to export virtual servers and pools to a CSV file.

Environment

  • BIG-IP LTM
  • virtual servers and pools configured
  • Export virtual servers and pools into CSV file


Cause

There is no functionality supported on BIG-IP system that will allow you to automatically export configuration elements such as virtual servers and pools to a CSV that can be opened in a sheet editor.

Recommended Actions

Use one of the following one-liners that create a CSV file, /var/tmp/virtuals.csv with a list of virtual servers and its pools.

Note: The script might need some further adjustments in order to return expected data matching your specific environment.

  •  Log in to bash and execute the command using the following syntax:
    for i in '<partition 1>' '<partition 2>'; do tmsh list ltm virtual /$i/* {pool destination} | awk '/virtual/{printf "%s,",$3}/destination/{printf "%s,",$2}/pool/{printf "%s,",$2; system("tmsh list ltm recursive "$0" {members} | awk '\''/:/{gsub(/ /, \"\", $0);gsub(/{/, \",\", $0);printf $s,$1}'\''");printf "\n"}'; done > /var/tmp/virtuals.csv
    For example:
    for i in 'Common' 'my_partition1'; do tmsh list ltm virtual /$i/* {pool destination} | awk '/virtual/{printf "%s,",$3}/destination/{printf "%s,",$2}/pool/{printf "%s,",$2; system("tmsh list ltm recursive "$0" {members} | awk '\''/:/{gsub(/ /, \"\", $0);gsub(/{/, \",\", $0);printf $s,$1}'\''");printf "\n"}'; done > /var/tmp/virtuals.csv 
    Note: To add more partitions, append the name in single quotes. For example: 'Common' 'my_partition1' 'my_partition2'. Or use a single partition with: 'Common'. The for loop would not be necessary in that case, but to avoid issues with the command, using a single loop item is fine.

    or
     
  • use the tmsh command to export full configuration of the virtual servers (each in single line) into text file.
    tmsh -q -c 'cd / ; list ltm virtual recursive one-line' > /var/tmp/virtuals.csv


Note: Afterwards the file can be opened in a sheet editor but might require some additional adjustments.
