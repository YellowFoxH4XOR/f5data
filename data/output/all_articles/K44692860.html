Known Issue

The BIG-IP ASM system may incorrectly parse JSON unicode encoded content.

This issue occurs when all of the following conditions are met:

  • The ASM security policy is configured with a JSON content profile.
  • The JSON content profile is configured to prohibit certain metacharacters.

Impact

The BIG-IP ASM system blocks legitimate JSON requests with an illegal meta character in value violation.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM system incorrectly parses JSON unicode encoded content into prohibited metacharacters.
  • The BIG-IP ASM system triggers an illegal meta character in value violation.

Workaround

To work around this issue, you can disable the check characters setting in the JSON profile. To do so, perform the following procedure:

Impact of workaround: Disabling the check characters setting can cause false negative as the BIG-IP ASM system may not allow illegitimate JSON content.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Content Profiles > JSON Profiles.
  3. Click on the relevant profile name for JSON.
  4. Click the Value Meta Characters tab.
  5. Clear the Check characters check box.
  6. Click Update.
  7. Click Apply Policy.
