Topic

This article applies to BIG-IP 9.x - 10.x. For information about other versions, refer to the following article:

  • K13853: Enabling logging for the WMI performance monitor (11.x)

When troubleshooting WMI performance monitor issues, it is often useful to view the raw data provided by the DLL. To view this data, you must enable WMI logging.

Important: The WMI log file can grow quickly. When WMI logging is enabled, monitor the size of the log file. Disable WMI logging as soon as you are finished troubleshooting.

Enabling WMI logging

To enable WMI logging, type the following command:

bigpipe db HttpAgents.WMI.log true

Note: The WMI log file, WMIHttpAgent.log, is located in the /var/tmp directory.

Disabling WMI logging

To disable WMI logging, type the following command:

bigpipe db HttpAgents.WMI.log false

The WMI log file is not removed when you disable WMI logging, nor is it rotated. You must remove the file manually.

Note: For more information about WMI performance monitoring for dynamic ratio load balancing, refer to K6914: Overview of the WMI performance monitor.
