K000150827: Terraform Import Sets Policy Template to BLANK on BIG-IP 17.x - POLICY_TEMPLATE_BLANK

Type
Support Solution
Published
2025-04-11
Updated
2025-04-11
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150827

Description

You are importing a policy using Terraform on BIG-IP Advanced WAF. Most policy elements—such as parameters, signatures, and allowed URLs—are successfully retained after import. However, you notice that the template_name value does not persist. Instead of retaining the intended value (e.g., POLICY_TEMPLATE_FUNDAMENTAL), the policy displays the template as POLICY_TEMPLATE_BLANK.


Environment

  • BIG-IP Advanced WAF
  • Terraform integration with BIG-IP provider
  • Version 17.x or later
  • Imported policy previously configured with a defined template (e.g., Fundamental, Rapid Deployment)

Cause

Starting in BIG-IP version 17.x, if the policyTemplateReference field is not explicitly set during policy import, the system automatically assigns POLICY_TEMPLATE_BLANK as the default value. This behavior results in Terraform detecting a difference in state between the imported policy and the desired configuration.


Recommended Actions

A fix has been developed and will be published in the official Terraform provider for BIG-IP. You can download the release and apply the updated version:

https://registry.terraform.io/providers/F5Networks/bigip/latest


Additional Information

This is a behavioral change introduced with the 17.x release of BIG-IP. Earlier versions may not exhibit this behavior, and the template name may persist without needing explicit reference in the import configuration.

This issue is cosmetic in nature and does not affect policy enforcement or traffic inspection behavior on BIG-IP Advanced WAF.
