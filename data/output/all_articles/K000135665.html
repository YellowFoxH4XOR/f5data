K000135665: After upgrade to 16.1.3.3 the browser displays extra "617" on the left top of the page

Type
Support Solution
Published
2023-07-31
Updated
2026-09-25
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000135665

Description

After upgrading to version 16.1.3.3, when accessing a virtual server via web browser, get the unexpected result:

  • On the top left of the page, show the number "617", it is unexpected.
  • The dynamic page may show unexpected content.

Environment

  • BIG-IP 16.1.3.3 LTM
  • Virtual server
  • HTTP profile
  • HTTP compression profile
  • HTTP analytics profile with "Page Load Time" enabled
  • HTTP response from pool member was chunked.

Cause

Bug ID 1311053.

 Recommended Actions

As a workaround, change db variable avr.cspm.inject.location to after_head.
tmsh modify sys db avr.cspm.inject.location { value after_head }
tmsh save sys config

Additional Information

None.
