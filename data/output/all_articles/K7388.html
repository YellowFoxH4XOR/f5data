Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following article:

  • K14534: Creating SSL certificates and keys with OpenSSL (11.x - 14.x)

Note: For BIG-IP 9.x and 10.x, F5 recommends that you create SSL keys, X509 certificates, and certificate signing requests using the Configuration utility, rather than the command line interface. For specific instructions, refer to the Configuration Guide for BIG-IP Local Traffic Management.

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

You can use the openssl command to create new Secure Sockets Layer (SSL) private keys, certificate signing requests (CSRs), and self-signed certificates. Depending on your requirements, perform one or more of the following procedures:

  • Generating a new SSL private key and CSR
  • Generating a CSR using an existing SSL private key
  • Generating a new SSL private key and self-signed certificate
  • Generating a self-signed certificate using an existing SSL private key

Note: For additional information about certificate-related tasks using the openssl command, refer to the Authenticating application traffic section of the BIG-IP Command Line Interface Guide (9.x), the Working with the OpenSSL Utility section of the Configuration Guide for BIG-IP Local Traffic Manager (10.x), or the openssl man page.

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Generating a new SSL private key and CSR

  1. Log in to the command line.
  2. To gnerate a new SSL private key and CSR, use the following command syntax:

    openssl req -out <CSR_path_and_name> -new -newkey rsa:1024 -nodes -keyout <key_path_and_name>

    Note: F5 recommends a minimum key size of 1024 bits. However, some CAs may require a 2048 bit key.

    For example, the following command creates a 1024-bit SSL private key and a CSR:

    openssl req -out /config/ssl/ssl.csr/f5test.csr -new -newkey rsa:1024 -nodes -keyout /config/ssl/ssl.key/f5test.key

    Note: You will be prompted to enter the certificate attributes.

    The SSL private key is written to a file named f5test.key in the /config/ssl/ssl.key/ directory, and the CSR is written to a file named f5test.csr in the /config/ssl/ssl.csr/ directory.

Generating a CSR using an existing SSL private key

  1. Log in to the command line.
  2. To generate a new CSR using an existing key, use the following command syntax:

    openssl req -new -key <key_path_and_name> -out <CSR_path_and_name>

    For example, the following command creates a new CSR using an existing SSL private key named f5test.key, and saves the CSR in the /config/ssl/ssl.csr/ directory as f5test.csr:

    openssl req -new -key /config/ssl/ssl.key/f5test.key -out /config/ssl/ssl.csr/f5test.csr

    Note: You will be prompted to enter the certificate attributes.

Generating a new SSL private key and self-signed certificate

  1. Log in to the command line.
  2. To generate a new SSL private key and self-signed SSL certificate, use the following command syntax:

    openssl req -x509 -nodes -days <# of days> -newkey rsa:<keysize> -keyout <key_path_and_name> -out <cert_path_and_name>

    Note: Replace <# of days> with the number of days in year increments for which you want the certificate to be valid.

    For example, the following command creates a 1024-bit SSL private key and a self-signed certificate that is valid for 1 year:

    openssl req -x509 -nodes -days 365 -newkey rsa:1024 -keyout /config/ssl/ssl.key/f5test.key -out /config/ssl/ssl.crt/f5test.crt

    Note: You will be prompted to enter the certificate attributes.

    The SSL private key is written to a file named f5test.key in the /config/ssl/ssl.key/ directory, and the certificate is written to a file named f5test.crt in the /config/ssl/ssl.crt/ directory.

Generating a self-signed certificate using an existing SSL private key

  1. Log in to the command line.
  2. To generate a new self-signed certificate using an existing SSL private key, use the following command syntax:

    openssl req -new -key <key_path_and_name> -x509 -days <# of days> -out <cert_path_and_name>

    Note: Replace <# of days> with the number of days in year increments for which you want the certificate to be valid.

    For example, the following command creates a new self-signed certificate using an existing SSL private key named f5test.key, and saves the certificate in the /config/ssl/ssl.crt/ directory as f5test.crt:

    openssl req -new -key /config/ssl/ssl.key/f5test.key -x509 -days 365 -out /config/ssl/ssl.crt/f5test.crt

    Note: You will be prompted to enter the certificate attributes.
