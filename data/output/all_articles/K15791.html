Known Issue

Swapping policy branches in the BIG-IP APM visual policy editor may fail.

Impact

You are unable to swap policy branches using the visual policy editor.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Swap operations using the visual policy editor fail with an error message that appears similar to the following example:

    Unable to complete request. Please refresh your vpe window.
  • Swap operations using the visual policy editor fail silently with no error message.

Resolution

Status

F5 Product Development has assigned ID 430330 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

There is no workaround for this issue. If you encounter this issue, you can use the visual policy editor to recreate the desired branches and delete the old branches.
