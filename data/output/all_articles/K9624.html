K9624: A UCS file may not contain BIG-IP ASM data if the /shared partition has less than five percent available space

Known Issue

This is the result of a known issue. A unified computing system (UCS) file may not contain BIG-IP ASM data if the /shared partition has less than five percent available space.

If less than five percent of available space is left on the /shared partition, and a bigpipe config save is performed to create a UCS file, the UCS file will be created without the BIG-IP ASM configuration data.

When the bigpipe utility encounters insufficient disk space to gather the BIG-IP ASM data, the following error message will be reported to console:

(DBD::mysql::db do failed: Error writing file '/var/tmp/ts_db.save_dir_20211.cstmp/ts_db.data.DCC.ACCOUNT_BLOCKING.cstmp' (Errcode: 28) at /usr/lib/perl5/site_perl/F5/ConfigSync.pm line 224.)

F5 Product Development tracked this issue as CR113190 and it was fixed in BIG-IP ASM 9.4.7 and 10.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.
