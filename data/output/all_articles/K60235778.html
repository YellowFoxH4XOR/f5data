Description

Alerts in /var/log/asm:

ControlPlane.CorrelationEngine[<PID>]: ControlPlane.CorrelationEngine`CRIT`<Date> <Time> `21122 `[throttle_alerts() at CorrelationEngine.cpp:442] Limit of real incidents exceeded by <#incidents> within last <#seconds> seconds
  • <PID> is the Process ID
  • <Date> is the Date of the occurrence
  • <Time> is the Time of the occurrence
  • <#incidents> is the number of real incidents
  • <#seconds> is the number of seconds elapsed

For example:

ControlPlane.CorrelationEngine[1234]: ControlPlane.CorrelationEngine`CRIT`Jan 01 12:00:00.000 `21122 `[throttle_alerts() at CorrelationEngine.cpp:442] Limit of real incidents exceeded by 90 within last 60 seconds

Environment

  • ASM Correlation Engine
  • Illegal requests detected

Cause

These messages are benign and can be safely ignored.
The Event Correlation feature allows the ASM to aggregate illegal requests detected within short period of time as a single security event.
In order to save resources, the Event Correlation limits the number of events stored in the memory.
After reaching the limit the system will stop adding new incidents, and the Limit of real incidents exceeded message is logged.

Recommended Actions

None

Additional Information

The Event Correlation limits are defined in the /etc/ts/correlation/correlation.cfg configuration file:

<...>
// RealLimit - limit of real incidents in memory
RealLimit=1000
<...>
