K000130340: Disable SNMP alerts for all Virtual Servers in a partition

Published
2022-12-23

Source

Description

You want to disable default SNMP traps or email notifications for all virtual servers in a specific partition.

Environment

  • BIG-IP Partitions 
  • Disable SNMP alerts 

Cause

Configuration
 

 Recommended Actions

1. Log in to the Advanced Shell (bash).
2. Review the log file to locate the alert message for which you want to disable notifications.
3. Back up the user_alert.conf file by typing the following command:
cp /config/user_alert.conf /config/user_alert.conf.backup
 
4. Using a text editor such as the vi utility, open the user_alert.conf file for editing.
5. Create a new alert entry using the following syntax:
alert VIP_DISABLE_ALERT "Virtual /<Partition name>/(.*)" {
# snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.999";
}
Example to disable SNMP alerts or email notifications for all the virtual servers in Test partition :
alert VIP_DISABLE_ALERT "Virtual /Test/(.*)" {
#          snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.999";
}
6. Save the changes made to the user_alert.conf file.
7. Restart the alertd process to load the file changes by typing the following command:
tmsh restart /sys service alertd


With this configuration, the user_alert.conf file is read after the alert.conf file, effectively disabling the trap and email notifications for all in Virtual servers in a specific partition.
