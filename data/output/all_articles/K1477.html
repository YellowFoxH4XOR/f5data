K1477: Reasons why 3-DNS may indicate that the status of a virtual server is unavailable (red) when nodes are still available in the virtual server

Type
Knowledge
Published
2006-02-17
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • 3-DNS: 4.6.4
Source
https://my.f5.com/manage/s/article/K1477

Topic

If a virtual server is configured to use a rule and any of the pools that are used by the rule are unavailable, 3-DNS will mark the virtual server as unavailable.
