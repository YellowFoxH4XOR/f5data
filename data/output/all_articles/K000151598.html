Description

You are looking for a way of fetching and showing the collected value of 'memberOf' attribute from AD Query Agent in your Access Policy, once the user sent the Credential to login and provided the details of the corresponding Group Name. 

Environment

  • Checking the value of 'memberOf' attribute
  • Access Policy configured with an AD Query Agent 
  • APM Module

Cause

There is no simple and direct way of checking the collected value of the 'memberOf' attribute in Access Policy.

Recommended Actions

The "memberOf" attribute is typically populated by an 'AD Query' Agent in your Access Policy. And, the return value of this attribute is stored in a session variable called "session.ad.last.attr.memberOf". There are some suggested ways to fetch this specific value, as following:

 

1. You can add a "Message Box" Agent on VPE under you desired Access Policy to pop-up and showing the fetched value of the attribute. In this regard, for debugging or testing purpose, you can simply use the below sample Message:

The user is a member of: %{session.ad.last.attr.memberOf}

 

2. You can also use the below command to put the filter based on desired SessionID and the corresponding learned ‘memberOf’ attribute:

# sessiondump --sid <sessionID> | grep session.ad.last.attr.memberOf

 

3. Below iRule sample script can be also helpful for checking and logging the desired attribute value:

when ACCESS_POLICY_AGENT_EVENT {
  # This event is triggered when an Access Policy agent completes its execution.
  # It's a good place to retrieve variables populated by agents like AD Query.

  if { [ACCESS::session data exists "session.ad.last.attr.memberOf"] } {
    set member_of_groups [ACCESS::session data get "session.ad.last.attr.memberOf"]
    log local0. "User is a member of groups: $member_of_groups"

    # Example: Check if the user is a member of a specific group
    if { $member_of_groups contains "CN=MyAdminsGroup,OU=Groups,DC=example,DC=com" } {
      log local0. "User is an administrator!"
      # Perform other actions, e.g., assign resources

    }
  }
}
