K02553442: How To Renew SSL Certificate Used By HTTPS Health Monitor Affected By Bug ID 932461 Using BIG-IQ

Description

This article provides the procedure using BIG-IQ for renewing the certificate used by a server SSL profile that is attached to HTTPS health monitor on a BIG-IP affected by Bug ID 932461 .

Environment

  • BIG-IQ managing a BIG-IP
  • Server SSL Profile attached to HTTPS health monitor
  • SSL Certificate being renewed
  • Bug ID 932461 affecting BIG-IP

Cause

Bug ID 932461 causes the HTTPS monitor to still try and use the previous certificate even after it has been renewed.

Recommended Actions

1. Renew the cert.
   Navigate to Configuration > Local Traffic > Certificate & Keys, and click the name of the certificate that is to be renewed.
   Click the 'Renew Certificate' on top right of the certificate screen.
   Populate the fields, if necessary, then click Renew.

2. Create a new server SSL profile
   Navigate to Configuration > Local Traffic > Profiles.
   Create a new server SSL profile. Select the cert/key/chain that was renewed.
   Click Save & Close.

3. Swap out the old profile from the health monitor.
   Navigate to Configuration > Local Traffic > Monitors.
   Select the https monitor which needs to be updated with the new SSL profile.
   In the monitor's SSL profile, select the newly-created SSL profile name.
   Click Save & Close.

4. Deploy the changes.
   Navigate to Deployment > Evaluate & Deploy > Local Traffic & Network.
   Create a deployment. Leave the default settings.
   Move the device which you need to deploy the change from Available to Selected.
   Click Create.
   Once evaluation has completed, and verified, click Deploy Now.

Once the changes have been deployed, managed BIG-IP should start using the same HTTPS monitor but with a new server SSL Profile with the renewed certificate.
