K14416812: F5OS-C Velos LCD panel is not responding, and F5 Logo ball not have lights.

Type
Support Solution
Published
2022-08-18
Updated
2023-02-21
Applies to
  • VELOS Platforms
  • F5OS
  • F5OS-C
  • VELOS CX410
Source
https://my.f5.com/manage/s/article/K14416812

Description
LCD touch panel is not responding.
Also F5 Logo ball is not having lights.
 

Environment

  • Velos
  • LCD touch screen
  • F5 Logo ball
  • Bezel

Cause
Possible hardware issue

Recommended Actions

Try to reinsert and Check below logs
  • /var/log_controller/events/event-log.log
  • /var/log_controller/velos.log
e.g.
Log in to Controller as root and run below command
grep -n -i lcd /var/log_controller/events/event-log.log
2313:65794 controller-2 module-present EVENT NA "Lcd removed" "2022-08-16 20:13:13.143680825 UTC"
2314:65794 controller-1 module-present EVENT NA "Lcd removed" "2022-08-16 20:13:14.229757737 UTC"
2315:65794 controller-2 module-present EVENT NA "Lcd present" "2022-08-16 20:13:19.143455113 UTC"
2316:65794 controller-1 module-present EVENT NA "Lcd present" "2022-08-16 20:13:20.230711661 UTC"

If you can not see "Lcd present", then check further with the below commands if they are repeadtedly logged.
grep -a -e "logoball" -e "lcd" /var/log_controller/velos.log
platform-hal[x]: priority="Err" msg="Action Error" index=0 message="error during LCD ZMQ request: error receiving LCD ZMQ reply: resource temporarily unavailable\n"

or

diag-agent[x]: priority="Info" msg="ChassisLocatorSubscriber - update LCD LogoBall Error" error=[error during LCD ZMQ request: error receiving LCD ZMQ reply: resource temporarily unavailable#012] interface="confd"
 

Additional Information

LCD touch panel, Bazel has two type for AC and DC, if you suspect replacement is required, please check which type you are using.
