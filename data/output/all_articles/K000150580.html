K000150580: AS3 cannot remove nested iRules in the same transaction

Description

AS3 cannot remove nested iRules in one transaction.

Environment

  • AS3 used to managed BIG-IP configurations.
  • an iRule referencing another iRule is part of the configuration.

 

Cause

AS3 software defect.

 

Recommended Actions

Resolved in 3.54.1.
