Description

Integrate the BIG-IP LTM and BIG-IP DNS, you may hit the following symptom:

  • Some virtual servers are not displayed in the DNS GSLB.
  • Some of the virtual server status is incorrect in the DNS GSLB.
  • Virtual server is not synced between BIG-IP DNS sync group.
  • BIG-IP DNS print the log below every 10 seconds in /var/log/gtm:

err iqsyncer[<PID>]: 011ae104:3: Gtm config sync result from local mcpd: result {

notice gtmd[<PID>]: 011a0006:5: hookOnChild: SYNC syncer exited with status == 0.(success)

notice gtmd[<PID>]: 011a001d:5: SYNC loading GTM config from: 10.10.10.10

Environment

  • BIG-IP DNS
  • BIG-IP LTM HA
  • DNS Sync group
  • Virtual server auto-disconvery

Cause

Incorrrectly configure the floating Self IP in the server configuration of LTM HA pair.

 Recommended Actions

  1. Navigate to DNS ›› GSLB : Servers : Server List, click the server name, in the tab "Devices", click the device name, remove the floating self IP.
  2. Restart gtmd and big3d on BIG-IP DNS.
bigstart restart gtmd big3d
