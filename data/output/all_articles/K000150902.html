K000150902: DHCP relay virtual server has stopped functioning.

Type
Support Solution
Published
2025-06-10
Updated
2025-06-10
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000150902

Description

  • DHCP relay virtual server has not working after configured.
  • From the pcap has found "Already connected flow: ERR_ISCONNECTED" message 

 

  1. <13> May 6 11:18:46 example.bigip.com notice DHCP:dhcp_client_server_relay_connect/4859: 0.0.0.0:68 -> 255.255.255.255:67: Already connected flow: ERR_ISCONNECTED
  2. <13> May 6 11:18:46 example.bigip.com notice DHCP:dhcp_client_server_relay_connect/4859: 0.0.0.0:68 -> 255.255.255.255:67: Already connected flow: ERR_ISCONNECTED

 

Environment

  • BIG-IP LTM
  • DHCP

Cause

There are existing connection, no connection records remains and initial incoming request does not match to existing connections.

 

Recommended Actions

  • Deleting existing connection and try test again. Please make sure that after deleting existing connection, no connection records remains and initial incoming request does not match to existing connections.

    Command to verify existing connection:
    # tmsh show sys conn cs-server-port 67 all-properties

    # tmsh show sys conn ss-server-port 67 all-properties


    Command to delete connection:
    # tmsh delete sys conn cs-server-port 67

    # tmsh delete sys conn ss-server-port 67

 

  • If the issue still persist use below command to restart tmm or reboot :

       # bigstart restart tmm 

       or

      # reboot

Note: Restarting TMM or reboot will interrupts all service traffic and other service traffic passes through. 

Additional Information
