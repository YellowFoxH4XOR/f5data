Known Issue

This is the result of a known issue. SOAP requests can have more than one immediate element child in the SOAP:body. However, the BIG-IP ASM system does not support SOAP requests that have more than one child in the SOAP:body.

When the BIG-IP ASM receives a request with more than two elements in the SOAP:body, the request is blocked and the following violation is reported: 

XML data does not comply with schema or WSDL document

For example, the following request will trigger a violation:

<soap:envelope>
    <soap:body>
        <xElement>5</xElement>
        <yElement>5.0</yElement>
    </soap:body>
</soap:envelope>

F5 Product Development tracked this issue as CR119455 and it was fixed in BIG-IP ASM version 10.1.0. For information about upgrading, refer to the BIG-IP ASM release notes.
