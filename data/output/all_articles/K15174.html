Issue

The virtual processor (vCPU) allocation limits for Virtual Clustered Multiprocessing (vCMP) guests has changed with various software releases for the following platforms:

  • BIG-IP 5200v (C109)
  • BIG-IP 5250v (C109)
  • BIG-IP 7200v (D110)
  • BIG-IP 7250v (D110)

Old Behavior

From version 11.0.0 through version 11.4.1 HF2 and 11.5.0, you are able to allocate up to eight vCPUs per vCMP guest.

From versions 11.4.1 HF3 and 11.5.1 through version 12.0.0 you are able to allocate up to four vCPUs per vCMP guest.

New Behavior

Beginning in version 12.1.0 and later, you can allocate up to six vCPUs per vCMP guest.

Impact

After upgrading the vCMP host (hypervisor) to software version 11.4.1 HF3 or 11.5.1 and later, vCMP guests will be downgraded to the maximum number of vCPUs for the software version.

Recommended Actions

None
