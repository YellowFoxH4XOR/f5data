K33719910: Recommendation for local DNS configuration on AWS VE

Type
Support Solution
Published
2020-12-09
Updated
2023-02-21
Applies to
  • Public Cloud
  • F5 Cloud Services
  • Amazon Web Services
Source
https://my.f5.com/manage/s/article/K33719910

Description
After statically configuring local DNS on AWS VE, DNS lookup server list are overwritten by DHCP via management.
It is best to use domain-name-servers at DHCP option on AWS if you need to configure local DNS server.

Environment

  • BIG-IP VE on AWS

Cause
None at time of publication. 

Recommended Actions

  1. Configure domain-name-servers at DHCP option on AWS

Additional Information

None
