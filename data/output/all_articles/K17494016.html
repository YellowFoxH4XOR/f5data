Description
daemon.log showing that icr_eventd keep on restarting,

emerg logger: Re-starting icr_eventd
emerg logger: Re-starting icr_eventd
emerg logger: Re-starting icr_eventd

Tried below but icr_eventd still keep restarting,

  • clear-rest-storage
  • bigstart restart restjavad
  • reboot
tmsh show sys service showing that icr_eventd down and waiting for restjavad while restjavad is up and running,

icr_eventd   down, 13:09:37 icr_eventd waiting for restjavad
...
restjavad    run (pid 4900) 22 hours
 

Environment

  • icr_eventd

Cause
Proxy config in /root/.curlrc break the icr_eventd init script.

Recommended Actions

  1. Remove /root/.curlrc
    • rm -rf /root/.curlrc
  2. Restart icr_eventd
    • bigstart restart restjavad

None
