Description

You want to know if the configuration option where you want to use HTTP::payload replace with MRF profile and HTTP/2 will work on BIG-IP.

Environment

  • BIG-IP
  • HTTP/2
  • MRF Profile

Cause

Information about the possibility of implementing HTTP::payload replace with HTTP/2 and MRF profile.

Recommended Actions

Implementing HTTP::payload replace with MRF profile and HTTP/2 is possible, but F5 strongly recommends testing this scenario in a staging environment before using it on a production device.
