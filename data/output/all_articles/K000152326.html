Description

When using the iRule log command to send log messages to his syslog server from time to time customer gets the following error message :

/var/log/ltm.5.gz:Jun 4 19:22:30 lab.unit.f5 tmm9[13175]: 01220001:3: TCL error: /Common/Syslog-rule - Traffic rejected (line 49) (line 49) invoked from within "log $syslog_server:$syslog_port $log_message"

Environment

  • TMOS
  • iRule

Cause

The reason for the failure means that BIG-IP is trying to send pkts through a full queue while log operations are excessive.

This can happen when you use the log command under a production virtual server that handles a lot of traffic, and iRule get executed a lot i.e.:

when CLIENT_ACCEPTED {
  # Define the syslog server IP and port
  set syslog_server "192.43.213.77"
  set syslog_port "10607"
  # Send the log message to the syslog server
  log $syslog_server:$syslog_port $log_message <---- problematic line
}
}

Recommended Actions

Best practice will be to use HSL for any high-volume logging and not log command
