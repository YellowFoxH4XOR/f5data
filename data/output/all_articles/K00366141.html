Description

  • APM RDP Remote Resource sessions do not establish when enabling Single Sign-On (SSO)
  • The same resource works fine with SSO disabled

Environment

  • BIG-IP APM
  • Remote Desktop resource (RDP) with Client Type set to "Native"
  • A firewall is in the path between BIG-IP and terminal server

Cause

With SSO enabled, the BIG-IP will use TLS when establishing the RDP session to the terminal server.
The firewall is configured to block TLS traffic on port tcp3389. Packet capture shows that BIG-IP gets TCP Reset when sending ClientHello as part of the RDP session.

Recommended Actions

  • Make sure the firewall does not block TLS on port tcp3389 for traffic between BIG-IP and the terminal server.
