Topic

Purpose

You should consider using this procedure under the following conditions:

  • You want to remove the BIG-IP DNS (formerly BIG-IP GTM) system from the BIG-IP DNS synchronization group.
  • You want to re-add the BIG-IP DNS system into the BIG-IP DNS synchronization group.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • The BIG-IP DNS system must already be part of an existing BIG-IP DNS synchronization group.

Description

A BIG-IP DNS synchronization group synchronizes the BIG-IP DNS configuration and metrics among its members. If you attempt to remove a member from the BIG-IP DNS synchronization group by changing the name of the BIG-IP DNS synchronization group for that member, the new name will be synchronized to the remaining members instead.

To properly remove a member from the BIG-IP DNS synchronization group, clear the Synchronization and Synchronize DNS Zone Files check boxes in the Configuration utility, or set the synchronization and synchronize-zone-files options to no in the TMOS Shell (tmsh).

To re-add the member to its previous BIG-IP DNS synchronization group, use the gtm_add utility.

Procedures

Removing a BIG-IP DNS system from the synchronization group

You can remove the BIG-IP DNS system from the synchronization group by performing the following procedure from either the Configuration utility or tmsh.

Impact of procedure: Depending on the BIG-IP version, performing the following procedure should not have a negative impact on your system. For BIG-IP 11.0.0 - 11.2.1, refer to K13899: The BIG-IP GTM may delete virtual servers after you disable synchronization.

Removing a BIG-IP DNS system using the Configuration utility (11.5.0 and later)

  1. Log in to the Configuration utility of the BIG-IP DNS system that you want to remove from the sync group.
  2. Navigate to DNS > Settings > GSLB > General.
  3. Clear the Synchronize check box and the Synchronize DNS Zone Files check box.
  4. Click Update.
  5. Change the Group Name to a unique name.
  6. Click Update.

Important: Depending on the timing, it is possible for other BIG-IP DNS systems in the Sync Group to detect the change in step 3,4 and update it's configuration, so you should verify the status on the other devices.

Removing a BIG-IP DNS system using the Configuration utility (10.x - 11.4.1)

  1. Log in to the Configuration utility of the BIG-IP DNS system that you want to remove from  the sync group.
  2. Navigate to System > Configuration > Global Traffic > General.
  3. Clear the Synchronization check box and the Synchronize DNS Zone Files check box.
  4. Click Update.
  5. Change the Group Name to a unique name.
  6. Click Update.

Important: Depending on the timing, it is possible for other BIG-IP DNS systems in the Sync Group to detect the change in step 3,4 and update it's configuration, so you should verify the status on the other devices.

Removing a BIG-IP DNS system using tmsh

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To remove the BIG-IP DNS system from the synchronization group, type the following command:

    modify /gtm global-settings general synchronization no synchronize-zone-files no

  3. Rename the synchronization group with a <unique name>

    modify /gtm global-settings general synchronization-group-name <unique name>

Save the change by typing the following command:

save /sys config gtm-only

Important: Depending on the timing, it is possible for other BIG-IP DNS systems in the Sync Group to detect the change in step 2 and update it's configuration, so you should verify the status on the other devices.

Re-adding a BIG-IP DNS system to the same synchronization group

You can re-add a BIG-IP DNS system to the same synchronization group by performing the following procedure.

Impact of procedure: The following procedure replaces the configuration from the BIG-IP DNS system on which it is run, with the configuration of the remote BIG-IP DNS system in the specified synchronization group.

  1. Log in from the command line of the BIG-IP DNS system that you removed from the synchronization group.
  2. To re-add the BIG-IP DNS system to the DNS synchronization group, type the following command:gtm_add <IP address of a member of the target DNS synchronization group>

Note: The synchronization group name on BIG-IP DNS will be updated with the existing synchronization group name

Important: Depending on the timing, it is possible for re-adding BIG-IP DNS systems to sync the change at "Removing a BIG_IP DNS system using the Configuration utility and tmsh" to remote BIG-IP DNS when performing gtm_add.
Before re-adding BIG-IP DNS, you should check if target DNS system has latest configuration time at local DNS and remote DNS. Please following K42042479 to check the BIG-IP DNS configuration time and workaround.
