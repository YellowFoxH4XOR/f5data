K000160666: Data Collection Plan for Troubleshooting ASM Live Update Connectivity via Proxy

Type
Support Solution
Published
2026-04-08
Updated
2026-04-08
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000160666

Description

Unable to update BIG-IP ASM live update using web proxy, where as bypassing the web proxy able to update

Environment

  • HTTPS Proxy server is configured in the BIG-IP ASM device. ( Refer K82512024 under section 'Configure BIG-IP ASM Live Update through an HTTPS proxy' to configure proxy server)
  • Updating the BIG-IP ASM signature live update through https proxy server fails, where as bypassing the web proxy able to update the BIG-IP ASM live update successfully in the device 

Cause

Proxy might drop the connections or BIGIP could be misconfigured.

Answer/Recommended Actions

1./ Validate Proxy Configuration: Please provide the current proxy settings configured on the BIG-IP system. Verify and ensure that the host, port, and authentication credentials are correct, or update them as necessary to align with your network environment.

# tmsh list /sys db proxy.*

sys db proxy.host {
    value "<null>"
}
sys db proxy.password {
    value "<password>"
}
sys db proxy.port {
    value "8080"
}
sys db proxy.protocol {
    value "http"
}
sys db proxy.username {
    value "<username>"
}

2./ Test network connection to  callhome.f5.com 

curl -kI -U username -x http://yourproxyaddress:8080 https://callhome.f5.com
or
curl -kI -x http://username:password@yourproxyaddress:8080 https://callhome.f5.com

Note: please confirm the username, password, and Proxy's IP address. 

3./ Test network connection to activate.f5.com server 

curl -kI -U username -x http://yourproxyaddress:8080 https://activate.f5.com
or
curl -kI -x http://username:password@yourproxyaddress:8080 https://activate.f5.com

Note: please confirm the username, password, and Proxy's IP address. 

4./ Resolve Domain Name: Ensure the BIGIP system resolves the domain names, 

nslookup callhome.f5.com
nslookup activate.f5.com

5./ Identify Egress Interface: Please confirm which interface the BIG-IP is utilizing to reach the F5 servers. The best practice is to route the connection through the Management interface, but it is not a strict requirement. 

ip route get <callhome.f5.com_IP_addr>
ip route get <activate.f5.com_IP_addr>

Note: Please replace domain names with IP addresses 

6./ Packet capture: If you confirm the BIGIP system sends the packets via MGMT interface, please use the below syntax and replace <proxy_ip> 

tcpdump -nnvi mgmt host  <proxy_ip> -v -w /var/tmp/F5support.pcap

Then update the ASM signatures, System  ››  Software Management : Live Update,  until fails. Stop the tcpdump (ctrl +c)

7./ Generate ASM qkview file: Please open the CLI (bash), copy/paste the below command, and collect the file: /var/tmp/support.qkview

# nice -19 asmqkview -s0 -f support.qkview

8./ File Upload: Upload all results and diagnostic artifacts to a new case for further technical review by the F5 Support team.
