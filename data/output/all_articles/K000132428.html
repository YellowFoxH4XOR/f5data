Environment

  • VELOS
  • Blade
  • Openshift cluster

Cause

Openshift cluster does not bring the blade to cluster properly.

Recommended Actions

Rebuild the OpenShift cluster with running "touch /var/omd/CLUSTER_REINSTALL" from the CLI on the active system controller, then run reboot.

None.
