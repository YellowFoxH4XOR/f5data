Description

tmsh create sys crypto key security-type password results in key created with security-type normal

Environment

  • Attempting to create a passphrase/password protected ssl key with tmsh

Cause

The tmsh shell does not support creating ssl keys password protected
Recommended Actions

Issue can be worked around by creating the passphrase protected ssl key with openssl and then importing:

  1. Create ssl key in bash shell with openssl

    openssl genrsa -des -out <key_path_and_name> <keysize>

    For example, the following command generates a new 2048-bit SSL private key in the /config/ssl/ssl.key/ directory named f5test.com_2015.key:

    openssl genrsa -des -out /config/ssl/ssl.key/f5test.com_2015.key 2048

  2. To install the new SSL private key and certificate into the BIG-IP filestore, use the following command syntax:

    tmsh install /sys crypto key <key_name> from-local-file <key_path_and_name> security-type password

    For example, the following commands install the SSL private key and certificate generated in the previous steps:

    tmsh install /sys crypto key f5test.com_2015.key from-local-file /config/ssl/ssl.key/f5test.com_2015.key security-type password
