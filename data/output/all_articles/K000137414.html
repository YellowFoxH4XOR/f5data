K000137414: VPN with proxy PAC only work in Windows I5 and not with Windows i7 Laptops

Support Solution
Published

2023-11-01
Applies to

  • BIG-IP APM: 16.1.2
Source

Description

VPN Edge Client with proxy PAC only work with Windows I5 and not with Windows i7 Laptops.

 

Environment

Edge Client

Proxy PAC

Windows i7 Laptops
Intel Processor 

 

Cause

This is not an APM or Edge Client issue.

 

Recommended Actions

Disabling below services solved the problem (some sort of compatibility issue):

Intel Connectivity Network Service

Intel Dynamic Bandwidth Management

IntelConnect Service
