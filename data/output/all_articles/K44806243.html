K44806243: Unable to view full Role description in GUI

Type
Support Solution
Published
2020-12-21
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K44806243

Description
When selecting Roles to add to System -> User Management -> Users or User Groups, the description of the Roles is not fully displayed due to the size of the window for adding the Role. Being unable to view the full description of a Role can make it difficult to understand it's privileges and scope.

Environment

  • BIG-IQ

Cause
Due the layout of the User and User Groups window, there is not sufficient room to fully display longer descriptions for roles and their descriptions are truncated.

Recommended Actions
The Roles and their descriptions can be easily viewed in the Role Management, rather than User Management section of the GUI. This is found in System -> Role Management -> Roles.

Additional Information
None
