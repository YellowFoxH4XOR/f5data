Topic

This article describes the order of precedence for a network address translations (NAT) object with a virtual server, with and without a SNAT pool.

Description

The BIG-IP system creates a source and destination listener for network address translations (NATs). A NAT listens for inbound requests matching the NAT IP address, and outbound requests originating from the NAT's origin IP address.

If a request originating from the NAT's origin IP address also matches a virtual server configured on the BIG-IP system, the virtual server will process the connection and the NAT translation address will be applied to the outgoing packet.

For example, the following configuration includes a NAT that maps the origin address of 10.10.64.2 to a translation address of 172.0.0.1, and a wildcard virtual server configured on the origin virtual local area network (VLAN). When the origin node, 10.10.64.2, initiates a request to a remote address, the wildcard virtual server processes the connection and the BIG-IP system applies the NAT translation address of 172.0.0.1 to the outgoing packet:

ltm nat example_nat {
    inherited-traffic-group true
    originating-address 10.10.64.2
    traffic-group traffic-group-1
    translation-address 172.0.0.1
}

ltm virtual /Common/wildcard_VS {
    destination /Common/0.0.0.0:any
    ip-protocol tcp
    mask any
    pool /Common/backend
    profiles {
        /Common/tcp { }
    }
    source 0.0.0.0/0
    translate-address disabled
    translate-port disabled
    vlans {
        /Common/internalvlan
    }
    vlans-enabled
}

In the following example, the configuration includes a NAT that maps the origin address of 10.10.64.2 to a translation address of 172.0.0.1, and a wildcard virtual server with a defined SNAT pool. It has an additional SNAT pool translation address compared to the previous one.

When the origin node, 10.10.64.2, initiates a request to a remote address, the wildcard virtual server processes the connection and the BIG-IP system applies the SNAT pool translation address of 172.0.0.2 to the outgoing packet. With this configuration, the SNAT pool translation address takes precedence over the NAT translation address.

ltm nat example_nat {
    inherited-traffic-group true
    originating-address 10.10.64.2
    traffic-group traffic-group-1
    translation-address 172.0.0.1
}
ltm virtual /Common/wildcard_VS {
    destination /Common/0.0.0.0:any
    ip-protocol tcp
    mask any
    pool /Common/backend
    profiles {
        /Common/tcp { }
    }
    source 0.0.0.0/0
    source-address-translation {
        pool /Common/snat_pool    ##Pool member 172.0.0.2 
        type snat
    }
    translate-address disabled
    translate-port disabled
    vlans {
        /Common/internalvlan
    }
    vlans-enabled
}

Note: For more information about the order of precedence for local traffic object listeners, refer to K9038: The order of precedence for local traffic object listeners.
