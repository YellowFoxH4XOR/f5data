Issue

When you run the 3ndc start or 3ndc restart command on large configurations, you may receive the following error message:

ERROR: 3dnsd is running but has not written to the file /var/run/3dnsd.pid
(it may still be loading)

Two of the most common reasons for receiving this error are:

  • You have a large, or complex, configurations running on older hardware.

  • There are syntax errors in the configuration file.

Large configurations running on older hardware

This error can occur when 3dnsd takes a long time to load due to the complexity of your configuration and the speed of your hardware. In this case, the error is benign.

Try waiting 30 to 45 seconds and run 3ndc status to see if it has written a pid (process ID) file. If a pid file has been written, the system will display a 3dnsd pid number. If the pid file has not been written, you will be notified that it is missing.

If 3dnsd does not write a pid file after 30 to 45 seconds, contact F5 Networks Customer Support for further assistance, or consider upgrading your hardware platform. Your account executive can provide you with more information regarding hardware upgrades.

Syntax errors in configuration file

This error may also occur because an edited configuration file contains syntax errors. In this case, sod-3dnsd (the daemon that ensures 3dns is running) will continually trying to restart 3dnsd and, because of the incorrect syntax, it is not able to load far enough to write a pid file.

In this case, you will also receive a message indicating that 3dnsd was restarted too many times too fast soon.

Verify that the 3-DNS Controller's configuration file syntax is correct by running the 3dparse -if <filename> command. If the configuration file syntax is incorrect, you will receive an error similar to the following:

3dparse: Initializing ...
3dparse: Parsing wideip.conf
wideip.conf:6: 'parse error' at character 'o' in line:
discovery_portlist {
o

If you receive the error, correct the syntax and rerun the 3ndc start or 3ndc restart command. You should not receive an error.

If the syntax contains no errors, you should receive the following message after running the 3dparse -if <filename> command:

3dparse: Initializing ...
3dparse: Parsing wideip.conf
3dparse: SUCCESS

If the 3-DNS configuration file syntax is not the cause for the error message, contact F5 Networks Customer Support for further assistance.
