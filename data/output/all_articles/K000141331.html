Description

When the Interface is UP but the LAG is down on one of the interface. From the interface statistics, the partner_oper_key is different on interfaces 5.0 and 6.0 on both the interfaces.

 

MEMBER MEMBER

NAME STATUS

----------------

5.0 UP

6.0 DOWN

4.0 32780 UP

5.0 32781 UP 

6.0 32782 IN_SYNC 

7.0 0 OUT_OF_SYNC

8.0 0 OUT_OF_SYNC

9.0 0 OUT_OF_SYNC

mgmt 0 OUT_OF_SYNC

 

Environment

  • F5OS-A
  • LAG

Cause

Mismatch in partner_oper_key (partner key) on the LACP interfaces.

Recommended Actions

Verify the partner_oper_key value,

  • Verify the LACP configuration for the partner key as they need to be identical across both the interfaces for proper LACP functionality.
  • Check if the physical cables are cross linked.
