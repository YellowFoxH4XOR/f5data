Known Issue

This is the result of a known issue. When upgrading from BIG-IP ASM 10.0.0 to BIG-IP ASM 10.0.1 or any cumulative hotfix for version 10.0.0, custom attack signature sets do not include systems that were added to the set prior to the upgrade. This issue occurs when the following two conditions are met:

  • The custom attack signature set is of the Filter-Based type.
  • The Signatures Filter setting has multiple systems listed in the Assigned Systems list.

After the upgrade, only the last system in the assigned systems list is present in the signature set. For example, a custom attack signature set named MY_SET_1 contains the following systems in BIG-IP ASM 10.0.0:

  • Outlook Web Access
  • WebDAV
  • Oracle
  • UNIX/Linux

After upgrading to BIG-IP ASM 10.0.1, the MY_SET_1 attack signature set only contains the following system:

  • UNIX/Linux

F5 Product Development tracked this issue as ID 329811 (formerly CR142288) and it was fixed in BIG-IP ASM 10.1.0. For information about upgrading, refer to the BIG-IP ASM release notes.
