K000135878: Error: 01070100:3: Can't delete user (user has no UID)

Type
Support Solution
Published
2023-08-31
Updated
2025-11-05
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.2
Source
https://my.f5.com/manage/s/article/K000135878

Description

Unable to delete a local user on a machine and receiving following error:

big-ip.com err mcpd[5715]: 01070101:3: Can't delete user (user CC has no UID)

Environment

BIG IP LTM

Cause

By default, all accounts that you create on BIG-IP with command line access are assigned UID 0.

This UID is required to run all of BIG-IP's command line utilities. However when the device is not able retrieve any UID it cannot perform the task.

 Recommended Actions

1. Delete offending user from /etc/password and  /etc/shadow using commands below which will automatically create a backup ending "e"

sed -ie '/<user name>/d' /etc/passwd
sed -ie '/<user name>/d' /etc/shadow

2. Delete the user from /config/bigip_user.conf using your favorite Linux text editor,

auth user <user name> {        <--- Delete all lines to 
    description < description>
    partition-access {
        all-partitions {
            role admin
        }
    }
    session-limit -1
    shell tmsh
}                <--- Delete all lines to here

3. Delete the home directories for this user

rm -rf /home/<user name>

Note: Whenever you create a test user, it creates its own home directory

4. Confirm if the user has now been deleted by trying to ssh into device using the user ID.

ssh <user name>@< bigip management IP >
