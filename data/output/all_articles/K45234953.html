K45234953: SNMP Traffic Volume Statistics for Node, Pool and Pool Member

Type
Support Solution
Published
2022-02-24
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K45234953

Description

SNMP provides traffic volume statistics in bytes for Node's, Pool's and Pool Members.

Environment

  • BIG-IP LTM
  • Nodes
  • Pools
  • Pool Members

Cause

N/A

Recommended Actions

Viewing Pool Member, Node and Pool Bytes IN/OUT Statistics with SNMP:

Node level:
View the number of bytes received by the specified node address from server-side.
String: ltmNodeAddrStatServerBytesIn
Numeric: .1.3.6.1.4.1.3375.2.2.4.2.3.1.4

View the number of bytes sent to server-side from the specified node address.
String: ltmNodeAddrStatServerBytesOut
Numeric: .1.3.6.1.4.1.3375.2.2.4.2.3.1.6

Pool level:
View the number of bytes received by the specified pool from server-side.
String: ltmPoolStatServerBytesIn
Numeric: .1.3.6.1.4.1.3375.2.2.5.2.3.1.3

View the number of bytes sent to server-side from the specified pool.
String: ltmPoolStatServerBytesOut 
Numeric: .1.3.6.1.4.1.3375.2.2.5.2.3.1.5

Pool member level:
View the number of bytes received by the specified pool member from server-side.
String: ltmPoolMemberStatServerBytesIn
Numeric: .1.3.6.1.4.1.3375.2.2.5.4.3.1.6

View the number of bytes sent to server-side from the specified pool member.
String: ltmPoolMemberStatServerBytesOut
Numeric: .1.3.6.1.4.1.3375.2.2.5.4.3.1.8
