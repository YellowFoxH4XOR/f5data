Description

  • NGINX Ingress Controller supports configuring access logs in JSON format using the log_format directive. However, error logs continue to output logs as shown below in plain text  and cannot be formatted as JSON.

Example error log entries:

 2025/09/01 02:46:10 [error] 218#218: connect() failed (101: Network is unreachable) for <nginx licensing server IP address>:443 during usage report:
 2025/09/01 02:46:10 [alert] 218#218: cannot send usage report; traffic processing will degrade in 107 days

Environment

  • NGINX Ingress Controller

  • Access Log

  • Error Log

  • JSON output

  • log_format directive

Cause

  • NGINX only allows custom formatting (such as JSON) for access logs using the log_format directive. Error logs are managed by the error_log directive, which does not support custom formatting or JSON output.

Recommended Actions

  • None

Additional Information

  • There is currently no supported method to output NGINX error logs in JSON format.
  • Access logs can be formatted as JSON using the log_format directive.
  • For error logs, only severity level and destination can be configured.
  • To request this feature, consider providing feedback or upvoting the relevant open feature request (e.g., GitHub issue #791).
