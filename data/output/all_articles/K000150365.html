Description

The Virtual IP Address does not appear in the routing table after creating a Virtual Server and Virtual Address to work with BGP. This issue prevents proper route advertisement.

Environment

  • BIG-IP LTM
  • Virtual Server works with BGP

Cause

The root cause of the issue is that the affected Virtual Addresses were not configured with route-advertisement set to "enabled." When this setting is disabled, the BIG-IP system does not update its routing table appropriately for BGP advertisements.

Recommended Actions

To resolve this issue, ensure that route-advertisement is enabled for the relevant Virtual Addresses. Follow these steps:

  1. Navigate to the configuration settings of the affected Virtual Address. Local Traffic  ››  Virtual Servers  ›› Virtual Address List
  2. Verify whether route-advertisement is enabled.
  3. If it is disabled, enable route-advertisement.
  4. Update the changes.
  5. Confirm that the routing table now includes the Virtual IP Address and that it is being advertised via BGP as expected.

If further assistance is required or if issues persist, contact F5 Support for additional troubleshooting.
