Description

bgpd would crash and restart with the core file when receiving a BGP notification for 'OUT_OF_RESOURCES' from its BGP peer and running the command 'show ip bgp neighbor'.


Environment

You must meet the following: 
  • BIG-IP using BGP
  • ZebOS (Dynamic routing)
  • BGP peering is established
  • BGP notification for 'OUT_OF_RESOURCES' is received from the BGP peer and 'show ip bgp neighbor' command is run to display the BGP peer information


Cause

Bug ID 795685 : Bgpd crash upon displaying BGP notify (OUT_OF_RESOURCES) info from peer


Recommended Actions

Do not use 'sh ip bgp neighbor' command after BGP notification for 'OUT_OF_RESOURCES' is received from the peer.
It is fixed in 15.1.0, and 14.1.2.5, please consider upgrading.
