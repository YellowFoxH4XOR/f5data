Description

Trying to undeploy an application using Guided configuration  getting the following on  /var/log/restjavad.0.log  : 

Error: [RestOperationNetWorkerHandler]: bad response received: 404 - transaction failed:01020036:3: The requested Access Policy Item (/Common/example.app/example_ent _in) was not found.

After this error gets the following, preventing to undeploy:

severe: [SamlSPDeployHandler] Deploy handler persist failed for example error = [RestOperationNetWorkerHandler]: bad response received: 500 - undefined

Environment

  • BIG-IP APM
  • Guided configuration

Cause

Objects were not created properly when deploying the application for the first time using Guided Configuration, so the objects could not be removed manually because they are not there 
 

Recommended Actions

Run the below commands to remove the application from the Guided Configuration. This will allow you to redeploy??????#Clear-rest-storage 

#bigstart restart restjavad
#bigstart restart restnoded


Note: Make sure that you are  not using BIG-IQ since this procedure deletes all items in the BIG-IQ REST database, which includes the discovered devices, imported configurations, and tenant-specific data. Elasticsearch data is deleted as well unless you include the option to keep it. The procedure is not reversible; consider carefully before proceeding.
