Description

For upgrading of JDK, Tomcat, and Cassandra on SDC

Environment

  • Software such as JDK/Tomcat/Cassandra running on existing SDC versions need an upgrade to a higher version to overcome security vulnerability.

Cause

Your vulnerability scanner reports a need to upgrade software to a higher version.

Recommended Actions

  • SDC Security bulletin contains the package patch for most Linux rpm; however, software like JDK/Tomcat/Cassandra can only be upgraded to higher versions by performing SDC software updates.

Additional Information

F5 recommends updating to the latest software version of SDC to have all the latest security fixes installed.
