Description

Getting errors when trying to upgrade from version 14.1.4 or higher to version 15.1.2.1 or lower (or other affected versions):

notice tmsh[9856]: 01420012:5: Loading schema version: 14.1.4
info tmsh[9856]: cli schema (14.1.4) has been loaded from schema data files.
crit tmsh[9856]: 01420001:2: Can't load keyword definition (aaa-active-directory-server.kdc_validation) : framework/SchemaCmd.cpp, line 825
emerg load_config_files[9854]: "/usr/bin/tmsh -n -g -a load sys config partitions all " - failed. -- Loading schema version: 14.1.4
err mcpd[7375]: 01070425:3: Full configuration load failed.

Environment

  • BIG-IP running version 14.1.4 or higher 
  • Trying to upgrade to version 15.1.2.1
  • Configuration fails to load after upgrading.

Cause

This happens due to a schema update in 14.1.4 that is not present in version 15.1.2.1 or lower. This issue is tracked with:

Bug ID 1006357: Config load failure upon upgrade from newer maintenance releases to older versions when APM has AD AAA objects configured

Recommended Actions

Upgrade to version 15.1.3 instead.
