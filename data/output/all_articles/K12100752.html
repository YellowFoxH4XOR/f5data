Description

The following error message is displayed when navigating to System > Configuration > AppIQ

  • Not Found. The requested URL was not found on this server.

Environment

  • BIG-IP WebUI
  • Navigate to System > Configuration > AppIQ

Cause

Bug ID 1056993

Recommended Actions

Navigate directly to the following page on your BIG-IP (replacing <BIG-IP> with the IP/hostname of the system):

https://<BIG-IP>/tmui/tmui/system/appiq_ng/views/settings.html
