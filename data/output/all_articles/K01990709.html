Topic

You must manage certain global server load balancing (GSLB) objects from the /Common default partition.

Description

Certain GSLB objects cannot be created or modified in non-default administrative partitions. You must create and modify the following objects from the /Common partition:

  • Data centers
  • Servers
  • Links
  • Prober pools
  • DNSSEC zones
  • DNSSEC keys
  • Regions

In BIG-IP 11.6.0 and later, when you use the Configuration utility to view one of the previously-mentioned objects from a partition other than /Common, the buttons used to create, delete, disable, and enable the objects appear dimmed. Additionally, when using the TMOS Shell (tmsh), you cannot view or manage the objects from a partition other than /Common.

In versions prior to BIG-IP 11.6.0, when you attempt to create or modify one of the GSLB objects from a partition other than /Common, the system may generate an error message indicating that you do not have permissions to edit the object.
