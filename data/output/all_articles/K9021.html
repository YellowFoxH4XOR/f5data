Known Issue

The big3dshim process included with all BIG-IP versions prior to 9.2.2 fails to translate Extended Content Verification (ECV) monitor requests from 3-DNS systems properly.

If a 3-DNS system delegates an ECV monitor to the BIG-IP system, no actual monitoring is performed. However, the result is reported as successful. Therefore, the results are inconclusive and may potentially cause false positives.

F5 Product Development tracked this issue as CR53444 and it was fixed in BIG-IP 9.2.2. For information about upgrading, refer to the BIG-IP LTM and ASM Release Notes.

Workaround

You can work around this issue by configuring the 3-DNS system to avoid delegating ECV monitors to BIG-IP versions prior to 9.2.2. To do so, perform the following procedure:

  1. From the navigation pane of the 3-DNS Configuration Utility, click Servers.
  2. Click BIG-IP.
  3. Click the name of the BIG-IP system in question.
  4. In the Factories section, clear the ECV check box.
  5. Click Update.
