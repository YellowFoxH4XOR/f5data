Description

What is the purpose and permissions of each user role when creating accounts on the BIG-IP? What user roles can you assign to a BIG-IP user account?

Environment

  • BIG-IP user roles

Cause

A BIG-IP user role defines the types of resources, or objects, that a user can manage on the system. A user role is a property of a BIG-IP administrative user account; for each user account, you can assign a different user role to each administrative partition that the user has access to. This allows you to assign multiple user roles to each user account on the system.

Recommended Actions

The available user roles that you can assign to a BIG-IP user account depends on the BIG-IP version. For more information, refer to the following table:

BIG-IP versionResource
