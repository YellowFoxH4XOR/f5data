Description

When polling for power supply or chassis fan status via SNMP, false result (not present) may be returned intermittently.

# snmpwalk -v 2c -c <community> localhost SNMPv2-SMI::enterprises.3375.2.1.3.2
- snip -
F5-BIGIP-SYSTEM-MIB::sysChassisPowerSupplyStatus.1 = INTEGER: good(1)
F5-BIGIP-SYSTEM-MIB::sysChassisPowerSupplyStatus.2 = INTEGER: notpresent(2) <== false result
- snip -

# snmpwalk -v 2c -c <community> localhost SNMPv2-SMI::enterprises.3375.2.1.3.2
- snip -
F5-BIGIP-SYSTEM-MIB::sysChassisFanStatus.1 = INTEGER: notpresent(2) <== false result
- snip -

Not all devices will encounter this issue. Even on devices having this issue, false result may be returned very rarely, for example, once in 2 months of regular polling (every 30 sec).

Environment

  • BIG-IP i-Series platform
  • Polling power supply or chassis fan status via SNMP

Cause

Unknown. Bug ID 1462337 is filed to track this issue.

Recommended Actions

There is no known workaround on the BIG-IP at this time.
