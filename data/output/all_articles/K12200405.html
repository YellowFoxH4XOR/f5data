Issue

Error Message

err mcpd [<PID>]: 01071be6: 3: port-fwd-mode value of interface (<Interface.Number>) is not compatible with trunk (<Trunk Name>) member interface (<Member Interface.Number>).

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <Interface.Number> is the interface whose port forwarding mode value is incompatible with the corresponding <Member Interface.Number>.
  • <Trunk Name> is the name of the trunk in which the interfaces reside.
  • <Member Interface.Number> is the member interface that is incompatible with the corresponding <Interface.Number>.

For example:

err mcpd [5013]: 01071be6: 3: port-fwd-mode value of interface (1.1) is not compatible with trunk (Trunk1) member interface (1.2).

Message Location

You may encounter this message in the following location[s]:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • An invalid configuration is present. All interfaces in the same trunk must have the port-fwd-mode property set to the same value.
Impact

There is no impact.

Recommended Actions

None
