Overview

This article describes the support lifecycle policy for F5 AI Security, which includes F5 AI Guardrails and F5 AI Red Team. This policy defines supported release types, lifecycle milestones, and version eligibility for technical support and software fixes.

Scope

This policy applies to F5 AI Guardrails and F5 AI Red Team deployed in the following modes:

  • F5-managed SaaS deployments
  • Customer-managed (on-premises) deployments, including associated software components provided by F5

Release model

F5 AI Guardrails and F5 AI Red Team use a versioned major.minor.patch release format.

For example:

10.10.4

Version schema definitions

  • Major version identifies a major release stream.
  • Minor version identifies feature releases.
  • Patch version identifies maintenance or security updates.

Notes

  • Major releases may introduce significant new functionality and architectural changes.
  • Long-Term Stability (LTS) releases receive extended Standard Support and are recommended for long-running production deployments.
  • Support activities occur on the latest maintenance release of each supported release track.
  • F5 provides engineering hotfixes only for versions within the Standard Support phase.

End of Life

A release reaches End of Life (EoL) when it reaches End of Technical Support (EoTS). After EoL, F5 has no obligation to provide support, fixes, or updates for the release.

Support phases

Standard Support

The Standard Support phase begins on the General Availability (GA) date of release. During Standard Support, F5 provides:

  • Technical support.
  • Defect fixes.
  • Security updates.
  • Maintenance releases.
  • Engineering hotfixes, when applicable.

End of Software Development

After EoSD, F5 does not:

  • Develop new software fixes or enhancements.
  • Produce new maintenance releases or engineering hotfixes.
  • Provide security fixes.

End of Technical Support

After EoTS:

  • The release is no longer eligible for technical support.
  • F5 no longer provides troubleshooting or configuration assistance.

Note: Unless otherwise stated, EoSD and EoTS occur on the same date.

Version support policy

SaaS deployments

For F5-managed SaaS deployments:

  • Customers are supported on the currently active service version.
  • F5 manages service updates and platform maintenance.
  • F5 may remove deprecated functionality as part of ongoing service updates.

On-premises deployments

For customer-managed (on-premises) deployments, F5 supports:

  • The latest patch release of the currently supported major/minor version.
  • Engineering hotfixes for supported versions, when required.

F5 may require you to upgrade to a supported version to continue receiving technical assistance.

Engineering hotfixes

F5 may provide engineering hotfixes to address critical defects or security vulnerabilities during the Standard Support phase. Hotfix availability is subject to technical feasibility and does not extend the lifecycle of a release beyond its published support phase.
