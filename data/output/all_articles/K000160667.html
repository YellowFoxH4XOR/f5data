Description

Excessive statsd or other system daemon logs in /var/log/ltm.

 

Environment

BIG-IP TMOS

 

Cause

When a config filter is created, the default includes "level debug", which sets several processes to log at that level. This is regardless of the sys db setting.

 

Answer/Recommended Actions

Set the filter to the level that the system admin is happy with (EG info, notice, etc).

tmsh modify sys log-config filter <name> level <level>

Example:

tmsh modify sys log-config filter my-filter level warn

Note: The filter also has a "source" option where you can specify daemons like "statsd", "chmand", "evrouted", for example.
