K000089434: Install of NGINX Controller fails due to 'permission denied' error

Type
Support Solution
Published
2021-06-22
Updated
2021-08-04
Source
https://my.f5.com/manage/s/article/K000089434

Description

When installing NGINX Controller v3.15+ as a non-root user, the install fails and a 'permission denied' error is seen.

i.e.

Error

Cleaning up...

error: Error loading config file "/etc/kubernetes/admin.conf": open /etc/kubernetes/admin.conf: permission denied

error: Error loading config file "/etc/kubernetes/admin.conf": open /etc/kubernetes/admin.conf: permission denied

 

 Environment

  • NGINX Controller 3.15+
  • Installing using a non-root account

 

 Cause

Controller should be installed using a non-root account that has this ability to use sudo; however scripts should not be executed using sudo.

NGINX Controller must also be installed to a supported distribution.

 

 Recommended Actions

Verify account used to install has the ability to sudo.
