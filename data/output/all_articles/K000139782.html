K000139782: Bot Defense not Issuing CAPTCHA

Type
Support Solution
Published
2024-05-24
Updated
2024-05-24
Source
https://my.f5.com/manage/s/article/K000139782

Description

Bot Profile failing to apply configured action, CAPTCHA. Instead generates an Alarm with reason: Non-Qualified page from a different domain

 

Environment

  • BIG-IP ASM 
  • Bot Defense Profile attached to Virtual Server
  • HTTP request uses Referer Header

 

Cause

Issue happens when the BIG-IP ASM has not received enough data to mark the URL as qualified.

Often happens in Lab scenarios

 

Recommended Actions

Manually add the URL to the Qualified Lists.

tmsh
modify sys db dosl7.cs_qualified_urls value /url/

For example: 

modify sys db dosl7.cs_qualified_urls value /my/page.html,/my/logon*
