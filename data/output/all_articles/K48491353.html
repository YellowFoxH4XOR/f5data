Issue

Error Message

info tmm{<PID>]: 016b0002:6: Rewrite: <message>

In this error message, note the following:

  • <PID> is the process ID for the tmm process
  • <message> is an informational message from the rewrite subsystem

For example:

info tmm{11250]: 016b0002:6: Rewrite: Initialized rewrite filter

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • A virtual server is configured with a rewrite profile.
  • The log.rewrite.level database key is set to Informational or higher (more verbose).

The BIG-IP system logs various informational messages for the rewrite filter using this message ID. They are generated during normal control flow and may include the following:

  • Initialized rewrite subsystem
  • Uninitialized rewrite filter
  • No Content-Type header in response
  • Selected type CSS by matching Content-Type header
  • Selected type HTML by matching Content-Type header

Impact

None

Recommended Actions

You can set the log level for the rewrite filter to the default setting using the TMOS Shell (tmsh). To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To set the level for the log.rewrite.level database key, use the following command:

    modify /sys db log.rewrite.level reset-to-default
