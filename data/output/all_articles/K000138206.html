Description

The GNU C Library also known as glibc provides the core C libraries for software programs to use on a Linux system. BIG-IP software runs on a Linux host OS along with third-party software. For more information refer to the following articles:
  • K3645: Base operating system information for the BIG-IP host system
  • K11398383: BIG-IP third-party software matrix (17.x)
Nearly every software package on the BIG-IP system use glibc capabilities. This includes both F5 proprietary software and third-party software.

Environment

  • BIG-IP system
  • glibc

Cause

Require information about glibc functionality on the BIG-IP system.

Recommended Actions

You can run rpm on BIG-IP to view the capabilities of glibc and then trace the capability back to view specific software.

  1. Enter the following command from the BIG-IP CLI:

    rpm -q --provides glibc

    This produces a long list of libraries/capabilities and among them are:
    libc.so.6 and libc.so.6()(64bit)

  2. You can look at what packages require specific libraries with the following command syntax:

    rpm -q --whatrequires <library>

    For example:

    rpm -q --whatrequires libc.so.6

    This shows a long list of packages including F5 proprietary software bigd, tmsh, and sod as well as third-party software bind.

    rpm -q --whatrequires 'libc.so.6()(64bit)'

    This displays another long list of packages that includes F5 proprietary software TMM and third-party software such as grep, logrotate, bash, openssl and there is some overlap since packages use more than one library/capability.

  3. You can list all packages installed on the BIG-IP system with:

    rpm -qa
