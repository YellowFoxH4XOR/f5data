Description

BIG-IP LTM does not provide dns responses for DNS zones defined in local BIND. This occurs if the DNS profile has been configured with "Rapid Response Mode" enabled and Rapid Response Last Action set to the default value of DROP.

Sample LTM DNS profile configuration as below.

ltm profile dns /Common/custom-dns-prof {
    app-service none
    defaults-from /Common/dns
    enable-rapid-response yes
    rapid-response-last-action drop
}

Environment

  • BIG-IP LTM
  • DNS profile with "Rapid Response Mode" enabled and "Rapid Response Last Action" set to the default value.
  • DNS zones defined in BIND.
  • Some DNS zones defined in DNS Express

Cause

This is by design.
When "Rapid Response Mode" enabled and "Rapid Response Last Action" set to the default value of "Drop", all DNS requests for zones not in DNS Express will be silently dropped.

Additional Information

To allow resolution of DNS requests for zones not in DNS Express set "Rapid Response Last Action" to "Allow". This will allow the requests to be passed on to BIND. For a full list of configuration options for "Rapid Response Last Action", see article K18522641: Overview of the DNS profile

ltm profile dns /Common/custom-dns-prof {
    app-service none
    defaults-from /Common/dns
    enable-rapid-response yes
    rapid-response-last-action allow
}
