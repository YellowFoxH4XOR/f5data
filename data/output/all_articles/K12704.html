K12704: The ARX system does not pass traffic on a VLAN created with an ID of 0 or greater than 4009

Known Issue

This is the result of a known issue. The ARX system allows you to configure a VLAN that is outside the range of supported VLAN IDs, but the system does not pass traffic on that VLAN. A VLAN ID of 0 or greater than 4009 is outside the supported range (the range of supported VLAN IDs is 1 to 4009).

The expected behavior when you configure a VLAN with an ID outside of the supported range is that the system generates an error message that appears similar to one of the following examples:

% ERROR: Out of range argument '0' entered.
  Valid entry is an integer value between '1' and '4009'.

% ERROR: VLAN_BAD_RANGE (34144282):
  VLAN ID 4010 is not between 1 and 4009.

F5 Product Development tracked this issue as ID 349751 and it was fixed in ARX versions 5.2.2 and 6.0.0 For information about upgrading, refer to the ARX release notes.

Workaround

Delete the VLAN configured with an unsupported VLAN ID and create a new VLAN using a supported VLAN ID between 1 and 4009. For information about the vlan command, refer to the ARX CLI Reference guide.
