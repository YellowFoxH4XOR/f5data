K13155595: AWS - Unable to attach encrypted EBS volume to Big-IQ instance with ''instance readability check failed'' error

Type
Support Solution
Published
2022-10-10
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K13155595

Description

You create encrypted copies of the volumes attached to the Big-IQ instance on AWS. You detach the original volumes and attach the new, encrypted volumes, but encounter "instance readability check failed" errors. You notice that an unencrypted copy works.

Environment

  • The AWS instance type is supported
  • This AWS instance supports encrypted volumes

Cause

The copy was unsuccessful.

Recommended Actions

  1. Confirm the instance is supported by AWS. Use this site to check AWS Instance Types 
  2. Recreate the encrypted volume. Create an Amazon EBS volume
  3. If a new volume still fails, collect the system logs while in the failed state per Troubleshoot instances with failed status checks and contact AWS.
