Description

The Active device of the High Availability pair has no network connectivity. Connectivity is restored, when the device is set to Standby.
MAC address is changed by the translucent setting in transparency mode:

Active device, sample MAC:

show /net arp
--------------------------------------------------------------------------------
Net::Arp
Name           Address        HWaddress          Vlan              Expire-in-sec  Status
--------------------------------------------------------------------------------

10.11.100.50   10.11.100.50   00:00:5e:00:ff:ff  /Common/VLANX     292            resolved    <<<<  Wrong MAC address


Whereas in the Standby:

10.11.100.50   10.11.100.50   02:00:5e:00:ff:ff  /Common/VLANX     280            resolved    <<<<  Correct MAC address


The MACs are not the same. The first byte for the Active system is "00", but should be "02".

The same bit shift (00 instead of 02) is seen in several MAC addresses across the active system.
 

Environment

  • Have upgraded to TMOS 14.1.2.6
  • No network connectivity while Active.
  • Using VLAN Groups. VLAN Group's 'Transparency Mode' is set to 'translucent'.

Cause

       VLAN Group transparency mode set to "translucent" in the VLAN Group's settings

Recommended Actions

Set transparency mode to "transparent"

Additional Information

Manual Chapter : VLANs VLAN Groups and VXLAN
