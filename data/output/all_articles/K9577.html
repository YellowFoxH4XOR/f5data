Topic

The BIG-IP ASM remote logging profile contains a severity attribute that allows the administrator to specify the severity level of the log entries sent to the remote server. This attribute only applies to log entries sent to a remote server and does not affect the severity level of information logged locally.

The available severity attributes include the following:

  • Emergency
  • Alert
  • Critical
  • Error
  • Warning
  • Notice
  • Informational
  • Debug

The severity level applies to all log entries sent to the remote logging server by the logging profile, and all log entries received by the remote logging server from the BIG-IP ASM logging profile will appear with the selected severity level.

For example, when a severity level of Critical is selected, all log entries received by the remote logging server will appear with Critical in the severity section of the message. Therefore, a log entry stating an occurrence of an addition or update to a policy will appear as Critical.
