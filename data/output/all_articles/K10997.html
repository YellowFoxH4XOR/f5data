Topic

An 8.3 file name (also called a short file name or SFN) is a file name convention used by legacy 16-bit Windows programs. The 8.3 file names allow 16-bit programs to use an abbreviated 8-character file name to access a file name that contains more than eight characters. ARX metadata stores only one file name per file, and therefore does not support 8.3 file names for managed volumes. Since presentation (direct) volumes do not use metadata, you can use 8.3 filenames to access files on presentation volumes.

Note: For more information about 8.3 file names, refer to http://support.microsoft.com/kb/142982. This link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.
