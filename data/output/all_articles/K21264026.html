Known Issue

The Traffic Management Microkernel (TMM) restarts when the system applies the FLOW_INIT iRule to a virtual server.

This issue occurs when all of the following conditions are met:

  • Logging is enabled within the iRule.
  • The system applies FLOW_INIT to a virtual server.
  • The system receives packets but is unable to find a virtual server for the packets.

Impact

TMM restarts and disrupts traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM restarts and may produce a core file.
  • When TMM restarts, it disrupts traffic.
