Topic

You should consider using this procedure under the following condition:

  • You want to remove and replace a defective appliance or field replaceable unit (FRU), restore the BIG-IP software to the closest manufacturing validated release, and then activate the license on the replacement appliance.

Description

This document assists customers with a structured approach to prepare and install the BIG-IP software on an RMA system using the F5 Imaging Tool Kit. F5 provides this document specifically to guide F5 customers and expedite the software reinstallation process. If you experience problems during any step of this process, contact F5 Technical Support.

The following information applies to the F5 Imaging Tool Kit:

  • F5 supplies the F5 Imaging Tool Kit to customers who request an expedited RMA; the kit contains necessary components and instructions to quickly assist customers in restoring service on an RMA device.
  • You should use the F5 Imaging Tool Kit on BIG-IP and VIPRION platforms only; the kit does not work on other platforms.
  • F5 does not ship the Imaging Tool Kit with FRU or accessory parts.
  • The F5 Imaging Tool Kit is not available in Japan.
  • You do not need to return the F5 Imaging Tool Kit to F5.

This document covers the following procedures:

  • Determining the correct USB flash drive to use for the installation
  • Removing and replacing the defective unit or FRU
  • Restoring the BIG-IP system software to the closest manufacturing release
  • Setting up the BIG-IP installation (prior to booting up the unit)
  • Preparing the VIPRION 4400, B4100 blade to boot from the USB drive
  • Installing BIG-IP 10.x - 11.x software
  • Installing BIG-IP 9.x software
  • Activating the BIG-IP license on the replacement unit
  • Workaround process if primary installation fails
  • Troubleshooting garbled console output

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have the F5 Imaging Tool Kit that F5 provides with expedited Return Materials Authorization (RMA) systems.
  • You determine that the major and maintenance version of software is installed on the failed unit.
  • You have a functional laptop with the following software installed:
    • A terminal emulator/network file transfer application, such as PuTTY
    • A secure copy client, such as WinSCP
    • A web browser

Procedures

To prepare and install the BIG-IP software on an RMA system using the F5 Imaging Tool Kit, perform the following procedures:

Determining the correct USB flash drive to use for the installation

Refer to the following information to determine the correct USB flash drive to use for the installation:

  • Use the F5 imaging drive DOS flash drive only for the following BIG-IP platforms running software versions 10.0.0 through 11.1.0:
    • BIG-IP 1500
    • BIG-IP 3400/3410
    • BIG-IP 6400/6800
    • BIG-IP 8400/8800
  • Use the F5 imaging drive EXT2 for all other BIG-IP hardware platforms.

For information about determining the BIG-IP platform type, refer to the following articles:

  • K13144: Determining the BIG-IP model and platform type (11.x - 17.x)
  • K10635: Determining the BIG-IP model and platform type (9.x - 10.x)

Removing and replacing the defective unit or FRU

To remove (un-rack) and replace the defective unit, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Turn off the failed unit, and then disconnect the power cords.
  2. Label and disconnect all other cables that connect to the failed unit.
  3. Remove the failed unit from the rack.
  4. Rack mount the replacement unit.
  5. Connect power cords to the replacement unit.

    Important: Do not turn on the platform or reconnect network cables yet; these tasks are reserved for later in the process.

Restoring the BIG-IP system software to the closest manufacturing release

To restore the BIG-IP software on the RMA unit, perform the following procedures:

Setting up the BIG-IP installation (prior to booting up the unit)

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Use the null modem cable to connect your laptop to the console port on the BIG-IP unit.
  2. Start the terminal emulator/network file transfer application on the laptop, and verify that the terminal is configured correctly.
  3. Install the correct USB flash drive into the USB port on the BIG-IP system.

    Note: Use the DOS flash drive for the BIG-IP 1500, 34XX, 6400, 6800, 8400, 8800 platforms, or the EXT2 drive for all other platforms.

Preparing the VIPRION 4400, B4100 blade to boot from the USB drive

If you are working with the B4100 blade, you must perform steps 1-6 to boot the system from the USB drive, and then skip to step 4 in the Installing BIG-IP 10.x - 11.x software procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Turn on the new unit.
  2. The LinuxBIOS loads.

    Note: If the unit locks up or boots to the local drive, you may need to enter the Switch Card Control Processor (SCCP)/Always-On Management (AOM) menu by pressing Shift + Esc + 9. From the Command Menu, type r (Reset Blade), then choose the number of the Blade to reset, and then select q (Quit menu) to return to the console.

  3. When the GRUB menu is displayed, stop the boot process by pressing the down arrow key.
  4. Use the arrow key to select the USB mass storage device. In the following example, sda1 is the USB mass storage device:

    Note: If you have attached a USB DVD drive containing a bootable CD or DVD that you create by copying the ISO image to the disc, then when you reboot, select the menu item sr0.

    +-------------------------------------------------------------------------+
    | BIG-IP 11.2.0 Build 2446.0 - drive hdc.1 |
    | End User Diagnostics |
    | TMOS maintenance |
    | USB mass storage device - sda1 |
    | USB mass storage device - sr0 |
    | |
    | |
    | |
    | |
    | |
    +-------------------------------------------------------------------------+

  5. After kboot finishes loading, proceed to step 4 in the Installing BIG-IP 10.x - 11.x software procedure.

Installing BIG-IP 10.x - 11.x software

Note: For installation information about the VIPRION 4400, B4100 blade, refer to the Preparing the VIPRION 4400, B4100 blade to boot from the USB drive section.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Turn on the new unit.
  2. The installation script indicates that the unit is booting from the USB.

    Note: If the unit locks up or boots to the local drive, you may need to enter the SCCP/AOM menu by pressing Shift + Esc + 9. You can use the menu options to select Reset the host subsystem, and then select Connect to host subsystem console.

  3. When boot loader finishes, the following appears on the console:

    boot:

  4. At the Terminal Type prompt, press Enter to start the 10.x, 11.x installation.
  5. Once initrd finishes loading, follow the prompts to complete the installation.
  6. When the system prompts you to select a major platform version, enter the appropriate option.

    Note: If you install software on a VIPRION Puma 100 blade (B4100), refer to the VIPRION 4400 Puma1 blade (B4100) section.

  7. At the Terminal type prompt, press Enter.
  8. At the v10, v11 prompt, type the major software version and press Enter.

    For example:

    Your selection: [v10, v11]: v11 <enter>

  9. The kernel queries the USB flash drive for all valid images, depending on the version of software you selected, and displays the list of 10.x or 11.x ISO images.
  10. At the prompt, select the number that corresponds to the major and maintenance version you want to install.
  11. At the prompt, type yes to continue.
  12. The system performs an MD5 checksum.
  13. At the prompt, remove the USB flash drive and press Enter to reboot the platform.

    Note: Disregard any error message that indicates the system cannot un-mount the USB flash drive.

You may now proceed to the Activating the BIG-IP license on the replacement unit section.

Installing BIG-IP 9.x software

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Turn on the new unit.
  2. The installation script indicates that the unit is booting from the USB.

    Note: If the unit locks up or boots to the local drive, you may need to enter the SCCP/AOM menu, by pressing Shift + Esc + 9. You can use the menu options to select Reset the host subsystem, and then select Connect to host subsystem console.

  3. When the boot loader finishes, the following text appears on the console:

    boot:

  4. At the prompt, press Enter to start the 9.x installation.
  5. Once initrd finishes loading, follow the prompts to complete the installation.
  6. When the system prompts you to select a major platform version, enter the appropriate option.
  7. At the Terminal type prompt, press Enter.
  8. When the boot loader finishes, type v9 at the boot prompt, and press Enter.

    For example:

    boot: v9 <enter>

  9. At the prompt, type v9 to install BIG-IP 9.x software
  10. After initrd finishes loading, the 9.x software versions display.
  11. Select the desired software version.
  12. Press Enter.
  13. At the Welcome screen, press Enter.
  14. At the Copyright screen, press Enter.
  15. If the hard drive is using the Volumes disk formatting scheme, the installer displays a Disk Warning screen. Select Yes.
  16. The Server Summary screen displays software options that are available. Select No.
  17. At the Boot Image Configuration screen, select the location for the installation; you can make a selection by highlighting the appropriate letter. Type h to highlight the first drive, HD1.1.
  18. Select Ok.
  19. To confirm the location for the install, select Ok.
  20. At the Boot Image Configuration screen, confirm the correct location for the installation. Type d to highlight Done.
  21. Select Ok.
  22. At the Setup Menu screen, type d to highlight Done.
  23. Select Ok.
  24. At the Disk Format Warning screen, select Yes.
  25. At the Install screen, select Yes.
  26. Once the installation finishes, the installer asks you to remove the CD-ROM. Remove the USB flash drive and press Enter to reboot the unit.

Activating the BIG-IP license on the replacement unit

Before you can configure and use the BIG-IP system, you must activate a valid license on the system. You must perform the following tasks before you attempt to activate the BIG-IP license:

  • You need the correct base registration key and any add-on registration keys; the keys should be in the RMA case. If you do not have the base registration key, you can find this information by looking up the RMA case that initiated your TOS case.
  • Connect an Ethernet cable to the BIG-IP management port, so that the system is on the same network segment as your laptop.

    Note: Some older BIG-IP units require a crossover Ethernet cable.

  • Use the LCD panel on the front of the device to specify a management IP address, a netmask for the IP address, and a default route.

    Note: The default BIG-IP management IP address is as follows:

    • BIG-IP: 192.168.1.245/24
    • VIPRION: 192.168.1.246/24

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility using a web browser, where <IP_address> is the address you configured for the management port:

    https://<IP address>/

  2. Click Activate.
  3. Click Manual.
  4. Click Next.
  5. Copy the dossier.
  6. Connect to the F5 Product Licensing page at the following address:

    https://secure.f5.com

  7. On the F5 Product Licensing page, click Activate License in the row that lists BIG-IP 9.x and higher.
  8. Paste the dossier into the Enter your dossier box.
  9. Click Next.
  10. Copy the license returned by the F5 Product Licensing page.
  11. Paste the license into the License box in the BIG-IP Configuration utility.
  12. Click Next.
  13. For BIG-IP 9.x, perform a software reboot after activation is complete by typing the following command from the BIG-IP command line:

    reboot

Workaround process if primary installation fails

If the BIG-IP system has less than 1.5GB of RAM, the 10.x installation fails. To work around this issue, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Boot up the BIG-IP system to the software version that shipped with the device.
  2. Insert the USB.
  3. Log in to the command line.
  4. Type the following command:

    dmesg | tail

  5. Determine the USB name by looking for one of the following:

    sdb | sdc | sde

  6. Mount the USB drive, depending on format type DOS; EXT2.

    For example, for DOS, type the following command:

    mkdir /tmp/usb; mount /dev/sdb /tmp/usb

    For example, for EXT2, type the following command:

    mkdir /tmp/usb; mount /dev/sdb1 /tmp/usb

  7. Change to the /tmp/usb/images/BIG-IP directory and then locate the ISO you want to use.
  8. Copy the ISO to the /shared/tmp directory.

    For example, type the following command:

    cd /tmp/usb/images/BIG-IP directory

  9. Un-mount the USB drive.
  10. Change to the /shared/tmp directory and then type the following commands:

    im <bigip image>.iso
    image2disk --format=volumes <bigip image>.iso

  11. Complete the installation.

Troubleshooting garbled console output

If the baud on the unit is not set to default, the console output may be garbled. To troubleshoot this condition, refer to the following articles:

  • K13885: Setting the baud rate of the serial console port (11.x - 13.x)
  • K9156: Setting the baud rate of the serial console port (9.x - 10.x)
