Description
 

When you bundle more than one SSL certificate(including intermediate and root certificates) on an SSL Client profile and assign it to a virtual server, how will the BIG-IP select the certificate to be sent to the client?
 

Environment
 

  • BIG-IP LTM
  • SSL profile
  • SSL Certificates bundle
 

Cause
 

It works as designed.

Example:

Having a certificate bundle with one site cert, two intermediate certs, and two root certs.

When starting a connection, the BIG-IP will only send one site certificate, one intermediate cert, and one root cert. The BIG-IP will only choose one intermediate and one root cert to be presented to the client. 

The election will be done according to the site's hostname you want to access.
 

Recommended Actions
 

None.
 

Additional Information


None.
