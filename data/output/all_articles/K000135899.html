K000135899: Editing an SSLO security policy produces an error

Type
Support Solution
Published
2023-08-22
Updated
2023-08-22
Source
https://my.f5.com/manage/s/article/K000135899

Description

Seeing "Security Policies did not successfully upgrade and redeployment is required. Add new, modify and delete of existing deployed instances are not allowed."

Another related warning message that may be seen:

"Unable to complete the cleanup. You must resolve the error (if any), delete the iApp blocks in error state (if any) from the iApps menu on the left hand side and perform CMI sync."

Environment

BIG-IP SSLO v16.1.3

Security Policy

Cause

Unlocking the security policy is required to make changes.

Recommended Actions

When ever changes are made to a security policy, one must redeploy the most recent security policies that were altered and will be reflected by the 'Unlock' icon.

Additional Information

None
