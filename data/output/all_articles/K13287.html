Known Issue

Purpose

You should consider using this procedure under the following condition:

  • You want to change the default Intelligent Browser Reference (IBR) timeout from the default of six months to an alternative timeout value

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must be familiar with manually editing files from the Linux command line using the vi or other text editor

Description

The IBR lifetime setting controls how long a browser caches IBR content before attempting to revalidate. The IBR feature is controlled using the Expires header or the max-age directive in the Cache-Control header. The default expiration is six months, which is the equivalent of 15724800 seconds. However, there may be instances in which you want to increase or decrease this value.

Procedures

Changing the default IBR value

You can change the IBR value by editing the pvsystem.conf file and restarting the pvac process.

Impact of procedure: BIG-IP WebAccelerator may temporarily fail to process traffic.

  1. Log in to the BIG-IP host as the root user.
  2. Using the vi or other text editor, edit the /config/wa/pvsystem.conf configuration file.
  3. Find the line that references ibrLifetime. 

    The content will appear as follows:

    <ibrLifetime>15724800</ibrLifetime>
  4. Change the value 15724800 to the value you require. Note that this value is denoted in seconds. For a 30-day expiration, you would set the value to 2592000. 

    For example:

    <ibrLifetime>2592000</ibrLifetime>
  5. Save the file.
  6. For your changes to take effect, restart the pvac process by typing the following command:

    bigstart restart pvac

Supplemental Information

  • For information about the IBR feature, refer to the Using the Intelligent Browser Reference feature section in the Policy Management Guide for the BIG-IP WebAccelerator System
