Known Issue

Modification of the TCP profile Keep Alive Interval setting may fail.

This issue occurs when all of the following conditions are met:

  • You create or modify a TCP profile using the Configuration utility.
  • You attempt to set the TCP profile Keep Alive Interval value to indefinite using the value of 0 (zero).

Impact

The TCP profile Keep Alive Interval value of zero is not accepted by the Configuration utility and an error is displayed.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to set the TCP profile Keep Alive Interval setting to indefinite by using the value of 0 (zero), an error message similar to the following example is displayed:

    Value out of range. Correct Range: 0 - 4294967295

  • When attempting to set the TCP profile Keep Alive Interval setting to indefinite by using the value of 0 (zero), from the Traffic Management Shell (tmsh), the value is accepted.

Workaround

To work around this issue, you can use the tmsh utility to set the TCP profile Keep Alive Interval setting when indefinite is required. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Set the TCP profile Keep Alive Interval setting to indefinite by using the following command syntax:

    modify /ltm profile tcp <profile name> keep-alive-interval 0

    For example:

    modify /ltm profile tcp my-tcp keep-alive-interval 0

  3. Save the configuration change by typing the following command:

    tmsh save /sys config

  4. Exit the tmsh utility by typing the following command:

    quit
