Topic

The BIG-IP WebAccelerator hds_prune pruning process is used to maintain the size of the disk cache. The hds_prune process has the following configuration options in the /config/wa/pvsystem.conf file:

  • hdsDiskScanInterval
  • hdsPruneStartLevel
  • hdsPruneStopLevel
  • hdsPruneMaxDiskCache (introduced in BIG-IP WebAccelerator 10.0.0 and backported to 9.4.8)
  • hdsLocation
     

hdsDiskScanInterval

The hdsDiskScanInterval option configures the frequency at which the pruning process is performed. By default, the hds_prune process is performed every 300 seconds. 

Note: F5 recommends that you do not change this value unless F5 Technical Support directs you to do so. 

hdsPruneStartLevel and hdsPruneStopLevel

The amount of pruning performed by the hds_prune process is controlled by the hdsPruneStartLevel and hdsPruneStopLevel settings. By default, the hdsPruneStartLevel setting is set to 20 and the hdsPruneStopLevel setting is set to 40.  When the space available on the filesystem decreases to 20 percent, the hds_prune process starts pruning the disk cache. The disk cache is pruned until the space available on the filesystem has increased to 40 percent.

The default settings were intended for a filesystem capacity of 5.7GB, allowing for the disk cache to be maintained between 4.6GB and 3.42GB. The pruning process starts pruning the disk cache when the cache grows to 80 percent of the 5.7GB capacity (approximately 4.6GB), and the process stops pruning the disk cache when the size has been reduced to 60 percent of the 5.7GB capacity (approximately 3.42GB).

On some platforms, the filesystem used for the WebAccelerator disk cache is a larger 33GB filesystem, and the default pruning values allow the disk cache to become too large. For example, with the 33GB filesystem, the pruning process does not start pruning the disk cache until the filesystem reaches 20 percent available capacity, allowing the disk cache to grow to be approximately 25GB.  

Note: For information about modifying the hdsPruneStartLevel and hdsPruneStopLevel, refer to the Modifying the hdsPruneStartLevel and hdsPruneStopLevel settings section in K12514: Reducing excessive disk cache pruning activity on a BIG-IP WebAccelerator system.

hdsPruneMaxDiskCache

Note: The hdsPruneMaxDiskCache option was introduced in BIG-IP WebAccelerator 10.0.0, and was also backported to 9.4.8. The setting helps prevent degraded performance or possible system instability if the WebAccelerator disk cache grows larger than approximately 6GB. For more information, refer to K9058: BIG-IP WebAccelerator may experience degraded performance or system instability as a result of a large WebAccelerator disk cache.

The hdsPruneMaxDiskCache option is used to specify the maximum space allowed for the disk cache. The default setting limits the maximum space used for the disk cache to be 6GB. Limiting the size of the disk cache allows for more efficient pruning by the hds_prune process.

hdsLocation

The hdsLocation option is used to specify the location of the WebAccelerator disk cache. The default location for the WebAccelerator disk cache is /var/wa/hds.

Important: Beginning in BIG-IP 10.0.0, the location of the disk cache was changed to /wam/hds. You should not modify the hdsLocation option. The new /wam/hds location uses a dynamically allocated volume tied to provisioning.

Note: In rare circumstances, a few systems may have been manually configured to use a larger /shared filesystem instead of the default /var filesystem, because of insufficient space for the disk cache. However, beginning in BIG-IP 10.0.0, the location of the BIG-IP WebAccelerator disk cache should no longer be modified.
