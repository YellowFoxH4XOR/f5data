Source

Description

The cookie is truncated by ASM when sending it to the backend server.

Environment

  • BIG-IP ASM 
  • ASM Policy enabled
  • The number of Cookies in HTTP is more than 100
  • There is an ASM-generated cookie (TS*) in the HTTP request

Cause

This behavior is due to a bug https://cdn.f5.com/product/bugtracker/ID1284073.html

Recommended Actions

Set the "asm.strip_asm_cookies" DB key to "false"

Impact of workaround: The ASM-generated cookies will be forwarded to the back-end server.
 
tmsh modify sys db asm.strip_asm_cookies value false
