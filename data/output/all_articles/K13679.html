Known Issue

The BIG-IP system fails to shut down the iControlPortal.cgi process.

This issue occurs when the following condition is met:

  • You modify the Idle time before automatic logout setting when the existing iControlPortal.cgi process is handling an iControl request.

    The setting for Idle time before automatic logout is located in the Configuration utility System > Preferences > Security Settings section. This setting specified the amount idle time in seconds before the system automatically logs out the inactive Configuration utility sessions.

    When you modify the Idle time before automatic logout setting, the BIG-IP system should shut down the existing iControlPortal.cgi process and start a new one using the new setting. However, the BIG-IP system does not shut down the existing iControlPortal.cgi process and a new process is started. As a result, the multiple iControlPortal.cgi processes may consume a significant amount of CPU and memory resources on the BIG-IP system.

    This issue typically occurs when the BIG-IP system is a managed device on an Enterprise Manager system because the Enterprise Manager uses iControl to manage the BIG-IP devices.

Impact

The BIG-IP system performance may be affected over time.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Slow response from the BIG-IP Configuration utility, as the performance of the system appears to be degraded.
  • The CPU and memory utilization graphs on the Configuration utility display high usage.
  • When using commands such as ps or top, you observe more than one iControlPortal.cgi process actively consuming the CPU and memory resources.

Workaround

To work around this issue, you must terminate all the iControlPortal.cgi processes that were started due to this issue. To do so, perform the following procedure:

Impact of workaround: Any existing iControl connections may need to re-establish. For example, after performing this workaround, you may have to refresh the Enterprise Manager-managed device properties page.

  1. Log in to the BIG-IP command line.
  2. Terminate all the iControlPortal.cgi processes by typing the following command:

    killall iControlPortal.cgi

    Note: This command terminates all iControlPortal.cgi processes. A new process starts automatically so the iControl communication remains available.
