Topic

Download notice to VPN end users: Your organization's BIG-IP APM system administrator uses the instructions in this article to download the BIG-IP Edge Client desktop application from the BIG-IP APM system and distribute it to VPN end users. This requirement is based on the BIG-IP Edge Client configuration objects of the installation package are specific to the intended access configuration for your organization. You must either refer to your organization's documentation or contact your IT department for details about how to download the BIG-IP Edge Client desktop application from your organization's internal resources.

If you are a BIG-IP APM VPN user who wants to download F5 Access mobile apps, refer to the following article:

  • K11060025: Downloading F5 Access mobile apps

If you are a BIG-IP APM system administrator who wants to allow user access to download the BIG-IP Edge Client directly from the BIG-IP system, refer to the following article:

  • K05816648: Enabling end user access to download the BIG-IP Edge Client for BIG-IP APM

If you are a BIG-IP APM VPN system administrator who wants to download F5 Access Mac, refer to the following article:

  • K000153125: BIG-IP administrator instructions for downloading and installing F5 Access Mac

Description

BIG-IP Edge Client is a package you can customize for a connectivity profile that is associated to a BIG-IP APM virtual server. After you customize it by selecting the components to install and specifying settings for it, you can download it from the BIG-IP APM system. From the Configuration utility, you can download the BIG-IP Edge Client installer for Windows and Mac OS X, as well as the BIG-IP Client for Linux command line. After you download the client, it is available for you to distribute as needed.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have BIG-IP APM provisioned on your BIG-IP system.
  • You have administrative access to the Configuration utility.

Procedures

  • Downloading BIG-IP Edge Client for Windows or Mac OS X
  • Downloading the command line client for Linux 
  • Downloading the Linux VPN installation files from the BIG-IP APM virtual server

    Note:  The Linux version of the BIG-IP Edge client is available only as a command line utility.

Downloading BIG-IP Edge Client for Windows or Mac OS X

Impact of procedure: Performing this procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Go to Access > Connectivity / VPN > Connectivity.

    Note: For versions prior to BIG-IP 13.1.0, go to Access Policy > Secure Connectivity.

    Note: You can also access this page by selecting the BIG-IP Edge Client for Windows, Mac OS X, and Linux link on the Welcome page.

  3. Select the connectivity profile you are going to use for your client.
  4. Select Customize Package.

    Note: Selecting Customize Package defaults to downloading the Windows client.

    Note: To move between Windows and Mac clients, select the arrow on the side.

  5. Select Download.

Downloading the command line client for Linux 

If you are a BIG-IP APM administrator, for versions prior to BIG-IP 14.1.0, download the linux_sslvpn.tgz file. For BIG-IP APM 14.1.0 and later, the Linux client is no longer available as a linux_sslvpn.tgz file. You should select and download the following Linux clients, as appropriate for your Linux distribution:

  • Command-Line Client for Linux (linux_f5cli.armhf.deb). Debian-based distribution on ARM architecture used mostly in mobile devices and netbooks. For example, Ubuntu ARM, Debian ARM, and so on.
  • Command-Line Client for Linux (linux_f5cli.x86_64.deb). Debian-based distributions. For example, Ubuntu, Debian, and so on.
  • Command-Line Client for Linux (linux_f5cli.x86_64.rpm). RPM-based distributions. For example, Fedora, CentOS, Redhat, and so on.

To download the f5fpc installation file, perform the following procedure:

Impact of procedure: Performing this procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Go to Access > Connectivity / VPN > Connectivity > Client Downloads.

    Note: For versions prior to BIG-IP 13.1.0, go to Access Policy > Secure Connectivity, and select the Clients Downloads tab.

  3. Select the appropriate command-line client for Linux file for your system.

    Note: Beginning in BIG-IP APM 14.1.0, you can download the Linux command-line client as DEB and RPM packages. The linux_sslvpn.tgz file is no longer available.

Downloading the Linux VPN installation files from the BIG-IP APM virtual server

BIG-IP APM end users can install the BIG-IP Edge Client software and Linux clients by downloading and installing the BIG-IP Edge Client for Windows directly from the public download URL of a known BIG-IP APM virtual sever. Use the following procedure to download the required files for your version of Linux to install software to allow VPN access to the BIG-IP APM virtual server.

Note: The BIG-IP APM system administrator can allow general access to these files to external users by creating a dedicated virtual server where the BIG-IP APM access policy contains the simple logic of Start > Allow. The access policy does not assign any resources and no access to internal resources is granted; however, users can access the listed files hosted on the BIG-IP APM by connecting to the virtual server as described in the procedure. This method does not require users to authenticate unless authentication is specifically configured in the access policy.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • In your browser, use the URL syntax:

    https://<big-ip apm virtual server>/public/download/<file name>

    Replace <big-ip apm virtual server> with the virtual server host name or IP address.

    Replace <file name> with each of the file names in the list.

    For example:

    https://vpn.example.com/public/download/linux_f5cli.x86_64.deb

    Important: When required by the BIG-IP APM virtual server access policy configuration, successfully authenticate to an Allowed branch of the access policy.

  1. Log in to the BIG-IP APM virtual server.
  2. Open a second tab in the browser to download files.
  3. In the second tab use the following URL syntax:

    https://<big-ip apm virtual server>/public/download/<file name>

    Replace <big-ip apm virtual server> with the virtual server host name or IP address.

    Replace <file name> with each of the file names in the list.

Linux VPN downloadable installation file names

Debian and Ubuntu

ARM architecture

  • linux_f5cli.armhf.deb

x86

  • linux_f5cli.x86_64.deb
  • linux_f5epi.x86_64.deb
  • linux_f5vpn.x86_64.deb

Redhat, Fedora, and CentOS

  • linux_f5cli.x86_64.rpm
  • linux_f5epi.x86_64.rpm
  • linux_f5vpn.x86_64.rpm

Important: The URL path and file names are case sensitive.

Note: F5 recommends that you install all the listed files related to your Linux version.
