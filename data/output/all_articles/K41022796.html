K41022796: Generation of md5sum for transmission to F5 Support

Type
Support Solution
Published
2019-10-22
Updated
2025-06-23
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K41022796

Description

Instructions for generation of md5sum checksum prior to transmission of files to F5 Support personnel.

Environment

  • BIG-IP

Cause

None

Recommended Actions

  1. Change directory to the location where the file require to generate an MD5 checksum:
    cd /var/<dir>
  2. To create an MD5 checksum file for the file, use the following syntax: 
    md5sum <name-of-file> > <name-of-file>.md5
  3. To move the file and its MD5 checksum file to the /var/tmp directory, use the following syntax: 
    mv /var/<dir>/<name-of-file>* /var/tmp/
