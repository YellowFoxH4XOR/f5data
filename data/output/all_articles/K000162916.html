K000162916: F5 Insight Temporary Password Not Showing

Type
Support Solution
Published
2026-08-13
Updated
2026-08-13
Applies to

  • F5 Insight: 1.2.1
Source
https://my.f5.com/manage/s/article/K000162916

Description

F5 Insight 1.2.1 deployed as a VMware OVA briefly displayed the temporary administrator password in the console, after which the password disappeared. The behavior was reported on every deployment of this version.

 

Environment

  • F5 Insight version 1.2.1
  • VMware OVA deployment
  • Initial administrator provisioning performed through the deployment process
  • Lab environment without DHCP, requiring static management IP configuration

 

Cause

F5 identified the behavior as Bug 2433349, which causes the temporary administrator password to briefly appear and then disappear during F5 Insight 1.2.1 VMware OVA deployments.

 

Answer/Recommended Actions

  • Redeploy the F5 Insight instance using Cloud-Init.
  • Create a `user-config.yml` file to preset the administrator password.
  • Create a `meta-data.yml` file containing the static management IP configuration.
  • Base64-encode both configuration files as required by the deployment procedure.
  • Add the encoded Cloud-Init data to the VMware VM during deployment.
  • Coordinate with the VMware administrators if assistance is required to attach the Cloud-Init data to the VM.
  • Validate administrator access after the redeployment.

Additional Information

Bug ID 2433349: Identified by F5 as matching the recurring temporary-password display issue.
