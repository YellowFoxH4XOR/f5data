Known Issue

The cpcfg utility may report an error message indicating that the device is busy.

This issue occurs when the following condition is met:

  • You use the cpcfg utility to copy a configuration from one boot location to another.

When you use the cpcfg utility to copy a configuration, the command successfully copies the configuration to the target boot location, but repeatedly reports a "device is busy" message. Output from the command appears similar to the following example:

info: Getting configuration from HD1.1
info: Copying configuration to HD1.3
info: Applying configuration to HD1.3
umount: /mnt/tm_install/13677.imanOb: device is busy
umount: /mnt/tm_install/13677.imanOb: device is busy
umount: /mnt/tm_install/13677.imanOb: device is busy

Impact

None. You can safely ignore the error message.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • A "device is busy" message is reported to the BIG-IP system console or command line.
