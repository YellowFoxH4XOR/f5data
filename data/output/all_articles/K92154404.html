Description

Attack Signature menu item Security  ››  Application Security : Attack Signatures  has been removed in v15.

Environment

  • BIG-IP ASM v15 and above
  • GUI/Configuration Utility
  • Attack Signatures menu

Cause

BIG-IP ASM version 15 introduced GUI change where you must now navigate to Security  ››  Application Security : Security Policies : Policies List ›› <policy name> ›› Attack Signatures

Recommended Actions

None
