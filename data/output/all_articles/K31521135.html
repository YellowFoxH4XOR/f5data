Description
Adding a secondary BIG-IQ to an AWS BIG-IQ HA pair hangs on "Transitioning" or "Configuring Database Replication"

Environment
  • BIG-IQ 7.1 deployment in AWS
  • Adding HA pair

Cause

Further root-cause analysis is in progress, but the reason seems to be that since Postgres is not able to startup, the DB upgrade gets stuck on the HA-creation process between BIG-IQ's, and in AWS in particular, the new required ports need to be added to the AWS security-group prior to attempting to pair CMs.

From BIG-IQ 7.1.0, the database utility used has been changed from Tokumx to Postgres, and additional TCP ports need to be added to the AWS Security groups.

Recommended Actions

First recover from a stuck attempt at configuring HA by performing the recovery procedure below to restore access.
Then add the new required ports to the AWS security-group before attempting the HA pairing again.

    Recovery
    To recover from a stuck attempt at configuring HA, reset the CMs you are attempting to pair using the following command syntax: 

    # sh /usr/bin/ha_reset -f <local IP>

    Run the command on both CMs you are attempting to pair.  Once the WebUI is restored on both CMs, then add the required ports to the AWS security-group.

    If the above command only restores the Primary's UI but does not work on the secondary, then you will need to run these additional commands on the Secondary's CLI: 
    # rm -f /var/lib/pgsql/config/server.*
# clear-rest-storage

    Important: If this issue is encountered as part of an upgrade and the secondary BIG-IQ UI is still stuck, you will need to rollback to the previous version, delete the upgraded installation, and redo the upgrade for the secondary CM.
    Once the secondary is upgraded again and the new required ports are added to the AWS security-group, then you can attempt to add the secondary CM.

    Add Required Service ports for HA peers

    Add the new ports to the AWS security-group assigned to the BIG-IQ instances that you are configuring as HA. refer to K15612: Connectivity requirements for the BIG-IQ system for the full details.

    Required Service ports for HA peers
    VersionService PortsPurpose
