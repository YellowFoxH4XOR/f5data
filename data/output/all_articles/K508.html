Topic

The load balancing modes are defined as follows:

Least connections mode

Least Connections is a dynamic load balancing mode that distributes connections to the server that is currently managing the fewest open connections.

Fastest mode

Fastest is a dynamic load balancing mode that distributes connections to the server that currently exhibits the fastest response time. The response time measurement is based on the SYN to SYN/ACK response time for TCP, or on the delta between the first packet sent to the server and the first packet received for UDP.

Observed mode

Observed is a dynamic load balancing mode that distributes connections based on a combination of two factors: the server that currently hosts the fewest connections and also has the fastest response time.

Predictive mode

Predictive is a dynamic load balancing mode that distributes connections based on a combination of two factors: the server that currently hosts the fewest connections, and also has the fastest response time. Predictive mode also ranks server performance over time and passes connections to servers that exhibit an improvement in performance rather than a decline.
