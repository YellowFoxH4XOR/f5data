Description

Firewall Control Service, 'fwctl' for macOS is a series of Python scripts that are used to control the built in 'pf' packet based firewall to block internet connectivity when not connected via the VPN. This is sometimes referred to as "Locked Mode VPN" or "Always Connected VPN". It runs as a daemon 'f5fwctl' launched from /Library/LaunchDaemons/ .

Edge Client Always Connected feature supports 3 modes of Traffic Control, when the VPN is not connected, changing between these modes was dependent on the Python scripts
  • Block
  • Allow
  • Allow "only in-Enterprise-LAN" 
  For Windows, the Installer can be customised to configure these settings, For macOS there is no APM GUI for this customisation and the settings have to be manually configured in the installer zip file by creating and editing settings files as per the manual. The installer can then be used to deploy individual devices.

Environment

SSL VPN with

  • Edge Client Always Connected mode configured
  • Network Location Awareness
  • macOS Client device
  • Upgrade Mac OS to version 12.3 

Cause

With the macOS 12.3 upgrade, that was released 15 March 2022, Apple has removed the Python 2.7 runtime engine and its associated modules, causing any dependent scripts to stop working. With the release of Edge Client 7.2.3 In July 2022 this feature is now supported again.

The latest GA releases are available on downloads.f5.com
Version 7.2.2.2 Build 5961 Build date 2022-7-15 Filename: apmclients-7222.2022.715.1500-5961.0.iso
Version 7.2.3 Build 6010 Build date 2022-7-15 Filename: apmclients-7230.2022.715.1725-6010.0.iso

When a supported Python is not present and the old scripts are run, the logs below will be seen, and the firewall will not be active: 

sudo tail -f /Library/Logs/F5Networks/f5fwctl.log

env: python: No such file or directory
env: python: No such file or directory

Recommended Actions

With the new Edge Client 7.2.3 version a new installer will need to be manually created and deployed, as per the steps in the manual, there is no automatic upgrade available. Previous installations will need to be removed manually and a new instalation deployed.

Apmclient version 7.2.2.2 and 7.2.3 use an updated daemon (based on Python 3.8 now) and this is a precompiled binary to avoid needing a system Python install.

  • it will create a new macOS installer package the following recommendations should be followed.
  • For configurations managed by Managed Deployment policies:
    • Restart the client side after performing client app deployment (pkg install)
    • Restart the client side after configuration change deployment
      i.e. any changes to the client files (note these files each require root to change)

      /Library/Application\ Support/F5Networks/config.f5c
      /Library/Application\ Support/F5Networks/f5fwctl.xml

F5  tracked this issue as BZ 1059025.
Logs for this fwctl daemon can be viewed at
sudo cat /Library/Logs/F5Networks/fwctl.log
