Known Issue

The BIG-IP system may stop processing client SIP requests.

This issue occurs when all of the following conditions are met:

  • The virtual server is configured with a SIP profile.
  • The virtual server uses an iRule with the SIP_REQUEST_SEND iRule event, and a table command with subtable.

    For example, the iRule with the SIP_REQUEST_SEND event that uses a table command with subtable may appear similar to the following example:

    when SIP_REQUEST_SEND {
    log local0. "sipInfo: [table keys -subtable sip_session_info]"
    }

Impact

The client SIP may time out and fail.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • F5 iHealth lists Heuristic H379826 on the Diagnostics > Identified > Low screen.
  • The BIG-IP system fails to send the client SIP request to the back-end server.
  • You may observe an error message in the /var/log/ltm file indicating that the system has aborted the iRule pending event. The error message may appear similar to the following example:

    01220009:6: Pending rule event SIP_REQUEST_SEND aborted
