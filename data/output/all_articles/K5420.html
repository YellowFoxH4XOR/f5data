Topic

Occasionally, it may be necessary for the BIG-IP LTM system to pass asynchronous packets from a server. For example, if the BIG-IP LTM system is deployed in a one-IP network topology with the node servers configured to use the BIG-IP system as their gateway, and a client from a remote network connects directly to the node server (that is, sends a SYN packet directly to the node server), the node server's SYN/ACK response packet will be sent to the client through the BIG-IP LTM system. If the BIG-IP LTM system is not configured to accept and pass this packet, the packet will be dropped and the connection will fail.

In order to pass traffic to the client's network, you must configure the BIG-IP LTM system with a forwarding virtual server. Typically, you would use a network or wildcard forwarding virtual server.

To enable the BIG-IP system to pass the asynchronous SYN/ACK packet, you must enable the Loose Initiation option in the FastL4 profile that is used by the forwarding virtual server. Enabling Loose Initiation causes the system to initialize a connection when it receives any TCP packet, rather that requiring a SYN packet for connection initiation.

When you configure the BIG-IP system to pass the asynchronous SYN/ACK packet, F5 also recommends enabling the Loose Close option. The Loose Close option specifies that the system closes a loosely-initiated connection when the system receives the first FIN packet from either the client or the server.

Configuring the BIG-IP LTM to pass asynchronous TCP packets from a server

Important: Enabling Loose Initiation can permit stray packets to pass through the system, which may pose a security risk and reduce system performance.

To enable Loose Initiation and Loose Close on the FastL4 profile, perform the following procedure:

  1. From the Configuration utility, click Local Traffic.
  2. Click Profiles.
  3. From the Protocol drop-down tab, click FastL4.
  4. Click the FastL4 profile used by your IP forwarding virtual server.
  5. Select the Enabled check box for Loose Initiation.
  6. Select the Enabled check box for Loose Close.
  7. Click Update.
