K75031120: Updating the BIG-IP Fraud Protection Service (FPS) signatures and engine

Topic

When your BIG-IP system is licensed and configured with the Fraud Protection Service (FPS), WebSafe, or MobileSafe modules, the BIG-IP system provides an option for updating malware signatures and the JavaScript engine. By updating the malware signatures and JavaScript engine, you maintain the system's ability to discover malware that targets websites and mobile apps.

F5 releases a new attack signature update approximately every six weeks. The signatures include updates to attack signatures, new malware baits, and attack data used to identify malware existence for FPS, WebSafe, and MobileSafe.

Note: With WebSafe and MobileSafe reaching End of Life (EoL) on 30 September 2021, F5 has no plan to release signature and engine updates for these modules after the EoL date. For more information, refer to K33057152: End of Life announcement for F5 WebSafe and F5 MobileSafe.

Description

Attack signature updates are available from the MyF5 Downloads site under the version of the BIG-IP system that you are currently running.

Since new fraud attacks and threats are constantly being developed, you should update the system-supplied signatures and engine on a regular basis to ensure that your applications are protected against new attacks. You can configure automatic updates or manually update the signatures.

The attack signature updates are cumulative; when you update the system-supplied attack signatures, the update provides the latest signatures along with all signatures from the previous updates. Updating the attack signatures also provides any revisions to existing signatures and engine.

The engine update installs an updated JavaScript engine that enables the BIG-IP system to discover new types of malware.

Recommendations

  • Configuring updates for malware signatures
  • Configuring updates for the system-supplied JavaScript engine

Configuring updates for malware signatures

In the Signatures Update screen, you can choose to automatically install a malware signatures update from the update server when an update is available, or perform a manual installation from an update file you receive from F5. 

  1. Log in to the Configuration utility.
  2. Navigate to Security > Security Updates > Fraud Protection Service > Signatures Update.
  3. To enable the automatic daily update check for signature updates, select the Update Automatically box.

    Note: Since you have enabled the Update Automatically selection, you are finished configuring signature updates and do not need to perform any of the following steps.

  4. If you did not enable the Update Automatically setting, you must choose one of the following Delivery modes:

    Automatic - you automatically receive a notification that an update is available.
    Manual - you update signatures by uploading the signatures update file that F5 sends. 
    Important: If you set Delivery Mode to Manual, note that this is a temporary setting and is valid only as long as you are in the update screen. When you leave the update screen, the Delivery Mode setting reverts back to Automatic.

  5. To install the signatures update, click Install Updates.

Note: You can manually check for available updates by clicking Check for Signature Updates. When new updates are available, the system displays a notification.

Important: It takes the system several minutes to apply the signature updates to the running configuration.

Configuring updates for the system-supplied JavaScript engine

In the Engine Updates screen you can choose to download and install available engine updates from the F5 update server or manually download and install the engine update from file.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Security Updates > Fraud Protection Service > Engine Update.
  3. Choose one of the following delivery modes:

    Automatic - the system automatically downloads and installs a FPS JavaScript engine update from the Update server.
    Manual -you perform an engine update from an update file that F5 sends.
    Important: If you set Delivery Mode to Manual note that this is a temporary setting and is valid only as long as you are in the update screen. When you leave the update screen, the Delivery Mode setting reverts back to Automatic.

    Note: When you select the Manual delivery mode, the Upload File setting appears.  Click the browse button to upload the engine update file from your local device.

  4. When you use the Manual Delivery mode, click Install Updates to install the update.

    Important: It can take the system up to four hours to apply the engine update to the running configuration.

    Note: You can manually check for an available update by clicking Check for Engine Updates.
