K000149112: Warning message: MEMORY_USAGE_ABOVE_THRESHOLD in restnoded

Description

You may find the following warning message in /var/log/restnoded/restnoded.log.

Fro example,

warning: [telemetry.service.ResourceMonitorService] MEMORY_USAGE: (rss=377.05, heapTotal=309.84, heapUsed=273.32, external=44.97, free=26.09, freeLimit=30.00, freeUtilizationPercent=113.05, provisioned=1432.00, release=1159.00, releasePercent=90.00, threshold=1288.00, thresholdPercent=90.00, thresholdUtilzationPercent=29.27, utilization=377.05, utilizationPercent=26.33), TREND = MEMORY_USAGE_NO_CHANGE, STATUS = MEMORY_USAGE_ABOVE_THRESHOLD

Environment

  • BIG-IP Telemetry Streaming

Cause

If OS available memory is under 30.00 MB, this warning message will display in restnoded.log then data processing will be temporarily ceased.

Recommended Actions

To increase host memory, for example,

  • tmsh modify /sys db provision.extramb value 1024
  • tmsh modify /sys db provision.tomcat.extramb value 128
  • tmsh save sys config partitions all
  • bigstart restart restnoded

Additional Information

None.
