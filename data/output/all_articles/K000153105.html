Description

Occasional failures may occur when polling telemetry data from BIG-IP, resulting in a "502 Proxy Error" with the following message:

Proxy Error

The proxy server received an invalid response from an upstream server.

The proxy server could not handle the request

Reason: Error reading from remote server

If it is curl or command line, it could print:

<!DOCTYPE HTML PUBLIC "-//IETF//DTD HTML 2.0//EN">
<html><head>
<title>502 Proxy Error</title>
</head><body>
<h1>Proxy Error</h1>
<p>The proxy server received an invalid
response from an upstream server.<br />
The proxy server could not handle the request<p>Reason: <strong>Error reading from remote server</strong></p></p>
</body></html> 

Environment

  • Product: BIG-IP
  • Telemetry Streaming package: f5 telemetry 1.35 or newer

Cause

This issue is caused by insufficient memory allocatoin, heavy load of configuration and telemetry objects, or insufficient socket timeout settings for the restnoded server end process. When having limited resources and larger configuration, without an extended server-side socket timeout, connections may be terminated prematurely during heavy load or complex telemetry operations, resulting in intermittent "502 Proxy Error" responses. 

Recommended Actions

  1. Increase Timeout Values
    Ensure these database keys are set to their maximum value (600):
    tmsh
modify sys db restjavad.timeout value "600" 
modify sys db restnoded.timeout value "600"
modify sys db icrd.timeout value "600"
save sys config
  2. Extend restnoded Server-Side Socket Timeout
    - Backup the current startup script for restnoded:
    cp /etc/bigstart/scripts/restnoded /var/tmp/restnoded-bigstart-backup

    - Edit the startup script /etc/bigstart/scripts/restnoded and add -k 600000 (timeout in milliseconds) to the execution line for restnoded:

    # Find the below line
    exec /usr/bin/f5-rest-node /usr/share/rest/node/src/restnode.js -p 8105 --logLevel finest -i ${LOG_FILE} -s none >> /var/tmp/${service}.out 2>&1

# Modify it to:
    exec /usr/bin/f5-rest-node /usr/share/rest/node/src/restnode.js -p 8105 --logLevel finest -i ${LOG_FILE} -s none -k 600000 >> /var/tmp/${service}.out 2>&1


    - Restart the services to apply changes:

    bigstart restart restjavad restnoded

     

  3. Review and follow the below best practice guide to further fine-tune your Telemetry setup
    K000135911: BIG-IP Telemetry Streaming common issues and best practices
