Known Issue

BIG-IP Mac Edge Client customizations are not applied when run on an end-user device.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM Mac Edge Client download package configuration is customized.
  • Users download and install the Mac Edge Client software on a Mac OS X 10.12 (Sierra) device.
  • Users initiate an access session with the Mac Edge Client.

Impact

The system does not apply the Mac Edge Client customizations when users run the package on the user device.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Customized features such as Branding and Text values are set to the BIG-IP Mac Edge Client defaults.
  • The BIG-IP Mac Edge Client otherwise functions as expected.

Workaround

To work around this issue, you can run a command line action on the user device to recover the Mac Edge Client customization settings. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. From the user's desktop of the affected user device, ensure that there are no instances of the BIG-IP Edge Client running.
  2. Locate and right-click the red F5 ball in the dock.
  3. To close the application, select Quit from the BIG-IP Edge Client pop-up menu.
  4. Open a terminal application.
  5. Type the following command in the terminal window.

    defaults write -globalDomain AppleLanguages -array "en" "en-US"

  6. Launch the BIG-IP Edge Client application.
