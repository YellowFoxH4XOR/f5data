Known Issue

This is the result of a known issue. You can use the bigpipe conn server command and the bigpipe conn client command to display connection table entries. Some versions of BIG-IP LTM will display a maximum of 7,037 connections in the table, even if there were more than 7,037 connections made. When this behavior occurs, an error message that appears similar to the following example displays:

BIGpipe: Unable to complete request

In addition, an error message similar to the following may be logged to the /var/log/tmm file:

mcp error: 0x1020004 at ../mcp/db_persist.c:287

Note: This issue only affects the ability to display the connection table entries, and is not a limitation on actual connections in the connection table.

F5 Product Development tracked this issue as CR35496 and it was fixed in BIG-IP LTM version 9.2.0. For information about upgrading, refer to the BIG-IP LTM release notes.

F5 Product Development is tracking this issue as ID 265159 (formerly CR73071) and ID 303207 (formerly CR49412-1) for BIG-IP versions 9.3.x and 9.4.x.

This issue still exists in the BIG-IP version 9.6.x and 10.x software branches.

For BIG-IP LTM 10.x, you are recommended to use tmsh utility instead of the bigpipe utility. For example, to display information about the active connections to the system using tmsh, you would type the following command:

tmsh show /sys connection all-properties
