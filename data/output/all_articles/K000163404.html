K000163404: The restjavad-audit log does not contain entries for successful REST API calls

Type
Support Solution
Published
2026-09-24
Updated
2026-09-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1, 21.X.X, 17.1.3, 21.1.X, 21.1.0, 21.0.X, 21.0.0
Source
https://my.f5.com/manage/s/article/K000163404

Description

On the affected TMOS versions, successful REST API calls to the BIG-IP system, meaning HTTP response status code below 400, are not logged in the restjavad audit log /var/log/restjavad-audit.*.log.

This affects to all mutating REST API methods, such as POST, PUT, and PATCH.

The expected behavior is that any mutating REST API method should be logged in the restjavad audit log at the default audit logging level, INFO, regardless of whether the response is successful or not.

Environment

  • REST API access to the BIG-IP system.
  • BIG-IP TMOS version is 17.5.1.6 or later, 21.0.0 or later, or 17.1.3.3 or later.

Cause

This is a known issue tracked under Bug ID2524081.

Answer/Recommended Actions

There is currently no workaround. Customers affected by this issue may contact F5 Support to request an Engineering Hotfix.
