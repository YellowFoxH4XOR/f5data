Known Issue

This is the result of a known issue. If you configure a master group that uses Windows domain (NTLM) authentication, users in that master group are unable to authenticate.

Note: This issue does not affect Active Directory (Kerberos) authentication.
 
F5 Networks Product Development tracked this issue as CR108007 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass Release Notes.
 
Additionally, this issue was fixed in cumulative hotfix HF-603-1 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads page.
 
For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.
 
For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
