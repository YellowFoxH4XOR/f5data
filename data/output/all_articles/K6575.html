Issue

The BIG-IP Application Security Module (ASM) may repeatedly display the following error message at the console:

Restarting asm

Receiving this error message typically indicates that the BIG-IP ASM failed to start successfully, due to a MySQL problem.

To resolve this issue, perform the following procedure:

  1. Determine if the mysql application is included in the bigstart list by typing the following command:

    bigstart list mysql

    If the mysql application is not included in the list, proceed to step 2; otherwise, proceed to step 3.

  2. Add mysql to the bigstart list by typing the following command:

    bigstart add --default mysql

  3. Determine if the mysql application is running by typing the following command:

    bigstart status mysql

    If the mysql application is not running, proceed to step 4; otherwise, proceed to step 5.

  4. Start the mysql application by typing the following command:

    bigstart start mysql

  5. Recreate the MySQL user by typing the following command:

    /usr/libdata/ucs_convert/06000001_mysql_user

If you continue to receive the error message after you have performed this procedure, contact F5 Technical Support for assistance.
