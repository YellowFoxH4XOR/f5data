Known Issue

This is the result of a known issue. If you configure a FirePass cluster with five or more secondaries, and you enable log consolidation on the cluster, you may experience one or more of the following issues:
  • Slow log propagation
  • Some log messages are not propagated to the cluster primary
  • Degraded cluster performance
  • Multiple administrators cannot view consolidated log reports simultaneously

Note: Log consolidation is enabled by selecting the Enable Log Consolidation check box on the Device Management: Configuration: Clustering and Failover page.

The cluster log consolidation feature is not optimized for medium to large clusters, and is not recommended for use in those environments. Additionally, this feature has been removed starting in version 6.0.2 of FirePass software. For more information about the removal of this feature, refer to K7537: Cluster Log Consolidation Feature.

Workaround

You can work around this issue by configuring the FirePass cluster to log to an external log server instead of to the cluster primary. You can enable external logging on the Device Management: Maintenance: Logs page in the System Logs section. You can disable log consolidation by clearing the the Enable Log Consolidation check box on the Device Management: Configuration: Clustering and Failover page.
