Description

Getting error "Could not add the Whitelist IP Address '<IPv6_addr>'. IP Address and IP Mask combination is not valid" when adding IPv6 exception

 

 

Environment

BIG-IP ASM

Adding IP Exceptions

 

Cause

IPv6 address specified instead of the Network address (same as subnet)

 

Recommended Actions

Specify the subnet address under both IP and Network config.

 

 

 

Additional Information

None
