Description

When attempting to create a UCS archive, the following error is displayed:

  • Unexpected Error: Can't add value (01800) to container, it should have been validated by a ParseNode, name (unlock_time) tag (63720)Error during config save.
  • Unexpected Error: UCS saving process failed.
    No relevant logs are seen in:
    /var/log/httpd/https_error,
    /var/log/webgui.log,
    /var/log/tomcat/catalina.out

Environment

  • Standalone and HA configurations
  • BIG-IP backup restoration

Cause

The error occurs if the User Lockout setting unlock_time is set to an invalid value such as 01800 (with a leading zero), likely due to a typo. The default value is 0.

 

Recommended Actions

Using the GUI

  1. Navigate to: System > Users > Authentication.
  2. In the User Lockout settings, check "Automatically enable lockout-users."
  3. Set the Unlock Time value to either 0 (default) or another valid custom value (without leading zeros).

Using the CLI

To set the unlock time to a valid value (e.g., 300 seconds for 5 minutes), run:

tmsh modify sys db password.unlock_time value 300

To reset to the default:

tmsh modify sys db password.unlock_time value 0

Additional Information

Ensure that the value entered for unlock_time does not contain leading zeros and is a valid integer.
