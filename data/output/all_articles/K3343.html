K3343: The reported value for pending probes may be inaccurate after a link has been down

Known Issue

This condition can exist for two reasons, one of which is expected and normal behavior and the other of which is a known issue.

When 3-DNS monitors a link that is down, 3-DNS will display a large value for that link in the Pending field on the Probers Statistics page. This value will slowly decrement as long as the link remains down. Under normal circumstances, once the link is up again, the value in the Pending field will accurately reflect the number of pending requests.

In rare cases, 3-DNS does not reset the value in the Pending field when the link is back up. When this occurs, probing works correctly, but the reported number of pending requests is inaccurate.

F5 Networks Product Development tracked this issue as CR33666 and CR41917.

Workaround

To work around this issue, reboot the 3-DNS Controller.
