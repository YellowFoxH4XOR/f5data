Known Issue

The iControl representational state transfer (REST) API may incorrectly log a high severity error message when you connect to the BIG-IP system.

This issue occurs when the following condition is met:

  • You use the iControl REST API to connect with your BIG-IP system.

Impact

The BIG-IP system incorrectly logs an error message with the log level SEVERE for normal operations.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/icrd file, you may observe error messages that appear similar to the following example:
    bigip-38 err icrd:  7204,12087,                    RestServer, SEVERE,Unknown socket for write event fd:11
