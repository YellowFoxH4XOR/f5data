Known Issue

The BIG-IP APM All Sessions report may not run automatically.

This issue occurs when all of the following conditions are met:

  • You create a new BIG-IP APM system user with the administrator role.
  • The new user logs on to the Configuration utility and navigates to Access Policy > Event Logs.

Impact

The system does not automatically run the default All Sessions report. 

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the new administrative user accesses Access Policy > Event Logs, the system does not automatically queue the option to run the All Sessions report.
  • The standard list of available reports does not display in the Report Name section.

Workaround

To work around this issue, you can manually set the system to automatically present the All Sessions report when you access the event logs. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log on to the Configuration utility.
  2. Navigate to Access Policy > Event Logs.
  3. Select the All Sessions report in the Built In Reports > Session Reports drop-down menu.
  4. Select Run Report.
  5. Set the Restrict by Time values.
  6. Click Run Report.
  7. Click the Set as default report tab of the report.

    Note: Performing this step will enable the system to automatically present the All Sessions report when you access the event logs in the Configuration utility.
