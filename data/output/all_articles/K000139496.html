Description

You are inquiring about the rate limit function within the Bot Defense profile, specifically how it operates and if there are configurable options such as editing the timeout duration. You've looked for documentation but require clarification on the functionality and configuration of this feature.

Environment

  • Bot Defense profile
  • Rate Limiting feature within the Bot Defense profile

Cause

Questions on the operation and configurability of the rate limiting feature, as well as seeking documentation for better understanding.

Recommended Actions

  • Rate limiting is applicable only to the Unknown bot type, as mentioned in the context.
  • Rate limiting is a mitigation action used to control the number of transactions per second (TPS) from a bot, to prevent excessive traffic from bots and protect the application server from being overwhelmed.
  • Rate limiting starts when the TPS exceeds a certain threshold, which is determined by the historical average TPS or the absolute TPS configured (default at 30 TPS).
  • The threshold for rate limiting is calculated by taking the lower value between the historical average TPS divided by 2 and the absolute TPS configured.
  • When a bot's TPS exceeds the threshold, the system mitigates the traffic by limiting the number of transactions it can make per second.
  • The default value for rate limiting is 30 transactions per second, but it can be configured based on specific requirements.
  • The purpose of rate limiting is to restrict the impact of bot traffic on the application and reduce the risk of a denial-of-service (DoS) attack. By implementing rate limiting, organizations can ensure that their applications remain accessible for legitimate users while mitigating the impact of bot traffic.

Additional Information

It's important to consider the balance between security and performance when configuring rate limiting. Excessive logging may lead to performance issues, and understanding the configurable options can help maintain optimal operation of your system.
