Description

Need to know the virtual server statistics and I don't have BIG-IP AVR provisioned.

Environment

  • BIG-IP AVR is not provisioned
  • Virtual Server
  • Statistics

Cause

None

Recommended Actions

To view virtual server statistics, like number of concurrent connections, packets in/out, average CPU utilization, etc. use the following methods:

  • Use tmsh to view virtual server statistics:
    • tmsh show ltm virtual <virtual_server_name>
  • Use the Configuration utility to view virtual server statistics:
    • Statistics > Module Statistics > Local Traffic.
      Select "Virtual Server" under Statistics Type to view current statistics for each virtual server 
    • Local Traffic > Virtual Servers > Virtual Server List > <virtual server name> > Statistics

Additional Information

For systems using the BIG-IP AVR module, you can view virtual server statistics by refering to the following resources:

  • Manual : BIG-IP Analytics: Implementations
  • K86503180: Generating a traffic statistics report for each Virtual Server from the GUI
