K000138023: When a list of ports is used in a ServiceEntry, the istioctl cluster gets created only for the first port on the list

Type
Support Solution
Published
2024-01-10
Updated
2024-01-10
Applies to
  • Aspen Mesh: 1.14
Source
https://my.f5.com/manage/s/article/K000138023

Description

After creating the following ServiceEntry resource, only the cluster for the first port is created

❯ more example-se-rr.yaml
apiVersion: networking.istio.io/v1beta1
kind: ServiceEntry
metadata:
  name: example-se
spec:
  exportTo:
  - .
  hosts:
  - example-002.example.com
  - example-004.example.com
  - example-006.example.com
  - example-011.example.com
  - example-012.example.com
  - example-013.example.com
  - example-nn-011.example.com
  - example-nn-012.example.com
  - example-xx-002.example.com
  - example-xx-003.example.com
  - example-xx-005.example.com
  - example-xx-006.example.com
  location: MESH_EXTERNAL
  ports:
  - name: http2-8081
    number: 8081
    protocol: HTTP2
  - name: http2-8443
    number: 8443
    protocol: HTTP2
  - name: http2-9443
    number: 9443
    protocol: HTTP2
  resolution: DNS_ROUND_ROBIN

❯ istioctl pc c sleep-5887ccbb67-mc7r9 --port 8081

Cause

Recommended Actions
