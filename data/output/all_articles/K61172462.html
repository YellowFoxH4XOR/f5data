Topic

This article applies to BIG-IP 11.x through 16.x. For more information about other versions, refer to the following article:

  • K12350: Enabling or disabling the Spanning Tree Protocol for a trunk (9.x - 10.x)

You should consider using this procedure under the following condition:

  • Your network design requires disabling or re-enabling the Spanning Tree Protocol (STP) for a trunk.

    Note: STP is enabled by default on all BIG-IP trunk interfaces and should remain enabled unless there is a specific reason to disable the protocol.

Description

The BIG-IP system supports STP, Rapid Spanning Tree Protocol (RSTP), and Multiple Spanning Tree Protocol (MSTP), which prevent bridge loops by blocking redundant network paths.

Note: STP is not supported on BIG-IP Virtual Edition (VE). Beginning in BIG-IP 11.6.0, STP and Link Layer Discovery Protocol (LLDP) are supported on the BIG-IP 2000s, 2200s, 4000s, and 4200v hardware platforms.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the TMOS Shell (tmsh).

Procedure

Impact of procedure: STP is enabled by default on all BIG-IP interfaces to help prevent bridge loops. F5 recommends testing any changes in an appropriate environment.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To disable or enable spanning tree for a trunk object, use the following command syntax:

    modify /net trunk <trunk_name> stp <disabled or enabled>

    For example, to disable spanning tree for a trunk named test-trunk, enter the following command:

    modify /net trunk test-trunk stp disabled

    Note: After disabling STP on the trunk, you may observe that STP is enabled on all member interfaces of the trunk; it should remain enabled unless there is a specific reason to disable the protocol.

  3. Save the configuration by entering the following command:

    save /sys config
