Topic

BIG-IP has three types of default configuration options:

  • High level configuration
    All of the settings that determine the way that BIG-IP processes traffic. These settings are stored in the /config/bigip.conf file.
  • Base configuration
    All of the settings that provide network access to BIG-IP. These settings are stored in the /config/bigip_base.conf file
  • Entire file system
    All configuration files except for the bigip.conf and bigip_base.conf files.

Important: Before you use any of these options, you must back up your current configuration as detailed in K3135: Backing up and restoring BIG-IP or 3-DNS configuration files.

High level configuration

To reset the high level configuration, perform the following steps:

  1. Log in to the command line.
  2. Reset the configuration in memory, by typing the following command:

    bigpipe reset

    The configuration contained in memory is now reset to the default settings, but the configuration saved in the /config/bigip.conf file is not yet changed.

  3. Save the default configuration, using the following command:

    bigpipe save

    The configuration contained in the /config/bigip.conf file is now reset to the default settings.

Base configuration

To reset the base configuration, perform the following steps:

  1. Connect to the console port of BIG-IP.

    Important: This step is required to reset the base configuration, because the self IP addresses will be reset, any connections over the network will be dropped.

  2. Log in to the command line.
  3. Reset the configuration that is contained in memory, by typing the following command:

    bigpipe base reset

    The configuration contained in memory is now reset to defaults, to the default settings, but the configuration saved in the /config/bigip_base.conf has not been changed.

  4. Save the default configuration, by typing the following command:

    bigpipe base save

    The configuration contained in the /config/bigip_base.conf is now been reset to the default settings.

Entire file system

To reload the file system, refer to one of the following Solutions:

  • If your system has a CD-ROM drive installed, follow the instructions in K4344: Reinstalling BIG-IP or 3-DNS system software on platforms that are equipped with a CD-ROM drive.
  • If your system does not have a CD-ROM drive installed, follow the instructions in K3135: Backing up and restoring BIG-IP or 3-DNS configuration files.
