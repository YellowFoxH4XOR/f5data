Known Issue

The statistics for individual links may be significantly lower than the actual usage.

This issue occurs when the following condition is met:

  • The BIG-IP system is configured with a link object.

This error in reporting occurs because the two daemons that generate this information miscommunicate. The big3d process requests statistical information for multiple objects in the same query, but the mcpd process replies to the request for each object individually. Since the big3d process expects the information to be returned in a single reply, the resulting information is inaccurately calculated.

Impact

Link statistics are not reported correctly.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Link statistics may show all throughput stats as much lower than expected.

Workaround

To work around this issue, you can monitor the link usage on the upstream router.

Note: If an upstream router has been configured as a node on the BIG-IP system, the throughput data may be available in the object's node statistics.
