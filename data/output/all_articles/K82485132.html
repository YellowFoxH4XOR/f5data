Description

You may want to know how to match subnets of client IP addresses, in order to select pool, SNAT pool or node.

Environment

  • iRule
  • IP address
  • Subnet match

Cause

None

Recommended Actions

You can make iRule similar to below:

[IP::addr [getfield [IP::client_addr] "%" 1] equals "x.x.x.x/<CIDR notation>"]

NOTE: getfield returns the value as text, so it is essential to change the format to IP address using IP::addr .

For example:

when CLIENT_ACCEPTED {
    if { [IP::addr [getfield [IP::client_addr] "%" 1] equals "172.16.0.0/16"] } {
        snat 192.168.10.10
    }
}

When multiple IP ranges or subnets need to be matched efficiently, it is recommended to create an Address (IP) type data-group. 

when CLIENT_ACCEPTED {
    if { [class match [getfield [IP::client_addr] "%" 1] equals <datagroup_name>] } {
            pool <pool_name>
    }
}
