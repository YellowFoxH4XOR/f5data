K6516: TXT records cannot be edited if multiple TXT records use the same name

Known Issue

This is the result of a known issue. Only the first TXT record may be edited when using Zone Runner if multiple TXT records use the same name. TXT records are organized alphabetically by contents of the RDATA field. Therefore, if you select an individual TXT record for editing, the first record using that name is opened for editing.

However, all TXT records are displayed properly when viewed from the Resource Record List page, including the unique RDATA contents.

For example, the abc record would be opened for editing, regardless of which record was selected, if the Resource Record List displayed the following TXT records:

NameView NameZone NameTTLTypeRDATA
readme.askf5.net.externalaskf5.net.30TXT"ghi"
readme.askf5.net.externalaskf5.net.30TXT"def"
readme.askf5.net.externalaskf5.net.30TXT"abc"

Important: This issue does not affect resolutions provided by DNS for these records; all records will be used for resolution queries.

F5 Product Development is tracking this issue as CR68259 and it was fixed in BIG-IP GTM 9.2.4 and 9.3. For information about upgrading, refer to the BIG-IP GTM Release Notes.
