Description

You would like to know which objects or entities are learnt when enabling learn from responses in a security policy.

Environment

  • Security policy
  • Learning
  • Policy building

Cause

The learn from responses setting only applies to objects or entities that can be learnt from response content.

Recommended Actions

Some of the things that the system may learn from responses are:

  • Status response codes
  • Redirection domains
  • Web server technologies
  • Login pages
  • Cookies

Note: This is not intended to be a definitive list of things that can be learnt from responses, but should help to understand the type of response content that ASM looks for with learn from responses enabled.

Additional Information

For more information about learning and policy building, refer to the following manual:
