Known Issue

This is the result of a known issue. Some zipped folders that are downloaded through a Portal Access Web Application favorite may become corrupted during the downloading process. The user will receive an error message that appears similar to the following example when they attempt to open the file:

Note: Different operating systems may use different error messages.

The Compressed (zipped) Folder is invalid or corrupted

This issue occurs under rare conditions when the FirePass device mistakenly injects data into the header of the file. For example, this can issue occur when the characters <a are found in the file. This issue tends to occur more frequently when the contents of the zipped folder are GIF files or other zipped folders.

F5 Networks Product Development tracked this issue as ID 317739 (formerly CR139045) and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass Release Notes.

This issue was fixed in cumulative HF-610-3-1 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.
