Topic

You should consider using this procedure under the following condition:

  • You want to view BIG-IP system software and the release of the Linux base operating system using Simple Network Management Protocol (SNMP).

Description

The BIG-IP system provides the following SNMP object identifiers (OID) to determine the version of your BIG-IP system software and the release of the Linux base operating system.

 
SNMP objectOIDDescription
sysProductVersion.1.3.6.1.4.1.3375.2.1.4.2.0Displays BIG-IP software version information
sysSystemRelease.1.3.6.1.4.1.3375.2.1.6.3.0Displays Linux base operating system release information
 

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have command line access to the BIG-IP system

Procedures

You can view BIG-IP version and the Linux base operating system release information from the BIG-IP command line using the snmpget command.

  • Viewing the BIG-IP version
  • Viewing the Linux base operating system release

Note: Beginning in 12.1.0, the BIG-IP system uses IP address 127.0.0.1 instead of 127.1.1.1.

Viewing the BIG-IP version

To view the BIG-IP version information, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to your BIG-IP system command line:
  2. To view the BIG-IP software version, use the following command syntax:

    snmpget -c <community_string> <host_name> <Object_Identifier>

    For example, you execute the following command to view your BIG-IP version:

    snmpget -c public 127.0.0.1 .1.3.6.1.4.1.3375.2.1.4.2.0

    The command output may appear similar to the following example:

    F5-BIGIP-SYSTEM-MIB::sysProductVersion.0 = STRING: 13.1.3.6

Viewing the Linux base operating system release

To view the Linux base operating system release information, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to your BIG-IP system command line:
  2. To view the release of the Linux operating system, use the following command syntax:

    snmpget -c <community_string> <host_name> <Object_Identifier>

    For example, you execute the following command to view the release of the Linux base operating system:

    snmpget -c public 127.0.0.1 .1.3.6.1.4.1.3375.2.1.6.3.0

    The command output may appear similar to the following example:

    F5-BIGIP-SYSTEM-MIB::sysSystemRelease.0 = STRING: 3.10.0-862.14.4.el7.ve.x86_64
