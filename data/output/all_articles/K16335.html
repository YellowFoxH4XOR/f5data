Topic

You can use this F5-supported iApp template to help you configure BIG-IP LTM to direct traffic and maintain persistence to Microsoft Remote Desktop Services Session Host servers. You can also use the iApp template for configuring BIG-IP AFM to provide a sophisticated layer of security for your Remote Desktop Session Host deployment.

Remote Desktop Services enables users to remotely access full Windows desktops, or individual Windows-based applications, on Remote Desktop Session Host computers. In an environment that uses a BIG-IP LTM system, a farm of Remote Desktop Session Host servers has incoming connections distributed in a balanced manner across the members of the farm.

For instructions about using this template and important prerequisites and configuration notes, refer to the Deploying F5 with Microsoft Remote Desktop Session Host servers deployment guide.

To download and install the iApp template, perform the following procedures:

Download the iApp template

Install the iApp template

Download the iApp template

Important: You must download the file; do not copy and paste the contents.

  1. Go to the MyF5 Downloads site.
  2. Read the End User Software License Agreement and Program Terms and accept the license by checking the box and selecting Next.
    Note: After you accept the End User Software License Agreement, the system does not present the agreement again for subsequent downloads that you perform during the same browser session.
  3. From the Select a product family drop-down menu, select BIG-IP.
  4. From the Product Line drop-down menu, select iApp-Templates.
  5. Select the iApp zip file iapps-1.0.0.xxx.x.zip.
  6. Select a download location from the drop-down menu.
  7. Select the Download button.
    Note: Some browsers save the file to a default location. You can review your specific browser's documentation to change the default location of where you want to save files.
  8. Repeat the procedure from step 5 for iapps-1.0.0.xxx.x.zip.md5
  9. Use a tool on your workstation to compare the MD5 hash of the zip file with the .md5 file.

Install the iApp template

  1. Unzip the zip file to a location accessible from your BIG-IP system.
  2. Log in to the Configuration utility.
  3. From the iApp tab, select Templates.
  4. Select Import.
  5. Select the Overwrite Existing Templates box.
  6. Select Browse.
  7. Browse to the location where you saved the iApp file.
  8. Select the file named f5.microsoft.rds_session_host.vx.x.x that corresponds to the iApp version you want to install.

    For example, the file for the December 2017 release of this iApp is named f5.microsoft.rds_session_host.v1.0.4.

    Note: Refer to the previous Support Matrix to select the most current supported template for your BIG-IP software version.

  9. Select Upload.

When the upload completes, the iApp is available for use.
