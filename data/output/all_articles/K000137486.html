K000137486: The configuration of LAGs is not automatically saved to bigip_base.conf.

Type
Support Solution
Published
2023-11-07
Updated
2024-11-27
Applies to
  • F5OS
  • F5OS-A: 1.8.0, 1.5.1
Source
https://my.f5.com/manage/s/article/K000137486

Description

After creating a VLAN, LAG, and LACP in F5OS, when you add the VLAN to the tenant, you may observe that the trunk configuration exists in the running-config, but the trunk configuration is not automatically saved to bigip_base.conf.

Environment

  • rSeries
  • Tenant

Cause

ID1393425

Recommended Actions

The workaround is to execute tmsh save sys config, which will save the configuration to bigip_base.conf.

None
