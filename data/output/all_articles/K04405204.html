Description
When attempting to create an AFM address list, the following error maybe encountered:
01070734:3: Configuration error: Please configure a dns-resolver under global-fqdn-policy.

Environment

  • BIG-IP AFM
  • Address-lists

Cause
A DNS Resolver has not been created

Recommended Actions

  1.  On the Main tab, click Network > DNS Resolvers > DNS Resolver List 
  2. Click Create
  3. In the Name field, type a name for the resolver.
  4. Click Finished.
  5. Once that is created then you will need to set a Global Context DNS Resolver in the AFM Options menu, go to Security > Options > Network Firewall > Firewall Options
  6. Under the section for FQDN Resolver select the DNS Resolver created above.
  7. Choose a refresh interval and then click Update.
  8. Retry creating the AFM address list
