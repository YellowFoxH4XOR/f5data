Known Issue

This is the result of a known issue. The mcpd process may fail to release memory resources during normal operations, which may result in memory exhaustion.

F5 Product Development is tracking this issue as CR99315.

This issue was fixed in Hotfix-BIGIP-v9.6.1-HF2, which has been issued for BIG-IP 9.6.1, for the BIG-IP 9.6 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
