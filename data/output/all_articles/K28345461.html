Description

Security scanner reports that the BIG-IP is vulnerable due to the CBC mode cipher encryption detected on management port GUI access also known as Config Utility. 
They recommended to reconfigure with stronger cipher and not to use CBC cipher. 

  • To disable CBC cipher on Management port 443
     

Environment

  • BIG-IP
  • Management port
  • Cipersuite
     

Cause

None
 

Recommended Actions

You can disable the CBC cipher on Management port 443 by following these steps:

  1. Log in to tmsh by typing the following command:
    tmsh
     
  2. List the currently configured SSL protocols.
    list /sys httpd ssl-ciphersuite

    For example, the system displays the following ciphers:
    ssl-ciphersuite ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES128-SHA:ECDHE-RSA-AES256-SHA:ECDHE-RSA-AES128-SHA256:ECDHE-RSA-AES256-SHA384:ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES128-SHA:ECDHE-ECDSA-AES256-SHA:ECDHE-ECDSA-AES128-SHA256:ECDHE-ECDSA-AES256-SHA384:AES128-GCM-SHA256:AES256-GCM-SHA384:AES128-SHA:AES256-SHA:AES128-SHA256:AES256-SHA256
     

  3. According to the list of cipher strings given in openssl documentation (https://www.openssl.org/docs/manmaster/man1/openssl-ciphers.html) there is no string describing all CBC ciphers. This means there is no simple way to disable all of these (and only these) with a simple '!CBC' or similar. To disable them, one has to disable any ciphers making use of it. Example ciphersuite syntax which excludes the ciphers being deemed as undesirable:

     ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-SHA384:ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES128-SHA:ECDHE-ECDSA-AES256-SHA:ECDHE-ECDSA-AES128-SHA256:ECDHE-ECDSA-AES256-SHA384:AES128-GCM-SHA256:AES256-GCM-SHA384

    For example:
    modify /sys httpd ssl-ciphersuite "ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-SHA384:ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES128-SHA:ECDHE-ECDSA-AES256-SHA:ECDHE-ECDSA-AES128-SHA256:ECDHE-ECDSA-AES256-SHA384:AES128-GCM-SHA256:AES256-GCM-SHA384"
     

  4. Verify the change was made to the running configuration.
    list /sys httpd ssl-ciphersuite
     
  5. Save the updated running configuration to disk.
    save /sys config

     

Additional Information

After you have disabled CBC ciphers on the management port, you may want to test the cipher list currently offered by the BIG-IP system using a utility such nmap. To do so, log into a Linux system that has access to the BIG-IP management port and use a command such as the following:

nmap --script ssl-enum-ciphers -p 443 <management_IP>
