Description

Native RDP object cannot be launched from full webtop:

  • .rdp file is downloaded to the client but it cannot be launched
  • in packet capture from APM we can see that there is no traffic on TCP port 3389
  • in /var/log/apm the error like below is logged:
    server-side connection was reset, reason: Unknown HTTP method from client
     
  • on the client a popup window comes up with the following message in it
    Your computer can't connect to the remote desktop gateway server, contact your network administrator for assistance

Environment

  • RDP Native objects configured on full webtop 
  • HTTP profile: Unknown Method option is set to reject
Cause

Failure is caused by the Unknown Method set to Reject in HTTP profile.

Recommended Actions

Change the Unknown Method option to Allow in HTTP profile.
