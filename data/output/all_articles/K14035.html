Known Issue

The BIG-IP PSM system may not report request check violations.

This issue occurs when all of the following conditions are met:

  • A request length exceeds the value defined for the long_request_buffer_size parameter.

    Note: The default long_request_buffer_size value is 10 MB. For more information about modifying this value, refer to K14034: Configuring large request processing for PSM.
  • The Request Length Exceeds Defined Buffer Size request check is set to Alarm and Block.

Impact

Requests that are blocked by the BIG-IP PSM security policy for violation of the Request Length Exceeds Defined Buffer Size request check are not logged to the system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Requests that are blocked by the Request Length Exceeds Defined Buffer Size request check do not generate Occurrence counts in the PSM Statistics screen.

Workaround

To work around this issue, you can configure and enable remote logging. The statistics will be reported to a remote logging server if one is configured. This workaround will not result in statistics logging to the BIG-IP PSM system.

Configuring remote logging

Impact of workaround: None.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Protocol Security > Options.
  3. Click Remote Logging.
  4. In the IP Address field, enter the log server IP address and modify the port value if needed.
  5. Click Add.
  6. Make any further modifications to the menu options as appropriate for your remote logging server.
  7. Click Save.

Enabling Remote Logging

Impact of workaround: None.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Protocol Security > Security Profiles.
  3. Click HTTP.
  4. Select the affected HTTP security profile.
  5. Select the Remote Logging option.
  6. Click Update.
