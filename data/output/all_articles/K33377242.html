K33377242: Machine Certificate check fails if both expired and valid certificates exist on MacOS client

Type
Support Solution
Published

Updated

Description

MacOS clients that have 2 (or more) certificates in their System Keychain: one valid and one expired, both having the same Common Name, may fail the Machine Certificate check on the APM.

For instance, the following certs with the same Common Name, both issued by the same CA, are present in the System Keychain of the MacOS client
 - certificate #1
      userA.example.com   <----- valid certificate

 - certificate #2
      userA.example.com   <----- expired certificate !!!

In this case, when userA logs in, the APM selects cert #2 (even though cert #1 - valid cert - exists); hence the MacOS client fails the check.

Environment

  • MacOS clients having 2 (or more) certificates: valid and expired, both having the same name
  • APM Clients/BIG-IP Edge Client for Mac version is 7213 (or earlier) 

Cause

This is bug ID 1000965 : [APM][MAC] - Mac Machine Cert Check fails if cert expired AND valid cert exists

fixed in APM Clients version 7214
Release Notes : APM Client 7.2.1.4

Recommended Actions

Upgrade APM Clients/BIG-IP Edge Client on the affected MacOS clients to version 7214 Update 1 (or later version).

For upgrading the APM Clients version on the APM, you can follow K52547540: Updating BIG-IP Edge Client for the BIG-IP APM system

For upgrading the BIG-IP Edge Client version on the affected MacOS clients, you can follow K44328534: BIG-IP administrator instructions for downloading BIG-IP Edge Client for Windows and Mac OS X, and Linux clients


Another workaround is to delete the expired certificate/s on the affected MacOS client, in cases where upgrading the APM|Edge Client is not possible.

1. From the Finder, click Go :: Utilities :: KeyChain Access.
2. In the left pane, click System.
    It lists all the certificates.
3. Check the expiration dates listed to the right.
5. Click on the certificate that you want to delete.
6. In the menu bar, click Edit :: Delete.
