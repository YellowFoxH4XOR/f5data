K57058111: Unable to create or edit TXT records containing a plus (+) character

Type
Support Solution
Published
2022-02-25
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP DNS: 16.0.0, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 16.0.1
  • BIG-IP LTM: 16.0.1, 16.0.0, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.5
Source
https://my.f5.com/manage/s/article/K57058111

Description

Unable to create or edit TXT records, in ZoneRunner, which contain a plus (+) character in the RDATA field

  • BIG-IP DNS
  • BIG-IP with DNS Services
  • The following error message is observed, when attempting to edit an existing TXT record:
    Resolver returned no such record

Environment

Relevant environmental factors specific to the topic

  • TXT record contains a "+" character.

Cause

This is caused by Bug ID 950069.

Recommended Actions

If you need to edit an existing record which contains a +, you may be able to delete and recreate the record, but only if the new one does not contain the + character. Otherwise, you must freeze the zone and then manually edit the BIND zone file, located in /var/named/config/namedb/. For more information, refer to K7032: Freezing zone files to allow manual update to ZoneRunner-managed zone files.

Additional Information

Bug ID 950069 also affects NAPTR records.
