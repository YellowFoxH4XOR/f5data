Issue

Note: The EUD is a platform-specific package. The EUD version 12.x branch is specific to the BIG-IP 1600, 3600, 3900, 6900, 8900, and EM4000 platforms, and may only be used to field test those platforms. The then-current EUD utility is included in each BIG-IP software installation package, and the most current version in each branch is also available as a standalone installation package on the F5 Downloads site. For more information about the EUD utility, refer to K7172: Overview of the End User Diagnostics (EUD) software.

Important: Field testing a BIG-IP 6900 or 8900 system that runs version 10.1.0 with EUD version 12.5 will corrupt the RAID file system of the unit. For more information, refer to K10902: Running EUD corrupts RAID file system on BIG-IP 6900 and 8900 platforms.

Beginning in EUD version 12.6, the test report log (eud.log) is no longer stored in the /shared/log directory; it is saved in the root directory ( / ) of the boot partition.

This change in behavior was necessary to accommodate running the EUD utility on BIG-IP 6900 and 8900 systems that perform hard drive mirroring. Because the EUD utility is not RAID-aware, it cannot write its test report log to the mirrored file systems of BIG-IP 6900 and 8900 systems. Instead, the boot partition of all BIG-IP systems is a primary partition formatted with a FAT32 file system, which makes it suitable to host the EUD test report log.

Important: All BIG-IP platforms running EUD version 12.6 use the new save location, regardless of whether the platforms are the 1600, 3600, 3900, 6900, 8900, or EM4000. The EUD utility does not distinguish between BIG-IP platforms, and it does not determine their file systems before it writes the test report log.

Retrieving the EUD test report log

The boot partition of the BIG-IP system is not mounted automatically at boot time. Therefore, to retrieve the eud.log file you must perform one of the following procedures:

Retrieving the EUD test report log manually
Retrieving the EUD test report log using a shell script

Retrieving the EUD test report log manually

  1. Connect to the BIG-IP system command line interface.
  2. To create a temporary mount point for the boot partition, enter the following command:

    mkdir /shared/log/bootdir
  3. To mount the boot partition on the newly created mount point, enter the following command:

    mount <device> /shared/log/bootdir

    Note: If a BIG-IP system includes a Compact Flash device, the boot partition is the first partition on the Compact Flash device. If a BIG-IP system does not include a Compact Flash device, the boot partition is the first partition on the hard drive. Refer to the following list to determine what device to use in the command above:

    BIG-IP 1600 /dev/sda1
    BIG-IP 3600 /dev/hda1
    BIG-IP 3900 /dev/hda1
    BIG-IP 6900 /dev/hda1
    BIG-IP 8900 /dev/hda1
    BIG-IP EM4000 /dev/hda1

    For example, on a BIG-IP 1600 system, you would enter the following command:

    mount /dev/sda1 /shared/log/bootdir
  4. To copy the eud.log file from the boot partition to the /shared/log directory, enter the following command:

    cp /shared/log/bootdir/eud.log /shared/log
  5. To unmount the boot partition, enter the following command:

    umount /shared/log/bootdir
  6. To remove the temporary mount point, enter the following command:

    rmdir /shared/log/bootdir

Retrieving the EUD test report log using a shell script

The following shell script automates retrieving the EUD test report log. You can use this script in place of the manual procedure listed above:

#!/bin/bash


# EUD log finder script
# version 1
#

MOUNTPOINT='/shared/log/bootdir/'
mkdir $MOUNTPOINT

# Find an fdisk utility
if [ -f /sbin/sfdisk ]; then
FDISKBIN="/sbin/sfdisk -l --force"
else
if [ -f /sbin/fdisk ]; then
FDISKBIN="/sbin/fdisk -l"
else
echo "I cannot find a valid fdisk program so I am exiting."
rmdir $MOUNTPOINT
exit 165
fi
fi

# Find boot partition
for BOOTPARTITION in $( $FDISKBIN 2>&1|grep '.*\*.*FAT32'|cut -f1 -d' do
if [ "$BOOTPARTITION" ]; then
mount $BOOTPARTITION $MOUNTPOINT
fi
done

# Find and copy eud.log to /shared/log/ if possible
if [ -e $MOUNTPOINT"eud.log" ]; then
echo "Found EUD log file"
cp $MOUNTPOINT"eud.log" /shared/log/
echo "Copied eud.log to /shared/log/"
else
echo "I cannot find an EUD log file so I am exiting."
fi
echo

umount $MOUNTPOINT
rmdir $MOUNTPOINT

To create the script on the BIG-IP system, perform the following procedure:

Note: You need to create the script on the BIG-IP system only once.

  1. Connect to the BIG-IP system command line interface.
  2. Change directories to the /shared directory by entering the following command:

    cd /shared
  3. Using a text editor, edit a new file named get_eud_log.
  4. Paste the shell script into the text editor.
  5. Save the file and quit the text editor.
  6. To change the permissions of the get_eud_log file, enter the following command:

    chmod 777 get_eud_log

To execute the get_eud_log script, enter the following command at the BIG-IP command line:

/shared/get_eud_log
