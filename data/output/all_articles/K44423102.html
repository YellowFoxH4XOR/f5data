Description

How to block users on APM side where the machine (client) is locked on AD (Active Directory)

Environment

  • APM
  • Access Policy
  • AD locked Client
Cause

On the AD side when the machine is locked it has an AD Attribute : userAaccountControl
which shows (Accountdisable) has value : 4098 

Recommended Actions

On Access Policy, in the AD Query VPE agent:
  1. Fetch the attribute userAaccountControl
  2. On the branches check if value is 4098
  3. Deny access if the value matches, otherwise Allow
