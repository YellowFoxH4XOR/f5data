K000152663: Configuration load failure after upgrading AFM-provisioned device to BIG-IP 17.5.x: 01420006:3: "tcp-ack-flood" unknown property

Type
Support Solution
Published
2025-07-22
Updated
2025-07-22
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.0, 17.5.X, 17.5.1
  • BIG-IP AFM: 17.5.0, 17.5.X, 17.5.1
Source
https://my.f5.com/manage/s/article/K000152663

Description

Attempted to upgrade AFM provisioned device to BIG-IP 17.5.x.

Configuration failed to load after the upgrade, with messages similar to the following printed to the console or /var/log/ltm:

err tmsh[10565]: 01420006:3: "tcp-ack-flood" unknown property
emerg load_config_files[10563]: "/usr/bin/tmsh -n -g -a load sys config partitions all " - failed.
Loading schema version: 17.5.1
Syntax Error:(/config/bigip.conf at line: 24189) "tcp-ack-flood" unknown property

Environment

  • AFM provisioned
  • After upgrade to BIG-IP 17.5.x

Cause

  • Bug ID 1983553: Unable to load config after upgrading to v17.5.x with the Syntax Error: "tcp-ack-flood" unknown property

Recommended Actions

To work around this issue, remove or comment out tcp-ack-flood from the device DOS config (security dos device-config) in the bigip.conf.

For example:

dynamic-signatures {
    detection enabled
    dns {
        detection enabled
        mitigation medium
    }
    mitigation medium
    network {
        detection enabled
        mitigation medium
    }
#   tcp-ack-flood {             # This line commented out
#       state disabled          # This line commented out
#   }                           # This line commented out
}

Then reload the configuration:

tmsh load sys config
