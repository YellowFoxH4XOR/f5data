Known Issue

This is the result of a known issue. Some vulnerability scanners are reporting that FirePass potentially has a CGI script vulnerability. This is a false positive. These scanners frequently send requests for potentially vulnerable files in the /my.logon.php3 path. FirePass will return a 200 response code for any requests made in the /my.logon.php3 path, regardless of whether the specific file requested exists. The Apache web server that runs the FirePass web interface will return a 200 response code even if it is not able to map the URI to an existing file.

F5 Networks Product Development is tracking this issue as CR106298 to make an admin-configurable setting to handle path information in the /my.logon.php3 path.

Note: For resolving CGI vulernability reports in the license.php3 path, refer to see K9304: Hiding license information.
