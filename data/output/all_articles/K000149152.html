K000149152: F5OS VLAN unassign and deletion in rapid succession sometimes results in 400 "illegal vlan-listener reference" response

Type
Support Solution
Published
2024-12-31
Updated
2024-12-31
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.7.X, 1.5.X, 1.8.0, 1.7.0, 1.5.2, 1.5.1, 1.5.0
  • F5OS-C: 1.6.X, 1.6.2, 1.6.1, 1.6.0
Source
https://my.f5.com/manage/s/article/K000149152

Description

Attempting to un-assign and delete a VLAN shortly after via API sometimes results in a 400 response similar to the following:

{
  "ietf-restconf:errors": {
    "error": [
      {
        "error-type": "application",
        "error-tag": "malformed-message",
        "error-message": "illegal reference /vlan-listeners/vlan-listener{0.host 1234}/vlan"
      }
    ]
  }
}

Environment

  • F5OS VLAN deletion
  • API operations

Cause

Bug ID1759761 tracks this issue.

Recommended Actions

Bug ID1759761 has no fix at the time of this article's publication, but you can avoid this issue by introducing a small delay between the un-assign and delete operations.

Additional Information

The issue is more likely to occur in low-latency environments.
