Type

Updated

Applies to

  • BIG-IP APM: 16.X.X, 16.1.X, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.X, 16.0.1, 16.0.0
Source
https://my.f5.com/manage/s/article/K000132433

Description

Users connecting to Network access using the browser may fail intermittently with the following pop message:

 

"Please check internet connection and relaunch network access resource"

 

Environment

  • BIG-IP APM Network Access (Connect using browser)
  • Ubuntu Client

 

Cause

Recommended Actions
