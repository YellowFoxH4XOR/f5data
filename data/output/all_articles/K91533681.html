Description

iSeries LCD only shows Secure Mode and no other information is visible on the device LCD display.
The LCD does not respond to user input.
This happens when you change the admin password to anything other than default in the BIG-IP device.
You will see the error message In /var/log/touchscreen_lcd:

err lcdui[1236]: URL: http://x.x.x.x/mgmt/tm/sys/xxxx, result: 'Host requires authentication' (204), HTTP method 2, status 401.

Environment

  • LCD Panel
  • iSeries platform
  • BIG-IP v14.1.2.3 - v14.1.4, v15.1.2.1, v 15.1.3, v16.0.1.1
Cause

Bug ID 970829

Recommended Actions

Update or upgrade your BIG-IP system to a version listed in the Fixed In section of Bug ID 970829.
