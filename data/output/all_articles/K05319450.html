Description

/var/log/ltm is logging the following message:
01010225:3: Failure to query dns-express db <reason>.

In this log message, note the following:

  • <reason> is the database query failure reason.

For example:

01010225:3: Failure to query dns-express db (DB Not Ready).
01010225:3: Failure to query dns-express db (Discarded).

Environment

  • BIG-IP LTM
  • DNS Express

Cause

  • DB Not Ready - A query to the DNS Express database was not successful, database is not ready.
  • Discarded - A query to the DNS Express database is malformed and therefore discarded.
A DNS resolution query continues to process according to the DNS Profile configuration.  A DNS Authoritative Transfer (AXFR) request results in either a SERVFAIL or FORMERR response to the requesting client.

Recommended Actions

None.  This is informational
