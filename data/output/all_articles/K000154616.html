Description

Rebooting a BIG-IP device while the datasyncd obfuscation process is running interrupts the ongoing obfuscation of JavaScript used for client-side security features (such as CAPTCHA, bot defense, and device ID). After reboot, the obfuscation process will automatically restart, which may result in a temporary increase in CPU usage and delay completion of the task. No data loss or corruption occurs during this interruption.

Environment

  • Datasyncd obfuscation
  • ASM or FPS provisioned

Cause

The datasyncd obfuscation process is a scheduled background task that obfuscates JavaScript code for enhanced client-side security. If the device is rebooted while this process is active, it will be interrupted and must restart after the system comes back online. This can temporarily increase CPU usage and delay completion of the obfuscation. 

Recommended Actions

  • Schedule device reboots outside of the datasyncd obfuscation window to avoid repeated interruptions and delays.
  • If a reboot occurs during obfuscation, expect the process to restart and a temporary spike in CPU usage.
  • The obfuscated JavaScript is stored internally within ASM/FPS configuration; logs or policy profiles are not affected by this process.
  • No manual recovery action is required; the system resumes automatically.
  • For further details, refer to F5 Knowledge Base articles K02827102, K10313808, and K57518219.
