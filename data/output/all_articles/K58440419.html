Description
When running IPv6 traffic on virtual server with FastL4 profile, below symptom may be observed 

  • CPU usage is much higher for IPv6 than IPv4 traffic

  • CPU usage is higher with much lower throughput 

  • Error logs observed during system reboot or license activation

warning mcpd[PID]: 01071859:4: Warning generated : License does not support the TurboFlex profile choosen. TurboFlex profile set to base.

  • Statistic is 0 when shows PVA Assist connections, for example:

tmsh show /sys pva-traffic global
-------------------------------------------------
Sys::PVA
-------------------------------------------------
PVA Traffic                ClientSide  ServerSide
  Bits In                           0           0
  Bits Out                          0           0
  Packets In                        0           0
  Packets Out                       0           0
  Current Connections               0           0
  Maximum Connections               0           0
  Total Connections                 0           0

Miscellaneous
  Cur PVA Assist Conns              0
  Tot PVA Assist Conns              0
  HW Syncookies Generated           0
  HW Syncookies Detected            0

Environment

  • BIG-IP LTM 14.x or 15.x

  • IPv6

  • Platforms with the embedded Packet Velocity Acceleration (ePVA) chip. 

  • FastL4 profile with PVA acceleration enabled

Cause

Wrong License cause the TurboFlex profile changed to base.

In bigip_base.conf, related configuration can be found

sys turboflex profile-config {
    type turboflex-base
}

Recommended Actions

  1. Install the correct License which support TurboFlex profile of turboflex-adc at least

  2. Change the turboflex to adc at least to support ipv6 ePVA following manual below

TurboFlex Profiles Overview

  1. Reboot the box and test again
