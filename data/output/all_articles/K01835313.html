Description

When reviewing the LTM logs, you observe logs similar to the following in /var/log/ltm, and are concerned if it is an issue:

Nov 30 02:21:14 bigip1.example.com warning mcpd[6839]: 01071be0:4: CMI Heartbeat Response 172.16.20.40 - Mismatched sequence numbers - expecting 21514, received 21513

Environment

  • BIG-IP
  • Configuration Synchronization

Cause

The Mismatched sequence numbers log occurs when the connection to the peer has been briefly interrupted (such as during the sync of a large configuration). The connection is automatically and swiftly reconnected once the sync operation is finished. MCPD notes that the heartbeat response from the peer is stale, and logs the 'Mismatched sequence numbers' message. As such, this log is not indicative of a problem, but rather is the side-effect of recovery from a transitory disconnect.

Recommended Actions

None. This log message can be safely ignored.
If you suspect, however, that there is an issue with the configsync, you may want to further check the sync-related logs in the LTM logs. See K34291400 for more information.
