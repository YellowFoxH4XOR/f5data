K000134705: [F5OS] Error Message: 01070338:3: Cannot create trunk <<trunk name>>, maximum limit reached

Applies to

Source

Description

  • A tenant has already been deployed and you are trying to add a trunk inside it.
  • After fill all the data under Networking >> Trunks>> New, you get an error that reads:

01070338:3: Cannot create trunk test_trunk_tenant, maximum limit reached


Environment

  • Trunking in an F5OS tenant
  • Error Message
  • It happens in all tenants in all F5OS platforms


Cause

This is an expected behavior. VLANs and Trunking/LAGs must be created in the host device.

 Recommended Actions

  1. Please, create the trunk in the host device, under Networking Settings >> LAGs
  2. Stop the tenant where you want to attach the new Trunk/LAG.
  3. Reconfigure the tenant,
  4. Re-deploy the tenant.
