Description
QKViews capture top information in two places, one of which is "top -cb -n 2 -d 1.0", executed at the start and end of the QKView generation. This command is executed from the bash shell with the output saved as part of the QKView data. If the QKView is uploaded to iHealth, the output can be viewed there. Due to bash shell functionality, process command names in this top execution may become truncated and consequently may not provide useful information in the QKView or iHealth.

Environment

  • QKView
  • iHealth

Cause
Bash will truncate command output width to 80 characters by default with truncation occurring to the right side of the output. Both an Administrator at the bash shell and the QKView process utilize the same bash shell and consequently experience the same, potentially truncated output. Truncated information recorded into the QKView is then preserved in that same state in iHealth. Note that the output format changes slightly in 14.1.0 with the "+" character being added to any line truncated to highlight that truncation has occurred.

Recommended Actions
The bash shell is functioning as designed with the output properly captured into the QKView with iHealth correctly displaying that captured information. If full top output is needed for troubleshooting, it must be gathered from the bash shell manually by an Administrator. Additional Information
The "top -cb" and "top -cb (text only) commands in iHealth display full process/command names as their information is synthetically generated from per-process information captured in the QKView rather than actual top process output. As they are not truly top process output, a notice to this effect is displayed in iHealth for both commands. These may be useful in determining the full command names from truncated "top -cb -n 2 -d 1.0" results if the truncated commands can be matched to the full commands. These commands can be accessed by going to Commands -> Standard -> UNIX -> Current Data in iHealth.
