Known Issue

If you attempt to configure an HTTP monitor receive string using an octal value, you may receive an error message.

This issue occurs when all of the following conditions are met:

  • You are attempting to use an octal value in the receive string of an HTTP monitor using the Configuration utility or the BIG-IP command line.
  • The octal value is greater than \077.

The HTTP monitor can accept both hex and octal values in the send and receive strings. This functionality is particularly useful when you want to use extended ASCII characters within these fields.

Impact

You are unable to enter octal values greater than \077.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The following error message displays in the Configuration utility or on the command line:

    01070753:3: Monitor /Common/<monitor name> recv parameter contains an invalid regular expression (Invalid or trailing backslash).

Workaround

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

To work around this issue, use hex values instead of octal values. To do so, follow the instructions in K4186: Entering escape sequences in an http monitor's send and receive strings.
