Description

  • SSL connections are failing
  • The following error are encountered in the LTM logs: 
    crit tmm9[12811]: 01260010:2: FIPS acceleration device failure: priv key encrypt err. req count=0 err code=0x2000000d, ERR_SECURE_INIT_INCOMPLETE (Driver has not come to operational stage yet)

Environment

  • BIG-IP
  • FIPS

Cause

Possible hardware failure. Unknown at time of publication.

Recommended Actions

Once this error is encountered, contact F5 Support for further assistance. For information about contacting Support, refer to K2633: Instructions for submitting a support case to F5.

Additional Information

  1. Check the state of the FIPS card by running the following command from bash:
    fipsutil info
  2. Or running the command: 
    show sys crypto fips key field-fmt all-properties

The following output is seen which may be indicative of a FIPS Failure Issue: 

Cfm2Initialize2 error 536870925
Cfm2Initialize2 error 536870925
Cfm2Initialize2 error 536870925
