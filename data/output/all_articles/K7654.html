K7654: Client Certificate Passwordless Authentication with an additional client certificate check fails when the login username does not match sAMAccountName

Topic



When you configure Client Certificate Passwordless Authentication with an additional client certificate check against an Active Directory attribute, the login username contained in the client certificate must match the sAMAccountName stored in Active Directory. In order to retrieve the attributes from the Active Directory server, FirePass searches for a sAMAccountName that matches the login username. If the search is successful, FirePass performs the additional client certificate check with the information returned by Active Directory. If the search is unsuccessful, FirePass cannot perform the additional client certificate check and the user authentication fails.

Note: You can configure which client certificate field contains the login username in the Request client certificate during logon drop-down menu on the Device Management : Security: Certificates page.

To address this issue, F5 Networks will create a customizable client certificate Active Directory search attribute field. F5 Networks Product Development is tracking this enhancement request as CR63663. To monitor the status of this CR, refer to the FirePass Release Notes.
