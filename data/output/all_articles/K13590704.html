K13590704: Removing a BIG-IP from BIG-IQ kicks user from GUI

Type
Support Solution
Published
2021-09-10
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K13590704

Description
When you are removing a BIG-IP device or Application from the BIG-IQ, you get kicked out from the GUI and see the following message:

Waiting for BIG-IQ services to become available

Environment

  • BIG-IQ CM configured in VMWare
  • Trying to remove a BIG-IP from BIG-IQ

Cause
BIG-IQ device might be running low on resources

Recommended Actions

  1. Verify that your BIG-IQ has the minimum amount of recommended resources assigned from this guide: Hypervisor guest definition requirements
  2. If it doesn't have the minimum required resources, increase the amount of memory/CPU assigned to the BIG-IQ
  3. In order to recover access to the GUI, type the following command: 
tmsh restart /sys service tokumx tokumond restjavad webd guiserver
