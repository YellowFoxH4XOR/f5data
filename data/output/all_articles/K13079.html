Known Issue

FirePass Web Application tunnels fail to connect when all of the following conditions are met:

  • You have configured the FirePass Controller so user sessions are inside a Protected Workspace (PWS)
  • You have installed Engineering hotfix HF-340099-340872-354839-354931-1 (Support for Firefox 4)

Note: This issue affects all supported browsers.

Impact

Users cannot connect to a Web Application tunnel if the user's session is inside a Protected Workspace.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Users receive a page cannot be displayed message when accessing a Web Application favorite.
  • The vdeskctrl.dll file is version 7000,2011,328,1843 on the client system; you can view this with the FirePass Component Troubleshooting Utility (CTU)

Workaround

This issue exists in a component installed on the client's computer; you must remove and reinstall the client components from the FirePass controller.

To work around this issue, you can remove the engineering hotfix HF-340099-340872-354839-354931-1 from the FirePass controller and remove the client components from affected users' systems. To do so, perform the following procedure:

Impact of workaround: Removing the engineering hotfix removes support for Firefox 4. 

  1. Remove the engineering hotfix HF-340099-340872-354839-354931-1.

    For detailed instructions, refer to the Removing a hotfix section of K3430: Installing FirePass hotfixes.
  2. Remove the client components on affected systems.

    For detailed instructions, refer to K8253: Removing FirePass client components from Windows client systems
