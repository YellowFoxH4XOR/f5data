Description

You received a Return Materials Authorization (RMA) for a device that you suspect is defective. Perform the procedure in this article to replace your rSeries system.

Environment

  • You have physical access to the rSeries device.
  • You have serial console access to the rSeries device.
  • You have administrative access to the rSeries device.

Cause

None

Recommended Actions

Perform the procedures in this section to replace the rSeries device:

  • Preparation
  • Data removal from the system
  • Platform hardware installation
  • Software configuration and setup
  • Restore rSeries system configuration data and BIG-IP tenants

Impact of Procedure

When replacing an rSeries device, all BIG-IP tenants including their services will be down. F5 recommends performing this during a scheduled maintenance. Alternatively, if you have another rSeries device running the same BIG-IP tenants in a High Availability (HA) setup, you can failover the tenants, before replacing the device.

Data removal from the system

rSeries systems use an encryption key, also called the primary key, to encrypt and decrypt highly sensitive passphrases contained in the configuration database.

Before you return a F5 rSeries system to F5 for reprocessing or repair, you should reset the encryption key to remove any sensitive data from your system. For more information on how to do so, refer to the appropriate Platform guide manual:

  • Returned Material Data Security Statement chapter of the Platform Guide: r5000/r10000 Series manual.
  • Returned Material Data Security Statement chapter of the Platform Guide: r2000/r4000 Series manual.

Platform hardware installation

Install the replacement device into a rack. Refer to the appropriate platform guide for information on platform installation

  • Platform Installation chapter of the Platform Guide: r5000/r10000 Series manual.
  • Platform Installation chapter of the Platform Guide: r2000/r4000 Series manual.

Software configuration setup

Perform the following procedure to set up the software for restoration:

  1. F5 recommends that you perform a reset-to-default operation to clear the existing configuration before attempting to restore to a previous configuration.

    Connect to the rSeries device through the device console and perform the procedure in K20024872: Restore the rSeries configuration to factory default settings.

  2. Configure initial network management access to the system. You can do so by connecting to the system through the management console and starting the Setup wizard with the following command:

    appliance-setup-wizard

    • F5 rSeries Systems: Getting Started manual
    • F5 rSeries system initial configuration manual

  3. Upgrade/update the replacement rSeries F5OS-A software to the original version.

    • K93807441: Manage F5OS-A images on the F5 rSeries system
    • F5 rSeries Systems: Installation and Upgrade manual
  4. Activate the license on the replacement rSeries device. For more information on licensing the rSeries, refer to the System licensing overview section of the System Settings chapter of the F5 rSeries Systems: Administration and Configuration manual.
    Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Restore rSeries configuration data and BIG-IP tenants

  1. Restore the rSeries configuration data. Perform the procedures in the following article.

    Note: Set the primary key as described in the article. You set the same primary (encryption) key on both systems so that the encrypted elements are moved successfully along with the configuration.

    • K47512994: Back up and restore the F5OS-A configuration on an rSeries system

  2. Verify the system license. Re-license the system if required.
  3. Ensure that the appropriate tenant BIG-IP software ISO files are imported.
  4. For every BIG-IP tenant, restore the UCS archive.

    Note: Alternatively, if you have another rSeries device running the same BIG-IP tenants in a High Availability (HA) setup, you can set up the new BIG-IP tenants for Configuration Synchronization.

    • K13132: Backing up and restoring BIG-IP configuration files with a UCS archive.
    • K4423: Overview of UCS archives
