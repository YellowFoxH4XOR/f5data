Topic

This article applies to BIG-IP 9.x and 10.x. For information about other versions, refer to the following article:

  • K16528: Overview of the vlangroup.forwarding.override database key (11.x - 12.x)

Introduced in BIG-IP 9.4.0, the vlangroup.forwarding.override database key determines how the BIG-IP system handles traffic with a destination MAC address that does not match any of the BIG-IP system's local MAC addresses. The variable is used in situations where a BIG-IP system is configured with both a Virtual Local Area Network (VLAN) group and a wildcard forwarding virtual server.

The vlangroup.forwarding.override database key can be set to either enable or disable:

  • enable:

    Traffic with a destination MAC address that does not match any of the BIG-IP system's local MAC addresses is bridged by the VLAN group, even if an applicable wildcard forwarding virtual server is present

  • disable:

    Traffic with a destination MAC address that does not match any of the BIG-IP system's local MAC addresses is handled by an applicable wildcard forwarding virtual server (if one exists), even if a VLAN group is present

By default, the variable is set to enable.

Note: Generally, the BIG-IP system does not receive traffic with a destination MAC address that does not match any of the BIG-IP system's local MAC addresses. However, this can occur when a BIG-IP system is configured with a VLAN group. A VLAN group merges two or more member VLANs by bridging them at Layer 2 (L2) level. This allows a node on a member VLAN to ARP for a destination node on another member VLAN. After the source node has learned the destination node's MAC address, the source node can send Ethernet frames directly to the destination node by using the BIG-IP system as a L2 switch. It is within this context that the BIG-IP system can receive traffic with a destination MAC address other than its own. Forwarding certain traffic using a wildcard forwarding virtual server instead of VLAN group bridging allows a BIG-IP Administrator to control protocol level settings (such as idle timeout values) via a FastL4 profile.

To configure the vlangroup.forwarding.override database key, perform the following procedure:

  1. Log on to the BIG-IP system command line.
  2. Specify a new value for the database key by entering the following command:

    bigpipe db vlangroup.forwarding.override <enable|disable>

    For example:

    bigpipe db vlangroup.forwarding.override disable

  3. Save the configuration by running the bigpipe save command.
