Known Issue

Modifying virtual servers may fail when using the tmsh utility.

This issue occurs when the following condition is met:

  • The tmsh edit command is used to modify an existing virtual server.

Impact

You are unable to modify the virtual server.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you use the tmsh edit command to modify an existing virtual server, the editor screen displays the default template for creating a virtual server.
  • You are unable to save changes to an existing virtual server using the tmsh edit command.

Resolution

Status

F5 Product Development has assigned ID 414245 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can use the modify command in the tmsh utility. For more information about using the tmsh modify command, refer to the Traffic Management Shell (tmsh) Reference Guide.

Impact of workaround: Performing this procedure should not have a negative impact on your system.
