Description

Unable to configure policy rules in Common to forward traffic to objects in non-Common partitions after upgrade to 13.x or later.

This was possible in previous versions.

Environment

  • LTM policy rule

Cause

It is no longer possible from version 13.0.0 onwards due to the fix for ID632204. That was an intentional change.

Recommended Actions

  • The rules for partition objects are:
  • Objects in Common can access/use/view only objects in Common. Cannot access/use/view objects in non-Common.
  • Objects in non-Common can access/use/view objects in Common and in the same non-Common partition.
  • Objects in non-Common cannot use/access/view objects in other non-Common objects.

Re-configure traffic policies in line with the rules for partition objects outlined above.
