Topic

F5 has recently discovered and corrected a number of critical issues that affect customers running FirePass 6.1.0. F5 recommends that all customers currently running version 6.1.0 install cumulative HF-610-1, or a later version of the cumulative hotfix, as soon as possible.

The following CRs are fixed in cumulative HF-610-1 for FirePass 6.1.0:
