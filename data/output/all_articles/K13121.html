Topic

Note: For information about changing system maintenance account passwords in earlier versions, refer to K3350: Changing system maintenance account passwords (9.x - 10.x).

You should consider using these procedures under either of the following conditions:

  • You want to modify the passwords for the root or admin users.
  • You want to reset a lost or forgotten root password.

Description

On installation, the BIG-IP and BIG-IQ systems create a default root user and a default administrative user with the following credentials.

UsernamePassword
rootdefault
adminadmin

For more information about default users, refer to K13148: Overview of default management access settings for F5 products.

You should always modify the passwords for BIG-IP and BIG-IQ maintenance accounts from their defaults. The procedures in this article provide multiple ways to modify the system maintenance account password to comply with password policies, standards such as PCI compliance, or other security policies appropriate to your organization.  If you lose or forget the root password, you can reset it without reinstalling the system software.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • To modify the root or admin passwords, you must have either administrator or root level access to either the BIG-IP Configuration utility or BIG-IQ user interface or the command line, respectively.
  • To reset a lost root password, you must have access to the BIG-IP or BIG-IQ serial console.

Procedures

  • Use the BIG-IP Configuration utility to modify the BIG-IP system maintenance account passwords
  • Use the BIG-IQ user interface to modify the BIG-IQ system maintenance account passwords
  • Use tmsh to modify system maintenance account passwords
  • Reset a lost or forgotten root password
  • Non-interactively modify the system maintenance account passwords

For a brief demonstration of the BIG-IP procedures, go to  Change the admin or root password on your BIG-IP system.

Use the BIG-IP Configuration utility to modify the BIG-IP system maintenance account passwords

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Go to System > Platform.
  3. Under User Administration, choose the Password box for either Root Account or Admin Account.
  4. Enter the new password.
  5. Enter the same password in the Confirm box for the account that you chose in step 3.
  6. Select Update.
  7. If you have updated the password for Admin Account, the system logs you out of the Configuration utility, and you must log in again using the new password.

Use the BIG-IQ user interface to modify the BIG-IQ system maintenance account passwords

You can use the BIG-IQ user interface to modify the BIG-IQ admin user account password but not the root user account password. To modify the BIG-IQ root user account password, you must use the TMOS Shell (tmsh) procedure described in the Use tmsh to modify the system maintenance account passwords procedure. To use the BIG-IQ user interface to modify the BIG-IQ admin user account password, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ user interface.
  2. Go to System > USER MANAGEMENT > Users.
  3. Select the admin user. The BIG-IQ user interface displays the User Properties for the admin user.
  4. For Old Password, enter the existing password for the admin user.
  5. For Password, enter your preferred new password for the admin user.
  6. For Confirm Password, enter the same password for the admin user that you chose in the previous step.
  7. Select Save & Close.

Use tmsh to modify the system maintenance account passwords

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To modify the password for the root account, enter the following command:

    Note: If you need to modify the password for only the admin account, skip to step 5.

    modify auth password root

  3. When prompted, enter the new root password.
  4. When prompted, reenter the new root password to confirm.

    Note: If you need to modify the password for only the root account, skip the remaining steps.

  5. To modify the password for the admin account, enter the following command:

    modify auth user admin prompt-for-password

  6. When prompted, enter the new admin password.
  7. When prompted, reenter the new admin password to confirm.
  8. To save changes to the configuration files, enter the following command:

    save sys config

  9. To exit tmsh, enter the following command:

    quit

Reset a lost or forgotten root password

BIG-IP 14.1.0 and later

To reset a lost or forgotten root password, refer to the following articles:

  • K35811337: Recover the root password on non-RAID BIG-IP platforms (BIG-IP 14.1.0 and later)
  • K23220345: Recover the root password on RAID-capable BIG-IP platforms (BIG-IP 14.1.0 and later)

BIG-IP 11.0.0 through 14.0.0

To reset a lost or forgotten root password, refer to K73551536: Recover the root password on BIG-IP platforms (BIG-IP 11.x - 14.0).

BIG-IQ

To reset a lost or forgotten root password on the BIG-IQ system, refer to K92740423: Recover the root user password on BIG-IQ Virtual Edition.

Non-interactively modify the system maintenance account passwords

If you use automation to configure the BIG-IP system, you may want to update the system maintenance account passwords non-interactively (not prompted for a password). You can incorporate the following procedure using the BIG-IP command line into your automation process.

Impact of procedure: Performing the following procedure should not have a negative impact on your system; however, ensure you securely store and transmit cleartext passwords.

  1. Use your automation tool to log in to the BIG-IP command line using SSH.
  2. To modify the password for the root or admin account, use the following syntax that includes the semicolon to combine the tmsh command and the history command to delete the cleartext passwords from bash history.

    echo -e '<new password>\n<new password>' | tmsh modify auth password <root or admin>; history -d $(history 1).

    For example:

    echo -e 'secret\nsecret' | tmsh modify auth password root; history -d $(history 1)

  3. You can verify the command is not stored in history by entering the following command:

    history

  4. To save changes to the configuration files, enter the following command:

    tmsh save sys config

  5. If the device is in a device group, synchronize the change with the following syntax:

    tmsh run cm config-sync <sync_direction> <sync_group>

    For example:

    tmsh run cm config-sync to-group FailoverGroup
