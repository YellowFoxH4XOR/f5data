K9667: Terminal display may be garbled when running the End-User Diagnostic (EUD) on a VIPRION blade

Source

Topic

If the End-User Diagnostics (EUD) is run on a VIPRION blade that was accessed using the bladectl command, the terminal display will be garbled. This is the expected behavior.

Recommended Action

You must run the EUD on the local console of a VIPRION blade that is being tested.

For information about running the EUD, refer to the End-User Diagnostics release note.
