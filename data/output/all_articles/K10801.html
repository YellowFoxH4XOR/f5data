Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator pvac parser incorrectly parses commands that are contained within commented out sections of HTML code.

When this issue is encountered, an error message that appears similar the following example may be reported to the /var/log/wa/pvac.log file:

debug WA Debug: [          PvPezParser.cxx:4789           parser_warn ] < ended tag instead of expected >

For example, the following Javascript code that is contained within a commented out section of the HTML code would be erroneously parsed by the pvac parser:

<html><body>
<script type="text/javascript">
<!-- hide script from older browsers
for (i=0; i<9; i++) {
document.write('<img src="/icons/pie'+i+'.gif">');
}
// -->
</script>
</body></html>

This behavior may impact the performance of the system. For more information, refer to K10800: Large numbers of PvPezParser warnings may impact system performance.

F5 Product Development tracked this issue as ID 223350 (formerly CR129157) and it was fixed in BIG-IP version 11.0.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.
