Description

What do the different fields in F5OS alarms and SNMP traps mean?

Environment

  • F5OS
  • VELOS
  • rSeries appliances

Cause

None

Recommended Actions

F5OS alarms are both logged and sent as SNMP traps with the following fields defined in F5-ALERT-DEF-MIB:

  • alertSource indicates the component raising or clearing the alarm.
  • alertEffect is an integer value representing the state of the alarm:
    • clear(0) is reported in alertEffect when alarm is cleared.
    • assert(1) is reported in alertEffect when alarm is raised.
    • event(2) is updated in alertEffect when event notification is reported.
  • alertSeverity is an integer value representing alert severity:
    • emergency(0), system is unusable
    • alert(1), action must be taken immediately
    • error(3), error conditions
    • warning(4), warning conditions
    • notice(5), normal but significant condition
    • info(6), informational
    • debug(7), debug-level messages
    • na(8), severity is not-applicable for cleared alerts
  • alertTimeStamp is the timestamp at which the event fired in UTC.
  • alertDescription is a text description of the alert.

Additional Information

F5OS Alarms are defined in these MIBs:

  • F5-CTRLR-ALERT-NOTIF-MIB for VELOS controllers.
  • F5-PARTITION-ALERT-NOTIF-MIB for VELOS partitions.
  • F5OS-APPLIANCE-ALERT-NOTIF-MIB for rSeries appliances.
