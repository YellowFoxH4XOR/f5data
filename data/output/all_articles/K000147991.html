K000147991: Why blocked requests ( Attacks) are not visible in HTTP LB Security Monitoring?

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Apps
  • F5 Distributed Cloud Multi-Cloud App Connect
Source
https://my.f5.com/manage/s/article/K000147991

What Happened?

  • You cannot see the blocked requests when going to Security Monitoring on HTTP Load Balancer (LB) as only 500 requests are shown out of x amount.

Environment

  • F5 Distributed Cloud WAAP

  • F5® Distributed Cloud Console

  • Logs

Resolution/Answer

  • That’s by design.
  • For any selected time range, only 500 security events (logs) will be shown in the UI.
  • The chart will show the trend or full count of events.

None
