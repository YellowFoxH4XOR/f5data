K000141173: F5OS-A LACP down

Type
Support Solution
Published
2024-09-25
Updated
2024-09-25
Applies to
  • F5OS
  • F5OS-A: 1.5.1
Source
https://my.f5.com/manage/s/article/K000141173

Description

  • LAG interfac oper-status DOWN
  • LAG interface members lacp_state LACP_DEFAULTED
  • LACP members SYNCHRONIZATION status OUT_SYNC
  • Interfaces oper-status UP
  • LLDP/LACP PDUs exchanged betwwen F5OS system and peer device.

Environment

  • F5OS-A
  • r2000 and r4000 series appliances.
  • LLDP or LACP is configured correctly in both ends
  • Links are up.

Cause

Seen behavior is caused by known issue tracked with the Bug ID 1352421

Recommended Actions

Upgrade to an unaffected version. As a workaround, you can reboot the device.

Additional Information

To confirm if Bug ID 1352421 is in play, you can run the following command on CLI connected as root.

netstat -an | egrep 1030\|1031

If the output is similar to the following, confirms that ID1352421 is in play:

tcp 0 0 100.75.3.71:1030 0.0.0.0:* LISTEN
tcp 0 0 100.75.3.71:1031 0.0.0.0:* LISTEN
tcp 0 0 100.75.3.71:1031 100.65.60.2:59598 ESTABLISHED
tcp 0 0 100.75.3.71:1031 100.65.60.2:60760 ESTABLISHED

The nic-manage has no subscribers connected to port 1030. This is not correct.
