K000134787: Monitors don't work with recv-disable string if using In-TMM monitoring

Type
Support Solution
Published
2023-05-25
Updated
2023-05-25
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0, 16.1.3, 14.1.5, 15.1.8
Source
https://my.f5.com/manage/s/article/K000134787

Description

When In-TMM monitoring is enabled, HTTP, HTTP2 or TCP monitors with the recv-disable string function don't work - the pool member is marked as offline instead of disabled.

Environment

  • HTTP, HTTP2 or TCP monitor with the recv-disable string function configured.
  • In-TMM monitoring configured.

Cause

This is due to bug ID1287045.

Recommended Actions

  • Disable In-TMM monitoring. For further information see K11323537: Configuring In-TMM monitoring
  • If disabling In-TMM monitoring is not an option, open a support case and request an engineering hotfix (EHF). For further information see K4918: Overview of the F5 critical issue hotfix policy

Additional Information

None.
