K000137657: Do we need to re-download or re-install NGINX Plus code with new subscription once current NGINX Plus Subscription ends?

Description

  • What happens after a current NGINX Plus subscription expires?
  • Do we need to re-download or re-install NGINX Plus?
  • Is the NGINX Plus code going to stop working after the subscription expires?

Environment

NGINX Plus

Cause

None

Recommended Actions

You are not required to re-download the code, however when the NGINX subscription is updated, you will need to replace the NGINX Plus certificate and public key (nginx-repo.crt and nginx-repo.key files). Starting from NGINX Plus Release 33, the JSON Web Token (JWT) file will be required. For the detailed procedure please refer to the following article,

  • Installing NGINX Plus

The code won't stop working, however, NGINX Plus cannot be updated and the following error could be encountered. Refer to K00009136 for more details.

Failure: repodata/repomd.xml from nginx-plus: [Errno ###] No more mirrors to try. https://pkgs.nginx.com/plus/*****/2/x86_64/repodata/repomd.xml: [Errno ###] HTTPS Error 400 - Bad Request.

    • K000091326 : Unable to update NGINX
