Known Issue

This is the result of a known issue. When a Client SSL profile is configured to require client certificates, the BIG-IP system may send an invalid ServerHello message in response to a ClientHello message. This behavior causes the SSL handshake between the client and the BIG-IP system to fail.

This issue can also occur if the client attempts to use either the EXP-RC4-MD5 or the EXP-DES-CBC-SHA ciphers to establish the connection. In this situation, it does not matter if the Client SSL profile is configured to require a client certificate.

When this issue occurs, the system logs an error message to the /var/log/ltm file that appears similar to following example:

info tmm1[5208]: 01260013:6: SSL Handshake failed for TCP from 10.1.1.1:30000 to 10.2.2.2:35000

F5 Product Development tracked this issue as ID 225930 and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP 10.2.0. You may download this hotfix or a later version of this hotfix from the F5 Downloads site.
