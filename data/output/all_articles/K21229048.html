K21229048: Error Message -- err tmsh[11920]: 01420006:3: ''global-settings'' unexpected argument

Applies to

Source

Description

In BIG-IP version 13.1.0 and later, analytics global-settings command is used to list or modify the global analytics settings.
This message occurs if BIG-IQ discovers a BIG-IP of a version older than 13.1.0, and have the stats collection enabled.

As an impact you may see this message in the following files:

  • /var/log/ltm 
  • /var/log/audit
     

Environment

  • BIG-IP 13.1.0 and later
  • BIG-IQ
  • Stats collection enabled

Cause

In BIGIP versions prior to 13.1.0, the command “ analytics global-settings” is not available.

For example:
BIGIP V12
[root@Big-ip-V12:Active:Standalone] config #tmsh list analytics global-settings
Syntax Error: "global-settings" unexpected argument 

BIGIP V13
[root@(Big-ip-V13:Active: Standalone]# list analytics global-settings
analytics global-settings { }


Recommended Actions

The workaround is to deploy a private version of analytics iApp. Or Upgrade the device to V13 or above
