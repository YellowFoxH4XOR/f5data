Description

Blade rebooted unexpectedly.

The following messages are found in /var/log/kern log:

warning kernel: swapper/22: page allocation failure: order:2, mode:0x104020

warning kernel: swapper/22: page allocation failure: order:2, mode:0x104020

warning kernel: kswapd0: page allocation failure: order:2, mode:0x104020

warning kernel: tmm.0: page allocation failure: order:2, mode:0x104020

 

Environment

  • BIG-IP
  • VIPRION
  • B4450N blade

Cause

Bug ID 950849

Bug ID 1126045

Recommended Actions

Follow the workaround in ID950849 to increase the kernel's min_free_kbytes

Additional Information

This issue has also been observed in 15.1.7
