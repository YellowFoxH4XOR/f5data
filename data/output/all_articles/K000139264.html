Description

  • You have 2 units ( A and B) in sync.
  • You modify the traffic-group from traffic-group-1 (floating) to traffic-group-local-only (non-floating) for a virtual address on unit A.
  • You attempt a config sync from unit A to unit B and get an error message similar to below:

err mcpd[6020]: 01070712:3: Caught configuration exception (0), Values (/Common/x.x.x.x) specified for virtual address metadata (/Common/x.x.x.x references): foreign key index (virtual_address_FK) do not point at an item that exists in the database..

 

Environment

BIG-IP LTM
Virtual address with a metadata
traffic-group-local-only

Cause

The virtual address in question is configured with a metadata and associated with a non-floating traffic-group, such as the example below:

ltm virtual-address myVirtualAddr {
  address 4.4.4.4
 inherited-traffic-group true
mask 255.255.255.255
 metadata {
 references {
value 1
  }
}
traffic-group traffic-group-local-only
}

Recommended Actions

1. Use tmsh to remove the metadata setting from the relevant Virtual address
   tmsh modify ltm virtual-address <virtual-address-name> metadata none

2. Attempt the config sync again
