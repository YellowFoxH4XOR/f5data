K03529340: Message ''Sending database catchup request file '/var/apm/localdb/localdb.unsolicited.full.x'' are printed to /var/log/apm repeatedly

Published
2021-12-03
Updated
2025-07-09
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K03529340

Description

The below message is printed repeatedly under /var/log/apm
01ab0014:5: Sending database catchup request file '/var/apm/localdb/localdb.unsolicited.full.hostname.of.your.device.16xxxxxxx' to device group '/Common/your-device-group'.

Environment

  • BIG-IP HA
  • APM provisioned

Cause

These logs occur when localdbmgr checks with the device group to see if it needs to update to the latest version of the localdb. localdbmgr tries to check the timestamp delta of the localdb and if the timestamp varies, then localdbmgr will send an unsolicited response to the db sync leader. This will result in a full copy of the database being sent to the device with the out of date timestamp. The logs will occur if the log level for localdbmgr is set to notice and localdbmgr is being restarted.

Recommended Actions

No action is required. This log message is expected and does not indicate a problem
