K000163461: SAML with Client Cert Auth using F5 Access for Android in version 3.2.2

Type
Support Solution
Published
2026-09-29
Updated
2026-09-29
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000163461

Description

Because of security improvements in version 3.2.2, some users whose company login requires an extra digital certificate check (used with certain sign-in providers) found that login would fail, with the connection being rejected before it could complete.


Environment

  • F5 Access for Android in version 3.2.2
  • Use of SAML sign in 
  • Client Certificate Authentication


Cause

Security Enhancements in version 3.2.2 were then improved for version 3.2.2


Answer/Recommended Actions

Upgrade to F5 Access for Android version 3.2.3

The latest F5Access app is updated to correctly recognise and respond to these certificate requests at the right moment during login, restoring the ability to connect for the affected users while still keeping passwords and codes protected from untrusted sites.
