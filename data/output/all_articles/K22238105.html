Description

BIG-IP command utility istats command option "remove" behavior changed to same as "reset" since v13.1.0.
"remove" option in v12.* and before used to delete the table, but in v13.1.0 and later set the values to "0" as same as "reset".
 

Environment

  • BIG-IP v13.1.0 and later
     

Cause

In v13.1.0,  tmstats2 for istats was merged into tmstat.  Part of this changes istats remove to act as reset.
So we added new "drop_row" option.

v12.1.*
# istats
Usage: istats <operation> [-s <segment-filename>] <key> [<value>]
   <operation> is one of: 'set' 'incr' 'get' 'remove' 'dump'
   <key> is a single quoted argument: "<class> <object> <measure-type> <measure>" (like "ltm.pool /Common/mypool counter mystat")
   <measure-type> is one of: 'counter' 'gauge' 'maximum' 'minimum' 'string'
   <value> must be specified for 'set' and 'incr', and must be an integer for 'incr'
           The <value> for a gauge may be negative.  Use 2 dashes before the negative value (like 'incr "... gauge ..." -- -1')

V13.1.0 and later
config # istats
Usage: istats <operation> [-s <segment-filename>] <key> [<value>]
   <operation> is one of: 'set' 'incr' 'get' 'remove' 'dump' 'drop_row'
           'drop_column' 'clear_row'
   <key> is a single quoted argument: "keyspace <table> <column> <value> ... <type> <measure>"
           (like "ltm.pool /Common/mypool counter mystat")
   <type> is one of: 'counter' 'gauge' 'string' 'text' 'signed' 'unsigned' 'bin'
           'dec' 'hex' 'timestamp' 'timeval' 'uinthex'
   <value> must be specified for 'set' and 'incr', and must be an integer for 'incr'
           The <value> for a gauge may be negative.  Use 2 dashes before the
           negative value (like 'incr "... gauge ..." -- -1')
 

Recommended Actions

Use drow_row option to delete row.
There is no way to delete table, but reboot will reset removes custom made tables.
