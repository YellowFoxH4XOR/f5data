Description

Installing multi-cluster Aspen Mesh with multi-primary on different network setup is documented by Aspen Mesh and Istio docs.

In Aspen Mesh 1.9.5-x, due to recent changes on Istio ingress-gateway Helm Charts manifests, we need to add an additional step to configure multi-cluster deployment.

Environment

  • Kubernetes: 1.17.x,1.18.x,1.19.x,1.20.x 
  • Aspen Mesh: 1.9.5-x 

Cause

None

Recommended Actions

The following file was removed from Helm Charts:

manifests/charts/gateways/istio-ingress/templates/preconfigured.yaml

As a result we no longer need to add global.multuCluster.enabled: true option in the overridden values.yaml file.

The Istio eastwest-gateway configuration (the content of preconfigured.yaml file) was moved to:

samples/multicluster/expose-services.yaml

The configuration from the above file needs to be applied manually after cluster installation on all mesh clusters. expose-services.yaml file is included into Aspen Mesh installation tar-ball file.

On every mesh cluster, to apply the configuration, please run:

kubectl apply -n istio-system -f samples/multicluster/expose-services.yaml

The configuration has to be applied on all cluster, at the end of the documented procedure , after eastwestgateway is installed.
