Topic

You should consider using this procedure under the following condition:

  • You want to view product release notes for F5 products.

Description

For a brief demonstration of how to view VNF Manager release notes, go to  Viewing VNF Manager release notes on F5 Cloud Docs.

Prerequisites

If MyF5 prompts you to log in to view an article, and you do not have a MyF5 account, refer to K000089224: Register for a MyF5 account .

Procedures

  • View product release notes for most F5 products on MyF5
  • View product release notes for all NGINX products on NGINX Docs
  • View product release notes for VNF Manager, BIG-IP Next SPK, BIG-IP Next CNF, and F5 Insight on F5 Cloud Docs

View product release notes for most F5 products on MyF5

  1. Go to MyF5 (my.f5.com).
  2. Go to Resources > Product Manuals and Release Notes.
  3. Under Product, select the product you want, or select Search and enter the product name.
  4. If applicable, under Version, select the product version you want.
  5. Under Document Type, select Release Note.

View product release notes for all NGINX products on NGINX Docs

The following NGINX products do not have standardized release notes:

  • NGINX Unit
  • NGINX Amplify
  • NGINX ModSecurity WAF

To view product release notes on NGINX Docs, do the following:

  1. Go to NGINX Docs (docs.nginx.com).
  2. Select the NGINX product you want.

    Note: For NGINX Management Suite Instance Manager, API Connectivity Manager, and Security Monitoring, select NGINX Management Suite, and then select the product name you want.

  3. Select Releases.

View product release notes for VNF Manager, BIG-IP Next SPK, BIG-IP Next CNF, and F5 Insight on F5 Cloud Docs

View VNF Manager release notes

  1. Go to F5 Cloud Docs (clouddocs.f5.com).
  2. Under Network Function Virtualization, select F5 VNF Manager.
  3. Select Release notes.

View BIG-IP Next SPK release notes

  1. Go to F5 Cloud Docs (clouddocs.f5.com).
  2. Under 5G Networks, select Service Proxy for Kubernetes.
  3. Select Release Notes.

View BIG-IP Next CNF release notes

  1. Go to F5 Cloud Docs (clouddocs.f5.com).
  2. Under 5G Networks, select Cloud-Native Network Functions.
  3. Select Release Notes.

View F5 Insight release notes

  1. Go to F5 Cloud Docs (clouddocs.f5.com).
  2. Under XOps, select F5 Insight.
  3. Select Release Notes.
