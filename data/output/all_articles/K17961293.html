Description
BIG-IP APM Native RDP client on Windows 10 may fail to connect with an error message similar to the following:

The connection has been terminated because an unexpected server authentication certificate was received from the remote computer.

Environment

  • BIG-IP APM 13.0.0 or later
  • Remote Desktops resource
  • Native RDP client
  • Destination Type Host Name is used and resolved to multiple IP Addresses with different certificate, and the certificate is invalid for Host Name
  • Windows 10 RDP client 

Cause
BIG-IP APM may connect multiple RDP servers by Host Name resolution and client may receive different certificates from each RDP server. 
This may result in connection termination. 
 

Recommended Actions

  1. Modify DNS records to map the Host Name to a single IP Address
  2. Make sure that the RDP server present a valid certificate
