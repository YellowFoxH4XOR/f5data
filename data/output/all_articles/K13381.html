Known Issue

When you attempt to install a renewed Secure Sockets Layer (SSL) certificate using the Traffic Management Shell (tmsh), the BIG-IP system fails the installation and returns an error. This issue occurs when the following condition is met:

  • You use one of the following commands:
    • tmsh install sys crypto cert <cert name> from-local-file <path/to/cert/file>
    • tmsh install sys crypto cert <cert name> from-editor
    • tmsh install sys crypto cert <cert name> from-url <url/to/cert/file>

Impact

Users cannot install a renewed SSL certificate using the tmsh install sys crypto cert command.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system logs error messages to the /var/log/ltm file and command line, similar to the following example:

    01020066:3: The requested unknown (/Common/blue.sg.es.example.com.crt) already exists in partition Common

Workaround

To work around this issue, you can use the Configuration utility to install the renewed SSL certificate. Alternatively, you can use the tmsh modify sys file ssl-cert command to install the renewed SSL certificate. To do so, perform one of the following procedures:

  • Using the Configuration utility to install the renewed SSL certificate
  • Using the tmsh modify sys file ssl-cert command to install the renewed SSL certificate

Using the Configuration utility to install the renewed SSL certificate

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > SSL Certificate List.
  3. Select the affected SSL certificate.
  4. Click Import.
  5. Click Browse.
  6. Select the file containing the renewed SSL certificate.
  7. Click Import to install the renewed SSL certificate.

Using the tmsh modify sys file ssl-cert command to install the renewed SSL certificate

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Install the renewed SSL certificate by using the following command syntax:

    modify sys file ssl-cert <cert name> source-path <path/to/cert/file>

    For example, to install the renewed SSL certificate located in /var/tmp/blue.sg.es.example.com.renewed.crt into the SSL certificate name blue.sg.es.example.com.crt, type the following command:

    modify sys file ssl-cert blue.sg.es.example.com.crt source-path file:/var/tmp/blue.sg.es.example.com.renewed.crt

  3. Save the change by typing the following command:

    save sys config
