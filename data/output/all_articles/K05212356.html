Description

Attempting to install an ENG HF into a fresh volume. The task never shows any progress. After rebooting from CLI, the BIG-IP is not operational and  these errors appear:

In the /var/log/kern.log:

info kernel: ata5.00: configured for UDMA/133
info kernel: sd 4:0:0:0: [sda] tag#26 FAILED Result: hostbyte=DID_OK driverbyte=DRIVER_SENSE
info kernel: sd 4:0:0:0: [sda] tag#26 Sense Key : Medium Error [current] [descriptor]
info kernel: sd 4:0:0:0: [sda] tag#26 Add. Sense: Unrecovered read error - auto reallocate failed
info kernel: sd 4:0:0:0: [sda] tag#26 CDB: Read(10) 28 00 12 65 cd 20 00 00 08 00
err kernel: blk_update_request: I/O error, dev sda, sector 308661536

In the /var/log/daemon.log:

emerg logger[835]: Re-starting logmysqld
emerg logger[945]: Re-starting monpd
emerg logger[1024]: Re-starting asm

In the /var/log/ltm:

err logmysqld[24275]: Fatal error db.cpp:exec_query:150 CREATE TABLE IF NOT EXISTS log_data (
notice sod[6342]: 010c0044:5: Command:  running enable bd bigstart.
err logmysqld[24866]: Fatal error db.cpp:exec_query:150 SELECT COUNT(*) from log_data_current errno[2013] strerror[Lost connection to MySQL server during query]
notice sod[6342]: 010c0044:5: Command:  running enable bd bigstart.
err logmysqld[25550]: Fatal error db.cpp:exec_query:150 SELECT COUNT(*) from log_data_current errno[2002] strerror[Can't connect to local MySQL server through socket '/var/lib/mysql/mysql.sock' (111)]
notice tmm[19646]: 01010029:5: Clock advanced by 556 ticks
err logmysqld[26283]: Fatal error db.cpp:exec_query:150 CREATE TABLE IF NOT EXISTS log_data_current (

You have performed EUD and all tests have passed.

Environment

  • BIG-IP LTM
  • MySQL database

Cause

  • MySQL database corrupted

Recommended Actions

  1. Perform EUD to discard hardware issues.
  2. Try to repair the MySQL databases with the article: K05755225.
  3. If the issue is not resolved, boot the system to a different software image: K34745165
  4. If the unit did not recover, consider performing a clean installation of your BIG-IP: K13132

None.
