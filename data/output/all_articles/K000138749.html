Description

You want to configure Google reCAPTCHA as part of APM policy login process for dedicated Route Domain. When adding the default route configured to dedicated Route Domain, following error can be seen in the /var/log/apm logs:

 

<date> <time> <hostname> warning apmd[5817]: 0149026a:4: <APM_policy>: Unexpected result while verifying CAPTCHA (<CAPTCHA_object>): Couldn't perform CAPTCHA validation: Timeout was reached, proceeding with policy: 0. 

 Environment

  • BIG-IP APM
  • Google reCAPTCHA
  • Route Domain

 Cause

This is expected behavior. APM authentication always uses Route Domain 0 to connect to Google and verify the Captcha. 

 Recommended Actions

Create default route for Route Domain 0.

None
