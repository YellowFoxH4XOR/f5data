K000092609: Statistics collection error: agentInstaller failed: java.lang.IllegalStateException: conflicts with file from package

2022-11-13

Applies to
  • BIG-IP
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.1.0
Source
https://my.f5.com/manage/s/article/K000092609

Description

BIG-IQ: 8.1.0.2

Managed device:  LTM1

BIG-IQ: Devices tab > Devices > LTM1 > Statistics Collection // shows error:

Statistics collection error: agentInstaller failed: java.lang.IllegalStateException: installIapp on device 1.1.1.1

failed: java.lang.IllegalStateException: file /var/config/rest/iapps/staging/f5.bigiq-analytics.tmpl from install of analytics-iapp2-8.1.0.1-0.0.36.noarch

conflicts with file from package analytics-iapp-8.1.0-0.0.36.noarch.

Please try again by clicking "Save and Close," below.

Environment

BIG-IQ: 8.1.0.2

BIG-IP: 16.1.3.1 being managed by BIG-IQ

Cause

BIG-IQ is trying to install a rpm file, but cannot due to the conflict with a file that exists on BIG-IP LTM1

Recommended Actions

Based on the error message:

analytics-iapp2-8.1.0.1-0.0.36.noarch 

analytics-iapp-8.1.0-0.0.36.noarch 

--

On the BigIP device: LTM1

Please run command in CLI:

Command:

rpm -qa | grep analytics

If the file: analytics-iapp-8.1.0-0.0.36.noarch is found on the box(LTM1), please try removing it:

CLI:

rpm -e analytics-iapp

 No need to be concerned if rpm file is deleted.

The rpm file is being pushed from BIG-IQ box to the BIG-IP box(LTM1); thus, the rpm file will be replaced.

Additional Information

None.
