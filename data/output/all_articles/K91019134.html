Known Issue

The Configuration utility may erroneously reset the statistics of all pool members when resetting the statistics of one pool member.

This issue occurs when all of the following conditions are met:

  • You have configured a pool with multiple pool members on the BIG-IP system.
  • You attempt to reset the traffic statistics for a specific pool member from the BIG-IP Configuration > Statistics > Module Statistics > Local Traffic page.

Impact

You cannot reset the traffic statistics for a specific pool member.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you want to select a specific pool member to reset its traffic statistics, you navigate to BIG-IP Configuration > Statistics > Module Statistics > Local Traffic, and set the Statistics Type to Pools, and you notice that the system is resetting statistics of all the pool members in the same pool.

Workaround

To work around this issue, you can use the TMOS Shell (tmsh) to reset the traffic statistics of a specific pool member. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP system.
  2. Access tmsh by typing the following command:

    tmsh

  3. Reset the traffic statistics of the pool member by using the following command syntax:

    reset-stats /ltm pool members { <pool_member> }

    For example:

    reset-stats /ltm pool members { 192.168.1.1:http  }
