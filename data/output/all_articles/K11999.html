K11999: Post-Logon Actions are not processed in a Protected Workspace

Type
Knowledge
Published
2010-08-27
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 7.0.0, 6.1.0
Source
https://my.f5.com/manage/s/article/K11999

Topic

This is expected behavior. The FirePass controller will not process Endpoint Security : Post-Logon Actions if your VPN session is running within a Protected Workspace. The restrictions that Protected Workspace impose will block any Post-Logon Actions that are associated with your VPN session.

Note: For more information about Protected Workspaces and Endpoint Security refer to the FirePass Controller Administrator Guide.
