Description

When attempting to reactivate the license, you  are  presented with the error message:

Error 51091: The system platform is either unrecognized or is not a valid version for the identified platform - The license server was not able to determine the appliance's platform from the dossier.

The reactivate button can also be grayed out or missing from the configuration utility.

Environment

  • BIG-IP vCMP
  • License reactivation

Cause

This message may occur when the following conditions are met:

  • You are attempting to reactivate the license on a vCMP guest rather than a vCMP Host.
  • You failed to reactivate the system prior to performing an upgrade.
  • You are attempting to activate a new device that is running an incompatible version of software.


Recommended Actions

  • Make sure to reactivate license prior to performing an upgrade. For more info, refer to K7727: License activation may be required before a software upgrade for the BIG-IP or Enterprise Manager system
  • Reactivate the license from the vCMP Host and not the vCMP Guest.

    Impact of procedure: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. When licensing redundant BIG-IP systems, F5 recommends that you activate the license on your BIG-IP devices while they are in standby mode.
  1. Log in to the Configuration utility using an account with the administrator role.
    Note: If this is a new BIG-IP system, open a web browser on a workstation attached to the network on which you configured the management port and type the following URL in the browser: https://<IP address>/. <IP_address> is the address that you configured for the management port.
     
  2. Select Activate.
    Note: If the BIG-IP system is already licensed, navigate to System > License and select Re-activate. 
     
  3. Select either Automatic or Manual as the activation method and click Next.
    Note: If your system does not have Internet access to the F5 license server, you must select Manual and follow the steps below.
              If you choose Automatic, this will generate the End-user License Agreement. Read and accept it and sk
      ip the remaining steps below.
       
    • Copy the dossier and connect to the F5 Product Licensing page at secure.f5.com.
    • On the F5 Licensing Tools page, select Activate F5 product registration key for BIG-IP 9.x and later.
    • Paste the dossier into the Enter Your Dossier box, and then select Next.

      The F5 Product Licensing page produces your license.

    • Copy the license and paste it into the License box in the Configuration utility.
    • Select Next and wait for configuration to reload.
       

    Additional Information
    License reactivation can also be done from the command line, refer to: K2595: Activating and installing a license file from the command line.
