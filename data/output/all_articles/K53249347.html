Description

  • How to do IP reputation update via BIG-IQ

Environment

  • BIG-IQ CM
  • IP Intelligence

Cause

  • IP reputation updates cannot be controlled by the BIG-IQ
  • Each IPI licensed BIG-IP system connects to an IP intelligence database, download the contents, and automatically keep the database up to date.
  • From BIG-IQ device you can configure blacklist, whitelist, feed lists and policies to check traffic against an IP intelligence database.
    For more on blacklists, whitelists, feed lists and policies, visit: Manual Chapter : Managing IP Intelligence Settings
