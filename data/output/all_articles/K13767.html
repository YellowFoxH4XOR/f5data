Known Issue

Description

The ephemeral FTP listener of the FTP data connection may be unbound from its socket.

This issue occurs when the following condition is met:

  • An ephemeral FTP listener in the LISTEN state receives a RESET before receiving a SYN to open the new data connection.

This issue may occur if an ephemeral listener is created for an FTP DATA connection, and the listener uses a previously-used TCP port for which a reset from a previous connection arrives before the initial SYN for the new connection. 

Impact

FTP data connections fail to connect.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • FTP connections fail to connect.
