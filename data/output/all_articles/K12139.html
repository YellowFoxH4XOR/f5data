Issue

This article applies to Server SSL certificate support of the SHA-2 hashing algorithm. For information about Client SSL certificate support, refer to the following article:

  • K16324: The BIG-IP Client SSL profile now accepts client SSL certificates signed using the SHA-2 hashing algorithm

Beginning in BIG-IP 10.1.0, the Client SSL profiles support Server SSL certificates signed using the SHA-2 hashing (SHA-224, SHA-256, SHA-384, and SHA-512) algorithm.

Note: For information about SSL ciphers supported in BIG-IP 10.x, refer to K11444: SSL ciphers supported on BIG-IP platforms (10.x).

Note: Management traffic, such as the Configuration utility, does not support SHA-2 signed SSL certificates.
