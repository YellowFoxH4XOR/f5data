K000132432: [F5OS-A] Radius authentication: Wrong IP in NAS-IP-Address Field

Type
Support Solution
Published
2023-02-07
Updated
2023-02-07
Applies to
  • F5OS
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000132432

Description

With Radius Authentication for rSeries, rSeries appliance send NAS-IP address with internal IP

     User-Name Attribute (1), length: 7, Value: user1

     User-Password Attribute (2), length: 18, Value: 

     NAS-IP-Address Attribute (4), length: 6, Value: 100.65.60.2 <<--------- [KO]

     NAS-Identifier Attribute (32), length: 15, Value: password-auth

     NAS-Port Attribute (5), length: 6, Value: 699

     NAS-Port-Type Attribute (61), length: 6, Value: Virtual

     Service-Type Attribute (6), length: 6, Value: Authenticate Only

 

Environment

  • F5OS-A
  • rSeries
  • v1.x

 

Cause

  • Bug ID 1205345

 

Recommended Actions

Avoid to use NAS-IP for authentication, where it is possible.

The expected NAD-IP should be able to set by the RADIUS server side, so please configure your RADIUS server to use IP address rSeries sends, if it can.

NOTE: NAS-IP can NOT be changed by manually on rSeries.

 

Additional Information

  • K000093127: [F5OS-C] Radius NAD-IP-Address is taking from NAS-IP, and the NAS-IP is set IPv6 automatically.
