Known Issue

The BIG-IP system may fail to initiate an IPsec tunnel after a failover event.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP systems are in an active-standby configuration.
  • You have configured an IPsec tunnel between your BIG-IP system and remote devices.
  • Your active BIG-IP system fails over to the standby device and then becomes the active device again within the IKEv1 phase 2 lifetime.

After the failover events occur, your BIG-IP system may fail to remove the IKEv1 phase 2 security association parameters for the IPsec connection.

Impact

The BIG-IP system fails to initiate the IPsec tunnel and network connectivity between the private networks fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Network connectivity between the private networks fails.

Workaround

To work around this issue, you can configure the BIG-IP system to delete the IPsec security associations following a failover event. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Use a text editor to edit the /config/failover/active file.
  3. Add the following lines to the end of the file:

    logger -p local0.notice "Employ ID636744 workaround. Purge IPsec phase2 SAs."
    tmsh delete net ipsec ipsec-sa

  4. Save the changes and exit the file.
