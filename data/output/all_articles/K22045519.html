Description

When attempting to access https://<BIG-IP mgmt IP>/mgmt/tm via the Configuration Utility (WebUI) the logon window doesn't appear and the page reports "unauthorized". 

Environment

  • Attempting to run an API call to /mgmt/tm via the Big-IP Configuration Utility
  • Connecting to the same BIG-IP at https://<BIG-IP mgmt IP>/xui is successful

Cause

Basic Authentication is disabled on this BIG-IP. This db variable is enabled by default.

sys db httpd.basic_auth {
    default-value "enable"
    scf-config "true"
    value "enable"
    value-range "disable enable"
}

Recommended Actions

Enable basic authentication on the BIG-IP.

Note: This process temporarily interrupts access to the Configuration Utility. It isn't traffic impacting, however, F5 recommends performing changes during maintenance windows.

From the command line:
  1. Check the current value for basic authentication 
getdb httpd.basic_auth
  1. Enable basic authentication
setdb httpd.basic_auth enable
  1. Restart the web service
tmsh restart service httpd
