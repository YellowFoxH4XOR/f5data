K000150833: How to create IP Prefix Sets with API Calls (cURL and Postman)

Description

  • You want to use Postman to make API Calls in order to create IP Prefix Sets in your F5 Distributed Cloud tenant/namespace.

Environment

  • F5 Distributed Cloud Services API

  • Postman / cURL

Answer/Recommended Actions

  1. First, you need to have a valid API Token with the appropriate role and correct namespace.
  2. Go to the Authorization tab and enter your API Token as seen below where;
    - Key: Authorization
    - Value: APIToken $token
    - Add to: Header 
  3. Next, make sure that you are making this API Call to the correct API Endpoint (your console, tenant, namespace). Based on the API documentation, the API Endpoint should look like this: https://your.console.ves.volterra.io/api/config/namespaces/{your.namespace}/ip_prefix_sets

  4. Now you need the JSON body, which will contain information about the array and objects that you want to create (IP Prefix Sets). You can retrieve a sample JSON request body from the API documentation.
  5. Replace the fields as necessary, including the name of your IP Prefix Set, your namespace, and the list of IP subnets in the form of "Key": "Value" pairs such as "ipv4_prefix": "198.252.138.0/24".
     
    {
    "metadata": {
        "name": "ddos-black-list",  # <---- name your IP Prefix Set
        "namespace": "system".      # <---- indicate your namespace
    },
    "spec": {
        "ipv4_prefixes": [
            {
                "ipv4_prefix": "198.252.138.0/24" #IP Prefixes with subnet
            },
            {
                "ipv4_prefix": "167.127.95.0/24"  #IP Prefixes with subnet
            },
            {
                "ipv4_prefix": "167.127.191.0/24" #IP Prefixes with subnet
            }
        ]
    }
}
  6. Now you are ready to send a POST request to create the IP Prefix Set.
  7. You can export the full cURL command from the Postman request above by following steps in this article: How to get the cURL command equivalent for a Postman API call and viceversa
    1. or you can use the sample cURL command template below. This can be imported into Postman too, by following the steps in the article above.
    2. You may also execute the cURL in your CLI or any other application of your choice.
      curl -X POST --location 'https://your.console.ves.volterra.io/api/config/namespaces/your-namespace/ip_prefix_sets' \
--header 'Content-Type: application/json' \
--header 'Authorization: APIToken $Your_API_Token' \
--data '{
  "metadata": {
    "annotations": {},
    "description": "A description of your IP Prefix Set",
    "disable": true,
    "labels": {},
    "name": "The name of your IP Prefix Set",
    "namespace": "your-namespace"
  },
  "spec": {
    "ipv4_prefixes": [
      {
        "ipv4_prefix": "x.x.x.x/32",
        "ipv4_prefix": "x.x.x.x/32"
      }
    ]
  }
}'

Additional Information

  • If you encounter this error: API Group could not be determined for Method: POST Path: /api/config/namespaces/your-namespace/ip_prefix_sets/
    • It is because there is an issue with your API Token. You may have not assigned it to the correct namespace, and you may need to assign it an admin role.
  • Updating the IP Prefix Set in the future will require using the PUT Method instead of POST, where you will need to include all the desired IP prefixes as the entire object will be replaced with a new list of IP Prefixes.
    • Replace IP Prefix Set
  • Other operations include List, Get and Delete IP Prefix Objects. These are straightforward and self-explanatory once you understand how to create one. Refer to our API documentation for examples of these operations.
