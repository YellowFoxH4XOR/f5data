K000162390: After upgrading BIG-IP to 17.5.1.6 last statistics collected in BIG-IQ shows as January 1, 1970

Source
https://my.f5.com/manage/s/article/K000162390

Description

After upgrading BIG-IP to 17.5.1.6, BIG-IQ stopped receiving statistics and security logs. BIG-IQ displayed a last statistics collection date of January 1, 1970 for the upgraded BIG-IPs.

Environment

  • BIG-IQ - 8.4.1
  • Managed BIG-IP - 17.5.1.6

Cause

In BIG-IP systemauth.primaryadminuser was not local default "admin" user.

Answer/Recommended Actions

Below changes in BIG-IP:

# tmsh modify sys db systemauth.primaryadminuser value admin
# tmsh save sys config
# reboot

None
