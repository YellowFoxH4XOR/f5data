Description

Tenants running in VELOS chassis will still display chassis-type as "viprion" for the output of "tmsh list cm device" command.

For example:

[root@velostenant01:Active:Standalone] config # tmsh list cm device
cm device /Common/velostenant01.local {
<snip>
  chassis-id chs000000s
    chassis-type viprion <------
<snip>

Environment

  • VELOS
  • F5OS-C
  • Tenants

Cause

ID2227509

Answer/Recommended Actions

This is a cosmetic defect.
