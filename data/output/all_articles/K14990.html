Known Issue

External datagroups may not be properly synchronized across members of a device group.

This issue occurs when all of the following conditions are met:

  • You have one or more BIG-IP system with the configuration synchronized in a device group.
  • An external datagroup on one BIG-IP system is updated and synchronized to the other BIG-IP system in the device group.

Impact

iRules that rely on up-to-date data within a device group may produce inaccurate results.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H447282 on the Diagnostics > Identified > Medium screen.
  • iRules running on some devices in a device group may not have access to up-to-date data within the datagroup.
  • The datagroup file is synchronized across BIG-IP systems in the device group, but TMM does not load the updated data.

Workaround

To work around this issue, you can restart the TMM process on the system with the non-updated datagroup. To do so, perform the following procedure:

Impact of workaround: The BIG-IP system temporarily goes offline and stops passing traffic. This procedure should be performed only on a standby system or during a maintenance window.

  1. Log in to the BIG-IP command line interface as the root user.
  2. Type the following command:

    bigstart restart tmm
