Topic

You should consider using this procedure under the following condition:

  • You want users of the access profile to be able to change passwords with the BIG-IP APM access profile logon page.

Description

The following procedure enables a check box on the BIG-IP APM access profile logon page that the system presents to users when authenticating. When users select the Change Password check box on the logon page, they are required to supply their credentials to authenticate. After the system authenticates users, it presents them with a BIG-IP APM webpage that allows them to change their Active Directory password.

Active Directory users' password changes rely on the users' passwords for authentication and authorization. This is a function of Active Directory and is not a configured setting of the BIG-IP APM system.

To change their password, users must enter their old password and their newly created password. The old password must be their current Active Directory password. When the BIG-IP APM system runs the password change, it invokes the Kerberos change password API. The BIG-IP APM system does not call the Active Directory set-password function, which requires an advanced privileged Active Directory user account (domain admin or user admin).

If the users' account password change interval time has expired, they are still required to update their password. In this scenario, authentication relies on the last password set. The BIG-IP APM AAA configuration does not require Active Directory privileges beyond read-only access. For security purposes, F5 recommends that you create a low-privilege Active Directory service account to be used by the BIG-IP APM configuration to run read-only LDAP queries. F5 discourages you from storing high-privilege account credentials for Active Directory on the BIG-IP APM system.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must configure the access profile to use an AAA profile that authenticates users with Active Directory.
  • You must have administrative access to the BIG-IP APM system.

Procedures

Enable the access policy logon page to present the Change Password option

To enable the display of the Change Password check box for an access policy logon page, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Access > Profiles / Policies > Access Profiles (Per-Session Policies).
  3. For the affected access policy name, in the Per-Session Policy column, select Edit to open the Visual Policy Editor (VPE).
  4. Locate the Logon Page policy item and select it to edit it.
  5. In the pop-up window, on the Properties tab, under Logon Page Agent, locate row 3  and for Type, select checkbox.
  6. For Post Variable Name, enter following text:

    change_password

  7. For Session Variable Name, enter the following text:

    change_password

  8. Select Save.
  9. In the upper-left corner of the VPE, select Apply Access Policy.
  10. Select Close to close the VPE.
