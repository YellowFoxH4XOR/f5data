K000092519: Unable to add fqdn in the Shared Objects ›› Address Lists

  • BIG-IP AFM: 17.5.1
Source

Description
The address list defined as "net address-list" does not support FQDN addresses. It only supports IPv4 and IPv6 addresses as members of the address list.

Environment

  • Network address-list for use as destination address/virtual-address for a virtual server
  • Network address-list for use as client source address for a virtual server

Cause
Functioning as designed.

Recommended Actions
None 

Additional Information
Supporting only IPv4 and IPv6 addresses for the NET address-list object is by design. Refer to the manual for more details and examples.
