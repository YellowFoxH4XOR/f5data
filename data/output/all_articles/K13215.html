Topic

Apple released Mac OS X version 10.7 (Lion) on July 20, 2011. The Samba technology was removed from the Mac OS X 10.7 release, which uses a new SMB client software. Support for Mac OS X version 10.7 was introduced in ARX 6.0.0. For information refer to K10909: F5 Data Solutions Compatibility Matrix.

Previous ARX versions do not support support Mac OS X version 10.7 as a client; however, some features may function through the ARX system.

Supplemental Information

  • K13216: Mac OS X version 10.7 (Lion) clients may be unable to view files and/or directories using Finder
