Description
This article explains how to enable debug and trace logging in F5 Application Services 3 Extension (AS3). Enabling these options helps collect detailed information about declaration processing, which is useful for troubleshooting and when escalating issues to F5 Support.

 

Environment
BIG-IP (LTM, or other modules supported by AS3)
AS3 (v3.x and later)

 

Details/Explanation
AS3 supports enhanced logging and trace capabilities through the Controls class in your declaration. By setting "logLevel": "debug", "trace": true, and optionally "traceResponse": true, you can collect verbose logs and trace files that capture the desired, current, and diff states of your declaration, as well as the CLI script generated by AS3.

 

For full details on the Controls class and its parameters, see the AS3 Controls schema reference.

 

How to enable debug and trace logging:

Add a Controls section to your AS3 declaration, for example:

{
    "class": "AS3",
    "action": "deploy",
    "persist": true,
    "declaration": {
        "class": "ADC",
        "schemaVersion": "3.0.0",
        "controls": {
            "class": "Controls",
            "logLevel": "debug",
            "trace": true,
            "traceResponse": true
        },
        "SampleTenant": {
            "class": "Tenant",
            "SampleApp": {
                "class": "Application",
                "service": {
                    "class": "Service_HTTP",
                    "virtualAddresses": [
                        "192.0.2.1"
                    ],
                    "pool": "web_pool"
                },
                "web_pool": {
                    "class": "Pool",
                    "members": [
                        {
                            "servicePort": 80,
                            "serverAddresses": [
                                "192.0.2.10",
                                "192.0.2.20"
                            ]
                        }
                    ]
                }
            }
        }
    }
}

 

  • "logLevel": "debug" enables verbose logging.
  • "trace": true" writes trace files to disk.
  • "traceResponse": true" includes trace output in the API response.


After submitting the declaration:

AS3 will generate trace files in the /tmp/ directory on the BIG-IP system. The files are named after the tenant and include:


/tmp/SampleTenant _desired.json
/tmp/SampleTenant _current.json
/tmp/SampleTenant _diff.json
/tmp/SampleTenant _script.cli

 

If "traceResponse": true is set, the API response will include trace output directly in the response body.
