Known Issue

A Secure Sockets Layer (SSL) handshake using the DES-CBC-SHA cipher suite and SSLv2 protocol will fail.

This issue occurs when all of the following conditions are met:

  • The client or server SSL profile is configured to use the DES-CBC-SHA cipher suite. This cipher suite is listed in COMPAT stack.
  • The SSL handshake occurs using the DES-CBC-SHA cipher suite and SSLv2 protocol.

DES-CBC-SHA is supported by SSLv3 and should not be used for SSLv2 handshake.

Impact

The SSL handshake fails with no error message logged.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The SSL handshake fails when you use the DES-CBC-SHA cipher with SSLv2, and the system does not log an error message.
