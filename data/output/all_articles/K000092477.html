Description

The GUI of the standby controller is not working, and may have similar to the below messages:

Server Error(s)

An internal error occurred. Please try again later. If the problem persists, contact technical support for assistance.

 Environment

  • F5OS-C
  • Velos
  • any version
  • GUI on Standby Controller

 Cause

By design. Standby Controller GUI is not supported for use including viewing configuration. 

 

 Recommended Actions

Use Floating IP to access to GUI for all purposes. 

 

 Additional Information

None
