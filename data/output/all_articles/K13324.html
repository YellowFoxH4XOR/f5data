K13324: The gtm_add script no longer supports the SSH protocol as a fallback option to synchronize BIG-IP GTM configuration files

Type
Knowledge
Published
2012-01-16
Updated

Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP GTM: 11.1.0, 11.0.0
Source

Issue

Old Behavior

In BIG-IP versions prior to 11.0.0, the gtm_add script uses the SSH protocol to exchange SSL certificates and as a fallback option to iQuery when synchronizing BIG-IP GTM configuration files.

The gtm_add script is an interactive script used to authenticate and integrate a new BIG-IP GTM system into an existing synchronization group that is defined on one or more remote BIG-IP GTM systems.

New Behavior

Beginning in BIG-IP GTM 11.0.0, the gtm_add script continues to use SSH to exchange SSL certificates; however, the script no longer supports the SSH protocol as a fallback option to synchronize BIG-IP GTM configuration files. The script uses iQuery over TCP port 4353 to synchronize the configuration files.

F5 Product Development tracked this change as ID 344497.

Impact

The gtm_add script requires both SSH and iQuery to integrate a new BIG-IP GTM system into a synchronization group.

Recommended Actions

Make sure that TCP ports 22 and 4353 are open between the BIG-IP GTM systems prior to running the gtm_add script.
