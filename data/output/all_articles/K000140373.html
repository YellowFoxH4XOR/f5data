Description

Environment

  • VELOS
  • F5OS-C
  • System Controllers

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 1556173.

Recommended Actions

  • Upgrade to a F5OS-C version with the fix of ID 1556173.
  • Perform a system controller failover and reboot the controller that was previously active. Support confirmed the issue will go away after a system controller reboot, while it may return later.
  • Increase failover.nettimeoutsec from default 3 seconds. Refer to K7249: Configuring the network failover timer for instruction.
