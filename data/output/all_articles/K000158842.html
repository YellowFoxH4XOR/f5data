K000158842: Can the XC Default Error Page feature work in CE environments?

2025-12-18

Applies to

Source

Description

You want to configure the F5 XC Default Error Page on a HTTP LB served from a Customer Edge (CE) Site, but the expected default page is not presented.

Environment

  • Customer Edge
  • HTTP Load Balancer

Answer

XC Default Error Page is not supported on CEs.

  • The default error page will be displayed only for the error response code (>= 400) generated internally in the HTTP Load Balancers.
  • The default error page will be displayed only in REs and not in CEs.
  • The default error page will be displayed for an HTTP 421 (Misdirected Request) error, regardless of whether the LB is advertised on the RE or CE. Please note that configuring a custom error page for HTTP 421 is currently not supported.
