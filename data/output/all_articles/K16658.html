Known Issue

Subscriber flows may still be forwarded when matching an enforcement policy rule with the gate status disabled.

This issue occurs when all of the following conditions are met:

  • You have created an enforcement policy and added a rule that has gate status disabled.
  • You have disabled classification on the virtual server associated with the enforcement policy.

Impact

Subscriber flows that match the enforcement policy will be forwarded.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Subscriber flows that should be dropped are being forwarded to an endpoint.

Workaround

Ensure that the Classification option is not disabled on a virtual server that is associated with enforcement policies that have the gate status disabled.
