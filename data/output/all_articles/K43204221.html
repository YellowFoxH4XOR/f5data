K43204221: BIG-IP APM Windows Protected Workspace is deprecated

Applies to

Source

Topic

Beginning in BIG-IP APM 15.1.0.1, the Windows Protected Workspace client-side feature is deprecated. F5 Product Development assigned ID 911749 to this. 

Description

Windows Protected Workspace is a client-side feature that you configure using the BIG-IP APM VPE to create a temporary protected Windows user workspace for an APM session. The Protected Workspace control deletes the temporary workspace and all of the folder contents at the end of the session.

This feature works with Windows XP and Windows 7 but is not supported on Windows 10. Because Windows XP and Windows 7 are no longer supported, the Windows Protected Workspace is also no longer supported in BIG-IP APM.

Recommendation

Do not use the Windows Protected Workspace feature in your BIG-IP APM access policy.
