K84190846: Log all requests not logging any events

Type
Support Solution
Published
2020-12-07
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.1.2
Source
https://my.f5.com/manage/s/article/K84190846

Description

Virtual server has a security logging profile configured and working to log all requests to a remote server.
Default security logging profile "Log all requests" is added to the security logging profiles configured on the virtual server but requests (events) are not logged locally.

Environment

  • BIG-IP ASM
  • virtual server with a Security policy configured
  • above virtual server is configured with a non default Security logging profile configured
  • above virtual server has the default logging profile  "Log all requests" is added to the security logging profiles configured on the virtual server

Cause
unknown

Recommended Actions

  1. create a custom security logging profile that logs local for all requests
  2. configure this custom security logging profile instead of the default security logging profile "Log all requests"
