Known Issue

The BIG-IP system incorrectly allows you to use certain special characters in file object names. For example, the system allows you to import a Secure Sockets Layer (SSL) certificate (or other file object) containing characters such as white-space, ASCII control characters, or non-ASCII characters.

Impact

  • File objects containing special characters may not be properly included in UCS archives.
  • Upgrades may fail if the file object is referenced in the BIG-IP configuration file (bigip.conf), but missing from the filestore after upgrade.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • File objects containing special characters may not be properly included in UCS archives.
  • The file object may be referenced in the bigip.conf file, but missing from the filestore.

Workaround

To work around this issue, you can make sure you create object names of fewer than 63 characters (including the partition name), that contain no spaces or special characters other than an underscore ( _ ) or a hyphen ( - ).
