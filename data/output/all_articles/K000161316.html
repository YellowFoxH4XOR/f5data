K000161316: AS3 Declarations Fail with HTTP 403 "Direct Access to /mgmt/tm/util/ Is Not Permitted" After Upgrade to BIG-IP with APM Provisioned

Type
Support Solution
Published
2026-05-18
Updated
2026-05-28
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.3, 17.5.1
  • BIG-IP LTM: 17.1.3, 17.5.1
Source
https://my.f5.com/manage/s/article/K000161316

Description

  • AS3 declarations that previously succeeded on earlier BIG-IP versions begin failing after upgrading to BIG-IP 17.5.1.6 or 17.1.3.2 when Access Policy Manager (APM) module is provisioned. AS3 POST requests return HTTP 403 errors with the message:
failure querying config for tenant <tenant_name> (POST .../mgmt/tm/util/bash execute bash command response=403 body={"code":403,"message":"Direct access to /mgmt/tm/util/ is not permitted.","kind":":resterrorresponse"})
  • The overall AS3 response returns HTTP 422 with a code: 400 result per tenant.

Environment

  • Product: BIG-IP LTM
  • Version: 17.5.1.6, 17.1.3.2
  • AS3 version: 3.56.0 and earlier
  • Module: APM provisioned
  • Condition: Issue occurs only when APM is provisioned; AS3 declarations succeed when APM is de-provisioned

Cause

  • When APM is provisioned on BIG-IP 17.5.1.6 or 17.1.3.2, a security restriction is enforced that blocks direct REST API access to the /mgmt/tm/util/ endpoint. AS3 version 3.56.0 and earlier internally relies on POST calls to /mgmt/tm/util/bash to query device configuration during declaration processing. With APM provisioned, these internal calls are rejected with HTTP 403, causing all AS3 declarations to fail. AS3 version 3.57.0 contains a fix that addresses this blocked REST access.

Answer/Recommended Actions

 

  1.  Upgrade AS3 to version 3.57.0 or later, which contains a fix for the blocked /mgmt/tm/util REST endpoint when APM is provisioned on BIG-IP 17.5.1.6 or 17.1.3.2
  2. Download the AS3 3.57.0 RPM from F5 Downloads once the GA release is available.
  3. Install the RPM on the BIG-IP device following standard AS3 installation procedures. For information about installing AS3 on the BIG-IP device, refer to Downloading and installing the BIG-IP AS3 package on F5 CloudDocs for detailed instructions.
