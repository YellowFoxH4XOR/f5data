Description

A forwarding virtual server with a FastL4 profile applied stops working after upgrading to the following BIG-IP software versions:
  • 14.1.4.4 and higher
  • 15.1.4.1 and higher
  • 16.1.0 and higher

Environment

The issue occurs under the following conditions:

  • A forwarding virtual server with a FastL4 profile
  • FastL4 profile has Loose Init option enabled
  • Traffic passing through the virtual server has an nPath/async routing configuration

Cause

A bug fix was released to address an issue with the FastL4 profile that may cause it to consume more resources with certain types of traffic. However, the fix for this issue resulted in nPath/async traffic to stop working when going through a forwarding virtual server with a FastL4 profile. For more information, please refer to K50343028: BIG-IP FastL4 profile vulnerability CVE-2022-23029.

Recommended Actions

To resolve the issue with nPath/async routing, please enable the Loose Close option in the FastL4 profile.
