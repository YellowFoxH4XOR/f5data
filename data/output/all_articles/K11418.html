Known Issue

This is the result of a known issue. The BIG-IP WOM shutdown script, referred to as the WOC plug-in shutdown script, executes the qkview-lite script and generates a tech.out file to the /var/log directory even when the BIG-IP WOM is not provisioned on the BIG-IP system. The BIG-IP system executes the shutdown script when the system is restarted or when the user executes the bigstart restart command.

Eventually, the tech.out files may use up a significant amount of disk space in the /var/log volume.

F5 Product Development tracked this issue as CR127364 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WOM release notes.

Additionally, this issue was fixed in Hotfix-BIGIP-10.0.1-402.7-HF4 issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing version 10.x hotfixes on systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).

Workaround

To delete extraneous tech.out files, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Change directories to the /var/log directory by typing the following command:

    cd /var/log
  3. To determine whether the /var/log volume contains extraneous wocplugin tech.out files, type the following command:

    ls -las /var/log/ |grep wocplugin

    The example output indicates that the /var/log directory contains three extraneous wocplugin tech.out files:

    172 -rw-r--r-- 1 root root 165101 Mar 8 06:50 wocplugin.3400r65b.askf5lab.net.20091204125925.tech.out
    172 -rw-r--r-- 1 root root 166383 Mar 8 06:50 wocplugin.3400r65b.askf5lab.net.20091204131522.tech.out
    192 -rw-r--r-- 1 root root 188132 Mar 8 06:50 wocplugin.3400r65b.askf5lab.net.20091204132944.tech.out
  4. To remove the wocplugin tech.out files, type the following command:

    rm -rf wocplugin.*
