Topic

Beginning in BIG-IP ASM 10.0.0, you can configure sensitive parameters in the following two ways:

Defining a parameter from the Policy » Parameters » Sensitive Parameters page

When you define a parameter from the Policy » Parameters » Sensitive Parameters page, you create a global sensitive parameter. A global sensitive parameter supersedes any URL level parameters with the same name. For example, if a global sensitive parameter and a URL level parameter that is not marked as sensitive share the same name, the parameter is always considered sensitive, regardless of the URL.

Configuring a parameter as sensitive from the Policy » Parameters » Parameters List page

When you configure a parameter as sensitive from the Policy » Parameters » Parameters List page:

  • If the Parameter Level is set to Global Parameter, the BIG-IP ASM will always treat that parameter as sensitive, regardless of the URL. This is the same as defining a global sensitive parameter from the Sensitive Parameters page.
  • If the Parameter Level is set to URL Parameter, the BIG-IP ASM will treat that parameter as sensitive only when it is associated to a specific URL.
