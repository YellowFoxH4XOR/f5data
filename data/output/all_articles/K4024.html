Known Issue

This is most likely the result of a known issue. The Add Proxy pages do not work correctly with the Netscape Navigator browser. When you try to add a proxy, you may receive a blank page or the next page arrow button may be replaced with the word null when you click it.

This problem occurs with Netscape versions 4.78 through 8.0 beta, but may also occur with other versions as well.

F5 Networks Product Development tracked this issue as CR37281 and CR41923.

Workaround

To work around this problem, use the command line or another web browser to create proxies.
