Description

Attack signatures that are Staged will not be logged with ArcSight remote logger.

Environment

  • BIG-IP ASM
  • ArcSight configured as remote logger

Cause

This is the intended design.

Recommended Actions

There is no workaround that utilizes ArcSight.

It is possible to log staged signatures remotely with an alternative method such as a CSV file.

None
