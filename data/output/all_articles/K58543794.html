Description

To view or extract the contents of an encrypted user configuration set (UCS) archive file outside a BIG-IP system, you must first decrypt the UCS archive file into a new decrypted archive file by performing the procedure described in this article.

Environment

  • BIG-IP
  • UCS
  • Passphrase

Cause
N/A

Recommended Actions

  1. Log in to tmsh by typing the following command
    • tmsh
  2.  Create UCS file using a password
    • save /sys config file <UCS file name> passphrase <passphrase>
  3.  Exit tmsh by typing the following command:
    •   quit
  4. Use one of the procedures listed in article below to transfer the UCS file to your local machine.
    • K175: Transferring files to or from an F5 system
  5. Install PGP from the following site:
    • https://gnupg.org
    • Note: gnupg.org site is a third party tool which is not maintained by F5.  The content here can change at any time.
  6. Open a cmd window or a bash terminal and make sure GPG has been included in your PATH:
    Example:
    C:\> gpg --version
    gpg (GnuPG) 2.2.19
    libgcrypt 1.8.5
    Copyright (C) 2019 Free Software Foundation, Inc.
    License GPLv3+: GNU GPL version 3 or later <https://gnu.org/licenses/gpl.html>
    This is free software: you are free to change and redistribute it.
    There is NO WARRANTY, to the extent permitted by law.
    Note: the configuration in your environment is closely tied to your system, please visit your vendor support site if you run into any issue to perform this step.
  7. Move to the directory where the encrypted file is located by typing the following command:
    Example:
    • C:\> cd Users\f5user\ExamplePath
    • C:\Users\f5user\ExamplePath>
  8.  Decrypt the UCS file by typing the following command, a passphrase will be asked:
    Example:
    •  C:\Users\f5user\ExamplePath> gpg --output <DecryptedFileName> --decrypt <UCS file name>
  9. The decrypted file can be inspected using the following command:
    Example:
    • C:\Users\f5user\ExamplePath> less <DecryptedFileName>
