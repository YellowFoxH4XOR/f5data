Issue

Error Message

notice alertd[<PID>]: 01100043:5: logcheck Notice: <message>

In this error message, note the following:

  • <PID> is the process ID for the alertd process
  • <message> is an informational message regarding the log rotation process

For example:

notice alertd[6464]: 01100043:5: logcheck Notice: Receive alert msg from diskmonitor 0

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The alertd process receives a message from the disk monitoring subsystem, which leads to a check for log rotation.
  • The logrotate utility runs to compress log files.
  • The alertd process is disconnected from the mcpd process due to rebooting or shutting down the BIG-IP system.

Impact

There is no impact. This message is normal and does not indicate an error condition.

Recommended Actions

None
