Topic

Summary

The ARX system will not respond to UDP traceroute requests.

Description

Traceroute is a network diagnostic tool that displays the path and measures transit delays of packets across a network. By default, traceroute uses user datagram protocol (UDP) datagrams with destination port numbers from 33434 to 33534. For security purposes, the port configuration on the ARX system will, by default, reject packets outside of the ports that are required for ARX functionality. As a result, tools such as traceroute may fail.

Recommendations

If a traceroute is necessary in your troubleshooting steps, F5 recommends that you initiate the traceroute from the ARX system.

Note: The ARX system CLI expect traceroute command is implemented with limited functionality.
