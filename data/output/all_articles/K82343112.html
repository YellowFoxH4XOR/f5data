Description

A Network Access resource and a Network Access Webtop are assigned using the Advanced Resource Assign action and the Network Access session closed.
APM logs (/var/log/apm): "VPN Cleanup: failed to release IPv4 ERR_ARG"

Environment

  • APM
  • Network Access
  • Webtop
  • VPN disconnected

Cause

This occurs when a Network Access session and an APM session are closed simultaneously.

Recommended Actions

No actions necessary.  These logs are logged at the Notice level and are just Informational.

Additional Information

None
