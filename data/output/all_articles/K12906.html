K12906: System load data may be reset when upgrading from FirePass version 6.0.1 and earlier

Source

Topic

When upgrading to FirePass version 6.0.2 or later, the upgrade process resets the system load historical information. Beginning with FirePass version 6.0.2, the database that stores load statistics is no longer compatible with previous versions. As a result, the system loses historical load data when you upgrade your FirePass software.

FirePass maintains historical system load information to allow you to display system load statistics for a period of up to 1 month. The FirePass controller stores this data in a database, and you can access the data from the Device Management : Monitoring : System Load screen.
