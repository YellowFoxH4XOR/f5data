Description
You want to know where to find the UCS Backup of a manage BIG-IP in BIG-IQ

Environment

  • BIG-IQ
  • managed BIG-IP
  • Backup Management

Cause
None

Recommended Actions

  1. Login to command line
  2. Run the command below:
    find / -name "*.ucs"
    Example:
    [root@CM-BIG-IQ:Active:Standalone] config # find / -name "*.ucs"
    find: '/proc/32080': No such file or directory
    /usr/local/www/guiserverroot/usr/share/monitors/.ucs
    /usr/share/monitors/.ucs
    /var/local/ucs/config.ucs
    /shared/ucs_backups/big-ip_backup_BIG-IP-15.five.lab_20220815123521.ucs
  3. Now you know that managed BIG-IP UCS backup is located in /shared/ucs_backups/
  4. You can use file transfer software to transfer the file to your local drive

Additional Information
You can also download the UCS backup from the GUI under DEVICES > BACKUP & RESTORE > Backup Files
