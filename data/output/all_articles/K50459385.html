Topic

The BIG-IP hybrid SSL acceleration feature enables the system to split SSL offload between the hardware accelerator and the CPU.

Description

Hardware SSL acceleration, which is used by BIG-IP platforms equipped with hardware SSL accelerators, provides the ability to process SSL transactions via a dedicated hardware chipset and resource. To further advance SSL acceleration efficiency, BIG-IP 15.1.0 introduced the hybrid SSL acceleration feature to provide software-based SSL acceleration, which solely relies on CPU, as part of SSL offload resources. This is useful for BIG-IP systems where the CPU is underused, and you can improve SSL offload performance by assigning an additional CPU resource to share the SSL workload.

To configure hybrid SSL acceleration, you can set the fixed-ratio variable. The value can range from 0 to 1000:

  • 1000 indicates full hardware acceleration with no CPU acceleration.
  • 0 indicates no hardware acceleration with full CPU acceleration.

Note: The default value of the fixed-ratio variable is 1000.

To enable the hybrid SSL acceleration feature, or customize the current SSL acceleration strategy, perform one of the following procedures:

  • Configuring hybrid SSL acceleration using the Configuration utility
  • Configuring hybrid SSL acceleration using tmsh

Configuring hybrid SSL acceleration using the Configuration utility

Impact of procedure: The impact depends on the specific environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.

  1. Log in to the Configuration utility.
  2. Go to System > Crypto Offloading > Acceleration Strategy.
  3. For Fixed Ratio, enter the ratio value.

    For example, to use the hardware accelerator to process 80 percent of SSL traffic, enter 800.

  4. Select Update.

Configuring hybrid SSL acceleration using tmsh

Impact of procedure: The impact depends on the specific environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.

  1. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  2. To modify the hardware acceleration ratio, use the following command syntax:

    modify /sys crypto acceleration-strategy fixed-ratio <ratio_value>

    For example, to use the hardware accelerator to process 80 percent of SSL traffic, enter the following command:

    modify /sys crypto acceleration-strategy fixed-ratio 800

  3. To verify the configured ratio value, enter the following command:

    list /sys crypto acceleration-strategy fixed-ratio

  4. To save the configuration, enter the following command:

    save /sys config

Recommendations

When planning the hybrid SSL acceleration feature, you should consider the following factors:

  • The ideal hardware-to-software acceleration ratio is highly dependent on the specific operation environment and should be determined case-by-case. If you set the acceleration strategy ratio value too low, it may affect the overall device performance when too much of the CPU resource is occupied by crypto operations. F5 recommends that you monitor the system performance closely, especially CPU usage, after changing the acceleration strategy ratio value.
  • Older, non-iSeries platforms that use the Nitrox crypto accelerator already use the CPU for crypto operations because the Nitrox accelerators support RSA only. Therefore, the CPU performs the Elliptic Curve Diffie-Hellman (ECDH) operations.
  • BIG-IP Virtual Edition (VE) systems do not have hardware SSL acceleration. The BIG-IP VE system displays the SSL acceleration strategy setting; however, the ratio setting is ignored, and the system processes all crypto operations by CPU.
  • The SSL acceleration strategy setting is global to the appliance. If the device is Virtual Clustered Multiprocessing (vCMP) capable, then the vCMP guests will inherit the setting.
  • To review the current SSL acceleration distribution:
    • In the Configuration utility, go to System > Crypto Offloading > Acceleration Strategy > Statistics.
    • From the BIG-IP command line, use the tmsh show sys crypto acceleration-strategy command.

      For example, the following output shows seven of the total 15 ECDH-based SSL transactions are processed by CPU instead of the hardware accelerator:
