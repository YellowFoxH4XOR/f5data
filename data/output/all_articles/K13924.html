Known Issue

The advanced customization preview window may not display changes made to the interface elements.

This issue occurs when the following condition is met:

  • You attempt to view changes made in the advanced customization preview window.

Impact

Customizations cannot be previewed in the preview window.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The advanced customization preview window does not display the change.

Resolution

Status

F5 Product Development has assigned ID 378478 to this issue. Workaround

To work around this issue, you can view the changes by connecting to the virtual server that is associated with the customized access policy.

Impact of workaround: Performing the suggest workaround should not have a negative impact on your system.
