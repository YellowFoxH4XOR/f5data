Known Issue

This is the result of a known issue. If you select the Force FirePass session termination if the browser or Webtop is closed check box on the Users : Endpoint Security : Post-Logon Action page, FirePass standalone VPN clients may disconnect immediately after establishing a Network Access connection.

This issue does not occur when the Use Legacy Logon Prompt setting is enabled in the standalone VPN client. For more information about the Use Legacy Logon Prompt setting, refer to K6955: The Use Legacy Logon Prompt setting of the standalone VPN Client is not compatible with pre-logon checks.

F5 Networks Product Development tracked this issue as CR101486 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

This issue has been fixed in cumulative hotfix HF-603-2.1, which has been issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by clearing the Force FirePass session termination if the browser or Webtop is closed check box on the Users : Endpoint Security : Post-Logon Action page.
