K9742: Enterprise Manager may need to install a new big3d data collection agent on managed devices

Topic

The Enterprise Manager system uses the big3d Data Collection Agent to communicate status and statistics with its managed devices. The Enterprise Manager verifies whether its managed devices are running a compatible version of the big3d agent under each of the following conditions:

  • The Statistics Data Collection feature is first enabled on the Enterprise Manager system.
  • A new device is discovered and the Statistics Data Collection feature is already enabled.
  • An existing device is refreshed and the Statistics Data Collection feature is already enabled.

In Enterprise Manager 2.0.0 and later, if the Enterprise Manager has a newer version of the big3d agent than the target device, the Enterprise Manager system marks the device as Impaired and displays a message indicating that an upgrade is recommended or required. To collect statistics for this device, you must manually initiate the upgrade task through the Data Collection Agent Installation wizard.

Initiating the Data Collection Agent Installation wizard

To initiate the Data Collection Agent Installation wizard in 2.0.0 and later, perform the following procedure:

Impact of procedure: Upgrading the big3d agent causes the BIG-IP GTM system to temporarily change the status to Offline for all objects hosted on the system being upgraded.

  1. Log in to the Configuration utility.
  2. Navigate to Enterprise Management > Tasks > Task List.
  3. Click New Task.
  4. In the Software Installation section, select Install Data Collection Agent.
  5. Click Next.
  6. In the Device Selection section, select the devices with data collection enabled requiring update option.
  7. Select the devices that you want to update.
  8. To initiate the big3d installation, click Next.

    Note: If the upgrade fails, you must manually install the big3d agent on the managed device from the Enterprise Manager command line as detailed in K13372: Error Message: 04010568:3: Error found on device <IP address> (UID: <device ID>): Data collection connection failed.

In Enterprise Manager 1.7.0 and 1.8.0, if the Enterprise Manager system has a newer version of the big3d agent than the target device, the Enterprise Manager system will automatically upgrade the big3d agent on the target device. If the upgrade fails, you must manually install the big3d agent on the managed device from the Enterprise Manager command line as detailed in K13372: Error Message: 04010568:3: Error found on device <IP address> (UID: <device ID>): Data collection connection failed.

In versions prior to Enterprise Manager 1.7.0, the big3d agent was not used and no updates are required or performed.
