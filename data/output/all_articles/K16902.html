Issue

Old Behavior

In versions prior to BIG-IP 11.5.0, Secure Vault encrypted passphrase values listed in the /config/bigip.conf file or viewed from the Traffic Management Shell (tmsh) match across devices to which the configuration objects are synchronized. One example is an encrypted passphrase value in a Client SSL profile.

New Behavior

Beginning in BIG-IP 11.5.0, Secure Vault encrypted passphrase values listed in the /config/bigip.conf file or viewed from the tmsh utility no longer match across devices to which the configuration objects are synchronized. This change in behavior has no effect on the passphrase that was encrypted, and does not impact functionality.

F5 Product Development tracked this change as ID 417845.

Impact

None; this issue is cosmetic.
