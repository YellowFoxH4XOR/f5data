Description

IP Intelligence not working after activating license.

Checking the reputation of an IP address from CLI using 'iprep_lookup' command, outputs the following error:

# iprep_lookup 1.1.1.1
opening database in /var/IpRep/F5IpRep.dat
ERROR: Failed to access IP reputation memory-map
ERROR initializing IP reputation database /var/IpRep/F5IpRep.dat.

Also in /var/log/iprepd/iprepd.log:

iprepd|INFO|Jan 01 12::00.000|11111|vThreatDataMonitor: check for newer data since 0.0 upd 0 build
iprepd|ERR|Jan 01 12::00.000|11111| failed connect to 52.24.103.52 on 443
iprepd|ERR|Jan 01 12::00.000|11111|ConnectSocket fails (probably DNS not configured)

Environment

  • Activated IP Intelligence license
  • autoupdate is enabled
  • TMM route configured
  • Packet capture shows BIG-IP responding to SYN-ACK with a TCP reset:

    [F5RST(peer): RST from BIG-IP internal Linux host]

Cause

Bug ID 993269: DoS timestamp cookies are incompatible with FastL4 TCP timestamp rewrite option

This is how it looks like with timestamp cookie enabled on affected VLAN:

tmsh list security dos device-config dos-device-config tscookie-vlans {
    tscookie-vlans {
        <affected-vlan>
    }
}

Recommended Actions

Disable timestamp cookies on the affected VLAN.

For example to disable on vlan external:

tmsh modify security dos device-config dos-device-config tscookie-vlans delete { external }

Additional Information

Another possible workaround is as follows:

  • Instead of using TMM route, use the Management Route to reach the Public Internet.
