Description

When customer wants to clear the ram cache via REST API (iControlREST).

Environment

  • BIGIP LTM
  • iControlREST
  • Version 14.1.2

Cause

None.

Recommended Actions

Make sure you have SSH or Console access to the device

  1. To delete all your ram cache at once.

    # curl -sk -u <username>:<pw>  -X DELETE https://bigip-mgmt/mgmt/tm/ltm/profile/ramcache/all

    Note: replace <username>:<pw> with the Administrator credentials for your F5 GUI.

    For example:
    # curl -sk -u admin:admin -X DELETE https://10.10.10.10/mgmt/tm/ltm/profile/ramcache/all
