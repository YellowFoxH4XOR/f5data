Description

When trying to renew or import a certificate, you notice that after importing the certificate provided by the CA, the key is not present, and you require a key for the certificate to work in your environment.

 

Environment

  • BIG-IP LTM
  • CSR generated in the BIG-IP

Cause

This is an expected behavior from certain Certificate Authorities (CA).

The CA will generate the certificate based on the CSR details generated by the BIG-IP. In this case, the key should be within the CSR request.

 

Recommended Actions

Import the certificate provided by the CA to the CSR request.

You can follow the next steps:

 

  1. Go to System > Traffic Certificate Management > SSL Certificate List > Create.
  2. Create the CSR. (Be sure to select "Certificate Authority" in the issuer field.)
  3. Download the CSR and send it to the CA.
  4. Once you have the Certificate provided by the CA, go back to System > Traffic Certificate Management > SSL Certificate List and select the previously created CSR.
  5. Select Import and upload the certificate provided by the CA.
  6. Associate the certificate to the SSL profile.

 

Additional Information

If the CSR Request was deleted from the BIG-IP, it will be required to create a new CSR and send it to the CA. Otherwise, the key will not match with the new certificate provided by the CA.
