To verify that the WMI agent is installed and operating:

  1. Open the scripts directory and confirm that it contains the WMI agent.
  2. Try to launch the WMI agent.
  3. Verify that the f5isapi.dll file is responding correctly by connecting to:

    http://localhost/scripts/f5isapi.dll

    You should receive the following message:

    Please specify action for the ISAPI to take.

If f5isapi.dll fails to respond, contact F5 Technical Support for further assistance.
