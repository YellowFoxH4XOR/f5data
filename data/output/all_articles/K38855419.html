Issue

Error Message

info vcmpd[<PID>]: 01510007:6: <vcmpd_operational_information_status>

In this error message, note the following:

  • <PID> is the process ID for the vcmpd process.
  • <vcmpd_operational_information_status> is various information about guest and vdisk during normal operation.

For example:

info vcmpd[6210]: 01510007:6: Guest (EXAMPLE): Setting up watchdog shared memory.
info vcmpd[6210]: 01510007:6: VDisk (EXAMPLE.img/4): Syncing with MCP - [filename:EXAMPLE.img slot:4 installed_os:1 state:5]

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • Various guest conditions occur during normal operation, such as adding or removing vdisks, deleting files, and guest setup and shutdown.

Impact

None. This is an informational log message.

Recommended Actions

None
