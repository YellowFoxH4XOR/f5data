Known Issue

This is the result of a known issue. The gtmd process will crash when all of the following conditions are met:

  • A 3-DNS system, and combination BIG-IP GTM and BIG-IP LTM system are members of the same sync group
  • The 3-DNS generates links based on default routes
  • The combination BIG-IP GTM and BIG-IP LTM system receives gateway probes with NULL pool names from the 3-DNS

If the combination BIG-IP GTM and BIG-IP LTM system receives responses for the 3-DNS gateway probes, the gtmd process will attempt to find the pool member with the NULL pool name and crash.

F5 Product Development tracked this issue as CR69132 and it was fixed in BIG-IP GTM 9.2.4 and 9.3. For information about upgrading, refer to the BIG-IP GTM Release Notes.
