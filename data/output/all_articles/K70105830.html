K70105830: BIG-IQ cannot import BIG-IP services

Type
Support Solution
Published
2022-04-08
Updated
2026-04-22
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.X, 8.3.X, 8.2.X, 8.1.X, 8.0.X, 8.1.0, 8.2.0, 8.3.0, 8.0.0, 8.4.1, 8.4.0
Source
https://my.f5.com/manage/s/article/K70105830

Description

When you attempt to discover and import AFM (or other) services on the BIG-IQ system, you get the following error message:

"The system returned an unexpected error (400 Bad Request). Only one task can run at a time, an import task is waiting for conflicts to be resolved"
 

Environment

  • Discovering the BIG-IP configuration and services on the BIG-IQ system
  • BIG-IQ, BIG-IP ASM/AFM/LTM/DNS

Cause

A dependent task that requires manual intervention to resolve conflicts was unable to complete. In addition, the conflict intervention option does not pop-up or appear in the BIG-IQ GUI.

Recommended Actions

1. You can review the restjavad log files (for example, /var/log/restjavad.0.log) and locate the Task ID that is pending for manual intervention due to conflicts and was unable to complete.

The syntax of the error message in the restjavad log file will appear in this format,

Import task https://localhost/mgmt/cm/adc-core/tasks/declare-mgmt-authority/<TASK_ID> is waiting for conflicts to be resolved (status: FINISHED, currentStep: PENDING_CONFLICTS)

To search through multiple restjavad log files to locate this error message pattern, you can use the grep command as follows:

grep "Import task.*declare-mgmt-authority.*PENDING_CONFLICTS" /var/log/restjavad.*.log

Sample of the result from the grep command,

/var/log/restjavad.2.log: [WARN][04 Mar 2021 11:49:41 GMT][/cm/adc-core/tasks/declare-mgmt-authority AdcDmaTaskCollectionWorker] Import task https://localhost/mgmt/cm/adc-core/tasks/declare-mgmt-authority/ab862e8f-c1c1-46ba-81c7-c3de25446e8b is waiting for conflicts to be resolved (status: FINISHED, currentStep: PENDING_CONFLICTS) 

From the result sample above, the Task ID will be ab862e8f-c1c1-46ba-81c7-c3de25446e8b.

2. Then delete the pending task using the Task ID via the restcurl command:

restcurl -X DELETE '/cm/adc-core/tasks/declare-mgmt-authority/ab862e8f-c1c1-46ba-81c7-c3de25446e8b'

3. Repeat Step 2 on the other Task ID(s) if there are more instances found in Step 1.
4. From BIG-IQ Centralized Management's GUI, remove all services associated with the affected BIG-IP and eventually remove the affected BIG-IP device.
5. Next, re-add the affected BIG-IP device that was removed from Step 4, and verify if discovery and import works.
