Topic

Note: For information about the Adaptive Services Module (ASM) and Network Services Module (NSM), refer to the Hardware Modules section in the ARX 6000 Hardware Installation Guide.

Important: F5 recommends that you save your configuration files before performing this procedure.

To add an ASM or NSM to a pair of ARX 6000 systems, perform the following procedures:

  • Power off both ARX systems.
  • Insert the service module cards.
  • Power on ARX switches
  • Add six proxy IP addresses to each ARX system (only required if an NSM card was added).   
  • Verify addition.

Note: The following procedures refer to the pair of ARX 6000 systems as ARX1 and ARX2, in which ARX1 was initially the active system and ARX2 was initially the backup system.

Note: In this procedure, F5 assumes that you are installing both an ASM card and an NSM card. 

Power off both ARX systems 

  1. Power off the ARX2 (backup) system.
  2. Power off the ARX1 (active) system.

Insert the service module cards

Note: For information about installing the ASM and NSM, refer to the Removing and Replacing Modules section of the ARX 6000 Hardware Installation Guide.

  1. Insert an ASM card into an empty slot on the ARX2 system.
  2. Insert an NSM card into an empty slot on the ARX2 system.
  3. Insert an ASM card into an empty slot on the ARX1 system.
  4. Insert an NSM card into an empty slot on the ARX1 system.

Power on the ARX systems

  1. Power on the ARX1 system.
  2. Wait 5 minutes.
  3. Power on the ARX2 system.
  4. Wait until the show processors command displays an Up state for all processors on both ARX1 and ARX2. The show processors command appears similar to the following example:

    Proc     Module  State       Up Time             Total Kb  Free Kb  CPU1M   CPU5M
    ----     ------  ----------  ------------------  --------  -------  ------  -----
    1.1      SCM     Up          0 days, 00:10:53    4023348   3323088  4       4
    3.1      ASM     Up          0 days, 00:07:06    4023348   3278000  0       0
    3.2      ASM     Up          0 days, 00:06:43    4023348   3187680  0       0
    5.1      NSM     Up          0 days, 00:06:45    2042880   1303917  0       0
    5.2      NSM     Up          0 days, 00:06:45    2042880   1303917  0       0
    5.3      NSM     Up          0 days, 00:06:40    2042880   1303917  0       0
    5.4      NSM     Up          0 days, 00:06:40    2042880   1303917  0       0
    5.5      NSM     Up          0 days, 00:06:45    2042880   1318253  0       0
    5.6      NSM     Up          0 days, 00:06:45    2042880   1318253  0       0

    Note: The HA redundancy connection is not established at this point.
     
  5. Reboot the ARX1 system by typing the following command:

    reload
  6. Wait 5 minutes.
  7. Reboot the ARX2 system by typing the following command:

    reload
  8. Wait until the command prompt displays the correct hostname, and the show processors command displays an Up state for all processors on both ARX1 and ARX2.

    Note: The command prompt may initially be displayed as the default (SWITCH).

    Note: The HA redundancy connection should now be re-established between the ARX1 and ARX2 systems.
  9. On the ARX1 system, use the show redundancy command to verify that the redundancy connection to the ARX2 system is established. The show redundancy command output displays a status of Up for both ARX systems:

                                                   Transitions
    Node Switch/Quorum Disk   Status     Role    Total Last (UTC)
    ---- -------------------- ---------- ------- ----- -------------------
    *1   ARX1                 Up         Active  Never -
     2   ARX2                 Up         Backup  Never -
     QD  172.30.20.10         Up       Quorum  11    04:01:52 09/01/2010
  10. On the ARX2 system, use the show redundancy command to verify that the redundancy connection to the ARX1 system is established. The show redundancy command output displays a status of Up for both ARX systems:

                                                   Transitions
    Node Switch/Quorum Disk   Status     Role    Total Last (UTC)
    ---- -------------------- ---------- ------- ----- -------------------
     1   ARX1                 Up         Active  Never -
    *2   ARX2                 Up         Backup  Never -
     QD  172.30.20.10         Up       Quorum  11    04:01:52 09/01/2010

    Important: If the HA redundancy connection is not re-established, repeat the reboot process (Steps 5 through 8).

 Add six proxy IP addresses to each ARX system (only required if an NSM card was added) 

  1. Log in to the ARX2 system.
  2. Enable privileged mode by typing the following command:

    enable
  3. Enter configuration mode by typing the following command:

    config
  4. Configure a new proxy IP addresses using the following syntax:

    ip proxy-address nnn.nnn.nnn.nnn mmm.mmm.mmm.mmm vlan xxx

    Replace nnn.nnn.nnn.nnn with the Proxy IP address to be configured.
    Replace mmm.mmm.mmm.mmm with the subnet mask for your Proxy IP network.
    Replace xxx with the proxy interface VLAN.

    For example:

    ip proxy-address 192.168.1.24 255.255.255.0 vlan 10
     
  5. Repeat Step 4 for each of the six new proxy IP addresses to be added to the ARX2 system.
  6. Log on to the ARX1 system.
  7. Enable privileged mode by typing the following command:

    enable
  8. Enter configuration mode by typing the following command:

    config
  9. Configure a new proxy IP addresses using the following syntax:

    ip proxy-address nnn.nnn.nnn.nnn mmm.mmm.mmm.mmm vlan xxx

    Replace nnn.nnn.nnn.nnn with the Proxy IP address to be configured.
    Replace mmm.mmm.mmm.mmm with the subnet mask for your Proxy IP network.
    Replace xxx with the proxy interface VLAN.

    For example:

    ip proxy-address 192.168.1.24 255.255.255.0 vlan 10
  10. Repeat Step 9 for each of the six new proxy IP addresses to be added to the ARX1 system.

Verify addition

  1. Log in to the ARX1 system.
  2. Verify that the ARX1 system is the active system by typing the following command:

    show redundancy

    The output of the command appears similar to the following example:

                                                   Transitions
    Node Switch/Quorum Disk   Status     Role    Total Last (UTC)
    ---- -------------------- ---------- ------- ----- -------------------
    *1   ARX1                 Up         Active  Never -
     2   ARX2                 Up         Backup  Never -
     QD  172.30.20.10         Up       Quorum  11    04:01:52 09/01/2010
  3. Verify that the new ASM/NSM service modules are online by typing the following command:

    show chassis slotinfo

    The output of the command appears similar to the following example:

     Slot Environment:
     Slot  Type   State             Power    Temperature     NVR Battery  Drive
     ----  -----  ----------------  -------  --------------  -----------  ---------
      1    SCM    Online            Online   Normal (<45 C)  Good         LSI Good
      2    ASM    Online            Online   Normal (<65 C)  N/A
      3    ASM    Online            Online   Normal (<65 C)  N/A
      5    NSM    Online            Online   Normal (<65 C)  N/A
      6    NSM    Online            Online   Normal (<65 C)  N/A
  4. Verify that the namespaces are online by typing the following command:

    show namespace status all
  5. Log on to the ARX2 system.
  6. Verify that the ARX2 system is the backup system, by typing the following command:

    show redundancy
  7. Verify that the new ASM/NSM service modules are online by typing the following command:

    show chassis slotinfo
