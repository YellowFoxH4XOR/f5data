Issue

Error Message

01420003:5: User idle time out reached; logged out of tmsh.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
  • The /var/log/audit file
Description

This message occurs when the following conditions are met:

  • You have configured an idle timeout period (in minutes) for the TMOS shell (tmsh) command line interface. The default value is disabled.
  • The configured idle timeout period has expired.

Impact

The BIG-IP system logs out users with tmsh terminal access. Users with Advanced shell (bash) access return to bash.

Recommended Actions

Modifying the tmsh idle timeout period

You can modify the current idle timeout period for the BIG-IP system using tmsh.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. View the idle timeout period by typing the following command:

    list cli global-settings idle-timeout

  3. Modify the idle timeout period using the following command syntax:

    modify cli global-settings idle-timeout <value>

    For example, to modify the idle timeout period to 20 minutes, type the following command:

    modify cli global-settings idle-timeout 20

  4. Disable the idle timeout period by typing the following command:

    modify cli global-settings idle-timeout disabled

  5. Save the configuration by typing the following command:

    save sys config
