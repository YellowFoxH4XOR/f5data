Issue

Error Message

tmrouted[<PID>] 01910603: Withdrawing route <%s> matching admin network not suppressed

In this error message, note the following:

  • <%s> is the route that matches the BIG-IP management network
  • <PID> is the process ID for the tmrouted process

For example:

tmrouted[50702] 01910603: Withdrawing route 10.15.42.0/24 matching admin network not suppressed

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • The BIG-IP system is running an advanced routing protocol, such as Open Shortest Path First (OSPF).
  • The BIG-IP system attempted to withdraw a route from the kernel that matched the mgmt network.

The BIG-IP system may log the above error message when an adjacent router advertises a route that matches the BIG-IP management network, and the system adds and then attempts to withdraw the advertised route.

Impact

The message is informational, however, you should verify that the management network route was not replaced by the advertised route.

Recommended Actions

Verify that the BIG-IP management network route still exists in the Linux kernel routing table and was not overwritten. For more information about management interface routing and configuring the management interface, refer to K13284: Overview of management interface routing (11.x - 14.x).
