Security Advisory Description

When negotiating IPsec tunnels with configured, authenticated peers, the peer may negotiate a different key length than the BIG-IP configuration would otherwise allow. (CVE-2020-5938)

Impact

IPsec connections can be created with a different key length than specified in the BIG-IP configuration, potentially leading to lesser-than-configured encryption strength for the connection.

For example, if the BIG-IP system was configured for AES256 encryption, the Security Association could be successfully negotiated using AES128 encryption. It is not possible to change the algorithm, or to disable encryption, but it is possible for peers to modify the key length and still successfully negotiate an IPsec connection.
