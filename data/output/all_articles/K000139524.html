Description

What is a Visual Policy Editor?

Environment

  • BIG-IP APM

Cause

Not applicable.

Recommended Actions

Not applicable.

Additional Information

The visual policy editor is a screen or interface that allows users to configure an access policy or a per-request policy using visual elements. It provides a visual representation of the policy and allows users to easily add actions, configure properties and rules for actions, and define endings such as Allow or Deny. 

To use the Visual Policy Editor, after logging in to the GUI on F5 , select Access -> Profiles / Policies, Then select for the targeted access policy.
