Topic

This article lists the Microsoft Azure Linux Agent (waagent) version supported by BIG-IP versions.

Description

BIG-IP VE uses the Microsoft Azure Linux Agent (waagent) to manage Linux and allows VM to interact with the Azure Fabric Controller. The Microsoft waagent is distributed as part of BIG-IP VE installation in Azure environment.

Important: You must not install or upgrade the waagent on your BIG-IP VE instance even though the waagent version is not the latest version supported by Microsoft because doing so may cause some functionality to break on your BIG-IP VE instance. F5 does not support upgrading third party software components separately from a BIG-IP install/upgrade. For more information, refer to K41211285: About upgrading 3rd Party software components on BIG-IP or BIG-IQ. For information about getting support for BIG-IP instances on Microsoft Azure environment, refer to K40701984: F5 Support for BIG-IP solutions on Microsoft Azure.
