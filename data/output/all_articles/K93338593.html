Known Issue

DNS Express uses the wrong time-to-live (TTL) value for the Start of Authority (SOA) Resource Record Signature (RRSIG) record in the NoData response.

This issue occurs when all of the following conditions are met:

  • You have configured DNS Express.
  • A query results in a NoData response and Domain Name System Security Extensions (DNSSEC) signing request.

Impact

This brings the behavior in line with RFC2308. There is no known functional impact.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • DNS Express returns an incorrect TTL for the SOA RRSIG record in a NoData response.
