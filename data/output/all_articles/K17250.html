Known Issue

The BIG-IP APM system may escape the pipe character (|) in Active Directory (AD) or Lightweight Directory Access Protocol (LDAP) attributes.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured to authenticate using AD or LDAP AAA servers.
  • An AD/LDAP query returns binary attributes containing the pipe character (|).
  • Non-printable characters are used in the AD/LDAP attribute values.

Impact

The pipe character (|) is escaped by the BIG-IP APM system during processing, thereby changing the attribute value.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • User requests fail because the AD objectGUID value changed. For example, you notice the BIG-IP APM system prepends the value 5c (backslash) to the value 7c (vertical bar) similar to the following example:

    Original attribute value:

    AE D0 A5 57 DD 7C EF 4C 79 89 BC 8E C2 5A CC 5B

    Altered attribute value:

    AE D0 A5 57 DD 5C 7C EF 4C 79 89 BC 8E C2 5A CC 5B

  • Security Assertion Markup Language (SAML) services are impaired or become inaccessible when using AD/LDAP authentication.
