K864: Minimum system requirements to boot the BIG-IP or 3-DNS system software and run a network boot server

Type
Knowledge
Published
2006-02-17
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • 3-DNS: 4.6.4
  • BIG-IP 4.X: 4.6.4
Source
https://my.f5.com/manage/s/article/K864

Topic

The system must contain one of the following CPUs:

  • Intel 80386
  • Intel 80486
  • Intel Pentium Pro
  • Intel Pentium
  • Intel Pentium 4
  • Intel Pentium II
  • Intel Pentium III
  • AMD and Cyrix CPUs compatible with the above Intel models

The system must contain one of the following PCMCIA/PC Card Controllers if network or disk access relies on a PC Card:

  • Cirrus Logic CL-PD6710
  • Cirrus Logic CL-PD672X
  • IBM KING
  • Intel i82365
  • Intel i82365SL
  • Ricoh RF5C296
  • Ricoh RF5C396
  • Vadem VG468
  • Vadem VG469
