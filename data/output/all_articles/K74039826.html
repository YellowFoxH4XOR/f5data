Description
There are times when it becomes necessary to run or setup a BIG-IP with an earlier version than it is currently running. You may have an older installed version on the BIG-IP. However, you cannot choose, at the time of boot, from the "Install Configuration" dropdown the 'yes' option as this will not work as desired. The problem is you cannot downgrade a BIG-IP. If you try there will be unintended consequences. K14568: Downgrading BIG-IP software (15.x - 21.x)

Environment

  • Any module of the BIG-IP

Cause

After an RMA you need to set it up to run an earlier version than it was sent with, setup a lab environment, or any number of other reasons.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. The gist of this is you have to do a clean install. In the case of an RMA there will be a license issue because you would have to activate the base registration key for the replacement device when booted into the OS it was shipped with. Since it would be activated at that point doing the clean install would be hung up when activating the license in the older version because it would have been already been activated. It that were to happen you would have to request an "Allow move", so you can re-use it. The "Allow move" is not always allowed. To do the clean install follow the steps in K13117: Performing a clean installation of BIG-IP 11.x - 17.x

  2. After booting into the older version use the "config" utility to setup the management IP/subnet/default gateway via a console connection. K15040: Configuring and displaying the management IP address for the BIG-IP system

  3. Once that is done log into the GUI and run through the setup of the base configuration and install the base registration key. K7037: Overview of the BIG-IP Setup utility

  4. Build/Rebuild HA/configsync K42161405: Rebuilding device trust using the Configuration utility

  5. Then you can either sync from the peer, that has a knows good configuration, to the device with the base config or you could load a ucs using the no-license command. K13132: Backing up and restoring BIG-IP configuration files with a UCS archive
