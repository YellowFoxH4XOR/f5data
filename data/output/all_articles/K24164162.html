K24164162: SDC TTA is collecting 3 copies of logs files by default

Type
Support Solution
Published
2021-07-22
Updated
2023-02-21
Applies to
  • Traffix SDC: 5.X.X, 5.1.X, 5.0.X, 5.2.0, 5.2.X, 5.0.0, 5.1.0
Source
https://my.f5.com/manage/s/article/K24164162

Description

When collection of TTA log, only 3 copies of the TTA log is being collected.

Environment

  • SDC 5.1
  • tta-ng.sh script
  • Log files

Cause

By default, SDC TTA log collects only 3 copies of files.

Recommended Actions

To collect desired number of TTA log files, use option -n
  1. Change to the scripts folder
    #cd /opt/traffix/scripts
  2. Run tta script using -n option. If you want 10 files run the below command
    #./tta-ng.sh -n 10
