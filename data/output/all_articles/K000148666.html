Source

Description

Significant drop in telemetry streaming data: Error: severe [telemetry.AWS_CloudWatch.My_Consumer] Unable to forward to AWS CloudWatch consumer Traceback: ThrottlingException: Rate exceeded

Environment

  • AWS CloudWatch
  • AS3 policy declaration
  • Telemetry Streaming v1.18-
  • LTM

Cause

restnoded has trouble with large and frequent requests made to PUT to CloudWatch

Recommended Actions

Upgrade Telemetry RPM version (v1.28+) to resolve Telemetry Streaming bug 191: CloudWatch Log Loss

Change Timeout Values on icrd, restjavad and restnoded:

#tmsh modify sys db icrd.timeout value 300
#tmsh modify sys db restjavad.timeout value 300
#tmsh modify sys db restnoded.timeout value 300

Set provision.restjavad.extramb to 80% of provision.extramb:

Verify provision.extramb value:

#tmsh list sys db provision.extramb

Increase restjavad extramb to 80% of provision.extramb:

#tmsh modify sys db provision.restjavad.extramb value ####
