K000161527: The action value in a profile cannot be changed from accept/reject/drop to Don't Inspect in CLI

Type
Support Solution
Published
2026-07-07
Updated
2026-07-07
Applies to
  • BIG-IP
  • BIG-IP AFM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000161527

Description

When modifying a protocol inspection profile in BIG-IP AFM using the CLI (tmsh), the available action values for signatures and compliance checks are limited to "accept", "drop", and "reject". The CLI does not provide a direct option to set an action to "Don't Inspect". To achieve "Don't Inspect" behavior in the CLI, delete the specific compliance or signature item from the profile, which removes inspection for that item.

Environment

BIG-IP AFM, protocol inspection profiles configured for services such as GTP, with compliance checks like gtp_end_user_ip_spoofing.

Cause

The CLI (tmsh) interface for protocol inspection profiles does not expose "Don't Inspect" as an action value. The absence of a compliance or signature item in the profile is equivalent to "Don't Inspect". The GUI allows direct selection of "Don't Inspect", but in CLI, deletion of the item is required.

Recommended Actions

  • To revert a compliance or signature item to "Don't Inspect" in CLI, use the following tmsh command to delete the item from the profile:
    modify security protocol-inspection profile <profile_name> services modify { <service> { compliance delete { <compliance_item> } } }
  • Example:

    • modify security protocol-inspection profile new_GTP_profile services modify { gtp { compliance delete { gtp_end_user_ip_spoofing } } }

  • After deletion, verify the profile configuration. The absence of the compliance or signature item indicates it is set to "Don't Inspect".
  • In the CLI, only "accept", "drop", and "reject" are available as action values. Use deletion to achieve "Don't Inspect".
  • For confirmation, list the profile properties and ensure the item is no longer present:

    • tmsh list security protocol-inspection profile <profile_name> all-properties

  • In the GUI, "Don't Inspect" can be selected directly; in CLI, deletion is required.
