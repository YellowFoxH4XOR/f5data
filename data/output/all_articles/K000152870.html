K000152870: BIG-IP APM Network Access failure after activating new F5 appliance

Description

Following the migration from an old F5 appliance to a new one, VPN authentication fails with the Edge Client displaying a small pop-up error message: 

"You do not have access to the Network Access Connections. Please contact your system administrator."

This generic message typically indicates a failure in access policy evaluation within BIG-IP APM, preventing the VPN connection from being successfully established.

Environment

  • BIG-IP APM 
  • Network Access

Cause

This error is commonly triggered when an access policy rule fails to evaluate as expected. Common root causes include, but are not limited to the following:

  • Syntax errors in Tcl expressions (e.g., missing or misplaced curly brackets, incorrect logical operators)
  • Incorrect or missing session variable references

Recommended Actions

  • Review APM session logs in var/log/apm for detailed error messages related to policy evaluation.
  • Trace the access policy flow to identify which specific rule or action is failing.
  • After making necessary corrections, apply the access policy and retest the VPN connection.
  • If you are unable to identify the failing rule or action, please contact F5 support with the following data:
    • Session ID of the failed attempt.
    • Qkview generated from the relevant BIG-IP system.
