Description

When trying to run gtm_add, the command fails and you receive the below error message:
ERROR: Can't create a hard link /config/gtm/server.crt.backup to local server cert file /config/gtm/server.crt. The file /config/gtm/server.crt.backup may already exist.

Environment

  • BIG-IP DNS

Cause

DNS is not provisioned on the local device

Recommended Actions

Provision DNS on the local device
  1. From the GUI, navigate to System  ››  Resource Provisioning
  2. Click the checkbox next to Global Traffic (DNS) and adjust the dropdown to the appropriate provisioning level for your device
  3. Click Submit
  4. Once provisioning is complete, try running gtm_add again
