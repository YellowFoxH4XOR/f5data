K000158977: BIG-IP system is not sending SNMP traps for pool member up/down events to your external server

Type
Support Solution
Published
2026-01-04
Updated
2026-02-25
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000158977

Description

SNMP traps are not being sent when pool or pool member status changes occur, although manual snmptrap commands from the CLI work successfully.

  • Manual snmptrap commands from CLI successfully send traps to the SNMP server.
  • Pool member status changes (up/down) via WebUI do not trigger SNMP traps.
  • Pool member status logs appear in /var/log/ltm but SNMP traps are not generated.
  • Packet captures show no SNMP traffic when pool status changes via WebUI.
  • The alertd process does not trigger SNMP notifications for pool member events.

Environment

  • BIG IP LTM
  • SNMP Trap
  • Configuration:
    • SNMP traps configured with valid community string and destination.
    • mcpd log level set to "error".

Cause

The mcpd log level was set to "error or warning" instead of the default "notice" level. Pool member status change logs are generated at the "notice" level. When mcpd loglevel is set to "error", these notice-level logs are not written, preventing the alertd process from detecting pool member status changes and triggering the corresponding SNMP alert traps.

Recommended Actions

  1. Verify the current mcpd log level: 
    tmsh list sys db log.mcpd.level
  2. Set the mcpd log level to the default "notice" value: 
    tmsh modify sys db log.mcpd.level value notice
tmsh save sys config
  3. Verify the change: 
    tmsh list sys db log.mcpd.level
  4. Generate test pool member status change events and verify if SNMP traps are now being sent

Optional: Monitor SNMP traffic with packet capture to verify traps are sent:

tcpdump -ni mgmt -s0 -w /var/tmp/snmp_test.pcap port 161

Additional Information

  • When mcpd log level is set to "error", only error-level messages (severity 3 and below) are logged, filtering out notice-level pool member status changes.
