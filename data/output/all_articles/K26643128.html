Description

After deploying a new VE on Xen project the Image is installed on the smaller Logical Disk HD2  instead of HD1.

show /sys software
--------------------------------------------------------
Sys::Software Status
Volume  Product  Version   Build  Active  Status
--------------------------------------------------------
HD2.1    BIG-IP 14.1.2.6   0.0.2     yes  complete  

list /sys disk all-properties
sys disk logical-disk HD1 {
    mode mixed         
    size 169984
    vg-free 0
    vg-in-use 0
    vg-reserved 0
}
sys disk logical-disk HD2 {
    mode mixed          
    size 77824
    vg-free 21420
    vg-in-use 56184
    vg-reserved 0
}


Environment

  • BIG-IP VE
  • Xen Project Hypervisor
  • Datastore Disk in use

Cause

The datastore disk has not been removed during the deployment 

Recommended Actions

  1. Take a UCS backup
  2. Re-deploy the VM following the manual/guide.  See Manual section Virtual machine storage requirements
  3. Restore configuration from the UCS

 

Additional Information

K13132: Backing up and restoring BIG-IP configuration files with a UCS archive
