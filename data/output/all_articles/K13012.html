K13012: The backup ARX system in a redundant pair is unable to ping the remote systems

Known Issue

You cannot use the ping command on a backup ARX system in a redundant pair to ping a remote system. The ping command will fail with an INVALID_IP_ADDR error message. However, the backup ARX system will respond to ping requests as expected.

This issue occurs when all of the following conditions are met:

  • The ARX system is configured in a redundant pair.
  • You attempt to ping a remote system from the backup ARX system.

You can use the show redundancy command to determine if the ARX is currently the active or backup system. The show redundancy command output will appear similar to the following example:

                                               Transitions
Node Switch/Quorum Disk   Status     Role    Total Last (UTC)
---- -------------------- ---------- ------- ----- -------------------
*1   ARX1a                Up         Backup  Never -
 2   ARX1b                Up         Active  1     16:49:44 07/25/2011
 QD  192.168.10.11        Up         Quorum  1     16:49:16 07/25/2011

Impact

You cannot use the ping command to verify connectivity from a backup ARX system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The ping command will fail with the following error message:

    % ERROR: INVALID_IP_ADDR (38010912):
      Invalid IP address or hostname 'Source IP not hosted by switch.' specified.
