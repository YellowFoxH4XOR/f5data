K000150413: Trial key is incompatible with VMware

Type
Support Solution
Published
2025-03-17
Updated
2025-03-17
Applies to
  • BIG-IP
  • Virtual Editions
  • BIG-IP LTM: 17.5.X, 17.1.X, 16.1.X, 17.5.0, 17.1.2, 17.1.1, 17.1.0, 16.1.5, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0
Source
https://my.f5.com/manage/s/article/K000150413

Description

You received a trial license from F5 and performed a license activation. Upon activation via the automatic method, the browser returns to the initial license page and you observed this error, "The error might be due to the trial key being incompatible with VMware. Please request a new trial key from the F5 website, selecting 'BIG-IP VE and BIG-IQ', and then try reactivating with the new key."

Environment

 LTM VE

Cause

 Unknown at the time of publication. 

Recommended Actions

  ​​​​​​​Activate the trial license manually. 

  1. Log in to the Configuration utility using an account with the administrator role.

    Note: If this is a new BIG-IP system, open a web browser on a workstation attached to the network on which you configured the management port and type the following URL in the browser: https://<IP address>/. <IP_address> is the address that you configured for the management port.

  2. Select Activate.

    Note: If the BIG-IP system is already licensed, navigate to System > License and select Re-activate. Optionally on BIG-IP 12.1.0 and later, select the Enable License Comparison check box to compare a new license with the existing BIG-IP license.

  3. Select Manual.
  4. Select Next.
  5. Copy the dossier and connect to the F5 Product Licensing page at secure.f5.com.
  6. On the F5 Licensing Tools page, select Activate F5 product registration key.
  7. Paste the dossier into the Enter Your Dossier box, and then select Next.

    The F5 Product Licensing page produces your license.

  8. Copy the license and paste it into the License box in the Configuration utility.
  9. Select Next.
