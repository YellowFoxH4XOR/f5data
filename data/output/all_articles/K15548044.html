Description

You may the symptoms following the below steps:

  • Use the iRule RULE_INIT event.
  • The RULE_INIT refers to some classes to set global or static variables. For example, Pool, SNAT Pool, and Data Group.
  • Change the Pool/SNAT Pool/Data Group content, but the variables also use original Pool/SNAT Pool/Data Group items.
  • For example:

  1. You write an iRule related a SNAT Pool at RULE_INIT event, the SNAT Pool has three ip address:192.168.1.100, 192.168.1.101, and 192.168.1.102.
    when RULE_INIT {
        set static::snatpool "SNATPool"
        set static::members_list "members -list $static::snatpool"
        set static::i 0
        foreach static::snat_ip [eval $static::members_list] {
            set static::snat_ips_list($static::i) [lindex $static::snat_ip 0]
            incr static::i
        }
        log local0. "Loaded SNAT IPs from $static::snatpool_name: [array get static::snat_ips_list]"
    }
    when CLIENT_ACCEPTED {
        log local0. "Loaded SNAT IPs from $static::snatpool_name: [array get static::snat_ips_list]"
    }

  2. When you save the iRule, the variable snat_ips_list will initialize, check log /var/log/ltm.
    info tmm[xxx]: Rule /Common/iRule_INIT <RULE_INIT>: Loaded SNAT IPs from SNATPool: 0 192.168.1.102 1 192.168.1.101 2 192.168.1.100

  3. And when you add an ip address 192.168.1.103 to the SNAT Pool, the variable snat_ips_list still use original SNAT Pool IP list when next connection comes in, for example: 
    info tmm1[xxx]: Rule /Common/iRule_INIT <CLIENT_ACCEPTED>: Loaded SNAT IPs from SNATPOOL: 0 192.168.1.102 1 192.168.1.101 2 192.168.1.100

Environment

  • iRules
  • RULE_INIT
  • Variables

Cause

A variable set in RULE_INIT will only be updated when this iRule is updated. For more details, please refer to RULE_INIT on F5 Cloud Docs.

Recommended Actions

It needs to update the iRule so the updated class items will be used. For example, you can follow the below steps to re-initialize the RULE_INIT event.

  1. Add the following content in the RULE_INIT event. then save the iRule.
    when RULE_INIT {
      ...
      log local0. "Re-initialize variables"
      ...
    }
  2. Check /var/log/ltm whether appear the Re-initialize variables content.
