K40275495: Comparing two UCS backup files with large configuration files causes BIG-IQ GUI to hang and eventually timeout

Type
Support Solution
Published
2021-07-06
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K40275495

Description

When using the Backup Compare feature of Big-IQ to "View Config Differences", the UI will hang (keeps spinning) and not show the differences as expected. Eventually, BIG-IQ will logout the user from GUI.  This only happens when you are comparing UCS snapshots containing .conf files exceeding ~3.5MB. 

Environment

  • BIG-IQ 7.x and 8.x
  • Large configuration files in BIG-IP
  • Use of "Backup Compare History" to "view differences"

Cause

F5 Product Development Team is still investigating at the time of publication. 

Recommended Action 
No workaround available for this as of the time of publication while PD is still investigating. 

Additional Information

None
