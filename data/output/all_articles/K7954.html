Known Issue

This is the result of a known issue. The End-User Diagnostics (EUD) program will always indicate that a non-Reduction of Hazardous Substances (RoHS) compliant Federal Information Processing Standards (FIPS) cryptographic card has failed its diagnostic test, even when the card is fully functional. EUD versions prior to version 10.0.6.x will incorrectly display a failed status for non-RoHS FIPS cards.

Note: The EUD version is displayed at the top of the EUD menu interface.

The EUD is a bootable, menu-driven program used to troubleshoot hardware components. FIPS cryptographic cards perform hardware-based SSL acceleration and secure storage of cryptographic information. Two models of FIPS card exist: those that comply with the European Union's RoHS standard, and those that do not omply with RoHS. RoHS-compliant FIPS cards are not affected by this issue.

When you run an EUD test of the FIPS card using either the FIPS card test option or the option to run all non-interactive tests, the EUD reports that errors were found during the FIPS card test, and the test failed. The output of the EUD is similar to the following example:


***** FIPS Test *****

Cavium FIPS test setup.

Cavium FIPS test started.

Cfm1F5Util error (line 1651): USER Login : 0x40000207 : ERR_PIN_INCORRECT

The FIPS test failed!

Permissible error count exceeded.

This error is incorrect. Unless there are physical symptoms that suggest a problem, this error can safely be ignored.

F5 Networks Product Development tracked this issue as CR83744, and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.

This issue still exists in the FirePass version 5.x branch.

Additionally, a hotfix for certain versions of FirePass software will be issued. Customers affected by this issue can contact F5 Networks Technical Support to request status on the hotfix. Include the change request number and the number of this Solution in your correspondence.

Note: F5 Networks normally distributes EUD updates as stand-alone hotfixes. For this EUD update, in addition to hotfixes for earlier versions of FirePass Software, the update package for FirePass version 6.0.2 contains the updated EUD. Future EUD updates may or may not be included with subsequent new versions of FirePass software.
