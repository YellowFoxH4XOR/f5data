Known Issue

The BIG-IP APM Machine Certificate Auth agent may select an expired certificate.

This issue occurs when the following condition is met:

  • The client machine store contains both a valid and an expired certificate.

Impact

Machine certificate check fails and users are unable to establish an access session.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Machine Certificate Auth agent selects a matching, but expired certificate, if found before a valid certificate.

Workaround

There is no workaround for this issue. However, you can alternatively remove expired certificates from the client machine certificate store.
