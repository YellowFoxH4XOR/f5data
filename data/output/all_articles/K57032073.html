Description

This article will describe how to verify that you have a full APM (Access Policy Manager) license.

  • Your APM sessions are limited to 10
  • You observe the following log messages in /var/log/apm:
<big-ip_hostname> warning tmm1[20306]: 01490508:4: /Common/<access_policy_name>:Common:<session-ID>: Global concurrent access session limit reached.

In the above log message the Session ID is the unique APM session ID.

K15387: Overview of BIG-IP APM session cookies

Environment

Relevant environmental factors specific to the topic

  • Access Policy Manager (APM)
  • Configuration objects and settings
  • System License

Cause

This occurs when you have a APM Limited license, but not a full APM license.

Recommended Actions

Verify your APM license from the Big-IP Command Line:

  1. Login to the Big-IP Command Line.
  2. Run the following command:

    tmsh show /sys license detail

  3. If the output you should see "mod_apm" otherwise you do not have a full apm license:

    mod_aml
        Application Acceleration Manager - Core
    mod_apm
        Access Policy Manager
    mod_apml
        Access Policy Manager Limited
    mod_dnsgtm
        DNS/GTM
    mod_ltm
        Local Traffic Manager
