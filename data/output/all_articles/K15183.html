Known Issue

Deploying an iApp Application Service based on an f5.dns template may fail.

This issue occurs when all of the following conditions are met:

  • You attempt to create a new iApp Application Service with the following configuration options:

    • Under Network > Where will the virtual servers be in relation to the DNS servers?, select BIG-IP virtual server IP and DNS servers are on different subnets
    • Under Network > How have you configured routing on your DNS servers?, select DNS servers have a route to clients through the BIG-IP

    Impact

    You are unable to create the iApp Application Service.

    Symptoms

    As a result of this issue, you may encounter the following symptoms:

    • When you deploy a new iApp Application Service based on the f5.dns template, you are unable to create the Application Service, and in the BIG-IP Configuration utility, you may observe a message similar to the following example:

      script did not successfully complete: (can't read "::net__snatpool": no such variable
      while executing
      "subst $substa_out"
      invoked from within

      set substa_out [subst $$substa_in]
      set substa_out [subst $substa_out]
      } else {
      ..."

    Workaround

    To work around this issue, you can first create the iApp Application Service specifying that the DNS servers do not have a route to clients through the BIG-IP system, and then reconfigure the system with the needed options. To do so, perform the following procedures:

    Impact of workaround: Performing the following procedures should not have a negative impact on your system.

    Creating the iApp Application Service

    Note: Options will dynamically appear and disappear as you select various options throughout the configuration.

    1. Log in to the BIG-IP Configuration utility.
    2. From the main menu, click iApp > Application Services.
    3. Click Create.
    4. In the Name field, type the name for your Application Service.
    5. From the Template list, select the f5.dns template.
    6. Under Template Options > Which configuration mode do you want to use?, select Advanced - Configure advanced options.
    7. Under Network > Where will the virtual servers be in relation to the DNS servers?, select BIG-IP virtual server IP and DNS servers are on different subnets.
    8. Under Network > How have you configured routing on your DNS servers?, select DNS servers do not have a route to clients through the BIG-IP.
    9. Under Network > How many connections per server do you expect?, select Less than 64,000 concurrent connections per server.
    10. Fill out the remaining required fields, and then click Finished.

    Re-configuring the iApp Application Service

    Note: Options will dynamically appear and disappear as you select various options throughout the configuration.

    1. Log in to the BIG-IP Configuration utility.
    2. From the main menu, click iApp > Application Services.
    3. Click the name of the previously configured iApp.
    4. Select the Reconfigure tab.
    5. Under Template Options > Which configuration mode do you want to use?, select Advanced - Configure advanced options.
    6. Under Network > How have you configured routing on your DNS servers?, select DNS servers have a route to clients through the BIG-IP.
    7. Make any other desired changes to the iApp.
    8. Click Finished.
