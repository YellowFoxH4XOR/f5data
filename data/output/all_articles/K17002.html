Known Issue

Description

The BIG-IP APM system may not return correct form parameter value.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP APM system for portal access.
  • You are using the Internet Explorer 9 or 10 browser to generate client-side traffic.
  • JavaScript dynamically populates the form parameter value on the client.

In the following example, JavaScript dynamically populates the value for the action input element when submitting the form. When executing the submitPage function, the form parameter action is populated with an empty value instead of the Continue value:

 <script>
      function submitPage(action)
      {
        document.CheckoutMainForm.action.value=action;
        document.CheckoutMainForm.submit();
      }
    </script>

    <form name="CheckoutMainForm" action="form-post.html" method="post">
        <input name="action" type="hidden" value="">
        <input name="newCreditCard" type="hidden" value="N">
        <!-- Continue Button -->
        <center>
            <input class="calc-button" onclick="javascript:submitPageContinue')" type="button" value="Continue">
        </center>
    </form>

Impact

The form parameter is populated with an incorrect value, causing web applications to malfunction.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When using portal access, a form parameter is populated with an incorrect value.
  • When using portal access, requested pages fail to display.
  • Web applications malfunction or fail to render properly in the Internet Explorer 9 or 10 browsers.
