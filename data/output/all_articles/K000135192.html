K000135192: Warnings for istiod pods regarding horizontalpodautoscaler/istiod during Aspen Mesh installation

Type
Support Solution
Published
2023-06-22
Updated
2023-06-22
Applies to
  • Aspen Mesh: 1.14
Source
https://my.f5.com/manage/s/article/K000135192

Description

During Aspen Mesh 1.14.x installation there are warnings for istiod pods regarding horizontalpodautoscaler/istiod

26m     Warning  FailedGetResourceMetric    horizontalpodautoscaler/istiod  failed to get cpu utilization: unable to get metrics for resource cpu: no metrics returned from resource metrics API
26m     Warning  FailedComputeMetricsReplicas  horizontalpodautoscaler/istiod  invalid metrics (1 invalid out of 1), first error is: failed to get cpu resource metric value: failed to get cpu utilization: unable to get metrics for resource cpu: no metrics returned from resource metrics API
23m     Warning  FailedGetResourceMetric    horizontalpodautoscaler/istiod  failed to get cpu utilization: did not receive metrics for any ready pods
23m     Warning  FailedComputeMetricsReplicas  horizontalpodautoscaler/istiod  invalid metrics (1 invalid out of 1), first error is: failed to get cpu resource metric value: failed to get cpu utilization: did not receive metrics for any ready pods


Environment

Aspen Mesh 1.14.x
 

Cause

The warnings are generated because the horizontal pod autoscale feature is not able to communicate with the metrics server.
 

Recommended Actions

Install Kubernetes Metrics Server.
Metrics Server can be installed either directly from YAML manifest or via the official Helm chart. To install the latest Metrics Server release from the components.yaml manifest, run the following command.

kubectl apply -f https://github.com/kubernetes-sigs/metrics-server/releases/latest/download/components.yaml


Additional Information

The Kubernetes Metrics Server collects resource metrics from the kubelets in your cluster, and exposes those metrics through the Kubernetes API, using an APIService to add new kinds of resource that represent metric readings. You can find more information about this feature in this link.
