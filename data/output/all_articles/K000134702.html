Description

You are interested in continuously monitoring client or server system connections on your BIG-IP device using the tmsh command and obtaining timestamps for the connection information. This support solution provides step-by-step instructions to log the command output with timestamps to a file using a loop in the tmsh utility. By following these guidelines, you will be able to effectively track system connections over time, aiding in troubleshooting and performance analysis.

Environment

BIG-IP

Cause

By following these guidelines, network administrators can effectively track system connections over time, aiding in troubleshooting and performance analysis.

Recommended Actions

To continuously run the command "tmsh show sys connection ss-server-addr 10.0.0.1" every 5 seconds on a BIG-IP device and log the output with timestamps to the file "/shared/test," you can use a combination of tmsh, a loop, and the `date` command to generate timestamps.

 

Here's an example command:

 

# while true; do echo "$(date +"%Y-%m-%d %H:%M:%S"): $(tmsh show sys connection ss-server-addr 10.0.0.1)" >> /shared/test; sleep 5; done

 

Explanation of the command:

 

- The `while true` part creates an infinite loop that continues until it is manually interrupted.

- `echo "$(date +"%Y-%m-%d %H:%M:%S"):` generates the current timestamp using the `date` command and formats it as "YYYY-MM-DD HH:MM:SS".

- `$(tmsh show sys connection ss-server-addr 10.0.0.1)` executes the desired tmsh command to show the system connections for the specified server address.

- `>> /shared/test` appends the output of the command, along with the timestamp, to the file "/shared/test".

- `sleep 5` pauses the loop for 5 seconds before repeating the process.

 

With this command, the output of the "show sys connection ss-server-addr 10.0.0.1" command, along with the corresponding timestamp, will be continuously logged to the file "/shared/test" every 5 seconds.

 

Please note that you need appropriate permissions to write to the "/shared" directory. Adjust the file path as needed to match your specific requirements and ensure proper access rights.
