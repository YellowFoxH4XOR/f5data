Known Issue

This is the result of a known issue. The BIG-IP ASM system writes two types of cookies to enforce elements in the security policy: the Main ASM cookie and the ASM Frame cookie. The BIG-IP ASM system writes these cookies using the Max-Age attribute. The Max-Age attribute, defined in RFC 2109, sets the lifetime of the cookie using a delta-seconds value. According to the RFC, after the delta-seconds value has elapsed, the browser should discard the cookie.

Because the Max-Age attribute is loosely interpreted by web browsers, certain web browsers treat the BIG-IP ASM cookie as a persistent cookie. For example, certain browsers ignore the Max-Age attribute and discard the cookie when the browser session is closed, while other browsers interpret the Max-Age attribute differently and store the cookie until the delta-seconds value has elapsed.

Since the ASM cookies are intended to be session cookies, it is not desirable for the browser to save the cookie after the browser session is closed.

Note: The Max-Age attribute is scheduled to be removed from the cookies in a future version of the BIG-IP ASM system.

For an overview about BIG-IP ASM cookies, refer to K6850: Overview of BIG-IP ASM cookies.

F5 Product Development tracked this issue as ID 244682 (formerly CR76316), and it was fixed in BIG-IP ASM 9.4.1. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Workaround

To work around this issue, perform one of the following procedures depending upon the version of BIG-IP ASM that you have installed:

BIG-IP ASM 9.2.0 through 9.2.5, and 9.3.0 through 9.3.1

In BIG-IP ASM 9.2.0 through 9.2.5, and 9.3.0 through 9.3.1 you can set the cookie_max_age by accessing the Internal Parameters page. To do so, perform the following procedure:

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Access the internal parameters page by entering the following URL into your browser, where <address> is the address of your BIG-IP ASM system:

    https://<address>/dms/internal/

  3. Set the cookie_max_age value to 0 (zero).
  4. Click Update.
  5. Restart the BIG-IP ASM unit.

BIG-IP ASM 9.4.0

In BIG-IP ASM 9.4.0, you can set the cookie_max_age by accessing the Advanced Configuration page. To do so, perform the following procedure:

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Click Application Security, then click Options.
  3. Click Advanced Configuration.
  4. Set the cookie_max_age value to 0 (zero).
  5. Click Update.
  6. Restart the BIG-IP ASM unit.
