Description
     gtm_add and bigip_add command freezes after entering password at the password prompt.

Environment

  • GTM to LTM communication for iquery

Cause
MTU issue between the GTM and LTM.

Recommended Actions

  1. On the GTM, lower the MTU on the vlan from 1500 to 1400

Additional Information

After entering the password at the password prompt and hitting enter, the GTM freezes. This is the first point in the connection where the gtm sends a full size packet. If there is an mtu issue, that packet never reaches the ltm and the gtm hangs.
