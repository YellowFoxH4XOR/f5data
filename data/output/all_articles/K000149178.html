K000149178: [APM] Access policy results to errorcode=25, MRHSession cookie value is not followed

Type
Support Solution
Published
2025-01-03
Updated
2025-02-05
Source
https://my.f5.com/manage/s/article/K000149178

Description

APM access policy may result to errorcode=25. For example,  one browser may work and another browser may not. It was noticed that some client app (for instance, browser) may not send the latest MRHSession cookie value.

Environment

  • APM

  • errorcode=25

Cause

The client's app (for instance, browser) is not sending the latest MRHSession cookie value and APM returns errorcode=25 as result.

Answer/Recommended Actions

Make sure that the client's app sends the latest MRHSession cookie value toward APM. As temporal action (in general, not recommended from security perspective), the BIG-IP APM administrator may disable session id rotation functionality (in another words, MRHSession cookie value is not rotated). More info in

K18390492: Security | BIG-IP APM operations guide (go to Session ID rotation)

https://my.f5.com/manage/s/article/K18390492
