K00979312: BIG-IQ - BIG-IP device status ''This device is not available''

Type
Support Solution
Published
2022-09-07
Updated
2025-04-02
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K00979312

Description

One or more BIG-IP devices are showing "This device is not available" (red diamond) in the BIG-IQ GUI: Devices -> BIG-IP Devices

Environment

  • BIG-IQ
  • BIG-IP status "This device is not available"

Cause

BIG-IQ is unable to communicate with BIG-IP

Recommended Actions

  1. Check network connectivity between BIG-IQ and BIG-IP
    telnet <BIG-IP address> 443
  2. Re-establish device trust. Remove Device and re-add to BIG-IQ:
    Select Check box for device to be removed
    Click Remove All Services
    Wait a few minutes for services to be removed from BIG-IQ
    Select Check box for device to be removed
    Click Remove Device

Additional Information

Remove All Services may fail if there are applications (under the Applications Tab).
These Applications will need to be removed before removing services.
If you do not want to remove all the applications, you can reinitiate the trust via REST:
K34941260: How to re-add a managed device into BIG-IQ CM and reinitiate the trust establishment via REST without using the GUI
