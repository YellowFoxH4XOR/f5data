Topic

When you create a security policy and select Automatic for the Policy Building learning mode, you can additionally enable the Fully Automatic option. The Fully Automatic option accepts all learning suggestions that reach a score 100.

Description

When you create a security policy and select Automatic for the Policy Building Learning Mode (without the Fully Automatic option), the system accepts most learning suggestions that reach a score 100. In this mode, learning suggestions that are designated as Manual Accept Only must be manually accepted by the administrator.

Note: A learning suggestion is a recommendation to adjust the security policy based on traffic to the web application. While some suggestions are triggered by innocent traffic, other suggestions are triggered by a violation.

In BIG-IP Advanced WAF / ASM version 15.1.0, you can enable the Fully Automatic option when selecting the Automatic Policy Builder learning mode. The Fully Automatic option accepts all learning suggestions that reach a score 100, even those that normally require manual acceptance by the administrator. This mode is useful when you don't want to spend time reviewing and manually accepting learning suggestions.

For example, a request that generates a HTTP 405 response status code (Method Not Allowed) may produce the following learning suggestion: Add 405 to Allowed Response Codes. If the Policy Building Learning Mode is set to Automatic (without the Fully Automatic option), the suggestion would require manual acceptance by the administrator to be added to the policy. If the Fully Automatic option is enabled, the system automatically accepts the suggestion after it reaches a score of 100.

The following table lists the learning suggestions that the system flags as Manual Accept Only. These suggestions are automatically accepted in Fully Automatic mode after reaching a learning score of 100:
