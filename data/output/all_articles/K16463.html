Topic

This article applies to Inband monitor support for embedded Packet Velocity Acceleration (ePVA) connections. For related articles, refer to the following:

  • K10689: Inband monitors are not compatible with PVA accelerated connections

Summary

The Inband monitor is not compatible with server-side connections that are accelerated by the ePVA chip.

Note: For more information about the ePVA feature, and which BIG-IP platforms contain the ePVA chip, refer to K12837: Overview of the ePVA feature.

Description

With an Inband monitor, the BIG-IP system performs passive monitoring as part of client requests. If you associate an Inband monitor with a pool that services ePVA accelerated connections, the BIG-IP system will no longer use the ePVA chip to accelerate the connections. This situation occurs because the Traffic Management Microkernel (TMM) does not have full visibility of connections that are accelerated by the ePVA chip; therefore, the Inband monitor cannot mark a pool member down when the pool member fails to reply in a timely manner to connection attempts or data request attempts. The pool member will be properly monitored only by a standard monitor applied to the pool member.

Recommendations

When configuring virtual server traffic to use ePVA acceleration, you should consider using other monitor types, such as TCP or HTTP monitors instead of the Inband monitor type.
