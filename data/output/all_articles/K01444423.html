Known Issue

The iControl representational state transfer (REST) application programming interface (API) may fail to respond when fetching a large number of objects.

This issue occurs when all of the following conditions are met:

  • You use the iControl REST API to perform either of the following operations:
     
    • You obtain a large amount of data. For example, you attempt to obtain the list of a 20,000 member pool.
    • You modify a large configuration object. For example, you attempt to load a firewall rule list with 20,000 entries.

Impact

The iControl REST API does not respond.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your iControl REST client receives "HTTP 500 - Internal Server Error" responses when making requests that target large objects.
  • The system logs error messages to the /var/log/icrd file that appear similar to the following example:

    Exception: java.lang.OutOfMemoryError: Direct buffer memory

Workaround

To work around this issue, you can paginate the iControl REST request using Open Data Protocol (OData) $skip and $top query parameters. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. To return a full list of 1000 pool members, use the following iControl REST command syntax:

    curl -s -k --user <user:password> -H "Content-Type: application/json" -X GET https://<IP Address>/<path>

    For example, to return the full listing of 1000 pool members in the pool named example_pool, type the following command:

    curl -s -k --user admin:admin -H "Content-Type: application/json" -X GET https://192.168.10.100/mgmt/tm/ltm/pool/~Common~example_pool/members

  2. To return only the first 100 pool members using OData $skip and $top query parameters, use the following iControl REST command syntax:

    curl -s -k --user <user:password> -H "Content-Type: application/json" -X GET https://<IP Address>/<path>?\$skip=0\&\$top=100

    For example, to return the first 100 pool members in the pool named example_pool, type the following command:

    curl -s -k --user admin:admin -H "Content-Type: application/json" -X GET https://192.168.10.100/mgmt/tm/ltm/pool/~Common~example_pool/members?\$skip=0\&\$top=100

  3. To return the second group of 100 pool members, use the following iControl REST command syntax to add 100 to the $skip parameter's value:

    curl -s -k --user <user:password> -H "Content-Type: application/json" -X GET https://<IP Address>/<path>?\$skip=100\&\$top=100

    For example, to return the second group of 100 pool members in the pool named example_pool, type the following command:

    curl -s -k --user admin:admin -H "Content-Type: application/json" -X GET https://192.168.10.100/mgmt/tm/ltm/pool/~Common~example_pool/members?\$skip=100\&\$top=100

  4. Continue with the remaining eight queries by adding the necessary amount to the OData $skip value. In the previous examples, the $skip amount increases by 100 for each query.
