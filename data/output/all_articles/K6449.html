Topic

The following special characters are allowed in SNMP community strings:

  • (
  • .
  • *
  • /
  • -
  • :
  • _
  • ?
  • =
  • @
  • ,
  • &
  • )
  • %
  • $*

*For BIG-IP 9.x and 10.x, you can use the $ special character only when configuring an SNMP community from the command line. Beginning in BIG-IP 11.0.0, you can use the $ special character when configuring an SNMP community using the Configuration utility.
 

Note: Beginning in 15.1, @ is no longer a usable community string character per ID 932233
