K39021183: Error message: 01020059:3: IP Address :: is invalid, must not be all zeros

Type
Support Solution
Published
2022-12-28
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K39021183

Description

You may notice the similar to the below error message in /var/log/boot.log file

Sep 29 01:16:48 bigip err dhcp_config[20330]: save error: 01020059:3: IP Address :: is invalid, must not be all zeros.
Sep 29 01:16:48 bigip err NET[20566]: dhclient: dhcp-config failed with rc=<1>

Environment

  • BIG-IP

 

Cause

  • This error message due to dhcpv6 being enabled but likely not getting a valid response.

Recommended Actions

disable dhcpv6

modify sys global-settings mgmt-dhcp disabled


 

<Before change>

(tmos)# list sys global-settings

sys global-settings {
    gui-setup disabled
    hostname bigip.local    
    mgmt-dhcp dhcpv6
}

<After change>

(tmos)# list sys global-settings

sys global-settings {
    gui-setup disabled
    hostname bigip.local
}
