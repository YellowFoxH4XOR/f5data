Security Advisory Description

A January 2007 security advisory by Michael Ligh and Greg Sinclair describes several security issues present in some versions of FirePass software. The advisory can be found at the following location:

http://mnin.org/advisories/2007_firepass.pdf

F5 has issued a series of Solutions to address the individual issues contained in the advisory. This overview Solution allows customers to quickly determine which issue in the advisory is addressed by which Solution document, and provides additional information about hotfixes.
