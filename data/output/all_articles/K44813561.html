Description

If BIG-IP provisioned with vCMP, in some cases rsync process on vCMP Host responsible for syncing the imported guest health statistics may exit with failure. 
Due to rsync on the VCMP host exited with failure, VCMP guests on the blade will be restarted. 

You may notice an error message logged in /var/log/ltm file:
err vcmpd[<PID>]: 01510004:3: Guest (<guest_name>): Rsync daemon exited unexpectedly; will restart
err vcmpd[<PID>]: 01510004:3: Guest (<guest_name>): Failure - VM exited unexpectedly.
alert vcmpd[<PID>]: 01510011:1: vCMP guest <guest_name> powered off.
info vcmpd[<PID>]: 01510007:6: Guest (<guest_name>): VS_RUNNING->VS_FAILED
err vcmpd[<PID>]: 01510004:3: Guest (<guest_name>): Failure - VM exited unexpectedly.
  • <PID> is the process ID of vcmpd
  • <guest_name> is the name of the vCMP Guest which is affected.

Environment

  • vCMP

  • BIG-IP 13.1.0.0 through 13.1.0.5

Cause

Bug ID 701449

Recommended Actions

Note: This issue is fixed in BIG-IP V13.1.0.6 or above.
  • Upgrade the vCMP Host to BIG-IP 13.1.0.6 or later.
