K000135377: The modified virtual server is not shown in Wide IPs on Link Controller.

Description

When choosing the Virtual Server on Wide-IP virtual-server member selection list, there is an inconsistency between the Virtual Servers configured on Link Controller LTM module, and the Virtual Servers available to choose on Wide-IP virtual-server list.

Environment

  • BIG-IP Link Controller
  • Virtual Servers in LTM and DNS modules with different parameters

Cause

There is inconsistency between LTM Virtual Servers configured in bigip.conf, and DNS virtual-servers in bigip_gtm.conf file.

LTM Virtual Server was changed (for example: name, IP, port) manually by user, and the changes are not reflected automatically to GTM virtual-servers list of the local datacenter /Common/Default_DC.

Example 1 : same name, different IP for Virtual Servers on LTM and the default local DNS server Default_DC.

/config/bigip.conf 
ltm virtual /Common/VS_example1 {
destination /Common/172.16.0.1:0

/config/bigip_gtm.conf
gtm server /Common/bigip1.example.com {
datacenter /Common/Default_DC
...
monitor /Common/bigip
 product bigip
 virtual-server-discovery enabled
 virtual-servers {
 /Common/VS_example1 {
 destination 192.0.2.1:0
 }

Example 2: Different virtual server names with same IP and service port

/config/bigip.conf 
ltm virtual /Common/VS_example_2 {
destination /Common/192.0.2.2:0

config/bigip_gtm.conf
/config/bigip_gtm.conf
gtm server /Common/bigip1.example.com {
datacenter /Common/Default_DC
...

 /Common/VS_example2 {
 destination 192.0.2.2:0

Recommended Actions

Check and compare the LTM Virtual Server list in bigip.conf with the DNS virtual-servers list in bigip_gtm.conf file for local default datacenter Default_DC.

  • tmsh list ltm virtual
  • tmsh list gtm server

Remove the inconsistent Virtual Server from GTM virtual-server list of datacenter Default_DC.

modify gtm server <server name> virtual-servers delete { /Partition/<VS_NAME> }

For example:

modify gtm server bigip1.example.com virtual-servers delete { /Common/VS_example1 /Common/VS_example2 }

Wait approximately 30 seconds, the affected Virtual Server should be recreated on DNS virtual-servers list automatically in datacenter Default_DC.

Now, it should reflect the same virtual servers configured on LTM module.

And will be available for selection in Wide-IP Virtual Server member selection list.
