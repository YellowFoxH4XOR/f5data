Topic

You should consider using this procedure under the following condition:

  • You want to install and set up Ansible and its pre-requisites software packages on your Linux control host.

Description

Ansible is a tool that you run from a control host to automate configuration management tasks in your server inventory. To use Ansible, you must install Python 2.7 or Python 3.5 or later on your control host. This article is a step-by-step guide to set up your Linux control host to run Ansible with Python3 for the first time.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the Linux control host on which you want to run Ansible.

Procedures

Perform the following procedures to set up Ansible on your Linux control host:

Note: Python 3.5 or later is required for you to use Ansible on your Linux control host. If your host already has the latest Python 3.x version installed, you can skip this procedure.

  • Installing Python3
    • Installing Python 3 on Ubuntu
    • Installing Python 3 on CentOS
  • Installing pip3
  • Installing and creating a virtualenv
  • Installing Ansible

Installing Python 3

You should install the latest Python3 version available in the software repository appropriate to your Linux operating system version. To install Python3, perform one of the following procedure as appropriate for your Linux OS:

Note: Python 3.5 or later is required for you to use Ansible on your Linux control host. If your host already has the latest Python 3.x version installed, you can skip this procedure.

Installing Python 3 on Ubuntu

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Enter the following command to update and refresh repository lists:

    sudo apt update

  2. Enter the following command to install supporting software:

    sudo apt install software-properties-common

  3. Enter the following commands to add the Deadsnakes PPA to install the latest Python version:

    sudo add-apt-repository ppa:deadsnakes/ppa
    sudo apt update

  4. For example, on Ubuntu 18.04, to install Python 3.8 enter the following command syntax:

    sudo apt-get install python<version>

    For example:

    sudo apt-get install python version3.8

  5. Enter the following command syntax to verify your installation:

    /usr/bin/python<version> -V

    For example:

    /usr/bin/pythonversion3.8 -V

Installing Python 3 on CentOS

Note: Python 3.5 or later is required for you to use Ansible on your Linux control host. If your host already has the latest Python 3.x version installed, you can skip this procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system

  1. Update the environment by entering the following command:

    sudo yum update

  2. To add the EPEL repository, enter the following command:

    sudo yum install epel-release

  3. To install Python, enter the following command syntax:

    sudo yum install python<version>

    For example on CentOS 7, to install Python 3.6, enter the following command:

    Note: Running the following command installs the latest Python3 version available in the software repository for your specific CentOS version. For CentOS 7, it is currently Python 3.6. This may change in future.

    sudo yum install python3

  4. Enter the following command syntax to verify your installation:

    /usr/bin/python<version> -V

    For example, if you installed Python 3.6, enter the following command:

    /usr/bin/python3.6 -V

    Note: This command installs Python 3.6 and pip3 on your CentOS system.

Installing pip3

pip is a standard package-management system used to install and manage software packages written in Python.

Installing pip3 on Ubuntu

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • To install pip3, enter the following command:

    sudo apt-get install python3-pip

Installing pip3 on CentOS

If you performed the procedure Installing Python3 on CentOS, pip3 is already installed on your system.

Installing and creating a virtualenv

virtualenv is a tool to create isolated Python environments so that you can run Ansible using the Python versions you want to use.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. To install virtualenv, enter the following command:

    sudo pip3 install virtualenv

  2. To create a virtualenv with the Python version you want, use the following command syntax:

    virtualenv -p /usr/bin/python<version> <example_directory_name>

    For example, for Ubuntu 18.04, enter the following command to create an example virtual environment ansible_env with Python 3.8 as the Python interpreter:

    virtualenv -p /usr/bin/python3.8 ansible_env

    For example, for CentOS 7, enter the following command to create an example virtual environment ansible_env with Python 3.6 as the Python interpreter:

    virtualenv -p /usr/bin/python3.6 ansible_env

  3. Enter the virtual environment by entering the following command:

    cd ansible_env

  4. Activate your virtual environment by entering the following command:

    source bin/activate

    Your shell prompt displays the following or similar:

    (ansible_env) [user@hostname ansible_env] $

  5. Verify your Python version by entering the following command:

    python -V

    Output indicates the Python version you specified in step 2.

Installing Ansible

Perform the following procedure to install Ansible.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. To install Ansible, enter the following command:

    pip3 install ansible

  2. Verify your Ansible installation and the Python version it is using by entering the following commands:

    ansible --version
    ansible-playbook --version

  3. To exit the virtualenv, enter the following command:

    deactivate

Additional Information

After Ansible installs, you are ready to run it. However, depending on your playbook, Ansible may require additional modules to be installed in your virtual environment. For example, if your Ansible playbook manages Vmware vCenter, when you run the ansible-playbook command, you may observe the following error message:

An exception occurred during task execution. To see the full traceback, use -vvv. The error was: ModuleNotFoundError: No module named 'pyVim'
fatal: [<IP address>]: FAILED! => {"changed": false, "msg": "Failed to import the required Python library (PyVmomi) on <hostname>'s Python /root/ansible_env/bin/python. Please read the module documentation and install it in the appropriate location.

In the previous example, the message indicates that the PyVmomi module is not installed in your virtual environment.

To install any additional dependency modules required by your Ansible playbook, use the following command syntax:

pip3 install <module_name>

For example, to install the PyVmomi module, enter the following command:

pip3 install PyVmomi
