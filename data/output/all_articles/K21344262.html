Known Issue

The Endpoint Security Client-Side agent may fail the Last Scan Time Not Older Than antivirus software check.

This issue occurs when all of the following conditions are met:

  • An access policy is configured with a client-side endpoint agent to perform the Last Scan Time Not Older Than antivirus check.
  • A user attempts to establish an access session from a device that is running the Dutch language version of BitDefender Internet Security.

Impact

Users may be denied access to the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The access policy Last Scan Time Not Older Than is evaluated incorrectly for user devices that are running the Dutch language version of the BitDefender antivirus software.
  • When you view a sessiondump of the affected session, the system displays an error message similar to the following example:

    <session id>.session.check_software.last.av.item_2.errors 70 Failed to get 'last_scan'. code: -6 (Object not found) mId: 12 iId: 9
