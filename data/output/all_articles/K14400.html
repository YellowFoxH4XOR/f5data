Known Issue

Attempting to delete multiple Secure Sockets Layer (SSL) certificates may fail.

This issue occurs when all of the following conditions are met:

  • You select the select all check box on the Configuration utility SSL Certificate List page.
  • One or more of the certificates are associated with an SSL profile.

Impact

You cannot delete multiple SSL certificates using the select all check box.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • SSL certificates not associated with an SSL profile are not deleted when using the select all button.
  • An error message in the Configuration utility appears similar to the following example:

    File object by name (/Common/Default.crt) is in use

Resolution

Status

F5 Product Development has assigned ID 414993 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can select the specific SSL certificates that you want to delete. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > File Management.
  3. Click SSL Certificate List.
  4. Select the check box next to the SSL certificates, not associated with an SSL profile, that you want to delete.
  5. Click Delete.
