K000130595: Disabled WideIP still returns IP in DNS response

Type
Support Solution
Published
2023-01-12
Updated
2023-01-12
Applies to
  • BIG-IP
  • BIG-IP DNS: 15.1.6
Source
https://my.f5.com/manage/s/article/K000130595

Description

BIG-IP DNS provides dns responses for a disabled WideIP.

Environment

BIG-IP DNS

Disabled WideIP

Default DNS profile

 

Cause

This is by design. When the WideIP is disabled, it will not match any queries. The default behavior is to send the query to local BIND.

Recommended Actions

1. Create a custom DNS profile and the 'Use BIND Server on BIG-IP' set to disabled. Then apply the custom DNS profile to the listener.

2. Disable the pools in GSLB opposed to the WideIP.

3. Create simple iRule to respond with noerror and attach to the WideIP, opposed to disabling the WideIP. (Disabling the WideIP will not process the iRule)

 

Additional Information

Example iRule to provide noerror for A record requests.

when DNS_REQUEST {
if { [DNS::rrtype] equals "A" } {
noerror
   }
}
