Description

Not seeing reverse DNS look up queries for Bot Defense Protection.

There are no packets seen in the packet capture run on the BIG-IP.

Environment

  • DNS servers access via MGMT route
  • DNS Resolver: 8.8.8.8

Cause

Bot Defense Protections performs DNS reverse look up queries by using the TMM interface.
 

Recommended Actions

Configure a TMM route to be able to reach the desired DNS Resolvers.
 

Additional Information

None.
