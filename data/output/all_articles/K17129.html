Known Issue

The BIG-IP system provisioned with AFM may not respond to the traceroute utility.

This issue occurs when all of the following conditions are met:

  • You have licensed and provisioned the BIG-IP system with the AFM module.
  • The BIG-IP system has a configuration that allows traffic forwarding (forwarding virtual server).
  • You attempt to use the traceroute utility from a client device, in which traffic goes through the BIG-IP forwarding virtual server to a server device.

Impact

The client device running the traceroute utility does not see the BIG-IP system's self IP in the resulting output. This issue is cosmetic, and the BIG-IP system functions correctly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The client traceroute packet reaches the target server device correctly.
  • The client device running the traceroute utility does not see the BIG-IP system's self IP in the resulting output.
