K11953: The BIG-IP system does not pass 'ICMP Unreachable - Fragmentation Needed' packets to nodes when the virtual server is in PVA Assist mode

Known Issue

This is the result of a known issue. The BIG-IP system does not forward ICMP Unreachable - Fragmentation Needed packets to the nodes when the virtual server receiving the ICMP packet is in FastL4 PVA Assist mode. As a result, the BIG-IP system may drop some connections.

Note: This issue has only been observed on PVA Enabled platforms, which include the BIG-IP 3400, 6400, 6800, 8400, and 8800 platforms.

Note: This issue was introduced in BIG-IP version 9.4.8 Hotfix 4 for the 9.4.x branch.

F5 Product Development tracked this issue as ID 338062, and it was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

To work around this issue, you can either disable PVA if you would like the virtual server to continue to use FastL4 profile, or modify the FastL4 virtual server to a standard virtual server.

Disabling the PVA

  1. Log in to Configuration utility with administrator privileges.
  2. Click Local Traffic.
  3. Click Virtual Servers.
  4. Click Profiles.
  5. From the Protocol drop-down menu, select FastL4.
  6. Create a new FastL4 profile by clicking the Create button.
  7. Click on the custom check box for the PVA Acceleration field.
  8. Select None from the drop-down menu.
  9. Save the profile by clicking the Finished button.
  10. Click Local Traffic.
  11. Click Virtual Servers.
  12. From the Virtual Server list, select the Virtual Server in question.
  13. From the Configuration drop-down menu, select Advanced.
  14. Select the FastL4 created in Step 3 for the Protocol Profile (Client).
  15. Save the new profile assignment by clicking Update.

Changing the FastL4 virtual server to standard virtual server

  1. Log in to Configuration utility with administrator privileges.
  2. Click Local Traffic.
  3. Click Virtual Servers.
  4. From the Virtual Server list, select the Virtual Server in question.
  5. From the Type drop-down menu, select Standard.
  6. Save the modification by clicking Update.
