Description
Cipher set string starts with ALL or DEFAULT. If you want to configure custom cipher set which starts with "!", you may configure by inserting the escape "\" character in the beginning from the bash prompt. 

Environment

  • Cipher Set String

Cause

None

Recommended Actions

  1. Configuring cipher set strings start's with  "!" may give you an error, however, the command is successful. 
    Example: 
    [root@x:Active:Standalone] config # tmsh modify ltm profile client-ssl test_ssl ciphers '!SSLv3:!ADH:HIGH:MEDIUM:!RSA'
    Syntax Error: command history is only available in shell mode

    root@(x)(cfg-sync Standalone)(Active)(/Common)(tmos)# modify ltm profile client-ssl test_ssl ciphers '!SSLv3:!ADH:HIGH:MEDIUM:!RSA'
    root@(x)(cfg-sync Standalone)(Active)(/Common)(tmos)# list ltm profile client-ssl test_ssl ciphers
    ltm profile client-ssl test_ssl {
        ciphers !SSLv3:!ADH:HIGH:MEDIUM:!RSA
    }
    Note: The cipher string is updated. 
     
  2. From bash prompt, the command is not successful and to workaround form a bash prompt you may use the escape character. 
    Example: 
    # tmsh modify ltm profile client-ssl test_ssl ciphers '\!SSLv3:!ADH:HIGH:MEDIUM:!RSA'
    [root@x:Active:Standalone] config # tmsh list ltm profile client-ssl test_ssl ciphers
    ltm profile client-ssl test_ssl {
        ciphers !SSLv3:!ADH:HIGH:MEDIUM:!RSA
    }
