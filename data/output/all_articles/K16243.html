Known Issue

Carrier-grade network address translation (CGNAT) translations have a high rate of port reuse when the Large Scale Nat (LSN) pool Persistence Mode setting uses the Address setting.

Impact

The BIG-IP system uses a smaller range of TCP ports for CGNAT translations than what is actually available, causing a higher rate of new connection failures.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Clients experience intermittent connection failures.
  • The BIG-IP system creates new connections using a smaller range of TCP ports than what is available.
