Topic

F5OS-C/A software comprises the Base OS and Service components. The tables in this article list the currently supported versions between the Base OS and Service components, as well as the supported BIG-IP tenant software versions for the different VELOS and rSeries hardware products.

Description

VELOS hardware products

  • VELOS CX1610 (R100) chassis with SX1610 system controllers and BX520 (A119) blade(s)
  • VELOS CX410 (F101) chassis with SX410 system controllers and BX520 (A119) or mix of BX520 (A119) and BX110 (A118) blades
  • VELOS CX410 (F101) chassis with SX410 system controllers and BX110 (A118) blade(s)

In the following tables, the table headings are described as follows:

  • F5OS-C controller supported versions: F5OS-C controller software versions currently supported by the hardware (oldest through newest for each minor branch). Support is limited to the matching set between the Base OS and Service versions. For example, Base OS version 1.8.2 requires and supports only Service version 1.8.2.
  • F5OS-C partition supported versions: F5OS-C partition software versions currently supported by the hardware and F5OS-C controller software versions. Support is limited to the matching set between the partition Base OS and Service versions as well as between the controller and partition software versions. For example, controller version 1.8.2 requires and supports only partition Base OS and Service versions 1.8.2.
  • Supported tenant software versions: BIG-IP tenant software versions supported by the F5OS-C software combinations. For example, BIG-IP tenant versions 17.1.0 through 17.5.1 for the BIG-IP 17.x branch are supported on F5OS-C controller version 1.8.2 and partition version 1.8.2 combination for VELOS CX410 hardware product.
  • AOM: The latest version of AOM firmware supported by the hardware.

Note: F5's signing certificates were rotated in October 2025. As a result of this, some tenant images for versions released prior October 2025 will fail verification on F5OS versions released in October 2025 or later, and F5OS versions released prior to October 2025 may fail to verify some more recent tenant images. For more information, refer to K000157005: F5 signing certificate and key rotation, October 2025.
