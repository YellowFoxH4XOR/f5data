Issue

Error Message

notice mcpd[<pid>]: 01070921:5: Virtual Server '/<partition>/<virtual_server_name>' on partition '<partition>' <user_action> by user '<username>'

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <partition> is the name of the partition on which the virtual server resides.
  • <virtual_server_name> is the name of the virtual server.
  • <user_action> is the user requested action and is either enabled or disabled.
  • <username> is the name of the user performing the action.

For example:

notice mcpd[6251]: 01070921:5: Virtual Server '/Common/example_virtual_server' on partition 'Common' disabled by user 'admin'

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following condition is met:

  • A user changes the state of the virtual server to enabled or disabled.

Impact

This message is a notification of the change in state of the virtual server. Disabling a virtual server prevents the virtual server from accepting new connections. A disabled virtual server will continue to process existing connections, and the virtual address still advertises through Address Resolution Protocol (ARP) and responds to Internet Control Message Protocol (ICMP) requests.

Recommended Actions

If the message indicates the virtual server is disabled, you can enable it using either the Configuration utility or the TMOS shell (tmsh). To do so, perform one of the following procedures:

Using tmsh to enable a virtual server

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Enable the virtual server using the following command syntax:

    modify ltm virtual <virtual_server_name> { <enabled | disabled> }

    For example, to enable the virtual server example_virtual_server, type the following command:

    modify ltm virtual example_virtual_server enabled

Using the Configuration utility to enable a virtual server

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Select the check box next to the virtual server you want to enable.
  4. Click Enable.
