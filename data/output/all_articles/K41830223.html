Known Issue

The No license error counter is not incremented for all license-related traffic drops.

This issue occurs when the following condition is met:

  • The BIG-IP system receives traffic that it is not licensed to process, so the system drops the traffic. An example would be when a system drops Virtual Extensible LAN (VXLAN) traffic because it does not have an SDN license.

For the affected versions, the No license error counter is incremented only for traffic that is dropped due to SSL license limitations. All other license-related traffic drops will not increment the No license error counter.

Impact

Inaccurate No license error counter statistics may make it more difficult to diagnose dropped traffic conditions.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing the No license error counter using the tmsh show sys traffic command, you notice that the counter does not increment for traffic drops that are known to be license-related.
