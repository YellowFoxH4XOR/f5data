K000149277: rSeries host still uses old DNS lookup server IP after changing to a different DNS server IP

Type
Support Solution
Published
2025-01-13
Updated
2025-02-05
Applies to
  • F5OS
  • F5OS-A: 1.7.0, 1.5.1, 1.5.2
Source
https://my.f5.com/manage/s/article/K000149277

Description

After changing DNS lookup server ip on the rSeries host, the unit is still forwarding queries to old DNS server IP.

/etc/resolv.conf output shows newly configured DNS lookup server ip 

Environment

  • rSeries F5OS-A

Cause

This is due to a known issue described in the following ID - Bug ID 1360729: Update of system dns config requires docker restart

Recommended Actions

To resolve this issue one can upgrade to the fixed version - 1.8.0 and later 

To workaround this issue on earlier versions, one can restart the appliance to fully effect the changes.
