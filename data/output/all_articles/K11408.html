Known Issue

This is the result of a known issue. If a managed BIG-IP LTM version 10.0.1 device is licensed for rate shaping and a rate class has been defined, the Enterprise Manager can discover the device, but it may mark the device as Impaired and log error messages to the /var/log/em file. The logged messages depend on the BIG-IP LTM configuration. This behavior is a BIG-IP LTM issue that affects the Enterprise Manager system's ability to discern the true status of the managed device.

If a rate class has been created on the BIG-IP LTM, but has not been assigned to a virtual server, the Enterprise Manager system logs the following error messages:

emdeviced[1925]: 04010538:3: [06dd1bb0] WARNING: 
Dependency Local Traffic / Drop Policy / tail that should be in the Common partition not found
     
emdeviced[1925]: 04010539:3: [06dd1bb0] WARNING: 
Dependency Local Traffic / Drop Policy / tail not found in any partition
     
emdeviced[1925]: 04010538:3: [06dd1bb0] WARNING: 
Dependency Local Traffic / Queuing Discipline / sfq that should be in the Common partition not found
     
emdeviced[1925]: 04010539:3: [06dd1bb0] WARNING: 
Dependency Local Traffic / Queuing Discipline / sfq not found in any partition

Note: These error messages are not reported in the Devices > Details section of the Enterprise Manager Configuration utility.

If a rate class has been created on the BIG-IP LTM system and has been assigned to a virtual server, the Enterprise Manager system logs the following error message:

emdeviced[1925]: 04010568:3: [06dd1bb0] Error found on device 192.168.1.1 
(UID: 43): get change control info: iControl error: 'iControl::OperationFailed - primary code:2(0x2) 
secondary code: 0(0x0) string: bigpipe command '/usr/bin/bigpipe shell' with stdin ' red list  fred 
list  tail list ' returned unexpected number of instances (0)'

Note: This error message is reported in the Devices > Details section of the Enterprise Manager Configuration utility.

The BIG-IP LTM system simultaneously logs the following error message to the /var/log/ltm file:

EX! xcf::XConfigException:'bigpipe command '/usr/bin/bigpipe shell' with stdin ' red list  fred list  tail list ' returned unexpected number of instances (0)' Logged@XConfig.cpp:412::getInstances() Created@LtmClassHandler.cpp:277::getInstances()

F5 Product Development tracked this issue as CR132939 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.
