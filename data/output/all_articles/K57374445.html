Issue

Error Message

info pfmand[<PID>]: 01660009:6: Link: <interface> is <status>

In this error message, note the following:

  • <PID> is the process ID for the pfmand process
  • <interface> is the external interface on the BIG-IP system
  • <status> is the link status for the interface

For example:

info pfmand[6233]: 01660009:6: Link: 1.8 is UP

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • An external interface on a BIG-IP 2000/4000 series platform has experienced a change in link status.

For example, this message can be generated when plugging or unplugging the network cable or when the remote device has gone offline or come online.

Impact

None. This is an informational message.

Recommended Actions

None
