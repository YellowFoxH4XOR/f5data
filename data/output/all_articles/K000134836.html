Description

You want to know the max size limit of the allowed/trusted CA certificates which can be included in the certificate bundle.

 

Environment

  • BIG-IP
  • Certificate bundle

Cause

None

Recommended Actions

There is no specified max size limit for the cert bundle. If you have a lot of text in the bundle it may slow it down at some point as it reads the file for the correct cert - but there is no hard-coded limit.
