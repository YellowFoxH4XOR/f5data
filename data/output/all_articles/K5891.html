Topic

In FirePass versions prior to version 5.5.1, you specified the Citrix ICA Client package location on the Application Access: Terminal Servers: Master Group Settings page.

Starting in FirePass version 5.5.1, you specify the Client ICA Client package location on the the Application Access: Terminal Servers: Global Settings page. Additionally, the Citrix ICA Client package is no longer located on the FirePass controller, although you can upload the package to the FirePass controller.

Configuring the Citrix ICA Client package location

You can specify a location from which a client system can download and install an ICA Citrix Client package: the FirePass controller or a web server. The FirePass client-side component automatically updates the Citrix ICA Client when one of the following two conditions is met:

  • The Citrix ICA Client is not installed on the client system.
  • The client system is using an older version of the Citrix ICA Client than the version you specified.

For information about where to obtain the Citrix ICA Client, refer to your Citrix documentation or visit the Citrix web site at http://www.citrix.com.

To configure the location of the Citrix ICA Client package, perform the following three procedures:

  • Specifying the FirePass controller as the download location
  • Specifying a Citrix website or custom URL as the download action
  • Determining the version of the Citrix ICA Client file


Specifying the FirePass controller as the download location

By default, the Citrix ICA Client package is not located on the FirePass controller. If you designate the FirePass controller as the download location, you must first upload the Citrix ICA Client package to the FirePass controller.

To specify the FirePass controller as the download location, perform the following procedure:

  1. In the navigation pane, click Application Access, Terminal Servers, and then Global Settings.
  2. Locate the FirePass Controller option in the Citrix ICA Client location section of the page.
  3. Click the (click here to install) link or the (click here to reinstall) link to upload the Citrix client to the FirePass controller.

    Depending on your version of FirePass software, a message similar to one of the following three examples appears:

    Please browse for Citrix ICA client .cab or .msi file and click upload:
    Please browse for Citrix ICA client cab file and click upload:
    Please browse for wficac.cab or wficat.cab and click upload:

    Important: Older versions of FirePass software do not support the MSI version of the Citrix ICA client installer. For more information, refer to SOL9305: The Citrix XenApp version 11 client cannot be uploaded to FirePass.
     
  4. Click the Browse button to specify the location of the Citrix ICA Client file.

    Note    : In version 6.0.1 and earlier of FirePass software, the uploaded file must be named wficac.cab or wficat.cab. Starting in version 6.0.2 of FirePass software, there is no filename restriction.
  5. Click the Upload file button to upload the Citrix ICA Client file to the FirePass controller.
  6. In the Version box, use the default setting or specify the Citrix ICA Client version you want to use. For information about determining the version of a Citrix ICA Client, refer to the section Determining the version of the Citrix ICA client file.

    Important:     Do not specify a version later than the one located on the FirePass controller; otherwise, the client system will download and reinstall the Citrix client package each time it connects to the terminal servers.
  7. Click the Update button for your changes to take effect.


Specifying a Citrix website or custom URL as the download location

Use the Citrix web-site or the Custom URL option to have the client system dynamically download and install the Citrix ICA Client package from a web server.

To specify the Citrix website or custom URL, perform the following procedure:

Important: Older versions of FirePass software do not support the MSI version of the Citrix ICA client installer. For more information, refer to K9305: The Citrix XenApp version 11 client cannot be uploaded to FirePass.

  1. In the navigation pane, click Application Access, Terminal Servers, and then Global Settings.
  2. Locate the Citrix web-site option or the Custom URL option in the Citrix ICA Client location section of the page.
  3. In the URL box, specify the URL from which users can download the Citrix ICA Client package.
  4. In the Version box, use the default setting or specify the Citrix ICA Client version you would like to use. For information about determining the version of a Citrix ICA Client, refer to the section Determining the version of the Citrix ICA client file.

    Important: Do not specify a version later than the one located on the web server; otherwise, the client system will download and reinstall the Citrix client package each time it connects to the terminal servers.
  5. Click the Update button for your changes to take effect.


Determining the version of the Citrix ICA Client file

To verify the version of the Citrix ICA Client file, perform one of the following two procedures depending on which version of Citrix ICA Client you are using:

Citrix ICA Client versions 10.2 and later

If you are using the Citrix ICA Client version 10.2 or later, perform the following procedure:

  1. Install the Citrix ICA Client package you are distributing to your users onto a Windows workstation.
  2. Using a text editor, open the following file:%PROGRAMFILES%\Citrix\ICA Client\version.dat
  3. The file contains one line, which is the version of the Citrix ICA Client package.For example:10.100.55836

Citrix ICA Client versions prior to 10.2

If you are using an earlier version of the Citrix ICA Client, perform the following procedure:

  1. Obtain the wficat.cab file (Citrix client package) you are distributing to your users and save it to a Windows workstation.
  2. Double-click the wficat.cab file to view its contents.

    A list of files appears.
  3. In the wficat.inf file, locate the wfica.ocx string. Under the wfica.ocx string, the line starting with FileVersion contains the version of the Citrix ICA Client package.

    For example:

    [wfica.ocx]
    file-win32-x86=thiscab
    clsid={238F6F83-B8B4-11CF-8771-00A024541EE3}
    FileVersion=8,00,24737,0
