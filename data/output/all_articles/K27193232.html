Description

When attempting to load the configuration the following error is encountered and configuration load fails:
01070038:3: Monitor /Common/namedmonitor address type requires a port.

Environment

  • LTM
  • wildcard port (*) port configured for the alias of a monitor

Cause

The port configuration on a monitor is * instead of a specified port number
Bug ID 786517: Modifying a monitor Alias Address from the TMUI might cause failed config loads and send monitors to an incorrect address

Recommended Actions
Manually modify the wildcard port.

The following steps require Advanced Shell (bash) access and expect that you have some knowledge of how to edit configuration files in /config directory on BIG-IP (there are several methods available including vi and nano on the BIG-IP itself).
Warning: F5 does not recommend editing BIG-IP configuration files. However, these steps have been known to be effective in previous instances of this issue.

  1. Edit the bigip.conf
  2. Find the monitor listed in the error message
  3. Find the :* for the alias port and change * to a port number (such as 80 or 443).  it does not have to be *right* as it can be changed to the proper value in the WebUI after the configuration loads.
  4. Save the changes to bigip.conf
  5. Verify the changes with:
    tmsh load /sys config verify
  6. If it has no further errors, load the configuration with:
    tmsh load /sys config
  7. Save the configuration back to disk with:
    tmsh save /sys config partitions all
  8. In some instances the license may need reloaded to clear the webui message that not all configuration objects have loaded with:
    reloadlic
