K000160375: BIG-IQ Centralized Management: "400 Bad Request" Error When Adding BIG-IQ Server to Device Group

Type
Support Solution
Published
2026-03-17
Updated
2026-03-17
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.0
Source
https://my.f5.com/manage/s/article/K000160375

Description

When attempting to create a custom Device Group in BIG-IQ Centralized Management and trying to add the BIG-IQ server itself to the Device Group, the following error message occurs:

The system returned an unexpected error (400 Bad Request). Device not discovered: 9c7b9f0b-6219-4282-9cc6-80ab3ebb1b27

This issue does not occur when adding BIG-IP devices to Device Groups; only the BIG-IQ server is affected.

Environment

  • Product: BIG-IQ Centralized Management
  • Attempted inclusion of BIG-IQ server in Device Group via the DEVICES tab

Cause

The DEVICES tab in BIG-IQ Centralized Management is designed exclusively for managing BIG-IP devices. Attempting to add the BIG-IQ server itself to a Device Group is unsupported and results in a "Device not discovered" error.

Answer/Recommended Actions

  • To configure backup tasks for the BIG-IQ system, use the SYSTEM tab in the BIG-IQ GUI.
  • Do not attempt to add the BIG-IQ server to Device Groups in the DEVICES tab, as this is unsupported and will result in errors.
  • For BIG-IQ system backups, follow the procedures outlined in the SYSTEM tab.

Additional Information

  • This is expected behavior. Device Groups are intended only for BIG-IP device management, not for the BIG-IQ server itself.
