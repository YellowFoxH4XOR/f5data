Description

LocalDB daemon (localdbmgr) log level is controlled by Access Policy log level of default-log-settings, and localdbmgr needs to be restarted to apply log level changes.

Environment

BIG-IP APM

LocalDB AAA Users

Cause

The LocalDB (daemon localdbmgr) log level is controlled by the Access Policy log level of default-log-settings. However, after changing the Access Policy log level, "localdbmgr" needs to be restarted using CLI:

tmsh restart /sys service localdbmgr

Answer/Recommended Actions

To change the localdbmgr log level:

(1) Refer to K24826763: Configuring the BIG-IP APM Logging Levels (12.x and newer) to change Access Policy Log level of default-log-settings (found under: GUI: Access  ››  Overview : Event Logs : Settings => default-log-setting).

(2) From CLI:

tmsh restart /sys service localdbmgr

Note: During this restart, LocalDB authentication will temporarily stop working. F5 recommends performing such a task during a maintenance window.
