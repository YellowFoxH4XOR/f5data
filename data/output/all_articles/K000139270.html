Description

You are using AD authentication to access to the VPN through BIG-IP Edge Client. You noticed that after the first connection the field of the username in the logon page is populated with the username previously entered. You would like the username not to be cached.

Environment

  • BIG-IP APM
  • BIG-IP Edge Client
  • Logon Page
  • Username

Cause

This works by design when option 'Save Servers Upon Exit' is enabled.

Recommended Actions

Currently, the only way to prevent the BIG-IP Edge Client from remembering the prior user session, is to create a customized install of the BIG-IP Edge Client that has the 'Save Servers Upon Exit' check box cleared/disabled (In the Connectivity Profile, click the Win/Mac Edge Client menu, then uncheck the 'Save Servers Upon Exit' box). However once the BIG-IP Edge Client is closed and re-opened, it would prompt for the server name as well. So every time the client is opened, the user would need to enter the server name as well as their credentials.
