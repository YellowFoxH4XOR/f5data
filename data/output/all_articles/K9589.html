BIG-IP Traffic Management Operating System (TMOS) supports installation using a USB CD-ROM drive on the following platforms:

  • BIG-IP 520/540
  • BIG-IP 1500
  • BIG-IP 1600
  • BIG-IP 3400
  • BIG-IP 3600
  • BIG-IP 4500
  • BIG-IP 6400
  • BIG-IP 6800
  • BIG-IP 6900
  • BIG-IP 8400
  • BIG-IP 8800
  • BIG-IP 8900

Note: USB CD-ROM installation is not supported on the BIG-IP 1000, 2400, 5100, 5110, and 4100 series platforms.

To install the BIG-IP TMOS from a USB CD-ROM, perform the following procedure:

  1. Plug in a supported USB CD-ROM.
  2. Log in to the Switch Card Control Processor (SCCP) or Always On Managament (AOM).

    Note: For more information about the SCCP, refer to K3454: Overview of the SCCP. For more information about the AOM, refer to K9403: Overview of the AOM subsystem.

  3. Select the Reboot Host subsystem option.

    Note: This option exists for both SCCP and AOM platforms.

    This step will reboot the system, resulting in a boot from the USB CD-ROM.
  4. Select option 1 from the menu to boot from the USB CD-ROM drive.

    Follow the instructions on the screen.

    Note: BIG-IP 8400 and 8800 platforms may fail to boot to USB CD-ROM.  For more information, refer to K9399: BIG-IP 8400 and 8800 systems may not allow booting from some USB devices.

Once the system has successfully booted, the installation software will prompt you through the installation process. When you have finished the installation and the system has rebooted, you may restore a compatible UCS archive, or configure the system from scratch.

Note: For more information, refer to K3621: Reinstalling BIG-IP LTM,ASM, GTM, PSM, APM, WOM, Link Controller, WebAccelerator, or Edge software.
