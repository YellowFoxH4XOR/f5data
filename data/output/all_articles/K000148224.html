What Happened?

I want to allow only access to the DNS configuration of the F5® Distributed Cloud (XC) Console to one of your users.

Environment

  • F5® Distributed Cloud
  • Users
  • Roles

Resolution/Answer

To only allow DNS access to a user

you first need to find out what type of user the person is:

1. Login to the console for the tenant
2. Go to the Administration workspace

For privileged role:

3. Create a role.
ex: priviledged-dns-access.
4.  Click Allowed API Groups to expand the list of API groups.
5. Select ves-io-infrastructure-write, ves-io-infrastructure-read and ves-io-secrets-read (the last one if for the use of TSIG keys in case needed)
6. Save the mapping

  • If SCIM is enabled, get the object ID for the group and create the group and assign the above-created role. ex: "priviledged-dns-access"
  • If SCIM is enabled the users mapped to the group will be synced to this group.
  • If SCIM is not enabled, assign the created role ("priviledged-dns-access") to the user for the "system" namespace.

For limited role:

1. Create a role - ex: limited-dns-read-access

2. Click on Allowed API Groups to expand the list of API groups

3. Select - ves-io-infrastructure-read

4. Save the mapping

  • If SCIM is enabled, get the object ID for the group and create the group and assign the above-created role. ex: "limited-dns-read-access"
  • If SCIM is enabled the users mapped to the group will be synced to this group
  • If SCIM is not enabled, assign the created role ("limited-dns-read-access") to the user who must have limited access to the "system" namespace.
