Known Issue

The BIG-IP APM Access not found page may use the incorrect style sheet.

This issue occurs when the following condition is met:

  • A user connects to a URL that has an invalid suffix.

Impact

The Access not found page displays the incorrect format.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Access not found page uses the incorrect stylesheet, resulting in incorrect page formatting.
  • While processing access_notfound.inc, the system uses main.css instead of apm.css.
