Topic

You should consider using this procedure under the following condition:

  • You want to disable SSLv3 negotiations for the Configuration utility.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have command line interface access to the BIG-IP system.

Description

Secure Socket Layer (SSL) 3.0 negotiation may take place when an SSLv3-capable client accesses the Configuration utility. If you have security concerns over the SSLv3 protocol, you may want to disable the SSLv3 protocol for the Configuration utility.

Starting with the following BIG-IP versions, you can now disable SSLv3 for the Configuration utility using the tmsh ssl-protocol command:

  • BIG-IP 11.5.0 or later

    Note: SSLv3 negotiation for the Configuration utility has been disabled, by default, in 11.5.4 and 12.0.0.

  • BIG-IP 11.4.1 HF6 or later
  • BIG-IP 11.4.0 HF9 or later
  • BIG-IP 11.2.1 HF13 or later
  • BIG-IP 10.2.4 HF10 or later

Important: If you disable the SSLv3 protocol for the Configuration utility, doing so may impact your ability to establish device trust between peers for BIG-IP systems that are running 11.x software versions earlier than 11.5.0-HF3 and 11.5.1-HF2. If you need to establish device trust for the affected versions, do not proceed until you have successfully set up device trust between the peers. Additionally, the tmsh ssl-protocol option is available only in software versions listed in the previous section of this article, and may result in the configuration failing to roll over when you upgrade to a version that does not support this option. If you plan to upgrade your system, F5 recommends that you upgrade to one of the supported software versions listed in the previous section of this article.

Procedures

Disabling SSLv3 for the Configuration utility

Impact of procedure: When accessing the Configuration utility, all browsers that use the SSLv3 protocol will get immediately disconnected. F5 recommends that you perform this procedure during a scheduled maintenance period.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To disable SSLv3 authentication, type the following command:

    modify /sys httpd ssl-protocol "all -SSLv2 -SSLv3"

    Note: To re-enable the SSLv3 protocol, set ssl-protocol to all -SSLv2.

  3. Save the configuration by typing the following command:

    save /sys config
