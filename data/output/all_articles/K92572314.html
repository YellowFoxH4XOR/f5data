Known Issue

Remote desktop and application tunnel access sessions may fail to establish.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM access profile has an access policy configured with an application tunnel or remote desktop resource.
  • You have configured the access profile with a virtual server that uses a Client SSL profile.
  • In the Configuration utility, the Client SSL profile's Client Certificate option is set to Require.

Impact

Access session users are unable to successfully launch the application tunnel or remote desktop.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to launch an application tunnel or remote desktop from your webtop, the application fails to launch.
  • When viewing network traffic between the BIG-IP APM system and the destination resource while the application is being launched, there is no application-related network communication.

Workaround

To work around this issue, you can configure the access policy to require Client SSL certificates and remove the certificate requirement from the Client SSL profile. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure will remove the Client SSL certificate requirement from the Client SSL profile.

  1. Log in to the Configuration utility.
  2. Navigate to Access Profiles > Access Profiles List.
  3. To the right of the access policy to edit, click Edit.
  4. Click the (+) symbol to the left of the resource assign action to which you want to require a Client SSL certificate.
  5. Click the Authentication tab.
  6. Select On-Demand Cert Auth, and click Add Item.
  7. From the Auth Mode menu, select Require.
  8. Click Save.
  9. Click Finished.
  10. Click Save.
  11. Click Apply Access Policy.
  12. Click Close.
  13. Navigate to Local Traffic > Profiles > SSL Client.
  14. Select the affected Client SSL profile.
  15. In the Client Authentication section, set the Client Certificate option to Request or Ignore.
  16. Click Update.
