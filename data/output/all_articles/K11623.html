Topic

When configuring BIG-IP APM or BIG-IP Edge Gateway to communicate with an Oracle Access Manager (OAM) server, you may want to use a password to authenticate the session. To configure the BIG-IP APM or BIG-IP Edge Gateway device to use a password when communicating with the OAM server, you will need to enable Simple Transport Security Mode. The ability to enable Simple Transport Security Mode is added after installing engineering hotfix 10.2.1707.10. For more information, refer to K11622: Getting started with Oracle Access Manager integration for BIG-IP APM and BIG-IP Edge Gateway.

Note: Starting in BIG-IP APM 10.2.1, a field has been added to the Configuration utility that allows you to set the password when configuring the OAM Simple Mode. BIG-IP APM 10.2.1 users do not need to perform the following procedures.

Configuring the AAA OAM server

  1. Log in to the BIG-IP Configuration utility.
  2. Expand the Access Policy section.
  3. Click on AAA Servers. 
  4. Click Createbutton.
  5. Enter a name for your OAM server in the Name field.
    For example:
    OAM_Server
  6. From the Type drop-down menu, select Oracle Access Manager. 

    Note: Configuration options will display. 
  7. Populate the necessary information in the Configuration section.
  8. Click Finished.

Configuring Simple Transport Security Mode

  1. Log in to the BIG-IP command line.
  2. To use the /usr/bin/pcrypt utility to encode the password to be used between your F5 device and the OAM server, use the following command syntax: 

    Note: This password is set on the OAM server. Reference your OAM user manual for information about configuring the password.

    /usr/bin/pcrypt abcd1234
    U=c[De\RWugP7VUQicj4`ZBNRBh<_@G0W^EX*[cRB3/Dj,L
  3. Enter the bigpipe shell by typing the following command:

    bpsh

    Note: Your command prompt will change to bp>.
  4. Set the password using the hash from step 2 and apply it as a database setting by using the following command syntax: 

    bigpipe db oamserver.globalaccessprotocolpassphrase "U=c[De\RWugP7VUQicj4`ZBNRBh<_@G0W^EX*[cRB3/Dj,L"

    Note: If you receive the The requested BIGdb variable (oamserver.globalaccessprotocolpassphrase) was not found error message, it indicates that the necessary engineering hotfix has not been installed. For more information, refer to K11622: Getting started with Oracle Access Manager integration for BIG-IP APM and BIG-IP Edge Gateway. 
     
  5. Enable simple transport security mode by typing the following command:
    bigpipe db oamserver.transportsecuritymode simple
