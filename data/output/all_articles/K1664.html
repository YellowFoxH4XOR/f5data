Known Issue

This is the result of a known issue. You will receive the following error when you use the Configuration utility to create a new data center and then attempt to modify another data center that is the first data center in alphabetical order.

Error 331781 -- Memory error

F5 Networks Product Development tracked this problem as CR28459, CR28534 and CR41902.

Workaround

To work around this issue, log out of the Configuration utility and start a new session.
