Issue

Note: For information about the requirements to configure RADIUS authentication for the ARX, refer to the Configuring RADIUS section of the CLI Network Management Guide.

When the ARX system is configured to use a RADIUS server for authentication, if the user configuration on the RADIUS server does not contain the Cisco-Account-Info attribute, or if the attribute does not have a valid group defined, the user will not be able to log in to the ARX by way of SSH or Telnet. The ARX system will log an error message in the error.log and syslog files that appears similar to the following example:

AUTH_SSH-0-ERR-MSG3:: error: Radius group not configured at server

Additionally, the client will report a message that appears similar to the following example:

Connection to 172.30.64.208 closed

Note: Clients accessing the ARX Manager GUI will be able to log in, but unable to change any configurations. For more information, refer to K12159: Clients authenticated by RADIUS are able to log in to the ARX Manager GUI but unable to make configuration changes.
