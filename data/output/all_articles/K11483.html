Known Issue

This is the result of a known issue. Regular expressions used for custom patterns within Data Guard may not appear to work.

An issue within the RegExp engine may cause the BIG-IP ASM system to not report any or all valid matches when a valid regular expression is used.

F5 Product Development tracked this issue as ID 222444 (formerly CR119606) and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0, and Hotfix-BIGIP-9.4.8-407.0-HF4 for BIG-IP 9.4.8. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing 10.x hotfixes, refer to K10025: Managing BIG-IP product hotfixes(10.x).

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

Workaround

In some situations, rewriting the regular expression to be more or less specific for the type of pattern to match may help prevent this behavior from occurring.
