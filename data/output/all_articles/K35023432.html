Known Issue

Secure Sockets Layer (SSL) memory corruption may occur when using the Service Name Indication (SNI) feature.

This issue occurs when all of the following conditions are met:

  • Either Client or Server SSL is configured.
  • SNI is used to select a non-default profile.

Impact

The Traffic Management Microkernel (TMM) may restart, causing a disruption in traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Random memory becomes corrupt, causing TMM to produce a core file.
