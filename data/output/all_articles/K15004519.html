Security Advisory Description

The NFSv2 and NFSv3 server implementations in the Linux kernel through 4.10.13 lack certain checks for the end of a buffer, which allows remote attackers to trigger pointer-arithmetic errors or possibly have unspecified other impact via crafted requests, related to fs/nfsd/nfs3xdr.c and fs/nfsd/nfsxdr.c. (CVE-2017-7895)

Impact

When exploited, the NFS vulnerability may allow remote attackers unauthorized access to modify information and disrupt service.

Security Advisory Status

F5 Product Development has assigned CPF-24180 (Traffix) to this vulnerability.
