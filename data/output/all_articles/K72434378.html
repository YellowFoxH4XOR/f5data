Source

Description

After upgrading the BIG-IP device to v15.x, the BIG-IP device command prompt shows 'ipsd down' message. 

tmsh show /sys service all shows following errors

ipsd                      down, waiting for mysql to release running semaphore
logmysqld                 down, waiting for mysql to release running semaphore
monpd                     down, waiting for mysql to release running semaphore
mysql                     down, Failed to initialize MySQL

Environment

  • BIG-IP AFM 
  • Software upgrade to v15.x

Cause

mysql  service is not started properly after upgrade. Hence ipmd and other service mentioned above is shows as down.

Recommended Actions

 After the upgrade perform mcpd forceload and reboot of the device. Refer procedure  K13030: Forcing the mcpd process to reload the BIG-IP configuration
