K000149004: Creation of API Policy fail because special characters were not allowed

Source

Description

The creation of API Policy fails because special characters were not allowed. Encountering the following error message in the asm_config_server.log file:

asm_config_server.pl|ERR|<timestamp>|347|F5::ASMConfig::Handler::log_error_and_rollback,,Failed to parse YAML Open API Content: Traceback (most recent call last):yaml.reader.ReaderError: unacceptable character #x<hex_code>: special characters are not allowed

Environment

  • Adv. WAF.
  • OpenAPI Spec File in YAML format.

Cause

While the OpenAPI Spec file may be encoded in UTF-8, the YAML format itself only permits a limited range of Unicode characters. This range excludes most special characters, including emojis.

Recommended Actions

To resolve the import failure, locate and remove the unsupported character (e.g., the emoji) from the OpenAPI Spec file's description section or any other relevant area. Once the character is removed, attempt to import the file again.
