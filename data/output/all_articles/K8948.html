Known Issue

This is the result of a known issue. When verbose mode is used in policy merge, a message regarding the param_attrib_id key is reported that appears similar to the following example:

The Global Parameter '*' (wildcard) was not modified, but the secondary value differs:
param_attrib_id remained '9' (secondary value = '12')
No Global Parameters were added/changed.

This message may occur when you create a policy using the HTTP and HTTPS Rapid Deployment Templates and then perform a merge.

Note: You can safely ignore this message.

F5 Product Development tracked this issue as CR102239 and it was fixed in BIG-IP ASM 10.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.
