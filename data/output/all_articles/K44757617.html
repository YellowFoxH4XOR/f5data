Known Issue

BIG-IP APM may fail to rewrite URLs during JavaScript execution.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • The web application HTML page executes large external JavaScript.

Impact

Web applications may malfunction or fail to render properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • User requests contain non-rewritten URLs.
  • When using portal access, web applications malfunction or fail to render properly in browsers.
