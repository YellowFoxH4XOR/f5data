K23209210: Not showing Collected HTTP metrics and transactions under Monitoring > Local Traffic > HTTP in BIG-IQ VE 7.0.0

Source

Description

No statistics (Virtual Server names and Chart plots) showing under Monitor > Local Traffic > HTTP in BIG-IQ

Environment

  • BIG-IQ 
  • Target LTM Virtual Servers with HTTP Profile 
  • Target BIG-IP with provisioned AVR module

Cause

Application Statistics Collection was not set up by creating an HTTP Analytics profile and associate to the Virtual Server
 
Recommended Actions

To properly collect statistics of Virtual Servers from managed BIG-IP devices, we have to ensure that those virtual servers have Analytics profiles attached. 
To create an HTTP Analytics profile and associate it to the virtual server, refer to: Setting Up Application Statistics Collection

None.
