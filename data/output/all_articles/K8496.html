Known Issue

This is the result of a known issue. Certain requests may be blocked after importing the security policy to BIG-IP ASM 9.4.2, 9.4.3 or 9.4.4 from a previous version. This can be caused when the imported security policy has a parameter with an allowed metacharacter of null. When this issue occurs, the following violation is logged to the violations screen and the /var/log/asm file:

Illegal meta character in parameter

F5 Product Development tracked this issue as CR94104 and it was fixed in BIG-IP ASM 9.4.5. For information about upgrading, refer to the BIG-IP ASM Release Notes.
