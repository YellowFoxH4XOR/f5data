Description

You get the message "Error 51133, F5 registration key is not compatible with the detected platform." when creating pool for new ELA/FCP base registration key. 

Environment

  • BIG-IQ (license manager) 6.x and later
  • BIG-IQ License Manager or Centralized Manager
  • BIG-IP Virtual Edition (VE)
  • Enterprise License Agreement (ELA)
  • Flexible Consumption Program (FCP)
  • Catalog (CAT) key

Cause

Creating a RegKey Pool is not required when adding an ELA/FCP license. The pool is created automatically upon activation of Catalog Key.

Recommended Actions

  1. Log in to BIG-IQ.
  2. Select Devices.
  3. Go to License Management > Licenses
  4. Select Add License (Do not select Add RegKey Pool).
  5. In License Name, enter a name for your subscription.
  6. In Base Registration Key, paste the Catalog key that F5 emailed to you or download it from MyF5 Subscriptions.
  7. In Activation Method, select Automatic or Manual. 
    Note: To automatically activate the FCP, your BIG-IQ must be configured to traffic to the internet.
