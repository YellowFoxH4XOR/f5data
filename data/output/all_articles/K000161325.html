K000161325: Force Offline not showing if current user is not in Common Partition

Type
Support Solution
Published
2026-05-19
Updated
2026-05-19
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000161325

Description

You cannot force offline the device. The Force Offline button is greyed out under Device Management --> Devices --> Self.

Environment

LTM

Cause

Current logged user is in a different partition.

Answer/Recommended Actions

Make sure that you are in the Common Partition.

The other way to put the device into Forced Offline state, is by running the command below in the CLI.

  1. Login to BIGIP CLI.
  2. Enter commands

        bash

        tmsh run /sys failover offline
