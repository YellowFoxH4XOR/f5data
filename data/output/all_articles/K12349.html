K12349: The ARX virtual server may continue to display Access Control Lists of the source filer after a migration

Topic

The ARX system does not provide an internal Security Account Management (SAM) database; therefore, the namespace proxies all SAM queries to one of its CIFS filers, chosen at random. When migrating shares, if the source and destination filers have local groups defined, the virtual server may continue to show Access Control Lists (ACL) of the source filer. Environments affected by this condition should use the sam-reference option to specify the destination filer as the sam-reference filer.

Note: For information about selecting a sam-reference filer, refer to the Selecting a SAM-Reference Filer section of the ARX CLI Storage Management Guide.
