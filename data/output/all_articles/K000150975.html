K000150975: APM is categorizing a new IPAD running 18.4.1 as a MACOS

Type
Support Solution
Published
2025-04-24
Updated
2025-06-03
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000150975

Description

New iPad 16 version 18.4.1 is classified by the APM as a MACOS instead of IOS device.

 

Environment

BIG-IP APM version 17.X

iPad

 

Cause

User Agent is sent by the iPad , this is expected:

Old iPad: 

Mozilla%2F5.0%20(iPad%3B%20CPU%20OS%2012_5_7%20like%20Mac%20OS%20X)%20AppleWebKit%2F605.1.15%20(KHTML%2C%20like%20Gecko)%20Version%2F12.1.2%20Mobile%2F15E148%20Safari%2F604.1

 

New iPad: 

Mozilla%2F5.0%20(Macintosh%3B%20Intel%20Mac%20OS%20X%2010_15_7)%20AppleWebKit%2F605.1.15%20(KHTML%2C%20like%20Gecko)%20Version%2F18.4%20Safari%2F605.1.15
