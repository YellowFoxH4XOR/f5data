Description

Unlike in the previous version, the new version does not display the actual number of parameters in the ASM event logs when a request exceeds the parameter limit.

 

v16.x or v15.x

Number of total parameters <3> in request (query string and post-data) exceed maximum limitation

 v17.x

Number of parameters in request (query string and post-data) exceeded maximum limitation of <2>.

 

Environment

  • BIG-IP ASM
  • Upgrade from version 15.x. to 17.x

 

Cause

  • The issue is due to changes introduced by the fixes for Bug ID 884945 and Bug ID 1004801 
  • These changes stop parameter parsing when a request exceeds the defined maximum limitation, resulting in the actual number of parameters not being logged.
