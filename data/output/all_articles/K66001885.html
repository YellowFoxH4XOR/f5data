Known Issue

The Application Security report may be missing drilldown information.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM system is configured with partitions.
  • A virtual server configured in a non-default partition is configured with an Application Security Policy.
  • The virtual server has processed traffic.
  • You complete the following steps:
    1. Navigate to Security  >  Reporting  > Application > Charts.
    2. Modify the partition to the non-default partition where the virtual server resides.
    3. Click the Expand Advanced Filters link.
    4. To reference the virtual server in the non-default partition, you configure the Virtual Servers option and click Update.
    5. Click the Export Report link to export the report to a PDF file.

Impact

The PDF report is missing drilldown information.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the exported PDF report, the Requested drilldowns section and virtual server name information is missing.
  • When you view similar exported PDF reports when run from the default (Common) partition, the reports include the Requested drilldowns section and virtual server name information.
