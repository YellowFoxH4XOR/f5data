Description

When creating a VELOS Tenant with Central Manager, after selecting the VELOS provider, the area where sizing is normally displayed with show "Error: Unable to obtain data: SHARED-00001: Internal server error".


Environment

Central Manager with VELOS provider (a partition) configured.


Cause

Central Manager is unable to communicate with the configured VELOS provider.


Reasons can include an IP connectivity issue between Central Manager and the VELOS system, or that the partition on the VELOS system has been disabled after the provider was added.


A less obvious reason is that the default port of 8888 was changed to 443 when initially adding the VELOS provider to Central Manager. While this is a port that Central Manager can authenticate on and therefore consider the provider to be working, it is the wrong port for Central Manager to use when managing the VELOS provider. The appearance is therefore that the VELOS provider has been successfully added, but in practice no Next instance can be created.


Recommended Actions

Configure the VELOS provider to use 8888. Do not change the default port when setting the provider up.
