K000164055: App Tunnel connections respond slowly with APM Clients 7.2.7 through 7.2.7.2

Type
Support Solution
Published
2026-11-02
Updated
2026-11-11
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000164055

Description

After you upgrade to an affected APM Clients version, Application Tunnel resources may respond slowly. For example:

  • SSH takes several seconds to show the password prompt, and each typed character takes 5 seconds or more to appear.
  • Web pages load slowly, and file transfers are slow to start.

Environment

  • BIG-IP APM with Application Tunnel resources
  • APM Clients 7.2.7, 7.2.7.0, 7.2.7.1, or 7.2.7.2

Note: APM Clients 7.2.7.2 is included in BIG-IP 17.5.1.9 through 17.5.1.11, 17.1.3.5 through 17.1.3.7, and 21.1.0.2 through 21.1.0.4.

Cause

Bug ID 2504945. The APM client waits to fill a large read buffer before it forwards data into the tunnel. This delays small, interactive traffic such as SSH.

Recommended Actions

The issue was fixed in the APM client version 7274, please download it from MyF5 Downloads, install it on each BIG-IP APM system. For the details, please refer to K52547540: Updating BIG-IP Edge Client for the BIG-IP APM system.

Note: Please upgrade the Edge Client to the version 7274 too. If the existed Edge Client version is 726x or earlier, you may get upgrade fail issue or other unexpected issue, please perform the fresh installation for the Edge Client 7274.

Note: Upgrading the BIG-IP software alone does not resolve this issue. The fix is in the APM Clients package.

Important: You cannot install an APM Clients image that is older than the System Default image for your BIG-IP version, and client devices do not downgrade automatically. For more information, refer to K01483676.
