Known Issue

Description

The BIG-IP system may have two management IP addresses after you copy the configuration between boot locations.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system has a minimum of two boot volumes.
  • The same static management IP address is configured on multiple boot volumes.

    Note: Dynamic Host Configuration Protocol (DHCP) is not used to add a management IP address.
  • You change the management IP address on the active volume.
  • You copy the configuration from one boot location to another by using one of the methods described in the following articles:
     
    • K14704: Installing a configuration when activating a boot location
    • K14724: Using the cpcfg command to copy a configuration from one boot location to another
  • You boot the BIG-IP system to the non-active boot volume that received the new configuration.

Impact

The BIG-IP system can be accessed unexpectedly by using two different management IP addresses.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When listing the management IP addresses, an unexpected second IP address is present.

Workaround

To work around this issue, you can restart the network service. To do so, perform the following procedure:

Impact of workaround: This procedure will interrupt traffic processing, and should only be performed during a maintenance period.

  1. Log in to the command line of the BIG-IP system.
  2. To restart the network process, type the following command:

    service network restart
