K11136476: ''Managed by BIG-IQ'' not showing on BIG-IP

Type
Support Solution
Published
2022-03-04
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.X.X
Source
https://my.f5.com/manage/s/article/K11136476

Description

BIG-IP device is added and managed by BIG-IQ, but "Managed by BIG-IQ" status is not reflected in BIG-IP GUI.

Environment

  • BIG-IP GUI
  • BIG-IQ CM

Cause

Not known at the point of publication. 

Recommended Actions

  1. From the BIG-IQ CM, remove the affected BIG-IP.
  2. Run command on BIG-IP Bash
    clear-rest-storage
  3. Add BIG-IP to BIG-IQ.
  4. Login BIG-IP GUI to verify "Managed by BIG-IQ" status is reflected.
    or 
    Run the following Bash CLI command to confirm:
    restcurl shared/resolver/device-groups/cm-bigip-allDevices/devices

Additional Information

None.
