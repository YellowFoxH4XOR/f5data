Known Issue

This is the result of a known issue. If you attempt to configure an SMTP server whose hostname starts with a numerical character, the command fails with an error message that appears similar to the following example:

ARX1# config
ARX1(cfg)# smtp
ARX1(cfg-smtp)# mail-server 5mx.example.com

% ERROR: SMTP_MUST_START_LETTER (42139661):
The mailserver string must start with an upper or lowercase letter. This is an invalid string: 1test.example.com

ARX1(cfg-smtp)#

F5 Product Development tracked this issue as ID 35872 and it was fixed in ARX version 5.1.0. For information about upgrading, refer to the ARX release notes.
