Description

Following message appears  in /var/log/messages occasionally:

notice logrotate[XXXX]: ALERT exited abnormally with [1]

Message similar to the following appears in /var/log/ts/cron.log:

asm|INFO|Aug 03 13:10:23.634|xxxxx|,,error: error renaming temp state file /var/lib/logrotate-asm.status.tmp
asm|INFO|Aug 03 20:10:32.960|xxxxx|,,error: error renaming temp state file /var/lib/logrotate-asm.status.tmp
asm|INFO|Aug 05 06:10:36.907|xxxx|,,error: error opening /ts/log//clean_db.log.25.gz: No such file or directory

Environment

  • BIG-IP v13.1.3

Cause

This issue can happen when two instances of logrotate ran at a time that caused tmp file re-named by one instance and the other spit the error.
/usr/share/ts/bin/asm_logrotate is scheduled every 5 min in /etc/cron.d. However sometimes, one instance may take a long time for some reason and next schedule kicks in.

Recommended Actions

Please enable verbose logging to have more detailed info when it occurs next time.

  1. Login to cli, and in bash type in below command:

# mount -o remount,rw /usr

  1. modify /usr/share/ts/bin/asm_logrotate as follow:

a. vi /usr/share/ts/bin/asm_logrotate

b. type in 'i' to enter insert mode, and replace exsting contents with below information. Please copy and paste below contents to your configuration.

#!/bin/bash

LOG_FILE="/ts/log/cron.log"
# redirect standard error and standard output into debug log file,
# with a perl filter to add timestamps to all output
exec 1> >(perl -MF5::Logger -e '$logger = F5::Logger->new(shift); while(<>) { chomp; $logger->info($_); }' "${LOG_FILE}") 2>&1

/usr/bin/logger -t logrotate "DEBUG: start asm logrotate"
/usr/sbin/logrotate -v -s /var/lib/logrotate-asm.status /etc/ts/common/asm_logrotate.conf
EXITVALUE=$?
if [ $EXITVALUE != 0 ]; then
    /usr/bin/logger -t logrotate "ALERT exited abnormally with [$EXITVALUE]"
else
    /usr/bin/logger -t logrotate "DEBUG: completed asm logrotate"
fi
exit 0

c. press ESC to exist insert mode, and input :wq! to save the modification and return to bash.

  1. in bash, type below command:

# mount -o remount,ro /usr

This modifying will tell when it runs and how it finished in /var/log/messages, and vervose output in /var/log/ts/cron.log.

Please contact F5 Techinical Support to open a support case and submit the debug data for analysis.
