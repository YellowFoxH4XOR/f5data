Description

The file /var/local/ucs/config.ucs exists after an upgrade, consuming a lot of space on a device with large configuration.

Is this file safe to delete?

Environment

  • After upgrade
  • Disk space

Cause

None

Recommended Actions

None

Additional Information

This UCS file is completely safe to delete, assuming the upgrade was successful and regular backups are maintained. It is not used after the upgrade.
