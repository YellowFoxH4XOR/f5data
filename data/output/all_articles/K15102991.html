Description
Virtual servers stopped processing traffic after evaluation licenses expired

For example:
  • vCMP Guest getting SSL TPS error messages in /var/log/ltm
  • license command resulted in TPS limit of 0 on vCMP Host
    tmsh show sys license detail | grep -i perf_SSL_total_TP
    perf_SSL_total_TPS :[0]
  • SSL TPS is configured as UNLIMITED
Note: This symptom can also manifest with other licensed features.

Environment
  • Recently licensed product with perpetual and evaluation/time-limited licenses applied
  • Add-on license is expired
    • Error displayed in /var/log/ltm
Cause
ID469724

Recommended Actions
F5 recommends deactivating the evaluation license (before or after it expires) and activating the purchased license by following: K2595: Activating and installing a license file from the command line

This is because, when evaluation and demonstration features expire, features enabled by evaluation and perpetual licenses also expire.  For more information, refer to Bug ID469724.

None at time of publication.
