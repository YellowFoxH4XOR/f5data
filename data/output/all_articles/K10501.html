Known Issue

Note: This issue affects BIG-IP versions 9.4.x and 9.6.x only.

Note: The Configuration utility refers to a class as a Data Group.

This is the result of a known issue. A BIG-IP administrator can successfully create an empty class (a class which contains no elements) using the Configuration utility or the corresponding bigpipe command from the command line. The empty class is created and saved successfully in the bigip.conf file; however, if the configuration is reloaded, the operation fails and the BIG-IP system returns an error message that appears similar to the following example:

BIGpipe class operation error:
01070629:3: No class type was specified for class (<class name>).

F5 Product Development tracked this issue as CR89147 and it was fixed in BIG-IP version 10.0.0. For information about upgrading, refer to the BIG-IP LTM, GTM, Link Controller, ASM, PSM or WebAccelerator release notes.

Workaround

To avoid this issue, ensure that each new class you create contains at least one element.
