Topic

When you use the 3dnsmaint utility to synchronize SSH keys between different devices, 3-DNS opens an SSH connection to the device to transfer the keys. The BIG-IP version 9.x SSH daemon operates only in keyboard interactive mode. The 3dnsmaint SSH client does not use keyboard interactive mode; therefore, 3dnsmaint is unable to make an SSH connection and transfer the keys.

Unlike the 4.x software branch, BIG-IP systems in the 9.x software branch does not require that you synchronize SSH keys when you add a BIG-IP system to a 3-DNS configuration. If you need to synchronize SSH keys between 3-DNS and a BIG-IP version 9.x system for another reason, you must synchronize the keys manually.

Synchronizing keys manually between 3-DNS and BIG-IP version 9.x systems

  1. Log in to the BIG-IP command line.

  2. Change directories to the /var/ssh/root/ directory by typing the following command:

    cd /var/ssh/root/

  3. Generate an SSH key by typing the following command:

    ssh-keygen -t dsa

  4. When prompted to enter a file name for the new key, type a file name of your choice.

    When the key generation completes, a public key and a private key are created.

  5. When prompted to enter a passphrase, press the Enter key without specifying a passphrase.

    Important: Automatic SSH communications, such as the ConfigSync process, will no longer work correctly if you enter a passphrase.

  6. To create a symbolic link to the private key in the /root/.ssh/ directory, use the following command syntax and replace <filename> with the file name you specified for the key in step 5:

    ln -s /var/ssh/root/<filename> /root/.ssh/id_dsa

    For example:

    ln - s /var/ssh/root/mynewkey /root/.ssh/id_dsa

  7. To create a symbolic link to the public key in the /root/.ssh/ directory, use the following command syntax and replace <filename> with the file name you specified for the key in step 5:

    ln -s /var/ssh/root/<filename>.pub /root/.ssh/id_dsa.pub

    For example:

    ln - s /var/ssh/root/mynewkey.pub /root/.ssh/id_dsa.pub

  8. To append the public key that you created to the 3-DNS authorized_keys file, use the following command syntax and replace <address> with the IP address of the 3-DNS Controller:

    cat /root/.ssh/id_dsa.pub | ssh -l root <address> "cat >>/root/.ssh/authorized_keys"

  9. To append the 3-DNS public key to the BIG-IP authorized_keys file, use the following command syntax and replace <address> with the IP address of the 3-DNS Controller:

    ssh -l root <address> "cat /root/.ssh/id_dsa.pub" >>/var/ssh/root/authorized_keys

You should now be able to establish a connect between the BIG-IP version 9.x and the 3-DNS systems without entering a password.

When you open an SSH connection between 3-DNS and BIG-IP version 9.x, you must supply a username, even when the username is the same. To do so, use the following command syntax, replacing <user> with the username and <address> with the IP address of the system to which you want to connect:

ssh -l <user> <address>
