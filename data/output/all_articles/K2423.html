Topic

The higher the number is for the node, the greater the weight/priority is for traffic load balancing. When you create a node, BIG-IP assigns a value of 1 to the node by default. If you have three nodes (two with a value of 5 and one with the default value of 1) and use the Minimum Active Members pool property, BIG-IP only load balances traffic across the servers with the (higher) priority value of 5. If your highest priority group falls below the Minimum Active Members number for that pool, the BIG-IP load balances to the next highest priority group that is above its minimum. So, the server with the weight of 1 would receive traffic only if both servers with the priority weight of 5 were down.

Note: When using ratio and round robin load balancing modes, the servers with a weight of 5 would get five times the amount of traffic load balanced to them than the server with the weight of 1.
