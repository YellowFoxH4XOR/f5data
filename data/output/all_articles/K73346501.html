Known Issue

When you create a pool with a new node, the system always assigns the partition of the pool to that node.

This issue occurs when the following condition is met:

  • You create a node while creating a pool in a partition that is different from the node.

Impact

The system displays the node in the wrong partition.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you create a node while creating a pool, the system sets the partition of the node to one of the pools, regardless of what you specify. For example, after you run the following command, the system assigns the new node to differentpartition:

    root@(v13)(Active)(/differentpartition)(tmos)# create ltm pool my_pool2 members add { /Common/172.16.199.33:0 }

Workaround

To work around this issue, you can create a node separately and then add it to the pool.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
