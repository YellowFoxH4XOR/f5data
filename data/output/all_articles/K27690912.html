Description

Unable to generate the QKView, you have checked the qkview process (K61154426 - running command ps -ef | grep -i [qk]view) but none exist.

When trying to backup the UCS file (using tmsh), you may see the error logs similar to the following.

Unexpected Error: Can't create temp directory, /var/tmp/.config.tmp/eGYdiV, errno 30] Read-only file system
Error during config save.
Unexpected Error: UCS saving process failed.

Once trying to generate the tarball file (using tmsh), you may also see the error logs similar to the following.

tar: Removing leading `/' from member names
tar (child): /var/tmp/test-tarball.tar.gz: Cannot open: Read-only file system
tar (child): Error is not recoverable: exiting now

After trying to force a system file check (K73827442) but the device needs to use the console access. After accessing to the device, it requests to run FSCK command manually.

Environment

  • BIG-IP

Cause

The file system is corrupt.

Recommended Actions

Note: This procedure should be done by using the console access to the device.

  1. Run the following command to force system file check and repair file systems. 
    fsck -y /dev/mapper/vg--*
  2. Reboot the device. 
    reboot

None.
