K11195: The Windows cached credentials are not updated when the Active Directory password is changed

Topic

When a user updates an Active Directory password from the FirePass logon page or the FirePass webtop, the cached credentials are not updated on the Windows client system. For remote users whose workstations are joined to a domain, this means that the password to log in to Windows (the cached password) is different than the password to log in to FirePass (the current Active Directory password).

If users can communicate with the domain controller through a Network Access connection, users can update the cached credentials by performing the following procedure:

  1. Log in to the Windows client system using the cached credentials.
  2. Log in to the FirePass controller.
  3. Launch the Network Access connection which enables communication with the domain controller.
  4. Once the Network Access connection is established, press CTRL+ALT+DELETE.
  5. Select Lock Computer or Lock this computer, depending on the version of Windows running.
  6. Press CTRL+ALT+DELETE again to unlock the computer.
  7. When prompted, enter the current Active Directory password.
    The Windows client caches the current Active Directory password.

Alternately you can also use the F5 Networks VPN client and Windows Logon integration to reset the users password.

Follow the procedure in K8092: Configuring Windows Logon Integration to configure and use Windows Logon integration. Use the users current Active Directory password, and the Windows client cached password will be updated.
