K000130398: AppIq log files are not stored under /var/log/appiq

Type
Support Solution
Published
2023-03-20
Updated
2023-12-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.2.X, 8.2.0
Source
https://my.f5.com/manage/s/article/K000130398

Description

AppIq log files are not stored under /var/log/appiq on CM and DCD after upgrade to 8.2.0


Environment

  • BIG-IQ
  • Log files
  • CM 
  • DCD
  • CLI

Cause

Bug ID 1117597


Recommended Actions


1. After Installing or Upgrading to BIG-IQ version 8.2.0, the following log files are no longer updated or visible under /var/log/appiq:

CM:
configserver.log
queryservice.log
postaggregator.log

DCD:
*agentmanager.log

NOTE: health-calculator.log is not affected by this issue

2. Please follow the workaround on Bug ID 1117597: Appiq logs are not updated or found when using BIG-IQ version 8.2.0

Additional Information

None
