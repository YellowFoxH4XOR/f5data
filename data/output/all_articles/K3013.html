K3013: BIG-IP compliance with Federal Information Processing Standard (FIPS) standard FIPS-197

Topic

Starting in BIG-IP version 4.5.9, AES ciphers are included in the default cipher list; however, to comply with FIPS-197, you must configure BIG-IP to use only the AES ciphers for SSL communication.

For BIG-IP to be FIPS-197 compliant, you must configure each proxy with AES ciphers. You can do this from the command line, or from the Configuration utility.

Command line instructions

To configure BIG-IP to refuse clients that do not negotiate using an AES cipher setting, type the following command:

bigpipe proxy <ip>:<port> clientssl ciphers \"AES\"

Configuration utility instructions

To configure BIG-IP to refuse clients that do not negotiate using an AES cipher setting, perform the following steps:

  1. From the Configuration utility, click Proxies.
  2. Click the link for the Proxy.
  3. Click the Proxy Advanced Properties tab.
  4. Type the following command in the Client Cipher List String box:

    bigpipe proxy <ip>:<port> clientssl ciphers \"AES\"
