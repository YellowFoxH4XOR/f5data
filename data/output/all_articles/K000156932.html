Description

On F5 rSeries (r5000 and 10000 only ) appliances, the port mappings view display fiber ports associated with pipelines using a color codes.

For instance, Pipeline-1 ports are displayed in green; pipeline-2 ports are displayed in purple.

This visual difference can also lead to questions about port status, initialization, or configuration issues on pipeline-2 due to purple color than green.

Environment

  • Product: F5OS - Appliance
  • Hardware: rSeries (specifically r5000 and r10000 series)

Cause

The use of different colors in the port mappings view is intentional for visual differentiation between the pipelines on rSeries 5000 and 10000 platforms.

This is by design and does not indicate any configuration problem, initialization issue, or malfunction.

Recommended Actions

  • The color coding is expected behavior and serves only to distinguish between pipelines.
  • For further details on rSeries pipelines and port mapping visualization, refer to official documentation:
    • rSeries Networking Guide – Pipelines (r5000 and r10000 only) on F5 Cloud Docs
