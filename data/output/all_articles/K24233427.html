Known Issue

The BIG-IP system repeatedly logs the 'notice Oops @ 0x2402248:5157: bad transition' message.

This issue occurs when all of the following conditions are met:

  • There are no specific configuration requirements.
  • Your BIG-IP system actively processes traffic.

Impact

The system repeatedly logs the 'notice Oops @ 0x2402248:5157: bad transition' message.

Note: You can safely ignore this message.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system repeatedly logs the following log message to the /var/log/ltm and/or the /var/log/tmm file:

    notice Oops @ 0x2402248:5157: bad transition

Workaround

In the event of excessive logging, you can modify a BIG-IP system variable to turn off logging of this message. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log on to the Traffic Management Shell (tmsh).
  2. Disable logging of this message by typing the following command: 

    modify /sys db tmm.oops value silent

  3. Save the configuration change by typing the following command:

    save /sys config partitions all

  4. Exit tmsh by typing the following command:

    quit
