Description

No Learning Suggestions generated when Requests are sent using Postman.
 

Environment

  • User-Agent is Postman
  • When browser is used, learning suggestions are seen
  • Default Policy settings 


Cause

In the Learning ad Blocking settings > Policy Building Process section, the option 'Learn only from non-bot traffic' is enabled.

Note: 'Learn only from non-bot traffic' is enabled by default.

ASM is considering requests generated using Postman as bot traffic.
 

Recommended Actions

Disable 'Learn only from non-bot traffic' in Learning and Blocking settings.
 

Additional Information

None.
