Known Issue

In rare conditions, removing a DNS cache may cause the Traffic Management Microkernel (TMM) to produce a core file and restart.

This issue occurs when the following condition is met:

  • You delete a DNS cache from the BIG-IP configuration at the same time the DNS cache is being queried.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from TMM restarting, and systems that are configured as part of a high availability (HA) group may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • If configured for HA, the BIG-IP system fails over to the standby system.
  • The BIG-IP system generates TMM core files to the /shared/core directory, with a time stamp that correlates to the traffic interruption.

Workaround

To work around this issue, you can disable the virtual server that is associated with the DNS cache for 60 seconds before you remove the cache. To do so, perform the following procedure:

Impact of workaround:  The virtual server associated with the DNS cache will temporarily be unable to pass traffic. F5 recommends that you perform this procedure during a maintenance window.

  1. Log in to the BIG-IP Configuration utility as the admin user.
  2. Navigate to Local Traffic > Virtual Servers > Virtual Servers List.
  3. Select the virtual server that is associated with the DNS cache-enabled profile that you want to remove.
  4. Click Disable.
  5. Wait 60 seconds.
  6. Navigate to Local Traffic > Profiles > Services > DNS.
  7. Click the DNS profile that is associated with your DNS cache.
  8. In the DNS Cache section, select Disable.
  9. In the DNS Cache Name section, select Select.
  10. Click Update.
  11. Navigate to Local Traffic > DNS Caches > DNS Cache List.
  12. Select the DNS cache you would like to remove.
  13. Click Delete.
  14. Navigate to Local Traffic > Virtual Servers > Virtual Servers List.
  15. Select the virtual server that is associated with the DNS cache-enabled profile that you previously disabled.
  16. Click Enable.
