Description
'if not' statement returns a TCL error in iRule

You see an error similar to the example below in /var/log/ltm
 TCL error: /Common/example_irule <HTTP_REQUEST> - can't use non-numeric string as operand of "!"     while executing "if { not [HTTP::host] eq "example.com"} { }

Environment

  • BIG-IP LTM
  • Virtual Server
  • iRule

Cause
When using the 'not' operator in an 'if' statement, you need to wrap the compared objects in parenthesis so that the 'not' operator is given a boolean object to negate.

Example:

when HTTP_REQUEST {
    if { not [HTTP::host] eq "example.com"} {
        log local0. "Host [HTTP::host] does not match"
    } else {
        log local0. "Host does match"
    }
}

Recommended Actions

  1. Review /var/log/ltm for TCL errors in your iRule.
  2. Navigate to the iRule in the GUI (Configuration Utility), specified by the error
  3. Add parenthesis around 'if' test objects
when HTTP_REQUEST {
    if { not ([HTTP::host] eq "example.com")} { 
        log local0. "Host [HTTP::host] does not match"
    } else {
        log local0. "Host does match"
    }
}
Note: see Related Content for additional information regarding iRule Operators
