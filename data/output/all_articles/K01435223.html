Description

Unable to import BIGIP config to BIGIQ due to an error message : Conflicts found, import halted

You may see error in the logs at /var/log/restjavad.log as follows:

[ERROR]Conflicts found, import halted
[ERROR]Local Traffic & Network module has not been imported or failed import
[ERROR]Failed to process module tasks for device LTM1.example.com (10.0.0.0); reason: Local Traffic & Network module has not been imported or failed import
 

Environment

  • Importing configurations
  • BIG-IP
  • BIG-IQ 

Cause

When using the new 'multi-device' add in BIG-IQ, we don't get the same conflict resolution popup that we got in previous versions where adding the single device at a time was the only option.

The proper workflow to perform when encountering "Conflicts found, Import halted" is to navigate to Devices >> [Device Name] >> Services >> [Click Import on the conflicted module].

Then a popup showing the objects in conflict with the opportunity to select either BIG-IQ, BIG-IP, or Create Version will be provided. 

Recommended Actions

  1. Enable restjavad debug for further troubleshooting.
  2. Correct the conflict on BIG-IP.
