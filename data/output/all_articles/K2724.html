K2724: Logging data contained in a variable from a rule

Topic

To log iRules variables, you must configure the iRules log section to include the literal syntax of your rule. Place the iRules log section after the "action" section of the rule; that is, the portion of the rule that selects, discards, or forwards a pool.

Note: Expanded iRule variables were not available prior to version 4.5 PTF-06.

For example:

log "some text stuff here" + your_actual_variable + "more text here (or blank space to separate values)"

You must start the log message with quoted text prior to assigning a variable to the log. It is helpful to leave an empty space at the end of the string so that the variable value is not appended directly to the string.

Following are two rule examples and their corresponding log entries. The first example is simple and the second, more complex.

Simple rule example

Rule

Following is a simple rule example:

if (http_host contains "site.com") {
use pool www_pool 
log "matched " + http_host + " by client " +client_addr
}
else {
discard
}

Corresponding log entry

Following is an example of corresponding log entry for the simple rule to log to the /var/log/bigip file. Once you create the rule condition, attach a log statement similar to the following:

Jun 15 12:12:35 shimon kernel: RULE testlogging - matched www.site.com 
by client 172.16.10.201

Complex rule example

Rule

Following is a complex rule example used to parse Windows Media.

rule winmedia9_rule {
if (findstr(tcp_content, <0x63,0x6c,0x69,0x65,0x6e,0x74,0x2d,0x69,0x64,0x3d>,
 10, 200))
{
log "client  " + client_addr + "wmid: " + findstr(tcp_content,
<0x63,0x6c,0x69,0x65,0x6e,0x74,0x2d,0x69,0x64,0x3d>, 10, 200)
+ "  passed"
use pool xpmedia_pool
}
else {
log "${client_addr}  failed "
use pool xpmedia_pool
}
}

This rule eliminates the duplication of writing a log rule separately, by allowing you to use the same findstr() (for this example) variables as the logging variables.

Corresponding log entry

Following is an example of corresponding log entry that the complex rule will log to the /var/log/bigip file. Once you create the rule condition, attach a log statement similar to the following:

Aug  2 12:51:56 erickson32 kernel: RULE winmedia9_rule - client 192.168.14.31 wmid:
1859716044

Note: For more specific instructions about how to create iRules, refer to the iRules chapter of the BIG-IP Reference Guide.
