K12743130: BIG-IQ error message: ''Certificate at IP address x.x.x.x is not trusted. Please verify the host is correct, and set up SSL Certificate Verification settings for the server certificate or one of its trust chain certificates.''

Description

When trying to discover a new device to BIG-IQ you receive a GUI pop-up stating:
Certificate at IP address 10.116.18.82 is not trusted. Please verify the host is correct, and set up SSL Certificate Verification settings for the server certificate or one of its trust chain certificates.

Environment

  • BIG-IQ CM
  • Adding a new device
  • The BIG-IQ has SSL Certificate Verification enabled

Cause

SSL Certificate Verification is enabled and the certificate /config/httpd/conf/ssl.crt/server.crt on the target device has not been imported to the BIG-IQ.

Recommended Actions

There are two options that can resolve this issue.

If SSL validation is not required, disable the Verify Hosts  attribute
    In the BIG-IQ GUI:
        System > SSL CERTIFICATE VERIFICATION 
                Uncheck the box in front of "Verify Hosts"
 
If SSL validation is required import the managed device certificate
  1. Export the device certificate from the BIG-IP(s) that you are trying to add.
        Manual Chapter: Device Certificate Management
  2. Import the device certificate to the BIG-IQ
    BIG-IQ GUI: System >> SSL CERTIFICATE VERIFICATION
  3. Click on "Import"
  4. Upload or paste the certificate that will be trusted by the BIG-IQ
