K28365250: Unable to delete image in rSeries

Type
Support Solution
Published
2022-07-07
Updated
2023-02-21
Applies to
  • rSeries Platforms
  • F5OS
  • F5OS-A: 1.1.X, 1.1.1, 1.1.0
Source
https://my.f5.com/manage/s/article/K28365250

Description

The rSeries system fails to delete unused system ISO in the system management confd CLI with the following error:

For example:
appliance-1(config)# system image remove iso 1.0.1-14867
Error: application communication failure

Environment

  • F5OS-A

Cause

Bug ID 1116185

Recommended Actions

  1. Restart the system_image_agent container by running the following command from an administrative advanced shell ( bash ) session:
    [root@appliance-1 ~]# docker container restart system_image_agent
     

  2. Check that the system_image_agent container is in running status:
    [root@appliance-1 ~]# docker inspect -f '{{.State.Status}}' system_image_agent
    running

Additional Information

None
