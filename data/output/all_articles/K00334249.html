Description
HTTP2 web request fails when going through SSL- Orchestrator explicit proxy with "ERR_HTTP2_INADEQUATE_TRANSPORT_SECURITY" error visible in Web Developer tool.

Environment

  • SSL-Orchestrator versions 13.x through 16.0

Cause
Destination server select none HTTP2 compatible cipher version

Recommended Actions

Upgrade to version 16.1.0 where we introduced support for TLS Application-Layer Protocol Negotiation (ALPN) extension.

Additional Information
To verify that incompatible cipher combination is the issue:

  1. Capture server side TLS handshake and review 'Server Hello' for select cipher.
  2. Check rfc9113 BadCipherSuites list to see if it is supported for HTTP/2 protocol.
