Description

When attempting to add a DNS Logging Profile to a DNS Profile, the following error maybe encountered:

  • 01070734:3: Configuration error: Invalid Devicegroup Reference. The profile_dns (/Common/shared/gtm_dns_profile) requires dns_logging_options (/Common/gtm_dns_logging) to be syncd to the same devices

The following terms are referenced in the error message:

  • "profile_dns" is the name of the DNS Profile being modified
  • "dns_logging_options" is the name of the DNS Logging Profile being configured on the DNS Profile

Environment

The following factors may result in the error message being produced:

  • DNS Express zones are configured under a Sync-Only folder
  • Nameservers are configured under a Sync-Only folder
  • DNS Load Balance Decision Logging is required to be configured

Cause

Because the DNS profile in the sync'd directory is in a different device group to the Logging Profile in another directory, the Logging Profile would not be able to be sync'd to the Peer.

As such, the BIGIP would not be able to reconcile the configuration and returns the error message.


Recommended Actions

The actions or steps required to address the topic covered in the description.

  1.  Re-create the Log Publisher in the appropriate directory
  2. Re-Create the DNS Logging Profile in the appropriate directory.
  3. Add the re-created DNS Logging Profile to the DNS Profile.
