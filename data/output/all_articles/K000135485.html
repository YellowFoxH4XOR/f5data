K000135485: Problem with SMP v1 and SNMPv2c not working on BIG-IQ

Description

You would like to use SNMPv1 or SNMPv2c but even you prepared the configuration on BIG-IQ the monitoring requests don't work.

Environment

  • BIG-IQ
  • SNMP

Cause

The main cause of such problems is the disabled specific version of the SNMP in configuration like on example below:

sys snmp {
    agent-addresses { tcp6:161 udp6:161 }
    allowed-addresses { 127.0.0.0/8 }
    communities {
        /Common/Community1 {
            community-name user1
            source default
        }
    }
    snmpv1 disable            <---
    snmpv2c disable          <---
}

 

Recommended Actions

 

You can use the following commands to check and enable or disable specific versions for SNMP.

 

Please use the following command to display the configuration of the SNMP:

tmsh list sys snmp all-properties
 

Using the command below you can enable the specific version of the SNMP:

tmsh modify sys snmp snmpv1 enable

tmsh modify sys snmp snmpv2c enable

Using the command below you can disable the specific version of the SNMP:

tmsh modify sys snmp snmpv1 disable

tmsh modify sys snmp snmpv2c disable
 

At the end please use following command to save all changes to the configuration:

tmsh save sys config
