Description
Slowness in an application has been detected. When taking a packet capture, packets like next are shown:

   41  14.319785 0.003917 3004 192.168.3.1 → 192.168.3.2 52 38458 8089 TCP OUT s3/tmm5 : [TCP Dup ACK 36#1] 38458 → 8089 [ACK] Seq=1070 Ack=5291 Win=19890
Len=0 SLE=6751 SRE=8211

192.168.3.2 corresponds to an Self IP in the BIG-IP and 192.168.3.1 to a member in a pool. 
 

Environment

  • Production traffic in the BIG-IP

Cause
SACK (Selective Acknowledgments) are in use. This means that BIG-IP received from 6751 to 8211 but not 1-6750

Recommended Actions

Check network between the Self IP and the backend server. This basically means that there are some packet loss in the direction backend server -> Self IP 

Additional Information
TCP Selective Acknowledgments (SACK)
