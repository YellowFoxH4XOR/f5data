Description

F5 AI Security supports the Role Based Access Control (RBAC) feature. By default, F5 AI Security provides the following roles out of the box:

  • Org owner: Only one user can have this role; the creator of the instance.
  • Org admin: This role provides access to all F5 AI Security features and functionalities.
  • User: This role is limited to basic tasks, for example, sending prompts.

You can create a new RBAC role and choosing only specific permissions for the role requirements. The permissions are categorized under the following functions:

  • Organization
  • Guardrails
  • Models
  • Projects (All)
  • Users
  • Campaigns
  • Reports
  • Attack types

You can then either assign the new custom RBAC role to an existing or a new user.

Environment

  • F5 AI Security platform

    Note: The platform URL depends on your deployment; it can be using F5 AI Security Software as a Service (SaaS) or your own on-premises system. If your deployment uses F5 AI Security SaaS, the URLs may either be https://us1.calypsoai.app or https://eu1.calypsoai.app.

  • You have access to an account with either the Org owner or Org admin role.

Cause

None.

Recommended Actions

  • Configuring a new RBAC role
  • Assigning the new custom role to an existing or new user

Configuring a new RBAC role

  1. Login to your F5 AI Security platform with an account that has either the Org owner or Org admin role.
  2. Select Settings from the left menu. The platform presents a page with tabs such as Account, Users, Organization, Custom roles and Integrations.
  3. Select Custom roles.
  4. Select Create custom role located at the top right.

  5. Enter a name for your custom role in the Add name setting.
  6. Select the permissions necessary for your custom role from the various categories. For example, you can custom view only role by selecting the View-only projects from the Projects (All) category, the View-only campaigns from the Campaigns category and the View-only reports from the Reports category.
  7. Save the changes by selecting Save located at the bottom right.

Assigning the new custom role to an existing or new user

  1. Login to your F5 AI Security platform with an account that has either the Org owner or Org admin role.
  2. Select Settings from the left menu.
  3. Select Users.
  4. If you want to assign the new custom role to an existing user, select the ellipsis (three horizontal dots) to the right of that existing user followed by Edit User.

  5. Select the new custom role from the dropdown for the Role setting.

  6. Select Save to save the change.
  7. If you want to assign the new custom role to a new user, ensure you select the new custom role for the Role setting when you invite the new user.
