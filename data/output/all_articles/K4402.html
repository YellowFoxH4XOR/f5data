K4402: Messages logged by the big3d daemon when it starts and stops

Topic

When big3d starts, it logs a message similar to the following to the /var/log/3dns file:
    big3d: STATE: big3d started

Beginning in BIG-IP and 3-DNS version 4.6.3, big3d also logs a message to the /var/log/3dns file when it exits. This message appears similar to the following:

    big3d: STATE: big3d exiting

F5 Product Development tracked this customer requested feature as CR29859 and CR41801.

When you use the bigstart command to start and stop big3d, a message will also be logged in the /var/log/bigip file.
