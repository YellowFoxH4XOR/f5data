Topic

You should consider using this procedure under the following conditions:

  • You want to completely reinstall the BIG-IQ system, including wiping all mass-storage devices, and restoring the BIG-IQ hardware system (for example, BIG-IQ 7000) to the factory defaults.
  • You want to reinstall a BIG-IQ system that no longer boots from any of its boot locations.

Description

On rare occasions, you may be required to perform a clean installation of the BIG-IQ hardware system. During a clean installation, all mass-storage devices are wiped, therefore restoring the BIG-IQ system to its factory defaults. In addition, a clean installation allows you to reinstall a BIG-IQ unit that no longer boots from any of its boot locations.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You can access the BIG-IQ hardware's serial terminal console.
  • You have an MD5 checksum utility that is appropriate for your operating system.

    Note: For additional details on available MD5 checksum utilities, refer to the Supplemental Information section.

  • USB mass storage-based installations require the following, specific prerequisites:
    • A USB mass storage device, at least 2GB in size
    • Physical access to the BIG-IQ system
    • A GNU/Linux system running the 2.6.x kernel, capable of creating a bootable USB thumb drive

      Note: There are several additional requirements that are detailed in K13164: Overview: Creating a Bootable USB Thumb Drive (11.x).

  • USB DVD-ROM-based installations require the following specific prerequisites:
     
    • A USB DVD-ROM drive
    • Writable DVD media
    • Physical access to the BIG-IQ system
  • PXE installations require the following specific prerequisites:
     
    • A workstation that resides on the same network segment as the BIG-IQ system
    • The workstation must be configurable as a PXE server, providing DHCP, TFTP, and HTTP services

Downloading the installation image

You must download and verify the MD5 checksum for the F5 software file transfer from the F5 Download site. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the F5 Downloads site.

    For more information about accessing the F5 download site, refer to K167: Downloading software and firmware from F5.

  2. Download the desired BIG-IQ product ISO image and its corresponding MD5 file.
  3. Verify the MD5 checksum by following the steps detailed in K8337: Verifying the MD5 checksum for the downloaded F5 software file.

    Important: Do not skip step 3; the following procedures do not verify the validity of the file. Continuing with a corrupted ISO image may lead to unpredictable results.

Choosing an installation method

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

You should choose an installation method based on the equipment available to you. Choose one of the following installation methods, which are listed in order of preference:

  • USB DVD-ROM drive

    Note: F5 recommends that you perform a clean installation by using a USB DVD-ROM drive, as this is the simplest and most reliable of all of the installation methods.

  • USB thumb drive
  • PXE server

    The primary advantage of performing a clean installation using a PXE server is that physical access to the BIG-IQ system is not required, and you can do everything remotely. Additionally, using a PXE server can be convenient when you reinstall several systems, as this method allows you to perform several concurrent installations. However, using a PXE server is more complex than the other installation methods. The files essential to setting up the PXE server are included in the product ISO images; you can use these files to manually configure a workstation as a PXE server.

Preparing the installation environment

Prepare the installation environment by performing one of the following procedures:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • Preparing the installation environment using a USB DVD-ROM drive

    Burn the product ISO image to a DVD.

  • Preparing the installation environment using a USB thumb drive

    Create the bootable USB thumb drive using the product ISO file. To do so, perform the procedure in K13164: Overview: Creating a Bootable USB Thumb Drive (11.x).

  • Preparing the installation environment using a PXE server

    The following steps are not exhaustive and you should take them only as an example. The example configurations and commands are specific to Linux operating systems. However, you can set up a PXE server on other operating systems as well. Additionally, F5 Technical Support will not be able to assist you in setting up your own PXE server.

    To configure a workstation as a PXE server, refer to the following guidelines:

    • The workstation you plan to configure as a PXE server must provide TFTP, DHCP, and HTTP services. If it is available to you, the workstation may be a virtual machine. Make sure to position the PXE server on the same network segment as the F5 system's management port.

      Important: Ensure that no DHCP server is already present on the management network. If a DHCP server is already present, configuring a PXE server may interfere with the normal operation of your existing DHCP server, and may cause traffic disruption.

    • The TFTP service must serve the contents of the /tftpboot/X86PC/UNDI/F5 directory, which is included in each product ISO file. Additionally, the tftpd process must support the tsize option. For example, in Debian GNU/Linux, the tftpd package does not support the tsize option, and therefore is not suitable for use in a PXE environment; instead, use the tftpd-hpa package.

      Mount the product ISO file to a directory and then copy the required files to your TFTP root directory.

      For example:

      mount -o loop /root/BIG-IQ-4.6.0.0.0.119.iso /mnt/iso
      cp -Rv /mnt/iso/tftpboot/X86PC/UNDI/F5/* /tftpboot/

    • The DHCP server must be configured with the next-server and filename options. These options define, respectively, the IP address of your TFTP server and the file that the F5 system should retrieve. The following subnet declaration is an example of how the DHCP server should be configured:

      subnet 192.168.1.0 netmask 255.255.255.0 {
      range 192.168.1.100 192.168.1.200;
      option subnet-mask 255.255.255.0;
      option broadcast-address 192.168.1.255;
      next-server 192.168.1.1;
      filename "pxelinux.0";
      }

      F5 assumes in this article that one workstation provides all of the required services (TFTP, DHCP, and HTTP), hence the IP address of the TFTP server (192.168.1.1) is basically that of the DHCP server.

    • The HTTP server must serve the root directory ( / ) of the product ISO file. You may find it convenient to mount the ISO file to a directory, and then place a link to that directory in your www directory.

      For example:

      mount -o loop /root/BIG-IQ-4.6.0.0.0.119.iso /mnt/iso
      cd /var/www/
      ln -sf /mnt/iso/ /var/www/big-iq

Installing the software

To perform a clean installation of BIG-IQ hardware system using PXE or any of the USB removable media installation methods, perform the following procedure:

Impact of procedure: This procedure will destroy all information on the device.

  1. Connect to the BIG-IQ system serial console.

    Important: If you are reimaging a platform that uses the Always-On Management (AOM) subsystem, the serial port baud must match the AOM baud. For more information on AOM, refer to K9403: Overview of the AOM subsystem.

  2. Depending on the type of installation method you have chosen, perform one of the following actions:
    • Connect the USB DVD-ROM drive to the BIG-IQ system and load the disc you burned with the product ISO image.
    • Connect the USB thumb drive to the BIG-IQ system.
    • Ensure that the PXE server is ready, and the required services are running.
  3. Depending on the type of installation method you have chosen, perform one of the following actions:
    • For any of the USB removable media installation methods, reboot the BIG-IQ system. If the BIG-IQ system cannot be rebooted, power cycle the system.
    • For the PXE installation method, access to the console screen that is connected to the BIG-IQ system.

      Power up the BIG-IQ system, press p to go into the one-time PXE boot mode.

      For more information on how to netboot using the platform BIOS, refer to K9599: Configuring AOM based BIG-IP platforms to boot from a network boot server. The BIG-IQ 7000 hardware platform is similar to the BIG-IP 7x00 platform series.

    Note: Upon completion of this step, regardless of the installation method, the BIG-IQ system boots into the Maintenance Operating System (MOS).

  4. The MOS asks you to specify the type of terminal you are using. If you do not know what to specify, press Enter. The default setting (vt100) works for most cases.
  5. If you have booted the BIG-IQ system from a USB removable media containing a BIG-IQ software image, and you want to perform a custom installation using the diskinit and image2disk utilities, press Ctrl+C and continue with step 6.

    Otherwise, to reinstall the system according to the manufacturing installation plan, press Enter and continue with step 9. The default manufacturing installation will only install on the software volume slot MD1.1.

  6. To wipe all mass-storage devices inside the BIG-IQ system, type the following command:

    diskinit --style volumes

    This command will create at least two software installation volume slots on the BIG-IQ system. The software volume slots will be MD1.1 and MD1.2.

  7. The diskinit utility asks whether you want to proceed with wiping the drives.

    To continue and wipe the drives, type y and press Enter.

    If you do not want to wipe the drives, and you want to exit the command, type n and press Enter.

    Important: Confirming this operation destroys all data on the system. Do not proceed with this step if you have data that needs to be recovered from the system. Using the MOS, you may be able to manually mount a partition or volume and recover such data.

  8. To install the software, use the following command syntax according to the chosen installation methods:
    • For any of the USB removable installation methods, use the following command syntax:

      image2disk --nosaveconfig --nosavelicense --instslot=<Volume-Name>

      In the previous syntax, <Volume-Name> refers to the software volume slot name with which you would like to perform the installation.

      For example, to install on MD1.1, type the following command:

      image2disk --nosaveconfig --nosavelicense --instslot=MD1.1

    • For the PXE installation method, use the following command syntax:

      image2disk --nosaveconfig --nosavelicense --instslot=<Volume-Name> http://<Server_IP>/<Path>

      In the previous syntax, note the following:

      - <Volume-Name> refers to the software volume slot name with which you would like to perform the installation.

      - <Server_IP> and <Path>, respectively, refer to the HTTP server IP address and the www directory path that you have set up for the PXE installation method in the previous procedure.

      For example, to install BIG-IQ software on MD1.1 using the HTTP server that is configured in the previous procedure, type the following command:

      image2disk --nosaveconfig --nosavelicense --instslot=MD1.1 http://192.168.1.1/big-iq

    Note: You must specify the --nosaveconfig option, as the system does not have a configuration to save. For more information about the image2disk utility, refer to the Help page by using the image2disk --h command.

  9. Once the installation has completed, complete one of the following steps, depending on the chosen installation methods:
    • For any of the USB removable media installation methods, disconnect the USB removable media from the BIG-IQ system.
    • For the PXE installation method, if you are no longer required to have the PXE server running, you may want to shut down the TFTP, DHCP and HTTP services that are running on the PXE server.
  10. To restart the system, type the following command:

    reboot

    The system boots up to a predefined default software slot from the installation that you have completed.
