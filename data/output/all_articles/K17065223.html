Known Issue

DNS Express may respond to name resolution requests using out of date resource record information.

This issue occurs when all of the following conditions are met:

  • You are using DNS Express to answer DNS name resolution queries for multiple domain names.
  • A zone transfer for one of the DNS domains is failing.

Note: This issue may also affect domains, or zones, that have successfully transferred from the remote DNS name server.

Impact

DNS Express responds to DNS name resolution requests using out of date, or previous, resource record information.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • DNS resolution queries are answered using out of date resource records.
  • Messages log to the /var/log/ltm file every 10 seconds that appear similar to the following example:

    zxfrd[4567]: 0153100e:3: Transfer of zone example1.com failed with rcode (REFUSED).
    zxfrd[4567]: 01531015:3: Failed to retrieve next RR in XFR for zone example1.com.
    zxfrd[4567]: 01531018:3: Failed to transfer zone example1.com from 192.168.10.1, will attempt AXFR.
    zxfrd[4567]: 0153101c:5: Handling NOTIFY for zone example2.com.

Workaround

To avoid this issue, ensure that zone transfers from remote name servers to the local BIG-IP system running DNS express do not fail.
