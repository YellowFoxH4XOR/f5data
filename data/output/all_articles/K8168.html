Known Issue

This is the result of a known issue. If a file is created in the %TEMP% directory on a Windows client system during a user’s FirePass session, and the file has the read-only attribute set, the FirePass Cache Cleaner component does not remove the file after the FirePass session is terminated.

The Cache Cleaner helps prevent information leaks by removing content from the browser cache when users log out. To enable the Cache Cleaner, select the Inject ActiveX/Plugin to clean-up client browser web cache check box on the Users: Endpoint Security: Post-Logon Actions page.

For more information about the read-only file attribute, refer to your Microsoft Windows documentation.

F5 Product Development tracked this issue as CR88119 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

This issue still exists in the FirePass version 5.x branch.

Additionally, Cumulative Hotfix HF-601-9 has been issued for FirePass version 6.0.1 and Cumulative Hotfix HF-602-1 has been issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the Cumulative Hotfix from the F5 Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
