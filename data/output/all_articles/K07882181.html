Description

Your BIG-IP License Manager (LM) is part of the ELA/FCP program.
The BIG-IQ LM registration key has been supplied by F5 Customer Success.
You want to know how to license BIG-IQ License Manager.

Environment

  • BIG-IQ License Manager (LM)
  • ELA/FCP

Cause

Due to an issue being investigated in BUG ID 966253, BIG-IQ's system personality is shown as "BIG-IQ Central Management" even if it is used as a License Manager.
As a result, the license activation and initial setup is slightly different than typically expected.

Recommended Actions

The following will walk you through activating the license for BIG-IP License Manager using the supplied LM registration key, followed by the steps to complete the initial setup:

  1. Log in to BIG-IQ
  2. In the base registration key box, copy and paste the Base registration key of BIG-IQ.
  3. In the Activation Method, select Automatic.
  4. Click on Activate button
  5. In the  End User License agreement box, review and click on Agree
    A text by the side of the Activate button, "license activation completed successfully"
  6. Click on the Next.
    Note: Due to a cosmetic issue, the "System Personality" screen displays 3 options
    • "BIG-IQ Central Manager",
    • "BIG-IQ Data Collection Device" and
    • "BIG-IQ License manager"
However only "BIG-IQ Central Manager" is selectable.
  1. System personality: put a check in BIG-IQ Central Manager, click next at the bottom right of the screen.
  2. Hostname and Management Address: Fill in an FQDN hostname, management IP and management route (only if the management route is not a default route), Discovery address can be set to use management Port. Click Next.
  3. Services: DNS details should be pre-populated along with NTP (time servers), these can be tested by clicking the test button, set your Time zone location. Click next.
  4. Master Key: Check the requirements and type in the Master key and confirmation. Click Next, On the pop-up box click close. Note: Store this password in a location where future teams will have access to it as this is necessary if adding a BIG-IQ standby or data collection device (DCD).
  5. Password: Change admin and root passwords, and Click on next
  6. Launch: Review the data and click on Launch bottom right of the screen.
  7. Pop up box: Restart services, click on the restart button

You will now see a User session terminated pop up box, you can click on Logout.
Refresh the web browser, you will see the BIG-IQ restarting screen, and then the logon screen.

  1. Log into BIG-IQ
  2. System--This Device--Licensing
  3. Review license details.
