Known Issue

The BIG-IP system fails to synchronize SNAT objects during a ConfigSync operation. This issue occurs when one of the following conditions are met:

  • The SNAT object is configured with Automap for its Translation option
  • The SNAT object is configured with a SNAT Pool for its Translation option

This issue does not affect SNAT object configured with an IP address for its Translation option.

Impact

SNAT objects are not correctly synchronized to a high availability peer.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The SNAT object is not synchronized to the peer unit and will not be displayed after a ConfigSync operation
  • The ConfigSync status remains In Sync after the creation of the affected SNAT object

Workaround

To work around this issue, you can manually configure the affected SNAT object on the peer device. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic >> SNATs >> SNAT List.
  3. Click on the Create button.
  4. Type the name of the SNAT object in the Name box.
  5. Select the Translation option configured for the affected SNAT object.
  6. Configure the remaining options as appropriate.
  7. Click on the Finished button to create the SNAT object.
