Description

While navigating to the menu Access ›› API Protection : Profile of the BIG-IP Configuration Utility, you get prompted with the following message:

No API Protection License: All requests will fail and no traffic will pass through

Environment

BIG-IP

APM (Limited) is provisioned

Cause

The feature "API Protection" does require the unit is fitted with a full-fledged APM license.

Recommended Actions

F5Support suggests reaching out to your Account Manager, to get the necessary license, keys or addons.

Additional Information

The unit is very likely licensed with the following module: "APM, Limited": this does enable the "ACCESS" and "API Protection" menus, but this does not enable the "API Protection" feature itself.
