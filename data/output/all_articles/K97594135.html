Description

Purchased add-on module goes missing / unlicensed after license reactivation on the same BIG-IP device. This can happen after RMA.

Environment

  • License reactivation
  • Existing add-on
  • Hardware

Cause
Licensing Server Issue.

Recommended Actions

  1. Contact F5 Technical Support.
  2. F5 Technical Support team will notify you once the issue is resolved.
  3. License must be reactivated again.

None
