Description

TMM generated core and failovered unexpectedly while APM traffic was processed.

 

Environment

  • BIG-IP APM
  • v15.1.8 - v15.1.10

 

Cause

  • Bug ID 1506005

 

Recommended Actions

v15 will be in End of Technical support phase in Dec 2024, so upgrading to fixed version 17.1.2, 16.1.5 and later is recommended

  • K5903: BIG-IP software support policy

 

Additional Information

If this issue occurred on v15.1.10.4.0.26.5, /var/log/tmm has similar to below log when the core is generated.

notice ** SIGSEGV **
...
notice RIP: 0x0000000000aff1d1 EFLAGS: 0x0000000000013202

This is one example, and depending on the version and Engineering hotfix level, the RIP code will be different.
