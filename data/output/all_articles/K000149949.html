Description

Upgrade of Customer Edge (CE) nodes in an F5 Distributed Cloud environment. Questions include expected upgrade duration, potential traffic interruption, and whether upgrades occur in parallel or sequentially across multiple CEs.

Environment

  • Product: F5 Distributed Cloud
  • Scenario: Upgrade of three CE nodes in a cluster

Cause

None

Answer/Recommended Actions

  • Typical upgrade duration for a three-node CE cluster is approximately 30–60 minutes.
  • It is recommended to extend the maintenance window to up to 3 hours to accommodate unexpected issues.
  • During the upgrade:
    • F5 Software upgrade generally does not cause noticeable traffic interruption when completed successfully.
    • Operating System (OS) upgrade may cause brief network interruptions, typically lasting 30–60 seconds.
  • In environments with only control nodes (no worker nodes), the Node by Node Upgrade feature does not apply.
  • No reboot is required to enable the Node by Node Upgrade feature, but it is only relevant for worker nodes.

Additional Information

  • Brief network interruption is expected during the OS upgrade phase.
  • F5 support is available 24/7 for assistance should the CE upgrade not complete correctly.
  • If the Node by Node Upgrade feature is enabled, it only affects worker nodes and not control nodes.
