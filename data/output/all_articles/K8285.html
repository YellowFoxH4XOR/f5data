Known Issue

This is the result of a known issue. When a TCP SYN packet is received for a service that does not exist on a forwarding virtual server, the BIG-IP LTM generates a TCP RST packet with an incorrect ACK value.

F5 Product Development tracked this issue as CR89149. To monitor the status of this CR, refer to the BIG-IP LTM release notes.

Additionally, this issue was fixed in HOTFIX-BIG-IP-9.1.3-HF1 issued for BIG-IP version 9.1.3, for the BIG-IP 9.1 software branch, and in HOTFIX-BIG-IP-9.3.1-HF2 issued for BIG-IP version 9.3.1, for the BIG-IP 9.3 software branch. You may download these hotfixes or later versions of these hotfixes from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about managing F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.
