Known Issue

BIG-IP APM access policy reports may not contain user session geographical location data.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with an access policy.
  • User access requests are processed by the access policy.

Impact

Session geographic location data is intermittently not stored in the BIG-IP APM database.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When running an access policy report, user access information regarding geographic location such as State/Country/Continent codes are not included in the report for user session attempts.
  • When viewing user access session attempts that are logged to the /var/log/apm file, geographical location information for the connections is included in the log entry.
