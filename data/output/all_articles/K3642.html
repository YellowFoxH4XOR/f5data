Topic



For the FirePass Auto-login to applicable Terminal Servers using FirePass user login credentials option to work, the following criteria must be met:

  • The user has an account that is compatible with the terminal server.
  • The user account name is the same for FirePass and the terminal server.
  • The user account password is the same for FirePass and the terminal server.
  • Both FirePass and the terminal server use the same Windows domain for authentication.

If all of these conditions are met and auto-login still does not work, it may indicate that the Terminal Services login configuration for the Windows 2000 or 2003 server is set to Always prompt for password. If this option is enabled, auto-login will not work.

Disabling the "Always prompt for password" option

To disable the Always prompt for password option, perform the following steps on the Windows 2000 or 2003 server:

  1. Click the Start button on the desktop.

  2. Click Administrative Tools.

  3. Click Terminal Services Configuration.

  4. From the menu, click Connections.

  5. Right-click RDP-Tcp.

    The context menu opens.

  6. Click Properties.

  7. Click the Logon Settings tab.

  8. Deselect the checkbox for Always prompt for password.

  9. Click Apply.

Auto-login should now work properly.
