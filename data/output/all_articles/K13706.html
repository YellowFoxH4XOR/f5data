Known Issue

The BIG-IP system may write extraneous log entries to the /var/log/ts/model_layer.log file.

This issue occurs when the following condition is met:

  • The ASM module is licensed and installed on a BIG-IP system
  • The ASM module is not provisioned on the BIG-IP system
  • An Enterprise Manager system manages the BIG-IP system

Impact

Unnecessary log entries may fill the hard disk drive.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system may continually write log entries to the /var/log/ts/model_layer.log file. The log entries will appear similar to the following example:

    23223,-e,F5::Logger::info,,ASM is not licensed/enabled.

Workaround

To work around this issue, you can configure the BIG-IP system to automatically rotate and truncate the log file. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the BIG-IP ASM command line.
  2. Using a text editor, open the /etc/ts/common/asm_logrotate.conf file.
  3. Add the following stanza to the end of the file:

    /ts/log/model_layer.log {
    prerotate
    perl /usr/share/ts/bin/large_file_truncate.pl /ts/log/model_layer.log
    endscript
    compress
    rotate 10
    size=10M
    olddir=/ts/log/
    copytruncate
    }
  4. Save and exit the file.
