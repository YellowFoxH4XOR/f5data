Description:

Error 51139 received when activating the license:

"Unable to grant license key: Error 51139, A valid dossier contains only hexadecimal characters; A-F and 0-9. What appears to be sent in is a F5 Registration Key, not the expected dossier. - A valid dossier contians only hexadecimal characters; A-F and 0-9. What appears to be sent in is a F5 Registration Key, not the expected dossier."

Environment:

  • Licensing
  • BIG-IP  all versions
  • BIG-IQ all versions

Cause:

During the manual activation done from BIG-IP GUI, the Step 1 is to copy dossier that is generated in the system.

Step 2 is  to put the dossier into Activate product page  Activate product

The Base Registration Key has been put instead of dossier in Activate product 

 

Recommended Actions:

 

Follow the manual activation procedure described in the article:

K7752: Licensing the BIG-IP system
