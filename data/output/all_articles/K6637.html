Known Issue

The alternate load balancing method in a pool is not used when topology load balancing fails. When a Local Domain Name System (LDNS) request does not match a BIG-IP GTM topology record, the BIG-IP GTM system uses Round Robin to distribute requests instead of using the Alternate load balancing method specified in the pool.

F5 Product Development tracked this issue as CR69154 and it was fixed in BIG-IP GTM 9.2.4 and 9.3. For information about upgrading, refer to the BIG-IP GTM release notes.

Workaround

To work around this issue you can create an additional topology record that negates the topology statement that you are matching. To do so, use the is not operator in the new topology statement to indicate that the name resolution request does not match the topology statement. You will then need to point the destination of the new topology record to a pool that performs the desired behavior.

For example, the first topology statement below sends LDNS requests originating from the UK to pool."UK_Pool." The second topology statement sends all LDNS requests that do not match the first topology statement to pool."Other_Pool". You would then configure the pool."Other_Pool" topology statement with the desired load balancing method.

pool."UK_Pool" country."UK" 100
pool."Other_Pool" !country."UK" 100
