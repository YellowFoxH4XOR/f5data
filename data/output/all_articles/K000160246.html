K000160246: AD password reset not enforcing password complexity check

Type
Support Solution
Published
2026-03-13
Updated
2026-03-13
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000160246

Description

With AD Auth agent, users are allowed to change their password when it has expired on the AD server. 

When password has expired on AD server, it responds to APM with Kerberos error "KRB5KDC_ERR_KEY_EXP NT Status: STATUS_PASSWORD_MUST_CHANGE". Then APM renders a new logon page back to the user to introduce the new password.

Windows password policies are enforced on Windows server via Group Policy Objects (GPO) at the domain level or via Fine-Grained Password Policies (PSO) for specific users/groups. 
GPO sets a default policy (globalPwdPolicy) for all domain users. 
PSO policies at 'CN=Password Settings Container,CN=System,DC=<domain>' bypasses the default domain policy for those users/groups.

When "Complexity check for Password Reset" is enabled on AD Auth agent, APM fetches those Windows password policies from AD server, stores them in the PSO cache and validates the new password. If succeeds, it sends the new password to AD server (KPASSWD)

Environment

  • BIGIP deployed with APM
  • APM access policy including an AD Auth agent
  • AD Auth agent with "Complexity check for Password Reset" enabled

Causes

  • A Firewall dropping packets to AD server or networking issue
  • PSO cache on APM not matching latest changes on AD server
  • AD server on APM configured with a pool of servers but not all them with the same data
  • Password policy changed on AD server but not yet applied
  • PSO policy is applied to a user which takes precedence over the GPO policy

Recommended Actions

Check these ports are opened between APM and AD servers

88/UDP,TCP (KRB5)
389/TCP (LDAP)
464/TCP (KPASSWD)


Obtain password settings from default GPO policy.
(ie. AD server with ip '10.1.1.1' & 'Administrator' account & 'lab.lan' domain)

ldapsearch -x -H ldap://10.1.1.1 -D "Administrator@lab.lan" -W -b "DC=lab,DC=lan" -s base "(objectClass=*)" maxPwdAge minPwdAge minPwdLength pwdProperties pwdHistoryLength

 

Check if a user account has assigned a PSO policy
(ie. AD server with ip '10.1.1.1' & 'Administrator' account & 'user1' account & 'lab.lan' domain)

ldapsearch -x -H ldap://10.1.1.1 -D "Administrator@lab.lan" -W -b "CN=user1,CN=Users,DC=lab,DC=lan" -s base "(objectClass=user)" msDS-ResultantPSO

 

Obtain password settings from that PSO policy
(ie. AD server with ip '10.1.1.1' & 'Administrator' account & 'lab.lan' domain & PSO policy 'LabTestPolicy')

ldapsearch -x -H ldap://10.1.1.1 -D "Administrator@lab.lan" -W -b "CN=LabTestPolicy,CN=Password Settings Container,CN=System,DC=lab,DC=lan"  msDS-PasswordComplexityEnabled  msDS-PasswordHistoryLength  msDS-MinimumPasswordLength  msDS-MaximumPasswordAge  msDS-MinimumPasswordAge  msDS-PasswordSettingsPrecedence


Once you know the AD password policy to be applied to a user (PSO or GPO), Verify if the new password is compliant. 

password length  (from AD password policy)
minimum age   (from AD password policy)
password complexity   (from AD password policy)

APM follows these rules to make the new password to meet Windows's complexity requirements

Not contain the user's account name or parts of the user's full name that exceed two consecutive characters
Be at least six characters in length
Contain characters from three of the following four categories:
  English uppercase characters (A through Z)
  English lowercase characters (a through z)
  Base 10 digits (0 through 9)
  Non-alphabetic characters (for example, !, $, #, %)


Clear PSO and Kerberos caches from the APM AAA AD server object to force fetching latest password policies from AD server.

Check logs just before 'session.ad.last.errmsg' is dumped to narrow down root cause.

'session.ad.last.errmsg' can be one of these values:

'Your new password must be at least X characters length'
'Your new password must be at least X days old'
'Your new password must be more complex to meet domain password complexity requirements'
