Issue

Error Message

warning tmm[<PID>]: 01010038:4: Syncookie threshold <value> exceeded, virtual = <IP>:<port>

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • <value> is the number of SYN requests observed.
  • <IP> is the IP address of the affected virtual server.
  • <port> is the port number used by the virtual server.

For example:

warning tmm[18415]: 01010038:4: Syncookie threshold 16384 exceeded, virtual = 10.10.10.10:80

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • SYN cookie protection is enabled in the TCP, Fast HTTP, or FastL4 profile associated with the virtual server.
  • The number of new or untrusted TCP connections exceeds the value configured for the System > Configuration > Local Traffic > General > SYN Check Activation Threshold setting.

Impact

SYN cookie protection remains active until the number of new or untrusted TCP connections falls below the low watermark as defined by the pvasyncookies.virtual.invalidthreshold database key. While SYN cookie protection is active, the BIG-IP system creates an entry in the connection table only after receiving an ACK from the client containing the correct encoded secret.

Note: The the pvasyncookies.virtual.invalidthreshold database key was deprecated in BIG-IP version 13.0.0. For more information, refer to Bug ID 692183: Deprecated DB variables .

Recommended Actions

Normal spikes in traffic levels may be enough to trigger this message. You should investigate whether traffic loads are within expected levels or whether the messages are the result of an attack.
