Known Issue

The qkview utility may generate a false "virtual is not a valid entity" error message.

This issue occurs when all of the following conditions are met:

  • The system is provisioned for modules that use BIG-IP Analytics, such as the BIG-IP APM or BIG-IP AFM modules.
  • BIG-IP Analytics is not provisioned.
  • The qkview utility is used to generate a diagnostic file.

Impact

This is a benign error message that can be safely ignored.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H573033 on the Diagnostics > Identified > Low screen.
  • The qkview utility generates an error message in the /var/log/ltm file similar to the following example:

  • err tmsh[PID]: 01420006:3: virtual is not a valid entity.
