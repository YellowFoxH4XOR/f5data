Description

The configuration is not loading in the tenant due to

  • Tenant on F5OS-A/F5OS-C has corrupted vlan names.
  • When reviewing the errors. i.e. by using tmsh load /sys config verify, the name of one or more VLANs has corrupted characters at the end.
  • You may see similar to below error message in /var/log/ltm in tenants.

01070712:3: Internal error, object is not in a folder: type: vlan id: /Common/<vlan_name_over_31>

  • On the F5OS tenants, mcpd, devmgmtd and lind restart in a loop.

 

Environment

  • F5OS-C / F5OS-A
  • Velos / rSeries
  • Tenant with VLAN name is  more than 31 characters.

 

Cause

  • Bug ID 1183901

 

Recommended Actions

Please rename Vlan name no more than 32 (supported maximum 31 characters for vlan name). 

Inside the impacted tenant, manually edit the bigip_base.conf file to replace the strange characters with the correct ones.
