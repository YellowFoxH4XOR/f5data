Description
On GUI, when you try to replace the clientssl profile on a virtual server that has DoH (DNS over HTTPS) server profile, the system presents an error similar to the following

An error has occurred while trying to process your request.

In below example, virtual server virtual vs_doh_listener has configured with DoH (DNS over HTTPS) server profile.

[root@LTM1.example.com:Active:Standalone] # tmsh list ltm virtual vs_doh_listener
ltm virtual vs_doh_listener {
.......
    profiles {
        clientssl {       
            context clientside
        }
        dns { }
        doh-server { }
        http { }
        http2_test {
            context clientside
        }
        tcp { }
    }
}

Environment

  • BIG-IP LTM
  • Virtual server has doh-server profile and clientssl profile.
  • Replace a clientssl profile to other clientssl profile via GUI.

Cause

Bug ID 1041133

Recommended Actions
Use TMSH to change the client ssl profile in virtual server instead of GUI.

  1. Log in to the device using SSH and type the following command for tmsh 
    #tmsh
  2. For example, use below command from TMSH to replace the clientssl profile in virtual server doh_vs profiles to new clientssl profile "new_clientssl"
    [root@LTM1.example.com:Active:Standalone] # tmsh modify ltm virtual doh_vs profiles replace-all-with { dns { context all } doh-server { context all } http { context all } http2 { context clientside } tcp { context clientside } udp { context serverside } new_clientssl { context clientside } }
