Issue

Old Behavior

Prior to BIG-IP 11.0.0, the BIG-IP system restored the configuration either in full or only partially, depending on the host name of the unit on which you installed the user configuration set (UCS) configuration archive.

If the host name of the unit matches the host name stored in the UCS archive, the BIG-IP system restores the full configuration, including self IP addresses and Virtual Local Area Networks (VLANs). If the host name of the unit does not match the host name stored in the UCS archive, the BIG-IP system restores only the shared configuration, such as virtual servers, pools, and profiles.

New Behavior

Beginning in BIG-IP 11.0.0, when installing a UCS configuration archive, the BIG-IP system restores the full configuration.

Due to an architectural change in BIG-IP 11.0.0, the UCS configuration archive is intended for complete configuration backup and restore usage only.

Note: The default configuration will not be restored properly when attempting to rollback to the default configuration from a non-default configuration using a UCS archive. 

F5 Product Development tracked this change as ID 357761.
