Known Issue

Key Exchange Method statistics are not consistent between the TMOS Shell (tmsh) and the Configuration utility.

This issue occurs when all of the following conditions are met:

  • You configure a Client SSL profile with an RSA certificate and assign it to a virtual server.
  • The client connects to the virtual server with the Client SSL profile using Secure Sockets Layer (SSL).
  • You display the statistics in tmsh and in the Configuration utility.

Impact

You observe inconsistent results, which may cause confusion regarding which values are correct.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Configuration utility and tmsh and are inconsistent in reporting Key Exchange Method certificate statistics.

Workaround

To work around this issue, F5 recommends that you use tmsh when gathering Key Exchange Method certificate statistics.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
