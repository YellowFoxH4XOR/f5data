Description
You are trying to determine which vCMP host system a guest is deployed on.

Environment

  • vCMP dedicated host with guests

Cause
None

Recommended Actions

  1. In the /config/bigip_base.conf you can see the host serial number under "cm device <DeviceName>"

    cm device /Common/<DeviceName>
        chassis-id xxxxxxxxx
    You can use the chassis-id to identify the host serial number
        
    # tmsh list /cm all-properties | grep -i "chassis-id"

Additional Information
Unfortunately you cannot identify the host device name or management IP at this time.
