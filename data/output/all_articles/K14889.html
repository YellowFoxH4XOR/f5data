Issue

Error Message

Instance not found:/Common/<client|server>ssl

In this error message, note the following:

  • <client|server>ssl is the SSL profile type that you want to create. The possible values are clientssl or serverssl.

For example, if you attempt to create a Client SSL profile from the Configuration utility by clicking Local Traffic > Profiles > SSL, the following error message appears:

Instance not found:/Common/clientssl

If you attempt to create a Server SSL profile, the following error message appears:

Instance not found:/Common/serverssl

Message Location

You may encounter this message in the following location:

  • The Configuration utility

Description

This message occurs when all of the following conditions are met:

  • The BIG-IP system is provisioned only with the BIG-IP AFM module or BIG-IP GTM module.
  • You have not yet provisioned the BIG-IP LTM module on the BIG-IP system, or you do not have the appropriate license coverage.
  • You attempt to create a Client SSL or Server SSL profile from the Configuration utility by clicking Local Traffic > Profiles > SSL.

Depending on the license that you purchase, the BIG-IP license may contain one or more BIG-IP modules. For example, if you purchase a BIG-IP license for BIG-IP AFM and BIG-IP LTM modules, but you provision the license for only the BIG-IP AFM module, attempts to create an SSL profile are flagged with the error message.

Impact

You cannot create a Client SSL or Server SSL profile.

Recommended Actions

If the BIG-IP license contains the BIG-IP LTM module, provision the BIG-IP LTM module.

If the BIG-IP license does not contain a valid key for the BIG-IP LTM module, you are required to purchase the BIG-IP LTM module license key and provision it on the BIG-IP system before you can create an SSL profile.
