Known Issue

VIPRION systems may experience an active-active traffic group when the traffic group's Auto Failback option is enabled.

This issue occurs when all of the following conditions are met:

  • You have multiple VIPRION systems in a high availability (HA) configuration.
  • You have one or more traffic groups with the following configuration:
    • The Failover Method setting is set to HA Order.

      Note: By default, the Failover Method setting is set to Load Aware.

    • The Auto Failback option is set to Enabled.

      Note: By default, the Auto Failback option is set to Disabled.

Impact

An active-active traffic group may cause traffic processed by the VIPRION system to fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Connections processed by the VIPRION systems randomly fail.
  • Both VIPRION systems log error messages simultaneously to the /var/log/ltm file that appear similar to the following example:

    notice sod[5678]: 010c007e:5: Not receiving status updates from peer device /Common/example.com (192.168.10.100) (Disconnected).
    notice sod[5678]: 010c006d:5: Leaving Standby for Active: Next Active, peers agree on config.
    notice sod[5678]: 010c0053:5: Active for traffic group /Common/traffic-group-1.
    notice sod[5678]: 010c0019:5: Active

Workaround

There is no workaround for this issue. To avoid this issue, do not enable the Auto Failback option on VIPRION systems.
