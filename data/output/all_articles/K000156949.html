Description

Wafw00f is an open-source project to identify and fingerprint Web Application Firewall (WAF) products.

Environment

Adv.WAF

Cause

The tool in question fingerprint our WAF by the cookie naming pattern, as well as the default response string when a request is blocked.

Recommended Actions

  • Use the steps in K54501322 to modify the ASM cookie names.
  • Avoid using the default response body that the system delivers when a request is blocked.
