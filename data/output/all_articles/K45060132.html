Description

$SNAT_IP and $SNAT_PORT value in Request Settings of Request Logging profile is not logged at the first request because that information has not been determined at the time of processing the first request.

Environment

  • $SNAT_IP and/or $SNAT_PORT is used in Request Settings of Request Logging profile

Cause

$SNAT_IP and $SNAT_PORT value has not been determined at the time of processing the first request.

Recommended Actions

Set SNAT_IP and SNAT_PORT in Response Settings field of Request Logging profile.

Additional Information

None.
