Topic

Prior to deploying BIG-IP APM Portal Access profiles for applications using JavaScript, you should review the application's JavaScript coding.

Description

BIG-IP APM Portal Access uses a rewrite engine to process JavaScript between the application and the access session user (reverse proxy). Some browsers are tolerant of non-conforming and incorrect JavaScript code syntax; however, the rewrite engine, when parsing this code, does not correct JavaScript coding errors and may interpret or rewrite code in an unintended manner, ultimately affecting the end user's ability to interact with the application.

Recommendations

When planning to deploy the BIG-IP APM Portal Access feature for applications that use JavaScript, ensure that your application does not include certain types of JavaScript coding errors. To do so, perform the following tasks:

  • Review the JavaScript code for completeness and conformity to JavaScript coding standards.
  • Ensure that the JavaScript code does not contain logic or object reference type errors.
  • Ensure that the JavaScript code does not have syntax errors.
