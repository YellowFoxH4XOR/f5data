Known Issue

This is the result of a known issue. The Dashboard utility monitors overall system performance and performance of specific modules on the BIG-IP system. Using the Dashboard utility causes a memory leak in the mcpq process. For example, if you open the BIG-IP Configuration utility and navigate to Overview > Performance > Dashboard, and leave the screen open, the mcpq process begins to consume an excessive amount of memory.

F5 Product Development tracked this issue as CR128312 and it was fixed in BIG-IP version 10.1.0.  For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WOM release notes.
