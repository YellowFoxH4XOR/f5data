K000161229: BIG-IP Appliance Fails to Boot Due to Hard Drive Errors

Type
Support Solution
Published
2026-07-15
Updated
2026-07-15
Source
https://my.f5.com/manage/s/article/K000161229

Description

 A BIG-IP appliance fails to boot into the operating system after a reboot attempt.  After connected to console, the system enters GRUB rescue mode and displays repeated ATA disk read errors:

[13610705.363798] ata1.00: exception Emask 0x0 SAct 0x0 SErr 0x0 action 0x0
[13610705.403913] ata1.00: irq_stat 0x40000001
[13610705.428958] ata1.00: failed command: READ DMA
[13610705.456590] ata1.00: cmd c8/00:01:6c:b6:05/00:00:00:00:00/e0 tag 2 dma 512 in
[13610705.456590]     res 61/04:00:6c:b6:05/00:00:00:00:00/e0 Emask 0x1 (device error)
[13610705.549217] ata1.00: status: { DRDY DF ERR }
[13610705.576327] ata1.00: error: { ABRT }

Environment

  • BIG-IP i2X00
  • Reboot

Cause

 Possible physical hard drive failure.

Answer/Recommended Actions

  1.  Attempt to Run End-User Diagnostics (EUD):
    • If possible, use a bootable USB drive to run EUD. This can help confirm hardware failure, especially if the internal drive is inaccessible or the EUD option is missing from the boot menu.
    • Refer to F5 documentation for instructions:  K7172: Overview of the End User Diagnostics software
  2. Please open a support case with F5 Support and provide the EUD result to the case.

Additional Information

None.
