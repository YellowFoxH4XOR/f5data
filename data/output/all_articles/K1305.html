K1305: Accessing the BIOS on a BIG-IP 2000 and BIG-IP 5000 switch appliances

Topic

If Quiet Boot is enabled on your system (that is, you see only the System is Booting... prompt when rebooting the system), press the S key while rebooting the unit. This opens the BIOS.

Important: You need to press the S key very quickly. It may take a few attempts to get the timing down.

If your system is not using Quiet Boot, you see the BIOS information screen, the memory check, and then a prompt to press the S key to enter the BIOS. Press the S key at this time to enter the BIOS.
