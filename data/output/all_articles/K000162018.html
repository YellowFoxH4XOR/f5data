K000162018: No RST packets are sent out even though "service-down-action reset" is configured on pool and monitor is marked down.

Type
Support Solution
Published
2026-07-01
Updated
2026-07-01
Applies to
  • BIG-IP
  • BIG-IP LTM: 21.1.0
Source
https://my.f5.com/manage/s/article/K000162018

Description

When "service-down-action" is set to "reset" (default "none") on pool, BIG-IP sends RST packets out to both client and pool member after monitor is marked down. However, on BIG-IP v21.1.0, no RST packets are sent out even though pool monitor is marked down.

 

Environment

  • Pool "service-down-action" ("Action On Service Down" on GUI) parameter is set to "reset (Reject)".
  • Running BIG-IP v21.1.0. No other software versions are known to be affected, at the time of article publication.

 

Cause

Bug ID2311013.

 

Answer/Recommended Actions

If "service-down-action" must be set to "reset" and an immediate fix is required, contact F5 Support to request an Engineering Hotfix (EHF) for your specific version.

 

Additional Information

None.
