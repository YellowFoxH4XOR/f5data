K000149998: Unable to set an idle timeout on serial console session for root access

Type
Support Solution
Published
2025-02-26
Updated
2025-02-26
Source
https://my.f5.com/manage/s/article/K000149998

Description

F5OS-A version 1.5.2 does not enforce an idle timeout for console sessions when logged in as the root user via the serial console. Attempts to configure an idle timeout using the system settings config idle-timeout command do not apply to root access through the serial console.


Environment

  • Product: F5OS - Appliance
  • Version: 1.5.2
  • Platform: F5-BIG-LTM-R5800, C129
  • Access Method: Serial console session with root login

Cause

The inability to enforce an idle timeout for root user sessions over the serial console is a limitation in F5OS-A version 1.5.2. This behavior is by design and was addressed in a later release (version 1.8.0) through an enhancement request (RFE ID 1188057).


Recommendations

To resolve this issue and enable enforcement of idle timeouts for root user sessions over the serial console, follow these steps:


Upgrade to Version 1.8.0 or Later:


The enhancement introduced in version 1.8.0 allows configuration of idle timeouts for root access via the serial console.

After upgrading, login as admin and use the following commands to configure and verify idle timeouts:


  • system settings config idle-timeout <value_in_seconds>
  • system settings config sshd-idle-timeout <value_in_seconds>
  • show full-configuration system settings config

Test both SSH and serial console sessions to confirm that the configured timeout values are enforced.


Testing Post-Upgrade:


Log in as root via both SSH and serial console.

Remain inactive for a duration exceeding the configured timeout value.

Verify that the session is automatically logged out due to inactivity.
