Security Advisory Description

Format string vulnerability in libxml2 before 2.9.4 allows attackers to have unspecified impact via format string specifiers in unknown vectors. (CVE-2016-4448)

Impact

Allows an attacker unauthorized disclosure of information, unauthorized modification, and disruption of service.

Security Advisory Status

F5 Product Development has assigned ID 601059 (BIG-IP), ID 605255 (BIG-IQ and iWorkflow), ID 605256 (Enterprise Manager), and ID INSTALLER-2551 (Traffix SDC) to this vulnerability. Additionally, BIG-IP iHealth may list Heuristic H607649 on the Diagnostics > Identified > Medium page.
