K10010: Apache version may result in a false positive during a vulnerability scan

Applies to

Source

Topic

When a security vulnerability is reported for the Apache HTTP Server 1.3.33, F5 Product Development isolates and patches the vulnerable source code. In addition, a Security Advisory Solution is published on AskF5 with a list of FirePass hotfixes. Installing the hotfixes resolves the security vulnerability; however, installing the hotfixes does not modify the version of the Apache HTTP Server. Therefore, a security scanner may incorrectly report that FirePass is running a vulnerable version of the Apache HTTP Server.

Note: For more information, refer to K4602: Overview of the F5 security vulnerability response policy.
