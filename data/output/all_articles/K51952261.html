Description
When trying to make device trust the following error appears in /var/log/ltm:
Aug  3 12:55:36 err devmgmtd[pid]: 015a0000:3: getDeviceInfo failed: [xmlHelpers.cpp:90 getXPathValue] expected 1 node for //faultstring, got 0
Aug  3 13:04:47 err devmgmtd[pid]: 015a0000:3: getDeviceInfo failed: [xmlHelpers.cpp:90 getXPathValue] expected 1 node for //faultstring, got 0

Environment

  • BIG-IP LTM HA
  • iControl-Soap 

Cause
Management IP of peer device is missing from bigip.conf - specifically from iControl-soap list of IPs.

Recommended Actions

To resolve this issue add the management IP of the peer device to the list of iControl-Soap IP addresses.
To do this, instructions can be found in K17459 - specifically in section "Adding an IP address or range of IP addresses to the current allowed list"

Additional Information

K17459: Restricting access to the iControl SOAP API by source IP address
