K000093194: High memory utilization on BIG IP DNS

Published
2022-12-13

Applies to

Source

Description

The /shared folder has high utilization unnecessarily, as evidenced by 'df -h /shared'.


Environment

BIG-IP DNS


Cause

There is a single file which is the file used by the Zone Runner daemon (zrd) which is unnecessarily large.


Recommended Actions

Ensure the diagnostic level for the zonerunner daemon (zrd) is at its default level of 'notice'


tmsh list /sys db log.zrd.level value

sys db log.zrd.level {

value "notice"

}


check for the existence of the file /service/zrd/debug using the following command


ls -l /service/zrd/debug


if the file exists, delete it then restart the zonerunner daemon:


rm -f /service/zrd/debug && tmsh restart sys service zrd


Now eliminate the unnecessary large file; use the following command from bash mode, ensuring that you start the command with the right angle bracket as shown:


>/shared/tmp/zrd.out


Additional Information

The daemon zrd isn't critical to operation of the unit, while it's restarting zonerunner services will not be available:


K89999342: BIG-IP daemons ​​​​​​​
