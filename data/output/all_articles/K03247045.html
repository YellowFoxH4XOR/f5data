K03247045: The free space of disk partition var reduce slowly due to growing temporary file of truncated Live Update file (ASU)

Type
Support Solution
Published
2020-02-27
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.0.1, 14.1.2, 14.1.0, 14.0.1, 14.0.0, 15.0.0, 13.1.1, 13.1.0, 13.1.3
Source
https://my.f5.com/manage/s/article/K03247045

Description

The usage of disk partition /var grow slowly.

  • Run the command "df" command regularly, compare the disk usage of disk partition /var, see the usage growing slowly.
  • If the free disk space is lower than the threshold, will hit the issue K60799644.
  • Check the folder /var/ts/var/tmp/, will see more and more subfolder like /var/ts/var/tmp/sigfile.tmp.<xxxxxx>
  • In the asm log file, see the log match the bug ID 767077, and the modified time match the folder /var/ts/var/tmp/sigfile.tmp.<xxxxxx>

Environment

  • BIG-IP ASM (the version refer to ID 767077)
  • Live Update

Cause

ID 767077, and the tmp file was not deleted.

Recommended Actions

  • Upgrade to the version contain the fix for ID 767077.
  • Apply the workaround mentioned in the ID 767077.
  • The mitigation method, delete the tmp folder /var/ts/var/tmp/sigfile.tmp.<xxxxxx> regularly.

Additional Information

None.
