If you need to provide a diagnostic dataset to F5 Technical Support, you can download a dataset from the FirePass Administrative Console by performing the following procedure:

Note: If the FirePass Administrative Console is inaccessible, you can alternately download a dataset from the FirePass Maintenance Console. For more information, refer to K6009: Downloading a diagnostic dataset from the FirePass Maintenance Console.

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Device Management: Maintenance: Troubleshooting Tools page.
  3. In the F5 Support Diagnostic tool section, click on the Capture a new dataset link.

    The screen refreshes, and displays a message that appears similar to the following example:

    Processing new dataset... Please be patient....

    Once the capture is complete, the screen refreshes again and displays the Troubleshooting Tools page.

    Note: The capture make take several minutes to complete. Do not navigate away from the page.
  4. In the F5 Support Diagnostic tool section, click on the Download existing dataset link.
  5. When prompted by your browser, download the dataset to your workstation.
