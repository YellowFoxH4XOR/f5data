Known Issue

This is the result of a known issue. The standby unit may switch to active during a database synchronization operation, forcing the previous active unit to standby. The newly-active unit may truncate the internal user database and attempt to synchronize the truncated database to the previous active unit. This may result in lost user data.

F5 Product Development tracked this issue as CR44853 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

Additionally, Cumulative Hotfix HF-552-11 has been issued for FirePass version 5.5.2, Cumulative Hotfix HF-601-11 has been issued for FirePass version 6.0.1, and Cumulative Hotfix HF-602-3 has been issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the Cumulative Hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

F5 Product Development has identified that the failover features introduced in FirePass version 5.4 will greatly reduce the occurrence of this issue. For information about the new failover features, refer to K5611: Configuring FirePass to use new failover features introduced in version 5.4.
