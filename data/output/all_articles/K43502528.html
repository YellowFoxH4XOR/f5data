Description
You want to see what Pool Member you are being persisted to when using Cookie persistence.

Environment

  • BIG-IP LTM
  • Cookie Persistence

Cause
None

Recommended Actions

Create an iRule that can be used to decode the BIGipServer cookie.

  1. SSH to log into the TMOS shell.

  2. Run the following command:

    load sys config from-terminal merge

  3. Paste the following configuration:

    ltm rule _rule_procedures {
    proc decode_cookie { cookie_value } {

      # Use this proc to decode a BigIPServer cookie.
      #
      # REF: https://sra.io/2018/07/09/finding-and-decoding-big-ip-and-netscaler-cookies-with-burp-suite/
      #
      #1. Start with a Big-IP cookie i.e. 1677787402.36895.0000 which represents <encoded IP>.<encoded port>.0000.
      #2. To decode the IP Address:
      # * Convert the number to its hex equivalent: 6401010A
      # * Convert each hex byte to decimal: 100 1 1 10
      # * Reverse the order and join with ".": 10.1.1.100
      #
      #3. To decode the port:
      # * Convert the number to its hex equivalent: 901F
      # * Reverse the order of the first half and second half: 1F90
      # * Convert the resulting hex value to decimal: 8080

      # Create a list of IP, Port, 0000
      set fields [split ${cookie_value} "."]

      # Save the encoded IP and Port to variables.
      set ipAddr [lindex ${fields} 0]
      set port   [lindex ${fields} 1]

      # Convert IP Address and Port to Hex
      set hexIPAddr [format %X $ipAddr]
      set hexPort   [format %X $port];unset ipAddr;unset port

      # Decode IP Address
      #2) Convert each hex byte to decimal
      scan ${hexIPAddr} %2x%2x%2x%2x ip4 ip3 ip2 ip1; unset hexIPAddr
      
      #3) Reverse the order and join with "."
      set ipAddr ${ip1}.${ip2}.${ip3}.${ip4};unset ip1;unset ip2;unset ip3;unset ip4

      # Decode Port
      # Reverse the order of the first half and second half
      
      scan ${hexPort} %2s%2s port2 port1;unset hexPort
      scan ${port1}${port2} %4x port;unset port1;unset port2

      set decoded_cookie ${ipAddr}:${port};unset ipAddr;unset port

      return $decoded_cookie

    }
    }

    ltm rule rule_decode_cookie {
    when HTTP_REQUEST {

      
      if {[string tolower [HTTP::path]] starts_with "/decodecookie/"} {
        # In this test case, we use a simple virtual server and send 'curl http://10.1.116.115/decodecookie/1677787402.36895.0000 -H "Cookie: BIGipServer_jadams=1925717420.47873.0000"'
        # ltm virtual vs_decode_bigipserver_cookie { destination 10.1.116.115:http profiles { http { } tcp { } } rules { ltm rule rule_decode_cookie { } }
        # This is great for "on the fly" testing.
        set poolMember [call /Common/_rule_procedures::decode_cookie [URI::basename [HTTP::uri]]]
        log local0.debug "decoded_BigipServer Cookie: ${poolMember}"
      }

      # This is a more "real-world" application, where we decode the value of the BIGipServer cookie directly.
      # Decoding BIGipServer Cookie using the BigIPServer cookie value.
      set cookies [HTTP::cookie names]
      foreach cookie ${cookies} {
        if {${cookie} starts_with "BIGipServer"} {
          set poolMember [call /Common/_rule_procedures::decode_cookie [HTTP::cookie ${cookie}]]
          log local0.debug "decoded_BigipServer Cookie: ${poolMember}"
        }
      }
      
      HTTP::respond 200 content "decoded_BigipServer Cookie: $poolMember\n"
    }
    }

  4. Press "Ctrl + d" to merge the configuration.

  5. Save the configuration:

    save sys config

For any HTTP_REQUEST event where a BIGipServer cookie is present, you now see logs similar to the following:

debug tmm2[30164]: Rule /Common/rule_decode_cookie <HTTP_REQUEST>: decoded_BigipServer Cookie: 10.1.1.100:8080

Additional Information
While it may be convenient at times to be able to decode the IP:Port of the pool member you are being persisted to; this is considered to be a breach of secure information by some groups.
Should you choose to encrypt your BIGipServer cookie, please see K23254150: Configuring cookie encryption for BIG-IP persistence cookies from the cookie persistence profile.
