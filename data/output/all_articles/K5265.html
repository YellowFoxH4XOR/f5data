K5265: Production Rules may not revert to the normal load balancing mode when the Stop Time is reached

Known Issue

This is the result of a known issue. Production rules may not always return the load balancing mode to normal when the Stop Time is reached. As a result, 3-DNS will continue to use the load balancing mode which was started by the production rule until the mode is manually reset to normal.

F5 Networks Product Development tracked this issue as CR11703 and CR11710.
