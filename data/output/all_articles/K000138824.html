K000138824: ASM error message "Failed add on missing foreign key for hsl_virtual_server [virtual_server_name = '/partition/virtualServerName']" in /var/log/ts/asm_config_server.log is benign

Type
Support Solution
Published
2024-03-05
Updated
2024-03-05
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000138824

Description

  • You see an error message "Failed add on missing foreign key for hsl_virtual_server [virtual_server_name = '/partition/virtualServerName']" in /var/log/ts/asm_config_server.log

Environment

  • ASM and APM provisioned

Cause

The INFO level message in question is triggered by an update message from mcpd to tsconfd (ASM daemon) for /Common/websso profile (related to APM).

The update message is ignored and has no meaning to ASM functionality.

This is not database corruption.


Recommended Actions

The message can be ignored.
