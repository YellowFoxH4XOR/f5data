Topic

The BIG-IP ASM system supports the use of the xml output file from the IBM AppScan Standard edition vulnerability assessment tool for building a security policy.

Description

In BIG-IP ASM 11.1.0, the ASM system introduces support for building a security policy using the xml output file from the IBM AppScan Standard edition. However, if you attempt to build a security policy using the xml output file from the IBM AppScan Enterprise edition, the BIG-IP ASM system fails to import the output file. This is because the IBM AppScan Enterprise edition uses an xml format that is different from the Standard edition.

Recommendations

F5 recommends that you use the IBM AppScan Standard edition to export the xml output file and import it to the BIG-IP ASM system. For information about exporting the xml output file from the IBM AppScan Standard edition, refer to the documentation that comes with the IBM AppScan Standard edition.
