Known Issue

The BIG-IP system may not prioritize traffic as expected when you use ePVA full acceleration. This known issue applies to TCP three-way handshake packets where a Class of Service (CoS) configuration is providing prioritization using 802.1p fields.

This issue occurs when all of the following conditions are met:

  • You have enabled the CoS feature, and mapped 802.1p fields to configured traffic priority objects.
  • Your BIG-IP system has an ePVA chip.

    For more information about platforms with the ePVA chip, refer to SOL12837: Overview of the ePVA feature.

  • The system processes TCP traffic with a virtual server that has an associated FastL4 profile.
  • The FastL4 profile's PVA acceleration value is either full or assist.

Impact

Performance of latency sensitive applications may be affected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Virtual server traffic receives an unexpected traffic priority.
  • Application performance through the BIG-IP system is degraded.
