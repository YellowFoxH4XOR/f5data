K000163817: Verifying source translation address selection in F5BigNatPolicy

Type
Support Solution
Published
2026-10-21
Updated
2026-10-21
Applies to
  • BIG-IP Next CGNAT CNF: 1.4.0
  • BIG-IP Next CNF
Source
https://my.f5.com/manage/s/article/K000163817

Description

In BIG-IP Next CGNAT CNF, traffic in an F5BigNatPolicy configured for dynamic PAT and NAPT used the first configured sourceTranslation address for source NAT.

Environment

BIG-IP Next CGNAT CNF version 1.4.0 with an F5BigNatPolicy configured for dynamic PAT and NAPT.

Cause

The source translation address selection required validation.

Answer/Recommended Actions

No configuration change is required. In the tested F5BigNatPolicy, the first configured source translation address was used for SNAT. Use a packet capture on the relevant traffic path to validate the source translation address used by a specific policy.

Additional Information

This result applies to the tested policy and does not establish address-selection behavior for all configurations.
