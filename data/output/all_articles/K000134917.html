K000134917: Error Message when uploading QKView from F5OS

Type
Support Solution
Published
2023-06-06
Updated
2023-06-06
Applies to
  • F5OS
  • F5OS-A: 1.5.X, 1.3.X, 1.5.0, 1.3.2, 1.3.1, 1.3.0
  • F5OS-C: 1.5.X, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000134917

Description

You may encounter a 404 - Doesn't Exist error when you attempt to upload a QKView to F5 iHealth portal from the following location on a F5OS-C/A system:

  • From DIAGNOSTICS > System Reports page in the webUI
    • Select a QKView capture and then click on Upload to iHealth.

    • Fill out required fields on the Upload to iHealth popup and click Upload.

    • After clicking Upload, a Server Error popup will be displayed indicating there is a 404 - Doesn't Exist error.

Environment

  • F5 VELOS system running F5OS-C 1.5.1 and earlier.
  • F5 rSeries system running F5OS-A 1.5.0 and earlier.

Cause

You attempt to upload QKView files from an F5OS version that does not have the new F5 iHealth API Token Service implemented. As a result, you will not be able to uoload a QKView to F5 iHealth from the F5OS product but will instead receive a 404 - Doesn't Exist message.

Recommended Actions

You have to download the QKView locally and manually upload the QKView to F5 iHealth:

Generate the QKView from F5OS from the webUI

  1. Go to DIAGNOSTICS > System Reports.
  2. Click on Generate QKView.
  3. Provide a filename in the popup prompt and click the Generate QKView button.

    Note: This applies to both VELOS and rSeries devices.

Generate the QKView from F5OS from the Command Line Interface

  1. Log in to the command line interface (CLI) of the system using an account with admin access
  2. Generate a QKView file:

    system diagnostics qkview capture exclude-cores { false | true } filename maxcoresize maxfilesize timeout

Download QKView from F5OS to local machine

Please refer to the Download the QKView file section of article K000134530: Upload rSeries and VELOS system QKView diagnostic files to iHealth2.

Upload the QKView file to iHealth2

Please refer to the Upload the QKView file to iHealth2 section of article K000134530: Upload rSeries and VELOS system QKView diagnostic files to iHealth2.
