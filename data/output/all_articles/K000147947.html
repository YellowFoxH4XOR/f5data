K000147947: Why am I getting the "This account is not the owner of the requested zone name" error message?

Description

When creating a new DNS zone, the error message "This account is not the owner of the requested zone name" appears and the zone cannot be created:

Environment

  • F5® Distributed Cloud (F5XC) DNS

 

Answer/Recommended Actions

If you have multiple F5XC tenants and you need to create subdomains in those different tenants, you can open a Support Request through the F5 Distributed Cloud Console to ask for an override, which will allow the creation of the said subdomains.

The F5 Distributed Cloud technical team will perform verification and once confirmed, will allow the override.

 

Cause

This error happens when the parent zone or a subdomain from the same zone already exists in another F5 Distributed Cloud tenant.

For instance:

  • Tenant A has created the zone test.example.com
  • If Tenant B then tries to create the zone zone.example.com, then the creation will be not possible until ownership check has been done.

This check is in place to make sure that by default only the tenant containing the parent DNS zone can create subdomains of that zone. F5 checks the ownership of the so-called eTLD (effective top-level domains) ownership, or more precisely, the Public Suffix List (PSL).
