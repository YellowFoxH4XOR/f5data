Description

This article describes how to modify the ciphers used by the Secure Shell (SSH) service on F5OS devices.

Environment

F5OS Appliance

Cause

None

Recommended Actions

Use confd to modify the SSH service (sshd) configuration.

Note: If FIPS 140 is enabled, the SSH and HTTPS services do not allow changing the available Ciphers or KEX algorithms. This is by design.

  1. Upgrade your F5OS device to version 1.4.0 or a higher release. This upgrade will provide the necessary enhancements and security updates, including the ability to configure SSH cryptographic ciphers via the confd configuration utility. Once the upgrade is complete, the F5OS device's crypto pieces are configurable via the CLI.
  2. Login to the F5OS controller with administrative privileges.
  3. Display the list of ciphers by typing the following command:

    show running-config system security services service sshd

  4. Enter the confd shell using the following command:

    config

  5. Enter the config-service-sshd mode with the following command:

    system security services service sshd

  6. Remove CBC ciphers using this command:

    config ciphers [ aes128-ctr aes128-gcm@openssh.com aes256-ctr aes256-gcm@openssh.com ]

  7. Commit the change using this command:

    commit

Additional Information

You can check the existing SSH ciphers when logged into the root account by entering the command cat /etc/ssh/sshd_config. For example:

cat /etc/ssh/sshd_config
# Ciphers and keying
# F5 DEFAULT CONFIG START
Ciphers aes128-ctr,aes256-ctr,aes128-gcm@openssh.com,aes256-gcm@openssh.com,aes128-cbc,aes256-cbc
KexAlgorithms ecdh-sha2-nistp256,ecdh-sha2-nistp384,ecdh-sha2-nistp521,diffie-hellman-group16-sha512,diffie-hellman-group14-sha256,diffie-hellman-group14-sha1
# F5 DEFAULT CONFIG END
#RekeyLimit default none

To check the default ciphers when logged into the root account you can run the following command:

sshd -T | awk '/ciphers/,/banner/ $2 ~ "[a-z]-[a-z]" { print $2}' | sed s'/,/\n/'g
