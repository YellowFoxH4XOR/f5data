Description

After upgrading to 17.1.1.3 and edge client, 75% of time, end user get this error and can not go through RADIUS authentication., 25% of time they can authenticated.

 

Environment

  • BIG-IP APM
  • V17.1.1.3
  • RADIUS authentication with pool (with one pool member)

 

Cause

This can be one of the corner case. Possibly due to Priority group is set for the aaa server pool member but Priority Group Activation was not activated.

ltm pool /Common/ { 
   members {
      /Common/x.x.x.x:1812 {
         address x.x.x.x
         priority-group y
      }
   }
   <----- no "min-active-members 1" (on GUI: Priority Group Activation is set disabled)
}

 

Recommended Actions

Possibly this can be resolved by one of the blow:

  • Remove priority group if there is only one pool member.
  • Activate Priority Group Activation if there are multiple pool member in the Radius pool
  • Quick update pool's config (add description etc)

Best practice is if there is only one server member, then set AAA object with Direct especially when you do not need to have monitor.

Additional Information

This issue maybe corner case, as could not reproduce the issue in a test environment.
