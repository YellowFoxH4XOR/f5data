Description
Deployed HA pair in Azure from GITHUB link 
Devices attempt to failover but Cloud Failover Extension (CFE) is not notifying the User Defined Routing (UDR) to move the gateway to the second device

Environment

  • Azure
  • LTM VE 16.1.2

Cause
The CFE declaration for the "defaultNextHopAddresses" is not working when using a routetag

Recommended Actions

Modify the declaration to "static" for "defaultNextHopAddresses" and list both BIG-IP internal self-ip
