K000160734: VPN connection failures with Edge client on MAC OS

Type
Support Solution
Published
2026-04-15
Updated
2026-04-15
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.X, 17.5.1, 17.5.0
Source
https://my.f5.com/manage/s/article/K000160734

Description

When accessing via the Safari browser, “Client Cert Inspection” is Allow and authentication succeeds, but when accessing via Edge Client, “Client Cert Inspection” is Deny and authentication fails.

Environment

  • BIG- IP APM
  • Client Cert Inspection

Cause

The Edge Client may not have explicit access permissions to the private key of the client certificate on macOS.

Because it lacks these permissions, the Edge Client cannot present the certificate during VPN authentication, and as a result, the client certificate inspection is being denied.

Recommended Actions

Please check the following.

The certificate/key has to be installed in the proper stores.

The App (Edge Client) has to have access to the certificate/key.

The Edge Client is explicitly specified as having access permissions to the private key of the client certificate.
