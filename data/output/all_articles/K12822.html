Known Issue

Description

When users connect to an Outlook Web Access (OWA) 2010 Portal Access favorite with a Firefox 3.5.x browser, the Send button may be unresponsive. Users are unable to send emails, but are able to successfully connect, draft a new email, and open received email. This issue occurs because the FirePass proxy engine improperly rewrites the object associated with the Send button.

This issue occurs when all of the following conditions are met:

  • User connects to an OWA 2010 Portal Access favorite
  • User connects with a Firefox 3.5.x browser
  • User attempts to click the Send button

Impact

Users may be unable to send email.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The user gets no response when they click the Send button on the OWA 2010.

Workaround

To work around this issue, you can use a sed script for the OWA Portal Access favorite to properly handle the send objects. To do so, perform the following procedure:

Impact of Workaround: Minimal decrease in performance. Most likely undetectable.

Configuring sed script for OWA 2010 Portal Access favorite

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Portal Access: Web Applications: Content Processing.
  3. Click the Add New Favorite link.
  4. Enter a name for the script in the Processing script name field.

    For example:

    FireFoxOWA Script

  5. Enter the following in the URL match patterns field:

    */uglobal.js*

  6. Enter the following in the Content Type field:

    t

  7. Select the Allow caching check box.
  8. Enter the following in the sed processing script field:

    s@!(a\.tagName&&a\.tagName\.toLowerCase()=="body")&&\(b\.setStartBefore(a);var e=F5_Invoke_createContextualFragment\)@\1@

  9. From the Processing drop-down menu, select Post-process response data (after content patching).
  10. Click the Add New button.
