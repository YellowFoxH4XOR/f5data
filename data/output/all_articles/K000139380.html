K000139380: BIG-IQ: Unable to activate license manually with 504 Gateway timeout error

Type
Support Solution
Published
2024-04-23
Updated
2024-04-23
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.2.0
Source
https://my.f5.com/manage/s/article/K000139380

Description

When you try to get a dosser key of a Registration Key with Add-op Keys to manually activate a license from Devices > LICENSE MANAGEMENT > Licenses, you get an error similar to the following on the BIG-IQ Web GUI.

  1. The system was unable to complete one of the requested tasks (504 Gateway timeout). Try performing this task again.
  2. No error message

Environment

  • BIG-IQ
  • Activating a Registration Key with Add-op Keys manually.

Cause

The restjavad is not responding.

Recommended Actions

You can restart restjavad op BIG-IQ CM to fix the issue.

tmsh restart sys service restjavad

Impact of procedure: The restjavad service on a BIG-IP system is briefly interrupted during the restart. F5 recommends performing this procedure during a maintenance window.
