Description

Is it essential to set salt phrase and primaly-key when restoring config on the same unit?

Environment

  • F5OS-A / F5OS-C
  • any version
  • rSeries / Velos

Cause

  • n/a

Recommended Actions

When backup file is restored, you will be requested to type salt phrase and primary-key.
Before you take backup file, set those is essential, and keep those information in safe location with the backup file.

To set the salt phrase and primaly-key, please follow: 

  • For rSeries: K47512994: Back up and restore the F5OS-A configuration on an rSeries system
  • For Velos: K50135154: Back up and restore the F5OS-C configuration on a VELOS system
