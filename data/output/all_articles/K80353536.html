K80353536: BIG-IP does not show up the whole list of Certificate Subject Alternative Name (SAN) in GUI or CLI

Updated

Applies to

  • BIG-IP LTM: 15.0.1, 15.0.0, 14.1.2, 14.1.0
Source
https://my.f5.com/manage/s/article/K80353536

Description

  • After upgrade to v14.1.2.3, it does not show the whole list of Subject Alternative Name SSL certificate in WebGUI or CLI.
  • Use the command below to check SAN list of specific certificate, it is missing some SANs.
    • openssl x509 -in <certificate name> -noout -text 

Environment

  • Recently perform upgrade from v13.x or earlier to v14.1.2.
  • The whole list of SAN can be displayed in WebGUI and CLI prior to upgrade.
  • Using a certificate with a Subject Alternative Name longer than 1023 characters.
  • This does not have impact to the SSL production traffic.


Cause

This is a cosmetic error. Product Development has assigned a Bug ID below to address this issue.
Bug ID 828789: Display of Certificate Subject Alternative Name (SAN) limited to 1023 characters

Recommended Actions

As a workaround, specify fewer than 1023 character for the Certificate Subject Alternative Names.
