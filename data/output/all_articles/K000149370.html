Description

After the upgrade to 17.1.2, named service is unable to start.

daemon.log contains the similar errors below;

/var/log/daemon.log
Jan 15 19:36:29 bigip err named[21683]: /config/named.conf:30: option 'dnssec-lookaside' no longer exists
Jan 15 19:36:29 bigip crit named[21683]: loading configuration: failure
Jan 15 19:36:29 bigip crit named[21683]: exiting (due to fatal error)
Jan 15 19:36:29 bigip notice systemd[1]: named.service: main process exited, code=exited, status=1/FAILURE
Jan 15 19:36:29 bigip notice systemd[1]: Unit named.service entered failed state.
Jan 15 19:36:29 bigip warning systemd[1]: named.service failed.
Jan 15 19:36:30 bigip warning systemd[1]: Cannot add dependency job for unit fips.target, ignoring: Unit not found.
Jan 15 19:36:30 bigip warning systemd[1]: start request repeated too quickly for named.service
Jan 15 19:36:30 bigip err systemd[1]: Failed to start The named process is the DNS server daemon..
Jan 15 19:36:30 bigip notice systemd[1]: Unit named.service entered failed state.
Jan 15 19:36:30 bigip warning systemd[1]: named.service failed.

The errors from another options below;

Apr  8 01:37:14 bigip err named[23393]: /config/named.conf:55: option 'dnssec-enable' no longer exists
Apr  8 01:40:15 bigip err named[24906]: /config/named.conf:81: option 'additional-from-auth' no longer exists
Apr  8 01:40:49 bigip err named[25347]: /config/named.conf:82: option 'additional-from-cache' no longer exists

This error also appears when you try to make a change in the GUI under "System --> Configuration --> Device -->DNS".  When you make a change to the system's DNS servers, it restarts named, which tries to load named.conf, which then errors.

Environment

  • After the upgrade to 17.1.2
  • named.conf contains the removed configuration options.

Cause

It is due to BIND version change.

17.1.2 uses BIND 9.18.28.

From 9.18.28, several configuration options are removed completely. If named.conf contains such removed options, named may fail to start. 

For more details, please refer to https://bind9.readthedocs.io/en/v9.18.28/notes.html#id85

Recommended Actions

Remove (or comment-out) the affected configuration options from /var/named/config/named.conf .
