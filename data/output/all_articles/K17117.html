Known Issue

Attempts to access BIG-IP APM Oracle Access Manager (OAM) resources may fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM access profile references an OAM AAA profile.
  • Your initial attempt to access an OAM destination resource through the access profile fails at the network level.
  • Your attempts to access the same or alternate OAM destination resources through the access profile are unsuccessful.

Impact

The OAM AccessGate ID cookie returned by BIG-IP APM may reference the wrong domain.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to access the OAM access profile, the browser stops responding or appears to be in a redirect loop.
  • You view log messages in the /var/log/apm file that appear similar to the following example:

    notice eam[<pid>]: 01490000:5: Retry for initializing accessgate '<oam aaa profile name>'
    notice eam[<pid>]: 01490000:5: Retry 1 : wait for 1 seconds before retrying initializing accessgate '<oam aaa profile name>'...
    warning eam[<pid>]: 01490000:4: Accessgate ID from OAM server doesn't match with the accessgate name
