Known Issue

If a user with the FirePass 6.1 standalone client connects to the BIG-IP APM system, the user is prompted to update their client to the BIG-IP Edge Gateway. After the update is completed and the user attempts to connect to a Protected Workspace, the network access session fails to start and the BIG-IP Edge Gateway client will crash, and the user will receive an error message. After the user closes the error message, the user will remain in the Protected Workspace. If the user exits their PWS session and re-launches the BIG-IP Edge Gateway, the user will be able to successfully connect.

Note: This issue has not been reported for FirePass clients using versions other than 6.1; however, it may affect other versions.

F5 Product Development tracked this issue as ID 243500 (formerly CR136938), and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP APM release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
