Known Issue

This is the result of a known issue. The BIG-IP GTM system records the following log message to the /var/log/gtm log file when the big3d process has attempted to establish a TCP connection to a probe target, and has failed to make a connection:

big3d: 01330002:4: Connection failed: Transport endpoint is not connected

In some cases, the BIG-IP GTM system records the log message in an overly verbose manner. This is a result of the syslog log level being set to Notice.

F5 Product Development tracked this issue as CR65112, and it was fixed in BIG-IP GTM 9.3 and 9.4. For information about upgrading, refer to the BIG-IP GTM Release Notes.
