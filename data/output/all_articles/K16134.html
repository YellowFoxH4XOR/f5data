Known Issue

The network access drive mapping may contain an incorrect path.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is running an 11.5.0 hotfix.
  • The BIG-IP APM system is configured with a network access profile.
  • Using the Configuration utility, you add drive mappings to the network access profile using the backslash ( \ ) character.

    For example:

    \\<host>\<path>

Impact

Drive mappings do not function.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing the drive mapping configuration of the network access profile, the saved mappings are missing backslash characters.

    For example:

    \\<host>\<path>

    An example drive mapping stored in the BIG-IP APM network access profile configuration appears similar to the following example:

    \<host><path>
  • When creating a drive mapping containing the backslash character, escaping each backslash with a backslash saves the configuration correctly.

    For example:

    \\\\<host>\\<path>

    An example drive mapping stored in the BIG-IP APM network access profile configuration appears similar to the following example:

    \\<host>\<path>
  • When creating a network drive mapping with the Traffic Management Shell (tmsh), the configuration is saved correctly.

Workaround

To work around this issue, you can escape configuration backslashes with backslashes.

For example:

\\<host>\<path>

When creating the drive mapping, you would enter the following drive mapping in to the Configuration utility:

\\\\<host>\\<path>
