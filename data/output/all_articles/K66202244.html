Issue

Old Behavior

In BIG-IP versions prior to 13.0.0, if a connection requests the use of this extension, the BIG-IP system replies with a normal master secret, and the connecting device can decide to terminate the connection for lack of security.

New Behavior 

Beginning in BIG-IP 13.0.0, SSL profiles support RFC 7627: Transport Layer Security (TLS) Session Hash and Extended Master Secret Extension. This extension provides additional security to SSL sessions by binding the master secret to a log of the full SSL handshake used to compute it. This behavior prevents attackers from setting up a second SSL session with the same master secrets.

Recommended Actions

There are no configuration options for this feature. You can only enable or disable this feature using a database variable. This feature is enabled by default.

To disable extended master secret support, set the tmm.ssl.ExtmsEnabled database key to false. You should only have to do this when troubleshooting suspected extended master secret issues.

tmsh modify /sys db tmm.ssl.extmsenabled value false

To view the connections currently using extended master secrets, you can use the tmsh show ltm profile client-ssl command. In the command output, locate the value of the Extended Master Secret Handshakes entry in Certificates/Handshakes.
