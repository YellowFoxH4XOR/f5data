K000133506: Changing password fails with "BAD PASSWORD: is too similar to the old one" error

Type
Support Solution
Published
2023-04-13
Updated
2023-05-04
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.3
Source
https://my.f5.com/manage/s/article/K000133506

Description

The customer tried to change admin's password via GUI.

Even though new password is not similar at all, changing password failed with "BAD PASSWORD: is too similar to the old one" error .



Environment

  • BIG-IP v15.1.3

Cause

Length of new password is 7 though password.difok db key value is 8 (default).

According to password.difok db key, 8 characters must be different between old and new password. But new password has only 7 characters.

Thus, new password hits "BAD PASSWORD: is too similar to the old one" error .

Recommended Actions

Make new password 8 or more different characters or Change password.difok db key value 7 or less.

Additional Information

None
