K000135169: VS 'translated IP' for Generic Host server is not monitored

Type
Support Solution
Published
2023-06-22
Updated
2023-06-22
Source
https://my.f5.com/manage/s/article/K000135169

Description

VS "translated IP" attached to Generic Host server object is no monitored.

Probes are send for "destination" IP instead.


Environment

GTM system with generic-host server object and translation IP in use for VS


Cause

Refer to the below configuration.


For VS translated IP to be monitored a translation IP must be set up at server level too.


gtm server /Common/server {

datacenter /Common/DC

devices {

device {

addresses {

192.0.2.2 { } ----> There is no translation address configured on gtm server and hence it

chooses the address field.

}

}

}

monitor /Common/gateway_icmp

prober-preference inside-datacenter

product generic-host

virtual-servers {

VS1 {

destination 192.0.2.1:0

monitor /Common/gateway_icmp

translation-address 192.0.2.2

translation-port 443

}

}

}


Recommended Actions

None required.


Additional Information

None.
