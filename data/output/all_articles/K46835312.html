K46835312: BIG-IP AWS instance ran out of secondary IP addresses

Updated

Applies to

Source

Description

Creating new deployment of BIG-IP in AWS. System stops creating Secondary IP for Virtual Severs
Expected to use 100 IP addresses, and system fails after creating about 15

Environment

  • AWS
  • BIG-IP

Cause
AWS instance selected does has limit on the number of secondary IP allowed. For more information, refer to the following AWS documentation:

  • Elastic network interfaces
  • Maximum IP addresses per network interface

Recommended Actions

Consider one of the following as appropriate for your environment:

  • Each AWS instance type supports a maximum number of network interfaces. Redeploy using an AWS instance that allows the number of secondary IP needed for the deployment.
  • Plan and design your network environment so that the number of IP addresses a network interface require, do not exceed the AWS instance limit. For example, you can add an additional network interface or split an existing subnet.
