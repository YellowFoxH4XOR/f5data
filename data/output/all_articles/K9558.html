Known Issue

In a FirePass high availability (failover pair) configuration, the global settings for the Windows Antivirus checker, Logger, and Far-End Security Integration inspector are not synchronized from the active controller to the standby controller. The global settings for these inspectors are configured on the Users: Endpoint Security: Endpoint Inspectors page.

F5 Product Development tracked this issue as CR85666 and it was fixed in FirePass 6.0.3. For information about upgrading, refer to the FirePass release notes.

Workaround

You can work around this issue by manually configuring the global settings for the Windows Antivirus checker, Logger, and Far-End Security Integration inspector on the standby controller.
