Description

When you use a UDP monitor and it fails your server/pool member may show this, or a similar, error message in its logs.

  • "A malformed RADIUS message was received from client <hostname>. The data is the RADIUS message"
  • The pool member is marked down.

Environment

Relevant environmental factors specific to the topic

  • UDP monitor
  • RADIUS, or other server, that a UDP monitor is being used to track its state.

Cause

A UDP monitor contains the default send string of "default send string". When this is sent to a pool member it can be seen as a fragmented or inappropriate message and the server will not accept the connection and will close it.

Recommended Actions

  1. Configure the proper Send and Receive strings.
  2. Delete "default send string" from the box and leave the Receive string blank. If you do not specify both a Send String and a Receive String, the monitor performs a simple service check and connect only.
