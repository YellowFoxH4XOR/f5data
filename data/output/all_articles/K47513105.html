Description

Pool member returns a response similar to the following when connecting through an virtual server:

400 Bad Request
Your browser sent a request that this server could not understand.

 

Environment

  • Virtual server
  • Backend server has different port from Virtual server's port
  • Policy may forward connection to different port pool member or node from virtual server's port.
     

Cause

Port Translation is disabled on the virtual server.


Recommended Actions

Enable Port Translation in the virtual server configuration.


Additional Information

When Port Translation is disabled, SSL will be terminated on the virtual server on port 443, and connections to HTTP pool members will use the same destination port, in this case port 443. This results in a plaintext HTTP request being sent to a port which is typically used for HTTPS connections. Web servers may treat this as a bad request and return a HTTP 400 Bad Request response.
