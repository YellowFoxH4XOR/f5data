Known Issue

DoSL7 profile non-default acceptlisted IP addresses might not be excluded from policy processing.

This issue occurs when all of the following conditions are met:

  • You configure a DoSL7 profile that includes acceptlisted IP addresses that are different from the default DoSL7 profile.
  • The DoSL7 profile is dynamically attached to transactions through an iRule or Centralized Policy Matching (CPM).
  • The DoSL7 policy processes traffic that matches the acceptlisted IP addresses.

Impact

The acceptlisted IP addresses of the non-default DoSL7 profile are not excluded from processing.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system enforces the DoSL7 policy on IP addresses that are not configured in the default DoSL7 acceptlisted addresses.
