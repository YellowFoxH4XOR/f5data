K000130499: i15800 went into an inoperable state

Type
Support Solution
Published
2023-01-19
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.1.3
Source
https://my.f5.com/manage/s/article/K000130499

Description

New iSeries BIG-IP with default configuration went into an inoperable state after downgrading from 15.1.5 to 13.1.3.4.

Environment

iSeries

Cause

Unknown

Recommended Actions

Running mcpd reload will often recover the device; sometimes, this needs to be done several times.

K13030: Forcing the mcpd process to reload the BIG-IP configuration

If the issue persists, you can collect the following information and contact F5 support. 

1. Enable mcpd debug and save the configuration.

modify sys db log.mcpd.level value debug

save sys config

2. reboot the device

3. disable mcpd debug and save config

modify sys db log.mcpd.level value notice

save sys config

4. Collect mcpd.out file from /var/tmp/

5. collect qkview

6. Run EUD to check for hardware errors.

 

Additional Information

None
