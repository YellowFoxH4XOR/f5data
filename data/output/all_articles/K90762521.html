K90762521: Trying to upgrade new EPSEC: Failed to reserve hugetlbfs memory output is truncated

Type
Support Solution
Published
2022-03-01
Updated
2026-01-09
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.2
Source
https://my.f5.com/manage/s/article/K90762521

Description

  • Trying to upgrade a new EPSEC
  • Seeing these errors:
    Failed to reserve hugetlbfs memory output is truncated, fctx->output: fctx->command:/usr/bin/epsecperlwrapper -f -b install epsec-1.0.0-1156.0.iso
    EPSEC: Installation of EPSEC package failed. Install command output Unknown

Environment

  • epsec-1.0.0-1156.0.iso (may affect other versions)
  • BIG-IP version 16.1.2 

Cause

This is due to Bug ID 1064357

Recommended Actions

  • This is a cosmetic issue, the installation has actually been successful.
  • It can be cleared up by performing an mcpd reload - instructions are at K13030: Forcing the mcpd process to reload the BIG-IP configuration
    NOTE: please be aware performing an mcpd reload will cause a full reboot of the unit

 

Additional Information

None
