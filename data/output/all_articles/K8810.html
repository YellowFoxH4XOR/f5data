Topic

The TACACS+ profile for application authentication requires the BIG-IP system to be licensed for use with the Client Authentication module.

The TACACS+ profile can be used to provide application authentication for users within an existing TACACS+ environment. Setting up TACACS+ for use with application authentication requires the configuration of the following two components:

Note: For a detailed explanation of the various options available for the TACACS+ authentication configuration object and the authentication profile, refer to SOL8808: Overview of TACACS+ Authentication.

  • The authentication configuration object that specifies the servers, shared key, protocol to use, and general behavior to communicate with the TACACS+ server(s).
  • The authentication profile that is associated with the virtual server, to allow the virtual server to pass authentication requests to the TACACS+ server(s).

Configuring an authentication object 

The authentication configuration object is used to specify all the necessary configuration information that is needed to communicate with the TACACS+ server(s). To create an authentication configuration object, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Click Profiles
  4. Click Authentication.
  5. Click Configurations
  6. Click Create.
  7. In the Name box, type a name for the configuration.

    For example:

    my_tacacsplus_conf
  8. From the Type menu, select TACACS+
  9. In the Servers box, type an IP address and click Add.
  10. In the Secrets box, type the TACACS+ shared key.
  11. In the Confirm Secret Box, re-type the TACACS+ shared key that you specified in the Secret box.
  12. From the Encryption menu, retain the default value (Enabled) or select Disabled.
  13. In the Service Name box, type ppp for the name of the service.

    Important: This setting is required.

    Note: For a list of alternate service names, refer to K8808: Overview of TACACS+ Authentication.
  14. In the Protocol Name box, type ip for the name of the protocol.

    Note: This setting is optional.

    Note: For a list of alternate protocol names, refer to K8808: Overview of TACACS+ Authentication.
  15. The following setting is optional and only displayed when the Advanced Configuration option is selected:

    From the Authentication menu, select either Authenticate to first server or Authenticate to each server until success.
  16. The following setting is optional and only displayed when the Advanced Configuration option is selected:

    From the Accounting Information menu, select either Send to first available server or Send to all servers.

    Note: Support for TACACS+ accounting was introduced in BIG-IP version 10.2.0. Although the Accounting Information menu appears in earlier versions, it is only used by BIG-IP systems running versions 10.2.0 and later.
  17. The following setting is optional and only displayed when the Advanced Configuration option is selected:

    From the Debug Logging menu, select either Disabled (Default) or Enabled.

    This option allows an administrator to troubleshoot communication or authentication problems with the TACACS+ server by logging debug information to the /var/log/secure file.
  18. Click Finished.

Configuring an authentication profile

The authentication profile is associated with a virtual server to pass client username and password information to a TACACS+ server for authentication. To create an authentication profile, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Click Profiles
  4. In the Authentication menu, click Profiles
  5. Click Create.
  6. In the Name box, type a name for the profile.

    For example:

    my_tacacsplus_prof
  7. From the Type menu, select TACACS+
  8. Select the Custom check box to enable all fields in the configuration.
  9. From the Mode menu, retain the default value (Enabled) or select Disabled.
  10. From the Configuration menu, select the configuration object previously created.

    For example:

    my_tacacsplus_conf
  11. From the Rule menu, retain the default value (_sys_auth_tacacs) or select another iRule if one has been created for use with TACACS+.
  12. From the Idle Timeout menu, select Specify or Indefinite. If you select Specify, configure the number of seconds the authentication or authorization request can remain idle before timing out (the default is 300). If you select Indefinite, and authentication or authorization request will remain idle indefinitely.
  13. Click Finished.

Once the TACACS+ configuration object and profile have been completed, associate the new TACACS+ authentication profile with the virtual server that will use TACACS+ authentication.
