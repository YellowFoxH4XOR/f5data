K52282354: Failure when verifying to factory syndication with Google Auth app; error message: User failed Google Authenticator Code verification

Type
Support Solution
Published
2021-03-22
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.2
Source
https://my.f5.com/manage/s/article/K52282354
Description

Access Policy login fails when verifying to factory syndication with Google Auth app.
The following message is logged in /var/log/apm:
Logging Agent: User failed Google Authenticator Code verification

Environment

  • Two-Factor Authentication With Google Authenticator
Cause

This may be due to delay between APM and NTP server.

Recommended Actions

Synchronize APM with NTP server.
K10240: Verifying NTP peer server communications

Additional Information

None
