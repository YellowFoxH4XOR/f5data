Description
By default, the HTTPS health monitor uses the bigd process to monitor. The default HTTPS health monitor uses a default SSL cipher list that cannot be modified. However, if you need the BIG-IP system to use a specific set of SSL ciphers when monitoring the members of a resource pool, you can configure a custom HTTPS monitor to use a Server SSL profile that is configured to match the SSL ciphers.

If the associated Server SSL profile is configured with the DEFAULT cipher string, the BIG-IP system applies the f5-default cipher group on the bigd process. If the associated Server SSL is configured with a cipher string other than DEFAULT, the cipher suites that the bigd process advertises are subjected to the supported OpenSSL cipher suite. For example, the cipher string in the Server SSL profile is DEFAULT:!RSA, the advertised cipher suites are determined by OpenSSL only.

Environment

  • BIG-IP
  • HTTPS MONITOR

Cause
Not all ciphers supported by tmm will be supported by bigd due to each process leveraging different TLS/SSL stacks

Recommended Actions

You can verify that your cipher string is compatible with OpenSSL by using the following command:
openssl ciphers '[cipher string]'

For example:
openssl ciphers 'RSA'

If the cipher string is compatible with OpenSSL the command will display a list of corresponding cipher suites:
AES256-GCM-SHA384:AES256-SHA256:AES256-SHA:CAMELLIA256-SHA:AES128-GCM-SHA256:AES128-SHA256:AES128-SHA:SEED-SHA:CAMELLIA128-SHA:RC2-CBC-MD5:RC4-SHA:RC4-MD5:RC4-MD5:DES-CBC3-SHA:DES-CBC3-MD5:NULL-SHA256:NULL-SHA:NULL-MD5

However, if the cipher string is not compatible with OpenSSL the command will result in an error similar to the following:
openssl ciphers 'DEFAULT:!DHE_DSS'
Error in cipher list
47997666063216:error:140E6118:SSL routines:SSL_CIPHER_PROCESS_RULESTR:invalid command:ssl_ciph.c:1225:
 

Additional Information
If the cipher string is not compatible with OpenSSL, https monitor will fail.
SSL/handshake will fail without sending a Client Hello message, because there is not available cipher suites with the incompatible cipher string.
