Known Issue

The BIG-IP system does not correctly handle fragmented IPv6 packets on BIG-IP Virtual Edition (VE).

This issue occurs when all of the following conditions are met:

  • You are running BIG-IP VE.
  • The BIG-IP system receives fragmented IPv6 traffic.

Impact

The BIG-IP system does not successfully process traffic that depends on fragmented IPv6 packets.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP VE platforms do not correctly handle IP fragmentation with IPv6 packets. The system receives initial fragmented packets but discards subsequent fragments.
