K000148946: AS3 SchemaVersion deployed different from BIG-IQ AS3 version

Type
Support Solution
Published
2024-12-17
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IQ
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000148946

Description

You are modifying the existed AS3 deployment, by sending the patch. You may notice differences between schema versions.

Schema in your deployment:

{
"class": "AS3",
"action": "patch",
"schemaVersion": "3.44.0",
...
}

Application Deployment logs from BIG-IQ might have different schema version:

{
...
},
"updateMode": "selective",
"schemaVersion": "3.12.0"
}

Environment

  • BIG IQ
  • AS3

Cause

Expected behavior, to change the schema version in original deployment on BIG IQ, you need to deploy the whole declaration one more time, not by using patch action.

Recommended Actions 

If new schema version is required, re-deploy the whole application.

Additional Information 

None
