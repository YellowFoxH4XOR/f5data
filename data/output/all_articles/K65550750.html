Overview

On April 1, 2021, BIG-IP ASM began End of Sale (EoS). For more information, refer to K72212499: End of Sale announcement for BIG-IP ASM.

You can find several reasons to migrate to Advanced WAF in Get Ahead of Web App Security by Migrating from BIG-IP ASM to F5 Advanced WAF, which also includes step-by-step instructions on how to upgrade, whether you are using BIG-IP ASM 12.1 or have an ELA in place.

Beginning with EoS, on April 1, 2021, F5 upgraded licenses for BIG-IP 14.1 and later to include Advanced WAF capabilities.

Note: You do not need a new license. After you reactivate your license key, F5 automatically updates valid perpetual and term subscription BIG-IP ASM licenses to the Advanced WAF feature set.

Note: Migration does not apply to Public Cloud PAYG. For more information, refer to the Public Cloud PAYG section in K72212499: End of Sale announcement for BIG-IP ASM.

Migrate to Advanced WAF

If you have a large installed base of BIG-IP ASM, you can perform license reactivation using the command line. For more information, refer to K2595: Activating and installing a license file from the command line.

After you migrate to Advanced WAF, the Configuration utility still references BIG-IP ASM in some locations, such as the Resource Provisioning page. These references do not indicate that your system failed to upgrade to Advanced WAF.

If your company is bound to buying from a list of "approved" products, check with your procurement teams and F5 Account Manager to ensure that Advanced WAF is on this list.

Reactivate your BIG-IP license

To reactivate your BIG-IP license, do the following:

  1. Open the Configuration utility.
  2. Go to System > License.
  3. At the bottom of the page, select Re-activate.
     

  4. In Activation Method, do one of the following:
    • If your BIG-IP system communicates outbound to the internet and connects to the F5 Licensing Server:
      • Select Automatic (requires outbound connectivity).
         
    • If your BIG-IP system cannot reach the F5 Licensing Server directly through the internet:
      • Select Manual.
      • Refer to K7752: Licensing the BIG-IP system for information about how to complete the licensing steps.
  5. Select Next.

Verify you have Advanced WAF

You can use the Configuration utility or the command line to verify that you upgraded to Advanced WAF.

Use the Configuration utility

To verify that you have Advanced WAF using the Configuration utility, do the following:

  • Select Security.

    Under Security, if Guided Configuration displays, you successfully upgraded to Advanced WAF.

     

Use the command line

To verify that you have Advanced WAF using the command line, do the following:

  1. Log in to the console.
  2. Enter the following command syntax:

    grep -e waf_gc -e mod_waf -e mod_datasafe bigip.license

    When the output contains the following enabled flags, you successfully upgraded to Advanced WAF:

    waf_gc:       enabled
    mod_waf:      enabled
    mod_datasafe: enabled

Verify you have FPS

If you plan to use the Advanced WAF DataSafe feature, you must have Fraud Protection Service (FPS). To verify that you licensed FPS, do the following:

  • In the Configuration utility, go to System > Resource Provisioning.

    Under Module, when Fraud Protection Service (FPS) displays, you successfully licensed FPS.
     

ELA Customers

The automatic upgrade of BIG-IP ASM licenses does not apply to ELA licenses. If you are an ELA customer, as of the EoS date, you can continue to access existing VE configurations that contain BIG-IP ASM for the remainder of your ELA agreement.

If you want Advanced WAF or the new Best configuration that includes Advanced WAF, contact your F5 Customer Success Manager for assistance.

Transition from LOAD to CAT SKUs

ELA agreements no longer include BIG-IP ASM. When your ELA term ends, if you enter into a new agreement, you must migrate from your current LOAD SKU(s) to new Catalog SKU(s), which do not include BIG-IP ASM products. You can continue to run your LOAD SKU(s) in parallel as you migrate to Catalog SKU(s).

F5 provides the following support to help you migrate from LOAD to CAT SKUs:

  • You can continue to use LOAD SKUs alongside newly-issued CAT SKUs as you migrate from LOAD to CAT SKUs.
  • Customer Success is available to provide support at every step of your migration. Connect with your Customer Success manager (CSM) to obtain technical CSM support.

For more information, refer to the following resources:

  • K54288604: How to migrate from ELA "Load" to "Catalog" licenses
  •  How to Migrate from ELA "Load" to "Catalog" Licenses (6:14)

Pricing

After you upgrade to Advanced WAF, you can continue to renew your support agreement based on your original BIG-IP ASM or Best purchase, without a support price increase. This support price continues, even after you upgrade to Advanced WAF for free.

As of July 1st, 2021, there are Best SKUs that include F5 Advanced WAF. (They contain BTA in the SKU name.) These SKUs cost more than the previous Best SKUs that reached EoS (prices differ per SKU).
