Known Issue

The Traffic Management Microkernel (TMM) may produce a core file when the BIG-IP WebAccelerator processes a large POST request.

This issue occurs when all of the following conditions are met:

  • A BIG-IP WebAccelerator-enabled virtual server receives a large POST request (>10MB).
  • An invalidation trigger matches the request.

When processing POST requests with large bodies, the BIG-IP WebAccelerator system's viewstate processing may encounter an insufficient memory condition. As a result, TMM produces a core file. The size of the POST request required to trigger this issue depends on the amount of memory pressure the system is under. A system under heavy memory pressure may experience this issue with a POST request as small as 10MB.

Impact

TMM may produce a core file and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H432438 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP system may unexpectedly fail over to another system in the device group.
  • You may see a TMM core file in the /shared/core directory.

Workaround

To work around this issue, you should ensure that the Acceleration policy does not contain invalidation rules for paths that receive large POST requests.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
