Known Issue

Steering (traffic forwarding) does not work as expected when you use a Performance (Layer 4) Virtual Server and classification is disabled

Impact

The system is not sending traffic to the expected location or endpoint.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system is not sending Client traffic to the expected location or endpoint.
