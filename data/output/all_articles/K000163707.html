Topic

This article describes how to increase storage for an F5 Insight virtual machine (VM) under the following conditions:

  • The F5 Insight OVA was deployed with the default 80 GB disk.
  • The primary VMware vsphere disk was accidentally under-provisioned.
  • Additional storage is required after deployment.

Description

F5 Insight stores application data on the primary virtual disk. A minimum of 600 GB is required for a supported deployment. Follow the following procedure to increase the HD size. You can also find more information in Expand the F5 Insight virtual disk on Clouddocs.

Recommended Actions

Depending on whether the virtual machine has already completed first boot, perform one of the following procedure:

Important: In both scenarios, do not add a second HD in VMware vSphere.

  • Scenario 1: The VM has not completed first boot
  • Scenario 2: The VM completed first booth

Scenario 1: The VM has not completed first boot

When the F5 Insight VM has not booted up once, you only need to login to VMware vSphere to increase the virtual HD and no further action is required. To do so, perform the following:

VMWare vSphere

  1. Login to vSphere.
  2. Deploy the F5 Insight OVA file.
    1. Increase Hard Disk 1 to at least 600 GB.
  3. Allow the system to complete first boot and installation. During first boot, F5 Insight automatically detects and consumes the available space on the primary disk.

No further action is required.

Scenario 2: The VM completed first booth

When the F5 Insight VM has booted up at least once, after increasing the virtual HD in VMware vSphere, you need to run a disk expansion utility on F5 Insight. For more information on this utility, refer to the Additional Information section.

To do so, perform the following procedure:

VMWare vSphere

  1. Login to vSphere.
  2. Edit the F5 Insight VM settings.
    1. Increase Hard Disk 1 to the desired size.
  3. Save the configuration.

F5 Insight

  1. Login to bash on F5 Insight.
  2. To run the disk expansion utility, enter the following command:
    sudo /opt/f5insight/scripts/f5insight-disk-expand.sh
  3. To verify the expansion is successful, enter the following command:
    df -h /opt

Additional Information

F5 recommends using the disk expansion utility /opt/f5insight/scripts/f5insight-disk-expand.sh when you want to expand the virtual HD after the F5 Insight VM has booted up at least once.

  • The utility does not modify VMware virtual disk settings. It operates only inside the guest operating system.
  • You must first expand the VMware disk before running the utility.
  • The utility then expands the operating system and application storage to consume the newly available capacity.
