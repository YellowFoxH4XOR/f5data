K000092374: Virtual Server Pool having intermittent disconnections, Pool monitor configured without "host" domain information (empty) on send strings and received string to "200/200 OK"

Type
Support Solution
Published
2022-10-12
Updated
2022-12-28
Source
https://my.f5.com/manage/s/article/K000092374

Description

Virtual Server Pool having intermittent disconnections. Pool monitor are configured without "host" domain information (empty) on send strings, while received strings with "200/200 OK". The web server found to have return HTTP 400 Bad request when tested with CLI CURL command # curl -v -k -H "Host:" https://127.0.0.1/path1/index.html

  • Sent Strings configured with empty host domain
  • Get Strings configured with "200/200 OK"

Environment

  • BIG-IP LTM
  • Configuration objects and settings
  • Products and features

Cause

Pool monitor are configured send strings with empty "host" which will cause the web server return 400 Bad request instead of 200 OK. The reason is web server (e.g Apache) will be expecting host domain information instead of a blank/empty domain information.

 Recommended Actions

  1. It is recommended to include domain information on the monitor send strings "host" as the web server is expecting this information, else, it will return HTTP 400 Bad Request instead of 200 OK.
  2. Please refer to the attached KB K2167 for more information on how to construct pool monitor send strings. 
  • Example: GET /index.html HTTP/1.1\r\nHost: host.domain.com\r\nConnection: Close\r\n\r\n
