Known Issue

Running the ACCESS::session command in an iRule may cause TMM to exit and restart.

This issue occurs when all of the following conditions are met:

  • The ACCESS::session command is used in an iRule that is referenced by a virtual server.
  • Your BIG-IP system is running either 11.5.1 HF5 or 11.4.0 HF8, or has an engineering hotfix for ID 455113 installed.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from TMM restarting. If the BIG-IP system is configured as part of a high availability (HA) group, a failover event may occur.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H541347 on the Diagnostics > Identified > Medium screen.
  • The active BIG-IP system fails over to the standby system if configured in an HA group.
  • The BIG-IP system generates TMM core files to the /shared/core directory.
  • In the /var/log/ltm log file, you observe messages similar to the following example:

    notice sod[7056]: 01140045:5: HA reports tmm NOT ready.
