Known Issue

This is the result of a known issue. The BIG-IP LTM ServerSSL profile does not support serve-initiated SSL renegotiation.

When an SSL connection is established between a client and a server, either the client or the server can request a session renegotiation.

The BIG-IP can be configured to terminate client SSL communications using a ClientSSL profile, and to communicate with the back end server using a ServerSSL profile. This configuration allows secure communication on both sides of the BIG-IP. If the back end server requests a renegotiation of the SSL connection with the BIG-IP , the ServerSSL profile erroneously closes the connection.

F5 Networks Product Development tracked this issue as CR82852 and it was fixed in BIG-IP version 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM or ASM Release Notes.
