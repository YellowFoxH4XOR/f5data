K00523515: BIG-IQ discovery failed to connect to 10.10.10.10 : Bad Request(400)

Type
Support Solution
Published
2021-09-21
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X
Source
https://my.f5.com/manage/s/article/K00523515

Description
BIG-IQ discovery with error: Failed to connect to 10.10.10.10 : Bad Request(400)

Environment

  • BIG-IQ
  • Discovering managed device

Cause
This failure was related to network connectivity traffic and route issues.

Recommended Actions

  1. Validate bidirectional connectivity between the CM and device being discovered on port 443
  2. Ensure restjavad is running on the managed device
    # bigstart status restjavad
  3. You can try restarting restjavad
    # bigstart restart restjavad
  4. Test managed device restjavad is responding
    # restcurl -u admin:<password> /mgmt/tm/sys/provision
  5. Test BIG-IQ to managed device communication
    # curl -sku admin https://<bigIP>/mgmt/shared/resolver/device-groups/tm-shared-all-big-ips/devices
        If the curl times out or doesn’t respond with a good response, check networking.
