K3138: Reasons why the BIG-IP system may not re-establish a lost link with a Cisco Catalyst 6500 unless the system is rebooted

Topic

When a fiber gigabit link is lost between a BIG-IP system and a Cisco Catalyst 6500 series switch, the BIG-IP system cannot reestablish the link unless the system is rebooted.

This issue is typically caused when the speed and duplex of the gigabit interface on the BIG-IP system is changed manually.

To resolve this issue, set the interfaces on both the BIG-IP system and Cisco switch to auto-negotiate.

If this does not solve the problem, it may be possible that your Cisco switch requires serialized gigabit interface converters (GBIC). If this is the case, contact Cisco for a replacement.
