K8180: FQDN is required for Active Directory authentication or group mapping

2010-07-21

Issue

In FirePass software versions prior to 6.0.2, Active Directory (AD) queries for authentication or group mapping use either a fully-qualified domain name (FQDN) or a non-FQDN (such as those used in older Windows networking environments) for the Domain field of the configuration for the AD server. The configuration for the AD server is located on the Authentication tab of the Users: Groups: Master Groups page, and on the Group mapping methods tab of the Users: Groups: Dynamic Group Mapping page, when you click the Configure link for the AD method.

For example, the AD domain DOM1.SITEREQUEST.COM is an FQDN, which permits AD authentication and group mapping under all versions of FirePass software. However, the domain DOM1, which may be used in a Windows NT environment or an AD environment that has been migrated from Windows NT, generally does not permit AD authentication or group mapping in FirePass 6.0.2 and later versions.

Note: Support for AD User Principal Names (UPN) format was introduced in 6.0.2. Hotfix HF-69104-1-1 and later versions of this hotfix add support for UPN for 6.0.1. The change in behavior described for 6.0.2 also applies to 6.0.1 with hotfix HF-69104-1-1 or later versions of the hotfix.
