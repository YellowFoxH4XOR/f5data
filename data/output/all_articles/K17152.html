Known Issue

LSN pool backup member prefixes may not be propagated to the IP routing table.

This issue occurs when all of the following conditions are met:

  • You configure an LSN pool with backup member prefixes.
  • You enable route advertisement for the LSN pool.
  • The tmrouted process is restarted.

Impact

The LSN pool backup members prefix is not included in the IP routing table.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • LSN pool backup-member prefixes are not propagated to the IP routing table after the tmrouted process is restarted.
  • The LSN pool backup members prefix is not included in the IP routing table.

Resolution

Workaround

To work around this issue, you can remove the backup members from the LSN pool configuration, and then add them back to the LSN pool configuration. The backup members prefixes will subsequently be propagated to the IP routing table.

Impact of workaround: Performing the workaround should not have a negative impact on your system.
