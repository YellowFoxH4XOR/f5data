Topic

You should consider using these procedures under the following condition:

  • You want to perform an in-place upgrade for your BIG-IP Next Central Manager instance.

Description

You can upgrade the BIG-IP Next Central Manager using in-place upgrade by performing the following:

  • Download the BIG-IP Next Central Manager upgrade file from MyF5 Downloads site.
  • Back up your BIG-IP Next Central Manager configuration and save a copy to a secure location.
  • Upload the upgrade file to your BIG-IP Next Central Manager instance and upgrade the instance.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have administrative access (admin user access) to your BIG-IP Next Central Manager instance.

Procedures

  • Downloading the BIG-IP Next Central Manager upgrade file
  • Backing up the BIG-IP Next Central Manager configuration
  • Uploading the upgrade file and upgrade the BIG-IP Next Central Manager

Downloading the BIG-IP Next Central Manager upgrade file

Prior to upgrading the BIG-IP Next Central Manager, you must first download the upgrade file from MyF5 Downloads page. To download the BIG-IP Next Central Manager upgrade file from MyF5 Downloads page, perform the following procedure:

Impact of procedure: Performing the following procedures should not have a negative impact on your system.

  1. Go to MyF5 Downloads page.
  2. Sign in to MyF5 portal as needed.
  3. Accept the F5 terms and conditions by checking the I have read and agree to the terms of the End User License Agreement and Program Terms. and select Next.
  4. Select BIG-IP_Next for the Select a product family option.
  5. Select Central Manager (CM) for the Product Line option.
  6. Select the major version you want to download from the Product Version option. For example, 20.2.
  7. Select the version you want to download from the Select a product container option. For example, 20.2.0.
  8. Select the upgrade file with a .tgz extension from the Select a download file option; the upgrade filename should be in the format of BIG-IP-Next-CentralManager-<version>-<build>-Update.tgz. For example, BIG-IP-Next-CentralManager-20.2.0-0.5.41-Update.tgz
  9. Select the location nearest to you from the Download locations option.
  10. Select Download to initiate the download of the BIG-IP Next Central Manager upgrade file to your workstation. Alternatively, you can select the Copy Download Link to copy the download link and use it from the destination workstation/server you want to download the upgrade file.
  11. Repeat steps 8 through 10 for the MD5 file for the upgrade file. The filename should be in the format of BIG-IP-Next-CentralManager-<version>-<build>-Update.tgz.md5.
  12. Follow the instructions described in K8337: Verifying the MD5 checksum for the downloaded F5 software file to verify the integrity of the downloaded upgrade file using MD5 checksum before proceeding to the next procedure.

Backing up the BIG-IP Next Central Manager configuration

Prior to performing an upgrade on your BIG-IP Next Central Manager instance, you should create a backup your BIG-IP Next Central Manager configuration and save it to a secure location. To create a backup of your BIG-IP Next Central Manager configuration, perform the steps described in the Create an Immediate Backup for BIG-IP Next Central Manager procedure of the How to: Back up and restore BIG-IP Next Central Manager. When you have created the backup file, save the backup file to a secure location as described in K175: Transferring files to or from an F5 system.

Uploading the upgrade file and upgrade the BIG-IP Next Central Manager

Impact of procedure: Performing the following procedures should not have a negative impact on your system.

  1. Login to the BIG-IP Next Central Manager webUI as the admin user.
  2. Select the Workspace menu (nine dots in a square formation) located at the top left corner of the webUI.
  3. Select System followed by CM Maintenance.
  4. Select Upgrade under the About BIG-IP Next Central Manager section.
  5. Select Next.
  6. Select Browse under Step 2. Upload or select the upgrade file section; this will pop up a dialog box for you to locate the upgrade file.
  7. Locate the upgrade file with .tgz extension which you have downloaded from MyF5 Downloads page from the previous procedure and select Open.
  8. Select Upload to initiate the upload to the BIG-IP Next Central Manager; wait for the upload to complete. When the upload is completed successfully, the webUI would indicate Upload successful for <upgrade filename.tgz>.
  9. Select Upgrade to initiate the upgrade process.
  10. Select Yes, Upgrade to confirm the upgrade; wait for the upgrade to complete.

    Note: During the upgrade process, the BIG-IP Next Central Manager may undergo a restart of some or all of the containers/services while presenting the webUI for login. However you may not be able to login to the BIG-IP Next Central Manager webUI until the necessary containers/services are started up properly. If you are unable to login properly, you may want to monitor the logs in the /var/log directory and wait for the upgrade process to be completed.
