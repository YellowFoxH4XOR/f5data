01070417:5: AUDIT - client Unknown, user root - transaction #16192273-2 - object 0 - create_if { asm_attack_type { asm_attack_type_name "Other Application Attacks" asm_attack_type_attack_type_bit_index 2 } } [Status=Command OK]

Environment

  • BIG-IP ASM provisioned
  • No ASM policy configured on the virtual server
  • Pool nodes updates

Cause

Bug ID 854177: Pool nodes have frequent IP address updates due to an FQDN node-set to honor DNS TTL.

Recommended Actions

These are cosmetic log messages if no ASM policies are configured. You can ignore the message.
