K43590271: Probing, changing and verifying the default timeout value for iControl REST API F5 Authentication token

Type
Support Solution
Published
2022-03-18
Updated
2025-04-02
Applies to
  • F5 Automation and Orchestration
  • BIG-IP
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K43590271

Description

The default lifetime value for the iControl REST API F5 Authentication token is 1200 sec (20 minutes).
The REST API Reference version 4.5.0 PUB-0281-05" (can be obtained from https://devcentral.f5.com/d/big-iq-systems-rest-api-reference):
The p. 3-53 says:

"Authentication token resource API The authentication token resource manages authentication tokens (cookies) that allow password-less interaction with the REST framework. The authentication tokens are issued for a specific life-time. They are not limited to the default 20 minute life-span of the Apache PAM module authentication mechanism."

Environment

  • 14.0.0
  • POSTMAN

Recommended Actions

Note : Replace <device mgmt ip address> with the IP Address of your device.

  1. Using POSTMAN tool, send POST command to https://<device mgmt ip address>/mgmt/shared/authn/login passing following parameters in body:

    {
    "username":"<username>",
    "password":"<password>",
    "loginProviderName": "tmos"
    }

    You will receive the Auth Token with its timeout value in the response similar to the following :

    {
        "username": "admin",
        "loginReference": {
            "link": "https://<device mgmt ip address>/mgmt/cm/system/authn/providers/tmos/1f44a60e-11a7-3c51-a49f-82983026b41b/login"
        },
        "loginProviderName": "tmos",
        "token": {
            "token": "QJUOOCH2OQZQPCTJ46SHBOJNEG",    <<<================= note the token value.
            "name": "QJUOOCH2OQZQPCTJ46SHBOJNEG",
            "userName": "admin",
            "authProviderName": "tmos",
            "user": {
                "link": "https://localhost/mgmt/shared/authz/users/admin"
            },
            "timeout": 1200,   <<<<=========================================== note the timeout value.
            "startTime": "2019-02-16T17:31:21.660-0800",
            "address": "x.x.x.x",
            "partition": "[All]",
            "generation": 1,
            "lastUpdateMicros": 1550367081660532,
            "expirationMicros": 1550368281660000,
            "kind": "shared:authz:tokens:authtokenitemstate",
            "selfLink": "https://localhost/mgmt/shared/authz/tokens/QJUOOCH2OQZQPCTJ46SHBOJNEG"
        },
        "generation": 0,
        "lastUpdateMicros": 0
     
  2. Using that token, send a PATCH command to change the timeout value:
    Note : Replace <token> with the token value obtained in the previous step.

    Using POSTMAN tool sent PATCH command to https://device mgmt ip address/mgmt/shared/authz/tokens/<token> passing following parameters in body:

    {
     "timeout" : 4200
    }

    And you will see the timeout value is changed to 4200 shown in the example below : 

    {
        "token": "QJUOOCH2OQZQPCTJ46SHBOJNEG",
        "name": "QJUOOCH2OQZQPCTJ46SHBOJNEG",
        "userName": "admin",
        "authProviderName": "tmos",
        "user": {
            "link": "https://localhost/mgmt/shared/authz/users/admin"
        },
        "timeout": 4200,            <<<==========================================   note that the value has changed.
        "startTime": "2019-02-16T17:31:21.660-0800",
        "address": "x.x.x.x",
        "partition": "[All]",
        "generation": 2,
        "lastUpdateMicros": 1550367513072628,
        "expirationMicros": 1550371281660000,
        "kind": "shared:authz:tokens:authtokenitemstate",
        "selfLink": "https://localhost/mgmt/shared/authz/tokens/QJUOOCH2OQZQPCTJ46SHBOJNEG"
     
  3. To verify, send GET request for https://<device mgmt ip address>/mgmt/shared/authz/tokens/<token> with header X-F5-Auth-Token and its value as QJUOOCH2OQZQPCTJ46SHBOJNEG and without any message body.

    You will get a response similar to the following:

    {
        "token": "QJUOOCH2OQZQPCTJ46SHBOJNEG",
        "name": "QJUOOCH2OQZQPCTJ46SHBOJNEG",
        "userName": "admin",
        "authProviderName": "tmos",
        "user": {
            "link": "https://<device mgmt ip address>/mgmt/shared/authz/users/admin"
        },
        "timeout": 4200,
        "startTime": "2019-02-16T17:35:31.000-0800",
        "address": "x.x.x.x",
        "partition": "[All]",
        "generation": 1,
        "lastUpdateMicros": 1550621130999991,
        "expirationMicros": 1550371281660000,
        "kind": "shared:authz:tokens:authtokenitemstate",
        "selfLink": "https://localhost/mgmt/shared/authz/tokens/QJUOOCH2OQZQPCTJ46SHBOJNEG"
    }

Additional Information

The token is valid throughout its lifetime i.e. it can be used for multiple operations while its lifetime.
