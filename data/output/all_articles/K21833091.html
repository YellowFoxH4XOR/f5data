Issue

Error Message

org.xbill.DNS.Tokenizer$TokenizerException: <none>:1: text string too long.

Message Location

You may encounter this message in the following location:

  • The ZoneRunner Configuration utility interface when creating a zone record

Description

This message occurs when the following condition is met:

  • When adding a new DNS BIND TXT record that contains more than 255 characters.

Note: The BIND software package does not support TXT records that exceed 255 characters.

Impact

The BIG-IP system will fail to load the new record.

Recommended Actions

To work around this issue, you can modify the zone file IN TXT record into multiple quoted sections. For more information, refer to Internet Engineering Task Force (RFC 4408) section 3.1.3 and Internet Engineering Task Force (RFC 1035).

Note: This link takes you to a resource outside of AskF5. The third party could remove the document without our knowledge.

For example:

IN TXT "v=spf1 .... 256characterstring..."

The updated IN TXT record is divided into secondary quoted sections:
IN TXT "v=spf1 .... first sting" "second string"
