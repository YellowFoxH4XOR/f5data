Issue

Error Message

err mcpd[<PID>]: 01070978:3: The vlan (<vlan_name>) for the specified self IP (<IP address>) must be one of the vlans in the associated route domain (<route_domain_name>). For example: 192.168.0.1%1234 for self IP in route-domain 1234.

In this error message, note the following:

  • <PID> is the process ID of the mcpd process.
  • <vlan_name> is the Virtual Local Area Network (VLAN) you specified when defining the self IP address.
  • <IP address> is the IP address you are attempting to define.
  • <route_domain_name> is the route domain of the self IP you are attempting to define.

For example:

err mcpd[7985]: 01070978:3: The vlan (/Common/exampleVLAN) for the specified self IP (192.0.2.2) must be one of the vlans in the associated route domain (/Common/example_RouteDomain). For example: 192.168.0.1%1234 for self IP in route-domain 1234.

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility
  • The TMOS Shell (tmsh)

Description

This message occurs when the following condition is met:

  • You attempt to define a self IP address for a VLAN that resides in a non-default route domain without using the relevant route domain ID.

With the BIG-IP system, you are able to configure multiple route domains. A route domain is a BIG-IP object that defines a network configuration that allows the same IP address to exist on multiple VLANs.

Impact

The requested operation is not successful and no changes are made to the system.

Recommended Actions

When defining a BIG-IP object (with an IP address) for a route domain, you must include the relevant route domain ID in the IP address, using the %ID format.

For example, when defining a self IP address for a VLAN that resides in a route domain with an ID of 2, you should use the following self IP address format:

X.X.X.X%2

When defining a self IP address for a VLAN that resides in a route domain with an ID of 20, you should use the following self IP address format:

X.X.X.X%20

Note: The route domain with an ID of 0 (zero) signifies the Default route domain. You do not have to include the relevant route domain ID for IP addresses in the default route domain.
