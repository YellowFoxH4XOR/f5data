Topic

  • You want to use the iControl REST API to obtain a list of established access sessions.
  • You want to use the iControl REST API to delete an access session or delete all access sessions.

Description

You can use the iControl REST API procedures in the article to view, delete a specific access session or delete all access sessions.

Typographic conventions

The following typographic conventions are used in the command syntax examples:

Note: If you are a new user of the iControl REST API, refer to K13225405: Common iControl REST API command examples.

  • <DELETE> = curl -sk -u admin:<password> -X DELETE https://<big-ip apm address>
  • <GET> = curl -sk -u admin:<password> -H "Content-Type: application/json" -X GET https://<big-ip apm address>

Prerequisites

You must meet the following prerequisites to use this procedure:

  • The BIG-IP APM system is licensed, provisioned, and configured with a management IP address.
  • You have administrative access to the BIG-IP APM Configuration utility.
  • You have command line access to a Linux system (or an alternate BIG-IP system) with the curl and jq (command line JSON processor) utilities installed.

Procedures

  • View a list of established access sessions
  • Delete a specific access session ID
  • Delete all access session IDs

View a list of established access sessions

Using the iControl REST API, you can generate a list of established access sessions.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • At the Linux command line, use the following command syntax:

    <GET> /mgmt/tm/apm/access-info | jq -M .

    For example:

    curl -sk -u admin:<password> -H "Content-Type: application/json" -X GET  https://<apm ip address>/mgmt/tm/apm/access-info | jq -M .

    Example command output:

    {
      "kind": "tm:apm:access-info:access-infostats",
      "selfLink": "https://localhost/mgmt/tm/apm/access-info?ver=15.1.0",
      "entries": {
        "https://localhost/mgmt/tm/apm/access-info/9c0a5b2d": {
          "nestedStats": {
            "entries": {
              "clientIp": {
                "description": "192.168.1.72"
              },
              "logonUser": {
                "description": "user1"
              }
            }
          }
        },
        "https://localhost/mgmt/tm/apm/access-info/b7c5ede0": {
          "nestedStats": {
            "entries": {
              "clientIp": {
                "description": "192.168.1.72"
              },
              "logonUser": {
                "description": "user2"
              }
            }
          }
        }
      }
    }

    Note: The access session ID at the end of the URL in the "entries:" subsection (9c0a5b2d and b7c5ede0}.

Delete a specific access session ID

To delete a specific access session ID you can use the following procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. When viewing the list of access sessions, determine the access session ID by locating "logonUser": { "description": in the JSON output. This field is the authenticated username for the access session.
  2. In the "entries": section of the JSON output, locate the following URL syntax that corresponds with the "logonUser". This line precedes the "logonUser" information by 7 to 8 lines in the JSON output.

    https://localhost/mgmt/tm/apm/access-info/<session id>

    Note: In the example command to view all access sessions the access session ID for user1 is 9c0a5b2d.

  3. To delete the access session use the following command syntax:

    <DELETE> /mgmt/tm/apm/session/<session id>

    For example:

    curl -sk -u admin:<password> -X DELETE https://<apm ip address>/mgmt/tm/apm/session/9c0a5b2d

Delete all access sessions

You can use the iControl REST API to delete all access sessions using the following combination of iControl REST URLs and Linux utility commands:

Impact of procedure: Performing the following procedure will delete all access sessions.

<GET> /mgmt/tm/apm/access-info | jq -M . | grep https | grep -v selfLink | sed s'/\// /'g | sed s'/"/ /'g | awk '{system("curl -sk -u admin:<password> -X DELETE https://<big-ip apm address>/mgmt/tm/apm/session/"$7)}'

Note: Replace <big-ip apm address> with the IP address of the BIG-IP APM system, replace <password> with the administrative password of the BIG-IP APM system.

For example:

curl -sk -u admin:<password> -H "Content-Type: application/json" -X GET  https://<apm ip address>/mgmt/tm/apm/access-info | jq -M . | grep https | grep -v selfLink | sed s'/\// /'g | sed s'/"/ /'g | awk '{system("curl -sk -u admin:<password> -X DELETE https://<apm ip address>/mgmt/tm/apm/session/"$7)}'
