Topic

In previous versions of BIG-IP software, the /root/.bash_history command line history file did not contain time stamp information. Therefore, there was no way to determine the date and time that a command was entered in the system.

Beginning with BIG-IP 9.3.0 and 9.4.2, the BIG-IP system adds a time stamp to the history file created for the command line interface. Now, each command that appears in the command line history file contains an associated time stamp that indicates when the operation occurred.

The format of the time stamp contains the following options:

  • %d — day of month
  • %h — abbreviated month name
  • %y — last two digits of year
  • %H — hour
  • %M — minute

For example, the following partial output from the history command shows the date and time each command that was entered at the command line interface:

history command output for BIG-IP 9.3.0, 9.3.1, and 9.4.2 through 9.6.1:

2 20Jul07 17:26 history
3 20Jul07 17:26 cat /VERSION
4 20Jul07 17:27 bigpipe list
5 20Jul07 17:27 history
6 20Jul07 17:28 b platform show
7 20Jul07 17:29 b conn 8 20Jul07
17:29 b list 9 20Jul07 17:29 b self
10 20Jul07 17:30 f5adduser --h
11 20Jul07 17:30 bigpipe interface show

history command output for BIG-IP 10.0.0 and later:

57 2011-01-19 13:05:57 history
58 2011-01-19 13:08:00 cat /VERSION
59 2011-01-19 13:08:03 bigpipe list
60 2011-01-19 13:08:06 history
61 2011-01-19 13:08:11 b platform show
62 2011-01-19 13:08:13 b conn
63 2011-01-19 13:08:16 b list
64 2011-01-19 13:08:20 b self
65 2011-01-19 13:08:27 history

Note: If you want to change the time stamp format displayed by the history command, you must edit the HISTTIMEFORMAT line in the /root/.bash_profile file.
