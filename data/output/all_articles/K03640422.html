Description

Trying to ssh to the command line interface fails with "Unable to negotiate with 192.168.1.10 port 22: no matching key exchange method found.  Their offer: ecdh-sha2-nistp256,ecdh-sha2-nistp384"

  • BIG-IP System is offering a limited set of KexAlgorithms, Ciphers or MACs due to Common Criteria guidelines.
  • Common Criteria Mode is Enabled
  • No matching Methods, Cipher or MACs found error from ssh client.

Environment

  • BIG-IP
  • Common Criteria Mode is enabled
    • tmsh list sys db security.commoncriteria
      sys db security.commoncriteria {
          default-value "false"
          scf-config "true"
          value "true"              <<<<<<<<<<<<  Common Criteria Mode enabled
  • The sshd config file contains the following:
    • /config/ssh/sshd_config
      • # F5 Note
        # The next several items were applied automatically because
        # "tmsh sys db security.commoncriteria" has value "true".
        KexAlgorithms ecdh-sha2-nistp256,ecdh-sha2-nistp384
        MACs hmac-sha1,hmac-sha2-256
        Ciphers aes128-gcm@openssh.com,aes256-gcm@openssh.com,aes128-ctr,aes256-ctr,aes128-cbc,aes256-cbc
        RekeyLimit 256M 3600s
        HostKey /config/ssh/ssh_host_rsa_key
        DisableDSAAuth yes

Cause

Common Criteria Mode offers a limited set of Key Exchange Algorithms, Ciphers and MACs.  The may cause negotiation issues with various ssh clients.

Recommended Actions

Use ssh client that supports the required Key Exchange Algorithms, Ciphers and MACs.

Additional Information

Common Criteria is an international initiative to standardize security functionality and assurance measures. For more information about Common Criteria Certification, refer to the following Common Criteria website:
https://www.commoncriteriaportal.org/
