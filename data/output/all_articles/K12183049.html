K12183049: Mapping VE registration keys after a subscription renewal

Type
Support Solution
Published
2020-08-10
Updated
2026-06-30
Applies to
  • Virtual Editions
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K12183049

Description

After renewing a BIG-IP Virtual Edition (VE) subscription, the existing license keys need to be mapped to the modules on the new subscription. This process extends the support dates on these existing license keys to match the entitlement dates on the renewal. This article describes standard renewal mapping scenarios. For more information on amendment licensing scenarios, refer to K000161949: Amendment order licensing behaviour in BIG-IP Virtual Edition VE subscription.

After the license keys are mapped, the license keys appear on the renewed subscription. This occurs even if the existing subscription has yet to expire. Reload the page after 15 minutes to view these updates. 

Note: You will not be able to see all newly assigned registration keys in MyF5 until you successfully complete the mapping. The submit button remains greyed out until all keys are mapped.
Note: This mapping process doesn't impact the BIG-IPs. This is only an administrative process. The BIG-IPs are only impacted when their license is reactivated.

Environment

  • MyF5 account
  • Admin access to the current subscriptions

Procedure

  1. Visit MyF5 and either sign up for a new account or log in to an existing account. The following figure shows the Sign In page.

     

    Figure: MyF5 Sign In page

  2. After you log in, the Overview page displays, showing your subscription business, as shown in the following figure:
     

     
    Figure: Overview landing page

  3. Select My Products and Plans > Subscriptions or scroll down to the Overview section and select Subscriptions, as shown in the following figure:
     

    Figure: My Products and Plans selection

  4. Identify the renewal subscription by looking for Subscriptions with a status of Active. Then click into the Map Subscription option in the ACTIONS column.
    Important: If the Map Subscription option is greyed out, please reference K000157072: Map Subscription greyed out.

    The Registration Key Mapping page displays. The original expiring subscription and corresponding registration keys are displayed, along with the renewal subscription, as shown in the following figure.
    Important: If "Something went wrong" displays instead, refer to K000133288: Mapping error with VE subscription key.

     

    Figure: Registration Key Mapping page

  5. To map the registration keys to the new subscription, you have two options:
    • Select Configuration Mapping, which maps all keys with a single click. This option is only available for a standard renewal in which you are renewing all keys with no new keys added or discontinued keys.
    • Individually select the registration keys from the picklist under Renewed Subscription, which mirror those under Existing Subscription. As you select the available registration keys, the mirrored under Existing Subscription become grayed out, indicating that they are no longer available in this configuration.

    Important: If this is an up-sell and additional keys are added to the renewal opportunity, the additional keys appear as all X's until after the mapping is successfully completed.

     

    Figure: Map registration keys to new subscriptions

  6. Please read below before clicking Submit.
    Important: This mapping cannot be undone. Follow K000139475 to resolve.
    • All license keys must be populated before the Submit becomes active.
    • Before submitting the final mapping, if the selections need to be adjusted, clear all selections on the page by selecting Reset.

  7. After the license keys are mapped to the new subscription, and these selections verified and confirmed, select Submit. 
    • Any unassigned registration keys become inactive and are no longer available for use.
    • The interface displays the following warning message: After clicking submit, any unassigned Reg Keys will become inactive. You will no longer be able to use these to activate another device per the image below.
    • Additionally, these unassigned keys no longer have entitlement and can't be reactivated on the existing BIG-IP VE. 

       

      Figure: Submission
