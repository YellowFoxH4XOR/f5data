Known Issue

This is the result of a known issue. The bigstart utility can be used to control services on the BIG-IP system. The bigstart status command provides a status on the specified system services.

When the qkview script is run on a VIPRION system, the bigstart status command is only run on the primary blade and not run on the secondary blades. As a result a tech.out file obtained from a VIPRION system will only contain system service status from the primary blade.

F5 Networks Product Development tracked this issue as CR106361 and it was fixed in BIG-IP version 10.0.0. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in BIGIP-9.6.1-839.0-HF3, which has been issued for BIG-IP version 9.6.1.You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
