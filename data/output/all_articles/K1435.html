Known Issue

This is the result of a known issue. The Configuration utility allows a maximum of 15 characters for an Auth Model role in the Valid Roles list.

F5 Product Development tracked this issue as CR28217 and CR41898.

Workaround

To enter an Auth Model role name with more than 15 characters in the Valid Roles list, perform the following steps:

  1. Log in to the command line.
  2. Add the desired role name, using the following command syntax:

    bigpipe authz <model> ldap valid roles <role>

    For example:

    bigpipe authz MyLDAPModel ldap valid roles ThisIsLongerThan15
  3. Save the configuration, by typing the following command:

    bigpipe save
