Description

Configuring remote syslog with RFC5424

Environment

  • LTM
  • Remote syslog

Cause

None

Recommended Actions

Use the below syslog include syntax to send all logs to remote syslog using RFC5424 format:

  • tmsh modify /sys syslog include "destination remote_server {<udp|tcp>(\"<replace with correct syslog server IP>\" port (<port number>) localip(<replace with correct self-ip>) flags(syslog-protocol));};filter f_alllogs {level (debug..emerg);};log {source(local);filter(f_alllogs);destination(remote_server);};"

For example, to send all log to remote syslog 192.0.2.1 via UDP port 514 with BIG-IP self-ip 192.0.2.2:

  • tmsh modify /sys syslog include "destination remote_server {udp(\"192.0.2.1\" port (514) localip(192.0.2.2) flags(syslog-protocol));};filter f_alllogs {level (debug..emerg);};log {source(local);filter(f_alllogs);destination(remote_server);};"

To save the syslog include configuration, enter the following command:

  • tmsh save /sys config

Additional Information

  • Using flags(syslog-protocol) you should be able to let those log messages sent remotely using format RFC5424. Below show the difference between the two:
    • Without flags(syslog-protocol)
      • <133>Jan 10 17:20:06 LTM.example.com tmsh[14538]: 01420002:5: AUDIT - pid=14538 user=root folder=/Common module=(tmos)# status=[Command OK] cmd_data=save sys config
    • With flags(syslog-protocol)
      • <133>1 2023-01-10T17:24:32-08:00 LTM.example.com tmsh 14538 - - 01420002:5: AUDIT - pid=14538 user=root folder=/Common module=(tmos)# status=[Command OK] cmd_data=save sys config
