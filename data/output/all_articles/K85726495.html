Description

You see this 'configuration has not yet loaded' in GUI right after re-activate the license
tmsh load sys config verify will fail, and stderr is similar to below:

Syntax Error:(/config/bigip.conf at line: 1447) "OK recv-disable none send GET" unknown property

In ltm log, you will find similar output:

err tmsh[22648]: 01420006:3: "OK recv-disable none send GET" unknown property

Restoring ucs does not resolve the issue

Environment

  • Prior to upgrade, you performed a license re-activation. 

Cause

F5 has created internal Bug ID for this issue.
Bug ID 579694 [GUI] GUI does not do validation check for Trailing backslash in http monitor send string

Syntax Error:(/config/bigip.conf at line: 1447) "OK recv-disable none send GET" unknown property

This message actually complains the some http monitor above line 1447 in bigip.conf that has unbalanced quotation. For example.

send "GET / HTTP/1.1\r\nHost: example.com\r\nConnection: Close\r\n\r\"

Recommended Actions

1. Manually edit bigip.conf. Make sure send string ends with \n before the closing quotation mark.

send "GET / HTTP/1.1\r\nHost: example.com\r\nConnection: Close\r\n\r\"
-change to- 
send "GET / HTTP/1.1\r\nHost: example.com\r\nConnection: Close\r\n\r\n"   

2. tmsh load sys config verify should be successful. Then run
tmsh load sys config
