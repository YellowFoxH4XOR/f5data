What Happened?

  • I tried to setup a Service Policy rule to block an IP from accessing my application.
  • Now all IPs are blocked.

Environment

  • Service Policy

Resolution/Answer

You probably created another row for an IP and left it blank like in the following example:

If you create an empty row for clients and save, then its equal to match all.

To fix the issue you need to remove the empty row.
