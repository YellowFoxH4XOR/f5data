Description

How to use an iRule to log incoming client addresses, and how to enable or disable logging using the DEBUG variable.

Environment

  • iRule

Cause

None. This article serves as an informational guide.

Recommended Actions

  1. Create an iRule with the following content: 
    when HTTP_REQUEST {
    set DEBUG 1  --- > # 1 to turn on, 0 to turn off
    if { $DEBUG } { log local0. "client: [IP::remote_addr] -> [HTTP::host][HTTP::uri]" }
}

Attach the iRule to a virtual server to start logging incoming client addresses.

  1. To enable or disable logging, set the DEBUG variable to 1 (enabled) or 0 (disabled) in the iRule.

Additional Information

The value of the expression must be a boolean (a numeric value, where 0 is false and anything is true, or a string value such as true or yes for true and false or no for false); if it is true, then the iRule executes body1 by passing it to the Tcl interpreter.
For more information on iRules, expressions, and if statements, refer to this F5 Community article: iRules 101-02: If and Expressions
