Description

The Edge Client hangs "Initializing".

The /var/log/apm log does not show PPP starting for that Session.

The /var/log/apm log has "err tmm[24085]: 0149059c:3: (null):(null):: MYVPN Error: Invalid sidlen 0"

The Client Diagnostic shows "CURDialer::OnRasCallback(), RAS error (state=RASCS_Disconnected, error=628: The connection was terminated by the remote computer before it could be completed.)"

 

Environment

  • The Configuration uses DTLS.

Cause

The DTLS Virtual Server has a HTTP profile applied.

Recommended Actions

Remove the HTTP Profile from the DTLS Virtual Server. The DTLS Virtual Server correct configuration is described here: https://my.f5.com/manage/s/article/K54955814

Additional Information

Although the configuration is incorrect, it does not cause an issue in all deployments.
It is possible that this issue occurs after an upgrade.
