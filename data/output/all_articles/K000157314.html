Description

BIG-IP is not responding to SNMP polls received on self-IP after adding this self-IP address to the agent-addresses config.

For example:

---

sys snmp {

  agent-addresses { <self-ip>:161 }

}

Environment

- LTM

- SNMP configured with custom agent-addresses

 

Cause

If you want to open port for SNMP on self-IP, you must use self-IP port lockdown (K17333) and not snmp agent-addresses setting.

 

Recommended Actions

Revert sys snmp agent-addresses to default (tcp6:161 udp6:161), save config, and restart snmpd daemon.

 

(tmos)# modify sys snmp agent-addresses replace-all-with { tcp6:161 udp6:161 }

(tmos)# save sys config

(tmos)# quit

# bigstart restart snmpd

 

Additional Information

K17333: Overview of port lockdown behavior (12.x - 17.x)
