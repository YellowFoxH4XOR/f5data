Description

You may be unable to login via tmsh and see the following errors:

  • Login failed via non-admin users
  • In /var/log/ltm: 
    crit tmsh[20720]: 01420001:2: Can't create temp directory, /var/system/tmp/tmsh/mNNyVw, errno 13] Permission denied : framework/TempDir.cpp, line 216
  • Error messages via SSH login:
    [root@localhost ~]# ssh username@192.168.1.100
    Password:
    exception: (Can't create temp directory, /var/system/tmp/tmsh/1v35Lw, errno 13] Permission denied) (framework/TempDir.cpp, line 216), exiting...

Environment

  • SSH
  • TMSH

Cause

Bug ID 769029

Recommended Actions

To prevent this issue, you may try any one of the three workarounds:

  • You can login as a root user to execute system commands.

  • You can use the user_alert.conf to detect the error log and auto change /var/system/tmp/tmsh/ dir permission by invoking a script chmodtmptmsh.sh. When /var/log/ltm appear log "01420001:2: Can't create temp directory /var/system/tmp/tmsh/", the script chmodtmptmsh.sh will change directory permission  to 1777. Even though you see this error, but script will execute and fix the error.

  1. Create /config/user_alert.conf and add the following content.
    alert SWICH_TMPTMSH_PERM "01420001:2: Can't create temp directory, /var/system/tmp/tmsh/" { exec command="/shared/tmp/chmodtmptmsh.sh" }
    Please refer to this article in details:  K14397: Running a command or custom script based on a syslog message

  2. Create /shared/tmp/chmodtmptmsh.sh, file content is following:
    #!/bin/sh
    chmod 1777 /var/system/tmp/tmsh

  3. Change the file chmodtmptmsh.sh permission. execute follow command add execute permission.
    chmod 755 /shared/tmp/chmodtmptmsh.sh

  4. Restart the alertd process, execute follow command.
    bigstart restart alertd

  • You can modify tmpwatch file and let the cron job not delete tmsh dir, but it will delete old tmp files of one day ago.

  1. Edit /etc/cron.daily/tmpwatch: vi /etc/cron.daily/tmpwatch

  2. Locates this line in tmpwatch: /usr/sbin/tmpwatch 1d /var/system/tmp 

  3. Replace it with: /usr/sbin/tmpwatch --nodirs 1d /var/system/tmp
