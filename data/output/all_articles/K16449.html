Known Issue

The BIG-IP system may unnecessarily retransmit packets when receiving Internet ControL Message Protocol (ICMP) Type 3 Code 4 (Fragment Needed) messages.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system has established a TCP connection with a client.
  • Your BIG-IP system receives an ICMP Fragmentation Needed message from the client requesting a smaller Maximum Transmission Unit (MTU), for example 1490 bytes.
  • Your BIG-IP system sends a TCP packet to the client using the 1490 MTU.
  • Your BIG-IP system receives an additional ICMP Fragmentation Needed message from the client for the same MTU of 1490.
  • Your BIG-IP system resends previously sent TCP messages with a 1490 MTU, even though the MTU size has not changed.

Impact

There will be additional network congestion due to unnecessary packet retransmissions.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You notice additional packet retransmissions on the network.

Workaround

To work around this issue, you can disable path MTU discovery. To do so, perform the following procedure:

Impact of workaround: This is a global setting that impacts all connections to the BIG-IP system, and may have adverse effects on traffic handling, which requires a smaller MTU. Contact F5 Technical Support if you are uncertain about the impact of this modification.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To disable the Path MTU Discovery setting, type the following command:

    modify sys db tm.enforcepathmtu value disable
