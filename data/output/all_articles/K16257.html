Known Issue

The avrd process may produce a core file and restart while capturing traffic to an external logging system. This issue occurs when all of the following conditions are met:

  • The BIG-IP system is provisioned with the BIG-IP Analytics (AVR) module.
  • A virtual server is associated with an AVR profile that includes the following properties:
    • The Traffic Capturing Logging Type setting is set to External.
    • The Publisher setting is set to a remote logging system.
    • Under the Capture Filter section, the Capture Requests or Capture Request Details settings are set to the Body, Header or All options.

Impact

The BIG-IP system is unable to collect statistics and generate reports while the avrd process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system is unable to collect statistics while the avrd process restarts.
  • The BIG-IP system is unable to generate reports while the avrd process restarts.
  • The BIG-IP system produces an avrd core file in the /shared/core directory.
