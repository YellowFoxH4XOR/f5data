Known Issue

Citrix applications with names that contain an ampersand fail to start through the BIG-IP APM system.

This issue occurs when all of the following conditions are met:

  • Users attempt to access a Citrix application from a BIG-IP APM webtop or Citrix Receiver.
  • The name of the published application contains an ampersand.

Impact

Users cannot access Citrix applications from a BIG-IP APM webtop or Citrix Receiver.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H431320 on the Diagnostics > Identified > Medium screen.
  • Citrix applications fail to launch when accessed from the BIG-IP APM system.
  • Invalid parameter messages, similar to the following example, appear in the /var/log/apm file:

    notice tmm[13534]: 01490505:5: d0fc63ef: Invalid parameter (_-+{}`~,&LogonTicket) value (020EDE6FDEB7A963F46D362E54C93B)
