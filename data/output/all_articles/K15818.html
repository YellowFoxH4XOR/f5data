Known Issue

The Configuration utility may produce an error message when you modify members of a wide IP pool.

This issue occurs when the following condition is met:

  • You use the Configuration utility to modify an existing wide IP pool of virtual servers on a BIG-IP Link Controller system.

Impact

You cannot modify the pool.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When using the Configuration utility to modify the wide IP pool of virtual servers, you observe an error message that appears similar to the following example:

    HTTP Status 404 - type Status report message description
    The requested resource is not available.
    Apache Tomcat/6.0.41

Workaround

To work around this issue, you can delete and recreate the wide IP or use the Traffic Management Shell (tmsh) to modify the wide IP pool. To do so, perform the following procedure:

Impact of workaround: The following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. To add/delete pool members, use the following command syntax:

    modify /gtm pool <pool name> members <add/delete/replace-all-with> { <server_name>:<partition path/virtual_server_name> }

    For example:

    modify /gtm pool test.mylab.local members add  { lc.mylab.local:/Common/vs1 }
  3. To save the pool configuration modifications, type the following command:

    save /sys config
  4. To exit the tmsh utility, type the following command:

    quit
