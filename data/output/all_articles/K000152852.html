K000152852: AOM Display Issues After Downgrading F5OS from 1.7.0 to 1.5.x Due to LCD UI Firmware Mismatch

Type
Support Solution
Published
2025-08-01
Updated
2025-08-01
Applies to
  • F5OS
  • F5OS-A: 1.7.X, 1.5.X, 1.7.0, 1.5.3, 1.5.2, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000152852

Description

This article addresses an issue where the Advanced Out-of-band Management (AOM) display on F5OS-A appliances behaves abnormally after the system is upgraded to F5OS version 1.7.0 and then downgraded back to 1.5.x. Customers may notice missing or incorrect information on the AOM LCD panel, or even a blank display, after such version changes.

Environment

  • iSeries
  • AOM
  • F5OS-A 1.7.0

Cause

When F5OS is upgraded from 1.5.x to 1.7.0, the LCD UI firmware is also upgraded from version 1.11.0 to 1.13.12. If the system is later downgraded back to 1.5.x (including via clean installation), the LCD UI firmware does not automatically downgrade and remains at 1.13.12.

The LCD UI version 1.13.12 is designed to display HOSTNAME, MGMT address, and OS version. However, a known issue (bug ID1583629) can cause the AOM to display incorrect information, show a blank screen, or fail to show any details in the System Info page when running F5OS 1.5.x with LCD UI 1.13.12. 

Recommended Actions

The actions or steps required to address the topic covered in the description.

1. Check the LCD UI version

  • Run the following command to verify the current and target LCD UI firmware version:
    docker exec -it platform-fwu psf call GET:firmware/lcd/ui
  • Output example:
      field                     | value
    ----------------------------+----------
      actionRequiredAfterUpdate | none
      componentLocation         |
      componentSubtype          | ui
      componentType             | lcd
      currentVersion            | 1.13.12
      targetVersion             | 1.11.0
      updatePolicy              | newer
      updateRequired            | false

2. Apply the workaround for bug ID1583629:

  • Follow the documented workaround to manually downgrade the LCD UI firmware from 1.13.12 to 1.11.0.
  • After applying the workaround, the AOM should return to normal operation:
    • The default AOM page will display only the model (e.g., "r2600").
    • The System Info page (accessed by touching the screen) will show detailed information such as HOSTNAME, MGMT address, and OS version.
    • As shown in Understanding AOM Display Behavior with Different LCD UI Versions on F5OS-A Appliances .

Additional Information

  • This issue is specific to scenarios where the F5OS-A system is upgraded to 1.7.0 (which updates the LCD UI firmware) and then downgraded to 1.5.x.
  • Clean installation of F5OS 1.5.x does not revert the LCD UI firmware to 1.11.0.
  • After applying the workaround and downgrading the LCD UI firmware, the AOM display should function as expected.
