Description

Device Certificates Renewed and iQuery Connection failing with unsupported certificate error.

  • Results in: ssl3_read_bytes:sslv3 alert unsupported certificate:s3_pkt.c:1498:SSL alert number 43 SSL return code: SSL_ERROR_ZERO_RETURN
  • DNS Log may contain events similar to:
    • err gtmd[11111]: 011ae114:3: iqmgmt_ssl_connect: SSL error: error:14094413:SSL routines:ssl3_read_bytes:sslv3 alert unsupported certificate (12345678) from connection 10.10.10.10

Environment

  • DNS
  • iQuery
  • Device Certificates
  • Third-Party Signed Certificates

Cause

When device certificates were issued the SSL Client extension was not included. You can use the following command to check the certificate.

openssl x509 -noout -purpose -in /config/httpd/conf/ssl.crt/server.crt | grep -iE | grep -iE 'client|server'

SSL client : No <<<<<<<<<< This needs to be Yes
SSL client CA : No
SSL server : Yes
SSL server CA : No

Recommended Actions

Re-Issue Certificates with required extensions and import to devices.

Additional Information

For information about the deprecation of clientAuth EKU for public certificates generated by Public Key Infrastructure (PKI) certificate authorities (CA) and what you can do to prepare, you may want to refer to the F5 DevCentral article: The End of ClientAuth EKU…Oh Mercy…What to do?.
