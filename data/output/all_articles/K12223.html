Issue

The BIG-IP WebAccelerator 4500 platform ships with two hard drives in a hardware RAID configuration. If the RAID becomes degraded, the BIG-IP system logs an error message that appears similar to the following example to the /var/log/raid_monitor.log file:

RAID monitor: RAID is degraded.  Run 'rebuild_raid -s' for more information.

If you encounter this log message, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. View the RAID status by typing the following command:

    rebuild_raid -s

    Output will appear similar to the following example:

    RAID status: DEGRADED
    HDD 1 status: OK
    HDD 2 status: DEGRADED
     
  3. If the RAID status is reported as DEGRADED, rebuild the RAID by typing the following command:

    rebuild_raid -r

    Wait for the command to complete.
     
  4. Verify whether the RAID was repaired by typing the rebuild_raid -s command again.

    If the repair was successful, output should appear similar to the following example:

    RAID status: OK
    HDD 1 status: OK
    HDD 2 status: OK

    If the RAID is still reported as DEGRADED, or if the issue clears and then reappears, run the EUD utility and open a case with F5 Technical Support.

    Note: For information about the EUD software, such as downloading and running the EUD, and EUD fixes and enhancements, refer to the End User Diagnostics release notes.

    Note: For instructions about checking the EUD version on your BIG-IP system, refer to K8002: Determining the End-User Diagnostics version.
