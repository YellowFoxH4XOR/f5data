Description
BIG-IP is not responding to SNMPv3 UDP 161 traffic. When running a snmpwalk you get a timeout and fails with the following error:
snmpwalk: Timeout

Environment

  • SNMPv3

Cause
agent-address feature in the SNMPv3 configuration is configured with "none" and it needs to be configured with the listening ports.

Recommended Actions
Make sure the SNMP on the BIG-IP is configured with listening ports. The system default agent addresses are defined as per below:
agent-addresses { tcp6:161 udp6:161 }

  1. Modify the bigip_base.conf in a text editor to add the listening ports in the agent-addresses stanza.
  2. Load the configuration with the following command:
    tmsh load sys config
  3. Restart SNMPD 
    tmsh restart sys service snmpd

Additional Information
Refer to documentation on configuring SNMP for details on configuration items:

# tmsh help sys snmp
agent-addresses
     Indicates that the SNMP agent is to listen on the specified
     address. F5 Networks recommends that you do not change this
     setting without fully understanding the impact of the change.
