K000091185: Unable to install Nginx Controller with error "Failed to find mTLS information. Cannot decommission the license for this NGINX Controller"

Type
Support Solution
Published
2021-12-27
Updated
2022-07-17
Source
https://my.f5.com/manage/s/article/K000091185

Description

  • You provisioned a Linux System that suffice Nginx Controller minimum requirements
    • https://docs.nginx.com/nginx-controller/admin-guides/install/nginx-controller-tech-specs/#hardware-specifications
  • You successfully installed all of the Controller's pre-requisites tools using the "helper.sh prereq" Script
    • https://docs.nginx.com/nginx-controller/admin-guides/install/install-nginx-controller
  • However, the instillation fails to complete, terminates with error and exit the instillation process with the below error
    • Failed to find mTLS information. Cannot decommission the license for this NGINX Controller

 Environment

  • Nginx Controller
  • HTTP Proxy

 Cause

  • The Host system resides behind an HTTP Proxy

 Recommended Actions

  • If the Host system/computer resides behind an HTTPs proxy, the recommendation is to disable the proxy relating to the IP address and hostname of the host computer
  • The host computer refers to the system on which the NGINX Controller is being installed
  • To disable HTTPS proxy, follow the command " export NO_PROXY=<current_ip>,<current_hostname> "
    • For more reading refer, https://docs.nginx.com/nginx-controller/admin-guides/install/install-nginx-controller/#install-nginx-controller

 Additional Information

  • None
