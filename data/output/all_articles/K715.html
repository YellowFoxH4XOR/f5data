Known Issue

This is the result of a known issue. You should only enter a netmask when you create a network virtual server. The Configuration utility erroneously prompts you to enter a netmask when you create an individual virtual server. If you enter a netmask for the individual virtual server, the Configuration utility does not allow you to remove it.

F5 Networks Product Development tracked this issue as CR40884 and CR41862.
