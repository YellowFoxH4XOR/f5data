Description

How to delete a BIG-IP device from BIG-IQ using GUI.

Note: If the BIG-IP IP address has been manually changed since being discovered by BIG-IQ refer to:
K39233324: BIG-IP systems report being managed by the BIG-IQ system after being removed from the BIG-IQ system's device inventory 

Environment

  • BIG-IQ
  • Remove BIG-IP from BIG-IQ

Cause

None

Recommended Actions

  1. Using GUI from BIG-IQ go to
    Devices Tab > BIG-IP Devices >> Select the device that you want to delete and click on Remove All Services.
  2. If step 1 fails, review error message and see Additional Information section.
  3. You will see a notice that the services have been successfully removed, then select the device and click on Remove Device.

Note: If the above steps are unsuccessful or result in an error, refer to the following article:
K34143072: How to manually delete a BIG-IP device which can not be re-discovered or deleted from BIG-IQ
