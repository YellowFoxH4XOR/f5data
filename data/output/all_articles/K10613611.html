Issue

Error Message

01690000:5: shutdown cleanly

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The evrouted process has cleanly shutdown. This typically happens when the BIG-IP system is shutting down or rebooting.

Note: The evrouted process handles all events on the local control plane, and directs the messages to the appropriate subscribed process.

Impact

There is no impact; this message is informational.

Recommended Actions

None
