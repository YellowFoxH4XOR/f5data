Issue

OPSWAT Endpoint Security (EPSEC) software development kit (SDK) (OESIS) version change.

Old Behavior

In the BIG-IP APM OPSWAT Endpoint Security Integration update release 470.0 and earlier, F5 used OPSWAT OESIS 3 SDK.

New Behavior

Beginning in the OPSWAT Endpoint Security Integration (epsec) update release 489.0 and later, F5 added the OPSWAT OESIS 4 SDK.

With the move to OESIS 4, OPSWAT also renamed some of the product categories to align with current industry terminology. The changes are as follows:

  • AntiVirus and AntiSpyware product categories were merged to create a single category called Anti-Malware.
  • Peer to Peer changed to File Sharing. 

The new categories are listed in the OPSWAT Application Security Integration Support Charts available from the BIG-IP system. To access these files in the Configuration utility, click the F5 ball at the top of the page, and click OPSWAT Application Security Integration Support Charts.

Alternatively, you can browse  to the following URL: https//<BIG-IP_mgmt_IP>/sam/admin/vpe2/public/php/supportTable.php

F5 Product Development tracked this change as ID 507798.

Impact

The OESIS 4 libraries include increased support coverage for more products of top security applications in the market. You may see that products that were previously mapped to the other products category will now be mapped to more specific products.  Also OESIS 4 libraries provide enhanced granular classification and reporting of endpoint security products by their functional components (for example, products that have both anti-malware and firewall components).

In OESIS 4, support for some legacy products has been removed, support for some new products has been introduced, and support for some products was unchanged. For specific information, refer to the following document:

Important: The following link points to a document that lists products for which support was removed, added, or has not changed in the OPSSWAT Endpoint Security Integration update for release 489.0. F5 provides this information so you understand the types of changes that were made specifically for the 489.0 release. It is important to understand that the specific list of supported products will likely change in subsequent update releases. Whenever you update an OPSWAT release, F5 recommends that you review your BIG-IP APM policies to determine if any modifications will be required after you upgrade to the new OPSWAT release.

OPSWAT 3 to OPSWAT 4 update 

The document contains the following sections:

  • Removed from OESIS 4 release - List of legacy products that were previously available in the OPSWAT EPSec 470.0 (OPSWAT 3) release but will no longer be available in the OPSWAT 4 release.
  • Added with OESIS 4 release - List of products that will be introduced in the OPSWAT 4 release.
  • Unchanged with OESIS 4 release - List of products that were previously available and will still be available in the OPSWAT 4 release. 

Recommended Actions

When planning for an upgrade to the March 2017 (or later) OPSWAT release, F5 recommends that you review your BIG-IP APM policies to determine if any modifications will be required after you upgrade to the new OPSWAT release.
