Known Issue

This is the result of a known issue. BIG-IP GTM object names containing the following characters may cause navigation issues in the Configuration utility:

  • slash ( / )
  • question mark ( ? )
  • equal ( = )
  • ampersand ( & )

For example, if you create a BIG-IP GTM server object with a name containing one of the listed characters, and you enable or disable a virtual server that is defined as a resource for the server object, the virtual server disappears from the Resources page, or you are returned to an alternate Configuration utility page after clicking the Enable or the Disable button. In addition, after enabling or disabling the virtual server object, the breadcrumb trail on the Configuration utility page may indicate a nonexistent or incorrect path.

Note: If the virtual server disappears from the Resources page, it will reappear when you navigate back to the virtual server resources page (Global Traffic >>  Servers >> my_server >> my_virtual_server).

F5 Product Development is tracking this issue as ID 249341 (formerly CR122809).

This issue does not affect the BIG-IP GTM 10.x software branch.
