Description

Pushing a configuration containing the directive ssl_ocsp leaf; to a NGINX Plus instance by using NGINX Instance Manager fails with the following error:

error reading config from /etc/nginx/nginx.conf, error: invalid value "leaf" in "ssl_ocsp" directive, it must be "on" or "off"

Applying the same configuration directly on the NGINX Plus instance works without error.

This prevents management of OCSP configurations with the "leaf" parameter through NGINX Instance Manager.

Environment

  • NGINX-agent version earlier than 2.44.0
  • NGINX Instance Manager version 2.20.0
  • Configuration must include: ssl_ocsp leaf;

Cause

A bug in the NGINX Agent’s external validation library used by NGINX Instance Manager restricts accepted values for the ssl_ocsp directive to only "on" or "off", incorrectly rejecting the valid "leaf" parameter. This validation issue only occurs when pushing configurations via NGINX Instance Manager.

Recommended Actions

Workaround:

  • Use "on" or "off" for the ssl_ocsp directive when pushing configurations via NGINX Instance Manager if the "leaf" parameter is not required.
  • If the "leaf" parameter is required, apply the configuration directly on each NGINX Plus instance until a fix is available.

Permanent fix:

  • Upgrade NGINX Agent to version 2.44.0 which includes a fix for this issue.
  • You can download the new agent from the following URL: https://github.com/nginx/agent/releases/tag/v2.44.0
