Known Issue

A client browser may not trust certificates issued by the BIG-IP SSL forward proxy. This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP system with an SSL forward proxy configuration. This applies to F5 SSL Orchestrator deployments.
  • The Client SSL profile used by the SSL forward proxy configuration is configured with the same certificate for both the Certificate Key Chain setting and the CA Certificate Key Chain setting (under the SSL Forward Proxy section).
  • The certificate used in both settings contains a subjectKeyIdentifier (SKI) certificate extension.

In the BIG-IP SSL forward proxy, the SKI of a CA certificate is typically included in the certificate issued by the BIG-IP SSL forward proxy to the clients. This allows a client browser to chain together the certificate path. When the Certificate Key Chain setting contains the same certificate as the CA Certificate Key Chain setting, the certificate issued by BIG-IP SSL forward proxy would have the same value for both the authorityKeyIdentifier (AKI) and SKI certificate extensions. As a result, the client browser is unable to determine the certificate path and reports a warning.

Impact

A client browser does not trust the certificate issued by the BIG-IP SSL forward proxy and reports a certificate verification warning.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • A client browser does not trust the BIG-IP SSL forward proxy certificate and reports a certificate verification warning ERR_CERT_AUTHORITY_INVALID.
  • The BIG-IP SSL forward proxy certificate received by the client browser contains the same value for both the AKI and SKI certificate extensions.

Workaround

To work around this issue, you should ensure that you do not use the same certificate for both the Certificate Key Chain setting and the CA Certificate Key Chain setting of the affected Client SSL profile. You should ensure that these two settings use different certificates. Before changing the certificate for either setting, you must ensure that you have already imported the certificate you want to the BIG-IP system. For information on importing the certificate to the BIG-IP system, perform the procedure appropriate for your environment using one of the following articles:

  • K14620: Manage SSL certificates for BIG-IP systems using the Configuration utility
  • K15462: Managing SSL certificates for BIG-IP systems using tmsh

To change the certificate configured for either of the settings, perform the procedure appropriate for your deployment.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  • BIG-IP SSL Forward Proxy
  • F5 SSL Orchestrator

BIG-IP SSL Forward Proxy

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > SSL > Client.
  3. Click the name of the affected Client SSL profile used in the SSL forward proxy configuration.
  4. Depending on your application environment, you should perform steps 5 through 10 on either the Certificate Key Chain setting or the CA Certificate Key Chain setting (under the SSL Forward Proxy section).
  5. Select the configured certificate in either the Certificate Key Chain setting or the CA Certificate Key Chain setting.
  6. Click Edit.
    A dialog box in the Configuration utility appears for editing the certificate key chain.
  7. For Certificate and Key, select the certificate and key you want.
  8. For Chain, select the appropriate chain certificate, as needed.
  9. For Passphrase, enter the certificate passphrase, as needed.
  10. To save the change, click OK.
  11. To save the change to the Client SSL profile, click Update.

F5 SSL Orchestrator

  1. Log in to the Configuration utility.
  2. Go to SSL Orchestrator > Configuration.
  3. Click SSL Configurations.
  4. Click the name of the affected SSL configuration.
  5. Depending on your application environment, you should perform steps 6 through 10 on either the Certificate Key Chain setting or the CA Certificate Key Chain setting under the Client-side SSL section.
  6. Click Edit (the pencil icon) on the right of the configured certificate in either the Certificate Key Chain setting or the CA Certificate Key Chain setting.
  7. For Certificate and Key, select the certificate and key you want.
  8. For Chain, select the appropriate chain certificate, as needed.
  9. For Passphrase, enter the certificate passphrase, as needed.
  10. To save the change, click DONE.
  11. To deploy the change, click Deploy.
