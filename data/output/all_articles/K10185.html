Known Issue

This is the result of a known issue. If a Mac OS X user kills the browser they are using to connect to the FirePass device while there is an active Network Access session, the svpn process does not die. As a result, the next time the user attempts to launch Network Access, the connection will fail. This issue occurs with the Firefox and Safari browsers.

F5 Product Development tracked this issue as CR106776 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative HF-603-3, which has been issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

For a list of the latest hotfixes, refer to K10322: FirePass hotfix matrix.

Workaround

You can work around this issue by either rebooting your computer or manually killing the svpn process. To manually kill the svpn process, perform the following procedure:

  1. Open the Activity monitor from the /Applications/Utilities/ folder.
  2. Click the svpn process from the list of processes.
  3. Click the Quit Process button in the upper-left corner of the Activity monitor window.
