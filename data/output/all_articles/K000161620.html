Description

UCS load can fail  after manually uploading bot signature file in new BIG-IP  device.

Environment

  • Bot Signature
  • UCS
  • ASM

Cause

UCS is taken of the device with new bot signature files and then tried to load that UCS to a new BIG-IP device with default config with old bot signature.

Since, UCS contains the new bot signature  in the config file, UCS load will fail so same version  bot signature need to be loaded in the new device before attempting to load the UCS.

Now, there are two ways to load bot signature. Automatic update or Manual update.

In Automatic mode, bot signature will be downloaded and installed and UCS can be loaded successfully.

But in Manual mode, bot signature file has to be manually downloaded and then upload and then install it. It is observed that after this manual bot signature update, UCS still fails to load as shown in below example.

Example:

Before uploading the bot signature, it shows three signature related to CVE.

# cat bigip.conf | grep -i "cve"

security bot-defense signature "/Common/Exchange RCE Detector(CVE-2021-34473)" {
security bot-defense signature /Common/CVE-2019-11043 {
security bot-defense signature /Common/CVEScraper {

After uploading the bot signature manually, it still shows only three signatures related to CVE.

# cat bigip.conf | grep -i "cve"

security bot-defense signature "/Common/Exchange RCE Detector(CVE-2021-34473)" {
security bot-defense signature /Common/CVE-2019-11043 {
security bot-defense signature /Common/CVEScraper {

Error can be seen as shown below in the screen during UCS load after manual signature update:

load_config_files[35049]: "/usr/bin/tmsh -n -g -a load sys config partitions all  platform-migrate" - failed. -- 01070277:3: The requested signature (/Common/exploit tool for CVE-2023-2227) was not found.

But status shows that bot signature is installed successfully.  This happens because new signature file in config is still missing as config was not saved after signature manual file update. Now, After saving the config, it shows more signature related to CVE and UCS can be loaded successfully.

# tmsh save sys config

Answer/Recommended Actions

Save the config after manual bot signature file upload and then attempt UCS load.

# tmsh save sys config
