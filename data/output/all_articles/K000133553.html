K000133553: Creating a LTM policy configuration with double quotes requires escape character

Type
Support Solution
Published
2023-04-18
Updated
2023-04-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000133553

Description

Double quotes used in the LTM policy configuration are removed when saving the policy

When entering the literal string in the LTM policy rule "value" such as

header-replace value Bearer realm="https://abc-test.example.com/service/token,service=apple"

Value becomes Bearer realm=https://abc-test.example.com/service/token,service=apple

How do we keep the double quotes on the value?

Environment

  • LTM Policy

Cause

Behavior by design

 

Recommended Actions

 

Double quotes can only be saved in an escaped format as \"

When entering the string escape double quotes for example

Bearer realm=\"https://abc-test.example.com/service/token,service=apple\"

The above example in a policy looks like below:

 

tmsh list ltm policy

 

ltm policy replace-header-policy {
   requires { http }
   rules {
       header-replace {
           actions {
               0 {
                   http-header
                   response
                   replace
                   name Test
                   value "Bearer realm=\"https://abc-test.example.com/service/token,service=apple\""
               }
           }
       }
   }
   status published
   strategy first-match
}

 

The result is as below:

 

curl 192.0.2.12 -I
HTTP/1.1 200 OK
Server: nginx/1.22.1
Date: Thu, 01 Apr 2023 01:01:01 GMT
Content-Type: text/html
Content-Length: 75
Connection: keep-alive
Test: Bearer realm="https://abc-test.example.com/service/token,service=apple"
