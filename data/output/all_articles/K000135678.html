K000135678: Virtual Server IP does not appear to be listening, even though its Enabled/Green

Type
Support Solution
Published
2023-07-31
Updated
2023-07-31
Source
https://my.f5.com/manage/s/article/K000135678

Description

  • BIG-IP VEs in Azure can work as Active/Active pair. To do so, virtual addresses need to use Traffic Group "None" allowing both BIG-IP devices to respond to Azure Load Balancer(ALB) health probes.


Environment

  • BIG-IP VEs in Azure members working as Active/Active with ALB failover.


Cause

BIG-IP HA pair working in Active/Active state contain Virtual Adresses associated to a traffic group.

 

 Recommended Actions

Modify the virtual addresses to use Traffic Group "None".


1.      Login into the Configuration Utililty.

2.      Navigate to Local Traffic > Virtual Servers.

3.      On the Menu bar, click the Virtual Address List tab.

4.      Click the address of the virtual server you just created like "0.0.0.0/0".

5.      From the Traffic Group list, select "None".

6.      Click Update.

7.      Repeat for each virtual server address.


Additional Information
