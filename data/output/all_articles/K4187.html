For information about how to set the recursion bit in BIG-IP GTM, refer to the following articles:

  • K7054: Setting the recursion bit for gtmd process replies on the BIG-IP GTM system (9.x)
  • K14913: Setting the recursion bit for the gtmd process replies on the BIG-IP GTM system (10.x - 11.x)

Normally, the recursion bit is set in a DNS response only when a DNS server is not authoritative for the name specified in the query it is answering.

On 3-DNS, two separate daemons are responsible for answering DNS queries:

  • 3dnsd
    Answers for wide IP names.
  • named
    Answers for normal DNS zone entries.

Since 3dnsd is authoritative for wide IP names, it will not set the recursion bit in responses. Because named is not the authoritative source for other zone entries, it will always set the recursion bit by default.

Some applications may not accept DNS responses that do not have the recursion bit set. Starting in versions 4.5.12 and 4.6.3, you can work around this issue by configuring 3-DNS to set the recursion bit on all responses from 3dnsd.

To enable this feature, perform the following steps:

  1. Using a text editor, such as vi or pico, edit the wideip.conf file.
  2. Locate the globals section.
  3. Add the following line:

    3dns_sets_recursion yes
