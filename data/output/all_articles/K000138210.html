K000138210: Deployment Error when deploying WAF policy using the "Guided Configuration" error "Deployment error [RestOperationNetworkHandler] request timeout."

Description

When trying to create a new Security policy using the Guided Configuration the operation will time out displaying the message below in GUI:


Deployment error

[RestOperationNetworkHandler] request timeout.


The restnoded logs will display the same block being in a loop:


var/log/restnoded/restnoded.log

Environment

  • AWAF Guided Configuration

Cause

Block stuck into a loop.


Recommended Actions

1. Run the command below to identify blocks in bad/error state.


# restcurl /mgmt/shared/iapp/blocks -u admin:admin | jq '.items[] | select(.state == "ERROR") | {id, name}'


2. If the block appears using the above command, it can be removed. The username and password will be required for this action.


# restcurl -X DELETE /shared/iapp/blocks/fea26fb9-3604-4346-9781-997ca75a490a -u <username>:<password>


3. To delete the Blocks they need to be in an error state. If they are not in error state, the commands below can be used.


# restcurl -X PATCH -d '{"state":"ERROR"}' "/mgmt/shared/iapp/blocks/fea26fb9-3604-4346-9781-997ca75a490a" -u <username>:<password>

# restcurl -X PATCH -d '{"state":"UNBOUND"}' "/mgmt/shared/iapp/blocks/fea26fb9-3604-4346-9781-997ca75a490a" -u <username>:<password>


4. From GUI navigate to iApps ›› Application Services: Applications LX and delete all blocks with a red dot (ERROR).


5. Once the above is complete, restart the restjavad and restnoded services and try recreating the policy again.


# bigstart restart restjavad restnoded
