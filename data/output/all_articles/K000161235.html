Description

Deploying F5 Distributed Cloud Customer Edge (CE) sites across diverse on-premises and cloud environments traditionally requires significant manual effort. Secure Mesh Site v2 (SMSv2) simplifies CE deployment by reducing the number of configuration steps and the time required to bring new sites online, regardless of the underlying infrastructure platform or provider.

  • How can F5 Distributed Cloud Customer Edge sites be deployed quickly across multiple platforms and providers?
  • What platforms and providers are supported for CE deployment using Secure Mesh Site v2 (SMSv2)?
  • How is a new Secure Mesh Site v2 CE created in the F5 Distributed Cloud Console?
  • Where can step-by-step guides and Terraform automation examples for SMSv2 CE deployments be found?

Environment

  • F5 Distributed Cloud (SaaS)

Cause

None

Answer/Recommended Actions

Use Secure Mesh Site v2 (SMSv2) in the F5 Distributed Cloud Console to deploy Customer Edge sites rapidly across supported platforms. SMSv2 significantly reduces the number of configuration steps and time required to onboard new CE sites compared to previous deployment methods.

Prerequisites

  • An active F5 Distributed Cloud account with appropriate permissions.
  • Access to the target infrastructure platform (hypervisor, cloud provider, or baremetal) where the CE will be deployed.

Deploying a Secure Mesh Site v2 CE

  1. Log in to the F5 Distributed Cloud Console.
  2. Navigate to Multi-Cloud Network Connect → Site Management → Secure Mesh Sites v2.
  3. Click Add Secure Mesh Site.
  4. Provide a site name.
  5. Under Provider Name, select the target infrastructure platform from the dropdown:
    • VMware, AWS, Azure, GCP, OCI, Nutanix, OpenStack, Equinix, Baremetal, KVM, or OpenShift Virtualization.
  6. All remaining options can be used with default values and adjusted as needed to meet organizational networking and business requirements.
  7. Click Add Secure Mesh Site to complete the creation.

Additional Information

Secure Mesh Site v2 (SMSv2) delivers three key benefits for CE deployments across heterogeneous environments:

  • Simple to Deploy: SMSv2 quickly stands up and onboards CEs in any environment, significantly reducing the number of manual steps and time-to-online for new sites.
  • Secure Networking Underlay: App Connect steers traffic between sites by extending applications and enabling scale across the F5 Distributed Cloud global fabric.
  • SaaS Console: Provides universal visibility and centralized, consistent policy enforcement across all CE locations from a single management plane.

SMSv2 is the next-generation approach to CE deployment in F5 Distributed Cloud, replacing the previous site management workflow with a streamlined, provider-aware configuration experience. By selecting the provider at creation time, the Console presents only the relevant configuration options for that platform, reducing complexity and the risk of misconfiguration.
