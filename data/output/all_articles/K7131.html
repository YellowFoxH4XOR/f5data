Topic

The alarm light is located on the front, left side of the following BIG-IP switch platforms:

  • BIG-IP 1000 (D39)
  • BIG-IP 2400 (D44)
  • BIG-IP 5000 (D50)
  • BIG-IP 5100 and 5110 (D51)

In BIG-IP version 4.5, a solid red alarm light indicates one of the following two conditions:

  • The system memory utilization has increased, and is nearing the memory reboot percentage setting.

    When this occurs, the BIG-IP system will output the following log message to the /var/log/bigip file:

    Note: In the following log message, NN% represents the current percentage of kernel memory consumption on the BIG-IP system.

    BIG-IP kernel memory consumption has reached NN%

    The kernel will clear the solid red LED when memory consumption drops below 40 percent.

  • The alarm light has been manually turned on by the bigpipe led sw error command.

For either condition, you can clear the LED light by typing the bigpipe led sw error reset command. However, if system memory continues to increase, the alarm LED will reactivate.
