Description

Telemetry service toward kafka server failed.


  • [telemetry.service.ConsumersService.Kafka.f5telemetry_default::My_Consumer] error: MessageSizeTooLarge can be observed in restnoded.log


Environment

  • BigIP
  • Telemetry
  • Kafka

Cause

The low default setting on kafka server of 1MB for max message bytes and message max bytes, cause telemetry failure on F5 end.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1.  increase the allowable size for message.max.bytes and max.message.bytes on kafka server.
