Topic

The Packet Velocity ASIC (PVA) hardware acceleration levels include the following three modes:

  • Full

    All traffic is load balanced in L4 mode, such as virtual servers that operate only on IP addresses and ports of incoming traffic. The Full level does not modify TCP or IP packet optimizations; everything a client or server supports is sent directly through the network and managed by the ASIC.

    For example, the virtual server load balances to three nodes using the Round Robin algorithm with no persistence or rules.
  • Partial

    The software (not the ASIC) load balances the SYN packets as normal, and the ASIC assists with the remaining packets in the connection leading up to and including, closing the connection.

    For example, the virtual server uses a rule examining the IP addresses contained in the packets.
  • None

    The ASIC is passive and not involved in any load balancing for the virtual server traffic. Traffic is passed to the software and load balanced as normal.

    For example, the virtual server uses a rule that performs delayed binding and uses insert cookies.

Note: For more information, refer to K4832: Overview of PVA Acceleration.

You can determine if a virtual server is being accelerated by the PVA by performing one of the following two procedures, depending on the version of the BIG-IP system that you are running:

BIG-IP 9.x and later

To determine if a virtual server is being accelerated by the PVA, type the following command from the command line where <VIP_NAME> is the name of the virtual server you want to check:

bigpipe virtual VIP_NAME show

The output appears similar to the following example:

VIRTUAL ADDRESS 10.10.65.30   UNIT 1|     ARP enable|     (cur, max, limit, tot) = (0, 0, 0, 0)|     (pkts,bits) in = (0, 0), out = (0, 0)+-> VIRTUAL my_http_internal   SERVICE 80    |     PVA acceleration none    |     (cur, max, limit, tot) = (0, 0, 0, 0)    |     (pkts,bits) in = (0, 0), out = (0, 0)    |     requests (total) = 0    +-> POOL http_pool

Examine the PVA acceleration line located beneath the VIRTUAL heading to determine the acceleration status. In this case, this virtual server's hardware acceleration level is set to None.

Note: You can show all virtual servers using the bigpipe virtual show command.

BIG-IP 4.5.0 through 4.6.4

To determine if a virtual server is being accelerated by the PVA, type the following command from the command line where <IP:PORT> is the IP address and port of the virtual server you want to check:

bigpipe virtual IP:PORT show

The output appears similar to the following example:

VIRTUAL +------> 10.10.44.100        UNIT 1|            (cur, max, limit, tot) = (21501, 30227, 0, 15513952)|            (pckts,bits) in = (66856120, 49267595064), out = (50166623, 55064355248)+------> PASS ANY IP: disabled|+---+--> SERVICE   http            ENABLED|        hw_acceleration full|        (cur, max, limit, tot) = (21501, 30227, 0, 15513952)|        (pckts,bits) in = (66856120, 49267595064), out = (50166623, 5504355248)POOL webservers...

Examine the hw_acceleration line located beneath the SERVICE heading to determine the acceleration status. In this case, this virtual server's hardware acceleration level is set to Full.
