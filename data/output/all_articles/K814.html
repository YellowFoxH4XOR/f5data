K814: After logging out, you cannot log in to NameSurfer as the same user

Known Issue

This is the result of a known issue. When you attempt to use the Login as different user option to open a new NameSurfer session and you already have a session open, you may receive the following error:

Authorization failed
You entered an invalid user name or password.

NameSurfer does not allow you to use the Login as different user option to open a new session while you have another session open for the same user.

F5 Networks Product Development tracked this issue as CR37565.

Workaround

To log in to NameSurfer again, restart your web browser and open the Configuration utility.
