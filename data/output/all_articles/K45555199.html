Topic

You should consider using this procedure under the following condition:

  • You want to restore only the BIG-IP Advanced Routing Module (ARM) configurations on the BIG-IP system to factory default settings on the currently-active volume.

Description

You may occasionally need to remove only the BIG-IP ARM configurations and restore them to the factory default settings with no impact to other BIG-IP system configurations. To do so, you can empty the /config/zebos/rd<x>/ZebOs.conf files, and then restart the tmrouted process.

When you restore BIG-IP ARM configurations to factory default settings, the system completes the following tasks:

  • Removes all dynamic routing configuration objects
  • Removes all dynamically learned routes
  • Retains the BIG-IP license file
  • Retains static and connected routes configured on the Traffic Management Microkernel (TMM).

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have root access to the BIG-IP system.

Procedures

Restoring BIG-IP ARM configurations to factory default settings

Impact of procedure: This procedure removes all dynamic routing configuration objects and all dynamically learned routes on the BIG-IP system.

  1. Log in to the BIG-IP command line.
  2. Empty the BIG-IP ARM configuration file on a route domain. 

    For example, to empty the BIG-IP ARM configuration on route domain 0, type the following command:

    cp /dev/null /config/zebos/rd0/ZebOs.conf

  3. Repeat step 2 for all route domains.
  4. Restart the tmrouted process by typing the following command:

    tmsh restart sys service tmrouted
