K10142: Confirm that pre-logon checks are ordered correctly

Topic

When writing pre-logon sequences, you must ensure that the order of the rules will not lead to unintentional false positives. For example, if you want to do a registry check for something that will only be on your Windows users' machines, but you also have Mac OS X users, you must first have a rule that examines what OS the user is connecting with and only check the registry of the Windows users. If you are working on a pre-logon sequence that is failing for some operation systems but not others, ensure that there is not a missing rule that directs the different operating systems to the correct checks.

Note: You can configure the Check OS inspector to determine a user's operating system. For more information about configuring the Check OS inspector, refer to the FirePass Controller Administrator Guide.
