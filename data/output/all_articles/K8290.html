Topic

The TM.LHPNoMemberAction database variable allows the administrator to control how the BIG-IP system handles responses to client traffic from a different MAC address than those defined in the last hop pool.

The TM.LHPNoMemberAction variables settings are as follows:

ValueDescription
0 (Default)If auto_lasthop is enabled, the traffic is returned to the MAC address from which it was sent. If auto_lasthop is disabled, return traffic is routed using the IP routing table.

Note: The auto_lasthop feature is enabled by default.

1The traffic is rejected.

Note: This replicates the default behavior of BIG-IP 4.x.

2The client traffic is routed back through a member defined in the last hop pool.

To set the value of the TM.LHPNoMemberAction variable, use the following command syntax:

BIG-IP 11.x and later

tmsh modify /sys db tm.lhpnomemberaction value <value>

BIG-IP 10.x

bigpipe db TM.LHPNoMemberAction <value>
