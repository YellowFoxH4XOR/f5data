K14887: The ARX Cloud Extender agent may fail to migrate files to/from an Amazon S3 cloud target

Known Issue

The ARX Cloud Extender agent may fail to migrate files to/from an Amazon S3 cloud target.

This issue occurs when the following condition is met:

  • You configure an ARX Cloud Extender policy to migrate files to an Amazon S3 cloud target.

The certificate chain returned by the Amazon S3 web service has been updated by Amazon. The ARX Cloud Extender S3 connector is unable to validate this new certificate chain.

Impact

Data stored on the Amazon S3 target is not available.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The ARX Cloud Extender agent fails to migrate files to/from the Amazon S3 cloud target, and logs error messages similar to the following example to the console.log and summary.log files:

Resolution

Status

F5 Product Development has assigned ID 440402 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases, point releases, or hotfixes that resolve this issue, refer to the following table.

Type of fixFixes introduced inRelated articles
ReleaseNoneNone
Point release/hotfix1.10.1.3*None

*To obtain the hotfix, contact F5 Technical Support and reference this article number and the associated ID number.

Workaround

There is no workaround for this issue. However, customers affected by this issue may contact F5 Technical Support to request an early release of a fixed version of ARX Cloud Extender software which is currently still being tested.
