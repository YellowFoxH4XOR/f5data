Description

Access >> Guided configuration shows some object has Error status. Clicking View Details, the below error message is shown

 

Config Processor is not available: java.util.concurrent.TimeoutException: Unavailable: http://localhost:8100/mgmt/shared/iapp/processors/adfs-provider

 

restjavad, tomcat, restnoded was restarted, but no change

 

Environment

  • BIG-IP APM
  • v15.x, v16.x, v17.0.x
  • Guided Configuration v10.0

 

Cause

  • Guided Configuration v10 supported by only v17.1.0 and above

Release Notes : Guided Configuration 10.0

 

Recommended Actions

We have EngHF for Guided Config for known issues, please request EngHF for v15.x, v16.x, v17.0.x for v9.0

Please request EngHF Guided Config to F5 Support with fresh qkview from the unit you are going to install.

Then downgrade to AGC 9.0:

  1. Go to iApps  ››  Package Management LX
  2. Uninstall all the packages
  3. when you go back to Access  ››  Guided Configuration by default AGC 9.0 will be installed
  4. then install EngHF of GC v9.0
