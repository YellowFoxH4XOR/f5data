Vulnerability description and product information

Information about these advisories is available at the following locations:

  • http://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2007-5925
    An authenticated user who can issue SQL commands could crash the database server.
  • http://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2007-5969
    A malicious user with filesystem access could cause data loss on the filesystem.
  • http://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2007-6303
    VIEW definition updates do not occur correctly, allowing an authenticated user to bypass security around the VIEW

Security Advisory Status

F5 Product Development tracked this issue as CR91292 for BIG-IP and Enterprise Manager, and it was fixed in BIG-IP 10.0.0 and Enterprise Manager 1.7.0. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, Link Controller, WebAccelerator, and Enterprise Manager release notes.
