Topic

You should consider using this procedure under the following condition:

  • You want to export a matching certificate/key pair in Personal Information Exchange Format (PFX) format.

Description

The PFX file format is an archive file format for storing many cryptography objects as a single file. It is commonly used to bundle a private key with its X.509 certificate. When you export a certificate/key pair to a PFX file, you can use the file for different purposes; for example, you can use it to install the client certificate in the web browser's SSL certificate store. For more information, refer to K12140946: Configuring the BIG-IP system to perform two-way SSL authentication.

For information about importing a certificate/key pair, refer to K14620: Managing SSL certificates for BIG-IP systems using the Configuration utility. After you import the certificate/key pair, the files appear in the following directories.

FileLocationExample
certificate/config/filestore/files_d/<partition>_d/certificate_d//config/filestore/files_d/Common_d/certificate_d/
key/config/filestore/files_d/<partition>_d/certificate_key_d//config/filestore/files_d/Common_d/certificate_key_d/

Note: If you have not already imported the certificate/key pair to the BIG-IP system, you can use secure copy (SCP) to copy the files to the /var/tmp directory of the system and proceed to Using the openssl command to export the certificate/key pair to PFX format.

Prerequisites

You must meet the following prerequisites to use this procedure:
  • You have administrative access to the Configuration utility.
  • You have command-line access to the BIG-IP system.

Procedures

  • Copying the certificate/key pair to the /var/tmp directory on the BIG-IP system
  • Verify the certificate file format
  • Using the openssl command to export the certificate/key pair to PFX format

Copying the certificate/key pair to the /var/tmp directory on the BIG-IP system

F5 recommends making a copy of the production certificate/key pair found at the locations described in the previous table. Before you attempt to export the certificate/key pair to PFX format, copy it to the /var/tmp directory and then perform the conversion on the certificate/key pair copy. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Locate the SSL certificate/key pair using the information in the previous table. On a production device, the certificate.crt and privatekey.key files may have _xxxx numeric digits appended to the file names.
  3. Copy the certificate file to the /var/tmp directory using the following command syntax:

    cp /config/filestore/files_d/Common_d/certificate_d/<Certificate-Filename> /var/tmp/<Destination-Filename>

    For example, to copy the :Common:clientCA.crt_53627_1 file to /var/tmp, type the following command:

    cp /config/filestore/files_d/Common_d/certificate_d/\:Common\:clientCA.crt_53627_1 /var/tmp/clientCA.crt

  4. Copy the key file to the /var/tmp directory using the following command syntax:

    cp /config/filestore/files_d/Common_d/certificate_key_d/<Key-Filename> /var/tmp/<Destination-Filename>

    For example, to copy the :Common:clientCA.key_126700_1 file to /var/tmp, type the following command:

    cp /config/filestore/files_d/Common_d/certificate_key_d/\:Common\:clientCA.key_126700_1 /var/tmp/clientCA.key

  5. Verify that the files are copied correctly by using the follow command syntax:

    ls -las /var/tmp/<Destination-Filename>

    For example, to list the certificate and key files, type the following commands:

    ls -las /var/tmp/clientCA.crt
    ls -las /var/tmp/clientCA.key

Verify the certificate file format

It is possible that the certificate file may be encoded in the Distinguished Encoding Rules (DER) format instead of PEM format. If the certificate file is encoded in the DER format and you attempt to export the certificate/key pair to PFX format, you may fail to do so and observe an error message similar to the following example:

unable to load certificates

You must convert the certificate file encoded in the DER format to the PEM format before exporting the certificate/key pair to PFX format. To verify the certificate file format, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Verify if the certificate file is encoded in the DER format by entering the following command syntax:

    openssl x509 -in /var/tmp/<certificate-filename> -inform DER -text

    For example,

    openssl x509 -in /var/tmp/clientCA.crt -inform DER -text

    If the command returns error messages similar to the following example, then the certificate is not encoded in the DER format:

    unable to load certificate
    47067611796336:error:0D0680A8:asn1 encoding routines:ASN1_CHECK_TLEN:wrong tag:tasn_dec.c:1220:
    47067611796336:error:0D07803A:asn1 encoding routines:ASN1_ITEM_EX_D2I:nested asn1 error:tasn_dec.c:386:Type=X509

    You can skip the next step and proceed to perform the next procedure to export the certificate/key pair to PFX format.

    If the command returns an output describing the certificate attributes like serial number, issuer, validity etc, then the certificate is encoded in the DER format and you need to perform the next step to convert it to the PEM format before exporting the certificate/key pair to PFX format.

  2. If the certificate file is encoded in the DER format, convert it to the PEM format by entering the following command syntax:

    openssl x509 -inform DER -outform PEM -text -in /var/tmp/<certificate-file-encoded-in-DER-format> -out /var/tmp/<certificate-file-encoded-in-PEM-format>

    For example,

    openssl x509 -inform DER -outform PEM -text -in /var/tmp/clientCA.crt -out /var/tmp/clientCA.pem.crt

Using the openssl command to export the certificate/key pair to PFX format

To export the certificate/key pair to PFX format, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Export the certificate/key pair to PFX format to /var/tmp/certificate.pfx using the following command syntax:

    openssl pkcs12 -export -out /var/tmp/<PFX -CertificateName> -inkey /var/tmp/<Key-Filename> -in /var/tmp/<Certificate-File-encoded-in-PEM-format>

    For example, to export the certificate clientCA.pem.crt and key clientCA.key copied in the previous procedure, type the following command:

    openssl pkcs12 -export -out /var/tmp/certificate.pfx -inkey /var/tmp/clientCA.key -in /var/tmp/clientCA.pem.crt

    The exported PFX file is named /var/tmp/certificate.pfx.
