Topic

This article applies to FirePass 5.4.2 through 7.0. For information about other versions, refer to the following article:

•    K10942: Installing OPSWAT hotfixes on BIG-IP APM systems
 
The FirePass controller's Endpoint Security feature allows administrators to detect the presence and state of third party security software, such as personal firewalls, antivirus, anti-spam, anti-spyware or integrated packages. To perform this detection, the Windows antivirus checker and Windows firewall checker Endpoint Inspectors, which are listed on the Users: Endpoint Security: Endpoint Inspectors page, use software libraries from a software development kit (SDK) created by OPSWAT, Inc.

OPSWAT provides a vendor-independent framework for endpoint security management. The FirePass controller incorporates OPSWAT's Endpoint Security Integration SDK libraries in the Endpoint Inspectors.

OPSWAT periodically issues new versions of the SDK libraries because new security products and new versions of existing security products are released continually, and because software bugs are discovered. FirePass software will incorporate releases of the OPSWAT SDK libraries after F5 Networks has performed the necessary software development and quality assurance testing. F5 Networks does not provide a schedule for incorporation of new OPSWAT SDK libraries. Typically, updates with the new libraries are periodically issued as hotfixes to supported versions of FirePass software.

Important: OPSWAT hotfixes are cumulative. Installing the latest OPSWAT hotfix will install all components contained in previous OPSWAT hotfixes.

If you are experiencing an issue in detecting a Windows-based third party security product using one of the aforementioned Endpoint Inspectors, you should download the latest OPSWAT hotfix from F5 Networks, install the hotfix on your FirePass system, and then determine whether you continue to experience the issue. See the Obtaining OPSWAT hotfixes section for instructions about obtaining the latest hotfix.

If you continue to experience the issue, then determine whether your security product is supported by the current OPSWAT SDK libraries installed by the hotfix. Supported antivirus products can be found in the FirePass online help located on the Users: Endpoint Security: Inspectors: Antivirus Support Chart: Antivirus Support Chart online help page. Supported firewall products can be found in the online help located on the Users: Endpoint Security: Inspectors: Firewall Support Chart: Firewall Support Chart online help page. Both locations indicate the version of the SDK libraries.

If your product is listed as supported, and you are still experiencing your issue, then open a case with F5 Networks Technical Support. For information about opening cases with F5 Networks, refer to K623: Opening a new case with F5 Networks Technical Support from AskF5.

If your product is not listed as supported by the chart in the online help, refer to K7661: Options for security products not supported by OPSWAT.

Important: Do not contact OPSWAT for support requests. OPSWAT works through vendors of security products to address issues with supported products or requests to add support for products. Support requests should be directed to F5 Networks for issues regarding the FirePass controller's implementation of OPSWAT's SDK, and to the vendors of the security software for issues regarding their products' implementation of the SDK.

Note: For information about removing the FirePass OPSWAT Anti-Virus and Firewall Integration Libraries on a Windows client system, refer to K8253: Removing FirePass client components from Windows client systems.
 

Obtaining OPSWAT hotfixes

Customers with valid support contracts can obtain the latest OPSWAT hotfix by performing the following procedure:

  1. Using a browser that will accept cookies from the originating website, connect to the F5 Downloads site.

  2. If you have an account, supply your email address as username and password. Otherwise, you need to register for a login.

  3. On the Downloads Overview page, click the Find a Download button.

  4. On the Product Lines page, click the FirePass link.

  5. On the Product Version page, select your version of FirePass software from the drop-down menu.

  6. Click the link whose Description field contains OPSWAT.

  7. On the End User License Agreement page, read the agreement and click the I Accept button if you accept the terms of the agreement.

  8. On the Select a Download page, click the link whose Filename field contains the hotfix (the name has an .enc extension).

  9. On the Select a Download Method page, click the icon next to the method you want to use to transfer the file.

  10. Save the file to the location you will subsequently use to upload to the FirePass controller.

To install the OPSWAT hotfix, refer to K3430: Installing FirePass hotfixes. The password for the OPSWAT hotfix is F5Networks.
