Description

  • You may observe BIG-IP reuses port even when the previous tcp monitor connection is not terminated completely.

Environment

  • BIG-IP
  • TCP monitor
  • Pool Member

Cause

There is a system variable at linux host side, net.ipv4.tcp_fin_timeout whose default value is 60 seconds.
With TCP monitor, when closing the TCP monitor connection, BIG-IP will send out FIN to the server.
If BIG-IP cannot get the FIN from the server, it's considered the connection is not closed properly.
BIG-IP will enter FIN_WAIT_2 state and follow the system setting net.ipv4.tcp_fin_timeout.
Therefore possibly reuse the port to initialize a new TCP monitor instance after 60 seconds.

 

 Recommended Actions

If the intermedia device does not accept port reuse, the customer should fix the server behavior to respond back FIN properly.
Otherwise, the customer may consider using other types of monitors. e.g. tcp_half monitor
