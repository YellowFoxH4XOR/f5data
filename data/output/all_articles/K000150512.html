Description

LTM policy created by AS3 class Endpoint_Policy automatically adds http in the requires list causing an error like below when assigning it to a virtual server without http profile.

010716d9:3: Virtual server /My_Tenant/My_Application/vs_01 requires a profile of type http or http-connect for ltm policy /My_Tenant/My_Application/policy_01.

The LTM policy created by AS3 looks like below, and you will also notice it shows status legacy.

ltm policy /My_Tenant/My_Application/policy_01 {
    last-modified 2025-01-24:05:30:32
    partition My_Tenant
    requires { tcp http }
    rules {
        ...
    }
    status legacy
    strategy best-match
}

The issue has been reported in AS3 github issues.

Virtual server requires a profile of type http or http-connect for ltm policy #873

Environment

  • AS3
  • LTM policy

Cause

The issue is tracked by ID 1855777 / AUTOTOOL-4673.

Recommended Actions

To workaround the issue, create a draft LTM policy outside of AS3 (GUI, TMSH, or iControl REST) and publish it. Reference the LTM policy from AS3.

Additional Information

AS3 currently uses legacy mode to create an LTM policy. The legacy mode skips drafting and publishing process when creating the policy, and therefore, it has a limitation in populating values in the requires parameter. The fix of the issue changed the behavior of AS3 to avoid using legacy mode and go through drafting and publishing like BIG-IP admins normally do when creating a LTM policy through TMSH or GUI. Therefore, created LTM policy will have status published instead of status legacy.
