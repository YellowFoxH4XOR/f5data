Description

  • You have NGINX Ingress Controller load balancing traffic to your applications running in a containerized environment 
  • You performed an upgrade on the NGINX Plus Ingress Controller deployment 
  • However, after the upgrade, the ingress pod fails to start and logs the below error 

Failed to watch *v1.TransportServer: failed to list *v1.TransportServer: the server could not find the requested resource (get transportservers. k8s.nginx .org

Environment

  • NGINX Ingress Controller
  • Upgrade
  • Helm
  • Custom Resource Definition (CRDs)

Cause

  • CRDs were NOT updated prior to NGINX Plus Ingress Controller deployment upgrade

Recommended Actions

  • You can upgrade CRDs by following steps provided here

Additional Information

  • By default, the Ingress Controller requires a number of custom resource definitions (CRDs) installed in the cluster.
  • And by default, upgrading the Ingress Controller deployment, either through Helm or editing manifest, will NOT upgrade CRDs.
  • Hence, you would need to update CRD independent of Ingress Controller deployment
