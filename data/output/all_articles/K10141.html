Known Issue

This is the result of a known issue. When selecting the Windows Files icon in the left navigational pane of the webtop or the Windows File link in the main pane of the webtop, users may incorrectly receive an access denied error message. This issue occurs when the following two conditions are met:

  • Cumulative HF-603-1, HF-603-2, or HF-603-2.1 is installed on the FirePass controller
  • The Limit Windows Files Access to Favorites only check box is selected for the user’s master group on the Portal Access: Windows Files: Master Group Settings page

F5 Product Development tracked this issue as CR120623 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative HF-603-3 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

For a list of the latest hotfixes, refer to K10322: FirePass hotfix matrix.

Workaround

Users can work around this issue by selecting a specific Windows Files favorite instead of selecting the Windows Files icon in the left navigational pane, or the Windows Files link in the main pane of the webtop.
