Description

On rare ocasions, the BIG-IP system might log error messages similar to the ones below in /var/log/ltm:
 
012a0004:4: Mezzanine +12V_SATA = <voltage> mV out of range <voltage>/13443 mV
012a0004:4: Mezzanine +3.3V = <voltage> mV out of range <voltage>/3525 mV
 

Environment

  • BIG-IP systems running on Viprion 4300/4340N blades
  • usually occurs after an upgrade

Cause

These error messages are typically the result of an intermittent error in measuring the voltage values by the voltage sensor and are a rare occurrence. This is a known issue tracked as Bug ID 376240.
 

Recommended Actions

  1.  If the errors are intermittent, a reboot of the device usually clears up the issue
  2.  If the issue persists after a reboot, run an EUD and troubleshoot for power supply issues

Additional Information

None
