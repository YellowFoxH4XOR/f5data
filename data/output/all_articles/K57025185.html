Description

REST API call to get the information from BIG-IP for e.g. BIG-IP version information fail with below error:

TypeError: Cannot call method 'split' of undefined

At the same time icrd log show syntax error for file /etc/icrd.conf. Error would look something like below example:

iControl REST Child Daemon, SEVERE,icrd encountered an error when it loads configuration. The error is [Failed to parse configuration file /etc/icrd.conf.]. This error prevents icrd from handling client requests. Please fix this error and restart icrd.

In the /var/log/restjavad.0.log file, you observe error messages that appear similar to the following example:
"icrd encountered a critical configuration error. Please verify that the error has been fixed and restart icrd."
[ChildWrapper] Killing IcrdChild process 1396 
[ChildWrapper] Child runner thread was interrupted. Killing child: 4f6971da-fc7b-4bd2-b781-2af6896c32cb 
[ChildWrapper] Child runner thread was interrupted. Killing child: 4f6971da-fc7b-4bd2-b781-2af6896c32cb

Environment

  • REST API calls failing to get information from BIG-IP. 

Cause

This occurs when /etc/icrd.conf is modified with some syntax error. 

Recommended Actions

Follow below instructions to resolve the issue. 

  1. Check if /etc/icrd.conf file was recently changed or modified. 
  2. In this example, below were the modification done with incorrect syntax when compared to default /etc/icrd.conf file.  
    ...
     "options" : {
          "transactionTimeoutSeconds" : 120,
          "transactionExecTimeoutSeconds" : 300,
          "heartbeatSeconds" : 300,
          "childLogLevel" : 2                              <-- a comma should be in the end of this line
                "childIdleTimeout" : 320                         <-- a comma should be in the end of this line
                "socketIdleSeconds" : 180                    
       },
    ...
     
  3. When adding a new line in option clause, make sure end the last line with a comma ",". 
  4. Add the commas in below lines to correct syntax error as below:
    ...
     "options" : {
          "transactionTimeoutSeconds" : 120,
          "transactionExecTimeoutSeconds" : 300,
          "heartbeatSeconds" : 300,
                "childLogLevel" : 2,                                       <-- Added ','           
                "childIdleTimeout" : 320,               <-- Added ','                              
                "socketIdleSeconds" : 180                    
       },
    ...
               
  5. Once done restart restjavad using below command:
    bigstart restart restjavad
