K000157204: LACP Interface Fails to Join Bundle and Logs "Error NULL interface descriptor" on F5OS 1.8.3 rSeries Appliances (Bug ID 2132141)

Type
Support Solution
Published

Updated
2025-12-12
Applies to

  • F5OS-A: 1.8.3
Source
https://my.f5.com/manage/s/article/K000157204

Description

On F5 rSeries appliances running F5OS version 1.8.3, a specific port (interface 8.0) may fail to join a configured LACP (Link Aggregation Control Protocol) bundle, even though other links on the same device operate normally. The affected interface remains in a "DOWN" state and does not participate in LACP negotiation. System logs show repeated messages such as:

Error NULL interface descriptor

This issue prevents successful link aggregation and may impact network redundancy or throughput.

Environment

  • Product: F5OS Appliance Software
  • Version: 1.8.3
  • Hardware: rSeries 2000/4000 platforms (C130/C131)
  • Configuration: LACP link aggregation with multiple interfaces; only one port (interface 8.0) affected
  • Log messages: "Error NULL interface descriptor" observed in platform logs
  • Recent actions: Appliance deployed with LACP configuration; issue observed after upgrade or initial setup

Cause

Bug ID 2132141

Recommended Actions

  • Download and install the engineering hotfix F5OS-A-1.8.3-23493.R2R4.EHF-1.iso, which addresses the LACP join issue for interface 8.0 on r2000 and r4000-series appliances.
  • After applying the hotfix, verify that all interfaces successfully join the LACP bundle and confirm that "Error NULL interface descriptor" messages no longer appear in the logs.
  • If the issue persists after the upgrade, collect fresh QKViews from all affected devices and contact F5 Support for further analysis.

Additional Information

The hotfix specifically resolves the LACP join issue for interface 8.0. Other unrelated issues may require separate investigation. The bug does not affect all interfaces, only the specified port on r2000 and r4000-series appliances.
