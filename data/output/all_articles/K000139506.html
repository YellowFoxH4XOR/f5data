K000139506: Error when trying to load available VMWare Horizon resources

Type
Support Solution
Published
2024-05-03
Updated
2024-05-03
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000139506

Description

You are experiencing issues where logging into the APM webtop does not load VMware Horizon resources correctly. Additionally, when connecting using the VMware Horizon Client, it prompts for login credentials twice. This scenario can be confusing and may hinder your productivity by requiring unnecessary additional steps to access your resources.

Environment

  • APM configured for VMware Horizon integration
  • VMware Horizon Client in use
  • Recent changes to login message settings on Horizon server

Cause

The underlying source of the issue is the login message that has been configured on the Horizon server, which is interfering with the expected behavior of the webtop loading process and causing repeated login prompts when using the Horizon client.

Recommended Actions

  • Review the VMware Horizon server settings for login messages.
  • Modify or disable the login message that has been set on the Horizon server.
  • Ensure that no additional policies or settings are contributing to the double login prompt.
  • Test the APM webtop and VMware Horizon Client access to confirm the issue is resolved.
  • If the issue persists, refer to the documentation for troubleshooting APM with VMware Horizon integration or contact F5 support for further assistance.

Additional Information

When a login message is set on the VMware Horizon server, it can sometimes conflict with the way F5 APM processes authentication requests. This can lead to unexpected behaviors such as the webtop not loading properly and multiple login prompts. Adjusting these settings often resolves these types of issues.
