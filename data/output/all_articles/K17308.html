Known Issue

BIG-IP GTM Domain Name System (DNS) resolution responses may not have the recursion available (RA) bit set.

This issue occurs when all of the following conditions are met:

  • A DNS query is resolved to the BIG-IP DNS system with the RA and recursion desired (RD) bits set from an authoritative DNS server.
  • The BIG-IP GTM system stores the resolution in the DNS cache.
  • A subsequent DNS query, for the same fully-qualified domain name (FQDN), is resolved from the DNS cache.

Impact

The BIG-IP GTM system fails to set the RA bit on the cached DNS response.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When comparing the DNS response of the authoritative DNS server with the BIG-IP GTM cached response, you notice that the RA bit is not set in the BIG-IP DNS response.
  • Devices that query the BIG-IP GTM system for DNS resolution, and receive a resolution missing the RA bit, may erroneously determine that the BIG-IP GTM system is not an available resolver.
