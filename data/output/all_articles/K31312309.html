Description

Creating AS3 template in BIG-IQ does not allow '-' (dash) in tenant field.
When creating an AS3 template in BIG-IQ there is a check or validation of the character you can input in the tenant field.

Note: The limitation is lifted beginning in BIG-IQ 7.1 with AS3 extention 3.18.

Error Example (appears in GUI) when deploying AS3 application:

{ "code": 422, "message": "status:422, body:{"code":422,"errors":[": propertyName "test-test" should match pattern "^[A-Za-z][0-9A-Za-z_]*$""],"declarationFullId":"","message":"declaration is invalid"}", "originalRequestBody": "{"code":422,"errors":[": propertyName "test-test" should match pattern "^[A-Za-z][0-9A-Za-z_]*$""],"declarationFullId":"","message":"declaration is invalid"}", "referer": "10.10.10.10", "restOperationId": 883503, "errorStack": [], "kind": ":resterrorresponse" }

Environment

  • BIG-IQ CM
  • AS3 template creation
  • Using dash "-" in tenant field

Cause

ID852361

The restriction is imposed by the AS3 schema:
"propertyNames": {
"pattern": "^[A-Za-z][0-9A-Za-z_]*$",
"maxLength": 64 },

Recommended Actions

Upgrade AS3 extention to 3.17.0 as in following article:  K54909607: BIG-IQ Centralized Management compatibility with F5 Application Services 3 Extension and F5 Declarative Onboarding
