Known Issue

This is the result of a known issue. Deleting views in the BIG-IP GTM Configuration utility generates an error message. If you select the check boxes of multiple views, click the Delete button, and then clear the check box of a view after being prompted to confirm, the following error message is displayed by the Configuration utility:

01150317:3: View '' not found..

F5 Product Development tracked this issue as CR85657 and it was fixed in BIG-IP GTM 10.1.0. For information about upgrading, refer to the BIG-IP GTM Release Notes.

Workaround

Verify that you have correctly selected the views that you want to delete before you click the Delete button.
