Description

Authentication might fail on DCs with certain Kerberos delegation scenarios with errors messages similar to the following logged to /var/log/apm:

12345678:S4U ======> trying to fetch S4U2Proxy ticket for user: user@domain.com@DOMAIN.COM server: HTTP/example@domain.com
12345678:Kerberos: can't get S4U2Proxy ticket for server HTTP/example@domain.com - Message stream modified (-1765328343)
00000000: Kerberos: Failed to get ticket for User: 'user@domain.com@DOMAIN.COM' accessing service: 'HTTP/example@domain.com'


Environment

  • BIG-IP APM
  • Kerberos SSO

Cause

Microsoft released a November security update that causes Kerberos delegation to fail to issue a S4u2self  ticket.

MS KB5007247

Note: This link takes you to a resource outside of MyF5.

Recommended Actions

Microsoft has release patches depending on the affected operating system affected to address this issue. It is recommended to either removed the update or install the supplemental patch and restart the websso daemon on the Big IP.
Once installed, run the following command from the command line of the affected BIG-IP device:

tmsh restart sys service websso
