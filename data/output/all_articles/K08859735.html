Topic

This article applies to BIG-IP 14.x - 17.x. For information about other versions, refer to the following articles:

  • K13044205: Overview of the FTP profile (12.x - 13.x)
  • K82334253: Overview of the FTP profile (11.x)

This article discusses the File Transfer Protocol (FTP) profile settings. You can find the FTP profile in the Configuration utility by navigating to Local Traffic > Profiles > Services > FTP.

Description

The FTP profile enables you to specify how a BIG-IP virtual server processes FTP traffic. To manage FTP traffic, you can tailor FTP profile settings to your specific needs. For those settings that have default values, you can retain those default settings or modify them. You can modify any setting, either when you create the profile or at any time afterwards.

Settings and definitions in the FTP profile

General Properties

SettingDefault ValueDescription
Name Specifies the name of the FTP profile.
Parent ProfileftpSpecifies the profile from which this profile inherits settings. The default is the system-supplied ftp profile.

Settings

SettingDefault ValueDescription
Translate ExtendedEnabledSpecifies, when selected (enabled), that the system ensures compatibility between IPv4 and IPv6 clients and servers when using the FTP protocol. The default is checked (enabled).
Inherit Parent ProfileDisabledSpecifies, when selected (enabled), that the FTP data channel inherits the TCP profile used by the control channel. If disabled, the data channel uses FastL4 only. The default is unchecked (disabled).
Introduced in BIG-IP 11.1.0.
Data Port20Allows you to configure the FTP service to run on an alternate port. The default is 20.
FTPS ModeDisallowAvailable options:
  • Disallow: The BIG-IP system resets the connection to any client that sends AUTH SSL or AUTH TLS to initiate FTPS. The BIG-IP system also does not respond to FEAT commands from FTPS clients.
  • Allow: The system allows FTPS negotiation, and it intercepts Transport Layer Security (TLS), if you configured Secure Sockets Layer (SSL) forward proxy on the virtual server.
  • Require: The system requires FTPS negotiation to protect FTP data transfers.

When you use Allow or Require, FTPS negotiation transitions the virtual server to Pass Through mode and encrypts traffic. After this transition, the BIG-IP system can no longer inspect FTPS traffic. After a connection transitions to explicit FTPS, the BIG-IP system only supports Passive mode data connections. To support Passive mode connections, there must be another virtual server that is the listener for the data connections. This must be a wildcard virtual server, which means the following: Source Address is 0.0.0.0/0, Destination Address is 0.0.0.0/0, and Service Port is 0.

If the FTP virtual server has source address translation, the wildcard virtual server must have the same configuration. If you configure a Large Scale NAT (LSN) pool on the FTP virtual server, the wildcard virtual server must use the same LSN pool, and you must enable persistence on the LSN pool. The system disables connections for any security profile on the virtual server, such as BIG-IP ASM policies and firewall rules, when it transitions to explicit FTPS.

Note: In previous versions, the FTPS Mode setting has available options of Enabled or Disabled. When you upgrade from a previous version, note the following:

  • If the previous value was Enabled the new value will be Allow.
  • If the previous value was Disabled, the new value will be Disallow.
Enforce TLS Session ReuseDisabledSpecifies, when selected (enabled), that the system enforces the data connection to reuse a TLS session. The default value is unchecked (disabled).
Allow Active ModeEnabledSpecifies, when selected (enabled), that the system allows FTP Active Transfer mode. The default value is enabled.
Protocol SecurityDisabledSpecifies, when checked (enabled), that the system inspects FTP traffic for security vulnerabilities using an FTP security profile. This option is available only on systems licensed for BIG-IP ASM.

Recommendations

The BIG-IP system allows you to modify the default FTP base profile. However, F5 recommends that, instead of modifying the default profile, you create a custom profile and use the default profile as the parent profile. You can then modify some or all of the values defined in the custom profile, while leaving the parent profile settings at their default value. For more information, refer to K14488: Working with profiles.
