Description

After deploying BIG-IP on AWS, you may fail to connect meta-data from BIG-IP.
It may be due to missing default route. 

# curl http://169.254.169.254/latest/meta-data/
curl: (7) Failed to connect to 169.254.169.254 port 80: Connection timed out

Environment

  • AWS 
  • Route /LOCAL_ONLY/default exists in /config/partitions/LOCAL_ONLY/bigip.conf
  • BIG-IP doesn't show route /LOCAL_ONLY/default

Cause

Unknown.

Recommended Actions

Delete and re-create the default route, then you will be able to connect meta-data properly.

1. Comment-out default route from bigip.conf
/config/partitions/LOCAL_ONLY/bigip.conf
#TMSH-VERSION: 15.x.x.x
#net route /LOCAL_ONLY/default {
# gw <route_IP_address>
# network default
#}
 
 
2. Verify and load the config
# tmsh load sys config verify
# tmsh load sys config 
 
3. Create default route
# tmsh create net route /LOCAL_ONLY/default network default gw <route_IP_address>
 
4. Save the config
# tmsh save sys config

5. Confirm whether you can see the default route and connect to meta data;
# tmsh show net route
# ip route
# curl http://169.254.169.254/latest/meta-data/
