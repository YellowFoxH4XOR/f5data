Description

Troubleshooting Bot Defense

  • legal traffic being blocked.
  • Requests classified as malicious

Environment

Relevant environmental factors specific to the topic

  • ASM Provisioned
  • Bot Defense configured
  • Debug logging

Cause

None.

Recommended Actions

The actions or steps required to address the topic covered in the description.

Enable Bot Defense logging:

1. tmsh modify sys db log.botd.level value debug

2. tmsh save sys config

3.tmsh restart sys service botd

4. Verify Bot logs by tailing the following log file:
  tail -f /var/log/botd/botd.log

5. Re-create the issue.

Capture a HAR file from the client:

HAR Analyzer

===========================================

6. Disable Bot Defense Debug:

A. tmsh modify sys db log.botd.level value info

B. tmsh save sys config

C. tmsh restart sys service botd

7. Export the violation from ASM GUI for Bot request.

    Security ›› Event Logs : Bot Defense : Bot Request

8. Generate new qkview.

A. SSH: qkview -s0
  

To see the change:

tmsh list sys db log.botd.level

sys db log.botd.level {
    default-value "Info"
    scf-config "false"
    value "Info"
    value-range "Debug Error Info"
}
