Topic

You should consider using this procedure under the following condition:

  • You want to disable basic authentication for iControl REST.

Description

Beginning in the BIG-IP versions listed in the following table, you can disable Basic Auth for iControl REST using system variable httpd.basic_auth.

BranchFeature introduced in
16.x16.0.0
15.x15.1.0.5
14.x14.1.2.7
13.x13.1.3.4
12.x12.1.5.2

The possible variable values are enable and disable. By default, the variable is set to enable.

  • When you enable the variable, the system allows Basic Auth to be used for iControl REST. 
  • When you disable the variable, the system prevents Basic Auth from being used and requires token-based authentication.
Note: Disabling basic authentication for iControl REST does not affect your login to the BIG-IP Configuration utility.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP command line.

Procedures

Disable basic authentication using Advanced Shell (bash) 

Impact of procedure: If the BIG-IP system is not managed by a BIG-IQ system, the following procedure should not have a negative impact on your system. However, if the BIG-IP system is managed by BIG-IQ, disabling basic authentication affects the BIG-IQ's ability to manage and monitor the BIG-IP system. Nonetheless, you can use this workaround by applying the steps in K58356114: BIG-IQ unable to manage BIG-IP when Basic Auth is disabled before performing the following procedure.

  1. Log in to the command line of the BIG-IP system.
  2. To check the current value assigned to httpd.basic_auth, enter the following command:

    getdb httpd.basic_auth

  3. To disable Basic Auth, enter the following command:

    setdb httpd.basic_auth disable

  4. To verify the variable value after the change, enter the following command:

    getdb httpd.basic_auth

    The output should appear as follows:

    disable

  5. Restart the BIG-IP httpd service by entering the following command:

    bigstart restart httpd
     

Disable basic authentication using the TMOS Shell (tmsh) 

Impact of procedure:  If the BIG-IP system is not managed by a BIG-IQ system, the following procedure should not have a negative impact on your system. However, if the BIG-IP system is managed by BIG-IQ, disabling basic authentication affects the BIG-IQ's ability to manage and monitor the BIG-IP system. Nonetheless, you can use this workaround by applying the steps in K58356114: BIG-IQ unable to manage BIG-IP when Basic Auth is disabled before performing the following procedure.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To check the current value assigned to httpd.basic_auth, enter the following command:

    list sys db httpd.basic_auth

  3. To disable Basic Auth, enter the following command:

    modify sys db httpd.basic_auth value disable

  4. To verify the variable value after the change, enter the following command:

    list sys db httpd.basic_auth

    The output should appear as follows:

    sys db httpd.basic_auth {
        value "disable"
    }

  5. Restart the BIG-IP httpd service by entering the following command:
    tmsh restart /sys service httpd
