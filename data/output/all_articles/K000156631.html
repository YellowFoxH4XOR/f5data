Description

This article covers inquiry on whether ASM signature protection is possible for CVE-2025-59145.

Environment

  • ASM provisioned

Cause

ASM signature or WAF protection is not feasible for CVE-2025-59145.

The WAF is designed to block external threats like SQL injection or XSS via inbound requests. However, the attack vector for CVE-2025-59145 is such that it involves compromised npm packages already embedded in your codebase as dependencies. Since the malicious code deploys with your app, there are no suspicious requests for the WAF to detect or block.

Recommended Actions

The only solution is to update/remove the compromised packages, audit dependencies, and rebuild. WAF signatures are ineffective for threats already within your application.
