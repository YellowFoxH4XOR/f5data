Description

How to configure L2 Marking (802.1p) using iRule.

Environment

  • L2 Marking (802.1p)
  • iRule
  • LINK::qos

Cause
None

Recommended Actions

None

Additional Information

With an iRule such as below:

when CLIENT_ACCEPTED {
LINK::qos 5
}

when SERVER_CONNECTED {
LINK::qos 5
}

We can mark the packets going to the pool member (serverside egress) and packets going back to the client (clientside egress) .  See below (third column is the VLAN priority):

# tshark -ta -n -r test_2100_2.pcap -Tfields -e ip.src -e ip.dst -e vlan.priority -e _ws.col.Info
  10.83.229.1     10.83.229.200 0  IN  s1/tmm1 : 35111 → 2100 Len=5  <- Packet arrives from client (unmarked)
  10.83.228.100   10.83.228.2   5  OUT s1/tmm1 : 35111 → 2100 Len=5  <- Sent to the pool member, QOS marked
  10.83.228.2     10.83.228.100 0  IN  s1/tmm1 : 2100 → 35111 Len=5  <- Response from the pool member (unmarked)
  10.83.229.200   10.83.229.1   5  OUT s1/tmm1 : 2100 → 35111 Len=5  <- Response to the client, QOS marked
