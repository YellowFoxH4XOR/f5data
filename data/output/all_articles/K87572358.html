K87572358: Removing an SDC site using clearSdcSiteFromEms.py got ''SyntaxError: EOL while scanning string literal''

Type
Support Solution
Published
2022-04-14
Updated
2024-10-01
Status
Legacy Content
Applies to
  • Traffix SDC: 5.1.X, 5.1.0
Source
https://my.f5.com/manage/s/article/K87572358

Description

when running the script /opt/traffix/scripts/clearSdcSiteFromEms.py from EMS's CLI to remove an SDC site we get:

[root@ems1-130 ~]# python /opt/traffix/scripts/clearSdcSiteFromEms.py sdc-example
  File "/opt/traffix/scripts/clearSdcSiteFromEms.py", line 24
    elif app['type'] == 'elk:
                             ^
SyntaxError: EOL while scanning string literal

Environment

  • EMS's shell
  • SDC

Cause
SDC-1791 Script error when execute clearSdcSiteFromEms.py

Recommended Actions

Script will be fixed in the next CF. In current CFs you may edit it manually on all master nodes.

Edit the script /opt/traffix/scripts/clearSdcSiteFromEms.py and put the missing ' in line 24
Before:
    elif app['type'] == 'elk:
After:
    elif app['type'] == 'elk':

Additional Information
Signaling Delivery Controller - Bare Metal System Maintenance Guide, refer to "Removing an SDC Site".
