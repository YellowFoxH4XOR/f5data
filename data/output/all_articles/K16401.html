Known Issue

Tunnel objects may remain in memory after you delete them.

This issue occurs when all of the following conditions are met:

  • You create a tunnel object and load it into Traffic Management Microkernel (TMM) memory.
  • You delete the tunnel object.

Impact

You will see no noticeable impact when working with a small number of tunnels. However, you may notice the impact to memory consumption if you create and delete a large number of tunnels.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you create and delete a large number of tunnels, the TMM Used Memory counter continues to grow when you view memory statistics using the tmsh show sys memory command.
