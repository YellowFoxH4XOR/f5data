Description

This article provides guidance on how to upload Entrust intermediate and root certificates separately from the server certificate on BIG-IP LTM, and how to reference these certificates in SSL profiles or other relevant instances. This approach allows for flexible management and reuse of CA certificates across multiple configurations.

 

 

Environment

BIG-IP LTM.

Uploading and managing Entrust intermediate and root CA certificates independently from server certificates..

Cause

Uploading intermediate and/or root CA certificates separately is required for environments where these certificates need to be referenced by multiple SSL profiles or virtual servers, rather than being bundled with each server certificate.

 

 

Recommended Actions

Steps to Upload Intermediate and Root Certificates Separately.

 

  1. Access the BIG-IP Configuration Utility (GUI):

Open your web browser and navigate to the BIG-IP management IP address.

        2. Navigate to Certificate Management:

Go to System > Certificate Management > Traffic Certificate Management > SSL Certificate List.

        3. Upload the Root Certificate:

Click Import.

Set Import Type to Certificate.

Enter a descriptive name (e.g., Entrust_Root_CA).

Choose Upload File, then select your root certificate file (.crt or .pem).

Click Import.

 

         4. Upload the Intermediate Certificate:

Repeat step 3 using a different name (e.g., Entrust_Intermediate_CA) and select your intermediate certificate file.

 

         5. (Optional) Upload Server Certificate:

If needed, repeat the process for your server certificate using its own unique name.

 

         6. Reference Certificates in SSL Profiles:

When configuring an SSL profile (Local Traffic > Profiles > SSL > Client/Server):

Set the Certificate field to your server certificate.

Set the Key field to your private key.

Set the Chain field to reference your uploaded intermediate certificate.

For client authentication scenarios, set the Trusted Certificate Authorities field to reference your uploaded root certificate if required.

         7. Save Changes:

Save/apply changes as needed in your configuration.

 

Note: Bundling of intermediate/root CA with server certificates is not required; uploading them separately is supported and recommended for easier management and reuse across multiple profiles or virtual servers.
