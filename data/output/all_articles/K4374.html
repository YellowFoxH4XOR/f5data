K4374: Links that start an Application Tunnel or SSL VPN from within a web page fail after upgrade to FirePass version 5.4

Type
Known Issue
Published
2007-05-04
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 6.0.1, 6.0.0
Source

Known Issue



This is the result of a known issue. Previous to FirePass version 5.4, you could insert JavaScript code into a web page that will start an Application Tunnel or SSL VPN session, as detailed in the FirePass help files and in K3644: Starting an Application Tunnel or SSL VPN Connection through a portal, without creating a security exception.

Beginning with FirePass version 5.4, this code no longer works in the default configuration.

Workaround

You can work around this issue using one of the following two processes:

  • Enable compatibility mode
    This process will restore the behavior of previous versions. This process will not require any changes to the existing links.

  • Put the code in the sandbox
    This process requires that you modify all existing links.

Enable compatibility mode

To enable compatibility mode, perform the following steps:

  1. Log in to the Administration Console.

  2. From the navigation panel, click Portal Access.

  3. Click Web Applications.

  4. Click Content Processing.

  5. From the Content Processing page, click the Global Settings link.

  6. Check the box next to Compatibility Mode.

  7. Click the Update button.

The Application Tunnel and SSL VPN links should now work again.

Put the code in the sandbox

To put the code in the sandbox, perform the following steps:

  1. Log in to the Administration Console.

  2. From the navigation panel, click Device Management.

  3. Click Customization.

  4. From the Customization page, check the box next to Allow WebDAV sandbox customization.

  5. Type a password in the WebDAV password field.

  6. Using a WebDAV-enabled client, put the code into the sandbox.

    For example, if you are using Microsoft Word, put the existing code in the sandbox and use the Save As function as follows:

    The URL should begin with http://<hostname>/sandbox/. If the URL is:

    http://firepass.askf5.com/sandbox/

    Save it with a file name of your choice.

    For example:

    http://firepass.askf5.com/sandbox/askf5sslvpnlink.html

    Note: When you save the file, you will be prompted to enter login information. The user name is webdav and the password is the one that you specified in step 5.

  7. Now you can either include the file within an existing HTML file or you can link to that URL. The link to the page must use HTTPS, although you saved it using HTTP.

    For example:

    https://firepass.askf5.com/sandbox/askf5sslvpnlink.html
