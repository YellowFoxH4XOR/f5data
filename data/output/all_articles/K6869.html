Custom characters for the BIG-IP system

Custom characters are not allowed, except for the following:

  • hyphen (-)
  • period (.)
  • underscore (_)

The object name must start with a letter or underscore.

Custom characters for the BIG-IP DNS (formerly known as BIG-IP GTM) system

Custom characters are allowed with the following exceptions:

  • double quote (")
  • open curly brace ({)
  • end curly brace (})
  • control characters (for example "^M")
  • ampersand (&)
  • colon (:)

The object name must start with an alphabetic character or underscore.

BIG-IP ASM

You should not use the following words in the BIG-IP ASM configuration:

Parameter names

  • UNNAMED
  • DYN_SESSION
  • DYN_FLOW

Object type names

  • no_ext

Frame target values

  • 15
  • 30
  • 31
  • 99
  • 0
