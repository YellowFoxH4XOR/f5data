K10208: Display format change for the number of files used

Issue

In ARX versions prior to 3.2.2, the ARX Manager GUI uses the xx.xxx number format to display the number of files used. For example, a volume using 55,554,688 files would be displayed in the GUI as follows:

55.554 M used (133.399k dirs)

Beginning in ARX 3.2.2, the ARX Manager GUI uses a two-digit format to display the number of files used. For less than 10 million files used, the format is x.x M, for 10 million files or more used, the format is xx M. 

For example, a volume using 55,554,688 files would be displayed in the ARX Manager GUI as follows:

55 M (133 k dirs) of 59 M

Note: The ARX CLI behavior did not change. The ARX CLI for all versions will display the actual number of files used similar to the following example: 

Files: 55,554,688 used (133,399 dirs), 4.4 M free, 68 M max (automatic).

F5 Product Development tracked this change as ARX ID 27621 and 34827.
