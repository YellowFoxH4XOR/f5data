Description

CRLDP Auth agent may fail to verify a client certificate's revocation status if there is no valid host information in the client certificate's CRLDP entries or in the CRLDP Auth server configuration. During this failure, the following message can be logged in the /var/log/apm:

warning apmd[<PID>]: 0149015e:4: (null):Common:abcdefgh: CRLDP Auth agent: CRL lookup failed for LDAP url 'ldap:///CN=test,CN=Configuration,DC=example,DC=com,DC=cn?certificateRevocationList?base?objectClass=cRLDistributionPoint?certificateRevocationList' reason 'No valid host found in the certificate. Please use Direct or Pool options in the CRLDP object.'

Environment

BIG-IP APM

Access policy configured with CRLDP Auth Agent

Cause

This is by-design logging behavior to inform the APM admin that the client certificate does not have a valid host for the LDAP CRLDP entry.

If the client certificate cannot have the host entry, APM can be configured to have a host entry in the CRLDP Auth Server configuration (GUI: Access ›› Authentication : CRLDP -> {CRLDP Auth server} -> Use Pool or Direct -> Server Address).

Answer/Recommended Actions

Two options:

(1) Configure a proper host field for the CRLDP ldap URI in the client certificate. OR,

(2) Configure an appropriate Server Address in the CRLDP Auth Server configuration (GUI: Access ›› Authentication : CRLDP -> {CRLDP Auth server} -> Use Pool or Direct -> Server Address).

Additional Information

None.
