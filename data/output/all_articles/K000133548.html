K000133548: New Add-on key (SKU#: F5-ADD-BIG-AWFVEUP1G) did not enable WAF module on BIG-IP VE

Type
Support Solution
Published
2023-04-18
Updated
2025-02-07
Applies to
  • BIG-IP
  • Virtual Editions
Source
https://my.f5.com/manage/s/article/K000133548

Description

After activating Add-on key (SKU#: F5-ADD-BIG-AWFVEUP1G), it did not enable WAF module on BIG-IP VE with base SKU#: F5-BIG-LTM-VE-25MV18.

Environment

  • BIG-IP VE license
  • Add-on key

Cause

SKU#: F5-ADD-BIG-AWFVEUP1G is for upgrading an existing ASM or WAF license to 1G of throughput. A WAF base license is required, or WAF add-on module needs to be already Active.

Recommended Actions

Contact account manager to find out the correct add-on key to use.

Additional Information

None
