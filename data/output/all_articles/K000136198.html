K000136198: Create SSH public key authentication keys for linux and putty clients

Type

Published
2023-09-14

Description

This article describes how to easily create SSH private and public keys that are compatible with Linux and Putty (for Windows) clients. We create the proprietary Putty .ppk file from the Linux keys.

Enviornment

  • SSH
  • Public Keys 
  • Authentication

Cause

None

Recommended Actions

On your Linux host, you must have puttygen installed. This is already likely to be available in your default Linux distro source.

  1. Create location to generate keys:

    user@host:~$ cd .ssh/
    user@host:~/.ssh$ mkdir demo
    user@host:~/.ssh$ cd demo/

  2. Generate basic keys:

    user@host:~/.ssh/demo$ ssh-keygen -f demo_id_rsa
    Generating public/private rsa key pair.
    Enter passphrase (empty for no passphrase):
    Enter same passphrase again:
    Your identification has been saved in demo_id_rsa
    Your public key has been saved in demo_id_rsa.pub
    The key fingerprint is:
    SHA256:qaAbxiMt+YV09wco+45aLxKGLxPRFPxVzjKz4hXbk3Y user@host
    ...
  3. Check they were created:


    user@host:~/.ssh/demo$ ls -la
    -rw------- 1 user user 2602 Sep 14 13:42 demo_id_rsa
    -rw-r--r-- 1 user user  567 Sep 14 13:42 demo_id_rsa.pub

    Note: The demo_id_rsa file is the private key. Do not share this file!

    user@host:~/.ssh/demo$ cat demo_id_rsa
    -----BEGIN OPENSSH PRIVATE KEY-----
    b3BlbnNzaC1rZXktdjEAAAAABG5vbmUAAAAEbm9uZQAAAAAAAAABAAABlwAAAAdzc2gtcn
    NhAAAAAwEAAQAAAYEApBEfRvM5unxM87MxNpXiiifkRbdUXf5s69x13dah62cQiKRhoXZo
    ...
    fVxo8+iW/M9mPTAAAxDW1pY2hhZWxAemVpc3MBAgMxBQ==
    -----END OPENSSH PRIVATE KEY-----

    The demo_id_rsa.pub public key file can be safely shared across systems. The content of that file should be copied to the correct location on the remote server.

    user@host:~/.ssh/demo$ cat demo_id_rsa.pub
    ssh-rsa AAAxB3NzaC1yc2EAAAADAQxBAAABgQCkER9G8zm6fExzszE2leKKJ+RFx1Rd/...9z7m8Czvcv9OvBA3KyX9D//k= user@host

  4. Copy public key to remote server:

    If the remote server is a Linux based host such as an F5 device, then copying the public key to the remote server is easily done as so from the local host:

    $ ssh-copy-id -fi demo_id_rsa user@server

  5. Convert to the proprietary .ppk format with puttygen:

    user@host:~/.ssh/demo$ puttygen demo_id_rsa -O private -o demo_id_rsa.ppk

    user@host:~/.ssh/demo$ ls -la
    -rw------- 1 user user 2602 Sep 14 13:42 demo_id_rsa
    -rw------- 1 user user 2065 Sep 14 13:50 demo_id_rsa.ppk
    -rw-r--r-- 1 user user  567 Sep 14 13:42 demo_id_rsa.pub

    The .ppk file should take this format:

    user@host:~/.ssh/demo$ cat demo_id_rsa.ppk
    PuTTY-User-Key-File-3: ssh-rsa
    Encryption: none
    Comment: user@host
    Public-Lines: 9
    AAAAB3NzaC1yc2EAAAADxQABAAABgQCkER9G8zm6fEzzszE2leKKJ+RFt1Rd/mzr
    3HXd1qHrZxCIpGGhdmgKuluaC7br4Y7YTtoxq05cQy6pC9pf05VrTgdM7bMp+MbP
    ...
    n0Dpxox/epTg8HhcMpy4mihnrgThqxJp8dnaUf5ggHvoqPE3Oq5fwSnrDqVheqLB
    vKfqIi+9z7m8Czvcv9OvBA3KyX9D//k=
    Private-Lines: 21
    AAABgAyCkQ0ivauhD724qPoxX/TjNCOMEOmhMqKiFaCxMs6AINbHxflUTdGc7SAo
    CtjImFDuY5naP72G5+IUQ8tGbGBuu4gboIDaSyUt4lxM/ZiIzs8sH5pmrMxrUxmY
    ...
    emGxmjDE5+4Z5xolRvut1+9pCA==
    Private-MAC: 559029befcc5a668048e81x23852f5cffdac409xd0530b7aac4e30d94313d938

    As long as the public key has been correctly provided to the remote server or F5 device, Putty can now use the .ppk to login as the user.

Additional Information

 The public key is copied to the server for a specific user. It is not a global way to login for any user. Therefore, Linux and Putty must attempt to login as the same user that the public key was copied for.

The same public key could be copied for multiple users but this would also require sharing the private key with multiple users, which is highly undesirable from an authentication security standpoint.
