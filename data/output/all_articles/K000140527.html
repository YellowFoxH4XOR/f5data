K000140527: Update the BIG-IQ device license

Type
Support Solution
Published
2024-07-31
Updated
2026-09-08
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K000140527

Description

You need to renew the device license for the BIG-IQ.

Environment

  • BIG-IQ

  • Flexible Consumption Plan (FCP)

Cause

With each contract renewal, the license for the BIG-IQ needs to be updated to renew its entitlement, to open F5 support tickets via the MyF5 Customer Portal, and to upgrade the BIG-IQ.

Recommended Actions

Download the latest license key for BIG-IQ from MyF5 then apply it to the BIG-IQ.

Note: Reactivating the license only impacts the BIG-IQ. No remote BIG-IPs are affected.

  1. Confirm whether the BIG-IQ persona is Centralized Manager or License Manager. On the BIG-IQ, navigate to the System tab > This Device > Licensing and note the Licensed Module.
    Important: BIG-IQ Centralized Manager needs to be renewed with a BIG-IQ Centralized Manager license, otherwise functionality will be lost if a BIG-IQ License Manager key is applied.
    Note: BIG-IQ License Manager (LM) can be renewed with BIG-IQ LM or Centralized Manager. Applying a Centralized Manager license to BIG-IQ LM adds functionality, such as, back ups, upgrades, and configuration management.
  2. Logon to MyF5 > Subscriptions > Subscription ID [FCP] (Status: Active) 
  3. Copy a BIG-IQ Subscription Registration Key that has a status of "ready to activate" or "ready to reassign". These indicate the key is available for use. Or generate another key if on MyF5 Self Service for FCP post Jan 13, 2025.
  4. On the BIG-IQ, navigate to System tab > Licensing > Reactivate.
  5. Copy the new BIG-IQ license key into Base Registration Key.
  6. Select the activation method. Automatic requires access to activate.f5.com via port 443 per IP addresses for F5 hosted services.
  7. Click Activate.
  8. Allow 5 - 10 minutes for services to restart on the BIG-IQ. 

Additional Information

Please email the F5 Customer Success Team at CustomerSuccess@f5.com for any questions related to the available license keys in MyF5.
