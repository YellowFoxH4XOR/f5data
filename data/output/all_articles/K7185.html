Known Issue

This is the result of a known issue. Instead of passing the request to BIND, the BIG-IP GTM will reset the TCP connection for a TCP DNS query if there is no matching wide IP configured on the BIG-IP GTM system.

This behavior prevents proper response handling. BIND should answer the request with the correct information or respond with an NXDOMAIN message indicating that no information is available.

F5 Product Development tracked this issue as CR74975 and it was fixed in BIG-IP GTM 9.3 and 9.4.2. For information about upgrading, refer to the BIG-IP GTM Release Notes.
