Description
This article provides information on creating a self-signed certificate using iControl REST API with OpenSSL.

Environment

  • BIG-IP LTM
  • iControl REST API

Cause
None

Recommended Actions

IMPORTANT:
  • F5 recommends that before making any changes to your systems, you back up each system and store the backup in a remote and secure location. For information, refer to K13132: Backing up and restoring BIG-IP configuration files with a UCS archive.
  • Ensure there is enough disk free space (at least 3gb) on the /var/ and /shared/ partitions. For information, refer to K14403: Maintaining disk space on the BIG-IP system.
  • Test the provided commands in the test environment before using it in production.
  1. Prepare the iControl REST API command using the following formats

      iControl REST API Command Format
      curl -sku [admin]:[password] -X POST -H "Content-Type: application/json" -d "{\"command\":\"run\", \"utilCmdArgs\":\"-c '[openssl command]'\"}" https://[BIG-IP Management IP]/mgmt/tm/util/bash -s | jq . | sed 's/\\n/\n/g'

        OpenSSL Command Format
        openssl req -x509 -nodes -days [number of days] -newkey rsa:[byte size] -keyout [/config/ssl/ssl.key/default.key] -out [/config/ssl/ssl.crt/default.crt] -subj /CN=[Common Name]/L=[Locality]/ST=[State]/O=[Organization]/OU=[Organizational Unit]/C=[Country]/emailAddress=[admin email]

        NOTE: Replace the fields with '[]' above with their respective values
         
        CodeDescription
        CNCommon Name
        LLocality (City)
        STState (or Province)
        OOrganization (for example, company)
        OUOrganizational Unit
        CCountry code (for example, SG for Singapore

        For example:  
        openssl req -x509 -nodes -days 3650 -newkey rsa:2048 -keyout /config/ssl/ssl.key/default.key -out /config/ssl/ssl.crt/default.crt -subj /CN=mybigip.local.com/L=Singapore/ST=Singapore/O=mydepartment/OU=myunit/C=SG/emailAddress=admin@local.com

        Combining the two commands: 
        curl -sku admin:mypass -X POST -H "Content-Type: application/json" -d "{\"command\":\"run\", \"utilCmdArgs\":\"-c 'openssl req -x509 -nodes -days 3650 -newkey rsa:2048 -keyout /config/ssl/ssl.key/default.key -out /config/ssl/ssl.crt/default.crt -subj /CN=mybigip.local.com/L=Singapore/ST=Singapore/O=mydepartment/OU=myunit/C=SG/emailAddress=admin@local.com'\"}" https://192.168.100.100/mgmt/tm/util/bash -s | jq . | sed 's/\\n/\n/g'
