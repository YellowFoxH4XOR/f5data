K94801507: Logins Summary page can be configured as the default display page for administrator, resource administrator, and auditor roles

Issue

Old Behavior

In versions prior to BIG-IP 14.0.0, the Logins Summary page is available on the Configuration utility by navigating to System > Logins > Summary; however, you cannot make this page the default display page for users logged in with the administrator or auditor role.

New Behavior

Beginning in BIG-IP 14.0.0, you can configure a system database variable to set the Logins Summary page as the default display page for users logged in with the administrator, resource administrator, or auditor role. This behavior is controlled by the BIG-IP system database variable named ui.users.redirectsuperuserstoauthsummary, and, by default, the variable it is set to false. To enable the ability to display the Logins Summary page by default for users logged in to the system with these roles, you can change the variable to true.

Additionally, if you want explicit notification of previous successful and failed Configuration utility login attempts, this new behavior allows the system to provide it.

Impact

None

Recommended Actions

Enabling the ability to set the Logins Summary page as default display page

  1. Log in to the TMOS Shell (tmsh).
  2. Type the following command:

    tmsh modify /sys db ui.users.redirectsuperuserstoauthsummary value true

Disabling the ability to set the Logins Summary page as default display page

  1. Log in to tmsh.
  2. Type the following command:

    tmsh modify /sys db ui.users.redirectsuperuserstoauthsummary value false
