Known Issue

Note: This Solution only applies to BIG-IP platforms that contain a switch card control processor (SCCP) and are running version 9.4.8. For information on the SCCP, refer to K3454: Overview of the SCCP.

This is the result of a known issue. When the bigpipe interface -j command is run, the BIG-IP system logs an error message to the /var/log/ltm file that appears similar to the following example:

sccp sbmand[451]: 012a0003:3: HAL get stats failed for 0.0

This error message is benign and can be safely ignored.

Note: The bigpipe interface -j command is automatically run during a qkview operation; therefore, the error message may be present in your logs even if you have not run the command yourself.

F5 Product Development is tracking this issue as ID 327770 (formerly CR126377).
