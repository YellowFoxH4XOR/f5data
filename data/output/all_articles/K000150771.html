Description

When using BIG-IP APM with an IP Intelligence (IPI) license, the IP Reputation column in the Access report shows "unknown".

Environment

  • Product: BIG-IP APM
  • Version: 16.X or 17.X
  • Feature: IP Intelligence (IPI)
  • Configuration: IPI license provisioned; APM access report

Cause

The issue occurs when the BIG-IP system cannot connect to required BrightCloud reputation feed servers—especially the IPv6 endpoint (localdb-ipv6-daily.brightcloud.com). In supported versions, both IPv4 and IPv6 IPI databases must be downloaded and loaded into TMM for proper operation. If either database is unavailable or not loaded, IPI lookups will return "unknown" or blank values.

Recommended Actions

Verify Connectivity:

Ensure network connectivity from BIG-IP to these BrightCloud servers:

localdb-ip-rtu.brightcloud.com
localdb-ipv6-daily.brightcloud.com
api.bcti.brightcloud.com


Refer to F5 article K03011490: Verifying connectivity for the IPI Subscription service for a full list of required URLs and ports.

Check Database Status:

Run these commands on BIG-IP to verify IPI database status:

#tmsh show sys iprep-status

------------------------------------------------------------------------

#iprep_lookup <IP_ADDRESS>


Both IPv4 and IPv6 databases should be shown as loaded and current.

Additional Information

The downloaded IP reputation database contains only malicious addresses; if a client IP is not listed as malicious, Ip reputation value will in the access report will be blank.
If the database is not loaded due to connectivity issues, values will appear as "unknown".
