Known Issue

This is the result of a known issue. If your BIG-IP system is licensed for the ZebOS set of advanced routing modules (ARM), and you attempt to start the ARM using the zebos enable command, the advanced routing module does not start, and the following message is output to the console:

Dynamic routing is not licensed. Please contact your F5 representative to license this feature.

F5 Product Development tracked this issue as CR94441 and it was fixed in BIG-IP LTM 9.4.5. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

To work around this issue, perform the following procedure:

  1. Log in to the command line.
  2. To enable each routing protocol, type the following command:

    bigpipe db tmrouted.<protocol> enable

    For example, if your BIG-IP system is licensed for the BGP routing daemon, type the following command:

    bigpipe db tmrouted.bgp enable
  3. Type the following command to enable tmrouted and ensure that the service starts at boot:

    bigstart add tmrouted
  4. Start the routing daemon by typing the following command:

    bigstart start tmrouted
