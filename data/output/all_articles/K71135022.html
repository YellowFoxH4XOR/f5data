Description

When adding HA devices to BIG-IQ, LTM keep flagging change-pending every 10 minutes as it didn't add the "Cluster Display Name".

Environment

 

 

  • HA device clustering

 

Cause

 

"Cluster Display Name" is missing in configuration to avoid flagging.

 

Recommended Actions

 

  1.  Remove(Delete) both BIG-IP from BIG-IQ.
  2.  Do a manual sync for BIG-IP, make sure it is synced.
  3.  Add LTM1 to BIG-IQ "Devices --> BIG-IP DEVICES --> Add Device", fill IP/password, for "Cluster Display Name", choose "Create New", then give a name of it, click "Add".
  4.  Add LTM2 to BIG-IQ "Devices --> BIG-IP DEVICES --> Add Device", fill IP/password, for "Cluster Display Name", choose "Use Existing", then choose the name in step3 (for example Devicednsgroup), click "Add". No need import configuration.
  5.  Go to BIG-IP, do a manual sync due to K99031155. Make sure BIG-IP is synced.
  6. Go to BIG-IQ, "Devices --> BIG-IP CLUSTERS --> DSC Groups", click discover, make sure the "Cluster Display Name" is correct showed.
