Description

Oracle monitor is marking pool members down unexpectedly.

 

Environment

  • BIG-IP Oracle Monitor
  • Oracle Debug Log for pool member includes this reference "Asking daemon to ping remote database. Expected result not received: Database down, see /var/log/DBDaemon-0.log for details."
  • DBDaemon-0.log includes this SQL error "exceeded simultaneous SESSIONS_PER_USER limit"

Cause

Session limit per user on the Oracle DB was being hit by the BIG-IP for the monitor traffic for the user configured.

 

Recommended Actions

Increase the session limit per user on the Oracle DB.

 

Additional Information

Commands to turn on Oracle debug logging for a monitor

tmsh modify gtm monitor oracle <monitor name> debug yes

or

tmsh modify ltm monitor oracle <monitor name> debug yes

Logs will be saved in /var/log/monitors/ 

After collecting logs, turn off with these commands:

tmsh modify gtm monitor oracle <monitor name> debug no

or

tmsh modify ltm monitor oracle <monitor name> debug no
