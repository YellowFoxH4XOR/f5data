K000139773: BIG-IP Tenant QKView warning "Failed to run qkview on slot: X"

Type
Support Solution
Published
2024-05-24
Updated
2024-05-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000139773

Description

  • When generating a qkview from a BIG-IP tenant which is deployed in multiple blades a warning is generated
  • A message similar to the following appears on GUI or CLI

    Warning: Failed to run qkview on slot: 1
    Warning: Failed to run qkview on slot: 5
  • The BIG-IP tenant is configured with a modified list of ciphers, MAC and key exchange algorithms used by the SSH service

Environment

  • F5OS Tenant
  • Qkview from BIG-IP Tenant
  • Velos platform with multiple blades

Cause

The BIG-IP tenant is configured with a modified list of algorithms, and none of the default algorithms included on the /config/ssh/ssh_config file are listed.

Recommended Actions

At least one Cipher, one KEX algorithm, and one MAC from the ciphers used by the ssh client must be included for blade-to-blade communication to allow SSH between slots and qkview collection. For the list of ciphers, refer to the /config/ssh/ssh_config file.
