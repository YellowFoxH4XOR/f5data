Description

Connection to the tenant management IP fails when it is on a different subnet from the F5OS-A management

Environment

  • rSeries
  • BIG-IP Tenant

Cause

Connectivity to the Tenant's Management IP is via the F5OS-A Management Interface

Recommended Actions

A network route must be added through the F5OS management IP to connect to the tenant management IP

Additional Information

As there is no functionality in F5OS-A to add any additional management routes other than the default gateway, this route would need to be added to an upstream router.  It is not a best practice or recommended configuration by F5.
