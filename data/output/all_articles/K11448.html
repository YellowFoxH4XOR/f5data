Known Issue

This is the result of a known issue. When mapping Active Directory groups in the FirePass controller, if the group name contains a vertical bar ( | ) character, mapping from the FirePass controller to Active Directory fails to map a user to the Active Directory group. The group displays an underscore ( _ ) character instead of the vertical bar. 

For example:

my_group

This issue occurs as a result of Active Directory remapping the vertical bar character to an underscore character for Windows 2000 compatibility. This converted name is returned to the FirePass controller for the Active Directory group mapping.

F5 Product Development is tracking this issue as CR140130.

Workaround

You can work around this issue by avoiding using the vertical bar character in group names. In addition, you can work around this issue by setting the group as the primary group for the user and mapping to the converted group name. As a result, the FirePass controller will recognize the user as a member of the converted group name.

Note: For more information about group mapping, refer to K9061: Overview of FirePass group mapping.
