K000151004: Tenant Configuration lost during blade removal and re-add to a VELOS partition

Type
Support Solution
Published
2025-04-24
Updated
2025-04-24
Source
https://my.f5.com/manage/s/article/K000151004

Description

Tenant configurations are lost when a blade is removed and re-added to a partition, necessitating a UCS restore for recovery.

Environment

  • VELOS-C

Cause

This behavior is intentional, as the security model mandates the removal of user data when a blade transitions between administrative domains.

Recommended Actions

Recover Tenant Configurations from a Reliable UCS Backup file.

Additional Information

Enhancement request RFE (ID 1144457) proposes adding a message during blade removal to notify the administrator of data deletion.
