Description

The local bind DNS nameserver does not resolve external domains and returns the following error :
Example for the domain google.com:
 
can't find google.com: Query refused
 
Environment
  • BIG-IP DNS
  • ZoneRunner
  • Local bind enabled in DNS profile (all the other methods like DNS cache, DNSexpress, DNSsec disabled)
  • Recursion lookup desired

Cause

In most cases, such error is interconnected with misconfiguration of bind nameserver (named.conf). If the "forward nameservers" are configured, and "recursion yes;" & "forward only;" options are not set, the bind server will not perform the recursive lookup.

Recommended Actions

Verify if named.conf includes "recursion" and "forward" parameters
 
1. Log in to the BIG-IP command line.
2. Change directories to the /var/named/config directory by typing the following command:
 
cd /var/named/config
 
3. Create a backup of the named.conf file by typing the following command:
 
cp named.conf named.conf.orig
 
4. To edit the named.conf file, locate the recursion option.
For example:
 
recursion no;
 
Change the recursion option to yes. For example:
 
recursion yes;
 
5. Add the forward only option statement directly below the changed recursion statement. For example:
 
recursion yes;
forward only;
 
6. Save the changes to the named.conf file.
7. Restart named to allow the changes to reload by typing the following command:
 
tmsh restart /sys service named
