K000137457: tcpdump with net in the filter and not prefix doesn't work in script dosl7d_attack_monitor

Type
Support Solution
Published
2023-11-03
Updated
2023-11-23
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.7, 15.1.9, 15.1.10, 15.1.6, 15.1.8
Source
https://my.f5.com/manage/s/article/K000137457

Description

The script to record traffic during a DOS attack doesn't include the destination prefix of the Virtual Server.
It doesn't capture any traffic when the DOS profile is configured for a network Virtual Server, for example 0.0.0.0/0

Example:

dosl7d_attack_monitor|INFO|Sep 13 08:54:15.338|24937|main::recordTcpDump,,going to exec: nice -30 tcpdump net 0.0.0.0 and port 12081 -i0.0 -s 0 -W 2 -Z root -C 10.24 -w '/shared/dosl7/tcpdumps/2023_9_13_8:54:15-2.pcap'

...

dosl7d_attack_monitor|DEBUG|Sep 13 08:54:47.368|24937|main::clearEmptyFile,,/shared/dosl7/tcpdumps/2023_9_13_8:54:15-2.pcap size is 0 

Environment

  • BIG-IP ASM 
  • Traffic Record
  • tcpdump

Cause

This is cause by  Bug ID1360129

Please open a case with F5 support to request for a Engineer HotFix for bug ID 1360129
