Known Issue

This is the result of a known issue. When you use certain non-alphanumeric characters in the password for the Maintenance Console, the FirePass controller denies access to the Maintenance Console, even when you enter the password correctly. The password configuration for the Maintenance Console is found on the Device Management: Security: Console Access Security page of the Administrative Console.

F5 Product Development tracked this issue as CR78302 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Workaround

To work around this issue, use only alphanumeric characters in the Maintenance Console password. If you have already entered a Maintenance Console password with a non-alphanumeric character, change the Maintenance Console password to an alphanumeric password by selecting the Change Password check box on the Device Management: Security: Console Access Security page of the Administrative Console, then entering an alphanumeric password.

If you have already entered a Maintenance Console password with a non-alphanumeric character, and cannot access the Administrative Console, you can enter the existing non-alphanumeric password at the Maintenance Console password prompt, adding two backslash characters (\\) before each non-alphanumeric character. If the non-alphanumeric character is a backslash, then add three backslash characters (\\\) before each backslash character. For example, if the password is pass\word, you would enter the following:

pass\\\\word
