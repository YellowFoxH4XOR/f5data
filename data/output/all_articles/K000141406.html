Description

CNAME requests are not resolved by listener.

'A' type wide IP with a CNAME pool is not resolving the DNS CNAME requests.

Environment

  • BIG-IP DNS

Cause

No wide ip cname type configured.

Recommended Actions

If you want the BIG-IP DNS to respond to both A and CNAME record type requests, you must configure two wide IPs. One wide IP of type A with a CNAME pool type, and a second wide IP of type CNAME with a CNAME pool type. At a minimum, an A record type wide IP should be configured with a CNAME pool.
