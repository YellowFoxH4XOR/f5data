Topic

You should consider using these procedures under the following condition:

  • You want to reference content stored in an external file in an iRule.

Description

External data groups allow you to store content for the data group in an external file on the BIG-IP system rather than in the bigip.conf file. Because the content is not included in the bigip.conf file, external data groups are better suited for large data sets. The bigip.conf file contains the metadata for the data group and references the file location. The data stored in the external data group file is a comma-separated list of values (CSV format). 

When creating external data groups, you first import the external file to the BIG-IP system then you create the new data group and reference the imported file as the type. When importing a data group file, you select the type based on the type of data in the data group file. You can import the following types of data groups files to the BIG-IP system:

  • Address
  • String
  • Integer

After you create the new external data group, you can then reference the data group in your iRules.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have administrative access to the BIG-IP system.

Procedures

  • Create the external data group file
  • Import the external data group file
  • Create the external data group

Create the external data group file

The data group file is the external file containing the content you want to reference. You can create the file on the BIG-IP system using a text editor such as vi or pico, create the file on another device or the BIG-IP system using a script, and then either copy it over or import it to the BIG-IP system. You should format the contents of the file in CSV format and use := as a key/value separator by default. The following example external data group file output shows data formatted for the address, string, and integer types:

Note: When creating the data group file on Windows systems, you may create the file created with \r\n line terminators, which may prevent the BIG-IP system from importing the file. For more information, refer to v11: iRules Data Group Updates on DevCentral.

Address

# cat ext_dg_address.txt
host 192.168.1.1,
host 192.168.1.2 := "host 2",
network 192.168.2.0/24,
network 192.168.3.0 mask 255.255.255.0 := "network 3",
network 192.168.4.0 prefixlen 24,

String

# cat ext_dg_string.txt
"name1" := "value1",
"name2" := "value2",
"name3" := "value3",

Integer

# cat ext_dg_integer.txt
1 := "test 1",
2 := "test 2",
3 := "test 3",

Import the external data group file

Before you create the external data group, you must import the data group file to the BIG-IP system. You can import the file from a client machine using the Configuration utility or you can copy the file to the BIG-IP system and import it using the TMOS Shell (tmsh). To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: When creating the data group file on Windows systems, you may create the file created with \r\n line terminators, which may prevent the BIG-IP system from importing the file. For more information, refer to v11: iRules Data Group Updates on DevCentral.

Use the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to System > File Management > Data Group File List.
  3. Select Import.
  4. For File Name, select Choose File and select the data group file to import.
  5. For Name, select Create New and enter a name for the imported file.
  6. For File Contents, select the type of content contained in the file: Address, String, or Integer.
  7. For Key / Value Pair Separator, you can leave the value as default unless you used a different separator in your data group file, in which case, specify it here.
  8. Select Import.

Use tmsh

  1. If the external data group file is not local to the BIG-IP system, copy it to the BIG-IP system. In this example, we use the ext_dg_address.txt data group file in the /var/tmp/ directory.
  2. Log in to tmsh by entering the following command:

    tmsh

  3. Import the external data group file using the following syntax:

    create /sys file data-group <imported_filename> separator "<separator>" source-path file:/<path_to_external_file> type <ip | string | integer>

    For example, to import the /var/tmp/ext_dg_address.txt file and name it ext_dg_address_file, enter the following command:

    create /sys file data-group ext_dg_address_file separator ":=" source-path file:/var/tmp/ext_dg_address.txt type ip

  4. Save the changes by entering the following command:

    save /sys config

Create the external data group

After you import the data group file, you can create the external data group. You specify the imported data group file when creating the external data group. To create an external data group, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Use the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > iRules > Data Group List.
  3. Select Create.
  4. For Name, enter a name for the data group.
  5. For Type, select (External File).
  6. For File Name, select the file you imported from the list.
  7. Select Finished.

Use tmsh

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Create the new external data group and reference the imported file using the following syntax:

    create /ltm data-group external <data_group_name> external-file-name <data_group_filename>

    For example, to create a new data group named ext_dg_address that references the ext_dg_address_file data group file created previously, enter the following command:

    create /ltm data-group external ext_dg_address external-file-name ext_dg_address_file

  3. Save the changes by entering the following command:

    save /sys config
