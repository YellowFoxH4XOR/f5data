Description

How to find out SSH protocol version running in BIG-IP?

Environment

  • BIG-IP
  • SSH protocol

Cause
None

Recommended Actions

  1. Execute this command on the command line
    grep -i protocol /var/run/config/sshd_config
  2. Here is the sample output
    #Protocol 2,1
    Protocol 2                        
    # HostKey for protocol version 1
    # HostKeys for protocol version 2
    # similar for protocol version 2
  3. The second line in the above example states Protocol 2. This states that only v2 is supported.
