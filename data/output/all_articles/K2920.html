Topic

If you need to access the network when recovering a system in single user mode, perform the following steps:

  1. Bring up the appropriate interface, by using the following command syntax:

    /sbin/ifconfig <interface> <ip address> netmask <netmask>

    For example:

    /sbin/ifconfig 1.2 10.90.100.1 netmask 255.255.255.0

  2. Add a default route, by using the following command syntax:

    /sbin/route add default <router ip address>

    Now you can use FTP or other tools that require the use of a network.

    You must use IP addresses rather than domain names because address resolution does not work in single user mode.

    For example:

    /usr/bin/ftp <ip address>

    Note: You can use another host that is connected to the network to look up IP addresses.

  3. After you perform the necessary tasks in single-user mode, you can return to multi-user mode by typing the following command:

    exit
