Description

How is "Install Configuration" used when switching boot locations on BIG-IP and when should someone specify "No" or "Yes"?

Environment

  • Installed a new BIG-IP version
  • Switching boot location to the new location

Cause

N/A

Recommended Actions

  • For a fresh install, the configuration is automatically copied over, so your designation of "Yes" or "No" doesn't really matter under default conditions on a fresh install.
  • For a non-fresh install, the configuration won't be copied over by default. If you have an updated configuration on your running instance and you want to copy, then you can proceed with "Yes" and it will copy the updated configuration over on reboot. If you don't want to copy the local config over, then choose "No".

Note: It's basically a web UI interface of "cpcfg" command.
