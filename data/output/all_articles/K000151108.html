K000151108: Citrix Receiver Download URL Not updating

Type
Support Solution
Published
2025-04-30
Updated

Status
Legacy Content
Applies to

  • BIG-IP APM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000151108

Description

You are experiencing an issue where the Citrix Receiver Download URL is not updating as expected on your BIG-IP APM. This can prevent users from downloading the required Citrix Receiver client. The issue occurs because the default URL for downloading the Citrix Receiver client is no longer valid, resulting in an outdated or broken link.

Environment

  • BIG-IP APM

Cause

  • The default URL for the Citrix Receiver client download is outdated and no longer valid.

Recommended Actions

  1. Navigate to Access >> Connectivity / VPN : VDI / RDP : Citrix Client Bundles.
  2. Open the appropriate Citrix Client Bundle.
  3. Locate the Download URL field.
  4. Update the Download URL to a valid, current URL for the Citrix Receiver client.
  5. Save the configuration and test to ensure users can successfully download the client.
