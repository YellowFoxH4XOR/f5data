K000132399: Need case-sensitive URI in ASM logging profile

Type
Support Solution
Published
2023-02-02
Updated
2023-02-18
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.3
Source
https://my.f5.com/manage/s/article/K000132399

Description

Syslog message generated by ASM security logging profile does not retain case-sensitivity for URI field.

Environment

  • BIG-IP ASM
  • Logging profile
  • Remote logging
  • "Policy is case sensitive" set to No on ASM policy configuration

Cause

Seen behavior is expected if the ASM policy in question has "Policy is case sensitive" set to No. When "Policy is case sensitive" is set to No, the ASM evaluates and logs all URI's in lower case.

Recommended Actions

If you need ASM to treat file types, URLs, and parameters as case sensitive you will need to set "Policy is case sensitive" to Yes.

Additional Information

Security Policy is case sensitive:

Specifies, when checked (enabled), that the security policy treats file types, URLs, and parameters as case sensitive. Specifies, when cleared (disabled), that the security policy treats file types, URLs, and parameters as case insensitive. Disable this setting if the web application is case insensitive. When this setting is disabled, the system stores these security policy elements in lowercase in the security policy configuration. The default setting is enabled.
