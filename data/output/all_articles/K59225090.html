Known Issue

BIG-IP GTM does not allow a loopback address with fallback IP load balancing.

This issue occurs when any of the following conditions are met:

  • You attempt to specify 127.0.0.1 for fallback IPv4 within the Configuration utility.
  • You attempt to specify 127.0.0.1 for fallback IPv4 using the Traffic Manager Shell (tmsh) utility.

Impact

You are unable to configure a loopback address using fallback IP load balancing.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the tmsh utility, you observe an error message that appears similar to the following example:

    01020061:3: IP Address 127.0.0.1 is invalid, loopback not allowed.

  • In the Configuration utility, you observe an error message that appears similar to the following example:

    Invalid IP or Hostname
