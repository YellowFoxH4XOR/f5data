Description

GUI [ also known as configuration Utility] may display ASM Critical Warnings when navigating to the Application Security Policies list

 ASM Critical Warnings : An upgrade process was interrupted. It is very likely that ASM will start with a severe inconsistent internal state and critical errors.

Environment

  • BIG-IP
  • ASM

Cause

  • System configuration restore started using UCS file
  • UCS restore process is interrupted in the middle of the restoration 
  • In particular, if the interruption happened at a time '/ts/lock/ts_db.lock' is locked, then an ASM critical warnings can be displayed when accessing Application Security Policies using the GUI [ configuration Utility] 

Recommended Actions

  • To remove the Warnings message from the GUI, initiate and restore a previously archive UCS file
  • If no previous UCS file available, then restore a freshly generated UCS.
