Topic

F5 has recently discovered and corrected a number of critical issues that affect customers running BIG-IP 10.0.1. F5 recommends that all customers currently running 10.0.1 install Hotfix-BIGIP-10.0.1-378.0-HF3, or a later version of the cumulative hotfix rollup, as soon as possible.

Note: CRs new to the release are in bold text.

Important: This release contains a BIOS update for the 6900 and 8900 platforms. Do not reset or power-cycle the BIG-IP system during the installation for these platforms.

The following CRs are fixed in Hotfix-BIGIP-10.0.1-378.0-HF3 for BIG-IP 10.0.1:
