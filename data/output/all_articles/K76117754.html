Known Issue

Creating a Session Initiation Protocol (SIP) monitor using the BIG-IP DNS Configuration utility results in the following error message:

General database error

This issue occurs when all of the following conditions are met:

  • You provision the BIG-IP DNS module (formerly BIG-IP GTM).
  • You log in to the BIG-IP DNS Configuration utility and do the following:
    1. Navigate to DNS > GSLB > Monitors.
    2. Click Create.
    3. In the Type list, you click SIP.
    4. You configure and attempt to save the SIP monitor.

Impact

You are unable to create SIP monitors using the BIG-IP DNS Configuration utility.

Symptoms

As a result of this issue, you encounter the following symptom:

  • When you attempt to create a new SIP monitor using the BIG-IP DNS Configuration utility, you receive the following error message:

    General database error.

Workaround

To work around this issue, you can use the TMOS shell (tmsh) to create the new SIP monitor. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To create a new SIP monitor, use the following command syntax:

    create gtm monitor sip <monitor_name> <option_1> <option_2>

    For example, to create a new SIP monitor named example_sip, type the following command:

    create gtm monitor sip example_sip

  3. To view the available monitor options, type the following command:

    create gtm monitor sip <monitor_name>?.

  4. To save the configuration, type the following command:

    save sys config
