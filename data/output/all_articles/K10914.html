Known Issue

This is the result of a known issue. Mac OS X users running Safari 4 may hang while trying to connect to a FirePass controller during the Checking client session if a client check has been configured in the pre-logon sequence.

This issue does not exist for Safari 3 or FireFox users.

F5 Product Development tracked this issue as CR128305 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

This issue has been fixed in cumulative hotfix HF-603-5.1.1 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

To work around this issue, users can connect successfully with either Safari 3 or a supported version of FireFox.
