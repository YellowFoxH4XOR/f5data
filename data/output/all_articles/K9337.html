Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following article:

  • K13550: Persistence entries mirrored to the standby unit shows an age of 0 seconds (11.x - 13.x)

You can use persistence mirroring on the BIG-IP system to duplicate the active system's persistence information to the peer unit. When failover occurs, persistent connections can proceed as the peer system becomes active.

When viewing the mirrored persistence entries on the standby unit, using the Configuration utility or the command line, the age value is always displayed as 0 (zero) seconds, as shown in the following bigpipe persist show all example output:

----------------------------------------------------------------------
PERSISTENT CONNECTIONS
|     Mode source addr   Value 172.16.65.254
|        virtual 172.16.65.19:http   node 10.10.64.1:http   age 0sec
----------------------------------------------------------------------

This behavior is expected. The active system does not mirror the persistence age to the standby system. When failover occurs, the newly active system resets the age time for mirrored persistence entries to 0 seconds.

Note: For more information about connection and persistence mirroring, refer to K7222: Overview of connection and persistence mirroring (9.x - 10.x).
