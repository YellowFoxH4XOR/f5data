Known Issue

The BIG-IP GTM system may incorrectly mark down resources monitored by an external monitor.

This occurs when the following condition is met:

  • The debug feature is enabled on the external monitor.

Impact

The BIG-IP GTM system may mark available resources down.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP GTM system is expected to redirect debug messages resulted from the monitor to the /var/log/<monitor_type>_<monitor_name>.<ip_address>.<port>.log file, however, this file is not generated.
  • The BIG-IP GTM system may incorrectly mark resources down.

Workaround

To avoid the issue, you can disable the debug feature using either the Configuration utility or the Traffic Management Shell (tmsh) utility. To do so, perform one of the following two procedures.

In addition, it may be possible to use an alternate tool, such as the tcpdump utility, to perform troubleshooting on a monitor. For more information about using tcpdump, refer to K411: Overview of packet tracing with the tcpdump utility.

Impact of workaround: None.

Disabling the BIG-IP GTM monitor debug feature using the Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Global Traffic > Monitors and select the name of the monitor to disable the debug feature.
  3. Click on the Configuration drop-down menu and select Advanced.
  4. To disable the debug feature, click on the Debug drop-down menu and select No.
  5. To save the modification, click Update.

Disabling the BIG-IP GTM monitor debug feature using the tmsh utility

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  2. To disable the debug feature on a BIG-IP GTM monitor, use the following command syntax:

    modify /gtm monitor scripted <GTM_Monitor_Name> debug no

    For example, to disable the scripted BIG-IP GTM monitor type named my_gtm_script, enter the following command:

    modify /gtm monitor scripted my_gtm_script debug no
  3. Save the changes by typing the following command:

    save /sys config
  4. To exit the tmsh utility, type the following command:

    quit
