K000133475: Expired certificates within the ca-bundle.crt certificate in the BIG-IQ

Type
Support Solution
Published
2023-04-12
Updated
2024-07-03
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.0.0, 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X
Source
https://my.f5.com/manage/s/article/K000133475

Description

The ca-bundle.crt certificate may be outdated, and so, several certificates within the bundle are expired.

 

Environment

BIG-IQ

 

Cause

The BIG-IQ's software version has not been updated for some time, new software versions include an updated ca-bundle.crt certificate

 

Recommended Actions

None, even though the ca-bundle.crt exists in the BIG-IQ, it is not used by the BIG-IQ, given that the ca-bundle.crt is a traffic certificate and the BIG-IQ is a control plane only device

 

Additional Information

None
