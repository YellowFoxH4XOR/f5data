Description
F5 unable to connect to proxy using the default proxy.port db value of 8080

Environment

  • F5 configured with proxy.host and with default value of proxy.port.
  • F5 required to connect to internet to download ASM database or upload qkview to ihealth.
  • Internet proxy is listening on port 8080, and F5admin decides to leave the proxy.port to its default value.

Cause
Even though there is a default value of 8080 for proxy.port, the db key proxy.port must be manually set to 8080 for the port to take effect.

Recommended Actions

  1. If internet proxy is running on port 8080, run the below commands to manually configure the proxy.port

    tmsh modify sys db proxy.port value 8080
    tmsh save sys config
