Topic

The BIG-IP ASM security policy object types are limited to eight characters.

Note: An object type is an extension such as .php, .asp, and .html.

Workaround

To work around this issue, you can perform one of the following procedures:

  • Enabling the Traffic Learning feature
  • Creating a web object

Enabling the Traffic Learning feature

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Application Security > Web Applications.
  3. On the Web Applications page, select the name for which Traffic Learning should be enabled.
  4. Select Traffic Learning.
  5. Select Apply Policy.

Note: All the extensions learned by the Traffic Learner will be grouped together and assigned to an Object Type named no_ext.

Creating a web object

  1. On the Main tab of the navigation pane, expand Application Security, and then click Web Applications.
  2. In the Name column, click the name of a web application.
  3. In the Security Policies List area, under the Security Policy Name column, click the name of security policy.
  4. On the menu bar, click Web Objects.
  5. Above the Web Application Objects list, click Create.
  6. In the Object Path box, type the full resource path starting with the slash (/) character.
  7. In the Protocol list, select the protocol to be used to access the object.
  8. To get the default object type associations for this web object, click Get Defaults.
  9. Click Create.
  10. To put the security policy changes into effect immediately, click Apply Policy.
