K000148261: Interfaces went down in Velos Partition

Type
Support Solution
Published
2024-10-25
Updated
2024-10-25
Applies to
  • F5OS
  • F5OS-C: 1.5.X, 1.6.X, 1.6.2, 1.6.1, 1.6.0, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000148261

Description

  • Error "Unexpected NACK detected during I2C transaction" on Velos partition
  • Error messages similar to the following can be seen on Partition velos.log file

    blade-1(p2) fpgamgr[14]: priority="Err" version=1.0 msgid=0x301000000000007 msg="SDK error during device programming." API="pageSetReadI2c: i2c_write" code=-15 error="Unexpected NACK detected during I2C transaction".
    blade-1(p2) fpgamgr[14]: priority="Err" version=1.0 msgid=0x304000000000014 msg="DDM I2C error reading channel monitoring values" PORTGROUP="1/2".

  • Error messages similar to the following can be seen on Partition /var/log/messages

    blade-1 journal: error: I2C read unexpected NACK after writing address byte

Environment

  • Velos
  • F5OS-C
  • Interfaces marked down

Cause

Seen behaviour is the result of a known issue tracked with the Bug ID 1328985

Recommended Actions

As a workaround, ensure that all interfaces, used or unused, are enabled.

Additional Information

None
