Description

If you want to know the number of active sessions of VMware Horizon View , the corresponding OID does not exist. 
 

Environment

  • BIG-IP APM

Cause

The OID for VMWare Horizon view only is not available, instead, use Active Sessions Established.

Recommended Actions

Count it by the number of total active sessions. 
That is: Active Sessions Established apmAccessStatCurrentActiveSessions (.1.3.6.1.4.1.3375.2.6.1.4.3)
