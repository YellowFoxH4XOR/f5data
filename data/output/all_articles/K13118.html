Known Issue

Description

Microsoft Office 2010 cannot open files downloaded in a Protected Workspace.

This issue occurs when all of the following conditions are met:

  • The user is in a Protected Workspace
  • The file is downloaded from an untrusted internet source
  • The file is being opened in Microsoft Office 2010

Impact

Users are unable to open downloaded files in Office 2010.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When opening the file fails, an error message that appears similar to the following example displays:
          
       Word experienced an error trying to open the file.
       Try these suggestions.
       * Check the file permissions for the document or drive.
       * Make sure there is sufficient free memory and disk space.
       * Open the file with the Text Recovery converter.

Workaround

Impact of workaround: An untrusted file may infect the computer system with a virus.

To work around this issue, you can unblock the file access security. To do so, perform the following procedure:

  1. Right click the document experiencing the issue.
  2. Click Properties.
  3. Click Unblock.
  4. Click OK.
