Known Issue

This is the result of a known issue. The BIG-IP ASM stores incoming requests in plain text format. Certain requests may include sensitive data that you may not want the system to store once the request has been processed. You can avoid storing any sensitive data as plain text by adding the names of the input fields to the Sensitive Parameters property. The BIG-IP ASM system then replaces the sensitive data with a series of asterisk ( * ) characters.

However, when you are running the Policy Builder, and the sensitive parameter value contains meta characters, the Policy Builder will not update the meta characters within the sensitive parameters.

F5 Product Development tracked this issue as ID 250176 (formerly CR68024) and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP ASM release notes.
