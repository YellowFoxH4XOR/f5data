Description

DNS resolves a FQDN (Fully Qualified Domain Name) to an IP address but does not specify the protocol used such as http or https.

Environment

Relevant environmental factors specific to the topic

  • DNS (formally GTM)

Cause

DNS records do not specify the specific browser protocol.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. If your webserver requires https, then configure an http to https redirect on the webserver.
