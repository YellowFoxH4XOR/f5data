Error Message

01071732:3: Autopopulate not licensed. Disabling autopopulate on member <pool_member>::.

In this error message, note the following:

  • <pool_member> is the name of a pool member that had fqdn autopopulate enabled.  

The error may also be listed without a pool member name.  For example:

01071732:3: Autopopulate not licensed. Disabling autopopulate on member ::.

Message Location

You may encounter this message in the following location[s]:

  • /var/log/ltm
Description

This message occurs when all of the following conditions are met:

  • You have not re-activated your BIG-IP license PRIOR to the upgrade.
  • You have upgraded your BIG-IP version recently
  • There are pool member(s) that had Fully Qualified Domain Name (fqdn) nodes with autopopulate enabled in the previous configuration.

Impact

When the BIG-IP's configuration is loaded into the upgraded version of BIG-IP, the "autopopulate enabled" feature will become disabled for fqdn nodes in a pool.  Even if the BIG-IP license is re-activated after the upgrade, that feature will not be restored.  It will have to be manually updated, as it has been completely stripped from the configuration during the upgrade.
 
You may also see these errors in /var/log/ltm:

  • 01071859:4: Warning generated : Load balancing feature not licensed.
  • 01180006:3: Software version not covered by service agreement service check date <yyyymmdd> version date <yyyymmdd>>
 
In the last error message listed above, note the following:
  • service check date <yyyymmdd> is the last date that the BIG-IP license was re-activated 
  •  version date <yyyymmdd>> is the License Check Date required of the version that you have installed.
Additionally, you may find this error message in /var/log/dynconfd*:
 
(5140) [E]: <node name>: FQDN does not exist. DNS query returns NXDOMAIN
In this error message, <node name> will be populated with an FQDN of a node that was previously listed with autopopulate enabled.  For example: 
2018-07-09 15:13:40.975165 (5140) [E]: [my_web_app.net]: FQDN does not exist. DNS query returns NXDOMAIN
