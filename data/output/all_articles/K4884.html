K4884: Applications that are accessed through FirePass may immediately log out users or fail to load pages

Topic



While there are a number of reasons why an application accessed through FirePass may fail to load pages, the most common reason is that a JavaScript was used to test the content of the of the page and the test failed, or the content did not match the expectations. If the content fails the JavaScript test, errors might be reported or the application could refuse to allow further operations.

Some common JavaScript tests perform the following functions:

  • Check the protocol of the URL to make sure it is http://
  • Check the URL to make sure the host name matches the server
  • Perform a checksum on the page and make sure it matches the original

JavaScript tests frequently fail when the site is accessed through FirePass, because FirePass modifies URLs to use the HTTPS protocol and the host name of the FirePass.

You can use one of the following solutions to work around this issue:

  • Modify the application so that the tests allow for the changes made by FirePass.
  • Use a content processing script to modify the JavaScript test.
  • Use a content processing script to remove the JavaScript test.

For more information about content processing, refer to the FirePass Controller Administrator Guide.
