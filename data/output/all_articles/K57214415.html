Security Advisory Description

This vulnerability exploits the application layer gateway (ALG) mechanism of network address translations (NATs), routers, and firewalls through modification of internal IP extractions for a client browser connection and therefore bypasses the browser's port restrictions. This attack requires that the NAT or firewall device must support ALG (used for protocols that require multiple ports such as DCC, FTP, H323, IRC, and SIP).

Using a timing attack or with WebRTC, the attacker can inject a new packet into the packet stream, taking control of the data portion of a TCP or User Datagram Protocol (UDP) headerless packet.

Impact

There is no impact; F5 products are not affected by this vulnerability.

Security Advisory Status

F5 Product Development has evaluated the currently supported releases for potential vulnerability, and no F5 products were found to be vulnerable.
