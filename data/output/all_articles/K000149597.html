Description

Information about robots.txt served on BIG-IP and BIG-IQ management IP.

Entering https://<big-ip_mgmt-ip>/robots.txt in browser shows:

User-agent: *
Disallow: /

Environment

  • BIG-IP  or BIG-IQ management IP
  • https://<big-ip_mgmt-ip>/robots.txt

Cause

File robots.txt is not F5 specific, here's more about the Robots Exclusion Protocol:

https://en.wikipedia.org/wiki/Robots.txt

https://www.cloudflare.com/learning/bots/what-is-robots-txt/

 

robots.txt is a file that non-malicious web crawlers can use to determine what resources they are allowed to visit.

In the case of BIG-IP, it says that they disallowed to visit anything:

----

User-agent: *

Disallow: /

----

 

Generally, it's not expected that BIG-IP is accessible publicly from the Internet (where web crawlers can scan it) but F5 serves this file to prevent search engines from indexing BIG-IP in case customers accidentally expose the management GUI to the Internet.
