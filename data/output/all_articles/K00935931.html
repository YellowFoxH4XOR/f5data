Known Issue

Using iRules with asynchronous commands in the ICAP_RESPONSE event may result in data loss.

This issue occurs when the following conditions are met:

  • An Internet Content Adaptation Protocol (ICAP) profile, an HTTP profile, and a Response Adapt profile are assigned to an internal virtual server.
  • The ICAP internal virtual server has an iRule that contains commands that may take an extended period of time to complete asynchronously in the ICAP_RESPONSE event.

Impact

The HTTP client receives an incomplete HTTP response from the ICAP server. As a result, the internal virtual server times out the HTTP connection and closes it.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You observe that data returning from the ICAP server to the HTTP client may stall while an ICAP_RESPONSE event is pending on the internal virtual server.
