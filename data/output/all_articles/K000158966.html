K000158966: Higher swap usage on BIG-IP Virtual Edition (VE) running 17.5.0

Type
Support Solution
Published
2025-12-31
Updated
2025-12-31
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.0
Source
https://my.f5.com/manage/s/article/K000158966

Description

VE running 17.5.0 may have higher swap use, from about 60 MB extra, but can be more (up to low hundreds of MB) if many network interfaces.


Environment

Virtual Edition running 17.5.0


Cause

sysctl vm.min_free_kbytes was increased, from 24141 to a minimum 98304 on 17.5.0, to allow more memory for a new network driver.


Recommended Actions

Typically this was benign. Later software versions (17.5.1 onwards) restricted change to sysctl vm.min_free_kbytes on VE hosted on Hyper-V and Azure platforms, and reverted the change for other platforms via the fix of ID 1880365.
