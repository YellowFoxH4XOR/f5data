Description

Is there a limit to the amount of configuration objects such as virtual servers that can be created on a BIG-IP appliance?

Environment

  • Configuration files
  • Virtual servers

Cause

None

Recommended Actions

There is no hard limit to the amount of objects that can be created. However, the amount of traffic the system can handle is limited by the resources it has available, and the resource limitation varies by platform.

Consideration should be given to the amount of traffic the system is expected to handle. For example, if there are 5000 virtual servers handling a small amount of traffic, this may be less resource-intensive than 50 virtual servers handling a substantial amount of traffic.

Monitoring also does not scale well with large configurations, particularly when using resource-intensive monitors such as HTTPS, or external monitors. Consider using larger monitor intervals, or implement In-TMM monitoring.

Finally, very large configurations may incur timeouts or slowness when accessing the GUI. Consider increasing the provision.tomcat.extramb database variable to reduce the impact of this.
