Known Issue

This is the result of a known issue. If you apply to a virtual server a TCP profile with the MD5 signature setting enabled, the virtual server should reject or ignore connections that do not present the MD5 signature option during the three-way handshake. However, the virtual server will accept connections regardless of whether the peer presented the MD5 option.

Additionally, this issue affects both client-side and server-side connections. A client is expected to present the MD5 signing option to the BIG-IP system in the initial SYN. The server is expected to present the MD5 signing option in its ACK to the BIG-IP system's SYN.

Note: This issue does not affect TCP connections established from the BIG-IP host (for example, BGP connections).

Note: When the MD5 signature setting is enabled, and an MD5 signature is present, the MD5 signature is validated.

F5 Product Development is tracking this issue as ID 223426 (formerly CR129710).
