Description

When the HTTP requests have a long query string length that exceeds the default limit, the BIG-IP ASM/Advanced WAF system does not process the exceeded part even if the request content matches an attack signature. The attack signature check will be performed only to the limit of the url length and the rest of it will be ignored if the HTTP requests are extremely long.

Environment

  • BIG-IP ASM / BIG-IP Advanced WAF
  • Virtual server
  • Pool member
  • Security policy

Cause

The system global variable ecard_max_http_req_uri_len defines the maximum URL length that the system can support in its internal buffers. The default value of ecard_max_http_req_uri_len is 2048 bytes.  
Recommended Actions

To let the BIG-IP ASM/Advanced WAF system perform attack signature checks, you will have to increase the ecard_max_http_req_uri_len system variable to accommodate the request length:

  1. Login the Configuration Utility.

  2. Navigate to Security  ››  Options : Application Security : Advanced Configuration : System Variables

  3. Increase the variable ecard_max_http_req_uri_len to proper value.
