Description

  • BIG-IP pair is failing to complete the configsync, and displays an error regarding the DB size.
    err mcpd[7046]: 01070710:3: Database error (82), Can't extend DB size by <value> bytes, error code:82 - EdbDbConnection.cpp, line <value>.

Environment

  • High-Availability pair
  • Configsync 
  • BIG-IP LTM

Cause

In rare cases, large configurations, especially those with many internal data-groups or iRules, can exhaust the mcpd configuration allocation.

Recommended Actions

By default, the mcpd.maxdbsize is 512. You can increase it to 1,024, by following the procedure given below:

  1. Login to the BIG-IP command line
  2. Set mcpd.maxdbsize to 1024
    tmsh modify sys db mcpd.maxdbsize value 1024
  3. Save the change:
    tmsh save sys config
  4. Initiate Sync device from GUI
    a. Select the device with latest config changes
    b. Push the selected device configuration to the group

Additional Information

If your configuration contains large internal data-group, consider using external data-groups, instead.
