Description:

This article describes how to remove unused expired certificates and keys from BIG-IQ.

Certificates are shared objects which you can use on managed BIG-IPs. During process of discovery and import none of the certificates are removed from BIG-IQ. If administrator is using external scripts to renew certificates on BIG-IP, we can find leftovers on BIG-IQ.

Environment:

BIG-IQ CM

shared objects Certificates

Cause:

BIG-IQ does not provide built-in automation for removing expired or unused certificates and SSH keys.

Recommended Actions:

  • Automated Removal of Unused Certificates

Use the BIG-IQ REST API to list all certificates and remove those not assigned to any profile:

curl -u admin:admin http://localhost:8100/mgmt/cm/adc-core/working-config/sys/file/ssl-cert/ | jq -r ".items[] | .id" | xargs -I {} curl -X DELETE http://localhost:8100/mgmt/cm/adc-core/working-config/sys/file/ssl-cert/{} -u admin:admin

Note: Certificates still in use will not be deleted; a 400 error will indicate dependencies.

  •  Automated Removal of Unused SSH Keys

Similarly, use the BIG-IQ REST API to list all SSH keys and remove those not assigned elsewhere.

Example command:

curl -u admin:admin http://localhost:8100/mgmt/cm/adc-core/working-config/sys/file/ssl-key/ | jq -r ".items[] | .id" | xargs -I {} curl -X DELETE http://localhost:8100/mgmt/cm/adc-core/working-config/sys/file/ssl-key/{} -u admin:admin
