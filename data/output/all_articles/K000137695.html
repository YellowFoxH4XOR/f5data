Description

When there is no pool or node monitor failure event or even there is no monitor object is attached to pool or node, virtual server may flaps its status.

Nov 16 15:56:04 bigip.local notice mcpd[5217]: 010719e8:5: Virtual Address /Common/10.1.1.154 monitor status changed from DOWN to UNCHECKED.
 

Environment

All the following conditions are matched:
 

  • FQDN node and FQDN pool are configured and associated with virtual server.
  • DNS server returns SERVFAIL response against DNS query for FQDN node object.
     

Cause

When BIG-IP receives DNS SERVFAIL response against DNS query for FQDN node object, virtual server, to which FQDN node/pool object is attached to, status can flap.
