Known Issue

Application Access Java application tunnel may not function with Internet Explorer.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with an Application Access Java application tunnel.
  • You establish a session with the BIG-IP APM system using Internet Explorer 11.
  • You have configured Internet Explorer to use Enhanced Protected Mode.

The default configuration of Internet Explorer 11 includes Enhanced Protected Mode. When running in this mode, the browser process runs inside an AppContainer that prevents the interception and redirection of connection requests intended for processing by the BIG-IP APM application tunnel.

Impact

The application tunnel does not function.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When launching the application tunnel, the new browser window opens. However, the application is not accessible.

Workaround

To work around this issue, you can modify the Internet Explorer 11 configuration by disabling Enhanced Protected Mode or by adding the back-end server destination resource to the Trusted or Intranet Sites lists.
