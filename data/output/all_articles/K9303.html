Known Issue

This is the result of a known issue. A user is able to successfully launch and connect to a VNC terminal server favorite upon first access. However, when closing the browser window for the first session and then attempting to launch the favorite again, the user is unsuccessful in connecting. The following error message is displayed:
 
Failed to connect to server

F5 Networks Product Development is tracking this issue as CR108650.

Workaround

You can work around this issue by logging out and logging back in.
