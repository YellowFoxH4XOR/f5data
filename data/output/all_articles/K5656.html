K5656: Microsoft PPP adapter and F5 Network Access client report different values for connection statistics

Topic

The Microsoft Windows Point-to-Point Protocol (PPP) adapter and the FirePass Network Access client report different values for the number of bytes transferred and for compression ratios.

These statistics differ because the Microsoft Windows PPP adapter collects information from a higher location in the networking stack than the FirePass Network Access client.

The Microsoft Windows PPP adapter collects statistics before the IP packet is framed by PPP and before IP and TCP/UDP headers are compressed using Van Jacobson compression. Application data in the packet payload is not compressed. Therefore, the bytes reported consist of the uncompressed IP and TCP/UDP headers, and the application data.

The compression reported is the Van Jacobson IP and TCP/UDP header compression ratio.

In contrast, the FirePass Network Access client collects statistics after PPP framing and after the compression of TCP/UDP headers. The FirePass Network Access client includes bytes that are transmitted or received by the Link Control Protocol (LCP) and the IP Control Protocol (IPCP), which are protocols used to negotiate and monitor a PPP connection.

The compression ratio reported is the optional gzip-deflate compression, configured on the Network Access: Resources page in the FirePass Administrative Console. Compression is applied to the entire PPP, LCP or IPCP packet, and then sent through SSL to or from the FirePass.

Viewing statistics collected by Microsoft Windows

To view the statistics collected by Microsoft Windows, double-click the FirePass network connection's Network icon in the System Tray.

Note: The FirePass network icon will have the same name as the Network Access Favorite, and this name will appear when the user places the mouse over the icon.

After double-clicking the FirePass network icon, a status window will open and display the statistics collected by Microsoft Windows.

Viewing statistics collected by the F5 Network Access client

Using a browser

View the statistics collected by the F5 Network Access client by performing the following steps:

  1. Log in to the FirePass controller.
  2. Open a Network Access connection.
  3. Click the Summary icon in the Network Access pop-up window.

    The statistics will display in the Network Access pop-up window.

Using the standalone VPN client

  1. Log in to the FirePass controller.
  2. Under the View menu in the Stand-alone VPN client, select Advanced Mode.

    The statistics will display in the main window of the Stand-alone VPN client.
