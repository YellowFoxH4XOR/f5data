Description

  • BIG-IP Edge Client Setup Wizard ended prematurely because of an error. Your system has not been modified. To install this program at a later time, please run the installation again.

Cause

Windows requires that software is signed by a software signing certificate. 

Recommended Actions

When experiencing Edge Client installation issues, you can use the following troubleshooting steps to determine the root cause:

    • Install after disabling Antivirus, Firewall, Real-time protection software, and security software
    • Confirm the root certificate using certmgr.msc
    • Verify the computer has connectivity to the internet.
      • The windows software validation process checks against a 3rd party Certificate from Entrust.

    Install after disabling Antivirus, Firewall, Real-time protection software, and security software

    It is possible for security software to block requests for "entrust.net." Disabling security software will test for this block.

    Impact of procedure: Disabling security software may place a client machine at risk for external threats.

    1. Disable/uninstall active security software on client machine
    2. Attempt to re-install BIG-IP Edge Client

    Procedure back out: Re-enable/re-install the client security software.


    Confirm the Root Certificate using certmgr.msc

    Using the certmgt.msc utility within Windows, you can validate the Entrust root CA on the client in question.

    Impact of procedure: The following procedure should have no negative impact on the client

    1. Launch certmgr.msc from a Windows run prompt
    2. Navigate to Trusted Root Certification Authorities > Certificates
    3. Verify the existence and dates for Entrust Root Certification Authority

    Update/Install Entrust root CA

    If the Entrust root CA is out of date or missing, you can use the following steps to update/install.

    Impact of procedure: The following procedure should have no negative impact on the client

    1. Follow the steps provided by Entrust to download and install the root certificate authority
      https://www.entrust.com/get-support/ssl-certificate-support/root-certificate-downloads/
      Note: This link takes you to a resource outside of AskF5, and the third party could remove the document without our knowledge.
       
    2. Attempt to install the Edge Client

    Additional Information

    Windows requires that software is signed by a software signing certificate. When installing F5 software, your computer will attempt to validate the file origination by checking the software certificate embedded in the F5 Edge Client installer files against the Root signing authority from Entrust. This certificate should be on your computer already, but from time to time expires, or is updated by the vendor.
