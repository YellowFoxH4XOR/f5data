Topic

This article provides information about the October 2025 F5 signing certificate and key rotation for BIG-IP APM network access VPN clients.

Description

In October 2025, F5 rotated the cryptographic certificates and keys used to sign software update packages. As a result, the verification logic within the BIG-IP APM Installer Service (auto-updater) has been updated to recognize and validate packages signed with the new certificates and keys.

Mandatory update to APM Client 7261

To ensure a secure and uninterrupted upgrade/update path, systems using the BIG-IP APM Client installer service must first update to APM Client 7261. This version is the first release capable of recognizing the newly signed update packages. Once on APM Client 7261, you can continue updating normally to later versions.

This requirement only applies to upgrade/update scenarios that relies on the BIG-IP APM Client Installer Service which is BIG-IP APM’s proprietary auto-updater.

For more information, refer to K15302: Understanding BIG-IP Edge Client Component Update behavior for Windows, macOS, and Linux CLI. 

Non-mandatory update

You do not need to make the mandatory update to APM Clients 7261 under the following conditions:

  • You install updates on VPN clients directly via MSI files. Refer to K44328534: BIG-IP administrator instructions for downloading BIG-IP Edge Client for Windows and Mac OS X, and Linux clients

    (This archived article may provide some limited workarounds K84473448: How to download and install Windows BIG-IP Edge Client without an installation package

  • You use your own deployment tools (e.g., SCCM, Intune, or other enterprise software distribution platforms)

In such cases, the BIG-IP APM auto-update signature validation logic is bypassed, so the certificate rotation does not impact the upgrade process.

Additional Information

BIG-IP releases from 17.1.3.1 onwards include a bundled upgrade to APM Clients 7262, to avoid signing issues when upgrading from older versions you should roll out APM Clients 7261 with the F5 auto updater, to your client base before upgrading your BIG-IP.
