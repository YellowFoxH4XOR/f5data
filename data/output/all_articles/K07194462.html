K07194462: Outdated gossip device information

Type
Support Solution
Published
2021-01-22
Updated
2025-04-01
Applies to
  • F5 Automation and Orchestration
  • BIG-IP
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K07194462

Description

After a software upgrade you may see wrong data in the "gossip" output for devices that are part of a device group.
For example when calling the "shared/resolver/device-groups/tm-shared-all-big-ips/devices" endpoint, the output may show correct device names and IP information, but the software version may be wrong.

This can also cause an error log message every 10s in the restjavad-audit log file:

[Date][ForwarderPassThroughWorker] {"user":"credentials","method":"GET","uri":"http://localhost:8100/mgmt/shared/resolver/device-groups/tm-shared-all-big-ips/devices/identifier","status":404,"from":"IP address"}

Environment

  • Upgraded BIG-IP
  • Managed by BIG-IQ or AS3
  • Gossip

Cause

The cause is not know at this time.

Recommended Actions

In order to update the device details under the "shared/resolver/device-groups/tm-shared-all-big-ips/devices" endpoint you can follow these steps:

1. Delete gossip devices:
restcurl -X DELETE shared/resolver/device-groups/tm-shared-all-big-ips/devices

2. Force gossip to update device information:
restcurl -X POST -d '{}' tm/shared/bigip-failover-state

3. Restart restjavad:
tmsh restart /sys service restjavad
