K000163454: Does the “Response rate limit was reached” error message apply to a remote log profile?

Type
Support Solution
Published
2026-09-29
Updated
2026-09-29
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K000163454

Description

The “Response rate limit was reached” error message occurs when both of the following conditions are met:

 

  • Response logging is enabled in the logging profile associated with the virtual server.
  • BIG-IP ASM receives more responses per second than the value configured for the response_log_rate_limit system variable.

 

Environment

BIG-IP ASM / Advanced WAF.

A logging profile with response logging enabled

Local logging or remote logging destination

 

Cause

None

 

Answer/Recommended Actions

The response_log_rate_limit system variable applies to response logging regardless of whether the logging profile uses a local logging destination or a remote logging destination.

 

The variable also applies regardless of whether response logging is configured for:

  •  Illegal requests only
  • All requests

The limit controls the rate at which ASM processes and logs responses; it is not specific to the logging destination.
