Known Issue

The BIG-IP ASM may send a TS session cookie on every processed HTTP response.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM security policy is configured with policy building set to automatic or manual.
  • The security policy is applied to a virtual server that actively processes HTTP/HTTPS traffic.

Impact

Processed HTTP connection responses sent from the BIG-IP ASM include a Set-Cookie for the TS session cookies on each processed response. 

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing the HTTP network level traffic the BIG-IP ASM system includes a TS session cookie on each response even when the value of the cookie has not changed.
