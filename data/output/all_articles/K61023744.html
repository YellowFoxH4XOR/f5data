Description

After upgrade of BIG-IQ device Gui reports "Waiting for BIG-IQ services to become available"

/var/log/tokumon/current errors:

[INFO] postgres_configurator: configurePostgresqlIsReady:rbacReady. ready:false
[INFO] postgres_configurator: is db ready. dbIsReady:false
[WARNING] tokumon: isDBReady db is NOT ready.


 

Environment

  • BIG-IQ Centralized Management Cluster
  • Upgrade to version 7.x or 8.x
  • Hanged rbac process

Cause

ID957445 - tokumond won't start indexing the database until the rbac-reset finishes

Recommended Actions

Perform rbac-reset on problematic device:
  1. Open SSH session to affected BIG-IQ:
  2.  perform command: /usr/bin/rbac-reset
  3. Monitor process by accessing database and checking count of authorization journals
  4. Open database and perform  select query few times ( counter from point 5 should go to 0):
    psql -U postgres -d bigiq_db
    select count(*) from bigiqauthorization.shared_authorization_journals;
  5. Output example:
    bigiq_db=# select count(*) from bigiqauthorization.shared_authorization_journals;
     count
    -------
         2
    (1 row)

    ---========================================================================================--
    bigiq_db=# select count(*) from bigiqauthorization.shared_authorization_journal;
     count
    -------
         0
    (1 row)
