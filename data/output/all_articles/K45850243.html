Description

VLAN names longer than 24 characters will be truncated in a VMCP Guest.
Long VLAN names (longer than ~24 characters) are not truncated on the hypervisor. This happens only on guests.

Example error log:
warning vcmpd[6310]: 01510005:4: VLAN name truncation happens. Truncating the VLAN name from vlan_Example_Very_Long_Vlan_Name to vlan_example_truncated
 

Environment

  • VMCP Guests
  • VLAN names

Cause

VLAN name is too long for the VCMP Guest.
Note: this should not impact traffic

Recommended Actions

  1. Use shorter VLAN names on the hypervisor.
