Description

A BIG-IP system with multiple differently-weighted routes towards a destination may sometimes send return traffic towards the destination via a non-preferred route.

Environment

  • BIG-IP LTM
  • BGP

Cause

This behaviour is expected when auto-lasthop is enabled. With auto-lasthop, the BIG-IP system returns traffic to the MAC address from which the connection was received without considering any metrics or preferences that have been defined in the routing table.

Recommended Actions

You can configure the BIG-IP system to consult the routing table for return traffic by disabling auto-lasthop either globally or on the affected configuration object as per K13918.

Note: The auto-lasthop feature saves CPU cycles on your BIG-IP system by reducing the number of route table lookups needed to return traffic towards clients. Disabling this feature may therefore have an impact on CPU usage.
