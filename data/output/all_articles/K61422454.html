Description

When connecting to a new virtual server with the IP address, an invalid certificate warning is presented in the browser, but the trusted certificate chain is present.

Environment

  • Virtual Server
  • HTTPS
  • Browser

Cause

The subject of the certificate issued by the public CA is not the IP address, but rather the common name. The host and domain name entered in the browser's address bar must match the subject of the server's certificate.

Recommended Actions

Connect using website's host and domain name, rather than IP address.

None
