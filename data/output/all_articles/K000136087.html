K000136087: The SSL profile lost after modify the SSL configuration via SSL Orchestrator Guided Configuration

Type
Support Solution
Published
2023-09-05
Updated
2023-09-05
Applies to
  • F5 App Protect
  • F5 SSL Orchestrator: 16.1.3
Source
https://my.f5.com/manage/s/article/K000136087

Description

In the SSL Orchestrator Configuration page, click one L3 Inbound topology, modify the SSL Configuration, deploy it, then the SSL configuration will lost.
In the virtual server for this topology, Client SSL profile and Server SSL profile will become empty.
Access the SSL Orchestrator Configuration page again, click the same L3 Inbound topology, click SSL Configuration section, will see the warning below:

Non-SSL Orchestrator-managed SSL settings have been selected. Please go to Local Traffic >> Profiles >> SSL to manage the SSL profiles directly.

Environment

  • BIG-IP SSLO with SSL Orchestrator RPM version 9.3
  • L3 Inbound topology
  • SSL Configuration

Cause

It is caused by ID 1099205.

 Recommended Actions

Upgrade to 16.1.4 or higher, upgrade the SSL Orchestrator RPM version to 9.4, this issue will not happen.

Before upgrade, please follow the steps below to restore the SSL Configuration:

  1. Logon Configuration Utility, navigate to SSL Orchestrator  ››  Configuration.
  2. Click the L3 Inbound topology with this issue.
  3. Go to Interception Rule section, under Protocol Settings, under Client SSL Profiles and Server SSL Profiles, move the correct SSL profile (/common/ssloT_<topology name>.app/ssloT_<topology name>-cssl and /common/ssloT_<topology name>.app/ssloT_<topology name>-sssl) from Available to Selected.
  4. Click Deploy.

Before upgrade, if you need to modify the SSL Configuration, the workaround to prevent this issue:

  1. Logon Configuration Utility, navigate to SSL Orchestrator  ››  Configuration.
  2. Click the L3 Inbound topology which you want to modified.
  3. Go to the SSL Configuration section, modify the configuation, repeat to click Save & Next.
  4. Go to Interception Rule section, under Protocol Settings, under SSL Configurations, move the correct SSL Configuration (ssloT_<topology name>) from Available to Selected.
  5. Repeat to click Save & Next, click Deploy.
