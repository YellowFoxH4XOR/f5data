Topic

This topic explains how to update F5 AI Guardrails and custom guardrails. Guardrail updates are available automatically when F5 releases new versions, but you control when the updates take effect. The steps differ slightly depending on whether you are updating AI Guardrails or custom guardrails, and whether your environment is SaaS or self-hosted.

Description

When F5 releases guardrail updates, your organization receives them automatically (SaaS) or after you deploy the new version (self-hosted). To avoid disrupting live projects, there is a manual step to adopt the updates. This gives you control over when changes take effect.

This topic covers two update paths:

  • Updating F5 AI Guardrails out-of-the-box guardrails
  • Updating custom guardrails

The following table summarizes how each update path works:

Prerequisites

You must meet the following prerequisites to use these procedures:

  • Org admin access: You must be an org admin to update any guardrail type.
  • AI Guardrails permission: Required to update AI Guardrails out-of-the-box guardrails.
  • Custom guardrails permission: Required to update custom guardrails.

Procedures

  • Update all guardrails at once
  • Update a single guardrail
  • Update custom guardrails
  • Self-hosted environments

F5 tests all out-of-the-box guardrails before release. You can update all affected guardrails at once, or update them one at a time.

Update all guardrails at once

Important: This action can't be undone.

  1. Log in to the AI Security UI
  2. Navidate to AI Guardrails > Guardrails
  3. Select Update all. A modal appears. It describes what has changed and lists all affected guardrails.
  4. Review the changes listed in the modal.
  5. Select Update all to apply the updates. All affected guardrails are updated immediately. Projects using these guardrails are updated to the new version automatically.

Update a single guardrail

Important: This action can't be undone.

  1. Select the N guardrail updates link for the package you want to update.
  2. Select Update available for the guardrail you want to update.
    A modal appears. It describes what has changed.
  3. Review the changes listed in the modal.
  4. Select Update to apply the update.
    Projects using this guardrail are updated to the new version automatically.

Update custom guardrails

When a system or infrastructure update affects your custom guardrails, the system automatically creates a new unpublished version of each affected guardrail. You can test the new version before publishing and choose when to deploy it.

  1. Select Update available next to the guardrail you want to update.
    The Edit view opens. The new unpublished version appears at the top of the list. The release version is appended to the previous version name.
    Note: To change the version name, create a new version.
  2. Select Test to open the Playground and test the new version.
  3. When testing is complete, select Publish to make the new version available to projects.

Self-hosted environments

In self-hosted environments, the update path is the same for AI Guardrails and custom guardrails. Your organization controls when to install the release that contains the new versions. You can also roll back to a previous product version if needed.
