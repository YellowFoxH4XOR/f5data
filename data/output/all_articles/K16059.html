Known Issue

BIG-IQ Security allows deployment of nested IP address and port lists to managed devices that do not support the feature.

This issue occurs when all of the following conditions are met:

  • You use BIG-IQ Security to create a firewall object containing either a nested IP address list or a nested port list.
  • You attempt to deploy the firewall object to a managed device running BIG-IP AFM.
  • The managed device is running 11.4.0 or earlier.

Impact

When deployed from BIG-IQ Security, firewall objects containing nested IP address lists or nested port list will not be present on the managed device.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • New firewall objects deployed to managed devices are missing.
