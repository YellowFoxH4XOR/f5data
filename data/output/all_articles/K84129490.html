K84129490: Unable to delete silo due to stale reference to a previously imported BIG-IP

Type
Support Solution
Published
2021-09-30
Updated
2026-08-03
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.1.0, 8.3.0, 8.0.0, 8.2.0, 8.1.0, 7.1.X
Source
https://my.f5.com/manage/s/article/K84129490

Description

Unable to delete Silo due to following error:

The silo mysilo1 is not empty: device 192.168.1.1 (xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx) in the silo

Environment

  • BIG-IQ
  • Delete silo from BIG-IQ

Cause

Silo contains an stale reference to a previously imported BIG-IP. In other words, affected managed BIG-IP had been removed from BIG-IQ but the silo still contain a stale reference to it.

Big-IQ only allows deletion of silo when it contains no device references.

Recommended Actions

  1. List all existing silos and from the command output identify which silo to delete:
    # restcurl /cm/shared/silos | jq '.items[]|{name,id}' -c | sort

    Example Output:
    {"name":"mysilo1","id":"b187d6d2-05c4-3c79-93b8-3d72cf563beb"}
    {"name":"ournewsilo2","id":"79b4fae5-75b4-373c-a3d7-ae79dce2b8b8"}
     
  2. Delete only the affected silo. Replace "<silo ID>" with Silo ID identified from Step 1.
    # restcurl -X DELETE /cm/shared/silos/<silo ID>

    Example:

    Assuming the affected silo is "mysilo1", following will be the command to delete it:
    # restcurl -X DELETE /cm/shared/silos/b187d6d2-05c4-3c79-93b8-3d72cf563beb
     
  3. Delete all existing references to the affected silo. If needed, re-run the commands several times until totalItems return 0 to ensure all references have been deleted. Replace "<silo name>" with the silo name identified from Step 1:

    # for i in $(restcurl "/shared/index/config?%24filter=cm/silo%20eq%20'<silo name>'&category=working-config&inflate=false" | jq -r .items[] | cut -d"/" -f 5-); do restcurl -X DELETE ${i}; done

    # restcurl "/shared/index/config?%24filter=cm/silo%20eq%20'<silo name>'&category=working-config&inflate=false" | jq .totalItems

    Example:

    Assuming the affected silo is "mysilo1", following are the commands to list and delete all references to this silo:

    # for i in $(restcurl "/shared/index/config?%24filter=cm/silo%20eq%20'mysilo1'&category=working-config&inflate=false" | jq -r .items[] | cut -d"/" -f 5-); do restcurl -X DELETE ${i}; done

    # restcurl "/shared/index/config?%24filter=cm/silo%20eq%20'mysilo1'&category=working-config&inflate=false" | jq .totalItems
