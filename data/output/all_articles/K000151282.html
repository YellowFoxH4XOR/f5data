What Happened?

  • Why does my CE interface not come up/show even though I specified it during initial CE creation/registration?

Environment

  • F5® Distributed Cloud (XC)
  • Customer Edge (CE)
  • XC Console

Resolution/Answer

  • Node names specified in XC Console site configuration need to match actual node names of the CE. Otherwise, all sorts of issues can emerge, including interfaces not coming up that you expect. Moreover, node names specified in any interface configuration must match actual node names of CE.
  • You can see actual node names of CE in XC Console MCNC (multi-cloud network connect) > infrastructure (left pane) > sites > click your site name > infrastructure (top toolbar).
  • Compare the actual node names to what you have configured in XC Console by navigating to XC Console MCNC (multi-cloud network connect) > infrastructure (left pane) > sites > click your site name > Manage Configuration
  • NOTE: For secure mesh CE, it's not possible to change the static IP address for a SLO interface on a CE node after CE deployment. If you try to do this, you will receive an error message. The only way this can be done is by destroying and recreating the CE with the different static IP address.
