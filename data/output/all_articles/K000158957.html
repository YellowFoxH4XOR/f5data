K000158957: BIG-IP DNS (GTM) does not respond to certain DNS queries when "unhandled-query-action" is set to "drop"

Type
Support Solution
Published
2025-12-31
Updated
2025-12-31
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.5.1
Source
https://my.f5.com/manage/s/article/K000158957

Description

BIG-IP DNS (GTM) does not respond to certain DNS queries, resulting in dropped packets without any response to the client. Packet captures show that:

  • DNS queries for domains matching configured Wide IPs receive proper responses
  • DNS queries for domains not matching any Wide IP or DNS Express Zone are silently dropped with no response sent to the client

This behavior occurs when the DNS profile is configured with the unhandled-query-action parameter set to drop.

Environment

  • Product: BIG-IP DNS (GTM)
  • Configuration:
    • DNS profile with unhandled-query-action set to drop
    • DNS Express disabled or not configured for all queried domains
    • Wide IPs configured for specific domains only

Cause

The DNS profile configuration option unhandled-query-action is set to drop. This setting instructs the BIG-IP DNS system to silently drop any DNS query that does not match a configured Wide IP or DNS Express Zone, resulting in no response being sent to the client for those queries.

Recommended Actions

  1. Review the current DNS profile configuration to verify the unhandled-query-action setting:
    tmsh list ltm profile dns <profile_name> unhandled-query-action
  2. If responses are desired for all DNS queries (including those not matching a Wide IP or DNS Express Zone), modify the unhandled-query-action setting:
    tmsh modify ltm profile dns <profile_name> unhandled-query-action allow
  3. Review and update Wide IP configurations to ensure all required domains are covered by the BIG-IP DNS configuration.
  4. Consider configuring DNS Express Zones for domains that should receive responses but do not require Wide IP functionality.

Additonal Information

The unhandled-query-action  parameter in the DNS profile controls how the BIG-IP DNS system handles queries that do not match any configured Wide IP or DNS Express Zone. Available options include:

  • drop: Silently drops unmatched queries without sending any response
  • allow: Forwards or responds to unmatched queries according to other DNS profile settings
  • reject: Sends a DNS response indicating the query cannot be processed
