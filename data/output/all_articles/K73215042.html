K73215042: After BIG-IP system upgraded to 16.1.x, opening ASM security Policy may remain stuck on ''Loading policy general settings...''

Type
Support Solution
Published
2021-09-01
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.1.X, 16.1.2, 16.1.1, 16.1.3, 16.1.0
Source
https://my.f5.com/manage/s/article/K73215042

Description

  • You upgrade BIG-IP system to version 16.1.0.x
  • Upgrade succeeded but after the upgrade the system failed to load the details of security policies
  • From the User Interface [UI], you navigate and select a policy  Security  ››  Application Security : Security Policies : Policies List >  <name of policy> 
  • The page gets stuck in " Loading policy general settings... "
  • This in turn prevents you from being able to edit/update any of the policies you created in previous boot location
  • Browser developer tools console log may display an error similar to the following:
