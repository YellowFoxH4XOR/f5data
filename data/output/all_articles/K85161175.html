K85161175: ASM update stuck on ''Building Preview''

Type
Support Solution
Published
2023-04-07
Updated
2023-04-07
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP ASM: 15.1.2
Source
https://my.f5.com/manage/s/article/K85161175

Description

Your screen display gets stuck when applying an attack signature update.

Environment

  • Application Security Manager (ASM)
  • Occurs during attack signature update

Cause

Unknown at the time of publication.

Recommended Actions

To work around the issue, follow these steps:

  1. Access the command line interface of your F5 device.
  2. Run the following command in bash:  
    bigstart restart tomcat

This command will restart the Tomcat service and should resolve the stuck screen display issue.

None
