K13190: The asmqkview script is compatible with iHealth

Applies to

Source

Issue

Old Behavior

Previously, the BIG-IP ASM asmqkview utility created an ASM-specific snapshot file that did not contain the data collected by the qkview utility, and it was not compatible with BIG-IP iHealth. When submitting diagnostic information for BIG-IP ASM to F5 Technical Support, it was necessary to send both an asm_snapshot file and a qkview output file.

New Behavior

Beginning in BIG-IP ASM 10.2.2, when you run the asmqkview utility, the qkview utility runs automatically and creates a single diagnostic file that you can upload to BIG-IP iHealth to diagnose the health and proper operation of the system.

For more information about the data collected by the asmqkview script, refer to K6824: Overview of the 'asmqkview' script.

Impact

You can load the output of the asmqkview script directly into BIG-IP iHealth.

Recommended Actions

None
