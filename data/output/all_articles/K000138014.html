Description

HA cluster BIG-IP were not responding to the configured "Floating Self IP address" from HA member, network or self ICMP ping from CLI
 

Environment

  • BIG-IP
  • DSC (HA cluster)
  • Floating IP
  • ICMP Ping not reachable
  • GUI
 

Cause

Floating IP were not reachable because both HA cluster were in force offline mode
 

Recommended Actions

To address the floating IP's network reachability issue, bring either one or both of the BIG-IP HA cluster members online.

  1. Login to BIG-IP GUI > Device Management > Devices > "Hostname (Self)" > Release Offline
  2. A prompt to agree "Bring this Device back online?" > Click "OK" button to agree
