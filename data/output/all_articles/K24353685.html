Description

BIG-IQ deployment has not been managed over time and is currently failing to upgrade with random errors

  • Elastic Search is down
  • Unable to successfully run the Pre-Upgrade Script
  • Open Distro errors

Environment

  • BIG-IQ CM 
  • DCD's
  • BIG-IQ HA

Cause

Upgrading a BIG-IQ HA/DCD's that maintenance has been neglected and needs to be brought back into production but status is unknown

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Remove the secondary Big-IQ CM from the primary CM: System -> HA -> Remove Secondary
  2. Run clear-rest-storage on the former secondary Big-IQ.  (*This should not clear out the content of /shared/ucs_backups)
  3. From bash on the primary CM run:
    # reset-data-collection-cluster
  4. On all of the DCDs run:
    # clear-rest-storage
  5. On the Primary BIG-IQ CM run Pre-Upgrade Script, it should succeed now and show no issues
  6. Upgrade the primary and secondary Big-IQ CM devices
  7. Reform the BIG-IQ CM's HA pair
  8. Add the DCDs back in, if desired
