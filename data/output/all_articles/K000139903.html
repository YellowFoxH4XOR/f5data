Description

A certificate revocation list (CRL) is a list of digital certificates that have been revoked by the issuing certificate authority (CA) before their actual or assigned expiration date.

If a CRL file is concatenated by multiple CRL list, please don't seperate CRL list published by same CA, or the later one the the file will be ignored by BIG-IP.

Environment

  • BIG-IP
  • SSL or TLS
  • Certificate revocation list (CRL)

Cause

This is expected behavior.

Recommended Actions

Please make sure the CRL published by same CA is in a same list in the concatenated CRL file.
