K6972: The RST response from the origin server is translated into a FIN for a BIG-IP ASM-enabled virtual server

Known Issue

This is the result of a known issue. If a BIG-IP ASM-enabled virtual server connection receives an RST response from the origin server, the BIG-IP ASM will change the packet to a FIN when passing the packet to the client. As a result, a blank page may display.

F5 Product Development tracked this issue as CR73316, and it was fixed in BIG-IP ASM 9.3 and 9.4.2. For information about upgrading, refer to the BIG-IP ASM release notes.
