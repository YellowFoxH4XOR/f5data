Known Issue

The BIG-IP APM system may not display the correct logon page for local users.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access policy uses a local user database for authentication.
  • The access policy is configured with multiple logon pages.
  • The local user authenticating is configured with the option Force Password Change in the Local User DB.

Impact

After the user changes the password, the system presents the incorrect logon page.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After the user changes the password, the system presents the incorrect logon page.
  • The system displays the correct logon pages when the user is not requested to change their password.

Workaround

To work around this issue, you can reset the value of the session.logon.page.challenge variable. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > Access Profiles > Access Profiles Lists.
  3. Open the visual policy editor by clicking Edit to the right of the Access Profile name.
  4. Click the + to the successful branch of the LocalDB Auth agent.
  5. Select the Assignment tab.
  6. Click Variable Assign.
  7. Click Add Item.
  8. Click Variable Assign.
  9. Click the change link for rule one.
  10. Select Custom Variable.
  11. In the Custom Variable text box, enter the following text:

    session.logon.page.challenge

  12. In the Custom Expression text box, enter the following text:

    expr { 0 }

  13. Click Finished.
  14. Click Save.
  15. In the upper left corner of the visual policy editor, click Apply Access Policy.
