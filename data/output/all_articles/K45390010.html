K45390010: Software Installation Can't Be Stopped Manually

Type
Support Solution
Published
2022-11-07
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K45390010

Description

Can't stop or terminate the software installation process in below condition

  • Installation progress is very slow
  • Installation progress stops at xx%
  • Stop or cancel the installation during the installation
How to cancel or interrupt a software installation?

Environment

  • BIG-IP
  • Upgrade
  • Installation with Configuration Utilities or TMSH

Cause

Don't have such TMSH commands or GUI icons, and it is by design.
 

Recommended Actions

The installation can't stop or terminate gracefully and no commands can terminate it.

Additional Information

  • K95602348: Software installation stuck at 0%
  • K13030: Forcing the mcpd process to reload the BIG-IP configuration
