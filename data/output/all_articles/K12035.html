Topic

CAPTCHA is a security mechanism that distorts a challenge keyword that you must interpret and enter a response to authenticate. CAPTCHA is designed to assist in the prevention of automated attacks.

F5 Networks Product Development tracked a request for enhancement (RFE) to implement CAPTCHA challenge-response logon security in FirePass as ID 294146 (formerly CR130588) and ID 295746 (formerly CR130588-1), and it was added in FirePass version 7.0.0. For information about upgrading, refer to the FirePass Release Notes.

This RFE has been included in cumulative HF-610-3-1 for FirePass version 6.1.0 . You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Note: For more information about configuring CAPTCHA in FirePass, refer to K12034: Configuring CAPTCHA challenge-response logon security in FirePass.
