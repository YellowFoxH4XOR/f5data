Topic

This article applies to BIG-IP 11.x. For information about previous versions, refer to the following article:

  • K6293: Overview of the RAM Cache aging rate setting for the HTTP profile (9.x - 10.x)

The cache aging rate setting in the Web Acceleration profile specifies how the system calculates the comparative age of each cache entry.

Description

Increasing the value of the setting will exponentially increase the comparative age of objects over time. Possible values for the aging rate are from 0 (slowest aging) to 10 (fastest aging). The default setting is 9.

The comparative age of an object is one of several factors, including hit rate and priority, that together determine which objects are removed from the cache when space is needed for new objects. The aging rate setting controls how much relative weight is given to age versus these other factors when performing the calculation.

The BIG-IP system uses the following formula to calculate the comparative age of an object:

Comparative age = Age in minutes * 2 ^ Aging rate
