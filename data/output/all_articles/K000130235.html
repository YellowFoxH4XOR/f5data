Description

Does BIG-IP License manager supports managing license for BIG-IP CGN?


Environment

BIG-IP License Manager

Managing License for BIG-IP with CGNAT module

Cause

N/A

Recommended Actions

Beginning in BIG-IQ Centralized Management 5.1.0, you can assign, refresh, revoke, and reassign remote BIG-IP VE device licenses using the License Manager.



CGNAT is a module on BIG-IP and licensing tasks which we are doing on BIG-IPs are not module related. This means that whatever version of BIG-IP listed in K34133507: BIG-IQ Centralized Management compatibility matrix


under BIG-IQ Centralized Management 8.2.0


Device - Backup/Restore, Upgrade, Licensing, etc. is supported by BIG-IQ License Manager

None
