K11014: Joining a global server to the Active Directory domain or updating a domain computer account password will fail through a NAT

  • ARX: 5.0.5, 5.0.1, 5.0.0, 5.1.0, 5.0.6
Source

Topic

If a device between the ARX system and the Domain Controller performs a NAT on the request to join a global server to an Active Directory domain, or a request to update a domain computer account password, the request will fail with an error that appears similar to the following example:

:GUI-0-ERR-ADJOIN_PWCHANGE:: The domain-join operation failed because the account specified for this operation does not have keys generated for it. See documentation for more information.

To join a global server to an Active Directory domain, or update a domain computer account password, the request must not go through a NAT.
