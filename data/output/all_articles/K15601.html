Known Issue

Users may be unable to delete packet filter rules from the BIG-IP system.

This issue occurs when the following condition is met:

  • The packet filter rule has an order value greater than 32767.

Impact

Packet filtering does not function as expected.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The affected packet filter rule is removed from the configuration but still applies to traffic.
  • You notice error messages similar to the following example in the /var/log/tmm file:

    notice mcp error: 0x1030010 at ../mcp/db_packet_filter.c:279
    notice MCP message handling failed in 0x5bdb80 (16973840): Jan 31 09:22:25 - MCP Message:
    notice obj_delete {

Workaround

To work around this issue, you can restart the Traffic Management Microkernel (TMM) process. To do so, perform the following procedure:

Impact of workaround: Restarting the TMM process interrupts traffic processing on the BIG-IP system. You should perform this procedure during a maintenance window, or while the system is in standby mode.

Note: For VIPRION systems, you may need to restart the TMM process on each blade in the chassis.

  1. Log in to the BIG-IP command line.
  2. To restart the TMM process, type the following command:

    bigstart restart tmm
