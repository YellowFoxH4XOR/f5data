Known Issue

This is the result of a known issue. The BIG-IP ASM system incorrectly allocates memory for response URI buffers when inspecting HTTP 100 Continue traffic. This results in a memory leak and may cause the BIG-IP ASM system to stall while inspecting large amounts of HTTP 100 Continue traffic.

F5 Product Development is tracking this issue as CR123181.

This issue has been fixed in Hotfix-BIGIP-9.3.1-74.0-HF7, which has been issued for BIG-IP 9.3.1. You may download this hotfix or later versions of the cumulateive hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing F5 product hotfixes (9.x).
