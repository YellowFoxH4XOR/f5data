K50337347: The monitor template min was not found

Type
Support Solution
Published
2021-10-27
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP DNS: 16.1.X, 16.0.X, 16.1.3, 16.1.2, 16.1.1, 16.X.X, 16.0.1, 16.0.0, 16.1.0
Source
https://my.f5.com/manage/s/article/K50337347

Description
The configuration from GTM may not load from version 15.x to 16.x.
Will see either of the following errors on attempted configuration load:

01070022:3: The monitor template min was not found.
or
01070022:3: The monitor template require was not found.
 

Environment

  • GTM in version 15 upgraded to 16.x

Cause
The "min of" or "required" feature was applied to GTM generic-host in a server object.  This configuration option doesn't properly convert to version 16.
Bug ID 1030881: [GTM] Upgrade failure - 01070022:3: The monitor template min was not found.

Recommended Actions

  1. Boot back into 15
  2. Find the 'generic-host' server objects that have minimum up requirements (either directly in the webui or by examining the bigip_gtm.conf).
  3. In the Configuration Utility navigate to DNS  ››  GSLB : Servers : Server List and do the following for each Server in the list that has a Product of 'Generic Host'
    1.  Find the configuration item in the Advanced Configuration settings for Health Monitors of the Server
    2.  Either Remove all monitors or Change Availability Requirements to "All Health Monitors"
  4. In System  ››  Disk Management  ››  HD1 (reachable from System  ››  Software Management : Image List) delete the previous v16 volume where upgrade was attempted
  5. Reinstall v16 to a new volume (can be the one you just deleted)
  6. Boot back into 16, configuration should now load as expected.
  7. If needed, add back any removed monitors or changed requirements to the Configuration of each Server that was modified.

Additional Information
Example failing configuration when upgrading from 15.1.0 to 16.1.0:
Configuration in 15.1.0:

gtm server "/Common/Server - example" {
    datacenter /Common/DC-example
    devices {
        "Device - example" {
            addresses {
                192.168.0.5 { }
            }
        }
    }
    monitor min 1 of { /Common/gateway_icmp }
    product generic-host
}

upon booting into 16.1.0 results in:

Loading schema version: 15.1.0
  /config/bigip_gtm.conf
Loading schema version: 16.1.0
01070022:3: The monitor template min was not found.
Unexpected Error: Validating configuration process failed.

or Configuration in 15.1.0:

gtm server "/Common/Server - example" {
    datacenter /Common/DC-example
    devices {
        "Device - example" {
            addresses {
                192.168.0.5 { }
            }
        }
    }
    monitor require 1 from 1 { /Common/gateway_icmp }
    product generic-host
}

upon booting into 16.1.0 results in:

Loading schema version: 15.1.0
  /config/bigip_gtm.conf
Loading schema version: 16.1.0
01070022:3: The monitor template require was not found.
Unexpected Error: Validating configuration process failed.

Successful change of the monitoring in 15.1.0 looks like:

gtm server "/Common/Server - example" {
    datacenter /Common/DC-example
    devices {
        "Device - example" {
            addresses {
                192.168.0.5 { }
            }
        }
    }
    monitor /Common/gateway_icmp
    product generic-host
}
