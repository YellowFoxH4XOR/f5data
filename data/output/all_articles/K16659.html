Known Issue

Portal access sessions may become unresponsive.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • The BIG-IP APM portal access uses a rewrite profile.
  • The destination resources use session cookies that total a combined size that exceeds 32 KB.

Impact

The BIG-IP APM system temporarily becomes unresponsive.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users are temporarily unable to connect to portal access resources through the BIG-IP APM system.
  • You view log messages in the /var/log/rewrite file correlating to the time of the incident, similar to the following example:

    notice rewrite - RewritePlugin.cpp:2017 : 13876 attempt recovery from signal 6 while 24648 cores, jmp_level :1rewrite - RewritePlugin.cpp:2017 : 24648 attempt recovery from signal 6 while 0 cores, jmp_level :1
    notice rewrite - RewritePlugin.cpp:2047 : terminating due to signal 15
  • The BIG-IP system generates a rewrite core file to the /shared/core directory that appears similar to the following example:

    /shared/core/rewrite.0.bld2419.0.core.gz
  • When viewing BIG-IP APM CPU utilization at the time of the incident, CPU utilization is maximized.
