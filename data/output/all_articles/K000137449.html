K000137449: Updating components fail with error 'timeout of 60000ms exceeded'

Type
Support Solution
Published
2023-11-02
Updated
2023-11-02
Applies to
  • NGINX Products
  • NGINX Controller: 3.19.6-APIM, 3.19.5-APIM
Source
https://my.f5.com/manage/s/article/K000137449

Description

Making changes to a published API (from any environment) fails with the following error:

Error updating components for [published-api-name]
[published-api-name]-comp: Error: timeout of 60000ms exceeded

Updating an 'API Gateway' without any changes also fails the following error:

Error creating gateway [GW-NAME]: timeout of 60000ms exceeded

Environment

NGINX Controller - APIM

Cause

None

Recommended Actions

Reduce log level on declarative-ext-api pod:

kubectl patch cm $(kubectl get cm | grep declarative-ext-api | sed 's/ .*//') -p '{"data":{"LOG_LEVEL":"info"}}'
kubectl delete pod -l app=declarative-ext-api

If issue persists collect the following information and open a support case:

  • Start a HAR capture in the browser
  • Reproduce the issue
  • Wait for the 60000ms timeout message to appear
  • Refresh the GUI and verify whether the change is present both in the GUI object and in the related instances
  • Stop and save the HAR capture
  • Generate a new supportpkg
  • Provide supportpkg and HAR capture to the support case
