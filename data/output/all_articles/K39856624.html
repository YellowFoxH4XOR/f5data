Description

No analytics data is being displayed even though the TCP-Analytics profile is selected in the performance http virtual server configuration.

Environment

  • LTM and AVR 
  • Fast HTTP 
  • TCP Analytics

Cause

Fast HTTP Profile is not compatible with a TCP Analytics Profile. 
AVR does not receive any tcp analytics data when using the Fast HTTP profile (http performance).

Recommended Actions


If TCP analytics are required configure the affected virtual server with a different HTTP profile. Otherwise remove the TCP Analytics Profile from the virtual server configuration.
