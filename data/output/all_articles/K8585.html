K8585: Microsoft NetMeeting does not work properly through Network Access

Topic

If a user calls or hosts a Microsoft NetMeeting conference through a Network Access connection, various NetMeeting functions such as audio, video, and application sharing may not function properly. Additionally, a user may be unable to join or host a NetMeeting conference through a Network Access connection.

This behavior may occur when Microsoft Winsock2 is installed on the client system. NetMeeting uses the Winsock2 application programming interface (API) to enable quality of service (QoS) in NetMeeting. An interoperability issue exists between the Microsoft QoS Packet Scheduler and Point-to-Point Protocol (PPP) adapters. As a result, the FirePass Network Access client is affected by this issue because it uses a PPP adapter to communicate with the FirePass controller.

To determine whether a client system has Winsock2 installed, check for the following Windows registry key on the client system:

HKEY_LOCAL_MACHINE\System\CurrentControlSet\Services\Winsock2

If the registry key exists, the client system has Winsock2 installed.

Important: Many voice over IP (VoIP) applications are incompatible with network address translation. To support VoIP applications, including NetMeeting, you must configure FirePass to use a virtual subnet instead of Network Address Port Translation (NAPT). Using a virtual subnet requires routing changes on your network infrastructure; by default FirePass uses NAPT. For more information about configuring a virtual subnet, refer to the FirePass Controller Administrator Guide.

If you are running Windows XP, you can can resolve this issue by installing Windows XP Service Pack 3 (SP3). If you are running a different version of Windows, or if you do not want to install SP3, you can work around this issue by disabling Winsock2 in NetMeeting.

Note: For more information about Windows XP SP3, refer to http://www.microsoft.com/downloads/details.aspx?FamilyID=68c48dad-bc34-40be-8d85-6bb4f56f5110&displaylang=en.

To disable Winsock2 in NetMeeting version 3.01, open a registry editor tool and add the DisableWinsock2 DWORD value with a value data of 1 to the following registry key:

Important: If you make an error while editing the Windows registry, you can create severe issues that can be solved only by reinstalling the operating system. Use the registry editor with extreme caution.

HKEY_LOCAL_MACHINE\software\microsoft\conferencing\rrcm

To disable Winsock2 in NetMeeting version 2.1.x, open a registry editor tool and add the DisableWinsock2 DWORD value with a value data of 1 to the following registry key:

HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Internet Audio\NacObject\
