Issue

Error Message

% ERROR: SNAP_NO_STORAGE_CONTAINERS (44367909):
  Warning, could not determine any back-end storage containers (volumes) for this request. In order to successfully complete a snapshot request, at least one storage container must be present. Check Snapshot configuration.

Message Location

You may encounter this message in the following location:

  • The Snapshot Summary section of a snapshot report.

Description

This message occurs when the following condition is met:

  • A snapshot rule is invoked and there are no external-filers configured with the manage snapshots command.

The manage snapshots command indicates the external-filer supports managed snapshots. If there are no external-filers configured with the manage snapshots command option and a snapshot rule is run, the snapshot rule will fail.

Impact

The snapshot rule fails.

Recommended Actions

For external-filers that support snapshots, you can enable managed snapshots. To do so, perform the following procedure:

  1. Log in to the ARX CLI.
  2. Enter privileged mode by typing the following command:

    enable

  3. Enable global mode by typing the following command:

    global

  4. Enter the external-filer configuration mode for the desired external-filer using the following command syntax:

    external-filer <name>

  5. Enable managed snapshots for the external-filer using the following command:

    manage snapshots

  6. Exit the external-filer configuration mode by typing the following command:

    end
