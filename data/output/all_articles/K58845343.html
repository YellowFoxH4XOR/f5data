Description

GTM/DNS monitor log message, explaining the reason of monitor flap, may be truncated. Example being:

gtm.1:Dec  2 08:15:41 xyz alert gtmd[6146]: 011a4003:1: SNMP_TRAP: Pool /Common/abcdefghijklm123456 member /Common/12345 (ip:port=10.10.10.10:443) state change green --> red ( Monitor /Common/a-big-monitor-string-can-cause from 10.10.20.30 : connect: timeout search result false: disabled by pool (/Com)

Environment

  • DNS/GTM
  • Monitors

Cause
DNS/GTM monitors have a limit of 127 character under the WHY section. This is to ensure optimum memory consumption. If the size is increased, it may cause overload on the overall memory consumption.

The above error message truncates /Common to /Com.
There are various other messages which may be truncated under the WHY(between the parenthesis) section of the monitor.

Recommended Actions

None and It is functioning as designed.
