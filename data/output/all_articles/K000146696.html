K000146696: How can I check if new attack signatures are added to Distributed Cloud?

Source

What Happened?

There is a new CVE and the attack signatures have not been added to Distributed Cloud (XC).

Environment

  • F5®Distributed Cloud (SaaS)
  • F5 Distributed Cloud Console (XC Console)

Resolution

  • Check the Signatures Changelog to see if the specific attack signatures have been recently added.
  • Check the F5 Distributed Cloud Status Page for any recent or upcoming changes to Attack Signature updates

Additional Information

  • If the signature is absent, verify the CVE records on cve.mitre.org or cve.org. Similar attack pathways may exist (e.g., directory traversal, LFI, RFI).
  • The attack path may resemble that of other CVEs. For instance, a CVE might utilize attack paths like directory traversal, LFI, or RFI.
  • Signatures for these attack paths have already been integrated into Distributed Cloud.
  • There isn't a need to add a new signature in such cases. Distributed Cloud is equipped to handle these known attack paths effectively.
