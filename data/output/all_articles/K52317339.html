Description

  • The Content-Security-Policy (CSP) header sent by the BIG-IP Configuration Utility specifies both unsafe-inline and unsafe-eval.

Environment

  • BIG-IP GUI (Configuration Utility)

Cause

  • The Content Security Policy (CSP) is defined in the /config/httpd/conf/httpd.conf file
  • By default, the BIG-IP is configured to allow inline JavaScript and eval statements
  • The configuration of the CSP cannot be changed as inline JavaScript and eval statements are required for the Configuration Utility to function correctly

Recommended Actions

  • F5 recommends restricting access to the Configuration Utility and other administrative interfaces to a secure, trusted network as well as trusted users
  • F5 recommends performing administrative actions in a secure environment, at a minimum a dedicated browser and at best a secure jump-host
  • F5 does not recommend, or support, modifications to the system default Content-Security-Policy header

Additional Information

F5 does not consider that the system default Content-Security-Policy constitutes a vulnerability in the product due to the general architecture of the Configuration Utility and other measures in place to prevent and limit the possibility of web-based attacks against the Configuration Utility such as Cross Site Scripting (XSS). Following the security best practices outlined above for administering the BIG-IP will further eliminate risk of malicious scripts being injected by a third party and executed in the context of the administrator's browser.
