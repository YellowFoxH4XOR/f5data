Topic

Secure Web Gateway (SWG) for BIG-IP APM is licensed as a subscription for one or three years.

Description

During the active license period, the SWG subscription (Websense) URL and threat database are regularly updated to included changes in URL categories and to newly identified threats. When an SWG subscription expires, the subscription databases stops returning categories. 

Without access to the active subscription databases, access policies configured to interact with subscription database (including through the use of an iRule) may block requests. The logic behind this behavior is based on the security standpoint that using a stagnant URL and threat databases may allow access to uncategorized or miscategorized URLs and threats.
