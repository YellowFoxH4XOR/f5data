Known Issue

This is the result of a known issue. BIG-IP ASM occasionally logs the following error message to the recovery_manager.log file:

[ERR,2008-01-27 22:56:16 CST]1994,/ts/recovery/recovery_mngr.pl,main::repl_cmd_complete,,replication reported that slave is down!

This error message is not serious and is caused by a temporary race condition in which either the slave_io thread or the slave_sql thread is slow to respond.

Note: F5 is working to eliminate exclusionary language in our products and documentation. For more information, refer to K34150231: Exclusionary language in F5 products and documentation.

F5 Product Development tracked this issue as CR94533, and it was fixed in BIG-IP ASM 9.4.5. For information about upgrading, refer to the BIG-IP ASM release notes.
