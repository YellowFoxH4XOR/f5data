K000150302: Config load failure after relicense attempt

Type
Support Solution
Published
2025-03-08
Updated
2025-03-08
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000150302

Description

Configuration not able to load.

May see the following 

 "/usr/bin/tmsh -n -g -a load sys config partitions all " - failed. -- Syntax Error:(/defaults/config_base.conf at line: 1) "sh" unexpected argument 2025 Mar 8 21:15:16 example

Environment

  • LTM
  • after license re-activation

Cause

First line of /defaults/config_base.conf contains incorrect information (in the log message above, this first line contains 'sh example'

Recommended Actions

Delete incorrect first line of file /defaults/config_base.conf

Note: as this file resides on a read-only filesystem you will need to use the technique in used K20330103: Mounting the /usr file system in read-write mode --> to allow editing of the file.

Additional Information

None
