Description

DNS version or DNS hostname are being revealed

Environment

  • BIG-IP DNS
  • BIND

Cause

None

Recommended Actions

Add empty version and hostname options to the named.conf file 

Impact of procedure: BIND may momentarily stop responding to DNS requests during the restart, and then resume responding when the process successfully restarts.
  1. Navigate to Global Traffic > ZoneRunner > Named Configuration.
  2. Add the following lines to the options section:
    options {
    ...
    version "none";
    hostname "none";
    }
Important: Make sure there is a semi-colon (;) at the end of the definitions.

Note: See K6827 in Related Content for additional information and steps on how to make these changes from the command line.
