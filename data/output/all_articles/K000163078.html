K000163078: Big-IQ Backup schedule for Big-IP when it fails removes all devices in the list below the error

Type
Support Solution
Published
2026-08-25
Updated
2026-08-25
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K000163078

Description

BIG-IQ Backup Schedules incorrectly displayed number of managed devices as deleted after a scheduled UCS backup task. The affected devices remained managed by BIG-IQ.

Environment

  • BIG-IQ VE.
  • Scheduled UCS backups configured for multiple managed BIG-IP devices.
  • Some affected managed devices had been rebuilt or re-registered.

Cause

Bug ID 2447793

Answer/Recommended Actions

None.

The Backup Schedules page incorrectly reports existing managed devices as deleted. This can cause administrators to believe that the backup schedule is missing devices or to modify the schedule unnecessarily.

None
