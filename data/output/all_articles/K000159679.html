Source

Description

Unable to add a network in CIDR format to the Allowed Lists section of Bot Defense profiles in the Bot Defense XC module using the GUI. The GUI displays an "Invalid IP Address" error when saving a valid network entry, preventing exceptions for entire networks via the GUI.

Environment

  • BIG-IP Distributed Cloud Services (XC)
  • Product: BIG-IP ASM
  • Version: 17.5.1
  • Bot Defense XC module

Cause

Input validation bug or limitation in the Bot Defense XC GUI prevents acceptance of valid CIDR-formatted networks.

Recommended Actions

  • Use the CLI to add networks to the Allowed Lists section:
    modify saas bd profile <Profile_name> allow-ip-addresses add {<network>/<mask>}
  • Replace <Profile_name> with the target profile name and <network>/<mask> with the desired CIDR entry.
  • Ensure the network is specified in standard CIDR notation (e.g., 10.0.0.0/8/).
  • If the GUI continues to reject valid input, verify the exact network/mask and method used, and collect any error messages for further analysis.
  • Escalate the issue to the product team for future GUI correction.
