Topic

FirePass and the BIG-IP APM system provide endpoint inspection of registry settings for Windows clients. Currently, FirePass and the BIG-IP APM system do not provide direct support for Windows 64-bit operating systems. The Windows Registry checker endpoint inspector is a 32-bit component, and it is capable of checking only 32-bit registry keys.

Windows has separate storage for registry keys used by 32-bit and 64-bit application, and automatically redirects 32-bit applications to a 32-bit registry branch Wow6432Node inside the 64-bit registry hive. Accessing 32-bit registry keys on a 64-bit operating system uses the Windows registry redirector.

Note: Supported keys are specified in the following Microsoft article. The following link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge: http://msdn.microsoft.com/en-us/library/aa384253(VS.85).aspx

Note: For more information about the Microsoft registry redirector, refer to the following article. The following link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge: http://msdn.microsoft.com/en-us/library/aa384232(VS.85).aspx

The feature to allow the FirePass and BIG-IP APM systems to test against the Windows 64-bit OS registry hive is included in BIG-IP APM 10.2.1 and FirePass 7.0.0. For information about upgrading, refer to the FirePass release notes.

This issue has been fixed in cumulative hotfix HF-610-4, which has been issued for FirePass 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
