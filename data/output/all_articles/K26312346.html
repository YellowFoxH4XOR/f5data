Topic

You should consider using this procedure under the following condition:

  • You want to use a local traffic policy to redirect all incoming HTTP virtual server requests to the HTTPS virtual server configured for the same DNS host name or IP address.

An alternative method that F5 recommends for redirecting HTTP requests to HTTPS is to use an iRule. Using an iRule to redirect from HTTP to HTTPS also provides additional flexibility such as an HTTPS virtual server on a non-standard port or an IPv6 HTTPS virtual server. For information about using an iRule to redirect HTTP requests to HTTPS, refer to K10090418: Configuring an HTTP virtual server to redirect to HTTPS using an iRule.

Description

To configure the BIG-IP local traffic policy to redirect HTTP requests to HTTPS for a virtual server on the BIG-IP system, you must first configure a local traffic policy that contains at minimum a rule that detects incoming HTTP requests and redirects it to an HTTPS virtual server.

You must then associate the local traffic policy to the appropriate HTTP virtual server. You can perform this configuration using either the Configuration utility or the TMOS Shell (tmsh). Certain policy actions support Tool Command Language (Tcl) command substitutions, providing flexibility in configuring policies.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to the Configuration utility or tmsh.
  • You have an existing HTTP and HTTPS virtual server using the same virtual address on your BIG-IP system.
  • You want to redirect all incoming HTTP virtual server requests to the HTTPS virtual server configured for the same DNS host name or IP address.

Procedures

  • Use the Configuration utility to configure a local traffic policy to redirect HTTP requests to the HTTPS virtual server
  • Use tmsh to configure a local traffic policy to redirect HTTP requests to the HTTPS virtual server

Use the Configuration utility to configure a local traffic policy to redirect HTTP requests to the HTTPS virtual server

To use the Configuration utility to configure a local traffic policy to redirect HTTP requests to an HTTPS virtual server, perform one of the following procedures for your BIG-IP system:

To watch a video demo of this procedure, go to  Redirect HTTP requests to HTTPS with a local traffic policy using the Configuration utility.

Impact of procedure: The system responds to any requests to the HTTP virtual server with an HTTP redirect to the HTTPS virtual server. The impact of the procedure depends on the specific environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Policies > Policy List.
  3. Select Create.
  4. Enter a Policy Name.

    For example:

    myHTTPtoHTTPSpolicy

  5. For Strategy, select the appropriate option for your application environment.

    If you are performing this procedure to only redirect HTTP requests to HTTPS, you can use the default setting, Execute first matching rule.

  6. Select Create Policy.
  7. Under Rules, select Create.
  8. Enter a rule name Name.

    For example:

    myHTTPtoHTTPSrule

  9. For Match all of the following conditions, leave the default setting, All traffic.
  10. For Do the following when the traffic is matched, select + to expand the options.
  11. In the first list, select Redirect.
  12. For to location, enter the following tcl command:

    tcl:https://[getfield [HTTP::host] ":" 1][HTTP::uri]

    Note: The [getfield [HTTP::host] ":" 1] function extracts the host name from the host header. If you specify a non-standard port, it removes the port from the host header.

  13. For at, select request instead of the default http proxy request.

    If you require the policy to be triggered at http proxy request event, an explicit http profile is required.

  14. Select Save
  15. To save the new rule and policy, under General Properties, select Save Draft.

    To save the rule and policy for immediate use, select Save and Publish Policy.

  16. Go to Local Traffic > Virtual Servers > Virtual Server List.
  17. In the Resources column for the HTTP virtual server that you want to redirect HTTP requests, select Edit.
  18. Under Policies, select Manage.
  19. For Available, select the local traffic policy you created in previous steps and move it to Enabled.
  20. Select Finished.

Use tmsh to configure a local traffic policy to redirect HTTP requests to HTTPS for a virtual server

To use tmsh to configure a local traffic policy to redirect HTTP requests to HTTPS for a virtual server, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Create a local traffic policy to redirect HTTP requests to HTTPS using the following command syntax:

    • create /ltm policy /Common/Drafts/<policy name> controls add { forwarding } requires add { http } strategy first-match rules add { <rule name> { actions add { 0 { http-reply redirect location "tcl:https://[getfield [HTTP::host] \":\" 1][HTTP::uri]" } } } }

      For example, to create a local traffic policy with the myHTTPtoHTTPSpolicy policy name and myHTTPtoHTTPSrule rule name, enter the following command:

      create /ltm policy /Common/Drafts/myHTTPtoHTTPSpolicy controls add { forwarding } requires add { http } strategy first-match rules add { myHTTPtoHTTPSrule { actions add { 0 { http-reply redirect location "tcl:https://[getfield [HTTP::host] \":\" 1][HTTP::uri]" } } } }

    • Publish the created policy by using the following syntax:

      publish ltm policy Drafts/<policy_name>

      For example:

      publish ltm policy Drafts/myHTTPtoHTTPSpolicy

    • Associate the local traffic policy with the HTTP virtual server that you want to redirect HTTP requests using the following command syntax:

      modify /ltm virtual <virtual server name> policies add { <policy name> }

      For example, to associate the myHTTPtoHTTPSpolicy local traffic policy you created in step 2 with the myHTTPvs HTTP virtual server, enter the following command:

      modify /ltm virtual myHTTPvs policies add { myHTTPtoHTTPSpolicy }

    • Save the change by entering the following command:

      save /sys config
