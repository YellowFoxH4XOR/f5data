Description

There is a leading Dot "." added before Domain Name attribute in Cookie which might be flagged as a vulnerability or misinterpreted as to include the subdomain is allowed

Environment

  •  BIG IP ASM

Cause

Even with specific hostname defined in the ASM policy settings, ASM still adds a leading dot to the Domain attribute of its cookies.

This is the default behavior of ASM when setting the Domain attribute explicitly and is not controlled by the GUI option “Include Subdomains.”

This behavior is part of ASM's internal cookie logic.

ASM takes a conservative approach that ensures compatibility with older specifications like RFC 2109 and RFC 2965, while still remaining compliant with the current standard, RFC 6265. These older specifications required or assumed the presence of a leading dot when a Domain is explicitly defined. By including it, ASM ensures interoperability with legacy clients and intermediaries that may still expect this format.

The presence of the leading dot should not be considered a security vulnerability — it is compliant with current RFC standards.
