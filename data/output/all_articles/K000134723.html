K000134723: ASM signatures are not updating on one guest in HA pair

Type
Support Solution
Published
2023-05-22
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP ASM: 13.1.4
Source
https://my.f5.com/manage/s/article/K000134723

Description

In a vCMP host with old service check, there are guests that successfully update signatures, while there are others that do not update correctly. Logs like next are likely to be found in /var/log/ts/asm_config_server


asm_config_server 2022-03-02 03:51:04.255 -05:00 Critical asm_config_server.pl[14633] F5::Sigfile::Update::store_error_and_die,,Service contract cannot be verified (Cannot handle state FAULT_RETURNED). Please re-license your installation of Big-IP manually.



Environment

  • Host with old License Service Check
  • vCMP Guest with same Service Check, version older than 14.1.0, failing to update signatures older
  • vCMP in the same host, version 14.1.0 or later, successfully updating signatures



Cause

Prior to 14.1.x, Attack Signature Update required a license with Service Check Date within the last 18 months.


This is all covered by "K8217: Managing BIG-IP ASM attack signatures (11.5.x - 14.0.x)"


License validation was removed in 14.1.0 for ID709500 .



Recommended Actions

Two options:

  • Update license
  • Move to version 14.1.0 or later those failing guests
