Known Issue

Upgrades can fail when you configure the BIG-IP system to use an external Hardware Security Module (HSM).

This issue occurs when all of the following conditions are met:

  • You have a BIG-IP system that is configured to use an external HSM.
  • You upgrade to a software version between 11.5.0 and 11.5.1, or 11.6.0.

    Note: This issue does not affect BIG-IP 11.5.2, which was released after 11.5.0, 11.5.1, and 11.6.0.

Impact

BIG-IP GTM is unable to answer client Domain Name System (DNS) requests.

BIG-IP LTM is unable to process Secure Sockets Layer (SSL) traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system is not processing DNS or SSL traffic.
  • The configuration fails to load, and in the /var/log/ltm file, you observe an error message similar to the following example:

    err mcpd[7472]: 010713e4:3: FIPS subsystem reported error while attempting file object operation: Identical key already exists in FIPS card with handle (10). Cannot import duplicate key (A234i557806T2356BB11886BKDF61AA).
    err mcpd[7472]: 010712d8:3: DNSSEC Key Generation 1 of key /Common/ksk10 failed import.
    err tmsh[19485]: 01420006:3: Loading configuration process failed.
