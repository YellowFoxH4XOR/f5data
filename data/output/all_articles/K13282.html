Topic

Windows 7 and Windows 10 users are prompted to install the Network Access Helper application whenever they start a Network Access tunnel. This occurs when the user does not have administrator rights on the computer and User Account Control is enabled.

Description

Users who are affected by this issue see messages similar to the following in the logterminal.txt or f5Report file:

DIALER, 1, \PatchHostsHelperRPCClient.cpp, 391, CPatchHostsHelperRPC::Connect, EXCEPTION - Error waiting for elevation helper (result: 258)
DIALER, 1, \PatchHostsHelperRPCClient.cpp, 402, CPatchHostsHelperRPC::Connect, EXCEPTION caught: CPatchHostsHelperRPC::Connect() - EXCEPTION
DIALER, 2, \UFilterService.cpp, 178, UFilterService::Connect(), Failure connecting to F5 DNS Relay Proxy service. Service is not installed or is not running.

To prevent this prompt you can perform one of the following actions:

  • Turn off UAC on the Windows PC.
  • Install the DNS Relay Proxy Service.

    Note: The DNS Relay Proxy component requires Windows administrator privileges for installation. After the service is installed, the DNS Relay Proxy service runs for users with limited Windows privileges.

  • If you encounter this behavior even when administrative (or Administrator) rights are granted, you can work around this issue by creating a Microsoft ACT Shim on the device.

    For more information about Microsoft ACT and creating an application Shim, see the following Microsoft articles:

    • Application Compatibility Toolkit (ACT) Technical Reference
    • Understanding Shims
