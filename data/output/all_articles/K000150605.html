Description

Dynamic DNS updates are used to register client network adapter IP addresses after establishing Network Access but the VPN client's local adapter IP(s) that should not be registered are registered.

Environment

  • APM
  • Network Access Resource configured with "Register this connection's addresses in DNS" and configured to discard non-PPP adapter registration
  • Edge Client for Windows or F5 VPN for Windows

Cause

Windows clients query DNS for the SOA record of the zone associated with their connection’s DNS suffix. The name server returned in an SOA record is used by clients for Dynamic DNS updates.

If the IP address in the SOA record does not match the DNS server configured in the Network Access Resource, the  DNS Relay Proxy Service will not filter the registration requests. The service will only filter registration requests sent to the configured DNS server in the Network Access Resource.

Recommended Actions

In order to work around this behavior, add a DNS server in the Network Access Resource to match the SOA record received by the client.

Additional Information

There is an open Request For Enhancement to improve the ability of the DNS Relay Proxy service to filter registration requests. ID1326789.
