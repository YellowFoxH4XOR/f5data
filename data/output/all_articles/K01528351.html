Description
This article provides the SNMP OID for checking the BIG-IP's network interface status.

Environment

  • BIG-IP LTM
  • SNMP

Cause
None

Recommended Actions

  1. On bash shell of the BIG-IP unit, run the following to obtain the OID string: 

    For example: 
          # snmpwalk -v 2c -c public localhost f5|grep -i interfacestatus
          F5-BIGIP-SYSTEM-MIB::sysInterfaceStatus."1.1" = INTEGER: up(0)
          F5-BIGIP-SYSTEM-MIB::sysInterfaceStatus."1.2" = INTEGER: up(0)
          F5-BIGIP-SYSTEM-MIB::sysInterfaceStatus."1.3" = INTEGER: up(0)
          F5-BIGIP-SYSTEM-MIB::sysInterfaceStatus."1.4" = INTEGER: up(0)
          F5-BIGIP-SYSTEM-MIB::sysInterfaceStatus."1.5" = INTEGER: up(0)
          F5-BIGIP-SYSTEM-MIB::sysInterfaceStatus."1.6" = INTEGER: up(0)
          F5-BIGIP-SYSTEM-MIB::sysInterfaceStatus."mgmt" = INTEGER: up(0)
     
  2. Get the numeric OID of the above 

    For example: 
        # snmptranslate -On F5-BIGIP-SYSTEM-MIB::sysInterfaceStatus."1.1"
          .1.3.6.1.4.1.3375.2.1.2.4.1.2.1.17.1.1
