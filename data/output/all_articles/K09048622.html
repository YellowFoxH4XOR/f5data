Description

BIG-IP appears to be sending and receiving jumbo frames
  • Packet capture shows jumbo frames
  • Jumbo frames are not actually sent on the network

Environment

  • BIG-IP
  • Packet Capture

Cause

TCP Segmentation Offload (TSO) and Large Receive Offload (LRO) moves some packet segmentation and re-assembly out of the linux kernel to the hardware. Libpcap collects data between the kernel and the hardware, so it captures jumbo frames sent from the linux kernel to the hardware, rather than the smaller packets transmitted by the hardware on to the network. 

Recommended Actions

TSO and LRO can be disabled for segment size troubleshooting, but you should generally leave them enabled for better performance. For information, refer to K15609: Overview of TCP Segmentation Offload and Large Receive Offload.
