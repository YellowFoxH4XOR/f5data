Description

VELOS tenant shows sys fpga firmware-config type l7-performance-fpga on one or more of the slots after reboot. It originally had type standard-balanced-fpga.

Environment

VELOS tenant

Cause

This is one of symptoms of ID 1102425.

Recommended Actions

If secondary slots are operative unlike ID 1102425 describes, the state of having the type l7-performance-fpga is cosmetic. F5OS tenants do not support different FPGA firmware, nor does the VELOS hardware.

However, if you are concerned about meeting the condition of ID 1102425, consider upgrading to the version with the fix of the bug.

Additional Information

You may either see mismatched fpga firmware-config types between slots or all slots having type l7-performance-fpga depending on whether slot failover have been triggered when you run clsh tmsh list sys fpga. The slot that becomes secondary will get the type l7-performance-fpga due the the known issue.

# clsh tmsh list sys fpga
=== slot 2 addr 127.3.0.2 color green ===
sys fpga firmware-config {
    type l7-performance-fpga
}
...snip...
=== slot 1 addr 127.3.0.1 color green ===
sys fpga firmware-config {
    type standard-balanced-fpga
}
