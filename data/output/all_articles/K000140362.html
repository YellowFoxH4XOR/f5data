Known Issue

The F5OS webUI fails to upload QKView files to iHealth.

This issue occurs when the following condition is met:

  • You attempt to upload QKView files from the F5OS webUI directly with the qkview upload feature.

Impact

The QKView file upload process fails with errors.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • An error message similar to the following example appears in the /var/log/messages file and the F5OS webUI:

    x509: certificate signed by unknown authority

Workaround

To work around this issue, you can download the generated QKView file and upload it to iHealth manually. To do so, perform the following procedures:

Impact of workaround: Performing the following procedures should not have a negative impact on your system.

  • Download a QKView file from the F5OS webUI
  • Upload a QKView file to F5 iHealth

Download a QKView file from the F5OS webUI

  1. Log in to the F5OS webUI.
  2. Go to SYSTEM SETTINGS > File Utilities.
  3. For Base Directory, select diags/shared.
  4. Select qkview.
  5. Select the QKView file you want to download.
  6. Select Download.

Upload a QKView file to F5 iHealth

  1. Open a web browser and log in to the F5 iHealth site.
  2. Select Upload.
  3. Select Choose.
  4. Go to the QKView file on your local system.

Note: As an alternative to using F5 iHealth, you can also provide the QKView file to F5 Support. To do so, refer to K000090853: Exchange files with F5 Support using MyF5.
