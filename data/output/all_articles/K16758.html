Known Issue

Long-lived iControl representational state transfer (REST) requests may time out and fail to complete.

This issue occurs when the following conditions are met:

  • Your BIG-IP system experiences heavy resource utilization.
  • You use the iControl REST interface to make a request, such as saving a large system configuration or creating a large user configuration set (UCS).

Impact

iControl REST requests fail to complete.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • iControl REST requests time out or fail to complete.

Workaround

To work around this issue, you can run long-lived iControl REST requests in a batch mode transaction.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
