Description

When deploying an Application Template to a BIG-IP Next instance via Central Manager, an error occurs:

FAST-0002: Internal Server Error: Failed to create application <app> on BIG-IP Next instance: Failed to submit declaration to AS3: At least one L3-network object must be configured before applying a declaration.

Environment

  • Central Manager

  • Deploying a new application template to a BIG-IP Next tenant running on VELOS

Cause

Running BIG-IP Next Central Manager 20.0.2. This is tracked as ID 1493005.

Recommended Actions

Upgrade BIG-IP Next Central Manager to 20.2.0 or higher.

Additional Information

FAST-0002 is a generic error code for an internal server error. Ensure the error string matches this error string before considering this as a workaround.
