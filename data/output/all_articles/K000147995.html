Description

I am receiving continuous alerts notifications and only want active alerts notifications.

 

Environment

  • F5®Distributed Cloud
  • F5 Distributed Cloud Console (XC Console)
  • F5®Distributed Cloud (SaaS)

 

Cause

Alert notification intervals are set to 4 hours by default.

 

Answer/Recommended Actions

To configure alerts frequency:

1. In Alert Policies edit the Policy Rules and toggle on Show Advanced Fields

2. Configure the Policy Rule Notification Parameters

  • You can modify the Notification Interval For a Alert by specifying the time in seconds, minutes, hours, or days
  • Inhibiting alerts can be configured under Wait to Notify
  • Specific group interval can be configured under Notify Interval for a Group
