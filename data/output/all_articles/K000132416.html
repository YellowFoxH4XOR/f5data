Description

  • Unable to deploy AS3 template via ansible to BIG-IP with BIG-IQ
  • Unable to delete BIG-IP tenant from BIG-IQ

Environment

  • BIG-IQ CM
  • AS3
  • BIG-IP VE provisioned with ASM and other modules (LTM, AVR. AFM) with 8GB of memory or less

Cause

As per K40257355 "To avoid capacity issues in BIG-IP 12.x and later, you should provision the BIG-IP ASM module on systems with 8GB or more of memory. On systems with 8 GB of memory, you should provision BIG-IP ASM as Dedicated in order to allocate the maximum available memory for BIG-IP ASM. For BIG-IP VE and vCMP guests, you should allocate 8GB or more or memory to the BIG-IP instance before provisioning BIG-IP ASM."

Recommended Actions

For BIG-IP VEs, the recommended path is to add more memory to the VMs (at least 12 GB).
