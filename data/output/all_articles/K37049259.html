Known Issue

The assigned link on the BIG-IP LTM Virtual Server Properties page may incorrectly report none for the link name.

This issue occurs when the following condition is met:

  • You have the right configuration of self IP addresses, BIG-IP GTM servers, BIG-IP GTM links, and BIG-IP LTM virtual servers.

Impact

The system displays incorrect information for the virtual server's link.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you navigate to LTM > Virtual Servers > Properties, the Link value sometimes displays none when it should display an actual link name.

Resolution

Status
