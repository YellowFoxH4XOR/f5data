K000139462: Central Manager K3S fails to start with Node and Pods unavailable

Description

Central Manager fails to start k3s after an IP change is introduced via DHCP or cloud-init to a previously configured instance. IP changes to a node will disrupt the K3S service on that node and when participating in an CM-HA cluster, will break the cluster configuration for that node.

Environment

Relevant environmental factors specific to the topic

  • BIG-IP Next Central Manager
  • DHCP is used to configure the Management Network
  • DHCP later assigns different IP than what was originally used during installation

Cause

Kubernetes (K3S) is unable to handle a dynamic updates to its node IP address. This also affects CM-HA clusters as there are currently no mechanisms available to notify other nodes in the cluster of the modified node IP.

Recommended Action

If possible, reconfigure the DHCP server or cloud-init configuration to provide the IP address originally assigned to the CM instance and reboot.
