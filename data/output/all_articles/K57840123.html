Description
BIG-IP system uses components from multiple CentOS versions and the base host operating system version can be manually determined from the command line.

Environment

  • BIG-IP
  • CLI access
  • Base operating system

Cause
None

Recommended Actions

  1. Log in to BIG-IP CLI
  2. If logged in TMOS mode, enter bash mode by typing the below command. 
    #bash
     
  3. Enter any of the below commands to get the base OS version. 
    #cat /etc/redhat-release
    #cat /etc/centos-release
    #less /etc/os-release

    Example: 
    root@LTM1.example.com:Active:Standalone] config#cat /etc/redhat-release
    CentOS Linux release 7.3.1611 (Core)

Additional Information
Based on the BIG-IP version, the base operating system may vary. Please refer to K3645: Base operating system information for the BIG-IP host system
For the latest versions of CentOS, please refer to www.centos.org/centos-linux/
