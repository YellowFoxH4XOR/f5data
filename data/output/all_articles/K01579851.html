Issue

Error Message

012b2003:5: Unknown message type 191 from ::ffff:<ip>:<port>

In this error message, note the following:

  • <ip>:<port> is the IP address and port of the device monitored by BIG-IP DNS (formerly known as BIG-IP GTM) using iQuery

For example:

012b2003:5: Unknown message type 191 from ::ffff:171.206.100.7:4566

Message Location

You may encounter this message in the following location:

  • The /var/log/gtm file

Description

This message occurs when the following condition is met:

  • The monitored device's big3d version is not compatible with the BIG-IP DNS system's big3d version.

Monitored BIG-IP systems must run the same or later big3d version as the BIG-IP DNS system.

Impact

This error message indicates that ongoing communication issues exist between BIG-IP DNS and the device it is attempting to monitor.

Recommended Actions

Upgrade the big3d version on the monitored device.
