Known Issue

This is the result of a known issue. The BIG-IP Dashboard utility does not correctly display the current Secure Sockets Layer (SSL) transactions per second (TPS) under the SSL TPS tab in the Connections panel. The SSL TPS tab will always display SSL TPS as 0 (zero), regardless of whether the BIG-IP system processes SSL traffic.

F5 Product Development tracked this issue as ID 225370 and ID 328770 (formerly CR139208), and it was fixed in BIG-IP 10.2.4 and 11.0.0. For information about upgrading, refer to BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Workaround

You can work around this issue by using the SSL Transactions graph in the Performance Graphs utility to monitor SSL TPS on the BIG-IP system. The SSL Transactions graph is located under the Overview > Performance > All page in the Configuration utility. Alternatively, you can monitor SSL TPS using SNMP.

Note: For more information about using SNMP, refer to K6644: Using SNMP to collect SSL transactions per second data.
