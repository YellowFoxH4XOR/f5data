K6119: BIG-IP LTM allows only one cipher option for client SSL negotiation

Known Issue

The BIG-IP LTM system may truncate cipher options that should be presented when negotiating a client SSL connection, resulting in only one available cipher. If the client does not support the listed cipher, the connection will fail.

F5 Product Development tracked this issue as CR50926, CR50940, and CR54994, and it was fixed in BIG-IP LTM 9.1.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.
