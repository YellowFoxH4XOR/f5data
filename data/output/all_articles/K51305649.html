Known Issue

The Virtual Server Discovery feature may not detect new BIG-IP virtual servers.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP DNS system has already discovered the existing virtual servers of a BIG-IP device.
  • You add a new virtual server to the BIG-IP device that shares the same IP address and port of an existing virtual server residing in an alternate Virtual Local Area Network (VLAN).

Impact

The Virtual Server Discovery feature fails to detect new virtual servers.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The newly created virtual server is not available for use on the BIG-IP DNS systems.
  • When you remove the existing BIG-IP DNS virtual server, the Virtual Server Discovery feature detects the BIG-IP virtual servers correctly.

Workaround

To work around this issue, you can remove the existing matching IP address and port virtual server from the BIG-IP DNS configuration and then allow the Virtual Server Discovery feature to detect the BIG-IP virtual servers.

Impact of workaround: The deleted virtual server will not be available for the BIG-IP DNS configuration to use until the Virtual Server Discovery feature has re-discovered it.

Alternatively, you can manually add the new virtual server to the BIG-IP DNS configuration. To add a new virtual server to an existing BIG-IP DNS server, perform the following procedure.

Creating a BIG-IP DNS virtual server

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Ensure that the existing BIG-IP DNS virtual server name exactly matches the configured virtual server name of the BIG-IP system.
  2. Log in to the Configuration utility.
  3. Navigate to DNS > GSLB > Servers > Server List.
  4. Click the name of the affected BIG-IP LTM server.
  5. Click Virtual Servers.
  6. Click Add.
  7. In the Name box, type a name for the virtual server.

    Note: Verify that the name matches the name used by the BIG-IP LTM configuration.
  8. In the Address box, type the IP address of the virtual server.
  9. In the Service Port box, type the configured port of the virtual server.
  10. Click Create.

    Note: When you have defined BIG-IP LTM as a BIG-IP DNS server object with an associated BIG-IP health monitor, you do not need to select a health monitor for the virtual server.
