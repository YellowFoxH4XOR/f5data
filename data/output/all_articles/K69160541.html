Description

BIG-IP does not allow RTSP traffic with video content between STB (Set-top box) and Server.

  • HTTP phase of RTSP traffic is established correctly
  • TCP 554 traffic shows up on BIG-IP but BIG-IP does not respond (confirmed via packet capture)
  • STB can not load video from RSTP Server

Environment

  • BIG-IP LTM

Cause

BIG-IP does not respond on the traffic which is not destined to any of Virtual Server listeners.

Recommended Actions

RTSP architecture has following prerequisities, both must be met to allow RTSP traffic correctly.

  1. Virtual Server for HTTP traffic only
  2. RSTP tcp 554 can not face BIG-IP inline
For more information check below URL  .pdf file: page 2 Figure 2 as traffic flow diagram reference.

RTSP: One of the Foundations of Convergence

Additional Information

RTSP session is made up with 2 phases:

1. HTTP GET port 80 from client (STB) to RTSP Server
2. TCP dst port 554 from client (STB) to RTSP Server for registration and content download start

  • Standard Virtual Server with tcp profile
  • SNAT enabled
  • Virtual server listen on all ports with the wildcard .*
