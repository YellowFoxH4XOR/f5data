Description

You encountered a permission error when creating a UCS file via BIG-IP GUI or performing 'tmsh save sys ucs' command on the console.

Environment

  • BIG-IP
  • You can see symbolic link failure events in /var/log/user.log and/or /var/log/liveinstall.log
    error: tm_install::VolumeSet::VolumeSet_prep_root -- symlink failed; /mnt/tm_install/16112.1xXHGS/var/tmp to ../shared/tmp : File exists 
  • When generating the UCS, you encountered the error below: 
    Saving active configuration...
sh: /var/tmp/cs_save_pre_script: Permission denied
Error executing 'pre-save' configsync script /var/tmp/cs_save_pre_script.
/var/tmp/filestore_temp: Directory does not exist
sh: /var/tmp/cs_save_post_script: Permission denied
Error executing 'post-save' configsync script /var/tmp/cs_save_post_script.

WARNING:There are error(s) during saving.
        Not everything was saved.
        Be very careful when using this saved file!

Error creating package
Error during config save.
Unexpected Error: UCS saving process failed.

Cause

There are previous changes made on the folder permissions or you've accidentally deleted or recreated /var/tmp directory

Recommended Actions

  1. Check if there's an existing /var/tmp folder
    # ls -la /var/tmp

    If there is, remove the existing /var/tmp directory
    # rm -rf /var/tmp
     
  2. Create a symbolic link between /shared/tmp and /var/tmp
    # ln -s /shared/tmp /var
     
  3. You should now be able to create a UCS backup
