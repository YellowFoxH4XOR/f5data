Known Issue

The BIG-IP system may display an erroneous chassis fan status on some platforms when the fan speeds are within normal operating range.

This issue occurs when one of the following conditions is met:

  • You use the tmsh show sys hardware command to display the fan status.
  • You use the bigpipe platform command to display the fan status.
  • You query the BIG-IP system fan status using Simple Network Management Protocol (SNMP).

Impact

The BIG-IP system may report an erroneous chassis fan status.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H530765 on the Diagnostics > Identified > Low screen.
  • The tmsh show sys hardware command output may display the chassis fan status as 3 instead of up.

    For example:

    Chassis Fan Status
      Index  Status  Fan Speed(rpm)
      1      3       2904
      2      3       2900
      3      3       2893
      4      3       2903
  • In BIG-IP 10.2.4, the bigpipe platform command output may display an error for the chassis fan status.

    For example:

    +-> CHASSIS FAN
        |   |     (1) error - 9121rpm   (2) error - 9926rpm
        |   |     (3) error - 9642rpm
     
  • An SNMP query of the OID sysChassisFanStatus may return with a status of 3 instead of good(1):

    For example:

    F5-BIGIP-SYSTEM-MIB::sysChassisFanStatus.1 = INTEGER: 3

Resolution

Workaround

To work around this issue for BIG-IP 10.2.4, you can use the tmsh show sys hardware command to display the fan status. You can treat a status of 3 (initializing) in the tmsh show sys hardware command output as up if the reported fan speed is within normal operating range; the system will report a separate error if the chassis fan speed falls outside of normal operating range. Additionally, you can treat a status of 3 (initializing) as good(1) using SNMP if the reported fan speed is within normal operating range.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
