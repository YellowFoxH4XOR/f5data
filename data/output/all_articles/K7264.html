Known Issue

This is the result of a known issue. The BIG-IP system reports the following FIPS initialization error message to the console during boot up:

.Cfm1F5Util error (line 1245): Library Initialization : 0x13 : 
Undefined Error Code \n Can't login to the FIPS card.  
You may have to reinitialize it. 
To reinitialize the card, login as root and run: 
  fipsutil -f init 
and select a new SO pin. 
This will delete any keys you have stored in the card.

This error message reports that the FIPS driver was not initialized properly before the system attempted to access the FIPS driver. As a result, any Secure Socket Layer (SSL) profile that requires access to the FIPS card will not function, and the FIPS card will not handle any SSL traffic.

F5 Product Development tracked this issue as CR74892 and it was fixed in BIG-IP LTM 9.3 and 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
