Topic

When a master group is created and configured for client certificate authentication, up to three authentication options can be configured.

Initially, the Authentication tab on the Users: Groups: Master Groups page will display a single option:

Automatically log-in when client certificate is present

You must select this check box to perform passwordless authentication with a client certificate. Passwordless authentication enables a user with a valid client certificate to be automatically logged in to the FirePass controller when the user's browser loads the FirePass logon page. The user is only required to select the client certificate used by the browser. No additional user input or action is required.

Additionally, the following text is displayed:

You must enable the Request client certificate during logon setting before you can use client certificate authentication. Click on the link below to install client root certificates and configure global settings.

To enable the Request client certificate during logon setting, and install a client root certificate, click the Client Root Certificates and Settings link, which displays the Device Management: Security: Certificates page. On this page you can install your client root certificate, create a self-signed client root certificate (if a client root certificate is not already installed), or if you need to, install additional client root certificates.

Note: For more information about installing a client root certificate from a third-party certificate authority, consult the online help for the Device Management: Security: Certificates page, or the Installing and configuring client root certificates section of the Using Server Certificates chapter in the FirePass Controller Administrator Guide.

Note: For more information about creating self-signed client root certificates, refer to K7478: Creating and requiring self-signed client certificates.

Once you have installed the client root certificates and applied the configuration changes, select the Request client certificate during logon check box, and use the drop-down menu to select the field of the certificate you want to use to populate the logon (Username) field of the FirePass logon page.

Note: For more information about configuring this drop-down menu, refer to the Setting up client-certificate-based authentication section of the Managing Users and Configuring Groups chapter in the FirePass Controller Administrator Guide. Return to the Authentication tab for your master group, on the Users: Groups: Master Groups page.

Two new options should now appear on the Authentication tab of the Users: Groups: Master Groups page:


  • Required client certificate issuer

    This drop-down menu allows you to accept client certificates issued by Any issuer  (i.e. all client root certificates installed on the Device Management: Security: Certificates page) or to accept only client certificates which have been issued by a specific client root certificate. For configurations with a self-signed certificate, the Common Name field of the self-signed certificate will be one option in the drop-down menu. The Common Name is typically the fully qualified domain name (FQDN) of the FirePass controller.
  • Perform additional client certificate check using

    This drop-down menu allows you to perform an additional authentication using either an LDAP or Active Directory server, using the credentials contained in the certificate.

If the previous two new options do not appear, you have not selected a field of the certificate to populate the logon (Username) field of the FirePass logon page, and instead you will see output that appears similar to the following example:

You must select a global certificate field to use as logon username before you can use client certificate authentication. Click on the link below to install client root certificates and configure global settings.

In this situation, you should return to the Device Management: Security: Certificates page and use the drop-down menu below the Request client certificate during logon check box to choose a setting; select any setting other than the following:

Do not use certificate field for logon username

Once you have made that change, you should see the additional two configuration options under the Authentication tab for your master group, on the Users: Groups: Master Groups page.
