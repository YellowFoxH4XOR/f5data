Description

When trying to delete a user ID from GUI localDB "Access ›› Authentication : Local User DB : Users"  get the below error for random deletion.

"CliHandler: Local User Database: Failed to delete user. CliHandler: Command failed with return code 255. It did not print any error message."
 

Environment

BIG-IP APM 13. X or higher.

 

Cause

Special characters in the username field will cause issues when trying to delete a random user id from GUI.
eg for wrong username format : ï¿½labcd@local
The user deletion error message occurs mostly because of incorrect format of values uploaded using bulk CSV upload option.

 

Recommended Actions

Got two options

  • Either delete the username via cli in bash.

eg: ldbutil --delete --instance="/Common/<instance name>" --uname="<username>"

 

  • Take backup of the localDB and delete the entire local DB and upload new CSV with correct format of username.

The username should not be more than 31 characters. ( if you try adding username via GUI it wont let you do but in bulk CS upload this value is limit is not checked).

The username should contain only characters "a-z A-Z 0-9 _ - . @".
