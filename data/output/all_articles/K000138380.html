Description

Slow upload / download speed going through BIG-IP virtual server with FastL4 profile. Packet analysis with wireshark often shows the server's calculate window size shrinking and packet transfer stops. 

Environment

  • Upload / download speed
  • FastL4 profile
  • TCP Progressive profile
  • Window congestion
  • GUI

Cause

Server (pool member) limits window size due to overwhelming traffic

Recommended Actions

Changing to f5-tcp-progressive profile with additional congestion control setting will reduce overwhelming to the server while allows higher throughput compare to default TCP profile. 

From the GUI, local traffic > Virtual Servers > Select the virtual server > Configuration > Protocol Profile (Client) > drop down menu > select "f5-tcp-progressive" 

Note: FastL4 profile (non full proxy) would put more burden on the server (pool member) itself especially when downloading / uploading large files.
