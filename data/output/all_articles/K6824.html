Topic

The asmqkview script automatically collects configuration and diagnostic information from BIG-IP ASM systems. The information is gathered into a single file, which you can then provide to F5 Support to aid in troubleshooting. F5 Support requires asmqkview output in all cases where remote access to the product is not available.

  • BIG-IP ASM 10.2.2 and later
  • BIG-IP ASM 9.2.0 through 10.2.1

BIG-IP ASM 10.2.2 and later

Note: When you run the asmqkview utility, the qkview utility is automatically executed. When collecting ASM data for versions 10.2.2 or later, it is not necessary to collect the output of both the qkview command and the asmqkview command separately, as that data is now automatically included in the output of the asmqkview utility.

Running asmqkview

You must run asmqkview from the command line. To do so, perform the following procedure:

  1. Log in to the command line.
  2. Run asmqkview by using the following command syntax:

    asmqkview <options>

  3. Collect the output file from the /var/tmp/ directory.

    The output file name is <hostname>.qkview, where <hostname> is the host name of the device on which you are running asmqkview.

Command options

You may use the following asmqkview options:

Note: The following options provide additional information that may be useful to F5 Support. In general, F5 does not recommend that you include these options unless directed to do so by your F5 Support representative.

  • --add-request-log (--add-proxy-log in 10.2.2 - 11.5.x)
    • Add reports data. This information may include sensitive parameter information, such as usernames or passwords, unless the Mask Value in the Logs setting is enabled for the parameter.
    • ASM learning tables
    • Captured traffic data; files that were generated by the DoS Protection profile (Record Traffic option). The tcpdump output may include sensitive information, such as request and response HTTP headers and parameter information.
  • --request-log-size-limit
    • Introduced in BIG-IP ASM 11.6.0
    • This option limits the size of the request log collected by asmqkview (in MB).
  • --include-traffic-data
    • ASM learning tables
    • Captured traffic data; files that were generated by the DoS Protection profile (Record Traffic option). The tcpdump output may include sensitive information, such as request and response HTTP headers and parameter information.
  • --no-policy-history
    • Do not include policy history.

      Note: If you do not select this option, it may increase the processing time.

The asmqkview script also runs a copy of the standard version qkview script, and you may specify the following qkview options at the command line, as well:

  • -d

    Include debug output

  • -f <output file name>

    Specify an output file name different from the default output

  • -h

    Help

  • -r

    Restrict to this blade only

  • -s <max file size>

    Limit output file to a maximum size. Specify a max file size between 0 and 104857600 bytes in BIG-IP ASM 14.0.0 and later, and between 0 and 78643200 bytes in previous versions.

  • -t <max time>

    Specify a maximum time, in seconds, to run any module

The asmqkview utility on BIG-IP ASM 10.2.2 and later creates a diagnostic file that you can upload to F5 iHealth, or provide to F5 Support to aid in troubleshooting.

Note: For information about uploading diagnostic files to iHealth, refer to K12878: Generating diagnostic data using the qkview utility.

Note: For information about sending files to F5 Support, refer to K000090853: Exchange files with F5 Support.

BIG-IP ASM 9.2.0 through 10.2.1

The following BIG-IP ASM related configuration files and log files are collected and archived by the asmqkview script:

  • The /ts/ts.ver file

    The BIG-IP ASM version file

  • BIG-IP ASM log files

    Files under the /ts/log and /var/log/asm directories

  • BIG-IP ASM configuration files

    All .cfg files under the /ts/ directory

  • MySQL errors file

    All .err files under the /var/lib/mysql/ directory

  • BIG-IP ASM databases

    DCC and PLC

Starting in BIG-IP ASM 9.4.4, a 5 GB limit is imposed for asmqkview files. The asmqkview script collects files in the following order:

  • /var/log/asm*
  • /var/lib/mysql/*.err
  • /ts/log/* (top level only)
  • /var/lib/mysql/*err
  • /ts/log/* (second level and beyond)
  • *.cfg under /ts
  • MySQL dumps of DCC and PLC databases

When the script is running, if a particular directory pushes the total size of all files added to the asmqkview list over the 5 GB limit, then the parent directory and subdirectories are omitted. For example, if /var/lib/mysql/mysqld.err is 6 GB, all files in the /var/lib/mysql/*.err section are omitted from the asmqkview list, but subsequent groups, such as /ts/log/*, are included (that is, if adding them does not push the total over the limit).

Note: The following files are added to the asmqkview output without a size limit check:

  • /ts/ts.ver
  • PROXY_LOG, if requested by command line flag
  • InnoDB status
  • DCC table status (not contents)
  • PLC table status (not contents)
  • PRX table status (not contents)
  • MySQL process list

Running asmqkview

Note: You can run the asmqkview script by itself on a standalone BIG-IP ASM system. Alternatively, if the BIG-IP ASM system is running as a licensed module on a BIG-IP system, you can run the qkview script. When you run the qkview script on a BIG-IP system, the qkview script automatically calls and runs the asmqkview script. For more information, refer to K1858: Overview of the qkview utility (9.x).

On standalone BIG-IP ASM systems, you can run asmqkview from the command line.

To run asmqkview, perform the following procedure:

  1. Log in to the command line.
  2. Run asmqkview by entering the following command:

    asmqkview

  3. Collect the output file from the /shared/tmp/ directory.

    The output file name is asm_snapshot.<hostname>.tar.gz, where <hostname> is the host name of the device on which you are running asmqkview.

Command options

To specify a maximum size limit for the asm_snapshot file, you can use the following command syntax:

asmqkview --size_limit=<max size in bytes>

Note: The --size_limit flag is no longer available starting in BIG-IP ASM 9.4.0.

To include the request log in the asmqkview command output, you can use the following command syntax:

asmqkview --add-proxy-log

Note: The asmqkview command output option includes only the first 100,000 requests from the log file.

Note: For information about sending files to F5 Support, refer to K000090853: Exchange files with F5 Support.
