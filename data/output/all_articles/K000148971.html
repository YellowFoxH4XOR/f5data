Topic

This article explains the pay-as-you-grow (PAYG) offerings for the F5 r12000 series platform. For information about other F5 rSeries platforms, refer to the following articles:

  • K44211301: PAYG license support for F5 r5000 and r10000 series platforms
  • K44442211: PAYG license support for F5 r2000 and r4000 series platforms

Description

The F5 r12000 series platform offer upgradable three-tier PAYG licensing; licenses include r12600-DS, r12800-DS, and r12900-DS.

The assigned PAYG license defines the data-plane performance of the rSeries platform. This is achieved by limiting the number of available vCPU, number of tenants, and number of SSL transactions per second (TPS).

The r12000 series platform have a three-tier PAYG offering starting with the r12600-DS. Through license upgrades, you can unlock more performance on the same hardware platform. For example, to increase performance on an r12000 series platform, you can upgrade the r12600-DS license to an r12900-DS license. The published data sheet numbers are based on these newer PAYG strategies.
