Description

When trying to connect to a Remote Desktop reource via the BIG-IP APM you may see the following error message in the APM logs:

notice vdi[6610]: 019cffff:5: /Common/<RDP_Access_Policy>:Common:<SessionID>: {7796.C} No RDG policy specified, deny access to <Desktop_example1>:3389
 

Environment

  • BIG-IP APM
  • Native Remote Desktop 

Cause

Lack of RDG agent under main policy

Recommended Actions

Create a simple Start --> Allow RDG-RAP Access Policy, and assign it into the main Access Policy.
  1. Login to the Webui >>  Access  >>  Profiles / Policies : Access Profiles (Per-Session Policies).
  2. Create a new profile and choose Profile Type RDG-RAP. Then edit that profile and modify the ending to Allow. Save and apply.
  3. Then under main policy, Edit the Access policy via the Visual policy Editor (VPE) , click on +  at the end of your policy and configure RDG Policy Assign and specify the one created in step 1.
  4. Save
