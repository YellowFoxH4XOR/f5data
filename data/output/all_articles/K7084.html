Known Issue

Note: This known issue only affects F5 8400 and 8800 series platforms, which utilize the PVA 10 chip.

This is the result of a known issue. A SYN flood on a PVA-accelerated virtual server that is using the FastL4 profile can cause the Packet Velocity ASIC (PVA) to lock.

This issue can result in one or more of the following behaviors:

  • Nodes arbitrarily change their up or down status
  • Traffic is rerouted to software handling
  • The sweeper attempts to remove connections but is quickly overwhelmed, and causes the Traffic Management Microkernel (TMM) to crash
  • Memory consumption quickly grows and is not released after the SYN flood is stopped
  • All nodes are marked as down and the PVA stops generating SYN cookies, which causes the system to stop passing traffic

F5 Product Development tracked this issue as CR72690 and it was fixed in BIG-IP LTM 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
