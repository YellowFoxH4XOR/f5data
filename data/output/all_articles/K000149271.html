Description

Through browsers, we can access to Citrix, passing SAML authentication.

But through Citrix Receiver, the SAML authentication is failing.

 

Environment

  • BIG-IP APM
  • SAML
  • Citrix Receiver

 

Cause

  • F5 does not support SAML authentication for Citrix receiver yet.

 

Recommended Actions

  • If this function is required, please contact F5 support.
