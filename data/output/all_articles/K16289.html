Known Issue

When the mcpd process is not fully operational and you attempt to perform a license activation, the BIG-IP system generates a malformed dossier. When you submit the malformed dossier using either the automatic or the manual license activation method, the license activation fails.

Impact

You are unable to obtain an updated license for the affected BIG-IP system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you submit the malformed dossier using the automatic license activation method, the license activation fails and the BIG-IP system reports an error message in the Configuration utility that appears similar to the following example:

    Unable to grant license key: Error 51143, Monitor: nCipher Error - Manifest Structure is Malformed
  • When you submit the malformed dossier using the manual license activation method, the F5 license server reports an error message similar to the following example:

    Unable to grant license key: Error 51143, Monitor: nCipher Error - Manifest Structure is Malformed

Workaround

To prevent this issue from occurring, you must ensure that the mcpd process is fully operational before attempting to perform the license activation.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
