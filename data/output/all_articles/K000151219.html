K000151219: Proxy client certificate (and key), from client SSL/TLS handshake, to upstream service in http context does not work

Type
Support Solution
Published
2025-05-08
Updated
2025-05-08
Applies to
  • NGINX Products
  • NGINX Gateway Fabric
  • NGINX Ingress Controller
  • NGINX Plus
  • NGINX Open Source
Source
https://my.f5.com/manage/s/article/K000151219

Description

NGINX cannot be configured, in http context, to proxy client certificate (and key), received from client SSL/TLS handshake, to an upstream service.

Environment

NGINX [Plus]

Cause

By design.

Recommended Actions

Implement one of the following solutions

  • NGINX [Plus]: implement TLS/SSL passthrough with the stream module

  • NGINX Ingress Controller (choose one):

    • Implement TransportServer

    • Implement MTLS (EgressMTLS)

  • NGINX Gateway Fabric: see Configure TLS Passthrough
