Description

After enabling Cookie Hijacking protection on ASM, the BIG-IP triggers random false positives for ASM Cookie Hijacking violation, with the reason "Mismatched message key".

Environment

  • BIG-IP ASM
  • Cookie Hijacking protection (Security >> Application Security >> Sessions and Logins >> Session Tracking)

Cause

F5 found this as Bug ID 830341

Recommended Actions

The solution for this case is first to upgrade to one of the "Not Affected Versions" (from the BugID 830341 article), to make sure we will have the required parameter available: ignore_cookies_msg_key
Note: The affected versions does not have the parameter, hence you will require to upgrade to an higher/fixed version.

In case you are already using "Not Affected Version" - Please use the following command to implement a fix and restart ASM process:
Impact of workaround: Restarting the asm process causes the BIG-IP ASM system to fail over to the remaining members of the device group.

  1. Run the following command from CLI:

    /usr/share/ts/bin/add_del_internal add ignore_cookies_msg_key 1

  2. To restart the BIG-IP ASM process, type the following command:

    bigstart restart asm
