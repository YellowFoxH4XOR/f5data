Known Issue

The internal signing certificate included in FirePass versions 7.0.0, and earlier expires on November 10, 2011 at 23:14:56 GMT. When the FirePass Portal Access reverse-proxy engine patches a Java applet, it re-signs the Java class or archive using an internal signing certificate.   

Impact

The Java applet will not be loaded by the web browser unless the user accepts the expired certificate.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Accessing Java applets through Portal Access will display the following error message:

    The digital signature was generated with a trusted certificate but has expired.
