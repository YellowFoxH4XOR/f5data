Known Issue

The BIG-IP system delivers a message to the wrong peer if you have configured bidirectional persistence.

This issue occurs when all of the following conditions are met:

  • You have configured bidirectional persistence.
  • A pool of server devices is sharing the same state.
  • One server is down.
  • The other server uses the same session to send the message to another peer.

Impact

The BIG-IP LTM system may send the message to the wrong peer.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system delivers a message to the wrong peer if you have configured bidirectional persistence.
  • The existing algorithm that selects the direction to forward a message that matches a bidirectional persistence entry may send the message to the wrong peer.

Workaround

To work around this issue, you can use an iRule to route and deliver the message, or do not share the state between servers.

Impact of workaround: Performing the workaround should not have a negative impact on your system.
