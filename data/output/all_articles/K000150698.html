Description

This KB article explains how BIGIP administrator can verify the access-profile customization type (standard or modern) in GUI and in CLI.

Environment

  • Access-profile
  • Customization
  • Standard
  • Modern

Cause

None

Answer/Recommended Actions

1) To verify the access-profile type in GUI (aka Configuration Utility), the BIGIP APM administrator should go to 'Access  ››  Profiles / Policies : Access Profiles (Per-Session Policies)' and refer to Customization column.

2) The verification of customization type of access-profile type in CLI is more challenging. The below procedure may be used:

2.1) in lab, I created 2 access-profiles 'ap_ruslan_customization_old' and 'ap_ruslan_customization_new'. The first one was created using Standard customization type and the second one was created using Modern customization type.

2.2) Each access profile after initial creation has the default built-in agents. For example, the ending deny agent. 

2.3) We can verify the properties of such agents and based on output to determine the customization type used during initial policy creation:

root@(bigip.local)(Standalone)(Active)(/Common)(tmos)# list apm policy customization-group ap_ruslan_customization_old_end_deny_ag 
apm policy customization-group ap_ruslan_customization_old_end_deny_ag {
    checksum SHA1:62:fd61541c1097d460e42c50904684def2794ba70d
    create-time 2025-04-03:12:00:36
    created-by admin
    last-update-time 2025-04-03:12:00:36
    mode 33188
    revision 1
    size 62
    source standard <=== (!)
    type logout
    updated-by admin
}                 
root@(bigip.local)(Standalone)(Active)(/Common)(tmos)# list apm policy customization-group ap_ruslan_customization_new_end_deny_ag 
apm policy customization-group ap_ruslan_customization_new_end_deny_ag {

}
