Known Issue

BIG-IP Edge Client for Mac OS X may fail to establish a session.

This issue occurs when all of the following conditions are met:

  • A user initiates a connection to the BIG-IP APM system through the Mac OS X BIG-IP Edge Client.
  • The BIG-IP APM access policy is configured with the Machine Info agent.

Impact

Attempts to access the BIG-IP APM access profile fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the access policy is only configured with the Machine Info agent, attempts to access the system fail sporadically.
  • When the access policy includes the Machine Info agent, followed by any other agent, attempts to access the system fail consistently.
  • When you remove the Machine Info agent from the access policy, Mac OS X BIG-IP Edge Client users can access the BIG-IP APM access profile.
