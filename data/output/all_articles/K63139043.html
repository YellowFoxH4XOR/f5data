Description
Users are unable to pass the OCSP authentication with error message like below

/Common/ocsp_auth:Common:c1c61dbd: OCSP Auth agent: Failure status 'Error querying OCSP responder host (f5apm.f5.local) path (/)'

Environment

  • APM policy
  • OCS authentication object

Cause
1) The APM unit is either unable to reach / resolve to the host name of the ocsp responder
2) The OCSP server is not responding
 

Recommended Actions

  1. Check if there is connectivity issue to the OCSP responder
  2. Check if the unit is able to resolve to the host name of the OCSP responder
