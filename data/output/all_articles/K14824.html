Known Issue

The mcpd process may leak memory over time.

This issue occurs when the following condition is met:

  • BIG-IP add-on modules are using the mcpd process to communicate with the Traffic Management Microkernel (TMM).

Impact

The BIG-IP system may experience resource exhaustion and possible failover.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H428641 on the Diagnostics > Identified > Medium screen.
  • The amount of memory that mcpd uses increases progressively.
  • The system fails over to a host in the device group due to memory exhaustion.
