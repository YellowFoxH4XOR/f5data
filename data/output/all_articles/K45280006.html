Description

Starting in BIG-IQ 8.0 you can manage even more of your F5 Security products.

Environment

  • You can...
    • Create
    • Import
    • Export
    • Delete
    • Clone
    • Deploy
    • Use the "Policy Analyzer"
    • Use a Default Policy
    • Make available for application service template (Service Catalog Templates will deprecate in future versions)
    • Make unavailable for application service template (Service Catalog Templates will deprecate in future versions)
    • Create a policy and "Save as policy Template"
    • Compare Policies
  • Threat Intelligence, Network Security, Fraud Protection Services, Web Application Security, Shared Security, IPsec
  • Advanced WAF (AdvWAF)/ASM, AFM, SSLO
Note: SSLO version 9.0 and up are not currently supported.
 
From within these varied options you can add policies to virtual servers, update polices and configuration, compare a test policy with a prod policy, use the ready to use archive to correct/fix policies, and numerous other functions.
These options are found within the BIG-IQ under the 'Configuration' tab. From there you can explore the many options you will find.
