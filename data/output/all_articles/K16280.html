Topic

You should consider using this procedure under the following condition:

  • You want to enable or disable debugging of the BIG-IP AFM firewall rules compilation.

Description

During the rule compilation on the BIG-IP AFM system, you can enable the new pccd.rule.debug debugging system database variable to display debugging information about the micro-rules in each of the firewall rules.

The new system database variable is available in the following versions or hotfixes:

  • 12.0.0 or later
  • 11.6.0 or later
  • 11.5.2
  • 11.5.1 with HF4 or later

When the pccd.rule.debug system database variable is set to true, after the next firewall rules compilation you can observe the debug output collected on at least two of the following log files:

  • /var/log/pccd.urule.current
  • /var/log/pccd.urule.success
  • /var/log/pccd.urule.fail

When the compilation is successful, the /var/log/pccd.urule.current file will be soft-linked to the /var/log/pccd.urule.success file.
When the compilation fails, the /var/log/pccd.urule.current file will be soft-linked to the /var/log/pccd.urule.fail file.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrator role access to the Traffic Management Shell (tmsh) utility.
  • The BIG-IP system is running any of the following versions or hotfixes:
    • 12.0.0 or later
    • 11.6.0 or later
    • 11.5.2
    • 11.5.1 with HF4 or later

Procedures

Enabling and disabling the debug database variable

To enable or disable debugging of the BIG-IP AFM rule compilation's system database variable, perform the following procedure:

Impact of procedure: F5 recommends that you return the pccd.rule.debug system database variable to the default value of false after you complete the troubleshooting steps. Leaving debugging enabled when the system is in normal production mode may generate excessive logging and cause poor performance.

  1. Log in to the tmsh utility by typing the following command:

    tmsh
  2. To enable the troubleshooting database variable, type the following command:

    modify sys db pccd.rule.debug value true

    The BIG-IP system will attempt a new compilation of the rules.

    Optional: You can force an immediate new compilation of rules by restarting the pccd daemon using the following tmsh command:

    restart /sys service pccd

  3. Review the /var/log directory to locate the pccd.rule.success, which means the rule compilation is successful. Otherwise, look for the pccd.rule.fail file, which means that the rule compilation failed.
  4. When you are finished collecting the debugging files related to rule compilation, you should disable the rule debugging database variable. To disable rule debugging, type the following command:

    modify sys db pccd.rule.debug value false
