Known Issue

This is the result of a known issue. The Failover.VlanFailsafe.ResetTimerOnAnyFrame BigDB key is not included in the /config/BigDB.dat file of a clean install of BIG-IP 9.2.4.

Note: BIG-IP 9.2.4 and 9.4 introduced the Failover.VlanFailsafe.ResetTimerOnAnyFrame BigDB variable as part of a change in behavior with VLAN failsafe. For more information, refer to K6593: VLAN Failsafe can be configured to reset its timer on reception of any frame.

If the /config/BigDB.dat file does not contain an entry for the Failover.VlanFailsafe.ResetTimerOnAnyFrame variable, attempts to set the variable will fail with the following error message:

# bigpipe db Failover.VlanFailsafe.ResetTimerOnAnyFrame true
BIGpipe: BIGdb variable modification error:
01020036:3: The requested BIGdb variable
(failover.vlanfailsafe.resettimeronanyframe) was not found.

F5 Product Development tracked this issue as CR69309, CR66174, and CR64239 and it was fixed in BIG-IP LTM 9.1.3, 9.2.5, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

If upgrading is not an immediate option, you can manually add the Failover.VlanFailsafe.ResetTimerOnAnyFrame BigDB key to the /config/BigDB.dat file, by performing the following procedure:

Important: This procedure requires you to shutdown BIG-IP services, which will interrupt traffic. F5 recommends performing this procedure on the standby BIG-IP system or during a maintenance window.

Important: You must perform this procedure from the console or management interface. If you are connected to the BIG-IP system through a self IP and perform this procedure, you will lose connectivity to the BIG-IP system.

  1. Log in to the BIG-IP command line using the console or management interface.
  2. Change directories to the /config directory by typing the following command:

    cd /config

  3. Back up the original BigDB.dat file by typing the following command:

    cp BigDB.dat BigDB.dat.sol7123

  4. Shut down BIG-IP services by typing the following command:

    bigstart shutdown

  5. Edit the BigDB.dat file by adding the following entries between the [Failover.TmmStartDelay] and [Pva.HealthCheck.Interval] entries:

    [Failover.VlanFailsafe.ResetTimerOnAnyFrame]
    default=false
    type=enum
    realm=common
    enum=|true|false|
    display_name=Failover.VlanFailsafe.ResetTimerOnAnyFrame

  6. Save the BigDB.dat file.
  7. Start BIG-IP services by typing the following command:

    bigstart startup

  8. Set the Failover.VlanFailsafe.ResetTimerOnAnyFrame BigDB variable by typing the following command:

    bigpipe db Failover.VlanFailsafe.ResetTimerOnAnyFrame true
