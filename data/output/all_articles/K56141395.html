Description

Automatic BIG-IP VE deployment with vAPP is failing to add initial configuration.
Management address did not set up.
Error in /var/log/ltm log after deployment:

localhost.localdomain err tmsh[PID]: 01420006:3: "192.168.1.1" a netmask must be specified

Environment

  • BIG-IP new deployment with vAPP
  • ESXi deployment
  • BIG-IP 14.x and above

Cause

Management address does not have mask specified

Recommended Actions

Add network mask to management address in vAPP mgmt-addr.  For example:

mgmt-addr 192.168.1.1/24

Additional Information

None
