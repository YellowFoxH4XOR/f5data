Known Issue

BIG-IP systems with Load Balancer Limited (LBL) licenses fail provisioning initialization after an upgrade.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is licensed with an LBL license.
  • You upgrade your BIG-IP 10.x system to BIG-IP 11.4.x - 11.5.x.

Impact

None. The message that displays on the BIG-IP system is cosmetic and can be cleared using the procedure described in the Workaround section of this article.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Configuration utility displays a message similar to the following example:

    Provisioning Warning

  • The BIG-IP command line interface prompt displays a message similar to the following example:

    ModuleNotLicensed

Workaround

To work around this issue, you can set the Resource Provisioning option for the BIG-IP LTM system to None. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To set the Resource Provisioning option to None, type the following command:

    modify /sys provision ltm level none

  3. Save the change by typing the following command:

    save /sys config
