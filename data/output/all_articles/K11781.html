Known Issue

This is the result of a known issue. The ARX system configured with a CIFS namespace may experience a rare race condition when performing internal Kerberos functions. As a result, the ARX system will become unresponsive and the distributed Network-Attached Storage (dNAS) process will dump core.

Additionally, the error.log file will contain messages that appears similar to the following example:

: dnas[14800]: [E:1] Writing core file.
: dnas starting; build 11767; nsid 1; pgrp 45; iid 2

Note: You can use the show cores command to display the available core files. For information, refer to the ARX CLI Reference Guide.

F5 Product Development tracked this issue as ID 38544 and it was fixed in ARX version 5.0.7 for the ARX 5.0.x software branch, and in version 5.1.7 for the ARX 5.1.x software branch. For information about upgrading, refer to the ARX release notes.

Additionally, this issue was fixed in ARX versions 5.1.5 HF2 (build 11969) and 5.0.6 HF8 (build 11774). Customers affected by this issue should request these versions from F5 Technical Support, and reference this Solution number and ID 38544.
