Known Issue

This is the result of a known issue. When the ARX system attempts a snapshot for a Windows 2008 R2 filer with 20 or more mount points, the snapshot fails with an error message that appears similar to the following example:

WMI-0-ERR-WMI_RESPONSE_FAULT:: The server responded with a fault. Reason: The WS-Management service cannot complete the Pull operation for the enumeration because the wsman:MaxEnvelopeSize, wsen:MaxCharacters or wsen:MaxElements parameters differ from those specified to the enumeration. The application needs to specify the same parameters for Pull as were specified for the enumeration. HTTP Status: 500. Fault Code: w:InternalError.

F5 Product Development tracked this issue as ID 345775 and it was fixed in ARX versions 5.1.9, 5.2.2, and 5.3.1. For information about upgrading, refer to the ARX release notes.
