Known Issue

This is the result of a known issue. The BIG-IP system does not display the recent compression statistics graph in the Overview statistics page of the performance dashboard.

Note: The Overview statistics page is displayed when you select Overview from the View drop-down selection menu in the upper-right corner of the dashboard.

Note: Recent compression statistics is displayed when you select Recent from the Filter drop-down selection menu in the upper-right corner of the Throughput section.

When viewing the Overview statistics page in the BIG-IP performance dashboard, the throughput displayed includes a filter menu, which allows only a subset of the collected statistics to be displayed. The available filter options include the following:

  • Recent
  • Hour
  • Day
  • Week
  • Month

For example, you can choose Hour to display only statistics for the past hour. However, in BIG-IP version 10.0.0, when you select Recent to display only recent compression statistics on the Overview statistics page, the recent compression statistics graph is not displayed.

F5 Product Development tracked this issue as CR120056 and CR119978 and it was fixed in BIG-IP version 10.0.1. For information about upgrading, refer to the BIG-IP LTM or WOM release notes.

Workaround

You can work around this issue by using an alternate filter for the throughput statistics. The graph displays as expected when you select any value other than Recent. For systems licensed for the BIG-IP WAN Optimization module, you can also choose WAN Optimization from the View drop-down selection menu, and filter the Throughput tab for recent events to correctly display the compression statistics graph.
