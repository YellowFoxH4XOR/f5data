K000092682: Using F5OS REST API to remote download system image

Type
Support Solution
Published
2022-11-22
Updated
2022-12-05
Source
https://my.f5.com/manage/s/article/K000092682

Description

You should consider using this procedure under the following condition:

  • You want to use REST command to download images from a remote web server into BIG-IP F5OS system.

Environment

  • F5OS
  • REST API
  • Web server hosting the F5OS system images

Cause

None

Recommended Actions

In the following example, we use Curl as the REST API client retrieving a Controller ISO image from a web server: 
$ curl -i -k -u admin:admin -X POST --header "Content-Type: application/yang-data+json" https://<F5OS management address>:8888/restconf/data/f5-utils-file-transfer:file/import --data @- <<EOF
  {
    "f5-utils-file-transfer:local-file": "images/staging/F5OS-C-1.3.2-9645.CONTROLLER.iso",
    "f5-utils-file-transfer:remote-url": "https://<web server address>/F5OS-C-1.3.2-9645.CONTROLLER.iso"
  }
  EOF
Note: Replace with the appropriate hostnames or IP addresses for the F5OS Chassis/Partition/Appliance management address and the web server.

Additional Information

If you must download system image from a web server that has an SSL certificate that is either self-signed or signed by an untrusted Certificate Authority, you will need to use Curl's insecure flag ("-k") and add the following line to the above JSON payload: 
$ curl -i -k -u admin:admin -X POST --header "Content-Type: application/yang-data+json" https://<F5OS management address>:8888/restconf/data/f5-utils-file-transfer:file/import --data @- <<EOF
  {
    "f5-utils-file-transfer:insecure": "",
    ...
  }
...

Note: Ensure that you trust the web server before you attempt to download any image files from it.
