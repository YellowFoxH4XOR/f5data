K75731142: ASM attack signatures are not updating to system

Type
Support Solution
Published
2023-04-06
Updated
2023-04-06
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP ASM: 16.1.2
Source
https://my.f5.com/manage/s/article/K75731142

Description

You are unable to update the Attack Signature Update (ASU) to your system. The ASU was spinning until it reached the timeout, and the liveupdate.script file is corrupted. The live update repository was initialized with the default scheme.

Environment

  • Automatic or Manual Update Enabled
  • ASU, ASM Module
  • ASM VE v16.1.2

Cause

The Live Update File was corrupted.

Recommended Actions

To resolve the issue, please complete the following steps:

  1. Restart tomcat with the following command:

    bigstart restart tomcat

  2. Verify that ASU is updated by running the following command:

    restcurl -u admin:<ADMIN_PASSWORD> /mgmt/tm/live-update/asm-attack-signatures/installations?\$select=loadDateTime,addedEntitiesCount,modifiedEntitiesCount,deletedEntitiesCount,status,updateFileReference,errorMessage

  3. Run the following command to check the update files:

    restcurl -u admin:<ADMIN_PASSWORD> /mgmt/tm/live-update/asm-attack-signatures/update-files?\$select=filename,selfLink

  4. Check the following directory for update files:

    ll /var/lib/hsqldb/live-update/update-files/
