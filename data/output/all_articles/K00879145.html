Known Issue

The BIG-IP system may fail to monitor pool members identified using fully-qualified domain names (FQDNs).

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system configuration includes one or more pools that identify members using FQDNs.
  • One or both of the following events occur:
    • The DNS servers used by the BIG-IP system to resolve FQDNs frequently fail to respond to DNS resolution requests.

      Note: To review the defined DNS servers in the Configuration utility, navigate to System > Configuration > Device > DNS.

    • When DNS servers are unreachable, Internet Control Message Protocol (ICMP) unreachable packets cannot reach the BIG-IP system.

Impact

A pool monitor status remains as either unknown or down, regardless of the pool member's availability.

Note: Pool members with a status of unknown can receive new client requests.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You notice one or more pool members that remain in the unknown or down status while responding to the applied monitors.

Workaround

To work around this issue, you can ensure that connectivity between the BIG-IP system and remote DNS servers is stable and that the BIG-IP system receives ICMP unreachable packets when DNS servers are unreachable.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
