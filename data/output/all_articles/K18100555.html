Description

Opening and viewing exported UCS files locally from Windows OS

Environment

Need to view UCS content for reference of old config (ie.bigip.conf, bigip_base.conf)

Cause

Unwanted changes to a Big-IP config and need reference to previous UCS file with last known good config to return to previous settings of a VIP, APM Policy, iApp etc

Recommended Actions

  1. 7-ZIP (Download from internet)
  2. Notepad++ (Download from internet)
  3. Right click on UCS file and extract content to folder
  4. The extracted content will mirror file structure or files on the Big-IP when viewing them from the CLI.
  5. Navigate to the file needed to be viewed/reviewed.
  6. Right click the file (ex: config/bigip.conf) and open with Notepad++
  7. From Notepad++ you can then search for the needed (VIP, IP, APM Policy etc) for comparison.
