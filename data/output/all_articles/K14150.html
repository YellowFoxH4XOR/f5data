Known Issue

The TMM process may core dump if mirroring is enabled on a persistence profile.

This issue occurs when all of the following conditions are met:

  • The virtual server is configured with persistence profile, with mirroring enabled.
  • The mirrored connection to the virtual server is temporarily interrupted (disconnect / reconnect).
Impact

If the BIG-IP system is a member in a redundant configuration, traffic fails over to the standby BIG-IP system. If the BIG-IP system is not part of a redundant pair, traffic is interrupted until the TMM process restarts.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Messages that appear similar to the following example are logged to the /var/log/ltm file:

    Pool /Common/pool_one member /Common/10.1.1.1:80 session status forced disabled.
    Pool /Common/pool_one member /Common/10.1.1.1:80 session status enabled

    HA Connection with peer 172.16.1.1:1028 lost

  • The TMM processes crashes and the system writes a core file to the /shared/core directory.
