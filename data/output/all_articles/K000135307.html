Description

Sometimes, loading configuration on BIG-IP systems may fail due to the following error log:


01070712:3: Cannot create static route: 0.0.0.0%<ABC>/0 gw X.X.X.X%<ABC> on interface in rd<ABC> - netlink error: 101 (Network is unreachable)

 

This error indicates that the system is unable to establish a network route due to an unreachable network, possibly because of a misconfiguration.

 

Environment

  • BIG-IP
  • loading configuration during upgrade or from UCS archive
 

Cause

This log message suggests that there might be a misconfiguration that prevents BIG-IP from successfully loading the configuration.

Such issues are particularly prevalent following a migration or upgrade process. It's essential to scrutinize the configuration settings, ensuring that the network routes are correctly set up, and that there are no inconsistencies between the new and old configurations that might hinder network accessibility.

Additionally, the issue could be associated with an incorrect ARP entry in the BIG-IP's ARP table. An erroneous or stale ARP entry might disrupt the routing process, preventing the establishment of the network route as indicated in the log message. 

 

Recommended Actions

Remove problematic static routes for example by editing the /config/bigip.conf file, which are obstructing the configuration from loading, and then re-add them. This will help resolve the issue, and if necessary, a new ARP entry will be recorded in the BIG-IP's ARP table.

 

Example part of the affected configuration:

 

net route /Common/DefaultGatewayABC {

    gw X.X.X.X%ABC

    network default%ABC

}


After the configuration is successfully loaded, it's crucial to remember to re-add those static routes.

 

Additional Information

This issue can be related to K34193654.
