K2495: Changing the host name of a 3-DNS Controller

Topic

To change the name of a 3-DNS Controller, perform the following steps:

  1. From the command line, type the following command:

    config

    A menu displays.

  2. Select the Set host name option, and then press Enter.
  3. Type the new host name for the 3-DNS Controller, and then press Enter.
  4. Optional: You can quit the config screen.
  5. After you change the name of your 3-DNS Controller, you must change the records in the domain zone files to reflect the name change, especially with Start of Authority (SOA) records.

    For example, for the domain help.dev.net, you would change the SOA record in the zone file from:

    @ IN SOA oldname.dev.net. help.dev.net.

    to:

    @ IN SOA newname.dev.net. help.dev.net
  6. Reboot the 3-DNS Controller.

    Note: The name change takes effect when the 3-DNS Controller boots up.
