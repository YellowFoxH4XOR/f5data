Topic

F5 has recently discovered and corrected a number of issues that affect customers running ARX 6.2.0. F5 recommends that all customers who are currently running ARX 6.2.0 install the latest cumulative rollup hotfix that is available.

The following table lists the rollup hotfixes available for ARX 6.2.0. Each hotfix lists the ID number and description for the issues fixed by the hotfix:

Note: These rollup hotfixes are cumulative; each hotfix contains the fixes included in the previous hotfixes.

413481During HA rendezvous, when redundancy is first enabled, it is possible to "no enable" redundancy on the ARX that will become the backup switch before it is fully established.  As part of rolling back redundancy, all global scope data is removed from the joining ARX.  Previously, it was possible for a database transaction conflict to prevent removal of this data.  This would cause numerous split-brain conditions when the joining ARX resumed stand-alone function.
In this situation, the joining ARX now reboots on failure to clear all global scope data.  The data is then automatically removed during restart.
414433A design limitation on the number of outstanding notify-change requests could cause syslog to be flooded with 'No available message id for notify-change request' messages.
