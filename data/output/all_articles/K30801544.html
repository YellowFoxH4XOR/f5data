Description

You want to use iControl REST API to gain the status of a Virtual Server, Pool, Pool Member. However, the iControl REST API does not have a field reflecting the availability of Virtual Server, Pool, or Pool Member on the corresponding resource endpoint. Alternatively, we have a stats endpoint that provides the availability and status reason information.

Environment

  • BIG-IP LTM
  • iControl REST API
  • Virtual Server
  • Pool
  • Pool Member

Cause

None

Recommended Actions

You may use the stats endpoint to retrieve and parse the availability status.

For Virtual Server, the endpoint URL will be:

https://<host>/mgmt/tm/ltm/virtual/~<partition>~<vs name>/stats

For Example, you can fetch the virtual server status by running a command as below:

curl -k -u <admin>:<admin_passwd> https://localhost/mgmt/tm/ltm/virtual/vs/stats

The response will have three entries represent availability status, enable status, and the reason for the status. The fields of these entries are separately named as status.availabilityState, status.enabledState, and status.statusReason. You may refer to this article for the meanings of those fields K16008: Overview of BIG-IP pool status (11.x - 16.x)
{
    kind: 'tm:ltm:virtual:virtualstats',
    generation: 1109,
    selfLink: 'https://localhost/mgmt/tm/ltm/virtual/vs/stats?ver=12.1.0',
    entries: {
        'https://localhost/mgmt/tm/ltm/virtual/vs/~Common~vs/stats': {
            nestedStats: {
                kind: 'tm:ltm:virtual:virtualstats',
                selfLink: 'https://localhost/mgmt/tm/ltm/virtual/vs/~Common~vs/stats?ver=12.1.0',
                entries: {
                    -- snipped --
                    'status.availabilityState': {
                        description: 'available'
                    },
                    'status.enabledState': {
                        description: 'enabled'
                    },
                    'status.statusReason': {
                        description: 'The virtual server is available'
                    },
                    -- snipped --
                    totRequests: {
                        value: 4
                    }
                }
            }
        }
    }
}
Note: You can use the URL https://<host>/mgmt/tm/ltm/pool/~<partition>~<pool>/stats to check the availability for pools. Similarly, this URL for members: https://<host>/mgmt/tm/ltm/pool/~<partition>~<pool>/members/~<partition>~<member name>/stats

Additional Information

Similarly, you can retrieve DNS pool or pool member availability status by referring to K30560942: How to retrieve pool and pool member availability by iControl REST
