Description
APM log messages report Chrome and IE web browser user-agents as Mozilla. The reason for this goes back to a time where many web content providers constructed their websites to be fully functional with Mozilla user-agents and IE was forced to implement Mozilla compatibility within their user-agent strings, Chrome to follow suit, and it stuck ever since. 

Environment

  • APM
  • Web-browser is being used to connect

Cause
None

Recommended Actions

This is expected behavior.

Microsoft announced the end of support for Internet Explorer on June 15, 2022 . You should use supported browsers such as MS Edge, Chrome or Firefox.

Additional Information
Example APM log messages reporting user-agents of Chrome web browser on MacOS and IE on Win10, respectively:

  •   /Common/access_policy:Common:4a02fdca: Received User-Agent header: Mozilla/5.0 (Macintosh; Intel Mac OS X 10_14_6) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/78.0.3904.97 Safari/537.36.
  •   /Common/access_policy:Common:bd9c7f7b: Received User-Agent header: Mozilla/5.0 (Windows NT 10.0; WOW64; Trident/7.0; rv:11.0) like Gecko.
