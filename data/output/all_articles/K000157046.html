Known Issue

The VELOS system may fail to bring up an Small Form-factor Pluggable (SFP) interface.

This issue occurs when all of the following conditions are met:

  • You removed the SFP from one of the blades installed in the VELOS system and subsequently reinserted the SFP back to the same interface on the same blade.
  • The VELOS system is running F5OS-C 1.8.0.

Impact

The affected interface is reported as down in F5OS-C however the switch at the other end of the link may report the link as up.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The F5OS-C system reports the affected interface as down even though the switch connected to the interface may report the link as up.

Workaround

To work around this issue, you can reboot the blade with the affected interface. To do so, perform the following procedure:

Impact of workaround: Depending on your tenant configuration, rebooting a blade may temporarily disrupt traffic processing for the tenant(s) configured to run on that blade.

Using the partition webUI

  1. Login to the webUI of the partition where the affected blade is assigned; you should login as the admin user or a user with the admin role.
  2. Navigate to SYSTEM SETTINGS > General.
  3. Under the System Operation & Status section, locate the affected blade.
  4. Select Reboot for the affected blade and then select OK when prompted for confirmation. You can monitor the status of the blade from the webUI.

Using the partition CLI

  1. Login to the CLI of the partition where the affected blade is assigned; you should login as the admin user or a user with the admin role.
  2. Reboot the blade by entering the following command syntax:

    cluster reboot node blade-<n>

    where <n> is the blade number.

    For example, you would enter the following command to reboot blade 2:

    cluster reboot node blade-2

  3. You can monitor the status of the blade using the following command:

    show cluster nodes node state summary
