K000148307: How to identify iApp objects in the GUI and CLI

Description

Due to how iApp configuration objects are handled you will need to know how to identify them in both the CLI and the GUI. The need to identify them will often occur when you see a message similar to this when you try to update a configuration object outside of the iApp itself.

010715bc:3: The application service (/Common/testhttp.app/testhttp) has strict updates enabled, the object (Virtual Server /Common/testhttp.app/testhttp_vs) must be updated using an application management interface.

K51033596: Error Message: 010715bc:3: The application service (&lt;iApp name&gt;) has strict updates enabled, the object (&lt;iApp object&gt;) must be updated using an application management interface.

Environment

  • Need to update the configuration
  • Any configuration object created by the iApp
  • iApps and Strict Updates.

Cause

iApps are templates used to create configurations. Often without the iApps trying to do so manually cannot be done without extensive knowledge of all the needed objects, how they have to be set up, and the iRules that may also have to be used.

It is important to note here that if Strict Updates is disabled in the iApp that you can change the configuration of the object outside of the iApp. That can cause unintended consequences and should only be done with the guidance of F5 and documented.  K51699308: Modifying or deleting an iApp

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1.  Check the configuration via either the GUI or CLI to identify whether an object was created by an iApp or not.
    1. On the CLI when you view the configuration object 2 things are added to it when it is created.
      1. In the path the name is reused and .app is added.
      2. To name an object identifier is added such as _vs for virtual server.
      3. Example: ltm virtual /Common/testhttp.app/testhttp_vs
    2. In the GUI
      1. In the section titled General Properties is a block labeled Partition / Path and in that you will see .app appended to the Path.
      2. The name will have the object identifier added to the name.
