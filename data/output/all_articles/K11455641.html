Security Advisory Description

NGINX LDAP reference implementation configuration can be modified by sending crafted HTTP requests.

Note: nginx-ldap-auth is not an NGINX Product. It is published as a reference implementation of LDAP and describes the mechanics of how the integration works and all of the components required to verify the integration. It is not a productionâ€‘grade LDAP solution. For example, there is no encryption of the username and password used for the sample login page, and security notices call this out.

This issue occurs when one or more of the following conditions are met:

  • Command-line parameters are used to configure the nginx-ldap-auth Python daemon.
  • There are unused, optional nginx-ldap-auth configuration parameters.
  • nginx-ldap-auth's LDAP authentication depends on specific group membership.

Impact

nginx-ldap-auth configuration is modified and LDAP authentication may be bypassed.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • nginx-ldap-auth configuration parameters are overwritten.
