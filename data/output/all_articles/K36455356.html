Known Issue

When you view pool statistics for a wide IP and the number of pools exceeds those displayed on the page by default (the first 10), there is no option to view the statistics for the remaining pools.

This issue occurs when the following condition is met:

  • The number of pools for which statistics can be displayed exceeds the default of 10 per page.

Impact

When the number of pools for a wide IP exceeds 10, you can view the pool statistics for the 10 that are displayed on the page by default, but you can't view the statistics for the others.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the number of pools exceeds the default of 10 per page, the option to display additional pages is missing.

Workaround

To work around this issue, you can increase the number of records displayed by default. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > Preferences.
  3. Under System Settings, change the Records Per Screen value from 10 to a number that enables you to view all your pool entries.
  4. Click Update.
