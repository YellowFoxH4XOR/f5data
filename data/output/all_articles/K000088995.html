K000088995: Dependency Errors during install of App-Protect 3.2.0

Type

Published

Source

Description

Following the setup of app-protect at https://docs.nginx.com/nginx-app-protect/admin-guide/install-for-controller/ encountered dependency errors during the install process of app-protect.

 Environment

Ubuntu 18.04

App-Protect 3.2.0

Nginx-Plus R24

Nginx Controller 3.16.1

 Cause

Dependency issues with Nginx-Plus R24 and Nginx Controller 3.16.1 and App Protect 3.2.0. At the time of this writing Nginx Controller 3.16.1 and App Protect 3.2.0 do not support Nginx-Plus R24.


Module missing during load of nginx: ngx_http_f5_metrics_module.so

 Recommended Actions

Install supported version of Nginx-Plus. At the time of this writing it would be: apt-get install nginx-plus=23-1~bionic
