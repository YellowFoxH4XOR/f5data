Known Issue

This is the result of a known issue. The signing certificate used by the Java console and Java-based legacy hosts expired on November 29, 2008 at 00:00:00 GMT. When you access the Java console, you may receive an error message reporting that the digital signature has expired. This error message does not prevent the Java console from loading or running unless you decline to accept the expired digital signature.

Note: You can access the Java console by selecting the Please click here to start a console session to the Maintenance Account link on the Device Management : Maintenance : Troubleshooting Tools page.

Similarly, if a user accesses a Java-based legacy host favorite, the user may receive an error message reporting that the digital signature has expired. This error message does not prevent the Java console from loading or running, unless the user declines to accept the expired digital signature.

F5 Product Development tracked this issue as CR113720 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, hotfix-113720-1 has been issued for FirePass versions 5.5.2, 6.0.1, 6.0.2, and 6.0.3. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Note: After installing hotfix-113720-1, the new Java signing certificate expires on November 10, 2011 at 23:14:56 GMT.
