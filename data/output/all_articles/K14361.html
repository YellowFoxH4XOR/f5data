Known Issue

If you apply a custom filter to the policy attack signature list, the system may intermittently return an incorrect display.

This issue occurs when the following condition occurs:

  • The BIG-IP ASM policy attack signature list is filtered through the Advanced Custom Filter page, and filtering results, with any of the following filter types:
    • Update Dates
    • Accuracy
    • Risk
    • Overrides

The most direct way to navigate to the Advanced Custom Filter page is to go to Application Security > Options : Attack Signatures : Attack Signature List > Filter > Custom.

Impact

  • When filtering the policy attack signature list the filter settings can revert to the default settings, or the system may return a blank page.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you view a policy attack signature list that has been filtered for Update Dates, and you view pages beyond the first page results, the system may display a blank page.
  • When you view a policy attack signature list that has been filtered for Accuracy, Risk, Update Dates, or Overrides, and you view pages beyond the first page results, the filter settings revert to their default settings.
