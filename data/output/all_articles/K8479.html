Topic

Starting in BIG-IP version 9.4.0, a new log file system is introduced for BIG-IP systems containing hard drives. The new log file system allows you to determine the amount of disk space specifically reserved for logging purposes, and also allows you to accurately monitor the disk space used by log files.

BIG-IP platforms containing hard drives

The BIG-IP log files are comprised as follows, depending on which version you are running:

Note: For information about managing system log files, refer to K7115: Managing log files on the BIG-IP system.

BIG-IP 9.0.0 through 9.3.1

In BIG-IP version 9.0.0 through 9.3.1 systems containing hard drives, the log files are stored in the /var/log directory, which is a symbolic link to /shared/log.

BIG-IP 9.4.0 and later

In BIG-IP versions 9.4.0 and later systems containing hard drives, the log file system is created during the boot process by a startup script, and mounted as a loopback device to the /var/log directory. The default log file system size is 7 gigabytes. A symbolic link to the /shared/log directory is created to preserve logging continuity for older versions of BIG-IP. The log file system size can be controlled using the resize-logFS command.

Important: Beginning in BIG-IP version 10.0.0, the resize-logFS utility was deprecated due to major architectural changes. BIG-IP systems running version 10.0.x include the utility; however, any attempts to change the size of the log file system will fail. Beginning in BIG-IP version 10.1.0, the resize-logFS utility was removed. Use of this utility is only supported in BIG-IP version 9.x.

Note: If the startup script does not find sufficient disk space in the /shared partition for the default 7 gigabyte log file system, the system does not mount the log file system as a loopback device, and the /var/log directory is symbolically linked to the /shared/log directory.

After the 7 gigabyte log file system is created by the system, you can use standard UNIX commands to accurately monitor how much disk space is available to the log file system. To monitor the available disk space for the /var/log directory, perform the following procedure:

  1. Log in to the command line.
  2. Type the following command:

    BIG-IP 10.x

    df -k /var/log |sed -n -e '3p'|awk '{print $3}'

    For example, the following command output indicates that the system has 6.3 gigabytes of available disk space for the log file system:

    6671492

    BIG-IP 9.x

    df -k /var/log |sed -n -e '2p'|awk '{print $4}'

    For example, the following command output indicates that the system has 6.2 Gigabytes of available disk space for the log file system:

    # df -k /var/log |sed -n -e '2p'|awk '{print $4}'

    6504520

BIG-IP platforms containing CF drives only

In all BIG-IP versions for systems containing CF drives, the log files are contained in the /var/log directory.
