Topic

The interface statistics, CPU usage, and other system-related SNMP OIDs are all from the UC Davis MIB. For the standard IfEntry interface statistics, the UC Davis MIB derives the counter types from Integer32 and not Integer64.

Beginning in version 4.5, the 1000, 2000, 2400, 5000, and 5100 switch appliances allow you to query for the IfXEntry OIDs, which contain 64-bit counters (called High Capacity counters) in addition to some 32-bit counters.

Following are the 32-bit counters that have 64-bit counterparts, along with the 64-bit OIDs:

32-bit64-bit
ifInOctetsifHCInOctets
ifInUcastPktsifHCInUcastPkts
ifInMulticastPktsifHCInMulticastPkts
ifInBroadcastPktsifHCInBroadcastPkts
ifOutOctetsifHCOutOctets
ifOutUcastPktsifHCOutUcastPkts
ifOutMulticastPktsifHCOutMulticastPkts
ifOutBroadcastPktsifHCOutBroadcastPkts

The BIG-IP version 9.x software branch SNMP agent uses numerous Counter64 type objects. Approximately one third of the SNMP objects are Counter64 type. This number will continue to grow as the product matures.

For example, BIG-IP version 9.0.0 included approximately 3,800 objects, 1,200 of which were Counter64 type. The number of objects in BIG-IP version 9.2.3 has increased to approximately 8,300 objects, almost 1,500 of which are Counter64 type.

Important: Counter64 type objects may only be viewed using SNMP v2c. SNMP v1 does not support Counter64 type objects.
