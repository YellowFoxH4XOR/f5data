Description

Adding TLSA records to a zone file when using ZoneRunner.

Environment

  • TLSA Records in Zone Files
  • ZoneRunner

Cause

None

Recommended Actions

TLSA records can be added to local BIND by creating and using a file similar to the following (in this example we'll name the file "/var/tmp/nsupdate.in" but the filename is not significant):

 

server 127.0.0.1

update add _443._tcp.mysite.com. 3600 TLSA 0 0 1 12ab34cd56ef

send

 

Adjust as necessary. Then run the following command at the bash prompt, pointing to the file created above:

 

nsupdate /var/tmp/nsupdate.in

 

No output is expected.

 

ZoneRunner will not show the record, but queries that are allowed to hit local BIND (selfIP with open ports and no virtual server, or virtual server with DNS profile that has use-local-bind and unhandled-query allow) will be answered with the expected TLSA record (whether or not DNSSEC is configured).

 

If DNS Express is configured to pull in a zone that has TLSA records, it will respond appropriately (whether or not DNSSEC is configured).
