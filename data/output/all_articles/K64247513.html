Description

  • Unable to receive Access Session information on BIG-IQ CM Dashboard

Environment

  •  BIG-IQ DCD
  •  BIG-IQ CM

Cause

  • high disk usage on /var directory
  • high disk specification for log retention
  • there will be log message in /var/log/ltm similar to 
    •  Apr  3 14:35:02 err diskmonitor: 011d0004:3: Disk partition /var has only 4% free

Recommended Actions

  • Free up space by deleting historical data from /var directory
or
  • If there is a requirement to keep historical Eleasitserarch data, increase disk space
  • Please reference in how to increase disk space on the BIG-IQ
    • K30902515: Resizing the /var, /var/log, or /shared file system on a BIG-IQ Virtual Edition
