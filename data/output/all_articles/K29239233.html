Description

The Max In Progress Sessions Per Client IP restricts the number of In-progress access policies for a given client IP address. In-progress access policies are client sessions which BIG-IP APM is still evaluating to determine whether to grant or deny client access to protected resources. This article provides an overview of how to determine the value for this feature.

Environment

  • BIG-IP APM
  • APM Access Policy
  • Max In Progress Sessions Per Client IP

Cause
N/A

Recommended Actions

The max-in-progress-sessions property is part of the access DoS/DDoS Protection features which restricts the number of access sessions _currently_ being evaluated by an APM per-session profile for a _given_ client IP address.  If there are large number of users simultaneously accessing APM from behind a proxy or NAT, then this feature would be exhausted much faster. When the number of sessions in progress for a single client IP address exceeds the value configured for the Max In Progress Sessions Per Client IP setting in the access profile, you will see the following message in /var/log/apm:

warning tmm[<pid>]: 01490547:4: Access Profile <name>: Per IP in-progress sessions limit (<#>) exceeded for <IP_address>

Note: You can monitor the number of  "In-progress" sessions for an specific IP address by running the following command  in bash mode:
watch -n1 'tmsh show apm access client-ip <IP address> all-properties | egrep "^apm access|status " | grep "status pending" | wc -l'

To determine the best value for this property, we should ask the following two questions:

  1.  How many users are there behind the NAT-ed IP that is accessing to the Policy?
  2. How many of them may concurrently try to logon?

Based on those answers, you can adjust the value of the max-in-progress-sessions with the following process:

  1. Log in to the Configuration utility.
  2. Navigate to Access Profiles:

    13.x and later

    Access > Profiles/Policies

    11.x - 12.x

    Access Policy > Access Profiles

  3. Click on the name of the access profile.
  4. In the Properties tab, under Settings, modify the value for the Max In Progress Sessions Per Client IP setting.
  5. Click Update
