K8284: A Firefox browser window launched through a Dynamic App Tunnel does not tunnel traffic through the FirePass controller

Type
Knowledge
Published
2008-12-29
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 6.0.3, 6.0.2, 6.0.1, 6.0.0
Source
https://my.f5.com/manage/s/article/K8284

Topic

If a user opens a Dynamic App Tunnel that is configured to launch Firefox, a new Firefox browser window appears, but the user may not be able to access internal websites. This behavior occurs when Firefox is already running on the client machine when the user launches the Dynamic App Tunnel. Traffic from the new Firefox browser window is routed through the client’s default network connection instead of the Dynamic App Tunnel. The user may be able to access external websites in the new Firefox window, but not internal websites. This behavior is due to a code compatibility issue between the FirePass software and the Firefox software.

You can work around this issue by configuring a Web Application Tunnel instead of a Dynamic App Tunnel. Additionally, users can work around this issue by ensuring that all Firefox browser windows are closed before launching the Dynamic App Tunnel.

Note: Web Application Tunnels are configured on the Application Access: App Tunnels: Resources page under the Web Application Tunnels tab.

F5 Networks Product Development is tracking this issue as CR84697.
