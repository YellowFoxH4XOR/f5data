Description

You have a rSeries device running F5OS-A, and you wish to backup your configuration automatically.

Environment

F5OS-A
Usage of APIs

Cause

None

Recommended Actions

A full article about rSeries Configuration Backup and Restore (f5.com) tells us that we have 3 options for performing backups: WebUI, F5OS CLI, and API calls. To do this automatically, we will use API calls.

For an API call to work, considering that it will be called from the same device you want to run this backup on (to let us use crontab), the call will be done from management IP (in our case 192.168.0.1) back to the management IP.

For this to be successful, we need to allow requests originating from the management IP to access the API. We can follow Configure the Allow List on the F5 rSeries system and allow them on ports 8888 as well as 443 in F5OS CLI:

hostname.f5.com(config)# system allowed-ips allowed-ip api1 config ipv4 address 192.168.0.1 port 8888 prefix-length 24

hostname.f5.com(config-allowed-ip-testing)# commit and-quit

Commit complete.

hostname.f5.com(config)# system allowed-ips allowed-ip api2 config ipv4 address 192.168.0.1 port 443 prefix-length 24

hostname.f5.com(config-allowed-ip-testing2)# commit and-quit

Commit complete.

After adding the management IP to the allow list, please find below an API call that can be used to backup the configuration. In this setup, the credentials to the admin account are admin/admin, and the management IP address is 192.168.0.1. It also shows us the output and the result, so we can use it to test that this is indeed working:

[root@appliance-1(hostname.f5.com) ~]# curl -k -X POST -u admin:admin -H "Content-Type: application/yang-data+json" -d '{"f5-database:name": "F5OS-BACKUP-APPLIANCE1-'"$(date +"%Y-%m-%d")"'"}' https://192.168.0.1/api/data/openconfig-system:system/f5-database:database/f5-database:config-backup

{

"f5-database:output": {

"result": "Database backup successful."

}

}


To make it automatic, here's an example crontab entry that will run this script daily at 2:00 AM, and any output will be discarded to >/dev/null 2>&1:
Important: Completing the following will store the Administrator password in "plain-text" in crontab of the F5OS.  This is not recommended.

0 2 * * * curl -k -X POST -u admin:admin -H "Content-Type: application/yang-data+json" -d '{"f5-database:name": "F5OS-BACKUP-APPLIANCE1-'"$(date +"\%Y-\%m-\%d")"'"}' https://192.168.0.1/api/data/openconfig-system:system/f5-database:database/f5-database:config-backup >/dev/null 2>&1

Additional Information

There could be a concern regarding the plain-text password from the script syntax, here below are steps to mask the password to make it not showing as the plain-text.

1) Masking the password with Base64 format.

[root@appliance-1(hostname.f5.com) ~]#echo -n admin:admin | base64
YWRtaW46YWRtaW4= 

2) Create a file under /var/F5/system/etc for pasting the base64 header result.

# cat /var/F5/system/etc/backup.txt 
Authorization: Basic YWRtaW46YWRtaW4=

3) Modify the curl script to point to the file.

0 2 * * * curl -k -X POST -H "$(cat /var/F5/system/etc/backup.txt)" -H "Content-Type: application/yang-data+json" -d '{"f5-database:name": "F5OS-BACKUP-APPLIANCE1-'"$(date +"\%Y-\%m-\%d")"'"}' https://192.168.0.1/api/data/openconfig-system:system/f5-database:database/f5-database:config-backup >/dev/null 2>&1
