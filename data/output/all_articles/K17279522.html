Description

  • After using "TCP::collect 0 0" in an iRule you may notice a new warning message when upgrading from 12.0.0 to a newer version or when restoring from an old UCS file
  • LTM log will contain the following warning message:
/Common/example_iRule:9: warning: [The following errors were not caught before. Please correct the script in order to avoid future disruption. "invalid argument 0; expected syntax spec:"136 17][TCP::collect 0 0]

Environment

  • BIG-IP
  • iRule
    • TCP::collect

Cause

  • Prior to 12.0.0 there were no restrictions to the values of the arguments specified in the TCP::collect command.
  • Validation for TCP::collect was changed in 12.0.0 (with the introduction of JET specifications).  

Recommended Actions

  • As of 12.0.0 the first argument ("collect_bytes") must be a positive integer
  • The second argument ("skip_bytes") must be a positive integer
    Note: F5 Support does not design or configure iRules.  If you are in need of any assistance configuring an iRule to best work for your environment, F5 Professional Services can assist.
