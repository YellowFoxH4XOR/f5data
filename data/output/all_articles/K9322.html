Known Issue

This is the result of a known issue. If you relicense a BIG-IP PSM system as a BIG-IP ASM system, the remote logging profiles previously created on the BIG-IP PSM system are no longer configured on the system.

As a result, the administrator must recreate all remote logging profiles after the migration is complete.

F5 Networks Product Development tracked this issue as ID 221260 (formerly CR95071) and it was fixed in BIG-IP version 10.0.0. For information about upgrading, refer to the BIG-IP ASM or PSM Release Notes.
