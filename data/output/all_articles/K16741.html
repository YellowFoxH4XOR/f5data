Topic

Summary

The LineRate Operating System (LROS) supports the following HTTP request methods:

  • GET
  • HEAD
  • POST
  • PUT
  • DELETE
  • CONNECT
  • OPTIONS
  • TRACE

For more information about HTTP request methods, refer to section 4 of RFC7231.

Description

The LineRate system supports HTTP and TCP service types for the following:

  • Virtual server configurations
  • Virtual IP configurations
  • Real server configurations

The HTTP service type allows for Layer 7 (L7) load balancing, for HTTP and HTTPS content types. The TCP service type allows for load balancing of TCP connections without processing the TCP payload.

When the LineRate system is configured to use the HTTP service type, request methods other than the types defined in RFC7231 will result in HTTP responses similar to the following example:

HTTP/1.1 400 Bad Request
Content-Type: text/html
Content-Length: 108
Connection: close

<html><head><title>Status 400 Bad Request</title></head><body><h1>Status 400 Bad Request</h1></body></html>

Recommendations

If unsupported HTTP methods are required, you must use the TCP service type for your virtual server, virtual IP, and real server configurations. Selecting the TCP service type prevents the use of any L7 features, such as cookie persistence.
