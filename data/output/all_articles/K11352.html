Known Issue

This is the result of a known issue. The bigpipe shell utility attempts to load the system configuration and then stalls when using Tab completion for the bigpipe load command option.

For example, hitting the Tab key to complete the following command results in the bigpipe utility attempting to execute the bigpipe load command:

bp>load <TAB>
bp>load Loading the configuration ...

If you press the Enter key while the command is stalled, the bigpipe load command will complete; however, the configuration may be only partially loaded to memory.

F5 Product Development is tracking this issue as ID 247953 (formerly CR139343).

This issue does not affect the BIG-IP version 9.x code branch.

Workaround

If you experience this issue, and the BIG-IP configuration is only partially loaded to memory, you can execute the bigpipe load command to reload the complete configuration to memory.
