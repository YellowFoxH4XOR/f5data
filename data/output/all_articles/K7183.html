Known Issue

Note: FirePass version 6.0.1 is the first release to support Microsoft Windows Vista clients.

This is the result of a known issue. Mapping a networked drive through a static application tunnel fails on Windows Vista clients.

Note: For more information, refer to K9750: Configuring an application tunnel to map a network drive.

Networked drives that share files through the SMB/CIFS protocol, such as Microsoft Networking file shares, can be accessed through static application tunnels configured to run on port 139. However, users connecting to the FirePass controller with the Windows Vista operating system will not be able to successfully launch a static application tunnel on port 139. The following error message will appear in the Status section of the application tunnel window:

Couldn't open proxy server

F5 Networks Product Development tracked this issue as CR73903 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Important: For FirePass version 6.0.3 and later, you must install the DNS Relay Proxy service on Windows Vista clients to resolve this issue. You can download the DNS Relay Proxy client component on the Device Management : Client Downloads : Windows (x86) page in the FirePass Administrative Console. For more information, refer to K9694: Overview of the DNS Relay Proxy service.

Workaround

To work around this issue, upgrade to version 6.0.3 or later, and download and install the DNS Relay Proxy component on affected Windows Vista client systems.

Alternatively, you can use Windows Files Favorites to access network drives for Windows Vista clients.
