K53217130: When BIG-IP is behind proxy server. BIG-IP is unable to perform licensing after running SOAPLicenseClient command.

Type
Support Solution
Published
2020-10-13
Updated
2025-04-01
Applies to
  • BIG-IP LTM: 14.1.2
Source
https://my.f5.com/manage/s/article/K53217130

Description

When BIG-IP is behind proxy server. After licensing using command SOAPLicenseClient, refer to K44027283.

# SOAPLicenseClient --proxy <proxy_IP_addr>:<proxy_port> --basekey <base-reg-key> --certupdatecheck

After that BIG-IP shows the following error message from CLI.

***Error: Cannot determine IP for license server.

Environment

  • BIG-IP
  • BIG-IP is already configured via K10942531 to join a proxy server.
  • Already perform licensing the BIG-IP using command from K44027283.

Cause

SOAPLicenseClient needs a working DNS server for resolve this hostname/ip mapping.

Recommended Actions

  1. Open the command line from your local PC.
  2. Run the command nslookup activate.f5.com to check the F5 licensing server IP address, refer to K15202.

    nslookup activate.f5.com

    Name:    activate.f5.com
    Address:  104.219.111.132
     
  3. Add Hostname and Address above into the BIG-IP /etc/hosts file, refer to K13206. This would match F5 licensing server hostname and IP address locally.
  4. Perform licensing BIG-IP using command SOAPLicenseClient again, refer to K44027283.
