Description

Log message appears in the /var/log/apm file:
Access to <Portal-Name> rejected because it points to reserved address.
Dev tools shows client requesting resources at 127.0.0.1

Environment

  • Portal Access
  • Localhost
  • APM

Cause

Rewritten request for 127.0.0.x localhost content

Recommended Actions

Configure re-write profile with bypass list containing *://127.0.0.1*:

  1. Navigate to: Access >> Connectivity / VPN >> Portal Access >> Rewrite
  2. Click 'Create' and set a name for the profile
  3. Set 'Parent Profile' to /Common/rewrite
  4. Set 'Rewrite Mode' to Portal (Access)
  5. Under 'Portal (Access)' set 'Enable Split Tunneling' to 'Yes'
  6. Under 'Bypass List' add an entry for: *://127.0.0.1*
  7. Apply the new profile to the Virtual Server
