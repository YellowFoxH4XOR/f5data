Environment

  • Installing an ISO software image

Cause

It is unclear what can cause this situation to transpire. However, you can identify this as being down to an ISO image file (or similar large file) mounted on the device using the mount command:

# mount | egrep tm_install
/shared/images/BIGIP-15.1.2.1-0.0.10.iso on /mnt/tm_install/23823.I5_BNE type iso9660 (ro,relatime)

The image is left mounted and not unmounted once the software installation is finished. This can potentially happen if the software image is installed and the device isn't booted into the new version. 

Recommended Actions

Impact of procedure: The commands specified in this section should not have any negative impact on the system.

  1. To umount the /mnt/tm_install/<directory>, the following command can be utilized:
    umount /mnt/tm_install/<directory_name>
    For example, if your directory name is /mnt/tm_install/23823.I5_BNE, then the following command should be used:
    umount /mnt/tm_install/23823.I5_BNE

  2. To confirm that the file has been unmounted, you can run the following command again:
    df -h
