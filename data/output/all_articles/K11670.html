Known Issue

This is the result of a known issue. If a BIG-IP system with the Cavium FIPS Hardware Security Module is upgraded to version 10.0.1 hotfix 4, the system will fail to initialize the FIPS card.

Additionally, the system will return the following error message each time you log on to the command line:

Cfm1F5Util error (line 1335): Library Initialization : 0x13 : Undefined Error Code

This issue occurs because the kernel installed by hotfix 4 lacks the driver for the FIPS card.

F5 Product Development is tracking this issue as ID 329808 (formerly CR142042).

Note: This issue only affects BIG-IP version 10.0.1-HF4.

Workaround

You can work around this issue by copying the kernel module for the FIPS card from the BIG-IP version 10.0.1 final edition kernel. To do so, perform the following procedure:

  1. Log on to the BIG-IP system command line.
  2. Execute the following commands to copy the kernel module:

    cd /lib/modules/2.4.21-10.0.1.283.0smp/kernel/drivers/

    cp -R crypto /lib/modules/2.4.21-10.0.1.402.0smp/kernel/drivers/

  3. Execute the following command to reboot the system:

    full_box_reboot
