Description

  • While boot up BIG-IP vCMP guest the mcpd show error while loading the configuration:
  • When running command: tmsh load sys config verify , it fails with:
    Validating configuration...
    /config/bigip_base.conf
    /config/bigip_user.conf
    /config/bigip.conf
    /config/bigip_script.conf
    01070710:3: Could not find master-key object - sys/validation/MasterKey.cpp, line 3070
    Unexpected Error: Validating configuration process failed.

Environment

  • vCMP implementation
  • High availability vCMP guests 
  • BIG-IP vCMP Standby guest rebooted and lost Master Key- getting the following error:
    01070710:3: Database error (0), Could not find master-key object - sys/validation/MasterKey.cpp, line 3070.

Cause

2131085: https://cdn.f5.com/product/bugtracker/ID2131085.html

Recommended Actions

Re-deploy the BIG IP guests following K20081511: Shutting down and restarting the vCMP guest from the vCMP host 

Alternately, on a non-vCMP system, restart mcpd on the primary blade.
