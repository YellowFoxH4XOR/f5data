Description

When trying to upgrade to version pi_updates_17.1.0-20231026.1244.im

These errors show on the screen:

DEBUG removing signature 2951

ERROR Failed to adjust configuration: 01020036:3: The requested Protocol Inspection Signature (2951) was not found.

2ERROR Error during switching: 01020036:3: The requested Protocol Inspection Signature (2951) was not found.


Environment

  • Protocol Inspection Update
  • Removed Signatures

Cause

Signature 2951 was removed in the latest updates.

Recommended Actions

  1.  Downgrade to pi_updates_17.1.0-20230921.2028.im
  2. Upgrade to the latest IM. At the time of publication, pi_updates_17.1.0-20231026.1244.im
