K000149266: Snmpget calls are not working

Type
Support Solution
Published
2025-01-29
Updated
2025-01-29
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000149266

Description

Your Snmpget calls are not working when you try to call for SystemUptime. The following error appear as the output: 

snmpget: Authentication failure (incorrect password, community or key) (Sub-id not found: (top) -> sysSystemUptime)

Environment

  • BIG-IP
  • SNMP
  • snmpget

Cause

Error in the SNMP database

Recommended Actions

Reload a configuration based on K13030: Forcing the mcpd process to reload the BIG-IP configuration

Additional Information

None
