Issue

Error Message

01071c1c : You cannot delete the nodejs version <version>

In this error message, note the following:

  • <version> is the nodejs version that encountered a delete action. 

For example:

You cannot delete the nodejs version v0.12.15

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • An attempt to remove nodejs is executed.
  • The attempt does not use the supported administrative methods, TMOS Shell (tmsh) or the Configuration utility. 

    Note: Manual deletion of nodejs versions is not permitted.

Impact

You are unable to delete the nodejs version.

Recommended Actions

None
