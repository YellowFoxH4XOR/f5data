K000141414: When polling F5OS Platform Stats MIBs, NMS returns "Wrong Type (should be OCTET STRING)" after receiving F5OS-A device SNMP response

Type
Support Solution
Published
2024-10-11
Updated
2024-10-11
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.8.0
Source
https://my.f5.com/manage/s/article/K000141414

Description

F5OS-A device software has been upgraded to F5OS-A 1.8.0, and NMS has not been loaded with the latest F5OS MIBs file.

The snmpwalk command output for different F5OS-A release:

F5OS-A 1.5.2

Tue Mar 12 16:58:56 UTC 2024
F5-PLATFORM-STATS-MIB::tempCurrent."platform" = STRING:  24.3  centigrade
F5-PLATFORM-STATS-MIB::tempAverage."platform" = STRING: 24.3 centigrade
F5-PLATFORM-STATS-MIB::tempMinimum."platform" = STRING: 24.0 centigrade
F5-PLATFORM-STATS-MIB::tempMaximum."platform" = STRING: 24.7 centigrade

F5OS-A 1.8.0 LA:

Wed Sep 25 16:07:22 UTC 2024
F5-PLATFORM-STATS-MIB::tempCurrent."platform" = Wrong Type (should be OCTET STRING): INTEGER: 265
F5-PLATFORM-STATS-MIB::tempAverage."platform" = Wrong Type (should be OCTET STRING): INTEGER: 266
F5-PLATFORM-STATS-MIB::tempMinimum."platform" = Wrong Type (should be OCTET STRING): INTEGER: 262
F5-PLATFORM-STATS-MIB::tempMaximum."platform" = Wrong Type (should be OCTET STRING): INTEGER: 270

Environment

  • F5OS-A 1.8.0
  • F5-PLATFORM-STATS-MIB

Cause

Starting from F5OS-A 1.8.0, some MIB objects in F5-PLATFORM-STATS-MIB has been updated with new MIB object syntax. For instance, OID, F5-PLATFORM-STATS-MIB::tempCurrent:

F5-PLATFORM-STATS-MIB::tempCurrent
tempCurrent OBJECT-TYPE
  -- FROM	F5-PLATFORM-STATS-MIB
  -- TEXTUAL CONVENTION TemperatureType
  SYNTAX	Integer32
  DISPLAY-HINT	"d-1"
  UNITS		"centigrade"
  MAX-ACCESS	read-only
  STATUS	current
  DESCRIPTION	"The current temperature in celsius/centigrade"

Therefore, it is necessary for NMS to load the latest MIBs files that are included in the latest F5OS-A release.

Recommended Actions

  1. Follow K25293033 to download the latest MIBs and load them onto the NMS.

Sample snmpwalk output from polling F5-PLATFORM-STATS-MIB::temperatureStatsTable after latest MIBs installed on NMS:

F5-PLATFORM-STATS-MIB::tempCurrent."platform" = INTEGER: 24.6 centigrade
F5-PLATFORM-STATS-MIB::tempAverage."platform" = INTEGER: 24.0 centigrade
F5-PLATFORM-STATS-MIB::tempMinimum."platform" = INTEGER: 22.0 centigrade
F5-PLATFORM-STATS-MIB::tempMaximum."platform" = INTEGER: 24.9 centigrade
