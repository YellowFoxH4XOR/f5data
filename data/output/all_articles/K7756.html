K7756: The BIG-IP ASM security policies are not applied on the redundant system following a configsync

Known Issue

This is the result of a known issue. In a BIG-IP ASM redundant pair configuration, the security policies are synchronized to the redundant system when a configsync is performed. However, the policies are not applied on the redundant system following the configsync operation. As a result, the security policy that is in place prior to the configsync operation remains the active policy on the redundant system.

F5 Product Development tracked this issue as CR83346, and it was fixed in BIG-IP ASM 9.3.1. For information about upgrading, refer to the BIG-IP ASM release notes.

Workaround

You can work around this issue by applying the security policy on the redundant system following a configsync operation. To do so, perform the following procedure:

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Application Security > Web Applications.
  3. Click the active policy name.
  4. In BIG-IP ASM 9.2.x, click Set Active Policy on the Web Application Properties screen to update the settings.

    In BIG-IP ASM 9.3, click Apply Policy.
