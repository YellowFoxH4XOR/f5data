K54118314: In BIG-IP APM, the Guided Configuration Utility stuck in '' initializing.... ''

Type
Support Solution
Published
2021-01-21
Updated
2023-02-21
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 16.0.1
Source
https://my.f5.com/manage/s/article/K54118314

Description

You created an administrator user and then you are trying to navigate to the Guided Configuration utility, Access >> Guided configuration. Then, it gets stuck at "Initializing.... "

In /var/log/restjavad-audit.0.log, you will see a log similar to this:

"http://localhost:8100/mgmt/shared/iapp/global-installed-packages","status":401,"from":"x.x.x.x"}

Environment

  • BIG-IP APM
  • Guided Configuration Utility

Cause

Unknown

Recommended Actions

Use the built-in admin account and the Guided Configuration will load.

Additional Information

None
