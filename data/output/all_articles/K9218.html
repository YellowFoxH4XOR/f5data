Topic

The network map page displays a visual representation of the configuration objects on the BIG-IP system, such as virtual servers, pools, nodes, and iRules. The network map also displays statistics about existing objects.

The network map page is not designed for printing to paper from a web browser, and will result in incorrect output. For example, if you attempt to print the network map page using most web browsers, parts of the map will be missing from the printed output.
