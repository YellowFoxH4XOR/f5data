Description

Getting “011f0007:3: http_process_state_egress_data - Invalid action:0x10d081” in ltm log

Environment

  • BIGIP
  • VS is configured with FastL4 and HTTP profiles simultaneously

Cause

The VS is configured with FastL4 and HTTP profiles simultaneously:
<snip>
profiles {
        /Common/http {
            context all
        }
        /Common/fastL4 {
            context all
        }
    }
<snip>

Recommended Actions

Use either HTTP or FastL4 profile, not both

None
