Description

  • An existing ASM logging profile cannot be changed
  • No new messages logged in /var/log/ts/dcc.log

Environment

  • BIG-IP with ASM provisioned
  • ASM logging profile is configured to send logs to an external server
  • Trying to change the logging destination is unsuccessful - even though the configuration shows the new server, logs go to the old server

Cause

The "dcc" process stopped working properly.

Recommended Actions

Restart "dcc" process

  1. pkill -f tsconfd
  2. pkill -9 dcc
  3. remove and re-apply the logging profile

None
