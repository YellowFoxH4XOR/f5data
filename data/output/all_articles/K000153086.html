K000153086: Group import fails in BIG-IP APM with multiple AAA AD pool members enabled

Type
Support Solution
Published
2025-08-31
Updated
2025-08-31
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.0, 17.1.2, 17.1.1, 17.5.X, 17.1.X, 17.5.1, 17.5.0
Source
https://my.f5.com/manage/s/article/K000153086

Description

  • When configuring a BIG-IP APM AAA Active Directory server pool with multiple domain controllers as pool members, group import operations may fail.
  • The group import is successful only when one pool member is active while the others are disabled.

Environment

  • BIG-IP APM
  • AAA AD server pool
  • AD group import

Cause

BIG-IP APM does not support AAA load balancing. Instead, it uses a priority group mechanism where only the member with the highest priority group is active for authentication and group import.

Recommended Actions

Ensure a unique priority group value is assigned to each member of the AAA AD server pool.
