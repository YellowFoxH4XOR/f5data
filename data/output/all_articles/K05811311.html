Description

You can use this F5-supported iApps template to provide service discovery within cloud environments.

Support Matrix

For information about BIG-IP releases that support the various versions of this iApps template, refer to the following table.

iApp versioniApp supported for BIG-IP versionsiApp not supported for BIG-IP versions
f5.service_discovery.v1.0.012.1.x - 15.x12.0.0 and earlier

You should only install the f5.service_discovery.tmpl iApps template from one of the cloud templates for your cloud provider. F5 does not support or recommend downloading and installing f5.service_discovery.tmpl manually.

To install the iApps template from a cloud template, perform the following procedure:

  • Installing the iApps template from a cloud template

To download the iApps template, perform the following procedure:

  • Downloading the iApps template

Installing the iApps template from a cloud template

  1. Go to the F5 Cloud iApps page on Github.

    Note: This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge

  2. Click Sign in and enter your credentials at the login page.
  3. In the Search or jump to field at the top left of the page, search for f5 cloud iapps.
  4. Click F5Networks/f5-cloud-iapps.
  5. To find the required f5.service_discovery.tmpl iApps template, click the f5-service-discovery folder.
  6. Read the README.md file carefully.

    Note: You should only install the f5.service_discovery.tmpl iApps template from one of the cloud templates. F5 does not support or recommend downloading and installing f5.service_discovery.tmpl manually. 

  7. Depending on your cloud provider, click the appropriate link. For example, f5-aws-cloud-formation or f5-azure-arm-templates.
  8. To deploy the template for your cloud provider, follow the README.md files.

Downloading the iApps template

Important: You must download the file; do not copy and paste the contents.

  1. Go to the F5 Cloud iApps page on Github.

    Note: This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge

  2. Click Sign in and enter your credentials at the login page.
  3. In the Search or jump to field at the top left of the page, search for f5 cloud iapps.
  4. Click F5Networks/f5-cloud-iapps.
  5. Click Clone or Download.
  6. Click Download ZIP.
