Known Issue

The automatic license activation method may stall or time out.

This issue occurs when the following conditions are met:

  • The BIG-IP system does not have internet access during license activation
  • The BIG-IP system is not configured to resolve hostnames

In versions 10.2.x and 11.0.x, the BIG-IP system no longer uses hardcoded DNS servers to resolve the license activation server. The system instead uses a script that attempts to resolve the license server by sending DNS requests to the root name servers. If access to the root servers is blocked, the automated license-reactivation process may stall and the Configuration utility may stop responding. The system will then attempt to resolve the license server name by using any DNS servers defined in the /etc/resolv.conf file. If the BIG-IP system is unable to resolve the license server names, the Configuration utility eventually posts the manual activation option.

Impact

You may be forced to manually activate the BIG-IP license.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • If DNS is not available, the automatic license activation method may stall and eventually post the manual activation option.
  • If local DNS is available, the automatic license activation method may be delayed while the system attempts to contact the root name servers.

Workaround

Impact of workaround: None.

To work around this issue, you can use one of the following three options:

  • Allow access to the root DNS servers

    Configure the firewall to allow port 53 queries from the BIG-IP management IP address.
  • Configure the BIG-IP to resolve DNS hostnames

    For more information, refer to K13205: Configuring BIG-IP to resolve DNS hostnames (11.x) and K8437: Configuring BIG-IP to resolve DNS hostnames (9.x - 10.x)
  • Use the manual license activation method

    For more information, refer to K7752: Licensing the BIG-IP system.
