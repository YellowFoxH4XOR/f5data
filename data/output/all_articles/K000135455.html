K000135455: TCP Keep Alive retry interval

Type
Support Solution
Published
2023-09-18
Updated
2026-04-27
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000135455

Description

Customer may notice that the TCP Keep Alive packet does not send following the configured TCP Keep Alive Interval sometimes.

Environment

  • BIG-IP
  • TCP profile
  • Virtual Server

Cause

BIG-IP sends Keep Alive packet to peer following configure, but if there is no ACK received from the peer, BIG-IP will keep trying to send the Keep Alive packet, it is something like Keep Alive retransmission. In this scenario, the Keep Alive will not follow the keep alive interval setting of TCP profile, instead it will choose the minimum value of TCP idle timeout and TCP Keep Alive Interval to resend keep alive packet.

Recommended Actions

This is expected system behavior, no action needed.

Additional Information

None.
