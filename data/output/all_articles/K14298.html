Known Issue

Setting DHCP on the management port of a VIPRION chassis results in a blank page or error when you attempt to view the System > Platform page in the Configuration utility.

This issue occurs when the following condition is met:

  • You are using the following VIPRION platforms:

    • 2400
    • 4400
    • 4480

Note: In BIG-IP 10.x through 11.x, DHCP in not supported on the management port of the aforementioned VIPRION platforms. Setting DHCP on the management port in those versions does not actually enable DHCP on the management port.

Impact

  • The System > Platform page fails to load.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The System > Platform page is blank or displays an error message.

Resolution

Status

F5 Product Development has assigned ID 361815 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Point release/hotfixNoneNone

Note: In BIG-IP 11.x, DHCP is no longer an available option in the Configuration utility; however, you can set it using the Traffic Management Shell (tmsh). Even though you can set DHCP using tmsh, it will not be enabled on the management port.

Workaround

To work around this issue, you can disable DHCP on the management port using the tmsh utility. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Disable DHCP on the management port by typing the following command:

    modify sys db dhclient.mgmt value disable

  3. Save the change by typing the following command:
    • BIG-IP 10.1.0 and later:

      save /sys config

    • BIG-IP 10.0.x:

      save config
