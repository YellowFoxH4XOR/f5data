K000153179: sFlow for rSeries (host)

Type
Support Solution
Published
2025-08-27
Updated
2025-08-27
Applies to
  • F5OS
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000153179

Description

sFlow, a network traffic monitoring protocol that provides flow-level visibility, is not supported on F5 rSeries platforms running F5OS-A. There is currently no option to enable sFlow functionality at the F5OS-A (host/platform) level at the time of publication.


Environment

  • F5OS - Appliance


Cause

sFlow is not implemented as a feature on the F5OS-A platform for rSeries appliances. The current version of F5OS-A does not provide sFlow support at the host/platform level at time of publication.


Recommended Actions

  • Use SNMP (including SNMPv3) for platform-level monitoring and statistics collection, which is supported on F5OS-A.
  • For flow-level monitoring, sFlow can be configured within BIG-IP tenants running on rSeries, but not at the F5OS-A host level..
  • If sFlow or NetFlow support at the platform level is required, consider submitting a feature request through your authorized F5 account team.
