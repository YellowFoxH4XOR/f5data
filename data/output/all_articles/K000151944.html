Description

On a BIG-IP system using IP Intelligence (IPI), an incomplete or missing IPv6 IP Intelligence reputation database may cause elevated CPU usage on Traffic Management Microkernel (TMM) processes. In this condition, the system can also experience elevated network latency, packet loss, High Availability (HA) instability, and related performance degradation symptoms.

 

In the affected state, the IPv4 IPI database may successfully load, as confirmed by the following message in the /var/log/ltm log file:
015c0010:5: Initial load of IPv4 Reputation database has been completed

However, the equivalent IPv6 database load completion message does not appear:
015c0010:5: Initial load of IPv6 Reputation database has been completed

 

Additionally, the following messages may repeatedly appear in logs:

  • /var/log/tmm:
    Scheduling priority: normal. Nice level: -19.
  • /var/log/iprepd/iprepd.log:
    Unable to download update file <filename> from https://localdb-ipv6-daily.brightcloud.com/<filename>...

 

Environment

This issue occurs when all of the following conditions are met:

  • BIG-IP system configured with the IP Intelligence (IPI) feature.
  • Connectivity issues between the BIG-IP device and BrightCloud update servers ("localdb-ipv6-daily.brightcloud.com").

 

Cause

This issue occurs due to the BIG-IP system's inability to retrieve and load the IPv6 IP Intelligence database from the F5 BrightCloud reputation update servers. ID1132449 has been filed to track this issue.

 

Recommended Actions

To resolve this issue, take the following steps:

  • Ensure the BIG-IP system has permitted outbound HTTPS connectivity to the BrightCloud update servers, specifically "localdb-ipv6-daily.brightcloud.com".
  • Verify DNS name resolution to "localdb-ipv6-daily.brightcloud.com" is functional.
  • Confirm that security rules or firewalls do not prevent connectivity to external BrightCloud IP Intelligence update services.
  • After connectivity is restored, verify that IP Intelligence (IPI) database (both IPv4 and IPv6) has successfully updated and loaded fully onto the BIG-IP system.

Please refer to K03011490 for detailed instructions.
