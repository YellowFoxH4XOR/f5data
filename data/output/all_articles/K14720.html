Topic

This article applies to BIG-IP 10.x - 11.x. For information about other versions, refer to the following article:

  • K16122817: Configuring user authentication for single-user mode access (12.x - 13.x)

You should consider using this procedure under the following condition:

  • You want to restrict access to single-user mode on your BIG-IP host.

Description

Booting into single-user mode allows a user with console access to a BIG-IP system to bypass standard authentication and may be considered a security risk. It is possible to configure the BIG-IP host to require the root password to be entered before single-user mode is activated.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the BIG-IP root password.

Procedures

Configuring single-user mode authentication

You should perform the following procedure on each slot and boot location on which you want to restrict single-user mode access.

Impact of procedure: Root password recovery will not be possible after implementing this change.

  1. Log in to the BIG-IP command line as the root user.
  2. Use a text editor to edit the /etc/inittab file.
  3. Add the following lines to the end of the file:

    # Require Root Password in Single User Mode (SOL14720)
    ~:S:wait:/sbin/sulogin

  4. Save your changes.

Subsequent boots into single-user mode will require the user to enter the root password.
