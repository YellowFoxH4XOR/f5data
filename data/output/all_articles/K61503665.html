Description

You may see the following message in /var/log/ltm when BIG-IP AFM is provisioned:

01010299:5: Per-VLAN hardware syncookie protection is disallowed because device level TCP Half Open Vector is being used

Environment

BIG-IP AFM is Provisioned

Cause

Message is observed as BIG-IP AFM module is provisioned and that the AFM TCP Half Open Vector will provide the Syn Cookie Protection and will take precedence over the Network  ››  VLANs : VLAN List  ››  <VLAN Name> : Hardware Syn Cookie configuration. 

Recommended Actions

Message is informational. Review configured threshold values of BIG-IP configurations related to Syn Cookie protection:

  • Global SYN Check threshold
  • Default per Virtual SYN Check threshold
  • AFM TCP Half Open vector Device Protection detection and mitigation threshold  
  • AFM TCP Half Open vector Protection Profile detection and mitigation threshold
