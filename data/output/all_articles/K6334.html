Topic

By default, the Configuration utility for the BIG-IP ASM system only displays HTTP classes they are enabled for the BIG-IP ASM system.

To display all HTTP Classes, including those that are disabled, perform the following procedure:

  1. Log in to the Configuration utility.
  2. In the main navigation pane, click Application Security.
  3. Click Classes.
  4. In the Application Security column, click the button marked with a downward-pointing arrow.
  5. Select the Show All option.
