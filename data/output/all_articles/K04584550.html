Source

Description
Gateway pool using wrong IPv6 source address from different vlan causing next-hop device discard or ignore F5 IPv6 packets.

Environment

  • BIGIP-LTM
  • IPv6
  • Gateway pool

Cause
This is known issue caused by ID 676990.

Recommended Actions

Upgrade to v13.1.3.2 and enable the db key then save the config change.

tmsh modify sys db snat.hosttraffic value enable
tmsh save sys config

None
