K000160401: Error: 'shutdown' action 'connection' does not support parameter of type 'pool' while configuring F5 LTM policy terraform resource

2026-03-19

Applies to

  • BIG-IP
  • F5 BIG-IP Resources for Terraform

Source
https://my.f5.com/manage/s/article/K000160401

Description

When using the Terraform BIG-IP LTM policy provider resource to remove a rule from an LTM policy that contains both forwarding rules (to a pool) and a "shutdown connection" (reset) rule, you may encounter an HTTP 400 error. The error message appears as follows:

 

Error: 010716de:3: Policy '/Common/Drafts/test_policy', rule 'default'; target 'shutdown' action 'connection' does not support parameter of type 'pool'.

Environment

  • F5 BIG-IP LTM
  • Terraform BIG-IP provider version earlier than 1.25.0
  • LTM policy containing both forwarding rules (to a pool) and a "shutdown connection" (reset) rule
  • Example configuration below
resource "bigip_ltm_pool" "pool1" {
    name = "/Common/pool1"
}
 
resource "bigip_ltm_pool" "pool2" {
    name = "/Common/pool2"
}
 
resource "bigip_ltm_policy" "test_policy" {
  name     = "/Common/test_policy" 
  strategy = "first-match"
  requires = ["http"]
  controls = ["forwarding"]
 
  rule {
    name = "rule1"
    
    condition {
      http_host   = true
      http_uri    = false
      values      = ["host1"]
      contains    = false
      equals      = true
      starts_with = false
      ends_with   = false
      path        = false
      tcp         = false
      address     = false
      matches     = false
    }
    
    action {
      forward    = true
      pool       = "pool1"
      connection = false
      shutdown   = false
    }
  }
 
  rule {
    name = "rule2"
    
    condition {
      http_host   = true
      http_uri    = false
      values      = ["host2"]
      contains    = false
      equals      = true
      starts_with = false
      ends_with   = false
      path        = false
      tcp         = false
      address     = false
      matches     = false
    }
    
    action {
      forward    = true
      pool       = "pool2"
      connection = false
      shutdown   = false
    }
  }
 
  rule {
    name = "default"
    
    action {
      shutdown = true
      select   = false
    }
  }
}

Cause

This issue is due to a bug in the Terraform BIG-IP provider (versions earlier than 1.25.0) where the provider does not correctly handle the removal of forwarding rules in policies that also contain a shutdown rule. The provider may attempt to merge rule parameters incorrectly, resulting in an unsupported configuration being sent to BIG-IP.

Answer/Recommended Actions

  1. Upgrade the Terraform BIG-IP provider to version 1.25.1 or later. The issue is resolved in version 1.25.1, which correctly handles the removal of forwarding rules without associating unsupported parameters with the shutdown action.
