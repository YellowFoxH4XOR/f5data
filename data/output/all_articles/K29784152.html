K29784152: Getting error while removing old ssl certificate.

Source

Description

The following error is being triggered when trying to remove a certificate key file:

01070265:3: The Certificate Key File (/Common/<key name>.key) cannot be deleted because it is in use by a AAA SAML Server (/Common/<server name>).

Environment

  • APM AAA SAML server
  • Certificate Key file
  • APM

Cause

The key is still in use by a SAML server configuration object and can't be deleted until it is removed from the SAML server configuration object.


Recommended Actions

The certificate needs to be removed from the SAML server configuration

If the configuration object referencing the object you want to delete is orphaned or not currently in use, consider reconfiguring the unused object or removing it from the configuration.

For more information about removing orphaned configuration objects, refer to K15335: F5 recommends removing orphaned configuration objects.
