Known Issue

A user may erroneously configure network access compression on a BIG-IP APM system that is not licensed for compression.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is not licensed for compression.
  • In the Configuration utility, the user selects the GZIP Compression setting under the Network Settings properties of the Network Access feature.

Impact

Gzip compression erroneously appears available in the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The user selects the GZIP Compression setting in the Network Settings properties. However, network access traffic is not compressed.
  • The BIG-IP system logs a message in the /var/log/ltm file that appears similar to the following example:

    err tmm[15088]: 01240011:3: Compression license limit of 0 Mbit/s exceeded today.

Resolution

Status

F5 Product Development has assigned ID 423137 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, users can select the No Compression setting under the Network Settings properties of the Network Access feature.
