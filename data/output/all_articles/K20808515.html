Description

On a device with the configuration similar to the below where fastL4 and HTTP profile assigned at the same time, system may exhibit high memory pressure and aggressive mode sweeper being activated.

When "show sys memory" command is checked xdata would be seen as the highest memory consumer.

Configuration contains at least one VS where fastL4 profile is assigned along with HTTP profile:
ltm virtual /Common/virtual_server {
...
    profiles {
        /Common/fastL4 { }
        /Common/http { }
    }
...
}

Environment
  • fastL4 profile is used alongside http profile on a VS
  • v13.1.1
Cause

BugTracker ID742184

Recommended Actions
  • Avoid using fastL4+http profiles together
    --or--
  • Upgrade to a fixed version.
