Topic

The BIG-IP LTM system can load balance IPv4 requests to IPv6 servers and vice versa by automatically translating the source address to the appropriate self IP address on the server Virtual Local Area Network (VLAN).

Note: For more information, refer to K9279: BIG-IP automatically translates addresses between IPv4 and IPv6 when necessary.

You can insert the original client IP address into the request forwarded to the server by applying a HTTP profile with the following value configured in the Request Header Insert field:

CLIENT_ADDRESS: [IP::remote_addr]

This header insert will insert into the request a new header named CLIENT_ADDRESS, the value of which contains the original client IP address in the original version.
