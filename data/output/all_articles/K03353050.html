Description

IPsec is basic BIG-IP TMOS functionality and we support it on BIG-IP by default with any combination of license and provision settings.

Support and Engineering put IPsec under the LTM umbrella for the purpose of product ownership and administration. As a result, solution and support articles will normally only be tagged as LTM. Therefore, searching the knowledgebase for IPsec information may be improved by filtering for LTM.

The majority of IPsec use cases require a Virtual Server to handle tunneled traffic, so any module that allows the BIG-IP administrator to configure Virtual Servers will be able to terminate and handle IPsec. The lack of a Virtual Server results in an extremely restricted set of use-cases for an IPsec tunnel.
 

Environment

BIG-IP with any module provisioned that allows the creation of Virtual Servers.

 

Cause

None


Recommended Actions

None
