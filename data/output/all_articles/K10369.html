Note: This procedure is for FirePass version 6.1.0 and earlier. For later versions of FirePass and BIG-IP APM, refer to K12639: Setting the debug level for the BIG-IP Edge client for Microsoft Windows.

During the course of troubleshooting an issue on a PC client, it may be helpful to change the debug level. To change the debug level and clear the log files, perform the following two procedures:

  • Changing the debug level
  • Resetting the log files

Important: Before changing any registry information, save a copy of the existing key and confirm that the changes will not have any adverse effects on the client. For more information, contact your PC support.

Changing the debug level

  1. Open the Registry Editor by entering the following command from the Run prompt:

    regedit
  2. Expand the HKEY_CURRENT_USER tree.
  3. Expand the Software tree.
  4. Expand the uRoam tree.
  5. Right click on the TerminalProxy tree.
  6. Select New > DWORD Value.
  7. Rename the new DWORD Value to DebugLevel.
  8. In the right panel, double-click DebugLevel.

    A pop-up window displays.
  9. Change the Value data: field to the appropriate debug level.
    A value of 4 is typically used for troubleshooting.
  10. Click OK.

Resetting the log files

  1. Navigate to %userprofile%\Local Settings\Temp or %temp% on Windows XP or %userprofile%\AppData\Local\Temp or %temp% on Windows 7 or Vista.
  2. Delete all f5*.txt and f5*.txt.bak files.
  3. Delete the logterminal.txt and logterminal.txt.bak files.

After you have set the debug level and cleared the logs, have your user log in to the FirePass device again to generate new logs. F5 Technical Support may request that you run F5wininfo.exe to generate a report using the new debug settings.
