Description

When running the BIG-IQ command ./preUpgradeCheck for BIG-IQ systems prior to version 7.1.0 an error message similar to the following is displayed:

ActiveVolumeSize: 459018240 KB
RequiredSpace: 459018240 KB
Free space: 82526208 KB
Disk space compatibility: NOK

Environment

  • BIG-IQ VE

Cause

There is not enough space to proceed with the upgrade.

Recommended Actions

  1. Check if you have other existing non-used volume, running tmsh show sys software.
  2.  To delete existing partitions use the following command from the BIG-IQ command line:
    tmsh delete sys software volume HD1.X
    Note: HD1.X replace the X with the volume ID number.
     
  • Alternatively you will need to increase the disk size on the Hypervisor.
    For more information refer to: K58621633: Extending disk space on a BIG-IQ Virtual Edition.
