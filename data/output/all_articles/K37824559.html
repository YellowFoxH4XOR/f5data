Description

There currently is no configured limit to the number of Attack Signature Sets that can be created or configured on the BIG-IP ASM.

Environment
  • BIP-IP ASM
  • Attack Signature Sets

Cause

The number of Attack Signature Sets is not limited at a configuration level, however, it may be limited to the resource like memory.

None
