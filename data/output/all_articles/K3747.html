Topic

When attempting to reset the admin password using the Setup utility, you may receive the following error message:

A Serious Error has occurred: Role: bigiprole2 does not exist.

This error indicates that the LDAP daemon, which is used for authenticating user accounts, is not running. When this occurs, error messages that appear similar to the following messages may appear in the /var/log/slapd file:

Dec 19 02:46:52 askf51 slapd[9874]: daemon: bind(2) failed
Dec 19 02:46:52 askf51 slapd[9874]: slapd stopped.
Dec 19 02:46:52 askf51 slapd[9874]: connections_destroy: nothing to destroy.
Dec 19 02:47:53 askf51 slapd[9893]: daemon: bind(2) failed errno=48 (Address already in use)

This issue is most likely caused by the deletion of the default.key file or the default.crt file, which are used by LDAP. These files are located in the /config/bigconfig/ssl.key and /config/bigconfig/ssl.crt directories, accordingly. In versions of BIG-IP and 3-DNS prior to 4.5.11 and 4.6.3, the Configuration utility does not prevent the administrator from deleting this file.

If you have accidentally removed this file, contact F5 Technical Support for assistance.
