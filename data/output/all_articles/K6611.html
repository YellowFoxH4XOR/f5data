Known Issue

This may be the result of a known issue. BIG-IP ASM blocks some HTTP/1.0 responses to BIG-IP ASM-enabled virtual servers. This issue may occur after the following sequence of events:

  • The client sends an HTTP/1.0 request to a BIG-IP ASM-enabled virtual server.
  • The server responds with an HTTP/1.0 304 response containing a Keep-Alive header.
  • The BIG-IP ASM system ignores the server response, causing the connection to stall.

F5 Product Development tracked this issue as CR69121 and it was fixed in BIG-IP ASM 9.2.4 and 9.3.0. For information about upgrading, refer to the BIG-IP ASM Release Notes.
