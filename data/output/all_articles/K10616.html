Issue

The following error message may be reported on the Reports: System Logs page, or output to the syslog file of your remote syslog server (if configured):

GarbageCollection session '?????' is terminated

This error message indicates that a user terminated their session, and the user's session is no longer tracked in the FirePass controller's connection table. This message can be safely ignored.
