Description

HA Sync is failing with error similar to below
 
tmsh show cm sync-status
---------------------------------------------------------------------------------------------------------------------------------------------------------------
CM::Sync Status
---------------------------------------------------------------------------------------------------------------------------------------------------------------
Color  red
Status  Sync Failed
Mode   high-availability
Summary A validation error occurred while syncing to a remote device
Details
     bigip1.lab.test: connected
     sync-failover (Sync Failed): A validation error occurred while syncing to a remote device
     - Sync error on bigip1.lab.test: Load failed from /Common/bigip2.lab.test 01070099:3: Can't change user password for user root (Error writing `/etc/passwd.lock.TBPbfT': No space left on device)
     - Recommended action: Review the error message and determine corrective action on the device
 

 

Environment

  • BIG-IP pair in HA
  • HA sync

Cause

A user copied files into the root ('/') partition and caused it to fill up to 100%
 
/var/log/ltm logs show : 011d0004:3: Disk partition / has only 0% free
 
Checking the disk space shows

  2. Update the user password again for sync to work
