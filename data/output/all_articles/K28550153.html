Description

This article describes the procedure to copy files from one VIPRION slot to another when there are no management IP addresses assigned to the slots.

Environment

  • VIPRION platform 
  • Slots do not have management IP addresses assigned
  • vCMP guest environments 

Cause

Support may need to see files from a particular slot of a vCMP guest or host running on a VIPRION platform. Typically, getting files from different slots on the host are easy as the slots usually have management IP's assigned to use with SSH. In a vCMP guest environment, it's common that management IP addresses are not assigned to slots on the guests. 

Recommended Actions

You can use the following procedure if you like to copy files from one slot to another on a VIPRION platform:

For this procedure, we made the following assumptions:

  • Support asked for a tarball of the logs from the guest on slot 2
  • Slot 1 is the active slot 
  • Slot 2 has the files we need
  • Slots 1 and 2 do not have IP address assigned on the guest
  1. SSH into management IP address of vCMP guest (this will connect you to the active slot of this device, slot 1 in our example)
     
  2. To change into bash shell from TMSH shell, type the following command:
    run /util bash
     
  3. To change into slot 2 of guest:
    ssh slot2
     
  4. Type the following command to change into /var/tmp directory:
    cd /var/tmp
     
  5. To create tarball of logs on slot 2, type the following command:
     tar -czvf slot2_log.tar.gz /var/log/* (this will put a tarball of the logs in /var/tmp directory called slot2_log.tar.gz)
     
  6. You can use the following command syntax to copy that tarball from slot 2 to the active slot (slot 1):
    scp slotX_filename.tar.gz root@slotY:/location_to_put_file

    For example, to copy tarball from slot 2 to the active slot (slot 1):, enter the following command:
     scp slot2_log.tar.gz root@slot1:/var/tmp (this will copy the tarball from slot2 to slot1 in /var/tmp)
     
  7. Retrieve this file to upload to the case
