K000133297: EdgeClient for Windows restarts VPN connection

Type
Support Solution
Published
2023-03-31
Updated
2025-04-16
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.0
Source
https://my.f5.com/manage/s/article/K000133297

Description

Users of F5 EdgeClient on Microsoft Windows report that their VPN connection through NetworkAccess does not stay connected.

Further inspection of the user's EdgeClient logs using the F5Report showed the following error:

2023-01-01,20:44:44:010, 45452,45456,DIALER, 2, \URDialer.cpp, 1807, CURDialer::OnTimer, :RasGetConnectStatus failed, 6 (0x6) The handle is invalid.

Or

2025-04-07, 7:48:04:998, 9328,9952,DIALER, 2, \URDialer.cpp, 1817, CURDialer::OnTimer, :RasGetConnectStatus failed, 6 (0x6) 控制代碼無效

Environment

  • Microsoft Windows 10 or 11
  • F5 EdgeClient
  • APM configured for NetworkAccess

Cause

There are potentially many different causes for this error message.

One of them is that Microsoft Windows sometimes erroneously determines that network connectivity is not available anymore and drops connections.

Recommended Actions

Try to disable the ActiveProbing feature by setting the following registry key to 0 and see if that resolves the issue:

HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\NlaSvc\Parameters\Internet\EnableActiveProbing = 0
