Description

The below audit_forwarder error log keep reporting without Radius communication issue.

err audit_forwarder[1665]: Dropped message: 184 State: PendingRecv

Environment

  • Radius authentication is in use 
  • Audit forwarder enabled

Cause

Bug ID 1194409

Recommended Actions

There is no negative impact on the system functionalities, apart from the incorrect logs. 

At the moment, there is no other way to stop these messages other than disabling audit logs.

Additional Information

You can verify if Radius is used by the audit_forwarder with the following command:

# tmsh list sys db config.auditing.forward.type value
