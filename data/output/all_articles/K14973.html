Known Issue

The BIG-IP system stores large numbers of incoming Address Resolution Protocol (ARP) packets that are never released, causing Traffic Management Microkernel (TMM) memory usage to grow.

This issue occurs when all of the following conditions are met:

  • You have one or more Virtual Local Area Network (VLAN) groups configured.
  • ARP requests are being broadcast on any of the VLANs in the VLAN group.

Impact

Performance may degrade over time, become unresponsive due to memory exhaustion, and eventually reboot.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H446700 on the Diagnostics > Identified > Medium | High screen.
  • The TMM memory utilization graph constantly grows.
  • The BIG-IP system may fail over to a host in the device group due to memory exhaustion.
  • The BIG-IP system unexpectedly reboots.
  • The TMM process may exit and generate a core file in the /shared/core directory.
