Known Issue

Having multiple Virtual Clustered Multiprocessing (vCMP) guests on a VIPRION chassis in an high availability (HA) configuration may cause an unstable data plane.

This issue occurs when all of the following conditions are met:

  • You deploy multiple vCMP guests.
  • You are using VIPRION chassis.
  • The VIPRION chassis is in an HA configuration.

Impact

Unstable data plane may cause traffic disruption and packet drops.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When multiple vCMP guests are deployed in an HA configuration with VIPRION chassis, the data plane cluster may become unstable. When this issue occurs, the BIG-IP system logs repeated log messages in /var/log/ltm similar to the following example:

    CDP: exceeded 1/2 timeout for PG 3
