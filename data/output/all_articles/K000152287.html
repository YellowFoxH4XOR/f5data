Description

Following error is generated while trying to configure SSL profile ciphers with keyword "aNULL" or "eNULL".

Jun  6 13:28:24 bigip.local err mcpd[5548]: 01070312:3: Invalid keyword 'enull' in ciphers list for profile /Common/my_clientssl
Jun  6 13:28:27 bigip.local err mcpd[5548]: 01070312:3: Invalid keyword 'anull' in ciphers list for profile /Common/my_clientssl

 

Here is example of client-ssl profile modification command that generated the errors. Error is generated while using keywords "aNULL" or "eNULL" on SSL profile cipher suites.

[root@bigip:Active:Standalone] config # tmsh modify ltm profile client-ssl my_clientssl ciphers 'DEFAULT:!aNULL'
01070312:3: Invalid keyword 'anull' in ciphers list for profile /Common/my_clientssl
[root@bigip:Active:Standalone] config #
[root@bigip:Active:Standalone] config # tmsh modify ltm profile client-ssl my_clientssl ciphers 'DEFAULT:!eNULL'
01070312:3: Invalid keyword 'enull' in ciphers list for profile /Common/my_clientssl
[root@bigip:Active:Standalone] config #

 

Similar error "cipher string is invalid" can also be seen while trying to use "aNULL" or "eNULL" on cipher rule object.

[root@bigip:Active:Standalone] config # tmsh modify ltm cipher rule my_cipher_rule cipher 'DEFAULT:!eNULL'
01071b80:3: Cipher rule (/Common/my_cipher_rule): cipher string is invalid.
[root@bigip:Active:Standalone] config #

 

 

Environment

Configure SSL profile ciphers with cipher string "aNULL" or "eNULL".

 

 

Cause

Keywords "aNULL" or "eNULL" is not valid cipher string on SSL profile.

 

Note: "aNULL" or "eNULL" is still valid and supported cipher string on Configuration Utility (GUI) httpd ssl-ciphersuite configuration, as described on K93500304.

 

 

Recommended Actions

Avoid using keywords "eNULL" or "aNULL" while configuring SSL profile ciphers option. "aNULL" cipher suites or "eNULL" cipher suites are both disabled by default and it is not necessary to add exclusion for either "aNULL" or "eNULL".

 

If you use cipher string 'ALL' or 'AES' to build your custom cipher lists, anonymous cipher suites may be enabled and you may want to explicitly disable anonymous cipher suites. To do so, you can use another keyword '!ADH', as described in K000130269.
