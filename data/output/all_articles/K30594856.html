Policy Information

F5 is announcing the End of Life (EoL) of the System Center Virtual Machine Manager (SCVMM) for network virtualization using generic routing encapsulation (NVGRE) gateway plug-in, effective June 15, 2016.

ProductVersion
BIG-IP11.5.2, 11.6.0 HF6, 11.6.1
BIG-IQ4.4.0, 4.5.0, 4.6.0 (Centralized Management), 1.0.0 (Cloud and Orchestration)
SCVMMWindows Server SCVMM 2012 UR4, UR9

Old Behavior

F5 introduced the SCVMM NVGRE gateway plug-in with BIG-IQ Cloud 4.4.0. This feature was designed to allow BIG-IP to be either a Hyper-V network virtualization (HNV) gateway or to provide Layer 4 through Layer 7 intelligence for inbound traffic.

Alternatives

Customers who want to deploy a gateway should leverage the Windows Server 2012 R2 inbox HNV gateway, or available solutions from appliance vendors providing this functionality.

Product Support

F5 plans to end support for the SCVMM NVGRE gateway plug-in, which applies to the following products:

Plug-in Support (beyond EoSD)

Once the EoSD date passes, customers can download the binary and source code for the plug-in from the F5 Github location. Until the EoTS date, F5 Technical Support will provide configuration support on only the original binary; F5 will not support any changes to the binary that is posted to Github.

Recommended Actions

F5 recommends that customers do not deploy BIG-IP as the Microsoft HNV NVGRE gateway in production environments.
