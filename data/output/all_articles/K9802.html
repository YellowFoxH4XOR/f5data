Topic

The FirePass Network Access configuration permits an administrator to configure DNS settings for the established Network Access SSL VPN connection. You can configure DNS settings in the Network Access: Resources: DNS tab. FirePass 5.5 and earlier used these configuration items to modify the Windows client system-wide TCP/IP settings, using the configuration that is  specified on the FirePass controller. While this behavior used the Network Access-specified DNS settings, the user required administrative rights to the client machine when Network Access was established.

Beginning in FirePass 6.0.2, the Enforce DNS Search Order feature allows the administrator to choose how DNS settings configured on the FirePass controller can be applied to the Windows client machine. When this option is cleared (disabled), a configured DNS server and/or domain suffixes are added as connection-specific settings to the client interface created for FirePass Network Access. The FirePass controller can make these changes without the user having local administrative privileges at the time Network Access is established.

However, if the Enforce DNS Search order feature is selected (enabled), these settings are added to the Windows system-wide TCP/IP settings, in addition to the connection specific interface. As a result, the FirePass controller reverts to the prior behavior and local administrative rights are required by the client machine when Network Access is established.

Beginning in FirePass 7.0, when you have enabled the Enforce DNS Search order in the Network Access configuration, and you have not defined any Network Access DNS Name server addresses, the FirePass controller uses the configured system-wide DNS Name server addresses that is configured in the Device Management: Configuration: Network Configuration: DNS tab. Releases prior to 7.0 did not fall back to the configured system-wide nameserver addresses for DNS resolution.

Note: This feature applies to only supported Windows client operating systems. This feature does not support Mac and Linux based systems.

Note: If this option is enabled, but the domain suffix is not configured, the FirePass controller uses the system-wide domain suffixes configured under the Device Management: Configuration: Network Configuration: DNS tab.
