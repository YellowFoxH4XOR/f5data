Description

You would like to know if it is possible to configure an FQDN instead of an IP address, when configuring a security logging profile.

Environment

  • Security log profile
  • Request logging

Cause

None

Recommended Actions

At the time of this article's publication you cannot specify an FQDN destination from within the security log profile directly.

If you would like F5 to add support for this feature in the future, please open a service request with F5 Support and reference this article.

As a workaround, you may configure a virtual server to deliver the logs to an FQDN destination:

  1. Configure a pool using an FQDN node
  2. Configure a virtual server, pointing to the pool
  3. Configure the security log profile destination using the virtual server's IP
