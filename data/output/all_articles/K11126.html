Known Issue

This is the result of a known issue. FirePass version 6.1.0 is unable to successfully restart services when a master group name contains a period character ( . ) in the group name. As a result, if a master group has a period in its name and you attempt to restart the FirePass controller's services, you will be unable to access the Administrative Console.

Important: Do not create master groups that include a period in the name.

You can view the master group names by navigating to Users: Groups: Master Groups. If any group names include a period, you must perform the following actions:

  • Delete the group name
  • Create a new group that does not include a period character
  • Install hotfix HF-610-1 prior to restarting services

Note: In the event that you have attempted a service restart when a master group name includes a period without the installed hotfix, refer to K10922: Recovering from a failed upgrade to FirePass version 6.1.0.

Important: As instructed in K10923: Upgrading to FirePass version 6.1.0, F5 recommends that you install hotfix HF-610-1 on all FirePass controllers upgraded to FirePass version 6.1.0

F5 Networks Product Development tracked this issue as ID 294196 (formerly CR133285) and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

This issue was fixed in cumulative HF-610-1 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
