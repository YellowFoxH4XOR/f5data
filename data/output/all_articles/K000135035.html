K000135035: OIDC Authentication with Azure AD Fails: Blank Page with Spinning Icon

Type
Support Solution
Published
2023-06-14
Updated
2023-06-14
Applies to
  • NGINX Products
  • NGINX Instance Manager: 2.10.0
Source
https://my.f5.com/manage/s/article/K000135035

Description

After setting up OIDC Authentication with Azure AD access to NMS ui fails with a blank page and a spinning icon in the middle of the page. Requests to /api/platform/v1/userinfo and /api/platform/v1/features fails with '404 Not Found' and '403 Forbidden', respectively. NMS logs (/var/log/nms/nms.log) reports the following ERROR log message:

Nginx-Management-Suite-User header is missing - cannot authenticate

Environment

NMS

Azure AD

Cause

Azure AD user properties does not contain a value for the Email attribute

Recommended Actions

Populate a value for the Email attribute in the Azure AD user properties
