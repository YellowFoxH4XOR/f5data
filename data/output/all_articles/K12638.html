Known Issue

This is the result of a known issue. Customized network access messages that contain a session variable will not display correctly on Apple OS X and Linux.

When a network access connection has a customized message configured on the Network Access : Resources : Customization tab, and the message contains a session variable (such as %session.user.username%), FirePass will not translate the message to show the contents of the session variable; instead, FirePass will display the literal name of the session variable.

For example, if the connection established message is configured to display Welcome %session.user.username%, the expected behavior is for Welcome John Smith to display. However, due to this known issue, Apple OS X and Linux users instead view the following message:

Welcome %session.user.username%

F5 Product Development is tracking this issue as ID 350621.
