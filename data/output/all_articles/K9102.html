Known Issue

This is the result of a known issue. When accessing the BIG-IP Configuration utility using a bookmark, your browser may return the following error message on a white background:

Major application error, please see logfile

In addition, a Java NullPointerException error message is logged to the /var/log/tomcat4/catalina.out file, appearing similar to the following example:

ERROR [Thread-17] controller.F5WebController:processWebResponse - Exception thrown in processWebResponse: java.lang.NullPointerException
java.lang.NullPointerException
at web.common.formredirect_jsp._jspService(formredirect_jsp.java:123)

For example, this issue can occur when you bookmark a page while running the Setup utility, and then attempt to access the Configuration utility using the same bookmark.

F5 Product Development is tracking this issue as ID 248959 (formerly CR97190).

Workaround

You can work around this issue by accessing the Configuration utility using the hostname or IP address, and navigating to the desired page.
