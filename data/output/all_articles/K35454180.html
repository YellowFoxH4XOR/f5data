Description

Error messages seen in the /ts/log/bd.log: attack_patterns_funcs.cpp:0597|Report to protobuf failed

Environment

  • JSON Content-Type in the Request
  • Event logs show a large number of Attack Signature violations
  • Attack Signature violations are False Positive

Cause

These log message are triggered when a large number of Attack Signature violations have been detected in a request.
This typically occurs where request would be treated as a form-data, however, the actual content would actually be JSON.
This causes ASM to parse the whole request against the Attack Signatures and triggers a number of false positives.
 

Recommended Actions

The recommendation is to review the policy configuration on the system to ensure that the correct header based content profiles have been applied.

To create a JSON profile and steps for associating a JSON profile with a URL, please refer to the procedure described in the Manual Chapter : Adding JSON Support to an Existing Security Policy (v15.x), or the same manual chapter for the software version installed on the BIG-IP.
 

Additional Information
You have manually added JSON support to the active security policy. The policy can now secure applications that use JSON for data transfer between the client and the server. If web application traffic includes JSON data, the system checks that it meets the requirements that you specified in the JSON profile.
