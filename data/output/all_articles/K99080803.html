Description
IPv4 clients are facing the issue of slow or timeout intermittently when trying to access via IPv4 network. If the client connects via IPv6 network, everything works just fine.

 intermittently slow to load : IPv4 client --> IPv4 network --> BIG-IP --> IPv6 server
 everything works fine       : IPv6 client --> IPv6 network --> BIG-IP --> IPv6 server

Environment

  • TCP profile with proxy-mss enabled(default)

Cause
Given an ingress interface IPv4 with an MTU of 1500 and an egress interface with an MTU of 1500, when using proxy-mss enabled we calculate and ingress_mtu of 1500 - (IPv6 header of 60 bytes - IPv4 header of 40 bytes) = 1480 on the ingress interface.

Therefore we will determine ingress packets of 1500 as too big and will send an ICMP unreachable - need to frag (mtu 1480).

Recommended Actions

  1. Disable proxy-mss in TCP profile.
  2. If step 1 does not work, change mss value to 1440 in TCP profile.
