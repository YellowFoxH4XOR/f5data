K44237211: ifInDiscards OID should NOT be used for VLAN.

Type
Support Solution
Published
2023-02-21
Updated
2026-09-18
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K44237211

Description

ifInDiscards should be used only for the physical interfaces, as ifInDiscards is not suitable for VLAN. It's an issue that VLAN is also shown as "ethernetCsmacd(6)" like a physical interface.

Environment

  • SNMP OID .1.3.6.1.2.1.2.2.1.13 is used for value of interface discards.
  • You can observe the discard count even though VLAN or physical interface does not have drops count from output of command 'tmsh show /net vlan' or ifconfig.

Cause

It is difficult to tell which interfaces are VLANs in the ifTable. so the discard value of the VLAN is not correct to set. 

Recommended Actions

ifInDiscards is not suitable for VLAN so please monitor ifInDiscards only for the physical interfaces.

  1. Replace OID to 1.3.6.1.4.1.3375.2.1.2.13.6.2.1 for VLAN drop count.

    [root:Standby:Disconnected] config # snmpwalk -c public -v2c localhost 1.3.6.1.4.1.3375.2.1.2.13.6.2.1
    F5-BIGIP-SYSTEM-MIB::sysVlanStatDropsIn."/Common/vlan_ha" = Counter64: 0  <<<<<<---------!!
    F5-BIGIP-SYSTEM-MIB::sysVlanStatDropsIn."/Common/vlan_external" = Counter64: 0 <<<<<---------!!
    F5-BIGIP-SYSTEM-MIB::sysVlanStatDropsIn."/Common/vlan_internal" = Counter64: 0 <<<<<---------!!
