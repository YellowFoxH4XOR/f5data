K000133285: You can not see the data plane CPU statistics on F5 r2000/r4000 Series tenant dashboard

Type
Support Solution
Published
2023-03-31
Updated
2024-11-19
Applies to
  • rSeries Platforms
  • BIG-IP
  • rSeries 4000
  • rSeries 2000
  • BIG-IP LTM: 15.1.7, 17.1.0, 15.1.8, 17.1.X, 15.1.6
Source
https://my.f5.com/manage/s/article/K000133285

Description

  • You can not find the CPU usage with the data plane statistics on the F5 r2000/r4000 Series platform tenant's dashboard.

Environment

  • r2000/r4000
  • Tenant
  • Dashboard
  • Data plane and Control plane CPU

Cause

The separate control plane and data plane statistics in the dashboard are only used for the HTSplit feature-enabled platforms.

Based on the K000133171, we know that F5 r2000/r4000 CPUs do not support the HTSplit feature, so it is expected behavior that you can not see the data plane CPU statistics in the tenant's dashboard on the F5 r2000/r4000 Series platform.

 Recommended Actions

You may use the tmsh command tmsh show sys performance system detail to check the CPU statistics, for details please check K04191163 .

Additional Information

You also should not see the control plane CPU statistics in the tenant's dashboard on the F5 r2000/r4000 Series Platforms, but under the impact of the known bug ID969329, you still can see the control plane CPU statistics from the tenant's dashboard on the F5 r2000/r4000 Series Platforms.
