K000149762: A temporary file will appear when you execute the edit command

Source

Description

When the user edits the configuration file to follow the article like K13333, the temporary file will appear.

At that time, the temporary file "/var/system/tmp/tmsh/*/data" is created for editorial.

When the user saves it, the temporary file will be removed and then the configuration file will be updated.


Environment

v16.x or higher


Cause

This is design by default.


Recommended Actions

None

 

Additional Information

It will have the same result that is not only to edit Syslog but also execute the command edit /sys *.
