Description

After pushing an AS3 declaration to BIG-IP, the following error message is returned which is also logged in /var/log/restnoded/restnoded.log

severe: [appsvcs] {"message":"Declaration failed: 01070083:3: Monitor /partition/application/tcp is in use.","level":"error"}

Environment

  • AS3 declaration
  • BIG-IP

Cause

Bug 1195533

Recommended Actions

Update to AS3 3.52 where this issue is fixed

Additional Information

To workaround the issue:

  1. Manually remove the offending monitor on BIG-IP
  2. Re-POST the AS3 declaration
