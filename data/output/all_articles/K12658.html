Known Issue

This is the result of a known issue. Users accessing Domino Web Access (DWA) with Internet Explorer may be unable to expand the right sidebar, and may receive one of the following error messages:

A script on this page is causing Internet Explorer to run slowly

JS error: Message: Could not load 'ibm.iNotes.widget.layout.DWASidebarContainer'; last tried '../ibm/iNotes/widget/layout/DWASidebarContainer.js'

In addition, the user may not receive an error message, but the right panel appears blank. This issue does not occur if the user accesses DWA with Firefox.
