Known Issue

Description

BIG-IP APM access policy Lightweight Directory Access Protocol (LDAP) queries may fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system access policy is configured with the LDAP Query agent object.
  • The LDAP query agent is configured to fetch nested groups.
  • The LDAP query attempts to retrieve group membership for a user that belongs to a group from a foreign domain.

Impact

The BIG-IP APM LDAP query agent fails, and user access sessions may fail to establish.

Symptoms

As a result of this issue, you may encounter one or more of the  following symptoms:

  • The system logs messages similar to the following example in the /var/log/apm file:

    err apd[<pid>]: 01490235:3: <session_id>: LDAP Module: Failed to make ldap_search in 'CN=[<cn>] Deploy MDM,OU=<ou>,DC=<host>,DC=<domain>,DC=<com>' with filter '' and scope '0'. Referral, 0000202B: RefErr: DSID-03100747, data 0, 1 access points ref 1: '<host.domain.com>'
  • The LDAP query agent fails after an upgrade to BIG-IP 11.6.0.
