Known Issue

The bigtop utility may fail to include Packet Velocity ASIC (PVA) statistics when reporting the throughput statistics for the BIG-IP system. This issue occurs when the following condition is met:

  • The pva.acceleration database variable is set to full.

    Note: The pva.acceleration database variable is set to full by default. Do not modify the value for this database variable unless recommended by F5 Support.

Impact

The bigtop utility reports incorrect throughput values.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In bigtop utility output, the values in the bits in prior <x> seconds column for the virtual servers do not add up to the values in the same column for the BIG-IP system.

    For example:

    | bits since | bits in prior | current
    | Jul 31 23:32:39 | 10 seconds | time
    BIG-IP ACTIVE |---In----Out---Conn-|---In----Out---Conn-| 00:27:40
    VIP2400-R47-S40.lab.ss.example.com 17.20G 16.72G 12.91M 52.35M 33.76M 52746

    VIRTUAL name |---In----Out---Conn-|---In----Out---Conn-|-Nodes Up--
    /Common/example_page_2012 20.81G 25.17G 8.620M 129.1M 143.6M 50283 4
    /Common/example_page_2012_5001 10.88G 12.29G 4.291M 0 0 0 4
