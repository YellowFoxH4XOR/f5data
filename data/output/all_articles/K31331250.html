K31331250: After RMA of blade in host all guests starting up with old version

Type
Support Solution
Published
2022-08-11
Updated
2023-02-21
Applies to
  • VIPRION Platforms
  • BIG-IP
  • BIG-IP LTM: 15.1.5
Source
https://my.f5.com/manage/s/article/K31331250

Description

After replacement of Viprion blade and failover to second blade, all guests revert to old version

Host's ltm log:

Jul 20 00:03:19 slot1 notice vcmpd[28846]: 01510006:5: Guest (guest1): Installing image (/shared/images/BIGIP-13.1.0.6-0.0.3.iso) to VDisk (/shared/vmdisks/guest1.img).

Environment

  • Blade in chassis was replaced and after failover to other blade, all guests started with old version
  • BIG-IP
  • Viprion

Cause

This is cause because the guests are installed on only one blade - the one that was replaced
vcmp guest guest1 {
    allowed-slots { 1 2 3 4 }
    assigned-slots { 1 } <<<
    cores-per-slot 12
    hostname host1
    initial-image BIGIP-13.1.0.6-0.0.3.iso <<<

Recommended Actions

Prior to replacement of blade in chassis, make sure that all guests are deployed on at least an additional blade that is not about to be replaced
