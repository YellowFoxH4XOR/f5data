Description

         Alarm LED Is Blinking on rSeries or VELOS Devices

 

Environment

  • rSeries device
  • VELOS device

 

Cause

  • Presence of historical alarms in the device.
  • We can view the alarms by running the command show system alarms ( to be run in CLI using admin credentials). 
    Below is an example of the output seen.

           

     appliance-1# show system alarms

     ID     RESOURCE      SEVERITY  TEXT                                       TIME CREATED
     ---------------------------------------------------------------------------------------------------------------
     262401 Portgroup 1   ERROR     Lanes: 1,2,3,4 Receiver power low alarm   2024-12-13 17:42:49.367753024 UTC
     263169 interface-4.0 WARNING   Interface down                             2025-01-07 09:43:XX.XXXXXX UTC
     262401 Portgroup 4   ERROR     Lanes: 1 Receiver power low alarm          2025-01-07 09:44:XX.XXXXXX UTC
     263169 interface-3.0 WARNING   Interface down                             2025-01-07 09:55:48.545225653 UTC
     262401 Portgroup 3   ERROR     Lanes: 1 Receiver power low alarm          2025-01-07 09:56:XX.XXXXXX UTC

 

 

Recommended Actions

 

  • To turn off the LED, we need to clear the alarms present in the device.
  • Edit the below docker command based on the alarm details seen ( while running the 'show system alarm' command ) and run it in the CLI ( with root credentials).
     docker exec alert-service /confd/test/sendAlert -n "<ALERT_NAME>" -s "<RESOURCE>" -i <ALERT_ID> -d "<DESCRIPTION>" -r clear -se <SEVERITY>

 

  • To edit the above docker command we need to understand the output from 'show system alarms'

    Understanding the Alarm Output

    First, identify the alarm details from show system alarms:

    # show system alarms
ID      RESOURCE        SEVERITY  TEXT                                 TIME CREATED
----------------------------------------------------------------------------------------------------------
262401  Portgroup 3     WARNING   Lanes: 1 Receiver power low warning  2025-01-30 09:14:50.550560474 UTC
↑       ↑               ↑         ↑
AlertID Source          Severity  Event description

Note: Only clear alarms if you've verified the underlying issue is resolved. Clearing alarms doesn't fix the actual problem—it only removes the notification.
