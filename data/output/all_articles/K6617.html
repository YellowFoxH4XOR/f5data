Known Issue

This is the result of a known issue. If the BIG-IP GTM system receives a request with an LDNS persistence record referring to a non-existent pool, the gtmd process will core dump.

F5 Product Development tracked this issue as CR68140 and it was fixed in BIG-IP GTM 9.2.4. For information about upgrading, refer to the BIG-IP GTM Release Notes.
