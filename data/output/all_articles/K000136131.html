Topic

The default TACACS Profile on Cisco ISE does not work for F5OS

 

Description

If we look at the documentation:

MyF5 Home / Knowledge Center / VELOS Systems: Administration and Configuration / User Management

We see that an F5 User needs to be assigned user attributes:

 

F5-F5OS-UID=1001
F5-F5OS-GID=9000 <-- THIS MUST MATCH /etc/group items
F5-F5OS-HOMEDIR=/tmp <-- Prevents sshd warning msgs
F5-F5OS-USERINFO=test_user <-- Optional user info
F5-F5OS-SHELL=/bin/bash <-- Ignored; always set to /var/lib/controller/f5_confd_cli

 

Recommended Actions

If we look at a TACACS Profile in Cisco ISE, we need to add the Custom Attributes as follows:
 



If we look at the overall TACACS Profile page, we see there is an option for Task Attribute View or Raw View.
If we change the option to Raw View, we can simply paste the following text:

F5-F5OS-UID=1001
F5-F5OS-GID=9000
F5-F5OS-HOMEDIR=/tmp

This TACACS Profile just needs to be assigned to any user/device combination that is required to login to F5OS.
