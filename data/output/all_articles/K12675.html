Topic

The BIG-IP native SSL/TLS stack is compatible with the False Start feature, as defined in section 3 of the False Start internet-draft. As a result, a virtual server that references an SSL profile with the DEFAULT cipher string is able to complete handshakes with a peer system that implements False Start.

False Start is an optional Transport Layer Security (TLS) feature used by some web browsers to shorten the message flow during the TLS handshake. The TLS False Start internet-draft specifies that a client can send application data when the TLS handshake is only partially complete; when the client completes its side of the TLS handshake by sending its ChangeCipherSpec and Finished messages, it does not have to wait for the peer's ChangeCipherSpec and Finished messages before sending data.

Note: The BIG-IP compat SSL/TLS stack is not compatible with the False Start feature. For more information, refer to K12676: The BIG-IP compat SSL stack is not compatible with TLS False Start.

Note: For information about using SSL ciphers with the BIG-IP system, refer to K8802: Using SSL ciphers with BIG-IP Client SSL and Server SSL profiles.
