K000153101: APM On-Demand Cert Auth and the certificate pop-up window on the client side

Description

When the "On-Demand Cert Auth" is configured in an APM policy, and the end users try to connect to the virtual server applied with the APM policy, a window will pop up to choose the certificate for authentication. This article will discuss the conditions under which a window will pop up or not.


Environment

BIG-IP APM

On-Demand Cert Auth


Cause

When the user is connected to an APM policy where the On-Demand Cert Auth is configured, the prompt or pop-up window for a user to select a certificate to present for authentication depends on the settings on the APM and the client machine.


Recommended Actions

On APM:

  • Client SSL profile:

Trusted Certificate Authorities --> This is mandatory, and the cert here is to verify the client certificate

Advertised Certificate Authorities --> optional, be aware of the maximum size if configured.


  • On-Demand Cert Auth in APM policy

Auth Mode: Request --> only pop up when there are multiple certs matching the CA

Auth Mode: Require --> will pop up a window to choose the cert


On the end-user side:


  • Make sure the website is added to the 'Trusted sites, otherwise, the window for cert selection will pop up

Internet Options - Security - Trusted sites 


  • Make sure a valid certification & key is installed on the machine:

Open "Manage user certificates" or "certmgr.msc"- Current User, and check the certs under "Personal";

Also, verify it under Internet Options - Content - Certificates - Personal. If no cert under here, then check if the key was imported.


  • When only one cert matches the CA on the machine, then no pop-up window; otherwise, the user will be prompted to choose the cert from a pop-up window.
