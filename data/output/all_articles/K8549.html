Known Issue

This is the result of a known issue. In BIG-IP versions 9.4.2 through 9.4.8 you must use the bigpipe syslog include command to configure more than one remote syslog server.

Note: For more information, refer to K8259: The bigpipe syslog remote server command may only be used to add a single remote UDP syslog server.

Configuring an additional remote syslog server using the bigpipe syslog include command causes the system to log the following error message to the /var/log/boot.log file each time you restart the syslog-ng utility:

syslog-ng: Macro escaping can only be specified for inline templates

This error message is benign and is generated because syslog-ng requires a message template to be defined before it can attempt to escape certain characters.

F5 Product Development tracked this issue as CR88600 and it was fixed in BIG-IP LTM version 9.6.1. For information about upgrading, refer to the BIG-IP LTM release notes.

Note: The BIG-IP LTM version 9.6 software branch is specific to the VIPRION platform. If you are running BIG-IP software on a platform other than VIPRION, you cannot upgrade to version 9.6 software.
