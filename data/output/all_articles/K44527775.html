Issue

Error Message

notice chmand[<PID>]: 012a0047:5: Chassis power module 2 turned on.

In this error message, note the following:

  • <PID> is the process ID for the chmand process.

For example:

notice chmand[10013]: 012a0047:5: Chassis power module 2 turned on.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The chassis power module 2 is turned on.

Impact

None

Recommended Actions

None
