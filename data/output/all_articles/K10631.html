K10631: Allow lists for Web Application Tunnels are not fully restored from backup

Known Issue

This is the result of a known issue. When restoring the FirePass configuration from a backup file, only the first line of a Web Application Tunnel Allow list is restored.

For example, if you configured a Web Application Tunnel with the following Allow list:


www.example.com:80

login.example.com:80

login.example.com:443

the Allow list will be restored from the backup file as:

www.example.com:80

Additionally, this issue can occur after installing or removing a hotfix.

F5 Networks Product Development is tracking this issue as ID 296520 and ID 297309 (Formerly CR127289).

Workaround

You can work around this issue by defining resource group Allow lists on the Application Access : App Tunnels : Resources page under the Web Application Tunnels tab instead of defining an individual Allow List for each resource.

Note: This workaround does not decrease security, since individual App Tunnel Allow Lists are applied to all App Tunnel Favorites assigned to a user. For more information, refer to K7894: Individual App Tunnel Allow Lists are applied to all App Tunnel Favorites assigned to a user.
