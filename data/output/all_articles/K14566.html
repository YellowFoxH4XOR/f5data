Known Issue

The High-Speed Bridge (HSB) may lock up when using certain VLAN group configurations.

This issue occurs when the following conditions are met:

  • The vlangroup.flow.allocate db variable is disabled.
  • The system receives a packet larger than the VLAN's MTU.

The vlangroup.flow.allocate db variable is enabled by default and allows the system to forward packets between VLAN group members.

Impact

This issue may cause the BIG-IP system to trigger a failsafe event, and subsequently restart.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H426383 on the Diagnostics > Identified > Medium screen.
  • This issue may cause the BIG-IP system to trigger a failsafe event, and subsequently restart.
  • In the /var/log/ltm file, you may observe error messages similar to the following examples:

    tmm1 crit tmm1[8052]: 01230111:2: Interface 0.2: HSB DMA lockup on transmitter failure.
    tmm3 crit tmm3[8054]: 01230111:2: Interface 0.4: HSB DMA lockup on transmitter failure.
    notice overdog[5041]: 01140029:5: HA nic_failsafe tmm1 fails action is reboot.
    emerg overdog[5041]: 01140043:0: Ha feature nic_failsafe reboot requested.

Workaround

To work around this issue, you can enable the vlangroup.flow.allocate db variable. To do so, perform the following procedure:

Impact of workaround: Enabling the vlangroup.flow.allocate db variable allows the system to forward packets between VLAN group members.

  1. Log in to the Traffic Management Shell (tmsh) utility.
  2. Enable the vlangroup.flow.allocate variable by typing the following command:

    modify /sys db vlangroup.flow.allocate value enable

  3. Save the configuration by typing the following command:

    save /sys config
