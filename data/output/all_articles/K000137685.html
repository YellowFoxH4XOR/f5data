K000137685: BIGIQ ASM import error "protocolIndependent is set only once, and should not be changed. Existing value: false, New value: "."

Type
Support Solution
Published
2023-11-24
Updated
2023-11-24
Source

Description

You get below were when trying to Import AWAF config from BIGIQ


"Failed to copy configuration to working-config; reason: Policy '<ASM_policy_name>': protocolIndependent is set only once, and should not be changed. Existing value: true, New value: false"


Environment

BIGIQ Import

AWAF policy


Cause

The reason why it's not allowed to be imported into BIG-IQ is that previously the Security Policy had protocolIndependent set to True, which means that the Policy contained URL's with the protocol specified eg http, https, ws, wss etc. and BIG-IQ is not be able to resolve this conflict.


Recommended Actions



  1. BIG-IP GUI: Security ›› Application Security : Security Policies : Policies List : select Policy > General Settings > Advanced Settings > Differentiate between HTTP/WS and HTTPS/WSS URLs > Select Enabled
  2. Click Save
  3. Click Apply Policy

Additional Information

https://clouddocs.f5.com/products/big-iq/mgmt-api/v7.0.0/ApiReferences/bigiq_public_api_ref/r_asm_policies_60.html


protocolIndependent Does the user want to allow for protocol independent URLs? True / False optional


True = enabled

False = disabled


It's best to delete the ASM policy from BIG-IQ if you ever need to modify the Language, case sensitivity and protocol independence settings.
