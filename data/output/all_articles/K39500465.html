Known Issue

Displaying virtual server statistics may cause an mcpd process memory leak.

This issue occurs when the following condition is met:

  • You routinely use the Configuration utility or the Traffic Management Shell (tmsh) to display virtual server statistics over a period of uptime.

Impact

Over time, system performance may degrade, and the system may eventually become unresponsive or reboot due to memory exhaustion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The amount of memory that mcpd uses progressively increases.
  • You are unable to configure the BIG-IP system.
  • Your BIG-IP system fails over to another device in the device group.
  • Your BIG-IP system generates a mcpd core file to the /shared/core directory.
