Description

DNS functionality fully or partially not working.
Configuration Utility shows no DNS object.
Configuration file /config/bigip_gtm.conf has default configuration only.

Environment

  • You are upgrading GTM/DNS device to version 13.1.0 or higher
  • You are upgrading GTM/DNS device:
    • Without re-activating the license
    • With an expired license
  • You are rebooting device with expired license

Cause

Due to bug ID847105, GTM/DNS configuration is reverted back to default if the box is upgraded with a license that is either expired or has not been re-activated.

Important: K7727: License activation may be required before a software upgrade for the BIG-IP or Enterprise Manager system

Recommended Actions

Refer to ID847105 for workaround.
