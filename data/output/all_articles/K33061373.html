Description
After loading UCS file, navigating to SSL Orchestrator >> Configuration is unable to display the SSLO Guided Configuration page and shows the following error:

Server Error!
The iApp LX sub-system is currently unresponsive. The JavaScript sub-system is currently unavailable.
Please open TMSH or ssh shell and try restarting restnoded. Also look for errors in /var/log/restnoded/restnoded.log

Environment

  • F5 SSL Orchestrator
  • Loading UCS file
  • GUI : SSL Orchestrator >> Configuration

Cause
BUG ID 835161

Recommended Actions

• If you are running v14 and v15,  try to restart restnoded and restjavad processes (workaround of BUG ID 835161)
# bigstart restart restnoded restjavad

• If it doesn't fix the issue, you may need to extract more memory.
# tmsh modify sys db provision.extramb value 2048
# tmsh modify sys db provision.tomcat.extramb value 512
# tmsh modify sys db restjavad.useextramb value true
# bigstart restart restjavad && sleep 20 && bigstart restart restnoded

• If the issue is still not resolved, try clicking "Reload Page" in iApps >> Application Services >> Applications LX
