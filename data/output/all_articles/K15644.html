Known Issue

The BIG-IP system may fail to process traffic for all existing subscribers. This issue occurs when all of the following conditions are met:

  • You configured the Client Connection Limit setting to a value greater than zero for the affected LSN pool.
  • The number of existing connections processed by the active system for each subscriber is closed to the configured value for the Client Connection Limit setting.
  • A failover occurs and the standby BIG-IP system takes over as the active unit.

Impact

Traffic is disrupted for all existing subscribers after a failover.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H480220 on the Diagnostics > Identified > High screen.
  • All existing subscribers are unable to connect after a failover occurs.
  • The lsndb list client command output shows the connection counts are at the limits for each subscriber.
  • The BIG-IP system sends an RST packet to the subscriber with the following reset cause:

    Translation address not found
