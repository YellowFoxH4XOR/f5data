Description

When adding a BIG-IP to a BIG-IQ device an error messages similar are logged:

/var/log/restjavad.0.log:

[/cm/global/tasks/device-trust/94ebbe30-ba7b-4de8-b14d-dac49a94acc9/worker BigIPTrustTaskWorker] Failed to connect to 10.10.10.1, check credentials: Unauthorized(401)

/var/log/restjavad-audit log:

[ForwarderPassThroughWorker] {"user":"local/null","method":"GET","uri":"http://localhost:8100/mgmt/shared/identified-devices/config/device-info","status":401,"from":"<>"}

Environment

  • BIG-IQ 
  • BIG-IP

Cause

ID1146373.

Basic authentication for rest admin account failing when client address is sent null to /usr/bin/pam-authenticator.

Recommended Actions

  1. Check if communication using port 22 and 443 is working on both directions, you can use telnet to test.            
  2. Verify any FW or ACL, in path between BIG-Ip and Big-IQ, is not blocking TCP ports 22 and 443.
  3. Check if local admin account is configured on BIG-IP
  4. Please login to the BIG-IP command line as "root", run the following commands from bash:
        clear-rest-storage
        bigstart restart restjavad
Important: Do not run this command on devices that have SSLO provisioned and configured. Contact F5 Support for further assistance.
