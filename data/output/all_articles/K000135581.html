Description

When checking from the BIG-IP Configuration utility, you notice that some modules are missing.

 

For instance, in the case of APM or ASM, the Access menu, as well as, its associated sub-menus are missing from the GUI.

 

Environment

  • BIG-IP Configuration utility
  • BIG-IP product modules
  • Resource Provisioning

Cause

The most likely reason why a certain module is 'missing' from the web GUI, is that it is licensed but not provisioned.

 Recommended Actions

Check to make sure that the concerned BIG-IP module is provisioned

(System ›› Resource Provisioning)

 

If the issue still persists even after provisioning the said module, contact F5 Technical Support for further technical assistance.
