K000138205: ip route command showing egress traffic using lcdusb0 interface

Type
Support Solution
Published
2024-01-11
Updated
2024-01-11
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.9
Source
https://my.f5.com/manage/s/article/K000138205

Description

Under certain conditions, it is possible for BIGIP software to report the interface for egress traffic to use lcdusb0 or some other unexpected interface. This is a display issue only and does not affect the operation of egress traffic from the BIGIP. 

Environment

  • Route Domains
  • ECMP BGP routes on non-default route domain

Cause

On non-default route domains with ECMP(Equal Cost Multi-Path) BGP(Border Gateway Protocol) the BIGIP might report that it will use ucdlcd0 or some other unexpected physical interface for egress traffic for default gateway. ECMP traffic correctly followed the Advanced Routing path in BIGIP software using the zebra route, making this a display issue only.

Example:

root@BIGIP-A:Active:Standalone] config # rdexec 2 ip route get 8.8.8.8
8.8.8.8 via 127.1.1.253 dev lcdusb0  src 127.1.1.254  <-- Notice the lcdusb0 interface


 
ID1400189 has been created to track this issue.

Recommended Actions

Being a display issue only, there are no recommended actions.
