K000138391: DNS Express responds with a malformed packet

Type
Support Solution
Published
2024-01-29
Updated
2024-01-29
Applies to
  • BIG-IP
  • BIG-IP DNS: 15.1.10
Source
https://my.f5.com/manage/s/article/K000138391

Description

When running NSLOOKUP to the DNS listener, the response is "Can't Find" with a malformed packet

  • Using NSLOOKUP to query the DNS listener for a resolution
  • DNS response is not given using NSLOOKUP, however DIG works as intended
  • "Warning: Message parser reports malformed message packet"

Environment

DNS module utilizing DNS EXPRESS

  • Not using DNSSEC
  • DNS Listener with default DNS profile

Cause

Malformed DNS express responses are received when the UDP size limit is set to exactly 512 and a zone is signed with algorithm 13

Recommended Actions

Contact F5 Support for an ENGHF to resolve the issue

 

Additional Information

Bug ID 1137217: DNS profile fails to set TC flag for the responses containing RRSIG algorithm 13
