Description

You want to configure an advance external SMTP monitor.

Environment

  • BIG-IP
  • SMTP
  • Monitor
  • Script

 

Cause

You want to configure an advance external SMTP monitor that provides more flexibility in the monitor's query

Recommended Actions

  1. Using a text editor create a script file (shell / Perl, Python, etc.) that will perform the SMTP query, e.g:

    #!/bin/sh
    ncat ${node_ip} ${port} < ${input_file} | grep ${RECV}
    Important: The variable names of node_ip, port, input_file and RECV will be utilized by the BIG-IP as part of the monitor.


  2. Create an input text file for the script
    EHLO hostname
    MAIL FROM: sender@example.com
    RCPT TO:  recepient@example.com
    DATA
    From: Sender <sender@example.com>
    To:  Recipient <recepient@example.com>
    Date: date
    Subject: A test message from hostname
    This is a test
    .
    QUIT

    Note: The script’s return value is 0 when the command’s response is true (having the string PIPELINING as an output) and 1 if it is false. The script is expecting to have the string PIPELINING in the response and base on this to determine if the query succeeded or not.

    # nc 192.168.80.27 25 < mail.txt | grep PIPELINING
    250-PIPELINING
    # echo $?
    0
    # nc 192.168.80.27 25 < mail.txt | grep example  
    # echo $?
    1
  3. Upload the script and the SMTP input files to the BIG-IP LTM system System > File Management : External Monitor Program File List
  4. Click on Import and import the script file to the BIG-IP




    Note: In case that you need to modify/update the script, you should do it from the same location on the BIG-IP.
  5. Associate the script and the with the monitor by creating an  External monitor (type External)
  6. In the External Program choose the script that you uploaded
  7. Create Variables matching the variables that are in the script (node_ip, port, input_file, RECV) and add values:




  8. The rest of the settings should be configured the same way that you are configuring a monitor
  9. Associate the monitor with a pool
