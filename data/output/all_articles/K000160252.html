Description

When accessing the Setting -> About configuration page in BIG-IP DDoS (version 17.1.3), a persistent GUI error banner (red triangle with minus sign) appears. Along with the banner There is no optionality for DHD application installation in the "Install Method". This does not have an impact on the traffic and can be observed after an upgrade to version 17.1.3 or 17.5.1.x.

Environment

  • Product: BIG-IP DDoS
  • Version: 17.1.3, 17.5.1.x
  • DHD

Cause

The behavior is due to the following bug IDs:

  • Bug ID2138229: DHD GUI is not properly rendering, resulting in an empty error banner.
  • Bug ID2183781: DHD RPM package is missing or mismatched in version 17.1.3.

ID2183781 refers to the RPM package for DHD which remains in the previous version hence the behavior. The command below can be used to verify the version. 

#tmsh list /mgmt shared iapp installed-packages

Answer/Recommended Actions

Open a case with f5 support to verify the behavior and request for EHF.

Additional Information

  • The error is cosmetic and does not affect production traffic.
  • The EHF resolves both the GUI rendering and RPM package version issues.
