Known Issue

Configuration synchronization (ConfigSync), using IPv6 addressing, fails to complete and generates an error message.

This issue occurs when all of the following conditions are met:

  • You configure multiple BIG-IP devices in a device group.
  • You configure the BIG-IP device group members to use IPv6 addresses for ConfigSync operations.
  • You attempt to synchronize the configuration between BIG-IP devices in the device group.

Impact

You are unable to synchronize configuration objects between BIG-IP devices in the device group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to synchronize the BIG-IP configuration, you view error messages in the /var/log/ltm file that appear similar to the following examples:

    err mcpd[5269]: 01071392:3: Background command '/usr/bin/rsync --rsync-path=/usr/bin/rsync -at --blocking-io  /var/named/config/  rsync://fd88:8888:1:f5::1/var_name' failed. The command exited with status 10.
    err mcpd[5269]: 01071392:3: Background command '/usr/bin/rsync --rsync-path=/usr/bin/rsync -at --blocking-io  /config/big3d/  rsync://fd88:8888:1:f5::1/big3d' failed. The command exited with status 10.
  • You cannot synchronize configuration objects between BIG-IP devices in the device group.

Resolution

Status

F5 Product Development has assigned ID 451479 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles
Release11.6.0K2200: Most recent versions of F5 software
Hotfix11.2.1 HF11K9502: BIG-IP hotfix matrix

Workaround

To work around this issue, you can configure the BIG-IP device group members to use IPv4 addresses for ConfigSync operations.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
