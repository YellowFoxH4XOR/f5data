K25319915: Enable or disable the access policy based on the SAML URI.

Type
Support Solution
Published
2020-11-12
Updated

Applies to

Source

Description

When using Access Policies with SAML SP authentication before the APM Logon Page, it should exist the SAML IDP authentication prompt request, to improve the Virtual server the Access Policies can be optimized and disable or enable the Access policy only if there is a specific URI.

Environment

  • Access Policy
  • SAML

Cause

Normally, SAML uses a URL like this "/saml/sp/profile/post/acs" in the process of authentication, which is not defined in the URL based pool selection iRule that comes with the iApp. So it goes to the default, which is ACCESS:disable

Recommended Actions

Adding next switch case for SAML before the default:

   switch -glob [string tolower [HTTP::uri]] {
       "/saml/sp/profile*" {
          ACCESS::enable
       }
   default {
         ACCESS::disable
      }
   }


Note: The URL may change depending on the design/configuration, but same solution.
