Description

LDAP authentication is not working for CLI access; however in the case of BIG-IQ, GUI authentication works fine. You observe the following logs in /var/log/secure:

err sshd[1560]: error: PAM: Authentication failure for SOME_LDAP_USER from 10.0.0.1
err sshd[1560]: error: Received disconnect from 10.0.0.1 port 45837:13: The user canceled authentication.  [preauth]
err sshd[21238]: pam_ldap(sshd:auth): error reading from nslcd: Connection reset by peer

Note: The specific error message error: PAM: Authentication failure is a generic authentication failure error that can also occur with local authentication. When it appears in conjunction with pam_ldap error messages, it is related to LDAP authentication.

Environment

  • LDAP authentication configuration
  • BIG-IQ CLI 
  • BIG-IP CLI

Cause

Incorrect configuration.

Recommended Actions

Make sure that your bind-pw password value is set up correctly, you can get your bind-pw password from your LDAP server administrator.
