Description

Your request has been blocked by ASM with the reason of "<file type> file exceeding URL length limit" and triggered the violation of "Illegal URL length".

However, in your ASM Policy, that file type is not set as "Allowed File Types" or "Disallowed File Types", and you think there shouldn't be any length restriction for that file type.

Environment

  • BIG-IP ASM

  • File Type

  • Illegal URL length

Cause

This is expected behavior, the request hit wildcard file type whose URL length is by default limited to 100.

Recommended Actions

Please consider defining a specific allowed file type for the request, and set the "URL Length" to an expected value to avoid the violaiton.
