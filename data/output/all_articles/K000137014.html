K000137014: Unable to manage or see Chassis Partitions from VELOS Controller GUI - An internal error occurred

Type
Support Solution
Published
2023-09-27
Updated
2023-09-27
Applies to
  • F5OS
  • F5OS-C: 1.5.X, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000137014

Description

Unable to manage or view Chassis Partitions and blades from VELOS GUI.

Error appears:

Server Error(s)
An internal error occurred. Please try again later. If the problem persists, contact technical support for assistance.
error-message: An internal error occurred. Please try again later. If the problem persists, contact technical support for assistance.
original-error: Network Error

Blades are not visible underneath Chassis Partition Overview.

Using browser developer tools reveals some requests to /api/data/openconfig-platform:components result in an error or incomplete response.

Environment

  • VELOS
  • Controller GUI

Cause

Bug ID 1165973: Application error while using the CLI command "show components"

This issue can occur when the system has a faulty sensor.

Recommended Actions

Troubleshooting should focus on the faulty sensor. The GUI issue is simply a side effect of that.

Additional Information

The error described in this article's Description is a generic one that can occur under other conditions.
