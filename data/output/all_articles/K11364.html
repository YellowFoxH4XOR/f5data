Known Issue

This is the result of a known issue. The default Flow Control setting for an interface is Pause TX/RX. If you change the value to a non-default setting, such as None, the interface will transition to down and then up following a configuration load.

When this issue occurs, the interface will be marked down for a short period of time, such as 3 seconds, before transitioning to an up state. The transition logs to the /var/log/ltm file, and appears similar to the following example:

Mar 1 09:32:17 [7332]: 010a0043:5: The configuration was successfully loaded.
Mar 1 09:32:17 sccp bcm56xxd[1128]: 012c0015:6: Link: 1.1 is DOWN             
Mar 1 09:32:20 sccp bcm56xxd[1128]: 012c0015:6: Link: 1.1 is UP

F5 Product Development is tracking this issue as ID 334497 (formerly CR130147).

This issue does not affect the 9.4.x and later software branches.
