K11744: The BIG-IP WebAccelerator system does not log requests served from RAM Cache

Topic

When you configure the logging preferences for an acceleration policy, you can select:

  • Log all transactions
  • Only log transactions served from cache
  • Do not log

However, the logging feature does not log requests that the BIG-IP WebAccelerator system has served from Hot Cache (also known as RAM Cache). This behavior is expected.

The following table illustrates which requests are logged by the BIG-IP WebAccelerator system:

 RequestLog all transactionsOnly log transactions served from cacheDo not log
Requests served from Hot Cache (RAM Cache)---
Requests served from Smart Cache (Disk Cache)XX-
New requests (objects requested for the first time)X--
Requests for objects that have expiredX--
Requests for uncacheable objectsX--
Requests that produced an errorX--

If you require logging requests served from RAM Cache (for example for troubleshooting purposes), you may assign an iRule similar to the following example to the appropriate virtual server:

when CACHE_REQUEST {
  set r_time [clock format [clock seconds] -format {%d/%b/%Y:%H:%M:%S} ]
  set c_ip [IP::client_addr]
  set cs_method [HTTP::method]
  set cs_uri [HTTP::uri]
  set cs_host [HTTP::header Host]
  set cs_version [HTTP::version]
  set cs_UserAgent [HTTP::header "User-Agent"]
  set cs_Referer [HTTP::header "Referer"]
  set cs_cookie [HTTP::header Cookie]
}

when CACHE_RESPONSE { 
  set sc_bytes [CACHE::header Content-Length]
  if {$sc_bytes equals ""} {
    set sc_bytes "-"
  }
  set log_str "$c_ip - - \[$r_time\] \"$cs_method $cs_uri HTTP/$cs_version Host: $cs_host\" - $sc_bytes \"$cs_Referer\" \"$cs_UserAgent\" \"$cs_cookie\""
  log user.notice $log_str
}

The iRule will log all requests served from RAM Cache and their current hit count to the /var/log/ltm file. Each entry will look similar to the following example:

<CACHE_RESPONSE>: 192.168.1.10 - - [01/01/1970 12:12:12] "GET /images/1.jpg HTTP/1.1 Host: www.example.com" - 2088 "http://www.example.com/index.html" "Mozilla/5.0 Chrome/4.0.233.0"

Requests served from RAM Cache will be logged to the /var/log/ltm file, while all other requests will be logged to the /var/log/wa/access/access_log_<policy_name>.log file.
