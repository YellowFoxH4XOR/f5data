Description

Data Center is online but not coming back up in Data Center List after site maintenance. (big3d timeouts)

These messages are seen in the LTM log: no reply from big3d: timed out: disabled by server

 

From the /var/log/gtm file:

Environment

  • BIG-IP DNS
  • bigip monitor for data center
  • Communication between gtmd and big3d has been broken

Cause

gtm polling using a bigip monitor is disabled after the timeout limit which is 90 seconds by default.

Recommended Actions

Restart the gtmd and big3d processes on the DNS system(s) after the remote bigip/data center is online.

  • CLI commands to run:
    • bigstart restart gtmd
    • bigstart restart big3d
