Description



This article provides an overview of f5-cloud-libs on BIG-IP VE. F5-cloud-libs is usually installed on BIG-IP VE when BIG-IP VE was deployed from one of the supported Cloud Formation Template (CFT) in AWS, Azure Resource Manager (ARM) template in MS Azure or from Cloud Deployment Manager (GDM) template in Google Cloud.
 
When CFT/ARM/GDM template deployment was initiated to deploy BIG-IP VE in public cloud provider, the BIG-IP VE downloads F5-cloud-libs file (f5-cloud-libs.tar.gz) from the Internet and places it into /config/cloud/ directory on BIG-IP VE. This download is the CFT/ARM/GDM run-time system, which support initial BIG-IP VE onboarding and configuration. For instance f5-cloud-libs can facilitate in setting up VLANs, self IPs and default gateway on BIG-IP VE, configure HA cluster between two BIG-IPs or run autoscale code to elect master in autoscale cluster.
 
Note that in order for f5-cloud-libs.tar.gz to be downloaded, management subnet created in public cloud provider (which then mapped to one of BIG-IP VE interfaces) requires a route and access to the Internet.
 
The location from which f5-cloud-libs.tar.gz is downloaded as well as f5-cloud-libs version can be determined by investigating relevant CFT/ARM/GDM template file on F5 GitHub page. For instance, let’s examine template for standalone 2NIC BIG-IP VE in Azure, AWS and in Google Cloud.
  1. In Azure when using template version v7.5.0.0, f5-cloud-libs.tar.gz is downloaded from: https://cdn.f5.com/product/cloudsolutions/f5-cloud-libs/v4.18.0/f5-cloud-libs.tar.gz 
    Details: https://github.com/F5Networks/f5-azure-arm-templates/blob/v7.5.0.0/supported/standalone/2nic/existing-stack/byol/azuredeploy.json#L815
  2. In AWS when using template version v5.5.0, f5-cloud-libs.tar.gz is downloaded from: http://cdn.f5.com/product/cloudsolutions/f5-cloud-libs/v4.18.0/f5-cloud-libs.tar.gz
    Details: https://github.com/F5Networks/f5-aws-cloudformation/blob/v5.5.0/supported/standalone/2nic/existing-stack/byol/f5-existing-stack-byol-2nic-bigip.template#L1296
  3. In GCP when using template version v3.5.0, f5-cloud-libs.tar.gz is downloaded from: https://cdn.f5.com/product/cloudsolutions/f5-cloud-libs/v4.18.0/f5-cloud-libs.tar.gz
    Details: https://github.com/F5Networks/f5-google-gdm-templates/blob/v3.5.0/supported/standalone/2nic/existing-stack/byol/f5-existing-stack-byol-2nic-bigip.py#L332
BIG-IP VE onboarding logs as well as network/cluster/autoscale logs are located under /var/log/cloud/ directory on BIG-IP VE (provided that BIG-IP VE was deployed from CFT/ARM/GDM template in public cloud provider). 
 

Environment


BIG-IP VE running in AWS, Azure or Google Cloud and deployed from one of the supported CFT/ARM/GDM templates.
 
Supported BIG-IP VE templates in AWS: https://github.com/F5Networks/f5-aws-cloudformation/tree/master/supported
Supported BIG-IP VE templates in Azure: https://github.com/F5Networks/f5-azure-arm-templates/tree/master/supported
Supported BIG-IP VE templates in Google Cloud: https://github.com/F5Networks/f5-google-gdm-templates/tree/master/supported
