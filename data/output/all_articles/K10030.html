Issue

Error Message

sm-5-2 apm-5: VCIFS[12273]: [E:1] failed to begin creation of file parent "(sharename)" name "(filename)" - An error occurred while performing lock operation (-97)

In this error message, note the following:

  • (sharename) is share name that the operation is taking place
  • (filename) is the file the ARX system is attempting to complete a lock operation on.

For example:

sm-5-2 apm-5: VCIFS[12273]: [E:1] failed to begin creation of file parent "/test" name "source_boo_4-23222" - An error occurred while performing lock operation (-97)

Message Location

You may encounter this message in the following location:

  • ARX syslog

Description

This message occurs when the following conditions are met:

  • If an ARX system attempts to perform a lock operation, but the operation is not successful

A lock failure is typically caused by a temporary condition, and does not necessarily indicate an issue. For example, a lock failure could be caused by a network timeout, a slow back-end filer, or a pending operation in the metadata database. This error message should clear once ARX is able to lock the file.

Impact

Clients will not have sole access to the file until the lock operation is completed.

Recommended Actions

None
