K000160927: F5OS-A 1.8.x rSeries Interfaces Remain Down After Being Enabled

Type
Support Solution
Published
2026-04-21
Updated
2026-04-21
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.8.3, 1.8.0
Source
https://my.f5.com/manage/s/article/K000160927

Description

On F5 rSeries platforms running F5OS-A 1.8.x, interfaces may remain DOWN even with F5-qualified optics and correct configuration. This occurs when an SFP transceiver is inserted while the port is administratively disabled. Enabling the port afterward does not automatically bring the link UP, leaving the interface down.

Environment

  • F5OS-A 1.8.x
  • F5 rSeries platform

Cause

Bug ID 1891029

Answer/Recommended Actions

- If an interface remains DOWN after being enabled, remove and reinsert the SFP transceiver to bring the port UP.
- Ensure the port is enabled before inserting the SFP, if possible.

None
