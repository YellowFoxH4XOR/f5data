Issue

Starting in FirePass version 6.0.3, the Active Directory authentication method and the Active Directory dynamic group mapping method support nested groups. Nested groups is a feature of Active Directory, which allows you to configure a group as a member of another group.

To enable nested groups for a FirePass master group which uses Active Directory authentication, select the Check nested groups check box under the Authentication tab in the master group configuration.

 

Important: The Check nested groups check box does not appear unless you enter a value in the User must belong to Domain group field and click the Save settings button.

 

To enable nested group support for dynamic group mapping, select the Check nested groups while mapping check box in the Active Directory mapping method configuration.

 

Important: A known issue exists in FirePass version 6.0.3 that causes nested groups to fail if the user’s primary group in Active Directory contains a space character. For more information, including a hotfix, refer to K9473: Active Directory authentication and dynamic group mapping may fail if nested groups are enabled and the user's primary group contains a space character.

 

Additionally, nesting options depend on whether the domain functionality (mode) of your Windows domain is set to native mode or mixed mode.
