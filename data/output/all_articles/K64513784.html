Description

/var/log/ltm shows tcpdump start and stops, producing similar to the below messages:

notice tmm*[<PID>]: 013e0000:5: Tcpdump starting locally on 127.1.1.5:2 from 127.1.1.254:37745
notice tmm*[<PID>]: 013e000b:5: Tcpdump starting DPT providers:Noise Provider
notice tmm*[<PID>]: 013e0002:5: Tcpdump stopping on 127.1.1.2:2 from 127.1.1.254:37745
notice tmm*[<PID>]: 013e0002:5: Tcpdump stopping on 127.1.1.6:2 from 127.1.1.254:37745
notice tmm*[<PID>]: 013e0002:5: Tcpdump stopping on 127.1.1.3:2 from 127.1.1.254:37745
 

Environment

  • BIG-IP
  • ASM provisioned
  • security dos profile
  • tcpdump
     

Cause
Security dos profile settings.
You must have enabled tcpdump in Dos Protection Profile's HTTP

security dos profile /Common/Dos_Profile {
    app-service none
    application {
        ...
            tcp-dump {
                record-traffic enabled  <<<----------[!]
                repetition-interval once-per-attack
            }

On GUI, 
Security  ››  DoS Protection : Protection Profiles  ››  <profile_name>
then click HTTP's edit mark, then option appears in left side pane.
You can see under Record Traffic, check mark is in for Record Traffic During Attacks,

 


Recommended Actions

As it is configured, however if it is too often, then best to investigate the cause.
