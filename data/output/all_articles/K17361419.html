Description

You have rebooted the BIG-IP Virtual Edition (VE) machine either from the GUI or the CLI and it failed to start properly. An error message was displayed on the console reading 

buffer i/o error on dev dm-3 logical block (Number)

You then had to reboot the machine from the Hypervisor and it started normally.

Environment

  • Post-reboot condition
  • BIG-IP Virtual Edition
  • Hypervisor (for example, ESXi)

Cause

This issue is most likely related to a file system or disk problem on the Hypervisor and is not directly associated with F5.

Recommended Actions

Perform a hardware or software check on your Hypervisor to ensure it's functioning properly and there are no disk or file system issues.
