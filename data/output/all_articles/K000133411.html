K000133411: How to limit TLS protocols for port 9300 on a BIG-IQ DCD

Type
Support Solution
Published
2023-04-05
Updated
2025-04-02
Applies to
  • BIG-IQ
Source

Description

This article covers how to limit TLS protocols for port 9300 on a BIG-IQ Data Collection Device (DCD). For information about how to limit cipher suites for port 9300, refer to:

  • K97187319: How to Limit Weak Cipher Suites for Port 9300 on a BIG-IQ DCD

By default, the BIG-IQ DCD uses TLS 1.1 and TLS 1.2 for TCP port 9300 connections. The Elasticsearch component uses this default configuration to transport data between nodes. The BIG-IQ prefers TLS 1.2; however, it's possible that a node could accept a connection using TLS 1.1.
Note: TLS 1.3 is not supported for the TCP port 9300 node transport connection.

There are some circumstances in which you might want to limit the acceptable TLS protocols on TCP port 9300, for example, you may have security concerns when your VA Scan Report shows BIG-IQ supports an earlier TLS protocol. To limit the protocols, follow the Recommended Actions below.

Environment

  • BIG-IQ DCD
  • TCP port 9300
  • TLS protocols

Cause

The default Elasticsearch configuration for the BIG-IQ may accept a connection using TLS 1.1.

Recommended Actions

To limit the TLS protocols for BIG-IQ TCP port 9300 connections, perform the following procedure:
Note: The following procedure is not a standard procedure. It might not be migrated during upgrade and it might be incompatible with future versions.

  1. Edit the Elasticsearch configuration file using an editing tool like vim:
vim /var/config/rest/elasticsearch/config/elasticsearch.yml
  1. Find the opendistro_security > ssl > transport settings displayed below:
 opendistro_security:
  disabled: false
  ssl:
    transport:
      pemcert_filepath: es_node.pem
      pemkey_filepath: es_node-key.pem
      pemtrustedcas_filepath: es_root-ca.pem
      enforce_hostname_verification: false
  1. Add the following lines to the transport settings. Do not modify the http settings.
enabled_protocols:
- TLSv1.2

For example:
opendistro_security:
  disabled: false
  ssl:
    transport:
      pemcert_filepath: es_node.pem
      pemkey_filepath: es_node-key.pem
      pemtrustedcas_filepath: es_root-ca.pem
      enforce_hostname_verification: false
      enabled_protocols:
      - TLSv1.2
  1. Save the configuration file. If you use vim, press ESC then : and x.
  2. Restart the Elasticsearch process.
Impact of procedure: Elasticsearch will be temporarily unavailable during the restart.
bigstart restart elasticsearch
