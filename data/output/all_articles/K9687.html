Topic

The ARX 6000 platform requires two system disk drives for operation. The two disk drives provide RAID Level 1 redundancy. These drives contain software images, reports, scripts, log files, and configuration files.

If one of the two system disk drives fails, you must manually rebuild the RAID configuration on the replacement drive.

Important: The replacement drive must match the existing remaining drive model or the RAID rebuild process will fail. For information about identifying the existing drive model, refer to K9682: The ARX 6000 platform hard drive identification.

Note: For information about removing and replacing an ARX 6000 system drive, refer to the Removing and Replacing a Disk Drive section of the ARX 6000 Hardware Installation Guide.

After inserting the replacement drive, start the RAID rebuild process by performing the following procedure:

Note: If the ARX 6000 platform is part of a high availability cluster, the ARX system should be the backup system when performing the RAID rebuild process.

  1. Log in to the ARX command line.
  2. Enable privileged mode by typing the following command:

    enable
  3. Start the RAID rebuild process by typing the following command:

    raid rebuild <disk#>

    For example, to rebuild the RAID configuration for the disk in Bay 2, you would type the following command:

    raid rebuild disk2
  4. Display the RAID rebuild progress by typing the following command:

    show chassis diskuse

    The rebuild progress will be displayed under the State column in the Disk Details section of the command output, which appears similar to the following example:

    Disk     Size        State             Transfer Rate Model
    -------- ----------- ----------------- ------------- -----------------
    Bay 1    68.50G     Online             320MB/sec     ATLAS10K5_73SCA
    Bay 2    68.50G     Rebuild 13 %       320MB/sec     ATLAS10K5_73SCA
     
  5. Verify that the RAID rebuild is complete by typing the following command:

    show chassis diskuse

    The RAID rebuild is complete when both drives are listed as Online under the State column in the Disk Details section of the command output, which appears similar to the following example:

    Disk     Size        State             Transfer Rate Model
    -------- ----------- ----------------- ------------- -----------------
    Bay 1    68.50G     Online             320MB/sec     ATLAS10K5_73SCA
    Bay 2    68.50G     Online             320MB/sec     ATLAS10K5_73SCA
