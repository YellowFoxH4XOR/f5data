K00838098: ERROR: UCS version <version> is newer than system's <version> when loading a UCS file

Type
Knowledge
Published
2023-05-18
Updated
2023-05-18
Source
https://my.f5.com/manage/s/article/K00838098

Description

When loading a UCS file you may get an error like the following :
Installing full UCS (12.1.3.2) data, excluding license file.
Extracting manifest: /var/local/ucs/example.ucs
ERROR: UCS version(12.1.3.2) is newer than system's(12.1.3.1).
Not supported - exit installation.
Operation aborted.
Unexpected Error: UCS loading process failed.

Environment

  • Restoring UCS
  • BIG-IP

Cause

A UCS that is created on a specific version cannot be restored on a lower version.

Recommended Actions

Upgrade the BIG-IP to the same version as where the UCS archive was created and then restore the configuration with the UCS file.
