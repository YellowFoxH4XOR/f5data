Known Issue

The BIG-IP system may incorrectly send High-Speed Logging (HSL) messages to the destination of a matching half-wildcard or network virtual server.

This issue occurs when one of the following conditions are met:

  • You have configured HSL to use a pool of HSL destination members with an IP address that matches a half-wildcard or network virtual server.
  • You have configured an iRule to send HSL messages to an IP address that matches a half-wildcard or network virtual server.

Impact

Log messages may be lost.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The HSL destination host does not receive the HSL messages.
  • The system sends the HSL messages to the resource of the matching half-wildcard or network virtual server.

Workaround

To work around this issue, you can configure a virtual server that fully matches the HSL destination hosts and sends the HSL messages to the desired destination.

Impact of workaround: The workaround should not have a negative impact on your system.
