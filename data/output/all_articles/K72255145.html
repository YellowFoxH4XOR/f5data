Description

How to extract a list of Virtual Servers and their associated Pools and Members to a .csv file 

Environment

  • Use this procedure when requiring the need to export a list of Virtual Server's and its Pool members across a configured partition of a BIG-IP system to a .csv file
NOTE: This procedure is provided  “AS IS” and is an example only of how one can use a simple bash script to extract the output from tmsh commands to create a .csv file. This is not covered by F5 Scope of Support see https://www.f5.com/services/support/support-offerings/support-policies
 
Cause

Not an issue

Recommended Actions

The following is an example of how to export a list of Virtual Server and Pools info to a .csv file, it is provided as a demonstration of what can be achieved with the use of an script and CLI (Command Line Interface) access to a BigIP device:

1.- In order to create the script use your preferred text editor - in this example 'nano' is used (you can use other text editor like vi). First create a script file with your selected name - example 'vs-pool-list'

    # nano vs-pool-list.sh

2.- Paste the sample code into the opened script file, then use Ctrl+x and type "Y" to save the changes:

    echo vs name, destination, pool, pool members
    VIRTUALS=$(tmsh -q -c "cd / ; list /ltm virtual  recursive" | grep "ltm virtual" | awk -F' ' '{print "/"$3}')
    for VS in $VIRTUALS;
    do
      echo -n $VS,
      DEST=$(tmsh list ltm virtual $VS | grep destination | cut -d" " -f6)
      echo -n $DEST,
      POOL=$(tmsh list ltm virtual $VS | grep pool | cut -d" " -f6)
      echo -n $POOL,
      if [ -n "$POOL" ];
      then
        MBRS=$(tmsh list ltm pool "$POOL" | grep address | cut -d" " -f14)
        echo -n $MBRS
      fi
      echo
    done

3.- Change the permissions on the newly created script to allow execute permissions:

    # chmod 744 vs-pool-list.sh

4.- Verify the script file has all the content with the cat command:

    [root@bigip_A_test:Active:In Sync] ~ # cat vs-pool-list.sh
    echo vs name, destination, pool, pool members
    VIRTUALS=$(tmsh -q -c "cd / ; list /ltm virtual  recursive" | grep "ltm virtual" | awk -F' ' '{print "/"$3}')
    for VS in $VIRTUALS;
    do
      echo -n $VS,
      DEST=$(tmsh list ltm virtual $VS | grep destination | cut -d" " -f6)
      echo -n $DEST,
      POOL=$(tmsh list ltm virtual $VS | grep pool | cut -d" " -f6)
      echo -n $POOL,
      if [ -n "$POOL" ];
      then
        MBRS=$(tmsh list ltm pool "$POOL" | grep address | cut -d" " -f14)
        echo -n $MBRS
      fi
      echo
    done
    [root@bigip_A_test:Active:In Sync] config #

5.- Execute the script with this command, and wait until it finish:

    # ./vs-pool-list.sh

6.- When finished, you can copy / paste the output to your Excel spreadsheet and split the values to multiple columns (use 'space' as field separator).
     You will still have to manually format what's left to make it human-usable documentation.

As an alternative to step 5 and step 6 you can use the linux redirector '>' to direct the output from the script directly to a file example.

   # ./vs-pool-list.sh > results.csv
