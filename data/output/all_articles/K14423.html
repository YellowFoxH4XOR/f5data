Known Issue

The wamd process may produce a core file if disk or RAM resources abruptly become low.

This issue occurs when all of the following conditions are met:

  • The BIG-IP WebAccelerator system is under heavy load.
  • The BIG-IP WebAccelerator is performing CPU-intensive tasks, such as image optimization or PDF linearization.
  • The /shared file system is nearing capacity.
  • Memory resources are near capacity.

This issue occurs due to a race condition on heavily-loaded systems between the time when wamd checks for space to perform the optimization tasks and the tasks take place. Upon failure, the wamd process produces a core file and immediately restarts.

Impact

The BIG-IP Web Accelerator system temporarily stops passing traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H421532 on the Diagnostics > Identified > Medium screen.
  • You may see wamd core files in the /var/core directory.
  • The BIG-IP WebAccelerator system intermittently stops passing traffic.
  • You may observe the following message in the /var/log/wamd.log file:

    WA pdlin qpdf failed to optimize PDF, returning original

To work around this issue, you can clear the /shared file system of any unnecessary files.
