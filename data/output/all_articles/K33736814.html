Known Issue

BIG-IP 10000 series platforms may generate error messages indicating high current or high voltage readings for power supply units (PSU) #1 or #2.

This issue occurs when the following conditions are met:

  • You have BIG-IP 10000 series (D112, D113) platform.
  • The system has one or more PWR-0149 / FND850 DC PSUs installed.

This cosmetic issue is caused by EEPROM corruption and may result in PSU error messages and critical alarms if the corruption impacts PSU parameters that are monitored by sensors.

Note: To confirm that the error you receive is cosmetic only and to verify the Chassis Power Supply Status for each installed PSU is marked up, you can view the output of the following command:

tmsh show sys hardware command

Impact

This issue is cosmetic, is not indicative of a power supply failure, and does not affect the power supply functionality.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system logs an error messages to the /var/log/ltm file that appears similar to the following examples:
    • notice chmand[10556]: 012a0005:5: Tmstat::updateSensorTbls: HAL SenSvc error: BourneSeepromDev: seeprom data exceeds max size
    • crit chmand[7746]: 012a0013:2: Blade 0 hardware sensor critical alarm: Power supply #2 meas. main output voltage (mV): 65535
  • The system logs an error message to the /shared/log/eud.log file that appears similar to the following example:

    Power supply #2 model number: FND850-S101Gÿÿÿÿÿ

  • The LCD panel, or tmsh show /sys alert lcd command output may display messages that appear similar to the following examples:
    • critical 0x12a0013 Blade 0 hardware sensor critical alarm: Power supply #1 meas. main output voltage (mV): 2147471633
    • critical 0x12a0013 Blade 0 hardware sensor critical alarm: Power supply #1 meas. main output current (mA): 2147473113
    • critical 0x12a0013 Blade 0 hardware sensor critical alarm: Power supply #2 meas. AC input voltage (mV): -65280

Resolution

Status

F5 Product Development has assigned ID 585875 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases, point releases, or hotfixes that resolve this issue, refer to the following table.

Type of fixFixes introduced inRelated articles
ReleaseNone*None
Point release/hotfixNone*None

*Currently deployed PSUs are not field-programmable, so there is no software fix for this cosmetic issue. However, the supplier updated the PWR-0149 DC PSUs that F5 ship as RMA replacements with a new firmware to eliminate the messages.
