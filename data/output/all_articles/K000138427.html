Description

BIG-IP logs a message similar to below in /var/log/messages when logs are rotated.

notice syslog-ng[<PID>]: The current log file has a mismatching size/inode information, restarting from the beginning; state='affile_sd_curpos(/var/log/audit)', stored_inode='49265', cur_file_inode='49262', stored_size='0', cur_file_size='0', raw_stream_pos='2242934'

Note: <PID> is the process ID of the syslog-ng process.
Note: The filename /var/log/audit may vary depending on how sys syslog include is configured.

Environment

  • BIG-IP is configured with syslog configuration with source definition that references a file under /var/log directory, which will be rotated at night. Such configuration will look like below.
sys syslog {
    include "source s_audit { file(/var/log/audit); }; ...snip...; log {source(s_audit); ...snip...; };"
    ...snip...
}

Cause

This log message indicates syslog-ng noticed the change in the file info (in the case of example above, a change in inode from 49265 to 49262) while reading /var/log/audit, and it's reading the file from the beginning. When logrotate happens while syslog-ng is reading the file, syslog-ng notices the change in the file info like inode (which basically means file has changed), and syslog-ng loses the position where it was reading, so it needs to restart reading the file from the beginning. For more information about logrotate, please refer to K13367: Managing log files on the BIG-IP system (11.x - 17.x).

Recommended Actions

The message can be safely ignored.
