Description

F5 does not support Signaling Delivery Controller (SDC) feature customization and tailored scripts nor verify and validate Method Of Procedure (MOP). This includes F5 Professional Services (PS) deployed solutions that are implemented at the customer request. F5 can render consultative assistance when necessary. However, F5 is unable to take any responsibility for any feature customization and tailored scripts deployed nor MOP used to perform a change. As such, F5 is also unable to guarantee any Root Cause Analysis (RCA).

In addition, if you are considering upgrading 3rd party software in SDC. If you upgrade of 3rd sofware  and have issue or trigger issue to SDC software, clean installation of SDC may be required.



Environment

SDC Feature customization
MOP review
3rd Party Software(example rpms)

Cause

None

Recommended Actions

Prior to deploying any SDC feature customization and tailored scripts or using MOP to perform a change, F5 recommends all customers to test this in lab under all required production scenarios, environment and load.

Additional Information

Scripts refer to set of code in Groovy scripting language that calls SDC Application Programming Interface (API) methods.
To view list of API methods, click Help > API Scripting from WebUI.
