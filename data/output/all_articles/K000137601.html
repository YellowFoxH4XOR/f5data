Description

When the VPN connected, on the windows client, the browser popup, user see the APM deny page.

Environment

  • BIG-IP APM
  • Virtual Server
  • Access profile
  • Network Access
  • ACL

Cause

When VPN connected, the windows OS detect the network event, will check the connectivity to internet. For the details, please review An Internet Explorer or Edge window opens when your computer connects to a corporate network or a public network. If the ACL block the connection, the client may get the deny page.
Note: This link takes you to a resource outside of AskF5, and the third party could remove the document without our knowledge.

Recommended Actions

The workaround: 

  • Edit the ACL, allow the connection to the special web site.
  • Change the client setting, disable the connectivity probe. And it is depending on the client OS.
