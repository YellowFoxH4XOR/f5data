Issue

Beginning with BIG-IP 9.4.2, you can enable audit logging for the bigpipe command.

When you enable audit logging for the bigpipe command, the system logs user-entered bigpipe commands, including bigpipe commands run from the bigpipe shell interface, and bigpipe commands run by the system.

You can select the following auditing levels on the BIG-IP system:

  • Disable: The bigpipe shell does not audit any commands.
  • Enable: The bigpipe shell audits all commands that users enter, and the commands run by the bigpipe merge command, but not the commands run by the bigpipe load and bigpipe import commands.
  • Verbose: The bigpipe shell audits all of the commands that users enter, and the commands run by the bigpipe merge command. Additionally, the bigpipe shell audits the commands run by the bigpipe load and bigpipe import commands, except for those commands that are found in the following system configuration files:
    • The config_base.conf file
    • The base_monitors.conf file
    • The profile_base.conf file
    • The daemon.conf file

Beginning with BIG-IP 9.4.4, the Debug auditing level is also available:

  • Debug: The bigpipe shell audits all user-initiated and system-initiated configuration changes.

Enabling bigpipe command auditing

1. Log in to the Configuration utility.

2. Navigate to System > Logs.

4. Click the Option menu.

5. In the Audit Logging section, select Enable, Verbose, or Debug from the bigpipe menu.

6. Click Update.

Viewing the bigpipe command audit logs

1. Log in to the Configuration utility.

2. Navigate to System > Logs.

4. Click the Audit menu.

Note: You can also view audit logs for the bigpipe command from the command line in the /var/log/audit file.
