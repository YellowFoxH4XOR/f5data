Known Issue

The BIG-IP APM Configuration utility may not correctly display user-defined access control lists (ACL).

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM is configured with more than 10 ACLs.
  • The BIG-IP APM administrative user attempts to view or page through the configured ACLs.

Impact

The Configuration utility page view limits the ACLs display to the first 10 ACLs.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you view ACLs with the Configuration utility, each page displays the same 10 ACLs, regardless of the page number you have selected.
  • When you view ACLs with the Show All configuration option, each page displays the complete list of configured ACLs, as expected.

Resolution

Status

Workaround

To work around this issue, you can use the Show All option in the Configuration utility; to find that option, navigate to Access Policy > User-defined ACLs.
