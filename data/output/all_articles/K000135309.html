K000135309: Big-IP Edge Client disconnecting/reconnecting when using Trellix

Type
Support Solution
Published
2023-08-31
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP APM: 14.1.4
Source
https://my.f5.com/manage/s/article/K000135309

Description

The APM Edge Client, when used in conjunction with Trellix security software, may encounter instability issues where it constantly connects and disconnects. However, by disabling the Trellix security feature, the Edge Client is able to establish a stable connection.

 

Environment

  • BIG-IP APM
  • Edge Client
  • Trellix v4.1.0

 

Cause

The instability issue observed between the APM Edge Client and Trellix security software can be attributed to a specific problem within Trellix 4.1.0. It incorrectly identifies an F5 API call as malicious, leading to frequent disruptions in the connection.

 

Recommended Actions

Reach out to the support team of Trellix, providing them with detailed information about the issue. Explain the problem clearly, mentioning the versions of APM Edge Client, Trellix, and any relevant error messages encountered.
