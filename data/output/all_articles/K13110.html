Known Issue

The syslog include configuration is not loaded during a software version upgrade. This issue occurs when all of the following conditions are met:

  • The BIG-IP configuration contains syslog include statements
  • The BIG-IP system is upgraded from BIG-IP versions prior to 10.2.2

This issue occurs because the syslog include configuration resides in different BIG-IP configuration files across versions. During the upgrade, the syslog configuration is rolled forward in the /config/bigip_sys.conf file. However, the configuration is not loaded into memory.

Note: For more information, refer to K13107: Certain syslog configuration now resides in a different BIG-IP configuration file.

Impact

The syslog-ng utility does not function as expected on the upgraded BIG-IP system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The syslog include configuration that is previously configured on the BIG-IP system does not exist on the upgraded BIG-IP system
  • The syslog-ng utility may not be logging as previously configured

Workaround

There is no workaround for this issue. After an upgrade to BIG-IP version 10.2.2 through 10.2.4, you have to locate the syslog include configuration in the /config/bigip_sys.conf file and re-add it using bigpipe command or tmsh utility. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the command line.
  2. Use a text editor or text viewer to view the /config/bigip_sys.conf file.
  3. Locate the syslog include statement in the syslog configuration stanza.

    The following is an example of a syslog configuration stanza that comprises only the include statement:

    syslog {
       include "destination d_remote { udp(10.10.10.10 port(514)); };"
    }

  4. Re-add the syslog include statement using either the bigpipe command or tmsh utility:

    • tmsh utility

      tmsh modify /sys syslog include <syslog include configuration>

      In this command, note the following:

      • <syslog include configuration> is the syslog include configuration extracted in the previous step

      For example,

      tmsh modify /sys syslog include "destination d_remote { udp(10.10.10.10 port(514)); };"

    • bigpipe utility

      bigpipe syslog include <syslog include configuration>

      In this command, note the following:

      • <syslog include configuration> is the syslog include configuration extracted in the previous step

      For example,

      bigpipe syslog include "destination d_remote { udp(10.10.10.10 port(514)); };"

  5. Save the changes by entering one of the following two commands:

    • tmsh utility

      tmsh save sys config

    • bigpipe utility

      bigpipe save all
