K000150385: How to manage partition LAGs and VLANs in F5OS

Description

This article provides some standard steps when managing partition network settings in F5OS (rSeries and VELOS)

 

Environment

rSeries/VELOS platform

 

Cause

none

 

Recommended Actions

When creating VLAN and LAGs:

  • Log into the chassis partition
  • Navigate to Network Settings --> VLANs and click ADD
  • Fill in the VLAN ID and Name, click Save & Close
  • Navigate to Network Settings --> LAGS and click ADD
  • Fill in the Name, select LAG Type, adjust LACP related settings, check the required interfaces, check Trunk VLANs (Tagged), and click Save & Close
  • Navigate to TENANT MANAGEMENT --> Tenant Deployment and click ADD
  • Define the properties of tenant, check the required VLANs, and click Save & Close
  • Navigate to TENANT MANAGEMENT --> Tenant Deployment, select the Tenant, click Provision, and then Deploy

When adding a VLAN:

  • Log into the chassis partition
  • Navigate to Network Settings --> VLANs and click ADD
  • Fill in the VLAN ID and Name, click Save & Close
  • Navigate to Network Settings --> LAGS, click the target LAGs
  • Check the new-created VLAN ID in Trunk VLANs (Tagged) and click Save & Close
  • Navigate to TENANT MANAGEMENT --> Tenant Deployment and click the target Tenant
  • Check the new-created VLAN ID in VLANs and click Save & Close
  • Log into the Tenant
  • Navigate to Network --> VLANs, you should see the new-created VLAN ID in the VLAN List

When adding a new LAG:

  • Log into the chassis partition
  • Navigate to Network Settings --> LAGS and click ADD
  • Fill in the Name, select LAG Type, adjust LACP related settings, check the required interfaces, check Trunk VLANs (Tagged), and click Save & Close
  • Log into the Tenant
  • Navigate to Network --> Trunks, you should see the new-created trunk in the Trunk List

When changing VLAN ID:

  • Log into the chassis partition
  • Navigate to TENANT MANAGEMENT --> Tenant Deployment and click the target Tenant
  • Deselect the target VLAN ID in VLANs and click Save & Close
  • Navigate to Network Settings --> VLANs, select the target VLAN, and click Delete
  • Click Add, fill in the new VLAN ID and the same Name as before, click Save & Close
  • Navigate to Network Settings --> LAGS, click the target LAGs
  • Check the new-created VLAN ID in VLANs and click Save & Close
  • Log into the Tenant
  • Navigate to Network --> VLANs, you should see the new-created VLAN ID in the VLAN List

When changing LAG name:

  • Log into the chassis partition
  • Navigate to Network Settings --> LAGS, select the target LAGs, and click Delete
  • Click Add, fill in the new Name, select LAG Type, adjust LACP related settings, check the required interfaces, check Trunk VLANs (Tagged), and click Save & Close
  • Log into the Tenant
  • Navigate to Network --> Trunks, select the deleted Trunk, and click Delete

When deleting VLAN:

  • Log into the chassis partition
  • Navigate to TENANT MANAGEMENT --> Tenant Deployment and click the target Tenant
  • Deselect the target VLAN ID in VLANs and click Save & Close
  • Navigate to Network Settings --> VLANs, select the target VLAN, and click Delete
  • Log into the Tenant
  • Navigate to Network --> VLANs, select target VLAN, and click Delete

When deleting LAG:

  • Log into the chassis partition
  • Navigate to Network Settings --> LAGS, select the target LAGs, and click Delete
  • Log into the Tenant
  • Navigate to Network --> Trunks, select the deleted Trunk, and click Delete
