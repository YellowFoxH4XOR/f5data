Description

You've created and applied an iRule that uses the DNS_REQUEST and/or DNS_RESPONSE events, or otherwise directly processes DNS packets, but are seeing that the iRule doesn't do anything when applied to a virtual server

Environment

  • BIG-IP LTM or DNS
  • Virtual Server
  • DNS iRule

Cause

DNS iRule events and commands require a GTM or DNS Services license

Recommended Actions

Verify that your BIG-IP does not have DNS Services or the Global Traffic Manager Module
  1. From your BIG-IP's GUI, navigate to System > License
  2. If you find either DNS Service or Global Traffic Manager Module are listed under the Active section, this is not the issue
