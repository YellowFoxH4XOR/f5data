K000148243: PSU fault detected on F5OS-A

Type
Support Solution
Published
2024-10-24
Updated
2026-03-21
Applies to
  • F5OS
  • F5OS-A: 1.5.X, 1.5.4, 1.5.3, 1.5.2, 1.5.1, 1.5.0, 1.8.X, 1.8.0, 1.7.0, 1.7.X, 1.8.3
Source
https://my.f5.com/manage/s/article/K000148243

Description

The device shows a 'PSU fault detected' warning for one or both PSUs. You verified that the PSU is compatible with the hardware as per K36588206.

Environment

  • F5OS-A
  • PSU fault detected
  • version higher than 1.5.2

Cause

Unknown.

Recommended Actions

Reseat the PSU per the Reseating Power Supply Units (PSUs) in F5 rSeries and VELOS Devices procedure and restart the diag-agent

1. From the command line, log in as the root user and run:

docker restart diag-agent

2. Verify the alarm has been removed:

show system alarms

3. Reseat PSU-2 if the alarm persists.

Additional Information

If the device runs a software version before 1.5.2, the issue might be related to K000140419.
