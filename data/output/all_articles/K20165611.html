K20165611: Unable to login using local accounts(remote auth works fine)

Type
Support Solution
Published
2023-05-25
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K20165611

Description

  • You are unable to login to your BIG-IQ with a local user. 
  • When you try to change the password with 'passwd' utility you see this output:

    --ERROR--
    This user is NOT authenticated from a remote source.
    Please change the password at the remote authentication server

Environment

  • BIG-IQ CM
  • Local users

Cause

Unknown.

Recommended Actions

Switch the CLI/SSH to local with:

# tmsh modify /auth source type local
# tmsh save sys config

then use passwd to change password:

# passwd <local-account>

Additional Information

None.
