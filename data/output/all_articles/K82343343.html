<DATE> <HOST> info lacpd[11702]: 01160016:6: Interface 1.1, link admin status: enabled, link status: up, duplex mode: full, lacp operation state: down
<DATE> <HOST> info lacpd[11702]: 01160010:6: Link 1.1 removed from aggregation Jul 6 22:30:57 DSCSPMV004.prevnet notice mcpd[7639]: 01bb0003:5: Trunk: TRK_UPL is DOWN

Environment

  • LACP
  • BIG-IP LTM
  • After upgrade

Cause

K54329115: LACP trunk went down after upgrade
 

Recommended Actions

Reboot the device with the following command:
  
reboot
