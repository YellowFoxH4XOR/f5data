Known Issue

Automatic attack signature updates fail to use the configured proxy address.

This issue occurs when all of the following conditions are met:

  • You license and provision the BIG-IP ASM module on the BIG-IP system.
  • You configure the BIG-IP ASM system to use a proxy address for outbound communication to the update servers.
  • You attempt to update attack signatures using the following steps:
    1. Set the Delivery mode to Automatic.
    2. Navigate to Security > Security Updates.
    3. Click Check for Updates.

In BIG-IP ASM 13.0.0 and later, you can use the following database keys to configure the system to use a proxy when updating attack signatures:

  • proxy.host
  • proxy.port
  • proxy.protocol
  • proxy.username
  • proxy.password

However, when this issue occurs, the system does not use the configured proxy for automatic attack signature updates, and you must download updates manually.

Impact

The BIG-IP ASM system is unable to check for or receive automatic attack signature updates.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system fails to update attack signatures in Automatic Delivery mode and displays the following message:

    Could not reach the update server. Error: No response from update server

  • The system logs messages similar to the following example to the /var/log/asm file:

    01310027:2: ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::log_error_and_rollback): Could not reach the update server. Error: No response from update server

Workaround

To work around this issue, you can manually download signature updates and then install them. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Go to the F5 Downloads site.
  2. Download the latest signature file to your workstation.
  3. Log in to the Configuration utility.
  4. Navigate to Security > Security Updates > Application Security.
  5. Under Security Update, in Delivery Mode, click Manual.
  6. In Upload File, browse to and upload the signature file. 
  7. Click Install Updates.
