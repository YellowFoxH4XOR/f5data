Description

You may not be able to deliver the BWC policy to the BIG-IP when you are using standard mode for the F5 Openstack Agent

Environment

  • Openstack
  • BIG-IP LTM
  • Bandwidth Controller Policy
  • F5 Openstack Agent

Cause

The BWC policy is supported only by the lite mode for F5 Openstack Agent

Recommended Actions

Switch the f5_agent_mode to lite and restart the F5 Openstack Agent. To Modify the mode to lite mode, you may follow the below procedures:

  1. Log in to your server

  2. Modify the F5 Openstack Agent configuration file. By default, the configuration file is located at /etc/neutron/services/f5/f5-openstack-agent.ini

    For example,  you may have your agent configured as normal mode under [DEFAULT] section:

    f5_agent_mode = normal

    you need to modify the mode to lite as below:

    f5_agent_mode = lite 

  3. Restart the F5 Openstack Agent

    sudo systemctl restart f5-openstack-agent.service

Additional Information

Most of the new features will require the lite mode.
