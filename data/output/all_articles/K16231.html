Known Issue

BIG-IP APM access sessions may encounter page reloads for some content.

This issue occurs when all of the following conditions are met:

  • You are using the Mozilla Firefox browser, and have an established access session to the BIG-IP APM system.
  • Java script code returned from a destination resource contains an expression similar to the following example:      

    <script>
            document.location.hash = "";
          </script>

Impact

The Firefox browser reloads the current page.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When users attempt to access the content provided by the Java script code, the Firefox browser reloads the current page.
  • When users attempt to access the content provided by the Java script code, the content is not displayed.

Workaround

To work around this issue, you can create and apply an iRule to properly handle the rewriting of the Java script code from {location.hash = ''} to {location.hash = '#'}.

Note: You need to design the iRule syntax around the Java script of the specific application.
