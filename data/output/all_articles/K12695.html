Known Issue

This is the result of a known issue. When you disable a TMM interface on a BIG-IP LTM Virtual Edition system or a BIG-IP APM Virtual Edition system, the Configuration utility and command line both report the interface as disabled, but the interface does not go down and it continues to process traffic.

F5 Product Development tracked this issue as ID 225019 (formerly CR138342) and it was fixed in BIG-IP 11.3.0. For information about upgrading, refer to the BIG-IP release notes.

Workaround

You can work around this issue by using your VMware hypervisor product to disable the desired TMM interface; this is opposed to disabling the interface from within the BIG-IP system. To do so, perform the following procedure:

  1. Start VMware vSphere.
  2. Log in.
  3. Right click the BIG-IP virtual machine.
  4. Click Edit Settings.
  5. Select the network adapter corresponding to the TMM interface that you want to disable.

    For example, to disable interface 1.1, select Network adapter 2.

    Note: The first network adapter corresponds to the management interface, and all ensuing network adapters correspond to TMM interfaces.
  6. Under Device Status, clear the Connected check box.
  7. Click OK.

The interface is now disconnected from the network. Once you are ready to re-enable the interface, repeat the previous procedure, and in step 6, select the Connected check box.

Note: For information about your specific version of VMware vSphere, refer to your product documentation.
