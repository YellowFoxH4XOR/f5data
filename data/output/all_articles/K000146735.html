What Happened?

I want to know how to block or allow DNS (port53), SSH (port 22), and WebUI access to sites.

 

Environment

  • F5® Distributed Cloud
  • Cloud and Edge Sites Service on F5 Distributed Cloud Services Platform

 

Resolution/Answer

In the Cloud and Edge Sites Service, when creating a  site or fleet of sites the default value is to allow traffic from ports who service WebUI , DNS port, and SSH port. To disallow, login with your credentials into F5 Distributed Cloud Services Console, and do the following:

  1. In the Cloud and Edge Sites service page, select Manage-> Site Management
    A submenu will open with options to select Cloud Sites, DC or Edge Sites, and Fleets.
  2. Find a site or fleet for which you want to disallow access to DNS, SSH, or WebUI.
  3. Select ... (ellipsis icon) for the site of fleet of your choice. From the pop up menu that appears,  select Manage Configuration.
  4. Once the configuration screen that appears, select Edit Configuration (pencil icon on the top right).
  5. Scroll to bottom of the Advanced Configuration:
     
  6. Select Custom Blocked Services Configuration.
     
  7. Click Add Item
    You will see a select box with option to select WebUI port, DNS port, or SSH port. Select the service you want to block.
  8. Select the network type Site Local Network or Site Local Inside Network.
    The Site Local Network provides connectivity to the public network  while the Site Local Inside Network is a secure private network that is not connected to the public network.
     
  9. Once type of network is selected, click Add Item
  10. Click Save and Exit
