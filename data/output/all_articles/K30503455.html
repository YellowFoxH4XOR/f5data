Source

Description

You want to move an evaluation license from one BIG-IP VE to another. The license is still within its validity period.

Environment

  • BIG-IP VE
  • Evaluation / Trial License

Cause

None

Recommended Actions

1. Ensure that the evaluation license is still within it's validity period. Refer to K9245 on how to check license validity.
2. Revoke the license prior to using it on another device. For steps on how to revoke VE license, refer to K41458656.
