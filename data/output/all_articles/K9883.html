K9883: Configuring the BIG-IP WebAccelerator to recognize SVG file type objects

Topic

BIG-IP WebAccelerator versions 10.0.1 and earlier do not classify Adobe Scalable Vector Graphic (SVG) files. For those BIG-IP versions, the images object type in the default globalfragment.xml file does not include the svg or svgz extentions.

Note: Starting in BIG-IP WebAccelerator version 10.1.0, the images object type in the default globalfragment.xml file includes the svg and svgz extentions. F5 Networks Product Development tracked this enhancement as CR117722.

Workaround

You can add the svg and svgz extentions to the images object type in the globalframent.xml file. To do so, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Change directories to the /config/wa directory by typing the following command:

    cd /config/wa
  3. Back up the original globalfragment.xml file by typing the following command:

    cp globalfragment.xml globalfragment.xml.sol9883
  4. Open the globalfragment.xml file in a text editor.
  5. Locate the images objType entry similar to the following:

                <objType
                    type="images"
                    group="images"
                    category="common"
                    displayName="ExceptBMP"
                    ext="jpg, jpeg, jpe, gif, png, tif, tiff, ico, wbmp"
                    mimeType="image/jpeg, image/jpg, image/gif, image/tiff,
                        image/ico, image/x-icon, application/ico,
                        application/x-ico, application/x-win-bitmap,
                        image/x-win/bitmap, image/vnd.wap.wbmp,
                        application/png,
                        application/x-png,
                        image/png"
                    compressToClient="none"
                />
  6. Edit the images objType entry, adding svg and svgz to the ext entry. For example:

                <objType
                    type="images"
                    group="images"
                    category="common"
                    displayName="ExceptBMP"
                    ext="jpg, jpeg, jpe, gif, png, tif, tiff, ico, wbmp, svg, svgz"
                    mimeType="image/jpeg, image/jpg, image/gif, image/tiff,
                        image/ico, image/x-icon, application/ico,
                        application/x-ico, application/x-win-bitmap,
                        image/x-win/bitmap, image/vnd.wap.wbmp,
                        application/png,
                        application/x-png,
                        image/png,
                        image/svg+xml"
                    compressToClient="none"
                />
  7. Save the globalfragment.xml file.
  8. Restart the pvac daemon by typing the following command:

    Important: Restarting the pvac daemon will briefly disrupt connections, and invalidate objects in the LTM RAM Cache. Restarting the pvac daemon should be scheduled accordingly.

    bigstart restart pvac

The BIG-IP WebAccelerator will now classify Adobe Scalable Vector Graphic (SVG) files as images.
