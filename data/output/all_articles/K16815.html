Known Issue

The Configuration utility displays an incorrect virtual server status of yellow (unavailable) and sends a connection limit reached SNMP trap when all members of a pool are manually disabled.

Note: The correct virtual server status is red (offline) when all members of a pool are manually disabled.

This issue occurs when all of the following conditions are met:

  • You have manually disabled all members of a pool.
  • You view the virtual server availability status using the Configuration utility.

Impact

The Configuration utility displays an incorrect status and sends and an incorrect SNMP trap.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the virtual server status using the Configuration utility, the status appears incorrect.
  • Your BIG-IP system unexpectedly sends connection limit reached SNMP traps.
