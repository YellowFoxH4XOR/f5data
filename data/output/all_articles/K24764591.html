K24764591: Hosts are being turned off

Type
Support Solution
Published
2022-06-01
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.1.3
Source
https://my.f5.com/manage/s/article/K24764591

Description
Pool members are being marked Down by the health monitors, while the ICMP node monitors show as Up

The following types of log messages may be seen from pool members in /var/log/ltm:

/Common/tcp: down; last error: /Common/tcp: Unable to connect.
/Common/tcp: down; last error: /Common/tcp: No successful responses received before deadline.

Environment

  • BIG-IP
  • Virtual Server Pool with TCP monitor defined
  • Node default ICMP monitors enabled

Cause
This issue appears to be tied to backend server behavior.  The node is still reachable via the ICMP monitor, but the individual services are no longer listening on the port.

Recommended Actions
Review the behavior on the backend servers to confirm that the services are enabled and listening on the correct port(s).

Additional Information
None
