K000159839: After software version upgrade, user is now automatically taken out to logon page when user session expires on GUI.

Type
Support Solution
Published
2026-02-02
Updated
2026-02-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1, 21.0.X, 21.0.0, 17.1.3
Source
https://my.f5.com/manage/s/article/K000159839

Description

After software version upgrade, GUI behavior changed. 

On previous versions, when GUI session expires, user sees pop-up window with notification message "Your login credentials are no longer valid" and user has to press "Log in" button to get back to logon screen. Also, user could see configuration objects behind notification pop-up window although user session had already expired.

Figure: GUI screenshot when session expired (pre ID1624701 fix)

 

After upgraded to specific versions, user no longer see pop-up window. Instead, user is automatically taken to initial logon screen.

Figure: GUI screenshot when session expired (post ID1624701 fix)

 

Environment

  • GUI user session expired (i.e., exceeded "sys httpd auth-pam-idle-timeout" value).
  • Software version 17.1.3.1, 17.5.1.4, or 20.0.0.1 (at the time of article publication).

 

Cause

Bug ID1624701 fix (fixed in 17.1.3.1, 17.5.1.4, and 20.0.0.1, at the time of article publication).

 

Answer/Recommended Actions

None. This is expected behavior change.

 

Additional Information

None.
