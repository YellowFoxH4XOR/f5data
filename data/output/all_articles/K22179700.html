Known Issue

Attempting to use a netHSM key without a BIG-IP HSM license causes the SSL handshake to fail with a generic error message.

This issue occurs when all of the following conditions are met:

  • You are attempting to use a netHSM key.
  • You do not have a BIG-IP HSM license installed.

Impact

All netHSM key exchanges will fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Errors similar to the following example may be seen in the /var/log/ltm log file when the SSL debug option is enabled:

    -- debug tmm3[28399]: 01260009:7: Connection error: ssl_hs_vfy_sign_srvkeyxchg:8309: sign_srvkeyxchg (80)
    -- info tmm3[28399]: 01260013:6: SSL Handshake failed for TCP 10.10.10.13:47804 -> 10.10.10.23:443

Workaround

To work around this issue, you can obtain and install a BIG-IP HSM license for your BIG-IP system.

Impact of workaround: Performing the recommended action should not have a negative impact on your system.
