Description

BigIP VE's mgmt interface may show incorrect media as 100TX-FD from TMSH, but the actual speed is 1 Gbps or 10 Gbps, it depends on the interface type assigned by the hypervisor.

 

Environment

LTM VE

Cause

BigIP VE's mgmt interface media show as 100TX-FD from TMSH, but the actual speed is 1 Gbps or 10 Gbps.

 

Recommended Actions

You can verify the mgmt interface speed from tmsh show net interface and ethtool command
1. From the command "tmsh show net interface"

Example:

tmsh show net interface

2. Use ethtool command to view the eth0(mgmt interface) information

  • Verify the mgmt mac-address from command "ifconfig"

[root@BIGIP-01:Active:Standalone] config # ifconfig
