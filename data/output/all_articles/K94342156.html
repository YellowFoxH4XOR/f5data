Description

The use of scan command is for scanning string and format together then assign the matching value to the specified variables.
 

Environment

  • iRule
  • Scan Command

Cause

None

Recommended Actions

Format of scan string looks similar to: ?varName varName ...?

If a * is present in the conversion specifier then no variable is assigned and the next scan argument is not consumed.

Example: 
  1. Scanning for two variables in an ip address:
    scan [IP::client_addr] %*d.%*d.%d.%d c d
    The scanning format is %*d.%*d.%d.%d and two variables are c and d.
    If client_addr is 10.10.12.250 the value of c and d will be 12 and 250 respectively. (The last two octets without * are used)
     
  2. Scanning for one variable in an ip address: 
    scan [IP::client_addr] %*d.%*d.%*d.%d c
    The scanning format is %*d.%*d.%*d.%d and one variable is c
    If client_addr is 10.10.12.250 the value of c will be 250. (Only the last octet without * is used)
