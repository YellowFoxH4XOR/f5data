Description

  • Export Inventory button missing from BigIQ Devices Tab

Environment

  • BIGIQ
  • Managed BIGIPs
  • Inventory list

Cause

Users without administrative privilege can not export managed BIGIP inventories from BIGIQ.


Recommended Actions

Login with Administrative privileges enabled user to export the inventory list from BIGIQ.

None.
