Description

If erasing one blade in a cluster with the F5 Disk Erase utility, will it rejoin the cluster when it finishes and restarts?

Environment

  • VIPRION
  • Disk Erase

Cause

None

Recommended Actions

After completing Disk Erase and restarting the blade, it will not automatically come into quorum and rejoin the cluster. The following message will be printed at the console upon boot:

Warning: Drive in Bay 1, Shelf A was erased by F5 Disk Erase Utility.
Reboot and Select proper Boot device
or Insert Boot Media in selected Boot device and press a key

The remaining blades will report the erased blade as offline.
