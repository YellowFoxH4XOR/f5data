Known Issue

This is the result of a known issue. If you click the Please click here to start a console session to the Maintenance Account link on the Device Management: Maintenance: Troubleshooting Tools page in the FirePass Administrative Console, the Java applet loads but the login prompt never appears. This issue may occur intermittently, and when it occurs, the Msg field in the bottom right corner of the applet window reports either Re-sync or Closed. When the Java applet is functioning properly, the Msg field reports Ready and then becomes blank.

F5 Networks Product Development tracked this issue as CR98730 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in Cumulative Hotfix HF-602-5 issued for FirePass version 6.0.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by connecting to the FirePass Maintenance Console using a serial connection. For more information, refer to the FirePass Controller Getting Started Guide.
