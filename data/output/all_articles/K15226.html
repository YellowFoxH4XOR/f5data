Issue

Error Message

failed (Signature file not found - /shared/images/BIGIP-<Version-Build>.iso.sig)

In this error message, note the following:

  • <Version-Build> is the BIG-IP version and the build number of the ISO image, which you attempted to install without the appropriate ISO signature (.sig) file in the /shared/images directory.

For example:

failed (Signature file not found - /shared/images/BIGIP-11.5.0.0.0.221.iso.sig)

Message Location

You may encounter this message in the following locations:

  • The tmsh show /sys software command output.
  • The Configuration utility's System > Software Management > Image List page, in the Install Status column of the slot where you attempted the installation.

Description

This message occurs when all of the following conditions are met:

  • The BIG-IP system has the liveinstall.checksig database key enabled.
  • You performed an installation of the BIG-IP software image or hotfix.
  • You do not have the respective signature (.sig) file for the BIG-IP software image or hotfix in the /shared/images directory.

Beginning BIG-IP 11.5.0, the BIG-IP system has the BIG-IP software ISO file authenticity verification feature, which is disabled by default. For more information, refer to K15225: Enabling signature verification for BIG-IP ISO image files.

Impact

The failed installation will not resume even if you provide the matching signature file for the affected BIG-IP ISO file.

Recommended Actions

If you want the BIG-IP system to continue checking the ISO file signature, download the matching signature file for the BIG-IP ISO image file from the F5 Downloads site. You must delete the affected volume that has the failed installation and perform a new installation again.

For more information about using the file authenticity verification feature, refer to K15225: Enabling signature verification for BIG-IP ISO image files.
