Known Issue

The Master Control Program Daemon (MCPD) may fail to validate passphrase-protected SSL keys.

Impact

The BIG-IP system configuration may fail to load.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • An error message similar to the following example is logged to the /var/log/ltm file:

    err mcpd[1234]: 01070712:3: Caught configuration exception (0), Unable to verify key (/Common/pw_key.com) is protected by provided passphrase. - sys/validation/FileObject.cpp

Resolution

Status

F5 Product Development has assigned ID 449617 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases, point releases, or hotfixes that resolve this issue, refer to the following table.

Point release/hotfixNoneNone

Workaround

None. You must remove the passphrase from the SSL key. For more information about removing a passphrase from an SSL key, refer to K14912: Adding and removing encryption from private SSL keys (11.x - 16.x).
