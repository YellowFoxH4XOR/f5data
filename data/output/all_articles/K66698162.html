Description

  • When performing a USB install, the process fails with an error

    error: tm_install::VolumeSet::VolumeSet_add_planned -- error adding /config:83

  • diskinit --style volumes also fails with the same error

Environment

This can occur in any hardware environment when attempting a clean install.

Cause

  • This is caused by bad sectors that cannot be recovered on-the-spot by S.M.A.R.T.
  • IDE Cable or IDE Port issues could also be responsible.

Recommended Actions

  • Run End User Diagnostics (EUD) on the system.
    Note: See K7172: Overview of the End User Diagnostics software for details on how to run an EUD on your platform. 
  • Submit request for RMA
