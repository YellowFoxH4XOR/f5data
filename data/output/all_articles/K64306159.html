K64306159: F5 Configuration Utility does not display the page properly after login

Support Solution
Published
2021-06-24
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 15.1.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.X.X, 15.1.2, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.3
Source
https://my.f5.com/manage/s/article/K64306159

Description

After login to F5 Configuration Utility, the page cannot be displayed properly, only the top banner is showing, the rest of the page (including the menu bar) shows blank.  The following symptoms are noticed:

  • No relative error messages shown in /var/log/httpd/httpd_errors
  • No relative error messages shown in /var/log/tomcat/catalina.out
  • Captured HAR file shows "HTTP 503 (Service Unavailable)" error from requested URL "/xui/update/mainmenu?_=xxxxxx"
  • After restart httpd and tomcat services, issue still exists

Environment

  • BIG-IP
  • Configuration Utility

Cause

Unkown

Recommended Actions

Reboot system from CLI via the command below:

#reboot

Additional Information

None
