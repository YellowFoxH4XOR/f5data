K000135345: Upgrading F5OS from 1.3.2 to 1.4.0 or later fail

Type
Support Solution
Published
2023-07-03
Updated
2023-07-03
Source
https://my.f5.com/manage/s/article/K000135345

Description

Software upgrading F5OS from version 1.3.2 to 1.4.0 and later fail with error message.

 

/qkview/subpackages/host-qkview/qkview/filesystem/var/log/messages

 

MMM DD HH:MM:SS hostname journal: CDB: Upgrade failed: Upgrade transaction failed to validate: /oc-sys:system/aaa/authentication/f5-aaa-ldap:ldap/ssl (value "start_tls"): ssl cannot be start-tls with server type ldaps

MMM DD HH:MM:SS hostname journal: confd_load: 337: maapi_start_trans() failed: operation in wrong state (17): Can't start read-write transaction before phase1

 

 

Environment

  • Prior to upgrading, LDAP server group and TLS were configure together.
  • Upgrading F5OS from version 1.3.2 to 1.4.0 and newer versions

 

Cause

Due to the fix of ID1137341 after version 1.4.0, LDAP server group and TLS are not allowed to configure together.

 

Recommended Actions

  • Do not configure an LDAP server group as type "LDAP over SSL" and also set the LDAP "TLS" setting to "StartTLS".
  • Set the LDAP server group to "LDAP over TCP" if the LDAP "TLS" setting is "StartTLS".
