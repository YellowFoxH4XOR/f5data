Description

The tmsh show /sys hardware command on iSeries platforms does not provide the following information that is available for other platform types:

  • Fan Speed (RPM)
  • Chassis Outlet temps
  • CPU temp

Environment

  • tmsh show /sys hardware command
  • iSeries platform

Cause

This behavior is by-design for iSeries platforms and is not indicative of a failure.

Recommended Actions

You can display the CPU temperature and fan speed sensor information on an iSeries platform using either of the following commands:

  • tmctl sensor_measurement_table
  • ipmiutil sensor

Additional Information

F5 does not support changing thresholds of CPU temperature and FAN speed on iSeries and newer platforms.
