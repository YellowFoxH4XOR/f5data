Known Issue

The Traffic Management Microkernel (TMM) may use a link local address when attempting to forward traffic to an external IPv6 global address.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured to use dynamic routing.
  • Equal Cost Multipath (ECMP) IPv6 routes to a remote destination where the nexthop is a link local address.
  • You have configured a virtual server that generates sideband traffic from TMM, such as DNS resolver.

Impact

The BIG-IP system may fail to forward traffic to remote destinations when traffic routes through link local addresses.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe that traffic egresses from a link local address instead of an IPv6 global address.
  • The BIG-IP system fails to forward traffic to IPv6 global addresses.
