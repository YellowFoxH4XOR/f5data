K25007819: BIG-IP Edge Client may transition to ALWAYS_DISCONNECTED mode

Type
Knowledge
Published
2019-01-31
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.0, 12.1.3, 12.1.2, 13.0.0
  • APM Clients
Source
https://my.f5.com/manage/s/article/K25007819

Topic

When you enable Always Connected mode in the client package, BIG-IP Edge Client for Windows may fail to reconnect after access to the BIG-IP APM system fails.

Description

When you configure Edge Client for Windows with Always Connected mode enabled in the client package and the connection to the BIG-IP APM system fails or is denied for some reason, Edge Client may transition to ALWAYS_DISCONNECTED mode and fail to reconnect. As a result, the client is unable to establish a network access session, even when access to the BIG-IP APM system is restored momentarily.

When this issue occurs, Edge Client generates messages to the %TEMP%\logterminal.txt file on the client system that appear similar to the following example:

Connection mode changed to ALWAYS_DISCONNECTED
CConnectionMgr::RefreshConnections, [ConnMgr] Connection Mode: ALWAYS_DISCONNECTED. Network Location: UNKNOWN. Session State: 3

Recommendations

When you encounter this behavior, you may be able to re-establish network access by deleting the client.f5c file from the client system and restarting Edge Client. The client.f5c file will regenerate once you restart Edge Client. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the client system with administrator privileges.
  2. Stop the Edge Client process (f5fpclientW.exe) using a utility, such as the Windows Task Manager. 
  3. Open the Windows Explorer utility.
  4. Navigate to C:\Users\<username>\AppData\Roaming\F5 Networks\VPN where <username> is the name of the user who is unable to connect.
  5. Right-click the client.f5c file, select Delete, and confirm the action.
  6. Restart Edge Client.
