Known Issue

This is the result of a known issue. The BIG-IP system rejects virtual server connections when the Client SSL profile is configured to request a certificate and the client fails to send a client certificate.

By default the Client Certificate setting in the Client SSL profile is set to ignore certificates from client systems. If the setting is set to request, the BIG-IP system should request a valid certificate from a client and always accept the client connection regardless of whether the client sends a valid certificate.

F5 Product Development tracked this issue as CR111646, and it was fixed in BIG-IP version 10.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue has been fixed in hotfix-BIGIP-9.4.8-396.1-HF3, which has been issued for BIG-IP version 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
