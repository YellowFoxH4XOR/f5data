Description

IP forwarding VIP stopped handling traffic after upgrade from 11.6.3 to 11.6.5.2

Environment

  • BIG-IP system v11.6.5.2
  • Wildcard IP Forwarding Virtual Server

Cause

Due to Bug ID 751409, MCP Validation does not detect when virtual servers differ only by overlapping VLANs. The bug is triggered when there are 2 forwarding VIPs and the impacted one doesn't have vlans specified. To resolve the issue configure both forwarding VIPs to listen on their corresponding VLAN(s).

Recommended Actions

Delete both forwarding VIPs and recreate each one listening on their corresponding VLAN
