K8204: Error Message: The DNS server(s) configured for FirePass are unreachable via ICMP echo request (ping)

Issue

The FirePass controller allows an administrator to configure a remote Syslog server, which receives the FirePass system logs. To configure a remote Syslog server, select the Enable Remote Log Server check box and configure the Remote host field of the System Logs section on the Device Management: Maintenance: Logs page.

The Remote host field will contain either a hostname, a fully qualified domain name (FQDN), or an IP address. When the Remote host field is populated with one of these forms, and the administrator clicks the Apply System Log Changes button, the FirePass controller will perform the following two actions: 

  • The FirePass controller will send an ICMP echo request (ping) packet to each of the DNS name servers configured on the DNS tab of the Device Management: Configuration: Network Configuration page if an ICMP echo reply packet is received from any one of the servers.
  • The FirePass controller will use the DNS server or servers to perform name resolution on the hostname or FQDN in the Remote host field. DNS name resolution will be performed even if the hostname or FQDN has an entry in the Hosts tab of the Device Management: Configuration: Network Configuration page. If the Remote host field contains an IP address, no DNS resolution is requested, but the ICMP echo request in the first step is still performed.

If the ICMP echo request in the first step does not result in the FirePass controller receiving the ICMP echo response, the following message appears below the System Logs heading:

The DNS server(s) configured for FirePass are unreachable via ICMP echo request (ping). Remote sys log cannot be started without a DNS server to resolve the name or IP address in the Remote host field.

The message will appear even if a different ICMP message, such as an ICMP Destination Unreachable error message, is received.

Common reasons for not receiving an ICMP echo response are as follows:
  • The DNS server or servers are down or unreachable
  • The DNS server or servers are configured not to respond to ICMP echo requests
  • A device such as a firewall prevents ICMP echo requests from reaching the DNS servers

When the error message is displayed, the Enable Remote Log Server check box will automatically be cleared.

Workaround

If it is not possible to permit the DNS servers to send ICMP echo replies to the FirePass controller, a workaround can be configured on the FirePass controller by adding the IP address of any pingable device to the end of the list of DNS servers on the Hosts tab of the Device Management: Configuration: Network Configuration page. 

For example:

Name ServersIP Address
Name Server 0:192.168.1.1
Name server 1:192.168.1.2


If the DNS tab contains the above example’s Name Servers configuration, you can add a third address at the bottom of the list, which will appear similar to the following example:

Name ServersIP Address
Name Server 0:192.168.1.1
Name server 1:192.168.1.2
Name server 2:192.168.1.254


Name server 2: 192.168.1.254 could be any pingable IP address, such as the default gateway, or even the FirePass controller itself.  Because this system is pingable, the error message does not appear, and the FirePass controller can proceed to making the DNS query in the second step.

By placing the address last in the list, the normal DNS resolution for the FirePass controller's other name resolution requirements are not affected.
