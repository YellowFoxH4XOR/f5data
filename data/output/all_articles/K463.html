K463: Support for FTP active mode in virtual servers, NATs, and SNATs

Topic

FTP active mode requires the use of both a control port (port 21) and a data port (port 20). FTP active and passive modes are supported in the following configurations:

  • Virtual servers support both active and passive FTP
  • SNATs support both active and passive FTP
  • NATs support active FTP for traffic inbound to the translated address and passive FTP for traffic outbound from the translated address

If you receive a 500 Illegal Port Command error when attempting to open an FTP connection from a node that accesses the Internet through a BIG-IP NAT, use passive FTP.
