Description

DNS sync group may fails to sync Zone files after upgrade to 15.x

Environment

  • DNS sync Zone files are not being synched.
  • Recently upgraded to 15.x FW version
  • Probably seen messages like: "Error: SYNC_ZONES from <IP> skipped. Reason: sync_zones currently running from ip <IP>" as per K19315323
  • It can occur that workaround described in K19315323 do not fix the issue.
  • zrd daemon is Down or Flapping after upgrade, can be verified as following example with a 'show sys service all | grep zrd' command:
          (tmos)# show sys service all | grep zrd
      zrd down, rndc down
 
  • It can be possible to see something similar to this on audit logs:
    audit logs suggest that this could be SElinux permission issue: type=AVC msg=audit(2021-05-11T19:19:13-03:2085): avc: denied { read } for pid=21801 comm="rndc" name="rndc.key" dev="dm-13" ino=30 scontext=system_u:system_r:ndc_t:s0 tcontext=system_u:object_r:unlabeled_t:s0 tclass=lnk_file

Cause

Unknown at the time of publication 

Recommended Actions

Sync failures can be related to the fact zrd is down. Apply the following workaround to fix SElinux permission issues: 

  1.- #touch /.autorelabel
  2.- #reboot

Additional information
