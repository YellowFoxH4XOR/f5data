Description

  • Aggressive mode sweeper killing connections frequently
  • Users reporting getting disconnected and warning and error messages logged
  • Error messages in /var/log/ltm

 

warning tmm1[PID]: 011e0002:4: sweeper_segment_cb_any: Aggressive mode /Common/default-eviction-policy activated (100000000001b) (global memory). (4396598/5172224 pages)
warning tmm3[PID]: 011e0002:4: sweeper_segment_cb_any: Aggressive mode /Common/default-eviction-policy activated (300000000001c) (global memory). (4396598/5172224 pages)
warning tmm[PID]: 011e0002:4: sweeper_segment_cb_any: Aggressive mode /Common/default-eviction-policy activated (1a) (global memory). (4396598/5172224 pages)
warning tmm2[PID]: 011e0002:4: sweeper_segment_cb_any: Aggressive mode /Common/default-eviction-policy activated (200000000001d) (global memory). (4396598/5172224 pages)
err tmm[PID]: 011e0003:3: Aggressive mode sweeper: /Common/default-eviction-policy (1a) (global memory) 55396 Connections killed
err tmm2[PID]: 011e0003:3: Aggressive mode sweeper: /Common/default-eviction-policy (200000000001d) (global memory) 111368 Connections killed
err tmm1[PID]: 011e0003:3: Aggressive mode sweeper: /Common/default-eviction-policy (100000000001b) (global memory) 112090 Connections killed
err tmm3[PID]: 011e0003:3: Aggressive mode sweeper: /Common/default-eviction-policy (300000000001c) (global memory) 111581 Connections killed
err tmm[PID]: 011e0003:3: Aggressive mode sweeper: /Common/default-eviction-policy (1a) (global memory) 227355 Connections killed
err tmm2[PID]: 011e0003:3: Aggressive mode sweeper: /Common/default-eviction-policy (200000000001d) (global memory) 226653 Connections killed

 

Environment

  • BIGIP configured with SNAT specific or global
  • Translation addresses used for translating client IP addresses have default settings
  • Many clients using SNAT or global SNAT

Cause

TMM memory exhaustion due to many idle SNAT connections.

 Recommended Actions

Modify snat-translation addresses to use lower idle timeout, see K000132182 .

Additional Information

You can verify memory usage by checking memory usage by components "bigip_connection" and "source addr translation" by running below commands and check usage of each component.

 

tmctl -d blade memory_usage_stat -s name,allocated,max_allocated

tmctl -d blade tmm/umem_usage_stat -s name,allocated,max_allocated

 

Verify how many SNAT addresses have open/idle connections.

 

tmctl -d blade profile_bigproto_stat -s name,vs_name,open name=_bigproto
