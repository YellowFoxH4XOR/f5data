K08525994: Find the APM Client Version via the BIG-IP Edge Client

Type
Support Solution
Published
2022-07-29
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K08525994

Description
In a troubleshooting session, it is sometimes necessary to identify or verify the APM Client version that a particular customer is running. 
Sometimes, K49063135 is not useful as the information is not reported to the logs.

Environment

  • APM Client version
  • Edge client

Cause
None

Recommended Actions

  1. Open BIG-IP Edge Client.
  2. Click on View Details.
  3. Then, select the Miscellaneous tab, the info is shown under Version Information.
It would read something like 7221,2022,412,1126

Additional Information
None
