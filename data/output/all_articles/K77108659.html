Description

When attempting to enable auto-renew for a SSL Certificate within SSL Certificate Order Manager. It's not available until 2 weeks of expiration. 

Environment

  • BIG-IP
  • SSL Certificate Order Manager

Cause

  • When the certificate is within (2 weeks) from expiring the option for enabling auto renew will become available. 
  • When the certificate is within (1 week) from expiring the option for auto renew will automatically be selected. 
  • The request is not sent automatically as you need to fill in the "ID" field and then select update. 
  • Update must be selected in order for the request to be processed. Otherwise you will see errors like the following in the logs. 
  • Dec 31 12:00:00 f5-lab-device info mcpd[12345]: 01b50026:6: Key (/Common/New_SSL_Cert) cert-order-manager (/Common/Certificate_authority_manager) at status (none) received order-type (auto-renew) order-id () download-cert(0).
Dec 31 12:00:00 f5-lab-device err mcpd[12345]: 01b50039:3: Key (/Common/New_SSL_Cert) certificate order manager order-id should not be empty while making a renewal order.

Recommended Actions

To renew certificate via the CLI within the two week window perform the following. 
  1. Create CSR for the SSL Certificate
  2. Select "NONE" and Order ID example (12345) 
  3. Update and refresh the Certificate
  4. Login to TMSH
  5. Run the following command to enable:
    • tmsh modify sys crypto cert-order-manager Certificate_authority auto-renew no
    • tmsh modify sys crypto cert-order-manager Certificate_authority auto-renew yes
  6. Refresh the WebUI. 
  7. Certificate should be enabled for auto-renew if it's within the 2 week window. 

Additional Information

  • SSL Certificate Management v15.x 
  • SSL Certificate Management v16.x
