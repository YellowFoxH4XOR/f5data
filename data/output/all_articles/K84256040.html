Description
A configured CAPTCHA as part of authentication for an Access Policy is failing. User may see "Data provided for authentication is not valid. Please try again.".
Following errors showing for failing session logs:

014902b9:3: <access_policy>:<session ID>: CAPTCHA verification failed with error code: invalid-input-secret
0149027d:5: <access_policy>:<session ID>: CAPTCHA (/Common/My_Captcha) verification failed.


Environment

  • BIG-IP APM
  • CAPTCHA authentication object

Cause
The secret parameter is invalid or malformed.

Recommended Actions

Fix the keys of the CAPTCHA object, Secret and Site Key. Make sure the strings are correct, with no missing or extra characters.

Additional Information
None.
