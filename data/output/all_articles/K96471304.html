Description

You may see the bellowing log in /var/log/ltm
On active device:
mcpd[<PID>]: 010718ed:5: DATASYNC: requested force sync by user: %bdosd

On standby device;
mcpd[<PID>]: 010714a0:5: Sync of device group /Common/dos-global-dg to commit id 1168958 7126383151908447683 /Common/DC01_F5_A.test.cn 0 from device /Common/DC01_F5_A.test.cn complete.

In this log message:
  • <PID> is the process id of mcpd process

Environment

  • AFM
  • HA

Cause

'dos-global-dg' is auto-generated when AFM is provisioned, the device group is created internally for BDoS(Behavioral DoS) HA purpose. The log messages are triggered as a result of the regular auto sync for the device-group 'dos-global-dg'

Recommended Actions

You can safely ignore these message and it will not bring any service impact. You can also disable these messages by changing the logging level of mcpd process, the default logging level is Notice:
# tmsh list sys db log.mcpd.level
sys db log.mcpd.level {
    value "Notice"
}

Additional Information

For how to change the logging server, you can refer to the bellowing article:
K5532: Configuring the level of information logged for Traffic Management-related events
