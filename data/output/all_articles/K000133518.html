K000133518: tcpdump stopped with an error "errbuf ERROR:Session expired due to timeout"

Type
Support Solution
Published
2023-04-14
Updated
2023-04-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000133518

Description

When using tcpdump without the -n option, it may abnormally stop and throw an error that says "errbuf:Session expired due to timeout" together with "tcpdump: pcap_loop: Session expired due to timeout". See sample output below.
 

00:00:43.666676 ARP, Ethernet (len 6), IPv4 (len 4), Request who-has 192.168.30.14 tell 192.168.30.11, length 66 in slot1/tmm0 lis=

errbuf:Session expired due to timeout

tcpdump: pcap_loop: Session expired due to timeout

338 packets captured

338 packets received by filter

0 packets dropped by kernel
 

Environment

  • Tcpdump
  • DNS Server Lookup List is configured with addresses but are not working or reachable.


Cause

  • Failure of tcpdump to resolve a host from a DNS server.

 
Recommended Actions

  • Ensure that the DNS Server Lookup List contains reachable and working DNS servers.
  • Alternatively, use the -n option to disable name resolution. For example:

tcpdump -vvv -ni <interface> <filter>
