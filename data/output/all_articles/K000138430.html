Description

FAST: Unable to delete a FAST application if a Pool Member is Forced Offline (01020036:3: The requested Pool Member was not found.)

 

Environment

  • BIG-IP
  • FAST
  • AS3

 

Cause

 

If the FAST Application being deleted references a Pool from a different FAST Application, the operation will fail if a Pool Member is manually set to a Forced Offline State.

 

Recommended Actions

Manually Enable, Disable, or remove the Forced Offline Pool Member.

 

Additional Information

  • This issue does not occur if the Pool Member is in a Disabled state.
  • In a future FAST release there will be an option to set the Pool Member state via the FAST Template.
