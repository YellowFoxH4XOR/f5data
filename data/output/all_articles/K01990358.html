Description

For most standard virtual server configurations you can delete the virtual server object from the BIG-IP configuration without first removing associated local traffic resources, such as Pools, iRules, Profiles and Policies. Deleting a virtual server with associated resources does not delete the associated local traffic resources from the BIG-IP configuration.

Note: Some configurations may create a dependency on the virtual server object that you want to delete, preventing you from removing the virtual server. For example, if you have another virtual server with an iRule that references the virtual server that you want to delete, you must remove the virtual server reference from the iRule before you can delete the desired virtual server.

Environment

Relevant environmental factors:

  • BIG-IP with a virtual server configured that needs to be deleted.

Cause

Need to delete a virtual server from a BIG-IP configuration.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Delete the virtual server via Configuration utility or TMOS Shell.
    1. Log in to tmsh on the command line by entering the following command:
      tmsh
    2. Delete virtual server by using the following syntax:
      delete ltm virtual <vs name>
  2. You can delete virtual server using the Configuration utility:
    1. Log in to the Configuration utility.
    2. Go to Local Traffic > Virtual Servers > Virtual Server List.
    3. Select virtual verver name.
    4. Select Delete.
  3. If the virtual server's virtual address is unused by any other virtual server, the virtual address associated with the deleted virtual server, can also be deleted under "Local Traffic > Virtual Server > Virtual Addresses".
