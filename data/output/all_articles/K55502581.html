Issue

Error Message

01010028:3: No members available for pool <pool_name>

In this error message, note the following:

  • <pool_name> is the name of the pool.

For example:

01010028:3: No members available for pool example_pool

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility
Description

This message occurs when one of the following conditions is met:

  • The pool is marked down by a monitor because none of the pool members are reachable.
  • A hardware or software issue prevents pool monitors from communicating successfully with pool members.

Impact

The pool is marked down, and services requiring the pool members are unavailable.

Recommended Actions

BIG-IP health monitors may mark a pool member down because the node or pool member's service is unresponsive, the monitor is configured incorrectly, or because some other issue is preventing successful monitoring such as network issues. To determine why a monitor marked a pool member down, refer to K12531: Troubleshooting health monitors.
