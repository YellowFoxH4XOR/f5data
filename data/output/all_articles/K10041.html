Known Issue

This is the result of a known issue. In BIG-IP version 9.x, the SSH .shosts file was stored in the /root directory. In version 10.x, the .shosts file was replaced with a symlink to the /var/ssh/root/shosts file. When you upgrade from BIG-IP version 9.x to version 10.x, the symlink is correctly created, although the contents of the original /root/.shosts file from version 9.x may not be migrated to the /var/ssh/root/shosts file. As a result, SSH connections from the SCCP or AOM to the host may not function.

F5 Product Development tracked this issue as CR120833 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, or WebAccelerator release notes.

Workaround

If you have upgraded from version 9.x to version 10.x, and SSH connections from the SCCP or AOM to the host are not functioning, you can attempt to work around the issue. To do so, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Using a text editor, manually create the /var/ssh/root/shosts file with the following contents:

    127.0.0.1
    127.2.0.1
    127.2.0.2
  3. Save the changes and exit the file.
