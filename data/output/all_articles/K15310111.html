Issue

Error Message

sod<pid>: 010c005b:5: Dropping a packet that is not a failover packet.

In this error message, note the following:

  • <pid> is process ID of the affected daemon.

For example:

sod[9122]: 010c005b:5: Dropping a packet that is not a failover packet.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The sod process detects and discards a malformed packet on a network failover interface.

BIG-IP systems configured to use network failover send heartbeat packets over the network to device group members. The network failover heartbeat packets use MCP message encoding and are transported over the network using UDP. The packets contain data used to communicate a device's availability and failover status and appear similar to the following example:

out slot1/tmm0 lis=
13:53:58.432941 IP 10.0.0.34.57696 > 10.0.0.36.cap: failover_packet {
   failover_packet_cluster_mgmt_ip ip_address 172.16.17.23
   failover_packet_slot_id uword 0
   failover_packet_state ulong 5
   failover_packet_sub_state ulong 0
   failover_packet_monitor_fault ulong 0
   failover_packet_hop_cnt uword 0
   failover_packet_peer_signal ulong 0
   failover_packet_version ulong 2
   failover_packet_msg_bits ulong 2
   failover_packet_traffic_grp_score ulong 7694
   failover_packet_device_load ulong 1
   failover_packet_device_capacity ulong 0
   failover_packet_traffic_group_load ulong 1
   failover_packet_build_num ulong 2825870500
   failover_packet_next_active ulong 1
   failover_packet_traffic_grp string `/Common/traffic-group-1`
   failover_packet_previous_active ulong 1
   failover_packet_active_reason ulong 0
   failover_packet_left_active_reason ulong 1
}

Impact

There is no impact; the BIG-IP system discards malformed or incorrect packets that are received on a failover interface.

Recommended Actions

None
