Topic

Message Routing Framework (MRF) Diameter allows the BIG-IP system to route all messages through a single connection to its Diameter peer. Compared to previous releases, BIG-IP 15.1.x collects more protocol specific statistics per pool member (Diameter peer) and sends SNMP traps to notify the monitoring systems so as to enhance the ability to monitor the health of diameter peers.

Description

In BIG-IP 15.1.x, the BIG-IP system includes the following changes to provide protocol specific statistics per pool member (Diameter peer):

  • Message-based counters are included in the existing statistics tables for virtual server, pool, and pool members.
  • A new statistics table is added to capture connection, packet, byte, and message-based activities for egressing connections created by the Diameter transport configuration profile.
  • When the Associate Clientside to Pool member setting is enabled in the MRF Diameter router profile, the pool member can collect client-side statistics if one of the configured routes list the pool member that matches the IP and port of the client-side connection or just the port in the case of an ephemeral connection.
  • Additional statistics counters are included in the existing statistics table for the MRF Diameter session profile to assist with observing the health of connected Diameter peer. For example, counters such as answer messages with result codes breakdown are included.
  • The system uses new conditional log events to generate SNMP traps.

Several SNMP traps are added or enhanced to utilize collected statistics. For more information about these traps, refer to K10202756: SNMP Traps for MRF Diameter per peer statistics on the BIG-IP system.

Recommendations

You must enable the Per Peer Stats Collection setting in the MRF Diameter router profile for the BIG-IP system to collect protocol specific statistics per pool member (Diameter peer). To do so, perform either of the following procedures:

Impact of procedure: Performing either of these procedures should not have any impact to your system.

Enabling per-peer statistics collection using the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > Message Routing > Diameter.
  3. Select Router Profiles.
  4. Select the router profile you want to use.
  5. Under Statistics Collection Settings, for Per Peer Stats Collection, select Enabled.
  6. Select Update.

Enabling per-peer statistics collection using tmsh

  1. Log in to the TMOS Shell (tmsh).
  2. Enter the following command syntax:

    modify ltm message-routing diameter profile router <diameter router profile name> per-peer-stats enabled

    For example, to enable the Per Peer Stats Collection setting for the myexamplediameterrouter profile, enter the following command:

    modify ltm message-routing diameter profile router myexamplediameterrouter per-peer-stats enabled

  3. Save the changes by entering the following command:

    save sys config
