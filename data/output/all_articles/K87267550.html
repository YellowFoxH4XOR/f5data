K87267550: Error Message: ''Configuration error: Configuration from primary failed validation: 01071ab6:3: The requested media [__] for interface [__] is invalid. Valid settings are: [__]. Please see SOL14556 for details.... failed validation with error 17242806.''

Description

  • Viprion slot is offline 
  • Error messages
    • "Configuration error: Configuration from primary failed validation: 01071ab6:3: The requested media [__] for interface [__] is invalid. Valid settings are: [__]. Please see SOL14556 for details.... failed validation with error 17242806."

Environment

  • Viprion with multiple blades
  • Viprion blade

Cause

This is due to a configuration inconsistency between blades in a Viprion system. If slot1 has it's SFP media type set to something like 1000T that tries to get copied to the other slots, if the media type is invalid then the configuration load will fail on the other slots resulting in the blade being offline.

Recommended Actions

  1. Review the LTM logs for the error message noted above and note the interface mentioned. 
  2. Enter a tmos shell:
    # tmsh
  3. Modify the interface media to a compatible value such as "auto"
    # modify net interface 1/1.1 media-sfp auto
  4. Save the configuration
    # save /sys config
