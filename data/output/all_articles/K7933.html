K7933: Removing wildcard entries added by the Policy Builder

Topic

The Policy Builder utility can be used by an administrator to generate a detailed security policy for the BIG-IP ASM system. When you run the Policy Builder utility, it adds wildcard expression objects for object types, objects, and parameters.

If the administrator starts the Policy Builder utility, and then clicks Stop to end the Policy Builder process before it has completed running, an incomplete wildcard expressions object may remain for object types, objects, and parameters. As a result, requests are incorrectly blocked by the security policy.

To remove wildcard entries added by the policy builder, perform the following procedure:

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Application Security > Web Applications.
  3. Click the name of the web application.
  4. From the Application Security menu, select Object Types.
  5. Select the check box next to the wildcard (*), and click Delete.
  6. Repeat steps 4 and 5 for object and parameter wildcard objects.
  7. Click Apply Policy.

Note: If the wildcard objects were created by running the Policy Builder with the Typical Security Template set to Typical, you should remove all wildcard expressions including object types, objects (both HTTP and HTTPS), and parameters.

Note: If the wildcard objects were created running the Policy Builder with the Typical Security Template set to Basic, you should remove wildcard expressions for object types and parameters.
