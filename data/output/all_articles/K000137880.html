Description

The following logs can be seen in /var/log/ltm when you Re-activate the device's license.

  • warning chmand[3801]: 012a0004:4: CHMAN request (from get_dossier) for tag:19 failed
  • notice mcpd[5488]: 0107143c:5: Connection to CMI peer /Common/<device_hostname> has been removed
  • notice mcpd[5488]: 01070419:5: Platform initialization phase triggered.
  • warning sod[5989]: 010c007c:4: Device waiting in Offline for configuration load to complete.
  • notice sod[5989]: 010c0054:5: Offline for traffic group traffic-group-1.
  • notice sod[5989]: 010c003e:5: Offline

 

Environment

  • BIG-IP
  • License Re-activation

 

Cause

Need to Re-activate the license.

 

Recommended Actions

Important: The license reactivation process will trigger a reload of the configuration, which will temporarily interrupt all traffic processing. This process can also trigger an unexpected Failover event if performed on an Active HA mode BIG-IP system. 

  1. To prevent unwanted Failover, always perform license Re-activation on the Standby device.
