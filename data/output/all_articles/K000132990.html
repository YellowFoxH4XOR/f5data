K000132990: Error message: blk_update_request: I/O error, dev sda, sector xxxxxxxxx

Type
Support Solution
Published
2023-03-15
Updated
2025-04-01
Applies to
  • BIG-IP
  • Virtual Editions
Source
https://my.f5.com/manage/s/article/K000132990

Description

Console of BIG-IP VE/VCMP version logs constantly similar to below log.

blk_update_request: I/O error, dev sda, sector xxxxxxxxx

For example, /var/log/kern.log displays similar to be below messages:

info kernel: sd 0:0:0:0: [sda] FAILED Result: hostbyte=DID_OK driverbyte=DRIVER_SENSE
info kernel: sd 0:0:0:0: [sda] Sense Key : Vendor Specific(9) [current]
info kernel: sd 0:0:0:0: [sda] <<vendor>>ASC=0x80 <<vendor>>ASCQ=0x85
info kernel: sd 0:0:0:0: [sda] CDB: Write same(16) 93 08 00 00 00 00 09 8c c0 00 00 00 20 00 00 00
err kernel: blk_update_request: I/O error, dev sda, sector xxxxxxxxx
warning kernel: EXT4-fs (dm-19): discard request in group:12 block:10752 count:1024 failed with -5

 

Environment

  • BIG-IP VE version or VCMP systems 

Cause

  • Possible hardware issue on the host level.

Recommended Actions

If the impacted device is a valid virtual hard disk storage such as hdx or sdx, check on the VCMP host/Hypervisor system log for related activity.
blk_update_request: I/O error, dev sda, sector xxxxxxxxx

Else, for peripheral device such as floppy disk and DVD drive, this can be safely ignored as they are not used by virtual system.
blk_update_request: I/O error, dev fd0, sector xxxxxxxxx
blk_update_request: I/O error, dev sr0, sector xxxxxxxxx
