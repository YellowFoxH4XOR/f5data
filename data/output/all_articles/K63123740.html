Description

Attempts to connect to RDP resource via BIG-IP APM fail to launch.

  • Access is successful and the client can be downloaded.
  • Logs indicate starting RDP desktop.
  • No traffic can be seen to the RDP resource.
Users may see the following error when trying to launch the desktop:

An error occurred while communicating with the Remote Desktop Gateway. If this keeps happening, contact your network administrator for assistance.
or  
Your Computer cannot connect to the Remote Desktop Gateway Server

Environment

  • APM provisioned.
  • Remote Desktop configured but will not work.

Cause

The clientssl profile is configured with client certificate authentication with Request enabled. 

Recommended Actions

Change the clientssl profile configuration from Request to Ignore and configure the APM VPE with On Demand cert auth.

Additional Information

If Certificate authentication is required, configure the APM VPE with On Demand cert auth. This way cert auth happens once during the browser portion of going through the policy and before launching the RDP Client.

The browser handles the cert request as it should, but because the client ssl profile is set to request, a new connection (launching of the RDP client) will generate the prompt and the RDP client doesn't like the certificate request. Set the clientssl profile to ignore and add the OnDemand Cert Auth in the VPE.  This way, the request for the client cert happens one time during the execution of the VPE and never again.
