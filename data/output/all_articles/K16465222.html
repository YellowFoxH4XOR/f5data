Known Issue

The Configuration utility may incorrectly reset the Certificate Key Chain setting of a Client SSL profile to its default values.

This issue occurs when all of the following conditions are met:

  • You use the Configuration utility to create a Client SSL profile.
  • You configure the new Client SSL profile to inherit from a parent profile other than the default, clientssl.
  • You customize the Certificate Key Chain setting of the new Client SSL profile by changing the default certificate and key.
  • You use the Configuration utility to change any setting in the affected Client SSL profile.

Impact

The Client SSL profile uses the wrong certificate, key, or chain.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you modify the affected Client SSL profile in the Configuration utility, you observe that the Certificate Key Chain setting resets to its default values.

    For example, you observe the default values in the TMOS Shell (tmsh), and they appear as in the following example:

      tmsh list ltm profile client-ssl example_profile cert-key-chain
      ltm profile client-ssl example_profile {
        cert-key-chain {
            default {
                cert default.crt
                chain none
                key default.key
                passphrase none
            }
        }
      }

Workaround

To work around this issue, you can use tmsh instead of the Configuration utility to modify the affected Client SSL profile. Alternatively, in the parent profile of the affected Client SSL profile, you can select the Certificate Key Chain check box. This sets the value of inherit-certkeychain to false, preventing the issue from occurring. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > SSL > Client.
  3. Click the name of the parent profile of the affected Client SSL profile.
  4. Select the Certificate Key Chain check box.
  5. Click Update.
