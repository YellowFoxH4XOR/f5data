Description

Due to various reasons, a VELOS tenant might not get deployed properly.

In kubernetes you would 'kubectl describe ...' the pod to see what is happening.

On VELOS you can run the following command in the CLI (operational mode):

show tenants

It might say "starting":

Allocating resources to tenant is in progress

Environment

This can happen when you are trying to deploy a new VELOS tenant

Cause

Unspecified

Recommended Actions

  1. Redeploy (could fix the issue)
  2. Reboot the device (fixes the issue most of the time)
  3. Upgrade to latest version (If there is a bug, it might be resolved in a newer version)
