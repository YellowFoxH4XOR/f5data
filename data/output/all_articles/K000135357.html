K000135357: Error "A certificate is required to complete client authentication" after Edge Client upgrade

Type
Support Solution
Published
2023-07-06
Updated
2023-07-06
Applies to
  • BIG-IP
  • APM Clients
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000135357

Description

After upgrading Edge Client to version 7.2.4.1, Client are getting the following pop-up error during authentication:

"A certificate is required to complete client authentication".

 

Error may show intermittently.

 

On a CTU client report the following logs may be found:

<date>, 7272,26988,APPCTRL, 48, \UBindSecurityMgr.h, 89, UBindSecurityMgrImpl::OnSecurityProblem, Client cert requested

<date>, 7272,26988,APPCTRL, 2, \UBindSecurityMgr.h, 109, UBindSecurityMgrImpl::OnSecurityProblem, Denied Untrusted Virtual Server

 

Environment

• Edge Client version 7.2.4.1 or higher

• Access policy with a "Client Cert Inspection" agent

• SSL Client profile with "Client Certificate" set to "request" or "require"

 

Cause

Bug ID 1307717.

 

Recommended Actions

Contact F5 Support and request an Engineering HotFix.

 

Additional Information

None.
