K000147825: What do I need to do to grade a domain as secure while running a security scan?

Description

  • You are running a security/vulnerability scan (for example: https://securityheaders.com/) to the domain and want to grade the domain as secure.
  • What do you need to do to grade the domain as secure?
  • How do you protect/add Security Headers?

Environment

  • F5® Distributed Cloud HTTP Load Balancer

Answer/Recommended Actions

You have to add the following HTTP Headers to grade the domain as secure:

  • Content-Security-Policy
  • X-Frame-Options
  • X-Content-Type-Options
  • Referrer-Policy
  • Permissions-Policy

The headers have to be added under the HTTP Load Balancer > Other Settings > More Options > Header Options.

It is important for you to know the values that are valid. You can find the official documentation here: https://developer.mozilla.org/
