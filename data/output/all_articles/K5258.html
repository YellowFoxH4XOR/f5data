K5258: 3-DNS may overwrite configuration changes that are made while synchronization is in progress

Known Issue

This is most likely the result of a known issue. 3-DNS does not prevent you from making configuration changes while automatic configuration synchronization is in progress. As a result, when the automatic configuration synchronization completes, 3-DNS may overwrite the configuration changes you made.

Because synchronization usually completes quickly, this issue rarely occurs.

F5 Network Product Development tracked this issue as CR30225.
