Known Issue

This is the result of a known issue. When the BIG-IP ASM system uses a logging profile with remote storage enabled for the ArcSight storage type, the anomaly detection and violation reports that are sent to the remote ArcSight system include cumulative values for the Dropped Requests event counter. These cumulative values include all events since the start of the attack. However, the remote ArcSight system expects delta values, which are the number of new requests dropped since the last report. As a result, the remote ArcSight system will report inaccurate totals for the Dropped Requests.

F5 Product Development tracked this issue as ID 226733 (formerly CR142062) and it was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP ASM or PSM release notes.

In addition, this issue was fixed for ID 324382 in Hotfix-BIG-IP-10.2.0-1755.1-HF1, issued for BIG-IP version 10.2.0. You may download this hotfix or a later version of the  hotfix from the F5 Downloads site.
