Topic

In BIG-IP APM 12.x, you can individually configure the logging levels for access policy components for each access policy. You can create a custom logging profile and then add the logging profile to your access policy.

To enable debug logging for the websso process, you must configure the default logging profile (default-log-settings).

Description

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the Configuration utility.

Procedures

Enabling debug logging for the websso process

When troubleshooting issues with single sign-on (SSO) on the BIG-IP APM system, it may be useful to turn on debug logging for the websso process. You can enable debug logging for the websso process in an access policy by using the Configuration utility. To do so, perform the following procedure:

Impact of procedure: Enabling websso debug logging may cause excessive logging in a system with a large number of user logins. You should only enable debug logging when troubleshooting. You should disable debug logging once you've finished troubleshooting.

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > Event Logs > Log Settings.
  3. Select default-log-setting.
  4. Click Edit.
  5. Make sure the Enable Access System Logs check box is selected (selected by default).
  6. Click Access System Logs in the left column to configure the log settings.
  7. Set the log level for SSO to Debug.
  8. Click OK.

Once you finish troubleshooting, you should disable debug logging for the websso process by resetting logging to its default value. To do so, perform the previous procedure steps 1-6, set the log level for SSO to Notice, then click OK.
