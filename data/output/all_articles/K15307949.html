Description

The Status LED of device shows "Amber Solid" state on standby device whereas it shows "Green Solid" on  Active device.

Environment

  • BIG-IP standby device 
  • iSeries hardware

Cause


Amber Solid state of status LED should be expected behavior if device is in HA standby state and booting fine. Refer to the following for additional information.

  • Platform Guide: i2000/4000 Series
  • Platform Guide: i5000/i7000/i10000/i11000 Series
     

Recommended Actions

None as this is expected behavior.

None
