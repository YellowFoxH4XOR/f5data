K000129982: RSET command when using SMTP with StartTLS

Type
Support Solution
Published
2022-12-29
Updated
2022-12-29
Source
https://my.f5.com/manage/s/article/K000129982
Description
When using StartTLS for SMTP the RSET command might be noticed in the packet capture, after TLS handshake.
Environment
  • BIG-IP LTM
  • SMTP with StartTLS
 Cause
Upon completion of the TLS handshake, the SMTP protocol is reset to the initial state (the state in SMTP after a server issues a 220 service ready greeting). The server MUST discard any knowledge obtained from the client, such as the argument to the EHLO command, which was not obtained from the TLS negotiation itself. 
Recommended Actions
No actions required. This is expected behavior.
Additional Information
RFC3207 - 4.2 Result of the STARTTLS Command
