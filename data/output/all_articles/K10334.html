Known Issue

This is the result of a known issue. When you use the Configuration utility to change the enable/disable status of a BIG-IP GTM object, the updated status may not immediately reflect in the Configuration utility. The change is immediately made to the wideip.conf configuration file, but the object's visual status is not updated in the Configuration utility.

For example, if you use the Configuration utility to disable a link on the BIG-IP GTM system, the change is made immediately to the wideip.conf file; however, the link's visual status does not immediately change.

This issue occurs when the gtmd process has not yet updated the shared memory segment used by the mcpd process, and the mcpd process returns the old status displayed by the Configuration utility.

F5 Product Development is tracking this issue as ID 248701 (formerly CR92216).
