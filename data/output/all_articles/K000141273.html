K000141273: VELOS partition upgrade failed - Cannot allow stp on an interface with an assigned aggregate-id

Type
Support Solution
Published
2024-09-30
Updated
2024-09-30
Applies to
  • F5OS
  • F5OS-C: 1.5.X, 1.6.X, 1.6.2, 1.6.1, 1.6.0, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000141273

Description

Attempted to upgrade VELOS partition, which resulted in:

Partition Database upgrade compatibility check failed

The /var/log/sw-util.log file contains a message similar to the following:

upgrade_1_vers_1.6.0-18695 | CDB: Upgrade failed: Upgrade transaction failed to validate: /oc-stp:stp/interfaces/interface{1/1.0}/config/name (value "1/1.0"): Cannot allow stp on an interface with an assigned aggregate-id.

Environment

  • VELOS partition upgrade
  • Interface configuration

Cause

This issue is occurring because STP is enabled on one or more of the individual member links in a LAG.

Recommended Actions

Remove the STP configuration from interfaces which are LAG members, then attempt the upgrade again.

Additional Information

Early versions of F5OS-C allowed STP to be configured on the individual member links in a LAG. Current versions of F5OS do not support this configuration.
