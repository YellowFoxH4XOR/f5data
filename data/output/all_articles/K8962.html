Topic

If your Outlook Web Access (OWA) 2007/2010 server uses forms-based authentication, and you want to configure single sign-on (SSO) using a FirePass portal access favorite, perform the following procedure:

Important: In order to log on using SSO with OWA, the user’s FirePass username and password must be identical to the user’s Exchange username and password.
 
Note: If your OWA server uses basic authentication, and you want to configure SSO using a FirePass portal access favorite, refer to the following document for your version of Microsoft Exchange Server:
 
Deployment Guide: Deploying F5 with Microsoft Exchange Server 2007

Deployment Guide: Deploying F5 with Microsoft Exchange Server 2010

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Portal Access: Web Applications: Resources page.
  3. Click the Add New Favorite link.
  4. In the Name field, enter a name for the favorite.

    For example:

    Outlook Web Access
  5. In the URL field, enter the URL for the owaauth.dll file on the OWA server.

    Note: Typically, this file is located at /owa/auth/owaauth.dll under the root URL.

    For example:

    http://mail.siterequest.com/owa/auth/owaauth.dll
  6. Connect users to OWA as either a public computer with the full OWA web client, a private computer with the full OWA web client, or to the OWA server as a private computer with the OWA light web client:
    • If you want users to connect to OWA as a public computer with the full OWA web client, enter the following content in the URL variables field where [OWA_Root_URL] is the root URL of the OWA server:

      destination=[OWA_Root_URL]/owa&flags=0&forcedownlevel=0&trusted=0&username=
      %username%&password=%password%

      For example:

      https://mail.siterequest.com

    Note: For some OWA 2010 deployments it may be necessary to include the encoding value (isUtf8=1) at the end of the URL.

    For example:

    destination=https://[OWA2010_Root_URL]/owa/&flags=0&forcedownlevel=0&trusted=0&username=%username%&password=%password%&isUtf8=1

    • If you want users to connect to OWA as a private computer with the full OWA web client, enter the following content in the URL variables field where [OWA_Root_URL] is the root URL of the OWA server:

      destination=[OWA_Root_URL]/owa&flags=4&forcedownlevel=0&trusted=4&username=
      %username%&password=%password%

      For example:

      https://mail.siterequest.com
    • If you want users to connect to the OWA server as a private computer with the OWA Light web client, enter the following content in the URL variables field where [OWA_Root_URL] is the root URL of the OWA server:

      destination=[OWA_Root_URL]/owa&flags=5&forcedownlevel=0&trusted=4&username=
      %username%&password=%password%

      For example:

      https://mail.siterequest.com

    Note: For information about the security implications of connecting as a public or private computer, or for information about the OWA Light client, refer to your Microsoft Exchange 2007/2010 documentation.
  7. Select the Use POST for URL variables check box.
  8. Optionally, select the Open in New Window check box.
  9. In the Allow list field, enter a list of URLs required for accessing the OWA server.

    For example:
    • http://mail.siterequest.com/*
    • https://mail.siterequest.com/*
  10. Click the Add New button.
