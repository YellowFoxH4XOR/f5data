Topic

Purpose

You should consider using this procedure under the following conditions:

  • You have modified an existing access profile with the TMOS Shell (tmsh) or the Configuration utility.
  • You want to apply the access profile changes to the BIG-IP APM running configuration using tmsh.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP APM command line or tmsh.

Description

When creating or modifying a BIG-IP APM access profile, the profile changes are not included in the functioning for the active access profile until you have uploaded the changes into the running (active) configuration. When you use the Configuration utility to apply the access profile changes to the running configuration, you must select the access profile in the Access Profile List section and select Apply Access Policy. When you perform the same action using tmsh, the required command syntax is inconsistent with the Configuration utility, which may be confusing. tmsh uses incrementing the access profile changes, but the Configuration utility uses applying access profile changes. The following tmsh procedure covers the required tmsh syntax to apply access profile modifications into the BIG-IP APM running configuration:

Procedures

Updating the BIG-IP APM running access policy configuration using tmsh

To load a specific access profile into the BIG-IP APM active running policy, perform the following procedure:

Impact of procedure: Updating the running configuration with access profile changes immediately applies the changes to subsequent new sessions of the access profile.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Apply the modified access policy to the BIG-IP APM active running configuration:

    modify /apm profile access <access profile name> generation-action increment
