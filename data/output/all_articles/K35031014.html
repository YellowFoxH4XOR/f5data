Issue

Error Message

clusterd[<PID>]: 013a0005:4: <clusterd warning message>

In this error message, note the following:

  • <PID> is the process ID for the clusterd process.
  • <clusterd warning message> is the warning reported by the clusterd process.

For example:

warning clusterd[4224]: 013a0005:4: Software Status table: local slot active entry missing
warning clusterd[4224]: 013a0005:4: Clusterd using /VERSION for SW specification

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • A clusterd process is emitting a log message at the WARNING log level.

Impact

None

Recommended Actions

None
