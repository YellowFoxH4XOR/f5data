Known Issue

The BIG-IP Virtual Edition (VE) and BIG-IQ VE instances may fail to start up properly on the Amazon Web Services (AWS) platform. This issue occurs when all of the following conditions are met:

  • You deployed the VE instance using one of the following Amazon Machine Images (AMI), which was released before 01/21/2014, from the AWS Marketplace:
    • F5 BIG-IP Virtual Edition for AWS (BYOL) version 11.4.0
    • F5 BIG-IP Virtual Edition for AWS (BYOL) version 11.3.0
    • F5 BIG-IQ Virtual Edition for AWS (BYOL) version 4.1.0
  • You have rebooted the VE instance, or a newly-deployed instance is booting up.

This issue occurs because the VE instance is unable to properly instantiate CPU cores and virtual devices after you recently upgraded the hypervisor on the AWS platform.

Impact

The AWS BIG-IP or BIG-IQ instance is not accessible and cannot process traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The AWS BIG-IP or BIG-IQ instance is not accessible.
  • You may observe Linux kernel stack traces similar to the following example right after the system presents the login prompt:

* Important: The BIG-IP 11.4.1 AMI that AWS released on 01/21/2014 on the AWS marketplace contains all fixes included in BIG-IP 11.4.1 HF3. Workaround

If you have not rebooted your AWS BIG-IP or BIG-IQ instance, you must contact F5 Technical Support to request an engineering hotfix, and install the engineering hotfix in a new slot. To prevent the issue from occurring, you must ensure that you reboot the instance to the new slot that contains the engineering hotfix.

If you have rebooted your AWS BIG-IP or BIG-IQ instance, you can recover from this issue by rebuilding your AWS BIG-IP or BIG-IQ instance using the updated BIG-IP or BIG-IQ AMI from the AWS marketplace. To do so, perform the following procedure:

Impact of workaround: If you do not have a backup copy of the affected instance's UCS archive file, you have to reconfigure the instance from scratch.

  1. Log in to your AWS account.
  2. Create a new instance using the updated BIG-IP or BIG-IQ VE AMI from the AWS marketplace, and deploy the instance.
  3. When the instance is up and running, configure the management interface.
  4. Contact F5 Technical Support to allow your VE license to be reactivated.
  5. Log in to your VE instance, and license the new instance with your VE license. For information about licensing the BIG-IP or BIG-IQ VE system, refer to K7752: Overview of licensing the BIG-IP system.
  6. When you have successfully licensed the new instance, perform either of the following steps:
    • If you have a copy of the UCS archive file, upload the UCS archive file and restore the configuration. For instructions on uploading a copy of the UCS archive file, refer to K175: Transferring files to or from an F5 system. For instructions on restoring the configuration, refer to K13132: Backing up and restoring BIG-IP configuration files (11.x).
    • If you do not have a copy of the UCS archive file, reconfigure the new instance from scratch.
