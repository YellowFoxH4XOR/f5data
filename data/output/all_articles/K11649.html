Known Issue

This is the result of a known issue. The End User Diagnostic (EUD) utility may falsely report that the FirePass device has disk block failures in the fsck portion of the output. The output may appear similar to the following example:

***** Run fsck on all drive partitions *****
/dev/discs/disc0/part4: clean, 5194/2626560 files, 133743/5242880 blocks
Size:               pass
Blockcount:         pass
Total:              pass
Direct blocks:      pass
Set sizes:          FAIL
Indirect blocks:    FAIL
Logical sequences:  pass
Physical sequences: FAIL

Overall:            FAIL

This failure status may be incorrect.

F5 Networks Product Development is tracking this issue as CR140272 and it is fixed starting in EUD version 10.0.9.14.

Additionally, point hotfix HF-140272-1-1  has been issued for FirePass versions 6.1.0, 5.5.2, 5.5.1, and 5.5. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
