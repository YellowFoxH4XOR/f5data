Description

Currently, F5’s BIG-IP Access Policy Manager (APM) delivers two Linux client options:

  1. A minimal command-line client (f5fpc)
  2. A browser-based Network Access plugin.

There is no standalone, full-featured graphical user interface (GUI) client for Linux akin to the Windows or macOS Edge Client. Linux users must either:

• Install and script against the f5fpc CLI (login/password only, no endpoint security)

• Use the browser-downloadable Network Access plugin (supports most VPN features, but no drive mappings and limited endpoint security)

For more information about the following methods please refer to the technical documentation here:

https://techdocs.f5.com/en-us/edge-client-7-2-4-1/big-ip-access-policy-manager-edge-client-and-application-configuration-7-2-4-1/clients-for-linux.html
