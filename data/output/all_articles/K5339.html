Topic

FirePass does not support Microsoft Windows XP Embedded as a client operating system.

Application Tunnels and FirePass Network Access (SSL VPN) do not operate with Windows XP Embedded. The Web Application Proxy (MyIntranet) may work properly, but no FirePass features are supported for use with Windows XP Embedded clients
