Topic

Command execution or operating system command injection is a common attack against web applications in which the attacker runs arbitrary commands on the host operating system by way of a vulnerable application. The web applications can be manipulated to process user input using the command line and to run the commands.

Description

The BIG-IP ASM system can mitigate a command execution injections attack with the attack signature feature or with defined metacharacters. This article lists the steps you must follow to mitigate command execution injection using attack signatures and assumes that the default configuration is defined.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the ASM Configuration utility.

Procedures

To mitigate command execution attacks, refer to the following procedures:

  • Adding the command execution signatures
  • Enabling and enforcing the command execution signatures
  • Switching to blocking mode
  • Verifying that command execution attacks are being blocked

Adding the command execution signatures

Impact of procedure: Adding attack signatures to the security policy can generate false positives. In such cases, use the learning page to remove the false positives.

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. Click Advance on the top right.
  4. On Attack Signatures click the expand option.

    The attack signatures sets display.

  5. Click the change button on the right, the Select Policy Attack Signature Sets display.
  6. Click the Command execution / injection options, and click Change.
  7. Verify that the signature set has learn alarm and block enabled.
  8. Click Save and then click Apply Policy.

Enabling and enforcing the command execution signatures

  1. Go to Security > Application Security > Policy Building > Learning and Blocking Settings.
  2. On Attack Signatures click the expand option.

    The attack signatures sets display.

  3. Clear the Enable signatures staging option.
  4. Click Save and then click Apply Policy.

Switching to blocking mode

  1. Go to Security > Application Security > Policy Building > Learning and Blocking Settings.
  2. Go to the general setting in the upper part of the page under enforcement mode and choose Blocking from the list.
  3. Click Save.
  4. Click Apply Policy.

Verifying that command execution attacks are being blocked

  1. Go to Security > Event logs >  Application > Requests.
  2. To open the filer, click Show Filters Details.
  3. Under the Violation list, choose Attack Signature Detected, then click Go.
  4. The blocked request with command execution should be listed in the request log.
  5. The attack type name displays in the request log.
