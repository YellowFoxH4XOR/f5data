Known Issue

When a DNS server fails to respond, or is slow to respond to queries, the BIG-IP ASM bd process may produce a core file.

This issue occurs when the following condition is met:

  • A DNS server being used by the BIG-IP ASM bd process is either down, or responds slowly.

Impact

The BIG-IP ASM system fails to process traffic while the bd process restarts. A failover may occur if the BIG-IP ASM system is part of a high-availability (HA) group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H567687 on the Diagnostics > Identified > Medium screen.
  • In the /var/log/asm file, you may observe messages similar to the following example:

    crit perl[12559]: 01310027:2: ASM subsystem error (exec_core.pl,main::add_ts_log_line): ASM core restarted for recovery purposes

  • In the /var/log/ts/ts.log file, you may observe messages similar to the following example:

    exec_core.pl|ERR|Nov 20 13:27:37.729|12559|main::add_ts_log_line,,ASM core restarted for recovery purposes

  • In the /var/core directory, you may observe a core file that appears similar to the following example:

    bd_bld473_0_core_12559.gz
