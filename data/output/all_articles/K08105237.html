Description

  • GTM configuration may go missing after upgrade
  • You may observe GUI error ' not all configuration has loaded completely '

Environment

  • GTM / DNS
  • Upgrade 

Cause

  • Unknown

Recommended Actions

  • Access the BIG-IP from CLI
  • Use the below tmsh command to verify the validity of GTM configuration
           tmsh load /sys config gtm-only verify
  •  The command may return error like shown below
01071033:3: Server (/Common/app.example.com) contains monitor (min 1 of /Common/bigip /Common/https) which is an invalid type.01071033
Unexpected Error: Validating configuration process failed.
  • Copy/backup up /config/bigip_gtm.conf file following the below command
          cp /config/bigip_gtm.conf /config/bigip_gtm.conf.K08105237.bak
  • Use a text editor like vi, vim, nano or your preferred editor and open /config/bigip_gtm.conf file 
  • Modify configuration and remove the invalid configuration element from affected virtual server like shown below
gtm server /Common/app.example.com {
    ...
    monitor min 1 of { /Common/bigip /Common/https }          <---------------  invalid monitor /Common/bigip
    ...
}
  • After modifying the configuration, you would have it like below 
gtm server /Common/app.example.com {
    ...
    monitor /Common/https            <---------------  valid monitor /Common/https
    ...
}
   
  • Save changes to the file 
  • Verify configuration further following tmsh load /sys config gtm-only verify
  • If all verified correctly without error then use tmsh command to load configuration 
         tmsh load /sys config 
  • Check and verify if configuration loads successfully
