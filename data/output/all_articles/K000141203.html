Description

There is intermittent issue with ECONNRESET. Some of the connections are closed by BIG-IP with [F5RST(peer): TCP retransmit timeout] sent to client.

Environment

  • BIG-IP LTM
  • standard virtual server
  • pool with multiple pool members configured with different ports
  • gateway_icmp monitor

Cause

Back end server is not configured to listen on the same ports as ports specified for pool members. As a result, when traffic is load balanced between pool members, some of them are processing traffic correctly and provides expected responses, but the other are not able to respond to initial SYN from BIG-IP. If pool member never responses, the connection is closed by BIG-IP after TCP retransmissions.

Recommended Actions

To fix the issue you can perform one of the following actions:

  1.  Remove from a pool on BIG-IP the pool member which is not able to respond to traffic sent by BIG-IP.
  2.  Modify configuration on back-end server side to make sure that it can process traffic on the same ports as configured on BIG-IP.

To avoid such issues and check availability of pool members, assign monitor sending probes to pool member on the specific port - for example tcp or http.
