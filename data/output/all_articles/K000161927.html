K000161927: [BIG-IQ] DCD snapshot request timed out

Type
Support Solution
Published
2026-09-08
Updated
2026-09-08
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K000161927

Description

BIG-IQ DCD snapshot jobs report "Request timed out" errors and fail in the GUI, despite CLI and backend logs showing snapshot completion as "SUCCESS".

 

Environment

BIG-IQ has DCD snapshot collection set up.

 

Cause

Bug ID1051505.

Recommended Actions

/var/config/rest/config/restjavad.properties.json file: the value "elasticSearch" should be "elasticsearch".


Update the configuration file and restart BIG-IQ.
