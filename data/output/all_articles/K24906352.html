Known Issue

If you use the BIG-IQ system to change the order of firewall policy rules, the changes may not be deployed to the BIG-IP AFM system.

This issue occurs when all of the following conditions are met:

  • You move two or more firewall rules, together, two or more positions in the list.
  • You deploy the firewall policy to a managed device running the BIG-IP AFM system.

Impact

You cannot correctly deploy the rule-ordering changes you made using the BIG-IQ system to the BIG-IP AFM system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP AFM firewall policy rule order is inconsistent with the rule order on the BIG-IQ system.

Workaround

To work around this issue, you can perform one of the following procedures:

Re-ordering and deploying firewall policy rules one at a time

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

BIG-IQ 5.2.0 and later

  1. Log in to the BIG-IQ system.
  2. Navigate to Configuration > Security > Network Security > Firewall Policies.
  3. Click the name of the policy you want to edit.
  4. If the rule list is not already displayed, click Rules.
  5. Re-order an individual rule as you want.
  6. Click Update.
  7. Click Save & Close.
  8. Proceed with evaluating and deploying the change.

BIG-IQ 5.1.0 and earlier

  1. Log in to the BIG-IQ system.
  2. Navigate to Network Security > Policy Editor > BIG-IP > Firewall Policies.
  3. Click the name of the policy you want to edit.
  4. If the rule list is not already displayed, click the Rules & Rule Lists tab.
  5. Re-order an individual rule as you want.
  6. Click Save & Close.
  7. Proceed with evaluating and deploying the change.

Editing the Description field in the firewall policy rules that you have re-ordered

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

BIG-IQ 5.2.0 and later

  1. Log in to the BIG-IQ system.
  2. Navigate to Configuration > Security > Network Security > Firewall Policies.
  3. Click the name of the policy you want to edit.
  4. If the rule list is not already displayed, click Rules.
  5. Re-order rules as you would like.
  6. For each rule that you re-ordered, click the pencil icon to edit the rule.
  7. In the Description box, modify the description.
  8. Click Update.
  9. Click Save & Close.
  10. Proceed with evaluating and deploying the changes.

BIG-IQ 5.1.0 and earlier

  1. Log in to the BIG-IQ system.
  2. Navigate to Network Security > Policy Editor > BIG-IP > Firewall Policies.
  3. Click the name of the policy you would like to edit.
  4. If the rule list is not already displayed, click the Rules & Rule Lists tab.
  5. Re-order the rules as you want.
  6. For each rule that you re-ordered, click the name of the rule to edit it.
  7. In the Description box, modify the description.
  8. Click Save & Close.
  9. Proceed with evaluating and deploying the changes.
