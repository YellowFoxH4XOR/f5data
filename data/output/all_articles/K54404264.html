Description

You are not able to create a VLAN using the TMOS shell (tmsh) command line. For example, you are not able to create VLAN using the following tmsh command if the trunked Interface does not exist:

create /net vlan vlan_example_1000 interfaces add { Example_Trunk { tagged }} tag 1000

You can use the following command syntax to create a VLAN:

create /net vlan <vlan_name> interfaces add { <interface> }

For example:

create /net vlan test-vlan interfaces add { 1.1 }

Environment

  • BIG-IP systems
  • Adding VLAN using the tmsh command line
  • Interface object has not been verified

Cause

The Interface object <interface> does not exist.

Recommended Actions

To resolve the issue, please follow one of the following options.
  1. Change the interface object name to an existing interface object.
  2. Create the interface object before creating the VLAN.

Additional Information

  • K14961: Create and modify VLANs using the tmsh utility
  • K76150238: Error Message: <path to command>: <path to command>: cannot execute binary file
