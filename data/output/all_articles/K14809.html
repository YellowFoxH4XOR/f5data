Issue

Old Behavior

In versions prior to BIG-IP 11.4.0, automatic synchronization of the system configuration is only available to Sync-Only device groups, and you must manually synchronize the Sync-Failover device groups configuration.

New Behavior

Beginning in BIG-IP 11.4.0, you can enable automatic synchronization of the system configuration when using the Sync-Failover device group setting. When you select the Automatic Sync box and clear the Full Sync box, the system defaults to the Incremental Synchronization setting.

Note: You cannot select both Automatic Sync and Full Sync. Selecting both Automatic Sync and Full Sync produces an error message similar to the following when attempting to save the configuration:

010716af:3: Failover device group (/Common/test) cannot have both auto-sync and full-load-on-sync simultaneously enabled.

F5 Product Development tracked this change as ID 403022.
