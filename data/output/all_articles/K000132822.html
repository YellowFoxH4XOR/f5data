Description

BIG-IQ is not receiving statistics from BIG-IP.

Environment

  • BIG-IQ
  • BIG-IP statistics are unavailable

Cause

There are various causes for this issue.

Recommended Actions

Verify the following requirements for stats collection:

  1. The AVR module must be provisioned on BIG-IP devices. AVR is memory intensive and should only be provisioned on systems with at least 8GB of RAM.
  2. Bi-directional communication is required between BIG-IP and all BIG-IQ nodes on port 443. See K77432253 on how to use telnet to troubleshoot.
  3. The BIG-IQ iApp must be installed on BIG-IP. See the following article to see if the BIG-IP version is impacted by the issue described in K14002893

Additional Information

K77432253: The value of "Stats Last Collection Date" is ''Jan 1, 1970'' or ''Dec 31, 1969'' for monitored BIG-IPs

K15612: Connectivity requirements for the BIG-IQ system

K14002893: BIG-IQ cannot enable Statistics collection towards some BIG-IP
