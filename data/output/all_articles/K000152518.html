Description

TCP connection is terminated by reset. F5 ethernet trailer shows cause code "Route domain not reachable (strict mode)"

Environment

  • BIG-IP with standard virtual server (VS) configured in partition to listen within route-domain (RD) other than RD0

  • Route-domain in strict or non-strict mode
  • Selection of pool done within irule using data-group specified by name only (not partition)
  • At least 2 partitions with the same data-group name (used by the irule)
  • Connection captured by tcpdump and f5ethernet trailers plugin analysed by wireshark or tshark or logged to /var/log/ltm.

Cause

BIG-IP irules do not relate data-group names to the calling partition.

Data-group names should be fully specified if the name itself is not unique.

If not, the last copy of the data-group loaded by mcpd will be used.

Recommended Actions

Configure data-group names within irules to be fully qualified with partition name  or use unique data-group names across the BIG-IP configuration
