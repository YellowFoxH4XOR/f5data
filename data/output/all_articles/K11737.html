Known Issue

This is the result of a known issue. The BIG-IP ASM bd process may leak memory when Data Guard is configured in the security policy and the system fails to uncompress a gzip response from the server. When this issue occurs, the system logs error messages to the /var/log/bd.log file that appear similar to the following example:

clean_resp.c:498|Uncompressed HTML is above maximal size ( max size <data_size>, uncompress len:<data_length>)
clean_resp.c:640|get_resp for export(sampling) failed
response_header_accumulator.c:266|clean_resp_peek_data failed ret -1 len 0

This issue may eventually cause the BIG-IP ASM bd process to core.

F5 Product Development is tracking this issue as ID 225545 (formerly CR139651).

This issue has been fixed in Hotfix-BIGIP-10.2.0-1755.1-HF1 issued for version 10.2.0, Hotfix-BIGIP-10.1.0-3402.0-HF2 issued for BIG-IP versions 10.1.0, and Hotfix-BIGIP-9.4.8-407.0-HF4 issued for BIG-IP version 9.4.8.
