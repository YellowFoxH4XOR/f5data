Description

It is required to increase the message limit for sending to a remote syslog server as explained on K8306: Syslog enhancement supports larger message sizes sent to remote syslog servers using an iRule, but you get the following error:

Syntax Error: unexpected argument "bigpipe"

Environment

  • SYSLOG

Cause

Using discontinued command bigpipe.

Recommended Actions

For newer versions, the correct syntax for changing the db key is:

tmsh modify sys db tmm.maxremoteloglength value <new value>?????
