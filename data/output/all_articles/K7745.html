Known Issue

This is the result of a known issue. If you create a user account that begins with root, such as root123, the BIG-IP system automatically attempts to synchronize the password to the SCCP root user account. As a result, the /etc/passwd file on the SCCP is deleted and management connectivity is lost.

F5 Product Development tracked this issue as CR75131 and it was fixed in BIG-IP version 9.4.2. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, Link Controller, or WebAccelerator release notes.
