Topic

Beginning in BIG-IP GTM and Link Controller version 9.3, it is possible to configure how a wide IP responds to a query for an AAAA resource record when no IPv6 pool members exist for the wide IP. This behavior is controlled by the IPv6 NoError Response setting.

Note: For more information, refer to K7851: Configuring the BIG-IP GTM or Link Controller systems to provide NOERROR responses for IPv6 queries.

You can enable or disable this setting on a wide IP basis exclusively using the Configuration utility.

F5 Product Development is tracking an enhancement request as CR73573 to configure the IPv6 NoError Response setting through iControl. This functionality is useful when managing a large number of wide IPs on a BIG-IP GTM or Link Controller system.
