K000157355: The TOR browser traffic is not blocked, despite the suspicious browser setting being configured to block in the bot profile.

Description

The ASM bot profile is not blocking requests from the TOR browser, even though the "Suspicious Browser" setting is configured to block.



Environment

BIG IP ASM

BOT Profile created with Balanced template


Cause

The TOR browser can evade Bot Defense because it presents a legitimate User-Agent string (e.g., Firefox). The Balanced template of Bot Defense relies on signatures, browser verification, and anomaly detection; however, with a valid User-Agent string, the browser may not be flagged as suspicious or a bot.


Recommended Actions

→ Do not rely solely on User-Agent strings for blocking suspicious browsers; they are easily spoofed.

→ Combine User-Agent checks with additional indicators, such as IP reputation using IP Intelligence, for more robust detection.

→ For stricter enforcement against suspicious browsers like TOR, configure the Bot Defense profile with the "Strict" template. The strict template enforces the most rigorous checks. Only browsers that pass proactive verification are allowed. All bots except trusted ones are blocked or challenged. This means suspicious browsers (like Tor) are much more likely to be challenged with CAPTCHA or blocked.
