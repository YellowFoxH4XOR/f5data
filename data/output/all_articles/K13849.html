Description

Overview of BIG-IP Analytics CSPM injection

Environment

  • Collected Metrics > Page Load Time option in the BIG-IP Analytics is enabled
  • AVR Analytics

Cause

BIG-IP Analytics can track and report on the client-side page load time for a given application. This data is generated by the BIG-IP Client Side Performance Monitoring (CSPM) feature. To calculate the client-side load time for a web resource, the CSPM feature injects a piece of JavaScript code into the HTTP response that it sends to the client. When the client browser executes the JavaScript, it calculates the specific timing values needed by the CSPM feature, and reports those values back to the BIG-IP system in a cookie.

An HTTP response is eligible for CSPM injection under the following conditions:

The HTTP content is not compressed.
The HTTP content-type is text/html.
The HTTP content contains an HTML <head> tag.
For a response containing the CSPM injection to generate results, the client browser must support the Navigation Timing API (window.performance.timing).

Navigation Timing is currently supported by the following browsers:

Mozilla Firefox 4 and later
Chrome 10 and later
Microsoft Edge
By default, CSPM injection only occurs on a pre-defined ratio of HTTP responses in order to minimize any impact CSPM processing may have on system performance.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. If the Page Load Time metric isn't needed disable the setting at Local Traffic  ››  Profiles : Analytics : HTTP Analytics, uncheck Page Load Time under Collected Metrics.
  2. Ensure that clients are using supported browsers. You can check specific browsers for support of the Navigation Timing API by using the tests available at the following location. This link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge, http://w3c-test.org/navigation-timing/. 
  3. If a virtual server enabled with the Page Load Time feature has not been accessed from a supported browser, the Page Load Time statistics page in the Configuration utility will display the following message, There is no data for this chart either due to a lack of relevant traffic or because no profile has this metric enabled.
  4. In versions 13.0.0 HF1 and later you can change when we inject the JS by modifying a database variable within the BIGIP:
    Injecting after head:
    # tmsh modify sys db avr.cspm.inject.location value after_head
    Injecting at the end (the default):
    # tmsh modify sys db avr.cspm.inject.location value at_the_end

  5. In versions 11.6.2 and later you can change when we inject the JS by modifying a system file and restarting TMM.

    a) Edit /etc/bigstart/scripts/avr.provision
    b) If you want to inject after the head tag you need to change the following line:
       "inject_after_head_tag=0" to "inject_after_head_tag=1"
    c) Restart TMM:
        Note: This will impact traffic, perform this step during a maintenance window.
            # bigstart restart tmm
