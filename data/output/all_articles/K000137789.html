Description

resolve::lookup not working with a hyphen, dash in the dns name

 

Environment

BIG-IP

iRule

Cause

Using the wrong type of hyphen.

 

Example 1: https://www.chick‐fil‐a.com/

‐ Hyphen Unicode Character “‐” (U+2010)

NOTE: This type of hyphen will fail. It is not interpreted correctly.

 

Example 2: https://www.chick-fil-a.com/

- Hypen-Minus Unicode Character “-” (U+002D)

NOTE: This hyphen will work properly.

Recommended Actions

Keep in mind that when copying iRule code from programs/sources, a simple hyphen may be changed to something that looks like a Hyphen-minus. If the expected result/behavior fails, try changing the hyphen on a text editor like notepad or something else that won't change the format or characters.
