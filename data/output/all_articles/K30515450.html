Known Issue

The BIG-IP APM rewrite process may incorrectly process multi-byte character Extended Unix Code (EUC) character sets.

This issue occurs when the following condition is met:

  • Web application content such as HTML, XML, or JavaScript code uses the EUC encoding scheme.

Impact

The web application may not render or function as expected.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The web application may not render or function as expected.
