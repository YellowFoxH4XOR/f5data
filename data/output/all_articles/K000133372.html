K000133372: UCS archive size grew significantly following an Upgrade from 12.x to later release.

Description

 

After an upgrade from 12.x to a later release, the customer noted that the UCS archives were significantly larger - from ~5Mb to over 10Mb.

 

Environment

 

BIG-IP upgraded from 12.x to a later release.

 

Cause

 

Investigation of the UCS archive showed that files under /var/tmp/storage_temp had increased significantly after the upgrade. The files under that directory contain the backup of the iControl REST data store.

On releases of BIG-IP after version 12.x, more functionality has been implemented in the iControl REST API. As a result of this increased functionality, the data store to support this functionality is much larger. This results in a larger UCS file when creating archives.

 

Recommended Actions

 

None. This is expected behavior.
