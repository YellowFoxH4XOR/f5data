K000151786: Modifying DNS cache local zones causes a loss of DNS resolution

Type
Support Solution
Published
2025-06-11
Updated
2025-06-11
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.5.X, 17.5.0, 17.1.2
Source
https://my.f5.com/manage/s/article/K000151786

Description

After upgrading to v17.1.2.x/v17.5.0, when performing any modifications to DNS cache local zones (add/remove/modify) causes a loss of DNS resolution for local or reverse records until TMM is restarted.

Environment

  • DNS Cache local zones

Cause

Bug ID1966405 - Modifying DNS cache local zones in BIG-IP DNS 17.1.2.x causes the DNS cache to malfunction, breaking resolution for local and reverse records until TMM is restarted.

Recommended Actions

Until a fix is provided, the only available workaround is to restart TMM. If the DNS cache local zones do require any modifications, a TMM restart will be required after making those changes. To minimize risk, it is recommended to avoid altering the DNS cache local zones unless absolutely necessary, as such changes can trigger the reported issue. If modifications are essential, gather any changes that need to be performed, schedule a maintenance window for the changes and ensure TMM is restarted afterward.

Additional Information

None.
