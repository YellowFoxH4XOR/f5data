K41459114: BIOCSETF: Network is unreachable when running tcpdump

  • BIG-IP LTM: 14.X.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K41459114

Description

The following message appears when running tcpdump from the BIG-IP command line:

BIOCSETF: Network is unreachable

Environment

  • Command line interface

Cause

tcpdump is used from a non-default route domain shell

Recommended Actions

Run tcpdump from route domain 0.

Additional Information

tcpdump should always be run from route domain 0. It's important to quit out of any other route domain shell first. Avoid use of rdsh since it spawns the rdsh 0 shell inside of the existing route domain shell.

Refer to the following article for more information:

  • K6546: Recommended methods and limitations for running tcpdump on a BIG-IP system
