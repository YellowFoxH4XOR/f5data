Issue

Error Message

notice sod[<PID>]: 010c008c:5: Previously unreachable unicast address <IP Address> port <Port Number> is now reachable.

In this error message, note the following:

  • <PID> is the process ID for the sod process.
  • <IP Address> is the unicast IP address.
  • <Port Number> is the port number being used with the unicast IP address.

For example:

notice sod[6087]: 010c008c:5: Previously unreachable unicast address 192.0.2.14 port 1026 is now reachable.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The error condition that prevented the unicast address from being reachable has cleared. 

Impact

Normal transmission for network failover packets is restored.

Recommended Actions

None
