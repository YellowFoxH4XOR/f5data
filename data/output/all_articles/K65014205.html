K65014205: A user with manager permission cannot update a datagroup via AS3

Type
Support Solution
Published
2024-08-01
Updated
2024-08-01
Applies to
  • BIG-IP
  • BIG-IP Platforms
Source
https://my.f5.com/manage/s/article/K65014205

Description

Updating a data group via AS3 by a user with other sets of permissions than the Administrator may cause an error: 
'code': 401, 'message': 'Authorization failed'

Attempts at modifying other configuration objects may also fail.

Environment

  • BIG-IP
  • AS3

Cause

Authorization failure due to the wrong set of permissions.

Recommended Actions

A BIG-IP user should have the Administrator role to use the AS3 functionality.
