Description

  • The checksum generated for the gzip part is wrong
  • Content returned by the backend is exactly 64 KiB long (or its multiplication: 128 KiB, 192 KiB)

Environment

  • Hardware iSeries or Viprion 4450 blades
  • HTTP compression profile

Cause

Bug ID 876569: QAT compression codec produces gzip stream with CRC error

Recommended Actions

There is no fix for this Bug ID at the time of article's publication.
As a workaround, suggested to disable hardware compression and use software compression.
To do so, run the following command:
tmsh modify sys db compression.strategy value softwareonly

None
