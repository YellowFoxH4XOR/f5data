Description
Trying to configure Constrained Delegation feature (C3D) and getting an error similar to any of these:

/var/log/audit
Configuration error: SSL Client Certificate Constrained Delegation feature state on clientssl profile(s) and/or serverssl profile(s) doesn't match on Virtual Server (/Common/Example_VS).

/var/log/ltm
err mcpd[5432]: 01071c6c:3: Profile /Common/SSL_Server_Profile SSL client certificate constrained delegation key is missing.

err mcpd[5432]: 01071c6d:3: Profile /Common/SSL_Server_Profile SSL client certificate constrained delegation CA key and certificate do not match.

Environment

  • SSL profiles
  • Constrained Delegation feature C3D

Cause
Server SSL profile missing a Certificate and Key.
SSL Client and Server Side profiles both need to have C3D enabled before being attached to the VS.

Recommended Actions

Make sure the Server Side SSL Profile, has a valid Certificate and Key settings configured. For more details refer to: Configuring the Server SSL profile section on K14065425: Configuring Client Certificate Constrained Delegation (C3D).
Important: Make sure to modify both client and server side profiles to enable C3D before attaching them to the Virtual Server.
