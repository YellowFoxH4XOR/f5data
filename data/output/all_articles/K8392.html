The following procedure configures passwordless authentication using client certificates for a single master group. Users who belong to that master group and who have a valid client certificate installed will be able to log on to the FirePass without supplying a password on the FirePass login page.

Note: For information about creating self-signed client certificates, refer to K7478: Creating and requiring self-signed client certificates.

Configuring passwordless authentication using client certificates

To configure passwordless authentication, perform the following procedure:

  1. Log in to the FirePass Administrative console.
  2. Click Device Management.
  3. Click Security.
  4. Click Certificates.

  5. Select the check box next to Request client certificate during logon.

    Note    : This option will only appear after installation of a client root certificate. Once the client root certificate is installed, the check box will appear and will be selected, by default.

  6. In the drop-down menu under Request client certificate during logon, select the client certificate field that will match the logon username.

    Note: For FirePass self-signed client certificates, select Use certificate common name (CN) for logon username.

  7. Click the Update button.
  8. Click Device Management.
  9. Click Configuration.
  10. Click Network Configuration.
  11. Click the Web Services tab.
  12. Click the Configure link next to the SSL-enabled web service or services that will service the users' logins using passwordless authentication with certificates.
  13. Select the Request Client Certificate check box.

  14. Click the Update button.

    Note: Changes to the web service will not take effect until you finalize the changes and perform a service restart. To finalize the changes, click on the Finalize tab and then the Finalize Changes button. After the finalization is complete, you can perform a service restart. Service restarts can be performed from the Device Management: Maintenance: Restart Services page. Restarting or shutting down the FirePass Controller will also restart services.

  15. Click Users.
  16. Click Groups.
  17. Under Group Name, click the master group you want to configure.

    If you do not have an existing master group, click the Create new group button to create a new master group.  Select Client certificate (Passwordless) for the authentication method, and then on the Authentication tab, select the Automatically log-in when client certificate is present check box.
  18. Click the Authentication tab.
  19. Click Convert authentication method.
  20. Click Client Certificate Passwordless Authentication.

    The following message displays:

    Are you sure you want to convert the authentication scheme to Client Certificate Passwordless Authentication?

  21. Click the Continue button.
  22. Select the Automatically log-in when client certificate is present check box.

Users with a valid client certificate who belong to the master group you just configured can now log on without a password.

Using Active Directory to perform additional verification

To perform additional verification using Active Directory, perform the following procedure:

  1. Select the check box next to Perform additional client certificate check against Active Directory attribute.
  2. In the Client certificate subject field used for comparison drop-down menu, select a certificate field to compare against an Active Directory attribute.

    For example:

    Client certificate common name (CN)

  3. Under Active Directory attribute used for comparison, enter an Active Directory attribute to compare against the client certificate field.

    For example:

    sAMAccountName

  4. In the Comparison method drop-down menu, select the type of comparison you'd like to perform.

    For example:

    Direct match of client certificate field to Active Directory attribute

  5. Under Configure Active Directory Settings, enter your Active Directory information.

    For example:

    Domain name: siterequest.com
    Kerberos server name (optional): server.siterequest.com
    WINS server IP address (optional): wins. siterequest.com
    Domain admin name: Administrator
    Domain admin password: MyAdminPass

  6. Click the Update button.
