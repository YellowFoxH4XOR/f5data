K000163715: APM: F5 Access for Android fails with “Bad address” when a Network Access resource contains an invalid route

Type
Support Solution
Published
2026-10-14
Updated
2026-10-14
Source
https://my.f5.com/manage/s/article/K000163715

Description

F5 Access for Android fails to establish a VPN tunnel after authentication. The client reports:

Failed to establish VPN

java.lang.IllegalArgumentException: Bad address

BIG-IP APM may log:

Session deleted (fatal_error; code - 10)

Environment

  • BIG-IP APM
  • F5 Access for Android
  • Network Access resources containing multiple subnet routes

Cause

An invalid or unsupported route (127.0.0.1/32) in a Network Access resource causes Android to reject the route when F5 Access calls VpnService.Builder.addRoute().

Resolution

  1. Review the included routes in the affected Network Access resource.
  2. Remove any invalid or unsupported route (for example, 127.0.0.1/32).
  3. Save the configuration and apply the access policy changes.
  4. Reconnect with F5 Access for Android.

The VPN tunnel should establish successfully after the invalid route is removed.
