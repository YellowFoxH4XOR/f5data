Known Issue

This is the result of a known issue. If you run tmm from the command line, the system may not correctly detect if another instance of TMM is already running. As a result, TMM statistics are cleared, and any existing TMM instances will crash.

Note: Previous versions of BIG-IP generate the following error message when attempting to run the tmm command:

sys_getlock: 1 instance of tmm already running.
tmm: sys_getlock failed (ERR_UNKNOWN).

F5 Product Development is tracking this issue as CR121563.

This issue was fixed in Hotfix-BIGIP-9.4.8-396.1-HF3 issued for BIG-IP version 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
