Description

Telemetry Streaming RPM is not being sync'd to the peer after import.

 

Environment

BIG-IP LTM

Config Sync

Telemetry Streaming

 

Cause

This can occur when the Telemetry Streaming RPM is not copied to /var/config/rest/iapps/RPMS/ on the BIG-IP after the Import.

The process of copying the RPM to /var/config/rest/iapps/RPMS/ is an automatic internal process.

 

Recommended Actions

Workaround:

Manually Import Telemetry Streaming RPM on each device.
