Known Issue

Network access connection URL interactions may trigger memory leaks.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM configuration uses a network access profile.
  • Users access the network access profile /vdesk/connect.php3 and /vdesk/webtop.eui URLs.

Impact

A small amount of memory is used by the URL action and not returned to the system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice a progressive increase in the amount of memory that is used by the affected system.
  • When running the tmctl -w 200 memory_usage_stat | grep 'method (variable)' command, you notice that the "method (variable)" consumed memory increases over time.
  • In extreme memory usage conditions, the BIG-IP APM system unexpectedly fails over to another system in the device group.
