Known Issue

This is the result of a known issue. The iQuery protocol XML parser artificially places a value limit of 256 on the following BIG-IP GTM monitor probe settings:

  • probe_interval
  • probe_timeout
  • probe_num_probes
  • probe_num_successes

For example, if you configure an external monitor with a probe_timeout setting of more than 256, you will see the monitor timeout at the 8-bit overflow value of 256 seconds.

F5 Product Development is tracking this issue as ID 225799.
