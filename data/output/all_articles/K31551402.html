Description

The LCD Panel only shows Secure Mode after boot up. 

Environment
  • BIG-IP iSerial Platform
  • Used "Power Off" LCD touch screen to cut the power supply off 
Cause

Pressing Power Off on LCD touch screen shutdown the system ungracefully. After booting up, the restjavad process is not working as expected.

Recommended Actions

You can use these 2 commands to fix this issue:
  1. Login to the CLI of BIG-IP system.
     
  2. Run the command:
    clear-rest-storage
     
  3. Run the command:
    tmsh restart sys service restjavad
 
Additional Information

To prevent the BIG-IP system from running into such a kind of issue in the future, it's suggested to shutdown the system by using the command line. If the LCD panel must be used, first press Halt, and then press Power Off.
