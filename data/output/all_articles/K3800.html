Topic

Starting in BIG-IP 9.4.2, the system includes a type of profile that you can use to manage Stream Control Transmission Protocol (SCTP) traffic. SCTP is a Layer 4 transport protocol, designed for message-oriented applications that transport signaling data.

In BIG-IP versions prior to 9.4.2, L4 and L7 functions do not support the SCTP. In versions 4.5.x through 4.6.x, and versions 9.0 through 9.4.1, the BIG-IP LTM cannot read information in SCTP headers, so it cannot make load-balancing decisions based on embedded addresses used for SCTP multi-homing, SCTP port numbers, or data payload. The BIG-IP LTM cannot differentiate SCTP connections when packets use the same source and destination IP addresses. When SCTP multi-homing is used and packets that belong to the same session may have multiple source and destination addresses, the BIG-IP LTM will not treat them as a connection.

The BIG-IP LTM will process SCTP packets the same way that it processes all IP protocols (other than TCP and UDP) based only on the information that is contained in the IP header. The BIG-IP LTM can process SCTP packets in this manner for virtual servers, NATs, or SNATs when any IP processing is enabled. BIG-IP versions prior to 9.0 can pass SCTP packets using IP forwarding.

For information on this feature in later versions, refer to the BIG-IP LTM product manuals for your version.
