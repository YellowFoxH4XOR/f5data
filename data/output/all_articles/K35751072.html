Description

In AFM, when configuring destination protocol "any" in a rulelist it gets displayed as "HOPOPT" within the AFM policy view.

Environment

  • AFM
  • Inline rule editor disabled

Cause

Seen behavior is the result of having AFM Inline rule editor disabled.

Recommended Actions

Enable Inline Rule Editor

  1. On the GUI go to Security > Options > Network Firewall > Firewall Options
  2. Check Inline Rule Editor
  3. Click Update

Additional Information

None.
