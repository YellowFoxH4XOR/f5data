Issue

The syslog and procdat log files may contain the following cryptic error messages:

DFM_DFMR_ERROR: "Failed to perform existence check"

These error message are not clearly indicative of the actual issue encountered. However, the error messages are often indicative of a metadata inconsistency.

Note: For information about performing a metadata inconsistency check, refer to the ARX CLI Reference Guide.

For example, the following message does not clearly indicate a pathname was not found on a filer when the ARX system conducted a lookup for a user request to remove a file. DNAS could not find the file or the file's parent directory. The remove file request will remain pending until the metadata inconsistencies are resolved.

: DFM_DFMR_ERROR: "Failed to perform existence check" [-340]: dnasrecovercommon.c:dnas_rcvr_check_exist_retpfh():[291] 2009-06-18T13:43:19.717+0000:INFRL6011:1-1-ACM-28747:DNAS_PGRP-1-6-PEND_KEEP_RETRY:: REMOVE vol=("/SALES") pdid=(0x100000031b159) psid=(4) filename=("Sales Pending.xls~RF32ea1315.TMP") txid= (3096224743817975) [38953 270160].

F5 Networks Product Development is tracking an enhancement request as ARX ID 35704 to improve the usability of these error messages so they provide a clearer understanding of the issues.
