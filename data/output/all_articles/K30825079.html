Description

You would like to know if a specific virtual server is performing two way SSL / TLS authentication ( also known as mutual authentication ) with a client.

Environment

  • Two way SSL / TLS

Cause

None

Recommended Actions

  1. Navigate to the virtual server in question and locate the client SSL / TLS profile which is assigned on this virtual server and make a note of it.

    Local Traffic  ››  Virtual Servers : Virtual Server List

    Select the virtual server and make a note of the  SSL Profile (Client) field.

  2. Next and according to your configuration navigate to the following menu and select the profile in question in order to review it's settings.

    Local Traffic  ››  Profiles : SSL : Client

    and check if the following two settings are enabled.

  • Client Certificate
  • Trusted Certificate Authorities

If they are, then this virtual server is using two way SSL / TLS authentication with the respective clients.

Additionally, the following options may also be enabled:

  • Advertised Certificate Authorities (optional)
  • Certificate Revocation List (optional)

Additional Information

None
