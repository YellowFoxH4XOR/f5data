Description

Environment

  • BIG-IP 10350-F
  • FIPS Firmware  CNN35XX-NFBE-FW-1.0-52
  • FIPS Firmware  CNN35XX-NFBE-FW-1.0-39

 

Cause

  • BugID 1282761 Unable to load old FW 1.0-39 on new MFG FIPS device
  • FIPS 5th and 6th Generation chip does not support FIPS Firmware  CNN35XX-NFBE-FW-1.0-39

 

 Recommended Actions

  1. Please consult with F5 support before upgrading or downgrading FIPS firmware. 
  2. Verify the hardware generation with the command fipsutil info. The first number of the serial number is the hardware generation number:
config # fipsutil info
Label:              test123
Model:              NITROX-III CNN35XX-NFBE

Serial Number:      5.0G xxxx-xxxxxxxx
FIPS state:         2

config # fipsutil info
