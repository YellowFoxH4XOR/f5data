K000137192: High latency observed when legacy server using NetBIOS, direct access is working normally

Description

Huge delay seen when loading initial webpage. Did not experience such delay when directly accessing backend server (bypassing BIG-IP). NetBIOS which is a legacy protocol was configured on server.

Based on packet capture, after BIG-IP sends the initial request to pool member, a consistent delay (~9s) before pool member responded with initial data.

Sample packet capture snippet below that was taken from a Windows server (pool member). NetBIOS Name Service ('yellow' lines), took few seconds to timeout. Until then, server only start responding with application data (frame# 292).

BIG-IP: 172.19.70.19
Pool member (Windows server): 172.19.70.41



 

Environment

  • Server (pool member) enabled NetBIOS
  • BIG-IP

Cause

Backend server NetBIOS Name Service query has to timeout before sending response data 

 Recommended Actions

NetBIOS is a configuration on the backend server. It is a legacy protocol and suggested to be disabled if causing delay.

For example, to disabled NetBIOS on a Windows Server 2003, please refer to How to configure TCP/IP networking while NetBIOS is turned off on a server running Windows Server 2003.
