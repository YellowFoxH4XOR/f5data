Description

BIG-IP APM network access, VPN full tunnel configuration

When you use this option, you specify that all traffic from client devices connected to network access (including traffic to or from the local subnet) is forced over the VPN tunnel. After client devices are connected to the BIG-IP APM network access VPN, changes are made to their routing configurations. This includes changes to the client routing table, default route and default gateway.

For more information on the full tunnel network routing and the difference between split tunnel and full tunnel refer to the following:
  • Network Security section of K18390492: Security | BIG-IP APM operations guide.
  • Routing options section of K49720803: Common approaches to configuring VPN | BIG-IP Edge Client operations guide

Environment

  • BIG-IP APM network access
  • VPN
  • Full Tunneling

Recommended Actions

Follow below steps to configure Network Access with Full Tunneling option:

  1. Creating lease pool
    1. Go to Access > Connectivity/VPN > Network Access (VPN) > IPV4 Lease Pools
    2. Click Create
    3. Fill name of new lease pool
    4. Add addresses to Member list
    5. Save
       
  2. Creating Network Access resource:
    1. For BIG-IP v13.x-17.x
      Go to Access > Connectivity/VPN > Network Access (VPN) > Network Access List

      For BIG-IP v12.x
      Go to Access Policy >  Network Access  > Network Access List
       
    2. Click Create
    3. Name new network access resource
    4. Click Finish
    5. Go to Network Settings tab
    6. In General Settings, add created lease pool in procedure 1
    7. In Client Settings > Traffic options use default option Force all traffic through tunnel
    8. Go to DNS tab
    9. Fill DNS options
    10. Save
       
  3. Add network access resource to Access Policy VPE
  4. Attach updated Access polity to the Virtual Server
