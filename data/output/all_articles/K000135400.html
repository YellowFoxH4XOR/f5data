Description

You notice the standby device is initiating a connection even it is not sending ASM event logs to external syslog servers.

Environment

Remote security logging profile is applied to Virtual Server.

Cause

Both active and standby device will establish a TCP connection with your remote syslog server and then keeping it open, in order to get iteself ready to send data to the destination remote syslog server. (In other words, when the standby device goes active, because TCP connection has already been established, the device can then immediately start sending traffic logs to remote syslog server).

Only the active device (which takes traffic in the traffic group) will send logs to the remote syslog server.

none.
