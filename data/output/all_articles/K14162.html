Known Issue

You may be unable to create or update an HTTP health monitor using the Configuration utility.

This issue occurs when all of the following conditions are met:

  • You use a Google Chrome or Safari web browser.
  • You attempt to configure a long send or receive string that contains word wraps within the text box of the Configuration utility.

Impact

You are unable to create or update affected HTTP monitors using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to save or update an affected monitor configuration, a warning message similar to the following example appears on the Configuration utility screen:

    Some Fields below contain errors. Correct them before continuing.

    Value may not contain literal newline characters.

Workaround

To work around this issue, you can use the Internet Explorer or Firefox browser. Alternatively, you may use the Traffic Management Shell (tmsh) to create the HTTP monitor. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

The following procedure allows you to create, view, or modify an HTTP monitor from the tmsh utility.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To create a basic monitor called new_http with a send and receive string, type the following command:

    create ltm monitor http new_http send "GET /" recv "OK"

    You can view your configured monitor by typing the following command:

    list ltm monitor http new_http

    For example:

    ltm monitor http new_http {
    defaults-from http
    destination *:*
    interval 5
    recv OK
    send "GET /"
    time-until-up 0
    timeout 16
    }

    Note: You may still view the monitor using the Configuration utility, but if the send or receive strings are larger than one line of the text input box, you will be unable to save changes.

  3. Optional: To modify an existing monitor, you can type a command similar to the following example:

    modify ltm monitor http new_http send "GET /monitor.asp" recv "UP"

    Note: For more information about tmsh options to create or modify HTTP monitors, type the following command:

    help ltm monitor http

  4. Save the change by typing the following command:
     
    • BIG-IP 10.1.0 and later:

      save /sys config

    • BIG-IP 10.0.x:

      save config
