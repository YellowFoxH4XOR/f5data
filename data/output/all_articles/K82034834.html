Description

Error 51133, F5 registration key is not compatible with the detected platform

This message can also appear similar to the following example:

Error 51133 - Invalid Registration Key for the Platform Detected

Environment

You may encounter this message in the following location:

  • The Configuration utility

Cause:

This message occurs when one of the following conditions is met:

  • You attempt to add an add-on license to a trial license.
  • You attempt to use a trial license, which is version specific, on a version that is not specified.
  • You attempt to add an evaluation license to a production unit.
  • You attempt to license a platform with an incompatible registration key.

Impact

Attempts to add the add-on license or to add the license to the device will fail, and the system produces the error message.

Recommended Actions

You must license the system on the appropriate software version and platform that are compatible with the registration key. For example, you must license the system on the software version specified in the license file or a later version. If you need a new registration key, contact your F5 Sales representative.
