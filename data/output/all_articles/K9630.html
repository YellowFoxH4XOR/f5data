If you configure a master group with RADIUS authentication, FirePass supports RADIUS challenge/response authentication without additional configuration. In order for the challenge/response to succeed, the RADIUS server must set the Code field to 11 (Access-Challenge) when responding to the Access-Request packet sent by FirePass. Additionally, the RADIUS server must send a valid Response Authenticator as described in RFC2865:

The value of the Authenticator field in Access-Accept, Access-Reject, and Access-Challenge packets is called the Response Authenticator, and contains a one-way MD5 hash calculated over a stream of octets consisting of: the RADIUS packet, beginning with the Code field, including the Identifier, the Length, the Request Authenticator field from the Access-Request packet, and the response Attributes, followed by the shared secret. That is, ResponseAuth = MD5(Code+ID+Length+RequestAuth+Attributes+Secret) where + denotes concatenation.

If the RADIUS server does not send a response with the Code field set to 11, or if the Response Authenticator is not valid, FirePass does not prompt the user for the challenge and authentication fails. To determine whether your RADIUS server is compliant with the protocol described in RFC 2865, refer to your vendor documentation.
