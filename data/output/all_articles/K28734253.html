Description

This article tries to clarify whether XML SOAP requests larger than 30 megabytes would still be scanned according to the XML Firewall Configuration and relevant XML attack signatures

Environment

  • ASM
  • XML Profile
  • Large SOAP requests

Cause

None

Recommended Actions

The 30 megabytes maximum value for long_request_buffer_size applies to the XML SOAP requests.

As described in article K17573 beginning in BIG-IP ASM 11.5.0, when the Request length exceeds defined buffer size violation is not set to block, the system inspects the first 10 KB of large requests (larger than 10 MB, by default) for slow post attacks. With this behavior, administrators can allow large requests and the BIG-IP ASM system can inspect and enforce the first part of the data instead of passing all data without inspection.
