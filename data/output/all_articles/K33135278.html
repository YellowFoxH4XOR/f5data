Known Issue

The Virtual Clustered Multiprocessing (vCMP) guest may fail to perform a BIG-IP software installation when the image verification database variable is enabled.

This issue occurs when all of the following conditions are met:

  • You have deployed one or more vCMP guests on the vCMP hypervisor.
  • You enable the liveinstall.checksig database variable for automatic image verification.

    Note: The liveinstall.checksig database variable is disabled by default.

  • You attempt to install software on the vCMP guest, with the required BIG-IP software image file (.iso) and signature (.sig) file present in the /shared/images directory of both the hypervisor and the vCMP guest.

Impact

When you attempt to install BIG-IP software on a vCMP guest, the installation fails while performing an automatic signature verification of the software image.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you install software on the vCMP guest, the tmsh show /sys software status command reports a failed installation status with an error message similar to the follow example:

    failed (Repository must be a file for signature validation ; /tmp/lind_util.4TyB3a.)

Workaround

  • BIG-IP system with FIPS license
  • BIG-IP system without FIPS license

BIG-IP system with FIPS license

To work around this issue, you can remove all images and .sig files from the vCMP host.

BIG-IP system without FIPS license

To work around this issue, you can disable automatic image verification and then perform image verification manually before installing. To do so perform the following procedure:

Impact of workaround: Performing the suggested procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP system.
  2. To disable automatic image verification, disable the signature verification database variable by entering the following command:

    tmsh modify /sys db liveinstall.checksig value "disable"

  3. To manually verify the image, use the procedure described in K24341140: Verifying BIG-IP software images using SIG and PEM files.
