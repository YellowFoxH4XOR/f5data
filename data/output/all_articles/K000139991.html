K000139991: You do not have permission to access this page my.acl.php3? errorcode=17

Type
Support Solution
Published
2024-06-12
Updated
2025-04-01
Applies to

  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000139991

Description

You have published new application through BIG-APM Webtop but the users receive an error:

You do not have permission to access this page.

Access was denied by an access control list.

The following error is displayed in web browser status bar:

my.acl.php3? errorcode=17

Environment

  • BIG-IP APM
  • Portal Access
  • Webtop
  • ACL

Cause

Application IP address, Virtual Server IP address or both are rejected by ACL Rule

Recommended Actions

  1. Analyze BIG-IP pktfilter logs to determine which ACL rule is rejecting the packets and check affected subnets/IPs
# cat /var/log/pktfilter

OR

# tail -f /var/log/pktfilter

Example:

Jan 11 09:18:00 example.org notice tmm[13991]: 01580005:5: /Common/Example:Common:00000000: reject ACL: /Common/Example_Rule:0 packet: https://example.com tcp 93.184.215.14:14868 -> 172.16.1.1:443

   2. Create new ACL rule to allow these subnets/IP addresses or remove ACL rule which blocks these subnets/IP addresses
