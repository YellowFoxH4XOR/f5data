Known Issue

This is the result of a known issue. The /recover partition my not have enough free space to create or recover a snapshot image. As a result, when attempting to create or recover a snapshot image, you may receive the following error message:

Error occurred while configuring system to reboot in recovery mode. Please contact F5 Support.

Note: If you receive this error message, you will need to contact F5 Technical Support. For more information about contacting F5 Support refer to K2633: Instructions for submitting a support case to F5.

F5 Product Development tracked this issue as ID 294459 (formerly  CR140026), and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-610-3-1 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
