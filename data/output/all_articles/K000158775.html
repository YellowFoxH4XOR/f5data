Topic

This article describes the following about NGINX Instance Manager (NIM):

  • What: F5’s licensing endpoint used in NIM will replace expiring Entrust CA certificates on February 15, 2026.
  • Who’s affected: NIM versions 2.12 to 2.20 using JWT-based licensing (NGINX One SKUs and legacy NIM FCP SKUs).
  • Impact: Licensing connectivity will break, preventing new installations and connected-mode usage reporting.
  • Action: Upgrade to NIM 2.21 or later, or apply the mid-December 2025 patches (NIM 2.18.1, 2.19.3, 2.20.1).
  • Deadline: Complete upgrades before February 15, 2026.

Overview

Entrust CA, used in NIM licensing flows, will no longer be a trusted certificate authority for browsers. Older NIM versions ship with an embedded licensing bundle that only accepts Entrust-signed certificates for the F5 licensing servers. The current Entrust certificates used by older NIM licensing flows will be replaced on February 15, 2026. To avoid reliance on a single certificate authority, NGINX Instance Manager will trust multiple well-known CAs through an updated certificate bundle. NIM 2.21 includes this updated bundle so JWT-based licensing and connectivity to the licensing endpoint service continue to work in NIM 2.21 and later. Because the timeline is tight, patch releases (NIM 2.18.1, 2.19.3, and 2.20.1) will also be provided so you can do a minor version upgrade while planning an upgrade to NIM 2.21 and later.

Audience

Customers running NGINX Instance Manager who use JWT-based licensing (NGINX One SKUs and legacy NIM FCP SKUs), or who plan to move to JWT-based SKUs (current NGINX One SKUs only support JWTs).

Key dates

  • November 7, 2025: NIM 2.21 is available and includes the updated CA bundle.
  • Mid-December 2025: Patch releases for NIM 2.18, 2.19, and 2.20 will be made available with the updated CA bundle.
    • Patch versions: 2.18.1, 2.19.3, 2.20.1
  • February 15, 2026: Entrust certificate is replaced. After this date, affected versions lose licensing connectivity to the licensing endpoint service.

License types and SKU clarification

  • Legacy FCP-based NIM SKUs: These SKUs use JWTs for reporting, including usage and entitlement checks with the licensing endpoint service.
  • NGINX One SKUs: These SKUs use JWTs only.
  • S/MIME licenses: If you are currently using S/MIME via legacy NIM SKUs, your licensing continues to work through this change. When you renew or move to JWT-based SKUs, upgrade to the latest NIM release, ideally NIM 2.21 or later, so JWT licensing and usage reporting continues to work.

What breaks on affected versions after February 15, 2026

  • New installations on NIM 2.12 to 2.20 cannot complete license activation with the licensing endpoint service. The NIM UI and management APIs will not function until the system is licensed.
  • Already licensed NIM 2.12 to 2.20 instances:
    • UI and APIs continue to work, except for the licensing page in connected mode.
    • Data planes continue to submit usage to NIM using the /nginx-usage endpoint.
    • NIM cannot forward usage to the licensing endpoint service in connected mode.
    • Manual usage upload in disconnected mode continues to work where supported.
    • NIM instance termination calls to the licensing endpoint service fail.
    • If acknowledgements are not received for about six months, you must perform manual usage uploads to remain compliant. (Otherwise, your data plane traffic will stop.)

Impacted versions

Earlier than NIM 2.12

  • Licensing method: S/MIME
  • Impact: No impact from the Entrust change.
  • Action: No patch needed. If you plan to adopt JWT licensing, upgrade to 2.21 using supported paths.
  • NIM 2.12.0 reached end of technical support. Therefore, F5 recommends upgrading to the latest NIM version to get current features and security fixes. 

NIM 2.12 through 2.17

  • Context: JWT support was introduced to support FCP usage reporting. Disconnected mode is not available for FCP JWTs.
  • Impact after February 15, 2026: Behavior aligns with NIM 2.18 to 2.20 (below), with fewer workarounds because disconnected mode is unavailable for FCP JWTs.
  • Actions:
    • Recommended: Upgrade to NIM 2.21 using supported upgrade paths.
    • Interim: Upgrade to a patched NIM 2.18 or later to continue using existing FCP JWTs until you can move to NIM 2.21. 

NIM 2.18 through 2.20

  • Notable changes: The /nginx-usage endpoint was introduced for NGINX One mandated usage reporting. FCP JWTs are recognized under the NGINX One entitlement model by the licensing endpoint service.

New installations after February 15, 2026

  • License activation fails. NIM UI and management APIs are unavailable until licensed.
  • Data planes can still post usage to NIM at /nginx-usage. NIM stores usage locally but cannot forward it to the licensing endpoint service in connected mode.

Already licensed instances after February 15, 2026

  • UI and APIs work in connected and disconnected modes, except for the licensing page in connected mode.
  • Usage forwarding from NIM to the licensing endpoint service fails in connected mode.
  • Disconnected mode manual usage upload continues to work.
  • If acknowledgements are not received for six months, you must perform manual usage uploads to remain compliant. (Otherwise, your data plane traffic will stop.)
  • NIM termination calls to the licensing endpoint service fail.

  • Actions

NIM 2.21

  • Updated CA bundle included.
  • JWT licensing and usage forwarding work as expected.
  • No action required once on NIM 2.21.

Additional Information

Contact F5 support

If you cannot patch or upgrade in your maintenance window, open a support case with F5 Support and include the following:

  • Your current NIM version and license type.
  • Log excerpts showing licensing or usage forwarding failures.
  • Whether disconnected mode and manual uploads are viable.
  • Your target timeline to reach NIM 2.21.

Review the following important notes:

  • NIM 2.21 has been available since November 7, 2025 and contains the updated CA bundle. This is the recommended target release.
  • Patch releases for NIM 2.18, 2.19, and 2.20 are targeted for December 2025 for customers who need interim mitigation.
  • To avoid licensing disruptions after February 15, 2026, plan and complete upgrades to NIM 2.21 as soon as feasible.
