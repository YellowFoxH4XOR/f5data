Known Issue

The Traffic Management Microkernel (TMM) may leak memory when you are using plug-ins and you reinitialize the plug-in.

This issue occurs when all of the following conditions are met:

  • You have configured plug-in-based functionality. For example, the BIG-IP ASM system, the BIG-IP APM system, etc.
  • You make a configuration change that causes the system to reinitialize the plug-in.

Impact

Over time, the tmm process may exhaust memory resources until the system restarts and produces a core file. If the BIG-IP system is a member in a device group, traffic may fail over to another device group member. If the BIG-IP system is not part of a device group, traffic is interrupted until the tmm process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The amount of memory allocated for and used by the tmm process increases over time.
  • The tmm process exhausts memory resources over time. As a result, system performance may degrade, and the system may eventually become unresponsive.
  • The tmm process restarts and generates a tmm core file to the /shared/core directory.
  • Your BIG-IP system unexpectedly fails over to another system in the device group.
