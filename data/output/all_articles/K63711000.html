Issue

Error Message

01b40028:3: On profile <ProfileName>: Invalid SSL option <SSLOption> found

In this error message, note the following:

  • <ProfileName> is the name of the SSL profile.
  • <SSLOption> is name of the unsupported SSL option.

For example:

err mcpd[6457]: 01b40028:3: On profile (/Common/MySSLProfile): Invalid SSL option (gmsslv1.1) found

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file.

Description

This message occurs when the following condition is met:

  • You attempt to add an unsupported option to the SSL profile.

The Options List in the SSL profile provides selection from a set of industry standard SSL options and workarounds for handling SSL processing. You can add or removed options from the list for SSL profiles to provide workarounds for SSL connections. If you attempt to add an unsupported option using the TMOS Shell (tmsh), the system generates the error message.

Impact

You are unable to create or modify the SSL profile with the unsupported SSL option.

Recommended Actions

The supported list of SSL options for the SSL profile may change depending on your BIG-IP version. To display the supported list of options for your version, perform one of the following procedures:

Impact of procedure: Performing the following procedures should not have a negative impact on your system.

Displaying the SSL options using the Configuration utility

  1. Log into the Configuration utility.
  2. Navigate to Local Traffic > Profiles > SSL > Client or Server.
  3. Click the name of the SSL profile.
  4. For Configuration, click Advanced.
  5. For Options List, review the available SSL options.

Displaying the SSL options using the tmsh utility

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Start typing the command and press the Tab key to display a list of command options available to complete the command.

    For example, if you begin typing the following command you can press the Tab key to display all possible SSL options:

    create ltm profile client-ssl clientssl options {

  3. The available SSL options are displayed.
