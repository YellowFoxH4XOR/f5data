K000137178: HA Active system shows peer offline but peer device is on Standby mode

Type
Support Solution
Published
2023-10-09
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.0.0, 13.0.X, 13.0.1, 13.X.X, 13.1.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.0
Source
https://my.f5.com/manage/s/article/K000137178

Description

  • Active BIG-IP shows peer as offline, even though peer BIG-IP is on Standby mode.
  • The netstat -pan command shows an output similar to the following:

Standby device:

udp 0 0 10.0.0.5:39161 10.0.0.6:1026 ESTABLISHED 6339/sod off (0.00/0/0)
udp 0 0 10.0.0.5:1026 0.0.0.0:* 6339/sod off (0.00/0/0)
udp 0 0 10.0.0.1:1026 0.0.0.0:* 6339/sod off (0.00/0/0)
udp 0 0 10.0.0.1:55584 10.0.0.2:1026 ESTABLISHED 6339/sod off (0.00/0/0)

Active device:

udp 0 0 10.0.0.2:49217 10.0.0.1:1026 ESTABLISHED 5857/sod off (0.00/0/0)
udp 0 0 10.0.0.6:40543 10.0.0.5:1026 ESTABLISHED 5857/sod off (0.00/0/0)

Environment

  • BIG-IP.
  • HA pair.
  • Active device shows HA pair as Offline.

Cause

sod process not working as expected.

Recommended Actions

Perform the following steps during a maintenance window:

1. Failover the traffic to peer device
2. Connect to the newly Standby device CLI
3. Restart sod

bigstart restart sod

4. Check HA status
5. If issue persist please force mcpd to reload

touch /service/mcpd/forceload
reboot

Additional Information

None
