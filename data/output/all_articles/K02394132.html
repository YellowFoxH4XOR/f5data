Description

Unable to reconfigure iApps after a BIG-IP software upgrade. The following error occurs:

Error parsing template:01020005:3: The requested operation is not implemented yet.

Environment

  • BIG-IP APM 
  • Configured iApps
  • BIG-IP upgrade

Cause

Intermittent issues with mcpd process.

Recommended Actions

Restart mcpd process. Refer to K13030: Forcing the mcpd process to reload the BIG-IP configuration for the step by step instructions.

Additional Information

Bug ID 721338: Error creating application service from imported iApp Template
