Issue

Error Message

local/tmm err tmm[<PID>]: 01010005:3: Profile <Profile_Name>, ramcache_uri_<includes/excludes/pinned> error - couldn't compile regular expression pattern: quantifier operand invalid

In this error message, note the following:

  • <PID> is the process ID for TMM.
  • <Profile_Name> is the name of the affected HTTP profile.
  • <includes/excludes/pinned> indicates which elements in the HTTP profile's RAM Cache configuration TMM failed to compile.

For example:

local/tmm err tmm[7346]: 01010005:3: Profile cache-test, ramcache_uri_includes error - couldn't compile regular expression pattern: quantifier operand invalid

local/tmm err tmm[7346]: 01010005:3: Profile cache-test, ramcache_uri_excludes error - couldn't compile regular expression pattern: quantifier operand invalid

local/tmm err tmm[7346]: 01010005:3: Profile cache-test, ramcache_uri_pinned error - couldn't compile regular expression pattern: quantifier operand invalid

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • An HTTP profile's RAM Cache URI list configuration contains a URI entry in the Pin List, Include List, and/or Exclude List that is not formatted as a regular expression.
  • The HTTP profile is associated with a virtual server.

URIs specified in the HTTP profile's RAM Cache URI list configuration must be formatted as a regular expression. You will not receive an error message when you create or update the HTTP profile with a non-regular expression URI. However, when you apply the HTTP profile to a virtual server, TMM is unable to compile the non-regular expression URI. As a result, the BIG-IP system logs an error message and will not perform content as expected.

Impact

The BIG-IP system will not perform URI caching as expected.

Recommended Actions

Use regular expressions when configuring URI lists for URIs to be cached, excluded from the cache, or pinned in the cache.

For example, a valid URI would appear as follows

.*\.pdf

In this URI, note the following:

  • . matches any single character
  • * matches the preceding element zero or more times
  • \. matches a literal dot

Alternatively, an invalid URI would appear as follows:

.*.pdf
