K000146893: What is the limit on number of port and domain combinations in an HTTP or TCP Load Balancer?

What Happened?

I want to configure a new HTTP or TCP Load Balancer and want to know the limitations in domains and ports for it.

Environment

  • F5® Distributed Cloud HTTP Load Balancer

Resolution/Answer

  1. The load balancer now supports up to 32 domains and 64 non‑overlapping ports, with no additional restriction on the total combinations, so you can use a maximum of 32 × 64 domain port pairings.
  2. If you want your TCP load balancer to listen 443 port, please notice to enable SNI feature. If you create a TCP load balancer without SNI enabled listening on the same TCP port 443, it may lead all the HTTPs LBs don't work if the TCP LB is created first.
