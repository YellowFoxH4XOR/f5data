Source

Description

Forwarding IP virtual server with source/destination 0.0.0.0/0 stop working after software upgrade to v14.1.2
If the virtual server is acting as a default gateway for a LAN subnet, you may be failing to reach the Internet through the Forwarding IP  virtual server.
Source-port is set to preserve in the virtual server setting.
tmsh list ltm virtual <forwarding_IP_virtual_server-name> all-properties
ltm virtual /common/forwarding_IP_virtual_server-name {
    app-service none
<snip>

    source-port preserve                 =================> !
<snip>
}

Environment

  • Wildcard forwarding IP virtual server 
  • Upgrade to v14.1.2

Cause

Bug ID 890229: Source port preserve setting is not honored

Recommended Actions

To work around the issue, set source-port to preserve-strict.
