K33536596: LDAP logs not being logged with informational APM log level applied

Type
Support Solution
Published
2020-12-07
Updated
2023-02-21
Status
Legacy Content
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP APM: 12.1.4
Source
https://my.f5.com/manage/s/article/K33536596

Description
BIG-IP APM Logging profile not logging LDAP logs when being at informational level, if a manual failover is triggered, the other unit log them correctly.
For example, next kind of logs should appear when a logging profile is using informational level, but they are not: 

bigip info apmd[278789]: 01490007:6: /Common/access_profile:Common:122c2874: Session variable 'session.ldap./Common/access_profile_act_ldap_query_ag.attr.whenChanged' set to '20201116052132.0Z'
bigip info apmd[278789]: 01490007:6: /Common/access_profile:Common:122c2874: Session variable 'session.ldap./Common/access_profile_act_ldap_query_ag.attr.whenCreated' set to '20051103220720.0Z'



Environment

  • BIP-IP APM
  • Logging profile at information level

Cause
Unknown

Recommended Actions

Rebooting the affected BIG-IP should be fixing the issue.

Additional Information
None
