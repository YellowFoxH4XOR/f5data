Topic

This article applies to BIG-IP 9.x - 10.x. For information about other versions, refer to the following articles:

  • K14318: Monitoring SSL certificate expiration on the BIG-IP system (11.x - 12.x)

BIG-IP LTM Secure Sockets Layer (SSL) certificates need to be renewed prior to the certificate expiration date. You can use the Configuration utility or command line to view information about existing certificates and key pairs.

Viewing the SSL certificate expiration date from the Configuration utility

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Click SSL Certificates.
  4. The certificate expiration date appears under the Expiration column.

Note: An exclamation mark ( ! ) next to an SSL certificate indicates that the certificate has expired, or will expire within 30 days.

Viewing the SSL certificate expiration date from the command line

  1. Log in to the BIG-IP command line.
  2. To view the expiration date of the default.crt SSL certificate from the BIG-IP command line, type the following command:

    openssl x509 -in /config/ssl/ssl.crt/default.crt -noout -enddate |cut -c10-40

    The expiration date displays. For example:

    Mar 4 22:16:25 2018 GMT

The checkcert utility

The checkcert utility examines all the certificates in the /config/ssl/ssl.crt directory, including bundled certificates files. The checkcert utility is called from /etc/cron.weekly/5checkcert, and it examines the expiration date of each certificate on the system.

Note: By default, the checkcert utility does not check the ca-bundle.crt certificate file.

If the checkcert utility finds a certificate that has expired or will expire within 30 days, it logs an error message to the /var/log/ltm file.

A log message indicating that the SSL certificate has expired will appear similar to the following example:

01380001:4: Certificate 'askf5' in file askf5.crt expired on Fri Jun 15 18:11:38 2007 GMT

A log message indicating that the SSL certificate will expire in 30 days or less will appear similar to the following example:

01380002:4: Certificate 'askf5' in file askf5.crt will expire on Sat Jul 14 18:15:24 2007 GMT

Note: You can configure the BIG-IP system to send SNMP traps when the above messages are logged. To do so, refer to K3727: Configuring custom SNMP traps.
