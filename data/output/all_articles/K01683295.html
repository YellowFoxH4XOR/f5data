Description

  • DNS queries for type ANY are not responding with answer from wideip
  • DNS queries for type ANY only receive a SOA response

Environment

  • DNS queries for type ANY
  • no resource records matching the query name exist in BIND for the query
  • wideip matching the query name is available

Cause

DNS type 'ANY' queries are handled by sending the query to BIND, and once BIND has a response, sending that response back through GTMd for modification. If GTMd has a wideip matching any of the answers type and query name , it will replace it with an RR according to it's load balancing algorithm.

Recommended Actions

DNS type 'ANY' queries will be answered if a BIND resource record is configured matching the query name.
