Known Issue

The BIG-IP ASM system may incorrectly log a DoSL7 action as Blocking when logging to a remote Splunk server.

This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM system is configured for remote logging to a Splunk server.
  • The BIG-IP ASM system is configured with the DoS profile in Transparent mode.

Impact

The remote Splunk logging server displays misleading output regarding DoSL7 attacks.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Splunk DoSL7 log entries, where the attack has ended (dos_attack_event="Attack ended"), display the value of the action field as Blocking instead of Transparent, as shown in the following example:

  • DoSL7 log entries, before the attack has ended, display the correct value of the action field, as shown in the following example:
