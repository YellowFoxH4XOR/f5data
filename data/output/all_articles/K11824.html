Topic

The show health command output does not display filerAccessDenied events.

The ARX system will log filerAccessDenied events in the syslog file. The messages will appear similar to the following example:

- filerAccessDenied (181) : Dir Setattr returned 'access not permitted' for volume [/vol1] share [share1] path /Home/User/Settings/ProfileAD/

F5 Product Development is tracking an enhancement to add this functionality as ID 38711.
