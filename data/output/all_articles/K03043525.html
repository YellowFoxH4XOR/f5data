Description

  • You have configured ASM Security policy
  • The policy is set to traffic learn
  • Traffic learning suggestions identified and report a legitimate request like /favicon.ico
  • Suggests has a format

Matched HTTP URL: [HTTPS] *.[Ii][Cc][Oo]
Suggested Action: Add/Update Wildcard HTTPS URL. Set Wildcard Order to Last before wildcard URL(s) '*'.

  • When considering '*.[Ii][Cc][Oo]' , you wonder if the learning suggestion is incorrect or caused by a known issue (bug)

Environment

  • Learning Suggestion
  • ASM
  • BIG-IP

Cause

  • When Policy Builder suggests a learning suggestion'[Ii][Cc][Oo]' for '/favicon.ico' specifically '.ico', it is doing so considering both upper and lower case.
  • In other words, '[Ii][Cc][Oo]' allows the Policy Builder to add a non case-sensitive wildcard *.

Recommended Actions

  • None

Additional Information

  • Suggestion is an attempt to draw security policy administrator's attention to Policy Builder findings. 
  • A suggestion with '*.[Ii][Cc][Oo]' format, does not imply a bug or incorrect suggestion.
