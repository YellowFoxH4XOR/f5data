Topic

You can modify the /config/bigip.conf file, or use the Configuration utility, to block specific IP addresses.

Important: Before you make any changes to the bigip.conf file, create a backup of the current configuration.

Following are examples of syntax used in the /config/bigip.conf file to block and discard specific hosts. You may also choose to redirect these IP addresses to a different site rather than discard them using a rule. For specific instructions about this option, and other rule options, refer to the BIG-IP Reference Guide.

Example 1

To block a specific IP address, or group of IP addresses, from accessing a specific URL from the command line, perform the following steps:

  1. Create an address class that contains the IP addresses you want to block.

    For example:

    class blocked_hosts {
host 192.33.46.2
host 192.33.44.7
network 192.32.45.0 mask 255.255.255.0
network 207.37.95.0 mask 255.255.255.0
}

  2. Create a rule that contains the URL and the blocking host class you created in the previous step.

    For example:

    rule url_block_rule {
if (http_uri contains 'restricted_URL') {
if (client_addr equals one of blocked_hosts) {
discard
} else {
use (server_pool)
}
}
else {
use (server_pool)
}
}

Example 2

Following is a more complex example in which you create a second class of blocked pages and blocked IP addresses:

  1. Create a string class that contains the blocked URLs and an address class that contains the host addresses you want to block.

    For example:

    class blocked_pages {
'restricted_page'
'sales_results'
'future_plans'
}
class blocked_hosts {
host 192.33.46.2
host 192.33.44.7
network 192.32.45.0 mask 255.255.255.0
network 207.37.95.0 mask 255.255.255.0
}

  2. Create the rule that contains the string class and the blocking address class you created in the previous step.

    For example:

     rule url_block_rule {
if (http_uri contains one of blocked_pages) {
if (client_addr equals one of blocked_hosts) {
discard
} else {
use (server_pool)
}
}
else {
use (server_pool)
}
}
