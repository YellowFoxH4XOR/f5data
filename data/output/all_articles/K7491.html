Known Issue

This is the result of a known issue. Compression statistics for an HTTP profile can be displayed from the command line and the Configuration utility on the BIG-IP system. The BIG-IP LTM system does not update the counters for pre-compress and post-compress content type compression statistics. The total fields are updated properly; however, the individual content type statistics are not updated and display the number zero (0).

F5 Product Development tracked this issue as CR78695, and it was fixed in BIG-IP LTM 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, Hotfix-BIGIP-9.4.1-HF1 has been issued for BIG-IP LTM 9.4.1. You may download this hotfix from the F5 Downloads page.
