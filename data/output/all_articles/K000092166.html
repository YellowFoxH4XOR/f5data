K000092166: guided configuration deployment error "error reading provision response: MCP Session terminated"

Source

Description

With trying to deploy an "Azure AD Application" with the help of the Access Guided Configuration tool, you are prompted with an error message similar to:

guided configuration deployment error "error reading provision response: MCP Session terminated

 Environment

  • BIG-IP APM
  • Access Guided Configuration
  • Azure AD application

 Cause

This may be due to improper permissions to the application.

 Recommended Actions

Please ensure we have granted the following permissions to the application:

  • Application.Read.All
  • Application.ReadWrite.All
  • Application.ReadWrite.OwnedBy
  • Directory.Read.All
  • Group.Read.All
  • IdentityRiskyUser.Read.All
  • Policy.Read.All
  • Policy.ReadWrite.ApplicationConfiguration
  • Policy.ReadWrite.ConditionalAccess
  • User.Read

 Additional Information

None
