K31601079: ASM Sensitive Data masking failing

Type
Support Solution
Published
2020-12-07
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 13.1.X, 13.1.4, 13.1.3, 13.1.1, 13.1.5, 13.1.0
Source
https://my.f5.com/manage/s/article/K31601079

Description

Sensitive Data Masking is configured but specific parameters are NOT being masked

  • Specific parameters are configured as Sensitive Data to be masked.
  • Configured parameters are NOT masked.
  • No error messages are observed

Environment

  • BIG-IP ASM Security policy configured, associated to a virtual and taking traffic (policy can be in transparent or blocking mode)
  • Sensitive Data Masking feature has been configured to be on for the policy and a specific parameter has been configured

Cause

Sensitive Data Masking is not occurring due to the configuration for the Body Handling being set to something that does NOT parse parameters, for instance Apply Values and Signatures 

In order for the configured parameter settings to take effect the Body Handling needs to be set to Form Data or one of the known formats such as XML or JSON.

Recommended Actions

Change Body Handling in the policy to Form Data
