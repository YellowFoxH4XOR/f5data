Topic

Summary

The BIG-IP AFM system drops or rejects network traffic on Network Address Translation (NAT) addresses when the default Virtual Server & Self IP Contexts rule is set to drop or reject.

Description

The BIG-IP AFM system drops or rejects network traffic destined for a NAT address when the BIG-IP AFM default Virtual Server & Self IP Contexts rule is set to drop or reject. As a result, users are unable to access network resources behind the NAT address. This behavior is by design.

Recommendations

To allow network traffic to reach a NAT address, you can configure an allow firewall rule in the global context for the NAT address. To do so, perform the following procedure:

Impact of workaround: The allow firewall filter is applied to all Traffic Management Microkernel (TMM) interfaces. 

  1. Log in to the Configuration utility.
  2. Navigate to Security > Network Firewall.
  3. Click Add.
  4. From the Context menu, select Global.
  5. In the Name box, type a name for the rule.
  6. In the Protocol menu, specify the protocols to use.
  7. Enter the Source configuration in the following fields:
    • From the Address: menu, select the source address type to use with this rule.
      • To apply the rule to any IP address accessing the firewall, select Any.
      • To select a predefined list of addresses to apply to the rule,

        AFM 11.4.0 and later

        Select Specify followed by Address List and select the name of the predefined list of addresses before clicking Add.

        AFM 11.3.0

        Select List. To use an address list with this rule, move the list from the Available box to the Selected box by clicking <<.

      • To enter one or more IP addresses to which the rule applies, select Specify. Type an IP address into the Address: box, and click Add to add them to the address list. Repeat this step for each IP address to add.
    • From the Port: menu, select the source port type to use with this rule.
      • To apply the rule to any port accessing the firewall, select Any.
      • To select a predefined list of ports to apply to the rule,

        AFM 11.4.0 and later

        Select Specify followed by Port List and select the name of the predefined list of ports before clicking Add.

        AFM 11.3.0

        Select List. To use a port list with this rule, move the list from the Available box to the Selected box by clicking <<.

      • To enter one or more ports to which the rule applies, select Specify. Select Single Port or Port Range from the drop-down menu. Type a port or port range into the Port: box, and click Add to add them to the port list. Repeat this step for each port, or port range to add.
    • From the VLAN: menu, select the source Virtual Local Area Network (VLAN) type to use with this rule.
      • To apply the rule to any VLAN configured on the firewall, select Any.
      • To enter one or more VLANs behind the firewall to which the rule applies, select Specify. To use a VLAN with this rule, move the VLAN from the Available box to the Selected box by clicking <<. Repeat this step for each VLAN to add.
  8. Enter the Destination configuration in the following fields:
    • From the Address: menu, select the destination address type to use with this rule.
      • To apply the rule to any IP address accessing the firewall, select Any.
      • To select a predefined list of addresses to apply to the rule,

        AFM 11.4.0 and later

        Select Specify followed by Address List and select the name of the predefined list of addresses before clicking Add.

        AFM 11.3.0

        Select List. To use an address list with this rule, move the list from the Available box to the Selected box by clicking <<. 
      • To enter one or more IP addresses to which the rule applies, select Specify. Type an IP address into the Address: box, and click Add to add them to the address list. Repeat this step for each IP address to add.
    • From the Port: menu, select the destination port type to use with this rule.
      • To apply the rule to any port accessing the firewall, select Any.
      • To select a predefined list of ports to apply to the rule,

        AFM 11.4.0 and later

        Select Specify followed by Port List and select the name of the predefined list of ports before clicking Add.

        AFM 11.3.0

        select List. To use a port list with this rule, move the list from the Available box to the Selected box by clicking <<.
      • To enter one or more ports to which the rule applies, select Specify. Select Single Port or Port Range from the drop-down menu. Type a port or port range into the Port: box, and click Add to add them to the port list. Repeat this step for each port or port range to add.
  9. From the Action menu, select Accept Decisively.
  10. Click Finished.
