Topic

The FirePass Windows Logon Integration component allows users to establish a FirePass VPN connection when they logon to their Windows systems without modifying Microsoft GINA components. FirePass supports a limited number of pre-logon checks for Windows Logon Integration clients. If you configure a pre-logon check that does not support Windows Logon Integration clients, users using the Windows Logon Integration component cannot logon to the FirePass controller.

Note: For more information about supported pre-logon checks, refer to K8097: Windows Logon Integration support for pre-logon inspectors.

One workaround is to configure a pre-logon sequence that bypasses all pre-logon checks for Windows Logon Integration clients, while performing pre-logon checks for all other clients. To do so, perform the following procedure:

Important: FirePass detects the Windows Logon Integration component as a standalone client. By bypassing the pre-logon check for Windows Integration clients, you will also bypass the pre-logon check for users using the FirePass standalone VPN client. If you do not want to allow users using the standalone VPN client to bypass the pre-logon check, do not perform the following procedure.

  1.  Logon to the FirePass Administrative Console.
  2. Click Users.
  3. Click Endpoint Security.
  4. Click Pre-Logon Sequence.
  5. Next to the active pre-logon sequence, click the backup & edit link.

    The Pre-Logon Sequence Editor opens.
  6. To the right of the Sequence Start box, mouse over the Go action.

    A + (plus) link appears to the right of the Go action.
  7. Click the + link.

    The Change Sequence panel opens.
  8. In the Change Sequence panel, click the option button next to UI mode.
  9. Click the Apply changes button.

    The UI mode inspector appears in your pre-logon sequence.
  10. To the right of the standalone client rule, click the Logon Denied Page box.

    The End Page Properties panel opens.
  11. In the End Page Properties panel, select Logon Allowed Page from the Type menu.
  12. Click the Update button.
 
When users access the FirePass controller using the FirePass Windows Logon integration component or the FirePass standalone VPN client, they will now bypass any pre-logon checks.
