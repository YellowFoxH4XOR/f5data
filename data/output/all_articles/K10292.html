Known Issue

This is the result of a known issue. The Citrix terminal server window may appear to the right of the screen and partially off the screen if you configure a Citrix MetaFrame terminal server favorite with the following settings:

  • Separate window with menu (Citrix only) is selected in the Window Type menu
  • Percent of Screen Size is selected in the Screen resolution menu

The correct behavior is for the favorite to be displayed in the center of the screen.

Important: For FirePass version 6.0.3, this issue only occurs after installing cumulative HF-603-2, HF-603-2.1, or HF-603-3 on the FirePass controller.
 
F5 Product Development is tracking this issue as CR123814 for FirePass version 6.0.3.
 
F5 Product Development tracked this issue as CR106372 for FirePass version 6.0.2 and it was fixed in cumulative HF-602-8. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
 
For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.
 
To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.
 
Workaround
 
You can work around this issue by selecting a different setting for the Window Type option. To do so, perform the following procedure:
  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Application Access: Terminal Servers: Resources page.
  3. Select the name of the Citrix Terminal Server favorite you want to configure.
  4. In the Window Type menu, select an alternate setting.
  5. Click the Update button.
