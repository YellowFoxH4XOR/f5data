Description
After upgrading BIG-IP AFM, virtual server to virtual server, communication on the same BIG-IP AFM may be incorrectly dropped.

Environment

  • BIG-IP AFM
  • Firewall Mode
  • Upgraded to 13.1.0 or 12.1.3.6 or later

Cause
In previous versions, internal communication between virtual servers was not properly verified by AFM firewall rules and incorrectly allowed to pass.
 

Recommended Actions

  1. Allow all vlan to vlan communication.
  2. Configure BIG-IP ADM firewall rules to permit all allowed traffic and deny traffic that should not be allowed.
