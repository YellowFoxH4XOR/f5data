Description

BIG-IP DNS is responding with the IP of an offline virtual server / pool member.

Environment

  • BIG-IP DNS / GTM
  • Wide-IP
  • In the pool, fallback load balancing method will resolve to the pool member

Cause

All pool members are unavailable, the Preferred / Alternate load balancing method failed, and the fallback load-balancing method will not respect the virtual server / pool member status, (This is the normal, default behavior).

Recommended Actions

  1. Change the load-balancing method configuration of the pool to match the requirement.

  2. Enable Respect Fallback Dependency, for details, refer to Manual Chapter : About load balancing and resource availability

Additional Information

None.
