K000134773: Unable to delete any BIG-IP device from the BIG-IQ CM GUI

Type
Support Solution
Published
2023-05-24
Updated
2024-01-10
Status
Final
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.2.X, 8.2.0
Source
https://my.f5.com/manage/s/article/K000134773

Description

You are unable to delete any BIG-IP device from the BIG-IQ CM GUI. After confirming delete, nothing happens and the BIG-IP is not deleted.

Environment

BIG-IQ CM

Cause

Invalid BIG-IP device was discovered by the BIG-IQ

Recommended Actions

  1. Find the invalid BIG-IP device with iControl REST from the BIG-IQ CLI using the following command:

    restcurl /cm/shared/tasks/discovery-controller | jq '.items[].details[] | select(.hostname == null)'

  2. Review the output from the previous command and take note of the invalid device's UUID in the link under deviceReference.
  3. Delete the invalid device in the /shared/resolver/device-groups/cm-bigip-allBigIpDevices/devices/ list using the following syntax:

    restcurl -X DELETE /shared/resolver/device-groups/cm-bigip-allBigIpDevices/devices/<UUID of invalid device>

    For example:

    restcurl -X DELETE /shared/resolver/device-groups/cm-bigip-allBigIpDevices/devices/5d960da6-e346-4772-b7ee-77ebe8d5cf56

  4. After deleting the invalid device you should be able to delete the devices from BIG-IQ GUI.
