Description

Enabled the Secure attribute for ASM cookies, following the instructions in K13787.

Observing that the Secure attribute is not added to ASM Feature cookies.

Environment

  • Cookies
  • ASM cookie_secure_attr enabled

Cause

Cookies in question are not ASM Feature cookies, but actually from DoS or Bot Defense profiles. The Secure attribute is enabled for those via a db key:

sys db dosl7.use_secure_cookies {
    default-value "disable"
    scf-config "true"
    value "disable"
    value-range "disable enable"
}

Recommended Actions

Enable the Secure attribute for DoS and Bot Defense cookies:

tmsh modify sys db dosl7.use_secure_cookies value enable

Note: An ASM restart is not required.

Additional Information

Here is an example of an ASM Feature cookie set with the Secure attribute:
