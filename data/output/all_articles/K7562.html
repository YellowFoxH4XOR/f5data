Topic

The MSSQL health monitor is an Extended Application Verification (EAV) monitor that can be used to perform service checks on Microsoft SQL Server-based services. When you run the MSSQL health monitor, BIG-IP LTM calls the MSSQL_monitor program located in the /usr/share/monitors directory. The MSSQL_monitor program then logs in to the SQL database and runs a database query.

Because login times to Microsoft SQL Server-based databases can be slow, the MSSQL health monitor has relatively high default values for the interval and timeout settings: 30 and 91 seconds respectively. The high default values for the interval and timeout settings allow the MSSQL health monitor time to log in, run the database query, and report the status to the bigd process. Because the MSSQL health monitor requires enough time to perform this process, F5 recommends that you do not change the default values for the interval and timeout settings. If the interval and timeout settings are shortened, the MSSQL monitor can mistakenly mark the service as down.
