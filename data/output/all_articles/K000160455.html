K000160455: Script to collect missing files from qkview due to Bug ID 2240913

Type
Support Solution
Published
2026-03-25
Updated
2026-08-14
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000160455

Description

Devices on 17.5.1.4 and 17.5.1.5 are affected by Bug ID 2240913

Environment

LTM

Cause

Bug ID 2240913 causes some files to not be included in the qkview.

Answer/Recommended Actions

Update or upgrade to a fixed version. This issue is fixed in BIG-IP 17.5.1.6. Alternatively, use the following:

1. Create a script to collect excluded files from the qkview.

   a. Login to F5 CLI.

   b. Enter commands 

        bash

        nano /var/tmp/collect_missing_qkview_files.sh

   c. Paste the following

#!/bin/bash

# Script to collect missing files not included in QKview due to bug ID2240913
# Tested on BIG-IP v17.5.1.4 and v17.5.1.5

OUTPUT="/var/tmp/missing_qkview_files_$(date +%Y%m%d_%H%M%S).tar.gz"

echo "Collecting missing files and directories..."

tar -czv \
 --exclude='*/certificate_key_d/*' \
 --exclude='*/trust_certificate_key_d/*' -f "$OUTPUT" \
/config/filestore \
/config/partitions \
/config/.diffVersions \
/shared/tmstat \
/var/log/auditd \
/var/log/botd \
/var/log/crashinfo \
/var/log/datasync \
/var/log/dwdl \
/var/log/ecmd \
/var/log/httpd \
/var/log/iprepd \
/var/log/journal \
/var/log/monitors \
/var/log/restnoded \
/var/log/tomcat \
/var/log/ts

echo "Archive created: $OUTPUT"
echo "You can download this file for further analysis."

    d. Press Ctrl + X and type 'Y' to save the file.

 

2. Run the script.

   bash /var/tmp/collect_missing_qkview_files.sh

3. Extract the .tar.gz file created from the /var/tmp/ directory.
