Issue

Error Message

01ad0016:5: Monitor Agent TMM <Number>: deleted activity: MID <MonitorID>

In this error message, note the following:

  • <Number> is the TMM ID number.
  • <MonitorID> is the in-TMM monitor ID.

For example:

notice tmm[15822]: 01ad0016:5: Monitor Agent TMM 0: deleted activity: MID 3

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when one of the following conditions is met:

  • An in-TMM monitor is deleted. 
  • A change to an in-TMM monitor is made.  The old monitor is deleted and a new one is created to replace it.

Impact

Monitor probe messages stops going out for that monitoring activity, and any latent responses are ignored until a new monitor is in place

Recommended Actions

These notification messages can be useful for analysis of in-TMM monitoring activity.  If the messages appear to be excessive or outside the scope of a monitor change or deletion, contact F5 Technical Support.
