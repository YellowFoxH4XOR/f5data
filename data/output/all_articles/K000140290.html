Description

This article describes the steps how to generate and download QKView on F5OS using Configuration Utility (Web GUI).

 

Environment

  • F5OS
  • QKView

 

Cause

You want to provide a QKView file to F5 Support to aid in troubleshooting an issue with your F5OS devices

​​​​​​​

Recommended Actions

You can generate a QKView file from the Configuration Utility. It contains diagnostic information, such as configuration data, log files, time series statistics, and platform information.
  1. Log in to the webUI using an account with admin access.
  2. On the left pane, click DIAGNOSTICS > System Reports. 
  3. To generate a system report, click Generate QKView in the upper right corner of the screen.
  4. Enter a name for Filename. You can leave other options at the default value. 
  5. To start, click Generate QKView.

 You can then download the QKView file locally.

  1. On the left pane, click SYSTEM SETTINGS > File Utilities.
  2. From the Base Directory list, select diags/shared.
  3. Under diags/shared, select qkview.
  4. Select the QKView file and click Download.

QKView files can be uploaded to F5 iHealth or send them to F5 support using your "MyF5" account.
