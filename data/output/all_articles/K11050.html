Known Issue

Important: This issue only affects the BIG-IP 1600, 3600, 3900, 6900 and 8900 platforms.

Important: Due to a different issue, any BIG-IP platform running a version prior to 10.1.0 may experience a behavior similar to that described in this Solution. For more information, refer to K10196: The BIG-IP system may not display the unit state on the LCD.

This is the result of a known issue. The LCD display of a BIG-IP system does not report the following system states:

  • Unit going active
  • Unit going standby

This behavior occurs because the alert.conf file does not include the lines that are required to update the unit state on the LCD.

Note: This issue only affects certain platforms because the alert.conf file is provided by a platform-specific package.

F5 Product Development tracked this issue as CR134883, and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Workaround

You can work around this issue by manually adding the missing lines to the alert.conf file. To do so, perform the following procedure:

Important: The /etc/alertd/alert.conf file is not included in UCS archives. If this is a concern, you may instead add the configuration entries provided in Step 5 to /config/user_alert.conf. The /config/user_alert.conf file takes precedence over the /etc/alertd/alert.conf file, and so you may wish to remove these custom entries after upgrading to a version of BIG-IP software that is not affected by this issue.

  1. Log on to the BIG-IP system command line interface.
  2. Change directories to the /etc/alertd/ directory by entering the following command:

    cd /etc/alertd/

  3. Back up the alert.conf file by entering the following command:

    cp alert.conf alert.conf.SOL11050
  4. Using a text editor, open the alert.conf file.
  5. Replace the following alerts:

    alert BIGIP_SOD_SODERR_SOD_STANDBY {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.14"
    }
    alert BIGIP_SOD_SODERR_SOD_ACTIVE {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.15"
    }

    with:

    alert BIGIP_SOD_SODERR_SOD_STANDBY {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.14";
    lcdwarn description="Unit going Standby." priority="0"
    }
    alert BIGIP_SOD_SODERR_SOD_ACTIVE {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.15";
    lcdwarn description="Unit going Active." priority="0"
    }

  6. Save the file and exit the text editor.
