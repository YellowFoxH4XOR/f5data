Note: For information about BIG-IP ASM cookies, refer to K6850: Overview of BIG-IP ASM cookies.

The BIG-IP ASM sets two types of cookies for client responses to enforce elements in the security policy. The BIG-IP ASM cookies are inserted into HTTP responses to client requests. The BIG-IP ASM signs each cookie with an MD5 digest signature, which is stored in the first 32 Bytes of the BIG-IP ASM cookie. Each time a returning client presents a BIG-IP ASM cookie, the BIG-IP ASM validates the digest stored in the cookie header against a message key stored on the BIG-IP ASM system. If the MD5 validation succeeds, the request is allowed to continue. If the MD5 validation fails, the following violation warning is logged to the /var/log/asm file, the Configuration utility on the Requests screen in 9.4.2 and later, and the Forensics section in 9.2.0 through 9.4.1:

Modified ASM Cookie

In BIG-IP ASM 9.4.0 to 11.3.0, the cookie digest key calculation used to create the MD5 signature is stored in the Advanced Configurations section in the BIG-IP ASM Configuration utility. The BIG-IP ASM system ships with a default MD5 digest key.

Important: Starting in BIG-IP ASM 11.4.0, the cookie digest key value is no longer manually configured. The cookie digest key is automatically derived with the Cookie Protect feature using an AES or BC5 Scramble algorithm.

Note: For security reasons, F5 recommends that you change the default MD5 digest key to a unique value. When changing the default value for the MD5 digest key, use the same key value for units in a redundant pair, by configuring the setting on one system and performing a config sync to the redundant pair member.

Changing the default MD5 digest key in the BIG-IP ASM system

Note: Beginning BIG-IP ASM 11.4.0, you can no longer change the default MD5 digest key in the BIG-IP ASM system. By default, the system will randomly generate the key during the initial start of the system. For more information, refer to the Configuring Advanced Cookie Protection chapter of the BIG-IP Application Security Manager: Implementations guide.

BIG-IP ASM 11.3.0

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Security > Options > Application Security > Advanced Configuration > System Variables.
  3. Type a 32-character value for the cookie_digest_key.
  4. To save the changes, click Save.

BIG-IP ASM 11.0.0 through 11.2.1

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Application Security > Options > Advanced Configuration > System Variables.
  3. Type a 32-character value for the cookie_digest_key.
  4. Click Update. (In version 10.x and later, click Save.)

BIG-IP ASM 10.2.x

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Application Security > Options > Advanced Configuration > System Variables.
  3. Type a 32-character value for the cookie_digest_key.
  4. Click Update.

BIG-IP ASM 9.4.0 through 10.1.0

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Application Security > Options > Advanced Configuration.
  3. Type a 32-character value for the cookie_digest_key.
  4. Click Update.

After changing the MD5 cookie digest key, you must restart the BIG-IP ASM bd process. To do so, type the following command from the command line:

bigstart restart asm
