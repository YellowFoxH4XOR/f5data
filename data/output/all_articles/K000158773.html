K000158773: Swapping of base registration key

Type
Support Solution
Published
2025-12-16
Updated
2025-12-30
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.X, 17.1.X, 17.5.1, 17.5.0, 17.1.3, 17.1.1, 17.1.0, 17.1.2
Source
https://my.f5.com/manage/s/article/K000158773

Description

Base registration keys are unique per device serial number and cannot be swapped even for the same hardware product model.

Environment

  • Base registration key
  • Hardware product model

Cause

None

Recommended Actions

Base registration keys are provided upon purchase of any hardware products. Each base registration keys are uniquely designed to contain features intended for that specific hardware.

Additional Information

Base registration keys can be moved if the device has been approved for RMA. Please refer to this article: K36582218: Error 51092: This license has already been activated on a different unit
