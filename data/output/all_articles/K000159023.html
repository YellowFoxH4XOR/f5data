Description

When a temporary evaluation add-on license is applied to BIG-IP and subsequently a permanent add-on license is activated, the system displays "Evaluation in Progress" message.

This occurs specifically when:

  • A time-limited evaluation DNS license (add-on key) was activated first
  • A permanent DNS license (add-on key) was activated afterward
  • The evaluation license has not yet expired
  • The system continues to show "Evaluation in Progress" despite the permanent license being activated

Figure: BIG-IP Console

Environment

  • Evaluation add-on license
  • Permanent add-on license
  • Time-limited evaluation license
  • Perpetual add-on license

Cause

When an evaluation or demonstration add-on license is present on the system, it takes precedence over subsequently activated permanent licenses until the evaluation license expires. The evaluation license must be actively removed or allowed to expire before the permanent license becomes fully active. This behavior is documented in Bug ID 469724.

Recommended Actions

Important: When an evaluation/demonstration add-on license expires, features included in both the evaluation add-on as well as the regular, perpetual license stop working.

Note : For F5OS (rSeries/VELOS) : F5OS does not support manual removal of add-on keys via GUI or CLI. However, expired evaluation add-on licenses are automatically removed upon license reactivation after expiration. Refer to K61532741: Expired add-on licenses (including evaluation add-ons) are automatically removed upon license re-activation for more information.

Deactivate the evaluation license via CLI or GUI. 

  1. Through the CLI, using the get_dossier command:

get_dossier -b <Base_License> -a <Add-on_License> -i <Eval/Inactive_License>

Example : get_dossier -b ABCDE-ABCDE-ABCDE-ABCDE-ABCDEFG -a ABCDEFG-ABCDEFG -i ABCDEFG-ZZZZZZ

 

  1. Through the GUI

Go to System > License

Select Re-activate

For Add-On Registration Key List, select the evaluation add-on key to be removed

Select Delete

Then activate the permanent license
