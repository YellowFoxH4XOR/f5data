K40311108: Disabling console logging on the BIG-IP system

Topic

You should consider using this procedure under the following condition:

  • You would like to prevent your BIG-IP system from displaying console log messages.

Description

The BIG-IP system is configured, by default, to log emergency syslog messages to the console port of the device.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have administrative access to the TMOS Shell (tmsh).

Disabling syslog_ng console messaging

You can use tmsh to modify the system syslog configuration by disabling syslog console logging. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure stops the BIG-IP system from generating syslog console messages.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To disable syslog console messaging, type the following command:

    modify /sys syslog console-log disabled

  3. Save the configuration change by typing the following command:

    save /sys config

  4. To exit tmsh, type the following command:

    quit
