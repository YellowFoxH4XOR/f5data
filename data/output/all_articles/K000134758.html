K000134758: Backup Schedule reverts to default Start Date and Time in BIG-IQ GUI

Type
Support Solution
Published
2023-07-01
Updated
2024-12-24
Status
Final
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.0
Source
https://my.f5.com/manage/s/article/K000134758

Description

After creating a scheduled backup under devices, if you click on the newly created backup, the Start Date reverts back to default.  If it was a weekly backup, the Days of the Week that were selected are no longer visible.

 

For instance:

 

(1) Create backup called Daily1 with start date May 11, 2020 14:0

 

Once backup is created, when you click on the actual backup name, the Start Date reverts back to default.

 

 

Environment

  • BIG-IQ
  • Big-IP Backup

Cause

Known issue tracked under Bug ID: 1301225 - "BIG IP/ BIG-IQ Backup Schedules Start Date is reset to Present date" 

 

Recommended Actions

This is just cosmetic in the GUI.

 

To know the actual backup schedule, you can:

 

1. Look at the Next Start Date/Time in the main backup schedule page:

 

 

2. Or check the start time using restcurl command from CLI

 

# restcurl /shared/task-scheduler/scheduler/ | jq '.items[] | select(.taskBodyToRun.taskBody) ' | jq -r [.id,.name,.timeToStartOn]             

[

 "cdfa6456-2652-3114-86ae-cb9020b5d2dd",

 "Daily1",

 "2023-05-11T14:00:00+1200"

]

If it was a weekly backup, you can also check the days of the week from the CLI:

# restcurl /shared/task-scheduler/scheduler/ | jq '.items[] | select(.taskBodyToRun.taskBody) ' | jq -r [.id,.name,.timeToStartOn,.daysOfTheWeekToRun]
[
"e7f9883d-8095-3460-8bc0-048b5a6bb272",
"Backup_Schedule",
"2023-08-07T00:00:00.000-07:00",
[
2,
4,
6
]
]

The Days of the Week numbers start with 1 for Sunday, 2 for Monday and so forth.  2,4,6 above stands for Mondays, Wednesdays, and Fridays.
