Known Issue

Description

Automatic license registration fails if SSL proxy is enabled.

This issue occurs when all of the following conditions are met:

  • FirePass is configured with an SSL proxy
  • The Activate License Registration Method option is set to Automatic

Impact

You are unable to use the automatic license activation feature.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Administrative console appears to hang for several minutes after clicking the Request License button.
  • The Administrative console displays the following error message:

    Error connecting to F5 licensing server.

Status

F5 Product Development has assigned ID 360577 to this issue, and has confirmed that this issue exists in the products listed in the Applies To box. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can activate the FirePass license by performing the manual registration procedure in K10476: Licensing the FirePass controller.

Impact of workaround: none
