Known Issue

This is the result of a known issue. Firefox and Safari users may be unable to connect to a Citrix Web Interface 5.x (XenApp) Portal Access favorite if client detection has been enabled. If Firefox and Safari users attempt to connect to the Citrix Web Interface 5.x Portal Access favorite, their connection will appear to hang. Users connecting with Internet Explorer should be able to connect successfully. This issue does not appear to affect Citrix Web Interface versions prior to 5.1.

F5 Networks Product Development tracked this issue as CR136958 and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in cumulative hotfix HF-610-2 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

Users can successfully establish a connection to the XenApp Portal Access favorite by using Internet Explorer.
