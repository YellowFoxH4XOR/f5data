Known Issue

The management interface cannot be disabled on BIG-IP platforms with an Always On Management (AOM) subsystem.

This issue occurs when one of the following conditions are met:

  • The platform is one of the following:
    • BIG-IP 1600 (C102)
    • BIG-IP 3600 (C103)
    • BIG-IP 3900 (C106)
    • BIG-IP 6900 (D104)
    • BIG-IP 8900 (D106)
    • BIG-IP 8950 (D107)
    • BIG-IP 11000 (E101)
    • BIG-IP 11050 (E102)
    • Enterprise Manager 4000 (C106)

Impact

The management interface cannot be disabled.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • After setting the management interface to disabled, the tmsh show running-config /net interface mgmt command falsely reports that the interface is disabled, as shown in the following example output:

    net interface mgmt {
    disabled
    mac-address 0:1:d7:65:c9:4
    media-active 100TX-FD
    }

  • After setting the management interface to disabled, the tmsh show net interface mgmt command reports that the interface is still set to up, as shown in the following example output:

    -----------------------------------------------------------
    Net::Interface
    Name Status Bits Bits Errs Errs Drops Drops Colli
    In Out In Out In Out sions
    -----------------------------------------------------------
    mgmt up 17.1G 17.1G 0 0 4.2K 0 0

  • After setting the management interface to disabled, the bigpipe interface mgmt show command falsely reports that the interface state is set to DS (disabled), as shown in the following example output:

    | DS 100 FD 2.130M 455278 1029 0 15.32G 864.0M 0

  • After setting the management interface to disabled, the bigpipe base list command falsely reports that the interface is disabled, as shown in the following example output:

    interface mgmt {
    disable
    }

Workaround

To work around this issue, you can unplug the management port, or disable the port on the connected switch. To do so, perform one of the following procedures:

Unplug the management port

Impact of workaround: None

To unplug the management port, you require physical access to the device.

Disable the port on the switch to which the management port is connected

Impact of workaround: None

To disable the port on the switch that is connected to the management interface, consult the switch documentation.
