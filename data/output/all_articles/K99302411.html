Issue

Old Behavior

In versions prior to BIG-IP 12.0.0, BIG-IP DNS wide IPs answered DNS queries for the following record types:

  • A
  • AAAA
  • CNAME

New Behavior

Beginning in BIG-IP 12.0.0, BIG-IP DNS wide IPs answer DNS queries for the following additional record types:

  • MX
  • SRV
  • NAPTR

MX, SRV, and NAPTR records provide a different type of data than A, AAAA, and CNAME records. To better accommodate the different data types, it is now possible to have two wide IPs with the same name.

Impact

After upgrading to 12.0.0 or later, you may notice your BIG-IP DNS configuration contains two wide IPs with the same name; one type A and one type AAAA. This behavior occurs under the following conditions:

  • Your configuration includes one or more wide IPs with no associated pool.
  • Your configuration includes one or more wide IPs with the IPv6 NoError Response setting enabled.
