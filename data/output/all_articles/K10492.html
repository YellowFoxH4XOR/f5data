Topic

F5 has recently discovered and corrected a number of critical issues that affect customers running BIG-IP 9.4.6. F5 recommends that all customers currently running 9.4.6 install Hotfix-BIGIP-9.4.6-425.0-HF3, or a later version of the cumulative hotfix rollup, as soon as possible.

Note: CRs new to this release are in bold text.

The following CRs are fixed in Hotfix-BIGIP-9.4.6-425.0-HF3 for BIG-IP 9.4.6:
