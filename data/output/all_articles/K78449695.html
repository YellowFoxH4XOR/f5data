Known Issue

You cannot manually disable support for the Transport Layer Security (TLS) Fallback Signaling Cipher Suite Value (SCSV) on the BIG-IP system.

This issue occurs when the following condition is met:

  • You are running a BIG-IP version that supports the TLS Fallback SCSV.  For more information about supported versions, refer to K16935: Support for the TLS Fallback SCSV.

Impact

Incompatible clients are unable to connect to the BIG-IP system, and they experience a service disruption.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Secure Sockets Layer (SSL) clients are unable to connect to the BIG-IP system
  • The BIG-IP system sends fatal SSL alerts to the client.

Workaround

There is no workaround for this issue.  However, fixed versions include the ssl.fallback_scsv database variable which you can use to enable and disable supported functionality for the TLS Fallback SCSV.  To disable the TLS Fallback SCSV in fixed versions of the BIG-IP system, perform the following procedure:

Impact of procedure: Performing the following procedure may expose the system to SSL downgrade attacks and weaknesses in SSL 3.0. You should consider such security concerns before implementing this change.

  1. Log in to the Advanced shell (bash).
  2. Disable the TLS Fallback SCSV by typing the following command:

    tmsh modify /sys db ssl.fallback_scsv value disable

To revert the change back to the default, replace disable with enable for the command in step 2 in the previous procedure.
