Security Advisory Description

BIG-IP Virtual Edition (VE) may expose a mechanism for remote attackers to access local daemons and bypass port lockdown settings. (CVE-2020-5887)

Impact

The vulnerability can occur on BIG-IP VE systems with the following configuration:

  • An IPv6 forwarding virtual server
  • An IPv6 floating self IP address
  • A virtual server has the HTTP profile configured with http explicit proxy enabled and default-connect-handling set to allow

Hosts in adjacent networks may be able to bypass port lockdown settings on BIG-IP VE hosts.

Mitigation

To mitigate this vulnerability, you can deny access to the IPv6 TMM IP address when the HTTP explicit proxy is enabled on an HTTP profile. To do so, use an iRule similar to the following example and apply it to the explicit HTTP virtual server.

when SERVER_CONNECTED {
    if { [IP::remote_addr] eq "fc00:f5::1" } {
        drop
    }
}
