K19335445: Perfect Forward Secrecy (PFS) option is inherited

Type
Support Solution
Published
2022-02-24
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K19335445

Description

When the IKE peer is configured to be IKEv2, the Perfect Forward Secrecy (PFS) option for the IPsec policy is inherited from the IKE peer configuration. Therefore, when using IKEv2, the PFS setting in IPsec policy is ignored

Environment

BIGIP IPSEC VPN implementations

Cause

When the IKE peer is configured to be IKEv2, the Perfect Forward Secrecy (PFS) option for the IPsec policy is inherited from the IKE peer configuration. 
Therefore, when using IKEv2, the PFS setting in IPsec policy is ignored.

Recommended Actions

Make sure that VPN peer supports selected PFS algorithm for both both IPSEC VPN phases
