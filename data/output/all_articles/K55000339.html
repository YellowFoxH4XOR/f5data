Description

After upgrading a BIG-IP VE some SelfIPs do not work. Because of this issue after upgrade of BIG-IP VE, some of the virtual IPs will be online and some virtual IPs will be offline.

The device shows "incomplete/unknown" in the arp table:
tmsh show /net arp 
Name           Address        HWaddress          Vlan            Status
---------------------------------------------------------------------------------------
10.10.10.10    10.10.10.10    incomplete         /Common/vlan2   unknown
10.10.10.11    10.10.10.11    incomplete         /Common/vlan3   unknown

In some systems, if the logs go back far enough, you can see the old interface mapping and the new interface mapping in this log file:

var/log/cloud-init-output.log

Environment

  • Upgrade BIG-IP VE
  • Interfaces
  • Self-IP

Cause

BIG-IP Virtual Edition (VE) now uses the Hypervisor-presented interface ordering, when the vAPP option on VMware is enabled. As the result of an upgrade from a version before the listed versions above to a version after the listed versions above, the interfaces may be reordered to match the Hypervisor-presented interface ordering.
This will cause vlans to now be associated with incorrect interfaces.

Recommended Actions

The interface assignments can be swapped in the hypervisor to remedy this situation.
Note: This action may impact other VMs on this hypervisor - not just this Big-IP.  If there are other VMs on the hypervisor it might be best to adjust the vlan interface assignments on the Big-IP.

You can use the command output from tmsh show sys mac-address to help see where the vlans and interfaces are mapped on the BIG-IP and modify the host mapping accordingly.

tmsh show /sys mac-address

------------------------------------------------------------------------------------------------------------

Additional Information

Beginning in the following BIG-IP versions in their respective software branches, BIG-IP Virtual Edition (VE) uses the Hypervisor-presented interface ordering, when the vAPP option on VMware is enabled:

  • BIG-IP 17.x.x: 17.0.0
  • BIG-IP 16.1.x: 16.1.2.2
  • BIG-IP 15.1.x: 15.1.5.1
  • BIG-IP 14.1.x: 14.1.5
