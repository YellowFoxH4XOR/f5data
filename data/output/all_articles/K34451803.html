K34451803: HTTP Debugger tools (eg: Burp) don't work over F5 SSL VPN

Type
Support Solution
Published
2020-04-09
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP APM: 14.X.X, 14.1.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.0, 14.0.1, 14.0.0
Source
https://my.f5.com/manage/s/article/K34451803

Description

Developers troubleshooting applications with the following HTTP debuggers: Fiddler , Burp , Charles.
When the F5 SSL VPN client is connected the application crashed and no traffic can be profiled. 

Environment

  • APM - Network access
  • Developer tools to be access 
Cause

When we use tools like Burp and Fiddler (i think Charles works on the same way) they add themselves as proxy (or are asked to set it IP something like 127.0.0.1 ) on the browser
This interferes with NA and hence doesn't work

Recommended Actions

Use one of the following options:
  • Enable Use Local Proxy Settings option on Network Access profile's Network Settings of the BIG-IP APM system. 

    Impact of procedure: This change affects all VPN clients accessing the network access object. You may create a network access object just for troubleshooting and assign it as a resource for your client just for testing purposes.

    1. Login to the BIG-IP Configuration utility.
    2. Go to Access > Connectivity / VPN > Network Access (VPN).
    3. Select the name of your network access.
    4. Select Network Settings.
    5. Under Client Settings, select Advanced.
    6. For Client Proxy Settings, select the checkbox.
    7. For Use Local Proxy Settings, select the checkbox.
    8. Select Save.

  • Use alternative debugging tools that does not add themselves as proxy. For example, the Chrome developer tool.

Additional Information

When you use Edge Client with other VPN/FW/Proxy tools on the client.
It may work in certain environments, however, it may also cause failure upon upgrade/config change.
In a situation where Edge Client is not working well with other VPN/FW/Proxy tools on the client, customer can narrow down the issue by only installing Edge Client to see if F5 VPN is working.
