K000139481: ASM policy export in JSON format with "Template-based" option fails with "Parent Policy is mandatory" error

Type
Support Solution
Published
2024-05-01
Updated
2024-05-01
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.X.X, 16.1.X, 17.1.X, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0
Source
https://my.f5.com/manage/s/article/K000139481

Description

When exporting ASM policy in JSON format with "Template-based" option (instead of "Full"), it results in a Could not export policy popup error within Web UI and subsequently the following message is logged to /var/log/asm:

Apr 22 09:18:34 localhost crit g_server_rpc_handler_async.pl[26585]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::ImportExportPolicy::Base::fatal_error): Could not add the Policy '/Common/1713802714'. Parent Policy is mandatory

Environment

  • Exporting a child or security policy in JSON format with Template-based option.
  • ASM / AWAF running 16.1.0 or later release.

Cause

Since 14.x, ASM/AWAF has had the ability to make parent policy as being mandatory within the Security ›› Options : Application Security : Advanced Configuration : Parent Policy Settings section in Web UI.

As part of enabling this setting, new security policies must be attached to a compatible Parent policy and it is a global device-wide setting. This is the reason behind why parent policy option has an asterisk next to it and is deemed as mandatory whenever a new child or security policy is being created.

Given that the Parent Policy is Mandatory is enabled within this section in the Web UI, it results in policy export failure when doing so in JSON format with "Template-based" option.

Recommended Actions

Disabling the Parent Policy is Mandatory setting within Security ›› Options : Application Security : Advanced Configuration : Parent Policy Settings section subsequently allows for policy export in JSON format with "Template-based" option to take place successfully without resulting in an error.

Additional Information

The JSON format export option is not available for exporting parent policies. It's only available in 16.1.0+ releases for child and security policies. The error covered in this article is observed regardless of whether we try to export a child or security policy.
