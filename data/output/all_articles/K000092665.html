Description

Dashboard control-plane CPU graph / meter show high usage even if only 1 of the control-plane cores has high CPU usage.

 

Environment

  • BIG-IP

Cause

This is due to current Dashboard design, the dashboard shows CPU usage from the busiest core. This usage is not an average of all control-plane cores.
This is tracked in ID 863709.

 

Recommended Actions

Use the "System Average" value in the Dashboard instead.

 

Additional Information

In BIG-IP VE (Virtual Edition) environment, Data plane (TMM) and Control plane are not separated on CPU core. 
Therefore, for VE platform, Control-plane CPU on Dashboard shows the busiest "CPU core", and this Usage actually includes both Data plane and Control plane utilizations.
