Known Issue

The QKView file for a secondary blade appears corrupted.

This issue occurs when all of the following conditions are met:

  • You run the qkview utility on a BIG-IP system with multiple blades.
  • You attempt to access the tarball by typing the following command:

    tar -tvzf 127.3.0.2.qkview | tail

Impact

The BIG-IP system posts the following messages:

gzip: stdin: unexpected end of file

tar: Child returned status 1

tar: Error is not recoverable: exiting now

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Normally, a QKView file created on a multi-blade system will include a QKView for every blade on the system. As a result, those QKView files have an error that makes the tarball appear corrupted, even though it is not corrupted.
