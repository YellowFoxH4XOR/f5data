Description

As a part of migration process, BIG-IP's management port need to be disconnected.
Is this affect BIG-IP to process traffic?
 

Environment

  • BIG-IP any version
  • HA pair
     

Cause

n/a
 

Recommended Actions

As long as there is no traffic which need to go through management port, no issue should occur.
However if unicast is in use for HA connectivity, management port is set. In that case, to avoid unexpected failover, force standby unit offline is recommended.
