Source

Description
Unable to delete partition due to error:

010713f9:3: The folder /<folder_name> cannot be deleted because it contains configuration item (folder /<folder_name>/Drafts)

Environment

  • LTM v13.1.4.1
  • deleting a custom partition

Cause
You have to delete the draft first before the deleting the partition

Recommended Actions

  1. Login to bash or command line.
  2. Enter to TMOS by typing:
    # tmsh
  3. Use command to delete the folder (change <folder_name> to the correct folder):
    # delete sys folder /<folder_name>/Drafts
  4. Use the command to delete the intended partition
    # delete auth partition <partition_name>
  5. To save changes, run:
    # save sys config
