Known Issue

This is the result of a known issue. If you include a BIG-IP 9.0 - 9.0.4 unit in a 3-DNS configuration, the following message may appear in the 3-DNS /var/log/3dns log file:

3dnsd: CFG:checkResources: Insufficient prober resources at <IP address>. Can not dynamically increase the factory count as the maximum of 255 has been reached.:iqmaster.c:186

This message occurs because iQuery messages sent by the BIG-IP system have an incorrect time stamp. When 3-DNS reads the incorrect time stamp, it may attempt to increase the size of the iQuery message queue.

This problem does not affect user traffic, but may result in a large log file.

F5 Product Development tracked this problem as CR45293 and it was fixed in BIG-IP 9.0.5. For information about upgrading, refer to the BIG-IP LTM Release Notes.
