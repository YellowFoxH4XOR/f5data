Description

At the time of article publication, BIG-IP does not yet support Record Size limit TLS extension described in RFC 8449.
Even though client comes in with record_size_limit TLS extension set in client hello message, BIG-IP just ignores it.

 

Figure: Handshake with record_size_limit extension

 

Figure: Record Size Exceeded

"Maximum Record Size" client-ssl profile setting is available to control TLS record size.

Figure: Maximum Record Size option

 

Environment

  • Virtual server with client-ssl profile.
  • Client hello TLS message contains record_size_limit TLS extension.

 

Cause

None.

None.
