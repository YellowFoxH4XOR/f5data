Known Issue

Network access resources may be unreachable on Windows 8 devices.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with a network access profile.
  • You establish a network access session using PPPoE on Windows 8.

Impact

You are unable to access network resources.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The first attempt to establish a network access session using Point-to-Point Protocol over Ethernet (PPPoE) does not allow access to network resources.
  • A second attempt to establish a network access session using PPPoE allows access to network resources.
  • When viewing the user device routing table before establishing a network access session, the routing table includes a default route.
  • When viewing the user device routing table after establishing the first PPPoE network access session, the routing table does not include a default route.

Workaround

To work around this issue, you can terminate the current access session and establish a new access session.
