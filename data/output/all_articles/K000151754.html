K000151754: High Memory usage on BIG-IP due to ASM memory leak with SSRF DNS lookup

Type
Support Solution
Published
2025-06-16
Updated
2025-06-16
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.1, 17.1.0
  • BIG-IP LTM: 17.1.1, 17.1.0
Source
https://my.f5.com/manage/s/article/K000151754

Description

High memory usage may occur on BIG-IP systems with provisioned WAF/ASM. Memory consumption can increase steadily, sometimes exceeding 95%, without any memory killer events or out-of-memory (OOM  Killer) log entries. System logs may display repeated errors such as:

IO_PLUGIN|ERR |May 31 09:16:28.720|25969|dns_resolver.c:0183|dns_lookup_notify_status: job handle id null. req_id <5996670636214837316>

IO_PLUGIN|ERR |May 31 09:25:37.461|25969|dns_resolver.c:0183|dns_lookup_notify_status: job habdle id null. req_id <5996670636214837476>

Environment

  • Enabled modules: ASM/WAF
  • SSRF DNS lookup enabled

Cause

This issue is caused by a memory leak in the ASM process, related to the following known bugs:

Bug ID 1360965: Occurs when DNS lookup features (such as SSRF) are enabled and wildcard parameters use auto-detect.

Bug ID 1325145: Occurs when SSRF configuration is present for domain names with the action set to "Resolve". These conditions cause the ASM process to gradually consume more system memory.

Recommended Actions

Upgrade BIG-IP software to version 17.1.2 or later.
