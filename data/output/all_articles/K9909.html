Topic

When the BIG-IP ASM bd process stops accumulating a response, error messages that appear similar to the following examples may be logged to the /var/log/asm file:

Status Code 01310014 - ASM filtered HTML exceeded limit: event code C499 Filtered Response HTML exceeded max limit

Status Code 01310013 - ASM bad response: event code I1627 Stopped response accumulation / extraction for support id: <support_id>

This behavior may occur when a response is more than 50 MB in length, or when certain functionality, such as DataGuard or extraction, is not working as expected. When this issue occurs, you can attempt to mitigate the issue and increase the size of the response buffers by changing the max_filtered_html_length internal parameter.

Note: For information about changing the max_filtered_html_length value, refer to K42301022: Configuring the BIG-IP ASM system to parse HTTP responses that are larger than 50 MB in length (11.x - 13.x).

Note: This behavior only occurs in text/* content types, and only if the BIG-IP ASM system is accumulating responses.
