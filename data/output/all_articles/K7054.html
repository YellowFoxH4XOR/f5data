Topic

This article applies to BIG-IP 9.x. For information about other versions, refer to the following article:

  • K14913: Setting the recursion bit for gtmd process replies on the BIG-IP GTM system (10.x - 11.x)
The recursion available (RA) bit is set or cleared by a nameserver in all DNS responses, to indicate if recursion services are available. The bit is true if the name server is willing to provide recursive service for the client, regardless of whether the client requested recursive service. However, some applications may not accept DNS responses that do not have the recursion bit set.
Two separate daemons can answer DNS queries on a BIG-IP GTM system. The gtmd process answers for wide IP names, and the named process answers for non-wide IP (BIND) DNS zone entries.
The gtmd process is authoritative for wide IP names and does not, by default, set the RA bit in responses. If you require the BIG-IP GTM system to set the RA bit for all gtmd answers for wide IP names, perform the following procedure:
  1. Log in to the BIG-IP GTM Configuration utility.
  2. Navigate to System > General Properties.
  3. From the Global Traffic menu, click General.
  4. Select the Gtmd Sets Recursion check box.
  5. Click Update.
