Known Issue

This is the result of a known issue. The BIG-IP snmp_dca monitor does not include the community string, and leaves it blank when sending out monitor probes. As a result, no statistics are available for the dynamic ratio load balancing algorithm and the BIG-IP system will distribute connections using a 1:1:1 ratio among pool members.

F5 Product Development tracked this issue as ID 224950 (formerly CR138162) and it was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, the issue was fixed in Hotfix-BIGIP-10.1.0-3402.0-HF2, which has been issued for BIG-IP version 10.1.0, and in Hotfix-BIGIP-10.2.0-1755.1-HF1, which has been issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
