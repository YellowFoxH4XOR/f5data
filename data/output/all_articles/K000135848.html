K000135848: APP_PROTECT failed to open /opt/app_protect/config/config_set.json with errno 13: Permission denied

Type
Support Solution
Published
2023-08-14
Updated
2025-06-27
Source
https://my.f5.com/manage/s/article/K000135848

Description

  • Trying to enable Nginx App Protect fails with an error message.
  • Error messages: "APP_PROTECT failed to open /opt/app_protect/config/config_set.json with errno 13: Permission denied"

Environment

  • Nginx App Protect installed and configured via Nginx conf file

Cause

This error can occur if selinux is not installed/enabled or applied correctly on the directory.

Recommended Actions

  • Follow our NAP Administration Guide SELinux Configuration to configure/install/manage SE Linux.

Additional Information
