Description

On GUI, EV certificate CN value is not correctly displayed. Here is example of the issue. 

Figure: EV certificate issue screenshot

 

On this example, the correct common-name is "web123.f5ss.local". However, some EV certificate unique attribute, such as "serialNumber" or "businessCategory", are wrongly displayed as part of common-name.

OpenSSL command shows the certificate CN as "CN=web123.f5ss.local".

[root@bigip:Active:Standalone] config # openssl x509 -in /config/filestore/files_d/Common_d/certificate_d/\:Common\:evcert_web123.f5ss.local_73070_1 -subject -noout -nameopt RFC2253
subject= C=JP,ST=Tokyo,L=Minato-ku,street=1-2-3Akasaka,O=F5SS Co.\,Ltd.,CN=web123.f5ss.local,businessCategory=Private Organization,jurisdictionC=JP,serialNumber=0000-01-234567
[root@bigip:Active:Standalone] config #

 

This is GUI cosmetic issue. This does not cause any functional problem in SSL traffic processing.

 

Environment

  • EV certificate is imported and displayed on GUI.

 

Cause

Bug ID1378141.

 

Recommended Actions

To confirm common-name, you can use "list sys crypto cert [certificate-name] | grep common-name" command.

root@(bigip)(cfg-sync Standalone)(Active)(/Common)(tmos)# list sys crypto cert evcert_web123.f5ss.local | grep common-name
    common-name web123.f5ss.local
root@(bigip)(cfg-sync Standalone)(Active)(/Common)(tmos)#
