Issue

Error Message

notice mcpd[<PID>]: 01070638:5: Pool <pool_name> member <member_name>:<port> monitor status <status>.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process
  • <pool_name> is the partition and name of the pool
  • <member_name> is the partition and node name of the pool member
  • <port> is the port number used by the pool member
  • <status> is the availability status of the pool member

For example:

notice mcpd[7845]: 01070638:5: Pool /Common/pool_http member /Common/10.10.10.10:443 monitor status down.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • A health monitor is configured to check the availability of a pool member.
  • The availability status for the pool member changes to a status other than up.

The pool member status is dependent on the virtual server configuration, and the configuration and health status results for associated monitors. The system generates this message when it detects a status change for a pool member and the pool member status changes to one of the following:

  • unchecked
  • node down
  • down
  • forced down
  • up and awaiting man resume
  • iRule down
  • inband down
  • FQDN down

Note: This message is not generated when the pool member availability status is up.

Impact

This message is informational and reports the availability status of a pool member. Unexpected changes to a pool member's availability state may indicate a configuration problem or lack of resource availability.

Recommended Actions

If the system reports an unexpected down status, verify the pool member configuration, the configuration of associated pool member monitors, and the resource availability to ensure pool member availability.
