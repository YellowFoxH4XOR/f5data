Description

When provisioning vCMP guests in SSL Dedicated mode, regardless of the number of cores per guest selected, it is not possible to create more than 1 guest. Once tried the following error occurs: 
Exceeded the platform maximum of 1 guests/slot with SSL mode 'dedicated' on slot(s): 0

Environment

  • Boxes with a single Coleto Creek SSL card

Cause

For the units with a single Coleto Creek SSL card only one guest with SSL dedicated mode can be created. Once setting vCMP guest with SSL dedicated mode, the whole chip is assigned for this guest and there is nothing else we can assign to another one. 

Recommended Actions

The number of Guests with SSL Dedicated Mode relies on a number of Coleto Creek accelerators.  

For example: single Coleto Creek SSL card = 1 vCMP SSL  dedicated  mode Guest
