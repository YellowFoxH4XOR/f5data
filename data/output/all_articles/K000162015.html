K000162015: Luna HSM Client installation fails on BIG-IP 17.5.1.x due to insufficient disk space in the /usr partition

Type
Support Solution
Published
2026-07-01
Updated
2026-07-01
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000162015

Description

Installation of Luna HSM Client on BIG-IP LTM fails with errors related to insufficient disk space in the /usr partition, which is mounted as read-only.

Environment

  • BIG-IP LTM, version 17.5.1
  • /usr partition at 100% capacity and mounted as read-only
  • Attempting installation of Luna HSM Client for SafeNet Luna HSM integration

Cause

Insufficient available space in the /usr partition, which is also mounted as read-only by default, prevents the installation of the Luna HSM client.

Answer/Recommended Actions

 

  1. Verify /usr filesystem utilization and note down the filesystem path using df -h command. For example:
    df -h 
    Filesystem                             Size  Used Avail Use% Mounted on

  2. Remount /usr with read-write attribute: 
    mount -o remount,rw /usr 
  3. Resize the /usr partition, using the previously noted path: lvresize -L +500M -r <your-usr-lv-path> For example:
    lvresize -L +500M -r /dev/mapper/vg--db--vda-set.1._usr 
  4. Proceed with Luna HSM client installation.
  5. Remount /usr as read-only:
    mount -o remount,ro /usr
  6. Ensure the system is not in Appliance Mode, as this may restrict installation capabilities.
