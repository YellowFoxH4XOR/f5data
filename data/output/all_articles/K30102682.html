Description

Under rare conditions while booting lopd may fail to connect to LOP and result in a failed boot or reboot loop

  • failed boot resulting in reboot loop
  • Error message:
    013d0004:3: Not connected to LOP (retrying) : LopDev: Lop Dev Socket connect Failed (error code:0x2)

Environment

This issue may occur on the following F5 Network appliances and blades:
  • BIG-IP 2000-/4000-series appliances
  • 5000-/7000-series appliances
  • 10000-/12000-series appliances
  • VIPRION B2100, B2150, B2250 blades

Cause

Bug ID 498332

Recommended Actions

To prevent the issue you must upgrade to a version where ID 498332 is fixed (12.0.0 or above).
If upgrade is not possible installing to a different volume can work around the issue but will not prevent it from happening again.

Additional Information

Certain F5 appliances and blades implement the Always On Management functionality via a LOP (Lights Out Processor) or LBH (Lights Out Processor/Backplane Microcontroller Hybrid) device. Under rare conditions while the LOP/LBH firmware is being accessed or updated at boot the firmware for that boot location may become corrupted.
