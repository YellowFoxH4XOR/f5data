Description

This article will describe how to configure non-default SNAT with Per-App VPN configurations.

  • When using a non-default SNAT Per-App VPN configurations will fail.

Environment

  • Access Policy Manager (APM)
  • Virtual Policy Editor (VPE)
  • Per-App VPN Configuration.
  • Apple iOS
  • F5 Access client

Cause

When using a non-default SNAT Per-App VPN configurations will fail.

Recommended Actions

Adding a Route Domain and SNAT Selection object to the Virtual Policy Editor (VPE):

  1. Login to the Configuration Utility.
  2. Navigate to Access>Profiles>Policies>Access Profiles (Per Session Policies).
  3. Click on Edit under the Per-Session Policy.
  4. In the VPE click on the + sign.
  5. Select the Assignment tab and select the Route Domain and SNAT Selection object.
  6. Select the correct Route Domain and SNAT from the drop down menus.
  7. Click Add Item.
