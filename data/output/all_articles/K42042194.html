Description

You should consider using this procedure under the following condition:

  • The BIG-IP is not responsive (device is down)
  • You noticed that is not booting up
  • Direct console connection to the device shows nothing
     

Environment

  • BIG-IP 
  • Hardware Platform
     

Cause

Unknown at time of publication.
 

Recommended Actions

Cold shutdown the device by following these steps.

  1. Shut down the device completely. 
    • For some devices: From the BIG-IP system front panel, hold the X button for four seconds to turn off the host subsystem.
  2. Turn off Power Supply Unit (PSU) switch.
  3. Disconnect all network cables from the system including the power cables.
  4. Once the device is off, wait a few minutes before plugging back the power cables and console cable. Don't connect network cables yet.
  5. Power on the device.
    • If the BIG-IP system does not start up after you perform this procedure, contact F5 Technical Support.
    • If the device starts, run EUD. 
  6. If the device successfully booted up, generate QKView and open a Support Case.
  7. Connect all network cables and verify services.
