Description

NGINX App Protect not sending logs to Remote Logging Server.

 

Environment

  • Splunk
  • Default Logging profile applied
 

Cause

The file /etc/app_protect/conf/log_default.json has to be referenced in the directives in nginx.conf file.
 

Recommended Actions

Following steps describe steps to creating a custom logging file and associating it to nginx config file.

1. It is recommended to create a custom security log directive file that meets the logging requirements

It can be done first by copying the default file log_default.json and giving it a desired name.

The following section is then adjusted:

"content": {
"format": "default", <<<
"max_request_size": "any",
"max_message_size": "5k"
}

In the case of Splunk, change "format" to splunk.

2. Using any preferred editor, open nginx.conf and change the log_default.json to the custom one created in the previous step.


It should then look as below:

app_protect_security_log "/etc/app_protect/conf/<custom_log_default>.json" /var/log/app_protect/security.log;

3. Restart NGINX by entering one of the following commands, as appropriate for the initial NGINX installation method and operating system:

# nginx -s reload
Or
# systemctl restart nginx
