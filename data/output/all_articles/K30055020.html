K30055020: How to tell the SSLO software version from any BigIP ISO image?

Type
Support Solution
Published
2022-08-13
Updated
2023-02-21
Applies to

Source
https://my.f5.com/manage/s/article/K30055020

Description
New BIG-IP software releases may come with new SSL Orchestrator software version.
You may want to get to know if any new SSL Orchestrator software is bundled within a BIG-IP ISO image.

Environment

  • F5 SSL Orchestrator

Cause
None

Recommended Actions

  1. Download the BIG-IP ISO image
  2. Import the ISO file to BIG-IP with navigating to System  ››  Software Management : Image List  ››  New Image...
  3. Open a terminal connection to the BIG-IP
  4. Navigate to the ISO folder: #cd /shared/images
  5. Create a temporary folder: #mkdir /mnt/cdrom
  6. Mount the ISO image: #mount -t iso9660 -o ro,loop BIGIP-<version>.iso /mnt/cdrom/
  7. Navigate to the right folder: #cd /mnt/cdrom/BIGIP<version>/noarch
  8. Run the command: #rpm -qlp `ls | grep orchestrator`
    This later should output something similar to this: /usr/share/packages/f5-iappslx-ssl-orchestrator/f5-iappslx-ssl-orchestrator-16.1.1-9.1.70.noarch.rpm
    The last 3 digits - 9.1.70 in the example above - show the SSL Orchestrator software version.
  9. Issue the commands:
  • #cd /
  • #umount /mnt/cdrom
  • #rmdir /mnt/cdrom
