K000149513: HTTP compression enabled may affect Network Access connection

Description:

Users are unable to connect to the VPN using F5 BIG-IP APM. The issue occurs regardless of whether the Edge Client, browser components (Network Access), or the F5 Access app from Apple Store is used.  Logs indicate repeated errors such as:

Profile download failed, Network error
Error occurred while processing request (2)
Recv failure: Connection reset by peer

Additionally, attempts to access "<VPN_server_FQDN>/pre/config.php?version=2.0" result in connection resets. See the Additional Information section to get detailed information on how to confirm the issue.

Environment

  • Edge Client or browser or F5 Access App used to connect
  • HTTP compression profile attached to Network Access Virtual Server

Cause:

The root cause of the issue may be caused by the HTTP compression profile attached to the affected VS. This causes connection failures for requests involving XML files (such as "/pre/config.php?version=2.0"). The BIG-IP system does not natively support compression for this XML file.

Recommended Actions

To resolve the issue, a solution could be to exclude the specific resource from compression. To achieve this, you need to identify the HTTP Compression profile associated with the Network Access Virtual Server and then edit it as follows:

  1. Navigate to Local Traffic ›› Profiles : Services : HTTP Compression ›› Select the appropriate profile name.
  2. Ensure that Selective Compression is enabled (if it was not already selected).
  3. Add /pre in the URI Exclude List field and save the changes by pressing the "Update" button at the bottom of the page.

This configuration ensures that requests to the /pre/config.php file are excluded from compression, which can help resolve issues related to XML file handling during VPN connection attempts.

Additional Information

To verify the availability of the config.php file, you can execute the following curl command:

curl -v '<VPN_server_FQDN>/pre/config.php?version=2.0'' -H "user-agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/132.0.0.0 Safari/537.36" --compressed

please replace <VPN_server_FQDN> with the actual server address.

The curl command simulates an HTTP request to fetch the XML resource (config.php) required by the VPN client. If successful, the server should return the content of the XML file without errors. If there is an error such as "Connection reset by peer," it may indicate a compression issue.

Alternatively, you can try to open the link: https://<VPN_server_FQDN>/pre/config.php?version=2.0 in a browser.
