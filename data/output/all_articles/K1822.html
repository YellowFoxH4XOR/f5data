Topic

To configure an FTP health monitor to work in passive mode, use the following steps:

  1. Log in to the command line.
  2. Create a monitor to set the FTP pinger to passive mode:

    Note: The following command creates a monitor called passive_ftp with a username of anonymous and a password of user@company.com. The command also retrieves the /README file. The important part of this command is FTP_PASSIVE "1" which sets the FTP pinger to passive mode.

    bigpipe monitor passive_ftp '{ use ftp username "anonymous"
password "user@company.com" get "/README" FTP_PASSIVE "1" }'
  3. Type the following command, where x.x.x.x is the IP address of the node you want to service check: This node is associated with the monitor you created in step 1.

    bigpipe node x.x.x.x:21 monitor use passive_ftp

  4. Save the configuration by typing the following command:

    bigpipe save

Editing the /config/bigip.conf file to create a passive FTP pinger

To configure an FTP pinger to work in passive mode by editing the /config/bigip.conf file, open the /config/bigip.conf file and add the following information at the bottom, under the monitors section.

monitor passive_ftp {
       # type ftp
        use "ftp"
        interval 5
        timeout 16
        dest *:*
        username "anonymous"
        password "user@company.com"
        get "/README"
        FTP_PASSIVE "1"
}
node x.x.x.x:21 monitor use passive_ftp
