Known Issue

The Configuration utility may report a general database error message when accessing the Local Traffic > Pools > Pool List page.

This issue occurs when the following condition is met:

  • You sort the nodes displayed in the Local Traffic > Nodes > Node List page by address prior to accessing the Pool List page.

Impact

Configuration utility users are unable to view the Pool List page.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When accessing the Pool List page, the Configuration utility displays an error message that appears similar to the following example:

    General database error retrieving information.

Resolution

Status

Workaround

To work around this issue, you can use a browser tool to delete the JSESSIONID cookie that causes the error message, or you can navigate back to the Node List page and sort the nodes by Name.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
