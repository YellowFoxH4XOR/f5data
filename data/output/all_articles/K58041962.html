Description

After upgrading a VCMP host or performing a UCS restore the configuration fails with the following error message when running tmsh load sys config:

err mcpd[1001]: 01071769:3: Decryption of the field (sym_unit_key) for object (<guest name>) failed

Environment

  • An upgrade or UCS restore of the vCMP host
  • Having a vCMP guest's sym-unit-key field populated
  • Having changed the host's master key

Cause

Bug ID 803833

Recommended Actions

  1. Disable all VCMP guests on the VCMP hosts
  2. Backup the configuration file /config/bigip.conf:
    # cp /config/bigip.conf /var/tmp/bigip.conf_K58041962
    Note: A backup file will created: /config/bigip.conf.bak
  3. Edit /config/bigip.conf on the host and comment out the objects with sym-unit-key field
    Warning: Manually modifying the configuration file is not supported by F5, however, this technique has been known to mitigate this issue.
    # sed -i.bak 's/sym-unit-key/#sym-unit-key/g' /config/bigip.conf
  4. Reload the configuration
    tmsh load sys config
  5. Save the configuration
    tmsh save sys config
  6. This will generate a new sym-unit-key for each VCMP guest
  7. The sym-unit-key is used to generate the master key for each VCMP guest, since you have changed this for each guest you then need to retrieve the master key from each of the other VCMP guest peers if they are in a high availability pair per K9420: Installing UCS files containing encrypted passwords or passphrases (11.5.x and later)
