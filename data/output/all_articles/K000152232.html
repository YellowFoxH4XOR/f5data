Description

A "Provisioning Warning" alert appears on the BIG-IP dashboard. This warning is visible in the GUI and also appears in the CLI as 'ModuleNotLicensed'.

For example: 

GUI:

Figure: Provisioning Warning – Resource Provisioning screen showing the LTM module provisioned without a license.

CLI prompt:

[root@BIG-IP1:ModuleNotLicensed::Active] config #

Environment

  • BIG-IP

Cause

This warning appears because a module has been provisioned without a valid license, which is expected behavior in such cases.

Recommended Actions

1. De-provision Unlicensed Module: you need to de-provision the module that has no license.

Important: De-provisioning can impact traffic. It's recommended to perform this during a maintenance window or when the device is in Standby.

You can do this via the BIG-IP GUI:

1. Go to System > Resource Provisioning

2. Set the unlicensed module to None

3. Submit the changes

Or via CLI:

tmsh modify sys provision <module_name>  level none
tmsh save sys config

2. Review Licensing:
If you need to use the module, obtain and install the correct license.
