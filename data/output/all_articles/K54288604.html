K54288604: How to migrate from VE Subscription or ELA Load licenses to FCP Catalog licenses

Description

You need to migrate from Virtual Edition (VE) Subscription license keys or from Enterprise License Agreement (ELA) Load license keys to the new Flex Consumption Program (FCP) Catalog (CAT) license keys.

Environment

  • ELA/LOAD or VE/Subscription licensing
  • FCP/CAT licensing
  • BIG-IQ License Manager/Centralized Manager
  • BIG-IP Virtual Edition (VE)

Cause

VE Subscription or LOAD licenses are expiring and need to be replaced with the new, active FCP CAT licenses. 

Recommended Actions

  • Activate the new CAT license keys
  • Assign the new CAT license offering

Note: Reactivating the license impacts traffic on the device receiving the new license. F5 recommends performing these changes during a maintenance window.

Activate the new CAT license keys

Since all licenses within this catalog should be activated, the automatic method is preferred, but this requires access to the internet. Otherwise each offering needs to be manually activated. This involves generating the dossier and activating it via activate.f5.com.

  • Automatically install FCP licenses for BIG-IP VEs using BIG-IQ
  • How to manually license FCP in BIG-IQ

Assign the CAT license offering to the BIG-IP

  1. On the BIG-IQ, navigate to Devices tab > License Management > Licenses
  2. Select the Name of the Catalog license key created in step Activate the new CAT license keys
  3. Choose the relevant Offering Name
  4. Under Assignment, select License Devices
  5. From the drop down list, set the Unit of Measure to Yearly. This is the only accepted unit for FCP.
  6. Optional: Add a Chargeback Tag to identify this instance for internal organization. 
    Note: This is the only time to add a Chargeback Tag. To update this post activation, the BIG-IP license must be revoked then reapplied.
  7. If the BIG-IP is:
    • Managed:  Select the device from the drop down list
    • Unmanaged:  Enter IP in Device Address, confirm Port, and provide credentials for the BIG-IP.
  8. Select Assign in the bottom right corner of the screen
  9. Confirm Assignment select OK. 
    Important:     Reactivating the license impacts traffic as services restart on the BIG-IP. F5 recommends performing these changes during a maintenance window.
  10. Notice under Devices > License Management > Assignments that the status of the BIG-IP is now active and running (green).
  11. On the BIG-IP, after its services restart, verify the license via System > License. It should be provided by the BIG-IQ and should match the offering just assigned.
