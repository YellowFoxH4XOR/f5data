K000140755: Creating a new partition results in "Install Status" shows "None"

Type
Support Solution
Published
2024-08-20
Updated
2024-08-20
Applies to
  • F5OS
  • F5OS-C: 1.6.X, 1.6.2, 1.6.1, 1.6.0
Source
https://my.f5.com/manage/s/article/K000140755

Description

After creating a new partition, the system controller shows the partition's Install Status as None.

Environment

  • Creating a new partition via system controller

Cause

This is expected behavior anytime you create a new partition.

  • Once you create a new partition, the Install Status gets displayed as None.
  • Upon upgrading the partition, the value gets changed to Pending during the course of installation and eventually to Success once it is successful.

Recommended Actions

None, as it is expected behavior to see Install Status as "None" when creating a new partition.

Additional Information

None.
