K000092512: BIG-IP java connection to port 443 of BIG-IQ Centralized Manager's management IP

Type
Support Solution
Published
2022-10-27
Updated
2022-11-01
Source
https://my.f5.com/manage/s/article/K000092512

Description

  • BIG-IP maintains a java connection to the BIG-IQ CM's management IP on port 443 after upgrading to from 14.1.4 to version 15 or higher
  • Firewalls might start seeing packets and block if there is no allow rule for this

 

 Environment

  • BIG-IQ Centralized Manager
  • BIG-IP added to the CM
  • Statistics collection is not enabled/ required

 

 Cause

This is a change in behavior due to a fix applied to a different issue on v14 where the BIG-IQ needs to maintain certain statistical information from BIG-IPs. However, it seems this is an unintended side effect whereas the BIG-IP maintaining this connection is not really needed. A new ID has been created to track this behavior.

 

Bug ID 1182729 iControl REST: java connection establishing from BIG-IP to BIG-IQ MGMT

 

 Recommended Actions

This connection is harmless but is also not doing anything. Either allow it on firewalls or disable it using the steps provided

  1. vi /etc/rest.BIG-IP.properties
  2. set "rest.common.device.automatic.refresh.enabled" : false
  3. save /etc/rest.BIG-IP.properties
  4. bigstart restart restjavad
