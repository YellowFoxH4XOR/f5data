K64302672: How to modify the time for log rotation

Type
Support Solution
Published
2020-04-15
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K64302672

Description

By default, the BIG-IP system is configured to rotate the log file after 3AM or 4AM. For example, in the LTM log file, the first line is like:

Apr  6 04:41:07 <hostname> info audit_forwarder: audit_forwarder started.

In some cases we need to change the time for the log rotation.

Environment

  • BIG-IP
  • Log file rotation

Cause

None

Recommended Actions

  1. Please check the system load history, find the period for the light load. For example, the system load is light from 5AM to 10AM.
  2. Please review the article K33730915, modify the setting for START_HOURS_RANGE via the text editor. For example, the setting below will change the log rotation event between 5AM to 10AM:

    START_HOURS_RANGE=5-10

    Note: There is no need to restart any process, the changes will take effect the next day.
