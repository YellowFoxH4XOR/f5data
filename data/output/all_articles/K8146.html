Issue

This article applies to FirePass. For information about BIG-IP APM, refer to the following article:

  • K15453: Error Message: Network Access Connection Device not found

When a Microsoft Windows client opens a Network Access connection, the FirePass client component may display an error message that appears similar to the following example:

Network Access Connection Device was not found

This error message may occur when one or more of the following conditions are met:

  • The Telephony service or the Remote Access Connection Manager service is disabled, corrupted, or cannot start on the Windows client system
  • The F5 Network VPN Adapter was disabled or uninstalled on the client system
  • The Network Access client components were updated from FirePass 6.0.2 components to FirePass 6.0.3 or later components

If a user continues to receive this error message, and the previously-described conditions do not apply to the client system, other factors specific to the client may cause this error message. For example, a conflict between the F5 VPN Adapter and third-party software installed on the client system. If you are unable to resolve the issue using the methods described below, contact F5 Technical Support.

The Telephony service or the Remote Access Connection Manager service is disabled, corrupted, or cannot start on the Windows client system

The FirePass Network Access client component is dependent on the Microsoft Windows Telephony API (TAPI) and the Remote Access Connection Manager service. Therefore, Windows clients cannot establish a Network Access connection unless the Telephony and Remote Access Connection Manager services are running.

Resolution

If the Startup type for the Telephony service or the Remote Access Connection Manager service is set to Disabled on the client system, you can work around this issue by changing the Startup type to Automatic and then rebooting the Windows client system. If the Startup type for the Telephony service is not set to Disabled, manually start the Telephony service if it is not currently running, or restart the Telephony service if it is running. If the Startup type for the Remote Access Connection Manager service is not set to Disabled, manually start the Remote Access Connection Manager service if it is not currently running, or restart the Remote Access Connection Manager service if it is running.

Note: Some or all of these actions may require Administrator privileges on the Windows client system.

Note: For more information about managing Windows services, refer to your Microsoft Windows documentation.

The F5 Network VPN Adapter was disabled or uninstalled on the client system

To determine whether the F5 Network VPN Adapter is installed, open the Windows Device Manager, select Show hidden devices from the View menu and then expand the Network adapters section.

Note: For more information about managing devices using the Device Manager, refer to your Microsoft Windows documentation.

Resolution

If the F5 Network VPN Adapter appears in the Windows Device Manager, right-click the F5 Network VPN Adapter. If the Enable option appears on the menu, that indicates that the adapter is currently disabled. Select Enable to enable the adapter.

If the F5 Network VPN Adapter does not appear in the Windows Device Manager, or if the Windows Device Manager reports an error with the F5 Network VPN Adapter, uninstall and reinstall the Network Access components on the client system.

Note: For more information, refer to K8253: Removing BIG-IP APM and FirePass client components from Windows client systems.

The Network Access client components were updated from FirePass 6.0.2 components to FirePass 6.0.3 or later components

This behavior is rare, and has been reported for Windows Vista clients, but it may also occur on Windows XP clients.

Resolution

Reboot the Windows client system.
