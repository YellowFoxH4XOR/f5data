Known Issue

DNS search of wide IP by alias names may display no data.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP DNS system with wide IPs that are additionally configured with alias names.
  • When using the Configuration utility, you attempt to search existing wide IPs using wide IP alias names.

Impact

Your search returns no data.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to search for a wide IP based on a configured alias name, the wide IP is not found.
  • Using a search based on the wide IP name the search returns the wide IP.
  • Reviewing the wide IP configuration lists the configured aliases.

Resolution

Workaround

To work around this issue, you can search based on the wide IP name.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
