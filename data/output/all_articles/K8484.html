Known Issue

Note:  The issue described in this document does not apply to version 10.1.x and 10.2.x, as SNMP functionality for WebAccelerator OIDs was disabled for these versions.  In WebAccelerator version 11.x, F5 re-implemented full WebAccelerator SNMP functionality, and the issue described in this document is fixed in WebAccelerator version 11.x.

The BIG-IP WebAccelerator-specific MIB file is not located in the same directory as the other MIB files on the BIG-IP system, and is not referenced by the snmpd agent. Most MIB files on the BIG-IP system are located in the /usr/share/snmp/mibs directory. However, the WebAccelerator specific MIB file is located in the /usr/local/wa/mib directory and is named wa.mib. The wa.mib file is not loaded when the snmpd agent starts. Therefore, if you try to use one of the SNMP utilities from the BIG-IP command line, the system will display the object identity only by number, and will not provide a meaningful object identifier by name for the WebAccelerator-specific OIDs. The output appears similar to the following example:

snmpwalk -v 2c -c public localhost:12406 .1.3.6.1.4.1.3375.14.1

If you type the example snmpwalk command, the system will query the snmpd agent for some of the WebAccelerator-specific OIDs. However, the descriptions do not provide meaningful object identifiers by name for the WebAccelerator-specific objects.

The snmpwalk command provides output that appears similar to the following example:

F5-BIGIP-COMMON-MIB::f5.14.1.1.0 = STRING: "Mon, 17 Mar 2008 19:25:14 GMT"
F5-BIGIP-COMMON-MIB::f5.14.1.2.0 = STRING: "101707_213034_build04_Release"
F5-BIGIP-COMMON-MIB::f5.14.1.3.0 = ""
F5-BIGIP-COMMON-MIB::f5.14.1.4.0 = ""
F5-BIGIP-COMMON-MIB::f5.14.1.5.0 = STRING: "9.4"
F5-BIGIP-COMMON-MIB::f5.14.1.6.0 = Gauge32: 3

F5 Product Development is tracking this issue as ID 248705 (formerly CR92293).

Workaround

To ensure that the snmpd agent references the WebAccelerator-specific MIB file, you can create a symbolic link in the /usr/share/snmp/mibs directory that points to the WebAccelerator-specific MIB file. To do so, type the following command:

ln -s /usr/local/wa/mib/wa.mib /usr/share/snmp/mibs

If you type the following snmpwalk command, the system will provide meaningful object identifiers by name for the WebAccelerator-specific objects:

snmpwalk -v 2c -c public localhost:12406 .1.3.6.1.4.1.3375.14.1

The snmpwalk command now provides output that appears similar to the following example:

WA::startTime.0 = STRING: "Mon, 17 Mar 2008 19:25:14 GMT"
WA::buildVer.0 = STRING: "101707_213034_build04_Release"
WA::buildLatestLoc.0 = ""
WA::buildLatestGlob.0 = ""
WA::configVer.0 = STRING: "9.4"
WA::logLevel.0 = Wrong Type (should be INTEGER): Gauge32: 3

Note: The BIG-IP WebAccelerator system processes use SNMP ports 12400 and 12406. For information about the SNMP ports used to monitor the BIG-IP WebAccelerator, refer to the Administrator Guide for the BIG-IP WebAccelerator System.
