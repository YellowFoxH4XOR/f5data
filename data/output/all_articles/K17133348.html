Known Issue

The BIG-IP APM apd process may exit while processing certain Tool Command Language (Tcl) string operations.

This issue occurs when the following condition is met:

  • You have configured your access policy to use certain Tcl commands, such as clock format or encoding, in Tcl expressions.

For example, you may view this issue when you have configured the Endpoint Security (Server-Side) Time Date action with a Tcl expression that contains code similar to the following example:

[clock format [mcget {session.user.starttime}] -format %u]

Impact

Users are unable to complete the access policy while the apd process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The access policy fails to complete when accessed or is unavailable.
  • The system generates an apd core file to the /shared/core directory.
  • The system generates a SIGSEGV fault to the /var/log/apm file.
