Description

After upgrading to version 17.1.1.4 bd will be restarting constantly and the device will remain offline. The bigip can produce a core file and bd.log contains entries such as the ones below.

BD_MISC|ERR |Nov 20 14:23:29.614|21078|temp_func.c:1070|g_customer_uuid overflow
BD_MISC|ERR |Nov 20 14:23:29.618|21078|temp_func.c:2295|CONFIG_TYPE_PROTOBUF_FILENAMES message had parsing error: could not parse protobuf message
BD_MISC|ERR |Nov 20 14:23:29.618|21078|table_funcs.cpp:2734|CONFIG_TYPE_PROTOBUF_FILENAMES message had errors in block_index: 90. status=-1
BD_MISC|ERR |Nov 20 14:23:29.630|21078|temp_func.c:2288|CONFIG_TYPE_MANIFEST message had parsing error: could not parse protobuf message
BD_MISC|NOTICE|Nov 20 14:23:30.197|21005|signals.c:0047|Received (null) - terminating

Environment

  • Upgrade to version 17.1.1.4

Cause

A possible cause for this behavior can be bug ID1346461.

Recommended Actions

Open a case to verify if the issue is indeed related to ID1346461. If so, this has been fixed in version 17.1.2. It is recommended to upgrade to this version instead.
