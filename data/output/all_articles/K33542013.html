Description

SAML Authentication is not working properly when user has installed CheckPoint SandBlast Agent.
User is authenticated to OKTA Portal
Clicks in the portal on the App that is deployed behind F5
User is correctly redirected from the portal to the APP URL
User sees F5 error page "Logged out successfully"

Environment

  • APM
  • CheckPoint SandBlast Agent
  • SAML
  • OKTA

Cause

CheckPoint SandBlast plugin tries to scan the URL /my.policy and thus a redirect back to OKTA is not working.

Recommended Actions

Refer to CheckPoint documentation or contact CheckPoint Support to exempt URL scanning for specific URL /my.policy

None
