K7830: Added partial session ID to System Logs user logon messages

Issue

Prior to FirePass 6.0.1 with cumulative hotfix HF-601-5, session ID information was not included in user logon messages on the Reports: System Logs page.

For example:

Jul 20 13:34:35 security [john@Default] User john logged on from 192.168.0.131

The new behavior is to include the last five digits of the user?s session ID in the user logon message.

For example:

Jul 20 13:36:50 security [john@Default] User john logged on from 192.168.0.131 Sid = 7496f

F5 Product Development tracked this enhancement as CR83332 and it is included starting in FirePass 6.0.2. For information about upgrading, refer to the FirePass Release Notes.

Additionally, cumulative hotfix HF-601-5 has been issued for FirePass 6.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
