Description

After a tenant memory allocation change, MCPD could not start and the tenant became inaccessible. Loading the BIG-IP configuration failed with 01020036:3: The requested user (f5hubblelcdadmin) was not found.

Environment

  • BIG-IP LTM
  • The BIG-IP configuration contained references to the internal user f5hubblelcdadmin

Cause

ID2386673

The configuration load failure was traced to references for f5hubblelcdadmin in /config/bigip_user.conf and related BIG-IP authentication configuration files.

BIG-IP reported that the requested user did not exist while validating the configuration.

Answer/Recommended Actions

Edit the configuration file "config/bigip_user.conf" and comment out the part for "f5hubblelcdadmin"

i.e.:

#auth user f5hubblelcdadmin {
#  description f5hubblelcdadmin
#  encrypted-password none
#  partition-access {
#    all-partitions {
#      role admin
#    }
#  }
#  session-limit -1
#  shell none
#}

Then try to load the config again:

tmsh load sys config
