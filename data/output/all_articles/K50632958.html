Description

When you try to delete an SSL certificate that is being used by an HTTPs monitor, you will find the following message
  
"01070265:3: The Certificate File (/<Partition>/<certificate name>.crt) cannot be deleted because it is in use by a SSL certificate monitor parameter (/<Partition>/<HTTPs Monitor name> CERT=)."

Environment

  • You have configured a Cert and Key on an HTTPS monitor using the configuration utility on version before 13.1.0
  • Currently you are running a version after 13.1.0

Cause

From version 13.1.0, as The BIG-IP LTM migrated the  HTTPS monitor SSL configuration to an SSL profile. During upgrade process new server SSL profile will be created based on the SSL attributes of the monitors. So now the feature Cert and Key are deprecated and cannot be modified on the Configuration Utility.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Create a UCS backup of the  BIG-IP LTM device 
  2. Change partition to /< Partition Name>  if required 
    #cd /< Partition Name>
  3. Clear the SSL cert configuration in tmsh
    #tmsh modify ltm monitor https < HTTPS Monitor name> cert none
  4. Clear the Key config 
    #tmsh modify ltm monitor https < HTTPS Monitor name> key none
  5. Save config 
    # tmsh save sys config
  6. Then try to remove the SSL certificate from GUI
