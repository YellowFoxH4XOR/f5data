Issue

Error Message

[WARN][<date>][<task and iControl REST worker>] unable to refresh current config: java.lang.IllegalStateException: Failed to start task on <BIG-IP hostname>: java.lang.IllegalStateException: An active configuration request is in progress for device <device URI>. This request cannot be processed until the active request completes. Please try again in a few minutes.

In this error message, note the following:

  • <date> is time and date the error occurred.
  • <task and iControl REST worker> is the relative URI of the task and the name of the iControl REST worker.
  • <BIG-IP hostname> is the hostname of the target BIG-IP device.
  • <device URI> shows the device ID or machine ID that represents the target BIG-IP where the configuration task is running.

For example:

[WARN][10 May 2018 12:44:34 UTC][/cm/device/dsc-group-task DSCGroupTaskCollectionWorker] unable to refresh current config: java.lang.IllegalStateException: Failed to start task on bigip.example.com: java.lang.IllegalStateException: An active configuration request is in progress for device https://localhost/mgmt/cm/system/machineid-resolver/f9da3138-63d9-4f89-8b16-19a139183c15. This request cannot be processed until the active request completes. Please try again in a few minutes."

Message Location

You may encounter this message in the following locations:

  • /var/log/restjavad.0.log
  • The BIG-IQ user interface

Description

This message occurs when the following conditions is met:

  • An active request is in progress on the target BIG-IP system when an attempt to refresh the current config is made.

Impact

You must wait until the active request completes.

Recommended Actions

If the error message persists for an extended period of time and you are unable to run other tasks, it may mean that the task on the affected BIG-IP has stalled. You can restore task functionality by restarting restjavad on the affected BIG-IP system. To do so perform the following procedure:

Impact of procedure: The iControl REST service on the BIG-IP system is briefly interrupted during the restart. F5 recommends performing this procedure during a maintenance window.

  1. Log in to the TMOS shell (tmsh) of the affected BIG-IP by typing the following command:

    tmsh

  2. Restart restjavad by typing the following command:

    restart /sys service restjavad
