Topic

The FirePass Client API does not support Windows Mobile devices. However, the FirePass SSL VPN client for Windows Mobile 5 and 6 devices is fully integrated with Microsoft Connection Manager. If you want to develop a customized SSL VPN client for Windows Mobile devices, use the Connection Manager API.

For information about developing applications with the Microsoft Connection Manager API, refer to the following sites. The following links will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

  • http://msdn.microsoft.com/en-us/library/bb416435.aspx
  • http://msdn.microsoft.com/en-us/library/aa458955.aspx
  • http://blogs.msdn.com/windowsmobile/

Note: For information about the FirePass Client API, refer to K7615: FirePass Client API.
