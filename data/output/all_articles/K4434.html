K4434: Reasons why the 3dpipe command may run very slowly

Topic

The 3dpipe command uses BIG-IP API calls to the local CORBA provider to obtain configuration information and apply changes. Old self IP address records may remain in the configuration database after you change the self IP addresses for the system. When this occurs, 3-DNS attempts to use those records to communicate when it makes API calls.

To remove old self IP addresses from the database entries and restore the 3dpipe performance, perform the following steps:

  1. Log in to the command line.
  2. Display the self IP addresses that are currently associated with the CORBA provider, by typing the following command:

    bigpipe db get Local.Bigip.CORBA.Port

    You should receive a list of database keys, similar to the following:

    Common.Bigip.CORBA.Port.172.16.22.11 = "683"
Common.Bigip.CORBA.Port.172.16.22.13 = "683"
Common.Bigip.CORBA.Port.10.10.96.1 = "683"
  3. Remove the database keys that include a self IP address that is no longer configured on 3-DNS, using the following command syntax:

    bigpipe db unset Common.Bigip.CORBA.Port.<IP Address>

    For example:

    bigpipe db unset Common.Bigip.CORBA.Port.10.10.96.1
