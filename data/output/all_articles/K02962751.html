K02962751: Connecting to NTP sources in AWS

Description
Outbound connectivity to external Network Time Protocol (NTP) resources in Amazon Web Services (AWS) requires the opening of UDP 123 in the Security Group.

Environment

  • Amazon Web Services (AWS)
  • NTP
  • BIG-IP / BIG-IQ VE
     

Cause

NTP uses UDP port 123 which is not open by default in AWS security groups.
 

Recommended Actions

  1. Utilize AWS internal NTP service of 169.254.169.123
    or
    Allow UDP port 123 inbound to the BIG-IP instance security group.
     
  2. Force sync with the NTP server: K78084428: How to force ntp sync to a specific NTP server
