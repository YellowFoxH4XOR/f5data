Description

You vulnerability scanner has detected that the BIG-IP GUI (Configuration Terminal) is using ssl-anon-ciphers and ssl-null-ciphers cipher suites.

This article explains how to disable ssl-anon-ciphers and ssl-null-ciphers cipher suites on BIG-IP Configuration Terminal.

Environment

  • BIG-IP
  • Disable ssl-anon-ciphers and ssl-null-ciphers cipher suites on BIG-IP Configuration Terminal

Cause

None.

Recommended Actions

  • To remove ssl-anon-ciphers, you will need to add !aNULL in the httpd configuration
  • To remove ssl-null-ciphers, you will need to add !eNULL in the httpd configuration
  1. Log in to tmsh by typing the following command:

    tmsh

  2. To list the currently configured SSL ciphers, type the following command:

    list /sys httpd ssl-ciphersuite

    For example, the BIG-IP 14.1.0 system displays the following ciphers:

    ssl-ciphersuite ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES128-SHA:ECDHE-RSA-AES256-SHA:ECDHE-RSA-AES128-SHA256:ECDHE-RSA-AES256-SHA384:ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES128-SHA:ECDHE-ECDSA-AES256-SHA:ECDHE-ECDSA-AES128-SHA256:ECDHE-ECDSA-AES256-SHA384:AES128-GCM-SHA256:AES256-GCM-SHA384:AES128-SHA:AES256-SHA:AES128-SHA256:AES256-SHA256

  3. You will now need to add the following code to the existing SSL cipher suites to remove ssl-anon-ciphers and ssl-null-ciphers.
    :!eNULL:!aNULL
     
  4. To change the SSL ciphers allowed in Configuration utility, type the following command:

    modify /sys httpd ssl-ciphersuite "<allowed ciphers>"

    For example:

    modify /sys httpd ssl-ciphersuite "ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES128-SHA:ECDHE-RSA-AES256-SHA:ECDHE-RSA-AES128-SHA256:ECDHE-RSA-AES256-SHA384:ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES128-SHA:ECDHE-ECDSA-AES256-SHA:ECDHE-ECDSA-AES128-SHA256:ECDHE-ECDSA-AES256-SHA384:AES128-GCM-SHA256:AES256-GCM-SHA384:AES128-SHA:AES256-SHA:AES128-SHA256:AES256-SHA256:!eNULL:!aNULL"

  5. Save the configuration change by typing the following command:

    save /sys config
