Known Issue

A virtual server with a FastL4 profile behaves differently when the BIG-IP AFM system is provisioned.

This issue occurs when all of the following conditions are met:

  • You have a virtual server configured with a FastL4 profile.
  • The FastL4 profile has Loose Init enabled.
  • You have provisioned the BIG-IP AFM system.

Impact

The system drops reset (RST) packets that do not relate to any existing flows, but the system should not drop the packets if you have enabled Loose Init.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • If you have provisioned the BIG-IP AFM system, a FastL4 virtual server with Loose Init enabled drops all RST packets that do not relate to any existing flows.
