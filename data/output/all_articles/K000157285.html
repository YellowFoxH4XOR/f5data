Source

Description

  • Every hour there is burst of below log message in /var/log/ltm. 
    01010029:5: Clock advanced by <milliseconds> ticks
  • You do not observe high CPU utilization.
  • No performance or production impact observed.

Environment

  • BIG-IP

Cause

Bug ID 1306249

Recommended Actions

The clock advanced tick message happening every hour is expected as part of ID1306249. Logs can be ignored if there is no service impact.

Additional Information

The fixed version in Bug ID 1306249 means that this tmm.ssl.useffdhe db variable available in those fixed version to toggle the settings with. Meaning if you want to disable tmm.ssl.useffdhe you can do that in fixed version. In affected version you would require an EHF to disable tmm.ssl.useffdhe.
