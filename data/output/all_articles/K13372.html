Issue

Error Message

04010568:3: Error found on device <IP address> (UID: <device ID>): Data collection connection failed.

In this error message, note the following:

  • <IP address> is the IP address of the BIG-IP system managed by the affected Enterprise Manager.
  • <device ID> is the unique internal identification number assigned to the device by the affected Enterprise Manager.

For example:

04010568:3: Error found on device 172.28.71.15 (UID: 4): Data collection connection failed.

Message Location

You may encounter this message in the following location:

  • The /var/log/em file

Description

This message occurs when all of the following conditions are met:

  • You attempt to install a newer version of the big3d Data Collection Agent to the target BIG-IP system.
  • The target BIG-IP system is running BIG-IP 10.1.0 and later.

When the Enterprise Manager has a newer version of the big3d agent than the target BIG-IP system, you need to upgrade the big3d agent on the target BIG-IP system for the Statistics Data Collection feature to function properly. Depending on the Enterprise Manager version, you can complete the upgrade automatically or manually through the Data Collection Agent Installation wizard.

Beginning with BIG-IP 10.1.0, the /usr directory is mounted as read-only. This change prevents the big3d agent from installing into the /usr/sbin directory on the target BIG-IP system. Newer versions of the big3d agent will be installed in the /shared/bin directory. If the big3d agent upgrade through the Data Collection Agent Installation wizard repeatedly fails from the Enterprise Manager, you must manually install the big3d agent through the Enterprise Manager command line. The manual upgrade procedure for the big3d agent is described in the Recommended Actions section.

Impact

The Statistics Data Collection feature will not function properly for the affected target BIG-IP systems.

Recommended Actions

To properly install the big3d agent to the target BIG-IP system, perform the following procedure:

Impact of procedure: If the target BIG-IP system is part of a network for which the BIG-IP GTM is managing traffic, the BIG-IP GTM may temporarily mark the target BIG-IP system offline during the big3d_install. If the target BIG-IP system is a BIG-IP GTM, that system may temporary mark all GTM objects down during the big3d_install.

  1. Log in to the command line of the Enterprise Manager.
  2. Install the big3d agent to the target BIG-IP system by typing the following command:

    big3d_install <IP address>

    For example, to install the big3d agent to the target BIG-IP system with an IP address 172.26.149.14, you would type the following:

    big3d_install 172.26.149.14

    Note: You may be prompted for the credentials of the root user account on the target BIG-IP system.

  3. Log in to the command line of the target BIG-IP system.
  4. Find the version of the big3d agent on the target BIG-IP system by typing the following command on the target BIG-IP system:

    /shared/bin/big3d -v

  5. Find the version of the big3d agent on the Enterprise Manager by typing the following command on the Enterprise Manager:

    Enterprise Manager 2.0.0 and later

    /shared/bin/big3d -v

    Enterprise Manager 1.8.0

    /usr/sbin/big3d -v

  6. Compare and verify that the big3d agent versions are the same on both the target BIG-IP system and the Enterprise Manager. Repeat Step 2 if the versions are not the same.
  7. Rediscover the target BIG-IP system. For details about Enterprise Manager 1.7.0 through 2.2.0, refer to the Discovering devices section in the Enterprise Manager Administrator Guide. For details about Enterprise Manager 2.3.0, refer to the Discovering BIG-IP devices section in the Enterprise Manager Getting Started Guide.
