Description
BIG-IP AFM Logging properties is not easily translated from the configured option to the tmctl statistics output. This article describes how to translate these properties.

Environment

  • BIG-IP AFM
  • Network Firewall Logging Configured

Cause
None

Recommended Actions

One-Liner
tmctl fw_logthrottle_stat -c| awk 'BEGIN {OFS=FS=",";logtype[1] = "acl-match-accept";logtype[2] = "acl-match-reject";logtype[3] = "acl-match-drop";logtype[4] = "ip-errors";logtype[5] = "tcp-errors";logtype[6] = "tcp-events";logtype[7] = "aggregate-rate"};{if ($1 ~ "global-network") {sub($4, logtype[$4], $4);print} else {print}}' | column -t -s,

Pretty Printed
tmctl fw_logthrottle_stat -c| awk '
BEGIN {
  OFS=FS=","
  logtype[1] = "acl-match-accept"
  logtype[2] = "acl-match-reject"
  logtype[3] = "acl-match-drop"
  logtype[4] = "ip-errors"
  logtype[5] = "tcp-errors"
  logtype[6] = "tcp-events"
  logtype[7] = "aggregate-rate"
}
{
  if ($1 ~ "global-network") {
    sub($4, logtype[$4], $4)
    print
  }
  else {
    print
  }
}
' | column -t -s,
