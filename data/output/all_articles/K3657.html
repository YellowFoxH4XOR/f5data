K3657: The ''memAvailReal'' OID reports more available memory than the ''vmstat'' command does

Known Issue

This is the result of a known issue. The amount of available memory that the memAvailReal OID reports is slightly higher than the actual amount of available memory. The difference between what the memAvailReal OID reports and the real value is not predictable, but it is a small percentage.

The amount of available memory reported by the vmstat command is accurate.

F5 Networks Product Development tracked this problem as CR33921 and CR41919.
