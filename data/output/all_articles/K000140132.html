Topic

This article describes the multiple methods to determine the serial number of a power supply unit (PSU) for a BIG-IP iSeries or F5 rSeries hardware product. The serial number of a PSU is necessary whenever you request a replacement PSU from F5.

Description

You can determine the serial number of a PSU for a BIG-IP iSeries or F5 rSeries hardware product using the following methods:

  • Physical product label
  • QKView uploaded to F5 iHealth
  • tmsh utility / webUI / Command Line

Physical product label

You should use this method if you have already pulled out the non-functioning PSU from the BIG-IP iSeries or F5 rSeries hardware product. On the top side of every PSU, there is a product label that includes the model, part number and serial number. The serial number is usually listed as S/N on the label. QKView uploaded to F5 iHealth

You can generate a QKView file from your BIG-IP iSeries or F5 rSeries hardware product and upload it to F5 iHealth. For information about generating a QKView file from your BIG-IP iSeries or F5 rSeries hardware product and uploading it to F5 iHealth, refer to the following articles appropriate for your hardware product:

  • BIG-IP iSeries: K12878: Generating diagnostic data using the qkview utility
  • F5 rSeries: K04756153: Generating diagnostic data for rSeries systems using the qkview utility

Perform the following procedure appropriate for your hardware product to determine the serial number of the PSU using the QKView file uploaded to F5 iHealth:

  • BIG-IP iSeries
  • F5 rSeries

BIG-IP iSeries

  1. Log into the F5 iHealth portal.
  2. Select the QKView you have uploaded for your BIG-IP iSeries hardware product.
  3. Select Commands.
     
  4. Select tmsh.
     
  5. Select sys.
     
  6. Select show /sys hardware.
     

    This should bring up a new window displaying the output collected for this command.

  7. Check the status of the PSUs from the Chassis Power Supply Status section.
     
  8. Scroll down and locate the psu1 and psu2 under the Hardware Version Information section. You should observe a Serial Number row for each PSU. If there is no PSU in that slot, the Serial Number row would be displayed as N/A.
     

F5 rSeries

  1. Log into the F5 iHealth portal.
  2. Select the QKView you have uploaded for your F5 rSeries hardware product.
  3. Select Commands > Standard.
     
  4. Select system_manager > system_manager - /confd/scripts/f5_confd_run_cmd show components. This should bring up a new window displaying the output collected for this command.
     
  5. Scroll down and locate components component psu-1 and components component psu-2 sections. You should observe a state serial-no row for each PSU. If there is no PSU in that slot, the state serial-no row would be displayed as Not Available.
     

tmsh utility / webUI / Command Line

If the PSU and your BIG-IP iSeries / F5 rSeries hardware product are both still functional, you can login to the tmsh utility of the BIG-IP iSeries hardware product or the webUI / command line (CLI) of the F5 rSeries hardware product to determine the serial number of the PSU. To do so, perform the procedure appropriate for your hardware product:

  • BIG-IP iSeries
  • F5 rSeries

BIG-IP iSeries

  1. Login to the tmsh utility of the BIG-IP iSeries as the admin user.
  2. To display the hardware information of the BIG-IP iSeries, enter the following command:

    show /sys hardware

  3. Locate the psu1 and psu2 under the Hardware Version Information section. You should observe a Serial Number row for each PSU. If there is no PSU in that slot, the Serial Number row would be displayed as N/A.

F5 rSeries

webUI

  1. Login to the webUI of the F5 rSeries as the admin user.
  2. Select SYSTEM SETTINGS > General.
  3. Under the System Inventory section, locate the Serial Number column for the Power Supply Unit 1 and/or Power Supply Unit 2 component.

CLI

  1. Login to the CLI of the F5 rSeries as the admin user.
  2. To display the PSU information of the F5 rSeries, enter the following command:

    show components component psu-*

  3. The serial number for each PSU is located in the state serial-no row.
