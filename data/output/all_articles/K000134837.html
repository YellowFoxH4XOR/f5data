K000134837: Subscription based add-on license does not add additional vCPU.

Type
Support Solution
Published
2023-05-30
Updated
2024-11-19
Applies to
  • Private Cloud
  • Public Cloud
  • Amazon Web Services
  • F5 Ready Cloud Partners
  • Google Cloud
  • Alibaba Cloud
  • Microsoft Azure
Source
https://my.f5.com/manage/s/article/K000134837

Description

VE Subscription add-on License does not add vCPU. This is true for all core based term subscription add-ons regardless of the environment, Azure, AWS, on premise, etc.

Environment

  • VE core based term subscription license
  • Azure, AWS, on premise

Cause

The VE core based term subscription add-ons will not add vCPUs.
This is an expected behavior.

Recommended Actions

The only way to achieve 16 vCPUs in this case would be to start with 16 vCPUs subscription license: F5-LTM-16-PRM-SUB.

Additional Information

The behavior described in this article does not apply to Version Plus perpetual core based SKUs as well as add-ons for throughput based SKUs.
