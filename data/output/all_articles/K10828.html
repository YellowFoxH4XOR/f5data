Known Issue

This is the result of a known issue. When the Ignore no-cache HTTP headers in the response setting is disabled on the images leafnode in the Sharepoint 2003 policy, requests for documents matching the following description will fail to load and clients will receive authentication prompts for documents requiring NTLM authentication:

  • PDF documents that are returned based on multiple range requests
  • Images that are returned using conditional GET requests

From the client perspective, the failures appear as multiple 401 (Unauthorized) responses that cause an NTLM authentication prompt. In addition, when the reauthentication prompt takes place four times in a row, the client browser may hang.

F5 Product Development tracked this issue as CR130725 and it was fixed in BIG-IP WebAccelerator version 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.

Additionally, this issue was fixed in Hotfix-BIGIP-10.0.1-378.0-HF3 issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
