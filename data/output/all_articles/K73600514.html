Known Issue

The statistical data of the Network DoS reports may not be correctly migrated after an upgrade.

This issue occurs when all of the following conditions are met:

  • The BIG-IP AFM system is running on either one of the following software versions:
     
    • 11.5.x or with any of the hotfix branches
    • 11.4.x or with any of the hotfix branches
  • The BIG-IP AFM system has Network DoS reports that contain statistical data about Client-IP addresses.
  • You have upgraded to BIG-IP 11.6.0 or 12.0.0.

Impact

There may be loss of statistical data about the Client-IP address in the newly upgraded software slot.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The statistical data about the Client-IP address existed in the previous software slot before you performed the upgrade.
  • After the software upgrade, the system does not correctly migrate the Network DoS report statistics to the new software slot, and this may lead to the loss of statistical data about the Client-IP addresses.
