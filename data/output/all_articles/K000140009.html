Description

Add an irule to a virtual server irule list using the command line without overwriting the current irule list

 

Environment

  • BIG-IP LTM
  • iRules
  • Virtual Server
  • Command line

Cause

For example, when using the command `tmsh modify ltm virtual vs_https rules { my_irule}` it will overwrite the irule list with the new irule 'my-irule'

Recommended Actions

1.Access the BIG-IP system with command-line utility.

 

2. List the current iRule list using the following command, see below an example output:

tmsh list ltm virtual one-line | sed -n -e 's/.*rules { \(.*\) } .*/\1/p'

_sys_https_redirect http_ok_response_irule

 

3.Copy the output irule list of the previous step and add the new irule to the current irule list of the virtual server by using the command `tmsh modify ltm virtual <virtual server name> rules { }`, in this example you can copy the output of the previous step and add the irule list to the command, see below:

 

tmsh modify ltm virtual vs_https rules { my_rule _sys_https_redirect http_ok_response_irule}
