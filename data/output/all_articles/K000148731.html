Description

  • The Delegated Domain (DD) feature automatically creates the DNS record for an HTTP Load Balancer as soon as an F5 Distributed Cloud (F5XC) customer creates the HTTP Load Balancer.
  • DD was introduced when F5XC lacked an integrated Authoritative DNS solution. This solution has since been added with F5 Distributed Cloud DNS.
  • We disabled DD in December 2023, giving customers advance notice to request and control the timing of their migration.
  • Now, it's time to migrate the remaining customers and domains! We plan to complete this migration in March, 2025. 

Environment

  • F5® Distributed Cloud
  • F5® Distributed Cloud DNS

Answer / Recommended Actions

What you (the customer) need to do

If your Delegated Domains were not using DNSSEC: 

This migration is transparent, and you do not need to take any further actions. 

The Name Servers (NS) that Delegated Domains used were: 

  • ns1.volterradns.io
  • ns2.volterradns.io
  • ns3.volterradns.io
  • ns4.volterradns.io 

The Name Servers that F5 Distributed Cloud DNS uses are: 

  • ns1.f5clouddns.com
  • ns2.f5clouddns.com 

We will be changing the glue records for ns[1-4].volterradns.io and pointing them to the IP addresses for ns[1-2].f5clouddns.com 

If your Delegated Domains were using DNSSEC: 

  • You will have to disable DNSSEC before the migration.  

To do this, please complete the following: 

  1. Remove the DS record in the parent zone,
  2. Disable DNSSEC in the Delegated Domain migration 

  • You will need to reenable DNSSEC after the migration is complete. 

To do this, please complete the following: 

  1. Enable DNSSEC in the Primary DNS zone,
  2. Copy the DS record in the parent zone. 

 The Name Servers changes are the same as described above.
