Description

BIG-IP Remote Authentication (Active Directory / LDAP /ClientCert LDAP) has been configured to use LDAPS. When the SSL setting is "Enabled", the authentication works. But, when set to Start TLS, it doesn't work.

Environment

BIG-IP Remote Authentication (Active Directory / LDAP / ClientCert LDAP )

Cause

Authentication is configured with the SSL settings as "Start TLS"

"Start TLS" / STARTTLS will make the initial connection over plaintext communication. Then, the client uses the STARTTLS command to signal to the server that it wants to use SSL/TLS.

If the configuration of your Active Directory / LDAP server does not allow STARTTLS method, the authentication will fail.

Recommended Actions

Use the SSL option "Enabled", instead of STARTTLS, in the BIG-IP's Active Directory / LDAP settings.
