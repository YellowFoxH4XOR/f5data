K8883: Configuring a pre-logon sequence that restricts access based on the client browser's SSL cipher

Topic

On the Device Management : Security : User Access Security page, you can configure low-grade, medium-grade, or high-grade levels of security for the SSL Cipher Security setting. The group of SSL ciphers allowed for each grade is predefined, and you cannot add or remove individual ciphers to or from these security levels.

Note: For a list of SSL ciphers permitted by each cipher security level, refer to K3795: Overview of SSL Cipher Security levels.

If you want to deny access to an SSL cipher that is permitted by your configured cipher security level, you can configure a pre-logon sequence to direct client browsers using that cipher to the Logon Denied page. To do so, perform the following procedure:
 
Important: You cannot configure a pre-logon sequence to allow SSL ciphers that are not permitted by the configured cipher security level. Users cannot access the pre-logon sequence page if their browser is using a cipher that is not permitted by the configured cipher security level. To add additional security ciphers, you must configure a lower level of cipher security and then use the procedure below to deny access to all unwanted SSL ciphers.
 
  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users : Endpoint Security : Pre-Logon Sequence page.
  3. In the Create new sequence field, enter the name of the pre-logon sequence.

    Note: If you have an existing pre-logon sequence, you may edit that pre-logon sequence instead of configuring a new one.
     
  4. In the Based on menu, select template : Empty.
  5. To create the pre-logon sequence, click the Create button.
  6. Click the edit link next to the name of the pre-logon sequence you just created.
  7. Mouse over the line to the right of the Sequence Start box.

    A plus ( + ) icon appears.
  8. Click the plus icon.
  9. The Change Sequence screen appears on the right.
  10. In the Change Sequence screen, select New Action from the Using menu.
  11. Click the Apply Changes button.

    The Edit Action screen appears.
  12. In the Edit Action screen, enter a name for the action in the Name field.

    For example:

    Cipher Check
     
  13. Optionally, enter a description for the action in the Description field.
  14. Click the Update details button.
  15. Click the Close panel link in the top right of the Edit Action screen.
  16. Mouse over the line to the right of the action you just created.

    A plus ( + ) icon appears.
  17. Click the plus icon.

    The Insert Rule screen appears.
  18. In the Insert Rule screen, enter a name for the rule in the Name field.

    For example:

    Deny Unwanted Ciphers
  19. In the text field under the Name field, enter a list of cipher using the following format:

    Note: In the following example, <CIPHER1>, <CIPHER2>, and <CIPHER3> are the names of the SSL ciphers you want to deny.

    session.ssl.cipher=="<CIPHER1>" OR
    session.ssl.cipher=="<CIPHER2>" OR
    session.ssl.cipher=="<CIPHER3>"

    For example:

    session.ssl.cipher=="AECDH-DES-CBC-SHA" OR
    session.ssl.cipher=="ECDH-RSA-DES-CBC-SHA" OR
    session.ssl.cipher=="ECDH-ECDSA-DES-CBC-SHA" OR
    session.ssl.cipher=="ADH-DES-CBC-SHA" OR
    session.ssl.cipher=="EDH-RSA-DES-CBC-SHA" OR
    session.ssl.cipher=="EDH-DSS-DES-CBC-SHA" OR
    session.ssl.cipher=="DES-CBC-SHA" OR
    session.ssl.cipher=="RC4-6" OR
    session.ssl.cipher=="4-MD5" OR
    session.ssl.cipher=="DES-CBC-MD5"
     
  20. Click the Insert Rule button.
  21. Click the Back to console link at the top right corner of the page.
  22. In the Select Sequence to Use section of the page, select the option button to the left of the pre-logon sequence you just configured.
  23. To apply the pre-logon sequence, click the Apply button.
 
If a user accesses the FirePass controller, and the user's browser is using a cipher you configured in Step 19, FirePass redirects the user to the Logon Denied page.
