Topic

You may receive the following gettyd message in the /var/log/messages file:
 

Sep 20 19:19:12 xxxxxxxx gettyd[43]: select fails: Invalid argument

Correcting the system date

You will receive these gettyd messages if your system date is off by an excessive number of years. For example, if your system date is set to 1933, it will cause the gettyd process to become unstable and log repeated errors into the /var/log/messages file.

To verify that an incorrect date is the reason for these errors, view the system date by typing the following command:

date

Correct the time and date as required. For specific instructions about how to do this, refer to K597: Setting the time and date on a BIG-IP or 3-DNS Controller.

Correcting the /etc/ttys file

If the tty00 or tty0d entries within the /etc/ttys file are configured to use on secure rather than in secure, it can cause getty to spawn quickly and cause errors.

To correct this, perform the following steps:

  1. Open the /etc/ttys file.

  2. Edit the file as follows, specific to the version you are running.

    For BIG-IP versions 1.8.3 through 4.6.4 and all 3-DNS versions other than versions 3.0 through 4.0.2, edit the file as follows:

    Change the following line:

    tty00 "/usr/libexec/getty pccons" vt100 in secure

    To read:

    tty00 "/usr/libexec/getty pccons" vt100 on secure

    For 3-DNS versions 3.0 through 4.0.2, edit the file as follows:

    Change the following line:

    ttyd0 "/usr/libexec/getty std.9600" vt100 in secure

    To read:

    ttyd0 "/usr/libexec/getty std.9600" vt100 on secure

  3. Save and close the /etc/ttys file.

  4. Type the following command:

    kill -HUP 1
