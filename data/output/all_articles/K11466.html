Known Issue

This is the result of a known issue. When a snapshot is deleted, corruption may occur in an internal ARX database that contains snapshot information. When this issue occurs, an error message that appears similar to the following is logged to the ARX syslog file:

:VCIFS-1-WARN-DBSELECT:: Error while selecting PolicyUserRecord entries from database: Key not found.

As a result of the database corruption, the Previous Versions tab will be missing and clients will be unable to browse the remaining snapshots in the ~snapshots folder.

F5 Product Development tracked this issue as ID 38493 and it was fixed in ARX version 5.2.0. For information about upgrading, refer to the ARX release notes.

This issue has been fixed in ARX version 5.1.5 Build-11969 (Hotfix 2). You may download this version or later versions from the F5 Downloads site.

Additionally, this issue has been fixed in hotfix 5.0.6 HF8 available for ARX versions 5.0.6. To request this hotfix, contact F5 Technical Support and reference this Solution and ID number.

Workaround

To allow snapshots in the ~snapshot folder to be visible again, and the Previous Versions tab to reappear, you must manually correct the internal ARX database. Customers affected by this issue should contact F5 Technical Support for assistance and reference this Solution and ID number.
