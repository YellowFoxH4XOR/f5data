K000133671: AS3 FQDN Pool_Members do not auto populate properly

Description

AS3 FQDN Pool_Members do not auto populate properly when deleting an existing AS3 deployment.

Nodes that are created under the /Common partition will remain if deleting the AS3 declaration. (DELETE https://{bigIP mgmt IP address}/mgmt/shared/appsvcs/declare)

When POST'ing a subsequent AS3 declaration, the nodes under /Common changes from Auto Populate Enable to Auto Populate Disabled.

 

BigIP WEBUI

Local Traffic ›› Pools : Pool List ›› demo_pool : Members : <Select each member>

FQDN

Auto Populate Disabled

 

Environment

AS3

FQDN node

 

Cause

This behavior is associated to "shareNodes": true (where the nodes are created under /Common Tenant). These nodes are *not* removed if you DELETE the AS3 declaration. (DELETE https://{bigIP mgmt IP address}/mgmt/shared/appsvcs/declare)

 

 

Recommended Actions

Workaround: delete the nodes under /Common/Shared when necessary.

 

Additional Information

ID1269421.

 

This issue *does not* occur if the sharesNodes is set to False.

 

example AS3 Pool declaration using FQDN nodes with shareNodes set to true.
