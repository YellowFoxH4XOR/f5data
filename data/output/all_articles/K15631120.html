Description

  • When using Linux commands to delete a user through the CLI it appears as if the user is deleted, but when going into the GUI the user is still present.
Example: 
[F5_Big-IP] ~ # userdel administrator
userdel: user administrator is currently used by process 1 -
 
The user was force deleted, using the following syntax command:
[F5_Big-IP] ~ # date; echo "remove administrator "; userdel --force administrator
Fri Oct 20 10:21:16 PDT 2017 remove administrator userdel: user administrator is currently used by process 1
When using the following command syntax it seemed like the user had been deleted as no output was returned:
[F5_Big-IP] ~ # grep ^administrator: /etc/passwd
[F5_Big-IP] ~ #
  • The user will continue to be present in the GUI.

Environment

  • Linux commands using CLI.

Cause

Even if userdel is the correct command to delete a user, this is redhat / centos linux command with F5 software written on top of it. To be able to delete the user F5 commands have to be used to delete a user instead of the linux commands.

Recommended Actions

Impact of procedure: Restarting the BIG-IP system disrupts traffic processing until the system is back up.

1. If the Linux commands were used to force delete the user the system has to be rebooted. 
2. Log in to the Advanced Shell (bash).
3. To restart the BIG-IP system, enter the following command:
reboot
4. Log in to tmsh as an administrator by entering the following command:
tmsh
5. Use the following command syntax to delete the user:
delete auth user administrator
6. Save the  configuration changes in all administrative partitions:
tmsh save sys config
7.Verify the user has been deleted with the following command syntax:
grep administrator /etc/passwd
