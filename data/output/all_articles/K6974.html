Known Issue

This is the result of a known issue. The BIG-IP LTM X509::extensions iRule command is used to return the X509 extensions set on a specified X509 certificate. The BIG-IP LTM X509::extensions iRule command does not parse the Microsoft Universal Principal Name (UPN) from SSL certificates.

F5 Product Development tracked this issue as CR72445 and it was fixed in BIG-IP LTM versions 9.3 and 9.4.1. For information about upgrading, refer to the BIG-IP LTM release notes.
