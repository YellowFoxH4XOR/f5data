Issue

warning tmm[<PID>]: 01200015:4: Warning, ICMP error limit reached

In this error message, note the following:

  • <PID> is the process ID for the Traffic Management Microkernel (TMM) process.

For example:

warning tmm2[18868]: 01200015:4: Warning, ICMP error limit reached

Message Location

You may encounter this message in the following location:

  • The /var/log/tmm file

Description

This message occurs when the following condition is met:

  • Your BIG-IP system encounters excessive Internet Control Message Protocol (ICMP) traffic.

The BIG-IP system triggers a warning message when the threshold value configured in the database variable tm.maxicmprate is reached. The default value for the tm.maxicmprate database key is 100 Pkts/Sec.

The tm.maxicmprate database key specifies a general rate limit applied to ICMP error messages coming from servers back through the BIG-IP LTM system to the clients. Each ICMP event must be associated with an established connection flow.

For example, if a virtual server receives traffic on a port where there is no listener configured, then the BIG-IP system system generates an ICMP Destination unreachable (Type 3, Code 3) response, or if the virtual server connection generates ICMP unreachable response from the pool member, the BIG-IP LTM system passes the ICMP responses back to the clients. In both scenarios, the system continues to generate the response until the number of ICMP messages reaches the value specified by the tm.maxicmprate database key. After the number of ICMP error messages reaches the value specified by the tm.maxicmprate database key, the BIG-IP system enforces the rate limit.

Impact

Excessive ICMP traffic may be an indication of distributed denial-of-service (DDoS) attacks. You should investigate further to determine the cause of excessive ICMP traffic.

Recommended Actions

  • You can use command line utilities to monitor TMM statistics. For more information, refer to K10191: Troubleshooting packet drops.
  • To detect and mitigate DDoS attacks, refer to K14813: Detecting and mitigating DoS/DDoS attacks (11.4.x - 16.x) and K7301: Protecting the BIG-IP system against denial-of-service attacks (9.x - 11.3.x).
