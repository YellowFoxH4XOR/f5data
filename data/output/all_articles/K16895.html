Known Issue

Attempting to initiate an access session using a bookmarked URI may fail.

This issue occurs when all of the following conditions are met:

  • You have an established BIG-IP APM access session.
  • You bookmark a URI of a destination resource that was rewritten by the access session.
  • After termination of the access session, you attempt to start a new session using the saved bookmark.

Impact

You cannot access the bookmarked location.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to initiate an access session using the bookmark, the system redirects the request to the BIG-IP APM logout page.
