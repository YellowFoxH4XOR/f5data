Description

You may find the following error message in /var/log/kern.log :

For example :

err kernel: Buffer I/O error on dev loop0, logical block 0, async page read

 

Environment

 

・BIG-IP

 

Cause

 

/dev/loop0 is only used to mount loopback devices, such as an ISO.
It should  not indicate any problems with the hardware in any way.

Recommended Actions

 

None

 

Additional Information

 

None
