Source

Description

Unable to license BIG-IP Next instance via CM when there is no network connectivity to license server

 

Environment

  • BIG-IP Next CM
  • No Internet Access

Cause

BIG-IP Next CM is unable to reach license server

Recommended Actions

Use Disconnected Mode procedure to license BIG-IP Next instances

 

 

Additional Information

License server domain: product.apis.f5.com
