Topic

This article applies to VIPRION platforms running BIG-IP 11.x and later. For information about other versions, refer to the following article:

  • K10621: Setting the serial console baud rate on a VIPRION system (9.6.x - 10.x)

You should consider using this procedure under the following condition:

  • You want to change the serial console baud rate on a VIPRION platform.

Description

The default serial console baud rate on VIPRION platforms is 19200. F5 recommends that you set the baud rate on the connecting serial terminal to match the BIG-IP serial console port baud rate, rather than modify the VIPRION serial port configuration. However, if you cannot modify the connecting serial terminal settings, you can set the serial console baud rate on a VIPRION system by performing the procedure in this article.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have console access to the VIPRION system.

Procedures

Modifying the serial console baud rate on a VIPRION system

  1. Connect to the serial console port of the primary blade of the VIPRION cluster using a serial terminal and a null modem cable.

    Note: The Primary LED is illuminated on the chassis to indicate which blade is currently the cluster primary.

  2. To change the baud rate for the blade, use the following syntax, replacing <baud> with the desired baud rate:

    tmsh modify /sys console baud-rate <baud>

    For example:

    tmsh modify /sys console baud-rate 9600

  3. To change the baud rate in the system hardware, access the console port menu by simultaneously pressing the ESC+Shift+9 keys.

    A command menu similar to the following displays:

    B --- Set baud rate
    C --- Capture blade console
    I --- Display platform information
    P --- Power on/off blade
    R --- Reset blade
    Q --- Quit menu and return to console

  4. Select the Set baud rate option from the menu.
  5. Set the console port baud rate to the same value that you configured in step 2.

    Note: When the new baud rate is accepted, your current console connection using the old baud rate drops.

  6. Change the baud rate on your serial terminal to match the newly configured baud rate.
  7. Re-establish the serial connection to the blade.
  8. To exit the console port menu, press Q.
  9. To save the configuration, type the following command:

    tmsh save /sys config

  10. To reboot the blade, type the following command:

    reboot

    Note: Rebooting the blade forces the system to promote a new primary blade.

  11. Repeat the procedure on the newly promoted primary blade until you have reconfigured all blades in the cluster.
