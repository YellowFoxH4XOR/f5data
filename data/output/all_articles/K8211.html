Topic

Beginning in FirePass version 6.0.2, you can use two new session variables to verify the Microsoft hotfixes (also referred to as updates or KBs) installed on a Windows client machine. The %session.win_info.hotfixes.hf_list% session variable contains a list of system hotfixes installed on the client machine, and the %session.ie_info.hotfixes.hf_list% session variable contains a list of Internet Explorer hotfixes installed on the client system. In order to access these variables, you must use the Extended Windows and IE info pre-logon inspector in your pre-logon sequence.

Configuring a new pre-logon sequence

To configure a new pre-logon sequence that writes the information contained in the %session.win_info.hotfixes.hf_list% and %session.ie_info.hotfixes.hf_list% variables to the FirePass logon log, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users: Endpoint Security: Pre-Logon Sequence page.
  3. In the Create new sequence field, enter the name for the new pre-logon sequence.
  4. In the Based on menu, select template: Empty.
  5. Click the Create button.
  6. In the Select Sequence to Use section of the page, click the edit link next to the pre-logon sequence you just created.

    The Pre-Logon Sequence Editor opens.
  7. Roll your mouse over the line next to Sequence Start.

    A plus sign (+) character appears on the line.
  8. Click the plus sign character.

    The Change Sequence panel appears.
  9. In the Change Sequence panel, select the Extended Windows and IE info button.
  10. Click the Apply Changes button.
  11. In the sequence, roll your mouse over the line, to the right of the Extended Windows and IE info button.

    A plus sign character appears on the line.
  12. Click the plus sign character.

    The Change Sequence panel appears.
  13. In the Change Sequence panel, select the Write to Logon log button.
  14. Click the Apply Changes button.

    The Edit Action panel appears.
  15. In the Edit Action panel, click the Logger link.

    The Endpoint Inspector Details panel appears.
  16. In the Expression field, enter the variable name and text you want displayed in the logon log.

    For example:

    Windows System KBs detected: %session.win_info.hotfixes.hf_list%
    Internet Explorer KBs detected: %session.ie_info.hotfixes.hf_list%

  17. Click the Update button.
  18. At the top right corner of the page, click the Back to console link.

    This link returns you to the Users: Endpoint Security: Pre-Logon Sequence page.
  19. Select the button next to the pre-logon sequence you created in Step 5.
  20. Click the Apply button.

The pre-logon sequence you created is now active. When a Windows client logs on to the FirePass controller, navigate to the Reports: Logons page and click the user's logon name.
