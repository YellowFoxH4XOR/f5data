Issue

Error Message

err zrd[PID]: 01150b21:3: RCODE returned from query: 'NOTAUTH'

In this error message, note the following:

  • [PID] is the process ID of the ZoneRunner daemon.

Message Location

You may encounter this message in the following locations:

  • The /var/log/gtm file

Description

This message occurs when all of the following conditions are met:

  • You configure a ZoneRunner zone list that contains a zone with a Zone Type of Forward.
  • On the Resource Record List page, you use All to search for the affected zone.

Each time the system performs a resource record query for a Forward type zone, the ZoneRunner daemon prints two errors in the /var/log/dns (BIG-IP 12.x and later) or /var/log/gtm (BIG-IP 11.x) file. The error message does not indicate a failure; it indicates that the named process is not authoritative for the Forward domain you are querying.

Impact

This error message does not have a negative impact on your BIG-IP system.
