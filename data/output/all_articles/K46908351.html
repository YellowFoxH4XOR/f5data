Description


Under the DOS profile Application Security ›› Bot Signatures ›› Bot Signature Check the warning message is displayed:

  • This feature will not be fully operational since the DNS Resolver List is empty. To add one, navigate to Network  »  DNS Resolvers : DNS Resolver List.

The warning message does not describe that the DNS Resolver should be configured in the default route domain.

Environment

  • BIG-IP ASM
  • DOS profile

Cause


Bot profile requires a DNS resolver to fully operate. The DNS resolver needs to be configured the default route domain.

Recommended Actions

Configure a DNS resolver in the default route domain under section Network  »  DNS Resolvers : DNS Resolver List.
