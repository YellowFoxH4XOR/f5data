Known Issue

This is the result of a known issue. When the Enterprise Manager discovers a device that has a Kerberos profile configured, the device is marked as impaired. The device status, located on the Configuration utility Device screen, reports the following error message:

get change control info: iControl error: 'iControl::OperationFailed - primary code:2(0x2) secondary code: 0(0x0) string: BIGpipe parsing error: 012e0008:3: The requested command (<Kerberos profile name> list) is invalid'

F5 Product Development tracked this issue as CR132150, and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WAN Optimization, or Edge Gateway Release Notes.

Additionally, this issue was fixed in Hotfix-BIGIP-9.4.8-379.3-HF1 issued for BIG-IP version 9.4.8 and in Hotfix-BIGIP-10.1.0-3372.0-HF1 issued for BIG-IP version 10.1.0. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

For information about downloading software, refer to K167: Downloading software and firmware from F5.

For information about how to manage F5 product hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
