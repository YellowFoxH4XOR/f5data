Known Issue

This is the result of a known issue. The BIG-IP GTM Configuration utility allows you to create a server object with a name containing a trailing space. However, if you attempt to modify a virtual server resource for that server object, the action fails and the Configuration utility reports an mcpd error message indicating that the server does not exist.

For example, if you create a Generic host server on the BIG-IP GTM and the name contains a trailing space, such as Namewithtrailingspace, and you attempt to modify a virtual server resource for the server, the Configuration utility reports the following error message:

01070222:3: VS test server Namewithtrailingspace does not exist

In addition, an mcpd error message is logged to the /var/log/ltm file:

mcpd[1732]: 01070222:3: VS test server namewithtrailingspace does not exist

Note: Creating a server object with a name that includes a space character between the first and last characters works as expected.

For example:

Works

"ServerWithSpace InTheMiddle"
  -------------^

Does not work

"ServerWithSpaceAtTheEnd "
         --------------^

F5 Product Development tracked this issue as ID 337824, and it was fixed in BIG-IP 11.4.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Workaround

Do not create any objects on the BIG-IP GTM system with a name that includes a trailing space character. If you created a server object with a name that contains a trailing space and you are unable to modify the object, delete and recreate the server object.
