K7553: LDAP authentication fails when LDAP Server Signing is enabled on an Active Directory LDAP server

Known Issue

This is the result of a known issue. LDAP Server Signing is a security setting that reduces the risk of man-in-the-middle (MITM) attacks. FirePass does not currently support LDAP Server Signing. Therefore, if you enable LDAP Server Signing on an Active Directory LDAP server, FirePass cannot bind to the LDAP service over an unencrypted connection. For more information about LDAP Server Signing and compatibility issues, refer to the following Microsoft Knowledge Base article:

Client, service, and program incompatibilities that may occur when you modify security settings and user rights assignments

F5 Product Development is tracking this issue as ID 359483.

Workaround

You can work around this issue by either disabling LDAP Server Signing on your Windows Active Directory LDAP server or enabling FirePass to use LDAP over Secure Sockets Layer (SSL).

To disable LDAP Server Signing, refer to the documentation for your LDAP server.

To enable FirePass to use LDAP over SSL, perform the following procedure:

  1. Navigate to the Users: Groups: Master Groups page.

  2. Select the Master Group that uses LDAP authentication.

  3. Click the Authentication tab.

  4. Next to Port, enter 636.

  5. Select the Use SSL connection check box.

  6. Click Save Settings.

  7. If Lookup user's DN using template is selected, no further configuration is necessary. If Lookup user's DN using query is not selected, proceed with the following steps.

  8. Next to Password, enter the password for your LDAP user DN.

  9. Next to Confirm Password, enter the same password.

  10. Click Save Settings.
