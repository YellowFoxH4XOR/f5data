Description

The following article outlines how to statically publish SAML metadata on the APM webtop.

Environment

  • BIG-IP APM
  • APM webtop available
  • SAML configured as SP or IdP
  • iRule and iFiles

Cause

Currently the BIG-IP does not support publishing IdP and SP metadata xml via publicly accessible URI / URL

Recommended Actions

The workaround would be to download the metadata file, upload it to the BIG-IP iFiles hosted files, then this file can be referenced in a response iRule when queried.

  1. You will need to export the Metadata from the BIG-IP that you would like to use.
  • IdP will be used for this example
  • Access  ››  Federation : SAML Identity Provider : Local IdP Services
    Note: For version 11.x and 12.x SAML can be found here - Access Policy  ››  SAML : BIG-IP as IdP
  • Click on the IdP you would like the Metadata to be hosted and click Export Metadata
  1. Import the metadata into the iFiles List:
  • Local Traffic  ››  iRules : iFile List  ››  Click on Create
  • Next to File Name click the + button to add a new file
  • Click on Choose File and choose the metadata file
  • Name the file and click on Import
  • Choose the metadata File from the list and Name the iFile, for example idp_metadata
  1. Create an iRule that references and can respond with this metadata:
  • Local Traffic  ››  iRules : iRule List  ››  Click Create
  • Name the iRule idp_metadata_irule
  • Add in the following iRule

    when HTTP_REQUEST {
        if {[string tolower [HTTP::uri]] contains "metadata.xml"}{
            set metadata [ifile get "/Common/idp_metadata"]
        HTTP::respond 200 content $metadata
            unset metadata
        }
    }
  1. Apply the idp_metadata_irule to the IdP Virtual Server
  • Local Traffic  ››  Virtual Servers : Virtual Server List  ››  example_idp_vs
  • Click on Resources
  • Under iRules  ››  Click Manage
  • Move the idp_metadata_irule from the Available column and into the Enabled
  1. When there is a call to the URL that contains metadata.xml, it will respond with the published XML metadata 
    Example: https://idp.example.com/metadata.xml
