K9462: The OSPF protocol fails to form adjacencies if port lockdown restricts IP protocol 89

Topic

When configuring a BIG-IP system for participation in dynamic routing with the Open Shortest Path First (OSPF) protocol, the self IP addresses on VLANs for which the BIG-IP system should participate in OSPF routing must allow IP protocol 89.

OSPF Hello messages use multicast destinations for which installation of the Advanced Routing Module creates a special multicast listener in the TMM. This listener accepts the multicast OSPF Hello packets that initiate the OSPF neighbor discovery process. However, the resulting unicast database descriptor response packets are subject to port lockdown restrictions, and if IP protocol 89 (OSPF) is not allowed, these responses will not be seen by the BIG-IP LTM, and at this point, the OSPF primary and secondary negotiation stalls.

In order to support the complete OSPF handshake and negotiation process, you must configure each self IP address to allow IP protocol 89. To do so, perform one of the following procedures for each self IP address that participates in OSPF negotiations:

BIG-IP LTM 9.4.5 and later

BIG-IP LTM versions 9.4.5 and later include OSPF in the Allow Default protocol list. To apply the Allow Default list to the self IP address, perform the following procedure:

  1. Log in to the BIG-IP LTM Configuration Utility
  2. Click Network.
  3. Click self IPs.
  4. Select Allow Default from the Port Lockdown drop-down box.
  5. Click Update.

BIG-IP LTM prior to 9.4.5

For BIG-IP LTM versions prior to 9.4.5, you may need to apply a custom port lockdown definition. To create a custom protocol list for the self IP address, perform the following procedure:

  1. Log in to the BIG-IP LTM Configuration Utility.
  2. Click Network.
  3. Click self IPs.
  4. Select Allow Custom from the Port Lockdown drop-down box.
  5. Click the option button next to Protocol.
  6. Select OSPF from the drop-down menu.
  7. Click Add.

    If updating an existing custom port lockdown list, skip to step 9.
  8. If creating a new custom port lockdown list, add an appropriate set of protocol and port combinations for your environment.

    Note: F5 recommends using the default port lockdown list as a basis for custom port lockdown configurations, modifying the list as necessary to match your requirements. For more information, refer to K7317: Overview of port lockdown behavior which details the protocols that are enabled when the Allow Default port lockdown option is selected.
  9. Click Update to save the completed protocol list.

    Repeat this procedure until all self IP addresses used in OSPF negotiations have been updated with the required port lockdown settings.
