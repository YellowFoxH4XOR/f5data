K62738186: Setting IP exception to ''Always Block'', we lose ability to select ''Never Log Traffic''

Type
Support Solution
Published
2022-07-21
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K62738186

Description

When creating an IP Address Exception, if you select to always block this IP, the line item to "Never log traffic from this IP address" is not available to select.

Environment

Relevant environmental factors specific to the topic

  • Conditions
  • Configuration objects and settings
  • Products and features

Cause

If the "IP is blacklisted" item (Under Security  ››  Application Security : Policy Building : Learning and Blocking Settings : IP Addresses and Geolocations) is set to Block and/or Alarm, the BIG-IP ASM will log a violation when a request comes from an IP address that falls in the range of an IP address exception marked for "always blocking", that is, the black list of IPs.

Recommended Actions

As an alternative, the event log page has enhanced filter options to filter out unwanted blocked requests.
