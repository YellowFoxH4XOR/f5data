Known Issue

This is the result of a known issue. When using a FirePass Portal Access favorite to access Citrix published resources, only one resource can be launched. Attempts to launch more than one resource from the Citrix portal will fail silently. This issue only affects FirePass 6.0.1 with cumulative hotfix HF-601-6.

F5 Product Development tracked this issue as CR86148 and it was fixed in FirePass 6.0.2. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue is fixed in cumulative hotfix HF-601-7 issued for FirePass version 6.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
