Topic

In BIG-IP ASM 9.4.0 through 9.4.1 only, you can disable or enable application security on all virtual servers by using a bigdb variable.

Disabling application security on virtual servers

To disable application security on all virtual servers, type the following command from the BIG-IP ASM command line:

b db ASM.Bypass enable

Requests to all virtual servers will now bypass the BIG-IP ASM, and be routed according to the virtual server configuration.

Enabling application security on all virtual servers

To enable application security on all virtual servers, type the following command from the BIG-IP ASM command line:

b db ASM.Bypass disable

Note: For information about disabling and enabling application security on all virtual servers for BIG-IP ASM 9.4.2 and later, refer to K9063: Disabling and enabling application security on all virtual servers.

Note: For information about disabling and enabling application security on all virtual servers for BIG-IP ASM 9.2.3 through 9.2.5, refer to K5889: Disabling and enabling application security on all virtual servers.
