Known Issue

The BIG-IP AAM system may respond with duplicate response headers when certain request headers are used.

This issue occurs when all of the following conditions are met:

  • BIG-IP AAM is configured on a virtual server.
  • An HTTP client is using the Accept-Encoding: identity request header.

Impact

Client HTTP requests may time out.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP AAM system responds with duplicate and conflicting Content-Length: headers.
  • One of the duplicate Content-Length: headers is correct and the other header has an incorrect value.
