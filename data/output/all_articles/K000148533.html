Topic

You should consider using this procedure under the following condition:

  • You want to use an iRule to block HTTP requests with unwanted hosts in the HTTP Host header.

To do this with a local traffic policy instead refer to K42113232: Use the LTM to resolve Host Header Injection vulnerability

To block requests with unwanted User-Agents refer to K31914583: Blocking HTTP requests with unwanted User-Agent header using an iRule

Description

The HTTP Host header contains the hostname or IP address of the server where the request is being sent. You can create an iRule to block hosts that are not on your allowed list.

You can use the following key commands to build the iRule:

  • The [HTTP::host] command returns the host string from the client-request HTTP Host header.
  • The equals operator verifies if the host matches an item on the allowed list.
  • The reject command resets connections with unwanted hosts.
  • The class match command searches lists of strings in a data group.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP Configuration utility.
  • You have a virtual server configured with an HTTP profile.

Procedures

Creating a data group containing a list of allowed hosts

To create a data group containing a list of allowed hosts, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules > Data Group List.
  3. Click Create.
  4. For Name, type a name for the data group.
  5. For Type, click String.
  6. Under Records, for String, type an allowed host and leave Value blank.

    For example, to include a specific host in your allowed list, for String, enter:

    myhost.example.com

  7. Click Add.
  8. Repeat steps 6 and 7 as needed to add more hosts in the data group.
  9. Click Finished.

Creating an iRule to block HTTP requests with unwanted hosts

To create an iRule that blocks client HTTP requests containing unwanted hosts in the request header, perform the following procedure:

Impact of procedure: The impact of the suggested procedure depends on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules > iRule List.
  3. Click Create.
  4. For Name, type a name for the iRule.
  5. For Definition, enter the host blocking iRule.

    For example, the following iRule blocks requests from clients that have a Host header containing a host that is not listed in the data group named allowed_hosts:

    when HTTP_REQUEST {
      if {!([class match [HTTP::host] equals allowed_hosts])}{
        reject
      }
    }

  6. Click Finished.
  7. Associate the iRule with the virtual server.
