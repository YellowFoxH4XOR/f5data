Description

  • Basic BIG-IP health monitor tools appear inadequate to create required health monitor.
  • Need a monitor that can accept a range HTTP response codes or something else custom.


Environment

  • BIG-IP
  • Need to create a monitor and lacking the necessary levers in BIG-IP to create the needed monitor.


Cause

Common monitor types through the BIG-IP are not able to offer the customizability that is needed; but a custom external monitor may be able to do this.


Recommended Actions

Create a custom curl monitor by following the steps in this article:

K31435017: Steps to create custom curl monitor
