Known Issue

Emails generated by the BIG-IP system may fail after upgrading to 13.0.0.

This issue occurs when all of the following conditions are met:

  • You perform an upgrade to BIG-IP 13.0.0.
  • You configure your BIG-IP system to deliver locally generated email messages using one of the following articles:
    • K15288: Sending an advance email alert for impending SSL certificate expiration
    • K13180: Configuring the BIG-IP system to deliver locally-generated email messages (11.x - 13.x)

Impact

Email notifications generated by the BIG-IP system do not reach the intended recipient.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system generates emails with no domain name in the email's From: line.
  • Error messages exist in the outbound SMTP server's mail logs that appear similar to the following example:

    postfix/smtpd[12345]: warning: Illegal address syntax from unknown[192.168.10.100] in MAIL command: <root@>

  • The rewrite-domain option is set to none when running the following example TMOS Shell (tmsh) command:

    tmsh list /sys outbound-smtp rewrite-domain | grep -i none
        rewrite-domain none

  • Email notifications generated by your BIG-IP system do not reach the intended recipient.

Workaround

To work around this issue, you can configure the rewrite-domain setting of the SSMTP configuration with the hostname of the BIG-IP system. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To determine the fully-qualified domain name (FQDN) of the BIG-IP system, type the following command:

    list sys global-settings hostname

    The command output shows ltm1.example.com is the FQDN of the BIG-IP system:

    sys global-settings {
        hostname ltm1.example.com
    }

  3. To configure the mail client to connect to an external SMTP server using the BIG-IP system's FQDN, use the following command syntax:

    modify sys outbound-smtp mailhub <mail_server>:<port> rewrite-domain <fqdn>

    For example, to configure the system to send email messages to host mail.mydomain.com using port 587 from fqdn ltm1.example.com, you would type the following command:

    modify sys outbound-smtp mailhub mail.mydomain.com:587 rewrite-domain ltm1.example.com

  4. To save the configuration, type the following command:

    save sys config
