Description

In the Configuration Utility or WebUI when navigating to the Access >> Guided Configuration page an "Access forbidden!  You don't have permission to access the requested object.  Error 403" error message is shown.
 

Environment

BIG-IP APM version 14.x or later
 

Cause

Unknown at this time
 

Recommended Actions

These steps will clear out all of the Guided Configuration files and reset to the base version that was installed in the original version.  If you were using a later version you will need to upgrade again.

Steps from the CLI (bash):

# bigstart stop restnoded restjavad
# clear-rest-storage

After running these commands wait at least 5 minutes or more for everything to be cleanly removed.

Then go to GUI: Access ->  Guided Configuration, it will auto re-install the base version package

This procedure has not been known to impact traffic but you may wish to perform these steps at a low usage or maintenance window just to be safe.
