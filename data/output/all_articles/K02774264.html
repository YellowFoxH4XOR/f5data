Known Issue

The BIG-IP DNS system (formerly known as BIG-IP GTM) does not include an OPT record in responses to DNS queries it receives that contain OPT records. This is in violation of RFC 6891.

This issue occurs when the following condition is met:

  • DNS queries to the BIG-IP DNS system include an RFC 6891-compliant OPT record.

Impact

A resolver that does not see an OPT might interpret this as a lack of support and might send duplicate TCP requests.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP DNS system does not include an OPT record in responses to DNS queries it receives that contain OPT records.
