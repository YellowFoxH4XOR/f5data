Known Issue

The system may not accurately reflect applied node connection rate limiting in statistics.

This issue occurs when all of the following conditions are met:

  • You configure the node level connection Rate Limit on an available, enabled node.
  • Traffic for the node exceeds the Rate Limit allowed connections-per-second setting.
  • You view connection reset statistics using the Traffic Management Shell (tmsh) or the tmctl command.

Impact

The system does not proportionally increment statistic information for Rate Limit.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you view the output of the tmsh utility, the counter for Rate Limit does not increment proportionally to the number of rate limited connections; however, other rst-cause counters increment when rate limiting is applied.

    The following are affected rst-cause counters:

    • No pool member available
    • Rate limit
    • Unknown reason
    • Precision failed
    • Session lookup failed
