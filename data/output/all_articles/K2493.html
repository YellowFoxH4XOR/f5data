Topic

You can configure a virtual server to allow all ports by using the any (or wildcard) virtual port.

To allow all ports through a virtual server, perform the following steps:

  1. Enable the any port by typing the following command:

    bigpipe service any tcp enable

  2. If you need to pass UDP traffic through the wildcard port, you must enable both the UDP and a UDP persistence timer by typing the following commands (in this example, the timer is set for 30 seconds):

    bigpipe service any udp enable

    bigpipe service any timeout udp 30

  3. Create a virtual server that will pass all ports for the virtual address, by typing the following command (replacing the IP addresses in the example with the applicable IP addresses for your configuration):
     bigpipe virtual 10.10.10.10:any use pool wildcard_pool translate port disable

    Note: You must disable port translation so that each service coming through the VIP will retain its original destination port.

    Now traffic destined for the virtual address using any TCP or UDP port will be load balanced through the virtual to the defined nodes.
