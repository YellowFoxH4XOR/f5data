Issue

Error Message

010713c2:5: No new proposal values detected

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • The mcpd process receives and processes a message to update either the settings for the administrative network settings or cluster floating interface, such as the IP address, gateway address, or host name.
  • The message contains no new or changed information.

Impact

No changes are made and the settings retain their current values.

Recommended Actions

If a change was intended, you can verify the information provided in the given update method with the current settings to ensure the values are correct.
