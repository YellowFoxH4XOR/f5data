Description

After replace the hard disk, see the error log in the /var/log/ltm:

err statsd[<PID>]: 011b020a:3: Error 'No such device' reading file '/sys/block/sdb/stat'
err statsd[<PID>]: 011b0900:3: TMSTAT error max disk stat: read failed.
err chmand[<PID>]: 012a0003:3: Physical disk HD2 not found for logical disk delete
And then see the error log repeatedly every 5 seconds in the /var/log/ltm:
err statsd[<PID>]: 011b0203:3: Error 'No such file or directory' opening file /sys/block/sdb/stat
err statsd[<PID>]: 011b0900:3: TMSTAT error max disk stat: read failed.

Environment

  • 6900
  • BIGIP 11.5.4
  • Replace one harddisk

Cause

Stop sdb failed, and the new disk is identified as sdc, so the system cannot find '/sys/block/sdb/stat'
