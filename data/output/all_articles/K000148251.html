K000148251: RDS server thrown "CallOutput on empty outputSink"

Type
Support Solution
Published
2024-11-26
Updated
2024-11-26
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148251

Description

 

RDP disconnect suddenly with the following error messages:

 

Jan 01 00:00:00 bigip.example.local err vdi[16221]: 019cffff:3: /Common/APM_Profile:Common:d07a7bb1: {227.C} CallOutput on empty outputSink.

Jan 01 00:00:00 bigip.example.local err vdi[16221]: 019cffff:3/Common/APM_Profile:Common:d07a7bb1: {1e5.S} An exception is thrown (TMEVT_INGRESS): Invalid connection context.

 

Environment

 

  • BIG-IP APM v17.X
  • MS Remote Desktop Service environment

 

Cause

 

It can be by connection refused thrown on server due to a failure on some software installed:

 

vdi[16221]: 019cffff:5: (null)::d07a7bb1: {231.S} Failed to connect to RDG target rds.example.local:3389: system:111: Connection refused

 

 Recommended Actions

 

Make sure the RDS server is working properly and no additional or third-party software is affecting the RDS service.
