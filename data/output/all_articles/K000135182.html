K000135182: System Memory and/or Storage stats are missing from the GUI and CLI

Type
Support Solution
Published
2023-06-22
Updated
2023-06-22
Applies to
  • F5OS
  • F5OS-C: 1.5.X, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000135182

Description

When F5OS-C is being upgraded, and when OpenShift is being reinstalled the controller stats on GUI and management CLI show default values (or no values).
 

Environment

  • F5OS-C
 

Cause

This is expected behavior.

 

Recommended Actions

Wait for the F5OS upgrade or OpenShift reinstallation to complete prior to attempting to view statistics.
 

Additional Information

None
