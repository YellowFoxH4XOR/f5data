Description

When using a Fast HTTP (Performance) virtual server type, the AVR TCP-analytics is not reporting any statistics.

Environment

  • BIG-IP AVR
  • Fast HTTP (Performance) Virtual Server
  • tcp-analytics profile

Cause

The tcp { } profile is added to Standard Virtual Servers but it is missing in the Fast-HTTP virtual server type and can't be added by design.
The tcp-analytics profile menu item for Fast-HTTP virtual servers is an LTM design error.

Recommended Actions

Use a different virtual server type if TCP statistics required (Fast-HTTP is extremely limited).

Additional Information

None.
