K000132810: DNS Express not initiating Zone Transfer after receiving DNS Notify

Type
Support Solution
Published
2023-03-02
Updated
2023-03-02
Applies to
  • BIG-IP
  • BIG-IP DNS: 16.1.3
Source
https://my.f5.com/manage/s/article/K000132810

Description

DNS Express not initiating Zone Transfer after receiving DNS Notify


Environment

  • BIG-IP DNS
  • DNS Express


Cause

Verify Notify TSIG option is enabled (by default) in the DNS Express zone and waits for the TSIG key to be sent from the Authoritative DNS Server

Recommended Actions

Disable the Verify Notify TSIG option on the DNS zone. With this configuration, DNS Express can process a NOTIFY message without a TSIG key, even when a subsequent zone transfer requires a TSIG key.
