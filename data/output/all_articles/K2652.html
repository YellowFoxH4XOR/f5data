Topic

ICMP is an Internet communications protocol used to determine information about routes to destination addresses, such as virtual servers managed by BIG-IP and 3-DNS Controllers. There are two ways to allow ICMP to pass through the BIG-IP.

  • The first, more desirable, alternative is to enable any_IP on a virtual server or SNAT and allow the passing of non-TCP and non-UDP packets, such as ICMP, through the virtual server or SNAT.
  • The second, less desirable, alternative is to enable IP forwarding and allow the BIG-IP to pass all traffic. This has the disadvantage of allowing any packets through as well and making the back end servers completely visible.

Important: This solution is appropriate for virtual servers that are configured as part of a network. Virtual servers that configured to be in a standalone /32 network will not function as described in this solution. Do not use a /32 netmask on a forwarding virtual server if the intention is to forward traffic.

When you create a forwarding virtual server to forward traffic to another IP address, use the netmask for that IP address. If the destination IP address has a /32 netmask, the forwarding virtual server must be configured with an alternative netmask, such as a /24 or another relevant netmask.

Enabling any_ip on a virtual server

To enable any_ip on a virtual server, type the following two commands:

b virtual <ip> any_ip enable
b save

Enabling any_ip through a SNAT

To enable any_ip through a SNAT, type the following commands (specific to the version of BIG-IP you are running):

BIG-IP version 4.5 - 4.6.2

Type the following two commands:

b global snats any_ip enable
b save

Now BIG-IP will allow any non-TCP and non-UDP traffic to pass through the virtual server or SNAT and the addresses will be translated appropriately.

BIG-IP version 4.2

Type the following two commands:

b internal set any_ip_through_snat 1
b save

Now BIG-IP will allow any non-TCP and non-UDP traffic to pass through the virtual server or SNAT and the addresses will be translated appropriately.

Enabling IP forwarding

Warning: Enabling IP forwarding allows all packets through BIG-IP, making the back end servers completely visible. For more information about IP forwarding, refer to the BIG-IP Controller Reference Guide.

You can enable IP forwarding from the command line or the Configuration utility.

Command line

To enable IP forwarding from the command line, type the following command:

b global ipforwarding enable

The change will take effect immediately. To make the change permanent, type the following command:

b save

Configuration utility

To enable IP forwarding from the Configuration utility, perform the following steps:

  1. From the left navigation pane of the Configuration utility, click System.
  2. Click the Advanced Properties tab.
  3. Check the box next to ipforwarding.

    Note: In BIG-IP version 4.2, this box is labeled, Allow IP Forwarding.

  4. Click Apply.
