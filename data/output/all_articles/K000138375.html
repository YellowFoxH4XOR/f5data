K000138375: HD2 is used for datastor and cannot be used for file storage.

Type
Support Solution
Published
2024-01-26
Updated
2024-01-26
Source
https://my.f5.com/manage/s/article/K000138375

Description

When a you view the Disk Management page of the GUI it will show at least 2 drives.

Environment

  • BIG-IP VE

Cause

HD1 is used for file storage. HD2 is used for datastor for the various provisioned modules.

  • Note: HD2 cannot be used for storage of files such as images.

Recommended Actions

  1. If you have run out of space you will need to delete any unused images then install the image.
  2. If the issue is simply the need for additional space then if this is a VE or vCMP guest you can extend that space...
    1. K14952: Extending disk space on BIG-IP VE
    2. K24156414: Increasing the disk space for a BIG-IP vCMP guest
  3. In some situations you can also... K93621640: Extend Virtual Edition filesystem size using an additional HDD
  • NOTE:The second article references snapshots. Snapshots are not recommended to be used on a BIG-IP or BIG-IQ... K000093184: Taking a Snapshot of a BIG-IP VIrtual Edition from a hypervisor (eg. VMware ESX, KVM)
