Known Issue

If you attempt to open an Adobe Acrobat document (PDF) with Adobe Acrobat Reader X in a FirePass Protected Workspace, the PDF document fails to open.

This issue occurs when all of the following conditions are met:

  • The FirePass controller is configured to use the Protected Workspace action in a prelogon sequence.
  • The user is accessing a PDF document.

Impact

Users are unable to access PDF documents.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Users may receive an error message that appears similar to the following:

    To run Acrobat in the Protected Workspace, you must close it in the default desktop.
    If you do, all unsaved changes will be lost.
    Do you want to close Acrobat in the default desktop?

  • Users may receive an error message that appears similar to the following:

    There is a problem with Adobe Acrobat/Reader.
    If it is running, please exit and try again.

  • User's browser may appear to freeze.

Workaround

To work around this issue, you can remove the Protected Workspace action from the active pre-logon sequence. To do so, perform the following procedure:

Impact of workaround: Removing the Protected Workspace action will remove the protective services that PWS provides.

Removing Protected Workspace from FirePass EndPoint Security

  1. Log in to the FirePass Controller Administrator interface.
  2. Navigate to Users : Endpoint Security : Pre-Logon Sequence.
  3. Click backup & edit next to the active pre-logon sequence.
    The Pre-Logon Sequence editor window opens.

    Important: The sequence is active. Every change you make in this page will take effect immediately.

  4. Hover the mouse pointer over the Switch to PWS action. An X appears in the upper right corner of the action.
  5. Click the X.
    The Delete Action pane opens on the right.
  6. From the Delete action, leave branch after: option, select inside PWS.
  7. Click the Delete action button.
  8. Click Back to console.
