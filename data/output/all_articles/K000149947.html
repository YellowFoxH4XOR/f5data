K000149947: Experiencing Traffic Disruption and Subsequent 503 Error after Upgrading NGINX Plus to R33 or above

Type
Support Solution
Published
2025-04-30
Updated
2025-08-16
Applies to
  • NGINX Products
  • NGINX Plus: R35, R34, R33
Source
https://my.f5.com/manage/s/article/K000149947

Description

  • Experiencing 503s after upgrading to NGINX Plus version R33 or above.
  • Starting with NGINX Plus R33, all NGINX Plus instances require a valid JSON Web Token (JWT) license.
  • If NGINX is unable to connect to licesinig server, it will log the below error in its log (/var/log/nginx/error.log file) 
[emerg] 1476#1476: cannot send usage report; traffic processing has been stopped; see https://docs.nginx.com/solutions/about-subscription-licenses

Environment

  • Nginx Plus
  • Upgrade
  • Subscription 

Cause

  • Unable to send the initial report to product.connect.nginx.com caused by firewall rules or the instance being completely isolated 

Recommended Actions

  • Detailed instructions can be found in the Admin guide 

Additional Information

  • This license is tied to your subscription (not individual instances) and is used to validate your subscription and automatically send usage reports to F5’s licensing endpoint (product.connect.nginx.com), as required by your subscription agreement.
    In offline environments, usage reporting is routed through NGINX Instance Manager.
