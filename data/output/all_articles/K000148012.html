K000148012: How can I find out which user created a site?

Published
2024-11-08

Applies to

  • F5 Distributed Cloud
Source

Description

  • I share a tenant with several users
  • I want to be able to determine which user created which site

Environment

  • F5® Distributed Cloud (SaaS)
  • Site Management

Answer/Recommended Actions

Note: You need access to the System namespace for this

On the dashboard

  1. From the F5® Distributed Cloud Console go to System namespace > Manage > Site Management and select the type of site to check (e.g. AWS VPC Sites)
  2. Click on the gear icon on the right side
  3. Under System Metadata click the checkbox for Creator ID 
  4. Click Apply to see the email of the user as part of the dashboard

 

On the site JSON

  1. Go to the Site dashboard of your choice (e.g. AWS VPC Sites), and click on the greater than icon (>) of the site 
  2. Click on the two arrows next to system_metadata and find the email in the value of creator_ID
