Description

It is noticed that tmsh show sys log ltm timestamp is different from the /var/log/ltm timestamp. Refer to the examples below.

[root@ltm-A-example:Active:Standalone] config # tail /var/log/ltm
Mar 11 17:08:21 ltm-A-example.local notice mcpd[5993]: 01070727:5: Pool /Common/pool-https-example member /Common/10.10.10.10:443 monitor status up. [ /Common/monitor-example: up ]  [ was down for 0hr:2mins:52sec ]
Mar 11 17:08:21 ltm-A-example.local notice mcpd[5993]: 01070727:5: Pool /Common/pool-https-example member /Common/10.10.10.202:443 monitor status up. [ /Common/monitor-example: up ]  [ was down for 0hr:2mins:52sec ]
Mar 11 17:08:21 ltm-A-example.local notice mcpd[5993]: 01070727:5: Pool /Common/pool-https-example member /Common/10.10.10.203:443 monitor status up. [ /Common/monitor-example: up ]  [ was down for 0hr:2mins:52sec ]
Mar 11 17:08:21 ltm-A-example.local notice mcpd[5993]: 01070727:5: Pool /Common/pool-https-example member /Common/10.10.10.204:443 monitor status up. [ /Common/monitor-example: up ]  [ was down for 0hr:2mins:52sec ]

[root@ltm-A-example:Active:Standalone] config # tmsh show sys log ltm
ltm 03-11 09:08:21 notice ltm-A-example.local mcpd[5993]: Pool /Common/pool-https-example member /Common/10.10.10.204:443 monitor status up. [ /Common/monitor-example: up ]  [ was down for 0hr:2mins:52sec ]
ltm 03-11 09:08:21 notice ltm-A-example.local mcpd[5993]: Pool /Common/pool-https-example member /Common/10.10.10.203:443 monitor status up. [ /Common/monitor-example: up ]  [ was down for 0hr:2mins:52sec ]
ltm 03-11 09:08:21 notice ltm-A-example.local mcpd[5993]: Pool /Common/pool-https-example member /Common/10.10.10.202:443 monitor status up. [ /Common/monitor-example: up ]  [ was down for 0hr:2mins:52sec ]
ltm 03-11 09:08:21 notice ltm-A-example.local mcpd[5993]: Pool /Common/pool-https-example member /Common/10.10.10.10:443 monitor status up. [ /Common/monitor-example: up ]  [ was down for 0hr:2mins:52sec ]

The /var/log/ltm will show the time according to the Time Zone configured while the tmsh show sys log ltm  will show the UTC time.

Environment

  • BIG-IP
  • Using tmsh show sys log
  • /var/log/ log files
  • Displayed time is different between tmsh and log files.

Cause

This issue is related to ID530530 and ID664735.

Recommended Actions

There is currently no fix to this issue.
The workaround is to use iControl REST API to view the log files with the tmsh output. Refer to K41550738.
