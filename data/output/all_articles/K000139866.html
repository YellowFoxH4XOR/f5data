K000139866: Where to find the license of F5OS-A platforms

Type
Support Solution
Published
2024-07-01
Updated
2025-06-05
Applies to
  • F5OS
  • F5OS-A: 1.5.X, 1.7.X, 1.7.0, 1.5.2, 1.5.1, 1.5.0
Source

Description

You may wish to verify the licensing details for your F5OS-A systems. As a comparison, in the BIG-IP system, you can check licenses using GUI under "System  ››  License",  using the CLI command tmsh show sys license, or check the file under /config/bigip.license . You may want to check the same information on F5OS-A systems.

Environment

  • F5OS-A
  • License information

Cause

None, this is informational

Recommended Actions

You may achieve this purpose by several methods:

  1. Using the F5OS GUI

    Login to the F5OS GUI, in the left navigation tabs, find SYSTEM SETTINGS and click Licensing

  1. Using the ConfD CLI

    Login to the F5OS ConfD CLI, under Operational mode(the default without using config) and enter the below command to show the license.

    show system licensing
  1. Check the license file under the F5OS platform filesystem at /var/system/license/velos.license, for example:
    cat /var/system/license/velos.license

 

Additional Information

If you wish to verify the license the F5OS-A platform passed to your tenant, you may use the below command, this could be helpful for tenant-license-related troubleshooting:

kubectl get secret <tenant-name>-1-secrets -o json | jq '.data.LICENSE' -r  | base64 -d

For example, if you have a tenant named test-tenant:

kubectl get secret test-tenant-1-secrets -o json | jq '.data.LICENSE' -r  | base64 -d
