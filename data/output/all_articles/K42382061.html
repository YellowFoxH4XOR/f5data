Description

You fail to configure the HA failover configuration.

The following error message is seen when adding the Management Address in the Failover Network.
01070920:3: Application error for confpp: Job for f5-firewall.service failed because the control process exited with error code. See "systemctl status f5-firewall.service" and "journalctl -xe" for details.
 

Environment
  • BIG-IP devices
  • Fail to setup HA failover with error message:
    01070920:3: Application error for confpp: Job for f5-firewall.service failed because the control process exited with error code. See "systemctl status f5-firewall.service" and "journalctl -xe" for details.

Cause

Unknown at the time of publication.

Recommended Actions

Doing an MCPD reboot on both devices to resolve the issue.

  1. Login to the Command Line.
  2. Save the current configuration.
    tmsh save sys config
  3. Create a forceload flag.
    touch /service/mcpd/forceload
  4. Reboot the device with command:
    reboot
  5. Repeat the on the peer device.
  6. Proceed to configure the HA failover config by inserting the peer management IP address.
