Description

After failed upgrade, booting into new boot-location system appears to have no configuration

  • System  hostname has changed
  • Users accounts may have disappeared
  • Configuration Utility (GUI) no longer showing previous configuration
  • The command tmsh load sys config partitions all  returns an error

Environment

  • You have booted into new boot-location containing a newer version of software
  • During selection of boot-location you specified to copy configuration from previous version or this option was greyed out

Cause

An incompatibility was detected during load of the configuration files, which prevented this configuration from loading successfully

Recommended Actions

  1. To self-diagnose possible causes, run the following command and search reported issues in the  AskF5 knowledge-base:
    Note: warnings may be ignored

    tmsh load sys config partitions all verify
     
  2. If you were unable to resolve this please send the output of above command, together with a fresh QKview of the system while it is running the upgraded software

    Generate QKview archive as per K12878

Additional Information

After you have collected this data you can boot back into the previous boot-location while F5 Support reviews the data collected
