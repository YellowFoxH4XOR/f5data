Issue

Error Message

0153102a:3: Failed connect callback to <ip_address> for transfer of zone <zone>.

In this error message, note the following:

  • <ip_address> is the IP address of the remote master DNS nameserver.
  • <zone> is the name of the zone attempting to transfer.

For example:

0153102a:3: Failed connect callback to 192.168.10.100 for transfer of zone example.com.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • DNS Express fails to perform a zone transfer from a master DNS nameserver.

Impact

If this is the initial zone transfer, DNS Express does not host the zone. If the zone was successfully transferred previously, DNS Express does not receive updates to the zone. If the zone transfer continues to fail, and the zone expiration time is exceeded, DNS Express stops hosting the zone until the next successful transfer.

Recommended Actions

The failure is most likely due to a network connectivity or network configuration problem. To troubleshoot this issue, perform the following tasks:
  1. Investigate network connectivity between the BIG-IP system and the master DNS nameserver.
  2. Verify the network configuration on all devices, including intermediate switches and firewalls.
  3. Use this log message in conjunction with other ZXFR log messages that should appear to help diagnose the issue.
