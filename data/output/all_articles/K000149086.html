K000149086: DPM binary fails to start, error "Dirty database version 49. Fix and force version."

Type
Support Solution
Published
2024-12-20
Updated
2024-12-20
Applies to
  • NGINX Products
  • NGINX Instance Manager: 2.18.0
Source
https://my.f5.com/manage/s/article/K000149086

Description

The dataplane manager binary (nms-dpm) fails to start causing NIM to become inoperable. The following error message, or similar, occurs in the NMS logs.

<DPM>[11188]: Error: could not run dqlite repo. error: Dirty database version 49. Fix and force version.

Environment

NGINX Instance Manager

Cause

The dpm database is corrupt

Recommended Actions

Clear the dpm database and restart NIM

sudo systemctl stop nms nginx
sudo rm -rf /var/lib/nms/dqlite/dpm
sudo systemctl restart nms nginx
