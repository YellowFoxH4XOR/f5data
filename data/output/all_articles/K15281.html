Topic

Support for the Event Correlation feature on BIG-IP ASM systems that run on Virtual Clustered Multiprocessing (vCMP) guests is dependent on the BIG-IP ASM version and the hardware platform.

Description

Starting in BIG-IP ASM 11.6.0 HF4 and BIG-IP 12.0.0, BIG-IP ASM systems running on vCMP guests on platforms with solid state drives (SSDs) support the Event Correlation feature.

Note: For more information about vCMP platforms with SSDs, refer to K14760: High density vCMP.

Prior to BIG-IP ASM 11.6.0 HF4 and BIG-IP 12.0.0, BIG-IP ASM systems that run on vCMP guests do not support the Event Correlation feature. BIG-IP ASM systems that run on vCMP guests on non-SSD platforms also do not support the Event Correlation feature regardless of the version they are running on. Additionally, in BIG-IP ASM 11.4.0 and later versions, the Configuration utility may report an error similar to the following example when you attempt to navigate to the Event Correlation page:

Event Correlation is not supported on this platform.

The Event Correlation feature is introduced in BIG-IP ASM 11.1.0 to provide an aggregated view of security events in the Configuration utility. When two or more illegal requests are sent to the web application within a short period of time, the system correlates them as a security event. For example, the system aggregates requests into a single event if a single user causes multiple violations over time. You can view security events by navigating to the following page:

BIG-IP ASM 11.3.0 and later

  • Security > Event Logs > Application > Event Correlation

BIG-IP ASM 11.1.0 through 11.2.1

  • Application Security > Reporting > Event Correlation
