Description

You find large numbers of "SSL connection being terminated" messages are present in /var/log/ltm similar to the example below

warning tmm1[<pid>]: 01260020:4: SSL Connection terminated for TCP <IP address>:<port> -> <IP address>:<port>

Environment

  • BIG-IP
  • SSL is enabled and in use
  • One of the following sys db variables is set to TRUE 
    • security.fips140.compliance
    • security.commoncriteria

Cause

Warning messages are being logged due to Bug ID 795345 

These log messages accurately represent SSL state changes on the device, but these messages are intended to be visible only when more detailed logging is enabled on the BIG-IP

Note: See Related Content for more information about ID 795345 

Recommended Actions

These log messages do not indicate an issue on your device and can be safely ignored, but can be filtered out if desired
  1. Navigate to System > Logs > Configuration > Log Filters.
  2. Type a name for the log filter.
  3. In the Severity list, click the severity level that matches the error message that you want the system to filter.
  4. In the Source list, click all.
  5. In the Message ID box enter 01260020 (the 8-hexadecimal-digit message ID that appears in the log message).
  6. In the Log Publisher list, click None.
  7. Click Finished.
Note: See Related Content for more information about configuring log filters

Additional Information

The system reports as 'warning' messages that potentially should be info-level messages. The messages in /var/log/ltm are generated as warnings regardless of an unclean or clean shutdown. The message should be under level 'info' if SSL connection terminates cleanly, and under level 'warning' if SSL connection terminates uncleanly.
