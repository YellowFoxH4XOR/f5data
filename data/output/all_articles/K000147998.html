Description

  • I am trying to use the Alerts API
  • I am getting null as a result
  • I want an API call that matches the System > Notifications > Alerts > Active Alerts page

Environment

  • F5® Distributed Cloud
  • API

Answer/Recommended Actions

You'll need to use the appropriate request as per our API documentation, but this example is for the Alerts to get the alerts matching the filter for the given namespace. 

These instructions assume you already have an API Token to be able to access. If you don't, follow the documentation on Credentials before.

 

1. Find the appropriate request                                                                                                                   

https://www.volterra.io/#operation/ves.io.schema.alert.CustomAPI.Alerts/api/data/namespaces/{namespace}/alerts

2. Adapt it depending on your usage plan

Free or Team plan

 https://console.ves.volterra.io/api/data/namespaces/system/alerts

Organization plan - Replace <tenant> with your own

 https://<tenant>.console.ves.volterra.io/api/data/namespaces/system/alerts

3. Make sure to include the following headers:

  1. Authorization: The value is your API Token
  2. Access-Control-Allow-Origin: Allows any origin access to your resources
  3. X-Volterra-Apigw-Tenant: The value is the name of your tenant

This is what your final request should look like. Don't forget to replace the <tenant> and <APIToken>values

curl --location --request GET 'https://<tenant>.console.ves.volterra.io/api/data/namespaces/system/alerts' \
--header 'Authorization: <APIToken>' \
--header 'Access-Control-Allow-Origin: *' \
--header 'x-volterra-apigw-tenant: <tenant>' \
--header 'Content-Type: text/plain' \
--data-binary '@'

Note: when there are not active alerts, without query params start_time and end_time to specify query range the results are empty and might issue: "data": "null" as output .
