BIG-IP version 4.0 through 4.6.4

To restart the bigd utility on BIG-IP versions 4.0 through 4.6.4, type the following command:

bigstart reinit bigd

BIG-IP version 2.1 through 3.3.1 PTF-06

To restart the bigd utility on BIG-IP versions 2.1 through 3.3.1, type the following command:

bigd
