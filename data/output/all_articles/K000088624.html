K000088624: 403 error while updating NGINX

Type
Support Solution
Published
2021-03-30
Updated
2026-07-30
Source
https://my.f5.com/manage/s/article/K000088624

Description

yum update gets the following error for the nginx plus:

Loaded plugins: ulninfo

https://plus-pkgs.nginx.com/centos/7.4/x86_64/repodata/repomd.xml: \[Errno 14\] HTTPS Error 403 - Forbidden

Trying other mirror.

No packages marked for update

Environment

  • Nginx Plus update
  • CENTOS 7

Cause

Certificate and key file expired.

Recommended Actions

Download new key and certificate files from myf5 portal and replace old ones.

Additional Information

None
