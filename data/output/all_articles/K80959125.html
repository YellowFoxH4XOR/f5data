Description

When creating a virtual server with shared objects like port lists or address lists, the network map and virtual server list search option fails to return results for this virtual server. 

Environment

  • V14.1X,  V15.X, V16.X
  • Shared Objects
  • Port Lists
  • Address Lists
  • Virtual servers 
  • Network map

Cause

Bug ID 745125.  

The Network Map will display a blank address field.

None
