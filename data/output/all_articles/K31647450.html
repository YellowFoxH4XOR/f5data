Description

Nessus reports "Remote open ports can be enumerated via SSH" on BIG-IP platform. 

Environment

  • Nessus scan tool (by Tenable)
  • Nessus Plugin ID 14272 
  • Access to BIG-IP to perform Compliance auditing

Cause

This report doesn't necessarily mean these ports are open for public access. Nessus scan tool requires to login to BIG-IP in order to perform scans.  Nessus runs 'netstat' on the BIG-IP system to enumerate these open ports. However, BIG-IP only listens these ports on loopback address for the internal processes, for example:

udp 0 0 127.0.0.1:4500
udp 0 0 127.0.0.1:500

These ports cannot be accessed from outside network and such reports can be safely ignored.

Recommended Actions

  • Running netstat  to list the open port and  its process:
netstat -nap | grep 127\.0\.0\.1 | grep LISTEN
  • Contact F5 Support if you cannot determine whether an open port belongs to a normal BIG-IP process
