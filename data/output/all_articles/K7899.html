Known Issue

This is the result of a known issue. The HTTP::redirect and HTTP::respond iRule commands generate an error message when used within the LB_FAILED iRule event. If either command is called from within that event, the BIG-IP LTM logs the following message in the /var/log/ltm file:

http_process_state_prepend - Invalid action EV_SINK_HEADER during ST_HTTP_PREPEND_HEADERS

F5 Product Development tracked this issue as CR50764, and it was fixed in BIG-IP LTM 9.3.1 and 9.4.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.3.0-HF3 issued for BIG-IP 9.3.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
