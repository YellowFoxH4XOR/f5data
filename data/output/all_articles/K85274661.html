K85274661: Unable to connect to RDP servers behind the BIG-IP

Type
Support Solution
Published
2019-12-19
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K85274661

Description:

Unable to load balance connections to RDP servers through the BIG-IP.
When you try to connect to an RDP server using the Remote Desktop Connection application, the connection attempt times out.

Environment:

  • LTM
  • Virtual server type: Standard
  • HTTP profile applied to virtual server

Cause:

Remote Desktop Protocol (RDP) is a proprietary protocol developed by Microsoft.
It's not compatible with HTTP profile.

Recommended Actions:

Deattach HTTP profile out of affected virtual server.

Additional Information:

If a Standard virtual server is configured with Layer 7 functionality, such as an HTTP profile, the client must send at least one data packet before the server-side connection can be initiated by the BIG-IP LTM system. If no HTTP traffic is received connection to pool member is not established.
