Known Issue

The BIG-IP system may not cache HTTP responses if a Response Adapt profile is applied to a virtual server.

This issue occurs when all of the following conditions are met:

  • You associate a Response Adapt profile with a virtual server.
  • The virtual server also uses a Web Acceleration profile to cache HTTP objects.

Impact

HTTP responses are not cached.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system's cache statistics report less caching than expected.
