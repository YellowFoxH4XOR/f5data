Description
This article describes how to generate an APM custom report with user MAC address.

Environment

  • BIG-IP APM

Cause
None

Recommended Actions

  1. In the APM VPE, add the "Machine Info" agent i.e. at the tab Endpoint Security (client-side)
  2. After the "Machine info", add the "Variable Assign" agent with the following entries
          For example: 
          Custom Variable: session.logon.macaddress
          Custom Expression: mcget {session.machine_info.last.net_adapter.list.[0].mac_address}    
  3. After the "Variable Assign", the "Logging" agent e.g. you can add the Logging agent at the end of the policy flow before the Ending agent, with the following entries
          For Example: 
          Type: "Custom"
          Session Variable: session.machine_info.last.net_adapter.list.*
  4. Create the custom report with User MAC address
          a. Go to "Access  ››  Overview : Access Reports" (press the Cancel button when the "Report Parameters" window pop-ups)
          b. In the "Reports Browser" pane, click the "Custom Reports"
          c. Press the Create button found at the bottom of its window space
          d. Fill out the "Report Name"
          e. In the "Report Fields" tab, tick the available fields you need to include in the report.
          f. In the Fields under the "Access Policy" branch, add the "Session variable value"
          g. On the right pane i.e. "Selected Fields", double click the Alias field of "Session variable value" and place the entry: session.logon.macaddress
          h. Save and run the report
