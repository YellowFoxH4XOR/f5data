K000130435: Windows ICMP NAT forwarding fails when SNAT connection table exists

Type
Support Solution
Published
2023-01-03
Updated
2023-05-04
Source
https://my.f5.com/manage/s/article/K000130435

Description

Windows ICMP NAT forwarding fails when SNAT connection table exists.

However, Linux ICMP NAT forwarding is working properly.

Environment

  • NAT
  • Windows ICMP

Cause

BIG-IP is functioning as designed and the current issue in this case is due to the same identifier value being used for all the ICMP requests generated by Windows client.


Recommended Actions

None

Additional Information

None
