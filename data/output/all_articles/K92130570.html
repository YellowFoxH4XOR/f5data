Known Issue

A large number of DNS requests may cause TCP connections to stall.

This issue occurs when all of the following conditions are met:

  • The virtual server uses a DNS profile with caching enabled.
  • The BIG-IP virtual server is flooded with DNS requests.

Impact

The BIG-IP system may experience high memory usage when TCP connections do not expire.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H516693 on the Diagnostics > Identified > Medium screen.
  • In the /var/log/tmm file, you observe error messages that appear similar to the following example:

    notice hud_msg_queue is full

  • The tmsh show ltm profile tcp global command output may display a large number of open TCP connections:

    For example:

    [root@localhost:Active:Standalone] config # tmsh show ltm profile tcp global
    ----------------------------------------
    TCP Profile
    ----------------------------------------
    Connections
    Open 5.3K
    ...
