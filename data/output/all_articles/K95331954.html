K95331954: Check BIG-IP AFM DDoS attack logs in bash based on attack id

Description

The BIG-IP AFM DDoS logs in configuration utility is limited or truncated,  we can use bash shell to query the mysql database directly to get the detailed logs. 

Environment

  • BIG-IP AFM
  • Virtual server
  • DDoS profile 

Cause

None

Recommended Actions

To check the related log based on attack id, use following syntax in bash shell:

mysql -uroot -p`perl -I/ts/packages -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw` logdb -e 'use logdb; select * from log_data where log_msg like "%attack_id=<attack_id>%;"'

Note: Replace <attack_id> with your actual attack id in above command.

To check the realted log based on attack source IP, use following syntax in bash shell:

mysql -uroot -p`perl -I/ts/packages -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw` logdb -e 'use logdb; select * from log_data where log_msg like "%source_ip=<source_ip>%;"

Note: Replace <source_ip> with any IP address in above command.
