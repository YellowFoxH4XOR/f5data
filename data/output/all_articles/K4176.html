Issue

The following message appears on all non-RLX platforms during an upgrade. If you are not running an RLX blade server, you can safely ignore this message.

shutdown rlxsnmpd: not running

If you are running an RLX blade server, you will receive this message if rlxsnmpd is not running. If you are running an RLX blade server and you receive this message, contact F5 Networks Technical Support for assistance.
