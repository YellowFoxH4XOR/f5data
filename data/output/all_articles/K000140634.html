Description

After upgrade BIG-IP AFM from 15.1.x to 16.1.x or 17.1.x, loading config failed with "pccd encountered a fatal error".     

  • crit pccd[xxxx]: 015d0000:2: Assertion 'err == PC_ENONE' failed at pc_cfg_CMessageProcessor.cpp:4799
  • emerg pccd[xxxx]: 015d0000:0: pccd encountered a fatal error and will be restarted shortly...
  • err mcpd[xxxx]: 01070425:3: Full configuration load failed.  

Environment

  • Upgrade from v15.1 (v15.1.4 or later) to v16.1.x or v17.1.x 
  • Storage Format of Security Logging Profile has dslite_src_ip or dslite_dst_ip or both  
  • AFM

Cause

ID997781 and ID1014609 were fixed on v15.1.4, however these were not fixed on both v16/v17 releases yet. 

Recommended Actions

We can avoid or fix with following changes. F5 recommends to perform "To avoid issue before upgrade".

  To avoid issue before upgrade

  1.  Login to tmsh via CLI
  2.  Open config merge prompt
    #load sys config merge from-terminal
  3. Copy & paste below lines
    security log nat-end-inbound-storage-field dslite_src_ip { }
    security log nat-end-outbound-storage-field dslite_src_ip { }
    security log nat-errors-storage-field dslite_src_ip { }
    security log nat-quota-ex-storage-field dslite_src_ip { }
    security log nat-start-inb-storage-field dslite_src_ip { }
    security log nat-start-outb-storage-field dslite_src_ip { }
    security log nat-end-inbound-storage-field dslite_dst_ip { }
    security log nat-end-outbound-storage-field dslite_dst_ip { }
    security log nat-errors-storage-field dslite_dst_ip { }
    security log nat-quota-ex-storage-field dslite_dst_ip { }
    security log nat-start-inb-storage-field dslite_dst_ip { }
    security log nat-start-outb-storage-field dslite_dst_ip { } 
  4. Submit lines using Ctrl + D
  5. Save the configuration by typing the following command:

    #save sys config

  6. Confirm submitted 12 lines are available on bigip_base.conf
  7. Upgrade to v16.1.x or v17.1.x 

  To fix issue after upgrade

  1.  Login to bash via CLI
  2.  Open /config/bigip_base.conf file using vi or nano command
  3.  Copy & paste below lines to end of the file
    security log nat-end-inbound-storage-field dslite_src_ip { }
    security log nat-end-outbound-storage-field dslite_src_ip { }
    security log nat-errors-storage-field dslite_src_ip { }
    security log nat-quota-ex-storage-field dslite_src_ip { }
    security log nat-start-inb-storage-field dslite_src_ip { }
    security log nat-start-outb-storage-field dslite_src_ip { }
    security log nat-end-inbound-storage-field dslite_dst_ip { }
    security log nat-end-outbound-storage-field dslite_dst_ip { }
    security log nat-errors-storage-field dslite_dst_ip { }
    security log nat-quota-ex-storage-field dslite_dst_ip { }
    security log nat-start-inb-storage-field dslite_dst_ip { }
    security log nat-start-outb-storage-field dslite_dst_ip { } 
  4. Load the configuration by typing the following command:

    #tmsh load sys config

  5. Save the configuration by typing the following command:

    #tmsh save sys config
