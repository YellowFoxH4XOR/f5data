K03554840: IControl REST calls fail after upgrade

Type
Support Solution
Published
2023-04-06
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K03554840

Description

After upgrading to version 13.1.0.x or later, you may notice that users who previously had permissions to make calls to iControl REST lose their ability to do so.

Environment

  • Upgrading to version 13.1.0.x or later
  • Using iControl REST

Cause

The issue occurs because a previously privileged user can no longer query iControl REST. Additionally, some remotely authenticated users may lose access to the Network Map and Analytics view after the upgrade.

Recommended Actions

To address this issue, you can repair the current user's permissions by following these steps:

  1. Delete the state maintained by IControlRoleMigrationWorker and restart the restjavad process:

    # restcurl -X DELETE "shared/storage?key=shared/authz/icontrol-role-migrator"
# bigstart restart restjavad
  2. Update the shared/authz/roles/iControl_REST_API_User userReference list: 
    # restcurl shared/authz/roles/iControl_REST_API_User > role.json
# vim role.json
  3. add { "link": "https://localhost/mgmt/shared/authz/users/[your-user-name]" } object to userReferences list
  4. add all affected users' accounts using PUT:  
    # curl -u admin:admin -X PUT -d@role.json http://localhost/mgmt/shared/authz/roles/iControl_REST_API_User
Now, when you create a new user, the permissions should start in a healthy state.
