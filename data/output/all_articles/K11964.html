Known Issue

This is the result of a known issue. If you attempt to use the image2disk command with the --noarray and --format=partitions options, you can render the system unbootable.

You can use the image2disk --noarray command option when upgrading or installing software on the BIG-IP system to format the file system without creating a mirrored volume set. You should only use the --noarray option with the --format=volumes command option, which is used to format the BIG-IP system with the Logical Volume Management (LVM) disk-formatting scheme.

For example, the following command installs version 10.0.x and formats the file system using LVM without creating a mirrored set:

image2disk --instslot=<single disk slot> --format=volumes --nosaveconfig --noarray <BIG-IP-10.0.x.iso>

Note: BIG-IP systems that ship with version 10.x are configured to use the LVM disk-formatting scheme. To determine the disk-formatting scheme used by a BIG-IP version 10.x system, refer to K10817: Determining the disk-formatting scheme used by a BIG-IP version 10.x system.

F5 Product Development is tracking this issue as ID 223794 (formerly CR131945).

Workaround

If you used the image2disk command with the --noarray and --format=partitions options, and the system fails to boot, you must perform a clean installation of BIG-IP version 10.x. For information about performing a clean installation of version 10.x, refer to K10819: Performing a clean installation of BIG-IP version 10.x.
