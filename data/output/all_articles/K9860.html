K9860: Reasons to configure the domain administrator account for Active Directory authentication

Topic

When configuring Active Directory authentication for a master group, you are prompted to configure a domain administrator account in the Domain admin name and Domain admin password fields. For security reasons, you may elect to configure a non-administrator account in this field. However, doing so will result in the following feature loss: 

  • Password management

    Users will be unable to update their Active Directory password through FirePass. Therefore, if a user’s password has expired, the user will be unable to log on to the FirePass controller.
  • Active Directory user import

    You will be unable to import Active Directory accounts to that master group on the Users : User Management page.

    Note: The user import feature can be used for only a master group configured for local users.

Important: The information supplied in this Solution applies to a default Active Directory configuration. Using a highly-customized Active Directory configuration, you may be able to grant a non-administrator account the necessary privileges to perform the functions listed in this Solution.
