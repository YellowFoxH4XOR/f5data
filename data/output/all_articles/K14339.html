Known Issue

  Description

The ARX 4000 platform's interface 2/13 and interface 2/14 statistics are not available within the ARX collect diagnostics files.

This issue occurs when the following condition is met:

  • You are using the ARX collect diagnostics tool

Impact

Interface statistics information is not available.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Statistics information is not available within the diagnostics files.

Workaround

To work around this issue, you can manually gather the interface statistics. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable

  3. To gather the interface statistics, use the following command syntax:

    show interface gigabit (interface number) stats

    For example:

    show interface gigabit 2/13 stats

    Output will appear similar to the following example:
