K000139512: CRLDP issue when using https

Type
Support Solution
Published
2025-06-19
Updated
2025-06-19
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000139512

Description

You have configured CRL to take the URL from the certificate.

You have several certification authorities and the problem occurs only when using https instead of http to download the CRL.

You can observer following errors in apm logs:

CRLDP Auth agent: CRL lookup failed for LDAP url 'https://example.com/app/cert/crl/cert_example.crl' reason ''

Environment

  • BIG-IP APM
  • CRLDP Authentication
  • APM access policy configured with a CRLDP Auth agent

Cause

BIG-IP APM does not support downloading Certificate Revocation Lists (CRLs) over the HTTPS protocol. Only HTTP and LDAP protocols are supported for retrieving CRLs via CRLDP authentication.

Recommended Actions

Request your Certificate Authority (CA) to publish required CRLs over HTTP or LDAP instead of HTTPS.

Additional Information

An RFE (ID1600029) has been filed to request support for HTTPS in CRLDP AAA
