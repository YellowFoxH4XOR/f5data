Description

This article explains how to check the current Telemetry Streaming config on a Big-IP, as well as how to check it in a qkview.

 

Environment

Big-IP with Telemetry Streaming feature configured

 

Cause

The Telemetry Streaming configuration is not stored in the regular Big-IP configuration files.

However, the Telemetry Streaming config can be seen in the file /var/log/restnoded/telemetryDeclarationHistory - the latest (current) config is at the very end of the file. Since this file is captured in a qkview by default, you can also check the state of the Telemetry Streaming config at the time a qkview was taken, by checking the contents of this file in a qkview - simply check the last declaration at the end of the file.
