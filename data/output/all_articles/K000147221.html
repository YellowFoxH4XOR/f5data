K000147221: Why is the “Explain with AI” feature unavailable for my user ID?

Applies to

Source

What Happened?

  • You attempted to use the “Explain with AI” feature in the AI Assistant, but encountered the following error message:

"You cannot access this feature with your current role. Contact your Administrator and ask them to
change your role to access it."

 

Environment

  • F5® Distributed Cloud
  • AI Assistant 

Resolution/Answer

To gain access to the “Explain with AI” feature, one of the following must be applied for the user in question:

  • The user has role f5xc-ai-assistant-monitor in system namespace.

  • The user has role ves-io-admin-role in system namespace.

Additionally (not instead of the above), for custom roles, ensure f5xc-ai-assistant-standard-monitor is included in the allowed API groups.

Cause

  • Starting on September release, a new Role-Based Access Control (RBAC) requirement was introduced, restricting access to the AI Assistant feature within the System namespace.
