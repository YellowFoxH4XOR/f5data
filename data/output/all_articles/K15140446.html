K15140446: BIG-IQ HA setup stuck in ''Configuring Database Replication''

Type
Support Solution
Published
2022-09-28
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K15140446

Description

While adding a standby BIG-IQ Centralized Management for High Availability, It goes through all of the steps to create a secure connection, but it gets stuck in the "Configuring Database Replication" phase for a long time.

Environment

  • Big-IQ 7.1.X

The initial phases of the procedure are completed successfully: 

  • The SSH trust with the peer device is stablished and verified
  • The peer device is added to the BIG-IQ device group
  • The peer device became Active in the device group

The following error is found in the /var/log/ha_pg_basebackup.log file (in the Standby device):
 

pg_basebackup: could not connect to server: SSL error: certificate verify failed
 

The Standby device becomes inaccessible from the GUI: "Waiting for BIG-IQ services to become available..."

The incomplete procedure brings down the restjavad, postgres and tokumond processes in the Standby:

bigstart status
:
:
postgres     down 51 minutes, normally up
restjavad    down 51 minutes, normally up
:
tokumond     down 51 minutes, normally up
:

Cause

  • Expired HA certificate

Recommended Actions

Validate the expiration date of the HA certificates in both HA peer devices:

Run in the command line:

openssl x509 -in /var/lib/pgsql/config/server.crt -issuer -subject -startdate -enddate -noout

In this example the certificate is valid in the Standby:

openssl x509 -in  /var/lib/pgsql/config/server.crt -issuer -subject -startdate -enddate  -noout
issuer= /CN=10.155.226.26/O=F5 BIG-IQ System
subject= /CN=10.155.226.26/O=F5 BIG-IQ System
notBefore=Sep 16 14:03:42 2022 GMT
notAfter=Sep 15 14:03:42 2024 GMT <<<<< Certificate is valid

But it has expired in the Active:

openssl x509 -in  /var/lib/pgsql/config/server.crt -issuer -subject -startdate -enddate  -noout
issuer= /CN=10.155.226.25/O=F5 BIG-IQ System
subject= /CN=10.155.226.25/O=F5 BIG-IQ System
notBefore=Sep 27 19:57:53 2022 GMT
notAfter=Sep 28 19:57:53 2022 GMT <<<<< Certificate has expired

For the certificate that has expired, run in the command line:

ha_generate_certs -f <discovery IP>

Once the certificates are confirmed to be valid:
 

       1. Recover the GUI access in the Standby device:

           K25419468: BIG-IQ user interface stuck with a 'Waiting for BIG-IQ services to become available' error message

       2. Reset the HA in both devices, in the command line:
 
           /usr/bin/ha_reset -f <local discovery address>
          
       3. Retry the procedure

Note: The certificates are valid for a period of two years
