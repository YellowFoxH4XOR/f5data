Description

Asm response logs are not being forwarded to SIEM. The issue is seen with the response and not the request. While a traffic capture will show the request, it will not show the response.


Environment

  • ASM remote logging
  • ArcSight

Cause

This issue is a limitation of the ArcSight format type. When the Splunk format type is chosen, the response is seen.


Recommended Actions

If remote response logging is required, Splunk format type can be considered, or Comma-separated values and use "user-defined" storage format and select the same fields as ArcSight has. Then, if any fields are not necessary, they can be replaced with response-related ones. In that way, ArcSight formatted logging messages can be sent via Remote Storage Type "Remote" and have some response-related fields in it. However, the caveat is that you will lose some fields in exchange for response-related fields.
