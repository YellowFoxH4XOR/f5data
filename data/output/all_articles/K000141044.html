Description

The web browser displays an "Insecure Connection" warning when accessing the BIG-IP GUI.

Environment

  • BIG-IP LTM

Cause

The web browser displays this warning message because the BIG-IP is using a self-signed certificate for its management interface. This is standard behavior and is not a cause for concern if the management interface is only accessible from within your internal network or VLAN.

Recommended Actions

No action is required.

If you prefer to eliminate the warning message, you can replace the self-signed certificate with a certificate signed by a trusted Certificate Authority (CA).
