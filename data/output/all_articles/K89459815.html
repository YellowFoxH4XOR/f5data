Description

While creating a new firewall rule, you find that you cannot specify a destination port

Environment

  • BIG-IP AFM
  • New firewall rule

Cause

If protocol option is set to Any, you will not be able to configure a destination port

Recommended Actions

Setting Protocol option to something other than Any will allow you to configure a destination port in your firewall rule

None
