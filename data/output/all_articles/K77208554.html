Topic

You should consider using this procedure under the following condition:

  • You want to create a new BIG-IP virtual machine from an ISO image using the VMware Host Client for ESXi.

Description

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the VMware ESXi server using the VMware Host Client.
  • There are sufficient available resources on the VMware ESXi server to create and support the new virtual machine.

Procedures

Creating a BIG-IP virtual machine instance

In some deployments, the VMware ESXi Host Client may not be able to process the upload of a BIG-IP VE OVA file. You can create a new BIG-IP virtual machine by uploading the BIG-IP ISO image to the VMware ESXi server, create a new virtual machine configuration, and install the BIG-IP using the BIG-IP ISO image. The following procedure guides you through deploying a new BIG-IP virtual machine by using a BIG-IP ISO image file. 

Impact of procedure: Performing the following procedure uses datastore, memory, and CPU resources of the VMware ESXi server.

  1. Log in to the VMware Host Client URL https://<hostname or ip address>/ui using a compatible web browser. For more information regarding compatible browsers refer to: VMware Host Client System Requirements.

    Note: This link takes you to a resource outside of AskF5. The third party could remove the document without our knowledge.

  2. To avoid allowing a host client timeout while creating the new virtual machine instance, click the <username>@<hostname/ip address> tab.

    Note: The tab title is based on the <username> username used to access the ESXi Host Client, and <hostname/ip address> is the hostname or ip address used to access the ESXi Host Client.

  3. Click Settings > Application timeout of 1 hour or greater. 
  4. Click Host. 
  5. Click Create/Register VM. 
  6. Select Create a new virtual machine and click Next. 
  7. Enter a Name for the new virtual machine.
  8. Click ESXi Compatibility.
  9. For Guest OS family, click Linux.
  10. Select the appropriate base operating system version for the Guest OS version of the BIG-IP ISO image you plan to install and click Next. For more information refer to: K3645: Base operating system information for the BIG-IP host system.
  11. Select a datastore with sufficient resources for the new virtual machine and click Next. 
  12. Configure Customized settings to match the minimum requirements for the BIG-IP version (or greater). For more information refer to the following articles:
    • K15796: Hardware requirements to host BIG-IP VE on private cloud platforms
    • K14946: Overview of BIG-IP VE image sizes
    • K12149: Adding TMM interfaces to the BIG-IP Virtual Edition running on VMware ESXi
  13. Set SCSI Controller 0 to LSI Logic Parallel.
  14. Set Network Adapter 1 to use the appropriate management network for the BIG-IP instance.
  15. To add network interfaces to the virtual machine instance click Add other device > Network Adapter.
  16. Expand the Network Adapter settings.
  17. Set Adapter Type to VMXNET 3 and MAC Address to Automatic.

    Note: Repeat steps 15 through 17 to add additional network interfaces to the virtual machine instance.

  18. Click Add other device > CD/DVD Drive > Datastore ISO file.
  19. Click a previously uploaded BIG-IP ISO image file from one of the VMware ESXi datastores. When using an existing uploaded BIG-IP ISO upload image file skip to step 24.

    Note: To upload a new BIG-IP ISO image file follow steps 20 through 23.

  20. For CD/DVD Media click Browse.
  21. Click a previously uploaded BIG-IP ISO image file or click Upload.
  22. Select the BIG-IP ISO file to upload from your local device.
  23. Click Open to upload the BIG-IP ISO file.
  24. Click Finish to complete the virtual machine configuration. 
  25. Start the new virtual machine configuration. 
  26. From the virtual machine console, press Enter when Terminal type? [vt100] displays.
  27. From the virtual machine console, press Enter when Press [Enter] to begin installation displays.
  28. From the virtual machine console, press Enter when Remove media, then press [Enter] to reboot displays.

    Note: After the virtual machine restarts, you can license and configure the BIG-IP VE instance.
