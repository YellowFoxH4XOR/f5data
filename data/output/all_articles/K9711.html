Issue

In BIG-IP versions prior to 9.4.2, the syslog-ng.conf file was intended to be saved in the UCS configuration archive by default, but an incorrect path was specified for the syslog-ng.conf file in the /usr/libdata/configsync/cs.dat file (the configuration archive file list), and the file was not included.

Beginning in BIG-IP 9.4.2, the syslog-ng.conf file is no longer intended to be included in the archive by default, and the entry referencing the syslog-ng.conf file has been removed from the /usr/libdata/configsync/cs.dat file list.

You can add the syslog-ng.conf file to the configuration archive file list by performing the procedure detailed in K4422: Viewing and modifying the files that are configured for inclusion in a UCS archive.

Important: Restoration of a UCS archive file that includes the /etc/syslog-ng/syslog-ng.conf file could cause two documented known issues, which were resolved in BIG-IP 9.4.0. For BIG-IP versions prior to 9.4.0, F5 recommends that you reference the following articles before you include the /etc/syslog-ng/syslog-ng.conf file in your configuration archive:

  • K5872: BIG-IP does not pass traffic and non-management interfaces are non-responsive after upgrading BIG-IP to versions 9.1.1 or 9.2.2
  • K5879: BIG-IP does not pass traffic and non-management interfaces are non-responsive if syslog-ng fails to start
