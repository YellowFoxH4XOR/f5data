K000137606: Search virtual servers with highest CPU over 5 minutes

Applies to

Source

Description

Search and sort for virtual server with highest CPU over 5 minutes


Environment

BIG-IP LTM v15.1.3

Virtual Server CPU


Cause

Find the virtual server consuming the most CPU and sort them


Recommended Actions

Purpose: lists virtual servers and their last 5 minute CPU. Combines the 2 data lines into one line and sorts the 7th column, CPU, in descending order. The highest CPU virtual server is at the top.



BASH oneliner: tmsh show /ltm virtual | grep -e "Ltm::" -e "Last 5 Min" | sed 'N;s/\n/ /' | sort -rn -k7



Sample Output:


Ltm::Virtual Server: /Common/Shared/vip05-F5lab-prod-web-https Last 5 Minutes 4


Ltm::Virtual Server: /Common/Shared/vip-F5lab_stream Last 5 Minutes 0


Ltm::Virtual Server: /Common/Shared/vip08-F5lab-mobile-api-https Last 5 Minutes 0
