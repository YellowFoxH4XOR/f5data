Topic

F5 is announcing that the End of Software Development (EoSD) for BIG-IP version 4.x became effective December 31, 2008 in accordance with the guidelines contained within K3225: F5 End of Life Policy and K5903: BIG-IP software support policy.

As of December 31, 2008, F5 no longer provides security updates, software fixes (hotfixes), or consulting services for BIG-IP version 4.x. Additionally, service contracts enter the Extended Support phase beginning with the End of Software Development (EoSD) in accordance with the guidelines contained within K4309: BIG-IP Platform Lifecycle Support Policy.

During the Extended Support phase, F5 will only offer configuration support and RMA services. Defect correction will not be provided. F5 may offer a customer access to certain software updates, which may include security or stability related software releases.

All configuration support for BIG-IP version 4.x during the Extended Support phase is considered reasonable effort, which is limited to technical phone support and hardware support.

Note: Reasonable effort is confined to system configuration support. No response time targets, guarantees, or SLAs shall apply. No escalations to Engineering Services or Product Development will be utilized. RMA support is included, as long as the platform itself has not exceeded its End of Technical Support (EoTS) or End of RMA (EoRMA) support date.

Customers should view the corresponding software release notes to determine if a particular software release is suitable for their platform or software version. Access or compatibility of these software updates are not guaranteed and will be made under F5 reasonable effort support guidelines.

Additionally, if a platform is not compatible with the latest Maintenance-Only software release, the platform may be restricted from operating that version through the F5 software licensing process.

The effective End of Technical Support (EoTS) date is December 31, 2009 for the BIG-IP version 4.x software, completing its End of Life (EoL) cycle.

Note: Some platforms running BIG-IP 4.x software are capable of upgrading to the BIG-IP LTM version 9.x software. 

For more information about this announcement, contact your local F5 Partner Business Manager or Inside Sales Representative.
