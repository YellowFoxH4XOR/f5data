Known Issue

The BIG-IP system may terminate the connection of Oracle Access Manager sessions.

This issue occurs when the following condition is met:

  • A virtual server is configured with the following:
    • Client SSL profile
    • APM access policy
    • OAM support is enabled

This issue occurs when the eam process requests a client certificate. If no client certificate is returned, the access policy incorrectly assumes an error and terminates the connection.

Impact

Users are unable to access resources through the Oracle Access Manager enabled virtual server.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • User sessions are terminated unexpectedly.
  • The system logs the following error message in the /var/log/ltm file:

    tmm1 err tmm1[11328]: 01230140:3: RST sent from
    <virtual server>:443 to <client device>:1362, Unknown reason

Workaround

To work around this issue, you can remove the access profile from the virtual server. To do so, perform the following procedure:

Impact of workaround: You cannot apply the BIG-IP APM access policy functions to the Oracle Access Manager virtual server.

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. Click Virtual Servers.
  4. Click the name of the virtual server to edit.
  5. Select None from the Access Profile drop-down menu.
  6. Click Update.
