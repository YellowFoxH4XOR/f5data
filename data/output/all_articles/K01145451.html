Environment

  • ASM provisioned 
  • Bot signature update installation is failing 
  • Predefined Bot signature is configured 
     

Cause
This issue can have multiple causes:

  • Bug ID 883853: Bot Defense Profile with staged signatures prevents signature update
  • If Bug ID 883853 does not apply, then it is possible that a user-defined signature has the same name as the pre-defined signature

Recommended Actions

  1. Delete predefined bot signature from bigip.conf. In this example, according to logs above the predefined signature is  /Common/git signature Or you can simply comment the lines for the config of this predefined signature from bigip.conf file. 
     
  2. Load configuration using below command:
     tmsh load sys config
     
  3. Create an user-defined git signature (or the one deleted in your case) from GUI under Security ›› Bot Defense : Bot Signatures : Bot Signatures List : Create 
     
  4. Install the latest bot signature file again.
