K000160980: F5OS-A - Attempts to configure host key algorithms such as ecdsa-sha2-nistp384 result in the error

Type
Support Solution
Published
2026-04-24
Updated
2026-04-24
Applies to
  • F5OS
  • F5OS-C: 1.8.2
Source
https://my.f5.com/manage/s/article/K000160980

Description

Attempts to set algorithms such as ecdsa-sha2-nistp384 or ecdsa-sha2-nistp384-cert-v01@openssh.com result in the error:

Aborted: 'system security services service sshd': <algorithm> Is not part of allowed HostKeyAlgorithms list

Environment

  • Product: F5OS-A (rSeries)
  • Version: 1.8.2, 1.8.3, and above
  • SSH host key algorithm configuration attempted via CLI
  • non-FIPS licensed F5OS-A system

Cause

  • Only the following SSH host key algorithms are supported for configuration on non-FIPS licensed F5OS-A systems:

    • ecdsa-sha2-nistp256
    • ssh-ed25519
    • rsa-sha2-512
    • rsa-sha2-256

Attempts to configure unsupported algorithms will fail with an error. This is expected behavior.

Answer/Recommended Actions

To restrict SSH host key algorithms, select only from the supported list above.
