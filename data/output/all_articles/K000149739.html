Description

"Error getting auth token from login provider" when a user that includes "mgmt" or "shared" is used.

Environment

BIGIP LTM

Cause

Bug ID 1789437 bigip with username mgmt or shared are not getting access to some info after login

Recommended Actions

Use a different user name.
