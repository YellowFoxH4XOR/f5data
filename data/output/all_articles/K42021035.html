Description

  • Adding a DNS Resource Record, in ZoneRunner is failing with error:
Command 'create; for type 'zone_rr_text' is refused because SYNC ZONES is running


  • /var/log/gtm shows similar events:
Jul 9 20:05:53 slot2/gtm.site.com notice gtmd[12613]: 011a001c:5: SYNC_ZONES from 100.100.100.100 skipped. Reason: sync_zones currently running from ip 20.30.40.50
Jul 9 20:05:56 slot2/gtm.site.com notice gtmd[12613]: 011a001c:5: SYNC_ZONES from 200.200.200.200 skipped. Reason: sync_zones currently running from ip 20.30.40.50

Environment

  • BIG-IP DNS

Cause

  • This can occur, if configuration changes are being made to multiple sync group members. The other devices are attempting to sync their configuration updates to the local BIG-IP DNS system, causing the local configuration changes to be blocked.

Recommended Actions

  • Reattempt the local configuration change
or
  • Designate one BIG-IP DNS sync group member as the one that all administrators will make changes to.
