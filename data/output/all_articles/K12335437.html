Description

Executing the following commands or equivalent will graceful shutdown the SSH daemon:

  • killall $(pidof sshd)
  • kill -15 $(pidof sshd)

Environment

  • BIG-IP
  • systemd

Cause

When executing the commands shown above, the SSH daemon terminates on a SEGTERM signal. The default systemd configuration for SSH will not restart the SSH daemon on graceful shutdown.

Recommended Actions

To recover, you may run one of the following workarounds:

  1. If you have access to the graphical configuration utility, navigate to the system service list, select and restart the sshd service.
  2. If you have access to the console, run the following command:
    systemctl restart sshd.service
