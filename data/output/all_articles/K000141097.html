K000141097: Tmm snapshots are not being generated the /shared/tmstat/snapshots directory is missing or empty

Type
Support Solution
Published
2024-09-17
Updated
2025-02-05
Source
https://my.f5.com/manage/s/article/K000141097

Description

Tmm snapshots are usually generated every hour and every 24 hours (every 3600 and 86400 seconds) and saved in /shared/tmstat/snapshots, but on some devices this directory does not exist or is empty

 

Environment

BIG-IP

 

Cause

This can be caused by switching statistics roll-ups to the 'slow_merge' method per https://cdn.f5.com/product/bugtracker/ID499348.html

 

Recommended Actions

Check sys db merged.method and modify to fast_merge:

# tmsh list sys db merged.method all-properties
sys db merged.method {
    default-value "fast_merge"
    scf-config "false"
    value "slow_merge"
    value-range "fast_merge slow_merge"
}

# tmsh modify sys db merged.method value "fast_merge"

# tmsh list sys db merged.method all-properties
sys db merged.method {
    default-value "fast_merge"
    scf-config "false"
    value "fast_merge"
    value-range "fast_merge slow_merge"
}
