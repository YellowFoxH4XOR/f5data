Known Issue

The BIG-IP 10G interfaces may be marked down, or up and down, when connected with a Cisco Nexus switch.

This issue occurs when the following conditions are met:

  • The BIG-IP platform is a VIPRION B2250, or B4300 blade, or a BIG-IP 10x00 appliance.
  • The Cisco Nexus switch is upgraded to or running version 7.0(5)N1(1).

Impact

The BIG-IP interfaces do not pass traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The affected BIG-IP 10 GB interfaces do not pass traffic.
  • The system logs error messages to the /var/log/ltm file that appear similar to the following example:

    info bcm56xxd[7567]: 012c0015:6: Link: 1/1.2 is DOWN
    info bcm56xxd[7567]: 012c0015:6: Link: 1/1.2 is UP
    info bcm56xxd[7567]: 012c0015:6: Link: 1/1.2 is DOWN
    info bcm56xxd[7567]: 012c0015:6: Link: 1/1.2 is UP

Workaround

To work around this issue, you can toggle the interface to disabled and then enabled. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log into the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Use the following command syntax to disable the interface:

    modify /net interface <interface> disabled

    For example:

    modify /net interface 2/1.2 disabled

  3. Use the following syntax to enable the interface:

    modify /net interface <interface> enabled

    For example:

    modify /net interface 2/1.2 enabled
