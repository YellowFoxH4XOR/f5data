Description

The /shared and /var/log directories are mounted on logical volumes that are common across all boot locations on the BIG-IP system.
 
Volume set's of these directories are shared across all the boot locations, hence the content of this file-system are available across all the boot locations. Such as the software images, log files, etc. 

Environment

  • File System 
  • /shared and /var/log 

Cause

None. 

Recommended Actions

Volume set  "/dev/mapper/vg--db--sda-dat.share.1" and "/dev/mapper/vg--db--sda-dat.log.1"  are common across all the boot locations.

To view the volume set run "lvdisplay" command.
  1.  [root@LTM1.example.com_b:Standby:Changes Pending] config # lvdisplay | grep log
       LV Name /dev/vg-db-sda/dat.log.1
  2. [root@LTM1.example.com_b:Standby:Changes Pending] config # lvdisplay | grep share
       LV Name /dev/vg-db-sda/dat.share.1

The remaining directories like /, /config, /usr, etc are mounted on different volume set for each boot location. 

For instance, / is mounted on different volume set on each boot location. Hence the content of this directories are not available from one boot location to the other however /shared and /var/log mount points  uses the same volume set across the boot locations, hence the content on these file systems are available throughout all the boot locations.
 In the below example, the volume set for root is different on each volume.                                       

[root@LTM1.example.com_b:Standby:Changes Pending] config # lvdisplay | grep root
  LV Name                /dev/vg-db-sda/set.1.root
  LV Name                /dev/vg-db-sda/set.2.root
  LV Name                /dev/vg-db-sda/set.3.root
