Description

You want to record the backend pool select decision result.

Environment

  • BIG-IP LTM
  • iRule
  • Load Balance Decision
  • Persistence
  • Logging

Cause

None

Recommended Actions

In some scenarios, such as load balance troubleshooting, you may want to know how the BIG-IP LTM makes load balance decisions. You can use the iRules below to record load balance decision results, as well as the persist records if applicable.

  • IP::remote_addr
  • TCP::remote_port
  • LB::server
  • persist

The example below shows a format for recording the results to the /var/log/ltm log file. You may customize the format and optionally remove the Ratio and Persists parts based on your real requirement.

when LB_SELECTED {
    log local0. "LB INFO - Client: [IP::remote_addr], Port: [TCP::remote_port], Pool: [LB::server], Ratio: [LB::server ratio], Persist: [persist lookup source_addr [IP::client_addr]]"
}

The output with no persist records will be like this:

Jan 23 00:00:00 bigip1 info tmm[<pid>]: Rule /Common/lb_decision_rule <LB_SELECTED>: LB INFO - Client: 192.168.10.1, Port: 8999, Pool: /Common/Pool_lb_1 10.10.10.1 8080, Persist:

The output where persist  records exists will be like this:

Jan 23 00:00:05 bigip1 info tmm[<pid>]: Rule /Common/lb_decision_rule <LB_SELECTED>: LB INFO - Client: 192.168.10.1, Port: 8999, Pool: /Common/Pool_lb_1 10.10.10.1 8080, Persist: /Common/Pool_lb_1 10.10.10.1 8080

Additional Information

You may use HSL related commands to send the result to your logging servers instead of just locally, for this purpose you may refer to the below iRule commands:

  • HSL::open
  • HSL::send

For example, assume you have an HSL pool configured as lb_decision_logging_pool, you can use the below example for sending the records to remote high-speed logging systems.

when CLIENT_ACCEPTED {
   set hsl [HSL::open -proto UDP -pool lb_decision_logging_pool]
}
when LB_SELECTED {
   HSL::send $hsl "<134> LB INFO - Client: [IP::remote_addr], Port: [TCP::remote_port], Pool: [LB::server], Ratio: [LB::server ratio], Persist: [persist lookup source_addr [IP::client_addr]]\n"
}
