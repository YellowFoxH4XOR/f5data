Description

If the software installation fails on a vCMP Guest, to mitigate, please copy the iso image from vCMP Host to vCMP Guest and try again from the local iso image on the vCMP Guest itself.
Error message during installation from vCMP Host iso: failed (Failed to install.)

for example:
tmsh show /sys software
--------------------------------------------------------
Sys::Software Status
Volume  Product  Version   Build  Active  Status
--------------------------------------------------------
HD1.1    BIG-IP 16.1.3.4   0.0.2     yes  complete
HD1.2    BIG-IP 16.1.3.5   0.0.5      no  failed (Failed to install.)

Environment

  • BIG-IP
  • vCMP Host with vCMP Guests
  • vCMP Guest upgrade failed

Cause

There can be many reasons for a failed installation, such as incorrect Linux file permissions between the vCMP Guest and the Host, for example:

Bug ID 987301: Software install on vCMP guest via block-device may fail with error 'reason unknown'

Recommended Actions

To workaround, please copy the ISO images from vCMP Host into the vCMP Guest, and use those to perform the installation.

This will allow the installation to proceed with the ISO image in the Local selection.

 

1. Login to the vCMP host Command Line.
 
2. Navigate to the ISO image directory by typing:
cd /shared/images/
 
3. Use scp to copy the ISO image from the vCMP host to the vCMP guest.
scp <local.ISO> <remote.login.credential>@<vCMP.guest.ip.address>:/shared/images/

For example; when <local.ISO> is BIGIP-14.1.2.1-0.0.4.iso, <remote.login.credential> is root, <vCMP.guest.ip.address> is 10.10.10.10 than the command would be:
scp BIGIP-14.1.2.1-0.0.4.iso root@10.10.10.10:/shared/images/
 
4. Once the file has been transferred, login to the vCMP guest's GUI.
 
5. Navigate to System > Software Management.
 
6. You will see there are 2 software images with the intended upgrade version.
 
7 .Select the image which is in Local (not Host) and proceed with the software installation.

Additional Information

There can be many reasons for a failed installation, please view the error messages from command: tmsh show sys software and logs /var/log/ltm and /var/log/liveinstall.log for more information.
