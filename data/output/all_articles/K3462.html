Topic

When you run the /usr/local/bin/genkey script, it determines if a FIPS card is present in the system. If a FIPS card is installed, the /usr/local/bin/genkey script calls the /usr/local/bin/genkey.fips script. This script generates command line arguments and calls the /usr/contrib/bin/generatekey script using those arguments.

You can modify the /usr/local/bin/genkey.fips script to save the temporary output it generates, which will allow you to examine the output after the script completes. To make this modification, edit the /usr/local/bin/genkey.fips file by commenting out the following line:

rm -f ${NFTMP}* /tmp/_rkey_script

This modification will allow the following files to remain after the script completes:

  • /tmp/_nftmp
  • tmp/_rkey_script

Debugging the key generation process

The environment variables NFAST_KMTOOL_DEBUG and NFAST_KMTOOL_DEBUGFILE are available to force the /usr/contrib/bin/generatekey script to generate debug information. To set these variables, use the following commands:

    • NFAST_KMTOOL_DEBUG=1
    • export NFAST_KMTOOL_DEBUG
    • NFAST_KMTOOL_DEBUGFILE=/var/tmp/nfast.log
    • export NFAST_KMTOOL_DEBUGFILE

    If you set these variables, the /usr/contrib/bin/generatekey command will save debugging output to the specified log file.

    To disable the debug logging, use the following commands:

      • unset NFAST_KMTOOL_DEBUG
      • unset NFAST_KMTOOL_DEBUGFILE
