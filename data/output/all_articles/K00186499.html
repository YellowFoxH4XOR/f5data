K00186499: How to automate checking the temperature on SDC/Traffix environment ?

Type
Support Solution
Published
2023-02-07
Updated
2024-10-01
Applies to
  • Traffix SDC
Source
https://my.f5.com/manage/s/article/K00186499

Description


The temperature checking on SDC equipment can be automated by scheduling a command in the  crontab on the linux system.
The best way is using external linux server with e.g. CentOS7. This server need to connected to the network where is the access to the iLO4 interface for our SDC/EMS servers.
The "ipmitool" (Intelligent Platform Management Interface) give the possibility to monitoring temperature sensors on the iLO4 interface components.

Environment

  • SDC 5.x
  • Traffix/SDC
  • HPE iLO4
  • Linux servers

Cause

None

Recommended Actions

  1.  Install "ipmitool" tool on the linux server (e.g CentOS7)
# yum install ipmitool
  1. Create script "tempetarure_check_script" with the following content:
[root@control log]# cat /root/tempetarure_check_script

date >> /root/temperature_chassis
ipmitool -I lanplus -H <iLO IP address> -U ****** -P ******** sensor | egrep "49-Sys Exhaust|50-Sys Exhaust"|awk -F '|' '{print $1,$2,$3}' >> /root/temperature_chassis
[root@control log]# cat /root/tempetarure_check_script

date >> /root/temperature_chassis
ipmitool -I lanplus -H <iLO IP address> -U ****** -P ******** sensor | egrep "49-Sys Exhaust|50-Sys Exhaust"|awk -F '|' '{print $1,$2,$3}' >> /root/temperature_chassis
  • date command - put the timestep on the output in the "temperature_chassis" file
  • ipmitool - collect sensors information and generate output for two sensors 49, 50 and redirect to the output "temperature_chassis" file
  1. Schedule the script to run every 5 minutes in the crontab file
[root@control log]# cat /etc/crontab
SHELL=/bin/bash
PATH=/sbin:/bin:/usr/sbin:/usr/bin
MAILTO=root

# For details see man 4 crontabs

# Example of job definition:
# .---------------- minute (0 - 59)
# |  .------------- hour (0 - 23)
# |  |  .---------- day of month (1 - 31)
# |  |  |  .------- month (1 - 12) OR jan,feb,mar,apr ...
# |  |  |  |  .---- day of week (0 - 6) (Sunday=0 or 7) OR sun,mon,tue,wed,thu,fri,sat
# |  |  |  |  |
# *  *  *  *  * user-name  command to be executed
*/5 * * * * root /root/tempetarure_check_script
  1. The output contain the temperature for two sensors with timestamp every 5 min:
[root@control ~]# tail -f /root/temperature_chassis
Mon May 24 10:30:01 CEST 2021
49-Sys Exhaust     26.000       degrees C
50-Sys Exhaust     27.000       degrees C
Mon May 24 10:35:01 CEST 2021
49-Sys Exhaust     26.000       degrees C
50-Sys Exhaust     27.000       degrees C
