Known Issue

Rewritten portal access content that contains an eval event may not function correctly.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a portal access profile.
  • The portal access profile processes HTML content that contains a JavaScript eval call.
  • The JavaScript eval call is redefined within the HTML page.

Impact

Web applications may not function correctly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The JavaScript eval call functionality produces unexpected results.
  • When the eval call is executed, the web browser may fail to respond or experience instability.
