K04211357: Configuring custom Attack Signature to block specific strings from payload of POST request

Source

Description
Use ASM customize Attack Signature to block specific strings from POST request payload

Environment

  • ASM
  • Attack Signature

Cause
Need to block POST request which is having payload with uuid==123456

UsernameField=xxx&chkEnableQB=off&uuid=123456&uuidOld=123456&DeviceLocation=&location=&xxx=&xxx=&SubmitNext=Sign+In

Recommended Actions

  1. Go to GUI > Security > Options > Application Security > Attack Signatures > Attack Signature List > Create
  2. Create a customized Attack Signature similar to the below
    • Name: Blocking-uuid-uuid=123456
      ID: 3000000000
      Signature Type: Request
      Systems: <select appropriate server technologies type>
      Attack Type: Injection Attempt
      Rule: Simple Edit Mode
      Matched Element: Request Content
      Matched Criteria: contains string
      Keyword: uuid=123456
      Match Case: checked
      Accuracy: High
  3. Select that appropriate ASM policy from GUI
    • GUI > Security > Application Security > Security Policies > Policies List
  4. Choose Attack Signature from that ASM policy
  5. Search that Attack Signature using ID and select it to Enforced
  6. Checked Block for that Attack Signature from Blocking page.
