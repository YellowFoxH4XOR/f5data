Description

You would like additional information regarding the usage of the OID ltmDnsCacheStatFailureCf that is located in F5-BIGIP-LOCAL-MIB.txt.

Since v14.x, ltmDnsCacheStatFailureCf is no longer visible in the WebUI or TMSH.

ltmDnsCacheStatFailureCf is the "response failure" that is triggered when there is not client side connection flow when we attempt to respond. This is mainly when the client is no longer responding to the BIG-IP's responses to it.

F5 has determined that these statistics should be removed from tmsh or WebUI as they are considered TMM internal statistics that are used to track internal failures. Therefore, they are no longer accessible for the end customer.

Environment

  • OID ltmDnsCacheStatFailureCf
  • Versions prior to v14.x
