Known Issue

This is the result of a known issue. 3-DNS contains some routines that generate debugging messages. These debugging directives are normally removed before software is released, but have not yet been removed from 3-DNS. In some cases, these routines may generate error messages when no problem is apparent. These errors may be cosmetic; however, F5 recommends that you open a case with F5 Technical Support to verify the cause of the error.

F5 Product Development tracked this issue as CR20337 and CR41886.
