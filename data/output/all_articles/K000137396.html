Description

You would like to configure your NGINX Ingress Controller with multiple host/domains.

Environment

  • NGINX Ingress Controller

Cause

None

Recommended Actions

You can create or modify the Ingress Controller ingress YAML file rules specifying each host configuration.

Example multiple host configuration:

apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
name: cafe-ingress
spec:
ingressClassName: nginx
rules:
- host: cafe.example.com
http:
paths:
- path: /tea/
pathType: Prefix
backend:
service:
name: tea-svc
port:
number: 80
- path: /coffee/
pathType: Prefix
backend:
service:
name: coffee-svc
port:
number: 80
- host: cafe.example-1.com
http:
paths:
- path: /tea/
pathType: Prefix
backend:
service:
name: tea-svc
port:
number: 80
- path: /coffee/
pathType: Prefix
backend:
service:
name: coffee-svc
port:
number: 80
- host: barista.example.com
http:
paths:
- path: /barista/
pathType: Prefix
backend:
service:
name: tea-svc
port:
number: 80
