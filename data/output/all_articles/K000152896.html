Description

For example in TMM vulnerability CVE-2025-21087 mentions "When Client SSL or Server SSL profiles are configured on a virtual server, or Domain Name System Security Extensions (DNSSEC) signing operations are in use, undisclosed traffic can cause an increase in memory and CPU resource utilization." What is the meaning of "undisclosed traffic" in Security Advisory articles?

Environment

  • Security Advisory article

Cause

None

Recommended Actions

What we meant by "undisclosed traffic" is that we are not disclosing or sharing the details of the exact nature of the traffic because the information could potentially allow an attack to exploit the vulnerability. Basically for security reason it is standard practice to avoid providing attackers with specific information that could be used to exploit the vulnerability.
