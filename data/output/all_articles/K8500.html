K8500: Users are redirected to the Administrative Console logon page

Topic

Users may be redirected to the FirePass Administrative Console when they attempt to logon to the FirePass webtop using a URL similar to the following example:

https://firepass.siterequest.com

The FirePass Administrative Console URL will appear similar to the following example:

https://firepass.siterequest.com/admin/

This behavior occurs when user logon is not enabled for the web service.

Important: Users cannot logon to the webtop using the Administrative Console logon page.

To enable user logon for a web service, perform the following procedure:

  1. Logon to the FirePass Administrative Console.
  2. Navigate to the Device Management: Configuration: Network Configuration page.
  3. Click the Web Services tab.
  4. Click the Configure link next to the web service you want to configure.
  5. Select the User Logon check box.
  6. Click the Update button.
  7. Click the Finalize tab.
  8. Click the Finalize Changes button.
  9. Click the Apply Changes and Restart button.
  10. Click the Restart button.
