Known Issue

The Citrix XenApp template will fail to save if the password contains an exclamation point (!).

Impact

You are unable to create a Citrix APM policy using the XenApp template.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Clicking Finish in the XenApp template generates the following error message:

    Bad Characters. Only the following special characters are allowed: period,
    asterisk, forward slash, dash, colon, underscore, question mark, equals, at
    sign, comma, ampersand and space (.*/-:_?=@,& )

Resolution

Status

F5 Product Development has assigned ID 373274 to this issue, and has confirmed that this issue exists in the products listed in the Applies To box. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles
Release11.0.0K2200: Most recent versions of F5 software
HotfixNoneNone

Workaround

To work around this issue, you can use an account to access the Citrix server that does not contain an exclamation point.
