K000140018: Not able to access rSeries management IP through GUI/CLI (ICMP Destination unreachable), but ping works

Published

Applies to

Source

Description

Cannot access the rSeries appliance's management IP through HTTPS or SSH, but ping works.

Management IP returns ICMP Destination unreachable (Port unreachable) in response to TCP SYNs.

Environment

  • rSeries
  • Management access

Cause

An allowed-ips entry exists which blocks access from all other sources.

For example:

system allowed-ips allowed-ip snmpmgr
 config ipv4 address 10.10.10.50
 config ipv4 prefix-length 32
!

Recommended Actions

You need to either configure additional allowed-ips entries, or modify the existing entries.

In the example given above, the entry was intended for SNMP access (port 161), which is disabled by default. If this entry was modified to include port 161, access from all other clients would not be blocked.
