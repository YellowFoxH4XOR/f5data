You can configure the BIG-IP ASM system to send forensics data to a remote syslog server. To do so, perform one of the following procedures depending on the software version running on your BIG-IP ASM system:

Note: The Logging Profile configuration option was introduced in BIG-IP ASM 9.4.3. Using this feature is often preferred over performing the following procedure, as it is a much more flexible option. For more information, refer to the Configuring the logging profile for a web application section of the Configuration Guide for BIG-IP Application Security Management.

Note: For information about configuring the BIG-IP system to send all logging information to a remote syslog server, refer to K5527: Configuring BIG-IP to log to a remote syslog server.

BIG-IP ASM 9.4.2

  1. Log in to the command line.
  2. Use the following bigpipe command syntax:

    Note: The following bigpipe command should be entered as a single command and should not contain line breaks.

    bigpipe syslog include '"destination d_asm { file(\"/var/log/asm\" create_dirs(yes));}; destination loghost { udp(\"w.x.y.z\" port(514));}; log { source(local); filter(f_local3); destination(d_asm); destination(loghost);};"'

    For example, if the IP address of the remote syslog server is 10.0.0.1, the bigpipe syntax would be the following:

    bigpipe syslog include '"destination d_asm { file(\"/var/log/asm\" create_dirs(yes));}; destination loghost { udp(\"10.0.0.1\" port(514));}; log { source(local); filter(f_local3); destination(d_asm); destination(loghost);};"'
  3. Type the following command to save the configuration:

    bigpipe save all
  4. Type the following command to restart syslog-ng:

    bigstart restart syslog-ng

BIG-IP ASM 9.2.0 through 9.4.1

  1. Log in to the BIG-IP ASM command line.
  2. Back up the original /etc/syslog-ng/syslog-ng.conf file by typing the following command:

    cp /etc/syslog-ng/syslog-ng.conf /etc/syslog-ng.conf.bak
  3. Using a text editor, edit the /etc/syslog-ng/syslog-ng.conf file.
  4. Locate the following section:

    # local3.* /var/log/asm
    filter f_local3 {
    facility(local3) and level(info..emerg);
    };
    destination d_asm {
    file("/var/log/asm" create_dirs(yes));
    };
    log {
    source(local);
    filter(f_local3);
    destination(d_asm);
    };
  5. Replace the above section with the following:

    # local3.* /var/log/asm
    filter f_local3 {
    facility(local3) and level(info..emerg);
    };
    destination d_asm {
    file("/var/log/asm" create_dirs(yes));
    };
    destination loghost {
    udp("w.x.y.z" port(514));
    };
    log {
    source(local);
    filter(f_local3);
    destination(d_asm);
    destination(loghost);
    };
  6. Under the destination loghost section, substitute w.x.y.z with the IP address of the remote syslog server.
  7. Save the file.
  8. Restart the syslog-ng utility by typing the following command:

    bigstart restart syslog-ng
