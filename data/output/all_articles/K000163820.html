K000163820: What is the SNMP OID to view self IP address from all Route Domains?

Description

  • When you use these two OID 1.3.6.1.2.1.4.20.1.2 or 1.3.6.1.2.1.4.34.1.3, you only get information of self IP address from Route Domain (RD) 0 and management IP address.
  • You would like to know SNMP OID SNMP OID to view self IP address from all Route Domains.

Environment

  • BIG-IP
  • SNMP
  • Multiple Route Domains (RD)

Cause

None

Answer/Recommended Actions

This .1.3.6.1.4.1.3375.2.1.2.8.1.2.1.2 OID will give you output of self IP address from all Route Domain but it will be HEX string. To view the binary version of it run below command. 

snmpwalk -m ALL -v2c -c public <Enter the IP address of the BIG-IP or if you are running in BIG-IP itself then you can mention "localhost"> sysSelfIpTable | awk '
/sysSelfIpAddr/ {
name=$1
split($0, a, "= Hex-STRING: ")
hex=a[2]
n=split(hex, b, " ")
if(n==4) printf "%s IP: %d.%d.%d.%d (RD0)\n", name, strtonum("0x"b[1]), strtonum("0x"b[2]), strtonum("0x"b[3]), strtonum("0x"b[4])
if(n==8) printf "%s IP: %d.%d.%d.%d RD:%d\n", name, strtonum("0x"b[1]), strtonum("0x"b[2]), strtonum("0x"b[3]), strtonum("0x"b[4]), strtonum("0x"b[5])*16777216+strtonum("0x"b[6])*65536+strtonum("0x"b[7])*256+strtonum("0x"b[8])
}'

Additional Information

snmpwalk -v 2c -c public localhost .1.3.6.1.4.1.3375.2.1.2.8.1.2.1.2
