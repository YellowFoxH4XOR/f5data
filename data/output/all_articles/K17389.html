Known Issue

The dnatutil utility may fail to perform reverse mapping for some IP addresses after a VIPRION P8 blade failure.

This issue occurs when all of the following conditions are met:

  • You have a multi-blade VIPRION P8 chassis.
  • Your BIG-IP system uses carrier-grade network address translation (CGNAT).
  • One of the blades in the VIPRION P8 chassis fails.
  • You use the dnatutil utility to reverse map translated subscriber IP addresses.

Impact

The dnatutil utility fails to perform reverse mapping for some IP addresses.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When comparing the output from the tmsh show sys conn command with the dnatutil utility, you notice that some subscriber IP address translations do not agree.

Workaround

To work around this issue, you can change the Large Scale NAT (LSN) pool members for LSN deterministic NAT pools to trigger a deterministic NAT data rebuild.

Impact of workaround: If possible, F5 recommends that you perform the workaround during a planned maintenance window.
