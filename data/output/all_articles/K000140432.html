K000140432: F5OS-A configuration restore error: rejected data access path /oc-platform:components/component{psu-2}

Type
Support Solution
Published
2024-07-25
Updated
2024-07-25
Applies to
  • F5OS
  • F5OS-A: 1.5.X, 1.5.2, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000140432

Description

Attempt to restore F5OS-A configuration backup to rSeries appliance fails:

appliance-1(config)# system database config-restore name backup-file
Proceed? [yes/no]: yes
Error: access denied
Database config-restore failed.

After enabling confd debug logging following K000092683, a message similar to the following is observed in /var/F5/system/log/devel.log:

confd[145]: devel-aaa User: admin[admin] rejected data access path /oc-platform:components/component{psu-2} op create due to rule "device-configuration/openconfig-component-access"

Environment

  • rSeries
  • Configuration restore (for example, after RMA)

Cause

This message indicates that the backup file contains a psu-2 component, but the appliance does not have a psu-2 present.

Recommended Actions

Either insert another PSU into the system, or remove the psu-2 component from the backup file:

# Remove these lines
<component>
  <name>psu-2</name>
  <config>
    <name>psu-2</name>
  </config>
</component>

Then attempt to restore the backup file once more.

Additional Information

Ensure confd debug logging is disabled when you finish troubleshooting.
