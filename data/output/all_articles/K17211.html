Known Issue

The BIG-IP GTM ZoneRunner utility may not log debug data.

This issue occurs when the following condition is met:

  • You modify the log level for the ZoneRunner daemon for debug logging.
  • You attempt to view ZoneRunner debug logs in the /var/log/gtm log file.

Impact

Debug data is not logged by the ZoneRunner utility in the /var/log/gtm log file.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the BIG-IP GTM log file for ZoneRunner data, there is no debug data.
  • When you modify the ZoneRunner logging level to debug, no ZoneRunner debug data is logged.

Workaround

To work around this issue for troubleshooting purposes, you can restart the Zonrunner process to force the system to log debug log data. To do so, perform the following procedure:

Impact of workaround: F5 recommends that you place ZoneRunner in the debug logging configuration only if F5 Technical Support directs you to do so.

  1. Log in to the command line of the affected BIG-IP device.
  2. Type the following command to set the ZoneRunner utility to debug.

    touch /service/zrd/debug

  3. Restart the Zonerunner process by typing the following command:

    tmsh restart /sys service zrd

    Note: The ZoneRunner process debug log is located at /var/tmp/zrd.out.

  4. To turn off ZoneRunner debug logging, type the following commands:

    rm /service/zrd/debug

    tmsh restart /sys service zrd
