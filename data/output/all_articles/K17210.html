Known Issue

The BIG-IP system deletes all of the files in the user's home directory when the admin account changes the user password.

This issue occurs when the following condition is met:

  • When the administrative account modifies the user password either using the Configuration utility or the Traffic Management Shell (tmsh).

Impact

The BIG-IP system deletes all the files in the user's /home directory.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system deletes all of the files in the user's /home directory.

    For example, all the files will be deleted for the user /home/Test when the password is modified for user Test.
