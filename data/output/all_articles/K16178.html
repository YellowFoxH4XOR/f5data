Known Issue

Traffic Management Microkernel (TMM) CPU utilization may spike when processing Client SSL connections.

This issue occurs when all of the following conditions are met:

  • The virtual server is configured with the following:
    • A Client SSL profile
    • The default persistence profile is set to ssl persistence, and fallback persistence profile is set to dest_addr or source_addr persistence
  • The virtual server processes Client SSL connections.

Impact

Some Client SSL connections are delayed or reset.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H486522 on the Diagnostics > Identified > Low | Medium | High screen.
  • Some Client SSL connections through the virtual server are delayed or reset.
  • The top command shows multiple TMM instances using a high CPU percentage.
