K000134865: SAML attribute parsing issue after upgrading to 17.1.0.1

Type
Support Solution
Published
2023-05-31
Updated
2023-05-31
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000134865

Description

During SAML Authentication while TMM parses the assertion to extract the attributes and its respective values, all the attributes values are combined into a single string with '|' as separator and are assigned to a single variable leaving remaining ones empty.

Environment

  • BIG-IP APM 17.1 or 17.1.0.1
  • BIG-IP as SAML Service Provider

Cause

This is due to the following BZID:
Bug ID 1282105: Assertion response attributes parsing issue after upgrade to BIG-IP 17.1.
This will result in a single session variable with many attributes such as the following:

May 24 12:53:58 example.local info apmd[14693]: 01490007:6: /Common/ap_profile:Common:4999a9qd: Session variable 'session.saml./Common/ap_profile_act_saml_auth_ag.attr.name.LastOTPTime' set to '| Group | Another_Group | https://example.com/authweb | 354ec1bd-38e1-1920-af81-fc042a976c84 | 1598 | https://example.com/authweb | 2598 | a014492320aes43080d7d9e7d1d3a9 | PROD | 2023-04-27T14:02:00.0

Recommended Actions

At the time of publication, please open a case with support requesting an EHF to resolve ID1282105
