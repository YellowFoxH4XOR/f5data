K000141328: Cannot connect to appliance with SSH while GUI and console are accessible

Type
Support Solution
Published
2024-11-20
Updated
2024-11-20
Source
https://my.f5.com/manage/s/article/K000141328

Description

You cannot connect to the device over SSH with any user. When trying to do so, the connection fails with a 'no route to host' message:

#ssh admin@<mgmt_IP>

ssh: connect to host <mgmt_IP> port 22: No route to host

 

However, you can ping mgmt IP and moreover, GUI and console are accessible.

Environment

  • F5OS-A
  • SSH
  • no route to host

Cause

There could be either of these reasons:

1) Incorrect prefix length

or

2) Manual changes to /etc/sysconfig/network-scripts/ifcfg-mgmt

 

Recommended Actions

1) Verify if the prefix length is correctly configured:

  • When connecting through GUI go to System Settings >> Management Interface
  • When connecting through the console port, log in as admin and run #show system mgmt-ip

system mgmt-ip state ipv4 system address <mgmt_IP>

system mgmt-ip state ipv4 prefix-length 24

system mgmt-ip state ipv4 gateway <gateway_IP>

system mgmt-ip state ipv6 system address ::

system mgmt-ip state ipv6 prefix-length 0

system mgmt-ip state ipv6 gateway ::

 

2) Verify if the IPADDR value from /etc/sysconfig/network-scripts/ifcfg-mgmt has not been modified. The default value is 0.0.0.0 and this should not be changed. 

#cat ifcfg-mgmt

TYPE=Ethernet

PROXY_METHOD=none

BROWSER_ONLY=no

BOOTPROTO=none

IPADDR=0.0.0.0

PREFIX=32

 

If the IPADDR value has been changed to something else than 0.0.0.0, this needs to be reverted. A reboot will be needed for the changes to take effect.

 

Another way to check it is by running #ip address | grep mgmt

2: mgmt: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc mq state UP group default qlen 1000

77: mgmt0-system@mgmt: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc noqueue state UP group default qlen 1000

  inet 10.10.10.10/24 brd 10.10.10.255 scope global noprefixroute mgmt0-system

'mgmt' should not have any IP address configured
