Description

  • When logged into a Virtual Clustered Multiprocessing (vCMP) guest you may not see or have access to software that has been installed on the hypervisor (host) system.

Environment

Relevant environmental factors specific to the topic

  • vCMP guest
  • vCMP Hypervisor
  • Software image

Cause

This is is the result of the TMUI redirect-http-to-https being enabled.

Recommended Actions

This issue can be worked around by disabling the redirect-http-to-https setting with the following command;

  1. Log in to the TMOS shell (tmsh) by typing the following command:
    tmsh
  2. Type the following command:
    modify sys httpd redirect-http-to-https disabled
  3. Save the configuration by typing the following command:
    save /sys config
    NOTE: This will need to be done on both systems if your system is part of a HA pair.
