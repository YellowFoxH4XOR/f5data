K8360: The IP address for a central or remote WebAccelerator system cannot have a 0 (zero) as one of the octets

Known Issue

This is the result of a known issue. When you attempt to create a central or remote WebAccelerator system using a 0 (zero) as one of the octets in the IP address, the WebAccelerator will not be created. Additionally, the Configuration utility will display the following error message:

There was 1 error. The Accelerator was not saved.
(1) The field IP Address must contain a valid IP address

For example, the following IP addresses will fail:

192.168.10.0
192.168.0.10
10.0.10.10
0.10.10.10

F5 Networks Product Development tracked this issue as CR91229 and it was fixed in Webaccelerator version 9.4.5. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.3-HF3 issued for BIG-IP version 9.4.3. You may download this hotfix or later versions of the Hotfix from the F5 Networks Downloads site.
