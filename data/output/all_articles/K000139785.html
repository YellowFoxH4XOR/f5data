Description

Users may notice ASM has blocked genuine requests after updating the latest attack signatures. The traffic might be impacted for new user agents. 

Environment

  • BIG-IP ASM
  • Android's Dalvik user agent
  • Windows's RestSharp user agent
  • Attack Signatures
  • Bot Defense 

Cause

Issue is due to new user agents. ASM BOT defense blocking them as Untrusted BOT category.

Recommended Actions

As a workaround, Validate the new user agents with the application team to confirm if the requests are genuine and if they are coming from new user agents or not. Accordingly, we can add an exception in the below path in GUI 

Impact of workaround:  Performing the below procedure will not impact any BOT traffic

  •  Navigate to Security ›› Bot Defense ›› Bot-Defense Profiles >> Select the desired profile.
  • Go to Bot Mitigation Settings & then select Mitigation Settings Exceptions.
  • Click on Add Exceptions & search for Dalvik as well as RestSharp.
  • Check on the box & click on ADD in the results of the Search.
  • Now you can select either Alarm or None or CAPTCHA etc from drop-down options for the earlier selected user agents.
  • Click on Save in the Bot Profile.
  • Check & validate that the users can access the website now.
