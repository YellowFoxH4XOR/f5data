K3692: Reasons why you may receive an error when I trying to load a configuration after I upgrading to BIG-IP or 3-DNS version 4.5.11, 4.6.3, or later versions

Topic

Starting in version 4.5.11, BIG-IP uses a new configuration file to store static routes.

When you upgrade to version 4.5.11, the process attempts to convert any existing /config/routes file into the new format. If the process fails, the system will continue to use your existing /config/routes file; however, it will display the following error messages each time you load the configuration:

Warning: Old style config file (/config/routes) exist!
Warning: Please remove it and enter static routes to /config/static_routes
Warning: or contact F5 support for assistance.
Warning: Executing /config/routes
Warning: Errors may be displayed

If you receive an error message, you must manually convert your /config/routes files to the new format.

For more information, refer to K3687: Managing static routes.
