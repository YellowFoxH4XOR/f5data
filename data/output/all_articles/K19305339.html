Known Issue

The BIG-IP system fails to include the /etc/openldap/ldap.conf file in the user configuration set (UCS) archive file.

This issue occurs when the following condition is met:

  • You perform a UCS backup.

Files that are included during a UCS backup are defined in the /usr/libdata/configsync/cs.dat file. Since the /etc/openldap/ldap.conf file was not defined in the /usr/libdata/configsync/cs.dat file, the BIG-IP system will not save the file to the UCS archive file.

Impact

Customizations you made to the /etc/openldap/ldap.conf file will be lost after you perform a UCS restoration or a software upgrade.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • If you have disabled Lightweight Directory Access Protocol (LDAP) referrals by performing the procedure in K17311: Globally disable use of LDAP referrals for the BIG-IP system, your change is not saved after performing a UCS restoration or a software upgrade.

Workaround

To work around this issue, you can define an entry for the /etc/openldap/ldap.conf file in the /usr/libdata/configsync/cs.dat file manually before performing a UCS backup or a software upgrade. To do so, refer to K4422: Viewing and modifying the files that are configured for inclusion in a UCS archive.

Impact of workaround: The suggested procedure should not impact BIG-IP traffic processing; however, F5 recommends that you perform this procedure only during a maintenance window.
