Topic

The FirePass controller can act as a proxy for Microsoft's ActiveSync protocol. Pocket PC, smartphone and similar personal data assistant (PDA) hardware that run supported versions of Windows Mobile software can synchronize with a Microsoft Exchange server by connecting through the FirePass controller. The following information will allow you to configure your FirePass controller to securely proxy ActiveSync connections over an SSL connection.
 
Note: While many other applications or devices that use ActiveSync (such as Lotus Notes Traveler) have not been fully vetted, they may be usable with the same settings that are outlined in this Solution.

Note: For supported versions of Windows Mobile software, refer to the FirePass Release Notes.

Prerequisites

  • Microsoft Exchange server with:

    • ActiveSync enabled and configured
    • Basic Authentication enabled on the ActiveSync virtual server or virtual directory
  • FirePass version 5.5 or later version, or version 5.4.2 of FirePass software with hotfix HF-51046-53333-54861-1
  • Identical usernames and passwords for ActiveSync users on both the FirePass controller and the Exchange server, or the ActiveSync users' master groups configured to use external users, authenticating to the Active Directory for the Exchange server
  • A valid SSL server certificate installed on the FirePass HTTPS web service used by the ActiveSync client

Note: In this context, a valid SSL server certificate is one that does not generate any certificate warnings when you access the SSL- encrypted website using a web browser that is configured to display certificate warnings.

Note: If you do not have a valid SSL server certificate, you can configure a non-SSL web service on the FirePass controller and use this service to perform ActiveSync. However, the communication will be completed without encryption, so you should understand the security implications and your organization's security policy before using this configuration. For more information, refer to K9225: Allowing HTTP web services on the FirePass Controller.

Configuring the FirePass controller for ActiveSync

To configure the FirePass controller for ActiveSync, perform the following two procedures:

  • Configuring an ActiveSync Landing URI

  • Configuring master groups for ActiveSync access

Note: For information about configuring your Exchange server and ActiveSync services, consult the Microsoft documentation for your Exchange server.

Note: For information about configuring your client, consult the documentation from the vendor of your Pocket PC, smartphone, or similar device.

Configuring an ActiveSync Landing URI

To configure an ActiveSync Landing URI, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Click Device Management.
  3. Click Customization.
  4. Click the URI-based Customization tab.
  5. Type Microsoft-Server-ActiveSync in the New Landing URI field.

    Note: The string Microsoft-Server-ActiveSync is not an arbitrary string; do not substitute a different string.

  6. Select the ActiveSync Authentication option button.
  7. Click the Apply button.

Configuring master groups for ActiveSync access

The following configuration creates a pattern-based proxy bypass to the Exchange server for ActiveSync connections, using the string in the previous configuration section as the pattern base. Each master group that will provide ActiveSync access to its users must be configured with this bypass.

To configure a master group for ActiveSync access, perform the following procedure:

  1. Click Portal Access.
  2. Click Web Applications.
  3. Click Master Group Settings.
  4. Select the master group from the Master Group drop-down menu at the top of the page.
  5. Under the Minimal Content-Rewriting Bypass section, in the Comma separated list of patterns field, under the Pattern-based section, type the following string:

    /Microsoft-Server-ActiveSync*
     

    Important: The string must be entered without additional whitespace on either side.

  6. Under the Minimal Content-Rewriting Bypass section, type the base URL for the ActiveSync virtual directory. The base URL is the protocol specification, either http:// or https:// followed by the hostname or fully-qualified domain name.

    For example:

    http://exchange.siteconfig.com

    Important: The ActiveSync virtual server or virtual directory must be enabled for HTTP basic authentication. For more information about configuring Directory Security Authentication and Access Control on virtual servers and directories, consult the documentation for Microsoft IIS Manager.

  7. Click the Add button.
  8. Ensure that the Exchange server URL is specified in the Allow list: under the Access Control Lists section. or alternatively that the Default action: drop-down menu is set to Allow.
  9. Ensure that the Show Administrator favorites check box under the Access limitation section is not selected.
    Note: If you are running FirePass version 6.0.2 with cumulative HF-602-11 or later, refer to K10154: ActiveSync fails when the 'Show administrator-defined favorites only' option is enabled for the user's master group.

Repeat these steps for each master group that will provide ActiveSync access.

Additional Steps

Ensure that the Block non-HTML data (file downloads, doc and pdf attachments) check box on the Global Settings tab of the Portal Access: Web Applications: Contentent Processing page is not selected.

Note: For more information, consult the FirePass online help located in the Device Management: Customization: Global: ActiveSync section.
