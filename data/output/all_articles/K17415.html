Known Issue

Responses from the DNS transparent cache may contain RRSIG records.

This issue occurs when the following condition is met:

  • Your system's DNS transparent cache receives a DNS query without the DO bit set.

    Note: When a cache miss for a DNS query is answered by the pool member, the response may contain RRSIG records.

Impact

DNS responses may contain unnecessary resource records (RR) sets that are not RFC-compliant.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The DNS transparent cache may include RRSIG records in the responses for queries without the DO bit set.
