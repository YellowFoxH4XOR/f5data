Known Issue

Note: The Enterprise Manager versions listed in the Applies To box do not currently support BIG-IP version 11.0.0.

This is the result of a known issue. When Enterprise Manager version 2.0.0 through 2.2.0 manages a BIG-IP ASM version 10.1.0 through 10.2.3 system, the Enterprise Manager Device List may list the BIG-IP ASM status as impaired.

Log messages that appear similar to the following example will be displayed in the /var/log/em file on the Enterprise Manager device:

04012002:3: Encountered fatal error message Invalid document structure during DOM parsing of XConfig::XML in line 1 and column 1
0402010f:3: EX! DeviceConfig.cpp:246::getDisplayableXMLText:f5em::XmlException Unable to set displayable data 'XML parsing failure == (f5em::XmlException) Stack trace: [ 1: /usr/lib/libf5util.so [0xf7e72ffb]; 2: /usr/lib/libf5util.so(TraceableException::TraceableException()+0x47); 3: /usr/bin/emdeviced(f5em::EMException::EMException(std::string const&)+0x1e); 4: /usr/lib/libem.so(f5em::XmlException::XmlException(std::string const&)+0x24); 5: /usr/lib/libem.so(f5em::DeviceConfigInstance::getDisplayableXMLText(std::string const&)+0x7e4); 6: /usr/lib/libem.so(f5em::DeviceConfigInstance::setData(std::string const&, bool)+0x180); 7: /usr/lib/libem.so(f5em::DeviceUtil::getConfigInfo(f5em::Device&, f5em::DeviceUtil::ConnectionInfo const&, std::string const&)+0x3274); 8: /usr/lib/libem.so(f5em::DeviceUtil::retrieveInfo(f5em::Device&, std::string const&)+0x166b); 9: /usr/lib/libem.so(f5em::RefreshUtil::refreshDevice(unsigned int, std::string const&, f5em::Device&)+0x7cf); 10: /usr/bin/emdeviced [0x812560f]; 11: /usr/bin/emdevice

F5 Product Development tracked this issue as ID 335744 (formerly CR136286), and it was fixed in BIG-IP versions 10.2.1 and 11.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.

This issue has been fixed in a hotfix. To request the hotfix, contact F5 Technical Support, referencing this article number and the associated ID numbers.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.
