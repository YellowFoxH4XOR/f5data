Topic

With the different techniques available for BIG-IP WOM, it is important to understand that turning on all available optimizations in every situation will not necessarily provide the best performance gains. You must take several considerations into account when determining the best set of optimizations to use for any given situation.

Symmetric data deduplication is one of the techniques used for BIG-IP WOM. Selection of memory or disk mode for symmetric data deduplication is dependent on the hardware platform and BIG-IP WOM link speed. The symmetric data deduplication technique is also dependent on the nature of the data, the protocol, and the network; therefore, a detailed understanding of these factors is required before implementing BIG-IP WOM.

F5 recommends the following guidelines for symmetric data deduplication configuration in data center-to-data center deployments:

  • Use the Memory mode setting for symmetric data deduplication with BIG-IP WOM connection speeds greater than 10 Mbps.
  • Use the Disk mode setting for symmetric data deduplication with BIG-IP WOM connection speeds up to 10 Mbps.              

    Note: For more information, refer to the BIG-IP WOM product documentation.
