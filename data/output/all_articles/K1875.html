Topic

To configure multiple default gateways, perform the following steps.

  1. Create a pool that contains as its members the IP addresses of the routers that the BIG-IP or 3-DNS will use as gateways.

    Important: For BIG-IP Controllers, F5 Networks recommends that the members of this new pool are in the same subnet and that they have the same MTU. For BIG-IP Link Controllers these members will most likely be on different subnets, but they should still have the same MTU if possible.

  2. Configure the pool you created as the Default Gateway Pool through the Configuration utility or the command line using the following instructions.

Configuration utility

To configure the pool the Default Gateway Pool using the Configuration utility, perform the following steps:

  1. From the Configuration utility menu, click Systems.
  2. Click the Properties tab.
  3. From the drop-down box next to Default Gateway Pools, choose the pool you created.

Command line

To configure the pool the Default Gateway Pool using the command line, type the following command:

bigpipe default_gateway use pool <pool name>

The BIG-IP or 3-DNS Controller will now use the available nodes in the pool you created as the network default gateway for load-balanced, outbound traffic.
