Description
BIG-IP virtual server processing UDP traffic with rate shaping starts dropping all packets.

Environment

  • BIG-IP LTM
  • fastL4 with idle timeout set to 0 (zero)
  • UDP
  • Rate shaping
  • Rate shaping ceiling rate reached

Cause
Bug ID 1067025

Recommended Actions

Configure the fastL4 profile to use an idle timeout value greater than 0 (zero).
