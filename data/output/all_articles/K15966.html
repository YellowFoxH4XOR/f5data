Known Issue

The Fast HTTP Assertion "flow in use" failed error message causes the Traffic Management Microkernel (TMM) to restart and produce a core file.

This issue occurs when the following condition is met:

  • You have configured a virtual server with a Fast HTTP profile.

This issue occurs as a result of an infrequent race condition that can occur when a Fast HTTP connection is closing.

Impact

The BIG-IP system may temporarily fail to process traffic while the TMM restarts. If you have configured the system as part of a high-availability system, the device may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H499708 on the Diagnostics > Identified > Medium|High screen.
  • The BIG-IP system unexpectedly fails over to another system in the device group.
  • The BIG-IP system temporarily fails to process traffic.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system logs an error message to the /var/log/tmm file that appears similar to the following example:

    notice panic: ../base/flow_table.c:631: Assertion "flow in use" failed.

Workaround

To work around this issue, you can configure the virtual server to use the HTTP and OneConnect profiles instead of the Fast HTTP profile.

Impact of workaround: Performance may be impacted, depending on your specific environment.
