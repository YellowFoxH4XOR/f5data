K45912545: Configuring Authorization with LDAP Groups

Type
Support Solution
Published
2022-07-06
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K45912545

Description
BigIQ can assign user roles to specific LDAP groups so that its members inherit the permissions described in the role when logging into the system.

Environment

  • BIG-IQ with a working LDAP Auth Provider configured.

Cause
N/A

Recommended Actions

  1. Navigate to System > User Management > Auth Providers in order to configure group membership information
  2. The following steps are mutually exclusive and only one of the two parameters (Group Membership Filter or Group Membership User Attribute) should be used and the other should remain empty.
    1. If your LDAP schema contains membership information in the User Object:
      • Edit Group Membership User Attribute and write down the name of the attribute that stores such information. 
    2. If your LDAP schema contains user information in the group object:
      • Edit Group Membership Filter and write down the search filter that will be used to retrieve the list of groups for which the authenticated user is member.

        Note: Two special tokens can be used in this Group Membership Filter, {username} and {userDN}. The first token will be substituted for the exact string that has been entered in the GUI username field, whereas the second token will be substituted for the full Distinguished Name of the authenticated user. A common filter that should work in most of the LDAP schemas is "(|(member={userDN})(uniqueMember={userDN}))"

Additional Information
For more information about configuring LDAP to communicate with BIG-IQ see https://techdocs.f5.com/en-us/bigiq-8-1-0/authentication-roles-and-user-management/ldap-user-authentication.html
