Policy Information

Summary

Common Criteria Certification for BIG-IP 12.1.3.4

Description

CSEC has certified BIG-IP LTM and AFM 12.1.3.4 for Common Criteria against the Firewall collaborative Protection Profile 1.0, and BIG-IP LTM and APM 12.1.3.4 for Common Criteria against the Network Device collaborative Protection Profile 1.0. For more information about the Security Target and related information, refer to the following CSEC website:

  • BIG-IP LTM+AFM
  • BIG-IP LTM+APM

Common Criteria is an international initiative to standardize security functionality and assurance measures. For more information about Common Criteria Certification, refer to the following Common Criteria website:

http://www.commoncriteriaportal.org

Note: This document, along with the Common Criteria Guidance Supplement, provides guidance on the secure installation and secure use of the Target of Evaluation (TOE) for the evaluated configuration. These documents provide clarifications and changes to the standard documentation and should be used as the guiding documents for the configuration and administration of the TOE in the Common Criteria evaluated configuration. Official product documentation should be referred to and followed only as directed within these guiding documents.

Installation

To install the BIG-IP system in accordance with the evaluation's expectations, refer to the following document in the document ISO:

  • Guidance Supplement: AGD_PRE and AGD_OPE

This document contains information to ensure that you have the correct software version of the BIG-IP system and describes how to configure that system to be Common Criteria-compliant. This document is included in the ISO described below.

Product Documentation

The following ISO files contain the product and guidance documentation for the 12.1.3.4 Common Criteria evaluation:

  • CommonCriteriaDocumentation-12.1.3.4.iso - F5 Downloads
  • CommonCriteriaDocumentation-12.1.3.4.iso.sha256 - F5 Downloads

To verify the ISO file against the checksum, use the following Linux sha256sum command with the -check option:

sha256sum –check CommonCriteriaDocumentation-12.1.3.4.iso.sha256
