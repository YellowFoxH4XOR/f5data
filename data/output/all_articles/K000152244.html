Topic

This article discusses BIG-IP APM F5 Access for Android incompatibility with 16KB Page Size Support (Future Support Planned)

Description

This article addresses a current incompatibility issue where the F5 Access application for Android devices does not function correctly on devices or operating system configurations that utilize a 16KB (kilobyte) page size. This can manifest as connection failures, application crashes or errors can be visible during app launch, or general instability when attempting to establish a VPN connection through F5 Access.

Some newer Android devices or custom ROMs may be configured with a 16KB page size.

F5 is actively working on incorporating support for 16KB page sizes in a future release of the F5 Access for Android application.

Conditions

This issue specifically impacts Android devices where the underlying system's memory page size is set to 16KB. Users with devices utilizing the standard 4KB page size (which is the vast majority of Android devices) will not experience this particular incompatibility.

To determine your device's page size, it typically requires technical knowledge or specific diagnostic tools. Generally, if you are experiencing connectivity issues with F5 Access on a newer device or a device running a custom ROM, this could be a contributing factor.

Availability

Currently, F5 Access for Android does not support 16KB page sizes.

F5 is committed to providing this support in a future release of the F5 Access for Android application. We do not have a specific release date to announce at this time, but customers are encouraged to monitor the Google Play Store for updates to the F5 Access app

Recommendations

At this time, there is no workaround within the F5 Access application itself to enable compatibility with 16KB page sizes.

Additional Information

Important: F5 does not recommend or support running third-party procedures. However, if you must, you should run the command on a test device.

To display the pagesize of on an Android device, you can execute the following command:

Note: To execute the following command, refer to the google documentation to enable developer options in the Android device

adb shell getconf PAGE_SIZE

This command returns 4096 (for 4KB) or 16384 (for 16KB).
