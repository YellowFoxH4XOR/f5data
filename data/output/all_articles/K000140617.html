Description

When installing a fibre optic module on your F5OS system, you should verify that it is supported on the platform.

Environment

  • Velos hardware platforms
  • rSeries hardware platforms

Cause

You need to install a optics hardware module on your system

Recommended Actions

To verify that you are installing the correct optics hardware module on your F5OS system, F5 recommends the following:

  • Verify the information on the optics label. For example, verify the following information from the labels below:
    Note: the difference in the revision numbers.
    • This identifies the module as OPT-0054-01 Innolight (Rev ‘R1A’).
      • Optics number: OPT-0054-01
      • Vendor oui: 447c7f
      • Revision number: R1A
         

        Display the optic modules connected by entering the following command on the  F5OS management CLI, confD:

        show portgroups portgroup

        You may observe an output similar to the following when OPT-0054-01 Innolight (Rev ‘R1A’) is connected:

        [..] 
        state vendor-name "F5 NETWORKS INC."
         state vendor-oui 447c7f
         state vendor-partnum "OPT-0054        "
         state vendor-revision 1A
         state vendor-serialnum "<your serial number> "
         state media      25GBASE-LR
         state optic-state QUALIFIED
        [...]

    • This identifies the module as OPT-0054-01 Finisar Rev ‘RA1’).
      • Optics number: OPT-0054-01
      • Vendor oui: 009065
      • Revision number: RA1
         

        Display the optic modules connected by entering the following command on the  F5OS management CLI, confD:

        show portgroups portgroup

        You may observe an output similar to the following when OPT-0054-01 Finisar (Rev ‘RA1’) is connected:

        [..] 
        state vendor-name "F5, INC."
         state vendor-oui 009065
         state vendor-partnum "OPT-0054        "
         state vendor-revision A1
         state vendor-serialnum "<your serial number> "
         state media      25GBASE-LR
         state optic-state QUALIFIED
        [...]

  • For more information on the optics, such as the specification, and supported hardware platform, refer to
    K6097: Specifications of the Fiber Gigabit Ethernet SFP, XFP, SFP+, QSFP+, and QSFP28 module ports on BIG-IP system platforms
