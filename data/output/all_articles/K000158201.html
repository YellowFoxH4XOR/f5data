Description

When creating a GSLB server using the BIG-IP DNS Configuration Utility (GUI), the device name associated with the server is automatically created and its name cannot be specified or modified. When using the CLI (tmsh), administrators can specify or change the device name for GSLB server. This is a limitation in the GUI design.

Environment

  • BIG-IP DNS

Cause

The Configuration Utility (GUI) does not provide an option to set or change the device name for GSLB server, while the CLI does.

Recommended Actions

  • Use CLI (tmsh) to create GSLB servers if custom device naming is required:
    Example command:

    #tmsh create gtm server <server_name> addresses add { <ip_address> { device-name <desired_device_name> } } virtual-servers add { <vs_name> { destination <ip_address>:<port> } } product generic-host datacenter <datacenter_name>

  • To modify an existing Generic Host's device name, use:
    #tmsh modify gtm server <server_name> devices replace-all-with { <new_device_name> { addresses replace-all-with { <ip_address> } } }
