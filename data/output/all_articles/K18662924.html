Description

SSLO Guided Configuration is in read-only mode with the following message in the GUI: SSL Orchestrator ›› Configuration

This BIG-IP configuration is currently being managed by the BIG-IQ and is read-only

This is true even if BIG-IQ is not managing the configuration.

Environment

  • BIG-IP
  • BIG-IQ
  • SSLO

Cause

ID939193

Recommended Actions

Download the new SSLO package from F5 website. For the version 15.1.10, it is f5-iappslx-ssl-orchestrator-15.1.0-7.7.20.noarch.rpm from F5 download page for SSLO 15.1.9, it contain the fix for this issue. If the BIG-IP SSLO version is not compatible with this RPM package, please raise a service request to F5.

Once the RPM with a fix has been acquired, install it on the BIG-IP:

  1. Click iApps -> Package Management LX.
  2. Click on Import and select the RPM.
  3. Click Upload. This will install the selected RPM on the box.
  4. Verify the new SSLO package has been installed with expected version.


The Workaround provided in the RPM means that you can disable read-only mode following the below steps:

To *disable* SSLO GUI's read-only mode, change the local BIG-IP monitor pool member value to 'Force Offline'

  1. Browse to Pool Member location – Local Traffic > Pools > sslo_bigiqMonitor > Members
  2. Change the BIG-IQ monitor pool member value to 'Force Offline'

To *re-enable* SSLO GUI's read-only mode, switch it back to 'Enable'
