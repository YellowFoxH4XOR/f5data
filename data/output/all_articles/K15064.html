Known Issue

Some hardware platforms may not display valid platform names when queried using SNMP.

This issue occurs when the following condition is met:

  • You are using one of the following BIG-IP hardware platforms:

    • 2000s, 2200s, 4000s, 4200v, 10000s, 10200v

Impact

SNMP monitoring applications that query platform names may receive an unknown platform name.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • An SNMP query of the platform name will result in an unknown platform name.

    For example, you run the following SNMP query from the local BIG-IP host:

    snmpget -c public localhost .1.3.6.1.2.1.1.2.0

    The output displays similar to the following example:

    MIB::sysObjectID.0 = OID: F5-BIGIP-SYSTEM-MIB::unknown
