Issue

The switchboot command enables you to view and modify boot partition information on the BIG-IP system. When the grub_open command is run, a lock file is created to prevent other users or processes from making changes concurrently. If the grub_close command is not run after the grub_open command, running the switchboot command will result in the following error message:

ERROR: Failed to find active image location

You can prevent this error message from occurring by closing the grub.conf file and removing the lock file after running the grub_open command and before running the switchboot command. To close the configuration file and remove the lock file, type the following command at the command line:

grub_close

When the command prompt returns, you can run the switchboot utility.

Note: For more information about the switchboot command, refer to K5658: Overview of the switchboot utility.
