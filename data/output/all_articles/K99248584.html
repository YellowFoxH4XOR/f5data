K99248584: There seems to have been a slight problem with the BIG-IP® Application Security Manager database.

Type
Support Solution
Published
2023-04-07
Updated
2023-04-07
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.0.1
Source
https://my.f5.com/manage/s/article/K99248584

Description

You are encountering an error message when applying the ASM policy. The message states: "There seems to have been a slight problem with the BIG-IP® Application Security Manager database. Please try again by pressing the refresh button in your browser. We apologize for any inconvenience." Additionally, you are unable to view the ASM event logs. You found an error message in the /var/lib/mysql/mysqld.error file or during the mysqlcheck command output.

Environment

  • ASM/AVR provisioned

Cause

This issue is caused by Bug ID 947341

Recommended Actions

Performing these actions should not have a negative impact on your system.
Note: This workaround does not survive an upgrade. It must be reapplied after every upgrade until the upgraded version contains a fix.

  1. Increase 'open_files_limit' to '10000':

    • In the /etc/my.cnf file, change the value of the 'open_files_limit' parameter to 10000.
    • Restart MySQL by running the following command:  
      bigstart restart mysql

  2. Run the following command:

    pkill asmlogd

     

After completing these steps, you should no longer encounter the error message when applying the ASM policy.
