K000152717: Unsuccessful Response Codes Panel in NGINX One Console Shows "No Data Found" Despite 4xx Errors in NGINX Log

Description

The "Unsuccessful Response Codes" dashboard in F5 Distributed Cloud Console may display a "No Data Found" message, even when HTTP 4xx errors (such as 404) are confirmed in NGINX Plus logs. This occurs despite regular traffic generating unsuccessful response codes, resulting in the dashboard not reflecting these errors.

Environment

  • F5® Distributed Cloud
  • F5 NGINX One Console
  • NGINX Plus

Cause

This issue is caused by the absence of the status_zone directive within the relevant location block(s) in the NGINX configuration. Without this directive, NGINX does not collect or expose the necessary status metrics required for the dashboard to display unsuccessful response codes.

Recommended Actions

To resolve this issue and enable visibility of HTTP 4xx/5xx metrics on the "Unsuccessful Response Codes" panel:

1. Edit your NGINX configuration to include the status_zone directive inside each relevant location block.
Example:

server {
    listen       80 default_server;
    server_name  localhost;
 
    access_log  /var/log/nginx/host.access.log  main;
 
    location / {
        status_zone test_zone; #<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<< Add this line
        root   /usr/share/nginx/html;
        index  index.html index.htm;

2. Reload or restart NGINX after making configuration changes.

3. Confirm that unsuccessful response codes are now visible on the dashboard.

Additional Information

Make sure that NGINX Plus API is enabled.

The panel should look like this once the status_zone directive is added.
