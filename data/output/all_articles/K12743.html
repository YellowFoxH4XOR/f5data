Known Issue

This is the result of a known issue. If an Apple iOS Edge Client user with multiple connection configurations saves changes to a configuration other than the active configuration, the graphs located on the Statistics tab stop showing current information. The graph will stop moving and will not start again until the application is closed and re-opened.

Note: This is a cosmetic issue only; it will not affect the active session.

F5 Product Development tracked this issue as ID 347168 and this issue was fixed in BIG-IP Edge Client version 1.0.1. You can download BIG-IP Edge Client version 1.0.1 from iTunes. For more information, refer to the iTunes F5 BIG-IP Edge Client website.

Workaround

To re-engage the Statistics graph, the user can close and re-open the Apple iOS Edge Client application.
