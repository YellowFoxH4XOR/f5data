Topic

The 3dpipe command displays information about the following:

  • Datacenters
  • Wide IPs
  • Devices
  • Virtual servers
  • Synchronization groups
  • Statistics

Important: The 3dpipe command is case sensitive. When you use a configuration object name in a 3dpipe command, use the same case that you specified in the Configuration utility or wideip.conf file.

Datacenters

You can view the following information for a datacenter with the 3dpipe command:

  • Configured datacenters
  • Enabled/Disabled status for datacenters

Configured datacenters

To display all configured datacenters, type the following command:

3dpipe datacenter show

This will display the main configuration stanza from the wideip.conf file for each datacenter, including the name, location, and contact information.

Enabled/Disabled status for datacenters

To display the status (enabled or disabled) for a datacenter, use the following command syntax:

3dpipe datacenter <datacenter> status

Replace <datacenter> with the name of the datacenter.

For example:

3dpipe datacenter Main status

Wide IPs

You can view the following information for a wide IP with the 3dpipe command:

  • Configured wide IPs
  • Enabled/Disabled status for wide IPs
  • Associated pools
  • Enabled/Disabled status for wide IP pools
  • Availability status for wide IP pools
  • Wide IP pool virtual servers and their status
  • Enabled/Disabled status for a wide IP of a specific datacenter

Configured wide IPs

To display all configured wide IPs, type the following command:

3dpipe wideip show

This will display the main configuration stanza from the wideip.conf file for each wide IP, including the wide IP name and status.

Enabled/Disabled status for wide IPs

To display the status (enabled or disabled) for a wide IP, use the following command syntax:

3dpipe wideip <wideip> status

Replace <wideip> with the wide IP's fully qualified domain name

For example:

3dpipe wideip askwip1.askf5.com status

Associated pools

To display the pools that are associated with a wide IP use the following command syntax:

3dpipe wideip <wideip> pool show

Replace <wideip> with the wide IP's fully qualified domain name.

For example:

3dpipe wideip askwip1.askf5.com pool show

This will display the main configuration stanza from the wideip.conf file for the wide IP pool, including the pool name and status.

Enabled/Disabled status for wide IP pools

To display the status (enabled or disabled) for a wide IP pool use the following command syntax:

3dpipe wideip <wideip> pool <pool> status

Replace <wideip> with the wide IP's fully qualified domain name and replace <pool> with the name of the pool.

For example:

3dpipe wideip askwip1.askf5.com pool MainPool status

Availability status for wide IP pools

To display the availability status color for a wide IP pool, use the following command syntax:

3dpipe wideip <wideip> pool <pool> avail

Replace <wideip> with the wide IP's fully qualified domain name and replace <pool> with the name of the pool.

For example:

3dpipe wideip askwip1.askf5.com pool MainPool avail

Wide IP pool virtual servers and their status

To display the virtual servers that belong to a specific wide IP pool and the availability status color for those virtual servers, use the following command syntax:

3dpipe wideip <wideip> pool <pool> virtual show

Replace <wideip> with the wide IP's fully qualified domain name and replace <pool> with the name of the pool.

For example:

3dpipe wideip askwip1.askf5.com pool MainPool virtual show

Enabled/Disabled status for a wide IP of a specific datacenter

To display the status (enabled or disabled) for the wide IP of a particular datacenter, use the following command syntax:

3dpipe wideip <wideip> datacenter <datacenter> status

Replace <wideip> with the wide IP's fully qualified domain name and replace <datatcenter> with the name of the datacenter.

For example:

3dpipe wideip askwip1.askf5.com datacenter Main status

Devices

You can view information for the following devices:

  • 3-DNS Controllers
  • BIG-IP systems
  • EDGE-FX Cache systems
  • Routers
  • Hosts

3-DNS Controllers

You can view the following information for 3-DNS Controllers:

Configured 3-DNS Controllers

To display all 3-DNS Controllers in the configuration, type the following command:

3dpipe 3dns show

This will display the main configuration stanza from the wideip.conf file for each configured 3-DNS Controller, including name, address, type, and status.

Enabled/Disabled status

To display the status (enabled or disabled) for a 3-DNS Controller, use the following command syntax:

3dpipe 3dns <address> status

Replace <address> with the 3-DNS Controller's self IP address.

For example:

3dpipe 3dns 172.16.22.4 status

BIG-IP systems

You can view the following information for BIG-IP systems:

Configured BIG-IP systems

To display all BIG-IP systems in the configuration, type the following command:

3dpipe bigip show

This will display the main configuration stanza from the wideip.conf file for each configured BIG-IP system, including name, address, type, and status, and number of virtual servers.

Enabled/Disabled status

To display the status (enabled or disabled) for a BIG-IP system, use the following command syntax:

3dpipe bigip <address> status

Replace <address> with the BIG-IP system's self IP address.

For example:

3dpipe bigip 172.16.22.4 status

EDGE-FX Cache systems

You can view the following information for EDGE-FX Cache Controllers:

Configured EDGE-FX Cache systems

To display all the EDGE-FX Cache Controllers in the configuration, type the following command:

3dpipe edgefx show

This will display the main configuration stanza from the wideip.conf file for each configured EDGE-FX Cache, including name, address, type, status, and number of virtual servers.

Enabled/Disabled status

To display the status (enabled or disabled) for an EDGE-FX Cache, use the following command syntax:

3dpipe edgefx <address> status

Replace <address> with the EDGE-FX Cache's external self IP address.

For example:

3dpipe edgefx 172.16.28.1 status

Routers

You can view the following information for routers:

Configured routers

To display all the routers in the configuration, type the following command:

3dpipe router show

This will display the main configuration stanza from the wideip.conf file for each configured router, including name, address, type, and status.

Enabled/Disabled status

To display the status (enabled or disabled) for a router, use the following command syntax:

3dpipe router <address> status

Replace <address> with the self IP address that the 3-DNS Controller uses to access the router.

For example:

3dpipe router 172.16.20.1 status

Hosts

You can view the following information for hosts:

Configured hosts

To display all the hosts in the configuration, type the following command:

3dpipe host show

This will display the main configuration stanza from the wideip.conf file for each configured host, including name, address, type, status, and number of virtual servers.

Enabled/Disabled status

To display the status (enabled or disabled) for an EDGE-FX Cache, use the following command syntax:

3dpipe host <address> status

Replace <address> with the host's self IP address.

For example:

3dpipe host 172.16.24.4 status

Virtual servers

You can view information for the following objects associated with virtual servers:

  • BIG-IP
  • EDGE-FX Cache
  • Host

You can view the following information for virtual servers:

  • Enabled/Disabled status for virtual servers

BIG-IP

To display all virtual servers associated with a BIG-IP, use the following command syntax:

3dpipe bigip <address> virtual show

Replace <address> with the BIG-IP's self IP address.

For example:

3dpipe bigip 172.16.22.4 virtual show

This will display the main configuration stanza from the wideip.conf file for each BIG-IP virtual server, including address, port, and status.

EDGE-FX Cache

To display all virtual servers associated with an EDGE-FX Cache, use the following command syntax:

3dpipe edgefx <address> virtual show

Replace <address> with the EDGE-FX Cache's self IP address.

For example:

3dpipe edgefx 172.16.28.1 virtual show

This will display the main configuration stanza from the wideip.conf file for each EDGE-FX Cache virtual server, including address, port, and status.

Host

To display all virtual servers associated with a host, use the following command syntax:

3dpipe host <address> virtual show

Replace <address> with the host's IP address.

For example:

3dpipe host 172.16.24.4 virtual show

This will display the main configuration stanza from the wideip.conf file for each host virtual server, including address, port, and status.

Enabled/Disabled status for virtual servers

To display the status (enabled or disabled) for any type of virtual server, use the following command syntax:

3dpipe virtual <address>:<port> status

Replace <address> with the virtual server's self IP address and replace <port> with the virtual server's service port.

For example:

3dpipe virtual 172.16.24.4:80 status

Synchronization groups

You can view the following synchronization information with the 3dpipe command:

  • 3-DNS Controllers in a synchronization group
  • Enabled/Disabled status for synchronization group

3-DNS Controllers in a synchronization group

To display the 3-DNS controllers that belong to the same synchronization group, type the following command:

3dpipe syncgroup show servers

This will display the main configuration stanza from the wideip.conf file the synchronization group including the self IP address and synchronization priority for each 3-DNS Controller.

Enabled/Disabled status for synchronization group

To display the status (enabled or disabled) for a synchronization group, use the following command syntax:

3dpipe syncgroup <syncgroup> status

Replace <syncgroup> with the synchronization group's name.

For example:

3dpipe syncgroup MainGroup status

Statistics

To display basic statistics about the 3-DNS Controller, type the following command:

3dpipe stats summary

Note: For additional information about the data provided by the 3dpipe stats summary command, refer to K2101: Overview of the the 3dpipe stats summary command.
