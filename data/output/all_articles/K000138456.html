K000138456: The ASM Disallow File Upload of Executables feature not block the script file

Type
Support Solution
Published
2024-06-03
Updated
2024-06-03
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000138456

Description

You may refer K64356849: Configuring the BIG-IP ASM system to block file uploads containing binary executable content has config the BIG-IP ASM to block some executable content, but some executable content is unable to block by ASM policy, for example, the .sh, .bat script file.

Environment

  • Disallowed file upload content detected 
  • Script file 

Cause

This is by design, the ASM support detects the following file type as binary executable content, but the script file is not in the following file type list.
ELF (Executable and Linkable Format - the standard binary file format for Unix and Unix-like systems)
PE (Portable Executable - used in 32-bit and 64-bit versions of Windows operating systems)
Mach-O (Mach object file format - used in Mac OS X)

Recommended Actions

You can refer K78925560: Configuring the BIG-IP ASM system to restrict file uploads based on file extensions use a regular expression to define to allow the file extensions on the Parameter.
