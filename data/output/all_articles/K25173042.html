Known Issue

BIG-IP APM network access VPN browser clients may not establish a connection for the first time after browser-based VPN components on the client system are auto-updated. This issue occurs only once and disappears afterwards. All future requests to establish browser-based VPN connections work without any issues.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is running software version 16.0.1.1, 15.1.2.1, 14.1.4, and 13.1.3.6 or a version listed in the Applies to (see versions) box.
  • You upgrade the APM Clients on the system to the following versions:
    • 7.2.1.1
    • 7.1.9.8
    • 7.1.8.5

Beginning in BIG-IP 13.1.0, APM Clients lets BIG-IP APM administrators update the Edge Client version on the BIG-IP system without needing to upgrade the entire BIG-IP system. For more information, refer to K52547540: Updating BIG-IP Edge Client for the BIG-IP APM system.

Impact

Network access VPN users cannot establish a connection when using the browser the first time they connect.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Network access VPN users observe that the browser-based VPN components fail to launch.

Workaround

To work around this issue, network access VPN users can relaunch their network access resources, or BIG-IP administrators can reinstall the network access browser components on all users' client machines. To do so, perform one of the following procedures:

  • Network access VPN users relaunch the network access resources
  • Browser components including the f5vpn_setup.exe VPN helper application should update automatically when the browser connects, regardless of the Component Update settings after you update the APM Clients version on the BIG-IP system. However, if required, BIG-IP administrators can reinstall the network access browser components on all users' client machines by using one of the following procedures:
    • Redeploy and install the Windows BIG-IP Edge Client package with Web Browser Add-ons checked
    • Redeploy and install the f5vpn_set.exe VPN helper application

Network access VPN users relaunch the network access resources

After VPN users face the issue where the network access resources failed to launch, to relaunch the network access resources, while on the Waiting for Network Access Application Status dialog, VPN users can perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Immediately after the Network Resources fails to launch, on the Waiting for Network Access Application Status dialog box of the web browser, select More options.
  2. Select Try to launch Network Access again.

Redeploy and install the Windows BIG-IP Edge Client package with Web Browser Add-ons selected

To redeploy and install the Windows BIG-IP Edge Client package with Web Browser Add-ons selected, BIG-IP APM administrators should perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Download the BIG-IP Edge Client package from the BIG-IP APM system by completing the following steps:
    1. Log in to the Configuration utility.
    2. Go to Access > Connectivity / VPN > Connectivity > Profiles.
    3. Select the name of the connectivity profile associated with the network access virtual server.
    4. Select Customize Package.
    5. Ensure that the Web Browser Add-ons for BIG-IP Edge Client checkbox is selected.
    6. Select any other components you require.
    7. Select Download.
  2. Distribute and install the BIG-IP Edge Client package on every users' client machines. For example, you can do so through the Windows Group policy, or host the package on a company website.

Redeploy and install the f5vpn_set.exe VPN helper application

To redeploy and install the f5vpn_setup.exe VPN helper application on every users' client machines, BIG-IP administrators should perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Download the f5vpn_setup.exe VPN helper application from the BIG-IP APM system. To do so, perform the Retrieving the SSL VPN helper application for Windows using the Configuration utility or Retrieving the SSL VPN helper application for Windows using the BIG-IP APM virtual server procedures in K08285295: How to download the F5 helper applications for Windows from the BIG-IP APM system.
  2. Distribute and install the f5vpn_setup.exe file on every users' client machines. For example, you can do so through the Windows Group policy, or host the package on a company website.
