Known Issue

This is a result of a known issue. RAM Cache does not make efficient use of xfrag memory allocations. As a result, RAM Cache allocates additional xfrag memory allocations, which utilize more physical memory than is specified in the profile.

F5 Networks Product Development tracked this issue as CR68549 and it was fixed in BIG-IP LTM versions 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.3.0-HF3 issued for BIG-IP version 9.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For information about the F5 Networks hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.

For information about managing F5 Networks product hotfixes, refer to K6845: Managing F5 Networks product hotfixes.
