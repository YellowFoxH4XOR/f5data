Description

You want to check all the APM session variables on the command line.

Environment

  • Check all the APM session variables.
  • BIG-IP APM 

Cause

None

Recommended Actions

  1. You should make sure that you have the terminal full access privileges.
  2. Then you login to the BIG-IP CLI.
  3. Run the following command at the bash prompt to check the currently active session variables:
# sessiondump --allkeys
