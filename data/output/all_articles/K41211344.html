Source
https://my.f5.com/manage/s/article/K41211344

Description

A SSLO virtual server is referenced in a BIG-IP's iRule. When upgrade BigIP version from v15.1.x to v16.1.x, encounter following error in SSLO UI,

err mcpd[9705]: 01070340:3: virtual_server (/Common/sslo_<topology_name>.app/<virtual server_name>) is referenced by one or more rules

In this error message, note the following:

  • <topology_name> is a name of the SSLO topology.
  • <virtual server_name> is the name of the SSLO virtual server.

Environment

  • SSLO UI
  • Upgrade BigIP version
  • iRule contains SSLO virtual server

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 1101609.

Recommended Actions

The bug is scheduled to be fixed in BIG-IP v16.1.3 or SSLO version 10.1. If you require an engineering hotfix (EHF), please contact F5 Support to request for the EHF.
