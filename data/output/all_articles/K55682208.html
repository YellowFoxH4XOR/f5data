K55682208: ''tmsh ?'' returns - Syntax Error: unexpected argument ''X''

Type
Support Solution
Published
2022-10-06
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K55682208

Description

When running "tmsh ?" for tmsh help using command line interface it gives error as shown below :

[root@bigip1:Active:Standalone] config # tmsh ?
Syntax Error: unexpected argument "a"

When it should actually show results as below:

[root@bigip1:Active:Standalone] etc # tmsh ?
Modules:
  /                     TMOS Command Line Interface
  analytics             Analytics reports
  api-protection
  apm                   Access Policy Manager
  auth                  User accounts and authentication
  cli                   Local user settings and configuration transactions
  cm                    Centralized management configuration
  ltm                   Local Traffic Manager
  ...

Environment

  • BIG-IP
  • CLI
  • tmsh help

Cause

Having a file or directory with single character /number as its filename in the same folder you try to run "tmsh ?" from causes this error as by default bash tried to replace special character ? with single character/digit file 

Example:
[root@bigip1:Active:Standalone] config # touch 1
[root@bigip1:Active:Standalone] config # ll 1
-rw-r--r--. 1 root root 0 Oct  5 18:55 1
[root@bigip1:Active:Standalone] config # tmsh ?
Syntax Error: unexpected argument "1"
[root@bigip1:Active:Standalone] config #

Recommended Actions

1. If this file is needed , rename it to include multiple characters/digits or change the directory to run "tmsh ?" 

Example - Changing directory 
[root@bigip1:Active:Standalone] config # tmsh ?
Syntax Error: unexpected argument "1"
[root@bigip1:Active:Standalone] config # ll 1
-rw-r--r--. 1 root root 0 Oct  5 18:59 1
[root@bigip1:Active:Standalone] config # cd /var
[root@bigip1:Active:Standalone] var # tmsh ?
Modules:
  /                     TMOS Command Line Interface
  analytics             Analytics reports
  api-protection
  apm                   Access Policy Manager
  auth                  User accounts and authentication
  cli                   Local user settings and configuration transactions
  cm                    Centralized management configuration

Example - Renaming file 
[root@bigip1:Active:Standalone] config # tmsh ?
Syntax Error: unexpected argument "1"
[root@bigip1:Active:Standalone] config # mv 1 abc
[root@bigip1:Active:Standalone] config # ll 1
ls: cannot access 1: No such file or directory
[root@bigip1:Active:Standalone] config # ll abc
-rw-r--r--. 1 root root 0 Oct  5 19:01 abc
[root@bigip1:Active:Standalone] config # tmsh ?
Modules:
  /                     TMOS Command Line Interface
  analytics             Analytics reports
  api-protection
  apm                   Access Policy Manager
  auth                  User accounts and authentication
  cli                   Local user settings and configuration transactions
  cm                    Centralized management configuration


2. If file is not needed, remove it :

[root@bigip1:Active:Standalone] config # rm 1
rm: remove regular empty file '1'? y
[root@bigip1:Active:Standalone] config #

Additional Information

It's documented in bash manual:
# man bash

Pathname Expansion
After word splitting, unless the -f option has been set, bash scans each word for the characters *, ?, and [. If one of these characters appears, then the word is regarded as a pattern, and replaced with an alphabetically sorted list of file names matching the pattern

Pattern Matching
 ?   Matches any single character.
