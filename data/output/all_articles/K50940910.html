Description

All of the attack signatures are organized into sets and are stored in the attack signature pool on ASM. This article describes the procedure to find the ASM attack signature sets for particular attack signatures using the bash cli.

Environment

  • BIG-IP ASM
  • Attack Signatures
  • CLI
  • Attack Signature sets

Cause

None

Recommended Actions

Follow the procedure below to display the list of ASM attack signature sets containing the particular attack signature

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the bash shell of the BIG-IP
  2. Execute the following command to determine which ASM signature sets contain a particular signature ID: 
    #mysql -uroot -p`perl -I/ts/packages -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw` -e 'select PLC.NEGSIG_SETS.set_id, PLC.NEGSIG_SETS.set_name, PLC.NEGSIG_SET_SIGNATURES.sig_id from PLC.NEGSIG_SETS LEFT JOIN PLC.NEGSIG_SET_SIGNATURES on PLC.NEGSIG_SET_SIGNATURES.set_id = PLC.NEGSIG_SETS.set_id where sig_id in (<sig_id>);'
  3. Bash output will be displayed containing the list of ASM attack signatures sets that contain the ASM signatures with ID mentioned in <sig_id>

For example, You want to determine the signature ID 200000098 belongs to which ASM signatures set

#mysql -uroot -p`perl -I/ts/packages -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw` -e 'select      PLC.NEGSIG_SETS.set_id, PLC.NEGSIG_SETS.set_name, PLC.NEGSIG_SET_SIGNATURES.sig_id from PLC.NEGSIG_SETS LEFT JOIN PLC.NEGSIG_SET_SIGNATURES on PLC.NEGSIG_SET_SIGNATURES.set_id = PLC.NEGSIG_SETS.set_id where sig_id in (200100092);'
