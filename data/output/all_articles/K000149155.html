Description

Database monitors periodically fail and mark a pool member down. The monitored pool member is therefore not selected to receive traffic.

Environment

  • LTM
  • SQL database monitors, such as:
    • PostgreSQL
    • MySQL
    • Microsoft SQL Server
  • Multiple database monitors are configured to probe the same database on a given node

Cause

ID1778793

Recommended Actions

You can work around this issue by using a BIG-IP EAV external monitor to probe the health of your database. An example for how to set up an EAV monitor for MySQL database servers is available in the DevCentral article titled MySQL Monitor.

For PostgreSQL and Microsoft SQL Server databases, you may additionally work around this issue by adding a unique connection property as a suffix to the database name. This will ensure a unique JDBC connection string is constructed for each monitor and will avoid the issue described by this bug.

For example, the "ApplicationName=<monitor_name>" or "applicationName=<monitor_name>" connection properties can be used in PostgreSQL or Microsoft SQL Server respectively to provide the name of the calling monitor to the database without affecting the database connection itself.

Example tmsh commands to disambiguate monitorA and monitorB which both probe a database named "samedb" on the same node:

  • PostgreSQL monitors:
    • tmsh modify ltm monitor postgresql monitorA database samedb?ApplicationName=monitorA
    • tmsh modify ltm monitor postgresql monitorB database samedb?ApplicationName=monitorB
  • MS SQL Server:
    • tmsh modify ltm monitor mssql monitorA database '"samedb;applicationName=monitorA"'
    • tmsh modify ltm monitor mssql monitorB database '"samedb;applicationName=monitorB"'

Note: In the examples above, the PostgreSQL monitor requires a "?" character as a separator between the database name and the connection property, while MS SQL Server requires a ";" as separator. The extra quoting in the example command for MS SQL Server is required to preserve the ";" separator in the database name.
