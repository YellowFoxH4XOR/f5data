K000161089: Users with Administrator role cannot see configuration in partitions other than /Common after upgrading BIG-IP to 17.1.3.2, 17.5.1.6, or 21.0.0.2

Type
Support Solution
Published
2026-05-04
Updated
2026-07-28
Applies to
  • BIG-IP
  • BIG-IP LTM: 21.0.0, 17.1.3, 17.5.1
Source
https://my.f5.com/manage/s/article/K000161089

Description

  • After upgrading to 17.1.3.2, 17.5.1.6 or 21.0.0.2, a user with administrator role logged into the GUI is unable to view any LTM configurations like virtual servers, pool, profiles, etc., which are part of a non-Common partition.
  • The connection to the GUI may get interrupted when trying to change partitions.
  • In CLI, as user with administrator role, the LTM configuration in non-Common partition exist and you can view and edit them.
  • In GUI, if you create a new configuration on a non-Common partition as a user with administrator role, that configuration will end up getting created in /Common partition.

Environment

  • BIG-IP LTM
  • 17.1.3.2, 17.5.1.6, 21.0.0.2

Cause

This is a regression introduced in BIG-IP versions 17.1.3.2, 17.5.1.6, and 21.0.0.2. F5 Product Development has assigned 2264009 to this issue. There is no service or production impact, but administrators cannot manage virtual servers, pools, profiles, etc. 

Answer/Recommended Actions

This issue is fixed in the following released BIG-IP versions:

  • BIG-IP 17.1.3.4
  • BIG-IP 17.5.1.8

For BIG-IP 21.0.x, no released BIG-IP 21.0.x version includes this fix. Contact F5 Support to request an Engineering Hotfix (EHF) or consider an upgrade to BIG-IP 21.1.x.

EHFs are also available for BIG-IP 17.1.3.2 and 17.5.1.6 from MyF5 Downloads:

  • BIG-IP 17.1.3.2: Hotfix-BIGIP-17.1.3.2.0.14.32-ENG.iso
  • BIG-IP 17.1.3.2: Hotfix-BIGIP-17.1.3.2.0.39.32-ENG.iso (also includes the fix for Bug ID 2290709)
  • BIG-IP 17.5.1.6: Hotfix-BIGIP-17.5.1.6.0.67.25-ENG.iso

Additional Information

Previously, F5 published references to older hotfix versions that are no longer required for specific devices: 

  • Hotfix 17.5.1.6.0.39.25-ENG (for iSeries Hardware)
  • Hotfix 17.5.1.6.0.63.25-ENG (for all other devices and VEs, Viprion guests, and F5OS tenants)

If you have questions about the removed EHF Versions, please contact F5 Support.
