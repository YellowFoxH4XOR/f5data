K000135398: Portal Access with an ADFS deployment (extended protection) failing

Type
Support Solution
Published
2023-08-29
Updated
2023-08-29
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.7
Source
https://my.f5.com/manage/s/article/K000135398

Description

You are having trouble configuring Portal Access with SSO and ADFS, specifically with the extended protection feature.

Environment

  • ADFS (Extended Protection feature, uses CBT)
  • Token forwards (eg. CBT, Channel binding token)
  • APM
  • Portal Access

Cause

Portal Access with token forwards is not supported.

Reference: https://techdocs.f5.com/kb/en-us/products/big-ip_apm/manuals/product/apm-clientcompatmatrix-15-1-0.html
"Portal Access does not support web applications that rely on identity federation scenarios (Oauth/SAML/Azure AD) with token forwards and does not work as expected, especially when Azure AD is configured behind the PA. The topology becomes complex because the PA needs to split the ingress for rewriting and non-rewriting."
