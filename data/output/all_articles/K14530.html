Known Issue

BIG-IP users who are assigned the manager role are unable to deploy the Sharepoint 2010 iApp.

This issue occurs when all of the following conditions are met:

  • You have a BIG-IP user assigned the manager role.
  • The user attempts to deploy the Sharepoint 2010 iApp.
  • The default option to Create an NTLM profile from within the Sharepoint 2010 iApp configuration screen has been selected.

Impact

You are unable to deploy the Sharepoint 2010 iApp.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H425501 on the Diagnostics > Identified > Medium screen.
  • You may see an error message that appears similar to the following example in the BIG-IP Configuration utility, and in /var/log/ltm:

    Access Denied: user (<user>) does not have create access to object (ltcfg_instance)

    In this error message, note the following:
    • <user> is the username with the manager role who is attempting to create this iApp.
