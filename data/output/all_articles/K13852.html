Topic

The following article describes the BIG-IP Analytics advanced filters that can be configured to report specific combinations of data.

Description

The BIG-IP Analytics module provides a set of advanced filters in order to view the data collected in different combinations and groupings. For example, for a given time period, you may choose to view statistics for only connections that were sent to two specific pool members, and only connections that requested three specific URLs on those pool members.

Advanced filtering is available at the following location in the Configuration utility:

BIG-IP Analytics 11.1.0 and later

  • Statistics > Analytics > <Filter Tab> > Expand Advanced Filters

BIG-IP Analytics 11.0.0

  • Overview > Statistics > <Filter Tab> > View: Advanced

Advanced filter combinations

For each top level filter tab that is selected, you can choose from a specific set of sub filters to further filter the statistics. In addition, some combinations of filters are mutually exclusive. Filters that are irrelevant for the current view-by selection are hidden. For example, under the Transactions top-level filter tab, if you choose URLs from the View By: drop-down menu, only the relevant filter options are displayed (Applications, Virtual Servers, Pool Members and URLs). The irrelevant filter options are hidden (Client IP Addresses, Client Subnets and Countries).
