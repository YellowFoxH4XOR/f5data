Environment
  •     BIG-IP LTM
  •     Exchange iApp 2013
  •     iRule for redirection.

Cause
Cache mismatch between client, virtual server, and pool members.

Recommended actions
  • Disable cache on the iRule that is applying it to the virtual server configuration.
Additional information
 
Here is an example about how to disable cache on an iRule.

****Before****
"/owa*" {
            if { [HTTP::header exists "Accept-Encoding"] } {
             HTTP::header remove "Accept-Encoding"
         }
            pool <POOL_NAME>
            return
        }

****After****
"/owa*" {
            if { [HTTP::header exists "Accept-Encoding"] } {
             HTTP::header remove "Accept-Encoding"
         }
            pool <POOL_NAME>
            CACHE::disable     <-----------------------------!!!!!
            return
        }
