Topic

You should consider using these procedures under the following conditions:

  • You want to back up your VELOS system configuration data.
  • You want to restore your VELOS system configuration data.

Description

The confd process manages the F5OS-C configuration on a VELOS system. The system stores the configuration in its configuration database (CDB).

At the chassis level, the F5OS-C configuration contains data that includes the following:

  • DNS
  • Network time protocol (NTP)
  • Authentication servers
  • Logging setup
  • High availability (HA) setup
  • Management IP addresses of the system controllers
  • Basic configuration of existing partitions, such as the partition name, floating management IP address, and the partition-to-slot mapping

At the partition level, the F5OS-C configuration contains data that includes the following:

  • Portgroups of the assigned slots/nodes/blades
  • VLANs
  • Logging setup
  • Authentication servers
  • HA setup

To perform a complete backup of the VELOS system, you must:

  • Back up the configuration data at the chassis and partition levels.
  • Back up any deployed tenants using the tenants’ backup mechanism.
  • Back up the system license (Registration key and any add-on keys)

Note: Beginning in F5OS-C versions that contain the fix for ID 1080041, when the database config-backup is performed, the license file is not included in the backup file.

For example, if you have a deployed tenant that is a BIG-IP Virtual Edition (VE) system, you must back up the tenant BIG-IP system using its user configuration set (UCS) archive.

When you back up configuration data, the system saves the backup file in XML format to the following locations:

  • Backup at the chassis level: /var/confd/configs directory
  • Backup at the partition level: /var/F5/partition<ID>/configs directory, where <ID> is the partition number

Note that you use the following references in the confd command line interface:

  • Reference the /var/confd/configs directory as configs/.

    Note: In F5OS-C 1.1.x, the reference is /mnt/var/confd/configs.

  • Reference the /var/F5/partition<ID>/configs directory as configs/.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • If you are performing a backup or restore at the chassis level, you have chassis administrator access to the command line of the VELOS system.
  • If you are performing a backup or restore at the partition level, you have partition administrator access to the command line of the VELOS system.
  • If you are using BIG-IQ to perform the VELOS backups, please refer to the K34133507: BIG-IQ Centralized Management compatibility matrix.

Procedures

  • Set the primary key
  • Back up your VELOS chassis or partition configuration data using the webUI
  • Back up your VELOS chassis or partition configuration data using the command line
  • Restore your VELOS chassis or partition configuration data
  • Download a backup file using the webUI
  • Upload a backup file using the webUI
  • Export a backup file using the webUI
  • Export a backup file from the command line
  • Import a backup file using the webUI
  • Import a backup file from the command line

Set the primary key

Important: Before saving the configuration file, you must complete this procedure in case you need to restore the config file on a different system.

The F5 VELOS system uses a primary key to perform encryption and decryption of highly sensitive passwords/passphrases in the configuration database. You should periodically reset this primary key for additional security. You should at least set the primary key once prior to performing any configuration backup if you have not already done so. However, F5 recommends setting this primary key before every backup to avoid unnecessary issues due to intermittent configuration or upgrade issues. In the case of a configuration migration such as moving configuration to a replacement system controller due to RMA, it is important to set the primary key to a known value so that the same key can be used to restore the configuration on the replacement system controller. Note that replacing a blade does not require the restoration of the primary key since it gets its copy from the system controller's confd process.

  1. Log in to the CLI of the chassis floating management IP address as the chassis administrator.
  2. Enter the configuration mode terminal by entering the following command:

    config

  3. Set the strings for a passphrase and salt by entering the following command syntax:

    system aaa primary-key set passphrase

    The system prompts you separately for the passphrase and its confirmation, followed by the salt and its confirmation similar to the following example:

    Value for 'passphrase' (<string, min: 6 chars, max: 255 chars>): ********
    Value for 'confirm-passphrase' (<string, min: 6 chars, max: 255 chars>): ********
    Value for 'salt' (<string, min: 6 chars, max: 255 chars>): ********
    Value for 'confirm-salt' (<string, min: 6 chars, max: 255 chars>): ********

  4. Exit the configuration mode terminal by entering the following command:

    end

  5. Check the primary key hash by entering the following command:

    show system aaa primary-key state hash

    Output appears similar to the following:

    system aaa primary-key state hash <hash_key>

    Note that the hash can be used to check and compare the status of the primary key on both the source and the replacement device.

  6. Record the salt and passphrase strings for later use because they are required to restore the configuration on a replacement system controller.

    For more information, refer to Manual Chapter : Additional System Tasks in the VELOS Systems: Administration and Configuration manual.

Back up your VELOS chassis or partition configuration data using the webUI

Starting in F5OS-C 1.2.0, you can perform a backup of your VELOS chassis or partition configuration data using the webUI. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Do one of the following:
    • If you are backing up chassis configuration data, log in to the webUI of the chassis floating management IP address as the chassis administrator.
    • If you are backing up partition configuration data, login to the webUI of the partition floating management IP address as the partition administrator.
  2. Go to SYSTEM SETTINGS > Configuration Backup.
  3. Select Create. The webUI displays Create Configuration Backup.
  4. For Name, enter the name you want to use for the configuration backup file.
  5. Select Create. Prior to F5OS 2.0.0, the webUI displays a message to indicate the status of the configuration backup. Select Dismiss to exit.
  6. If you need to move the backup file off the system, the system allows you to directly download it from the SYSTEM SETTINGS > Configuration Backup page starting in F5OS-C 1.8.0. Select Download next to the configuration backup file you want to download to your local workstation. For versions prior to F5OS-C 1.8.0 or if you prefer to export the backup file to a remote HTTPS server, refer to the Export a backup file using the webUI procedure.

Back up your VELOS chassis or partition configuration data using the command line

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Do one of the following:
    • If you are backing up chassis configuration data, log in to the command line of the chassis floating management IP address as the chassis administrator.
    • If you are backing up partition configuration data, login to the command line of the partition floating management IP address as the partition administrator.
  2. Enter the configuration mode terminal by entering the following command:

    config

  3. Back up the configuration data by using the following command syntax:

    system database config-backup name <backup file name>

    For example, to save the configuration data to a backup file named cli-backup1, enter the following command:

    system database config-backup name cli-backup1

  4. Exit the configuration mode terminal by entering the following command:

    exit

  5. If you need to move the backup file that you created in step 3 off the chassis, perform the procedure under the Export a backup file from the command line section in this article.

Restore your VELOS chassis or partition configuration data

Before you restore the configuration, if the backup file is located at a remote location, perform the procedure under the Import a backup file from the command line section in this article.

Impact of procedure: Performing this procedure overrides any existing configuration on your VELOS chassis or partition with the configuration data in the backup file.

  1. Do one of the following:
    • If you are restoring chassis configuration data, log in to the command line of the chassis floating management IP address as the chassis administrator.
    • If you are restoring partition configuration data, login to the command line of the partition floating management IP address as the partition administrator.
  2. Enter the configuration mode terminal by entering the following command:

    config

  3. Restore the configuration data by using the following command syntax:

    system database config-restore name <backup file name>

    For example, to restore the configuration data to a backup file named mybackup.backup, enter the following:

    system database config-restore name mybackup.backup

  4. If you are restoring configuration data to the chassis, the system proceeds with no requirement to confirm. If you are restoring configuration data to an existing partition, the system displays a warning about clearing the existing configuration prior to restoring to a previous configuration. F5 recommends that you perform a reset-to-default operation to clear the existing configuration before attempting to restore to a previous configuration for the partition. For more information, refer to K000149614: Reset the configuration of a VELOS partition to factory default settings. Enter yes to proceed with the configuration restoration to the partition.
  5. Exit the configuration mode terminal by entering the following command:

    exit

Download a backup file using the webUI

You can download a backup file from your VELOS chassis or partition to your workstation. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Do one of the following:
    • If you are downloading a backup file from the VELOS chassis, log in to the webUI of the chassis floating management IP address as the chassis administrator.
    • If you are downloading a backup file from a VELOS partition, login to the webUI of the partition floating management IP address as the partition administrator.
  2. For F5OS 2.0.0 and later, go to System Monitoring > File Utilities. Prior to F5OS 2.0.0, go to SYSTEM SETTINGS > File Utilities.
  3. Under File Transfer Operations, for Base Directory, select configs.
  4. For configs, select your backup file.
  5. Select Download. You should observe your web browser begins to download the selected file to the browser's temporary directory on your workstation.

Upload a backup file using the webUI

You can upload a backup file from your workstation to your VELOS chassis or partition. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Do one of the following:
    • If you are uploading a backup file from the VELOS chassis, log in to the webUI of the chassis floating management IP address as the chassis administrator.
    • If you are uploading a backup file from a VELOS partition, login to the webUI of the partition floating management IP address as the partition administrator.
  2. For F5OS 2.0.0 and later, go to System Monitoring > File Utilities. Prior to F5OS 2.0.0, go to SYSTEM SETTINGS > File Utilities.
  3. Under File Transfer Operations, for Base Directory, select configs.
  4. Select Upload.
  5. The webUI displays a file locator popup; navigate to the location of the backup file on your workstation which you wish to upload and then select the backup file.
  6. Select Open to initiate the upload to the VELOS chassis or partition.

Export a backup file using the webUI

Starting in F5OS-C 1.2.0, you can export a backup file from your VELOS chassis or partition to an HTTPS server using the webUI. To do so, perform the following procedure:

Note: For the transfer to complete properly, the HTTPS server must be able to accept PUT/POST requests and use an SSL certificate signed by a public CA.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Do one of the following:
    • If you are exporting a backup file from the VELOS chassis, log in to the webUI of the chassis floating management IP address as the chassis administrator.
    • If you are exporting a backup file from a VELOS partition, login to the webUI of the partition floating management IP address as the partition administrator.
  2. For F5OS 2.0.0 and later, go to System Monitoring > File Utilities. Prior to F5OS 2.0.0, go to SYSTEM SETTINGS > File Utilities.
  3. Under File Transfer Operations, for Base Directory, select configs.
  4. For configs, select your backup file.
  5. Select Export. The webUI displays File Export.
  6. For Server (F5OS 2.0.0 and later) or Server URL (prior to F5OS 2.0.0), enter the remote HTTPS server URL.
  7. If the remote HTTPS server requires basic authentication, for Username and Password, enter the username and password.
  8. If you want to skip certificate warnings when exporting files to the remote HTTPS server, select the Ignore Certificate Warnings check box.
  9. Select Export File.
  10. You can monitor the status of the file export under File Transfer Status.

Export a backup file from the command line

You can export the backup file from the VELOS system to an HTTPS server using the command line. Beginning F5OS 2.0.0, you can export the backup file from the VELOS system to an SCP or SFTP server using the command line. To do so, perform the following procedure:

Note: For the transfer to complete properly, the HTTPS server must be able to accept PUT/POST requests and use an SSL certificate signed by a public CA. If the remote HTTPS server is using a self-signed SSL certificate or an SSL certificate signed by a non-public CA, you can use the insecure option to disable verification of the remote system identity.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Do one of the following:
    • If you are exporting a backup file from the chassis, log in to the command line of the chassis floating management IP address as the chassis administrator.
    • If you are exporting a backup file from a partition, login to the command line of the partition floating management IP address as the partition administrator.
  2. To verify that the backup file exists in the directory, use the following command:

    file list path configs/

  3. To export a backup file, use the following syntax:

    file export local-file <path/to/backup_file> remote-host <host_address> remote-file <path/to/remote_file> protocol <https | scp | sftp> [username <user>] [insecure]

    Note: Use the insecure option if you want to skip certificate warnings when exporting files to the remote HTTPS server.

    For example, to export the cli-backup1 chassis backup file to the /tmp/ directory of the remote SCP host at 192.168.10.100, enter the following command:

    file export local-file configs/cli-backup1 remote-host 192.168.10.100 remote-file /tmp/cli-backup1 protocol scp username myscphostadmin

  4. To check the status of the file transfer, enter the following command:

    file transfer-status

    When the transfer is complete, the system displays output similar to the following example:

    result

    S.No.|Operation  |Protocol|Local File Path                                             |Remote Host         |Remote File Path                                            |Status            |Time                
    1    |Export file|SCP     |configs/cli-backup1                                         |192.168.10.100       |/home/ubuntuadmin/F5/F5OS/cli-backp1                        |         Completed|Sun Jul  5 20:19:28 2026

    Note: If the export using scp/sftp fails and you observe the error message Host identity could not be verified from the file transfer-status command output, you may want to refer to K000162039: Error "Host identity could not be verified" when exporting/importing file from/to F5OS using scp/sftp to/from a remote host for information about resolving it.

Import a backup file using the webUI

Starting in F5OS-C 1.2.0, you can import a backup file to your VELOS chassis or partition from an HTTPS server using the webUI. To do so, perform the following procedure:

Note: For the transfer to complete properly, the HTTPS server must be able to accept PUT/POST requests and use an SSL certificate signed by a public CA.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Do one of the following:
    • If you are importing a backup file from the VELOS chassis, log in to the webUI of the chassis floating management IP address as the chassis administrator.
    • If you are importing a backup file from a VELOS partition, login to the webUI of the partition floating management IP address as the partition administrator.
  2. For F5OS 2.0.0 and later, go to System Monitoring > File Utilities. Prior to F5OS 2.0.0, go to SYSTEM SETTINGS > File Utilities.
  3. Under File Transfer Operations, for Base Directory, select configs.
  4. Select Import. The webUI displays File Import.
  5. For URL, enter the remote URL path to the file you want to use.
  6. If the remote HTTPS server requires basic authentication, for Username and Password, enter the username and password.
  7. If you want to skip certificate warnings when importing files from the remote HTTPS server, select the Ignore Certificate Warnings check box.
  8. Select Import File.
  9. You can monitor the status of the file import under File Transfer Status.

Import a backup file from the command line

You can import the backup file to the VELOS system from an HTTPS server using the command line. Beginning F5OS 2.0.0, you can import the backup file to the VELOS system from an SCP or SFTP server using the command line. To do so, perform the following procedure:

Note: For the transfer to complete properly, the HTTPS server must be able to accept PUT/POST requests and use an SSL certificate signed by a public CA.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Do one of the following:
    • If you are importing a backup file from the chassis, log in to the command line of the chassis floating management IP address as the chassis administrator.
    • If you are importing a backup file from a partition, login to the command line of the partition floating management IP address as the partition administrator.
  2. To import a backup file, use the following syntax:

    file import remote-host <host_address> remote-file <path/to/remote_file> local-file <path/to/backup_file> protocol <https | scp | sftp> [username <user>] [insecure]

    Note: Use the insecure option if you want to skip certificate warnings when importing files from the remote HTTPS server.

    For example, to import the mybackup.backup chassis backup file from the /tmp/ directory of the remote host at 192.168.10.100 using the insecure option, enter the following command:

    file import remote-host 192.168.10.100 remote-file /tmp/mybackup.backup local-file configs/mybackup.backup insecure

  3. To check the status of the file transfer, enter the following command:

    file transfer-status

    When the transfer is complete, the system displays output similar to the following example:

    result
    S.No.|Operation  |Protocol|Local File Path              |Remote Host         |Remote File Path                 |Status          |Time
    1    |Import file|HTTPS   |configs/mybackup.backup      |192.168.10.100      |/tmp/mybackup.backup             |Complete        |Wed Dec 29 06:59:59 2021

    Note: If the export using scp/sftp fails and you observe the error message Host identity could not be verified from the file transfer-status command output, you may want to refer to K000162039: Error "Host identity could not be verified" when exporting/importing file from/to F5OS using scp/sftp to/from a remote host for information about resolving it.

  4. To verify that you imported the backup file into the directory, use the following command:

    file list path configs/
