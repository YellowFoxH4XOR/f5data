Known Issue

The BIG-IP APM rewrite process may exit and produce a core file when processing empty values in HTTP headers.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a portal access profile.
  • Using the TMOS Shell (tmsh), you configure the portal access profile and modify a resource item without specifying resource item headers.

    For example:

    modify /apm resource portal-access <portal access profile name> items modify { item { headers { { } } } }

  • An access session user attempts to access the portal access resource.

Impact

Traffic is temporarily disrupted while the rewrite process produces a core file and restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users are temporarily unable to connect to portal access resources through the BIG-IP APM system.
  • When you use portal access, web applications malfunction or fail to render properly in browsers.
  • The BIG-IP system generates a rewrite process core file to the /shared/core directory that appears similar to the following example:

    /shared/core/rewrite.0.bld0.0.249.core.gz

Workaround

To work around this issue, you can fix the portal access configuration. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh.
  2. List the BIG-IP APM portal access configuration with the following command:

    tmsh list apm resource portal-access

  3. Identify the portal access configurations that contain the configuration stanza headers none.
  4. For each affected portal access resource item that contains the stanza, type the following command to correct the stanza:

    modify /apm resource portal-access <resource> items modify { <resource item> { headers none } }

    Following is an example of an affected portal access resource:

    list /apm resource portal-access pa-test

    apm resource portal-access pa-test {
        acl-order 1
        customization-group empty_resource_web_app_customization
        items {
            item {
                headers none
                host www.example.com
                order 1
                paths /some_path/
                subnet 0.0.0.0/0
            }
        }
    }

    Following is an example of a portal access resource stanza after you run the command:

    modify /apm resource portal-access pa-test items modify { item { headers none } }

    list /apm resource portal-access pa-test

    apm resource portal-access pa-test {
        acl-order 1
        customization-group empty_resource_web_app_customization
        items {
            item {
                host www.example.com
                order 1
                paths /some_path/
                subnet 0.0.0.0/0
            }
        }
    }

    Note: After you run the command, the configuration stanza no longer contains the configuration statement headers none.

  5. To exit tmsh, type the following command:

    quit
