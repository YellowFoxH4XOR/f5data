Known Issue

This is the result of a known issue. If you attempt to restore a UCS archive file with a large number of FIPS keys/CERTs (approximately more than 1,300) from the Configuration utility, the BIG-IP system will return the following error message and abort the restoration operation after ten minutes:

Error executing shell command.

When this issue occurs, you may also find the following error messages logged in the /var/log/tomcat4/catalina.out file:

ERROR [Thread-19] io.MCPConnectionBroker:freeConnection - ----> Error: Could not free connection!!!
ERROR [Thread-19] util.Syscall:call - Exception trying perform a system call.
java.sql.SQLException: Null message reply. in statement [SELECT SINGLE * FROM shell_call WHERE command = 0 AND args = 'config install "/var/local/ucs/test.ucs"']
ERROR [Thread-19] util.F5Error:<init> - Error executing shell command.

Note: This issue only affects platforms with a FIPS card. For information about the platforms that support a FIPS card, refer to K6499: BIG-IP platforms that support FIPS.

F5 Product Development tracked this issue as ID 237422 (formerly CR70225), and it was fixed in BIG-IP version 9.4.0. For more information about upgrading, refer to the BIG-IP LTM, ASM, and Link Controller release notes.
