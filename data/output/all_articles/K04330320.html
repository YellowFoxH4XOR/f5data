Description

You have upgraded your BIG-IP devices but have reverted it back to the older software version (downgrade).

After you have reverted back to the older software version, version mismatch status is still present in the HA status.

The HA group (Device Management > Device Groups) has more than 2 BIG-IPs configured. For example there are 4 BIG-IPs configured in the HA Device Group.

Environment
  • BIG-IP
  • BIG-IP has been upgraded and then reverted back to previous software version
  • After downgraded version mismatch is still present
  • There are more than 2 BIG-IP in HA Device Group

Cause

Among all the devices configured in the Device Group, another device is running on another BIG-IP software version.

Recommended Actions

You will need to identify which BIG-IP is running another software version and revert it.

  1. Login to each BIG-IP configured HA Device Group.
  2. Navigate to System > Configuration > Device > General on each device to confirm the software version.
  3. The BIG-IP device with a difference software version, navigate to System > Software Management > Boot Locations and boot to the correct BIG-IP software version.
