Description

The failover status change can be performed from both the Command Line Interface (CLI) via tmsh and via the Configuration Manager (GUI). This article will cover the CLI only.

Environment

  • Failover
  • Command Line

Cause

None

Recommended Actions

To perform a failover state change the command syntax is:

(tmsh) run sys failover <properties> <sub-properties> <configurationItem>

Please refer to the table below for the explanation for the command properties:

PropertiesSub-PropertiesConfiguration ItemsExplanation
offline--Sets the current device to offline (Since persist or no-persist options are not specified, the default action is to persist the offline status of the unit between system restarts.)
no-persist-Sets the device to offline and will not persist the change in status of a unit.
persist-Sets the device to offline and will persist the change in status of a unit.
online--Sets the status of a unit or cluster from Forced Offline to either Active or Standby, depending upon the status of the other unit or cluster in a redundant system configuration.
standby--Sets the currently the active unit or cluster fails over to a Standby state, causing the standby unit or cluster to become Active. Since no device or traffic-group is specified, then the next active device will be automatically chosen among the devices according to the current device configuration.
device<deviceName>Sets the device that should next become the active device for the specified traffic group or all traffic groups (if a traffic group is not specified).
traffic-group<trafficGroupName>Sets the traffic-group that should fail over to the Standby state, the traffic-group will become Active on another device.

Examples:

To set the currently active device to standby and failover to the peer device:

(tmsh) run sys failover standby 

If there are more than one peer devices and there is a specific one that should become active:

(tmsh) run sys failover standby device <deviceName> 

If the current device is to be set to offline:

(tmsh) run sys failover offline

If the current device is to be set to offline and we want the offline state to persist even after a reboot:

(tmsh) run sys failover offline persist
