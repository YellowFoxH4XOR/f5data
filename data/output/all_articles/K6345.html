Topic

When a connection matches a SNAT that has mirroring enabled and also a virtual server that does not perform mirroring, the active BIG-IP unit will not send mirroring data to the standby unit.

For example, a connection with an origin address of 172.17.1.100 and a remote destination address, matches both the example_virtual wildcard virtual server, and the example_snat SNAT configuration objects displayed below:

snat example_snat {
   mirror enable
   translation 172.16.1.100
   origin 172.17.1.100
}
virtual example_virtual {
   destination any:any
   ip forward
}

When the BIG-IP system processes the connection, the active BIG-IP system will not send mirroring data to the standby system, even though mirroring is enabled for the SNAT object.

This behavior occurs because of the order in which virtual server traffic is processed. SNAT objects are a sort of wildcard forwarding virtual server enabled only for traffic sourced from certain addresses. However, the forwarding capability of a SNAT object has lower priority than that of a virtual server. Therefore, when a flow matches both a SNAT and a virtual server, the SNAT will turn into a pure address manipulation object, and the virtual server that matched the flow destination will manage the flow. This is the behavior described in this article; the virtual server handles the flow and SNAT is only used to provide address manipulation. Since the virtual server does not have mirroring turned on, no flows are mirrored.

Recommended Actions

You can configure the BIG-IP to send mirroring data for the affected virtual server by enabling connection mirroring for the virtual server. However, this configuration will mirror all flows handled by the virtual server, even those that do not match the SNAT. To enable connection mirroring for a virtual server, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Click Virtual Servers.
  4. Click the virtual server to which you want to enable connection mirroring.
  5. Set Configuration to Advanced.
  6. Select the Connection Mirroring check box.
  7. Click Update.
