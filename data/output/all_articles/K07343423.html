K07343423: How to Increase the threshold in BigIQ for Disk Usage Alert for Managed BIG-IP

Type
Support Solution
Published
2020-10-22
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K07343423

Description

You are receiving alarms for partition /opt//sdm/usr being over 80% of disk usage in the BIG-IQ CM device. 

Environment

  • BIG-IQ CM
  • BIG-IP
  • Disk space usage for partition /opt//sdm/usr is showing as being over 80% in the BIG-IQ
  • /usr partition is over 80% in the BIG-IP device

Cause
This is an expected behavior when the BIG-IP is managed by BIG-IQ. The BIG-IQ CM threshold to send alarms for high disk space usage in the managed devices is 80%. In some cases, like in the one explained in article K23607394: The /usr partition shows high disk space usage, the high disk usage is normal. You might want to change the BIG-IQ threshold to a higher value.

Recommended Actions

You can modify the default threshold in the BIG-IQ CM by following the next steps:
  1. Gather the existing "disk_usage_exceeds_threshold_ip" setting and save it into a file.
    restcurl /cm/shared/event/alert-config/disk_usage_exceeds_threshold_ip
  2. Copy the output to a notepad or any text editor.
  3. Based on the output from Step 1, look for "alertConditionExpression" and "threshold". Verify if it's currently set to 80% (i.e."0.80d). And, modify it to 0.97
This new threshold will ensure all recent BigIP's OS versions options are covered:

Examples:

BigIP OS version        /usr directory utilization

  14.1.X                    4.0G  3.2G  649M  84% /usr
  15.1.3                    5.0G  4.4G  382M  93% /usr
  15.1.5.1                 5.1G  4.7G  199M  96% /usr
  16.1.2.2                 5.7G  4.7G  695M  88% /usr


 
  1. Issue a PATCH command via restcurl with the changes made on Step 3
    restcurl -X PATCH '/cm/shared/event/alert-config/disk_usage_exceeds_threshold_ip' -d ' <Result from Step3> '
Example:
