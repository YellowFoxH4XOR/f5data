Topic

3-DNS provides the full_debug script, which allows you to temporarily enable verbose logging when troubleshooting a problem. When you enable the full_debug script, 3-DNS begins logging all levels of the local2 facility. This causes all 3-DNS messages to be reported in the /var/log/3dns log file. In addition, big3d and named are restarted using USR1 to enable debugging.

Once the full_debug script is enabled, 3-DNS automatically disables the full_debug script after two hours to protect disk space.

To enable the full_debug script, type the following command:

full_debug on

To disable the full_debug script, type the following command:

full_debug off
