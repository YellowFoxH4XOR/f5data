Description

BIG-IP VE stopped passing traffic.  Network not reachable.

Repeated error found on /var/log/ltm similar to the following:

01071859:4: Warning generated : cannot set MTU for eth1. No such device. For legacy VE driver

Other symptoms can include:

  • Management IP may have reverted back to default IP
  • Self-IPs and Virtual Server IPs on TMM interfaces not reachable

Environment

  • BIG-IP VE on vSphere ESXi 6.7
  • VMware ESXi 6.7 host was upgraded to Update 2 or Update 3
  • Recent move of the Virtual Machines using Vmotion

Cause

Bug ID 774445: BIG-IP Virtual Edition does not pass traffic on ESXi 6.7 Update 2

Recommended Actions

Upgrade to a BIG-IP software version with the compatible driver. Alternatively to workaround the issue on affected versions, refer to the workaround on this article: K74921042: BIG-IP VE may fail to process traffic after upgrading the VMware ESXi 6.7 host to Update 2 (or later).

Additional Information

Same symptoms can be found on higher versions (BIG-IP v14, v15, v16), in relation to similar BUG-ID, Bug ID 922885: BIG-IP Virtual Edition does not pass traffic on ESXi 6.5, with similar workaround on: K27872027: BIG-IP VE may fail to process traffic after deployment on a VMware ESXi 6.5 host.
