K000133528: Certificate behavior the cert already existed error message

Type
Support Solution
Published
2023-04-15
Updated
2023-04-15
Applies to
  • NGINX Products
  • NGINX Instance Manager: 2.8.0
Source
https://my.f5.com/manage/s/article/K000133528

Description

  • NIM manages multiple Nginx plus instances
  • Each instances generates its own certificates
  • But these certificates have the same NAME, as shown below

  • After version upgrade to 2.8.0
  • Any attempt to push configuration from NIM to managed systems which uses these certificates fails with error
Instance config failed to publish to: {"instance:6b4ec88b-0cdf-3e4e-a618-59d9782799d4":"multiple cert object with given name found"}--

  • If using NIM version 2.7.0, no such complaint is seen and publication of configuration is successful

    

Environment

  • Nginx Instance Manager
  • Certificate

Cause

  • Bug ID NMS-40444

Recommended Actions

  • Upgrade to 2.9.1 or above

Additional Information

  • None
