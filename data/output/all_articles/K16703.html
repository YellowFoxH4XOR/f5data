Known Issue

On the Configuration utility, the AFM Overview Summary screen has two Add Widget links that offer different sets of display methods.

This issue occurs when all of the following conditions are met:

  • You have navigated to Security > Overview > Summary.
  • You have attempted to create a new widget by clicking one of the two Add Widget links.

The Add Widget links allow users to create a new widget with the chosen display method for the target security statistics.

Impact

User may not be able to create a new widget with the desired display method.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • There are two Add Widget links available on the AFM Overview Summary page that offer different sets of display methods.  
  • You click a link and you do not see the desired display method for the new widget. 
  • You click the Add Widget link on the right edge of the Summary page, and you get the display method using the Summary Table or Summary Box.
  • You click the Add Widget link at the bottom of the Summary page, and can choose one the following display methods:

    • Details Table
    • Line chart
    • Pie chart
    • Bar chart

Workaround

Choose the display method you want for the new widget by clicking the appropriate Add Widget link, as described previously in the Symptoms section.
