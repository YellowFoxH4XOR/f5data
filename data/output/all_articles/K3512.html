Known Issue

A significant amount of BIG-IP CPU resources are required when loading the Network Map page for large configurations. High CPU utilization can lengthen the time it takes for the BIG-IP system to load the Configuration utility.

F5 Product Development tracked this issue as CR23325.

Workaround

To work around this issue, change the Configuration utility default page to another page within the Systems tab by performing the following steps:

Important: This procedure requires that you modify the Configuration utility HTML code. Future upgrades to the BIG-IP system may overwrite these files and require that you make the changes again.

  1. Back up the affected files, by typing the following commands:

    cp /usr/local/www/bigipgui/templates/topology.html
    /usr/local/www/bigipgui/templates/topology.OLD

    cp /usr/local/www/bigipgui/templates/systemframe.html
    /usr/local/www/bigipgui/templates/systemframe.OLD

  2. Using a text editor, edit the /usr/local/www/bigipgui/templates/topology.html file.

  3. Locate line 17.

    It should appear as follows:

    foldersTree = newFolder("System", "/bigipgui/bigconf.cgi?command=generate_vipmap&inplace=true", "/bigipgui/images/bigiplogos.gif", "/bigipgui/images/bigiplogos.gif");

  4. Remove this line and replace it with the following line:

    foldersTree = newFolder("System", "/bigipgui/bigconf.cgi?command=system_properties", "/bigipgui/images/bigiplogos.gif", "/bigipgui/images/bigiplogos.gif");

  5. Edit the /usr/local/www/bigipgui/templates/systemframe.html file.

  6. Locate line 17.

    It should appear as follows:

       src             = "/bigipgui/bigconf.cgi?command=generate_vipmap&inplace=true"

  7. Remove this line and replace it with the following line:

       src             = "/bigipgui/bigconf.cgi?command=system_properties"
