Issue

Error Message

debug statsd[<PID>]: 011b090c:7: tmstat_query_rollup on table <table> called

In this error message, note the following:

  • <PID> is the process ID for the statsd process.
  • <table> indicates which table roll up is being performed.

For example:

debug statsd[<PID>]: 011b090c:7: tmstat_query_rollup on table profile_tcp_stat called

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The log level for the statsd process is set to debug.

This message is a debug-level log message and is generated when the BIG-IP system performs a statistics table roll up.  This normally occurs once every 30 seconds.

Impact

Logging to the /var/log/ltm file increases until the log level for the statsd process is lowered.

Recommended Actions

The debug log level may result in the system using significant resources, and you should use it only when troubleshooting. To reduce the amount of statsd logging, you can modify the log level setting to use the default value of warning using the Traffic Management Shell (tmsh). To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Modify the log level for the statsd process using the following syntax:

    modify sys db log.statsd.level value <log_level>

    For example, to change the log level to warning, type the following command:

    modify sys db log.statsd.level value warning
