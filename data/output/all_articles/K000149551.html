K000149551: After upgrade to v17.1.0, some TCP segments with unexpected flags might be dropped

Type
Support Solution
Published
2025-01-30
Updated
2025-01-30
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.X, 17.1.2, 17.1.1, 17.1.0
Source
https://my.f5.com/manage/s/article/K000149551

Description

After upgrade to software version 17.1.0, some TCP segments with unexpected flags might be dropped.
For example, a TCP segment that have RST+ACK+PSH flags set in the same segment.

 

Environment

  • BIG-IP LTM

 

Cause

In v17.1.0 as part of an effort to improve code in DoS/DDoS area, changes such as TCP flag classification were introduced.

 

Recommended Actions

Working as expected, for example: RST+PSH+ACK flags in same TCP segment is considered as bad/malformed.
While such segment (with TCP flags RST+PSH+ACK) being accepted on earlier BIG-IP versions, in v17.1.0 such segment will be dropped.
