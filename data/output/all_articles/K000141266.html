Description

An AFM dos profile may incorrectly report 2 sets of stats for some Vectors
For example, below we can see 2 sets of stats reported for vector OTHER DOS on profile My_Dos_profile

Cause

Recommended Actions

The issue can be resolved by restarting all blades in the Viprion system, with the command below:
clsh reboot
