Known Issue

The Configuration utility incorrectly allows users to set a string value to 'none' during local traffic policy configuration.

This issue occurs when the following condition is met:

  • From the Configuration utility, you set the following string parameters to 'none':

    • Operands

      For example, the http-cookie and http-header operands require a name string.
    • Actions

      For example, the Tcl expression action requires a string.

Impact

The BIG-IP configuration fails to load.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system fails to load the configuration using the tmsh load /sys config command.
