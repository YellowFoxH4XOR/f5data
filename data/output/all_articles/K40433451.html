K40433451: SNAT Pool IP is not responding to ICMP traffic

Type
Support Solution
Published
2021-02-11
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • VIPRION Platforms
  • Public Cloud
  • Private Cloud
Source
https://my.f5.com/manage/s/article/K40433451

Description

After upgrade, the SNAT Pool IP addresses are not responding to ICMP traffic. 

Environment

  • You upgraded to BIG-IP version 15.1.0 or above
  • ICMP 
  • SNAT pool

Cause
Due to ID948757, IP addresses defined on SNAT Pools may fail to reply to ICMP echo requests.

Recommended Actions

  1. Upgrade to a version 16.0.1, 15.1.2 or 14.1.3.1.
  2. Contact F5 support to request an EHF for your current version.
