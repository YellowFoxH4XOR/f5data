Known Issue

This is the result of a known issue. Certain behaviors may terminate a Safari user's communication with the FirePass device. Some examples include leaving a drop-down menu or a right-click menu open too long, and scrolling through an HTML drop-down control.

F5 Product Development tracked this issue as ID 296296 (formerly CR116911) and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative hotfix HF-603-2.1, which was issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For a list of current hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

This issue is specific to Safari. You can work around this issue by using Firefox or another browser instead of Safari.
