K000132798: emerg mcpd[7543]: 01070608:0: License is not operational (expired or digital signature does not match contents) after upgrading the device to 15.1.X version.

Type
Support Solution
Published
2023-03-01
Updated
2023-03-01
Source
https://my.f5.com/manage/s/article/K000132798

Description

  • Once the device is upgraded to version 15.1.8, it displays an error message on the graphical user interface stating that the license for the device is not functional and exhibits misbehavior.
  • If attempting to modify the device, the user will be unsuccessful due to the license error. Additionally, if the UCS is used, an error message will appear indicating that the server has encountered an internal error or misconfiguration, and it cannot complete the user's request.
  • Customer may receive the error in the log "emerg mcpd[7543]: 01070608:0: License is not operational (expired or digital signature does not match contents)".

 

 

Environment

  • Big-IP LTM
  • Recently Upgraded to 15.1.8.1 / 15.1.8

Cause

This is due to the below mentioned Bug-ID
ID1209561

 

 Recommended Actions

  1. To temporarily resolve the issue, the device needs to be reloaded.
  2. F5 has fixed this issue in an engineering hotfix for the respective version. Open a case with F5 TAC to request the EHF.
