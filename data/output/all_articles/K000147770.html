K000147770: How do I troubleshoot getting a request_payload_too_large error message

Description

I am receiving a request_payload_too_large error message in my requests.

Environment

  • Load Balancer

Cause

  • Buffer Policy is buffering the entire request before sending to upstream application.

Answer/Recommended Actions

This can be resolved by changing the Buffer Policy:

Option 1: Changing the Buffer Policy for a Route

  1. Go to the Load Balancer configuration then Go to Routes
  2. Under Routes, click on Advanced Options
  3. Open Miscellaneous Options
  4. Select Route Specific Buffering Configuration under Enable Route Specific Buffering
     
  5. You have 2 options:
    • Input the Max Request Bytes limit (up to a maximum 10485760 bytes)
    • Check the box to disable the Buffer Policy
  6. Click Apply for the Buffer Policy
  7. Click Save and Exit

Option 2: Changing Buffer Policy for the entire Loadbalancer

  1. Go to the Load Balancer configuration
  2. Click on Other Settings
  3. Click on More Options
  4. Open Miscellaneous Options
  5. Click on configure under Buffer Policy
  6. You have two options:
    • Input the Max Request Bytes limit (up to a maximum 10485760 bytes)
    • Check the box to disable the Buffer Policy
  7. Click Apply for the Buffer Policy
  8. Click Apply to save Load Balancer Miscellaneous Options
  9. Click Save and Exit
