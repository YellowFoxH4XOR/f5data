Additional Information

In reality it's fine when the value is bigger than 0 %

This value can fluctuate between 1 and 100% depending on the traffic spikes. It's just aggregative number of different (hundreds) metrics.

Low value doesn't prevent BADOS to successfully detect and mitigate.

HTTP Behavioral DoS can work when parameter [x1, x2, x3, x4] x1 is above 0. This allows using global rate and bad actors detection/mitigation.

When parameter x4 is 100 it indicates that signatures mechanism can be used too.

Parameters x2 and x3 are less relevant for the customers - x2 indicates the number of internal anomaly metrics, x3 – the number of collected good samples for signatures mechanism.
