Topic

VIPRION chassis systems may have more than one Base Registration Key assigned.

Description

BIG-IP platforms are assigned a Base Registration Key that is unique to the platform, and will generally never change, except when you replace a device as part of a Return Materials Authorization (RMA). The new replacement unit has its own Base Registration Key, but the registration key changes during the RMA process, and F5 relicenses the device using the Base Registration Key of the suspected defective unit.

In the case of a VIPRION chassis, F5 licenses the new chassis using the Base Registration Key of the old chassis, as with any other platform. However, the original Base Registration Key assigned to the new device still resides in a SEEPROM chip that is installed on the chassis. This condition may lead to an incongruity in Base Registration Key information, depending on the method you use to query the key.

A command that reads the Base Registration Key from the hardware returns the original key that is recorded in the SEEPROM, as shown in the following example:

tmsh show sys hardware | grep "Registration Key"

Registration Key ONNCE-UZSRU-BTVVE-XKHRW-KEVHXBG

A command that reads the Base Registration Key from software shows the newly installed, correct Base Registration Key that the system is using, as shown in the following example:

grep "Registration Key" /config/bigip.license

Registration Key : S5749-79659-21213-68586-0869290

Recommendations

This incongruity does not affect the ability of the chassis to pass traffic or to license and load software modules.

If you prefer to have the Base Registration Key data consistent across all locations on the chassis, contact F5 Technical Support and reference this article for assistance with updating the key data that is saved in the SEEPROM.
