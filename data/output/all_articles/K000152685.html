Description

The IP Intelligence policy appears in the "Security" tab of the Virtual Server with BIG-IP ASM (Advanced WAF) license, even when an IP Intelligence Subscription-based license has not been purchased or activated on the Device. This can lead to confusion regarding whether the IP Intelligence feature is operational without a valid license. No error messages are displayed, but any configured IP Intelligence policies will not be enforced if the required license is missing. 

Environment

  • IP Intelligence Policy
  • BIG-IP ASM (Advanced WAF) Provisioned
  • IPI (IP Intelligence) is NOT Licensed or Activated

Cause

The BIG-IP ASM user Interface displays configuration options for the IP Intelligence policy by default, regardless of licensing status. However, actual functionality—including downloading and using the IP Reputation Database—requires a separate, valid Subscription-based IP Intelligence license. Without this license, any related policy configurations will have no effect on traffic processing. 

Recommended Actions

  • The presence of the IP Intelligence policy in the GUI does not indicate that it is active or functional.
  • To enable and use IP Intelligence features (such as blocking or alerting based on malicious or suspicious IP reputation), purchase and activate an appropriate IP Intelligence license for your BIG-IP system.
  • After licensing, verify that the system downloads and updates the IP reputation database (K13875) and that enforcement actions are enabled.
  • If no valid license is present, any configured policies under this feature will not affect traffic.
