Description

BIG-IQ CM does not appear to push configuration from the Deployment tab to APM

Environment

  • BIG-IQ
  • APM (it's possible that this can also occur with other BIG-IP Modules)
  • Access policy configuration 

Cause

The APM object is not associated with Access Policy, which in turn is not associated with a Virtual Server 

Recommended Actions

In the BIG-IQ GUI:

  1. Confirm the creation/association of new APM object with that of an access policy, under the Configuration tab
  2. Confirm the access policy in question is associated with a Virtual Server
  3. Confirm the creation/evaluation of a deployment, under the Deployment > Evaluate & Deploy  > Access
  4. Deploy the Deployment

Additional Information

  Once you create access object like policy, webtop and so on, it needs to be associated with Access Policy before it gets pushed onto managed BIG-IP
  If not associated, even if you manage to complete the deployment, you will not see the change on the BIG-IP. In other words, you would need to modify/create an existing/new access policy
  Finally, if verification/evaluation fails, then the deployment button will not be available for you, as the configuration you intend is incorrect.
