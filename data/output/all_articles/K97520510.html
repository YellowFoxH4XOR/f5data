 Description

BIG-IP is not booting and asking for root password for maintenance

  • Symptoms: Not booting
  • Error messages: Give root password for maintenance 
(or type Control-D to continue):
bash: tty: command not found
bash: warning: setlocale: LC_CTYPE: cannot change locale (en_US.UTF-8): No such file or directory
bash: warning: setlocale: LC_COLLATE: cannot change locale (en_US.UTF-8): No such file or directory
bash: warning: setlocale: LC_MESSAGES: cannot change locale (en_US.UTF-8): No such file or directory
bash: warning: setlocale: LC_NUMERIC: cannot change locale (en_US.UTF-8): No such file or directory
bash: warning: setlocale: LC_TIME: cannot change locale (en_US.UTF-8): No such file or directory
[root@!:!:!] ~ #

Environment

  • Conditions: console session
  • Products and features: BIG-IP 

Cause

Linux files system have errors and they need to be fixed and checked on Linux

Recommended Actions

  1. Enter the root password
  2. Once you are logged in, run the fsck command:  fsck -y
    Note: If the above command is not working after reboot, run the command 'fsck -A -y'
  3. It is going to take a while depending on how many files system are corrupted
  4. Finally type: reboot
  5. If you receive the same message again you might want to repeat the same steps one more time
     

Additional Information

You might want to force an fsck once the BIG-IP is up and running again following the instructions from:
  K73827442: Forcing a file system check on the next system reboot (12.x - 15.x)
