Topic

You should consider using this procedure under the following condition:

  • You want to enable or disable the autoconnect in BIG-IP Edge Client.

Description

You can configure the BIG-IP Edge Client to automatically connect to the VPN server. This feature allows you to configure the Edge Client to automatically establish VPN connection when the computer is not on the corporate network. When the computer is connected to the corporate network, the Edge Client detects the computer's location and does not attempt to connect. To automatically connect the VPN tunnel, BIG-IP Edge Client must know when the computer is not connected to the corporate network. This is accomplished by adding the corporate domain in the Location DNS List of the connectivity profile applied to the virtual server to which the BIG-IP Edge Client connects to establish the VPN tunnel.

When building the Edge Client installation package, in the selected connectivity profile, if the Location DNS List is configured, then the Edge client will always show the "Auto-Connect" button.

If you want to hide the "Auto-Connect", button, you can remove the configuration for Location DNS List, and then rebuild the Edge Client installation package, remove and  re-install the Edge Client.

When building the Edge Client installation package, in the selected connectivity profile, if the Location DNS List is NOT configured, then the Edge client may show the "Auto-Connect" button, it is depending on the connectivity profile which is applied to the virtual server for the VPN. For this scenario, you can follow the steps below, disable / enable the "Auto-Connect" button.

Prerequisites
You must meet the following prerequisite to use this procedure:

  • You must have administrative access to the Configuration utility.

Procedures

To enable or disable autoconnect on the BIG-IP Edge Client, perform the appropriate following procedure:

  • Enabling autoconnect on the BIG-IP Edge Client
  • Disabling autoconnect on the BIG-IP Edge Client

Enabling autoconnect on the BIG-IP Edge Client

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access > Connectivity / VPN.

    Note: For BIG-IP 12.x and earlier, navigate to Access Policy > Secure Connectivity.

  3. Click the appropriate Connectivity Profile and click Edit Profile.
  4. Under Win/Mac Edge Client, click Location DNS List.
  5. Click Add.
  6. Enter the DNS suffix of the network where the BIG-IP Edge Client should not establish the VPN tunnel.

    For example: enter example.com if you do not want the Edge Client to use *.example.com.

  7. Click Update.
  8. Repeat steps 5 - 7 if you need to add more domains.
  9. Click OK .

The next time the BIG-IP Edge Client connects to the BIG-IP APM VPN virtual server, the BIG-IP Edge Client's configuration is updated and autoconnect is enabled. To use the feature, users must click the Auto Connect button.

Disabling autoconnect on the BIG-IP Edge Client

If autoconnect is enabled but you want your users to connect manually, you need to remove the domains in the location DNS list. To do so perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access > Connectivity / VPN.

    Note: For BIG-IP 12.x and earlier, navigate to Access Policy > Secure Connectivity.

  3. Click the appropriate connectivity profile.
  4. Click Edit Profile.
  5. Under Win/Mac Edge Client, click Location DNS List.
  6. Click a domain and click Delete to remove it from the list. Repeat this step until all domains are removed from the list.
  7. Click OK .

The next time the BIG-IP Edge Client connects to the BIG-IP APM VPN virtual server, the BIG-IP Edge Client's configuration is updated, autoconnect is disabled, and the Auto Connect button is removed from the BIG-IP Edge Client application.
