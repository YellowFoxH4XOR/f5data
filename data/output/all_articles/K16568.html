Issue

Old Behavior

By default, when the BIG-IP LTM system receives unsolicited traffic, such as bridge protocol data unit (BPDU) messages, the Virtual Local Area Network (VLAN) failsafe timer does not reset. Only traffic that reaches the Traffic Management Microkernel (TMM), such as Address Resolution Protocol (ARP) and IPv6 neighbor discovery responses, resets the VLAN failsafe timer.

The failover.vlanfailsafe.resettimeronanyframe database-key variable controls whether the BIG-IP system resets the VLAN failsafe timer on whenever the system receives any frame, and the variable default value is false. This means that the BIG-IP system resets the timeout counter only when the system receives an ARP and IPv6 Neighbor Discovery Protocol (NDP) in response to VLAN failsafe traffic. When you set the failover.vlanfailsafe.resettimeronanyframe database key to true, the BIG-IP system resets the VLAN failsafe timeout counter when it receives any frame.

New Behavior

Beginning in BIG-IP 11.4.0, when the BIG-IP system receives any frame and activates aggressive mode, it ignores the failover.vlanfailsafe.resettimeronanyframe database key setting and resets the VLAN failsafe timeout counter.

The VLAN failsafe timeout counter's default Fail-safe Timeout value is 90 seconds. At the point that the counter's value reaches 50 percent of the configured value without the system detecting VLAN traffic, the BIG-IP system begins to generate VLAN failsafe traffic, which indicates that the system has activated aggressive mode. After this occurs, the BIG-IP system resets the timeout counter each time the system receives any frame, including monitor traffic, such as traffic from a gateway_icmp monitor. This behavior prevents the system from marking down the VLAN and prevents VLAN failsafe from triggering a failover before the VLAN remains idle for the entire configured Fail-safe Timeout interval.

F5 Product Development tracked this change as ID 400237.

Impact

After the system activates aggressive mode it ignores the failover.vlanfailsafe.resettimeronanyframe database key setting.
