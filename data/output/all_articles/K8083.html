K8083: When searching for logons containing a hyphen, FirePass only displays the first 20 results

Known Issue

This is the result of a known issue. When you search for users by logon name on the Users: Users Management page, and your search query contains a hyphen ( - ) character, FirePass correctly reports the total number of records returned and displays the first 20 records on the first page. When you click the right arrow icon to view the next 20 records (if the search produced over 20 records), FirePass displays no records and replaces the hyphen character with the characters :45: in the search text box.

If you select Logon from the Search by drop-down menu and enter sales-usa as the search query, the number of records returned is displayed at the top of the page. For example:

Records 0...20 (56 total)

The first 20 records display at the bottom of the page. To view the next 20 results, click the right arrow icon to the right of Records 0...20 (56 total). Since the query contains a hyphen character, the top of the second page displays:

Records 20...0 (0 total)

However, the top of the second page should display the following:

Records 20...40 (56 total)

Additionally, the search text box displays sales:45:usa instead of the original search query sales-usa.

F5 Product Development tracked this issue as CR87469 and it was fixed in FirePass 6.0.3. For information about upgrading, refer to the FirePass Release Notes

Additionally, cumulative hotfix HF-601-9 has been issued for FirePass 6.0.1 and cumulative hotfix HF-602-1 has been issued for FirePass 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by excluding the hyphen ( - ) character from your search query when searching by logon name on the Users: Users Management page. For example, search for sales or usa instead of sales-usa.
