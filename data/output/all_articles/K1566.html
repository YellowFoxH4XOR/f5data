Known Issue

This is the result of a known issue. BIG-IP allows VLANs with names that contain up to 15 characters; however, the Setup utility does not allow you to create VLAN names with more than 12 characters.

F5 Networks Product Development tracked this issue as CR28429 and CR41900.

Workaround

If you want to create VLANs with names that contain more than 12 characters, you must do so after you run the Setup utility. For more information, refer to the BIG-IP manual.
