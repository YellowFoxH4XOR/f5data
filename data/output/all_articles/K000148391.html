Description

You want to check if you have enough disk space for your BIG-IP software upgrade.

You will need to have minimum 15 GiB free space in the volume group to install the software image.

Environment

  • Software upgrade.

Cause

None

Recommended Actions

You can check if your BIG-IP has enough diskspace using either of the below commands :

# vgs

  VG        #PV #LV #SN Attr   VSize   VFree
  vg-db-sda   1   9   0 wz--n- 500.1g    11.6

# tmsh list sys disk all-properties

sys disk logical-disk HD1 {
    mode mixed
    size 153600
    vg-free 11916
    vg-in-use 141472
    vg-reserved 0
}

If you do not have enough disk space you can follow below recommendation:

  • If you have multiple boot location where older software images are installed and they are not going to be used. Delete those unused boot location by following K33265170: Deleting a boot location volume to free up disk space
  • If you only have one single boot location in which your BIG-IP is currently running on and you have no other boot locations to delete, then follow the Recommended Actions mentioned in K91895955: Unable to upgrade with error ''failed (Disk full (volume group). See SOL#10636)''

Additional Information

How to check which all software images you have in boot location? The one which shows "yes" in "Active", is the boot location and software image your BIG-IP is currently running on. You can delete boot location which has "no" in "Active" if you no longer require it and to free up disk space.

# tmsh show sys software

--------------------------------------------------------

--------------------------------------------------------
