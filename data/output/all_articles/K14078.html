Known Issue

The End-User Diagnostics (EUD) may incorrectly report the following test status when a hard disk is missing or undetected:

Overall Test Result: PASSED

This issue occurs when the following condition is met:

  • You run the EUD utility on one of the following BIG-IP platforms:
    • 6900 (D104)
    • 8900 (D106)

Impact

The false test report may cause confusion about the state of the hard drives/compact flash.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The EUD SMART test reports that the drive was not found and abort the test. The output appears similar to the following example:

    Executing SMART Test ...
    Test Begin: SMART Test
    /dev/sda was not found and will not be tested
    /dev/sdb was not found and will not be tested
    /dev/sdc was not found and will not be tested
    /dev/sdd was not found and will not be tested
    Test Aborted: SMART Test: No drive to test

  • The overall EUD test indicates a passed result that appears similar to the following example:

    Total number of tests that ran: 14
    Total number of tests that passed: 14
    Total warnings in log: 0
    Total errors in log: 0
    Overall Test Result: PASSED

  • As a result of the missing hard drive, the system stops responding at the command prompt and reports error messages that appear similar to the following example:

    console=tty0 console=ttyS0,19200 panic=1 quiet platform=Gemini
    Error 22: No such partition
    Press any key to continue...

    kernel (hd1,1)/vmlinuz.eud root=/dev/ram0 rw console=ttyS0,19200 quiet
    Error 22: No such partition
    Press any key to continue...

Resolution

Status

F5 has confirmed that this issue exists in the products listed in the Applies to (see verions) box, located in the upper-right corner of this article. Workaround

A workaround does not exist for this issue. If the SMART test fails to find the hard drive and attempts to perform a clean installation fail, contact F5 Support.
