K000150588: Firewall Policy Rule ID Changes When Modifying a Rule Using "Filter Active Rules List"

Type
Support Solution
Published
2025-03-27
Updated
2025-03-27
Status
Final
Applies to
  • BIG-IP
  • BIG-IP AFM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150588

Description: 

Policy rule ID changes when modifying a rule using the filter "Active Rules" and committing the changes. This occurs when a rule is edited through the "Filter Active Rules List" section in the AFM policy, and upon applying the updated rule, the system reorders the rule

 

Environment:

BIG-IP AFM
AFM policy
Filter Active Rule List

 

Cause:

BUG ID 1820489

 

Recommended Actions: 

As a workaround, remove the filter before committing the changes.

 

 

Additional Information:

 

None
