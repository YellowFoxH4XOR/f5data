Description

You setup a Global Log Receiver and some of the syslog messages sent are receiving multiple logs in one message to the QRadar.

 

Environment

  • F5® Distributed Cloud (XC)
  • Global Log Receiver

Answer/Recommended Actions

The log stream is being sent as intended, but the QRadar receiver needs to be told to split the stream into multiple records, which are separated with a newline (\n).
