Known Issue

This is the result of a known issue. When accessing a Citrix application through an application tunnel using the Citrix Online Plug-in version 12.x inside a Protected Workspace, the requested application fails to load. Protected Workspace prevents the Citrix Online Plug-in version 12.x wfcrun32.exe component from communicating with the ssonsrv.exe component.

F5 Product Development is tracking this issue as ID 340752 for FirePass 7.0.0.

F5 Product Development tracked this issue as ID 340962 for BIG-IP APM and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

This issue has been fixed in cumulative hotfix HF-70-2, which has been issued for FirePass 7.0.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about downloading software from F5, refer to SOL167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

Note: This issue cannot be corrected in FirePass version 6.1.0 due to the difference in how FirePass integrates into the client operating system.

Workaround

You can work around this issue by removing Citrix Online Plug-in version 12.x and installing Citrix Online Plug-in version 11.
