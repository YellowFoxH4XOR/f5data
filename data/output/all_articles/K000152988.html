Description

When attempting to create a local account from the command line, the following error message is being received:

Error: User not found. Please commit any changes before setting the password

Environment

F5OS-C

VELOS

Cause

This may be because of ID1858617.

Recommended Actions

  • Let's connect to the controller GUI, floatingIP, and let's navigate to Users & Roles;
  • let's click the role the new account is supposed to have;
  • please clear the LDAP group declaration from it - leaving it empty - and apply the changes.

Additional Information

Bug ID 1586057: F5OS displays an incorrect error if the admin tries to set a password before committing a new user
