Introduction

The sudo utility allows a user with non-root permissions to execute root functions (as a superuser) from the command line. It is most often used in UNIX systems to provide a specific user with the ability to execute certain commands, while still limiting the user's administrative access to the root account.

Setting up a non-root user requires that you edit the system's /etc/passwd file with the UNIX commands, chpass or vipw. If you are not familiar with these commands, refer to the man pages by typing the following commands:

man vipw
man chpass

For more information about the /etc/passwd file, refer to the UNIX administrator reference material.

The following instructions assume that the user, for which you are providing sudo access, has already been created and that the user is able to successfully log in with his or her account.

When you set up a new non-root user, you must provide the user with a non-root UID (user identification) and GID (group identification). In general, a non-zero UID and a GID of 1) are safe to use on BIG-IP; however, F5 Networks recommends that you run the grep <UID> /etc/passwd command to verify the availability of a user ID. If this command returns nothing, the user ID is available for use.

It is also important that you edit the /etc/passwd file and assign a login class of daemon to the user. The classes are defined in the /etc/login.conf file. You can view the class definition when editing a user in vipw.

For example:

rootuser:_J9..8IWY.58Zdo103NI:500:1:daemon:0:0:Not quite root:/root:/bin/bash

In this example:

  • The UID is 500.
  • The GID is 1.
  • The login class is daemon.

Setting up a user to use the sudo utility

To allow the rootuser user to use the sudo utility, perform the following steps:

  1. Edit the /etc/group file and add the new user as part of the wheel group.

    /etc/group file example:

    wheel:*:0:root,rootuser 
daemon:*:1:daemon  
kmem:*:2:root  
sys:*:3:root  
tty:*:4:root  
operator:*:5:root  
uucp:*:6:  
bin:*:7:  
utmp:*:12:  
mail:*:14:  
nogroup:*:32766:
  2. Create a /etc/sudoers file, similar to the following example.

    Note: You may choose to specify more restrictive user permissions than provided in the example.

    /etc/sudoers:  
rootuser ALL=(ALL) ALL
  3. To set the correct permissions on the /etc/sudoers file, type the following command:

    chmod 0440 /etc/sudoers

Using the sudo utility

Once a user has been set up to use the sudo utility, they can execute sudo with the sudo -u root command or sudo <command>.

For example:

sudo -u root rm junk.file

Or:

sudo vipw

The user will be prompted for a password and, if the password is correct, the command will be executed. The user will not be prompted for a password on subsequent sudo -u root requests.
