Description

We have a WAF policy which is in Transparent mode. There are still blocked requests for WSS.

Non-WSS requests do not get blocked.

Environment

  • WSS messages
  • Transparent mode
  • Attack signatures

Cause

Bug ID 961509: ASM blocks WebSocket frames with signature matched but Transparent policy

Recommended Actions

This bug only affects behaviour while in Transparent mode.

To workaround the immediate issue, disable Block for the attack signatures in question.

Bug ID 961509 is not fixed in any current version at the time of this article's publication, but an engineering hotfix may be requested by opening a Service Request with F5 Support.
