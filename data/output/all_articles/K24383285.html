Description

BIG-IP is not able to load the configuration due to the incorrect role assigned to internal account "f5hubblelcdadmin".

Following error is observed on /var/log/ltm:

01070820:3: User Modification Denied: User (root) may not change the role of system account (f5hubblelcdadmin) Unexpected Error: Validating configuration process failed.

/config/bigip_user.conf file looks similar to excerpt below:

auth user f5hubblelcdadmin {
    description f5hubblelcdadmin
    encrypted-password ***scrubbed***
    partition-access {
        all-partitions {
            role guest     <-----------------
        }
    }
    shell none
}

Environment

Upgrade to version 12.x

Cause

Possible related to Bug ID 625114: Internal sync-change conflict after update to local users table

Recommended Actions

1. Edit the bigip_users.conf file and change "role guest" to "role admin" under the "f5hubblelcdadmin" built-in user.
2. Load the configuration using the command:
# tmsh load sys config

3. If the configuration loaded successfully, save the change by running this command:
# tmsh save sys config
