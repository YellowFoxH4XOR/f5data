Description
How to upgrade from v5.x - 6.x to the current version 7.x or 8.x

Note:

When upgrading Big-IQ, there is no impact to the Big-IP licensed units.
There is no activity from Big-IQ to the Big-IPs that affects the license on the Big-IP without
specific user intervention using the Big-IQ UI or API.
The license permanently exists on the Big-IP until it is specifically changed.

Environment

  • VE (Virtual Edition)
    • Cloud Hosted
  • BIG-IQ License Manager
  • .iso

Cause
None

Recommended Actions

To download the BIG-IQ image, follow the below procedure. 

 

  1. Log into BIG-IQ
  2. Click on system (top of the screen) then on the left menu expand "This device" click on Licensing
  3. Click on reactivate (automatic method)
  4. On a new browser tab, navigate to https://downloads.f5.com  
  5. Click on find a download, BigIQ centralized management, the system defaults to the most recent version of the software.
  6. Click on the file you want to download from the name column. 
    For Example: (click 7.0.0.1 under name)
  7. Review the End User Software License, Click on I Accept.
  8. From the name column, click on the file name of the image file
    For example Big-IQ-7.0.0.1-0.0.6.iso link.
  9. Click on the closest location, the file will start downloading

To upload the downloaded image to BIG-IG follow the below procedure. 

  1. Click on the BigIQ browser tab, click System  ››  Software Management 
  2. Click on images, then upload the image.
  3. Click on choose file, browse to download folder, choose the ISO file, click on upload 
    For example: BIG-IQ-7.0.0.1-0.0.6.iso

To install and upgrade BIG-IQ License Manager follow the below procedure. 

  1. Click on Installations
  2. Note the current version of the device, 
    For Example BIG-IQ V 5.4.0 
  3. Click on Upgrade
  4. Software image: select the uploaded image.
    For example: BIG-IQ-7.0.0.1-0.0.6.iso
  5. Target Volume: click in right side dot, type HD1.2 in the new volume box.
  6. Place a check in the UCS backup box.
  7. Click on Install in the bottom right of the page.
    You will notice the below status while the software image is being installed. 
    Pop up box, showing install progress  **do not close!**. (takes 10-15 minutes)
    Pop up box "Software installed successfully" click on close.
    Pop up box, "user session terminated", click on Log Out.
  8. BigIQ web page "site cannot be reached" (refresh in about 10 minutes)
  9. BigIQ GUI shows "waiting for BIG-IQ services to become available"
  10. BigIQ GUI shows"upgrading"
  11. New logon screen, login same user and password as before (admin)
  12. Once logged in click on Devices either in the middle of the screen or at the top of the screen.
  13. On the left, click on License management (to expand the menu) and then click on licenses.
  14. Observe list of ELA, cick on the ELA name, and we can see the offerings.
    Note: The advantage of BigIQ 7.x and newer is automated billing reports
