Description

Device failed to load the configuration after reboot to new partition with upgraded software version with following error message. 

Aug 20 00:47:08 LTM1.example.com err mcpd[9869]: 01070312:3: Invalid keyword 'sslv2' in ciphers list for profile /Common/serverssl-insecure-compatible
Aug 20 00:47:09 LTM1.example.com err tmsh[11953]: 01420006:3: Loading configuration process failed.
Aug 20 00:47:09 LTM1.example.com err mcpd[9869]: 01070425:3: Full configuration load failed.

Environment

  • Upgrade to BIG-IP V14 or V15
  • SSL Profile configured with SSLv2 ciphers 
  • Upgrading from BIG-IP v12.x/v13.x.

Cause

Bug ID 811333: Upgrade fails when SSLv2 cipher is in the cipher list of an SSL profile
sslv2 is no longer a valid option in SSL cipher profile in Big-IP v14.x and 15.x 
Recommended Actions

If you are encountering this after upgrading, run the following commands from the bash prompt:
  1. Backup the configuration:
    #cp /config/bigip.conf /config/bigip_backup.conf
  2.  List the occurrences of 'sslv2' in the bigip.conf:
    # more bigip.conf | grep -i sslv2
  3. Remove the SSLv2 references
    # sed -i "s/\!SSLv2://g" /config/bigip.conf
  4. Check to ensure there are no 'sslv2' references:
    # more bigip.conf | grep -i sslv2
  5. Verify the configuration:
    # tmsh load sys config verify
  6. Try loading the configuration:
    # tmsh load sys config
