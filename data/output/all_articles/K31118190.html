K31118190: iRule static variables

Type

Published
2025-09-29
Updated

Description

Static variables in iRules are global, so if you define the same variable in multiple iRules, you should make sure that all iRules define the variable with the same value.

Environment

This occurs in all systems that use iRules.

Cause

If you define the same variable with different values in different iRules, then the variable will contain the value of the last iRule that is last loaded into memory.

iRules are loaded in Alphanumeric order, so if you have two iRules named iRule1 and iRule2, the iRule2 will always be loaded last, so if you have the same static variable in each of these iRules, then whatever value is configured in iRule2, will be the value for both iRules.

Recommended Actions

  • Make sure that all iRules contain the same value for static variables
  • If you want different values, then make sure each iRule uses a different names for their static variables.

Additional Information

If you want to know what order your iRules are loaded into memory, you can change iRules logging from Notice to Debug

In the GUI, goto System -> Logs -> Configuration -> Options

Then in  Section "Local Traffic Logging", change iRules from Notice to Debug

To modify this from the CLI:

# tmsh modify sys db log.rules.level value Debug
