K000147760: What to do when you receive "conflicts with existing virtual host " error while creating CDN

Description

This article explains how to proceed if you encounter the error:
"Domain example.com, Protocol TCP, Port 443 on tenant VIP conflicts with existing virtual host" when trying to create a CDN distribution in F5 Distributed Cloud (XC).
The error occurs when attempting to use the same domain name for both an HTTP Load Balancer and a CDN distribution.

Environment

  • Distributed Cloud (SaaS)
  • F5 Distributed Cloud Console
  • CDN

Cause

The error is caused by using the same domain name for both an HTTP Load Balancer and a CDN distribution.

Answer/Recommended Actions

To avoid this problem, use a different subdomain for the CDN distribution or the HTTP Load Balancer.
Examples:

  • Example 1:
    • HTTP Load Balancer domain: example.com
    • CDN domain: cdn.example.com
  • Example 2:
    • HTTP Load Balancer domain: lb.example.com
    • CDN domain: example.com
