Description
How to find protocol, bits, and ciphers negotiated for a particular iquery connection using TMSH.

Environment

  • BIG-IP DNS or LTM part of iQuery mesh
  • BIGIP version 14.1.0
  • TMSH

Cause
None

Recommended Actions

Packet capture is required to find out ciphers, bits, and protocols used for a particular iquery connection, in BIG-IP v14.1.0 and later this information can be verified using TMSH.

Version 14.1.0
Run the following command in TMSH 

[root@gtm1:Active:Standalone] config # tmsh show gtm iquery 172.16.100.2

Additional Information
An iQuery connection is an SSL connection on port 4353 from a gtmd process to the big3d process on a remote or local BIG-IP. When big3d starts, it listens for port 4353 on all configured self IP addresses and the management interface IP address.   

By default, iQuery establishes an SSL connection to the remote big3d process using version TLS1.0 or higher and in some situations, SSL connection needs to run at a higher TLS version

This information is not available in version 12.1.1 see the output below
