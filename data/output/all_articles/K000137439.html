Environment

Azure cloud deployment

Cause

Outbound internet access isn't being allowed. vNet isn't able to reach one of the services required for BIG-IP to complete onboarding

Recommended Actions

You need outbound access not only from the Management subnet, but also from the outbound subnet for initial instantiation.
Make sure that new instances are allowed to fetch data from external resources."

Outbound access is a requirement, documented here: https://github.com/F5Networks/f5-azure-arm-templates-v2/tree/main/examples/failover .
“Internet access is required via the management interface and then via a dataplane interface (for example, external Self-IP) once a default route is configured.”
What this means is that you need outbound Internet access from BOTH your Management NIC and your external NIC when you are deploying the template. The reason for this is that some of the startup script is downloaded from the Internet, and after that, the network is configured and then more things may be downloaded during initial onboarding.
