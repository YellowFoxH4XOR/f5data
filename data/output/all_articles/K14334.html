Security Advisory Description

F5 BIG-IP Analytics 11.x before 11.4.0 uses a predictable session cookie, which makes it easier for remote attackers to have unspecified impact by guessing the value. (CVE-2013-7408)

This may become apparent when running vulnerability scans (such as Qualys) against a virtual server that is configured with an Analytics profile. The scanner may report that the BIG-IP Analytics session cookie is predictable.

For example, a vulnerability scanner may report the following BIG-IP Analytics session cookies as predictable:

Set-Cookie: avr_1711324808_0_0_4294901760_655818752_0=1818401381_13212460
Set-Cookie: avr_1711324808_0_0_4294901760_655818752_0=1818057897_13212461
Set-Cookie: avr_1711324808_0_0_4294901760_655818752_0=1818057969_13212463
Set-Cookie: avr_1711324808_0_0_4294901760_655818752_0=1818058009_13212464
Set-Cookie: avr_1711324808_0_0_4294901760_655818752_0=1818058057_13212465

Impact

Minimal. The BIG-IP Analytics session cookie is used for analytics, not application authentication.

Security Advisory Status

Beginning in BIG-IP 11.4.0, the BIG-IP Analytics cookie is encrypted and should be considered safe by security scanning tools. This change was introduced with ID 396752. Recommended Actions

To mitigate this vulnerability, you can use an iRule to encrypt the BIG-IP Analytics session cookie sent to the client. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules.
  3. Click Create.
  4. Enter a name for the iRule.
  5. In the Definition box, define an iRule that encrypts the BIG-IP Analytics session cookie.

    For example:

    when RULE_INIT {
        set static::encryption_passphrase abc123
    }

    when HTTP_REQUEST {
        set cookies [HTTP::cookie names]
        foreach cookiename $cookies {
            if {$cookiename starts_with "avr_"} {
                set cookieval [HTTP::cookie value $cookiename]
                set decrypted [HTTP::cookie decrypt $cookiename $static::encryption_passphrase]
                if { ($decrypted eq "") } {
                    HTTP::cookie remove $cookiename
                    HTTP::cookie insert name $cookiename value $cookieval
                }
            }
        }
    }

    when HTTP_RESPONSE_RELEASE {
        set cookies [HTTP::cookie names]
        foreach cookiename $cookies {
            if {$cookiename starts_with "avr_"} {
                HTTP::cookie encrypt $cookiename $static::encryption_passphrase
            }
        }
    }

  6. Click Finished.
  7. Associate the iRule with the virtual server.
