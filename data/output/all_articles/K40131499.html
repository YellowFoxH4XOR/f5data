Description

You should consider using this procedure under the following condition:

  • You want to allow end-user Windows devices to establish access sessions when the end user authenticates.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Your BIG-IP APM access policy is configured to use Windows credentials for Edge Client access. For instructions, refer to K14964: Configuring the BIG-IP APM access policy to use Windows credentials for Edge Client access.
  • You have administrative access to the BIG-IP APM system and the end-user Windows device.

Procedures

Configuring Dialup Entry/Windows Logon Integration

After customization, the BIG-IP APM administrator can download the Dialup Entry/Windows Logon Integration installation package and supply the package for use on end-user devices.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. From the local user device, log in to the BIG-IP APM Configuration utility.
  2. Navigate to Access > Connectivity/VPN > Connectivity > Profiles.
  3. Select the connectivity profile.
  4. From the Customize Package menu, select Windows.
  5. In the Available Components section of the Customize Windows Client Package window, ensure the following components are selected:
    • Dialup Entry/Windows Logon Integration
    • User Logon Credentials Access Service
  6. Click Dialup Settings.
  7. In the Phonebook Entry Name box, enter a name for your deployment.
  8. Click Download.
  9. Follow the on-screen steps to install the downloaded component installer package. This will create a Windows Dial-up and VPN adapter using the name specified in step 7.
  10. To launch the Dial-up and VPN adapter, click the Windows network icon in the lower-right corner, select the adapter name, and then click Connect.
  11. Log in to the BIG-IP APM access profile using the end-user credentials.
  12. Log out of the Windows client device.
  13. At the Windows login screen, enter the end user’s Windows credentials and select one of the following options:
    • Network logon (Windows 7)
    • Network sign-in (Windows 8)
    • Networks (Windows 10)

      Note: If the Network logon option does not appear on the Windows login screen, the feature may not be supported on your Windows version.

  14. In the Network Connections menu, select Dial-up and VPN.
  15. Enter the end-user credentials.
  16. Optional: If the Network Connections menu re-appears requesting login credentials, enter the end user’s BIG-IP APM access profile login credentials to re-attempt establishing the Dial-up and VPN adapter connection.

    Note: After successful authentication, the user is logged in to the Windows device and the Dial-up and VPN adapter connection is established.
