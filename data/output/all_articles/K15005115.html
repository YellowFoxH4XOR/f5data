Issue

Error Message

notice tmm[<PID>]: 01860019:5: MR_SIP: Ingress message queue full, closing TCP window (flow <Source IP Address:Port -> Destination IP Address:Port>)

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • <Source IP Address:Port -> Destination IP Address:Port> is the source/destination IP address and port of the Session Initiation Protocol (SIP) connection.

For example:

notice tmm[17986]: 01860019:5: MR_SIP: Ingress message queue full, closing TCP window (flow 10.0.0.1:45899 -> 10.0.0.50:5060)

Message Location

You may encounter this message in the following location:

  • /var/log/ltm

Description

This message occurs when one of the following conditions is met:

  • The system receives messages faster than it can process them.
  • An asynchronous iRules process occurs during a SIP or message routing (MR) iRules event, and while the iRules script is running, the system receives additional messages.

Impact

Once the queue exceeds the limit, the TCP window begins to close.

Recommended Actions

Rewrite the iRule to avoid asynchronous operations.
