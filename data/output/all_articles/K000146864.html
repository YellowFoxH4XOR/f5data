Description

I want to use a private repository with F5's virtual Kubernetes (vK8s) workload.

 

Environment

  • F5® Distributed Cloud
  • vK8s workload

Answer/Recommended Actions

No, this option is not allowed on our Virtual Kubernetes workload.

 

Additional Information

If you want to use private repositories you have to use Managed Kubernetes. To enable it you have to switch to advanced fields if you want to select it.
