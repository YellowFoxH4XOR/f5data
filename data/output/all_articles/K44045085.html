Description

This log message repeats regularly in the following locations:

  • /var/log/audit log file
  • System  ››  Logs : Audit : List in the BIG-IP GUI

info sshd(pam_audit)[<PID>]: 01070417:6: AUDIT - user root - RAW: sshd(pam_audit): user=root(root) partition=[All] level=Administrator tty=ssh host=<localhost_ip>

These logs may also be triggered when you run the following command with clsh on a VIPRON system: 
      clsh tmsh show sys cluster

Environment

  • The BIG-IP is a VIPRION platform
  • There are multiple blades in the chassis

Cause

This log message is recording the Primary blade of the Cluster establishing SSH communication with the other blades in the chassis.
It is normal behavior the Primary blade to communicate with the other blades in the chassis.
This is the BIG-IP operating as designed.

Recommended Actions

You can safely ignore this log message.
