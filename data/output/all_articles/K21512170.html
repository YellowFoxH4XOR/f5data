Issue

Description

Remote logging of Bot Defense messages in BIG-IP 12.1.x 

Environment

  • BIG-IP ASM
  • Bot Defense
  • BIG-IP 12.x and earlier
  • High-Speed Logging (HSL)

Cause

An iRule is used to log Bot Defense messages.

Recommended Actions

  • Log Bot Defense information for all IP addresses
  • Log Bot Defense information for a single IP address

Log Bot Defense information for all IP addresses:

Note: This procedure uses HSL: Clouddocs > BIG-IP API Reference > HSL::open.
  1. Go to Local Traffic > iRules.
  2. Select Create.
  3. Enter a name.
  4. Paste the following syntax into Definition:

    Note:  Replace <POOL_NAME> with the HSL pool name.

    when CLIENT_ACCEPTED {
    set hsl [HSL::open -proto UDP -pool <POOL_NAME>]
    }
    when BOTDEFENSE_ACTION {
            append log " source [IP::remote_addr]"
            append log " host [HTTP::host]"
            append log " uri [HTTP::uri]"
            append log " cs_possible [BOTDEFENSE::cs_possible]"
            append log " cs_allowed [BOTDEFENSE::cs_allowed]"
            append log " cs_attribute(device_id) [BOTDEFENSE::cs_attribute device_id]"
            append log " cookie_status [BOTDEFENSE::cookie_status]"
            append log " cookie_age [BOTDEFENSE::cookie_age]"
            append log " device_id [BOTDEFENSE::device_id]"
            append log " captcha_status [BOTDEFENSE::captcha_status]"
            append log " captcha_age [BOTDEFENSE::captcha_age]"
            append log " default action [BOTDEFENSE::action]"
            append log " reason \"[BOTDEFENSE::reason]\""
            log local0.  "IP= $clientip , $log"
            HSL::send $hsl $log
    }

  5. Select Finished
  6. Add the iRule to the virtual server.

Log Bot Defense information for a single IP address

Note: This procedure uses HSL: Clouddocs > BIG-IP API Reference > HSL::open.

  1. Go to Local Traffic > iRules.
  2. Select Create.
  3. Enter a name.
  4. Paste the following syntax into Definition:

    Note:

    • Replace <POOL_NAME> with the HSL pool name.
    • Replace <IP_ADDRESS> with the user's IP address.

    when CLIENT_ACCEPTED {
    set hsl [HSL::open -proto UDP -pool <POOL_NAME>]
    }
    when BOTDEFENSE_ACTION {
    if { [IP::addr $clientip equals <IP_ADDRESS>] } {
            append log " source [IP::remote_addr]"
            append log " host [HTTP::host]"
            append log " uri [HTTP::uri]"
            append log " cs_possible [BOTDEFENSE::cs_possible]"
            append log " cs_allowed [BOTDEFENSE::cs_allowed]"
            append log " cs_attribute(device_id) [BOTDEFENSE::cs_attribute device_id]"
            append log " cookie_status [BOTDEFENSE::cookie_status]"
            append log " cookie_age [BOTDEFENSE::cookie_age]"
            append log " device_id [BOTDEFENSE::device_id]"
            append log " captcha_status [BOTDEFENSE::captcha_status]"
            append log " captcha_age [BOTDEFENSE::captcha_age]"
            append log " default action [BOTDEFENSE::action]"
            append log " reason \"[BOTDEFENSE::reason]\""
            log local0.  "IP= $clientip , $log"
            HSL::send $hsl $log
      }
    }

  5. Select Finished.
  6. Add the iRule to the virtual server.
