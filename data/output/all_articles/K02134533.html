Description

ASM is logging legal requests, despite being configured to log only illegal requests.

Environment

  • Security policy
  • Logging

Cause

Session Awareness is enabled and configured to Log All Requests when a threshold is triggered.

This is configured at Security >> Application Security : Sessions and Logins : Session Tracking.

 

Recommended Actions

The logging is expected, so no action is required.

To prevent those requests being logged when a threshold is triggered, disable logging for each threshold under the Log All Requests tab, then apply the security policy.

Note: The symptoms described in this article might be seen even without using Session Awareness. In some cases, logging abnormalities are caused by a known issue, or inconsistency in ASM's configuration state. Upgrading to a recent release in your BIG-IP's software branch is recommended before opening a case with F5 Support for troubleshooting.
