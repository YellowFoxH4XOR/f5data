Known Issue

Connections may experience long delays during TCP loss recovery.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration includes one or more TCP profiles with the following settings:
    • Nagle's algorithm is disabled, which is the default value.
    • The Appropriate Byte Counting setting is enabled, which is the default value.
  • Your BIG-IP system is in TCP loss recovery phase due to packet loss.
  • The TCP congestion window size is smaller than the received TCP packet.
  • The server-side maximum segment size (MSS) is larger than the client-side MSS.

Impact

Remote clients may experience delayed or stalled TCP connections.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system fails to send full-size segments, though the TCP congestion window is large enough.
  • Remote clients experience delayed or stalled TCP connections.

Workaround

To work around this issue, perform one of the following procedures in the order of recommendation:

  • Enabling the Proxy Maximum Segment setting
  • Raising the initial congestion window size
  • Disabling ABC

Enabling the Proxy Maximum Segment setting

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Note: The Proxy Maximum Segment setting is enabled by default. You only need to perform this procedure if this setting is disabled.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Protocol > TCP.
  3. Under Name, click the appropriate TCP profile.
  4. Under Connection Setup, ensure the Proxy Maximum Segment setting is enabled.
  5. Click Update.

Raising the initial congestion window size

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Note: You should set the initial congestion window size to a number at least the size of the server-side MSS divided by the client-side MSS.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Protocol > TCP.
  3. Under Name, click the appropriate TCP profile.
  4. Under Data Transfer, modify the Initial Congestion Window value.
  5. Click Update.

Disabling the Appropriate Byte Counting setting

Impact of workaround: ABC is enabled by default. Disabling this setting may negatively impact traffic processing.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Protocol > TCP.
  3. Under Name, click the appropriate TCP profile.
  4. Under Congestion Control, ensure the Appropriate Byte Counting setting is disabled.
  5. Click Update.
