Topic

You should consider using this procedure under the following condition:

  • You want to configure the BIG-IP DNS system to allow recursion.

Description

When you configure a DNS server to allow recursion, the server queries other DNS servers to help requesting clients resolve domain names that are not authoritative. When you configure the DNS system to allow recursion, it also increases the system's vulnerability to DNS amplification attacks. For this reason:

  • Recursion is disabled by default in named.
  • DNS Express does not support recursion.  Use DNS Cache to support this functionality.
  • When you configure the system for recursion, the system provides recursive replies only to clients with source IP addresses within a self IP address subnet.

Under certain circumstances, you may want to configure DNS recursion on the BIG-IP DNS system. You can use the following procedures to enable recursion and define the IP subnets that receive recursive answers.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have access to the BIG-IP DNS system Configuration utility.

Procedures

  • Enabling DNS recursion on the BIG-IP DNS system
  • Restricting DNS recursion on the BIG-IP DNS system

Enabling DNS recursion on the BIG-IP DNS system

By default, the BIG-IP DNS system does not perform recursive DNS queries. You can use the following procedure to configure the system to perform recursion in named:

Impact of procedure: Performing the following procedure increases the number of DNS queries that the BIG-IP DNS system performs, increasing system resource use.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > Zones > ZoneRunner > named Configuration.

    Note: In BIG-IP 11.4.1 and earlier, navigate to Global Traffic > ZoneRunner > Named Configuration.

  3. In the Options box, scroll down to the options section, find the recursion no; statement, and edit it to read recursion yes;.
  4. Click Update.

Restricting DNS recursion on the BIG-IP DNS system

When you configure the system to allow recursion, the system sends recursive replies only to clients with source IP addresses within a self IP address subnet. You can use the following procedure to modify the default self IP address subnet.

Impact of procedure: Increasing the number of addresses in an IP subnet increases the number of DNS queries that the BIG-IP DNS system performs and therefore increases system resource use.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > Zones > ZoneRunner > named Configuration.

    Note: In BIG-IP 11.4.1 and earlier, navigate to Global Traffic > ZoneRunner > Named Configuration.

  3. In the Options box, scroll down to the end of the options section of the file and add a list of relevant IP addresses or network addresses for which you want the BIG-IP DNS system to provide recursive DNS queries.

    For example, the following internal access list contains the 192.168.10/24 network:

    acl "internal" { 192.168.10.0/24;};

    For example, the following internal access list contains the 10.10.0.0/16 and 192.168.10/24 networks:

    acl "internal" { 10.10.0.0/16; 192.168.10.0/24;};

  4. Add the following allow-recursion statement to the options section of the file, where internal matches the name of the access list:

    allow-recursion { internal; };

  5. Click Update.
