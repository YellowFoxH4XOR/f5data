Known Issue

Authenticated administrative users are redirected to a No Access error page while running the HA Wizard.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is running a version (includes engineering hotfixes) that contains the code fix for Bug IDs 1032405 and 941649.
  • An authenticated administrative user selects System > High Availability > HA Wizard in the Configuration utility.

Impact

You are unable to run or finish the HA Wizard process. 

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Provisioning HA setup using  HA Wizard reports No Access.
  • You may see an error similar to the following in the /var/log/webgui.log file:

    web.FormHandler:doAllowedCharactersCheck - /tmui/Control/form returning response as, No Access

Resolution

Status

F5 Product Development has assigned ID 1042993 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article.
