Source

Description

BIG-IQ License Manager or Data Collection Device (DCD) shows License Inoperative CLI prompt

Environment

  • Upgrade or Deploy BIG-IQ License Manager or DCD to a supported version and choose the option to skip licensing

Cause

The TMOS CLI prompt is checking for the bigip.license. However, the license is not present because the license for BIG-IQ is no longer required for BIG-IQ DCD or License Manager.

Recommended Actions

There is no known impact to this and it is purely cosmetic at this stage. 

Additional Information

The TMOS CLI prompt is MCPD's view of the bigip.license file. The registration information for BIG-IQ is stored in this endpoint which MCPD is not able to properly interpret at this time:

restcurl -u admin:admin /mgmt/tm/shared/licensing/registration
{
  "skipLicense": true, <---
  "registrationKey": "NO LICENSE", <---
  "versionDateTime": "xxxxxx",
  "machineId": "xxxxxxxxx",
  "generation": 0,
}
