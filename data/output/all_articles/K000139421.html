K000139421: SAML authentication (Azure as the external IdP) for MS Exchange websites

Type
Support Solution
Published
2024-04-26
Updated
2024-04-26
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.X, 17.1.1, 17.1.0
Source
https://my.f5.com/manage/s/article/K000139421

Description

You would like to implement SAML authentication (Azure is the external IdP) for MS Exchange websites. You would like to use SAML in ActiveSync communications. All of the URI and authentication are working (/owa, /ecp) except the following https://example.com/microsoft-server-activesync

In the browser (Firefox, Chrome, Edge) you can see a connection reset (PR_CONNECT_RESET_ERROR)

Environment

  • BIG-IP APM
  • Access Profile
  • SAML Authentication
  • ActiveSync
  • Microsoft Exchange Profile

Cause

The Microsoft Exchange Profile is interfering with the SAML configuration as the default authentication for ActiveSync in Exchange Profile is Basic.

Recommended Actions

Remove the Microsoft Exchange Profile from Access Profile

Additional Information

None
