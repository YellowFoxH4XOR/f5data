K000132544: You Cannot Associate A Trunk VLAN to More Than One Interface on r2xxx/r4xxx Platfoms

Type
Support Solution
Published
2023-02-15
Updated
2024-11-05
Applies to
  • rSeries Platforms
  • rSeries 2000
  • rSeries 4000
Source
https://my.f5.com/manage/s/article/K000132544

Description

You want to associate a Trunk VLAN to more than one interface but you find the check box of the target VLAN is disabled(greyed out). Or, when you are trying to configure a VLAN to multiple interfaces like the one below using the CLI, you find it shows the error:  Aborted: 'interfaces interface': Vlan may only have one member. The following vlans do not comply: <VLAN-TAG>

#config
interfaces interface 1.0
config type ethernetCsmacd
config enabled
ethernet switched-vlan config trunk-vlans [ 4096 ]
!
interfaces interface 2.0
config type ethernetCsmacd
config enabled
ethernet switched-vlan config trunk-vlans [ 4096 ]
!

appliance-1(config)# commit
Aborted: 'interfaces interface': Vlan may only have one member. The following vlans do not comply: 4096


Environment

  • F5OS-A
  • r2xxx/r4xxx Platforms
  • Configuring A Trunk VLAN to multiple interfaces.

Cause

This is not supported for F5OS-A versions before 1.8.0 for r2/r4 platforms. Since version 1.8.0, this is supported but extra caution should be considered to avoid L2 traffic loops. The new feature introduction manual is here: Manual Chapter : New Features in this Version on F5 Techdocs.

Note that higher platforms like r5xxx have the functionality to associate a Trunk VLAN to multiple interfaces even before 1.8.0.

Recommended Actions

For r2/r4 platforms before version 1.8.0, you may consider using LAG. For more information you may refer to K000133283: [F5OS-A] How to set a trunk vlan to multiple Interfaces on rSeries 2000/4000 series? or the Manual Chapter : Network Settings(rSeries) on F5 Techdocs.

For the r2/r4 version 1.8.0 and later, you will be able to configure one VLAN for multiple interfaces by enabling the below global configuration in the ConfD terminal:

NOTE: Adding the same VLAN ID to multiple interfaces could result in L2 loops. Special considerations should be made to the network topology to avoid L2 loops. 

config
system network config multi-interfaces-vlan enabled
commit

Additional Information

None.
