K000152543: Does an Origin Pool require all configured Health Checks to pass to be considered healthy?

Description

When you have two or more health checks configured on an origin pool do all of them need to pass for the origin pool to be marked as healthy?

Environment

Load Balancer, Origin Pool

Cause

Within a single Origin Pool every health-check you attach is evaluated conjunctively, so the pool is marked healthy only when all of its checks are passing. If any one of them fails the pool’s status drops to unhealthy and traffic is withdrawn until every probe recovers.

 

Recommended Actions

If you need an “either-or” result, for example, declare the service up when at least one of several different probes succeeds, the way to model that in F5XC is to create separate Origin Pools, each with its own check, and reference those pools from the load balancer (either with equal weights so traffic spreads while any pool is up, or with priority weights if you want a primary-fallback pattern). That keeps the checks independent and the load balancer will continue to serve traffic as long as one of the pools stays healthy.
