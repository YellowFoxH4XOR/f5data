K000161169: Persistent "Lost connection to tmm from gtmd" and "Connection to MCP failed" Error Logs on BIG-IP DNS

Description

BIG-IP DNS (GTM) systems continuously log the following errors:

  • Lost connection to tmm from gtmd
  • Connection to MCP failed

These messages appear persistently in /var/log/gtm and are not resolved by  disabling persistence, or removing GTM monitors. The errors  generate continuous alerts and log entries.

Environment

  • Product: BIG-IP DNS
  • Version: 17.1.3
  • tm.tcpstopblindinjection database key enabled

Cause

Enabling the tm.tcpstopblindinjection database key causes persistent "Lost connection to tmm from gtmd" and "Connection to MCP failed" error logs on BIG-IP DNS systems.

related with Bug ID 2132165: SMTP, SSH/SFTP, FTP connections fail after enabling tm.tcpstopblindinjection 

Answer/Recommended Actions

To resolve the issue:

  1. Disable the tm.tcpstopblindinjection database key on all affected BIG-IP DNS devices:
    tmsh modify sys db tm.tcpstopblindinjection value disable
  2.  upgrade to 17.1.3.1 or later released version which has ID2132165 fixed 

Additional Information

  • The issue is not related to NTP synchronization, configuration migration method, or persistence/monitor settings.
  • The error is reproducible in lab environments using affected UCS files.
  • Disabling the tm.tcpstopblindinjection key immediately stops the error logs.
  • The bug may also impact SMTP, SSH/SFTP, FTP, and internal GTM process communications.
