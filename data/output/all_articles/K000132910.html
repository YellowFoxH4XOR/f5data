K000132910: Not able to rediscover SSM configuration on BIG-IQ

Type
Support Solution
Published
2023-03-09
Updated
2023-03-09
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0
Source
https://my.f5.com/manage/s/article/K000132910

Description

Discovery of SSM module on BIG-IQ results in the following error message:

 

Failed calculating configuration differences; reason: Difference operation failed: Internal error: adding device-specific item with no device provided by caller (see log)

 

Environment

  • BIG-IQ
  • Unable to discover SSM

Cause

Bug ID1238405

Recommended Actions

Open case with F5 support and request JAR file with fix.

Additional Information

The JAR file will not survive an upgrade.

The JAR file is specific to the BIG-IQ version.

A new JAR file should be requested after upgrading to new BIG-IQ version unless already fixed.
