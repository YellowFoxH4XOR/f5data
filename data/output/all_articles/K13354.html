Known Issue

The Traffic Management Microkernel (TMM) may produce a core file while processing certain types of Secure Sockets Layer (SSL) traffic. This issue occurs when the following condition is met:

  • The BIG-IP system is configured with a virtual server that references a clientSSL profile.

Impact

The BIG-IP system temporarily fails to process traffic, and fails over if configured as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • A TMM core file generates in the /shared/core directory.
  • The BIG-IP system logs SIGSEGV or SIGFPE to the /var/log/tmm file.
  • The BIG-IP system logs an entry that appears similar to the following example into the /var/log/tmm file:

    panic: ../kern/xbuf.c:2273: Assertion "valid xfrag" failed

  • The BIG-IP system temporarily fails to process traffic.
