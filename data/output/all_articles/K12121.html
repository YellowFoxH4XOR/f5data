Known Issue

Note: For information about viewing the current running firmware version, and/or performing a firmware upgrade, refer to K9991: Upgrading the ARX firmware.

Important: Do NOT perform a firmware upgrade (technically, a downgrade) from version 5.1.0 (or later) to version 5.0.5 (or earlier).

This is the result of a known issue. Once an ARX system's firmware has been upgraded to the firmware provided in an ARX version 5.1.0 or later release, the system's firmware MUST NOT be upgraded (technically, downgraded) to firmware version 5.0.5 or earlier. If the ARX system firmware is upgraded from version 5.1.0 or later to version 5.0.5 or earlier, the system will become unresponsive and may require replacement.

The show firmware update verbose command may indicate an upgrade is available after booting to the earlier version.

For example:

Show Firmware Update Verbose
----------------------------

Slot  Firmware     Running         Current         Status
--------------------------------------------------------------------

1    Bootstrap     2.04.003.09681  2.04.003.09681  Up to date
1    Firetruck     17              17              Up to date
1    Diag          5.00.000.11559  5.00.000.11559  Up to date
1    BootLoader    5.00.000.11560  5.00.000.11560  Up to date
1    Hunchback     1               1               Up to date
1    NSM Boot      5.01.000.11898  5.00.000.11645  Upgrade available
1    NSM Diag      5.01.000.11898  5.00.000.11645  Upgrade available
1    NSM BootLdr   5.01.000.11898  5.00.000.11645  Upgrade available
1    NSM Boot      5.01.000.11898  5.00.000.11645  Upgrade available
1    NSM Diag      5.01.000.11898  5.00.000.11645  Upgrade available
1    NSM BootLdr   5.01.000.11898  5.00.000.11645  Upgrade available


However, you should NOT perform this upgrade. Performing this upgrade may result in the system becoming unresponsive and requiring replacement.

F5 Product Development tracked this issue as ID 33104 and it was fixed in ARX version 5.0.6. For information about upgrading, refer to the ARX release notes.

Workaround

Customers affected by this issue should contact F5 Technical Support, referencing this article and ID 33104.

To prevent this issue, do not perform a firmware upgrade from version 5.1.0 or later to version 5.0.5 or earlier. The ARX version 5.0.5 or earlier release will function properly with the version 5.1.0 or later firmware.
