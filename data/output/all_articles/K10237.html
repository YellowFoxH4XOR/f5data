Issue

In BIG-IP versions prior to 9.2.5, the BIG-IP system logs the Peer cert verify error message at the syslog level of warning. As a result, the BIG-IP system logs all SSL peer certificate verification errors by default. For example, if a configured certificate fails verification, the BIG-IP system rejects the connection request and logs a warning message that appears similar to the following example:

Peer cert verify error: unable to get local issuer certificate (depth 0; cert /C=MyCompany/OU=Network Support/CN=lb1.domain.com)

Beginning in BIG-IP 9.2.5, the BIG-IP system logs the Peer cert verify error message at the syslog level of debug. As a result, the BIG-IP system no longer logs SSL certificate configuration errors by default. For example, if a configured certificate fails verification, the BIG-IP system rejects the connection request without logging a warning message.

Enabling peer certificate verification messages

You can enable peer certificate verification messages on the BIG-IP system by changing the Log.Ssl.Level BigDB variable to debug. To do so, perform one of the following procedures:

Important: Changing the Log.Ssl.Level BigDB variable from warning to debug is not recommended except for troubleshooting purposes. If you leave the verbose logging enabled when the system is in normal production mode, the system might perform poorly. F5 recommends returning the db variable to the default value when you have completed the troubleshooting steps.

BIG-IP 11.x

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Set the Log.Ssl.Level to debug by typing the following command:

    modify /sys db log.ssl.level value debug

  3. Save the change by typing the following command:

    save sys config

Note: To revert the Log.Ssl.Level variable to warning, type the following commands:

modify /sys db log.ssl.level value warning

save sys config

BIG-IP 9.2.5 through 10.x

  1. Log in to the BIG-IP command line.
  2. Set the Log.Ssl.Level to debug by typing the following command:

    bigpipe db Log.Ssl.Level Debug

  3. Save the configuration by typing the following command:

    bigpipe save

Note: To revert the Log.Ssl.Level variable to warning, type the following commands:

bigpipe db Log.Ssl.Level warning

bigpipe save
