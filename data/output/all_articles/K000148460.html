Description

Error Message 

  • Error 51087: Add-on Module Key Module is explicitly Excluded for this Base Registration Key


In this error message, note the following: 

  • <Base Registration Key> is the base registration key of the product you are attempting to add the new add-on key
  • <Add-on Module Key and SKU> is the add-on key you are attempting to add

 

Message Location

You may encounter this message in the following locations:

  • In the Configuration utility, if you attempt to activate the add-on key using the Configuration utility
  • In the command line or TMOS Shell (tmsh), if you attempt to activate the add-on key using the tmsh install sys license add-on-keys command

 

This message occurs when:

An add-on module key is explicitly excluded for a base registration key, which means that the add-on key cannot be applied to the existing product base registration key. 
This situation occurs when the add-on key is not valid for the specific product base registration key you are trying to add it to. 

 

Impact:  As a result, you will be unable to activate the new add-on key for your F5 product. 


Environment

Licensing:

    • BIG IP

    • BIG IQ

Cause

Applying Add-on Module Key Module that is explicitly Excluded for this Base Registration Key.

​​​​​​​

Answer/Recommended Actions

To address this issue, it is recommended to contact your F5 sales representative to verify if the add-on key is compatible with the product base registration key.
Alternatively, you can reach out to F5 Technical Support for further assistance by following the instructions provided in K2633 for submitting a support case to F5.
