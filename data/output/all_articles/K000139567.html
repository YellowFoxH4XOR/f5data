Description

After migration of their AD/DNS from software version 2016 to 2019---the Exchange server remained in 2013. changed the domain controller host name, and all outlook clients of the public users is in disconnected state---no issues for internal users, and OWA is working.

Also upgraded BIG-IP from v12 to latest version, the issue still remained the same.

/var/log/apm has similar to below log

apmd[<PID>]: 01490106:4: /Common/<access_policy>:Common:<session_ID>: AD module: authentication with 'ml291' failed: Preauthentication failed, principal name: <user>@<domain>. Invalid user credentials. (-1765328360)

 

in tcpdump with the Kerberos, can see multiple error KRB5KDC_ERR_PREAUTH_REQUIRED and KRB_ERR_RESPONSE_TOO_BIG

<AD server IP> <BIG-IP IP> KRB5 377 IN s1/tmm0 : KRB Error: KRB5KDC_ERR_PREAUTH_REQUIRED

<AD server IP> <BIG-IP IP> KRB5 288 IN s1/tmm0 : KRB Error: KRB5KRB_ERR_RESPONSE_TOO_BIG

 

Environment

  • BIG-IP APM
  • Outlook Client
  • AD upgrade
  • Kerberos

 

Cause

  • AD upgrade caused the MaxTokenSize smaller and it is not enough size for the environment.

Recommended Actions

  • Increase MaxTokenSize in AD server
