K16769: Fetching Active Directory nested and primary groups requires an admin account configured in the AAA object

Issue

Old Behavior

In versions prior to BIG-IP APM 11.5.0, configuring the admin account (Admin Name/Admin Password fields) in the AAA object was not a requirement for the AD Query action to fetch primary groups or nested groups.

New Behavior

Beginning in BIG-IP APM 11.5.0, configuring the admin account (Admin Name/Admin Password fields) in the AAA object is a requirement for the AD Query action to fetch primary groups or nested groups. This new behavior is a result of a change in how the Active Directory group cache is built in the BIG-IP APM system.

Impact

The AD Query action configured to fetch primary groups or nested groups will fail if an admin account with sufficient rights is not configured in the AAA object.
