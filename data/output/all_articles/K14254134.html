Description

SNMP tool SNMPv3 GetBulk request timeout when trying to request pool names list.

  • Error message in /var/log/daemon.log is logged
err snmpd: send response: Too long

Environment

  • SNMP tool advertises a small SNMPv3 msgMaxSize less than 1500 octets in its GetBulk request
  • BIG-IP configuration includes a long list of pool names

Cause

BIG-IP generated Response-PDU that exceeds the SNMP tool SNMPv3 msgMaxSize limit is discarded.

Recommended Actions

SNMP tool needs to increase its msgMaxSize setting to accommodate expected large response PDU from BIG-IP.
