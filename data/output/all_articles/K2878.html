Topic

When connecting to the BIG-IP proxy using specific lists of permitted ciphers, you may receive the following error message:

No compatible ciphers

This is expected behavior and does not indicate a problem with the BIG-IP system.

If you would like to prevent BIG-IP from logging this error message, you can change this behavior by modifying the OpenSSL operation through the bigdb key, Common.Bigip.Proxy.SSLOptions.

To implement this change, perform the following steps:

  1. Type the following command:

    bigpipe db set Common.Bigip.Proxy.SSLOptions = "0x8388608"

  2. Restart the proxy to initiate the new options by typing the following command:

    bigpipe load
