Note: For information about displaying the version information for other F5 products, refer to K914: Displaying the software version of your F5 product.

Configuration utility

To display the BIG-IP version information using the Configuration utility, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click System.
  3. Click the Properties tab.

    The version displays in the Kernel Version box.

Command line

To display the BIG-IP version information using the command line, type the following command:

bigpipe version
