Known Issue

IPsec tunnels are unstable when the tunnel endpoint is a Cisco device with an older Dead Peer Detection (DPD) implementation.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP system to use a point-to-point IPsec tunnel.
  • The IPsec tunnel endpoint is a Cisco device that has an older DPD implementation.

Impact

The IPsec tunnel remains unstable as the status changes continuously between up and down.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The IPsec tunnel is unstable as the status continuously changes between up and down.
  • In the /var/log/racoon.log file, you may observe error messages similar to the following example:

    ERROR: Cookie mismatch in DPD ACK!.
    DPD: remote (ISAKMP-SA spi=8f4441e38e32262dkcu24df78a0d83krej1) seems to be dead.
    INFO: purging ISAKMP-SA spi=8f4441e38e32262dkcu24df78a0d83krej1.

Workaround

There is no workaround for this issue. To stabilize the IPsec tunnel, disable DPD.
