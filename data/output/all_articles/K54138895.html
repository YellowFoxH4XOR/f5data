Description

  • DoS profiles with BaDoS enabled may be limited to a maximum of 70 Virtual Servers
    Note: 70 virtual servers is a recommended value and not a hard limit. Your specific platform may accommodate a higher or lower maximum number of virtual servers with BaDoS enabled dependent on your configuration and available resources.
  • High Monpd memory usage

Environment

  • More then 70 virtual servers configured with DoS profiles that have BaDoS enabled.

Cause

This is expected behavior due to the high amount of memory usage for Monpd caused by BaDoS' functionality.
Note: The specific BIG-IP platform's maximum memory may change the maximum number of Virtual Servers with DoS with BaDoS enabled. Platforms with lower maximum memory may not be able to configure the maximum number of Virtual Servers.

Recommended Actions

  • Reduce the number of virtual servers with DoS profiles that have BaDoS enabled.
