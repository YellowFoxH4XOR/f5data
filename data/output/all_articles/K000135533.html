K000135533: SSRF test failure after applying ASM policy

Type
Support Solution
Published
2023-07-19
Updated
2025-01-14
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000135533

Description

Testing for SSRF vulnerabilities (requests includes a URI parameter) on a Virtual Server with ASM policy could generate DNS queries to resolve the Host. This could result in some SSRF test failures.

 

Environment

BIG-IP ASM 16.x, 17.x

 

Cause

The SSRF test fails because BIG-IP ASM tries to resolve the URI parameter in the request. This is an expected behavior when the SSRF Host configuration is set to Resolve. This is the default configuration.

 

Recommended Actions

The wildcard configuration cannot be deleted. Instead set this to Deny to stop the DNS queries.

 

Find the configuration in the GUI:

Navigate to Security ›› Application Security : Security Policies : Policies List

Select the ASM policy attached to the Virtual Server

Expand Advanced Protection

Select SSRF Protection

Look for the wildcard configuration.

Click on the Edit (pencil) button

Set the Action to Deny

Click Update button

Click Save and Apply Policy
