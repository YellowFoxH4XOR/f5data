Description

You would like to understand the assigned value for remote-port osp listed in the output of the following TMSH command:
tmsh list sys syslog
sys syslog {
    remote-servers {
        /Common/mysyslog {
            host 172.1.10.1
            remote-port osp
        }
    }
}

Environment

  • syslog server remote port config
  • syslog server 
  • tmsh

Cause

None.

Recommended Actions

Actually, the string also means the port, and there is a map where you can check the corresponding relationship between the string and port from IANA: Service Name and Transport Protocol Port Number Registry. 
Note: The above links take you to resources outside of AskF5. Third parties could remove these documents without our knowledge.
The IANA service names are also listed in the file /etc/services on the BIG-IP system, so you can also get the port info by running the command cat /etc/services | grep osp:
osp             5045/tcp                # Open Settlement Protocol
By checking the link or running the cat command, you may know the osp string in the example means the port of 5045.

Additional Information

Anyway, the system would store the syslog remote port as a number rather than a string, for details you may check the config file under /config/bigip_base.conf.
For example, you can use the below command to check your syslog remote port config:
cat /config/bigip_base.conf
sys syslog {
    remote-servers {
        /Common/remotesyslog1 {
            host 172.1.10.1
            remote-port 5045
        }
    }
}
