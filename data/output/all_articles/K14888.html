Topic

You should consider using this procedure under the following condition:

  • You want to display the BIG-IQ software version information.

Description

You can use the Traffic Management Shell (tmsh) or the BIG-IQ user interface to display the BIG-IQ software version.

Prerequisites

You must meet one of the following prerequisites to use this procedure:

  • You can access tmsh.
  • You have a valid user account to access the BIG-IQ user interface.

    Note: BIG-IQ 4.0.0 requires an account with an Administrator role.

Procedures

  • Using tmsh to display the BIG-IQ software version
  • Using the BIG-IQ user interface to display the BIG-IQ software version in BIG-IQ 5.2.0 and later
  • Using the BIG-IQ user interface to display the BIG-IQ software version in BIG-IQ 5.0.0 - 5.1.0
  • Using the BIG-IQ user interface to display the BIG-IQ software version in BIG-IQ 4.1.0 and later
  • Using the BIG-IQ user interface to display the BIG-IQ software version in BIG-IQ 4.0.0

Using tmsh to display the BIG-IQ software version

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To display the BIG-IQ software version, type the following command:

    show /sys version

Using the BIG-IQ user interface to display the BIG-IQ software version in BIG-IQ 5.2.0 and later

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ system.
  2. Navigate to System > THIS DEVICE > General Properties.

    The software version displays in the Version Installed field.

Using the BIG-IQ user interface to display the BIG-IQ software version in BIG-IQ 5.0.0 - 5.1.0

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ system.
  2. Navigate on the menu to System Management > BIG-IQ HA > Select the local host's device name > Software Version.

    The software version displays in the Version Installed field.

Using the BIG-IQ user interface to display the BIG-IQ software version in BIG-IQ 4.1.0 and later

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ system.
  2. In the upper-right corner of the screen, move your pointer over the host name of the BIG-IQ system, and the BIG-IQ software version will display.

    For example, the version displayed may appear similar to the following example:

    BIG-IQ 4.4.0.0.0.5858

    In this example, the BIG-IQ software version is 4.4.0 and the build number is 0.0.5858.

Using the BIG-IQ user interface to display the BIG-IQ software version in BIG-IQ 4.0.0

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ system using the credentials of an Administrator role.
  2. Click the TMOS menu.
  3. Navigate to System > Configuration > Device > General.

    The software version displays in the Version field.

    For example, the version and build for BIG-IQ 4.0.0 may appear similar to the following example:

    BIG-IQ 4.0.0 Build 1114.0 Final
