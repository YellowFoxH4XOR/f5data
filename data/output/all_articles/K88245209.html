Recommended Actions

The best way to approach it is to delete sslo config on both boxes and re-create.

Click the 'cleanup' (trash) button on each sslo and recreate. If you cannot because the button is greyed out, then try uninstalling sslo rpm from both boxes, then reinstalling.

You can uninstall using iappslx page. Navigate to:

iapps -> package management LX
