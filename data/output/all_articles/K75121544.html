K75121544: DNS with Response Code [5] ''REFUSED'' causes FQDN Pool or Node(s) down

Type
Support Solution
Published
2022-08-12
Updated
2023-02-21
Status
Final
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.X, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.8, 15.1.1, 15.1.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K75121544

Description

  • FQDN pool members/nodes were marked down or unavailable
  • May have multiple DNS servers configured and some of the DNS server may be working as expected (for example: DNS server response verified using dig command)
  • Log message similar to the following can be found in /var/log/dynconfd.log
2022-07-03 03:23:30.967159 (7372) [E]: [BIG-IP-01.local]: FQDN does not exist. DNS query returns NXDOMAIN


Environment

  • BIG-IP LTM
  • FQDN pool members/nodes


Cause

DNS server response with RCODE 5 - REFUSED.

DNS server returns a valid DNS answer (RCODE 5 - REFUSED), BIG-IP will not query the next DNS server in the DNS server list.

Note: For more information about RCODE 5 - REFUSED, please refer to RFC 1035.

Note: This link takes you to a resource outside of AskF5, and the third party could remove the document without our knowledge.


Checking DNS response with dig

[BIG-IP-01.local] ~ # dig @172.16.10.1 example.node.local

; <<>> DiG 9.11.22 <<>> @172.16.10.1 example.node.local
; (1 server found)
;; global options: +cmd
;; Got answer:
;; ->>HEADER<<- opcode: QUERY, status: REFUSED, id: 40448
;; flags: qr rd; QUERY: 1, ANSWER: 0, AUTHORITY: 0, ADDITIONAL: 1

--- output omitted for brevity ---


Recommended Actions

Either of the following can resolve the issue.

  • Investigate and resolve the DNS Server that responded with RCODE 5 - REFUSED.
  • Remove DNS Server that is giving RCODE 5 - REFUSED from BIG-IP DNS server list.
