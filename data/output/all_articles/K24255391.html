Description

  • Even when From Address is configured in STMTP parameters, From Address is replaced by the email address root@HOSTNAME by the BIG-IP system.
  • SMTP server filters might reject the email as the sender email is not the one configured.

Environment

Relevant environmental factors specific to the topic

  • SMTP configured in the BIG-IP system.
  • SMTP is configured with the corresponding From Address. 
  • The SMTP From Address is the email address that the email is being sent from. This is the "Reply-to" address that the recipient sees.
  • FromLineOverride disabled.

Cause

In versions prior to BIG-IP 13.0.0, the TMOS Shell (tmsh) does not have the ability to configure the FromLineOverride settings in the Secure Simple Mail Transfer Protocol (SSMTP) configuration.

The FromLineOverride setting is set to disabled by default. You can leave this setting in the default configuration unless you have custom alerts configured in the /config/user_alert.conf file to send the email notifications using a non-default fromaddress parameter. The fromaddress parameter uses root as the default user.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Log in into the BIG-IP CLI.
  2. To configure the FromLineOverride setting, use the following command syntax:
tmsh modify /sys outbound-smtp from-line-override <enabled|disabled>
  1.  Save the changes, use the following command syntax:
tmsh save sys config
