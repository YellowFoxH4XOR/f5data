Known Issue

This is the result of a known issue. When copying a folder with a large group of files to an existing folder on a shared drive, the Mac OS X 10.6 client may occasionally receive a pop-up message that appears similar to the following example:

finder cannot read or write files. error code -36.

Note: No error messages are logged on the ARX system.

Important: This issue no longer occurs starting in Mac OS X 10.6.4.

F5 Product Development tracked this issue as ID 39755 and 38000 and it was fixed in ARX 5.1.7. For information about upgrading, refer to the ARX Release Notes.

Additionally, this issue was fixed in ARX 5.1.5 Hotfix 5 (build-11975) and 5.1.0 Hotfix 4 (build-11933). You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

Workaround

This issue is random and infrequent. Repeating the copy operation is usually successful. Additionally, users can install Mac OS X 10.6.4 or later using Software Update to resolve this issue.
