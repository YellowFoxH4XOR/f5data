Description

When installing the BIG-IP Edge Client on Windows 11, installation may fail with the following error message:

Module C:\Program Files (x86)\F5 VPN\f5papi.dll failed to register. HRESULT -1073741819. Contact your support personnel.

Environment

  • BIG-IP Edge Client
  • Windows 11
  • Installation Directory: C:\Program Files (x86)\F5 VPN\
  • Security software or endpoint protection enabled at time of installation

Cause

The issue occurs when local security software blocks the registration of the f5papi.dll file during installation, causing the client to be incomplete or non-functional.

Recommended Actions

  • Temporarily disable any antivirus software and try install again.
  • Add an exclusion/whitelist for the Edge Client installation directory (for example, C:\Program Files (x86)\F5 VPN) and specifically for f5papi.dll within your security software settings.
