Description
Unable to access GUI while able to SSH to the BIG-IP 

Environment

  • LTM
  • GUI
  • SSH

Cause
None

Recommended Actions

Run the following commands during a maintenance window in order to fix the issue:

tmsh modify sys db provision.extramb value 500
tmsh modify sys db provision.tomcat.extramb value 200
tmsh modify sys db restjavad.useextramb value true
bigstart restart restjavad && sleep 20 && bigstart restart restnoded

Important: The above commands can cause a short traffic disruption. (HA failover might occur while the services restart)

Note: It is always recommended to take a UCS backup and arrange for a maintenance window before performing any activities on the BIG-IP.
