Description

BIG-IP cluster device group changes to Changes Pending at the same time, every day, but nobody did any change.

Environment

  • BIG-IP APM provisioned

Cause

Dynamic file is downloaded/discovered for APM Network Access Address Space object.

For example:

apm resource address-space /Common/O365_addr_space {
    cfg-uri https://example.com/endpoints
    discovery-interval 1440
    dns { <snip> }
    ipv4 { <snip> }
    ipv6 { <snip> }
    last-discovery-time 2022-06-25:16:05:01
    trusted-ca-bundle /Common/ca-bundle.crt
    type microsoft
}

This triggers an immediate Changes Pending when the discovery task is activated.

Note: The frequency may not be daily if a different discovery-interval is in use.

Recommended Actions

No action is required, but the discovery-interval can be increased, if desired.
