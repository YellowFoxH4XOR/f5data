Description

After upgrading the BIG-IP LTM Virtual Edition (VE) instances in Azure Marketplace, users may experience that the F5 Cloud Failover Extension (CFE) stops functioning. This issue typically arises immediately after performing an OS upgrade, where CFE fails to operate as expected and may require manual reinstallation to restore its functionality.

Environment

  • BIG-IP VE
  • Azure
  • CFE

Cause

The default timeout value for the database key iapplxrpm.timeout (set at 60 seconds) is often insufficient for the CFE installation or upgrade process during BIG-IP OS upgrades, leading to failures in CFE operation.

Recommended Actions

To prevent CFE failures during future BIG-IP OS upgrades:

 

  1. On both active and standby BIG-IP devices, execute:
    tmsh modify sys db iapplxrpm.timeout value 300
    tmsh save sys config
  2. Verify the new setting:
    tmsh list sys db iapplxrpm.timeout all-properties
  3. Confirm that the value is set to 300 seconds on all HA devices before starting the upgrade.
  4. Proceed with your OS upgrade.

Additional Information

  • The change to iapplxrpm.timeout must be applied individually on each device in an HA pair.
  • The recommended value of 300 seconds falls within the supported range of 30–600 seconds.
  • Adjusting this setting should not cause service disruption.
