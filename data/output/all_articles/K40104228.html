Issue

Error Message

01260014:3: Cipher <cipher> negotiated is not configured in profile <profile_name>.

In this error message, note the following:

  • The <cipher> is the SSL cipher in hex format.
  • The <profile_name> is the name of the SSL profile processing the connection.

For example:

01260014:3: Cipher 9d:5 negotiated is not configured in profile /Common/example_ssl

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • The Proxy SSL option has been enabled in the Client and Server SSL profiles.
  • The Proxy SSL Passthrough option has not been enabled in the Client and Server SSL profiles.
  • The cipher negotiated by the client and server is not supported in one of the SSL profiles.

Note: This message has been deprecated as of BIG-IP 12.0.0. For information regarding a similar message logged in BIG-IP 12.0.0 and later, refer to K42945549: Error Message: 01260025:3: Cipher c013:5 negotiated is not supported by Proxy SSL configured in virtual server /Common/example_ssl.

Impact

The SSL connection will fail.

Recommended Actions

  • Ensure that the Client and Server SSL profiles are configured to support all required ciphers.
  • Reconfigure the backend SSL server to negotiate only ciphers allowed by the Client and Server SSL profiles.
