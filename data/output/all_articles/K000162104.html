K000162104: XC CDN Cache Rules Expression Terms are ANDed Together

Description

When configuring CDN Cache rules in the XC console you can add several Terms to an Expression. These terms are ANDed together. This can lead to inadvertent cache Bypasses.

Environment

  • F5® Distributed Cloud HTTP Load Balancer
  • F5 XC CDN
  • CDN Cache Rules

Answer/Recommended Actions

A customer may want to cache all image files in the "Images" directory as well as all of the images in the "images" directory. However, this will not work as one expression:

 

 

In the F5 XC schema, multiple criteria placed inside a single cache_rule_expression array are ANDed together. Because we placed both path_match blocks inside the same cache_rule_expression list, the proxy requires the HTTP request path to simultaneously start with /images/ AND /Images/. Since this is physically impossible, the rule will never trigger.

To fix this, we have two options: We can either separate the paths into different expressions within the rule_expression_list (since those are evaluated sequentially until the first match occurs), or we can consolidate them into a single MatchRegex operator.
