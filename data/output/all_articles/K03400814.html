Known Issue

An error may occur when using the Configuration utility to modify Client SSL profiles using password protected keys.

This issue occurs when all of the following conditions are met:

  • Your configuration includes one or more Client SSL profiles using a password protected Secure Sockets Layer (SSL) key.
  • You attempt to modify the Client SSL profile using the Configuration utility.

Impact

The Client SSL profile cannot be modified using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you modify a Client SSL profile using the Configuration utility, you observe an error message similar to the following example:

    01070313:3: Error reading key PEM file /config/filestore/files_d/Common_d/certificate_key_d/:Common:example.key_45678_1 for profile /Common/example-clientssl: error:0907B068:PEM routines:PEM_READ_BIO_PRIVATEKEY:bad password read

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to modify the Client SSL profile.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
