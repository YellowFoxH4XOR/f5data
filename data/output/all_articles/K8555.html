Known Issue

This is the result of a known issue. When a user selects a Citrix MetaFrame Portal Terminal Server favorite, FirePass contacts the Citrix master browser using anonymous credentials to obtain a list of published applications. If successful, FirePass displays a link for each retrieved application on the webtop, and the user is prompted for Citrix credentials after selecting one of the application links. Since FirePass obtains the application list before prompting the user for Citrix credentials, FirePass may display links to applications for which the user does not have the necessary Citrix permissions to execute. If the user attempts to execute a Citrix application without the necessary permissions, the user receives an error message from the Citrix client software.

Note: In previous versions of FirePass software, FirePass did not contact the Citrix master browser using anonymous credentials. For more information, refer to K8554: Change in Behavior: FirePass uses anonymous credentials to retrieve Citrix MetaFrame Portal published application list.

If FirePass cannot obtain an application list using anonymous credentials, FirePass prompts the user for Citrix credentials in order to obtain a list of published applications from the Citrix master browser. In this instance, FirePass obtains the application list using the supplied Citrix credentials, and the user can execute all Citrix applications listed on the webtop.

F5 Networks Product Development tracked this issue as CR89471 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-602-2 has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

Installing Cumulative Hotfix HF-602-2 or a later version of the Cumulative Hotfix adds the Use anonymous credentials to retrieve application list from Citrix servers check box to the Application Access: Terminal Servers: Master Group Settings page. By default, this check box is cleared. When the Use anonymous credentials to retrieve application list from Citrix servers check box is cleared, FirePass prompts the user for credentials in order to retrieve the published application list from the Citrix master browser. When the check box is selected, FirePass uses anonymous credentials to retrieve the published application list from the Citrix master browser.

Important: The Use anonymous credentials to retrieve application list from Citrix servers check box is a master group setting, not a global setting.

Alternatively, if the logon credentials for the FirePass master group are identical to the logon credentials for the Citrix server, you can work around this issue by performing the following procedure:

  1. Logon to the FirePass Administrative Console.
  2. Navigate to the Application Access : Terminal Servers : Master Group Settings page.
  3. In the Master Group menu, select the name of the master group you want to configure.
  4. Select the Auto-logon to applicable Terminal Servers using FirePass user logon credentials check box.

Note: By selecting the Auto-logon to applicable Terminal Servers using FirePass user logon credentials check box, FirePass will attempt to auto-logon to all Terminal Server favorites configured for the master group, not just Citrix MetaFrame Portal Terminal Server favorites.
