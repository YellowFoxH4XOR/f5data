K10148: The Protected Workspace inspector now includes configuration options for saving files to external media

Issue

Previously, users in Protected Workspace were able to save files to a writeable CD drive, but not to a USB flash drive. Starting in cumulative hotfix HF-603-3, the Protected Workspace inspector now includes the following two configuration options:

  • Allow user to record CDs

    Note: This option corresponds to the Windows XP CD recording feature, which does not support DVD disks. Additionally, this option does not support Windows 2000 and Windows Vista clients.
     
  • Allow write access to USB flash drives

These options allow FirePass administrators to define whether users in Protected Workspace can save files to external media.
 
Note: For information about configuring the Protected Workspace inspector, refer to the FirePass Controller Administrator Guide.
 
F5 Product Development tracked this enhancement as CR108131.
