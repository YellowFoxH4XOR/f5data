Description

APM RDP Resources with SSO enabled may fail to launch or allow users to authenticate, when using an Android Tablet.
Users may receive repeated password prompts when attempting to launch RDP links or they may receive an authentication failure.
 

Environment

  • Big-IP APM RDP Resource
  • Android Tablet

Cause

This issue is caused by ID910169

Support for RDP 10.x client on Android RDP resources will not work when SSO is enabled on the APM RDP resource configuration. 
This is fixed in versions v17.0, v16.1.3.1, v15.1.6.1, and v14.1.5.1, where you can now use RDP resources with SSO enabled.

Recommended Actions

  1. Upgrade to a fixed F5 software version that supports RDP with SSO enabled on Android Tablets
  2. Disable SSO in the APM RDP resource configuration
