Topic

FirePass and the BIG-IP APM system do not currently support the routing compartment feature in the Windows Next-Generation TCP/IP Stack. Routing compartments are used to prevent network traffic from being accessible between users logged into the same computer using a remote connectivity solution, such as Remote Desktop, at the same time. Users have the ability to configure routing compartments that will prevent multiple users from passing traffic over a VPN connection in Windows 7, Windows Server 2008, and some versions of Windows Vista.

For more information on routing compartment, refer to your Windows documentation.
