K000149608: Cannot apply change to ASM Policies : The table '<table-name>' is full.

Type
Support Solution
Published
2025-02-13
Updated
2025-02-27
Source
https://my.f5.com/manage/s/article/K000149608

Description

The BIG-IP fails to apply ASM policy changes. The GUI shows pending changes, but when attempting to apply them, the screen refreshes without saving the updates. Relevant error messages in ASM Logs include: 

ASM subsystem error (asm_config_server.pl): Could not update the BotIncident. Failed to insert to PRX.BOT_INCIDENT_TOP_IPS: The table 'BOT_INCIDENT_TOP_IPS' is full.

ASM subsystem error (asm_config_server.pl): Failed on insert to PLC.PL_SUGGESTIONS: The table 'PL_SUGGESTIONS' is full.

Environment

  • BIG-IP ASM
  • An ASM Policy is configured with pending changes.

Cause

These errors are generated when a MySQL table becomes full. This can lead to several issues such as ASM not being able to apply changes to the policy. 

Recommended Actions

Impact of Procedure: This procedure will empty the specified MySQL tables, which may cause some data such as logs to be cleared from the device. 

Manually clear the MySQL tables shown in the logs with the following command:

mysql -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e "TRUNCATE <DATABASE>.TABLE_NAME>;"

Example:

  • To manually clear the 'BOT_INCIDENT_TOP_IPS' table in the 'PRX' database, you would use the following command:
  • mysql -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e "TRUNCATE TABLE PRX.BOT_INCIDENT_TOP_IPS;"

Locate the MySQL table.

In most cases, the log will include the database with the table name, such as 'PRX.BOT_INCIDENT_TOP_IPS'. However, if the there is no database included, as in 'PL_SUGGESTIONS', you can locate the database using the following commands:

  • List all tables in a database
    • mysql -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e 'USE PRX; SHOW TABLES;' 
  • List all available databases
    • mysql -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e 'USE PRX; SHOW TABLES;'
  • Search for a specific table name within a database. (Example: PL_SUGGESTIONS)
    • mysql -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e 'USE PLC; SHOW TABLES LIKE "%PL_SUGGESTIONS%";'
