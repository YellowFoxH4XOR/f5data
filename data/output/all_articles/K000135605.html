Description

In an IPv6 network segment, the first and last addresses of a subnet are typically reserved and are not available for assignment to individual devices.  
The last address of the subnet is reserved for the network broadcast address which cannot be assigned to an individual device.

This is similar to IPv4 networking, where the first and last addresses of a subnet are reserved for the network address and the broadcast address respectively.
 

Symptoms

If the last address of a subnet is configured as a Self-IP, the connection request to this Self-IP will be dropped, leading connection failure.

For example, if 2001:DB8::3/126 (mask ffff:ffff:ffff:ffff:ffff:ffff:ffff:fffc) is configured as a Self-IP, all connections to this Self-IP should fail.
In this case, it actually means that the network portion is 2001:DB8::0/126, and the host portion can range from 1 to 2, making the usable addresses 2001:DB8::1 and 2001:DB8::2.  The address 2001:DB8::3 would be the broadcast address for this subnet, and therefore it cannot be assigned to an individual device.
 

Environment

  • LTM
  • IPv6


Recommended Action

This is expected.
Please avoid configuring the last addresses of IPv6 network segment as a Self-IP.
