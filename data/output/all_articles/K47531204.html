Description

"security device-id attribute" appears in /config/bigip_base.conf after upgrading to 13.1.0 or later. 

For example, /config/bigip_base.conf contains:
  
security device-id attribute /Common/att01 {
    id 1
}
security device-id attribute /Common/att02 {
    id 2
}
security device-id attribute /Common/att03 {
    id 3
}
 

Environment

  • BIG-IP system 13.1.0 or later. 
 

Cause

This is by design. 
 

Recommended Actions

  • You can safely ignore this settings.

None
