Description

Blade in offline state, with reason 'Slot Failed: got signal (Terminated); stopping'.

From tmsh command 'show /sys cluster all-properties' it shows the status and the reason:

show /sys cluster all-properties
----------------------------------------------------------------------

----------------------------------------------------------------------

Availability            available
State                   enabled
Reason                  Cluster Enabled
Primary Slot ID         1
Primary Selection Time  12/06/2023 08:24:59
  --------------------------------------------------------------------------------------------------------------------
  | Sys::Cluster Members
  | ID  Address               Availability     State     Licensed  HA               Clusterd      Reason
--------------------------------------------------------------------------------------------------------------------
    1   10.10.10.169          available        enabled   true      active           running       Run
    2   10.10.10.170          offline          enabled   true      unknown          shutdown      Slot Failed: got signal (Terminated); stopping
    3   10.10.10.171          available        enabled   true      active           running       Run
    4   10.10.10.172          available        enabled   true      active           running       Run

  • VIPRION blade B4300 (A108)
  • VIPRION blade B4340N (A110)

Cause

  • BIG-IP is in Offline state.
  • BIG-IP platforms may be susceptible to parity errors.

Recommended Actions

  1. Reseat the blade to boot up
  2. If the issue persists, run an EUD test and share results with F5 support.
