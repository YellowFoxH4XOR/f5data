Known Issue

This is a result of a known issue. The mcpd process can leak memory when Enterprise Manager is used to transfer a configuration from one system to another system. The memory leak occurs in the mcpd of the BIG-IP LTM system from which the Enterprise Manager is pulling the configuration.

F5 Product Development tracked this issue as CR76340 and it was fixed in BIG-IP LTM 9.4.1. For information about upgrading, refer the BIG-IP LTM Release Notes.
