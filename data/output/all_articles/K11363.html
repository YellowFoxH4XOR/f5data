Known Issue

This is the result of a known issue. The LCD System Menu displays, by default, when a system is started and allows basic configuration options from the keypad next to the LCD display. If you disable the LCD System Menu, the change does not persist across restarts. As a result, the LCD System Menu displays after the system has restarted.

F5 Product Development is tracking this issue as ID 225431 (formerly CR139366).

Workaround

To prevent access or configuration changes from the LCD Systems Menu, you can re-enable and then disable the LCD System Menu after each system restart. To do so, perform one of the following procedures:

Command line

BIG-IP 11.x

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Re-enable the LCD System Menu by typing the following command:

    modify sys global-settings lcd-display enabled
  3. Disable the LCD System Menu by typing the following command:

    modify sys global-settings lcd-display disabled

    Note: You do not need to issue the save /sys config command. The modify sys global-settings lcd-display command automatically updates the tmsh database and sets the appropriate value for the option.

BIG-IP 9.4.0 through 10.x

  1. Log in to the BIG-IP system.
  2. Re-enable the LCD System Menu by typing the following command:

    bigpipe system lcd display enable

  3. Disable the LCD System Menu by typing the following command:

    bigpipe system lcd display disable

    Note: You do not need to issue the bigpipe save command. The bigpipe system lcd display command automatically updates the bigpipe database and sets the appropriate value for the option.

Configuration utility

BIG-IP 10.x through 11.x

  1. Log in to the Configuration utility.
  2. Navigate to System > Configuration > Device > General.
  3. Next to Display LCD System Menu, select the Enabled check box.
  4. Click Update.
  5. Next to Display LCD System Menu, clear the Enabled check box.
  6. Click Update.

BIG-IP 9.4.x

  1. Log in to the Configuration utility.
  2. Navigate to System > General Properties.
  3. Next to Display LCD System Menu, select the Enabled check box.
  4. Click Update.
  5. Next to Display LCD System Menu, clear the Enabled check box.
  6. Click Update.
