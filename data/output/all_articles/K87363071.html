Description

You have exported an Access Policy. When importing the policy an error is reported similar to the following:

Import error: Syntax Error:(/shared/tmp/apmom/import/p--11-02--07-34-31--208.conf at line: 976) "{" unexpected argument

Environment

  • Access Policy Manager configured
  • Large Access Policy being imported
  • A busy device will increase the likelihood of this occurring

Cause

Timeout when receiving the data from the internal database during the generation of the export. The generated export is corrupt.
Bug ID 847109: Very large policies could have problems with re-import

Recommended Actions

Upgrade to BIG-IP version 16.0.0 or later.

Additional Information

None.
