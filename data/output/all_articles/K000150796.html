K000150796: Maximum session in progress per client IP does not produce a log in /var/log/apm

Description

You have configured 'Max In Progress Sessions Per Client IP' for the Access Profile.

In your BIG-IP logs under / var/log/apm you don't see the following warning after violating the limit.

 `warning tmm [<pid>]: 00000000:1: Access Profile <name>: Per IP in-progress sessions limit (<#>) exceeded for <IP_address>`.

Environment

  • BIG-IP APM
  • APM Logs
  • Local-syslog
  • Per IP in-progress sessions

Cause

The publisher sys-db-access-publisher does not include local-syslog destination

Recommended Actions

Include local-syslog destination in the publisher sys-db-access-publisher

  1. On the Main tab, click System > Logs > Configuration > Log Publishers
  2. Click on sys-db-access-publisher
  3. For the Destinations setting, select the local-syslog destination from the Available list and move the destination to the Selected list.
  4. Click Update
