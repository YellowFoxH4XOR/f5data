Known Issue

Local traffic policy configuration for a matched action may display invalid configuration object choices.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with partitions.
  • Pools exist in various partitions.
  • You select a partition.
  • Using the Configuration utility, you create or modify a local traffic policy using the Do the following when the traffic is matched: forward-only to pool action.
  • Using the pool selection menu, you select a displayed pool member that does not reside in the current partition.
  • You click Save to complete the local traffic policy creation or modification.

Impact

The system displays an error message and does not complete the configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to create or modify the local traffic policy, the system displays an error message similar to the following example:

    An error occurred:
    transaction failed:01070726:3: policy action /<partition>/Drafts/<policy name> pools_pools_pools 0 in partition <partition> cannot reference Pool /<partition>/<pool name> in partition <partition>

  • When you select a pool that resides in the current partition, you can successfully save the local traffic policy configuration.

Resolution

Status

F5 Product Development has assigned ID 632204 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, for the pool selection, ensure that you select pools that only reside in the current partition.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
