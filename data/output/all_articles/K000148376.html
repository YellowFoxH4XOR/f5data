Description

After specifying an Alias Service Port on the monitor and saving the settings, it cannot be changed after that.

  • It will not show any error but the change will not take effect, value will remain the same.

Environment

  • BIG-IP DNS
  • Using the GUI
  • DNS/GTM monitors with alias address For example, HTTP, TCP and or ICMP
  • Alias Service Port

Cause

Bug ID 708680

Recommended Actions

Use CLI and edit on TMOS Shell (tmsh).

For example, to modify "Test_DNS_HTTP" with port Alias Service Port 8080 to 8081, use the command below to change and save config:

tmsh

modify gtm monitor http Test_DNS_HTTP destination *:8081

save sys config gtm-only partitions all
