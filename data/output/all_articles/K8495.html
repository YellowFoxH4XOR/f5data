K8495: The client certificate remains after the local user account is deleted

Known Issue

This is the result of a known issue. When you delete a local user account that contains a client certificate generated by FirePass, FirePass adds the client certificate to its Certificate Revocation List (CRL), but fails to delete the client certificate. If you create a new user account with the same logon name as the deleted user account, FirePass incorrectly associates the client certificate generated for the deleted user account with the new user account.

F5 Networks Product Development is tracking this issue as CR94435.

Workaround

You can work around this issue by manually deleting the client certificate associated with the new user account. To do so, perform the following procedure:

  1. Logon to the FirePass Administrative Console.
  2. Navigate to the User: User Management page.
  3. Click the Edit button next to the affected user account.
  4. Click the Delete Client Certificate button.
