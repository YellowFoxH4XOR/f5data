Description

When loading the configuration, for example, with the load sys config command, a warning message similar to the below is seen:

WARNING! Role no-access will lockout the user f5user

Environment

  • User accounts

Cause

User account exists with a role set to No Access.

Recommended Actions

These warnings are informational and can typically be safely ignored.

If the No Access role is incorrect, change the role to a different one (System >> Users >> User List >> <User>). This will eliminate the messages.

Alternatively, delete the user if it is no longer required.

Additional Information

By default, the user role that the BIG-IP system assigns to a user account on each partition is No Access.

The No Access role prevents a user from accessing the system.
