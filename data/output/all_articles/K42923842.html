Description

When trying to deploy several vCMP Guest at the same time, this may fail with the following errors:

err vcmpd[19644]: 01510004:3: Guest (<hostname>): Failure - Error starting VM. Timed out after 900 seconds.
info vcmpd[19644]: 01510007:6: Guest (<hostname>): VS_STARTING->VS_FAILED
err vcmpd[19644]: 01510004:3: Guest (<hostname>): Failure - Error starting VM. Timed out after 900 seconds.
info vcmpd[19644]: 01510007:6: Guest (<hostname>): VS_FAILED->VS_STOPPED

You may notice partition /shared/vmdisks/ has no free space on the vCMP Host:

011d004:3 Disk partition /shared/vmdisks/ has only 0% free

Environment

  • vCMP Host with vCMP Guests allocated
  • Partition /shared/vmdisks/ full on the vCMP Host

Cause

Partition /shared/vmdisks/ is running out of space on the vCMP Host due to several Guests provisioned, so the Host cannot allocate more images.

Recommended Actions
Delete the unused images to release space from the partition /shared/vmdisks/

  1. Run the following command on the Host to review the image files list and choose unused images that can be deleted:
    ls -larth /shared/vmdisks
  2. Change all VCMP Guests state to Configured mode.
  3. Go to vCMP>> Guest List >>  <Guest name >
  4. From the unused vCMP Guest, change Initial Image to None.
  5. Move the chosen image on step 1 to /var/tmp/ folder.
  6. Delete the unused vCMP Guest.
  7. Re-try to provision and deploy your vCMP Guests.
