Known Issue

This is the result of a known issue. A virtual server that references an SSL profile may experience a memory leak when processing an extremely high number of concurrent connections. This issue occurs when many of the connections attempt to renegotiate existing SSL sessions.

Note: This issue has only been observed during load testing.

F5 Product Development tracked this issue as ID 225523 (formerly CR139590) and it was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, WebAccelerator, APM, WOM, or Edge Gateway release notes.

This issue has also been fixed in Hotfix-BIGIP-10.2.0-1755.1-HF1, which has been issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing version 10.x hotfixes on systems, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
