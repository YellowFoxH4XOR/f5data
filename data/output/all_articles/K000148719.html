Description

This article addresses issues with remote authentication using RADIUS on F5 BIG-IP. Despite reviewing initial troubleshooting steps and verifying configurations, it was found that the remote RADIUS server is not responding to pings from the BIG-IP device.

  • You followed article K15763
  • RADIUS server is not pingable

Environment

  • BIG-IP LTM
  • Remote authentication

Cause

The issue may be caused by incorrect routing, especially if the ping to the remote server is unsuccessful. Remote authentication servers are often expected to be reachable via the management interface of the BIG-IP device.

Recommended Actions

It is best to verify the reachability of the remote authentication RADIUS server using the command below.

ip route get <RADIUS_IP>

Example output where RADIUS is reachable via management:

10.10.10.10 via 10.150.250.254 dev mgmt  src 10.150.250.30
    cache

If a route exists, ensure that the subnet and network prefix are correct.

tmsh list sys management-route

If not, add an appropriate static management route for the remote server using the command below.

tmsh create /sys management-route <name> network <RADIUS_IP> gateway <gateway>
