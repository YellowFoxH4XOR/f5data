K43308318: After installing a new blade, the vCMP Guest is showing Red and Offline

Source

Description

After installing a new blade, the vCMP Guest is showing Red and Offline

Environment

  • Viprion
  • BIG-IP version 15.x
  • vCMP host Configuration utility is showing Guest as "No License"
  • vCMP Guest is showing Red and Offline
  • When loging into vCMP Guest under System  ››  Software Management : Image List you see "Waiting on Image" on Install Status column.

Cause

vCMP host is missing the .iso file from current vCMP Guest version.

Recommended Actions

Upload the current vCMP Guest version into the vCMP host, System  ››  Software Management : Image List
