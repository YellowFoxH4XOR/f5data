Topic

Summary

When using a Channel (802.3ad Link Aggregation), it is important to match the Link Aggregation Control Protocol (LACP) setting for all devices in order to prevent the system from improperly marking down an LACP controlled channel.

Description

LACP allows ports on both sides of a redundant link to configure themselves into a trunk link (aggregate link), without the need to  manually configure the ports into trunk groups. If the ARX system and its peer device have different LACP timer settings, the peers may periodically disconnect from each other due to a device not receiving a Link Aggregation Control Protocol Data Unit (LACPDU) when expected. By default, the ARX system uses Fast_Periodic_Time for its transmissions (transmits an LACPDU message once per second) and Short_Timeout_Time (the device will timeout if the peer takes longer than three seconds to respond).

The IEEE 802.3ad standard for LACP indicates that you can have an Active/Active, Active/Passive or a Passive/Active LACP configuration. However, due to limitations, the 500, 2000, and 4000 ARX platforms only support a Passive LACP configuration, so the connecting switch must be active. The 1500 and 2500 ARX platforms only support an Active LACP configuration, so the peer should be passive.

Note: an Active/Active configuration may function, but is not recommended.

Recommendations

When configuring a channel, you should consider the following factors:

  • Identify the default LACP settings for each device.
  • Determine the desired LACP time-out for your network configuration.
  • Adjust the LACP time-out, per requirements.

Review configuration and statistics, and identify if a change is required

Note: The following information will be available in the collect diag file beginning in ARX 6.1.1 HFRU 4 and 6.2.0.

To review a channel's LACP configuration, use the following command syntax:

show channel [channel number] lacp

For example, type the following command:

show channel 1 lacp

A properly-configured ARX channel has a balanced number of ingress and egress packets.  In the following output, you can see the difference in the LACP packets. To get the LACP statistics for the channel, use the following command:

show channel [channel number] lacp stats

For example, type the following command:

show channel 1 lacp stats

You should see the following output:

Rx — Indicates the number of ingress packets.

Adjust the LACP time-out, per requirements

If the LACP settings have been identified as mismatched, and an adjustment is necessary, you can adjust the LACP rate on the ARX system by using the following commands.

Impact of recommended action: Link time-out changes may cause an LACP link to be marked down fast or slow, depending on the configuration change.

  • If the peer device is configured for a longer LACP time-out than three seconds, you can adjust the ARX channel configuration so that the settings match. Use the lacp rate command to lengthen the rate to one LACPDU every 30 seconds and to lengthen the time-out to 90 seconds. To do so, type the following command:

    lacp rate long-timeout

  • If the peer device is configured for a shorter time-out than 90 seconds, you can adjust the ARX channel configuration so that the settings match by returning the ARX system to the default setting by using the no form of the lacp rate command. To do so, type the following command:

    no lacp rate
