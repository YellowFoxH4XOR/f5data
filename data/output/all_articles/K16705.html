Known Issue

The Traffic Management Microkernel (TMM) should not update the expected next sequence number variable when receiving Datagram Transport Layer Security (DTLS) packets with bad records.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server to process DTLS traffic using a Secure Socket Layer (SSL) profile.
  • The virtual server receives a DTLS packet with a bad record and very high sequence number.

Impact

DTLS packets, which do not have bad records, may be dropped.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Client connections that use DTLS are failing.
