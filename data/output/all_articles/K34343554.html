K34343554: Unable to apply JWT Key Configuration in OAuth Bearer SSO configuration

Legacy Content
Applies to

Source
https://my.f5.com/manage/s/article/K34343554

Description

When configuring an OAuth Bearer SSO method, the signing key doesn't populate in the dropdown menu in the new OAuth Bearer SSO Configuration, after creating the JSON Web Token>Key Configuration.
This prevents the OAuth Bearer SSO configuration from saving and you are unable to complete the configuration.

Environment

  • BIG-IP APM
  • OAuth SSO

Cause

The OAuth Bearer signing key doesn't populate when there isn't an ID value for the JWT Key Configuration.
The GUI doesn't enforce that you enter in an ID value, making this easy to overlook

Recommended Actions

  1. In the BIG-IP GUI, navigate to the Access > Federation > JSON Web Token > Key Configuration, and select the key you created. Enter in a value for the ID. Save the changes and go back to the Access>Single Sign-on>OAuth Bearer" configuration and you should then be able to select your JWT key you created.
