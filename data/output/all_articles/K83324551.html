Known Issue

The Configuration utility cannot display detailed CPU graphs when the number of system CPUs is too large.

This issue occurs when the following condition is met:

  • A VIPRION system has a total of 288 or more CPU cores across all blades.

Impact

You are unable to view the detailed CPU graphs.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Navigate to Statistics > Performance, and under System CPU Usage, click View Detail Graph. The system does not display the graph and displays the following error message:

    Error trying to access the database.
