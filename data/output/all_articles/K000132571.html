K000132571: Failed to load UCS file to rebuilt vCMP Guest HA

Type
Support Solution
Published
2023-04-26
Updated
2023-04-26
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000132571

Description

Failed to restore load UCS backup file to newly rebuilt vCMP guest even after customer has done rekey the master key with shell command # f5mku -r <masterkey>.

The UCS backup file were encrypted with passphrase, and during restore, there should be a prompt to enter the passphrase, however, were prompted with error message:

"passphrase is required"

 

Environment

BIG-IP
vCMP
DSC
Restore encrypted UCS
 

Cause

During encrypted UCS restore, there's no passphrase prompted
 

Recommended Actions

1. Restore UCS file that is encrypted with passphrase

# load sys ucs encrypted_UCS.ucs passphrase < passphrase >

2. If this is a BIG-IP with existing HA cluster, force config sync to make sure all HA cluster are properly synced

# run cm config-sync to-group < group-name > force-full-load-push
