Known Issue

This is the result of a known issue. The bigpipe config check all command runs a syntax check for BIG-IP system daemon configuration files.

Note: Running the bigpipe config check all command should not be necessary as mcpd code provides checks for BIG-IP system daemon configuration files.

When you run the bigpipe config check all command, the results are different depending on the platform.

When you run the command on a VIPRION system, the system always reports the following output:

No reports have been received.

When you run the command on an appliance system, a bcm56xxd message that appears similar to the following example is displayed:

DAEMON STATUS bcm56xxd
    Configuration OK   at 14594d 17:46:51
|    Last error at 14594d 17:46:51                                         
|        Message:  Failover event detected.  Marking external interfaces down. bsx.c(3218)

F5 Product Development is tracking this issue as ID 291249 (formerly CR102064).
