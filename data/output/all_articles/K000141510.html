K000141510: EDNS Cache Control (65333) OPT not shown at "server-side" in a packet capture when DNS Cache is used

Type
Support Solution
Published
2024-10-18
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP DNS
  • BIG-IP LTM: 14.1.5
Source
https://my.f5.com/manage/s/article/K000141510

Description

  • DNS cache remove edns opt code 65333 field on server side traffic

Environment

  • DNS
  • DNS Cache

Cause

Only BigIP Next supports this experimental edns opt code.

 

Recommended Actions

  1. Disable DNS cache, if opt code 65333 is require to be delivered to external resolver.
