Issue

Starting in BIG-IP APM and Edge Gateway 10.2.0, you may see a new Session statistics log in the /var/log/apm file. The new log message appears similar to the following example:

Jun 7 16:55:24 local/tmm2 notice tmm2[6697]: 01490521:5: 5d2d61c8: Session statistics - bytes in: 840, bytes out: 996

In this example, 5d2d61c8 is the session ID for the user. The bytes in and bytes out is a summary of the traffic as it relates to both network access and web application usage after the user terminates their session. This log is for informational purposes only, and can be safely ignored as it does not indicate any errors or issues.
