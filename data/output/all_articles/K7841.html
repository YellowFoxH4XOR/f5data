Known Issue

This is a result of a known issue. A local user that is created with a username of 25 characters or more will be allowed remote access if it is switched from local authentication to remote authentication, even when it does not exist on a remote authentication server. When the username is 25 characters or more, the BIG-IP system will bypass the authentication process.

When this issue occurs, a message that appears similar to the following example is recorded in /var/log/secure log file:

httpd[4132]: pam_radius_auth: User name was NULL, or too long

Note: The admin user is the only user that can switch a user from local to remote authentication.

F5 Product Development tracked this issue as CR79163 and it was fixed in BIG-IP version 9.4.1. For information about upgrading, refer to the LTM, GTM, ASM, Link Controller, or WebAccelerator release notes.
