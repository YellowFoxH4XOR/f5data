Topic

The FirePass Portal Access reverse-proxy engine currently supports the HTTP, HTTPS, and FTP protocols. If you have an application that requires another protocol, for example, the Real Time Streaming Protocol (RTSP), you need to configure a Network Access or Application Access favorite to gain access to that application.

Note: For information about configuring a Network Access or Application Access favorite, refer to the FirePass Controller Administrator Guide.
