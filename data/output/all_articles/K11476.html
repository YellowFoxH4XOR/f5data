Topic

The eventd process uses iControl messaging to provide asynchronous event notification to subscribers, such as Enterprise Manager systems. The BIG-IP GTM system does not communicate monitor state changes with the mcpd process. As a result, eventd cannot obtain and provide BIG-IP GTM monitor state information to the iControl subscription mechanism.

Note: Currently, iControl is able to notify eventd subscribers of BIG-IP LTM monitor state changes through the iControl subscription mechanism. The eventd process scrapes the mcpd messages according to the subscription, and sends the notifications of BIG-IP LTM monitor state changes to subscribers when those events occur.
