K000147802: What does "Drop reason: Out Forward Policy" mean?

Type

Published
2024-11-08
Updated
2025-02-23
Applies to

  • F5 Distributed Cloud
Source

Description

I created a Site and in in the Flow Table I can see that there are dropping packets with the reason Out Forward Policy. What does that mean?

Environment

  • F5® Distributed Cloud
  • Create Virtual Site 

Answer/Recommended Actions

This drop reason means that the Access Control Lists (ACLs) configured on the Customer Edge (CE) have denied the flow. You have to check your ACLs.

Additional Information

  • Cluster sizes have to be 1 or 3, 2 is not allowed
