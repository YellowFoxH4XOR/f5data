Description

You see the error below when attempting to redirect an HTTP request via using iRule
bigip1 err tmm[PID]: 01220001:3: TCL error: /Common/example_irule <HTTP_REQUEST> - Operation not supported. Multiple redirect/respond invocations not allowed (line 11)

Environment

  • BIG-IP LTM
  • Virtual Server
  • HTTP Profile
  • iRules

Cause

This error is generated anytime more than one HTTP::redirect and/or HTTP::respond is executed during a single event.

Recommended Actions

Review your current iRule configuration to identify which HTTP::redirect and/or HTTP::respond can be triggered during a single HTTP event and rework the iRule's flow to provide only one redirect per event.
Note: This error can be generated if you are using multiple iRules that contain HTTP::redirect and/or HTTP::respond commands that execute against the same HTTP event.
