Known Issue

The configured user account role prevents you from viewing the system logs.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is licensed and provisioned with BIG-IP ASM.
  • You configure an administrative user with the Application Security Editor or Application Security Administrator role.
  • You enable the matching user role system database variable.
    • ui.logaccess.applicationsecurityadmin 
    • ui.logaccess.applicationsecurityeditor
  • The Application Security Editor or Application Security Administrator role authenticated user attempts to view the system logs.

Impact

Access to the system logs fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When using the Configuration utility to view the system logs, the System option is not available..
  • When using the TMOS Shell, the /sys option is not available.
