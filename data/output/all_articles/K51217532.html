Description
Statics are not being collected for some or all managed BIG-IPs that have statics collection enabled. 
The BIG-IQ restjavad.0.log contains logs similar to the following:

[WARN][12 Aug 2021 14:16:07 EDT][/cm/shared/stats-mgmt/agent-install-and-config-task/a0ddde9f-2e5c-4665-b2fa-fe24c28dca2f/worker AgentInstallAndConfigTaskWorker] agentInstaller failed: java.lang.IllegalStateException: installIapp on device 192.0.2.35 failed: java.lang.IllegalStateException: package analytics-iapp-7.1.0.1-0.0.41.noarch is already installed

 

Environment

  • BIG-IQ with DCDs attached 
  • Statics collection enabled for BIG-IP

Cause
When operating correctly the avrd process on the managed BIG-IPs initiates a connection to port 443 on the DCD to deliver collected statics. During the course of normal operation, if the CM does not receive statics information for a managed BIG-IP with statics collection enabled within an expected amount of time, the CM will attempt to reinstall the statics collection agent on the BIG-IP as an attempt to get statics collection working. If the BIG-IP and/or DCDs have inadequate routing to facilitate these TCP connections, statics will not be delivered to the DCD and the DCD will not return statics for the BIG-IP when the CM queries for the statistics. This will lead the BIG-IQ CM to attempt to reinstall the Statistics collection agent on the BIG-IP.  This will continue in a loop until corrective action is taken. 

Recommended Actions

  1. Assess the expected connectivity requirements for the BIG-IP to DCD communication and configure any routes needed to facilitate the desire network path. Both DCD and BIG-IP routing need to be taken into account.
