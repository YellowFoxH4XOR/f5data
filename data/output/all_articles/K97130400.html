Topic

F5 removed the the following unused feature flag from the bigip.license file:

  • perf_compression_per_core

Description

The perf_compression_per_core feature flag may appear in the bigip.license file. Because this feature flag was never used, F5 removed it from the license server.

If you have an existing license with this feature flag, the feature flag will be removed on a subsequent license reactivation.

There is no impact to product behavior with this change; the BIG-IP system never used the feature flag.
