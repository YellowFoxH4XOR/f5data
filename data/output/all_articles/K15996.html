Known Issue

BIG-IP Edge Client for Windows may not resume sessions properly if network connectivity is momentarily lost.

This issue occurs when all of the following conditions are met:

  • You use BIG-IP Edge Client for Windows to successfully establish a session with the BIG-IP APM system.
  • Connectivity to the BIG-IP APM system is lost, and subsequently re-established.

Impact

BIG-IP Edge Client creates a new session with the BIG-IP APM system after connectivity is restored, rather than resuming the original session.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H500443 on the Diagnostics > Identified > Low screen.
  • Previously authenticated users are prompted for login credentials again, even though their original session is still active in the BIG-IP APM system.
  • The BIG-IP APM system reports additional connections from clients using BIG-IP Edge Client.
