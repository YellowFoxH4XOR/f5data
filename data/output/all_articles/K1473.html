Topic

You can configure BIG-IP to use simple persistence as a backup to cookie persistence by setting a simple persistence timeout value. You can configure this from the Configuration utility or from the command line.

Configuration utility

To configure simple persistence as a fall back method from the Configuration utility, perform the following procedure:

  1. From the navigation pane of the Configuration utility, click Pools.
  2. Click the name of the specific pool you want to modify.
  3. From the toolbar, click Persistence.
  4. In the Simple Persistence Timeout box, set a timeout value for simple persistence.
  5. Check the Active Cookie option button.
  6. Click Apply.

    Command line

    To configure simple persistence as a fall back method from the command line, type the following command where <pool name> is the pool you want to modify, and <value> is the timeout value for simple persistence.

    Note: This command assumes that cookie persistence is already configured on the pool.

    bigpipe pool <pool-name> modify { simple_timeout <timeout> }

    After you run this command, the BIG-IP will default to cookie persistence for the specified pool if a cookie is present. If a cookie is not present and the client IP address is in the Simple Persistence table, the client will persist based on the simple persistence settings.

    Note: You can also configure simple persistence as a backup for SSL persistence by configuring SSL persistence for the pool, and defining a timeout value for simple persistence.
