Known Issue

Multiple SQL monitors running against a single node may incorrectly mark a node down.

This issue occurs when all of the following conditions are met:

  • You have multiple SQL monitors configured to monitor a single SQL member in a single pool.
  • Each monitor is monitoring the SQL server on the same IP address and port.
  • Your monitors have a short interval time of approximately 12 seconds or less.

Impact

The BIG-IP system may incorrectly mark the node down, or the node may experience flapping, whereby the node is repeatedly marked up and down in succession.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • SQL servers are unexpectedly marked down.
  • SQL servers are repeatedly marked up and down in succession.
