Description

With MacOS it is possible to have some client devices that get stuck with old OESIS Library updates installed, and do not update to show the correct versions when they are checking with an APM Device.

  • device fails to be able to check for some administrator situations like Firewall status
  • normal antivirus checks can be completed without issue.
  • Edge Client updates may have been manually distributed in the past

Environment

Relevant environmental factors specific to the topic

  • Edge Client updates may have been distributed, but OESIS Libraries may not be current.
  • Auto update of Libraries is not happening

Cause

Under some circumstances the auto update fails to complete (for example, poor networking) and the device times out, and never upgrades.

Recommended Actions

The actions or steps required to address the topic covered in the description.

- Check the version of the EPSEC libraries installed on the APM being used.


The most reliable way of checking this is to use curl to check the version date-stamp from the APM's Viirtual address.
$ curl 'https://apm.lab.example.com//public/download/mac_oesisInspector.tar.ver'
Where you replace "apm.lab.example.com" with the FQDN of your APM device, and will respond with a string like this

7090.2022.0916.1

Where the 2022 is a year code and the 0916 is for the 16th Sept (month-date).

Also from the APM CLI the following command can be run

# cat  /var/sam/www/webtop/public/download/mac_oesisInspector.tar.ver

7090.2022.0916.1

- Check on the MACOS Device end


Check on the terminal of the MacOS Device, if the same EPSEC libraries are being used:
 $ cat /Library/F5Networks/Inspectors/OesisInspector.ver

7090.2021.0725.1
  A reported version like above means the Libraries are a year old, and need updating.


7090.2022.0707.1
A reported version like above shows a recent version is present but not the latest.

Additional Information

The main 
/Applications/BIG-IP Edge Client.app/Contents/Helpers/PolicyServer
 is installed as part of the "BIG-IP Edge Client.app" (as part of the APMClients bundle) but the OesisInspector is actually installed in the folder "/Library/F5Networks/Inspectors/" as a part of the epsec package from the APM

Here you can see that the OesisModule: SDK Version = '4.3.2698.0' is being installed by the Policy Server
SDK Version = '4.3.2698.0' matches the epsec build epsec-1.0.0-1303.0.iso
(for details see
