Known Issue

This is the result of a known issue. On a system with two or more CPUs, the highest numbered CPU is dedicated to the Traffic Management Microkernel (TMM). The CPU Utilization graph in the Configuration utility indicates incorrect usage for the TMM-dedicated CPU. For example, the 6800 platform contains dual Opteron CPUs, with CPU1 dedicated to the TMM process. If you use the Configuration utility to view the CPU Utilization graph for CPU1, the graph indicates 0 percent usage on a heavily loaded system.

F5 Product Development is tracking this issue as CR99560.

This issue does not affect BIG-IP version 9.6.0 and later.

Workaround

To work around this issue, you can use the bigpipe global command to view TMM statistical information.
