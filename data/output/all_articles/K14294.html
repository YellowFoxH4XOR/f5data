K14294: Configuring the BIG-IP WebAccelerator system to use an upstream BIG-IP LTM system to perform an SSL offload

Purpose

You should consider using this procedure under the following condition:

  • You are using the BIG-IP WebAccelerator system with an upstream BIG-IP LTM system performing SSL offload.

Prerequisites

None

Description

As documented in SOL14223 (See the Supplemental Information section), version 11 of the BIG-IP WebAccelerator system rewrites absolute and relative URIs to absolute URLs when using the Intelligent Browser Referencing (IBR) feature.  If you are using upstream clientSSL virtual servers to offload BIG-IP WebAccelerator virtual servers, the absolute and relative links within accelerated HTTP code may not be correctly translated to include an https://.  In this scenario, you can configure the BIG-IP LTM system and BIG-IP WebAccelerator system to use a NULL SSL cipher. To do so, perform the following procedures:

Configuring the BIG-IP SSL Offload Host

Impact of procedure: There may be minimal CPU overhead and an increase in latency when processing a NULL SSL connection.

  1. Log in to the Configuration utility of the BIG-IP system doing the SSL offload.
  2. Navigate to Profiles > SSL > Server.
  3. Create a new Server SSL profile by clicking Create.
  4. From the Configuration menu, select Advanced.
  5. Remove all text from the Ciphers box, and replace with the following text:

    NULL

  6. To save the new profile, click Finished.
  7. In the Virtual Server configuration screen, under SSL Profile (Server), associate this new server SSL profile with your virtual server.
  8. To save your changes, click Update.

Configuring the WebAccelerator Host

Impact of procedure: There may be minimal CPU overhead and an increase in latency when processing a NULL SSL connection.

  1. Log in to the Configuration utility of the BIG-IP WebAccelerator system.
  2. Navigate to Profiles > SSL > Client.
  3. Create a new Client SSL profile by clicking Create.
  4. From the Configuration menu, select Advanced.
  5. Remove all text from the Ciphers box, and replace with the following text:

    NULL

  6. To save the new profile, click Finished.
  7. In the Virtual Server configuration screen, under SSL Profile (Client), associate this new client SSL profile with your virtual server.
  8. To save your changes, click Update.
