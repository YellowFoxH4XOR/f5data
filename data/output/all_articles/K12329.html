K12329: F5 BIG-IP Edge Portal users are unable to authenticate to back-end servers using basic, digest, or NTLM authentication

Topic

When a BIG-IP Edge Portal user attempts to connect to a back-end server that uses basic, digest, or NT Lan Manager (NTLM) authentication schemes, the page will appear to be loading for a long time but will eventually time out.

This issue occurs due to an Apple iOS limitation in which the iframeded browser (UIWebView) does not support the authentication schemes; however, F5 Product Development is also tracking this issue as ID 342871.

Workaround

You can work around the iOS limitation by configuring single sign-on (SSO) mapping for the resources that need basic, digest or NTLM authentication schemes.

Note: For instructions about configuring SSO mapping, refer to the Configuration Guide for BIG-IP Access Policy Manager.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.
