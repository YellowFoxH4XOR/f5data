K000137996: ASM might detect false positives while integrating it with Jira file upload

Type
Support Solution
Published
2023-12-21
Updated
2023-12-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000137996

Description

  • You configure ASM security policy to protect Jira
  • ASM blocks files uploaded to Jira

Environment

  • ASM Security Policy applied to virtual server
  • Jira is back end application
  • You try to upload file to Jira

Cause

Post request to upload the file generated by Jira front-end might have following content type header:

Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet

As this content type is not a default one in URL configuration ASM will try to parse it, while the content is binary file, what would cause a lot of false positives.

Recommended Actions

1.  Log in to the Configuration utility (GUI)

2. Navigate to Security > Application Security > URLs > Allowed URLs > Allowed HTTP URLs.

3.  Click Create to build a new Allowed URL definition.

4.  For URL, enter /your/url. [This is a hypothetical example of URL, replace with the URL for which you are seeing the false positive block requests]

5.  Click Advanced to display the Header-Based Content Profile.

6.  Click the Header-based Content Profiles tab and enter the following information:

    Request Header Name: Content-Type

    Request Header Value: *application/vnd.openxmlformats-officedocument.spreadsheetml.sheet*

    Body handling: Do nothing

After changes has been made, click on Update and Apply Policy.
