K000157367: The NGINX Instance Manager v2.20.0 GUI is unable to display the last upload time.

Type
Support Solution
Published
2025-11-12
Updated
2025-12-15
Applies to
  • NGINX Products
  • NGINX Instance Manager: 2.20.0
Source
https://my.f5.com/manage/s/article/K000157367

Description

In NGINX Instance Manager version 2.20.0, the GUI does not display the time of the last successful usage report upload, even though usage reports are sent successfully and the GUI confirms the upload. This issue was not present in version 2.19.0, where the last upload time was displayed as expected.

Environment

  • NGINX Instance Manager version 2.20.0
  • Usage reporting feature enabled and used via the GUI

Cause

A regression in NGINX Instance Manager version 2.20.0 resulted in the unintended removal or breakage of the functionality that displays the last successful usage report upload time in the GUI.

Recommended Actions

  • Upgrade NGINX Instance Manager to version 2.21.0 or later to restore the display of the last successful usage report upload time in the GUI.
  • After upgrading, verify that the GUI correctly displays the last upload time following a successful usage report submission.

Additional Information

None.
