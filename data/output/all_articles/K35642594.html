Issue

Error Message

err mcpd[<PID>]: 01070165:3: License file stat fails: <message>.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <message> provides details about the licensing error.

For example:

err mcpd[5823]: 01070165:3: License file stat fails: No such file or directory.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The /config/bigip.license file is not present on the BIG-IP system.
  • The BIG-IP system is unable to access the /config/bigip.license file.

Impact

The BIG-IP system is offline and fails to process traffic until the system is properly licensed.

Recommended Actions

Ensure the license for the BIG-IP system is installed and activated:

  • To activate or re-activate the license, refer to K7752: Licensing the BIG-IP system.
  • To verify the license is valid, refer to K9245: Verifying that a BIG-IP license is valid.
