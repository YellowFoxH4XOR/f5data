Description
This article discusses how to dump resource records of BIND to a file.

Environment

  • BIG-IP DNS (GTM)
  • Review of dump

Cause
The rndc utility provides useful feature to dump BIND resource records.

Recommended Actions

To dump all resource records from all zones in all views, run the following command:
# rndc dumpdb -zones
Note: The output is wriitten to the file /var/named/config/namedb/named_dump.db 

Alternatitvely, a view can be specified, to only dump the records from that view. For example to limit output to those present in the 'external' view:

# rndc dumpdb -zones external
