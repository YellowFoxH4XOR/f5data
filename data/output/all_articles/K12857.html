K12857: Citrix ICA client software must be uploaded to the master node of a cluster or a failover pair

Topic

If you have configured the FirePass environment for a cluster or failover mode, the option to upload and configure Citrix clients is disabled on all secondary nodes. As a result, to install the Citrix client software on all the nodes in your FirePass deployment, you must upload the software to the primary node and allow the primary node to synchronize with the secondary nodes. Citrix clients can then download and automatically update the Citrix ICA and JICA client software directly from any FirePass controller in the cluster or failover pair.

For more information about uploading the Citrix ICA and JICA client to the FirePass controller, refer to the Specifying Citrix ICA client location section of the FirePass Controller Administrator Guide.
