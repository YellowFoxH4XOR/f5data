Description

We cannot view in-built top-level domains in F5 DNS devices from GUI or CLI.

By default, the f5 DNS device uses the DNS root nameservers published by InterNIC from https://www.internic.net/domain/named.root & these are hardcoded within the software code. 

Environment

  • BIG-IP DNS
  • Top Level Domain List
  • Root servers

Cause

We cannot view them as this is hardcoded in the software code itself. 

Recommended Actions

DNS cache resolver without defined root hints will also use this list from software code.

For more details refer to "Using specific DNS servers as authoritative root nameservers" section in https://techdocs.f5.com/en-us/bigip-14-1-0/big-ip-dns-services-implementations/configuring-dns-caching.html

When you add DNS root nameservers, the BIG-IP system no longer uses the default nameservers published by InterNIC, but uses the nameservers you add as authoritative for the DNS root nameservers.

Additional Information

In November 2023 IANA updated the B root nameserver IP's. Old IP's were 199.9.14.201 and 2001:500:200::b. New ones are 170.247.170.2 and 2801:1b8:10::b. BIG-IP is still using old ones.
