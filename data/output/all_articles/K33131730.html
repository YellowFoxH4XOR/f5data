Known Issue

The Configuration utility may fail to validate bad formatting for an external data group.

This issue occurs when all of the following conditions are met:

  • You have an existing external data group configured on your BIG-IP system.
  • You navigate to the external data group page from the Configuration utility (File Management > Data Group File List) and attempt to update the content.
  • You attempt to update the data group with bad data group formatting.

    For example, the data group entry may be missing a trailing quote, as in the following example:

    "www.example.com?id=1” := "http://www.example1.com

Impact

The system fails to update the external data group, and the error message does not reflect the actual issue you encountered.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You use the Configuration utility to update the external data group, and the update fails with the following error message:

    01070711:3: St9bad_alloc.

Workaround

To work around this issue, you can update the external data group content by using the TMOS Shell (tmsh) command that will validate the data group formatting before the system loads the configuration. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Note: You must be familiar with the vi utility to perform this procedure

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Edit the external data group configuration by using the following command syntax:

    edit /sys file data-group <data-group-name>

    For example, the following command will switch to a vi editor mode where you can make the necessary changes on the data group configuration of the data group named test_dg:

    edit /sys file data-group test_dg

  3. Make the necessary changes, and when you are done with the edits, save the changes by typing the following command:

    :wq!

  4. To commit the changes to the BIG-IP configuration, type y when you see the following prompt:

    Save changes? (y/n/e)

    If the content validation fails, you should notice an error message similar to the following example:

    0107169a:3: The data group external file (/config/filestore/.stage_d/84_d/Common_d/data_group_d/:Common:dg1_38252_2) has an invalid format, line: 1.

  5. To fix the issue, when you see the following prompt, type y to return to the vi mode:

    There were errors. Continue editing(y) or discard changes(n) (y/n)

    Note: if you type n the system will not save the changes that you have just made, and the system will automatically exit from the vi editor.

  6. Locate and fix the invalid data group format. Repeat steps 3 and 4 until the error message no longer appears.
  7. Save the configuration by typing the following command:

    save /sys config
