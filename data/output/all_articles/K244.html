Known Issue

This is the result of a known issue. If you set the minimum active members for a pool to zero, or use the default value of zero, priority load balancing does not work correctly.

The zero value is translated internally to 65535. Since the pool never has the minimum of 65535 members available, it ignores priority mode and uses all members for load balancing.

F5 Networks Product Development tracked this issue as CR30143 and CR41781.
