Description

This article describes how to grant a local user account terminal access to the Advanced Shell (bash) or the TMOS Shell (tmsh) on the BIG-IP system.

When a user does not have bash or tmsh access, and an SSH connection is established to the BIG-IP system, the connection closes and the user is prompted with the following error message:

This account is currently not available.

Environment

This situation happens under the following circumstances:

  • A new user account is created in the BIG-IP system with Terminal Access set to Disabled.
  • A BIG-IP default user account admin, which is an Administrator role, has Terminal Access set to Disabled by default.

Cause

Even though the user is assigned an Administrator role, they are unable to access bash or tmsh. The BIG-IP user role does not determine whether Terminal Access is enabled or disabled.

Recommended Actions

To provide a user terminal access (either bash or tmsh), perform one of the following procedures:

  • Provide a user terminal access using the BIG-IP Configuration utility
  • Provide a user terminal access using tmsh

Provide a user terminal access using the BIG-IP Configuration utility

  1. Log in to the BIG-IP Configuration utility with Administrator role credentials.
  2. Go to System > Users > User List.
  3. Select the username of the user to whom you want to provide terminal access.
  4. For Terminal Access, select the drop-down options.
  5. To grant the user bash access, select Advanced Shell; to grant the user tmsh access, select tmsh.
  6. Select Update.

Provide a user terminal access using tmsh

  1. Log in to tmsh on the BIG-IP system by entering the following command:

    tmsh

  2. Modify the username of the user to whom you want to provide terminal access using the following command syntax:
    • To enable user access for tmsh, use the following command syntax:

      modify /auth user <UserID> shell tmsh

    • To enable user access for bash, use the following command syntax:

      modify /auth user <UserID> shell bash

    For example, to enable the user adm_emp2 access to tmsh, type the following command:

    modify /auth user adm_emp2 shell tmsh

  3. To save the changes, type the following command:

    save /sys config
