Description

You are looking to configure BIG-IQ for local and/or remote authentication.

Environment

  • Configuration objects and settings
  • Setting up authentication roles for the BIG-IQ
  • Remote and Local Auth, LDAP, RADIUS, TACACS

Cause

In BIG-IQ there are two different authentications mechanisms. When you access the system via SSH, then TMOS authentication is used, in this case authentication works in the same way as in a BIG-IP (BIQ 8.1.0 is based on TMOS 15.1.x). But when you access the BIG-IQ GUI, then BIG-IQ has its own authentication method which is java based not TMOS based. You can configure it to work locally or remotely. Unlike BIG-IP, in BIG-IQ you can configure multiple providers at the same time and you can select against which one to authenticate with.

Recommended Actions

On the BIG-IQ, for SSH, it will use the same db to enable or disable local auth fallback when remote auth is used. But the GUI works differently. Review the "Related Content" for applicable information.
