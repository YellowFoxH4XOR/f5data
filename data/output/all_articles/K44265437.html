Description

  • How to deploy BIG-IP AFM protocol inspection signatures from BIG-IQ
  • On BIG-IQ GUI there is no a Deploy option, only Install

Environment

  • AFM protocol inspection signatures
  • BIG-IQ

Cause

The protocol inspection signatures 'Push' option from BIG-IQ results in all of the following:

  1. Download to BIG-IP
  2. Install to BIG-IP
  3. Deploy to BIG-IP

Meaning that the BIG-IQ is able to 'deploy' the protocol inspection signatures to BIG-IP the without requiring to log onto the BIG-IP.

Recommended Actions

To deploy BIG-IP AFM protocol inspection signatures from BIG-IQ pleas perform the procedure outlined in the following manual:

Managing Intrusion Prevention System (IPS) section Update inspection packages
