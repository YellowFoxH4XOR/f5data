Known Issue

The Configuration utility does not support using a slash (/) when you specify the IPv6 address network notation. For example, the Configuration utility does not allow you to use the following IPv6 address notation:

ipv6-address/prefix-length.

This issue occurs when the following condition is met:

  • When using the Configuration utility, you attempt to use a slash (/) when specifying the IPv6 address network notation.

Impact

You are unable to specify the IPv6 addresses when you use a slash format.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your attempt to specify the IPv6 addresses fails when you use a slash format.

Workaround

To work around this issue, you can use the ffff notation to specify the routing prefix for IPv6 addresses. For example, to specify a /64 network, enter the following:

ffff:ffff:ffff:ffff:0000:0000:0000:0000
