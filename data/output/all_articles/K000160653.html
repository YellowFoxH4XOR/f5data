Description

The keywords in the Attack Signatures Readme.txt indicate the type of update applied to each attack signature:


  • "Updated ... to provide better coverage":

The detection rule for the signature was modified (major update). This may affect detection and could result in new false positives or improved detection.


  • "Updated ... to have more accurate metadata":

Only the reference information was edited (minor update). The detection logic was not changed.


Newly added signatures and signatures with major updates ("provide better coverage") will be placed in staging.

Attack signatures with minor updates ("have more accurate metadata") will not be placed in staging.


For more information, please refer to:

K14761: Attack signatures with minor updates are not placed in staging
