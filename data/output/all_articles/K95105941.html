Description

When HTTP protocol violations occur there is no learning suggestion as the next steps must be appropriately analyzed by the Security engineer operating the ASM.

If it is determined that it is appropriate to turn off the HTTP compliance violations, a method to do so is provided below.
 

Environment

  • BIG-IP ASM or BIG-IP Advanced WAF
  • Security policy in place with HTTP compliance in blocking mode
  • Security policy is in blocking mode
  • Application being protected by the ASM policy fails to function due to blocks occurring for HTTP compliance failure.

Cause

Application is not HTTP Protocol Compliant.
 

Recommended Actions

Fix the application such that it is HTTP Protocol Compliant.

If fixing the application is not feasible, consider the following method to stop Blocking the non-compliant traffic:

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. From the Current edited policy menu, select the intended policy.
  4. From the General Settings section, select the Advanced setting. (BIG-IP 12.x - 15.0.1 only)
  5. Find the "HTTP Protocol Compliance failed" entry.
  6. Click on the Alarm check box to turn off all HTTP Protocol Compliance checks.  Note: this will affect ALL traffic coming through this policy.  If you have a small number of URLs that are non-compliant, consider using a Local Traffic Policy to bypass ASM for that specific URL as shown in Manual Chapter : Configuring ASM with Local Traffic Policies
  7. Click on the Block check box to turn off all HTTP Protocol Compliance checks . Note: this will affect ALL traffic coming through this policy.  If you have a small number of URLs that are non-compliant, consider using a Local Traffic Policy to bypass ASM for that specific URL as shown in Manual Chapter : Configuring ASM with Local Traffic Policies
  8. Save and Publish the Security Policy.
  9. Test your Application to see if it now works.

Note: F5 does not recommend turning off all HTTP compliance Checks unless required, due to the holes left in the protections by doing so.
Note: You can be more precise as to what you open by choosing to not block only specific HTTP protocol checks, rather than disabling all of them at once.
