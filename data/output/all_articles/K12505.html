Topic

Beginning in ARX version 5.2.0, the clear health command was introduced to provide the ability to clear events displayed in the System Health Information section of the show health command output. For ARX versions prior to 5.2.0, you cannot clear a system health event.

The clear health command uses the following syntax:

clear health <Event>

For example, the show health command displays an event that appears similar to the following example:

System Health Information
Date ID Event Description
---------------------------------------------------------------------------------------
Tue Dec 25 12:34:00 2010 (620) - shareFreeSpaceThresholdRaise shr 'cifs_1:/cifs_mv1:cifs_mv1_sh1', filer 'filer-01' :Share is below the configured threshold of free space.

You can clear the shareFreeSpaceThresholdRaise event by performing the following procedure:

  1. Log in to the ARX system through the serial console.
  2. Enable privileged mode by typing the following command:

    enable
  3. Clear the shareFreeSpaceThresholdRaise event by typing the following command:

    clear health shareFreeSpaceThresholdRaise
