K000154649: Maximum number of detected signatures in the “sig_ids” field is limited in ASM remote logs

Type
Support Solution
Published
2025-09-10
Updated
2026-07-29
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K000154649

Description

When the “sig_ids” field is added to an ASM remote request logging profile, and an HTTP request triggers more than 10 attack signatures in the ASM security policy, only 10 signature IDs are included in the remote request log.

Environment

  • AWAF/ASM with remote request log configured 

Cause

With request-only remote logging, the “sig_ids” field can include up to 10 signature IDs.

If the logging profile is configured to log responses in addition to requests, the field can include up to 15 signature IDs.

Recommended Actions

None

Additional Information

RFE ID2048357 was opened to increase this limit.
