Known Issue

The BIG-IP system sends an incorrect SSL/TLS alert message when you receive an unsupported client certificate.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system has a virtual server that references an SSL profile.
  • The Client Certificate option in the SSL profile is set to either Require or Request.

    Note: The default setting is Ignore.
  • The virtual server receives an unsupported SSL certificate from a remote client.

Impact

Incorrect diagnostic information may prolong troubleshooting SSL/TLS connection failures.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you view packet captures, the BIG-IP system sends an internal_error alert instead of the correct unsupported_certificate alert.
