K48908342: TCP Checksum errors have been detected from BigIP in front of Firewall

Type
Support Solution
Published
2024-03-21
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K48908342

Description

Firewall checksum check indicating wrong Layer 4 checksum valued getting from the Big IP 

  • Firewall logs shows TCP checksum error from the Big IP
  • Packet capture shows wrong checksum values 
    note: The packet capture must be from the Firewall and not from the Big IP.

Environment

  • vCMP
  • ePVA supported platform
  • Filter your capture with the following:
    tcp.checksum_bad.expert
  • You will get similar error message:
    Checksum: 0xef3c incorrect, should be 0x6f3c(maybe caused by "TCP checksum offload"?)
    note: Verify you are getting different checksum's values for every few packets (Which included F5 Device  i.e. f4:15:63:aa:bb:cc)

Cause

Unknown.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Run EUD  to check  hardware failure
  2. After reboot it might resolve the issue-  Check again Firewall checksum 

    Note: In case it not resolved -Please collect all the information and open a new Support Case

Additional Information

To enable the checksum validation, Open Wireshark capture perform below steps:

  1. Go to Edit.
  2. Select Preferences.
  3. Select UDP / TCP protocol.
  4. Validate the UDP / TCP checksum if possible.
