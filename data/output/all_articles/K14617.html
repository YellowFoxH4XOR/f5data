Known Issue

On rare occasions, the Traffic Management Microkernel (TMM) may produce a core file while processing TCP SYN packets.

This occurs when the following condition is met:

  • The virtual server is configured with a TCP profile.

Impact

TMM may stop responding and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H427542 on the Diagnostics > Identified > High screen.
  • The BIG-IP system sends a SIGFPE signal to TMM, resulting in a stack trace and core file.
  • The BIG-IP system may temporarily fail to pass traffic.
  • The BIG-IP system logs messages similar to the following example to the /var/log/tmm file:

    notice MPI stream: connection with node 127.20.1.6 established
    notice MPI stream: connection to node 127.20.1.8 expired for reason: TCP retransmit timeout (tcp4.c:8690)
