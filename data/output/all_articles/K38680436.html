The BIG-IP versions listed in the Fixes introduced in column of K30523121: BIG-IP TMM vulnerability CVE-2021-23034 may cause a loss of functionality when the RESOLV::lookup iRules command is used. The RESOLV::lookup  iRules command is deprecated as of BIG-IP 15.1.0; F5 recommends that customers update their iRules to use the RESOLVER and DNSMSG namespaces.
K05920565: Software installation fails with Error Message : "failed (Could not access configuration source; sda/vda, 1 )" error during a BIG-IP software upgradeDuring a BIG-IP software upgrade, installing a new software image in a new partition (both via Configuration utility and tmsh) fails with an error message.
K31992159: After upgrading to 13.1.x you are not able to see configuration objects on the BIG-IP due to a configuration load failureInvalid keyword 'kedh' in ciphers list error triggers configuration load failure. This occurs after updating from BIG-IP 13.1.x to another 13.1.x version (for example: 13.1.3.4 to 13.1.3.6).
K12017200: CPU usage spikes after upgrade or enabling Analytics profile potentially causing GUI to become unavailableWhen the avrd process is initialized after an upgrade and reboot, it communicates with mcpd to process BIG-IP configuration details. If the BIG-IP system contains a large configuration with several thousand objects, this leads to avrd consuming 100 percent CPU for up to 30 minutes.
