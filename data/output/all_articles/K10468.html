Known Issue

This is the result of a known issue. In a failover pair (high availability) configuration, the Users : User Management page on the standby controller reports more concurrent sessions than the same page on the active controller. This is a cosmetic issue, and does not impact users. The active FirePass controller correctly calculates the number of concurrent sessions to determine whether the licensed limit has been reached. The active controller reports the correct number of concurrent sessions on the Users : User Management page. FirePass administrators should disregard the concurrent sessions reported by the standby controller.

F5 Product Development tracked this issue as CR101535 and it was fixed in FirePass 7.0.0. For information about upgrading, refer to the FirePass release notes.
