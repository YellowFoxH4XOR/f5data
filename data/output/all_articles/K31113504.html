K31113504: Antivirus Check Undetected

Type
Support Solution
Published
2021-02-24
Updated
2023-02-21
Applies to
  • BIG-IP APM: 15.X.X
Source
https://my.f5.com/manage/s/article/K31113504

Description

Access policy unable to detect client-side requests for resources

Environment

  • Access is denied
  • AV Windows Malware installed  

Cause

EPSEC database is not up to date.
 

Recommended Actions

To enforce Antivirus check, update EPSEC database using the following step:  

On Configuration Utility, browse to System  >  Software Management > Antivirus Check Updates > Device EPSEC Status


Additional Information

There are other reasons for the AV checks to fail, to name a few:

  • Antivirus Software installed not supported yet
  • Antivirus Software version installed not supported yet
  • Edge Client version is not up to date
  • Misconfiguration of Antivirus check in the Access Policy
