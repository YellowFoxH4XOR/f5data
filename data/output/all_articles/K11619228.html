Known Issue

Data Guard may block and/or mask non-credit card number values.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM security policy is configured with the Data Guard option for credit card numbers.
  • Content processed by the BIG-IP ASM security policy contains numeric values that start with the number 4 and contain 14 or 15 digits.

    Note: Credit card numbers that start with the number 4 are typically 13 and 16 digits in length.

Impact

Content containing a matching numeric value will trigger a security violation.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the security policy Data Guard feature is enabled for credit card numbers and configured to mask data content containing 14 or 15-digit sequences that start with the number 4, the feature will trigger an alarm and mask the values.
  • When the security policy is configured in blocking and the Data Guard feature is enabled for credit card number content containing 14 or 15-digit sequences that start with the number 4, the feature will trigger an alarm and block the values.

Workaround

To work around this issue, you can disable Data Guard credit card number security checking. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure will disable the masking or blocking of content containing credit card numbers for the security policy.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Data Guard.
  3. Remove the check box setting for Credit Card Numbers.
  4. Click Save.
  5. Click Apply Policy.
