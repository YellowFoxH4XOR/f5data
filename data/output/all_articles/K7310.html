K7310: The SQL monitor can mark a node as UP even if the database is unavailable

Knowledge
Published
2007-04-13
Updated

Status
Legacy Content
Applies to
  • Legacy Products
  • BIG-IP 4.X: 4.6.4
Source

Topic

When a user name is allowed to authenticate by another database on the same SQL server, the EAV SQL monitor verifies SQL-based services by attempting to perform an SQL login to a service. If successful, the monitor marks the node as UP and available for use. Since the SQL monitor bases the availability of the service on a successful SQL login, it is possible for the SQL monitor to mark a node UP and available even if the desired SQL database is not accessible. This behavior results from a user name being allowed to authenticate by another database on the same SQL server. In this case, the SQL monitor marks the node as UP even though the desired database is not available.

To prevent this behavior from occurring, the SQL server should be configured to reject logins when the requested database is unavailable. Consult your database administration guide for instructions about how to configure a user login to fail if the database is not available.
