Known Issue

When you configure network access profiles with Protocol Security Module (PSM) HTTP protocol security, the Traffic Management Microkernel (TMM) may produce a core file.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is licensed with PSM.
  • Your BIG-IP APM system is configured to use a network access profile.
  • Your system uses a virtual server for network access that has an associated HTTP profile with HTTP protocol security enabled.

Impact

Network access sessions fail.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • During the initiation of the network access profile, the pop-up window to indicate that network access is established temporarily appears, and then the session fails.
  • The BIG-IP APM system generates a TMM core file to the /shared/core directory.
  • The BIG-IP APM system fails over to another system in the device group.
  • The BIG-IP APM system temporarily fails to process traffic while TMM restarts.

Workaround

To work around this issue, you can disable protocol security on the affected HTTP profile. To do so, perform the following procedure:

Impact of workaround: After performing this procedure, HTTP protocol security no longer applies to the network access virtual server.

Using the Configuration utility to disable HTTP protocol security

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Services > HTTP.
  3. Click on the HTTP profile associated with the virtual server that is using the affected iRule.
  4. Clear the Protocol Security check box to the right of Protocol Security.
  5. Click Finished.

Using the tmsh utility to disable HTTP protocol security

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Disable protocol security of the HTTP profile by using the following syntax:

    modify ltm profile http <name_of_affected_http_profile> security disabled
  3. Save the change by typing the following command:

    save /sys config
