Issue

Error Message

mysqlhad[<PID>]: 014e0001:6: mysql failure detected, attempting to restart mysql (attempt <#>).

In this error message, note the following:

  • <PID> is the process ID for the mysqlhad process.
  • <#> is the number of times the BIG-IP system attempted to restart MySQL.

For example:

mysqlhad[9872]: 014e0001:6: mysql failure detected, attempting to restart mysql (attempt 1).

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The high availability subsystem detects that the MySQL service has failed.

Impact

BIG-IP services that are rely on the MySQL database, such as BIG-IP ASM, BIG-IP AVR, and BIG-IP APM reporting, do not function properly until the MySQL service is restored.

Recommended Actions

When this message appears repeatedly, consider the following:

  • You can check the status of the mysql service using the tmsh show /sys service command.  If the status is down, manually restart the MySQL service by using the tmsh restart /sys service mysql monpd command. 

    Note: Depending on provisioned modules, you may also have to restart other services, such as the asm, avrd, localdgmgr, and logd services.  

  • A lack of available disk space or memory may prevent the MySQL service from functioning properly.  Ensure there is available disk space in the file system mounted on the /var directory by checking the output of the df -h command.  Check the current levels of module provisioning in the System > Resource Provisioning page in the Configuration utility to ensure the system has available memory.  You may be able to reprovision the modules in order to increase available memory.
  • In some cases the MySQL database may need to be reset.  For more information, refer to the following:
    • K14194: Troubleshooting the BIG-IP ASM MySQL database
    • K6992: Resetting the BIG-IP ASM database to a default configuration
    • K14956: Resetting BIG-IP AVR statistics
