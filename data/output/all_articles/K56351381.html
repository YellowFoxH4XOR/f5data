Description

Configuration is not loaded after upgrade to v16.x/v17.x when WAM/AAM (Application Acceleration Manager) is provisioned in the BIG-IP system. Following errors are noted in /var/log/ltm.

01070734:3: Configuration error: WAM Application "/Common/abc.app/abc_aam": local policy "/Common/Microsoft SharePoint 2010" must exist.
Unexpected Error: Validating configuration process failed

Alternatively the following error may also show up:

err mcpd[10087]: 01020036:3: The requested parent profile (/Common/wam-tcp-wan-optimized) was not found.

Environment

  • BIG-IP LTM
  • BIG-IP WAM/AAM  
  • Software upgrade from version 13.1.0-15.x to v16.x/v17.x

Cause

Use of non supported WAM/AAM (Application Acceleration Manager) module. WAM/AAM (Application Acceleration Manager) module is not supported from BIG-IP version 16.x  as BIG-IP 16.0.0 has completed the End of Life of the BIG-IP WAM/AAM product. Related to Bug ID 941961.

Recommended Actions

  1. Boot the BIG-IP system to the previous working version 
  2. Under virtual server settings, remove any AAM profiles from virtual servers and change the references from wam-tcp-wan-optimized to something else in your config file (e.g., tcp-wan-optimized).
    Note: For more information about the F5 WAN optimized profiles, refer to K03553427: Using optimized TCP profiles.
  3. Proceed to delete any AAM profiles.
  4. After deletion of AAM profiles, repeat the software upgrade.
