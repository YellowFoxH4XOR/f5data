Description

Customer wants to confirm whether ASM can protect ONVIF protocol.



Environment

ONVIF protocol

Adv WAF


Cause

ONVIF is a standard for communicating between video surveillance/security devices and services. It doesn't define any new protocol, but rather builds a layer on top of existing protocols on the control and data planes.


Recommended Actions

1. Control Plane uses SOAP and Web Services. Here ASM/AdvWAF provides extensive support: it can enforce WSDL conformance as well as SOAP and XML well-formedness. So ONVIF WSDLs can be enforced and attack signatures are detected within the SOAP payload.


2. Data (streaming) Plane uses all popular streaming protocols like RTP, RTSP and HTTP. Of all these, ASM/AdvWAF supports only HTTP: it can detect signatures and attack vectors in the header and body. The other protocols are not supported.
