Description

  • You have installed NGINX Plus version R33 or above.
  • Or, you have upgraded your NGINX to version R33 or above.
  • You want to verify if NGINX instillation / upgrade is compliant with Usage Reporting.

Environment

  • NGINX Plus R33 or above
  • Usage Reporting
  • Subscription
  • Upgrade
  • NGINX error log level

Cause

  • In NGINX Plus version R33 and above, Subscription validation and usage reporting to F5’s licensing endpoint is now a requirement

Recommended Actions

  • Access host system
    • SSH into the host system where the NGINX installed
  • Increase NGINX Error Log Level:
  • Edit the NGINX configuration file to set the error log level to "info" for more detailed logging. 
    • Open /etc/nginx/nginx.conf in a text editor.
vi /etc/nginx/nginx.conf
  • Locate and edit error_log directive from within the "MAIN" block and set it as follows:

user nginx;
worker_processes auto;
error_log /var/log/nginx/error.log info;
pid /run/nginx.pid;

Save and exit the editor.

  • Test and Reload NGINX Configuration:
    • Test the configuration for syntax errors:
sudo nginx -t
    • Reload the NGINX configuration:
sudo nginx -s reload
  • Monitor the NGINX Error Log:
    • Use the following command to monitor the log for usage report events:
sudo tail -f /var/log/nginx/error.log
    • Look for log entries similar to:

[info] ... usage report was sent

NGINX sends usage reports every hour by default.

Additional Information

For offline environments, usage reporting is routed through NGINX Instance Manager.
