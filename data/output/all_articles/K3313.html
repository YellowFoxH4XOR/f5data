Known Issue

When BIG-IP is configured with two hardware failover cables, the standby system does not become active when the active system is rebooted. This issue occurs when the user shuts down a system in a redundant pair by pressing the reset button. This type of reboot does not reset the serial port state on the system which prevents sod, on the standby system, from making the standby system active.

This issue does not occur if the user shuts down the system through the command line. This issue also does not occur when the user power cycles the system, because a loss of power allows the serial port state to properly reset and prompt the standby system to become active.

If your IT policy requires a redundant failover method, F5 Networks recommends that you configure BIG-IP with a single-cable between the redundant systems in conjunction with network failover.

For specific details about configuring network failover, refer to the Configuring a Redundant System chapter of the BIG-IP Reference Manual.
