Known Issue

Under rare conditions, the TMM process may stop responding due to an unexpected interaction between HTTP and SSL handlers.

This issue occurs when all of the following conditions are met:

  • You configure a virtual server with the HTTP profile.
  • You configure a virtual server with the SSL profile.

Impact

The BIG-IP system experiences interruptions in traffic processing while the TMM process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The TMM process stops responding.
  • The TMM process produces a core file with a SIGABRT message.
  • A BIG-IP system in a high-availability (HA) configuration fails over to the peer system.
  • The BIG-IP system generates a TMM core file in the /var/core directory.
