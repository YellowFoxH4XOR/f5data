Description

How to create a backup BIG-IP UCS file using iControl REST with the BIG-IQ REST API endpoint.

Environment

  • BIG-IQ
  • BIG-IP
  • iControl REST API

Cause

Use iControl REST to create a UCS backup of a BIG-IP from the BIG-IQ.

Recommended Actions

Performing the following procedure requires command-line access to a system with the curl utility and, optionally, the jq (command line JSON processor) utility installed. These utilities are commonly available on Linux systems but can also be installed on Microsoft Windows and Mac OS X systems. Additionally, you can perform this procedure on a BIG-IP system. If you're not using the jq utility, you can omit the variable creation, TOKEN=$(), variable reference, $TOKEN and | jq portion of the commands.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Obtain the BIG-IQ auth token and add it to a shell variable:

    TOKEN=$(curl -ks -X POST -d "{'username':<username>, 'password':<password>, 'loginProviderName':<login provider> }" https://<BIG-IQ>/mgmt/shared/authn/login | jq .token.token)

    For example:

    TOKEN=$(curl -ks -X POST -d "{'username':admin, 'password':admin, 'loginProviderName':local}" https://10.155.19.176/mgmt/shared/authn/login | jq .token.token)

  2. Obtain the list of devices with TOKEN variable you created in step1:

    curl -ks -H "X-F5-Auth-Token: $TOKEN" 'https://<BIG-IQ>/mgmt/shared/resolver/device-groups/cm-bigip-allDevices/devices?$select=hostname,managementAddress,uuid' | jq

    For example:

    curl -ks -H "X-F5-Auth-Token: $TOKEN" 'https://10.155.19.176/mgmt/shared/resolver/device-groups/cm-bigip-allDevices/devices?$select=hostname,managementAddress,uuid' | jq

    Example output that contains the device UUID:

    {
      "items": [
        {
          "uuid": "5d960da6-e346-4772-b7ee-77ebe8d5cf56",
          "hostname": "fulldeploy-bigip.com",
          "managementAddress": "10.155.19.175"
        },
        {
          "uuid": "65f8d1ac-4e8e-4bf9-93cd-5cb658edf20a",
          "hostname": "fulldeploy-bigiq-cm.com",
          "managementAddress": "10.155.19.176"
        }
      ],
      "generation": 2365,
      "kind": "shared:resolver:device-groups:devicegroupdevicecollectionstate",
      "lastUpdateMicros": 1706041058043940,
      "selfLink": "https://localhost/mgmt/shared/resolver/device-groups/cm-bigip-allDevices/devices"
    }
     

  3. Create a backup UCS file of the BIG-IP:

    Skip to step 4 to create an encrypted UCS backup

    curl -ks -H "X-F5-Auth-Token: $TOKEN" 'https://<BIG-IQ>/mgmt/cm/system/backup-restore' -H 'Content-Type: application/json' --data-raw '{ "includePrivateKeys": true , "isEncrypted": false, "deviceReference": { "link": "https://localhost/mgmt/shared/resolver/device-groups/cm-bigip-allDevices/devices/<uuid>" }, "backupLifeTime": 14, "name": "<filename>", "description": ""}' | jq

    For Example:

    curl -ks -H "X-F5-Auth-Token: $TOKEN" 'https://10.155.19.176/mgmt/cm/system/backup-restore' -H 'Content-Type: application/json' --data-raw '{ "includePrivateKeys": true, "isEncrypted": false, "deviceReference": { "link": "https://localhost/mgmt/shared/resolver/device-groups/cm-bigip-allDevices/devices/5d960da6-e346-4772-b7ee-77ebe8d5cf56" }, "backupLifeTime": 14, "name": "mybackup.ucs", "description": ""}' | jq

    Note: The BIG-IQ retains the backup for 14 days per the backupLifeTime setting.

  4. Alternatively, create an encrypted UCS file of the BIG-IP:

    curl -sk -H "X-F5-Auth-Token: $TOKEN" 'https://<BIG-IQ>/mgmt/cm/system/backup-restore' -H 'Content-Type: application/json' --data-raw '{ "includePrivateKeys": true, "isEncrypted": true, "passphrase": "<plain text passphrase>", "deviceReference": { "link": "https://localhost/mgmt/shared/resolver/device-groups/cm-bigip-allDevices/devices/<uuid>" }, "backupLifeTime": 14, "name": "<filename>", "description": ""}' | jq

    For example:

    curl -sk -H "X-F5-Auth-Token: $TOKEN" 'https://10.155.19.176/mgmt/cm/system/backup-restore' -H 'Content-Type: application/json' --data-raw '{ "includePrivateKeys": true, "isEncrypted": true, "passphrase": "12345678", "deviceReference": { "link": "https://localhost/mgmt/shared/resolver/device-groups/cm-bigip-allDevices/devices/5d960da6-e346-4772-b7ee-77ebe8d5cf56" }, "backupLifeTime": 14, "name": "myencryptedbackup.ucs", "description": ""}' | jq

    Note: The BIG-IQ retains the backup for 14 days per the backupLifeTime setting.

Additional Information

  • The UCS file is located in /shared/ucs_backups/
  • The UCS file will appear in the BIG-IQ GUI under Devices > Backup Files > Backup Status > All
  • The UCS file will appear in the BIG-IQ GUI under Devices > Backup Files > Backup Status > Finished when complete.
