Important: Clearing the cache on the BIG-IP WebAccelerator or BIG-IP AAM system will temporarily increase traffic to the origin web servers until the BIG-IP WebAccelerator or BIG-IP AAM system repopulates its cache.

You can clear the BIG-IP WebAccelerator and BIG-IP AAM cache from the command line by performing one of the following procedures, depending on the version you are running:

Note: BIG-IP WebAccelerator and BIG-IP WOM were combined to create BIG-IP AAM in 11.4.0.

BIG-IP WebAccelerator and BIG-IP AAM 11.x and later

To manually clear the BIG-IP WebAccelerator or BIG-IP AAM cache data stored in the Datastor/Metastor, type the following command:

wa_clear_cache

Note:  The wa_clear_cache command is supported in BIG-IP WebAccelerator Virtual Edition platforms starting in version 11.1.0.

BIG-IP WebAccelerator 10.x

To manually clear the BIG-IP WebAccelerator cache and the LTM HotCache from the command line, type the following command:

wa_clear_cache

BIG-IP WebAccelerator 9.4.2 through 9.4.8

To manually clear the BIG-IP WebAccelerator cache and the LTM HotCache from the command line, type the following commands:

wa_clear_cache
bigpipe profile http http-acceleration ramcache entry all delete

Note: If necessary, replace the profile name http-acceleration with the name of the profile for which the cache entries should be deleted.
