K12308: Web scraping detection may cause the BIG-IP ASM to dump core if DNS is not accessible

Known Issue

The BIG-IP ASM web scraping detection engine may cause the BIG-IP ASM bd process to core file if no DNS resolver is available. If DNS is not available to the BIG-IP ASM when web scraping detection is enabled, the following error messages and core files may appear:

  • The /var/log/ltm file:

    01480024:3: Can't bind the flow, waiting for config response on channel mem://bd3

  • The /var/log/ts/bd.log file:

    |02/09/10 08:09:26|8272|io_manager_init.c:0345|internal_keep_alive: BD shrinking...,going down num_rw_threads from CLI= 8

  • The /var/core directory:

    bd.bld1755.1.core.21487.gz

F5 Product Development tracked this issue as ID 332390 (formerly CR 142125) and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP ASM release notes.
