Description

  • You see log messages similar to below in /var/log/ltm
 err statsd[31783]: 011b0600:3: Error ''/var/rrd/acl' is too small (should be 590296 bytes)' during rrd_update for rrd file '/var/rrd/acl'
  • Qkview generation takes extremely long or does not complete
  • You apply the workaround written in Bug ID 883049 but the issue persists

Environment

  • BIG-IP
  • v11.5 and later

Cause

A truncated version of the binary file (such as 'acl' in the above log) could also exist in /shared/rrd.1.2.perm/

Recommended Actions

Delete the truncated version of the binary file in  /shared/rrd.1.2.perm/

  1. Stop statsd
    bigstart stop statsd
     
  2. Make a copy of /shared/rrd.1.2.perm/acl
    cp /shared/rrd.1.2.perm/acl /var/tmp/acl.backup
    cp /var/rrd/acl /var/tmp/acl.backup2
     
  3. Delete acl from /shared/rrd.1.2.perm/ 
    rm -f /shared/rrd.1.2.perm/acl
    rm -f /var/rrd/acl
     
  4. Start statsd
     bigstart start statsd
