Source

Description

The appiqpostaggregator daemon is in a restart loop.

# tmsh show sys service | grep appiqpostaggregator
appiqpostaggregator run (pid 15497) 0 seconds, 3 starts, 30331 restarts

Logging for the appiqpostaggregator daemon has stopped.

# ls -lh /var/log/appiq/postaggregator.log
-rw-r--r--    root    root  1224607 Nov 11 2024 20:48 postaggregator.log

As a result of appiqpostaggregator failing to come up, DCD began displaying the following warning: "Statistics overflow protection detected".

Environment

  • BIG-IQ with statistics collection enabled for managed devices.

Cause

Unknown.

Answer/Recommended Actions

Reboot the BIG-IQ CM device to recover.

Additional Information

None
