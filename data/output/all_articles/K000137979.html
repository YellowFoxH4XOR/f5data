Description

When creating a bot defense profile that will protect a Single Page application and the endpoint is an API, the requests are not being challenged by the bot defense profile.


The bot defense event log will show that the URL has not been qualified for injection and the Actual Verification Action is Challenge-Free Verification. The request has not been challenged and the protection action is not engaged even though the bot is categorized as malicious.


Detected Anomalies will indicate a Resource request without browser verification cookie.




Environment

  • ASM
  • Bot Defense

Cause

The system will require a valid cookie that was allocated to browser clients during Verify Before or Verify After Access actions.  


Recommended Actions

Enable API Access for Browsers and Mobile Applications.


Security --> Bot Defence --> Choose the profile --> Bot Mitigation Settings
