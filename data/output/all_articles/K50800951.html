Description

Configuration cannot be loaded after a BIG-IP software upgrade to v16.x or 17.x, and the following log entries are being reported to /var/log/ltm file on attempt to load the config using the CLI command: 'tmsh load sys config'.

01020036:3: The requested profile (/Common/wam-tcp-wan-optimized) was not found.
Unexpected Error: Loading configuration process failed.

Environment

  • Software upgrade from 13.1.0 through 15.1.x to 16.x or 17.x.
  • Configuration contains profiles that use TCP wam-tcp-wan-optimized and/or wam-tcp-lan-optimized as parent profiles.

Cause

This is caused by BUG ID 941961.

Recommended Actions

Using any convenient text editor (vi or nano) remove offending profiles from bigip.conf file(s) and adjust the configuration elements that use them accordingly.

Here are two examples:

  • Copy the definition of 'wam-tcp-wan-optimized' from /defaults/wam_base.conf into /config/bigip.conf, and then reload the configuration.
  • Change the references to wam-tcp-wan-optimized to something else in your config file (e.g., tcp-wan-optimized), and then reload the configuration.
