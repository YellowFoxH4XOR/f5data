Known Issue

This is the result of a known issue. A pre-logon sequence that determines whether a Windows client is running Avira's AntiVir anti-virus software fails to detect a running instance of the software. Windows clients are directed to the other branches of the pre-logon sequence, even if the Avira AntiVir software is running.

FirePass pre-logon sequences can detect the state of third party security programs, such as anti-virus software and personal firewalls, using an API provided by the OPSWAT libraries. The API for the Real-Time Protection (RTP) feature allows a FirePass pre-logon sequence rule to determine the state (running or not running) of security programs, in the pre-logon sequence. If the pre-logon sequence requires a running anti-virus program to log in to FirePass, then the pre-logon sequence fails and logging in to the FirePass controller from the host running Avira Antivir is not possible.

F5 Product Development tracked this issue as CR81024, and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Important: Avira PersonalEdition Classic 7.x and Avira PersonalEdition Premium 7.x are supported starting in OPSWAT SDK 2.5.1. FirePass version 6.0.2 includes OPSWAT SDK 2.4.4.1; therefore, it will not detect Avira PersonalEdition Classic 7.x and Avira PersonalEdition Premium 7.x unless you install OPSWAT Hotfix 2.5.1 or later versions of the OPSWAT hotfix. For more information about OPSWAT hotfixes, refer to K6664: Obtaining and installing OPSWAT hotfixes.

Additionally, this issue was fixed in OPSWAT 2.4.2 (hotfix-81024). You may download this hotfix or later versions of the OPSWAT hotfix from the F5 Downloads site.

For instructions about obtaining and installing an OPSWAT hotfix, refer to K6664: Obtaining and installing OPSWAT hotfixes.

Verifying the issue

To verify that you are experiencing this issue, inspect the pre-logon data collected by FirePass during a login attempt. For instructions about how to display the pre-logon data collected by FirePass, refer to K6358: Displaying pre-logon data for a FirePass client.

Upon inspection of the pre-logon data for an array entry with the H+BEDV index, the output will appear similar to the following example:

[H+BEDV] => Array
(
[agent_id] => OPSWAT_AV
[data_version] => 1.0
[protect] => off
[update] =>
[need_update] =>
[expression_id] => ITEM%231
[name] => H+BEDV
[features] => 3
[engine_version] => 7.4.0.37
[database_version] => 6.39.0.85
[database_signature] =>

[database_time] => 2007.07.02 00:00:00
[monitor] => unknown
[last_scan] => <
[gui_state] => hidden
[description] => AntiVir%20PersonalEdition%20Classic%20Windows
[database_age] => 1
)

If the [monitor] field contains unknown, this may indicate that the pre-logon sequence check failed, and it may not be possible to log in to the FirePass Controller.
