Applies to

Source

Description

To verify Open-Source VMware Tools version use for F5 VE instance

 

Environment

  • ESXI

Cause

An Open-Source VMware Tools VMware Tools implementation is installed on the guest operating system and the version of Open-Source Vmware tool are obtainable on VE instance.

 

Recommended Actions

To view the Guest managed Vmware Tool version

  1. Login to Vsphere
  2. Select the relevant VE instance
  3. Refer to VMware tool versions

Additional Information

Guest's Open-Source Vmware tool version cannot be upgrade.
