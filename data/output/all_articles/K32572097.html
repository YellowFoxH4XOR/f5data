Error Message

01071029: <string>

In this error message, note the following:

  • <string> is the observed error message. The error message varies according to different triggering conditions as described in the Description section table.

For example:

01071029:5: Invalid master key

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
