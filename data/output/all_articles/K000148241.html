K000148241: Verify FIPS platform on BIG-IP

Type
Support Solution
Published
2024-12-31
Updated
2025-06-19
Applies to
  • BIG-IP
  • F5OS
Source
https://my.f5.com/manage/s/article/K000148241

Description

    • Verify whether your system is a FIPS platform.

Environment

    • BIG-IP

Cause

  • Verify whether your system is a FIPS platform.

Recommended Actions

  • You can run the below command to get more information about the FIPS platform.
    • tmsh run util fips-util info

    • fips-util -v info

    • tmsh show /sys crypto 

    • tmsh show /sys crypto fips

Additional Information

None.
