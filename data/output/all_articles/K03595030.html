K03595030: BIG-IP rSeries change root and admin passwords from the cli

Published
2023-04-28
Updated
2025-04-16
Applies to

  • F5OS
Source
https://my.f5.com/manage/s/article/K03595030

Description

root and admin password change on F5OS rSeries.

Environment

F5OS
BIG-IP rSeries

Cause

None

Recommended Actions

Login to the F5 rSeries appliance with admin credentials.
If you are already logged in with the root account then type: su admin in order to login with the admin account.

To change the root password:

R2600-R84-S14# system aaa authentication users user root config set-password password
Value for 'password' (<string>): *********
R2600-R84-S14#

To change the admin password:

R2600-R84-S14# system aaa authentication users user admin config set-password password
Value for 'password' (<string>): *********
R2600-R84-S14#

Additional Information

Note: You will be required to change their password on their first successful login.

K000138796: User change of password is required on first successful authentication attempt
