Description

  • While uploading/importing TLS / SSL certificate, I get a "Network Error"

Environment

  • F5® Distribute Cloud Console
  • SSL/TLS configuration certificates

Cause

  • Custom role is required to import TLS certificate

Answer/Recommended Actions

User needs to have a custom role created with the following API groups to upload/import TLS certificate:

system namespace:

  • f5xc-console-basic-monitor
  • f5xc-securemesh-standard-monitor

default namespace:

  • f5xc-securemesh-standard-admin
  • f5xc-securemesh-standard-monitor
  • f5xc-securemesh-standard-user

shared namespace:

  • f5xc-securemesh-standard-monitor
