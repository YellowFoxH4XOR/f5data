Topic

The BIG-IP APM base and maximum license counts are platform and module specific.

This article applies to BIG-IP Virtual Edition (VE) APM licensing. For information about other platforms, refer to the following articles:

  • K15624537: BIG-IP APM licensing for BIG-IP Standard platforms (non-iSeries)
  • K01151630: BIG-IP APM licensing for BIG-IP iSeries appliances
  • K41332981: BIG-IP APM licensing for VIPRION

Note: VE licenses V16 and earlier and V18 and later have different properties. License versions are also not directly equivalent to BIG-IP software versions. For more information about F5 VE license versions and how they relate to BIG-IP software versions, refer to K15643: BIG-IP VE license offerings.

Description

The BIG-IP APM system uses different types of licenses, depending on the type of resource you access.For example, note the following:

  • The system uses an Access Session (AS) license when you start any new session.
  • The system uses a User Connectivity (CCU) license when you are assigned one or more BIG-IP APM resources with a VPN tunnel or portal access.
  • The system uses a Secure Web Gateway (SWG) license when you employ a URL filtering service or an SWG service.

For more information about license types, refer to K13267: BIG-IP APM connectivity license use.

Description

Starting with license version V18, BIG-IP APM Base and Add-on licenses come with 500 CCU (SSL-VPN) user sessions. You can augment the BIG-IP APM Base license with Add-on Throughput and SSL-VPN user session licenses. Additionally, BIG-IP APM licensing offers High Performance VE licensing that is sold on vCPU (base 8 vCPUs). You can augment vCPU by purchasing Add-on licenses in increments of 4 vCPU. The following tables outline BIG-IP VE throughput and SSL-VPN licensing.

Important: Application of a new license and license activation may be required to obtain the licensed features presented in this article.

Important: Throughput cannot be upgraded. To increase throughput, you must have the next-level license.

Beginning September 2019 for a BIG-IP APM standalone, GBB (Best), or BIG-IP APM add-on license, after you reactivate the license on your BIG-IP system, you may observe that the value of the total access sessions and total swg limited sessions increases to a large value (10M, 20M, and greater).

For example:

# tmsh show apm license
--------------------------------------------
Global Access License Details:
--------------------------------------------
 total access sessions: 10.0M
 [...]
 total swg limited sessions: 10.0M

This behavior occurs so that the number of total access sessions and total swg limited sessions are effectively unrestricted based on licensing. However, the values (10M, 20M) do not indicate your BIG-IP APM system's performance capacity to handle the number of user sessions. You must continue performing capacity and sizing tests before you deploy your BIG-IP system in production. This licensing change does not affect the current CCU and SWG license counts, nor does it alter the mechanism of license enforcement.
