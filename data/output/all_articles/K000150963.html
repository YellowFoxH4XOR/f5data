K000150963: HTTP2 max streams exceeded counter incrementing unexpectedly

Type
Support Solution
Published
2025-07-10
Updated
2025-07-10
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2, 17.5.0, 17.5.1, 17.1.1
Source
https://my.f5.com/manage/s/article/K000150963

Description

Output of "tmsh show ltm profile http2" might show "max streams exceeded" as incrementing when max-streams has not  been reached.

Environment

  • BIG-IP terminating http/2 connections from client

  • Output of "tmsh show ltm profile http2 <profile-name>" shows "max streams exceeded" incrementing 

Cause

This field can be incremented when the number of ingress RST_STREAM packets from the client exceeds a certain (unspecified) threshold.

Recommended Actions

Investigate why client is sending large rate on RST_STREAM packets.

Additional Information

Change added by defect ID1366025 to protect BIG-IP against CVE CVE-2023-44487.

Note that a client sending excessive concurrent stream requests (Ie: in excess of configured max-concurrent-streams) will also increment this counter.
