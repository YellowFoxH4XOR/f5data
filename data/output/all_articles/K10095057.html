Topic

You should consider using this procedure under the following condition:

  • You want to filter and modify incoming Border Gateway Protocol (BGP) updates.
  • You want to filter and modify outgoing BGP updates.

Description

You can use route maps to filter BGP route updates and modify BGP route attributes.

A route map matches BGP route updates with a range of configured match conditions. You specify whether a route update matching a condition is allowed (permit) or rejected (deny). There is an implicit deny at the end of every route-map. When a route matches a condition and is allowed, you can optionally modify (set) attributes for that route. 

The format of the route map is as follows: route-map route_map_name [[permit | deny] | [sequence-number]]

You can configure the following list match conditions on the BIG-IP system:

  • as-path
  • community
  • extcommunity
  • interface
  • ip
  • ipv6
  • metric
  • origin
  • route-type
  • tag

You can set the following list attributes on the BIG-IP system when a match condition is permitted:

  • aggregator
  • as-path
  • atomic-aggregate
  • comm-list
  • community
  • dampening
  • extcommunity
  • ip
  • ipv6
  • level
  • local-preference
  • metric
  • metric-type
  • origin
  • originator-id
  • tag
  • weight

Prerequisites

You must meet the following prerequisites to use this procedure:

  • The BIG-IP system is licensed for the BIG-IP Advanced Routing Module.
  • You have administrative access to the BIG-IP command line.

Procedures

Filtering and modifying BGP updates using a route map on the BIG-IP system

In the following implementation, a route map is configured on BIG-IP A to deny entry of any BGP route updates with IP address 1.1.1.0. All other BGP updates will be permitted with the attribute metric value set to 5.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP A command line.
  2. Access the imish utility by typing the following command:

    imish

  3. Enter enable mode by typing the following command:

    enable

  4. From the prompt, enter configuration mode by typing the following command:

    config terminal

  5. Create an access list for the 1.1.1.0 network by typing the following command:

    access-list 1 permit 1.1.1.0 0.0.0.255

  6. Create a route map to deny updates from 1.1.1.0 network and set a metric of 5 to all other updates:

    route-map rm1 deny 10
     match ip address 1
    route-map rm1 permit 20
     set metric 5

  7. Enter BGP routing configuration mode in AS 100 by typing the following command:

    router bgp 100

  8. Specify BIG-IP B as an eBGP neighbor by typing the following command:

    neighbor 160.10.20.2 remote-as 200 

  9. Apply route map rm1 to incoming BGP updates on BIG-IP A by typing the following command:

    neighbor 160.10.20.2 route-map rm1 in 

  10. Exit configuration mode by typing the following command:

    end

  11. Write the configuration by typing the following command:

    write
