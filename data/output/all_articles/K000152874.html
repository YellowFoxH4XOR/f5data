Environment

BIG-IP AWS

CFE Failover

IAM profile

S3 bucket


Cause

IAM profile didn't have permission for S3 bucket


Recommended Actions

In the IAM policy, you have to see the following rule. The CFE must have permission for s3:ListAllMyBuckets.


{

"Version": "2012-10-17",

"Statement": [

{

"Effect": "Allow",

"Action": [

"s3:ListAllMyBuckets"

],

"Resource": [

"*"

],

"Condition": {

"StringEquals": {

"aws:PrincipalAccount": "<my_account_id>"

}

}

},
