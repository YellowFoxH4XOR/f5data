Description

During the boot process, the system pauses and asks to Enter password:

Version 2.17.1255. Copyright (C) 2016 American Megatrends, Inc.

F5 Platform: C117 OBJ-0614-xx BIOS (Build: 1.18.009.0) Date: 09/01/2016

Press <c> to enter setup.

Press <e> to launch F5 Disk Erase Utility.

/--- Enter Password ---\

| |

| |

| |

\----------------------/

But, admin and root passwords don’t work.

Environment

  • BIG-IP LTM
  • Password recovery

Cause

Unknown at the time of publication.

Recommended Actions

  1. Upon reboot, you will be prompted to Enter Password.
  2. Press <c> to enter setup.
  3. Navigate to the Security option and select the User Password option. Enter User Current Password then Enter <blank/nothing> when it prompts for Create New User Password. It will ask Clear Old User Password, so select Yes.
  4. Repeat the above step for the Administrator Password to clear the Admin password as well.
  5. Navigate to the Save & Exit option in the Setup Utility and select Save Changes and Reset.
  6. Now the system boots up normally without prompting to enter a password.

 

Additional Information
If the issue persists, a clean installation is recommended to fix it (K13117).
