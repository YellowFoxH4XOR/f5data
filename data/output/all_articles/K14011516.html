Description

An outage was experienced after creating a new iRule based on another iRule, with variables set similar to the following in both iRules:

First iRule

ltm rule /Common/snat_rule_1 {
    when RULE_INIT {
set static::snat_select(0) 1.1.1.1
set static::snat_select(1) 2.2.2.2
set static::snat_select(2) 3.3.3.3
set static::snat_select(3) 4.4.4.4
    }
}

Second iRule

ltm rule /Common/snat_rule_2 {
    when RULE_INIT {
set static::snat_select(0) 10.10.10.10
set static::snat_select(1) 10.10.10.11
set static::snat_select(2) 10.10.10.12
set static::snat_select(3) 10.10.10.13
    }
}

Note: These are not complete iRules, but show the relevant portion of iRule code causing the problem.

Environment

  • iRule
  • Virtual Server

Cause

Both iRules set static variables with the same name but different values. A static variable is global and available to all iRules.

This results in two iRules attempting to set the same variables with different values.

Recommended Actions

Avoid use of static variables unless absolutely required. If static variables are required, ensure that multiple iRules are not setting the same variable within the same event unless the logic of all iRules involved is accounting for this.
