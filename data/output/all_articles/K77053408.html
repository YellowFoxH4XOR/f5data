K77053408: BIG-IQ /usr folder reporting 97% full

Type
Support Solution
Published
2020-12-14
Updated
2025-04-02
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.0.X, 6.0.1, 6.1.0
Source
https://my.f5.com/manage/s/article/K77053408

Description

After upgrading the BIG-IQ to 6.1.0 the /usr folder may display 97% usage.

Environment

  • BIG-IQ
  • Upgrade to 6.1.0

Cause

After upgrading to v6.1.0 /usr will go to 97% and not go any higher

Recommended Actions

This is benign and can be safely ignored.

However, if you would like to give /usr more space so it drops below 97%, you can do that with these steps:
Resize the partition so it will not show as red in the BIG-IQ GUI. From the Bash(#) shell:
df /usr
Filesystem            Size  Used Avail Use% Mounted on
/dev/mapper/vg--db--sda-set.1._usr  <--- example name in the lvresize command below.  This can change per boot image.
                      3.3G  3.0G   98M  97% /usr

  1. Check your free disk space by running command: vgdisplay
  2. mount -o remount,rw /usr
  3. lvresize -L +200M -r /dev/mapper/vg--db--sda-set.1._usr
  4. mount -o remount,ro /usr

This will give an additional 200M to the /usr filesystem that should drop the utilization percent to ~91%, using a larger value will increase it more.  This is dynamic, so the system can remain online while executing the command.

Additional Information

This alert can be disregarded because the /usr file system is read-only and will not grow because of temporary files.
