Description

DNS Security Profile is still taking effect even if DNS Security was set to disabled (under DNS  ››  Delivery : Profiles : DNS ›› <dns profile name>) 

# tmsh list ltm profile dns dns-security-afm
ltm profile dns dns-security-afm {
    app-service none
    defaults-from dns
    dns-security <profile name>   -------------->>>>
    enable-dns-firewall no        -------------->>>>
}

Environment

  • BIG-IP AFM
  • BIG-IP DNS
  • DNS firewall security is set to "NO"
  • DNS Security Profile associated

Cause

There is a Request for Enhancement (RFE) internally tracked and submitted to F5 product Development team to make "enable-dns-firewall" deprecated in the DNS profile.
 

Recommended Actions

If you want the DNS firewall security disabled, disassociate the security profile totally from DNS profile and verify if DNS query/responds is working as expected.
 

Additional Information

None.
