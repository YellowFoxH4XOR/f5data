Issue

The BIG-IP APM system uses OPSWAT OESIS software, which can detect the presence and state of third-party security software, such as personal firewalls, antivirus, antispam, antispyware, or integrated packages, and of software patch levels on client systems connecting to F5 devices. The OESIS Diagnose utility is available to detect software updates and changes that may cause trouble with inspection and to assist with troubleshooting client connections that fail security checks or cause unexpected behavior.

OESIS Diagnose provides detailed diagnostic information that F5 Technical Support requires to troubleshoot the operation of the detection engine. Because the Endpoint Security (EPSEC) libraries change frequently, F5 distributes versions for each supported platform inside the EPSEC OPSWAT ISO update file on the F5 Downloads site. You can download the most recent EPSEC OPSWAT ISO file in each BIG-IP version product line.

Important: For EPSEC versions older than epsec-1.0.0-954, the WaDiagnose utility fails due to its license expiration. For more information, refer to ID 987701.

To obtain the diagnostic logs:

  1. Extract the ISO file using a file archiving and extraction utility, such as WinZip or 7-Zip.
  2. Go to the .Tools directory of the ISO file.
  3. Execute the appropriate application to generate output files.
  4. Provide the output files to F5 Support.
To do so, use the procedure for your type of system:
  • Generating the OESIS diagnostic log on a Windows system
  • Generating the OESIS diagnostic log on Mac and Linux systems

Generating the OESIS diagnostic log on a Windows system

The application takes a few minutes to generate two diagnostic log files.

  1. Go the F5 Downloads site.
  2. Select your BIG-IP version and locate the epsec-<version>.iso file.
  3. Follow the steps to download the file to your client device.
  4. Open the file using your preferred file archiving utility.
  5. Go to .Tools\Windows in the ISO file directory.
  6. Extract all the OESISDiagnose_*.zip files you find in the directory. For example, OESISDiagnose_V3V4.zip and OESISDiagnose_V4.zip.

    Notes:

    • In versions prior to 489.0, the filename is OESISDiagnose_V3.zip.
    • In some versions, you may find only the OESISDiagnose_V3V4.zip file.
  7. Perform the following procedures for the files you extracted in the previous step:

    Note: If you have both OESISDiagnose_V3V4.zip and OESISDiagnose_V4.zip, you need to perform both procedures.

    Note: If you enabled user account control (UAC) on your computer, you may have to input your administrative credentials before you can run OEISIS Diagnose.

    Extracting OESIS diagnostic logs from ZIP files on the Windows system
    Important: OESISDiagnose_V3V4 is for BIG-IP V11/12/13 and OESISDiagnose_V4 is for BIG-IP V14/15/16.
    FileSteps
    OESISDiagnose_V3V4.zip
    1. Extract the OESISDiagnose_V3V4.zip. file and then open it.
    2. Locate the OesisDiagnose_bridge.exe file in the extracted destination directory.
    3. Right-click the OesisDiagnose_bridge.exe file and select Run as administrator.

      While OesisDiagnose_bridge.exe runs, the system displays a DOS window and generates the OESISDiagnoseLog_V3.log and OESISDiagnoseLog_V3.xml diagnostic output files.

    4. Note the new OESISDiagnoseLog_V3.log and OESISDiagnoseLog_V3.xml log files.
    OESISDiagnose_V4.zip
    1. Extract the OESISDiagnose_V4.zip. file and then open it.
    2. Locate the WaDiagnose.exe in the extracted destination directory.
    3. Right click the WaDiagnose.exe file and select Run as administrator.

      While WaDiagnose_bridge.exe runs, the system displays a DOS window and generates the WaDiagnoseResults_XXX.txt diagnostic output file.

    4. Note the WaDiagnoseResults_XXX.txt log file.
  8. Provide these log files to F5 Support. For more information, refer to K000090853: Exchange files with F5 Support.

    For example, if you extracted both OESISDiagnose_V3V4.zip and OESISDiagnose_V4.zip, provide the following three files: OESISDiagnoseLog_V3.log, OESISDiagnoseLog_V3.xml  and WaDiagnoseResults_XXX.txt.

Generating the OESIS diagnostic log on Mac and Linux systems

  1. Go the F5 Downloads site.
  2. Select your BIG-IP version and locate the epsec-<version>.iso file.
  3. Follow the steps to download the file to your client device.
  4. Mount the EPSEC OPSWAT ISO file on the affected device, or create a DVD-ROM image on disc and place the disc in the DVD-ROM drive of the affected device.
  5. Open the EPSEC OPSWAT ISO file on the affected device, and copy either the .Tools\Mac or .Tools\Linux directory to a destination folder on the affected system.

    Note: Select the appropriate directory for the operating system installed on the affected device.

  6. Go to the .Tools\ subdirectory for your system.
  7. For each OESISDiagnose_Vx.tar file you find in the .Tools\ subdirectory, perform the following procedure:
    Note: If you have both OESISDiagnose_V3V4.tar and OESISDiagnose_V4.tar, you need to perform both procedures.

    Extracting OESIS diagnostic logs from ZIP files on Mac and Linux systems

    FileSteps
    OESISDiagnose_V3V4.tar:
    1. Extract the OESISDiagnose_V3V4.tar. file by entering the following command:

      tar xvf OESISDiagnose_V3V4.tar

      If you are running Linux, enter the appropriate directory, depending on your platform: i686 or x86_64. For example:

      cd x86_64

    2. Run OESISDiagnose_V3V4 in elevated mode by entering the following command:

      sudo ./OESISDiagnose_V3V4

      When the test completes, the system displays the following output:

      Test has finished. Log file generated at: /tmp/.Tools/Linux/x86_64/OESISDiagnoseLog_V3.log

    3. Note the new OESISDiagnoseLog_V3.log and OESISDiagnoseLog_V3.xml files. Confirm that the UserLevel in OESISDiagnoseLog_V3.log is root.
      OESISDiagnose_V4.tar:
      1. Extract the OESISDiagnose_V4.tar. file by entering the following command:

        tar xvf OESISDiagnose_V4.tar

        If you are running Linux, enter the appropriate directory, depending on your platform: i686 or x86_64. For example:

        cd x86_64

      2. Run wadiagnose by entering the following command:

        ./wadiagnose

      3. Note the new WaDiagnoseResults_XXX.txt log file.
    1. Provide the log file to F5 Support. For more information, refer to K000090853: Exchange files with F5 Support.

      For example, if you extracted both OESISDiagnose_V3V4.zip and OESISDiagnose_V4.zip, provide the following three files: OESISDiagnoseLog_V3.log, OESISDiagnoseLog_V3.xml, and WaDiagnoseResults_XXX.txt.
