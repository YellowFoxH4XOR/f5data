Known Issue

An iControl REST transaction fails when it encounters a schema version mismatch.

This issue occurs when all of the following conditions are met:

  • You use the iControl REST interface to configure or query a BIG-IP system.
  • Your iControl REST transaction specifies a BIG-IP schema version that does not match the BIG-IP version of the BIG-IP system.

Impact

The iControl REST transaction fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to run the iControl REST transaction, the system returns an error similar to the following example:

    {"code":400,"message":"Error on connection or connection was closed by peer:1114","errorStack":[]}

Resolution

Status

F5 Product Development has assigned ID 618163 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can specify the correct BIG-IP software version schema in the iControl REST transaction.

Impact of workaround:  Performing the suggested workaround should not have a negative impact on your system.
