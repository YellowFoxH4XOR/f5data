Description

When importing an ASM/AWAF policy with Import Target set to Replace Policy, the importing policy inheritance settings are not retained by default.

Environment

  • ASM policy import/replace

Cause

By design the Retain the Inheritance setting is set to Disabled and the setting is not displayed, causing the user to be unaware the inheritance will not be imported as expected.

Recommended Actions

To import the ASM/AWAF policy to replace an existing policy and retain the imported policy inheritance settings, change the Import Target setting to New Policy and change the Retain the Inheritance setting to Enabled. Then change the Import Target setting back to Replace Policy and proceed to import the policy. The imported policy will now correctly reflect the expected inheritance settings.
