Description

You have a third-party application that relies on the optional "typ":"JWT" key/value pair in the JOSE (JSON Object Signing and Encryption) header.
You notice that the JWT token generated by the OAuth profile on the APM does not supply this header.

Environment

  • APM configured as an OAuth Authorization server with support for JWT tokens enabled

Cause

Currently, there are no options available either in the APM native configuration or via an iRule to set the 'typ' header in JWT tokens

Recommended Actions

  1. Contact Technical Support and request an engineering hotfix for Bug ID 1124109 which addresses this requirement.
    Note this EHF statically sets the "typ":"JWT" header in the code; hence it cannot be disabled.

Additional Information

As per RFC7519 the "typ" header is optional
More information on the "typ":"JWT" key/value pair header could be found at https://jwt.io/
