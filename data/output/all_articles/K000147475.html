Description

  • I want to know how to change the expiration date for API certificates, API Tokens and KubeConfig within the F5® Distributed Cloud Console

Environment

  • F5® Distributed Cloud Console

Resolution/Answer

To set up the expiration time policy for API Certificat, API Token and KubeConfig:

1. In the console, go to Administration 

2. Go to Tenant Settings

3. Click on Tenant Overview

4. Go to Credential Expiry Policy

5. Click on Set Up Expiration Preferences

6. Select the amount of time (days), you want your credentials to remain active

7. Click Save.
Note:The images may change depending on your Distributed Cloud version. For example, the default values are 90 days at time of update.
