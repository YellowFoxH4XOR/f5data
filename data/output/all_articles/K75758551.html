Issue

Description

01070151:3: Rule [<irule_name>] error: Unable to find ifile (<ifile_name>) referenced at line <#>: [ifile get "<ifile_name>"]

In this error message, note the following:

  • <irule_name> is the iRule name.
  • <#> is the line that references the iFile.
  • <ifile_name> is the name of the file imported into the BIG-IP system.

For example:

01070151:3: Rule [/Common/iFile_iRule] error: Unable to find ifile (/Common/iFile.html) referenced at line <10>: [ifile get "/Common/iFile.html"]

Environment

  • You are using the Configuration utility.
  • You import a file as an iFile.
  • You create an iRule to reference the iFile.
  • You configure a virtual server with the iRule.
  • The virtual server processes a connection request matching the iRule syntax.

Cause

  • The iFile profile is not yet created.
  • The iRule is configured with the wrong iFile profile name.

Recommended Actions

  • Importing the iFile for use with the BIG-IP system
  • Creating an iFile profile
  • Modifying the iRule to use the iFile profile

Importing the iFile for use with the BIG-IP system

  1. Log in to the Configuration utility.
  2. Navigate to System > File Management > iFile List.
  3. Click Import.
  4. Click Choose file.
  5. Locate the iFile on your local device.
  6. Click Open.
  7. For Name, type a name for the iFile.
  8. Click Import.

Creating an iFile profile

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules > iFile List.
  3. Click Create.
  4. Under General Properties, type a name for the profile.
  5. For File Name, click the imported file.
  6. Click Finished.

Modifying the iRule to use the iFile profile

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules > iRule List.
  3. Click the iRule name that references the iFile.
  4. For Definition, modify the iRule to reference the iFile profile name.

    In the following example, the iRule syntax references the /Common/iFile_Profile iFile:     

    when HTTP_REQUEST {
             set ifileContent [ifile get "/Common/iFile_Profile"]
             HTTP::respond 200 content $ifileContent
             unset ifileContent
          }

    Note: Replace /Common/iFile_Profile with the appropriate information for your deployment.

  5. Click Update.

    Note: The iRule can now be applied to the intended virtual server.
