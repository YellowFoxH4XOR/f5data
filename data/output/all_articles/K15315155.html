K15315155: iRule continues logging after being removed from Virtual Server

Type
Support Solution
Published
2022-01-29
Updated
2023-02-10
Applies to
  • BIG-IP Platforms
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K15315155

Description

An iRule previously applied to a Virtual Server continues logging even after being removed from the Virtual Server.
 

Environment

  • BIG-IP LTM
  • iRule previously applied to a Virtual Server and removed


Cause

The BIG-IP contains information about all the sessions that are currently established on the BIG-IP system, causing the iRule to continue logging for existing connections.


Recommended Actions

Login to the command line and apply the following tmsh command to delete BIG-IP connection table entries of the logging virtual server:

tmsh delete sys connection cs-server-addr <Virtual Server IP address> cs-server-port <port>


Additional Information
None.
