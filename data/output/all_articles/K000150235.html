Description

High-speed logging (HSL) is not functioning when using the 'ArcSight' Common Event Format (CEF) as the remote log destination, under the Log Filters object. No packets are observed being sent to the configured remote log collector(s), even though other formats such as Syslog and Splunk work correctly. A warning message may appear during configuration:

ArcSight destination <destination_name> is only supported for AFM, ASM, and SWG components.

Environment

Relevant environmental factors specific to the topic

  • High-speed Logging (HSL) configured with 'ArcSight' as the remote log format.
  • Log Filters object attached to a Log Publisher pointing to a pool of remote log collectors.
  • Other formats like Syslog and Splunk function correctly in the same environment for Log Filters.
  • LTM, ASM provisioned.

Cause

The ArcSight Common Event Format (CEF) is only supported for specific modules—AFM, ASM, and SWG—and does not support system-level logs or general-purpose logging via HSL. This behavior is by design.

Recommended Actions

Ensure that the ArcSight format is being used exclusively for AFM, ASM, or SWG components. For system-level logs and Log Filters, or unsupported modules, use alternative log formats such as Syslog or Splunk.
