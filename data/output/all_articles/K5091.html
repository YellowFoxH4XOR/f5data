Known Issue

This is the result of a known issue. The BIG-IP system may output the following error message to the console when a trunked interface is unplugged while traffic is passing through the trunk:

Port 21: bcm_port_update failed: Unexpected chip or driver state
kernel: Warning: timeout draining packets on port 21

This error message is benign and can be ignored.

F5 Networks Product Development tracked this issue as CR24149.
