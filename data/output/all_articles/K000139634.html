Description

Background information on the implementation of Repository Access. This will aid in resolving update issues. These typically manifest as Status 403 returns when using yum.

 

Environment

AWS, using NGINX Pus Subscription images from AMI marketplace.

This is for the Amazon Linux 2 version. Similar functionality is implemented for other platforms.

 

Cause

NGINX Plus is licensed by subscription. Part of this subscription is access to the NGINX Plus repository.

This enables updates and installation of additional modules, using yum.

 

The yum plugin gets instance metadata from IMDS and then sends it to the NGINX Plus repository url through the headers.

This needs a token to retrieve.

 

On the actual VM it's /usr/lib/yum-plugins/ngx-amazon-id.py

Note the existence of the X-NGX-REPO-ID base64 encoded header.
To get this from the AWS metadata server requires presenting an authentication header which is acquired from the http://169.254.169.254/latest/api/token endpoint. This is what the yum plugin does.

Recommended Actions

This is informational.

Additional Information

The NGINX repository on a subscription instance is:

cat nginx-plus.repo

import base64
import urllib2
try:
    import simplejson as json
except:
    import json

from urllib2 import ProxyHandler
from yum.plugins import TYPE_CORE

requires_api_version = '2.3'
plugin_type = (TYPE_CORE,)
token = ''

ID_DOC_HEADER = "X-NGX-REPO-ID"
ID_SIG_HEADER = "X-NGX-REPO-SIGNATURE"
TOKEN_TTL_HEADER = "X-aws-ec2-metadata-token-ttl-seconds"
TOKEN_HEADER_ID = "X-aws-ec2-metadata-token"
ID_DOC_URL = "http://169.254.169.254/latest/dynamic/instance-identity/document"
ID_SIG_URL = "http://169.254.169.254/latest/dynamic/instance-identity/signature"
TOKEN_URL = "http://169.254.169.254/latest/api/token"

# We do not want to use a proxy to read the Amazon instance metadata, so bypass
# any proxy that might be set, including by http{s}_proxy environment
# variable(s).
proxy_handler = ProxyHandler({})
opener = urllib2.build_opener(proxy_handler)


def init_hook(conduit):
    '''
    Plugin initialization hook. For each NGINX repo, replace yum's representation of the
    repo with a subclass that adds in the necessary headers.
    '''

    # Only process nginx repos
    repos = conduit.getRepos()
    ngx_repos = repos.findRepos('nginx-*')

    # Retrieve the Amazon metadata
    global token
    token = _get_token()
    id_doc = _load_id()
    id_sig = _load_signature()

    if id_doc and id_sig:
        # Encode it so it can be inserted as an HTTP header
        # Signature does not need to be encoded, it already is.
        id_doc = base64.urlsafe_b64encode(id_doc)
        id_sig = base64.urlsafe_b64encode(id_sig)

        # Add the headers to all NGINX repos
        for repo in ngx_repos:
            repo.http_headers[ID_DOC_HEADER] = id_doc
            repo.http_headers[ID_SIG_HEADER] = id_sig


def _read_aws_metadata(url):
    req = urllib2.Request(url)
    req.add_header(TOKEN_HEADER_ID, token)
    try:
        fp = opener.open(req)
        data = fp.read()
        fp.close()
    except urllib2.URLError:
        return None

    return data


def _get_token():
    req = urllib2.Request(url=TOKEN_URL, data=b'')
    req.get_method = lambda: 'PUT'
    req.add_header(TOKEN_TTL_HEADER, '120') # Time to live in seconds
    try:
        fp = opener.open(req)
        token = fp.read()
        fp.close()
    except urllib2.URLError:
        return ''

    return token


def _load_id():
    '''
    Loads and returns the Amazon metadata for identifying the instance.

    @rtype: string
    '''
    return _read_aws_metadata(ID_DOC_URL)


def _load_signature():
    '''
    Loads and returns the signature of hte Amazon identification metadata.

    @rtype: string
    '''
    return _read_aws_metadata(ID_SIG_URL)
