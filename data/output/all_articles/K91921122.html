Description

Error message in serial console: Cannot open an IPMI driver: /dev/imb, /dev/ipmi0, /dev/ipmi/0, or direct driverless when booting up device.

Environment

  • BIG-IP iSeries

Cause

K00415052: AOM may stop responding during an upgrade on iSeries platforms

Recommended Actions

  1.  Please run tmsh show sys hardware in order to verify if proper Base MAC is assigned

    Platform
      Name           none
      BIOS Revision  OBJ-0615-xx BIOS: 1.18.002.0 ME: 6.0.50.1252 06/09/2016
      Base MAC       ff:ff:ff:ff:ff:ff    <<<============ !!!
      PVA Version    20

    System Information
      Type                       C118

  2.  If you see Base MAC as ff:ff:ff:ff:ff:ff please follow K00415052: AOM may stop responding during an upgrade on iSeries platforms
