K29294287: BIG-IP will respond Neighbor Advertisement for IPv6 subnet network address receiving Neighbor Solicitation

Type
Support Solution
Published
2025-07-07
Updated
2025-07-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X
Source
https://my.f5.com/manage/s/article/K29294287

Description

If there is an IPv6 self IP configured on BIG-IP, when BIG-IP receives an IPv6 NS (Neighbor Solicitation) for the network address, then BIG-IP will respond NA （Neighbor Advertisement） for such a request.
For example:
An IPv6 self IP is configured as following:

net self v6self {
    address 2001:DB8::251/64
    allow-service all
    traffic-group traffic-group-local-only
    vlan testvlan
}

The network address for this IPv6 subnet is 2001:DB8::.
Then for an IPv6 NS to request MAC address for address 2001:DB8::, BIG-IP will respond NA with its own MAC address.

Environment

  • BIG-IP
  • IPv6 self IP

Cause

This function is by design.

Recommended Actions

Please avoid using IPv6 subnet network address as a service IP in your network.
