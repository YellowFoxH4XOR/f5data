Description

When applying an NGINX Plus configuration that implements NGINX App Protect WAF protection that following error (or similar) occurs.

Config apply failed (write): error running nginx -t -c /etc/nginx/nginx.conf:
error running nginx -t -c /etc/nginx/nginx.conf:
{
  "completed_successfully": false,
  "event": "configuration_load_failure",
  "error_message": "app_protect_default_policy is required but no bundle provides it",
  "softwareVersion": "4.10.0",
  "componentVersions": {
    "wafEngineVersion": "11.48.0",
    "wafNginxVersion": "5.48.0"
  }
}
nginx: configuration file /etc/nginx/nginx.conf test failed

Environment

NGINX Plus

NGINX App Protect WAF

Cause

This error will occur when the 'app_protect_enable on;' directive is implemented with an 'app_protect_policy_file' directive and there is another 'app_protect_enable on;' directive implemented in a separate context block that is not accompanied by an 'app_protect_policy_file' directive. For example:

server {
  ...
  app_protect_enable on;
  app_protect_policy_file "/etc/nms/NginxDefaultPolicy.tgz";
  ...
}
server {
  ...
app_protect_enable on;
  ...
}

Recommended Actions

Either remove the 'app_protect_enable on;' directive(s) that are not paired with the 'app_protect_policy_file' directive or add the 'app_protect_policy_file' directive along with the 'app_protect_enable on;' directive(s) that are not paired with the 'app_protect_policy_file' directive. For example:

server {
  ...
  app_protect_enable on;
  app_protect_policy_file "/etc/nms/NginxDefaultPolicy.tgz";
  ...
}
server {
  ...
  app_protect_enable on;
  app_protect_policy_file "/etc/nms/NginxDefaultPolicy.tgz";  ...
}

Additional Information

If you are deploying the configuration through NIM and the error persists after implementing the procedures under Recommended Actions, restart NGINX Agent on the affected instance(s) and re-Publish the updated configuration from NIM.
