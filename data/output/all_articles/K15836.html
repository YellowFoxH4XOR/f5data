Topic

Summary

The File System module, included with the LineRate version of Node.js, allows only absolute paths.

Description

LineRate uses the Node.js framework to provide a flexible data manipulation mechanism. The File System Node.js module provides various functions for file manipulation, including open, read, and close. While conventional Node.js allows files to be specified with both absolute and relative paths, the LineRate version of Node.js only allows you to reference the absolute path. This limitation affects all functions of the File System module, except for the fs.realpathSync() function.

Assume a file named test.html is located in the current working directory of the LineRate system (/home/linerate/data/scripting by default), and the following code, which references only the relative path, is used in a script to check the status of the file:

fs = require('fs');
try {
  var stat = fs.statSync('test.html');
}
catch(e) {
  console.log(e.message);
}

The system logs a message similar to the following example to the /var/log/controller.messages file:

No such file or directory

Recommendations

F5 recommends that you always specify the absolute path when using the LineRate Node.js File System module. The previously used example can be re-written as follows:

fs = require('fs');
try {
  var stat = fs.statSync('/home/linerate/data/scripting/test.html');
}
catch(e) {
  console.log(e.message);
}

Alternatively, the full path of a specified object can be obtained using the fs.realpathSync() function in the File System module. The previously used example can be re-written as follows:

fs = require('fs');
try {
  var stat = fs.statSync(fs.realpathSync('test.html'));
}
catch(e) {
  console.log(e.message);
}
