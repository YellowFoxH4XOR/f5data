Description

Software downloaded from F5's website may trigger a false positive in a third party malware scanner while being verified prior to installation.
 

Environment

  • Any computer with an anti-malware or antivirus package to which F5 software has been downloaded

Cause

Your anti-malware or antivirus software does not recognize this as safe software in spite of where you downloaded this from.  This phenomenon is rare, but not unheard of.  It is worth knowing that no malware scanner is ever 100% perfect and you may see this with other software - that is, not just F5's software.

Recommended Actions

To verify any download from the F5 download site, please also download the .sig and/or .md5 file(s) and verify the checksum accordingly against those files.  Provided that the checksums match, you can be assured that neither the files nor the contents of said files have been modified in any way.

Additional Information

Please note that F5 does not provide support for third-party software such as anti-malware software.  If you have questions about your malware scanner, please contact the maker of the software directly.
