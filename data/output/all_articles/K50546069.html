Known Issue

External data groups with no metadata can cause the Traffic Management Microkernel (TMM) to not respond.

This issue occurs when all of the following conditions are met:

  • A class match iRule returns at least nine matches.
  • The data group is extremely large.
  • The database variable tmm.classallocatemetadata is set to disabled.

This issue is a result of very large data groups missing the metadata that reports, to the system, the number of entries within the data group. If a class match iRule returns at least nine matches, a misallocation occurs, resulting in the TMM not responding.

Impact

Traffic is disrupted while TMM restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • For standalone BIG-IP systems, all traffic that the system handles is disrupted until TMM restarts. No resources are available until after you reboot TMM,
  • For redundant BIG-IP systems, failover occurs.
