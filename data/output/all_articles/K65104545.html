Description

Email Alerts not sent after upgrade to version 14.x
Error in /var/log/maillog similar to:

err sSMTP[25925]: SSL not working: certificate verify failed (20)
err sSMTP[25925]: Cannot open <mailserver>:587

Environment

  • Recent upgrade to version 14.x
  • Email Notification Configured in /config/user_alert.conf
  • ssmtp (/etc/ssmtp/ssmtp.conf) configured to use user authentication
    AuthUser="Username"
    AuthPass="Password"

Cause

ssmtp doesn't load the system's default set of trusted CAs automatically.

Recommended Actions

At the Bash prompt, reconfigure ssmtp configuration file  to use /etc/ssmtp/ca-bundle.crt CA Certificate:
  1. Make a copy of /etc/pki/tls/certs/ca-bundle.crt:

    cp /etc/pki/tls/certs/ca-bundle.crt /etc/ssmtp/ca-bundle.crt

  2. change the permission of /etc/ssmtp/ca-bundle.crt to read/write for all users like '666':

    chmod 666 /etc/ssmtp/ca-bundle.crt

  3. Modify /etc/ssmtp/ssmtp.conf by adding the following anywhere in the file:

    TLS_CA_File=/etc/ssmtp/ca-bundle.crt
