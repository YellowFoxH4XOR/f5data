K000139119: Inconsistency in password policy enforcement of "reject-username"

Type
Support Solution
Published
2024-03-31
Updated
2024-07-01
Applies to
  • F5OS
  • F5OS-A: 1.7.0
Source
https://my.f5.com/manage/s/article/K000139119

Description

Even after disabling the "reject-username" option with the command system aaa password-policy config reject-username false, the password policy still prevents users from setting their password as their username.

Environment

  • F5OS
  • Password policy

Cause

This is tracked by ID1552921. As expected, the system will always prevent users from configuring a password that is identical to their username.

Recommended Actions

Do not use passwords that contain the username.

Additional Information

None
