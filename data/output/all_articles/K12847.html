Known Issue

When an Active Directory (AD) user account is set to use Kerberos DES encryption, the FirePass controller fails to authenticate the user.

This issue occurs when all of the following conditions are met:

  • The FirePass controller uses Active Directory for authentication.
  • The user account in Active Directory has the Kerberos DES encryption option enabled.

Impact

Affected user accounts are unable to log in to the FirePass controller.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Users accounts set to use Kerberos DES encryption are unable to log in.
  • Affected users receive the error message Either Username or Password do not match!  Please try again.
  • Logon report details contain the message Active Directory auth Failed. You can view the logon details by selecting a user’s logon name on the Reports : Logons page.

Workaround

To work around this issue, you can disable the Use Kerberos DES encryption types for this account option for an Active Directory user account.

For information about managing Active Directory accounts, refer to your Microsoft Windows documentation.

Impact of workaround: There may be other services that authenticate against Active Directory that rely on Kerberos DES encryption to function. Those services will break if you disable Kerberos DES encryption.
