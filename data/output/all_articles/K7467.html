Topic

The BIG-IP system includes the option to install a FIPS hardware security module (HSM). The FIPS HSM is available in the BIG-IP 6400, 6800, 6900, 8400, 8900, 10200, and 11000 platforms.

The HSM stores private keys on Flash RAM within the card. The amount of RAM available depends on the type of FIPS card that is installed. The FIPS cards that ship with the BIG-IP LTM systems support the following maximum number of private keys:

Note: The maximum number of SSL keys listed in the following table is only applicable to RSA 2048-bit private keys.

BIG-IP PlatformMaximum RSA 2048-bit keys
i5820-DF, i7820-DF10,000
10350v-F100,000
5200, 7200, 10200, 110001,998 keys
6900, 890011,327 keys

The numbers differ when you use other SSL key types and bit length combinations. As expected, 512-bit RSA keys take approximately half the space of 1024-bit keys, and 2048-bit RSA keys takes approximately twice as much space.
