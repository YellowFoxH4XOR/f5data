K000148972: Configure SNMP community for IPv6

Type

Published
2024-12-17
Updated
2024-12-17
Source

Description

Configuring SNMP community name and access for IPv6.

  • Able to ping remote system via IPv6, not getting SNMP message. 

 

Environment

  • SNMP access
  • SNMP trap
  • IPv6

 

Cause

Community string is not enabled for IPv6.

 

Recommended Actions

Configure steps from the webUI:

  1. On the Main tab, click System > SNMP > Agent > Access (v1, v2c) or Access (v3).
  2. Click Create.
  3. From the Type list, select IPv6.
  4. In the Community field, type the name of the SNMP community for which you are assigning an access level.
  5. From the Source list, select All, or select Select and type the source IP address in the field that displays.
  6. From the Access list, select an access level, either Read Only or Read/Write.

Configure from the TMSH shell:

modify sys snmp communities add { <name> { access <ro|rw> community-name <name> ipv6 <enabled|disabled> source <IP address> } }

For example:

modify sys snmp communities add { SnmpName { access rw community-name CommunityName ipv6 enabled }}

Verification from TMSH shell : 

list sys snmp communities
