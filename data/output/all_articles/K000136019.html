K000136019: Nessus plugin 69826 is triggering on the BIG-IP's management interface

Type
Support Solution
Published
2023-08-29
Updated
2023-08-29
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000136019

Description

Nessus scan plugin 69826 is claims that the JSESSIONID cookie has the 'secure' property enabled but it's being served over HTTP on the BIG-IP's management interface.

 

Environment

BIG-IP configuration utility

 

Cause

The only response that the BIG-IP serves on port 80, is a redirect to HTTPS. And during the redirect it doesn't set any cookie.

 

Recommended Actions

However, port 80 can be completely disabled by unchecking "Redirect HTTP to HTTPS" under System ›› Preferences

Note: Once this is disabled, https needs to be prefixed when accessing the BIG-IP every time.

 

Additional Information

This is Severity: No Risk as per Nessus
