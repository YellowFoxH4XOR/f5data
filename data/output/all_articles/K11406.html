Topic

When performing a ConfigSync operation from a BIG-IP system that has a FIPS card installed, an error message similar to the following error message may be reported:

key_import_file: error 2 : No such file or directory

This error message occurs only if you have deleted the .exp files from the /ssl/ssl.cavfips directory. The .exp files are encrypted copies of the private keys stored on the FIPS card. These files are automatically created the first time a private key is loaded into the Hardware Security Module (HSM) or when the fipskeys export command is run. The .exp files may be safely deleted, and so the error message can be ignored on BIG-IP systems with FIPS cards.

Additionally, starting in BIG-IP version 9.4.0, this error message is no longer reported on systems with FIPS hardware.
