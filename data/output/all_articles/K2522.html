Topic

In a typical configuration, IDS systems are assigned a false IP address on the BIG-IP system, so traffic destined for the IDS system can be directed to that address. By default, the BIG-IP system applies an ICMP health check to every node. Since the false IP address will not respond to the ICMP health check, the BIG-IP system will mark the node down and will not send traffic to that node.

To resolve this problem, remove the default ICMP check. If you want to use ICMP checks with other nodes, you must assign the ICMP monitor to each node.

For information about how to configure health checks, refer to the Monitors chapter in the BIG-IP Reference Guide.
