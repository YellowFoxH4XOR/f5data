Known Issue

This is the result of a known issue. The BIG-IP 3410 (C100) platform does not pass traffic following an upgrade to version 10.0.0, 10.0.1, or 10.1.0. This issue does not occur immediately after the upgrade. Instead, the upgraded BIG-IP 3410 platform continues to function correctly until the first power cycle, power loss, or full box reboot. After one of the these events occurs, the unit stops passing all traffic.

You can observe the following behavior on a unit affected by this issue:

  • Running the bigpipe interface -j command displays 0 (zero) packets in for the 0.1 and 4.1 interfaces
  • Running the bigpipe ha table command displays the Switchboard Failsafe feature in a triggered state (Act is set to yes)

Note: Management traffic is not affected by this issue.

F5 Product Development tracked this issue as ID 329784 (formerly CR134775), and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, GTM, or Link Controller release notes.

In addition, this issue was fixed in an engineering hotfix issued for BIG-IP version 10.0.1. Customers affected by this issue should contact F5 Technical Support, referencing this Solution number and the associated ID number, to request the hotfix.

Workaround

You can work around this issue by upgrading the affected volumes or partitions on the BIG-IP 3410 platform to BIG-IP version 10.2.0 or later.
