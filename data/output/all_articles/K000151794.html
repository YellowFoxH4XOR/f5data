Description

Procedure to install nShield netHSM client software version 12.60 and above in a BIG-IP LTM environment.

For installation in BIG-IP DNS environment see K000135349: nShield HSM 12.60+ Client installation for BIG-IP DNS sync group

Environment

  • BIG-IP LTM
  • Appliance/VE
  • RFS installed on external server
  • Client software 12.81.2
  • Single nShield netHSM

 

Cause

None

 

Recommended Actions

 

1. Copy files from vendor supplied CD /linux/amd64/nfast/ to nfast directory on BIG-IP:

Depending on the client version you are installing the name of the files may differ to those shown below. These files are for 12.81.2.

ls -la /shared/thales_install/amd64/nfast/

2. Uninstall existing software from BIG-IP devices if installed previously:

nethsm-thales-install.sh -u

The following commands will remove any remaining traces of the client software from BIG-IP:

rm -f /etc/init.d/nc_hardserver

rm -f /opt/nfast

rm -rf /shared/nfast

rm -rf /dev/nfast

userdel nfast

groupdel nfast

 

3. Install and configure RFS on external server and install security world files as per nShield netHSM vendor documentation.

 

4. Verify network connectivity to RFS and netHSM from BIG-IP using ping and/or telnet command. See vendor documentation for port numbers.

 

Ensure these IP addresses have network connectivity and operate in the <NETHSM VLAN> referenced in the next step.

 

5. Install client software on BIG-IP and complete installation:

On BIG-IP:

nethsm-thales-install.sh --hsm_ip_addr=<HSM_IP> --interface=<NETHSM_VLAN> --rfs_ip_addr=<RFS_SELF_IP> --hsm_partition_name="loadshared accelerator"

 

If previous command was successful on BIG-IP, repeat steps 1, 2, 4 and 5 for other BIG-IP devices in the sync group.

6. Run pkcs11d test on each BIG-IP (some tests may fail if not supported on HSM):

pkcs11d_test_suite

 

7. Create ssl key for further testing and deployment.

See manual chapter Managing External HSM Keys for LTM for additional details.
