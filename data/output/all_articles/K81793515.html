Known Issue

The Traffic Management Shell (tmsh) erroneously accepts a floating self IP address to be configured as either of the following mirroring addresses:

  • The Primary Local Mirroring Address (mirror-ip) setting
  • The Secondary Local Mirroring Address (mirror-secondary-ip) setting

By design, the BIG-IP system can mirror only to local self IP addresses. Hence, the Configuration utility displays only the local self IP addresses for selection when you use the Configuration utility to configure mirroring. The tmsh utility, however, displays no IP addresses for selection and incorrectly accepts any self IP addresses that exists on the system. 

Impact

Mirroring on the BIG-IP system fails to function if you have configured a floating self IP address as the mirroring address.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The mirroring on the affected BIG-IP systems fails.
  • If you used the tmsh utility to configure either the mirror-ip or the setting to use the floating self IP address, then in the Configuration utility, the affected mirroring address is displayed as None on the Mirroring Configuration page under the Device Connectivity tab of the device (Device Management > Devices > <name of device>).

Workaround

To work around this issue, you can reconfigure the affected mirroring address to use a local self IP address. To do so, perform either of the following procedures:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Devices.
  3. In the Device List, select the name of the local device indicated with (Self).
  4. In the Device Connectivity section, select Mirroring.
  5. Select the appropriate IP addresses from the Primary Local Mirroring Address and Secondary Local Mirroring Address list.
  6. Click Update.

Traffic Management Shell 

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Configure the primary/secondary mirror address by using the following command syntax:

    modify /cm device <device_name> mirror-ip <IP address> mirror-secondary-ip <IP address>

    For example, configure mirroring for a device named example.com using the local self IP address 192.168.23.100 as the primary mirror address and the local self IP address 192.168.23.101 as the secondary mirror address, by typing the following command:

    modify /cm device example.com mirror-ip 192.168.23.100 mirror-secondary-ip 192.168.23.101

  3. Save the change by typing the following command:

    save /sys config
