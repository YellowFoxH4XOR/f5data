Topic

Starting in FirePass version 6.0.3, you have the option to export and import pre-logon sequences. This option allows you to configure a large number of pre-logon sequences across multiple FirePass controllers. To export and import a pre-logon sequence, perform the following three procedures:

Exporting a single pre-logon sequence

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users: Endpoint Security: Pre-Logon Sequence page.
  3. In the Select Sequence to Use section, click the export link next to the name of the pre-logon sequence you want to export.
  4. When prompted by your browser, download the zip file containing the exported sequence.

 
Exporting all pre-logon sequences

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users: Endpoint Security: Pre-Logon Sequence page.
  3. In the Import/Export Sequence(s) section, click the Click here to export all sequences link.
  4. When prompted by your browser, download the zip file containing the exported sequences.


Importing a pre-logon sequence

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users: Endpoint Security: Pre-Logon Sequence page.
  3. In the text field in the Import/Export Sequence(s) section, enter the full path to the zip file containing the pre-logon sequence or sequences you want to import.

    Alternately, click the Browse button to browse for the zip file.
  4. Click the Import button.

Note: If you selected the Click here to export all sequences link to create the zip file, all pre-logon sequences contained in the zip file will be imported.

Important: If the name of an imported pre-logon sequence matches the name of an existing pre-logon sequence on the FirePass controller, FirePass does not overwrite the existing pre-logon sequence. Instead, FirePass adds a number to the end of the imported pre-logon sequence name so that it does not conflict with an existing name. For example, if the imported pre-logon sequence name is AV, but a pre-logon sequence named AV already exists on the FirePass controller, FirePass renames the imported pre-logon sequence to an available name, such as AV(1).
