K87963051: Virtual servers in traffic-group-local-only (non-floating) will not sync to device group

Type
Support Solution
Published
2021-01-07
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.X.X, 13.1.X, 13.0.X, 12.1.X, 12.0.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.0, 13.0.1, 12.X.X, 12.1.6, 12.1.5, 12.1.4, 12.1.3, 12.1.2, 12.1.1, 12.1.0, 12.0.0, 13.0.0
Source
https://my.f5.com/manage/s/article/K87963051

Description

  • Virtual servers is missing on the standby device
  • The sync status of the device shows that they are In Sync

Environment

  • BIG-IP LTM
  • HA Configuration

Cause

Traffic objects in traffic-group-local-only (non-floating) will not sync to group. This is by design. Allowing local-only traffic objects to sync will cause IP conflict, therefore prohibited.

Recommended Actions

Modify the configuration of the Virtual Address to be part of traffic-group floating type, normally traffic-group-1.

Steps to do it:
  1. On the Active device GUI, go to Local traffic > Virtual address list
  2. Click on the Virtual Address affected
  3. Change traffic group to floating traffic group from drop-down menu
  4. Select update
  5. Now perform a config sync from Active to Standby ( select overwrite configuration check box)
  6. Confirm virtual server is synced to Standby device.

Additional Information

  • A  symptom is that the Device will still process traffic for the affected Virtual Server when in Standby.
  • This can occur if the Virtual Address is the same as an existing Self IP in traffic-group-local. In this case the Traffic group of the Virtual Address cannot be changed.
  • To verify if the Virtual Address is of type floating or non-floating, we might need to execute the command below :

LOCAL :

ltm virtual-address /Development/x.x.x.x {
    address x.x.x.x
    arp enabled
    mask 255.255.255.255
    traffic-group /Common/traffic-group-local-only  -------------- LOCAL
}

FLOATING:

ltm virtual-address /Development/y.y.y.y{
    address y.y.y.y
    arp enabled
    mask 255.255.255.255
    traffic-group /Common/traffic-group-1------------------------- FLOATING
