Description

NTLM authentication is failing and the following messages are logged in /var/log/apm:

Jun 20 13:31:44 slot1/bigip debug nlad[24645]: 01620000:7: <0x7fa84127d700> client[7]: DC[10.0.1.20]: schannel[2]: DC returned code: 0xc0000022. Netlogon Authenticator validation failed.

Jun 20 13:31:45 slot1/bigip debug eca[24777]: 0162000c:7: [Common] 192.168.0.101:43969 (0x7f97c0003430) nla_agent::logon, rc = STATUS_ACCESS_DENIED (3221225506)

The Microsoft Windows 2022 server is logging the error:

Event ID 5827 The Netlogon service denied a vulnerable Netlogon secure channel connection from a machine account.

Environment

  • BIG-IP APM configured as RDP gateway
  • Windows Server 2022 with fix for cve-2020-1472 that enforces secure RPC when using the Netlogon secure channel

Cause

Client side NTLM authentication will fail if encryption is disabled for the nlad daemon on the BIG-IP with the following line in "/etc/bigstart/startup/nlad":

exec /usr/bin/${service} -use-log-tag 01620000 -encrypt no

Recommended Actions

Do not disable encryption for nlad on the BIG-IP. If encryption is already disable, reenable it be removing the "-encrypt no" flag in the above referenced configuration file.

Additional Information

Microsoft Windows Server updates as of February 2021 will enforce secure schannel communication.
