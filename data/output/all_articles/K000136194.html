Description

The add command `modify ltm html profile <name> { rules add { <rule_name> } }` is not working properly.

<Scenario 1> 

root@(bigipA)# tmsh list ltm profile html test-html-profile
ltm profile html test-html-profile {
app-service none
rules {
test-01
}
}

root@(bigipA)# tmsh modify ltm profile html test-html-profile rules add { test-02 } 

Using add {} command is accepted, but it doesn’t actually update the profile.

root@(bigipA)# tmsh list ltm profile html test-html-profile
ltm profile html test-html-profile {
app-service none
rules {
test-01
}
}

<Scenario 2>  

root@(bigipA)# tmsh list ltm profile html test-html-profile
ltm profile html pr-html-bug-no-add {
app-service none
rules {
test-01
test-02
}
}

Using add {} command is accepted, but it doesn’t actually update the profile even test-02 is deleted. 

root@(bigipA)# tmsh modify ltm profile html test-html-profile rules add { test-02 }

root@(bigipA)# tmsh list ltm profile html test-html-profile
ltm profile html pr-html-bug-no-add {
app-service none
rules {
test-01
}
}

Environment

BIG-IP
TMSH

Cause

(Add) the command for 'ltm profile html rules" doesn't work correctly.

Recommended Actions

Please consider one of the workarounds below to add or replace the rule for html profile. 

1. Use 'replace-all-with' instead of 'add'.
Note: If the html profile has already rule configured, existing rule and new rule for HTML profile should be in the replace-all-list {}.

tmsh modify ltm profile html <name of profile> rules replace-all-with { <existing rule> <new rule>}

root@(bigipA)# tmsh list ltm profile html test-html-profile
ltm profile html test-html-profile {
app-service none
rules {
test-01
}
}
root@(bigipA)# tmsh modify ltm profile html test-html-profile rules replace-all-with { test-01 test-02 }

2. Use 'add' command to add rules at the same time to empty html profile.

When test-html-profile does not have any rule yet: 

root@(bigipA)# tmsh list ltm profile html test-html-profile ltm profile html test-html-profile {
app-service none
}
root@(bigipA))# tmsh modify ltm profile html test-html-profile rules add { test-01 test-02 }


3. Use 'add' command with the same rule name two times

If you want to add test-02 rule into test-html-profile including already test-01: 

root@(bigipA))# tmsh modify ltm profile html html test-html-profile rules add { test-02 test-02 }   <<-- list its name twice.
