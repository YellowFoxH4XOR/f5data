Known Issue

The BIG-IP WebAccelerator or BIG-IP AAM may erroneously validate Extension values in an acceleration policy.

Note: BIG-IP WebAccelerator and BIG-IP WOM were combined to create BIG-IP AAM in BIG-IP 11.4.0.

This issue occurs when the following condition is met:

  • You configure an acceleration policy with an Extension value that starts with or is equal to any of the following values:
    • * (asterisk)
    • *. (asterisk period)
    • . (period)

The system fails to validate these values, but they appear to save and publish normally. The system does not support these values, and will not compile the policy.

Impact

An affected acceleration policy fails to compile and is not enforced against any traffic processed by a virtual server that is configured to use the policy. Affected traffic bypasses the BIG-IP WebAccelerator or BIG-IP AAM functionality.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H554023 on the Diagnostics > Identified > Medium page.
  • When you configure an Extension with an affected value in an acceleration policy, the policy appears to save and publish normally. However, BIG-IP WebAccelerator or BIG-IP AAM functionality is not applied to traffic processed by a virtual server that is configured to use the policy.
  • When you load a configuration that contains an affected policy, the configuration appears to load normally. However, BIG-IP WebAccelerator or BIG-IP AAM functionality is not applied to traffic processed by a virtual server that is configured to use the policy.
  • In the /var/log/tmm file, you observe an error message similar to the following example:

    WAC [wac_finalize_policy]: ERROR - unable to compile policy '/Common/Copy2 of Generic Policy - Complete'. 

Resolution

Workaround

To work around this issue, you can ensure that any Extension values in an acceleration policy are not configured to start with or be equal to the affected values (*, *. or .).

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
