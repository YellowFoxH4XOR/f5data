K000140412: Allowed parameters are not detected on ASM and being block

Type
Support Solution
Published
2024-07-23
Updated
2024-08-01
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000140412

Description

ASM does not detect an allowed parameter and blocks the request.

 

Environment

  • ASM
  • More than 5000 parameters

Cause

The URL has over 5000 parameters, and the maximum configurable value is 5000; see K05240064.

Recommended Actions

Increase the internal max_num_request_params to a value greater than 5000.

Note: Increasing the number of allowed parameters can impact CPU utilization and memory.

 

/usr/share/ts/bin/add_del_internal add max_num_request_params < Number of Parameters >

Example:

/usr/share/ts/bin/add_del_internal add max_num_request_params 10000

 

Additional Information

CPU Utilization and memory usage should be monitored. In addition, you may have to fine-tune the parameter number to find the right value for the environment.
