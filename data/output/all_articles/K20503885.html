Issue

Old Behavior

In versions prior to BIG-IP 11.2.0, the Alert Timeout setting in the BIG-IP Secure Sockets Layer (SSL) profiles has a default value of 60 seconds.

The SSL alert timeout specifies the duration that the system tries to close an SSL connection by transmitting an alert or initiating an unclean shutdown before resetting the connection.

New Behavior

In BIG-IP 11.2.0 through 12.0.0, the Alert Timeout setting in the BIG-IP SSL profiles has a default value of 10 seconds. Beginning in BIG-IP 12.0.0 HF1 for the BIG-IP 12.0.0 branch and BIG-IP 12.1.0, the default value of the Alert Timeout setting is now indefinite.

A slow client SSL connection may be prematurely reset if the SSL alert timeout is set too low. This change may help alleviate this potential scenario. For more information, refer to K81143224: The BIG-IP system may prematurely reset client SSL connections that are slow.

F5 Product Development tracked this change as ID 382830 and ID 447958.

Impact

SSL connections should not be reset after transmitting an alert or initiating an unclean shutdown.
