K83220400: Any admin password works for Control REST endpoint starting with /mgmt using restcurl utility

Type
Support Solution
Published
2021-08-05
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K83220400

Description

When using restcurl utility, a user name is needed when querying any iControl REST endpoint starting with /mgmt but placing a blank (or any password) will still display the expected items queried.  

Example: 
# restcurl -u admin: /mgmt/tm/net/self
{
  "kind": "tm:net:self:selfcollectionstate",
  "selfLink": "https://localhost/mgmt/tm/net/self?ver\u003d13.1.3",
  "items": [
    {
      "kind": "tm:net:self:selfstate",
      "name": "example_self",
      "partition": "Common",
      "fullPath": "/Common/example_self",
      "generation": 1,
      "selfLink": "https://localhost/mgmt/tm/net/self/~Common~example_self?ver\u003d13.1.3",
      "address": "192.168.100.1/24",
....


Environment

  • BIG-IQ
  • Making a query or request by accessing a REST endpoint starting with /mgmt/ using restcurl

Cause

This is an expected behavior. You can only use restcurl after authenticating to bash and the command line (ssh).  Adding /mgmt to the url forces the entry to webd, which requires a username and password, but it recognizes that you are already authenticated.

Recommended Actions

None. 

Additional Information

Note: The only entry point externally is through webd, which requires the /mgmt/ to have a username and password, so there is no security hole.
