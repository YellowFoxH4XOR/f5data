Description

Steps to modify a multi bladed vCMP guest with cluster and individual blade management IP addresses.

Environment

  • Multi blade vCMP guest with each blade instance with it's own management IP address

Cause

None

Recommended Actions

  1. Access the BIG-IP Bash prompt of the vCMP guest
  2. Change the cluster and blade management IP addresses on the vCMP guest:
    Note: In this example the vCMP guest runs on 4 blade instances

    tmsh modify sys cluster default { address <ip adrress/mask> members { 1 { address <blade 1 ip address> } 2 { address <blade 2 ip address>  } 3 { address <blade 3 ip address>  } 4 { address <blade 4 ip address>  } } }

    For example:

    tmsh modify sys cluster default { address 10.0.0.5/24 members { 1 { address 10.0.0.1 } 2 { address 10.0.0.2  } 3 { address 10.0.0.3  } 4 { address 10.0.0.4  } } }

  3. Save the configuration:

    tmsh save sys config

  4. Access the BIG-IP Bash prompt of the vCMP host 
  5. Change the cluster IP address and gateway on the vCMP host:

    tmsh modify vcmp guest <guest name> { management-ip <ip/subnet bits> management-gw <gateway ip> }

    For example:

    tmsh modify vcmp guest GUEST1 { management-ip 10.0.0.5/24 management-gw 10.0.0.254 }

  6. Save the configuration:

    tmsh save sys config

None
