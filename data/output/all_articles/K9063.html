Topic

In BIG-IP ASM versions 9.4.2 through 9.4.8, you can enable or disable application security on all virtual servers by using the Module.ASM bigdb variable.

Note: Enabling or disabling application security in version 10.x is done using the Resource Provisioning screen in the Configuration utility.

Enabling the BIG-IP ASM

Before using the ASM on the BIG-IP system, you may need to enable the module. For example, when you install the ASM on a BIG-IP system, you must enable it before you can access it from the Configuration utility.

You can enable the system from the command line, or by using the Configuration utility. To do so, perform one of the following two procedures:

Enabling the ASM from the command line

  1. Log in to the command line.
  2. Type the following command:

    bigpipe db Module.ASM enable
  3. To reboot the BIG-IP system, type the following command:

    reboot

Enabling the ASM using the Configuration utility

  1. Log in to the Configuration utility.
  2. Click System.
  3. Click License.
  4. Click the Modules tab.
  5. Select Enabled from the Application Security Manager drop-down menu.
  6. Click Update.
  7. Reboot the BIG-IP system.

Disabling the ASM

Under certain circumstances, you may want to disable the ASM, and return the box to CMP mode. For example, if you are debugging traffic processing through a virtual server, you might want to temporarily disable the ASM.

You can disable the ASM from the command line, or by using the Configuration utility. To do so, perform one of the following two procedures:

Disabling the ASM from the command line

  1. Log in to the command line.
  2. Type the following command:

    bigpipe db Module.ASM disable
  3. To reboot the BIG-IP system, type the following command:

    reboot

Disabling the ASM using the Configuration utility

  1. Log in to the Configuration utility.
  2. Click System.
  3. Click the Modules tab.
  4. Select Disabled from the Application Security Manager drop-down menu.
  5. Click Update.
  6. Reboot the BIG-IP system.

Note: For information about disabling and enabling application security on all virtual servers for BIG-IP ASM versions 9.2.3 through 9.2.5, refer to K5889: Disabling and enabling application security on all virtual servers.

Note: For information about disabling and enabling application security on all virtual servers for BIG-IP ASM versions 9.4.0 through 9.4.1, refer to K7016: Disabling and enabling application security on all virtual servers.
