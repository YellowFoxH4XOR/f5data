K000162076: BIG-IP AFM Policy Compilation Performance Impact When Using FQDN Address Lists with Empty Source or Destination Fields

Source

Description

When configuring BIG-IP AFM firewall rules with FQDN address lists in the destination field and leaving the source address list empty or set to "any," policy compilation times can increase dramatically, potentially exceeding 15 minutes. Compilation times return to normal (e.g., 30 seconds) when FQDN rules are disabled or when both source and destination address lists are explicitly defined.

Following an example issue configuration:

The rule-list /Common/zone_UNTRUST-to-zone_TRUST has an FQDN address-list in the destination, but an empty source address-list. 

root@(velos-d)(cfg-sync Disconnected)(/S1-green-P::FIREWALL RULES COMPILATION IN-PROGRE*)(/Common)(tmos)# list security firewall rule-list zone_UNTRUST-to-zone_TRUST
security firewall rule-list zone_UNTRUST-to-zone_TRUST{
    rules {
        ID-123456 {
            action accept-decisively
            description "Legacy ID: 900"
            ip-protocol tcp
            destination {
                address-lists {
                    ABC-ABCD-GROUP
                    FW_FQDN_List
                }
                port-lists {
                    HTTPS
                }
                zones {
                    zone_TRUST { }
                }
            }
            source {
                zones {
                    zone_UNTRUST { }
                }
            }
        }

}

Environment

  • Product: BIG-IP AFM
  • Version: 17.1.3
  • Firewall rules using FQDN address lists in the destination field with empty or undefined source address lists

Cause

Excessive compilation time occurs when firewall rules use FQDN address lists in the destination field and the source address list is left empty or set to "any." This leads to inefficient blob generation during policy compilation. This behavior is tracked under Bug ID 2290261 and is considered "Functions As Designed."

Answer/Recommended Actions

  • Always define specific address lists for both source and destination fields in firewall rules that use FQDN address lists.
  • Avoid leaving source or destination address lists empty or set to "any" to prevent slow policy compilation.
  • Review and update existing firewall rules to ensure address lists are explicitly set.

Additional Information

Adding explicit address lists to both source and destination fields significantly reduces policy compilation time.
