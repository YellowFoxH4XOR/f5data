Known Issue

This is the result of a known issue. Users who try to download a CSR from the Web Services tab on the Device Management: Configuration: Network Configuration page will only be able to download the last created CSR. This occurs even if the last CSR has been deleted from the Administrative Console. Please make sure to confirm the time stamp of any CSR file that you download to ensure it is the CSR file you are expecting.

F5 Product Development tracked this issue as CR134002 and it was fixed in FirePass 7.0.0. For information about upgrading, refer to the FirePass release notes.
