Known Issue

Disabling Virtual Local Area Network (VLAN)-keyed connections may trigger the Traffic Management Microkernel (TMM) process to produce a core file and restart.

This issue occurs when all of the following conditions are met:

  • You disable VLAN-keyed connections.
  • The BIG-IP system processes File Transfer Protocol (FTP) or multicast traffic.

Impact

The BIG-IP system temporarily fails to process traffic while the TMM process restarts. If the BIG-IP system is configured for high availability (HA), the system fails over to a peer system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM generates a core file in the /shared/core directory.
  • The BIG-IP system logs a SIGFPE to the /var/log/tmm file at the same time as TMM produces a core file and restarts.
  • The BIG-IP system logs repeating error messages in the /var/log/tmm files that appear similar to the following example:

    notice ** SIGSEGV **

  • The BIG-IP system logs repeating error messages in the /var/log/ltm file that appear similar to the following example:

    notice lopd[4153]: 013d0006:5: caught SIGTERM
