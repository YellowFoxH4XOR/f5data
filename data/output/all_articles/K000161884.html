Topic

Beginning in F5OS 2.0.0, F5OS-A software for rSeries appliances and F5OS-C software for VELOS chassis systems are unified into one F5OS release.

Description

F5OS 2.0.0 unifies F5OS-A and F5OS-C software images into one F5OS version release for rSeries appliances and VELOS chassis systems. Unifying F5OS-A and F5OS-C software releases simplifies software management and reduces complexity across diverse deployments. This provides a more uniform experience for system operations and software lifecycle management.

Software images

In F5OS 2.0.0 and later, the software image files for rSeries appliances and VELOS chassis systems now specify the hardware platform type in the file name and include the following platform types: 

Platform typeDescription
R2R4Software ISO image for r2000 and r4000 series appliances.
R5R10Software ISO image for r5000, r10000, and r12000 series appliances.
APPLIANCESoftware ISO image for all rSeries appliances (r2000, r4000, r5000, r10000, and r12000 series).
CONTROLLERSoftware ISO image for VELOS system controllers (SX410 and SX1610).
PARTITIONSoftware ISO image for VELOS chassis partitions (BX110 and BX520 blades).
CHASSISSoftware bundle which includes ISO images for VELOS system controllers and chassis partitions.

For example, the first two software image files listed below support specific rSeries appliances and the third supports all rSeries appliances:

  • F5OS-2.0.0-22925.R2R4.iso
  • F5OS-2.0.0-22925.R5R10.iso
  • F5OS-2.0.0-22925.APPLIANCE.iso

F5OS 2.0.0 and later software for VELOS chassis systems still includes a single bundled image containing system controller and chassis partition ISO images, as well as granular ISO images for just the system controller or chassis partition software. 

Features and enhancements

In addition to unifying F5OS releases, F5OS 2.0.0 also strengthens security and system resilience by updating key software components, adding SHA-256/512 for SNMPv3 authentication and AES-256 for SNMPv3 encryption, enhancing cipher management, and adding support for TLS 1.3 for the management interface. 

Other enhancements and added features include the following:

  • Updated webUI interface retaining the same API
  • Support for bcrypt/blowfish encryption for stored passwords
  • Management interface VLAN tagging for rSeries
  • Support for IEEE 802.1ad double tagging (Q-in-Q)
  • Cloud-init support for F5OS tenants
  • Foreground Diagnostics providing hardware and service health in live environments

For more information about fixes and known issues in F5OS 2.0.0, refer to the F5OS 2.0.0 release notes.

Note: F5OS 2.0.0 release notes are located under the F5OS Platform Software for VELOS product line of the F5OS product family/group on the MyF5 Downloads page. Select 2.0.0 under Product Version to locate the release notes.
