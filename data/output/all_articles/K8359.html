Topic

The SCCP is a separate sub-system that controls the F5 switch hardware.

To determine the version of the SCCP running on the BIG-IP system, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Use SSH to access the SCCP by typing the following command:

    ssh sccp

  3. After you are logged into the SCCP, type the following command:

    flashver |grep kernel

    The SCCP version information will appear similar to the following example:

    kernel SCCP Linux build 12.0.5.5.0 Fri Sep 14 17:09:17 2007

  4. Type the following command to exit the SCCP:

    exit

Note: For more information, refer to K3454: Overview of the SCCP.
