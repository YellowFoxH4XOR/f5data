Known Issue

The BIG-IP APM system may fail to create VDI (VMware View and Citrix) remote desktops.

This issue occurs when all of the following conditions are met:

  • In the Configuration utility, you attempt to create a new VDI remote desktop using Pool as the destination type.
  • You attempt to create a new VDI remote desktop in a non-default partition that uses a route domain different than 0.

Impact

You are unable to create VDI remote desktops through the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to create a new VDI remote desktop resource, the Configuration utility displays an error message similar to the following example:

    01070734:3: Configuration error: apm resource remote-desktop: /<partition_name>/<vdi_desktop_ressource_name> :only one destination type is supported

Workaround

To work around this issue, you can configure the VDI remote desktop resource using the TMOS Shell (tmsh). To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. From the /Common partition, type the following command to switch the relevant partition:

    cd /partition_name/

  3. To create a VMware view remote desktop named test_res_vdi that is associated with the /partition_name/pool_testpool, type the following command:

    create apm resource remote-desktop vmware-view test_res_vdi pool /partition_name/pool_test

  4. To save the configuration change, type the following command:

    tmsh save sys config
