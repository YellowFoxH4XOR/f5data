Description

Unable to download the attack signatures for BIG-IP ASM device

Following errors are noted in GUI

Check for updates failed for the following modules:

  • ASM Attack Signatures - Could not retrieve latest file for asm-attack-signatures
  • Browser Challenges - Could not retrieve latest file for browser-challenges
  • Server Technologies - Could not retrieve latest file for server-technologies   

Following logs are noted in /var/log/asm or /var/log/tomcat/liveupdate.log

SEVERE: Servlet.service() for servlet [org.apache.jsp.tmui.system.support.download_jsp] in context with path [/tmui] threw exception java.lang.IllegalStateException: getOutputStream() has already been called for this response

Environment

  • BIG-IP ASM attack signature update
  • BIG-IP ASM able to resolve and able to reach callhome.f5.com
  • BIG-IP ASM device has valid support contract

Cause

None.

Recommended Actions

  1. Login into BIG-IP device through SSH, and restart the following process.

           pkill -f asm_config_server
           bigstart restart restjavad
           tmsh restart sys service tomcat

           Impact of workaround: The BIG-IP Configuration utility will not be available until tomcat daemon is up.

        2. Download the live update again in BIG-IP ASM device
