Topic

This article applies to BIG-IP Edge Client for macOS clients when you update the APM Clients version of your BIG-IP system to 7.1.9 or later. For more information on APM Clients versions, refer to K13757: BIG-IP Edge Client version matrix.

Description

Beginning in APM Clients 7.1.9, BIG-IP Edge Client for Mac, the main operations window is moved to the upper task bar to make operations less intrusive. New users may not notice the new top menu item and may mistakenly believe the client is not running. 

To mitigate this problem, new welcome and splash screens are added to make launching the BIG-IP Edge Client for the first time more obvious to new users. 

The welcome screen has a Do not show this welcome screen on start check box that you can use to prevent the screen from appearing in the future. The splash screen displays for three seconds each time BIG-IP Edge Client starts.

Recommendations

BIG-IP Edge Client provides controls for you to enable or disable the splash and welcome screens. Depending on whether you are a VPN user or a BIG-IP APM administrator, perform the following procedures:

  • VPN user: Enable or disable the welcome and splash screens
  • BIG-IP APM administrator: Enable or disable the welcome and splash screens
VPN user: Enable or disable the welcome and splash screens

As a VPN user, perform the following procedure on your Mac client:

  1. Launch BIG-IP Edge Client on Mac.
  2. Select the BIG-IP Edge Client icon at the top.
  3. Select Preferences.
  4. Select either one of the following check boxes or leave both cleared.
    • Show Welcome Screen on start
    • Show Splash Screen on start
  5. Close the Preferences window.
BIG-IP APM administrator: Enable or disable the welcome and splash screens

As a BIG-IP administrator, you use the following domain and key pair to enable or disable the welcome and splash screens:

  • Welcome screen:
    • Domain: com.f5networks.EdgeClient
    • Key: F5DoNotShowWelcomeScreenOnStart
  • Splash screen:
    • Domain: com.f5networks.EdgeClient
    • Key: F5DoNotShowSplashScreenOnStart

To set the values of the keys, you use the defaults command, which you can run on a Mac terminal or in a script or policy that manages the macOS client systems in your environment. To do so, use the following command syntaxes:

Note: For more information on the defaults command, enter defaults help. 
  • To read the current running values of the keys, enter the following commands:
defaults read com.f5networks.EdgeClient F5DoNotShowSplashScreenOnStart
defaults read com.f5networks.EdgeClient F5DoNotShowWelcomeScreenOnStart
  • To display the values of all keys in the com.f5networks.EdgeClient domain, enter the following command:

    defaults read com.f5networks.EdgeClient

  • To enable the keys and disable the welcome or splash screens, enter the following commands:
defaults write com.f5networks.EdgeClient F5DoNotShowSplashScreenOnStart 1
defaults write com.f5networks.EdgeClient F5DoNotShowWelcomeScreenOnStart 1
