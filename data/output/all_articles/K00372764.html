Description
When you use the iControl Rest API to create a client ssl profile, you receive the error:

{"code":400,"message":"one or more configuration identifiers must be provided","errorStack":[],"apiError":26214401}

Environment

  • BIG-IP v14, 15
  • Clientssl profile
  • iControl Rest API

Cause
The key/value pair for certKeyChain requires a name attribute while cert-Key-Chain does not.

Recommended Actions

  1. If using the attribute certKeyChain use [ {"name":"default","cert":"myApi.crt","key":"myApi.key"} ]
  2. If using the attribute cert-key-chain use [ {"cert":"myApi.crt","key":"myApi.key"} ]

Additional Information
An example client-ssl POST request using cert-Key-Chain:

REQUEST

POST '/mgmt/tm/ltm/profile/client-ssl/' \
--header 'Content-Type: application/json' \
--header 'Authorization: Basic ****' \
--data-raw '{
    "name":"myClientSSLProfile",
    "partition": "Common",
    "fullPath": "/Common/myClientSSLProfile",
    "cert-Key-Chain":[{"cert":"default.crt","key":"default.key"}]
}'

RESPONSE

HTTP 200

POST '/mgmt/tm/ltm/profile/client-ssl/' \
