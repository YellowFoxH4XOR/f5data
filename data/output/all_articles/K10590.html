Topic

This Solution provides the steps required to update the BIG-IP 8400/8800 platform BIOS, which corrects the USB boot issue described in K9399: BIG-IP 8400 and 8800 systems may not allow booting from some USB devices.

Important: The steps in this Solution require that you access the BIG-IP 8400/8800 platform through the serial/console port in order to install the BIOS update. F5 recommends that you apply the BIOS update to the standby system first or during a maintenance window for a standalone system.

Note: The workaround in SOL9399 is temporary, as it does not persist through a power cycle. Updating the BIOS, which is outlined in this Solution, provides a permanent fix for affected platforms.

Important: This Solution only applies to 8400 and 8800 systems built with the following motherboard part numbers: MOB-0019-07, MOB-0019-08 and MOB-0019-09. You can view the part number of the motherboard by typing the following command:

bigpipe platform show | grep MOB

Output will appear similar to the following example:

Host board   serial: 05120981100028   part: MOB-0019-07 REV A

Attempting this Solution on a non-affected system will not adversely affect the system; instead the flash operation will fail.

To upgrade the BIG-IP 8400 and 8800 platform BIOS, perform the following procedure:

  1. Create a DOS bootable USB thumb-drive.

    Note: Check with your USB thumb-drive manufacturer for tools to make the USB thumb drive DOS bootable or the freely available HP USB Disk Storage Format Tool (Windows XP/Vista) is reported to work with many different USB thumb-drives.

  2. Download the 8x00BIOS.zip file from downloads.f5.com.
     
  3. Uncompress the file. It will contain the following three files:

    8400BE.com
    ADOS414.exe
    OBJ-0099.rom
  4. Copy the files to the DOS bootable USB thumb-drive.
     
  5. Connect the USB thumb-drive to the BIG-IP 8400/8800 platform.
     
  6. Connect to the BIG-IP 8400/8800 platform console/serial port.

    Note: For serial ports settings, refer to K7683: Connecting a serial terminal to a BIG-IP system.
  7. Display the SCCP menu by simultaneously pressing and holding the Shift, ESC, and 9 keys.

    Note: The command being sent is: ESC (.

    You will be presented with a screen that appears similar to the following example:

    [hostconsh] Command Menu:
    1 --- Connect to Host subsystem console
    2 --- Select Host subsystem boot mode: boot from local drive
    3 --- Select Host subsystem boot mode: netboot from SCCP
    4 --- Select Host subsystem boot mode: netboot from external server
    5 --- Reboot Host subsystem (sends reboot command)
    6 --- Halt   Host subsystem (sends halt command)
    7 --- Reset  Host subsystem (issues hardware reset--USE WITH CARE!)
    8 --- Reboot SCCP subsystem (issues hardware reset--USE WITH CARE!)
    9 --- Halt   SCCP subsystem (issues hardware shutdown--USE WITH CARE!)
    Q --- Exit Host subsystem console shell
    [hostconsh] Enter command:
  8. Reboot the host and redirect the serial connection to the host, using the following options:

        * Press 7 to Reset the Host.
        * Press y when asked if you want to proceed.
        * Press 1 when the Command Menu is presented again.

    This procedure allows you to reboot or reset the host portion of the system, and then connect to the host while it is in the process of booting.
     
  9. Press the DEL key.

    The BIOS SETUP screen will display.

    Note: Some terminal emulators do not correctly forward key-strokes over the serial connection. Correct operation has been observed using HyperTerminal.
     
  10. Click the left arrow button once to enter the EXIT screen.
     
  11. Click the arrow down button once to enter the LOAD OPTIMAL DEFAULTS screen.

  14. After booting to the DOS bootable USB thumbdrive, run the following commands in the order given:

        a. 8400be.com

        b. ADOS414.exe OBJ-0099.rom /P /B /N /C /L0

        Note: The L0 option the string above is L (zero).
  15. The Firmware Update Utility screen will appear and the flash upgrade will commence.

    The screen will appear similar to the following:

      NOTE: The install will take a few minutes; wait for the UUT to reboot.
    WARNING: Do not interrupt the install it will corrupt the BIOS.
  16. Once the BIOS update is completed, remove the USB thumb-drive, and reboot the system.
