Description

Custom Endpoints in Telemetry Streaming not returning the same format as default endpoints.

with using include data, they returned the same virtual server name of tmui.

f5_clientside_totConns{virtualServers="/Common/vip_192.168.1.100_1234"} 0

however, after changing it to custom endpoint, they returned it with underscored for virtual server name as follows.

f5_virtualTotConns__Common_vip_192_168_1_100_1234_stats_clientside_totConns 0

 

 

Environment

  • Telemetry Streaming
  • Custom endpoints

Cause

https://github.com/F5Networks/f5-telemetry-streaming/issues/257

Recommended Actions

Custom Endpoints doesn't provide the same internal contextual data and default endpoints. That's why metric's generator/parser unable to provide the same output.

 

Due to this we should treat this request as RFE and because TS is no longer under development it want be implemented

PLEASE NOTE: F5 BIG-IP Telemetry Streaming is no longer in active development. We are moving this technology into maintenance mode, focusing on the next generation of Telemetry innovations. We will continue to update BIG-IP TS with critical security updates.
