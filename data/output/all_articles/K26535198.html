K26535198: AGC is not synching over the HA units

Type
Support Solution
Published
2020-04-14
Updated
2023-06-30
Applies to
  • BIG-IP
  • BIG-IP APM: 15.X.X, 15.1.X, 15.0.X, 15.1.0, 15.0.1, 15.0.0, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1
Source
https://my.f5.com/manage/s/article/K26535198

Description
The Access Guided Configurations (AGC) may not synchronize over between the BIG-IP HA units. 

Environment

  • BIG-IP Access Policy Manager (APM)
  • Access Guided Configuration
  • BIG-IP Device Service Clustering (DSC) or High Availability (HA) system

Cause
Each BIG-IP unit in the HA should have its own unique REST device ID

You can verify this by running the following command in the HA units:

cat /config/f5-rest-device-id

Check if the HA units have the same REST device IDs.

Recommended Actions

You can generate a new REST device ID file for the affected BIG-IP device by performing the following procedure. 

F5 recommends that before making any changes to your systems, you back up each system and store the backup to a remote location. For information, refer to K13132: Backing up and restoring BIG-IP configuration files with a UCS archive.

Impact of procedure: The following procedure requires that you restart the restjavad process; therefore, the REST interface of this device will be unavailable while the system is restarting the process.

  1. Log in to the affected BIG-IP device.
  2. Rename the existing REST device ID file by typing the following command:
    mv -b /config/f5-rest-device-id /config/old.f5-rest-device-id
  3. Restart the restjavad process to generate a new set of REST device ID files by typing the following command:
    tmsh restart /sys service restjavad
  4. Validate that you have the new REST device ID in the /config/f5-rest-device-id file and that is not the same as the HA peer unit.
  5. Synchronize the AGC over the HA units.
  6. Once the AGC successfully synchronizes between the HA units, you can safely delete the old duplicate file that you renamed in step 2.
    To delete the files, type the following command:
    rm -f /config/old.f5-rest-device-id
