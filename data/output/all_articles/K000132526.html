Description

You suddenly encounter unable to access a site through the SSLO that forward proxy enabled in the SSL profile of topology and the profile contains expired CA certificates in the ca-bundle even though it contains other valid CA certificates.

 

In /var/log/ltm log, you would see similar messages as below are logged.

 

warning tmm1[25038]: 01260006:4: Peer cert verify error: certificate has expired (depth 0; cert /C=US/O=Example./CN=Example CA)

warning tmm1[25038]: 01260009:4: 203.0.113.1:443 -> 192.0.2.1:53212: Connection error: ssl_shim_vfycerterr:4405: alert(45) certificate has expired

warning tmm1[25038]: 01260006:4: Peer cert verify error: self signed certificate in certificate chain (depth 0; cert /C=US/ST=WA/O=example, Inc./CN=author-www.example.com)

 

Environment

  • BIG-IP version < 16.1.3.1
  • SSL profile in SSL Orchestrator configuration has forward proxy enabled.
  • SSL profile contains expired CA certificates in the ca-bundle.

 

Cause

Bug ID 1070789

 

 Recommended Actions

Remove all invalid trusted (i.e., expired) certificates from the certificate chain and replace them with a valid trusted certificate.

These articles K74439849, K60612439 and K18121454 may be helpful to resolve the issue.
