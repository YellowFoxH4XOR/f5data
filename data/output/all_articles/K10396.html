Known Issue

This is the result of a known issue. The no ip address command does not remove an NTLM authentication server IP address. The IP address remains in the NTLM authentication server configuration.

For example, after you use the no ip address command to attempt to remove the NTLM authentication server IP address, if you use the show ntlm-auth-server <name> command to display the NTLM authentication server configuration, the IP address is still present, as shown in the following example:

arx1(gbl-ntlm-auth-srv[test])#

show ntlm-auth-server test

Name              Domain Name      Server           Port
------------------------------------------------------------------------
test              aaaaa            1.1.1.1          25805

Mapped to the Following Namespaces
------------------------------------------------------------------------

F5 Product Development tracked this issue as ARX ID 35313 and it was fixed in ARX version 5.0.5. For information about upgrading, refer to the ARX release notes.

Additionally, this issue has been fixed in a hotfix available for ARX version 4.1.1. Customers affected by this issue should contact F5 Technical Support, referencing this Solution number and ARX ID 35313.
