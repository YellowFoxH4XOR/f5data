Description

How is the "cpu" value calculated from Telemetry Streaming System Information output?

https://clouddocs.f5.com/products/extensions/f5-telemetry-streaming/latest/output-example.html#system-information
<snippet>
 

 {     "system": {         "hostname": "telemetry.bigip.com",
         "cpu": 0,         "memory": 0,         "swap": 0,         "tmmCpu": 0,         "tmmMemory": 0, }

</snippet>

Environment

Telemetry Streaming declaration configured a System Poller definition.

https://clouddocs.f5.com/products/extensions/f5-telemetry-streaming/latest/telemetry-system.html#system-poller

Cause

ref:
https://clouddocs.f5.com/products/extensions/f5-telemetry-streaming/latest/poller-default-output-reference.html#cpu

cpu
Parent:	system
Endpoint:	/mgmt/tm/sys/host-info
HTTP Method:	GET

e.g. (VE with 2 cpu cores)
<snippet>
# curl -sku <admin:password> https://{bigIP MGMT IP}/mgmt/tm/sys/host-info | jq .
  "entries": {
    "https://localhost/mgmt/tm/sys/host-info/0": {
      "nestedStats": {
        "entries": {
          "activeCpuCount": {
            "value": 2
          },
          "cpuCount": {
            "value": 2
          },
          "https://localhost/mgmt/tm/sys/hostInfo/0/cpuInfo": {
            "nestedStats": {
              "entries": {
                "https://localhost/mgmt/tm/sys/hostInfo/0/cpuInfo/0": {
                  "nestedStats": {
                    "entries": {
                      "oneMinAvgSystem": {
                        "value": 4
                      },
	"https://localhost/mgmt/tm/sys/hostInfo/0/cpuInfo/1": {
			          "oneMinAvgSystem": {
                        "value": 5
                      },
</snippet>

The "cpu" value is calculated as a rounded average of each CPU "oneMinAvgSystem" value. 
i.e. 
Based on the returned oneMinAvgSystem output above: ((4 + 5) / 2) = 4.5 The output is then rounded up to 5.
