K01584609: BIG-IQ or BIG-IP devices may experience TMM Memory leak at xdata and xhead

Type
Support Solution
Published
2021-12-15
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IP
  • BIG-IP LTM: 15.1.0, 15.0.1, 15.0.0, 15.0.X
Source
https://my.f5.com/manage/s/article/K01584609

Description

Memory usage of TMM appears to be leaking on BIG-IP and BIG-IQ systems. 
The output of tmsh show sys memory indicates a large number of allocations in the xdata and xhead subsystems.
Allocated value remains high and does not decrease as  shown in the following example.

# tmsh show sys memory 
SubSystem                        Alloc (bytes)    Max Alloc (bytes)      Object Size    Current Allocations
-------------------------------  ---------------  -------------------  -------------  ---------------------
xdata                            107.2M           107.3M                        2048                  54890
xhead                            1.7M             1.7M                            32                  54890

 

Environment

  • BIG-IP version 15.0 - 15.1.0.2, provisioning vCMP host
  • BIG-IQ version 8.0 - 8.1
  • BIG-IP and BIG-IQ devices have been running for 8 weeks or longer without restarting TMM or rebooting the devices.

Cause

F5 tracks this issue as ID 903905 and fixed at BIG-IP version 16.0.0, 15.1.0.3 and BIG-IQ 8.1.0.1.

Recommended Actions

Upgrading to a fixed version.

Additional Information

Bug ID 903905: BIG-IQ or BIG-IP devices experience a service disruption during certain circumstances
