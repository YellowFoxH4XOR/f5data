Topic

You should consider using this procedure under the following condition:

  • You want to install and prepare a PostgreSQL database before installing NGINX Controller.

Description

You can choose to use an external PostgreSQL database when installing NGINX Controller. The database must be accessible from the NGINX Controller server with a DNS-resolvable name or an IP address, and, for preparing the database for NGINX Controller, you need to create a database user role with the database creation permission. This article describes how to install the database and create the required user on various Linux systems.

Note: For information about NGINX Controller installation and prerequisites, refer to the NGINX Controller Installation Guide.

Important: To ensure the data is securely stored at rest, you should apply encryption to the PostgreSQL database. For more information, refer to the Data Partition Encryption section in PostgreSQL Encryption Options.

Note: This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

Additionally, F5 recommends that you use an encrypted block device or filesystem on the host where NGINX Controller is being installed to protect any local volumes.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the host system on which you want to install the PostgreSQL database.

Procedures

NGINX Controller supports PostgresSQL 9.5. NGINX Controller 3.9.0 adds support for PostgresSQL 12.3. The following procedures provide commands to install either PostgresSQL 9.5 or PostgresSQL 12.

Note: PostgresSQL minor releases are indicated as follows: Beginning with PostgresSQL 10, the minor version is indicated by the number following the first decimal point. For example, 10.0 or 10.1. For older versions, the minor version release is indicated after the second decimal point. For example: 9.5.3 or 9.5.4. Therefore, when you use your operating system's package manager to install PostgresSQL 12, ensure that you install the latest minor release available. For example, PostgresSQL 12.4. For more information, refer to PostgresSQL versioning policy.

Installing PostgreSQL on CentOS 7

For CentOS 7, you can use Yellowdog Updater, Modified (YUM) package-management utility to install PostgreSQL. To do so, perform the following procedure, using the commands appropriate for your version:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the host system command line on which you want to install the PostgreSQL database.
  2. To gain sudo privilege, enter the following command:

    sudo -s

  3. To install the PostgreSQL YUM repository, enter the following command:

    yum install https://download.postgresql.org/pub/repos/yum/reporpms/EL-7-x86_64/pgdg-redhat-repo-latest.noarch.rpm -y

  4. To install the PostgreSQL Client, enter the following command, as appropriate for your version:

    • PostgresSQL 12: yum install postgresql12 -y
    • PostgresSQL 9.5: yum install postgresql95 -y

  5. To install the PostgreSQL Server, enter the following command, as appropriate for your version:

    • PostgresSQL 12: yum install postgresql12-server -y
    • PostgresSQL 9.5: yum install postgresql95-server -y

  6. To initialize the database, enter the following command, as appropriate for your version:

    • PostgresSQL 12: /usr/pgsql-12/bin/postgresql-12-setup initdb
    • PostgresSQL 9.5: /usr/pgsql-9.5/bin/postgresql95-setup initdb

  7. By default, PostgreSQL only listens on localhost. To expose the service to external hosts, enter the following command, as appropriate for your version:

    • PostgresSQL 12:echo "listen_addresses='*'" >> /var/lib/pgsql/12/data/postgresql.conf
    • PostgresSQL 9.5: echo "listen_addresses='*'" >> /var/lib/pgsql/9.5/data/postgresql.conf

  8. To configure the clients that are allowed to connect to the database, use the following command syntax:

    echo "host all all <allowed_client_network> md5" >> /var/lib/pgsql/<version>/data/pg_hba.conf

    For example, to allow a single client IP address 10.10.1.84, enter the following command, as appropriate for your version:

    • PostgresSQL 12: echo "host all all 10.10.1.84/32 md5" >> /var/lib/pgsql/12/data/pg_hba.conf
    • PostgresSQL 9.5: echo "host all all 10.10.1.84/32 md5" >> /var/lib/pgsql/9.5/data/pg_hba.conf

      Note: You can allow all clients to connect by using a wildcard network (0.0.0.0/0), but F5 does not recommend this for a production environment.

  9. To enable PostgreSQL service, enter the following command, as appropriate for your version:

    • PostgresSQL 12: systemctl enable postgresql-12
    • PostgresSQL 9.5: systemctl enable postgresql-9.5

  10. To start PostgreSQL service, enter the following command, as appropriate for your version:

    • PostgresSQL 12: systemctl start postgresql-12
    • PostgresSQL 9.5: systemctl start postgresql-9.5

  11. To exit sudo privilege, enter the following command:

    exit

Installing PostgreSQL on Ubuntu 18.04

For Ubuntu 18.04, you can use Advanced Packaging Tool (APT) package-management utility to install PostgreSQL. To do so, perform the following procedure using the commands, as appropriate for your version:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the host system command line on which you want to install the PostSQL database.
  2. To gain sudo privilege, enter the following command:

    sudo -s

  3. To add PostgreSQL to the APT repository list, enter the following command:

    echo "deb http://apt.postgresql.org/pub/repos/apt/ `lsb_release -cs`-pgdg main" >> /etc/apt/sources.list.d/pgdg.list

  4. To add PostgreSQL key to APT list, enter the following command:

    wget -q https://www.postgresql.org/media/keys/ACCC4CF8.asc -O - | sudo apt-key add -

  5. To update APT, enter the following command:

    apt-get update

  6. To install additional PostgreSQL modules, enter the following command as appropriate for your version:

    • PostgresSQL 12: apt-get install postgresql-contrib-12 -y
    • PostgresSQL 9.5: apt-get install postgresql-contrib-9.5 -y

  7. To install the PostgreSQL Server, enter the following command as appropriate for your version:

    • PostgresSQL 12: apt-get install postgresql-12 -y
    • PostgresSQL 9.5: apt-get install postgresql-9.5 -y

  8. By default, PostgreSQL only listens on localhost. To expose the service to external hosts, enter the following command as appropriate for your version:

    • PostgresSQL 12: echo "listen_addresses='*'" >> /etc/postgresql/12/main/postgresql.conf
    • PostgresSQL 9.5: echo "listen_addresses='*'" >> /etc/postgresql/9.5/main/postgresql.conf

  9. To configure the clients that are allowed to connect to the database, use the following command syntax:

    echo "host all all <allowed_client_network> md5" >> /etc/postgresql/<version>/main/pg_hba.conf

    For example, to allow a single client IP address 10.10.1.84, enter the following command as appropriate for your version:

    • PostgresSQL 12: echo "host all all 10.10.1.84/32 md5" >> /etc/postgresql/12/main/pg_hba.conf
    • PostgresSQL 9.5: echo "host all all 10.10.1.84/32 md5" >> /etc/postgresql/9.5/main/pg_hba.conf

      Note: You can allow all clients to connect with a wildcard network (0.0.0.0/0), but F5 does not recommend doing this in a production environment.

  10. To restart PostgreSQL service, enter the following command:

    service postgresql restart

  11. To exit sudo privilege, enter the following command:

    exit

Preparing PostgreSQL database for NGINX Controller

A PostgreSQL user role with CREATDB permission is required to complete the accessibility for NGINX Controller. To create the database user, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the host system command line on which the PostSQL database is installed.
  2. To gain sudo privilege as a PostgreSQL user, enter the following command:

    sudo -i -u postgres

  3. To launch PostgreSQL client, enter the following command:

    psql

    The PostgreSQL client command prompt may appear similar to the following example:

    postgres=#

  4. To create the service account that the NGINX Controller uses, use the following command syntax:

    CREATE USER naas WITH PASSWORD '<password>';

    For example, to create user naas with password example_password, enter the following command:

    CREATE USER naas WITH PASSWORD 'example_password';

    Note: F5 recommends that you change the password to a more secure and unique combination.

  5. To grant the user permissions to create databases, enter the following command:

    ALTER USER naas CREATEDB;

  6. To exit PostgreSQL client, enter the following command:

    \q

  7. To exit sudo privilege, enter the following command:

    exit
