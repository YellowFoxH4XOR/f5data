Known Issue

IPSec tunnels may drop packets when NAT Traversal is On and no Network Address Translation (NAT) occurs in the network between tunnel endpoint devices.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP system as an IPSec tunnel endpoint.
  • The IKE Peers NAT Traversal option is On. The default setting is Off.
  • There is no NAT occurring in the network between the IPSec tunnel endpoints.

Impact

Data packets will fail to pass through the IPSec tunnel.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Data packets are failing to pass through the IPSec tunnel.
  • When viewing packet captures, the BIG-IP system receives Encapsulating Security Payload (ESP) packets for destination port 500 instead of 4500.

Workaround

There is no workaround for this issue. When setting the IKE Peers NAT Traversal option to On, ensure that NAT is occurring in the network between the IPSec endpoints.
