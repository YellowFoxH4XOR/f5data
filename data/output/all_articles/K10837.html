Known Issue

The FirePass Windows Files feature does not currently support Windows Server 2008 file server clusters. Unlike file shares on Windows 2003 clusters, file shares on Windows 2008 clusters cannot be accessed by IP address. Currently, Windows Files favorites access file shares by IP address, regardless of the Universal Naming Convention (UNC) path entered in the Path field. For example, if you configure the following UNC path in the Path field:

\\fileserver1\public1\

FirePass uses the IP address of fileserver1 when requesting the file share.

For example:

\\172.16.101.1\public1\

Note: For information about why file shares on Windows 2008 clusters cannot be accessed by IP address, refer to the following article. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

http://blogs.technet.com/askcore/archive/2009/01/09/file-share-scoping-in-windows-server-2008-failover-clusters.aspx.

F5 Product Development is tracking an enhancement request as ID 237928 (formerly CR106631) to add support for Windows Server 2008 clusters. If you require this functionality in the immediate future, contact your local F5 Sales Representative.
