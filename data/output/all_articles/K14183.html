This article applies to BIG-IP DNS 11.x - 21.x. For information about other versions, refer to the following article:

  • K12456: Configuring the BIG-IP GTM system to advertise the Listener address by way of BGP (9.x - 10.x)

You should consider using this procedure under the following condition:

  • You want to configure the BIG-IP DNS system to advertise the Listener address by way of Border Gateway Protocol (BGP).

Description

There may be occasions when you want to configure the BIG-IP DNS system to advertise the Listener address by way of BGP. For example, if you plan to implement anycast DNS and use BGP to distribute Local Domain Name System (LDNS) requests to the closest BIG-IP DNS system among a mesh of BIG-IP DNS systems sharing a Listener address, you must advertise the BIG-IP DNS Listener addresses by way of BGP.

To configure the BIG-IP DNS system to advertise the Listener address by way of BGP, perform the following procedures:

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You licensed your BIG-IP system for the Advanced Routing Module (ARM), including BGP.
  • You configured your BIG-IP system as a BGP peer with the upstream routers.

Procedures

Selecting an IP address to use as the Listener

The BIG-IP DNS system uses the Listener address to listen for DNS queries and identify the resolution requests for which it is responsible. Before you configure the system to advertise the Listener address by way of BGP, you should be aware of the following IP address restrictions:

  • For a redundant BIG-IP DNS system, select the floating self IP address to be the Listener address.
  • For a standalone BIG-IP DNS system, do not select a self IP address to be the Listener address.

Configuring the BIG-IP DNS Listener address (11.5.0 and later)

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to DNS > Delivery > Listeners.
  3. Select Create.
  4. In the Name box, enter a name for the Listener.
  5. In the Listener list, select Advanced.
  6. Under Listener, in the Destination section, in the Address box, do one of the following:
    • For a redundant BIG-IP GTM system, enter the floating self IP address.
    • For a standalone BIG-IP GTM system, enter an IP address that does not match a self IP address.
  7. Select the Route Advertisement check box.
  8. Under Service, in the Protocol list, select either UDP or TCP.
  9. Select Finished.

Configuring the BIG-IP DNS Listener address (11.0.0 - 11.4.1)

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Global Traffic > Listeners.
  3. Select Create.
  4. Do one of the following:
    • For a redundant BIG-IP DNS system, enter the floating self IP address.
    • For a standalone BIG-IP DNS system, enter an IP address that does not match a self IP address.
  5. In the Protocol list, select either UDP or TCP.
  6. Select the Route Advertisement check box.
  7. Select Finished.

Configuring BGP to redistribute kernel routes

Impact of procedure: Performing the following procedure should not have a negative impact on your system, but it may affect routes on upstream devices.

  1. Log in to the BIG-IP command line.
  2. To access the IMI Shell (imish), enter the following command.

    imish

  3. To enter Enable mode, enter the following command:

    enable

  4. To enter Configuration mode, enter the following command:

    configure terminal

  5. To enable the BGP routing process, use the following command syntax, where <ID> is the router ID:

    router bgp <ID>

  6. Configure BGP to redistribute kernel routes by entering the following command:

    redistribute kernel

  7. Exit the current mode by entering the following command:

    end

  8. Save the configuration by entering the following command:

    copy running-config startup-config

  9. Log out of the imish utility by entering the following command:

    exit

Verifying that the BIG-IP system is advertising the route by way of BGP

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To access the imish utility, enter the following command:

    imish

  3. To enter Enable mode, enter the following command:

    enable

  4. To display BGP routes that the system is advertising or learning, enter the following command:

    show ip bgp
