Known Issue

The Google Web Toolkit (GWT) parser may block legal requests.

This issue occurs when the following conditions are met:

  • A GWT content profile is associated with the security policy.
  • The GWT request contains non-digit characters at the end of the request payload.

GWT is a Java framework that is used to create AJAX applications. When you add GWT enforcement to a security policy, the BIG-IP ASM system can detect and block malformed GWT data, and request payloads and parameter values that exceed length limits.

Impact

The BIG-IP ASM system incorrectly blocks legal requests.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM system blocks legal requests with non-digit characters at the end of the request payload.
