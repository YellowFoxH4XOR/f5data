Known Issue

The BIG-IP GTM Synchronization option may stay in the disabled state after being re-enabled.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP GTM system is configured as part of a synchronization group.
  • You manually change the Synchronization option from the enabled state to the disabled state.
  • You then manually set the Synchronization option back to the enabled state 7-13 seconds after being placed in the disabled state.

Impact

The attempt to set the Synchronization option back to an enabled state fails.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP GTM configuration changes are not synchronized with other peer devices in the synchronization group.
  • All BIG-IP GTM devices in the synchronization group are automatically set with the Synchronization option to disabled.

Workaround

To work around this issue, you can wait at least 15 seconds after the device is set to the disabled state before manually re-enabling synchronization.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
