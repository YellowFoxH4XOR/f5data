Description

Newly replaced blade results in the neurond daemon restarting continuously.

Environment

  • VIPRION platform running with C4800 blade

Cause

Unknown
 

Recommended Actions

Remove and reinstall neurond into bigstart:
  1. Remove neurond from bigstart
    bigstart remove neurond
  2. Reset neurond configuration to defaults:
    bigstart add --default neurond
  3. Add neurond back to bigstart:
    bigstart add neurond    
    If the issue persists, pull the blade out and reinsert and make sure the blade is properly seated.
