Description

Configuring BIG-IQ Automatic failover results in the following error message when establishing communication with Quorum DCD:

An error occurred while adding the BIG-IQ: Error: Unable to communicate with ha-quorum Error: ha-primary: Username and/or password is incorrect
 

Environment

  • BIG-IQ
  • Configuring Automatic failover

Cause

Unknown issue on BIG-IQ DCD node

Recommended Actions

Remove the HA configuration on all BIG-IQ CM/DCD nodes using the below command and configure Auto Failover again:
ha_reset -f <local discovery IP>
 

Additional Information

If the Recommend Action does not resolve the issue, restore the factory default settings and reconfigure the Quorum DCD.

K15886: Restore the BIG-IQ system to factory default settings
