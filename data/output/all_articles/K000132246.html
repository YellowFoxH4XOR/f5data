Description

You can use the snmptranslate command to translate MIB OID into the SNMP object name.

Environment

  • BIG-IP LTM
  • SNMP

Cause

You have the SNMP OID and your SNMP system requires the SNMP object name to poll the request monitoring info

Recommended Actions

Note: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. To find an SNMP object name when the OID is known, use the following command syntax:

snmptranslate -Oa <OID>

For example:

snmptranslate -Oa .1.3.6.1.4.1.3375.2.1.1.2.21.28.0

F5-BIGIP-SYSTEM-MIB::sysGlobalTmmStatMemoryTotal.0

Additional Information

Adding the -Td flag will output detailed information including the description.

snmptranslate -Oa .1.3.6.1.4.1.3375.2.1.1.2.21.28.0 -Td
