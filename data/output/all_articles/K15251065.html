Known Issue

The Traffic Management Microkernel (TMM) may produce a core file and restart in certain module pairings.

This issue occurs when all of the following conditions are met:

  • Your system is licensed and provisioned with the BIG-IP APM and Analytics (AVR) modules.
  • A virtual server is configured with a BIG-IP APM access profile and an associated Analytics profile.
  • Traffic is processed by the virtual server.

Impact

Traffic interruptions may occur intermittently, due to the tmm process producing a core file and restarting.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates TMM core files in the /var/core directory, and the time stamp of the files correlates to the time of the traffic interruption.
  • When you remove the virtual servers that are associated with Analytics profiles, traffic processing becomes stable.

Workaround

To work around this issue, you can remove the Analytics profile from the configuration of the affected BIG-IP APM virtual server. To do so, perform the following procedure:

Impact of workaround: Analytics data will no longer be gathered for traffic processed by the virtual server.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Select the affected virtual server.
  4. From the Configuration menu, select Advanced.
  5. Ensure that the HTTP Analytics Profile and TCP Analytics Profile sections are set to None.
  6. Click Update.
