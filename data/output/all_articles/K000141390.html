K000141390: Expired or Incorrect BIG-IP device certificate shows in BIG-IQ DNS Sync Groups

Type
Support Solution
Published
2024-10-08
Updated
2025-02-07
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management
Source
https://my.f5.com/manage/s/article/K000141390

Description

When navigating the BIG-IQ: Devices > BIG-IP CLUSTERS > DNS Sync Groups, a sync group may show "Certificate Expired" for a member BIG-IP DNS device even though it is actually using a valid device certificate.


Environment

  • BIG-IQ
  • BIG-IP DNS

Cause


BIG-IQ uses iControl SOAP Management::KeyCertificate::get_certificate_list() with ManagementModeType set to MANAGEMENT_MODE_WEBSERVER to pull the device certificate from the BIG-IP DNS which it uses to show on the BIG-IQ UI's DNS Sync Group page. If there are multiple certificates stored in the BIG-IP DNS' /config/httpd/conf/ssl.crt/ folder, the SOAP call returns all of those certificates. Due to ID1692021, BIG-IQ picks an incorrect certificate from the list.

Recommended Actions


Remove unnecessary certificates from the BIG-IP DNS' /config/httpd/conf/ssl.crt/ folder except for the server.crt file. Thereafter, refresh the DNS Sync Group from the BIG-IQ UI so it requests the BIG-IP DNS for its device cert.

Additional Information

None.
