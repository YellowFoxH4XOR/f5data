Known Issue

The Traffic Management Microkernel (TMM) process may produce a core file and restart when the Policy and Charging Rules Function (PCRF) installs duplicate BIG-IP PEM policies.

This issue occurs when all of the following conditions are met:

  • You enable the BIG-IP PEM system with the Gx and Gy configuration.
  • You configure Gy quota management for PEM policies.
  • The PCRF system installs an already installed policy against a subscriber.

Impact

Traffic is disrupted while the TMM process produces a core file and restarts. The affected BIG-IP system, configured as part of a high availability (HA) device group, may fail over to a peer device.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The TMM process generates a core file to the /shared/core directory.
  • The affected BIG-IP system unexpectedly fails over to another system when configured as part of an HA device group.

    Workaround

    There is no work around for this issue. However, you can avoid this issue by configuring the PCRF system so that it does not install an already installed policy against a subscriber.
