Description
The BIG-IP system may automatically append extra CR/LF characters to the end of an HTTP monitor traffic when there are insufficient CR/LF. 

  • BIG-IP system automatically translates each LF character to CR/LF at the end of the Send String. 
           For example:
           "GET / HTTP/1.1\nHost: host.domain.com\nConnection: Close\n\n" --> "GET / HTTP/1.1\nHost: host.domain.com\nConnection: Close\r\n\r\n"
  • BIG-IP system automatically appends CR/LF to the end of the Send String. 
           For example:
           "GET / HTTP/1.1\nHost: host.domain.com\nConnection: Close\r\n" --> "GET / HTTP/1.1\nHost: host.domain.com\nConnection: Close\r\n\r\n"
  • BIG-IP system automatically appends CR/LF/CR/LF to the end of the Send String. 
           For example:
           "GET / HTTP/1.1\nHost: host.domain.com\nConnection: Close" --> "GET / HTTP/1.1\nHost: host.domain.com\nConnection: Close\r\n\r\n"

Environment

  • BIG-IP system
  • Custom HTTP monitor
