Description

you would like to generate a report or have a summary on list of certificates that are expired or expiring on BIG-IP system.

Additionally you may also like to know to which ssl profiles these certificates are associated with and then to which virtual servers these ssl profiles are assigned.

Environment

  • BIG-IP LTM
  • SSL certificates

Cause

  • Informational

Recommended Actions

To view the summary on SSL certificates that are expired or about to expire you need to generate a qkview file and upload to ihealth.

To view the summary on SSL certificates that are expired or about to expire perform following steps :

  1. Generate qkview file from BIG-IP system you would like to see the summary
  2. Upload to ihealth
  3. Once qkview is uploaded successfully, navigate to diagnostic tab in left side menu
  4. In the provided list you will find a Heuristic with title- SSL certificates are expired, about to expire, or are not yet valid
