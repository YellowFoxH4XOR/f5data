Description

You are using template f5-azure-arm-templates-v2 for Azure deployment and encounter the following error after running the Powershell Script:

New-AzureRmVM : Long running operation failed with status 'Failed'.
Additional Info:'OS Provisioning for VM '<device_name>' did not finish in the allotted time. The VM may still finish provisioning successfully. Please check provisioning state later. For details on how to check current provisioning state of Windows VMs, refer to https://aka.ms/WindowsVMLifecycle and Linux VMs, refer to https://aka.ms/LinuxVMLifecycle.'
ErrorCode: OSProvisioningTimedOut

Environment

  • Deploying BIG-IP VE in Azure

Cause

Values you used for the bigIpPasswordSecretId parameter and BIGIP_PASSWORD in runtime init config are missing.

Recommended Actions

You must create the key vault and secret prior to deploying.

Additional Information

Azure ARM Deployment fails on BigIPTemplate #11
