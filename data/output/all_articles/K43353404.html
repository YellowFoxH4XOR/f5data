Known Issue

Under certain conditions, the qkview utility may stall or produce a core file.

This issue occurs when one of the following conditions is met:

  • You create or modify many configuration objects while the qkview utility is running. For example, you use a script to make several thousand configuration changes all together.
  • A filestore mapping is corrupt. For example, there are filestore files listed in the configuration that are missing from the file system.

Impact

Users cannot generate a qkview snapshot.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates a qkview core file to the /shared/core directory.
  • qkview processing fails to complete.
  • In the /var/log/ltm file, you observe an error message similar to the following example:

    err mcpd[4596]: 0107134e:3: Failed while making snapshot: (Failed to link files existing(/config/ssl/ssl.crt/ca-bundle.crt) ew(/config/.snapshots_d/certificate_d/1389867940_:Common:ca-bundle.crt_1) errno(2)(No such file or directory).) errno(2) errstr(No such file or directory).

Workaround

There is no workaround for this issue. However, you can postpone any large configuration changes until after the qkview process has completed.
