K000139996: Users unable to connect to VPN using mobile hotspot

Type
Support Solution
Published
2024-06-12
Updated
2024-07-16
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.X, 16.1.X, 15.1.X, 17.1.1, 17.1.0, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 15.1.10, 15.1.9, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0

Source
https://my.f5.com/manage/s/article/K000139996

Description

Mobile users are no longer able to connect to the BIG-IP SSL VPN after upgrading to an APM Client that introduces the fix for Tunnel Crack vulnerability.

 

You may see a message similar to:

"The VPN connection has failed because it attempted to connect to an insecure network. Please switch to a secure network."

 

Environment

BIG-IP APM 15.1.10.3, 15.1.10.4, 16.1.4.2, 16.1.4.3, 17.1.1.1, 17.1.1.2, or 17.1.1.3 with APM client 7.2.4.6 BIG-IP Edge Client 7246

SSL VPN

Mobile Hotspot

Cause

ID 1586657, IPv6 address is being assigned when connecting to a mobile hotspot instead of a regular IPv4.

Recommended Actions

To workaround this issue, you can request EHF apmclients-7247.2024.529.1126-6423.0 by opening a support case. As a temporary workaround, disable IPv6 on the impacted users WiFi adapter.
