Description

There is an article that explains how to integrate the BIG-IP with Azure Sentinel from DevCentral. While creating the LTM Request Log Profile via CLI/TMSH like next example, an error message appears similar to this:

"Syntax Error: "client_ip="$CLIENT_IP",server_ip="$SERVER_IP"," unknown property"

For example:

create ltm profile request-log telemetry request-log-pool telemetry-local request-log-protocol mds-tcp request-log-template event_source=\"request_logging\",hostname=\"$BIGIP_HOSTNAME\", client_ip=\"$CLIENT_IP\",server_ip=\"$SERVER_IP\", http_method=\"$HTTP_METHOD\", http_uri=\"$HTTP_URI\", virtual_name=\"$VIRTUAL_NAME\",event_timestamp=\"$DATE_HTTP\" request-logging enabled

Environment

  • BIG-IP LTM
  • LTM Profiles
  • TMSH
  • Telemetry

Cause

There are some extra spaces between the parameters in the command and the BIG-IP does not recognize them.

Recommended Actions

To fix this issue, please validate that there are no extra spaces in the command, for example:

create ltm profile request-log telemetry request-log-pool telemetry-local request-log-protocol mds-tcp request-log-template event_source=\"request_logging\",hostname=\"$BIGIP_HOSTNAME\",client_ip=\"$CLIENT_IP\",server_ip=\"$SERVER_IP\",http_method=\"$HTTP_METHOD\",http_uri=\"$HTTP_URI\",virtual_name=\"$VIRTUAL_NAME\",event_timestamp=\"$DATE_HTTP\" request-logging enabled

Additional Information

This syntax error can also happen if you use "{ }" on the command, for example http_host=\"${host}\ should be http_host=\"$host\.
