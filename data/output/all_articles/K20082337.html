Description

BIG-IP GTM/DNS iquery are not properly communicating with each other.

GSLB sync will not be working during this issue.

This article explains how to know when GSLB sync is not working.

Environment
  • BIG-IP GTM/DNS
  • GLSB sync not working
  • iquery between BIG-IP GTM/DNS is not connected

Cause

None.

Recommended Actions

You will need to run the following command and check the Configuration Time.
tmsh show /gtm iquery

Configuration Time is the last time the GSLB configuration has been synced.
