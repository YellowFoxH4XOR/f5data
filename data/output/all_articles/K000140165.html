K000140165: Status of the pool member is reported as unknown (enabled) with a reason of 'Pool member service checking is enabled, but result is not available yet'

Type
Support Solution
Published
2024-06-27
Updated
2024-06-27
Source
https://my.f5.com/manage/s/article/K000140165

Description

The system incorrectly reports the service checking status for pool members. As a result of this issue, you may encounter the following symptoms:

  • The availability status of a pool is reported as unknown (enabled) with a reason of The children pool members either do not have service checking enabled, or service check results are not available yet.
  • The availability status of pool members is reported as unknown (enabled) with a reason of Pool member service checking is enabled, but result is not available yet

Example: tmsh show ltm pool test_pool members all-properties

---------------------------------------------------------------------
Ltm::Pool: test_pool
---------------------------------------------------------------------
Status
Availability : unknown
State : enabled
Reason : The children pool member(s) either don't have service checking enabled, or service check results are not available yet
Monitor :
Minimum Active Members : 0
Current Active Members : 0

--------------------------------------------------------------
| Ltm::Pool Member: test_member
--------------------------------------------------------------
| Status
| Availability : unknown
| State : enabled
| Reason : Pool member service checking is enabled, but result is not available yet
| Monitor Status : checking
| Session Status : enabled
| Pool Name : test_pool
| IP Address : 10.10.10.10

 

Environment

Pool members are down

Unknown.
