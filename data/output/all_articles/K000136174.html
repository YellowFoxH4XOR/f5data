Description

When creating a BIG-IP DNS pool, the list of virtual servers are no longer appearing in the drop-down menu.

Environment

BIG-IP DNS

Cause

One of the GSLB server name or a virtual server name might erroneously contain a blank space / white space / tab character . For example, notice "bad_vs_name " below contains a white space at the end its name:

gtm server /Common/generic_host_server_or_LTM
  datacenter /Common/DC1
  devices {
    /Common/generic_host_A {
      addresses {
        100.100.100.100 { }
      }
    }
  }
  monitor /Common/http
  product generic-host
  virtual-servers {
    "bad_vs_name " {
      destination 100.100.100.200:80
    }
    good_vs_name {
      destination 100.100.100.210:80
    }
  }
}

 

Recommended Actions

Remove the "bad_vs_name " virtual server from GSLB Server /Common/generic_host_server_or_LTM.

Re-add the virtual server without the whitespace at the end of the name. For example: "my_virtualserver"

If the GSLB server name contains a white space, Manually edit /config/bigip_gtm.conf, and remove the white space, and reload the config with command line: tmsh load sys config gtm-only.
