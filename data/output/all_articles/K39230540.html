Issue

Error Message

01071a12:3: ClientSSL (/Common/clientssl) cannot get its defaults from (), as it doesn't exist.
Unexpected Error: Loading configuration process failed.

Message Location

You may encounter this message in the following locations:

  • When you attempt to perform a configuration synchronization (ConfigSync) between peers using the Configuration utility, TMOS Shell (tmsh), or Advanced Shell (bash) command line.
  • When you run the tmsh load sys config command from tmsh or the bash command line.
  • When you run the tmsh load sys config verify command from tmsh or the bash command line.
Description

This message occurs when the following conditions are met:

  • The /config/bigip.conf configuration file contains a Client SSL profile named /Common/clientssl.
  • The /Common/clientssl profile in the /conifig/bigip.conf file has either the inherit-ca-certkeychain or inherit-certkeychain setting configured with a value of true.
  • You upgrade to BIG-IP 14.0.0 or later.

The /Common/clientssl profile is actually a default profile and not in the /bigip/conf file by default. If you modify the /Common/clientssl profile with a non-default value (such as a previously described), the system writes an entry to the /config/bigip.conf file. If the entry is written with the inherit-ca-certkeychain or inherit-certkeychain settings configured with a value of true, the configuration is invalid because the /Common/clientssl profile is not a child profile and does not have a parent profile, and therefore has nothing from which to inherit. BIG-IP 14.x configuration validation fails and does not load the configuration.

Impact

The invalid configuration fails to load during ConfigSync or when you attempt to verify or load the configuration.

Recommended Actions

To prevent the /Common/clientssl profile from being written to the /config/bigip.conf file, you should avoid modifying a default profile. F5 recommends that you instead create a custom profile using the default profile as the parent profile. You can then modify some or all of the values defined in the custom profile while leaving the parent profile settings at their default value. For information, refer to K14488: Working with profiles.

To recover from this issue, perform one of the following procedures:

  • Removing the /Common/clientssl profile entry from the /config/bigip.conf file

    Note: This is the recommended procedure if the system's default values for the /Common/clientssl profile are sufficient.

  • Modifying the /Common/clientssl profile entry in the /config/bigip.conf file

    • Note: Use this procedure if you have customized the /Common/clientssl profile and do not want to use the system default values.

Removing the /Common/clientssl profile entry from the /config/bigip.conf file

To remove the /Common/clientssl profile entry from the /config/bigip.conf file and allow the system to use the default values for the /Common/clientssl profile, perform the following procedure:

Impact of procedure: Edit errors in the /config/bigip.conf configuration file may prevent it from loading. F5 recommends using caution when editing the file and testing any changes during a maintenance window with consideration to the possible impact on your specific environment.

  1. Log in to the BIG-IP command line.
  2. Back up the existing /config/bigip.conf file by typing the following command:

    cp /config/bigip.conf /config/bigip.conf.k39230540

  3. Open the /config/bigip.conf file using either the vi or pico text editor.
  4. Locate and remove the entire configuration stanza for the /Common/clientssl object.

    For example:

    ltm profile client-ssl clientssl {
        alert-timeout indefinite
        allow-dynamic-record-sizing disabled
        app-service none
        authenticate once
        authenticate-depth 9
        ca-file none
        cache-size 262144
        cache-timeout 3600
        cert default.crt
        cert-extension-includes { basic-constraints subject-alternative-name }
        cert-key-chain {
            default {
                cert default.crt
                key default.key
            }
        }
        chain none
        cipher-group none
        ciphers DEFAULT
        client-cert-ca none
        crl-file none
        handshake-timeout 10
        inherit-ca-certkeychain true
        inherit-certkeychain true
        key default.key
        maximum-record-size 16384
        mod-ssl-methods disabled
        mode enabled
        options { dont-insert-empty-fragments no-tlsv1.3 }
        passphrase none
        peer-cert-mode ignore
        peer-no-renegotiate-timeout 10
        renegotiate-max-record-delay indefinite
        renegotiate-period indefinite
        renegotiate-size indefinite
        renegotiation enabled
        secure-renegotiation require
        strict-resume disabled
        unclean-shutdown enabled
    }

  5. Save the changes and exit the text editor.
  6. Reload the configuration by typing the following command:

    tmsh load /sys config

Modifying the /Common/clientssl profile entry in the /config/bigip.conf file

To modify the /Common/clientssl profile entry in the /config/bigip.conf file to change the inherits-ca-certkeychain value to false, perform the following procedure:

Impact of procedure: Edit errors in the /config/bigip.conf configuration file may prevent it from loading. F5 recommends using caution when editing the file and testing any changes during a maintenance window with consideration to the possible impact on your specific environment.

  1. Log in to the BIG-IP command line.
  2. Back up the existing /config/bigip.conf file by typing the following command:

    cp /config/bigip.conf /config/bigip.conf.k39230540

  3. Open the /config/bigip.conf file using either the vi or pico text editor.
  4. Locate configuration stanza for the /Common/clientssl object.

    For example:

    ltm profile client-ssl /Common/clientssl {
       ...

  5. Within the /Common/clientssl configuration stanza,  edit the inherit-ca-certkeychain and/or inherit-certkeychain entries and change the value to be false.

    For example,

    locate:
        inherit-ca-certkeychain true
        inherit-certkeychain true
    change to be:
        inherit-ca-certkeychain false
        inherit-certkeychain false

  6. Save the changes and exit the text editor.
  7. Reload the configuration by typing the following command:

    tmsh load /sys config

  8. For members of a sync group, you need to repeat the procedure on each member of the sync group or synchronize the configuration using the Manual with Full Sync sync type.
