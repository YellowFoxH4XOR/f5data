K000138266: AS3 'updateMode' behavior with 'complete' option in use.

Type
Support Solution
Published
2024-03-26
Updated
2024-03-26
Applies to

  • F5 Application Services 3 Extension
Source

Description

What happens when a declaration with 'updateMode' set to 'complete' is referencing a specific tenant on a multitenant system.

Environment

Configuration is deployed to a multitenant system using AS3.

Cause

When 'updateMode' is set to 'complete' in all cases the configuration is wiped out and then recreated for a specific tenant.

Recommended Actions

None.
