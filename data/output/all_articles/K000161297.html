K000161297: APM client not working

Type
Support Solution
Published
2026-05-15
Updated
2026-05-15
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000161297

Description

After installing the F5 Access client (F5Access-7262.pkg) and required helper packages (mac_f5epi.pkg, mac_f5vpn.pkg) on macOS, the F5 Access application opens and displays saved configuration but does not initiate a connection attempt or generate any log entries when a user tries to connect. No error messages are displayed. Browser-based VPN tunnel establishment works correctly on the same endpoints using the same BIG-IP APM instance, confirming the issue is isolated to the F5 Access client application.

Observed symptoms:

  • F5 Access client launches and displays saved configuration
  • Clicking connect produces no activity — no connection attempt, no error, no log entries
  • No log files generated under /Library/Application Support/F5Access/logs/ or /Users/<username>/Library/Logs/F5Access/
  • Browser-based tunnel connection succeeds on the same affected endpoints
  • Issue is consistent across multiple Macs with identical configuration

Environment

  • Product: BIG-IP APM
  • BIG-IP Version: 17.5.1
  • APM Clients ISO: apmclients-7253.2025.729.424-6868.0.iso
  • F5 Access Client Version: F5Access-7262.pkg
  • Helper Packages Installed:
    • mac_f5epi.pkg (Endpoint Inspection Helper)
    • mac_f5vpn.pkg (VPN Helper)
  • Installation Method: Manual — all existing F5 software uninstalled prior to fresh installation
  • Affected Endpoints: Multiple MacBooks with identical configuration
  • APM Connection: Browser-based tunnel confirmed working on all affected endpoints

Cause

Unknown at time of publication.

Possible contributing factors under investigation:

  • macOS System Extension approval not completed after installation
  • macOS VPN profile not accepted in System Settings > Privacy & Security > VPN & Network Extensions
  • macOS version incompatibility with F5 Access 7262
  • Corrupted installation or missing permissions preventing the client from invoking the VPN helper

Answer/Recommended Actions

  1. Step 1 — Verify macOS Version Compatibility
    1. Confirm the macOS version on all affected endpoints.
    2. Cross-reference against the BIG-IP APM Client Compatibility Matrix (see Related Content) to confirm F5 Access 7262 is supported on the installed macOS version.
  2. Step 2 — Approve System Extension and VPN Profile
    1. Open System Settings > Privacy & Security.
    2. Scroll to VPN & Network Extensions (macOS 13+) or Security (macOS 12 and earlier).
    3. Confirm any F5-related system extension or VPN profile is approved.
    4. If no prompt was received during installation, uninstall and reinstall F5Access-7262.pkg and watch for system extension approval prompts.
  3. Step 3 — Verify Installation Order
  4. Ensure packages are installed in the following order:
    1. mac_f5epi.pkg
    2. mac_f5vpn.pkg
    3. F5Access-7262.pkg
  5. Step 4 — Check for Conflicting Network Extensions
    1. Remove or disable any other VPN clients or network extension software that may conflict with F5 Access.
    2. Reboot the Mac after removal before retesting.
  6. Step 5 — Collect Logs for Analysis
    1. After a failed connection attempt, check the following locations for log files:
    2. /Library/Application Support/F5Access/logs/
    3. /Users/<username>/Library/Logs/F5Access/
    4. If no logs are present, this confirms the client is being blocked at the OS level before any connection logic executes.
  7. Step 6 — Reinstall with Full Cleanup
  8. If the above steps do not resolve the issue:
    1. Uninstall all F5 software.
    2. Manually remove any residual F5 files from /Library/Application Support/, /Library/Extensions/, and /Users/<username>/Library/.
    3. Reboot.
    4. Reinstall packages in the order listed in Step 3.
    5. Accept all system extension and VPN profile prompts.
    6. Retest connection via F5 Access client.

Additional Information

  • Browser-based VPN tunnel establishment (mac_f5epi.pkg + mac_f5vpn.pkg) functioning correctly confirms that the APM server configuration, network connectivity, and authentication are not the source of the issue. The problem is isolated to the F5 Access client application layer on the affected endpoints.
  • The mac_f5epi.pkg and mac_f5vpn.pkg packages are helper components invoked by the browser or F5 Access client during APM session setup. They do not provide a standalone GUI or direct launch capability and cannot be used independently to initiate a VPN session outside of a browser or the F5 Access client.
  • The F5 Access client (F5Access-7262.pkg) is required for non-browser-based VPN tunnel management, including the ability to save multiple connection profiles and launch tunnels directly from the client UI.
  • On macOS 13 (Ventura) and later, stricter privacy controls require explicit user approval of system extensions and VPN profiles. If these approvals are not granted, the F5 Access client may silently fail to initiate any connection without displaying an error.
