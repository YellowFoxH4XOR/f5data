Issue

Error Message

warning chmand[<pid>]: 012a0004:4: Unsupported power supply model: SP0811XXXXXXZ01A
warning chmand[<pid>]: 012a0004:4: Voltage on PSU0(4294917V) is out of range.

In this error message, note the following:

  • <pid> is the process ID of the chmand process

For example:

warning chmand[6343]: 012a0004:4: Unsupported power supply model: SP0811XXXXXXZ01A
warning chmand[6343]: 012a0004:4: Voltage on PSU0(4294917V) is out of range.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You are running the C2200 VIPRION chassis.
  • Your VIPRION chassis uses a DC power supply.
  • You are running BIG-IP 11.x.

Impact

None. This message may be safely ignored.

Recommended Actions

If you encounter this error message in a version later than 11.x, use the following troubleshooting steps:

  • Ensure you properly inserted the affected power supply unit (PSU) into the PSU slot. You can request to reseat or reinsert the PSU to ensure it is in proper contact to the chassis.
  • Contact F5 Support to troubleshoot the PSU error message further.
