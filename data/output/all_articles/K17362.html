Known Issue

Description

The changes you made to the BIG-IP APM local user database after a UCS archive restore may be lost.

This issue occurs when all of the following conditions are met -- in the following order:

  • You perform a BIG-IP system restoration from a UCS file.
  • You make changes (such as adding or removing users) to the BIG-IP APM local user database.
  • You perform a system reboot, or the localdbmgr daemon is restarted.

For more information about the backup and restoration of the BIG-IP APM local user database, refer to K59100837: Backing up and restoring the BIG-IP APM local user database

Impact

Changes that you made to the BIG-IP APM local user database are lost.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG APM local user database on the BIG-IP APM system remains intact following a UCS archive restoration.
  • Additions, deletions, or updates of local user database records are lost following a system reboot or localdbmgr daemon restart.
