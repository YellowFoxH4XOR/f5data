Topic

F5 has recently discovered and corrected a number of critical issues that affect customers running BIG-IP 9.3.1. F5 recommends that all customers currently running 9.3.1 install Hotfix-BIG-IP-9.3.1-HF1, or a later version of the cumulative hotfix rollup, as soon as possible.

The following CRs are fixed in Hotfix-BIG-IP-9.3.1-HF1 for BIG-IP 9.3.1:

CRArticleDescription
CR65654K8287The switchboot utility does not report the new build number after a hotfix rollup is installed
CR75559K8288Change in Behavior: TCP persistence timeout variable is now configurable
CR76055K8290Change in Behavior: TM.LHPNoMemberAction variable allows control over routing behavior when last hop pools are used
CR82508K8291STP BPDU packets received on a 10Gb port are not forwarded when in STP passthrough mode
CR87184K8058The BIG-IP system marks an unsupported internal interface on 1500 platforms as up
CR87365K8296Virtual server discovery does not correctly handle duplicate names for 500 or more virtual servers
CR87866K8297Eventd no longer consumes excessive CPU time while events are in its queue.
CR88060K8298The BIG-IP GTM 9.x big3d daemon installed on a BIG-IP 4.x system is turned off during a configsync
CR88139K8166A memory leak can result when certain HTTP and CACHE iRule commands are used together
CR88223K8282Failed SSL connections using compat ciphers can effect other SSL connections
CR88260K8299Intermittent OSPF MD5 authentication fails due to small packet length
CR88337K8300Using network failover and serial cable failover with an active-active configuration may result in address conflicts
CR89149K8285A RST packet is sent with an incorrect ACK value when a TCP SYN packet is received for a service that does not exist
CR89559K8301Native SSL connections can fail when receiving an SSL record consisting of exactly 32 fragments
CR89582K8302A lost connection between big3d daemons results in a memory leak

The hotfix is available for download at the F5 Downloads site. For information about downloading software from F5, refer to K167: Downloading software from F5.

For information about installing a hotfix, refer to K6845: Managing F5 product hotfixes.
