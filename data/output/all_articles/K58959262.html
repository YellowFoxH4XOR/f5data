K58959262: SPDY, IIOP, and MSSQL profile types are not available in BIG-IP 13.x

Type
Knowledge
Published
2017-03-21
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.1.X, 13.0.X, 13.1.5, 13.1.4, 13.1.3, 13.X.X, 13.1.0, 13.0.1, 13.0.0, 13.1.1
Source
https://my.f5.com/manage/s/article/K58959262

Issue

Old Behavior

In versions prior to BIG-IP 13.0.0, you can configure the SPDY, IIOP, and MSSQL profiles types.

New Behavior

Beginning in BIG-IP 13.0.0, the SPDY, IIOP, and MSSQL profile types are no longer available for configuration.

Impact

In BIG-IP 13.0.0, configurations with profiles using the SPDY, IIOP, or MSSQL profile types will not load.

Important: If you upgrade and attempt to roll a configuration forward, or attempt to install a user configuration set (UCS) file containing SPDY, IIOP, or MSSQL profiles, the configuration fails to load in BIG-IP 13.0.0.

Recommended Actions

  • Before you upgrade to BIG-IP 13.0.0, ensure your configuration is not using SPDY, IIOP, and MSSQL profiles.
  • UCS files that contain a configuration using SPDY, IIOP, or MSSQL profiles should not be installed in BIG-IP 13.0.0.
