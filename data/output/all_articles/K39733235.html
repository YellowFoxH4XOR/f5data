Description
The configuration fails to load due to a white space inserted in object path after the partition name such as '/<partition name>/         <name of profile>' in BIG-IP configuration file.

The system displays an error messages similar to the following example:
01070734:3: Configuration error: Invalid create, modify, or delete for fw_log_profile objects in the root folder. Unexpected Error: Validating configuration process failed. 
 

Environment

  • After boot or upgrade
  • Logging profile that includes a leading TAB character

Cause

  • Suspected variation of ID627454 
  • Cutting and pasting a text into a logging profile name field, including the TAB character

Recommended Actions

Impact of workaround: F5 recommends that you perform the following workaround during a maintenance window.
  1. Log in to the command line of the affected BIG-IP system.
  2. To create a backup copy of the /config/bigip.conf file, type the following command:
    cp /config/bigip.conf /config/bigip.conf.K39733235
  3. Use a text editor to open the /config/bigip.conf file.
  4. Locate the affected security log profile and remove the heading space/tab character of the log profile name:  
    From: 
    security log profile /Common/   example_log_profile_name {   ------->>>>> !!!!!
        application {
            /Common/        example_log_profile_name {           ------->>>>> !!!!!
                filter {
                    login-result {
                        values { login-result-failed }
                    }
                    request-type {
                        values { all }
                    }
                    search-all { }
                }
                guarantee-logging enabled
                guarantee-response-logging enabled
                response-logging all
            }
        }

    To: 
    security log profile /Common/example_log_profile_name {   ------->>>>> 
        application {
            /Common/example_log_profile_name {                ------->>>>> 
                filter {
                    login-result {
                        values { login-result-failed }
                    }
                    request-type {
                        values { all }
                    }
                    search-all { }
                }
                guarantee-logging enabled
                guarantee-response-logging enabled
                response-logging all
            }
        }
  5. Remove the same spaces in every virtual server that references this profile. 
  6. Load the BIG-IP configuration:
        tmsh load sys config
