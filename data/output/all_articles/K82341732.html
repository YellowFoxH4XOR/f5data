Description

Your system is currently using unsecure LDAP authentication, and you want to enable secure LDAP authentication.

Environment

  • BIG-IP 13.1.4
  • LDAP

Cause

None

Recommended Actions

To enable secure authentication on the BIG-IP, follow these steps:

  1. Go to System ›› Users : Authentication.
  2. Click 'Change' at the bottom.
    • Under 'Authentication' settings, select 'Enabled' or 'Start TLS'.
    • Enabled: Starts an SSL handshake immediately upon connecting.
    • Start TLS: Connects using plain text, then issues a STARTTLS command to switch to SSL/TLS.
  3. Click Finished.

After you complete these steps, secure LDAP authentication will be enabled.
