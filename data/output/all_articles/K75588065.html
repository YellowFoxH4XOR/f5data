Description

When a BIG-IP APM Portal Access resource is configured with a web service virtual server that exists on the same node that the BIG-IP APM virtual server exists on then the internal traffic between BIG-IP APM and the web service virtual server will source the client IP address. The "Source Address Translation" (SNAT) setting on the BIG-IP APM virtual server has no affect on this behavior. A packet capture taken on the BIG-IP APM and filtering on the Portal Access virtual server's IP will reveal this behavior.

Client IP address <-> BIG-IP APM virtual server IP address / Client IP address  <-> Web service virtual server IP address / SNAT IP address <-> Pool member IP address

Environment

  • BIG-IP APM virtual server
  • Web service virtual server on same node the BIG-IP APM virtual server exists on
  • Portal Access resource configured with the web service 

Cause

This is expected behavior.

Recommended Actions

None.

None.
