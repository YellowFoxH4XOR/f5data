Known Issue

This may be the result of a known issue. The snmptrap.conf file is saved in UCS configuration archives. Occasionally, the snmptrap.conf file is updated when you upgrade. Currently, there is not a way to merge changes from the new snmptrap.conf file to the saved version. As a result, the old snmptrap.conf file is retained and some SNMP traps may fail because the updates to the snmptrap.conf file are not included.

When this problem occurs, the files must be merged manually. Contact F5 Technical Support for assistance.

F5 Product Development tracked this issue as CR23564 and CR41889.
