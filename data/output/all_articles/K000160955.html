K000160955: Error reply received while fetching stats. ERRCODE=255 ERRORSTR='No rows found in table 'cpu_stat' with 4 matching key values'

Description

F5OS may log repeated platform-stats-bridge errors such as:

`ERRCODE=255 ERRORSTR="No rows found in table 'cpu_stat' with 4 matching key values"`  

These messages can appear after an OS upgrade or during normal operation when platform statistics are being queried for SNMP polling. The condition is transient and affects availability of some platform metric polling data, but it does not affect traffic processing or tenant operation.

Environment

F5OS

Cause

Timing/race condition in F5OS control-plane scheduling. The low-priority tmctl stats collection process may not populate tmstat tables such as cpu_stat before platform-stats-bridge attempts to read them for SNMP polling.

Answer/Recommended Actions

The condition is transient and typically clears as the statistics tables are populated. No manual intervention is required for service continuity. Be aware that SNMP polling for platform statistics dependent on the affected tmstat table may temporarily fail, while unrelated statistics remain available. This behavior does not impact traffic processing or tenant OS instances. 

F5OS does not provide a built-in method to suppress this specific platform log. If log noise reduction is required, filter message ID 0x4305000000000001 on the external syslog server
