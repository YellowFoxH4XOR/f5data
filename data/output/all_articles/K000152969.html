K000152969: No data available error when submitting a case

Type
Support Solution
Published
2025-08-26
Updated
2025-10-14
Applies to
  • BIG-IQ
  • BIG-IP
  • F5OS
Source
https://my.f5.com/manage/s/article/K000152969

Description

Getting the no data available message when creating a case in My F5

 

 

Environment

 

  • Case creation in My F5

Cause

Getting the pending approval status on My F5 account

 

 

Recommended Actions

Contact the Admin user for the account to remove the pending approval and elevate the user's role to "viewer" or Contact F5 Support if the account has no Admin user.
