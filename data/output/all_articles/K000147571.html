K000147571: How to resolve TLS automatic certificate renewal failure?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-21
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147571

Description

  • My TLS certificate for the HTTP load balancer is expiring and automatic certificate renewal is failing.

Environment

  • F5® Distributed Cloud (XC) Console
  • HTTP Load balancer

Resolution/Answer

  • If you have added new domains to the load balancer, please make sure to map the CNAME for that domain.
  • If no new domains are added, please check and confirm if you have done the CNAME mapping properly.

Cause

  • Missing CNAME mapping for any domain in the load balancer can cause this issue.

Additional Information

  • For delegated domain XC will take care of all the things once the NS record created for the delegated domain in the root domain registrar.
  • However in case of non delegated domain you need to take care of DNS records.  You can use DIG command to check and confirm the CNAME mapping.
