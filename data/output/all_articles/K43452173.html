Issue

Error Message

01260009:4: Connection error: ssl_hs_alloc:1687: The number of active handshakes <value1> reached the global limit <value2> (80)

In this error message, note the following:

  • <value1> is the number of active Secure Sockets Layer (SSL) handshakes that the BIG-IP system is processing.
  • <value2> is the global active SSL handshake limit defined for the system.

For example:

01260009:4: Connection error: ssl_hs_alloc:1687: The number of active handshakes 15000 reached the global limit 15000 (80)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The number of active SSL handshakes for the BIG-IP system reaches the limit specified in the tmm.ssl.activehandshakethreshold database variable.
You can use the tmm.ssl.activehandshakethreshold database variable to limit the number of active SSL handshakes for the BIG-IP system. The default setting is 0 (zero), which means that there is no limit.

Impact

When the number of active SSL handshakes reaches the specified limit, the system terminates the most recent SSL handshake and logs this error message.

Recommended Actions

Monitor active SSL handshakes and system resources over time and determine whether you can increase the limit specified in the tmm.ssl.activehandshakethreshold database variable.
