Description

Post upgrade many certs and keys were revoked in the newer boot location 

Environment

  • BIG-IP LTM
  • BIG-IP upgrade to version 16.x, 17.x

Cause

This issue is due to the image being installed in HD volume long back and an upgrade being performed recently. Due to which when the upgrade is done, the system took the older configuration saved in the HD volume.

 

Recommended Actions

  1. If you have installed an upgrade image long back, and are booting into the volume now, it is recommended to set Install Configuration to Yes. The Install Configuration option copies the configuration from the selected Source Volume to the destination boot location.
  2. You can rollback and try to upgrade again by setting install Configuration to Yes
