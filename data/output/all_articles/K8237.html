Known Issue

This is the result of a known issue. When running the Policy Builder to build a new security policy, the Traffic Learning screen may display violations that have already been accepted by the Policy Builder. When this issue occurs, you may see violations such as Illegal object type and Illegal parameter for objects that were previously added to the security policy. After several minutes the violation may disappear from the Traffic Learning screen.

In some cases, the false violations remain in the Traffic Learning screen indefinitely. For example, violations such as Length errors, and Illegal meta character in Object, may remain in the Traffic Learning screen. When you click on the violation, there is no value that can be changed because the Policy Builder has already added the violation to the security policy.

F5 Product Development tracked this issue as CR87427 and it was fixed in BIG-IP ASM 9.4.4. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Workaround

You can work around this issue by clearing the false violations from the Traffic Learning screen. To clear the false violations from the Traffic Learning screen, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Application Security.
  3. Click the relevant web application.
  4. Click Violations.
  5. Click the violation and determine whether it has been accepted by the Policy Builder.
  6. If the violation has been accepted by the Policy Builder, clear the violation by clicking the clear button.
