Description

Error "Cannot find disk information." when accessing the resource provisioning screen in the GUI.

Environment

  • BIG-IP
  • versions: 14.1.x, 14.1.2, 15.0.x
  • GUI (Configuration Utility)

Cause

Bug ID 726240
 

Recommended Actions

Follow the workaround written in Bug ID 726240
This issue is fixed in V15.1.* and V14.1.2.1 and later.

On a virtual appliance this error can also be caused by the device being under-provisioned: memory and/or CPU
 

Additional Information

When running the configuration utility in the GUI, after clicking Next on the License screen the GUI reports an error and you are unable to proceed: Cannot find disk information.
