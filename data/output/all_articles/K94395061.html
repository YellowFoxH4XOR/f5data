Description

The F5 SSL Orchestrator currently forwards only decrypted application data to the security devices that are configured as part of the service chain in a deployment. The F5 SSL Orchestrator does not support forwarding TLS metadata together with decrypted application data to these chained security devices. This limitation may prevent these security devices from detecting SSL/TLS level attacks that may lead to data exfiltration.
