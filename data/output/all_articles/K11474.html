Issue

Error Message

The username or password is not correct. Please try again.
(error: Cannot contact any KDC for realm '<domain>', principal name: <username>@<domain>. Please verify Active Directory and DNS configuration.)

A similar corresponding error message is logged to the /var/log/apm file:

err apmd[<pid>]: 01490107:3: AD module: authentication with '<username>' failed: Cannot contact any KDC for realm '<domain>', principal name: <username>@<domain> (-1765328228)

In the error messages, note the following:

  • <username> refers to the user's UPN logon name
  • <domain> refers to the user's UPN domain

Client interface example:

The username or password is not correct. Please try again.
(error: Cannot contact any KDC for realm 'example.com', principal name: <user01@example.com. Please verify Active Directory and DNS configuration.)

Note: The first part of the error message may mislead users to think they have incorrectly submitted their credentials.

Message Location

You may encounter this message in the following locations:

  • Client interface
  • The /var/log/apm file

Description

This message occurs when the following condition is met:

  • The BIG-IP APM system cannot access the Active Directory AAA server that is configured to authenticate users.

Impact

Users will be unable to authenticate the BIG-IP APM system.

Recommended Actions

  • Verify that the key distribution center (KDC) is online.
  • Verify the network connectivity from the BIG-IP system to the KDC.
  • Verify that TCP port 389 (LDAP), TCP, and UDP ports 88 (Kerberos) are open between the BIG-IP system and the KDC.
  • Verify that the KDC is resolvable through DNS.
