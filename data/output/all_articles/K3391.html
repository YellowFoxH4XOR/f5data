Topic

You can configure web services to allow communication with FirePass for the following purposes:

  • Administrator access to the Administrative Console
  • User login and VPN functionality
  • An HTTP server that redirects users to HTTPS
  • MyDesktop functionality
  • Failover pair and cluster synchronization

To use web services, you must configure (at a minimum) the following:

  • A service that provides access to the Administrative Console
  • A service for user login and VPN functionality

You may also need to configure the following:

  • A service for the MyDesktop agents to communicate with the FirePass, for those clients using MyDesktop
     
  • An HTTP service for the Synchronization Agent, if you are using a failover pair or cluster

You can configure FirePass web services with the following access permissions:

CodeAccess permissions
UAllow access by non-administrative users.
AAllow Administrator access.
DUsed by MyDesktop agents.
SUsed by the Synchronization agent.

Adding a new web service

To add a new web service, perform the following procedure:

  1. Log in to the Administrative Console.
  2. Click Device Management.
  3. Click Configuration.
  4. Under the Configuration heading, click Network Configuration.
  5. Click the Web Services tab.
  6. In the add new service section, populate the following fields:

    • IP address
    • port
    • host name
  7. If you want the web service to be encrypted, check the box for SSL.
  8. Click the Add New button.

    The Web Service Configuration page opens.

  9. Verify your entries and make changes, if required.
  10. If you are configuring an SSL web service, click the appropriate certificate.
  11. If you want to use the web service to redirect users who attempt to access the FirePass using HTTP, type the HTTPS URL for redirection in the HTTPS URL to redirect to box.
  12. If you want to access the FirePass using HTTP, check the Do not redirect to HTTPS box.

    Use this option to support user access from browsers that do not include SSL or when you are configuring a service for the Synchronization Agent.

    Note: F5 Networks recommends that you do not enable HTTP access for users, as the user sessions will not be encrypted.

  13. Select the web service access level by checking any of the following check boxes:

    Note: The Synchronization checkbox will appear only in redundant systems and the Desktop checkbox will appear only if the web service does not use SSL.

    • User Login
    • Admin Login
    • Desktop
    • Synchronization
  14. Click the Update button.
  15. Click the Finalize tab.
  16. Click the Finalize Changes button.

Modifying a web service

To modify an existing web service, perform the following procedure:

  1. Log in to the Administrative Console.
  2. Click Device Management.
  3. Click Configuration.
  4. Under the Configuration heading, click Network Configuration.
  5. Click the Web Services tab.
  6. In the Web Server Configuration section, locate the web service that you want to modify and click Configure.
  7. Modify the fields you want to change.
  8. Click the Update button.
  9. Click the Finalize tab.
  10. Click the Finalize Changes button.
