Description

  • It is not possible to export large security logs from ASM using the Configuration Utility 

Environment

  • ASM
  • Security Logs

Cause

  • Feature limitation on the ASM, in which only 100 records can be included in a single export
Recommended Actions
  • Filter the Event Logs by Basic or Advanced filter to minimize the records under 100 or less for Security Events Report.

  • None
