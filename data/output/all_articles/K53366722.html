Description
Configuration load error similar to what is shown below that it can appear in tmsh load sys config verify command or in LTM log:

Sep  3 12:25:51 bigip.localhost emerg load_config_files[16848]: "/usr/bin/tmsh -n -g -a load sys config partitions all base " - failed. -- 01070307:3: Invalid interface 2.1

This error occurs if the specified network interface in the BIG-IP configuration is not found. It can set the BIG-IP system to an INOPERATIVE state.

Environment

  • BIG-IP LTM
  • Missing interface 
  • Reload Config

Cause
None

Recommended Actions

In order to resolve the issue, follow the steps below.

If we take the example error on interface 2.1, in the BIG-IP CLI (bash shell), run: 

  1. Backup the bigip_base.conf
    cp -p /config/bigip_base.conf /config/bigip_base.conf.orig

  2. Check the available interfaces 
    tmsh show net interface
    Note If the command does not run because MCPD is also not running, check and note the physical ports.

  3. Edit the bigip_base.conf, lookup for '2.1' net interface and replace them with the interface no. as per step 2 above; save and exit the editor.

  4. Run a configuration verification 
    tmsh load sys config verify

  5. If step 4 is all clear, load the configuration
    tmsh load sys config

  6. Once all are loaded, the BIG-IP Configuration Utility/GUI should be available and ready. Done.
