Known Issue

When a JavaScript-created link points to a site that contains the word Undefined, Firefox and Safari users may be unable to click on the link. This issue occurs because the word Undefined is appended to the end of the link, which causes the link to fail. This issue only occurs with the Firefox or Safari browsers.

For example, the correct link should appear as follows:

https://www.example.com/test.htm

However, the link is rewritten to appear as follows:

https://www.example.com/test.htmundefined

F5 Product Development tracked this issue as ID 338898 and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

Additionally, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.0-1789.0-HF2, which has been issued for BIG-IP APM 10.2.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about downloading software from F5, refer to K167: Downloading software from F5.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

Workaround

You can work around this issue by using the Internet Explorer browser instead of Safari or Firefox.
