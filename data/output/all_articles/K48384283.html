Issue

Description

01071859:4: Warning generated : <iRule_name>: warning: [unmatched closing character][}]

In this error message, note the following:

  • <iRule_name> is the name of the iRule in question.

For example:

01071859:4: Warning generated : /Common/ProxyPass:123: warning: [unmatched closing character][}]

You may encounter this message in the following locations:

  • TMOS Shell (tmsh)
  • The /var/log/ltm file

Environment

  • Upgraded from BIG-IP 13.1.0.6 to 13.1.1
  • An iRule has one or more curly brace that is not escaped 

Cause

The iRule in question has one or more curly brace that needs to be escaped.

Recommended Actions

To work around this issue, curly brace literals need to be escaped to stop the verification from flagging the warning. 

For example, you need to prepend an escape character to the curly brace literal in the following iRules command syntax:

set serverside [string trimleft [getfield $ppass " " 2 ] "{" ]

To look like this:

set serverside [string trimleft [getfield $ppass " " 2 ] "\{" ]

Similarly, in another example, you need to prepend an escape character to the curly brace literal in the following iRules command syntax:

set newpool [string trimright [getfield $ppass " " 3 ] "}" ]

To look like this:

set newpool [string trimright [getfield $ppass " " 3 ] "\}" ]
