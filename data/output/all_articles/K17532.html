Known Issue

Imported BIG-IP local user database entries may not display in the Access Policy > Local User DB page of the Configuration utility.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access policy uses a local user database for authentication.
  • A user entry is imported to the local user database without the UID field.
  • A single imported user entry is manually deleted from the Configuration utility.

When a user entry is imported without a UID field, all imported entries will be mapped to a single entry in one of the internal MySQL tables. Therefore, deleting a single entry that was imported without the UID field, in the Configuration utility, causes display issues for all other entries imported without the UID field.

Impact

The Configuration utility fails to display user entries correctly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When deleting a local user database entry, from the Configuration utility, the system displays an error message similar to the following example:

    "Request Timed out" error being displayed when deleting users

  • Imported local user database entries may not display in the Configuration utility after you have deleted a single imported user entry.
