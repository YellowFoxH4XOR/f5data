Known Issue

The HTTP_DISABLED iRules event may cause the Traffic Management Microkernel (TMM) to restart.

This issue occurs when all of the following conditions are met:

  • You use the HTTP_DISABLE iRules event.
  • HTTP is disabled before the first request reaches the HTTP filter. (This might occur if you use TCP::collect, or if HTTP::disable is invoked in CLIENT_ACCEPTED.)

Impact

TMM may stop responding, and then restart, which affects traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The HTTP_DISABLE iRules event is invoked when you enable or disable the HTTP filter. If this occurs before the system releases the first HTTP request, then the TMM may stop responding.
