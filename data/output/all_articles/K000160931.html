K000160931: Hardware Temperature Thresholds on F5OS r5600 and r10900 Devices: Monitoring and Configuration Limitations

Description

Hardware temperature thresholds on F5OS r5600 and r10900 appliances are factory-set and cannot be modified by users. Only monitoring of current temperature values and thresholds is supported.

Environment

  • Product: F5OS
  • Platform: r5600, r10900 appliances

Cause

This is expected behavior; temperature thresholds for r5600 and r10900 cannot be modified.

Answer/Recommended Actions

  • Temperature thresholds are hardcoded and not user-editable.
  • To monitor current hardware temperature and threshold values, use:
    docker exec -ti platform-hal psf run GET:lop/analog-alerts $filter="contains(object 'Temperature')"
    Example output:

    "enterAt": 420

    Note: 420 represents 42.0°C.
  • To retrieve sensor data (including temperature):
    docker exec -it platform-hal ipmiutil sensor -ctwg temperature
  • The system will automatically generate alerts/events if hardware temperature crosses the factory-set thresholds.
  • Ensure devices are installed in environments that meet F5's specifications for temperature and airflow.

Additional Information

  • The inability to modify hardware temperature thresholds is by design for hardware safety and reliability.
  • Alerts at lower temperatures than the factory-set threshold are not supported on these platforms.
  • For further details on hardware specifications and environmental requirements, refer to the official platform guide.
