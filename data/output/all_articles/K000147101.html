K000147101: How to onboard a new user to F5® Distributed Cloud Services systems

  • F5 Distributed Cloud

What Happened?

  • You have a new team member
  • You want him to be able to access F5® Distributed Cloud Services systems (formerly known as Acorus Networks)
  • They need access to a data center

Environment

  • F5® Distributed Cloud Services

Resolution/Answer

To onboard a new user to F5® Distributed Cloud Services systems:

  1. Raise a F5 Distributed Cloud Services support request
  2. Add the following details before submitting your support request:
    • New user's name
    • Email
    • Company's name
    • Systems to be added on: Slack channels, Equinix account, and internal documentation
    • Optional: The data center where access is required (e.g. PA4 data center)
  3. Submit your support request
  4. Our support engineers will confirm once access was granted
  5. Validate access
  6. Inform the support engineers that you are able to access and ask for ticket closure
