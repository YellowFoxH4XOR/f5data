K000163786: Import of OpenAPI API protection profile via CLI

Description

An OpenAPI specification cannot be imported directly into a BIG-IP APM API protection profile with tmsh. Use the BIG-IP REST API to create the profile and specify the location of the OpenAPI specification.

Environment

  • BIG-IP APM 17.5.1
  • API protection profile
  • OpenAPI specification stored on the BIG-IP tenant
  • Guided Configuration components available on the system
  • Specification located under /var/config/rest/downloads/

Cause

The tmsh API protection profile command reference does not provide a direct method for importing an OpenAPI specification.

Recommended Actions

  1. Place the OpenAPI specification on the BIG-IP tenant under:

    /var/config/rest/downloads/

  2. Open Access → Guided Configuration once to activate the required components.
  3. Submit a POST request to the API protection profile REST endpoint:

    /mgmt/tm/apiprotection/api-protection-profile

  4. Include the specification path in the profileProperties.specFilePath property:

    curl -k --user admin \
    -H 'Content-Type: application/json' \
    -X POST 'https://<management-address>/mgmt/tm/apiprotection/api-protection-profile' \
    --data-binary '{
    "name": "profile_name",
    "isNew": true,
    "profileProperties": {
    "specFilePath": "/var/config/rest/downloads/openapi_specification.yaml",
    "dnsResolver": "/Common/default-dns-resolver",
    "usePool": true
    }
    }'

    Replace the profile name, specification path, DNS resolver, and pool setting with values appropriate for the system.

  5. Use interactive authentication, such as curl --user admin without specifying a password on the command line. curl prompts for the password interactively, so the password is not included in the command line or stored in a credentials file.
  6. Verify the imported profile and its paths:

    tmsh list api-protection profile apiprotection all-properties

  7. Confirm that the imported API protection profile is visible in the BIG-IP Configuration utility.

Additional Information

  • This procedure applies to a BIG-IP APM API protection profile, not a BIG-IP ASM profile.
  • Authentication is required for the REST API. Interactive prompting changes how the password is supplied but does not remove the authentication requirement.
  • The internal product code and tmsh commands used by Guided Configuration to process an OpenAPI upload are not provided.
  • The specification must exist at the path supplied in specFilePath.
  • The DNS resolver and pool settings must be valid for the BIG-IP system.
