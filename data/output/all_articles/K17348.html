Description

Beginning in BIG-IP 12.0.0, the Virtual Local Area Network (VLAN) DAG Round Robin feature allows stateless traffic to spread across all blades within a VIPRION chassis.

This option is available on the following VIPRION chassis and blades:

  • VIPRION C2200
  • VIPRION C2400
  • VIPRION C4480
  • VIPRION B2100
  • VIPRION B2150
  • VIPRION B2250
  • VIPRION B4340
  • VIPRION B4340N
  • VIPRION 4450 (A114)

You can access this feature using the dag-globals round-robin-mode (global | local) Traffic Management Shell (tmsh) command.

The feature enables you to specify global disaggregation settings to use either global (default) or local. The global option specifies that stateless traffic will use the Round Robin method across all blades and Traffic Management Microkernels (TMM). The local option specifies that stateless traffic will use the Round Robin method across all TMMs on the blade the traffic is received.

Note: To use this global feature, you must enable the VLAN DAG Round Robin feature on a VLAN and you must specify the required UDP ports. For more information about configuring the VLAN DAG Round Robin feature, refer to the VLANs, VLAN Groups, and VXLAN chapter in the BIG-IP TMOS: Routing Administration guide. For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Viewing the current setting

To view the current global status setting, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To view the current global status setting, type the following command:

    tmsh list net dag-globals round-robin-mode

    For example:

    # tmsh list net dag-globals round-robin-mode
    net dag-globals {
        round-robin-mode global
    }

Modifying the current VLAN DAG setting

To change the mode from global to local, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To change the mode to local, type the following command:

    tmsh modify net dag-globals round-robin-mode local

  3. To save your changes, type the following command:

    tmsh save sys config
