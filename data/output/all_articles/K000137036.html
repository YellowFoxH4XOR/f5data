K000137036: How to add a BIG-IP Next instance that was deleted back into Central Manager

Description

Normally, when you delete a BIG-IP Next instance from BIG-IP Next Central Manager, the BIG-IP Next instance is reset to factory defaults; however, you may be able to re-add the instance if you deleted it when it was unreachable by (1) choosing the unreachable instance and (2) clicking Delete:

Environment

  • BIG-IP Next removed from inventory in Central Manager
  • The BIG-IP Next instance was unreachable at the time it was removed (for example the instance was powered down)
  • The BIG-IP Next instance has been powered back on and the API is in a healthy state
  • You wish to re-add the instance into Central Manager again and you do not want to lose the original settings that were in the BIG-IP system.

Cause

You can add a previously deleted instance back into inventory, as long as you remember the admin-cm password that you chose when you originally added the instance.

Recommended Actions

  1. From the My Instances page on Central Manager, click Add
  2. Enter the IP address of the BIG-IP Next instance you wish to re-add
  3. For the username and password, use "admin-cm" and the password you used for that account
  4. When you are prompted for new management credentials, do not use "admin-cm"; instead, use new credentials like "admin-cm2" and a new password.
  5. After the BIG-IP Next instance has been successfully re-added, you can restore any backups that you have previously taken.
