Topic

Starting with BIG-IP ASM 13.1.0, you can configure the BIG-IP ASM to re-execute Cross-Site Request Forgery (CSRF) protection after a specified amount of time.

CSRF is an attack method that exploits a pre-existing relationship of trust and forces running unwanted actions on a currently authenticated web applications. CSRF protection allows you to protect against CSRF attacks by adding a CSRF token to the identified URLs using JavaScript. You can configure CSRF protected URLs explicitly or as wildcard entities.

CSRF protection works by identifying the known list of URLs in the web page and is not designed to anticipate the arrival of additional content in the page after examination of the presented content.

Note: For a more detailed description of CSRF protection, refer to K11930: Overview of the ASM CSRF protection feature.

Description

In environments in which URLs are derived through dynamic content, the complete list of URLs may not be present at the initial page load. The ability to re-execute CSRF on a page assists in identifying URLs that are generated or modified by dynamic content and are not available for DOM traversal at the initial onload of the page.

Recommended Actions

To accommodate page-delayed content, you can change the system database variable asm.csrf_rerun_interval to a value greater than zero (default). The specified value is the amount of time in seconds the BIG-IP ASM waits before re-executing CSRF protection on the page content.

Important: Before modifying the BIG-IP ASM system asm.csrf_rerun_interval database variable, when expecting delayed content for a page, you should have a good understanding of that page's average load time so that you can accurately specify the variable time value.

Modifying the asm.csrf_rerun_interval system database variable

  1. Log in to the TMOS Shell (tmsh).
  2. Enter the following command syntax:

    modify /sys db asm.csrf_rerun_interval value <numeric value in seconds>

    Note: Replace <numeric value in seconds> with the appropriate amount of time to permit content retrieval.

  3. To exit tmsh enter the following command:

    quit
