Known Issue

This is the result of a known issue. By default, the BIG-IP GTM system answers UDP DNS queries from LDNS servers. If the BIG-IP GTM system is configured with a TCP GTM listener, the TMM process will panic if the BIG-IP GTM DNS filter receives a TCP DNS request.

Note: A TCP GTM listener is only configurable from the command line in BIG-IP GTM versions 9.2.4 and 9.2.5 with a hotfix. For more information, refer to K7117: Configuring the BIG-IP GTM to answer TCP DNS requests.

F5 Product Development tracked this issue as CR74730 and it was fixed in BIG-IP GTM 9.3 and 9.4.2. For information about upgrading, refer to the BIG-IP GTM Release Notes.
