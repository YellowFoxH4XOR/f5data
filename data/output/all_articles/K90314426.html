Description

  • Unable to view ASM Event logs on Configuration utility (GUI)
  • When accessing the page  Security  ››  Event Logs : Application : Requests a pop-up with the following message "Failed to load requests" appears
  • Similar log may appear in /var/log/asm:

    Jan 14 13:54:36 asm crit g_server_rpc_handler.pl[13025]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::log_error_and_rollback): DBD::mysql::st execute failed: Table './PRX/REQUEST_LOG#P#p6636400001' is marked as crashed and should be repaired at /usr/local/share/perl5/F5/ASMConfig/Entity/Base.pm line 1402.
     

Environment

  • ASM Event logs

Cause

The ASM PRX database table got corrupted.

Recommended Actions

Repair the ASM PRX table.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Connect to the device management IP address via SSH
     
  2. Run the following command from BIG-IP bash shell in order  to repair the PRX table:
    mysql -t -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e 'repair table PRX.REQUEST_LOG'
