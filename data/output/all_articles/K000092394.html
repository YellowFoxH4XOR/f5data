K000092394: ASM/AWAF Not detecting Attack Signatures

Type
Support Solution
Published
2022-10-06
Updated
2022-10-06
Source
https://my.f5.com/manage/s/article/K000092394

Description

Sometimes, ASM/AWAF does not trigger Attack Signatures or other violations.

Environment

  • All Attack Signatures and violations are enforced

Cause

This occurs when the policy was created without setting the Application Language.

In this case, the system sets it to "NA".

Recommended Actions

The Application Language must be configured for the ASM/AWAF to understand and trigger the required violations.

Impact of Procedure: By changing policy properties there can be unexpected outcomes, therefore, F5 recommends performing the activity during a maintenance window.

  1. Browse to Security > Application Security > Security Policies > Policies List
  2. Click on the desired policy
  3. For "Application Language" select the language which applies to your application.
  4. Click on Save
  5. Click on Apply Policy

Additional Information

None.
