Description

How to remove or uninstall F5 Telemetry Streaming configuration from the BIG-IP?

Environment

  • Telemetry

Cause

Procedure to remove telemetry configuration from the BIG-IP

Recommended Actions

To remove the entire Telemetry Streaming configuration, you can send a POST request to the /mgmt/shared/telemetry/declare endpoint with the following body:

{
  "class": "Telemetry"
}

This will delete the Telemetry Streaming configuration. You can use a RESTful API client or cURL, for example:

curl -X POST http://<big-ip-address>/mgmt/shared/telemetry/declare \
-H "Content-Type: application/json" \
-d '{ "class": "Telemetry" }' \
-u <admin>:<password>

Replace <big-ip-address>, <admin>, and <password> with your actual BIG-IP management IP address and credentials.

If you also want to remove the Telemetry Streaming extension package itself, navigate to iApps > Package Management LX in the BIG-IP GUI, locate the f5-telemetry package, and select Uninstall.
