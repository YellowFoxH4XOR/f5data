K83484259: F5 Edge Client not working with Windows with error in edge client logs ''The specified service does not exist as an installed service''

Type
Support Solution
Published
2019-12-19
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.X, 15.0.X, 15.1.0, 15.0.1, 15.0.0, 15.1.8, 15.1.7, 15.X.X, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.6
Source
https://my.f5.com/manage/s/article/K83484259
Description 

EDGE client refuses to work on Windows computer.
Diagnostic tool says all is fine.
It just disconnects the tunnel and allocates a new IP over and over.
Edge client logs contain errors such as:

Warning  2019-01-01 12:00:00:000  UNINSTALL  \&amp;#x0C;5/Service/ServiceHelpers.h, f5::Service::GetServiceState, Failed to open service '<F5_service>': 1060 (0x424) The specified service does not exist as an installed service.

Environment

  • Windws 10
  • Edge Client 
Cause

Windows Events Viewer show error:  "vpn.fqdn.com which has failed. The error code returned on failure is  720
Microsoft tech-net linked to the error code: VPN/RASClient - The error code returned on failure is 720

Recommended Actions

Uninstall network adaptor WAN miniports:
  1. Open Device Manager (Right Click on Start button and choose device
    manager)
  2. Expand the 'Network Adapters' WAN miniports in device manager
  3. Uninstall ALL WAN Miniport adapters
  4. Reboot the computer
