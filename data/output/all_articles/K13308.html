Known Issue

The BIG-IP system does not process ciphers with a strength of 192 bits. This issue occurs when the following condition is met:

  • The affected Secure Sockets Layer (SSL) profile is configured to use a cipher suite with a cipher strength of HIGH.

When an SSL profile is configured to use the string HIGH in the Ciphers field, the BIG-IP system is expected to process the list of supported ciphers that have a strength of greater than 128 bits. This includes the ciphers with a strength of 192 bits, for example DES-CBC3-SHA.

Impact

The BIG-IP system fails to process SSL traffic using 192 bit ciphers.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • SSL handshakes fail.
  • The BIG-IP system fails to process SSL traffic using 192 bit ciphers.

Workaround

To work around this issue, you can configure the SSL profile to use ciphers with a strength that is higher than 128 bit by using this string DEFAULT:!ADH:!EXPORT40:!EXP:!LOW:!MEDIUM for the Ciphers field. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > SSL > Client for Client SSL profiles or Local Traffic > Profiles > SSL > Server for Server SSL profiles.
  3. Click on the affected SSL profile.
  4. In the Configuration menu, select Advanced.
  5. Select the Ciphers check box.
  6. In the Ciphers text box, type the following string:

    DEFAULT:!ADH:!EXPORT40:!EXP:!LOW:!MEDIUM
  7. Click Update.
