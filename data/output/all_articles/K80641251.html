Description
 

The virtual server, using a request logging profile, and pool members are shown as up, but suddenly all the traffic passing through the VS is being reset by the BIG-IP.


If we take a packet capture on a 443 Virtual Server, you will find a reset with the following error after the SSL handshake: [F5RST: Internal error ((TMIREQLOG) Error initiating response. failed)]

For example:

443 → 52234 [RST, ACK] Seq=1624902969 Ack=2792346187 Win=0 Len=86 [F5RST: Internal error ((TMIREQLOG) Error initiating response. failed)]
 

Environment
 

  • BIG-IP LTM
  • Virtual Server
  • Request logging profile


Cause

The virtual server is configured with a Request Logging Profile that stopped working properly.
 

Recommended Actions
 

We have 2 options to fix the issue:
  1. Remove the request logging profile from the Virtual Server or
  2. Make sure that the Remote logging Server is working properly
