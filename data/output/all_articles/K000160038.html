Description

When try to set the backups of F5OS partitions on BIG-IQ you may encounter a problem when the F5OS devices are located behind a NAT. 

Environment

  • BIG-IQ
  • F5OS partitions
  • VELOS 

Cause

The root cause is a product limitation in BIG-IQ — there is no functionality to edit or override discovered partition management IPs for F5OS partitions. When partitions are behind NAT, BIG-IQ cannot reach them using their real IPs, resulting in failed backups. While the controller backup completed, partition backups failed because BIG-IQ detected and attempted to use the real partition management IPs, which were not reachable from BIG-IQ due to NAT. There is no supported method to override or edit the discovered partition management IPs in BIG-IQ, resulting in partial backups. 

Answer/Recommended Actions

First approach is to configure 1:1 static NAT mappings on the network infrastructure so that BIG-IQ can reach partition management IPs via their NAT IPs.

If your environment requires this functionality, you can submit the RFE case to add this kind of feature.
