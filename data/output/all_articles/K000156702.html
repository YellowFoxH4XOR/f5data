K000156702: The SNMP platform reports spikes of very high error rate, to the interfaces of the VELOS chassis, since upgrade to 1.8.0

Type
Support Solution
Published
2025-09-30
Updated
2025-09-30
Applies to
  • F5OS
  • F5OS-C: 1.8.0
Source
https://my.f5.com/manage/s/article/K000156702

Description

SNMP monitoring platforms (such as Zabbix) may report unexplained spikes in interface error counters (ifInErrors and ifOutErrors) on F5 VELOS chassis. These spikes can appear as very high error rates for specific OIDs, such as ifInErrors.33554445 or ifOutErrors.33554445, with values like 3954040833, even though there is no corresponding network outage or actual interface error. SNMP logs and packet captures confirm the presence of these anomalous counter values.

Environment

  • Product: F5OS - Chassis
  • Platform: F5-VEL-LTM-CX410-AC, F101
  • Software Version: 1.8.0 (including 1.8.0-19782.LTS)
  • Monitoring: SNMP polling via Zabbix or similar tools
  • Typical OIDs affected: ifInErrors, ifOutErrors

Cause

This issue is caused by a known bug (Bug ID 1624057) affecting the BX110 FPGA register reads on VELOS platforms. The bug results in bad register reads, which are then reflected as erroneous high values in SNMP error counters. These spikes are cosmetic and do not indicate actual interface errors or packet loss.

Recommended Actions

Upgrade to F5OS version C-1.8.0 EHF-1 or preferably C-1.8.1, where the bug is addressed.
