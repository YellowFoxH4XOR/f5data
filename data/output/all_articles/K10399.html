Topic

F5 has recently discovered and corrected a number of critical issues that affect customers running BIG-IP 9.4.7. F5 recommends that all customers currently running 9.4.7 install Hotfix-BIGIP-9.4.7-326.1-HF1, or a later version of the cumulative hotfix rollup, as soon as possible.

The following CRs are fixed in Hotfix-BIGIP-9.4.7-326.1-HF1 for BIG-IP 9.4.7:

CR
ArticleDescription
CR100218K8867The BIG-IP system sends a TCP reset packet with an incorrect sequence number
CR124714K10398The interface command hangs on the BIG-IP 1000 and 2400 platforms
CR125853K10366BIND vulnerability CVE-2009-0696

The hotfix is available for download at the F5 Downloads site. For information about downloading software from F5, refer to K167: Downloading software from F5.

For information about installing a hotfix, refer to K6845: Managing F5 product hotfixes.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For a list of the latest hotfixes for each BIG-IP software branch, refer to K9502: BIG-IP hotfix matrix.
