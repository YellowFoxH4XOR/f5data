Known Issue

The BIG-IP Server SSL profile may re-use expired Secure Socket Layer (SSL) session IDs.

The Server SSL session cache reaper may take as long as one hour to process the entire session cache. As a result, SSL session IDs may remain in the cache past the configured timeout period until the reaper purges the cache.

Impact

The BIG-IP Server SSL profile may continue to use an expired SSL session ID after the SSL cache timeout has been reached.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Server SSL profile statistics include expired session entries. To view the number of current session cache entries, you can use the following command syntax:

    tmsh show ltm profile server-ssl <profile name> | grep -A5 “Session Cache”

    For example:

    tmsh show ltm profile server-ssl my-server-ssl-profile | grep -A5 “Session Cache”
