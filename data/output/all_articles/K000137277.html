K000137277: Command to check Interfaces up and down (flapping)

Description

You want to check if the interfaces are flapping or not.

Environment

  • BIG-IP
  • Interface
  • Vlan

Cause

None

 Recommended Actions

You can use the following commands on CLI to check the status of the interfaces. The Output log lines will show the change of the interface status and help to find if the interface was frequently up and down or not:

grep -E "Link.*is (DOWN|UP)" /var/log/ltm* | sed -r 's/^[^:]+://g' | sort -n | uniq

You can also check the current interfaces status by the following command:

tmsh show /net interface all-properties -hidden
