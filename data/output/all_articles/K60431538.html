K60431538: Debug snmpd[##]: truncating integer value > 32 bits messages appearing in syslog

Type
Support Solution
Published
2021-07-21
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K60431538

Description
You may notice "debug snmpd[##]: truncating integer value > 32 bits" log messages in your syslog server.

Environment

  • BIG-IP
  • syslog

Cause

Some values sent to SNMP can grow too large over time, causing an integer truncation error.  SNMP values are truncated and an error message is logged in /var/log/daemon.log:
err snmpd[##}: truncating integer value > 32 bits
 

Recommended Actions

  1. You may upgrade to a fixed version for ID 774617 , or
  2. Filter the log messages sent out to remove syslog servers (11.x - 15.x): 
    #edit sys syslog all-properties

include "
    filter f_audit{
        match(AUDIT) and not match(\"truncating integer value\");               <<<--------------
         };
          destination d_syslog_server {
              udp(<IP address> port (514));
               };
                log {
                    source(s_syslog_pipe);
                    filter(f_audit);
                    destination(d_syslog_server);
                };
                "
