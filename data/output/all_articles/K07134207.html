Description

When you attempt to reactivate a license on the Activate F5 Product page, you are presented with the following error message:

Unable to grant license key: Error 515

Environment

  • Licensing
  • BIG-IP Virtual Edition
  • Revoke License

Cause
The attempted license reactivation experienced a failure.

Recommended Actions

Perform below steps on how to revoke the license in your BIG-IP VE.

Using the Configuration utility to revoke and reuse a BIG-IP VE license

Impact of procedure: Revoking the license disables traffic management features and returns the BIG-IP system to an unlicensed state.

  1. Log in to the Configuration utility.
  2. Navigate to System > License.
  3. On the License page, click Revoke.
  4. When prompted to remove the license, click OK.
  5. You can now install the license on the new BIG-IP VE system.

Using tmsh to revoke and reuse a BIG-IP VE license

Impact of procedure: Revoking the license disables traffic management features and returns the BIG-IP system to an unlicensed state.

  1. Log in to tmsh by typing the following command:

    # tmsh

  2. To revoke the license, type the following command:

    revoke /sys license

  3. You can now install the license on the new BIG-IP VE system.
After fifteen (15) minutes, re-attempt license activation. If the error persist, contact F5 Technical Support.
