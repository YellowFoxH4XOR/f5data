Description:

ASM session db dump is a simple command line tool which prints to the standard output the session db entries related to the asm session tracking feature.

 

Environment:

  • ASM or Advanced WAF provisioned
  • ASM policies configured on a system
  • The tool is available since v12.1.0

Cause:

The tool maybe helpful while debugging the session tracking feature functionality.

 

Recommended Actions:

To verify entires in asm session db run:

 

/usr/share/ts/bin/asm_sessiondump --list

 

Please use with caution as it might contain a lot of records.

 

Additional Information:

asm_sessiondump usage:

 

Usage: /usr/share/ts/bin/asm_sessiondump <options>

  --help    Show this help message

  --list    Show list of all sessions

  --delete_all Delete all sessions

  --status <block_all|track_all|block> Show sessions with a specific status

  --sid  <sid>   Show a specific session id

  --usr  <username> Show a specific username

  --ip   <ip>    Show a specific ip address

  --device <device>  Show a specific device ID

  --delete --sid  <sid>   Delete a specific session id

  --delete --usr  <username> Delete a specific username

  --delete --ip   <ip>    Delete a specific ip address

  --delete --device <device>  Delete a specific device ID
