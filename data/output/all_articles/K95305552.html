K95305552: How to download or update the GeoIP2 database

Type
Support Solution
Published
2020-01-13
Updated
2025-02-07
Applies to
  • NGINX Products
  • NGINX Plus: R20, R19, R18
Source
https://my.f5.com/manage/s/article/K95305552

Description

  • No longer able to update the GeoIP2 database automatically.
  • When attempting to update the database, the user is unable to resolve the geolite.maxmind.com DNS name, and receives the following error message:

    Resolving geolite.maxmind.com (geolite.maxmind.com)... failed: Name or service not known.

Environment

  • GeoIP2

Cause

Beginning December 30, 2019, MaxMind made significant changes to accessing and using GeoLite2.

Note: NGINX does not distribute the MaxMind databases.

Recommended Actions

For more information, refer to Significant Changes to Accessing and Using GeoLite2 Databases.
