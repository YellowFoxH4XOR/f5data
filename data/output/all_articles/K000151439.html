Description

FltRedirSrv.txt is the file where F5 DNS Relay Proxy service dumps its logs.
VPN tunnel is established with Edge Client and this error is dumped in the FltRedirSrv.txt log file.

DNSRelayProxy::ProcessRequest, Query for 'example.lab.lan' type 28 class 1 id 183
DNSRelayProxy::PrepareStaticEntryReply, Static entry found: 10.1.1.3
DNSRelayProxy::PrepareStaticEntryReply, IP address (10.1.1.3) is invalid for this address family (23). Error code: 10022

'exmple.lab.lan' is the destination FQDN configured  in APM network access as hostname with IPv4 address 10.1.1.3

Conditions:

  • hostname added as static host with an IPv4 address in network access configuration
  • Computer sending dns query requests for A and AAAA records for that hostname

Environment

  • APM deployed on BIG-IP
  • Network access configured on APM

Cause

A hostname (example.lab.lan) has been added with an IPv4 address (10.1.1.3) in network access 'static hosts'.
If computer sends two dns query request (A and AAAA) to resolve that hostname, F5 DNS Relay Proxy service will catch them and will try to find its static IPv4 (A) and IPv6 (AAAA) addresses.


As only an IPv4 address was added as an 'static hosts', dns relay proxy service will send back a dns query response with the IPv4 static entry found

DNSRelayProxy::ProcessRequest, Query for 'example.lab.lan' type 1 class 1 id 36755
DNSRelayProxy::PrepareStaticEntryReply, Static entry found: 10.1.1.3

And will also response with error "IP address is invalid for this address family (23). Error code: 10022" because there was not any IPv6 static host for the same hostname.

DNSRelayProxy::PrepareStaticEntryReply, IP address (10.1.1.3) is invalid for this address family (23). Error code: 10022

Recommended Actions

As administrator only added an IPv4 address, service will not be impacted by that error when dns query request for an AAAA record fails. So no action needed.
