K22561057: Local storage of large UCS backups may fill up /var

Type
Support Solution
Published
2021-09-15
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K22561057

Description

/var is filling up, logging messages.

  • Device drive appears to be running out of space.
  • Device is logging messages constantly after saving UCS file.
  • Disk partition /var has only % free

Environment

  • Depending on the modules provisioned, some configurations can become quite large, creating UCS files 500MB and larger.
  • UCS backup files of the configuration
  • BIG-IP All versions

Cause

Backing up larger configurations can result in very large UCS files.  Storing several of these files locally can quick fill up the /var partition.

Recommended Actions

Determine if there are any large files that are taking up space in /var

  1. Run this command in the command line of the BIG-IP: df -h > /var/tmp/$HOSTNAME-var_largest_files.txt; find /var -xdev -type f -ls|sort -nr -k 7,7 >> /var/tmp/$HOSTNAME-var_largest_files.txt
  2. Then review the output of the resulting file and look for large files in  /var/local/ucs
  3. Transfer the large UCS files off the BIG-IP and store them remotely.
