K000140323: Running gtm_add script fails with "ERROR: found "END CERT..." without BEGIN at line: 0."

Type
Support Solution
Published
2024-08-01
Updated
2024-08-01
Applies to
  • BIG-IP
  • BIG-IP DNS: 15.1.10, 16.1.5, 17.1.1
Source
https://my.f5.com/manage/s/article/K000140323

Description

When you run gtm_add command it is failing with this error:

ERROR: found "END CERT..." without BEGIN at line: 0.

ERROR: Malformed certificates found in local /config/httpd/conf/ssl.crt/server.crt.

Environment

  • BIG-IP DNS
  • DNS sync group

Cause

Bug ID1612201

Recommended Actions

Convert the certificate format using openssl x509 command. For each affected certificate run:

cp /config/httpd/conf/ssl.crt/server.crt /config/httpd/conf/ssl.crt/server.crt-back

openssl x509 -in /config/httpd/conf/ssl.crt/server.crt-back > /config/httpd/conf/ssl.crt/server.crt
