Description

The GUI automatically removes leading and trailing spaces of string fields.
 

Environment

Any string field, for example, datagroup strings that contain leading or trailing spaces.

Cause

This is expected behavior due to behavior change described in ID624351.

Recommended Actions

Use tmsh if a string field needs to have a leading or trailing space.
