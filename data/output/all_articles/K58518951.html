Description

BIG-IP supports F5 VSAs for use with NPS RADIUS authentication. To use these attributes, you must perform the procedure in the NPS server indicated in the recommended actions field.

You should consider using this procedure under the following condition:

  • You want to use F5 vendor-specific attributes (VSA) when configuring remote RADIUS authentication with a Windows Network Policy Server.

Environment

  • This article applies to BIG-IP 11.x - 17.x.
  • You must have configured the BIG-IP system to use remote RADIUS authentication. For information about configuring remote user authentication, refer to the BIG-IP TMOS: Implementations manual.

    Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

  • You must have administrative access to your BIG-IP system.
  • You must have administrative access to the RADIUS server.
  • You must have the RADIUS dictionary file added to your RADIUS server.
  • You must have the Remote Role Groups configured to use F5 vendor-specific attributes with RADIUS authentication.

            Note: For information about how to configure Remote Role Groups to use F5 vendor-specific attributes with RADIUS authentication refer to K14324: Using F5 vendor-specific attributes with RADIUS authentication

Cause
 None.

Recommended Actions

Configuring the Vendor-Specific Attribute Information in the Network Policy Server
 

Impact of procedure: The following procedure should not have a negative impact on your system.

The following example was taken from a server running Windows Server 2019 Datacenter.
 

1. Open the Network Policy Server inside the Windows Server.

2. Select Network Policies > Click on your network policy or create a new one > Click on Settings > Vendor Specific > Add > Vendor Specific Attribute Information > Add > Enter vendor code: 3375 > Select Yes. It conforms. > Configure Attribute.

3. In the "Configure VSA (RFC Compliant)" window you will have to configure 4 different attributes.

       1. F5-LTM-User-Info-1 Attribute:

           Vendor-assigned attribute number: 12, Attribute format: String, Attribute Value: Remote Role Group's Attribute String configured on the BIG-IP. (For example, if the remote role group on the BIG-IP has an attribute string of F5-LTM-User-Info-1=auditor, the VSA attribute value should be set to auditor)
           Note: For information about User-Role numbers and Vendor-assigned attribute numbers refer to K14324: Using F5 vendor-specific attributes with RADIUS authentication


        2. F5-LTM-User-Role Attribute:
             Vendor-assigned attribute number: 1, Attribute format: Decimal, Attribute Value: Desired User-Role number.

(Example: 0 for Administrator, 80 for Auditor, etc..)

      

        3. F5-LTM-User-Shell Attribute:
             Vendor-assigned attribute number: 5, Attribute format: String, Attribute Value: disable or tmsh
              

        4. F5-LTM-User-Partition:
             Vendor-assigned attribute number: 3, Attribute format: String, Attribute Value: Desired partition.

(Example: Common, All, etc..)
Note: If the BIG-IP only has one partition, this value must be set to Common.
