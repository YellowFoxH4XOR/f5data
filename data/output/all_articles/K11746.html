Known Issue

This is the result of a known issue. Calling the TCP::close iRule command from the CLIENTSSL_CLIENTCERT iRule event may cause TMM to crash and dump core.

F5 Product Development tracked this issue as CR115061 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

You can work around this issue by replacing the TCP::close iRule command with the reject iRule command.
