Description

When  trying to connect to VPN through browser or edge client and not get connected with :

Error  : "Disconnected: Failed to download configuration"

Logterminal.txt (Client machine %temp%) has similar to below log

692,15840,F5LOGVIEWER, 48,,,, current log level = 63
15744,128,HOST, 1, , 1826, CHostCtrl::OnTimer(), TUNNEL_SERVER_READY_CHECK - configuration read timed out
15744,128,HOST, 1, \HostCtrl.h, 1477, CHostCtrl::Failed, Failed to download configuration (error: 0)

Environment

  • BIG-IP APM
  • BIG-IP ASM
  • Network Access 
  • VPN
  • ASM policy on the same Virtual server 

Cause

This could happen due to following reasons (not exhaustive list but most common)  -

  • Security (AWAF) Policy applied on the same VS
  • Antivirus or some firewall or some end point security else installed on the machine which is not allowing it to download
  • Some  other VPN too (like cisco or juniper) installed on the same machine.
  • Network problems (some in-between devices prevent HTTP communication between the client and APM).
  • K000149053: Users may fail to establish VPN tunnels if the sys db variable ipv6.enable is set to a non-default value of "false"


Recommended Actions


  • Remove ASM policy and see if the issue resolved.
  • Set Antivirus/Firewall/Endpoint-Security not to disturb VPN. (Please ask the vendor of those tools about how-to)
  • Remove other VPN app/software
  • Take tcpdump and determine there is no network issue.
  • apply workaround for K000149053
