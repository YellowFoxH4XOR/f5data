Description

When attempting to activate newly purchased add-on licenses (such as Threat Campaigns and IP Intelligence) on a BIG-IP system, users may encounter an "Invalid Key Format" error message. This error typically appears during the license activation process in the Configuration utility and prevents successful activation of the add-on features.

Error message example:

  • "Invalid Key Format: <Reg-Key>"
  • "Registration key is invalid"

Environment

BIG-IP 
Licensing
Add-on license activation

Cause

The "Invalid Key Format" error occurs when an add-on key is entered into the Add-on Key field with an incorrect format.

Note: The format of the BIG-IP add-on registration key is as follows:

AAAAAAA-BBBBBBB

Answer/Recommended Actions

The actions or steps required to address the topic covered in the description.

  1.  Copy the add-on key into a plain text editor (such as Notepad) and verify there are no extra spaces, double dashes (--), hidden or additional characters
  2.  After verifying that the add-on key is in the correct format, you can copy the add-on key from plain text editor into the Big IP GUI and verify that the add-on key is in the correct format.  Proceed with the rest of the license activation steps.
  3. If the issue persists, manually type the 14 character add-on key directly in the Add-on key field and proceed with the rest of the license activation steps.
