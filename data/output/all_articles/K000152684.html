K000152684: LTM Policy insert custom header for all domain hosted by Virtual Server instead for specific one

Type
Support Solution
Published
2025-07-23
Updated
2025-09-03
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000152684

Description

You have created and attached a LTM policy to Virtual Server for inserting custom header to responses, but policy apply header for all domains where you would like to insert headers only for specific domains.

Environment

  • Polices
  • HTTP
  • iRule

Cause

None

Recommended Actions

You can try to use the following iRule instead of Policy to apply the headers only for specific domains:

Important: Please test the iRule before applying it to the production Virtual Servers

when HTTP_REQUEST {
# Save the Host header in a per-connection variable
set req_host [string tolower [HTTP::host]]
}

when HTTP_RESPONSE {
# Access the saved Host header variable
if { [info exists req_host] && ($req_host eq "example.com" || $req_host eq "anotherdomain.com") } {
HTTP::header insert "X-Custom-Header" "YourHeaderValue"
}
}
