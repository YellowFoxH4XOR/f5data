K41271842: Unable to update ASM Signature Error: Failed to mount: '/bin/mount

Type
Support Solution
Published
2021-03-30
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K41271842

Description

Cannot install ASU due to no loop devices.

On occasion the ASM will not be able to update attack signatures and may show errors similar to the following:

[20739]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::Sigfile::Update::store_error_and_die): Failed to mount: '/bin/mount': 512 at /usr/local/share/perl5/F5/ImUtils.pm line 74.
[20739]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::handle_error): Code: 999, Error message = Failed to mount: '/bin/mount': 512 at /usr/local/share/perl5/F5/ImUtils.pm line 74.
[20739]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::log_error_and_rollback): Failed to mount: '/bin/mount': 512

 

Environment

  • BIG-IP 12.*
     

Cause

Bug ID 925357
 

Recommended Actions

Follow workaround of K72133961: Can not install software, md5sum match, Build, version not recognized.
 

Additional Information

ASM will mount the ASU image under /bin/mount to /dev/loop1 -> /dev/loop7
The bellow command run and it shows all 8 devices used for ASU ISO images:

losetup -a
