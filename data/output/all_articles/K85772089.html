Known Issue

Removing a pool from a virtual server does not update its status.

This issue occurs when all of the following conditions are met:

  • You create a pool and assign a monitor to it.
  • The pool goes green (available).
  • You create a virtual server without assigning the pool to it.
  • The virtual server remains blue (unknown).
  • You associate the pool to the virtual server.
  • The virtual server goes green.
  • You remove the pool from the virtual server.
  • The virtual server remains green, even though it should go back to blue.

Impact

The virtual server appears associated with a monitored pool when it is not. This behavior has no functional impact on the virtual server because a virtual server without a pool has no traffic to pass, and associating a pool with the virtual server will reflect the pool status.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Removing a pool from a virtual server does not update the virtual server's status.
