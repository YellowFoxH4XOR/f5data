Description

The Edge client shows as stuck in the "connecting" status, even after the VPN tunnel is established. The latest version (7214) is supported for Monterey

Environment

Relevant environmental factors specific to the topic

  • Mac OS 12 Monterey
  • Using Edge client to establish a VPN connection
  • using a Proxy configuration

Cause

This is being tracked internally as ID 1071989. An EHF fix is available. This is similar to the older problem K15080655 and updates K23237239
Preliminary investigation has revealed that if another process running on the client system attempts to connect to 127.0.0.1:4444 using TLS, the svpn process will not report the connection status correctly. This seems to be related to the proxy configuration in this case.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Open a ticket and request and Engineering Hotfix APMClient build 5434
  2. This EHF should be superseded by the next GA APMClients release
