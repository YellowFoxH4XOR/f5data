Description

I want to configure an AWS TGW and I want to know if there is any special configuration needed to advertise a custom VIP via BGP to on-premises sites and other VPC spokes attached to the TGW? Site?

Environment

  • Customer Edge
  • AWS TGW

Answer/Recommended Actions

 Yes, this can be done, there is a setting within AWS for route propagation on the routing table with TGW/VPC. It can be found under VPC > Route Tables > Your route table

None
