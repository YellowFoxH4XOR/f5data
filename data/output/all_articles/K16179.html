Known Issue

An invalid or corrupted encrypted password entry in a monitor definition causes the bigd process to continuously restart.

This issue occurs when all of the following conditions are met:

  • You configure a monitor with a username and password.
  • The encrypted password entry in the configuration file becomes corrupt, or is manually edited and no longer valid.
  • You load the affected configuration file.

Impact

The BIG-IP system will not perform health monitoring when the bigd process is restarting. As a result, the BIG-IP system may not collect information used for dynamic load balancing decisions and send traffic to nodes that are not responding.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H501811 on the Diagnostics > Identified > Medium screen.
  • The bigd service continuously restarts.
  • The system logs an error message to the /var/log/ltm file that appears similar to the following example:

    Fatal error: An unexpected failure occurred while performing an OpenSSL cryptography operation. Root error: 10219:error:0606506D:digital envelope routines:EVP_DecryptFinal_ex:wrong final block length:evp_enc.c:323:

Workaround

To work around or recover from this issue, you can use the BIG-IP Configuration utility to update the password within the affected monitor definition.

Impact of workaround: Performing the recommended workaround should not have a negative impact on your system.
