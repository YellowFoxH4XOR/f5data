Topic

Microsoft has released multiple antivirus products under different names over time, leading to some confusion. For systems running Windows 7 that are not able to upgrade to Windows 10, Windows Defender only includes anti-spyware capability. This means that Windows Defender is detected by the BIG-IP APM system's endpoint protection feature only as an anti-spyware product, not as an antivirus product.

To achieve full device protection on older systems running Windows 7, Microsoft recommends using Microsoft Security Essentials.

For more information, refer to Security Essentials Download.
