Description

If you have PFX certificates and want to use them with NGINX Plus, you have to convert them to a PEM format. This is because NGINX only supports a PEM format for certificates.

Environment

  • NGINX Plus.
  • OpenSSL command-line tool.
  • Pre-generated PFX (PKCS#12) certificates.

Cause

  • NGINX Plus natively supports only a PEM format for certificates.

Answer/Recommended Actions

You can use the OpenSSL command-line tool to convert a PFX certificate to a PEM format.

For example:

  • Get a PEM certificate:
openssl pkcs12 -in example.pfx -out example.pem -nokeys
  • Get a PEM private key:
openssl pkcs12 -in example.pfx -out example.p.key.pem -nocerts
  • Remove the KEY password/passphrase (optional):
openssl rsa -in example.p.key.pem -out example.key.pem

Once the PEM certificates have been generated, you can use them with the "ssl_certificate" and "ssl_certificate_key" directives as usual.

Additional Information

  • Password-protected PEM private keys can be managed securely using the "ssl_password_file" directive.
