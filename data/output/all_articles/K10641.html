K10641: The Single Sign-On feature with Radius authentication requires the user to enter a display name when accessing email

Type
Knowledge
Published
2009-10-28
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 6.0.3
Source
https://my.f5.com/manage/s/article/K10641

Topic

Users accessing their email will be prompted to enter their display name even if the Single Sign-On feature has been configured using Radius authentication. Radius does not pass an attribute for the display name that the FirePass controller can cache. FirePass will cache the user's username and password. Therefore, once the user enters their display name, they will have access to their email.

To avoid requiring users to manually enter their display name, you can change the Single Sign-On feature to authenticate against Active Directory.
