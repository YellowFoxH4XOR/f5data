Description

This article covers the qkview file that is visible within Last Generated Snapshot section under System > Support within Configuration Utility, what it represents and how to prevent the numerous qkview files being generated from utilizing disk space on the system. 

Environment

  • Qkview files generated via GUI or CLI

Cause

  • Generating qkview from System > Support section via GUI eventually saves the file under /shared/support/ directory. You will temporarily see the file with ".qkview" extension being created within /shared/tmp/ but, once everything is done, the file gets saved in /shared/support/ folder.
  • Generating qkview from CLI saves the file within /shared/tmp/ directory. It never saves the file under /shared/support/ folder.
  • When generating a qkview from GUI as well as from CLI, you will only see the last generated qkview within Last Generated Snapshot section. The other older file(s) can be retrieved via SCP access to the device, if necessary.

Recommended Actions

For example, if a qkview is generated via GUI and then the CLI, then the timestamp of the Last Generated Snapshot shows the qkview that was generated via CLI. Here is what happens when moving or removing the files from any one of the directories where these files get stored:

  • When moving the qkview file from /shared/tmp/ to another directory or delete this file, you would witness a qkview download taking place via GUI. This was because a file still existed within /shared/support/ directory.
  • Now, if you also move the file from /shared/support/ to another directory or delete this file, you will no longer saw the download as taking place via the GUI.

The best practice recommendation to prevent qkview files from utilizing disk space is to remove gzip compressed files (.tar.gz extension) from /shared/support/ and remove any files with .qkview extension from /shared/tmp/ directory. Following this, any attempts to download the file via GUI will be futile. The file that continues to show up under Last Generated Snapshot section within GUI will need to be deleted manually.
