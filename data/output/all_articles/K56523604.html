Description
Unable to login into BIG-IP console via Console or SSH. An error similar to this one is shown:

BIG-IP <version>
Kernel 3.10.0-862.14.4.el7.ve.x86_64 on an x86_64
<Hostname> login: <username>
login: PAM failure, aborting: Critical error - immediate abort

Environment

  • BIG-IP
  • Unable to login via SSH or Console
  • In some cases, all services hosted on the device are down
Cause
This symptom is reason to suspect a compromised system. It is consistent with attacks which try to wipe the hard drive.

Recommended Actions
Review K11438344: Considerations and guidance when you suspect a security compromise on a BIG-IP system and take appropriate action. This includes discussing next steps with your security team and a clean install. You may restore from a known-good configuration backup if available.

F5 recommends installing a current release that includes the most recent fixes and security patches when performing a clean install. For information about releases with the latest fixes and security patches, refer to the list of articles in the Related Content section of this article. We also provide detailed guidance for securing BIG-IP and strongly advise customers never to expose their BIG-IP management interface to the public internet and to ensure the appropriate controls are in place to limit access K13092: Overview of securing access to the BIG-IP system.
