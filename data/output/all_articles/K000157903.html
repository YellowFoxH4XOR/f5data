K000157903: Uploaded wrong F5OS image to rSeries but can't remove it with 'system image remove' command

Type
Support Solution
Published
2025-11-19
Updated
2025-11-19
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.5.X, 1.8.3, 1.8.0, 1.5.4, 1.5.3, 1.5.2, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000157903

Description

Uploaded an R2R4 image to an R5R10 system (or vice versa), but cannot remove it with system image remove command.

Environment

  • rSeries
  • Image import

Cause

The system image remove command can only be used with images that have been imported by the software management subsystem.

Recommended Actions

If the wrong image variant has been uploaded, it will not be imported and the file can be deleted from the filesystem directly.

For example:

(/var/log/sw-mgmt.debug)

DEBUG: VERSION info {'date': '2025-10-09', 'platform': 'R2R4', 'status': 'not_imported', 'source': '/var/export/chassis/import/iso/F5OS-A-1.5.4-37447.R2R4.LTS.iso', 'type': 'lts'}
ERROR: sw-mgmt: priority=error msgid=0x3501000000000099 msg=Unsupported platform: R2R4

(Delete image manually)

rm /var/import/staging/F5OS-A-1.5.4-37447.R2R4.LTS.iso
