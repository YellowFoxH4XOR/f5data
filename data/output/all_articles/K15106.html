Topic

In BIG-IQ 6.x and later, BIG-IQ software does not use cumulative hotfixes. Beginning with these versions, product defects and security fixes are included in a full release referred to as a point release; however, these versions are still eligible to receive engineering hotfixes. Point releases are identified by a fourth version element. For information, refer to K8986: F5 product support policies.

You should consider using these procedures under the following condition:

  • You want to install a hotfix on a BIG-IQ system using either the BIG-IQ user interface or TMOS Shell (tmsh).

Description

F5 periodically releases cumulative hotfixes that contain fixes for software defects that may need to be addressed between minor or maintenance BIG-IQ software releases. You can download cumulative hotfixes from the F5 Downloads site.

Note: This article also applies to engineering hotfixes, which are provided only through a support case. For information about whether a specific engineering hotfix is included in the next cumulative hotfix, contact F5 Support and reference the appropriate case number.

Considerations when managing BIG-IQ hotfixes:

  • You can use the BIG-IQ user interface or tmsh to install hotfixes and perform the following hotfix-related tasks:
     
    •   Import hotfix files to an image library on the BIG-IQ system
    •   Display the version and build of hotfix images
    •   Install hotfix images on an inactive boot location, when needed

  • When installing a hotfix, you must run the hotfix installation from an active boot location and specify an inactive boot location as the target installation location. This allows you to prepare an inactive boot location in advance, by installing the necessary software image and hotfix, and then boot to the new location when you are ready to run the configuration. For example, if the BIG-IQ system is running 4.3.0 on the active boot location (for example, HD1.1), and you want to install HF1, prepare an inactive boot location as the target installation location (for example, HD1.2). If the inactive boot location is running an older software version, such as 4.2.0, the software update will first install the base version 4.3.0 ISO image to the inactive boot location, and then install HF1. Therefore, it is essential to have the base version ISO available in the image library.

  • The configuration and license from the current boot location is copied to the target installation location. During the maintenance window, you can then designate HD1.2 as the active boot location and boot the system to it. If you need to revert to the previous hotfix version, you can boot to the formerly-active boot location that does not contain the hotfix (HD1.1 in this example).
     
  • Hotfixes are cumulative. Every time a cumulative hotfix is produced, all packages from previously-generated hotfixes for that product on that branch are automatically included in the cumulative hotfix. The most recent hotfix for each product contains all previously-issued hotfixes for that product.
     
  • You must manage hotfixes on each member of a redundant device group. A configuration synchronization (ConfigSync) does not synchronize a hotfix to a redundant system.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have access to the BIG-IQ system using an Administrator role credential.
  • You have root user access to tmsh.

Procedures

Use one of the following procedures to install or manage BIG-IQ hotfixes:

  • Determine and download the hotfix file
  • Install a hotfix image using the BIG-IQ user interface
  • Install a hotfix image using the BIG-IQ command line

Determine and download the hotfix file

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

To determine the appropriate hotfix to install on the system, you should review the latest available hotfixes for corresponding BIG-IQ releases by going to the F5 Downloads site or referring to K15113: BIG-IQ hotfix and point release matrix. You should download the hotfix related files to your local workstation. For more information, refer to K167: Downloading software and firmware from F5.

When preparing to install a hotfix image on the BIG-IQ system, F5 recommends that you download the following three types of files for each hotfix:

  • ISO file - BIG-IQ hotfix files are ISO archive files. For example, a BIG-IQ hotfix file may appear similar to the following:

    Hotfix-BIG-IQ-4.3.0-3880.0-HF1.iso

  • MD5 file - The MD5 file for checking the integrity of the ISO file. For example, a BIG-IQ hotfix MD5 file may appear similar to the following:

    Hotfix-BIG-IQ-4.3.0-3880.0-HF1.iso.md5

  • Hotfix release note - The ISO installation file has a corresponding hotfix release note. You should always read the hotfix release note before you install a hotfix. This file contains important notes about each particular hotfix. For example, a BIG-IQ hotfix release note file may appear similar to the following:

    Hotfix-BIG-IQ-4.3.0-3880.0-HF1.htm

Install a hotfix image using the BIG-IQ user interface

You can use the following procedure to upload and install the hotfix image using the BIG-IQ user interface.

Impact of procedure: If you reboot the system after installing the hotfix, the function of the BIG-IQ system may be disrupted. F5 recommends that you perform this procedure during a scheduled maintenance window.

BIG-IQ 5.2.0 and later

  1. Log in to the BIG-IQ user interface using the Administrator role credentials.
  2. Select the System tab.
  3. In the left column, select Software Management.
  4. Under Software Management, select Images.
  5. Select Upload Image and choose the appropriate hotfix located on your local workstation.
  6. After the hotfix has successfully uploaded, ensure the Verification Status is Verified before continuing.
  7. Under File Name, select the new hotfix image hyperlink.
  8. Under Software Management, select Installations.
  9. Select Upgrade.
  10. From the Software Image menu, select the newly uploaded hotfix.
  11. From the Target Volume option, select the appropriate boot partition to install the hotfix.
  12. Optional: To reboot the BIG-IQ system into the newly hotfixed partition, select the Reboot into Target Volume check box.
  13. Optional: To make a backup of the BIG-IQ system configuration prior to upgrading, select the Back up the BIG-IQ system before upgrade check box. 
  14. Select Install.
  15. Select Continue from the pop-up window to confirm the hotfix installation.
  16. An additional pop-up window displays the installation progress. Select Close after the installation has completed.
  17. To verify the hotfix has been installed, go to This Device > General Properties.
  18. Under Boot Locations, verify the hotfix has been installed to the correct partition.
  19. To reboot into the newly hotfixed partition, select Edit.
  20. Under Localhost Volumes, use the Boot Locations menu to choose the newly hotfixed partition. 
  21. Select Reboot.
  22. When prompted to reboot the device, select Reboot Now.

BIG-IQ 5.0.0 - 5.1.0 

  1. Log in to the BIG-IQ user interface using the Administrator role credentials.
  2. Select System Management.
  3. Select Inventory.
  4. Select Software Management.
  5. Select Available Images.
  6. Select Upload Image and choose the appropriate hotfix located on your local workstation.
  7. After the hotfix has successfully uploaded, ensure the Verification Status is Verified before continuing.
  8. Select BIG-IQ HA.
  9. Under Device Name, select the hyperlink with the domain name of the local BIG-IQ system.
  10. Select Software Version.
  11. Select Update.
  12. From the Software Image menu, select the uploaded hotfix.
  13. From the Target Volume option, select the appropriate boot partition to install the hotfix.
  14. Optional: If you wish to reboot the BIG-IQ system into the newly hotfixed partition, select the Reboot into Target Volume check box.
  15. Select Apply.
    After the hotfix installation has completed, the BIG-IQ system returns to the Software Version page.
  16. To verify the hotfix has been installed, go to Software Images.
  17. Select Installed Images and ensure that the newly hotfixed partition has the same Build number as the uploaded hotfix file.

BIG-IQ 4.4.0 - 4.6.0 

  1. Log in to the BIG-IQ user interface using the Administrator role credentials.
  2. Select System.
  3. Perform the following steps for your version:

    BIG-IQ 4.5.0 and 4.6.0:

        a. Select Configuration.

        b. Under BIG-IQ Systems, select HA Peer Group to expand the menu and select localhost

    BIG-IQ 4.4.0:

        a. Select Configuration.

        b. Under BIG-IQ Systems, select Management Group to expand the menu and select localhost.

  4. Select the gear symbol for localhost and select Properties.
  5. Select the Software Upgrade tab.
  6. Select Update.
  7. From the Software Image menu, select an image to be installed.
  8. Select a target volume from the Install Location menu.
  9. Optional: If you want to reboot to the target installation location after the hotfix is installed, select Reboot After Live Install.
  10. Optional: If you want to set the default boot volume to the hotfix target installation location, select Set Default Boot Location.
  11. To start the hotfix installation, select Apply.
  12. If you selected the Reboot After Install action in step 6, a pop-up window asks for confirmation to continue. To begin the installation, select OK, or to modify your selections, select Cancel.

The interface provides the progress of the update installation process. When the system completes the update installation, the system displays Install complete. If you have selected the Reboot After Install action in step 9, the system reboots immediately after completing the hotfix installation.

Install a hotfix image using the BIG-IQ command line

You can use the following procedure to upload and install the hotfix image using tmsh.

Impact of procedure: If you reboot the system after installing the hotfix, the function of the BIG-IQ system may be disrupted. F5 recommends that you perform this procedure during a scheduled maintenance window.

  1. Copy the downloaded ISO and MD5 files to the BIG-IQ system's /shared/images directory. For more information, refer to K175: Transferring files to or from an F5 system.
  2. Log in to the BIG-IQ command line prompt.
  3. Change directories to the /shared/images directory by entering the following command:

    cd /shared/images

  4. To read the MD5 checksum and check the related ISO file, use the following command syntax:

    md5sum -c <Hotfix-MD5-Filename>

    For example:

    md5sum -c Hotfix-BIG-IQ-4.3.0-3880.0-HF1.iso.md5

  5. Observe the output from the md5sum command:
     
    • If the hotfix file is verified with a correct checksum, the command returns an output that appears similar to the following example:

      Hotfix-BIG-IQ-4.3.0-3880.0-HF1.iso: OK

    • If the hotfix file is verified with an incorrect checksum, the command returns an error message with output that appears similar to the following example:

      Hotfix-BIG-IQ-4.3.0-3880.0-HF1.iso: FAILED
      md5sum: WARNING: 1 of 1 computed checksum did NOT match

      If you have an incorrect checksum, you should download the hotfix file and the MD5 checksum file to the BIG-IQ system again and repeat this verification procedure.

  6. Log in to tmsh by entering the following command:

    tmsh

     
  7. To install the hotfix image, use the following command syntax:

    install sys software hotfix <Hotfix_Name>.iso volume <Volume_Name>

    For example, to install Hotfix-BIG-IQ-4.3.0-3880.0-HF1.iso on HD1.2, enter the following command:

    install sys software hotfix Hotfix-BIG-IQ-4.3.0-3880.0-HF1.iso volume HD1.2

  8. To show the status of the hotfix installation, enter the following command:

    show sys software status

    For example, the following output indicates that hotfix build 3880.0 is installing on volume HD1.2:

    ---------------------------------------------------------------
    Sys::Software Status
    Volume  Product  Version   Build  Active                 Status
    ---------------------------------------------------------------
    HD1.1    BIG-IQ    4.3.0  3860.0     yes               complete
    HD1.2    BIG-IQ    4.3.0  3880.0      no  installing 34.000 pct

  9. To boot the BIG-IQ system to a desired volume, or software image, use the following command syntax:

    reboot volume <volume_number>

    For example, to boot the BIG-IQ system to volume HD1.2, enter the following command:

    reboot volume HD1.2
