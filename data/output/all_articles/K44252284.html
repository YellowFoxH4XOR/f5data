K44252284: Error message in browser: You are not securely connected to this site

Source

Description
The SSL profile was updated with a new CA, after the update the client see the error message on the browser: You are not securely connected to this site

From capture, it was found that the client sent a Certificate Unknown alert

10.X.X.X 57173 10.X.X.X 443 TLSv1.2 820 IN s1/tmm0 : Client Hello
10.X.X.X 443 10.X.X.X 57173 TLSv1.2 450 OUT s1/tmm0 : Server Hello, Change Cipher Spec, Encrypted Handshake Message
10.X.X.X 57173 10.X.X.X 443 TLSv1.2 310 IN s1/tmm0 : Alert (Level: Fatal, Description: Certificate Unknown)

Environment

  • BIG-IP LTM
  • SSL profile with a new certificate


Cause
Subject Alternative Name (SAN) extension is missing in the certificate.


Recommended Actions

  1. Take a capture to confirm the correct TLS flow
  2. Verify that the certificate file contains all the mandatory certificate extensions
  3. Generate a new CA including SAN extension and load it to the SSL profile.


Additional Information
None.
