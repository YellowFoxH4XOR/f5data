Description

After successfully publishing an instance group's NGINX configuration, one or more NGINX configuration files are not appearing on one or more instance group members.

Environment

NGINX Instance Manager (NIM)

Cause

This issue may occur when the missing NGINX configuration files have been previously removed directly from the instance group member or members.

Recommended Actions

This issue can be remedied by implementing one of the following procedures:

  • On NIM, create a change, such as a comment, in each of the instance group's NGINX configuration files that are missing on the affected members and Publish the instance group NGINX configuration
  • Restart NIM services: 
sudo systemctl restart nms

Additional Information

NIM will publish instance group NGINX configuration files, to instance group members, only if the files have been newly created or updated with changes. Note, the first Publish of instance group NGINX configuration after restarting NIM services will result in all instance group NGINX configuration files pushed to the instance group members.
