Known Issue

The FTP health monitor password is not encrypted on the BIG-IP system. For example, if you create an FTP monitor and configure a username and password for authentication, the BIG-IP system saves the password in plain text in the bigip.conf file.

Impact

The FTP monitor password is saved in plain text and is not secure.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You may observe the FTP monitor password when viewing the /config/bigip.conf file.
