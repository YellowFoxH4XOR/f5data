Description

Unable to access  a web page through a Virtual Server but it's working fine when directly connecting to the pool member.

The backend server is operating on port 443 (HTTPS) and virtual server is configured with SSL profiles NOT attached

Environment

  • BIG-IP LTM 
  • Profiles
  • SSL reencryption not configured 

Cause

HTTP profile attached to the VIP.

Recommended Actions

Remove the HTTP profile from the Virtual Server as it might cause problems with forwarding the client hello to the Pool member as the pool member is operating on HTTPS protocol.

None.
