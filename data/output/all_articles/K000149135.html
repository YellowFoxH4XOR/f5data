Description

MFA is not presently supported without the use of additional tools on the BIG-IP admin GUI logon page.

Environment

  • BIG-IP LTM
  • GUI (Configuration utility)
  • Admin authentication

Cause

MFA is not supported out of the box on the BIG-IP admin GUI login page.

Recommended Actions

None

Additional Information

  1. For more information on using APM as a remote auth source, refer to https://techdocs.f5.com/en-us/bigip-15-0-0/big-ip-local-traffic-manager-implementations/implementing-apm-system-authentication.html .
    1. On the BIG-IP Configuration utility, go to System > Users > Authentication. 
    2. Select Change.
    3. Select Remote - APM based.
    4. Select + to create a new Access Profile.
    5. Select an appropriate Authentication Type and proceed to configure your desired authentication.
      A sample of how to configure APM for MFA with active directory is here ( Create an MFA Auth + OTP access policy).
      Note: This procedure creates a System Authentication type access profile while the access profile created in the video is of the type All.
      Perform the procedure to create an access profile (System Authentication) then use the access profile in the video as a sample and example to create your desired authentication.
      Another sample with a 3rd party product is here: https://www.miniorange.com/iam/integrations/f5-big-ip-apm-multi-factor-authentication-mfa

The configuration from the APM side should be similar to the above no matter which 3rd party product is being used for MFA.
