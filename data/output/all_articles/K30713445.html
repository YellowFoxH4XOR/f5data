Description

There is BIG-IP APM Client Certificate Authentication agent exists. And some APM Administrators may want to retrieve the client's certificate fingerprint from session variable value (and then, for example, confirm if it's legitimate and correct or if it matches with some correct client certificates fingerprints database values). And this procedure describes how to get the certificate fingerprint value in iRule from session variable value.

Environment

  • APM
  • Client Certificate Authentication
  • Certificate fingerprint (thumbprint)
  • iRule

Cause

None

Recommended Actions

  • Get the expected client's certificate fingerprint 
# openssl x509 -in client_cert_auth_user.crt -noout -fingerprint
SHA1 Fingerprint=3B:4A:73:12:DA:4A:E4:E2:13:57:B3:45:99:F8:A9:16:38:D3:54:5B
  • Configure the testing virtual server with apm profile and irule. For example:
ltm virtual vs_client_cert_auth {
[...]
    profiles {
        ap_client-cert_insp_auth { } <<< (!) the Access-Profile with Client Cert Auth (mode require) agent plus Irule Event Agent 'HASH'
        cs_profile_client_cert { <<< (!) the client-ssl profile with the corresponding 'peer-cert-mode require'
            context clientside
        }
[...]
    rules {
        case1-7772780341v2 <<< (!) the irule logic which is invoked for VPE's Irule Event Agent 'HASH'
    }
[...]

ltm profile client-ssl cs_profile_client_cert {
    app-service none
    ca-file client_cert_authCA
    cert-key-chain {
        client_cert_auth_bigip_0 {
            cert client_cert_auth_bigip
            key client_cert_auth_bigip
        }
    }
    defaults-from clientssl
    inherit-ca-certkeychain true
    inherit-certkeychain false
    peer-cert-mode require <<<<<<<<<<<<<<<<<<<<<< (!)
}
  • In VPE,  for example, there is the below sequence of agents created:
Start -> Client Cert Auth agent -> Irule Event (HASH) agent -> Allow
  • The irule syntax
# tmsh list ltm rule irule-article
ltm rule irule-article {
when ACCESS_POLICY_AGENT_EVENT {
switch [ACCESS::policy agent_id] {
        "HASH" {
# getting the whole cert in PEM format from session.ssl.cert.whole which is base64 encoded
  set wholecertpem [ACCESS::session data get "session.ssl.cert.whole"]
  #log local0. $wholecertpem

# removing PEM format related  '-----BEGIN CERTIFICATE-----'/'-----END CERTIFICATE-----'
  set wholecertpem [string map {"-----BEGIN CERTIFICATE-----" ""} $wholecertpem]
  set wholecertpem [string map {"-----END CERTIFICATE-----" ""} $wholecertpem]

# removing end of line character '\n' from certificate string
  set wholecertpem [string map {"\n" ""} $wholecertpem]
  #log local0. $wholecertpem

# bas64 decoding the certificate string
  set wholecertbin [b64decode $wholecertpem]

# getting sha1 digest from wholecertbin variable which is the result of apm's session.ssl.cert.whole
  binary scan [sha1 $wholecertbin] H* APMthumbprint
  log local0. "APM thumbprint: $APMthumbprint"
}
}
}
}
  • As the result, in LTM Logs, you should get something similar to
# tailf /var/log/ltm | grep 'irule-article'
Nov  4 12:07:37 bigip.local info tmm1[5238]: Rule /Common/irule-article <ACCESS_POLICY_AGENT_EVENT>: APM thumbprint: 3b4a7312da4ae4e21357b34599f8a91638d3545b
