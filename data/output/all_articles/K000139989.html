K000139989: Portal Access: blank page shown for one of the link in the portal after changing rewrite profile to modern type.

Description

Portal Access issue.

Log in to the portal (no sso) works, and first page display ok. However from there try to go to one of the option, it gives blank page.

This issue started happen after changing rewrite profile to modern type following K000130439: Configuring the Rewrite Control List (RCL) to address ES6/7/next compatibility for Portal resource,

 

Environment

  • BIG-IP APM
  • Portal Access
  • Modern type of rewrite profile
  • blank page from the portal page

 

Cause

  • The portal's one of the link is inconpatible with the modern type rewrite profile.

 

Recommended Actions

  • Add the portal to bypass list in modern rewrite profile
