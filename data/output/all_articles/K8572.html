Known Issue

This is the result of a known issue. Running the sys-icheck system integrity check after upgrading to BIG-IP WebAccelerator version 9.4.4 may produce an error message in the /config/wa/pvsystem.conf.tmpl file that appears similar to the following example: 

ERROR: S.5.....   /config/wa/pvsystem.conf.tmpl

The 9.4.4 installation spec file does not list the file as configurable; therefore, the integrity check for the file will fail if the file has been modified. This error message is not indicative of a failure.

F5 Networks Product Development is tracking this issue as CR97273.
