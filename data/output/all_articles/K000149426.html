K000149426: How to get a packet capture of F5OS-A REST API

Type
Support Solution
Published
2025-01-23
Updated
2025-03-10
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.8.0
Source
https://my.f5.com/manage/s/article/K000149426

Description

A way to determine REST API calls and responses for F5OS-A only.

Environment

  • F5OS-A
  • rSeries
  • REST API

Cause

To gather the commands sent to the F5OS-A REST API in a packet trace

Recommended Actions

  1. Login to the appliance with the root user
  2. From bash, start the packet capture with the following command
    nsenter -t $(pgrep httpd | head -1) -n tcpdump -i lo -nn 'port 8008' -w /root/rest-api.pcap
  3.  Run you REST command
  4. Stop the packet trace by pressing control+c

Additional Information

This is only for F5OS-A rSeries. This will not work for F5OS-C VELOS systems.
