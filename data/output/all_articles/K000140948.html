Description

An HA pair of BIG-IPs in Active/Standby goes to Active/Active after a device certificate expiration

Environment

  • Expired Cert

  • HA Pair
  • failover.secure enabled

Cause

If the failover.secure DB key is enabled, failover traffic between devices is encrypted using DTLS and authenticated using the device trust certificates.  As a result, if one of those certificates is expired, the DTLS communication will fail and both devices will not see the other as available, so each will go active.

Recommended Actions

Options, one of next:

Renew certificates by following K47052252: Procedure to renew Device Trust Certificates on BIG-IP system

Disable secure.failover by running "tmsh modify sys db failover.secure value disable"
