Known Issue

This is the result of a known issue. Setting connection limits on pool members or nodes may cause the mcpd process to leak file descriptors.

When this issue occurs, the following error message is recorded in the /var/log/ltm file:

emerg mcpd[2317]: 0107094e:0: File cache: fatal error (directory traversal, can't open directory (/var/db/.fc/) Too many open files) (FileCache.cpp:182)

As a result, mcpd may restart or produce a core file, causing disruption to traffic.

F5 Product Development tracked this issue as CR104068 and it was fixed in BIG-IP version 10.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue has been fixed in hotfix BIGIP-9.6.1-HF2, which has been issued for BIG-IP version 9.6.1, for the BIG-IP 9.6 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
