Topic

This article provides an overview of BIG-IP AFM DoS vectors and settings.

Description

BIG-IP AFM DoS vector settings

  • Attack Type is the name of the attack vector.
  • Type specifies the area to which the attack vector applies.
  • State specifies how to enforce protection for the attack type: Mitigate (watch, learn, alert, and mitigate), Detect-Only (watch, learn, and alert), Learn-Only (collect stats, no mitigation), or Disabled (no stat collection, no mitigation). Choosing a state, if available, determines which detection settings are displayed.
  • Threshold Mode specifies how thresholds are set for this vector. The available options are the following:

    Note: F5 does not recommend using the Fully Automatic setting too soon after installation. Automatic thresholds require some historical data to work properly.

    • Fully Automatic implements automatic thresholds and mitigates DDoS attacks based on server stress. It simplifies the settings for DoS vectors by allowing the system to adjust typical DoS vector levels over time and adjusting the sensitivity of the detection and rate limiting for that vector automatically. Attack Floor EPS and Attack Ceiling EPS are configured for auto thresholds. If the server is not stressed, packets are not dropped.
    • Auto Detection/Multiplier Based Mitigation implements thresholds and mitigates DDoS attacks based on the specified Mitigation Multiplier. The system uses the value to calculate the rate limit thresholds and mitigates the attack vector if traffic reaches the threshold.
    • Manual Detection/Auto-Mitigation allows you to set thresholds manually based on your experience with the network systems you are protecting or based on using simulated automatic thresholds. However, the system also automatically examines server stress, and mitigates the attack vector if the server is stressed.
    • Fully Manual allows you to configure parameters for DoS vector detection and rate limiting manually. The system mitigates the attack vector based on the threshold values you set.
  • Detection EPS specifies how many packets per second the system must discover in traffic in order to detect this attack.
  • Detection % specifies the threshold percent the system must discover in traffic in order to detect this attack.
  • Mitigation EPS specifies the maximum number of this type of packet per second the system allows for a vector. The system drops packets once the traffic level exceeds the rate limit.
  • Bad Actor Detection specifies that Bad Actor detection is enabled. This section appears only for non-error packets and non-sweep/flood packets. Bad actor detection allows automatic detection, logging, and rate limiting of specific IP addresses that appear to be the source of an attack, based on criteria you configure.
  • Hardware Acceleration specifies if the attack vector utilizes the ePVA/sPVA.
  • Drop All The BIG-IP system drops some bad or malformed type packets in DoS vectors regardless of Mitigation EPS Threshold setting.
  • Additional Information includes information specific to the security vector.
