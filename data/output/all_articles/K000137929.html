Description

If you wish to mitigate Apache Struts CVE-2023-50164 in your environment, the following document describes how to do so using F5 products and services such as BIG-IP Advanced WAF, F5 Distributed Cloud and F5 Silverline WAF.
Note: For details of any impact to F5 products or services, see K000137931: Apache Struts vulnerability CVE-2023-50164

Environment

  • BIG-IP Advanced WAF (ASM) deployment with
    • Virtual Server proxying traffic to a system vulnerable to CVE-2023-50164
    • ASM policy associated with the Virtual Server
  • Or F5 Distributed Cloud Web App Firewall/WAAP
  • Or F5 Silverline WAF

Cause

None

Recommended Actions

F5 products and services protect against CVE-2023-50164 via Path Traversal signatures including the following signature which should be enabled in any security policies:

200007016: Directory Traversal attempt "../" (Parameter)


BIG-IP Advanced WAF / BIG-IP ASM

For full instructions, see K000137924: Mitigating CVE-2023-50164 with BIG-IP ASM / Advanced WAF. You can follow these instructions to enable relevant Path Traversal signatures in your security policies.


F5 Distributed Cloud App Firewall

In order to protect the pool members against CVE-2023-50164, F5 Distributed Cloud App Firewall customers should ensure their App Firewall configuration is set to include ‘Medium and High Accuracy Signatures’, which is the default configuration, and ensure that signature ID 200007016 is not skipped in any WAF exclusion rules or Service Policies.


F5 Silverline WAF

F5 Silverline WAF customers are protected by default but can contact the SOC in the event of any queries.


NGINX App Protect

For full instructions, see K000137930: NGINX App Protect signatures to block CVE-2023-50164 . You can follow these instructions to enable relevant Path Traversal signatures in your security policies.
