K40653497: Disabling Splunk processes in SDC systems when TDR or Trace function is not in use

Type
Support Solution
Published
2022-08-15
Updated
2024-10-01
Applies to
  • Traffix SDC: 5.2.X, 5.2.0, 5.1.X, 5.1.0
Source
https://my.f5.com/manage/s/article/K40653497

Description

  • Disabling Splunk processes in SDC systems

Environment

  • Traffix SDC 5.x
  • CF 29 and below
  • Splunk
  • TDR and Trace features

Cause

Splunk processes can overutilize the SDC resources. As there is no plan to use TDR or Trace function and Splunk process may be disabled.

Recommended Actions

These are the steps to disable splunk :

1. Go to the folder monit template in the salt directory.

[root@SDC01 monit]# pwd
/srv/salt/5.1_21-2/monit

2. Comment out the template of the splunk process

[root@SDC01 monit]# cat monit.template.splunkforwarder
{% import 'monitVars.sls' as vars with context  %}
{# <--multi-line comment
check process {{vars.nodeId}} with pidfile /dev/shm/splunkforwarder.pid
    mode active
    start program = "/bin/bash -c '{{vars.componentPath}}/bin/traffix_restart_snmptrap {{instanceName}} -d {{trapDest}} -s {{vars.nodeId}} -t sdcProcessRestart -o {{hostName}} -l {{siteName}} -c splunk;{{vars.componentPath}}/bin/traffix_splunkforwarder_init start'" with timeout 10 seconds
    stop program  = "{{vars.componentPath}}/bin/traffix_splunkforwarder_init stop" with timeout 200 seconds
#} <--multi-line comment

3. Next, push the splunk to the minion nodes. Note that in this example I only pushed it to minion node SDC01, so you need to do this in all your minion nodes that have splunk running.

[root@SDC01 monit]# salt 'SDC01*' state.sls splunk

4. Verify the splunk process monit script is empty.

[root@SDC01 monit]# cat /etc/monit.d/monit.splunkforwarder

<empty>

5. Monit summary will show no more splunk forwarder process.

[root@SDC01 monit]# monit summary

6. Kill the current running splunk process.

[root@SDC01 monit]# ps -ef | grep splunk
root      2660     1  0 May29 ?        00:42:25 splunkd -p 8089 start
root      2666  2660  0 May29 ?        00:00:00 [splunkd pid=2660] splunkd -p 8089 start [process-runner]

[root@SDC01 monit]# kill 2660

[root@SDC01 monit]# ps -ef | grep splunk
root     25754 31326  0 18:41 pts/0    00:00:00 grep splunk

7. Since you have commented out the script that monit uses to auto start the splunk process it will no longer be started.

8. You will notice that in the other node/s that you have not run this, the splunkd still exists and if you kill the process monit will still bring it back.
