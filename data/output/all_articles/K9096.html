K9096: Custom blocking response page character encoding must match the Application Language for the web application

Topic

A custom blocking response page allows an administrator to specify the content of the response that the BIG-IP ASM system sends to the user when the security policy blocks a client request.

If you configure a custom blocking page for your policy, and the Application Language for your web application does not match the character encoding of the uploaded file, the blocking page may be garbled during the upload and conversion process.

For example, uploading a Shift-JIS encoded blocking response page to a web application for which the Application Language is set to Unicode (utf-8) will result in an unreadable blocking response page.

Note: This behavior is by design, and is not the result of a software defect.

To ensure that the blocking response page is not garbled during the upload process, verify that the character encoding of the blocking page you want to use matches the Application Language of the web application.
