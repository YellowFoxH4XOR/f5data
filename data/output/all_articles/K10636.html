Topic

This article provides an index of articles with recommendations for users to understand the See SOL#10636 error message in the log file or console screen with regard to a disk full error.

You observe the See SOL#10636 error message when installing BIG-IP software and there is insufficient disk space available. Following are two common examples where you might see the error message:

  • In the /var/log/liveinstall.log file:

    info: Installing packages.
    error: tm_install::Process::Process_full_install -- predicted size for BIGIP1212 is 10365728 and vg has 10354688 remaining.
    Terminal error: Disk full (volume group). See SOL#10636
    *** Live install end at 2017/02/21 11:31:40: failed (return code 2) ***

  • In output from the command tmsh show sys software; the output may be similar to the following example:

    -------------------------------------------------------------------------------------------
    Sys::Software Status
    Volume  Product  Version    Build  Active                                            Status
    -------------------------------------------------------------------------------------------
    HD1.1    BIG-IP   12.1.1  0.0.184      no                                          complete
    HD1.2    BIG-IP   12.1.1  0.0.184      no                                          complete
    HD1.3    BIG-IP   12.1.2  0.0.249     yes                                          complete
    HD1.4    BIG-IP   12.1.2  0.0.249      no  failed (Disk full (volume group). See SOL#10636)
