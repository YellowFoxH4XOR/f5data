K84043524: BIG-IP VE bandwidth usage throughput was maxed out but has now returned to normal levels

Support Solution

2025-04-01
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K84043524

Description
F5 bandwidth usage throughput was maxed out for a period of time.
Now bandwidth usage has returned to normal levels

Environment

  • Network Connectivity
  • Bandwidth limit reached

Cause
Unknown at time of publication

Recommended Actions

When bandwidth usage is higher than normal, to investigate the cause, collect and examine the following information:
  1. Identify which Virtual Servers show the most traffic, using the Dashboard statistics in the GUI
  2. TCPdump of the traffic through each affected Virtual Server: K411: Overview of packet tracing with the tcpdump utility
  3. Examine the Connection Table for anything unusual:
    1. Connect to BIG-IP CLI
    2. Run command

      tmsh show /sys connection

      K40033505: Explaining the output of tmsh show sys connection
