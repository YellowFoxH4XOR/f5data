Known Issue

The bd agent may restart when you attempt to apply a BIG-IP ASM policy.

This issue occurs when all of the following conditions are met:

  • Your system is provisioned with BIG-IP ASM.
  • The BIG-IP ASM configuration contains corrupted data.
  • You are attempting to apply a policy.

Impact

The BIG-IP ASM system temporarily fails to process traffic while the processes restart.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The bd and bd_agent processes restart.
  • In the /var/log/asm log file, you observe an error message similar to the following example:

    crit perl[21745]: 01310027:2: ASM subsystem error (bd_agent,): bd_agent exiting, error:[Bit::Vector::new_Dec(): input string syntax error at /usr/local/share/perl5/F5/CfgConvert.pm line 66, <$inf> line 1. ]
