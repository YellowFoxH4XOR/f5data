K000132804: Only one RDP/VDI resource seen using a Native View client

Type
Support Solution
Published
2023-03-01
Updated
2023-03-02
Applies to
  • BIG-IP
  • BIG-IP APM: 14.1.5
Source
https://my.f5.com/manage/s/article/K000132804

Description

When there is one VDI resource assigned it shows up, but when there are two or more resources, only one of them shows up in the Native client. We can see both assigned in session logs, yet only one appears on the native client and only one sends packets to the user.

Environment

  • APM
  • VDI profile
  • Two or more RDP/VDI resources assigned
  • Accessed via the VMWare Native client

Cause

The behavior is a limitation when accessing these resources from the Native View client. If you add two remote desktops to the resource assign agent (Advanced resource assign block in the policy), only the first remote desktop resource will be visible in the Native View client, whereas in the browser you will see all of them.

That is how this media is functioning right now.
