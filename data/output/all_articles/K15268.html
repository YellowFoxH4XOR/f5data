Known Issue

The mcpd process may restart and produce a core file when performing a full synchronization operation.

This issue occurs when the following condition is met:

  • Your system performs a configuration synchronization (ConfigSync) operation for virtual servers in a traffic group that has non-floating IP addresses.

Impact

The BIG-IP system may experience a brief service interruption while the mcpd process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H459745 on the Diagnostics > Identified > High screen.
  • After changing the IP addresses for a traffic group from floating to non-floating, performing a ConfigSync operation causes the BIG-IP system to experience a brief service interruption while the mcpd process restarts.
  • The BIG-IP system fails over if configured as part of a high-availability system.
  • The BIG-IP system generates an mcpd core file.
