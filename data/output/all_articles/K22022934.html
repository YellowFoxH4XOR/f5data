Description

When attempting to apply a traffic policy to a virtual server, the operation fails with an error similar to the following:

err mcpd[6905]: 010716d8:3: Compilation of ltm policies for virtual server /Common/HTTP-VS failed; Couldn't publish shared memory segment.

An additional error may be seen in /var/log/ltm:

err mcpd[6203]: 010716d5:3: Failed to publish LOIPC object for (loipc_vs_HTTP-VS.1590677603.613255357). Call to (shm_open) failed with errno (13) errstr (Permission denied).

Environment

  • Policy
  • Virtual server

Cause

There is a duplicate mount of /dev/shm which does not retain the SELinux contexts of the original /dev/shm. This prevents mcpd from creating a shared memory segment in /dev/shm, throwing the error.

[root@v14:Active:Standalone] config # mount | grep shm
tmpfs on /dev/shm type tmpfs (rw,noatime,seclabel)
none on /dev/shm type tmpfs (rw,noatime,seclabel)  <----

Recommended Actions

Unmount the duplicate mount:

umount -l /dev/shm

If the issue persists, reboot the system.

Additional Information

/dev/shm mount is a temporary filesystem used for shared memory functions between processes. There may be additional symptoms when this issue is encountered.
