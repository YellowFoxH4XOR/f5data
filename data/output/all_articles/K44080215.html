Topic

Starting with the release of BIG-IP AFM 13.1.0, protocol inspection profiles are part of the configurable feature set for BIG-IP AFM when configured with an intrusion prevention system (IPS) subscription add-on license. Protocol inspection profiles for TCP and UDP act as an intrusion prevention system (IPS) implementation for the BIG-IP AFM system.

However, there are a few default configuration settings that can impact legitimate traffic in your production environment. F5 recommends you test these settings to ensure they don't cause false positives.

Description

The configuration for protocol inspection profiles has default settings, some of which may cause unexpected results when you deploy the profile in a production environment.

Inspection IDs have Action settings that are set to Drop or Reject by default. These settings can cause inspection ID criteria to match traffic, creating false positives and impacting legitimate traffic in your environment.

To eliminate the possibility of the protocol inspection profile impacting legitimate traffic, F5 recommends the following:

  • Change the default, inspection ID, Action settings to Accept.
  • Set the inspection Log to Yes.
  • After you deploy the protocol inspection profile and the system processes traffic for a period of time, monitor the total hit count for each inspection ID.
  • Determine the impact to your environment by doing the following:
    • Change the inspection ID, Action settings back to Drop or Reject.
    • Monitor the total hit count for each inspection ID, and then compare them with the hit counts you got when the inspection ID Action settings used Accept.

Recommendations

To deploy a new protocol inspection profile for production traffic and prevent inspection IDs from impacting legitimate traffic in your environment, you should consider using the following steps:

  • Creating a protocol inspection profile, configuring the 'Action' settings for inspection IDs using Accept, and monitoring results
  • Changing the 'Action' settings for inspection IDs back to Drop or Reject and monitoring results

Creating a protocol inspection profile, configuring the 'Action' settings for inspection IDs using Accept, and monitoring results

You can create a new protocol inspection profile, configure the Action settings for inspection IDs with Accept, and enable logging for inspection IDs by performing the following steps:

Impact: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Protocol Security > Inspection Profiles.
  3. To create a new inspection profile, click Add and then in the list, click New.
  4. For Profile Name, type a name.
  5. CDlick Enabled for any or all of the following: Signatures, Compliance, and AVR Stats Collect.
  6. For Service, click the service type(s) for the profile.
  7. On the New Profile page, in the lower section, click the name of the service type.
  8. Expand Properties, and then for Service Type, click Enabled.
  9. For Ports, type the appropriate ports for the service type.
  10. Click Close.
  11. At the top of the check box column, select the top check box to select all inspection IDs.

    The Edit Selected Inspections window displays.

  12. For Action, click Accept.
  13. For Log list, click Yes.
  14. Click Apply.
  15. Click Commit Change to System.

The new inspection profile is ready for use as part of the network firewall and virtual server security policies.

Changing the 'Action' settings for inspection IDs back to Drop or Reject and monitoring results

The following steps modify the inspection ID in a protocol inspection profile so that its Action setting uses Drop or Reject.

Impact: Performing the following procedure modifies inspection ID criteria, which impacts how the system processes traffic that matches it.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Protocol Security > Inspection Profiles.
  3. Click the name of the inspection profile you want.
  4. Near the top of the page, click the service type name.

    The Properties window displays on the right.

  5. Next to the inspection ID you want to modify, select the check box.
  6. In Properties, for Action, next to the Action you want, change Accept to Drop or Reject.
  7. Click Commit Change to System.
