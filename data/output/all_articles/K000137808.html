Description

There is a need to redirect all the requests to a static self-defined maintenance page during a maintenance window

Environment

  • Nginx Plus & Nginx OSS

Cause

None.

Recommended Actions

Please refer to the below example for one of the approaches to display a static sef-defined maintenance page. Nginx will rewrite all the client requests once the administrator puts the maintenance.html under the '/user/share/nginx/html' directory.

server {
    listen 8888;
    root /usr/share/nginx/html;
    if ( -f /usr/share/nginx/html/maintenance.html ) {
        rewrite ^ /maintenance.html last;
    }
    location = /maintenance.html {
        root /usr/share/nginx/html;
    }
    <Other location definations>
}
