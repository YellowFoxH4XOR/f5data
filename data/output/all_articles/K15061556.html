Description

You want to change the HTTP response Status Code, using an iRule for a Virtual Server. For example, to change a Status Code 404 Not Found sent by the server, for a 200 OK, to be sent to the client in the response.

You want to keep the same HTTP payload.

Environment

  • iRules
  • HTTP

Cause

None

Recommended Actions

Below iRule is an example that will change the response Status Code from 404 to 200, and keep the same payload. The iRule needs to be attached to the Virtual Server.

when HTTP_RESPONSE {
   if { [HTTP::status] contains "404"} {
      HTTP::collect [HTTP::header Content-Length]
   }
}
when HTTP_RESPONSE_DATA {
   HTTP::respond 200 content [HTTP::payload]
}

Note: This is just an example iRule and might need adjustments and testing according to each specific environment.
