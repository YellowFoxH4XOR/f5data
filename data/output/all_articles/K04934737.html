Topic

You should consider using this procedure under the following conditions:

  • You want to find out the list of data files referenced by the single configuration file (SCF) from the separate TAR file.
  • You want to view the content of a data file in the SCF TAR file.

Description

When you save a copy of a SCF, the system stores data files, such as SSL certificate/keys, external data group files, or so on, in the BIG-IP filestore (/config/filestore) in a separate TAR file. By default, the name of the TAR file has the same name as the SCF file and has the .tar file extension in the /var/local/scf directory.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP command line.
  • If the SCF TAR file is encrypted with a passphrase, you must have the passphrase to decrypt it prior to performing any file operations on the file.

Procedures

  • Determining the list of data files in the SCF TAR file
  • Viewing the content of a data file in the SCF TAR file
  • Optional: Decrypting the SCF TAR file

Determining the list of data files in the SCF TAR file

You can find the list of data files in the SCF TAR file by performing the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Locate the SCF TAR file you want; by default, the SCF TAR file is located in the /var/local/scf directory.
  3. To find the list of data files in the SCF TAR file, enter the following command syntax:

    tar -tvf <SCF TAR filename>

    A command in this syntax returns an output similar to the following example:

    -rw------- root/root        61 2020-06-07 23:24 data
    -rw-r--r-- root/root      3414 2020-05-26 00:17 files_d/Common_d/trust_certificate_d/:Common:dtca-bundle.crt_63047_4
    -rw-r--r-- root/root      1314 2019-09-30 20:54 files_d/Common_d/trust_certificate_d/:Common:dtca.crt_63043_2
    -rw-r--r-- root/root      1294 2019-09-30 20:54 files_d/Common_d/trust_certificate_d/:Common:dtdi.crt_63039_2
    -rw-r----- root/webservices 1704 2019-09-30 20:54 files_d/Common_d/trust_certificate_key_d/:Common:dtca.key_63045_2
    -rw-r----- root/webservices 1704 2019-09-30 20:54 files_d/Common_d/trust_certificate_key_d/:Common:dtdi.key_63041_2
    -rw-r--r-- root/root          63 2020-06-07 20:19 files_d/Common_d/data_group_d/:Common:string_name_value_external_dg_file_86732_1
    -rw-r--r-- root/root        5753 2020-03-25 00:18 files_d/Common_d/certificate_d/:Common:cert1_104793_1
    -rw-r----- root/webservices 1679 2020-03-25 00:19 files_d/Common_d/certificate_key_d/:Common:cert1key_104799_1

Viewing the content of a data file in the SCF TAR file

You can view the content of a data file in the SCF TAR file by performing the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Locate the SCF TAR file you want; by default, the SCF TAR file is located in the /var/local/scf directory.
  3. To view the content of a data file in the SCF TAR file, enter the following command syntax:

    tar -tOf <SCF TAR filename> <data filename>

    Using the example output from the previous procedure, you enter the following command to view the files_d/Common_d/data_group_d/:Common:string_name_value_external_dg_file_86732_1 external data group file:

    tar -tOf myexampleSCF.tar *string_name_value_external_dg_file*

Optional: Decrypting the SCF TAR file

If the SCF TAR file is encrypted with a passphrase, you must decrypt it first. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Locate the encrypted SCF TAR file you want; by default, the SCF TAR file is located in the /var/local/scf directory.
  3. To confirm that the SCF TAR file is encrypted, enter the following command syntax:

    file <SCF TAR filename>

    The command returns output similar to the following example if it is encrypted:

    myexampleSCF.tar: PGP message

  4. To decrypt the SCF TAR file, enter the following command syntax:

    gpg --output <desired SCF TAR filename after decryption> --decrypt <encrypted SCF TAR filename>

    For example, to decrypt the myexampleSCF.tar to myexampleSCFdecrypted.tar, enter the following command:

    gpg --output myexampleSCFdecrypted.tar --decrypt myexampleSCF.tar

  5. Follow the instructions to provide the passphrase used to encrypt the file. After the SCF TAR file is decrypted, you can view the list of data files in it or view the content of a data file in it.
