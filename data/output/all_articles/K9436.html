K9436: Firefox 3 does not pass session cookies to Java-based applets

Topic

Firefox 3 does not pass session cookies to Java-based applets when the Firefox Accept 3rd party cookies option is not selected.

Mozilla is tracking this issue as Bug 441166. 

Note: For more information, refer to the following website:

https://bugzilla.mozilla.org/show_bug.cgi?id=441166

When the Accept 3rd party cookies option is not selected, FirePass Java applets that require maintaining session state, such as Application Tunnels, will fail.

Note: For more information about configuring your cookie preferences, refer to the Mozilla Knowledge Base.
