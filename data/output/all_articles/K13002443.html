Description

You are writing an iRule and receive the error, "01070151:3: Rule [/Common/<rulename>] error: /Common/<rulename>:2: error: [parse error: PARSE syntax 59 {syntax error in expression "<expression>": extra tokens at end of expression}][<expression>" when you try to save it

Environment

  • BIG-IP
  • New iRule

Cause

This error is caused when the TCL validation of the new iRule finds characters where it isn't expecting them

Recommended Actions

Review your iRule to ensure that there are no typos made in the expression, either with the comparators you are using and with the variables they are testing

None
