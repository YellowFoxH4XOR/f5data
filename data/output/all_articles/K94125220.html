Description


This article explains how to change the default installation schedule of BIG-IP ASM signatures (such as attack signatures, bot signatures, browser challenges, server technologies, or threat campaigns) using the tmsh utility. 

Environment

  • BIG-IP ASM
  • BIG-IP ASM Signatures
  • Installation schedule

Cause


None

Recommended Actions

To view the current install schedule:

  1. Log in to tmsh on the BIG-IP system using the following command:
    tmsh
  2. List the current schedule parameters configured using the following command:
    list /mgmt tm live-update asm-attack-signatures install-schedule

 

For example, below is the current schedule configured to install the attack signatures update on Monday during 13:00 and 21:00 BIG-IP time

{
    applyAtAllTimes false
    applyOnAllDays false
    applyOnFridays false
    applyOnMondays true
    applyOnSaturdays false
    applyOnSundays false
    applyOnThursdays false
    applyOnTuesdays false
    applyOnWednesdays false
    endTime "21:00"
    frequency "scheduled"
    kind "tm:live-update:asm-attack-signatures:install-schedulestate"
    selfLink "https://localhost/mgmt/tm/live-update/asm-attack-signatures/install-schedule"
    startTime "13:00"
}

Note: Below commands can be modified to use bot-signatures, browser-challenges, server-technologies, or threat-campaigns such as:

  • tmsh list /mgmt tm live-update bot-signatures install-schedule
  • tmsh list /mgmt tm live-update browser-challenges install-schedule
  • tmsh list /mgmt tm live-update server-technologies install-schedule
  • tmsh list /mgmt tm live-update threat-campaigns install-schedule 

 

To modify existing BIG-IP ASM attack signatures schedule, follow the procedure below:

  1. Log in to tmsh on the BIG-IP system using the following command:
    tmsh
  2. Modify the current schedule parameters configured using the following command:
    For example :To add the installation  schedule to Tuesday 
    modify /mgmt tm live-update asm-attack-signatures install-schedule applyOnTuesdays true
  3. Save the configuration using the following command:
    save sys config
  4. Verify whether the new installation  schedule is applied
    list /mgmt tm live-update asm-attack-signatures install-schedule
 {
    applyAtAllTimes false
    applyOnAllDays false
    applyOnFridays false
    applyOnMondays true
    applyOnSaturdays false
    applyOnSundays false
    applyOnThursdays false
    applyOnTuesdays true
    applyOnWednesdays false
    endTime "21:00"
    frequency "scheduled"
    kind "tm:live-update:asm-attack-signatures:install-schedulestate"
    selfLink "https://localhost/mgmt/tm/live-update/asm-attack-signatures/install-schedule"
    startTime "13:00"
}

Note: Below commands can be modified to use bot-signatures, browser-challenges, server-technologies, or threat-campaigns such as:

  • tmsh modify /mgmt tm live-update bot-signatures install-schedule  applyOnTuesdays true
  • tmsh modify /mgmt tm live-update browser-challenges install-schedule applyOnTuesdays true
  • tmsh modify /mgmt tm live-update server-technologies install-schedule applyOnTuesdays true
  • tmsh modify /mgmt tm live-update threat-campaigns install-schedule applyOnTuesdays true
