Issue

Error Message

01010366:3: DNS: Virtual <virtual_server> exceeded ingress queue limit, throttling

In this error message, note the following:

  • <virtual_server> is the virtual server object that is processing DNS requests.

For example:

01010366:3: DNS: Virtual /Common/udp-listener exceeded ingress queue limit, throttling.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The DNS packet queue has reached the high watermark limit.

By default, the BIG-IP system queues DNS packets that are destined for a virtual server with a DNS profile and monitors the queue while the Traffic Management Microkernel (TMM) actively processes DNS packets. If the DNS queue reaches the high watermark limit of 262144 packets, the system throttles incoming DNS packets until the number of queued packets drops below the low watermark setting of 196608.

When the number of queued packets drops below the low watermark setting, the system disables DNS packet throttling and logs an error message that appears similar to the following example:

  • 01010367:3: DNS: Virtual /Common/udp-listener throttling disabled

Impact

New incoming DNS requests are dropped until the number of queued packets drops below the low watermark.

Recommended Actions

None

The default DNS queuing settings are optimized for most environments. However, you can change the high or low watermark settings or disable DNS queuing by reviewing the following procedure:

Impact of action: Disabling DNS queuing may impact DNS performance. If your system experiences a high volume of DNS requests while DNS queuing is disabled, some requests may be dropped causing DNS resolvers to resend them.

  1. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  2. Modify the DNS queuing settings as needed, by entering the following commands:
    • To enable/disable DNS queuing, use the following syntax:

      modify /sys db dns.queuing value <enable/disable>

    • To change the high watermark value, use the following syntax:

      modify /sys db dns.ingress.queue.high value <value>

    • To change the low watermark value, use the following syntax:

      modify /sys db dns.ingress.queue.low value <value>

  3. Save the changes by entering the following command:

    save /sys config

  4. To exit tmsh, enter the following command:

    quit
