Known Issue

The BIG-IP system does not decrement the TTL value when forwarding an ICMP Type 11 (Time Exceeded) packet.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured with a Forwarding (IP) virtual server.
  • The BIG-IP system receives an ICMP Type 11 packet.

When forwarding an ICMP Type 11 packet, the BIG-IP system sets the TTL to 255 instead of decrementing the TTL.

Impact

This issue may increase network congestion and high CPU usage on the BIG-IP system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Excessive number of ICMP Type 11 packets on the wire
  • Increased network congestion
  • Higher than expected CPU usage
