K000161790: Transferring managed BIG-IP UCS backup to remote server using SCP fails in BIG-IQ GUI

Type
Support Solution
Published
2026-06-21
Updated
2026-06-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.X, 8.4.2, 8.4.1, 8.4.0
Source
https://my.f5.com/manage/s/article/K000161790

Description

  • You are trying to generate UCS backup for BIG-IP from BIG-IQ GUI and transferring the UCS file to remote server using SCP fails with below error
    1. Task
    <File-name_Device-name_date>.ucs failed: to archive backup while making ssh connection to <Remote Server IP address>Session.connect: java.security.SignatureExecption: Signature encodeing error

  • SCP transfer works when you manually execute command from BIG-IQ CLI.

Environment

  • BIG-IQ
  • UCS backup transfer to remote server
  • SCP

Cause

RFE (Request for Feature Enhancement) ID1783729

Remote server chooses rsa-sha2-256 or other KEX host signature which is not supported in BIG-IQ SSH/SFTP library (JSCH)

Answer/Recommended Actions

The fix is to configure the remote server to use BIG-IQ supported KEX host signature - ssh-rsa, ecdsa-sha2-nistp256 or ecdsa-sha2-nistp384.
