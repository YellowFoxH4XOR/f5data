Topic

Due to current design properties, you must enable both port translation and address translation when you configure virtual servers with a WebAccelerator-enabled HTTP Class Profile.

By default, a standard virtual server configured with a host address and service port will have both port translation and address translation enabled.

Network virtual servers and wildcard virtual servers will have address translation, port translation, or both disabled by default. For details about the default translation settings for a virtual server, refer to the following table:

Virtual Server TypeExampleAddress TranslationPort Translation
Standard192.168.10.1:80EnabledEnabled
Network192.168.10.0:80DisabledEnabled
Wildcard Address0.0.0.0:80DisabledEnabled
Wildcard Port192.168.10.1:*EnabledDisabled
Wildcard0.0.0.0:*DisabledDisabled

 

Important:  When configuring virtual servers that are enabled for the WebAccelerator system, configure them so they only process HTTP traffic. Enable the WebAccelerator system for only virtual servers that are configured with the service port for HTTP specified, such as Standard, Network, or Wildcard Address virtual servers. F5 recommends that you do not enable the WebAccelerator system for virtual servers that are configured for unspecific service ports, such as Wildcard Port or Wildcard (0.0.0.0:*) virtual servers; these virtual servers are often intended to process non-HTTP traffic.

Note: For information about enabling the WebAccelerator system for a virtual server that has translation disabled, refer to K8523: Enabling WebAccelerator for a network virtual server or wildcard address virtual server.

Ensuring that port and address translation are enabled for a standard virtual server

To ensure that port and address translation are enabled for a standard virtual server, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. Click Virtual Servers.
  4. Click the desired virtual server.

    The General Properties and Configuration page for the virtual server opens.

  5. From the Configuration box, select Advanced.
  6. Verify that the check box for Address Translation is selected.
  7. Verify that the check box for Port Translation is selected.
  8. Click Update.
