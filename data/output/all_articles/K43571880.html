Description
IPv6 neighbor shows as down, BGP neighbor status is Active

  • ip -f inet6 neigh show command shows neighbor as failed
  • IPv6 neighbor not shown in show /net ndp all command
  • Packet capture shows BIG-IP sending Neighbor Solicitation packets, no Neighbor Advertisement packets being received in return
  • Pings from the BIG-IP to the IPv6 neighbor fail
  • Other IPv6 neighbors defined in BIG-IP are working as expected

Environment

  • IPv6 Self-IP configured
  • BGP IPv6 neighbors configured

Cause
Potential network connectivity issues exist preventing the F5 from reaching the IPv6 neighbor, such as a firewall blocking traffic.

Recommended Actions

  1. Confirm Neighbor Solicitation messages are egressing the BIG-IP via packet capture:
    1. tcpdump -s0 -vnni 0.0:nnn "ip6 protochain 58" -w /var/tmp/<filename>.pcap
  2. Confirm Neighbor Solicitation messages are reaching the IPv6 neighbor via packet capture
  3. Confirm Neighbor Advertisement messages are egressing the IPv6 neighbor via packet capture
  4. Confirm no firewall blocks exist for the traffic between the BIG-IP and the IPv6 neighbor
