Description

Post upgrade, BIG-IP console prompt displays "FIREWALL RULES RE-COMPILATION NEEDED".
 

Environment

  • Upgrade from 15.1.3. to 15.1.5.
  • Only seen on the Standby device
  • AFM license but NOT provisioned
  • Device Group is "In Sync"


Cause

In standby's bigip_base.conf file the following configuration was found:

security firewall on-demand-compilation {
    mode enabled
}
security firewall on-demand-rule-deploy {
    mode enabled
}

Note: Same configuration was found in the Active device's bigip_base.conf file.

This is an indication that the device was provisioned with AFM module in the past and also had configurations.

Note: Same configuration was found in the UCS archive taken before the upgrade.
 

Recommended Actions

This configuration has no impact on the functionality of existing provisioned module/s, therefore it can safely be removed from the bigip_base.conf file.

Impact of procedure: F5 recommends that you perform this procedure during a maintenance window. The activity involves restarting system processes and rebooting. These actions interrupt traffic. Additionally, when the BIG-IP system is in a device group, it fails over to the next available member.
  1. Log in to the BIG-IP CLI
     
  2. Using any editor tool, open bigip_base.conf
     
  3. Remove the following configuration:

    security firewall on-demand-compilation {
        mode enabled
    }
    security firewall on-demand-rule-deploy {
        mode enabled
    }
     
  4. Load the configuration using:

    tmsh load sys config
     
  5. Save the configuration using:

    tmsh save sys config
     
  6. Reboot the device.
     
  7. Repeat the steps 1-6 on the peer device.

None.
