K000137650: How to check the cause of failover

Type
Support Solution
Published
2023-11-22
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000137650

Description

Need to determine the root cause of failover.

 

Environment

  • BIG-IP
  • Any version
  • HA pair
  • Failover
 

Cause

  • many possible reasons
  • K95002127 : Troubleshooting BIG-IP failover events 
 

Recommended Actions

Check in originally Active unit /var/log/ltm

 

Examples

  • The below log indicate HA-Group is configured, and HA-Group setting triggered Failover
notice sod[PID]: 010c0045:5: Leaving active, group score 0 peer group score 200.
notice sod[PID]: 010c0052:5: Standby for traffic group traffic-group-1.

 

  • The below log indicate User rebooted the system on GUI and caused failover

notice sod[PID]: 010c0044:5: Command: reboot enable all GUI.

           You can also check who rebooted in /var/log/audit:

syscalld[PID]: 01070417:6: AUDIT - user - RAW: Request to run /usr/bin/cmd_sod reboot enable all GUI.

 

  • The below log indicate HA connectivity issue (between IPs configured in unicast addresses)

warning sod[6643]: 010c0083:4: No failover status messages received for 3.100 seconds, from device <host name> (<ha self ip / mgmt ip>) (unicast: -> <ha self ip / mgmt ip>).
