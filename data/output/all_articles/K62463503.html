K62463503: QuotaExceededError: The quota has been exceeded

Type
Support Solution
Published
2021-03-04
Updated
2025-04-01
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.X.X
Source
https://my.f5.com/manage/s/article/K62463503

Description

Error "QuotaExceededError: The quota has been exceeded" may appear on the login page of the BIG-IQ

Environment

  • BIG-IQ Configuration Manager

Cause

QuotaExceeded occurs when the browser's localStorage gets out of memory

Recommended Actions

Clearing the local storage from Developer Tools on the browser may resolve the issue. If you wish to investigate what led to the browser's local storage running out of memory, capturing the response from the Network tab of Developer Tools and capturing the restjavad logs at this point may be helpful.

Additional Information

None
