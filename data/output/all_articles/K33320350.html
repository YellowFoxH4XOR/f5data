Description

Is it required to configure CRL for BIG-IP GUI (Configuration utility) ?

Environment

  • BIG-IP
  • Configuration utility / GUI
  • HTTPS/SSL certificate

Cause

n/a
 

Recommended Actions

  • It is not required to define any CRL for the Configuration utility.
  • To update the status of a certificate using a CRL, the client (browser) reaches out to the CA and downloads its certificate revocation list. After doing this, it then must search through the entire list for that individual certificate.
