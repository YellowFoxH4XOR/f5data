Description

When you attempt to configure the BIG-IP ASM HTTP Redirection Protection with characters that are non-compliant to RFC 1035 using the Configuration utility (Security > Application Security > Headers > Redirection Protection), the configuration attempt fails and the Configuration utility returns an error message similar to the following example:

Please enter a valid Redirection Domain Name

Environment

Relevant environmental factors specific to the topic

  • BIG-IP ASM
  • HTTP redirection protection

Cause

This error message is caused by using characters that are not compliant to RFC 1035.

Recommended Actions

  • Do not use special characters for domain names. 
  • The labels must follow the rules for ARPANET host names. They must start with a letter, end with a letter or digit, and have as interior characters only letters, digits, and hyphen. There are also some restrictions on the length. Labels must be 63 characters or less.
    Note: Currently, the system does not support non-English domain names. For more information about the restrictions, refer to RFC1035.

Additional Information

In the Domain Name field, type the name of the domain (in English-only, such as example.com), or its IP address.
If protection is enabled and no domains are configured, then only relative URIs are allowed (for example, /login.php).
