Description
While running BIG-IP APM in an HA pair configuration, you're experiencing the following situation:

  • APM sessions seem to not be mirrored to the StandBy unit;
  • Upon performing failover, users cannot establish APM sessions.

Environment

  • BIG-IP APM
  • HA pair.

Cause
This may be because of the configuration of the Virtual Servers' Virtual Address(es).
Here is an example:
ltm virtual-address /Common/192.0.2.1 {
    address 192.0.2.1
    arp enabled
    icmp-echo enabled
    mask 255.255.255.255
    traffic-group none <-------------- [!!]
}
With "traffic-group" set to "none", sessions are *not* mirrored.

Recommended Actions

You need to put the Virtual Servers' Virtual Address(es) into a floating traffic group.
Please refer to the following article: K53040085: How to move a Virtual Server's Virtual Address into a different Traffic Group

Additional Information
None.
