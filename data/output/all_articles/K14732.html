Known Issue

The BIG-IP ASM system may fail to accept a cookie where the first 20 characters of its name match an existing allowed cookie. This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM security policy contains an existing allowed cookie that has a name with 20 or more characters.
  • You attempted to add another allowed cookie, either through manual configuration or through learning, where the first 20 characters of its name match the existing cookie.

    For example, the security policy has an existing allowed cookie named abcdefghij1234567890. If you attempt to add a new allowed cookie named abcdefghij1234567890A, either through learning or manual configuration, the BIG-IP ASM Configuration utility fails to accept the new cookie and reports an error.

This issue occurs because the BIG-IP ASM system uses the first 20 characters of a cookie name to uniquely identify the cookie.

Impact

You are unable to add a new allowed cookie that has a similar naming convention as an existing allowed cookie.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP ASM Configuration utility fails to accept the new cookie, and reports an error similar to the following example:

    Could not add Allowed Cookie abcdefghij1234567890A; Error : Failed add on duplicate record for AllowedCookie found -- add aborted
