Description

License requirement for ASM live update 

Environment

  • Attack signature
  • Live update
  • License
  • v14.1 and above 
Cause

After version 14.1.0, ASM license verification prior to attack signature update has been removed.
Hence no mention about license requirement in the following article. 
K82512024: Managing BIG-IP ASM Live Updates (14.1.x - 15.x)

Recommended Actions

Re-activating the license is not necessary prior to attack signature live update. 

Additional Information

Prior to version 14.1.x , you must re activate the license prior to attack signature update as per following article.
K8217: Managing BIG-IP ASM attack signatures (11.5.x - 14.0.x)
