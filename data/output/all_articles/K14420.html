K14420: Web acceleration is now enabled by associating a Web Acceleration profile with the virtual server

Source

Issue

Old Behavior

In BIG-IP WebAccelerator versions prior to 11.0.0, web acceleration is associated to a virtual server by means of an HTTP class profile when the Webacceleration option is set to Enabled.

New Behavior

Beginning in BIG-IP WebAccelerator 11.0.0, web acceleration is enabled through the Web Acceleration profile.

Impact

Enabling web acceleration in an associated HTTP class profile for 11.0.0 and later may result in unnecessary Traffic Management Microkernel (TMM) CPU load.

Recommended Actions

You should use an HTTP class profile only when you are using BIG-IP WebAccelerator and BIG-IP ASM simultaneously on the same virtual server.

When enabling BIG-IP WebAccelerator and BIG-IP ASM on the same virtual server, you must set the following parameters:

  • Associate the Web Acceleration profile with the virtual server.
  • Set the Webacceleration option in the associated HTTP class profile to Accelerate.
  • Set the Application Security option in the associated HTTP class profile to Enabled.

If the WebAcceleration option in the associated HTTP Class Profile is set to Bypass, it will disable BIG-IP WebAccelerator on that virtual server.
