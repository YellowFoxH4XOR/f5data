K000152383: csyncd generating core file every 5 seconds

Source

Description

csyncd generating core file every 5 seconds. Unable to view software image from BIG-IP GUI. 

 

Environment

  • Core
  • Upgrade
  • csyncd
  • GUI

 

Cause

csyncd binary is corrupted

 

Recommended Actions

There are 2 options to resolve this issue. Please use option 2. if you can't do option 1.

Option 1: reinstall the software to a new boot location

Option 2: If you have working unit which is in same version

a. Mount /usr as read-write: 
[root@bigip:Active:Standalone] / # mount -o remount,rw /usr

b. Check the selinux permissions on the csyncd binary:
[root@bigip:Active:Standalone] / # ls -lZ /usr/bin/csyncd

-rwxr-xr-x. root root system_u:object_r:csyncd_exec_t:s0 /usr/bin/csyncd

c. Stop csyncd daemon 
[root@bigip:Active:Standalone] / # bigstart stop csyncd

d. Copy a known working csycnd binary into /usr/bin/ directory ( From peer unit running same version )

e. Check that the selinux permissions are the same. ( Refer step b. )

f. Start csyncd daemon:
[root@bigip:Active:Standalone] / # bigstart start csyncd

g. Check status of csyncd daemon:
[root@bigip:Active:Standalone] / # bigstart status csyncd

csyncd        run (pid 28997) 16 seconds, 1 start

h. Remount /usr as ro:
[root@bigip:Active:Standalone] / # mount -o remount,ro /usr
