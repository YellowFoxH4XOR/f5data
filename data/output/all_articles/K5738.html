Topic

The BIG-IP DNS system uses the ZoneRunner utility to manage DNS zone files and the BIND configuration. The ZoneRunner utility uses Dynamic DNS Update to immediately update the zone's resource record data to BIND without requiring BIND to stop and restart.

BIND does not write these dynamic updates to the associated zone file immediately. Instead, these updates are stored in a journal file, with a .jnl filename extension. If BIND is restarted after a shutdown or crash, it replays the journal file to incorporate the zone into any updates that took place after the last zone dump. BIND occasionally writes or dumps the complete contents of the updated zone to its zone file; however, BIND does not do this immediately after each dynamic update. Instead, the dump is delayed by up to 15 minutes, allowing additional updates to take place.

Because of this delay, it is possible for the ZoneRunner utility to display different resource record data for a zone than is present in the zone file for that zone.

For more information, refer to K5909: Forcing BIND to dump the dynamic updates stored in the journal files.
