K32216501: [F5OS-A] Restoring backup failed with the error: Database config-restore failed

Type
Support Solution
Published
2022-07-21
Updated
2024-09-05
Applies to
  • VELOS Platforms
  • F5OS
  • rSeries Platforms
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K32216501

Description

When restoring the F5OS configuration, the following error may be encountered:

system database config-restore name <backup file name>
A clean configuration is required before restoring to a previous configuration.
Please perform a reset-to-default operation if you have not done so already.
Proceed? [yes/no]: yes
Error: Database config-restore failed.

Followed: K000134534: [F5OS] Restoring backup failed with the error: Database config-restore failed, but still issue is not fixed.
 

Environment

  • F5OS-A v1.0.x-v1.3.x
  • F5OS-C v1.0.x-1.5.x
  • rSeries / Velos
  • Restoring the management CLI database backup file between 2 different systems

Cause

  • Bug ID 1117417

Recommended Actions

If you are restoring the configuration database from a different F5OS hardware, you will need to ensure the following are the same:

  • Installed system software versions. To verify the software version installed, refer to
    • K07950100: Display the F5OS-A software version on the F5 rSeries system
    • K62132391: Display the F5OS-C software version on the VELOS system

Then follow the workaround written in Bug ID 1117417
