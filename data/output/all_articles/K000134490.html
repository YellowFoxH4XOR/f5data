Description

  • You successfully configured your Nginx to process traffic securely 
  • However, when you tried to access your application, your browser displays error message like
                  SSL_ERROR_RX_RECORD_TOO_LONG
  • When you further looked into Nginx  log, you may notice log entry similar to the below
2023/04/20 14:52:18 [info] 997349#997349: *734734 client sent plain HTTP request to HTTPS port while reading client request headers, 
        client: 192.168.1.2, 
        server: example.com, 
        request: "GET /alpha/merge/check HTTP/1.1",
        host: "example.com:8050"

Environment

  • Nginx Plus
  • BIG-IP
  • SSL profile
  • SSL directives

Cause

  • Client sends request in plain text to a virtual server that expects to complete SSL handshake or vise versa

Recommended Actions

  • Either configure the application/virtual server to auto redirect to HTTPS.
  • Or make sure you send request to virtual with using the correct protocol.
