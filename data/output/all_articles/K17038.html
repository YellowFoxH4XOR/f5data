Known Issue

BIG-IP GTM may not answer name resolution queries from BIND while the rndc reload process is running.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP GTM system to answer DNS queries using the BIG-IP local BIND instance.
  • You have enabled the Synchronizing DNS Zone Files option, which is the default setting.

Impact

BIG-IP GTM will not answer DNS queries from the local BIND instance.

Note: BIG-IP GTM may not answer wide IP queries if you configure the system in a synchronization group and a sync occurs while the rndc reload process is running.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP GTM fails to answer client DNS queries for domain names in the local BIND instance.
  • BIG-IP GTM fails to answer client DNS queries for domain names associated with wide IPs.

Workaround

To work around this issue, you can move critical zone files from local BIND to DNS-Express.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
