Known Issue

A Virtual Clustered Multiprocessing (vCMP) guest residing on a secondary VIPRION blade may incorrectly perform a software installation using a partially uploaded software image file.

This issue occurs when all of the following conditions are met:

  • You have a vCMP guest that spans multiple blades on a VIPRION system.
  • You upload a software image to the /shared/images directory of the VIPRION host system. For example, you use the winscp utility.
  • The upload is interrupted and results in an incomplete image file with a .part or .filepart file extension.
  • The incomplete image file syncs to all of the other blades.
  • The subsequent attempt to upload the image file is successful.
  • You perform a software installation on the vCMP guest using the block-device-image option.

    The command syntax appears similar to the following example:

    tmsh install /sys software block-device-image <iso_image_file> volume <software_volume>

The vCMP guest on the secondary blades may erroneously choose the incomplete image file to install.

Impact

The software installation on the vCMP guest residing on a secondary blade fails to complete successfully.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The incomplete image file with a .part or .filepart file extension appears in the /shared/images directory on all of the blades.
  • The software installation on the vCMP guest on the primary blade completes successfully, while the vCMP guest on secondary blades fails with an error message that appears similar to the following example:

    Software Compatibility tests failed

Workaround

To work around this issue, you can delete the incomplete image file using the Traffic Management Shell (tmsh) before performing the software installation from the vCMP guest. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the VIPRION command line.
  2. Log in to tmsh by typing the following command:

    tmsh

  3. To delete the incomplete image file, use the following command syntax:

    delete /sys software image <incomplete_image_file>

    For example, to delete the incomplete image file named BIGIP-12.1.2.0.0.249.iso.filepart, type the following command:

    delete /sys software image BIGIP-12.1.2.0.0.249.iso.filepart

  4. Save the configuration by typing the following command:

    save /sys config

  5. Perform the software installation from the vCMP guest again.
