K59555459: Support of multiple Response Policy Zone feed zones with a single DNS cache

Type
Support Solution
Published
2021-12-17
Updated
2026-09-10
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP DNS
Source
https://my.f5.com/manage/s/article/K59555459

Description

You would like feed multiple Response Policy Zone (RPZ) in one DNS cache object.

Environment

  • BIG-IP DNS
  • DNS cache
  • Response Policy Zone

Cause

Starting in BIG-IP 21.1.0, BIG-IP DNS supports associating multiple Response Policy Zone (RPZ) feed zones, up to 65,535, with a single DNS cache.

Answer/Recommended Actions

Upgrade to BIG-IP 21.1.0 or later if deploying multiple RPZ zones in DNS caches is required.

Additional Information

None
