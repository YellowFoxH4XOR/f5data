Issue

Error Message

BIG-IQ Centralized Management 6.x and later

01070903:3: Constraint 'hostname must be a fully qualified DNS name' failed for '/Common/system'

BIG-IQ Centralized Management 5.x

Invalid Hostname

Message Location

You may encounter this message in the following location:

  • The BIG-IQ user interface
    • The Setup Wizard Management Address page (https://<BIG-IQ_IP_address>/ui/setup/wizard/address)
    • The System > THIS DEVICE > General Properties page

Description

This message occurs when the following condition is met:

  • You attempt to configure the BIG-IQ system with a host name that is not a fully qualified domain name (FQDN).

You must use an FQDN for the BIG-IQ host name, such as bigiq1.example.com. A BIG-IQ host name such as bigiq1 will trigger the error message, and the configuration change fails.

Impact

Attempts to change the host name for the BIG-IQ system fail.

Recommended Actions

Ensure you use an FQDN for the BIG-IQ host name, such as bigiq1.example.com.

Note: You can use the tmsh modify sys global-settings hostname command to configure the BIG-IQ system with a short name that omits domain information for testing purposes. However, F5 does not recommend it for a production system.
