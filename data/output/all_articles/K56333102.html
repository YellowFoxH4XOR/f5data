Issue

Error Message

015c0004:3: <error_reason>

In this error message, note the following:

  • The <error_reason> is the detailed failure reason.

For example:

015c0004:3: ConnectSocket fails (probably DNS not configured)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions are met:

  • The BIG-IP system is unable to perform necessary DNS lookups.
  • The BIG-IP system is unable to connect to the IP Address Intelligence server vector.brightcloud.com on TCP port 443.

Note: The IP address assigned to vector.brightcloud.com may be changed in the future without notice.

Impact

The BIG-IP ASM system is unable to accurately diagnose traffic coming from IP addresses with bad reputations. Features such as iRules may not work as expected due to having a stale IP address database.

Recommended Actions

  • Ensure that the BIG-IP system is able to perform necessary DNS lookups.
  • Ensure that the BIG-IP system is able to connect to the IP Address Intelligence server vector.brightcloud.com on TCP port 443.
