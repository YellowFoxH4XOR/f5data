K39454101: Unable to edit APM agents via VPE if it contains too many expression

Type
Support Solution
Published
2020-01-15
Updated
2023-02-21
Applies to
  • Virtual Editions
Source
https://my.f5.com/manage/s/article/K39454101

Description

Accessing Dynamic Resource assigned for Active Directory on Access Policy is not successful with an error message listed below.

  • Sorry, server was irresponsive while undefined for more than one minute
  • Argument 1 of Node.removeChild is not an object
  • Unable to call dialogueDelete not from first dialogue in stack

Environment

  • BIG-IP APM
  • APM Agents

Cause

APM agents which contains too many expressions.
 

Recommended Actions

Verify the configuration /config/bigip.conf file and if the agent in question has many expressions (in the hundreds) associated with it.
Follow either of the recommendations to work around the issue. 

  1.  Couple resource assign in a row with fewer groups, something like the following. 

Example: start -> ra -> ra -> ra -> ra -> ...

  1. An alternative approach is to declare a macro and do some branching:

Example: start -> decide|-> ra1

|-> ra2

|-> ra3

Additional Information

None
