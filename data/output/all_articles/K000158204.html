K000158204: sflow-data Not Correctly Exported with only interface counter data being received

Type
Support Solution
Published
2025-12-15
Updated
2025-12-15
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000158204

Description

sFlow data exported from BIG-IP LTM is incomplete, with only interface counter data being received instead of expected sFlow traffic sample packets. 

Environment

  • BIG-IP LTM
  • sFlow configured and enabled on multiple VLANs and interfaces
  • VLANs are members of VLAN groups operating in transparent mode
  • sFlow receivers configured to export data to external collectors

Cause

sFlow traffic sampling is not supported for VLANs that are members of VLAN groups on BIG-IP. Only interface counter data is exported in this configuration.

Recommended Actions

To enable sFlow traffic sampling, remove the relevant VLANs from any VLAN group configuration. If VLAN groups are required for network design, sFlow traffic sampling for those VLANs will not be possible; only counter data will be available.
