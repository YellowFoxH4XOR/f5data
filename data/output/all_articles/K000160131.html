Description

Customers deploying BIG-IP Virtual Edition (VE) in VMware Cloud Foundation 9 (VCF9) environments need to understand compatibility and support boundaries. VCF9 is Broadcom's latest full-stack private cloud platform that uses ESXi as its core hypervisor. The question arises whether BIG-IP VE version 17.5.1 and other versions are compatible with VCF9, particularly regarding the underlying ESXi version used within VCF9.

Key considerations include:

  • VCF9 uses ESXi as its core hypervisor
  • F5 does not perform specific testing on VMware Cloud Foundation platforms
  • Compatibility depends on the ESXi version within VCF9

Environment

  • Product: BIG-IP LTM Virtual Edition (VE)
  • Version: 17.5.1 (and other BIG-IP VE versions)
  • Platform: VMware Cloud Foundation 9 (VCF9)
  • Hypervisor: ESXi (version varies within VCF9)
  • Account Type: Enterprise customers deploying private cloud infrastructure

Cause

F5 Product Management does not plan to perform specific testing on VMware Cloud Foundation for Classic BIG-IP VE. Support is based on the underlying ESXi hypervisor version rather than the VCF platform itself.

Answer/Recommended Actions

  1. Identify the ESXi version used within your VCF9 environment.
  2. Verify ESXi compatibility against F5's official compatibility matrix:
    • Visit: https://clouddocs.f5.com/cloud/public/v1/matrix.html
    • Locate your BIG-IP VE version in the VMware ESXi compatibility table
    • Confirm that your ESXi version is listed as supported
  3. Understand support boundaries:
    • F5 will support BIG-IP VE issues related to the ESXi hypervisor
    • F5 will NOT support VCF-specific features or problems
    • Deployment and testing are performed at customer's own risk
  4. Deploy BIG-IP VE only if the ESXi version within VCF9 is listed in the F5 compatibility matrix.

Additional Information

About VMware Cloud Foundation 9 (VCF9):

  • VCF9 is a unified "Cloud Operating Model" that behaves like a public cloud but runs on private infrastructure
  • Key features include unified operations console, Virtual Private Clouds (VPCs), NVMe memory tiering, and global deduplication
  • VCF9 uses ESXi as its core hypervisor, which is the basis for BIG-IP VE compatibility

Expected Behavior:

  • BIG-IP VE should function in VCF9 environments if the underlying ESXi version is supported by F5
  • Standard BIG-IP VE features and functionality should work as documented for the supported ESXi version

Deployment Considerations:

  • Test thoroughly in non-production environments before production deployment
  • Ensure ESXi version compatibility before deploying BIG-IP VE
  • Be aware that VCF-specific features (VPCs, unified operations, etc.) may not have been tested with BIG-IP VE
