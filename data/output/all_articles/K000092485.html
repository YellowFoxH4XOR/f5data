Description

BIG-IP Virtual Machine can boot, but unable to load the configuration.When accessing the appliance from GUI, a pop-up window appears with the below error.

This BIG-IP system has encountered a configuration problem that may prevent the Configuration utility from functioning properly. To avoid adverse effects on the system, F5 Networks recommends restricting your use of the Configuration utility to critical tasks until the problem is resolved. Beware that attempting to modify your configuration in this state with the Configuration utility may cause your configuration to be overwritten.

Environment

  • BIG-IP LTM
  • Virtual Machine
  • Azure Cloud
  • GUI
  • Configuration files
  • Boot

Cause

Issue is due to defective file system or damaged hard drive, Config files could also be deleted or modified.

Recommended Actions

 Copy the configuration from the "bigip.conf.bak" and "bigip_base.conf.bak" to "bigip.conf" and "bigip_base.conf" and reboot the system.

#cp /config/bigig.conf.bak /config/bigip.conf 
#cp /config/bigip_base.conf.bak /config/bigip_base.conf
