Description

I have a specific use case that needs to add and remove HTTP headers in the process of a request. 

On a client request, I want to add a Header (Client-Header-One for example) with a value. During the HTTP LB processing I want to remove the first header (Client-Header-One) and add another one (New-Header-One) so the origin server receives the new one and not the first one.

Expectation:

What actually happens:

Environment

  • F5® Distributed Cloud HTTP Load Balancer
  • HTTP Header Processing

Cause

  • None

Answer/Recommended Actions

You have to do the following:

  1. Add the new-header in the `Simple Route` -> `Advanced Options`
  2. Remove the old-header in the HTTP Load Balancers's `Other Settings` .

With this approach, the new header would initially be added during the route processing and the old-header would be removed during the VH level header processing. Route-level processing occurs before LB-level processing.
