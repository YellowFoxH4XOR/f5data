Known Issue

This is the result of a known issue. To load balance multi-homed routers, you must configure 3-DNS with a link to the router that uses a self IP address on each of the multi-homed networks. 3-DNS will only allow this configuration if a different VLAN is configured for each self address. If you attempt to create this configuration without first creating a VLAN for each self IP address, the Configuration utility will not create the link and may crash.

F5 Networks Product Development tracked this issue as CR21513 and CR41814.
