Description

After upgrading SWG environment to v14.x users are unable to access through SWG proxy.
in the APM logs, you can see a log similar to the following: 

July 15 02:26:21 bigip1.f5.com info tmm1[19370]: 01870000:6: /Common/SWG_Forward_Proxy_AP:Common:fe0c6696: Executed agent (/Common/swg_forward_proxy_1_act_category_lookup_ag) with return status (Need more data to start policy)

Environment

  • SWG Forward Proxy VIP
  • BIG-IP upgraded to 14.x

Cause

This error means there is incomplete data which is limiting the per-request policy to execute further.

In previous versions, there was no ability to select an action on incomplete request , so passthrough mode was engaged and the connection would succeed, assuming the handshake between the client and server was successful.

However with v14 onwards , Per-Request Policy has a new setting called Incomplete Action which is by default set to "Deny" causing the incomplete requests to fail. 

Recommended Actions

The Per-Request policy should be re-designed so that it doesn't experience incomplete data issue however in case you want to allow it anyway , below changes can be made:
  1. from the BIG-IP GUI, navigate to Access  ››  Profiles / Policies : Per-Request Policies
  2. Click on your Per-Request policy and change the Incomplete Action  setting from "Deny" to "Allow"

Note: This change will allow any incomplete requests which are not desirable at times in production environments and should be reviewed by customer's internal team before proceeding.
