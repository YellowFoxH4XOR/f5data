K000161090: ASM Attack Signatures updates not installing as scheduled

Type
Support Solution
Published
2026-05-04
Updated
2026-05-13
Applies to
  • BIG-IP
  • BIG-IP ASM: 21.0.0, 17.1.3, 17.5.1
Source
https://my.f5.com/manage/s/article/K000161090

Description

ASM Attack Signatures updates are being downloaded automatically on the BIG-IP system, but do not install at the scheduled time. In the BIG-IP GUI, the downloaded Attack Signature Update (ASU) file appears as "Pending" with a blank install date. Manually installing the pending ASU file completes successfully.

Environment

  • BIG-IP ASM
  • Attack Signature Update

Cause

Bug ID 2213605

Recommended Actions

  1. As a workaround, manually click the Install button on the pending ASU file.
  2. Upgrade to a version where Bug ID2213605 has been fixed.
