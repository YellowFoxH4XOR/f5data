Known Issue

BIG-IP i2x00 and i4x00 series platforms generate Link Aggregation Control Protocol (LACP) protocol data units (PDUs) with incorrect media access control (MAC) addresses.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system runs on the i2x00 series or i4x00 series platform.
  • You configure a trunk to use Active LACP mode.

Some Cisco and Juniper switches may discard LACP PDUs sent by BIG-IP i2x00 and i4x00 series platforms. When this occurs, the peer system sends PDUs with a Partner System ID that contains all zeros.

Impact

Peer switches may discard the PDUs sent by the BIG-IP system, rendering LACP inoperable.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When LACP is enabled, the trunk fails to establish.
  • The peer system sends LACP PDUs with a Partner System ID that contains all zeros.
  • The first 32 bits of the Actor System ID of the LACP PDU sent by the BIG-IP system does not match the first 32 bits of the Ethernet source MAC address for the PDU.
