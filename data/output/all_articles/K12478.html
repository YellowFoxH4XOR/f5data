Topic

Note: Access to C$ is intended for MMC use and considered a privileged management operation.

When a namespace is configured with multiple CIFS services, C$ presentation is per namespace not per CIFS service. Therefore, all of the managed volumes for each of the CIFS services will be displayed. Accessing C$ will list all managed volumes within the namespace.

The following example displays a single namespace configured with two CIFS services, exporting three managed volumes each:

Global Server1-> CIFS Service1 (browsing enabled) -> exporting 3 Managed volumes MV1, MV2 and MV3
Global Server2-> CIFS Service2 (browsing enabled) -> exporting 3 Managed volumes MV4, MV5 and MV6

Accessing \\Global Server1\C$ will list all six managed volumes.

It is not possible to configure a per-service presentation. To prevent \\Global Server1\C$ from displaying MV4, MV5, and MV6 you must configure each CIFS service in separate namespaces.
