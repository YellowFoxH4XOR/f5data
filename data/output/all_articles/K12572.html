Known Issue

This is the result of a known issue. The BIG-IP ASM Policy Log incorrectly transposes the values entered for changes to the TPS increased by and TPS reached settings for both the IP Detection Criteria and the URL Detection Criteria within the DoS Attack Prevention feature.

For example, the following changes are made to the BIG-IP ASM policy:

  • IP Detection Criteria:
    • Transactions per second (TPS) increased by: 2000%
    • TPS reached: 10 transactions per second
  • URL Detection Criteria:
    • TPS increased by: 2000%
    • TPS reached: 10 transactions per second

The Policy Log shows the changes to the policy with the values for the TPS increased by and TPS reached settings transposed, as follows:

IP Detection Criteria: TPS increase percent was set to 10.
IP Detection Criteria: TPS reached was set to 2000.
URL Detection Criteria: TPS increase percent was set to 10.
URL Detection Criteria: TPS reached was set to 2000.

F5 Product Development tracked this issue as ID 226946 and it was fixed in BIG-IP ASM 10.2.2 and 11.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Note: For more information about the Policy Log feature, refer to the Reviewing a log of all security policy changes section of the Configuration Guide for BIG-IP Application Security Manager.
