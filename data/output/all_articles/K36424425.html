Description

NFS Traffic is failing but no reset or error is seen on F5. Connections are said to be terminated after a normal FIN,ACK between client and server.

Environment

  • NFS
  • FastL4
  • BIG-IP packet capture is performed  (eg. tcpdump  -nni 0.0:nnn -s0 host 1.1.1.1 -w /shared/tmp/abc.pcap)

Cause

BIG-IP is just doing a pass-through. The error is coming from the NFS Server (like 2.2.2.2 from the above example). Per rfc7530, this is an NFS specific error:

NFS4ERR_PERM (Error Code 1): This indicates that the requester is not the owner. The operation was not allowed because the caller is neither a privileged user (root) nor the owner of the target of the operation.

Recommended Actions

The error suggests that this is likely a privilege user problem. Thus, first check with NFS team and see why they are responding with an NFS4ERR_PERM for a client's call.
