Description

After changing the default device certificate, the BIG-IP Configuration utility (GUI) is still showing as Not Secure by your browser, this is observed while accessing the GUI with the IP address of the device. After displaying additional information about the connection, under Security > Owner, you can find the error: This website does not supply ownership information.

Environment

  • BIG-IP

Cause

Common causes for the Not Secure error: 

  • IP address of the device does not match the common name or subject alternative names (SANs) in the device certificate.
  • The device certificate is not trusted by your browser.

Recommended Actions

  • While accessing the GUI, you need to use the hostname that matches the common name or one of SANs. 
  • Install the root certificate and if necessary any intermediate certificates into your browser certificate store to establish a chain of trust to the BIG-IP device certificate.

Additional Information

An IP address can be added as a SAN. Otherwise, you need to configure DNS to resolve the hostname to the IP address.
