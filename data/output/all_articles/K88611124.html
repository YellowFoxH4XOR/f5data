Description
BIG-IQ alerting feature Monitoring -> Alerts & Notifications -> Settings -> Device Alert Conditions -> HA error does not include errors from BIG-IP HA status changes.

Environment

  • BIG-IQ 
  • HA pair
  • Alerting feature

Cause
This behavior is by design. The setting is not used for monitoring BIG-IP HA status but the BIG-IQ itself.

Recommended Actions

None
