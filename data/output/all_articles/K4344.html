K4344: Reinstalling BIG-IP or 3-DNS system software on platforms that are equipped with a CD-ROM drive

Topic

To remove all configuration settings and restore factory settings, you can reinstall BIG-IP and 3-DNS system software by performing the following steps:

  1. Place the system software CD in the CD-ROM drive.

    For information about how to download software, refer to K167: Downloading software from F5 Networks.

  2. Reboot the system by typing the following command:

    reboot

  3. After the boot completes, the system displays the following menu options:
    1 Install software onto hard disk
2 Setup server to provide network installation
  4. Type 1 and press Enter.

    The system will display a warning message.

  5. If you want to proceed with the installation and delete your current configuration, type Y and press Enter.

    The installation will proceed.

  6. When prompted, press Enter to reboot the system.
