Known Issue

This is the result of a known issue. The BIG-IP ASM system rejects session IDs that contain encoded characters, and reports the following violation:

Illegal Session ID in URL

This behavior occurs when the server responds to a request and includes a session ID with encoded characters. The BIG-IP ASM system rejects any requests from the client that contain the session ID, regardless of whether the session ID contains encoded or decoded characters.

F5 Product Development tracked this issue as CR96082 and it was fixed in BIG-IP ASM 9.4.5. For information about upgrading, refer to the BIG-IP ASM release notes.
