Known Issue

This is the result of a known issue. When changing the Statistics Collection Server for a Generic Host from Auto Select to a specific device such as a BIG-IP system, the setting is not saved to the /config/gtm/wideip.conf file.

F5 Product Development tracked this issue as CR69164, CR59947, and CR68233 and it was fixed in BIG-IP GTM 9.2.4 and 9.3. For information about upgrading, refer to the BIG-IP GTM Release Notes.

Workaround

To work around this issue by manually specifying a statistics server, perform the following procedure:

  1. Log in to the BIG-IP GTM command line.
  2. Using a text editor, edit the following file:

    /config/gtm/wideip.conf

  3. Add the following line to the Generic Host server statement for which you wish to add a Statistics Collection Server, where <prober_ip_address> represents the IP address of the F5 device that will be configured as the Statistics Collection Server.

    prober <prober_ip_address>

    For example, if the Generic Host server name is host.f5.com, add the prober IP address to the Host statement, as follows:

    { // datacenter=gdc, #VS=2   name            "host.f5.com"   type            generic   prober          172.25.25.150        box {      address 2002:a0a:7696:0:10:10:118:101      unit_id 1      }         vs {            name            "blah"            address         1.1.1.2:80 // http   }
  4. Save the changes to the wideip.conf file.
  5. Verify the wideip.conf file syntax after making the change by typing the following command:

    gtmparse

  6. Load the configuration changes to memory by typing the following command:

    gtmload
