Issue

Old Behavior

In BIG-IP versions prior to 10.1.0, when a pool member is added to a pool, the default value for the Priority Group setting is 1. The Priority Group setting assigns a priority number to the pool member, which is used for distributing traffic according to priority levels when the Priority Group Activation is enabled on the pool.

New Behavior

Beginning in BIG-IP 10.1.0, the default value for the Priority Group setting is 0 when a pool member is added to a pool. When a pool member has its Priority Group setting assigned 0, the pool member will have the lowest priority. If a pool has Priority Group Activation enabled and all of the members in the same pool have their Priority Group setting assigned 0, all of the members will have equal priority.

F5 Product Development tracked this change as ID 209095 (formerly CR123571).

Impact

None

Recommended Actions

None. However, if the BIG-IP system is not distributing traffic to new pool members, you should verify that the priority group settings are set appropriately for all members in the affected pool. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Pools > Pool List.
  3. Click the link under the Members column for the affected pool.
  4. Inspect the Priority Group column for all the members in the affected pool.
  5. Optional: If the priority group setting for a pool member is incorrect, click on the affected pool member.
  6. Optional: Type the appropriate value in the Priority Group box for the pool member.
  7. Optional: Click Update to save the changes.
  8. Optional: Repeat steps 2 through 7 if the priority group setting for other pool members are incorrect.
