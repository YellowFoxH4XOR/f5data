K11576305: /Common/bigip monitor on a Generic Host may cause the configuration to not load

Description

BIG-IP DNS configuration not loading after upgrade. 

An error message similar to following can be seen in /var/log/ltm file:

Apr  5 07:02:37 localhost err mcpd[8617]: 01071033:3: Server (/Common/192.0.2.10) contains monitor (/Common/bigip) which is an invalid type.

This can happen even after a reboot or license re-activation.

Environment

  • BIG-IP DNS Server settings
  • Generic Host with bigip monitor applied
  • BIG-IP DNS 

Cause

Bug ID 718230

Recommended Actions

Modify the DNS/GTM configuration to manually remove the monitor

  1. SSH to log into the BIG-IP

  2. Edit /config/bigip_gtm.conf

    vim /config/bigip_gtm.conf

  3. Search for the Server object in question:

    gtm server /Common/generic-host.example.com {
        addresses {
            192.0.2.10 {
                device-name /Common/generic-host.example.com
            }
        }
        datacenter /Common/Default
        monitor /Common/bigip   <---------------------------
        product generic-host    <--------------------------

  4. Delete the line monitor /Common/bigip line or change to the monitor to /Common/icmp_gatewway

    For Example:

    gtm server /Common/generic-host.example.com {
        addresses {
            192.0.2.10 {
                device-name /Common/generic-host.example.com
            }
        }
        datacenter /Common/Default
        monitor /Common/icmp_gateway   <---------------------------
        product generic-host

  5. Reload the configuration

    tmsh load /sys config gtm-only
