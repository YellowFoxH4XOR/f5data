K000149754: Why is HTTP 400 Response Code missing from XC request/API access logs

Description

I want to know why the HTTP 400 Response Code is missing from F5® Distributed Cloud (XC) request/API access logs.

Environment

  • F5® Distributed Cloud

 

Answer/Recommended Actions

Since 400 response code indicates the request was invalid HTTP, XC drops this at the front door and does not forward it to other microservices within XC (including logging) for further processing since this would be a waste of time and resources. Instead, XC recognizes that the request is invalid HTTP and drops it without further processing.
