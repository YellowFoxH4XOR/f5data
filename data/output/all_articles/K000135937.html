K000135937: BIG-IQ not sending logs to configured syslog server

Type
Support Solution
Published
2023-09-11
Updated
2023-09-11
Source
https://my.f5.com/manage/s/article/K000135937

Description

  • No packets are sent to the remote logging device after initial configuration

Environment

  • BIG-IQ 8.1.0.2, 8.2.0
  • CM

Cause

Unknown Software issue (at the moment of publishing this information)

Recommended Actions

Perform a modification to the syslog server settings, for example check or uncheck a "Service" (like Access) 

Additional Information

None
