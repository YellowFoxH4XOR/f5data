K7669: Using Express Connect for HTML pages with base tags and a relative path URL causes an HTTP 404 response page

Known Issue

This is the result of a known issue. The WebAccelerator Express Connect feature does not honor a base tag value with a relative path URL. The base tag specifies a base URL for links in the page; however, the WebAccelerator will incorrectly re-write the link. As a result, the client will request objects using an incorrect path URL resulting in an HTTP 404 response page, with a page not found error message.

For example, if the base tag specifies a relative path URL using ../, the WebAccelerator will ignore the two periods and insert the express connect fully qualified domain name when rewriting the link. Additionally, if the base tag specifies a relative path URL using a sub-directory without a preceding slash, the WebAccelerator will ignore the directory when rewriting the link.

F5 Product Development tracked this issue as CR76935 and it was fixed in BIG-IP WebAccelerator version 9.4.2. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Note: Starting in BIG-IP WebAccelerator version 9.4.2, the Express Connect feature is called MultiConnect.

Workaround

If upgrading is not an immediate option, you can work around this issue by disabling the WebAccelerator Express Connect feature.

Note: You can also modify your HTML base tags so they do not use relative path URLs.

To disable the WebAccelerator Express Connect feature, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click WebAccelerator.
  3. Click Applications.
  4. Under the Action column, click the Edit link for the application for which you want to disable the Express Connect feature.
  5. In the Hosts section in the Action column, click the Options link for the requested host for which you want to disable the Express Connect feature.
  6. Select 0 (zero) from the HTTP Subdomains drop-down menu.
  7. Select 0 (zero) from the HTTPS Subdomains drop-down menu.
  8. Click Save.
