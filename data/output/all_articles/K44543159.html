K44543159: Error: [braces are required around the expression] When Deploying an iRule from BIG-IQ

Type
Support Solution
Published
2021-09-27
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.1.X, 7.0.X, 8.X.X, 7.X.X, 8.0.X
Source
https://my.f5.com/manage/s/article/K44543159

Description

When deploying an iRule from BIG-IQ onto a BIG-IP, an error similar to this one appears on the screen: 

Transaction <<transaction ID>> on BIG-IP <<IP>> failed after 0 seconds: Rule [<<name of the irule>>] error: <<name of the irule>>:6: error: [braces are required around the expression][<<Full Conent of the iRule>>]

If the deploy target is an HA pair the device that receives the changes first will get the above error.
The peer that was second in line will show the error below in the GUI pop up message:

Writing changes to the peer failed so they were not synced to this device

Environment

  • Deploying an iRule from BIG-IQ GUI
  • Using Unicode or UTF-8 characters

Cause

 Valid Unicode or UTF-8 characters that are used in iControl REST commands are parsed incorrectly.

Recommended Actions

Remove or replace invalid  Unicode or UTF-8 characters and deploy again. 

Additional Information

In the below example  iRule code we use non-standard quotation marks  “ ”.

when HTTP_RESPONSE
{
     log local0. “This is a log”
}

This will throw the error:

Transaction 1620502057960224 on BIG-IP <IP> failed after 0 seconds: 01070151:3: Rule [/Common/test_irule] error: /Common/test_irule:6: error: [braces are required around the expression][when HTTP_RESPONSE { log local0. “This is a log”}]


This version with standard quotation marks can be deployed without error:

when HTTP_RESPONSE
{
     log local0. "This is a log"
}
