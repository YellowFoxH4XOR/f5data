Known Issue

The BIG-IP ASM bd process may produce a core file when the security policy encoding is modified.

This issue occurs when all of the following conditions are met:

  • A security policy configuration uses language encoding that has many secondary encodings (such as GBK).
  • The BIG-IP system receives a high rate of requests where parameters or URLs are using different secondary encodings (such as GB18030, GB2312, and Big5).
  • The BIG-IP ASM administrator modifies the security policy language encoding.

Impact

BIG-IP ASM fails to pass traffic while the bd process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the BIG-IP ASM administrator applies a modified policy, the bd process produces a core file in the /var/core directory.
  • Messages similar to the following example are logged to the /var/log/ts/bd.log file:

    BD_MISC|CRIT |<date - time>|12345|signals.c:0055|Received SIGSEGV - Core Dumping
