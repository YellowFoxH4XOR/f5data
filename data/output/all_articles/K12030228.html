Known Issue

The BIG-IP APM rewrite profile may fail to process cookies.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • The domain attribute of the cookie is set to an empty value.

Impact

The web application does not function as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The web application does not function as expected.
  • The browser error console displays an error message similar to the following example:

    Object doesn't support this property or method
