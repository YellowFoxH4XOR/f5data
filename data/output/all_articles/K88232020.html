Description
An error message similar to the following may appear in /var/log/audit on the BIG-IP after upgrade from a BIG-IP version previous to 13.1 to a version 13.1.0.5 or later, after enabling BIG-IQ statistics collection (post-upgrade).
01020036:3: The requested application instance (/Common/bigiq-analytics.app/bigiq-analytics) was not found 

Environment

  • BIG-IP
  • BIG-IQ

Cause
BIG-IP v. 13.1.0.5 and later now use the AVR (analytics) module to stream statistic data to the BIG-IQ DCDs. 
Prior to this version, AVR was not required to be provisioned, but with 13.1.0.5 and up AVR must be provisioned on the BIG-IP instance.

Recommended Actions

This action will be temporarily disruptive to services.  Please arrange to complete during a maintenance window or on a standby unit.
  1. Disable statistics gathering at the BIG-IQ for the BIG-IP instance in question.
  2. On the BIG-IP, navigate to System > Resource Provisioning.
  3. Select the Application Visibility and Reporting (AVR) and provision with Minimal.
  4. Click Submit.
  5. The BIG-IP will restart services.
    Important: While the BIG-IP restarts services traffic processing will not be performed.
  6. Re-enable statistics gathering at the BIG-IQ for the BIG-IP instance in question.
  7. Allow 5-10 minutes for the new settings to take complete effect.
