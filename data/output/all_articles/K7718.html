Note: F5 does not recommend configuring the management IP address as the mirroring address. You should configure a self IP address as the mirroring address.

In most versions of BIG-IP, the system prohibits configuring the mirroring IP address on the same network as the management port.

Note: The mirroring address is identified as the Mirroring Address in version 10.x, the Connection Mirror Address in version 9.4.x, and the Failover Address in version 9.3.x.

The BIG-IP system prohibits configuring the management IP address as the mirroring address in versions 9.1.2, 9.2.x, 9.4.x, and 10.x. If you attempt to configure the management IP address as the mirroring address using the Configuration utility or the command line, the BIG-IP system generates an error message that appears similar to the following example:

01070707:7: The state mirroring address, statemirror.secondary.peeripaddr, <ip_addr> may not be on the same network as the management port

In BIG-IP version 9.1.3, 9.3.0, and 9.3.1, the system permits you to configure the mirroring IP address on the same network as the management port, although in these versions the BIG-IP system logs the following warning message to the /var/log/ltm file when you configure the management IP address as the mirroring address:

Warning: use of the management port for state-mirroring traffic may severely impact state-mirror functionality!

F5 Product Development tracked this enhancement as CR67009 and CR67010, and it was changed in BIG-IP LTM versions 9.1.3 and 9.3.0.
