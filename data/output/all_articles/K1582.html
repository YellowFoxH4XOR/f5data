K1582: Configuring cookie persistence that will last only until the client's browser session is closed

Topic

BIG-IP version 4.0 through 4.6.4

Type the following command where <pool_name> is the name of the pool on which you want to configure the session-based cookie:

b pool <pool_name> { persist_mode cookie cookie_mode insert }

BIG-IP version 3.0 through 3.3.1 PTF-06

Type the following command where <pool_name> is the name of the pool on which you want to configure the session-based cookie:

bigpipe pool <pool_name> { persist_mode cookie cookie_mode insert cookie_expiration 0d 00:00:00 }
