Description

This article describes how to enable audit log and remote logging for bash commands, which includes commands executed from tmsh run util bash.

Environment

  • BIG-IP All version

Cause

By default, user's bash command activities are not logged.

It's possible to log all the bash commands invoked by users on the system.

Recommended Actions

To enable audit logging for system user bash command activity, the actions or steps required following.

  1. SSH to BIG-IP.
  2. Add following lines into /etc/audit/rules.d/audit.rules
    -a always,exit -F arch=b64 -S execve -F uid=0 -k root_commands
    -a always,exit -F arch=b32 -S execve -F uid=0 -k root_commands
    Note: Changes to /etc/audit/rules.d/audit.rules will not persist across an upgrade. Any time you upgrade these audit.rules will need to be re-submitted and saved.
  3. To load the configuration change, run following.
    # augenrules --load
    Note: The audit log is written to /var/log/auditd/audit.log.  The system audit log is rotated when the file size reached at 8MB, and number of rotated file is 5.
  4. To send system audit logs to a remote syslog server.
    Refer to the steps described in K66016476 Send system audit Logging to an external destination
