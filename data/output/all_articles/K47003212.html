K47003212: SSLO GUI pull-down menu is unavailable in Firefox

Type
Support Solution
Published
2021-01-27
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP SSL Orchestrator: 15.X.X, 15.0.X, 15.1.1, 15.1.0, 15.1.X, 15.0.0
Source
https://my.f5.com/manage/s/article/K47003212

Description

When you use Firefox for SSLO Guided Configuration, pull-down menu may be unavailable.
Then you may not able to select the certificate or key in "Certificate Key Chain" or "CA Certificate Key Chain" in "SSL Configurations" section.
 

Environment

  • F5 SSL Orchestrator
  • Mozilla Firefox
  • SSL Orchestrator Guided Configuration
  • "Certificate Key Chain" or "CA Certificate Key Chain" in "SSL Configurations" section

Cause

Unknown.

Recommended Actions

  1. Check the supported browser version.
  2. Use another browser (ex. Chrome)

Additional Information

None.
