Description

Unable to find the Attack Signature set Generic Detection Signatures (High/Medium Accuracy).
 

Environment

  • Generic Detection Signatures is available
  • Latest Attack Signature file ( 12 Dec 21 ) is installed
  • Required LOG4J Signatures are installed and available


Cause

In version 13.x ( and 12.x and 11.x ) , the following two sets are not available; it is by design:

  • Generic Detection Signatures (High Accuracy)
  • Generic Detection Signatures (High / Medium Accuracy)


These are available in 14.x and later versions.


Recommended Actions

None.


Additional Information

The two differences between the set 'Generic Detection Signatures (High / Medium Accuracy)' and 'Generic Detection Signatures' are:

Generic Detection Signatures (High / Medium Accuracy)

  • Systems: System Independent, General Database, Various systems
  • Accuracy: Greater Than/Equal To Medium


Generic Detection Signatures

  • Systems: All
  • Accuracy: All
