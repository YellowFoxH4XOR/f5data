K000151248: During software upgrade , config load fails with error:- "state" may not be specified more than once

Support Solution

2026-03-06
Applies to

  • BIG-IP ASM: 17.5.0
Source
https://my.f5.com/manage/s/article/K000151248

Description

When upgrading BIG-IP to 17.5.0, the following errors may occur during configuration load: "Syntax Error: (/config/bigip.conf at line: XXXX) "state" may not be specified more than once"

Environment

  • BIG-IP
  • Software upgrade version: 17.5.0
  • Configuration in bigip.conf, including node, pool, or virtual server objects with multiple "state" directives.

Cause

The error "state" may not be specified more than once occurs when duplicate "state" directives (such as state disabled or state enabled) are defined for the same object in the configuration file.

Recommended Actions

  • Before making any changes to the configuration file, you should create a backup copy using the  command:
    cp /config/bigip.conf /config/bigip.conf.backup
  • Open `/config/bigip.conf` and search for objects (nodes, pools, virtual servers or other config objects) with more than one "state" directive.
  • Remove any duplicate "state" lines so each object has only one directive. For example,  removed "state disabled" from below snip of config:
    • per-dst-ip-limit-pps infinite
    • per-source-ip-detection-pps infinite
    • per-source-ip-limit-pps infinite
    • scrubbing-category /Common/attacked_ips
    • scrubbing-detection-seconds 10
    • scrubbing-duration 900
    • simulate-auto-threshold disabled
    • state detect-only
    • state disabled  ----> remove this
  • Verify config load again 'tmsh load sys config verify partitions all' to see if error disappears.
