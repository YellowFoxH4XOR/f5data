K000137141: LDAP remote authentication lookup failed: Inappropriate authentication

Type
Support Solution
Published
2023-12-07
Updated
2023-12-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.9
Source
https://my.f5.com/manage/s/article/K000137141

Description

LDAP remote authentication fails with message similar to:

 

<authc="loginuser"> cn=F5Admins,ou=group,dc=f5,dc=com: lookup failed: Inappropriate authentication


in /var/log/secure.

Environment

  • LDAP remote authentication

 

Cause

This error message has multiple causes. One common cause is the account being used to perform the simple bind does not have a password because it is not a user account.

 

LDAP remote authentication uses the supplied username to perform a LDAP Query for an LDAP account, and then attempts a simple bind for that account using the supplied password. It is possible that the account returned by the ldapsearch is not the account expected.

 

In the above example, the account that was returned by the ldapsearch was a group not a user, so it can not be authenticated with the user's password. This might be a result of a misconfigured search directory or search filter.

 

Recommended Actions

Ensure search-base-dn and login-attribute are configured so as to return the correct user account from the ldapsearch using the supplied username. The ldapsearch tool in the cli can be used to test various combinations of search-base-dn and login-attribute, as in the Troubleshooting LDAP authentication for BIG-IP administrative users article.
