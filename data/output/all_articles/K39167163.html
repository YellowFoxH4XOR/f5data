Known Issue

In rare instances, the devmgmtd process may produce a core file if a timeout condition occurs during an iControl query.

This issue occurs when the following condition is met:

  • A timeout occurs during an iControl query.

Impact

The daemon recovers and proceeds with the operation.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You view error messages in the /var/log/messages file that appear similar to the following examples:

    notice logger: Started writing core file: /var/core/devmgmtd.bld4.0.420.core.gz for PID 8137
    notice logger: Finished writing 9534529 bytes for core file: /var/core/devmgmtd.bld4.0.420.core.gz for PID 8137

  • A devmgmtd core file is present in the /shared/core directory.
