Description

BIG-IP goes offline after deleting ib_logfile files from /var/lib/mysql/. Similar errors will be found on mysqld.err log:

mysqld.err log

230928 17:41:28 mysqld_safe mysqld from pid file /var/lib/mysql/mysqld.pid ended
230928 17:41:33 mysqld_safe Starting mysqld daemon with databases from /var/lib/mysql
230928 17:41:33 [Note] /usr/sbin/mysqld (mysqld 5.5.53-MariaDB) starting as process 39237 ...
230928 17:41:33 InnoDB: The InnoDB memory heap is disabled
230928 17:41:33 InnoDB: Mutexes and rw_locks use GCC atomic builtins
230928 17:41:33 InnoDB: Compressed tables use zlib 1.2.7

230928 17:41:33 InnoDB: Completed initialization of buffer pool
InnoDB: Error: log file ./ib_logfile1 is of different size 0 0 bytes
InnoDB: than specified in the .cnf file 0 268435456 bytes!
InnoDB: Possible causes for this error:
(a) Incorrect log file is used or log file size is changed
(b) In case default size is used this log file is from 10.0
(c) Log file is corrupted or there was not enough disk space
In case (b) you need to set innodb_log_file_size = 48M
230928 17:41:33 [ERROR] Plugin 'InnoDB' init function returned error.

230928 17:41:33 [ERROR] Aborting

The root/.bash_history can be checked, to confirm the file has been deleted.
 

Environment

  • Disk space maintenance
  • ASM
  • MySQL

Cause

Removal of the ib_logfile on /var/lib/mysql/.

 Recommended Actions

  1. Stop mysql 
    # bigstart stop mysql
  2. Remove logfile mysql/ib_logfile
    # /bin/rm -f /var/lib/mysql/ib_logfile*
  3. Start mysql 
    # bigstart start mysql

Note: Restarting mysql is service interrupting. Perform the recommendations during maintenance window.
