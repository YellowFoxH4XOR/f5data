K11953353: Error Message: Cannot add the Data Collection Device because the Cluster GUID could not be set.

Type
Support Solution
Published
2021-10-27
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K11953353

Description
When attempting to add a DCD node to the BIG-IQ cluster of data collection devices, you may encounter error:

 ...[/cm/shared/cluster-guid ClusterGUIDWorker] Unable to save the cluster GUID due to com.f5.rest.workers.storage.KeyNotFoundException: cm/shared/cluster-guid
 

Environment

  • BIG-IQ 

Cause
BIG-IQ experiences a corrupted GUID for the cluster.

Recommended Actions

  1. Restart restjavad on all BIG-IQ Data Collection Devices and Configuration Manager:
    tmsh restart /sys service restjavad
     

Additional Information

You may see this error in /var/log/restjavad.x.log:
