Known Issue

This is the result of a known issue. When you type the no windows-mgmt-auth ? command from within global configuration mode, the ARX CLI Help incorrectly prompts for a policy name to be specified.

For example: 

arx01(gbl)# no windows-mgmt-auth ?

 / - Specify the policy name.

The question mark ( ? ) character should prompt the ARX CLI Help to display the Windows management-authorization group(s) that can be specified.

For example:

arx01(gbl)# no windows-mgmt-auth ?

winmgmt1               -
winmgmt2              -
Text<1-64>          - Specify the windows management authorization group.

F5 Product Development tracked this issue as ID 35925 and it was fixed in ARX version 5.1.0. For information about upgrading, refer to the ARX release notes.
