Known Issue

The BIG-IP system may fail to delete a self IP address.

This issue occurs when all of the following conditions are met:

  • You create a static route using a Virtual Local Area Network (VLAN) as resource.
  • You attempt to delete a self IP that is associated with the VLAN.

Impact

You are unable to delete a self IP address.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You are unable to delete a self IP address.
  • When you use the Configuration utility or Traffic Management Shell (tmsh) to attempt to delete a self IP address, you receive an error message similar to the following example:

    0107172e:3: Cannot delete SelfIP /Common/routeTest as the vlan /Common/internal that it references is referenced by the route static entry /Common/staticRouteSelfIPtest.

Workaround

To work around this issue, you can temporarily remove the static route entry, delete the self IP, and then recreate the static route entry again. To do so, perform the following procedure:

Impact of workaround: Removal of the affected configuration may disrupt services that are already in use. F5 recommends that you perform this procedure during a scheduled maintenance window for the affected BIG-IP system.

  1. Log in to the Configuration utility.
  2. Navigate to Network > Routes.
  3. Select the checkbox of the affected VLAN resource route.
  4. Click Delete, then click Delete to confirm deletion of the route.
  5. Navigate to Network > Self IPs.
  6. Select the checkbox of the self IP you wish to delete.
  7. Click Delete, then click Delete to confirm deletion of the self IP.
  8. Navigate to Network > Routes.
  9. Click Add.
  10. Enter the name of the route.
  11. Enter the Destination IP address and Netmask.
  12. Select the resource to use VLAN/Tunnel from the Resource menu.
  13. Select the desired VLAN from the VLAN/Tunnel menu.
  14. Click Finish.
