Description
iRules SSL::sessionid command returns an empty string when Frequency of Client Authentication for Client SSL Profile is set to Always.

Environment
  • iRules SSL::sessionid
  • Client SSL Profile
Cause
When the Client Authentication is set to Always in Client SSL profile, BIG-IP requires the client to present a certificate every time so the system can neither cache the session nor will it send a session ID.

Recommended Actions
To enable cache of the Session ID on the system, perform the following procedure:
Note: The Frequency setting specifies the frequency of client authentication for an SSL session. The default value for this setting is once. 
  1. Go to Local Traffic > Profiles > SSL > Client.  
  2. Select name of the affected Client SSL profile.
  3. Under Client Authentication section, select Once for Frequency. 
  4. Select Update.
