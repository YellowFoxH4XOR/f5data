Description

You need to track usage for Software modules provisioned on Hardware (SWonHW) licensed through the Hybrid Flex Consumption Program (H-FCP), formerly HELA (Hybrid Enterprise License Agreement).

Environment

  • BIG-IP
  • iSeries/rSeries
  • Viprion/VELOS
  • H-FCP/HELA
  • SWonHW

Background

This subscription differs from a standard Software-only Flex Consumption Program (FCP) in that it allows for the purchase of FCP-specific Hardware, and the licensing of the corresponding Software modules, through the FCP, which is why it is referred to as a Hybrid-FCP (H-FCP). The assigned license key or add-on is referred to as a “Golden Key” because it includes all functionality of a Best License. SWonHW refers to the fact that these are subscription-based Software Modules provisioned on Hardware.

Monthly Reporting

Per the program terms, Software Modules are included in the monthly activity report at the time the hardware is shipped, not when it's installed. The modules included in the original commit are automatically billed until the customer informs their Customer Success Manager (CSM) that additional software modules are provisioned. 

Tracking software provisioning is either a manual process where the customer informs their Customer Success Manager of any changes or they utilize the FCP Usage Script from BIG-IQ Centralized Manager.

Components

Software Modules: These are features and capabilities that comprise the Best License which includes APM, AFM, AWF (formerly ASM), AVR, DNS (formerly GTM), LTM, and Advanced Routing.

  • Billed per appliance (iSeries/rSeries) or per blade (Viprion/VELOS), regardless of the number of vCMP guests or tenants. For example, a VELOS chassis with 4 blades and 2 tenants each using LTM and Advanced Routing counts as 4 LTM and 4 Advanced Routing.

Feature Based Subscriptions (FBS): These are time-limited add-on keys, such as, Threat Campaign (TC), IP Intelligence (IPI), Intrusion Prevention System (IPS), Secure Web Gateway (SWG), Uniform Resource Locator (URL), and Policy Enforcement Manager URL (PURL). Once applied, they remained locked to the specific appliance.

  • Billed per appliance (iSeries/rSeries/Viprion/VELOS), regardless of the number of blades, vCMP guests, or tenants. For example, Threat Campaign applied to a VELOS chassis with four blades and 3 tenants counts as just 1 TC.

SSLO:

  • Billed per appliance (iSeries/rSeries) or per blade (Viprion/VELOS), regardless of the number of vCMP guests or tenants. When SSLO is licensed on a VELOS/Viprion chassis, the tenants/vCMP guests must provision SSLO explicitly then are billed for those blades the tenant/vCMP guest uses. For example, if an SSLO tenant occupies just two blades of four in a VELOS, it counts as 2 SSLO.  

FIPS:

  • Billed per appliance (iSeries/rSeries) or all blades (Viprion/VELOS), regardless of the number of vCMP guests or tenants. When FIPS is licensed on a VELOS/Viprion chassis, all the tenants/vCMP guests inherit it and are under FIPS level 2 controls. There is no enabling FIPS per tenant/vCMP guest, therefore, every blade in the chassis counts toward FIPS usage.
