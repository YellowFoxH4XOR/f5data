K000134701: Password required during reboot

Type
Support Solution
Published
2023-05-19
Updated
2023-05-26
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000134701

Description

During the reboot, the Big-IP requires a password to boot. 

Environment

  • Big-IP
  • Remote console

Cause

A boot password is set.

Recommended Actions

To remove the boot password:

  1. Access the Big-IP via a remote console then reboot the Big-IP
  2. When prompted for the password, enter it, then immediately press 'c' to enter setup
  3. Navigate to Security and arrow down to select Set User Password. It should show in the upper right corner.
  4. Change the password to nothing (leave blank)
  5. Select yes for "Clear old password"
  6. Save and exit setup

Additional Information

None
