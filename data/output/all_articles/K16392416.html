Description

Memory errors

The system observes memory errors when reading the value of a memory location. If the value from that location does not read as expected, the system reports a memory error.

The following are types of memory errors:

  • Hard memory errors are caused by a persistent physical defect in the memory module. This type of error occurs when the system uses a defective memory cell. Thus, they usually repeat.
  • Soft memory errors are caused by brief electrical disturbances, regardless of source. This type of error sometimes occurs within the memory module and sometimes comes from outside the system. This type of error is transient, and you can clear these errors by restarting your system.
  • Correctable errors are those in which ECC (error-correcting code) is integrated in the memory module and fixes the error. This type of error does not affect system performance.
  • Non-correctable errors are those which ECC cannot fix. When the system experiences this type of error, it stops processing.

MCE error

The Linux kernel monitors correctable and non-correctable memory errors, and the BIG-IP system reports machine-check (MCE) errors when it detects them. MCE error messages contain detailed information about where the errors exist, how many there are, which component or components are involved, and what type of memory error occurred. The way to decode MCE message varies for each platform based on the type of CPU or memory used.

Workaround for memory errors

There is no direct relation between hard or soft memory errors and correctable or non-correctable memory errors. However, if system operation cannot continue after you restart your system, it's likely that a non-correctable memory error caused a hard error. Soft errors can lead to both correctable and non-correctable memory errors, depending on the magnitude of the electrical disturbance applied to the memory module and strength of ECC integrated in that module. When your system experiences a non-correctable memory error, the best way to determine whether the memory error is hard or soft is to reset the memory module by restarting the system. If the restart resolves the error, it was a soft memory error. If not, it was a hard memory error.
