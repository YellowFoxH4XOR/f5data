Description

Does license reactivation or installing new license affect traffic in BIG-IP tenants?

Environment

  • F5OS
  • License
  • Reactivate
  • Renew

Cause

  • n/a

Recommended Actions

We recommend reactivation and Installation for new license in a scheduled maintenance window and when all BIG-IP tenants are in Standby mode. When re-licensing F5OS, all BIG-IP tenants will automatically reload the license. This will briefly interrupt BIG-IP tenant traffic while the BIG-IP tenant reloads its configuration.
If the license hasn't changed, the BIG-IP tenants recognize that their license file is up to date and no reload occurs. The BIG-IP tenant /var/log/ltm should log an entery similar to the following:

notice chmand[<PID>]: 012a0005:5: The guest license file is up to date. No update necessary.
