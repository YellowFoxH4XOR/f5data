Known Issue

The BIG-IP APM system logs user credentials in plain text when you set virtual desktop infrastructure (VDI) log levels to Debug.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system provides VDI access.
  • You set the VDI log level to Debug.

Impact

The BIG-IP APM system logs user credentials to the /var/log/apm file in plain text.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Entries in the /var/log/apm file appear similar to the following example:

    debug tmm[10269]: 01490000:7: Request (GET / HTTP/1.1  clientless-mode: 3  username: mike  password: mike  password1: 9872 Host: vdi.example.com  User-Agent: CitrixReceiver/7.2.3 iOS/10.3.2 CitrixReceiver-iPad CFNetwork Darwin VpnCapable  client-type: citrix  Content-Length: 0  X-Forwarded-For: 172.20.15.10  X-Citrix-Via: vdi.example.com    )

Workaround

To work around this issue, you can set the VDI log level to the default Notice setting. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

BIG-IP APM 13.0.0 and later

  1. Log in to the Configuration utility.
  2. Navigate to Access > Overview > Event Logs > Settings.
  3. Select the name of the log settings and click Edit.
  4. In the Access System Logs section, set the log level to Notice.
  5. Click OK.

BIG-IP APM 11.6.0 - 12.x

  1. Log in to the Configuration utility.
  2. Navigate to System > Logs > Configuration.
  3. In the Access Policy Logging section, set the log level to Notice.
  4. Click Update.

BIG-IP APM 11.5.4

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Set the log level to Notice by typing the following command:

    modify /sys db log.vdi.level value notice
