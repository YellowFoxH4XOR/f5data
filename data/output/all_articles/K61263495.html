Topic

You should consider using this procedure under the following condition:

  • You want to view PCI compliance status for one or more security policies.
  • You want to improve the PCI compliance status for a security policy.

Description

The Payment Card Industry Data Security Standard (PCI DSS) is a credit card security standard that was created to improve the security practices for organizations that manage and transmit cardholder data. You can use the Configuration utility to view PCI compliance reports and review suggestions to improve the PCI compliance status for a security policy.

The following table lists the PCI security requirements and the corresponding BIG-IP configuration object.

Security requirementRelevant BIG-IP configuration
Install and maintain a firewall configuration to protect cardholder dataN/A
Do not use vendor-supplied defaults for system passwords and other security parametersSystem > Platform > User Administration

Encrypt transmission of cardholder data across open, public networksLocal Traffic > Virtual Servers

Protect all systems against malware and regularly update antivirus software or programsN/A

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the Configuration utility.

Procedures

Viewing or improving the PCI compliance status for a security policy

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log into the Configuration utility.
  2. Navigate to Security > Reporting > Application > PCI Compliance.
  3. Click the policy name to view the PCI compliance status for that policy.
  4. Under Executive Summary, each PCI compliance requirement is designated with an icon that indicates the compliance state. The PCI compliance states are defined as follows:
    • Fully compliant: items with a green check mark.
    • Partially compliant: items with an exclamation mark.
    • Not compliant: items with a red X.
    • Not directly relevant to the BIG-IP ASM configuration: items marked with N/A.
  5. To improve the PCI compliance status for a specific requirement, click the hyperlink for the requirement and adjust the non-compliant settings.
  6. To display a printable PCI compliance report for the security policy, click Printable Version.
