Description

It is required to add the "partitioned" attribute to a Cookie.

 

Environment

BIG-IP LTM

Cookies

 

Cause

Required to add a "Partitioned" attribute in the "Set-cookie" header.

 

Recommended Actions

The HTTP::cookie attribute can be used to check, add, or delete the Partitioned attribute.

 

Example:

 

when HTTP_RESPONSE {

HTTP::cookie insert name "my_test_cookie" value "test"

HTTP::cookie attribute "my_test_cookie" insert "Partitioned"

}
