K000148669: After upgrading, offline device status, and license issues "A valid service contract is required to complete installation"

Type
Support Solution
Published
2024-11-21
Updated
2024-11-21
Source
https://my.f5.com/manage/s/article/K000148669

Description

The SKU V16 and under in the devices license does not allow for version 17.x to be installed. After upgrading, you read a banner like the following in the provisioning tab:

"A valid service contract is required to complete installation"

 

Environment

Big-IP LTM

SKU V16

Upgrading

 

Cause

V16 sku does not allow version 17.x to be installed

K15643: BIG-IP VE Version Plus license offerings

 

Recommended Actions

Contact account manager to request an update from V16 to V18.

 

Additional Information

None
