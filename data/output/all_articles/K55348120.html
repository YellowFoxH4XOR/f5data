Description
Assistance required to generate the passphrase values required for configuring a certificate that uses a passphrase with an AS3 declaration

Example AS3 declaration:

"certificate1": {
    "class": "Certificate",
    "remark": "replace these with real certificates and keys",
    "certificate": "<Certificate>",
    "chainCA": "<Certificate>",
    "privateKey": "<Key>",
    "passphrase": {
        "ciphertext": "<text>"
    }
}

Environment

  • BIG-IP
  • AS3
  • Certificate with passphrase required

Cause
N/A

Recommended Actions

Generating the ciphertext:

  1. On the CLI of a Linux device, run the following command:  echo -n <passphrase> | base64 -w0 | tr '+/' '-_' | tr -d '=' ;
  2. The output of the command is the ciphertext value to input into the AS3 declaration.
Example:
 
$ echo -n test | base64 -w0 | tr '+/' '-_' | tr -d '=' ;
dGVzdA
 

Additional Information

https://clouddocs.f5.com/products/extensions/f5-appsvcs-extension/latest/refguide/schema-reference.html#certificate-passphrase

The above example is using the default value ‘protected’=’eyJhbGciOiJkaXIiLCJlbmMiOiJub25lIn0' (you do not need to include this if it is the default).  You may also modify the protected value to use a SecureVault cryptogram if you have one or wish to generate one:
