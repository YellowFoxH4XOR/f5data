Description

WebUI: Device Management -> Overview : Stops responding after few seconds.

Environment

  • BIG-IP
  • GUI
     

Cause

Bug ID 853613

Recommended Actions

Check tm.tcpsendrandomtimestamp is set enable by running the following command on CLI:
 
tmsh list sys db tm.tcpsendrandomtimestamp
 sys db tm.tcpsendrandomtimestamp {
    default-value "disable"
    scf-config "false"
    value "enable"    
    value-range "disable enable"
 }
Set the value to disable by running the following command on CLI:
tmsh modify sys db sys db tm.tcpsendrandomtimestamp value disable
