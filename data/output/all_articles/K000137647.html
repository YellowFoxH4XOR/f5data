K000137647: Cannot install APM Clients 7.2.4.5 using MSI - Error 1406

Type
Support Solution
Published
2023-11-22
Updated
2024-06-06
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000137647

Description

You are installing Edge Client using MSI and you receive the error message:

Product: BIG-IP Edge Client -- Error 1406. Could not write value AskAboutUntrustedSSLCert to key \SOFTWARE\F5 Networks\RemoteAccess. System error . Verify that you have sufficient access to that key, or contact your support personnel.

Environment

  • BIG-IP APM
  • BIG-IP Edge Client
  • MSI installation

Cause

This is an installation issue with MSI

Recommended Actions

Edge Client requires this command for MSI installation to avoid the error:

For normal mode:
You must set IGNORESSLSERVERCERTERRORS and ALLOWHTTPCONNECTIONS.
The command syntax is as follows:

msiexec /i f5fpclients.msi /qn IGNORESSLSERVERCERTERRORS=<Value 0 or 1> ALLOWHTTPCONNECTIONS=<Value 0 or 1> /l*vx log.txt

For always connected mode:
-- Using msiexec: For example, for always-connected mode, you must set DISCONNECTEDVPNOPTION, DNSSUFFIXES, STARTAPPWITHWINDOWS, and IP, Stonewall exclusion list.
The command syntax is as follows:

msiexec /i f5fpclients.msi /qn DISCONNECTEDVPNOPTION=<One of NumericValue Provided as below> DNSSUFFIXES=<Will be provided by the user> STARTAPPWITHWINDOWS=<Value 0 or 1> IP0=<Exclusion Domain suffix 1> IP1=<Exclusion Domain suffix 2> IP2=<Exclusion Domain suffix 3> IP3=<Exclusion Domain suffix 4> IP4=<Exclusion Domain suffix 5>  IGNORESSLSERVERCERTERRORS=<Value 0 or 1> ALLOWHTTPCONNECTIONS=<Value 0 or 1>/l*vx log.txt


IGNORESSLSERVERCERTERRORS=0 -> Does not allow Untrusted servers in Windows Edge client.

IGNORESSLSERVERCERTERRORS=1 -> Allows untrusted servers in Windows Edge Client

ALLOWHTTPCONNECTIONS=0 -> Does not Allow HTTP VS in Windows Edge Client.

ALLOWHTTPCONNECTIONS=1 -> Allow HTTP VS in Windows Edge Client
 

When we set these in the msi command -> the registry value AskAboutUntrustedSSLCert and AllowHTTPConnections is set with value 0 or 1 to key \SOFTWARE\F5 Networks\RemoteAccess and hence the ERROR won't be seen

 

Additional Information

Beginning in APM Clients 7.2.4.7, you can enable connect/disconnect sound. For more information, refer to the APM Clients 7.2.4.7 release notes.
msiexec /i f5fpclients.msi /qn CONNECTIONSOUND=<Value 0 or 1> /l*vx msiInstallerLog.txt

<CONNECTIONSOUND> 

0 - Disable the Connect/Disconnect Sound
1 - Enable the Connect/Discounnect Sound
