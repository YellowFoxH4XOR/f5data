Description

ASM remote logging fails when using UDP.

Remote logs are missing. Messages similar to the following appear in bd.log and asm.log:

ASM configuration error: event code L3350 Failed to write to remote logger vs_name_crc 1119927693
LoggingAccount.cpp:3348`remote log write FAILED res = -3 <Failed to send remote message (remote server not responding)> errno <Message too long>.

Environment

-- A remote logger configured for UDP.
-- Max message length of 64 KB.

Cause

UDP message length used is too large.

Recommended Actions

Reduce the UDP message length from 64 KB to 1 KB.

or

Use TCP instead
