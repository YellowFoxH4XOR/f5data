Known Issue

MOS may fail to boot on some platforms due to missing kernel modules.

This issue occurs when all of the following conditions are met:

  •  You are running one of the following BIG-IP platforms: 1600, 6900, 11050, and VIPRION 2400. (These are the platforms known to be affected by this issue.)
  • The MOS was installed from the affected version.
  • The boot loader has been configured to boot to TMOS maintenance, by default. This may happen after you use the mosreboot command.

You can use the command grub_default -d to check the MOS version currently installed, where #TIC_STATIC_VERSION indicates the version of the MOS. For example, the output from grub_default -d  for the entry TMOS maintenance may appear similar to the following example:

title TMOS maintenance
    root (hd0,0)
    kernel /vmlinuz.mos root=/dev/ram0 rw console=ttyS0 ramdisk_size=155487 skip_media
    initrd /initrd.img.mos
    # TIC_STATIC_KEY: st.mos
    # TIC_STATIC_VERSION: 2.7.2-17.0

Impact

You are unable to boot the system into MOS to perform maintenance tasks.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • MOS failed to boot up, displaying an error message that appears similar to the following example:

    Kernel panic - not syncing: Attempted to kill init!

Workaround

To work around this issue, you can manually re-install the MOS using the ISO file from the version that has the issue fixed. To do so, perform the following procedure:

Impact of workaround: The installation of MOS is non-intrusive to the BIG-IP system services. However, maintenance tasks that you must perform after installing the new MOS would cause a service disruption on the BIG-IP system.

  1. Log in to the BIG-IP system command line.
  2. As a precautionary measure, create a UCS backup and store it in a safe location on the network. You can create a UCS archive by typing the following command:

    tmsh save /sys ucs config.ucs

  3. Create the /var/tmp/addmos file by typing the following command:

    touch /var/tmp/addmos

  4. Using a text editor, open the /var/tmp/addmos file.
  5. Paste the following code into the file:

    #!/usr/bin/perl
    use tm_install::Process;
    Process_add_mos($ARGV[0]);

  6. Save the file and exit the text editor.
  7. Modify the access permissions of the /var/tmp/addmos file by typing the following command:

    chmod 777 /var/tmp/addmos

  8. Install MOS by typing the following command syntax:

    /var/tmp/addmos <BIG-IP version 11.2.0 ISO image>

    For example:

    /var/tmp/addmos /shared/images/BIGIP-11.2.0.2446.0.iso

    The BIG-IP system returns output that appears similar to the following example:

    info: Updating MOS from 2.7.2 - 17.0 to 2.7.4 - 42.0
