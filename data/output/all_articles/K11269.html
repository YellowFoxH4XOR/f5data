K11269: ESI Invalidation does not return invalidation selector status

Topic

When the BIG-IP WebAccelerator receives a properly formed ESI invalidation request containing an invalid selector, the system sends a 200 OK response with the following message body:

Cache Invalidated

The message indicates that the SOAP wrapper transaction was successful; however, the message does not include the status of the action performed for each selector, and specifically does not reflect cache invalidation failure.

For example, if you invalidate content using the WebAccelerator ESI invalidation script described in K9009: The ESI invalidation script for the BIG-IP WebAccelerator, but specify an invalid application name, the system sends the following response:

F5 Networks Product Development is tracking as CR112282 a request to add an XML response message conforming to the ESI Invalidation Protocol v1.0 that includes the status of the action performed for each selector.
