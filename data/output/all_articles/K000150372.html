Description

TCP connection randomly resets with the following indicator: (Hudfilter abort)

This can be seen in various places across the BIG-IP system:

  • LTM/ASM logs contain the following error message:
    [0x31418fb:1527] Cannot initiate response; aborting the flow. (Hudfilter abort)
    [0x31418fb:1527] dosl7 abort (Hudfilter abort)
    [0x31418fb:1527] reconstructed failed (Hudfilter abort)
  • The output of tmsh show /net rst-cause indicates the following:
    -----------------------------------------------
    TCP/IP Reset Cause
    RST Cause: Count
    -----------------------------------------------
    Cannot initiate response; aborting the flow. 162945
    .........

Environment

  • BIG-IP ASM
  • Virtual server redirection configured
  • Bot defense profile attached to the virtual server

Cause

This RST error usually appears when a virtual server does redirection to another virtual server and both of them have BOT Defense profiles attached (two different ones).

Recommended Actions

To mitigate the issue and eliminate communication disruption, update the below system db variables:

Impact of workaround: There is no production impact expected when running these two commands.

From BIG-IP CLI (bash) enter the following commands:

tmsh modify sys db dosl7.cs_validate_ip value disable
tmsh modify sys db dosl7.proactive_defense_validate_ip value disable
