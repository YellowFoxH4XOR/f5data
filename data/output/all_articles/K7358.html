Known Issue

The following error message is logged to the /var/log/tmm log file when the Session Initiation Protocol (SIP) profile does not register correctly with the virtual server to which it is associated:

hudfilter_init: 'SIPP' is not a bottom-level filter

F5 Product Development tracked this issue as CR47559 and it was fixed in BIG-IP LTM version 9.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

Important: The following workaround requires a reboot of the BIG-IP system in order for TMM to acknowledge the necessary changes. It is recommended that the changes be made during a maintenance window to avoid interruption.

Note: You must access the system using the console or the management interface to prevent being disconnected when the system services are restarted.

  1. Log in to the BIG-IP LTM command line.
  2. Using a text editor, open the /config/tmm_base.tcl log file.
  3. Locate the section in the /config/tmm_base.tcl log file that contains filter constraints similar to the following example: 
    ## filter constraints#constrain TCP4 preclude {UDP IPFWD BIGPROTO}constrain UDP preclude {TCP4 IPFWD BIGPROTO}constrain IPFWD preclude {TCP4 UDP BIGPROTO}constrain FTP require TCP4 above TCP4constrain SSL require TCP4 preclude FTP above {TCP4 SSID}constrain HTTP require TCP4 preclude FTP above {TCP4 SSL}constrain DEFLATE require HTTP above {TCP4 SSL HTTP LINE STREAM XML}constrain DEFLATE2 require HTTP above {TCP4 SSL HTTP LINE STREAM XML}constrain LINE require TCP4 above {TCP4 SSL HTTP}constrain STREAM require TCP4 above {TCP4 SSL HTTP}constrain CONNPOOL require TCP4 above {TCP4 SSL HTTP LINE STREAM XML DEFLATE DE$constrain RAMCACHE require HTTP above {TCP4 SSL HTTP LINE STREAM XML DEFLATE DE$constrain SSID require TCP4 above TCP4constrain MSRDP require TCP4 preclude {HTTP FTP} above TCP4

  4. Add the following constrain statement to the end of the section containing the filter constraints:

    constrain SIPP above {TCP4 UDP}

    For example:

    ## filter constraints#constrain TCP4 preclude {UDP IPFWD BIGPROTO}constrain UDP preclude {TCP4 IPFWD BIGPROTO}constrain IPFWD preclude {TCP4 UDP BIGPROTO}constrain FTP require TCP4 above TCP4constrain SSL require TCP4 preclude FTP above {TCP4 SSID}constrain HTTP require TCP4 preclude FTP above {TCP4 SSL}constrain DEFLATE require HTTP above {TCP4 SSL HTTP LINE STREAM XML}constrain DEFLATE2 require HTTP above {TCP4 SSL HTTP LINE STREAM XML}constrain LINE require TCP4 above {TCP4 SSL HTTP}constrain STREAM require TCP4 above {TCP4 SSL HTTP}constrain CONNPOOL require TCP4 above {TCP4 SSL HTTP LINE STREAM XML DEFLATE DE$constrain RAMCACHE require HTTP above {TCP4 SSL HTTP LINE STREAM XML DEFLATE DE$constrain SSID require TCP4 above TCP4constrain MSRDP require TCP4 preclude {HTTP FTP} above TCP4constrain SIPP above {TCP4 UDP}
  5. Save the changes to file.
  6. Reboot the system by typing the following command:

    bigstart restart

    This command will restart all services on the BIG-IP LTM. If the unit is active, this command will initiate a failover.
