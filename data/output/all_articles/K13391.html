Topic

Suspected defective devices that are returned directly to F5 U.S. receiving agent (Cokeva) from outside the United States as part of the Return Materials Authorization (RMA) process must include a completed commercial invoice for U.S. customs purposes.

Description

You must complete the commercial invoice process under either of the following conditions:

  • You are returning a suspected defective device to the United States from a non-U.S. location following the process outlined in K13063: RMA Return readme instructions: United States.
  • You are returning a suspected defective device to the United States from a non-U.S. location following the process outlined in K13155: F5 product return instructions.

If you do not know which RMA Return readme instructions to use, refer to K12883: F5 RMA Return readme instructions, by country, or contact the RMA Coordinator Team by sending an email to rmacoordinator@f5.com or by calling F5 Support for your region.

Required Actions

To export the suspected defective device to the United States, print and complete the following commercial invoice form, following all of the instructions included in the document:
