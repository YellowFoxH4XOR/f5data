Description

  • getting error "400 Product Not Allowed" when requesting New Certificate via Certificate Order Manager

Environment

  • configuring a Certificate Order Manager
  • using Digicert CA
  • 'type_hint' is used under 'Order SSL' section

Cause

The error "400 Product Not Allowed" is received due to the endpoint being deprecated by DigiCert as it is now considered legacy products only. The only products that are currently supported under 'type_hint' are the following:

  • ssl_plus
  • ssl_multi_domain
  • ssl_wildcard
  • ssl_ev_plus
  • ssl_ev_multi_domain

Recommended Actions

  • There is no workaround presently available from the BIG-IP side for use with 'type_hint'
  • Identify what products you are subscribed for and if you are not subscribed to any of the above listed products, then Certificate Order Manager feature for DigiCert will not be suitable for use in your setup

Additional Information

You should contact DigiCert support for additional information as their current documentation does not specifically state which products have been deprecated.
