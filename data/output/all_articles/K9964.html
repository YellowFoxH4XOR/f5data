K9964: Users are not prompted to change an expired Active Directory password when a customized logon error page is uploaded using WebDAV

Known Issue

This is the result of a known issue. If you upload a customized logon error page (logon.failed.inc) to the FirePass controller using WebDAV, users cannot change an expired Active Directory password at the logon page. When this issue occurs, FirePass redirects users with expired Active Directory passwords to the logon.failed.inc page instead of prompting users to change their expired passwords.

Note: For information about using WebDAV customization, refer to K4440: Overview of WebDAV.
 
F5 Product Development tracked this issue as ID 296165 (formerly CR108742) and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally this issue has been fixed in cumulative hotfix HF-603-2.1 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
 
For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.
 
For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
