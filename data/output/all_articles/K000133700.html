K000133700: Inactivity Timeout not working as expected with modern JS patching PA resource

Type
Support Solution
Published
2023-04-28
Updated
2023-04-28
Applies to
  • BIG-IP
  • BIG-IP APM: 17.0.0, 17.1.0
Source
https://my.f5.com/manage/s/article/K000133700

Description

  • Issue was reported to occur with Portal Access resources configured for modern JS patching only.
  • Symptoms are following:
    • When users ARE actively working with the PA resource the session ends abruptly right when the Inactivity Timeout timer expires.
    • No "Do you want to stay connected?" popup is displayed
    • When users ARE NOT actively working with the PA resource, "Do you want to stay connected?" popup comes up and session can be extended as usual

Environment

  • Portal Access
  • Modern JS Patching configured
  • Web Acceleration profile used

Cause

Web Acceleration profile was reported to be the cause

 Recommended Actions

  1. Please clear the ramcache (K13255: Displaying and deleting HTTP cache entries from the command line (11.x and later)) 
    tmsh delete ltm profile ramcache all
  2. Disable Web Acceleration profile

Additional Information

If Web Acceleration profile is essential to your business needs, please create a specific configuration to help with large files if needed.
Please check K14903: Overview of the Web Acceleration profile and respective manual guides for further reference.
Please check out K15387: Overview of BIG-IP APM session cookies for further information regarding session cookies used in APM operation
