K22941103: Group membership with SAML and Azure AD

Type
Support Solution
Published
2022-08-22
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K22941103

Description

You are using SAML Authentication and you would like to obtain Group membership of the specific user in Azure Active Directory

Environment

  • SAML Authentication
  • Azure Active Directory
  • Group membership
  • MS Outlook 365

Cause

None

Recommended Actions

Under VPE in AD Query branch set "search Filter" to "(sAMAccountName=%{session.saml.last.identity})" or "(mail=%{session.saml.last.identity})" if you are using MS Outlook 365

Additional Information

None
