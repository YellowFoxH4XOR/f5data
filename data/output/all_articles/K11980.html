K11980: The BIG-IP system does not provision enough memory for the WebAccelerator module on the 8400 and 8800 platform

Known Issue

This is the result of a known issue. If you enable BIG-IP WebAccelerator on a 8400 or 8800 platform, the BIG-IP system does not provision enough memory for the module. As a result, BIG-IP WebAccelerator performance may degrade.

F5 Product Development is tracking this issue as ID 338564.

If you plan on using BIG-IP WebAccelerator with either the 8400 or the 8800 platform, contact F5 Technical Support for instructions about configuring and deploying a custom provisioning table to make sure the module receives adequate memory resources.
