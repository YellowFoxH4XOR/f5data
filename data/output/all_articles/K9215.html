Known Issue

This is the result of a known issue. When the get_region_item iControl command is used to retrieve the list of region members within a specified topology region, a list of all region members in all regions is returned.

F5 Product Development tracked this issue as CR69047 and it was fixed in BIG-IP 9.4.7 and 10.0.0. For information about upgrading, refer to the BIG-IP GTM Release Notes.

Workaround

You can work around this issue by using the Configuration utility to view the list of region members for a region. To do so, perform the following procedure:

  1. Log in to the BIG-IP GTM Configuration utility.
  2. Click Global Traffic.
  3. Click Topology.
  4. Click Regions.
  5. Click the region whose members you want to view.
  6. Examine the Member List in the Region Members section.
