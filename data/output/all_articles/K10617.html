Issue

The following error message may be reported on the Reports: System Logs page, or output to the syslog file of your remote syslog server (if configured):

GarbageCollection session '?????' is expired due to inactivity. User may have logged out improperly.

This error message indicates that a user did not log off properly, and FirePass has cleared the session. For example, if a user with an active FirePass session closes the browser before clicking the Logoff button, FirePass will retain the session in the connection table until the inactivity timeout is reached.

This message can be safely ignored.
