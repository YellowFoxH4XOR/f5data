Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator does not correctly compute the maximum transaction limit for each channel the pvac process opens.

As a result, the pvac process may drop SYNs from new connection requests when the system is busy. This issue occurs because the BIG-IP WebAccelerator does not correctly take into account queued transactions, and transactions currently processed when calculating the maximum transaction limit.

F5 Product Development tracked this issue as CR135783 and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator or Edge Gateway release notes.

This issue was fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
