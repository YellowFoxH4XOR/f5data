Source

Description

  • Partition  /var/asmdata1 running out of disk space
  • The following messages are logged on /var/log/ltm

    Jul 2 09:51:05 LTM1 err diskmonitor: 011d0004:3: Disk partition /var has only 11% free
    Jul 2 09:56:04 LTM1 err diskmonitor: 011d0004:3: Disk partition /var has only 10% free

  • The following critical error messages can be son on /var/log/asm

    Jul  7 16:00:53 Slb02 crit perl[13970]: 01310027:2: ASM subsystem error (clean_db.pl,): clean_db ended unexpectedly
    Jul  7 16:00:53 Slb02 crit perl[13970]: 01310027:2: ASM subsystem error (clean_db.pl,): Can't locate object method "log" via package "F5::Logger" at /usr/local/share/perl5/F5/DbClean.pm line 150.
    Jul  7 16:01:22 Slb02 crit perl[12067]: 01310027:2: ASM subsystem error (asm_start,F5::NwdUtils::Nwd::log_failure): Watchdog detected failure for process. Process name: clean_db.pl, Failure: Insufficient number of threads (required: 1, found: 0).

Environment

  • ASM provisioned
  • Device running software version from 12.0.0 to 12.1.3.7

Cause

Seen behaviour is caused by a known issue tracked with the Bug ID 748823.

Recommended Actions

Bug ID 748823 is fixed in software version 12.1.4 and above. Upgrade to a non affected version

Additional Information

None.
