Description

When experiencing BIG-IQ statistics data collection issues such as statistics data and/or graphs not shown in the BIG-IQ CM GUI. There are some things you can check and possibly resolve the issue or shorten the time to resolution if you need to contact F5 Support.

Environment

  • BIG-IQ CM / DCD
  • BIG-IP
  • Statistics data collection issues    

Cause

Unknown

Recommended Actions

Stats data collection issue for a single/some managed BIG-IP device(s):

  • Check Network Connectivity between the problematic BIG-IP(s) and the BIG-IQ DCD. Refer to K15612: Connectivity requirements for the BIG-IQ system
  • Check qkview for affected BIG-IP and BIG-IQ DCD 
  • Restart statsd. Refer to K69422258: Memory leak at statsd daemon


Stats data collection issue issue happening for all managed BIG-IP devices:

On the BIG-IQ CM:

  • Check the Elasticsearch health. Refer to K25649710: How to confirm health of Elasticsearch of BIG-IQ
  • Check for low disk space. Refer to K15318711: Low BIG-IQ disk space due to elasticsearch , Bug ID 1055153: Elasticsearch cluster goes into read-only if disk space runs low , and K30153940: BIG-IQ no longer shows statistics, ASM Event Logs are empty
  • Check for Elasticsearch shards. Refer to K45545531: Overview of how Elasticsearch is used by BIG-IQ and K73214203: BIG-IQ not showing graphs due to max shards
  • Check/Modify the stats interval. Refer to K000132598: Stats received from BIG-IQ are in wrong interval
  • Restart restjavad and statsd daemons. Refer to K48615077: BIG-IP daemons (15.x - 17.x)
  • Check for errors in /var/log/restjavad


On all devices (BIG-IQ CM, DCD, and BIG-IPs):

  • Check memory utilization and tune memory if required. Refer to:
    • K63328426: Increase memory for Tomcat and Restjavad when Out of Memory
    • K47241910: Interpreting an OOM killer log (out of memory)


If the previous doesn't resolve the stats data collection issue and you are going to contact F5 Support, have the following information available:

  • qkview for the BIG-IQ CM, DCD, and BIG-IP(s). Refer to K33704022: How to collect supporting data for a BIG-IQ support case
  • Provide information and/or full screen shots that include:
    • Date, time, URL/hostname
    • Specific menu of operation
    • Log messages
    • etc...
