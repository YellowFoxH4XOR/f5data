Known Issue

Amazon Elastic Compute Cloud (EC2) failover tools may not work in some Amazon Web Services (AWS) regions.

This issue occurs when all of the following conditions are met:

  • You have an AWS BIG-IP deployment.
  • You use high-availability features by means of the AWS failover script.

Impact

You may not be able to deploy BIG-IP high availability configurations on AWS.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You are not able to use the AWS /usr/libexec/aws/aws-failover-tgactive.sh failover script.

Workaround

To work around this issue, you can update the AWS command line interface (CLI) tools package. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Download the latest CLI tools. They are available directly from AWS as a .zip file.

    You can also download the latest CLI tools using the cURL utility by logging in to the BIG-IP host as the root user and typing the following command:

    curl -O http://s3.amazonaws.com/ec2-downloads/ec2-api-tools.zip

  2. Extract the files into a suitable location under the /opt/aws/ directory by using the following command syntax:

    mkdir -p <directory>
    unzip ec2-api-tools.zip -d <directory>

    For example:

    mkdir -p /opt/aws/ec2-api-tools-new isomg
    unzip ec2-api-tools.zip -d /opt/aws/ec2-api-tools-new isomg

  3. Make a note of the directory name by typing the following command:

    ls -1 /opt/aws

    The output will appear similar to the following example:

    ec2-api-tools-1.7.5.1

  4. Remount the /usr file system in read-write mode by typing the following command:

    mount -o remount,rw /usr

  5. Edit the /usr/libexec/aws/aws-failover-tgactive.sh script file using a screen editor.

    Find the line that begins with export EC2_HOME= and change it to the path of the directory you created.

    For example:

    export EC2_HOME=/opt/aws/ec2-api-tools-1.7.5.1

  6. Remount the /usr file system in read-only mode by typing the following command:

    mount -o remount,ro /usr
