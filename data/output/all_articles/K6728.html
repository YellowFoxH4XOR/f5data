Known Issue

This is the result of a known issue. You must follow certain rules when discovering and managing external authentication protocol devices in your network, such as RADIUS, LDAP, or Active Directory.

If you use an external user name for device discovery, the user must exist on the managed device. Once you discover the device, you can manage it by logging in to the Enterprise Manager with administrative privileges. In order to avoid authentication errors, you must ensure that the user name exists in the external authentication user list on the managed device prior to logging in to the Enterprise Manager.

F5 Networks Product Development tracked this issue as CR69362 and CR69362, it was fixed in versions 9.1.3 and 9.2.4. For information about upgrading, refer to the BIG-IP LTM or GTM Release Notes.
