Description

When establishing a tunnel between two F5 Distributed Cloud Customer Edge (CE) sites, the tunnel fails to come up.

 

Environment

Product: F5 Distributed Cloud Multi-cloud Networking

Multiple CE sites (e.g., on-premises and AWS)

Site Mesh Group configured for inter-site connectivity

 

Cause

The virtual site used in the Site Mesh Group was not assigned to the relevant CEs, preventing tunnel formation.

 

Recommended Actions

Assign Virtual Site to CEs: Ensure that the virtual site referenced by your Site Mesh Group is explicitly assigned to all participating CEs. This step is necessary for full mesh connectivity.

 

Additional Information

  • If you are troubleshooting tunnel establishment between CEs, ensure you follow the steps in the Site Mesh Group guide to properly configure the mesh and assign the correct virtual site.
  • Use the Virtual Site creation guide to verify that your CEs are correctly associated with the intended virtual site, as this is a common cause of tunnel issues (as seen in this case).
