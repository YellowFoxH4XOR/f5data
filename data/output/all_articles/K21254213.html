Known Issue

The system does not raise the Message Routing Framework (MRF) Session Initiation Protocol (SIP) iRules events if the event from the previous message is still running.

This issue occurs when the following condition is met:

  • The SIP event from the previous message performs an asynchronous operation (such as using the commands after a table).

Impact

The iRules scripts for SIP messages may not run on all messages that the system receives or sends.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The SIP_REQUEST, SIP_RESPONSE, SIP_REQUEST_SEND, or SIP_RESPONSE_SEND iRules event may not be raised for a message if the previous message on that connection has an iRules script still running.
