Issue

Error Message

err websso.0[<PID>]: 014d0048:3: /Common/<access_policy>:Common:<session_ID>: failure occurred when processing the work item

In this error message, note the following:

  • <PID> is the websso process ID.
  • <access_policy> is the name of the affected access policy.
  • <session_ID> is the affected access session ID.

For example:

err websso.0[22361]: 014d0048:3: /Common/remote_access:Common:208fc362: failure occurred when processing the work item

Message Location

You may encounter this message in the following locations:

  • The /var/log/apm file

Description

This error indicates a client had to disconnect before WebSSO completed the job.

This message may be encountered during any of the following situations:

  • The client session encountered a Kerberos error.
  • The client session is closed as a result of connectivity issues. For example:
    • Processing the related work item exceeded the timeout the job is allowed to be queued.
    • An external event occurred that caused connection to close.

Impact

User session may be terminated and required the user to reconnect.

Recommended Actions

  • Investigate any Kerberos errors encountered.
  • Investigate connectivity issues between BIG-IP APM and domain controller server that may be causing the connections to close or fail to connect.
    • If the domain controller server is not in the route domain 0, it is reachable but cannot work. For the more information, refer to K17148: BIG-IP APM support for Kerberos SSO and route domains 
  • If high CPU is noticed during the same time frame as the log message, investigate other possible reasons for the high CPU utilization because the reason for the job timeout is probably a result of high CPU utilization, not necessarily the cause of the high CPU utilization.
