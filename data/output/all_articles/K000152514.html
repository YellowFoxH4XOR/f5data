K000152514: Partition Deletion and FIPS Zeroization Triggered by FIPS License Addition or Removal on F5 VELOS Chassis

Type
Support Solution
Published
2025-07-10
Updated
2025-07-16
Applies to
  • F5OS
  • F5OS-C: 1.8.1
Source
https://my.f5.com/manage/s/article/K000152514

Description

Adding or removing the FIPS license will cause all chassis partitions to be deleted and configuration data to be lost.

Environment

  • VELOS (F5OS-C) version 1.8.1 or later
  • FIPS License Addition or Removal

Cause

Functioning as designed - (FAD)

Recommended Actions

Make sure you have the unit's primary key passphrase and salt securely recorded, as they will be required if a backup restore becomes necessary.

Additional Information

While this behavior is functioning as designed, the impact of adding or removing a FIPS license is not clearly apparent to the end user.

Defect IDs ( 1977845 & 1977873 ) have been filed to improve alerting both in the UI and CLI regarding FIPS zeroization and the deletion of all partitions when adding or removing a FIPS license on systems running software release 1.8.1 or later.
