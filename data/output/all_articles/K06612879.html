Description

Automatic Protocol Security Inspection Updates is not working.

The following error is seen:

Error: Exception caught in script. Check logs (/var/log/pi_hitless_upgrade) for details
 

Environment

  • Automatic update
  • vCMP guests


Cause

It appears to be due to Bug ID 778225: vCMP guests don't have the f5_api_com key and certificate installed when licensed by vCMP host

Note: In bug ID778225, it lists "Known Affected Versions" however, not which version the bug is fixed. This is because there is an ongoing investigation.


Recommended Actions

Install the hitless upgrade IM package manually.
 

Additional Information

None.
