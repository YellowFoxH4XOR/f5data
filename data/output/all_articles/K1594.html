Note: To configure date and time on BIG-IP version 9.x - 11.x, refer to K3381: Setting the time and date on BIG-IP.

To configure NTP synchronization from the command line, perform the following steps:

Note: The bsd kernel requires that you make this change in single-user mode, because ntpdate cannot reset the clock by more than 1,000 seconds, or faster than .5ms/s (half a millisecond per second). If your clock is off by more than 1,000 seconds, or .5ms/s, you will need to reset it in single-user mode. For more information, refer to K597: Setting the time and date on BIG-IP and 3-DNS.

  1. At the command line, type:

    config

  2. From the menu, select the M option.
  3. Answer the questions, as prompted.

    When you have answered all of the questions, BIG-IP saves the configuration to the /etc/ntp.conf file.

  4. Save the file.
  5. Exit the First Time Boot/Setup utility.
  6. Verify that the NTP daemon, ntpd, is running, by typing the following command:

    bigstart status ntpd

  7. Check the offset of the systems' clock against the NTP server to which you are synchronizing, by typing the following command:

    ntpdc

    This will put you into a command mode.

  8. View the clock offset, by typing the following command from the command mode:

    peers

    The output should appear similar to the following:

    my_bigip:~# bigstart status ntpd
bigstart: status ntpd
status ntpd: (pid 24707) is running
my_bigip:~# ntpdc
ntpdc> peers
     remote        local      st  poll  reach   delay     offset     disp
>=======================================================================
*192.168.20.30  10.10.10.21   2   64    17     0.00046    -7.031385  0.94548
ntpdc> quit
my_bigip:~#

    In this example, the offset is -7.031385. To correct this issue, you must set the local clock back by -7.031385 seconds.

Configuring the 3-DNS time_tolerance setting

The time_tolerance setting controls the maximum time difference allowed between 3-DNS units in a synchronization group. When any two units have a time difference greater than the time_tolerance setting, the unit with the earliest time will be updated to the time of the unit that is set to the latest time.

To configure the time_tolerance setting, perform the following steps:

  1. Log in to the Configuration utility.
  2. Click System.
  3. From the System page menu, click Timers and Task Intervals.
  4. In the Intervals section, enter a value for the 3-DNS Sync Time Tolerance.

    The default value for the time_tolerance setting is 10 seconds. The minimum value is 5 seconds and the maximum value is 600 seconds. A value of 0 disables this feature.

  5. Click the Update button.
