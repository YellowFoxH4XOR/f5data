Description

Add/Update FQDN-based pool member to AD or LDAP AAA Object using BIG-IP APM

  • You want to configure the AD or LDAP AAA object to use FQDN instead of IP Address to identify its pool members.

Environment

  • BIP-IP APM Provisioned
  • Using AD or LDAP AAA Objects
  • Want to configure FQDN based pool members

Cause

Currently the AD and LDAP AAA UI screens do not allow you to configure FQDN nodes.

Recommended Actions

To ADD FQDN-based pool members you need to perform the following steps.

  1. Create AD or LDAP AAA Object and add any IP Address into the pool section. (Access > Authentication > LDAP)
  2. Navigate to Local Traffic > Pools and select the pool you just created.
  3. Click on the Members tab
  4. Remove the previously created IP Address based member and Add the FQDN members.
  5. Navigate back to your AAA Object and you will see the IP Address listed for the FQDN Node.
To MODIFY the AAA pool you will need to follow these steps:
  1. Navigate to the AAA object
  2. Remove all nodes from the list.
  3. Add any IP address back into the node list
  4. Modify the AAA Object (ex. change Admin password)
  5. Follow steps 2-5 above.
