Description

Unable to see existing virtual server on the available list on ASM guided configuration

Environment

  • AWAF license
  • ASM guided configuration
  • Virtual server with ASM policy, BaDos Profile or Bot Profile assigned

Cause

Seen behavior is expected if the following conditions apply:

  • The virtual server doesn't have an HTTP profile assigned
  • The virtual server has assigned an ASM policy, a BaDos Profile or Bot Profile

Recommended Actions

None
