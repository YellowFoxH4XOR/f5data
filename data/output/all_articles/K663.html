Issue

When configuring a redundant pair of 3-DNS systems, the following is required:

  • Both 3-DNS systems must be running the same version of 3-DNS software (you cannot mix software versions in a redundant pair).
  • You must add the IP addresses of both external interfaces to the configuration of the 3-DNS.
  • You must make any configuration changes to the active 3-DNS system in order to synchronize with the standby system.

To troubleshoot synchronization on a redundant 3-DNS pair, perform the following steps on the active 3-DNS system:

  1. From the Navigation Pane of the Configuration utility, select 3-DNS.
  2. Select the IP address of the 3-DNS system from which you are configuring synchronization (that is, the IP address of the active 3-DNS).
  3. Verify that the IP address is the shared external IP address of the redundant 3-DNS pair.
  4. Verify the configuration of the individual IP addresses. (These are the external IP addresses of each system.)
  5. If you make any changes, click Update.
  6. Verify that both 3-DNS systems are listed in the same sync group.
