Description

You want to configure color for advisory banner on F5OS

Environment

  • F5OS

Cause

This can be required in order to distinguish different types of environment, for example production and lab environment.

Answer/Recommended Actions

You can set banner color for F5OS with GUI according to below steps:
1. Log in to the F5OS webUI as an administrator.
2. Go to SYSTEM SETTINGS > General.
3. Set Advisory Banner to Enabled.
4. Select a color and enter the environment name in Advisory Banner Text.
5. Click Save.

Alternatively, you can use below commands in CLI:
config
system settings gui advisory config enabled color orange text
commit
