K9863: User licenses are based on the number of active sessions rather than number of users

Topic

Planning for the correct number of licenses is an important part of any deployment. The FirePass system requires licenses based on the number of sessions that are connected rather than the number of users making a connection. For example, when a Windows Mobile device connects to a server by way of the Firepass system using ActiveSync, the FirePass system creates a session for the user. Therefore, the FirePass uses a license for the user for the duration of time the session remains active. If the same user logs in through the webtop, the FirePass system creates another session.  You need two licenses for the same user if ActiveSync is concurrently running in the background.

F5 Product Development is tracking a request for enhancement (RFE) as ID 265572 (formerly CR117572), ActiveSync requires additional license to run concurrently to webtop.

For more information about the number of licenses you will need, contact your F5 sales representative.
