Known Issue

The BIG-IP APM configuration may fail to load after a software upgrade.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is running version 11.4.0 or 11.4.1.
  • Virtual servers are configured with the rewriteplugin rewrite profile configuration object.
  • You upgrade the BIG-IP APM software to a version listed in the Applies to (see versions) box, located in the upper-right corner of this article.

Impact

After a software update, the BIG-IP APM configuration fails to load.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After upgrading BIG-IP APM software, the configuration fails to load and the system displays an error message similar to the following example:

    01070734:3: Configuration error: cannot attach profile (/Common/rewriteplugin) to virtual server (/<partition>/<virtual server name>) Unexpected Error: Loading configuration process failed.

Workaround

To work around this issue, you can modify the /config/bigip.conf configuration file to remove the offending objects. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected BIG-IP APM system.
  2. Using a text editor, open the /config/bigip.conf file.
  3. Locate the virtual server name that the system displayed in the error message.
  4. Remove the following line:

    /Common/rewriteplugin { }

  5. Save the changes to the /config/bigip.conf file.
  6. To load the system configuration, type the following command:

    tmsh load /sys config
