Known Issue

TCP flows that go through a Bandwidth Control (BWC) policy-enabled virtual server may experience lower throughput than expected.

This issue occurs when all of the following conditions are met:

  • You have applied a BWC policy to an IP Forwarding or L2 Forwarding virtual server.
  • A TCP traffic flow is processed by the affected virtual server.

Impact

TCP flows that go through an affected virtual server experience lower than expected throughput.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • TCP flows that go through an affected virtual server experience lower than expected throughput.

Workaround

To work around this issue, you can use a virtual server that proxies the TCP flow, such as a Standard virtual server, instead of a Forwarding virtual server.

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.
