Description

You will see these messages every 20 minutes on /var/log/maillog by default. This is due to some errors on the script that is executed by cron job.
The error messages should be similar to the followings.


Mar  5 03:40:02 hostname.local err sSMTP[9797]: Unable to connect to "localhost" port 25.
Mar  5 03:40:02 hostname.local err sSMTP[9797]: Cannot open localhost:25
Mar  5 04:00:02 hostname.local err sSMTP[22051]: Unable to connect to "localhost" port 25.
Mar  5 04:00:02 hostname.local err sSMTP[22051]: Cannot open localhost:25

Environment

  • v15.1.1 and later

Cause

This could be caused by either of the below bugs:

Bug ID 959629: Logintegrity script for restjavad/restnoded fails / K01630449: Overload of emails after upgrade to v15 with Subject: nice -n 19 ionice -c 3 /usr/bin/rest_logintegrity

Bug ID 1103953: SSMTP errors in logs every 20 minutes

Recommended Actions

Please follow the mitigations explained in K01630449 or Bug ID 1103953.
