Description

This article will show you how to enable Clickjacking protection on your ASM/Advanced WAF Security Policy

Environment
  • Have ASM or Advanced WAF enabled on your BIG-IP
  • Have an existing Security Policy
     
Cause

You can use this to help mitigate the Qualys security scan threat QID 11827 using ASM/Advanced WAF

Recommended Actions
  1. Navigate to the URL you would like to enable Clickjacking protection on in your security policy. This can be done by going to the following: 

    Security  ››  Application Security : URLs : Allowed URLs : Allowed HTTP URLs
     
  2. Then select the URL you would like to add this protection to. Note you can either select a Wildcard URL, and Existing URL or Create a new URL.
     
  3. After that change the view from Basic to Advanced via the drop down at the top
     
  4. Now you will see the option for Clickjacking Protection. Click the box to the right of that to enable the protection. 

    This specifies, when enabled, that the system adds the X-Frame-Options header to the domain cookie’s response header. This is done to protect the web application against clickjacking. Clickjacking occurs when attacker lures a user to click illegitimate frames and iframes because the attacker hid them on legitimate visible website buttons. Therefore, enabling this option protects the web application from other web sites hiding malicious code behind them. The default is disabled. After you enable this option, you can select whether, and under what conditions, the browser should allow this URL to be rendered in a frame or iframe.
     
  5. Next you will see the option appear for Allow Rendering in Frames. The conditions that determine whether the browser should allow this URL to be rendered in a frame or iframe.

    Never: This URL must never be rendered in a frame or iframe. The web application instructs browsers to hide, or disable, frame and iframe parts of this URL.

    Same Origin Only: The browser may load the frame or iframe if the referring page is from the same protocol, port, and domain as this URL. This instructs the browser to allow the user to navigate only within the same web application.

    Only From URL: The browser may load the frame or iframe from a specified domain. Enter the protocol and domain in URL format - for example, http://www.mywebsite.com. Do not enter a sub-URL, such as http://www.mywebsite.com/index.html.
