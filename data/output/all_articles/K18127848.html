K18127848: Dashboard of DOS Protection Profile displays 'Server stress is 100/100'

Applies to

  • F5 DDoS Hybrid Defender: 15.X.X, 15.0.X, 14.1.X, 15.1.1, 15.1.0, 15.1.X, 14.1.2, 14.1.0, 15.0.0
Source

Description

On the GUI dashboard, DOS Protection Profile displays:

'Server stress is 100/100'.

Environment

  • No signs of distress on the backend server
  • Server latency: 10 ms
  • Virtual Server Health: Moderate

Cause

This occurs due to the bados sensitivity which has been described in Bug ID 922597: BADOS default sensitivity of 50 creates false positive attack on some sites

The default value is 50. This value indicates higher sensitivity and attacks are being detected even with the littlest spike in traffic and hence displays 100/100 Server Stress.

Recommended Actions

Setting a higher value will lower the sensitivity attack will be triggered later or not will be triggered if it’s just traffic spike.

Modify the default sensitivity value from 50 to 500:

tmsh modify sys db adm.health.sensitivity value 500


Additional Information

Description of the DoS Transaction Outcomes:

  • Passthrough : Traffic that is allowed because it does not constitute a DoS attack.
  • Incomplete : Traffic that was dropped by the server because the connection was incomplete or the server did not respond. The system did not perform any DoS mitigation on this traffic. Transactions were reset, and responses were not sent to the client.
For the rest of the DoS Transaction Outcomes in the installed software version, refer to Manual Chapter : Viewing DoS Reports Statistics and Logs
