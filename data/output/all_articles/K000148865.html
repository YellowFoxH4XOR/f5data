K000148865: NGINX Plus R33 Upgrade - JWT License Location

Type
Support Solution
Published
2024-12-05
Updated
2025-01-14
Source
https://my.f5.com/manage/s/article/K000148865

Description

To upgrade to NGINX Plus R33, it is necessary to validate the JWT license. The JWT license file must be located in the same directory as the NGINX master process configuration file, which by default is /etc/nginx/nginx.conf. Specifically, the JWT token should be placed at /etc/nginx/license.jwt.

If the NGINX master process is configured to run from a different directory other than the default (/etc/nginx/nginx.conf), the license.jwt file should be placed in the same directory as the custom NGINX master process configuration file.

Environment

  • NGINX Plus R33
  • JWT License

Cause

None

Recommended Actions

Ensure the JWT license file (license.jwt) is located in the same directory as the running NGINX master process configuration file, without requiring any explicit "mgmt" configuration.

For example:

  • NGINX Master Process running on /etc/nginx-X/nginx.conf
  • JWT license should be apply to /etc/nginx-X/license.jwt
