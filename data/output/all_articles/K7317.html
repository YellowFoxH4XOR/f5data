Topic

This article applies to BIG-IP 9.x. For information about other versions, refer to the following articles:

  • K17333: Overview of port lockdown behavior (12.x - 15.x)
  • K13250: Overview of port lockdown behavior (10.x - 11.x)

The port lockdown feature allows you to secure the BIG-IP system from unwanted connection attempts by selecting one of the following four options for each Self IP address on the system:

  • Allow Default
  • Allow All
  • Allow None
  • Allow Custom

Each port lockdown list setting specifies the protocols and services from which a self IP can accept connections. The system refuses traffic and connections made to a service or protocol port that is not on the list with the following exceptions:

  • TCP port 1028: In a redundant pair configuration the system allows tcp:1028 for connection and persistence mirroring, regardless of the port lockdown settings.
  • ICMP: ICMP traffic to the self-IP address is not affected by the port lockdown list, and is implicitly allowed in all cases; however, in most cases, it is not possible to ping self IP addresses across VLANs.

    Note: For more information, refer to K3475: The BIG-IP system may not respond to requests for a self IP address.

The port lockdown settings are defined below:

Allow Default

The Allow Default option allows access for a pre-defined set of TCP, UDP, and network services that are typically required in a BIG-IP deployment.

F5 recommends using the Allow Default option on the self IP addresses that are used for synchronization and other critical redundant pair intercommunications.

Important: For optimal security, F5 highly recommends that only Self IP addresses that are on protected networks be used for synchronization and status communication between the devices in a redundant pair configuration. When possible, F5 recommends the use of a dedicated VLAN on the BIG-IP systems: The VLAN on each system should be populated with a single dedicated switch interface, and those interfaces should be directly linked by a crossover Ethernet cable.

Allow All

The Allow All setting specifies that allconnections to the self IP address are allowed, regardless of protocol or service.

Allow None

The Allow None setting specifies that no connections are allowed on the Self IP address, regardless of protocol or service; however, ICMP traffic is always allowed, and if the BIG-IP systems are configured in a redundant pair, connections to the state mirroring port, tcp:1028, are always allowed from the peer system.

Allow Custom

The Allow Custom setting allows you to specify the protocols and services for which connections are allowed on the self IP address; however, ICMP traffic is always allowed, and if the BIG-IP systems are configured in a redundant pair, connections to the state mirroring port, tcp:1028, are always allowed from the peer system.

Important: A known issue prevents connections to the state mirroring address when port tcp:1028 is explicitly allowed in the custom port lockdown list. For more information, refer to K12932: The BIG-IP system resets statemirror connections when port 1028 is configured in the Self IP Port Lockdown list.

Updating Port Lockdown settings for a specific self IP

  1. Log in to the Configuration utility.
  2. Click Network.
  3. Click Self IPs.
  4. Click the relevant Self IP address.
  5. For Port Lockdown, click the setting you want to use.
  6. Click Update.

Note: For more information about the BIG-IP mirroring and network failover transport protocols, refer to K9057: Service port and protocol used for BIG-IP network failover and K7225: Transport protocol used for BIG-IP connection and persistence mirroring.
