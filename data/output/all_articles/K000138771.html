K000138771: APM Portal Access stops working after upgrading Chrome to version 122+

Type
Support Solution
Published
2024-02-29
Updated
2024-12-04
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1, 16.1.4, 15.1.10, 15.1.9, 17.1.0
Source
https://my.f5.com/manage/s/article/K000138771

Description

Web application through APM Portal Access stops working after upgrading Chrome or Edge Browsers to version 122+.
Rather than displaying the application, a blank/white page is displayed.

In the Chrome console, the following error can be found:
cache-fm-Modern.js:516 Uncaught TypeError: Cannot assign to read only property 'constructor' of object '[object Object]'

Environment

  • Chrome v122.x
  • APM Portal Access

Cause

ID1552685

Recommended Actions

The issue is fixed in 16.x starting 16.1.5 and in 17.x starting 17.1.2.

For older versions, a workaround is available utilizing an iFile of javascript and an iRule applied to the Virtual Server used to access the Web Application via Portal Access.

Please follow K000148786 if you need such workaround.

    Please also note that the mentioned workaround requires support for Modern JavaScript. 

    To enable support for Modern JavaScript on Rewrite Control List (RCL), please check the K000130439.
