Description

ASM attack signatures to protect back-end applications from Apache Log4j SQL injection vulnerability CVE-2022-23305

Environment

BIG-IP ASM/Advanced WAF

Cause

NA

Recommended Actions

There are no ASM attack signatures designed to protect against CVE-2022-23305, but F5 Engineering Services (ES) recommends leveraging a combination of General Database signatures and also database signatures that explicitly provide coverage against the databases being used by this application

Additional Information

GUI: Security ›› Application Security : Attack Signatures
Advanced Filter: Systems > \"General Database\" + any other database servers that are being utilized by the application.
For example if the app uses Oracle DB or MySQL, then you can add them to be part of your signature set in addition to having 'General Database' (which provides protection in a generic manner regardless of what database is utilized by the app).
---
*If you use/want a user-defined signature set, you can create it with type 'Filter-based', under Available Systems, you should select 'General Database' and any other database servers that are being utilized by the application.
GUI: Security > Options > Application Security > Attack Signatures > Attack Signatures Sets

NOTE: To ensure that you protect your applications against new attacks, F5 recommends you regularly update attack signatures.
