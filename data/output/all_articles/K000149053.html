K000149053: Users may fail to establish VPN tunnels if the sys db variable ipv6.enable is set to a non-default value of "false"

Type
Support Solution
Published
2024-12-19
Updated
2024-12-19
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000149053

Description

Users may fail to establish VPN tunnels if the sys db variable ipv6.enable is set to a non-default value of "false". Users will observe:

"Failed to download configuration" 

message during this problem. Example Windows client-side logs during this problem (logged under %temp%\logterminal.txt):

2024-12-19, 7:08:46:870, 2900,3948,HOST, 1, , 2002, CHostCtrl::OnTimer(), TUNNEL_SERVER_READY_CHECK - configuration read timed out
2024-12-19, 7:08:46:870, 2900,3948,HOST, 1, \HostCtrl.h, 1485, CHostCtrl::Failed, Failed to download configuration (error: 0)

Environment

APM version 17.1.2 or any other APM version with the fix of ID903501.

sys db ipv6.enabled is set to a non-default value of "false".

Any client trying to establish a VPN tunnel.

Cause

This is due to ID1773161.

Recommended Actions

Set sys db variable ipv6.enabled to be "true":

tmsh modify sys db ipv6.enabled value true

Additional Information

Please note that such errors can be logged due to other causes. Refer to the Related Content section links for more details.
