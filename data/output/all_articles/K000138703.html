K000138703: [F5OS-A] An attempt to upgrade to v1.7 failed with 'System database upgrade compatibility check failed.''

Type
Support Solution
Published
2024-02-29
Updated
2024-02-29
Applies to
  • F5OS
  • F5OS-A: 1.7.X, 1.5.X, 1.7.0, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000138703

Description

Upgrading 1.5.x -1.6.x to 1.7.x is rejected by system with "System database upgrade compatibility check failed."

/var/log/messages has similar to below entry

journal: CDB: Upgrade failed: Upgrade transaction failed to validate: /f5-tenants:tenants/tenant{kbonecloud-gslb}/config/image is not configured
journal: confd_load: 337: maapi_start_trans() failed: operation in wrong state (17): Can't start read-write transaction before phase1
journal: "CDB: Upgrade failed: Upgrade transaction failed to validate: /f5-tenants:tenants/tenant{kbonecloud-gslb}/config/image is not configured\n"#015
journal: =ERROR REPORT==== DD-MMM-YYY::HH:MM:SS.xxxxxx ===
journal: init:boot_msg: "CDB: Upgrade failed: Upgrade transaction failed to validate: /f5-tenants:tenants/tenant{kbonecloud-gslb}/config/image is not configured\n"

 

Some of the tenants image is set with image file with bracket.

show tenants

tenants tenant <tenant_name>
state unit-key-hash <unit-key-hash>
state type BIG-IP
state image BIGIP-15.1.10-0.0.3.ALL-F5OS.qcow2.zip(1).bundle <<<-------[!]

 

Environment

  • F5OS-A
  • rSeries
  • Upgraded to 1.7.0

 

Cause

  • Bug ID 1552945


Recommended Actions

1. take tenant's ucs file and the master key 

NOTE: about master key please refer to: K9420: Installing UCS files containing encrypted passwords or passphrases (11.5.x and later)

2. delete tenants from the F5OS

3. rename tenant image file by running the below commands in F5OS-A CLI (log in as root)

cd /var/F5/system/IMAGE/

mv BIGIP-15.1.10-0.0.3.ALL-F5OS.qcow2.zip(1).bundle BIGIP-15.1.10-0.0.3.ALL-F5OS.qcow2.zip.bundle

4. recreate tenants and upgrade to the version your current version.

5. restore the ucs with Master key

NOTE: Follow K9420: Installing UCS files containing encrypted passwords or passphrases (11.5.x and later)

6. upgrade F5OS to 1.7.0
