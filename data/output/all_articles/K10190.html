Known Issue

This is the result of a known issue. The BIG-IP system does not honor changing the MTU value for VLANs. For example, if you change the default MTU value for a VLAN from 1500 to 1200, the system does not honor the change; the BIG-IP system will continue to use 1500 for the VLAN MTU.

F5 Product Development tracked this issue as CR115736 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WOM release notes.

Workaround

To work around this issue you must first delete the VLAN for which you want to change the MTU, and then recreate it with the desired MTU value.
