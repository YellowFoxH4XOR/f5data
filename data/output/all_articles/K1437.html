K1437: Reasons why virtual servers may not be displayed within wide IPs

Topic

This issue can occur under the following circumstances:

  • The port list for the BIG-IP virtual server is not properly defined on the 3-DNS Controller.
  • The wide IP was created on a different port than the one on which the virtual server exists.

You can correct these issues as follows.

Defining a port list for a wide IP

A virtual server will not display on the wide IP if the virtual server is not created for each port in the wide IP's port list.

If you have defined the virtual server on port 80 only, but you have specified a port list for the wide IP that contains ports other than port 80, that virtual server will not display in the Configuration utility of the 3-DNS Controller.

You can correct this issue by modifying the port list for the wide IP nd adding the port specified for the virtual server.

To modify a port list for a wide IP on the 3-DNS Controller, perform the following steps:

  1. From the 3-DNS Controller's Configuration utility, click Wide IPs.
  2. From the list, select a wide IP.
  3. From the top of the screen, click Port List.
  4. Type the port and click >> button to add it to the port list.
  5. Click the Update button to save.

Displaying all virtual servers

By default, the wide IP will display only virtual servers that are on the same ports as the wide IP; it does not display all virtual servers.

If you defined a wide IP on port 80, but the virtual server is on another port, that virtual server will not display in the Configuration utility of the 3-DNS Controller.

To configure the 3-DNS Controller to display all the virtual servers, create the wide IP on port 0, rather than defining a specific port.

For specific instructions about how to create a wide IP, refer to the 3-DNS Administrator Guide.
