Description
How to get F5 SSL Orchestrator (SSLo) config using localhost REST access.

Environment

  • SSLo Deployed

Cause
None

Recommended Actions

It is possible to get the SSLO config (in nested JSON format) using the following command locally on the box:
restcurl -u admin:admin -X GET http://localhost:8100/mgmt/shared/iapp/blocks > /config/sslo_configuration.txt

The output from this is in JSON nested within JSON format, which will appear similar to the following:
