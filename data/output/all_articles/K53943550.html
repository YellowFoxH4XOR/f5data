Description
Purpose of this article is to show how to configure  event logging retention on BIG-IQ  Centralized Management. ElasticSearch is storing data in indices on /var partition of DCD nodes.

Important: THE DEFAULT CONFIGURATION USES retention values which does not meet /var free space on DCD nodes. This could fill up /var partition on DCD node and break up stability of the cluster

Environment

  • BIG-IQ DCD Cluster
  • Enabled services on DCD nodes ( for example Access, Web Application Services)
  • Retention Configuration for event logs

Cause

None

Recommended Actions

  1. Review retention  set for indices ( services which you enabled on DCDs ) and change them to meet /var partition requirements :
    System > BIG-IQ DATA COLLECTION >  BIG-IQ DATA COLLECTION CLUSTER >  Configuration > Logging Data Collection  > Configure
    1. Access Policy (APM)     
    2. DoS Protection     
    3. Fraud Protection (FPS)         
    4. IPsec     
    5. Network Security (AFM)     
    6. Web Application Security (ASM)

      For example Web Application Security > Configure...
      asmindex
      Index Name     asmindex
      Rotation Type Size Based
      Max Index Size 100000 MB
      Retained index Count  5

      This means that we will store  ASM events  in 5 indexes  per 100GB  on /var which with standard partition image plan is not  possible

  2.  If required re-size /var partition by refering to:
    K30902515: Resizing the /var, /var/log, or /shared file system on a BIG-IQ Virtual Edition

Additional Information
The Indices settings specify the physical characteristics of how the data collection device manages your data. The DCD stores data coming in from BIG-IP devices in a data index. As data is received, it accumulates in the current index. When the accumulated data reaches the rotation threshold you set, four things happen.

  • A new current index is created.
  • BIG-IP data begins accumulating in the new index.
  • The former current index becomes one of the retained indices.
  • If the total number of indexes is now larger than the retained index count, the oldest one is dropped.


When you set up index rotation, you determine what triggers the rotation threshold.
