K9603: Microsoft Office documents may not open or save properly when accessed through a BIG-IP WebAccelerator using Internet Explorer 6

Important: For information about a behavior change introduced in Hotfix-BIG-IP-9.4.5-HF2 for BIG-IP WebAccelerator version 9.4.5 that may result in the behavior described in this solution, refer to K9671: The WebAccelerator may insert an HTTP Cache-Control: no-cache header into a response when an existing Cache-Control header is not present.

When using Internet Explorer 6 to access Microsoft Office documents through a BIG-IP WebAccelerator, if the BIG-IP WebAccelerator policy is configured to insert a no-cache HTTP directive, the user may be unable to open or save the document. In addition, the user will receive a dialog box with an error message that appears similar to the following example:

Internet Explorer was not able to open this Internet site. The requested site is either unavailable or cannot be found.  Please try again later.

This behavior is the result of the Internet Explorer 6 browser's handling of the no-cache HTTP directive. The browser honors the no-cache directive literally. The browser downloads the file, but does not keep a local copy in its cache. When the Microsoft Office application tries to access the local copy of the document, the document cannot be found.

Note: The pre-defined BIG-IP WebAccelerator policies are not affected by this behavior. For policy nodes matching the content types for Microsoft Office documents, caching is controlled using a small max-age value for the client cache settings of the policy rather than a no-cache directive.
