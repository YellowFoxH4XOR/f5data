Description

You want to specify a time period for exporting request events.

Environment

  • BIG-IP ASM/AWAF

Cause

None

 Recommended Actions

Filter by "requestDatetime" can be used to specify a time period.

For example:

Exporting events from 2023-06-19T01:31:50 to 2023-06-19T23:59:59.

# restcurl /tm/asm/events/requests\?\$filter=requestDatetime+ge+%272023-06-19T01:31:50Z%27+and+requestDatetime+le+%272023-06-19T23:59:59Z%27
