Description

When receiving the following error in the logs you may also see HTTP traffic is dropped with iRule execution error in packet capture.

01220001:3 TCL error: /Common/sslo_DV.app/sslo_DV-xp <HTTP_REQUEST> - bad port in node <addr> <port> cmdTCL error (line 1) (line 1)     invoked from within "virtual "${mypfx}-in-t-[IP::version]" [HTTP::proxy addr] [HTTP::proxy port]"
 

Environment

  • F5 SSL Orchestrator with explicit proxy configured
  • Client sending GET requests without AbsoluteURI

Cause

  • The GET requests are not RFC2616 compliant.
  • Per RFC2616 Section 5.1.2 proxy URIs require absoluteURI form.

Recommended Actions

The GET requests from the requesting server must include the absoluteURI form. 
For example:
GET http://example.com/" HTTP/1.1

Fixing this is outside the scope of SSLO.
