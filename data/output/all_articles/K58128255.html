K58128255: ASM security policy disallowed file type not prepopulated

Type
Support Solution
Published
2020-12-08
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.X.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K58128255

Description

New Security policy is deployed, but no disallowed filetypes show.

Environment

  • BIG-IP ASM
  • Security Policy deployed with "Fundamental" Security Policy Template

Cause

Design.  The "Fundamental" Security Policy Template expects the user to populate the disallowed filetypes appropriate to the application being protected.

This is different behavior from the "Rapid Deployment" Template which will pre-populate with the following pre-populated disallowed filetypes:

bak bat bck bin bkp cer cfg cgi cmd com conf config crt dat der dll eml exe hta htr

Recommended Actions

Either Add the appropriate disallowed filetypes to your deployed policy

or

Deploy a new policy based on the "Rapid Deployment" Template and adjust other setting as needed.
