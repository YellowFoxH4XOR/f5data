Description

When trying to boot the BIG-IP to an older software release from the Configuration Utility you encounter the error 'null does not exist'.

Environment

Relevant environmental factors specific to the topic

  • BIG-IP
  • Version Downgrade

Cause

The option 'Install configuration' is set to Yes. This causes the 'Source Volume' to be empty, resulting in the error.
No supported method exists to automatically roll back the BIG-IP configuration from a newer software version to an older version.

Recommended Actions

Select 'Install Configuration' to No when booting into an older software release.

  1. Log in to the Configuration utility as an administrative user.
  2. Navigate to System > Software Management > Boot Locations.
  3. Click the boot location you want to activate.
  4. From the Install Configuration list, click No.
  5. Click Activate.
  6. To confirm that you want to boot in another volume, click OK.

  

Additional Information

For more information on how to downgrade the BIG-IP system, refer to:K14568: Downgrading BIG-IP software (10.x - 16.x) ​​​​​​​
