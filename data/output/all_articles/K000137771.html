Description

Every day a new alert showing about /var partition getting full:

011d0005:4: Disk partition /var has less than 25% free

 

i.e.: alert at 05:51 /var less than 19% free. But when logged onto the device it is showing that there is 40% free.

Environment

  • BIG IP
  • vCMP Guest

Cause

Backup files runs every day and getting removed right after - From the history command it shows the backup (UCS) file sent to an other server and then removed the UCS file:

2023-10-29 05:48:10 scp -q /var/local/ucs/Backup.ucs root@10.10.10.10/var/tmp/22603.tmp

2023-10-29 05:48:26 rm -f /var/local/ucs/Backup.ucs

Recommended Actions

UCS file might become big and causing the DiskMonitor to raise a flag says the /var is with low free space.
This appearing only one time per day since after running scp command, to remote copy the file to a remote server, there is rm command to remove the file so the /var is back to what it had before.

In some cases you may free some space, so the alerts will not showing every day - Look the output provided for finding such files:

find /var -xdev -type f -exec du {} \; | sort -rn | head -20
