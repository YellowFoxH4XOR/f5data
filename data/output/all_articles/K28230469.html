Issue

Error Message

err tmm<n>[<PID>]: 01230140:3: RST sent from <src_ip>:<src_port> to <dst_ip>:<dst_port>, [<error_code>] <reason>

In this error message, note the following:

  • <n> is the number of the Traffic Management Microkernel (TMM) reporting the reset.
  • <PID> is the process ID.
  • <src_ip> is the source IP address.
  • <src_port> is the source port.
  • <dst_ip> is the destination IP address.
  • <dst_port> is the destination port.
  • <error_code> is an F5 internal code.
  • <reason> is the reason for the TCP reset (RST).

For example:

err tmm1[9509]: 01230140:3: RST sent from 10.10.10.100:8080 to 192.168.1.100:30021, [0x190896a:1837] TCP 3WHS rejected (bad ACK)

or

err tmm3[18941]: 01230140:3: RST sent from 10.10.10.100:56042 to 192.168.1.100:1514, [0x2b1c0d5:285] {peer} handshake timeout

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility

Description

This message occurs when all of the following conditions are met:

  • You have enabled the TM.RstCause.Log database variable.
  • Your BIG-IP system sends TCP RST packets.

When you enable the TM.RstCause.Log database variable, the BIG-IP system logs the reasons for sending TCP RST packets. When you enable the TM.RstCause.Pkt database variable, the BIG-IP system includes the RST cause information in the TCP RST packet payload.

Impact

Enabling the TM.RstCause.Log database variable may cause higher system resource consumption and possible system performance degradation in the event of a denial-of-service (DoS) attack. Enabling the TM.RstCause.Pkt database variable can also be a potential security risk by advertising information about your environment

Recommended Actions

Due to the potential impact of enabling the TM.RstCause.Log and TM.RstCause.Pkt database variables, F5 recommends that you enable these database variables for troubleshooting purposes only, and that you disable the database variables after you have completed any troubleshooting.

For more information about enabling and disabling the TM.RstCause.Log and TM.RstCause.Pkt database variables, and to view a list of common TCP RST log messages, refer to K13223: Configuring the BIG-IP system to log TCP RST packets.
