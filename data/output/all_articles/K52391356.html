Description
TMSH command via BASH throws error on config object 'not found'

  • For example: 

# tmsh show gtm wideip a /*/*
Display all 5249 items? (y/n) n
01020036:3: The requested WideIp (A /bin/a2p) was not found.

Note: The /bin/a2p is a system file. This can be verified by running: ls /*/* | grep a2p

Environment

  • BIG-IP DNS
  • BASH
  • TMSH

Cause
Running TMSH commands in BASH without properly surrounding the search expression, will cause BASH to search the entire file system.

Recommended Actions

When running TMSH in BASH surround your search expression:  

tmsh show gtm wideip a '/*/*'
