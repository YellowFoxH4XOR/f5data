Known Issue

This is the result of a known issue. When restoring the FirePass configuration from a backup file, entries in the Java Applet Tuning table are not restored if the table contained two or more entries when the backup file was created.

F5 Networks Product Development is tracking this issue as CR133952.

Workaround

You can work around this issue by manually re-adding the missing entries to the Java Applet Tuning table after restoring the configuration from a backup file.

Note: The Java Applet Tuning table is located on the Portal Access : Web Applications : Content Processing page under the Global Settings tab. By default, the table is hidden. To view it, click the Show Java tuning link.
