K30340529: Regarding SDC Splunk Support

Type
Support Solution
Published
2022-02-07
Updated
2024-10-01
Applies to
  • Traffix SDC: 5.2.X, 5.2.0, 5.1.X, 5.1.0
Source
https://my.f5.com/manage/s/article/K30340529

Description

Starting from SDC 5.1 CF30 and above, Splunk is replaced with ELK in EMS (Element Management System) deployments. EMS ELK comprises three components called Fluentd, Elasticsearch and Kibana. With the introduction of ELK, customer is strongly encouraged to upgrade to a release that includes ELK if TDR (Transactions Data Records) or Trace function is needed. Customers may continue to use Splunk functionalities that have been deployed prior to the release of SDC 5.1 CF30. F5 does not provide security updates or software fixes nor technical support related to Splunk components that are included in earlier releases.

Environment

  • EMS Splunk Support on SDC 5.1 CF29 or below

Cause

Not applicable

Recommended Actions

As both TDR and Trace features has been migrated to ELK, customer, who needs those features, is strongly encouraged to upgrade to SDC 5.1 CF30 or above such that F5 continues to provide the relevant technical support or software fixes.
