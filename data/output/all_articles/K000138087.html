K000138087: Give or receive access to a support case folder on Secure Files

Topic

F5 Support may require files to diagnose and fix technical support issues. F5 Support uses F5 Secure Files (securefiles.f5.com) to securely exchange files with you. This file transfer site complies with global data protection standards to safeguard the data you exchange.

You may want associates who are not on your MyF5 account to assist you with uploading or downloading files for a support case. You can send those associates an email invitation that gives them access to the folder for the support case on Secure Files.

These associates can access only the folders for support cases to which you invite them. You can also rescind access to case folders at any time.

Types of Secure Files users

Two categories of Secure Files users provide files about support cases to F5 Support:

  • Case owners—Users who are on the MyF5 account to which a support case belongs and have access to the case.
  • Invited users—Associates of support case owners who assist them with uploading or downloading files for a case. They are not on the MyF5 account to which the support case belongs, and they do not have access to the case.

Prerequisites

Prerequisites for support case owners

Support case owners who want to invite associates to access a case folder on Secure Files must have one or more of the following roles:

  • Case contact—Person whose name is listed under Contact Information on the support case page. To see the case page, go to MyF5 (my.f5.com) > Support > Case management > case ID.
  • Admin—Role in the account to which the case belongs*
  • Case Manager— Role in the account to which the case belongs*

    *Note: For more information about roles associated with MyF5 accounts, refer to K000136095: About MyF5 account user roles and permissions.

Prerequisites for invited users

Invited users who want to access a support case folder on Secure Files must have their own or a separate MyF5 account. If they do not already have an account, invited users can do one of the following:

  • Register for a MyF5 account before the support case owner sends them an email invitation to their case folder on Secure Files. For information about how to register for a MyF5 account, refer to K000089224: Register for a MyF5 account and K000135451: F5 requires multi-factor authentication (MFA) for account login.
  • When the invited user receives the invitation to access a support case folder on Secure Files, MyF5 will prompt the invited user to register for a new account as part of the invitation.

Case contacts

Give an associate access to a support case folder on Secure Files

You must meet prerequisites to send an email invitation to an associate to access a support case folder on Secure Files. For more information, refer to the Prerequisites for support case owners section in this article.

After you close a case, you are no longer able to invite a user to access the case folder.

  1. Go to MyF5 and sign in to your account.
  2. Go to Support > Case Management.
  3. Select the support case for which you want an associate to upload and download files.
  4. Under Invited Users to Case Folder, select Invite User.
  5. Enter first name, last name, and email, and then select Save.

    MyF5 sends the email to the recipient

View invited users who have access to a support case folder on Secure Files

You can view all the associates you invited to exchange files with F5 Support about a support case.

  1. Go to MyF5 and sign in to your account.
  2. Go to Support > Case Invitations to Secure Files.
  3. Select Invitations Sent.

Remove an invited user from a support case folder on Secure Files

You can remove associates you invited to exchange files with F5 Support about a support case.

After you close the case, you are no longer able to remove an invited user from a case folder.

  1. Go to MyF5 and sign in to your account.
  2. Go to Support > Case Management.
  3. Select the support case for which you want to remove an invited user.
  4. Under Invited Users to Case Folder, in the list, locate the row for the user you want to remove, and then in the Actions column, select Remove Access.

    MyF5 sends an email to the invited user notifying them that you removed their access to the folder. The user now displays under Removed Users.

Re-invite an associate you removed from a support case folder on Secure Files

After you remove an invited user's access to a support case folder on Secure Files, you can invite them again to access the folder.

After you close a case, you are no longer able to re-invite a user to access the case folder.

  1. Go to MyF5 and sign in to your account.
  2. Go to Support > Case Management.
  3. Select the support case for which you want to re-invite an associate you removed.
  4. Under Removed Users, in the list, locate the row for the user you want to re-invite, and then in the Actions column, select Invite.

    MyF5 sends an email invitation to the invited user to access the support case folder on Secure Files. The user now displays under Invited Users to Case Folder.

Invited users

Receive an email invitation and access a support case folder on Secure Files

You cannot use the account holder's MyF5 account to exchange files with F5 Support about the account holder's support case. You must have your own or a separate MyF5 account. For more information, refer to the Prerequisites for invited users section in this article.

After a case owner closes a case or rescinds your access, you can no longer access the case folder.

After you receive an email invitation from the account holder to access the folder for their support case on Secure Files, do one of the following:

You already have a MyF5 account

  1. In the email invitation you receive from F5, select the Sign In button.
  2. Sign in to your MyF5 account.

    The Case Invitations page on MyF5 displays.

  3. Select the Invitations Received tab, and then select the case for which you want to upload or download files.

    Secure Files opens and displays the case folder.

    Note: For information about how to use Secure Files, refer to Procedures in K000090853: Exchange files with F5 Support.

You need to register for a MyF5 account

  1. In the email invitation your receive from F5, select the Register for MyF5 button.
  2. Register for a MyF5 account and set up multi-factor authentication (MFA).

    After you register, the Case Invitations page on MyF5 displays.

    Notes:

    • If you need to navigate to the Case Invitations page, go to MyF5 > Support > Case Invitations to Secure Files.
    • For more information, refer to K000089224: Register for a MyF5 account and K000135451: F5 requires multi-factor authentication (MFA) for account login.
  3. Select the Invitations Received tab, and then select the case for which you want to upload or download files.

    Secure Files opens and displays the case folder.

    Note: For information about how to use Secure Files, refer to Procedures in K000090853: Exchange files with F5 Support.
