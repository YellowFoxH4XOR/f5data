Description

BIG-IP system experiences high CPU spikes every 1-5 minutes (depends on the stats collection interval). Stats collection is enabled, but we are not collecting any stats.

Logs similar to the following in /var/log/ltm:

err scriptd[10576]: 014f0013:3: Script (/Common/bigiq-analytics-send_stats) generated this Tcl error: (script did not successfully complete: (could not read "/shared/tmp/bigiq-analytics-stats_0": no such file or directory while executing "file size "$filename$currentfile"" ("foreach" body line 25) invoked from within "foreach virtual $virtual_list { set virtual_name "/[tmsh::get_name $virtual]" set partition_name [exec /usr/bin/tmsh -c "list ltm virtual $vir..." invoked from within "if {"$timeToPushState" == "1" }{ ###let's get data from TMSH set virtual_list "" catch {set virtual_list [tmsh::get_status ltm virtual recu..." line:1094))

Environment

  • BIG-IQ 7.0.0 used to manage the BIG-IP
  • Stats collection is enabled on the spiking BIG-IP
  • BIG-IP 12.x, 13.x, 14.x, 15.x

Cause

Bug ID 825301

Recommended Actions

Upgrade to BIG-IQ 7.1.0 or later.
