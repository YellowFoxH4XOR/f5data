Known Issue

The BIG-IP system may stop collecting performance data.

This issue occurs when the following condition is met:

  • The statsd process receives a SIGCHLD signal.

Impact

The BIG-IP system displays empty performance graphs in the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you navigate to Statistics > Performance in the Configuration utility, the performance data is missing.
  • The statsd process time does not increase from the top command output.

Workaround

To work around this issue, you can restart the statsd process. To do so, perform the following procedure:

Impact of workaround: Statistical data collection is not available while the statsd process restarts.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the statsd process, type the following command:

    restart /sys service statsd
