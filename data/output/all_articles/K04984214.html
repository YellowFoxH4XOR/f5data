Known Issue

Entering an infinite loop when reading an HTTP header buffer may cause the Traffic Management Microkernel (TMM) to restart and produce a core file.

This issue occurs when the following condition is met:

  • TMM reads an http_header_value_location() buffer that contains null or invalid data.

An unrelated error condition may cause an internal data inconsistency, where the http_header_value_location() buffer contains null or invalid data. If TMM attempts to read an http_header_value_location() buffer that contains null or invalid data, TMM can enter an infinite loop.

Impact

The BIG-IP system temporarily fails to process traffic as it recovers from TMM restarting, and devices configured as part of a high-availability pair may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system unexpectedly fails over to another system in the device group.
  • In the /shared/core directory, you observe a TMM core file.
