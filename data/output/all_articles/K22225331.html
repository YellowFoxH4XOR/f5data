Description
After upgrading your BIG-IP DNS (formerly GTM) systems, IPv6 pools are marked down. In /var/log/gtm there are messages similar to:

Feb 05 12:34:56 dns.example.com notice gtmd[12345]: 011ae108:5: Prober Selection: no preferred or fallback probers are available

Environment

  • BIG-IP DNS version 13.1 or later
  • DNS / GTM sync-group

Cause
There was a change in behavior in BIG-IP v13.1, where an IPv6 address is required when defining BIG-IP server objects to probe IPv6 generic hosts. In v12, BIG-IPs can probe IPv6 generic host with only an IPv4 address defined. After upgrading to v13, these BIG-IPs are unable to probe IPv6 generic host objects.

Recommended Actions
Add the necessary addresses to the gtm server object configuration

Additional Information
In this example, GTM1-A cannot be assigned to monitor IPv6 generic hosts.

gtm server /Common/GTM1-A {
    datacenter /Common/BIG-IP-Lab
    devices {
        /Common/GTM1-A {
            addresses {
                172.16.1.1 { }   <------- Only IPv4 IP configured
            }
        }
    }
    monitor /Common/bigip
    product bigip
}

Once an IPv6 address is configured the server can probe IPv6 generic hosts.

gtm server /Common/GTM1-A {
    datacenter /Common/BIG-IP-Lab
    devices {
        /Common/GTM1-A {
            addresses {
                172.16.1.1 { }
                2001::1 { }    <------------ new IPv6 server entry required
            }
        }
    }
    monitor /Common/bigip
    product bigip
}
