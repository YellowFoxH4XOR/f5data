K52003100: ASM HA pair goes to 'Changes Pending' after failover

Type
Support Solution
Published
2022-12-08
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K52003100

Description

When auto "Policy Building Learning Mode" security policy configured in a BIG-IP ASM sync-group,if there is failover event happen,the previously standby device(Current active device) will make a learning-progress-update-event, this will lead ASM sync-group goes to changes-pending status.

Environment

  • BIG-IP ASM
  • ASM sync-group
  • Auto policy building

Cause

This is functional as design.

Recommended Actions

None
