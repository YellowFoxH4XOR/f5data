K000163024: BIG-IP ASM/AWAF blocks JSON array requests with Illegal parameter violations

Description

BIG-IP AWAF blocks valid application/json POST requests containing JSON arrays. The requests generate an Illegal parameter violation because a string in the array is interpreted as a POST parameter name that is not defined in the security policy.

Example request body:

["abc","def","123",null,null]

Environment

  • BIG-IP AWAF
  • Requests with the Content-Type: application/json header
  • Request bodies containing JSON arrays rather than key-value JSON objects
  • An application security policy with JSON parameter parsing enabled for the affected URL

Cause

The JSON payload consists of arrays, but the JSON profile parses array values as request parameters. BIG-IP AWAF interprets the first string in each array element as a parameter name. Because the interpreted parameter name is not defined in the security policy parameter list, the request triggers an Illegal parameter violation and may be blocked.

Answer/Recommended Actions

Create a dedicated JSON profile for the affected application paths and disable parameter parsing for that profile.

  1. Navigate to Security > Application Security > Content Profiles > JSON Profiles.
  2. Select the applicable security policy.
  3. Create a new JSON profile.
  4. Disable Parse Parameters in the JSON profile.
  5. Leave the remaining JSON profile settings at their required or default values unless different settings are required by the application.
  6. Navigate to Security > Application Security > URLs > Allowed URLs > Allowed HTTP URLs.
  7. Select the applicable security policy.
  8. Create or update a wildcard/explicit allowed URL covering the affected application paths. For example:
    POST /application-path/*
  9. Associate the new JSON profile with the wildcard/explicit allowed URL.
  10. Save and apply the security policy.
  11. Retest the affected JSON-array requests.
  12. Monitor the application security event logs to confirm that the Illegal parameter violations no longer occur and that unrelated security violations continue to be handled according to policy.

Additional Information

  • Disabling Parse Parameters prevents JSON array values from being interpreted as application parameter names. But this doesn't hinder the security as still the request payload in body will be fully inspected as a whole. 
  • Apply this configuration only to URLs and HTTP methods that legitimately receive JSON arrays.
