K000138514: [F5OS-C] Is it possible to replace blade without ucs restoration when the partition has one blade assigned?

Published

Applies to

Source

Description

When single blade for the partition, is there any other way to replace it without UCS restoration written in

  • K08485448 : [F5OS-C] Replacing a blade in a VELOS system that has multiple blades installed
  • K19494503: Replacing a blade in a VELOS system that has only a single blade installed

 

Environment

  • F5OS-C
  • Velos
  • RMA
  • Blade
  • Spare slot available in the Chassis
 

Cause

  • RMA blade
 

Recommended Actions

If your blade to be replaced is up and running at the moment and also the chassis has spare slot1:
NOTE: All should have happen seamlessly, however, we recommend to do this while the Tenant is in Standby and in maintenance window.

1. insert the replaced blade to spare slot.

2. On System Controller GUI/CLI, add the blade in the spare slot to the partition.

NOTE: On Partition CLI (show cluster) / GUI (the new blade can be green but state Empty), wait till the software installation and clustering are completed.

3. Add the blade to the tenant on the Partition CLI/GUI

NOTE: Software installation and configuration syncing between blade will happen. But it will be recognized and working status it is completed.

4. Once all OK, then remove the faulty blade from the tenant configuration on the Partition CLI/GUI.

5. Remove the faulty blade from the Partition configuration on System Controller CLI/GUI.
