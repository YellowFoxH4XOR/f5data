Description

The X-Originating-IP is a email header field for identifying the originating IP address of a client connecting to a mail service's HTTP frontend.

This article explains the relationship between the X-Originating-IP header with the BIG-IP.

Environment

  • BIG-IP
  • E-mail Server

Cause

None

Recommended Actions

When the Virtual Server has enabled SNAT or Auto Map, the X-Originating-IP will be SNAT Pool or self IP addresses respectively. This is because the SNAT Pool or the self IP will be initiating a new connection to the email server.

If the Source Address Translation is None, the X-Originating-IP will be the client IP address which is communicating with the Virtual Server.
Important: When Source Address Translation is set to None, the email server will respond to the client IP and this might cause an asymmetric routing issue. Please ensure that traffic from the email server will return to the BIG-IP when you have set Source Address Translation to None.

Any other changes to the X-Originating-IP must be done on the email server.

None
