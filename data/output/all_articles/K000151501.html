Description

Most BIG-IP platforms include the Auto Last Hop feature on the management interface:

  • K52592992: Overview of the Auto Last Hop feature on the management interface

How can I verify if the system is using a lasthop entry for return traffic, without performing a route lookup or ARP resolution?

Environment

  • Auto Last Hop
  • Kernel lasthop module
  • Management interface

Cause

None

Recommended Actions

Kernel lasthop entries can be viewed by reading the /proc/net/lasthop file.

One approach is to use the column command to format the output:

column -t < /proc/net/lasthop

The example below shows a lasthop entry associated with an SSH connection from source IP 172.16.17.1 to a BIG-IP with management IP 10.1.1.10.

The age value of 0 indicates the entry is being actively refreshed by ingress packets.

Packets are arriving from a gateway that uses 10:00:5e:10:12:34. Response packets will be sent towards this MAC address, without a route lookup for 172.16.17.1.

[root@bigip:Standalone] config # column -t </proc/net/lasthop
proto  local_address    rem_address          dev   mac_address        age  ref
TCP    10.1.1.10:22     172.16.17.1:50956    mgmt  10:00:5e:10:12:34  0    2

Additional Information

BIG-IP hardware platforms, vCMP guests and F5OS tenants include the kernel lasthop module. BIG-IP Virtual Edition (VE) does not.
