Description

When importing firewall configurations from BIG-IP (LTM, AFM or different module) devices into BIG-IQ CM, administrators may be prompted to resolve configuration conflicts by selecting either "USE_BIGIP" or "USE_BIGIQ". The chosen option determines whether device or CM configuration becomes authoritative.

Environment

  • BIG-IP Module Import
  • BIG-IQ CM
  • Import  option chosen

Cause

The presence or absence of doNotCopyReferences within config-copy tasks directly reflects which conflict resolution option ("USE_BIGIP" vs. "USE_BIGIQ") was chosen during import.

Recommended Actions

  • If "USE_BIGIQ" is selected:
    The config-copy task includes doNotCopyReferences, listing objects not copied from device.
  • If "USE_BIGIP" is selected:
    No doNotCopyReferences property; all objects are overwritten from device.
  • Verification Steps:
    • Retrieve relevant import/declaration output.  
      • restcurl -u admin:a /cm/<module>/tasks/declare-mgmt-authority

NOTE Possible Values (access, adc-core, asm, dns, firewall, security-shared or websafe)
