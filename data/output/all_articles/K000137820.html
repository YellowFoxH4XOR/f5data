Description

APM can be configured behind Wide Area DNS (Wide-IP GTM). See Related Content. This functions by having the first connection via the Wide-IP FQDN processed as a redirect to the narrow-IP of that APM host. This works but results in the following usability issues.

  • After the Wide to narrow redirection, the browser can be bookmarked at the narrow-ip.
  • After an APM session is logged out or times out, the login option selects the narrow-ip again.

This reduces the utility of having a Wide-IP system.

Cause

This is an inevitable consequence of APM and Wide-IP compatibility.

Recommendation

Set an iRule on the APM Virtual Server. It disables events on that TCP flow to prevent APM from activating anyway.
This is cleared by explicitly returning "connection close".
This also performs the redirect from Wide to Narrow as specified by the guide.
  
when RULE_INIT {
 set static::wide_fqdn  "wide.example.com"
 set static::narrow_fqdn  "apm1.example.com"
 set static::root_domain "example.com"
 
 set static::marker_cookie [format "%s=%s; path=/; domain=%s" wide_marker yes $static::root_domain]
 
 # set to 0 to disable logging
 set static::wide_debug 1
}


when HTTP_REQUEST  {
    if { [HTTP::has_responded] } { return }

# Send Logout and Disconnect back to wide_fqdn

    if { [HTTP::uri] ne "/" } {return}
    if { [HTTP::method] ne "GET" } { return }

    if  { ([HTTP::header referer] contains "hangup") or ([HTTP::header referer] contains "/my.policy") } {

      HTTP::respond 302 Location "https://$static::wide_fqdn" Connection close
      if {$static::wide_debug} { log -noname  local0. "Hangup or Timeout, redirecting to Wide." }
      event disable all
      return
    }

# Narrow Persistence, as required by Guide.

    if { [HTTP::host] eq $static::wide_fqdn } {
      if {$static::wide_debug} { log -noname  local0. "Wide, redirecting to Narrow, Setting Cookie." }
      HTTP::respond 302 Location "https://$static::narrow_fqdn" "Set-Cookie" $static::marker_cookie Connection close
      event disable all
      return
    }

# Direct to Narrow (Bookmark) Detection

    if { [HTTP::cookie exists "wide_marker"] } {
 #      log -noname  local0. "Narrow, has cookie, Normal, ignore."
       return } 
    
      if {$static::wide_debug} { log -noname  local0. "Narrow, no cookie, (bookmark) redirecting to Wide." }
      HTTP::respond 302 Location "https://$static::wide_fqdn" Connection close
      event disable all
}

Additional Information

May not work with HTTP/2 or HTTP/3
