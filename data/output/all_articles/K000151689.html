Description

Traffic Management Criteria fails to create when the virtual server name starts with a number and adding a source address list.

GUI show following error.

Some fields below contain errors. Correct them before continuing.

/var/log/ltm log file show following error.

err mcpd[7072]: 01070088:3: The requested object name (/Common/10.1.1.1_VS_TMC_OBJ) is invalid.

/var/log/webui.log file show following error.

ERROR [ajp-bio-127.0.0.1-8009-exec-18] virtual_server.AbstractVirtualServerSettingsHandler:error     - java.sql.SQLException: General error: 01070088:3: The requested object name (/Common/10.1.1.1_VS_TMC_OBJ) is invalid. in statement [SET TRANSACTION END]
...
Caused by: com.f5.mcp.io.McpQueryException: 01070088:3: The requested object name (/Common/10.1.1.1_VS_TMC_OBJ) is invalid.

Environment

BIG-IP LTM

Cause

IP address is used as virtual server name causes unwanted failure upon Traffic Matching Criteria object creation.

Recommended Actions

Do not use IP address as virtual server name.

Refer to article below for details.

K13209: BIG-IP configuration object names must begin with an alphabetic character

None
