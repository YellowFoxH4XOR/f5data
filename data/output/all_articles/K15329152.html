Known Issue

The BIG-IP ASM Configuration utility may display an incorrect list of attack signatures that are ready to be enforced.

This issue occurs when all of the following conditions are met:

  • You have attack signatures in a security policy that have not passed their staging period.
  • The attack signatures have no learning suggestions.
  • On the attack signatures page, you set the Staging filter to Ready to be enforced.

Impact

When you attempt to filter the list of attack signatures to display only signatures that are ready to be enforced, the system displays an incorrect list of attack signatures.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP ASM Configuration utility incorrectly displays a list of attack signatures that are not ready to be enforced.
