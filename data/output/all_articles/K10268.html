K10268: Configuring Active Directory password expiration warnings

Topic

Starting in FirePass version 6.0.3, you can configure FirePass to warn users if their Active Directory password is set to expire. To do so, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Users: Groups: Master Groups page.
  3. Select the name of the master group you want to configure.
  4. Click the Authentication tab.
  5. Select the Warn user of password expiration check box.

    Note: The Warn user of password expiration check box appears only if the master group is configured for Active Directory authentication. For information about configuring Active Directory authentication, refer to the FirePass Controller Administrator Guide.
  6. Click the User Experience tab.
  7. In the System Warnings row, select the Beginner or Advanced option button.

    Important: If the System Warnings option is set to Don’t Use, users will not receive an Active Directory password expiration warning.
  8. On the domain controller, define the following two settings in the Domain Security Policy:

    • Local Policy: Security Options: Interactive logon: Prompt user to change password before expiration
    • Account Policies: Password Policy: Maximum password age

    Important: These settings must be configured in the Domain Security Policy. If you configure these settings in the Domain Controller Security Policy, but not in the Domain Security Policy, FirePass will not warn users of password expiration.

Additionally, there are certain instances where the password expiration warning feature does not work properly. For more information, refer to the following Known Issue Solutions:

  • K9791: Users incorrectly receive a password expiration warning when the 'Password never expires' option is enabled
  • K10220: The password expiration warning may not display if the gPLink attribute contains multiple Group Policy Objects
  • K10774: The Active Directory password expiration feature fails after installing cumulative hotfix HF-603-5.x or after upgrading to version 6.1.0
