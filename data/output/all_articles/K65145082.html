Description

After upgrade to version 15.x or later, iRule using CATEGORY::lookup fails and traffic is no longer being processed. Following logs might be seen in var/log/ltm:

info tmm1[24359]: 01220009:6: Pending rule /Common/irule <HTTP_PROXY_REQUEST> aborted for x.x.x.x -> y.y.y.y
err tmm1[24359]: 01220001:3: TCL error: /Common/irule <HTTP_PROXY_REQUEST> - Could not prepare URL categorization request.      invoked from within "CATEGORY::lookup $domain"
Environment

  • Upgrade to version 15.x or higher
  • iRule using CATEGORY::lookup and "http://" used as URI

Cause

Issue is caused by "http://" missing trailing slash -  "http:///" is a valid URI recognized as uncategorized.

Recommended Actions

Modify the iRule by adding missing trailing slash. Below is an example:

Before Fix:

when HTTP_REQUEST {
    set url http://[HTTP::host]
    log "Will categorize $url"
    set category [CATEGORY::lookup $url]
    set string "Category of $url: $category"
    log $string
    HTTP::respond 200 content "$string\n" Content-Type text/plain
}

After Fix:

when HTTP_REQUEST {
    set url http://[HTTP::host]/    <---- note the trailing slash
    log "Will categorize $url"
    set category [CATEGORY::lookup $url]
    set string "Category of $url: $category"
    log $string
    HTTP::respond 200 content $string Content-Type text/plain
}
