Topic

You can request free 30-day trials for the following products:

  • NGINX Plus with NGINX App Protect
  • Connectivity Stack for Kubernetes

    This trial includes NGINX Ingress Controller and NGINX App Protect.

If you would like more information about free trials, downloads, and pricing, you can refer to the Get F5 page.

Description

Refer to the following sections for the NGINX products that you want to try:

  • NGINX Plus with NGINX App Protect
  • Connectivity Stack for Kubernetes

NGINX Plus with NGINX App Protect

  1. Go to the Try F5 NGINX Plus and F5 NGINX App Protect page.
  2. Fill out the Request a Free Trial form.
  3. Select START MY FREE TRIAL.
  4. Follow the instructions in the email you receive from the NGINX Evaluation team to activate your 30-day trial.

Connectivity Stack for Kubernetes

  1. Go to the Try the Connectivity Stack for Kubernetes page.
  2. Follow the instructions on the page to start your free trial.
