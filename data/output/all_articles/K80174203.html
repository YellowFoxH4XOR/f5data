Description

After an upgrade, several virtual servers may stop responding to ping. Once reviewed the configuration, it may turn out that the icmp-echo parameter of  network virtual-address had changed to disabled.
ltm virtual-address /example {
    address 10.10.10.0
    arp enabled
    icmp-echo disabled
    mask 255.255.255.0
    traffic-group /Common/traffic-group-1
}

Environment

  • After upgrade to v14 or higher
  • BIG-IP LTM 
  • Virtual Servers not responding to ping (icmp-echo disabled) 

Cause

Bug ID 1019085

Recommended Actions

Enable icmp-echo manually by running the following command:        
# tmsh modify ltm virtual-address 10.10.10.0 icmp-echo enabled
