K000136958: BIG-IQ marking active BIG-IP devices as unavailable during scheduled backup

Type
Support Solution
Published
2023-09-25
Updated
2023-09-25
Applies to
  • BIG-IQ
  • BIG-IP
  • BIG-IQ Centralized Management: 8.0.0, 8.0.X, 8.1.0, 8.1.X, 8.2.0, 8.2.X, 8.3.0, 8.3.X, 8.X.X
Source
https://my.f5.com/manage/s/article/K000136958

Description

BIG-IQ may temporarily mark a BIG-IP that is being backed up. This can be during a scheduled backup or a manually initiated backup of the BIG-IP. You may see logs similar to the following in /var/log/restjavad.log

 

// Device Refresh Timeout

[WARNING][89910][22 Aug 2023 18:05:39 UTC][8100/mgmt ForwarderPassThroughWorker] URI:http://localhost:8100/mgmt/shared/inflate?em_server_ip=10.10.10.10&;, Referrer:http://localhost:8100/shared/identified-devices/config/device-refresh, Method:POST, Exception:java.util.concurrent.TimeoutException: remoteSender:192.168.10.10, method:POST 

 

// Device Available Timeout

[WARNING][89911][22 Aug 2023 18:05:39 UTC][8100/mgmt ForwarderPassThroughWorker] URI:http://localhost:8100/mgmt/shared/inflate/available?em_server_ip=10.10.10.10&;, Referrer:http://localhost:8100/shared/device-availability, Method:GET, Exception:java.util.concurrent.TimeoutException: remoteSender:192.168.10.10, method:GET

 

// Backup with Timeout

[WARNING][89912][22 Aug 2023 18:05:39 UTC][8100/mgmt ForwarderPassThroughWorker] URI:http://localhost:8100/mgmt/tm/shared/sys/backup/5b0a1896-de56-430e-as9c-c26e8346276c?em_server_ip=10.10.10.10&; Method:GET, Exception:java.util.concurrent.TimeoutException: remoteSender:192.168.10.10, method:GET

 

// Authentication Timeout

[WARNING][89913][22 Aug 2023 18:05:39 UTC][8100/mgmt ForwarderPassThroughWorker] URI:http://localhost:8100/mgmt/shared/authz/tokens, Referrer:Unknown, Method:POST, Exception:java.util.concurrent.TimeoutException: remoteSender:Unknown, method:POST

 

 

Environment

  • BIG-IQ
  • BIG-IP

Cause

Restjavad timeout is to short to complete the BIG-IP backup task and for the BIG-IP to respond the device-refresh pooling

 

Recommended Actions

Increase the timeout values for restjavad, restnoded, and icrd

 

Modify the timeout values from the command line of the BIG-IP 

 

# tmsh modify sys db icrd.timeout value 300

# tmsh modify sys db restjavad.timeout value 300

# tmsh modify sys db restnoded.timeout value 300

 

Save changes and restart related services on the BIG-IP 

 

# tmsh save sys config

# tmsh restart sys service restjavad

# tmsh restart sys service restnoded
