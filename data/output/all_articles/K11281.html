Topic

The BIG-IP ASM attack signature properties screen contains a Last Updated attribute, which refers to the date in which F5 Product Development last modified the attack signature.

Note: The Last Updated date is not related to when the signature was first released or installed on the system.

To view the Last Updated date for an attack signature, perform the following procedure:

  1. Log in to the Configuration utility.
  2. From the Application Security Main tab, click Attack Signatures.
  3. Click the Policy Attack Signatures tab.
  4. Click the signature for which you want to determine the Last Updated date.

    The Last Updated date displays on the Signature Properties screen.

    For example, in BIG-IP ASM version 10.1.0, the Last Updated date for the .createDocument (Headers) attack signature appears similar to the following example:

    Last Updated 07/13/2008
