Description

Not seeing expected log messages in /var/log/audit.

For example:
When the customer creates an iRule he would expect to see this logged in the /var/log/audit logs but this is not happening.

Environment

  • BIG-IP LTM 14.1.x
  • File var/log/journal does exist
  • Error was encountered while opening journal files: Input/output error

Cause
In v14.1.x logs are being processed by systemd-journald.
Issues with daemon systemd-journald not operating properly. 

Recommended Actions

  1. Run the following command to test systemd-joutnald daemon
     
    # journalctl -f > /var/tmp/<filename>.log

    -f, --follow
        Show only the most recent journal entries, and continuously print new entries as they are appended to the journal.
     
  2. If you get error "Error was encountered while opening journal files: Input/output error" then restart systemd-journald and this should resolve the issue.
        
    # systemctl restart systemd-journald
