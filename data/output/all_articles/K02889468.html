Issue

Error Message

info sdmd[<PID>]: 018e0005:6: Exiting, received shutdown signal

In this error message, note the following:

  • <PID> is the process ID for the Traffic Management Microkernel (TMM) process.

For example:

info sdmd[27423]: 018e0005:6: Exiting, received shutdown signal

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following conditions are met:

  • The sdmd process receives a sigint, sigterm, or sigquit signal.
  • You stop or restart the sdmd process by using the bigstart restart sdmd or bigstart stop sdmd command, or when the iRules Language Extensions (iRules LX) feature is unprovisioned.

Note: The sdmd process logs this message during a normal shutdown.

Impact

The sdmd process supports the iRules LX feature. If the sdmd process is not running, iRules LX is not operational.

Recommended Actions

If iRules LX is provisioned and the sdmd process is not running, you can restart the sdmd process from the command line by performing the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Type the following command:

    bigstart start sdmd

  3. Press Enter.
