Description

Error when reactivating license 
Error Message

err mcpd[5933]: 01070266:3: Dossier error 12

Environment

  • BIG-IP device is virtual
  • Using API call from BIG-IQ to license device
  • BIG-IP device is not reachable from the BIG-IQ

Cause:

This occurs when pushing a device license assignment from the BIG-IQ for assignmentType UNREACHABLE

The BIG-IP will show the license as "not operational (expired or digital signature does not match contents"  The BIG-IP is unable to be licensed with the assigned license from the BIG-IQ license pool.

Recommended Actions

The Dossier error 12 is an indicator that the incorrect hypervisor has been selected in the API call. As as example:

POST https://localhost/mgmt/cm/device/tasks/licensing/pool/member-management Request: { "licensePoolName": "pool name", "command": "assign", "address": "192.0.2.1", "assignmentType": "UNREACHABLE", "macAddress": "00:00:5E:00:53:00", "hypervisor": "azure", "tenant":"myBigIP1" }

when pushed to a device that is not in the Azure cloud space, but is a VMWare device, results in:
 

Sep 13 10:09:34 localhost emerg mcpd[5933]: 01070608:0: License is not operational (expired or digital signature does not match contents).
Sep 13 10:10:59 localhost err mcpd[5933]: 01070266:3: Dossier error 12.

The resolution in this instance is to change the hypervisor key/value pair to "hypervisor: vmware"
