K000138975: I configured an Allow List and locked myself out of the GUI/SSH in F5OS/VELOS. How do I restore?

Type
Support Solution
Published
2024-03-21
Updated
2024-03-21
Source
https://my.f5.com/manage/s/article/K000138975

Description

When configuring an Allow List for administrative access to the F5OS/VELOS environment, the default behavior is all administrative ports (except port 161) are allowed from any IP Address. When you create an entry in the Allow List entry for a port or ports, the behavior changes to only allow access from the entry for the specified IP and port(s).

Example 1:

Add from: 198.51.100.1/32 for port 443

Result:

Administrative access to port 443 is restricted to come from 198.51.100.1.

Example 2:

Add from: 198.51.100.0/24 for all ports  (443 (HTTPS), 80 (HTTP), 8888 (RESTCONF), 161 (SNMP), 7001 (VCONSOLE), and 22 (SSH). 

Result:

Administrative access to all ports is restricted to come from 198.51.100.0/24.

Environment

  • F5OS-A or F5OS-C
  • Adding an Allow List entry for Controlling Management access to the Device.

 

Cause

Behaving as designed.

 

Recommended Actions

To recover access to the device, You will need to access the device from the IP configured in the Allow List entry, or Access the device from the Console port using command line.

 

Use the webUI

  1. Log in to the webUI of the F5 rSeries system as the admin user.
  2. Go to SYSTEM SETTINGS > Allow List.
  3. Select the entry you want to delete.
  4. Select Delete.

 Use the CLI from Console:

  1. Log in to the CLI of the F5 rSeries system as the admin user.
  2. Enter the following command: 
    1. config
  3. Remove an existing entry in the Allow List using the following command syntax: 
    • no system allowed-ips allowed-ip <name> config <ipv4 | ipv6> address <ip_address> prefix-length <prefix> port <port>
    • In the command syntax, note the following:
      • <name> is the name for the Allow List entry.
      • <ipv4 | ipv6> is the protocol, either IPv4 or IPv6.
      • <ip_address> is the source IP address or subnet to allow.
      • <prefix> is the prefix length.
      • <port> is the port on the management interface.
  4. For example, the following command removes an allow list entry Named "entry1" from IPv4 address 10.10.10.50 to port 443 on the management interface: 
    1. no system allowed-ips allowed-ip entry1 config ipv4 address 10.10.10.50 prefix-length 32 port 443
  5. This command can also be truncated, which will remove all available settings for entry1:   
    1. no system allowed-ips allowed-ip entry1
  6. repeat as needed for any additional Allow List  entries.

By removing the Allow List entries, you have reverted the system to allow access from any IP, and can login to the GUI and re-consider your Allow List strategy.
