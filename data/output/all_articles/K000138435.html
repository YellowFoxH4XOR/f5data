K000138435: Inconsistent behavior exists in the creation of DNS names across different software versions

Type
Support Solution
Published
2024-02-01
Updated
2024-02-01
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000138435

Description

You may have noticed that you were able to create *xx_yy.local in the APM network resource's DNS Address Space on v15.1.7, but were unable to do so in v16.1.4.2.

Environment

  • APM
  • DNS Address Space

Cause

This issue is caused by ID1167985 and ID1071021.

Recommended Actions

ID1167985 has been fixed in v16.1.4.2.
You may need to consider requesting an EHF for ID1071021 on top of v16.1.4.2.

Additional Information

None
