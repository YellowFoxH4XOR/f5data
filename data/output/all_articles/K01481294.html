Known Issue

The BIG-IP system may fail to add a network interface to an existing network trunk.

This issue occurs when all of the following conditions are met:

  • You have a network trunk configured on the BIG-IP system.
  • The network trunk consists of network interfaces with the media speed setting fixed to a lower speed.

    For example, a BIG-IP system may have an Ethernet network interface with the media speed setting forced to 100Mbps on a 1GbE link. The network interface configuration will look something similar to the following example:

    net interface 1.3 {
    if-index 96
    mac-address 00:23:e9:00:66:c5
    media-active 100TX-FD
    media-fixed 100TX-FD
    media-max 1000T-FD
    mtu 1800
    }

  • You attempt to add another network interface to the network trunk using either the BIG-IP Configuration utility or TMOS Shell (tmsh) command.

Impact

You may not be able to add an additional network interface to an existing network trunk.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to add a network interface to an existing trunk, the operation fails with an error message similar to the following example:

    1070619:3: Interface 1.3 media type is incompatible with other trunk members

Workaround

To work around this issue, you can first remove all the interfaces from the trunk and re-add them all at the same time. To do so, perform the following procedure:

Impact of workaround: There will be disruption to the production network if the network trunk is currently in use. F5 recommends that you perform this procedure during a scheduled maintenance period.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Remove all the interfaces from the network trunk by using the following command syntax:

    modify /net trunk <trunk_name> interfaces delete { <interface_name1> <interface_name2> }

    For example, to remove all the interfaces from a network trunk named test-trunk, which has been configured with two interfaces 1.1 and 1.2, type the following command:

    modify /net trunk test-trunk interfaces delete { 1.1 1.2 }

  3. Add the new interface together with the existing interfaces to the network trunk by using the following command syntax:

    modify /net trunk <trunk_name> interfaces add { <interface_name1> <interface_name2> <interface_name3> }

    For example, to add interface 1.3 to the existing network trunk named test-trunk, type the following command:

    modify /net trunk test-trunk interfaces add { 1.1 1.2 1.3 }

  4. Save the changes by typing the following command:

    save /sys config

  5. To exit tmsh, type the following command:

    quit
