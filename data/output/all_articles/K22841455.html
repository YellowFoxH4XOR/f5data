Issue

Error Message

notice mcpd[<PID>]: 01070421:5: Base configuration initialization phase triggered

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.

For example:

notice mcpd[5524]: 01070421:5: Base configuration initialization phase triggered

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The mcpd process loads the configuration from the text configuration files instead of from the binary configuration image.

The mcpd process loads the text configuration files into the running configuration during the first boot up process and builds a binary configuration file that is used for subsequent starts.  If the binary file is missing or corrupted, the mcpd process loads the configuration from the text configuration files and generates this message.

Impact

There is no impact; this message is informational.  The mcpd process should become operational after the system successfully loads the configuration.

Recommended Actions

None
