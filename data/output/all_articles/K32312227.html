Known Issue

When you use the TMOS Shell (tmsh) to create a user configuration set (UCS) backup file, the system displays verbose output.

This issue occurs when the following condition is met:

  • You use tmsh to create a UCS backup file.

Impact

Creation of the UCS file generates verbose detail.

Note: This issue is cosmetic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When using tmsh to generate a UCS backup file, command output appears similar to the following example:

    tmsh save sys ucs ucs-bigiq-04022018.ucs

    Saving active configuration...
    Mon Apr  2 22:55:21.727  nssize is a deprecated parameter
    forked process: 2386
    all output going to: /var/log/tokumx-temp.log
    child process started successfully, parent exiting
    TokuMX mongo shell v2.0.3-mongodb-2.4.10
    connecting to: 127.0.0.1:27999/local
    { "dropped" : "local", "ok" : 1 }
    /var/local/ucs/ucs-bigiq-04022018.ucs is saved.

    The expected command output appears similar to the following example:

    tmsh save sys ucs ucs-bigiq-04022018.ucs

    Saving active configuration...
    /var/local/ucs/ucs-bigiq-04022018.ucs is saved
