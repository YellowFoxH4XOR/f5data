K21330246: HTTP/2 full proxy cannot be combined with ASM profile

Type
Support Solution
Published
2020-06-12
Updated
2026-06-11
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.X.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K21330246

Description

  • HTTP/2 full proxy cannot be combined with ASM profile
  • Enabling ASM policy to a Virtual Server with HTTP/2 profile may show the below error message 
    • Could not update policy due to ASMConfig exception: [603] MCP Validation error - 01070734:3: Configuration error: Profile(s) found on /Common/<name of profile> that are not allowed

Environment

  • ASM
  • HTTP/2
  • HTTP MRF Router

Cause

  • In version 14.1.x, HTTP/2 full-proxy configuration works with BIG-IP Local Traffic Manager (LTM) only.
  • Any other configuration is not supported on any optional BIG-IP modules including ASM.
  • HTTP/2 Full proxy + HTTP/2 MRF Router + ASM is not supported in 14.1.x

Recommended Actions

  • Upgrade to the latest version 15 or above where HTTP/2 full proxy is supported with ASM or Advanced WAF.

Additional Information

  • None
