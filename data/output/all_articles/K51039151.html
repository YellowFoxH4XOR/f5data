Description

Unable to modify custom parent client-ssl profile with error message below disaplayed on GUI/CLI and can not modify the custom parent profile.

   0107157c:3 Selected client SSL profiles do not match security policies for Virtual Server /<partition_name>/<virtual_server_name>
 

Environment

  • BIG-IP v11.* and later
  • Following K13452: Configuring a virtual server to serve multiple HTTPS sites using the TLS Server Name Indication feature, you have created custom parent client ssl profile (/Common/Client_ssl_parent_profile), and child client ssl profiles  (/Common/Client_ssl_child_profile1, /Common/Client_ssl_child_profile2) with it is assigned to a virtual server (/Common/virtual_server_example).
    example:
ltm profile client-ssl /Common/Client_ssl_child_profile1 {
    app-service none
    cert /Common/example_SNI.crt
    cert-key-chain {
        example_SNI_example_SNI {
            cert /Common/example_SNI.crt
            chain /Common/example_SNI.crt
            key /Common/example_SNI.key
        }
    }
    chain /Common/example_SNI.crt
    <<-------- This does not have checkmark for custom for ciphers
    defaults-from /Common/Client_ssl_parent_profile
    inherit-certkeychain false
    key /Common/example_SNI.key
    passphrase none
    server-name www.example.com
}
ltm profile client-ssl /Common/Client_ssl_child_profile2 {
    app-service none
    cert /Common/example2_SNI.crt
    cert-key-chain {
        example2_SNI_example2_SNI {
            cert /Common/example2_SNI.crt
            chain /Common/example2_SNI.crt
            key /Common/example2_SNI.key
        }
    }
    chain /Common/example2_SNI.crt
    ciphers DEFAULT <<--------[!] This has checkmark for custom for ciphers, but not modified.
    defaults-from /Common/Client_ssl_parent_profile
    inherit-certkeychain false
    key /Common/example2_SNI.key
    passphrase none
    server-name www.example2.com
}

when /Common/Client_ssl_parent_profile's ciphers are modified, it will produce the error:
   0107157c:3 Selected client SSL profiles do not match security policies for Virtual Server /Common/virtual_server_example
and not able to save the change, since Client_ssl_child_profile2 is going to have different cipher suite.
 

Cause

This is working as intended.
 

Recommended Actions

Remove the checkmark from custom column, for Ciphers and/or Client Authentications.
