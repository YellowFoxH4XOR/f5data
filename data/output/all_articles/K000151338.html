K000151338: Nginx in R32 (no patches) reports duplicate subject names for cert bundle

Type
Support Solution
Published
2025-05-14
Updated
2026-08-12
Status
Legacy Content
Applies to
  • NGINX Products
  • NGINX Plus: R32
Source
https://my.f5.com/manage/s/article/K000151338

Description

Implementation of a certificate bundle that contains duplicate subject names. For example, a client ssl directive that implements a certificate bundle with duplicate certificates: 

ssl_client_certificate cert_bundle_example_with_dup_certs.pem;

All certificates will be reported to clients, even the duplicates.

Environment

NGINX R32 (no patches)

Cause

Regression

Recommended Actions

Upgrade (R32 P1 or greater)

Additional Information

The NGINX Plus R32 Updates section of the Releases documentation indirectly indicates this issue has been fixed as part of a bundle of SSL certificate caching fixes, "Various fixes in SSL certificate caching".
