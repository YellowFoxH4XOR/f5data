Description

After rebooting F5OS appliance, tenants may fail to start or become unreachable. The following symptoms may be observed:

  • GUI error:

    "Failure for data/f5-tenants:tenants API. The server or an underlying service is unreachable. error-message: Failure for data/f5-tenants:tenants API. The server or an underlying service is unreachable. original-error: Network Error"

  • Pod logs show repeated errors such as "certificate signed by unknown authority".
  • CLI command show tenants returns:

    "Error: application communication failure" 

  • System logs contain messages like:

    tpm has no data, writing new key. getKeyFromTpm
    Failed to fetch Key from TPM2. Error code
    Key header check failed

Environment

  • Product: F5OS-A (Appliance)
  • Software Version(s): 1.8.0. or 1.5.X
  • Configuration: rSeries appliance with tenants deployed

Cause

This issue is caused by Bug ID 1976761

Recommended Actions

  • There is currently no supported workaround for this issue.
  • To resolve, perform a bare-metal reinstall of F5OS-A and reconfigure both system and tenants from scratch.
  • Do not restore configuration backups that may contain mismatched keys.
