Topic

Prior to FirePass version 5.5, a FirePass user could configure proxy server settings when they launched a Network Access favorite. These settings, which are used only for connections to FirePass, could be configured in the Setup section of the Network Access pop-up window under the Proxy Settings section. However, this feature was discontinued in FirePass version 5.5. Proxy settings are now automatically configured based on the browser's proxy settings.

Clients that require proxy server settings for FirePass that are different from the browser's default settings can use one of the following methods:

Direct access for FirePass; access to other sites using a proxy server

For direct access to FirePass and access to other sites using a proxy server, you can configure the FirePass name (or IP address if it is used to access FirePass) in the browser's proxy exception list.

Access to FirePass using a proxy server; direct access to other sites

To access FirePass using a proxy server with direct access to other sites, you can configure your browser with an automatic proxy configuration URL that points to a Javascript configuration file. The Javascript file contains the necessary configuration logic to direct FirePass requests through the proxy server, and to allow all other requests to go directly to their destinations. The Javascript file can be a local file or one that resides on a server.

Refer to the following URL for information about creating a proxy configuration file, which is often referred to as a .pac file:

www.microsoft.com/technet/prodtechnol/ie/reskit/6/part6/c26ie6rk.mspx

Access to FirePass using a different proxy server than the proxy server used to access other sites

To access FirePass using a different proxy server than the proxy server used to access other sites, you must use an automatic proxy configuration file. Refer to the Access to FirePass using a proxy server and direct access to other sites section.
