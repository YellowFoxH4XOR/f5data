K000137833: gtmd does not log "Will probe" / "Will not probe" with debug mode in /var/log/gtm

Type
Support Solution
Published
2023-12-07
Updated
2023-12-07
Applies to
  • BIG-IP
  • BIG-IP DNS: 16.X.X, 16.1.X, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.X, 16.0.1, 16.0.0
  • BIG-IP Link Controller: 16.X.X, 16.1.X, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.X, 16.0.1, 16.0.0
Source
https://my.f5.com/manage/s/article/K000137833

Description

log.gtm.level is set debug, to see which BIG-IP DNS is responsible to send monitor.
However can not see any "Will probe" or "Will not probe" log writen in K52381445: DNS monitor state showing ''no reply from big3d: timed out'' .

Environment

  • BIG-IP DNS
  • v16.1.* 
  • log.gtm.level
  • debug
 

Cause

  • Bug ID 1117405
 

Recommended Actions

To workaround this, 

  • make a unaffecting config change (e.g., create a dummy wide-ip or a dummy gtm pool) to force 'will probe' messages to be seen.　
  • restart gtmd    IMPORTANT: this has service impact
