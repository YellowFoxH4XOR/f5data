Known Issue

This is the result of a known issue. Traffic Management Microkernel (TMM) performance may be reduced when the Linux kernel processes IDE interrupts using the same CPU as TMM.

F5 Product Development tracked this issue as CR57883, and CR58211, and it was fixed in BIG-IP 9.1.2 and 9.2.3. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

If upgrading is not an immediate option, you can work around this issue by configuring the Linux kernel to use a CPU that TMM will not use when it processes the following interrupts:

  • IRQ 0 (the timer)
  • IRQ 14 (ide0)
  • IRQ 15 (ide1)
  • IRQ 18 (eth0)

This workaround is only effective on the following platforms, which are equipped with multiple CPUs:

  • BIG-IP 8400 (D84)
  • BIG-IP 6800 (D68)
  • BIG-IP 6400 (D63)
  • BIG-IP 5100 and 5110 (D51)
  • BIG-IP 2400 (D44)
  • BIG-IP 540 (D35)

To enable the workaround, perform the following steps:

  1. Log in to the command line.
  2. Back up the /etc/rc.local file by typing the following command:

    cp /etc/rc.local /etc/rc.local.sol5697

  3. Set the processor affinity for IRQ 0 by typing the following command:

    echo 1 > /proc/irq/0/smp_affinity

  4. Save the setting for IRQ 0 by typing the following command:

    echo "echo 1 > /proc/irq/0/smp_affinity" >>/etc/rc.local

  5. Set the processor affinity for IRQ 14 by typing the following command:

    echo 1 > /proc/irq/14/smp_affinity

  6. Save the setting for IRQ 14 by typing the following command:

    echo "echo 1 > /proc/irq/14/smp_affinity" >>/etc/rc.local

  7. Set the processor affinity for IRQ 15 by typing the following command:

    echo 1 > /proc/irq/15/smp_affinity

  8. Save the setting for IRQ 15 by typing the following command:

    echo "echo 1 > /proc/irq/15/smp_affinity" >>/etc/rc.local

  9. Set the processor affinity for IRQ 18 by typing the following command:

    echo 1 > /proc/irq/18/smp_affinity

  10. Save the setting for IRQ 18 by typing the following command:

    echo "echo 1 > /proc/irq/18/smp_affinity" >>/etc/rc.local

Note: The commands will take effect immediately; a reboot is not necessary.

To disable the workaround, perform the following steps:

  1. Log in to the command line.
  2. Restore the backed up /etc/rc.local file by typing the following command:

    cp /etc/rc.local.sol5697 /etc/rc.local

  3. Set the processor affinity for IRQ 0 by typing the following command:

    echo ffffffff > /proc/irq/0/smp_affinity

  4. Set the processor affinity for IRQ 14 by typing the following command:

    echo ffffffff > /proc/irq/14/smp_affinity

  5. Set the processor affinity for IRQ 15 by typing the following command:

    echo ffffffff > /proc/irq/15/smp_affinity

  6. Set the processor affinity for IRQ 18 by typing the following command:

    echo ffffffff > /proc/irq/18/smp_affinity

Note: The commands will take effect immediately; a reboot is not necessary.
