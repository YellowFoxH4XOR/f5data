Description

BIG-IQ GUI: Configuration tab > LOCAL TRAFFIC > Certificate Management > Certificates & Keys - The state of the cert and key is showing as "Not Managed" resulting in deployments failing.

 

Environment

  • BIG-IQ
  • Certificate and Key management
  • State is "Not Managed"

Cause

When you discover a BIG-IP device, BIG-IQ automatically imports meta data about the device's SSL certificates used for traffic management so you can monitor their expiration dates.
These SSL certificates display as unmanaged on BIG-IQ. Before you can deploy an SSL certificate and key to a BIG-IP device, you must convert it to managed by uploading its certificate/key to BIG-IQ.

Recommended Actions

Import certificate/key to BIG-IQ to change state to managed.

Additional Information

The following error message is displayed when trying to import invalid or compressed file to BIG-IQ instead of for example .crt file:

"Unable to retrieve ssl cert information"
