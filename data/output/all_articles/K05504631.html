Description

When doing a console access to vCMP host, it directly connects to the guest inside, not the host itself.

Environment

  • BIG-IP
  • VIPRION Platform
  • Running v14.x
  • Using console access to vCMP host

Cause

There still has a telnet session on the vCMP host, connecting to the guest.

Recommended Actions

  1. Secure Shell access directly to the vCMP host.
  2. Check the console process (tty), you will see the telnet session to the guest is still listed even you already quitted the session.

    To List the process, using the following command:

    ps aux | grep <service>

    For the example:
