Description

How to set the ifAlias attribute for the BIG-IP system

Environment

  • BIG-IP LTM
  • SNMP v3
  • SNMP v2c

Cause

BIG-IP interface description is not polled via SNMP.

Recommended Actions

1. Configure BIG-IP system with SNMP RW access. 

2. Set ifAlias from the CLI advanced shell (bash). For example,

# snmpset -v3 -l authPriv -u snmpusertest -a SHA -A "f5network" -x aes -X "f5network" localhost ifAlias.48 s "Internal"
IF-MIB::ifAlias.48 = STRING: Internal

3. Test via snmpwalk or snmpget. For example,

# snmpwalk -v3 -l authPriv -u snmpusertest -a SHA -A "f5network" -x aes -X "f5network" localhost ifAlias
IF-MIB::ifAlias.32 = STRING:
IF-MIB::ifAlias.48 = STRING: Internal

# snmpget -v3 -l authPriv -u snmpusertest -a SHA -A "f5network" -x aes -X "f5network" localhost ifAlias.48
IF-MIB::ifAlias.48 = STRING: Internal

4. Verify and poll ifAlias from your SNMP monitoring server.

Additional Information

Command syntax for SNMPv2c

# snmpset -v2c -c f5network localhost ifAlias.48 s Internal
IF-MIB::ifAlias.48 = STRING: Internal
# snmpwalk -v2c -c f5network localhost ifAlias
IF-MIB::ifAlias.32 = STRING:
IF-MIB::ifAlias.48 = STRING: Internal


Note: ifAlias.XX
XX is the if-index number of the interface

tmsh list net interface 1.1
net interface 1.1 {
    if-index 48
