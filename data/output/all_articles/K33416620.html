Description

You want to disable appliance mode configuration

Environment

  • BIG-IP 13.1.0

Cause

You load a UCS file from a BIG-IP with appliance mode License into a different BIG-IP without appliance mode license. The new BIG-IP will have configuration related to appliance mode restrictions even though your device is not licensed with an appliance mode license. 

Recommended Actions

Disable the appliance mode system db variables.

  1. Log on to the BIG-IP command line.
  2. Type the following TMSH commands:
    tmsh modify sys db systemauth.disablebash value false 
    tmsh modify sys db systemauth.disablerootlogin value false
