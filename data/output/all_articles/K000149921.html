K000149921: Disk partition /tmp/eud has only 0% free

Type
Support Solution
Published
2025-04-07
Updated
2025-04-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0, 17.X.X, 17.5.X, 17.5.0, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X
Source
https://my.f5.com/manage/s/article/K000149921

Description

  • You have noticed the following error message: Disk partition /tmp/eud has only 0% free.
  • The same can be seen upon running df -h from bash:
/dev/loop1                             130M  130M     0 100% /tmp/eud
  • No USB flash drive is connected to your device.

Environment

  • LTM
  • /tmp/eud directory

Cause

The /tmp/eud directory was mounted accidentally or remained mounted after a past activity, for example after an EUD upgrade.

Recommended Actions

To stop receiving the error messages, unmount /tmp/eud.

Impact of the procedure: Performing the following procedure should not have a negative impact on your system.

 

  1. Make sure that no USB flash drive is connected to the device.
  2. Verify if /tmp/eud is mounted. Use the following command:
mount
  1. If /tmp/eud is mounted, you will see a similar output:
/tmp/eud/EUD_SF-4.0.1.4.0.im on /tmp/eud type iso9660 (ro,relatime)
  1. Unmount the directory:
unmount /tmp/eud
  1. Execute df -h again. You should not see the output for /tmp/eud.
  2. The error message should not appear again.

Additional Information

None.
