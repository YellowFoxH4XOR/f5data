Description

On a multi-bladed Viprion chassis, the tmsh show /sys connection command may display less than 1000 flows, while running running more than 1000 CPS.
 

Environment

  • VIPRION multi-bladed chassis

Cause

Starting with version 13.1.0 and later, the command show /sys connection  displays only 1000 entries in connection table, however what is not discussed in the article K20234023 is that this number (the limit) is adjusted to take in to the account number of TMMs that are processing traffic.

Example:
Default output of show /sys connection command  is equivalent of 

show /sys conn max-result-limit 1000

This assumption will work for single bladed systems like appliances and VE. For multi-bladed system we need to take in to consideration for number of blades.

Assuming Viprion chassis with 8 blades and 12 TMMs with 2 threads each. Using formula for show /sys connection will display 1000/(8*12*2) ~ 6 connections in flow table. Please note that  formula used is more complicated, but the gist is the same.

Result  "appears"  strange, we would expect 143k but it is consistent with the formula.

This issue is less pronounced if Slot/TMM distribution is better - it is single slot, single TMM in our example 

Recommended Actions

When evaluating number of connections you would need to take in to account for number of blades and TMMs to understand output of show /sys connection.
