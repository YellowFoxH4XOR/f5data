K000150694: APM: How to check apm client version on BIGIP using CLI

Published

Source

Description

This KB article explains how BIGIP administrators can verify the installed apm client (aka EdgeClient app) version on BIGIP using CLI

Environment

  • BIGIP
  • APM client 
  • EdgeClient

Cause

None

Answer/Recommended Actions

Run the below command in bash to verify the apm client version running on BIGIP:

[root@bigip.local:Active:Standalone] config # df -h | grep apm

For example, the below lab BIGIP has apm client 7250 installed:

[root@bigip.local:Active:Standalone] config # df -h | grep apm 
/dev/loop0                                        445M  445M     0 100% /var/apm/mount/apmclients-7250.2024.1010.1953-6802.0.iso
