Description

When sending ASM report via mail get the error in /var/log/avr/avrexport.log:
Could not send e-mails: SMTP Error: data not accepted.; Accepted; Error code: 250

Environment

  • ASM/AdvWAF
  • ASM Scheduled Reports

Cause

When analyzing the packet capture we see the BigIP send a FIN immediately after sending the data. This causes the connection to disconnect causing the mail delivery failure

Recommended Actions

Increasing the timeout to 30 on the file /var/ts/dms/script/avrexport/avrmail.php as shown below:

 

# grep -n -B 4 Timeout /var/ts/dms/script/avrexport/avrmail.php

242-// set up mailer

243-$mail = new PHPMailer(true);

244-$mail->IsSMTP();

245-$mail->SMTPDebug = SMTP_DEBUG_LEVEL;

246:$mail->Timeout = 15; <------------- Increased the value to 30
