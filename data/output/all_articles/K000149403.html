K000149403: if-index between BIG-IP and BigIQ may not match

Type
Support Solution
Published
2025-02-04
Updated
2025-02-04
Source
https://my.f5.com/manage/s/article/K000149403

Description

When you push a config from BigIQ to a BIG-IP system, you may notice the if-index numbers do not match.

Environment

BigIQ

Cause

The if-index can update from any reboot or system upgrade. This does not affect anything functional, and is not stored in the bigip.conf. This is cosmetic, and can be ignored.

Example: VLAN if-index on BIG-IP could be 242 and VLAN if-index on BigIQ shows 240 (it can be any number) there is no practical difference. There is no manual setting for the if-index number. There is no expectation of consistency for these values

Recommended Actions

None, this is cosmetic only

Additional Information

if-index:

Displays the index assigned to this VLAN. It is a unique identifier assigned for all objects displayed in

the SNMP IF-MIB.

if-index is administrative, not functional, so there is no requirement to match. It just reflects that the elements were created in a different order between the members, and data can be accessed via different if-indexes using SNMP.
