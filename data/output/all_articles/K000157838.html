K000157838: Password hash values is different between HA BIG-IP devices

Applies to

Description

Password hash values for RADIUS server secrets and monitor credentials are different between the HA peer configuration files. 

Environment

  • BIG-IP LTM, version 17.1.2
  • High Availability (HA) cluster with Active and Standby tenants
  • RADIUS authentication servers and HTTPS monitors configured with encrypted secrets

Cause

The observed difference in encrypted password hash values is expected behavior due to the Secure Vault encryption mechanism in BIG-IP. Each device encrypts passphrases independently, resulting in different hash values even when the underlying secret is the same. This does not impact configuration synchronization or system functionality.

Recommended Actions

No action required; the differing encrypted hash values are normal and do not indicate a configuration sync issue.
