Description

 "Client Proxy Address" field in the Network Access Policy section (under Network Settings and Advanced Client Settings) cannot be configured a dns entry.

 It is possible to configure a single IP address as Client Proxy Address.

 We made RFE below, but it is not possible to configure a DNS entry as Client Proxy Address.

ID417897 Allow \"Client Proxy Address\" field value to be stored as a hostname or FQDN.

Environment

BIG-IP APM

Cause

This is by design.

None
