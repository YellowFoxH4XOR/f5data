Description

Connection refused when testing AS3 connectivity:

curl -kv -u admin https://1.2.3.4/mgmt/shared/appsvcs/info

curl: (7) Failed to connect to 1.2.3.4 port 443: Connection refused

 

Environment

BIG-IP VE LTM

BIG-IP AS3

AWS

Highly likely other cloud providers too

Cause

In BIG-IP VE 13.0 and later, BIG-IP VE sets the Configuration utility port to 8443 (instead of 443).

Recommended Actions

Use port 8443 instead of the typical 443.

Example:

curl -kv -u admin https://1.2.3.4:8443/mgmt/shared/appsvcs/info

<SKIP>

* Connection #0 to host 1.2.3.4 left intact

{"version":"3.50.2","release":"3","schemaCurrent":"3.50.0","schemaMinimum":"3.0.0"}

 

NOTE: This shows correct connectivity using BIG-IP AS3.
