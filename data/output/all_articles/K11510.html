Known Issue

The BIG-IP APM default DNS search domain is localhost.com, which is a public domain. Therefore, if an administrator does not remove the default search domain, the web application engine can apply the default search domain to resolve short hostnames. As a result, a shorthostname query may be associated with the localhost.com domain and resolve to a public/external IP.

F5 Product Development tracked this issue as CR129207 and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP APM release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
