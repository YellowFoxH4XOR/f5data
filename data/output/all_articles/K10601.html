Known Issue

This is the result of a known issue. If you upgrade a BIG-IP system to version 9.4.0 through 10.2.4, from versions 9.0.0 through 9.3.1, and the configuration includes Virtual Local Area Network (VLAN) group proxy excludes, the proxy excludes will be incorrectly converted, and the upgraded system will fail to load the converted configuration. When this behavior occurs, the BIG-IP system displays an error message that appears similar to the following example:

BIGpipe parsing error (Line 15):
012e0022:3: The requested value (192.168.1.1) is invalid (show | (<ip addr list> | none) [add | delete]) for 'proxy excludes' in 'vlangroup'

Note: The IP address displayed in the error message is the IP address intended to be excluded.

For example, configurations for versions 9.4.0 and earlier may include a VLAN group definition that includes a proxy exclusion.

For example:

vlangroup proxy exclude 192.168.1.1
vlangroup mygroup {
tag 4092
member external internal
}

Upon upgrade, the script converts the VLAN group definition to appear similar to the following example:

vlangroup mygroup {
tag 4092
members
external
internal
proxy excludes 192.168.1.1
}

However, the VLAN group and proxy exclude definitions should appear similar to the following example:

vlangroup all proxy exclude 192.168.1.1
vlangroup mygroup {
tag 4092
member external internal
}

Note: The syntax is almost identical to the syntax for versions 9.4.0 and earlier, with the addition of the VLAN group name to which the exclude applies. Specifying the all VLAN group name replicates the versions 9.4.0 and earlier behavior.

F5 Product Development is tracked this issue as ID 251407 (formerly CR96708).

Workaround

You can work around this issue by manually editing the bigip_base.conf configuration file after upgrading to incorporate the correct syntax. To do so, perform the following procedure after upgrading:

  1. Log in to the BIG-IP command line.
  2. Back up the bigip_base.conf file by typing the following command:

    cp /config/bigip_base.conf /config/bigip_base.conf.SOL10601
  3. Open the /config/bigip_base.conf file in a text editor.
  4. Locate the stanza defining the VLAN group.
  5. Modify the VLAN group definition to match the correct syntax, as demonstrated in the previous example.
  6. If your system is a redundant pair, repeat the procedure on the peer unit.
