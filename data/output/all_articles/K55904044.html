Topic

You should consider using these procedures under the following condition:

  • You want to configure the BIG-IP system to mirror SSL session cache data to peer device group members.

Description

SSL session resumption allows a client and server to reuse previously negotiated SSL parameters. The ability to cache and reuse SSL session data (session IDs) can increase the transactions per second (TPS) by limiting processor-intensive SSL key exchange functions. You can configure the BIG-IP system to mirror SSL session data to peer device group members. When you enable SSL session mirroring in the SSL profile, the BIG-IP system mirrors SSL session ID data to the appropriate device group member. This preserves SSL session resumption when failover occurs.

Note: SSL session cache mirroring is distinct from SSL connection mirroring. When you enable SSL connection mirroring, the BIG-IP system mirrors SSL connections that are terminated by the BIG-IP system to peer device group members. For information about SSL connection mirroring, refer to K17391: Configuring SSL connection mirroring for Client SSL virtual servers.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have access to the TMOS Shell (tmsh).
  • You have configured a virtual server that references an SSL profile.

Procedures

  • Enable the statemirror.secure database variable
  • Configure session mirroring for the SSL profile
  • Perform a ConfigSync
  • View SSL session mirroring statistics

Enable the statemirror.secure database variable

Before you enable session mirroring for an SSL profile, you must enable the statemirror.secure database variable. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To enable the statemirror.secure database variable, enter the following command:

    modify /sys db statemirror.secure value enable

Configure session mirroring for the SSL profile

You can configure SSL session mirroring for the SSL profile using the Configuration utility or tmsh. To do so, perform one of the following procedures:

  • Configuration utility
  • tmsh

Impact of procedure: Performing the following procedures should not have a negative impact on your system.

Configuration utility

  1. Log in to the Configuration utility.
  2. Go to the appropriate SSL profile:
    • For Client SSL profiles, go to Local Traffic > Profiles > SSL > Client.
    • For Server SSL profiles, go to Local Traffic > Profiles > SSL > Server.
  3. Select the name of the appropriate SSL profile.
  4. For Configuration, select Advanced.
  5. Select the Session Mirroring check box.
  6. Select Update.

tmsh

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To configure session mirroring for the SSL profile, use the following command syntax:

    modify /ltm profile <ssl_profile_type> <profile_name> session-mirroring enabled

    For example, the following command enables session mirroring for the Client SSL profile named MyclientSSL:

    modify /ltm profile client-ssl MyclientSSL session-mirroring enabled

  3. Save the change by entering the following command:

    save /sys config

Perform a ConfigSync

After you enable both the statemirror.secure database variable and the session mirroring setting on your SSL profile, you must synchronize the changes to other devices in the device group. To do so, perform the procedure in one of the following articles:

Note: If your device group sync type is Automatic, you can skip manual ConfigSync.

  • K13920: Performing a ConfigSync using the Configuration utility
  • K14856: Performing a ConfigSync using tmsh

View SSL session mirroring statistics

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To view SSL profile statistics on the active system, including SSL session mirroring statistics, use the following command syntax:

    show /ltm profile <ssl_profile_type> <profile_name>

    For example, the following command displays SSL profile statistics, including SSL session mirroring statistics, for the MyclientSSL profile:

    show /ltm profile client-ssl MyclientSSL
