Description

On client-ssl profile, when client certificate request mode is set to "request" and static CRL file is configured, following error may be written on /var/log/ltm log file while client accesses to virtual server with client certificate.

Mar  7 14:51:58 bigip.local warning tmm[11686]: 01260003:4: Certificate with serial 0186A0 revoked per CRL from issuer /C=JP/ST=Tokyo/O=F5SS/OU=LAB/CN=ubuntu2004server1ca.f5ss.local

 

If client certificate request mode is set to "require", SSL handshake may be terminated with additional errors such as "Peer cert verify error: certificate revoked".

Mar  7 14:57:40 bigip.local warning tmm2[11686]: 01260003:4: Certificate with serial 0186A0 revoked per CRL from issuer /C=JP/ST=Tokyo/O=F5SS/OU=LAB/CN=ubuntu2004server1ca.f5ss.local
Mar  7 14:57:40 bigip.local warning tmm2[11686]: 01260006:4: Peer cert verify error: certificate revoked (depth 0; cert /C=JP/ST=Kanagawa/L=Yokohama/O=F5SS/OU=LAB/CN=client100000.f5ss.local)
Mar  7 14:57:40 bigip.local warning tmm2[11686]: 01260009:4: 10.1.1.70:54682 -> 10.1.1.146:443: Connection error: ssl_shim_vfycerterr:4466: alert(44) certificate revoked
Mar  7 14:57:40 bigip.local warning tmm2[11686]: 01260013:4: SSL Handshake failed for TCP 10.1.1.70:54682 -> 10.1.1.146:443

 

Environment

  • client-ssl profile with "CRL File"
  • client-ssl profile with "Client Certificate" option either "request" or "require".
  • client submits revoked client certificate while accessing to virtual server with the client-ssl profile.

Figure: client-ssl profile settings

 

Cause

Client accesses to virtual server with revoked certificate.

 

Recommended Actions

Check if client certificate is revoked. You can use openssl command to verify client certificate file against CRL file.
In the following example, "client100000.crt" certificate is revoked but "validclient1.crt" is not revoked. 

$ ls -l *{crt,crl}
-rw-r--r-- 1 root root     1212 Mar 12 10:40 client100000.crt						: this is revoked client certificate
-rw-r--r-- 1 root root 29746275 Mar 12 10:40 ubuntu2004server1ca.f5ss.local.crl		: CRL file
-rw-r--r-- 1 root root     4706 Mar 12 10:40 ubuntu2004server1ca.f5ss.local.crt		: CA certificate
-rw-r--r-- 1 root root     1212 Mar 12 10:43 validclient1.crt						: this is valid (not revoked) client certificate
$
$ openssl x509 -in client100000.crt -serial -noout
serial=0186A0
$ openssl x509 -in validclient1.crt -serial -noout
serial=98967F
$
$ openssl verify -crl_check -CAfile ubuntu2004server1ca.f5ss.local.crt -CRLfile ubuntu2004server1ca.f5ss.local.crl client100000.crt
C = JP, ST = Kanagawa, L = Yokohama, O = F5SS, OU = LAB, CN = client100000.f5ss.local
error 23 at 0 depth lookup: certificate revoked
error client100000.crt: verification failed
$
$
$ openssl verify -crl_check -CAfile ubuntu2004server1ca.f5ss.local.crt -CRLfile ubuntu2004server1ca.f5ss.local.crl validclient1.crt
validclient1.crt: OK
$
