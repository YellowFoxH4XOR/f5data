Description

After rebooting BIG-IP device, loss of management connectivity may occur.  Symptoms include inability to access the system via SSH or GUI, management IP is not assigned via DHCP and commands such as tmsh show sys management-ip  returning no output or 192.168.1.245/24

Log messages may include:

/var/log/boot.log
   err dhcp_config[<err id>]: save error: 01070734:3: Configuration error: invalid Management Route, the dest/netmask pair <ip address>/<mask> already exists for /Common/<route name>
   err NET[<err id>]: dhclient: dhcp-config failed with rc=<1> 

Environment

  • Product: BIG-IP LTM
  • Management interface configured for DHCP
  • Static management route present in configuration

Cause

A static management route in the BIG-IP configuration conflicts with a route provided by the DHCP server. This overlap causes a configuration error during DHCP processing, preventing the management IP and route from being applied, resulting in loss of management access.

Recommended Actions

To resolve the issue:

  1. Remove the conflicting static management route from the BIG-IP configuration:
    • tmsh delete sys management-route <route name>
  2. Release and renew the DHCP lease for the management interface:
    • dhclient -r mgmt && dhclient mgmt
  3. Verify that the management IP and route are correctly assigned:
    • tmsh list sys management-ip
    • tmsh list sys management-route
  4. Prevent future conflicts by ensuring that static management routes do not overlap with routes provided by DHCP.

Another option to resolve this is by changing to static management IP and route.

Note: Changing the management route and IP needs to be performed using the Serial Console in the AZURE Portal to avoid loss of connectivity. 

       1. Change Management IP to specific IP address:
      tmsh create /sys management-ip 192.168.1.245/24
       2. Set specific default management route:
      tmsh create /sys management-route default gateway 192.168.1.254
       3. Verify that the management IP and route are correct:
      tmsh list /sys management-ip
      tmsh list /sys management-route
       4. Save changes to disk:
      tmsh save /sys config partitions all
