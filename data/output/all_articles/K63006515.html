Description

   There are several iApp RPM files under /var/config/rest directory.
   However unit has not configured with iApp.

Environment

  • LTM
  • Advanced WAF/ASM

Cause

   Guided configuration from GUI automatically download iApp template RPM files.

Recommended Actions

   As long as iApp has not deployed, user can remove those RPM files.

Additional Information

   Here is a command example to remove unnecessary RPM files.

   # cd  /var/config/rest/downloads
   # rm f5-iappslx-access-adfs-2.0.0-0.0.882.noarch.rpm
   # rm f5-iappslx-access-api-protection-1.1.0-0.0.882.noarch.rpm
