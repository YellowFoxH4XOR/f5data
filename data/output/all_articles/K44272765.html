Issue

Error Message

notice tmm[<PID>]: 01340009:5: HA reconnect with peer <peer info> for traffic-group <name> postponed.

In this error message, note the following:

  • <PID> is the process ID for the tmm process
  • <address> is the IP address and port of the peer system
  • <name> is the name and partition of the traffic group

For example:

notice tmm[15874]: 01340009:5: HA reconnect with peer 192.168.10.10:1029 for traffic-group /Common/traffic-group-1 postponed.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • You configure peer BIG-IP systems for high availability (HA).
  • The connection for HA communication between peer systems fails and the peer system reschedules the reconnection attempt.

Impact

There is no impact; this message is a notification.  

Recommended Actions

Rare occurrences of this message may indicate an intermittent or inconsequential issue. Multiple reoccurring messages may indicate a more serious issue or misconfiguration. Check to ensure the network resources used for HA are configured correctly and the peer systems are able to communicate. For more information, refer to K14135: Defining network resources for BIG-IP high-availability features (11.x - 12.x).
