Description

Unable to login in WebGUI with a 'Waiting for BIG-IQ services to become available' error message

Environment

  • BIG-IQ running v7.x
  • restarted service like tomcat, httpd, webd and guiserver but still unable to get the login page
  • The affected CM is a secondary unit

Cause

  • Failing to connect to postgres with error.

  • [ERROR] postgresql: Failed connecting to dbConnectUrl:postgres://postgres_replication@[localhost]:<REDACTED>postgres://postgres_replication@[localhost]:5432/bigiq_db - Error: The server does not support SSL connections

Recommended Actions

  1. Check the connection of tcp port 5432 between the primary and secondary. 
  2. Apply workaround on the secondary:

    # rm -f /var/lib/pgsql/config/server.*
    # clear-rest-storage
