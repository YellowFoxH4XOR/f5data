Known Issue

The Traffic Management Microkernel (TMM) process may restart when tmsh commands that display the connection table or persistence table are interrupted. This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is processing large quantities of active connections or persistence records.
  • You attempt to display the connection table using the tmsh show sys connection command or the persistence table using the tmsh show ltm persistence persist-records command.
  • You then attempt to cancel the tmsh show sys connection command or tmsh show ltm persistence persist-records command by using the Ctrl+C key sequence while either command is still in the process of displaying the data.

Impact

The BIG-IP system may temporarily fail to process traffic, and fail over if configured as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H459482 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP system fails to process traffic while the TMM process restarts.

Workaround

There is no work around for this issue. However, you can prevent this issue from occurring by waiting for the tmsh show sys connection command or tmsh show ltm persistence persist-records command to complete the process of displaying the data.
