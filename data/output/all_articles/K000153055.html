K000153055: Non-admin BIG-IQ users with custom roles/permissions are unable to view certificates and keys from web UI or through iControl REST API

Type
Support Solution
Published
2025-08-19
Updated
2025-08-19
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.0
Source
https://my.f5.com/manage/s/article/K000153055

Description

 

Non-admin users with custom roles/permissions are unable to view SSL certificates and keys in BIG-IQ 8.4.0 using the web UI or when using iControl REST API. When the affected user navigates through Configuration > LOCAL TRAFFIC > Certificate Management > Certificates & Keys, no certificates are shown even if the user is allowed to access the resources.

With iControl REST API, this can manifest as an empty result list similar to the following even if there are supposed to be certs/keys that should be visible:

# curl -su 'f5testuser' http://localhost:8100/mgmt/cm/adc-core/working-config/sys/file/ssl-cert | jq .
Enter host password for user 'f5testuser':
{
  "items": [],
  "generation": 2,
  "lastUpdateMicros": 1755557580126930,
  "kind": "cm:adc-core:working-config:sys:file:ssl-cert:adcsslcertcollectionstate",
  "selfLink": "https://localhost/mgmt/cm/adc-core/working-config/sys/file/ssl-cert"
}

Environment

  • BIG-IQ

 

Cause

 

  • Bug ID1935917.

 

Recommended Actions

 

  • Install an Engineering Hotfix (EHF) containing the fix for bug ID1935917 for v8.4.0.

 

Additional Information

None.
