Description

How to allow only specific countries (like Saudi Arabia) access based on the Geolocation for a specific URL.

Environment

  • ASM
  • Advanced WAF (AWAF)
  • Geolocation
  • IRule

Cause

Geolocation configuration on AWAF is applied to the whole policy which included all allowed URLs.

Recommended Actions

Here is the Proof of concept irule:

when HTTP_REQUEST {
    if { [string tolower [HTTP::uri]] starts_with "/abc" && [whereis [IP::client_addr] country] ne "SA" } {
        drop
    }
}

Note: You need modify the above iRule according to your need and test it before apply to the production environment

For more help in iRules, check iRules Home on F5 Cloud Docs.
