Known Issue

The Traffic Management Microkernel (TMM) process may restart and produce a core file.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system has a virtual server with the following configurations:

    • A pool
    • An SPDY profile
    • A compression profile
    • An iRule with the LB_FAILED event
  • The associated pool is down.
  • An error occurred in the LB_FAILED event of the associated iRule.

Impact

If the BIG-IP system is a standalone system, traffic will be disrupted while the TMM process is restarted. If the BIG-IP system is the active member of a high availability (HA) system, the restart will trigger a failover.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Traffic processing is disrupted on a standalone BIG-IP system.
  • Failover occurs on the BIG-IP system if the active member is part of an HA system.
  • The BIG-IP system generates a TMM core file to the /shared/core/ directory.
