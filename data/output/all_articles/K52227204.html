Description

  • Configuration utility restarts when running a large APM report or exporting report results
  • /var/log/tomcat/catalina.out has log messages containing string "java.lang.OutOfMemoryError"

Environment

  • BIG-IP APM
  • Reporting or exporting large reports

Cause

The tomcat process requires additional Java virtual memory.

Recommended Actions

Use the provision.tomcat.extramb database variable to increase the maximum amount of Java virtual memory available to the tomcat process. To do so, refer to K9719: Error Message: java.lang.OutOfMemoryError
