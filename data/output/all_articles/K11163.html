Topic

F5 is archiving many of our Deployment Guides as of 7/31/2020.

Description

Deployment guides archival

F5 is archiving many of our Deployment Guides as of 7/31/2020. In order to ease the configuration of F5 devices with different applications and protocols, F5 has introduced F5 Application Services Templates (FAST). FAST templates are the replacement for TCL-based iApp templates which used Deployment Guides as a blueprint. For more information, refer to K13422: F5-supported and F5-contributed iApp templates

While not all Deployment Guides are being archived, this archival is not limited to iApp-based Deployment guides.

Important notes:
  • Each of the deployment guides that has been archived has a message on the first page stating it has been archived.  
  • If a Deployment Guide does not include the archive message, it should still be considered valid for the products and versions it references.
  • The content in the archived deployment guides is still valid for the products and versions listed in the document.
  • The deployment guides will no longer be updated and may refer to F5 or third party products or versions that have reached end-of-life or end-of-support.
  • Many deployment guides refer to iApp templates that have been deprecated. For more information on iApp template deprecation, refer to K13422: F5-supported and F5-contributed iApp templates
  • You can find the archived deployment guides at Deployment Guide Archive .
  • After the archival occurs, the Deployment Guide index page will only contain the non-archived Deployment Guides.
