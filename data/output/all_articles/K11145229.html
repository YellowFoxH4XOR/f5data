Topic

Installing F5 VPN and endpoint inspector browser components on Linux clients requires Qt library libqt5core5a 5.5 or later.

Description

The first time a remote user starts network access, the BIG-IP Edge Client downloads a client component. This client component is self-installing and self-configuring, but the user must use Firefox to install the plugin on Linux systems. If the browser does not support this requirement to download the client component, the BIG-IP APM system prompts the user to download the controller client component from the controller and install it manually.

Beginning with BIG-IP 13.0.0, you can directly download the following Linux browser component packages from the BIG-IP APM system:

  • F5 Endpoint Inspector for Linux ( linux_f5epi.i386.deb )
  • F5 Endpoint Inspector for Linux ( linux_f5epi.i386.rpm )
  • F5 Endpoint Inspector for Linux ( linux_f5epi.x86_64.deb )
  • F5 Endpoint Inspector for Linux ( linux_f5epi.x86_64.rpm )
  • F5 VPN for Linux ( linux_f5vpn.i386.deb )
  • F5 VPN for Linux ( linux_f5vpn.i386.rpm )
  • F5 VPN for Linux ( linux_f5vpn.x86_64.deb )
  • F5 VPN for Linux ( linux_f5vpn.x86_64.rpm ) 

For more information about installing clients on Linux clients, refer to the Client for Linux chapter of the BIG-IP Access Policy Manager: Edge Client and Application Configuration manual.

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Recommendations

When you install the browser component packages, consider the following factors:

  • Before you install browser component packages, your system must have the Qt library libqt5core5a 5.5 or later installed.  For some Linux distributions where the libqt5core5a 5.5 and later versions are not available in the standard repositories, you can perform the following steps:
    1. Download and install the required Qt library from the non-standard repository.
    2. Build and install the required Qt library on the distribution.
  • To successfully install the network access client, the remote user must have superuser authority or be able to supply an administrative password.
