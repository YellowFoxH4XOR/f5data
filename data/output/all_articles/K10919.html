Topic

Note: BIG-IP WebAccelerator and BIG-IP WOM were combined to create BIG-IP AAM in 11.4.0.

BIG-IP WebAccelerator, or Application Acceleration Manager (AAM), uses the X-Client HTTP header for internal operations and to announce its presence to upstream BIG-IP ASM devices or WAM devices in a symmetric deployment. The header is not removed before the request leaves the BIG-IP WebAccelerator system.

If the BIG-IP WebAccelerator system processes a request containing an X-Client: WA header, the system returns compressed content in the response regardless of whether the HTTP request header is specified by the client. This issue can occur in rare deployment scenarios, such as when two BIG-IP WebAccelerator systems are installed in-line, but not in a symmetric configuration.

Note: For more information, refer to K8658: The BIG-IP WebAccelerator does not remove all internal HTTP headers.
