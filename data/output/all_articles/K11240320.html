K11240320: Interfaces reported as uninitialized after upgrading a BIGIP VE where a K74921042 workaround was previously applied

Description

After upgrading (to a fixed version), the TMM interfaces on a BIG-IP VE hosted in  VMware ESXi 6.7 host Update 2 shows as uninitialized.

#tmsh show net interface

    ----------------------------------------------------------------
    Net::Interface
    Name  Status   Bits    Bits   Pkts   Pkts  Drops  Errs     Media
                     In     Out     In    Out
    ----------------------------------------------------------------
    1.1   uninit      0       0      0      0      0     0      none   
    1.2   uninit      0       0      0      0      0     0      none   
    1.3   uninit      0       0      0      0      0     0      none   
    mgmt      up  12.1M  275.3M  17.4K  30.4K      0     0  100TX-FD

Environment

  • BIG-IP VE
  • VMware ESXi 6.7 host Update 2
  • You upgraded your BIG-IP Virtual Edition (VE) to a version where ID774445 is fixed and K74921042 is no longer needed

Cause

You applied the K74921042 workaround previously (usage of SOCK driver for BIG-IP 14.1.0 and later or UNIC driver for BIG-IP 13.1.0 through 14.0.0)

Recommended Actions

  1. Log in to the BIG-IP command line.
  2. (Optional) Take a backup of /config/tmm_init.tcl file:

    cp /config/tmm_init.tcl /var/tmp/

  3. Remove or delete the said file by entering following command:

    rm  /config/tmm_init.tcl

  4. Restart TMM to reload the driver by entering the following command:

    bigstart restart tmm
