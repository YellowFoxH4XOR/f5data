Description

Restore some BIG-IP configuration objects from a UCS backup without installing the entire archive

Environment

  • BIG-IP
  • UCS Archive

Cause

There are several reasons you want to restore individual configuration objects from a UCS archive. Common use cases include:
  • Accidental deletion or modification of a configuration object
  • Replication of configuration objects from another device

Recommended Actions

  1. If an error is made in later steps, it is possible to cause issues with your configuration. Back up your currently running configuration prior to attempting merge of new configuration objects. Note: Refer to K13132 for steps on backing up your configuration using a UCS archive.
  2. Extract the desired configuration file from the UCS archive.  Note: Refer to K4423 for steps on how to extract files from your UCS archive. If your UCS is encrypted, refer to K8465 instead.
  3. From the extracted configuration file, copy the complete stanza of the objects you wish to add to your running configuration. If you have only a few objects to move, you may paste them directly into the console in the next step. If you are restoring many objects, you may also paste them into a simple text document for ease of installation. If pasting configuration elements into text document, take care that no additional formatting is inserted by your text editor. Consider using simple text editors like Vi or Notepad that do not perform text formatting.
  4. Merge the configuration you wish to restore with the running configuration using load sys config merge, either by pasting your configuration into the terminal or by merging the configuration from a text file. Note: Refer to K81271448 for steps on using 'load sys config merge' to add objects to your running configuration.
