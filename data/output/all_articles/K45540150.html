Description

When navigating through the GUI, you suddenly receive the message "Unable to contact BIG-IP device".

Environment

  • BIG-IP

  • GUI

  • Network

Cause

There are too many connections to the BIG-IP management IP (GUI).

Recommended Actions

  1. Review the connection table using netstat command
    # netstat -pan | grep <mgmt IP addresss>

    For example:
