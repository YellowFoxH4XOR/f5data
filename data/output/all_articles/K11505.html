Issue

Error Message

err snmpd[<PID>]: send response:

In this error message, note the following:

  • <PID> is the process ID for the snmpd service

This is the result of cosmetic bug in the net-snmpd package; the BIG-IP snmp daemon may log numerous 'send response' error messages when no error has occurred.

The error messages may appear similar to the following example:

err snmpd[3222]: send response:
err snmpd[3222]:     -- F5-BIGIP-SYSTEM-MIB::sysSystemUptime.0
err snmpd[3222]: send response:
err snmpd[3222]:     -- F5-BIGIP-SYSTEM-MIB::sysInterfaceStatus."1.4"
err snmpd[3222]: send response:
err snmpd[3222]:     -- F5-BIGIP-SYSTEM-MIB::sysInterfaceStatus."1.3"

Message Location

You may encounter these messages in the following location:

  • The /var/log/daemon.log file

Description

This message occurs when the following condition is met:

  • You access the BIG-IP system management information base (MIB) via SNMP.

Impact

These log messages are benign, and you can safely ignore them.

Recommended Actions

None
