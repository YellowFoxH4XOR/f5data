Known Issue

Deleting a Name Authority Pointer (NAPTR) resource record may cause Domain Name Service (DNS) query failures for wildcard NAPTR records.

This issue occurs when all of the following conditions are met:

  • You have configured DNS Express to answer DNS queries.
  • You use the ZoneRunner utility to perform the following operations:
    • Create a zone with one or more NAPTR resource records.
    • Add a wildcard NAPTR resource record.
    • Delete one of the initial (non-wildcard) NAPTR resource records.

Impact

DNS queries for wildcard NAPTR resource record fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice DNS queries failing for a wildcard NAPTR resource record after deleting a different NAPTR resource record in the zone.
  • DNS queries for wildcard NAPTR resource records are failing, although the resource record still exists in the DNS Express database.
