K07004933: HTTP content does not load properly when ''Page Load Time'' is enabled in Analytics profile

Type
Support Solution
Published
2021-12-23
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP Analytics: 14.1.2
  • BIG-IP LTM: 14.1.2
Source
https://my.f5.com/manage/s/article/K07004933

Description

The content of the page doesn't load when the analytics profile is assigned to a virtual server.??????

Environment
  • AVR provisioned 
  • Virtual server with analytics profile
  • Page Load Time Enable

Cause

When Page Load Time is enabled, it inserts a JavaScript to HTML, to find out the time the content takes to respond, some browsers are not compatible with those JavaScript, which causes that the page doesn't load the content from HTML.

Recommended Actions

Disable Page Load Time
Local Traffic ›› Profiles : Analytics : HTTP Analytics ›› "Your profile"  > Collected Metrics > Page Load Time

Additional Information

None.
