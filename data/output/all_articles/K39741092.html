Topic

You should consider using this procedure under the following condition:

  • You want to upgrade or install the representational state transfer (REST) framework on the multi-blade VIPRION or Virtual Clustered Multiprocessing (vCMP) system before you use the BIG-IQ system to discover and manage the devices.

Description

The BIG-IQ and BIG-IP systems use the REST framework to exchange configuration and statistical data. Device discovery for the multi-blade VIPRION or vCMP system requires that the REST framework that is installed on these systems is compatible with the version of the REST framework on the BIG-IQ system. If the frameworks are not compatible, the device discovery process will fail. To avoid discovery failure, you can manually upgrade the REST framework before you perform device discovery.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • The VIPRION system is configured with more than one blade, or you intend for the BIG-IQ system to discover and manage a vCMP system.
  • The VIPRION or vCMP system is running on BIG-IP 11.5.x or 11.6.x.

    Note: BIG-IP systems running 12.x or later are not suitable for this procedure. The device discovery process for BIG-IP 12.x automatically installs the compatible REST framework to the system if the system detects missing components during the device discovery process.

  • The BIG-IQ system manages only compatible BIG-IP versions. For more information about the compatibility matrix between the two systems, refer to: K34133507: BIG-IQ Centralized Management compatibility matrix.

    Important: If you perform the procedure in this article using incompatible versions, the restjavad service may become stuck in a restart loop.

  • You have administrator credential access to the BIG-IQ and BIG-IP systems.
  • You have Advanced Shell (bash) access to the BIG-IQ and the BIG-IP systems.

Procedures

  • Check the existing version of the installed REST framework
  • Manually upgrade the REST framework

Check the existing version of the installed REST framework 

Impact of procedure: Performing the following procedure may cause services related to the REST framework to restart. F5 recommends that you perform this procedure during a scheduled maintenance period.

  1. Log in to the BIG-IP system command-line prompt.
  2. Perform an RPM query using the following command:

    rpm -qa | grep f5-rest-java-libs

    The command output may show the following list of installed REST framework packages:

    f5-rest-java-libs-mam-11.5.4-0.0.256
    f5-rest-java-libs-11.5.4-0.0.256
    f5-rest-java-libs-indexing-11.5.4-0.0.256
    f5-rest-java-libs-adc-11.5.4-0.0.256

    Optional: To perform the RPM query across all slots on a VIPRION system, you can use the following command syntax:

    for i in {1..<LASTSLOT>}; do echo "slot$i"; ssh slot$i 'rpm -qa | grep f5-rest-java-libs'; done

    For example, to query on a VIPRION with 4 slots, type the following command:

    for i in {1..4}; do echo "slot$i"; ssh slot$i 'rpm -qa | grep f5-rest-java-libs'; done

  3. Log in to the BIG-IQ system command-line prompt.
  4. Change directories to the BIG-IQ REST framework packages directory, by typing the following command:

    cd /usr/lib/dco/packages/upd-adc

  5. List the directory for file starting with f5-rest-*, by typing the following command:

    ls -w 15 f5-rest*

    The command output may show the following list of REST framework packages installed:

    f5-rest-auth-lib-12.0.0-0.0.4101.i686.rpm
    f5-rest-java-host-12.0.0-0.0.4101.i686.rpm
    f5-rest-java-libs-12.0.0-0.0.4101.i686.rpm
    f5-rest-java-libs-adc-12.0.0-0.0.4101.i686.rpm
    f5-rest-java-libs-indexing-12.0.0-0.0.4101.i686.rpm
    f5-rest-mcp-schema-12.0.0-0.0.4101.i686.rpm
    f5-rest-prepare-framework-update-12.0.0-0.0.4101.i686.rpm
    f5-rest-presentation-libs-12.0.0-0.0.4101.i686.rpm

  6. To evaluate if the REST framework requires an update, compare the results from step 2 and step 5. The bold text on the filenames and RPM package names denotes the REST framework base version number in each of the systems. When the BIG-IQ system detects an earlier version of the BIG-IP system, the BIG-IQ system attempts to upgrade the REST framework of the BIG-IP system.

Manually upgrade the REST framework

To manually upgrade the REST framework on the guest slots on the vCMP system, perform the following procedure:

Impact of procedure: Performing the following procedure may cause restjavad and some related services on the BIG-IP system to restart. F5 recommends that you perform this procedure during a scheduled maintenance period.

  1. Log in to the BIG-IQ system command line as the root user.
  2. Optional: If you already have established secure shell (SSH) trust between the BIG-IQ system and the managed BIG-IP devices, you can proceed to step 3. If you have not yet established the SSH trust, use the following command syntax to establish the SSH trust:

    ssh-copy-id -i ~/.ssh/identity.pub root@<BIG-IP Management IP Address>

    For example:

    ssh-copy-id -i ~/.ssh/identity.pub root@10.10.10.100

    Note: If you do not establish trust, the system will require that you provide the BIG-IP system's root password multiple times when you use the update_bigip.sh script.

  3. Change directories to the folder where the required files reside, by typing the following command:

    cd /usr/lib/dco/packages/upd-adc

  4. Run the installation script on each slot's management IP address, using the following command syntax:

    ./update_bigip.sh -a admin -p <password> <BIG-IP Management IP Address>

    In the previous syntax, note the following:

    • <password> is the password of the default administrator account for the BIG-IP device.

    For example:

    ./update_bigip.sh -a admin -p adminpassword 10.10.10.100

  5. Repeat step 4 on all of the installed slots on the VIPRION chassis or the vCMP guest instance.
  6. Optional: Validate that the system has upgraded the BIG-IP device's REST framework; you can do so by repeating the steps in the previous procedure: Check the existing version of the installed REST framework.
  7. When the REST framework of all of the BIG-IP devices have been upgraded, you can perform the BIG-IQ device discovery process, and when prompted, select Yes, skip software framework upgrade and continue.

    For more information on the device discovery process, refer to the Device Discovery and Basic Device Management chapter in the BIG-IQ Centralized Management: Device guide.
