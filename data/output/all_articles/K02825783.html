K02825783: GTM Wide IP cannot be created as disabled with Ansible collections

Description

When running an Ansible Playbook to create a disabled WideIP, the WideIP is created but with Enabled status.

Environment

  • BIG-IP DNS.
  • Using Ansible F5_Modules Collection v1.14.0 and v1.13.0.

Cause

Bug ID 1073533 

Recommended Actions

  • You can run the playbook twice as the workaround.

Additional Information

In the following playbook example, the WideIP is created with status disabled:

- name: Create a Wideip
hosts: localhost
vars:
provider:
password: admin
server: <mgmt IP>
user: admin
validate_certs: no
server_port: 443
collections:
- f5networks.f5_modules

tasks:

- name: create gtm A record
bigip_gtm_wide_ip:
provider: "{{ provider }}"
pool_lb_method: round-robin
name: <WIDEIP NAME>
type: a
state: disabled --------------------> !!!
delegate_to: localhost

After running the playbook, the wideip is created on BIG-IP, but its status is enabled.
