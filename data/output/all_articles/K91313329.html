Description

You have run a scan against your BIG-IP and determined that it is vulnerable to:

HTTP Public-Key-Pins Security Header Not Detected

Environment

  • Security scan
  • Virtual server
  • HTTP

Cause

Public-Key-Pins HTTP header is not returned by the application.

Recommended Actions

HTTP Public Key Pinning (HPKP) is a deprecated security mechanism which was delivered via an HTTP header to protect websites from impersonation.

Modern browser versions no longer support this feature, so applications should not use it. Applications returning a HPKP header to the client may generate connection errors.

BIG-IP never implemented support for HTTP Public Key Pinning, and it isn't recommended to generate this header via an iRule or policy, as it brings little to no security benefit for the application.
