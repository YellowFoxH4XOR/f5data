K000133079: How to open a Support case for a BIG-IP VE licensed by FCP

Type
Support Solution
Published
2023-03-20
Updated
2025-03-04
Applies to
  • BIG-IQ
Source

Description

You are using F5 Flexible Consumption Program (FCP) licenses that are deployed via BIG-IQ and need to open an F5 support case for one of the remote BIG-IPs.

Environment

  • FCP
  • BIG-IP licensed by BIG-IQ
  • Need to open a support case with F5

Cause

In perpetual or subscription licensing programs, each BIG-IP device receives its own unique base license key and in turn, its own serial number.

Whereas, the FCP uses catalog (CAT) license keys which allow a BIG-IQ License Manager to apply or revoke BIG-IP licenses.

Though the remote BIG-IP shows a unique base registration key via tmsh show sys license, the CAT license key from the BIG-IQ is the one necessary to open a support case. 

The base registration key is five blocks of characters and the last block of seven is the serial number XXXX-XXXX-XXXX-XXXX-ABCDEFG.

 Recommended Actions

Find the relevant base registration key for this BIG-IP either from the BIG-IQ or the subscriptions information available from the customer portal at my.f5.com.

If you have access to the BIG-IQ:

  1. Log into BIG-IQ.
  2. Select devices tab.
  3. On the left panel, expand License Management.
  4. Select Assignments and find the relevant BIG-IP.
  5. In the Name column, click the CAT key link for that BIG-IP.
  6. Within this properties screen, note the Base Reg Key. The serial number is the last block of 7 characters of this base registration key, XXXX-XXXX-XXXX-XXXX-ABCDEFG.
  7. Use this serial number to open the support case for the BIG-IP.

If you don't have access to the BIG-IQ, you can find this base registration key within the customer portal at my.f5.com.

  1. Log onto my.f5.com.
  2. Choose the relevant account from the drop down list.
  3. Click the subscriptions link.
  4. Select the active subscription ID for BIG-IQ. If the subscription is missing, please contact CustomerSuccess@f5.com. Include your name, email, and account information.
  5. Under Subscription Details find the relevant Catalog (CAT) key.
  6. Note the last 7 characters of its base registration key, XXXX-XXXX-XXXX-XXXX-ABCDEFG.
  7. These characters are the serial number you should use open the support case for the BIG-IP.
