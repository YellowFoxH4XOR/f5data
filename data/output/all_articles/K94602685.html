Description

The iControl REST API occasionally times out with the following error in /var/log/restjavad.0.log:

Exception:java.util.concurrent.TimeoutException

Environment

  • BIG-IP system
  • iControl REST API

Cause

Timeouts may occur, due to large responses, such as when requesting the status of all virtual servers or all Wide-IPs. (ID 858189)

Recommended Actions

In 16.0.0, 15.1.1, 14.1.2.7, and 12.1.5.2 new system DB variables were added to allow you to modify the timeout settings of restjavad, restnoded, and icrd therefore, you should upgrade to a fixed BIG-IP version and increase the following timeout values, as shown below:

Impact of procedure: The procedure requires restarting the restjavad and restnoded daemons. Access to the control plane will be affected. For more information on BIG-IP daemons, refer to K48615077: BIG-IP daemons (15.x - 16.x). For more information on control plane refer to K44525501: Overview of BIG-IP data plane and control plane.

  1. Upgrade to TMOS version listed as fixed in ID 858189
  2. Increase timeout values:

    tmsh modify sys db icrd.timeout value 180
    tmsh modify sys db restjavad.timeout value 180
    tmsh modify sys db restnoded.timeout value 180

  3. Save changes and restart related services:

    tmsh save sys config
    tmsh restart sys service restjavad
    tmsh restart sys service restnoded

Note: The default is 60 seconds for the 3 timeout values.

Additional Information

These db variables are not currently available in version 13.1.x. To obtain them you will need to upgrade to the newest version of 14.1.x or higher. To track when these will be available for 13.1.x you can monitor for updates either weekly or periodicly via our TechNews. This will let you know when it will release. If you any questions concerning this please contact F5 Support.

K9970: Subscribing to email notifications regarding F5 products
K9957: Creating a custom RSS feed to view new and updated documents

Alternately you can also check the release notes for the most current version of 13.1.x to see if ID858189 has been listed in the fixed section.
