Topic

By default, BIG-IP APM assigns the client an unallocated IP address from the lease pool associated with the Network Access object when a client system launches a Network Access connection. If you configure RADIUS authentication in your access policy, and you would like to set the client IP address to the returned value of the RADIUS Framed-IP-Address attribute, perform the following procedure:

Note: This procedure assumes that you have already configured an access policy with RADIUS authentication, and that the RADIUS server(s) configured in your access policy return the Framed-IP-Address attribute. For more information about configuring an access policy with RADIUS authentication, refer to the Configuration Guide for BIG-IP Access Policy Manager. 

  1. Log in to the BIG-IP Configuration utility.
  2. Go to Access > Profiles / Policies.
  3. Click Edit next to the the name of the access profile you want to configure.
  4. On the successful branch following the RADIUS Auth action, click the plus sign (+) to add an action.
  5. Select the Assignment tab
  6. Select the Variable Assign option button.
  7. Click Add Item
  8. In the Name field, enter a name for the action.

    For example:
    Assign Framed-IP-Address

  9. Click Add new entry.
  10. Click the change link.
  11. In the upper left menu, select Predefined Session Variable.
  12. From the Variable menu, select Network Access client IPv4.
  13. In the upper right menu, select AAA Attribute.
  14. From the Agent Type menu, select RADIUS.
  15. From the Attribute Type menu, select Use RADIUS attribute.
  16. In the RADIUS attribute name field, enter the following:

    framed-ip-address

  17. Click Finished.
  18. Click Save in the action builder screen.
  19. In the top left corner of the page, click the Apply Access Policy link.
  20. Click Close.
