Issue

Prior to version 12.5 of the End User Diagnostic (EUD) utility, the EUD utility performed a File System Check (fsck) each time it was initiated. Beginning in version 12.5 and later, the File System Check has been removed and no longer runs when the EUD utility is launched.

Note: EUD version 12.5 was released with BIG-IP 10.1.0.

The File System Check was removed for the following reasons:

  • The File System Check is a software or operating system utility used to diagnose, verify, or fix any related file system issues. The primary purpose of the EUD utility is to check and diagnose hardware issues specific to BIG-IP platforms to allow for troubleshooting purposes.

    Note: The EUD utility only ran a basic File System Check using the -y flag that would automatically repair, if possible, any file system related issues.

  • The File System Check may report false positives on systems running dual hard drive setups, such as the BIG-IP 6900 and 8900 platforms.

    Note: For more information, refer to K10902: Running EUD corrupts RAID file system on BIG-IP 6900 and 8900 platforms.

Workaround

If you want to run a File System Check to ensure the file system is operating correctly, you can force the system to run a File System Check the next time the system is rebooted.

Note: Running a file system check manually can still report false positives on systems running dual hard drive setups. If you have questions about the output from a file system check and whether or not it is a false positive, contact F5 Networks Technical Support.

Note: For information about performing a file system check on reboot, refer to K10328: Forcing a file system check on the next system reboot.
