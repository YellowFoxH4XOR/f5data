Topic

Topology load balancing is one of the methods you can use on the BIG-IP GTM system to distribute name resolution requests. The Topology mode bases the distribution of requests on the weighted scores for topology records. Topology records direct DNS queries to the closest virtual server, based on geographical information.

The BIG-IP GTM system uses the following regional database files to provide geolocation maps for topology load balancing:

  • netIana.inc
  • base_region.ISP

These internal regional database files are not updated with every BIG-IP GTM system release. It is not currently possible to import an external geolocation database into the BIG-IP GTM system’s internal regional database, or export the BIG-IP GTM system's internal regional database for use with other F5 products.

F5 Product Development tracked a feature enhancement to integrate the BIG-IP GTM system with an external database as CR73798. This enhancement was introduced in BIG-IP GTM 10.1.0.

For information about updating geolocation data for a BIG-IP GTM 10.1.0 or later, refer to K11176: Downloading and installing updates to the IP geolocation database.
