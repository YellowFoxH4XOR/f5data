Known Issue

When you automatically merge the BIG-IP ASM security policies, the merge may fail.

This issue occurs when all of the following conditions are met:

  • You run the BIG-IP ASM Configuration utility Policy Diff for two security policies.
  • The Policy Differences Summary includes entities that differ.
  • You choose to merge the security policies, including the unique items.

Impact

The policy merge fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you run Policy Diff and select to perform the merge with the unique entities, the policy merge fails with an error message similar to the following example:

    asm_config_server.pl|INFO|<date time>|25083|F5::ASMConfig::Handler::handle_error,,Failed add for extraction [extract_id = '', extract_name = 'Applicants[0].TaxResidencies.Residencies[0].Id', extract_level = '1'] asm_config_server.pl|INFO|<date time>|25083|F5::ASMConfig::Handler::handle_error,,Code: 201, Error message = Failed validating value '' for Search in Response Body Match Regular Expression Value: The value is empty

  • When you run Policy Diff and select to perform the merge without the unique entities, the policy merge succeeds.
