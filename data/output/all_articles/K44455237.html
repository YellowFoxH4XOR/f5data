Issue

Error Message

01071739:3: The hardware can't support a <number_cores> core guest

In this error message, note the following:

  • <number_cores> is the number of logical CPU cores you attempted to allocate to the Virtual Clustered Multiprocessing (vCMP) guest.

For example:

01071738:3: The hardware can't support a 10 core guest

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The console display

Description

This message occurs when the following condition is met:

  • The hardware resources that you attempted to allocate to the vCMP guest are not supported by the platform.

When you create a vCMP guest, you allocate hardware resources, such as CPU cores, to the guest. The total number of CPU cores that you can allocate to all vCMP guests depends on the number of physical cores that a single physical CPU contains on a particular platform.

Impact

The specified hardware resources were not allocated to the vCMP guest.

Recommended Actions

For more information about CPU and memory allocation for a vCMP guest on various platforms, refer to K14218: vCMP guest memory/CPU core allocation matrix.
