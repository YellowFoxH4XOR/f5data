Topic

The BIG-IP LTM Client SSL profile supports the POPS, IMAPS, and SMTPS protocols. After a client SSL virtual server is configured, the BIG-IP LTM system accepts SSL/TLS traffic for the appropriate protocol, decrypts it, and load balances it to the pool member servers.

Note: The SMTPS profile provides support for the STARTTLS extension. To avoid a conflict between the SMTPS and Server SSL profiles, do not configure a Server SSL profile when an SMTPS profile is applied to the virtual server.

To configure BIG-IP LTM to offload POPS, IMAPS, and SMTPS traffic, you must configure a Client SSL profile and associate it with a virtual server. You can create the virtual server to reference one of the ports listed in the following table.

ProtocolTCP Port
IMAPS993
POP3S995
SMTPS465
