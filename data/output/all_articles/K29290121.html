Description
Booting into an earlier version after upgrading a FIPS-enabled BIG-IP LTM or running big3d_install from a BIG-IP GTM to a FIPS-enabled LTM may result in a halted LTM system.

Environment
  • BIG-IP LTM with FIPS license
  • One of the following:
    • Upgrade and rollback to previous version of BIG-IP software.
    • Executing big3d_install from a GTM running a higher software version than the target LTM.

Cause
FIPS runs an integrity check on binaries to ensure that they have not been modified. When a BIG-IP is upgraded, the version of big3d is upgraded as well. As the big3d version is shared across boot locations, this upgraded agent persists when booting into an earlier software version. Additionally, when the big3d_install command is run from a GTM running a higher software version than the target LTM, big3d is upgraded on the LTM. In both cases since this is not the version that FIPS expects, it fails the test and halts the system with an error similar to this:

*** FIPS or Common Criteria power-up self-test failure.
*** This system has been placed in an error state.
*** To recover return to the grub menu and select another volume
*** or reinstall the system.
***
*** On many devices pressing the escape key followed by the (
*** key will bring up a menu which allows the system to be restarted.

Power-up self-test failures:
OpenSSL: Integrity test failed for libcrypto.so

or  
Power-up self-test failures:
TMM self-test: RSA sign and verify - KAT, error: ERR_INIT, line number: 458


This issue is a result of Bug ID 940733
 

Recommended Actions
  • Boot back into the newer software volume using the GRUB menu from the console.
  • Alternatively, you can prevent the bug from occurring by deleting /shared/bin/big3d before performing a rollback (booting to the volume with the earlier version).
  • If the target software volume has already experienced this issue (the system boots to a halted state), follow the instructions in K25205233: BIG-IP System halted while booting. Halt at boot after FIPS Integrity Check Result FAIL, in addition to deleting /shared/bin/big3d.
