Known Issue

This is the result of a known issue. When the tightening flag is enabled for a wildcard entity, and the BIG-IP ASM receives a request that contains an entity that matches the wildcard entity, the BIG-IP ASM system generates a learning suggestion for the found entity. Under certain conditions, the BIG-IP ASM system erroneously generates a learning suggestion parameter called UNNAMED, instead of the correct parameter name.

This issue can occur when the BIG-IP ASM adds a learning suggestion parameter to the policy, and the parameter is removed by an administrator. If the BIG-IP ASM receives the same request that generated the previous learning suggestion while the parameter name is in the BIG-IP ASM enforcer's cache, the system generates a learning suggestion parameter called UNNAMED.

F5 Product Development tracked this issue as CR107265.

BIG-IP ASM versions 9.4.5 and later are not affected by this issue.
