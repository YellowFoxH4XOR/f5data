Description

After upgrading the vCMP Host, vCMP guest fails to deploy with the following error message on GUI:
Status failed: Comment: Cannot deploy guest due to license limit. Maximum number of deployed guests is: 0

Environment

  • Upgrade
  • License
  • vCMP
  • CLI

Cause

None

Recommended Actions

1) Run the following command to verify the license status in cli:
tmsh show /sys license detail

2) Check if the above output showing the latest "Service Check Date" and verify the vCMP max guests value. 

Optional Modules
  ........
  perf_vcmp_max_guests [100000]
  VCMP max guests
  .......

3) On CLI bash, run the following command to restart vcmpd:

bigstart restart vcmpd
