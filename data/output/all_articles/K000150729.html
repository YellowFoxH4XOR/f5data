Description

  • Does XC support DNAME DNS records?
  • You are using DNAME DNS records in your application environment and want to know if that is compatible with F5 XC DNS service.

Environment

  • XC Console
  • XC DNS Management
  • DNS

Answer

Yes, XC supports DNAME DNS records. However, please be aware of the following limitations:

  • DNAME substitution is not possible for APEX records/naked domains as per RFC. Please refer https://datatracker.ietf.org/doc/id/draft-ietf-dnsext-rfc2672bis-dname-24.html#rfc.section.2.2
  • As per RFC 6672, DNAME record and A record cannot coexist for the same apex/root domain. Typical practice would be to have A record for root domain and DNAME for subdomains. For example, if you have a DNAME record for sub.example.com pointing to newsub.example.net, then any query for a name under sub.example.com (like a.sub.example.com or b.sub.example.com) will be redirected to the corresponding name under newsub.example.net (like a.newsub.example.net or b.newsub.example.net).

Additional Information

DNAME (Delegation Name) is a DNS record that provides a way to redirect or alias an entire subtree of the DNS namespace to another domain.

DNAME records can be good for domain migration or even load balancing queries, but they have to be configured on subdomains. DNAMEs cannot be used in the Apex zone (example.com in the example above provided).
