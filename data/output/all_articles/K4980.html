Topic

The bitrate evaluator measures the amount of traffic that passes over an SSL VPN connection each second. When you set a value greater than 0 for the bitrate evaluator, FirePass will ignore that amount of traffic when it decides whether or not the connection is idle. For example, if you set the value for the bitrate evaluator to 8, FirePass will treat SSL VPN connections that transmit up to 8 bytes in a second as if they are idle. This allows you to use an idle connection timeout with applications that send Keep-Alive traffic.

FirePass will average the number of bytes per second over the period, in minutes that you specify for the Timing Window. For example, if you set the Timing Window to 4, FirePass will measure the amount of traffic longer than 240 seconds, and then divide the result by 240.

For information about timeout values, refer to K3106: Configuring session time limits.

To configure the bitrate evaluator, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. In the main navigation pane, select Network Access.
  3. In the upper navigation pane, select Global Settings.
  4. Locate the Bitrate Evaluator Parameters section of the page.
  5. In the field named Bitrate threshold (Bytes/sec), enter the number of bytes you want FirePass to ignore.
  6. In the Timing Window drop-down menu, select the number of minutes you want to use as a sampling period.
  7. Click the Apply these rules now button.

The bitrate evaluator is now configured.
