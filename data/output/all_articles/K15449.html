Known Issue

A BIG-IP APM rewrite of Adobe Flash SWF files may fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access profile references a rewrite profile.
  • An Adobe SWF file is processed by the rewrite profile.
  • The Adobe SWF file contains a compressed body followed by additional data.

Impact

The rewrite of the Adobe SWF file fails.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Adobe SFW content may not render correctly when processed by the BIG-IP APM system.
  • The BIG-IP APM system sends a SIGABRT signal to the rewrite process, which produces a core file in the /shared/core directory, similar to the following example:

    rewrite.3.bld1953.0.core.gz

  • Users may be temporarily unable to connect to portal access resources through the BIG-IP APM system, and they may receive an error message similar to the following example:

    Page cannot be displayed
