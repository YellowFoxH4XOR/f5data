K000129991: BIG-IP authentication takes too much time when using LDAP

Type
Support Solution
Published
2023-02-09
Updated
2023-08-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 12.1.5
Source
https://my.f5.com/manage/s/article/K000129991

Description

Authentication to the BIG-IP system takes too much time when using a LDAP server.


Environment

• LDAP for BIG-IP authentication

 

Cause

The ldap configuration file (/etc/openldap/ldap.conf) has the referrals feature enabled.


Recommended Actions

Add the tag REFERRALS to the ldap.conf file and assign the value: no

# # LDAP Defaults

# # See ldap.conf(5) for details

# This file should be world readable but not world writable.

#BASE dc=example,dc=com

#URI ldap://ldap.example.com ldap://ldap-master.example.com:666

#SIZELIMIT 12

#TIMELIMIT 15

#DEREF never

TLS_REQCERT never

TLS_CACERTDIR /etc/openldap/certs

REFERRALS no  # <<< 
 

Additional Information

None.
