K000147462: How to use DNS Notify with F5 Distributed Cloud DNS

Type
Support Solution
Published
2024-11-08
Updated
2026-09-24
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud DNS Management
Source
https://my.f5.com/manage/s/article/K000147462

Description

DNS Notify allows a Primary DNS server to send notifications to other DNS servers (usually Secondary name servers) about the change of a zone. Those servers in turn will ask for a zone transfer (AXFR) to get those changes.

Environment

  • F5® Distributed Cloud DNS (XC DNS)
  • DNS Secondary

Cause

Zone transfers are not allowed from the Primary server to F5 Distributed Cloud DNS, or changes are made within the 5-minute rate limit, resulting in the second change not being accepted.

Resolution/Answer

  1. DNS Notify is a means by which a Primary DNS nameserver informs secondary nameservers that a zone update is available.
  2. DNS Notify is supported "out of the box" by F5 Distributed Cloud DNS.
  3. There's nothing to configure, whenever F5 Secondary DNS receives a Notify from a configured primary DNS server, it will request a zone transfer.
  4. Zone transfers have to be allowed from the Master server to F5 Distributed Cloud DNS.
    1. IP addresses to allowed are listed in this article.
    2. It is also possible to use TSIG to secure Zone transfers.
  5. If you are testing F5 Distributed Cloud Secondary DNS and do not have our NS listed in the NS records of your zones, you can use the "also-notify" feature in your Primary DNS - the IP addresses to send the notifies to are:
    1. 107.162.234.197
    2. 107.162.176.221
  6.  There is a 5-minute rate limit in the system, we can do two changes within 5minutes
    1. Important: If you are making third change within 5 minutes, the 3rd change will not be accepted
