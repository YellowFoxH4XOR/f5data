Known Issue

F5 has identified a firmware issue in some Western Digital hard drives used in the ARX 1000 platform, which may result in disk errors or drive failure.

This issue occurs when both of the following conditions are met:

  • The ARX 1000 platform has a Western Digital hard drive with model number WD1500HLFS-01G6U
  • The hard drive uses a firmware version earlier than R: 04.04v06

Important: The RAID controller in the ARX 1000 platform will not permit a firmware upgrade for the hard drive using a hotfix or software upgrade. Therefore, F5 is replacing any affected hard drives with new drives that have already been upgraded to firmware version R: 04.04v06. Customers with affected hard drives should request upgraded replacement drives using the standard F5 RMA process.

Note: The drive replacements will use the standard F5 RMA process, but may not be subject to the Terms and Conditions or SLA’s of Support contracts currently active with F5. These replacements will consist of F5 shipping replacement CRU/FRUs only, shipped from the F5 Service Logistic parts distribution center based in California, USA.

Identifying the hard drive model and firmware version:

To determine if the hard drives installed in your ARX 1000 system are affected, perform the following procedure:

  1. Log in to the ARX CLI.
  2. Display the drive model by typing the following command:

    show chassis diskuse

    The show chassis diskuse command output displays the drive model in the Disk Details section similar to the following example:

    Disk Details:
    Disk     Size        State               Transfer Rate   Model
    ------   ---------   -----------------   -------------   ----------------
    Bay 1    139.73G     Online              1.5Gb/sec       WD1500HLFS-01G6U
    Bay 2    139.73G     Online              1.5Gb/sec       WD1500HLFS-01G6U
    Important: If the disk model is not WD1500HLFS-01G6U, your device is not susceptible to the issue and does not require replacement.
  3. If the disk model is WD1500HLFS-01G6U, verify the drive's firmware version by typing the following command:

    grep /dev/sda:port log kmesg-current

    The command output appears similar to the following example:

    <6>/dev/sda:port1: M: WDC_WD1500HLFS-01G6U0 S: WD-WXL408734727 R: 04.04V06
    <6>/dev/sda:port2: M: WDC_WD1500HLFS-01G6U0 S: WD-WXL608041627 R: 04.04V06

    Important    : If a drive's firmware version is R: 04.04V06, the drive is upgraded and does not require replacement.

    If a drive's firmware version is earlier than R: 04.04V06, you should upgrade the drive. To request a replacement drive, contact F5 Technical Support and open an RMA request support case.

    Note    : A separate support case is required for each hard drive RMA.

    Note    : Support for logging the drive firmware version information was introduced in ARX version 5.x and in the latest 4.x hotfixes. For older ARX versions, if the grep command output does not display firmware version information, you must     upgrade to a currently supported ARX version.

Impact

Increased risk of drive failure.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The ARX system may display no symptoms.

    Important: F5 strongly recommends replacing the affected Western Digital WD1500HLFS-01G6U drives before symptoms occur.
  • The following show chassis diskuse command output may indicate a drive has failed:

    Disk Details:
    Disk     Size        State               Transfer Rate   Model
    ------   ---------   -----------------   -------------   ----------------
    Bay 1    139.73G     Online              1.5Gb/sec       WD1500HLFS-01G6U
    Bay 2    139.73G     Failed              1.5Gb/sec       WD1500HLFS-01G6U

Resolution

Status

F5 Product Development has assigned ID 355160 to this issue, and has confirmed that this issue exists in the products listed in the Applies To box.

The RAID controller in the ARX 1000 platform will not permit a firmware upgrade for the hard drive using a hotfix or software upgrade. This issue requires a hard drive replacement.

Workaround

  • A workaround is not available for this issue; you must replace the ARX 1000 hard drives. Once you have obtained replacement hard drives with the upgraded firmware, you can install the upgraded drives by performing the following procedure:

Replacing the ARX 1000 hard drive

Note: The following procedure is a hot-swap procedure and does not require the ARX 1000 to be powered down or encounter a loss of service. However, if the ARX 1000 hard drive is part of an HA redundant pair, F5 recommends that you replace the hard drives on the backup system first, then fail over services and repeat the drive replacement procedure on the formerly active system. You can use the show redundancy command to determine the active/backup status of a system in an HA redundant pair. For information about the show redundancy command, refer to the ARX CLI Reference Guide.

  1. Log in to the ARX CLI.
  2. Enter privileged mode by typing the following command:

    enable
  3. Verify the current state of the disks by typing the following command:

    show chassis diskuse

    The Disk Details section of the command output will display the state of the disks similar to the following:

    Disk Details:
    Disk     Size        State               Transfer Rate   Model
    ------   ---------   -----------------   -------------   ----------------
    Bay 1    139.73G     Online              1.5Gb/sec       WD1500HLFS-01G6U
    Bay 2    139.73G     Online              1.5Gb/sec       WD1500HLFS-01G6U

    Important: If both disks are online, you may replace either disk first. However, if one of the disks is already in a failed state, you must replace the failed disk first.
  4. Remove the disk from the RAID configuration using the following command syntax:

    raid offline <disk>

    In this command, note the following:

    • <disk> is disk1 or disk2, depending on the disk you are replacing.

      For example:

      raid offline disk2
    The system displays the following confirmation prompt:

    Set disk drive in Bay 2 offline? [yes/no]
  5. At the Set disk drive in Bay # offline? [yes/no] prompt, type the following:

    yes
  6. The show chassis diskuse command output indicates a logical disk status of Degraded and that the removed RAID disk has been marked as Failed:

    Logical Disk Details:
    Disk    Status                 Verification Mode  Verification Rate
    ------  ---------------------  -----------------  -----------------
    1       Degraded               Automatic          10 %

    Disk Details:
    Disk       Size          State               Transfer Rate   Model
    --------   -----------   -----------------   -------------   -----------------
    Bay 1      139.73G       Online              1.5Gb/sec       WD1500HLFS-01G6U
    Bay 2      139.73G       Failed              1.5Gb/sec       WD1500HLFS-01G6U
  7. Remove the front bezel of the ARX 1000 to expose the disk drive bays on the right side of the front panel.

    Note: Disk Bay 1 (disk1) is on the top and Disk Bay 2 (disk2) is on the bottom.
  8. Physically remove the drive that you are replacing.

    Note: For more information about physically removing the hard drive, refer to the ARX 1000 Hardware Installation Guide.

    Important: Static electricity may damage switch components. Make sure to wear antistatic wrist straps before handling disk drives.
  9. When you remove the drive, an audible RAID alarm will sound. Silence the RAID alarm by typing the following command:

    raid silence
  10. Install the replacement drive with upgraded firmware.
  11. Start the RAID rebuild process for the new replacement drive using the following command syntax:

    raid rebuild <disk>

    In this command, note the following:
    • <disk> will be disk1 or disk2, depending on the disk that you replaced.

      For example:

      raid rebuild disk2
    Note: The RAID rebuild process may take several hours to complete.
  12. Monitor the progress of the RAID rebuild using the show chassis diskuse command. The Disk Details section of the following command output indicates a state of Rebuild and displays the percentage of completion for the RAID rebuild process:

    Disk Details:
    Disk       Size          State               Transfer Rate   Model
    --------   -----------   -----------------   -------------   -----------------
    Bay 1      139.73G       Online              1.5Gb/sec       WD1500HLFS-01G6U
    Bay 2      139.73G       Rebuild      25 %   1.5Gb/sec       WD1500HLFS-01G6U
  13. Once the RAID rebuild process has completed, the following show chassis diskuse command output indicates a logical disk status of Optimal and both disks are online:

    Logical Disk Details:
    Disk    Status                 Verification Mode  Verification Rate
    ------  ---------------------  -----------------  -----------------
    1       Optimal                Automatic          10 %

    Disk Details:
    Disk       Size          State               Transfer Rate   Model
    --------   -----------   -----------------   -------------   -----------------
    Bay 1      139.73G       Online              1.5Gb/sec       WD1500HLFS-01G6U
    Bay 2      139.73G       Online              1.5Gb/sec       WD1500HLFS-01G6U
  14. Repeat this procedure to replace the other disk.

Verify the new replacement hard drive firmware version:

To verify the firmware version for the new replacement hard drives you installed in your ARX 1000 system, perform the following procedure:

  1. Log in to the ARX CLI.
  2. Verify the firmware version by typing the following command:

    grep /dev/sda:port log kmesg-current

    The output of the command appears similar to the following example:

    <6>/dev/sda:port1: M: WDC_WD1500HLFS-01G6U0 S: WD-WXL408734727 R: 04.04V06
    <6>/dev/sda:port2: M: WDC_WD1500HLFS-01G6U0 S: WD-WXL608041627 R: 04.04V06
