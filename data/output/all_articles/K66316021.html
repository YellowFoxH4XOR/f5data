Description

The BIG-IP LTM logs report:
Unexpected Error: Can't create temp directory, /var/path/to/file, errno <#>] No space left on device.

  • Restarting restjavad resolves the issue.
  • This issue is commonly mistaken with APM clients read only file system full per K22410024.

Environment

Most noticeable on devices with large UCS files, though small UCS files are also impacted.

  • BIG-IP LTM
  • lsof -ws | grep -i 'size\|deleted' returns deleted files still in use by restjavad.
  • df -h returns high amount of disk consumption for /var.

Cause

The symptoms may be caused be a known issue tracked as ID 767613, where the restjavad process keeps deleted files open, therefore, the space is not released and the disk becomes full.

Recommended Actions

Restart restjavad to release these deleted files and open disk space on /var. If this does not resolve, then it's likely there is another cause of the No space left on device error. Refer to K14403: Maintaining disk space on the BIG-IP system.
Note: Restarting restjavad briefly interrupts any iControl REST transactions to this system.

  1. tmsh restart sys service restjavad

Additional Information
