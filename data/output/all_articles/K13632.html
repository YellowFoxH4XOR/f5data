Known Issue

The BIG-IP system may reset connections when the BIG-IP ASM system and WebAccelerator are enabled on the same virtual server.

This issue occurs when all of the following conditions are met:

  • An HTTP Class profile with the following configuration options is assigned to a virtual server:
    • Application Security is set to Enabled.
    • The WebAccelerator action is set to Bypass.
  • A Web Acceleration profile is assigned to the same virtual server:
    • The Web Acceleration profile has an application defined in the Enabled list for the WA Applications cache setting.

Impact

The BIG-IP system may reset connections to the affected virtual server.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H382584 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP system resets connections to the affected virtual server.
  • In the /var/log/ltm file, you may observe error messages that appear similar to the following example:

    01220001:3: TCL error: Operation not supported (line 1) invoked from within "CACHE::disable"

Workaround

To work around this issue, you can enable BIG-IP WebAccelerator in the HTTP Class profile. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Application Security > Classes.
  3. Select the appropriate HTTP Class profile from the list.
  4. Change the WebAccelerator action to Accelerate.
  5. Click Update.
