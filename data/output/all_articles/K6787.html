Topic

Some web applications protected by the BIG-IP ASM may contain web objects that require a specific metacharacter. By default, a standard BIG-IP ASM security policy blocks requests containing certain metacharacters. However, you can use the Configuration utility's Character Sets page to configure the security policy to permit a particular metacharacter on a global level, and then use a regular expression to deny the metacharacter for a specific parameter value.

Configuring the BIG-IP ASM security policy to permit a metacharacter on a global level

  1. Log in to the Configuration utility.
  2. Navigate to Application Security > Web Applications.
  3. In the Name column, click the name of the web application you want to edit.
  4. In the Web Application Properties section, click the name of the security policy you want to edit.
  5. Click the Charsets menu.
  6. Select Parameter Value Charset from the Select Character Set menu.
  7. Find the metacharacter you want to allow globally, and select Y from the Action menu.
  8. Click Save.

You may use a regular expression to permit a metacharacter in the policy on a global level, but deny it for a specific parameter value. For example, your web application may require the policy to permit the ! (exclamation point) metacharacter for all web objects, but deny the same character for one web object.

Configuring the BIG-IP ASM security policy to allow a metacharacter on a global level, but deny it from a specific parameter value

  1. Perform the Configuring the BIG-IP ASM security policy to permit a metacharacter on a global level procedure.
  2. Click Flows from the menu.
  3. In the Flows List box, click the + (plus symbol) to expand the list of web objects.
  4. Click the web object you want to edit.
  5. In the List of Flow Parameters box, click the parameter name you want to edit.
  6. In the Parameter Characteristics section, select Alpha-Numeric from the Data Type menu.
  7. Select the Regular Expression check box.
  8. Type the regular expression statement that denies the metacharacter. For example, to deny the ! (exclamation point) metacharacter from this parameter value, type the following in the regular expression box:

    [^\x21]

  9. Click Update.
