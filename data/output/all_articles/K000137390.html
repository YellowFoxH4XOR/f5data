K000137390: Illegal cross-origin request violation triggered after upgrade to version 16.1.4 and 15.1.10

Type
Support Solution
Published
2023-10-27
Updated
2023-11-08
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000137390

Description

After upgrading bigip to v16.1.4 or 15.1.10 Illegal cross-origin request violation is triggered for requests that were legitimate in the previous version. The Allowed Origins list contains Origin Name configured with port 80.

 

Environment

  • AWAF
  • CORS

Cause

This behavior is noticed due to the fix of ID1029989. In versions that are affected by this bug ID, the security policy does not check the protocol in the Origin header of the request. After the fix, the protocol is checked in order to comply with CORS standards.

 

Recommended Actions

For the allowed URL(s) with HTML5 Cross-Domain Request Enforcement, in the 'Allowed Origin', define the appropriate 'Protocol', 'Origin Name', and 'Port'. The port must match the "Protocol" i.e. 443 for HTTPS, and 80 for HTTP.

  1. Navigate to Security  ››  Application Security : URLs : Allowed URLs : Allowed HTTP URLs 
  2. Select the URL with HTML5 Cross-Domain Request Enforcement
  3. Define protocol, origin name and port
  4. Repeat above steps for all the 'Allowed URLs' configured with HTML5 Cross-Domain Request Enforcement
