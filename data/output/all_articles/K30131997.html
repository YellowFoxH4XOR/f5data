Topic

The TMOS Shell (tmsh) is a hierarchical and modular command line utility used to configure and manage the BIG-IP system.

Description

The tmsh utility is structured as follows:

Modules

Modules pertain to an area of the BIG-IP configuration; a module higher in the tmsh hierarchy pertains to a broader area of the BIG-IP configuration, such as local traffic (LTM), while a module lower in the hierarchy pertains to a more specific area of the configuration, such as local traffic monitors.

  • The root module is the highest level in the tmsh hierarchy. When you initially log into tmsh, the prompt displays the root module as follows:

    (tmos)#

  • Lower-level modules are below the root module in the hierarchy. Some modules contain sub-modules of their own. When you navigate to a specific module in tmsh, the prompt changes to display module as follows:

    (tmos.<module>.<sub-module>)#

    In the following tmsh prompt example, tmos represents the root module, and ltm represents a sub-module of the root:

    (tmos.ltm)#

    In the following tmsh prompt example, tmos represents the root module, ltm represents a sub-module of the root, and monitor represents a sub-module of ltm:

    (tmos.ltm.monitor)#

Components

Components in tmsh are associated with a specific module and represent configurable objects in the BIG-IP configuration.

  • When you navigate to a component in tmsh, the prompt changes to display the component as follows:

    (tmos.<module>.<component>)#

    In the following tmsh prompt example, tmos represents the root module, ltm and monitor represent sub-modules, and diameter represents a specific component within the monitor sub-module:

    (tmos.ltm.monitor.diameter)#

  • You can access a tmsh component as follows:
    • Specify the full path to the component.

      For example, to display a component that resides anywhere in the tmsh hierarchy from anywhere else in the hierarchy, specify the full path to the desired component as shown in the following example:

      (tmos)# list /ltm pool MyPool

      or

      (tmos.sys.software)# list /ltm pool MyPool

    • Navigate to the component directly.

      For example, to navigate directly to the component, type the path to the desired component as shown in the following example:

      (tmos)# /ltm pool

      The prompt changes to reflect the updated path. You can now enter the command to display or modify the component:

      (tmos.ltm.pool)# list MyPool

Commands

A command in tmsh is a directive to perform a specific task related to a component. For example, you can use the create command within the LTM module to create a virtual server component that resides in that module.

Recommendations

  • To display the components and sub-modules for a specific module, use one of the following methods from the tmsh prompt:
    • Enter the module name followed by the question mark (?) character.

      For example:

      (tmos)# /ltm ?

    • Enter help followed by the module name.

      For example:

      (tmos)# help /ltm
