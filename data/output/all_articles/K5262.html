Known Issue

This is most likely the result of a known issue. In rare instances, 3-DNS may create separate server statements for each unit in a redundant pair, rather than a single server statement containing two box statements. When this occurs, configuration changes are not shared between the two units in the pair, resulting in two different configurations.

F5 Network Product Development tracked this issue as CR28180 and CR41835.
