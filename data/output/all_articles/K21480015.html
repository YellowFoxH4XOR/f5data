K21480015: Configuring Access Events Logging to BIG-IQ Via Management Interface

Description

The purpose of this article is to configure BIG-IP APM Access Events to be sent to BIG-IQ via MGMT Interface.

Note: F5 strongly recommends to use TMM interfaces instead of MGMT as:

• TMM does not use the management interface, so load balancing between pool members is not available.

• You cannot use the management port for request logging.

• Bandwidth is limited on the management port.

 

Environment

  • BIG-IQ Centralized Management
  • BIG-IQ Data Collection Nodes
  • Access service enabled on DCD node
  • BIG-IQ CM and DCDs set up as cluster to collect stats and events

Cause

None.

Recommended Actions

Prerequisites:

  • Verified communication between BIG-IPs and DCDs on Port 9997
  • Enabled Access Service on CM for DCD nodes listening on management port (BIG-IQ CM > System > BIG-IQ DATA COLLECTION > BIG-IQ Data Collection Devices > <dcd> > Services )

Enabling Access Events logging on BIG-IP from BIG-IQ and modifying config to send access events via management:

  1. Navigate to Monitoring > Dashboards > Access > Remote Logging Configuration
  2. Check BIG-IP on which we want to have access events collected and press configure
    NOTE: system will automatically deploy new pool, log destination and log publisher to marked BIG-IP - be sure that this process is done in the maitanace window if config change requires change window)
  3. Connect to BIG-IP and verify if following objects were created:
    •  System  ››  Logs : Configuration : Log Publishers > access-log-publisher
    •  System  ››  Logs : Configuration : Log Destinations >
    • access-remote-rfc5424-destination
    • access-remote-syslog-hsl
  4. Configure separate log destination for DCDs System  ››  Logs : Configuration : Log Destinations > Create..
    • Name: <prefared name>
    • eg DCD1
    • Type: Management Port
    • Address: Management IP od DCD
    • Port: by default 9997
    • Protocol: TCP
      Note: REPEAT THIS STEPS FOR ALL DCDs WHERE ACCESS SERVICE IS ENABLED
  5. Configure another set of destinations under System  ››  Logs : Configuration : Log Destinations > Create.. to set up log format  ( also for each DCD)
    • Name : access-remote-rfc5424-DCD1
    • Type: Remote Syslog:
    • Syslog Format: Syslog:
    • Forward to: <previously created  Management port type syslog server> DCD1
      Note: REPEAT THIS STEPS FOR ALL DCDs WHERE ACCESS SERVICE IS ENABLED
  6. Navigate to System  ››  Logs : Configuration : Log Publishers > access-log-publisher and add  previously created access-remote-rfc5424-DCD destinations
  7. Verify on BIG-IQ CM > Monitoring > DASHBOARD  >Access if new access logs are comming
