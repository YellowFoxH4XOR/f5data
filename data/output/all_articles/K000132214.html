K000132214: How to deploy the NLB with default target group

Type
Support Solution
Published
2023-01-24
Updated
2023-02-15
Applies to
  • NGINX Products
  • NGINX Ingress Controller: 2.4.2
Source
https://my.f5.com/manage/s/article/K000132214

Description

  • You have deployed Nginx ingress as a gateway to your cluster
  • You want to publish/expose the ingress through AWS Cloud service load balancer
  • You want to select, Network load balancer as opposed to the default classical load balancer
  • There are three main services for exposing a given deployment. Also, there is a fourth service type, but it is not essential for this discussion.
    •     NodePort, ClusterIP and Loadbalancer 
    •     LoadBalancer:- Exposes the Service externally using a cloud provider's load balancer.

-

  •      https://kubernetes.io/docs/concepts/services-networking/service/#loadbalancer
    •     it is the "cloud provider that implements and maintains the load balancer
    •    we can explore annotation provided by the service provider to provision different AWS loadbalancer

Environment

  • Nginx Ingress controller
  • AWS
  • Classic/network load-balancer

Cause

  • None

Recommended Actions

  • To instruct AWS SP, you can use annotation, such as
  • annotations:
    • kubernetes.io/ingress.class: alb

or

  • service.beta.kubernetes.io/aws-load-balancer-type: "nlb"

Additional Information

  • https://docs.nginx.com/nginx/deployment-guides/amazon-web-services/ingress-controller-elastic-kubernetes-services/#configuring-a-loadbalancer-service-to-use-nlb
