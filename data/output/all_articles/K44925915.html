Issue

Error Message

error mcpd[<PID>]: 010717dc:3: VXLAN tunnel remote address can be configured only as any(0.0.0.0) with flooding types none and multipoint.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.

For example:

error mcpd[12663]: 010717dc:3: VXLAN tunnel remote address can be configured only as any(0.0.0.0) with flooding types none and multipoint.

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility

Description

This message occurs when the following condition is met:

  • You configure a non-multicast Virtual eXtended LAN (VXLAN) tunnel in which the tunnel remote address is set to a non-zero address.

Impact

MCP validation blocks this improper configuration for non-multicast VXLAN tunnels and displays the error message.

Recommended Actions

For non-multicast VXLAN tunnels, you must set the tunnel remote address to 'any' (0.0.0.0).
