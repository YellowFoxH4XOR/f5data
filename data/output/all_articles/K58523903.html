K58523903: Suppressing the (y/n) confirmation prompt in TMSH

Type
Support Solution
Published
2021-09-14
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K58523903

Description  

 When automating tasks you want to suppress the (y/n) confirmation prompt when using TMSH commands.

  • The TMSH list type commands are used to display configuration.

Environment

  • Custom scripts that use TMSH on BIG-IP

Cause

This behavior is by design.

Recommended Actions

You can use the following TMSH command to suppress (y/n) prompt:
  1.  Modify the CLI preference display-threshold 
          (tmos)# modify cli preference display-threshold 0     (default display threshold is 100 lines) 
     (tmos)# save sys config
 

Additional Information

Note: Suppressing the prompt will not work for commands that may impact traffic:

For example:

      (tmos)#  run cm config-sync force-full-load-push to-group...
   (tmos)#  reboot
