Description

  • after upgrading from version 13 or version 14 to a version higher than 15.1.0 directly, you might see warnings on the logs, but configuration loads successfully
Examples:
  • running tmsh load sys config verify shows the warning message below on the CLI when upgrading from 14.1.4
Validating configuration...
Loading schema version: 14.1.4
  /config/bigip_base.conf
  /config/bigip_user.conf
  /config/bigip.conf
  /config/bigip_script.conf
Loading schema version: 15.1.3
There were warnings:
dos_udp_port_mode {both} has been renamed to {either}.Please update the config file or the script to avoid this warning.
  • running tmsh load sys config verify shows the warning message below on the CLI when upgrading from 13.1.1
Validating configuration...
Loading schema version: 13.1.1
  /config/bigip_base.conf
  /config/bigip_user.conf
  /config/bigip.conf
Loading schema version: 15.1.2.1
There were warnings:
dos_udp_port_mode {both} has been renamed to {either}.Please update the config file or the script to avoid this warning.

Environment

  • upgrades
  • BIG-IP AFM
  • port-lists
  • security DOS profiles

Cause

It appears that there was a schema change on 15.1.0 that changed a keyword for the 'match-direction' parameter of port-lists for DOS security profiles. If upgrading to 15.1.0, the automatic upgrade scripts correctly migrate this keyword to the new keyword. However upgrading to higher versions directly does not seem to have this automatically corrected.

Recommended Actions

  1. Save the (already) corrected configuration in the 15.x schema with:
    tmsh save /sys config 
     
  2. Check that the warning is cleared with:
    tmsh load sys config verify
