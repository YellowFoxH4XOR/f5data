Known Issue

The VIPRION 2400 platform may incorrectly report the virtual server's Packet Velocity ASIC (PVA) acceleration mode when using the Traffic Management Shell (tmsh).

This issue occurs when all of the following conditions are met:

  • The VIPRION 2400 platform is configured with a virtual server that has embedded Packet Velocity ASIC (ePVA) enabled.
  • The related FastL4 profile's PVA acceleration mode has been modified.
  • You attempt to use the tmsh utility to view the PVA acceleration mode of the affected virtual server.

    For example, you use command syntax similar to the following:

    tmsh show ltm virtual <Virtual-Server-Name>

Impact

You can ignore this issue. The actual performance of PVA configuration is as configured in the FastL4 profile that you applied to the affected virtual server using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Configuration utility shows the affected profile configured to the required PVA acceleration mode.
  • The tmsh utility may display a different PVA acceleration mode applied on the virtual server.

For example, the virtual server's PVA acceleration mode may show as PVA Acceleration: Partial when using tmsh, while in fact the FastL4 profile applied to the affected virtual server is PVA Acceleration: none.

Workaround

To work around this issue, you can reload the configuration after the PVA acceleration mode is modified. To do so, perform the following procedure:

Impact of workaround: Reloading the configuration may interrupt services and traffic.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Reload the configuration by typing the following command:

    load /sys config

  3. Exit tmsh by typing the following command:

    quit
