Issue

Old Behavior

BIG-IP versions prior to 11.0.0

In BIG-IP versions prior to 11.0.0, you can change an administrative partition's default route domain to any route domain that is configured on the system. 

Objects created without specifying a route domain will automatically be assigned to the route domain specified as default. For example, if an administrative partition MyTestPart is configured with a route domain ID of 5 as its default route domain, objects created in this partition without specifying a route domain ID will automatically be configured with route domain ID 5.

BIG-IP 11.0.0 through 11.1.0

In BIG-IP 11.0.0 through 11.1.0, an administrative partition's default route domain is fixed to default route domain zero (RD0) and is not configurable. When you create objects without specifying a route domain in any administrative partition, these objects will automatically be assigned to RD0. To configure an object for a non-zero route domain, you must denote the route domain notation for the object's IP address.

The configuration option continues to exist as the Partition Default Route Domain option on the Network > Route Domains > Create page in the Configuration utility and the default-route-domain option in the Traffic Management Shell (tmsh) (modify auth partition <part name> default-route-domain <rd id>). However, if you attempt to change the administrative partition's default route domain, both utilities will return an error message that appears similar to the following example:

0107082e:3: The default route domain cannot be changed for the <partition name> partition.

F5 Product Development tracked this change as ID 361298.

New Behavior

BIG-IP 11.2.0 and later

In BIG-IP 11.2.0 and later, the behavior was changed to match the pre-11.0.0 functionality; an administrative partition's default route domain is no longer fixed to default route domain zero and can be changed to any route domain that is configured on the system.

F5 Product Development tracked this change as ID 361358.

Impact

BIG-IP 11.0.0 through 11.1.0

When you upgrade a BIG-IP system to 11.0.0 or 11.1.0, the upgrade process will change all administrative partitions' default route domain to RD0. Additionally, when you create objects without specifying a route domain in any administrative partition, these objects will automatically be assigned to RD0. To configure an object for a non-zero route domain, you must denote the route domain notation for the object's IP address.

BIG-IP 11.2.0 and later

None
