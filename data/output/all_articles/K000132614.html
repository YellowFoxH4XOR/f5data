K000132614: Configured OCSP Responder does not use correct URL

Type
Support Solution
Published
2023-02-16
Updated
2023-02-16
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000132614

Description

The OCSP responder cannot verify any certificate, because the path defined in the OCSP Responder configuration isn't used.

 

 

Meanwhile, a packet capture reveals that the BIG-IP is not trying to access http://example.com/ocsp

but rather http://example.com

 

Environment

BIG-IP APM

OCSP responder

 

Cause

unknown

 

Recommended Actions

Define the entire path inside URL, using the example above:

 

URL: http://example.com/ocsp

 

Leaving Certificate Authority Path empty:

 

 

You may also need to uncheck Verify Signature and Verify Certificate options.
