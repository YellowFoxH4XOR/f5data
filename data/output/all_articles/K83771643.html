Description

Windows users experience a blue screen of dead (BSOD) or windows stop error/hard crash error while they connect to edge client. This issue happens randomly and system reboots when they notice this error. Post reboot users will connect to the edge client without any issue and no issue noticed when they are connected to edge client. 

Environment

  • BIG-IP APM
  • Edge client 
  • Windows OS

Cause

Issue is due to BUG ID 756468 on edge client.  

Recommended Actions

  1. Upgrade the APM client to either of the builds 7.2.2.2 or 7.2.3
    Note: Beginning in BIG-IP v13.1.0, only edge client can be upgraded to required version without needing to upgrade the entire BIG-IP system. 
    Important: The only way for the covpnv64.sys driver to update is for the client to install a package that is fixed and also connect to a VS that has the APMClients package that is fixed as well. The covpnv64.sys driver is updated on the client upon connection to a VS with the updated package. Building a package on a fixed version and connecting to a VS with an older APMClients package will fail to update the covpnv64.sys driver.

Additional Information
If end user machine is using Windows Driver Verifier, issue will be because of BUG ID - 760395. Please refer below
Bug ID 760395: Windows Driver Verifier running causes a crash in VPN Driver covpnv64.sys when you try to establish VPN connection

If the client machine is not using Windows Driver Verifier or you are already using an APM client version stated in the Recommended Actions section, then the issue is not related to ID 760395. BSOD could be caused by a variety of reasons. Contact your IT administrator for further assistance.
