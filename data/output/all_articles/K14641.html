Known Issue

TMM may not immediately re-use a source port when the Idle Timeout setting in the UDP profile is set to Immediate.

This issue occurs when all of the following conditions are met:

  • CMP is enabled for the affected virtual server.
  • The affected virtual server is processing UDP connections across multiple TMMs.

When the Idle Timeout setting is set to Immediate, TMM should immediately timeout the connection and allow the system to reuse the source port. However, when processing connections across multiple TMMs, the TMM may not allow the system to immediately reuse a source port that was previously used for a connection on another TMM.

Note: This issue will most likely affect SIP connections, as they rely on the source port remaining constant across the call. Although, the issue could affect any UDP-based communication that requires the system to not change the source port.

Impact

The affected UDP connection/call may fail if the system changes a source port.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H427304 on the Diagnostics > Identified > Medium screen.
  • SIP connections hang or fail.
  • UDP connections may fail as a result of the source port change.

Workaround

To work around this issue, you can disable CMP for the affected virtual server. To do so, perform the following procedure:

Impact of workaround: Disabling CMP may impact performance. Additionally, you should perform this procedure during a maintenance window or low traffic period to minimize any potential traffic interruption.

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.

  2. Disable CMP for the affected virtual server using the following command syntax:

    modify ltm virtual <virtual_server_name> cmp-enabled no

    For example:

    modify ltm virtual CMP_vip cmp-enabled no

  3. Save the configuration by typing the following command:

    save /sys config
