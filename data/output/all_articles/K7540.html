Known Issue

This is the result of a known issue. All BIG-IP VLANs must have an associated VLAN tag, whether it is used or not. VLAN tags allow frames to be properly handled internally. If a tag is not supplied when the VLAN is created, a tag is automatically generated. When traffic is mirrored to the destination mirrored interface, the traffic leaving the interface is tagged with the automatically-generated 802.1Q VLAN tag of that interface.

This behavior may cause problems for devices that are not configured with the same VLAN tag that the mirrored interface is using. The mirrored interface should remove the tag before the packet exits the interface.

F5 Product Development is tracking this issue as ID 249371 (formerly CR39873).
