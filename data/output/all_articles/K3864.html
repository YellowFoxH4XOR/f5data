Topic

There is an associated product code for each BIG-IP and 3-DNS product that F5 Networks offers. The licensing system uses this product code to enable software feature sets on the product.

The product codes are defined as follows:

Product CodeProduct BrandingAdditional Description
HABIG-IP HAFully featured BIG-IP Local Traffic Manager
FLBBIG-IP FireGuardSpecial-purpose BIG-IP for transparent-device load-balancing
LBBIG-IP LBSpecial-purpose BIG-IP for simple L4 static load-balancing
CLBBIG-IP Cache ControllerSpecial-purpose BIG-IP for cache load-balancing
SSLBIG-IP e-Commerce ControllerStand-alone SSL gateway, no load balancing
3DNS3-DNSGlobal Traffic Manager
LCBIG-IP Link ControllerSpecial-purpose BIG-IP/3-DNS for link load-balancing
XLB Deprecated, F5 internal product code

For a list of features enabled by each product code, refer to K3866: Feature flags that are include in each product code.
