Known Issue

BIG-IP APM access profile RADIUS authentication may fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access profile references a RADIUS AAA profile for authentication.
  • The RADIUS authentication response exceeds 2048 bytes.

Impact

Authentication fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users are unable to authenticate when accessing the RADIUS-authenticated access profile and the RADIUS response is greater than 2048 bytes.
  • Users are able to authenticate when accessing the RADIUS-authenticated access profile and the RADIUS response is less than 2048 bytes.
  • The system logs messages to the /var/log/apm file:

    err apd[5910]: 01490108:3: 89c4bd03: RADIUS module: authentication with '<username>' failed:   (0)
    info apd[5910]: 01490058:6: 89c4bd03: RADIUS agent: (logon attempt:0) authenticate with '<username>' failed
    info apd[5910]: 01490004:6: 89c4bd03: Executed agent '/Common/<radius aaa profile name>', return value 4
