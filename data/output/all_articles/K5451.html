To create a FirePass Portal Access favorite that performs automatic logon to a Citrix XenApp server (formerly Citrix Presentation Server and Citrix Metaframe Server) web interface, perform the following procedure:

Note: This Solution requires that the user's FirePass logon credentials are the same as the user's Citrix XenApp Server logon credentials.

Important: Automatic logon may fail if client detection is enabled on the Citrix server. For more information, refer to K8727: Automatic logon to a Citrix Server versions 4.0 through 4.5 web interface fails.

  1. Log on to the FirePass Administrative Console.
  2. In the main navigation pane, select Portal Access.
  3. In the upper navigation pane, select Web Applications.
  4. In the sub-menu, select Resources.
  5. Click the Add New Favorite link.
  6. In the Type menu box, select Favorite.
  7. In the Name text box, enter a name for the favorite.
  8. In the Web Application Type menu, select Generic.

    Note: If you are running FirePass version 6.x, the Web Application Type menu may not appear. If it does not appear, skip this step.
  9. In the URL text box, enter the URL for the Citrix XenApp Server web interface.

    For example:

    
 http://citrix.siterequest.com/Citrix/MetaFrame/default/login.aspx
  10. Enter the following line in the Url variables text box.

    state=LOGIN&LoginType=Explicit&user=%username%&password
    =%password%&domain=<DOMAIN>&login=Log+In

    Replace <DOMAIN> with the name of your Windows domain.

    For example:

    
 state=LOGIN&LoginType=Explicit&user=%username%&password

=%password%&domain=SiteRequestDomain&login=Log+In
  11. Depending on the version of FirePass you are running, select the Post url variables check box or Use POST for URL variables check box.
  12. Select the Open in new window check box.
  13. If you are running FirePass version 6.x, enter the URLs that are allowed to be accessed in the Allow list text box.

    For example, list a URL similar to the following example:

    http://citrix.siterequest.com/*

  14. Click the Add New button.

The Portal Access favorite is now configured.

When a user launches the Portal Access favorite, FirePass automatically logs on to the Citrix XenApp Server web interface by supplying the user's FirePass logon credentials. If automatic logon fails, your Citrix server may require different or additional URL variables than those listed in Step 10.

Note: For more information about determining which URL variables to configure, refer to the Adding URL variables section of the Deploying Citrix Presentation Server (MetaFrame) with the FirePass Controller Deployment Guide, available at the following location:

http://www.f5.com/pdf/deployment-guides/metaframe-firepass-dg.pdf
