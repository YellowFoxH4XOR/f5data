Description

TMM cores and restarts when attempting to create a self-IP

Environment

  • Adding new self-IP
  • LTM
  • Route domains

Cause

This issue is caused by BUG ID 790205 Adding a more-specific route to a route domain that overrides the default route in the default route domain can cause TMM to core


Recommended Actions

There is no workaround for this issue.  We recommend you upgrade to 14.0.1.1, 13.1.3, per the Bug Tracker article linked below.
Bug ID 790205: Adding a more-specific route to a child route domain that overrides the default route in the default route domain can cause TMM to core
