Description

When running the f5-system-scanner on BIG-IP ASM systems, a mismatch is reported for the file /etc/ts/tools/asmlogd.cfg. The scanner output indicates a SHA512 hash mismatch, specifically related to the protobuf_file_total_max_size parameter. Example error message:

MISMATCH etc/ts/tools/asmlogd.cfg sha512 expected: <expected_hash> sha512 actual: <actual_hash>

Environment

  • Product: BIG-IP ASM (Advanced WAF)
  • File: /etc/ts/tools/asmlogd.cfg
  • Scanner tool: f5-system-scanner

Cause

Each flagged file must be reviewed to determine if the change is expected. 

A common benign reason for for mismatch is due to the protobuf_file_total_max_size parameter, which is set automatically based on the platform type (hardware vs. virtual edition). The scanner tool compares the file to a default reference and flags any deviation, even if the change is expected and benign.

Answer/Recommended Actions

  • Each flagged file should be reviewed to determine if the change is expected.
  • Review the flagged file to confirm the only difference is the protobuf_file_total_max_size parameter.
  • On hardware appliances, a value of 5GB is expected; on virtual editions, 2GB is expected.
  • The scanner highlights differences from the default configuration yet may not indicate a harmful or critical issue.
  • You can check log rotation and disk space management by reviewing /var/log/ts/asmlogd.log for normal log file operations.
