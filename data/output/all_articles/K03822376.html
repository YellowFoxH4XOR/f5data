  • SFP interface flapping

Cause

Bug ID 722410: Forward Error Correction missing Auto option
Reed-Solomon Forward Error Correction (RS-FEC) is intended to be enabled with 100GBASE-SR links and disabled for 100GBASE-LR4 links

If your upstream switch does not support RS-FEC, you can use tmsh to disable it for the 100GbE interfaces on your platform.

Recommended Actions

You may set your  FEC to disable to overcome this behave:
(/Common)(tmos)# modify net interface 1.1 forward-error-correction disabled
