Known Issue

Multiple BIG-IP APM high availability (HA) failover events may trigger erroneous leasepool exhaustion.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with a network access profile.
  • Users have established network access sessions.
  • The BIG-IP APM system experiences a failover to a peer BIG-IP APM system.
  • Users have re-established network access sessions on the newly active BIG-IP APM system.
  • Failback occurs to the originally active BIG-IP APM system.

Impact

Access may fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H501252 on the Diagnostics > Identified > Low screen.
  • After the BIG-IP APM failback users are unable to establish a network access session, users may view an authentication failure error message.
  • The system logs messages to the /var/log/apm file that appear similar to the following example:

    notice tmm[8709]: 01490505:5: b9b62fd7: IPv4 Allocation failure: leasepool /<partition>/<lease pool name> is out of addresses
