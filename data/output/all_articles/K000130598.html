K000130598: changes made in the app declaration json are not being saved.

Type
Support Solution
Published
2023-02-02
Updated
2023-02-02
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.2.X, 8.2.0
Source
https://my.f5.com/manage/s/article/K000130598

Description

On the BIG-IQ, the customer was not able to make changes save to AS3 template that they have modified.

  • BIG-IQ GUI > Applications > Applications > Click on the "Application name" > Click again on the "Application name" > Under Properties > made changes to the JSON entries > Save

 

Environment

BIG-IQ

AS3 template

Cause

1. BIG-IQ GUI > Applications > Applications > Click on the "Application name" > Click again on the "Application name"

2. Reading the Help "?" from the BIG-IP, understand that the JSON is an read-only field, hence, it is expected to not accept any changes.

Recommended Actions

1. BIG-IQ GUI > Applications > Applications > Click on the "Application name" > Click again on the "Application name"

2. Proceed to modify the AS3 Apps by selecting either the "Services [Traffic Management]" or "Servers" instead.
