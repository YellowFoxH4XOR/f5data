K18044591: Error message: SSLO Deployment failed for {security policy} Error: connect: ECONNREFUSED IP:443

Type
Support Solution
Published
2023-03-31
Updated
2025-04-01
Applies to
  • BIG-IP
  • F5 App Protect
  • F5 SSL Orchestrator
  • BIG-IP AFM
Source
https://my.f5.com/manage/s/article/K18044591

Description

When deploying a configuration change to SSLO, you get prompted with an error message such as:
SSLO Deployment failed for {security policy} Error: connect: ECONNREFUSED IP:443

Environment

  • AFM provisioned
  • SSLO provisioned
  • SSLO configured in HA sync pair
  • AFM firewall policy applied to HA self-ips

Cause

When SSLO is deployed it makes a call to the peer HA self IP on port 443 to secure and communicate configurations. An AFM rule was applied to both peers HA self-ips and restricted to a vlan that the HA self-ips could not communicate on thus the connections were reset before leaving the F5.

Recommended Actions

Removed the AFM firewall rule from the HA self-ips on both devices.
  1. Navigate to Network  ››  Self IPs  ››  internal_self >> {HA Self IP}
  2. Select the "Security" tab
  3. In the "Network Firewall" section set Enforcement and Staging to disabled then update.
  4. Repeat steps 1-3 on the peer.
  5. Deploy SSLO again.
