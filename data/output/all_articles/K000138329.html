Description

Is the local-reply-mod filter, located in the samples folder, ready for production?
 

Environment

Aspen Mesh 1.14.6-am4 and newer
 

Cause

None
 

Recommended Actions

The local-reply-mod filter is ready for production even though is located in the samples folder.
 

Additional Information

local-reply-modification filter facilitates debugging by customizing the local-reply behavior of the Envoy proxy as follows:

  • Customizes the local-reply behavior of the Envoy proxy as follows:
  • Doesn’t overwrite the server header
  • Customizes the network reply
  • Adds custom logging fields

When the local proxy can’t reach the upstream service for an HTTP request, it generates a reply directly (a local reply). This reply typically has a 503 response code.
In the Aspen Mesh release directory, the sample chart is located in the following directory: samples/aspenmesh/local-reply-mod
