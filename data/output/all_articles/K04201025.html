Issue

Error Message

warning tmm[<PID>]: 01200009:6: Packet rejected remote IP <client_IP> port <client_port> local IP <virtual_IP> port <virtual_port> proto <proto>: Connection limit exceeded 

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • <client_IP> is the IP address of the client connecting to the BIG-IP system.
  • <client_port> is the port number used by the client.
  • <virtual_IP> is the IP address of the virtual server to which the client is connecting.
  • <virtual_port> is the port number the virtual server is using.
  • <proto> is the protocol used for the connection.

For example:

warning tmm[6819]: 01200009:6: Packet rejected remote IP 10.10.10.15 port 44545 local IP 10.10.10.10 port 80 proto TCP: Connection limit exceeded

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • Clients attempt to connect to the virtual server when the per-virtual connection limit has been reached.

Impact

The virtual server is unable to accept new connections until the number of active connections falls below the configured connection limit for the virtual server.

Recommended Actions

None
