K000093187: Updated attack signatures going to blocking/enforced mode

Type
Support Solution
Published
2022-12-08
Updated
2022-12-08
Source
https://my.f5.com/manage/s/article/K000093187

Description

When a live update is installed, all of new signatures are pushed directly to Enforced/Blocking, not to Staging


Environment

Attack Signatures

Live updates


Cause

Expected behavior when "Enable signature staging" is not enabled for the policy


Recommended Actions

1. Enable "Enable signature staging" at Security ›› Application Security : Policy Building : Learning and Blocking Settings : Attack Signatures

2. Click save


After this, all of the signatures may go to "Staging" because they were never explicitly enforced with "Enable signature staging" feature on. If so, do next:


1. Go to Security ›› Application Security : Attack Signatures

2. Click change properties and set it as next

Enable -> Don't Change

Perform Staging -> No

3. Click "Appy Changes to x filtered attack signatures"



After this, new signatures will stay in staging and already enforced ones will stay in that mode, unless there's a more updated one with the same ID.
