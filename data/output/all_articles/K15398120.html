Source
https://my.f5.com/manage/s/article/K15398120

Description

You want to reset the Default global firewall rule count/stats in Security  ››  Network Firewall : Active Rules.

You've tried with tmsh reset-stats security firewall global-rules command but it doesn't seem to work.

Environment

  • BIG-IP AFM
  • Default global firewall rule

Cause

None

Recommended Actions

To clear the Default global firewall rule stats/counters, restart tmm using the below command:
  # bigstart restart tmm

NOTE: restarting tmm will cause some disruption to production traffic so do it during a scheduled change/maintenance window.

None
