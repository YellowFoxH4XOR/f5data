Issue

In BIG-IP 9.4.5 and earlier, the BIG-IP system does not drop packets containing double 802.1q VLAN tags. This behavior may allow an attacker to inject one-way packets into a VLAN to cause a denial-of-service (DoS).

Note: The attacker node must have a Layer 2 (L2) connection to the BIG-IP system in order to send packets containing double 802.1q VLAN tags.

Starting in BIG-IP 9.4.6 and 10.0.0, the BIG-IP system drops packets containing double 802.1q VLAN tags.

F5 Product Development tracked this issue as CR100542 and it was fixed in BIG-IP 10.0.0 and 9.4.6. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, or WebAccelerator release notes.

This issue has been fixed in Hotfix-BIG-IP-9.3.1-HF4, which has been issued for BIG-IP 9.3.1, and in Hotfix-BIG-IP-9.4.5-HF1, which has been issued for BIG-IP 9.4.5. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
