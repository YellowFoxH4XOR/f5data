Known Issue

In rare circumstances, the asm_config_server and asm_config_rpc_handler processes may exit and restart during policy synchronization.

This issue occurs when all of the following conditions are met:

  • You have configured BIG-IP ASM systems in a device group.
  • You have enabled application security synchronization for the device group to synchronize security policies.

Impact

Policy synchronization stalls temporarily while the process restarts. Once the process has restarted, policy synchronization resumes. There is no impact on the configuration or on application traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP ASM security policy synchronization stalls or fails.
  • Administrators temporarily lose connectivity to the Configuration utility.
  • Security policy configuration updates fail or stall temporarily.
  • Core files are generated to the /shared/core/ directory that appear similar to the following example:

    asm_config_server_rpc_handler.pl.bld0.0.256.core.gz
    asm_config_server_rpc_handler_async.pl.bdk0.0.256.core.gz
