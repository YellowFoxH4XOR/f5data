K000149704: High TMM Memory on BIG-IP DNS

Type
Support Solution
Published
2025-02-07
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP DNS: 16.X.X, 17.X.X, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.X, 16.1.5, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.X, 16.0.1, 16.0.0
Source
https://my.f5.com/manage/s/article/K000149704

Description

DNS queries are dropped due to high TMM memory utilization and the Aggressive mode sweeper has been activated. See more at K13302777.

  • With error message: err tmm2[22991]: 011e0003:3: Aggressive mode sweeper: /Common/default-eviction-policy (2000000000000) (global memory) 44 Connections killed

Environment

  • BIG-IP DNS
  • TMM Memory
  • LDNS Server Caching

Cause

LDNS Server records are consuming too much of the memory.

Recommended Actions

There are few configuration/setting that we need to check and verify before we totally disable the LDNS server caching.

1. Check if the LDNS Server caching is enabled using the command below. 

tmsh list gtm global-setting general all-properties

gtm global-settings general {
    allow-nxdomain-override disabled
    auto-discovery yes
    auto-discovery-interval 30
    automatic-configuration-save-timeout 15
    cache-ldns-servers yes         <<<===---!!!

2. Verify if the LDNS server records are the top consumer of the Memory using tmctl.

tmctl -d blade memory_usage_stat -s name,cur_allocs -OK cur_allocs -L 5

name               cur_allocs
------------------ ----------
dns_ldns             53520525       <<<===---!!!
xdata                24695971
xhead                24631616
dns cache resolver    1546496 
cec                   1432584
}    

3. Check the configuration if the device is using persistence on the Wide IP.

tmsh list gtm wideip all-properties

Note: In order to disable the LDNS cache, you must disable persistence for the wide IPs in your configuration. In contrast, if you are using the persistence, you should not disable the LDNS cache.

4. To disable LDNS caching, run the command below.

tmsh gtm global-settings general cache-ldns-servers no

Additional Information

When a local DNS server (LDNS) makes a DNS request to the BIG-IP DNS system, the BIG-IP GTM system responds to the request and determines if it has an existing entry for the LDNS server stored in its cache. If the BIG-IP DNS system does not have an existing entry for the LDNS server stored in its cache, the system creates one.
