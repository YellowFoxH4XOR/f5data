Description
Upgrading BIGIP from v15.1.1 to v16.0.0.1 fails to load config with the following error message

fatal: (Can't load keyword definition (user-account.session_limit)) (framework/SchemaCmd.cpp, line 825), exiting...

Environment

  • Upgrade BIGIP v15.1.1 to v16.0.0.1
  • Config fails to load

Cause

Due to introduced RFE ID719338 in v15.1.1
ID947905 is created to trace this upgrade problem

Recommended Actions

If it's a part of the upgrade path, for example, you are upgrading from "13.1.1 → 15.1.1 → 16.0.0.1"
As a workaround, you can follow upgrade path "13.1.1 → 15.1.0.5 → 16.0.0.1" to avoid the problem, this is because 15.1.0.5 does not have ID719338
