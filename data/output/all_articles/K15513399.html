Issue

Error Message

01070312:3: Invalid keyword <cipher> in ciphers list for profile <profile>

In this error message, note the following:

  • <cipher> is the SSL/TLS cipher name or protocol that generated the error message.
  • <profile> is the affected SSL profile name in which the cipher or protocol was configured.

For example:

01070312:3: Invalid keyword 'rc4-md5' in ciphers list for profile MySSLProfile

Message Location

You may encounter this message in the following locations:

  • The SSL profile screen in the Configuration utility
  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • You attempt to define a cipher string that conflicts with the configuration in the SSL profile. For example, you attempt to configure a cipher that is only valid for the TLS 1.2 protocol, but TLS 1.2 is disabled in the SSL profile.
  • The configuration contains a custom cipher string, and you upgrade to a software version in which the cipher string or part of the cipher is no longer compatible.

Impact

The configuration may fail to load.

Recommended Actions

  • Adjust the profile or cipher string to ensure that they are compatible. For example, if the cipher string contains the AES256-SHA256 string, make sure that TLS 1.2 is enabled for the profile.
  • Remove cipher strings that are not compatible with the software version you upgraded to.

For example, if the upgrade process fails due to the presence of !RC4-MD5 in a cipher string, you can edit the configuration to remove it and then perform the upgrade. To remove instances of !RC4-MD5 from the configuration, perform the following procedure:

Impact of procedure: Performing the following procedure removes all instances of the string !RC4-MD5 from the configuration.

  1. Log in to the Advanced Shell (bash) on the BIG-IP system.
  2. Back up the configuration by entering the following command:

    cp /config/bigip.conf /config/bigip.conf.K15513399

  3. List the occurrences of !RC4-MD5 in the /config/bigip.conf file:

    grep -i '!rc4-md5' /config/bigip.conf

    The example output shows two cipher strings:

        ciphers DEFAULT:!EXP:!LOW:!SSLv3:!RC4-MD5:!RC4-SHA
        ciphers DEFAULT:!EXP:!LOW:!SSLv3:!RC4-MD5:!RC4-SHA

  4. Remove the occurrences of !RC4-MD5 by entering the following command:

    sed -i "/ciphers/s/\!rc4-md5://gI" /config/bigip.conf

  5. Check to ensure the occurrences are removed:

    grep -i '!rc4-md5' /config/bigip.conf

  6. Verify the configuration by entering the following command:

    tmsh load /sys config verify

  7. Load the configuration by entering the following command:

    tmsh load /sys config
