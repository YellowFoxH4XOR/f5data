K1049: Use of Java in EAV health monitors

Topic

At this time, there is no Java Virtual Machine (JVM) compiled for the BIG-IP system; therefore, you cannot run Java scripts or executables on the BIG-IP system.

You can work around this issue by running the Java program on a separate system and using a health monitor to check the status of the remote Java program.
