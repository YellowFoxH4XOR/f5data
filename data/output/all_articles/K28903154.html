Issue

Error Message

01010011:3: Persistence cookie hash failed <connection_info>

In this error message, note the following:

  • The <connection_info> is the following BIG-IP system configuration information relating to the error:
     
    • Client side or Server side - The side of the proxied connection.
    • vip - The virtual server for the connection.
    • profile - The persistence profile for the connection's persistence entry.
    • pool - The load balanced pool name for the connection.
    • client_ip or server_ip - The IP address of the client or server.

For example:

01010011:3: Persistence cookie hash failed (Server side: vip=/Common/example_vip profile=http pool=/Common/example_pool server_ip=192.168.10.100)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • A persistence profile compares a received HTTP cookie with a persistence table entry that is either invalid or has become stale.

Note: The length of the HTTP cookie header probably exceeds the offset of the cookie hash specified in the persistence profile.

Impact

The system may load balance client connections to an unexpected pool member.

Recommended Actions

Either of the following actions can help solve the problem:

  • Change the cookie hash entry in the persistence profile by modifying the cookie hash offset or length. This action will help accommodate the HTTP cookie in the server side response for the correct parsing of the cookie hash.
  • Change the HTTP cookie header on the pool member requiring persistent connections. This action will help accommodate the expected cookie hash in the related persistence profile.
