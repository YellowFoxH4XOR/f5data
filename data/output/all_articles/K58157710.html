Description

Attacks in the DoS Application Events log are missing values for the fields: Detection Threshold / Mitigate To Threshold / Threshold Condition.

Environment

  • DoS protection
  • Logging

Cause

The reason that Detection Threshold / Mitigate To Threshold / Threshold Condition are missing values is because behavioral detection and mitigation has been activated. With behavioral DoS, there are no "thresholds" as such, so these fields will always be blank.

Recommended Actions

To find additional details about DoS events, look up the attack ID in the DoS dashboard and expand the slider on the right-hand side, or review the /var/log/dosl7/dosl7d.log log file.
