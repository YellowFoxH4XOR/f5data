K000148739: How to determine the maximum attainable throughput when TCP Window Scaling is disabled

Type
Support Solution
Published
2024-11-27
Updated
2025-02-07
Applies to
  • BIG-IP
Source

Description

There are cases when the maximum attainable throughput needs to be determined for a TCP connection that goes through a non-congested large-capacity link given specific parameters such as link round trip time and TCP Window Scaling Option disabled. Bandwidth-delay product (BDP) is a useful formula for this. BDP is the product of the rate of data transmission multiplied by the round trip time through the link.

Environment

  • BIG-IP LTM
  • TCP

Cause

None.

Recommended Actions

Use the BPD formula to compute for maximum attainable throughput. 

  BDP in Bytes = Bandwidth in Bytes per second * Round Trip Time in seconds

 

With TCP Window Scaling Option disabled, the maximum amount of data that a transmitter can send before receiving an acknowledgement from the receiver for the very first segments would be 65535 bytes. If the link RTT is known, for example 50 ms, the BDP formula can be used to compute the maximum theoretical throughput (or bandwidth) which can be achieved through a link with theoretically sufficient capacity.

  BDP: 65535 Bytes

  Bandwidth or throughput: unknown

  RTT: 0.05 seconds

 

Substituting the values into the formula:

  65535 Bytes = Bandwidth (Bytes/sec) * 0.05 seconds

 

That gives a maximum theoretical bandwidth or throughput of 1,310,700 Bytes/sec or 10.5Mbps for a single TCP connection with TCP Window Scaling Option disabled and a link RTT of 50 ms.
