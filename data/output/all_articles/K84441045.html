K84441045: Device discovery failed due to inability to re-mount /usr in read-only

Type
Support Solution
Published
2019-10-08
Updated
2025-02-07
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K84441045

Description

In rare circumstances, a BIG-IQ device discovery of a BIG-IP device fails with the following error:

java.lang.IllegalStateException: Framework upgrade failed because the /usr file partition on BIG-IP (null) could not be re-mounted read-only due to the /usr file system being busy.


Environment

  • BIG-IQ device discovery attempt of BIG-IP version earlier than 12.0.0
  • Update Framework on Discovery checked

Cause

The framework update failed because the /usr file partition on BIG-IP could not be re-mounted read-only due to the /usr file system being busy.

Recommended Actions

To workaround this issue, you can manually re-mount the /usr partition on the BIG-IP system, and have the BIG-IQ rediscover the BIG-IP.

  1. Logon to the BIG-IP device's command line and mount /usr partition manually by typing the following commands:

    bigstart stop restjavad
    mount -o remount,ro /usr
    bigstart start restjavad
     
  2. From the BIG-IQ system, rediscover the BIG-IP device.
