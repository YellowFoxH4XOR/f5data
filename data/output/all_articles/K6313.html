K6313: Operating system support for the 'Prohibit routing table changes during Network Access Connection' feature

Topic

If you enable the Prohibit routing table changes during Network Access Connection feature, the FirePass controller prevents modifications to the client's IP routing table while the Network Access connection is active. The feature is available on the Policy Checks tab of the Network Access: Resources page.

The Prohibit routing table changes during Network Access Connection feature is supported on Windows client platforms. Starting in FirePass 6.0.3 with cumulative HF-603-1, this feature also supports Linux clients. Other client platforms, such as Mac OS X, are not currently supported.

Note: For more information about feature support on Linux clients, refer to K9482: Change in Behavior: The Prohibit routing table changes during Network Access connection setting now supports Linux clients.
