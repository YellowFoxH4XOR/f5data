K54714256: Root password aged

Source

Description

After logging in using root account you will see the following message:

You are required to change your password immediately (password aged)

You will see this message even if you have password-policy enforcement disabled:

list /auth password-policy policy-enforcement auth password-policy { policy-enforcement disabled }

Environment

Relevant environmental factors specific to the topic

  • BIG-IP, LTM
  • Password policy enforcement disabled

Cause

Setting policy-enforcement "disabled" does not change how max-duration is handled

Recommended Actions

tmsh modify /auth password-policy max-duration 99999
tmsh save sys config

chage -M 99999 root
chage -M 99999 admin(any other account)

Additional Information

None.
