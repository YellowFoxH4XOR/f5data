Known Issue

This is the result of a known issue. When you define a new browser on the Device Management: Configuration: New Browsers page, and a user connects to FirePass using the browser you defined, the FirePass session.os.platform session variable should be set to Unknown for that user. However, after installing cumulative HF-603-2, HF-603-2.1, or HF-603-3, FirePass incorrectly sets the session.os.platform session variable to Undefined when users connect using the browser you defined.

F5 Product Development tracked this issue as CR123881.

This issue was fixed in cumulative hotfix HF-603-4. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
