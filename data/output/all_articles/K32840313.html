Description

CPU utilization sudden increase to over 90% upon deleting the APM Event log profile. Notice that the urldb and urldbmgrd processes becomes typically high from Top outputs.

Environment

  • BIG-IP APM
  • SWG provisioned
  • APM Event log profile
  • High CPU utilization
  • urldb
  • urldbmgrd

Cause

A condition is triggered when a APM Event log profile attached to a Policy is deleted via GUI (Access ›› Overview : Event Logs : Settings) without detaching it from APM Policy . 

Recommended Actions 

Detach logging profile from policy before deleting.

or

Restart urldb and urldbmgrd using below command

# bigstart restart urldb urldbmgrd 

alternatively,

#tmsh restart /sys service urldb 
#tmsh restart /sys service urldbmgrd

or

Upgrade to 14.x or later

Additional Information

None.
