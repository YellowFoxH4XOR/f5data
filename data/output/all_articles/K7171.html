Topic

Both the standby and the active BIG-IP systems in a redundant pair are configured with the same floating self IP addresses. However, only the active BIG-IP system advertises and uses the floating self IP addresses.

In BIG-IP versions 9.0.0 through 9.3.1, the standby BIG-IP system cannot ping the floating self IP addresses; this is the expected behavior.

Beginning in BIG-IP version 9.4.0, improvements in the code allow both units to ping the floating self IP addresses.
