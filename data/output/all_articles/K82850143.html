K82850143: AVR reports missing data after changing avrd-interval to a non-default value

Type
Knowledge
Published
2019-05-28
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP Analytics: 14.X.X, 14.0.X, 13.1.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.0, 14.0.1, 14.1.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.0, 14.0.0
Source
https://my.f5.com/manage/s/article/K82850143

Issue

Description

  • BIG-IP Analytics and Application Visibility and Reporting (AVR) reports are missing data when viewed directly on the BIG-IP system.

Environment

  • AVR provisioned

Cause

The analytics global setting avrd-interval is modified to a non-default value.

Recommended Actions

Verifying the current value of avrd-interval

You can verify the current configured value for avrd-interval using the following command:

tmsh list analytics global-settings avrd-interval

For example, the following output indicates that the current value of the avrd-interval is 30:

analytics global-settings {
    avrd-interval 30
}

Changing avrd-interval back to the default value

Set the avrd-interval back to the default value of 300 and save the change using the following commands:

tmsh modify analytics global-settings avrd-interval 300

tmsh save sys config

Additional Information

The avrd-interval setting controls how often statistics are written to the database.

For AVR stats to be available internally, avrd-interval must be set to 300.

To send AVR data outside of the BIG-IP system, the off-box settings should be configured.
