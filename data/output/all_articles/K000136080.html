K000136080: Only one DNS Suffix shows up under the F5 VPN Adapter when running ipconfig /all

Type
Support Solution
Published
2023-09-04
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000136080

Description

When users connect via the F5 VPN, running the ipconfig /all command displays only one DNS suffix under the VPN adapter. This might cause confusion for users expecting to see all the configured DNS suffixes.

Environment

  • VPN
  • Windows Client machine

Cause

F5 VPN is only able to set a single entry under the "DNS suffix for this connection" in the VPN adapter settings, due to how Windows handles this. Any additional DNS suffixes are added to the "Append these DNS suffixes (in order)" list, which shows up under "Windows IP Configuration" when running ipconfig /all. This behavior ensures that the VPN connection uses the primary DNS suffix for its connection-specific resolutions, while still retaining the ability to search other suffixes if the primary fails.

Here is a fragment of such configuration to illustrate this:

C:\Users\Windows>ipconfig /all

Windows IP Configuration

<skipping a few lines...>
   DNS Suffix Search List. . . . . . : firstdns.f5.com
                                       seconddns.f5.com
                                       thirddns.f5.com

PPP adapter _Common_VPN_Net_access - 192.168.0.1:
   Connection-specific DNS Suffix. : firstdns.f5.com

 

You can also view the "Append these DNS suffixes (in order)" list and "DNS suffix for this connection" setting from the Windows settings point of view, by navigating to the following path:

Control Panel\Network and Internet\Network and Sharing Center

From there, click on the VPN adapter, Properties, Networking tab, Internet Protocol Version 4 (TCP/IPv4), Advanced... , DNS tab.

Here, you will see both the aforementioned "Append these DNS suffixes (in order)" table and the "DNS suffix for this connection" setting that only takes one entry.

Recommended Actions

None - this behavior is by design. However, if you find that the suffixes are not being added under the "Windows IP Configuration", or that they are unavailable, please see the articles below.
