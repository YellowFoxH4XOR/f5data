Known Issue

This is the result of a known issue. Loading a policy that contains a large XML configuration, and then applying the policy multiple times may cause the BIG-IP ASM bd process to consume memory until it eventually cores.

Note: This behavior does not affect the BIG-IP ASM 10.x branch due to architectural changes in the XML parser.

F5 Product Development tracked this issue as CR114859 and it was fixed in BIG-IP ASM 9.4.8. For information about upgrading, refer to the BIG-IP ASM release notes.
