Known Issue

Installation of OPSWAT EPSEC updates may fail without indication.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM device volumes are populated with different versions of BIG-IP software.
  • You boot the device into a volume that is an earlier version of software than the current volume.
  • You attempt to install an EPSEC OPSWAT update.

Impact

The installation fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to install the OPSWAT EPSEC update, an error similar to the following is displayed:

    File object by name (/Common/EPSEC/Images/epsec-1.0.0-450.0.iso) is in use.
     
  • When viewing system logs, you notice that there are no specific indications of what caused the update installation failure.

Resolution

Workaround

To work around this issue, you can perform a clean installation of the BIG-IP software. To do so refer to K13117: Performing a clean installation of BIG-IP 11.x - 12.x or Enterprise Manager 3.x.

Impact of workaround:  Performing the following procedure returns your device to an unconfigured and unlicensed state, and it will require restoration from a UCS backup file.
