Topic

The number of security policies supported by the BIG-IP ASM system are as follows.

BIG-IP 12.0.0 and later

Starting in BIG-IP 12.0.0, the system uses the following calculation to determine the number of supported security policies:

  • The system obtains the system memory size by subtracting 750 MB from the provisioned host memory for the BIG-IP ASM system; this size cannot be less than 700 MB.
  • If the obtained value is larger than 1.6 GB, the system supports up to 1,024 security policies; otherwise, the system supports up to 250 security policies.

    Note: You can attach an active policy to a virtual server to protect application traffic that passes through that virtual server. Inactive or parent policies (BIG-IP 13.0.0 and later) do not count towards this number.

    Note: You can see the system memory memory size by looking at the total_umu_max_size value passed to bd as a command line argument.  This can be overridden by the total_umu_max_size ASM system variable.

BIG-IP 11.4.0 - 11.6.x

In BIG-IP ASM 11.4.0, HTTP Class profiles were replaced with local traffic policies. Unlike a BIG-IP ASM web application, a local traffic policy can reference any number of active security policies, although a local traffic policy rule can reference only one active security policy for a connection. There is no hard limit to the number of security policies that you can create and configure, however, a BIG-IP ASM system allows only 250 security policies to be active at any given time.

BIG-IP 9.x - 11.3.0

In BIG-IP ASM 9.x through 11.3.0, a BIG-IP ASM web application contains one or more security policies. However, a web application can have only one active policy at a time. The security policy determines the legitimacy of incoming requests for the web application. The BIG-IP ASM system supports up to 250 web applications. There is no code limit on the number of security policies supported by the BIG-IP ASM system.

Recommendations

When configuring a large number of security policies, you can check the amount of host memory allocated to the BIG-IP ASM system to ensure the system has adequate memory.  For more information about checking provisioned memory, refer to K36854345: Viewing provisioned module resource allocation from the command line.
