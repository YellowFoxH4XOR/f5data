K22127764: Command ''tmsh show apm access client-ip x.x.x.x all-properties'' does not honor the filter, it shows all sessions.

Type
Support Solution
Published
2020-04-13
Updated

Applies to

Description

Command "tmsh show apm access client-ip x.x.x.x all-properties" does not honor the filter, it shows all sessions.

Example:
root@(localhost)(cfg-sync Standalone)(/Common)(tmos)#  show apm access client-ip 10.242.45.2 all-properties

apm::access-info
 Session                                  d8d17a2f
 -partition                                 DESJQM
 -status                               established
 -logon user                               ddu7875
 -client IP                            10.242.45.2
 -profile access type                          all
 -access profile                           ltm_apm
 -start time                   2020-04-02 09:26:30
 -expiration time              2020-04-07 20:59:30
 -bytes:(rx,tx)              (203562429,869876168)
 -packets:(rx,tx)                            (0,0)
 -ingress:(raw,compressed)                   (0,0)
 -egress:(raw,compressed)                    (0,0)

The above output shows that the command is not honoring the IP filter, it shows session information for IP 10.242.45.2 and 10.201.2.118

Environment

  • BIG-IP APM
  • tmsh

Cause

F5 Product Development has assigned Bug ID 713389 to this issue.

Recommended Actions

This issue has been resolved in version 14.1.x as well as a workaround for previous versions outlined in the above linked Bug Tracker article.
