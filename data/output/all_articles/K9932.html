Topic

Refer to the following sections for more details about interpreting the counters displayed by the bigpipe interface command and the bigpipe trunk command:

Statistics for interfaces

To view the statistics for interfaces, type the following command:

# bigpipe interface 1.1 show all

The command output displays interface statistics that appear similar to the following example:

INTERFACE 1.1   00:01:D7:32:07:86   ENABLED   up   MTU 1500
|     media auto (100baseTX full)   aggregation: detached
|     flow control tx rx (tx rx)
|     (pkts,bits,errs) in = (474911, 269.4M, 4), out = (409727, 250.2M, 0)
|     (drop,mcast) in = (0, 191277), out = (0, 27)    coll = 0

The last two lines include counters that report various statistics for the indicated interface.

For more details about the meaning of each counter, refer to the following table:

CounterDescription
pkts in/outThis counter reports the total number of frames received and sent; it includes dropped frames, but not frames with errors
bits in/outThis counter reports the total number of bits received and sent; it includes the bits from dropped frames, but not from frames with errors
errs in/outThis counter reports the total number of frames with framing or CRC errors
drop in/outThis counter reports the total numbers of packets dropped due to unknown L2 protocols or VLAN IDs (unrecognized packets), or because buffers were exhausted

Note: In BIG-IP versions 9.0 through 9.4.6 and 9.6.x, the output drop counter is always zero, since the BIG-IP system does not drop packets on transmission. Beginning in version 9.4.7, the input drop counter only reports frames that are not recognized, and the output counter reports input packets dropped due to buffer exhaustion. A low drop ratio is typically seen as a result of bursty traffic, and is no cause for concern. A high drop ratio may indicate the link is oversubscribed. In such cases, a higher speed interface or link aggregation should be considered.

Note: Some differences in the use of this counter also exist between platforms. For more information, refer to K5682: The dropped packet counter behavior is different on some BIG-IP platforms.

mcast in/outThis counter reports the total number of multicast or broadcast frames received and sent; it includes dropped frames, but not frames with errors

Note: The input and output directions (in and out in the command output) are defined from the point of view of the BIG-IP switch. The value of each in counter reports traffic that received by the switch, and the value of each out counter reports traffic sent by the switch.

To view a summarized output without the all parameter, type the following command

# bigpipe interface 1.1 show

The command displays the following summarized output in which the pkts drop and errors counters include the total number of drops or errors, regardless of direction:

interface   speed   pkts   pkts   pkts   pkts   bits   bits errors trunk
             Mb/s     in    out   drop   coll     in    out
  1.1 UP   100 FD 475269 410192      0      0 269.7M 250.5M      4

Statistics for trunks

To view the equivalent statistics for 802.3ad trunks, enter the bigpipe trunk command instead of the bigpipe interface command. The definition of each counter for the trunk statistics are the same as the definitions for the interface statistics.

When displaying the statistics for trunks, the summary statistics for the entire trunk are displayed, followed by the individual statistics for each interface.

To view the statistics for trunks, type the following command:

# bigpipe trunk show all

The command output displays trunk statistics that appear similar to the following example:

TRUNK test   00:01:D7:32:AF:10   LACP DISABLED   members: 2 (2 working)
|     (pkts,bits,errs) in = (6.662M, 4.065G, 0), out = (6.662M, 4.065G, 0)
|     (drop,mcast) in = (0, 6.662M), out = (1.501M, 6.662M)    coll = 0
+-> INTERFACE 1.3   00:01:D7:32:AF:09   ENABLED   up   MTU 1500
|   |     media auto (1000baseT full)   trunk: test   aggregation: attached
|   |     flow control tx rx (tx rx)
|   |     (pkts,bits,errs) in = (3.331M, 2.032G, 0), out = (3.331M, 2.032G, 0)
|   |     (drop,mcast) in = (0, 3.331M), out = (750785, 3.331M)    coll = 0
+-> INTERFACE 1.4   00:01:D7:32:AF:0A   ENABLED   up   MTU 1500
    |     media auto (1000baseT full)   trunk: test   aggregation: attached
    |     flow control tx rx (tx rx)
    |     (pkts,bits,errs) in = (3.331M, 2.032G, 0), out = (3.331M, 2.032G, 0)
    |     (drop,mcast) in = (0, 3.331M), out = (750859, 3.331M)    coll = 0

To view a summarized output without the all parameter, type the following command:

# bigpipe trunk

The command output displays similar to the following example:

trunk       status bandw   pkts   pkts   pkts   pkts   bits   bits errors
                    Mb/s     in    out   drop   coll     in    out
test            UP  2000 6.662M 6.662M 1.501M      0 4.065G 4.065G      0
