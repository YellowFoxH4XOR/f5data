K5781: The Persistence TTL timer restarts on each subsequent request from an LDNS server

Source

Topic

The Persistence TTL setting, persist_ttl, for a wide IP specifies the number of seconds to maintain a persistent resolution for an LDNS server. This counter will restart with each subsequent resolution request from the LDNS server.
