Description
BIG-IP systems fail to forward traffic whose destination IP address is unicast address but destination MAC address is broadcast address even the DB key tm.allowmulticastl2destinationtraffic is enabled.

Environment

  • BIG-IP v13
  • BIG-IP v14
  • BIG-IP v15
  • Wildcard Virtual Server.

Cause
This is due to ID975725.

Recommended Actions

As a workaround, a non-wildcard virtual server can be configured instead of a wildcard one.
