Description

About sys folder /Common/asm_nsyncd in bigip_base.conf:

  • Sys Folder /Common/asm_nsyncd is used to mark a device group and its corresponding objects that will require to be synced between HA pair.
  • Sys Folder /Common/asm_nsyncd is used to mark live update objects and associate them with the asm sync group.
  • When object is created and associated with a particular folder, once it is updated, the sync group that is marked by the same folder is now considered as a group that needs to be synced.

Environment

ASM

Cause

None.

None.

Additional Information

Impact for deleting the Sys Folder /Common/asm_nsyncd:

  • When ASM is not provisioned: None.
  • When ASM is provisioned: None, it will be automatically created on demand.
