Description

After an upgrade, a virtual server with a policy attached, is not functioning as expected, all policy entries are failing to work.

Environment

  • Virtual Server with LTM Policy attached
  • LTM policy using node command
  • Route Domains
  • After upgrade

Cause

Bug ID 934697: Route domain not reachable (strict mode)

Recommended Actions

To workaround the issue on affected versions, you can explicitly add the Route Domain ID to the node commands on the LTM policy attached to the Virtual Servers affected. For example:

ltm policy /Common/Policy_Example {
    controls { forwarding }
    requires { http }
    rules {
        Example {
            actions {
                0 {
                    forward
                    select
                    node 10.10.10.10%6 → Add % RD ID to explicitly specify route-domain ID where the node resides
                }
            }      

Additional Information

This can happen with LTM Policies and iRules.
