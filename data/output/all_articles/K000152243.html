K000152243: Enabling debug logging for tomcat in BIG-IP

Published
2025-06-30

Applies to

Source

Description
This article explains how to enable debug logging for the tomcat process on a BIG-IP. 

Environment

  • BIG-IP

Cause
None.

Recommended Actions

Setting to debug
To enable debug, apply the following changes:   

  1. To remount the /usr file system in read-write mode, type the following command:

    mount -o remount,rw /usr

  2. Backup the current tomcat logging configuration saved to file named /usr/local/www/tmui/WEB-INF/properties/logger.properties.bak
    cp -b /usr/local/www/tmui/WEB-INF/properties/logger.properties{,.bak}
  3. Create a debug version of logger.properties and save to file /usr/local/www/tmui/WEB-INF/properties/logger.properties.debug:
    Note: The following is a single command.
    cat /usr/local/www/tmui/WEB-INF/properties/logger.properties.bak | sed -e 's/#log4j.logger.com.f5=DEBUG,/log4j.logger.com.f5=DEBUG,/g' \
        -e 's/#log4j.logger.org=DEBUG/log4j.logger.org=DEBUG/g' \
        -e 's/#log4j.logger.web=DEBUG/log4j.logger.web=DEBUG/g' \
        -e 's/log4j.logger.org=ERROR/#log4j.logger.org=ERROR/g' \
        -e 's/log4j.logger.com.f5=ERROR/#log4j.logger.com.f5=ERROR/g' \
        -e 's/log4j.logger.web=ERROR/#log4j.logger.web=ERROR/g' > /usr/local/www/tmui/WEB-INF/properties/logger.properties.debug  
  4. Overwrite the default logger.properties with the debug version:
    cp -vf /usr/local/www/tmui/WEB-INF/properties/logger.properties.debug /usr/local/www/tmui/WEB-INF/properties/logger.properties
  5. Restart tomcat:
    bigstart restart tomcat

Setting logging to default
You can restore the default configuration by copying back the original file

  1. Restore the defaults stored in logger.properties.bak it back to logger.properties:
    cp -vf /usr/local/www/tmui/WEB-INF/properties/logger.properties.bak /usr/local/www/tmui/WEB-INF/properties/logger.properties
  2. To remount the /usr file system in read-only mode, type the following command:

    mount -o remount,ro /usr

  3. Restart tomcat:
    bigstart restart tomcat
