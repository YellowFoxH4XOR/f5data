K87144335: GSLB Server discover virtual server failed when virtual server attach address list or port list

Type
Support Solution
Published
2023-06-21
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K87144335

Description

The LTM virtual server attach address list or port list, when you add the LTM as GSLB server at GTM, you find GSLB server unable find the virtual server even if enable virtual server discover, but can discover other virtual server with not attach address list or port list with same LTM.

Environment

  • GSLB
  • Virtual Server discover
  • Address list
  • Port list

Cause

BIG-IP GSLB virtual server discover feature is not support discover the virtual server when virtual server attach address list or port list.

Recommended Actions

You can modify the virtual server discover to Enabled (No Delete) and manually add the virtual server at GSLB virtual servers list, please also attach the applicable monitor to the virtual server, because GTM bigip monitor unable detect the virtual server status.

Additional Information

None.
