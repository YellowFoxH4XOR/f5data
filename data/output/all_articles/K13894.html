Topic

You should consider using this procedure under the following condition:

  • You want to use Citrix Receiver for Google Android or Apple iOS with the BIG-IP APM system.

Description

Setting the BIG-IP APM access policy authentication action Max Logon Attempts Allowed setting to 1 allows proper operation with the Citrix Receiver clients.

This setting change may be required. If a user enters invalid credentials, the Citrix Receiver application may report that the user credentials have expired on an Apple iOS device, or the Citrix Receiver application may crash on a Google Android device. This is a known behavior of the Citrix Receiver application for mobile devices, and occurs when the BIG-IP APM access policy authentication action Max Logon Attempts Allowed setting is set to a value greater than 1.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Your BIG-IP APM system is configured to access Citrix XenApp.

Procedures

To set the access policy authentication Max Logon Attempts Allowed setting to 1, perform the following procedure:

Impact of procedure: Citrix Receiver clients who fail on the first login attempt will not be prompted to re-enter their credentials.

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > Access Profiles.
  3. Next to the name of the access profile to edit, click Edit.
  4. Click the RSA or AD authentication action.
  5. From the Max Logon Attempts Allowed menu, select 1.
