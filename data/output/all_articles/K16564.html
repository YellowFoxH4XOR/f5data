Topic

Beginning in BIG-IP 11.4.0, exchange is a reserved profile name. This change may affect upgrades from a BIG-IP version prior to 11.4.0 to a version later than BIG-IP 11.4.0 that contained a custom profile called exchange.

Description

Beginning in BIG-IP 11.4.0, there is a base profile named exchange used by the BIG-IP APM system as an application access profile, and so the exchange profile name is now reserved.

If you attempt to create a new profile named exchange in BIG-IP 11.4.0 or later, the BIG-IP system displays an error message similar to the following example:

01070293:3: The profile name (/Common/exchange) is already assigned to another profile.

If you attempt to upgrade from a version of BIG-IP prior to 11.4.0, where exchange was not a reserved profile name, then after you upgrade, your configuration fails to load and displays an error messages similar to the following example:

01070293:3: The profile name (/Common/exchange) is already assigned to another profile. Unexpected Error: Loading configuration process failed.

Recommendations

When planning an upgrade from BIG-IP versions prior to 11.4.0, you should consider the following factors:

If your existing configuration currently uses the exchange reserved profile name, you should rename it to a non-reserved name before you perform an upgrade. You can find a list of reserved names in K6869: Reserved words that should not be used in BIG-IP configurations.
