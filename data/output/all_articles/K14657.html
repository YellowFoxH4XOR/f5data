Known Issue

Users are unable to view the Configuration utility DNS Express Zone List page.

This issue occurs when the following condition is met:

  • From the Configuration utility Local Traffic > DNS Express Zones > DNS Express Zone List page, you attempt to sort the DNS Express Zone List by Status.

Impact

You are unable to use the Configuration utility to view DNS Express Zones.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H427966 on the Diagnostics > Identified > Low screen.
  • From the Configuration utility Local Traffic > DNS Express Zones > DNS Express Zone List page, you observe an error message similar to the following example: 

    General database error retrieving information

  • In the /var/log/webui.log file, you observe an error message similar to the following example:

    Column not found: ZXFR_STATUS_AVAILABILITY

Workaround

There is no workaround for this issue. However, you can mitigate this issue if you perform the following procedure:

  1. Close and reopen your web browser application.
  2. Log in to the Configuration utility again.
  3. Navigate to the Local Traffic > DNS Express Zones > DNS Express Zone List page.

    Note that you are unable to sort the DNS Express Zones by Status.
