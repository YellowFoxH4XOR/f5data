Description
When desiring to upgrade a specific BIG-IP platform, it is important to understand what software versions are supported on the platform. Running a version of software on a specific platform which is not supported for that specific platform can result in stability issues and lack of technical support assistance.

Environment

None

Cause
None

Recommended Actions

Determining what software releases are supported for a specific BIG-IP requires following a multi-step process.
  1. Determine the model of the BIG-IP. K13144 provides information on determining the model number.
  2. Locate the compatible software versions for the specific model. K9476 contains this information for each model and lists compatible versions for each.

Additional Information

  • K13144: Determining the BIG-IP model and platform type (11.x - 17.x)
  • K9476: The F5 hardware/software compatibility matrix
  • K31120922: Determining if a software release is supported on a specific BIG-IP platform
