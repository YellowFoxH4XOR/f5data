Known Issue

FirePass Network Access split tunnel routing may not function as expected.

This issue occurs when all of the following conditions are met:

  • You establish a Network Access session with a FirePass controller using the BIG-IP Edge Client for Mac OS.
  • The FirePass controller Network Access configuration is configured for split tunneling.
  • The BIG-IP Edge Client for Mac OS was downloaded and installed from a previous BIG-IP APM session.

Impact

Access to configured local area networks (LAN) may fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users who are running the BIG-IP Edge Client from a previous FirePass session have access to all LAN-configured resources.
  • Uninstalling the client's BIG-IP Edge Client and reinstalling the BIG-IP Edge Client from FirePass corrects the ability to access the configured LAN resources.
  • When viewing the route table of an established access session on an affected client device, some LAN routes are missing.

    For example, when the FirePass split tunnel configuration includes a LAN address space routed by the FirePass controller, the route table of the client device does not list the network interfaces as ppp0 for the particular LAN network when their session is established.
