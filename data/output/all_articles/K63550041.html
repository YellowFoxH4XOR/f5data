K63550041: Request Blocked for the violation: Illegal meta character in parameter name

Type
Support Solution
Published
2022-07-20
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K63550041

Description

Request Blocked for the violation: Illegal meta character in parameter name
 

Environment

  • Content-Type which both these requests have:
    Content-Type: text/x-gwt-rpc; charset=UTF-8

Cause

The URL configured in the ASM policy that is used to match this request is missing the GWT profile.
 

Recommended Actions

The following steps are for assigning GWT profile to the URL.
  1. Browse Security > Application Security > URLs > Allowed URLs > Allowed HTTP URLs
  2. Click on the desired URl
  3. Select Advanced from Allowed URL Properties
  4. Open the Header-Based Content Profiles
  5. Enter the following as described:
    Request Header Name: Content-Type
    Request Header Value: text/x-gwt-rpc; charset=UTF-8
    Request Body Handling: GWT
  6. Click Update
  7. Click on Apply Policy
     

Additional Information

None.
