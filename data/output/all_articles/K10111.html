Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator can corrupt the Cache-Control header when all of the following conditions are met:

  • The object is proxied by the BIG-IP WebAccelerator (the X-PvInfo header contains an S102xx S-code)
  • The response (X-PvInfo RA-code) matches a policy node where the Ignore no-cache HTTP headers in the response and Use HTTP  lifetime headers if present settings are disabled
  • The Client Cache settings are configured with a Maximum Age
  • The OWS is using the no-cache Cache-Control directive in its response

Note: For more information about the X-PvInfo header information, refer to the Viewing X-PvInfo response headers section of the Using HTTP Headers chapter in the BIG-IP WebAccelerator Policy Management Guide.

When this issue occurs, the corrupted Cache-Control header is typically missing a delimiting character, and may appear similar to the following example:

Cache-Control: max-age=172800no-cache

F5 Product Development tracked this issue as CR120248 and it was fixed in BIG-IP WebAccelerator 9.4.8 and 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.

This issue was fixed in BIGIP-10.0.1-378.0-HF3 issued for BIG-IP 10.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

Workaround

To work around this issue, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator Configuration utility.
  2. Click on the relevant policy.
  3. If the X-PvInfo R-code in the response is not RA0, navigate to the leaf node that corresponds to the R-code. Otherwise, navigate to the leaf node that corresponds to the the original request (A-code in X-PvInfo).
  4. Select Acceleration Rules from the drop-down menu.
  5. Click the Lifetime tab.
  6. Select the Use HTTP lifetime headers if present check box.
    Two additional options should appear.
  7. Select the Ignore no-cache HTTP headers in the response check box.
  8. Clear the Use HTTP lifetime headers if present check box.
  9. Click Save.
  10. Click Publish.
