Description

After implementing dynamic ssl certificates (sometimes referred to as 'lazy tls certificate loading') the "discarded" metric, found in the NGINX Plus api module's /api/(version)/http/server_zones endpoint, increases. 

Dynamic ssl certificates can be configured in a few ways. Here is one common example:

ssl_certificate ssl/$ssl_server_name.crt;
ssl_certificate_key ssl/$ssl_server_name.key;

In the above example, during request processing NGINX reconciles the cert and key variables to the sni hostname from the request. The cert and key names must match the names of cert and key files in the specified path. I.e. if a request's sni hostname is test.example.com then NGINX will look for a cert file /etc/nginx/ssl/test.example.com.crt and key file  /etc/nginx/ssl/test.example.com.key in path.

During the variable reconciliation process debug level error logs report something similar to the following:

(date/time) [debug] 66661#66661: *949 http script copy: "ssl/"
(date/time) [debug] 66661#66661: *949 http script var: "test.example.com"
(date/time) [debug] 66661#66661: *949 http script copy: ".crt"
(date/time) [debug] 66661#66661: *949 ssl cert: "ssl/test.example.com.crt"
(date/time) [debug] 66661#66661: *949 http script copy: "ssl/"
(date/time) [debug] 66661#66661: *949 http script var: "test.example.com"
(date/time) [debug] 66661#66661: *949 http script copy: ".key"
(date/time) [debug] 66661#66661: *949 ssl key: "ssl/test.example.com.key"

It is during this request processing where the "discarded" metric is increased. More specifically NGINX creates and frees a fake request to evaluate the certificate variables which modifies the api server "discarded" metric.

Here is an example of the "discarded" metric reporting an increased value from the api http server endpoint:

$ curl localhost/api/9/http/server_zones 2> /dev/null | jq '."test.example.com"."discarded"'
14

Here is an example of the "discarded" metric  reporting an increased value from the prometheus interpreter:

$ curl localhost/metrics 2> /dev/null | grep discarded | grep test.example.com
nginxplus_server_zone_discarded {server_zone="test.example.com"} 14

NGINX Plus

Dynamic ssl certificates

Dynamic ssl certificate processing
