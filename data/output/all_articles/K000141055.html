Description

While trying to access  "Device Management" > "Overview", error "Rest framework is not available" is being displayed and site is not displayed properly, also logs similar to:

Uncaught Error causing restjavad to exit. Thread id 28, 'com.f5.rest.workers.storage.ThreadPoolStorageRequestProcessor_8': java.lang.OutOfMemoryError: Java heap space

can be found in /var/log/restjavad.

Environment

  • BIG-IP

  • High Availability

Cause

Issue is caused by bug ID 1345989

Recommended Actions

Upgrade to fixed version, if no fixed version for your branch is available, or you are unable to upgrade, you can apply workaround from bug article, running "clear-rest-storage" command should not have impact for traffic processing.
