Description

When BIG-IP is configured behind a proxy server. BIG-IP is unable to perform licensing in the GUI, it needs to perform by using command SOAPLicenseClient with proxy option.

Environment

  • BIG-IP
  • BIG-IP is configured behind a proxy server, refer to K10942531.

Cause

None.

Recommended Actions

  1. Go to BIG-IP command line.

Run the command below for perform licensing.
To license the BIG-IP:
# SOAPLicenseClient --proxy <proxy_server_ip>:<proxy_server_port> --basekey <license_key> --certupdatecheck

Example: /usr/local/bin/SOAPLicenseClient --proxy http://1.2.3.4:443 --basekey XXXXX-XXXXX-XXXXX-XXXXX-XXXXXXX --certupdatecheck

Depending on your version you may need to omit the http:// from your syntax when running the SOAPLicenseClient

To revoke the BIG-IP license:
# SOAPLicenseClient --proxy <proxy_server_ip>:<proxy_server_port> --basekey <license_key> --revoke

Example: /usr/local/bin/SOAPLicenseClient --proxy http://1.2.3.4:443 --basekey XXXXX-XXXXX-XXXXX-XXXXX-XXXXXXX --revoke

Note that HTTPS is not a working option for proxy, but HTTP may be used instead (including on port 443 if needed).

For more options with the SOAPLicenseClient command, enter the command on the command line bash shell. You may observe an output similar to the following:

Usage: SOAPLicenseClient
       --basekey <"basekey1,basekey2..."> [--addkey <"addkey1,addkey2...">]
       [--host <host/ip>] [--port <port>] [--email <email>] [--firstname <first>]
[...]

Additional Information

If the proxy server cannot resolve the IP address by hostname or only allow to use IP address, you need to add the IP address for F5 hosted services to allowlist on the proxy server. For more information, refer to K15202: IP addresses for F5 hosted services.
