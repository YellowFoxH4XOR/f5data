Description

  • You are attempting to install the thales/ntrust/nfast  HSM software using the nethsm-thales-rfs-install.sh  script.
    https://techdocs.f5.com/kb/en-us/products/big-ip_ltm/manuals/product/big-ip-system-and-thales-hsm-implementation-14-0-0/01.html
  • The vendor files are incorrectly extracted to /opt/nfast fulling up the /  file system.

Environment

  • Any BIG-IP of version V14.1 or V15.0

Cause

This is due to the difference in version for  tar.

In version 13 it is   tar (GNU tar) 1.23
In version 14 it is   tar (GNU tar) 1.26

This affect show tar functions when extracting on to any existing symlink.

Recommended Actions

  1. This is fixed in V15.1 and later. The updated script can be copied from /usr/bin  on a later release and used.
  2.  Alternatively the script can be edited manually.
    cp /usr/bin/nethsm-thales-rfs-install.sh  /shared

    and edit the copy.
    See  Bug ID 758006: Thales nethsm-thales-rfs-install.sh script failing with / partition full
    for details
  3. Run the  edited file  /shared/nethsm-thales-rfs-install.sh

Additional Information

  • After the faulty script runs, data is in /opt/nfast   which is incorrect. To proceed you must delete this directory.
  • The correct installation will install to /shared/nfast     /opt/nfast is a symlink to  /shared/nfast, created  by the script.
