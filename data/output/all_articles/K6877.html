Known Issue

This is the result of a known issue. The HTTP::respond iRule command allows users to generate or rewrite a client request or a server response. If HTTP::respond is used with binary payload, the connection will time out.

F5 Product Development tracked this issue as CR64809 and CR64834, and it was fixed in BIG-IP GTM 9.2.5, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM or ASM Release Notes.
