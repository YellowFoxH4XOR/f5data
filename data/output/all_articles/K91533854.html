Known Issue

When you use the Configuration utility to add a new rule to an existing network firewall policy, another Policy Name box appears.

This issue occurs when all of the following conditions are met:

  • You have an existing network firewall policy configured on the BIG-IP system.
  • You attempt to add a new rule to the firewall policy using the Configuration utility, and you do not do so by navigating to Security > Network Firewall > Policies.

On the Configuration utility, you have different options for adding a rule to an existing network firewall policy. For example, if you add the rule by completing the following procedure, the system prompts you to enter a Policy Name, even though you have already selected the target firewall policy. 

  1. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
  2. Select the target virtual server.
  3. Click Security > Policies.
  4. Select the target firewall policy name. 

This issue has no negative impact to the rule you added to the target firewall policy; however, if prompted to do so, you have to enter a value for the Policy Name.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe that the target firewall policy name already exists in the menu, but a blank Policy Name box exists.
  • If you leave the Policy Name box blank and click Finished, you receive an error message similar to the following example:

    Some fields below contain errors. Correct them before continuing.

Workaround

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

To work around this issue, on the Policy box, click New, then select the target firewall policy name. You will not see the empty Policy Name box, and you can add the new rule to the target firewall policy.
