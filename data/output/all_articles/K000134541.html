Description

Backup is restored and tenant does not work due to invalid license.
Checked F5OS license, it is not possible to relicense.

Environment

  • F5OS-A  v1.0.x - v1.3.x
  • F5OS-C v1.0.x - v1.5.x
  • rSeries / Velos
  • Restore
  • License

Cause

  • Bug ID 1080041

Recommended Actions

There is no workaround. Once restoration is done, please update valid license.
NOTE: Most of the case restoration is done for replacement unit which should be linked with the faulty unit's license, so that reactivation / tenant works without any issue.
NOTE: This applies to Velos Partition backup.
