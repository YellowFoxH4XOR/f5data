Description

Adding the URL parameters to the existing datasafe profile using the tmsh utility

Environment

  • BIG-IP FPS
  • Antifraud profile
  • URL parameters

Cause
None

Recommended Actions

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:
    tmsh
  2.  To add a new parameter to existing url, use the following command:
    modify security anti-fraud profile <anti_fraud_profile_name> urls modify { <url_name> { parameters add { <parameter_name> } } }
  3.  Save the change by entering the following command:
    save /sys config
  4. To view the changes made, enter the following command:
    list security anti-fraud profile <anti_fraud_profile_name>

    For example, to add a parameter_1 to the existing URL url.html in the anti-fraud policy antifraud, use the following commands:
    # tmsh 
    # modify security anti-fraud profile antifraud urls modify { /url.html { parameters add { <parameter_1> } } }
    # save sys config
Note: <anti_fraud_profile_name> refers to the anti_fraud profile that is already configured on the Big-IP.
