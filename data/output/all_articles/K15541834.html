K15541834: BIG-IQ License Assignment page is empty in Devices License Management tab

Type
Support Solution
Published
2019-11-22
Updated
2025-02-06
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.X.X, 6.X.X
Source
https://my.f5.com/manage/s/article/K15541834
Description:

License Assignment Page on Big-IQ Is empty (Devices -->  License Management --> Licenses)
  • Adding a previously existing license generates the error:
    Activation failed: Error 51092, This license has already been activated on a different unit. Please contact technical support for assistance we can not do allow move for that license
  • All managed BIG-IPs continue to work correctly 
Environment:
  • BIG-IQ Centralized Management
  • You are managing BIG-IP licenses
  • You have no UCS backup for the BIG-IQ

Cause:
Problem due to corrupted BIG-IQ Configuration Database
 
Recommended Actions:
To resolve this issue, you will need to release and re-license each BIG-IP device managed by the BIG-IQ
  1. Collect Base Registration Keys for all managed devices  
    K15055: Using tmsh to view and manage licenses for BIG-IP and BIG-IQ systems
  2. Contact F5 support and open a new service request
  3. Request releasing each BIG-IP License so they can be re-added to BIG-IQ configuration
  4. Once licenses have been released, re-add all base registration keys to the BIG-IQ
    K77706009: Using BIG-IQ License Manager to remotely manage BIG-IP Virtual Edition licenses
    Note: The next steps may have impact on production traffic
  5. Revoke licenses from BIG-IP
    K41458656: Reusing a BIG-IP VE license on a different BIG-IP VE system
  6. License BIG-IP via BIG-IQ once more
  7. Perform step 5 and 6 for each base registration key
  8. Confirm if devices are working as expected
  9. Create a UCS from the BIG-IQ
  10. Schedule regular backups for BIG-IQ
    For further information on backup schedules please refer to "UCS Backup Management for the BIG-IQ System"
