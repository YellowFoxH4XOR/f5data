Description

The BIG-IP DNS is showing the following status on the Command Line after running gtm_add command.

[root@gtm-example-01:zrd DOWN:Standalone] config #

Environment

This solution is applicable when all the following conditions are met

  • Global Traffic (DNS) module is provisioned.
  • Ran gtm_add command.
  • The Configuration Utility is showing and Active or Standby status. The Configuration Utility status does not reflect the status on the Command Line.
  • The BIG-IP DNS is able to respond to DNS request accordingly.

Cause

Unknown at the time of publication.

Recommended Actions

Restarting the named and zrd processes would resolve the issue.

  1. Login to the BIG-IP DNS Command Line.
  2. Run the following command to restart the named and zrd processes.
    bigstart restart named zrd
  3. The Command Line status will now change reflecting the same status with the Configuration Utility.
