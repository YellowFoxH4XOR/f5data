Description

Configuration failed to load with an error message similar to:

Config not loading,Failed: name (/Common/dtca-bundle.crt) does not exist and there is no copy in trash-bin to restore from


Environment

  • After an Upgrade.
  • Possibly in other circumstances.

Cause

The version of the dtca-bundle.crt file saved in the config filestore is out of sync with the version noted in the BIG-IP base configuration file.

    • Bug ID 428876  This can still occur (rarely) in all versions (later than v12.1.0)
    • Bug ID 2302873 - Updated config not save to disk after fresh CA Certificate bundle was re-created via devmgmtd

Recommended Actions

Important: You should not edit the BIG-IP files directly unless directed to do so by F5 Technical Support of by an AskF5 Article. 

Verify a mismatch between filestore and base config:

  1. Check dtca-bundle.crt version in /config/bigip_base.conf
    grep -A 5 dtca-bundle.crt /config/bigip_base.conf | head -n5 
  2. See what versions are in the filestore:
    ​​​​​ls -l /config/filestore/files_d/Common_d/trust_certificate_d/\:Common\:dtca-bundle.crt*
    If there is no match proceed with steps below
  3. Backup bigip_base.conf
    cp /config/bigip_base.conf /config/bigip_base.conf.bk
  4. Collect the filesize and checksum value from the file in the filestore for the checksum values in bigip_base.conf
    Note: If there are more than one file choose the newest version
    1. Get File Size
      ls -l /config/filestore/files_d/Common_d/trust_certificate_d/\:Common\:dtca-bundle.crt_XXXXX_X | awk '{print $5}'
      • For example, returns 4074
    2. Get SHA1 checksum
      sha1sum /config/filestore/files_d/Common_d/trust_certificate_d/\:Common\:dtca-bundle.crt_XXXXX_X
      • For example, returns 87ba278705fff705fc18a35fd1da9484827d07ec
  5. Edit the /config/bigip_base.conf file to refer to the correct filename with editor of choice.
    1. Look for section:
      • cm cert /Common/dtca-bundle.crt { 
            cache-path /config/filestore/files_d/Common_d/trust_certificate_d/:Common:dtca-bundle.crt_12345_2
            checksum SHA1:1289:69b0278705ffc705fc18a35fd1da9484827d05ce
            revision 2 
        }   
    2. Replace cache-path value to match file name in filestore   
    3. Edit checksum values with those obtained from steps 4a and 4b   
    4. Update Revision number with value at end of filename
      • Example: 
        cm cert /Common/dtca-bundle.crt { 
            cache-path /config/filestore/files_d/Common_d/trust_certificate_d/:Common:dtca-bundle.crt_12345_3
            checksum SHA1:4074:87ba278705fff705fc18a35fd1da9484827d07ec
            revision 3
        } 
    5. save the file
  6. Verify syntax with:
    tmsh load sys config verify
  7. If no errors proceed with config load:
    tmsh load sys config
