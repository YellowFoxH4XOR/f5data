Description

PostgreSQL health monitor stopped working after upgrading from 15.1.4.0 to 15.1.4.1.

Environment

  • Upgrade BIG-IP System to v15.1.4.1
  • Configured Database monitor  (PostgreSQL Monitor)

Cause

Change in behavior in JDC driver for PostgreSQL.

Recommended Actions

Append &sslmode=allow in the database field as part of the connection string.

Example:

ltm monitor postgresql <monitor name> {
      app-service none
      count 6
      database <DB name>?ssl=true&sslfactory=org.postgresql.ssl.NonValidatingFactory&sslmode=allow  <=== append here
      debug no
      defaults-from postgresql
      description "To check the health of the PostgreSQL DB"
      destination *:*
      interval 30
      manual-resume disabled
      partition Common
      password ***scrubbed***
      recv 1
      recv-column 1
      recv-row 1
      send "SELECT 1;"
      time-until-up 0
      timeout 91
      username bigip
}
