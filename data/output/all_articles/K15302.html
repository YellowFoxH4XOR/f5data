Topic

The BIG-IP Edge Client is software that establishes a client-side SSL VPN connection to a BIG-IP APM or Edge Gateway system.

Description

When a remote Windows or macOS user launches the BIG-IP Edge Client app on a client device and initiates a network access session each time, the client device downloads and initializes the BIG-IP Edge Client installer.

Note: This applies only when using the standalone Edge Client software. It is not applicable when connecting with a web browser. When using web browsers, BIG-IP APM 13.0.0 and later versions use F5 helper applications. For more information, refer to K15326: Browser plug-in support for BIG-IP APM features and browser remediation options.

Attempting to initialize a BIG-IP APM access session on BIG-IP Edge Client triggers the BIG-IP APM or Edge Gateway system to check the current software version of the installed BIG-IP Edge Client application. When the BIG-IP Edge Client version on the BIG-IP system is later than the version installed on the connecting device, the system automatically updates the BIG-IP Edge Client application. After you established an access session using the updated BIG-IP Edge Client application, the system checks the BIG-IP Edge Client component versions and automatically updates the components based on the BIG-IP Edge Client application version and required components of the Secure Connectivity profile. (As the client device requires sufficient privileges to update, when you first install BIG-IP Edge Client, you should do so granting sufficient privileges.)

Note: The Linux CLI BIG-IP Edge Client does not automatically update.

The successful automatic update of the BIG-IP Edge Client application and components depends on any of the following conditions:

  • The BIG-IP APM or Edge Gateway system is upgraded, and the BIG-IP Edge Client or BIG-IP Edge Client components are updated.
  • When the device installed the BIG-IP Edge Client configuration, the installation set the automatic update feature (Component Update) to yes (default setting).
  • The client session connects to a BIG-IP APM or Edge Gateway with a different Secure Connectivity profile component than the Secure Connectivity profile that generated the installed BIG-IP Edge Client of the client device.

Important: The Component Update setting is part of the BIG-IP Edge Client install package. After you install the BIG-IP Edge Client, you cannot modify this setting on the client device unless you reinstall the BIG-IP Edge Client on the client device using an installation package that contains the setting. However, the setting on the APM connectivity profile takes precedence over the setting in the BIG-IP Edge Client, which makes the value in the BIG-IP Edge Client effectively redundant..

Note: To view the currently installed BIG-IP Edge Client version on your Windows device, launch the BIG-IP Edge Client, select View Details, and select the Miscellaneous tab. On macOS, select About BIG-IP Edge Client.

For more information about the BIG-IP Edge Client components for MacOS and Windows, refer to the following articles:

  • K14045: The BIG-IP Edge Client components for Windows
  • K14947: The BIG-IP Edge Client components for macOS X

Recommendations

When creating a Secure Connectivity profile for an access policy, you should consider the following factors:

  • To configure for BIG-IP Edge Clients to automatically attempt an upgrade when connecting to a BIG-IP APM or BIG-IP Edge Gateway access profile, you must set the BIG-IP APM or BIG-IP Edge Gateway system-side's connectivity profile Component Update settings to Yes.
  • To configure so that BIG-IP Edge Clients do not automatically attempt an upgrade when connecting to a BIG-IP APM or BIG-IP Edge Gateway access profile, you must set the BIG-IP APM or BIG-IP Edge Gateway system-side's connectivity profile Component Update settings to No. 
  • To configure the BIG-IP Edge Client to prompt the user to upgrade the components when connecting to a BIG-IP APM or BIG-IP Edge Gateway access profile, you must set the BIG-IP APM or BIG-IP Edge Gateway system-side's connectivity profile Component Update settings to Prompt.

For more information, refer to the Client auto-update section of K18820340: BIG-IP Edge Client operations guide | Chapter 2: BIG-IP Edge Client VPN lifecycle.

Note: Even if the Component Update setting in the Connectivity profile is set to No, some components, including Windows ActiveX components such as Host Control, InspectionHost, Machine Certificate Checker, and SuperHost, are updated automatically.

To configure the automatic update feature on the BIG-IP APM system, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Go to Access > Connectivity / VPN.

    Note: For BIG-IP 12.x and earlier, go to Access Policy > Secure Connectivity.

  3. Select the connectivity profile that is associated to your network access virtual server.
  4. Select Edit Profile.
  5. Select Win/Mac Edge Client.
  6. For Component Update, select your configuration.
  7. Select OK.
