Known Issue

BIG-IP APM password updates may fail for user account names that contain a period ( . ) character.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with a local user database.
  • An access policy references the local user database instance.
  • A local user account in the local user database instance is defined with a user name containing a period.
  • The local user database instance has Force Password Change enabled for the local user account.

Impact

The local user accounts may be unable to successfully log in to the BIG-IP APM system when Force Password Change is enabled.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When logging on to the BIG-IP APM access policy, the user is prompted to enter a new password.
  • After entering a new password and clicking the logon button, the user successfully logs in.
  • When using the newly created password for subsequent access policy logon attempts, the user receives the following error message:

    The username or password is not correct. Please try again.

  • When the user enters the original (old) password, they are looped back to entering a new password.

Workaround

To work around this issue, create a local user database account username that does not contain a period.
