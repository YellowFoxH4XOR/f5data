Description

You have applied KB5018410 on Windows 10

  • Users unable to connect through RDP profile
  • Citrix Workspace Client can´t connect with Netscaler server
  • Users unable to connect through VPN APM client

Environment

  • Windows 10
  • Security update KB5018410
  • RDP Profile or VPN Client
  • Citrix Workspace

Cause

TLS 1.0/1.1 being disabled by Microsoft for Windows 10 version 20H2-21H2 with the October 11, 2022 security update KB5018410

Recommended Actions

Install that patch KB5020435 on top of KB5018410 which fixes the issues introduce by security update KB5018410:

https://support.microsoft.com/en-us/topic/october-17-2022-kb5020435-os-builds-19042-2132-19043-2132-and-19044-2132-out-of-band-243f34de-2f44-4015-a224-1b68a4132ca5
