Description

The /var/log/tmm file is flooded with messages similar to below

<hostname> notice CEC: Decrypted QUIC AND PARSED DATA

<hostname> notice CEC: Decrypted QUIC AND PARSED DATA

 

You may observe a TMM core due to SIGABRT

Environment

BIG-IP PEM

Cause

These messages are a side effect of fixing a related QUICK issue. This verbose logging can cause TMM to miss heartbeats and get terminated by sod process.

Recommended Actions

Download and install the DPI-LatestSignatureFile classification update package from the MyF5 site to stop the messages.
