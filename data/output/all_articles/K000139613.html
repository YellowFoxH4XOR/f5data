Description

When you review documentation for OWASP and how it applies to Advanced WAF (AdvWAF) there are currently 2 articles that apply. But there is a difference in how that application takes place.

Environment

The group that decides on what is included in the OWASP Top 10 updates it yearly. In the 2023 version API usage was added.

  • There are 2 pertinent F5 Articles:
    • K45215395: Guide introduction and contents | Secure against the OWASP Top 10 for 2021
    • K000135973: Guide Introduction and contents | APIs and the OWASP Top 10 guide (2023)
  • Web Applications, API's
  • AdvWAF OWASP Dashboard
  • License needed for part of the API OWASP.

Cause

The AdvWAF OWASP Dashboard is only updated when it is decided there is a need to. At this point it only reflects the 2021 OWASP Top 10.

There is no separate dashboard for API or one that includes it with the current one. The guidance given, via the article above, is so you can configure and show that the AdvWAF is set to meet those standards through the configuration needed to do so. But it will not reflect in the OWASP Dashboard.

If APIs are involved then a decision will need to be made as to whether you want to purchase/register Leaked Credential Check. Starting in BIG-IP 16.1.x, you can configure the BIG-IP Advanced WAF/ASM system to match presented credentials to the known leaked credentials dictionary provided by Cloud Security Services such as Blackfish Credential Stuffing Service

Recommended Actions

  1. If you purchase the Credential Check reviewing the following articles will help:
    1. K18650749: Configuring brute force attack protection (13.1.0 and later) 
    2. K000135769: Broken authentication| APIs and the OWASP Top 10 guide (2023)
    3. Manual : F5 Leaked Credentials Check Implementation Guide
    4.  K000136066: Things to know about the Leaked Credential Check

Additional Information

The short of it is no you do not need the Credential Check to get the standard OWASP dashboard to show all 10's, as the dashboard only applies to the 2021 list. If you have API's that need to need to meet the OWASP Top 10 then you would need to purchase the Leaked Credential Check if you want to use the credential stuffing blocking that AdvWAF provides to meet what is in that section of the 2023 OWASP for APIs.
