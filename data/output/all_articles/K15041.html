Topic

You can use this F5 supported iApp template to configure availability, encryption, and remote access for VMware View and Horizon View. This template configures the BIG-IP LTM, BIG-IP APM, and BIG-IP AFM for environments using security servers in conjunction with connection servers or connection servers only.

Note: F5 Application Services Templates (FAST) are replacing iApp templates; however, moving forward, F5 continues to support and maintain the iApp f5.vmware_view.v1.5.7 and later. For more information, refer to K13422: F5 supported and F5 contributed iApp templates.

The iApp provides multiple ways of deploying the BIG-IP system with View. Specifically, if View is deployed with View Security Servers, the BIG-IP system can further protect, monitor, and load balance these servers, allowing PC-over-IP (PCoIP) Security Gateway services to be moved out of the DMZ. If only View Connection Servers are used, the BIG-IP LTM system can protect, monitor, and load balance those connection servers to provide greater reliability and more predictable scaling.

For instructions about using this template and configuring your VMware View or Horizon View environment, refer to Deploying F5 with VMware View and Horizon View. You can download the latest deployment guide.

To download and install the iApp template, perform the following procedures:

  • Download the iApp template
  • Install the iApp template

Download the iApp template

Important: You must download the file; do not copy and paste the contents.

  1. Go to the MyF5 Downloads site.
  2. Read the End User Software License Agreement and Program Terms and accept the license by checking the box and selecting Next.
    Note: After you accept the End User Software License Agreement, the system does not present the agreement again for subsequent downloads that you perform during the same browser session.
  3. From the Select a product family drop-down menu, select BIG-IP.
  4. From the Product Line drop-down menu, select iApp-Templates.
  5. Select the iApp zip file iapps-1.0.0.xxx.x.zip.
  6. Select a download location from the drop-down menu.
  7. Select the Download button.
    Note: Some browsers save the file to a default location. You can review your specific browser's documentation to change the default location of where you want to save files.
  8. Repeat the procedure from step 5 for iapps-1.0.0.xxx.x.zip.md5
  9. Use a tool on your workstation to compare the MD5 hash of the zip file with the .md5 file.

Install the iApp template

  1. Unzip the zip file to a location accessible from your BIG-IP system.
  2. Log in to the Configuration utility.
  3. From the iApp tab, select Templates.
  4. Click Import.
  5. Select the Overwrite Existing Templates check box.
  6. Click Browse.
  7. Browse to the location where you saved the iApp file.
  8. Select the file named f5.vmware_view.vx.x.x.tmpl that corresponds to the iApp version you want to install. For example, the file named f5.vmware_view.v1.5.9.tmpl
    Note: Refer to the previously mentioned Support Matrix to select the most current supported template for your BIG-IP software version.
  9. Click Upload.

When the upload completes, the iApp is available for use.
