K000090238: APP_PROTECT failed to get compilation status

Type
Support Solution
Published
2021-08-18
Updated
2024-04-03
Source
https://my.f5.com/manage/s/article/K000090238

Description

You may encounter the following error when running NGINX APP_PROTECT. Especially in a cloud environment:
==> /var/log/nginx/error.log <==
2021/05/12 15:58:30 [notice] 13958#13958: APP_PROTECT { "event": "configuration_load_start", "configSetFile": "/opt/app_protect/config/config_set.json" } 2021/05/12 15:58:30 [error] 13958#13958: APP_PROTECT failed to get compilation status

Environment

  • NGINX App Protect
  • Cloud

Cause

This error can be caused by insufficient memory on the Linux system to run APP_PROTECT.
The following conditions are met:

  1. There is no swap memory configured.
  2. The physical memory is less than 4 GB.

Recommended Actions

  1. Provision swap for the Linux system.
  2. Give the Linux system at least 5.25 GB of physical memory.

Additional Information

None
