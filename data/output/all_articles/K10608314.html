Known Issue

Some topology records may fail to synchronize.

This issue occurs when all of the following conditions are met:

  • Multiple BIG-IP DNS (formerly known as BIG-IP GTM) systems are configured in a sync group.
  • Configured topology records have overlapping subnet specifiers, such as 1.0.0.0/8 and 1.0.0.0/9.

Impact

DNS sync group members have incomplete sets of topology records, so returned DNS answers may differ from expected values.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Some DNS topology records are not synchronized to other devices in the sync group.

Workaround

To work around this issue, you can run the config-sync force-full-load-push command to force a push of all DNS objects. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Push changes to all units within the sync group by typing the following command:

    run cm config-sync force-full-load-push to-group gtm

  3. Confirm you want to force a full load sync.
