Issue

Error Message

Error Message: err sod[<PID>]: 010c003b:3: bind fails on <function> <IP address> port <port> error <message>

In this error message, note the following:

  • <PID> is the process ID for the sod process.
  • <function> is the operation being performed.
  • <IP address> is the IP address configured as the source failover address on the local system.
  • <port> is the port number.
  • <message> is the specific error message.

For example, there are sample values in the following error message:

err sod[3307]: 010c003b:3: bind fails on send_sock_fd addr 192.168.0.1 port 0 error Cannot assign requested address.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The defined failover IP address references a non-existent self IP address.

This may occur when the system is booting up and trying to load the configuration. The system logs this message when the sod process tries to bind to a self IP address that was not loaded to the configuration.

Impact

Failover does not work as expected.

Recommended Actions

On the BIG-IP system generating the error message, on the local and peer systems, configure both self and management IP addresses as the failover addresses. To do so, perform the following procedure:

Impact of workaround: The impact of the suggested workaround will depend on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.

For more information about failover and configuring failover addresses, refer to the Managing Failover chapter of the BIG-IP LTM: BIG-IP Device Service Clustering: Administration manual.

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

BIG-IP 13.0.0 and later

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Devices.
  3. Click the name of the device.
  4. Click the Failover Network tab.
  5. Click Add.
  6. In the Address list, click the Management Address.
  7. Click Finished.
  8. If you did not configure a self IP address, do the following:
    1. Click Add.
    2. In the Address list, click an appropriate self IP address, and then click Finished.
  9. Configure management and self IP addresses as failover addresses on the peer device as well.

BIG-IP 11.x - 12.x

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Devices
  3. Click the name of the device.
  4. Point to the Device Connectivity tab, and then click Network Failover.
  5. Click Add.
  6. In the Address list, click the Management Address.
  7. Click Finished.
  8. If you did not configure a self IP address, do the following:
    1. Click Add.
    2. In the Address list, click the appropriate self IP address, and then click Finished.
  9. Configure management and self IP addresses as failover addresses on the peer device as well.
