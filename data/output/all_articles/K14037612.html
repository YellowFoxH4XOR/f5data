Known Issue

You may be unable to import an access profile configured with User-defined ACLs.

This issue occurs when all of the following conditions are met:

  • You create an access profile that references User-defined ACLs.
  • There is a User-defined ACL with the Acl Order of 0 (zero).
  • You export the access profile.
  • You attempt to import the access profile.

Impact

When you import the access profile, the system produces an error and the import fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to import the access profile, you may observe an error similar to the following example:

    Import Error: Syntax Error:(/shared/tmp/import/<temporary import file name>.conf at line: 3) "acl-order" may not be specified more than once; Validating configuration...

  • Imports function as expected when you import access profiles that are configured with User-defined ACLs that do not include an ACL with the Acl Order of 0 (zero).
