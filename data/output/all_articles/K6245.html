K6245: Messages in the /var/log/tmm log file are not time-stamped

Source

Known Issue

This is the result of a known issue. The tmm process logs messages directly to the /var/log/tmm file, rather than passing messages through the syslog utility. As a result, messages in the /var/log/tmm file are not time-stamped, which can make troubleshooting difficult.

F5 Product Development tracked this issue as CR47845 and CR56011 and it was fixed in BIG-IP LTM 9.1.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.
