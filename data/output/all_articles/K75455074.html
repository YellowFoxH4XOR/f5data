Published

Status
Legacy Content
Applies to

Source

Description
When restjavad stops working it can cause issues with RestApi / iControl

Specifically this error message:
Response write attempt failed: java.io.IOException: Failed to send GET

Environment

  • LTM 12.1.3
  • 10200V-F Hardware

Cause
Unknown at time of publication.

Recommended Actions

Restart the restjavad daemon
  1. bigstart restart restjavad
