Description

When trying to send schedule reports to AWS SES service, the server is not able to process the request and you can see an error similar to:

 Could not send e-mails: SMTP Error: data not accepted.; Transaction failed: Expected MIME type, got ;; Error code: 554

Environment

  • Schedule Reports
  • AWS SES service
  • SMTP
  • AVR

Cause

This error is being caused due to AWS services do not accept empty Content-Type headers.

X-Mailer: BIG-IP by F5 Networks, Inc.
MIME-Version: 1.0
Content-Type: multipart/mixed;
boundary="b1_86628c78a8af79826a0a4e301d5f59a0"
Content-Transfer-Encoding: 8bit
This is a multi-part message in MIME format.
--b1_86628c78a8af79826a0a4e301d5f59a0
Content-Type: ; charset=us-ascii   <<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<< Content-Type empty

Recommended Actions

To work around this, you can perform the following:

1. Grant permissions to the user to modify the file /var/ts/dms/script/avrexport/avrmail.php     
     # chmod u+w /var/ts/dms/common/classes/class.phpmailer.php

2. Open the file with vi and go to the line 129 approximately            
     # vi /var/ts/dms/script/avrexport/avrmail.php
     Once you are in vi types ":129" to go to that line
     Add the following lines 
???????           if (!$mail_content_type)  $mail_content_type = 'text/html';

3. The new code should look like the following example      
    /********** get subject and body, if exist ***************/
     $mail_content_type = (string)$xml->content_type; /* If not specified a default text/plain will be used by class.phpmailer.php */
     if (!$mail_content_type)  $mail_content_type = 'text/html';
     $mail_subject = (string)$xml->subject;

4. Navigate to Security > Reporting > Scheduled Reports.

5. Select the report(s) for which you want to send an email.

6. Click Send Now
