Topic

F5 manufactures and ships two different SFP optics that look identical in size and shape: the one gigabit SFP and 10 gigabit SFP+ modules. You can identify the modules by information located on the top of the SFP module.

You can identify the 1 gigabit modules by looking for the following information:

Module Number: OPT-0010-00 1.25Gig, 850nm, 550m

Module Number: OPT-0011-00 1.25Gig, 1310nm, 10km

  • 1.25Gig specifies a 1 gigabit module
  • nm specifies the laser wavelength
  • m/km specifies the maximum operating distance

You can identify the 10 gigabit modules by looking for the following information:

Module Number: OPT-0016-00 10Gig, 850nm, 300m

Module Number: OPT-0017-00 10Gig, 1310nm, 10km

  • 10Gig specifies a 10 gigabit module
  • nm specifies the laser wavelength
  • m/km specifies the maximum operating distance

To view the interface maximum capabilities of the installed media of the platform, use the following tmsh command:

tmsh list net interface media-max

The command output display appears similar to the following example:
