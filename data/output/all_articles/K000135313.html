K000135313: How to get the Virtual Server state using SNMP polling via the Virtual Server name

Type
Support Solution
Published
2023-07-27
Updated
2023-07-27
Applies to
  • BIG-IP
  • BIG-IP LTM: 12.1.5
Source
https://my.f5.com/manage/s/article/K000135313

Description

You want to poll the F5 using SNMP for a specific Virtual Server state, filtering by the Virtual Server name.

Environment

  • BIG-IP
  • SNMP Server v1, v2c, v3

Cause

None.

 Recommended Actions

1. Log in to the command line
2. Determine the OID of the Virtual Server in question by running the command below.

# snmpwalk -v 2c -c public localhost F5-BIGIP-LOCAL-MIB::ltmVsStatusAvailState.\"<Virtual Server partition and name>\" -On

Example:

# snmpwalk -v2c -c public localhost F5-BIGIP-LOCAL-MIB::ltmVsStatusAvailState.\"/Common/VIP-HTTPS\" -On

Output:

.1.3.6.1.4.1.3375.2.2.10.13.2.1.2.17.47.67.111.109.109.111.110.47.86.73.80.45.72.84.84.80.83 = INTEGER: blue(4)

3. You can double-check if it is the correct Virtual Sever with the command below.

# snmptranslate -Td <OID>

Example:

# snmptranslate -Td .1.3.6.1.4.1.3375.2.2.10.13.2.1.2.17.47.67.111.109.109.111.110.47.86.73.80.45.72.84.84.80.83

Output:

F5-BIGIP-LOCAL-MIB::ltmVsStatusAvailState."/Common/VIP-HTTPS"

ltmVsStatusAvailState OBJECT-TYPE

 -- FROM      F5-BIGIP-LOCAL-MIB

 SYNTAX       INTEGER {none(0), green(1), yellow(2), red(3), blue(4), gray(5)}

 MAX-ACCESS   read-only

 STATUS       current

<...>

4. Now use the specific OID to check the state of the VS.

Additional Information

None.
