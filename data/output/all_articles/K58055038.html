Description

There are applications that use unicode characters that are not mapped as allowed by the ASM JSON parser, hence the ASM identifies properly formatted JSON data as malformed.

Detected Violations:
Malformed JSON data

Environment

  • ASM security policy
  • JSON content profile
  • Valid unicode character in JSON data
  • Detected Violations: Malformed JSON data
  • Request body is valid JSON formatting

Cause

Recommended Actions

Enable the relax_unicode_in_json internal parameter.

Impact of workaround: Performing the following procedure forces the BIG-IP system offline for a short period of time. F5 recommends that you perform this procedure during a maintenance window.
  1. Connect to CLI
  2. Enable relax_unicode_in_json
    /usr/share/ts/bin/add_del_internal add relax_unicode_in_json 1
  3. Restart ASM
    bigstart restart asm

Additional Information

relax_unicode_in_json: The default is 0. When the value is changed to 1, a bad unicode character does not produce a JSON malformed violation. A bad unicode character might be a legal unicode character that does not appear in the mapping of the system's JSON parser.

If there are any code points that should be added to the ASM JSON parser, please open a service request and submit a request for consideration.
