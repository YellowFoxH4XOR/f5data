Topic

A BIG-IP system is subject to limitations in the number of objects that may be configured when the configuration contains virtual servers for which Packet Velocity ASIC (PVA) acceleration is required. If more than the specified maximum number of objects is configured, virtual servers which otherwise qualify for PVA acceleration are demoted to wire mode (no PVA acceleration).

Note: To determine whether the system is equipped with a PVA chip, and to determine the relevant version of the chip, refer to K4832: Overview of Packet Velocity ASIC Acceleration, or the Platform Guide for your BIG-IP platform.

Pva.Lbdb.Vso

Note: Each virtual server requires one Pva.Lbdb.Vso entry and two Pva.Listeners.Dest.MaxEntries. You may increase the Pva.Lbdb.Vso DB key value in increments of 1024. When you increase the Pva.Lbdb.Vso DB key value, you must also increase the Pva.Listeners.Dest.MaxEntries DB key value in increments of 2048, up to the maximum value of 16384. For example, to support the maximum of 8192 virtuals, increase Pva.Lbdb.Vso to 8192 and PVA.Listeners.Dest.MaxEntries to 16384.
