Known Issue

The BIG-IP system may fail to establish a connection to Border Gateway Protocol (BGP) neighbors.

This issue occurs when all of the following conditions are met:

  • You license and enable the BGP BIG-IP Advanced Routing Module (ARM) on one of the following platforms:

    • BIG-IP 2000 series
    • BIG-IP 4000 series
  • You configure the BIG-IP system as a BGP peer with upstream routers.
  • You enable MD5 authentication for TCP connections between BGP neighbors.

Impact

The BIG-IP system fails to establish a connection to BGP neighbors.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When MD5 authentication for TCP connections between BGP neighbors is enabled, you notice that:

    • The BIG-IP system fails to establish connections to BGP neighbors.
    • The output from the show ip bgp neighbor command lists the BGP neighbor state as Active.
    • A packet trace reveals the BIG-IP system is sending RST packets in response to SYN/ACK packets from BGP peers.
