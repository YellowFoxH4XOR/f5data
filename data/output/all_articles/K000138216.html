Description

The GUI starts broadcasting these messages:

 

Got exception while handling EM auth token request: Invalid Certificate: Could not open certificate file: "/shared/em/ssl.crt/<<HA Pair's IP>>.crt": No such file or directory, referer: http://localhost:8100/tm/shared/bigip-failover-state

 

The same error appears in the /var/log/httpd/httpd_errors logfile

 

Environment

  • Restjavad database
  • Certificate missing
  • HA Failover.

Cause

At the time of publication, why the certificate goes missing is not known.

Recommended Actions

1. In the HA pair device's CLI, verify if the certificate exists

ls -ltr /shared/em/ssl.crt/*

 

2. If the certificate exists in the HA Pair, use the SCP command to copy it to the device where it is missing. This will stop the logging.

cd /shared/em/ssl.crt/

scp /shared/em/ssl.crt/<<IP>>.crt root@<<IP of the device where the certificate is missing>>:/shared/em/ssl.crt/
