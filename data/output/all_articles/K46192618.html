Issue

Error Message

notice zxfrd[<PID>]: 01531300:5: Cluster status changing from <status> to <status>

In this error message, note the following:

  • <PID> is the process ID for the zxfrd process
  • <status> is the cluster status of the blade

For example:

notice zxfrd[9872]: 01531300:5: Cluster status changing from Primary to Secondary.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The DNS Express zone transfer daemon (zxfrd) detected that the cluster status changed.

The primary blade in the cluster performs zone transfers. If the blade transitions to secondary status, the zxfrd process on the primary blade can begin performing zone transfers.

Impact

Zone transfers on the blade may either start or stop depending on the new cluster status.

Recommended Actions

No direct action is required by this message. However, if the cluster status change was unexpected or unintended, you should review log files for related messages in order to determine the cause.
