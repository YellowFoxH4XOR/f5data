K42550866: GUI is working very slowly

2022-04-27

Status
Legacy Content
Applies to
  • BIG-IP
Source

Description

GUI access slow after upgrade and then later even after downgrading it was the same issue


Environment

  • Configuration Utility
  • GUI Access

Cause

The BIG-IP system generates messages to the /var/log/httpd/httpd_errors file that appear similar to the following example:

err httpd[<PID>]: [error] (111)Connection refused: proxy: AJP: attempt to connect to 127.0.0.1:8009 (*) failed
err httpd[<PID>]: [error] proxy: AJP: failed to make connection to backend: localhost

Recommended Actions

bigstart restart tomcat
bigstart restart httpd

None
