Known Issue

The Traffic Management Microkernel (TMM) plug-in manager displays repeated client initialization messages and leaks memory.

The exact conditions are unknown; however, the memory leak rarely occurs.

Impact

TMM plug-in manager leaks memory and eventually shuts down.

Symptoms

As a result of this issue, you may encounter one or both of the following symptoms:

  • The TMM plug-in manager displays repeated client initialization messages.
  • The TMM plug-in manager displays an out-of-memory message.
