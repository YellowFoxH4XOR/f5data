Known Issue

This is the result of a known issue. The BIG-IP system will drop an ICMP ping sent from a non-local source address through a forwarding virtual server with a lasthop pool configured.

Note: This behavior only affects ICMP traffic; this behavior affects both IPv4 and IPv6 ICMP pings.

This behavior occurs when all of the following conditions are met:

  • No routes are configured
  • The autolasthop setting is disabled
  • The forwarding virtual server is configured with a lasthop pool

F5 Product Development tracked this issue as CR108984 and it was fixed in BIG-IP LTM 9.4.7 and 10.0.0. For information about upgrading, refer to the BIG-IP LTM Release Notes.
