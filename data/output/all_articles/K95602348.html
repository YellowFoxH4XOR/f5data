Environment

  • BIG-IP software upgrade

Cause

The cause of the installation failure was a failure to dismount some mount points which are temporarily used during the installation process.

Recommended Actions

  1. Follow the K13030 and force the mcpd process to reload the BIG-IP configuration.
  2. Then reboot the BIG-IP system. 

Additional Information

On F5OS-C Tenants, if the Recommended Actions do not resolve the problem, then the problematic software volume needs to be deleted in order to resume the installation.
