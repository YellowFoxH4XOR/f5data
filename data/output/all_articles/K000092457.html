Description

F5 Support may ask you to download a core file from your BIG-IP Next instance and upload the file to F5.

Environment

  • BIG-IP Next instance
  • You are using the REST API directly

Prerequisite procedures

  • How to log in to the BIG-IP Next REST API
  • Exchange files with F5 Support

Procedure

Procedure 1 - list the core files

Log in to the BIG-IP Next instance and obtain a REST token. You use the REST token to authenticate to the BIG-IP Next instance when sending commands. For more information about logging in to the BIG-IP Next instance REST API, refer to How to log in to the BIG-IP Next REST API .

Obtain the system ID

curl -sk -H "Authorization: Bearer $TOKEN" https://10.10.10.10:5443/api/v1/systems | jq
{
  "_embedded": {
    "systems": [
      {
        ...,
        "id": "5d4b1d42-d409-83a9-935c-2f978302b1be", <===
        "machineID": "5d4b1d42-d409-83a9-935c-2f978302b1be",
        ...,
        "platformType": "ve"
      }
    ]
  },
  "_links": {
    "self": "/systems?"
  },
  "count": 1,
  "total": 1
}

Save the ID to a SYSTEMID environment variable.

Obtain the list of core files

curl -sk -H "Authorization: Bearer $TOKEN" https://10.10.10.10:5443/api/v1/systems/$SYSTEMID/cores | jq
{
  "count": 2,
  "total": 2,
  "_embedded": {
    "cores": [
      "/api/v1/systems/5d4b1d42-d409-83a9-935c-2f978302b1be/cores/core.f5-fsm-tmm-6987fcbd57-67gzg.tmm.0.v6.96.1-0.0.3.1665696539.gz",
      "/api/v1/systems/5d4b1d42-d409-83a9-935c-2f978302b1be/cores/core.f5-fsm-tmm-6987fcbd57-67gzg.tmm.0.v6.96.1-0.0.3.1665696539.gz.crc"
    ]
  },
  "_links": {
    "_self": "/api/v1/systems/5d4b1d42-d409-83a9-935c-2f978302b1be/cores"
  }
}

Each file listed in the "cores" array is a file path to download the core file and the .crc file.  

Procedure 2 - download the core file

Download the core file.  The "-O" curl parameter tells curl to save the response to a file.

curl -sk -H "Authorization: Bearer $TOKEN" https://10.10.10.10:5443/api/v1/systems/$SYSTEMID/cores/core.f5-fsm-tmm-6987fcbd57-67gzg.tmm.0.v6.96.1-0.0.3.1665696539.gz -O

Do the same for the .crc (the checksum) file.

curl -sk -H "Authorization: Bearer $TOKEN" https://10.10.10.10:5443/api/v1/systems/$SYSTEMID/cores/core.f5-fsm-tmm-6987fcbd57-67gzg.tmm.0.v6.96.1-0.0.3.1665696539.gz.crc -O

Procedure 3 - verify the checksum of the core file

The .crc file is a sha512 hash of the core file.  Use this to ensure that the core file is not corrupt.

sha512sum core.f5-fsm-tmm-6987fcbd57-67gzg.tmm.0.v6.96.1-0.0.3.1665696539.gz

Compare the output of the sha512sum command with the contents of the .crc file and ensure they are identical.  If they are not identical, you will need to download and verify the core file again.

Procedure 4 - upload the core file to F5

You can do this by following Exchange files with F5 Support
