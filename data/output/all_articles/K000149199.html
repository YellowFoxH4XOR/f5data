Description

Deploying a BIG-IP VE in Azure China regions fails with an error message:

The offer with Offer ID 'f5-big-ip-byol' was not found.

Environment

  • Azure
  • China regions

Cause

F5 BIG-IP Virtual Edition (VE) images are not available in the Azure Marketplace for China.

Recommended Actions

You will need to follow the steps in the documentation page F5 BIG-IP Virtual Edition Without Azure Marketplace Access to upload a BIG-IP VE VHD image to an Azure storage account. You will then be able to reference the uploaded image in your ARM template.
