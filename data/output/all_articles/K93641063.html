Issue

Error Message

mcpd[<PID>]: 01070604:3: Cannot delete IP <IP_address> because it would leave a route unreachable.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process
  • <IP_address> is the self IP address that you want to delete

For example:

mcpd[5422]: 01070604:3: Cannot delete IP 10.10.10.10%2 because it would leave a route unreachable.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • You configure a route on the BIG-IP system that is only reachable from a single self IP address.
  • You attempt to delete the self IP address.

Impact

You are unable to delete the self IP address until you remove all routes that depend on the IP address.

Recommended Actions

None
