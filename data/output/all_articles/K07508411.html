Description

You are seeing ssl_shim_vfycerterr errors in /var/log/ltm

warning tmm1[13412]: 01260009:4: Connection error: ssl_shim_vfycerterr:4539: application verification failure (46)

Environment

  • BIG-IP LTM
  • Virtual Server
  • Client SSL Profile
  • LTM log file

Cause

This error is generated when a client attempts an SSL connection to a virtual server with the Client SSL profile configured to request peer certificate.

Recommended Actions

There are three options to address these messages:
  • Correct the issue that is causing the client or clients to send an empty SSL certificate to the BIG-IP
  • Review Client SSL and disable the client certificate option if not required Note: See Related Content
  • Raise logging threshold to prevent logging of warning level messages Note: See Related Content
