K36024485: BIG-IP APM Users cannot connect to VPN after upgrading to 13.X from 11.X

Description
After upgrade of your BIG-IP APM system users attempting to establish a VPN access session receive a TCP reset when initiating a connection to the VPN virtual server. When viewing the virtual server configuration, the virtual server is set to disabled though the virtual server configuration prior to upgrading was set to enabled. Attempting to configure the virtual server as enabled produces an error message similar to the following:
 
Configuration error: Virtual server (/<partition>/<virtual>) with access profile attached has traffic group (/<partition>/<traffic group name>)that is different from existing one (/<partition>/<traffic group name>)

Note: <partition> is the partition name of where the virtual server is configured, <virtual> is the name of the affected virtual server.
 

Environment

  • The BIG-IP APM virtual server for VPN access is configured with an IP address that is also configured as a self IP.
  • You upgrade the BIG-IP APM from version 11.x to version 13.x.

Cause
During the upgrade process a configuration IP address conflict was identified and the virtual server was set to disabled.

Recommended Actions

Implement one of the following configuration changes:
  • Change the self IP address to a unique IP address.
  • Change the virtual server IP address to a unique IP address.
