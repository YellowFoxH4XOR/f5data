Known Issue

iRules in administrative partitions other than /Common may stop functioning.

This issue occurs when one of the following conditions are met:

  • The configuration is loaded using tmsh load /sys config.
  • The configuration is loaded by way of a ConfigSync.

You may create iRules in administrative partitions other than /Common. When the configuration is loaded from a ConfigSync or using the tmsh command tmsh load /sys config, only the iRules configured in the /Common partition are loaded into TMM. While the iRules configured in other administrative partitions may still appear in the Configuration utility, the iRules cannot be referenced by TMM and will no longer function.

Impact

iRules in partitions other than /Common may stop functioning properly.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • iRules in partitions other than /Common cease to function.
  • Virtual servers using affected iRules may drop traffic or not process traffic properly.

Workaround

To work around this issue, you can either load the configuration in all partitions using the tmsh utility or update the affected iRules using the Configuration utility. To do so, perform one of the following procedures:

Loading the configuration in all partitions using the tmsh utility

To recover from or prevent this issue when loading configurations, you can load the configuration in all partitions using the following procedure:

Impact of workaround: The following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Load the configuration in all partitions by typing the following command:

    load /sys config partitions all

Updating the iRule using the Configuration utility

To recover from this issue, you can touch the affected iRules using the Configuration utility. To do so, perform the following procedure:

Impact of workaround: The following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules.
  3. Make sure you are in the correct administrative partition.
  4. Click the affected iRule.
  5. Click Update.
  6. Repeat this procedure for all affected iRules.
