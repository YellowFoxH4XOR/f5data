K43570223: Connection Mirroring may not work if devices on a HA pair have different VLAN names

Description

Connection mirroring doesn't work when trying to fail-over to the standby device, BIG-IP sends a RST packet to the client [F5RST: No flow found for ACK].
After a failover, you may observe RST. 

Environment

  • You have configured a mirroring channel on both BIG-IP in an HA Pair
  • You have enabled connection mirroring on the Virtual Server settings
  • You have different VLAN names on your primary and secondary device for the VLAN on which the traffic you want to be mirrored

Cause

You have different VLAN names (in Primary and Secondary) on the VLAN which you want to mirror traffic (ex. external vlan)

Working Scenario: Same VLAN Name

Example Client IP = 10.0.0.10
Example Virtual Server IP = 10.1.0.200

Active Unit:

  0.000000    10.0.0.10 -> 10.1.0.200   HTTP 88 Continuation or non-HTTP traffic
  0.000025    10.0.0.10 -> 172.16.0.10  HTTP 88 Continuation or non-HTTP traffic
  0.000029   10.1.0.200 -> 10.0.0.10    TCP 85 80 > 40886 [ACK] Seq=1 Ack=4 Win=4446 Len=0
  0.001289  172.16.0.10 -> 10.0.0.10    TCP 85 80 > 40886 [ACK] Seq=1 Ack=4 Win=14600 Len=0

Standby Unit:

  0.000000    10.0.0.10 -> 10.1.0.200   HTTP 88 Continuation or non-HTTP traffic             <--- Standby receives Client Response.
  0.000011  172.16.0.10 -> 10.0.0.10    TCP 85 80 > 40886 [ACK] Seq=1 Ack=1 Win=14600 Len=0  <--- Standby receives Server Response.

Not Working Scenario: Different VLAN Name

Active Unit:

  0.000000    10.0.0.10 -> 10.1.0.200   HTTP 88 Continuation or non-HTTP traffic
  0.000043    10.0.0.10 -> 172.16.0.10  HTTP 88 Continuation or non-HTTP traffic
  0.000053   10.1.0.200 -> 10.0.0.10    TCP 85 80 > 40888 [ACK] Seq=1 Ack=4 Win=4389 Len=0
  0.001812  172.16.0.10 -> 10.0.0.10    TCP 85 80 > 40888 [ACK] Seq=1 Ack=4 Win=14600 Len=0

Standby Unit

  0.000000  172.16.0.10 -> 10.0.0.10    TCP 65 80 > 40888 [ACK] Seq=1 Ack=1 Win=14600 Len=0   <--- Standby receives Server Response only. Next client request will be RST.

Recommended Actions

Change the VLAN names to match on both primary and secondary BIG-IP.
