K000092370: VE subscription license key status shows "ready to activate" on MyF5 portal

Type
Support Solution
Published
2022-12-07
Updated
2023-01-26
Source
https://my.f5.com/manage/s/article/K000092370

Description

VE subscription license key status shows "ready to activate" on MyF5 portal.

Environment

  •     VE subscription license
  •     MyF5

Cause

The license key has not been assigned / activated since the subscription started, or the license key has been revoked / released / Allow-moved.

Recommended Actions

Ready to Activate is a valid status that allows you to activate your license to your VE.

You can now proceed to activate the license on the BIG-IP system by using the Configuration utility, you can use either the automatic activation method or the manual activation method. Refer this article https://support.f5.com/csp/article/K7752 for more details.
