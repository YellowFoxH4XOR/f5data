K000158961: SSL handshake failures on BIG-IP LTM virtual server when a client presents a full certificate chain.

Type
Support Solution
Published
2026-01-01
Updated
2026-01-01
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000158961

Description

SSL handshake failures can happen on BIG-IP LTM when the client SSL profile is set up for client certificate authentication, and the CA file used for validation contains duplicate certificates. These duplicates causes the BIG-IP to fail SSL handshakes when a client presents a full certificate chain.

Environment

  • BIG-IP LTM

  • Client SSL profile requiring client certificate authentication

  • CA file for client certificate validation contains duplicate CA certificate entries

Cause

Duplicate CA certificate entries in the CA file used for client certificate validation in the client SSL profile causes SSL handshake failures when a client presents a full certificate chain.

Recommended Actions

  • Remove duplicate CA certificate entries from the CA file used in the client SSL profile.

  • Validate SSL handshake functionality after updating the CA file.

  • Monitor for recurrence and revalidate after future certificate updates.
