Description

NGINX ONE Subscription information

Environment

  • Nginx Plus R33

Cause

Functional questions about new product name in Subscription and Licensing: NGINX ONE

Recommended Actions

NGINX One is both the SaaS console, as well as the bundle name for the NGINX bundles.  You may see this bundling referred to as "packaging" sometimes.  The products inside the bundles are the same products. So, because NGINX One is not a new binary or replacement for NGINX Plus, you can download and use the same license as you did for Nginx Plus, and install that license the way you did for Nginx Plus, but now you actually get access to the NGINX One console that runs in F5 Distributed Cloud. 

Additional Information

Also with R33, you will need the JWT token. You can download it from the MyF5 portal under downloads.
