Known Issue

The forward iRule command may fail to forward connections as expected.

This issue occurs when all of the following conditions are met:

  • An iRule using forward commands is associated with a virtual server.
  • The virtual server is also configured to use a pool.

Impact

Connections are routed to pool members instead of being forwarded to the expected destination as specified by the forward iRule command.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Virtual server connections are routed to pool members instead of being forwarded by the forward iRule command to the destination determined by network routes.

Workaround

To work around this issue, you can remove the pool association from the virtual server and then reconfigure the iRule to select the pool with a pool command when the forward command is not issued.

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.
