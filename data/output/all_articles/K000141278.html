K000141278: How to display the CPU/Memory usage split between host and tenant on F5OS-A

Source

Description

You are on an rSeries r2000 or r4000 appliance which uses the same CPU cores to run the F5OS host and the BIG-IP tenant and want to distinguish between the percentage of CPU time used by each.

Environment

  • F5OS-A
  • rSeries r2000 and r4000 appliances

Cause

None

Recommended Actions

The F5OS WebUI Dashboard and the show components component cpu state CLI command both only show the combined total host and tenant CPU usage.

To separate out the CPU percentage dedicated to the F5OS host, you can either:

  • Monitor the CPU usage on the tenant and subtract it from the utilisation shown in F5OS to know how much of the CPU usage can be attributed solely to F5OS.

Or

  • You can use the command systemd-cgtop to show a split of CPU usage between the configured cgroups:

[root@appliance-1(R2600-F5OS-A) ~]# systemd-cgtop --depth 1
Path           Tasks      %CPU      Memory      Input/s      Output/s

 /             244        304.1     4.0G        -            -
 /kubepods     -          150.0     1.0G        -            -
 /system.slice -          145.8     2.8G        -            -

BIG-IP tenants run under Kubernetes and their CPU usage will be accounted for in the /kubepods cgroup.

The cgroup with path "/" is roughly equivalent to total CPU usage, "/kubepods" is roughly equivalent to BIG-IP tenant usage and "/system.slice" is roughly equivalent to F5OS host usage.

Note: The systemd-cgtop command displays the top Linux control groups on the system, ordered by their CPU, memory, or disk I/O usage. The systemd-cgls command can be used to view the Linux control group heirarchy. For more information, refer to the following links:

  • https://www.freedesktop.org/software/systemd/man/latest/systemd-cgtop.html
  • https://www.freedesktop.org/software/systemd/man/latest/systemd-cgls.html

These links take you to a resource outside of MyF5. The third party could remove the documents without our knowledge.
