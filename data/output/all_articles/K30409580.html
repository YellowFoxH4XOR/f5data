K30409580: Unable to view System > File Management : SSL Certificate List

Type
Support Solution
Published
2019-10-07
Updated
2023-02-21
Status
Legacy Content
Applies to

  • BIG-IP LTM: 12.1.1, 12.0.X, 12.1.0, 12.0.0
Source
https://my.f5.com/manage/s/article/K30409580

Description

A certificate that contains a duplicate .crt extension in the name may cause an error which prevents the ssl certificate list from loading.

Example:

sys file ssl-cert /Common/mycertificate.crt.crt {
    cache-path /config/filestore/files_d/Common_d/certificate_d/:Common:mycertificate.crt.crt_44639_1
    revision 1
}

Environment

  • SSL certificates
  • LTM v12.1.1

Cause

Bug ID 602502

Recommended Actions

  1. Delete such certificate through TMSH.
    Example:
    delete sys file ssl-cert /Common/mycertificate.crt.crt
  2. Reimport the certificate without the ".crt" extension in the certificate name.
    K14031: Importing the SSL certificate and key using the Traffic Management Shell
 

Additional Information

When this issue occurs you may also receive an error when trying to access the SSL Certificate List in the BIG-IP GUI:

"An error has occurred while trying to process your request."


You may also receive an error in the CATALINA.OUT log file:
