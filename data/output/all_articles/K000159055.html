K000159055: BIG-IQ DDoS Dashboard Shows Aggregated Client IPs Instead of Individual Source IP Addresses

Type
Support Solution
Published
2026-01-12
Updated
2026-01-12
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.0
Source
https://my.f5.com/manage/s/article/K000159055

Description

When viewing DDoS attack data in BIG-IQ Dashboards under DDoS → HTTP Analysis, the Client IPs section displays aggregated values (e.g., "Aggregated 2.92k") instead of showing individual client source IP addresses. This prevents administrators from identifying specific attacker IP addresses during or after a DoS attack incident.

Environment

  • BIG-IQ Centralized Management version 8.4.0 or later
  • BIG-IP with DoS profile configured on virtual server
  • AVR (Application Visibility and Reporting) module provisioned on BIG-IP
  • Virtual server configured with DoS profile but without HTTP analytics profile or with HTTP analytics profile that has client IP collection disabled

Cause

By design, BIG-IQ aggregates client IP data when only a DoS profile is attached to a virtual server without an HTTP analytics profile that explicitly enables client IP collection. BIG-IP collects statistics internally for DoS decision-making but does not send individual client IP addresses to BIG-IQ unless an analytics profile with collect-ip enabled and external logging is applied to the virtual server. This behavior prevents BIG-IQ from being overwhelmed with unnecessary data unless explicitly configured to collect these statistics.

Recommended Actions

The actions or steps required to address the topic covered in the description.

1.Provision AVR module on BIG-IP (if not already enabled):

    • Navigate to System → Resource Provisioning
    • Set AVR to Nominal or higher
    • Click Submit

2.Create or modify HTTP analytics profile:

    • Navigate to Local Traffic → Profiles → Analytics → HTTP Analytics
    • Create a new profile or modify an existing one
    • Enable Collect Client IP Addresses option (collect-ip enabled)
    • Enable External Logging under Statistics Logging Type
    • Configure an appropriate External Logging Publisher
    • Click Finished

3.Apply the HTTP analytics profile to the virtual server:

    • Navigate to Local Traffic → Virtual Servers → Virtual Server List
    • Select the relevant virtual server
    • Under Configuration, select Advanced
    • In the Analytics section, select the HTTP analytics profile created in step 2
    • Click Update

4.Verify configuration via TMSH (optional):

# tmsh list /ltm profile analytics <profile_name> all-properties

5.Confirm that collect-ip enabled and collected-stats-external-logging enabled are present in the output

6.Verify individual client IP addresses now appear in BIG-IQ:

    • Navigate to Dashboards → DDoS → HTTP Analysis
    • Check the Client IPs section for individual IP addresses instead of aggregated values
