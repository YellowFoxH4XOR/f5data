Topic

This article applies to BIG-IP 10.x. For information about other versions, refer to the following article:

  • K16272: Overview of the cluster shell utility (11.x - 12.x)

The cluster shell (clsh) utility is designed to assist VIPRION system administrators when executing a command on multiple blades simultaneously.

Description

By default, the clsh utility executes a command on all active blades with a green or available status.

Default behavior

To run a command on all blades using the clsh utility, use the following command syntax:

clsh <command>

For example, to run the date command on all blades, type the following command:

# clsh date

The command output appears similar to the following example:

=== slot 2 addr 127.3.0.2 color green ===
Mon Jun  8 15:13:49 PDT 2015
=== slot 3 addr 127.3.0.3 color green ===
Mon Jun  8 15:13:49 PDT 2015
=== slot 4 addr 127.3.0.4 color green ===
Mon Jun  8 15:13:49 PDT 2015
=== slot 1 addr 127.3.0.1 color green ===
Mon Jun  8 15:13:50 PDT 2015

Skipping a blade due to status

The date command will not be executed on inactive blades with a red or offline status.

In the following example, the date command is not executed on blade 2 due to the red status:

# clsh date
=== slot 2 addr 127.3.0.2 color red ===
=== slot 3 addr 127.3.0.3 color green ===
Mon Jun  8 14:52:43 PDT 2015
=== slot 4 addr 127.3.0.4 color green ===
Mon Jun  8 14:52:43 PDT 2015
=== slot 1 addr 127.3.0.1 color green ===
Mon Jun  8 14:52:43 PDT 2015

Targeting a specific blade or blades

To run a command on a specific blade, or blades, regardless of status, use the following command syntax:

# for i in <blade_1> <blade_2>; do ssh slot$i <command>; done

For example, to run the date command on blades 2 and 3 only, regardless of status, type the following command:

# for i in 2 3; do ssh slot$i date; done

The command output appears similar to the following example:

Tue Jun  9 10:30:37 PDT 2015
Tue Jun  9 10:30:37 PDT 2015

To run the date command on all four blades in a chassis, regardless of status, type the following command:

# for i in 1 2 3 4; do ssh slot$i date; done

The command output appears similar to the following example:

Tue Jun  9 10:30:37 PDT 2015
Tue Jun  9 10:30:37 PDT 2015
Tue Jun  9 10:30:37 PDT 2015
Tue Jun  9 10:30:37 PDT 2015

Recommendations

To obtain blade status prior to running the clsh utility, type the following command:

# bigpipe cluster

The command output appears similar to the following example:
