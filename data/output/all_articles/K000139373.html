K000139373: Virtual Server continues to listen on port or address list after the is removed from the virtual server in GUI

Type
Support Solution
Published
2024-04-23
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000139373

Description

When having a performance (fast l4) virtual server with an address or port list as destination, then changing to an actual address or port instead of the list on the GUI, the BIG-IP keeps listening only in the addresses or ports defines in the previously attached address or port list.

 

Example:

Address list with: 192.168.2.1 and 192.168.3.2 as destination address of the Virtual Server

Then changing the destination address to 0.0.0.0

 

Virtual Server keeps listening only to 192.168.2.1 and 192.168.3.2, nothing else

 

Environment

Address or port list

Performance FastL4 Virtual Server

Change on the GUI

 

Cause

Bug ID 745160

 

Recommended Actions

Restart tmm:

tmsh restart sys service tmm

 

Note: this procedure is disruptive, so ensure to do it in a maintenance window.
