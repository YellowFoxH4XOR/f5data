K000139422: Migrate/Renew NGINX Plus FCP

Type
Support Solution
Published
2024-04-26
Updated
2024-04-26
Applies to
  • NGINX Products
  • NGINX Plus
Source

Description

The NGINX Plus or NGINX Plus FPC is about to expire, but a new Flexible Consumption Plan (FCP) is beginning. 

Environment

  • NGINX Plus

  • Flexible Consumption Plant (FCP)

  • Second Generation (Second Gen) FCP

Cause

To retain active support and access the software repository for updates, any NGINX Plus servers on the original FCP need their certificate and key replaced with the ones from the new FCP. The new FCP is sometimes referred to as the second Second Gen FCP.

Recommended Actions

Download the certificate and key from the MyF5 Customer Portal and replace the existing certificate and key files on the NGINX Plus Servers.

Note: This process doesn't impact traffic, but F5 recommends performing this work during a maintenance window.

  1. Logon to my.f5.com
  2. Open Subscriptions
  3. Click the new FCP associated with NGINX
  4. Download the NGINX Plus certificate and key
  5. Follow these instructions, Installing NGINX Plus, to replace the certificate and key

    Additional Information

    To open support cases for these NGINX Plus servers, use the Subscription ID associated with FCP for NGINX from the MyF5 Customer Portal.
