Description

Continuous error logs stating "DDM I2C error reading channel monitoring values" for PORTGROUP="n" are observed on the F5OS platform. This indicates the system is unable to read Digital Diagnostic Monitoring (DDM) values from the optical transceiver in portgroup, which may result in inaccurate or unavailable optical monitoring data.

  • 2026-04-14T16:17:23.484729+09:00 TEST-DEVICE fpgamgr[15]: priority="Err" version=1.0 msgid=0x301000000000007 msg="SDK error during device programming." API="syncPageSetReadI2c: i2c_read" code=-15 error="Unexpected NACK detected during I2C transaction".
  • 2026-04-14T16:17:23.484734+09:00 TEST-DEVICE fpgamgr[15]: priority="Err" version=1.0 msgid=0x304000000000014 msg="DDM I2C error reading channel monitoring values" PORTGROUP="8".

Environment

  • F5OS
  • Portgroup
  • Optical transceiver(s)

Cause

The error is typically caused by physical or compatibility issues with the optic or cable, disabled interfaces within the portgroup, or rarely, a software bug (Bug ID 1328985).

Answer/Recommended Actions

To address the "DDM I2C error reading channel monitoring values" for portgroup, follow these steps:

  1. Physical Checks
    1. Reseat the optical transceiver in portgroup to ensure it is firmly seated.
    2. If possible, replace the transceiver with a known-good, F5-supported optic.
    3. Inspect the cable and the remote end for any physical issues.
  2. Configuration Checks
    1. Ensure all interfaces in portgroup are enabled, even if not used.
    2. Verify portgroup mode and optic compatibility (e.g., 40G optic in 40G mode).
  3. Optic Compatibility
    1. Confirm the optic is an F5-supported model for your platform. Refer to F5 documentation for supported SFP/QSFP modules.

Additional Information

If the error persists after physical and configuration checks, further investigation may be required to rule out hardware faults or rare software bugs.
