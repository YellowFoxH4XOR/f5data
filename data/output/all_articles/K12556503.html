Description

By default, most BIG-IP plugins run at a nice level of 0.  In rare instances there may be CPU contention with the control plane which warrants changing the nice level of the plugins. Beginning in 11.5, it is possible to change the nice level of these plugins via the tmplugin.splitplanes.nice db variable.

To change this setting, log into the CLI of the BIG-IP and issue the following command:

tmsh modify sys db tmplugin.splitplanes.nice value -5
bigstart restart

A negative value is specified above as processes running at lower nice values have priority.

To back out the change, do the following:

tmsh modify sys db tmplugin.splitplanes.nice reset-to-default
bigstart restart

Note: This setting has no effect on ASM's bd process in version 15 and later because of ID1048617.

Environment

BIG-IP devices that use HTSplit.

Cause

Not applicable.

Recommended Actions

It is seldom necessary to change this setting.  When plugins are starved of CPU, the likely cause is a bug or performance tuning issue (like provisioning).  It is not recommended to change this value except under the guidance of F5 Support.

Additional Information

None.
