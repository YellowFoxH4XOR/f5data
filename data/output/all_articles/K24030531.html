K24030531: BIG-IQ DCD hostname does not reflect to cm-shared-all-big-iqs when it changed in device-info

Type
Support Solution
Published
2022-04-01
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K24030531

Description

When changed hostname on BIG-IQ DCD, the new hostname info is not updated in DCD internal, like cm-shared-all-big-iqs is still use the old hostname.

Environment

  • BIG-IQ DCD
  • Hostname

Cause

Unknown 

Recommended Actions

To workaround this:

  1. Run the following command on DCD command line to get the UUID of the DCD:
    restcurl shared/resolver/device-groups/cm-bigip-allDevices/devices | grep -E "hostname|machineId"
    Note: Get the UUID of the DCD which you want to change the hostname.
     

  2. Run the following restcurl commands (one by one) on the DCD that you want to change the DCD hostname:
     

    For example:
     3afef46e-f8ac-4b7f-8dc1-8164b5ce8cbd is the DCD UUID and DCD1.example.com is the new hostname.
    Important: When executing these command on your DCD change the UUID (3afef46e-f8ac-4b7f-8dc1-8164b5ce8cbd)and new hostname (DCD1.example.com) to match your DCD system.

    restcurl -X PATCH /shared/resolver/device-groups/cm-esmgmt-logging-group/devices/3afef46e-f8ac-4b7f-8dc1-8164b5ce8cbd -d '{"hostname": "DCD1.example.com"}'
    restcurl -X PATCH /shared/resolver/device-groups/cm-websafe-allDevices/devices/3afef46e-f8ac-4b7f-8dc1-8164b5ce8cbd -d '{"hostname": "DCD1.example.com"}'
    restcurl -X PATCH /shared/resolver/device-groups/cm-dns-allDevices/devices/3afef46e-f8ac-4b7f-8dc1-8164b5ce8cbd -d '{"hostname": "DCD1.example.com"}'
    restcurl -X PATCH /shared/resolver/device-groups/cm-bigip-allDevices/devices/3afef46e-f8ac-4b7f-8dc1-8164b5ce8cbd -d '{"hostname": "DCD1.example.com"}'
    restcurl -X PATCH /shared/resolver/device-groups/cm-shared-all-big-iqs/devices/3afef46e-f8ac-4b7f-8dc1-8164b5ce8cbd -d '{"hostname": "DCD1.example.com"}'
    restcurl -X PATCH /shared/resolver/device-groups/cm-security-shared-allDevices/devices/3afef46e-f8ac-4b7f-8dc1-8164b5ce8cbd -d '{"hostname": "DCD1.example.com"}'
    restcurl -X PATCH /shared/resolver/device-groups/cm-firewall-allDevices/devices/3afef46e-f8ac-4b7f-8dc1-8164b5ce8cbd -d '{"hostname": "DCD1.example.com"}'
    restcurl -X PATCH /shared/resolver/device-groups/cm-access-allDevices/devices/3afef46e-f8ac-4b7f-8dc1-8164b5ce8cbd -d '{"hostname": "DCD1.example.com"}'
    restcurl -X PATCH /shared/resolver/device-groups/cm-asm-allDevices/devices/3afef46e-f8ac-4b7f-8dc1-8164b5ce8cbd -d '{"hostname": "DCD1.example.com"}'
    restcurl -X PATCH /shared/resolver/device-groups/cm-adccore-allDevices/devices/3afef46e-f8ac-4b7f-8dc1-8164b5ce8cbd -d '{"hostname": "DCD1.example.com"}'
