Issue

BIG-IP LTM may log an error message to the /var/log/ltm file that appears similar to the following example:

tmm tmm[1015]: 01010025:2: Device failure: cn0: Outbound FIFO command

This error message indicates a failure in the Cavium card outbound command queue. This is indicative of either a bad part or a thermal voltage issue. If your BIG-IP system logs the example error message, you should run the EUD utility and provide the diagnostic report to F5 Technical Support.

For information about the EUD, refer to K7172: Overview of the End User Diagnostics software.
