Description

After configuration remote logging server to receive logs from F5OS-A, it doesn't receive audit logs which are existing locally at F5OS-A device.

 

Environment

F5OS-A 1.4.0 and Later

Remote Logging Server

 

Cause

Missing command selectors selector AUTHPRIV DEBUG in the configuration of remote logging server. 

 

Configuration of remote logging server when using webGUI:

 

system logging remote-servers remote-server <ip_address_of_remote_logging_server>

 config remote-port 514

 config proto udp

 selectors selector LOCAL0 INFORMATIONAL

!

 

Recommended Action

To send audit.log events to the remote logging server, command selectors selector AUTHPRIV DEBUG must be added to the remote logging server configuration as below:

 

rxxxxx(config)# system logging remote-servers remote-server <ip_address_of_remote_logging_server>

rxxxxx(config-remote-server-ip_address_of_remote_logging_server)# config remote-port 514

rxxxxx(config-remote-server-ip_address_of_remote_logging_server)# config proto udp

rxxxxx(config-remote-server-ip_address_of_remote_logging_server)# selectors selector LOCAL0 INFORMATIONAL

rxxxxx(config-remote-server-ip_address_of_remote_logging_server)# selectors selector AUTHPRIV DEBUG

rxxxxx(config-remote-server-ip_address_of_remote_logging_server)# commit

% No modifications to commit.

rxxxxx(config-remote-server-ip_address_of_remote_logging_server)#

 

Additional Information

As of version 1.8.0 much this can be done in the GUI. K000161618: Configuring Remote Logging (Host Log Forwarding) via F5OS GUI (Version 1.8.0+)
