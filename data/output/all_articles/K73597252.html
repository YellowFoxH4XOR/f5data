K73597252: BIG-IQ is unable to discover LTM service - ''Error querying 'Persistence Source Address Affinity' from path'' error

Type
Support Solution
Published
2020-05-28
Updated
2023-10-16
Applies to
  • BIG-IQ Platforms
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IQ
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K73597252

Description

  • Error message:
    Error querying 'Persistence Source Address Affinity' from path '/mgmt/tm/ltm/persistence/source-addr' on device <DEVICE_NAME> (X.X.X.X), network communication failed due to protocol error

Environment

  • BIG-IQ 
  • You are trying to discover LTM service on BIG-IP device

Cause

Unknown at time of publication

Recommended Actions

There are two Resolution options:

  • Reboot of managed BIG-IP device

    -- or --

  • Update the restjavad configuration according to the following procedure:
    1. SSH into the BIG-IQ CM as root.
    2. Stop restjavad with the following command.

      bigstart stop restjavad

    3. Edit /var/config/rest/metadata/cm.adc-core.current-config.ltm.persistence.source-addr.adcpersistencesourceaddrstate.json as follows:
      a: Locate the line that reads:

         "distributeUpdateMethod": "PATCH"

      b: Insert a line above that line with the text:

         "discoveryPageSize": 100,

      c: The config will then look like this:

        [snipped]
        "configData": {
            "configType": "device-specific",
            "bigipData": [
              {
                "displayName": "Persistence Source Address Affinity",
                "icrUriPath": "/mgmt/tm/ltm/persistence/source-addr?options\u003dnon-default-properties",
                "icrItemKind": "tm:ltm:persistence:source-addr:source-addrstate",
                "isSingleton": false,
                "transformData": {
                  "uriPath": "/cm/adc-core/transform/ltm/persistence/source-addr",
                  "discoveryProperties": {
                    "requiredProperties": [
                      "bigIpVersion"
                    ]
                  }
                },
                "discoveryPageSize": 100, <- new value
                "distributeUpdateMethod": "PATCH"
              }
            ]
        },
        [snipped]

    4. If running BIG-IQ version < 8.x, run mongodb command:

      mongo bigiqDb --eval 'db.bigiqLiveObjects.remove({"_value.kind":"cm:shared:metadata:metadatastate"})'
       

      If running BIG-IQ version 8.x, run postgreSQL command: 

      psql -U bigiq -d bigiq_db -c "DELETE FROM bigiqliveobjects.shared_md;"

    5. Start restjavad with the command:

      bigstart start restjavad

Additional Information

None.
