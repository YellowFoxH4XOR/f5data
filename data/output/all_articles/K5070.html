K5070: Mirrored SSL session ID persistence records can accumulate on the standby system

Known Issue

This is the result of a known issue. BIG-IP does not mark SSL session ID persistence records when they are mirrored. As a result, the active unit does not send a message to the standby unit when SSL session ID persistence records are deleted. Mirrored SSL session ID persistence records can accumulate on the standby system without limit.

F5 Networks Product Development tracked this issue as CR49454 and CR49455 and it was fixed in BIG-IP version 4.5.13 for the 4.5 software branch. For information about upgrading, refer to the BIG-IP Release Notes.
