Known Issue

The iControl Common::Protocol Type is missing enum values.

This issue occurs when the following condition is met:

  • You assign a protocol type to a virtual server or any object that needs a protocol specification. If you do not specify the protocol integer value, the system labels the type as PROTOCOL_ANY, which is incorrect.

Impact

This issue affects the type of protocol that a virtual server accepts. For example, if you specify protocol 50, but protocol 50 does not exist in the list, iControl labels the type as PROTOCOL_ANY, which causes the virtual server to accept all protocols, which is incorrect behavior.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Because the Common::Protocol Type is missing enum values, some protocols incorrectly default to PROTOCOL_ANY, which is incorrect.
