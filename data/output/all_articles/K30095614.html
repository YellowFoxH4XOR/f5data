Description

After an upgrade, the load in the TMMs is unevenly distributed. This causes high CPU usage.
Over your traffic environment, you are handling IP-IP packet encapsulation.

Environment

Relevant environmental factors specific to the topic

  • BIG-IP LTM
  • VLAN DAG 
  • Upgrade to version 15.1.5.1 or later

Cause

At the time of processing encapsulated IP-IP packets over a VLAN with the DAG feature set as "outer" a single TMM thread gets overloaded, causing uneven distribution of traffic among TMMs.

Recommended Actions

Configure VLAN DAG with the inner setting to achieve a better distribution over TMMs threads.

  1.  Network >>  Vlans: Vlans List >> Select VLAN
  2.  DAG Tunnel: Inner
  3.  Update
