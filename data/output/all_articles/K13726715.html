Description

string map command does NOT understand regular expressions (regex).
iRule with string map will accept regex syntax but take it as fixed string, so that there is no error logged.
 

Environment

  • BIG-IP 
  • any version
  • iRule
     

Cause

string map is for only fixed strings. Please refer below site

  • https://wiki.tcl-lang.org/page/string+map
  • https://wiki.tcl-lang.org/page/string+mapx

     

Recommended Actions

If you need to use pattern matching (regex), then consider to use other commands in iRule, e.g. regsub .
