Known Issue

Generating a BIG-IP ASM report using the TMOS Shell (tmsh) may produce an error message.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM system is configured with a security policy that resides in a non-default partition.
  • You generate an Application Security report for the security policy, using the following command syntax:

    tmsh show analytics application-security report view-by violation range now-1d drilldown { { entity policy values { "/<partition>/<security policy name>" } } }

Impact

The Application Security report generation fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When attempting to generate the Application Security report, the system displays an error message that appears similar to the following example:

    Data Input Error: Invalid entity value /<partition>/<security policy name>

Workaround

To work around this issue, you can disable Application Visibility and Reporting (AVR) caching. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure may impact AVR performance.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Disable AVR caching by typing the following command:

    modify /sys db avr.requestcache value disable

  3. Exit tmsh by typing the following command:

    quit
