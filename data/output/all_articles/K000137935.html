Description

Synchronization between BIG-IP DNS devices stopped

 

Environment

BIG-IP DNS
Partitions

Cause

Unknown. Synchronization has been properly working for a long time, but suddenly it stopped.

NTP is working
iqdump <peer-IP> is properly responding
Peer Server Object is green
Synchronization settings are correct
Certs are current (not expired)

Recommended Actions

Solution:

Run this command on both GTM/BIG-IP DNS devices:

tmsh load sys config gtm-only

 

NOTE: Best to perform during a maintenance window. After running this command, create a test DC and verify it showed up on the peer GTM. Deleting it should also deleted it from its peer BIG-IP DNS.
