Issue

Error Message

01380002:4: Certificate <name> in file <file name> will expire on <date>

In this error message, note the following:

  • <name> is the Secure Sockets Layer (SSL) certificate's object name.
  • <file name> is the name of the SSL certificate file.
  • <date> is the SSL certificate's date and time of expiration.

For example:

01380002:4: Certificate 'example.com' in file example.com.crt will expire on Sat Jan 1 23:00:00 2016 GMT

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • An SSL certificate's validity period will expire within 30 days.
  • The check-cert command has been run.

The check-cert command can be run manually and is automated to run on a weekly schedule. For more information, refer to K14318: Monitoring SSL certificate expiration on the BIG-IP system (11.x - 12.x).

Impact

Expired SSL certificates may cause web browser warning messages, and applications that rely on SSL certificate verification may fail.

Recommended Actions

You can configure a BIG-IP system to monitor the SSL certificate expiration status and send an email when expiration is within 30 days. For more information, refer to K15288: Sending an advance email alert for impending SSL certificate expiration.
