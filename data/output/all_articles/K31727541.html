Description

  • HA/DSC disconnect state
  • Service Scaler VE License
  • BIG-IP License SKU F5-BIG-SVS-VE-08-V16
  • info mcpd[<PID>]: 0114002b:6: HA license_exceeded_t mcpd enabled.

Environment

  • Configure HA
  • Service Scaler VE License
  • SKU F5-BIG_SVS-VE-08-V16

Cause

The SKU F5-BIG-SVS-VE-08-V18-LIC is a variant of the "Load Balancer Limited" license, which includes mod_lbl but not mod_ltm. mod_ltm is required for HA. So no, this license for SKU F5-BIG-SVS-VE-08-V18-LIC does not support HA.

Recommended Actions
Use a License that includes mod_ltm

Additional Information

In the bigip.license file you should have the mod_ltm in order to set up HA.
