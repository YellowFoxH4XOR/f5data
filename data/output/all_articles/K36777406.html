Description

Can we export Web Application Security Event logs from BIG-IQ version 7 in pdf format?

Environment

  • BIG-IQ Centralized Management
  • Web Application Security Event logs

Cause

Only csv format is supported for exporting of Web Application Security Event logs from BIG-IQ Centralized Management. Export of Web Application Security Event logs in PDF or html format  is not supported in BIG-IQ version 7.

But export of Web Application Security Event logs in PDF is  supported from BIG-IQ 8.0.0 onwards
