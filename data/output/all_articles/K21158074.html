Description

If a WideIP (WIP) uses an iRule to select a pool and the WIP is part of a Distributed Application, inconsistent results will occur if all the pools in the iRule are not attached to the WIP.

  • WIP in a Distributed Application (DA)
  • WIP used an iRule to select a pool.
  • Some or all of the pools referenced by the iRule are not attached to the pool

Environment

BIG-IP DNS using DA

Cause

All DNS pools referenced by an iRule must be attached to the WIP for DA to correctly associate the resource with the DA.

Recommended Actions

  • Attach any pools referenced in an iRule to the WIP itself
