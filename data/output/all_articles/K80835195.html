K80835195: Unable to view graph in BIG-IQ CM due to ''INTERNAL_SERVER_ERROR: java.lang.ArithmeticException''

Type
Support Solution
Published
2021-10-19
Updated
2026-01-09
Status
Legacy Content
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.1.0, 7.0.0
Source
https://my.f5.com/manage/s/article/K80835195

Description

When checking the graph from BIG-IQ CM, (e.g., under Monitoring > Device > Health (where CPU Usage, Memory Usage, etc., graphs are located)), it does not show any plotted points; instead, it is only showing the below error message:
INTERNAL_SERVER_ERROR: java.lang.ArithmeticException: The calculation caused an overflow: 9223372035532800000 + 360000000"

In /var/log/appiq/configserver.log, the following example errors are also observed:

ERROR c.f.a.c.r.RetentionBySetting [scheduling-1] Failed to deleted indices '[]' for index family 'statistics' and index level 'tl0'
java.lang.ArithmeticException: The calculation caused an overflow: -9223372036854775808 + -3600000

Environment

  • BIG-IQ 7.1.0, 7.0.0
  • Statistics collection is enabled

Cause

ID 974373

Recommended Actions

Upgrade to BIG-IQ 7.1.0.3 or later as the ID is fixed in that version and where the system no longer raises the exceptions that impact functionality.
 

Additional Information

None.
