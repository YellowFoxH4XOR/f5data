Known Issue

The default rule _sys_auth_krbdelegate may be missing when you use the Kerberos authentication profile.

This issue occurs when the following condition is met:

  • You configure the BIG-IP system to authenticate with Kerberos delegation using the Advanced Client Authentication (ACA) module.

Impact

The system may create the authentication profile with erroneous default settings, resulting in user authentication failure.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Authentication fails when you use Kerberos delegation. 
  • When you use the Configuration utility, the authentication profile may display an empty Rule field.
  • In the /var/log/ltm file, you may observe repeated messages similar to the following example:

    err tmm4[12345]: 01010007:3: Config error: add virtual server profile error
    crit tmm5[12345]: 01010203:2: Proxy failed to attach auth rule

Workaround

To work around this issue, you can manually add the iRule _sys_auth_krbdelegate to your profile.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
