Description

When using a Bandwidth Controller Policy, you notice that download speed is limited but upload speed is not.

Environment

  • BIG-IP 11.x or later.
  • Bandwidth Controller.
  • iRule with only CLIENT_ACCEPTED event.

Cause

The most likely reason for this is that the iRule configured to limit bandwidth doesn't have a SERVER_CONNECTED event.

Recommended Actions

Configure the iRule to contain both a CLIENT_ACCEPTED event (limits download/server-to-client) and a SERVER_CONNECTED event (limits upload/client-to-server):

when CLIENT_ACCEPTED {
set session_id [IP::client_addr]
BWC::policy attach BWC_Policy_Name $session_id
}
when SERVER_CONNECTED {
set session_id [IP::client_addr]
BWC::policy attach BWC_Policy_Name $session_id
}

Additional Information

Do not use the session ID related iRule if it's for a static policy because static policies do not take a session ID parameter; however, dynamic policies require a session ID for the flow.
