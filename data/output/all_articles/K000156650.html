K000156650: BIG-IQ preUpgradeCheck script fails with a traceback error referencing a DCD node that does not exist

Type
Support Solution
Published
2025-09-26
Updated
2025-09-26
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.0
Source
https://my.f5.com/manage/s/article/K000156650

Description: 

When running the BIG-IQ preUpgradeCheck script fails with a traceback error referencing a DCD node that does not exist.

    Running CPU, Memory and disk space compatibility checks for DCD node 172.16.1.1
    ***************************************************************************************
    Provide the root account password if prompted.
      Traceback (most recent call last):
      File "./preUpgradeCheck", line 1036, in <module>
        sys.exit(main())
      File "./preUpgradeCheck", line 1023, in main
        runDiskSpaceChecks(session)
      File "./preUpgradeCheck", line 905, in runDiskSpaceChecks
        with SshConnection(ip, account, 22) as conn:
      File "./preUpgradeCheck", line 111, in __init__
        self._start_master_proc()
      File "./preUpgradeCheck", line 211, in _start_master_proc
        "ssh connection failed, exit code: %d" % master_rc)
    Exception: ssh connection failed, exit code: 255

    Environment:

    • Product: F5 BIG-IQ Centralized Management
    • Version: 8.3.0 (upgrade to 8.4.0)
    • Platform: F5-BIQ-VE-LAB (Virtual Edition)
    • Configuration: Standalone Central Manager, no DCDs, no HA

    Recommendations: 

    Clean Up Database Artifacts:

    • Identify and remove any lingering DCD entries:
      • restcurl -X DELETE /shared/resolver/device-groups/cm-asm-allLoggingNodes/devices`/<UUID_of_stale_DCD>
    • Recreate the missing Central Manager record:
      • restcurl /shared/resolver/device-groups/cm-shared-all-big-iqs/devices/<UUID_of_CM> | jq 'del(.selfLink,.groupName,.generation,.lastUpdateMicros) | [.+{"properties":{"isLoggingNode":false}}]|.[]' > /shared/tmp/esmgmt.json
      • curl -s <POST_URL> -X POST -d@/shared/tmp/esmgmt.json | jq .
    • Note: Replace <UUID_of_stale_DCD>, <UUID_of_CM>, and <POST_URL> with values appropriate for your environment. 

    Verify Resolution:

    • Ensure the Central Manager appears in the Installations screen.
    • Confirm that preUpgradeCheck completes without errors.
    • Proceed with upgrade to BIG-IQ 8.4.0.
