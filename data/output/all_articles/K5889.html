Topic

Beginning in BIG-IP AM 9.2.3, you can disable or enable application security on all virtual servers.

Disabling application security on virtual servers

Note: For information about disabling and enabling application security on all virtual servers for BIG-IP ASM 9.4.0, refer to K7016: Disabling and enabling application security on all virtual servers.

To disable application security on all virtual servers, perform the following procedure:

  1. Expand the Local Traffic menu.
  2. Click iRules.
  3. From the iRule menu click _ASM_Bypass rule.
  4. Change set ::asm_bypass 0 to set ::asm_bypass 1.
  5. Click Update.

Requests to all virtual servers will now bypass BIG-IP ASM, and routed according to the virtual server configuration.

To disable application security on a single virtual server, refer to K5692: ASM active policy for an HTTP class is removed if the HTTP class is disabled.

Re-enabling application security on virtual servers

To re-enable application security on all virtual servers:

  1. Expand the Local Traffic menu.
  2. Click iRules.
  3. From the iRule menu click _ASM_Bypass rule.
  4. Change set ::asm_bypass 1 to set ::asm_bypass 0.
  5. Click Update.
