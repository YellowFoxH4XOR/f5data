K000151567: Scope error when attempting to deploy Azure AD Application from APM Guided Configuration

Published

Applies to

Source
https://my.f5.com/manage/s/article/K000151567

Description

When attempting to deploy an Azure AD Application from the APM guided configuration you see a browser error pop up. 

  • /var/log/restnoded.log will show the following correlating error: 
    • Thu, 27 Feb 2025 18:33:14 GMT - fine: [AzureDeployConfigWorker] updateConfigDataWithResponse : got err response err={"aadError":{"code":"AccessDenied","message":"You cannot perform the requested operation, required scopes are missing in the token.","innerError":{"date":"2025-02-27T18:33:14","request-id":"79154790-afdc-40d7-8b75-977bec0fb2bd","client-request-id":"79154790-afdc-40d7-8b75-977bec0fb2bd"}}

    Environment

    • APM AGC v10
    • AAD (Azure AD Application) deployment

    Cause

    This is not an F5 issue.  The root cause lies with Microsoft Azure permissions.

    Recommended Actions

    Make sure Azure is configured properly on the APM:

    1. Refer Quickstart: Configure a client application to access web APIs for more information. 

    Additional Information

    Packet captures taken on the F5 will reveal that the MS Azure server is returning the scope error message within HTTP payload.
