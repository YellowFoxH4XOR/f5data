K000161285: Unable to authenticate for an internal website with APM policy in placed

Type
Support Solution
Published
2026-05-14
Updated
2026-05-14
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000161285

Description

Authentication to an internal website via APM policy fails with error "There was an issue with one of the values that you provided."

 

 

Environment

BIGIP APM

 

 

Cause

special characters in userID and password validation were not handled correctly

 

 

Answer/Recommended Actions

iRule scripts were modified to correctly handle special characters in userID and password validation, resolving the authentication failure.

 

 

Additional Information

None
