Topic

This article applies to BIG-IP 11.x through 12.x. For information about other versions, refer to the following articles:

  • K12042624: Restricting access to the Configuration utility using client certificates (13.x - 14.x)
  • K7453: Restricting access to the Configuration utility using client certificates (9.x - 10.x)

You should consider using this procedure under the following condition:

  • Your BIG-IP system requires client certificate authentication for access to the Configuration utility.

Description

You can configure the Configuration utility to use client certificate authentication for verifying a client's access by including the Certificate Authority (CA) certificate that signed the client certificates and include the following Apache parameters in the configuration:

  • SSLCACertificateFile
  • SSLVerifyClient
  • SSLVerifyDepth

Beginning in BIG-IP 11.2.0, these Apache parameters are available as the following Traffic Management Shell (tmsh) commands in the sys httpd component:

Apache parametertmsh command
SSLCACertificateFiletmsh list/sys httpd ssl-ca-cert-file
SSLVerifyClienttmsh list/sys httpd ssl-verify-client
SSLVerifyDepthtmsh list /sys httpd ssl-verify-depth

If you require the client certificate authentication to use a Certificate Revocation List (CRL), you must include the SSLCARevocationFile Apache parameter in the httpd configuration using the following procedure: Optional: Configuring the Configuration utility to use a CRL.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have the CA certificate that signed the client certificates for authentication in BIG-IP PEM-encoded format.
  • Optional: You have the CRL file in PEM-encoded format.
  • You have command-line access and tmsh access.
  • You have access to the Configuration utility (for BIG-IP 11.2.0 - 12.x).
  • You are familiar with the vi editor.

Procedures

  • Uploading the CA certificate to the BIG-IP system
  • Configuring the Configuration utility to use client certificate authentication
  • Optional: Configuring the Configuration utility to use a CRL

Uploading the CA certificate to the BIG-IP system

Before configuring the Configuration utility, you must upload the CA certificate to the BIG-IP system. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

BIG-IP 11.2.0 - 12.x

  1. Log in to the Configuration utility.
  2. Navigate to System > File Management > Apache Certificate List.
  3. Click Import.
  4. Click Browse and navigate to the CA certificate file location on your desktop. Alternatively, enter the full path to the CA certificate file.
  5. Enter a name for the CA certificate in the Name box.
  6. To upload the CA certificate, click Import.

BIG-IP 11.0.0 - 11.1.0

For BIG-IP 11.0.0 - 11.1.0, you must upload the CA certificate to the /config/httpd/conf/ssl.crt directory on the BIG-IP system. To do so, perform the procedure appropriate for your environment as described in K175: Transferring files to or from an F5 system.

Configuring the Configuration utility to use client certificate authentication

After you have uploaded the CA certificate to the BIG-IP system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

BIG-IP 11.2.0 - 12.x

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Configure the client certificate authentication by typing the following command syntax:

    modify /sys httpd ssl-ca-cert-file <path/to/cert> ssl-verify-client require ssl-verify-depth <cert depth>

    For example to configure client certificate authentication using a CA certificate /Common/ClientCertCA with the certificate depth at 20, type the following command:

    modify /sys httpd ssl-ca-cert-file /Common/ClientCertCA ssl-verify-client require ssl-verify-depth 20

  3. Save the configuration to the configuration files by typing the following command:

    save /sys config

BIG-IP 11.0.0 - 11.1.0

Impact of procedure: Failing to enter the command syntax correctly as detailed in the following procedure may result in failure to access the Configuration utility.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Edit the httpd configuration by typing the following command:

    edit /sys httpd

    Note: The command launches a vi editor within tmsh.

  3. Append the following lines within the httpd configuration stanza:

    include "SSLCACertificateFile /config/httpd/conf/ssl.crt/<CA cert file>
    SSLVerifyClient require
    SSLVerifyDepth 10"

    Note: If you have existing include statements for the httpd configuration, you must append them after the existing include statements.

    For example, if the CA cert file name is ca-cert.pem, the httpd configuration stanza should appear similar to the following example:

    sys httpd {
    include "SSLCACertificateFile /config/httpd/conf/ssl.crt/ca-cert.pem
    SSLVerifyClient require
    SSLVerifyDepth 10"
    }

  4. Save the configuration into memory by exiting the vi editor. To do so, type the following command:

    :wq!

  5. The vi editor prompts you with a confirmation to save the changes. Type y to confirm.

    The httpd process reloads with the new configuration.

  6. Save the configuration into the configuration files by typing the following command:

    save /sys config

Optional: Configuring the Configuration utility to use a CRL

If you require the Configuration utility to use a CRL, you must upload the CRL file to the /config/httpd/conf/ssl.crl directory on the BIG-IP system before modifying the httpd configuration. To do so, perform the following procedure:

Impact of procedure: Failing to enter the command syntax correctly as detailed in the following procedure may result in failure to access the Configuration utility.

  1. Upload the CRL file to the /config/httpd/conf/ssl.crl directory on the BIG-IP system by performing the procedure that is appropriate for your environment as described in K175: Transferring files to or from an F5 system.
  2. Log in to tmsh by typing the following command:

    tmsh

  3. Edit the httpd configuration by typing the following command:

    edit /sys httpd

    Note: This command launches a vi editor within tmsh.

  4. Append the following lines within the httpd configuration stanza:

    include SSLCARevocationFile /config/httpd/conf/ssl.crl/<CRL file>

    Note: If you have existing include statements for the httpd configuration, you must append them after the existing include statements.

    Using the example from the previous procedure, if the CRL file name is ca-crl.pem, the httpd configuration stanza should appear similar to the following example:

    sys httpd {
    include "SSLCACertificateFile /config/httpd/conf/ssl.crt/ca-cert.pem
    SSLVerifyClient require
    SSLVerifyDepth 10
    SSLCARevocationFile /config/httpd/conf/ssl.crl/ca-crl.pem"
    }

  5. Save the configuration into memory by exiting the vi editor. To do so, type the following command:

    :wq!

  6. The vi editor prompts you with a confirmation to save the changes. Type y to confirm.

    The httpd process reloads with the new configuration.

  7. Save the configuration to the configuration files by typing the following command:

    save /sys config
