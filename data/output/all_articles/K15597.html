Topic

You should consider using this procedure under the following condition:

  • You want to manually renew the Enterprise Manager Secure Sockets  Layer (SSL) certificate that is used for monitored device communications.

Description

The SSL certificate that the Enterprise Manager system uses for monitored device communication typically has a validity of one year. Prior to the SSL certificate expiration date, the local big3d on monitored devices will log warning messages about the expiring SSL certificate. By default, 30 days before expiration, the Enterprise Manager, will also log warning messages. You will see messages from both the Enterprise Manager and monitored devices similar to the following example:

SNMP_TRAP: SSL cert from IP ::ffff:10.1.1.1:42184 WILL EXPIRE on Aug 24 03:45:15 2016 GMT

The Enterprise Manager's IP address will appear in the warning message as shown in the previous example. When this SSL certificate is within 10 days of expiration, the Enterprise Manager system automatically generates a new SSL certificate with one year validity to replace the expiring SSL certificate, and pushes this newly generated SSL certificate to the monitored devices. If you prefer to manually renew the SSL certificate any time before the expiration date, you can do so by deleting the desired SSL certificate and restarting the Enterprise Manager services. During the restart, the Enterprise Manager will perform the SSL certificate regeneration and push this new SSL certificate to the monitored devices.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the Enterprise Manager system command line.

Procedures

To manually renew the Enterprise Manager SSL certificate used for monitored device communications, perform the following procedure:

Impact of procedure: The Enterprise Manager will be temporarily unavailable to monitor devices until the restart is complete.

  1. Log in to the command line on the Enterprise Manager system.
  2. Change directory to the SSL certificate directory by tying the following command:

    cd /config/em/ssl.crt/

  3. Delete the SSL certificates by typing the following command:

    rm *

  4. Restart the Enterprise Manager services by typing the following command:

    bigstart restart
