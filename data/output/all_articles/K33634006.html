Environment

  • Re-established the HA cluster but for some reason one member sees the other member as offline.

  • There is an enforcing device/module (firewall / AFM module) between the two members

Cause

There is a blocking rule on the enforcing element that is between the sites that is blocking the requests of only one site
This can also be caused by AFM module that is installed in the system

Recommended Actions

Correct the blocking rule so that HA traffic will be permitted bidirectional
