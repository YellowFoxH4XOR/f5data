K000158157: Backend does not return HTTP responses when ADFS proxy is enabled on a virtual server

Type
Support Solution
Published
2025-12-11
Updated
2025-12-11
Applies to
  • BIG-IP
  • BIG-IP APM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 21.X.X, 21.0.X, 21.0.0, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.3, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000158157

Description

After enabling the ADFS proxy feature on a BIG-IP APM virtual server, you may observe that no HTTP responses are received for client requests. Upon analyzing both client-side and server-side traffic, you notice that the BIG-IP APM does not forward client HTTP requests to the backend server.

Environment

  • BIG-IP APM
  • Virtual server with ADFS proxy enabled
  • Limited BIG-IP APM module license

Cause

A limited APM module license does not support the ADFS proxy feature.

Recommended Actions

Upgrade to a full BIG-IP Access Policy Manager (APM) license to use the ADFS proxy functionality and ensure that a valid access policy is configured and applied to the virtual server.
