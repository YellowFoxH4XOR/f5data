K000134969: LDAP Monitor not working as expected - Bind failed with <username> (49): Invalid credentials

Support Solution

2023-06-29
Applies to

Source

Description

User is configuring an LDAP monitor and is seeing the following error in the monitor debug logs:

Bind failed with <username> (49): Invalid credentials

 

Environment

  • LDAP monitor
  • BIG-IP
  • Bind failed
  • Invalid Credentials

 

Cause

Misconfiguration

 

Recommended Actions

The username needs to be configured in the correct format per K17472.

 

UserName: Specifies the user name if the LDAP servers require authentication. This can use the LDAP Namespace Structure ("cn=binduser,ou=group,dc=company,dc=com"), or the UserPrincipalName (UPN) format ("binduser@domain.com").

 

The Invalid Credentials error is the server response. You can directly test various user/password combinations using the ldapsearch described in the 'LDAP Monitor Optimization with ldapsearch' section of K17472: Overview of LDAP Monitoring (11.x - 15.x). You would just need to modify the command to your specific data to test. The basic command would be:

ldapsearch -xLLL -H 'ldap://ldapA.company.com' -b \"ou=group,dc=company,dc=com\" -s one -A -D \"cn=binduser,dc=company,dc=com\" -w 'mypassword' \"(cn=user1)\"

 

Additional Information

Verify the LDAP Namespace Structure is correct:

  • If this is your base: 
    BASE=dc=test,ou=group,dc=company,dc=com
     
  • This would be an incorrect LDAP Namespace Structure username:
    Username=CN=binduser,ou=group,dc=company,dc=com
     
  • This would be a correct LDAP Namespace Structure username:
    Username=CN=binduser,dc=test,ou=group,dc=company,dc=com
