Known Issue

iRule commands may return an invalid IP address.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP GTM system is configured with a wide IP that has IPv6 NoError Response enabled.
  • The wide IP is configured with an iRule that uses the [LB::server addr] command to query the load-balanced server decision.
  • The expected result from the iRule command for a query is an empty or null value.

Impact

The [LB::server addr] command returns an address, even when the system does not make a load-balancing decision.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Actions dependent on null values returned from the [LB::server addr] command may not function correctly.
  • The [LB::server addr] command returns an IPv6 address, even when the system does not make a load-balancing decision.

Workaround

To work around this issue, you can modify the iRule definition to first check for the IPv6 AAAA NOERROR header, prior to running the [LB::server addr] command. To do so, perform the following procedure:

Impact of workaround: F5 recommends that you perform this procedure during a scheduled maintenance window.

  1. Log in to Configuration utility of the affected device.
  2. Navigate to Global Traffic > iRules.
  3. Click the Name of the affected iRule.
  4. Modify the iRule Definition to return the [LB::server addr] only when a DNS AAAA response header does not contain the NOERROR response.

    Example iRule definition without the response header check for NOERROR:

    when LB_SELECTED {
    log local2. "LB Selected: [LB::server addr]"
    }

    Example iRule definition with the DNS AAAA response header check for NOERROR for BIG-IP GTM 11.0.0 and later.

    when LB_SELECTED {
    if {[DNS::rrtype] == "AAAA" && [DNS::header rcode] == "NOERROR"} {
    log local2. "IPv6 NoError"
    } else {
    log local2. "LB Selected: [LB::server addr]"
    }

    Example iRule definition with the DNS AAAA response header check for NOERROR for BIG-IP GTM 10.0.0 through 10.2.4.

    when LB_SELECTED {
    if {[DNS::rrtype] == "AAAA"} {
    log local2. "IPv6 NoError"
    } else {
    log local2. "Selected: [LB::server addr]"
    }
    }
  5. To save the iRule modifications, click Update.
