K35556409: ''ANY'' appears despite setting an IP address or host as the source in AFM Firewall policy rules in GUI

Type

Published

Updated

Legacy Content
Applies to

Source
https://my.f5.com/manage/s/article/K35556409

Description

"ANY" appears despite setting an IP address or host as the source in AFM Firewall policy rules in GUI. Issue can be seen in the location Security > Network firewall > Policies
 

Environment

  • Upgrade from 14.1.4.1 to 14.1.4.5
  • Traffic unaffected
  • All Sources display "ANY"
  • When clicked on Edit, "ANY" does not appear in the configured settings

Cause

This is a cosmetic issue. tracked under ID1072057

Recommended Actions

Upgrade to fixed version.
 

Additional Information

None.
