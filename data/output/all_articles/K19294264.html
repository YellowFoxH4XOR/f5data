Description
Non-admin users might experience HTTP 401 Unauthorized error response code on API calls. 

Environment

  • iControl
  • BIG-IP LTM
  • REST API

Cause
User's permissions are not displayed under the "userReferences" section for group "iControl_REST_API_User" due to Bug ID 718796.

Recommended Actions

 Run the following commands over bash:

   # restcurl -X DELETE "shared/storage?key=shared/authz/icontrol-role-migrator"
  # bigstart restart restjavad *or* tmsh restart /sys service restjavad

Now, when you create a new user, the permissions should start in a healthy state
