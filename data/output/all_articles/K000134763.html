K000134763: Can not generate CSR on F5OS

Type
Support Solution
Published
2024-05-23
Updated
2024-05-23
Applies to
  • F5OS
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000134763

Description

Unable to create CSR. Please create a Self-Signed Certificate with your preferred Key options and set Store TLS to "True"

Environment

  • F5OS-A
  • rSeries

Cause

Self-signed certificate not yet generated

Recommended Actions

1. Login via GUI

2. Go to System Settings > Certificate Management

3. Under Self-Signed Certificate > Create Certificate

Fill the form. At the bottom for Store TLS, set to True. Save.

4. Under Certificate Signing Request > Create CSR

Fill the form. Save.

Additional Information

None
