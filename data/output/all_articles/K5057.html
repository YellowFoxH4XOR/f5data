Known Issue

The following error message may appear in the 3dns log file after the system is restarted. In rare circumstances, a start-up conflict can occur between the big3d agent and 3dnsd daemon, but the condition is harmless.

WARN:FlushAllIQM: iqBufFlush() failed for <address>: No route to host:tasks.c:250

When this conflict occurs, the following message is logged to the /var/log/3dns file:

3dnsd: WARN:FlushAllIQM: iqBufFlush() failed for <address>: No route to host:tasks.c:250

You can safely ignore this error message.

F5 Networks Product Development tracked this issue as CR27820.
