Description

When Syncookie HW mode is triggered, logs show "01010240:5:  Syncookie HW mode activated" and traffic to the vlan is disabled

Environment

Relevant environmental factors specific to the topic

  • Hardware Synccookie enabled  and SYN cookie mode is triggered
  • VELOS and rSeries platforms

Cause
 

This issue is caused by the following bug IDs:

ID1075905
ID1075729

Recommended Actions

  • You can upgrade to 15.1.5.1
  • Disable hardware SYN Cookie on all objects (virtual server, VLAN, etc.).

None
