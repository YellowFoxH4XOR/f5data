Description

Use of /32 self-IP addresses not supported for:

  • HA failover configuration
  • HA config sync configuration
  • HA mirroring
  • DNS sync group

Environment

  • High Availability Cluster
  • High Availability failover, cofig sync and mirroring configuration
  • DNS sync group
  • Any BIG-IP platform and module
  • No available route to route the HA traffic to and from the HA self-IP addresses.

Cause

/32 self IP addresses cannot be used to create routing entries to next hop or default route.

Recommended Actions

Do not use /32 self IP addresses for HA configuration and use at least /30 self IP addresses.

Additional Information

If one creates static routes for the /32 self-IP addresses through a specific gateway then error message like below will be reported.

[rootadmin@bigip1:Standby:Sync Failed] config # tmsh show cm sync-status
