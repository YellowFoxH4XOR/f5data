K000161711: F5 System Scanner reports /root/.bash_profile SHA512 checksum mismatch

Type
Support Solution
Published
2026-06-15
Updated
2026-06-15
Source
https://my.f5.com/manage/s/article/K000161711

Description

F5 System Scanner reports a SHA512 checksum mismatch for file /root/.bash_profile.

Compared with the factory-default version, /root/.bash_profile contains the following additional line:

unset USERNAME

Environment

  • BIG-IP

  • F5 System Scanner

Cause

The "unset USERNAME" line in /root/.bash_profile is a known legacy entry from older Red Hat/CentOS bash skeleton templates.

If the system was upgraded from an earlier BIG-IP version, this line may have been preserved because BIG-IP in-place upgrades do not overwrite /root/.bash_profile. As a result, the original file content can remain across subsequent upgrades.

Answer/Recommended Actions

Compare /root/.bash_profile with the same file from a known-good BIG-IP system running the same TMOS version.

If the only difference is the following line, the F5 System Scanner mismatch can be safely ignored:

unset USERNAME

Example commands:

scp <known-good-bigip>:/root/.bash_profile /var/tmp/bash_profile.good
diff /root/.bash_profile /var/tmp/bash_profile.good
rm /var/tmp/bash_profile.good
