Known Issue

The BIG-IP system may unexpectedly terminate network access sessions.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a Network Access profile.
  • Network access session users attempt to establish an RDP connection to a destination resource using a Java-based client.
  • As the initial desktop content is rendering, the user attempts to click a desktop item.

Impact

The BIG-IP system terminates the user's session.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You observe an error message that appears similar to the following example:

    Connection exception: Connection failed.

Workaround

To work around this issue, avoid interacting with the RDP desktop until the initial content has finished rendering.
