Known Issue

The BIG-IP APM rewrite profile may incorrectly process JavaScript methods that build the user interface.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • The JavaScript code in the HTML page invokes methods, such as appendChild(), insertBefore() or other similar JavaScript methods use to build user interface.
  • Users connect to the BIG-IP APM system with Internet Explorer.

Impact

Users experience slowness in the web application performance when using Internet Explorer.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Users experience slowness in the web application performance with Internet Explorer.
