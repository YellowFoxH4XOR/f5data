K000135395: When renewed SSL certificate/key pairs of SSL profile, one pair of them disappeared from GUI

Type
Support Solution
Published
2023-07-06
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K000135395

Description

When trying to renew SSL certificate/key pairs of different types like RSA and EC on SSL profile, one pair of certificate/key pair may disappeared from GUI.

The cert/key pairs may have long filename such as the below,

 

config # tmsh list sys crypto cert |grep 2022

sys crypto cert xxxxx-east-vpn-xx.xx.xx_ecdsa_202206 {

sys crypto cert xxxxx-east-vpn-xx.xx.xx_ecdsa_202207 {

sys crypto cert xxxxx-east-vpn-xx.xxxx.xx_rsa_202206 {

sys crypto cert xxxxx-east-vpn-xx.xxxx.xx_rsa_202207 {

 

config # tmsh list sys crypto key |grep 2022

sys crypto key xxxxx-east-vpn-xx.xxxx.xx_ecdsa_202206 {

sys crypto key xxxxx-east-vpn-xx.xxxx.xx_ecdsa_202207 {

sys crypto key xxxxx-east-vpn-xx.xxxx.xx_rsa_202206 {

sys crypto key xxxxx-east-vpn-xx.xxxx.xx_rsa_202207 {

 

Environment

  • SSL profile
  • GUI

Cause

The issue is suspecting related to the length of the naming of the cert/pair and this is documented as ID1316569.

 

Recommended Actions

Try to create the cert/key pair name with shorter length, then the issue is not seen on GUI.

 

Additional Information

None
