Topic

You should consider using this procedure under the following condition:

  • You want to view the Message Routing Framework (MRF) Diameter statistics using SNMP queries.

Description

With more Diameter protocol specific statistics collected per pool member (Diameter peer), you can view the detailed stats from SNMP queries.

The following new SNMP OIDs are added for statistics related to MRF Diameter per-peer session and router profiles:

  • ltmMrPmbrDiameterSessionStat (.1.3.6.1.4.1.3375.2.2.6.41.1)
  • ltmMrPmbrDiameterRouterStat (.1.3.6.1.4.1.3375.2.2.6.41.2)

The following SNMP OIDs are enhanced with additional counters:

  • ltmDiametersessionProfileStat (.1.3.6.1.4.1.3375.2.2.6.39.2)
  • ltmDiameterrouterProfileStat (.1.3.6.1.4.1.3375.2.2.6.40.2)
  • ltmPoolStatTable (.1.3.6.1.4.1.3375.2.2.5.2.3)
  • ltmPoolMemberStatTable (.1.3.6.1.4.1.3375.2.2.5.4.3)

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have the necessary MRF Diameter configuration running on the BIG-IP system.
  • You have SNMP access to the BIG-IP system.

Procedures

To view the stats using SNMP, you can use a MIB browser to query the BIG-IP system using the described SNMP OIDs. Alternatively, you can use the snmpwalk utility to perform the query. To do so, perform the following procedure:

Note: Ensure that you add the IP address of the system you are performing the SNMP query from to the SNMP Access Client Allow List on the target BIG-IP system. For information about adding IP address to the list, refer to K13535: Restricting SNMP access to the BIG-IP system.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the SNMP system from which you want to query:
  2. Enter the following command syntax:

    snmpwalk -v2c -c <SNMP community string> <BIG-IP IP address> <SNMP OID>

    For example, to query the ltmMrPmbrDiameterSessionStat on the BIG-IP system with management IP address 192.168.61.154 with community string of public, enter the following command:

    snmpwalk -v2c -c public 192.168.61.154 .1.3.6.1.4.1.3375.2.2.6.41.1
