Description

Unable to create or update a virtual server with "Address List" and receive one of the errors below.

  • When creating virtual server with an address list, you get following error in the GUI (Configuration utility): 

"Some fields below contain errors. Correct them before continuing." "The traffic_matching_criteria name <vs name> cannot be longer than 64 characters."

  • When updating a virtual server with an address list, you get the following error in the GUI: 

"Some fields below contain errors. Correct them before continuing."

Environment

  • BIG-IP - LTM
  • Virtual Server and Address List ( GUI: Shared Objects > Address List )   

Cause

LTM objects names are limited to 64 characters. The full object name also includes the partition.

For example, the complete object name of a Virtual Server "My_Virtual_Server_1" in partition "Common" is  "/Common/My_Virtual_Server_1"

When using an Address List object in the Virtual Server configuration via the WebUI (TMUI/GUI), the BIG-IP automatically creates a traffic-matching-criteria object with the same name as the Virtual Server and the string "_VS_TMC_OBJ" appended.

For example, the complete object name of a traffic-matching-criteria object for the Virtual Server "My_Virtual_Server_1" is  "/Common/My_Virtual_Server_1_VS_TMC_OBJ"

If the complete object name of the Virtual Server is 54 characters or more, the resulting name of the traffic-matching-criteria object would have to be more than 64 characters, which is not allowed.

OR

Virtual server name must start with an alphabetic character in order to add an address list.  If the Virtual Server name is created without the first character as alphabetic the traffic-matching-criteria object fails to create.

Recommended Actions

Either of the following options:

  • Do not use a virtual server name that results in the complete object name for the virtual server being longer than 53 characters.
  • Do not use an Address List when the complete object name for the virtual server is longer than 53 characters.
  • Virtual server must start with an alphabetic character.
