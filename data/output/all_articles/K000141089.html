Description

After upgrade to BIG-IP 16.1.5 and v17.1.2, the configuration load may fail, if following configuration is defined.

sys sshd {
    include "
MACS hmac-sha1,hmac-ripemd160,hmac-ripemd160@openssh.com"
}

Some error messages example below.

/var/log/confpp.log

Aug 21 12:19:01 F5-i5800-2.f5net.com confpp[28704]: syntax check command FAILURE for unix_config_sshd returned: '65280'
STDERR/STDOUT text begins
/config/ssh/sshd_config line 23: Bad SSH2 mac spec 'hmac-sha1,hmac-ripemd160'.^M
STDERR/STDOUT text ends

-----------------------------------------------------------------------------------------------------------------------

Jan  7 18:35:37 F5-i5800-2.f5net.com confpp[26695]: syntax check command FAILURE for unix_config_sshd returned: '65280'
STDERR/STDOUT text begins
/config/ssh/sshd_config line 20: Bad SSH2 mac spec 'hmac-sha1,hmac-ripemd160,hmac-ripemd160@openssh.com'.
STDERR/STDOUT text ends

 

Environment

  • BIG-IP 17.1.2 
  • sshd 

Cause

The error is due to a behavior change for strict SSH restriction following.

In BIG-IP 16.1.5 and v17.1.2, hmac-ripemd160 is not allowed. The strict SSH apply, if the BigDB database key security.fips140.compliance is set to true.
In BIG-IP 16.1.4.2 and v17.1.1.4 hmac-ripemd160 is allowed. The strict SSH does not apply, if the BigDB database key security.fips140.compliance is set to true and the BigDB database key security.commoncriteria is set to false.

Recommended Actions

Remove hmac-ripemd160 and hmac-ripemd160@openssh.com from MACS list in the sshd include configuration.
