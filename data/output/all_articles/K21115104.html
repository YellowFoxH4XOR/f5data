K21115104: Unable to login into BIG-IQ Configuration utility after initial setup.

Type
Support Solution
Published
2022-08-10
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K21115104

Description

Following error are noted in the configuration utility when logging using default admin account during initial setup of the BIG-IQ. 

Insufficient permissions.

Environment

  • Initial setup of BIG-IQ Centralized Management or BIG-IQ Data Collection Device
  • Unable to login into the BIG-IQ configuration utility but able to login using SSH

Cause

Bug ID 904689

Recommended Actions

Follow the article https://my.f5.com/manage/s/article/K13380  and configure BIG-IQ with an NTP Server using tmsh and ensure there are no clock skew.

Additional Information

None
