Known Issue

The BIG-IP system may mark pool members down when a client aborts the connection to the virtual server.

This issue occurs when the following conditions are met:

  • Client browser activity causes the server-side connection to abort.
  • An Inband monitor is associated with the pool.

Impact

The pool member is marked down and unavailable for load balancing.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system marks the pool member down.
  • The BIG-IP system logs error messages to the /var/log/ltm file that appear similar to the following example:

    notice mcpd[7563]: 01070638:5: Pool /Common/mypool member /Common/10.20.0.10:80 monitor status down. [ /Common/base_inband: down ] [ was up for 0hr:0min:26sec ]
    err tmm1[13110]: 01010028:3: No members available for pool /Common/mypool
