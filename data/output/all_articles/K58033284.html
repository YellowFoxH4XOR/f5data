Known Issue

Switching partitions while viewing objects in the Configuration utility may result in empty list.

This issue occurs when all of the following conditions are met:

  • One partition contains multiple pages of objects.
  • The page count in one partition is greater than the page count in another.
  • The active page number is greater than 1.
  • You switch to a partition whose maximum number of pages is lower than the active page number.

Impact

The list of objects is empty, even though objects are available.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • On the LTM Pool List, Node List, and Address Translations pages, switching partitions while viewing objects in the Configuration utility results in an empty list.

Workaround

To work around this issue, return to the first page of objects before switching to any other partition.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
