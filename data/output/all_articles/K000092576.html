K000092576: rSeries appliance automatically reboots after a backup file is restored

Type
Support Solution
Published
2022-11-09
Updated
2022-11-15
Source
https://my.f5.com/manage/s/article/K000092576

Description

An rSeries appliance automatically reboots after a backup file is restored without notice.
 

Environment

  • rSeries
 

Cause

Note: This is expected behaviour due to portgroup changes.

When a backup file is restored, portgroup settings may change from their current or default values. As a result, a reboot is required. The appliance will reboot automatically.
 

Recommended Action

None. However, an improvement is being considered to provide a warning prompt notifying of a reboot prior to it happening. Should you be interested in the improvement please contact the F5 Support team and reference this KB Article.
 

Additional Information

None.
