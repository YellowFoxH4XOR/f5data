Description

After upgrading the BIG-IP, SNMP stops responding to polls.
  • Messages like the one below can be observed from snmpd.log 
    /config/snmp/snmpd.conf: Permission denied
Warning: no access control information configured.
(Config search path: /etc/snmp:/usr/share/snmp:/usr/lib64/snmp)
It's unlikely this agent can serve any useful purpose in this state.
Run "snmpconf -g basic_setup" to help you configure the snmpd.conf file for this agent.
alertd pid file not found: No such file or directory
NET-SNMP version 5.8

Environment

  • BIG-IP device that has been recently upgraded
  • SNMP polling is configured

Cause

SELinux policies failed to properly or completely transfer permissions for system files during the upgrade process.

Recommended Actions

Run the following commands on the affected system to restore the SNMP configuration: 
restorecon -rF /config/snmp/snmpd.conf
bigstart restart snmpd
