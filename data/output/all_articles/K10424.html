Known Issue

This is the result of a known issue. If you install cumulative hotfix HF-603-4 or HF-603-4.2, the Force password change on first logon setting for local user accounts no longer functions properly. If you select the Force password change on first logon check box for a new user account, FirePass correctly prompts the user to update the password at logon. However, when the user supplies the new password credentials, FirePass terminates the user’s session without updating the password. Therefore, the user is never able to log on.

F5 Product Development tracked this issue as CR126841 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative HF-603-4.3, which has been issued for FirePass 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by removing cumulative hotfix HF-603-4 and HF-603-4.2 from the FirePass controller. For instructions about removing a hotfix, refer to K3430: Installing FirePass hotfixes.
