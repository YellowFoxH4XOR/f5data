Description

Sync is failing, with show /cm sync-status output similar to the following:

--------------------------------------------------------------------------------
CM::Sync Status
--------------------------------------------------------------------------------
Color    red
Status   Sync Failed
Mode     high-availability
Summary  A validation error occurred while syncing to a remote device
Details
         ltm2.com: connected
         sync-group (Sync Failed): A validation error occurred while syncing to a remote device
          - Sync error on ltm1.com: Load failed from /Common/ltm2.com
01070734:3: Configuration error: Unknown template (/Common/f5.bigiq-analytics) specified for application ()
 

Environment

  • BIG-IQ managed BIG-IP system

     

Cause

Bug ID 757423
 

Recommended Actions

One workaround is to force a full sync on BIG-IP from the unit which has latest configuration. On CLI, please run below command:

tmsh run cm config-sync to-group <group> force-full-load-push
 

NOTE: This issue does not occur when running BIG-IQ version 7.0 and later, with BIG-IPs running the following versions:

  • 13.1.2.0 or later
  • 14.1.2.0 or later
  • 15.0.0.1 or later
