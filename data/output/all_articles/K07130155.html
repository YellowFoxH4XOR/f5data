Description

There was a requirement to query a specific external DB server from APM and update the received data to APM's local DB. Information to be updated in APM's local DB would  be ID, Password, email, phone number, and group information.

Environment

  • BIG-IP with APM provisioned and used.

Cause
Access to MySQL on BIG-IP is not allowed other than from internal components, which  have full permissions.
Also, remote network connections to BIG-IP's MySQL instance are not supported.

Recommended Actions

None. This is by design.
