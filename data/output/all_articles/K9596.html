K9596: Switching between multiple TN3270 Legacy Host favorites may cause the Legacy Host service to crash

Known Issue

This is the result of a known issue. If a user opens two or more TN3270 Legacy Host favorites, then repeatedly switches between those favorites, the Legacy Host service running on the FirePass controller may crash. When this issue occurs, the session tabs disappear in the browser and the client Java console reports an error message that appears similar to the following example:

CliTransportProvider: Content-length is damaged.

Additionally, users cannot access any new or existing Legacy Host favorites until an administrator restarts the FirePass services.

F5 Networks Product Development tracked this issue as CR84108 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.

Additionally, cumulative hotfix HF-601-12 has been issued for FirePass version 6.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by restarting the FirePass services on the Device Management : Maintenance : Restart Services page.
