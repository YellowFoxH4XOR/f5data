Issue

Error Message

<big_ip_device> err gtmd[<process_id>]:iqmgmt_receive: SSL error:140940F5:SSL routines:SSL3_READ_BYTES:unexpected record

In this error message, note the following:

  • <big_ip_device> is name of the local BIG-IP system.
  • <process_id> is the PID of the gtmd process.

For example:

f5_gtm_01 err gtmd[14797]: 011ae0fa:3: iqmgmt_receive: SSL error: error:140940F5:SSL routines:SSL3_READ_BYTES:unexpected record (336150773)

Message location

You may encounter this message in the following location:
  • The /var/log/gtm file
Description

This message occurs when all of the of the following conditions are met:

  • The BIG-IP DNS system (formerly known as BIG-IP GTM) is configured to use iQuery to monitor a remote BIG-IP device.
  • The BIG-IP DNS system attempts to transfer data over the iQuery connection during the Secure Sockets Layer (SSL) renegotiation phase.

Impact

This message indicates that an iQuery based health monitor attempted to transfer data during an SSL renegotiation of the iQuery connection. The SSL renegotiation for the iQuery connection randomly occurs approximately every 24 hours. The iQuery based health monitor will automatically re-attempt the data transfer and most often does not encounter an issue. However, under rare conditions, the health monitor momentarily marks the remote BIG-IP device in a 'down' state until the iQuery connection reestablishes. This momentary interruption usually completes within 1 second. When this behavior occurs, the BIG-IP system logs messages that appear similar to the following example:
