Known Issue

You are unable to edit the logon page agent using Internet Explorer 8.

This issue occurs when all of the following conditions are met:

  • You use Internet Explorer 8 to access the visual policy editor and edit the logon page.
  • In the logon page agent configuration, you choose select for the Type input field and populate the Value field, then click [edit] in the Customization section.

Impact

Editing the logon page fails with a JavaScript error.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You are are unable to edit logon pages in the visual policy editor using Internet Explorer 8.
  • You view Error on page messages in the browser when attempting to edit the Customization section of logon pages.
  • You view JavaScript errors in the console when using Internet Explorer 8 Developer Tools.

Workaround

To work around this issue, you can use a browser other than Internet Explorer 8 when editing an access policy with the visual policy editor or editing the value directly in the Values field.
