K000138620: Disable warning message host not found resolving endpoint "nginx-mgmt.local"

Type
Support Solution
Published
2024-02-15
Updated
2024-02-15
Applies to
  • NGINX Products
  • NGINX Plus: R30
Source
https://my.f5.com/manage/s/article/K000138620

Description

Is there any way to disable this warning message?

[warn] 278828#278828: usage report: host not found resolving endpoint "nginx-mgmt.local"


Environment

NGINX Plus


Cause

NGINX Plus users are required to report their NGINX usage to F5 for compliance purposes.


Recommended Actions

Cannot be disabled; customers are expected to install NGINX Instance Manager to report NGINX usage to F5 for compliance purposes.


Additional Information

A separate license for NGINX Management Suite is not required to track your NGINX product usage.
