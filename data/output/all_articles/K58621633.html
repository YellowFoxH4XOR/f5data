Topic

The process for expanding disk directory sizes that roll forward on upgrades is changed in BIG-IQ 5.4 and later.

Description

The TMOS Shell (tmsh) commands that you can use to expand the directory sizes on a currently running install slot do not roll forward to a new slot during an upgrade. Beginning in version BIG-IQ 5.4.0, you should use a new procedure to modify the disk directory size. 

For BIG-IQ 5.4.0 and later, refer to the following documentation appropriate for your application environment:

  • K30902515: Resizing the /var, /var/log or /shared file system on a BIG-IQ Virtual Edition
  • The Resizing Disk Space on BIG-IQ Virtual Edition chapter of the BIG-IQ Centralized Management DCD Sizing Guide.

    Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

For BIG-IQ 5.3.0 and earlier, refer to the K16103: Extending disk space on BIG-IQ Virtual Edition.
