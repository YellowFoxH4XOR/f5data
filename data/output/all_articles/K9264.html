Known Issue

This is the result of a known issue. The big3d_install script uses the secure shell (SSH) protocol to install F5 device certificates and the current version of the big3d process on remote F5 systems.

Note: For more information about the big3d_install utility, refer to K8195: Overview of the BIG-IP GTM big3d_install, bigip_add, and gtm_add utilities.

Note: If the SSL certificate has expired on BIG-IP GTM or BIG-IP LTM, then iQuery communication will fail. For more information, refer to K7466: Expiration of a Configuration utility SSL certificate on a BIG-IP LTM system causes the BIG-IP LTM to be marked down on a BIG-IP GTM system.

When you run the big3d_install script, the script incorrectly installs the device certificates to the end of the /config/gtm/server.crt and /config/big3d/client.crt files. This behavior may cause the iQuery communication to fail.

F5 Product Development tracked this issue as CR96679 and it was fixed in BIG-IP 10.0.0. For information about upgrading, refer to the BIG-IP LTM and GTM release notes.

This issue still exists in the BIG-IP 9.3, 9.4, and 9.6 software branches.

Workaround

You can work around this issue by running the bigip_add script on the BIG-IP GTM device. The bigip_add script installs the device certificates to the beginning of the /config/gtm/server.crt and /config/big3d/client.crt files. For example, to copy the device certificates between a local BIG-IP GTM system to a remote BIG-IP LTM system, perform the following procedure:

  1. Log in to the command line of the local BIG-IP GTM system.
  2. Use the following command syntax, where <remote_ltm_system> is the IP address of the remote BIG-IP LTM system:

    bigip_add <remote_ltm_system>

The trusted device certificate is now copied from the local BIG-IP GTM system to the beginning of the /config/big3d/client.crt file on the remote BIG-IP LTM system, and the trusted server certificate is copied from the remote BIG-IP LTM system to the beginning of the /config/gtm/server.crt file on the local BIG-IP GTM system.
