Description
Log rotation stops working and logrotate script fails when trying to run manually.
Permission denied errors returned when trying to run logrotate.

Example manual execution of logrotate:
logrotate -f /etc/logrotate.conf
error: stat of /var/log/boot.log failed: Permission denied
error: stat of /var/log/platform_check failed: Permission denied
error: stat of /var/log/tomcat/catalina.out failed: Permission denied
 

Environment

  • logrotate script


Cause

This error occurs due to bad security labels in /var/log.


Recommended Actions

Try disabling SElinux temporarily and see if syslog-ng starts up without a permission error. Perform the following steps from BIG-IP CLI:

Disable SElinux using the following commands:
setenforce 0
bigstart restart syslog-ng
Note: Disabling SElinux temporary disables operating system security check.
Note: Restarting syslog-ng temporarily may cause missing logs during restart, but this should only be a couple seconds.

To set up var only without reboot:
restorecon -R /var
Note: This command restores/resetup SElinux context for files under /var. this is required for SElinux access control.

To re-enable SElinux use the following commands:
setenforce 1
bigstart restart syslog-ng

To setup entire file
touch /.autorelabel
reboot
Note: This command will re-setup/label entire system file during startup after the reboot. The reboot will stop service.
