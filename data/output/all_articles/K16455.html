Known Issue

The scriptd process leaks file descriptors when running some Traffic Management Shell (tmsh) commands.

This issue occurs when the following condition is met:

  • A pipe is opened for a tmsh command that is run through scriptd, for example, when an icall script includes a definition using the tmsh::modify command.

The BIG-IP system will fail to close the pipes opened for tmsh commands run through scriptd.

Impact

Scripts may stop functioning and require scriptd to be restarted.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H543434 on the Diagnostics > Identified > Low screen.
  • Scripts stop functioning, and the system logs error messages similar to the following example:

    err scriptd[PID]: 014f0013:3: Script (/Common/testscript) generated this Tcl error: (script did not successfully complete: (the pipe system call failed, Too many open files while executing "tmsh::modify /sys file ifile install-script source-path "http://192.168.100.101/install"" line:1))

Workaround

To temporarily recover from this issue, you must restart the scriptd process using the following command:

bigstart restart scriptd

Impact of workaround: Performing the restart of scriptd should not have a negative impact on your system.
