K000157155: How to manage F5 hardware on the BIG-IQ for FCP usage script

Type
Support Solution
Published
2025-10-28
Updated
2026-07-10
Source

Description

To ensure the FCP usage script collects all the information about hardware Hosts and tenants, you need to ensure both the Host and the Tenant are managed on the BIG-IQ.

Note: If you add a new blade you will need to remove and re-add the Velos HOST before adding any Tenants, this will ensure we capture the new blade slot and serial number.

Environment

  • BIG-IQ 8.4 up

  • FCP Usage Script

Cause

If only a Host or Tenant is managed it will not display correctly in our reporting.

Answer/Recommended Actions

For rSeries and Velos hardware Hosts, we need to add them to the "F5OS" section of the BIG-IQ

 

  1. Click on Devices on the top middle menu, then F5OS on the left side menu
  2. Click on Platform / Devices
  3. Click the button Add Velos / rSeries System
  4. Fill in Device Name, FQDN / IP address, Username and Pasword of the Host device
  5. Click Submit & Add

For iSeries and Viprion Hosts and for all tenants and Guests (regardless of the host system) we add each BIG-IP to "BIG-IP Devices" section of the BIG-IQ

 

  1. Click on Devices at the top middle menu, then BIG-IP Devices on the left menu
  2. Click on Add Device(s)
  3. fill in IP address, port (443), user name and password of the BIG-IP device
  4. Set up and silo if needed or leave as "Do Not Use a Silo"
  5. Click on Add
