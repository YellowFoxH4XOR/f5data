Topic

Beginning in version 9.4.5, BIG-IP introduced a new monitor to control and manage FirePass sessions when the BIG-IP LTM or GTM systems load balance FirePass systems.

The FirePass monitor works by retrieving the load_status.php page from the monitored FirePass system. This page returns the FirePass current session count and the FirePass CPU load average, which the BIG-IP system uses to maintain the status of the FirePass Controller. The BIG-IP system will mark down any FirePass system that exceeds the maximum utilization settings defined in the FirePass monitor. FirePass systems which are marked down will reset the sessions already connected, and will not receive new session requests from the BIG-IP. In addition to actively diverting traffic from heavily loaded systems, BIG-IP LTM and GTM systems apply the utilization statistics returned by the FirePass monitor to assign an appropriate Dynamic Ratio value or Virtual Server score, thereby proactively distributing new sessions evenly between the monitored FirePass systems.

Note: Dynamic ratio is based on session concurrency alone. The FirePass CPU load average is not included in these calculations.

You can configure FirePass system monitoring by either the BIG-IP LTM or GTM system. To do so, perform the following procedures:

  • Configuring load status access on the monitored FirePass systems
  • Creating the custom FirePass monitor on the BIG-IP system
  • Assigning the custom FirePass monitor on the BIG-IP system

Configuring load status access on the monitored FirePass systems

Before you can monitor a FirePass system from a BIG-IP LTM or GTM system using the FirePass monitor, you must also configure the FirePass systems to be monitored. To do so, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Device Management: Monitoring: Load Status Access Security page.
  3. If you want to enable password protection for the Load Statistics page, in the New Password and Confirm New Password fields, enter the password that the remote BIG-IP LTM or GTM system will use to access the load statistics .

    Note: To bypass password protection, select the Do not use password for Load Status query check box.

    Note: The logon name is set to gtmuser; it cannot be changed.
  4. To save your password setting changes, click Update.
  5. To filter access to the Load Statistics page by source IP address, in the Load Status Access Security section, enter each BIG-IP self IP address from which FirePass will accept requests for the Load Statistics page.
  6. To save IP filter changes, click Apply.

    Note: To control access to the FirePass Load Statistics page, you can configure either password authentication or IP filters, or both together. One or both options must be configured as detailed in the above procedure for FirePass to respond to requests for the Load Statistics page.

    Important: The Load Status Access Page was introduced in FirePass 6.0.1. Versions prior to 6.0.1 do not include this feature and cannot be used with the BIG-IP LTM or GTM FirePass monitor.

    Note: If the Load Status Access Security page is missing in FirePass 6.0.1 or later, refer to K9144: The Load Status Access Security link is missing on the Monitoring page.

    Note: For more information about the Load Status Access Security page, refer to     K9142: External monitoring of a FirePass controller using the Load Status page. 

Creating the custom FirePass monitor on the BIG-IP system

To create a custom FirePass monitor on the BIG-IP system, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. For the BIG-IP LTM system, navigate to the Local Traffic: Monitors screen.
    For the BIG-IP GTM system, navigate to the Global Traffic: Monitors screen.
  3. Click Createbutton.
  4. Enter a name for the custom monitor.
  5. From the Type drop-down menu, select FirePass.
  6. Configure the Interval and Timeout values as appropriate for your environment.
  7. In the Cipher List field, accept the default value.
  8. In the Max Load Average field, accept the default value, or enter another value at which the BIG-IP system should mark the FirePass system down.

    Note: The Max Load Average setting specifies the number that the monitor uses to determine whether the FirePass system is marked up or down. The system compares the Max Load Average setting against a one-minute average of the FirePass system load. When the FirePass system load average falls within the specified Max Load Average, the monitor marks the FirePass system up. When the average exceeds the setting, the monitor marks the system down. The default setting is 12.0. You should configure this value appropriately based on the capacity of your FirePass and your environment.
     
  9. In the Concurrency Limit field, accept the default value of 95 percent, or enter another value at which the BIG-IP system should mark the FirePass system down.

    Note: The Concurrency Limit setting specifies the maximum percentage of licensed connections currently in use under which the monitor marks the FirePass system up. As an example, a setting of 95 percent means that the monitor marks the FirePass system up until 95 percent of licensed connections are in use. When the number of in-use licensed connections exceeds 95 percent, the monitor marks the FirePass system down. The default setting is 95. You should configure this value appropriately based on the capacity of your FirePass and your environment. 
     
  10. In the User Name field, if you configured your FirePass systems to use password authentication, accept the default value gtmuser.

    If you opted to bypass password protection for the FirePass Load Statistics page, clear this field.
  11. In the Password field, if you configured your FirePass systems to use password authentication, enter the password you configured on your FirePass system for the username gtmuser.

    If you opted to bypass password protection for the FirePass Load Statistics page, leave this field blank.
  12. To save the custom FirePass monitor, click Finished.

Assigning the custom FirePass monitor on the BIG-IP system

To assign the custom FirePass monitor to the FirePass pools already configured on the BIG-IP system, perform the following procedure:

  1. For the BIG-IP LTM system, navigate to the Local Traffic: Pools screen.
    For the BIG-IP GTM system, navigate to the Global Traffic: Pools screen.
  2. Select the pool containing the FirePass systems to be monitored.
  3. In the Health Monitors section, select the FirePass monitor you created above from the Available list, and click << to move it to the Active list.
  4. To save the new pool configuration, click Update.
