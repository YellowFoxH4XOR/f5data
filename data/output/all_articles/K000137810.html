K000137810: Unable to upgrade from the ISO software, unable to select appropriate disk volume via GUI.

Type
Support Solution
Published
2023-12-07
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000137810

Description

It is not possible to manage the disk from the GUI.
Unable to install new software from the ISO and upgrade by GUI.
Unable to choose the proper disk volume from the 'Select Disk' list during installation wizard.

System -> Disk Management showing blank page, no volumes.
For example:

 

After choosing the Image ISO to install from System -> Software Management:Image List, the 'Select Disk' list is empty or have different disk name with 0.0 GB free.
For example:

 

Environment

  • BIG-IP LTM
  • Upgrade
  • Creating a new Volume

Cause

Unknown

Recommended Actions

 

Important: Please create a UCS backup and copy that UCS backup from Host.

Using TMSH:
  1. create a new volume,
  2. install the software you wish to upgrade to on that volume
After doing those steps, disk volumes will appear on the Disk Management GUI.

For commands and steps, please refer to K92404240: Upgrade or upgrade a standalone BIG-IP system using the TMOS shell | BIG-IP update and upgrade guide
