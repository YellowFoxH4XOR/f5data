Issue

Error Message

Client side:

tmm1 err tmm1[<pid>]: 011f0011:3: HTTP header count exceeded maximum allowed count of <Count> (Client side: vip=/Common/<VIPName> profile=<HttpProfile> pool=/Common/<PoolName> client_ip=<ClientIP>)

Server side:

tmm1 err tmm1[<pid>]: 011f0011:3: HTTP header count exceeded maximum allowed count of <Count> (Server side: vip=/Common/<VIPName> profile=<HttpProfile> pool=/Common/<PoolName> server_ip=<NodeIP>)

In this error message, note the following:

  • <pid> is the process ID of the notifying Traffic Management Microkernel (TMM).
  • <Count> is the maximum number of allowed HTTP headers.
  • <VIPName> is the name of the affected virtual server.
  • <HttpProfile> is the name of the HTTP profile used.
  • <PoolName> is the name of the affected pool.
  • <ClientIP> is the IP address of the affected client
  • <NodeIP> is the IP address of the affected node.

For example, a server response that exceeds the maximum allowed number of HTTP headers may generate a message similar to the following example:

tmm1 err tmm1[7497]: 011f0011:3: HTTP header count exceeded maximum allowed count of 64 (Server side: vip=/Common/www1_https profile=http pool=/Common/www1_https_pool server_ip=192.168.16.160)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • An HTTP client has sent a request with more than the allowed number of HTTP headers.
  • An HTTP server (node) has sent a response with more than the allowed number of HTTP headers.

When this condition is met, a TCP RST is sent to the affected client or server, and the connection is closed.

Impact

Prematurely closed connections may affect some web applications.

Recommended Actions

If necessary, you can increase the Maximum Header Count in the HTTP profile. To do so, perform the following procedure:

  1. Log in to the Configuration utility as the admin user.
  2. Navigate to Local Traffic > Profiles > Services > HTTP.
  3. Select the HTTP profile that handles your affected traffic.
  4. Change the Maximum Header Count to a higher value, such as 128.
  5. Click Update.

All new connections now use the new configuration.
