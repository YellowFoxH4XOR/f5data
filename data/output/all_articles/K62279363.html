Description

When using an SQL monitor, to monitor the health of an SQL server, the pool member may initially be marked UP, but then will be marked DOWN.
Using the tcpdump utility to view network traffic between the BIG-IP and the SQL server(s) shows no health monitor request being sent by BIG-IP to the SQL server(s).

Environment

  • BIG-IP
  • SQL monitor in use

Cause

The issue is caused by a Bug ID 814761

Recommended Actions

  • Upgrade to a listed fixed version for Bug ID 814761.
  • Alternatively you can work around this issue by configuring a 'count' value of '1', in the SQL monitor configuration.
  1. Log on to the Configuration utility.
  2. Go to Local Traffic > Monitors.
  3. Select the SQL monitor name.
  4. Locate the Count field in Configuration.
  5. Modify the count from 0 to 1.
  6. Click Finished.
