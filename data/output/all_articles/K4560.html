Important: This Solution contains a command-line method of retrieving a serial number that was introduced as a new feature in BIG-IP and 3-DNS versions 4.5.11 and 4.6.3.

Locating the registration key on a licensed system

The serial number is located on the barcode sticker. The serial number and the registration key are located in the license file. You can use the serial number or the last 5 digits of the registration key to open service cases with F5 Networks Technical Support.

Serial number barcode sticker

The serial number begins with the letters bip and ends with the letter s, and can be found in the following locations:

  • For models 1000, 2000, 2400, 5000, and 5100, the serial number barcode sticker is silver and is located on the lower left, front corner of the system.
  • For the 2U model without a front door, the serial number barcode sticker is silver and is located on the lower left, front corner of the system.
  • For the 2U model with a front door, the serial number barcode sticker is white and is located on the lower left, front corner of the system within the channel on the inside of the door.
  • For the 4U model, the serial number barcode sticker is white and is located on the lower right, front corner of the system on the inside of the front door.
  • For the BIG-IP Blade Controller, you must get the serial number from the license file.

     

Serial number and registration key

You can view the registration key and/or serial number using the Configuration utility or the command line.

Configuration utility

To view the registration key from the Configuration utility, perform the following procedure:

  1. From the Configuration utility, click System Admin.

  2. Click the License Administration tab.

  3. Click the Show License File button.

Command line for BIG-IP switch appliances

To view the serial number for BIG-IP switch appliances from the command line, perform the following procedure:

  1. Log in to the command line.

  2. Type the following command to view the platform serial number:

    bigpipe serialnumber

    Note: This command will not work for BIG-IP server appliances.

    The output will appear similar to the following:

    
 Platform serial number: bip000000s

Command line for BIG-IP server appliances

To view the serial number for BIG-IP server appliances from the command line, perform the following steps:

  1. Log in to the command line.

  2. Type the following command to view the platform serial number:

    more /config/bigip.license

Locating the registration key on a unlicensed system

If the license has not yet been activated on your system, you can locate the registration key in the /config/RegKey.License file. This file will only be present on factory installed systems.
