Issue

When the ARX system is unable to determine whether a file or directory operation succeeded on a back-end filer, the ARX system temporarily locks the directory and logs a TAKE_PERSIST_LOCK:: PEND message to the ARX syslog.

For example:

2009-03-17T05:41:43.354+0000:arx01:4-1-ASM-1606:DNAS_PGRP-5-5-TAKE_PERSIST_LOCK:: PEND: Taking persistent lock on directory /vol1/Data/Home/jsmith/operations/ (did 0x1d00000009c2f0) for pending operation. 

A pending operation is typically caused by a temporary condition, and is not necessarily indicative of an issue. For example, a metadata operation may pend due to a network timeout or a slow back-end filer.

When the ARX system is able to determine whether a pending operation succeeded, the ARX system logs a PEND_DONE message that includes the status of the operation. In the following example, the requested operation (MKDIR) succeeded:

2009-03-17T05:41:43.354+0000:arx01:4-1-ASM-1606:DNAS_PGRP-5-5-TAKE_PERSIST_LOCK:: PEND: Taking persistent lock on directory /vol1/Data/Home/jsmith/operations/ (did 0x1d00000009c2f0) for pending operation.

2009-03-17T05:41:58.339+0000:arx01:4-1-ASM-1231:DNAS_PGRP-5-5-PEND_DONE:: MKDIR (complete) vol=("/vol1") pdid=(0x1d00000009c2f0) psid=(193) sid=(193) dirname=("marketing") imp=(0) txid=(6) [22123 442992].

Note: On a busy system, numerous messages may be logged between the TAKE_PERSIST_LOCK:: PEND message and the corresponding PEND_DONE message. To correlate these messages, compare the did values. The did value of the TAKE_PERSIST_LOCK:: PEND message will be the same as the did value of the PEND_DONE message. In the above example, both messages have a did value of 0x1d00000009c2f0.

In the following example, the requested operation failed, as indicated by the aborted status in the PEND_DONE log message:

2009-03-17T20:49:54.021+0000:arx01:2-1-ASM-2285:DNAS_PGRP-4-5-TAKE_PERSIST_LOCK:: PEND: Taking persistent lock on directory /vol1/Data/Home/jsmith/operations/ (did 0x14000000001425) for pending operation.

2009-03-17T20:50:06.939+0000:arx01:2-1-ASM-1298:DNAS_PGRP-4-5-PEND_DONE:: CREATE (aborted) vol=("/vol1") pdid=(0x14000000001425) psid=(174) sid=(174) filename=("~somefile.txt") txid=(18806) [11552 483504].

In this instance, the client would receive an error message indicating that the requested operation failed.
