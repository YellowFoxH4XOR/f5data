Description

Important: You should disable the Watchdog.State database variable only under advisement from F5 Technical Support.

The watchdog process is integral to the BIG-IP system, ensuring in the event of a system lockup, the system reboots and initiates a failover.

The Watchdog.State database variable enables and disables the watchdog process. This variable is enabled by default to allow the process to correctly monitor the system. Some situations may require you to disable the watchdog process for troubleshooting purposes, but only under the advisement of F5 Technical Support.

Disabling the watchdog process can cause adverse effects in the BIG-IP system. In addition to preventing the BIG-IP system from rebooting during a system lockup, disabling the watchdog process also prevents vCMP guests from correctly starting.
