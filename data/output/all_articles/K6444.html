Topic

The BIG-IP Link Controller big3d process can process any type of probe requests, whereas the BIG-IP Link Controller gtmd process is limited on the probing it can initiate. The gtmd process can send probes only to objects it is licensed to control, such as links or virtual servers — the gtmd process cannot send probes to objects it is not licensed to control, such as host servers.
