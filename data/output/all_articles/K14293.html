Known Issue

The TMM on a VIPRION uses a default MTU size of 1500, which may cause excessive packet fragmentation what packets processed have MTUs greater than 1500.

This issue occurs when all of the following conditions are met:

  • The virtual server has CMP enabled.
  • The virtual server handles network packets that exceed the MTU size of 1500.

Impact

The fragmented packets may result in IP header collisions and data corruption.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Data transferred through a BIG-IP virtual server may be corrupted.
