Description

Unable to build NGINX Ingress Controller Image

Error message says:

#44 11.10 W: Failed to fetch https://pkgs.nginx.com/plus/R31/debian/dists/bookworm/InRelease Certificate verification failed: The certificate is NOT trusted. The certificate issuer is unknown. Could not handshake: Error in the certificate verification. [IP: 10.10.10.10 8080]


Environment

NGINX Ingress Controller Image


Cause

Proxy in environment not allowing the connection


Recommended Actions

Allow list pkgs.nginx.com in the proxy


Additional Information

You can test the connectivity by running curl --key nginx-repo.key --cert nginx-repo.crt https://pkgs.nginx.com/plus/R31/ -v
Also, make sure the nginx-repo.crt and nginx-repo.key are in the kubernetes-ingress folder.
