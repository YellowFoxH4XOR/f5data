K000160355: IP Intelligence Feed Updates Fail Due to Missing Certificate/Key Files on BIG-IP Advanced WAF

Type
Support Solution
Published
2026-03-16
Updated
2026-03-16
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.3, 17.1.2, 17.1.1
Source

Description

Automatic updates for IP Intelligence feeds on BIG-IP Advanced WAF fail with errors indicating missing production certificate and key files required for secure communication with F5 API servers. Error messages in logs include:

  • No production cert file found.
  • No production key file found.
  • Command (openssl rsa -in none ...) failed.
  • Error: Exception caught in script. Check logs (/var/log/hitless_upgrade.log) for details

Environment

  • Product: BIG-IP Advanced WAF
  • Device licensed and managed by BIG-IQ, but last license activation performed manually on the device
  • IP Intelligence auto-update feature enabled

Cause

The root cause is the absence of the "api.f5.com" certificate and key files on the BIG-IP system. This occurs when license activation is performed manually rather than using the automatic method, especially in BIG-IQ managed environments. The missing files prevent secure communication with F5 API servers, blocking IP Intelligence feed updates.

Answer/Recommended Actions

  1. Schedule a maintenance window, as license re-activation will temporarily interrupt traffic processing.
  2. Perform Automatic license re-activation on the BIG-IP device:
    • Go to System > License in the BIG-IP Configuration utility.
    • Click Reactivate.
    • Select the AUTOMATIC activation method and proceed.
  3. After activation, verify that IP Intelligence updates are functioning.
  4. If the issue persists, open a Support Ticket by collecting and providing a fresh QKview for further investigation.
  5. For BIG-IQ managed environments, consult with a BIG-IQ specialist if Automatic re-activation does not resolve the issue.

Notes:

  • Manual license activation will NOT generate the required certificates.
  • There is no manual import option for IP Intelligence updates.

Additional Information

  • The "api.f5.com" certificate and key are required for IP Intelligence, IPS, and Classification Signature updates, but not for ASM component updates (Attack Signatures, Server Technologies, Browser Challenges, Bot Signatures, Threat Campaigns).
  • An expired f5_api_com.crt certificate does not impact user traffic.
  • If your environment is managed by BIG-IQ and the issue persists after automatic re-activation, further assistance from a BIG-IQ specialist may be required.
