Known Issue

The BIG-IP APM system may fail to encrypt server-side traffic when using the Server Side SSL option.

This issue occurs when the following condition is met:

  • You use the Server Side SSL option on a Citrix remote desktop resource.

Impact

Users cannot access Citrix desktops and applications.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Citrix applications and desktops do not display.
  • Network traffic between the BIG-IP system and Citrix shows that there is no Secure Socket Layer (SSL) handshake, and that the BIG-IP system is sending HTTP traffic on port 443 (HTTPS).

Resolution

Workaround

To work around this issue, you can disable the Server Side SSL option. To do so, perform the following procedure:

Note: Your Citrix servers must be able to accept port 80 (HTTP) traffic.

Impact of workaround: Communication between the BIG-IP system and the Citrix server is not encrypted, and you can view the communication as plain-text.

  1. Log in to the Configuration utility.
  2. Click Access Policy.
  3. Click Application Access.
  4. Click the Remote Desktops tab.
  5. Click the name of the Citrix remote desktop you want to edit.
  6. Clear the Server Side SSL check box.
  7. Click Update.
