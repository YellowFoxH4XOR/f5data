Description

ICMP packet drops were noticed on the BIG-IP VE hosted on Velos. User tries to ping the configured gateway IP for the management interface and the connection has been dropped. Upon checking the issue using packet capture on BIG IP VE ICMP packets are not going out of the device.

Looking at the tenant deployment status the hardware was r10900 running 1.3.2 Base OS, but the tenant is running on 17. x version.

Environment

  • BIG-IP VE
  • F5 OS Controller
  • ICMP
  • VELOS
  • Management interface
  • Tenant

Cause

Issue is due to incompatibility of the software version running on the tenant and Base OS. 

Recommended Actions

Advised to upgrade the Base OS version to 1.7.0.
