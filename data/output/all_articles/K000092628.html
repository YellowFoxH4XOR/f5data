K000092628: Configuration utility freeze on "Loading, receiving configuration data from your device"

Type
Support Solution
Published
2022-11-29
Updated
2022-12-07
Source
https://my.f5.com/manage/s/article/K000092628

Description

  • Configuration Utility may freeze on, "Loading, receiving configuration data from your device"

Environment

  • Clicking in the BIG-IP GUI
  • All configuration sections in the left side menu in the BIG-IP GUI

Cause

The delay or freeze is caused by insufficient memory provisioning setting for Management (MGMT).

Recommended Actions

Important: The BIG-IP system experiences a temporary traffic interruption as it recovers from the TMM restart, and devices configured as a high-availability (HA) pair may fail over. F5 recommends changing the Management memory size allocation during a scheduled maintenance window.
  1. Log in to tmsh by entering the following command:

    tmsh

  2. To view the current configured extra system memory, enter the following command: list sys db provision.extramb all-properties

    Output appears similar to the following:

    sys db provision.extramb {
        default-value "0"
        scf-config "true"
        value "0"
        value-range "integer min:0 max:8192"
    }

    Note: The previous example outputs the value of 0, meaning that the current provisioning is set to small in the Configuration utility (the default setting) and that no additional memory is allocated to the Management system.

  3. To modify the provisioned memory value, use the following command syntax: modify /sys db provision.extramb value <numeric value>

    Note: <numeric value> is the number of MB to additionally allocate to the host Management system.

    For example: 

    tmsh modify sys db provision.extramb value 512

  4. Save the configuration change by entering the following command:
    save /sys config
