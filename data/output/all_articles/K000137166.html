Description

The documentation for capturing packets in the debug environment of BIG-IP Next v20 refer to the network diagnostic tool tcpdump. 
How to: Log in and use the Debug utility

Environment

  • Big-IP BIG-IP-Next-CentralManager-20.0.1-0.6.79 Debug utility
  • BIG-IP version 20.0.1-2.139.10+0.0.136 traffic instance
  • Making network debug captures
  • Capturing Encrypted Traffic

Cause

The initial version of BIG-IP Next version v20 GA is not capable of decrypting packets as the --f5 ssl switch with tcpdump is not supported. 

tcpdump  --f5 ssl
tcpdump: WARNING: The "ssl" option is disabled.

Recommended Actions

This is being tracked as a known issue ID 1377553. 

Captures can be configured on a client device to capture session secrets and allow the captures from the BIG-IP to be decrypted using Wireshark see K50557518
