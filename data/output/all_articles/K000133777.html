K000133777: [F5OS-A] Unable to access "appliance-setup-wizard" errors out with "Access Denied"

Type
Support Solution
Published
2023-05-03
Updated
2023-05-03
Source
https://my.f5.com/manage/s/article/K000133777

Description

When using "root" account. It's unable to access "appliance-setup-wizard" errors out with "Access Denied", similar to the following example.


Execute \"appliance-setup-wizard\" at the CLI prompt.

Fill-in each field, as prompted.

Enter \"root\" credentials when prompt and submit.

That returns the \"access denied\" result shown below:

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

            ip addr show mgmt:

 IPv4 address...Error


{

 \"ietf-restconf:errors\": {

  \"error\": [

   {

    \"error-type\": \"application\",

    \"error-tag\": \"access-denied\",

    \"error-path\": \"/openconfig-system:system/f5-mgmt-ip:mgmt-ip/config/ipv4/

system/address\",

    \"error-message\": \"access denied\"

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


Environment

  • F5OS-A (from cases found on R4800, R5900 platform)
  • Any running F5OS-A software version

Cause

The appliance-setup-wizard needs to use the "admin" account to run successfully and is meant to set the box into appliance mode where root account is disabled.


 Recommended Actions

Use the "admin" account to access "appliance-setup-wizard".

Additional Information

None.
