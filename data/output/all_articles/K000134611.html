Description

BIG-IP resets connection after HTTP response from backend server with TCP reset cause as.

In /var/ltm/log you can see the following error:
011f0016:3: http_process_state_prepend - Invalid action:0x109010 Server sends too much data

In a packet capture you can see TCP RST sent by the BIG-IP with the following cause:
[F5RST(peer): HTTP Unexpected server data past end of response]

 

Environment

 

  • HTTP Unexpected server data

  • HTTP response code 204

  • No Content-Length and Transfer-Encoding headers in the response

 

Cause

The issue is caused by the HTTP server sending data after the HTTP response code 204 No Content. This can be verified in the packet capture through Wireshark.

 

Recommended Actions

Follow the HTTP conversation and check for any additional responses after the HTTP 204 is sent. The hex dump will show the data that is added to the response.

To resolve the issue, the application owner should correct the response to ensure that no extra data is added to the response with HTTP 204 response.

Additional Information

The 204 (No Content) status code indicates that the server has successfully fulfilled the request and that there is no additional content to send in the response payload body.
