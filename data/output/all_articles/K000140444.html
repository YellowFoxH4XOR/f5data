K000140444: Importing vulnerability scan output into ASM fails due to empty URL fields

Type
Support Solution
Published
2024-07-26
Updated
2024-07-26
Source

Description

Importing vulnerability scan into ASM at Security ›› Application Security : Vulnerability Assessments : Vulnerabilities fails due to empty URL fields

Environment

  • Importing a vulnerability scan result into the Generic Scanner.
  • Security ›› Application Security : Vulnerability Assessments : Vulnerabilities
  • ASM provisioned

Cause

The scan was performed against an IP address instead of an FQDN.

Recommended Actions

Redo the scan against the FQDN, not the IP address.
