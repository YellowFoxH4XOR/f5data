Known Issue

The BIG-IP system may incorrectly advertise unavailable virtual addresses to the ZebOS routing table.

This issue occurs when all of the following conditions are met:

  • You have configured dynamic routing.
  • Your virtual address is not associated with a virtual server.
  • You have enabled route advertisement for your virtual address.

Impact

The BIG-IP system incorrectly advertises the virtual address to the ZebOs routing table as available.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Open Shortest Path First version 2 (OSPFv2) does not advertise the virtual address upon monitor state changes.
  • When viewing the ZebOS routing table output using the IMI Shell (imish) command, you observe that the virtual address is advertised. To do so, type the following command:

    imish -e "show ip route"

    For example, the command output for route domain 300 appears similar to the following example:

    # imish -r 300 -e "sho ip ro k"|grep K
    K 1.1.1.2/32 is directly connected, tmm0
