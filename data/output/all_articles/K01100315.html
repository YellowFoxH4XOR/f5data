Known Issue

Using iControl commands to create BIG-IP DNS topology records may fail.

This issue occurs when the following condition is met:

  • You attempt to create a BIG-IP DNS topology record by using the iControl representational state transfer (REST) application programming interface (API).

Impact

Attempts to create topology records by using iControl REST commands fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • iControl REST commands fail with an error message that appears similar to the following example:

    {
    "code": 400,
    "message": "Topologies must specify both regions: ldns: server:",
    "errorStack": [],
    "apiError": 4001
    }

Workaround

To work around this issue, you can create topology records by using the Configuration utility, Traffic Management Shell (tmsh), or iControl SOAP API.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
