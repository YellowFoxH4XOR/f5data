This procedure configures dynamic group mapping using the LDAP Group Object mapping method. Configure the LDAP Group Object mapping method if your LDAP schema defines group membership using a group object attribute. The following example LDAP schema defines group membership using a static group object attribute:

dn: cn=Sales,dc=siterequest,dc=com
cn: Sales
objectClass: group
member: cn=John Smith,cn=Users,dc=siterequest,dc=com

Important: If your static group object attribute contains a Relative DN (RDN) instead of a full user DN, and you are running a version of FirePass software prior to FirePass version 6.0.2 with Cumulative Hotfix HF-602-2, you cannot use the LDAP Group Object mapping method. For information about configuring a workaround, refer to K8238: Configuring dynamic group mapping using the LDAP User Object mapping method with an LDAP group object attribute.

The following example LDAP schema defines group membership using a dynamic group object attribute:

dn: cn=Sales,ou=Groups,dc=siterequest,dc=com
cn: Sales
objectclass: groupOfUrls
memberURL: ldap:///dc=siterequest,dc=com??sub?(uid=jsmith)

If your LDAP schema defines group membership using a user object attribute, configure the LDAP User Object mapping method instead. The following example LDAP schema defines group membership using a user object attribute:

dn: cn=Linda Carry,ou=people,dc=siterequest,dc=com
cn: Linda Carry
objectClass: person
sn: Carry
memberOf: cn=sales,ou=groups,dc=siterequest,dc=com

Configuring dynamic group mapping using the LDAP Group Object mapping method

Because LDAP implementations and schemas vary widely, replace the objects and attributes in the following examples with the objects and attributes used in your LDAP schema:

dn: cn=John Smith,cn=Users,dc=siterequest,dc=com
cn: John Smith
objectClass: person
sn: Smith
description: Sales Associate
givenName: John

dn: cn=Sales,dc=siterequest,dc=com
cn: Sales
objectClass: group
member: cn=John Smith,cn=Users,dc=siterequest,dc=com

To configure dynamic group mapping using the LDAP Group Object mapping method, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users: Groups: Dynamic Group Mapping page.
  3. Select the Determine the user's master group dynamically using the master group mapping table check box, located under the Group Mapping Sequence tab.
  4. Navigate to the Users: Groups: Master Groups page.
  5. Click the Create new group button.
  6. In the New Group name field, enter the name of the new Master Group.

    For example:

    Sales
  7. In the Users in group menu, select External.
  8. In the Authentication method menu, select LDAP.
  9. Click the Create button.

    You are redirected to the Master Group configuration page.
  10. Under the General tab, select the Allow users to be assigned to this master group using dynamic master group mapping check box.
  11. Click the Authentication tab.
  12. For the Host, Port, Use SSL connection, Protocol version, and Follow referrals options, configure the settings required for your LDAP server.

    Note: The Follow referrals option appears in FirePass version 6.0.2 and later.
  13. Click the Lookup user's DN using template button.

    Note: This example configures the Lookup user's DN using template option. For your LDAP schema, you may need to configure the Lookup user's DN using query option.
  14. In the User DN template field, enter the DN template.

    For example:

    cn=%logon%,cn=Users,dc=siterequest,dc=com
  15. Click the Save Settings button.
  16. Click the Test button.
  17. Enter a valid LDAP username and password in the Username and Password fields, and then click the Test button.
  18. If the LDAP test passed, proceed to the next step. If the LDAP test failed, compare the information you entered in Steps 12 through 14 with your LDAP server configuration and schema, and adjust the FirePass configuration as necessary.
  19. Navigate to the Users: Groups: Dynamic Group Mapping page.
  20. Click the Group Mapping Methods tab.
  21. In the Mapping methods drop-down menu, select LDAP (group object).
  22. Click the Add mapping method button.
  23. Click the Configure link next to the LDAP (group object) mapping method.
  24. For the LDAP Server, LDAP Port, Use SSL connection, Protocol version, and Follow referrals options, configure the settings required for your LDAP server.

    Note: The Follow referrals option appears in FirePass version 6.0.2 and later.
  25. In the User DN field, enter the LDAP bind DN.

    For example:

    cn=Administrator,cn=Users,dc=siterequest,dc=com
  26. In the User password field, enter the password for the LDAP bind DN.
  27. Select the Get user DN using query button.
  28. In the Search Base DN field, enter the base DN for your LDAP query.

    For example:

    dc=siterequest,dc=com
  29. In the Query template field, enter the template for your LDAP query.

    For example:

    (&(objectclass=person)(cn=%logon%))
  30. In the Static members attribute field, enter the LDAP group object attribute that contains the full user DN.

    For example:

    member

    Note: This example configures the Static members attribute field. If your LDAP schema defines group membership using a dynamic group object attribute, configure the Dynamic members attribute field.
  31. Click the Update button.
  32. Click the Master group mapping table tab.
  33. Select LDAP (group object) from the Master group mapping table drop-down menu.
  34. Click the Add button.
  35. In the LDAP group object DN column, enter the full DN of the LDAP group you want to map.

    For example:

    cn=Sales,dc=siterequest,dc=com
  36. In the FirePass Group column, select the name of the Master Group you configured in Step 6.

    For example:

    Sales
  37. Click the Add button.
  38. Enter a valid LDAP username and password in the User name and Password fields, and then click the Test button.


If the LDAP group mapping test passed, the procedure is complete. If the LDAP test failed, compare the information you entered in Steps 24 through 36 with your LDAP server configuration and schema, and adjust the FirePass configuration as necessary.
