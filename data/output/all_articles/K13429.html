Known Issue

FirePass may block non-HTML data from being downloaded.

This issue occurs when the following conditions are met:

  • Non-HTML data, such as a PDF document is accessed.
  • The client is an Apple iPad.

Impact

Affected users are unable to access non-HTML data.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Affected clients receive an error message that appears similar to the following example:

    Security exception: Non-HTML data has been blocked for security reasons
