Known Issue

This is the result of a known issue. On FirePass 4000 platforms you may see false Battery Voltage warnings under the Main Board section of the Device Management: Monitoring: System Health page. If the Enable system alert E-mails checkbox on the System Health page is selected, the FirePass administrator receives email alerts for this false warning.

F5 Product Development tracked this issue as CR65407, and it was fixed in FirePass version 5.5.2 and 6.0.1. For more information about upgrading, refer to the FirePass release notes.

Additionally, a hotfix has been issued. For FirePass version 6.0.0, this issue was fixed in Cumulative Hotfix 600-1. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Downloads site.

Applying the hotfix disables monitoring of the motherboard battery in order to prevent false alarms. As a result, the Battery Voltage entry is removed from the Device Management: Monitoring: System Health page.

For instructions about how to obtain a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about how to install a hotfix, refer to K3430: Installing FirePass hotfixes.
