Known Issue

Network access sessions may continuously disconnect and reconnect.

This issue occurs when all of the following conditions are met:

  • Split tunneling is configured for network access.
  • The Prohibit routing table changes during Network Access connection option is enabled for network access.
  • The client device is successfully connected to network access.
  • A previously disconnected network adapter is connected to the client device.

Impact

Users are unable to maintain the network access connection. 

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Network access sessions may continuously disconnect and reconnect until you manually disconnect them.
  • You view error messages in the BIG-IP Edge Client report log that appear similar to the following example:

Resolution

Status

F5 Product Development has assigned ID 666783 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table.

Workaround

To work around this issue, you can disable the Prohibit routing table changes during Network Access connection option in Network Settings.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
