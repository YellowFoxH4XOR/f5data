K000140166: CRL fails with connection error: ssl_basic_crypto_cb:703: alert(20) Decryption error

Type
Support Solution
Published
2024-06-27
Updated
2024-06-27
Source
https://my.f5.com/manage/s/article/K000140166

Description

CRL validation does not work. In the BIGIP's logs you may see the following message:

(null connflow): Connection error: ssl_basic_crypto_cb:703: alert(20) Decryption error


Environment

Dynamic CRL validator

SSL profile

TLS1.3 in use

Cause

ID1366217

Recommended Actions

Do not use TLS1.3 or use static CRL by assigning a CRL file to the client SSL profile
