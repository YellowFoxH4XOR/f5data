Known Issue

This is the result of a known issue. When a user accesses a PDF file through Portal Access using Adobe Reader 9, and the user is in protected workspace, the file may fail to open with the following error message:

An internal error occurred.

Additionally, the following error message may also be reported:

There is a problem With Adobe Acrobat/Reader. Please exit Adobe Acrobat/Reader and try again.

This issue occurs when all of the following conditions are met:

  • The client system is running Windows Vista
  • User Account Control (UAC) is enabled in Windows Vista
  • The user connected to FirePass using Internet Explorer (IE)
  • Protected Mode is enabled for the current Web content zone in IE

    Note: By default, Protected Mode is disabled for the Trusted Sites zone. In FirePass versions 6.0.3 and 6.1.0, users must add the URL of the FirePass controller to the IE Trusted Sites zone in order to enter protected workspace.

F5 Networks Product Development is tracking this issue as CR133643.

Workaround

Users can work around this issue by connecting to FirePass using an alternate browser, such as Firefox.

Additionally, users can work around this issue by disabling Protected Mode for the Web content zone (typically the Trusted Sites zone) to which the FirePass URL is assigned. IE displays the current Web content zone and Protected Mode status in the Status Bar. For example:

Trusted sites | Protected Mode: On

Important: Disabling Protected Mode may decrease the security of the Windows Vista system. Users should perform this workaround at their own risk.

Note: For instructions about enabling and disabling Protected Mode, refer to the Configuring Protected Mode section of the following Microsoft article:

http://msdn.microsoft.com/en-us/library/bb250462%28VS.85%29.aspx
