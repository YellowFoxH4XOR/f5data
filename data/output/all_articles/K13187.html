Issue

Old Behavior

In versions earlier than BIG-IP 10.2.3, Secure Sockets Layer (SSL) cipher strings that were used to specify the list of SSL ciphers available to Client or Server SSL profiles included ciphers from the NATIVE and COMPAT SSL stacks.

For example, the following cipher strings included ciphers from both the NATIVE and COMPAT SSL stacks:

  • DEFAULT
  • ALL
  • LOW
  • MEDIUM
  • HIGH
  • EXP
  • etc.

BIG-IP SSL profiles can use ciphers from two different SSL stacks; the NATIVE stack is built into the Traffic Management Microkernel (TMM), and the COMPAT stack is based on the OpenSSL library. The NATIVE stack is an optimized SSL stack which the BIG-IP system can use to leverage hardware acceleration. F5 recommends that you use the NATIVE stack, as it is suitable for most SSL connections.

Note: The words NATIVE and COMPAT can also be used as cipher strings to specify the SSL ciphers that are included in an SSL profile. For example, using the NATIVE string in the SSL profile configures the virtual server to use ciphers from the NATIVE SSL stack.

New Behavior

Beginning in BIG-IP 10.2.3 and 11.0.0, cipher strings (excluding the COMPAT string) include ciphers from only the NATIVE SSL stack.

To configure an SSL profile to use ciphers from the COMPAT SSL stack, you must specify the COMPAT cipher string in the profile.

F5 Product Development tracked this change as ID 225510.

Note: Beginning in BIG-IP 14.0.0, F5 removed the COMPAT SSL stack and associated SSL ciphers from TMM, and you can no longer use them in SSL profiles. For more information, refer to K56282309: The COMPAT SSL stack has been removed from TMM.

Impact

SSL ciphers previously available to the profile may not be available to process SSL connections after upgrading.

Recommended Actions

If your SSL profile uses a cipher string that selects ciphers from the COMPAT SSL stack, you may be required to update the cipher string after upgrading to BIG-IP 10.2.3 or 11.0.0. To configure an SSL profile to use ciphers from the COMPAT SSL stack, you must specify the COMPAT cipher string in the profile. For example, to use DHE ciphers for an SSL profile you must specify the DHE+COMPAT cipher string in the Cipher field for the SSL profile.
