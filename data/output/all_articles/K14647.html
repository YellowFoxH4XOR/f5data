Known Issue

The copy smtp command will only send emails and attachments to e-support@f5.com.

When using the copy smtp command to send maintenance files from the ARX system as an email attachment, the SMTP daemon will incorrectly send the email to the default email address (e-support@f5.com) instead of sending the email to the email address specified as the target.

Impact

The SMTP daemon will send emails and their attachments to F5 Technical Support instead of the intended recipient.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The specified email recipient does not receive emails and attachments as expected.

Workaround

To work around this issue, you can download the files from the ARX Manager GUI or CLI. To do so, perform one of the following procedures:

Saving files from the ARX Manager GUI

                Impact of workaround: None.

                • Log in to the ARX Manager GUI.
                • Click Reports.
                • Select the check box next to the desired report file.
                • Click Download.
                • Save the file to the desired location.

                  • Saving files from the ARX Manager CLI

                  Impact of workaround: None.

                  1. Log in to the ARX CLI.
                  2. Enable privileged mode by typing the following command:

                    enable
                  3. Save the desired file using the following command syntax:

                    copy <directory file> ftp://[user:password@]server/dest-path [format {text|report|csv|xml}]

                    For example:

                    copy logs syslog ftp://user:password@noc.phredco.com/syslog-switch10.txt
