Topic

You can create a local traffic policy to support selective compression for types of content that can benefit from compression.

Description

You can associate a BIG-IP local traffic policy with a virtual server to support selective compression for types of content that can benefit from compression. For example, common text types (HTML, XML, and CSS style sheets) can realize performance improvements, especially across slow connections, if you compress them.
