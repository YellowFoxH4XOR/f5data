K000134673: Missing /var/log/audit logs when GTM debug logging is enabled

Type
Support Solution
Published
2023-05-18
Updated
2023-05-18
Applies to
  • BIG-IP
  • BIG-IP DNS: 15.1.5
Source
https://my.f5.com/manage/s/article/K000134673

Description

Missing /var/log/audit logs when GTM debug logging is enabled because messages might be suppressed.

For example enabling/disabling GTM pool members.

 

You may see the related message in /var/log/ltm:

systemd-journal[PID]: Suppressed <count> messages from /system.slice/runit.service

 

Environment

  • GTM (now known as DNS)
  • GTM debug logging enabled
  • Missing /var/log/audit messages

 

Cause

This is expected behavior related to K70501143 : Configure systemd-journald log suppression

 

 

Recommended Actions

systemd-journald can be configured not to perform any log suppression, in order to have all the output from gtmd written to the gtm log:

1. Edit /etc/systemd/journald.conf, and add these two lines (the defaults are 30 and 1000) inside the [Journal] section

 

RateLimitInterval=0

RateLimitBurst=0

 

2. Restart journald to apply the changes:

 

# systemctl restart systemd-journald
