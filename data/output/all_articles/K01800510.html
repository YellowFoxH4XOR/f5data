Description
Software upgrade and/or hotfix installation fails with error "failed (Cannot enumerate packages on target partition)"

Environment

  • Upgrade
  • BIG-IP has an extremely large UCS archive (e.g. 900MB)

Cause
During a software upgrade the BIG-IP creates a UCS archive and copies it to the target boot location. For extremely large UCS archives this may fail.

Recommended Actions

Increase the "var" disk space in the new boot location using the following command:
Note: Replace the "x" with the target boot location number. For HD1.2 this would be "2". Or you can get the correct name from the output of "lvscan".

lvresize /dev/vg-db-sda/set.x._var -L +5G --resizefs
bigstart restart lind
