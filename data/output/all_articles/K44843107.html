Known Issue

The BIG-IP ASM bd process may produce a core file when you have configured an extraction for a parameter.

This issue occurs when the following conditions are met:

  • You have configured extraction properties for a parameter.
  • The response is truncated in the middle of a tag.

Impact

The BIG-IP ASM system fails to process traffic while the bd process restarts. A failover may occur if the BIG-IP ASM system is part of a high-availability (HA) group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the /var/log/bd.log file, you may observe messages similar to the following example:

    BD_MISC|CRIT |<DATE>|12345|signals.c:0076|Received SIGSEGV - Core Dumping
  • In the /var/core directory, you may observe a core file that appears similar to the following example:

    bd_bld473_0_core_7328.gz
