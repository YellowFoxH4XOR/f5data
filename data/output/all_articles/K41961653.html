Description

Add one iRule to ALL virtual servers.

Environment

  • BIG-IP LTM
  • Virtual Servers
  • iRules

Cause

None

Recommended actions

  1. Create a file with the name of all virtual servers that need your iRule:

    Note: The following command will create a list of all virtual servers on the system, adjust it as needed in case just some virtual servers are needed and not all.

    tmsh show ltm virtual | grep Ltm:: | awk '{print $3}' >> /shared/tmp/virtual_list.txt

  2. Create the following script replacing New_iRule with the correct name of the iRule you need to apply (line 3, conserve the '' characters):

    #!/bin/bash

    new='New_iRule' #This needs to be changed with the correct iRule name
    noneRules='rules none'

    for i in $(cat /shared/tmp/virtual_list.txt)
      do
        rule=`tmsh list ltm virtual $i rules | egrep -v "\{|\}" | xargs`
        if [[ "$rule" == "$noneRules" ]]
          then
            tmsh modify ltm virtual $i rules { $new }
            echo "iRule $new was added to $i"
          else
            tmsh modify ltm virtual $i rules { $rule $new }
            echo "iRules $rule were conserved and added $new to $i"
        fi
    done
    tmsh save sys config

  3. Give execute permission to the script:

    chmod u+x <script_name>

  4. Run script:

    ./<script_name>

    For example:

    ./my_script
