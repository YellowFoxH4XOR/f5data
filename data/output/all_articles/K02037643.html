Description

One of the BIG-IP DNS devices in Synchronization group is serving the old DNSSEC key when running "dig DNSKEY mydomain. @<DNS Listener IP> +multiline"

Environment

  • BIG-IP DNS
  • DNSSEC
  • bigip_gtm.conf shows the correct keytag while performing "dig DNSKEY mydomain. @<DNS Listener IP> +multiline"

Cause

This happens when Iquery communication was broken and upon expiration of rollover timer, new DNSSEC keys are generated independently on each BIG-IP DNS box.

Recommended Actions

To work around this issue, ensure that the iquery connections between all the DNS Devices are connected.
The following command can be used to display the status of all Iquery Connections: 
#tmsh show gtm iquery 

Once verified, restart the TMM process on the box where DNSSEC key in DNS config that does not match the DNSSEC key used by TMM. 
Impact of workaround: Please perform this workaround during a maintenance  windows as restarting the affected TMM process will interrupt traffic processing on the BIG-IP system.

  1. Log in to the BIG-IP command line.
  2. To restart the TMM process, type the following command:
    bigstart restart tmm
