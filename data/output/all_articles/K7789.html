Known Issue

This is the result of a known issue. When using the Auto installation option, loading Network Access on a Mac OS X client fails. When the Auto installation option is selected, a blank pop-up window appears, and the Network Access client plug-in is not downloaded.

When you start a Network Access favorite from a Mac OS X client that does not have the Network Access client plug-in installed, the FirePass controller will display a pop-up window with the two following options:

  • Auto installation
  • Download and run a standalone installer package

If you select Auto installation, the FirePass controller displays a pop-up window with a message similar to the following example:

Installing Network Access for the first time. Please wait...

The FirePass controller will then display a blank pop-up window, with the following URL:

https://firepass.mycompany.com/vdesk/javalauncher/
launcherror3.php3/PACKAGE%20/signature%20is%20invalid%20

Note: The title bar may be compressed and therefore display only a portion of the URL.

The Java console containing Java debugging information may also appear, if the Safari browser is configured to display the Java console. You may close the blank pop-up window and the Java console without risk to your FirePass session.

F5 Product Development tracked this issue as CR81633 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

This issue was fixed in cumulative Hotfix HF-601-5 for FirePass version 6.0.1. You may download this hotfix or a later version of the cumulative hotfixes from the F5 Downloads site.
