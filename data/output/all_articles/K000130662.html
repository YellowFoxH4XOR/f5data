Description

If the Data Group name contains a special character such as a period ( . ), or a hyphen ( - ) and no brace characters are used around the name in the iRule, the Tool Command Language (Tcl) misinterprets the Data Group name when a connection triggers the iRule. Accordingly, the iRule may fail to locate the Data Group name and you may find the error message in /var/log/ltm:

err tmm2[17860]: 01220001:3: TCL error: /Common/iRule_example.com <DNS_REQUEST> - bad option "-p": must be -all, -index, -element, -name, or -value while executing "class match [string tolower [DNS::question name]] contains example.com"

Environment

  • DNS query
  • iRule

Cause

If the Data Group name contains a special character such as a period ( . ), or a hyphen ( - ) and no brace characters are used around the name in the iRule, iRule may interpret it as an option, rather than a string, to match against the datagroup. 

 Recommended Actions

You may use either of the two methods below as a solution:

  • use the option -- in iRule to terminate option processing

-- Terminates option processing (useful if the <item> or <class> begins with a hyphen).

  • enclose the Data Group name with brace characters ( { } )

Additional Information

To locate the specific DNS queries containing bad options, you may use the filter "-Y 'dns.qry.name eq "-P"' -T fields -e frame.number -e dns.qry.name" to search in the corresponding packets.
