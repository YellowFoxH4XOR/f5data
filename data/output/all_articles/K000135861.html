Description

The following logs are found when BIG-IP is configured for DNSSEC with external HSM after upgrading to nShield client v12.60.11+
rfs-sync and gtm sync fails

/var/log/gtm

 nfmakepath: need ${HOME} but not set and no default

 DNSSEC HSM: rfs-sync failed.

 DNSSEC HSM: rfs-sync failed all retries, giving up.

 err gtmd[456]: 011a0005:3: hookOnChild: SYNC syncer exited with error code 255

 

Environment

  • BIG-IP DNS
  • DNSSEC with external HSM
  • nShield client v12.60.11+
  • Unable to sync config in gtm sync group

Cause

Bug ID 1137569

Recommended Actions

An engineering hotfix can be provided on request.
 

Additional Information

Follow these instructions if one of the BIG-IP's in the GTM sync group is configured as RFS.

Due to Bug 1168237, the BIG-IP DNS device with gtm.peerinfolocalid == 0 should be configured as the RFS to ensure encrypted keys are synchronised in the sync group.

Verify the gtm.peerinfolocalid on each device using the following command:
tmsh list sys db gtm.peerinfolocalid

If necessary, uninstall the client software and reinstall RFS on the correct device.

Uninstall the client software using the following command:
nethsm-thales-install.sh -u

Refer to manual chapter for your BIG-IP software version for installation instructions.
