Description

Packet filter log doesn't reflect the log entry immediately on GUI.

Check if the expected log entries are seen in /var/log/pkfilter. 

LTM1 notice tmm1[17719]: 01250001:5: /Common/VS1 (9516070): no action on /Common/Vlan1, len: 66 [IPv4 52 192.168.1.1 -> 10.10.1.1 TCP 61571 -> 80 S]
LTM1 notice tmm1[17719]: 01250001:5: /Common/VS1 (9519999): no action on /Common/Vlan1, len: 66 [IPv4 52 192.168.1.1 -> 10.10.1.1 TCP 55517 -> 80 S]
LTM1 notice tmm1[17719]: 01250001:5: /Common/VS1 (9523764): no action on /Common/Vlan1, len: 66 [IPv4 52 192.168.1.1 -> 10.10.1.1 TCP 57302 -> 80 S]
LTM1 notice tmm1[17719]: 01250001:5: /Common/VS1 (9540083): no action on /Common/Vlan1, len: 66 [IPv4 52 192.168.1.1 -> 10.10.1.1 TCP 59800 -> 80 S]
LTM1 notice tmm1[17719]: 01250001:5: /Common/VS1 (9566889): no action on /Common/Vlan1, len: 66 [IPv4 52 192.168.1.1 -> 10.10.1.1 TCP 62399 -> 80 S]

Environment

  • BIG-IP
  • Packet Filter
  • GUI/ Configuration Utility
  • Log messages

Cause

This might be due to the delay caused by tomcat or httpd service. 
 

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Login to the Command Line.

  2. Replicate the issue.

  3. Validate if the log entries are reflected under /var/log/pktfilter.

  4. Navigate to System > Logs > Packet Filter and validate if the log entries are seen.

  5. If entries are not reflected on GUI, restart the tomcat and httpd service.
    # bigstart restart tomcat
    # bigstart restart httpd
