Description

BIG-IQ system may fail to collect statistics of BIG-IP systems after upgrading BIG-IQ system to 6.x. 

Environment

  • BIG-IP 13.1.0.5 or later.
  • BIG-IQ 6.0.0 or later. 
  • AVR 

Cause

Beginning in 6.0.0, BIG-IQ system uses a new statistics collection method for BIG-IP 13.1.0.5 or later. The new collection method requires BIG-IP system to provision AVR module. 

Recommended Actions

Provisioning AVR module using the BIG-IP Configuration utility 
Impact of procedure:  Traffic processing will be briefly interrupted as the BIG-IP system restarts services. This may result in a failover.  F5 recommends that you perform this procedure during a maintenance window, and start with the Standby device first. 

  1. Log in to the BIG-IP Configuration utility.
  2. Click System. 
  3. Click Resource Provisioning. 
  4. In the Provisioning column, select the check box for either Minimum or Nominal for Application Visibility and Reporting (AVR) module. 
  5. Click Submit. 

Provisioning AVR module using the tmsh utility 
Impact of procedure:  Traffic processing will be briefly interrupted as the BIG-IP system restarts services. This may result in a failover.  F5 recommends that you perform this procedure during a maintenance window, and start with the Standby device first. 

  1. Log in to the tmsh utility by typing the following command:
    tmsh

  2. To provision AVR module, type the following command:
    modify /sys provision avr level <Level_Resource>
    For example:
    modify /sys provision avr level nominal

  3. Save the change by typing the following command:
    save /sys config

Additional Information 


Enable AVR on the managed BIG-IP. Ensure the BIG-IP can connect to the (offbox-tcp-addresses, offbox-tcp-port) with offbox-protocol listed in "tmsh list analytics global-settings"

For Example: With AVR provisioned, the following configuration is available on the BIG-IP, the BIG-IP will send the statistics data to the "offbox-tcp-addresses" (which is the discovery address of the DCD).

# tmsh list analytics global-settings
analytics global-settings {
    avrd-interval 30
    ecm-port 443
    enable-bigiq-configuration enabled
    offbox-protocol https
    offbox-tcp-addresses { 192.168.1.16 }
    offbox-tcp-port 443
    source-id 0502da74-7f67-43a1-80df-c7d8d42sefec_10.20.7.4
    use-offbox enabled
}
