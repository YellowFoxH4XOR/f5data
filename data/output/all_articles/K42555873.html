Description
You want to create a user account to be able to manage iRule and iFile only via GUI/TMSH

Environment

  • User Role Access
  • iRule Manager
  • iFile Management
  • GUI access
  • tmsh access
  • v15.x

Cause
N/A

Recommended Actions

  1. Go to System > User > User List
  2. Click Create on the top-right of corner of the User List page
  3. Fill out the User Name and Password
  4. Select iRule Manager as role and assign to a partition, then click add
  5. Select tmsh for Terminal Access
  6. Click Finished

Additional Information
When a local user with multiple roles logs in to the system, the system applies the most powerful of those roles to the user and sets the current partition to the partition associated with that role. This role remains in effect until the user changes the current partition or the user logs off the system.
