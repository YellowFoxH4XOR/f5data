Description

Beginning in the following BIG-IP versions in their respective software branches, BIG-IP Edge Client supports Windows 10 and Windows 11 on ARM64 devices.

The following BIG-IP version and APM client 7.2.2 are required.
Note: BIG-IP 17.0.0 and BIG-IP 16.1.2.2 are shipped with APM client 7.2.2. For more information, refer to K13757: BIG-IP Edge Client version matrix.
  • BIG-IP 17.x: 17.0.0
  • BIG-IP 16.x: 16.1.2.2
  • BIG-IP 15.x: 15.1.6.1

Edge client components cannot be installed on Windows 10 and Windows 11.

  • Installation process of client components is not complete
  • F5 inspector is not working
  • Error message in CTU report: 
    DisplayError, InstallRootEnumeratedDriver FAILURE: Operation not allowed in WOW64

Environment

  • Windows 10 and Windows 11 on ARM processor
  • BIG-IP Edge Client components

Cause

Prior to the BIG-IP versions listed in the description and APM Client 7.2.2, BIG-IP Edge Client on Windows 10 and Windows 11 on ARM processor is not supported.

Recommended Actions

Update your system to a BIG-IP version listed in the Description section running APM client 7.2.2 or later. For more information, refer to K81649656: Overview of APM Clients update on BIG-IP APM

If your system is running a BIG-IP major version that is not listed in the Description section, and you need to stay on the same major version for example BIG-IP 15.1.5, you can contact F5 Support to request an Engineering hotfix.

Additional Information

F5 Product Development tracked this issue as ID 713327 (APM client) and ID 1054813 (BIG-IP APM).

To fully support Windows on ARM64 devices, you need to:

  • update to at least APM client 7.2.2. This includes support for installation, functionality, troubleshooting, auto-update and uninstallation of APM Clients components for ARM64-based Windows 10 and Windows 11.
    Note: For more information on updating APM client, refer to K81649656:  Overview of APM Clients update on BIG-IP APM

  • update or upgrade your system to a BIG-IP version listed in the Description section or an Engineering hotfix provided by F5 Support. This includes the Windows BIG-IP Edge Client package that contains the required Windows component to support ARM64-based devices.

    Note: You download the BIG-IP Edge Client package for Windows from the BIG-IP system and install it on your users' devices. For instructions on how to do so, refer to K44328534: BIG-IP administrator instructions for downloading BIG-IP Edge Client for Windows and Mac OS X, and Linux clients
