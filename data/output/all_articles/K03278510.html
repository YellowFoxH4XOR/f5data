Topic

Important: F5OS-A and F5OS-C are unified in F5OS 2.0.0. For information about F5OS 2.x software versions for F5 hardware platforms, refer to K000161884: F5OS-A and F5OS-C are unified in F5OS 2.0.0.

This article discusses the distinction between F5OS-A and F5OS-C software versions for F5 hardware platforms. F5OS-A software runs on F5 rSeries appliance platforms, and F5OS-C software runs on F5 VELOS chassis platforms.

Description

F5OS-A and F5OS-C software provide the underlying operating system for F5 appliance platforms and F5 chassis platforms that use a microservices platform layer. F5OS-A software is compatible with the F5 rSeries appliance platforms. F5OS-C software is compatible with the F5 VELOS chassis platforms. 

Note: F5OS-A and F5OS-C software is not compatible with iSeries or older platforms and is not compatible with VIPRION systems. These hardware platforms are not designed to support F5OS.

F5OS-C

F5OS-C chassis platform software provides the base OS and platform layer services components for the VELOS system controllers and chassis partitions. Each F5OS-C software version is available either as a single package, which includes the system controller and chassis partition ISO images, or as separate ISO images for the system controller and chassis partition software.

For example, the following table shows the package and ISO image files available for F5OS-C 1.5.1.

FilenameDescriptionSize
F5OS-C-1.5.1-14085.tarPackage for the entire F5OS release for VELOS. Includes System Controller and Partition ISO images.9 GB
F5OS-C-1.5.1-14085.CONTROLLER.iso Complete ISO image for System Controllers. Inc. base OS and platform services for System Controllers.5 GB
F5OS-C-1.5.1-14085.PARTITION.isoComplete ISO image for Partitions. Includes base OS for blades and platform services for Partitions.4 GB

Note: F5OS-C software files are located under the F5OS Platform Software for VELOS product line of the F5OS product family/group on the MyF5 Downloads page.

F5OS-A

F5OS-A appliance software is distributed as a single ISO image, which contains the base OS software and the platform layer services components for F5 rSeries platforms. Unlike the VELOS system, there are no system controllers or chassis partitions on F5 rSeries platforms, so there is no need for separate ISO image files.

The following table shows the ISO image files for F5OS-A 1.5.0.

FilenameDescriptionSize
F5OS-A-1.5.0-5781.R2R4.isoISO for rSeries 2000 & 4000 Appliance3 GB
F5OS-A-1.5.0-5781.R5R10.iso ISO for rSeries 5000 & 10000 Appliance4 GB

Note: F5OS-A software files are located under the F5OS Appliance Software product line of the F5OS product family/group on the MyF5 Downloads site.

Recommendations

When running the VELOS system, use the latest F5OS-C long-term support (LTS) release when possible. When running the F5 rSeries platform, use the latest F5OS-A LTS release when possible.
