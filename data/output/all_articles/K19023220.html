Description

Bot Defense Whitelisted IP addresses are sometimes sent challenges and request are blocked.

Environment

  • Source IP address: X.X.X.X
  • URL: Any
  • Mitigation and Challenge: Disabled

Cause

Before the whitelisting of the intended IP address, there are additional items.

Therefore, the order appears as follows:

  • Source IP Address: Any and URL: /xyz
  • Source IP Address: X.X.X.X and URL: Any

The first order item with Source 'Any' is applied to all requests. Requests that match these conditions bypass bot defense and the rest are challenged.

If the request doesn't match the first item then it checks the subsequent item and so on.

Recommended Actions

As whitelisting is based on the Source which is either IP address or Geolocation, reorder the intended IP addresses ( or Geolocation ) to the top of the list.

Note: Place items with specific IP address and/or URL on the top while the wildcards or Any should be in the bottom of the list.
