Topic

In various versions of the Microsoft Windows operating system, the Shell Command File file type is used to execute local shell commands. Due to its frequent use as an attack vector for malware and viruses, many security systems will block or quarantine attachments using the .scf file extension. For environments in which BIG-IP single configuration files (SCF) need to be transmitted through email, you can work around this issue by creating the SCF with a different extension. While the bigpipe export command automatically appends the .scf extension to the file, you can use UNIX redirection to save the SCF with a custom extension by entering the following command:

bigpipe export - > <mySCF.ext>

Similarly, the bigpipe import command requires an SCF to have an .scf extension. However, you can use UNIX redirection to load an SCF with a custom extension by entering the following command:

bigpipe import - < <mySCF.ext>

You cannot use the equivalent command in tmsh in this manner because tmsh does not support UNIX redirection.

Note: For more information about the BIG-IP SCF, refer to K8435: Overview of the single configuration file (SCF).
