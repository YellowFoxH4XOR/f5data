K58134586: Error when trying to upgrade from GUI: Server Error -- Illegal reference

Type
Support Solution
Published
2022-04-11
Updated
2023-02-21
Applies to
  • VELOS Platforms
Source
https://my.f5.com/manage/s/article/K58134586

Description

When attempting to upgrade from the GUI, repeatedly received "Server Error -- Illegal reference" messages
 

Environment

  • During ISO upgrade
  • F5OS v1.0.1
  • R10900

Cause

ISO may still be in the 'verifying' phase, indicating some corruption during upload

show system image

VERSION      ISO STATUS     DATE                IN USE
-------------------------------------------
1.0.1-14867  verifying                          false
1.0.0-11432  ready           2021-12-03         false

 

Recommended Actions

Remove and attempt to add the image again:

1. Try to remove the current image using the following commands:

    config
    system image remove iso 1.0.1-14867
    end

2. attempt to re-import the ISO file for 1.0.1-14867, per the usual (via the GUI)
