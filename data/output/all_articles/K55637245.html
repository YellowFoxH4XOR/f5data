Description

After adding any file to an imported workspace, when browsing to the LX workspaces list, the BIG-IP Configuration Utility throws an error like the one below:

 01070711:3: Caught runtime exception, boost::filesystem::status: Permission denied: "/var/ilx/workspaces/Common/test/rules/test_irule.tcl"

Environment

  • BIG-IP with iRules Language Extensions (iRulesLX) licensed and provisioned
  • A user recently import an iRulesLX workspace into the BIG-IP
  • Subsequently, a user successfully adds a file e.g. iRules, Node.js source file or any other file type to the said imported workspace
  • The user attempts to access the LX workspaces list

Cause

The LX workspace has insufficient SELinux security context which is being tracked in ID 1088961

Recommended Actions

Actioning the below command addresses the SELinux security context and will allow the user to access the LX workspaces page normally:

  • chcon -R system_u:object_r:irules_ilx_t:s0 /var/ilx/workspaces/Common/<NAME OF WORKSPACE>
