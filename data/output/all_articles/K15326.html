Topic

BIG-IP APM 12.x and earlier use browser plug-in APIs to install and launch secure remote and network access from the Google Chrome and Mozilla Firefox browsers. The browser plug-in is key for providing the F5 webtop experience and performing endpoint security checks.

BIG-IP APM 12.x and earlier also use Java Applet plug-in technology in the following ways:

  • Deliver remote desktop connectivity for Mac and Linux users with applets.
  • Deliver VPN-less TCP connectivity using the Application Tunnel feature with applets.
  • Real-time rewriting of Java code to allow applet-enabled internal web apps to proxy network connectivity back to BIG-IP APM for forwarding to corporate servers, also referred to as Java patcher.

Description

The Chromium project, Google Chrome, and Mozilla Firefox are ending support for Netscape plug-in APIs. Beginning in BIG-IP 12, Safari is also removed NPAPI plug-in support. Internet Explorer may block plug-ins and has also reached end of support on June 15, 2022.

Note: For more information about this change to the Chrome browser, refer to Google Chrome crx warning. This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

Oracle also ended support for all browser-based Java applets in all versions of the Java Runtime Environment (JRE).

BIG-IP APM 13.0.0 and later versions provide a solution that preserves the F5 plug-in-based webtop experience from earlier versions through the use of helper applications, which are installed on the user's system and handled with protocol handlers. For more information, refer to the F5 Helper Applications for Chrome, Firefox, and Edge Browsers for BIG-IP 13.0.0 release notes.

BIG-IP APM 13.0.0 and later also provide Microsoft Remote Desktop connectivity using Native RDP.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

F5 continues to support VPN portal access, also known as clientless VPN, and other BIG-IP APM browser plug-in-based features in BIG-IP 12.x and earlier. However, when browser vendors discontinue plug-in support, F5 will no longer update BIG-IP APM browser plug-ins for these browsers. F5 will continue to invest effort and resources into the development of the BIG-IP Edge Client APM for customers who are unable to upgrade to BIG-IP 13.0.0 or later. The endpoint security checking moves from browser-launched functionality to functionality inside the BIG-IP Edge Client and helper applications.

Recommendations

You should upgrade to BIG-IP APM 13.0.0 or later. If you cannot upgrade your BIG-IP system, when the Netscape plug-in APIs are no longer available in Chrome, Firefox, or Safari, F5 recommends that you host the BIG-IP Edge Client installer for your user base.

Note: Installation of the BIG-IP Edge Client on a client device when the client package option Web Browser Add-ons is enabled (the default), installs browser add-on components that allow users of the device to initiate access sessions using a web browser (Internet Explorer, Microsoft Edge, Mozilla Firefox, or Google Chrome). The BIG-IP Edge Client is available through a BIG-IP APM access policy webtop link.

Note: The application is a browser protocol handler for the f5-vpn protocol. The URI takes the following form: f5-vpn://

Note: F5 recommends that you disable the Network Access Client link for the webtop.

Note: Installation of access policy browser plugins may fail for the Firefox browser when connecting to a BIG-IP APM virtual server where the virtual server SSL certificate is not deemed valid by a CA of the Firefox CA certificate store.
