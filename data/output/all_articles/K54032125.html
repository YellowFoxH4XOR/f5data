Description

From two different platform devices (for example: Nitrox Cavium III vs Coleto Creek onboard compression)you might observe the compressed size of the same request URL will be a discrepancy even though the uncompressed size is the same:

Device i10800:

URL: https://www.test.com/
Bytes In (downloaded): 117.9 KB   <<---!! 
Uncompressed Size: 1,138.8 KB

Device 10200s:

URL: https://www.test.com/ 
Bytes In (downloaded): 60.3 KB <<---!! 
Uncompressed Size: 1,138.8 KB

Environment

  • Compression profile applied
  • Compression setting is identical between different platforms
  • Nitrox Cavium III
  • Coleto Creek onboard compression

Cause
The 10200s runs dual Cavium Nitrox CN3540 chips, while the i10800 does not run a dedicated compression chip, instead relying on the Intel HD8955 Coleto Creek CPU onboard compression. The path by which the payload gets compressed is not identical between hardware platforms. This means in practice is that the compression rates will differ between platforms. The Nitrox cards perform somewhat better than the Cave Creek, but does not have explicit numbers for Coleto Creek.

 

Recommended Actions

If you want to increase more compression rates, please consider below: 
  • Modify setting the 'gzip Compression Level' value higher on devices running low compression rates. 
    Note: Increasing the value will consume more CPU resources.
