K000160006: IPv6 Virtual Server is unreachable after upgrading to 17.5.x

Support Solution
Published
2026-02-13

Source
https://my.f5.com/manage/s/article/K000160006

Description

After upgrading a BIG-IP VE running in Hyper-V to 17.5.x, IPv6 Virtual Servers are unreachable.

Packet captures from a client on the same subnet as the Virtual Server show ICMPv6 Neighbor Solicitation messages being sent out for the Virtual Server address, but no ICMPv6 Neighbor Advertisement messages for the address are being received.

Packet captures on the BIG-IP do not show any ICMPv6 Neighbor Solicitation messages being received for the Virtual Server address.

 

 

Environment

- BIG-IP VE running on Hyper-V

- This may also effect VEs running on Azure

- v17.5.x

- xnet-dpdk driver in use

 

 

Cause

This may be related to ID2219929. Review the conditions in the bug tracker to confirm whether this BIG-IP is impacted.

 

 

Answer/Recommended Actions

As a quick workaround, switch back to the sock driver, which was the default prior to 17.5.0. For a longer-term solution, upgrade to a release that includes the fix for ID2219929. If no fixed release is available, you may request an Engineering Hotfix through F5 Support.
