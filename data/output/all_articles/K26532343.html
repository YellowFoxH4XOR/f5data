K26532343: Cannot discover the device - Error Message: minimumRto 5000 must be between 0 and 4999

Type
Support Solution
Published
2020-02-17
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K26532343

Description

  • Device discovery fails with an error messageI:
    Failed to copy configuration to working-config: reason: Failed copying from source to target: java.lang.IllegalArgumentException:minimumRto 5000 must be between 0 and 4999

Environment

  • BIG-IQ
  • Rediscovery of BIG-IP device
  • TCP profile with RTO (Retransmission Timeout) value bigger than 4999

Cause

RTO value is set to value bigger than 4999 for a TCP profile which is not acceptable by BIG-IQ.

Recommended Actions

  1. Go to your BIG-IP managed by BIG-IQ.
  2. Go to Local Traffic > Profiles > Protocol > TCP
  3. Find TCP profile with a value of minimum-rto bigger than 4999
  4. Change value directly on the device to match requirements (so it should be between 0-4999)
  5. On BIG-IQ, go to Devices > BIG-IP-devices > Affected Device > Services
  6. Press Rediscovery
  7. Press Reimport

Additional Information

None
