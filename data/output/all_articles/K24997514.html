Issue

Error Message

debug mcpd[<PID>]: 0107143b:7: CMI connection debug info: <message>

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <message> is a message related to centralized management infrastructure (CMI) inter-device configuration synchronization.

For example:

debug mcpd[7849]: 0107143b:7: CMI connection debug info: CmiPeers::send_msg_to_device_group()

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The log level for the mcpd process is set to debug.

Typically, this message indicates a change in state, such as when a device connects or disconnects.

Impact

The impact of the messages is generally low, but varies depending on the message.

Recommended Actions

For systems in an error state, review the logs for higher priority messages related to the issue.  Once troubleshooting is complete, you should restore the log level for the mcpd process to the default setting. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Restore the log level for the mcpd process to the default value by typing the following command:

    modify /sys db log.mcpd.level reset-to-default
