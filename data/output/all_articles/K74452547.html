Description

tmsh command shows following such results.

/bin/bash: /ltm: No such file or directory

Syntax Error: unexpected argument "bash"

Environment

  • BIG-IP system

Cause

The following lines appear in the configuration :

/config/bigip_base.conf

#TMSH-VERSION: 13.1.3.6

cli alias shared /Common/modify { 
    command bash
}

config/bigip_user.conf

}
cli alias private list {
    command bash     
    user admin
}

Recommended Actions

  1. Check whether this is an intentional configuration by administrator.

  2. it can be deleted and recover the bash error messages as following command.

        [root@bigip] config # tmsh delete cli alias private list
        [root@bigip] config # tmsh save sys config

Additional Information

None.
