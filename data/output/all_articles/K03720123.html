K03720123: ASM Remote Logging Profile Not Sending User-Defined Storage Format

Type
Support Solution
Published
2021-11-16
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.X.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.X, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.2
Source

Description

When creating a ASM Remote logging Profile and using User-Defined Storage Format you may find that the remote syslog server is not receiving the events.

  • Log Events are not arriving on Remote Syslog Server(s)
  • Configuration Utility Accepts Configuration without Error
  • ASM not forwarding syslog events

Environment

  • Using the User-Defined Storage Format 
  • No Errors from Configuration Utility or tmsh
  • ASM Remote logging Profile

Cause

The User-Defined storage format items require a delimiter and the configuration utility does not currently add these for you.  Not including the delimiter will not trigger an error in the configuration utility or tmsh but the syslog events will not be forwarded to the the remote server(s).

Recommended Actions

When adding items to the User-Defined field in Storage Format add a delimiter between the items.

Configuration Utility

  • Security  ››  Event Logs : Logging Profiles  ››  Edit Logging Profile
    • Application Security Section
      1. Storage Destination: Remote Storage
      2. Logging Format: Comma-Separated Values
      3. Storage Format: User-Defined
         

TMSH Utility

  • tmsh list security log profile <profile_name>

    Example:
    Correct User-Defined Formatting:
    format {
                    type user-defined
                    user-string destip=%dest_ip%,srcip=%ip_client%,request=%request%,response_content=%response%,response_code=%response_code%,support_id=%session_id%,dest_ip=%vs_name%
                }

    Incorrect User-Defined Formatting:
    format {
            type user-defined
            user-string destip=%dest_ip%srcip=%ip_client%request=%request%response_content=%response%response_code=%response_code%support_id=%session_id%dest_ip=%vs_name%
                }
