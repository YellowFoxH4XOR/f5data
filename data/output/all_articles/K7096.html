Known Issue

This is the result of a known issue. The BIG-IP GTM system saves LDNS path and persistence information to the /config/gtm/ldns.gz file. In rare cases, the ldns.gz file may contain a negative value for a path RTT (round trip time) metric that will cause the gtmd process to stop processing the file. As a result, BIG-IP GTM may delete some LDNS path and persistence data.

F5 Product Development tracked this issue as CR74799 and it was fixed in BIG-IP GTM 9.3 and 9.4.2. For information about upgrading, refer to the BIG-IP GTM Release Notes.
