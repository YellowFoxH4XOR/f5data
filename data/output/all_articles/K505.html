Topic

HP OpenView is an SNMP monitoring tool from Hewlett-Packard that works with the F5 Networks SNMP Management Information Base (MIB), LOAD-BAL-SYSTEM-MIB. To use it, download the LOAD-BAL-SYSTEM-MIB.txt file from the /usr/local/share/snmp/mibs directory, or access it through the Configuration utility.

Some versions of OpenView MIBwalker do not import F5 MIBs correctly.
