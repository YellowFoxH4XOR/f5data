Known Issue

This is the result of a known issue. If you configure client proxy settings for a Network Access connection with the Do not display tray icon for connection option for the connection enabled, the FirePass client-side component does not configure the client proxy settings in Internet Explorer when a user launches the connection.

Note: The Network Access client proxy settings feature requires Internet Explorer 5.0 or later.

F5 Product Development tracked this issue as CR98694 and it was fixed in FirePass 6.0.3. For information about upgrading, refer to the FirePass release notes.

This issue still exists in the FirePass version 5.x branch.

Additionally, cumulative hotfix HF-602-5 has been issued for FirePass 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by disabling the Do not display tray icon for connection option. To do so, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Click Network Access.
  3. Click Resources.
  4. In the Resource Group menu, select the resource group you want to configure.
  5. Click the Customization tab.
  6. Clear the Do not display tray icon for connection check box.
  7. Repeat Step 3 through 5 for each affected resource group.
