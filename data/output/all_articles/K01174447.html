Known Issue

Configuration synchronization (ConfigSync) may automatically apply changes to the peer device.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured as a member of a Sync-Failover device group.
  • Your BIG-IP APM system is also configured as a member of a Sync-Only device group that is set with the Automatic Sync option.
  • Your configuration is synchronized to the peer device.
  • You modify an access profile access policy.
  • The Sync-Only device group automatically synchronizes the change to the peer device.

Impact

A configuration change is unexpectedly applied to the running configuration on the peer device.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After you modify an access profile access policy, the configuration change is already part of the running configuration.

    Note: Expected behavior is that the peer device displays the Apply Access Policy notice.
