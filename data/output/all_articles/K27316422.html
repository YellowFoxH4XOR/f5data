Issue

Error Message

warning tmm[<PID>]: 01260034:4: SSL decryption canceled.

In this error message, note the following:

  • <PID> is the process ID for the tmm process.

For example:

warning tmm[10164]: 01260034:4: SSL decryption canceled.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The SSL decryption process is intentionally canceled during the SSL handshake (with the client-side terminating an SSL connection).

Impact

None
