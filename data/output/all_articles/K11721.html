Known Issue

This is the result of a known issue. When you configure an HA group using the Configuration utility, only pools configured in the active administrative partition are displayed. If you previously added pools from another partition to the HA group, those pools are removed when you click the Update button.

F5 Product Development is tracking this issue as ID 226504 (formerly CR141643).

Workaround

You can work around this issue using the bigpipe ha group command. To add a pool to an HA group, use the following command syntax:

bigpipe ha group <groupname> pools <poolname> { scoring { threshold <thresh#> weight <weight#> } } add

<groupname> is the HA group name, <poolname> is the name of the pool, <thresh#> is the threshold number, and <weight#> is the weight number.

For example:

bigpipe ha group myHaGroup pools http-B { scoring { threshold 1 weight 10 } } add

After all of the pools have been added to the HA group, run the bigpipe save command to save the changes.

Important: Future changes to the HA group must be made using the bigpipe ha group command, since the Configuration utility will only load and save pools from the active administrative partition. For more information about the bigpipe ha group command, refer to the Bigpipe Utility Reference Guide.
