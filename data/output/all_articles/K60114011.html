Description

The iRules REST::send method was designed before F5 standardized on a public facing REST interface. As a result, the provided documentation for the iRules REST:send method refers to internal REST endpoints. Furthermore, the REST::send method does not support returning results. So even if a valid endpoint is provided, typical validation of the request based on returned HTTP codes and application data cannot be performed.

Environment

  • Any BIG IP iRules implementation attempting to use the iRules REST::send method.

Cause

F5 Product Development has assigned ID 840785 to this issue and there is no workaround available.

Recommended Actions

Do not attempt to use the iRule REST::send method until it is refactored to support responses and documented endpoints.
