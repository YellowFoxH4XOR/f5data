K3267: Transparent and translucent VLAN groups will forward spanning tree BPDU messages

Known Issue

BIG-IP server appliances (non-switch models) that are in a standby state will forward Spanning Tree BPDU messages, if they are configured with a VLAN group that is in transparent or translucent mode.

The normal result of this defect is an infinite bridging loop.

BIG-IP IP Application Switches (those with a four-digit model number, such as 2000, 2400, 5000, and so forth) are not affected by this defect.

F5 Product Development is tracking this issue as CR28422 and CR41982.
