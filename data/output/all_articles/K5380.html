Topic

This article covers how to specify allowable IP ranges for SSH access to the BIG-IP or Enterprise Manager systems.

Description

You can update the SSH access list from both the Configuration utility and the command line. The access list is stored in the /etc/hosts.allow file and the configuration applies to both the management interface and the Traffic Management Microkernel (TMM) interface self IP addresses.

Important: The /etc/hosts.allow file is auto-generated and you should not manually edit the file.

To update the SSH access list, perform one of the following procedures:

  • Update the SSH access list from the Configuration utility
  • Update the SSH access list using the command line (BIG-IP 11.x and later or BIG-IQ 6.x and later)

Important: F5 recommends that you use the Configuration utility instead of the command line to update the SSH access list.

To watch a video demo of these procedures, go to  Specify allowable IP ranges for SSH access.

Update the SSH access list from the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to System > Platform.
  3. Under User Administration, for SSH IP Allow, select Specify Range, then enter the IP addresses or address ranges for the remote systems allowed to use SSH to communicate with this system.

    Important: Separate the IP address entries with a space. If you separate the IP addresses with a comma, a non-working entry is added to the /etc/hosts.allow file which potentially prevents you from reconnecting to the network through SSH.

    Note: When specifying a single IP address, do not specify the subnet (/32 or 255.255.255.255).

    For example, to restrict access to only systems on the 192.168.0.0 network and the single host 10.10.10.1, enter the IP addresses in the following format:

    192.168. 10.10.10.1

    You can use a netmask to restrict access to a range of IP addresses.

    For example:

    192.168.0.0/255.255.0.0

    You can also use a prefix length.

    For example:

    192.168.0.0/16

  4. Select Update.

Update the SSH access list using the command line (BIG-IP 11.x and later or BIG-IQ 6.x and later)

To update the SSH access list from the command line, perform the following procedure:

  1. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  2. (Optional) View the current SSH access list by entering the following command:

    list /sys sshd allow

  3. Specify an IP address or range of IP addresses that should be allowed by using the following command syntax:

    modify /sys sshd allow add {<ip_addr> or <ip_range> }

    Important: Separate the IP address entries with a space. If you separate the IP addresses with a comma, a non-working entry is added to the /etc/hosts.allow file, which potentially prevents you from reconnecting to the network through SSH.

    Note: When specifying a single IP address, do not specify the subnet (/32 or 255.255.255.255).

    For example, to add the 192.168.0.0 network and the single host 10.10.10.1 to the existing list of IP addresses that are allowed to log in to the system, enter the following command:

    tmsh modify sys sshd allow add { 192.168. 10.10.10.1 }

    You can use a netmask to restrict access to a range of IP addresses.

    For example:

    modify /sys sshd allow add { 192.168.0.0/255.255.0.0 }

    You can also use a prefix length.

    For example:

    modify /sys sshd allow add { 192.168.0.0/16 }

    Important: After you specify all of the addresses you want to be allowed, remove any addresses that you no longer want to allow, such as the default ALL entry which matches all IP addresses.

  4. To delete an IP address or range of IP addresses that should no longer be allowed, use the following command syntax:

    modify /sys sshd allow delete {<ip_addr> or <ip_range> }

    For example, to delete the default ALL entry from the existing list of IP addresses that are allowed to log in to the system, enter the following command:

    modify /sys sshd allow delete { ALL }

  5. Save the configuration by entering the following command:

    save /sys config
