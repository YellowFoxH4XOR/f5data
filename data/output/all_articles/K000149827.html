Description

This article explains how to identify the current version of the IP geolocation database installed on the BIG-IP device.

Environment

  • BIG-IP 
  • IP geolocation database

Cause

None

Recommended Actions

You can see the IP geolocation database version when you run the geoip_lookup command. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To query the IP geolocation database for the location of a specific IP address and view the version of the database, use the following command syntax:

    geoip_lookup <IP_addr>

    For example, the following command queries the IP geolocation database for location of IP address 24.24.24.24:

    # geoip_lookup 24.24.24.24
    Will attempt to lookup ip '24.24.24.24'
    No database specified.
    opening database in /shared/GeoIP/v2/F5GeoIP.dat
    size of geoip database = 22955072, segments = 9217516, version = Copyright (c) F5 Networks Inc, All Rights Reserved GEOIP2 v1, 20250217
    geoip_seek = 00e104e0
    geoip record ip = 24.24.24.24
    country_code = US
    country_name = United States
    region_name = New York
    continent_code = NA
    Scope = 24

    Review the version = string in the output of the command. In the previous example, 20250217 refers to the year, month, day of the geoip DB package build. This may not be the exact same date as the release version number in the package name.

  3. If the geoip DB is not the latest, proceed to install the latest one by following the procedures in K11176: Downloading and installing updates to the IP geolocation database
  4. (Optional) After downloading and unzipping the ip-geolocation-v2 packages, you can view details such as the release version number and build date by using the following syntax:
    rpm -qip /path/to/<geoip_file>.rpm
    For example:
    rpm -qip /shared/tmp/geoip-data-v2-Region2-2.0.0-20250217.747.0.i686.rpm
