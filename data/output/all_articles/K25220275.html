Description
Crowdstrike Falcon cannot be detected when Crowdstrike Windows Sensor filename is not the default WindowsSensor.x64.exe

From the OESIS diagnostic log, there is no Crowdstrike product information under the 'OESIS Antivirus Information' part

Environment

  • APM profile with Antivirus Checking
  • Crowdstrike Falcon installed on client side and it is running
  • Falcon instance resides in EU cloud (Lion)
  • Crowdstrike binary named WindowsSensor.LionLanner.x64.exe

Cause
Crowdstrike changed the name of the binary for Falcon instances that reside in the EU cloud (Lion). The new WindowsSensor.LionLanner.x64.exe Crowdstrike binary is not in the OPSWAT software libraries.

OPSWAT performs Endpoint Inspection checks based on registry entries which match Vendor-ID and Product-ID which match known file vendor/product file names. There is no mechanism for OPSWAT to be able to customize Malware product file names.

Recommended Actions

  • Please check with CrowdStrike to correct the filename 
  • You can also use the BIG-IP endpoint security feature to configure other access policy items to check the presence of Cloudstrike on the connecting computers. For example, you can use a Windows Process, Windows Registry, or File Check to determine if the security product is installed and enabled. For more information, refer to the following:
    • K41779111: OPSWAT does not support options for detecting third-party security products
    • The About endpoint security client-side items chapter of the BIG-IP Access Policy Manager: Visual Policy Editor manual.

      Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Additional Information
The original (default) filename of the CrowdStrike Windows Sensor (working example):

  • (from the OESIS Diaglog), the 538ef41c-4438-4957-8dba-39e576d27982 can be different for each user:
    [ProductMainExe="C:\ProgramData\Package Cache\{538ef41c-4438-4957-8dba-39e576d27982}\WindowsSensor.x64.exe"]

The WindowsSensor.LionLanner.x64.exe binary specifically for Falcon instances that reside in EU cloud (Lion) (non-working example):

  • C:\ProgramData\Package Cache\{538ef41c-4438-4957-8dba-39e576d27982}\WindowsSensor.LionLanner.x64.exe
