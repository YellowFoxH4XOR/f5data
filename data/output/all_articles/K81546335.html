Description

You may notice there is notice message generated with 10 minute interval  in /var/log/ltm as below:

May 27 08:13:13 <Hostname> notice mcpd[<PID>]: 01070410:5: Removed subscription with subscriber id avrd
May 27 08:23:39 <Hostname> notice mcpd[<PID>]: 01070410:5: Removed subscription with subscriber id avrd

Environment

  • BIG-IP
  • BIG-IQ
  • Analytics
  • AVRD

Cause

The BIG-IP managed by BIG-IQ has lost connection with DCD, and BIG-IP is trying to establish connection with DCD, if it failed to establish the connection successfully within 10 minutes, AVRD will restart itself.
Related logs can be found in /var/log/avr/avrd.log

EXTERNAL_MESSAGES|CRITICAL|May 27 21:06:51.862|12592|lib/avrpublisher/infrastructure/avr_http_connection.cpp:0214| Failed to establish connection within 600 seconds. Restarting avrd.

Recommended Actions

  1. Check the DCDs  associated to the BIG-IP with command below

tmsh list analytics global-settings
analytics global-settings {
    avrd-interval 30
    ecm-port 443
    enable-bigiq-configuration enabled
    offbox-protocol https
    offbox-tcp-addresses { 192.168.200.1 }
    offbox-tcp-port 443
    source-id be3136fb-1632-4e62-9281-22bd91812a35_192.168.200.2
    use-offbox enabled
}

  1. The offbox-tcp-addresses is the DCD IP address which BIG_IP trying to connect with, fix the connection issue will cease message

  2. If customer has removed the DCD already, you can cease the notice message with solution below 

    tmsh modify analytics global-settings use-offbox disabled
