K26620486: BIG-IQ ASM policy deployment failure

Type
Support Solution
Published
2019-09-09
Updated

Status
Legacy Content
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K26620486

Description

  • BIG-IQ Discovery of ASM fails

  • GUI error: Error querying 'ASM Policy - Signature' from path '/mgmt/tm/asm/policies/rhU5sTOt1ZSxZS8h5tuc1w/signatures' on device [target asm hostname] (10.10.10.10), network communication failed due to protocol error

Environment

  • BIG-IQ 5.4
  • Large number of ASM policy objects

Cause

BIG-IQ is sending an excessive volume of REST calls in parallel during discovery.

 

Recommended Actions

The issue can be worked around by reducing the number of parallel REST calls during discovery

  1.  On the BIG-IQ CLI execute the command: restcurl /cm/asm/preferences/discovery-batch-size -X PATCH -d {value:4}
