Known Issue

Restarting the BIG-IP system while running the tcpdump utility may cause the Traffic Management Microkernel (TMM) to create a core file.

This issue occurs when all of the following conditions are met:

  • You have started the tcpdump utility on the BIG-IP system.
  • You restart the BIG-IP system by running the following command:

    bigstart restart

Impact

TMM unexpectedly produces a core file.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM unexpectedly produces a core file while shutting down the system from the BIG-IP system command line.

Workaround

To work around this issue, you can stop any tcpdump capture prior to restarting the BIG-IP system.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
