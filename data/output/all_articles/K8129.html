Known Issue

This is the result of a known issue. After upgrading to BIG-IP ASM 9.4.2, 9.4.3, or 9.4.4, all requests through the security policy may be blocked.

When this issue occurs, the following message will be logged to the /var/log/asm file, and displayed in the Configuration utility under the Requests screen:

Illegal HTTP Format

Starting in BIG-IP ASM 9.4.2, product architectural changes were introduced that included a change to a setting in the HTTP profile called adaptive parsing. Beginning in BIG-IP ASM 9.4.2, this parameter must be set to enable for the BIG-IP ASM system to correctly process traffic. In BIG-IP ASM versions prior to 9.4.2, the adaptive parsing parameter is set to disable, but requests through the security policy are not affected for these versions.

If you perform an upgrade from any previous version of BIG-IP ASM to versions 9.4.2, 9.4.3, or 9.4.4, and the upgrade rolls forward the configuration, the adaptive parsing parameter will likely be set to disable and requests will be blocked by the BIG-IP ASM security policy.

Note: Performing an upgrade that rolls forward the configuration involves archiving the existing configuration files in the config.ucs file and storing it in the / partition prior to upgrading. Refer to the BIG-IP ASM Release Notes for more details.

If you perform a clean installation of BIG-IP ASM 9.4.2, 9.4.3, or 9.4.4, the adaptive parsing parameter is properly set to enable, and you will not experience this issue.

F5 Product Development tracked this issue as CR95758 and it was fixed in BIG-IP ASM 9.4.5. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Additionally, this issue was fixed in Hotfix BIG-IP-9.4.3-HF4 issued for BIG-IP 9.4.3, and in Hotfix BIG-IP-9.4.4-HF1 issued for BIG-IP 9.4.4. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about managing F5 product hotfixes, refer to K6845: Managing BIG-IP product hotfixes (9.x).

Resolution

Workaround

If you have performed an upgrade from a previous version of BIG-IP ASM to versions 9.4.2, 9.4.3, or 9.4.4, you can work around this issue by performing the following procedure:

  1. Log in to the command line.
  2. To enable adaptive parsing, type the following command:

    bigpipe profile http http adaptive parsing enable
  3. To save the setting, type the following command:

    bigpipe save
