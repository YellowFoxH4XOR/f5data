Known Issue

The Traffic Management Microkernel (TMM) may produce a core file while processing a protocol alert for Secure Sockets Layer (SSL) traffic.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a TCP virtual server that processes SSL-encrypted traffic.
  • During an SSL handshake between the client and the destination server, the server sends a protocol alert to the client.

Impact

The BIG-IP system temporarily fails to process traffic while the TMM process restarts. If you have configured the BIG-IP system for high availability (HA), it fails over to a peer system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM generates a core file in the /shared/core directory.
  • The BIG-IP system logs a SIGSEGV to the /var/log/tmm file at the time of the TMM core file and restart.
