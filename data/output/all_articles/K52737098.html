Description

Seeing the similar logs under /var/log/httpd/httpd_errors

err httpd[14994]: [proxy_http:error] [pid 14994] (20014)Internal error: [client 127.4.2.2:54343] AH01102: error reading status line from remote server localhost:8100, referer: http://127.4.2.1/lcdui/index.html

Environment

  • iSeries 
  • httpd
  • CLI

Cause

None

Recommended Actions

The message relates to internal communication with the front LCD panel.  This message can be ignored if not frequent.  Contact F5 support if seeing those logs frequently.

Additional Information

The LCD user interface browser(127.4.2.2) has several open connections to the AOM and host internally. 127.4.2.1 is assigned in the host side. 127.4.2.2 is assigned in the AOM side.
