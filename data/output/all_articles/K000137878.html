K000137878: Device inoperative after upgrade, showing HSB error

Type
Support Solution
Published
2024-03-26
Updated
2024-03-26
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000137878

Description

After upgrade BIG-IP remains INOPERATIVE, messages similar to the following found in /var/log/ltm. 

BIGIP.example.com chmand[8251]: 012a0000:0: FPGA firmware mismatch -  auto update, No Interruption!
BIGIP.example.com chmand[8251]: 012a0000:0:  No HSBe2_v5 PCIs found yet. possible restart to recover Dataplane.
BIGIP.example.com chmand[8251]: 012a0000:0: Dataplane INOPERABLE - only 0 HSBes found on this platform.
BIGIP.example.com chmand[8251]: 01550004:0: Dataplane init error: Dataplane INOPERABLE - only 0 HSBes found on this platform.

Environment

  • iSeries
  • BIG-IP software upgrade

Cause

Unknown

Recommended Actions

Verifying the symbolic link on another BIG-IP of the exact same model. The command to view the symbolic link is:

ls -l /config/firmware/hsb/current_version


If the symbolic link is correct, proceed with the following:

1. Rebooting BIG-IP via GRUB boot loader into previous version (rolback)
2. Delete the boot partition you previously boot into when performing upgrade
3. Reinstall software image
4. Perform upgrade again
