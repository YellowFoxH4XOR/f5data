Description

The message "Vlan allowed mismatch found" may be logged when the host and guest are configured with the same VLAN name. This occurs when the VLAN name is longer than 24 characters.

Environment

  • vCMP
  • Host and guest configured with the same VLAN name

Cause

VLAN names longer than 24 characters may be truncated, and the VLAN tag is appended. For example, a vlan with the name very_long_vlan_name_article_example and tag 4092 is truncated to:
very_long_vlan_name_art-T4092.0
and produces the following log messages:
01071322:4: Vlan allowed mismatch found: hypervisor (very_long_vlan_name_art-T4092.0:4092), guest (/Common/very_long_vlan_name_article_example:4092).
01071321:4: Vlan allowed mismatch found: hypervisor (very_long_vlan_name_art-T4092.0:4092), guest (/Common/very_long_vlan_name_art-T4092.0:-1) and (/Common/very_long_vlan_name_article_example:4092).

Recommended Actions
No action is required. This log message is benign. If you want to avoid this log message:
  1. Configure guest VLANs to match the truncated name used by vCMP.

Additional Information

vCMP can communicate a maximum of 32 characters to guests for VLAN names. VLAN names are truncated and modified to fit within this limit.
