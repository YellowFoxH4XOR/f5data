Source

Description

Unable to Enable/Disable pool members using REST Token based authentication after Upgrade for specific user

Error visible after sending PATCH to disable pool member

example:

{"code":401,"message":"Authorization failed: user=https://localhost/mgmt/cm/system/authn/providers/tmos/1f44a60e-11a7-3c51-a49f-82983026b41b/users/ab63a763-62c3-372a-883d-5cb8830fdb51



Environment

  • BIG-IP Upgrade
  • User account configured with operator role and partition-access to all-partitions
  • Token-based authentication method used for REST API calls

 

Cause

 Bug ID 718796: iControl REST token issue after upgrade


Answer/Recommended Actions

Follow K22162765 addressing REST API authentication failures with 401 Authorization failed errors
