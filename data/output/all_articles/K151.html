Known Issue

This is the result of a known issue. When you configure multiple VLAN groups, only the first VLAN group uses the mode that you specify with the vlangroups global. If the vlangroups global is set to opaque or transparent, any additional VLAN group that you configure will default to transparent mode. If the global is set to translucent, the mode of the VLAN group may switch from transparent to translucent and back.

F5 Product Development tracked this issue as CR27635 and CR41762.

Workaround

To work around this problem, set the vlangroups global to transparent, so that all VLAN groups use the transparent mode. If you require multiple VLAN groups using opaque or translucent mode, contact F5 Technical Support for assistance.
