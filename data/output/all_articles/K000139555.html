K000139555: Traffic comes in on port 443, how to send to pool nodes on port 9443

Description

You are experiencing an issue where your virtual server is currently accepting traffic on port 443, and you would like this traffic to be redirected to port 9443 when it is sent to the pool members. This typically involves altering the configuration of your load balancer to ensure that the traffic is handled correctly at both the virtual server and pool member levels.

Environment

  • Virtual server configured to listen on port 443
  • Pool members currently receiving traffic on port 443
  • Requirement to change traffic to port 9443 for pool members
  • F5 BIG-IP product environment

Cause

The need to change the destination port for traffic directed at pool members arises from your specific network or application requirements. This could be due to a number of factors such as internal port assignment policies, security considerations, or application architecture.

Recommended Actions

  1. Log in to the F5 BIG-IP Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Select the virtual server that is listening on port 443.
  4. Within the virtual server settings, locate the pool assignment.
  5. Edit the pool settings and modify the service port for each pool member to 9443.
  6. Save and apply the configuration changes.
  7. Ensure that the pool members are correctly listening on the new port 9443.
  8. Test the configuration by sending traffic to the virtual server and confirming that it reaches the pool members on port 9443.

Additional Information

When changing the destination port for pool members, it's important to verify that the pool members are configured to accept traffic on the new port and that any firewall rules or security groups are updated to allow traffic on port 9443. This ensures that the traffic is not only redirected correctly but also received and processed by the pool members.
