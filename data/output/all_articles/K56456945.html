Description

When attempting to access the Configuration Utility (GUI) of your BIG-IP, the page fails to load and /var/log/httpd_errors contains messages similar to the example below:

err httpd[<pid>]: [ssl:error] [pid <pid>] SSL Library Error: error:140890C7:SSL routines:ssl3_get_client_certificate:peer did not return a certificate -- No CAs known to server for verification?

Environment

  • BIG-IP
  • Configuration Utility

Cause

Error is generated when httpd is configured to require the client to present a certificate for authentication and the client fails to present a validatable certificate.

Recommended Actions

To verify the BIG-IP Configuration utility is configured for client certificate verification, you can run the following TMSH command from the command line of the BIG-IP device

tmsh list sys httpd
 
Example that the BIG-IP Configuration utility is configured for client certificate verification:

sys httpd {
    auth-pam-idle-timeout <value>
    ssl-ocsp-enable on        
    ssl-verify-client require 
}
 
To address the issue you can configure the client to present client certificate or disable the client certificate requirement when access the BIG-IP Configuration utility.

To disable client certificate request for the BIG-IP Configuration utility run the following TMSH commands from the command line of the affected BIG-IP device:

tmsh modify sys httpd ssl-verify-client no
tmsh modify sys httpd ssl-ocsp-enable off
tmsh save sys config
