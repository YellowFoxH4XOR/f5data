Known Issue

This is the result of a known issue. Configuration utility users are not logged when using remote TACACS+ authentication, and debug logging is enabled. Only users that attempt sshd connections are logged in the debug file.

F5 Product Development tracked this issue as CR92945 and it was fixed in BIG-IP LTM version 9.4.6. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.5-HF2, issued for BIG-IP version 9.4.5, for the BIG-IP 9.4 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about how to manage F5 Networks product hotfixes, refer to K6845: Managing BIG-IP product hotfixes (9.x).
