Description

When trying to Sync APM Policies and hanging in Sync Initiated

Environment

  • BIG-IP APM
  • APM Policy Sync
  • HA environment 

Cause

Even though a policy is not selected it will allow the sync process to go through but remain in Sync Initiated

Recommended Actions

In the APM policy Sync set the following:

  1. Navigate to:
    Access  ››  Profiles / Policies : Policy Sync

  2. Select the Policy to be sync'ed

  3. In the APM Policy Sync Pop up select the Advanced Settings making sure the policy is checked to be sync'ed

  4. Set the following to:
    Device Group: <Select Value>
    Description: <Description of policy to be Synced>
    Ignore errors due to Variable Assign Agent during sync: <no>
    Use Source configuration on Target to: <Yes>

  5. Initiate Policy Sync by hitting Sync button

  6. Policies should now be sync'ed without issue
