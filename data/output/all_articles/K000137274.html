Topic

You should consider using this procedure under the following condition:

  • You want to perform a software upgrade for a BIG-IP Next instance running on a F5 VELOS system.

Description

You can use the BIG-IP Next Central Manager to upgrade a BIG-IP Next instance running as a tenant on a F5 VELOS system. The BIG-IP Next software version you are upgrading to needs to be in the list of available tenant images on the VELOS chassis partition where the BIG-IP Next tenant resides. You can download the BIG-IP Next software from MyF5 Downloads using a local workstation and upload it to the F5 VELOS chassis partition. You can then use the BIG-IP Next Central Manager to back up the BIG-IP Next instance configuration and upgrade the BIG-IP Next instance software version. To do so, perform the following procedures:

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have a BIG-IP Next instance running on a F5 VELOS system.
  • The BIG-IP Next instance is managed by the BIG-IP Next Central Manager.
  • You have administrative access to the BIG-IP Next Central Manager.
  • You have administrative access to the F5 VELOS chassis partition where the BIG-IP Next instance resides.

Procedures

  • Upload the BIG-IP Next instance software bundle to the F5 VELOS system
  • Upgrade the BIG-IP Next instance

Upload the BIG-IP Next instance software bundle to the F5 VELOS system

Before uploading the BIG-IP Next software, you first need to download the BIG-IP Next software bundle file to a local workstation with administrative access to the F5 VELOS chassis partition where the BIG-IP Next instance resides. You can then log in to the F5 VELOS chassis partition and upload the file. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Download the BIG-IP Next on VELOS bundle file from MyF5 Downloads page to your local workstation. You can locate the BIG-IP Next on VELOS bundle file by selecting the BIG-IP_Next group and then F5 Systems (HW) product line on the MyF5 Downloads page. Select the desired Product Version and product container, then scroll down and select the BIG-IP-Next-VELOS-<version>.tar.bundle file. For information about downloading software from MyF5 Downloads page, refer to K167: Downloading software and firmware from F5. Proceed to the next step after you have completed the download of the bundle file you need.
  2. Log in as an Admin to the webUI of the VELOS chassis partition where the BIG-IP Next instance resides.
  3. Go to TENANT MANAGEMENT > Tenant Images.
  4. Select Upload.
  5. Select the bundle file you downloaded and start the upload process.
  6. The upload status is shown in the Image Import Status section of the Tenant Images page. Once the upload is complete the file will be unbundled by the F5 VELOS system resulting in 2 more files. For example, for BIG-IP Next version 20.0.1, the files should appear as follows:
    • BIG-IP-Next-VELOS-20.0.1-2.139.10+0.0.136
    • BIG-IP-Next-VELOS-20.0.1-2.139.10+0.0.136.tar.bundle
    • BIG-IP-Next-VELOS-20.0.1-2.139.10+0.0.136.yaml
    Wait until all the image files show a status of Replicated before proceeding.

Upgrade the BIG-IP Next instance

Before upgrading a BIG-IP Next instance, you should create a back up of its configuration using the BIG-IP Next Central Manager. To back up and upgrade a BIG-IP Next instance running on a F5 VELOS system, perform the following procedure:

Impact of procedure: Performing the following procedure for standalone BIG-IP Next instances causes a brief traffic outage and should be performed during a maintenance window.

  1. Log in to the BIG-IP Next Central Manager as an administrator.
  2. Select Manage Instances.
  3. Select the check box next to the BIG-IP Next instance you want to back up and upgrade.
  4. Select the Actions menu then select Back Up & Schedule.
  5. Enter a password for the back up file credentials.
  6. Select Back Up Now.
  7. The version column for the BIG-IP Next instance shows Back Up in progress until completion.
  8. Select the check box next to the BIG-IP Next instance you want to upgrade.
  9. Select the Actions menu then select Upgrade.
  10. Select F5 VELOS from the Provider list.
  11. For Chassis Partition IP Address or FQDN, enter the IP address or FQDN for the VELOS chassis partition where the BIG-IP Next instance resides.
  12. Select Authenticate. 
  13. Enter the administrative username and password for the VELOS chassis partition and select Submit.
  14. For Tenant, enter the name of the tenant to upgrade. The tenant name can be located in the TENANT MANAGEMENT > Tenant Deployments page of the VELOS chassis partition webUI.
  15. For Image, enter the BIG-IP Next software version to which you want to upgrade. You can view the available BIG-IP Next images on the TENANT MANAGEMENT > Tenant Images page of the VELOS chassis partition webUI. For example, to upgrade to BIG-IP Next version 20.0.1, enter BIG-IP-Next-VELOS-20.0.1-2.139.10+0.0.136. 
  16. Select Upgrade, then select Upgrade in the pop up to confirm. You will be back to the My Instances page on the BIG-IP Next Central Manager.
  17. The version column for the BIG-IP Next instance will display Upgrading during the upgrade process. Once complete, the version column will display the upgraded BIG-IP Next version.
