Description

When there is an alpha-numeric character after a period or a dot "." in the URI path, BIG-IP ASM detects the last suffix as a File Type. These trigger violations as 'Illegal File types'.

For example, the following request contains a period with an alpha-numerical character: 

/myrequest/abc/contains/dot.here
/request/xyz/contains/dot.23C6
/request/xyz/contains/dot.1FE
/request/xyz/contains/dot.540
/request/xyz/contains/dot.2558

In the above examples, 23C6,1FE,540 & 2558 are identified as File Types.

Environment

  • BIG-IP ASM
  • File type
  • Alarm/ Block flag enabled
  • Illegal File Type violation

Cause

Functioning as designed.
 

Recommended Actions

To avoid ASM in recognizing the URI path suffix as a File Type, create an explicit URL in Allowed URLs on the configuration utility by following below path.

Security ›› Application Security : URLs : Allowed URLs : Allowed HTTP URLs

Example:
For URL path /myrequest/abc/contains/dot.here,create a wildcard URL with below format,
/request/xyz/contains/dot.[a-zA-Z0-9]
