Description

Windows 10 clients hang on cache and session control in access policy

Environment

  • BIG-IP APM
  • BIG-IP Edge Client
  • Windows 10
  • Endpoint security
  • Cache and session control

Cause

Bug ID 759793

Recommended Actions
To avoid this issue you can refrain from using cache and session control in your access policy.

Additional Information
Cache and session control is being deprecated in a future release.
