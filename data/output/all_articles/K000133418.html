Description

Why are BIG-IPs logging Liveupdate logs in the /var/log/tomcat/liveupdate.log directory even though the ASM module is not provisioned?

Environment

BIG-IP

Cause

Functioning as designed.

Recommended Actions

None. This is expected. Live update functionality was configured to be usable by all modules, but currently only ASM and DoS actually use it.
