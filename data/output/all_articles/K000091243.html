Description

Unable to start NGINX.

 

Error displayed:

nginx: [error] APP_PROTECT failed to get compilation status

 

Environment

  • Trial version of App Protect
  • Active NGINX Plus subscription
  • Sufficient memory available

 

Cause

Compilation error due to incompatibility.
 

Recommended Actions

Upgrade to Debian version 10.

None.
