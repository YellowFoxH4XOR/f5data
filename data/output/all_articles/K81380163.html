Description

You may see similar messages in the audit log after a link failure:

<Date> <Time> <Hostname> notice mcpd[8460]: 01070417:5: AUDIT - client Unknown, user %bcm56xxd - transaction #144098-1 - object 0 - modify { interface { interface_name "1.1" interface_media_active 512 interface_status 1 interface_vendor_name

<Date>  <Time>  <Hostname> notice mcpd[8460]: 01070417:5: AUDIT - client Unknown, user %bcm56xxd - transaction #179626-1 - object 0 - modify { interface { interface_name "1.1" interface_media_active 917665 interface_status 0 interface_vendor_name

  • interface_status 1 means the link is down
  • interface_status 0 means the link is up

Environment

  • BIG-IP 10350F

Cause

The message will appear when there is an interface status change and they are generated by the bcm56xxd process to report the interface status to mcpd

Recommended Actions

  • Verify physical connectivity
  • Refer to AskF5 article K62013114 for additional troubleshooting steps
