Known Issue

The BIG-IP ASM system does not completely install the MySQL database if the BIG-IP ASM system is not provisioned when you load the user configuration set (UCS).

This issue occurs when all of the following conditions are met:

  • The UCS that you are loading contains BIG-IP ASM provisioning and a BIG-IP ASM configuration.
  • You are loading the UCS onto a system that is not provisioned for the BIG-IP ASM system.

If the BIG-IP ASM system is not provisioned when you load a UCS, the system moves aside the BIG-IP ASM configuration to be installed later (delayed load). The system does not set permissions correctly on the moved BIG-IP ASM configuration files, and as a result, the MySQL server cannot load the files.

Impact

The BIG-IP ASM configuration is not installed properly.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP ASM configuration is not installed properly.
  • The Policy page of the BIG-IP ASM configuration utility prompts you to run the Deployment Wizard and displays the following message:

    Run the Deployment Wizard to quickly configure a new security policy using a deployment scenario.

  • BIG-IPASM security policies are missing and the Security Policies page of the BIG-IP ASM Configuration utility displays the following prompt:

    Configure Security Policy

  • Messages that appear similar to the following examples are logged to the /ts/log/ts_debug.log file:

    asm|INFO||23681|,,DBD::mysql::db do failed: Can't get stat of '/ts/var/install/ts_db.save_dir_3521.cstmp/ts_db.data.DCC.ACCOUNT_ALTERNATE_RESPONSE_FILE_HEADERS.cstmp' (Errcode: 13) at /usr/lib/perl5/site_perl/F5/ConfigSync.pm line 516.

    asm|INFO||10086|,,DBD::mysql::db do failed: The file '/var/ts/var/install/ts_db.save_dir_11945.cstmp/ts_db.data.PLC.PL_XML_PROFILE_CLIENT_CERTIFICATE.cstm p' must be in the database directory or be readable by all at /usr/lib/perl5/site_perl/F5/ConfigSync.pm line 516.

Workaround

To prevent this issue, before loading the UCS file you must provision the appropriate resources to the BIG-IP ASM module using the Configuration utility or the tmsh sys provision command. For more information, refer to the online help in the Resource Provisioning menu of the Configuration utility and the Traffic Management Shell (tmsh) Reference Guide.

To recover from this issue, you must load the UCS file again. The initial load of the UCS file will have configured provisioning for the BIG-IP ASM system, so the system does not delay the BIG-IP ASM configuration installation during the subsequent UCS load.

Impact of workaround: None.
