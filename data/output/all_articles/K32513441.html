Description

  • Synopsis of issue, question, or intent
  • /var/log/user.log and /var/log/messages are full of closed-parenthesis lines: 
    MMM DD HH:MM:SS <hostname> )
MMM DD HH:MM:SS <hostname> 
MMM DD HH:MM:SS <hostname> @
  • These logs may also be found on your remote syslog server

Environment

  • This occurs when the system logs syslog messages containing embedded newlines, such as:
    • The cron process tries and fails to send an email, because of output about a cron script.
    • Modifying the syslog 'include' configuration
    • Applying ASM policy configuration change.
    • GTM.debugprobelogging output from big3d

Cause

  • BUG ID 842669
 

Recommended Actions

  1. Remount the /usr filesystem as read+write (r+w):
    mount -o rw,remount /usr
  2. Make a backup copy of the syslog-ng configuration template:
    cp /usr/share/defaults/config/templates/syslog.tmpl /usr/share/defaults/config/templates/syslog.tmpl.orig
  3. Add write permission to the template file:
    chmod +w /usr/share/defaults/config/templates/syslog.tmpl
  4. Configure syslog-ng to rewrite the newline character
    1. Open the template file:
      vi /usr/share/defaults/config/templates/syslog.tmpl
    2. Find the 'filter f_messages' section, shown in the below text.  
      filter f_messages {
    and not facility(auth, authpriv, cron, daemon, mail, news)
    and not message("WA");
};
      then under above text, add below: 
      rewrite r_no_multi_line {
    subst("\n", " ", value("MESSAGE"), flags(global));
    subst("\r", " ", value("MESSAGE"), flags(global));
};
    3. Add "rewrite(r_no_multi_line);" to the log object that sends all source local message to the syslog pipe: 
      log {
    source(local);
    rewrite(r_no_multi_line);    # <----- add this line before 
    destination(d_syslog_pipe);
};
  5. Save the changes and quit vi.
    :wq!
  6. In order for the BIG-IP system to write out the syslog conf with the modified template, you must change the syslog configuration. To do so, use tmsh to modify the 'daemon-from' to 'info' and then back to the default of 'notice':
    tmsh modify /sys syslog daemon-from info
    tmsh modify /sys syslog daemon-from notice
  7. Verify the changes were written to /etc/syslog-ng/syslog-ng.conf.
    less /etc/syslog-ng/syslog-ng.conf
  8. Set the permissions of the template file back to read-only.
    chmod -w /usr/share/defaults/config/templates/syslog.tmpl
  9. Remount the /usr filesystem as read-only:
    mount -o ro,remount /usr
