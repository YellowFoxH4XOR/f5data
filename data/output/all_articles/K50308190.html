Known Issue

The BIG-IP AFM Packet Tester tool is available in the Configuration utility when the BIG-IP AFM system is not licensed or provisioned.

This issue occurs when the following condition is met:

  • The BIG-IP system does not have BIG-IP AFM licensed or provisioned.

Impact

The Packet Tester is available to use when it should not be available.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Packet Tester, which is a BIG-IP AFM-only tool, is available in the Configuration utility when BIG-IP AFM is not provisioned.

Resolution
