Description

Split tunneling, There are 6 options for configuration:

  • IPv4 lan address space
  • DNS address space
  • IPv4 exclude address space
  • DNS exclude address space
  • Dynamic lan address spaces
  • Dynamic exclude address spaces

Exclude has a higher priority but what happens for example if there are identical items in Dynamic lan address space and DNS exclude address space?

 

Environment

  • BIG-IP APM
  • Split tunneling

 

Cause

  • n/a

 

Recommended Actions

  1. They can not have same object in those two items.
  2. If the address space contains, both need to pass, thus exclude wins.
