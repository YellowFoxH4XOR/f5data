K6446: The BIG-IP LTM 9.1.2 installer script may inaccurately warn that a CR is not resolved

Type
Knowledge
Published
2015-03-18
Updated
2023-02-21
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 9.1.2
Source
https://my.f5.com/manage/s/article/K6446

Topic

If you install BIG-IP LTM 9.1.2 on a system that has hotfixes installed, you may receive the following warning message:

WARNING!
The products you are attempting to upgrade have hotfixes
that are not resolved by the new versions you have chosen.
BIG-IP 9.1.2 does not resolve CR58142, CR59202, CR60115.

This message is inaccurate; the CRs listed in the message are fixed in BIG-IP 9.1.2. You can safely ignore the warning message.
