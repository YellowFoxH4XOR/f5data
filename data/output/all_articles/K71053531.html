Description
After BIG-IP system is upgraded to BIG-IP v15, CPU utilization may increase due to bigd process. Packet capture file shows that some back-end servers ignore SSL session resumption attempts from BIG-IP systems and always start new SSL sessions.

Environment

  • BIG-IP v15 or v16
  • BIG-IP LTM
  • HTTPS Monitor

Cause
F5 Inc. has ID 1060541 to track this performance issue.

Recommended Actions

To mitigate this issue, customers can configure back-end services to prefer SSL session resumptions.
