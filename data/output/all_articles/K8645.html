Known Issue

This is the result of a known issue. When a BIG-IP ASM-enabled virtual server receives a request with 25 or more HTTP headers, the virtual server drops the request. Requests with less than 25 HTTP headers are processed by the BIG-IP ASM-enabled virtual server as expected.

F5 Networks Product Development tracked this issue as CR95366 and it was fixed in BIG-IP LTM and BIG-IP ASM version 9.4.5. For information about upgrading, refer to the BIG-IP LTM or ASM Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.3-HF4 issued for BIG-IP version 9.4.3, and in Hotfix-BIG-IP-9.4.4-73.1-HF1 issued for BIG-IP version 9.4.4. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

For information about the F5 Networks hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.

For information about managing F5 Networks product hotfixes, refer to K6845: Managing F5 Networks product hotfixes.
