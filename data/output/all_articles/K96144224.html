Description
When deploying a new iApp LX application, it will fail if the tenant name used matches the name of an existing partition.
In the device logs you may see similar errors to:

01020036:3: The requested value list (/PartitionNameHere/ObjectNameHere) was not found.

Environment

  • Big-IP
  • Deploying iApp LX application

Cause
The tenant name chosen while deploying an iApp LX application will be used by the Big-IP to automatically create a new partition when deploying the application. If the tenant name chosen matches an already existing partition, the deployment of the app will fail, and may even remove existing objects configured under that partition.

Recommended Actions

  1. When deploying an iApp LX application do not use a tenant name that matches an existing partition.
    Chose a unique tenant name to avoid losing configuration in existing partitions.

Additional Information
At this time there is no way to create an iApp LX application under an existing partition.
A new partition will be created for any new iApp LX application being deployed, and will be named the same as the tenant name chosen.
