Known Issue

The Open Shortest Path First (OSPF) distance command does not function correctly.

This issue occurs when the following condition is met:

  • You use the CLI interface to specify the OSPF distance without the optional Access List Name.

Impact

The distance command does not function correctly and posts a memory allocation error message.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When specifying the OSPF distance without the optional Access List Name, you view a Memory allocation failed error message.

    For example:

    [root@test:Active:Standalone] config # tmsh
    root@(test)(cfg-sync Standalone)(Active)(/Common)(tmos)# run /util imish -r 1
    test.example.local[1]>enable
    test.example.local[1]#configure terminal
    Enter configuration commands, one per line. End with CNTL/Z.
    test.example.local[1](config)#router ospf 1
    test.example.local[1](config-router)#distance 10 10.10.10.0/24
    % Memory allocation failed

  • The system is unable to save the configuration change.
