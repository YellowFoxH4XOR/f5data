K81085993: Although certificate is renewed, an error message ''SSL cert at IP <IP ADDRESS> WILL EXPIRE on <DATE>'' is logged

Type
Support Solution
Published
2021-05-19
Updated
2023-02-21
Applies to
  • Virtual Editions
Source
https://my.f5.com/manage/s/article/K81085993

Description

After renewing the device certificates next logs still appear in /var/log/gtm:

  • 011ae0f4:1: SNMP_TRAP: big3d SSL cert at IP 10.10.10.20 WILL EXPIRE on May 12 11:35:43 2021 GMT

Also, a duplicate file for "server.crt" is created:

  • /config/gtm/server.crt~

Environment

  • BIG-IP DNS
  • Certificates renewed.
  • Gtmd and big3d.
  • /config/gtm/server.crt~

Cause

  • Sometimes gtmd and big3d need to be restarted in all the BIG-IP DNS systems of the mesh to get the new certificate information. 
  • The duplicate file (server.crt~) could have old certificates.

Recommended Actions
To workaround this issue follow the below steps:
 

  1. Delete the duplicate file with old certificates
    #rm /config/gtm/server.crt~

    Note: Be aware that restarting big3d and/or gtmd causes the iQuery connection to be torn down and re-established and causes iQuery to fail to connect.

  2. Restart gtmd and big3d daemons: 
    #tmsh restart sys service gtmd
    #tmsh restart sys service big3d
