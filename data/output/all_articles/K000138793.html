K000138793: How to remove a backend server from the BIG-IP configuration

Type
Support Solution
Published
2024-03-01
Updated
2024-03-01
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.0
Source
https://my.f5.com/manage/s/article/K000138793

Description

You want to remove a backend server from the BIG-IP configuration

Environment

BIG-IP LTM

Cause

None

Recommended Actions

Using the Network Map ( Local Traffic > Network Map ) you can view the pools where the backend server you want to deleted is associated to.

Once you have identified the pools where the server is associated, go to Local Traffic > Pools

Select the pool in question , go to Members , and click on the checkbox next to the member (server you want to delete) , then select Remove.

Finally, go to Local Traffic > Node List , select the server and click Delete.

Note: Before deleting the backend server from the BIG-IP configuration, please make sure the backend server is not being used by an iRule.
