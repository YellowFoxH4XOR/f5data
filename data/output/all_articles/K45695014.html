Environment

  • BIG-IP Virtual Edition
  • Host Hypervisor capable of running startup/onboarding scripts
  • Reboot performed on the BIG-IP
Cause
The suspected cause for this issue is an automated onboarding script associated with the host hypervisor. 

Recommended Actions
  • Disable any startup scripts that may be running on the host hypervisor
  • For instructions to reset the hostname, refer to K26057357: Change the BIG-IP system host name
  1. Log in to the Configuration utility.
  2. Go to System > Platform.
  3. Under General Properties, locate Host Name.
  4. Enter the new BIG-IP system host name.
  5. If applicable, change the time zone to the correct value in the Time Zone dropdown menu
  6. Select Update.
The BIG-IP system host name should now be updated in both the Configuration utility and bash.
