Known Issue

Duplicated routes may randomly exist in the management route table.

For example, a BIG-IP system with duplicated management routes may appear similar to the following:

[root@bigip:Active:Standalone] config # ip route show | cat -n
1 127.1.1.0/24 dev tmm0 proto kernel scope link src 127.1.1.1
2 127.3.0.0/24 dev mgmt_bp scope link
3 10.1.1.0/24 dev eth0 proto kernel scope link src 10.1.1.114
4 10.1.1.0/24 dev eth0 scope link src 10.1.1.114 metric 9
5 10.10.12.0/24 dev v311 proto kernel scope link src 10.10.12.114
6 127.7.0.0/16 via 127.1.1.254 dev tmm0
7 default via 10.28.22.254 dev eth0 metric 9

In this example, lines 3 and 4 are duplicated management routes.

Impact

None. If you perform an SNMP query on the ipCidrRouteTable object, you may encounter an error. For more information, refer to K16207: An SNMP query on the ipCidrRoute table may result in an error message.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The affected BIG-IP system displays duplicated routes in the management route table.

    For example:

    10.1.1.0/24 dev eth0 proto kernel scope link src 10.1.1.114
    10.1.1.0/24 dev eth0 scope link src 10.1.1.114 metric 9

Workaround

To work around this issue, you can remove the second entry of the duplicated management routes. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP system command line prompt.
  2. To display the current management route table, type the following command:

    ip route show

  3. Take note of the duplicated management route entries.

    For example, the command output from step 2 on a BIG-IP system with duplicated management routes may appear similar to the following:

    10.1.1.0/24 dev eth0 proto kernel scope link src 10.1.1.114
    10.1.1.0/24 dev eth0 scope link src 10.1.1.114 metric 9

  4. Delete the second entry of the duplicated routes.

    For example, referencing the output example from step 3, the second entry would be the following:

    10.1.1.0/24 dev eth0 scope link src 10.1.1.114 metric 9

    To delete this entry, you would type the following command:

    ip route del 10.1.1.0/24 dev eth0 scope link src 10.1.1.114 metric 9

    Note: This duplicated management route will re-appear after the BIG-IP system reboots.
