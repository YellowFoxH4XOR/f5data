Known Issue

This is the result of a known issue. Interactive startup mode is not supported in BIG-IP 10.1.0. Pressing I or Shift+I to enter interactive startup during the booting process causes the BIG-IP system to hang.

When you boot a BIG-IP system, the system displays a message that appears similar to the following example:

Press 'I' to enter interactive startup.

F5 Product Development tracked this issue as CR134203 and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, or WOM release notes.

Workaround

If your system hangs after pressing I or Shift+I to enter interactive startup, you can exit the suspended state by pressing Ctrl+C.
