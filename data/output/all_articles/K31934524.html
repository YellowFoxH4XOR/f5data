Security Advisory Description

SYN flood protection thresholds are not enforced in secure network address translation (SNAT) listeners. (CVE-2021-22998)

Impact

Connections to SNAT listeners are not bound by SYN cookie thresholds, leaving them potentially vulnerable to SYN flood class attacks. This issue does not affect SNAT pools or SNAT Automap on virtual servers. It only applies to traffic handled exclusively by a SNAT listener, such as listeners configured in Local Traffic > Address Translation, and does not apply when the incoming traffic matches a configured virtual server. For more information about SNAT features, refer to K7820: Overview of SNAT features.
