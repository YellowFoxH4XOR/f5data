Known Issue

This is the result of a known issue. The http-acceleration profile is required for BIG-IP WebAccelerator-enabled virtual servers to ensure that the RAM Cache statistics for the virtual server are included in the BIG-IP WebAccelerator performance graphs. Statistics for the BIG-IP WebAccelerator-enabled virtual servers that do not use the http-acceleration profile are not included in the BIG-IP WebAccelerator performance graph output.

Note: For more information about choosing an appropriate HTTP profile, refer to K11777: Choosing an HTTP profile for a BIG-IP WebAccelerator-enabled virtual server.

F5 Product Development tracked this issue as CR120070 and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue was fixed in Hotfix-BIGIP-10.0.1-402.7-HF4 issued for BIG-IP version 10.0.1, and Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.
