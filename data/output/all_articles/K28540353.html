Known Issue

Virtual Local Area Network (VLAN) failsafe generates traffic using Internet Control Message Protocol (ICMP), which fails if the VLAN CMP Hash is changed from Default.

This issue occurs when all of the following conditions are met:

  • You have configured VLAN failsafe.
  • You have changed the VLAN CMP Hash on the VLAN that is configured with failsafe to Source Address or Destination Address, instead of Default.
  • When the VLAN failsafe situation occurs, and the generated ARP requests are not being answered, VLAN failsafe resorts to ICMP.

Impact

There are rare situations where failsafe triggers but it should not have.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • VLAN failsafe generates traffic using ICMP, which fails if VLAN CMP Hash is configured with any other option than Default.
