Description

Traffic still forwarding to pool members where apache services are marked down

Pool members are configured to monitor using tcp health monitors

Environment

  • BIG_IP LTM
  • Health monitors

Cause

  • TCP health monitors checks the pool member status by performing tcp handshake
  • when apache services are brought down on node, port 80/443 will shutdown gracefully, leaving room for successful response during tcp health monitor checks.

Recommended Actions

Change tcp health monitors to HTTP/ HTTPS monitors for  pool members hosting HTTP/HTTPS services.

None
