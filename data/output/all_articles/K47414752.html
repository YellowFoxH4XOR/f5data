Description
The bigip_add script is stalling out between BIG-IP devices.

Environment

  • BIG-IP GTM or DNS
  • VLAN configured with a customized MTU

Cause
The bigip_add script executes some large commands, such as a large mkdir command. These large commands can fail to reach the destination device if there is a small or mismatched MTU configured between the two BIG-IP devices using the bigip_add script.

Recommended Actions

If you are encountering this condition you should review your BIG-IP device's MTU settings and those on any other network appliances between the two BIG-IPs.

To identify that this is the issue you are encountering, you can run the bigip_add in debug mode to find the failure point
bigip_add -d <peer device self-ip>
