Topic

Attack signatures are rules that identify attack sequences or classes of attacks on a web application and its components. You can apply attack signatures to both requests and responses.

The BIG-IP ASM system contains more than 1000 attack signatures. As a result, F5 recommends defining a custom filter when displaying attack signatures in the Configuration utility.

Displaying BIG-IP ASM attack signatures using a custom filter

  1. Click Attack Signatures from the Main tab in the Application Security screen.
  2. Click Policy Attack Signatures.
  3. Click Filterbutton.
  4. Define the filter to display only the attack signatures that you want to view.
  5. Click Go.

Note: You can also click the Save Filter button to save a customized filter. The system opens a pop-up screen, where you can type the name of the customized filter. The customized filter then appears in the Filter list. You can then view or delete the custom filter later.

Custom filter definitions

  • Filter list

    The Filter list drop-down menu allows you to sort attack signatures by type. The following options are available:

    • Show all signatures: Specifies that the system displays all attack signatures assigned to the security policy. This is the default.
    • Show signatures by name: Specifies that the screen displays signatures based on a string found in the signature name. Type part of the signature name in the box. This search is not case-sensitive.
    • Show signatures of accuracy greater than/equal to: Specifies that the screen displays signatures based on their accuracy level. Select either Low, Medium, or High from the list.
    • Show signatures of risk greater than/equal to: Specifies that the screen displays signatures based on the attack’s risk level. Select either Low, Medium, or High from the list.
    • Show signatures of attack type: Specifies that the screen displays signatures based on attack type. Select an attack type from the list.
    • Custom: Specifies that the screen displays signatures that match specific filter options. You may select multiple filter settings at once.
  • Containing String

    The Containing String filter specifies whether the screen displays signatures based on a specified string found in the signature name. The following options are available:

    • Any: Specifies all signatures, which is the default.
    • String: Specifies signature names that contain a specific string. Type part of the signature name in the box. This search is not case-sensitive.
  • Signature ID

    The Signature ID filter specifies whether the screen displays signatures based on their ID number. (The system automatically provides the signature ID which cannot be changed.) The following options are available:

    • Any: Specifies all signatures, which is the default.
    • Only: Specifies only signatures with a specific signature ID. Type the signature ID in the box.
  • Apply To

    Specifies what type of signatures the system displays. The following options are available:

    • All: Specifies signatures with all Apply To values, which is the default.
    • Only: Specifies signatures that are configured to inspect either the client request or the server response. Select either Request or Response from the list.
  • Apply to Parameter

    Specifies whether the system displays signatures based on alpha-numeric user-input parameters defined in the security policy. The following options are available:

    • All: Specifies both parameter and general signatures, which is the default.
    • Only: Specifies only signatures that either apply to parameters (Yes) or do not apply to parameters (No). Select either from the list.
  • Apply to XML

    Specifies whether the system displays signatures that apply to XML documents. The following options are available:

    • All: Specifies all signatures, which is the default.
    • Yes: Specifies only signatures that apply to XML documents.
    • No: Specifies only signatures that do not apply to XML documents.
  • Attack Type

    Specifies whether the screen displays signatures based on their attack type. The following options are available:

    • All: Specifies signatures with all Attack Type values, which is the default.
    • Only: Specifies signatures configured to protect against a specific attack type, which you select from the list.
  • Systems

    Specifies whether the screen displays signatures based on the system for which they were configured. The list of systems includes web applications, web servers, databases, and application frameworks. The following options are available:

    • All: Specifies signatures that protect any system, which is the default.
    • Only: Specifies signatures configured for one or more specific systems.
    • Assigned Systems: Lists the systems protected by the signatures.
    • Move buttons: Use the Move buttons [<<] [>>] to transfer selected systems between lists.
    • Available Systems: Lists the systems available for protection.
  • Accuracy

    Specifies whether the screen displays signatures based on their accuracy level. The following options are available:

    • All: Specifies signatures that match all accuracy levels, which is the default.
    • Only: Specifies signatures that match a specific accuracy level. Select Less Than/Equal To, Equals, or Greater Than/Equal To from the first list, and then select an accuracy level, Low, Medium, or High.
  • Risk

    Specifies whether the screen displays signatures based on their risk level. The following options are available:

    • All: Specifies signatures that protect against attacks of all risk levels, which is the default.
    • Only: Specifies signatures that protect against attacks of a specific risk level. Select Less Than/Equal To, Equals, or Greater Than/Equal To from the first list, and then select an accuracy level, Low, Medium, or High from the second list. Low indicates the attack may assist the user in gathering knowledge to perpetrate further attacks, but does not cause direct damage or reveal highly sensitive data. Medium indicates the attack may reveal sensitive data, or cause moderate damage. High indicates the attack may cause a full system compromise, denial of service, and the like.
  • User-defined

    Specifies whether the screen displays signatures based on who created them. The following options are available:

    • All: Specifies all signatures, which is the default.
    • Only: Specifies either user-defined (Yes), or system-defined (No) signatures.
  • Update Date

    Specifies whether the screen displays signatures based on the date the signature was changed. The following options are available:

    • All: Specifies all signatures, regardless of when they were changed, which is the default.
    • Only: Specifies signatures which were changed before or after a specified date. Select Before or After from the list, and then click the calendar icon to select a date.
  • Learn

    Specifies whether the screen displays signatures based on the Learn settings of the signature set to which the signature belongs. The following options are available:

    • All: Specifies all signatures, which is the default.
    • Only: Specifies signatures that belong to at least one signature set with the Learn setting enabled (Yes), or signatures where the Learn setting is disabled for all the signature sets to which the signatures belong (No).
  • Alarm

    Specifies whether the screen displays signatures based on the Alarm settings of the signature set to which the signature belongs. The following options are available:

    • All: Specifies all signatures, which is the default.
    • Only: Specifies signatures that belong to at least one signature set with the Alarm setting enabled (Yes), or signatures where the Alarm setting is disabled for all the signature sets to which the signatures belong (No).
  • Block

    Specifies whether the screen displays signatures based on the Block settings of the signature set to which the signature belongs. The following options are available:

    • All: Specifies all signatures, which is the default.
    • Only: Specifies signatures that belong to at least one signature set with the Block setting enabled (Yes), or signatures where the Block setting is disabled for all the signature sets to which the signatures belong (No).
  • In Staging

    Specifies whether the screen displays signatures in staging. The following options are available:

    • All: Specifies all signatures, which is the default.
    • Only: Specifies signatures that are only in staging (Yes), or not in staging (No).
  • Enabled

    Specifies whether the screen displays signatures based on their Enabled setting. This filter specifies only whether the signatures displayed are enabled or disabled for the entire security policy, without regard to parameter-specific settings. The following options are available:

    • All: Specifies all signatures, which is the default.
    • Only: Specifies signatures whose Enabled setting is checked (Yes), or cleared (No).
  • Overrides on Parameters

    Specifies whether the screen displays signatures based on their overridden on parameters security policy settings. The following options are available:

    • All Signatures: Specifies that the system displays all attack signatures assigned to the security policy. This is the default.
    • Signatures with overrides: Specifies that the system displays parameter-specific attack signatures whose security policy settings are overridden for at least one parameter configured in the security policy.
    • Signatures without overrides: Specifies that the system displays parameter-specific attack signatures whose security policy settings are not overridden on parameters.
    • Signatures with enable overrides: Specifies that the system displays parameter-specific attack signatures whose security policy settings are overridden for at least one parameter configured in the security policy, and the attack signatures’ overridden state is Enabled.
    • Signatures without enable overrides: Specifies that the system displays all signatures assigned to the security policy, except for parameter-specific attack signatures whose security policy settings are overridden for at least one parameter configured in the security policy and whose overridden state is Enabled.
    • Signatures with disable overrides: Specifies that the system displays parameter-specific attack signatures whose security policy settings are overridden for at least one parameter configured in the security policy, and the attack signatures’ overridden state is Disabled.
    • Signatures without Disable overrides: Specifies that the system displays all signatures assigned to the security policy, except for parameter-specific attack signatures whose security policy settings are overridden for at least one parameter configured in the security policy and whose overridden state is Disabled.
