K20254383: Ephemeral Authentication configuration items in the BIG-IP APM 15.1.0 Configuration utility are not functional

Topic

In BIG-IP APM 15.1.0, configuration items for Ephemeral Authentication appear in the Configuration utility; however, they are not functional and configuring them does not result in a working configuration.  

Description

The Ephemeral Authentication feature is not fully implemented in BIG-IP APM 15.1.0; however, the configuration items in the Configuration utility for the feature are exposed. Although you can configure and save the Ephemeral Authentication configuration using the Configuration utility and the TMOS Shell (tmsh), the BIG-IP APM system ignores the configuration and provides no Ephemeral Authentication functionality.

This applies to the following configuration items in the Configuration utility:

  • Access > Ephemeral Authentication > Access Configuration
  • Access > Ephemeral Authentication > Authentication Configuration
  • Local Traffic > Virtual Servers > <virtual_server_name> > Ephemeral Authentication > Access Configuration

For more information on the current Ephemeral Authentication product offerings, contact your local F5 Partner Business Manager or Inside Sales Representative.
