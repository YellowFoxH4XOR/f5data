Known Issue

Child monitors may retain configuration settings from parent monitors.

This issue occurs when all of the following conditions are met:

  • You create a new monitor configuration.
  • The new monitor’s Reverse or Transparent configuration settings differ from the parent monitor’s settings.
  • You load the configuration.

Impact

The new monitor configuration retains the parent monitor’s Reverse and Transparent setting selections.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Prior to loading the configuration, the new monitor functions as intended. However, after loading the configuration, the new monitor fails.
  • When viewing the new monitor configuration, you notice that the initial selections that differed from the parent monitor’s Reverse or Transparent settings are reverted.

Workaround

To work around this issue, you can re-create and assign a new monitor that references a parent monitor with the intended Reverse and Transparent default settings.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
