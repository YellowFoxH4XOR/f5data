Known Issue

Changes to RADIUS remote authentication do not fully sync.

This issue occurs when all the following conditions are met:

  • Devices in a sync group sync to the system-auth.config file.
  • You make a change to RADIUS remote authentication.

Impact

Changes to RADIUS authentication are not effective throughout the device group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • With multiple devices in a sync group, changes to remote authentication are effective on the device where you made the change. For example, you make changes using the following command:

    tmsh modify auth radius system-auth servers replace-all-with { AAA_a AAA_b } 

  • Although the changes sync to tmsh config on the other devices in the group, the changes are not effective on those devices. You observe this behavior because the changes do not appear in the /config/bigip/auth/pam.d/system-auth and the /config/bigip/auth/pam.d/radius/system-auth.conf files.

Workaround

To work around this issue, you can reload the configuration on each affected device within the sync group. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected device.
  2. To save and load the configuration information, type the following command:

    tmsh save sys config && tmsh load sys config
