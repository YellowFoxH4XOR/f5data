Topic

You should consider using this procedure under the following condition:

  •  You want to use the TMOS Shell (tmsh) to test a monitor.

Description

Beginning in BIG-IP 13.1.0, you can verify a monitor configuration by testing it before applying it to a pool, a pool member, or a node. You can perform this test using tmsh.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to tmsh.
  • You have a monitor configured on the BIG-IP system.

Procedures

Using tmsh to verify a monitor configuration

To verify a monitor configuration, perform the following procedure

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To test a monitor, type the following command:

    run /ltm monitor <monitor configuration> <name of the monitor> destination <IP>:<port>

    Example of testing a custom monitor:

    run /ltm monitor http my_custom_monitor destination 1.1.1.1:80

    Example of testing a default monitor:

    run /ltm monitor tcp tcp destination 1.1.1.1:80

Using tmsh to view the test result

To view the test result, perform the following procedure

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To view the test result, type the following command:

    show /ltm monitor <monitor configuration> <name of the monitor> test-result

    For example:

    show /ltm monitor tcp tcp test-result

    The command output appears similar to the following example:

       --------------------------
       LTM::Monitor /Common/tcp
       --------------------------
       Monitor Test Result:
         Destination:  1.1.1.1:80
         Last state:   up
         State time:   2018.04.11 09:15:34 (0hr:14mins:53sec ago)
         Last result:  Test Completed (UP)
                       See /var/log/monitors/Common_tcp-Common_monitor_test-80.log
