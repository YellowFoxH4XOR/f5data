Description

When sys db nokia.alert is enabled, custom snmp traps might not work or just send with incorrect OID.

Environment

  • Custom snmp traps are configured as K3727
  • Sys db nokia.alert is enabled

Cause

When sys db nokia.alert enabled, custom alert should be firstly defined in file 

/etc/alertd/alert_nokia.conf

Recommended Actions

To workaround this issue, please add custom trap OID in file /etc/alertd/alert_nokia.conf.

For example, if you have following custom trap configured in file /config/user_alert.conf:

alert BIGIP_HIGH_CPU_THRESHOLD "Cpu utilization over 300 seconds is (.*)" {
  snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.500"
}

Then you need to add following line in file /etc/alertd/alert_nokia.conf:

.1.3.6.1.4.1.3375.2.4.0.500 26800   1       0        4      0

Additionally, if "sys db nokia.alert" is not necessary, please just disable it to workaround this issue.
