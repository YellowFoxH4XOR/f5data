Known Issue

This is the result of a known issue. Some BIG-IP Configuration utility appearance and behavior can be customized using the settings available under System > Preferences. When a BIG-IP administrator accesses this page, some of the settings may display a cached value instead of their current value. This issue occurs because these settings are saved in a text-based configuration file, and are read only when the tomcat4 or tomcat daemon starts or after one of these settings is modified using the Configuration utility. If the settings are changed by any method other than using the Configuration utility (for example by performing a configsync operation or by restoring a UCS archive), the Configuration utility will display the cached value even though the text based configuration file was updated correctly.

For example:

  • On a BIG-IP System, the Display Host Names When Possible setting is cleared (disabled).
  • A UCS archive is created.
  • A BIG-IP administrator selects (enables) the Display Host Names When Possible setting.
  • The UCS archive is restored on the BIG-IP system.
  • The text-based configuration file, which stores the Display Host Names When Possible setting, is updated successfully and the BIG-IP Configuration utility stops displaying hostnames.
  • The System > Preferences page incorrectly shows the Display Host Names When Possible setting as selected.

F5 Product Development tracked this issue as ID 223810 (formerly CR132030) and it has been fixed in BIG-IP version 11.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Workaround

If you suspect that one of the settings under System > Preferences is not displaying its current value, you can force the setting to be reinitialized by restarting the tomcat4 or tomcat daemon. To do so, type the following command from the BIG-IP command line:

  • BIG-IP versions 9.0.0 through 10.0.1:

    bigstart restart tomcat4
  • BIG-IP versions 10.1.0 and later:

    bigstart restart tomcat

Note: Restarting the tomcat4 or tomcat daemon does not affect traffic but will cause the Configuration utility to be unavailable for a few seconds.

Note: The text-based configuration file responsible for storing these settings varies depending on the version of the BIG-IP software:

  • BIG-IP version 9.x: /usr/local/www/tmui/WEB-INF/properties/systemsettings.properties
  • BIG-IP versions 10.0.0 through 10.0.1: /etc/tomcat4/systemsettings.properties
  • BIG-IP versions 10.1.0 and later: /etc/tomcat/systemsettings.properties
