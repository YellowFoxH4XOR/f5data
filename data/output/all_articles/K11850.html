Known Issue

This is the result of a known issue. The bgpd process may intermittently send corrupted route update messages to peers. This occurs when the bgpd process adds non-zero values into the prefix length field of the route advertisement message. As a result, the peer terminates the BGP peering sessions, which causes traffic disruption and performance degradation. In addition, error messages may be logged to the /var/log/zebos.log file that appear similar to the following example:

BGP: %BGP-3-NOTIFICATION: received from 10.2.0.2 3/1 (UPDATE Message Error/Malformed Attribute List.) 2 data-bytes
BGP: %BGP-3-NOTIFICATION: received from 10.2.0.10 3/1 (UPDATE Message Error/Malformed Attribute List.) 2 data-bytes
BGP: %BGP-3-NOTIFICATION: received from 10.2.0.42 3/1 (UPDATE Message Error/Malformed Attribute List.) 2 data-bytes

F5 Product Development tracked this issue as ID 225230 (formerly CR138855) and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue was been fixed in Hotfix-BIGIP-10.2.0-1755.1-HF1 issued for BIG-IP 10.2.0 and BIGIP-10.1.0-3402.0-HF2 issued for version 10.1.0. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing version 10.x hotfixes on systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).
