Description

How to solve the error "Failed to validate TLS Parameters for xxxxx: Duplicated PublicKeyAlgorithm" showed up when trying to modify the Load Balancer

Environment

  • Distributed Cloud (XC)
  • HTTP Load Balancer

Cause

Multiple certificate types are long allowed on a single Load Balancer.

 

Resolution/Answer

Use a single certificate type on individual Load Balancers (i.e. RSA, EC-DSA).
