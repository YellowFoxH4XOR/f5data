Description


The BIG-IP LTM device certificate has been renewed however the DNS/GTM iQuery communication is still down.

The following messages are observed in /var/log/gtm: 

err gtmd[14728]: 011ae114:3: iqmgmt_ssl_connect: SSL error: error:14090086:SSL routines:ssl3_get_server_certificate:certificate verify failed (336134278) from connection 10.0.0.1
 iqmgmt_ssl_connect: IP: 10.0.0.2 SSL error:14090086:SSL routines:ssl3_get_server_certificate:certificate verify failed

Environment

  • BIG-IP DNS
  • LTM certificate renewal
  • iQuery

Cause

BIG-IP DNS does not have BIG-IP LTM's new certificate in its trust store.


Recommended Actions

Run bigip_add script on the BIG-IP DNS device to exchange the certificate with BIG-IP LTM:

bigip_add <BIG-IP-LTM_IP_address>
or
bigip_add <username>@<existing_LTM_IP_address>
