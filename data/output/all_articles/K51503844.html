K51503844: LTM Policy does not insert HTTP headers in response

Type
Support Solution
Published
2020-01-22
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K51503844

Description
The LTM policy is not inserting headers on the HTTP response.

The LTM Policy is intended to insert headers into HTTP responses if they are not sent by the server.

Environment

  • BIG-IP LTM
  • LTM policy configured with:
    • Insert HTTP Header action at response time
    • HTTP Header condition at request time

Cause
The condition checks for the presence of the HTTP headers in the request and will not operate in a response context.

Recommended Actions

To work around the issue set the policy condition for response time.

Additional Information
For example, using a BIG-IP local traffic policy to insert security HTTP headers "X-Frame-Options", "X-XSS-Protection", "X-Content-Type-Options" or "Strict-Transport-Security" as per the article below.
