Description

You are unable to use TACACS+ authentication when migrating from the iSeries/vCMP platform to rSeries/VELOS platform. On the tenant level however, TACACS+ authentication is working as expected.

Environment

  • F5OS hypervisor level (F5OS-A or F5OS-C)
  • All F5OS software version.

Cause

F5OS requires extra roles to be configured on the TACACS+ server (Group IDs and system authentication roles).

Recommended Actions

Apply the extra roles on the TACACS+ server (Group IDs and system authentication roles), an example configuration for tac_plus is below:

group = admin {
   service = ppp
   protocol = ip
   {
      default attribute=permit
      F5-F5OS-UID=1001
      F5-F5OS-GID=9000
      F5-F5OS-HOMEDIR=/tmp
      F5-F5OS-USERINFO=test_user
   }
}

user = test_tacacs_user {
      global = cleartext "test-tacplus"
      member = admin
}

For more detail about configuring TACACS+ authentication on F5OS refer to the Group IDs and system authentication roles and TACACS+ configuration overview sections in VELOS Systems: Administration and Configuration / User Management or F5 rSeries Systems: Administration and Configuration / User Management.
