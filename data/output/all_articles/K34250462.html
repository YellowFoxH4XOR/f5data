Issue

Error Message

0107146f:3: Self-device <AddressType> address cannot reference the non-existent Self IP (<IPAddress>); Create it in the /Common folder first.

In this error message, note the following:

  • <AddressType> is the type of address referenced.

    For example:

    • unicast
    • state mirroring
    • ConfigSync
  • <IPAddress> is the address of the self IP address.

For example:

0107146f:3: Self-device unicast source address cannot reference the non-existent Self IP (192.0.2.100); Create it in the /Common folder first

Message Location

You may encounter this message in the following location:

  • In the /var/log/ltm log file
  • Within the Traffic Management Shell (tmsh) command

Description

This message occurs when one of the following conditions are met:

  • You have attempted to define a configuration synchronization (ConfigSync) or mirror address that is not a valid self IP address.
  • Management IP address is not unique in each BIG-IP.

Impact

The operation fails and the system does not set the address.

Recommended Actions

Verify the management IP address is unique on all BIG-IP devices

tmsh list /cm device management-ip

Creating the self IP address to use as a ConfigSync or mirror IP address

To avoid this issue, you must create the self-IP address before you use it as a ConfigSync or mirror IP address. To do so, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Network > Self IPs.
  3. Click Create.
  4. Enter the name of the new self IP address.
  5. Enter the IP address and netmask of the new self IP address.
  6. Select the appropriate VLAN from the VLAN/Tunnel drop-down menu to assign the VLAN to the self IP address.
  7. From the Port Lockdown drop-down menu, select Default.
  8. Select traffic-group-local-only from the Traffic Group drop-down menu.
  9. Click Finished.
  10. Navigate to Device Management > Devices.
  11. Click the name of the local device (Self).
  12. Perform one of the following procedures:
    • Configuring the new self IP as a ConfigSync address
      1. Click the ConfigSync tab.
      2. From the Local Address drop-down menu, select the newly created self IP address.
      3. Click Update.
    • Configuring the new self IP as a mirror address
      1. Click the Mirroring tab.
      2. From either the Primary Local Mirror Address or Secondary Local Mirror Address drop-down menu, select the new self IP address.
      3. Click Update.
