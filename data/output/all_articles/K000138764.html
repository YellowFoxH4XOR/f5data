K000138764: ClientCert LDAP not working and Certificate Verification: Error (20): unable to get local issuer certificate in httpd error log

Type
Support Solution
Published
2024-11-04
Updated
2024-11-04
Source

Description

ClientCert LDAP is being configured and not working.

In the httpd error log (var/log/httpd/httpd_errors) this error is seen:

Certificate Verification: Error (20): unable to get local issuer certificate

Environment

  • ClientCert LDAP setup

 

Cause

The CA signing certificate is not found at the location listed in sys httpd ssl-ca-cert-file.

 

Recommended Actions

  1. Verify the expected location by running tmsh command:
    list sys httpd ssl-ca-cert-file
  2. Copy the CA signing certificate into this location.
