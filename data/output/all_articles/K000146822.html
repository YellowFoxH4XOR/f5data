Description

This article explains what a CNAME record is in the context of DNS and how it functions within F5 Distributed Cloud DNS.
A CNAME (Canonical Name) record is a type of DNS record used to alias one domain name to another.

Environment

  • F5® Distributed Cloud DNS

Cause

None

Answer/Recommended Actions

  • A CNAME record is a part of the DNS zone records (that may or may not be present) that is used to essentially redirect from one record to another.
  • The CNAME record for a DNS zone will have a DNS name for the record NAME, it will be of record TYPE “CNAME”, and it will have a VALUE of another DNS name.
  • If the DNS system is looking for example.com and finds it in the NAME of a CNAME record, then it will switch to looking for the DNS name in the VALUE field.
  • The VALUE field of a CNAME record is often called the CNAME, or canonical (true) name.
