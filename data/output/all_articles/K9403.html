Topic

Always-On Management (AOM) is a separate subsystem that provides lights-out management for the BIG-IP system and F5OS system using the 10/100/1000 Ethernet management port over secure shell (SSH) or the serial console.

Description

AOM enables you to manage BIG-IP and F5OS platforms using SSH (most platforms) or the serial console, even if the Host subsystem is turned off. The BIG-IP and F5OS Host subsystem and the AOM subsystem operate independently. If AOM is reset or fails, the BIG-IP and F5OS Host subsystem continues to operate and there is no interruption to load-balanced traffic. AOM is always turned on when power is supplied to the platform. If the BIG-IP and F5OS Host subsystem stops responding, you can use the AOM Command Menu to reset it.

The AOM architecture and feature set differs, depending on the platform.

AOM (rSeries appliances)

AOM features for the rSeries appliances are as follows:

  • Supports baud configuration
  • Captures the F5OS-A system console output
  • Displays AOM firmware and bootloader information, appliance serial number, power status and runtime status; AOM network configuration; power supply manufacturer, model and serial number
  • Powers on and powers off the F5OS-A system
  • Hardware resets the F5OS-A system
  • Supports IPv4 and IPv6 access
  • Configures the AOM network (For information on configuring the rSeries AOM network, refer to K000138036: Configure AOM SSH access in F5OS-A)

AOM (VELOS CX410 and CX1610 series chassis)

AOM features for the VELOS CX410 and CX1610 chassis as well as SX410 and SX1610 system controllers are as follows:

Note: The AOM for VELOS does not support IPv4 or IPv6 access at the point of publishing.

  • Supports baud configuration
  • Captures blade console output
  • Displays AOM firmware and bootloader information, chassis serial number (only on the active system controller), system controller serial number, power status for the active console; PSU controller firmware/bootloader information and serial number; power supply manufacturer, model and serial number; fantray firmware/bootloader information, serial number and runtime status
  • Powers on and powers off a system controller
  • Powers on and powers off a specific blade
  • Hardware resets a system controller
  • Hardware resets a specific blade

AOM (VELOS BX110 and BX520 series blades)

AOM features for the VELOS BX110 and BX520 blades are as follows:

Note: The AOM for VELOS does not support IPv4 or IPv6 access at the point of publishing.

  • Displays AOM firmware and bootloader information, blade serial number, blade width, and power status for the accessed blade
  • Captures blade console output
  • Powers on and powers off a specific blade
  • Hardware resets a specific blade

AOM (2000, 4000, 5000, 7000, and 10000 series platforms)

AOM features for the 2000, 4000, 5000, 7000, and 10000 series platforms are as follows:

  • Monitors status and maintains system health
  • Turns on, turns off, and restarts the BIG-IP Host subsystem
  • Supports a hardware watchdog with a minimum five-second time-out before a hardware restart
  • It provides a command menu, but no shell access
  • Supports IPv4 and IPv6 access
  • Uses password-based authentication for SSH (root password, by default)
  • Monitors power supply
  • Provides menu options to view MAC address, serial number, and some memory configuration
  • Supports baud configuration

AOM (800, 1600, 3600, 3900, 6900, 89XX, 11000, and 11050 series platforms)

AOM features for the 800, 1600, 3600, 3900, 6900, 89XX, 11000, and 11050 platforms are as follows:

  • Monitors status and maintains system health
  • Turns on, turns off, and restarts the BIG-IP Host subsystem
  • Supports a hardware watchdog with a minimum five-second time-out before a hardware restart
  • It provides a command menu and shell access
  • Supports IPv4 access
  • Uses SSH host key authentication for SSH
  • Supports baud configuration

AOM (i800, i2000, i4000, i5000, i7000, i10000, i11000 and i15000 series platforms)

  • Monitors status and maintains system health
  • Turns on, turns off, and restarts the BIG-IP Host subsystem
  • Supports a hardware watchdog with a minimum five-second time-out before a hardware restart
  • It provides a command menu, but no shell access
  • Supports IPv4 access
  • Uses password-based authentication for SSH (disabled by default)
  • Monitors power supply
  • Provides menu options to view MAC address and serial number
  • Supports baud configuration

AOM (VIPRION 2400 series chassis)

AOM features for the VIPRION 2400 chassis are as follows:

Note: The VIPRION 2200, 4400/4480, and 4800 series chassis do not contain AOM.

  • Supports baud configuration
  • Captures blade console output
  • Displays AOM firmware and bootloader information, chassis serial and part numbers, blade serial number, MAC address, and power status for the active console
  • Powers on and powers off a specific blade
  • Hardware resets a specific blade
  • Displays an error report for sensors on the chassis

AOM (VIPRION 2100, 2150, and 2250 series blades)

AOM features for the VIPRION 2100, 2150, and 2250 blades are as follows:

  • Monitors status and maintains system health
  • Supports a hardware watchdog with a minimum five-second time-out before a hardware restart
  • Displays AOM firmware and bootloader information, chassis serial and part numbers, blade serial number, MAC address, and power status for the active console
  • Captures blade console output
  • Provides a command menu
  • Supports baud configuration

Note: The AOM for VIPRION blades does not support IPv4 or IPv6 access.
