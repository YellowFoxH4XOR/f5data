Known Issue

This is the result of a known issue. When using the ng_export command to export an access policy from the command line, you may receive the following error message:

sourceMCPD::loadDllNo user role data for root

This error occurs because the ng_export command attempts to run as a user for which it does not have access; therefore, the command fails to launch.

F5 Product Development tracked this issue as CR139094 and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP APM release notes..

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
