Description

You may find that BIG-IP may not import configuration when performing software upgrade/installation, the device stays in default factory status, and when you check the /var/log/liveinstall.log, you may find the following similar log.

Environment

  • Configuration lost
  • Upgrade software
  • Liveinstall.moveconfig
  • Liveinstall.saveconfig

Cause

This is by design. When the system database key liveinstall.moveconfig or liveinstall.saveconfig value is disabled, no configuration will be installed on the target boot location, you can get more details from K13438: Controlling configuration import when performing software upgrade/installation.

Recommended Actions

Please roll back to the old software volume, then check the database key liveinstall.moveconfig and liveinstall.saveconfig value.
tmsh list /sys db liveinstall.moveconfig value
tmsh list /sys db liveinstall.saveconfig value
If you want to BIG-IP import configuration when performing software upgrade/installation, please ensure the system database key liveinstall.moveconfig and liveinstall.saveconfig value both enable, then upgrade the software again.
tmsh modify /sys db liveinstall.moveconfig value enable
tmsh modify /sys db liveinstall.saveconfig value enable
