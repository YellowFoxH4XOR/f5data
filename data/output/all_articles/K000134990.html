Description

If you upgrade from the previous EHF fix for the issue described in K000132932 then the original problem will be present again.

Environment

  • Running EHF APM fix for K000133476 either:
    • Hotfix-BIGIP-17.1.0.1.0.6.4-ENG.iso
    • Hotfix-BIGIP-16.1.3.4.0.52.2-ENG.iso
    • Hotfix-BIGIP-14.1.5.4.0.22.2-ENG.iso or
    • or any other incremental hotfix containing ID1283645
  • Running apmclient 7.2.4.2 or 7.2.4.3 (or EHF 7.2.4.1-update1) 
  • MacOS client devices running 13.3 or later
  • APM Access policy using Endpoint Inspection

Cause

The server side fix ID 1283645 that was in the previous EHF versions are not included in the recent base 17.1.0.2, 16.1.3.5 or 14.1.5.5. but will be included in subsequent releases and are now included in specific EHF in the interim.

Bug ID 1283645 : Server-side changes for Mac Edge Client Compatibility Issues with MacOS 13.3 as the support for WebView plugin is discontinued

Recommended Actions

UPDATE: On August 18, 2023 the BIG-IP version 16.1.4 was released containing ID1283645.

As of late September fixes for ID1283645 have been included in all the latest BIG-IP versions 17.1.0.3, 16.1.4, 15.1.9 and 14.1.5.6. Upgrading to these versions now replaces the EHF below as the recommended deployment.

Upgrading to the latest APMClients (Currently 7.2.4.4) is also recommended although this issue was also fixed in the included 7.2.4.3.

Visit https://my.f5.com/manage/s/downloads and download the EHF associated with your version. 
Do not upgrade to the base 14.1.5.5 release, but use the EHF Hotfix-BIGIP-14.1.5.5.0.16.2-ENG.iso on the base 14.1.5.5.
Do not upgrade to the base 16.1.3.5 release, but use the EHF Hotfix-BIGIP-16.1.3.5.0.86.5-ENG.iso on the base 16.1.3.5.
Do not upgrade to the base 17.1.0.2 release, but use the EHF Hotfix-BIGIP-17.1.0.2.0.38.2-ENG.iso on the base 17.1.0.2.

Note that all the latest base releases (listed below) already contain the APMClients 7.2.4.2 as a built in release, and can be upgraded to the APMClients 7.2.4.3 after install.
BIGIP-14.1.5.5-0.0.2.iso is the base release for 14.1.5.5
BIGIP-16.1.3.5-0.0.5.iso is the base release for 16.1.3.5
BIGIP-17.1.0.2-0.0.2.iso is the base release for 17.1.0.2
The BIGIP-15.1.9-0.0.6.iso base release 15.1.9 and point release 15.1.9.1 already contain ID 1283645 so an EHF is not required.

If you have other existing EHF in your deployments, you should open a support case and request a new EHF with those fixes in addition to the fix for ID1283645. 

Additional Information

See K000132932, K000133476 below for derails of the original MacOS 13.3 compatibility issue.

If you are still running a BIG-IP 14.x release, you should be aware that this will be end of support at the end of the year, you are recommended to plan your upgrade to a full newer build now.
