K39732182: Partition that is created outside of k8s-managed PARTITION, can only be managed by a user with admin or resource-admin privilege

Type
Support Solution
Published
2020-10-22
Updated
2023-02-21
Applies to
  • F5 Cloud Services
Source
https://my.f5.com/manage/s/article/K39732182

Description

  • Admin role is a requirement, when using f5-controller and kubernetes

Environment

  • Kubernetes
  • F5-controller
  • BIG-IP

Cause

  • None / by design

Recommended Actions

  • None
  • A service-user must have 'administrator' or 'resource administrator' role

Additional Information

  • At the moment, only certain configurational objects (i.e. items in the k8s-managed PARTITION) can be controlled by a none admin role
  • Please note, there is an existing request to allow non-admin users to manage certain task as in Enhancement Request: allow non-admin role for the k8s BIG-IP user #695.
