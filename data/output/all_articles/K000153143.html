What Happened?

  • You'd like to know if and how does XC App Firewall provide protection against Request Smuggling attempts

Environment

  • Distributed Cloud Load Balancer
  • Web Application Firewall

Resolution/Answer

Request Smuggling attempts are mitigated by two WAF components, RFC compliance checks and Attack Signatures

 

RFC compliance is covered by following violations:

 

Violation Name Description
VIOL_HTTP_PROTOCOL_MULTIPLE_HOST_HEADERSThe request contains multiple Host headers which is against HTTP protocol standards
VIOL_HTTP_PROTOCOL_BAD_HOST_HEADER_VALUE

 The Host header in the HTTP request contains an invalid or malicious value

VIOL_HTTP_PROTOCOL_UNPARSABLE_REQUEST_CONTENTThe content of the request is unparsable indicating potential evasion or corruption
VIOL_HTTP_PROTOCOL_NULL_IN_REQUESTPresence of null characters in the request which can be an attempt to manipulate or evade security filters
VIOL_HTTP_PROTOCOL_BAD_HTTP_VERSION

 Indicates a request with an invalid or unsupported HTTP version

VIOL_HTTP_PROTOCOL_CRLF_CHARACTERS_BEFORE_REQUEST_START

Presence of CRLF (carriage return and line feed) characters before the actual start of the HTTP request which might indicate an attempt to manipulate request processing.

VIOL_HTTP_PROTOCOL_NO_HOST_HEADER_IN_HTTP_1_1_REQUESTAn HTTP 1.1 request is missing the mandatory Host header
VIOL_HTTP_PROTOCOL_BAD_MULTIPART_PARAMETERS_PARSING

Issues with parsing multipart parameters in the HTTP request indicating potential evasion or malformed data

VIOL_HTTP_PROTOCOL_SEVERAL_CONTENT_LENGTH_HEADERSMultiple Content-Length headers in the request which is against HTTP protocol standards
VIOL_HTTP_PROTOCOL_CONTENT_LENGTH_SHOULD_BE_A_POSITIVE_NUMBERThe Content-Length header should contain a positive number and the request violates this rule
VIOL_HTTP_PROTOCOL_BODY_IN_GET_OR_HEAD_REQUESTRequest had a body even though the HTTP method should not carry one
VIOL_HTTP_PROTOCOL_BAD_MULTIPART_FORMDATA_REQUEST_PARSINGContents of the multipart request body could not be parsed due to bad formatting or unexpected data
VIOL_HTTP_PROTOCOL_HIGH_ASCII_CHARACTERS_IN_HEADERSHeader contained characters outside the normal ASCII range,which can be suspicious or invalid.

 

Protection against Request Smuggling is covered by (but not limited to) following Attack Signatures:

  • 200018182
  • 200020215
  • 200018146
