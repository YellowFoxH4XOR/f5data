Description

By default, APM allow the traffic between VPN clients.

Customer may want to filter / block the traffic between VPN clients.

Environment

  • BIG-IP APM
  • Access policy
  • Network access tunnel

Cause

It is expected result.

Recommended Actions

The workaround is, enable "Packets Filter", add the Rule to filter / block the traffic between VPN clients.

For example:

  1.  Login the Configuration Utility, on the Main tab, click Network > Packet Filters.
    The Packet Filters screen opens. Configure "Packet Filtering" to Enabled, click Update. 
  2. Click Rules.
  3. Click Create.
  4. Name the rule.
  5. From the Order list, select First.
  6. From the Action list, select Discard.
  7. From the Rate Class list, select a rate class if one exists on the system.
    You cannot use this setting if you have bandwidth control policy on the system.
  8. From the Bandwidth Controller list, select a bandwidth controller policy if one exists on the system.
    You cannot use this setting if you have a rate class on the system.
  9. From the VLAN / Tunnel list, select the connectivity profile or *All.
  10. From the Logging list, select Enabled if you want to log the frame.
  11. From the Filter Expression Method list, set the proper value to block the traffic between lease pool IP address / subnet:
    Filter Expression Method:    Build Expression
    Protocols:    Any
    Source Hosts and Networks:    Restrict to any in the list, add the IP address in the lease pool.
    Destination Hosts and Networks:    Restrict to any in the list, add the IP address in the lease pool.
    Destination Port:    Any
  12. Click Finished.
