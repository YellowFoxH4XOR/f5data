Issue

Note: The behavior described in this article has changed again beginning in BIG-IP 10.1.0. For more information, refer to K11373: The external monitor location is now /config/monitors.

In BIG-IP versions prior to 9.2.2, External Application Verification (EAV) monitors can reside outside of the /usr/bin/monitors directory, as long as the full path to the monitor is specified.

Beginning in BIG-IP 9.2.2, SubDomain extension checks for access permissions were added, restricting all EAV monitors to the /usr/bin/monitors directory.

Due to this change in behavior, if a BIG-IP system is running a version prior to 9.2.2 and the configuration includes EAV monitors that are located in a directory other than the /usr/bin/monitors directory, the configuration fails to load when the system is upgraded to a later version.

To prevent this behavior from occurring, move all EAV monitors to the /usr/bin/monitors directory and update all EAV paths within the configuration.

Note: EAV monitors are not included within a configsync operation or when a UCS file is created. If you want to include EAV monitors, refer to K4422: Viewing and modifying the files that are configured for inclusion in a UCS archive.

Note: For more information about configuring EAV monitors, refer to the Configuration Guide for BIG-IP Local Traffic Management.
