Description

All logs except for the ASM event logs are not received on Manage Engine Firewall Analyzer.


Environment

  • In the Event logging profile, logging format 'Comma-Separated Values' is selected


Cause

Manage Engine Firewall Analyzer supports Syslog BSD logging format ( RFC 3164 ).

ASM Log formatting is proprietary and only supports CEF, Key-Value Pairs, CSV and Syslog.


Recommended Actions

Manage Engine Firewall Analyzer also supports the following log formats:
  • WELF
  • IPFIX
  • CEF
  • CSV
  • Key-Value Pairs

As Manage Engine Firewall Analyzer has the option to change the format to the supported options by ASM which are CEF or Key-Value, switch to either and also in the logging profile, change the format to whichever of the options is chosen.


Additional Information

The supported ASM logging formats can be found in K37655278: BIG-IP ASM operations guide | Chapter 3: BIG-IP ASM event logging
