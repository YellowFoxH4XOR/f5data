Description

We can choose to create VLANS and self IPs from CLI as well in BIG-IP with proper user permissions.

 

Environment

BIG-IP

 

Cause

Informational

 

Recommended Actions

Follow the below commands to create a VLAN and self IP.

 

If you want to create an untagged VLAN

tmsh create net vlan <vlan-name> tag <vlan-tag-id> interfaces add { <interface-name> }

 

if you want to create a tagged vlan

tmsh create net vlan <vlan-name> tag <vlan-tag-id> interfaces add { <interface-name> { tagged } }

 

Save the configuration post the creation

tmsh save sys config

 

You can use the below command to list the existing VLANs

tmsh list net vlan

 

To create self Ips with default allow-service option

tmsh create /net self <self_ip_name> address <IP_address>/<prefix_length> vlan <vlan_name> allow-service { default }

 

tmsh save sys config
