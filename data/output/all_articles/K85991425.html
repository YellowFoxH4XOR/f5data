Known Issue

BIG-IP Edge Client may fail to detect language settings on macOS Sierra 10.12. 

This issue occurs when the following condition is met:

  • You configure macOS Sierra with a language region other than English. For example, you configure the language setting to Korean with different regions.

Impact

BIG-IP Edge Client customizations do not display correctly.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Customized items of BIG-IP Edge Client, such as the logo, banner, and tray icon do not display correctly.

Workaround

To work around this issue, you can modify the language-region setting to your specific region on macOS Sierra. To do so, type one of the following commands:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  • English:

    $ defaults write -globalDomain AppleLanguages -array "en" "en-US"

  • German:

    $ defaults write -globalDomain AppleLanguages -array "de" "de-US"

  • Korean:

    $ defaults write -globalDomain AppleLanguages -array "ko" "ko-US"

  • Japanese:

    $ defaults write -globalDomain AppleLanguages -array "ja" "ja-US"

  • French:

    $ defaults write -globalDomain AppleLanguages -array "fr" "fr-US"

  • Spanish:

    $ defaults write -globalDomain AppleLanguages -array "es" "es-US"

  • Chinese traditional:

    $ defaults write -globalDomain AppleLanguages -array "zh-Hant" "zh-Hant-TW" "zh-Hant-US"

  • Chinese simplified:

    $ defaults write -globalDomain AppleLanguages -array "zh-Hans" "zh-Hans-US"
