Known Issue

Important: This issue only applies to the 6800 platform. Not all 6800 platform models are affected by this known issue.

This is the result of a known issue. The 6800 platform may experience an unexpected reboot with the following error messages logged in the /var/log/kern.log file:

CPU 0: Machine Check Exception: 0000000000000004Bank 4: f655200134080813 at 0000000008cd5b00Kernel panic: CPU context corrupt

F5 Product Development tracked this issue as CR69067 and it was fixed in a BIG-IP BIOS update.
