Known Issue

This is the result of a known issue. When a redundant BIG-IP system configured to mirror an FTP virtual server fails over, FTP control connections may not resume successfully after failover, and the standby BIG-IP system may forward truncated commands to the server. As a result, FTP sessions in progress at the time of failover may stall and time out, or the servers may return error messages.

The following examples demonstrate the truncation that may occur when the BIG-IP system mirrors FTP commands during a failover, and the result:

Client commandTruncated versionResult
PORT 10,70,70,200,13,550,13,55FTP server sends HTTP Status 500:

500 Unknown command
NLST Server receives nothing, connection times out

F5 Product Development tracked this issue as CR127271 for the 9.4.x software branch and as CR127443 for the 10.x branch, and it was fixed in version 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, BIGIP-9.4.8-396.1-HF3 has been issued for BIG-IP version 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
