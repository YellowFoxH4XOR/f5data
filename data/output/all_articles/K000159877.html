K000159877: UCS creation fails with "TSocket::open() connect() Connection refused" error

Type
Support Solution
Published
2026-02-03
Updated
2026-02-04
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000159877

Description

You tried to create a UCS backup on BIG-IP and it failed with an error similar to the following.

Saving active configuration...

Thrift: Tue Feb 3 15:27:06 2026 TSocket::open() connect() Connection refused
Error during config save.
Unexpected Error: UCS saving process failed.

Environment

  1. You provisioned AVR and created scheduled reports.
  2. You then unprovisioned AVR without deleting those scheduled reports.
  3. Now you're trying to create UCS and receiving the "TSocket::open() connect() Connection refused" error.

Cause

F5 tracks the issue as ID 1061961.

Answer/Recommended Actions

After provisioning AVR, you can find scheduled reports at Local Traffic > Profiles > Analytics > Scheduled Reports.

You can delete all Scheduled Reports and unprovision AVR again before creating a UCS.
