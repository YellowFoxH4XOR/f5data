Topic

You should consider using this procedure under the following condition:

  • You need to determine the version of DDoS Hybrid Defender software running on your system.

Description

You can use the F5 DDoS Hybrid Defender Configuration utility to display the software version.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the Configuration utility.

Procedures

To determine the software version of your F5 DDoS Hybrid Defender system, perform one of the following procedures:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Determining the software version using the Configuration utility

  1. Log in to the Configuration utility of the DDoS Hybrid Defender system.
  2. Go to System > About.

    Note: For F5 DDoS Hybrid Defender 13.1.0-3.1 or earlier, navigate to DDoS Protection > Quick Configuration > About.

  3. The Configuration utility displays the software version under the product name DDoS Hybrid Defender.

    For example:

    DDoS Hybrid Defender

    13.0.0-2.0.96

Determining the software version using tmsh

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Enter the following command:

    list /mgmt shared iapp installed-packages

    The software version displays in the release attribute.

    For example:

    mgmt shared iapp installed-packages ed62c2de-c07d-32c6-8dc4-cf94fe0f9bbe {
        appName "f5-ddos-hybrid-defender"
        arch "noarch"
        generation 4
        id "ed62c2de-c07d-32c6-8dc4-cf94fe0f9bbe"
        kind "shared:iapp:installed-packages:installedpackagestate"
        lastUpdateMicros 1588744361104190
        packageName "f5-ddos-hybrid-defender-15.1.0-7.0.89.noarch"
        release "7.0.89"
        selfLink "https://localhost/mgmt/shared/iapp/installed-packages/ed62c2de-c07d-32c6-8dc4-cf94fe0f9bbe"
        status "READY"
        tags {
            "IAPP"
        }
        version "15.1.0"
    }
