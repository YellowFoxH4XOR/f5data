Description

When upgrading BIG-IP LTM systems in a Viprion environment, users often need to align software versions between vCMP guests and the Viprion chassis (host). A common question is whether the same BIG-IP ISO file (e.g., 17.5.1) can be used for upgrading both components. 

Environment

  • BIG-IP LTM
  • VIPRION
  • Upgrading vCMP guest and host

Cause

Uncertainty regarding whether the same BIG-IP ISO file is compatible for upgrading both the vCMP guests and the Viprion chassis (host) on supported hardware platforms.

Recommended Actions

The same BIG-IP ISO file can be used to upgrade both the vCMP guests and the Viprion chassis, provided that version supports your hardware platform.

Note: For version compatibility, please check this article: K14088: vCMP host and compatible guest version matrix
