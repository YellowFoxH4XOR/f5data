Issue

Old Behavior

In BIG-IP 11.3.0 and earlier, the BIG-IP system maintains only a single global connection and persistence mirroring channel. The active BIG-IP system in a high availability (HA) device group can mirror to only one specific standby BIG-IP system using this global mirror channel. This mirroring channel is created on TCP port 1028.

In BIG-IP 11.3.0 and earlier versions, you can implement mirroring only between a static pair (2) of BIG-IP devices.

New Behavior

Beginning in BIG-IP 11.4.0, the BIG-IP system maintains one mirroring channel for each traffic group. The active BIG-IP system in an HA device group dynamically establishes a mirroring connection to the standby system with a status of Next Active for a given traffic group. The port range for each connection channel begins at TCP 1029 and increases by increments of one for each new traffic group or channel created. By default, the BIG-IP system allows TCP 1029-1043 with a Port Lockdown setting of Allow Default.

For example:

Note: You can view the Next Active device on the Traffic Group properties page of the Configuration utility, or by using the tmsh show cm traffic-group all all-properties command.

--------------------------------------------------------------------------------------------------
Name               Device            Status   Next    Load  Next Active  Times Became  Last Became
                                              Active        Load         Active        Active
--------------------------------------------------------------------------------------------------
traffic-group-1    LTM2.example.com  standby  false   -     -            0             -
traffic-group-1    LTM3.example.com  standby  true    -     1            0             -
traffic-group-1    LTM1.example.com  active   false   1     -            1             -
traffic-group-2    LTM2.example.com  standby  true    -     1            0             -
traffic-group-2    LTM3.example.com  offline  false   -     -            0             -
traffic-group-2    LTM1.example.com  active   false   1     -            1             -

If three BIG-IP LTM devices configured with two traffic groups have the Active and Next Active status listed in the previous table, the system establishes the following mirroring channel connections:

  • The mirroring connection for traffic-group-1 is established from LTM1 to LTM3 on TCP port 1029.
  • The mirroring connection for traffic-group-2 is established from LTM1 to LTM2 on TCP port 1030.

Impact

The BIG-IP system now supports mirroring when using more than two devices in an HA device group.
