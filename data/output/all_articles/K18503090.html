K18503090: Warning: 'SELinux targeted policy relabel is required' 'Skipping the following R/O filesystems'

Type
Support Solution
Published
2022-11-10
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K18503090

Description

'SELinux targeted policy relabel is required' message appears at the initial bootup. The system posts messages similar to the following:

*** Warning -- SELinux targeted policy relabel is required.
*** Relabeling could take a very long time, depending on file
*** system size and speed of hard drives.
Warning: Skipping the following R/O filesystems:
/sys/fs/cgroup

Environment

  • Install new software and reboot
  • Monitor the console log

Cause

SELinux relabel always happens on the first boot. It is a necessary and planned task and there is no impact on the functionality of the system.
"Warning: Skipping the following R/O filesystems: /sys/fs/cgroup" message is part of the SELinux relabel process, just informing that it is skipping the relabel for /sys/fs/cgroup.

Recommended Actions

None needed. This is a cosmetic issue only. It is not a hardware issue or something to be concerned about.
