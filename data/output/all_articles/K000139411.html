K000139411: VELOS 400G Optics can exceed optic temperature limit resulting in an optic warning or alarm

Type
Support Solution
Published
2024-04-26
Updated
2024-06-12
Applies to
  • F5OS
  • F5OS-C: 1.6.2, 1.6.1, 1.6.0, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000139411

Description

400G Optics operate normally in standard operating temperatures without warnings or alarms. However, during extended Network Equipment Building System, NEBS operating temperature ranges above 45C ambient air temperature, optics may issue a thermal warning and alarm but still function normally.

Environment

  • NEBS extended ambient air temperatures above 45C.

Cause

Optic reaches thermal sensor specification limit prior to system thermal protection shutdown.

Recommended Actions

F5 recommends the following:

  • F5 recommends responding to any warnings and alarms from the system by resolving the increase in ambient temperature in your environment and lowering it back to standard operating temperatures.
  • Thermal warning and alarm messages are logged to the respective log files:

    /var/log_controller/velos.logs, /var/F5/partition1/log/velos.log

Use the confD interface to get Optics status and temperature. For example, to get the health and status of a single optic, enter the following command:

    syscon-1-active# show system health components component blade-2 hardware blade/hardware/optic0
    hardware blade/hardware/optic0
    state name optic-0
    state health ok
    state severity info
