Description

In vCMP capable devices it is possible to deploy one or more vCMP guests. vCMP guests are objects that users create on vCMP host systems to run one or more BIG-IP modules. A vCMP guest consists of a TMOS instance, and one or more BIG-IP modules. Each vCMP guest has its own share of hardware resources that the vCMP host allocates to it, allowing each vCMP guest to function like a separate BIG-IP device.

 

However there is a hardware offloading limitation on regards to AFM DoS profile applied to virtual servers configured in vGuests. At this context DoS feature will only work on software, DB keys dos.vcmphwdos or dos.forceswdos will not have any effect. The key points to take into account when referring to DoS Hardware offloading in vGuests are the ones below:

  • TMOS <v16.0: DoS at device context is offloaded in Hardware by default without requiring any manual intervention by customer. Only requirement is running the same TMOS version in vHost and vGuest.
  • TMOS ≥v16.0 DoS at device context is not offloaded in Hardware by default . Enabling DoS Hardware offloading at device context requires enabling DB key dos.vcmphwdos and running the same TMOS version in vHost and vGuest.
  • For all TMOS versions: DoS at VS context cannot be offloaded in Hardware.
