K70545203: ''Unsupported device version'' error when adding Big-IP version 14 or 15 to Big-IQ 7.1

Type
Support Solution
Published
2020-09-17
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K70545203

Description
When adding BIG-IP version 14 or 15 to BIG-IQ 7.1, BIG-IQ may report an error message "Unsupported device version", although they are supported versions. 
Sometimes BIG-IQ may report error "Only one task can be completed at a time" while adding a new BIG-IP device.

Environment

  • BIG-IQ has been upgraded to support later versions of Big-IP
  • BIG-IP version 14 or 15
  • Import service task in error state

Cause
If the Big-IQ device is upgraded while there is an import task in progress, then post-upgrade import may fail until the previous task is terminated or successfully completed.

Recommended Actions

  1. Locate any 'import in progress' devices on the Big-IQ and remove relevant service.
    For example APM for APM service import.
  2. Rediscover and import service on BIG-IQ
  3. If the issue persists with the error "Only one task can be completed at a time", verify the device being imported for any pending import task like BIG-IP on the list page.
    If pending tasks are found, remove the service, rediscover and import.
  4. Perform discovery and import BIG-IP version 14 and 15 devices that failed previously.
