Known Issue

Child monitors may not inherit all parent attributes.

This issue occurs when all of the following conditions are met:

  • You create a new BIG-IP GTM monitor using the import settings from an existing monitor.
  • The parent monitor is configured with one of the following attributes:

    • Ignore Down Response     
    • Reverse     
    • Transparent

Impact

The newly created monitor may not function as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When applying a child monitor to an object, the BIG-IP GTM system erroneously marks the state of the object.
  • When comparing a child monitor configuration to the imported settings of the parent monitor, you observe that not all parent monitor settings are inherited.

Workaround

To work around this issue, you can modify the child monitor to correct the missing import settings of the parent monitor.
