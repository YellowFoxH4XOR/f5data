K000092905: Network interface may remain down when connected to Cisco Nexus

Type
Support Solution
Published
2022-12-01
Updated
2024-10-04
Applies to
  • F5OS
  • F5OS-A: 1.3.1, 1.3.0
Source
https://my.f5.com/manage/s/article/K000092905

Description

You should consider using these procedures under the following condition:

  • A network port on your rSeries 5x00 appliance may remain down when connected to a Cisco Nexus device after setting the rSeries network interface to disable and immediately enabling it.

Environment

  • F5OS-A
  • rSeries 5x00
  • Cisco Nexus
  • Network interface

Cause

This issue is caused by 1196085 and is fixed in F5OS-A 1.4.0, F5OS-A 1.3.2.

Recommended Actions

  1. Consider temporarily using static LAG instead of LACP.
  2. Avoid placing network interface on administrative disabled.
  3. If the network interface must be administratively disabled, ensure a 30 seconds delay before enabling it.
  4. When disconnecting a link cable, ensure a 30 seconds delay before reconnecting the cable.
  5. When a network interface is determined to be in a faulty state, disabling the interface and re-enabling it with a 30 seconds in between may be sufficient to recover the network interface.
  6. If Step 5 does not work, a reboot of the appliance may be needed.
  7. To mitigate the interoperability between the rSeries and Cisco Nexus, place a 3rd party switch in between.
  8. If needed, follow the instructions on K000092892: Troubleshooting F5OS network interfaces and contact F5 Support by following the instructions from the following articles:
  • K000090255: Create a support case on MyF5
  • K2633: Instructions for submitting a support case to F5
