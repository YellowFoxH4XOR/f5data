Description

TMOS routing is unsupported and no longer developed (see K000149018 for more details). ZebOS should therefore be used for dynamic routing.

This article intends to demonstrate how to switch from TMOS routing to ZebOS.

Environment

  • BIG-IP v13+
  • Dynamic routing license
  • All modules

Cause

TMOS routing was added as an 'early access feature' in software version 13.1, but the feature never entered official release state. F5 Product Engineering is no longer developing / supporting TMOS routing.

Recommended Actions

Impact of workaround: If dynamic routing is actively being used by the F5 device, then this procedure will stop dynamic routing and will cause disruption.  If that's the case, please ensure to work under a dedicated maintenance window. 

 

To delete the router you configured in tmsh, type the command:

# tmsh delete net routing all route-domain <route-domain ID>

Note: do this for every route-domain with a routing configuration. You are required to specify the route-domain.

 

To disable the db variable:

# tmsh modify sys db tmrouted.tmos.routing value disable

 

To verify that the router is deleted (should show no output):

# tmsh list net routing

 

To re-enable the routing protocol under ZebOS config, add it to the desired route-domain(s). Example for adding BGP on route-domain 0:

# tmsh modify net route-domain 0 routing-protocol add { BGP }

 

Always remember to save config

# tmsh save sys config

 

If you have a backup ZebOS config, you can copy it now. Example for route-domain 0:

# mv /config/zebos/rd0/<filename> /config/zebos/rd0/ZebOS.conf

 

Note: if you don't have a backup ZebOS config, then configure ZebOS from scratch. To enter ZebOS config shell, type "tmsh run /util imish -r <id>" while replacing <id> with the correct route-domain number.
