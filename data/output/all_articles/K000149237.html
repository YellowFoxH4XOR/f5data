Description

Unable to console to BIG-IP device.

Observing an error similar to the following when attempting connection using PuTTY on a Windows client:

Unable to open connection to
COM8
Configuring serial port: Error 31: A device attached to the system is not functioning.

Environment

  • BIG-IP Hardware platforms
  • Console access
  • PuTTY

Cause

The error indicates an issue with accessing the COM port on the Windows client. This is most likely not a BIG-IP problem.

Recommended Actions

Troubleshooting should focus on the client-side.

Initial troubleshooting suggestions:

  • Verify whether the same setup can be used to connect to other BIG-IPs - if not, the problem is likely on the client-side.
  • Verify that the cable is properly connected at both ends.
  • Verify that the COM port is present and correct [COM8] in Device Manager.
  • If no COM port is present, or COM port shows a warning symbol, try uninstalling and reinstalling the driver.
  • Ensure you are using the correct serial terminal emulator settings (K7683).
  • Try a different cable.
  • Try a different terminal emulator program.
  • Try a different client.
