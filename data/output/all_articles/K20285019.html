Known Issue

The Traffic Management Microkernel (TMM) restarts when it tries to log an unknown subscriber.

This issue occurs when all of the following conditions are met:

  • Your system uses a large scale network address translation (NAT) pool or firewall NAT (FW NAT) source translation logging profile with subscriber-id enabled.
  • Your system uses a BIG-IP PEM profile that allows unknown subscribers.

Impact

TMM restarts and disrupts traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When your system uses carrier-grade network address translation (CGNAT) or FW NAT with subscriber-id logging enabled, it causes TMM to produce a core file when the subscriber ID is unknown.

Resolution

Status

F5 Product Development has assigned ID 721570 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can configure the BIG-IP PEM profile to deny connections from unknown subscribers.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
