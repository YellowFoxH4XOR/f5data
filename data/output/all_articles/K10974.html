Known Issue

This is the result of a known issue. The show health command output does not display the haPairQDiskFreespaceWarningRaise event.

F5 Product Development tracked this issue as ID 37025 and it was fixed in ARX version 5.2.0. For information about upgrading, refer to the ARX release notes.
