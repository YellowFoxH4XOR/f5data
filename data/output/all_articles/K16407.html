Known Issue

BIG-IP Edge Client may fail to establish access sessions.

This issue occurs when all of the following conditions are met:

  • The device is running the Windows 8.1 operating system.
  • The device's default browser is Internet Explorer, configured for Compatibility mode.
  • The Internet Explorer browser identifies as the following:

    Mozilla/4.0 (compatible; MSIE 8.0; Windows NT 6.2; WOW64; Trident/7.0; .NET4.0E; .NET4.0C; .NET CLR 3.5.30729; .NET CLR 2.0.50727; .NET CLR 3.0.30729; InfoPath.3)
  • You attempt to use BIG-IP Edge Client to establish a BIG-IP APM access session.

Impact

BIG-IP Edge Client fails to establish the session.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Windows 8.1 Edge Client fails to pass the access policy Host Check agent, and logs an error message that appears similar to the following example:

    plugin missing
  • At the time of the session failure, you may view log messages in the /var/log/apm file that appear similar to the following example:

    notice tmm3[<pid>]: 01490506:5: e4e70285: Received User-Agent header: Mozilla%2f4.0%20(compatible%3b%20MSIE%208.0%3b%20Windows%20NT%206.2%3b%20WOW64%3b%20Trident%2f7.0%3b%20.NET4.0E%3b%20.NET4.0C%3b%20.NET%20CLR%203.5.30729%3b%20.NET%20CLR%202.0.50727%3b%20.NET%20CLR%203.0.30729%3b%20InfoPath.3).

    notice tmm3[<pid>]: 01490544:5: e4e70285: Received client info - Type: IE Version: 5 Platform: WinNT CPU: unknown UI Mode: Full Javascript Support: 1 ActiveX Support: 0 Plugin Support: 1
