Known Issue

The BIG-IP APM access policy Active Directory (AD) Group Resource Assign agent fails to display AD groups and displays an error instead.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM access policy is configured with the AD Group Resource Assign agent.
  • AD group names include ASCII characters from the range of 0x00 through 0x20.
  • Using the visual policy editor, you attempt to view the AD groups retrieved by the AD Group Resource Assign agent.

Impact

The visual policy editor produces an error.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You receive an error similar to the following example when you use Internet Explorer to view the list of AD groups for the AD Group Resource Assign agent:

    Unable to find 'status' in Save response for 'getGroupsFromServerDialogue'

  • You receive an error similar to the following example when you use Firefox or Chrome to view the list of AD groups for the AD Group Resource Assign agent:

    Save Response for 'getGroupsFromServerDialogue' is invalid

Workaround

To work around this issue, remove the offending ASCII characters from the group names in AD, and then have the agent query AD for the updated group names. To do so, perform the following procedure:

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > AAA Servers.
  3. Click the name of the AD server configuration that you want to update the AD groups for.
  4. Click the Groups tab.
  5. Click Update.
