Description

When you try to create a UCS from GUI, BIG-IP may fail to create it with "Internal Server Error".
In addition to, you may see "OutOfMemoryError" message in /var/log/tomcat/catalina.out and tomcat restarting.

/var/log/tomcat/catalina.out
# java.lang.OutOfMemoryError: Java heap space
# -XX:OnOutOfMemoryError="/usr/bin/restart_tomcat"
# Executing /bin/sh -c "/usr/bin/restart_tomcat"...
Tue Jul 13 14:50:29 JST 2021: START... [Ljava.lang.String;@157fe3d
Tue Jul 13 14:50:29 JST 2021: Calling command 1 with args: " restart tomcat"
Tue Jul 13 14:50:34 JST 2021: DONE: com.f5.util.ContainerManager$Result@1ed20be

Environment

  • BIG-IP
  • Creating/Saving UCS file in GUI

Cause

It is due to lack of memory for tomcat.

Recommended Actions

Follow K9719 to increase memory for tomcat.

Additional Information

None.
