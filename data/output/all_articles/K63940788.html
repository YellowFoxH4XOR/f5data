Description

Users may not be able to access graphical user interface(GUI) of the BIG-IP system and it keeps restarting by showing the message  "configuration utility restarting". 

Httpd errros will be noticed under /var/log/httpd/httpd_errors showing following messages

/var/log/httpd/httpd_errors
Apr 21 21:47:43 slot1/example1aa err httpd[6383]: [error] ajp_read_header: ajp_ilink_receive failed
Apr 21 21:47:43 slot1/example1aa err httpd[6383]: [error] (120006)APR does not understand this error code: proxy: read response failed from (null) (*)
Apr 21 21:47:48 slot1/example1aa err httpd[6382]: [error] ajp_read_header: ajp_ilink_receive failed
Apr 21 21:47:48 slot1/example1aa err httpd[6382]: [error] (120006)APR does not understand this error code: proxy: read response failed from (null) (*)
Apr 21 21:47:54 slot1/example1aa err httpd[6765]: [error] ajp_read_header: ajp_ilink_receive failed

Also /var/log/tomcat/catalina.out does not show any error during the time of issue.
 

Environment

  • BIG-IP LTM
  • Configuration Utility
  • httpd daemon
  • tomcat daemon
  • httpd errors

Cause

Unknown at time of publication

Recommended Actions

Restart the tomcat process and httpd process 

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Log in to the Traffic Management Shell (tmsh) by typing the following command:
    # tmsh

  3. Restart the tomcat and httpd process by typing the following command:
    # restart /sys service tomcat
    # restart /sys service httpd
