Topic

This article applies to Inband monitor compatibility with Packet Velocity ASIC (PVA) connections. For related articles, refer to the following:

  • K16463: Inband monitors are not compatible with ePVA accelerated connections

The Inband monitor is not compatible with server-side connections that are fully accelerated by the PVA.

Note: The PVA is included in the BIG-IP 2400, 3400, 6400, 6800, 8400, and 8800 platforms. For more information about the PVA, refer to K4832: Overview of PVA Acceleration.

Description

With an Inband monitor, the BIG-IP system performs passive monitoring as part of client requests. The Inband monitor is not compatible with server-side connections that are fully accelerated by the PVA. This occurs because the Traffic Management Microkernel (TMM) does not have visibility of connections that are fully accelerated by the PVA; therefore, the Inband monitor cannot mark a pool member down when the pool member fails to reply in a timely manner to connection attempts or data request attempts. The pool member will only be marked down by a standard monitor applied to the pool member.

Recommendations

When configuring virtual server traffic to use PVA Acceleration, you should consider using other monitor types, such as TCP or HTTP monitors instead of the Inband monitor type.

Alternatively, if you are required to use the Inband monitor with PVA connections, you can demote the virtual servers using a pool with an Inband monitor to PVA Assisted mode. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles.
  3. Under the Protocol tab, click Fast L4.
  4. Select the FastL4 profile used by the virtual server featuring a pool with an Inband monitor.
  5. From the PVA Acceleration menu, select Assisted.
  6. Click Update.
