K000092964: Not seeing full list of persistence profiles in GUI

Type
Support Solution
Published
2022-12-04
Updated
2022-12-04
Source
https://my.f5.com/manage/s/article/K000092964

Description

When trying to create a persistence profile in Local Traffic > Profiles > Persistence > Create.  You are seeing a limited set of persistence profile options.

For Example:
With an ASM dedicated device you will only have the following options:

  • Cookie
  • Destination
  • Host
  • Source Address

Environment

Non-LTM Dedicated Module Licensed


Cause

This is by design.  Non-LTM Modules have limited persistence profile options.


Recommended Actions

If LTM persistence options are needed contact F5 Sales about adding the LTM Module.


Additional Information

None
