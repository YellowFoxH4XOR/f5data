K000151190: AWS upgrade notifications for F5 BIG-IP VE

Type
Support Solution
Published
2025-05-06
Updated
2025-05-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
  • BIG-IP Cloud Edition
Source
https://my.f5.com/manage/s/article/K000151190

Description

  • When operating F5 BIG-IP VE - ALL (BYOL, 2 Boot Locations) on AWS Marketplace, users may receive notifications regarding the release of a new software version (e.g., 17.1.2.2-0.0.12) while running an earlier supported version (e.g., 17.1.2.1-0.0.2). This can raise questions about whether an upgrade is required and what actions are necessary to maintain support and system stability.
  • Example of the notification : "As an existing customer, your subscription to the product, any running instances and access to previous versions are unaffected. However, F5, Inc. does recommend you to update to the latest version..."

Environment

  • Product: F5 BIG-IP VE - ALL (BYOL, 2 Boot Locations)
  • Platform: AWS Marketplace

Cause

F5 and AWS periodically release updated versions of BIG-IP VE to provide security patches, performance improvements, and new features or enhancements. Notifications about these updates are informational in nature; they do not require immediate action unless the currently deployed version is nearing end-of-support or specific vulnerabilities exist.

 

Recommended Actions

  • It is recommended to upgrade to the latest maintenance or point release for improved security, performance, and ongoing support.
    • Upgrades are not mandatory if your current version remains within its support lifecycle and there are no urgent requirements for new features or fixes.
    • Existing subscriptions, running instances, and access to previous versions will remain unaffected by the availability of a newer release.
  • Prior to upgrading:
    • Confirm that your virtual environment meets all system requirements for the target BIG-IP VE version (CPU, memory, disk space).
    • Backup your configuration files and ensure you have a recovery plan in place.
  • Follow standard upgrade procedures:
  • Continue monitoring F5’s support policies and advisories for any changes affecting your current software version.
