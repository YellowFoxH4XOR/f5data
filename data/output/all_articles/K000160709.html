Description

On systems using Antivirus Check Updates, multiple EPSEC packages may accumulate over time. Customers may want to remove older packages to recover disk space, but deleting a required package can affect package availability for the system or the currently installed version in use.

Environment

BIG-IP systems using EPSEC packages

EPSEC packages removal

Cause

BIG-IP may retain multiple downloaded EPSEC packages after updates are installed over time. This can make it unclear which packages are still required and which are only older, unused packages.

Answer/Recommended Actions

As a general rule, you should keep:

  • the system default EPSEC package
  • the currently installed EPSEC package

Any other EPSEC packages can be removed.

1. Identify the system default package:

Go to System > Software Management > Antivirus Check Updates > Package Status

Locate the package where System Package is shown as true

2. Identify the currently installed package:

Go to System > Software Management > Antivirus Check Updates > Device Status

Note the value shown in Installed Version

Please note that this can be the same package, or two different ones (in situations where EPSEC was updated independently of BIG-IP).

All other EPSEC packages can be removed per Removing unnecessary OPSWAT EPSEC packages from the BIG-IP APM system.
