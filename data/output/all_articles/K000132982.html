Description

  • You can not find the CPU usage with the data plane statistics in the VE's dashboard.

Environment

  • VE
  • Dashboard
  • Data plane and Control plane CPU

Cause

The separate control plane and data plane statistics in the dashboard are only used for the HTSplit feature-enabled platforms. So it is expected behavior that you can not find the data plane CPU statistics in the VE's dashboard.

 Recommended Actions

You may use the tmsh command tmsh show sys performance system detail to check the CPU statistics, for details please check K04191163 .

Additional Information

Actually, you also should not see the control plane CPU statistics in the VE's dashboard, but under the impact of the known bug ID969329, you still can see the control plane CPU statistics from the VE's dashboard.
