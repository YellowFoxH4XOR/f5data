Issue

The snapshot remove command deletes one or more filer snapshots associated with an ARX snapshot rule, without removing the rule itself.

Note: In the ARX GUI, the snapshot remove command corresponds to selecting the snapshot name and clicking the Remove button.
 
Previously, if a back-end filer failed to delete a snapshot, ARX noted the failure and then removed all references to the snapshot from its database. Once the snapshot was removed from the database, administrators could no longer delete the snapshot using the ARX CLI or GUI. To work around this behavior, administrators had to manually remove the snapshot from the filer.
 
Starting in ARX version 4.1.1 and 5.0.0, the snapshot remove command now creates a sparse snapshot when a back-end filer fails to delete a snapshot. Administrators may then attempt the removal at a later time, by using the snapshot remove command or the ARX GUI to remove the sparse snapshot.
 
Note: The sparse snapshot contains only the component snapshots which could not be deleted. For more information about sparse snapshots, refer to the ARX CLI Maintenance Guide.
 
F5 Networks Product Development tracked this enhancement as ARX ID 32965.
