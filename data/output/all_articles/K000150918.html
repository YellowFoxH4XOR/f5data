Source

Description

You may be unable to find some ASM/AWAF configs under GUI Security >> Application Security.

 

For example.

v15 ... IP address Exceptions exists under Security >> Application Security

 

v17... no IP address Exceptions

 

 

Environment

  • ASM/AWAF
  • GUI, Configuration Utility

Cause

It is expected. Some features are moved inside the policy.

Ex. (v17)

 

Recommended Actions

If you can't find some ASM config under Security >> Application Security, please check it inside the policy Security >> Application Security >> Security Policies >> Policies List >> <Policy-name>.
