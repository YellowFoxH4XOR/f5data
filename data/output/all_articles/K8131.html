Known Issue

This is the result of a known issue. If you enable the Cache Cleaner on the Users: Endpoint Security: Post-Logon Actions page, the FirePass Cache Cleaner component does not remove the following data on client systems:

  • Browsing history

    You can view the browsing history in Microsoft Internet Explorer 5.0 or later by pressing CTRL+H.
  • Address bar history

    You can view the Address bar history in Microsoft Internet Explorer 5.0 or later by clicking the down arrow to the left of the address bar.

The correct behavior is for the Cache Cleaner to remove the browsing history entries and the Address bar history entries created during the FirePass controller session, and associated with the FirePass controller URL.

Important: For browsers other than Microsoft Internet Explorer, the FirePass Cache Cleaner component does not remove browser history or cache. Only files in the Windows temporary directory are removed.

The Cache Cleaner helps prevent information leaks by removing content from the browser cache when users log out. To enable the Cache Cleaner, select the Inject ActiveX/Plugin to clean-up client browser web cache check box on the Users: Endpoint Security: Post-Logon Actions page.

F5 Networks Product Development is tracking this issue as ID 266718 (Formerly CR71841).
