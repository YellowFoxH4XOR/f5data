Description

Enabled Secure and HTTPOnly for ASM cookies but not all TS cookies contain the attribute flags.


Environment

  • HTTPOnly attribute is enabled ( cookie_httponly_attr )
  • Secure attribute is enabled by ( cookie_secure_attr )
  • Cookies missing the attributes flags were:

    TSxxxxxxxxx27
    TSxxxxxxxxx76
    TSxxxxxxxxx29
    TS_101_DID
    TSxxxxxxxxx77
    TSxxxxxxxxx71
    TSPD_101_DID


Cause

The listed TS cookies are generated for Proactive Bot Defense Functionality.
 

Recommended Actions

To enable Secure attribute flag for the mentioned TS cookies, refer to K93240866: Configuring the Secure attribute flag for the DoSL7 Proactive Bot Defense or Bot Defense Browser Verification cookie on BIG-IP ASM systems


Additional Information

Regarding HTTPonly; 

When, L7 DoS/Proactive Bot Defence is used, cookies are generated by client side Java script but, the inherent purpose of HTTPOnly flag is to block any client side script from accessing that cookie.

When a  HTTPOnly flag is set, Cookie cannot be accessed by client side scripts therefore, HTTPOnly flag cannot be used with the L7 DoS/Proactive Bot Defence cookies, since these cookies are being set and accessed by the L7 DoS/Proactive Bot Defence client side Java script.

Therefore, adding the HTTPOnly flag will cause these features to malfunction and legitimate users will get blocked.
