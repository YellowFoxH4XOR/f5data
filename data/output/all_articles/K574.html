Topic

BIG-IP offers a number of different persistence modes. The following lists show the available persistence modes in each major version branch of BIG-IP.

Versions 4.6.0 - 4.6.4

  • Simple persistence (also referred to as sticky sessions)
  • SSL persistence
  • Node Select Expression
  • Cookie persistence
  • SIP Call-ID persistence
  • Destination Affinity (Normally used with transparent nodes)
  • WTS persistence

Additionally, using iRules, BIG-IP can load balance and persist based on the client's packet contents. This is known as universal persistence (such as JSERVER clustering cookies, HTTP headers, or actual content within the TCP/UDP packet).

Versions 4.5.0 - 4.5.14

  • Simple persistence (also referred to as sticky sessions)
  • SSL persistence
  • Node Select Expression
  • Cookie persistence
  • SIP Call-ID persistence
  • Destination Affinity ( Normally used with transparent nodes)
  • WTS persistence

Additionally, using iRules, BIG-IP can load balance and persist based on the client's packet contents. This is known as universal persistence (such as JSERVER clustering cookies, HTTP headers, or actual content within the TCP/UDP packet).

Version 3.3.0 through 4.2.0

  • Simple persistence (also referred to as sticky sessions)
  • SSL persistence
  • Cookie persistence (with various modes)
  • SIP Call-ID persistence

Note: BIG-IP SSL Proxy also works in conjunction with Cookie persistence for SSL connections.

Version 1.8.3 - 3.2.0

  • Simple persistence (also referred to as sticky sessions)
  • SSL persistence
