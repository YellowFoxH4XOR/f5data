Known Issue

The BIG-IP APM system may fail to rewrite JavaScript code that has literal object definitions.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured for portal access.
  • The portal access content contains JavaScript code with literal object definitions that contain field names that are equivalent to JavaScript reserved keywords.

    The following is an example of such JavaScript code:

    var obj = {
    default: 'value'
}

Impact

You are unable to access the application through the portal access session, as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You cannot access the application through the portal access session.
  • When you analyze the rewritten content, you notice that the affected JavaScript code is not rewritten for portal access.
