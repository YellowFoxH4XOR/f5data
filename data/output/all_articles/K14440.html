Issue

Old Behavior

In versions prior to BIG-IP 11.0.0, folder path names could be up to 1023 characters in length.

New Behavior

Beginning in BIG-IP 11.0.0, folder path names are limited to 255 characters in length.

Attempting to load a configuration with a folder path name greater than 255 characters in length will result in the following error message in the /var/log/ltm file:

0107141f:3: The maximum allowable length of 255 for a full path has been exceeded.

Impact

Configurations upgraded from previous versions of BIG-IP may not load on 11.x.

Recommended Actions

You can resolve this issue either by shortening folder path names on 10.x before upgrading to 11.x, or manually editing the /config/bigip.conf file with a text editor to shorten path names.

For example:

ltm virtual /Common/VirtualServerName {
destination /Common/192.168.1.1:80
ip-protocol tcp
mask 255.255.255.255
mirror enabled
pool /Common/PoolName
}

In this example, if the highlighted portions are longer than 255 characters, you must shorten the local traffic object name. In the above example, you can shorten the local traffic object name, either PoolName or VirtualServerName, so the entire path is less than 255 characters. The /Common/ partition name should not be changed.

Note: If you make changes to the object name, you must also make changes to all other references of that object name in the bigip.conf file.
