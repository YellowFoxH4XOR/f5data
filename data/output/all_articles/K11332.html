Known Issue

This is the result of a known issue. The predictive and observed load balancing methods use an inverted ratio, causing them to rank servers with a higher number of connections above servers with a lower number of connections. As a result, the BIG-IP system sends a disproportionate amount of traffic to the servers with the most connections.

F5 Product Development tracked this issue as CR138156 and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

In addition, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.1.0-3402.0-HF2, which has been issued for BIG-IP version 10.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
