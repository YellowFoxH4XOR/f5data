K000138662: PSU reporting Status input lost/active

Support Solution

2024-02-20

Source

Description

  • Periodic input lost/active PSU status messages in device logs
  • Message similar to the following can be seen on /var/log/sel

     INF BMC Power Supply #1c Input Lost 6f [03 ff ff]
     INF BMC Power Supply #1c Input Active ef [03 ff ff]

  • Message similar to the following can be see on /var/log/ltm

     chmand[5676]: 012a0040:4: PSU1 Status input lost
     chmand[5676]: 012a0045:5: PSU1 Status input active

Environment

  • iSeries or rSeries
  • PSU
  • Status flapping

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 1342205

Recommended Actions

When this issue occurs, there is usually no adverse impact aside from the log messages. You can run the following commands to confirm that PSUs are working correctly:

platform_check
system_check -d
show /sys hardware
