Description

Syslog-ng can either use BSD (default) or ISO timestamp format in log files and file-like destinations.

BSD (default) format: Mnn DD hh:mm:ss
For example: May 10 09:39:20

ISO format: YYYY-MM-DDThh:mm:ssTZ
For example: 2019-05-09T09:39:20+08:00

The BIG-IP system or BIG-IQ instance allows you to configure this syslog configuration within tmsh to make use of either of these formats. This article focuses on how to configure local syslog entries within /var/log/* to make use of ISO timestamp format. 

Environment

  • tmsh
  • syslog

Recommended Actions

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To define the desired syslog filter that references the remote server, type the following command:

    edit /sys syslog all-properties

    The syslog configuration opens in the vi text editor and appears similar to the following example:

    modify syslog {
        auth-    priv-from notice
        auth-    priv-to emerg
        cron-from warning
        cron    -to emerg
        daemon-from notice
        daemon-to emerg
        description none
        include none
        iso-date disabled
        kern-from notice
        kern-to emerg
        mail-from notice
        mail-to emerg
        messages-from notice
        messages-to warning
        remote-servers none
        user-log-from notice
        user-log-to emerg
    }

  3. Replace the include none line with the desired option.
    For example, to configure syslog-ng to use the iso format timestamp, use the following syntax:
        include "
        options {
        ts-format(iso);
        };
        "
    Note: Alternatively you can modify the configuration line iso-date disabled to iso-date enabled.

  4. Exit the text editor by typing the following key sequence:

    :wq!

  5. At the following prompt, type y to save the changes to the file:

    Save changes? (y/n/e)

    The tmsh utility prompt returns.

    Note: If the syslog filter contained syntax errors, the tmsh utility returns the following prompt:

    There were errors. Continue editing (y) or discard changes (n) (y/n)

    The BIG-IP system now uses the ISO format timestamp.

  6. Save the configuration by typing the following command:

    save /sys config
