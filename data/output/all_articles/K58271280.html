K58271280: BIG-IQ Install Task Is Stuck With Status ''Waiting for current volume operation to complete.''

Type
Support Solution
Published
2021-05-13
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K58271280

Description

  • BIG-IQ install task may appear to be stuck
  • status of "Waiting for current volume operation to complete." is observed

Environment

  • BIG-IQ CM
  • BIG-IP image deployment task

Cause

There is another pending install operation on the same boot volume where BIG-IQ is installing the software.

Recommended Actions

Resolve the pending operation on the affected BIG-IP. For example, if it is waiting for the image that it needs to install, make sure that image is available in the /shared/images directory of the BIG-IP.

Additional Information

None.
