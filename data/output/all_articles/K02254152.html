Issue

Error Message

notice iprepd[<PID>]: 015c0009:5: IP Reputation has no license currently

In this error message, note the following:

  • <PID> is the process ID for the iprepd process.

For example:

notice iprepd[5226]: 015c0009:5: IP Reputation has no license currently

Message Location

You may encounter this message in the following location:

  • The /var/log/asm file

Description

This message occurs when all of the following conditions are met:

  • The ASM module is licensed and provisioned on the BIG-IP system.
  • The IP Intelligence feature is not licensed on the BIG-IP system.

Impact

Users cannot enable the IP Intelligence feature on the BIG-IP ASM system.

Recommended Actions

Before you can enable the IP Intelligence feature, the BIG-IP system must have a valid feature license. To obtain a license for the IP Intelligence feature, contact your F5 Sales representative. To reactivate an expired license, refer to K7752: Licensing the BIG-IP system.
