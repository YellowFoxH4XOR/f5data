K8825: Users are required to re-install the same OPSWAT library at every logon

Topic

This is the result of a known issue. If you configure the Windows antivirus checker with the Perform processes scan setting set to enabled or ask user in a pre-logon sequence, the FirePass client-side component may re-install the same OPSWAT library every time the user accesses the FirePass controller. This issue occurs when the OPSWAT 2.5.7 Update (hotfix-99915) is installed on the FirePass controller.

F5 Networks Product Development is tracking this issue as CR100480. To monitor the status of this CR, refer to the FirePass Release Notes.

Workaround

You can work around this issue by uninstalling OPSWAT Hotfix-99915 (OPSWAT 2.5.7 Update) from the FirePass controller. Alternately, you can work around this issue by disabling the Perform processes scan feature in the Windows antivirus checker. To do so, perform the following procedure:

  1. Logon to the FirePass Administrative Console.
  2. Navigate to the Users : Endpoint Security : Pre-Logon Sequence page.
  3. Next to the name of the active pre-logon sequence, click the backup & edit link.
  4. Click the Check for Antiviruses action.

    The Edit Action screen appears.
  5. In the Inspector section of the Edit Action screen, click the Windows antivirus checker link.

    The Endpoint Inspector Details window opens.
  6. In the Scan active processes for viruses section, select disabled from the Perform processes scan menu.
  7. Click the Update button.
