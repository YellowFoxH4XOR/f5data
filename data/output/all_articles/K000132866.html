K000132866: [F5OS-A] r4600 max number vCPU for Tenants 12 is not displayed in GUI

Type
Support Solution
Published
2023-03-06
Updated
2023-05-02
Applies to
  • F5OS
  • rSeries Platforms
  • F5OS-A: 1.3.X, 1.3.2, 1.3.1, 1.3.0
  • rSeries 4000
Source
https://my.f5.com/manage/s/article/K000132866

Description

Manual says R4600's Maximum vCPUs per tenant is 12. However GUI does not let us allocate 12 vCMPs.

 

 

Environment

  • r4600
  • Tenant
  • Max number of core

Cause

  • Bug ID 1234049

Recommended Actions

Use CLI (log in as admin user), the following ConfD command:

config
tenants tenant <existing_tenant name> config vcpu-cores-per-node 12 
commit and-quit

NOTE: this example is for the tenant already configured in GUI. When creating a new tenant from the scratch on CLI, other options in Additional Information will be required to set properly, such as image, mgmt-ip, and among other optons.
