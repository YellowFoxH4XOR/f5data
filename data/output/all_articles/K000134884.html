Description

Snmpd is continuously restarting and a core file is generated.

/var/log/daemon indicates error in snmpd.conf

err snmpd[20691]: /config/snmp/snmpd.conf: line 40: Error: snmpd: failed to parse this line.

emerg logger[21014]: Re-starting snmpd

 

Environment

  • BIG-IP
  • snmpd is coring every few minutes

Cause

Invalid snmpd.conf configuration/Unable to resolve hostname
Bug ID 569968

Recommended Actions

Resolve errors in /config/snmp/snmpd.conf as per the logs in /var/log/daemon

Additional Information

This can be triggered when BIG-IP has no network connectivity, eg when interfaces/trunks are down
