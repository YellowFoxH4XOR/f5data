Issue

Error Message

notice mcpd[<PID>]: 01070728:5: Node <name> address <IP> monitor status up

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <IP> is the IP address for the node.

For example:

notice mcpd[5664]: 01070728:5: Node /Common/node_10 address 10.10.10.10 monitor status up

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • You configure a node with a health monitor.
  • The status of the node changes and the health monitor marks the node up.

For example, when you turn on the BIG-IP system, or when the system brings a node online, then once the system successfully completes the monitor checks and marks the node as up, the system generates this error message.

Impact

There is no impact; this message is a notification of node status.

Recommended Actions

None
