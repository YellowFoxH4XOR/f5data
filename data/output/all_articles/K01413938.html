Description

  • When using Network Access, traffic that is going through the tunnel may need to be sent to a different gateway
  • This article will outline how to create a forwarding Virtual Server to handle this configuration

Environment

  • BIG-IP APM Network Access tunnel traffic
  • Tunnel users assigned lease pool IP addresses

Cause

Certain network configurations may require that tunnel traffic be forwarded to a specific Gateway

Recommended Actions

Create a Performance (Layer 4) Virtual Server to listen on the Network Access Tunnel and forward to a pool with a single node that has the IP address of the desired gateway.

Create a Pool that defines the desired gateway.

  1. Log in to the Configuration Utility

  2. Navigate to: 
    Local Traffic  ››  Pools : Pool List  ››  Click Create...

  3. Create a New Member by entering these values in the New Member area:

    SettingValue
    Name<Name your GW Pool>
    Health Monitorgateway_icmp (Leave Empty if your gateway dis-allows icmp)
    Address<IP Address of your GW>
    Service Port0

  4. Click Add and repeat step 3 for each gateway

  5. Click Finished.

Create a Performance (Layer 4) Virtual Server
Note: The Network Access tunnel will have the same name as the connectivity profile.

  1. Log in to the Configuration Utility

  2. Navigate to: 
    Local Traffic  ››  Virtual Servers : Virtual Server List ›› Click Create...

  3. Adjust the following settings:

    SettingValue
    Name<Name your VS>
    TypePerformance (Layer 4)
    Source Address<Subnet of your Lease Pool>
    Destination Address/Mask0.0.0.0/0
    Service Port0
    VLAN and Tunnel TrafficEnable On... <NA_Tunnel>
    Default Pool<GW Pool Created above>

  4. Click Finished
