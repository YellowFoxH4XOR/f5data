By default, the BIG-IP GTM system does not allow the use of underscore ( _ ) characters in wide IP names. The BIG-IP GTM system can be configured to accept underscore characters in wide IP names and in A or AAAA records.

To configure the BIG-IP GTM system to accept underscore characters in wide IP names, perform one of the following procedures:

Configuring the BIG-IP GTM system to accept underscore characters in wide IP names using the Configuration utility

  1. Log in to the Configuration utility.
  2. Click System.
  3. Click General Properties (In BIG-IP 10.x, click Configuration).
  4. From the Global Traffic box, select General.
  5. From the Domain Validation box, select Allow Underscores.
  6. Click Update.

Configuring the BIG-IP GTM system to accept underscore characters in wide IP names using the tmsh utility

  1. Log in to the command line with administrative privileges.
  2. Type the following tmsh command:

    tmsh modify /gtm global-settings general domain-name-check allow-underscore

  3. Save the configuration by typing the following tmsh command:

    tmsh save /sys config gtm-only
