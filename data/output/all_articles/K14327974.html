K14327974: Core files consuming disk space on root (/) filesystem

Type
Support Solution
Published
2022-03-11
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.X.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K14327974

Description

The root (/) filesystem is fully utilized when executing df -h, and a core file was revealed when executing commands similar to the following:

[root@bigip1:Active:In Sync] ~ # mkdir /var/tmp/test
[root@bigip1:Active:In Sync] ~ # mount /dev/mapper/vg--db--sda-set.1.root /var/tmp/test
[root@bigip1:Active:In Sync] ~ # ls -l /var/tmp/test/shared/core/*
total 145776
-rw-r--r--. 1 root root 149271885 Mar  7 19:01 tmm.1.bld0.0.7.core.gz

Environment

  • In-TMM monitors (sys db bigd.tmm) enabled

Cause

Bug ID 793929: In-TMM monitor agent might crash during TMM shutdown

This bug causes TMM to panic on an orderly shutdown/reboot of the BIG-IP, resulting in a core file. The core file might end up on the root filesystem, since the filesystem that is normally mounted to the /shared directory (encompassing /shared/core, which /var/core is a symlink to) may no longer be available at that point.

Recommended Actions

Upgrade to a fixed version.
