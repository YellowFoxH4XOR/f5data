Description

When trying to make rest calls, you get the following error:
Rest request failed: {"code":400,"message":"/var/config/rest/storage/_d0r6.fdx (No space left on device)"

Environment

  • LTM
  • REST API calls

Cause
This error is triggered when the /var parition is getting full.

Recommended Actions

Follow recommended actions if article K14403: Maintaining disk space on the BIG-IP system to free up the disk space on your device.
