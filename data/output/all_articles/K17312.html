Known Issue

VIPRION B2150 blades with a solid-state drive (SSD) display an unknown result when the Simple Network Management Protocol (SNMP) queries the sysObjectID object identifier (OID).

This issue occurs when all of the following conditions are met:

  • You have a VIPRION B2150 blade with an SSD installed.
  • You are performing an SNMP query of the sysObjectID OID.

Impact

You are unable to query the sysObjectID OID.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Querying the sysObjectID OID returns an unknown result instead of the expected bigipVprB2150 result.
