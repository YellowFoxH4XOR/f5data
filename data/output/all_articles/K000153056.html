Description

BIG-IP tenants on R-series set up high availability and connection mirroring might encounter the log if CMP Hash configuration is not the same between BIG-IP tenants.

01340004:3: HA Connection detected DAG discrepancy: local pg 0, remote pg 0, local pu 2, remote pu 1. Connection will be retried.

 

Environment

R-series BIG-IP tenants

 

Recommended Actions

Configure CMP hash to the same value between BIG-IP tenants.

 

Additional Information

R-series r2x00/r4x00 platform do not support to change CMP hash configuration.

R-series r5x00 and above high performance platforms support to change CMP hash configuration.
