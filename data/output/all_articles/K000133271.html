K000133271: BIG-IP Edge Client prevents connection to BIG-IP APM servers with untrusted SSL certificates

Type
Support Solution
Published
2023-04-04
Updated
2024-12-13
Applies to
  • BIG-IP
  • APM Clients
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000133271

Description

BIG-IP Edge Client for Windows and Mac OS prompts a pop up window warning that connection is being established with a BIG-IP APM Server that uses untrusted SSL certificates.

Beginning BIG-IP Edge Client for Windows and Mac OS, APM Clients 7.2.4.1, BIG-IP Edge Client will prevent connection to BIG-IP APM Servers with untrusted (invalid or self signed) SSL certificates.

Environment

  • BIG-IP APM Virtual Server using untrusted SSL certificates
  • BIG-IP Edge Client on Windows and Mac OS

Cause

Upgrade to BIG-IP Edge Client for Windows and Mac OS, APM Clients 7.2.4.1

Recommended Actions

The best practice when implementing secure services with BIG-IP APM is to use valid SSL certificates. Depending on your environments, if the use of self signed SSL certificate is acceptable and is needed on BIG-IP APM servers, you can enable and allow the connection by modifying the config.f5c file on Windows and the config_tmp.f5c file on Mac OS Edge Client installation packages before installing APM Clients 7.2.4.1.

To do so, perform the following procedure:

  • Modify the config.f5c file on Windows Edge Client installation packages
  • Modify the config_tmp.f5c file on Mac OS Edge Client installation packages
  • Installing BIG-IP Edge Client from the Windows command line
Prerequisite

You must meet the following prerequisites to use these procedures:

  • Administrator role access to BIG-IP APM system
  • Administrative access to an end user system to modify the config.f5c file or config_tmp.f5c and the installation zip packages
  • Install the APM Clients 7.2.4.1 on the BIG-IP APM system. For more information, review K23159056: Upgrade the BIG-IP Edge Client | BIG-IP update and upgrade guide.
Modify the config.f5c file on Windows Edge Client installation packages
  1. Download Edge Client package from Big-IP APM connectivity profile

    Access > Connectivity / VPN > Connectivity > Profiles

  2. Select the name of you connectivity profile.
  3. Select Customize Package.
  4. Select Download.
  5. Open the downloaded package in an archive manager and extract all files.
  6. Browse to the folder F5 VPN. Inside the extracted folder, open the config.f5c in a text editor and add the following line:

    <IGNORE_SSL_SERVER_CERT_ERRORS>YES</IGNORE_SSL_SERVER_CERT_ERRORS>

    For example, refer to the line in bold in an example config.f5c file:

    <?xml version="1.0" encoding="UTF-8"?>
    <PROFILE VERSION="2.0">

    <IGNORE_SSL_SERVER_CERT_ERRORS>YES</IGNORE_SSL_SERVER_CERT_ERRORS> 
    <SERVERS TRUSTED="YES">
    </SERVERS>
    <SESSION LIMITED="YES">
      <STAYCONNECTED>YES</STAYCONNECTED>
      <RECONNECTIONS>5</RECONNECTIONS>
      <SAVEONEXIT>YES</SAVEONEXIT>
      <SAVEPASSWORDS>NO</SAVEPASSWORDS>
      <REUSEWINLOGONCREDS>NO</REUSEWINLOGONCREDS>
      <REUSEWINLOGONSESSION>NO</REUSEWINLOGONSESSION>
      <PASSWORD_POLICY>
        <MODE>DISK</MODE>
        <TIMEOUT>240</TIMEOUT>
      </PASSWORD_POLICY>
      <UPDATE>
        <MODE>YES</MODE>
      </UPDATE>
    </SESSION>
    <LOCATIONS>
      <CORPORATE>
      </CORPORATE>
    </LOCATIONS>
    <UI>
      <CUSTOMIZE>
        <LANGUAGE>
        </LANGUAGE>
      </CUSTOMIZE>
    </UI>
    </PROFILE>

  7. Create a zip file containing all the extracted Edge Client files including the modified config.f5c file and folders. Provide an appropriate name to the zip file, example,

    Mod_EdgeClient.zip

  8. Download the file setupstub.exe from BIG-IP APM virtual server from the location <VirtualServer>/public/download/setupstub.exe
  9. Merge setupstub.exe and Mod_EdgeClient.zip (created in step 7) using the following command:

    copy setupstub.exe /b + Mod_EdgeClient.zip /b updatedBIGIPEdgeClient.exe

  10. This will create an updated installer package called updatedBIGIPEdgeClient.exe. This package can now be installed on Windows end user systems.

Note: While connecting to a BIG-IP APM server that is using an untrusted SSL certificate, if the IGNORE_SSL_SERVER_CERT_ERRORS flag value is YES, the warning prompt will present a Yes and No button. In case the IGNORE_SSL_SERVER_CERT_ERRORS flag value is NO, or if it is not added, while connecting to the APM Virtual Server, an error prompt will be presented..

Modify the config_tmp.f5c file on Mac OS Edge Client installation packages
  1. Download Edge Client package from Big-IP APM connectivity profile

    Access > Connectivity / VPN > Connectivity > Profiles

  2. Select the name of you connectivity profile.
  3. Select the drop down menu and select Customize Package Mac
  4. Select Download.
  5. Open the downloaded package in an archive manager and extract all files.
  6. Open config_tmp.f5c in a text editor and add the following line:

    <IGNORE_SSL_SERVER_CERT_ERRORS>YES</IGNORE_SSL_SERVER_CERT_ERRORS>

    For example, refer to the line in bold in an example config_tmp.f5c file:

    <?xml version="1.0" encoding="UTF-8"?>
    <PROFILE VERSION="2.0">

    <IGNORE_SSL_SERVER_CERT_ERRORS>YES</IGNORE_SSL_SERVER_CERT_ERRORS>
    <SERVERS>
    </SERVERS>
    <SESSION LIMITED="YES">
      <STAYCONNECTED>YES</STAYCONNECTED>
      <RECONNECTIONS>5</RECONNECTIONS>
      <SAVEONEXIT>YES</SAVEONEXIT>
      <SAVEPASSWORDS>NO</SAVEPASSWORDS>
      <REUSEWINLOGONCREDS>NO</REUSEWINLOGONCREDS>
      <REUSEWINLOGONSESSION>NO</REUSEWINLOGONSESSION>
      <PASSWORD_POLICY>
        <MODE>DISK</MODE>
        <TIMEOUT>240</TIMEOUT>
      </PASSWORD_POLICY>
      <UPDATE>
        <MODE>YES</MODE>
      </UPDATE>
    </SESSION>
    <LOCATIONS>
      <CORPORATE>
      </CORPORATE>
    </LOCATIONS>
    <UI>
      <CUSTOMIZE>
      <LANGUAGE>
      </LANGUAGE>
      </CUSTOMIZE>
    </UI>
    </PROFILE>

  7. Create a zip file containing all the extracted Mac Edge Client files including the modified config_tmp.f5c file and folders. Provide an appropriate name to the zip file, example, Mod_MacEdgeClient.zip. This zip installation file can now be installed on MAC end user systems.

Note: While connecting to a BIG-IP APM server that is using an untrusted SSL certificate, if the IGNORE_SSL_SERVER_CERT_ERRORS flag value is YES, the warning prompt will present a continue and cancel button. In case the IGNORE_SSL_SERVER_CERT_ERRORS flag value is NO, or if not added, while connecting to the APM Virtual Server, a warning prompt will present only a cancel button.
