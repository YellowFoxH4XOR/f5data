Description
IP Intelligence updates will fail to be retrieved after 02/24/2021 if the system has been configured to use a hard coded IP address for the update server, rather than resolving the server name using DNS.

Environment

  • BIG-IP 13.1.0 or later with an IP Intelligence subscription license
  • Configured with a hard coded IP address for vector2.brightcloud.com

Cause
The third-party source of IP Intelligence subscription data is migrating the update server due to the expiry of the previous SSL certificate. Requests made to the old IP (52.24.103.52) address will begin failing when the certificate expires on 02/24/2021.

Recommended Actions

  • Check that the local hosts file has not been modified
  • Check that your BIG-IP resolves the correct IP address

Check that the local hosts file has not been modified
Ensure that your BIG-IP system is not configured with a hard coded IP address in the /etc/hosts file.
Impact of procedure: Performing the following procedure should not have a negative impact on your system. 

  1. Log in to the command line of the affected BIG-IP system.
  2. Type the following command:
    grep brightcloud /etc/hosts
  3. Ensure that there are no references to 'vector2.brightcloud.com', if there are, edit the file to remove them, e.g., using ‘vi /etc/hosts’ or 'nano /etc/hosts'

Check that your BIG-IP resolves the correct IP address
Ensure that your BIG-IP system is configured with an accessible DNS server in the DNS Lookup Server List, DNS server, and BIND Forwarder Server List.
Impact of procedure: Performing the following procedure should not have a negative impact on your system. 

  1. Log in to the command line of the affected BIG-IP system.
  2. Type the following command:
    nslookup vector2.brightcloud.com

    If nslookup returns 52.24.103.52 then you must check your DNS server(s) to determine if they have been hard coded to return this IP address and adjust their configuration accordingly.

Additional Information
BIG-IP versions prior to 13.1.0 retrieve updates from 'vector.brightcloud.com' and are not affected by this change.
