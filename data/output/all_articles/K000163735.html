Description

BIG-IP tenant images transferred to F5OS via WinSCP SFTP are not finishing the import process, preventing them from being deployed on tenants.

 

 

Environment

- F5OS-A, F5OS-C

- WinSCP SFTP

- WinSCP's "Enable transfer resume/transfer to temporary filename" option is enabled

- F5OS WebUI shows the image status as:

- Status: Importing

- Type: Not Identified

 

 

Cause

ID2515105

 

 

Answer/Recommended Actions

Follow the workaround described in ID2515105.
