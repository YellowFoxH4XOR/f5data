Issue

Old Behavior

In versions prior to BIG-IP 10.0.0, when a redundant pair of BIG-IP systems is configured to perform mirroring, the Virtual Local Area Network (VLAN) tag on the standby system (that receives mirrored connections) must match the VLAN tag of the active system. If the VLAN tags for the mirroring connection are different between the active and standby systems, the connection information is not mirrored.

New Behavior

Beginning in BIG-IP 10.0.0, when a redundant pair of BIG-IP systems is configured to perform mirroring, the VLAN name on the standby system (that receives mirrored connections) must match the VLAN name of the active system. If the VLAN names for the mirroring connection are different between the active and standby systems, the connections are not mirrored.

Note: VLAN names are case sensitive. For example, a VLAN name of "internal" does not match a VLAN name of "Internal."

While it is possible for a pair of BIG-IP 10.x redundant systems to mirror connections with different VLAN tags (using untagged interfaces), it is not recommended because the systems encounter error messages when performing a configuration synchronization (ConfigSync). For more information, refer to K13893: Error Message: vlan on the redundant peer is setup with a different vlan tag id.

Impact

Connection mirroring does not function if the mirroring VLAN names do not match between the active and standby systems.

Recommended Actions

You should ensure redundant BIG-IP systems use matching VLAN names and VLAN tags on the VLAN used for mirroring.
