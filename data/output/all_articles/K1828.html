Note: For information about configuring SSH host-based authentication on BIG-IP versions 9.x systems, refer to K8537: Configuring SSH host-based authentication on BIG-IP versions 9.x systems.

To configure host-based authentication for the BIG-IP system, you must perform the following tasks:

  • Create public and private keys for users on the host and the remote host systems
  • Configure shared remote user keys
  • Configure client/server configurations on the host and the remote host systems

Creating public and private keys

To create public and private keys for users on the host and the remote host systems, perform the following steps:

  1. Type the following command:

    ssh-keygen -t dsa

  2. Accept the default values, using an empty passphrase.

    You have now created a pair of files called ~/.ssh/id_dsa and ~/.ssh/id_dsa.pub

  3. Repeat these steps on the peer system.

Configure shared remote user keys

To add the remote users' public key to the lists of authorized hosts and add the remote host to the known host file (required for host-based authentication), perform the following steps:

  1. Add the remote users public key to the list of hosts that are authorized for host-based authentication, by typing the following command:

    Cd ; ssh <Remote User>@<Remote Host> 'cat .ssh/id_dsa.pub' >> .ssh/authorized_keys

  2. Add the remote host to the known hosts file, which is required for host-based authentication, by typing the following two commands:

    echo -n '<Remote Host> ' >> .ssh/known_hosts

    ssh <Remote User>@<Remote Host> 'cat /config/ssh/ssh_host_dsa_key.pub' >> .ssh/known_hosts

  3. Configure SSH so that it attempts host-based authentication, by typing the following two commands:

    cd ; echo '<Remote User> <Remote Host>' >> .shosts

    chmod 400 .shosts

Configure client/server configurations

To configure client/server configurations on the host and the remote host systems, perform the following steps:

  1. Edit /config/ssh/sshd_config file.
IgnoreRhosts no
HostbasedAuthentication yes
AuthorizedKeysFile %h/.ssh/authorized_keys

  • On the remote system, edit the ~/.ssh/config file.
  • Add the following lines:

    UsePrivilegedPort yes
    HostbasedAuthentication yes

    Note: If you do not use a privileged port, the remote server will not allow host-based authentication. If you do not specify HostbasedAuthentication, the SSH client will default to password-based authentication.
