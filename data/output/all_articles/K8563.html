Known Issue

This is the result of a known issue. The BIG-IP Configuration utility improperly converts a certain range of Unicode characters used in an iRule to question mark ( ? ) characters. This issue does not occur until after the iRule is created and a user clicks the Update button on the iRule property screen.

The range of UTF-8 Unicode characters that are converted to question mark characters when used in an iRule starts with &#128; and ends with &#255;.

For example, when creating an iRule with UTF-8 Unicode characters using the Configuration utility, the Unicode characters are preserved, and not converted when clicking the Save button. However, if you edit the iRule and click the Update button, the Unicode characters are converted to question mark characters.

F5 Networks Product Development tracked this issue as CR96865 and CR104749 and it was fixed in BIG-IP version 10.0.0. For information about upgrading, refer to the BIG-IP LTM Release Notes.
