Description

You need to have HTTPS health monitoring for your Microsoft web applications, however, applying an HTTPS health monitor results in the pool members being marked down. When troubleshooting you see that the TLS handshake is failing.

 

Environment

  • BIG-IP LTM
  • Microsoft Web Applications requiring HTTPS Health monitors
  • HTTPS health monitor
  • TLS handshake failures are being observed.

Cause

Microsoft web applications using HTTPS usually require the server name in the client hello. If the server name is missing the connection fails during the TLS handshake.

 

Answer/Recommended Actions

In order to use an HTTPS health monitor with most Microsoft web applications you need to use either in-TMM monitoring or a custom external HTTPS health monitor to allow for SNI.
