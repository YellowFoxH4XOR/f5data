Description

BIG-IP has rebooted and the following error messages are seen in /var/log/ltm.

bigip-example-device warning chmand[8669]: 012a0004:4: System error caused by Host CPU(s) indicating thermal trip event
bigip-example-device warning chmand[8669]: 012a0004:4: System error caused by DC-DC converter power output suspect
bigip-example-device notice chmand[8669]: 012a0005:5: CPU temperature approaching its threshold (PROCHOT)
bigip-example-device notice chmand[8669]: 012a0005:5: DC power error with host clock generator 3.3V power supply
bigip-example-device notice chmand[8669]: 012a0005:5: DC power error with Cavium 1V power supply
bigip-example-device notice chmand[8669]: 012a0005:5: DC power error with host 1.2V power supply
bigip-example-device notice chmand[8669]: 012a0005:5: DC power error with BCM5695 power supply
bigip-example-device notice chmand[8669]: 012a0005:5: DC power error with host 1.5V power supply
bigip-example-device notice chmand[8669]: 012a0005:5: DC power error with host memory DDR power supply
bigip-example-device notice chmand[8669]: 012a0005:5: DC power error with host CPU core power supply
bigip-example-device notice chmand[8669]: 012a0005:5: DC power error with one of the power supplies
bigip-example-device notice chmand[8669]: 012a0005:5: DC power error with DDR VTT termination power supply
bigip-example-device notice chmand[8669]: 012a0005:5: DC power error with host 5V power supply
bigip-example-device notice chmand[8669]: 012a0005:5: DC power error with host 3.3V power supply
bigip-example-device notice chmand[8669]: 012a0005:5: DC power error with host 2.5V power supply
bigip-example-device notice chmand[8669]: 012a0005:5: DC power error with host 1.0V power supply
bigip-example-device notice chmand[8669]: 012a0005:5: DC power error with HSBe PLL 1.2V power supply
bigip-example-device notice chmand[8669]: 012a0005:5: DC power error with HSBe PLL 1.0V power supply
bigip-example-device notice chmand[8669]: 012a0005:5: DC power error with host FSB power supply

Environment

  • BIG-IP
  • Error messages in /var/log/ltm after the reboot

Cause

None.

Recommended Actions

The warnings about subsystem reset are normal for a reboot, they don't mean anything except that the box merely rebooted (they can occur even on a normal user-requested reboot). This includes the thermal trip event and DC power warnings.

None.
