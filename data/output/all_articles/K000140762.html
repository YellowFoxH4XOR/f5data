Description

SnmpV3 user cannot be created with a combination of SHA-2 and AES

  • Error message , 01070903:3: Constraint 'the AES privacy protocol keys cannot be shorter than 192 with SHA-2 auth protocol' failed for '/Common/okuv1'

Environment

Relevant environmental factors specific to the topic

  • Adding Snmpv3 configuration
  • Specific combination of SHA2 & AES or AES-2 & SHA
  •  (tmos)#modify sys snmp users add { user1 { access ro security-level auth-privacy auth-protocol sha256 auth-password kasswir privacy-protocol aes privacy-password letmein123 username okuv1 } }

 

Cause

BugID 1615081

 

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1.  Open SR with F5 support if the above setting is require for the effected version software.

Additional Information

Other combinations that faced constraint checks.

> 'SHA-256 + AES' returns "The AES privacy protocol keys cannot be shorter than 192 with SHA-2 auth protocol." 

> 'SHA-512 + AES' returns "The AES privacy protocol keys cannot be shorter than 192 with SHA-2 auth protocol."

> 'SHA + AES-256' returns "SHA-2 auth protocol is required with longer AES keys."

> 'SHA + AES-192' returns "SHA-2 auth protocol is required with longer AES keys."
