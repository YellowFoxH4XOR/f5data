Issue

Old Behavior

Prior to BIG-IP 11.2.0, on the BIG-IP system, all the SNMP subagents referenced the /config/snmp/subagents.conf configuration file.

The SNMP subagent configuration file includes the time interval for the subagent to ping the master agent, the maximum time the data will be cached, and the cache update time.

New Behavior

Beginning in BIG-IP 11.2.0, snmpd references the new subagent configuration file, /config/snmp/bigipTrafficMgmt.conf, while the nokiasnmpd and rmonsnmpd subagents continue to reference the /config/snmp/subagents.conf subagent configuration file.

F5 Product Development tracked this change as ID 369811.

Impact

You must make changes to the snmpd subagent configuration in the /config/snmp/bigipTrafficMgmt.conf file.

Note: The modification on the subagents configuration files may not be carried forward during an upgrade.
