Issue

Error Message

Vlan <vlan name> tag <vlan tag> is out of range.

In this error message, note the following:

  • <vlan name> is a string containing the name of the VLAN you are attempting to configure.
  • <vlan tag> is an integer representing the out of range VLAN tag ID.

For example:

err mcpd[4950]: 01071bf1:3: Vlan /Common/example tag 4095 is out of range.

Message Location

You may encounter this message in the following locations:

  • /var/log/ltm
  • The TMOS shell (tmsh)
  • BIG-IP Configuration utility

Description

This message occurs when the following conditions is met:

  • If a BIG-IP administrator attempts to configure a VLAN tag which is greater than 4094.

According to IEEE 802.1Q, the VLAN tag ID is 12 bits. The beginning of the range, 0 and the end of the range, 4095 are both reserved.

Impact

The configuration issued through a tmsh command or the Configuration utility is rejected as invalid.

Recommended Actions

When creating a VLAN, ensure that the VLAN tag is equal to or less than 4094.

For example:

tmsh create net vlan example interfaces add { 1.1 {} } tag 10

When modifying a VLAN, ensure that the VLAN tag is equal to or less than 4094.

For example:

tmsh modify net vlan example tag 15
