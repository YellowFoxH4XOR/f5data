K000147470: Error: "Port range feature does not support more than one load balancer"

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147470

 

Description

  • While creating the load balancer you are trying to add port ranges and you are getting above error.

 

Environment

  • F5® Distributed Cloud Console
  • HTTP Load Balancer

Cause

  • Multiple Load Balancers in a tenant cannot use the same port.

 

Answer/Recommended Actions

  • Do not overlap Load Balancer ports in the same tenant. 

 

Additional Information

  • None
