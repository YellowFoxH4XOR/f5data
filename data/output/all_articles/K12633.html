Known Issue

This is the result of a known issue. If an iOS BIG-IP Edge Portal or iOS BIG-IP Edge Client user attempts to connect to a FirePass version 6.1.0 device, the user's session will terminate prior to prompting the user for logon credentials. This issue occurs because the BIG-IP Edge Portal client sends an XML string that the FirePass is not configured to accept.

F5 Product Development tracked this issue as ID 294330 (formerly CR136649) and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-610-5, which has been issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
