Description

You want to verify and confirm which SSH versions are allowed on F5OS units.

Environment

  • F5OS-A
  • F5OS-C

Cause

None

Recommended Actions

The F5OS based systems only supports SSH protocol v2.

F5OS (-A and -C) is using a patched version of openssh 7.4p1 in current releases.

Please find below website for more details about openssh 7.4p1:

OpenSSH 7.4/7.4p1
