Security Advisory Description

The Traffic Management Microkernel (TMM) may produce a core file while processing layer 4 (L4) behavioral denial-of-service (DoS) traffic. (CVE-2020-5937)

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from a TMM restart, and devices configured as a high-availability (HA) pair may fail over.

If you are running a version listed in the Versions known to be vulnerable column, you can eliminate this vulnerability by upgrading to a version listed in the Fixes introduced in column. If the table lists only an older version than what you are currently running, or does not list a non-vulnerable version, then no upgrade candidate currently exists.

Mitigation

You can mitigate this vulnerability by disabling Dynamic Signatures where they are enabled. To do so, follow the following procedures:

Impact of mitigation: The Dynamic Signatures feature will be disabled.

Mitigation for protection profiles with either Network and/or DNS families enabled

  1. Log in to the BIG-IP Configuration utility as an administrative user.
  2. Go to Security > DoS Protection > Protection Profiles.
  3. Select the Network or DNS protection families enabled profile.
  4. Under Network or DNS families, select Edit at the bottom of the page.
  5. For Dynamic Signature Detection, select Disabled.
  6. Commit changes to the system for these settings to take effect.

Mitigation for device protection with Network and/or DNS families enabled

  1. Log in to the BIG-IP Configuration utility as an administrative user.
  2. Go to Security > DoS Protection > Device Protection.
  3. For Network or DNS, select Edit at the bottom of the page.
  4. For Dynamic Signature Detection, select Disabled.
  5. Commit changes to the system for these settings to take effect.

Note: If Dynamic Signatures are enabled in Device Protection and Protection Profiles, you must disable both.
