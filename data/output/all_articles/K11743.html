Known Issue

This is the result of a known issue. In BIG-IP 9.0.0 through 10.1.x, the BIG-IP system supports a maximum key size of 2048 bits when using Secure Sockets Layer (SSL) acceleration. However, the BIG-IP system does not prevent you from importing and applying SSL keys larger than 2048 bits. If you apply an SSL key larger than 2048 bits to a Client SSL or Server SSL profile connections using the associated virtual server will fail silently with an SSL handshake failure, and no messages are logged on the BIG-IP system.

F5 tracked this issue as ID 273900 (formerly CR86890), and BIG-IP 10.2.0 and later supports the use of 4096 bit SSL keys. For more information, refer to K10580: The BIG-IP Client SSL and Server SSL profiles support SSL key sizes up to 4096 bits.
