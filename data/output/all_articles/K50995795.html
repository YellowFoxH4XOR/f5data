K50995795: Can't add Modern Webtop on my Access Profiles

Description

Could not add Webtop to the Access Policy

Environment

  • Access Policy with Customisation : Standard
  • Webtop with Customisation : Modern 
Cause

You can apply Webtop with Modern Customisation on Access Policy with Modern Customisation type, and Standard with Standard only. 
You cannot change the Customisation type once its created so you will have to create a new Webtop and then assign it.

Recommended Actions

  • Both Access Policy and Webtop should be of same Customisation type.
