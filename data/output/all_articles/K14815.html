Topic

This article describes the user session cookie that the BIG-IP Analytics and Application Visibility and Reporting (AVR) module inserts into an HTTP response when you set the Analytics profile configuration to collect user sessions as a collected metric.

Description

When you configure the statistics gathering configuration of an Analytics profile to collect user sessions as one of the collected metrics, the AVR module sets an AVR user session cookie in HTTP responses. The cookie value is a decoded identifier set that the AVR module uses to identify unique user session information in application traffic. The system can use the cookie to monitor active sessions but not for authentication. The default idle timeout value is 5 minutes, but you can configure this setting in 5 minute increments from 5 minutes to 60 minutes.

Note: The system disables user sessions metric collection, by default, in an Analytics profile.

Identifying the AVR User Session cookie

You cannot modify a cookie name that is set by the AVR module.

Beginning in BIG-IP 11.3.0, the name of the cookie that the AVR module inserts consists of 15 b's (bbbbbbbbbbbbbbb). The Set-Cookie header that the module inserts into HTTP Responses appears similar to the following example:

Note: The cookie value in the following example has been truncated (/.../) for display purposes.

Set-Cookie: bbbbbbbbbbbbbbb=ECLAPEAACNPBIHLKHFFBBPE/.../AAOADEOLNHPCHOKAEKKIDBAIDO; HttpOnly

In versions prior to BIG-IP 11.3.0, the name of the cookie starts with avr_ and an underscore follows to separate the encodings of the application session.  The Set-Cookie header that the module inserts into HTTP Responses appears similar to the following example:

Set-Cookie: avr_1272187534_0_0_4294901760_3348371466_0=1804290649_185117;max-age=300;path=/

Beginning in BIG-IP 11.4.0, the cookie is also encrypted and should be considered safe by security scanning devices.

Recommendations

To prevent the AVR module from setting this cookie, do not enable user sessions as one of the collected metrics in the associated Analytics profile. When you leave the user sessions option cleared, the AVR module does not collect user session statistics but continues to collect other configured statistics for virtual servers using the associated Analytics profile. You can find the Analytics profiles in the Configuration utility by navigating to Local Traffic  > Profiles > Analytics. The user sessions setting is located under the Statistics Gathering Configuration section of the Analytics profile page.
