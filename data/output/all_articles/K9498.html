Known Issue

This is the result of a known issue. If you specify an invalid management route, the BIG-IP system does not report an error message.

For example, the following bigpipe command specifies a management IP address on the 172.27.84/24 network:

bigpipe mgmt 172.27.84.71 netmask 255.255.255.0

The following bigpipe command specifies a management default route on the 192.168.1/24 network, which does not exist on the management network, and does not generate an error message:

bigpipe mgmt route default gateway 192.168.1.254

Additionally, the BIG-IP system does not report an error message when a default route already exists and you specify another one.

Note: When a default route already exists on the system and you specify another one, the second route has no effect.

F5 Product Development is tracking this issue as CR87969.
