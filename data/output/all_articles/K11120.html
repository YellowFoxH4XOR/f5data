Topic

This article applies to BIG-IP WebAccelerator 10.x. For information about other versions, refer to the following article:

  • K92912133: Changing the prefix used by the BIG-IP AAM for IBR objects (11.4.x - 12.x)

The default prefix used by the BIG-IP WebAccelerator for Intelligent Browser Referencing (IBR) enabled objects is ;pv.

Beginning in BIG-IP 9.4.5-HF2, 9.4.6, and 10.0.0, it is possible to change the prefix used by BIG-IP WebAccelerator by modifying the <IBRPrefix>;pv</IBRPPrefix> entry of the /config/wa/pvsystem.conf file.

Important: You should change the prefix only when necessary for sites that have issues with semicolons ( ; ) in URLs.

Note: Changes you make to the /config/wa/pvsystem.conf file are preserved when you apply a hotfix or an engineering hotfix, but the changes do not survive upgrades between versions (for example, from 9.4.7 to 9.4.8 ). Previous versions of the /config/wa/pvsystem.conf file are saved with upgrades, but care should be taken when restoring changes to the file. For more information, refer to the BIG-IP WebAccelerator release notes.

The IBR prefix should be three characters long. If the prefix is less than three characters, the client will receive HTTP 404 errors for IBR-enabled objects. If the prefix is longer than three characters, the prefix will be truncated to three characters. If the prefix must be changed, ensure that you do not use a character from the following list:

  • carat ( ^ )
  • at symbol ( @ )
  • ampersand ( & )
  • colon ( : )
  • number sign ( # )
  • apostrophe ( ' )
  • quotation mark ( " )
  • less-than sign ( < )
  • greater-than sign ( > )

To configure BIG-IP WebAccelerator to use $pv as the IBR prefix, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Change directories to the /config/wa directory by typing the following command:

    cd /config/wa

  3. Back up the original pvsystem.conf file by typing the following command:

    cp pvsystem.conf pvsystem.conf.sol11120

  4. Open the pvsystem.conf file in a file editor.
  5. Change the <IBRPrefix>;pv</IBRPrefix> entry to the following:

    <IBRPrefix>$pv</IBRPrefix>

  6. Save the pvsystem.conf file.
  7. Stop the BIG-IP WebAccelerator services by typing the following command:

    bigstart stop pvac

  8. Start the BIG-IP WebAccelerator services by typing the following command:

    bigstart start pvac
