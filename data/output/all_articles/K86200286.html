K86200286: Extending /var partition during the upgrade to BIG-IQ v8.x

Type
Support Solution
Published
2021-12-24
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • Public Cloud
  • Private Cloud
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K86200286

Description
During the BIG-IQ upgrade to version v8.x, we can set a new /var partition size. 

Environment

  • BIG-IQ 7.x, 8.x
  • Upgrade
  • Customization of /var partition after upgrade

Cause
None

Recommended Actions

1. Points from 2-4 need to be done on every CM and DCD separately.  We are not synchronizing "global_attributes" file.
Note: We recommend having the same /var size on CMs and same /var size on DCDs. Example: 75GB /var on CMs and 100GB /var on DCDs. 

2. Create folder:

mkdir /shared/.tmi_config ;

3. Create file with desire /var partition size after the upgrade
echo "{ \"TMI_VOLUME_FIX_VAR_MIB\" : SIZE_IN_MB }" > /shared/.tmi_config/global_attributes ;


E.g. if you want to have /var with 100000MB:

echo "{ \"TMI_VOLUME_FIX_VAR_MIB\" : 100000 }" > /shared/.tmi_config/global_attributes ;

4. Check if the file is created and you see the correct size value.

cat /shared/.tmi_config/global_attributes ;

E.g. output:
# cat /shared/.tmi_config/global_attributes
{ "TMI_VOLUME_FIX_VAR_MIB" : 100000 }

5. Start installation on the new boot location.

6. After the upgrade /var partition should have the size that you inserted in the file.


# df -h
