Description
Testing OCSP in lab environment.

Environment

  • Customer is reporting an OCSP stapling issue.
  • A packet capture has been done that shows the OCSP request in it.
  • Customer provide the issuer information of the certificate

Cause

OCSP uses the hash of a certificate as a request. So that we can test the OCSP stapling by using openssl in our lab without having customer's certification.
You need to visit the issuer website to find out the issuer certificate and the CA and download them as PEM file.

Recommended Actions

  • On a Linux shell:

    openssl ocsp -no_nonce -url http://<OCSP_URL> -issuer <ISSUER_CERT> -serial 0x<HEX_string> -verify_other <OPTIONAL_CERT>

  • This is the OCSP profile that mapping to the openssl parameters:

    sys crypto cert-validator ocsp /Common/<NAME> {
        cache-timeout 300
        dns-resolver /Common/<RESOLVER>
        route-domain /Common/0
        sign-hash sha1
        strict-resp-cert-check disabled
        trusted-responders <OPTIONAL_CERT>   ==   "-verify_other"
    }

    sys file ssl-cert /Common/<NAME> {
        cache-path /config/filestore/files_d/Common_d/certificate_d/<FILENAME>
        cert-validation-options { ocsp }
        cert-validators {
            /Common/<OCSP_PROFILE> { }
        }
        issuer-cert /Common/<ISSUER_CERT>  ==  "-issuer"
    }
