K7750: Disabling SSL caching in Microsoft Internet Explorer decreases FirePass controller performance

Type
Knowledge
Published
2007-07-27
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 6.0.1, 6.0.0
Source
https://my.f5.com/manage/s/article/K7750

Topic



When you connect to the FirePass controller using Microsoft Internet Explorer (IE), you will create a significantly higher system load on the FirePass controller if SSL caching is disabled in your browser. If numerous users have SSL caching disabled while connected to the FirePass controller, severe performance degradation can occur and the FirePass controller may become unresponsive.

SSL caching is enabled by default in IE, and it can only be disabled by modifying a Windows registry key. SSL caching is disabled if the DisableCachingOfSSLPages value is set to 0x00000001 (1) in the following registry key:

HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Internet Settings

If DisableCachingOfSSLPages is set to 0x00000000 (0), IE will perform SSL caching.

Workaround

You can work around this issue by enabling SSL Caching in IE. To enable SSL Caching in IE, change the DisableCachingOfSSLPages value from 0x00000001 (1) to 0x00000000 (0) in the following Windows registry key:

HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Internet Settings

Warning: Make these changes at your own risk. Additionally, use the registry editor with extreme caution. If you make an error while editing the Windows registry settings, you can create issues that can only be solved by reinstalling the operating system.

For more information about modifying registry keys, refer to your Windows system documentation.
