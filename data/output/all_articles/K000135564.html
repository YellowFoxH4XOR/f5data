K000135564: How to disable the FIPS 140-2 Module

Type
Support Solution
Published
2023-07-21
Updated
2026-03-02
Source
https://my.f5.com/manage/s/article/K000135564

Description

When FIPS-140 is licensed it cannot be disabled. At one time there was a db variable that would allow disabling FIPS, but since 14.1.2 that is no longer the case. The db that points to the ability to disable it, when it is run you will receive the following error message:

root@(BIG-IP(tmos)# modify sys db security.fips140.compliance value false

01070734:3: Configuration error: Change to Security.FIPS140.Compliance DB variable not allowed without corresponding change in the FIPS 140-2 Compliance license.


Environment

  • In AWS and Azure FIPS is enabled by default.  K34409208: FIPS feature does not show up as Active Module in BIG-IP VE license
  • You have a FIPS add-on license.

Cause

Due to the security that FIPS provides disabling it is not allowed. It has to be removed from the license.


Recommended Actions

Per K91841023: Overview of the FIPS 140 Level 1 Compliant Mode license for BIG-IP VE "You cannot disable FIPS mode using the Configuration utility or tmsh. The only way to disable FIPS mode is to remove the license." The steps to do so are in the article.


NOTE: The same is true for a hardware appliance, vCMP, or VELOS.
