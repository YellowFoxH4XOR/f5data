Description

When restarting the sshd process receiving the following error message:

cat: /SLOT: No such file or directory
/etc/sysconfig/sshd-functions: line 142: [: -ne: unary operator expected

Environment

  • Changing the include statement in sshd properties

Cause

The non-VIPRION vCMP system will think it's running on a VIPRION and try to access the slots which will result in errors.

Bug ID 719622: vCMP guest on appliance or rSeries tenant (i.e. non-chassis hypervisor) prints errors during boot or when restarting sshd (bigstart restart sshd)

Recommended Actions

Change check condition in /etc/sysconfig/sshd-functions using a text editor (nano, vi, vim):

FROM:

 if [ "${CLUSTERED}" == "maybe" ] && [ `cat /SLOT` -ne 0 ]; then
                                          CLUSTERED="true"
                       fi


TO:

if [ "${CLUSTERED}" == "maybe" ] && [ -f /SLOT ] && [ `cat /SLOT` -ne 0 ]; then
                                         CLUSTERED="true"
                     fi
