Topic

When Client Proxy Settings is enabled on a network access resource, BIG-IP APM modifies the system proxy configuration to ensure that VPN tunnel traffic uses the proxy configuration in the network access configuration.

Description

Beginning in F5 Access 3.0.9, Android devices are able to use a Proxy AutoConfig (PAC) setting defined in a Network Access resource. This feature lets you configure an Android device to download a proxy script after establishing a secure tunnel with the BIG-IP APM system and apply this script to the Android OS VPN framework. When VPN connection is established, traffic flows through the tunnel, through BIG-IP APM and to the proxy server. To make Android VPN clients use a proxy, you must use the PAC setting. Other proxy-related settings are ignored.

To configure this, you enable the Client Proxy Settings and Client Proxy Autoconfig Script settings in a network access resource. 

Note: F5 Access 3.0.9 supports only Client Proxy Autoconfig Script. Other proxy settings such as Client Proxy Address and so on are not supported.  

To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Go to Access > Connectivity / VPN > Network Access (VPN).
  3. Select the network access resource to modify.
  4. Select the Network Settings tab.
  5. Select Client Proxy Settings.
  6. For Client Proxy Autoconfig Script, enter a URL (http or https) where a proxy script is hosted. For example, enter:

    http://internal.example.com/pac/proxy.pac

  7. Select Update.
To enable split tunneling on client devices when they establish network access, you can define it in the PAC file in step 6. The PAC file is downloaded and applied at the system level.

Recommendations

When users upgrade to F5 Access 3.0.9, traffic may be routed through a proxy server as defined in a network access resource even without any changes on the BIG-IP APM system. Depending on your network environment, Android VPN users may face service disruptions as a result. 

Before upgrading to F5 Access 3.0.9 Android or deploying it for your VPN users, F5 recommends the following:
  • Review your BIG-IP APM access policy, visual policy editor and network access configuration (Client Proxy Settings and Client Proxy Autoconfig Script) to determine whether this new feature will be enabled for F5 Access 3.0.9 users.
  • If you do not want to enable this feature for F5 Access 3.0.9 users, you can create a separate network access resource specifically for these users. In the visual policy editor, you can use the Client Type and/or Client OS checks to identify F5 Access Android users. To do so, perform the following procedure:
  1. Log in to the Configuration utility.
  2. Go to Access > Profiles / Policies.
  3. Select Edit to open the Visual Policy Editor.
  4. Select + at the appropriate branch rule.
  5. Select Endpoint Security (Server-Side).
  6. Use the Client Type and Client OS options to identify F5 Access Android users. Select one as appropriate.
  7. Select Add Item.
  8. Select Save.

After you have identified F5 Access Android users and directed their login to the appropriate branch, assign the new network access resource. For information on using session variables for more granular configuration, refer to the Recommended Actions section of K55714594: iOS or Android F5 Access is detected as Edge Client by APM.
