Topic

Note: Spanning Tree Protocol (STP) and Link Layer Discovery Protocol (LLDP) are supported on the 2000s, 2200s, 4000s, or 4200v hardware platforms beginning in BIG-IP 11.6.0.

Spanning Tree domains allow loop resolution in configurations where one or more external switches are connected in parallel with an IP Application Switch. The spanning tree protocols that the BIG-IP system supports are STP 802.1d, Rapid Spanning Tree Protocol (RSTP) 802.1w, and Multiple Spanning Tree Protocol (MSTP) 802.1s. However, when using 802.1q tagged VLANs, MSTP is the recommended spanning tree protocol for the BIG-IP system.

MSTP is an enhancement to RSTP and is specifically designed to understand VLANs and 802.1q VLAN tagging. Unlike STP and RSTP, which allow only one spanning tree instance per system, MSTP allows multiple spanning tree instances. Each instance corresponds to a spanning tree and can control one or more VLANs that you specify when you create the instance. Thus, for any BIG-IP system interface that you assigned to multiple VLANs, MSTP can block a path on one VLAN, while still keeping a path in another VLAN open for traffic. Neither STP nor RSTP has this capability.

For information about configuring MSTP spanning tree mode in BIG-IP 11.x, refer to the Spanning Tree Protocols chapter of the BIG-IP TMOS: Concepts manual.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Note: The default spanning tree mode for BIG-IP systems is Pass Through mode. When set to Pass Through mode, if your BIG-IP configuration only contains 802.1q tagged VLANs, the BIG-IP system will drop spanning tree BPDU messages which may result in a bridge loop. For information, refer to K5566: Spanning Tree Protocol BPDUs are not passed through 802.1q tagged VLANs.
