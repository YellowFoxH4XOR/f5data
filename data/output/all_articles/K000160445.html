K000160445: Zone transfers not processed when DNS Express and BIND share the same IP address on BIG-IP DNS

Type
Support Solution
Published
2026-03-24
Updated
2026-03-24
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.5.1
Source
https://my.f5.com/manage/s/article/K000160445

Description

Zone transfers from a primary DNS server to BIG-IP DNS BIND are not processed when DNS Express and BIND are configured to use the same IP address. NOTIFY messages are received from the primary DNS server, but BIND does not process them. Removing the DNS Express zone restores zone transfer functionality.

Environment

  • Product: BIG-IP DNS
  • Configuration:
    • Primary DNS server hosting an authoritative zone (e.g., "example.com")
    • BIG-IP DNS BIND configured as a "slave" for the zone
    • DNS Express zone configured for the same zone
    • DNS Express listener and BIND self-IP configured on the same IP address

Cause

The root cause is the shared IP address between the DNS Express listener and the BIND listener. DNS Express takes precedence and intercepts DNS traffic, preventing BIND from processing NOTIFY messages from the Primary DNS server. As a result, zone updates are not processed when DNS Express is enabled.

Answer/Recommended Actions

To resolve the issue and ensure both DNS Express and BIND process zone updates correctly:

  1. Create a new self-IP address on the BIG-IP, dedicated for BIND.
  2. Update the BIND configuration:
    • Add the new self-IP address under the listen-on port 53 directive.
    • Set the transfer-source option to the new self-IP address.
  3. Update the primary DNS server configuration:
    • Configure it to send NOTIFY messages to the new self-IP address.
    • Allow zone transfers to and from the new self-IP address.
  4. Ensure DNS Express and BIND operate on separate IP addresses to prevent traffic interception.
  5. Verify that after these changes, IXFR and AXFR transfers are processed as expected, and zone updates are reflected in both DNS Express and BIND.

Additional Information

  • When DNS Express and BIND share the same IP, DNS Express intercepts all DNS traffic, including NOTIFY messages intended for BIND.
  • After removing the DNS Express zone, BIND resumes processing NOTIFY messages and updates the zone as expected.
  • The BIG-IP updates the journal file immediately after a successful IXFR/AXFR transfer, but the zone file itself may not update for up to 15 minutes (default behavior).
