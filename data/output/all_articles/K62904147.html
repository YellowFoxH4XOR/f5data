K62904147: Adding a secondary IPv6 self-IP address to a VLAN

Type
Support Solution
Published
2022-03-01
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K62904147

Description
Adding a secondary IPv6 self-IP address to a VLAN with existing IPv6 self-IP address(es) and VLAN failsafe configured

Environment

  • BIG-IP, either standalone, or in an HA Pair
  • Existing IPv6 self-IP address(es) configured
  • VLAN failsafe configured

Cause
Additional IPv6 address space is required on the VLAN

Recommended Actions

  • For standalone BIG-IP deployments:
  1. Login to the BIG-IP CLI
  2. Disable the VLAN failsafe setting on the VLAN
tmsh modify net vlan <vlan_name> { failsafe disabled }
  1. Add the IPv6 link-local self-IP 
tmsh create /net self <selfIP_name> address <ipv6_addr>/<mask> vlan <vlan_name> traffic-group traffic-group-local-only
  1. Re-enable the VLAN failsafe setting on the VLAN
tmsh modify net vlan <vlan_name> { failsafe enabled }
  1. Save the configuration
tmsh save /sys config
 
  • For BIG-IP HA Pair deployments:
  1. Login to the CLI of the Standby BIG-IP (BIG-IP-2)
  2. Disable the VLAN failsafe setting on the VLAN
tmsh modify net vlan <vlan_name> { failsafe disabled }
  1. Add the IPv6 link-local self-IP address
tmsh create /net self <selfIP_name> address <ipv6_addr>/<mask> vlan <vlan_name> traffic-group traffic-group-local-only
  1. Add the IPv6 floating self-IP address
tmsh create /net self <selfIP_name> address <ipv6_addr>/<mask> vlan <vlan_name> traffic-group traffic-group-1
  1. Re-enable the VLAN failsafe setting on the VLAN
tmsh modify net vlan <vlan_name> { failsafe enabled }
  1. Save the configuration
tmsh save /sys config
  1. Login to the CLI of the Active BIG-IP (BIG-IP-1)
  2.  Fail the Active BIG-IP (BIG-IP-1) over to Standby
run /sys failover standby
  1. Disable the VLAN failsafe setting on the VLAN  
tmsh modify net vlan <vlan_name> { failsafe disabled }
    1. Add the IPv6 link-local self-IP address  
    tmsh create /net self <selfIP_name> address <ipv6_addr>/<mask> vlan <vlan_name> traffic-group traffic-group-local-only
      1. Re-enable the VLAN failsafe setting on the VLAN  
      tmsh modify net vlan <vlan_name> { failsafe enabled }
        1. Save the configuration
        tmsh save /sys config
        1. Sync the changes from the current Active BIG-IP (BIG-IP-2) to the Standby (BIG-IP-1)
        run /cm config-sync to-group <device-group-name>
          1. [Optional] Repeat Step 9 on the current Active BIG-IP (BIG-IP-2) to failover the HA Pair back to the original failover statuses, if desired
