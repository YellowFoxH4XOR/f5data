K000158820: BIG-IP: Couldn't contact INTERNAL licensing server.

Type
Support Solution
Published
2025-12-17
Updated
2025-12-18
Source
https://my.f5.com/manage/s/article/K000158820

Description

The BIG-IP administrator may see the below error when there is an attempt in 'System  ››  License  ››  Re-activate..., Activation Method -> Automatic (requires outbound connectivity)' to activate (re-activate) the license:

"Couldn't contact INTERNAL licensing server. Check your base registration key for correct formatting."

Environment

  • BIG-IP

  • License

Cause

Wrong DNS server value or DNS server is not able to resolve the licensing server hostname

Recommended Actions

Make sure that the proper DNS server is defined under 'System  ››  Configuration : Device : DNS, DNS Lookup Server List '. This server should be able to resolve the licensing server hostname entry (activate.f5.com).
