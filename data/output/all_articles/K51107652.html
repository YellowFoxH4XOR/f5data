Description

You want to change the expired password for root account.

After using the Linux command 'passwd root', the BIG-IP system continues to alert the user that the password is expired.

You changed password from Linux command prompt and not using BIG-IP tmsh command 'modify auth password root'

Environment

  • BIG-IP System
  • When root user is trying to log in using CLI, the system notifies the user that the password is still expired.
  • User is then prompted to change the password in bash mode.

Cause

Expired root password was changed via Linux command, however, it should be done via TMSH or Configuration Utility 

Recommended Actions

To change the root password via TMSH, please follow the steps below:

  1. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  2. To modify the password for the root account, enter the following command:

    Note: If you need to modify the password for only the admin account, skip to step 5.

    modify auth password root

  3. When prompted, enter the new root password.
  4. When prompted, reenter the new root password to confirm.
  5. To save changes to the configuration files, enter the following command:

    save sys config

  6. To exit tmsh, enter the following command:

    quit
