Description

Use wireshark to capture APM SSL VPN client PPP adapter

Environment

  • APM SSL VPN client
  • Windows Operating System

Cause

Use Wireshark to capture APM SSL VPN PPP adapter

Recommended Actions

  1. Install Wireshark 3.2.3 with npcap-0.9989 
  2. Install Win10Pcap 
  3. Established APM SSL VPN tunnel.
  4. Keep sending traffic via the APM VPN tunnel, with a command similar to the following:
 'ping -t <internal back-end-server IP>'
  1. Launch Wireshark and see which interface is showing activity
  2. "Wi-Fi is physical interface and "Local Area Connection* 9" is PPP interface 
  3. In Wireshark click Capture -> Options -> Select the PPP interface -> Uncheck "Promiscuous" mode
