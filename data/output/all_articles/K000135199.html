K000135199: Remote SSL OCSP Authentication does not work with WAF license

Type
Support Solution
Published
2023-06-23
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000135199

Description

With WAF license only the OCSP options are not visible.
The following option are not visible on GUI
Local Traffic  ››  Profiles : Authentication : CRLDP Servers
Local Traffic  ››  Profiles : Authentication : OCSP Responders

Environment

  • OCSP
  • WAF

Cause

This is an expected behavior with WAF only license.
OCSP Feature requires LTM license.

Recommended Actions

Upgrade to LTM license

Additional Information

None
