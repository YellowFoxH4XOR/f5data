Description

Split tunneling for traffic specifies that only the traffic targeted to a specified address space is sent over the network access tunnel.
With split tunneling, all other traffic bypasses the tunnel.

By default, split tunneling is not enabled.
When split tunneling is enabled, all traffic passing over the network access connection uses this setting.

Environment

  • BIG-IP 12.x-15.x
  • VPN
  • Split Tunneling

Recommended Actions

Follow below steps to configure Network Access with Split Tunneling option:

  1. Creating lease pool
    1. Go to Access > Connectivity/VPN > Network Access (VPN) > IPV4 Lease Pools
    2. Click Create
    3. Fill name of new lease pool
    4. Add addresses to Member list
    5. Save
       
  2. Creating Network Access resource:
    1. For BIG-IP v13.x-15.x
      Go to Access > Connectivity/VPN > Network Access (VPN) > Network Access List

      For BIG-IP v12.x
      Go to Access Policy >  Network Access  > Network Access List
       
    2. Click Create
    3. Name new network access resource
    4. Click Finish
    5. Go to Network Settings tab
    6. In General Settings, add created lease pool in procedure 1
    7. In Client Settings > Traffic options choose option Use split tunneling for traffic
    8. Fill IPV4 LAN Address Space
    9. Go to DNS tab
    10. Fill DNS options
    11. Save
       
  3. Add network access resource to Access Policy VPE
  4. Attach updated Access polity to the Virtual Server
