Topic

You should consider using this procedure under the following condition:

  • You received a BIG-IP device from F5 as a hardware replacement for a suspected defective device (RMA) that is a member of an existing device group.

Description

When F5 dispatches a replacement BIG-IP device for a suspected failed device and the failed device is a member of an existing device group, you must complete a series of procedures to configure the replacement device so it is in the same the suspected failed device was in prior to failure. Without a user configuration set (UCS) archive, the replacement BIG-IP device does not have the necessary configuration information for you to restore it to a working state. To restore the replacement device to a working state, you must configure the replacement BIG-IP device from the beginning by performing the following procedures:

  • Configure networking options for the management interface
  • Activate the license for the new hardware
  • Provision the appropriate BIG-IP modules
  • Configure networking options for the TMM interfaces
  • Set Device Connectivity options for the replacement BIG-IP device
  • Reconfigure the existing device trust and device group on an authority device

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You disabled mirroring by performing the steps described in K8086: Replacing a BIG-IP system in a redundant pair without interrupting service.
  • You completed all necessary steps to establish power and physical connectivity, as appropriate, for your environment.
  • You have the appropriate base registration key for licensing the replacement BIG-IP device.
  • You do not have a copy of the UCS archive that contains the configuration of the device being replaced.
  • You have the networking configuration information of the device being replaced.

Procedures

Configure networking options for the management interface

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Use the serial port to connect a terminal emulator to the BIG-IP system.

    Note: For more information about configuring terminal emulation, modifying baud, and understanding the null modem serial cable requirements, refer to the following articles:

    • K7683: Connecting a serial terminal to a BIG-IP system
    • K9156: Setting the baud rate of the serial console port (9.x - 10.x)
    • K587: Pinouts for serial terminal cables used to connect the 9-pin serial port on F5 products
  2. From the BIG-IP command line, start the F5 Management Port Setup tool by entering the following command:

    config

  3. Enter data in the IP address, netmask, and default management route pages.
  4. Connect the management port into your network, as appropriate.

    Note: If you do not have serial access to the device, you can set the management network settings by using the LCD display and keypad on the front panel of the device. For more information about this process, refer to the appropriate platform guide for your hardware platform.

Activate the license for the new hardware

To install, run, and upgrade the software, as well as receive support, you must reactivate the license from the Configuration utility. To do so, refer to K7752: Licensing the BIG-IP system.

Impact of procedure: Performing the procedure should not have a negative impact on your system.

If you require assistance with the RMA configuration procedures or any other assistance with installing the RMA device, contact F5 Support.

Provision the appropriate BIG-IP modules

To be able to use your BIG-IP licensed modules, you need to provision resources for them.

To do so, refer to to K12111: Provision licensed BIG-IP modules.

Note: In a high availability (HA) system, when you perform a ConfigSync, the modules provisioned on the systems do not synchronize.

Configure networking options for the Traffic Management Microkernel (TMM) interfaces

To begin the basic traffic management network setup on the replacement BIG-IP unit, you must configure the traffic management networking options, which should be identical to the unit that is being replaced. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Network.
  3. Select the options as appropriate depending on your environment and create the required networking:
    • Static Self IPs
    • Trunks
    • Route Domains
    • VLANs and so on

For detailed steps on configuring trunks (if any), Virtual Local Area Networks (VLANs), route domains, self IP addresses, and routes (if any), you can refer to the BIG-IP TMOS: Implementations manual.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

Note: When VLANs, route domains, self IPs, or routes exist in partitions that are not the Common partition, you must create them in the correct partition.

Impact of procedure: Performing the procedure should not have a negative impact on your system.

Set device connectivity options for the replacement BIG-IP device

Before you reconfigure the existing device trust and device groups on the replacement BIG-IP unit, you must configure the replacement BIG-IP device connectivity options. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

BIG-IP 13.x and later

  1. Log in to the Configuration utility.
  2. Go to Device Management > Devices.
  3. Select the name of the replacement BIG-IP unit.
  4. Select the ConfigSync tab.
  5. For Local Address select the self IP address for the ConfigSync IP address.
  6. Select Save Changes or Update.
  7. Select the Failover Network tab.
  8. Select Add.
  9. For Address, select the self IP address for the Network Failover IP address.
  10. For Port, select the port.

    (By default, Network Failover Port is 1026)

  11. Select Finished.
  12. Select Save Changes or Update.
  13. Select the Mirroring tab.
  14. For Primary Local Mirror Adress and Secondary Local Mirror Address, select the configuration you want.
  15. Select Save Changes or Update.

BIG-IP 11.x through 12.x

  1. Log in to the Configuration utility.
  2. Go to Device Management > Devices.
  3. Select the name of the replacement BIG-IP unit.
  4. Hover on the Device Connectivity tab and select ConfigSync.
  5. For Local Address select the self IP address for the ConfigSync IP address.
  6. Select Save Changes or Update.
  7. Hover on the Device Connectivity tab and select Failover Network.
  8. Select Add.
  9. For Local Address, select the self IP address for the Network Failover IP address.
  10. For Port, select the port.

    (By default, Network Failover Port is 1026)

  11. Select Finished.
  12. Select Save Changes or Update.
  13. Hover on the Device Connectivity tab and select Mirroring.
  14. For Primary Local Mirror Address and Secondary Local Mirror Address, select the configuration you want.
  15. Select Save Changes or Update.

Reconfigure the existing device trust and device group on an authority device

To restore the replacement BIG-IP device to a working state without a UCS archive, you can configure the existing device group to push the shared configuration to the replacement BIG-IP device. To do so, perform one of the following procedures on an authority device in the local trust domain, depending on the version of BIG-IP you are running:

BIG-IP 11.2.0 and later

Impact of procedure: F5 recommends that you perform this procedure during a maintenance window. This procedure causes the current device to lose connectivity with all other BIG-IP devices. Depending on the device group and traffic group configuration, the connectivity loss may result in an unintentional active-active condition that causes a traffic disruption.
For appliance platforms only (non-VIPRION platforms), you can prevent a standby device from going active by setting the standby device in the device group to Force Offline before performing the procedure. Standby devices that were set to Force Offline should be set to Release Offline after performing the procedure. For information on the Force Offline and Release Offline options, refer to K15122: Overview of the Force Offline option.

Delete the BIG-IP device that you're replacing from the device group

  1. Log in to the Configuration utility.
  2. Go to Device Management > Device Groups.
  3. On the Device Group List tab, select the device group that has the device that is being replaced as a member.
  4. To remove the device, under Configuration, for Members for Includes , select the name of the device being replaced and move it to the Available list.
  5. Select Update.
  6. Repeat these steps for every device group that has the device that you are replacing as a member of the group.

Delete the BIG-IP device that you're replacing from the local trust domain

  1. Go to Device Management > Device Trust > Device Trust Members.

    Note: For BIG-IP versions prior to BIG-IP 13.x, Go to Device Management > Device Trust > Peer List.

  2. Select the check box for the device being replaced.
  3. Select Delete to remove the device being replaced from the local trust domain.
  4. Select Delete to confirm the removal from the local trust domain.

Add the replacement BIG-IP device to the local trust domain

  1. Select Add for the replacement BIG-IP device to add it to the local trust domain.
  2. Enter the Management IP address, Administrator Username, and Administrator Password of the replacement BIG-IP device, and select Retrieve Device Information.
  3. Enter a name for the replacement BIG-IP device.
  4. Select Finished.

Add the replacement BIG-IP device to the device group

  1. Go to Device Management > Device Groups.
  2. Select Device Group.
  3. Select the device group to which you want to add the device as a member.
  4. Under Configuration, for Members, in the Available list, select the replacement BIG-IP device and move it to the Includes list.
  5. Select Update.

Perform a ConfigSync

  1. Go to Device Management > Overview.
  2. Select the device with which you want to sync the configuration.
  3. For Sync, select Sync Device to Group.
  4. Select Overwrite Configuration.
  5. Select Sync.
