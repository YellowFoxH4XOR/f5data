Topic

The datasync-global-dg device group is essential for BIG-IP ASM systems to function properly in the same trust domain.

Description

The datasync-global-dg device group is automatically created on systems in any of the following scenarios:

  • You provision the BIG-IP ASM system on a new BIG-IP installation.
  • You added a BIG-IP system to a trust domain that has another device with the datasync-global-dg device group.

After the datasync-global-dg device group is created on the systems, the device group automatically adds all devices in the same trust domain to itself. This includes devices that are not provisioned with the BIG-IP ASM system.

The main purpose of the datasync-global-dg device group is to synchronize the system client-side scripts as well as the system cryptographic keys across all of the devices in the same trust domain. Therefore, this device group is essential in order to maintain the consistency of the system scripts and keys across all devices in the trust domain, and must not be removed from the devices.

By default, the datasync-global-dg device group is not configured to perform an automatic synchronization, as such you must manually perform the synchronization for the datasync-global-dg device group. This action is required when you add a new device to the trust domain or you reload the configuration. Additionally, you will need to perform the synchronization for all device groups when you run the tmsh save sys config and the tmsh load sys config commands in sequence. Before you perform a synchronization for this device group, you must decide what device will hold the master copy of the system scripts and keys, and synchronize this device to the device group.

Note: All other configuration changes are handled by other device groups. The synchronization of other device groups do not interfere with the datasync-global-dg device group and should not cause devices to go offline.

Recommendations

When you add a BIG-IP device to the trust-domain that has another device with the datasync-global-dg device group, you must manually perform a synchronization for the datasync-global-dg device group at least once. If you do not do this, the device group will remain in the awaiting initial sync status. To do so, perform the following procedure:

Impact of procedure: During the synchronization, the devices receiving the sync may go offline for approximately three minutes. After the synchronization is complete, the receiving devices should return to an online state. F5 recommends that the synchronization be initiated from the device that is currently active to avoid potential traffic disruption.

  1. Log in to the Configuration utility.
  2. Go to Device Management > Overview.
  3. Under Device Groups, select datasync-global-dg.
  4. Under Devices, select the device you chose to hold the master copy of the system scripts and keys.

    These devices are sent to the rest of the devices.

  5. Under Sync Options, select Push the selected device configuration to the group.
  6. Select Sync.
  7. Select Sync and Overwrite.
