K13350: Active Directory queries now use the LDAP_MATCHING_RULE_IN_CHAIN OID

Type
Knowledge

Status

Applies to

Source

Issue

Old Behavior

Previously, the FirePass system did not perform recursive lookups when querying Active Directory nested groups. This could result in a query failure when the group name and the pre-Windows 2000 group name were not the same. For more information, refer to K11648: Active Directory group mapping fails when using nested groups.

New Behavior

Beginning in FirePass 6.1.0 with HF-610-4 applied, the Active Directory query method uses the LDAP_MATCHING_RULE_IN_CHAIN OID. This allows the query to use recursion for nested groups.

Note: Beginning in FirePass 6.1.0 with HF-610-7 applied, there is a new option to select the type of query to use. For more information refer to K13271: New option to select Active Directory query type.

F5 Product Development is tracking this change as ID 317757.

Impact

The new query method may result in increased wait times to retrieve query results.
