K000150236: Device continuous send mail to customer mail server with subject 'Anacron job 'cron.daily''

Type
Support Solution
Published
2025-03-05
Updated
2025-03-26
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.0, 17.1.X, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000150236

Description

BIG-IP LTM continuously sends emails with subject "Anacron job 'cron.daily' on <Hostname>". These emails are auto-generated by the system and sent in bulk, causing unnecessary traffic to the receiving mail server 

Environment

  • BIGIP
  • LTM

Cause

ID1366013

Recommended Actions

  • Disable the echo in /etc/init.d/F5Function
  • Make back up of the file

   #cp /etc/init.d/f5functions /shared/tmp

  • Edit /etc/init.d/f5functions and comment out following lines

         268 # echo $"FIPS Integrity Check: FIPS is disable"
