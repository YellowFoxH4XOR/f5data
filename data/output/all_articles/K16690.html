Known Issue

The BIG-IP system may incorrectly disconnect client connections when request logging is enabled.

This issue occurs when all of the following conditions are met:

  • A virtual server is configured with a Request Logging profile.
  • A client attempts to initiate a tunnel through the affected virtual server using the HTTP CONNECT method or the WebSocket 101 Switching Protocols status code.

Impact

Clients may be incorrectly disconnected from virtual servers, and incorrect information may be logged to logging servers.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Messages similar to the following example are logged to the /var/log/tmm* files:

    notice reqlog: tm_header value outside of buffer range

  • If TCP RST cause logging is enabled, messages similar to the following example appear in the /var/log/ltm file:

    01230140:3: RST sent from 10.0.0.100:8888 to 10.0.0.1:49208, [0x1a16131:319] Internal error ((TMIREQLOG)  failed)

    Note: For more information about TCP RST cause logging, refer to K13223: Configuring the BIG-IP system to log TCP RST packets.
