Description

1) Upgrade failed and configuration are not loading.
2) In some case, you are unable to change the user password or change the Terninal Access.

Getting the following error message in ltm log or GUI:

01070260:3: Can't change shell for username <username> (couldn't read from `/etc/passwd.lock': Failed to open file '/etc/passwd.lock': Permission denied)

Environment

  • BIG-IP v17, v16 and v15
  • After software upgrade
  • When trying to change the user password or Terminal Access

Cause

/etc/passwd.lock or /etc/group.lock permission has been changed.

Recommended Actions

1) CLI to the tenant using "root"
2) Go to bash shell
3) Back up both /etc/passwd.lock and /etc/group.lock

   # cp /etc/passwd.lock /etc/passwd.lock.bak
   # cp /etc/group.lock /etc/group.lock.bak

4) Remove the lock files

   # rm -f /etc/passwd.lock /etc/group.lock

5) Fix /etc/passwd permissions

   # chmod 644 /etc/passwd

6) Retry the operation.

Additional Information

In case of the software upgrade, if the steps above did not solve the issue, consider reinstalling the version:

1) Reinstall the same version with creating a new volume
2) Boot into the new volume copying config from source volume
