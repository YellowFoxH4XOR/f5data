Known Issue

The DNS Express responds to a non-existent record with a NOERROR response instead of with a NXDOMAIN response.

This issue occurs when the following condition is met:

  • You delete a wildcard resource record from the related DNS Express zone.

Impact

The DNS returns the incorrect response.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The DNS Express responds to a non-existent record with a NOERROR response instead of with a NXDOMAIN response.

Workaround

To work around this issue, you can delete the old database files /var/db/tmmdns.bin and /var/db/zxfrd.bin, and restart zxfrd. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Change directories to /var/db by typing the following command:

    cd /var/db

  3. Delete the files tmmdns.bin and zxfrd.bin by typing the following command:

    rm -f tmmdns.bin zxfrd.bin

  4. Restart zxfrd by typing the following command:

    bigstart restart zxfrd
