Description

An APM VPN Tunnel's Max Session Timeout is not configured within the VPN Tunnel's Network Access or Connectivity Profile configuration. Instead, this must be configured in the Access Profile's configuration, as described below.

Environment

Relevant environmental factors

  • BIG-IP APM
  • Virtual Server with Access Profile/Policy assigned that allocates an Network Access resource for VPN Tunnel connectivity.

Cause

N/A

Recommended Actions

The VPN Tunnel Max Session Timeout can be configured in the Access Profile, using the procedure below.

  1. In the GUI, navigate to Access > Profiles / Policies > Access Profiles (Per-Session Policies).
  2. Select the Access Policy of interest.
  3. Note the setting Maximum Session Timeout, and change it's value as needed to control the maximum duration an APM Session using that Access Profile can remain connected before being terminated.
