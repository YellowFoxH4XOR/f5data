K2932: Configuring the FirePass Web Application Proxy to work properly with Lotus iNotes

Topic

For Lotus iNotes to work correctly, you may need to change the FirePass configuration as follows:

  • Allow cookies to pass to the client browser
  • Allow cache control headers to pass to the client browser
  • Ensure that the client receives iNotes components in order

Alternatively, enabling the Feature Web Applications option located on the Portal Access: Web Applications: Content Processing: Global Settings tab will optimize your FirePass for handling Lotus iNotes sessions. For more information on using option, refer to the Configuration Guide for your FirePass version.

Allow cookies to pass to the client browser

Lotus iNotes requires that the client browser receives the cookies that are set by the iNotes server. In the default configuration, FirePass blocks transmission of cookies to the client browser.

To configure FirePass to allow iNotes cookies to pass to the client browser, perform the following procedure:

  1. Log in to the Administration Console.

  2. From the main navigation pane, click Portal Access.

  3. From the upper navigation pane, click Web Applications.

  4. From the menu, click Content Processing.

  5. Click the Global Settings tab.

  6. From the Web Applications Global Settings section of the page, check the box titled Don't block cookies, pass them to the browser for specific URL patterns.

  7. Check the box titled Automatically add websites that require client side cookie manipulation.

  8. Click the Update button.

Allow cache control headers to pass to the client browser

Lotus iNotes requires that the client browser receives the cache control headers that are set by the iNotes server. In the default configuration, FirePass removes all cache control headers from the content that it proxies.

To configure FirePass to allow cache control headers to pass to the client browser, perform the following procedure.

  1. Log in to the Administration Console.

  2. From the main navigation pane, click Portal Access.

  3. From the upper navigation pane, click Caching and Compression.

  4. From the Web Applications Global Settings section of the page, click the button next to Don't enforce no-cache.

  5. Click the Update button.

Ensure that the client receives iNotes components in order

Lotus iNotes requires that the client browser receives all iNotes components in the order that they are sent. If compression is enabled on FirePass, the delay imposed by compression may cause the components to arrive in a different order.

To prevent this issue, disable compression, by performing the following procedure:

  1. Log in to the Administration Console.

  2. From the main navigation pane, click Portal Access.

  3. From the upper navigation pane, click Caching and Compression.

  4. Remove the check from the Enable Compression check box.

  5. Click the Update button.
