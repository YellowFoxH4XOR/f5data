Known Issue

The BIG-IP APM system may fail to invoke the ECA::metadata iRule command.

This issue occurs when the following condition is met:

  • You configure the virtual server to use an iRule that executes the ECA::metadata command.

Impact

You cannot load or save BIG-IP configurations. 

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When loading or saving the configurations, the system logs error messages to the /var/log/ltm file that appear similar to the following example:

    error: [undefined procedure: ECA::metadata][ECA::metadata select_ntlm:/Common/<NTLM_Profile>]

Resolution

Status

F5 Product Development has assigned ID 510802 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles
ReleaseNoneNone

Workaround

To work around this issue, you can replace the ECA::metadata command with the ECA::select command.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
