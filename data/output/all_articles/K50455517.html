Description

When attempting to create/add a rule to an LTM policy using the Configuration utility that contains a negate condition ('is not'), datagroups are not available as an option. As a result, a user is unable to create or modify an LTM policy rule that tests for the absence of datagroup elements via the Configuration Utility.

Environment

  • LTM policy
  • datagroups

Cause

Bug ID 933793

Recommended Actions

As a workaround, you can create and modify policy rules involving datagroups through the tmsh utility:

Example:

modify ltm policy Drafts/<policy name> rules modify { <rule name> { conditions add { 0 { http-uri query-string not datagroup my-dg-list } } } }
