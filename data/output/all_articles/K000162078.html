K000162078: Database transaction failed after downgrading to F5OS-A 1.5.1 and replaying the ConfD database with reset-to-default option.

Type
Support Solution
Published
2026-07-05
Updated
2026-07-05
Applies to
  • F5OS Products
  • F5OS-A: 1.5.1
Source
https://my.f5.com/manage/s/article/K000162078

Description

After downgrading to F5OS-A 1.5.1 from a higher version ( i.e. F5OS-A 1.8.4 ), you replay the ConfD database backup file with the "reset-to-default" option. Loading of the configuration appeared to have failed with the following error:

<ERR> 8-Jul-2026::10:41:22.123 appliance-1 confd[131]: devel-c no registration found for callpoint snmp-community-mib-validation/validate of type=external path /SNMP_COMMUNITY_MIB:SNMP-COMMUNITY-MIB/snmpCommunityTable
<ERR> 8-Jul-2026::10:41:22.123 appliance-1 confd[131]: devel-c action action() error {application, "Database transaction failed."} for callpoint 'config-backup-restore' path /oc-sys:system/f5-database:database

Environment

  • Upgrade to a version higher than F5OS-A 1.5.1
  • Downgrade back to F5OS-A 1.5.1
  • Reloading of F5OS-A 1.5.1 ConfD database backup file with "reset-to-default" option 

Cause

1977025

Answer/Recommended Actions

This issue is resolved in F5OS-A 1.5.2
