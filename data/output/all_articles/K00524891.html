Description

MSSQL monitor fails against databases using charset other than ISO-8859-1
  • Error Messages: 
java.io.UnsupportedEncodingException: Windows collation <charset> is not supported by this driver

Environment

  • MSSQL monitor
  • Database charset not ISO-8859-1

Cause

Bug ID 672963

Recommended Actions 

The following steps link the correct charset file for bigd process.

Impact of workaround: Restarting the bigd process temporarily interrupts pool and node monitoring. F5 recommends testing any such changes during a maintenance window.
  1. Login to bash prompt
  2. Run the command: 
mount -o remount,rw /usr; ln -s /usr/java-64/openjdk/lib/charsets.jar /usr/java/openjdk/lib/charsets.jar; mount -o remount,ro /usr
  1. Restart bigd: 
bigstart restart bigd
