Description

You're trying to publish configuration changes to the managed NGINX Instances and fail with "modified_time: value must be less than now [timestamp.lt_now]" reported in the agent log.


 

Environment

  • NGINX One Console
  • NGINX Instance Manager


 

Cause

The system clock on the affected instance was not synchronized, causing config file timestamps to be invalid for publication; subsequent network connectivity issues also impacted agent communication.


 

Answer/Recommended Actions

Enabled NTP synchronization on both load balancers and ensured network connectivity, then restarted nginx-agent.
