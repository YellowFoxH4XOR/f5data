Known Issue

This is the result of a known issue. If users install Check Point SecureClient/SecureRemote software on a Windows machine and then open a FirePass Network Access Connection, they may experience packet loss and latency across the Network Access Connection.

F5 Product Development tracked this issue as CR83120, and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Additionally, cumulative hotfix HF-601-5 has been issued for FirePass version 6.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

To work around this issue, open the Properties menu of your Windows Network Connection and clear the Check Point SecuRemote check box. On most Windows platforms, your Network Connection will be named Local Area Connection. For more information about modifying network connections, refer to your Windows documentation.

Note: You will need to re-select the Check Point SecuRemote check box in order to run the CheckPoint SecureClient/SecureRemote software.
