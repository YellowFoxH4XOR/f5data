Description

The WebUI (Configuration Utility) is not responding. 

  • Lost connectivity to WebUI (Configuration Utility)
  • CLI (Advanced Shell / Bash) is available

Environment

  • BIG-IP LTM v16.1.2
  • The F5 was upgraded or rebooted
  • In the /var/log/httpd/httpd_errors file you see similar error messages as follows: 
F501.com warning httpd[14547]: [auth_pam:warn] [pid 14547] [client 10.10.10.11:8983] AUTHCACHE Error processing cookie RD5KT7YKDTROJIPYG2SGIHHMFM - Failed Read: User
F501.com err httpd[13886]: [core:error] [pid 13886] [client 10.10.10.11:36724] AH00126: Invalid URI in request GET /%2e%2e/%2e%2e/%2e%2e/%2e%2e/%2e%2e/%2e%2e/%2e%2e/%2e%2e/%2e%2e/%2e%2e/%2e%2e/%2e%2e/boot.ini HTTP/1.0
F501.com warning httpd[18798]: [ssl:warn] [pid 18798] AH01906: RSA server certificate is a CA certificate (BasicConstraints: CA == TRUE !?)
F501.com warning httpd[18798]: [ssl:warn] [pid 18798] AH01909: RSA certificate configured for localhost.localdomain:443 does NOT include an ID which matches the server name
 

Cause

Unknown

Recommended Actions

  1. Renew the self certificate by running the following command from CLI (Advanced Shell / Bash)
openssl req -x509 -nodes -days <number> -newkey rsa:<keysize> -sha256 -keyout /config/httpd/conf/ssl.key/server.key -out /config/httpd/conf/ssl.crt/server.crt
  1. Restart the httpd service
bigstart restart httpd

K9114: Creating a new SSL device certificate and key pair
