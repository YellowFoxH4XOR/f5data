Description

When connecting to the BIG-IP Configuration Utility (GUI), the following error keeps appearing:

Unable to contact BIG-IP device

After restarting the connection, the page works for a few seconds and the error repeats.

You can find the following logs repeatedly on /var/log/httpd/httpd_errors:

warning httpd[<PID>]: [warn] [client <client_IP] AUTHCACHE Error processing cookie <cookie_string>

Environment

  • Client Browser
  • BIG-IP GUI

Cause

K11140735: Error message: httpd<pid>: [error] <client_ip> AUTHCACHE Error processing cookie <cookie_string> - Cookie user mismatch

Recommended Actions

  • For troubleshooting purposes, try using a different browser to find out if you can connect with the other browser.
  • If you are having the issue with only one browser, clear the cookies and the cache to ensure that the client saves and returns the BIGIPAuthCookie cookie for subsequent requests. The BIG-IP system implements an authentication cache (pamcache) for all Configuration utility requests. The cache works by storing information such as a username hash and the remote client's IP address in the memory file system, which prevents the system from prompting the user for the username and password every time the user attempts to log in. Clients sending requests to the Configuration utility authenticate to the cache by submitting a BIGIPAuthCookie to the BIG-IP system. If the client or iControl application makes a request without returning the BIGIPAuthCookie cookie before the pamcache timeout period, the system logs the error message.

    In addition, to determine whether the browser is sending the BIGIPAuthCookie cookie, you can use a utility such as Web Developer tools. For example, in Firefox 83.0, under Option > Web Developer > Network, you may notice that the BIGIPAuthCookie value is set in the Cookies menu for the following HTTP request:

    [HTTP/1.1 200 OK 158ms]

            
        BIGIPAuthCookie    
        httpOnly    true
        path    "/"
        secure    true
        value    "29EA5B4835A69F09DF00C51CA691BECB14303167"
        BIGIPAuthUsernameCookie    
        httpOnly    true
        path    "/"
        secure    true
        value    "test"
            
        BIGIPAuthCookie    "29EA5B4835A69F09DF00C51CA691BECB14303167"
        BIGIPAuthUsernameCookie    "test"
        JSESSIONID    "C43EB2195253D9103C69DD4054EDE50C"

  • If your client browser frequently logs in to the Configuration utility without the BIGIPAuthCookie cookie, you may want to adjust the pamcache timeout value to a value less than the login frequency of the client browser. For information about adjusting the pamcache timeout value, refer to the Recommended Actions section in K11140735: Error message: httpd<pid>: [error] <client_ip> AUTHCACHE Error processing cookie <cookie_string> - Cookie user mismatch.

Additional Information

Customers have also reported "Unable to contact BIG-IP device" issues after upgrading to BIG-IP 15.0.0 - 15.1.1.  F5 recommends that you upgrade to the latest available 15.x.x version.
