K000134473: Unable to delete ephemeral node

Type
Support Solution
Published
2023-05-04
Updated
2026-07-24
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000134473

Description

You are unable to delete an FQDN ephemeral node. This can occur when attempting to delete the ephemeral node, without first deleting the parent node.

Example parent node:
 

ltm node f5_fqdn_node {
    fqdn {
        autopopulate enabled
        name www.example.com
    }
    state fqdn-up
}


Example ephemeral node of this parent node:

ltm node _auto_172.25.1.1 {
    address 172.25.1.1
    ephemeral true
    fqdn {
        autopopulate enabled
        name www.example.com
    }
}

Environment

  • BIG-IP LTM
  • FQDN Nodes

Cause

Trying to delete for example, the _auto_172.25.1.1 without first deleting the parent node, f5_fqdn_node.

Recommended Actions

  1. Log into the BIG-IP GUI.
  2. Locate the parent node on the Local Traffic > Nodes > Node List page using the previous example. Look for the node name and FQDN.
  3. Delete the parent node by selecting it and clicking the Delete button.
  4. Log in to the BIG-IP CLI.
  5. Delete the ephemeral node. For example to delete the _auto_172.25.1.1 node you would use the following command:
       tmsh delete ltm node _auto_172.25.1.1

Additional Information

The ephemeral node can only be deleted via the CLI, and cannot be tab'd to completion when deleting, this must be typed out fully.
