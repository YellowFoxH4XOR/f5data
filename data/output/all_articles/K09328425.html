Description

After upgrading from version 10.x to 15.x you notice that LDAP administrative user authentication is not working.

Environment

  • BIG-IP
  • Upgrade from version 10.x to 15.x with intermediary upgrade to 13.x
  • LDAP servers comma separated in configuration
 

Cause

LDAP servers need to be separated by space instead of comma.

Example wrong configuration found in /config/bigip_base.conf :

auth ldap /Common/system-auth {
    bind-dn "CN=redacted,OU=redacted,OU=redacted,OU=redacted,DC=redacted,DC=redacted,DC=redacted"
    bind-pw ***scrubbed***
    login-attribute redacted
    port 636
    referrals no
    search-base-dn DC=redacted,DC=redacted,DC=redacted
    servers { 10.10.10.10,10.10.10.11 }
    ssl enabled



Recommended Actions

Replace commas with spaces in the configuration. For the given example you can do it in GUI: 

System ›› Users : Authentication
In the host list please remove commas and use white spaces, ie:

modify from
10.10.10.10,10.10.10.11
to
10.10.10.10 10.10.10.11
