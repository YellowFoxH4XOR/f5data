K10403: The BIG-IP system does not honor the Datagram LB setting when multiple UDP packets contain the same IP tuple

Known Issue

This is the result of a known issue. The BIG-IP system does not honor the Datagram LB setting in the UDP profile when the virtual server receives multiple UDP packets containing same IP tuple (Source IP / Source Port / Destination IP / Destination Port). As a result, all packets with the same IP tuple are sent to the same pool member. The correct behavior is for the virtual server to load balance each UDP packet when the Datagram LB setting is enabled.

Note: When enabled, the Datagram LB setting instructs the BIG-IP system to load balance UDP traffic packet-by-packet. By default, the Datagram LB setting is disabled.

For example, if a RADIUS server sends several RADIUS accounting packets to the same virtual server, and the source port is the same for each packet, the packets are sent to the same pool member each time even if the Datagram LB setting is enabled in the associated UDP profile.

F5 Product Development tracked this issue as ID 207739 and ID 327238 (formerly CR120841) and it was fixed in BIG-IP LTM version 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, Hotfix-BIGIP-10.0.1-342.0-HF1 has been issued for BIG-IP version 10.0.1, for the BIG-IP 10.0.0 software branch. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
