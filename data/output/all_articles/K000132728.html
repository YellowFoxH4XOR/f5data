Description

Environment

  • F5OS-C
  • Velos
  • Blade
  • Disk size

Cause

The MFG over-provisioning process was updated to reduce the drive size to 700MB.
Thus, blades built before that change are 733GB and after that date are 700GB. 

 

Recommended Actions

n/a

 

Additional Information

There is no impact to having mixed hard disk size blades.
