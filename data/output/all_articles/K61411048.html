Issue

Error Message

notice zxfrd[<PID>]: 0153101f:5: <type> Transfer of zone <zone_name> from <ip_address> succeeded

In this error message, note the following:

  • <PID> is the process ID for the zxfrd process
  • <type> is the type of DNS request, either Authoritative Transfer (AXFR) or Incremental Zone Transfer (IXFR)
  • <zone_name> is the name of the zone that was transferred
  • <ip_address> is the IP address of the remote DNS nameserver

For example:

notice zxfrd[9872]: 0153101f:5: IXFR Transfer of zone example.com from 10.10.10.10 succeeded

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The DNS Express zone transfer daemon (zxfrd) successfully completes a zone transfer.

Impact

The transferred records are now available for incoming DNS queries.

Recommended Actions

None
