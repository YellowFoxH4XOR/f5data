Description

  • You have a validated and verified OpenAPI spec file
  • OpenAPI file make use of OpenAPI / swagger 3.x.x
  • You attempt to create an API Protection profile using OpenAPI spec file
  • But the attempt to create the profile ends with failure with the BIG-IP throwing error
    • /var/config/rest/downloads/openapi is not a valid OpenAPI spec file.
  • Also, you note there are very little log details to help troubleshoot described issue

Environment

  • OpenAPI
  • ASM
  • BIG-IP

Cause

  • At the moment, the BIG-IP API Protection only supports OpenAPI / Swagger 2.0
  • OpenAPI profile creation fails due to Guided Configuration dependency on the APM interaction.

Recommended Actions

  • To continue to use OpenAPI, at this stage, you would need to make use of OpenAPI 2

Additional Information

  • None
