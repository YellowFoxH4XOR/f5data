Known Issue

The BIG-IP system does not create the certificate_summary when the certificate chain is synced to high-availability (HA) peers.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured as part of an HA system.
  • You import a certificate chain file to one of the BIG-IP systems in an HA pair.
  • You perform a configuration synchronization (ConfigSync) operation to sync the certificate chain to the HA peer using the Configuration utility or with a TMOS Shell (tmsh) command.

Impact

After a ConfigSync operation, the certificate chain summary is not created on other HA peers.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After the ConfigSync operation, when you run the tmsh run /sys crypto check-cert verbose enabled command, the certificate chain summary is not displayed on the other HA peers.

Workaround

To work around this issue, you can copy the certificate chain file manually to the affected HA peers and update the certificate chain. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the standby BIG-IP command line and copy the certificate chain file to the /shared/tmp directory.
  2. Log in to tmsh by typing the following command:

    tmsh

  3. To update the certificate, use the following command syntax:

    modify /sys file ssl-cert <cert name> source-path <path/to/cert/file>

    For example, to update the certificate located in /shared/tmp/Cert-Chain_Browser_Serv.crt_58761_1 into the SSL certificate name Cert-Chain_Browser_Serv.crt , type the following command:

    modify /sys file ssl-cert Cert-Chain_Browser_Serv.crt source-path file:/shared/tmp/Cert-Chain_Browser_Serv.crt_58761_1

    Note: This step makes the units out of sync. To bring the units back in sync, perform an additional ConfigSync operation. For more information about ConfigSync, refer to K13920: Performing a ConfigSync using the Configuration utility.

  4. Save the change by typing the following command:

    save /sys config
