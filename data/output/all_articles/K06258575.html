Policy Information

This article provides an overview of the supported upgrade path and related information to assist in planning for an upgrade to F5 BIG-IP Guided Configuration.

Important: This article is not a comprehensive guide to upgrading. The specific steps for upgrading to a specific version are detailed in the release notes for that version.

Description

BIG-IP Guided Configuration for BIG-IP APM and Advanced Web Application Firewall provides simple, workflow-driven configuration templates that cover common use case scenarios. These configurations can be further edited, adding more components and apps, using the BIG-IP Guided Configuration interface.

F5 rapidly updates BIG-IP Guided Configuration as new deployment types and techniques are discovered. Each BIG-IP version includes a bundled version of BIG-IP Guided Configuration that can be updated.

Important: F5 recommends that you upgrade to the latest Guided Configuration use case pack when it is available. The latest use case pack includes additional templates, features, and fixes.

Support policy

The F5 software policy described in this article applies to F5 Guided Configuration (GC), also known as Access Guided Configuration (AGC).

Guided Configuration (GC) provides a simplified GUI to create BIG-IP configurations. F5 provides configuration and troubleshooting assistance for general questions for the last two releases of the GC iAppLX package. F5 provides fixes and enhancements based only on the latest release of the F5 GC package, then includes the fixes and enhancements in the next release available at downloads.f5.com.

Upgrade policy

F5 recommends that you upgrade to the current release of Guided Configuration to ensure the latest functionality and fixes. To ensure configuration stability, F5 Product Development exhaustively tests upgrade scenarios between versions. As with other F5 software, the maximum supported version jump is two versions. For example, you can upgrade from 4.0 to 6.0 but not 4.0 to 7.0. 

To find out which BIG-IP version supports your system's version of Guided Configuration, determine your Guided Configuration version, search MyF5.com for the Guided Configuration release notes (for example "Guided Configuration 10.0 release notes"), and then select Applies To: in the upper right corner of the release notes to view the supported BIG-IP versions. If you do not know your system's Guided Configuration version, refer to K04402174: How to display F5 Guided Configuration version. 

Note: BIG-IP 13.1.x contains an older iAppLX framework that supports only GC 7.x and earlier.
