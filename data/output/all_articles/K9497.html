Known Issue

This is the result of a known issue. If you replace a tri-speed copper small form-factor pluggable (SFP) module with a fiber SFP, the link status reports that the link is down, and error messages that appear similar to the following example may be logged to the /var/log/ltm file:

bcm56xxd[315]: 012c0016:6: Port ge3: Failed to recover link status: Operation timed out
bcm56xxd[315]: 012c0016:6: Port ge3: temporarily removed from linkscan

F5 Product Development tracked this issue as CR83207 and it was fixed in BIG-IP version 9.4.2. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue still exists in the BIG-IP version 9.6.x and version 10.x software branches.

Workaround

You can work around this issue by disconnecting and reconnecting the fiber SFP module for the link status to report.
