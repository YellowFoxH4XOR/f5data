K9631: RAM Cache behavior for objects when URL normalization is disabled

Topic

When URL normalization is disabled for a policy node, RAM Cache is also disabled. Objects matching the policy node will not be cached in the RAM Cache.

When URL normalization is globally disabled for an object type or group, RAM Cache behavior is not affected. Objects with URL normalization disabled globally are still eligible to be cached in the RAM Cache.

Note: LTM RAM Cache is referred to as Hot Cache in BIG-IP WebAccelerator documentation.

URL normalization may be disabled for a node by disabling the content-based identity feature in the Advanced Assembly section of the BIG-IP WebAccelerator acceleration policy. For more information about disabling the content-based identity feature, refer to K8379: Overview of advanced assembly features for BIG-IP WebAccelerator policies and the Selectively disabling content-based identity section of the Configuration Guide for the BIG-IP WebAccelerator System. 

In version 10.x, URL normalization may be disabled in the Configuration utility by navigating to the Web Accelerator > Policies > URL Normalization screen. To disable normalization globally for all object types and groups, set URL Normalization to Disable. To disable normalization for specific object types or groups, set URL Normalization to enable, and select only the desired objects and groups for normalization in the Normalize these Types and Normalize these Groups dialog boxes.

In version 9.4.x, URL normalization may be disabled globally for an object type or group by editing the content-based identity section of the /config/wa/globalfragments.xml file.

Note: Beginning in BIG-IP WebAccelerator 11.x, URL normalization is no longer supported.
