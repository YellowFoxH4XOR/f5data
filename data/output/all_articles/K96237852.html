Description

Client browser shows the following error message:
PR_CONNECT_RESET_ERROR

This Virtual Server goes to a Windows ADFS.

Pcap will show that the ADFS will send a RST to the BIG-IP after the BIG-IP sends a Client Hello.

This Client Hello will not have a SNI.

Environment

  • BIG-IP
  • Virtual Server for ADFS application
  • RST by ADFS after receiving BIG-IP Client Hello
  • BIG-IP Client Hello does not have SNI
  • Client browser will show error PR_CONNECT_RESET_ERROR

Cause

ADFS will RST the connection because it requires the SNI.

Recommended Actions

You will need to forward the SNI received by the client browser to the ADFS.
Refer to article K41600007 to resolve this issue.

None.
