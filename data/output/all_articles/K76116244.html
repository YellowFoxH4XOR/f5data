Known Issue

When you use the Configuration utility or the TMOS Shell (tmsh) to enter trailing comments in iRules, the BIG-IP system removes the comments.

This issue occurs when all of the following conditions are met:

  • You use tmsh to merge an iRule in a configuration file or enter the iRule manually in tmsh or the Configuration utility.
  • The iRules comments are outside of any event stanza.

Impact

The system removes the trailing comments in the iRules.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Comments at the bottom of an iRule (outside of any event stanza) end up missing from the configuration.

Resolution

Status

F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, make sure comments are inside of an event stanza.
