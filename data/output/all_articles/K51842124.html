Issue

Description

The Mac OS X Edge Client reports an Error: VPN disconnected error message while the user is connecting to the VPN.

You may observe the following error messages in the ~/Library/Logs/F5Networks/vpn.log file:

2019-03-15, 11:45:31:547, 2219, 134270, svpn.log, 1, receive() failed, 0x36, Connection reset by peer
2019-03-15, 11:45:31:548, 2219, 134270, svpn.log, 1, EXCEPTION - m_iTransport->Read() error
2019-03-15, 11:45:31:548, 2219, 134270, svpn.log, 1, EXCEPTION caught: UHTTPChannel::beginConnection() - EXCEPTION

Environment

  • BIG-IP APM Network Access in Full or Split Tunnel mode
  • BIG-IP Edge Client for Mac OS X

Cause

During the VPN connection setup, an intermediate device or BIG-IP sends a TCP reset (RST).

Recommended Actions

  • Enable TCP RST logging on the BIG-IP system to determine if the BIG-IP system initialized the TCP RST. For more information, refer to K13223: Configuring the BIG-IP system to log TCP RST packets.
  • Perform a simultaneous network packet capture on the BIG-IP and the MAC client to determine the cause of the network reset. For more information, refer to K50501944: Gathering data to troubleshoot BIG-IP APM Network Access tunnels (11.x).
