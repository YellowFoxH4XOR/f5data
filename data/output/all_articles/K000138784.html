Description

After upgrade tmsh list commands fail for user with role Guest with error "Unexpected Error: Can't display all items, can't get object count from mcpd"


Environment

BIG-IP

Cause

(Bug alias 912277) Less-privileged user (guest, operator, etc) is unable to list security ip-intelligence fqdn-entity

Recommended Actions

There is no hotfix available for this bug yet, but as a workaround for the guest role, if you are very specific in the command about the modules/commands you are trying to list you should be able to get the information needed


For instance:


Use "list ltm" when you want to see the ltm configuration, rather than using "list all-properties" and parsing through the output.

If you are working in the "list security" sub-command, specify the data you are looking for. "list security ip-intelligence blacklist-category" should still work while "list security ip-intelligence fqdn-entity" will not.


The question mark command helper still works, you can use that to find out syntax for specific commands they are looking for:


guestuser@(guest-list-bigip)(cfg-sync Standalone)(Active)(/Common)(tmos)# list ?
