Known Issue

This is the result of a known issue. In rare instances, TMM may core while processing a client SSL certificate.

F5 Product Development tracked this issue as CR137015 and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP APM, ASM, LTM, PSM, and WebAccelerator release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.
