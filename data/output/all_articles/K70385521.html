Description

When attempting to license the unit via GUI or CLI, gets a licensing error 

"Error 51074: Invalid Dossier - Contains non-Hexadecimal characters"

Environment

  • Configuration Utility (Web GUI)
  • CLI
  • Licensing

Cause

There is a possibility that non-hex characters have been accidentally added to the dossier. 

Recommended Actions

  • Double check the dossier for typos or "copy and paste" errors. 
  • Ensure that no characters are added or deleted.

Additional Information

A valid dossier contains only hexadecimal characters; A-F and 0-9.

Historically, we have seen customers copy e-mail notes requesting licenses, Auth3 files, V5A licenses, private keys, public keys, and the HTML source to the manual activation page.
