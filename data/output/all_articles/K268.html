Topic

The terms state mirroring and connection mirroring refer to BIG-IP's ability to share connection state information (to virtual servers (VIPs) and SNATs) between two BIG-IP Controller's in a redundant pair. This ensures that in the event of a failover, the peer BIG-IP will have current connection information and users will not be disconnected.

State mirroring is enabled on BIG-IP (by default) on a global level and must also be enabled for each virtual server and SNAT (this is disabled by default). For specific information about configuring state mirroring, refer to the BIG-IP Reference Guide.

State mirroring is typically more effective on services that have longer-lived connections, such as telnet or FTP. You should not enable state mirroring for HTTP or HTTPS.
