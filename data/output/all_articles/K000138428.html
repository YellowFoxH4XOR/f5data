K000138428: Unable to initialize HSM on a new rSeries appliance

Type
Support Solution
Published
2024-01-31
Updated
2024-01-31
Source
https://my.f5.com/manage/s/article/K000138428

Description

When deploying a new rSeries appliance with the hardware security module (HSM), the following error is returned:

 

rSeries-appliance(config)# fips hsm force-init

Value for 'new-so-password' (<string, min: 7 chars, max: 30 chars>): ********************

Value for 'confirm-new-so-password' (<string, min: 7 chars, max: 30 chars>): ********************

Error: HSM force init failed: UNKNOWN: no error message

 

Environment

  • rSeries appliance, running F5OS
  • HSM module

Cause

Special characters are not allowed in the password, resulting in the error.

 

Error: HSM force init failed: UNKNOWN: no error message

Recommended Actions

Run the "fips hsm force-init" command to initialize HSM, but use a password with only alphanumeric characters.
