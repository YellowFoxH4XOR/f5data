Description

This article explains how to poll SSL certificate expiration information using SNMP OIDs on BIG-IP LTM systems. It focuses on retrieving certificate expiration dates for monitoring purposes, including how to interpret and convert the returned values into a human-readable format.

Environment

  • Product: BIG-IP LTM

Cause

You would like to poll the specific OID regarding certificate expiration instead of receiving a trap.

Recommended Actions

To poll SSL certificate expiration information via SNMP, use the following OID:

Textual OID: F5-BIGIP-SYSTEM-MIB::sysCertificateFileObjectExpirationDate

Numeric OID: .1.3.6.1.4.1.3375.2.1.15.1.2.1.5

This OID will display all certificates with Counter64 format as follows:

F5-BIGIP-SYSTEM-MIB::sysCertificateFileObjectExpirationDate."/Common/default.crt" = Counter64: 2097664890
F5-BIGIP-SYSTEM-MIB::sysCertificateFileObjectExpirationDate."/Common/f5-irule.crt" = Counter64: 1815944413
F5-BIGIP-SYSTEM-MIB::sysCertificateFileObjectExpirationDate."/Common/ca-bundle.crt" = Counter64: 2405116800
F5-BIGIP-SYSTEM-MIB::sysCertificateFileObjectExpirationDate."/Common/f5-ca-bundle.crt" = Counter64: 2221603200

Each value can be calculated from the current value to date format using the following command:

date -d @2221603200 -u

Output:

Sat May 26 00:00:00 UTC 2040

You would expect to poll a specific cert and receive a complete date format. You should use the following OID and example command:

snmpwalk -v2c -c public localhost 1.3.6.1.4.1.3375.2.1.15.1.2.1.4

F5-BIGIP-SYSTEM-MIB::sysCertificateFileObjectExpirationString."/Common/default.crt" = STRING: Jun 21 12:41:30 2036 GMT
F5-BIGIP-SYSTEM-MIB::sysCertificateFileObjectExpirationString."/Common/f5-irule.crt" = STRING: Jul 18 21:00:13 2027 GMT
F5-BIGIP-SYSTEM-MIB::sysCertificateFileObjectExpirationString."/Common/ca-bundle.crt" = STRING: Mar 20 00:00:00 2046 GMT
F5-BIGIP-SYSTEM-MIB::sysCertificateFileObjectExpirationString."/Common/f5-ca-bundle.crt" = STRING: May 26 00:00:00 2040 GMT

To check the exact OID for the only one specific certificate, use:

snmpwalk -v2c -c public localhost -On 1.3.6.1.4.1.3375.2.1.15.1.2.1.4
