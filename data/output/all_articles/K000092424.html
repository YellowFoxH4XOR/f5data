K000092424: Are our BIG-IP APM Virtual Editions (VE's) compatible with VMware ESXi version 7.0 U3

Description

The question is will BIG-IP VE v15.1.5.7 works properly on VMware ESXi version 7.0 U3


 Environment

  • BIG-IP Virtual Edition
  • Deployed on VMware ESXi
  • ESXi version 7.0 U3
  • Compatibility

 Cause

Per F5 BIG-IP Virtual Edition Supported Platforms in the table, BIG-IP versions 16.1.X, 15.1.X, 14.1.0.6+ are compatible with Update 3 of the VMware ESXi hypervisor, there's a note in the document conveying this information:


"Support for major VMware ESXi releases and updates includes all subsequent patches (for example, U1-U2)."


The comment above implies also future updates like in this case U3.
