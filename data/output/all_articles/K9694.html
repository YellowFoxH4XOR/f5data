Topic

The Windows DNS Relay Proxy is a component of the BIG-IP Edge Client, and is uniquely configured for each associated APM policy, and globally configured on FirePass controllers. The component is installed as a Microsoft Windows system service. The DNS Relay Proxy resolves several client name resolution issues. Previously, clients connecting with a network access tunnel without the DNS Relay Proxy service installed would encounter the following issues:

  • BIG-IP APM and FirePass users with limited Windows privileges could not connect to host names defined on the Network Access : Resources page under the Hosts tab. This feature required write access to the Windows hosts file.
  • Users with limited Windows privileges could not connect to a FirePass Static Application Tunnel (App Tunnel) if the App Tunnel was configured with a remote host name instead of a remote IP address. To connect to the remote host by host name, the user required write access to the Windows hosts file.
  • Users running Windows Vista could not access Windows file shares through FirePass Static App Tunnels.
  • Users running Windows XP could not access Windows file shares through FirePass Static App Tunnels if the user's account on the client system was a Limited User account.

In addition to resolving these issues, the DNS Relay Proxy offers improvements to the Network Access split-tunneling feature. Specifically, when you configure split tunneling and type at least one domain name in the DNS address space field, the DNS Relay Proxy service directs client DNS requests to the DNS servers that are configured for the Network Access connection when the domain name matches a domain name in the DNS address space field. All other client DNS requests are directed to the DNS servers configured on the client system. The DNS Proxy component for APM Network Access split tunneling is specifically configured based on the Secure Connectivity > Client Profile settings in the BIG-IP APM policy's Connectivity Profile.

Note: The nslookup command will not be a valid DNS test as this command bypasses the DNS Proxy component and uses the locally configured DNS servers.

For Static App Tunnels, the DNS Relay Proxy service offers enhanced DNS name resolution functionality for applications that refer to other internal host names, such as a web page accessed through a Static App Tunnel that contains links to other internal host names.

Note: The DNS Relay Proxy service does not interface with the following FirePass features: Dynamic App Tunnels, Web App Tunnels, and Portal Access applications.

Important: The DNS Relay Proxy component requires Windows administrator privileges for installation. After the service is installed, the DNS Relay Proxy service runs for users with limited Windows privileges.

Recommendations

  • The DNS Relay Proxy service is a default component setting for the BIG-IP APM and BIG-IP Edge Gateway client download. For the FirePass Legacy Client, the DNS Proxy service component is an optional component, and is not automatically installed or delivered to client systems; you must manually download and install this component on client systems. To download the DNS Relay Proxy client component from the FirePass Configuration utility, navigate to Device Management > Client Downloads > Windows (x86) > Customize Package (add the DNS Relay Proxy as one of the components) > Download.
  • Download the DNS Relay Proxy application from the BIG-IP system. For more information about downloading the DNS Relay Proxy, refer to the Configuration Guide for BIG-IP Access Policy Manager.

    Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

  • Use an administrator account on the user's computer to install the DNS Relay Proxy.
