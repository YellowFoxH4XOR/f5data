Known Issue

Modifying Analytics profile objects may cause a memory leak.

This issue occurs when the following condition is met:

  • Analytics profiles are created, deleted, or modified.

Impact

A memory leak may eventually cause all Analytics reporting to stop.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The virtual and resident memory values for the md process may continue to increase over time, as seen in the example output of the top -p `pidof md` command:

    PID USER PR NI VIRT RES SHR S %CPU %MEM TIME+ COMMAND
    6534 root 20 0 280m 220m 8596 S 3.7 5.5 50:07.54 md
  • Messages similar to the following example may be written to the /var/log/ltm file:

    warning md[5510]: 01540004:4: AVR Alert, MD exceeded 90.7% of provisioned memory allocation!! Entering Collect None mode. Please raise AVR provisioning definitions

Status

Workaround

To work around this issue, you can restart the Analytics service. To do so, perform the following procedure:

Impact of workaround: All analytics services will be briefly interrupted.

  1. Log in to the BIG-IP command line.
  2. Restart the Analytics service by typing the following command:

    bigstart restart md
