K12471: The ARX system requires a 256-megabyte buffer to clear a 'shareFreeSpaceThresholdRaise' event

Known Issue

When the free space available for a share falls below the amount specified by a free space policy, the ARX system will send a shareFreeSpaceThresholdRaise event SNMP trap. To clear this event, a 256-megabyte buffer greater than the threshold must be reached.

For example, on a share configured with a 1000-megabyte free space threshold, if the space available drops below 1000 megabytes, the ARX system will send a shareFreeSpaceThresholdRaise event SNMP trap and log a message to the snmp file that appears similar to the following example:

- shareFreeSpaceThresholdRaise (620) shr 'cifs_1:/cifs_mv1:cifs_mv1_sh1', name 'filer-01', ip '10.10.10.106', threshold'1000MB', available '942MB', : Share is below the configured threshold of free space.

In addition, the show health command will list the shareFreeSpaceThresholdRaise event, which appears similar to the following example:

System Health Information
Date                      ID     Event                        Description
---------------------------------------------------------------------------------------
Tue Nov 23 11:56:46 2010 (620) - shareFreeSpaceThresholdRaise shr 'cifs_1:/cifs_mv1:cifs_mv1_sh1', filer 'filer-01' :Share is below the configured threshold of free space.

For this example, the share requires a minimum of 1256 megabytes of free space available to clear the shareFreeSpaceThresholdRaise event. The ARX system will then send a shareFreeSpaceThresholdClear event SNMP trap and log a message to the snmp file that appears similar to the following example:

- shareFreeSpaceThresholdClear (610) shr 'cifs_1:/cifs_mv1:cifs_mv1_sh1', name 'filer-01', ip '10.10.10.106', threshold '1000MB', available '1910MB', : Share is above the configured threshold of free space.

In addition, the show health command will no longer list the shareFreeSpaceThresholdRaise event.
