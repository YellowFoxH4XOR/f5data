Issue

Old Behavior

In versions prior to BIG-IP 14.1, Bot Signatures and Proactive Bot Defense are located on the DoS Profiles page in the Configuration utility.

Security  >  DoS Protection > DoS Profiles

New Behavior

Beginning in BIG-IP 14.1, the Bot Defense page is located under Security in the Configuration utility:

Security > Bot Defense

The following features are combined into one profile called the Bot Defense profile:

  • Proactive Bot Defense
  • Bot Signature features in the DoS profile
  • Web Scraping in the BIG-IP ASM security policy

For more information, refer to K42323285: Overview of the unified Bot Defense profile.

Impact

When upgrading ASM from previous versions to BIG-IP 14.1 or later, the system creates a new Bot Defense profile for each DoS profile that has Bot Signatures or Proactive Bot Defense or both turned on.

The Bot Defense Profile names start with bot-defense-upgraded-from- in the following location:

Security > Bot Defense > Bot Defense Profiles

For example:

Security > Bot Defense > Bot Defense Profiles > bot-defense-upgraded-from-DoSProfilesBeforeUpgrade
