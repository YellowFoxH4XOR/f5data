K000150502: BIG-IP ASM/advanced WAF, allowed URLs configured with group-matching wildcards are flagged with "Illegal URL" in versions v17.x and later

Description

When you configure group matching URLs under Security ›› Application Security : URLs : Allowed URLs, as shown in the example below, you may notice that requests matching those URLs are still flagged as illegal or blocked with the "Illegal URL" violation. This behavior occurs in newer versions of BIG-IP starting from v17.x, whereas it worked as expected in earlier versions. You would like to understand the reason behind this change in behavior.

/api/v2/fetch/@(users|data|services)

Environment

  • BIG-IP ASM
  • Group matching for allowed URLs

Cause

Behaviour change for group matching in v17.x compared to v16.x and v15.x.

Group matching was not supposed to be supported as in the syntax used in above example URL. In earlier versions of BIG-IP, this capability is present but marked as incorrect behaviour, and this is rectified on v17.x (ID1821165).

Recommended Actions

If you use such URLs configured in the previous versions, you should make sure to recreate your URLs based on the supported wildcard syntaxes, refer "Wildcard syntax" section in the Manual Chapter : Adding Entities to a Security Policy
