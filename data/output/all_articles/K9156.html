Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following article:

  • K13885: Setting the baud rate of the serial console port (11.x and later)

You can change the baud rate of the serial console port using one of the following three methods:

  • Setting the baud rate of the serial console port using the LCD panel
  • Setting the baud rate of the serial console port using the command line
  • Setting the baud rate of the serial console port using the SCCP or AOM command menu

Important: For systems with multiple BIG-IP versions installed, all boot locations must use the same baud rate.

Setting the serial console baud rate using the LCD panel

  1. On the LCD panel, press X  to enter the menu.
  2. Using the down arrow button, select System.
  3. Press check.
  4. Using the down arrow button, select Serial Speed.
  5. Press check.
  6. Using the down arrow button, select the desired baud speed.
  7. Press check.
  8. Press X twice to exit the menu.

Setting the serial console baud rate using the command line

  1. Log in to the command line.
  2. To view the current baud rate value, type one of the following three commands depending on the version you are running:
    • BIG-IP 10.1.0 and later

      tmsh show sys console

      For example:

      # tmsh show sys console

      Sys::Console
      ----------------
      Baud Rate 19200

    • BIG-IP 9.4.0 through 10.0.1

      bigpipe hardware baud rate show

      For example:

      # bigpipe hardware baud rate show
      HARDWARE - baud rate: 19200

    • BIG-IP 9.1.2 through 9.1.3, and 9.2.0 through 9.3.1

      bigpipe baud rate show

      For example:

      # bigpipe baud rate show
      BAUD RATE 19200

  3. Set the new baud rate by typing one of the following three commands, depending on the version you are running:
  • BIG-IP 10.1.0 and later

    tmsh modify sys console baud-rate <value>

    For example:

    tmsh modify sys console baud-rate 9600

  • BIG-IP 9.4.0 through 10.0.1

    bigpipe hardware baud rate <value>

    For example:

    bigpipe hardware baud rate 9600

  • BIG-IP 9.1.2 through 9.1.3, and 9.2.0 through 9.3.1

    bigpipe baud rate <value>

    For example:

    bigpipe baud rate 9600

Note:  The BIG-IP serial console supports the following baud rates: 9600, 19200, 38400, 115200. The default baud rate of the serial console is 19200.

  1. Save the changes by typing one of the following two commands depending on the version you are running:
    • BIG-IP 10.1.0 and later

      tmsh save sys config

    • BIG-IP 9.1.2 through 10.0.1

      bigpipe save all

Setting the serial console baud rate using the SCCP or AOM command menu

Note: To determine whether a specific BIG-IP platform has a SCCP subsystem or an AOM subsystem, refer to K9476: The F5 hardware/software compatibility matrix

  1. Connect the serial console to the CONSOLE port.
  2. Display the SCCP or AOM Command Menu by typing the following key sequence:

    Esc (

    For AOM-based platforms, the AOM Command Menu opens, as displayed below:

    AOM Command Menu

    1 --- Connect to Host subsystem console
    2 --- Reboot Host subsystem (sends reboot command)
    3 --- Reset  Host subsystem (issues hardware reset--USE WITH CARE!)
    4 --- Reset AOM subsystem (issues hardware reset--USE WITH CARE!)
    5 --- Power off Host subsystem (issues hardware shutdown--USE WITH CARE!)
    B --- AOM baud rate configurator
    L --- AOM subsystem login
    N --- AOM network configurator
    P --- AOM platform information

    For SCCP-based platforms, the SCCP Command Menu opens, as displayed below:

    [hostconsh] Command Menu:

    1 --- Connect to Host subsystem console
    2 --- Select Host subsystem boot mode: boot from local drive
    3 --- Select Host subsystem boot mode: netboot manufacturing test
    4 --- Select Host subsystem boot mode: netboot from external server
    5 --- Reboot Host subsystem (sends reboot command)
    6 --- Halt Host subsystem (sends halt command)
    7 --- Reset Host subsystem (issues hardware reset--USE WITH CARE!)
    8 --- Reboot SCCP subsystem (issues hardware reset--USE WITH CARE!)
    9 --- Halt SCCP subsystem (issues hardware shutdown--USE WITH CARE!)
    D --- Run Diagnostics
    I --- Run BIG-IP Installer (issues hardware reset--USE WITH CARE!)
    B --- SCCP baud rate configurator
    L --- SCCP login
    N --- SCCP network configurator

  3. Type B to run the baud rate configurator.
  4. When prompted, type the new baud rate.

    For example, you would type 9600 at the prompt to set the new baud rate to 9600.
