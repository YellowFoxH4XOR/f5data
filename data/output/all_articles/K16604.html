Known Issue

If an HTTP cookie is invalid, then subsequent modifications to HTTP cookie entries may result in the TMM producing a core file.

This issue occurs when all of the following conditions are met:

  • You have an HTTP virtual server configured.
  • The HTTP virtual server performs cookie processing using an iRule, protocol profile, or as a result of persistence.

Impact

If the BIG-IP system is a member of a redundant configuration, traffic fails over to the standby BIG-IP system. If the BIG-IP system is not part of a redundant pair, traffic is interrupted until the TMM process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system may temporarily fail to pass traffic.
