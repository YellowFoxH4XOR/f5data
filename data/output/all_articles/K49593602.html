Description

It is not possible to reset BIG-IP interface counters/statistics through CLI or Configuration Utility.

Environment

  • BIG-IP VE or VCMP platforms only.

Cause

Version might be affected by ID 594228, which does not permit management interface statistics counters to be reset.

Recommended Actions
Use CLI commands sequence:       

ifdown eth0; ifup eth0
Note: run above command as a single line 
tmsh reset-stats net interface mgmt
tmsh show net interface mgmt
 

Additional Information

Bug ID 594228: Resetting mgmt interface statistics doesn't work on VE or VCMP
