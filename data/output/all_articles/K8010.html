K8010: The BIG-IP ASM does not support the use of the X-Forwarded-For header for logging purposes

Note: A new feature has been introduced in BIG-IP ASM 10.1.0 to allow the configuration of specific X-Forwarded-For headers to be trusted. For information about how to configure this feature, refer to the BIG-IP Application Security Manager Configuration Guide for version 10.1.0. For more information about the Trusted X-Forwarded-For header, refer to K12264: Overview of the Trusted X-Forwarded-For header.

The X-Forwarded-For header is commonly used by network devices that translate the source IP address to store the original source IP address. Since the X-Forwarded-For header can easily be forged, and cannot be validated unless the upstream device is trustworthy, BIG-IP ASM does not use the value of the X-Forwarded-For header for logging, forensics, or statistics. Instead, BIG-IP ASM uses the source IP address listed in the packet as the address. As a result, traffic whose source IP address has been translated will be associated with the translation source IP address from the packet received by BIG-IP ASM. Traffic whose source IP address has been translated will not be associated with the originating source IP address of the client, even if the originating source IP address of the client is contained in an X-Forwarded-For header.
