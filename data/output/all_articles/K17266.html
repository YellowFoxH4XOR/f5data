Known Issue

The Traffic Management Microkernel (TMM) may restart when a protocol profile is modified and a virtual server referencing the protocol profile is deleted.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server to reference a protocol profile.
  • You modify the protocol profile.
  • Immediately after modifying the protocol profile, you delete the virtual server.

Impact

Service will be interrupted while TMM restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system may fail to process traffic for a brief period.
  • The BIG-IP system may fail over to another host in the device group.
  • TMM generates a core file in /var/core.

Workaround

To work around this issue, you can avoid modifying protocol profiles if the referencing virtual server will be deleted.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
