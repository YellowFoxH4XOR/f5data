Topic

You should consider using this procedure under the following conditions:

  • You are an F5 Anti-Bot Mobile SDK customer.
  • You want to integrate with Appdome.

Description

F5 provides an Appdome promotion code as part of the Anti-Bot Mobile SDK license key.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have received a registration key email from F5.

Procedures

Retrieving and activating your Appdome promotion code

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Open the email from f5networks@f5.com with the following subject line:

    Registration Key <Registration Key> for F5 Product <Product SKU>

  2. Search the email for the following string:

    App_Dome_Promo_Code

  3. Go to the Appdome registration page, locate the Enter Promo Code (if you have one) box, and enter the promotion code string from step 2.

For more information, contact your local F5 Sales team.
