Known Issue

Note: BIG-IP version 11.x is not affected by this issue as the bigpipe command is removed from BIG-IP software starting in version 11.0.0.

This is the result of a known issue. The bigpipe utility may report a bigpipe parsing error message when attempting to install or load a configuration file from a previous version of the BIG-IP system on BIG-IP 9.4.3 or later.

The parsing error message may appear similar to one the following examples:

  • BIGpipe parsing error (Line 27):
    012e0010:3: The requested value (crypt) is invalid ((crypt (<string> | none) | <string> | none)) for 'password' in 'configsync'
  • BIGpipe parsing error (Line 216):
    012e0021:3: The requested attribute () for 'configsync' is invalid.
  • BIGpipe parsing error (/config/bigip.conf Line 249):
    012e0054:3: The braced list of attributes is not closed for 'configsync'.

This issue occurs when the bigpipe utility encounters the encrypted configsync password located in the /config/bigip.conf file. This behavior does not occur with all encrypted passwords; it occurs based on the way the password is encrypted, and how the bigpipe utility interprets the characters used in the encryption.

F5 Product Development is tracking this issue as ID 248639 (formerly CR90952).

Workaround

If a bigpipe parsing error message is reported after upgrading to BIG-IP 9.4.3 or later, perform the following procedure:

  1. Log in to the command line.
  2. Using a text editor, edit the /config/bigip.conf file.
  3. Locate the line starting with configsync {.
  4. Add double quotation marks around the password listed after the password crypt line.

    For example:

    configsync {
    password crypt "@N1FCBf-BM<cC+EaFY6qUOWfeYOI,aS27CK/TU^:>Xd:Pck"
    }

  5. Save the changes.
  6. Load the configuration using the following command:

    bigpipe load

  7. Perform steps 1 through 6 on the peer unit.
