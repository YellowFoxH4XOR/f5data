Known Issue

Using the Configuration utility to configure a translation address for a BIG-IP GTM server may fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP GTM system runs an affected version.
  • Your BIG-IP GTM system may have one or more existing BIG-IP GTM servers configured with a translation address.
  • You have attempted to configure a translation address for the BIG-IP GTM server using the Configuration utility in one of the following ways:
    • You create a new BIG-IP GTM server with a translation address by way of Global Traffic > Servers > Server List > New Server.
    • You modify an existing BIG-IP GTM server and configure a translation address with an existing or new server address, by way of Global Traffic > Servers > Server List > Properties > [Existing-GTM-Server-Name].

Impact

You are unable to configure translation addresses for BIG-IP GTM servers using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H427850 on the Diagnostics > Identified > Medium screen.
  • When you click Create or Update to create or modify the BIG-IP GTM Server, the Configuration utility displays an error message similar to the following example:

    Invalid IP Address

Workaround

To work around this issue, you can configure translation addresses for BIG-IP GTM servers using the Traffic Management Shell (tmsh) utility. To do so, perform the following procedure.

Creating a BIG-IP GTM server with a translation address

Impact of workaround: You may be unable to use the Configuration utility to add a new BIG-IP GTM server address that has no translation address.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Create a new BIG-IP GTM server with a translation address, using the following command syntax:

    create /gtm server <GTM-Server-Name> addresses add { <GTM-Server-IP> { translation <Translation-IP-Address> } }

    For example, to create a new BIG-IP GTM server named gtm-A, with a server IP address of 10.10.10.100, and the translation IP address of 10.20.20.120, type the following command:

    create /gtm server gtm-A addresses add { 10.10.10.100 { translation 10.20.20.120 } }

  3. Save the changes by typing the following command:

    save /sys config

  4. Verify the list of BIG-IP GTM server addresses that you have modified by using the following command syntax:

    list /gtm server <GTM-Server-Name>

    For example, to list the BIG-IP GTM server gtm-A, type the following command:

    list /gtm server gtm-A

  5. To exit the tmsh utility, type quit and press Enter.

Adding a translation address to an existing BIG-IP GTM server

To use the tmsh utility to add a translation address to an existing BIG-IP GTM server, perform the following procedure.

Impact of workaround: You may be unable to use the Configuration utility to add a new BIG-IP GTM server address that has no translation address.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Add a translation address to an existing BIG-IP GTM server using the following command syntax:

    modify /gtm server <GTM-Server-Name> addresses [modify|add] { <GTM-Server-IP> { translation <Translation-IP-Address> } }

    For example, to modify an existing BIG-IP GTM server named gtm-A, with a server IP of 10.10.10.100, and the new translation IP address is 10.20.20.120, type the following command:

    modify /gtm server gtm-A addresses modify { 10.10.10.100 { translation 10.20.20.120 } }

  3. Save the changes by typing the following command:

    save /sys config

  4. Verify the list of BIG-IP GTM server addresses that you have modified by using the following command syntax:

    list /gtm server <GTM-Server-Name>

    For example, to list the configuration of the BIG-IP GTM server gtm-A, type the following command:

    list /gtm server gtm-A

  5. To exit the tmsh utility, type quit and press Enter.
