Known Issue

The SSL proxy session ID cache does not respect the limit set by the tmm.proxyssl.cachesize setting.

This issue occurs when all of the following conditions are met:

  • The Proxy SSL feature is enabled.
  • You have a non-default tmm.proxyssl.cachesize database key value set.

Impact

If you are using the tmm.proxyssl.cachesize setting to avoid low memory conditions, the low memory conditions may persist.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The conditions for which the tmm.proxyssl.cachesize setting is attempting to alleviate may continue to persist.
