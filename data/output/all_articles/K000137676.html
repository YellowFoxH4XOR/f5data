Description

When creating tenant through Configuration Utility, customer may find below error message popping up.

/tenants/tenant{<Tenant name>}/config: test has invalid value for storage/size. Maximum tenant size on this variant is 297GB.
Hide Details
error-type : application
error-tag : malformed-message
error-path : /f5-tenants:tenants/tenant[name='<Tenant name>']
error-message : /tenants/tenant{<Tenant name>}/config: test has invalid value for storage/size. Maximum tenant size on this variant is 297GB.

Environment

  • F5OS

  • R2000/R4000

Cause

297GB is the maximum tenant disk size on the R2000 and R4000 platform.

Recommended Actions

Reduce the tenant disk size allocation to 297G or lower.

Additional Information

None.
