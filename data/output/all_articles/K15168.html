Known Issue

The BIG-IP system may intermittently use an unexpected IP address as the SNAT IP address.

This issue occurs when all of the following conditions are met:

  • The configuration contains a virtual server that uses any one of the following profiles:
    • MBLB
    • SIP
    • Diameter
    • Radius
  • The affected virtual server uses an iRule that contains the SNAT command with a configured IP address in the LB_SELECTED event.

When this issue occurs, the message-based load balancing (MBLB) messaging proxy may incorrectly detect the iRule running state, which triggers the SNAT iRule to intermittently select a self IP address instead of the configured SNAT IP address for the affected connection.

Impact

The BIG-IP system may intermittently use a self IP address instead of the configured SNAT IP address.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H456702 on the Diagnostics > Identified > Medium screen.
  • The affected virtual server for the affected connection may intermittently select a self IP address instead of the configured SNAT IP address as the source IP address.
  • If the affected iRule has logging enabled, you notice in the /var/log/ltm log file that the system intermittently chooses the incorrect source IP address for the server side connection.
  • In the tcpdump capture, you observe that the system intermittently chooses the incorrect source IP address for the server side connection.
