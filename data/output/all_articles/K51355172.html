Known Issue

When you create a monitor using a TMOS Shell (tmsh) batch mode transaction, it may contain newline syntax that is not valid.

This issue occurs when all of the following conditions are met:

  • You use a tmsh batch mode transaction to create a monitor that contains the following escaped, newline syntax:

    \r\n

  • You assign the monitor to an object.

Impact

The monitor marks the monitored object as unavailable/down.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You create a monitor using a tmsh batch mode transaction and use the following escaped, newline syntax:

    \r\n

    However, the system saves the syntax as the following:

    \\r\\n

Resolution

Workaround

To work around this issue, you can create the monitor using the tmsh create /ltm monitor command, separate from the batch transaction.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
