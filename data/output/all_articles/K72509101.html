Known Issue

The BIG-IP system may fail to trigger the SERVER_CONNECTED iRule event.

This issue occurs when all of the following conditions are met:

  • Your system has an iRule associated with a virtual server that uses the SERVER_CONNECTED event.
  • The virtual server is configured with a User Datagram Protocol (UDP) profile.
  • The virtual server is also configured as the Performance (Layer 4) type with a FastL4 profile.

Impact

iRule commands that follow the SERVER_CONNECTED event are not executed.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • iRule commands that follow the SERVER_CONNECTED event are not executed.

For example, if there is a command following the SERVER_CONNECTED event to log information, the information is not logged.

Workaround

To work around this issue, you can change the virtual server type from Performance (Layer 4) to Standard. To do so, perform the following procedure:

Impact of workaround: Changing the virtual server type from Performance (Layer 4) to Standard may add a small amount of latency to connections.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Server > Virtual Server List.
  3. Select the affected virtual server.
  4. From the Type menu, select Standard.
  5. Click Update.
