K42766526: BIG-IP VE Management IP may fail if only 1 Network Card is used

Type
Support Solution
Published
2022-04-19
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K42766526

Description

If you setup a BIG-IP VE that only has one network card, then the Management Interface may fail, if you try to set a static IP Address for Management.

Environment

  • BIG-IP VE
  • Only a single network card provisioned
  • Static IP Address for Management

Cause

The BIG-IP VE has a DB Variable:

provision.1nicautoconfig

By default, this is set to enabled. When the BIG-IP boots, initially, the Static Management IP responds as expect. However when TMM takes over the single NIC interface, and if Management is not configured via DHCP, then the Management IP will stop responding.

Recommended Actions

You can either disable provision.1nicautoconfig, or add a 2nd NIC interface.

tmsh modify sys db provision.1nicautoconfig value disable
