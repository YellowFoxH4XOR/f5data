When Cisco SLB is selected for the Host Server SNMP probe type, the 3-DNS Controller probes the following OIDs:

IdentifierOID
VM IPAddress1.3.6.1.4.1.9.9.161.1.4.1.1.4
VM Port1.3.6.1.4.1.9.9.161.1.4.1.1.5
VM State1.3.6.1.4.1.9.9.161.1.4.1.1.2
VM Farm Name1.3.6.1.4.1.9.9.161.1.4.1.1.9
VM Current Connections1.3.6.1.4.1.9.9.161.1.4.1.1.17
VM Total Connections1.3.6.1.4.1.9.9.161.1.4.1.1.18
Farm Name1.3.6.1.4.1.9.9.161.1.2.1.1.1
Farm Servers1.3.6.1.4.1.9.9.161.1.2.1.1.4

To find OIDs for other vendors, use the strings Unix command on big3d and the grep command to get the manufacturer string.

For example:

strings /usr/sbin/big3d | grep 2467

Will return the following:

 1.3.6.1.4.1.2467.1.18.2.1.1
