Description

When configuring BIG-IQ to create daily backups and send them to a remote server, the backup process fails if the remote server is specified in the backup job. The error message displayed in the Alerts & Notifications tab under Monitoring of the GUI is:

 

Backup failed to be created "There was a failure when creating a backup. Additional information: UCS backup with id <backup_id>, name <backup_name>, and referer <referer_url> failed: to archive backup while making ssh connection to <remote_server_ip> Algorithm negotiation fail"

 

Direct SFTP connections from BIG-IQ to the remote server are successful, but backups initiated via the scheduler fail due to SSH algorithm negotiation issues.

 

Environment

  • BIG IQ
  • Backup remote server

Cause

The issue arises due to an incompatibility between key exchange algorithms supported by BIG-IQ's and those offered by the remote server.

Remote server can generate the following log:

Unable to negotiate with <BIG-IQ_IP> port <port>: no matching host key type found.
Their offer: ssh-rsa,ssh-dss,ecdsa-sha2-nistp256,ecdsa-sha2-nistp384,ecdsa-sha2-nistp521
Our offer: ssh-ed25519,rsa-sha2-512

 Recommended Actions 

Reconfigure SSH settings on remote server to match exchange algorithms with BIG IQ
