Known Issue

This is the result of a known issue. The cross-site request forgery (CSRF) cookie is not renewed upon first successful request after the cookie has expired. As a result, valid client requests are blocked, and a CSRF authentication expired violation is triggered each time the valid client attempts to make a request.

Note: For more information about CSRF, refer to the Configuring CSRF Protection chapter of the Configuration Guide for BIG-IP Application Security Manager.

F5 Product Development tracked this issue as ID 224964 (formally CR138200) and it was fixed in BIG-IP ASM 10.2.1. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue has been fixed in BIGIP-10.2.0-1755.1-HF1 for BIG-IP 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
