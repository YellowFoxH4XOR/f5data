Known Issue

This is the result of a known issue. When a user tries to establish a Network Access connection from a Linux or Mac OS X client that has a proxy configured in Firefox, the Network Access fails to launch. In addition, error messages that appear similar to the following examples display:

Network Access client prepare routing table error

Connection dropped

This issue appears to be isolated to FirePass 6.0.3 with HF-603-1 installed.

Note: For more information, refer to K10150: Web browser proxy settings.

F5 Product Development is tracking this issue as CR55523.
