Issue

This article provides numerous steps for troubleshooting common connectivity and logon issues that occur when accessing a FirePass controller from a Microsoft Windows system.

For BIG-IP APM and Microsoft Windows troubleshooting, refer to K17421: Troubleshooting BIG-IP Edge Client issues on Microsoft Windows systems.

Important: F5 supports FirePass controller software and FirePass client software. F5 does not support third party software, such as the client operating system or non-F5 applications installed on the client system.

Verifying the client system

The following procedures check basic network connectivity, system health, and common issues associated with establishing Network Access and Application Access connections:

  1. Log on to the client system using an account with local administrator privileges. Several FirePass client components require elevated privileges in order to install properly on a Windows system. Once these client components are installed, other users on the client system may run these components even if they do not have local administrator privileges.
  2. Attempt to reproduce the issue on the client system using the account with local administrator privileges. If the same issue occurs, proceed to the next troubleshooting step.

    If the issue does not occur, the likely cause of the issue is insufficient Windows privileges for the original user account. Have the original user log on to the client system and attempt to reproduce the issue again.

    If the issue still occurs, proceed to the next troubleshooting step.

    If the issue does not occur, the likely cause is insufficient Windows privileges. If permitted by your IT security policy, assign local administrator privileges to the user’s account on the client system. Alternatively, pre-install all required FirePass client components or install the FirePass Component Installer service on the client system.

    For more information about these options, refer to the FirePass Controller Administrator Guide.
  3. If the client system is running Windows XP with Service Pack 2, ensure that Microsoft Update KB884020 is installed.

    For more information, refer to K3289: FirePass compatibility with Windows XP Service Pack 2 clients.
  4. Verify basic TCP/IP connectivity on the client system using tools such as the ping utility and tracert utility.

    For more information about troubleshooting TCP/IP connectivity, refer to the following websites:
    • http://support.microsoft.com/kb/169790
    • http://support.microsoft.com/kb/314067
  5. Run the nslookup utility on the client system to verify that DNS is resolving properly.

    For more information about nslookup, refer to the following website:

    http://support.microsoft.com/kb/200525
  6. Review the known issues listed in the Release Notes for your version of FirePass software.
  7. Search the AskF5 Knowledge Base for known issues affecting your version of FirePass software.
  8. Attempt to reproduce the issue on other systems that run the same version of Microsoft Windows as the affected client system. If possible, ensure that the other systems have the same service packs and Windows hotfixes or updates as the affected client system.

    If the other systems are on the same Windows domain, log on to the other systems as the user who originally reported the issue and attempt to reproduce the issue.

    Additionally, log on as a user with local administrator privileges on the other systems and attempt to reproduce the issue. Determine whether the issue is isolated to a specific user account (the issue only occurs for one user account, regardless of the client system) or whether it is isolated to a specific client system (the issue only occurs on a single client system, regardless of which user is logged on). If you can reproduce the same issue on all systems, that indicates a possible issue with the FirePass software.

    Important: Windows client systems that are members of a Windows domain may have a Group Policy, which affects the operation of the Network Access (VPN) connection. F5 recommends that you attempt to reproduce the issue using at least one system that is not a member of the Windows domain.
  9. When the issue occurs, open the Windows Event Viewer to see if any errors or connection attempt messages are reported. For more information about using the Event Viewer, refer to your Microsoft Windows documentation.
  10. Ensure that the client system is free from viruses, spyware, trojans, or other forms of malicious software that may affect the operation of the client system.
  11. Open the Windows Task Manager and review processes listed under the Applications and Processes tab. Under the Processes tab, ensure that the Show processes from all users check box is selected (if it appears). Ensure that no processes are running that may interfere with a Network Access or Application Access connection, such as personal firewalls, which prohibit these connections or another vendor’s VPN software. Under the Performance tab, ensure that the client system has sufficient available CPU and memory to launch additional processes, such as the FirePass client components.

    Note: Some malicious software may prevent the Windows Task Manager from reporting all running processes. If you suspect that the client system has malicious software installed, you may need to run third-party software instead of the Windows Task Manager to verify which processes are running.
  12. On the client system, restore the browser configuration to its default settings. While many modern browsers are customizable, not all configurations are compatible with the FirePass client components.

    For more information about restoring the browser configuration, refer to the vendor browser documentation.
  13. Ensure that the Remote Access Connection Manager and the Telephony Windows services are in a Started state on the affected client system. Restart these services if possible.

    For more information about viewing and managing Windows services, refer to your Microsoft Windows documentation.
  14. Temporarily disable all antivirus, firewall, and other security software on the client system while troubleshooting the issue. If possible, close all non-F5 applications (excluding the browser if connecting to the FirePass webtop).

    Important: Performing this step may decrease the security of the client system and your network. Disabling security software may make the client system more vulnerable to attacks and malicious software. Before you perform this step, F5 strongly recommends that you evaluate the risks to your environment before disabling any security software. Perform this step at your own risk.
  15. Remove and re-install all FirePass client components on the client system.

    For more information about removing FirePass client components, refer to K8253: Removing FirePass client components from Windows client systems

    Note: Users may require Power User or Administrator privileges on the client system to remove and re-install the FirePass client components.


Troubleshooting pre-logon and logon failures

To troubleshoot pre-logon and logon failures, perform the following procedures:

  • To troubleshoot pre-logon failures, review client pre-logon data to determine which endpoint security checks are failing.

    For more information, refer to K6358: Displaying pre-logon data for a FirePass client.
  • To troubleshoot logon failures, temporarily enable extended error messages.

    For more information, refer to K3754: Configuring FirePass to log extended error messages about client login failures.
  • Review the known issues listed in the Release Notes for your version of FirePass software.
  • Search the AskF5 Knowledge Base for the known issues that affect your version of FirePass software.


Advanced Troubleshooting

You can use these advanced troubleshooting procedures if the previous troubleshooting steps do not resolve the issue. You can also use these procedures in conjunction with the previous troubleshooting procedures:

  1. If you are running FirePass version 6.0.2, log on to the FirePass Administrative Console and download the Components Troubleshooting Utility.

    This utility is located under the Downloads tab on the Device Management: Client Download: Windows (x86) page.

    Run the f5wininfo.exe utility on the affected client system, and select Generate Report from the File menu.

    Select the reports you want to generate, and review the reports to assist in your troubleshooting.
  2. Enable and review trace logs.

    If the user connects to the FirePass controller using the webtop, log on to the FirePass webtop on the client system and launch the affected Network Access or Application Access connection.

    In the Network Access or Application Access status window, click the Setup icon, and then click the arrow to the left of Trace Logs. 

    If trace logging is disabled, click the Click here to enable logging link to enable trace logging.

    Terminate the affected Network Access or Application Access connection, and then launch it again.

    In the status window, click the Setup icon in the Network Access or Application Access status window.

    Click the arrow to the left of Trace Logs, then click the Click here to view logs link to view the trace logs. If any errors are reported, enter the errors into the search engine on the AskF5 Knowledge Base to search for related Solutions. If you cannot find any related Solutions, provide the log data when opening a case with F5 Technical Support.

    If the user connects to the FirePass controller using the standalone VPN client, launch the VPN client on the client system and select Settings from the View menu.

    Select the Enable trace logs check box and click the OK button to enable trace logging. Reproduce the issue using the standalone VPN client.

    Next, select Settings from the View menu and click the View Trace Log button to view the trace logs. If any errors are reported, enter the errors into the search engine on the AskF5 Knowledge Base to search for related Solutions. If you cannot find any related Solutions, provide the log data when opening a case with F5 Technical Support.

If you performed all of the troubleshooting steps outlined in this Solution, but could not resolve issue, and the issue can only be reproduced on a single Windows system or a small group of Windows systems, you may need to reinstall the Windows operating system on the affected client systems.

Important: Perform this step at your own risk. F5 is not responsible for any issues arising from reinstalling the operating system. Some issues can only be resolved by reinstalling the operating system, especially in cases where the client system was corrupted due to malicious software, disk failure, or other hardware issues.
