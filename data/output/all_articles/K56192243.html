Description

Following error messages can be seen on device:

Nov 16 09:35:00 RC10210001 warning tmm2[20435]: 01010290:4: TCP: Memory pressure activated
Nov 16 09:35:00 RC10210001 warning tmm2[20435]: 01010290:4: TCP: Memory pressure activated

Mirroring IPs are not configured for devices:

CentMgmt::Device: /Common/big-ip-a

------------------------------------------------------------------------------------------------
Hostname                       big-ip-a
Mgmt Ip                        10.x.x.x
Configsync Ip                  10.y.y.y
Mirroring IP                   :: <-------------

But mirroring for persistence profile is enabled:

 

ltm persistence source-addr /Common/test_persist {
    app-service none
    defaults-from /Common/source_addr
    match-across-services enabled
    match-across-virtuals enabled
    mirror enabled <---------------------
    timeout 960
}

Environment

  • BIG-IP
  • Mirroring IPs not configured
  • Mirroring enabled for persistence profile

Cause

Persistence mirroring is enabled on some persistence profiles but there is no mirroring IP configured. This is a common cause of high persist entries in tmm memory.

Recommended Actions

There are two options to solve this issue:
  1. Configure Mirroring IPs on both devices in the cluster and restart TMM or reboot affected unit:
    K84303332: Overview of connection and persistence mirroring (13.x - 16.x)
     
  2. Disable mirroring on the persistence profiles:

    - Log in to tmsh by entering the following command:
    # tmsh

    - To enable persistence mirroring for a persistence profile, use the following command syntax:
    # modify /ltm persistence <profile_type> <profile_name> mirror disabled
    For example, to enable mirroring for a hash persistence profile named

    - Save the change by entering the following command:
    # save /sys config
