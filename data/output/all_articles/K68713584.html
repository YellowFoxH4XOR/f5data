Security Advisory Description

BZ2_decompress in decompress.c in bzip2 through 1.0.6 has an out-of-bounds write when there are many selectors. (CVE-2019-12900)

Impact

BIG-IP AAM

If an iSession tunnel is configured with an iSession profile that has bzip2 compression enabled, an attacker using specially crafted compressed files can exploit a vulnerability that exists in the decompress functionality of the bzip2 utility, causing an out-of-bounds write. For more information about out-of-bounds writes, refer to CWE-787: Out-of-bounds Write.

BIG-IP, BIG-IQ, Enterprise Manager, iWorkflow, and Traffix SDC

A locally authenticated attacker, using specially crafted compressed files, can exploit a vulnerability that exists in the decompress functionality of the bzip2 utility, causing an out-of-bounds write. For more information about out-of-bounds writes, refer to CWE-787: Out-of-bounds Write.

Mitigation

BIG-IP AAM

To mitigate this vulnerability for BIG-IP AAM, you can disable bzip2 compression in any configured iSession profile. To do so, perform one of the following procedures:

  • Using the Configuration utility to disable bzip2 compression
  • Using tmsh to disable bzip2 compression

Using the Configuration utility to disable bzip2 compression

Impact of action: Disabling compression may result in higher latency between iSession endpoints. F5 recommends only disabling bzip2 compression. Additionally, you should perform testing within a maintenance window to ensure changes are compatible with your environment.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > Services > iSession.
  3. Select the name of your iSession profile.
  4. Under Compression Settings, for Bzip2, select Disabled.
  5. Select Update.
  6. Repeat this procedure on the corresponding BIG-IP iSession tunnel endpoint.

Using tmsh to disable bzip2 compression

Impact of action: Disabling compression may result in higher latency between iSession endpoints. F5 recommends only disabling bzip2 compression. Additionally, you should perform testing within a maintenance window to ensure changes are compatible with your environment.

  1. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  2. To disable bzip2 compression for your iSession profile, use the following command syntax:

    modify /wom profile isession <profile name> compression-codecs delete { bzip2 }

    For example, to disable bzip2 compression in an iSession profile named my-iSession, enter the following command:

    modify /wom profile isession my-iSession compression-codecs delete { bzip2 }

  3. To view the configuration, use the following command syntax:

    list /wom profile isession <profile name>

    Output appears similar to the following example for a profile named my-iSession:

    wom profile isession my-iSession {
        app-service none
        compression-codecs { deflate lzo }
        defaults-from isession
    }

  4. Save the configuration by entering the following command:

    save /sys config
