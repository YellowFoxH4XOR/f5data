Issue

You should consider using this procedure under the following conditions:

  • You configure the access policy on the BIG-IP APM system with a machine certificate check.
  • The BIG-IP APM client fails to pass the configured machine certificate check.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When authenticating to the BIG-IP APM system, Windows users see a permission denied message. 
  • Windows users are unable to authenticate to the BIG-IP APM system.

Recommended Actions

This article provides steps for troubleshooting machine certificate authentication issues when the following occur:

  • The user accesses a BIG-IP APM system from a Windows system.
  • The user does not have local administrative privileges.

Procedures

When experiencing machine certificate authentication issues, you can use the following procedures to determine the root cause and work around the issue:

  • Generating diagnostic output using the Client Troubleshooting Utility (CTU)
  • Installing the machine certificate checker service for users who do not have local admin privileges

Generating diagnostic output using the CTU

To generate a report from an affected client and view the resulting f5mcertcheck file, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Click the About tab, and then click Downloads.
  3. Click Client Troubleshooting Utility for Windows to download the CTU executable file (f5wininfo.exe).
  4. Distribute the f5wininfo.exe file to an affected client.
  5. Run the f5wininfo.exe file as an administrator.
  6. To start the Diagnostic Reports option, on the main menu, click File and then click Generate Report.
  7. Review the logs found in the f5mcertcheck file generated by the CTU.

    When the machine certificate check fails due to insufficient user privileges, output appears similar to the following example:

    6004,2424,, 1, , 300, CCertCheckCtrl::CheckPrivateKey, EXCEPTION - The private key of the certificate is not present on the client computer OR not accessible to current user account
    6004,2424,, 1, , 330, CCertCheckCtrl::CheckPrivateKey, EXCEPTION caught: CCertCheckCtrl::CheckPrivateKey - EXCEPTION
    6004,2424,, 2, \f5/service/ServiceHelpers.h, 25, f5::Service::GetServiceState, Failed to open service 'MachineCertService': 1060 (0x424) The specified service does not exist as an installed service.
    6004,2424,, 2, \f5/RPC/BaseClient.h, 114, f5::RPC::BaseClient::CheckAndCall, Service isn't running
    6004,2424,, 1, , 0, , VerifyUsingService - Machine cert service isn't running. Limited user has no way to check machine certificate without service. Exiting

Installing the Machine Certificate Checker Service for users who do not have local admin privileges

For Windows clients that do not have local administrative privileges and fail a machine certificate check, you can work around the issue by installing the machine certificate checker service on the Windows system. The service can check the machine certificate on a client endpoint even when the user does not have administrative privileges. To download and install the machine certificate checker service, perform the following procedure:

Impact of procedure:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility and navigate to the Connectivity profiles:
    • Access > Connectivity / VPN > Connectivity (BIG-IP 13.x and later)
    • Access Policy > Secure Connectivity (BIG-IP 11.x - 12.x)
  2. In the list, click the Connectivity profile, and then click Customize Package.
  3. In Available Components, select Machine Certificate Checker Service, and then click Download.
  4. Distribute the downloaded machine certificate checker service to the failing client and install it as an administrator.

    The machine certificate checker service performs the machine certificate check for users without administrative privileges.
