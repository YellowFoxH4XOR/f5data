Topic

Beginning in BIG-IP 12.0.0, you can associate the clientssl-secure Secure Sockets Layer (SSL) profile with a virtual server. The clientssl-secure profile is a predefined profile type that you can use with valid and trusted SSL certificates to protect high-value sites.

Settings for the clientssl-secure profile

The clientssl-secure profile is based on the Client SSL profile. However, some values have been changed to allow for the highest security. The following table describes the notable clientssl-secure profile settings:

SettingValueDescription
Certificate Key Chaindefault.crt / default.keyBy default, the clientssl-secure profile uses a self-signed certificate, named default.crt. This field should be customized to reference a valid SSL certificate that is specific to the site to which the profile will be applied.
Ciphersecdhe:rsa:!sslv3:!rc4:!exp:!desThe cipher string is customized to meet the highest security needs. The string specifically excludes ciphers, such as DHE.
OptionsNo SSLThe Options List setting specifies that SSL is disabled for the profile. The SSL protocol is disabled to mitigate threats, such as the BEAST and POODLE vulnerabilities.
PassphraseNoneThe Passphrase setting is optional. It is only required if the key is passphrase-protected. There is no default value for this setting. If your key is passphrase-protected, enter the required passphrase.
RenegotiationDisabledThe Renegotiation option is disabled and the virtual server terminates or ignores renegotiation attempts.

Recommendations

When configuring the clientssl-secure profile, you should consider the following factors:

  • Configuring the clientssl-secure profile to use valid SSL certificates from a trusted certificate authority will allow the virtual server to obtain high scores from SSL server tests.
  • F5 recommends Extended Validation (EV) certificates for high-value websites, which may achieve a higher score from SSL server tests.
