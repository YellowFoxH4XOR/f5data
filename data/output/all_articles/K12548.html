Known Issue

This is the result of a known issue. The RAID controller battery status check is performed during the boot process of an ARX system. This check should be disabled for the ARX 2000 and 4000 platforms because they do not have a RAID controller battery. The battery status check may be inadvertently enabled on an ARX 2000 or 4000 system. As a result, the system will display the following warning message and prompt to the console:

The battery hardware is missing or malfunctioning, or the battery is unplugged,
or the battery could be fully discharged. If you continue to boot the system,
the battery-backed cache will not function. If battery is connected and has
been allowed to charge for 30 minutes and this message continues to appear, then
contact technical support for assistance.

Press 'D' to disable this warning (if your controller does not have a battery).

Note: Pressing the D key immediately after the prompt is displayed disables the battery check for subsequent reboots and allows the system to successfully continue the boot process.>

If you do not press the D key within approximately 10 seconds, the boot process attempts to continue. However, the system may fail to boot and display a message to the console that appears similar to the following:

GRUB loading, please wait...>

F5 Product Development tracked this issue as ID 344894 and it was fixed in ARX versions 5.2.2 and 6.0.0. For information about upgrading, refer to the ARX release notes.

Workaround

For ARX 2000 or 4000 systems that have had the battery status check inadvertently enabled, and display the warning message, pressing D immediately after the prompt is displayed disables the battery check for subsequent reboots.

If D was not pressed in time (or at all), and the system continued the boot process successfully, you can use the reload command to display the prompt to disable the battery check for subsequent reboots. If the system failed to boot and remained at the GRUB loading message, you must power cycle the ARX system to re-display the prompt.
