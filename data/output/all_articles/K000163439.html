K000163439: Advance End of Sale announcement for BIG-IP Virtual Edition V23 licenses

Type
Policy
Published
2026-10-01
Updated
2026-10-01
Source

F5 has released the Version Select perpetual licensing model for BIG-IP Virtual Edition (VE), which replaces the earlier Version Plus model.

As of October 1, 2026, the first set of Version Select licenses that are associated with BIG-IP 22.x are available for purchase. These new licenses will replace the existing BIG-IP VE V23 Version Plus licenses and will be compatible with BIG-IP versions 17.1.x through 22.x.

The new Version Select model includes base and upgrade add-on licenses. Base licenses are associated with a specific major BIG-IP software version (e.g. BIG-IP 22.x) and do not include access to subsequent major software versions.

To upgrade beyond the BIG-IP version associated with a Version Select base license, customers should obtain an upgrade add-on license, which adds support for the next sequential software version. For example, applying a V22 to V23 upgrade add-on license to a V22 base license enables that BIG-IP VE to also operate BIG-IP 23.x. Please note that only one upgrade add-on license can be applied to each base license.

With the availability of BIG-IP VE V22 Version Select licenses, F5 is announcing the End of Sale (EoS) of BIG-IP VE V23 Version Plus licenses, effective January 1, 2026.

F5 is providing advance product notification to customers and partners announcing intent to EoS the products listed in the following table.
