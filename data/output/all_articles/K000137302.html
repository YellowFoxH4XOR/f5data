K000137302: The installation stall with status ''Audited''

Type
Support Solution
Published
2023-11-08
Updated
2023-11-08
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000137302

Description

After installing the new image to the new boot volume HD 1.2, the installation stuck

GUI is not showing the new boot volume on System>>Software Management: Image List
GUI is showing the previous existing volume status as 'Audited'

CLI 'tmsh show sys software status' is showing the same results

The /var/log/liveinstall.log is showing the installation of the new image is success.
The /var/log/ltm is showing mcpd error "the requested software status (0 HD1.2) was not found"
 

Environment

BIG-IP, Install the new image 16.1.4.1 stalled.
Checked K91155702,  not matching - no /shared/noupgrade file on the system.


Cause

The lind process is unable to create the new volume.
(The lind process manages software installation and volume creation tasks.)
 

Recommended Actions

To workaround this issue, you can manually restart lind process

bigstart restart lind
Impact if not running: No software installation functionality

 

Additional Information
