Known Issue

The BIG-IP system may reset connections when a virtual server is configured with the OneConnect profile and the Preserve Strict setting.

This issue occurs when all of the following conditions are met:

  • Clustered Multiprocessing (CMP) is disabled or the Source Port setting is Preserve Strict on a virtual server.
  • The virtual server is configured with the OneConnect profile.
  • A client request to the virtual server reuses a server-side flow.

The issue appears more frequently when you use Preserve Strict setting on the 2000 and 4000 series platforms.

Impact

The system may unexpectedly reset connections.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H584370 on the Diagnostics > Identified > Low screen.
  • The system may unexpectedly reset connections to a virtual server that meets the previously mentioned conditions.
  • In the /var/log/ltm file,  you observe error messages that appear similar to the following examples:
     
    • err tmm1[16750]: 01230140:3: RST sent from 10.16.30.169:80 to 10.16.30.131:10001, Unknown reason
    • err tmm1[22581]: 01230140:3: RST sent from 10.16.30.169:80 to 10.16.30.131:10001, [0x23b4c98:1432] Out of ports
    • err tmm1[21816]: 01230140:3: RST sent from 10.16.30.169:80 to 10.16.30.131:10001, [0x26dad84:1657] Unable to obtain local port
