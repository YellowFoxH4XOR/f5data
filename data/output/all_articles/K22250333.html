Known Issue

Configuration changes to persistence profiles may cause a manual configuration synchronization (ConfigSync) operation to fail.

This issue occurs when all of the following conditions are met:

  • Automatic synchronization is disabled on a device group.
  • A user creates then deletes a persistence profile on one unit before manually syncing the configuration.

Impact

Peer units fail to load the configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After syncing the configuration, the system reports an error message in the Configuration utility that appears similar to the following example:

    01070381:3: One or more persistence attributes are incompatible with the persistence mode for profile (/Common/name-of-profile).

  • The system reports an error message to the /var/log/ltm file that appears similar to the following example::

    err mcpd[13722]: 01070381:3: One or more persistence attributes are incompatible with the persistence mode for profile (/Common/name-of-profile).

Workaround

To work around this issue, you can perform either of the following procedures:

Enabling full synchronization

Impact of workaround: This option has a performance impact as it syncs all configuration data each time a change occurs.

  1. On the Main tab, click Device Management > Device Groups.
  2. In the Group Name column, click the name of the relevant device group.
  3. Select the Full Sync check box.
  4. Click Update.

For more information about the differences between full and incremental synchronization, refer to the help section within Device Groups or the BIG-IP Device Service Clustering: Administration Guide.

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Performing a manual synchronization after each change

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

You should use this option if you do not want to enable a full synchronization, but you require that an administrator performs a manual synchronization after each change of a persistence profile.

For example:

  1. Create a profile.
  2. Perform a manual synchronization.
  3. Delete the recently created profile.
  4. Perform a manual synchronization.

This method ensures the proper information is updated on the local system before sharing the information with the peer units.
