K41507946: TLS support for the Enterprise Manager Configuration utility

Type
Knowledge
Published
2019-04-23
Updated
2023-02-21
Applies to
  • Legacy Products
  • Enterprise Manager: 3.1.X, 3.0.X, 3.1.1, 3.X.X, 3.0.0, 3.1.0
Source
https://my.f5.com/manage/s/article/K41507946

Topic

The Enterprise Manager system includes OpenSSL 0.9.8, which supports only Transport Layer Security (TLS) 1.0 for the TLS protocol. It does not support TLS 1.1 or TLS 1.2. As a result, you can only configure the Configuration utility to support TLS protocols up through TLS 1.0, as well as SSL protocols up through SSL 3.

Note: Enterprise Manager 3.1.1 HF8 includes OpenSSL 0.9.8zg.

Note: TLS 1.1 and TLS 1.2 are not included in OpenSSL until version 1.0.1.

Recommendations

F5 recommends that you consider migrating to BIG-IQ Centralized Management if you require the use of TLS 1.1 or TLS 1.2.
