Topic

You should consider using this procedure under the following condition:

  • You want to use the command line to view active Configuration utility user sessions (logged-in users).

Description

You can track active users connected to the Configuration utility by searching the audit logs on the BIG-IP system.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have Advanced Shell (bash) access to the BIG-IP system.

Procedures

Viewing active Configuration utility user sessions

This procedure describes how to use the grep utility to search the /var/log/audit file for BIG-IP user activity.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Search the /var/log/audit or /var/log/audit.1 files with the following syntax for httpd(mod_auth_pam), which indicates a user logged in to the BIG-IP system using the Configuration utility:

    grep "httpd(mod_auth_pam)" /var/log/<audit log file>

    For example:

    grep "httpd(mod_auth_pam)" /var/log/audit

    The output appears similar to the following:

    Sep 25 09:52:41 bigip16-0.askf5team.local notice httpd[4570]: 01070417:5: AUDIT - user admin - RAW: httpd(mod_auth_pam): user=admin(admin) partition=[All] level=Administrator tty=/bin/false host=172.16.0.75 attempts=1 start="Fri Sep 25 09:52:41 2020".
    Sep 25 11:54:38 bigip16-0.askf5team.local notice httpd[6286]: 01070417:5: AUDIT - user admin - RAW: httpd(mod_auth_pam): user=admin(admin) partition=[All] level=Administrator tty=/bin/false host=172.16.0.75 attempts=1 start="Fri Sep 25 09:52:41 2020" end="Fri Sep 25 11:54:38 2020".
    Sep 25 11:57:36 bigip16-0.askf5team.local notice httpd[26007]: 01070417:5: AUDIT - user user1 - RAW: httpd(mod_auth_pam): user=user1(user1) partition=[All] level=Administrator tty=/usr/bin/tmsh host=172.16.0.70 attempts=1 start="Fri Sep 25 11:57:36 2020".

    The lines with only a start time show when a user logged in, and the lines that contain both a start and end time indicate when a user has logged out. In this example, the admin user logged in and logged out while the user1 user has logged in but has not logged out, signifying an active user session.

    Note: In BIG-IP 11.6.x, the first archived file of the audit log is compressed, so the file is actually audit.1.gz. Handling compressed archived files is described in step 4 of the procedure.

  3. You can clean up the output by printing only certain fields using the pipe operator and the cut command. To do so, use the following command syntax:

    grep "httpd(mod_auth_pam)" /var/log/<audit log file> | cut -c 7- | cut -d' ' -f14,20-31

    For example:

    grep "httpd(mod_auth_pam)" /var/log/audit | cut -c 7- | cut -d' ' -f14,20-31

    The output appears similar to the following example:

    user=admin(admin) start="Fri Sep 25 09:52:41 2020".
    user=admin(admin) start="Fri Sep 25 09:52:41 2020" end="Fri Sep 25 11:54:38 2020".
    user=user1(user1) start="Fri Sep 25 11:57:36 2020".

  4. If a user session spans an extended period of time, you can search archived audit logs with the zgrep utility. For example, use either of the following commands:
    • zgrep "httpd(mod_auth_pam)" /var/log/audit.2.gz
    • zgrep "httpd(mod_auth_pam)" /var/log/audit.2.gz | cut -c 7- | cut -d' ' -f14,20-31
