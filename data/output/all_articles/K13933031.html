Recommended Actions
To determine if the BIG-IP is actually causing a delay in packet transmission, you MUST collect both clientside and serverside streams, preferably in the same packet capture.

  • Identify affected configuration objects
  • Build a Berkeley Packet Filter (BPF)
  • Perform a packet capture
  • Merge the captures
  • Analyze the packet captures

Perform a packet capture

Using the BPF from above, run a tcpdump while the problem is occurring.

tcpdump -s0 -i 0.0:nnn '(host 192.168.0.1 and port 80) or (host (10.10.10.10 or 10.10.10.20 or 10.10.10.30) and host (10.10.10.110 or 10.10.10.120 or 10.10.10.130) and port 80)' -w /var/tmp/K13933031.pcap -v -W 10 -C 125

Analyze the packet captures

Perform the following procedure to analyze the packet capture. Note that the following commands in this procedure assumes the virtual server is listening at port 443. Replace 443 in the commands as appropriate.

You may skip directly to the Use a script to analyze packet captures section instead of running the commands in this procedure manually.

Leverage the tcp.time_delta feature of tshark to identify delay in TCP transmissions
  1. Create the Wireshark and tshark filter for making a manageable capture:

    IMPORTANT: The following must be performed on a system which has the F5 Ethernet Trailers installed (default in tshark 3.0.1 and later).
    Note: F5 Ethernet trailers are not present on the BIG-IP until 14.0.0.

     
    1. Look for top 200 offending packets (ones with longest tcp.time_delta value) and save the output for further analysis: 
      tshark -r /var/tmp/K13933031.pcap \
    -Y tcp.port==443 \
    -E separator=, \
    -T fields \
        -e tcp.time_delta \
        -e ip.addr \
        -e tcp.port \
        -e f5ethtrailer.peeraddr \
        -e f5ethtrailer.peerport \
  | sort -k1nr -t, \
  | head -n 200 \
  | sed 's@,,$@@g' \
  | cut -d, -f2- \
  | sed -e "s/,443//g" \
  | sort -u > /var/tmp/K13933031.out

IMPORTANT: The following must be performed on a system which has the F5 Ethernet Trailers installed (default in tshark 3.0.1 and later).
Note: F5 Ethernet trailers are not present on the BIG-IP until 14.0.0.

  • Create the following script as /var/tmp/K13933031.sh 
    #!/usr/bin/env bash
REGEX_1_SEARCH='^([0-9]+\.[0-9]+\.[0-9]+\.[0-9]+),([0-9]+\.[0-9]+\.[0-9]+\.[0-9]+),([0-9]+),([0-9]+\.[0-9]+\.[0-9]+\.[0-9]+),([0-9]+\.[0-9]+\.[0-9]+\.[0-9]+),([0-9]+)$'
REGEX_1_REPLACE='(ip.addr==\1\&\&ip.addr==\2\&\&tcp.port==\3)||(ip.addr==\4\&\&ip.addr==\5\&\&tcp.port==\6)'
REGEX_2_SEARCH='^([0-9]+\.[0-9]+\.[0-9]+\.[0-9]+),([0-9]+\.[0-9]+\.[0-9]+\.[0-9]+),([0-9]+)$'
REGEX_2_REPLACE='(ip.addr==\1\&\&ip.addr==\2\&\&tcp.port==\3)'

read -p "Virtual Server Port[Default 443]: " VSPORT
VSPORT=${VSPORT:-443}

# This is used in a tshark filter below as: 'tcp.time_delta > ${DELAY}'
#   it can be set to 0 to show all tcp conversations (this may be a lot)
read -p "Minimum Delay (Set to '0' if you want to see all conversations) [Default 2]: " DELAY
DELAY=${DELAY:-2}

while IFS= read -r -d $'\0' f; do
  options[i++]="$f"
done < <(find . -maxdepth 1 -type f -name "*.pcap" -print0)

select opt in "${options[@]}" "Exit"; do
  case ${opt} in
    *.pcap)
      echo "Capture File ${opt} selected"
      CAPTURE="${opt}"
      break
      ;;
    "Exit")
      echo "You chose to stop exit"
      break
      ;;
    *)
      echo "This is not a valid option. Try again."
      ;;
  esac
done

DIRECTORY=$(dirname -- ${CAPTURE})
FILENAME=$(basename -- "${CAPTURE}")
EXTENSION="${FILENAME##*.}"
FILENAME="${FILENAME%.*}"
CATURE_FILTERS=${DIRECTORY}/${FILENAME}.out
CAPTURE_FILTERED=${DIRECTORY}/${FILENAME}_filtered.pcap

#
# Create a text file containing Wireshark Filters.
# These include Clientside and Serverside (when available) connections.
#
echo "Creating a list of top 200 longest delay packets. This may take a while..."
echo "Writing: ${CATURE_FILTERS}"

tshark -r ${CAPTURE} \
    -Y tcp.port==${VSPORT} \
    -E separator=, \
    -T fields \
        -e tcp.time_delta \
        -e ip.addr \
        -e tcp.port \
        -e f5ethtrailer.peeraddr \
        -e f5ethtrailer.peerport \
  | sort -k1nr -t, \
  | head -n 200 \
  | sed 's@,,$@@g' \
  | cut -d, -f2- \
  | sed -e "s/,${VSPORT}//g" \
  | sort -u > ${CATURE_FILTERS}

echo "Successfully wrote: ${CATURE_FILTERS}"

#
# Create a smaller packet capture,
#
echo "Creating filtered capture where tcp.time_delta is greater than '${DELAY}'."
echo "Output: ${CAPTURE_FILTERED}"

WIRESHARK_FILTER=$(sed -r "s/${REGEX_1_SEARCH}/${REGEX_1_REPLACE}/g;s/${REGEX_2_SEARCH}/${REGEX_2_REPLACE}/g" ${CATURE_FILTERS} | sed -r ':a;N;$!ba;s/$\n^/||/g')
tshark -r ${CAPTURE} -Y "${WIRESHARK_FILTER}" -w ${CAPTURE_FILTERED}

echo "Successfully created filtered capture: ${CAPTURE_FILTERED}"

#
# Iterate through each filter in ${CAPTURE_FILTERS}
# Reading from the smaller/filtered pcap
#
echo -e "\nParsing all filters in: ${CATURE_FILTERS}"

for WIRESHARK_FILTER in $(sed -r "s/${REGEX_1_SEARCH}/${REGEX_1_REPLACE}/g;s/${REGEX_2_SEARCH}/${REGEX_2_REPLACE}/g" ${CATURE_FILTERS}); do
    echo -e "\nWIRESHARK_FILTER: ${WIRESHARK_FILTER}"
    tshark -r ${CAPTURE_FILTERED} \
        -Y "(${WIRESHARK_FILTER}) && tcp.time_delta > ${DELAY}" \
        -E header=y \
        -E separator=\& \
        -T fields \
            -e tcp.time_delta \
            -e ip.src \
            -e ip.dst \
            -e tcp.srcport \
            -e tcp.dstport \
            -e _ws.col.Info \
    | sed 's/tcp.srcport/srcport/g;s/tcp.dstport/dstport/g' \
    | column -t -s\&;
done

    /var/tmp/K13933031.sh
