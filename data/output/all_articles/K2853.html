K2853: You cannot use the Configuration utility to make changes to wide IPs that use ports that are not listed in the port menu

Known Issue

This is the result of a known issue. When you configure a wide IP that uses a port that is not listed in the port menu of the Configuration utility, 3-DNS replaces the port number that you enter with the service name for that port in the /etc/services file.

If you attempt to modify the wide IP configuration from the Configuration utility, 3-DNS will not be able to match the service name to one of the available ports for the menu. As a result, you cannot make any changes to that wide IP.

F5 Product Development tracked this problem as CR29967 and it was fixed in 3-DNS 4.5.10 for the version 4.5 software branch.

The fix for version 4.5.10 applies to only standalone 3-DNS products. Products that are licensed as a BIG-IP/3-DNS combination or as BIG-IP Link Controller are still affected by this issue when using the BIG-IP Link Controller Configuration utility.

F5 Product Development tracked this additional problem as CR32977 and CR41876.
