Known Issue

Connection timeouts between the snmpd service and the SNMP subagent on your BIG-IP system may produce a core file.

This issue occurs when the BIG-IP system is under heavy load and the snmpd process or subagent takes a long time to respond.

Impact

The snmpd process and/or SNMP subagent process may restart, and affected data may be lost.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system generates a core file from the snmpd process and/or the related Net-SNMP subagent.
  • Core files appear in the /shared/core directory.
  • Core file prefixes vary based on the SNMP-related binary involved in this issue. The known core file prefixes include the following:
    • sflow_agent
    • subsnmpd
    • snmpd

Workaround

There is no workaround for this issue.

To recover from this issue, so that the snmpd process can continue to work with the affected subagent, you can restart the snmpd process. To do so, perform the following procedure:

Impact of workaround: Services offered by the snmpd process are briefly interrupted.

  1. Log in to the BIG-IP system command-line prompt.
  2. To restart the snmpd process, type the following command:

    bigstart restart snmpd
