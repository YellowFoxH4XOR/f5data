Known Issue

When using the Configuration utility, you cannot delete Secure Socket Layer (SSL) certificates with names that contain special characters.

This issue occurs when the following condition is met:

  • During import, the SSL certificate name contains special characters, such as asterisks (*), colons (:), question marks (?), equal signs (=), at signs (@), and ampersands (&).

When importing certificates, such as a Client Revocation List (CRL), into the Configuration utility, you must provide a unique name for the certificate. The Configuration utility allows you to create names with special characters. However, F5 recommends that you use alphanumeric characters for file names.

Impact

You cannot use the Configuration utility to delete certificates that contain special characters.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Configuration utility System > File Management > SSL Certificate List page correctly displays the imported certificate.

    For example:

    test.*:?=@,&123.pem
  • After you click the certificate name, the Configuration utility displays a message similar to the following example:

    Instance not found:/Common/test.*:?@,
  • Selecting the check box next to the certificate name and clicking Delete shows a message similar to the following example:

    No records to display.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to delete the certificates whose names contain special characters. To do so, perform the following procedure:

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Delete the desired certificate using the following syntax:

    delete sys crypto <certificate type> <name of certificate>

    Note: The tmsh utility treats certain special characters, such as asterisks and question marks, as wildcard characters. You must escape these characters by using the backslash character (\).

    For example, to delete a file named test.*:?=@,&123.pem.crl, you would type the following command:

    delete sys crypto crl test.\*:\?=@,&123.pem.crl
  3. Save the change by typing the following command:

    save /sys config
