Description

You may encounter the error message shown below while running bigip_add from the BIG-IP DNS to a remote BIG-IP LTM system.
  • ERROR: Can't parse remote /config/httpd/conf/ssl.crt/server.crt on 192.168.1.10 via ssh.
  • ERROR: nested "BEGIN CERT..." found in /config/big3d/client.crt at line: 80.


Environment

  • BIG-IP DNS
  • BIG-IP LTM
  • bigip_add script
  • Device certificate


Cause

The certificate located in the /config/big3d/client.crt of the remote BIG-IP LTM system is corrupted.


 Recommended Actions

    1. Log in to the CLI of affected BIG-IP LTM system.
    2. You may use cat, less or more to view the /config/big3d/client.crt. You would see something like this:

    3. Log in to the GUI of the same BIG-IP LTM.
    4. Go to System > Certificate Management > Device Certificate management > Device Trust Certificate.
    5. In the Certificate Subjects, look for and Remove the certificate of the BIG-IP DNS that is failing to run bigip_add script.
    6. Log in to the CLI of BIG-IP DNS and re-run the bigip_add script to initiate the exchange of the device certificate again.
