Known Issue

The Traffic Management Microkernel (TMM) may restart unexpectedly when the BIG-IP system processes a Security Assertion Markup Language (SAML) single logout (SLO) request.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is functioning as a SAML Identity Provider (IdP) with SLO configured.
  • The BIG-IP APM system processes multiple simultaneous user logins and logouts.
  • An SLO request is received from a service provider (SP), and the connection closes before request processing completes.

Impact

The BIG-IP APM system temporarily fails to process traffic as it recovers from TMM restarting, and systems configured as part of a high availability (HA) group may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users are temporarily unable to access the BIG-IP APM system.
  • A TMM core file is generated to the /shared/core directory.
