K1881: Reasons why the BIG-IP system may fail over when you set the time or date forward

Topic

All BIG-IP monitoring uses the system time. If the system time is advanced into the future beyond the timeout value of the monitor (or gateway failsafe), the BIG-IP system views the monitored object as down, which causes a failover.

To work around this issue, disarm the gateway failsafe before you advance the system time. To disarm the gateway failsafe, type the following command:

bigpipe global gateway failsafe disarm
