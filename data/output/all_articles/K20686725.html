Description

System reported a dataplane error on tmm and went offline during normal operation. No core file created.

/var/log/ltm showed the following logs:

Nov 28 10:17:03 bigip crit tmm[25029]: 01010025:2: Device error: hsbe2 hsb_lbb1 hde2_crc_errs count 65535.
Nov 28 10:17:03 bigip.example.com warning sod[13148]: 01140029:4: HA dataplane_inoperable_t tmm fails action is go offline and down

Environment

This issue occurs on hardware appliances using High Speed Bus (hsb).

Cause

Possibly related to  Bug ID 591708

Recommended Actions

The system should be rebooted to restore service.

If the system continues to fault it may be defective.
