K000152819: Terminating inactive HTTP stream connections in Aspen Mesh (istio)

Type
Support Solution
Published
2025-08-20
Updated
2025-08-20
Applies to
  • Aspen Mesh: 1.X.X
Source
https://my.f5.com/manage/s/article/K000152819

Description

  • By default, idle HTTP2 stream connections remain open for extended period of time.
  • You need to terminate these idle connections.

Environment

  • Aspen Mesh
  • Istio
  • Envoy
  • HTTP/2
  • HTTP streams

Cause

  • By default, Envoy's "stream_idle_timeout" parameter is set to disabled.

Recommended Actions

  • This behavior can be modified by applying an envoy filter.
apiVersion: networking.istio. io/v1alpha3
kind: EnvoyFilter
metadata:
  name: sse-server-stream-timeout
  namespace: test-server 
spec:
  workloadSelector:
    labels:
      app: fastapi-sse
  configPatches:
  - applyTo: NETWORK_FILTER
    match:
      context: SIDECAR_INBOUND  # We need to target inbound traffic, as this is the SSE server.
      listener:
        filterChain:
          filter:
            name: envoy.filters.network.http_connection_manager
    patch:
      operation: MERGE
      value:
        name: envoy.filters.network.http_connection_manager
        typed_config:
          '@type': type.googleapis. com/envoy.extensions.filters.network.http_connection_manager.v3.HttpConnectionManager
          stream_idle_timeout: 120s
  • After applying the above filter, inactive streams will close after 120 seconds (stream_idle_timeout: 120s).

Additional Information

  • When istio repackages the sidecar proxy (Envoy), some default values are changed. One of them is "stream_idle_timeout". In documentation it is stated that the default value is 5 minutes, but by default istio disables this functionality.
