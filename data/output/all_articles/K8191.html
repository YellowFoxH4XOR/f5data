Topic

On BIG-IP systems running the ASM module, TMM runs as a data plane task within the BIG-IP operating system, and ASM processes, such as bd, run as control plane tasks.

On multi-CPU/multi-core platforms, the BIG-IP system allocates CPU resources for TMM and ASM processes as follows:

  • Prior to BIG-IP 11.5.0, each logical CPU core is assigned a separate TMM instance, and each core processes both data plane and control plane tasks.
  • In BIG-IP 11.5.0 and later, data plane tasks and control plane tasks use separate logical cores on systems with Intel Hyper-Threading Technology (HT Technology) CPUs. Even-numbered logical cores (hyperthreads) are allocated to TMM, while odd numbered cores are available for other processes.

The ASM CPU utilization screen displays the aggregated system CPU usage of ASM resources as a percentage, over time. The graphs show the average bd and TMM CPU usage for each CPU on the multi-bladed chassis or standalone system. For a multi-bladed chassis, the graph shows a set of statistics for each blade. For systems with multi-blades, the graph reports one line for each blade.

Note: The bd process implements the BIG-IP ASM security policy on the HTTP requests it receives from TMM.

Viewing the ASM CPU utilization charts

To view the ASM CPU utilization screen, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Security > Reporting > ASM Resources > CPU Utilization.
  3. To display advanced filter options, click the Expand Advanced Filters.

Collect ASM CPU utilization data

If you want an SNMP manager to collect the ASM CPU utilization data, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Determine the process identifier (PID) for both the bd process and TMM with F5-BIGIP-SYSTEM-MIB::sysProcPidStatProcName.
  2. Configure the SNMP manager to poll any or all of the following OIDs:
    • F5-BIGIP-SYSTEM-MIB::sysProcPidStatCpuUsageRecent
    • F5-BIGIP-SYSTEM-MIB::sysProcPidStatCpuUsage1min
    • F5-BIGIP-SYSTEM-MIB::sysProcPidStatCpuUsage5mins
    Include the PID in the OID. In the following example 1234 is the PID for bd and 5678 is the PID for TMM:
    F5-BIGIP-SYSTEM-MIB::sysProcPidStatCpuUsageRecent.0.1234
    F5-BIGIP-SYSTEM-MIB::sysProcPidStatCpuUsageRecent.0.5678
