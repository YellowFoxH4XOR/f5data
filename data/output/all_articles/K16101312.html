Known Issue

The tcpdump utility may take several seconds to start capturing packets on Virtual Clustered Multiprocessing (vCMP) guests.

This issue occurs when all of the following conditions are met:

  • The tcpdump utility is being run within a vCMP guest on a VIPRION platform.
  • The vCMP guest has more than one blade in use.

Impact

The tcpdump utility takes slightly longer than expected to start capturing traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The tcpdump utility takes three or more seconds to start capturing packets.

Workaround

To work around this issue, you can wait several additional seconds to ensure that the tcpdump operation has a sufficient interval to start capturing packets.
