Description

Too many users logged on to the management interface via SSH at the same time can potentially cause a device to run out of memory. This article provides the steps for configuring SSH session limits. Using this setting allows BIG-IP administrators to limit how many users can concurrently have active SSH sessions to the device.


Environment

  • BIG-IP CLI Management
  • SSH


Cause

None
 

Recommended Actions

NOTE: In order to successfully implement the feature, the following configuration must be set prior to enabling the SSH session limits:

  •   sys sshd inactivity-timeout must be set to a non-zero value.
  •   cli global-settings idle-timeout must be set to a non-zero value


1. Set the SSHD inactivity timeout.

For example, to set the inactivity timeout to 240 seconds, use the following command:

tmsh modify sys sshd inactivity-timeout 240
 

2. Set the CLI idle timeout.

For example, to set the idle timeout to 240 seconds, use the following command:

tmsh modify cli global-settings idle-timeout 240
 

3. Enable the SSH session limit feature.

tmsh modify sys global-settings ssh-session-limit enabled
 

4. Set the max session total limit for all users.

For example, to set the total session limit to 5, use the following command:

tmsh modify sys global-settings ssh-max-session-limit 5

Note: This setting does not affect root, until you set ssh-root-session-limit to enabled.
 

5. Set the max session limit per user.

For example, to set the per-user limit to 3, use the following command:

tmsh modify sys global-settings ssh-max-session-limit-per-user 3

Note: This setting does not affect root, until you set ssh-root-session-limit to enabled.
 

6. To include root in the users limited by the policy, set the ssh-root-session-limit to enabled.

tmsh modify sys global-settings ssh-root-session-limit enabled



When session limits are hit, logs similar to the following appear in /var/log/secure:

Mar 17 13:40:25 bigip1 err sshd[20093]: pam_bigip_authz: pam_sm_acct_mgmt: Cannot login, SSH Max Session limit reached
Mar 17 13:40:25 bigip1 crit sshd[20093]: fatal: Access denied for user root by PAM account configuration [preauth]
