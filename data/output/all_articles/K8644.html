Topic

You can use FirePass Portal Access Web Application favorites to view a web portal that contains a webified list of published Citrix resources, such as Citrix Web Interface (formerly Citrix NFuse) or a custom portal page. Typically, a webtop favorite points to a login page for the portal. Following authentication, one or more web pages that list available Citrix resources are presented to the user. The list may be static, or the portal may generate the list of resources in real-time (after the portal has authenticated the user) by communicating with the Citrix XenApp server (formerly Citrix Presentation Server and Citrix MetaFrame Server).

In the absence of the FirePass controller, clicking on a resource results in a Citrix ICA configuration file sent to the user's browser. The file contains information to establish an ICA connection to the Citrix server hosting the resource, including an IP address (or computer name, typically a fully-qualified domain name) and TCP port number. The browser then launches an ICA client; either a webified ICA client such as the ActiveX client or the Java ICA client. Alternatively, the browser can launch a fat client, such as the Citrix Program Neighborhood. The choice of Citrix client is governed by the program associated with the file type of .ica in the browser's configuration. The client then opens a Citrix ICA network connection directly to the Citrix XenApp server to obtain the published resource.

When the user accesses this process through a FirePass Portal Access Web Application favorite, the process must be modified to pass network connections through the FirePass controller. When the portal sends an ICA configuration file to the FirePass controller (any file with an HTTP Content-Type header of application/x-ica), the reverse proxy engine makes several changes. First, the ICA file is temporarily stored on the FirePass controller, and the client is instead sent a web page with an F5 Networks ActiveX control. This control, the InstallerControl, downloads and installs (if needed) other F5 Networks ActiveX controls in order to open a Static Application Tunnel between the client and the FirePass controller for the ICA connection.

The Static Application Tunnel is created automatically, without user intervention.

Important: The Static Application Tunnel feature supports Windows clients, while the Static Java Application Tunnel feature supports Windows, Mac OS X, and Linux clients. F5 Networks Product Development is tracking an enhancement request for FirePass to open a Static Java Application Tunnel if it cannot open the ActiveX-based Static Application Tunnel when a user launches a Citrix Application through a Portal Access Web Application favorite. For more information, refer to K9232: FirePass does not launch Static Java Application Tunnels for access to Citrix Web Interfaces through Portal Access.

Alternatively, if the Citrix Java ICA client is used, the reverse proxy engine patches the client's Java byte code directly to enable the ICA network connections.

In addition to the ActiveX controls, the returned page also contains a link to the location on the FirePass controller with the ICA file. The ICA file is modified to work with the Application Tunnel. The IP address of the Citrix server in the Address parameter is changed to the loopback IP address created for the Application Tunnel. If the Address parameter instead contains a name, (typically a Fully Qualified Domain Name (FQDN)), the Application Tunnel will patch the client's host file to map the name to the loopback IP address of the Application Tunnel (the standard mechanism with an Application Tunnel).

Note: ICA files are not cached on the FirePass across FirePass user sessions. ICA files are deleted once the user logs out of FirePass.

Once the client requests the patched ICA file, the browser invokes the Citrix client that has been associated with the content type of application/x-ica. This client is the Citrix Web client, which is listed in Windows-based operating systems as the Citrix ICA Client Engine, normally the wfica32.exe helper program.
