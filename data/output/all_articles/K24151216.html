K24151216: Thick vs Thin VMware Virtual Hard Drive provisioning - (BIG-IQ VE)

Type
Support Solution
Published
2021-04-27
Updated
2025-04-01
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K24151216

Description

VMware Virtual Hard Drive provisioning types:
  • Thick Provisioning - All the space is allocated to the virtual hard drive at creation time.
  • Thin Provisioning - Space is allocated on demand as the space is used.

Environment

  • BIG-IQ Centralized Management (Virtual Edition)
  • VMware ESXi

Cause
None

Recommended Actions

BIG-IQ virtual disks are advised to be deployed as Thick provisioning (allocated up front).

Additional Information

Note: Increasing the disk size beyond 1.9 TB may render the system unbootable. F5 recommends the extended disk space should not exceed 1.9 TB.
