K7233: The BIG-IP ASM UCS no longer contains Forensic and Events data

Issue

BIG-IP ASM 9.2.0 through 9.2.5, the system archives both the Statistics data (Events and Attacks) and the Forensics data in a UCS archive.
 
In BIG-IP ASM 9.3.0 and 9.4.0, the BIG-IP ASM UCS archive no longer contains the Forensics data.
 
In BIG-IP ASM 9.4.5, the UCS archive no longer contains the Events data.
