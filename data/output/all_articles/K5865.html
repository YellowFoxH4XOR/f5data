K5865: BIG-IP does not send an SSL close alert when unclean shutdown is disabled

Known Issue

This is the result of a known issue. Typically, when SSL unclean shutdown is disabled, BIG-IP closes out the SSL layer connection using close alerts before closing the TCP connection.

If a connection uses HTTP keep-alives, SSL unclean shutdown is disabled on BIG-IP. and the client sends an SSL close alert before the node is finished sending data, BIG-IP may not send an SSL close alert. This can cause the client to delay closing the connection.

F5 Networks Product Development tracked this issue as CR55093 and CR55094, and it was fixed in BIG-IP version 4.5.14. For information about upgrading, refer to the BIG-IP Release Notes.
