This security advisory describes multiple BIND 9 denial of service vulnerabilities. For information about this advisory, refer to the Internet Systems Consortium website at the following location:

http://www.isc.org/sw/bind/

F5 Product Development is tracking this issue as ID 314714 (formerly CR68956) and ID 264730 (formerly CR68957) for the BIG-IP 9.x software branches.

This issue was fixed in BIG-IP 9.1.3, 9.2.5, 9.3.0, and 9.4.1. For information about upgrading, refer to the BIG-IP Release Notes.

F5 Product Development also tracked this issue as ID 335877 (formerly CR68958) for the Enterprise Manager software branch, and it was fixed in Enterprise Manager 1.2. For information about upgrading, refer to the Enterprise Manager Release Notes.

Workaround

F5 has made a version-specific patch available that addresses these CRs. You can download the BIND-VU697164-VU915404 patch from the F5 Downloads site for your specific software version.

For information about downloading software, refer to K167: Downloading software from F5.
