Description

You would like to find out if K14206 is applicable to BIG-IQ version 8.0.0.

Environment

  • BIG-IQ v8.0.0 and later
  • Apache 2.4.6

Cause

The issue is based on Apache version. BIG-IQ is currently running Apache server version 2.4.6, which defaults the FileETag Directive to FileETag MTime Size.
Hence you do not need to apply procedures in K14206 for BIG-IQ 8.0.0 and later.

Recommended Actions

None.
