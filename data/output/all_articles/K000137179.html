Description

WebSocket connection is not working on BIG-IP Virtual Server.

Packet trace shows connection is stalling on WebSocket data, after handshake completed.

Environment

  • Virtual Server
  • Websocket profile

Cause

This can happen if the Virtual Server has a websecurity profile applied, but no ASM Security Policy applied via iRules or Traffic Policy.

The websecurity profile is a hidden profile that is automatically applied to a virtual server when a Security Policy is applied.
The websecurity profile is not required to use the Websocket profile, from a purely LTM perspective.

Recommended Actions

Either assign an ASM Security Policy to the Virtual Server, or remove the websecurity profile:

tmsh modify ltm virtual <virtual-server> profiles delete { websecurity }

Note: Attaching or removing the websecurity profile from a virtual server cannot be done from the GUI.
