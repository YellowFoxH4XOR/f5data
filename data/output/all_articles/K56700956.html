Known Issue

The BIG-IP system may fail to forward MAP (also referred to as MAP-E) tunneling traffic.

This issue occurs when the following conditions are met:

  • A MAP tunnel profile is configured with either of the following settings:

    • The Embedded Address Bits Length value is set to 0 and the IPv4 Prefix value is set to greater than 0.
    • The combined values of the IPv6 Prefix and the Embedded Address Bits Length settings are greater than 48 bits.

Impact

The BIG-IP system fails to pass the MAP tunneling traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Packet captures indicate that the BIG-IP system fails to pass the MAP-E tunneling traffic.
