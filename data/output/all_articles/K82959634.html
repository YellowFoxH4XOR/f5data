Description

Device trust certificates such as dtdi.crt or dtca.crt are valid 10 years by default. If any of the certificates are expired, failover will still work. Failover traffic is based on UDP traffic and does not use any of the device trust certificates.

Environment

  • BIG-IP HA system
  • Encrypted failover heartbeat traffic (failover.secure DB key) is not in use

Note: you can check if secure failover is in use by executing a command:  tmsh list sys db failover.secure

 

Cause

This is by design.
 

Recommended Actions

None
