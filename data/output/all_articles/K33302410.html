K33302410: Microsoft Edge IE mode cannot display access policy logon page BIG-IP APM

Type
Support Solution
Published
2022-10-25
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 17.0.0
Source

Description

You are experiencing that the logon page is not visible (blank page) as you try to access your access policy using Microsoft Edge IE mode.

Environment

Relevant environmental factors specific to the topic

  • APM provisioned
  • Access policy working on other browsers
  • You are using Microsoft Edge IE mode

Cause

Microsoft Edge IE mode is not supported.

Recommended Actions

None
