Description
By default, the BIG-IQ user interface allows you to use a large range of SSL ciphers for SSL clients to connect to the user interface. If you require a more specific and secure list of SSL ciphers, you can modify the cipher list that the BIG-IQ user interface uses. This article describes how to check and modify the list of SSL ciphers that are supported by the BIG-IQ user interface.

Environment

  • BIG-IQ
  • The BIG-IQ user interface (webd service on BIG-IQ) uses openssl.

Cause

None

Recommended Actions

Impact of procedure: It's possible that the BIG-IQ user interface may become inaccessible if the client and server are not able to agree on a cipher. F5 recommends testing configuration changes in an appropriate environment before deploying to production.

  1. To check the openssl version, enter the following command:

    openssl version

  2. To display the available cipher suites, enter the following command:

    openssl ciphers

  3. To verify the cipher suites, enter the following syntax:

    openssl ciphers <cipher string>

  4. Back up a copy of the /etc/webd/webd.conf file before editing, by typing the following command:

    cp -p /etc/webd/webd.conf /var/tmp/webd.conf.backup

  5. Edit the /etc/webd/webd.conf file using a text editor of your choice.
  6. To modify the SSL ciphers, locate the line that begins with ssl_ciphers in the /etc/webd/webd.conf file. For example:

    ssl_ciphers ALL:!ADH:!EXPORT:!eNULL:!MD5:!DES:RC4+RSA:+HIGH:+MEDIUM:+LOW:+SSLv2;

  7. Edit this line to a preferred list of SSL ciphers.
  8. Save the changes and exit the text editor.
  9. To restart the webd process, type the following command:

    tmsh restart /sys service webd
