Known Issue

Node connection limits may not affect pool member status.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP nodes are configured with connection limits.
  • All pool members of a pool consist of connection limited nodes.
  • The node level connection limit is reached across all nodes of the pool.
  • You view the pool and node states using the Traffic Management Shell (tmsh).

Impact

The pool member status does not change to reflect the state of the connection limit exceeded nodes (Unavailable).

Note: This is a cosmetic issue and does not impact the handling of connections to the pool members.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When comparing the node state and the pool member state, the node state based on the node level connection limit exceeded (marked as Unavailable), is not reflected in the pool member state (pool members are still marked as Available).

    Note: For example, when the node level connection limit is reached, the node state changes from Available to Unavailable. The state of the node as a pool member remains in the Available state.
