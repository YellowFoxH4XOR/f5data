Description

How to enable empty_header_value_allowed asm system variable

Environment

ASM

System variable

Cause

Some headers are expected to legitimately contain empty values.

Recommended Actions

Following command to add the headers for empty value

# /usr/share/ts/bin/add_del_internal add empty_header_value_allowed header1,header2

# bigstart restart asm

Note: Please do the steps during maintenance window. Restarting ASM will cause a failover if done on the Active BIG-IP. If on done on a Standalone BIG-IP traffic will be disrupted while ASM restarts.

After the above command is executed empty_header_value_allowed will be appear under Security ›› Options : Application Security : Advanced Configuration : System Variables

None.
