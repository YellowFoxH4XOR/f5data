Description

ASM may mask Attack signature "Detected Keyword" in request log even though detected string is not part of sensitive header/parameter

Example:
Violation Details
Attack signature detected [3]
Detected Keyword    **** (sensitive data masked)
Attack Signature    ID200104770
                    Name JSP Expression Language Expression Injection (3) (Parameter)
Context    HTTP Request Body Unparsed Payload


Environment

  • BIG-IP ASM
  • Request triggering attack signature

Cause

ID638863

Recommended Actions

Workaround is to disable "Mask Value in Logs" for "Authorization" header under Security  ››  Application Security : Headers : HTTP Headers  ››  Edit Header

None
