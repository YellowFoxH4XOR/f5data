K23341824: [F5OS-A] New R5000 appliance won't save management IP

Type
Support Solution
Published
2022-05-03
Updated
2023-04-24
Applies to
  • rSeries Platforms
  • F5OS
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K23341824

Description

When running the initial appliance setup wizard, commit is failing with the following error message:

 {
 "ietf-restconf:errors": {
"error": [
{
"error-type": "application","error-tag": "access-denied","error-path": "/openconfig-system:system/f5-mgmt-ip:mgmt-ip/config/ipv4/system/address","error-message": "access denied"
}
]
}
}

Environment

  • F5OS-A
  • rSeries
  • Initial Configuration
  • Appliance Setup Wizard
    ​​​

Cause

  • You are attempting to commit change using root credentials

Recommended Actions

You run the Setup wizard using the root account, but will need the ADMIN user credentials to commit the configuration changes that you make using the Setup wizard.
