Description

OpenShift install is observed to take a long time when tailing the /var/log/openshift.log file or reviewing show cluster.

In some cases, installation fails when an ansible-playbook invocation times out, with a message similar to the following:

2025-04-22T11:41:01.237750-08:00 - Command "/usr/bin/ansible-playbook -vv --flush-cache -i /tmp/omd/etc_ansible_cluster_install /usr/share/ansible/openshift-ansible/playbooks/prerequisites.yml /usr/share/ansible/openshift-ansible/playbooks/openshift-checks/pre-install.yml /usr/share/ansible/openshift-ansible/playbooks/openshift-node/bootstrap.yml /usr/share/ansible/openshift-ansible/playbooks/openshift-etcd/config.yml /usr/share/ansible/openshift-ansible/playbooks/openshift-master/config.yml /usr/share/ansible/openshift-ansible/playbooks/openshift-master/additional_config.yml /usr/share/ansible/openshift-ansible/playbooks/openshift-node/join.yml /usr/share/ansible/openshift-ansible/playbooks/openshift-hosted/config.yml /usr/share/ansible/openshift-ansible/playbooks/openshift-service-catalog/config.yml" timed out after 5400 seconds

Environment

  • VELOS system controller
  • OpenShift install or rebuild

Cause

ID1928841

Remote authentication is configured but is inaccessible or slow to respond.

OpenShift rebuild is dependent on functional remote auth, since it uses ansible (ssh). Any delays or latency in remote auth will make the ansible playbooks that install the cluster take longer. In some cases, an ansible-playbook invocation might time out (typically after running for 90 minutes).

Recommended Actions

As a workaround for this issue, temporarily disable remote auth while performing an OpenShift rebuild.

This can be done part-way through a rebuild. However, if a playbook already timed out and does not appear to have been re-tried, a new rebuild may need to be triggered via:

touch /var/omd/CLUSTER_REINSTALL

Additional Information

OpenShift installation may fail due to other reasons. If remote auth is not configured but this problem still occurs, further troubleshooting is required.
