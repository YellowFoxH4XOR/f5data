Description
After adding a member in the Sync/Sync-Failover Device Group, the Sync Status shows "Awaiting Initial Sync" even after running a Configsync.

Environment

  • BIG-IP LTM
  • DSC / High-Availability

Cause
The VLANs of the self-IP used for the Configsync are not matching between the Device Group members.

For example, In the following BIG-IP unit 01, the VLAN of the ConfigSync self-IP is vlan-internal:

tmsh show /cm device >
------------------------------------------------------------------------------------------------
CentMgmt::Device: /Common/bigip01.local
------------------------------------------------------------------------------------------------
Hostname                       bigip01.local
Mgmt Ip                        192.168.35.74
Configsync Ip                  172.17.31.67 <==
Mirroring IP                   10.255.255.1
Mirroring Secondary IP         ::
Failover Multicast IP          ::
Failover Unicast IP(s)         172.17.31.67, management-ip
Device HA State                unknown
Device HA Load Capacity        0

tmsh list /net self >
net self /Common/selfip-internal {
    address 172.17.31.67/27
    allow-service {
        default
    }
    app-service none
    description none
    floating disabled
    fw-enforced-policy none
    fw-rules none
    fw-staged-policy none
    inherited-traffic-group false
    partition Common
    traffic-group /Common/traffic-group-local-only
    unit 0
    vlan /Common/vlan-internal <==
}

While in the BIG-IP unit 02, the VLAN of the ConfigSync self-IP is vlan-ha:

tmsh show /cm device >
------------------------------------------------------------------------------------------------

------------------------------------------------------------------------------------------------
Hostname                       bigip02.local

Mirroring IP                   10.255.255.1
Mirroring Secondary IP         ::
Failover Multicast IP          ::
Failover Unicast IP(s)         172.17.31.68, management-ip
Device HA State                unknown
Device HA Load Capacity        0

tmsh list /net self >
net self /Common/selfip-internal {
    address 172.17.31.68/27
    allow-service {
        default
    }
    app-service none
    description none
    floating disabled
    fw-enforced-policy none
    fw-rules none

Recommended Actions

  1. Use a common VLAN for the Configsync self-IP. 
         a. In the Configuration Utility (GUI), go to "Network  ››  Self IPs"
         b. Click on the name of the self-IP used for the Configsync.
         c. Change the entry of the "VLAN / Tunnel" field to the correct value.
  2. Initiate a Configsync under "Device Management  ››  Overview"
