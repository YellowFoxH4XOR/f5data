Known Issue

Description

Some clients may fail to connect to a FirePass network access tunnel.

This issue occurs when all of the following conditions are met:

  • The client is using a Firefox version 9 or later browser
  • The user is establishing a network access connection
  • The Minimize window after successfully connecting Network Access client option is selected

Impact

Affected users are unable to establish a network access connection.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Firefox browser appears to hang
  • After about one minute, the browser displays a message that appears similar to the following example:

    The F5 Networks Firepass Host Plugin has crashed.

Workaround

To work around this issue, you can disable the Minimize window after successfully connecting Network Access client option. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the FirePass Administrative Console.
  2. Click Network Access.
  3. Select the Resource Group you want to edit from the Resource Group: drop-down menu.
  4. Click the Customization tab .
  5. Clear the checkbox for the Minimize window after successfully connecting Network Access client option.
