K000137262: Disable/Enable interfaces directly in rSeries Tenant is not allowed

Type
Support Solution
Published
2024-03-11
Updated
2024-03-11
Applies to
  • F5OS
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000137262

Description

You want to Disable/Enable interfaces directly in a BIG-IP Tenant.

Environment

  • rSeries
  • BIGIP Tenant

Cause

Modifications to BIG-IP tenant's read-only network interfaces are blocked in the Configuration Utility but not in TMSH.

This discrepancy, where TMSH permits changes that the GUI does not, is tracked under bug IDs BugID1222649 and BugID1229309.

Directly disabling/enabling interfaces in the Tenant is not allowed and should be avoided.

Recommended Actions

The network interfaces are in read-only state. Any interface modification should only be done at the host (rSeries) level.

Additional Information

This behavior does not occur in VELOS platforms nor vCMP systems, the VM, whether it is F5OS tenant or vGuest - should not be allowed to disable the internal network connectivity.
