K000149961: SSRF Protection Block After F5 Update

Type
Support Solution
Published
2025-05-28
Updated
2025-05-28
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.0, 17.1.X, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000149961

Description

SSRF violation blocking events triggered after upgrade to 17.x version

 

Environment

  • BIGIP ASM
  • SSRF List
  • Upgrade to v17

 

Cause

New behavior introduced in v17.

After upgrading or installing v17.0.0 or later you observe that the SSRF hosts within an ASM policy is pre-populated with several entries

 

Recommended Actions

Review the SSRF Hosts entries and remove any which match the impacted traffic:

Security ›› Application Security : Security Policies : Policies List

Select the policy affected then go to Advanced Protection >> SSRF Protection

On the SSRF Hosts there will be a list with networks that may be affected

 

Additional Information

K000141082: ASM SSRF is populated with default entries starting in v17.0.0
