Known Issue

This is the result of a known issue. When TMM starts, the VIPRION system may log High-Speed Bridge (HSB) error messages to the /var/log/ltm file that appear similar to the following example:

tmm4[9379]: 01010025:2: Device error: hsb internal error QBI_BIST_ERRS address 0x00000cc4 status 0x10000000

F5 Product Development is tracking this issue as ID 315101 (formerly CR127544).

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.
