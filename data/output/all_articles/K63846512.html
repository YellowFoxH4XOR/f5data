K63846512: F5fpclients.msi digital signature of the object did not verify

Type
Support Solution
Published
2023-09-21
Updated
2023-09-21
Applies to
  • BIG-IP
  • APM Clients
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K63846512

Description

Installing the Edge Client by using SCCM or similar fails because the F5fpclients.msi digital signature of the object did not verify.
The Installation system may return :

Edge Client installation Installation Failed, /f5fpclients.msi is not trusted

Environment

  • Automated Deployment of the Edge Client to Windows.

Cause

Running BIGIPEdgeClient.exe /x  to extract the contents including the  F5fpclients.msi will damage the digital signature

Recommended Actions

  1. There is no way to prevent this or to resign.
  2. You must enable the SCCM to explicitly trust the F5fpclients.msi  file.
