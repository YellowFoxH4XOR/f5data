Known Issue

Remote desktop VMWare View sessions may fail to connect.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP APM system with a VMware View remote desktop application access profile.
  • You attempt to establish a session to the remote desktop using an HTML5 client.
  • You have configured the destination VMware View VCS (vCloud Suite) server to return the DNS name of the desktop.

Impact

The connection fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H496213 on the Diagnostics > Identified > Medium screen.
  • When you attempt to connect to the VMware View remote desktop you receive a server error message.
  • The system logs a message to the /var/log/apm file that appears similar to the following example:

    crit vdi[5886]: 01490000: {16.S} An exception is thrown: Failed to resolve hostname '<Desktop DNS name returned by VCS>': Name or service not known

  • The system logs messages to the /var/log/ltm file that appear similar to the following example:

    err tmm[12662]: 01220001:3: TCL error: /<partition>/<desktop profile name> <HTTP_REQUEST> - bad IP address format (line 18) invoked from within "node $tmm_<desktop profile name>_host_port"
    err tmm[12662]: 01230140:3: RST sent from <virtual server ip address:port> to <client ip address:port>, [0x17727da:1290] iRule execution error

  • Modifying the VMWare View VCS configuration to return the IP address of the remote desktop allows users to successfully access the remote desktop.

Resolution

Status

Workaround

To work around this issue, you can configure the VMware View VCS configuration to return desktop IP addresses instead of returning the desktop DNS name.

Impact of workaround: Performing this workaround should not have a negative impact on your system.
