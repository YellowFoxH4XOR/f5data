Topic

You should consider using this procedure under the following condition:

  • You want to view the Message Routing Framework (MRF) Diameter statistics using the TMOS Shell (tmsh).

Description

With more Diameter protocol specific statistics collected per-pool-member (Diameter peer), you can view the detailed statistics using tmsh.

The new commands in the following table are added to tmsh.

tmsh commandDescription
show ltm message-routing diameter transport-config <profile name> [detail]Displays the overall connection, packet, byte, and message counts for all current and previous connections created by the specific transport configuration profile. When you use the detail option, the output includes the statistics tables for all Diameter-related profiles attached to the transport configuration profile.
show ltm message-routing diameter pmbr-statsDisplays the profile statistics for all MRF Diameter profiles attached to virtual servers or transport configuration profiles that are used by current and existing connections for each pool member.

The following tmsh command syntaxes are enhanced to include new statistics counters:

  • show ltm message-routing diameter profile session <diameter session profile name>
  • show ltm message-routing diameter profile router <diameter router profile name>
  • show ltm virtual <vs name> detail
  • show ltm pool <pool name> detail

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have the necessary MRF Diameter configuration running on the BIG-IP system.
  • You have administrative access to tmsh.

Procedures

  • Viewing the statistics per pool member (Diameter peer)
  • Viewing the statistics per transport config profile
  • Viewing the statistics per session profile
  • Viewing the statistics per router profile

Viewing the statistics per pool member (Diameter peer)

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh.
  2. Enter the following command to view stats from a per-peer perspective:

    show ltm message-routing diameter pmbr-stats

Viewing the statistics per transport configuration profile

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh.
  2. Enter the following command syntax to view stats from a specific transport configuration profile:

    show ltm message-routing diameter transport-config <profile name> detail

    For example, to view stats from the myexample transport configuration profile, enter the following command:

    show ltm message-routing diameter transport-config myexample detail

Viewing the stats per session profile

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh.
  2. Enter the following command syntax to view stats from a specific Diameter session profile:

    show ltm message-routing diameter profile session <profile name>

    For example, to view stats from the myexamplesession session profile enter the following command:

    show ltm message-routing diameter profile session myexamplesession

Viewing the statistics per router profile

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh.
  2. Enter the following command syntax to view stats from a specific Diameter router profile:

    show ltm message-routing diameter profile router <profile name>

    For example, to view stats from the myexampleroute router profile, enter the following command:

    show ltm message-routing diameter profile router myexampleroute
