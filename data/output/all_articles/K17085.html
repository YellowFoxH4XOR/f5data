Known Issue

TCP window scaling is not applied when SYN cookie protection is activated.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system has a virtual server configured with a TCP profile.
  • The virtual server has SYN cookie protection activated.

    Note: SYN cookie protection is activated by default for TCP and FastL4 profiles.

  • The SYN Check Activation Threshold has been reached.

Impact

Client connections experience latency due to the inefficiency of the data transfer.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Client connections experience additional latency when SYN cookie protection is activated.
