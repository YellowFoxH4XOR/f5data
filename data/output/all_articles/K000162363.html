K000162363: Consolidated Dashboard Monitoring for BIG-IP AWAF, Behavioral DoS, and BIG-IP LTM

Description

Monitoring requirements span multiple virtual servers and Application Protection profiles, but BIG-IP AWAF, Behavioral DoS, and BIG-IP LTM dashboards have different aggregation scopes. DoS Analysis supports consolidated views, while Behavioral DoS and BIG-IP LTM dashboards are scoped to individually selected virtual servers.

Environment

  • Product: BIG-IP AWAF
  • Multiple virtual servers configured for monitoring
  • Multiple Application Protection profiles configured
  • Relevant interfaces:
    • Security > Reporting > DoS > Analysis
    • Security > Reporting > DoS > Dashboard
    • Statistics > Dashboard > Behavioral DoS
    • Statistics > Dashboard for BIG-IP LTM statistics

Cause

The dashboards have different design and aggregation capabilities:

  • DoS Analysis supports consolidated monitoring across multiple virtual servers and Application Protection profiles.
  • Behavioral DoS is designed for real-time monitoring of one virtual server at a time.
  • BIG-IP LTM statistics display metrics for individually selected virtual servers and do not aggregate multiple virtual servers in a single chart.

Answer/Recommended Actions

  1. For consolidated monitoring of multiple virtual servers and Application Protection profiles, open either:

    • Security > Reporting > DoS > Analysis
    • Security > Reporting > DoS > Dashboard

  2. Use the Dimensions pane in the DoS Analysis view to:

    • Expand the available dimensions.
    • Select one or more virtual servers.
    • Select one or more applications or Application Protection profiles.
    • Filter or compare selected entities.

  3. For real-time Behavioral DoS monitoring, open:

    • Statistics > Dashboard > Behavioral DoS

  4. In the Behavioral DoS dashboard, select each virtual server individually to review its Behavioral DoS metrics and attack status.

  5. For BIG-IP LTM monitoring, open the below Dashboard, and then select an individual virtual server to review its LTM metrics:

    • Statistics > Dashboard

  6. For historical or comparative DoS analysis across multiple objects, use Security > Reporting > DoS > Analysis instead of the Behavioral DoS dashboard.

  7. In large environments, regularly review system resource usage when monitoring many virtual servers and applications.

  8. For advanced reporting across multiple BIG-IP devices, consider using BIG-IQ Centralized Management. BIG-IQ-specific requirements should be evaluated separately.

Additional Information

  • The DoS Analysis view provides an aggregated view by default; additional configuration is not required to display data across monitored virtual servers and Application Protection profiles.
  • The Dimensions pane can narrow the view to selected objects or compare multiple entities.
  • Behavioral DoS dashboard data is real-time and persists for 24 hours. Historical data beyond this period is not available in that view.
  • The Behavioral DoS dashboard is designed to provide per-virtual-server details rather than a consolidated view across multiple virtual servers.
  • The BIG-IP LTM statistics dashboard is intended for individually selected virtual-server metrics and does not provide multi-virtual-server aggregation in a single chart.
