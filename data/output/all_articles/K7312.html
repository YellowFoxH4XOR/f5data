Topic

The BIG-IP system uses the following two network connection entry points:

  • Traffic Management Microkernel (TMM) switch interfaces
  • Management interface (also called the management port)

Either the TMM switch interfaces or the management interface can provide administrative access to the BIG-IP system. However, F5 recommends that you use the management interface.

Description

The TMM switch ports are the interfaces that the BIG-IP system uses to send and receive load-balanced traffic.

The system uses the management interface to perform system management functions. The management interface is intended for administrative traffic and cannot be used for load-balanced traffic. Additionally, since there are limited access controls that can be applied to the management interface, F5 recommends that you limit network access through the management interface to trusted traffic. For security reasons, the management interface should only be connected to a secure, management-only network, such as one that uses an RFC1918 private IP address space. If you do not have a trusted and secure management network, F5 recommends that you do not use the management interface and that you grant administrative access through the TMM switch interfaces or the local serial console.

Note: For more information about management interface administrative traffic, refer to K13284: Overview of management interface routing.

Administrative HTTPS and SSH traffic to the management interface can be restricted to specific IP ranges. For information about how to restrict access to the Configuration utility by source IP address, refer to K13309: Restricting access to the Configuration utility by source IP address (11.x - 17.x).

For information about how to restrict access to SSH by source IP address, refer to K5380: Specifying allowable IP ranges for SSH access.

In BIG-IP 14.1.0 and later, you can restrict access to the management interface using network firewall rules.  For more information, refer to K46122561: Restricting access to the management port using network firewall rules.

Changing the IP address of the MGMT interface after the initial deployment of the BIG-IP system

After you initially deploy the BIG-IP system, situations may arise in which you are required to change the IP address of the management interface. Consider the following when planning to change the management IP address:

  • If the BIG-IP system is in a device group and uses only the management interface for network failover, changing the management IP address likely results in a disruption of network failover traffic that can affect load balanced traffic if an unintended active-active redundancy state occurs.
  • The BIG-IP system may use the management interface to connect to DNS, NTP, SNMP, SMTP, SYSLOG, or LDAP servers. If this is the case, you should determine whether the BIG-IP system may be adversely affected if it fails to connect to these servers after the IP address is changed (for example, due to an access list). 
  • The BIG-IP system may be configured to accept incoming administrative connections to the management interface and TMM interface. To view what services are listening, enter one of the following commands at the BIG-IP command line:

    netstat -ltu
    or
    ss -ltu

For the previously listed reasons, F5 recommends that you change the IP address of the management interface during a maintenance window. If you require further information or assistance with the change, contact F5 Support.

Configuring the management interface

Impact of procedure: Review the previous section in this article for impact of changing management IP address. Additionally, when you are connected through the management interface, changing the management IP address disconnects you from the BIG-IP system.

  1. Log in to the Configuration utility.
  2. Go to System > Platform.
  3. Under General Properties, enter the appropriate settings for the management interface.
  4. Select Update.

To configure the management IP address using other methods, refer to K15040: Configuring and displaying the management IP address for the BIG-IP system.
