K000137708: After upgrade/reboot, Error message: Remote authentication server unreachable; local authentication failed.

Description

After upgraded/rebooted, remote authentication for GUI is failing with 

Remote authentication server unreachable; local authentication failed.

Log in to CLI fails.

The BIG-IP has multiple self IPs on a vlan and to accessing authentication server , it is using other self IP than it used to be before upgrade/reboot.

 

Environment

  • BIG-IP
  • Authentication for BIG-IP
  • Multiple Self IP on a vlan
 

Cause

  • the route is not set properly for the authenticatio nserver.


Recommended Actions

We recommend to use management IP for remote authentication as it is crucial to have GUI/CLI access when TMM is down.

However in some reasons you need to use self IP, then need to set route for it properly.
On CLI, bash mode, run below command finding the gateway and vlan and self ip which should initiate remote authentication

ip route add <authentication_server ip>/32 via <gateway> dev <vlan_name> src <self_ip>
