Known Issue

BIG-IP APM custom variables may contain extraneous characters.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access policy populates a custom Variable Assign value using a Custom Expression that includes the mcget -secure option.

    Example Custom Variable = Custom Expression:

    session.custom.pass = mcget -secure {session.logon.last.password}

  • The custom Variable Assign value is used in a subsequent function, or displayed by the Access Policy.

Impact

The value of the custom Variable Assign is corrupt.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Functions that depend on the custom Variable Assign value are unable to retrieve a correct value.
  • When you display the value of the custom Variable Assign, extraneous characters are included with the value.

    For example:

    The Custom Variable "session.custom.pass" derived by the Custom Expression "mcget -secure {session.logon.last.password}".
    The actual value returned by mcget -secure {session.logon.last.password} is "testpassword".
    The value displayed by the custom Variable Assign %{session.custom.pass} is "testpassword_=[8=[<134>F=["
