Known Issue

Information on the SNMP object sysIfxStat is not available on BIG-IP 2000/4000 platforms.

This issue occurs when you attempt to query the affected platform to retrieve information on the sysIfxStat SNMP object.

For example, you could type the following snmpwalk command on the affected platform:

snmpwalk -v 2c -c public localhost sysIfxStat

Impact

You cannot query the sysIfxStat SNMP object.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to use the snmpwalk command to query the sysIfxStat object, you observe output similar to the following example:

    F5-BIGIP-SYSTEM-MIB::sysIfxStatResetStats.0 = INTEGER: 0
    F5-BIGIP-SYSTEM-MIB::sysIfxStatNumber.0 = INTEGER: 0
