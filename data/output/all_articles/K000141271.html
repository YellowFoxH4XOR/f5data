Description

This article provides steps for data collection that are required in order to troubleshoot issues with BIG-IP APM and Virtual Desktop Infrastructure (VDI) such as Microsoft Remote Desktop Protocol, VMware View or Citrix applications.

Environment

BIG-IP APM configured to provide access to VDI resources.

Recommended Actions

When experiencing trouble with VDI resources, use the following procedures to gather data for troubleshooting:

  1. Enable Access and VDI debug logging on BIG-IP system:
    • Log in to the Configuration utility and navigate to Access > Overview > Event Logs > Settings.
    • Click Create.
    • Click General Information.
    • Type a name for the new APM Log setting.
    • Select the Enable Access System Logs check box.
    • Click Access System Logs.
    • For Access Policy, select Debug.
    • For VDI, select Debug.
    • Click Access Profiles.
    • In the Available list, select the check box for the affected access profile for which you want to enable debug logging and move it to the Selected list.
    • Click OK.

  2. Collect a Decrypted Packet capture while reproducing the issue:
    • Log in to BIG-IP Advanced shell (bash) with root credentials.
    • Please enable the tcpdump.sslprovider db key so we can collect a decrypted pcap
       # tmsh modify sys db tcpdump.sslprovider value enable
    • Capture the client traffic with tcpdump by entering the following command syntax:
      tcpdump -i 0.0:nnnp --f5 ssl -v dns or host <CLIENT_IP> or host <VDI_SERVER_IP> -w /var/tmp/vdi-capture.pcap
    • Hit Control-C when the issue has been reproduced to stop the capture.

  3. Disabling VDI debug logging:
    • Open the Configuration utility and navigate to Access > Profiles / Policies > Access Profiles (Per-Session Policies).
    • Click on the policy that was previously modified.
    • Click on the Log tab.
    • Remove the debug log setting from the Selected profile list.

  4.  Please disable the tcpdump.sslprovider  db key so we can collect a decrypted pcap
    # tmsh modify sys db tcpdump.sslprovider value disable
  5. Gathering the diagnostic data
    • Generate a tarball of the logs by typing the following command:
      tar zcvf /var/tmp/vdi-logs.tgz /var/log/{ltm,apm}*
    • Collect diagnostic data using the qkview utility:
      Follow the directions from K12878 .
