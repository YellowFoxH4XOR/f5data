Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator fails to parse web server content containing Edge Side Include (ESI) tags. When the BIG-IP WebAccelerator attempts to process ESI tags, the system logs error messages to the pvac.log file that appear similar to the following example:

[ TmPlugin.cxx:2100 serverHandler ] tm_vs_info_get failed (0)
[ TmPlugin.cxx:2106 serverHandler ] PV_PLUGIN_NOTIFY_ASYNC failure
[ TmPlugin.cxx:2281 error_on_esi ] ERROR for ESI! wa_context [0xa4714a8]

F5 Product Development tracked this issue as CR126497 and it was fixed in BIG-IP WebAccelerator 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

In addition, BIG-IP iHealth lists Heuristics H383277 and H382590 on the Diagnostics > Identified > High screen.

This issue was fixed in BIGIP-10.0.1-378.0-HF3 issued for BIG-IP 10.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
