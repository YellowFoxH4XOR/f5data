Topic

You should consider using these procedures under any of the following conditions:

  • You need to retrieve the serial number of your BIG-IQ 7000 hardware.
  • You need to retrieve the registration key for your BIG-IQ system.

Description

The serial number is located on the barcode sticker of the hardware platform, and it is also stored in the system configuration database. The registration key of the product is located in the license file.

The BIG-IQ 7000 hardware platform has a serial number format of f5-XXXX-XXXX while the BIG-IQ Virtual Edition (VE) uses a hexadecimal ID string. If you are using the BIG-IQ VE, you must use the BIG-IQ VE registration key rather than the serial number to open a support case if you encounter any issue where you require F5 Support assistance.

Important: You must have the serial number or the last seven digits of the registration key to open a service case with F5 Support. If you cannot provide either, your Support representative may be able to locate your system in the support entitlement database.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have administrative access to the BIG-IQ Advanced Shell (bash) or user interface.

Procedures

  • Display the serial number:
    • Display the serial number in the BIG-IQ user interface
    • Display the serial number using tmsh
    • Display the serial number with SNMP
  • Display the registration key:
    • Display the registration key in the BIG-IQ user interface
    • Display the registration key using tmsh
  • Additional procedures:
    • Locate the registration key on an unlicensed system
    • Request license information from F5 using the registration key

Display the serial number in the BIG-IQ user interface

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ system interface.
  2. Go to System > THIS DEVICE > General Properties.
  3. In the Properties tab, locate Serial Number.

    Note: A BIG-IQ VE may display N/A for the serial number. In either instance, use the registration key to open a support case for VE systems.

Display the serial number using tmsh

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  2. To display the serial number, enter the following command:

    show /sys hardware

    The Platform and System Information sections of the command output appear similar to the following example:

    Platform
      Name           BIG-IQ 7000
      BIOS Revision  OBJ-0482-xx Build: 2.06.214.0 05/02/2014
      Base MAC       00:11:22:33:11:22
      PVA Version    20

    System Information
      Type                       D110
      Chassis Serial             f5-abcd-1234
      Level 200/400 Part         200-0368-00 REV E
      Switchboard Serial         
      Switchboard Part Revision  
      Host Board Serial          pca0313z01f7
      Host Board Part Revision    

    The serial number format is f5-XXXX-XXXX. The serial number begins with F5, followed by a hyphen character ( - ), followed by four alphanumeric characters, followed by a hyphen, followed by four alphanumeric characters. For example, f5-abcd-1234.

Display the serial number with SNMP

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

You can obtain the device serial number by polling the following F5-BIGIP-SYSTEM-MIB OID sysGeneralChassisSerialNum or the numeric equivalent entry .1.3.6.1.4.1.3375.2.1.3.3.3.0 with the SNMP query command.

For example, using the snmpwalk command with the F5 MIB OID name, the command may appear similar to the following:

snmpwalk -v 2c -c public localhost sysGeneralChassisSerialNum

Example of the output of the serial number of the system may appear as follows:

F5-BIGIP-SYSTEM-MIB::sysGeneralChassisSerialNum.0 = STRING: f5-abcd-1234

Alternatively, using the snmpwalk command with the F5 MIB OID numeric value, the command may appear similar to the following:

snmpwalk -v 2c -c public localhost .1.3.6.1.4.1.3375.2.1.3.3.3.0

Example of the output of the serial number of the system may appear as follows:

F5-BIGIP-SYSTEM-MIB::sysGeneralChassisSerialNum.0 = STRING: f5-abcd-1234

Display the registration key in the BIG-IQ user interface

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ system interface using an account with Administrator role.
  2. Go to System > THIS DEVICE > Licensing.
  3. In the Base Registration Key field, locate the registration key.

Display the registration key using tmsh

To display the registration key from the BIG-IQ system using tmsh, perform the following procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Display the registration key and license information by entering the following command:

    show /sys license

    The command output appears similar to the following example:

    Sys::License
    Licensed Version         5.2.0
    Registration key         ABCDE-ABCDEF-ABC-ABCDEFG-ABCDEFG
    Licensed On              2017/04/26
    License Start Date       2017/04/25
    License End Date         2017/05/27
    Service Check Date       2017/04/26
    Platform ID              D110
    Appliance Serial Number  f5-abcd-1234

    Active Modules
      BIG-IQ, Basic, 7000 (ABCDEFG-ABCDEFG)
        BIG-IQ, AFM, 10 Devices, 7000
        BIG-IQ, ASM, 10 Devices, 7000
        BIG-IQ, 500 Cloud Nodes, 7000
        BIG-IQ, 20 Devices, 7000

Locate the registration key on an unlicensed system

If the license has not yet been activated on your BIG-IQ system, you can contact your F5 sales representative for assistance.

Request license information from F5 using the registration key

To request information about the current status of an F5 registration key, such as on which system a specific registration key has been activated, or what service contracts have been assigned, perform the following procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Open a browser session, and connect to the following site:

    https://secure.f5.com/validate/validate.jsp

  2. For Contact Email, enter your email address.
  3. For F5 Licenses / Serial Numbers, enter the base Registration Key.
  4. Select Submit Info Request.
  5. The F5 licensing server sends a license summary for the submitted registration key to the specified email address.
