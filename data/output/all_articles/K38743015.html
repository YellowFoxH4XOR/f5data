Known Issue

Interrupting a running qkview utility process may create orphan files.

This issue occurs when all of the following conditions are met:

  • You are running the qkview utility.
  • An external condition (such as Ctrl+C or kill) stops the qkview utility from completing.

Impact

The system does not remove the qkview temporary files upon exit.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • A forced exit of the qkview utility leaves temporary files, which were created by the qkview, in the /var/tmp directory.

Workaround

To work around this issue, you can manually delete temporary files stored in /var/tmp. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected system.
  2. To delete the files located in /var/tmp, type the following command:

    rm -f /var/tmp/*

    Note: You will see errors similar to the following example that you can safely ignore.

    rm: cannot remove `/var/tmp/<sub directory name>': Is a directory
