Description

During the upgrade procedure, if a configured virtual server with SIP persistence is not configured with the required profiles the BIG-IP will produce the below error and the configuration won't be able to load properly

  • 01070651:3: SIP persistence on virtual server /Common/SIP_VS requires a TCP/UDP/SCTP profile, SIP profile, and cannot be used with an FTP/HTTP profile.
Unexpected Error: Validating configuration process failed.

Environment

  • After upgrade from version 11.X to 12.X and later
  • Virtual Server configured with SIP persistence
 

Cause

A virtual server configured with the SIP persistence must be configured with the profiles  TCP/UDP/SCTP and SIP

 

Recommended Actions

  1. Before to proceed with the upgrade confirm that the virtual server is configured with the mentioned profiles TCP/UDP/SCTP and SIP

  2. If you already booted in the new version you have to manually modify the "bigip.conf" and add the profile in the VS

    ltm virtual /Common/sip_VS {
    destination /Common/10.x.x.x:x
    ip-protocol udp
    mask 255.255.255.255
    persist {
        /Common/sip {
            default yes
        }
    }
    pool /Common/sip_pool
    profiles {
        /Common/udp{ }           <<< ! 
        /Common/sip { }          <<< !
    }
    source 0.0.0.0/0
    source-address-translation {
        type automap
    }
    translate-address enabled
    translate-port enabled
}
