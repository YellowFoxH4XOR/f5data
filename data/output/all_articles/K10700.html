K10700: The reported CPU usage for the Host changed due to increased SSL polling

  • BIG-IP LTM: 10.0.1, 10.0.0

Issue

Starting in BIG-IP 10.x, TMM polls the SSL chips more frequently than in BIG-IP 9.x. This change was made to improve SSL performance. As a result, the TMM process sleeps less often during SSL processing, increasing Host CPU utilization and slightly increasing TMM CPU utilization. The increase in Host CPU utilization during SSL processing is cosmetic only; there is no negative impact on traffic management performance.

Note: For more information about TMM CPU usage, refer to K3242: Traffic Management Microkernel (TMM) CPU and RAM usage.
