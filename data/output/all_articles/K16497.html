Topic

Summary

BIG-IP APM 11.3.0 introduces support for basic features described in the Security Assertion Markup Language (SAML) 2.0 OASIS standard. Support for additional SAML 2.0 features is since added to the BIG-IP APM system to provide a comprehensive solution for Identity Provider (IdP) and service provider (SP) deployments.

Description

The BIG-IP APM system supports many of the SAML 2.0 Profiles, Bindings, and Protocols for IdP and SP deployments. The following section outlines the associated SAML elements supported by the BIG-IP APM system.

Note: The SAML artifact support is introduced in BIG-IP APM 11.6.0.

SAML Profiles

The following SAML 2.0 profile elements are supported by the BIG-IP APM system for SAML IdP and SP deployments:

  • Web Browser SSO Profile
    • HTTP Redirect and HTTP POST bindings are supported for sending (from SP) and receiving (to IdP) authentication requests.
    • Assertions can be transmitted from IdP to SP using either HTTP POST or artifact bindings only (HTTP Redirect binding is not supported).
    • Both IdP and SP initiated Web Browser SSO are supported.
  • Single Logout Profile (SLO)
    • Support is available for both SP and IdP for HTTP POST binding only (BIG-IP 11.4.0 and later).
  • Artifact Resolution Profile
    • BIG-IP APM as IdP - BIG-IP APM supports sending artifacts in place of assertions. The artifact could be sent to the SP with either HTTP Redirect or HTTP POST bindings. The BIG-IP APM system supports Artifact Resolution Protocol with SOAP binding used by the SP to resolve artifacts for assertions.

      Note: Artifacts are not supported in place of SLO, AuthnRequest, or ECP messages.

    • BIG-IP APM as SP - BIG-IP APM supports receiving artifacts in place of assertions and resolving such artifacts by way of the Artifact Resolution Protocol using SOAP bindings.

The following SAML 2.0 profiles are currently not supported for IdP and SP deployments with the BIG-IP APM system:

  • Identity Provider Discovery Profile
  • Assertion Query/Request Profile
  • Name Identifier Mapping Profile
  • SAML Attribute Profile

SAML Bindings

The following SAML bindings are supported by the BIG-IP APM system for IdP and SP deployments:

Note: SAML URI Binding is not supported for IdP and SP deployments.

  • SAML SOAP Binding
    • Supported for the Enhanced Client or Proxy (ECP) profile only when the BIG-IP APM system is deployed as an IdP with Office 365. Also supported for Artifact resolution protocol for both BIG-IP APM as an SP and/or as an IdP.
  • HTTP Redirect Binding
    • Supported for transmitting Authentication Requests from SP to IdP, and artifacts from IdP to SP. Enveloped signature is currently supported for HTTP Redirect binding.
  • HTTP POST Binding
    • Supported for sending (from IdP) and receiving (to SP) assertions and artifacts. HTTP POST binding is also supported by SLO protocol for both BIG-IP as SP and IdP (BIG-IP 11.4.0 and later).

SAML Protocols

The BIG-IP APM system supports the following SAML 2.0 protocols relating to the profiles listed previously:

  • Authentication Request Protocol
  • Artifact Resolution Protocol
  • Single Logout Protocol

The following SAML protocols are currently not supported with the BIG-IP APM system:

  • Assertion Query and Request Protocol
  • Name Identifier Management Protocol
  • Name Identifier Mapping Protocol
