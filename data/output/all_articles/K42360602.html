Issue

Error Message

notice chmand[<PID>]: 012a0027:5: <AOM_status_string>

In this error message, note the following:

  • <PID> is the process ID of the chmand process.
  • <AOM_status_string> is the status report from the BIG-IP Always-On Management (AOM) subsystem.

For example:

notice chmand[8484]: 012a0027:5: AOM SEL is full
notice chmand[8484]: 012a0027:5: AOM SEL is no longer full
notice chmand[8484]: 012a0027:5: LCD Health communication OK
notice chmand[8484]: 012a0027:5: Host to AOM communication now OK
notice chmand[8484]: 012a0027:5: Fan tray present
notice chmand[8484]: 012a0027:5: LCD present

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The AOM System Event Log (SEL) is full.
  • An alert condition previously reported has been cleared.

Impact

This is a notice level message with no impact except for the AOM SEL is full message, which may result in missing AOM logs.

Recommended Actions

If the AOM SEL is full, you can manually clear the log using the ipmiutil command. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure clears the AOM SEL. You should verify that the latest records have been logged in /var/log/sel before clearing the AOM SEL.

  1. Log in to the Advanced Shell (bash).
  2. To clear the AOM SEL, type the following command:

    ipmiutil sel -d
