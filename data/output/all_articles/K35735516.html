Description

Your device shuts down unexpectedly and you see the following log message in /var/log/ltm:

logger[<PID>]: shutting down for system shutdown on behalf of root

Environment

  • BIG-IP
  • Unexpected shutdown or reboot

Causes

  • The root user manually issued a reboot command.
  • A hypervisor initiates a shutdown of a BIG-IP VE instance.
  • The BIG-IP encounters a software anomaly that triggers the device to reboot. 
     

Recommended Actions

  • Review the hypervisor logs to see if the hypervisor initiated a shutdown of the BIG-IP VE instance.
  • Review the BIG-IP system logs for any anomalies, and the system folder /shared/core for any core files with a correlating time stamp at or just prior to the log message.
     

Additional Information

None
