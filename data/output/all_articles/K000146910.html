K000146910: Are there any size limits for Distributed Cloud DNS?

Type

Applies to

  • F5 Distributed Cloud DNS Management
Source

Description

I want to know if there are any size limits for F5® Distributed Cloud DNS?

Environment

  • F5® Distributed Cloud DNS (XC DNS)

Resolution/Answer

XC DNS has a standard limit of 10,000 resource record sets per hosted zone; however, users can contact Support to request the limit be increased.
