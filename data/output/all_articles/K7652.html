Known Issue

This is the result of a known issue. When a FastL4 virtual server is mirrored to a UDP virtual server on the peer BIG-IP LTM system, the TMM process can crash on the peer system. For example, if mirroring is enabled for the virtual server, and you change the profile type from UDP to FastL4 on the active system, the TMM process will crash on the standby system when the virtual server passes traffic.

F5 Product Development tracked this issue as CR64295, CR64872, and CR68200, and it was fixed in BIG-IP LTM versions 9.1.3, 9.2.4, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM release notes.
