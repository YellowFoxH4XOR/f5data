Issue

Error Message

Sensors out of range:
CPU-1 : Faulted!
CPU TControl Delta : Faulted!

Message Location

You may encounter this message in the following location:

  • Output from the E --- Display error report option in the AOM Command Menu

Description

This message occurs when all of the following conditions are met:

  • Your BIG-IP system runs on one of the following platforms:

    • BIG-IP 2000 series
    • BIG-IP 4000 series
    • BIG-IP 5000 series
    • BIG-IP 7000 series
    • BIG-IP 10000 series
    • BIG-IP 12000 series
    • VIPRION B2250 blade
  • The system is in the process of booting, or is unavailable, when you select the E --- Display error report option in the AOM Command Menu.

When the E --- Display error report option is selected in the AOM Command Menu, the system attempts to retrieve error reports from the respective sensors on the host. If the system is unavailable or still in the process of booting up, the Always-On Management (AOM) subsystem returns this error message.

Impact

None. This error message does not indicate a hardware issue with the BIG-IP system.

Recommended Actions

You must wait for the system to complete its booting process and become operational before you attempt to select the E --- Display error report option in the AOM Command Menu.
