Known Issue

HTTP connections are closed after receiving a response to an HTTP POST request, regardless of keep-alive status.

This issue occurs when all of the following conditions are met:

  • You are using the 'Performance (HTTP)' virtual server type with a FastHTTP profile.
  • You are sending an HTTP 1.1 POST request with Keep-Alives enabled.

Impact

Virtual server performance may be degraded due to excessive TCP port re-use.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • HTTP connections are closed with a FIN after HTTP post responses.
  • HTTP clients will open new TCP connections for requests made after a POST request.

Workaround

To work around this issue, you may consider using an alternative type of virtual server. To do so, perform the following procedure:

Impact of workaround: You may encounter a slight performance impact using an alternate virtual server type.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Select the virtual server you would like to change.
  4. Under Type, select an alternate virtual server type such as Standard.
  5. Click Update.

For more information about choosing virtual server types for HTTP traffic, refer to K4707: Choosing appropriate profiles for HTTP traffic.
