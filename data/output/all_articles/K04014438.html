Known Issue

The BIG-IP system may fail to reload the BIG-IP Advanced Routing Module (ARM) configuration.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured with a running configuration for one or more routing protocols in BIG-IP ARM.
  • A user configuration set (UCS) file containing a BIG-IP ARM configuration that is different from the running configuration is then restored on the system.

When this issue occurs, the BIG-IP ARM configuration file from the UCS file is restored on the system, but it does not load as the running configuration. All other BIG-IP configurations are not affected by this issue.

Impact

The BIG-IP system does not reload the BIG-IP ARM configuration and may not route traffic as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ARM running configuration is different from the BIG-IP ARM configuration file.
  • The BIG-IP system does not route traffic as configured in the BIG-IP ARM configuration file.

Workaround

To work around this issue, you can restart the tmrouted process to reload the BIG-IP ARM configuration file. To do so, perform the following procedure:

Impact of workaround: Depending on your environment, network traffic may be momentarily disrupted while the tmrouted process restarts.

  1. Log in to the Traffic Management Shell (tmsh).
  2. Restart the tmrouted process by typing the following command:

    restart sys service tmrouted
