Known Issue

This is the result of a known issue. Samba clients are unable to change ownership or permissions for CIFS files using the smbcacls command through the ARX system.

For example, a Samba client runs an smbcacls command that appears similar to the following example:

smbcacls -a ACL:CORP\\USER:ALLOWED/0/FULL  //10.10.10.20/test    "/testfile.txt"   -U MSDOM\\OSSM

As a result, the ownership or permissions change will not be performed, and the command will fail with an error message that appears similar to the following example:

cli_pipe_validate_current_pdu: RPC fault code DCERPC_FAULT_OP_RNG_ERROR received from host 10.10.10.20! ACE 'MSDOM\OSSM:ALLOWED/0/FULL': failed to convert 'MSDOM\OSSM' to SID

F5 Product Development tracked this issue as ID 336333 and it was fixed in ARX version 5.1.7. For information about upgrading, refer to the ARX Release Notes.
