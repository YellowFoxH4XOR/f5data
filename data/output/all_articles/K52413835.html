Source

Description

  • How to disallow URL and its subfolders on ASM software version 13.x
  • BIG-IP software version 13.x doesn't allow wildcard URLs

Environment

  • ASM
  • Disallowed wildcard URLs
  • BIG-IP software version prior to 14.x

Cause

None

Recommended Actions

For BIG-IP software version prior to 14.x you can use a Custom attack signature.

  1. Create a custom signature (see details here - Manual Chapter : Writing Custom Attack Signatures)

    Example: To filter uri containing /admin

    uricontent:"/admin"; nocase; objonly;

  2. Create a signature set (see details here - Manual Chapter : Assigning Attack Signatures to Security Policies )
  3. In Policy Settings > Learning and blocking settings, select ASM policy in question and go to "Attack signatures" and add the signature set previously created.
