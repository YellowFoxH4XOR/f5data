Issue

Old Behavior

In versions prior to BIG-IP AFM 11.6.0 (for the 11.6.x branch), 11.5.2, and 11.5.1 HF4 (for the 11.5.x branch), the Global Context setting in the Configuration utility Security > Options > Network Firewall page cannot be modified.

New Behavior

Beginning in BIG-IP AFM 11.6.0 (for the 11.6.x branch), 11.5.2, and 11.5.1 HF4 (for the 11.5.x branch), you can modify the value for the Network Firewall page's Global Context setting to either Reject or Drop. The Global Context setting determines the default firewall action.

The value of the tm.rejectunmatched database key will be set according to the value configured for the Global Context setting as follows:

  • If Reject is selected, the tm.rejectunmatched database key will set to true.
  • If Drop is selected, the tm.rejectunmatched database key will set to false.

Impact

The action for the system to use with rules defined for the Global Context setting can be changed using the Configuration utility. From the Security > Options > Network Firewall page, the configurable item for the default firewall action in the Global Context setting can be set to either Reject or Drop.
