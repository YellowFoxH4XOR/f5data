Description

You get the following error message from BIG-IQ when exporting the Inventory via the GUI Devices tab -> BIG-IP Devices

Error on server request
1.Could not retrieve inventory data from all devices

Environment

  • BIG-IQ v.7
  • Export Inventory
  • BIG-IQ is unable to connect with one or more managed BIG-IP devices
     

Cause

There are many causes as to why BIG-IQ is unable to connect with BIG-IP.  Refer to the error message column in the Inventory report for more details

Recommended Actions

Here are some known causes and recommendations:

  • Authorization failed: no user authentication header or token detected. (status code:401)
    Remove and re-add the BIG-IP device onto BIG-IQ to exchange certificates and re-establish trust

  • No route to host
    Troubleshoot network connectivity between BIG-IQ and BIG-IP

  • Any "code":500 message
    Troubleshoot BIG-IP device. 
    Check /var/log/restjavad.0.log on BIG-IP for error messages.
    Restarting restjavad on BIG-IP may help if resjavad is not behaving correctly: bigstart restart restjavad

Additional Information

Exporting device inventory details to a comma separated values (CSV) file
To export the BIG-IP Device inventory to a CSV file, your browser must be configured to allow popup screens.
Using BIG-IQ, you can quickly access and view the properties for all the devices you manage in your network. These properties include details about the device's IP addresses, platform type, license details, software version, and so forth. You (or another department in your company) can create custom reports containing this information to help manage these assets. To do this, you can export device properties to a CSV file and edit the data as required.

  1. At the top of the screen, click Devices tab.
  2. On the left, click BIG-IP DEVICES.
  3. Click the Export Inventory button.

BIG-IQ creates a CSV file and downloads it locally to your Downloads folder.
