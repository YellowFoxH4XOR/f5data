Description
When going through /config/bigip.conf, or checking tmsh show running-config all properties output, you found the following 'ecm' configuration and wonder what they are:

sys ecm cloud-provider aws-ec2
sys ecm cloud-provider dnet
sys ecm cloud-provider vsphere
sys ecm config
 

ECM stands for Elastic Compute Manager and

  • It is used to orchestrate application deployments,
  • This is built on top of Kubernetes to provide a management layer for F5 applications.
  • ECM is responsible for adding removing cluster node and provide application life cycle.
  • The ECM platform is mainly based on Google Kubernetes.


Environment

  • BIG-IP Virtual Edition
  • BIG-IP version 12.x and higher

Cause

None

Recommended Actions

ECM configuration is not used and can be left as is.

Additional Information

When you run tmsh show sys service in 13.x and higher, you see ecmd daemon listed in the output:

ecmd         down, Not provisioned

ecmd daemon exists on the system but not running
