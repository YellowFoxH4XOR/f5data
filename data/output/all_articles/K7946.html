Topic

The New Connections performance graph provides an overview of new connections established on the client and server side, as well as a detailed view that provides additional information on PVA-accelerated and SSL connections.

The New Connections performance graph provides a general overview of the following three criteria:

  • Client Connects

    The Client Connects section represents the total number of new connection flows created by TMM. This section includes all connections; it is not limited to any specific type or protocol. This value is reported by the following OID:

    Note: This section does not include fully accelerated PVA connections or connections that have exceeded a connection limit on the Virtual Server or Virtual Address.

    F5-BIGIP-SYSTEM-MIB::sysStatClientTotConns (.1.3.6.1.4.1.3375.2.1.1.2.1.7)

  • Client Accepts

    The Client Accepts section represents the number of connections that reached the TCP established state using the full proxy. This value is reported by the following OID:

    Note: This section does not include PVA accelerated connections; full proxy connections are not supported by the PVA. For PVA connection information, refer to the Total new connections section of this Solution.

    F5-BIGIP-SYSTEM-MIB::sysTcpStatAccepts (.1.3.6.1.4.1.3375.2.1.1.2.12.6)

  • Server Connects

    The Server Connects section represents the number of connections on the server side using the full proxy. In this case, the connection is not required to be in the TCP established state. This value is reported by the following OID:

    Note: The information reported includes connections created by the monitor(s).

    Important: Previous to BIG-IP version 9.4.2, the statsd process incorrectly used the OID F5-BIGIP-SYSTEM-MIB::sysTcpStatConnects (.1.3.6.1.4.1.3375.2.1.1.2.12.8), which includes all TCP connections and not just server side connections. This issue was tracked as CR76848 and was corrected in BIG-IP version 9.4.2.

    F5-BIGIP-SYSTEM-MIB::sysStatServerTotConns (.1.3.6.1.4.1.3375.2.1.1.2.1.14)

Total new connections

By selecting the View Detailed Graph link, the following connection information is provided in greater detail and includes PVA and SSL connection information:

  • Client Connects

    The Client Connects section represents the total number of new connection flows created by TMM. This section includes all connections; it is not limited to any specific type or protocol. This value is reported by the following OID:

    Note: This connection does not include fully accelerated PVA connections or connections that have exceeded a connection limit on the virtual server or virtual address.

    F5-BIGIP-SYSTEM-MIB::sysStatClientTotConns (.1.3.6.1.4.1.3375.2.1.1.2.1.7)

  • Server Connects

    The Server Connects section represents the number of connections created on the server side. In this case, the connection is not required to be in an established state. This value is reported by the following OID:

    Note: The information reported includes connections created by monitor(s).

    F5-BIGIP-SYSTEM-MIB::sysStatServerTotConns (.1.3.6.1.4.1.3375.2.1.1.2.1.14)

New PVA connections

  • PVA Client

    PVA client connections are client-side, fully PVA-accelerated connections. The connections are not required to be in an established state. This value is reported by the following OID:

    F5-BIGIP-SYSTEM-MIB::sysStatPvaClientTotConns (.1.3.6.1.4.1.3375.2.1.1.2.1.21)

  • PVA Server

    PVA server connections are server-side, fully PVA-accelerated connections. The connections are not required to be in an established state.

    Note: In the case of the 6800 platform, you may happen to see less than expected connections in the following two OIDs:

    F5-BIGIP-SYSTEM-MIB::sysStatPvaClientTotConns 
    F5-BIGIP-SYSTEM-MIB::sysStatPvaServerTotConns (.1.3.6.1.4.1.3375.2.1.1.2.1.28)

    When the D68.Acceleration.Strategy (9.4) db key or Pva.Acceleration.Strategy (< 9.4) is set to throughput (default value), approximately half of the PVA-accelerated connections are processed by TMM instead. In addition, they are accounted in the following two OIDs, instead of the PVA stats described in this section:

    F5-BIGIP-SYSTEM-MIB::sysStatClientTotConns (.1.3.6.1.4.1.3375.2.1.1.2.1.7)
    F5-BIGIP-SYSTEM-MIB::sysStatServerTotConns (.1.3.6.1.4.1.3375.2.1.1.2.1.14)

New Client SSL Profile connections

  • SSL Client

    Client-side SSL connections are established, which also establish the SSL session. The SNMP MIB F5-BIGIP-SYSTEM-MIB file provides fine-grained stats, and reports how many connections are hardware accelerated (native mode) or not (compat mode). These values are reported by the following OIDs, respectively:

    F5-BIGIP-SYSTEM-MIB::sysClientsslStatTotNativeConns
    (.1.3.6.1.4.1.3375.2.1.1.2.9.6)

    F5-BIGIP-SYSTEM-MIB::sysClientsslStatTotCompatConns
    (.1.3.6.1.4.1.3375.2.1.1.2.9.9)

  • SSL Server

    Server-side SSL connections are established, which also establish the SSL session. The SNMP MIB F5-BIGIP-SYSTEM-MIB file provides fine-grained stats, and reports how many connections are hardware accelerated (native mode) or not (compat mode). These values are reported by the following OIDs, respectively:

    F5-BIGIP-SYSTEM-MIB::sysServersslStatTotNativeConns
    (.1.3.6.1.4.1.3375.2.1.1.2.10.6)

    F5-BIGIP-SYSTEM-MIB::sysServersslStatTotCompatConns
    (.1.3.6.1.4.1.3375.2.1.1.2.10.9)

New Accepts and Connects connections

  • Client Accepts

    Client Accepts connections are the number of connections that reach the TCP established state using the full proxy. This value is reported by the following OID:

    Note: This connection does not include PVA-accelerated connections; full proxy connections are not supported by the PVA.

    F5-BIGIP-SYSTEM-MIB::sysTcpStatAccepts (.1.3.6.1.4.1.3375.2.1.1.2.12.6)

  • Server Connects

    Server Connects connections are the number of connections created on the server side using the full proxy. In this case, the connection is not required to be in the established state. This value is reported by the following OID:

    Note: This connection includes connections created by the monitor(s).

    F5-BIGIP-SYSTEM-MIB::sysTcpStatConnects (.1.3.6.1.4.1.3375.2.1.1.2.1.14)

The system is polled every ten seconds to determine the delta or change from the previous poll, at which time the graph is updated.

Note: For more information about polling the information graphed above using SNMP for use on a remote monitoring station, refer to the Configuring SNMP chapter of the BIG-IP Network and System Management Guide.
