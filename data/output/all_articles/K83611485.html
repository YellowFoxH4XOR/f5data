Description

Configuration Utility may freeze on, "Loading, receiving configuration data from your device"

Environment

Relevant environmental factors specific to the topic

  • Clicking on the Virtual Server list, Pool List or Node List in the GUI
  • Virtual Servers, Pool members, Nodes
  • BIG-IP LTM

Cause
The delay is caused by the "Display Host Names When Possible" setting in the BIGIP.

With this setting, every IP address on the device is attempting to be resolved by DNS. This can take a long time depending on the configured DNS servers and whether or not the look-ups are successful.

TMUI > System > Preferences > System Settings > Display Host Names When Possible

tmsh list sys db ui.system.preferences.displayhostnameswhenpossible
sys db ui.system.preferences.displayhostnameswhenpossible {
    default-value "false"
    scf-config "false"
    value "true"
    value-range "false true"
}

Recommended Actions

Disable Display Host Names When Possible
By disabling this feature, the BIG-IP will no longer attempt to resolve hostnames for IP Addresses of Nodes, Pool Members and Virtual Servers.
  1. SSH to log into the Advanced Shell (bash) prompt.
  2. Disable ui.system.preferences.displayhostnameswhenpossible
    tmsh modify sys db ui.system.preferences.displayhostnameswhenpossible value false
    tmsh save sys config

    Note: Since this is a custom DB setting, this will not be synced to any HA Peers, and must be performed on every device in a Sync Group.
