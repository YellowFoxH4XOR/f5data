Description

In ASM event log, the ASM Signature was triggered but the the request was allowed due to "Applied Blocking Settings: Staged, Potential False Positive"

 

Environment

  • BIG-IP ASM
  • Potential False Positive

Cause

Learning and Blocking Settings => Attack Signatures => Potential False Positive Detection set to Detect and Allow

Recommended Actions

Detect and Allow: Enables Attack Signature False Positive Mode. The system identifies a potential false positive attack signature, allows the request, and marks the request as a likely false positive violation. For additional information please refer to:

K20132133: Enabling Attack Signature False Positive Mode

K70544352: Reducing false positive violations
