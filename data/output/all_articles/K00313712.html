Description

The article describes an alternative solution to fix the following issue:

Rebooting the BIG-IP device with APM module provisioned results in not being able to connect to the GUI. The following error message can be seen in the CLI and /var/log/ltm.
 
emerg load_config_files[<PID>]: "/usr/bin/tmsh -n -g -a load sys config partitions all base " - failed. -- Error: failed to reset strict operations; disconnecting  from mcpd.  Will reconnect on next command.
 

Environment

  • BIG-IP
  • any version
  • APM provisioned
  • After upgrade / reboot/ restore UCS.
     

Cause

  • Bug ID 997793
    • K34172543: After rebooting the device unable to access the GUI. Console Error: failed to reset strict operations; disconnecting from mcpd

Recommended Actions

Follow the workaround in Bug ID 997793

If that does not work, try these commands in the CLI. Please note that the mcpd restart might be needed as well.
rm -rf /var/apm/lib/rpm
epsec -f refresh
tmsh load sys config
