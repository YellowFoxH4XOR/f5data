K000133605: APM: Edge Client component 'Dialup Entry/Windows Logon Integration' logs location

Type
Support Solution
Published
2023-04-21
Updated
2023-04-21
Source
https://my.f5.com/manage/s/article/K000133605

Description

The Edge Client package component 'Dialup Entry/Windows Logon Integration' (aka Pre-logon VPN) is integrated to the Windows log on service. This allows a BIG-IP APM VPN session to be established prior to Windows logon. The BIG-IP APM administrator may need to troubleshoot or review the logs for this VPN scenario.

Environment

  • APM
  • Edge Client
  • Dialup Entry/Windows Logon Integration (aka Pre-logon VPN)
  • Logs

Cause

The BIG-IP APM administrator may need to troubleshoot or review the logs for 'Dialup Entry/Windows Logon Integration' component of Edge Client package

Recommended Actions

Because there's no logged in user yet with Pre-Logon functionality, Edge Client creates a f5 Pre-Logon User account and logs there:

C:\Users\f5 Pre-Logon User\AppData\Local\Temp

f5DialServer.txt

f5LogonUI.txt

logterminal.txt
