Description

Upgraded to Known Affected Versions of ID 1006845 and configuration failed to load, with error:

01070311:3: Ciphers list 'ALL:!DH:!ADH:!EDH:@SPEED' for profile /Common/clientssl-insecure-compatible denies all clients Unexpected Error: Loading configuration process failed.

Client SSL profile clientssl-insecure-compatible has not been modified. Cannot find it in /config/bigip.conf.

Environment

  • After upgrade

Cause

Bug ID 1006845

Default clientssl profile is modified to use a Cipher Group.

Example:

ltm profile client-ssl /Common/clientssl {
    <..>
    ciphers none
    cipher-group /Common/f5-default         <---
    <..>
}

clientssl-insecure-compatible is loaded from /config/profile_base.conf and defaults from the clientssl profile, but itself uses a Ciphers list.

The Cipher Group and Ciphers list options are mutually exclusive settings in an SSL profile.

Recommended Actions

Modify the /config/bigip.conf file and remove the Cipher Group from the Client SSL profile. Configure a cipher list.

For example:

ltm profile client-ssl /Common/clientssl {
    <..>
    ciphers DEFAULT                         <--- Add this
    cipher-group /Common/f5-default         <--- Remove this
    <..>
}

Then reload the configuration:

tmsh load sys config

Alternatively, if you have already rolled back to the previous version, simply modify the clientssl profile to use a Ciphers list instead of a Cipher Group. This will prevent the issue on the next upgrade.

Additional Information

The Ciphers list '<ciphers list>' for profile /Common/<profile> denies all clients error can be a legitimate one if a Ciphers list is configured that will actually deny all clients.
