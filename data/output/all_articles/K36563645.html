Known Issue

The Proxy SSL feature does not work properly with the extended master secret and Online Certificate Status Protocol (OCSP).

This issue occurs when all of the following conditions are met:

  • The virtual server is configured to work in Proxy SSL mode.
  • The client and server negotiate the SSL handshake with the extended master secret.
  • The client and server negotiate to use the OCSP.

Impact

Proxy SSL does not work properly with the extended master secret and OCSP simultaneously.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The SSL handshake fails if the BIG-IP system operates in Proxy SSL mode, while the client and server negotiate to use the extended master secret and OCSP features together.
