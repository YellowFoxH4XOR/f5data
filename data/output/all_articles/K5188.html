K5188: Converting a redundant server object back into individual server objects

Topic

Redundant server objects cannot be converted to individual server objects. Once you have added a redundant address to an individual server object, you cannot remove it.

For example, if you add an individual BIG-IP and then temporarily add a redundant peer, you cannot remove the redundant peer.

To change a redundant server object to an individual server object, you must delete the redundant server object and then recreate the individual server object.
