Description

BIG-IP can only be configured to perform Single Sign-On (SSO) functions using APM. Without APM, all BIG-IP can do with SSO is pass the packets back and forth between devices, without being involved in the SSO functions directly. APM is required in order for BIG-IP to perform SSO functions for clients/servers.

Environment

Relevant environmental factors:

  • BIG-IP with APM Licensed, Provisioned, & properly configured.

Cause

None

Manual : BIG-IP Access Policy Manager: Single Sign-On Concepts and Configuration
