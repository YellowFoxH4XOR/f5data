Description

When upgrading the system by GUI, the disk volume list is blank on Install Software window wizard.

 

Environment

BIG-IP LTM

Upgrade

Cause

When upgrading to the major/minor software version or updating with the EHF, it's prohibited to choose the actual active working volume as the volume destination.

To be able to choose the disk volume when installing the EHF, there must be the non-active volume with the same software version that the EHF is designed for.

Recommended Actions

In the installation wizard, manually write the next free partition name number for the partition name that will be automatically created during installation.

For example:
In the System -> Software Management -> Image List, there is a disk volume name HD1.1 working as the active partition.


For installing the Engineering Hotfix (EHF) ISO image, please go to System -> Software Management -> Hotfix List:
- upload the EHF ISO image  (and the base corresponding ISO image, if it is different from the software version on the partition that you are installing from) by clicking 'import'
- mark the EHF image ISO you want to install, click 'install'
- on Install Software Hotfix window wizard, manually type the next available volume name, (in this case '2', as HD1.1 is already created and active now)
(it's impossible to install the EHF on the volume that is active)

- Installation will start, and the partition HD1.2 will be automatically created
