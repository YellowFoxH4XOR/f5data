K4031: Method of response time measurement used by fastest load balancing mode

Topic

In fastest load balancing mode, the BIG-IP system directs inbound connections to the node that has the fastest response time. The BIG-IP system determines response time based on the amount of time the node takes to respond to the first packet in a connection. This measurement is taken once per second when sufficient traffic exists.
