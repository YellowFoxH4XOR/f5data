Topic

You can configure the BIG-IP system to use a rule to check the HTTP header for cookies, find the cookie, and verify the value.

In this case, the rule will search for a cookie with the normal periods and, using the sub statement, also search for specific modified text.

This rule would appear similar to the following example:

RULE cookie_rule {
if (http_cookie ''SupportContract'' == ''paid.000'') {
use ( A_pool )
}
else {
if (http_cookie ''SupportContact'' == ''paid%2e000'') {
use ( A_pool )
}
else {
if (http_cookie ''SupportContact'' == ''void'') {
use ( B_pool )
}
else {
use ( X_pool )
}
}
}
}

With this rule, when the cookie and the value match, the BIG-IP system sends the connection to the pool that includes the issuing server.

Note: For specific instructions about how to configure a BIG-IP rule, refer to the iRules chapter in the BIG-IP Reference Guide.
