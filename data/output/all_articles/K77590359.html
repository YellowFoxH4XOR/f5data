Description

You want to export ASM bot events on version 13.1.1.

Environment

  • ASM version 13.1.1
  • Bot defense profile

Cause

None

Recommended Actions

There is no export feature via GUI for bot events as of time of publication of this article. You can use the following procedure to export the bot events via CLI:

  1. Login to CLI
  2. Switch to bash shell
  3. Run the following command:

    mysql -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e "select * from logdb.log_data limit 10000\G" > /shared/tmp/bot_event.txt

    Note: Above command will generate a file on /shared/tmp/ called "bot_event.txt" with the output of the last 10000 events.
