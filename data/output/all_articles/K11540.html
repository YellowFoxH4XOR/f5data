K11540: The default DoS detection mode is set to TPS after upgrade

Known Issue

This is the result of a known issue. If you upgrade a BIG-IP ASM configuration from version 10.0.x to version 10.1.0, the default DoS detection mode is erroneously set to the newly added TPS mode. In versions prior to 10.1.0, the DoS detection mode can be configured only as Latency mode. As a result, policies referencing the default mode will use TPS mode after the upgrade and may not function as expected.

F5 Product Development is tracking this issue as CR138202.

This issue does not exist in the BIG-IP version 10.2.0 software branch.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

Workaround

You can work around this issue by explicitly configuring Latency DoS detection mode in affected policies. To do so, perform the following procedure:

  1. Log in to the BIG-IP ASM Configuration utility.
  2. On the Main tab of the Application Security navigation pane, click Anomaly Detection.

    The DoS Attack Prevention screen opens

  3. Verify that the edited security policy is the one you want to update.
  4. Locate the Detection Criteria settings in the DoS Configuration area.
  5. Select the radio button for Latency.
  6. Click Save.
  7. To apply the new policy immediately, click the Apply Policy button.
