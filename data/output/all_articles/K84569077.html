Description
While attempting to sync the configuration, an error message similar to this may appear:

Sync error on example.hostname.net: Load failed from /Common/peer.system.net 01070920:3: Application error for confpp: AH00526: Syntax error on line 150 of /etc/httpd/conf.d/ssl.conf: SSLCertificateChainFile: file '/config/httpd/conf/ssl.crt/chain.crt' does not exist or is empty

Environment

  • Big-IP
  • Config-Sync

Cause
One member of the peer group has a chain certificate configured for the configuration utility, while the peer does not. This mismatch prevents the bigip.conf file from loading, since the referenced certificate file doesn't exist on the peer device.

Recommended Actions
Impact of procedure: Communication with other BIG-IP devices will fail until the new certificate is exchanged. There will be no impact to high availability (HA) features such as traffic groups and device groups.

You can either follow one of the procedures to resolve the sync issue.

  1. Identify which unit is missing the  /config/httpd/conf/ssl.crt/chain.crt 
  2. Bring the two systems into sync by etiher manually replicating the chain file, creating it if needed, or removing that configuration from the peer
  3. Copy the /config/httpd/conf/ssl.crt/chain.crt file from the peer to this system, then re-sync the configuration
  4. In some cases a full reboot of the device may be necessary
