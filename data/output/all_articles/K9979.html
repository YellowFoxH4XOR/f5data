Known Issue

This is the result of a known issue. Exiting Protected Workspace before terminating an active Network Access connection may cause a stop error (blue screen) for Windows Vista clients.

F5 Product Development tracked this issue as CR86452 and it was fixed in FirePass 6.0.3. For information about upgrading, refer to the FirePass release notes.

Workaround

Users can work around this issue by disconnecting the Network Access connection prior to exiting Protected Workspace.
