Topic

According to RFC2616, any HTTP request with a Content-Length header containing a negative value is considered to be invalid. When the BIG-IP ASM processes a request or response with a Content-Length header containing a negative value, the security policy blocks the request or response and the following request violation is logged to the /var/log/asm file:

Illegal HTTP Format
