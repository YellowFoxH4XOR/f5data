K000162991: IPv6 DAG prefix length reverts to /128 on a BIG-IP PEM tenant

Type
Support Solution
Published
2026-08-31
Updated
2026-08-31
Applies to
  • BIG-IP
  • F5 Distributed Cloud Services
  • BIG-IP PEM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000162991

Description

The effective DAG IPv6 prefix length on a BIG-IP PEM tenant is /128 even though the BIG-IP database key tmm.pem.session.ipv6.prefix.len is configured as another value, like /56.

Relevant platform log messages include:

- Receive dag_ipv6_prefix_length 128 from APIGW
- Push dag_ipv6_prefix_length 128 to MCPd
- Configuring DAG Global IPv6 Prefix Length still might require modification of vlans previously created with the old setting.

Environment

  • BIG-IP tenant.
  • BIG-IP tenant deployed on a VELOS chassis partition.
  • Chassis partition configuration contained dag-ipv6-prefix-length 128
  • BIG-IP PEM database key tmm.pem.session.ipv6.prefix.len changed in tenant

Cause

The VELOS chassis partition is configured with dag-ipv6-prefix-length 128, and this value is automatically propagated to the BIG-IP PEM tenant. The BIG-IP PEM database key configured with another value like /56 does not override the chassis-level DAG setting, so the effective prefix length remained /128.

Answer/Recommended Actions

To configure the required value, apply it at the VELOS chassis partition level.

1. Enter the tenant configuration context from the F5OS-C CLI:

config
tenants tenant <tenant-name> config dag-ipv6-prefix-length <new_value>
commit

2. Verify the result using the partition CLI:

show running-config tenants tenant <tenant-name>
show tenants tenant <tenant-name>

3. If the prefix length was previously configured directly within BIG-IP through TMOS, clear the tenant-side override on the tenant:

tmsh mod sys db dag.userconfigipv6prefixlen value false

4. Verify the configuration
