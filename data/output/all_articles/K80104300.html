Description
This error message is encountered during deployment of an Autoscale Group template in AWS.

Environment
Amazon Web Services

Cause
The name of a pre-existing valid AWS Elastic Load Balancer is a pre-requisite to deploying this template. It must be entered exactly in the template form.

Recommended Actions
Enter the name of the AWS Classic Elastic Load Balancer that you previously created for use in this Autoscale deployment.

Additional Information
The classic ELB in front of the BIG-IP VEs must be preconfigured to perform SSL offload for the BIG-IP WAF auto scale tier. See ELB configuration for an example of the ELB configuration.
