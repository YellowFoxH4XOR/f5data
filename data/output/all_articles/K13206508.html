Description

The virtual server is unable to process TLS traffic due to the following error message:

/var/log/ltm

Profile /<partition>/<clientssl_profile>: could not load CRL

Environment

  • BIG-IP
  • Client-SSL Profile with CRL file
  • iCall Script used to update CRL file

Cause

Misconfiguration - Multiple iCall scripts reference the same CRL object causing an internal conflict when iCall scripts are run at the same time.

Recommended Actions

Perform one of the following recommended actions to resolve the internal conflict:
  1. Remove duplicate iCall scripts that are performing the same task
  2. Use unique object names in each iCall script.

Additional Information

To view all iCall handlers and scripts:

tmsh list sys icall handler periodic
tmsh list sys icall script

To delete the duplicate handler and script:

tmsh delete sys icall handler periodic <name of iCall handler>
tmsh delete sys icall script <name of iCall script>
