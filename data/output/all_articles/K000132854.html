K000132854: How to configure name of ASM cookies?

Type
Support Solution
Published
2023-03-03
Updated
2023-03-03
Applies to
  • NGINX Products
  • NGINX Ingress Controller: 2.4.2
Source
https://my.f5.com/manage/s/article/K000132854

Description

  • You have successfully deployed Nginx Ingress controller with Nginx Approtect
  • Some ASM related cookies are set in client responses with WAF enabled.
  • Is it possible to modify Nginx Approtect cookie names in the same way as BIG-IP AWAF described in article K54501322

Environment

  • Nginx Approtect
  • Nginx Ingress Controller
  • BIG-IP AWAF
  • TS cookies

Cause

  • None

Recommended Actions

  • Nginx Approtect does not offer the same approach as BIG-IP ASM in terms of modifying TS cookie prefix, discussed in referenced article.

Additional Information

  • With Nginx Approtect, anything we need to configure, is made through policy or NGINX config file.
  • BIG-IP ASM implementation of TS cookie is ever slightly different to NAP.
  • ASM works through the use of enforcer centric DB variables.
  • These DB variables are fetched directly by ASM bd daemon from MCP (master control program daemon) on BIG-IP.
  • We do not have any equivalent mechanism for NAP at this time for such sys db fields or any specific implementation for these settings.
