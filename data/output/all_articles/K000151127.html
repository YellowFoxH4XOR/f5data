K000151127: [F5OS-A] - System licensing install does not work when using proxy-option

Type
Support Solution
Published
2025-05-01
Updated
2025-05-01
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.8.0
Source
https://my.f5.com/manage/s/article/K000151127

Description

The F5OS-A has to be configured with an HTTP upstream proxy.

As you're attempting to license the box, you're prompted with an error message:

  • GUI: "Cannot determine IP for license server."
  • CLI: "result Error: Cannot determine IP for license server"

Environment

F5OS-A

Upstream HTTP proxy

Cause

This may be because of: Bug 1933769 – Licensing via proxy server should use license server's FQDN

Recommended Actions

Workarounds would be:

  • either to add a static host-entry about the licensing server "activate.f5.com"
  • or to configure a DNS server, or allow port 53 access so the root DNS servers can be reached

Additional Information

None
