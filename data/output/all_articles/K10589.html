Known Issue

Important: This issue only affects 6900 and 8900 platforms that contain more than 4 gigabytes of RAM and are running BIG-IP version 9.4.6.

This is the result of a known issue. BIG-IP 6900 and 8900 platforms that contain more than 4 gigabytes of RAM and are running BIG-IP version 9.4.6 only report the first 4 gigabytes of RAM.

For example, a BIG-IP 6900 platform running version 9.4.6 with 8 gigabytes of RAM installed will report the following message when the bigpipe memory command is used:

(Host) Total = 371.4MB   Used = 367.1MB
(TMM)  Total = 3.352GB   Used = 104.7MB

The kernel recognizes only the first 4 gigabytes. The kernel does not address or use the remaining 4 gigabytes.

F5 Product Development tracked this issue as CR116214 and it was fixed in BIG-IP version 9.4.7. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, PSM or WebAccelerator release notes.
