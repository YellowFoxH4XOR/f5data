K11209488: The effect on managed BIG-IP devices when BIG-IQ license is released

Type
Support Solution
Published
2020-09-23
Updated
2024-07-18
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.0.0, 8.0.X, 8.1.0, 8.1.X, 8.2.0, 8.2.X, 8.3.0, 8.3.X, 8.X.X
Source
https://my.f5.com/manage/s/article/K11209488

Description

When a BIG-IQ VE instance is used to manage other BIG-IP devices, sometimes there is a need to release/allow-move the BIG-IQ base registration key due to BIG-IQ having issue.  

Environment

  • BIG-IQ CM
  • Managed BIG-IP's
  • Release/Revoke BIG-IQ license

Cause

None

Recommended Actions

BIG-IQ license release/allow-move procedure should not have any negative impact on its managed BIG-IP devices.


Additional Information

None
