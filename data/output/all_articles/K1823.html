Note: For BIG-IP 9.0 and later, refer to K7574: Monitoring SSL certificate expiration on the BIG-IP system (9.x - 10.x).

To find the expiration date of your Secure Socket Layer (SSL) certificate using the command line interface, perform the following procedure:

  1. In the /config/bigconfig/ssl.crt directory, find the specific SSL Certificate name that you want to verify.
  2. Use the following command syntax, replacing <insert_cert_name_here> with the SSL Certificate name:

    openssl x509 -in /config/bigconfig/ssl.crt/<insert_cert_name_here> -noout -enddate |cut -c10-40

    The expiration date displays and appears similar to the following example:

    Jan 7 22:41:14 2012 GMT
  3. To view both the start date and the expiration date for the SSL Certificate, replace -enddate with -dates as follows:

    openssl x509 -in
    /config/bigconfig/ssl.crt/<insert_cert_name_here> -noout -dates |cut -c10-40

    Both the start date and the expiration date display, and appear similar to the following example:

    notBefore=Jan  9 22:41:14 2002 GMT
    notAfter=Jan  7 22:41:14 2012 GMT
