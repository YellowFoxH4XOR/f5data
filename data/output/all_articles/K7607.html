K7607: Configuring an Application Tunnel Favorite to run multiple commands or applications

Topic



You can configure an Application Tunnel Favorite to specify a string to run a command or an application transparently. The following example code starts an application:

iexplore http://127.10.10.80/sales/automation.pl

Note: In FirePass version 5.x, you can enter this string in the Command Line field. In FirePass version 6.x, you can enter this string in the Application field.

You can only run one command or application from an Application Tunnel Favorite. For example, if you enter the following string, only App1 will start:

C:\MyApps\App1 & C:\MyApps\App2

If you want to run multiple commands or applications, you will need to create a batch file that contains those commands. For example, you can create the following batch file named AppTunnelCommands.cmd:

iexplore http://127.10.10.80/sales/automation.pl
telnet 127.10.10.10
putty -ssh 127.10.10.10

After creating the batch file, specify the path to that batch file in the Application Tunnel Favorite. For example, if you are running FirePass version 5.x, you can enter the following path in the Command Line field:

C:\Apps\AppTunnelCommands

If you are running FirePass version 6.x, enter the following path in the Application field:

C:\Apps\AppTunnelCommands

You must distribute the batch file to everyone who will access the Application Tunnel Favorite, and ensure that batch file is saved to the exact path you specified in the Application Tunnel Favorite. Using our previous example, the batch file should be saved to the following path on the client machines:

C:\Apps\AppTunnelCommands
