Description

Renewed the LTM iQuery certificate (Device Certificate), imported new certificate into BIG-IP DNS' 'Device Trust Certificates', however the iQuery connection still indicates that it's still using the old certificate from the LTM.

Environment

iQuery

BIG-IP DNS & BIG-IP LTM

Cause

The existing iQuery connection will not use the new certificate, until the iQuery connection's TLS connection is renegotiated. This is normal and expected.

Recommended Actions

Restart the iQuery daemons.

-- On the BIG-IP DNS system, run: bigstart restart gtmd

-- On the BIG-IP LTM system, run: bigstart restart big3d

Note: Restarting the iQuery daemons should not cause a noticeable interruption for users.

Additional Information

After restarting the iQuery daemons, the iQuery connection should reestablish quickly. During the brief period that iQuery is reconnecting, if a 'BIG-IP LTM' 'Virtual Server' were to change health state, the 'BIG-IP DNS' system would not know about that change. However, this is rare and typically not noticed by DNS resolvers that might be querying for a related BIG-IP DNS Wide-IP at the same time.
