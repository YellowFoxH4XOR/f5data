Topic

This article discusses naming conventions for using the Configuration utility to create a self-signed SSL certificate or an SSL Certificate Signing Request (CSR).

Description

When you use the Configuration utility to create an SSL certificate or CSR, the BIG-IP system automatically creates the physical file with the appropriate file extension. You are not required to include a file extension when naming a new SSL certificate or CSR. This functionality is by design.

For example, if you attempt to use one of the following suffixes to name a new SSL certificate or CSR:

  • .pem
  • .crt
  • .key

The following results occur:

  • If you attempt to create a self-signed SSL certificate, the BIG-IP system triggers an error and create only an SSL key file without the SSL certificate file.
  • If you attempt to create an SSL CSR, the BIG-IP system triggers an error and creates only an SSL key file without the CSR file.

The error message observed in the Configuration utility may appear similar to the following:

BIG-IP 11.4.x

Not Found

BIG-IP 10.x through 11.3.0

No such file or directory

Recommendations

Name a new SSL certificate or CSR

When you create an SSL certificate or CSR using the Configuration utility, avoid using a name that contains a period character ( . ) followed by one of the previously-mentioned suffixes.

Existing SSL key named with the suffix explained in this article

If you have previously attempted to name the SSL certificate or CSR with one of the previously-mentioned suffixes, and the attempt resulted in an SSL key that does not have the matching SSL certificate or CSR in the BIG-IP system, you should delete the affected SSL key and re-create the required SSL certificate or CSR, assigning a name that does not contain any of the previously-mentioned suffixes.
