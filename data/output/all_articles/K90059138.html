Security Advisory Description

Vulnerability in the Oracle WebLogic Server component of Oracle Fusion Middleware (subcomponent: Web Services). Supported versions that are affected are 10.3.6.0.0 and 12.1.3.0.0. Easily exploitable vulnerability allows unauthenticated attacker with network access via HTTP to compromise Oracle WebLogic Server. Successful attacks of this vulnerability can result in takeover of Oracle WebLogic Server. CVSS 3.0 Base Score 9.8 (Confidentiality, Integrity and Availability impacts). CVSS Vector: (CVSS:3.0/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H). (CVE-2019-2725)

Impact

There is no impact; F5 products are not affected by this vulnerability.

Security Advisory Status

F5 Product Development has evaluated the currently supported releases for potential vulnerability, and no F5 products were found to be vulnerable.

Security Advisory Recommended Actions

Using Advanced WAF or BIG-IP ASM to mitigate this vulnerability

To mitigate against this vulnerability, you can update the Advanced Web Application Firewall (Advanced WAF) or BIG-IP ASM systems with the following attack signatures:

  • Signature ID: 200004754  Java code injection - oracle.toplink.internal.sessions.UnitOfWorkChangeSet   (Parameter)
  • Signature ID: 200004755  Java code injection - oracle.toplink.internal.sessions.UnitOfWorkChangeSet   (Header)
  • Signature ID: 200004756  Java code injection - oracle.toplink.internal.sessions.UnitOfWorkChangeSet   

For more information, refer to DevCentral: Oracle WebLogic Deserialization Remote Code Execution.
