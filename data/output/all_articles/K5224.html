Known Issue

When attempting to view a pool configuration from the Configuration utility, the following error may occur when the pool definition contains all or part of a reserved word in a BIG-IP object.

An error has occurred while trying to process your request.

For example, the reserved word min, which is part of the monitor name minuto, will return an error message in the following monitor and pool configuration:

monitor minuto {   defaults from http   interval 10   timeout 31   recv "success"   send "GET /servercheck.html"}pool webserver_pool {   monitor all minuto   member 10.10.10.10:http}

This error is a result of a stringent reserve word check that the Configuration utility performs on pools and monitors when parsing for display.

F5 Product Development tracked this issue as CR53051 and the reserve word check feature was corrected in BIG-IP 9.1.1. The system will only look for the reserved word in its entirety, not part of a reserve word or combined with another word. For information about upgrading, refer to the BIG-IP LTM Release Notes.

For a list of reserved words, refer to K3653: Reserved words that should not be used in BIG-IP configurations.
