Known Issue

This is the result of a known issue. If a user's UserPrincipalName attribute is different than their sAMAccountname attribute, dynamic group mapping may fail if nested groups are used and the user's group is not the primary group. This failure occurs because the UserPrincipalName attribute is used in place of sAMAccountname in the LDAP query that FirePass sends back to the authentication servers. Since the sAMAccountname attribute is different than the UserPrincipalName, the authentication servers will determine the username as invalid and will not authorize authentication.

F5 Networks Product Development is tracking this issue as ID 3229907 (formerly CR140476).

This issue was fixed in cumulative hotfix HF-610-3-1 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.
