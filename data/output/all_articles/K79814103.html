Known Issue

The BIG-IP AFM system may drop truncated DNS responses.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP AFM system has the DNS DoS option enabled.
  • The DNS server responds to a request with a truncated bit set.

Impact

Clients do not receive truncated DNS responses.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP AFM system drops DNS responses with truncated bit sets.

Workaround

To work around this issue, you can disable DNS DoS protection by changing the dos.dnsport variable to another port for which there is no valid traffic. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure will have a negative impact on your system. Disabling DNS DoS protection makes the BIG-IP system vulnerable to DNS DoS attacks. If possible, you should revert to a version prior to BIG-IP 13.1.0.

  1. Log in to the command line.
  2. To change the dos.dnsport variable, type the following command:

    tmsh modify sys db dos.dnsport value 54
