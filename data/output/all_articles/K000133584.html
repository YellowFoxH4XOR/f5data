K000133584: BIG-IQ stuck when trying to update or reactivate ELA license

Type
Support Solution
Published
2023-04-19
Updated
2025-02-07
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K000133584

Description

When trying to update or reactivate a license ELA in BIG-IQ using automatic method and the BIG-IQ just gets stuck in trying to activate for hours, GUI will show Activating:



Environment

BIG-IQ Licensing

Cause

Unknown

Recommended Actions

1) On the BIG-IQ using the command line you can stop the activating process running the following command:

bigstart restart restjavad


2) Finally you can reconvene at your convenience and reactivate or update the license using the manual method.
