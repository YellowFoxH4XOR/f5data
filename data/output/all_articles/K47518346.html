Description

When asm security policy is assigned to virtual server causes RDP connections to fail

Environment

  • RDP over HTTPS
  • ASM security policy

Cause

Seen behavior is expected. ASM is a layer 7 Web Application Firewall and it is designed to address common attacks on web applications, primarily http and https attacks. It is not supported for RDP traffic.

RDP utilizes encryption, binary and protocols other than http and https. Even if the policy is in transparent mode ASM will still try to inspect the traffic and most likely due to the limitations it will drop the traffic.

Recommended Actions

You will need to bypass ASM for any RDP traffic, if you know the URL/specific header for RDP then you can use a local traffic policy and disable ASM for RDP only:

  • K04597703: Overview of the Local Traffic Policies feature (12.1.0 and later
  • K22021244: Bypassing the BIG-IP ASM system (12.1.0 and later)
