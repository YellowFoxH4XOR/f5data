Known Issue

This is the result of a known issue. When both RAM Cache and Application Security are enabled for a virtual server, and a request is blocked by the BIG-IP ASM security policy, the response is corrupted and then cached by the BIG-IP system. Additional requests for the same document receive the corrupted response from the BIG-IP RAM Cache.

When this issue occurs, the following message will be logged to the /var/log/ltm file:

tmm tmm[1716]: 011f0007:3: http_process_state_prepend - Invalid action EV_EGRESS_DATA during ST_HTTP_PREPEND_HEADERS

F5 Product Development tracked this issue as CR87083 and it was fixed in BIG-IP ASM 9.4.4. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.3-HF2 issued for BIG-IP 9.4.3. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
