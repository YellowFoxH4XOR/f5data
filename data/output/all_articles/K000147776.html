Description

  • How can I bypass DoS protection for specific hosts or networks?

Environment

  • F5® Distributed Cloud
  • Web App & API Protection

Cause

The default L7 DDoS Protection Settings automatically run and apply to all traffic matching an attack fingerprint.

Answer/Recommended Actions

You can use "Trusted Client Rules" to allow certain trusted IPs. 

LB >> Common Security Controls >> Trusted Client Rules >> Rules

 

  1. Navigate to your load balancer and select "Edit".
  2. Under "Common Security Controls" select Trusted Client Rules and Configure.
  3. Add your rules and select Skip DDoS Protection (or any other protections you would like to bypass)
  4. Save the configuration
 

 

 

 

 

Additional Information

Our machine learning algorithms are optimized to only block true attackers. If you need to perform load testing (and this has been approved by the XC SOC), then you can increase the RPS Threshold value within the DoS settings of your load balancer so that protections do not engage.
