K000136890: Unable to save address list

Type
Support Solution
Published
2023-10-18
Updated
2023-10-18
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000136890

Description

 

Unable to save the Address List in Shared Objects in GUI no error message found or display.

 

Environment

BIG-IP LTM 16.1.3

Cause

Enhanced UI security block the request

Recommended Actions

Reset the UI security to default. After saving then change it back.

1. Log in to tmsh by entering the following command:

 tmsh 

2. To edit the configuration use the following syntex

edit sys httpd all-properties 

To replace the line start with include "FileETag ..... " with include none

3. After save the configuration can start edit the Address List from GUI

4. To restore the configuration with replace the include none to

include "FileETag MTime Size

order deny,allow

deny from all

"

5. save the configuration

 

The other workaround is to using tmsh to configure the address list, you may refer to article K59224255: Creating an address-list using tmsh
