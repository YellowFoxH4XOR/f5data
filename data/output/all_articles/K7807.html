Known Issue

This is the result of a known issue. When using the gtm_add script to add a BIG-IP GTM system to an existing synchronization group with a large number of DNS zone files, the gtm_add script may fail to import all of the zones. The output of the gtm_add script will appear similar to the following example:

Sync_zones script failed to retrieve DNS/named configuration: external/com./IN: out of range

F5 Product Development tracked this issue as CR82646 and it was fixed in BIG-IP GTM 9.4.2. For information about upgrading, refer to the BIG-IP GTM release notes.
