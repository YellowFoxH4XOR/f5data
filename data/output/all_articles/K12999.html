Known Issue

You cannot add data group records that begin with a slash (/) character to data groups using tmsh.

This issue occurs when all of the following conditions are met:

  • You are creating or modifying a data group from tmsh.
  • The record you are adding to the data group contains a slash as the first character.

    For example, using the following tmsh command to add the record /path/index.html to the data group MyClass, will fail:

    (tmos) modify ltm data-group myclass records add {"/path/index.html"}

Impact

You cannot create or modify data group objects.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The tmsh command fails and generates an error message that appears similar to the following example:

    Syntax Error: the "create" command does not accept wildcard configuration identifiers

Workaround

To work around this issue, you can add the record to the data group by using the bigpipe command or the Configuration utility. To do so, perform one of the following procedures:

Impact of workaround: None

Modifying a data group using the bigpipe command

To add a record to the data group, use the following command syntax from the BIG-IP command line:

bigpipe class <classname> <record> add

For example, to add the record /path/index.html to the data group MyClass, you would enter the following command:

bigpipe class MyClass \"/path/index.html\" add

Modifying a data group using the Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules > Data Group List.
  3. Click the name of the Data Group you want to modify.
  4. Enter the new record data in the Records menu.
  5. Click Update.
