K11654: The BIG-IP system does not mirror connections for virtual servers using the radius or diameter profiles

Known Issue

This is the result of a known issue. If you enable connection mirroring for a virtual server that uses the radius or diameter profile, BIG-IP LTM does not mirror connections for that virtual server to the standby unit.

F5 Product Development tracked this issue as CR133817 and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM release notes.
