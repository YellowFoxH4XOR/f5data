Description

HA pair failover 

  • Failover occurred
  • in /var/log/ltm:
01140029:4: HA proc_running bd fails action is go offline and down links
  • in /var/log/asm:
asm_start process error : 01310027:2: ASM subsystem error (asm_start,F5::NwdUtils::Nwd::log_failure): Watchdog detected failure for process. Process name: bd, Failure: Insufficient number of threads (required: 8, found: 0).
  • in /var/log/kern.log:
warning kernel: httpd invoked oom-killer: gfp_mask=0x201da, order=0, oom_adj=0, oom_score_adj=0
err kernel: Out of memory: Kill process <process ID> (<process name>) score <score value> or sacrifice child

Environment

  • BIG-IP ASM

Cause

High memory and cpu usage causes bd to restart all ASM daemons which made active device go offline, resulting in failover to peer device. This may be due to db memory leak due to known issue like the below,  but bd is just a victime of the memory leak due to other process or lack of resources for the environment.

e.g.

  • Bug ID 880917
  • Bug ID 1066829

Recommended Actions

  • Check the memory usage, which process is using more memory.
