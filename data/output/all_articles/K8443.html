Known Issue

This is the result of a known issue. If you click the Delete link next to a landing URI that contains one or more backslash ( \ ) characters, the Device Management: Customization page refreshes, but FirePass does not delete the landing URI.

This issue occurs due to improper validation of the Create Landing URI field under the URI-based Customization tab on the Device Management: Customization page. In some instances, FirePass does not validate this field and accepts a landing URI that contains backslash characters. In other instances, FirePass correctly validates this field and reports an error message similar to the following example:

URI name may contain alphanumeric characters only

Valid URIs do not contain backslash characters. For more information about valid URI characters, refer to RFC2396.

F5 Product Development tracked this issue as CR93970 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative hotfix HF-552-12 issued for FirePass version 5.5.2, cumulative hotfix HF-601-11 issued for FirePass version 6.0.1, and in cumulative hotfix HF-602-3 issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
