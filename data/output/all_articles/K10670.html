Known Issue

This is the result of a known issue. Inconsistencies occur between local and remote logging when some or all of the following conditions are true:

  • A remote logging profile is configured for a web application
  • A violation is detected
  • An attack signature that is currently in staging is triggered

If all three of the conditions are true, the following logging occurs:

  • Only the non-signature violation is logged in the /var/log/asm file
  • The remote logging profile sends both the non-signature violation and the triggered attack signature to the remote logging server
  • The Configuration utility reports both the non-signature violation and the triggered attack signature

If a request triggers only an attack signature that is currently in staging, the following logging occurs:

  • No signature violation is logged in the /var/log/asm file
  • The remote logging profile does not send the triggered signature violation to the remote logging server
  • The Configuration utility reports the triggered attack signature violation

F5 Product Development is tracking this issue as ID 328029 (formerly CR129345).
