K4114: FirePass may not allow Active Directory users to change their passwords

Topic

If a user attempts to log in to FirePass using an expired Active Directory password, FirePass prompts the user to update the password. In certain instances, the password update fails. This typically occurs when one or more of the following conditions are met:
  • The user does not have sufficient Active Directory privileges to change the password
  • The user entered the wrong password in the Current password field
  • The hostname configured in the Kerberos server name field does not match the Full computer name configured on the Active Directory server

To change the Kerberos server name field in FirePass to match the Full computer name configured on the Active Directory server, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. From the navigation panel, click Users.
  3. Click Groups.
  4. Click Master Groups.
  5. From the Master Groups page, click the group name that contains the user account that is experiencing the password issue.
  6. Click the Authentication tab.
  7. In the Kerberos server name (optional) field, enter the fully qualified host name that matches the Full computer name configured on the Active Directory server.

    Important: FirePass must be able to resolve the host name in DNS in order to communicate with the Active Directory server.
  8. Click the Save Settings button.
