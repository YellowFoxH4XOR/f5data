Security Advisory Description

OpenSSL through 1.0.2h incorrectly uses pointer arithmetic for heap-buffer boundary checks, which might allow remote attackers to cause a denial of service (integer overflow and application crash) or possibly have unspecified other impact by leveraging unexpected malloc behavior, related to s3_srvr.c, ssl_sess.c, and t1_lib.c. (CVE-2016-2177)

Impact

This vulnerability may allow remote attackers to cause a denial-of-service (DoS) attack.

Security Advisory Status

F5 Product Development has assigned IDs 600223, 600232, 600248, and 600257 (BIG-IP), ID 600379 (BIG-IQ), ID 600381 (Enterprise Manager), LRS-60816 (LineRate), ID 611333 (F5 iWorkflow), and ID 410742 (ARX) to this vulnerability. Additionally, BIG-IP iHealth may list Heuristic H603174 on the Diagnostics > Identified > Medium page.
