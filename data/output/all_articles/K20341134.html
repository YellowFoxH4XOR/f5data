Description
Config sync is failing with
Summary : A validation error occurred while syncing to a remote device
Details : Caught configuration exception(0), Failed to Sync Files..

Environment

  • Configsync
  • APM not provisioned, but once was.

Cause
APM was once provisioned, but is no longer provisioned. The epsec part of the APM config is still present but the related files have been removed.

Recommended Actions

The config is looking for the existence of files in order to do the config sync, however it does not intend to use them.
Empty files can be created to allow the config to be sync'd even though they will not be used.
  1. Open a connection to the bash CLI of the BIG-IP.
     
  2. Run the following command to check what files are wanted but are missing.
    grep epsec /config/bigip.conf
    apm epsec epsec-package /Common/epsec-1.0.0-810.0.iso {
        cache-path /config/filestore/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-810.0.iso_61099_1
    apm epsec epsec-package /Common/epsec-1.0.0-170.0.iso {
        cache-path /config/filestore/files_d/Common_d/epsec_package_d/:Common:EPSEC:Images:epsec-1.0.0-170.0.iso_17197_1
    apm epsec epsec-package /Common/epsec-1.0.0-1770.iso {
        cache-path /config/filestore/files_d/Common_d/epsec_package_d/:Common:EPSEC:Images:epsec-1.0.0-177.0.iso_17199_1
    apm epsec epsec-package /Common/epsec-1.0.0-343.0.iso {
        cache-path /config/filestore/files_d/Common_d/epsec_package_d/:Common:EPSEC:Images:epsec-1.0.0-343.0.iso_31672_1
     
  3. The output shows that the files are listed in /config/filestore/files_d/Common_d/epsec_package_d
    Navigate to  /config/filestore/files_d/Common_d/epsec_package_d with the following command:
    cd /config/filestore/files_d/Common_d/epsec_package_d
     
  4. If the location does not exist, then create it with the following command:
    mkdir -p /config/filestore/files_d/Common_d/epsec_package_d
     
  5. Create blank copies of the missing epsec files using the following method.
    For example, a missing file is /config/filestore/files_d/Common_d/epsec_package_d/:Common:EPSEC:Images:epsec-1.0.0-343.0.iso_31672_1
    Take the full filename at the end of the path and create the file using the touch command:
    touch ":Common:EPSEC:Images:epsec-1.0.0-343.0.iso_31672_1"
     
  6. Repeat the touch command for each of the missing epsec files.
     
  7. You should now be able to perform a config sync without error.
     
It is OK to leave the empty file there, they will be quite harmless and will not impact your configuration. 

 

Additional Information
If you later provision APM on your BIG-IP again, you will need to ensure that you install a valid epsec file on your system.
