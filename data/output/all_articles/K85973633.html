Environment

  • BIG-IP HA deployed in Amazon Web Services (AWS)
  • Failover results in error
  • The BIG-IP VE fails to failover traffic after forcing the active to standby.

Cause

Amazon Web Services (AWS) added a token-based Instance MetaData Service API (IMDSv2). Prior versions of BIG-IP Virtual Edition supported only a request/response method (IMDSv1). The latest version of BIG-IP Virtual Edition now supports instances started with IMDSv2.

Recommended Actions

With the latest version of BIG-IP VE, for example 15.1.5.1 or 16.1.2.1, you can now initialize IMDSv2 only instances in AWS and migrate your existing instances to IMDSv2 only using aws-cli commands.

For more information including the BIG-IP versions that support IMDSv2, refer to the following:

  • ID968657 on bugtracker
  • Instance Metadata Service Version 2 (IMDSv2) on F5 Cloud Docs
  • Use IMDSv2 in AWS documentation
