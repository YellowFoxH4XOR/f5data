Issue

Error Message

01070151:3: Rule [<iRule name>] error: <iRule name>:<line number>: error: [ltm_rule_dns_write feature not licensed]<iRules command error>

In this error message, note the following:

  • <iRule name> is the full path of the name of the iRule, for example: /Common/myiRule.
  • <line number> is the line in which the iRules command is reported to be in error.
  • <iRules command error> is the iRules command error.

01070151:3: Rule [/Common/MyExampleDNSQuery] error: /Common/MyExampleDNSQuery:3: error: [ltm_rule_dns_write feature not licensed][DNS::header rcode NOERROR]

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility
  • The TMOS Shell (tmsh)

Description

This message occurs when one of the following conditions is met:

  • You attempt to save a configuration that contains an iRules command requiring a feature from the BIG-IP DNS license to a UCS backup file. 
  • You attempt to use tmsh to load or verify a configuration that contains an iRules command requiring a feature from the BIG-IP DNS license, for example : tmsh load sys config verify.
  • You attempt to create an iRule containing an iRules command that requires a feature from the BIG-IP DNS license using either tmsh or the Configuration utility.

Impact

  • You are unable to save to a UCS backup.
  • You are unable to load or verify your configurations. 
  • You are unable to create an iRule.

Recommended Actions

If you require use of the BIG-IP DNS feature in question, you need to obtain an appropriate license. For more information, contact your F5 sales representative.

To continue to load or verify or save the configuration, you must identify the iRule in question and remove the iRule, as well as related configuration manually. To do so, perform the following procedure:

Impact of procedure: F5 recommends that you perform this procedure during a scheduled maintenance window. Prior to manually editing any configuration file, you should ensure that you have created a backup copy of the configuration file in a secure location.

  1. Log in to the command line of the affected system.
  2. Using a text editor of your choice, for example vi, edit the configuration file /config/bigip.conf.
  3. Locate the affected iRule configuration and remove it.
  4. Locate any other configuration related to the iRule and edit it. For example, remove the affected iRule from an associated virtual server.
  5. Save the changes and exit the text editor.
  6. Verify the configuration using tmsh by typing the following command: 

    tmsh load sys config verify

  7. After the verification completes without errors, load the configuration by typing the following command:

    tmsh load sys config
