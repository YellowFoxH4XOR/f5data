Known Issue

The BIG-IP Edge Client might log erroneous log messages regarding a missing session cookie.

This issue occurs when all of the following conditions are met:

  • You use the BIG-IP Edge Client for Windows to establish an access session.
  • You view the BIG-IP Edge Client log of the user device.

Impact

The system logs repeated informational-level parser error messages.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you view the BIG-IP Edge Client user device log, you observe a repeated error message similar to the following example in the logterminal.txt file:

    Info <date and time>   APPCTRL\uhttpparser.cpp, UHttpParser::GetCookie, Cookie F5_ST not set

    Note: You can safely ignore the error message; it is due to a non-existent session cookie.
