Known Issue

This is the result of a known issue. If you configure FTP or SCP log archival on the Device Management : Maintenance : Logs page, and the FTP or SCP username you configure contains a backslash ( \ ) character, log archival fails. This issue occurs because FirePass adds an additional backslash character for each backslash character you entered in the User field, causing FirePass to contact the FTP or SCP server with an invalid username.

F5 Networks Product Development tracked this issue as CR98023 and it was fixed in FirePass version 6.0.3. For information about upgrading, FirePass Release Notes.

This issue still exists in the FirePass version 5.x branch.

Additionally, cumulative hotfix HF-602-5 has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
