Known Issue

This is the result of a known issue. The Configuration utility may display truncated trunk names when creating or editing a VLAN.

When you create a trunk, the BIG-IP system does not impose any limits on the length of the name you can give the trunk. For example, you would be able to create the following trunks:

production-trunk-internal
production-trunk-external

However, when creating or editing a VLAN, trunk names that are too long to fit in the Untagged, Available or Tagged select boxes will display truncated. For example, the trunks from the above example would appear similar to the following example:

production-tru
production-tru

Note: Generally, a trunk name is truncated after 13 or 14 characters, depending on the actual trunk name and the BIG-IP software version.

Due to this issue, it may be impossible to identify the trunks in the list.

F5 Product Development tracked this issue as CR136089, and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, APM, GTM, Link Controller, WebAccelerator, WAN Optimization, or Edge Gateway release notes.

Workaround

You can work around this issue by either creating trunks with shorter names or using the bigpipe utility from the command line to associate the correct trunk to a VLAN.
