Topic

Summary

The ARX system does not support encrypted file systems (EFS).

Description

EFS is a feature that provides file system-level encryption. The technology enables transparent encryption of files, in order to protect confidential data from attackers with physical access to the computer. When you use ARX as a managing system for filer stored data, the system uses an administrative user for all migration and policy level work, and it would not have the access rights to the EFS files.

The ARX system filters out undesirable attributes in file operations and directly rejects files that have those specific file attributes set, which includes EFS, to prevent the ARX system from handling the data requests improperly.

Recommendations

When planning an ARX managed volume, you will need to disable encryption for all shares that the ARX system will be managing. If the encryption is not disabled, the import will fail.
