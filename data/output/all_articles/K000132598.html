K000132598: Stats received from BIG-IQ are in wrong interval

Type
Support Solution
Published
2023-02-21
Updated
2024-07-04
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.0, 8.2.0, 8.1.0
Source
https://my.f5.com/manage/s/article/K000132598

Description

Wrong data intervals returned in output while pulling stats from BIG-IQ when using Metric query 

Environment

  • BIG IQ VE CM
  • Metric query
  • Statistics

Cause

Retention time configuration

Recommended Actions

Statistics real-time (raw) data is stored for 10 hours by default.
Increase the "Keep real-time (raw) data" value for desired time period (see Additional Information below).

Note: Increasing the retention time will increase the load for Elasticsearch on BIG-IQ and use additional disk space.

Additional Information

Manage the retention policy for your statistics data

K34499009: BIG-IQ is not aggregating data as expected
