K000161767: Newly added countries in AWAF/ASM geolocation databases are automatically allowed

Description

In BIG-IP AWAF/ASM, users can configure geolocation enforcement in a security policy to control access to a protected application based on the geolocation of client requests. This geolocation information is based on the GeoIP country list.

During a TMOS upgrade between certain versions, new countries may be added to the geolocation country list in the security policies. Because the default geolocation enforcement behavior allows all countries unless they are explicitly added to the disallowed list, newly added countries are automatically allowed.

For example, after upgrading BIG-IP from 17.1.x to 17.5.x, three new countries/regions, Curacao, Sint Maarten, and South Sudan, are automatically added as allowed.

Environment

  • BIG-IP AWAF/ASM

  • Geolocation enforcement configured in the security policy

Cause

This is expected behavior.

Answer/Recommended Actions

If the user applies an allow-only geolocation enforcement model, for example, allowing only clients from specific countries to access the application protected by the security policy while restricting all other countries, they should review the geolocation country list after an upgrade.

If new countries are added to the geolocation database during the upgrade, those countries may be allowed by default. The user should manually change them to disallowed after the upgrade if access from those countries should be blocked.
