Description
Deleting a login ID cookie information upon log out of the session via iRule is not working as expected. 
As a result, an error message "403 forbidden" page is presented instead of the login screen. 

Environment

  • iRule 
  • Set-cookie with a specific URL 
  • Delete Original Cookie

Cause
If the Set-Cookie from the server originally has a domain and path set, but the Set-Cookie which later attempts to delete that cookie has no specific domain or path, most browsers will not 'overwrite' or 'delete' the original cookie.

Recommended Actions

To work around the issue, fix the "Set-Cookie" line in iRule to ensure it matches the domain and path of the original cookie when attempting to delete a cookie.
