K13527565: Bot Defense blocking legitimate traffic - Suspicious HTTP Headers Presence or Order

Type
Support Solution
Published
2021-01-27
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.X.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K13527565

Description

Bot Defense blocks legitimate traffic with the following Detected Anomaly shown in the logs:

Suspicious HTTP Headers Presence or Order

This always happens on the same resources on the page, for example, requests for CSS or JavaScript.

Environment

  • Bot Defense
  • Web Acceleration profile applied to virtual server

Cause

HTTP version in request changed to HTTP/1.0 by Web Acceleration profile before Bot Defense processing

Original request:

GET /api/Settings/Test HTTP/1.1

With Web Acceleration profile:

GET /api/Settings/Test HTTP/1.0

Bot Defense allocates the request a high suspicious score, since all current browsers use a minimum of HTTP/1.1.

The request will be blocked and the Suspicious HTTP Headers Presence or Order anomaly will be raised if the calculated score for a request is greater than:

sys db botdefense.suspicious_jsfree_score {
    default-value "49"
    scf-config "true"
    value "49"
    value-range "unsigned_integer min:0 max:1000"
}

Recommended Actions

Review the request in the Bot Defense logs to first confirm if this is the root cause - if the request line shows HTTP/1.0, this is likely the issue.

There are three different solutions you can consider:

A) Remove the Web Acceleration profile from the virtual server to ensure the HTTP/1.1 version is kept in the requests.

Note: Responses will no longer be cached on the BIG-IP.

B) Increase the value of botdefense.suspicious_jsfree_score - this will prevent the request being blocked unless additional tests fail in the request and the score is greater than the configured value. For example:

tmsh modify sys db botdefense.suspicious_jsfree_score value 70

Note: This is generally not recommended as genuinely malicious clients would also need to receive a higher score in order to be blocked.

C) Upgrade. In BIG-IP 15.0.0 and later, HTTP/1.1 (or later) is maintained on the server side when Web Acceleration is enabled on a virtual server.

Additional Information

The HTTP version test is a JavaScript-free test that is performed by Bot Defense to verify legitimate browsers.
