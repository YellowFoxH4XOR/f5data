Known Issue

This is the result of a known issue. While using Linux and Mac OS X client workstations with FirePass, you may be prompted to install client components that are already installed on the FirePass. The message states that it is performing a new installation; however, FirePass is just upgrading the software.

F5 Networks Product Development is tracking this issue as CR117523.
