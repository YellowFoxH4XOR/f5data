K000135405: Re-starting localdbmgr continually showing up on device after upgrade

Type
Support Solution
Published
2023-07-06
Updated
2023-08-08
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000135405

Description

After an upgrade, localdb restarts frequently. Next log is shown under /var/log/apm

 

bigip1 localdbmgr[10899]: 01ab0032:3: Unable to open the file '/var/apm/localdb/response', errno 13

 

Environment

  • BIG-IP Upgrade

 

Cause

Bug ID 1044281

 

Recommended Actions

After booting into the affected boot location, force an SELinux relabeling:
 

Impact of workaround : The BIG-IP will be rebooted,  so please perform in a maintenance window.
 

# touch /.autorelabel && reboot

 

Additional Information

None
