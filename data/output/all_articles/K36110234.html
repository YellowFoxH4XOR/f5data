Topic

This article applies to BIG-IQ systems. For information about changing the default boot image on VIPRION systems, refer to the following article:

  • K9296: Changing the default boot image location on VIPRION platforms

You should consider using these procedures under the following condition:

  • You want to change the default boot image for your BIG-IQ system.

Description

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have administrative access to the BIG-IQ system.

The BIG-IQ system allows you to create multiple boot images, each containing a specific software image and configuration. When you select a new default boot image and restart the system, the BIG-IQ system uses the new boot image to start the system. You can use one of the following methods to change the BIG-IQ system's default boot image:

  • The BIG-IQ user interface
  • The TMOS Shell (tmsh)
  • The switchboot utility

Procedures

Use one of the following procedures to change the BIG-IQ system's default boot image.

Impact of procedure: F5 recommends performing these procedures during a maintenance window because the procedures involve restarting the BIG-IQ system.

  • Changing the default boot image using the BIG-IQ user interface
  • Changing the default boot image using tmsh
  • Changing the default boot image using the switchboot utility

Changing the default boot image using the BIG-IQ user interface

BIG-IQ 5.2.0 and later

  1. Log in to the BIG-IQ system user interface.
  2. Select the System tab.
  3. Expand THIS DEVICE.
  4. Select General Properties.
  5. Select Edit.
  6. Under Localhost Volumes, use the Boot Locations list to select the default boot image.
  7. Select Reboot to change to the new default boot image and restart the system, or select Save & Close to only change the default boot image.

BIG-IQ 5.0.0 through 5.1.0

  1. Log in to the BIG-IQ system user interface and navigate to the System Management page.
  2. Under Device Name, select the hyperlink for the local BIG-IQ system.
  3. Under Localhost Volumes, use the Boot Locations list to select the default boot image.
  4. Select Reboot to change to the new default boot image and restart the system, or select Save to only change the default boot image.

Changing the default boot image using tmsh

  1. To log in to the BIG-IQ system tmsh, enter the following command:

    tmsh

  2. To determine the current default software slot, enter the following command:

    show sys software status

    The following example command output shows the Active and default boot location is HD1.4:

    --------------------------------------------------------
    Sys::Software Status
    Volume  Product  Version     Build  Active    Status
    --------------------------------------------------------
    HD1.1    BIG-IQ    5.3.0  0.0.1119      no  complete
    HD1.2    BIG-IQ    5.1.0   0.0.628      no  complete
    HD1.3    BIG-IQ    5.2.0  0.0.5741      no  complete
    HD1.4    BIG-IQ    5.4.0  0.0.7437     yes  complete
     
  3. To change to the new default boot image and restart the BIG-IQ system, use the following command syntax:

    reboot volume <location>

    For example, to set the default boot image to the HD1.1 partition and restart the BIG-IQ system using the BIG-IQ 5.3.0 boot image, enter the following command:

    reboot volume HD1.3

Changing the default boot image using the switchboot utility

  1. Log in to the command line of the BIG-IQ system.
  2. To use the switchboot utility, enter the following command:

    switchboot

  3. The current default boot image is indicated with (default). Use the Up Arrow key or Down Arrow key to select the new default boot image. Ensure the cursor is blinking over OK. Use the Left Arrow key or Right Arrow key for selection.
  4. To use the new boot image and restart the BIG-IQ system, press Enter.
