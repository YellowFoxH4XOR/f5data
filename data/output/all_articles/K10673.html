Known Issue

This is the result of a known issue. If you add a CNAME record for an existing wide IP hostname, the BIG-IP GTM returns only the CNAME record and no A records in response to a query for the CNAME record.

For example, consider a wide IP called bigip-1.test.askf5.net that references a pool containing two virtual server members. If you use the ZoneRunner utility to create a CNAME record for bigip-1.test.askf5.net called www.test.askf5.net, the BIG-IP GTM will return only the CNAME record and no A records in response to a query for the CNAME record. This is displayed in the following dig command output:

dig @10.10.63.1 www.test.askf5.net

; <<>> DiG 8.3 <<>> @10.10.63.1 www.test.askf5.net
; (1 server found)
;; res options: init recurs defnam dnsrch
;; got answer:
;; ->>HEADER<<- opcode: QUERY, status: NOERROR, id: 32051
;; flags: qr aa rd ra; QUERY: 1, ANSWER: 1, AUTHORITY: 1, ADDITIONAL: 0
;; QUERY SECTION:
;; www.test.askf5.net, type = A, class = IN

;; ANSWER SECTION:
www.test.askf5.net. 1m30s IN CNAME bigip-1.test.askf5.net.

;; AUTHORITY SECTION:
test.askf5.net. 8m20s IN NS gtm.askf5lab.net.

;; Total query time: 3 msec
;; FROM: router.askf5lab.net to SERVER: 10.10.63.1
;; WHEN: Wed Dec 30 11:31:23 2009
;; MSG SIZE sent: 33 rcvd: 93

Note: Returning only the CNAME record without the corresponding A records in the response conforms to the specification defined in RFC1034 and does not prevent the DNS resolution from working properly; however, it adds latency to the DNS lookup. When the LDNS server receives the response containing the CNAME record, it must subsequently re-query the BIG-IP GTM for the corresponding A records.

Workaround

You can work around this issue by using the ZoneRunner utility to remove the CNAME record from BIND, and then using the BIG-IP GTM Configuration utility to add the name as an alias for the wide IP. To add an alias for the wide IP, perform the following procedure:

  1. Log in to the BIG-IP GTM Configuration utility.
  2. Click Global Traffic.
  3. Click Wide IPs.
  4. Click the wide IP for which you want to create an alias.
  5. Enter the name you used for the CNAME record in the Alias box.
  6. Click Add.
  7. Click Update.
