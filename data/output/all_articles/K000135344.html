K000135344: How to allow only a specific pattern/value in parameter

Description: 

In certain scenarios you may want to permit only specific value in the parameter and block anything else. To achieve that please check the following steps.

Environment

  • You have at least admin privileges.
  • You have GUI access of BIG-IP ASM/Advanced WAF
  • ASM/Advanced WAF should be provisioned.
  • You already have ASM Security Policy
  • You already know the parameter and security policy name.

Cause

Allow only a specific pattern/value in parameter

 

Recommended Actions

  1. Login to GUI of BIG-IP ASM/Advanced WAF
  2. Go to Security > Application Security > Parameters > Parameters List. Make sure you are making changes for the correct security policy.
  3. Click on the parameter for which you would like to do whitelisting.
  4. Click on data type and enable regular expression.
    Note: this option is only available if you select Data type as Alpha-Numeric
  5. Enter the regex to allow the required input.
    For example if you would like to allow any number starting with +1 or 1, then you may use a simple regex ^(\+?1).*
  6. Click update, To avoid any false positive, for testing purpose you may enable perform staging on the parameter and once the testing is done you may disable staging.
  7. Next to go to Security > Application Security > Policy Building > Learning and Blocking Settings. Make sure you are under correct security policy.
  8. Under Parameter, enable Learn, Alarm and Block for  “Parameter value does not comply with regular expression” 
  9. Save and Apply the policy.
