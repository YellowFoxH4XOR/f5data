Description
When connecting to a TLS Virtual Server the browser reports Connection Reset. A traffic capture shows that the TLS handshake completes correctly, followed by a RST.

Environment
Any Virtual Server with a Client SSL profile.


Cause

The Virtual Server does not attempt to connect to a pool member until the client TLS handshake is complete.
If it cannot start the server side, the virtual server will reset the client side TCP connection.

Recommended Actions
  •     Check that the pool is available.
  •     Check the server side networking. Snat or Snat Automap  is commonly required.

Additional Information

None.
