Known Issue

The BIG-IP ASM bd process may restart and produce a core file. This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM security policy is configured to enforce path parameter security.
  • The BIG-IP ASM system processes a request with path parameter.

Impact

The BIG-IP ASM system temporarily fails to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM system generates a bd core file to the /shared/core directory.
  • The BIG-IP ASM system sends a SIGSEGV to the BIG-IP ASM bd process and logs a message similar to the following example to the /var/log/ts/bd.log file:

    BD_MISC|CRIT |13693|signals.c:0075|Received SIGSEGV - Core Dumping
