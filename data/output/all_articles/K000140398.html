Description

BIG IP shows "Changes Pending" while no configuration changes done.  

Environment

  • BIG IP HA
  • ASM

Cause

ASM Live Update file is downloaded or installed and cause the BIG IP to show with "Changes Pending".  This behavior is expected.

Recommended Actions

None.

Additional Information

The behavior is similar to K92462725 but caused by Live Update.

On Active device Bigip1,  from asm and liveupdate logs,  we can see that Browser updates were downloaded and applied on Jun 24 22:10:25.
