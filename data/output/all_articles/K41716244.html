K41716244: ''Error while transforming Access Policy Item, exception 'NullPointerException' was returned'' when discovering Access service on BIG-IQ

Type
Support Solution
Published
2021-09-16
Updated
2023-10-16
Applies to
  • BIG-IQ
  • F5 App Protect
  • F5 SSL Orchestrator: 15.1.X, 15.1.1, 15.1.0
Source
https://my.f5.com/manage/s/article/K41716244

Description

Attempting to discover a BIG-IP device that is provisioned for SSL Orchestrator, on a BIG-IQ fails with the following error:

 Error while transforming Access Policy Item, exception 'NullPointerException' was returned


from /var/log/restjavad.0.log, we can see logs similar to the following:

[ERROR][30 Aug 2021 17:24:06 PST][/cm/access/tasks/discover-config/ef88e24a-26dd-453a-8cd3-6570ad145a3c/worker AccessDiscoveryTaskWorker] Error while transforming Access Policy Item, exception 'NullPointerException' was returned : java.lang.NullPointerException

Environment

  • BIG-IQ v7.1.0
  • BIG-IP SSLO v15.1.x (rpm 7.4.x or 7.5.x)

Cause

Unknown at time of publication

Recommended Actions

To workaround this issue, delete the "Abort" ending in the affected Per Request Policy (PRP)

1. log in to the Configuration utility
2. navigate to SSL Orchestrator  ››  Configuration and then click on the 'Security Policies' menu
3. click the padlock icon to unprotect the configuration (if it is locked)
4. under the Per Request Policies column, click the desired PRP. This will open the Virtual Policy Editor (VPE) for the PRP
5. once inside the PRP VPE: click the "Edit Endings" button, locate the "Abort" ending and then delete it by clicking the corresponding "x" button. Click Save.

now when you attempt to discover the Access service on the SSLO device from the BIG-IQ, it should now be successful.
