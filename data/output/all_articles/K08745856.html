Description

iRule with HTTP::payload and HTTP::collect attributes applied to handle double POST  requests using chunked transfer encoding coming over the same TCP session can cause iRule execution errors and connections drops.

 /var/log/ltm  :

01220001:3: TCL error: /Common/My_iRule <HTTP_REQUEST_DATA> - Expired (line 2) invoked from within "HTTP::payload"

Packet capture RST cause:

F5RST(peer): iRule execution error]

Environment
  • BIG-IP LTM
  • iRules
  • chunked transfer encoding
  • TCP
  • HTTP POST

Cause

Possible cause related to BUG ID 473787 and   ID 745291

Recommended Actions

  1.  Perform one POST request per TCP session or ,
  2. Upgrade to 15.0.0 or above which includes a fix for BUG ID 473787 and  ID 745291
