Known Issue

This is the result of a known issue. When the MultiConnect feature on the BIG-IP WebAccelerator system is enabled, clients will receive HTTP 404 errors for objects containing double period ( .. ) characters in their path or filename. This issue occurs because the BIG-IP WebAccelerator will drop the double period characters from the path or filename when parsing the object.

The following example displays the double period character in the filename before the MultiConnect feature is enabled:

<html>
<head/>
<body>
<img src="/foo_bar/foo_bar_image..gif"/>
</body>

The following example displays the dropped double period characters after MultiConnect is enabled:

<html>
<head/>
<body>
<img src="http://wa1.www.site.com/foo_bar/foogif"/>
</body>

F5 Networks Product Development tracked this issue as CR119112 and it was fixed in BIG-IP WebAccelerator version 10.0.1. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.
