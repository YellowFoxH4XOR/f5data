Environment

  • APM devices 
  • HA Sync 

Cause

Missing files in directory path /config/filestore/files_d/Common_d/external_monitor_d/

Recommended Actions

To work around this issue and restore functionality, perform one of the following actions depending on the situation:

Option 1 :
If a referenced file has been deleted, identify the missing file from the mcpd log messages and manually restore the missing file (e.g., from a backup copy, or via scp from another member of the HA group from which the file has not been deleted).

For example from above logs we need to copy files :Common:f5-iappslx-agc-usecase-pack-8.0-0.0.1563.tar.gz_122321_1 and :Common:f5-iappslx-agc-usecase-pack-8.0-0.0.1563.tar.gz.md5_122322_1 from backup or another member in HA to the device which has these files missing in /config/filestore/files_d/Common_d/external_monitor_d/: directory

Option 2 :
If a configuration being loaded references a file that does not exist on the system, either remove the file reference from the configuration or copy/install the file onto the target system before loading the configuration.

Note : It is recommended to run these steps during a maintenance window.

1. Take a UCS backup refer K13132

2. Edit /config/bigip.conf to remove the file references that do not exist on the system.

For example , remove the whole config below :

sys file external-monitor /Common/f5-iappslx-agc-usecase-pack-8.0-0.0.1563.tar.gz {
    cache-path /config/filestore/files_d/Common_d/external_monitor_d/:Common:f5-iappslx-agc-usecase-pack-8.0-0.0.1563.tar.gz_122321_1
    revision 1
}

3. Verify if config load is working by running "tmsh load sys config verify"

4. Try config sync now
