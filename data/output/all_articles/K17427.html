Issue

Error Message

Error Message: 01071466:3: The configsync and management IP addresses cannot be the same

Message Location

You may encounter this message in the following locations:

  • The serial console
  • The /var/log/ltm file

Description

This message occurs when the following conditions are met:

  • You use the Traffic Management Shell (tmsh) to configure the configuration synchronization (ConfigSync) IP address, and attempt to use the management IP address without first enabling the configsync.allowmanagement database variable.
  • You save a single configuration file (SCF) or user configuration set (UCS) file on a BIG-IP system that is configured to perform ConfigSync operations by using the management IP address, and install the SCF or UCS file on a BIG-IP system that has the configsync.allowmanagement database variable set to disable.

By default, the management address is unavailable for ConfigSync/device clustering communication.

Impact

If you save an SCF or UCS file on a BIG-IP system that is configured to perform ConfigSync operations by using the management IP address, and install the SCF or UCS file on a BIG-IP system that has the configsync.allowmanagement database variable set to disable, the ConfigSync operation will fail and the configuration may fail to load.

Recommended Actions

Enabling the configsync.allowmanagement database variable on the target BIG-IP system prior to installing the SCF/UCS file

Ensure that you set the configsync.allowmanagement database variable to 'enable' on the target BIG-IP system prior to installing the SCF or UCS file. To do so, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) on the target BIG-IP system by typing the following command:

    tmsh
  2. To enable the configsync.allowmanagement database variable, type the following command:

    modify /sys db configsync.allowmanagement value enable
  3. To load the SCF or UCS file, use either of the following command syntaxes:
    • To load an SCF file:

      load /sys config file <SCF path>
    • To load a UCS file:

      load /sys ucs <UCS path>

Note: You can configure the BIG-IP system to use the management IP address to accommodate device group communication and synchronization by enabling the configsync.allowmanagement database variable. However, F5 recommends using the self IP address on the internal Virtual Local Area Network (VLAN) for ConfigSync traffic.
