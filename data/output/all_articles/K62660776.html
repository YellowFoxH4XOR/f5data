Description
This article explains how to open and run  OPSWAT diagnostic tools in MacOS.
For endpoint inspection of devices connecting to BIG-IP APM, F5 uses a third party library (OESIS SDK) supplied by OPSWAT.
Note: F5 users should contact F5 Support for issues with these libraries, not OPSWAT.

Environment

  • APM Endpoint Inspection
  • OPSWAT OESIS Diagnose tool
  • MacOS

Cause
The folders at the top level in the EPSEC release iso image are hidden (they start with a dot or period).

Recommended Actions

Once downloaded the epsec<version>.iso from myDownloads.f5.com, follow next steps to mount, show hidden files and run the diagnose tools. 

  1. Right click in epsec<version>.iso
    Then go to "Open with" > DiskImageMounter
  2. Then an empty CDROM window should come up in the finder.
  3. Inside the blank CDROM window do CMD + Shift + .       <-- last one is a dot (.) and "unhides" the hidden files
  4. Hidden files will appear (in light grey)
  5. Open the .Tools directory
  6. Copy the directory 'Mac' to a local directory (for example the desktop)
    The steps above can be replaced with the terminal command
    cp /Volumes/CDROM/.Tools/Mac  ~/Desktop/ 
  7. In the current local directory, open the Mac directory
  8. In the now local directory, Unzip OESISDiagnose_V4.tar, this will contain an executable named 'waDiagnose' and some library files
  9. These executable files can be run by double clicking, or Right click then select go to "Open with" > Terminal
    Note that these files will be marked as "unsafe" by the Apple Security Quarantine system.
    In the terminal run the following command to mark them as "Safe"
    cd ~/Desktop/
    sudo xattr -d com.apple.quarantine *
  10. The executables will create an output file inside the same directory. The waDiagnose executable creates a new numbered file (the number is the current unix time) like 'WaDiagnoseResults_163000000.txt' each time it is run. 
  11. To run the commands as root (administrator) drag the executable to a terminal window and prefix with the 'sudo ' command, for example 
      sudo Desktop/Mac/OESISDiagnose_V4/waDiagnose
    Detection of some endpoint products like Firewalls and anti-malware devices require privileged user access, when opening a case you should provide copies of the diagnostic text data both as user and root each time.
