Known Issue

This is the result of a known issue. Configuring a fixed media setting for a BIG-IP interface and then changing the setting may result in the changes not taking effect.

For example, if a BIG-IP interface is set to a fixed media type, such as 1000baseT full, the setting will appear similar to the following example in the bigip_base.conf file:

interface 1.8 { media fixed 1000baseT full}

If you manually edit the bigip_base.conf file to remove the media fixed line and then load the configuration, the changes do not take effect and the media setting remains at the fixed value.

F5 Product Development tracked this issue as CR126034 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WOM release notes.

Workaround

You can work around this issue by changing the interface to the desired media setting using either the Configuration utility or the bigpipe command.
