K000151813: OpenSSL version running on BIGIP does not support TLS1.3

Type
Support Solution
Published
2025-06-20
Updated
2025-06-20
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000151813

Description

OpenSSL 1.0.2za-fips is running on BIG IP systems. Attempts to establish TLS 1.3 connections with certain third-party applications may fail because the current OpenSSL version which is OpenSSL 1.0.2za-fips running on BIG IP systems does not support TLS 1.3 and there is no option to upgrade OpenSSL on BIG IP system. The OpenSSL 1.1.1 release includes support for TLSv1.3. The error may be observed as the inability to negotiate a TLS 1.3 session and using the command openssl s_client -tls1.3 -connect <host> on the BIG-IP system may return an "unknown option -tls1.3" error.

Environment

  • BIG-IP LTM
  • OpenSSL 1.0.2za-fips
  • TLS 1.3

Cause

OpenSSL 1.0.2za-fips running on BIG IP systems does not support TLS 1.3.

Recommended Actions

BIG-IP systems use two separate SSL/TLS stacks:

The system (control plane) uses OpenSSL 1.0.2za-fips, while the traffic management microkernel (TMM, data plane) uses an internal F5 SSL stack, which is capable of supporting TLS 1.3 for virtual server traffic processing.

The OpenSSL version visible on the system is only relevant for control plane operations and not for traffic processing. The TMM’s internal SSL stack is responsible for negotiating TLS 1.3 with clients, independent of the system OpenSSL version.

When configuring a virtual server to offer TLS 1.3, the TMM process leverages this internal SSL stack to negotiate and establish TLS 1.3 sessions. The TMM does not use the system OpenSSL libraries for traffic processing; instead, it uses its own libraries, which are updated and maintained by F5 to support the latest protocols and ciphers, including TLS 1.3.
