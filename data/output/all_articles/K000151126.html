Description

Change the default BIOS Boot Order Media on a BIG-IP Appliance through Console access.

Environment

  • BIG-IP Appliance
  • Boot Order Media
  • USB Drive

Cause

The default boot order prioritizes USB drives over the internal media.

Recommended Actions

Follow the below procedure to change the boot priorities while USB key is connected.

  • Reboot the appliance while the USB Key is connected.
  • When the BIOS message appears, press 'c' to enter the BIOS.

Note: unlike other hardware, there is no "press F11 for boot device"

  • Use the keyboard arrow keys to go to the “boot” options in the BIOS menu.
  • Change the boot order, giving internal device the highest priority.
  • Use the menu option to "save config and exit".

Note: Do not press F4.

  • The device will boot to TMOS.
