Topic

To access the Configuration utility, perform the following steps:

  1. On the BIG-IP Controller, point your browser to the following address:

    https://<ip address of the BIG-IP Controller>

  2. When prompted, type the user ID and password you set during the installation process.

Note: For BIG-IP version 4.5, the user ID is set to admin by default during the installation process. Refer to the BIG-IP Reference Guide for more information about user ID and passwords.
