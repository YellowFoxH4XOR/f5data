K5140: Microsoft SharePoint may request reauthentication or fail to display pages when used through BIG-IP

Topic

Microsoft SharePoint is not fully compliant with the HTTP standard (RFC2616). When the BIG-IP system treats SharePoint connections as normal HTTP, any of the following issues may occur:

  • Initial authentication may fail.
  • SharePoint may require the user to reauthenticate frequently.
  • Pages may not be displayed.
  • Components of pages may not be displayed.

F5 Product Development has made two changes to the product to improve compatibility with Microsoft SharePoint. One of these changes is included in BIG-IP LTM 9.1.1 all later releases, and the other is in BIG-IP 9.2 and all later releases. For information about upgrading, refer to the BIG-IP LTM Release Notes.

For additional information about the changes that were made to the BIG-IP system improving compatibility with Microsoft SharePoint, refer to the following articles:

  • K5038: BIG-IP may remove data from an HTTP 304 (redirect) message
  • K5050: OneConnect may prevent NTLM authentication from succeeding
