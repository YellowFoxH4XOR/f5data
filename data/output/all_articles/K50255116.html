Description

  • High CPU on VCMP Host and you are suspecting one of the VCMP Guests causing such.
  • top shows /usr/libexec/qemu-kvm process has been using up high CPU from host
  • There is a need to determine what is the cause and which vGuest may be causing it. 


Environment

  • vCMP provisioned
  • Multi-VCMP Guests type of environment 
     

Cause

    There may be multiple causes. 
    This article is to assist in identifying which vGuest is the top contributor of the High CPU Utilization . 

    Recommended Actions

    1. Checking the top command on vCMP Host
      Example below shows that qemu-kvm processes in core 15 (which run the vCMP guest) is one of the top contributors and points to process ID 21617
