Description

  • I am not receiving any logs from Data Intelligence
  • My Credential Validation for Data Intelligence is failing

Environment

  • F5® Distributed Cloud Console

  • Data Intelligence
  • Splunk Cloud HTTP Event Collector (HEC)

Cause

The issue is caused by an incorrect endpoint configuration in the Data Receiver settings. The Data Receiver may be configured with a path in the endpoint URL (as required by some other integrations like GLR), but for Splunk HEC, only the base endpoint is needed. Including a path causes validation and log delivery to fail. Additionally, if the endpoint is incorrect, token encoding may not be handled correctly by the platform.

Answer/Recommended Actions

Splunk

  • When configuring your Splunk HEC Logs Endpoint, do not include a path (e.g. /services/collector), the Splunk Data Receiver automatically configures the path to /services/collector/event and doing so will result in failures in log delivery
  • When configuring the Splunk HEC Token, do not include the "Splunk" portion of the token:
    • Token you may receive from Splunk: Splunk 3bfde684-b110-5f8c-90ef-28024c9b928g
    • Configure in your Data Receiver as: 3bfde684-b110-5f8c-90ef-28024c9b928g
