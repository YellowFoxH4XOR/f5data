Known Issue

A browser's proxy setting may not be reset when a BIG-IP APM network access session is terminated.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with a network access profile that uses split tunneling.
  • The users are running the Windows operating system.
  • The user established a network access session using the F5 Edge Client.
  • The user abruptly terminated their access session (hard shutdown).

    Note: A hard shutdown may include a reboot or stopping the browser instance or Edge Client process of the established network access session.

Impact

Users are unable to access network resources.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The user's browser proxy settings point to a loopback address for the proxy after the termination of the network access session.

    Following is an example of a BIG-IP APM network access browser proxy automatic configuration script setting:

    https://127.0.0.1:44777

Workaround

To work around this issue, you can manually reset the browser's proxy settings. For information on configuring your browser's proxy settings, refer to browser manufacturer website for your specific browser version.

Impact of workaround: Adding or modifying the proxy settings will impact how the browser connects to the destination resources.

For example, to reset the proxy settings for Microsoft Internet Explorer 8, perform the following procedure:

  1. On the Internet Explorer menu bar, click Tools.
  2. From the Tools menu, select Internet Options.
  3. Click the Connections tab.
  4. Click LAN settings.
  5. Clear the check box for Use automatic configuration script.

    Note: If the environment requires that you use a proxy Automatic configuration script, replace the existing settings with the specific proxy server.

  6. To close the Local Area Network (LAN) Settings pop-up, click OK.
  7. To close the Internet Options pop-up, click OK.
