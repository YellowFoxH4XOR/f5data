K000151234: Environment variables are no longer preserved in njs after upgrading to NGINX Plus R33

Description

Environment variables are no longer preserved in njs after upgrading to NGINX Plus R33.

Environment

NGINX Plus

NJS module

Cause

Prior to njs 0.8.8 (shipped with NGINX Plus R33), environment variables used in njs code were inherited from the parent process. This is no longer the case starting with R33 and later versions. By design, NGINX Plus removes all inherited environment variables by default, except for the TZ variable.

Recommended Actions

Use the env directive to explicitly preserve environment variables after upgrading to R33 or later.
Usage example:

env MALLOC_OPTIONS;
env PERL5LIB=/data/site/modules;
env OPENSSL_ALLOW_PROXY_CERTS=1;

https://nginx.org/en/docs/ngx_core_module.html#env
