Description

BIG-IP Virtual Edition (VE) may not receive ICMPv6 unsolicited neighbor advertisement packets sent by neighbor devices.

Environment

  • BIG-IP VE
  • TMM SR-IOV ports using ixlv or iavf driver (Refer to K17204: BIG-IP VE NIC adapters that support SR-IOV for supported NIC)

Cause

It is due to a known issue ID 1211089 (ixlv) and ID 1293193 (iavf).

Recommended Actions

Upgrade to a version with the fix.

Additional Information

The following commands can be used to determine which device driver TMM is currently using.

# tmctl -d blade tmm/device_probed
# tmctl -d blade tmm/xnet/device_probed

In the following example, tmm/xnet/device_probed table shows driver_selected iavf and driver_in_use Yes, and it indicates TMM is using iavf driver.
