K4366: Reasons why security scanners report that BIG-IP allows traffic from UDP source port 53

Topic

By default, BIG-IP allows traffic to pass from UDP source port 53 through those VLANs on which port lockdown is enabled. BIG-IP must allow this traffic to pass when you configure BIG-IP to:

  • Perform DNS lookups and access a DNS server through a VLAN on which port lockdown is enabled.
  • Use the DNS proxy feature.

If you are not using either of these configurations, you can block this traffic.

Beginning in BIG-IP versions 4.5.13 and 4.6.3, you can configure BIG-IP to reject DNS traffic, by performing the following steps:

  1. Log in to the command line.
  2. Disable the open_dnsproxy_ports global, by typing the following command:

    bigpipe global open_dnsproxy_ports disable

BIG-IP will now reject all traffic from UDP source port 53 to the BIG-IP self address.
