Topic

The honor_vlans or, in BIG-IP version 4.5, vlans lookup, feature lets you include connection information in the VLAN tag within the BIG-IP connection table. This permits traffic with the same source and destination address to pass through BIG-IP several times, but on different VLANs. This is helpful for configurations that require transparent firewalls, proxies or caches that pass the traffic to a back-end node without changing the client or destination IP address.

Note: It is possible to disable this feature; however, at this time, there are no known configurations that would necessitate disabling it. Since disabling this feature makes the BIG-IP unaware of the VLAN, F5 Networks recommends leaving this feature in an enabled state. If you feel that you need to disable this feature for any reason, contact F5 Networks Technical Support for assistance.
