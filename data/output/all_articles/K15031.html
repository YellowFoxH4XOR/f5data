Issue

Error Message

warning: Global concurrent connectivity session limit reached.

For example:

warning tmm1[16201]: 01490508:4: 3b533fac: Global concurrent connectivity session limit reached.

Message Location

You may encounter this message in the following location:

  • The /var/log/apm file

Additionally, users accessing the BIG-IP APM User Connectivity License (CCU) dependent access profile may receive the following related message:

Your session could not be established.

The maximum number of concurrent user sessions has been reached. No new user sessions can start at this time.

Description

This message occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with resources that decrement the available CCUs set in the license.
  • The number of concurrent connectivity sessions exceeds the licensed CCUs.

The BIG-IP APM system CCU provides the maximum number of CCUs (concurrent user sessions for SSL VPN, app tunnels, and portal access) processed by the BIG-IP APM system.

Impact

Users are unable to establish a session with the configured BIG-IP APM access profile resource.

Recommended Actions

F5 recommends that you monitor traffic volumes to proactively manage the license limit. If the rate limit warnings persist, you can contact your F5 Sales Representative about updating the license to allow a higher threshold. Additionally, you can configure the BIG-IP system to send SNMP traps and email messages to a specified address when a message is logged because the system reaches the system license CCU limit.

Note: The SNMP traps regarding BIG-IP APM license limits are handled through the F5-BIGIP-COMMON-MIB.
