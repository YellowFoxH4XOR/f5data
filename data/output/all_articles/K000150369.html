K000150369: How to look for the Request/Support ID using Tenant Search

Type
Support Solution
Published
2025-03-13
Updated
2025-03-13
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000150369

Description

  • You want to look for a Support ID to view more in-depth information about the event
  • You tried to access a URL and got rejected with a warning page and a support ID number
    • The message states: "The requested URL was rejected. Please consult with your administrator. Your support ID is: ..."

Environment

  • F5® Distributed Cloud Console

Cause

None

Answer/Recommended Actions

Once you see the error message, please follow these steps: 

  1. Copy the support ID shown in the error message
  2. Go to Web App & API protection
  3. Select System Namespace > click on Tenant Search 
  4. You will see different options to search for your request using Source IP, Request ID, WAF Exclusion Rule Signature ID, and WAF Exclusion Rule Violation Name across the tenant
  5. Navigate to the specific load balancer to see the log.

Additional Information

Please note that only specific roles are able to view these dashboards.
