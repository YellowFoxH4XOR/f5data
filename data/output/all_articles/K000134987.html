K000134987: Various and numerous messages, in /var/F5/system/log/platform.log, about tcam-manager when the system network changed to RFC1918

Type
Support Solution
Published
2023-06-10

2023-06-10
Applies to
  • F5OS
  • F5OS-A: 1.5.X, 1.5.0
Source

Description

When the rSeries appliance system network is changed to RFC1918, you may see the following records from the /var/F5/system/log/platform.log file:

2023-01-01T12:00:00.475976+00:00 appliance-1 tcam-manager[138]: priority="Info" version=1.0 msgid=0x6b01000000000004 msg="INFO" MSG="Connection from client address:10.224.1.1".

2023-01-01T12:00:00.475997+00:00 appliance-1 tcam-manager[138]: priority="Info" version=1.0 msgid=0x6b01000000000004 msg="INFO" MSG="Converted client IP 0x0ae00101 to tenant id, 12288 0x3000".

2023-01-01T12:00:00.476590+00:00 appliance-1 tcam-manager[138]: priority="Info" version=1.0 msgid=0x6b01000000000004 msg="INFO" MSG="found tenant:, vcpus 1685986493".

2023-01-01T12:00:00.477842+00:00 appliance-1 tcam-manager[138]: priority="Err" version=1.0 msgid=0x6b01000000000007 msg="ERROR" MSG="Service Instance does not exist for 1".

2023-01-01T12:00:00.477868+00:00 appliance-1 tcam-manager[138]: priority="Err" version=1.0 msgid=0x6b01000000000007 msg="ERROR" MSG=" Confd access error obtaining tenant info for tenant:12288 slot:1".

2023-01-01T12:00:00.477877+00:00 appliance-1 tcam-manager[138]: priority="Err" version=1.0 msgid=0x6b01000000000007 msg="ERROR" MSG="neuron_handle_accept: failed to obtain tenant-12288 info from confd.".

2023-01-01T12:00:00.477887+00:00 appliance-1 tcam-manager[138]: priority="Info" version=1.0 msgid=0x6b01000000000004 msg="INFO" MSG="tcam_purge_by_client_id: Purge rules for client 0, tenant 12288".

2023-01-01T12:00:00.482634+00:00 appliance-1 tcam-manager[138]: priority="Info" version=1.0 msgid=0x6b01000000000004 msg="INFO" MSG="neuron_handle_responses: dropping resp to non-existent client".

Environment

rSeries

F5OS-A

Cause

This behaviour is tracked through bugID1304813.

Recommended Actions

While annoying, those messages are not a sign of any difficulty and are harmless.
