Description

Attempts to SCP files to the BIG-IP fail with a strange error like:
 

scp test.iso apiuser@10.201.69.106:/shared/images
Password:
cat: /co: No such file or directory
cat: fig/ssh/scp.whitelist: No such file or directory
"/shared/images/test.iso": path not allowed

 

Environment

  • SCP from a remote host to the BIG-IP

 

Cause

This is due to ID1160805

 

Recommended Actions

You can fix this issue by editing scp-checkfp to change the " to '

[testuser@bigip:Active:Standalone] ~ # su

[testuser@bigip:Active:Standalone] testuser # mount -o remount,rw /usr

[testuser@bigip:Active:Standalone] testuser # vi /bin/scp-checkfp

find the line

        IFS=$"\n"

change it to.  

        IFS=$'\n' # [Change to single quote]

[testuser@bigip:Active:Standalone] testuser # mount -o remount,ro /usr

Note: Modifying /bin/scp-checkfp may cause FIPS validation to fail on some systems.
