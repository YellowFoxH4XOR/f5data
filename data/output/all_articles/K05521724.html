Description


When admin attempt to update signing certificate for IDP service, the assertion fails and following error message appears in the /var/log/apm:

SSOv2 Error creating signed SAML message - cannot init cipher from IDP RSA KEY

Environment

  • APM policy configured
  • SAML federation resources including signing certificate

Cause

The error message "cannot init cipher from IDP RSA" means that the BIGIP was unable to initialize the cipher from the key because it was protected by a passphrase. 

Recommended Actions

You can do either of the below solutions:

1) Remove the passphrase from the key
2) Upload the key together with the passphrase. That is Select the "Password" option instead of "Normal" option when uploading the key.
