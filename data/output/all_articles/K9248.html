There may be occasions when you need to test the validity of the BIG-IP or 3-DNS software license. If the system is properly licensed, the bigpipe version command displays detailed licensing and version information for the BIG-IP system, including a list of licensed features.

For example, the following bigpipe version command output was generated from a BIG-IP version 4.5.13 system with a valid license:

bigpipe version
Kernel:
BIG-IP Kernel 4.5.13 Build86-b
Package:
BIG-IP Version 4.5.13 Build86-d
Global Edition

Product Code:
BIG-IP

Enabled Features:
Direct Node Select                        Expression Persistence
VLAN-Keyed Connection Table               MSRDP Persistence
HTTP Header Insert                        SIP Call-ID Persistence
Dynamic Ratio Load Balancing              HTTP Redirects
Gateway Failsafe                          Static Load Balancing
SNAT                                      NAT
Pools                                     Full Proxy
Probe Control                             HTTP Rules
Mirroring                                 Failover
Node HA                                   Dynamic Load Balancing
Destination Address Affinity              Cookie Persistence
SSL Persistence                           Simple Persistence
EAV                                       ECV SSL
ECV                                       ECV Transparent
Health Check                              Filter

If the system is not properly licensed the bigpipe version command output displays version information for the BIG-IP system, but the list of licensed features is missing.

For example, the following bigpipe version command output was generated from a BIG-IP version 4.6.4 system with an expired license:

bigpipe version
Kernel:
BIG-IP Kernel 4.6.4 Build8
Package:
BIG-IP Version 4.6.4 Build8
Global Edition

Product Code:
(indeterminate)

Enabled Features:

If you determine that the license is expired, or not valid, you may be required to re-install the license. For more information about licensing the BIG-IP system, refer to  K2595: Installing a new license file on BIG-IP or 3-DNS from the command line.
