Known Issue

You are unable to install a hotfix to the Virtual Clustered Multiprocessing (vCMP) guest using the Configuration utility.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is provisioned with vCMP guest slots running on the affected version.
  • The vCMP host system has the valid hotfix image ISO file.
  • You attempt to install the hotfix image to the vCMP guest using the Configuration utility.

Impact

You are unable to install the hotfix to the target vCMP guest.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The hotfix installation on the vCMP guest fails and returns an error message in the Configuration utility that appears similar to the following example:

    Major application error, please see logfile

  • After the hotfix installation fails, the /var/log/webui.log file contains an error message that appears similar to the following example:

    ERROR [TP-Processor1] controller.F5WebController:processWebResponse - response failed, no corresponding entry in responsemappings.xml for:null

Workaround

To work around this issue, you can use Traffic Management Shell (tmsh) to perform the hotfix installation instead of using the Configuration utility. To do so, perform the following procedure:

Impact of workaround: This procedure involves hotfix installation, which can be disruptive in processing traffic on the target vCMP guest. F5 recommends performing this procedure during a scheduled maintenance period.

  1. Ensure that the appropriate hotfix ISO file is already imported into the BIG-IP vCMP host's /shared/images folder. The ISO file will automatically appear on each vCMP guest as available for installation.
  2. Log in to tmsh of the target BIG-IP vCMP guest.

  3. To install the hotfix that is in the target vCMP guest, use the following command syntax:

    install /sys software block-device-hotfix <HF_IMAGE_NAME> volume <VOLUME_NAME>

    For example, to install Hotfix-BIGIP-11.6.0.3.0.412-HF3 onto volume HD1.1, you would type the following command:

    install /sys software block-device-hotfix Hotfix-BIGIP-11.6.0.3.0.412-HF3.iso volume HD1.1
