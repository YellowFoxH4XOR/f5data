Description

After an upgrade the BIG-IP HA peers device group shows the old software versions when looking at the following output:

  • The Configuration utility Device Management > Devices page.
  • The tmsh list cm device command.

Environment

  • BIG-IP
  • HA (device groups)

Cause
BUG ID 406878. For more information refer to K16544: The BIG-IP system may incorrectly display a previous version of BIG-IP installed on other devices.

Recommended Actions

  1. Log in to the Configuration utility for each device in turn.
  2. Navigate to Device Management > Devices.
  3. Click the (Self) device name.
  4. In the Description field, enter text to force the peer to advertise its new information.
  5. Click Update.

Additional Information
This is a cosmetic issue that does not affect system performance.
