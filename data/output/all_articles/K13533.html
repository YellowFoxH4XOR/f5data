K13533: The BIG-IP GTM module can be licensed and provisioned on one of the devices in a redundant pair

Topic

In BIG-IP versions prior to 11.x, if you have a BIG-IP redundant pair configuration in which both units are licensed and provisioned for BIG-IP LTM, and only one of the units is licensed and provisioned for BIG-IP GTM, you must provision the BIG-IP GTM module on both units. Failure to do so may result in the BIG-IP GTM system becoming unprovisioned or unconfigured after a ConfigSync operation. For more information, refer to K12322: Provisioning requirements for BIG-IP redundant pairs in which the BIG-IP GTM module is licensed on only one of the units.

Beginning in BIG-IP 11.x, if you have a mixed redundant pair configuration in which only one of the units is licensed and provisioned for BIG-IP GTM, you no longer need to provision the BIG-IP GTM module on all units. When you perform ConfigSync operations, the provisioning configuration is no longer synchronized to the redundant pair member.

Recommended Actions

None. If you have a mixed redundant pair configuration in which only one of the units is licensed and provisioned for BIG-IP GTM, you are not required to provision BIG-IP GTM on all units.
