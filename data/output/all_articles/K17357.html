Known Issue

The BIG-IP system may drop DNS or sFlow packets.

This issue occurs when a subset of the following conditions are met:

  • You configure a Virtual Local Area Network (VLAN) on the BIG-IP system to use dst-ip or src-ip for Clustered Multiprocessing (CMP) Hash.

    • You configure the BIG-IP system to send performance statistics to an sFlow device.
    • You configure a virtual server that uses an HTTP profile.
    • The virtual server processes HTTP connections.
  • You configure a VLAN to use dst-ip or src-ip for CMP Hash.

    • You configure an iRule to use RESOLV commands.
    • You associate a virtual server with the iRule.
    • The virtual server processes DNS requests.

Impact

The BIG-IP system drops DNS or sFlow packets.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice that some DNS requests fail.
  • You notice that the BIG-IP drops sFlow packets.
