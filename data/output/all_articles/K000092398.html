K000092398: Effect of gzip compression on VPN tunnel traffic

Type
Support Solution
Published
2022-09-28
Updated
2025-12-29
Source
https://my.f5.com/manage/s/article/K000092398

Description

You are trying to calculate the change in traffic (bytes) before or after compression (gzip).

Important: Beginning in APM Clients 7.2.6, BIG-IP network access VPN compression (client and server side) is deprecated. For more information, refer to K000158915: BIG-IP network access VPN compression deprecated from APM Client 7.2.6.

Environment

  • APM provisioned
  • VPN configured

Cause

You are trying to foresee the changes in traffic after enabling or disabling gzip compression for VPN.

 Recommended Actions

None

Additional Information

Unfortunately, it is impossible to foresee the size of a file before or after compression. This is due to the nature of gzip compression algorithm (DEFLATE). The algorithm analyzes the file for reoccurring binary patters and the more a pattern reoccurs the smaller the file can become after compression.

 

If you are interested in learning more about this we recommend looking for information about "data compression".
