K90310819: Display the number of installed power supply units

Published
2022-11-13
Updated
2023-02-21
Applies to
  • VELOS Platforms
Source

Description

To determine the number of installed Power Supply Units, follow the commands listed in the "Recommended Actions" section below.

Environment

  • F5OS-A
  • F5OS-C
  • VELOS Chassis
  • rSeries

Cause

None

Recommended Actions

To determine the number of installed power supply unit ( PSU ) from F5OS-A, login as admin and run the following commands in management CLI:

APPLIANCE-1# show components component psu-1 | include "state empty"
 state empty false
APPLIANCE-1# show components component psu-2 | include "state empty"
 state empty false
APPLIANCE-1# show components component psu-3 | include "state empty"
-----------------------------------------^
syntax error: unknown element

The above shows that there are 2 installed PSU and the third PSU or the PSU slot does not exist.

To determine the number of installed power supply unit ( PSU ) from F5OS-C, run the following commands in management CLI:

syscon-1-active# show components component psu-1 | include "state empty"
 state empty false
syscon-1-active# show components component psu-2 | include "state empty"
 state empty false
syscon-1-active# show components component psu-3 | include "state empty"
 state empty true
syscon-1-active# show components component psu-4 | include "state empty"
 state empty true

The above shows that there are 2 installed PSU and there are 2 empty PSU slots.
