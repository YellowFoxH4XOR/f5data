Known Issue

Important: This issue only affects BIG-IP 1500 platforms.

This is the result of a known issue. When running BIG-IP 9.2 on one slot and booting to a different slot that is running BIG-IP 9.1 or earlier, you may see the bcm56xxd daemon restarting frequently. As a result, you will not be able to use the system.

When this issue occurs after booting to version 9.1 or earlier, the BIG-IP system reports interface 4.1 as down and reports interface 0.1 (to which 4.1 connects) as up.

F5 is tracking this issue as CR49152.

Workaround

To work around this issue when transitioning from a version 9.2 boot to a version 9.1 or earlier boot, you must reboot the SCCP by performing the following procedure:

  1. Log in to the BIG-IP command line.
  2. Use the switchboot command to select the desired version to which you would like to boot.
  3. Connect to the SCCP by typing the following command:

    ssh sccp

    The sccp# prompt will be displayed.

  4. Reboot the SCCP, by typing the following command:

    reboot

    The entire platform (SCCP and host) will reboot.

Alternatively, you may power-cycle the system to force a full platform reboot.

Important: Power-cycling the system is only recommended if the above procedure cannot be performed.
