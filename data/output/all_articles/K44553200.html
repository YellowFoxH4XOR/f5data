Description

  • You are unable to access BIG-IP over SSH;
  • ssh daemon is down;
  • /shared/ssh is not present on a device;
  • the following messages appear in the log files :
/var/log/daemon.log :
 
Feb 12 04:51:25 <HOSTNAME> notice systemd[1]: sshd.service: main process exited, code=exited, status=1/FAILURE
Feb 12 04:51:25 <HOSTNAME>  err systemd[1]: Failed to start OpenSSH server daemon.
Feb 12 04:51:25 <HOSTNAME> notice systemd[1]: Unit sshd.service entered failed state.
 
/var/log/secure :
 
Feb 11 04:03:40 <HOSTNAME> err sshd[13560]: error: Could not load host key: /config/ssh/ssh_host_dsa_key
Feb 11 04:03:40 <HOSTNAME> err sshd[13560]: error: Could not load host key: /config/ssh/ssh_host_ecdsa_key
Feb 11 04:03:40 <HOSTNAME> err sshd[13560]: error: Could not load host key: /config/ssh/ssh_host_ed25519_key
Feb 11 04:03:40 <HOSTNAME> err sshd[13558]: error: Could not load host key: /config/ssh/ssh_host_rsa_key
Feb 11 04:03:40 <HOSTNAME> err sshd[13558]: error: Could not load host key: /config/ssh/ssh_host_dsa_key
Feb 11 04:03:40 <HOSTNAME> err sshd[13558]: error: Could not load host key: /config/ssh/ssh_host_ecdsa_key
Feb 11 04:03:40 <HOSTNAME> err sshd[13558]: error: Could not load host key: /config/ssh/ssh_host_ed25519_key

Environment

  • BIG-IP LTM 
  • SSH daemon is down / stopped

Cause

/shared/ssh directory has been removed from the BIG-IP device. SSH daemon cannot load host keys to the running config.

Recommended Actions

1. Access BIG-IP command line via console cable.

2. Create an empty /shared/ssh directory.
 
 mkdir /shared/ssh
 
3. Restart ssh daemon.
 
 bigstart restart sshd
