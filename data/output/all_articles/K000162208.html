Known Issue

When connecting to VPN on macOS browser, the auto-upgrade to 7270 fails. The macOS VPN package (mac_f5vpn.pkg) for APM client version 7270 exceeds a 200 MB limit, causing the upgrade to fail.

This issue occurs when all of the following conditions are met:

  • You use a browser to connect to VPN on macOS.
  • The client-side is running a version older than 7270.
  • You configured the Component Update setting in the connectivity profile to yes.

Impact

The auto-upgrade fails. You are still able to connect to VPN using the existing version.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You may observe a pop-up in the browser with a message similar to the following:

    Application update failed: Network error. Do you want to continue using old version?

  • You may observe in the client-side log, vpn.log a message similar to the following:
    HTTP per-response size exceeds max memory (200MB)
  • When Endpoint Inspection is configured in the access policy, you may observe in the client-side log, epi.log a message similar to the following:
    74065,3445276,, 1, /Session.cpp, 320, void f5::qt::Session::AutoUpdateFail(QString, bool), Auto update of application failed, Couldn't launch installer

Workaround

To work around this issue, you can manually download the VPN browser component, mac_f5vpn.pkg and perform the upgrade manually. To do so, refer to K70344735: Overview of BIG-IP APM F5 Helper Applications for macOS.

When Endpoint Inspection is configured in the access policy, you can manually download the EPI component, mac_f5epi.pkg and perform the upgrade manually. To do so, refer to K70344735: Overview of BIG-IP APM F5 Helper Applications for macOS.

Note: Even if you manually upgrade to 7270 by installing the VPN browser component, upgrading from 7270 to later versions fails.
