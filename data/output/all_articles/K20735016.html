Issue

Error Message

notice tmrouted[<PID>]: 01910001:5: Tmrouted starting

In this error message, note the following:

  • <PID> is the process ID for the tmrouted process.

For example:

notice tmrouted[<PID>]: 01910001:5: Tmrouted starting

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • Dynamic routing is initially enabled on the BIG-IP system.
  • The tmrouted process is restarted.
  • A BIG-IP system with dynamic routing enabled boots up.

Impact

There is no impact; this is a notification that the tmrouted process is starting.

Recommended Actions

There are no recommended actions; receiving this message is expected behavior when the tmrouted process starts.  If tmrouted restarts unexpectedly, you can review the logs for related tmrouted messages that may indicate the cause of the restart.
