Known Issue

Some HTTP iRules commands do not always return results as Tool Command Language (Tcl) lists.

This issue occurs when all of the following conditions are met:

  • You use one or more of the following HTTP iRules commands:
    • HTTP::cookie names
    • HTTP::cookie attribute names
    • HTTP::header names
    • HTTP::header values
  • A condition exists in which a single value is returned.

Impact

The HTTP iRules command returns a string rather than a list. This issue may affect Tcl code that expects a list, leading to incorrect behavior.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The HTTP iRules commands behave differently if they return only a single result. They will return a Tcl string rather than a Tcl list containing a string.

Workaround

If the script is having issues with the value being returned as a string instead of a list, you can work around this issue by configuring the script to detect and handle those values correctly.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
