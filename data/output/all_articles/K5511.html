Known Issue

This is the result of a known issue. When upgrading to BIG-IP 9.2, the installation script is unable to open a secure shell (SSH) connection to the Switch Card Control Processor (SCCP) when logged in as any user other than root. If you are not logged in as root, you will receive the following error message after beginning a local or remote installation:

Note: The installation process will begin; however, if the user is not logged in as root, the process will not complete, and the error message will appear.

ERROR: sccp communication failed(1). Contact support.

F5 Product Development tracked this issue as CR44734, and it was fixed in BIG-IP LTM 9.2, which includes the upgrade to OpenSSH 4.0. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

To work around this issue, log in as root.

Note: Do not log in as admin or any other user.

If you are unable to log in to the BIG-IP LTM system as root, run the su root command before performing a local or remote installation.
