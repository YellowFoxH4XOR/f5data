Known Issue

This is the result of a known issue. If Fiber small form-factor pluggable (SFP) ports are disabled and the system is rebooted, the system does not allow the Fiber SFP ports to be re-enabled using the Configuration utility or the bigpipe interface <interfacename>.<port> enable command.

F5 Product Development tracked this issue as CR81105 and it was fixed in versions 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, or Link Controller release notes.

Workaround

Important: The following workaround requires you to use the bigstart restart command. This command is essentially a soft reboot of the BIG-IP system and it will cause a redundant system to failover if you use it on an active system. Additionally, using the bigstart restart command will cause a traffic disruption on a non-redundant system. F5 recommends that you perform this procedure during a maintenance window to prevent disruption to customer traffic.

To enable the interface by issuing a bigstart restart command, perform the following procedure:

  1. Log in to the command line.
  2. Type the following command with the appropriate interface name and number:

    bigpipe interface <interfacename>.<port> enable

    For example:

    bigpipe interface 2.1 enable

  3. Save the changes by typing the following command:

    bigpipe save

  4. To enable the interface, type the following command:

    bigstart restart
