Note: This Solution only applies to BIG-IP versions prior to 10.1.0. Beginning with BIG-IP 10.1.0, by default, the big3d process listens for incoming iQuery connections on all self IP addresses configured on a VLAN.

The big3d daemon runs on all BIG-IP devices and collects performance information on behalf of the BIG-IP GTM system. By default, the big3d process only listens for incoming iQuery connections on port 4353 of the first self IP address configured on each VLAN. If additional self IP addresses are configured on a VLAN, the big3d process will not listen for incoming connections on these addresses.

To determine the first self IP address for a VLAN, type the following command:

bigpipe self show

The following command output shows that the first self IP address listed for the external VLAN is 10.0.0.1:

SELF 10.0.0.1 mask 255.255.0.0
| VLAN external floating disable
SELF 10.0.0.2 mask 255.255.0.0
| VLAN external floating disable
SELF 10.0.0.3 mask 255.255.0.0
| VLAN external floating disable
SELF 10.0.0.4 mask 255.255.0.0
| VLAN external floating disable

In the above example, the big3d daemon would only listen for incoming iQuery connections on the 10.0.0.1 self IP address.

In some cases, multiple self IP addresses may be configured on the same VLAN, and you may want the big3d process to listen on all self IP addresses configured on the VLAN. To do so, perform the following procedure:

  1. Logon to the BIG-IP system command line.
  2. Using a text editor of your choice, edit the /etc/bigstart/scripts/big3d file.
  3. Locate the following lines:

        exec /usr/sbin/${service}
    else
        exec /usr/sbin/${service}
  4. Change the lines to appear as follows:

        exec /usr/sbin/${service} -all-ip
    else
        exec /usr/sbin/${service} -all-ip
  5. Save the changes and exit the text editor.
  6. Restart the big3d process by entering the following command:

    bigstart restart big3d
  7. To verify that the system is listening on port 4353 on all self IP addresses on the VLAN, enter the following command:

    netstat -na |grep 4353
