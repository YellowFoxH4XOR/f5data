Description
After you click "Deploy" through the SSL Orchestrator [SSLO] main menu, the Configuration Utility reports a failure.
The "View details ..." option will then prompt you with a message such as:
Deployment failed for <sslo_object_name>Error: connect ECONNREFUSED 10.2.3.4:443

Environment

  • You're using BIG-IP SSLO;
  • You're running an HA pair;
  • You're trying to deploy a change to an existing SSLO configuration.

Cause
This is because of restrictions in place within the "Port Lockdown" settings attached to the HA SelfIPs..

Recommended Actions

Set Port Lockdown for the Self IP to "Allow Custom" and include 443 for TCP:
  1. Navigate to Network >> Self IPs
  2. Click the name of the selfIP involved in the HA communication;
  3. Locate the "Port Lockdown" parameter
  4. If set up a "Allow Custom", please ensure TCP/443 is added to the "Custom List"
  5. Please repeat steps from #1 to #4 to the peer unit

Additional Information
Depending the modification you tried to deployed to SSLO, you may need to first undo the failed deployment.
To do so:

  1. Navigate to the SSLO main menu
  2. Click the tab related to the modification you were trying to implement
  3. Click the check box to the name of the object
  4. Click Delete
