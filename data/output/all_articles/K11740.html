Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following article:

  • K13455: Overview of BIG-IP logging BigDB database keys (11.x - 12.x)

A number of the BIG-IP BigDB keys provide the ability to enable verbose logging, which can be useful for troubleshooting specific BIG-IP issues. F5 recommends that you do not modify these BIG-IP database keys, except for troubleshooting purposes, and that you always return their values to the default when the system is in production mode. Leaving the verbose logging enabled when the system is in normal production mode can cause poor performance.

The following BIG-IP BigDB keys should be set to their default values when the system is in production mode:

Note: Not all BigDB keys are present in all versions of BIG-IP software.

To display the current value of a BigDB key, use the following command syntax:

bigpipe db <bigdb_key>

For example, to display the Log.Bcm56xxd.Level BigDB key value, you would type the following command:

bigpipe db Log.Bcm56xxd.Level

To set the value of a BigDB key, use the following command syntax:

bigpipe db <bigdb_key> <value>

For example, to set the Log.Bcm56xxd.Level BigDB key value to its default value, you would type the following command:

bigpipe db Log.Bcm56xxd.Level Informational
