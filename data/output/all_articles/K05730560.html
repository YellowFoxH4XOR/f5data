Description
Configuring BIG-IQ Management IP to use TLSv1.2 for PCI Compliance

Environment

  • PCI scan failed
  • Requirements for TLS1.2 or above
  • Requirements for moduli of 2048 bits or greater.

Cause

The big3d process and Configuration Utility, which utilizes the Management IP, is configured to use TLSv1.

Recommended Actions
In order to configure the Management IP to only use TLSv1.2 and above, follow all of the procedures below.

  1.  Run below command to update the Configuration Utility to use moduli  of 2048 or greater

    # sed -i.K05730560 -e 's/ssl_ciphers.*$/ssl_ciphers AESGCM:AES:-ADH:-DHE:-AES128:-SHA1;/g' /etc/webd/webd.conf
     
  2. Run below tmsh command to restart the Configuration Utility (webd service)

    # tmsh restart sys service webd
     
  3. Run below tmsh command to update Big3D to use tls1.2 or above

    # tmsh modify sys db big3d.minimum.tls.version value tls1.2
     
  4. Run below tmsh command to update Big3D to use moduli  of 2048 or greater

    # tmsh modify sys db big3d.ssl.cipherlist value AESGCM:AES:-ADH:-DHE:-AES128:-SHA1
     
  5. Restart Big3D. This should not be traffic impacting.

    # bigstart restart big3d
