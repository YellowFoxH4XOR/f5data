Known Issue

System shutdowns may produce core files.

This issue occurs when the following condition is met:

  • You shut down your BIG-IP APM system while it actively processes session data.

This issue occurs when the BIG-IP APM system attempts to start a second instance of the apd and apmd services during a system shutdown. Core files are produced when a second set of service instances are initialized; however, the files do not represent an issue with the normal processing of session traffic.

Impact

The system generates core files for the apd and apmd services.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you shut down and restart the BIG-IP APM system, core files for the apd and apmd services appear in the /shared/core directory with time stamps that correlate to the system shutdown.
  • The system log messages similar to the following example to /var/log/apm file at the time of the shutdown:

    err apmd[22136]: 01490000:3: terminating due to signal 15
    err apmd[22136]: 01490000:3: 22136 skipping recovery from signal 6 apmsig_recover_level :0
    crit apmd[22136]: 01490000:2: ** SIGABRT **
