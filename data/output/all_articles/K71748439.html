Description

In versions prior to BIG-IP 13.0.0 HF1, you can configure the Route Advertisement option for a virtual address to be either Enabled or Disabled only.
You would like to have Route Advertisement 'Always' option equivalent in prior BIG-IP version.

Environment

  • BIG-IP
  • Version prior to 13.0.0 HF1

Cause

None.

Recommended Actions

To ensure virtual address always advertises the route regardless of the virtual servers availability, you can update the Advertise Route settings to Always.

In GUI:

  1. Navigate to Local Traffic > Virtual Servers > Virtual Address List.
  2. Click the name of the virtual address.
  3. Under Configuration, for Availability Calculation or Advertise Route, select Always from the drop down list.
  4. For Route Advertisement, click Always.
In CLI:
  1. Run command: tmsh modify ltm virtual-address <ip address> server-scope none
