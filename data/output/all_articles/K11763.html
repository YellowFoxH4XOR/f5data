Known Issue

This is the result of a known issue. When a pre-logon sequence log message exceeds 500 characters, the message will be truncated. The pre-logon sequence logger uses PHP syslog which has a 500 character limit. The PHP syslog limitation will affect both logon and system logs.

F5 Networks Product Development is tracking this issue as CR142238.
