Issue

Description

In /var/log/gtm you observe following error message:

gtmd[<PID>]: 011ae00b:3: Could not find monitor object <IP-Address>:<Port-Number>

In this error message, note the following:

  • <PID> is the process identification number for the gtmd process.
  • <IP-Address> is the IP address of the monitored BIG-IP GTM/DNS system.
  • <Port-Number> is the port number of the monitored BIG-IP GTM/DNS system.

For example:

gtmd[8566]: 011ae00b:3: Could not find monitor object 10.1.1.100:0

Environment

This message occurs when the following conditions are met:

  • BIG-IP GTM/DNS is provisioned.
  • Two or more BIG-IP GTM/DNS systems have the same sync-group name configured.
  • Global server load balancing (GSLB) sync between two or more BIG-IP GTM/DNS systems is broken or not configured.
  • There is a configuration discrepancy between two or more BIG-IP GTM/DNS systems or the affected BIG-IP GTM/DNS systems are monitoring the same BIG-IP LTM server, or both.

Cause

A BIG-IP GTM/DNS system uses iQuery protocol to monitor status of BIG-IP LTM servers. The big3d process, which is responsible for iQuery monitor probes response on the LTM side, broadcasts the reply to all BIG-IP GTM/DNS in the same GTM/DNS sync group. As a result, the affected BIG-IP GTM/DNS system receives a reply for objects which are not configured and writes an error to the log file.

Recommended Actions

To solve the issue, you can perform either one of the following actions. The way you choose depends on your needs.

  • You can restore BIG-IP GTM/DNS sync and be sure that all BIG-IP GTM/DNS systems in the sync-group share identical GSLB configuration. See Supplemental Information for more information.
  • If affected BIG-IP GTM/DNS systems are not supposed to share same configuration or should not belong to the same sync group, you need to change the BIG-IP GTM/DNS sync group name accordingly. To do that, perform the following procedure:
    1. Log in to the Configuration utility and go to DNS > Settings > GSLB > General.
    2. For Group Name, enter unique name for each BIG-IP GTM/DNS sync group in your network.

Additional Information

The behavior should not impact any service.
