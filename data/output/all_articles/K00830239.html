Topic

You should consider using this procedure under the following condition:

  • You want to enable BIG-IQ 6.1.0 through 7.0.0 to support a newly published Microsoft Azure BIG-IP Virtual Edition (VE) image version in the Azure cloud environment.

Description

This article explains how to modify the restjavad properties to enable BIG-IQ 6.1.0 through 7.0.0 to support the latest BIG-IP VE image version in the Azure Marketplace.

For BIG-IQ 7.1.0 or later, refer to K34843143: Adding support for a newly published Azure BIG-IP VE image version on the BIG-IQ system.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have a valid Azure cloud environment configuration on the target BIG-IQ system.
  • You are using the BIG-IQ system to deploy a new BIG-IP VE device to the Azure cloud environment.
  • You have Advanced Shell (bash) access to the BIG-IQ system with administrator credentials.

Procedures

Before adding the new Azure BIG-IP VE version to the restjavad properties file, you must validate that the current copy of the file has the existing configuration stanza to support Azure BIG-IP VE.

Validating the Azure configuration stanza

The BIG-IQ system has a list of pre-populated versions of Azure BIG-IP VE. You can view them using the following command from bash on the BIG-IQ system:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

jq '.azure.images' /var/config/rest/config/restjavad.properties.json

BIG-IQ 7.0.0 example output displays as follows:

{
  "includeImageVersions": [
    "13.1.100000",
    "14.0.001000",
    "14.1.003000"
  ]
}

The previous example output confirms that the following BIG-IP VE versions are supported in the Azure cloud environment:

  • BIG-IP 13.1.1
  • BIG-IP 14.0.0.1
  • BIG-IP 14.1.0.3

If you are unable to see the list of Azure BIG-IP VE versions, you may have an old version of the restjavad.properties.json file, possibly due to an upgrade of the BIG-IQ system from 6.0.0 to 7.0.x. For more information, refer to Bug ID 820949. To obtain a newer version of the restjavad.properties.json file, refer to the Workaround section in K02972920: The restjavad.properties.json file is not updated with latest version after upgrading the BIG-IQ system.

The restjavad.properties.json file with the Azure configuration stanza is available from the ISO file in BIG-IQ 7.0.0 or 7.0.0.1. You must have the file that contains the Azure configuration stanza before performing the next procedure.

Adding the new Azure BIG-IP VE version to the BIG-IQ system

After you verify that the restjavad.properties.json file has the Azure configuration stanza, you can add the version number of the newly published Azure BIG-IP VE.

Impact of procedure: You must restart the restjavad process after you modify the property file, which will cause interruptions to BIG-IQ system services. F5 recommends performing this procedure only during a scheduled maintenance period. 

  1. Log in to bash on the BIG-IQ system.
  2. Save a back-up copy of the restjavad property file by entering the following command:

    cp -a /var/config/rest/config/restjavad.properties.json /shared/tmp/restjavad.properties.json.backup

  3. Use a file editor to edit the /var/config/rest/config/restjavad.properties.json property file.
  4. Look for the azure section, and locate the following line that has a list of version numbers and starts with includeImageVersions.

    For example:

        "azure" :
    {
        ...
        ...
        ...
        "images" :
        {
            "includeImageVersions": [ "13.1.100000", "14.0.001000", "14.1.003000" ]
        }
    }

  5. On the includeImageVersions line, append the new BIG-IP VE version number.

    For example, to add BIG-IP 15.1.0.2, modify the line entry identified in Step 4 as follows:

    "includeImageVersions": [ "13.1.100000", "14.0.001000", "14.1.003000", "15.1.002000" ]

  6. After you save the changes, you must refresh the system. To restart the restjavad service, enter the following command:

    tmsh restart /sys service restjavad

    Once the BIG-IQ system resumes service, when you create a new cloud environment for Azure and select the BIG-IP Image Name drop-down list, you should see your newly added version of Azure BIG-IP VE.
