Description

You want to delete a specific APM session on the command line.

Environment

  • Check or delete the APM session or sessions.
  • BIG-IP APM 

Cause

None

 Recommended Actions

  1. You should make sure that you have the terminal full access privileges.
  2. Then you login to the BIG-IP CLI.
  3. Run the following command at the bash prompt to check the currently active sessions:
# sessiondump --list
  1. Then you can run the below command to delete the session you got from step 3:
# sessiondump --delete <the session ID>

Additional Information

  • For example, by running the above command in step 3, you may get the session ID you want to delete:
# sessiondump --list
acbd1234 10 SessionKey
  • Then you can run the below command to delete the session:
# sessiondump --delete acbd1234
