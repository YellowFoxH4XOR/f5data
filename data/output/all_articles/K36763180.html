K36763180: BIG-IP ASM does not automatically add escape character from v14.0.0

Type
Support Solution
Published
2020-04-13
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.X.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K36763180

Description
BIG-IP ASM does not automatically add escape character, which is often referred as back slash, starting from v14 on User-defined Storage Format of remote logging profile.

As a result, ASM logging format will be affected in a way that any double quotation character will be automatically stripped and actual logging format will be affected as well.

There is no adverse effect on sending such logs without double quotations but you may want to add them to each log entry for easy recognition.

Environment

  • BIG-IP ASM

Cause
Software specification changed.

Recommended Actions

  • You can manually add back slash as escape character in front of double quotation to avoid the change.
