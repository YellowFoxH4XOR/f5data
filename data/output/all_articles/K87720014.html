K87720014: Can Not Access F5 Configuration Utility Device Certificate Expired

Type
Support Solution
Published
2021-11-16
Updated
2025-04-01
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K87720014

Description

When the F5 device certificate expires Google Chrome may prevent access to the configuration utility with a page stating "Your connection is not private".

  • NET::ERR_CERT_DATE_INVALID
  • No apparent way to proceed to site.
  • You cannot visit <site> right now because the website uses HSTS.

Environment

  • The F5 Device Certificate has expired.
  • Using Google Chrome to access F5 Configuration Utility ( GUI ).

Cause

This is a security feature in Google Chrome to prevent accidentally accessing a site with an expired certificate.

Recommended Actions

  1. To bypass this page and proceed to the F5 Configuration utility you can type "thisisunsafe" without the quotes and Chrome should continue and allow you to access the site.
  2. Renew the Device Certificate
