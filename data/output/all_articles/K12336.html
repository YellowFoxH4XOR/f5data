Known Issue

This is the result of a known issue. Note: These debug messages are benign and can be safely ignored.

For example, the following HTML pages would trigger the log messages, because the HTML tags end with an equal sign or an unpaired quotation sign:

  • <HTML><A HREF=
  • <HTML><A HREF="
  • <HTML><A HREF='

The following malformed HTML pages would not trigger the log messages, since the HTML tags do not end with an equal sign or an unpaired quotation sign:

  • <HTML><A HREF=a
  • <HTML><A HREF="a
  • <HTML><A HREF='a

F5 Product Development is tracking this issue as ID 343590.

Workaround

To prevent this issue from occurring, ensure that the OWS serves properly coded HTML pages.
