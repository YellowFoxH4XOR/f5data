Description
When configuring a Virtual Server with the field "Source Address" as "Address list" and having more than one Address List configured in the BIG-IP, the Virtual Server does not allow all addresses in all lists to open a connection.
 

Environment

  • Virtual Server with Source Address as Address list
  • More than one address list configured in the BIG-IP

Cause
The Configuration utility will display all available Shared Object address lists for Source Address, only one (the select/highlighted) Address List can be utilized.

For example:
BIG-IP configuration includes  Address Lists 'A' and 'B'
'A' list with addresses 192.168.0.1 and 192.168.0.2
'B' list with addresses 192.168.0.3 and 192.168.0.4
When creating a Virtual Server and select "Address List" as "Source Address", A and B are shown
Only traffic from 192.168.0.1 and 192.168.0.2 is allowed, traffic from 192.168.0.3 and 192.168.0.4 fails
The reason why it's failing, it's because 'A' is selected and it's the only list taking effect

Recommended Actions

To accept traffic from all addresses needed, do one of next: 

  • Create a new list with all addresses that should be allowed by the Virtual Server
  • Complete the current working list with the missing source addresses
