Known Issue

The BIG-IP ASM Web Scraping Detection feature may generate unnecessary DNS queries.

This issue occurs when the following conditions are met:

  • The Web Scraping Detection violation is enabled with a blocking mask of Learn, Alarm, or Block
  • The BIG-IP ASM receives an HTTP request

The Web Scraping Detection feature maintains a list of allowed bots that are exempted from triggering Web Scraping violations. The identity of these bots is verified by a combination of their user-agent strings and DNS queries. The current list of allowed bots is:

  • Google
  • Yahoo
  • MSN
  • Ask.com
  • AOL

Only requests from these hosts should trigger DNS queries as a direct result of the web scraping feature. However due to this issue, the BIG-IP ASM may initiate DNS queries for hosts not included in the list above.

For example, the following user-agent header value for the googlebot web crawler would correctly trigger a DNS query:

User-Agent: Googlebot/2.1 (+http://www.googlebot.com/bot.html)

Impact

The BIG-IP ASM performs unnecessary DNS queries.

Symptoms

As a result of this issue, you will encounter the following symptoms:

  • HTTP requests with user-agent strings for hosts that are not listed in the Description section will incorrectly generate DNS queries from the BIG-IP ASM.

    For example, the following User-Agent header value does not match any of the allowed bots in the list above; however, due to this issue, the BIG-IP ASM may still generate a DNS query for the bot:

    User-Agent: envolk[ITS]spider/1.6 (+http://www.envolk.com/envolkspider.html)

  • If DNS is not correctly functioning, the bd process may restart, dump core, and the BIG-IP ASM may temporarily fail to process traffic.
