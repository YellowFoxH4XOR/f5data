K000146859: How is default anycast tenant VIP advertised on F5 Distributed Cloud Services.

What Happened?

You want to know how the default anycast tenant VIP advertised on F5 Distributed Cloud Services.

Environment

  • F5® Distributed Cloud Services HTTP Loadbalancer
  • F5® Distributed Cloud Services TCP Loadbalancer

Cause

  • None

Resolution/Answer

  • By default, when you sign up for F5 Distributed Cloud, you are provided a public IP address to which you can attach HTTP or TCP loadbalancers. 
  • This IP address is part of a pre-defined Virtual Site (ves-io-all-res), which is configured for ALL Regional Edges(RE) to process traffic for any services attached to your tenant's IP address. This virtual site is used when the VIP Advertisement is set to Internet on the HTTP or TCP loadbalancer.

  • The IP address that is associated with this virtual site will now be advertised into the F5 Global Backbone as a /32. 
  • The backbone follows its more specific route.  Once traffic reaches the Regional Edge associated with the Virtual Site, the Regional Edge software will decrypt, proxy, and apply any additional configurations to the application traffic flow.  

 

Additional Information

  • Users cannot assign this default VIP to user created virtual sites. Add-on IP is necessary to assign it to user created virtual sites.
