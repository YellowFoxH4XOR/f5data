Known Issue

This is the result of a known issue. Creating a virtual server from the command line with no arguments creates an IPv6 wildcard virtual server. If the BIG-IP system does not contain an IPv6 license, the virtual server configuration can generate an error message.

For example, the bigpipe virtual new-vip {} command creates the following virtual server definition:

virtual new-vip {
destination any6:any

If you save the virtual server configuration using the bigpipe save command, and then re-load the configuration using the bigpipe load command, the system generates the following bigpipe error message:

BIGpipe: virtual server modification error:
01070636:3: IP V6 not licensed (virtual server none).

F5 Product Development tracked this issue as CR51279 and it was fixed in BIG-IP version 9.4.0. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue still exists in the BIG-IP version 9.3 software branch.
