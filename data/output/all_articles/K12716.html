K12716: Performing a firmware upgrade after upgrading to ARX version 5.2.0 may result in a firmwareMismatchRaise trap

Known Issue

This is the result of a known issue. If you perform a firmware upgrade after upgrading to ARX version 5.2.0, the firmware upgrade may appear to fail with a firmwareMismatchRaise trap. The firmware upgrade is successful, but when the firmware attempts to update the BIOS, and the affected systems already have an up-to-date BIOS installed, the BIOS upgrade fails, so the firmware upgrade appears to fail. This issue does not affect system performance.

In addition to the firmwareMismatchRaise trap, the show health command also displays an error. To display the show health error, type the following command:

show health

The command displays output that appears similar to the following example:

System Health Information
 Date                        ID      Event                       Description
 ----------------------------------------------------------------------------------------
 Wed Feb  2 15:51:42 2011    (183) - firmwareMismatchRaise       The bios upgrade failed.

This issue affects ARX 4000 platforms and ARX 500 platforms with a model number of SR1500ALR (Alcolu). To determine if your ARX 500 is affected, display the model number by typing the following command:

show chassis

For affected ARX 500 systems, the command displays output that appears similar to the following example:

Identification:
Hostname                             UUID
------------------------------------ --------------------------------------
SWITCH                               a5d78a46-e3a2-11d4-9085-8be8de9df650
Chassis:
Chassis Type  Model Number                          HW Ver.  Serial
------------  ------------------------------------  -------  -------------
ARX-500       SR1500ALR (Alcolu)                             BZDG74800296

F5 Product Development tracked this issue as ID 350295, and it was fixed in ARX version 5.2.2 and version 6.0.0. For information about upgrading, refer to the ARX release notes.

Workaround

To prevent this issue from occurring, do not perform a firmware upgrade after upgrading systems to ARX version 5.2.0.

You must contact F5 Technical Support to clear this event; reference this article and ARX ID 350295 when you contact Technical Support.
