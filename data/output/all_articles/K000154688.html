K000154688: NGINXaaS resource status showing "Failed"

Type
Support Solution
Published
2025-09-15
Updated
2025-09-15
Applies to
  • NGINX Products
  • NGINX as a Service for Azure
Source
https://my.f5.com/manage/s/article/K000154688

Description

NGINXaaS resource in Azure Portal displays "Failed" provisioning state despite normal operation.

Environment

  • NGINXaaS

Cause

This is a known bug(NLB-5843) in NGINXaaS health reporting system caused incorrect "Failed" status display.

Recommended Actions

To workaround the issue, increase and then decrease the autoscale capacity. For example, update the autoscale capacity of your deployment from 10–20 NCUs to 20–30 NCUs. Once the operation is successful, scale the capacity back down to 10–20 NCUs.

The permanent fix to be prioritized in product roadmap.
