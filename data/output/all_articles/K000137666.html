Description

  • Web acceleration statistics section in BIG-IP configuration utility: Statistics ›› Module Statistics : Local Traffic ›› Virtual Servers : <VS_name> is empty.
  • Zeroes appear on web acceleration statistics for the profile attached to the virtual server.
  • In CLI (command-line interface) when using command "show ltm profile web-acceleration" statistics are displayed normally.

Environment

  • BIG-IP configuration utility.

Cause

This is due to bug ID1352113.

Recommended Actions

If you need to inspect the web acceleration statistics, the workaround is to use the CLI to inspect the web acceleration profile stats with command:

tmsh show ltm profile web-acceleration <profile_name>


For example, to display the web acceleration statistics for "webacceleration", the command would be:

tmsh show ltm profile web-acceleration webacceleration


Currently there is no fix - only workaround.

Additional Information

None.
