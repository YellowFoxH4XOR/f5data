K000160704: Unable to install APM client 7.2.6.2 on BIG-IP 17.5.1.3. with signature verification enabled

Type
Support Solution
Published
2026-04-10
Updated
2026-05-21
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000160704

Description

Installation of the APM client image apmclients-7262.2025.1203.525-7005.0.iso on BIG-IP APM 17.5.1.3 with signature verification enabled fails with the error:

Error opening key file /usr/lib/install/archive.pubkey.20160210.pem

...unable to load key file

Signature verification failed for "/shared/apm/images/apmclients-7262.2025.1203.525-7005.0.iso".

Please make sure the image is not corrupted and try to upload it again.

The signature file (.sig) is present, and manual verification using the new key confirms the image is valid. The installation process references an outdated key file, causing signature verification to fail.

Environment

  • Product: BIG-IP APM
  • Version: 17.5.1.3
  • APM client image: apmclients-7262.2025.1203.525-7005.0.iso
  • Signature verification enabled
  • New signing keys present: archive-2k.pubkey.20251002.pem, archive-3k.pubkey.20251002.pem
  • FIPS not enabled

Cause

ID 2149197

Answer/Recommended Actions

To work around this issue until a fix is released:

  1. Manually Verify Image Integrity (Recommended for Security)
    Run:

    openssl dgst -sha384 -verify /usr/lib/install/archive-3k.pubkey.20251002.pem \

    -signature /shared/apm/images/apmclients-7262.2025.1203.525-7005.0.iso.384.sig \

    /shared/apm/images/apmclients-7262.2025.1203.525-7005.0.iso

    Expected output: Verified OK

  2. Temporarily Disable Signature Verification
    Run:

    tmsh modify /sys db liveinstall.checksig value "disable"

    tmsh save sys config

  3. Install the APM Client Image
    Run:

    tmsh install /apm client image apmclients-7262.2025.1203.525-7005.0.iso

  4. Re-enable Signature Verification
    Run:

    tmsh modify /sys db liveinstall.checksig value "enable"

    tmsh save sys config

Note: If the system is FIPS-licensed, signature verification cannot be disabled. Contact F5 support for further guidance.

Additional Information

  • The root cause is a bug where the installation process references the old key file (archive.pubkey.20160210.pem) instead of the new key (archive-3k.pubkey.20251002.pem) after F5's October 2025 signing certificate/key rotation.
  • A fix is available to resolve this issue.
  • Manual verification of the image integrity using the new key is recommended before disabling signature verification.
