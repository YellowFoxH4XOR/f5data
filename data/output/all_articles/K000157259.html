Description

After upgrading the BIG-IP DNS (GTM) system to version 17.5.1.3, the configuration failed to load, displaying the error: "The configuration has not yet loaded. If this message persists, it may indicate a configuration problem." Further investigation revealed a version mismatch in the GTM configuration file, preventing successful configuration validation and system operation.

 

Environment

BIG-IP DNS (GTM) module, version 17.5.1.3

Running the following bash command shows error condition

tmsh load sys config gtm-only verify
Validating GTM system configuration...
 /usr/local/gtm/include/gtm_base_region_isp.conf
 /usr/share/monitors/gtm_base_monitors.conf
Validating configuration...
Data Input Error:(/config/bigip_gtm.conf at line: 0) Invalid version:17.1.2.1: Supported cli versions: 14.0.0 14.0.1 14.1.0 14.1.1 14.1.2 14.1.3 14.1.4 15.0.0 15.0.1 15.1.0 15.1.1 15.1.10 15.1.2 15.1.3 15.1.4 15.1.5 15.1.6 15.1.7 15.1.8 15.1.9 16.0.0 16.0.1 16.1.0 16.1.1 16.1.2 16.1.3 16.1.4 16.1.5 17.0.0 17.1.0 17.1.1 17.1.2 17.5.0 17.5.1 17.5.1.1 17.5.1.2 17.5.1.3

 

Cause

The root cause may be a version mismatch in the GTM configuration file (bigip_gtm.conf), which referenced an older version (17.1.2.1) instead of the current system version (17.5.1.3) or one of the accepted versions. This mismatch prevented the DNS configuration from loading successfully after the upgrade.

 

Recommended Actions

Use a command line editor to manually update the version reference in the GTM configuration file (/config/bigip_gtm.conf) to match the current system version (17.5.1.3) or to an accepted version in the list provided. In this case (17.1.2).

Reload the GTM-only configuration using the following command:

tmsh load sys config gtm-only

Reactivate the system license if prompted after configuration reload.

Verify system functionality post-correction.
