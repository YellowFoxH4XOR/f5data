Description

You have determined that persistence profile is causing uneven load balancing between your pool members.

Removing the persistence profile would resolve the load balancing issue however the persistence profile is required by the application.

Because of this scenario a pool member or several pool members is processing more traffic and might cause over processing by the server (pool member).

This issue might also happen when using OneConnect profile.

Environment

  • Persistence profile or OneConnect profile is used
  • Persistence profile is required by the application
  • Pool member has reached resource limitation due to high amount of connections

Cause

The persistence profile is causing higher amount of connection to a specific pool member or several pool members. Because of this higher increase of connections, the pool member might reach its resource limitation.

From the pool member perspective, reducing the total connections would easy the resource issue.

Recommended Actions

Since it is not an option to remove the persistence profile or the OneConnect Profile, you can only limit the connects to the pool member which will reduce the server's resource requirement.

  1. Login to the Configuration Terminal.
  2. Navigate to Local Traffic > Pools > Pool List.
  3. Click on the pool name.
  4. Click the Members tab.
  5. Click on the pool member which has the higher connection.
  6. At the Connection Limit option, enter the connection limit based on your pool member's capacity.
  7. Click Update.
