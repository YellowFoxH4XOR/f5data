Description

The BIG-IP Next CNF helm installation fails once using ZebOS ConfigMaps   

# helm install f5cnf f5ingress-9.2.11.tgz -n cnf-gateway -f values.yaml --debug
[2023-09-05 17:16:11]  WARNING: Kubernetes configuration file is group-readable. This is insecure. Location: /root/.kube/config
[2023-09-05 17:16:11]  install.go:194: [debug] Original chart version: ""
[2023-09-05 17:16:11]  install.go:211: [debug] CHART PATH: /root/ocp-in-gslab/project/cnf111/cnf111/sw/cnfinstall/tar/f5ingress-9.2.11.tgz
[2023-09-05 17:16:11]  
[2023-09-05 17:16:11]  Error: INSTALLATION FAILED: execution error at (f5ingress/templates/tmm-dynamic-routing-configmap.yaml:9:7): tmmRouting->config not provided. BGP Config is required.
[2023-09-05 17:16:12]  helm.go:84: [debug] execution error at (f5ingress/templates/tmm-dynamic-routing-configmap.yaml:9:7): tmmRouting->config not provided. BGP Config is required.
[2023-09-05 17:16:12]  INSTALLATION FAILED

# helm install f5cnf f5ingress-9.2.11.tgz -n cnf-gateway -f values.yaml
WARNING: Kubernetes configuration file is group-readable. This is insecure. Location: /root/.kube/config
Error: INSTALLATION FAILED: execution error at (f5ingress/templates/controller-deployment.yaml:179:13): controller.watchNamespace is required for BFD to OVN.

 

Environment

  • OpenShift 4.12
  • BIG-IP Next CNF 1.1.1

Cause

The bfdToOVN parameter is disabled by default in f5ingress helm values 
 

# helm show values f5ingress/f5ingress --version v9.2.11 | grep -i bfdToOVN -A 1
WARNING: Kubernetes configuration file is group-readable. This is insecure. Location: /root/.kube/config
  bfdToOVN:
    enabled: false

 

Recommended Actions

1.  Enable bfdToOVN  parameter in the CNFs Controller Helm values file:

tmm:
  bfdToOVN:
    enabled: true
  dynamicRouting:
    enabled: true
    configMapName: "cnf-bgp"

2. Add watchNamespace parameter to the CNFs Controller Helm values file :
 

controller:
  watchNamespace: app
