K000138524: iRule string map function to replace the HTTP Location header

Description

In cases when the application sends its local hostname in the HTTP Location header to perform an HTTP redirection, you can use an iRule to replace the HTTP Location header.

 

Environment

LTM
Virtual Server
iRules

 

Recommended Actions
Use an irule to replace the local hostnames.

 

Sample irule:

when HTTP_RESPONSE {

   #You may also want to search and replace within the html body.
   STREAM::expression "@server1.local@virtual-server.example.com@ @server2.local@virtual-server.example.com@"
   STREAM::enable

   #if HTTP redirection is detected
   if {[HTTP::header exists "Location"] } {
      set oldloc [HTTP::header "Location"]
      set newloc [string map {"server1.local" "virtual-server.example.com" "server2.local" "virtual-server.example.com"} $oldloc]
      HTTP::header replace "Location" $newloc
   }
}
