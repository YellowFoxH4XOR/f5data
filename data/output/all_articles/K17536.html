Known Issue

If a virtual server receives an ICMP unreachable message, the Traffic Management Microkernel (TMM) flow erroneously remains alive.

This issue occurs when all of the following conditions are met:

  • The configuration has one local virtual server that connects to another local virtual server.
  • The system sends an ICMP unreachable message to a virtual server.

Impact

Unterminated connections may consume a small amount of system resources until they time out.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Affected connections do not close until they time out.
