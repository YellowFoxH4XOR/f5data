Description

Changing the password for a user in SNMPv3 does not take effect.

Environment

  • BIG-IP all modules
  • SNMPv3 user authentication is configured

Cause

SNMPv3 user password change does not take effect if there is duplicated user defined.

It is possible to misconfigure SNMPv3 user names with duplicate entries in the configuration file /config/bigip_base.conf following:

sys snmp {
    agent-addresses { tcp6:161 udp6:161 }
snip..
    users {
        /Common/isnmpmon_1 {
            auth-password ***scrubbed***
            auth-password-encrypted ***scrubbed***
            auth-protocol sha
            oid-subset .1
            privacy-password ***scrubbed***
            privacy-password-encrypted ***scrubbed***
            privacy-protocol aes
            security-level auth-privacy
            username snmpmon
        }
        /Prod/isnmptmon_1 {
            auth-password ***scrubbed***
            auth-password-encrypted ***scrubbed***
            auth-protocol sha
            oid-subset .1
            privacy-password ***scrubbed***
            privacy-password-encrypted ***scrubbed***
            privacy-protocol aes
            security-level auth-privacy
            username snmpmon
        }
    }
}

With this configuration, Updating auth-password and privacy-password by recreating /Common/ismpmon_1 user does not take effect, because subsequent same user configration /Prod/isnmpmon_1 override the configuration.

Recommended Actions

Delete the dupulicated user.

To confirm whether the duplicated SNMPv3 user is configured or not.

Note: GUI(System ›› SNMP : Agent : Access (v3)) and tmsh list command(tmsh list sys snmp users) does not list the duplicated configuration, you need to open the configuration file /config/bigip_base.conf using the vi text editor.

  1. Log in as root with the password
  2. Using the vi text editor, open /config/bigip_base.conf file by typing the following command:

    vi /config/bigip_base.conf

    Search "username" under "sys snmp" configuration section

    If the duplicated username is found, Memorize the user configuration name
    Exit the vi text editor by typing following:
    :q!

  3. To delete the configuration, Type tmsh command following:

    tmsh modify sys snmp users delete { <Duplicate SNMPv3 user configiration name> }

    For example:

    tmsh modify sys snmp users delete { /Prod/ismpmon_1 }

  4. To save the configuration, Type tmsh command following:

    tmsh save /sys config
