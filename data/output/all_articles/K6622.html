Issue

Prior to BIG-IP 9.4.0, configuration parameters were saved in text-based files, such as the bigip.conf file and the bigip_base.conf file. At system startup, the text-based files were parsed, validated, and loaded into the MCP database. The validation process was time consuming for large files and could significantly slow system performance on startup.

Beginning in BIG-IP 9.4.0, at system startup, the BIG-IP uses Binary Load and Binary Save functions to allow the system to load a binary configuration image directly from storage instead of loading the configuration from the bigip.conf file and related files. Therefore, when the BIG-IP system is rebooted it no longer needs to parse, validate, and load database configuration from text files, making system startup more efficient.

The BIG-IP system uses the following two files for the binary image of the configuration:

  • /var/db/mcpdb.bin
  • /var/db/mcpdb.info

When the BIG-IP system is rebooted or system daemons are restarted, the binary files are used to load the BIG-IP system configuration. When you run the bigpipe load command, the /config/bigip.conf file is used to load the BIG-IP system configuration.
