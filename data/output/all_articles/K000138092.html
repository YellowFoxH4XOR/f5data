K000138092: BIG-IP VE does not support hot-plug network event on hypervisor

Type
Support Solution
Published
2023-12-31
Updated
2024-08-07
Source
https://my.f5.com/manage/s/article/K000138092

Description

BIG-IP VE does not support hot-plug network event on hypervisor. When a hot-plug network event does occur, it may lead to a TMM crash and TMM may not restart properly.

This may eventually lead to a TMM crash, which can happen days later.

The following may appear in /var/log/messages :
notice logger[23769]: Started writing core file: /var/core/tmm.0.bld0.0.3.core.gz for PID 22314
notice logger[26625]: Finished writing <size> bytes for core file: /var/core/tmm.0.bld0.0.3.core.gz for PID 22314

TMM will restart, but fail to start properly. The following may appear in /var/log/tmm :
notice stp_state_set: err - undefined ifnet for interface 1.1
notice stp_state_set: err - undefined ifnet for interface 1.2
 

Environment

  • BIG-IP VE in Azure cloud environment
  • Accelerated networking is in use
  • Azure performs network related maintenance on the hypervisor/platform level

Cause

Azure performs a maintenance on the platform. Changes on the NIC occur as a result. This is not supported by BIG-IP VE.

Recommended Actions

Reboot the BIG-IP VE to recover.

Additional Information

According to Azure, changes on the NIC are expected to happen when update at platform level occurs. This is part of the networking updates process. You can learn more at https://learn.microsoft.com/en-us/azure/virtual-network/accelerated-networking-how-it-works#azure-host-servicing .
