Known Issue

The BIG-IP system may not honor Internet Control Message Protocol (ICMP) fragmentation requests.

This issue occurs when all of the following conditions are met:

  • Datagram LB is enabled in a User Datagram Protocol (UDP) profile for the affected virtual server.
  • Your BIG-IP system sends a packet exceeding the maximum transmission unit (MTU) limit of an upstream device.
  • Your BIG-IP system receives an ICMP fragmentation required packet.

Impact

Large UDP DNS queries traversing devices with lower MTU limits may fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Intermittent DNS queries are failing.
  • ICMP fragmentation required packets are not being honored by your BIG-IP system.

Workaround

To work around this issue, you can disable the Path MTU Discovery setting that allows upstream routers to fragment large packets. To do so, perform the following procedure:

Impact of workaround: This is a global setting which impacts all connections to the BIG-IP system and may have adverse effects on traffic handling that requires a smaller MTU.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To disable the Path MTU Discovery setting, type the following command:

    modify sys db tm.pathmtudiscovery value disable
