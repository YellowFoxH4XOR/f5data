Known Issue

The BIG-IP APM apd process may exit and produce a core file if the Active Directory server becomes unavailable.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with an Active Directory AAA Server
  • The BIG-IP APM Access Policy is configured for AD Query
  • The BIG-IP APM system is unable to contact the Active Directory server

Impact

Users are unable to connect to application resources while the apd process restarts.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP APM system generates an apd core file to the /shared/core directory.
  • The BIG-IP APM system temporarily stops processing traffic while the apd process restarts.
