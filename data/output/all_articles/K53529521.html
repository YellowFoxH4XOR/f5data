Description

BIG-IP Remote - LDAP Auth for device administration can be configured to use standard unencrypted LDAP via Port 389. Or, can be configured to use secure LDAP (LDAPS) via Port 636 in order to ensure that the LDAP Auth traffic is encrypted. 

Environment

Relevant environmental factors:

  • BIG-IP with existing Remote - LDAP Auth config using unencrypted LDAP (Port 389) traffic.

Cause

Expected behavior, per design.

Recommended Actions

To change the Remote - LDAP config from standard LDAP (Port 389) to LDAPS (Port 636):

1) Set the SSL parameter to Enabled. The Port value will change from 389 to 636. This will also expose several additional SSL related configuration options.
2) Configure the SSL CA Certificate option to use an appropriate Root CA Certificate. 
3) Configure the SSL Client Key option to use an appropriate Client Key.
4) Configure the SSL Client Certificate option use an appropriate Client Certificate.
5) Then click the Finished button to save the changes.
