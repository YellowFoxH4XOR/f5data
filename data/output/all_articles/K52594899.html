Known Issue

The Traffic Management Microkernel (TMM) may leak memory when processing a high volume of Secure Sockets Layer (SSL) traffic using ephemeral ciphers.

This issue occurs when all of the following conditions are met:

  • Your configuration includes one or more virtual servers with an associated Client SSL profile.
  • Your BIG-IP system is processing a high volume of SSL traffic using ephemeral ciphers.

Cipher suites using ephemeral ciphers begin with either DHE or ECDHE. For a full list of cipher suites supported on the BIG-IP system, refer to K13163: SSL ciphers supported on BIG-IP platforms (11.x - 13.x).

Impact

TMM may become unstable and produce a core file as a result of exhausted memory.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The following command shows your BIG-IP system's SSL memory statistics are continually growing:

    tmsh show sys memory | grep -iE 'SubSystem|ssl_hs'

    Sys::SubSystem Memory
    SubSystem                        Alloc (bytes)  Max Alloc (bytes)  Object Size
    ssl_hs                                67890000           67890000        12345
    ssl_hs_m                              67890000           67890000        12345

  • SSL connections are very slow or are failing to establish.
  • Your BIG-IP system fails over to another host in the device group.
  • TMM produces a core file in the /var/core directory.
