Topic

This article compares the BIG-IP ASM/AWAF and BIG-IP Distributed Cloud Service Bot-defense profiles.

Description

Starting in BIG-IP version 17.0, the Distributed Cloud Services Bot defense profile is included in the BIG-IP Configuration utility (Distributed Cloud Services > Bot Defense starting in 17.1.0) and can be used along side the BIG-IP ASM/AWAF Bot Defense feature. Although there is some overlap in the functionality, the use cases differ. The following table compares the BIG-IP Distributed Cloud Services and BIG-IP ASM/AWAF Bot Defense features:

Bot Defense detailASM/AWAF Bot defenseDistributed Cloud Services Bot defense
Feature descriptionProvides Bot detection and layer 7 protection to application services. When clients access a protected web site for the first time, the system sends a JavaScript challenge to the browser. If the client successfully evaluates the challenge and resends the request with a valid cookie, the system allows the client to reach the server. Requests that do not answer the challenge remain unanswered and are not sent to the server. Requests sent to non-HTML URLs without the cookie are dropped and considered to be bots.

Provides standard and advanced/premium service-level Bot detection and protection against sophisticated and automated attacks aimed at selective endpoints of critical importance, such as login and purchase. Protects web and mobile applications from automated attacks by identifying and mitigating malicious bots. Uses JavaScript and API calls to collect telemetry data to be passed to the F5 Distributed Cloud Bot Defense service. The service analyzes the telemetry data and determines whether a client request should be forwarded or temporarily blocked pending some other mitigation action.

Use caseCan be used when your BIG-IP system is licensed with the ASM module and you want to protect your applications against automated attacks using the mitigation settings that you define in the Bot defense profile.Can be used when you want to integrate your BIG-IP system with the F5 Distributed Cloud Bot Defense service to protect your applications; the service analyzes the telemetry data and determines the bot mitigation action.
Deployment tasks
  • License the BIG-IP system with the ASM module.
  • Configure the ASM/AWAF Bot defense profile and associated it with the virtual server.
  • Obtain a F5 Distributed Cloud account and enable Bot Defense in the Distributed Cloud Console.
  • Add the BIG-IP system as a protected application in Bot Defense.
  • Configure the BIG-IP BD profile to send requests to be evaluated by the F5 Distributed Cloud Bot Defense service.
Profile compatibilityCan be used with the Distributed Cloud Bot defense profile on the same virtual server if desired.Can be used with the ASM/AWAF Bot defense profile on the same virtual server if desired.
Device ID

Used to track client devices for the applicable ASM/AWAF feature. When enabled, the system obtains a unique identifier for the client device by determining attributes such as browser type, version, installed updates, and fonts.

Designated for IBD services and analytics. Assigns identifiers to unique browser sessions which are used to analyze telemetry data. The analysis determines whether a device performs like other devices or exhibits distinct characteristics which indicate that it may be malicious or suspicious.
