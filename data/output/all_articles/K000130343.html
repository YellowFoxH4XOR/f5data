Description

After upgrade from 16.1.2.2, GUI returns the following error:

Not Found
The requested URL was not found on this server.

Message only seen on the following GUI pages:

  • DoS Setup >> Silverline
  • Dos Setup >> Global
  • Network >> High Availability
  • System >> About

Environment

  • DDoS
  • After upgrade
  • GUI

Cause

err iAppsLX_save_pre[pid]: basicRestJavadQuery Error on request(400): POST /shared/iapp/build-package {"appName":"f5-ddos-hybrid-defender"}

DHD RPM never got saved into the UCS file that was created during the upgrade and loaded to the target boot location.

Root cause is ID1079817 / K14384420.

Recommended Actions

  1. Mount the previous 16.1.2.2 boot location's /var filesystem to a temporary, read-only location.

    Note: Command below assumes HD1.1 is the 16.1.2.2 boot location.

    mkdir /mnt/old_var

mount -o ro /dev/mapper/vg--db--sda-set.1._var /mnt/old_var/

  2. Copy the f5-ddos-hybrid-defender directory from the temporary mount to the expected location in the current boot location's /var filesystem.

    cp -r /mnt/old_var/config/rest/iapps/f5-ddos-hybrid-defender /var/config/rest/iapps

  3. Ensure the correct security contexts are applied:

    restorecon -R /var/config/rest/iapps

  4. Re-create the symlink:

    ln -s /var/config/rest/iapps/f5-ddos-hybrid-defender/presentation /usr/local/www/iapps/f5-ddos-hybrid-defender

  5. Finally, unmount the previous boot location's /var filesystem.

    umount /mnt/old_var

The GUI pages should now be accessible again.

This should be a one time thing, and shouldn't need to be repeated on future upgrades.
