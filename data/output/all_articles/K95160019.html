K95160019: Disabling ''You can download Citrix Receiver from here.'' popup when accessing APM webtop resource

Type
Knowledge
Published
2024-04-26
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.X, 13.1.0, 13.1.1, 13.1.3, 13.1.4, 13.1.5
Source
https://my.f5.com/manage/s/article/K95160019

Topic

When launching Citrix published applications from the BIG-IP APM Webtop, a pop-up box stating "You can download Citrix Receiver from here" may appear.

Description

This often occurs when a modern web browser is unable to detect Citrix Receiver is already installed on the computer.

When this message appears, and it is know that Citrix Receiver is already installed on the Client computers, the Client can usually still launch the Citrix published application after closing the pop-up box.


Recommended Actions:

To prevent this pop-up message appearing, the following iRule can be applied to the virtual server to which the Clients connect for the APM Webtop:
    when HTTP_RESPONSE {
      HTTP::cookie insert name "F5_VdiUserClientChoicecitrix" value "native"
    }

With this iRule applied, the Cirtix published application should start without issue when selected on the APM Webtop
