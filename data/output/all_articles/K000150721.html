K000150721: Phantom optic (OPT-0053) show in the system even the portgroup is down and never insert any optic.

Type
Support Solution
Published
2025-04-04
Updated
2025-04-04
Applies to
  • F5OS
  • F5OS-C: 1.8.X, 1.8.0
Source
https://my.f5.com/manage/s/article/K000150721

Description

  • Phantom optics (OPT-0053) are displayed in the system despite no optics being inserted into the affected port groups.
  • The issue occurs even when the port group is down and has never been used.
  • Command "show portgroups" shows phantom optics with details such as:

    class="ql-syntax">portgroup 6 state vendor-name "F5 NETWORKS INC."
    state vendor-partnum "OPT-0053"
    state vendor-serialnum "INMAF4330082"
    state transmitter-technology "850 nm"
    state media 25GBASE-SR
    state optic-state QUALIFIED

Environment

  • F5OS-A 1.8.0
  • SFP
  • Portgroup

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 1881557

Recommended Actions

To resolve this issue, perform the following steps:

  1. Insert an optic into each socket that is incorrectly reporting OPT-0053 while the system is operational.
  2. Remove the optic from each socket after insertion.

This process overwrites the port group data during insertion and clears it upon removal.
