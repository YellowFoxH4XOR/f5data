K000148828: iControl REST API is not working with Radius Users after upgrade

Type
Support Solution
Published
2025-01-29
Updated
2025-01-29
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.0.0, 16.0.X, 16.0.1, 16.X.X, 17.X.X, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.X, 16.1.5, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0
Source
https://my.f5.com/manage/s/article/K000148828

Description

After upgrade devices to the BIG-IP 17.1.1.4 you are unable to acess the iControl REST API with Radius users. As well the following error appear when you try to connect by (RADIUS) user 

{"code":401,"message":"Unable to process request /tm/auth/source. Service is unavailable.","referer":"10.10.10.10","restOperationId":60566912,"kind":":resterrorresponse"}

Environment

  • BIG-IP
  • iControl REST

Cause

Unknown

Recommended Actions

Restarting restjavad on the BIG-IP system

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the restjavad process, type the following command:

    restart sys service restjavad

None
