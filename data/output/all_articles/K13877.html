Known Issue

The BIG-IP Edge Portal client for Apple iOS fails to authenticate when using client certificate authentication.

This issue occurs when all of the following conditions are met:

  • The FirePass controller is configured to use client certificates for logon.
  • The certificate is installed on the Apple iOS client.

Impact

The Apple iOS device users are unable to use client certificate authentication.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • User receive an error message that appears similar to the following example:

    Login Failed

  • The FirePass controller logon report shows Client certificate validation:No Certificate

Resolution

Status

F5 Product Development has assigned ID 373347 to this issue, and has confirmed that this issue exists in the products listed in the Applies To box. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can remove the FirePass certificate requirement for authentication. To do so, refer to FirePass Controller Configuration for BIG-IP Edge Portal App for iOS version 1.0.2
