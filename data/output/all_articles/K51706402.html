K51706402: Upgrade to version 14.1.4 failed due to whitespace in bigip.conf file

Type
Support Solution
Published
2022-01-10
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K51706402

Description
When a software upgrade is performed on the appliance from version 12.1.5.3 to 14.1.4 noticed configuration load failure.

On configuration utility noticed below error,
"The configuration has not yet loaded. If this message persists, it may indicate a configuration problem"

Also on CLI, the device state shows "INOPERATIVE" status and noticed below error logs

Upgrade fails during config load, and reports an error in /var/log/ltm:

Dec 22 01:08:08 <xxxxx> notice tmsh[11617]: 01420012:5: Loading schema version: 12.1.5.3
Dec 22 01:08:09 <xxxxx> info tmsh[11617]: cli schema (12.1.5.3) has been loaded from schema data files.
Dec 22 01:08:09 <xxxxx> err tmsh[11617]: 01420006:3: URL passed is invalid: Parsed text violates expected format        
Dec 22 01:08:09 <xxxxx> emerg load_config_files[11615]: "/usr/bin/tmsh -n -g -a load sys config partitions all " - failed. -- Loading schema version: 12.1.5.3
Dec 22 01:08:09 <xxxxx> err mcpd[8015]: 01070425:3: Full configuration load failed.

Environment

  • BIG-IP LTM

  • BIG-IP APM

  • Software Upgrade

  • Configuration reload

Cause

This issue occurs due to whitespace in some of the file names in bigip.conf

For example, you may see a similar configuration in bigip.conf file

sys file ifile /Common/My_file_name {
    cache-path /config/filestore/files_d/Common_d/ifile_d/:Common:My_file_name
    revision 1
    source-path "file:////shared/tmp/test/./SIN test/test/test.txt"
}
sys file ifile /Common/My_file_name {
    cache-path /config/filestore/files_d/Common_d/ifile_d/:Common:My_file_name
    revision 1
    source-path "file:////shared/tmp/test/./SIN test/test/test.txt"
}

Recommended Actions

Replace all of the whitespaces from the path in bigip. conf to %20 as referenced below

Example snippet as show below,

Error File:-

sys file ifile /Common/My_file_name {
   cache-path /config/filestore/files_d/Common_d/ifile_d/:Common:My_file_name
   revision 1
   source-path "file:////shared/tmp/test/./SIN test/test/test.txt"
}
sys file ifile /Common/My_file_name {
   cache-path /config/filestore/files_d/Common_d/ifile_d/:Common:My_file_name
   revision 1
   source-path "file:////shared/tmp/test/./SIN test/test/test.txt"
}

Final Modified output as below,


sys file ifile /Common/My_file_name {
   cache-path /config/filestore/files_d/Common_d/ifile_d/:Common:My_file_name
   revision 1
   source-path "file:////shared/tmp/test/./SIN%20test/test/test.txt"
}
sys file ifile /Common/P-Uat-UserProxy-sin-example-Resolvable {
   cache-path /config/filestore/files_d/Common_d/ifile_d/:Common:test.txt
   revision 1
   source-path "file:////shared/tmp/test/./SG%20test/test/test.txt"
}
