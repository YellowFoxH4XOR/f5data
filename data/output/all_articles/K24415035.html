Description

This article provides an easy method to compare the configuration between several BIG-IP hosts using the compare feature of the iHealth website

Environment

  • BIG-IP
  • iHealth (note: requires log in with F5 Login credentials)

Cause

You would like to compare the configuration between several BIG-IP hosts and see the differences between them to troubleshoot issues such as configuration synchronization
 

Recommended Actions

  1.   For each BIG-IP host generate a QKView file and upload it to iHealth per "Running a QKView file from the Configuration utility and uploading it to F5 iHealth " in K12878: Generating diagnostic data using the qkview utility
  2.   After the QKViews have been uploaded they will be listed on the "Uploads" tab.  You will be taken to this page by default after uploading any QKViews.
  3.   On the "Uploads" tab page select each QKView you would like to compare by checkmarking each box on the far left of the page for each hostname.
  4.   Click on the "Compare" button.
  5.   The next page will contain a summary of differences found between the hosts.
  6.   To see the actual differences between hosts you may click on the number in the column to the right of that item.  For example to see differences in VLANs between units click on the number to the right of the word "VLANs" on this summary page.  Each difference is listed on the next page and can be expanded to show the values from each hostname.
