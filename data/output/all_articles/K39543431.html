Topic

You should consider using this procedure under the following condition:

  • You want to configure a high availability (HA) pair of BIG-IP devices to synchronize the configuration with a non-failover disaster recovery device.

Description

When you configure a pair of BIG-IP devices for HA, you build redundancy in failover fault tolerance between the devices. Some administrators want to augment the HA deployment with a remote BIG-IP disaster recovery device, in the event that both the BIG-IP HA devices become unavailable. However, it can be a manual and time-consuming process to maintain the BIG-IP disaster recovery device with the most current configuration.

The procedures below describe how to configure your HA environment to add a remote BIG-IP disaster recovery device to the HA configuration synchronization.

Important: By including the BIG-IP disaster recovery device in the BIG-IP HA device group, you can configure the BIG-IP HA devices to synchronize to the BIG-IP disaster recovery device. The BIG-IP disaster recovery device can also synchronize its configuration to the BIG-IP HA devices.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • The BIG-IP HA devices and the remote BIG-IP disaster recovery device are able to connect across a common or routed network.
  • You configured your disaster recovery remote environment with duplicate resources used in the HA environment.
  • You have administrative access to all BIG-IP devices.

Important: To ensure the BIG-IP disaster recovery device requires the Force Offline state, you must review the Deploying the BIG-IP DR device section below, before you synchronize the HA configuration to the BIG-IP disaster recovery device.

Procedures

  • Configuring the BIG-IP HA devices
  • Deploying the BIG-IP disaster recovery device
  • Using the REST interface to set the Forced Offline state
  • Configure NTP on all devices
  • Adding the BIG-IP disaster recovery device to the BIG-IP HA pair device trust
  • Adding the BIG-IP disaster recovery device to the Sync-Failover device group

Configuring the BIG-IP HA devices

Notes:

  • The following procedure assumes you deployed the BIG-IP HA devices. If you are deploying a new pair of BIG-IP HA devices, refer to the Administration Creating an Active-Standby Configuration Using the Setup Utility chapter of the BIG-IP LTM BIG-IP Device Service Clustering guide, or the Administration Creating an Active-Standby Configuration Using the Setup Utility chapter of the BIG-IP TMOS: Implementations guide.
  • For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • In the HA pair that is in the Sync-Failover configuration, configure the Device Connectivity settings for the configuration synchronization (ConfigSync) local IP addresses to use a common network that allows all the devices (the BIG-IP HA devices and the BIG-IP disaster recovery device) to connect to each other for a specific Virtual Local Area Network (VLAN).

    For BIG-IP device ConfigSync connectivity, you may need to use the external facing VLAN addresses or a network tunnel through a dedicated VLAN between the data centers.

Important: Avoid using a floating self IP address on the VLAN used as the common network for ConfigSync.

Deploying the BIG-IP disaster recovery device

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Deploy the BIG-IP disaster recovery device using the Setup utility, which is available from the Configuration utility.
  2. Use a unique self IP address to configure the BIG-IP disaster recovery device as an HA device of the existing, Sync-Failover BIG-IP HA pair. 
  3. Ensure the following exactly match the BIG-IP HA pair configuration:
    • Software version
    • VLAN names
    • Provisioning and floating self IP addresses (excluding the configuration synchronization VLAN, where no floating self IP addresses should be configured)
  4. On the BIG-IP disaster recovery device, configure the Device Connectivity settings as follows:
    • Set Failover Network to No IP Address.
    • Set Mirroring (local mirror address) to None.

      This sets the local mirroring IP address to any6.

      Note: When your environment uses IPv6, and you configure the BIG-IP with a mirroring-enabled object, you may need to configure your network firewall or the BIG-IP disaster recovery device to block IPv6 from emanating from the BIG-IP disaster recovery device. Doing so prevents the BIG-IP HA devices from sending or receiving state information from the BIG-IP disaster recovery device. For more information on creating a packet filter for the BIG-IP, refer to the Packet Filters chapter of the BIG-IP LTM BIG-IP TMOS: Routing Administration guide.

      The BIG-IP disaster recovery device does not detect the state of the BIG-IP HA devices and promotes itself to the Active state.

  5. When you have a network environment with configuration objects—such as floating self IP addresses and/or virtual addresses—that can conflict with BIG-IP HA advertised addresses, F5 strongly recommends that you place the BIG-IP disaster recovery device in the Force Offline state, before you configure the floating self IP addresses of the device.

    The BIG-IP disaster recovery device remains in the Forced Offline state until the device is required to handle traffic (Release Offline). When either of the BIG-IP HA devices become available, the system places the BIG-IP disaster recovery device back in the Forced Offline state.

    Note: Because the BIG-IP disaster recovery device resides in an isolated network environment that is separate from the ConfigSync common network shared with the BIG-IP HA devices, when your deployment directs traffic to the BIG-IP disaster recovery device through Border Gateway Protocol (BGP), DNS, anycast or manual route changes, you do not need to set the BIG-IP disaster recovery device to the Forced Offline state.

Using the REST interface to set the Forced Offline state

Impact of procedure: Performing the following procedure places the BIG-IP disaster recovery device in the Offline state; it requires manual interaction to release the Offline state.

  • To set the system database variable failover.forceoffline to enable, use the following syntax:

    curl -sk -u admin:default -H "Content-Type: application/json" -X PUT -d '{"value":"enable"}' https://<dr device ip address>/mgmt/tm/sys/db/failover.forceoffline

  • To set the system database variable failover.forceoffline to disable, use the following syntax:

    curl -sk -u admin:default -H "Content-Type: application/json" -X PUT -d '{"value":"disable"}' https://<dr device ip address>/mgmt/tm/sys/db/failover.forceoffline

Configure NTP on all devices

To synchronize BIG-IP devices, the time on all the BIG-IP devices of the device group must be accurate.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • Ensure that the BIG-IP HA devices and the BIG-IP disaster recovery device are properly configured for network time protocol (NTP).

    For more information refer to the General Configuration Properties chapter of the BIG-IP LTM BIG-IP TMOS: Concepts guide.

Adding the BIG-IP disaster recovery device to the BIG-IP HA pair device trust

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • To synchronize the configuration of the BIG-IP HA pair to the BIG-IP disaster recovery device, you need to add the disaster recovery device to the BIG-IP HA pair device trust.

    For more information refer to the Administration Managing Device Trust chapter of the BIG-IP LTM BIG-IP Device Service Clustering guide.

    Note: To use TMOS Shell (tmsh) to add the BIG-IP disaster recovery device to the BIG-IP HA pair device trust, refer to K13639: Configuring a device group using tmsh.

Adding the BIG-IP disaster recovery device to the Sync-Failover device group

To include the BIG-IP disaster recovery device as part of device group configuration synchronization, you must add the BIG-IP disaster recovery device to the existing BIG-IP HA device group.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

To add the BIG-IP disaster recovery device to the existing device group, do the following:

Enable the Forced Offline state

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Devices.
  3. Click the name of the BIG-IP disaster recovery device.
  4. Click Force Offline.

Add the disaster recovery device to the existing device group

  1. Log in to the Configuration utility of one of the BIG-IP HA pair devices.
  2. Navigate to Device Management > Device Trust > Peer List.
  3. Click Add.
  4. In the Device IP Address box, enter the IP address of the BIG-IP disaster recovery device.
  5. In the Administrator Username box, enter the administrative username.
  6. In the Administrator Password box, enter the administrative user password.
  7. Click Retrieve Device Information.
  8. Click OK.
  9. Navigate to Device Management > Overview.
  10. Click the name of the HA device.
  11. Click Sync Device to Group.
  12. Click Sync.
  13. Navigate to Device Management > Device Groups.
  14. Click the name of the Sync-Failover device group.
  15. In the Available column, click the BIG-IP disaster recovery device.
  16. Click << to add the BIG-IP disaster recovery device to the Includes column.
  17. Click Update.
  18. Navigate to Device Management > Overview.
  19. Click the name of the HA device.
  20. Click Sync Device to Group.
  21. Click Sync.
