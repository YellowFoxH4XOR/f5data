Description

F5 iHealth takes the system configuration data and produces a custom diagnostics. iHealth helps to identify and protect against emerging threats, troubleshoot more quickly and check system overall health.  iHealth diagnostics support identify
•    Known Issues
•    Security Vulnerabilities
•    Best Practices
•    Comparisons of configuration to identify common configuration errors
•    Upgrade Advisor
•    Hardware Status
•    Performance Graphs
 

Environment

  • F5 iHealth 
  • Performance Graphs

Cause

None

Recommended Actions

Generating iHealth Diagnostics:  

Generate QKView  >> Download to work station >> Upload to iHealth.f5.com >> View the diagnostics output 

The initial report always starts with the Status Overview dashboard, which provides diagnostics results including any issues identified and possible upgrade options.  From here you can navigate to a variety of available information that will help you assess BIGIP system overall health and performance. iHealth performance can be viewed using standard and custom graphs.

  • Standard 
  • Custom Static
  • Custom Interactive
  • Groups

Standard Graphs

To access the Standard performance graphs, select the graphs on the left pane.

  1. Access the iHealth graphs

  2. Select the graph for viewing from the available list.

A typical BIGIP device contains the below options.
 

  • Select the checkbox next to the list and select the view selected button.
  • You can further narrow down the graphs to 30 days, 7days, 1 day, 3hours or to a customized date.

Note: iHealth graphs are available for a maximum of 30 days

Custom Static Graphs: In this section, you can view predefined custom graphs for

  1. System CPU Usage
  2. Blade 0 CPU Usage By Core
  3. Memory Used

Custom Interactive Graphs:

In this section, you can either view the Predefined graphs or create a customized graph and you can interactively access the graphs for a specific time frame.
To create custom interactive graphs, navigate to custom interactive graphs

  1. Select the create button
  2. Provide the required information.
  3. From data sets, select add
  4. Select the required information from the data set.
  5. Select Add.
  6. Select the Save Graph.
  7. To view the graph, select the name of the graph that you created.

Groups:  

In this section, you can configure custom interactive graphs for multiple groups from the available graphs.
To create custom groups graphs, navigate to custom interactive graphs

  1. Select the create button
  2. Provide the Group name From available graphs, choose the required groups and move to the Members
  3. Select the Save Group
  4. To view the graph for the Group you created, select the Group name from the available Groups.
