Topic

When running the eud_info command in BIG-IP 9.4.6 through 9.4.8, the system may prompt you to run the eud_info --xtract command as displayed in the following output:

eud_info: system EUD has no recorded version. Use '--xtract' option

When running the eud_info --xtract command, the system displays the EUD version along with an error message that appears similar to the following example:

warning: This system has no 'throttle' utility.

The eud_info --xtract command calls the /usr/bin/throttle utility, which is included in BIG-IP LTM 10.x to limit CPU usage when extracting EUD information. The throttle utility is not available for BIG-IP 9.x.
