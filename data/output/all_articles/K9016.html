K9016: Leaf node numbers will change for imported acceleration policies

Topic

A unique leaf node number is associated with each leaf node in a BIG-IP WebAccelerator acceleration policy. The leaf node number will appear in the X-PvInfo HTTP header as an A code or RA code.

Note: For information about the X-PvInfo header information, refer to the Viewing X-PvInfo response headers section of the Using HTTP Headers chapter in the BIG-IP WebAccelerator Policy Management Guide.

When an acceleration policy is imported from another BIG-IP WebAccelerator, the leaf node numbers will change for the imported policy and will not be the same as the original policy.
