K000138075: Application Editor Role not effective on GTM

Type
Support Solution
Published
2024-01-02
Updated
2024-01-02
Source
https://my.f5.com/manage/s/article/K000138075

Description

Application Editor Role for GTM/DNS module

  • Could not modify GTM/DNS pool
  • User with above role is able to enable/disable DNS pool via webui but unable to perform any of action pertaining to DNS pool via tmsh.


Environment

  • GTM/DNS
  • DNS pool
  • User configured with Application Editor Role

Cause

Function as Designed. Application Editor Role are only allow to enable/disable/offline/remove/add pool member for LTM module.

Recommended Actions

Nil

Additional Information

User should not be able to enable/disable DNS pool via weubi and bugid ID1441829 documented this.
