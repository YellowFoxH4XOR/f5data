K8626: Upgrading or importing a security policy to BIG-IP ASM 9.4.2 or later from a previous version may result in valid requests being blocked

Known Issue

This is the result of a known issue. Starting in BIG-IP ASM 9.4.2, the Check Objects check box was removed from the Object Types entity. As a result, if you upgrade from a previous version of BIG-IP ASM, or import a security policy from a version prior to 9.4.2 to 9.4.2 or later, the BIG-IP ASM 9.4.2 or later system checks those objects. As a result, the security policy may block valid requests.

Note: This issue occurs even if you disable the Check Object setting prior to upgrading.

F5 Product Development is tracking this issue as CR94835 and it was fixed in BIG-IP ASM 10.0.0. For information about upgreading, refer to the BIG-IP ASM Release Notes.

Workaround

To work around this issue, refer to K8619: Configuring the BIG-IP ASM security policy to not check objects of a specific object type.
