Description

Performance impact when applying ASM policies to any virtual servers

Environment

ASM

Cause

N/A

Recommended Actions

No license restriction on how many number of policy can be applied to virtual servers. But following article explain number of security policy supported

K6723: Number of security policies supported by the BIG-IP ASM system

Performance impact is based on many factors as below:

  • How many number of policy need to be applied to virtual servers
  • How many number of policies uses policy builder
  • What are the features enabled in each policy
  • Traffic pattern
  • Current resource allocation in terms of CPU and memory
  • Etc...
Predicting  resource consumption when applying the policy to many virtual serves will be difficult as there are may factors as above. 

Recommendation is to apply the polices gradually ( in batches) and monitor the CPU and memory.
