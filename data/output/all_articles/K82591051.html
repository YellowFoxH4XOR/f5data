Known Issue

Connections from Linux host processes to the Traffic Management Microkernel (TMM) intermittently fail on chassis-based BIG-IP devices

This issue occurs when the following condition is met:

  • You use a module and feature that require Linux host process communication to TMM within a chassis.

When using features that require a process on the Linux host to connect to a specific TMM within a chassis, those connections intermittently fail. As a result, the feature may display incorrect behavior, such as failure to create sessions in BIG-IP APM.

Note: In BIG-IP 11.4.1, only HF9 is affected.

Impact

This issue may result in possible service failure, such as disallowing entry to BIG-IP APM.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • User sessions intermittently fail to establish through BIG-IP APM.
  • Messages log to the /var/log/ltm file that appear similar to the following example:

    err tmm[17082]: 01230140:3: RST sent from 127.20.1.1:8217 to 127.20.1.254:10001, [0x2185456:1924] TCP 3WHS rejected
