K000138348: Ansible playbook fails to import key with passphrase on FIPS licensed VE

Type
Support Solution
Published
2024-01-24
Updated
2024-01-24
Source
https://my.f5.com/manage/s/article/K000138348

Description

  • Ansible playbook to import keys and cert fails on FIPS licensed BIG-IP VE.
  • If BIG-IP VE is not FIPS licensed there is no issue.

Environment

  • BIG-IP VE with FIPS license
  • bigip_ssl_key_cert module
  • f5networks.f5_modules:1.27.1

Cause

Seen behaviour is the result of an issue with with the bigip_ssl_key_cert module on collections with version 1.27.1 or older.

Recommended Actions

A fix has been merged in the latest collection. Please install the daily build of the collection with the following command:

ansible-galaxy collection install git+https://github.com/F5Networks/f5-ansible.git#ansible_collections/f5networks/f5_modules -p ./collections
