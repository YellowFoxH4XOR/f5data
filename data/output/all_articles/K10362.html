Known Issue

This is the result of a known issue. In BIG-IP 10.x, provisioning and licensing work together to ensure that BIG-IP software modules are accessible and provided with the appropriate system resources. When you roll forward a BIG-IP 9.x UCS file configured for both BIG-IP ASM and GTM, resource provisioning is disabled for the BIG-IP GTM module under version 10.x.

F5 Product Development is tracking this issue as ID 247488 (formerly CR120828).

Workaround

To enable resource provisioning for BIG-IP GTM, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to System > Resource Provisioning.
  3. Under Module Resource Provisioning, select the provisioning level you want from the Global Traffic (GTM) menu.
  4. Click Update.
