Description

The BIG-IP Access Policy Manager (APM) acting as a Security Assertion Markup Language (SAML) Service Provider (SP) does not support AES256-GCM as the data encryption method for the SAML Assertion from a SAML Identity Provider (IdP).

If the SAML IdP sends a SAML Assertion with AES256-GCM as the data encryption method to the BIG-IP APM SAML SP, you would observe an error similar to the following example in the /var/log/apm file:

01490202:3: /Common/mytest-apm-session:Common:09074b8b: SAML Agent: /Common/myauth_act_saml_auth_1_ag failed to process encrypted assertion, error: Unsupported encryption algorithm.

Environment

  • The SAML IdP uses AES256-GCM as the data encryption method for the Assertion

Cause

This is ID 824885.

Recommended Actions

Upgrade or update your BIG-IP system to a version that is fixed in ID 824885.
