K9408: Enabling and disabling PDF linearization on the BIG-IP WebAccelerator

Topic

With the default BIG-IP WebAccelerator configuration, PDF linearization cannot be disabled using an acceleration policy because the globalfragment.xml file's default objType definition for PDF files contains the transformFile="pdf.code" entry. The globalfragment.xml file's transformFile entry will override any Response Rewriting configurations made in the assembly rules of an acceleration policy.

To globally disable PDF linearization, and selectively enable PDF linearization, perform the following two procedures:

  • Globally disable PDF linearization
  • Enable PDF linearization for a specific acceleration policy

Globally disable PDF linearization

To globally disable PDF linearization on the BIG-IP WebAccelerator, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Change directories to the /config/wa directory by typing the following command:

    cd /config/wa
  3. Back up the original globalfragment.xml file by typing the following command:

    cp globalfragment.xml globalfragment.xml.sol9408
  4. Open the globalfragment.xml file in a text editor.
  5. Remove the transformFile"pdf.code" entry from the objType entry for PDF files. For example:

    <objType
                    type="pdf"
                    group="documents"
                    category="common"
                    displayName="PDF"
                    ext="pdf"
                    mimeType="
                        text/pdf,
                        text/x-pdf,
                        application/pdf,
                        application/x-pdf,
                        application/acrobat,
                        application/vnd.pdf"
                    compressToClient="wa"
                    transformFile="pdf.code"           <-- Delete this Line
                />
  6. Save the globalfragment.xml file. 
  7. Clear the BIG-IP WebAccelerator cache by typing the following command:

    wa_clear_cache

Newly requested unlinearized PDF files will no longer be linearized. 

Enable PDF linearization for a specific acceleration policy

To enable PDF linearization for a specific acceleration policy, perform the following procedure:

Note: Pre-defined Acceleration policies are not modifiable; this procedure must be performed on a User-defined Acceleration policy.

  1. Log in to the BIG-IP WebAccelerator Configuration utility.
  2. Click WebAccelerator.
  3. Click Policies.

    A new Policies Configuration window opens.
  4. Click on the User-defined Acceleration policy to be configured.
  5. Click the plus ( + ) sign to expand the Site nodes.
  6. Click the plus sign to expand the Static nodes.
  7. Click the plus sign to expand the Documents nodes.
  8. Click on the PDF node.
  9. Select Acceleration Rules from the drop-down menu.
  10. Click on the Assembly menu tab.
  11. Select Advanced from the Content Assembly Options drop-down menu.
  12. Select pdf.code from the Response Rewriting drop-down menu.
  13. Click the Save button.
  14. Click the Publish button.
  15. Optionally, type a comment or note in the Comment field.
  16. Click the Publish Now button.
