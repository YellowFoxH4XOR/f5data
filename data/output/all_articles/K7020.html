Issue

Error Message

Validation Warning in prober_def: Prober <IP Address> not previously declared.

In this error message, note the following:

  • <IP Address> is the configured prober address.

For example:

Validation Warning in prober_def: Prober 10.10.10.10 not previously declared.

Message Location

You may encounter this message in the following locations:

  • The /var/log/gtm file
  • The BIG-IP GTM system console

Description

This message occurs when all of the following conditions are met:

  • A prober address in the /config/gtm/wideip.conf configuration file is listed before the BIG-IP GTM object.
  • The gtmload or gtmparse command is used from the command line.

The prober address is found within the server object.

For example:

server { // datacenter=dc1, #VS=1   name            "host1"   type            load balancer   box {      address 10.1.1.132      unit_id 1   }   prober  10.1.1.16    <== Prober definition   monitor "gateway_icmp"   vs {      name            "10.1.1.132"      address         10.1.1.132:80 // http   }}server { // datacenter=dc1, #VS=0   name            "GTM"   type            bigip   box { // gtm         <== GTM object      address 10.1.1.16      unit_id 1   }   monitor "bigip"}

If you perform a gtmload or gtmparse with the previous configuration, the previous error message is reported to the console and is also logged to the /var/log/gtm file.

Impact

This is a warning message indicating that the address has not been previously seen, because the address was parsed before the declared address was parsed in the BIG-IP GTM object. This message will not affect probing in any way; it is an informational message.
