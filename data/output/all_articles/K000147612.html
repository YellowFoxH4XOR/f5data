K000147612: How do I work with MX records?

Type
Support Solution
Published
2024-11-08
Updated
2026-01-15
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud DNS Management
Source

Description

  • An MX record defines the mail servers responsible for accepting email on behalf of your domain (e.g., example.com).
  • These records instruct email delivery agents where they should deliver your email.

Environment

  • F5® Distributed Cloud Primary DNS

Cause

  • None

Answer

MX records must point to a domain name and require the following values:

  • Mail Server: The value points to the mail server's domain name (e.g., mail, mail.example.com), which accepts email on behalf of the domain.
  • Priority: The priority number indicates the preference for available MX records, where lower values are preferred.

The mail server with the lowest priority is always attempted first by email delivery agents when sending an email. If this mail server is unavailable or results in a message send failure, the agent will try the next mail server based on priority.

If multiple values share the same priority, the email delivery agent will select one mail server in a round-robin type fashion. Note that the distribution of how these records are selected by email agents is not predictable.
