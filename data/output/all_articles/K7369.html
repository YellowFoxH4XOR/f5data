Topic

The method for shutting down and restarting a BIG-IP system varies depending on whether the hardware platform is equipped with the Switch Card Control Processor (SCCP) or an Always-On Management (AOM) subsystem. The SCCP or AOM are separate subsystems that control the switch hardware.

Note: To determine whether a BIG-IP platform has an SCCP or AOM, refer to K9476: The F5 hardware/software compatibility matrix.

For information about shutting down and restarting VIPRION systems, refer to K11333: Rebooting or shutting down all blades in a VIPRION system.

For information about R series devices, refer to K000132560: rSeries appliance does not boot up, shows only AOM menu prompt on console.

Note: Shutting down a vCMP-provisioned BIG-IP system from the host does not first safely shut down guests. You should disable the vCMP guests before shutting down the vCMP host. For more information about disabling the vCMP guests, refer to K20081511: Shutting down and restarting the vCMP guest from the vCMP host.

Description

Shut down and restart BIG-IP platforms without an SCCP or AOM

  • Shut down
  • Restart

Shut down

  1. Log in to the command line.
  2. To halt the system, enter the following command:

    halt

    When you see the message indicating that the system is halted, you can safely turn off the power.

Restart

  1. Log in to the command line.
  2. To restart a BIG-IP platform without an SCCP or AOM, enter the following command:

    reboot

    Note: The BIG-IP restart process can take an average of four to eight minutes, depending on the BIG-IP device, resources, and configuration.

    Large configurations and configurations that include firewall rule compilation may take additional time to complete.

Shut down and restart BIG-IP platforms with an SCCP or AOM

To shut down and restart BIG-IP platforms that are equipped with the SCCP or AOM, use one of the following methods:

  • LCD panel
  • LCD touchscreen
  • Command line
  • SCCP
  • AOM

LCD panel

Note: You must halt the BIG-IP system before shutting it down or restarting it when you use the LCD panel.

To shut down BIG-IP platforms by using the LCD panel, perform the following procedure:

  1. Press X, and then use the arrow keys to navigate to the System menu.
  2. Press Check, and navigate to the Halt menu.
  3. Press Check.
  4. Press Check again at the confirmation screen.
  5. Wait 60 seconds before shutting down or restarting the machine.

    Important: After halting the unit from the LCD panel, you must wait at least 60 seconds before shutting down or restarting the unit. Failure to do so may result in unexpected behavior due to improperly shutting down the system.

To turn off the unit by using the LCD panel, hold down the X button for approximately four seconds.

To restart the unit by using the LCD panel, hold down the Check button for approximately four seconds.

LCD touchscreen

Note: The iSeries platforms have an LCD touchscreen.

To shut down the BIG-IP platforms using the LCD touchscreen, perform the following procedure:

Note: This procedure performs a shutdown of the BIG-IP operating system.

  1. To activate the LCD menus, touch the screen.
  2. Tap the System menu.
  3. On the System screen menu, swipe to scroll down to Halt.
  4. Tap Halt
  5. To shut down the unit, tap Confirm

To reboot BIG-IP platforms using the LCD touchscreen, perform the following procedure:

Note: This procedure performs a soft reboot and restarts the BIG-IP operating system.

  1. To activate the LCD menus, touch the screen.
  2. Tap the System menu.
  3. On the System screen menu, tap Soft Reboot.
  4. To restart the unit, tap Confirm.

Note: The F5 logo ball on the chassis front panel remains on when you shut down the unit.

Command line

To shut down BIG-IP platforms using the command line, perform the following procedure:

Note: The BIG-IP restart process can take an average of four to ten minutes, depending on the BIG-IP device, resources, and configuration.

Large configurations and configurations that include firewall rule compilation may take additional time to complete.

  1. Log in to the command line.
  2. To shut down the BIG-IP system, enter the following command:
    • TMOS shell (tmsh)

      (TMOS)# shutdown

    • Advanced Shell (bash)

      # shutdown -h now

  3. To restart BIG-IP platforms using the command line, enter the following command using tmsh or bash:

    reboot

SCCP

For information about shutting down or restarting the system by using the SCCP Host Console Shell, refer to K3757: Rebooting the BIG-IP system remotely when the command line is not available. For information about accessing the SCCP, refer to K3454: Overview of the SCCP.

AOM

For information about shutting down or restarting the system from the AOM menu, refer to K9403: Overview of the AOM subsystem.
