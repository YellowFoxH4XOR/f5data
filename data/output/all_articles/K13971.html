Known Issue

The QPDF application may restart and produce a core file when the BIG-IP AAM system or the BIG-IP WebAccelerator system linearizes a PDF document.

This issue occurs when the following condition is met:

  • The BIG-IP AAM or BIG-IP WebAccelerator system is attempting to linearize a PDF document that contains no pages.

BIG-IP AAM and BIG-IP WebAccelerator use the open-source QPDF application for processing of PDF files. When QPDF encounters a PDF file with no pages, the application produced a core file. Such malformed PDF files may be the result of dynamically generated PDF documents with no content.

Impact

PDF linearization will not be performed while the QPDF application restarts. However, the system continues to serve original PDF files proxied directly from the origin web server.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H515317 on the Diagnostics > Identified > Medium screen.
  • A QPDF core file will be located in the /var/core directory.
  • In the /var/log/wa/wamd.log file, you observe the following error messages:

    /usr/bin/pdlin.sh: line 104: 3724 Segmentation fault (core dumped) qpdf --linearize --preserve-id "$INPUT_FILE" "$OUT_FILE" > /dev/null 2>&1

    WA pdlin qpdf failed to optimize PDF, returning original

Workaround

There is no formal workaround to this issue. In most cases the core file is small, the core occurs infrequently, and you can safely ignore it.

However, if this issue is occurring frequently and it severely impacts system performance, you can mitigate this issue by disabling linearization in the acceleration profile.

Impact of mitigation: Disabling linearization causes the BIG-IP AAM or BIG-IP WebAccelerator system to proxy all PDFs to the origin web server, and may impact performance greater than the original issue does. The impact of disabling linearization depends on the specific environment. F5 recommends that you test any such changes during a maintenance window with consideration to the possible impact on your specific environment.
