Description

The SNAT Pool feature permits you to specify one or more IP addresses as the source IP address of connections forwarded by the BIG-IP system.

When there is more than one IP address specified in the SNAT Pool feature, the system uses the first IP address in the list for the first connection from the pool, the second IP address for the second connection, and so on until each SNAT Pool IP address has been used at least once. Then, the system employs the Least Connections load balancing method to ensure the IP addresses are evenly used by all subsequent connections.
