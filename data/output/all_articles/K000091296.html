K000091296: NGINX Ingress Controller's VirtualServer host field does not support wildcard domains

Type
Support Solution
Published
2022-03-01
Updated
2022-03-01
Source
https://my.f5.com/manage/s/article/K000091296

Description

  • NGINX Ingress Controller's VirtualServer host field does not support wildcard domains

Environment

  • NGINX Ingress Controller VirtualServer deployment

Cause

  • Not supported

 Recommended Actions

  1. Implement wildcard domain within server-snippets
    1. Implement a fake hostname value for host field
    2. Implement the actual wildcard domain hostname within server-snippets
    3. Note:
      1. This will result in two server-name directives
      2. The host field domain can be different from the server-snippets wildcard domain
    4. Example:

apiVersion: k8s.nginx.org/v1
kind: VirtualServer
metadata:
  name: cafe
spec:
  host: <your_domain>.example.com
  tls:
    secret: cafe-secret
  server-snippets: |
    server_name *.<your_domain>.com;
...
 

Additional Information

NGINX Ingress Controller documentation: VirtualServer Specification

Support for wildcard domains in the VirtualServer host field will be in NGINX Ingress Controller release 2.2.0, subject to change
