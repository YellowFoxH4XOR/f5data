Known Issue

The b64decode iRule command may cause a TMM memory leak when the base-64 decode operation fails.

The b64decode iRule command leaks resources when the decode operation fails to complete, for example, if the input string is not properly-encoded base-64 data.

Impact

Performance may degrade over time and the system may eventually become unresponsive due to memory exhaustion.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The system may eventually become unresponsive due to memory exhaustion.
  • The system may unexpectedly fail over or the TMM process may restart.
  • The tcl (variable) memory utilization grows over time.

    For example, running the following command over time may indicate that the memory utilization for the tcl (variable) object grows:

    tmctl memory_usage_stat | grep "tcl (variable)"
