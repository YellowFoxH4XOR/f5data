K000159570: BIG-IP VE license validation for SDN Services and Kubernetes ingress controller integration

Description

When attempting to configure BIG-IP Virtual Edition (VE) as a Kubernetes ingress controller, you need to validate whether your license includes SDN Services support, which is a prerequisite for this integration.

Symptoms:

  • Running the tmsh command show sys license | grep 'SDN Services' returns no results
  • Uncertainty about whether the current BIG-IP VE subscription supports Kubernetes ingress controller functionality
  • Need to determine if a license upgrade is required

Environment

  • BIG-IP Virtual Edition (VE)
  • BIG-IP version 17.1.x
  • Platform: F5-LTM-1G-PRM-SUB
  • Use case: Kubernetes ingress controller integration

Cause

The BIG-IP VE subscription license does not include SDN Services capability, which is required for Kubernetes ingress controller functionality. Standard LTM and Advanced WAF subscriptions alone are not compatible with Kubernetes ingress controller requirements.

Recommended Actions

To validate SDN Services support on your current license:

  1. Access the BIG-IP command line interface
  2. Run the following tmsh command:
    show sys license | grep 'SDN Services'
  3. If the command returns no output, SDN Services is not included in your current license

To obtain Kubernetes ingress controller capability:

  • Contact your F5 Customer Success Manager to discuss licensing options
  • Consider one of the following solutions:
    • Upgrade your current BIG-IP license to include SDN Services compatibility
    • Purchase a BIG-IP Next for Kubernetes subscription SKU
    • Evaluate NGINX subscription licenses for Kubernetes ingress controller capabilities

Additional Information

BIG-IP subscriptions with only LTM and Advanced WAF modules do not include the SDN Services feature required for Kubernetes ingress controller integration. A specific license entitlement or subscription type is needed to enable this functionality.

Different F5 product lines offer Kubernetes ingress controller capabilities:

  • BIG-IP with SDN Services enabled
  • BIG-IP Next for Kubernetes
  • NGINX-based solutions
