Known Issue

This is the result of a known issue. The big3d process may crash on a heavily loaded BIG-IP GTM system while processing DNS path probes. This issue can occur when a DNS probe protocol such as DNS_DOT or DNS_REV is configured on the BIG-IP GTM system, and the big3d process makes repeated attempts to gather path data from LDNS servers.

F5 Product Development tracked this issue as CR135713 and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP GTM release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
