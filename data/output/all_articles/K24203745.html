Description
While creating a draft policy from an existing (published) Policy, there is an immediate impact on the traffic going through this policy. 
Publishing the draft policy again will restore the traffic back.
Environment

  • BIG-IP LTM
  • LTM policy
  • HTTP2 profile 

Cause

  • Believed to be ID 1921049

Recommended Actions
As a workaround:

  1. Remove http2 profile before creating the draft policy from the Virtual Server.
  2. Create the Draft Policy without interrupting the traffic.
  3. Set back the http2 profile.
