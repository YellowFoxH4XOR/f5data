Known Issue

Files in the /etc/ssh/ directory are not backed up in user configuration set (UCS) archives.

This issue occurs when the following conditions are met:

  • You perform a UCS restore operation.
  • You upgrade the BIG-IP system and choose to move the configuration to the new boot location.

    Note: The BIG-IP system performs a UCS restore operation when you chose to move the configuration when performing an upgrade. The BIG-IP system installs a UCS to the new boot location.

Impact

SSH operations, such as auto-login, may be affected.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Configuration files in the /etc/ssh/ directory are not backed up or restored, such as a non-standard SSH configuration.

Workaround

To work around this issue, you can add the /etc/ssh directory to the UCS backup configuration. To do so, refer to K4422: Viewing and modifying the files that are configured for inclusion in a UCS archive. All subsequent UCS backup and restore operations will now include the /etc/ssh/ directory.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
