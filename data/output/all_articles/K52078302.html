Source

Description

S6c interface is used for mobility related authentications. It takes care of transport of commands to retrieve and to store mobility parameters.
The following will show how to add AVPs as an additional interface for S6c, for Supported Application IDs. 
 

Environment

  • Traffix SDC/EMS
  • S6c interface

Cause

Add additional Application IDs to support additional interface.
 

Recommended Actions

From 5.1 CF-12, additional application IDs can be added in the standard_dynamic_example.txt file (located in the /opt/traffix/sdc/config directory).
Note: The default configuration for SDC version 5.1 is not support  S6c interface, but this interface can be added for the components.

The procedure in F5 SDC 5.1 Troubleshooting Guide section 5.3.7 Adding Additional Supported Application IDs, describe step how to add a new application ID S6c. 

1. Open the standard_dynamic_example.txt file (located in the /opt/traffix/sdc/config directory).

Note: The file is an example file.
Important: For EMS deployments, you need to update the standard_dynamic.txt file in the EMS site and not the SDC site. Changes made to the file in the EMS site will be implemented in the SDC site and reflected in the SDC site Web UI


2. Update the standard_dynamic.txt file for any additional Application Identifiers.

The following fields need to be defined:
  • Name
  • applicationId
  • protocol
  • vendorId
  • applicationType
  • fsmType


Example of Added Application IDs to a standard_dynamic.txt File

[root@ems1 traffix]# cat standard_dynamic.txt 
Name,applicationId,protocol,vendorId,applicationType,fsmType

##### Important Notes!!!
 #This file only example how to add new interfaces.
 #Location of this example file is : /opt/traffix/sdc<version>/config
 #File with new interfaces should renamed to standard_dynamic.txt and copy to folder :/opt/traffix/

 #Header Columns definitions: 
 #name -interface name
 #applicationId - application ID
 #protocol - Diamater
 #vendorId - vendor ID
 #applicationType - Auth,Acc,Both,Rating
 #fsmType - Stateless,Stateful,Compound

3. Copy the file standard_dynamic.txt to /opt/traffix directory and save it.
4. Check that any newly added application IDs are defined in the Dictionary. If not, you need to update the Dictionary.
5. Restart the Web UI, tomcat services, CFP and FEP components.

Note: Upon restarting the Web UI, remove any cookies from the web browser.


6. Verify that any added Application ID appears in the SDC Web UI (Topology > Specific Site Settings > Site > SDC Components > Diameter).

Note: When removing an application ID from the standard_dynamic.txt file, it will not be removed from the SDC Web UI (Topology > Specific Site Settings > Site > SDC Components > Diameter), until you restart the Web UI.
