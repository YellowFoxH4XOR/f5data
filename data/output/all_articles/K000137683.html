Description

A Common Vulnerabilities and Exposures (CVE) ID number is a unique identifier associated with a specific vulnerability in a computer system or software.

Environment

Any computer system or software.

Additional Information

The CVE program is administered by the MITRE corporation, partly funded by the Cybersecurity and Infrastructure Security Agency (CISA) which is part of the U.S. Department of Homeland Security.

When someone refers to "a CVE" they are typically referring to an individual CVE ID in the MITRE CVE list. CVE entries are brief and include only, at most, a short description and details of the impacted software versions, any credits for discovery and links to vendor advisories or research details. For example, you can see the CVE list entry for CVE-2023-46747 here: https://www.cve.org/CVERecord?id=CVE-2023-46747

For more information on the operation of the CVE program and F5's participation as a CVE Numbering Authority (CNA) you can read MegaZone's longer article on DevCentral (see Related Content below).

The important detail to remember is that, unlike other identifiers such as CWE, a CVE ID refers to a single specific vulnerability.

When opening a case with F5 to enquire regarding a vulnerability it is extremely helpful to include the CVE ID if possible, but do note that not all vulnerabilities are assigned CVE IDs and that the CVE Program is not the only national effort to assign specific identifiers to vulnerabilities, others include:

  • The Carnegie Mellon University CERT/CC Vulnerability Notes Database (VU#)
  • AusCERT Security Bulletins (ASB or ESB)
  • The China National Vulnerability Database of Information Security (CNNVD)
  • The China National Vulnerability Database (CNVD)
  • Japan Vulnerability Notes (JVN# or JVNVU#)
  • National Cyber Security Centre Finland Vulnerability Database (FICORA #)

Various commercial entities also maintain their own lists which can be used as an identifier for a specific, publicly known, vulnerability, often cross-referencing with the CVE Program list.
