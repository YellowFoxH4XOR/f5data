Known Issue

This is the result of a known issue. If you configure Active Directory authentication for a master group, and enter a group name that contains the number sign ( # ) character in the User must belong to Domain group field, authentication may fail. Similarly, if you configure Active Directory dynamic group mapping, and enter a group name that contains the number sign in the Active Directory Group field in the master group or resource group mapping table, group mapping may fail.

These issues occur when one of the following two conditions are met:

  • The Active Directory group name begins with a number sign and also contains a space character
  • The Active Directory group name contains a number sign, but the number sign is not the first character of the group name

For example, the following Active Directory group name would not be affected by this issue:

#SomeGroup

However, the following Active Directory group names would be affected by this issue:

#Some Group

Some#Group

Note: This issue occurs in FirePass version 6.0.3 after installing cumulative hotfix HF-603-5, or a later version of the cumulative hotfix.
