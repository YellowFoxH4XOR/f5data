Known Issue

Attempts to validate certificate bundles using the Traffic Management Shell (tmsh) may fail.

This issue occurs when all of the following conditions are met:

  • After a certificate bundle has been installed, your BIG-IP configuration is manually reloaded.
  • You use the tmsh run /sys crypto check-cert command to validate the expiration date of the certificates in the bundle.

Impact

Users may not be able to determine the validity of certificates.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Immediately after installing the certificate bundle, attempts to check the validity of certificates using the tmsh run /sys crypto check-cert command will report the validity of certificates correctly. The tmsh command output displays accurate information.
  • After manually reloading the BIG-IP configuration, attempts to check the validity of certificates using the same tmsh command fail to report the validity of certificates correctly. The tmsh command output does not display accurate information.

Workaround

To work around this issue, you can either use the Configuration utility to validate the certificates in the bundle or you can force the mcpd process to reload the configuration. To force the mcpd process to reload the configuration, refer to K13030: Forcing the mcpd process to reload the BIG-IP configuration. To validate the certificates using the Configuration utility, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to System > File Management > SSL Certificate List.
  3. Optional: If your SSL certificates reside in partitions other than the Common partition, select the partition name from the Partition box.
  4. Check the Expiration column for the certificate expiration date.

    Note: A red exclamation mark indicates that the certificate has expired, and a yellow exclamation mark indicates that the certificate will expire within 30 days.
