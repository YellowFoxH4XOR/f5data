Topic

Purpose

You should consider using this procedure under the following condition:

  • You want to configure syslog from the command line on the Enterprise Manager system

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have administrator or resource administrator access to the Enterprise Manager tmsh shell

Description

The Enterprise Manager Configuration utility supports basic syslog configurations, such as defining system log levels. To perform more extensive syslog customizations, you must use the tmsh syslog command.

Procedures

Listing the current syslog configuration

To list the current syslog configuration, perform the following procedure:

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  2. To list the current syslog configuration, type the following command:

    list /sys syslog all-properties

Modifying the syslog log levels

To modify the syslog log levels defined on the Enterprise Manager system, perform the following procedure:

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  2. To modify the level of information that syslog-ng sends to log files, use the following command syntax:

    modify /sys syslog <option>

    For example, the default log level range for the authpriv syslog facility is notice to emerg. To change the log level range for the authpriv syslog facility to warning to emerg, you would enter the following command:

    modify /sys syslog auth-priv-from warning
  3. Save the change by typing the following command:

    save /sys config

Defining a remote syslog server

To define a remote syslog server on the Enterprise Manager system, perform the following procedure:

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  2. To define a remote syslog server, use the following command syntax:

    modify /sys syslog remote-servers add { <name> { host <IP address> remote-port <port> }}

    For example, to add remote syslog server 10.10.10.1 with port 514 and name mysyslog, you would type the following command:

    modify /sys syslog remote-servers add { mysyslog { host 10.10.10.1 remote-port 514 }}
  3. Save the change by typing the following command:

    save /sys config
