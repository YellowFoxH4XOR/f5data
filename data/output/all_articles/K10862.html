Known Issue

Note: When polled, the sysObjectID.0 SNMP OID returns the vendor's authoritative identification of the network management subsystem contained in the entity. That is, a description that is intended to uniquely identify the managed network device. For example, when a management station polls a BIG-IP 1600 system for this OID, the BIG-IP system will reply with a value of bigip1600.

This is the result of a known issue. A BIG-IP 3900 system that is polled for the sysObjectID.0 SNMP OID, will return a value of unknown.

F5 Product Development tracked this issue as CR133364, and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.
