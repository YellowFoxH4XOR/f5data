Description

After upgrading to BIG-IP version 17.5.1, BrightCloud URL categorization database downloads are no longer logged in the previous log file location /var/log/wr_urldbdownload.log.

BcDownloadDb: file part_bcdb_9.484.bin start at 08/05/2025 22:39:59...... finished at 08/05/2025 22:40:08
BcDownloadDb: file part_bcdb_9.484.bin start at 08/05/2025 23:42:01...... finished at 08/05/2025 23:42:10
2025-08-06T00:37:21+03:00 notice boot_marker : ---===[ HD1.1 - BIG-IP 17.5.1 Build 0.0.7 <HD1.1> ]===---
2025-08-19T01:36:37+03:00 notice boot_marker : ---===[ HD1.1 - BIG-IP 17.5.1 Build 0.0.7 <HD1.1> ]===---

Environment

  • BIG-IP version 17.5.1
  • BrightCloud URL categorization database (Webroot integration)

Cause

The BrightCloud SDK update in BIG-IP 17.5.x changed how database downloads are logged and monitored. 

Recommended Actions

To verify the BrightCloud database version, inspect the files in the database directory. The file name and its timestamp indicate the current database version and last update.
ll /var/wr_urldb/bcdatabase/

total 433152
-rw-r--r--. 1 root root 442979471 Aug 23 16:02 full_bcdb_rep_new_9.501.bin   <<<===---!!!
-rw-r--r--. 1 root root    122296 Aug 24 01:42 public_suffix_list.dat
-rw-r--r--. 1 root root         0 Aug 24 01:42 tld_patch.dat

To confirm database updates, monitor changes in the file name and modification time in the database directory. A new file with a higher version number or a recent timestamp indicates a successful update.

For troubleshooting:

Ensure the wr_urldbd process is running.
bigstart status wr_urldbd

Review the wr_urldbd.out log for errors related to BrightCloud connectivity. Below output shows successful update and adding of records.
less /var/log/wr_urldbd.out

BC_SDK: 2025-08-26 11:06:36 INFO: Load URL RTU: Added 10100 records
BC_SDK: 2025-08-26 11:06:36 INFO: Load URL RTU: Added 7578 records
BC_SDK: 2025-08-26 11:06:36 INFO: Load URL RTU: Added 11763 records

Confirm network connectivity and DNS resolution to BrightCloud update servers (e.g., api.bcti.brightcloud.com).

Additional Information

Periodically check the database directory for new database files.
