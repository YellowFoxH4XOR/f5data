Known Issue

The Redirect URL response page setting may not be preserved following an upgrade.

This issue occurs when the following conditions are met:

  • The BIG-IP ASM system is running software prior to 11.4.x, and the Redirect URL response page setting is configured with a URL.
  • You upgrade the BIG-IP ASM system to 11.4.x, 11.5.3, or 11.6.0.

Impact

The Redirect URL response page setting is not preserved, and the system fails to send a URL redirect to the user when the security policy blocks a client request.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system fails to send a URL redirect to the user when the security policy blocks a client request.
  • The Redirect URL setting is blank when you navigate to Security > Application Security > Blocking > Response Pages > Redirect URL.

Workaround

To work around this issue, you can reconfigure the Redirect URL response page after upgrading. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Blocking > Response Pages > Redirect URL.
  3. In the Redirect URL box, enter the appropriate URL.
  4. Click Save.
