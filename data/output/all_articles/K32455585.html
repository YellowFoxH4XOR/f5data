K32455585: must be equal to the number of macro terminalouts.

Type
Support Solution
Published
2021-08-26
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K32455585

Description

If the configuration is not loading after re-activating the license or booting in a different location. Since the configuration is not loading you can not edit or modify the macro. 
You might see these messages:  

Error messages: Number of rules in macro call (/Common/macro_name) must be equal to the number of macro terminalouts.

Environment

  • Access policies and macros
  • BIG-IP APM v13.1.3

Cause

Unknown, probably a bad configuration with the macros

Recommended Actions

Only if you are working in an HA pair:

  1. Copy the bigip.conf file from the working BIG-IP to the non-working peer.
  2. Once you have replace the bigip.conf, run tmsh load sys config
  3. If you have errors like:
    01070712:3: Failed: name (/Common/email_otp_act_logon_page_ag_3_9) Cache path (/config/filestore/files_d/Common/customization_group_d/:Common:email_otp_act_logon_page_ag_3_9_120191_1) does not exist and there is no copy in trash-bin to restore from.
     
  4. You will need to rename files as the message request.
  5. Finally you will be able to load the configuration.

Additional Information

None.
