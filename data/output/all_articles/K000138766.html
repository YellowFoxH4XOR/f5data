K000138766: BIG-IP stuck in INOPERATIVE state after configuring with F5 Declarative Onboarding

Type
Support Solution
Published
2024-02-29
Updated
2024-02-29
Applies to
  • Public Cloud
  • Microsoft Azure
Source
https://my.f5.com/manage/s/article/K000138766

Description

Running F5 Declarative Onboarding on BIG-IP sometimes causes BIG-IP to be stuck in INOPERATIVE state.

Environment

  • BIG-IP
  • Running F5 Declarative Onboarding

Cause

Unsupported Azure instance type not listed in F5 BIG-IP Virtual Edition Supported Platforms is used.

Recommended Actions

Try using one of supported Azure instance types.

Additional Information

None
