Description
Beginning in BIG-IP 13.1.0.8, the Access Guided Configuration is available to assist in the deployment of APM configurations. However, it is only available within full licensed BIG-IP APM. The Guided Configuration option will not be present in with APM Lab licensing or APM Limited provisioning. If you are on a Lab License, please contact your Account Manager.

Environment

  • Configuration Utility
  • tmsh
  • BIG-IP APM

Cause
None

Recommended Actions

Confirming Access Guided Configuration through the Configuration Utility
Access Guided Configuration  Access > Guided Configuration
Impact of procedure: Performing the following procedure should not have a negative impact on your system.
  1. Log into the BIG-IP Configuration Utility.
  2. Go to  Access.
  3. Click Guided Configuration.

Confirming Access Guided Configuration through BIG-IP Command Line Interface
The apm_agc object will appear in the license details, the following steps will show how to review.
Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log on to the command line of the BIG-IP.
  2. To access the tmsh utility typethe following command:

    tmsh

  3. Run the following command:

    show /sys license detail | grep apm

    Note: Verify the command output contains "apm_agc" .

    Example:

    [root@apm01:Offline:Standalone] config # tmsh show /sys license detail | grep apm
