K000148444: Microsoft Defender detected malicious files in /var/ts/var/account/negsig

Type
Support Solution
Published
2024-11-07
Updated
2024-11-07
Source
https://my.f5.com/manage/s/article/K000148444

Description

Microsoft Defender may detect suspicious keywords in files under /var/ts/var/account/negsig.

 

Environment

  • BIG-IP ASM

 

Cause

The files /var/ts/var/account/negsig/ do contain keywords that can be considered malicious by scanners, however, the files are required and used by the BIG-IP ASM for its attack signature enforcement feature.

 

Recommended Actions

None. Files are not malicious
