Known Issue

BIG-IP APM access policy synchronization may fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with an access policy that includes SAML resources.
  • You use Access Policy Sync to attempt to synchronize the access policy to peer devices of a device group.

Impact

The access policy does not synchronize.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you attempt an Access Policy Sync, the system displays an error message similar to the following example:

    01070734:3: Configuration error: Cannot find saml_sp_connector object /<partition>/<saml object name> associated with saml_sso_config object /<partition>/<saml object name>

  • When you run Access Policy Sync, the system does not update the access policy on the BIG-IP APM peer devices.

Workaround

To work around this issue, you can manually create an unused saml-sp-connector on the peer device before running the Access Policy Sync, to allow the devices to synchronize. To do so, perform the following procedures:

Creating an unused saml-sp-connector with the tmsh

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) of the peer device, by typing the following command:

    tmsh

  2. Create a temporary saml-sp-connector named SomethingTOSync by typing the following command:

    create /apm sso saml-sp-connector SomethingTOSync {assertion-consumer-uri http://SomethingToSync entity-id http://SomethingTOSync.com }

  3. To exit the tmsh utility type the following command:

    quit

Synchronizing an access policy with the Configuration utility

Impact of workaround: The access policy will be synchronized with peer members of the device group.

  1. Log in to the Configuration utility of the device with which you want to sync the access policy.
  2. Navigate to Access Policy > Access Profiles > Policy Sync.
  3. Select the Access Policy that you want to synchronize with the BIG-IP APM peer device.
  4. Click Sync Access Policy.
  5. From the Device Group box, select the appropriate Device Group.
  6. In the Description box, briefly describe why you are running the synchronization.

    Optional: Leave the box blank (the default).

  7. Set the Use Source configuration on Target option to Yes.
  8. Click Sync.
