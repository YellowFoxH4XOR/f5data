K6283: Configuring BIG-IP to send an SNMP trap when an external switchport goes down

Topic

By default, the bigipNetLinkDown (1.3.6.1.4.1.3375.2.4.0.24) SNMP trap is sent when an internal switchport goes down.

You can configure an SNMP trap to be sent in the event that an external switchport goes down by performing the following procedure:

  1. Log in to the command line.
  2. Edit the /config/user_alert.conf file.
  3. Add the following lines to the end of the file:

    alert BIGIP_NET_NETERR_LINK_DOWN "Link: (.*?) is DOWN"{
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.24"
    }

  4. Restart the alertd process by typing the following command:

    bigstart restart alertd

F5 Product Development tracked a Request For Enhancement as ID 251817 (formerly CR46901) for the BIG-IP system to send an SNMP trap in the event that an external switchport goes down; this behavior was added in BIG-IP 9.2.0. Beginning in BIG-IP 9.2.0, the BIG-IP system sends a BCM56XXDERR_LINKSTATUS (1.3.6.1.4.1.3375.2.4.0.37) SNMP trap when an external switchport goes down.
