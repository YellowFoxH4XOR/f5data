K000092438: Failed to create a VCMP guest with error "VDisk install process failed"

Type
Support Solution
Published
2022-10-12
Updated
2022-10-13
Source
https://my.f5.com/manage/s/article/K000092438

Description

When attempting to create a new VCMP guest, you encounter the following error:

# show /vcmp guest all-properties

----------------   --------- ------   -------------------------------------------------------------
Sys::Vcmp::Guest
Name               Slot ID   Status   Requested    Request   Retries  Comment
                                      State        Complete
----------------   --------- ------   -------------------------------------------------------------
newguest           0         failed   deployed     true            3  VDisk install process failed.


You may find messages similar to the following in /var/log/ltm :

notice vcmpd[17319]: 01510006:5: Guest (newguest): Creating VDisk (/shared/vmdisks/newguest.img)
info vcmpd[17319]: 01510007:6: VDisk (newguest.img/0): Syncing with MCP - [filename:newguest.img slot:0 installed_os:0 state:1]
info vcmpd[17319]: 01510007:6: Guest (newguest): VS_ACQUIRING_VDISK->VS_WAITING_INSTALL
info vcmpd[17319]: 01510007:6: Guest (newguest): VS_WAITING_INSTALL->VS_INSTALLING_VDISK
notice vcmpd[17319]: 01510006:5: Guest (newguest): Installing image (/shared/images/BIGIP-14.1.4.6-0.0.8.iso) to VDisk (/shared/vmdisks/newguest.img).
info vcmpd[17319]: 01510007:6: VDisk (newguest.img/0): Syncing with MCP - [filename:newguest.img slot:0 installed_os:0 state:2]
info bcm56xxd[17258]: 012c0012:6: FFP DAGV2 installed for newguest (cmp state 0x1)
info vcmpd[17319]: 01510007:6: VDisk (BIGIP-14.1.4.6-0.0.8.iso.img/0): Adding.
info vcmpd[17319]: 01510007:6: VDisk (BIGIP-14.1.4.6-0.0.8.iso.img/0): Syncing with MCP - [filename:BIGIP-14.1.4.6-0.0.8.iso.img slot:0 installed_os:0 state:0]
crit vcmpd[17319]: 01510003:2: Guest (newguest):  Install failed.
crit vcmpd[17319]: 01510003:2:
err vcmpd[17319]: 01510004:3: Guest (newguest): Install to VDisk /shared/vmdisks/newguest.img FAILED: Child exited with non-zero exit code: 255

Environment

  • BIG-IP

  • VCMP guest

  • Non-default vcmp.vdisk.new_image_size value

Cause

The vcmp.vdisk.new_image_size value might be too small for the BIG-IP version you are attempting to install (on the new guest).

Recommended Actions

  1. Verify if you have a non-default vcmp.vdisk.new_image_size value. 
    # tmsh list sys db vcmp.vdisk.new_image_size all-properties
sys db vcmp.vdisk.new_image_size {
    default-value "150"    <===
    scf-config "true"
    value "150"            <===
    value-range "unsigned integer min:15 max:500"
}
    Make sure the current value is the same as the default-value.
     
  2. If vcmp.vdisk.new_image_size is not in the default value, revert it back to default 
    # tmsh modify /sys db vcmp.vdisk.new_image_size value 150
# tmsh save /sys config partitions all
  3. Try to create the guest again
