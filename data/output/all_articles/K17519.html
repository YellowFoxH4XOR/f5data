Known Issue

Virtual Clustered Multiprocessing (vCMP) guests are unable to create new Virtual Local Area Networks (VLANs) using the BIG-IP system's Setup utility.

This issue occurs when all of the following conditions are met:

  • You have deployed a new vCMP guest.
  • You log in to the Configuration utility of the vCMP guest and attempt to use the Setup utility.

Impact

Users cannot create VLANs using the BIG-IP system's Setup utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you use the Setup utility to configure a vCMP guest, the BIG-IP system displays an error message similar to the following example:

    The VLAN has no interface, do you want to continue?

Workaround

To work around this issue, you can add the appropriate VLANs to the guest, from the vCMP host, during deployment. For configurations such as route domains on the vCMP guest, you can access the VLAN menu after using the Setup utility.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
