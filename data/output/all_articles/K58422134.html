Description

Config sync is failing with the following error message in the GUI:  (Sync Failed): A validation error occurred while syncing to a remote device - 01070712:3: Caught configuration exception (0), Invalid monitor rule instance identifier: 1826.New changes to the active device cannot be synced to the standby unit.

Environment

  • BIG-IP with fqdn nodes/pools with monitors
  • Full config-sync

Cause

Unknown at the time of publication

Recommended Actions

  1. As mentioned in Bug ID1017513, Try using incremental sync instead of full sync
     
  2. If the issue persist, manually Identify configuration discrepancies between the active and standby device, specifically on pool and pool member configuration with fqdns included in them and manually match the different configuration, either by matching what the primary has to the standby, or by removing the different configuration from both units. In the following example, the issue reside in the following pool configuration, which includes fqdns and it's not matching between the paired units:

    Active:

    ltm pool /Common/pool {
        members {
            /Common/x.x.x.x:443 {
                address x.x.x.x
                monitor /Common/https
            }
            /Common/fqdn.com:443 {
                fqdn {
                    autopopulate enabled
                    name fqdn.com
                }
                monitor /Common/https
            }
        }
        monitor /Common/tcp

    Standby:

    ltm pool /Common/pool {
        members {
            /Common/fqdn.com:443 {
                fqdn {
                    autopopulate enabled
                    name fqdn.com
                }
            }
        }
        monitor /Common/https
    The config-sync error was solved by manually removing the different monitor and pool member configuration from the pool in each device, which matched the configuration in both device.
     
  3. After that, please execute a config-sync from the Active device which should be successful now.
