Description

You want to insert year format to the BIG-IP syslog.

Environment

  • BIG-IP
  • Syslog

Cause

None.

Recommended Actions

  1. Login to BIG-IP command line
  2. Use Linux editor to edit the syslog-ng configuration, in this case using nano editor.

    # nano /etc/syslog-ng/syslog-ng.conf
     
  3. Add ts_format(iso); at the last line inside options section

    options {
       dir_perm(0755);
       perm(0600);
       chain_hostnames(no);
       keep_hostname(yes);
       stats_freq(0);
       log_fifo_size(2048);
       ts_format(iso);    --> !!!
    };
     
  4. Restart syslog-ng service.

    # bigstart restart syslog-ng
     

Additional Information

Log format example;

Before adding this option:

Oct 12 15:53:58 BIG-IP01

After adding this option:

2020-10-12T15:55:42+08:00 BIG-IP01
