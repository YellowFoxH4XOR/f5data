K000138118: External iApps are considered as part of SSL Orchestrator when named starting with sslo_

Type
Support Solution
Published
2026-05-12
Updated
2026-05-12
Applies to
  • F5 App Protect
  • F5 SSL Orchestrator: 15.1.X, 15.1.0, 15.1.1, 15.1.2, 15.1.9
Source
https://my.f5.com/manage/s/article/K000138118

Description

SSL Orchestrator logs "App config corrupted, please resolve before proceed" for the external apps in restnoded.log, while the GUI prints "One or more SSL Orchestrator configurations are in an incorrect state. Look for errors in /var/log/restnoded/restnoded.log for corrective action to those configurations before making additional changes to avoid further errors..."


Making SSL Orchestrator changes could affect the external apps named starting with sslo_.


Environment

SSLO is provisioned

iApps


Cause

ID1441541


Recommended Actions

Do not name iApp application that start with sslo_ in order to not conflict with SSL Orchestrator


Additional Information

None
