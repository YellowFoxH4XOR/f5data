K6730: BIG-IP ASM does not force unmatched requests to virtual server default pool

Updated

Applies to

  • BIG-IP ASM: 9.2.4, 9.2.3, 9.2.2
Source

Known Issue

Currently, traffic that does not match a BIG-IP ASM httpclass is rejected by the BIG-IP ASM system.

The traffic that does not match a BIG-IP ASM httpclass should instead be directed to the virtual server's default pool.

F5 Product Development tracked this issue as CR69832, CR69942, and CR70103 and it was fixed in BIG-IP ASM 9.2.4, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP ASM Release Notes.
