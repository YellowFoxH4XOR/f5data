K16810: The Status Age parameter of the OCSP Stapling profile has a new default value and acceptable range

Type
Knowledge
Published
2015-07-01
Updated
2023-02-21
Status
Legacy Content
Applies to

  • BIG-IP LTM: 11.6.0
Source
https://my.f5.com/manage/s/article/K16810

Issue

Old Behavior

In versions prior to BIG-IP 11.6.0 HF5, the Status Age field of the Online Certificate Status Protocol (OCSP) Stapling profile has a default value of 300 seconds, and allows you to specify a range of only 0 to 86400 seconds (one day).

New Behavior

Beginning in BIG-IP 11.6.0 HF5 the Status Age field of the OCSP Stapling profile has a default value of 86400 seconds (one day), and allows you to specify a range of 0 to 4294967295 seconds.

F5 Product Development tracked this change as ID 487587.

Impact

You can now configure the BIG-IP system to accept valid OCSP responses greater than one day old.

Recommended Actions

None
