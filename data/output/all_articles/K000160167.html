Description

You want to know how to send BIG-IQ Diagnostics (qkview) report directly to iHealth from BIG-IQ GUI. 

Environment

  • BIG-IQ GUI
  • iHealth

Cause

None

Answer/Recommended Actions

Follow Troubleshooting using iHealth.

Additional Information

You should allow network/firewall access in your infrastructure between BIG-IQ and ihealth.f5.com.

If you do not have network/firewall access to allow BIG-IQ to access ihealth.f5.com, you can generate qkview file on CLI (qkview -s0) and you will have to manually take out qkview file from BIG-IQ and upload it to ihealth.f5.com
