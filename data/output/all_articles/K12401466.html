Description

This article describes how to create a UCS file for a BIG-IQ device using the command line.

Environment

  • BIG-IQ 
  • UCS file

Cause

N/A.

Recommended Actions

  1. SSH to your BIG-IQ device with any user that has TMSH or BASH access by default root or admin are allowed.
     
  2. Then run the command from the bash: (replace FILENAME with the name for the UCS file)
    tmsh save sys ucs FILENAME.ucs
     
  3. File will be storage under /var/local/ucs
     
  4. This is an example in our labs:
    [root@BIG-IQ-8A:Active:Standalone] config # tmsh save sys ucs backup.ucs
    Saving active configuration...
    <<SNIPPET>>
    /var/local/ucs/backup.ucs is saved.

    [root@BIG-IQ-8A:Active:Standalone] config # cd /var/local/ucs

    [root@BIG-IQ-8A:Active:Standalone] ucs # ls -lsh
    total 32M
     18M -rw-r--r--. 1 root root  18M Apr  8 11:06 backup.ucs  --> Here my file
     14M -rw-r--r--. 1 root root  14M Mar  9 14:31 config.ucs

    [root@BIG-IQ-8A:Active:Standalone] ucs #
     
  5. Now you can download the file using WinSCP or FileZilla or using SCP from the command line.
