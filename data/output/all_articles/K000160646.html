Description

BIG-IQ SMTP alert notifications fail to deliver despite successful configuration tests. Similar error messages appear in logs of BIG-IQ:

Could not send SMTP event email for 'cpu_exceeds_threshold': javax.mail.AuthenticationFailedException: 535 5.7.3 Authentication unsuccessful

Alerts are visible in BIG-IQ GUI but not received via email.

Environment

  • SMTP setup for alert notifications
  • Alert conditions enabled in Monitoring > ALERTS & NOTIFICATIONS

Cause

  • Incorrect SMTP password caused authentication failures (535 5.7.3).

Recommended Actions

  1. Verify SMTP Credentials:
    • Ensure the SMTP username and password are correct in BIG-IQ configuration.
  2. Check Sender Permissions:
    • Confirm the SMTP sender address has permission to send emails through the SMTP server.
    • The sender address should match the credentials used for authentication.
  3. Enable Alert Conditions:
    • Make sure alert conditions are enabled in BIG-IQ (Monitoring > ALERTS & NOTIFICATIONS > Settings).
  4. Test Email Notifications:
    • After making changes, test email notifications to confirm successful delivery.
  5. Review Logs:
    • Check BIG-IQ logs for authentication or permission errors if emails are not received.
