K000130437: After loading UCS from tenant of Velos/rSeries, TMM repeatedly restart and generate core file.

Source

Description

After loading a UCS generated in a tenant on Velos/rSeries to classic BIG-IP (VE version, vcmp guest, platform), TMM constantly restarting and producing a core file.

Then you can see the similar to the below log in var/log/tmm:

notice panic: ../kern/sdag.c:630: Assertion "libsdag.so successfully loaded" failed.

 

Environment

  • UCS from Tenant on Velos/rSeries 5k/10K
  • restoration on platform, vCMP guest, VE version
 

Cause

  • Bug ID 1311613
 

 Recommended Actions

Follow the workaround in Bug ID 1311613
