Issue

Error Message

emerg overdog[<PID>]: 01140043:0: HA feature <feature> reboot requested

In this error message, note the following:

  • <PID> is the process ID for the overdog process.
  • <feature> is the name of the HA feature.

For example:

  • emerg overdog[6321]: 01140043:0: HA feature software_update reboot requested
  • emerg overdog[1494]: 01140043:0: Ha feature daemon_heartbeat reboot requested

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The BIG-IP high availability (HA) system detects that a reboot should be performed.

This message most commonly occurs when an administrator reboots the BIG-IP system to a new boot location.

Impact

The BIG-IP system reboots.

Recommended Actions

If the reboot was unexpected, you may be able to determine the cause by identifying the failing HA feature in the log message and correlating the feature with other references to it in the log files. To view a list of the HA features and actions, use the tmsh show /sys ha-status command.
