Known Issue

The Configuration utility may produce an error when using the browser's Back button.

This issue occurs when all of the following conditions are met:

  • You use the Configuration utility to delete an existing monitor.
  • You click the browser's Back button.

Impact

The system displays a partial page with an error message.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you click the browser's Back button, the displayed page stops responding and includes an error message that appears similar to the following example:

    Loading...
    Receiving configuration data from your device.

    This webpage requires data that you entered earlier in order to be properly displayed. You can send this data again, but by doing so you will repeat any action this page previously performed.

  • When you refresh the page, the system displays the configured Monitors list page.

Resolution

Status

F5 Product Development has assigned ID 499614 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

HotfixNoneNone

Workaround

To work around this issue, you can click Local Traffic > Monitors or click the Local Traffic > Monitors link to go back to the Monitors list page.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
