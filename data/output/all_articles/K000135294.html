Description

Sometimes you may want to check the Tripo statistics. You can view the Tripo statistics via command on the SDC that runs the Tripo process.

Environment

SDC, Tripo

Cause

How to view the Tripo statistics via CLI

Recommended Actions

To view the statistics

  1. SSH to the TRIPO node
  2. Define TRIPO environment to query information from TRIPO
    • su - traffix
    • . ~/Tripo/env/linux-x86_64/DefEnv Tripo

Detail for each command

  • monitor -> to monitor TRIPO component
  • UI_ViewStorage -s -> to monitor TRIPO storage
  • UI_ViewSiteRepTbl –s -> view replicate status
  • UI_ViewServers –p -> show connection information to Tripo Mate
  • UI_Config -> change Tripo configuration
  • UI_Admin –f -> Force replication to the remote site (not the local mate)
