Known Issue

Citrix Receiver-initiated remote desktop or applications may fail to launch.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP APM in StoreFront integration mode.
  • The virtual server that assigned the access profile is configured for SSL offload.
  • Connections processed by the BIG-IP APM virtual server to the Citrix applications are not re-encrypted.
  • You attempt to launch a Citrix application or desktop using the Citrix Receiver for HTML5.

Impact

You are unable to establish the application or desktop access sessions.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you launch a remote desktop access session, the page loads with a blank, black screen.
  • When you launch a Citrix application, the application content fails to render and the system displays an HTTP 302 found error.

Workaround

To work around this issue, you can disable SSL/TLS on the destination Citrix applications, or configure the BIG-IP system to encrypt the content that is destined to the Citrix applications, using a Server SSL profile that is assigned to the affected virtual server.

For more information regarding implementing the Server SSL profile, refer to The Managing Client- and Server-Side HTTP Traffic Using a Self-Signed Certificate chapter of the BIG-IP LTM BIG-IP System: SSL Administration guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

Impact of workaround: When the system sends traffic that the BIG-IP APM virtual server processed to the configured Citrix applications, the system will encrypt the traffic.
