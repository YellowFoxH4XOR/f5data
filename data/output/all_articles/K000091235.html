K000091235: Failed to Reactivate License for Nginx Controller APIM

Type
Support Solution
Published
2022-01-24
Updated
2022-03-16
Source
https://my.f5.com/manage/s/article/K000091235

Description

Problem with applying trail or evaluation license to a previously licensed version of NGINX Controller

 

 

 

Environment

  • NGINX Controller

Cause

Missing license for in Nginx Controller. Lack of WebUI functionality.

 Recommended Actions

  1. List and check pods status:
    • # kubectl get pods﻿
  2. Delete pod "platform-mgr-xxxx"
    • # kubectl delete pod <platform-mgr-xxxx>
  3. System automatically will recreate "platform-mgr-xxxx" pod
    • check again status pods: # kubectl get pods
  4. Apply again license.

None
