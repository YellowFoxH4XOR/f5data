Topic

This document is intended to provide an easy reference to a list of known issues affecting configuration import. Configuration import usually fails because the configuration parser may not process the configuration properly. If the configuration import fails after an upgrade, the BIG-IP system may run without any configuration loaded on the new software version. As a result, the BIG-IP system may not be able to process traffic.

Note: These are the issues we have identified so far; this is not a comprehensive list.

Issues affecting BIG-IP 10.x

  • K8564: Some bigpipe commands fail with a bigpipe parsing error message after upgrading to BIG-IP 9.4.2 or later
  • K8714: A bigpipe parsing error message is reported when installing or loading a configuration
  • K9238: The Configuration utility does not correctly process strings ending with backslash characters
  • K9411: Command line login fails when the local user name is longer than 32 characters
  • K10601: VLAN group proxy excludes are not properly converted upon upgrade
  • K10889: ‘cmp processor’ is not a valid option for the bigpipe virtual command
  • K11296: The default /etc/protocols file may cause a configuration load failure
  • K12251: Missing or ambiguous entries in the /etc/protocols or /etc/services files may cause configuration errors
  • K12365: The bigpipe load command fails when a pool member contains certain service numbers
  • K12404: The BIG-IP system does not properly validate high availability group names
  • K12795: The BIGpipe parser does not correctly parse nested quotes in an iRule
  • K12812: The Configuration utility and tmsh incorrectly allow profile names that begin with a non-alphabetic character

Issues affecting BIG-IP 9.4.x

  • K7988: The iRule parser may fail to correctly parse and load an iRule when using the bigpipe load command
  • K8564: Some bigpipe commands fail with a bigpipe parsing error message after upgrading to BIG-IP 9.4.2 or later
  • K8714: A bigpipe parsing error message is reported when installing or loading a configuration
  • K9238: The Configuration utility does not correctly process strings ending with backslash characters
  • K9411: Command line login fails when the local user name is longer than 32 characters
  • K10383: Using ‘default’ as a VLAN name causes silent configuration update failure
  • K10601: VLAN group proxy excludes are not properly converted upon upgrade
  • K10889: ‘cmp processor’ is not a valid option for the bigpipe virtual command
