Description
After an upgrade from 11.x or 12.x to 14.x, 15.x, 16.x config sync is not working and you see "Disconnected" state in GUI/CLI. 
In /var/log/ltm file, you can observe logs similar to:

0107143c:5: Connection to CMI peer x.x.x.x has been removed
01071432:5: CMI peer connection established to x.x.x.x port 6699 after 0 retries

Environment

  • AWS
  • Config-sync
  • Upgrade from 11.x, 12.x
  • Version after upgrade: 14.x, 15.x, 16.x
  • Config-sync VLAN MTU above 1500

Cause
Jumbo frames are not supported in the ixvf driver, BIG-IP is dropping all the jumbo packages and rejecting config-sync connection. 

Recommended Actions

  1. Log in to the Configuration utility.
  2. Navigate to Network > VLANs.
  3. Click VLAN List.
  4. Click on the config-sync VLAN name.
  5. Check the MTU size.
  6. If MTU is above 1500 e.g. 9000 change it to 1500.
  7. Click Update.
  8. Perform the same steps on secondary BIG-IP.
