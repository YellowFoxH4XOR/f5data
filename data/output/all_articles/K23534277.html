Known Issue

The system may present Radius authentication challenges to the user in hexadecimal format.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM access profile is configured with an access policy that uses the RADIUS Auth agent.
  • When authenticating a user, the Radius server sends an authentication challenge that is not in the ASCII character format.

Impact

The user is unable to interpret the authentication challenge that the Radius server sent.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the Radius server responds with an authentication challenge that contains characters that are not in ASCII format (for example the French, Spanish, and Swedish languages that contain non-ASCII accented characters), the system sends the challenge to the user in hexadecimal format.

Workaround

To work around this issue, you can modify the logon.inc code of the affected access profile, adding a function so the system can display the session variable. To do so, perform the following procedure:

Impact of workaround: F5 recommends that you perform the following procedure during a scheduled maintenance window.

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > Customization > Advanced.
  3. Expand the Access Profiles section.
  4. Select the affected access profile.
  5. Expand the Access Policy section.
  6. Expand the affected access profile Logon Pages section.
  7. Expand the Logon Page section.
  8. Click logon.inc.
  9. Search for the function OnLoad() in the logon.inc code (for BIG-IP APM 12.x, this is at approximately line 303, and for BIG-IP APM 11.6.x, this is at approximately line 260).
  10. Locate the following code stanza with the closing curly bracket (}) (for BIG-IP APM 12.x, this is at approximately line 309, and for BIG-IP APM 11.6.x, this is at approximately line 266).

    if ( softTokenHeaderStr ) {
    header.innerHTML = softTokenHeaderStr;
    }

    Important: Stated line numbers are approximates. Insert the code after the closing curly bracket ( }).

  11. After the closing curly bracket ( } ), add the following code.

    <? // CODE CHANGE TO HANDLE HEXADECIMAL RADIUS CHALLENGE
    if($challenge == 1){?>
    else if(header.innerHTML.substring(0,2) == "0x"){
    var hex = header.innerHTML;
    var str = '';
    var i=0;
    if (hex.charAt(0) == '0' && hex.charAt(1)== 'x') {
    i = 2;
    }
    var ret;
    for (; i < hex.length; i += 2) {
    ret = parseInt(hex.substr(i, 2), 16);
    if(isNaN(ret)){
    break;
    } else {
    str += String.fromCharCode(ret);
    }
    }
    if(isNaN(ret)){
    ret = hex;
    } else {
    ret = str;
    try{
    ret = decodeURIComponent(escape(str));
    } catch(e){};
    }
    header.innerHTML =String(ret).replace(/</g, '&lt;').replace(/>/g, '&gt;
    }
    <?}?>
    //END CODE CHANGE TO HANDLE HEXADECIMAL RADIUS CHALLENGE

  12. In the upper-right corner of the code editor, click Save Draft.
  13. In the Do you want to save your changes? window, click Yes.
  14. In the upper-left corner of the editor, click Save.
  15. In the upper-left corner of the Configuration utility, click Apply Access Policy.
  16. Click Apply Access Policy.
