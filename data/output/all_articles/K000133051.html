K000133051: Unable to configure SNMP in GUI on rSeries appliance

Type
Support Solution
Published
2023-03-17
Updated
2023-04-16
Applies to
  • F5OS
  • F5OS-A: 1.1.X, 1.1.1, 1.1.0
Source
https://my.f5.com/manage/s/article/K000133051

Description

You would like to configure SNMP on your rSeries device using Configuration Utility (GUI).

Environment

  • rSeries
  • F5OS-A 1.1.1

Cause

  • F5OS-A 1.1.1 does not allow SNMP configuration using Configuration Utility (GUI)

Recommended Actions

Perform a software upgrade to F5OS-A 1.3.2 which have the option to configure SNMP from Configuration Utility (GUI).
Note: F5OS-A 1.1.1 reached End of Technical Support milestone.

Additional Information

None
