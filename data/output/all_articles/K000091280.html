Description

When using MyF5 portal, there are some considerations in play when uploading and downloading files.

  • Only the main contact of the case can upload the files.

  • There is a 4GB limit for file uploads toiHealth.

Environment

  • MyF5
  • Upload to Secure Files
  • Download from Secure Files 
  • Qkview
  • PCAP
  • Log file

Cause

None.

Recommended Actions

  1. Who can upload file?

    1. In the event another individual will need to upload the file the case contact will need to be changed to the individual who will upload the data in order for the process to work correctly within Service Cloud. Once the upload is done the new contact can remain on the case while working with that individual or the contact can be changed back to the previous contact.

  2. Attachments and Sharing Files (such as pcaps, log files, and others)

    1. To upload, view, or share attachments open your case.

    2. Click on the Files section of the navigation bar.

    3. Click Upload Files or Drag and Drop attachments into the Files section

      1. If you Upload then select the file(s) you want to attach from the open window and select Open to upload the file(s).

      2. The dialog will indicate the file(s) have been uploaded.

      3. Click Done to proceed.

      4. The file upload is now complete.

  3. Managing Qkviews

    1. From the GUI

      1. Create a fresh qkview with an Unlimited Snaplen

        1. Go to System ›› Support ›› Support and click on New Support Snapshot.

        2. In the section labeled Support Snapshot choose Generate Qkview.

        3. In the section labeled QKView Options select Unlimited Snaplen.

        4. Click Start.

        5. Once it is done in the section labeled Last Generated Snapshot the new qkview will appear (This make take a few minutes to appear).

        6. Click on the Download button and download it.

      2. Once that is done upload it to iHealth

        1. Open a browser and connect to iHealth via https://ihealth.f5.com.

        2. Enter your iHealth credentials.

        3. If your current iHealth is impersonating someone, click Stop (that will be seen at the top of the page).

        4. Click Upload to upload the QKView.

        5. Click Choose, select the QKView file and click Open. You can select more than 1 qkview file.

        6. Enter your F5 Support Case (SR) number into the F5 Support Case (SR) block.

        7. Click Upload QKView(s) to upload the qkview(s) to iHealth.

    2. Create a qkview on the CLI:

      1. At times it will be necessary to create the qkview on the CLI.

        1. For a standard qkview use this command -

          qkview -s0

        2. For an asmqkview use this command -

          asmqkview -s0 --add-request-log --include-traffic-data -f /var/tmp/`/bin/hostname`_asmqkview_`date +%Y%m%d%H%M%S`.tgz

          1. This kind of qkview is typically much larger and can be well over 600MB and take over 20 minutes to run.

        3. Once it is finished it will need to be retrieved from the BIG-IP and will be in directory /var/tmp/. The easiest way to retrieve it is with an scp app such as WinSCP or Filezilla.

        4. For the standard qkview follow the steps for the GUI to upload it to iHealth.

        5. An asmqkview can be uploaded top iHealth but because of how it is used it would be better to upload it to F5 Secure Files. An asmqkview contains a mysql database that for ASM that is not in a standard qkview. ASM/AdvWAF policies are in that mysql database.

          Note: if you have any issues with the upload if either type of qkview please contact F5 Support.

Note:  A current limitation to be aware of is that only the contact on the service cloud case can upload the file to iHealth and have it appear in the case. You must also be registered in  my.f5.com
