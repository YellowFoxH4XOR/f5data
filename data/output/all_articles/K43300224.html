Issue

Error Message

01070320:3: Snatpool <name> is still referenced by a virtual server.

In this error message, note the following:

  • <name> is the name and partition location of the secure network address translation (SNAT) pool.

For example:

01070320:3: Snatpool /Common/snatpool_int is still referenced by a virtual server.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • You attempt to delete a SNAT pool that is currently referenced by a virtual server or a SNAT.

Impact

Users cannot delete SNAT pools from the configuration.

Recommended Actions

Before attempting to delete a SNAT pool from a configuration, you should remove any references to the SNAT pool by virtual servers and SNATs. To do so, perform the following procedures:

Impact of procedures: Performing the following procedures should not have a negative impact on your system.

  • Removing a SNAT pool from a virtual server
  • Removing a SNAT pool from a SNAT

Removing a SNAT pool from a virtual server

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Select the affected virtual server.
  4. In the Configuration section, from the SNAT Pool setting, deselect the SNAT pool to be deleted.
  5. For the Source Address Translation setting, select any option other than SNAT.
  6. Click Update.

Removing a SNAT pool from a SNAT

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Address Translation.
  3. Select the affected SNAT.
  4. For the Translation setting, select any option other than SNAT Pool.
  5. Click Update.
