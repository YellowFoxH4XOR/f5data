Issue

When the administrator accepts learning suggestions for object level parameters that have been pre-defined in the active security policy, the following error message is reported in the /var/log/asm file:

perl[2889]: 01310027:2: ASM subsystem error (learning_manager.pl,main::object_param_in_policy): Trying to return param_id,param_attrib_id=65, 16432 in scalar context

This message does not cause any adverse effects.

F5 Product Development tracked this issue as CR84416 and it was fixed in BIG-IP ASM version 9.4.4. For information about upgrading, refer to the BIG-IP ASM release notes.
