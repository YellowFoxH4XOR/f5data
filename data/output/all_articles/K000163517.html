K000163517: BIG-IQ: Unable to deploy BIG-IQ in VMware using vApp

Type

Published

Updated
2026-10-14
Applies to

  • BIG-IQ Centralized Management: 8.4.2
Source

Description

Deploying BIG-IQ 8.4.2 in VMware using vApp fails when the system selects the obsolete TMSH schema 12.1.1. 

Environment

BIG-IQ 8.4.2
VMware vApp deployment

Cause

ID 2285461

Answer/Recommended Actions

As a workaround, remove the obsolete schema library from the active library set by renaming it, then reboot the system.

# mount -o remount,rw /usr
# mv /usr/lib/libclischema.12.1.1.so /usr/lib/libclischema.12.1.1.so.disabled
# reboot

None
