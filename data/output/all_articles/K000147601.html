K000147601: How can I set up route configuration to disregard case sensitivity?

Type
Support Solution
Published
2024-11-08
Updated
2026-01-13
Applies to

  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147601

Description

You want to set up a route that isn't case-sensitive, allowing URLs like /test, /Test, /TEST, or /teSt to all point to the same endpoint.

Environment

  • F5® Distributed Cloud HTTP Load Balancer

Resolution/Answer

  • Add a Route in the HTTP Load Balancer section.

  • In the Path Match section, select Regex and enter the following pattern in the *Regex field.
(?i)^/test$

 

  • Add the necessary redirect parameters, and the route will ignore case sensitivity.
