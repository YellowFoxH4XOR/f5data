Known Issue

The BIG-IP APM rewrite profile may incorrectly handle the Range.createContextualFragment() method.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured for portal access.
  • The JavaScript code in the HTML page invokes the Range.createContextualFragment() method to insert new scripts into the HTML page.

Impact

Web applications may malfunction or fail to render properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Web page content that invokes the Range.createContextualFragment() method will not render properly in web browsers.
  • BIG-IP portal access deletes scripts inserted by the Range.createContextualFragment() method.
