Topic

You should consider using this procedure under the following condition:

  • You want to remove the BIG-IP system from a device group.

Description

The BIG-IP device group feature allows you to securely synchronize the BIG-IP configuration data between devices that are assigned to the device group and fail over when another device becomes unavailable. On occasion you may want to remove a device from the device group to which it is joined.

Before removing a device from a device group, you should be aware of the following:

Device trust and trust domains

Device trust establishes trust relationships between BIG-IP devices through certificate-based authentication. A trust domain is a collection of BIG-IP devices that trust each other and that you can assign to a device group to synchronize and fail over their BIG-IP configuration data, as well as regularly exchange status and failover messages. Each BIG-IP system in the trust domain is designated one of the following authority types:

  • Certificate signing authority (CA) - Specifies that the BIG-IP device can sign x509 certificates for another BIG-IP device that is in the local trust domain. In a standard redundant system configuration of two BIG-IP devices, both devices are typically peer CA devices.
  • Subordinate non-authority - Specifies that the device for which a CA device signs its certificate. A subordinate device cannot sign a certificate for another device.

Before you remove a device from the device group, you should verify the authority type designation for the device that you plan to remove and the devices that will remain in the device group. For example, if the device group contains one CA device and multiple subordinate devices and you remove the CA device from the device group, you will be unable to add more devices to the group unless you reset the device trust across all remaining devices in the group.

Device groups

The BIG-IP system supports the following two types of device groups:

  • A Sync-Failover device group contains devices that synchronize configuration data and support traffic groups for failover purposes. A Sync-Failover device group supports a maximum of eight devices.
  • A Sync-Only device group contains devices that synchronize configuration data, but do not synchronize failover objects, and do not fail over to other members of the device group. A Sync-Only device group supports a maximum of 32 devices.

To remove a BIG-IP device from a device group, perform the following procedures:

  • Determine the authority type for the device group members
  • Enable the Force Offline option
  • Remove the device from the device group
  • Remove the device from the Trust Group on the active BIG-IP system
  • Remove the trusted peer CA or subordinate devices from the device

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have access to the Configuration utility and the TMOS Shell (tmsh).

    Note: F5 strongly recommends that you use the Configuration utility to perform the removal procedures to ensure that configuration updates automatically synchronize to the remaining members of the device group.

Procedures

Determine the authority type for the device group members

Before you remove a device from the device group, you should determine the authority type designation for the device group members.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Enter the following command to list the devices in the trust domain:

    list /cm trust-domain

    For example, the following output indicates that there are two CA peer devices and one non-ca device in the trust domain:

    cm trust-domain Root {
    ca-cert dtca.crt
    ca-cert-bundle dtca-bundle.crt
    ca-devices { /Common/bigip_1.pslab.local /Common/bigip_2.pslab.local }
    ca-key dtca.key
    non-ca-devices { /Common/bigip_3.pslab.local }
    status initialized
    trust-group device_trust_group
    }

  3. Identify the authority type for the device group members.

    Note: If you plan to remove a CA device from the device group, you should verify that there is at least one other CA peer device in the group, otherwise you will be unable to add more devices to the device group after removing the CA device.

Enable the Force Offline option

You must enable the Offline option for the device that you will remove from the device group. The Force Offline option puts the BIG-IP unit into an offline state, during which time the system does not respond to or process local traffic connections.

To force the system offline, perform the following procedure:

Impact of procedure: The BIG-IP system terminates existing connections to local traffic objects and does not allow new connections when the Force Offline option is enabled. F5 recommends that you perform this procedure during a maintenance window.

  1. Log in to the Configuration utility of the device you want to remove from the device group.
  2. Go to Device Management > Devices.
  3. Select the local device (Self).
  4. Select Force Offline.

Note: To release the unit from its Forced Offline state, select Release Offline.

Remove the device from the device group

After you have enabled the Force Offline option for the device, you can remove the device from the group. The change to the device group synchronizes to the device group members. F5 recommends that you perform this procedure during a maintenance window.

To remove the device from the device group, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility of the device you want to remove from the device group.
  2. Go to Device Management > Device Groups.
  3. Select the device group name.
  4. In the Configuration section, select the device you want to remove from the group and move it to Available.
  5. Select Update.

Remove the device from the trust group on the active BIG-IP system

You can now update the trust group on the active BIG-IP device and remove the device that is no longer part of the device group.

To remove the device from the trust group, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

BIG-IP 13.x and later

  1. Log in to the Configuration utility of the active device.
  2. Go to Device Management > Device Trust > Device Trust Members
  3. Select the check box next to the device and select Delete.

BIG-IP 11.x through 12.x

  1. Log in to the Configuration utility of the active device.
  2. Go to Device Management > Device Trust > Peer List.
  3. If the device that you removed from the device group was a CA peer, select the check box next to the device and select Delete.
  4. Go to Device Management > Device Trust > Subordinate List.
  5. If the device that you removed from the device group was a subordinate non-authority device, select the check box next to the device and select Delete.

Remove the trusted peer CA or subordinate devices from the device

To remove the trusted peer CA or subordinate devices from the device that was removed from the device group, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

BIG-IP 13.x and later

  1. Log in to the Configuration utility of the device you removed from the device group.
  2. Go to Device Management > Device Groups.
  3. Select the device group name.
  4. In the Configuration section, move all listed devices to Available.
  5. Select Update.
  6. Go to Device Management > Device Trust > Device Trust Members
  7. Select any peer or subordinate devices that should not be associated with the current device and select Delete.

BIG-IP 11.x through 12.x

  1. Log in to the Configuration utility of the device you removed from the device group.
  2. Go to Device Management > Device Groups.
  3. Select the device group name.
  4. In the Configuration section, move all listed devices to Available.
  5. Select Update.
  6. Go to Device Management > Device Trust > Peer List.
  7. Select any CA devices that should no longer be associated with the current device and select Delete.
  8. Go to Device Management > Device Trust > Subordinate List.
  9. Select any subordinate non-authority devices that should no longer be associated with the current device and Select Delete.
