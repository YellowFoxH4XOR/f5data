Topic

Starting in FirePass version 6.0.2, you can disable compatibility modes.

Note: For instructions about disabling compatibility mode, refer to chapter 7 of the FirePass Controller Administrator Guide for version 6.0.2. After Compatibility Mode has been disabled, the restrictions for web applications are more relaxed that the restrictions outlined in K3622: Writing JavaScript applications for web sites that are accessed through Portal Access.

In general, it is advisable to keep web application code simple, clear and efficient. To ensure applications are passed correctly through the FirePass, F5 Networks advises to:

  • Avoid using bracket notation for access to built-in JavaScript properties using variables.
    For example, use document.write(‘narwhal’); rather than w=”write”;document[w](‘narwhal’);
  • Avoid using indirect references to built-in JavaScript functions.
    For example, use window.open(‘narwhal’); rather than F=window.open; F(‘narwhal’);
  • Avoid using JavaScript variables prefixed with ur and F5.
    F5 uses these prefixes for internal variables. To avoid conflicting with F5 internal variables, do not use variables such as urNarwhal or F5Narwhal.
  • Avoid using relative URL paths in JavaScript functions.
    For example, use window.open("http://www.example.com/narwhal"); instead of window.open("/narwhal");
