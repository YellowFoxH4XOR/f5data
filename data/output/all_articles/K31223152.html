K31223152: Error Message: DBD::mysql::db rollback failed: Turning on AutoCommit failed

Type
Support Solution
Published
2020-05-22
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.1.2
Source
https://my.f5.com/manage/s/article/K31223152

Description

After clicking on 'Apply Policy', the following error message is displayed on the dashboard:

DBD::mysql::db rollback failed: Turning on AutoCommit failed

Environment

  • In the /var/lib/mysql/mysqld.err log:
    mysqld restarted

    mysqld: Table '<TABLE_NAMES>' is marked as crashed and should be repaired
     
  • /var/log/daemon.log log:
    Re-starting logmysqld

    Re-starting monpd
     
  • /var/log/ltm log:
    logmysqld[XXXXXX]: Fatal error db.cpp:exec_query:XXXSELECT COUNT(*) from log_data_current errno[XXXX] strerror[Lost connection to MySQL server during query]
     
  • monpd daemon is 'down'

Cause

The BIG-IP ASM MySQL database is unable to start successfully due to possible corrupt AVR tables. 

Recommended Actions

To check and repair MYQL databases on BIGIP, follow the steps in the article K05755225: Checking and repairing MySQL databases on the BIG-IP system

NOTE: Only perform steps 1-4 of section '2. Rebuild the database.' in the 'Recommended Actions'
