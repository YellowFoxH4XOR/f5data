Description

BIG-IP APM logs the client's hostname to session variable session.client.hostname. This variable and its value is logged to /var/log/apm with Access Policy log level "Informational" or to Access session reports generated from the TMUI GUI. Implementing a "Logging Agent" and logging "Client Variables" to a BIG-IP APM Access Policy will log the session variable session.client.hostname and its to /var/log/apm at Access Policy level "Notice".

Note: If connecting to an Access Policy via web browser then the "Logging Agent" logging "Client Variables" will need to be implemented after an Endpoint Security (EPS) action or else session.client.hostname will not be logged by the Logging Agent

Environment

The client hostname session variable will be populated when connecting to a BIG-IP APM Access Policy protected virtual server when using any one of the following:

  • Web browser plus the BIG-IP APM Access Policy running any EPS check
  • Edge Client for Windows/Mac/Linux
  • F5 Access for iOS/Android/Windows 10

Cause

This is expected behavior.
