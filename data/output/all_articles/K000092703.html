K000092703: Client cert authentication gets SSL handshake err - ssl_hs_rsacertvfy (80)

Type

Published

Updated

Source

Description

Following error during SSL client authentication:

01260009:4: Connection error: ssl_hs_rsacertvfy:6074: ssl_hs_rsacertvfy (80)

 

Environment

- standard Virtual Server

- clientssl profile with client authentication configured

- error during SSL handshake

 

Cause

- client's SSL private key is invalid and needs to be replaced (along with the certificate)

Recommended Actions

Verify if client's private key is valid with the following command:

# openssl rsa -in client.key -check

 

The correct output is:

RSA key ok

Invalid key returns:

RSA key error: n does not equal p q
