Topic

You should consider using this procedure under the following conditions:

  • You want to configure certificate revocation list (CRL) verification for iQuery communication.

Description

The BIG-IP DNS system uses the iQuery protocol to collect dynamic load balancing and metrics information from remote BIG-IP DNS and other BIG-IP devices and distribute the information to remote BIG-IP DNS sync group members.

If your BIG-IP DNS systems use certificate authority- (CA-) signed SSL device certificates to authenticate iQuery connections, you may want to configure the systems to check for revoked SSL device certificates using a CRL.

A CRL allows a CA or CRL issuer to periodically communicate the revocation status of digital certificates that may have been compromised prior to their expiration date. Starting in BIG-IP 16.x, you can configure CRL verification for iQuery connections. To do so, perform the following procedures on all BIG-IP DNS synchronization group members:

  • Upload the PEM-encoded CRL file to the BIG-IP system
  • Confirm the CRL loaded properly
  • Configure additional iQuery settings as required

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Your BIG-IP DNS systems use SSL device certificates that were signed by a CA.
  • You have obtained a PEM-encoded CRL file from your CA or CRL issuer.

Procedures

Upload the PEM-encoded CRL file to the BIG-IP system

After you obtain a PEM-encoded CRL file from your CA or CRL issuer, upload the file to the /config directory on the BIG-IP DNS synchronization group members and name the file as follows: /config/revoked_certs.crl.

Impact of procedure: Performing the following procedure enables CRL validation on all iQuery connections.

  1. Log in to the system that contains the PEM-encoded CRL file.
  2. To upload the CRL file to the remote BIG-IP systems using SCP, use the following syntax:

    scp <CRL_filename> root@<BIG-IP_mgmt_IP>:/config/revoked_certs.crl

    For example:

    scp crl.pem root@192.0.2.1:/config/revoked_certs.crl

  3. Repeat the upload process for the remaining BIG-IP DNS sync group members.

    Note: For more information about transferring files to or from an F5 system, refer to K175: Transferring files to or from an F5 system.

Confirm the CRL loaded properly

When the CRL file is uploaded to the BIG-IP system, you can confirm that the file was loaded properly by performing the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS shell.
  2. To view the global traffic logs, use the following syntax:

    show /sys log gtm range <date range>

    For example, to view ltm logs from two days ago until now, enter the following command:

    show /sys log gtm range now-2d

    The following message indicates that CRL validation is enabled on all remote iQuery connections:

    012b3100:5: CRL file /config/revoked_certs.crl created, enabling CRL validation on all remote iQuery connections

Configure additional iQuery settings as required

To configure additional iQuery settings, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to DNS > Settings > GSLB > General.
  3. For iQuery, configure the following CRL settings as required for your environment:
    • CRL Validation Depth determines which CRLs are required during certificate validation for iQuery connections.
    • Use Not Yet Active CRL specifies whether to allow the usage of a CRL that is not-yet active when validating a certificate.
    • Use Expired CRL specifies whether to allow the usage of an expired CRL.
    • Use Revoked Certificates specifies whether to allow the usage of a revoked certificate in new or existing iQuery connections.
    • Reverify on CRL Becoming Active specifies whether to reverify the existing iQuery connection's certificates whenever a CRL becomes active.
    • Reverify on CRL Expiring specifies whether to reverify the existing iQuery connection's certificates whenever a CRL expires.
    • Reverify on CRL File Update specifies whether to reverify the existing iQuery connection's certificates whenever the CRL file is updated.
  4. Select Update.
