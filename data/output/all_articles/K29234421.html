802.1p VLAN traffic priority is now configurable by the TM.Egress.PktPriority database key.  

Old Behavior

Prior to BigIP 11.5.2 traffic generated by TMM was sent an 802.1p class of service priority of 0.  This was not configurable by the administrator.

New Behavior

Beginning in 11.5.2 the 802.1p VLAN traffic priority can be set by setting the TM.Egress.PktPriority Database Key to a value between 0 and 7.  Note that the default is 3.

F5 Product Development tracked this change as ID 505452

Impact

By making this configurable, BigIP administrators are better able to control the flow of traffic on their networks.
Note:  This priority is applied when the packet exits the BigIP and will not show in a tcpdump taken inside TMM (on a VLAN or on 0.0).
