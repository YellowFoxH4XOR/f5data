Known Issue

Two-factor RADIUS authentication may fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM access policy is configured for AAA RADIUS two-factor authentication using Push one-time password Integration.
  • Authenticating users supply a legitimate blank password when authenticating.

Impact

Authentication fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Authenticating users that supply a valid blank password are unable to successfully authenticate.
  • In the /var/log/apm file, you observe log messages similar to the following example:

    err apd[12710]: 01490000:3: modules/Authentication/Radius/RadiusAuthAgent.cpp func: "getRadiusUserInput()" line: 521 Msg: b84e974e: RADIUS Agent: getRadiusUserInput(): unable to decrypt user password due to NULL ciphertext

  • When the system is analyzing RADIUS authentication traffic between the BIG-IP APM system and RADIUS servers, and a user provides a blank password, the BIG-IP APM system does not send an authentication request to the configured destination RADIUS servers.
