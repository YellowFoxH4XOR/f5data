K000152611: After upgrade, the UI is reporting metrics are disabled and error message "Upstream Unavailable"

Type
Support Solution
Published
2025-07-16
Updated
2025-07-16
Applies to
  • NGINX Products
  • NGINX Instance Manager: 2.20.0
Source
https://my.f5.com/manage/s/article/K000152611

Description

After upgrading to v2.20.0 or higher, metrics in the UI are not populating and instead the following two UI messages are displayed:

(Error) Upstream Unavailable
(Informational) Metrics are currently disabled

Environment

NGINX Instance Manager

Cause

The platform-config API upstream service mapping parameter is missing from NIM's NGINX configuration.

Recommended Actions

Add the platform-config API upstream service mapping parameter within file /etc/nginx/conf.d/nms-http.conf and restart the NGINX service.

...
# Main routing logic
map $uri $mapped_upstream {
...
  "~^/api/platform/v1/resource-groups" core-api-service;
  "~^/api/platform/v1/platform-config/*" core-api-service; # <--- this is the new parameter
...
}
...

Additional Information

NIM v2.20.0 introduced API endpoint /api/platform/v1/platform-config/clickhouse.enable as part of the NIM lightweight mode feature. This endpoint signals whether or not Clickhouse (metrics storage and reporting) is enabled on NIM. To implement this new API endpoint, NIM's NGINX configuration file /etc/nginx/conf.d/nms-http.conf is configured with a platform-config API upstream service mapping parameter (see above). The NIM upgrade process asks to replace file /etc/nginx/conf.d/nms-http.conf, if that file has been customized in any way, with a new version of that file. Answering no (default selection) to this question results in a successful upgrade. However, the platform-config API upstream service mapping parameter is not present in NGINX config file /etc/nginx/conf.d/nms-http.conf. As a result, API endpoint /api/platform/v1/platform-config/clickhouse.enable is not available.
