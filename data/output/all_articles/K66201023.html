Known Issue

Datagram Transport Layer Security (DTLS) virtual server connections may experience multiple handshake requests.

This issue occurs when all of the following conditions are met:

  • You deploy a BIG-IP VE system using a supported VE hypervisor.
  • Your BIG-IP system is configured with a DTLS virtual server.
  • The virtual server processes DTLS connection requests.

Impact

There is a delay in processing the virtual server traffic, or the BIG-IP virtual server resets the connection.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the network-level traffic, you notice that the BIG-IP virtual server sporadically sends an ICMP Destination Unreachable - Port Unreachable message to the client during the DTLS handshake.
  • When you analyze the DTLS communication between the BIG-IP system and the client, you notice that the BIG-IP system sends a second DTLS handshake request to the client one second after sending the original DTLS handshake request.
