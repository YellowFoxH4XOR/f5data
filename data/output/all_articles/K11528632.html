Description

  • After an upgrade or restart of the device, the configuration fails to load in GUI. 
  • When running the command 'tmsh load sys config verify' command, the BIG-IP generates an error message similar to the following: 
    01070094:3: Referenced vlan (/Partition_name/VLAN_name) is hidden, does not exist, or is already on another instance.
Unexpected Error: Validating configuration process failed.

Environment

  • Post upgrade or after reboot configuration load fails
  • Device goes into Inoperative or disconnected mode
     

Cause

Partition from the error or VLAN was removed,  leaving behind some configuration in bigip_base.conf.
 

Recommended Actions

To resolve this issue, manually remove the lines from the configuration that relate to the object in the error above, and then reload the configuration.
Impact of workaround: You should perform the following procedure during a maintenance window, as traffic may be temporarily disrupted while the edited configuration loads.

  1. Log in to the BIG-IP command line.
     
  2. Create a backup of the existing bigip_base.conf file using the following command: 
    cp /config/bigip_base.conf /config/bigip_base.conf.backup
     
  3. Edit the BIG-IP configuration file using a text editor of your choice. For example, vi /config/bigip.conf.
     
  4. Remove the configuration line having '/Partition_name/VLAN_name' configuration file or comment out the line by adding '#' at the start of the line.
     
  5. Save the changes and exit the text editor.
     
  6. Run the following tmsh command to check the config load and errors:
    tmsh load sys config verify
     
  7. Load the configuration from the modified configuration file by typing the following command:
    tmsh load sys config
