Topic

You should consider using this procedure under the following conditions:

  • Your BIG-IP Virtual Edition (VE) runs on one of the following platforms:
    • VMWare ESXi /vCenter Server
    • Amazon Web Services (AWS)
    • Microsoft Azure 
    • Google Cloud Platform (GCP)
  • You want to access the serial console of the BIG-IP VE.

Important: The underlying technology to access the serial console of the BIG-IP VE depends on the specific vendor's platform. The steps may change without our knowledge. F5 Support does not provide troubleshooting support for issues related to serial console access. Consult the links provided and summarized in this article to refer to each vendor's documentation and support.

Description

This article provides a summary of links to access the serial console of BIG-IP VE on the different cloud platforms.

Note: The following procedures are provided for quick access. The cloud provider may update the procedures to access the serial console without our knowledge. For prerequisites, updates, and other details, refer to the specific links provided for each cloud provider.

Cloud platformProcedure to access serial consoleAdditional Information 
VMWare ESXi /vCenter ServerTo connect to VMWare remote console, refer to Start the VMware Remote Console Application:
  1. On the vSphere client, go to the virtual machine inventory.
  2. Select the BIG-IP virtual machine.
  3. On the Summary tab, select Launch Remote Console.
  • To access the BIOS and configure the BIOS boot delay, refer to Accessing the BIOS when the POST screen clears too quickly
 
Amazon Web Services (AWS)To connect to the EC2 serial console, refer to Connect to the EC2 Serial Console: 
  1. On AWS portal, go to EC2 > Instances.
  2. Select the BIG-IP instance.
  3. Select Actions > Monitor and troubleshoot > EC2 Serial Console.
  • To connect to an EC2 serial console, the instance must use an instance type that is built on the AWS Nitro System. This does not include bare metal instances. You can change the instance type.

    Note: The Nitro System is a collection of AWS-built hardware and software components. F5 does not provide a recommendation. To get recommendations for compatible instance types, refer to supported instance type for serial console and Get recommendations for an instance type.

  • You can also get an instance screenshot of the console output. For more information, refer to Get console output/instance screenshot.
 
Microsoft AzureTo connect to Azure serial console, refer to Azure Serial Console:
  1. On the Azure portal, select All resources.
  2. Select the BIG-IP virtual machine.
  3. In the Support + troubleshooting section, select Serial console.
  • To connect to the serial console, you need to enable boot diagnostics for the BIG-IP VM. For more information and other prerequisites, refer to Azure Serial Console for Linux.
  • You can also display a screenshot of a snapshot of your VMs current state or display the serial logs through boot diagnostics. For more information, refer to Azure boot diagnostics.
  • When the BIG-IP configuration fails to load, only root or admin users may log in and you may encounter login issues. For more information, refer to K28320936: Unable to login to BIG-IP VE on Azure when config load fails.
 
Google Cloud Platform (GCP)To connect to the VM instance's serial console, refer to Troubleshooting using the serial console:
  1. On the GCP portal, under the appropriate project, go to Compute Engine > VM Instances.
  2. Select the BIG-IP VM instance.
  3. Under Remote access, select Connect to serial console.
  • To connect to the serial console, you need to first enable connecting to serial ports for the instance.

  • You can also view serial port output and capture VM screenshots. For more information, refer to Viewing serial port output and Capturing VM screenshots, respectively.

 

Note: The links in this table take you to a resource outside of AskF5, and it is possible that the documents may be updated or removed without our knowledge.
