K32805293: How to Change APM webtop title ''F5 Dynamic Webtop'' to customized title

Type

Published
2021-01-19
Updated
2025-04-01
Applies to

  • BIG-IP APM
Source

Description
Change the APM webtop title "F5 Dynamic Webtop" to customized title.
Note : Unfortunately this is not officially supported at this time

Environment

APM Webtop customization 

Cause

Customization 

Recommended Actions

To change the title of "F5 Dynamic Webtop" you need to edit the following files:

/var/sam/www/php_include/webtop/renderer/webtop_full/full/mobile/webtop.inc
/var/sam/www/php_include/webtop/renderer/webtop_full/full/unknown/webtop.inc
/var/sam/www/php_include/webtop/renderer/webtop_full/full/mac/webtop.inc
/var/sam/www/php_include/webtop/renderer/webtop_full/full/linux/webtop.inc
/var/sam/www/php_include/webtop/renderer/webtop_full/full/windows/webtop.inc

For example change it on windows path :
/var/sam/www/php_include/webtop/renderer/webtop_full/full/windows/webtop.inc

Add below at the end of file:

<script language="javascript">
document.title = "Customized Title";             -------> Replace "Customized Title" with actual title 
</script>

Test the Webtop using a Windows machine after clearing cache.

Note : This will most certainly be overwritten by an upgrade
