K50359390: How to change a Self-IP address or its Subnet Mask

Type
Support Solution
Published
2019-10-30
Updated
2025-04-01
Applies to
  • BIG-IP
Source

Description

How to change the name of a Self IP, its address, or it's Subnet Mask on an in-use, or deployed BIG-IP. The BIG-IP operating system will reject these configuration changes, because doing so could make resources on an associated VLAN unreachable, resulting in the following error message:
K60575145 : Error Message: Cannot delete IP <IP_address> because it would leave a pool member (pool <pool_name>) unreachable.

In order to change a Self IP, you must first create the new Self IP address. After creating the new Self IP address for a given VLAN, the older Self IP can be deleted.

Environment

  • Admin needs to change a Self IP of Subnet Mask of a Self IP associated with an in-use VLAN.
  • CLI or GUI admin access is required.
  • Self IP addresses

Cause

Self IPs cannot have the IP address changed once they have been created. This is by design.

Recommended Actions

To modify Self IP properties, it is necessary to delete the address, and re-create it.

  1. Add the new Self IP (w/ new Name, IP address, or Subnet Mask) to the VLAN.
  2. Delete old Self IP address.
    Note: If an address is used for mirroring, failover or ConfigSync as part of the HA config  please refer to K14123529 How To Change HA Self-IP's Subnet Mask w/o causing a Failover event
