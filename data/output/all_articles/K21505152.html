K21505152: Portal access RST : SSL proxy shutdown (unrecognized name(112))

Type
Support Solution
Published
2023-07-14
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.1
Source
https://my.f5.com/manage/s/article/K21505152

Description

Admin has configured Portal access and the page loads partially or does not load at all.
 

Environment

  • Portal Access on port 443 
  • SNI value set on client hello on server side connection

Cause

Packet Captures confirms that   https://example.com has Server name on Client hello (extension) , which Portal access does not support 

BUGID : 588518
 

Recommended Actions

  • VS has default "serverssl" profile

ltm virtual /Common/VS_portal {
    destination /Common/192.168.20.21:443
    profiles {
        /Common/serverssl {
            context serverside

  • Create serverssl profile "/Common/serverssl_sni_cdn"

ltm profile server-ssl /Common/serverssl_sni_cdn {
    app-service none
    defaults-from /Common/serverssl
    server-name sample.example.com 
}

  • Add this irule to that VS a 

(user hex to strong convertor to get this value like : Online Text To Hex Converter Tool Note: This link takes you to a resource outside of myf5. The third parties could remove these documents without our knowledge.) 

when HTTP_REQUEST {
    if { [HTTP::has_responded] } { return }
    set ssp 0
    # sample.example.com -> 63646e2e6a6ss16d616e6574776f726b2e636f6d
    if {[HTTP::path] contains "63646e2e6a6ss16d616e6574776f726b2e636f6d"} {
      set ssp 1
    }
}
when SERVER_CONNECTED {
  if {[info exists ssp] && $ssp} {
    SSL::profile serverssl_sni_cdn
    set ssp 0
  } else {
      SSL::profile serverssl
    }
