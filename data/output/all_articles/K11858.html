Known Issue

This is the result of a known issue. When the maximum number of concurrent sessions has been reached and another user logs into the BIG-IP APM device, an existing user's session is terminated. The expected behavior is that the new user would receive an error message stating that the maximum number of sessions has been reached.

F5 Product Development tracked this issue as ID 336747 and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.
