Description

 You should consider using this procedure under the following condition:

  • You want to view the Network Access IPV4 or IPV6 lease pool statistics.
  • The BIG-IP APM system is configured for Network Access. Each client connected to Network Access is assigned a unique IP Address from a lease pool associated with that Network Access configuration. You can view lease pool statistics from the BIG-IP command line using the following procedure.

Environment

  • BIGIP APM with network Access (VPN) configured
  • You have administrative command line access to the BIG-IP APM system
  • You have Network Access configured with clients connected to a lease pool.

Cause

None

Recommended Actions

Displaying Network Access lease pool statistics (BIG-IP 12.x - 15.x)

You can view IPV4 or IPV6 lease pool statistics (total, assigned, max assigned, and free) at the BIG-IP command line using the following procedure.
Note:Network access lease pool statistics can not be reset independently from the access profile statistics.
Impact of procedure: Performing the following procedure should not have a negative impact on your system.
 
  • Log in to the BIG-IP command line as an administrative user.
  • Type the following command to view the lease pool statistics:

tmsh show apm resource leasepool

Output appears similar to the following example:

[root@apm:Active:Standalone] config # tmsh show apm resource leasepool

-----------------------------------------
Apm::Leasepool Statistics: Lease_Pool
-----------------------------------------
Current Members         254
Current Assigned          0
Current Free            254
Total Pick Requests       0
Total Pick Failures       0
Total Reserve Requests    0
Total Reserve Failures    0
Total Release Requests    0
Total Release Failures    0

Note: What the Totals are displaying, is the stats from the DHCP Server running on the BIG-IP.
The Total Release Failures usually indicates that the Client did not shutdown gracefully. If the Client does not re-connect within the Access Session Max session time, then a Release Failure will be logged.

Displaying Network Access lease pool statistics (BIG-IP 11.5.x - 15.x), bash shell
You can view IPV4 or IPV6 lease pool statistics (total, assigned, max assigned, and free) at the BIG-IP command line using the following procedure.
Note:Network access lease pool statistics can not be reset independently from the access profile statistics.
Impact of procedure: Performing the following procedure should not have a negative impact on your system.
 
  • Log in to the BIG-IP command line as an administrative user.
  • Type the following command to view the lease pool statistics:

 tmctl -w 200 leasepool_stat

name              slot_id cur_members cur_assigned cur_free max_assigned tot_pick_requests tot_pick_failure tot_reserve_requests tot_reserve_failure tot_release_requests tot_release_failure
----------------- ------- ----------- ------------ -------- ------------ ----------------- ---------------- -------------------- ------------------- -------------------- -------------------
/Common/Lease_Pool       0          254            0                    1                 1                0                    0                   0                    0                   0

Note: The -w option to tmctl specifies the formatted width of the output.
