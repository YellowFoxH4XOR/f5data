Known Issue

This is the result of a known issue. The Data Guard feature may not consistently enforce user-defined URLs when the enforcement mode is set to Enforce URLs from the list. As a result, Data Guard may incorrectly mask or block objects, or may incorrectly not mask or block objects.

Note: This issue does not occur when the Data Guard enforcement mode is set to the default setting, Enforce All URLs.

F5 Product Development tracked this issue as ID 225498 (formerly CR139552) and it was fixed in BIG-P 11.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.

This issue has been fixed in Hotfix-BIGIP-10.2.0-1755.1-HF1, which has been issued for BIG-IP 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing version 10.x hotfixes on systems, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
