K30494518: BIG-IQ not able to access GUI/SSH

Type
Support Solution
Published
2022-01-25
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K30494518

Description

You had lost access to BIG-IQ GUI and SSH.

Environment

  • BIG-IQ VE
  • Maintenance mode

Cause

File system may be corrupted.

Recommended Actions

Perform a file system check on the BIG-IQ system.

  1. Connect to the BIG-IQ system through console access.
  2. In Maintenance mode, enter the following command:

    fsck -Ay

  3. Reboot the BIG-IQ system and verify if login to GUI and SSH is restored.

Additional Information

None
