F5 BIG-IP LTM Traffic Policy Redirect Issue Resolution

Description

You are experiencing an issue with configuring your F5 BIG-IP LTM Traffic Policy. The error message "invalid url, value 'https://rightdomain.com%[HTTP::uri]'" indicates that there is a problem with the format of the URL used in the HTTP Redirect action. To address this, you correctly modified the redirect action to use TCL syntax. The correct format should be "tcl:https://rightdomain.com%[HTTP::uri]".

Environment

  • BIG-IP LTM is configured to redirect HTTP requests
  • The Traffic Policy is intended to redirect from wrongdomain.com to rightdomain.com
  • SSL offloading is configured on the LTM

Cause

The error was caused by an incorrect format in the HTTP redirect action URL. The BIG-IP system expects the redirect URL to be in a specific format that can be parsed and executed as a TCL command.

Recommended Actions

  • Correctly configure the HTTP Redirect action using TCL syntax:
    1. Edit the existing LTM Traffic Policy rule that contains the incorrect redirect action.
    2. Change the redirect action to use the TCL syntax: tcl:https://rightdomain.com%[HTTP::uri].
    3. Save the changes to the rule and policy, and ensure the policy is still associated with the relevant virtual server.
  • Test the redirect by accessing https://wrongdomain.com/index.html and verify that the client is redirected to https://rightdomain.com/index.html with the proper URI.
  • Monitor the application and network performance following the changes to ensure there are no disruptions or unintended behaviors.

Additional Information

Using TCL syntax for the redirect action allows for dynamic construction of the redirect URL. This method is powerful and flexible, enabling the use of various TCL commands and variables to manipulate the request and response traffic as needed by the policy.
