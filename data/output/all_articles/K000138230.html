Description

Attempting to send a large packet to a sever behind the BIG-IP fails.
The server returns an ICMP packet with Destination unreachable, Fragmentation needed to the BIG-IP.
The BIG-IP does not forward this ICMP packet to the Client.

Environment

IP-Forward Virtual Server
FastL4 profile with pva-acceleration enabled

Cause

Sequence number validation is enabled for accelerated flows.
This can be confirmed by verifying the value of the system variable pva.validatetcpseqinicmp

sys db pva.validatetcpseqinicmp {
default-value "true"
scf-config "true"
value "true"   <-- - - !!
value-range "false true"
}

Recommended Actions

Disable  PVA Acceleration on the Fastl4 profile of the affected virtual server.

or

Set Pva.ValidateTcpSeqInICMP to false with the command below:
tmsh modify sys db pva.validatetcpseqinicmp value false
