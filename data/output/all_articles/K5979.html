Topic

This article applies to BIG-IP ASM 9 .x through 10.x. For information about other versions, refer to the following article:

  • K42301022: Configuring the BIG-IP ASM to parse HTTP responses that are larger than 50 MB in length (11.x - 12.x)

You should consider using this procedure under the following condition:

  • You want to configure BIG-IP ASM to parse HTTP responses that are larger than 50 MB in length.

Description

By default, BIG-IP ASM does not parse HTTP responses that are longer than 50 MB in length. The max_filtered_html_length parameter defines the maximum response size that BIG-IP ASM can accumulate for purpose of checking or extracting data from the response. When the response exceeds the 50 MB length, BIG-IP ASM stops accumulating the response, logs an error message to /var/log/asm file, and passes the response to the client.

Note: BIG-IP ASM may fail to pass responses exceeding the 50 MB limit to the client. For more information, refer to K10007: BIG-IP ASM may fail to pass large responses to the client.

You can change the maximum response size that BIG-IP ASM will parse by performing one of the following procedures:

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have access to the BIG-IP Configuration utility.

Procedures

Modifying the max_filtered_html_length variable (10.2.0 - 10.2.4)

Impact of procedure: Restarting the BIG-IP ASM service will result in a brief traffic disruption.

  1. Log in to the BIG-IP Configuration utility.
  2. Click Application Security.
  3. In the Application Security menu, click Options.
  4. Click Advanced Configuration.
  5. On the System Variables page, locate the max_filtered_html_length setting.
  6. Enter the new maximum response size in bytes.
  7. Click Update.
  8. Log in to the command line.
  9. Restart the BIG-IP ASM processes by typing the following command:

    bigstart restart asm


Modifying the max_filtered_html_length variable (9.x - 10.1.0)

Impact of procedure: Restarting the BIG-IP ASM service will result in a brief traffic disruption.

  1. Log in to the BIG-IP Configuration utility.
  2. Click Application Security.
  3. Click Web applications.
  4. On the Application Security Main tab, click Options.
  5. Click Advanced Configuration.
  6. On the System Variables page, locate the max_filtered_html_length setting.
  7. Enter the new maximum response size in bytes.
  8. Click Update.
  9. Log in to the command line.
  10. Restart the BIG-IP ASM processes by typing the following command:

    bigstart restart asm
