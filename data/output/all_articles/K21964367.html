Known Issue

When you configure external logging for access control list (ACL) rule hits and the logging server connection is routed through a forwarding virtual server, the ACL logging produces a Traffic Management Microkernel (TMM) core file and causes service disruption.

This issue occurs when all of the following conditions are met:

  • You have an external logging server configured for an ACL rule match.
  • The destination IP address of the external logging server matches a forwarding virtual server's destination address and netmask and is routed through the forwarding virtual server IP address.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from the TMM restart, and devices configured for high availability (HA) may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system temporarily fails to process traffic as it recovers from the TMM restart, and devices configured for HA may fail over.
  • Your BIG-IP system generates a TMM core file to the /shared/core directory.

Workaround

To work around this issue, you can avoid configuring forwarding of remote logging through a forwarding virtual server, or you can fully disable remote logging.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
