Security Advisory Description

Undisclosed BIG-IQ pages have a reflected cross-site scripting vulnerability. (CVE-2021-23006)

Impact

An attacker may exploit this vulnerability using a crafted URL to a reflected cross-site scripting (XSS) in an undisclosed page of the BIG-IQ user interface.

Security Advisory Status

F5 Product Development has assigned ID 937677 (BIG-IQ) to this vulnerability.
