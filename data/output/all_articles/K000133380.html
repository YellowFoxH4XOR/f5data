Description

  • You installed F5 Access on your M-series CPU Mac, but it is not running.

Environment

  • F5 Access on MacOS
  • M1 CPU

Cause

F5 Access is not natively designed to run on Apple Silicon processors.

 Recommended Actions

  1. To be able to use F5 Access on Apples processors you will need an emulator software such as Rosetta.

For how to install and use Rosetta, see the Rosetta documentation:
https://support.apple.com/en-us/HT211861

Additional Information

For more information, refer to the F5 Access Apps Compatibility Matrix.
