K12201682: Datasync Obfuscator Process Runs Daily Causing High CPU Usage

Type
Support Solution
Published
2019-09-27
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP ASM
  • BIG-IP FPS
Source
https://my.f5.com/manage/s/article/K12201682

Description

  • Beginning in BIG-IP ASM and BIG-IP FPS 11.6.0 datasync-global-dg Device Group is automatically created
  • datasyncd in BIG-IP ASM and BIG-IP FPS within a Trust Domain runs an obfuscation process, daily and at the same time.
    NOTE: For more details about the datasync-global-dg refer to K16509: Overview of the datasync-global-dg device group
  • For BIG-IP ASM v14.x and later: K02827102: BIG-IP ASM and BIG-IP FPS systems experience higher CPU usage for several hours per day

Environment

  • High CPU usage for multiple hours
  • BIG-IP ASM and BIG-IP FPS
  • In a Device Group

Cause

BIG-IP ASM and BIG-IP FPS operating as designed

Recommended Actions

  • Determining When The Obfuscation Process Runs Each Day
  • Reschedule the daily start time of the Datasync Background Tasks

Determining When The Obfuscation Process Runs Each Day
Impact of procedure: Performing this procedure should not have a negative impact on your system.

By performing this procedure you will be able to determine at what time of day the datasync obfuscation process runs each day.

  1. SSH to log into the BASH prompt

  2. Search  /var/log/datasync/datasyncd.log for the next run:

    grep 'GEN_STATE_GRACE.*next' /var/log/datasync/datasyncd.log

    [CS_ASM_DOSL7 ] ( 0 seconds ago) GEN_STATE_GRACE [ 1000 / 1000] next : 1552757062 (Sat, Mar 16 2019 17:24:22)
    [CS_ASM_DOSL7 ] ( 0 seconds ago) GEN_STATE_GRACE [ 46 / 46] next : 1552843462 (Sun, Mar 17 2019 17:24:22)
    [CS_ASM_DOSL7 ] ( 0 seconds ago) GEN_STATE_GRACE [ 46 / 46] next : 1552929862 (Mon, Mar 18 2019 17:24:22)

Reschedule the daily start time of the Datasync Background Tasks

Use the WebUI and navigate to Security  ››  Options : Background Tasks
Should you discover that this process is impacting production traffic, Contact F5 Networks Support for assistance.

Additional Information

  • The obfuscation process runs when ASM and FPS is first provisioned or when a device receives a sync on the datasync-global-dg device group.
    This also sets the daily time the sync will occur every day moving forward.
  • The obfuscation process consumes available resources with a lower priority. If more important processes need CPU/Memory the obfuscation is de-prioritized or will wait until resources are available.
