K23204295: After failover to standby device, new VPN sessions (from Edge Client and via WEB) are not established

Description

The edge client cannot establish the connection. The users can see the error on the client:

/my.logout.php3?errorcode=21

Environment

  • The BIG-IP HA Pair failover
  • Edge Client cannot connect
  • errorcode=21

Cause

This device is encountering ID 994033 where the httpd_sam daemon doesn't recover and needs to be manually restarted.

Recommended Actions

  1. Check the status of httpd_apm daemon:
    httpd_apm down, waiting for httpd_sam to begin

    If it is down, continue to next step.
     
  2. Check the logs for entries associated with httpd_sam

    grep -i httpd_sam /var/log/apm
    run_httpd_sam_reinit: httpd_sam is not running. Skip reinit call.

    grep -i httpd_sam /var/log/daemon.log
    warning systemd[1]: httpd_sam.service failed.
    notice systemd[1]: Unit httpd_sam.service entered failed state.
    ????warning systemd[1]: httpd_sam.service start operation timed out. Terminating.

    If you see errors, continue to next step

  3. Restart the httpd_sam and httpd_apmd process:

    tmsh restart sys service httpd_sam httpd_apm
