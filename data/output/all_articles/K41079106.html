K41079106: Violation ''Illegal cross-origin request'' triggered

Type
Support Solution
Published
2020-07-06
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP ASM: 13.1.X, 13.1.4, 13.1.3, 13.1.1, 13.1.5, 13.1.0
Source
https://my.f5.com/manage/s/article/K41079106

Description

Violation "Illegal cross-origin request" triggered.

Environment

  • Request is blocked
  • It is a false positive
  • URL 'Enforcement Action' set to 'Verify Origin'

Cause
Upon inspection of the request headers, the following was found:

Origin: null

This triggered the violation  "Illegal cross-origin request".

Recommended Actions

An iRule can be used to remove this header from the request. An example of such is as follows:

when HTTP_REQUEST {
    if { [HTTP::header value "Origin"] starts_with "null" } then {
        HTTP::header remove "Origin"
    }
}

None.
