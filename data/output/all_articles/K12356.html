K12356: Citrix web portal applications fail to launch when App Tunnels are set to 'Don't Use' in the master group

Topic

When the master group App Tunnels option is set to Don't Use, attempts to access a Citrix web portal application in FirePass will fail with an HTTP 404 Not Found error message. This behavior is expected. When a user requests an application, the Citrix helper function opens an access tunnel to launch the application locally on the users computer.

Workaround

To enable the App Tunnel option, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Users : Groups : Master Groups.
  3. Click the name of the master group that has App Tunnels disabled.
  4. Click the User Experience tab.
  5. On the AppTunnels webifyer, click the Beginner option button.
  6. Click the Update button.
