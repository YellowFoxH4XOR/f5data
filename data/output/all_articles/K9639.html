Known Issue

This is the result of a known issue. The asm_snapshot file contains BIG-IP ASM configuration files that F5 Technical Support frequently needs when troubleshooting a BIG-IP ASM issue. An asm_snapshot file is produced by the asmqkview utility.

The asm_snapshot file does not include the PRX.PROXY_LOG_CONSUMERS table from the MySQL database. This table can help with troubleshooting learning manager issues.

F5 Product Development tracked this issue as CR101797 and it was fixed in BIG-IP ASM 9.4.6. For information about upgrading, refer to the BIG-IP ASM release notes.
