Description

  • Clients connecting through the SWG proxy receive status 503 errors for some sites.
  • If you have multiple datacenters, the users connecting to SWG at other datacenters may work.
     

Environment

  • Secure Web Gateway (SWG) installed.
  • APM integration is not required.

Cause

  • DNS resolution is failing. The  BIG-IP cannot resolve the requested site. DNS resolvers are typically different at different datacenters.
  • Enabling IPV6 support in  SWG requires that your infrastructure supports IPV6. Enabling IPV6 when SWG cannot connect with IPV6  will cause extensive failures.
     

Recommended Actions

  1. Ensure the sites resolve correctly.

Additional Information

If you have added irules to SWG, failures there can also cause  503 to be returned.
