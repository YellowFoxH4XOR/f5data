Issue

Old Behavior

In versions prior to BIG-IP 13.0.0, the Single-NIC BIG-IP Virtual Edition (VE) uses TCP port 443 for management traffic (traffic for the Configuration utility), by default. If you intend to use TCP port 443 for your application traffic, you must reconfigure the BIG-IP VE to use a different port for the Configuration utility.

New Behavior

Beginning in BIG-IP 13.0.0, the Single-NIC BIG-IP VE now uses TCP port 8443 for management traffic (including iControl REST), by default. This allows you to use TCP port 443 for your application traffic without having to reconfigure the listening port for the Configuration utility.

Note: The BIG-IP VE running on multiple NICs will still use TCP port 443 for management traffic, by default. You can use the tmsh list /sys httpd ssl-port command to verify the port that the httpd process is using.

F5 Product Development tracked this change as ID 597682.

Impact

You must specify the port number 8443 in the URL of your browser to access the Configuration utility of the BIG-IP system. For example, you would enter the following content in your browser:

https://<ip-address>:8443

Recommended Actions

None
