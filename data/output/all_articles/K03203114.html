Topic

Starting in BIG-IP 13.0.0 and BIG-IQ 8.0.0, there are two .iso images available for released versions on the F5 Downloads site.

Description

In the BIG-IP 13.0.0 release, the BIG-IP .iso image size is too large to be compatible with some older versions of the BIG-IP system.

A large contributor to the size of the .iso image is the number of F5 platform End User Diagnostics (EUD) images that the system must support. To mitigate this size limitation, F5 provides variant BIG-IP and BIG-IQ .iso images without the EUD files.

Beginning in BIG-IP 13.0.0 and BIG-IQ 8.0.0, the naming convention is similar to the following examples:

Image namePurpose
BIGIP-x.y.z-n.n.nnn.iso
BIG-IQ-x.y.z-n.n.nnn.iso		Use this image for upgrades; the image does not contain updated EUD files.
BIGIP-RECOVERY-x.y.z-n.n.nnn.iso
BIG-IQ-RECOVERY-x.y.z-n.n.nnn.iso		Use this image for full system recovery; the image contains the EUD files. The image size is larger than the upgrade image file.

Note: A RECOVERY iso image may not be available for every BIG-IP point release. If a RECOVERY iso image is not available for a specific BIG-IP point release, you can obtain the latest EUD package in the Hardware-Specific section of the F5 Downloads site. For more information, refer to K167: Downloading software and firmware from F5.
