Description
After upgrading from an earlier software version to 14.1.2.7 (or to v15.1.2), HA stops working via the management interface.
If there is no working unicast failover via the TMM channel, this will result in the units becoming Active Active.

You observe the following on all HA units during the issue:

  • The failover status is showing as 'Error' for the management entry per below:
    tmsh show cm failover-status

              --------------------
          CM::Failover Status
          --------------------
          Color    gray
          Status   STANDBY
          Summary  1/1 standby
          Details
          ------------------------------------------------------------------------------------------
          CM::Failover Connections
           Local Failover Address  Remote Device  Packets  Transitions  Received Last Packet  Status
           ------------------------------------------------------------------------------------------
           5.5.5.1:1026               Unit 1       0            1            -                Error  
           1.1.1.10:1026              Unit 1      50            2      2020-Nov-12 11:32:52     Ok

  • An entry for the management IP is missing when running the command below
    netstat -pano | grep -E 'sod|1026'

Environment

  • VCMP Guests
  • Network failover configured via management
  • Upgrade from pre v14.1.2.7 to 14.1.2.7
  • Upgrade from 15.1.0.4 to 15.1.2

Cause
ID969105

Recommended Actions

To workaround the issue you can run the command below on all VCMP Guests in the HA

touch /var/run/chmand.pid

Note: If the Guests are deployed on multiple slots, use the command below instead

clsh touch /var/run/chmand.pid


Important: The following workaround will not survive a reboot
