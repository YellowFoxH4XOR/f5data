Description

Most UDP applications, such as, DNS, do not send a response unless a valid request is received. For this reason, the UDP monitor is designed to primarily work with ICMP Destination Unreachable messages. If ICMP Destination Unreachable message is not received within "timeout", the pool member will be marked UP. In situations where the pool member sends a response, the pool member will be marked UP immediately without waiting for ICMP Destination Unreachable message. For more information about UDP monitor, refer to K6143: UDP health monitor operation.

From BIG-IP help page:

"Time Until Up":
Specifies the number of seconds to wait after a resource first responds correctly to the monitor before setting the resource to up. During the interval, all responses from the resource must be correct. When the interval expires, the resource is marked up. The default is 0, meaning that the resource is marked up immediately upon receipt of the first correct response.

In order for "Time Until Up" feature in UDP monitor to work, the pool member must send a response.

Below shows various scenarios and monitor behavior.

(tmos)# list /ltm monitor udp
- snip -
ltm monitor udp udp_monitor {          <=== same as default udp monitor
    adaptive disabled
    debug no
    defaults-from udp
    interval 5
    recv none
    recv-disable none
    send "default send string"
    time-until-up 0
    timeout 16
}
ltm monitor udp udp_monitor_time_until_up_60 {
    adaptive disabled
    debug no
    defaults-from udp
    interval 5
    recv none
    recv-disable none
    send "default send string"
    time-until-up 60                   <===
    timeout 16
}
ltm monitor udp udp_monitor_time_until_up_60_recv_string {
    adaptive disabled
    debug no
    defaults-from udp
    interval 5
    recv "i am alive"                  <===
    recv-disable none
    send "default send string"
    time-until-up 60                   <===
    timeout 16
}

Environment

  • BIG-IP
  • UDP monitor

Cause

"Time Until Up" only works if the pool member sends a response.

Recommended Actions

To use "Time Until Up" feature in UDP monitor, make sure your UDP server sends a response.
