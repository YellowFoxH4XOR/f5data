Description

  • Machine Cert Auth VPE item fails
  • Session variable 'session.check_machinecert.last.result' set to '-2'
  • Messages logged in /var/log/apm when making changes to the Machine Cert Auth VPE item similar to: 
May 23 19:12:59 mybigip.local err apmd[15542]: 0149015f:3: MachineCert Agent: Init failed in '/Common/access_policy_act_machinecert_auth_ag' reason 'Loading CA file failed'

Environment

  • APM
  • Machine Cert Auth configured to verify machine certificate installed on client computer
  • Correct installation of machine certificate and key on client computer was verified with "certutil -store my"
  • Client does NOT show message "Checking machine certificate..."
     

Cause

The CA certificate configured in the Machine Cert Auth object was imported using a format other than PEM. Certificates have to be imported in PEM format to be used by BIG-IP.

Recommended Actions

Make sure the CA certificate is imported using PEM format.

None.
