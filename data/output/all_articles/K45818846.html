Topic

You should consider using this procedure under the following condition:

  • You want to view, create, or delete users on the BIG-IP system using the iControl representation state transfer (REST) API.

Description

You can view, create, and delete users on the BIG-IP system. For more information about system user accounts, refer to K12173: Overview of BIG-IP administrative access controls.

The REST procedures described in this article are examples of common BIG-IP maintenance tasks. You can use the iControl REST API to perform most of the BIG-IP system management and configuration tasks that you can perform using the TMOS Shell (tmsh). For more information about the iControl REST API, refer to the iControl REST User Guide that applies to your BIG-IP system, available on F5 Cloud Docs.

The curl and jq utilities

Performing the following procedures requires command-line access to a system with the curl utility and, optionally, the jq (command line JSON processor) utility installed. These utilities are commonly available on Linux systems but can also be installed on Microsoft Windows and Mac OS X systems. Additionally, you can perform this procedure from an alternate BIG-IP system; however, the jq utility is not available on systems running versions earlier than BIG-IP 12.0.0. You can still use the curl portion of commands, but the resulting output is a single string rather than formatted JSON. For more information about the jq utility, refer to https://stedolan.github.io/jq.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Your BIG-IP system is licensed, provisioned, and configured with a management IP address.
  • You have administrative access to the BIG-IP Configuration utility.
  • You have command line access to a system with the curl utility and, optionally, the jq utility installed. From more information, refer to curl and jq utilities in this article.
  • You have access to F5 Cloud Docs to review iControl REST API documentation.

Procedures

  • Viewing the configuration for a BIG-IP system user account
  • Creating a new BIG-IP system user account on BIG-IP 11.6.0 and later
  • Creating a new BIG-IP system user account on BIG-IP 11.5.x and earlier
  • Deleting an existing BIG-IP system user account

Viewing the configuration for a BIG-IP system user account

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to view the configuration for the specified BIG-IP system user account:

    curl -sku admin:<password> -H "Content-Type: application/json" -X GET https://<BIG-IP hostname or mgmt IP address>/mgmt/tm/auth/user/<username> | jq -M .

    For example, to view the configuration for the user User_1 on a BIG-IP using the previously listed Example configuration, type the following command:

    curl -sku admin:testing -H "Content-Type: application/json" -X GET https://LTM1.example.com/mgmt/tm/auth/user/User_1 | jq -M .

    The output looks similar to the following example:

    {
      "kind": "tm:auth:user:userstate",
      "name": "User_1",
      "fullPath": "User_1",
      "generation": 401,
      "selfLink": "https://localhost/mgmt/tm/auth/user/User_1?ver=12.1.3",
      "description": "User_1",
      "encryptedPassword": "$6$r5eMKDWx$Sn251DC.QjxB/Ut/I8Z5u4CbQ6bc0NeURxPqxz2gFEhuneYIBhTJLIA7L8Nkft3M4roEJFgexvfJwsWLvGF.S1",
      "shell": "tmsh",
      "partitionAccess": [
        {
          "name": "Common",
          "role": "operator",
          "nameReference": {
            "link": "https://localhost/mgmt/tm/auth/partition/Common?ver=12.1.3"
          }
        }
      ]
    }

    If the specified user does not exist on BIG-IP 12.1.0 and later, the output looks similar to the following example:

    {
      "code": 404,
      "message": "01020036:3: The requested user (User_1) was not found.",
      "errorStack": [],
      "apiError": 3
    }

    If the specified user does not exist on BIG-IP 12.0.0 and earlier, the output looks similar to the following example:

    {
      "code": 404,
      "message": "01020036:3: The requested user (User_1) was not found.",
      "errorStack": []
    }

Creating a new BIG-IP system user account on BIG-IP 11.6.0 and later

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to create a new BIG-IP system user account:

    curl -sku admin:<password> -H "Content-Type: application/json" -X POST https://<BIG-IP hostname or mgmt IP address>/mgmt/tm/auth/user -d '{"name":"<username>","password":"<password>","partition-access":[{"role":"<user role>","name":"<partition name>"}],"shell":"tmsh"}' | jq -M .

    For example, to create a user named User_2 in the Common partition with the operator role and access to tmsh on a BIG-IP using the previously listed Example configuration, type the following command:

    curl -sku admin:testing -H "Content-Type: application/json" -X POST https://LTM1.example.com/mgmt/tm/auth/user -d '{"name":"User_2","password":"testing","partition-access":[{"role":"operator","name":"Common"}],"shell":"tmsh"}' | jq -M .

    The output looks similar to the following example:

    {
      "kind": "tm:auth:user:userstate",
      "name": "User_2",
      "fullPath": "User_2",
      "generation": 402,
      "selfLink": "https://localhost/mgmt/tm/auth/user/User_1?ver=12.1.3",
      "description": "User_2",
      "encryptedPassword": "$6$5z/UzGGI$DAa2FDImtpYPW/h/gFHR3XoGpL7TDj8boXaK4UrCLT7yJBRb5xYObOi9icmAlx4Wfb65VXpGLdiVV1DmYVxPX0",
      "shell": "tmsh",
      "partitionAccess": [
        {

            "link": "https://localhost/mgmt/tm/auth/partition/Common?ver=12.1.3"

    }

Deleting an existing BIG-IP system user account

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl utility installed
  2. Use the following command syntax to delete a BIG-IP system user account:

    curl -sku admin:<password> -H "Content-Type: application/json" -X DELETE https://<BIG-IP hostname or mgmt IP address>/mgmt/tm/auth/user/<username>

    For example, to delete the system user account User_2 on a BIG-IP using the previously listed Example configuration, type the following command:

    curl -sku admin:testing -H "Content-Type: application/json" -X DELETE https://LTM1.example.com/mgmt/tm/auth/user/User_2

    Note: This command does not produce output.
