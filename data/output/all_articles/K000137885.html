K000137885: After a reboot, are the Virtual Server and Pool statistics cleared?

Type
Support Solution
Published
2023-12-19
Updated
2023-12-19
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.2
Source
https://my.f5.com/manage/s/article/K000137885

Description

Some hours after a reboot I noticed a Virtual Server application was failing, so I would like to know if it was failing since the reboot or if it just started having issues.

 

Environment

  • BIG-IP
  • Virtual Server and Pool statistics.
  • Reboot

Cause

Virtual Server and Pool statistics are cleared after a reboot.

Recommended Actions

One way to determine if the service was working after a reboot is by reviewing the statistics of the Virtual Server or Pool. When the BIG-IP reboots, the statistics of the VS and Pool are cleared. If there is data shown in the statistics, it means that the VS was managing traffic at some point after the reboot. If all the statistics are zero, it means that there was no traffic after the reboot.

 

  • Review statistics from the GUI by navigating to Statistics ›› Module Statistics : Local Traffic and then select the Statistics Type you want to review.
  • Show Virtual Server statistics from the CLI

tmsh show ltm virtual <virtual_server_name>

  • Show Pool statistics from the CLI

tmsh show ltm pool <pool_name> members
