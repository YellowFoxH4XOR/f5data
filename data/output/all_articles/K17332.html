Known Issue

In rare conditions, the tmsh show sys conn command may cause the Traffic Management Microkernel (TMM) to produce a core file.

This issue occurs when all of the following conditions are met:

  • The Multipath TCP (MPTCP) option is enabled in the TCP profile.
  • You run the tmsh show sys conn command.
  • The BIG-IP system has connections in the forwarding state.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from TMM restarting. If you have configured the BIG-IP system as part of a high availability (HA) group, a device failover may occur.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails over to the standby system if the system is configured for HA.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
