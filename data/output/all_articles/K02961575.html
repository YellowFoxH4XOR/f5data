K02961575: How to monitor pool member with a value from a JSON file

Description

You want to monitor a pool with a condition and want to look for some specific value (e.g., "Error") and if that value is found then place the monitor in "UP" or  "Down" state. from json file from e.g. C:\AirWatch\emailgateway-X.X.X.\admin\abc.JSON

JSON is text based, and by default an HTTP monitor can parse the first 5,120 bytes into HTTP data (including the HTTP response headers).  This is explained in K3451:

K3451: Content length limits for HTTP and HTTPS health monitors
 

Environment

  • BIGIP
  • Monitor
  • JSON
  • HTTP

Cause

n/a

Recommended Actions 


This can be achieved via "Reverse" setting in HTTP monitors as explained in our manual pages in Monitor Settings Reference .

"Reverse:  Instructs the system to mark the target resource down when the test is successful. This setting is useful, for example, if the content on your web site home page is dynamic and changes frequently, you might want to set up a reverse ECV service check that looks for the string Error. A match for this string means that the web server was down. You can use Reverse only if you configure both Send String and Receive String."

The idea is simple - "if you find 'X' string in the response, mark the service as down;  else, mark it up".
