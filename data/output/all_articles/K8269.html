K8269: Web Application Tunnels are locked in Firefox when the Locked Browser option is disabled

Published

Updated
2023-02-21
Status

Applies to

  • FirePass: 6.0.0, 6.0.3, 6.0.2, 6.0.1
Source
https://my.f5.com/manage/s/article/K8269

Topic

If a user opens a Web Application Tunnel using Firefox, the browser window is locked even if the Locked Browser check box is not selected in the Web Application Tunnel configuration. This behavior occurs due to a code compatibility issue between the FirePass software and the Firefox software.

If your web application requires a full browser window, ensure that the Locked Browser check box is cleared in the Web Application Tunnel configuration, and that users connect to the FirePass controller using Microsoft Internet Explorer.

Note: Web Application Tunnels are configured on the Application Access: App Tunnels: Resources page under the Web Application Tunnels tab.

F5 Networks Product Development is tracking this issue as CR84697.
