Topic

You should consider using this procedure under the following condition:

  • You want to restrict access to the ASM Event Logs and Traffic Learning pages and corresponding REST APIs.

Description

By default, BIG-IP user accounts with less permissive user roles, such as Operator, can access the ASM Event Logs and Traffic Learning pages. As a result, these users may be able to view confidential or restricted information contained in the logs. For example, a user account with the Operator role can access the Security > Event Logs > Application > Requests page and view the details about an individual request that may contain confidential information.

Beginning in BIG-IP 16.0.0, you can prevent users with less permissive user roles from accessing the Event Log and Traffic Learning pages and corresponding REST APIs. After configuring the asm.restrict_asm_logs_access database variable, only users with Application Security and Administrator roles have access to the following Event Log and Traffic Learning pages and corresponding REST APIs:

  • Security > Policy building > Traffic Learning
  • Event logs > Application
    • Requests
    • Event Correlation
    • Brute Force Attacks
  • Event logs > Bot Defense
    • Bot Traffic
    • Bot Requests

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the TMOS shell (tmsh).

Procedures

Restricting access to the ASM Event Logs and Traffic Learning pages

To restrict access to the ASM Event Logs and Traffic Learning pages and corresponding iControl REST APIs, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log into the TMOS shell (tmsh) by entering the following command:

    tmsh

  2. Restrict access to the ASM Event Logs and Traffic Learning pages, by entering the following command:

    modify sys db asm.restrict_asm_logs_access value true

    Note: To restore access to the ASM Event Logs and Traffic Learning pages for user accounts with less permissive user roles, enter the following command: tmsh modify sys db asm.restrict_asm_logs_access value false
