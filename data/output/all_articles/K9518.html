Known Issue

This is the result of a known issue. When you log on to an Outlook Web Access (OWA) server through Portal Access and then delete an email message, the browser may continue to display the deleted message until you refresh the web page. This issue occurs when you open the email message in a new window and then click the delete icon in the message window. This issue does not occur when you select the email message in the main OWA window and click the delete icon. Additionally, this issue does not occur if the Open in new window check box is selected in the Web Application favorite configuration.

F5 Networks Product Development is tracking this issue a CR108562.
 
Additionally, this issue was fixed in cumulative hotfix HF-602-8 issued for FirePass version 6.0.2 and in cumulative hotfix HF-603-1 issued for FirePass version 6.0.3. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Networks Downloads page.
 
For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.
 
For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
 
Workaround
 
You can work around this issue by selecting the Open in new window check box in the Web Application favorite configuration. You can configure Portal Access Web Application favorites on the Portal Access: Web Applications: Resources page.
