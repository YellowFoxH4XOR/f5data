Issue

Error Message

01260009:4: Connection error: ssl_hs_alloc:1676: The number of per TMM active handshakes <value1> for <virtual server> on this TMM[<number>] reached the limit <value2>/TMM set in profile <profile>  (80)

In this error message, note the following:

  • <value1> is the number of active Secure Sockets Layer (SSL) handshakes that the virtual server is processing for the referenced Traffic Management Microkernel (TMM) instance.
  • <virtual server> is the name of the affected virtual server.
  • <number> is the affected TMM instance.
  • <value2> is the active SSL handshake limit defined in the SSL profile.
  • <profile> is the name of the SSL profile that is associated with the virtual server.

For example:

01260009:4: Connection error: ssl_hs_alloc:1676: The number of per TMM active handshakes 1000 for /Common/MySslVirtual on this TMM[1] reached the limit 1000/TMM set in profile /Common/MySslProfile  (80)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The number of active SSL handshakes for the virtual server reaches the limit specified in the Max Active Handshakes SSL profile setting.

You can use the Max Active Handshakes Client or Server SSL profile setting to limit the number of active SSL handshakes for the virtual server to which the profile is applied. The default setting is Indefinite, which means that there is no limit.

Impact

When the number of active SSL handshakes reaches the specified limit, the system terminates the most recent SSL handshake and logs this error message.

Recommended Actions

Monitor active SSL handshakes and system resources over time and determine whether you can increase the limit specified in the Max Active Handshakes SSL profile setting.
