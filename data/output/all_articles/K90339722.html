Description

When you try to set up a SecurID Object in APM VPE, the list of SecurID servers is displayed as none, even though you have SecurID AAA Objects setup in APM

Environment

  • BIG-IP 12.1.3.5 or 13.1.0.5 or lower
  • APM
  • SecurID AAA

Cause

This is a known bug (ID 712924 ), which is resolved in 12.1.3.6 or 13.1.0.6
Bug ID 712924: In VPE SecurID servers list are not being displayed in SecurID authentication dialogue

Recommended Actions

To work around this issue, manually modifying the RSA AAA server in SecurID Auth Agent via tmsh. 

  1. Modify the RSA AAA servers
    # tmsh modify apm policy agent aaa-securid <aaa agent> server <securid server name>
    For Example
    # tmsh modify apm policy agent aaa-securid APM_SecurID_act_securid_ag server SecurID_AAA

    When you look at the RSA SecurID VPE Object, it will still show that the AAA Server is none, but the Policy will work as expected.
     
  2. Verify that the Policy Agent is configured as expected, by listing this on the CLI
    # tmsh list apm policy agent aaa-securid APM_SecurID_act_securid_ag
    apm policy agent aaa-securid APM_SecurID_act_securid_ag {
    server SecurID_AAA
    }
