Description


Audit logs running util bash on a BIG-IP configured with F5-telemetry is generating log messages every minute similar to the following in /var/log/audit:

  • Mar 28 12:26:16 <BIG-IP hostname> notice icrd_child[20416]: 01420002:5: AUDIT - pid=20416 user=admin folder=/Common module=(tmos)# status=[Command OK] cmd_data=run util bash -c "/usr/bin/iostat -x -d | /usr/bin/tail -n +3 | /usr/bin/tr -s ' ' ','"
     
  • Mar 28 12:28:16 <BIG-IP hostname> notice icrd_child[20803]: 01420002:5: AUDIT - pid=20803 user=admin folder=/Common module=(tmos)# status=[Command OK] cmd_data=run util bash -c "/bin/df -P | /usr/bin/tr -s ' ' ','"
     
  • Mar 28 12:26:20 <BIG-IP hostname> notice icrd_child[20416]: 01420002:5: AUDIT - pid=20416 user=admin folder=/Common module=(tmos)# status=[Command OK] cmd_data=run util bash -c "/bin/unbuffer /usr/bin/guishell -c \"select max(config_sync_state) from profile_access_misc_stat;\" | tr '\\n' ' ' | sed -r 's/.*\\|\\s*\\|.*\\|\\s*([^|]*)\\s*\\|.*/apm_state\\n\\1/'"

Environment

  • F5-Telemetry iApp
  • BIG-IP LTM
  • Audit log

Cause
This is normal behavior and the log messages are triggered by the following file: /var/config/rest/iapps/f5-telemetry/lib/paths.json

Recommended Actions

You can filter these BIG-IP log messages by modifying the log message parameter.

 

  1. Log on to the BIG-IP Configuration utility.
  2. Go to System > Logs > Configuration > Log Filters.
  3. Type a name for the log filter.
  4. In the Severity list, select the severity level that matches the error message that you want the system to filter. (Notice level for the previous logs mentioned)
  5. In the Source list, select All.
  6. In the Message ID box enter the 8-hexadecimal-digit message ID that appears in the log message.
    Example:
    Mar 28 12:26:20 <BIG-IP hostname> notice icrd_child[20416]: 01420002:5: AUDIT
     
  7. In the Log Publisher list, select None.
  8. Click Finished.
