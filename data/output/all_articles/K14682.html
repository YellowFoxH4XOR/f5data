Known Issue

When you change the state of a node in the BIG-IP configuration, the state may not update correctly.

This issue occurs when all of the following conditions are met:

  • The version of your BIG-IP system is 11.1.0 HF2 through 11.3.0.
  • You changed the node configuration from user-down to user-up.
  • You modified the configuration using one of the following methods:
    • You locally merged the configuration using the following command:

      tmsh load /sys config [file|from-terminal] merge

    • You deployed an Enterprise Manager changeset against the affected BIG-IP system.

For example, a configuration may originally contain a node with a user-down state, and if you merge the configuration with that of a node with a user-up state, you will be unable to set the node's state, and the node's state remains user-down.

The same issue occurs when you merge the BIG-IP configuration with a deployment of an EM changeset.

Impact

The affected node remains in a user-down state.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The affected node is in a Forced Offline state. (In the Configuration utility, go to Local Traffic > Nodes > Node List > <Affected-Node-Name>)
  • When you type the following tmsh command, the affected node is in a user-down state:

    tmsh list /ltm node <Affected-Node-Name>

Workaround

To work around this issue, you can re-enable the node using the Configuration utility or the Traffic Management Shell (tmsh). To do so, perform one of the following procedures:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Configuration utility

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Local Traffic > Nodes > Node List.
  3. Select the affected node.
  4. In the General Properties section, in the State box, select Enabled.
  5. To save the changes, click Update.

TMSH utility

  1. Log in to the tmsh utility by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.

  2. Re-enable the node state using the following command syntax:

    modify /ltm node <Node-Name> state user-up

    For example, to modify the node 10.10.10.111, type the following command:

    modify /ltm node 10.10.10.111 state user-up

  3. To save the changes, type the following command:

    save /sys config

  4. To exit the tmsh utility, type the following command:

    quit
