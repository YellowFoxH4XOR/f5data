K000147225: How do I clear the Cache for a specific Load-Balanced Record?

Type
Support Solution
Published

Updated
2025-02-20
Applies to

  • F5 Distributed Cloud DNS Load Balancer
Source

Description

I want to know how I can clear the cache for a specific Load Balance record.

Environment

  • F5® Distributed Cloud
  • DNS Load Balancer (LB)

Cause

  • Response cache is enabled on the DNS Load Balancer

Answer/Recommended Actions

To clear the cache for a specific load balanced record:

  1. Navigate to DNS Management > Manage >  DNS Load Balancer Management >  in the record name and click the menu button (...) > Manage Configuration
  2. Click Edit Configuration on the top right corner
  3. Under Response Cache Parameters Choice, select Disable Response Cache from the dropdown

     

  4. Click Save and Exit
  5. Once the changes are applied the Cache is cleared and you can enable it again
  6. Enter Manage Configuration once more and click Edit Configuration
  7. Select Default Response Cache Parameters or customize them with Response Cache Parameters
     
  8. Click Save and Exit
