Description

You notice that some Javascript files are taking much longer to download than expected when accessing an IIS web application fronted by a BIG-IP.

This issue can occur when all of the following conditions are met:

  • The BIG-IP is between the client browser and an IIS-hosted web application.
  • Standard TCP virtual server (VS).
  • Windows 2019 server pool member(s).
  • serverside TCP profile with "delayed-acks" enabled.

Environment

  • BIG-IP
  • IIS
  • Windows Server 2019
  • Delayed ACKs

Cause

Delayed ACKs setting on serverside TCP profile causes performance issues with Windows Server 2019 pool members.

Recommended Actions

Creating a custom TCP profile and applying it to the server-side of the affected virtual server may allow you to correct this behaviour

  1. Navigate to Local Traffic > Profiles > Protocol > TCP.
  2. Create a new TCP profile and give it a name.
  3. Under the Data Transfer section, customise and disable Delayed ACKs.
  4. Save the new profile.
  5. Navigate to the virtual server.
  6. Under Protocol Profile (Server), apply your new TCP profile.
  7. Apply your changes and test the application.
