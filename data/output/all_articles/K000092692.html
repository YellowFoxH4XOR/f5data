K000092692: Can specific fqdn objcts in a security firewall address-list have their own refresh interval?

Description

Can specific FQDN objects in a security firewall address-list have their own refresh interval?

Individual FQDN objects in a security firewall address-list cannot have their own refresh interval.
Refresh interval is currently global for the defined security firewall global-fqdn-policy dns-resolver.

Environment

  • FQDN object in security firewall address-list

Cause

This is by design.

Recommended Actions

Set the desired global refresh interval with command.

tmsh modify security firewall global-fqdn-policy dns-resolver refresh-interval

Additional Information

Global refresh-interval value ranges.

# tmsh -a help security firewall global-fqdn-policy

OPTIONS

app-service

Specifies the application service to which the object belongs. The

default value is none. Note: If the strict-updates option is

enabled on the Application Service that owns the object, you

cannot modify or delete the object. Only the Application Service

can modify or delete the object.

 

description

User defined description.

 

dns-resolver

Specifies an existing net dns-resolver. This will be used by

firewall to obtain FQDN-to-IP Address mappings which will be used

to match firewall rules based on FQDN constraints. Note dns-

resolver none can be used to remove the object from global-fqdn-

policy if and only if there are no AFM rules with (non empty) FQDN

constraints.

 

refresh-interval

Specifies refresh interval to be used to re-resolve FQDN-to-IP

mappings. Unit is in seconds and default is 60 seconds. Minimum

allowed is 5 seconds and maximum is 2,764,800 (=32 days) seconds.
