Known Issue

This is the result of a known issue. If a user accesses the Google Docs website through Portal Access, certain features do not work properly. For example, when a user creates a new Google Doc, the link to the new document is not rewritten. Therefore, the browser accesses the new document directly instead of proxying the request through the FirePass controller.

Note: For information about Google Docs, refer to http://docs.google.com.  This link takes you to a resource outside of AskF5, and it is possible that the information may be removed without our knowledge.

F5 Product Development is tracking this issue as ID 296258 (formerly CR114980).
