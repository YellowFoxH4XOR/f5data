Description

Windows clients who are using the Windows Defender Antivirus software may fail the Antivirus check in the access policy. and depending on how the access policy checks in the VPE are configured, the user will either be denied logon to the APM or taken to the next action in the access policy.

Environment

  • BIG-IP APM with Antivirus check configured in the access policy (regardless if DB Age or Last Scan settings are configured)
  • Windows clients using Windows Defender

Cause

It appears the issue seems to have been caused by the Windows Defender Antivirus Security Intelligence update v1.347.876.0 which was released today.

Recommended Actions

This issue is confirmed fixed in the latest epsec version (epsec-1.0.0-1025.0) which you can download from the F5 Downloads site, so if your BIG-IP APM is not running this latest epsec version, we strongly recommend that you update to it.

To check your currently-installed epsec version, please see K14207: Determining the active OPSWAT version

To update the epsec version installed on your BIG-IP APM, please see K48955220: Installing an OPSWAT Endpoint Security update on BIG-IP APM systems (11.4.x and later) 

IMPORTANT: One of the following versions of BIG-IP are required to install epsec-1.0.0-1025.0:

BIG-IP 16.0.0 or later with APM Clients 7.1.9.9 Update 1(7199.2021.527.907-5235) or later, 7.2.1.3 or later
BIG-IP 15.1.0 or later with APM Clients 7.1.9.9 Update 1(7199.2021.527.907-5235) or later, 7.2.1.3 or later
BIG-IP 14.1.2 or later with APM Clients 7.1.9.9 Update 1(7199.2021.527.907-5235) or later, 7.2.1.3 or later
BIG-IP 13.1.3 or later with APM Clients 7.1.9.9 Update 1(7199.2021.527.907-5235) or later, 7.2.1.3 or later

So you may have to first update your BIG-IP software version and/or APM Clients version to the one listed above, before you can install this epsec binary.

To check your currently-installed APM Clients version, as well as, how to update to the latest version, please see K52547540: Updating BIG-IP Edge Client for the BIG-IP APM system
