Description

F5 resets client connection with cause "Malformed HTTP header error"

Environment

  • A virtual server is associated with an HTTP profile.
  • An iRule or LTM policy that uses HTTP header information is associated with the virtual server.
  • The BIG-IP system receives a specially crafted HTTP request or response
  • Running version 12.1.x, 13.1.x, 15.0.x, 15.1.x, 16.0.x

Cause

BIG-IP has more strict HTTP traffic check to comply with RFC. The behaviour is the result of the fix for IDs 858289, 858297, and 858301 as per  solution article K27551003.

Recommended Actions

Ensure that client request and server response is RFC compliant.

None.
