Description

What do SHA & AES represent in SNMP v3 authentication in WebGUI?

Environment

  • SNMP v3
  • Authentication
  • GUI

Cause

None

Recommended Actions

In WebGUI, System > SNMP > Agent Access (v3) > Record properties > Authentication > Type > SHA 
Note: SHA is equivalent to SHA1

In WebGUI, System > SNMP > Agent Access (v3) > Record properties > Authentication > Privacy > Protocol > AES 
Note: AES is equivalent to AES128

None
