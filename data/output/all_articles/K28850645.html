K28850645: APM Clients may require rundll32.exe to run on client device

Type
Support Solution
Published
2022-01-11
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP APM: 16.0.0, 17.X.X, 16.X.X, 17.5.X, 17.5.0, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.X, 16.1.5, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.X, 16.0.1
Source
https://my.f5.com/manage/s/article/K28850645

Description

Rundll32.exe is used to create a new process which handles the login page on the newer APM Client packages
As such, it is required on every login attempt and not only at installation time.

Environment

  • Big-IP APM Edge Client

Cause

Some client devices may have a local Firewall or Antivirus settings that blocks the rundll32.exe process, which may cause APM Access Policy evaluation to fail.

Recommended Actions

Ensure clients are allowing the rundll32.exe process through local firewall and antivirus settings when running APM Clients.

To do so on the built in Windows firewall, you can refer to the following documentation:

 - Create an Inbound Program or Service Rule
 - Create an Outbound Program or Service Rule

Note: These links take you to a resource outside of MyF5, and the third party could remove the documents without our knowledge

For other 3rd party Antivirus and Firewall software, refer to their documentation on allowing inbound and outbound services

Additional Information

Since there’s no way to directly launch a DLL file without downloading it, the rundll32.exe application is simply used to launch functionality stored in shared .dll files. This executable is a valid part of Windows, and normally shouldn’t be a threat.
