Topic

F5 Networks no longer provides big3d updates specifically for Extreme Alpine switches; however, the SNMP probing should provide you with the functionality that you need to collect UCD and SNMP metrics for Extreme Alpine switches.

Configuring SNMP probing

To do this configure SNMP probing, perform the following steps:

  1. From navigation pane of the 3-DNS Controller Configuration utility, expand the Servers list and select Host.
  2. Select the host you want probed, such as the Extreme Alpine switch.

    Note: If the host you want is not present, you will need to create it. For specific instructions about creating a host, refer to the 3-DNS Administrator Guide.

  3. Click the SNMP Configuration tab at the top of the screen.
  4. Check the box next to SNMP Enabled.
  5. From the Type list, select the appropriate device.
  6. Click Update.

Important: If you have a high volume of traffic (such as 4GB every 30 seconds) and are gathering metrics with an SNMP probe, you may experience roll-over problems when computing bytes, seconds, and so forth. You can work around this issue to some degree by decreasing the polling frequency.

Changing polling frequency

To change the global SNMP polling frequency, perform the following steps:

  1. From navigation pane of the 3-DNS Controller Configuration utility, choose Systems.
  2. Click the Timer and Tasks Intervals tab at the top of the screen.
  3. Change the timer on Host Data Refresh.
  4. Click Update.
