Description

After modifying an iRule, this stops working after some time, even when there are no TCL errors.
A virtual server has an iRule that contains multiple events with the same priority.

Environment

  • BigIP - LTM
  • iRule

Cause

The problem is most likely caused by the fact that the iRule execution order has changed.
 

Recommended Actions

  1. Use iRule 'priority' to ensure the correct execution order.
when <event_name> priority nnn

This issue is related to the Bug ID 1043985: After editing an iRule, the execution order might change.
