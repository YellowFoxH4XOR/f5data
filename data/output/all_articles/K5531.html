Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following article:

  • K13317: Configuring the level of information that syslog-ng sends to log files (11.x - 12.x)

The BIG-IP system uses the standard UNIX logging utility, syslog-ng, to deliver system messages to log files. You can configure the level of information that syslog-ng delivers to log files.

Note: Log messages for events related to Traffic Management Microkernel (TMM) are controlled by the alertd process. For detailed information about configuring the level of information logged for TMM events, refer to K5532: Configuring the level of information logged for TMM-specific events.

Syslog-ng uses facilities and levels to describe system messages. Facilities describe the specific element of the system generating the message. Levels describe the severity of the message.

The following facilities are available on the BIG-IP system. Each facility handles messages for specific elements of the system, as described in the following table:

Levels

The following levels are available for each facility, as described in the following table. The facilities are listed in order of the severity of the messages they handle. Generally, higher levels include all log messages from the lower levels. For example, the alert level will generally also report all messages from the emerg level, and the debug level will generally also report all messages for all levels.

LevelDescriptionVerbosity
emergEmergency system panic messagesMinimum
alertSerious errors that require administrator interventionLow
critCritical errors, including hardware and filesystem failuresLow
errNon-critical, but possibly very important, error messagesLow
warningWarning messages that should at least be logged for reviewMedium
noticeMessages that contain useful information, but may be ignoredMedium
infoMessages that contain useful information, but may be ignoredHigh
debugMessages that are only necessary for troubleshootingMaximum

Displaying the level of information thatsyslog-ng sends to log files

Before you change a specific syslog facility level, you may want to display the current levels. To display the current syslog facility levels, type the following command from the command line:

bigpipe syslog list all

Note: If you are running a BIG-IP version prior to 9.4.2, you can display the syslog facility levels by viewing the contents of the /etc/syslog-ng/syslog-ng.conf file.

Configuring the level of information that syslog-ng sends to log files

To configure the level of information that syslog-ng sends to log files, perform one the following two procedures, depending on which version of the BIG-IP system you are running:

BIG-IP 9.4.2 through 10.x

In BIG-IP 9.4.2 through 10.x, use the bigpipe command to perform custom syslog configurations. For example, the default log level range for the authpriv syslog facility is from notice to emerg. To change the authpriv syslog facility range to from warning to emerg, perform the following procedure:

  1. Log in to the command line.
  2. Use the following command syntax to change the log level range for the authpriv facility:

    bigpipe syslog authpriv from warning authpriv to emerg

  3. Type the following command to save the settings:

    bigpipe save

Note: For more information about configuring syslog settings using the bigpipe command, refer to K8260: Configuring syslog settings from the command line (9.x - 10.x).

BIG-IP 9.0.0 through 9.4.1

You can configure the syslog-ng utility by adding entries to its configuration file, /etc/syslog-ng/syslog-ng.conf.

Important: F5 recommends that you do not change the existing entries contained in the /etc/syslog-ng/syslog-ng.conf file because it already specifies the minimum amount of logging recommended. However, you can increase the level of logging or add additional log files.

Entries that you add to the syslog.conf file are cumulative. You cannot add a line to the file that will reduce the amount of logging from the default configuration. When adding entries to the syslog.conf file, you can use the wildcard character ( * ) in any of the fields. This allows you to choose multiple facilities at a specific level, multiple levels for a specific facility, or to log a message to multiple log files.

To add entries to syslog-ng.conf file, perform the following procedure:

  1. Log in to the command line.
  2. Change directories to the /etc/syslog-ng directory by typing the following command:

    cd /etc/syslog-ng

  3. Create a backup copy of the syslog-ng.conf file by typing the following command:

    cp syslog-ng.conf syslog-ng.conf.original

  4. Using a text editor, edit the syslog-ng.conf file.
  5. Add new entries in the following format to the end of the file:

    # authpriv.* /var/log/secure
    filter f_authpriv {
    facility(auth, authpriv) and level(notice..emerg);
    };
    destination d_secure {
    file("/var/log/secure" create_dirs(yes));
    };
    log {
    source(local);
    filter(f_authpriv);
    destination(d_secure);
    };

  6. Restart the syslog-ng process by typing the following command:

    bigstart restart syslog-ng
