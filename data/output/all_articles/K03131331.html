K03131331: The Upload Package and Install Package buttons for antivirus check EPSEC updates are disabled on standby systems

Issue

Old Behavior

In versions prior to BIG-IP APM 12.1.0, you can upload and install OPSWAT Endpoint Security (EPSEC) ISO updates to either active or standby systems in a high availability (HA) group.

When you navigate to the System > Software Management > Antivirus Check Updates page on an active or standby BIG-IP APM system, the Upload Package and Install Package buttons are enabled. However, performing these actions will trigger a configuration synchronization (ConfigSync). Performing these actions on a standby system may cause the standby system's configuration to unintentionally sync to other members of the device group. 

New Behavior

Beginning in BIG-IP APM 12.1.0, when you navigate to the System > Software Management > Antivirus Check Updates page on a standby BIG-IP APM system, the Upload Package and Install Package buttons are disabled. 

You can no longer perform these actions on a standby system. This behavior change is intended to prevent you from unintentionally syncing a standby system's configuration to the other members of a device group.

F5 Product Development tracked this change as ID 440013.

Impact

You can no longer upload and install an antivirus check updates EPSEC package to a standby BIG-IP APM system using the Configuration utility.

Recommended Actions

You should only upload and install antivirus check EPSEC updates to an active device.
