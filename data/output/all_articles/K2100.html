Known Issue

This is the result of a known issue. BIG-IP server appliances support only 32-bit counters. The maximum value that the 32-bit counters can contain is 4,194,302. When this number is reached, the counter rolls back to zero and begins counting again.

Note: BIG-IP switch appliances use 64-bit counters, so they are not subject to this limitation.

F5 Networks Product Development tracked this issue as CR32179 and CR41913.
