Known Issue

This is the result of a known issue. Modified read and write sizes may not be reflected for a Presentation volume. The nfs-param rsize and nfs-param wsize commands are used to change the NFS read size and write size between the current volume and its back-end shares. However, when these values are changed for a Presentation volume that imports a Managed volume, the ARX system does not request the new read size and write size values from the cached connection to the Managed volume. As a result, the newly-configured read size and write size values are not reflected when NFS clients mount the Presentation volume.

Note: For information about the nfs-param command, refer to the ARX CLI Reference Guide.

F5 Product Development tracked this issue as ID 38997 and it was fixed in ARX 5.2.0. For information about upgrading, refer to the ARX release notes.

Additionally, this issue is fixed in a hotfix available for ARX versions 5.0.6 and 5.1.5. Customers affected by this issue should contact F5 Technical Support, referencing this Solution number and the associated ID number, to request the hotfix.
