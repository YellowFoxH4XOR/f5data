K72885383: Failed authentication to Venafi SDK

Type
Support Solution
Published
2020-04-24
Updated
2025-02-07
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K72885383
Description

The BIG-IQ may fail to connect to a Venafi endpoint if using a certificate that is signed by a Certificate Authority (CA) that is not in Java's CA store.

You may see an error similar to this in /var/log/restjavad.0.log:

[INFO][23 Aug 2019 13:06:01 CDT][ VenafiAuthenticationHelper] Unable to authenticate user BIG_IQ at https://example.com/vedsdk/: java.lang.Exception: Login failed:
 at com.f5.rest.workers.adccore.externalca.venafi.api.VenafiHttpService$12.failed(VenafiHttpService.java:746)

Or in the BIG-IQ UI Configuration > Certificate Management > Third Party CA Management > Create....

  • "Unable to authenticate user <> at https://example.com/vedsdk/"

Environment

  • BIG-IQ Certificate Management
  • Venafi SDK
Cause

BIG-IQ is configured to use a proxy to access the Venafi SDK Endpoint.
The proxy is set to negotiate SSL traffic by signing a certificate.
The certificate is signed by a Certificate Authority not trusted by Java.

Recommended Actions

Gather the certificate authority file from the Venafi SDK site and import it into Java's trusted keystore. 

Impact: These actions should have no negative impacts on your BIG-IQ. The Web UI may be temporarily unavailable for a very short time while restarting restjavad.

  1. From the BIG-IQ command line console, navigate to a bash shell prompt.
  2. Copy the Certificate Authority file for the Venafi SDK into a file on your BIG-IQ:

    openssl s_client -showcerts -connect [venafi sdk endpoint]:443 </dev/null 2>/dev/null|openssl x509 -outform PEM > /var/tmp/venafi_sdk.pem
    Note: Replace [venafi sdk endpoint] with the Venafi endpoint for your account.

  3. Remount /usr partition as read, write (rw)

    mount -o remount,rw /usr

  4. Backup the existing CACert store:

    cd /usr/lib/jvm/java-1.8.0-openjdk-1.8.0.212.b04-0.el6_10.x86_64/bin; cp ../jre/lib/security/cacerts{,.org} ;

  5. Load the certificate to the keystore

    ./keytool -keystore ../jre/lib/security/cacerts -storepass changeit -import -trustcacerts -noprompt -alias my_proxy_CA -file /var/tmp/venafi_sdk.pem

    Note: You will get a return of "Certificate was added to keystore" if all went well.

  6. Remount /usr as read-only and restart restjavad

    mount -o remount,ro /usr ; bigstart restart restjavad

Additional Information

The /usr/lib/jvm/java..../bin is subject to change depending on BIG-IQ software version / latest JDK version.
