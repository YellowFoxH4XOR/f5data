K000158151: WAF Exclusion Policies Not Enforced on CE-Advertised Load Balancers

Type
Support Solution
Published
2025-12-10
Updated
2026-06-12
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud WAF
Source
https://my.f5.com/manage/s/article/K000158151

Description

This article describes an issue where WAF (Web Application Firewall) exclusion policies are not enforced on HTTP load balancers advertised via Customer Edge (CE) nodes in F5 Distributed Cloud. Any requests that should be excluded by a configured WAF exclusion policy continue to be blocked, regardless of which attack signature or criteria are specified. Inline exclusion rules created directly on the load balancer function as expected and provide a temporary workaround.

Environment

  • Product: F5 Distributed Cloud Web App & API Protection (WAF)
  • Feature: WAF Exclusion Policy
  • Deployment:
    • HTTP Load Balancers advertised on Customer Edge (CE) nodes
    • WAF exclusion policies applied at the load balancer level
  • Software Version:
    • Issue present in CE software version crt-20250613-3382 and earlier
    • Feature supported starting with CE software version crt-20250701-0198

Cause

Older versions of CE software (prior to crt-20250701-0198) do not support enforcement of global WAF exclusion policies on load balancers advertised via CE nodes. This is not due to a product defect, but rather because the feature was not implemented until later releases.

Recommended Actions

  1. Upgrade CE Software:
    Update your Customer Edge node(s) to version crt-20250701-0198 or later to enable support for WAF exclusion policies.
  2. Reapply and Test Exclusion Policies:
    After upgrading, reapply your desired WAF exclusion policy and test with previously blocked requests to confirm correct behavior.
  3. Temporary Workaround:
    If you cannot upgrade immediately, use inline exclusion rules directly on each affected load balancer as a temporary solution.

Additional Information

  • The issue does not affect load balancers advertised via Regional Edge (RE) nodes; those enforce WAF exclusion policies as expected.
