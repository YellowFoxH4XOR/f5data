Topic

Prior to BIG-IP versions 4.5.11 and 4.6.3, the default value of the syncookie threshold global variable was 150,000, regardless of platform. In BIG-IP versions 4.5.11 and 4.6.3, the default value was changed to 500,000 for platforms that contain a PVA (Packet Velocity ASIC).

A threshold setting of 150,000 is a reasonable value for all platforms that are not equipped with a PVA and F5 Networks recommends that you do not change this setting without first contacting F5 Technical Support.

For PVA-equipped platforms, such as the 2400, you should increase this setting to 500,000 to ensure that high, but normal, volumes of PVA-accelerated traffic do not trigger syn cookie processing.

To change the syncookie threshold setting to 500,000, type the following command:

bigpipe global syncookie threshold 500000
