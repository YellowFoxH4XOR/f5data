K000092489: BIG-IQ statistics collection stops due to Elasticsearch bookkeeper index error

Type
Support Solution
Published
2022-10-21
Updated
2026-07-29
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.0.X, 8.1.X, 8.1.0, 8.0.0
Source
https://my.f5.com/manage/s/article/K000092489

Description

  • Alert such as "statistics overflow protection detected" is displayed on BIG-IQ DCDs.
  • BIG-IQ statistics collection has stopped working.
  • Log file /var/log/appiq/configserver.log on BIG-IQ CM shows the following error:

WARN c.f.a.c.r.BookkeeperUpdate [scheduling-1] Failed update bookkeeper for time level 'tl0' with first full data of 'java.lang.NullPointerException'

Environment

  • BIG-IQ cluster with statistics collection enabled

Cause

This issue is due to Bug ID 1044337.

Recommended Actions

To attempt to resolve this issue, please run the following steps from bash on the BIG-IQ CM:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

1. Make a backup of the Elasticsearch book-keeper-end index

curl -sk https://localhost:9200/_reindex?pretty -H "content-type: application/json" -d '{"source":{"index":"book-keeper-end"},"dest":{"index":"bu-book-keeper-end"}}'

2. Delete the book-keeper-end index:

curl -skX DELETE https://localhost:9200/book-keeper-end

Note: The book-keeper-end index will be rebuilt automatically. This should not cause any loss of statistics data

3. Monitor the BIG-IQ system for one day to allow it to rebuild statistics from newly ingested data. If the issue persists, please contact F5 Support for further analysis.
