Issue

Old Behavior

In versions prior to BIG-IP GTM 11.0.0, iQuery supports only certificates that are generated using MD5 and SHA-1 hash algorithms.

New Behavior

Beginning in BIG-IP GTM 11.0.0, iQuery supports certificates that are generated using SHA-2 hash algorithm, in addition to MD5 and SHA-1.

Impact

iQuery can support a wider range of certificates by including the hashing functions of SHA-2.

Recommended Actions

None
