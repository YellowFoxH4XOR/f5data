Description

You are observing a high number of HTML transactions and resource transactions since the implementation of JavaScript verification on your BIG-IP ASM system. This document will help you understand the difference between HTML transactions and resource transactions, especially in the context of browser verification processes used in bot defense.

Environment

  • BIG-IP ASM
  • Security ›› Bot Defense ›› Create New Bot Profile ›› Add Exception ›› MALICIOUS BOT ›› BROWSER MASQUERADING

Cause

The primary cause for the high numbers of HTML or resource transactions detected by your ASM Bot Defense is likely automated processes. These processes are generating an abnormal amount of requests, which is inconsistent with typical human browsing patterns and thus flagged by verification systems to prevent misuse or security threats.

Recommended Actions

For HTML Transactions:

  • Review the bot detection logs to identify and analyze the patterns of traffic that may be indicative of automated processes.
  • Adjust the thresholds for HTML transaction detection based on the expected user behavior for your specific web application or site.
  • Implement additional verification methods, such as CAPTCHA, to better distinguish between human and automated traffic.

For Resource Transactions:

  • Investigate the types of resource transactions that are occurring in high volumes to ascertain if a particular type of resource is being excessively requested.
  • Modify your bot defense profile to accurately reflect the behavior of legitimate bots, adding exceptions if necessary.
  • Consider applying rate limiting measures to control the frequency of resource requests from a single source within a certain timeframe.
