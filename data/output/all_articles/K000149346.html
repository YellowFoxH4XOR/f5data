Description

When running platform check by K15442 in new arrival i5k device, or checking the /var/log/platform_check.log, you may notice the failure with the below error:

Incorrect PCI device '102b:0522' at PCI address 0a:00.0; expected '14e4:b041'.

In this log, notice the below details:

  • The 102b:0522 is the actual device identifier on PCI
  • The 0a:00.0 is the PCI address
  • The 14e4:b041 is the platform check built-in value

When you observe this error message, the EUD test could pass with no FAILs.

Environment

  • New arrival i5k devices
  • Platform check fail with PCI failure

Cause

This is due to a hardware change that changed the PCI and device mapping, this is internally tracked as ID1102957.

Recommended Actions

This should be cosmetic and give no impact. You may alternatives using EUD to further confirm the hardware health by following K7172: Overview of the End User Diagnostics software or K93403310: Running EUD from a USB thumb drive.
