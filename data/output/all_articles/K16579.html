Known Issue

The report export utility may not function.

This issue occurs when the following condition is met:

  • You attempt to export the BIG-IP ASM report for a specific security policy, from the BIG-IP ASM Configuration utility, by accessing the Security > Overview > Application > Traffic page.

Impact

Attempts to export reports fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to export the report, the system displays an error message similar to the following example:

    The page at https://<asm host name or IP address>
    Could not generate report. Undefined entity asm_security_policy was used

    OK
  • When you select a global Security Policy setting (such as per-widget), the report export is successful.

Workaround

To work around this issue, you can modify the default (per-widget) report to obtain an exportable report of the same data. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Overview > Application > Traffic.
  3. Ensure that the Security Policy menu is set to the default setting (per-widget).
  4. Edit the top report widget properties by locating the cog icon in the upper-right corner of the widget box and then clicking Settings.
  5. Click Add filter.
  6. From the Where menu, select Security Policy.
  7. In the contains text box, enter the name of the security policy you want to run the report for.
  8. Click Done.
  9. Click Export.
