K000137594: BIG-IQ - Statistics overflow protection detected

Published
2023-11-15

Applies to

  • BIG-IQ Centralized Management: 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0
Source
https://my.f5.com/manage/s/article/K000137594

Description

The monitoring graphs and analytics are displaying a "server error" message. BIG-IQ DCD cluster status is restarting, accompanied by the message "Statistics overflow protection detected."

Environment

  • BIG-IQ

Cause

Problem with the communication between devices.


Recommended Actions

The root cause of the problem may be asymmetric routing on a network switch.

This was leading to network firewall blockage between DCDs.

Additional Information

None
