Description

When devices in a BIG-IP device group do not have the same modules provisioned, you may find the following messages logged in /var/log/ltm on one or more devices.

01260013:4: SSL Handshake failed for TCP <bigip1_configsync_ip>:4353 -> <bigip2_configsync_ip>:<random_port>
01260009:4: (null connflow): Connection error: ssl_basic_crypto_cb:694: alert(20) Decryption error

Environment

  • BIG-IP HA ConfigSync
  • Devices have different provisioning
    For example, one device has LTM and ASM provisioned and the other has only LTM provisioned.

Cause

Device group members must have the same product licensing and module provisioning. For more information, refer to K13946: Troubleshooting ConfigSync and device service clustering issues.

Recommended Actions

Ensure that all devices in the device group have the same licensing and module provisioning.

Additional Information

None
