The port denials logging levels are defined with the following values:
ValueDescription
0Disables port denial logging.
1Enables UDP port denial logging and logs UDP port denials to the BIG-IP address.
2Enables TCP port denial logging and logs TCP denials to the BIG-IP address.
4Enables virtual UDP port denial logging and logs UDP denials to the VIP addresses.
8Enables virtual TCP port denial logging and logs TCP denials to the VIP addresses.
15Enables levels 0, 1, 2, 4, and 8 logging and logs UDP and TCP denials to the BIG-IP and VIP addresses.

To change the logging level, perform the following steps:

  1. From the Configuration utility, click the Advanced Properties tab.
  2. Type the desired value in the box next to verbose_log_level.
  3. Click Apply.
