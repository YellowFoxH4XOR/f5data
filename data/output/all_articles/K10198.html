Issue

In versions prior to BIG-IP 10.0.0, access to the Configuration utility was not affected if the client's source IP address changed during a session, for example when accessing the Configuration utility through a proxy device.

Beginning in BIG-IP 10.0.0, security measures have been built that cause a client to lose access to the device in the event the client's source address changes while using the Configuration utility. This security measure is to prevent a user from impersonating or hijacking another user's connection to the Configuration utility. If the client's source IP address changes during the course of a session, the user is logged out of the system. This applies to users that access the Configuration utility using a web browser or iControl applications that are used to login from remote systems.

Note: If your client web browser connects to the BIG-IP Configuration utility through a proxy device, and the client's source IP address changes during the session, you may be able to set a do not proxy option in the browser and prevent Configuration utility requests from using the proxy device. For more information, refer to K13048: Error Message: httpd[6902]: [error] <client_ip> AUTHCACHE Error processing cookie <hash> - Cookie impersonation detected from remote IP.
