Description

When the BIG-IP configuration is unable to load on MS Azure, you are unable to SSH to the BIG-IP VM and login fails via the serial console. You may observe a message in the /var/log/ltm file, or serial console logs similar to the following:

"/usr/bin/tmsh -n -g -a load sys config partitions all base " - failed. 

The config failed to load error can arise due to different reasons. For more information, refer to K02091043: Error Message: The configuration has not yet loaded. If this message persists, it may indicate a configuration problem.

Environment

  • BIG-IP VE on Microsoft Azure

Cause

When the system fails to load its configuration, this may break outbound connectivity in instances such as a 1-nic deployment. The lack of outbound internet connectivity breaks DNS resolution and creates issues for the Azure Linux agent, including but not limited to provisioning.

BIG-IP VE uses the Microsoft Azure Linux Agent (waagent) to manage Linux and to interact with the Azure Fabric Controller.

Recommended Actions

  1. When the BIG-IP system configuration does not load, only root or admin users may log in. Log in with root or admin accounts via the serial console.

    Note: Since the user admin is not used by default by the ARM templates, this (set a password for the admin user) must be performed manually after initial deployment.

  2. You should also take regular UCS archive and Azure snapshots of your BIG-IP VM in case there is a need to restore the system to an earlier working state.
