Known Issue

When performing Domain Name System Security Extensions (DNSSEC) signing, Traffic Management Microkernel (TMM) may experience a memory leak and eventually restart, and the hardware security module (HSM) fails.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP GTM provisioned.
  • You have configured the BIG-IP GTM system to sign DNS responses using DNSSEC.
  • The DNSSEC signing keys are protected by an HSM.

Impact

TMM may restart and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to process traffic for a brief period of time.
  • The BIG-IP system fails over to another host in the device group.
  • TMM generates a core file in the /var/core directory.
  • In the /var/log/ltm file, you may observe an error message similar to the following example:

    crit tmm2[23456]: 01260010:2: FIPS acceleration device failure: fips_poll: req: 371 status: 0x40000116 : ERR_HSM_ERROR
