K000135147: Error message 01070281:3: Invalid "http response chunking" value for profile XXX. Invalid entry, check allowed values

Type
Support Solution
Published
2023-06-21
Updated
2023-06-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000135147

Description

  • After upgrading to BIG-IP 17.1.x, the config may fail to load, resulting in the device remaining in an Offline state.
  • The /var/log/ltm file contains messages regarding "Full configuration load failed.".
  • "tmsh load /sys config verify" command or "tmsh load /sys config" command returns an error message referencing either response-chunking or request-chunking setting being invalid in an http profile and the /var/log/ltm file also contains the error message.

      E.g.

      01070281:3: Invalid "http response chunking" value for profile /Common/test_http_profile. Invalid entry, check allowed values.

Environment

  • Upgrade from a version prior to 15.0.0 to 17.1.x.

Cause

ID 1185169

Recommended Actions

  1. Log in to CLI.
  2. Edit /config/bigip.conf (and any partition bigip.conf files under /config/partitions/*/) to change the #TMSH-VERSION: line at the very top of the file from 17.1.x.x to the version of BIG-IP software that the device was previous running.
  3. Then issue the the following command:
           tmsh load sys config
