K000148302: [F5OS-C] Unable to upgrade System Controller software, receiving error with "Server Error(s): An internal error occurred. Please try again later...".

Description

When trying to upgrade VELOS System Controller, it's failed with the following error message.

Server Error(s)
An internal error occurred, Please try again later. If the problem persists, please contact technical support for assistance.

When you check VELOS velos.log (/var/log_controller/velos.log), you can see the following error messages.

2024-10-29T04:41:08.276681+00:00 controller-2 upgrade-service[13]: priority="Err" version=1.0 msgid=0x1c01000000000008 msg="Confd Operation failed" OP="Redundancy mode not preferred-auto, rolling upgrade not allowed" ERR=0.
2024-10-29T04:41:08.282901+00:00 controller-2 upgrade-service[13]: priority="Info" version=1.0 msgid=0x1c01000000000006 msg="Operation failed" OUTPUT="Redundancy mode not preferred-auto, rolling upgrade not allowed".

Environment

  • F5OS-C (VELOS)
  • System Controller software upgrade
  • The noticeable version is upgrading from v1.5.1 to v1.6.2

Cause

The main controller is fixed to only 1 controller, so the upgrade is blocked.

# show system redundancy
system redundancy state mode prefer-2 --> This one means only prefer Controller-2 as an Active controller.
system redundancy state current-active controller-2
NAME     NAME 
--------------------
controller-1 -   
controller-2 - 

Recommended Actions

  1. Set the High Availability Configuration> Preferred Node to Auto. (SYSTEM SETTINGS > Controller Management >High Availability Configuration >Preferred Node > Auto)

Additional Information

None.
