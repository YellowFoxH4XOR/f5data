F5 released the iOS BIG-IP Edge Portal application for the Apple iPhone, iPad, and iPod touch. The iOS BIG-IP Edge Portal application for iOS devices streamlines access to web applications that reside behind the BIG-IP APM and FirePass devices.

The iOS BIG-IP Edge Portal application features include:

  • Username/password authentication
  • Passcode lock enforced on the device
  • Client certificate support
  • Saving credentials and sessions
  • Saving local bookmarks and favorites
  • Accessing bookmarks with keywords
  • An iframeded web view
  • Ability to display all file types that native Mobile Safari supports

This application is a lightweight client for iOS access to the BIG-IP APM system and FirePass controller, and the application supports only the web application access.
