Description

  • Intermittent connection issues on SFTP virtual server
  • Client receive an error similar to:

    Connecting to sftp.example.com...
    ssh_exchange_identification: Connection closed by remote host
    Couldn't read packet: Error 0

Environment

  • LTM
  • SFTP virtual server
  • SFTP pool members
  • No persistence profile assigned

Cause

The SFTP virtual server doesn't have a persistence profile assigned for the load balanced connections.

Recommended Actions

Please use the recommended configuration described  on K24595255 to properly  load balance connection requests to SSH File Transfer Protocol (SFTP) servers.
