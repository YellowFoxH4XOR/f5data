K12191721: nmap ssl-enum-ciphers script scans a cipher ''TLS_ECDHE_RSA_WITH_3DES_EDE_CBC_SHA'' that F5 configuration utility does not use

Source
https://my.f5.com/manage/s/article/K12191721
Description

You may see the following ciphers in the output of nmap -sV --script ssl-enum-ciphers -p 443 <BIG-IP's management IP>

       TLS_ECDHE_RSA_WITH_3DES_EDE_CBC_SHA (secp256r1) - C
       TLS_RSA_WITH_3DES_EDE_CBC_SHA (rsa 2048) - C

You do not see these ciphers are included from the list of supported ciphers for the configuration utility.
tmsh list /sys httpd ssl-ciphersuitsys
httpd {
    ssl-ciphersuite ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES128-SHA:ECDHE-RSA-AES256-SHA:ECDHE-RSA-AES128-SHA256:ECDHE-RSA-AES256-SHA384:ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES128-SHA:ECDHE-ECDSA-AES256-SHA:ECDHE-ECDSA-AES128-SHA256:ECDHE-ECDSA-AES256-SHA384:AES128-GCM-SHA256:AES256-GCM-SHA384:AES128-SHA:AES256-SHA:AES128-SHA256:AES256-SHA256:ECDHE-RSA-DES-CBC3-SHA:ECDHE-ECDSA-DES-CBC3-SHA:DES-CBC3-SHA
}

Environment

  • BIG-IP v12 and v13
  • nmap scans the Configuration utility
Cause

Unknown at the time of publication

Recommended Actions

Remove the DES-based ciphers:

tmsh modify sys httpd ssl-ciphersuite ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES128-SHA:ECDHE-RSA-AES256-SHA:ECDHE-RSA-AES128-SHA256:ECDHE-RSA-AES256-SHA384:ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES128-SHA:ECDHE-ECDSA-AES256-SHA:ECDHE-ECDSA-AES128-SHA256:ECDHE-ECDSA-AES256-SHA384:AES128-GCM-SHA256:AES256-GCM-SHA384:AES128-SHA:AES256-SHA:AES128-SHA256:AES256-SHA256
