Known Issue

Description

Provisioning the APM Limited license sets the concurrent access session limit to zero. As a result, the BIG-IP APM system will be provisioned and you will be able to configure BIG-IP APM access policies, but users will not be able to log in to the BIG-IP APM system.

This issue occurs when the following condition is met:

  • APM Limited is provisioned on the BIG-IP system.
Impact

Users cannot access BIG-IP APM on the BIG-IP system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Users receive the following message:

    The maximum number of concurrent user sessions has been reached. No new user sessions can start at this time.
  • The following text may be missing on the BIG-IP license screen:

    ADD ACCESS POLICY MANAGER MODULE LIMITED
  • The BIG-IP system logs the following information in the /var/log/apm file:

    tmm[<pid>]: 01490510:5: 00000000: Initializing Access with max global concurrent access session limit: 0
    tmm[<pid>]: 01490523:5: 00000000: Initializing Access with max global concurrent connectivity session limit: 0

    In this information, note the following:
    • <pid> is the process ID.
