Known Issue

The BIG-IP system may incorrectly report down IPsec tunnels as up.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP system as an IPsec tunnel endpoint.
  • An IPSec tunnel has timed out and transitions to a down state.
  • You use the Traffic Management Shell (tmsh) or the Configuration utility to view the IPsec tunnel status.

Impact

The status of the down IPSec tunnel is incorrectly reported as up.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you use one of the following methods, the BIG-IP system shows the status for an IPSec tunnel that has timed out, as up, and the remote tunnel endpoint shows the status for the IPSec tunnel as down:
    • When you use the tmsh command show net ipsec traffic-selector
    • When you use the Configuration utility to navigate to: Network > IPsec > IPsec Diagnostics
