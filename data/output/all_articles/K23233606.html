K23233606: Device Discovery error with Invalid route domain error message

Description

BIG-IQ device discovery fails with Invalid route domain error, similar to the following:

Failed to copy configuration to working-config; reason: Failed copying from source to target: java.lang.IllegalArgumentException: Invalid name: 10.1.1.1%1:12345. Invalid route domain (1:12345)

Note: This error message will appear as a banner from the BIG-IQ WebUI during the import process attempt.

Environment

  • BIG-IQ device configuration import for BIG-IP
  • BIG-IP objects defined within route domains

Cause
Possible orphaned configuration object wherein the specified route domain no longer exists.

Recommended Actions

Remove the orphaned objects from the BIG-IP configuration and re-discover and re-import the configuration.

None
