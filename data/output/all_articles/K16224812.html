Description

When an APM Access Policy is configured with non-default value for Maximum Session Timeout, the rendered value of maximum remaining session's time can flip/flop in seconds on a user's webtop.
 

Environment

  • BIG-IP APM
  • v12.x-v16.x
  • Access Profile 

Cause

Bug ID 944093: This page's Known Affected Versions is not updated properly.
This issue affect v12.x - v16.x, as it is not yet fixed.
 

Recommended Actions

Change the parameter Maximum Session Timeout to default: 604800 seconds.
