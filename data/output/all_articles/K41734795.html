Known Issue

Wildcard wide IPs do not function correctly after you reload the configuration file.

This issue occurs when the following condition is met:

  • You run the following TMOS Shell (tmsh) command from the command line:

    tmsh load sys conf gtm-only

Impact

Wildcard wide IPs are not returning wildcard requests correctly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The wildcard wide IP tops functioning as a wildcard wide IP, and begins to function as a regular wide IP.
  • You may see NXDOMAIN responses for wildcard wide IPs.

Workaround

To work around this issue, you can restore the wildcard wide IP schema. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure will affect traffic; F5 highly recommends that you perform this procedure during a maintenance window.

  1. Log in to the command line.
  2. To touch the Master Control Program Daemon (MCPD) forceload script, type the following command:

    touch /service/mcpd/forceload

  3. To reload and sync the wide IP schemas, type the following command:

    bigstart restart mcpd
