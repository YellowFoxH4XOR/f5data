Known Issue

The Configuration utility does not display the IPsec Traffic Selectors page.

This issue occurs when the following condition is met:

  • You create an IPsec Traffic Selector with the protocol type set to Other.

Impact

You cannot modify or add IPsec traffic selectors using the Network > IPsec > Traffic Selectors page in the Configuration utility.

Note: Although the Network > IPsec > Traffic Selectors page in the Configuration utility is inaccessible, you can use the tmsh utility to modify or add IPsec traffic selectors with an ip-protocol type other than the defaults. (For example, defaults are All(255), TCP(6), UDP(17), or ICMP(1).)

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • After adding an IPsec traffic selector with the protocol type set to Other, the Network > IPsec > Traffic Selectors page is not accessible in the Configuration utility.
  • A message similar to the following example is displayed when you navigate to the Network > IPsec > Traffic Selectors page:

    An error has occurred while trying to process your request.

Workaround

To work around this issue, you can use the tmsh utility to modify or add IPsec traffic selectors that are configured with an ip-protocol type other than the defaults. (For example, defaults are All(255), TCP(6), UDP(17), or ICMP(1).)

Impact of workaround: You will not be able to access the Network > IPsec >Traffic Selectors page in the Configuration utility.

Note: If you want to access the Network > IPsec > Traffic Selectors page in the Configuration utility, you can remove the offending IPsec Traffic Selector by running the following tmsh command:

tmsh delete net ipsec traffic-selector <IPsec Traffic Selector name>
