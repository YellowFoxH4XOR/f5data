K12061: Logon names that contain a backslash character will log with the full name

Published

Issue

Beginning on FirePass 6.0.3, user names that contain a backslash ( \ ) character will be logged with the full user name rather than just the data after the backslash.

For example, a user logs on with an account that includes the following backslash:

example\joe.smith

The %username% variable will be logged as follows:

  • For FirePass versions prior to 6.0.3:

    joe.smith
  • For FirePass 6.0.3 and later:

    example\joe.smith

Important: This change will not affect users in groups that use either Active Directory or NTLM authentication methods. For these users, the domain name will still be stripped off the user name before it is logged. This distinction is important to make if the %username% variable is used anywhere other than authentication. For example, some environments may use the %username% as a variable in a pre-logon sequence.
