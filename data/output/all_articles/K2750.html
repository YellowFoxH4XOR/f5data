K2750: Reasons why BIG-IP or 3-DNS creates a dead.letter file in the /var/log directory when sendmail is enabled

Topic

By default, the root user is not able to receive mail. If you enable sendmail and do not define an alias in the /etc/aliases file to send root user mail to, any mail sent to the root will fail and will be appended to /var/log/dead.letter.

To resolve this issue, you must edit the /etc/aliases file and define an account where root mail should be sent. You can define a valid external email address, or, if you want mail to the root user to be automatically discarded, you can define /dev/null.

To configure this, perform the following tasks:

  1. Using a text editor, such as vi or pico, open the /etc/aliases file.
  2. Look for a line that begins with root:.

    Note: If you cannot find a line that begins with root:, create it.

  3. If you want email sent to the root account to go to an external email account, edit this line using the following syntax example:root: my_mail@mydomain.com

    If you want mail to the root account to be discarded, edit the line as follows:

    root: /dev/null

  4. Save the file.
  5. Type the following command to initiate the change:

    newaliases
