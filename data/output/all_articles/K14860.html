Known Issue

When you use the Traffic Management Shell (tmsh) to remove a local traffic policy from a virtual server, the system fails to remove the associated websecurity profile.

This issue occurs when all of the following conditions are met:

  • You configure a local traffic policy to control the BIG-IP ASM system.
  • The policy contains a rule that references a BIG-IP ASM security policy.
  • You use the tmsh utility to remove the policy from a virtual server.

BIG-IP local traffic policies allow you to define rules for how a virtual server handles traffic, such as enabling the BIG-IP ASM system. When you assign a policy to a virtual server, the system automatically assigns a websecurity profile. When you use the tmsh utility to remove the local traffic policy, the system does not remove the associated websecurity profile, and the profile remains in the virtual server configuration. As a result, using the Configuration utility to assign a local traffic policy that controls the BIG-IP ASM system to the virtual server causes the configuration to fail with a validation error.

Impact

You cannot use the Configuration utility to add a BIG-IP ASM-controlling local traffic policy to a virtual server.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Attempts to configure a virtual server with a local traffic policy that references a security policy fail when you use the Configuration utility.
  • A validation error similar to the following example appears in the Configuration utility:

    The requested virtual server profile (/Common/example_virtual /Common/websecurity) already exists in partition Common.

Workaround

To work around this issue, you can use the Configuration utility to manage local traffic policies for virtual servers, or use the tmsh utility to remove the associated websecurity profile from the virtual server. To use the tmsh utility to remove a websecurity profile from a virtual server, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Remove the websecurity profile by using the following syntax:

    modify ltm virtual <name of virtual server> profiles delete {<name of websecurity profile>}

    For example, to remove the policy example_websecurityprofile from the virtual server example_virtual, type the following command:

    modify ltm virtual example_virtual profiles delete { example_websecurityprofile }
