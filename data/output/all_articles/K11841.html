Known Issue

This is the result of a known issue. When the BIG-IP ASM processes an HTTP request that does not specify the HTTP version, the BIG-IP ASM bd process logs the request to the PROXY_LOG and sends the Learning Manager a message indicating that the request contains a bad HTTP version.

Note: The HTTP RFC specifies that if the version field is not included in the request, the recipient should assume the message is in the HTTP/0.9 format.

F5 Product Development tracked this issue as ID 225808 (formerly CR140219) and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP ASM release note.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3402.0-HF2 issued for BIG-IP 10.1.0, and in Hotfix-BIGIP-10.2.0-1755.1-HF1 issued for BIG-IP 10.2.0. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.
