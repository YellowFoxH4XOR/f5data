K70393130: tokumx daemon can be disabled after successful upgrade to 7.1

Type
Support Solution
Published
2021-05-06
Updated
2026-01-09
Status
Legacy Content
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.1.X, 7.1.0
Source
https://my.f5.com/manage/s/article/K70393130

Description
The toku database has been replaced by postgres in 7.1. When upgrading to 7.0 the toku database is migrated to postgres as one of the actions on the initial boot into 7.1. Afterwards the tokumx daemon is no longer needed.

Environment

  • BIG-IQ
  • Upgrade to 7.1 from an earlier version

Cause
toku database was deprecated in favor of postgres.

Recommended Actions
No action is required.

Additional Information
If desired, the tokumx service can be disabled after confirming upgrade to 7.1 has been completely successful.
