Topic

You should consider using this procedure under all of  the following conditions:

  • You want to troubleshoot issues on the BIG-IP APM system.
  • You want to enable APM debug logging in the /var/log/apm file.

Description

To obtain more information about BIG-IP APM issues on your system, you can enable APM debug logging, attempt to reproduce a problem, and then view the logs. 

Important: F5 does performance and sizing tests with logging set at default levels. While our products offer more verbose logging at debug level for troubleshooting purposes, we do not recommend using debug logging in production scenarios because the additional load incurred may cause instability. If debug logging is required for your deployment, the system capacity may be greatly reduced.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the Configuration utility.
  • You have access to the Advanced Shell (bash).

Procedures

Enabling APM debug logging

Impact of procedure: Enabling APM debug logging may cause excessive logging in a system with a large number of user logins. You should only enable debug logging when troubleshooting and disable debug logging after you've finished troubleshooting. 

  1. Log into the Configuration utility.
  2. For BIG-IP 13.x and later, navigate to Access > Overview > Event Logs > Settings.

    Note: For BIG-IP 12.x, navigate to Access Policy > Event logs > Log Settings.

  3. Click Create.
  4. Type a name for Name and select the Enable Access System Logs check box.
  5. Click Access System Logs.
  6. For Access Policy, click Debug.
  7. Click Access Profiles.
  8. In the Available list, click the appropriate access profile and move it to the Selected list.
  9. Click OK.

Procedure back out

To revert the changes to the access profile logging, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access > Overview > Event Logs > Settings.
  3. Select the check box for the newly created log settings.
  4. Click Edit.
  5. select Access Profiles
  6. Remove the applied access profile and click OK

F5 recommends keeping this logging profile around in case you need to debug more.  F5 also recommends that you turn off debug logging when not actively debugging.
