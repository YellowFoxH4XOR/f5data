Known Issue

The BIG-IP system may incorrectly log Inet port exhaustion messages at the critical log level.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is provisioned with the Carrier Grade NAT (CGNAT) module.
  • A virtual server is configured with a Large Scale NAT (LSN) pool.
  • Port exhaustion occurs on the affected virtual server.

Critical log level messages are typically used for errors that result in hardware and file system failures. An Inet port exhaustion message is a warning that a connection might have failed to find a port when performing NAT functions. The warning does not result in system failures and should not be logged at the critical log level.

Impact

You can safely ignore this issue, however, it may confuse users.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H553327 on the Diagnostics > Identified > Low screen.
  • You observed that the BIG-IP system logs Inet port exhaustion messages as crit, similar to the following example:

    crit tmm1[42120]: 01010201:2: Inet port exhaustion on 192.168.2.181 to 192.168.208.246:53 (proto 17)
