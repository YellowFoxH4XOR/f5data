Description

I need to know what HTTP methods are allowed by default in XC on a load balancer.

Environment

  • F5 Distributed Cloud (XC)

Cause

 

Answer/Recommended Actions

  • All HTTP methods are allowed by default (GET, HEAD, POST, PUT, DELETE, CONNECT, OPTIONS, TRACE, PATCH, COPY).

Additional Information

  • A service policy with a custom rule can be used to allow/block only specified HTTP methods.
