Description

Qualys vulnerability scanner has reported the following issue on BIG-IP:

QID: 105145
Title: Promiscuous Mode Interface(s) Found
Threat: A network interface when set in promiscuous mode allows user space applications to capture packets destined for other machines on the shared medium network.
Impact: Malicious users can snoop legitimate clear text sessions on the network.
Solution: Manually set the interface/device to unpromiscuous mode unless it's necessary and authorized.

Environment

  • BIG-IP
  • Qualys vulnerability scan
  • Promiscuous Mode Interface(s) Found

Cause

BIG-IP has interfaces shown as being in "promiscuous mode" at the Linux OS level. However, Linux is merely the foundation that TMOS rests upon, so "promiscuous mode" in this case just allows TMOS greater flexibility in exerting its own control over these interfaces.

Running a system scanner against the BIG-IP will detect promiscuous mode because scanners that can be run _on_ the system are designed to deal with general purpose Linux systems, where promiscuous mode is indeed something to be mindful of.  However, the BIG-IP has a separate networking subsystem called TMM (the Traffic Management Microkernel) that is handling traffic on these interfaces, and because it will respond for any one of up to several thousand MAC addresses (and also MAC Masquerade) it will need to be able to receive all of this traffic.  Since it is already receiving and processing this traffic, the potential sniffing issues associated with "promiscuous mode" are not a risk.

Recommended Actions

None. BIG-IP is functioning as designed.
