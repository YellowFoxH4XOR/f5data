K000151805: Voice call quality issue while using F5 VPN on Windows 11 23H2 Clients

Type
Support Solution
Published
2025-07-03
Updated
2025-07-03
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000151805

Description

You are experiencing voice call quality issues when using the F5 VPN (BIG-IP APM) after migrating to a Windows 11 Edition platform.

The issue is not observed on Windows 10 with F5 VPN

It is also not observed on Windows 11 with other VPN solutions like Cisco.

 

Environment

Product: BIG-IP APM

Version: 17.1.2

Client OS: Windows 11 23H2

 

Cause

While connected to the VPN, it is observed that F5VPNplugin.exe process is going in 'Suspended' status intermittently during the duration of the Voice call.

 

Recommended Actions

Microsoft Resolution:

1) Issue is not seen on versions later than Windows 11 23H2.

2) For Windows 11 23H2 clients, Microsoft provided a registry key workaround specific to Windows 11 23H2, after which the voice quality issue was resolved.
