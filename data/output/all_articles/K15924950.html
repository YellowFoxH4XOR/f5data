K15924950: OAuth JWT ''Refresh token'' is not readable

Type
Support Solution
Published
2021-03-31
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.1
Source
https://my.f5.com/manage/s/article/K15924950

Description
You might see following error when your BIG-IP APM is configured with the Oauth2 as AS—protecting enterprise resources:

Error example from /var/log/apm:
err apmd[13493]: 01490290:3: /example/App_OAuth2_client_RS_profile:example:7fec06ca:/example/App_OAuth2_client_RS_profile_act_oauth_scope_ag: OAuth Scope: failed for jwt-provider-list '/example/OAuth2_JWT_provider' , error: Invalid JWS token 

Environment

  • Oauth2 as Authorization Server (AS)—protecting enterprise resources  (K42333110)
  • JSON Web Token: (JWT )
  • BIG-IP APM

Cause

Above example shows that JWS token is not supported by third party service
Refresh tokens are used to get a new access token from the authorization server.
They are intended for the authorization server and do not include any information for the client.

Recommended Actions

Change token to the one that is supported by third party

For example:  Azure and F5 uses opaque tokens
About opaque tokens: Using APM as an OAuth 2.0 Authorization Server
