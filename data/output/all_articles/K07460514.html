Description

When a Protocol Inspection Profile that is configured for checking HTTP traffic (Service HTTP) is attached to a firewall rule handling HTTPS traffic then this traffic is dropped. 

This is expected behaviour.


Environment

  • Protocol Inspection Profile applied to an AFM policy.
  • Encrypted traffic (HTTPS).

 

Cause

Protocol Inspection engine cannot inspect encrypted traffic.

When a Protocol Inspection Profile is applied to traffic through a firewall policy the inspection is done before the traffic is decrypted, this means that AFM is trying to run compliance and signature checks against traffic that it cannot understand. In order to parse HTTPS traffic the Protocol Inspection engine requires this traffic to be previously decrypted.

 

Recommended Actions

To use Protocol Inspection with HTTPS traffic you need to attach the Protocol Inspection Profile directly to the Virtual Server instead of attaching it to a firewall rule.
