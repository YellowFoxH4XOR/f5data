Known Issue

This is the result of a known issue. If Microsoft PowerPoint is open on the client system when a user enters Protected Workspace, the user cannot open PowerPoint in Protected Workspace. This issue does not occur with other Microsoft Office programs, such as Word or Excel.

F5 Networks Product Development is tracking this issue as CR115755.
 
Workaround
 
Users can work around this issue by closing Microsoft PowerPoint before entering Protected Workspace.
