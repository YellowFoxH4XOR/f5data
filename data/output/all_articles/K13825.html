Known Issue

The gtm_add script fails to connect to remote BIG-IP GTM systems that are licensed for Appliance mode.

This issue occurs when the following condition is met:

  • You run the gtm_add script on a BIG-IP GTM system and specify a remote BIG-IP GTM system that is licensed for Appliance mode.

The gtm_add script is an interactive script that logs into the bash shell of a remote BIG-IP GTM system and exchanges SSL device certificates between the systems. The script can be used to integrate a new BIG-IP GTM system into an existing synchronization group that has one or more remote BIG-IP GTM systems. This issue occurs because the bash shell is disabled for systems licensed for Appliance mode.

Impact

The affected BIG-IP GTM system is unable to join the synchronization group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The affected BIG-IP GTM system is unable to join the synchronization group.
  • The gtm_add script fails to connect to the remote BIG-IP GTM system that is licensed for Appliance mode.
  • The gtm_add script generates output that appears similar to the following example:
