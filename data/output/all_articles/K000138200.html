Description

This article details the process of deleting APMclients images that are no longer needed. This process helps to free up disk space on the system. The BIG-IP system also includes APMclients images in the user configuration set (UCS) archives, so deleting APMclients images will reduce the size of UCS files as well.


Environment

Relevant environmental factors:

  • BIG-IP APM Module is in Provisioned state

Cause

As BIG-IP with the APM Module Provisioned are Upgraded, their APMclients package version is also automatically Upgrade to the version native to the BIG-IP version. As a result, older unused and unnecessary APMclients packages need to be deleted using the proper WebUI or TMOS/CLI, in order to maintain proper disk space usage in the "/config" partition/directory.


Recommended Actions

Using the Configuration utility to remove an APMclients package

Impact of procedure: Performing this procedure should not have a negative impact on the system.

  1. Log in to the Configuration utility of the active device.
  2. Go to System > Software Management > APM Clients.
  3. Select the APMclients package you want to delete from the system.
  4. Note: You cannot delete the default APMclients file included with the BIG-IP APM system. The APMclients file is labeled Yes under the System Default column.
  5. Select Delete.
  6. To confirm you want to delete the selected file, select Yes.
  7. Note: The file should automatically be deleted from the peer device after a configuration synchronization (ConfigSync) if the device is a member of a high availability (HA) group.

The Configuration utility should display that the APMclients package was successfully removed from the system.
