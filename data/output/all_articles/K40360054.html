Description

bigip_device_group doesn't specify how to enable Application Security Synchronization which is needed to sync ASM policy settings instead of LTM settings.

Environment

  • Ansible
  • bigip_device_group Playbook to enable ASM sync.

Cause

bigip_device_group Ansible module doesn't have a parameter to enable ASM sync.

Recommended Actions

To workaround this limitation, use the bigip_command Ansible module to run a TMSH command to enable asm-sync. here's an example task:

    - name: Task Enable ASM SYNC
      bigip_command:
        commands: "tmsh modify cm device-group {{ devgroup }} asm-sync enabled"
        provider: "{{ provider }}"
      when: inventory_hostname in groups['master']
      tags: enableasmsync

Additional Information

F5's SYS and LTM Ansible module are more feature rich (covering more features), the ASM module is currently limited to policy import, activation/deactivation, and creation. Over time this will change as F5 has a strong partnership with Ansible. for more info, visit F5 Ansible page on GitHub.
