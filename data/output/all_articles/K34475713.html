K34475713: LDAP user not able to authenticate in version 6.x

Description

Starting from v6.x, 'groupMembershipUserAttribute' setting has been removed from LDAP configuration settings in the GUI therefore BIG-IQ Administrator is not able to configure the LDAP setting in the same way. As a result, LDAP users do
    not pass the authorization hence the authentication fails at the end.

    Environment

    In earlier versions of BIG-IQ CM up to 6.x, when 'LDAP' is selected as the Auth Provider type, 'Group Membership User Attribute' option is available allowing BIG-IQ Administrator to define a value such as 'memberOf' to authorize the users if the LDAP users contains group information (i.e. user points to group).

    Starting from v6.x, LDAP and Active Directory providers have been split. As a result, 'Group Membership User Attribute' setting has been removed from LDAP Auth Provider GUI page because this attribute is arguably exclusive to Active Directory hence the  'Group Membership Filter' setting should be used instead as the LDAP group is the one that contains user information (i.e. group points to user).

    Cause

    This issue is a result of configuration improvement introduced in version 6.0.0.

    Recommended Actions

    1. To fix this issue after upgrade, you will need to delete 'Group Membership User Attribute' via command line then modify the 'Group Membership Filter' with (&(objectCategory=group)(member={userDN}))

      To delete the old vaule of 'Group Membership User Attribute':

      #curl -u admin -H "ContentType=application/json" -X PATCH -ks https://localhost/mgmt/cm/system/authn/providers/ldap/<provider UUID> -d'{"groupMembershipUserAttribute":""}'

    2. To configure LDAP Auth on version 6.0.0 onwards, use 'Group Membership Filter' setting for authorization.

    Additional Information

    'Group Membership Filter' and 'Group Membership User Attribute' are the properties generally used to determine group membership for the authenticated user. These are mutually exclusive properties (i.e. only one of them should be configured at the time).

    Note: If the BIG-IQ system is upgraded from v5.x to v6.x or v7.x, the previous settings of 'group Membership User Attribute' is rolled over during upgrade therefore authorization will continue as expected.
