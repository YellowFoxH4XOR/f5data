Known Issue

Denial of service (DoS) state changes may trigger the Traffic Management Microkernel (TMM) to produce a core file and restart.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a virtual server name that includes the period character (.).
  • You configure the virtual server with a security DoS protection profile.
  • The virtual server receives traffic that triggers DoS protection or determines that the requirement for DoS protection has ceased.

Impact

The BIG-IP system temporarily fails to process traffic while the TMM process restarts. If the BIG-IP system is configured for high availability (HA), the system fails over to a peer system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM generates a core file in the /shared/core directory.
  • Your BIG-IP system logs a SIGFPE to the /var/log/tmm file at the time TMM produces a core file and restarts.
  • In the /var/log/tmm file, you observe an error message similar to the following example:

    notice ** SIGSEGV **

  • In the /var/log/ltm file, you observe DoS attack start or stop messages similar to the following examples:

    notice tmm[<pid>]: 01010253:5: A  DOS attack has stopped for vector <vector type>, Attack ID <id number>.
    err tmm[<pid>]: 01010252:3: A  DOS attack start was detected for vector <vector type>, Attack ID <id number>.
    notice tmm[<pid>]: 01010253:5: A  DOS attack has stopped for vector <vector type>, Attack ID <id number>.

Resolution

Status

F5 Product Development has assigned ID 622204 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can delete the affected virtual server and recreate it, removing the period character from the virtual server name.

Impact of workaround: F5 recommends performing the suggested workaround during a scheduled maintenance window.
