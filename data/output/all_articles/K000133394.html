Description

  • You also managing Nginx instances from your Instance-Manager 
  • But, you are unable to view any kind of reporting/metrics for managed NGINX instances.

Environment

  • Nginx Instance Manager
  • Nginx Plus
  • Clickhouse
  • Metrics

Cause

  • Nginx instance manager must have Clickhouse credential. Failing to do so, results in NIM failing to access Clickhouse database.
  • This in turn results in lack of graphical representation of metrics on instance manage

Recommended Actions

  • Pass Clickhouse credential to Nginx Instance Manager by modifying /etc/nms/nms.conf file
  •  Modify NIM's nms.conf file as stated here,
    •  Please make sure to set Clickhouse address to "tcp://localhost:9000" when modifying nms.conf file
    • for example:- if we set password for the default username as "default"
                      clickhouse:
                      #   # Below address not used if TLS mode is enabled
                         address: tcp://localhost:9000
                      #   # Ensure username and password are wrapped in quotes
                         username: 'default'
                         password: 'default'

 

Additional Information

  • Also, there are a couple of prerequisites you would need to meet for metrics to work on NIM.
  • Is Clickhouse running. Check the state of the service 
    • sudo service clickhouse-server status
  • If Clickhouse running, then verify if Nginx Instance Manager can access Clickhouse.
    • during the initial instillations of Clickhouse, did you configure Clickhouse to use different username/password than the default value?
    • If so, you must pass these values to Nginx as described above by modifying /etc/nms/nms.conf file.
