Description

After applying add-on to the license, device is offline, in GUI you can see yellow banners that configuration was not loaded and license is not operational, logs similar to below one can be found in /var/log/ltm:

Mar 12 11:09:24 bigip.hostname emerg mcpd[6645]: 01070608:0: License is not operational (expired or digital signature does not match contents).

Environment

  • BIG-IP

Cause

This issue can occur if before applying license add-on, license was not reactivated for long time.

Answer/Recommended Actions

Reactivate license without applying add-on key, it should bring device to operational state, after relicensing without add-on key, you should be able to relicense your device one more time, this time using add-on key.

Additional Information

If license was not reactivated for some time before applying add-on key, it would be best practise to first re-license device without applying add-on key.
