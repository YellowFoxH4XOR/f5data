Description

Whilst running the nethasm-thales-install.sh script on BIG-IP the following error message was encountered:

Obtaining NetHSM hash ...
ERROR: Could not reach Thales HSM "<IP_ADDRESS>". Make sure the HSM IP address is correct and that the HSM is accessible to the BIG-IP.

You are unable to ping the HSM IP address, but you are able to telnet to the HSM IP address and port number from the BIG-IP.

A successful telnet connection:

telnet <HSM_IP_ADDRESS> 9004
Trying <HSM_IP_ADDRESS>...
Connected to <HSM_IP_ADDRESS>. Escape character is '^]'.
 

Environment

  • Thales HSM
  • BIG-IP v13.1+
  • Firewall between Thales HSM and BIG-IP

Cause

ID910673

Recommended Actions

Allow ICMP packets through your firewall

Additional Information

A ping check was introduced into the nethasm-thales-install.sh script in v13.1
