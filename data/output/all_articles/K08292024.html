Description
The install of NGINX Plus requires a certificate and key in order to download and install the product. However, the apt-get update command fails with an error message during NGINX Plus install:

  Could not load client certificate (/etc/ssl/nginx/nginx-repo.crt, SslCert option) or key (/etc/ssl/nginx/nginx-repo.key, SslKey option): Error while reading file. [IP: x.x.x.x 443]
 

Environment

  • NGINX Plus

Cause
Incorrect permissions on the .crt and .key file in /etc/ssl/nginx. The apt utility requires read permission for any user.

Recommended Actions

  1. cd /etc/ssl/nginx
  2. chmod 0644 nginx-repo.crt nginx-repo.key
  3. Try your apt update again
