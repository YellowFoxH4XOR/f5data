Description

How to Force DNS AXFR when DNS zones are out of sync between blades

 

Running the following tmsh command may output Failed IXFR (Refresh) (Slot #) for the Reason

# tmsh show ltm dns zone

Status
Availability : unavailable
State : enabled
Reason : Failed IXFR (Refresh) (Slot #)

/var/log/ltm may have similar lines as the ones below:

slot3/VIPRION.HOSTNAME err zxfrd[4988]: 0153100c:3: Failed on receive of <X> bytes for transfer of zone <zone> (Orderly shutdown), 0 bytes were received.
slot3/VIPRION.HOSTNAME err zxfrd[4988]: 01531018:3: Failed to transfer zone <zone> from <IP.address>, will attempt AXFR.
slot3/VIPRION.HOSTNAME err zxfrd[4988]: 0153100e:3: Transfer of zone <zone> failed with rcode (NOTAUTH).
slot3/VIPRION.HOSTNAME err zxfrd[4988]: 01531018:3: Failed to transfer <zone> from <IP.address>, will attempt AXFR.
slot1/VIPRION.HOSTNAME err zxfrd[6716]: 0153100e:3: Transfer of zone <zone> failed with rcode (NOTAUTH).
slot1/VIPRION.HOSTNAME err zxfrd[6716]: 01531018:3: Failed to transfer zone <zone> from <IP.address>, will attempt AXFR.
slot1/VIPRION.HOSTNAME err zxfrd[6716]: 0153100e:3: Transfer of zone <zone> failed with rcode (NOTAUTH).
slot1/VIPRION.HOSTNAME err zxfrd[6716]: 01531018:3: Failed to transfer zone <zone> from <IP.address>, will attempt AXFR.
slot3/VIPRION.HOSTNAME notice zxfrd[4988]: 0153101b:5: Ignoring NOTIFY for zone <zone> due IXFR in progress.
slot3/VIPRION.HOSTNAME err zxfrd[4988]: 0153102f:3: Timed out waiting for transfer data for zone <zone>.

The individual blades /shared/zxfrd/ directory will have files that don't match date.

Login to each of the blades and run the following commands to check the contents of /shared/zxfrd/ directory

# ls -l /shared/zxfrd

 

Environment

VIPRION

DNS Express

 

Cause

Zone transfer failing

Recommended Actions

Login in to the CLI via the console or SSH

1: Stop zxfrd process

# clsh bigstart stop zxfrd
2: Remove the files within the /shared/zxfrd directory

# clsh rm -rf /shared/zxfrd/*

3: Restart the zxfrd process 
# clsh bigstart start zxfrd
