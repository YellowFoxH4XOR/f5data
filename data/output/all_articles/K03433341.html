Known Issue

MCP leaks memory when synchronizing data group objects.

This issue occurs when the following condition is met:

  • You configure a device group that synchronizes data group objects with incremental sync enabled.

In versions prior to BIG-IP 13.0.0, the default synchronization behavior for configured device groups is to perform incremental sync unless the Full Sync check box is selected.

Impact

MCP leaks a small amount of memory with each synchronization and may stop responding.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • MCP leaks memory when synchronizing data group objects to peers in its device group.
  • In the /var/log/ltm log file, you notice MCP memory allocation errors and the mcpd process lost connections.
  • Your BIG-IP system restarts and generates a core file.
