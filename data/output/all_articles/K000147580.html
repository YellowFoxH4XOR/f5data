What Happened?

When a client makes an HTTP version 1.0 request to an F5 HTTP load balancer why does my origin server receive an HTTP 1.1 request?

Does F5 XC support HTTP version 1.0?

Environment

  • F5 Distributed Cloud
  • F5 XC Load Balancer

Resolution/Answer

  • F5 XC HTTP load balancers will accept a HTTP/1.0 request from a downstream client provided it contains a valid Host header (which the HTTP/1.0 protocol does not require)
  • The LB will respond in HTTP/1.0 and the connection closed
  • Upstream requests to the origin can either be HTTP/1.1 or HTTP/2 
  •  HTTP/1.0 is not supported on upstream requests

 

Additional Information

HTTP/1.0 became effectively obsolete with the standardization of HTTP/1.1 in 1999, but persisted in compatibility use through the 2000s. By the late 2000s, it was no longer used by modern clients and is now retained primarily for backward compatibility in servers and intermediaries.
