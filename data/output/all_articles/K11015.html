Known Issue

This is the result of a known issue. Internet Explorer 8 (IE8) users may be unable to open documents with their browser though Portal Access. When trying to open a document, the user may receive an error message that appears similar to the following example:

Unexpected call to method or property access.  cache-fm.php, line 61 character 351

The issue occurs only with IE8, which uses a different syntax for calling a document than previous versions of the browser.

F5 Networks Product Development tracked this issue as CR129874 and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass Release Notes.

This issue has been fixed in cumulative hotfix HF-610-1, which has been issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
