Description

You might want to stop gtmd when you upgrade BIG-IP DNS software, such as K11661449. 
If you change gtm configurations via Configuration Utility while stopping gtmd, you need to run tmsh save sys config gtm-only to update /config/bigip_gtm.conf file.
 

Environment

  • BIG-IP DNS system

Cause

This is by design. 
 

Recommended Actions

Please run tmsh save sys config gtm-only.
