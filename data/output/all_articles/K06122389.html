Description

Not able to see any report under Monitoring > Access> Network Access summary and user summary

Environment

  • BIG-IQ CM and DCD cluster
  • Access Events enabled on DCDs
  • BIG-IP APM configured with logging profile
  • No TMM route configured to log publisher (DCDs)

Cause

APM access logs requires  tmm route to  send Access logs  to DCD nodes 

Recommended Actions

  • Configure tmm route to DCD nodes on BIg-IP APM Device

or

  • Follow K21480015: Configuring Access Events Logging to BIG-IQ Via Management Interface 

Note This configuration is not recommended 

Additional Information

None.
