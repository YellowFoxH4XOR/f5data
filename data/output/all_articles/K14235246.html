Description

On BIG-IP 15.x and above, changing the management IP address from the Configuration Utility cannot work.

Environment

  • BIG-IP 15.x and above
  • Configuration Utility

Cause

Bug ID 817989

Recommended Actions

Use tmsh to create the management IP.  This will overwrite the old one.

Impact of procedure: none

  1. Log into Command Line Utility (CLI)

  2. Modify the management IP like this:

tmsh create /sys management-ip [ip address/prefixlen]

For example:

tmsh create /sys management-ip 192.168.1.245/24

  1. To view the management IP configurations

tmsh list /sys management-ip

  1. Save system configuration

tmsh save sys config

Additional Information

You may need to configure routes and gateways depending on your environment. To do so, refer to K15040: Configuring and displaying the management IP address for the BIG-IP system.
