Description

  • When running APM reports, the default date format is MM/DD/YYYY, regionally this may need to be changed to to DD/MM/YYYY.

Environment

  • BIG-IP APM
  • APM Custom reports

Cause

System default date format is in MM/DD/YYYY

 Recommended Actions

You can create a custom session variable using an iRule and reference this session variable in your custom reports.

  1. Use the following article to apply the iRule below
K50565834: How to add an iRule to a Virtual Server
when ACCESS_POLICY_COMPLETED {
    set date [ACCESS::session data get "session.server.session.user.starttime"]
    set scan [clock scan $date]
    set date_new [clock format $scan -format {%d\%m\%Y}]
    ACCESS::session data set "session.custom.user.starttime" $date_new
}

Refence session.custom.user.starttime session variable in custom reports for the updated format.
