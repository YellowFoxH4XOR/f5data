K9657: Inconsistent behavior for the Intelligent Browser Referencing feature

Topic

Note: For more information about the Maximum Age setting requirements, refer to K9653: The Maximum Age setting in the http-acceleration profile must be shorter than the Maximum Age setting in the BIG-IP WebAccelerator acceleration policy.

The Intelligent Browser Referencing (IBR) feature requires the object to be present in the memory Smart Cache. If the Maximum Age setting in the BIG-IP WebAccelerator acceleration policy is shorter than the Maximum Age setting in the http-acceleration profile, objects may be purged from the memory Smart Cache and cause inconsistent IBR behavior. As a result, IBR for objects will stop and start, the client browser will not use cached objects as expected, and it will request objects more frequently than expected.

Note: This behavior does not occur with default http-acceleration profiles and pre-defined BIG-IP WebAccelerator policies. In pre-defined BIG-IP WebAccelerator policies, the Maximum Age setting for images is four hours. The default Maximum Age setting in the http-acceleration profile is one hour.
