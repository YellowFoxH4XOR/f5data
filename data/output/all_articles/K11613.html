Known Issue

This is the result of a known issue. In rare instances, TMM may core when executing an iRule statement that parses HTTP headers. This issue occurs under certain traffic conditions, where the BIG-IP system incorrectly calculates the buffer required to parse the HTTP headers.

F5 Product Development tracked this issue as CR137033 and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, APM, PSM, and WebAccelerator release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0 and Hotfix-BIGIP-9.4.8-407.0-HF4 issued for BIG-IP version 9.4.8. You may download the hotfixes or later versions of the hotfixes from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.
