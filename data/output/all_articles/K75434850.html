K75434850: Error while importing XML format ASM security policy. ''The security policy file does not conform to the schema and cannot be imported.''

Type
Support Solution
Published
2020-11-19
Updated
2024-07-09
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.X.X, 15.1.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 15.0.1, 15.0.0
Source
https://my.f5.com/manage/s/article/K75434850

Description

  • Issue when trying to import an XML policy file in version 15
  • Configuration/s with metacharacters or configuration/s with method overrides defined on URLs.
  • "Cannot read imported policy file" error message on the Graphical User Interface (GUI) is displayed  
  • Error message will be logged in /var/log/asm file, as shown below, when policy fails to import

Nov 12 15:27:02 <hostname> crit g_server_rpc_handler_async.pl[13932]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::ImportExportPolicy::Base::fatal_error): The security policy file does not conform to the schema and cannot be imported. (line 33558: element mandatory_body: Schemas validity error : Element 'mandatory_body': This element is not expected. Expected is one of ( override_method, parameter, extraction, xml_profile, content_profile, brute_force, dynamic_flow, dynamic_flows, flow, cors_allowed_origins ).

Environment

  • ASM
  • Import/Export policy
  • BIG-IP

Cause

  • ID 898365: XML Policy cannot be imported

Recommended Actions

  •  Use binary export/import or move/remove the problematic elements from the XML file:
        <mandatory_body>
        <operation_id>
