Known Issue

An HTML form rewrite may trigger an HTTP 404 response.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is running one of the following versions:
    • 11.6.0 and 11.6.0 HF1 through HF3
    • 11.5.1 HF1 through 11.5.1 HF4
    • 11.5.0 HF1 through 11.5.0 HF5
    • 11.4.1 HF4 and higher 11.4.1 hotfix versions
    • 11.4.0 HF4 and higher 11.4.0 hotfix versions
  • Your BIG-IP APM access profile is processing session content that includes HTML forms.
  • The BIG-IP APM system rewrites an HTML form that does not include a form action item.

    For example:

    <html><head></head><body>
    <form name="myform" method="post" >
    Search: <input type='text' name='query' />
    <a href="javascript: submitform()">Search</a>
    </form>
    <script type="text/javascript">
    function submitform()
    {
    document.myform.submit();
    }
    </script>
    </body></html>

Impact

The system is unable to successfully submit the form.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the user accesses the HTML form using the Mozilla Firefox browser, they receive an HTTP 404 error.
  • When the user accesses the HTML form using the Microsoft Internet Explorer browser, they get logged out of their BIG-IP APM session.

Workaround

To work around this issue, you can modify the affected HTML form so it includes an action item or modify the form through a specially created iRule in which you can add the missing action to the affected form.
