K000091553: Config push error with duplicate location

Type
Support Solution
Published
2022-12-29
Updated
2022-12-29
Source
https://my.f5.com/manage/s/article/K000091553

Description

Error in Nginx Controller:

nginx: [emerg] duplicate location "/" in /etc/nginx/nginx.conf:579 nginx: configuration file /etc/nginx/nginx.conf test failed

 

Environment

Nginx Controller 3.22.2
Nginx+

Cause

This is a known issue for versions 3.22.2 and below:

Duplicate location error occurs during config push (wrong instance)
https://nginxsoftware.atlassian.net/browse/NMS-34014
 

Recommended Actions

Upgrade Nginx Controller to 3.22.3 or newer
 

Additional Information
