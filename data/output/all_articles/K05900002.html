Description

Provisioning failed with error 1 - Disk limit exceeded:

01071008:3: Provisioning failed with error 1 - 'Disk limit exceeded. 12288 MB are required to provision these modules, but only 4124 MB are available.'

Environment

  • Configsync
  • Disk space 
  • Software Upgrades

Cause

Insufficient disk space.

Recommended Actions

Perform the following steps to remove the unused volumes and reinstall into a new volume:

  1. Log in to the Configuration Utility. 
  2. Go to System > Software Management > Image List. 
  3. In the Installed Images section, select the logical disk name listed in the Disk column for the boot location you want to delete.

    For example, HD1

  4. In the Contained Software Volumes section, select the check box for the volume that you want to delete.

    Note: If the selected volume also has an associated application volume, such as a MySQL database, the associated application volume will also be deleted automatically so you do not have to select it. 

  5. Select Delete.

    After the system finishes deleting the selected volume, the Configuration utility may display the following banner message:

    The system must be rebooted for some changes to take effect. 

  6. Go to System > Configuration > Device > General.
  7. Select Reboot. 
  8. To confirm you want to reboot the device, select OK.
