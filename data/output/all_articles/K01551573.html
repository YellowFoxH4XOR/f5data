Description
Hash Offset and Hash Length settings doesn't work when an iRule with the persist hash command is used.

Environment

  • Hash persistence profile
  • iRule specifying persist value using persist hash command attached to persistence profile or virtual server

Cause
The following settings on the hash persistence profile are designed to allow the profile to work without an iRule and are ignored when an iRule is used:

  • Hash Offfset
  • Hash Length
  • Hash Start Pattern
  • Hash End Pattern
  • Hash Buffer Limit
