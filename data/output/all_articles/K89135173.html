Description

  • ASM manual live update fails with warning "Upload of an update file from a different version is not allowed"
  • Navigate to System > Software Management > Live Update and manually install a live update file
  • Warning message popup "Upload of an update file from a different version is not allowed"

Environment

  • ASM Provisioned
  • Manual Live Update method

Cause

The live update files located on downloads.f5.com can be version specific. For example a ServerTechnology update file downloaded from the 15.0.1 folder on downloads.f5.com will not be compatible with 15.1.2. 

Recommended Actions

  • Check that you are downloading the file from the folder that matches your software version.
    Note: There may not be an update file available for your build available on downloads.f5.com.
