Topic

This article applies to BIG-IP 11.x - 13.x. For information about other versions, refer to the following article:

  • K10822: Determining the compression capability of your BIG-IP system (9.x - 10.x)

You should consider using this procedure under the following conditions:

  • You want to determine your level of compression licensing.
  • You want to determine if your BIG-IP device is capable of hardware compression.

Description

The BIG-IP system offers various levels of software and hardware HTTP compression capability, depending on the platform and the software license. A software compression license is included in some BIG-IP base products and module licenses. You may purchase HTTP Compression Add-On licenses in specific increments. An unlimited compression license is also available, allowing compression throughput limited only by the capability of the system.

The HTTP compression value in a license indicates the maximum rate at which compression is performed on HTTP data. The rate of HTTP data is measured before the data has been compressed. If the rate of HTTP compressed data exceeds the licensed limits, the data exceeding the rate, in Mbps, is processed with NULL compression.

Note: For information about the available increments and pricing, contact your F5 Sales Representative.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You can access the Traffic Management Shell (tmsh).
  • Your BIG-IP system has a valid license installed.

Procedures

Determining software compression licensing limits

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Type the following command:

    show /sys license detail | grep perf_http_compression_Mbps

    Command output will determine the compression licensing limit, similar to the following examples:

    perf_http_compression_Mbps [unlimited]

    or

    perf_http_compression_Mbps [505]

Determining hardware compression availability

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Type the following command:

    show /sys license detail | grep "HTTP Hardware Compression"

    If the system contains hardware compression, the following command output displays:

    HTTP Hardware Compression

    If compression is not present, no output displays.
