Description

What are some methods to monitor temperature on a BIG-IP


Environment

BIG-IP

Cause

You would like to monitor temperature on a BIG-IP hardware unit

Recommended Actions

- You should be able to monitor temperatures internally by running the command "system_check -D" from the command line


- If you wish to monitor temperatures externally you will have to use SNMP, please see the article at https://my.f5.com/manage/s/article/K4026 you will need to download the MIB and decide on which OIDs to use, for example here is one that shows chassis temperature (the value is zero because this is a VE in our test lab):


[root@gallery-big-ip-14-1-4-6:TimeLimitedModules::Active:Standalone] config # snmpwalk -c public localhost sysChassis

F5-BIGIP-SYSTEM-MIB::sysChassisFanNumber.0 = INTEGER: 0

F5-BIGIP-SYSTEM-MIB::sysChassisPowerSupplyNumber.0 = INTEGER: 0

F5-BIGIP-SYSTEM-MIB::sysChassisTempNumber.0 = INTEGER: 0

F5-BIGIP-SYSTEM-MIB::sysBladeTempNumber.0 = INTEGER: 0

F5-BIGIP-SYSTEM-MIB::sysBladeVoltageNumber.0 = INTEGER: 0

[root@gallery-big-ip-14-1-4-6:TimeLimitedModules::Active:Standalone] config # snmptranslate -On F5-BIGIP-SYSTEM-MIB::sysChassis

.1.3.6.1.4.1.3375.2.1.3.2
