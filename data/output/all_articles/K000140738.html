Description

BIG-IP LTM VE has no free space for new software installation.

 

While you are installing the software version on a volume in BIG-IP device, you received below error:

 

(Disk full (volume group). See SOL#10636)

 

You may see the following error in /var/log/liveinstall.log

 

warning: tm_install::VolumeSet::choose_filesystem_plan -- Selected tiny plan (disk = 38797312, sz_standard = 14612880, sz_tiny = 8647152) error: tm_install::Process::Process_full_install -- predicted size for BIGIP16121 is 8647152 and vg has 7761920 remaining. Terminal error: Disk full (volume group). See SOL#10636

 

How can you check the volume size before the upgrade and mitigate this?

 

Environment

  • BIG-IP LTM VE
  • Installing a software version on a new/existing partition

Cause

Not enough disk space for new installations due to,

  • Existing boot volumes with old software versions
  • No available free space to create new boot volumes.

Recommended Actions

  • Use the boot volumes that are no longer in use to install new software.
  • Extend the free space from hypervisor and create a new boot volume.
