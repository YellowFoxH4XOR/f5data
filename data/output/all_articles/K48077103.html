Description

BIG-IP is issuing a TCP reset after a good OCSP response from an OCSP responder

[F5RST: iRule execution (reject command)]

Environment

  • OCSP responder configured
  • Client certificate authentication

Cause

OCSP responder configured does not match the OCSP server's signing record.

Recommended Actions

Configure the OCSP responder so that the ca-file contains the CA used in the OCSP server's signing record.

Additional Information

The OCSP responder configuration on the BIG-IP expects the signer of the OCSP records as the CA, not the issuer of the client certificates to be verified.

The OCSP verification is actually performed via an iRule, thus a failure may be reported in a way that appears to involve iRules.
