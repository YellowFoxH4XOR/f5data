Description
What are the various tmsh load sys config options, what files are impacted, and what do they do?  This article serves to provide some of the common users of TMSH load sys config

Environment

  • BIG-IP
  • configuration file

Recommended Actions
Below is a list of the various tmsh commands for loading a configuration - along with a general summary of what files are impacted and what the command does.

CommandFunction
tmsh load sys config verifyValidates the syntax of the config files if it was to try to overwrite the running config with them.
tmsh load sys configOverwrites the running config with the contents of the /config/bigip.conf, /config/bigip_base.conf and /config/bigip_user.conf files.
tmsh load sys config mergeOverwrites ONLY the information in the running config that is contained in the config files and does NOT overwrite information which exists in running but is not present in the config files.
tmsh load sys config file [filename]Overwrites the running config with the contents of the specified file.
tmsh load sys config baseAdds the base attribute only the bigip_base.conf and bigip_user.conf files are loaded, leaving out the bigip.conf file.
tmsh load sys config file [filename] mergeOverwrites any matching data in the running config from a file and ignores everything else. This is a great way to inject specific code into the running config. Afterwards a "tmsh save sys config" should be issued to then write from running config to files.
