Description

AVR classifies incoming DNS packets into Unrecognized category for Countries.

Additionally source IP and domain name for packets will be listed as N/A.

 

Environment

  • BIG-IP 15.1.10
  • AVR+GTM+AFM provisioned

 

Cause

ID837101.

 

Recommended Actions

Upgrade to a recommended version.

 

Additional Information

Bug ID 837101: AVR and BIG-IQ stats show N/A bar for Source IP and domain name on DNS query packet
