Known Issue

The BIG-IP system may drop incoming LACP packets for a LACP trunk. This issue occurs when the following condition is met:

  • Run the tcpdump command twice or more concurrently on a physical interface that belongs to the LACP trunk

Impact

The BIG-IP system may not process traffic as expected.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The affected interface may not process traffic as expected
  • The BIG-IP system logs messages that appear similar to the following example to the /var/log/ltm file when the LACP trunk link status fluctuates from up to down:

    01160024:4: warning: no receive on 1.1 for 45s (timeout=90s)
    01160016:6: Interface 1.1, link admin status: enabled, link status: up, duplex mode: full, lacp operation state: down
    01160010:6: Link 1.1 removed from aggregation

  • The affected interface may report abnormal levels of packet drops

Workaround

You may be able to recover the system by stopping all the tcpdump instances. If the issue continues to manifest after stopping all tcpdump instances, you can either restart the bcm56xxd process on the BIG-IP system or enable an Interface Mirror on any two unused interfaces and then disable it. To do so, perform the following procedure:

Restarting the bcm56xxd process

Impact of workaround: If the BIG-IP system is the active member of a redundant pair, restarting the bcm56xxd process will cause a failover. If the BIG-IP system is a standalone unit, restarting the bcm56xxd process will interrupt traffic processing.

  1. Log in to the BIG-IP command line.
  2. Restart the bcm56xxd process by typing the following command:

    bigstart restart bcm56xxd

Enabling and disabling an Interface Mirror

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Network >> Interfaces >> Interface Mirroring.
  3. From the Interface Mirroring State drop-down menu, select Enabled.
  4. Select any unused interface from the Destination Interface drop-down menu. For example, you could select 1.3.
  5. Select any unused interface from the Available box for the Mirrored Interfaces.
  6. Click << to move the selected interface to the Selected box.
  7. Click Update to save the change.
  8. From the Interface Mirroring State drop-down menu, select Disabled.
  9. Click Update to save the change.
