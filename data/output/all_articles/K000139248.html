K000139248: 403 Not authorized error when deploying AS3 declaration to BIG-IQ

Type
Support Solution
Published
2024-04-11
Updated
2024-04-11
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.0
Source
https://my.f5.com/manage/s/article/K000139248

Description

You are using non-admin user to deploy AS3 declaration to your BIG-IQ, but you get 403 Not authorized error.


Environment

  • BIG-IQ
  • AS3


Cause

For application creation, you need to add users to a custom Application Creator role, with access to any relevant BIG-IP AS3 templates.


Recommended Actions

You can follow the following steps to add users to a custom Application Creator role.

Monitoring and Managing Applications Using BIG-IQ / Managing BIG-IQ Applications / Managing BIG-IQ Applications

None
