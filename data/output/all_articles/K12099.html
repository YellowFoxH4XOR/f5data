Known Issue

This is the result of a known issue. Restoring a configuration from a UCS archive does not restore the fail-safe actions for system services. Instead, the BIG-IP system continues to use the same fail-safe actions that were defined before the UCS archive was loaded.

Note: This issue only affects fail-safe actions for system services. It does not affect other fail-safe settings such as those pertaining to VLANs or gateway pools.

F5 Product Development tracked this issue as ID 243467 (formerly CR136802) and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WAN Optimization, or Edge Gateway release notes.
