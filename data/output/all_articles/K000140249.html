Description

Disable SSLO Proxy Chaining

Environment

  1. SSLO
  2. Proxy chaining
  3. Bypass authentication 

Cause

Wanting to bypass explicit proxy authentication.

Recommended Actions

Internal Layered Architecture iRule

Additional Information

Proxy chaining config is global to the policy and not affected by policy matches. SSLO does not currently support "dynamic" egress. But you can implement a version of the internal layered architecture that can help you do this.
