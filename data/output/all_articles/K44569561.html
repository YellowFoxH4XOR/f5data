Description

You have an Advanced Web Application Firewall(AWAF) license with no LTM add-on. You are not able to create a virtual server to process UDP traffic. 

Environment

  • BIG-IP Licensing
  • Advanced WAF only License
  • UDP Profiles 

Cause

The following license(and likely others that do not have LTM licensing) does not include UDP functionality:

Example: F5-BIG-AWF-VE-25MV16

Recommended Actions

If you require UDP processing on your Big-IP WAF, you will need to contact your F5 account team to purchase an LTM add-on license.

Additional Information

You may determine if your BIG-IP WAF license supports LTM add-on by checking the following. 

  • WebGui : System | License. Search for Active Modules , Optional Modules and Inactive Modules
  • CLI/SSH, tmsh show sys license, Search for Active Modules, Optional Modules and Inactive Modules

Active Modules: This module is activated on the device.
Optional Modules: This module can be purchased from F5.
Inactive Modules: This module has been removed from your license previously. You may reactivate this module in the next license reactivation activity.
