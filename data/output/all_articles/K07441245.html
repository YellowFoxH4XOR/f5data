Known Issue

The BIG-IP system may not decrement the IP TTL field for embedded Packet Velocity Acceleration (ePVA) assisted FastL4 flows.

This issue occurs when all of the following conditions are met:

  • The system hardware includes an embedded Packet Velocity Acceleration (ePVA) chip.
  • Your virtual server traffic is processed by ePVA acceleration.
  • You configure a virtual server that has an associated FastL4 profile.

Impact

The TTL does not decrease for ePVA accelerated IP traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe that IP TTL does not decrement for ePVA-assisted flows, but decrements for flows without hardware acceleration. 
  • When you view a packet capture taken by the tcpdump utility, you observe that your BIG-IP system does not decrement IP TTL for ePVA assisted flows.

    For more information about the tcpdump utility, refer to K411: Overview of packet tracing with the tcpdump utility.

Resolution

Status

Workaround

To work around this issue, you can disable ePVA in the FASTL4 profile to see the IP TTL value decrements; however, doing so will increase CPU utilization as the virtual server connections will be subsequently processed in the software.
