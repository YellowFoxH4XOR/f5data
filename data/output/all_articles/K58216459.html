Issue

Error Message

notice mcpd[<PID>]: 01071682:5: SNMP_TRAP: Virtual /<partition>/<name> has become unavailable

In this error message, note the following:

  • <PID> is the process ID for the mcpd  process
  • <partition> is the name of the partition where the virtual server resides
  • <name> is the name of the virtual server

For example:

notice mcpd[6400]: 01071682:5: SNMP_TRAP: Virtual /Common/vs_example has become unavailable

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • You have configured a virtual server on the BIG-IP system.
  • The status of the virtual server changes and the virtual server becomes unavailable.

The system generates this message when a configured virtual server transitions the availability status from one of the other states, such as disabled, available, or unknown, to unavailable. You can view the status in the Configuration utility as a red diamond next to the virtual server.

Impact

The virtual server is unable to accept new connections.

Recommended Actions

This message may indicate that one or more pool members or nodes are down and not responding to monitors, or that there is a configuration issue. Verify that the pool members are correctly configured and assigned to the virtual server, and that pool members are available. In addition, check that associated monitors are configured correctly.
