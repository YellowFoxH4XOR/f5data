Description

  • The DNS::disable cache command doesn't work on DNS_RESPONSE iRule event
  • Unable to prevent a DNS response from being cached using iRule

Environment

  • DNS profile
  • DNS cache
  • iRule
  • DNS_RESPONSE iRule event

Cause

Seen behaviour is expected. Unfortunately the BIG-IP is not (by current design) able to prevent a response from being cached using an iRule like:

ltm rule fred {
when DNS_RESPONSE {
    if {[DNS::question name] eq "www.example.com"} {
        DNS::disable cache
    }
}
}

Recommended Actions

None

Additional Information

There is a Request For Enhancement (RFE) with ID 755064 to add DNS Cache feature to discard certain DNS responses. You may check the release notes for future releases if RFE ID 755064 is implemented.
