Description

Information about the 'asmlogd' Process and its CPU Usage

Environment

asm logging

CPU

Cause

N/A

Recommended Actions

Asmlogd process is responsible for storing request data to a binary log file on the BIG-IP ASM application volume. On chassis systems, the asmlogd process synchronizes request log data to the primary blade and writes the request data to the binary log file.

When you provision the BIG-IP ASM module , system create a volume called asmdata1 and mounts the /var/asmdata1 to asmdata1. The system writes binary request log data to the /var/asmdata1/request_log directory, and only uses the REQUEST_LOG table and associated MySQL tables for indexed data.

The asmdata1 volume is 6 GB on hardware platforms and 3 GB on BIG-IP Virtual Edition (VE) platforms

How to minimise the asmlogd CPU :

1) If any logging profile configured with log 'All requests' , we recommend changing it to 'Illegal Request' or setting up remote logging for all requests .

2) Disable guaranteed logging

3) Disable response logging if not necessary

4) Implementing the learning suggestions to avoid repeated violation .
