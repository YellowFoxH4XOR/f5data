Known Issue

Some BIG-IP GTM object names containing angle bracket characters (< ) or ( >) may affect iQuery traffic and cause the gtmd process to produce a core file.

This issue occurs when the following condition is met:

  • The BIG-IP GTM configuration contains one of the following objects in which the name contains an angle bracket character:
    • Virtual server
    • Server object

For example, if the BIG-IP GTM system discovers a virtual server object named <VirtualServer>, iQuery traffic to the virtual server object may fail and the gtmd process may crash and produce a core file.

Impact

The BIG-IP GTM system may be temporarily unavailable to process requests. In addition, the system may mark down affected virtual server objects.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP GTM system may log XML parsing errors to the /var/log/gtm file that appear similar to the following example:

    big3d[8092]: 012b2004:4: XML parsing error mismatched tag at line 73302
  • The system sends a SIGSEGV signal to the gtmd process, resulting in a stack trace and core file.
  • iQuery traffic fails when checking the status of the virtual server.

Workaround

To work around this issue, you can delete the affected BIG-IP GTM objects and recreate the objects using a name that does not contain the angle bracket characters. If the BIG-IP GTM server objects are configured to use the Virtual Server Discovery feature, you should delete and recreate the virtual server objects on the source BIG-IP system so that the BIG-IP GTM system will rediscover the virtual servers.

Impact of workaround: None.
