Description

This article explains how to reboot the F5 BIG-IP via command line.

Environment

  • BIG-IP
  • Command line
  • SSH or console access

Cause

None

Recommended Actions

There are 2 commands which you can choose to use to reboot your BIG-IP:

Note: Both commands achieve the same effect of rebooting the BIG-IP; there is no difference between them.

  • Option 1
    reboot
     
  • Option 2
    /sbin/shutdown -r
