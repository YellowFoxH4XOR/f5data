Description

BIG-IP Administrators may choose to modify the apm.xframeoptions database key to control how the BIG-IP APM system utilizes the X-Frame-Options HTTP response header. 
However, this database key has no affect or impact to APM Portal Rewrite traffic

Environment

  • BIG-IP APM Portal Access

Cause

APM Portal Rewrite does not have support for the "Referer" header. 
This means that the apm.xframeoptions database key has no affect or impact to APM portal rewrite traffic.

Recommended Actions

Do not configure APM Portal Access, if it is required to modify how the BIG-IP APM system utilizes the X-Frame-Options HTTP response header.
