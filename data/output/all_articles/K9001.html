Known Issue

This is the result of a known issue. The MySQL database may become corrupted if the power is interrupted or the system is power cycled, preventing the Configuration utility from starting properly. This behavior may occur when changes are being made to the system, or have recently been made, and the system is still writing the information to the database when power is lost.

F5 Product Development tracked this issue as ID 331495 (formerly CR101702) and it was fixed in BIG-IP ASM 9.4.6 and 10.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.
