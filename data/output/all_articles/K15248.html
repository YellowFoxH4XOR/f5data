Known Issue

The system may not enforce the connection limit on a virtual server after you configure the setting with a lower value.

This issue occurs when all of the following conditions are met:

  • The system has reached the configured connection limit on a virtual server.
  • You attempt to configure the connection limit on the affected virtual server with a lower value.

Impact

The system does not enforce the connection limit, and the affected virtual server begins accepting connections beyond the previously configured limit.

Symptoms

As a result of this issue, you may encounter one or more of the following symptom:

  • BIG-IP iHealth lists Heuristic H460185 on the Diagnostics > Identified > Medium screen.
  • The number of concurrent connections to the affected virtual server rises above the configured connection limit.

Workaround

There is no workaround for this issue. However, after the number of concurrent connections to the virtual server decreases to zero, the newly configured connection limit will be applied to all subsequent connections. To mitigate this issue, you can configure the connection limit with a lower value when the virtual server is not processing traffic.
