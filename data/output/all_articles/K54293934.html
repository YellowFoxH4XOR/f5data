Description

While generating a UCS file manually or the automated UCS generation when performing a software upgrade, the following error occurs in CLI:


tmsh save /sys ucs backup.ucs

Saving active configuration...
Script file does not exist:
  save.2600.save_pre = "/usr/libdata/configsync/msgbusd_storage_save_pre"
Error accessing database.
Error during config save.
Unexpected Error: UCS saving process failed.


Environment

  • BIG-IP
  • Creating UCS manually, or as part of a software upgrade

Cause

The following problem occurs after committing changes in /usr/libdata/configsync/cs.dat. This script is performed while taking a UCS file. It is using the old file which does not exist after the upgrade. For example: in version 15.1.4.1 the UCS script is using a "msgbusd_storage_save_pre" file but in 15.1.5.1 is using a "restjavad_storage_save_pre". The content of these files is the same. There is only a file name difference.  While taking the UCS after the upgrade and the cs.dat is from the prior version, it contains in the body of the script the old file which does not exist in the BIG-IP system after the upgrade, and the script can not be run.

The script has implemented the old file:

cat /usr/libdata/configsync/cs.dat

(...)
# msgbusd storage     
save.2600.save_pre = msgbusd_storage_save_pre  <----
save.2600.dir_opt = /var/tmp/storage_temp
save.2600.save_post = (rm -rf /var/tmp/storage_temp)
(...)


Recommended Actions

Change the part of the script to open the existing file:

  1. To remount the /usr file system in read-write mode, type the following command
    # mount -o remount,rw /usr
     
  2. Backup the current cs.dat, e.g.
    # cp /usr/libdata/configsync/cs.dat /usr/libdata/configsync/cs.dat.backup
     
  3. Using a text editor, edit the /usr/libdata/configsync/cs.dat file to remove, comment the following:

    # msgbusd storage
    save.2600.save_pre      = msgbusd_storage_save_pre
    save.2600.dir_opt       = /var/tmp/storage_temp
    save.2600.save_post     = (rm -rf /var/tmp/storage_temp)

    and put the following instead:

    # restjavad storage
    save.2600.save_pre      = restjavad_storage_save_pre
    save.2600.dir_opt       = /var/tmp/storage_temp
    save.2600.save_post     = (rm -rf /var/tmp/storage_temp)
     
  4. Save the file and exit the editor.
  5. To remount the /usr file system in read-only mode, type the following command:
    # mount -o remount,ro /usr
 

Additional Information

Important: If the BIG-IP system is upgraded to a new version, the cs.dat file is replaced and any customizations to this file will be lost. F5 does not recommend adding the cs.dat file into a UCS archive because you may encounter errors when saving or installing a UCS archive after you upgrade. For reference:

K4422: Viewing and modifying the files that are configured for inclusion in a UCS archive
