Known Issue

This is the result of a known issue. Mac OS X only allows FirePass to create interfaces for Java AppTunnels on the 127.0.0.1 address. If other Local Hosts are defined, FirePass attempts to bind to them but will fail. In addition, the following error appears in a Java console:

Note: For information about enabling and viewing the Java console, refer to How do I enable and view the Java Console? This link takes you to a resource outside of AskF5, and the third party could remove the document without our knowledge.

WARNING: Cannot bind '127.x.x.x:[1922-65535]
java.net.BindException: Can't assign requested address
    at java.net.PlainSocketImpl.socketBind(Native Method)
    at java.net.PlainSocketImpl.bind(PlainSocketImpl.java:365)
    at java.net.ServerSocket.bind(ServerSocket.java:319)
    at java.net.ServerSocket.bind(ServerSocket.java:277)
    at tunnel.Tunnel.bindSockets(Tunnel.java:138)
    at tunnel.Tunnel.run(Tunnel.java:188)

However, the error message may be ignored because FirePass automatically binds to 127.0.0.1.

Workaround

If you need to use an address other than 127.0.0.1, you must configure the address on the Mac OS X client. Configuring the IP address on the Mac OS X client requires root privileges. For example, to use the local address 10.10.10.1 in a Java AppTunnel configuration, users must first type the following command on the Mac OS X client machine:

sudo ifconfig lo0 add 10.10.10.1

To configure the IP address for the Java AppTunnel favorite, perform the following procedure:

  1. Log in to the FirePass Administrative console.
  2. Click Application Access.
  3. Click App Tunnels.
  4. Click Resources.
  5. Click on the App Tunnel Favorite link you want to examine.
  6. Expand the Static Tunnels section.
  7. In the Local Host field, populate the IP address that was configured on the Mac OS X client.
