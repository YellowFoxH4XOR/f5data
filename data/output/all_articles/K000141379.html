Description

You have created an Access Policy with Endpoint Check to check the macOS Sequoia (15.0) Native Firewall on the client, but the check is failing. You may see the following logs on /var/log/apm:

notice apmd[12909]: 014902f7:5: /Common/Test_AP:Common:e6c19ff9:/Common/Test_AP_act_fw_software_check_ag: endpoint software detected (sdk=4.3.3249.0,type=fw,id=100022,vendor_id=100011,version=15.0,state=,name=Mac OS X Builtin Firewall,vendor_name=Apple Inc.,db_signature=100189,db_version=,db_time=,last_scan=,engine_version=,missing_updates=).

Here, the "state=" parameter is empty (it should be either 0 (failure) or 1 (success)).

Environment

  • BIG-IP APM access policy configured with Endpoint Firewall Check agent.
  • EPSEC version is 1726 or earlier.
  • macOS Sequoia (15.0) with Native Firewall enabled.

Cause

This is due to EPSEC bug ID1677893.

Recommended Actions

This is fixed in EPSEC 1727 (epsec-1.0.0-1727.0.iso, available on the download site) or later.

Additional Information

None.
