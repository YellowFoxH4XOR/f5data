Description

  • Unable to apply ltm policy to fastl4 virtual server
  • An error appears when trying to apply a ltm policy to fastl4 virtual server
  • The following error can be seen on GUI

    010716d9:3: Virtual server <virtual_server_name> requires a profile of type tcp for ltm policy <ltm_policy_name>
     

Environment

  • LTM
  • Performance (Layer4) virtual server
  • Fastl4 profile
  • LTM traffic policy

Cause

Seen behaviour is expected.  A tcp ltm traffic policy cannot be assigned to a FastL4 virtual server (F5 it's coded to require a TCP profile)

Recommended Actions

You can use an iRule instead of the tcp ltm policy .

Additional Information

None.
