Topic

The BIG-IP Controller can filter out the Code Red worm attack by using a rule to discard the specific HTTP request.

Note: This rule works for the latest variant of the Code Red worm as of July 30, 2001. The worm can change, requiring that you adjust your rule accordingly.

To create this rule, perform the following steps.

  1. From the Configuration utility menu, create a rule that contains the following information, substituting server_pool for your actual pool name.

    if (http_uri contains "default.ida") {

   discard
}

else {

   use (server_pool )
}
  2. Configure or change your virtual server (VIP) to use the newly created rule instead of a pool.

For information about the Code Red worm, refer to:

  • http://www.cert.org/advisories/CA-2001-23.html
