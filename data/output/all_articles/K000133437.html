Description

In Active-Standby HA pair, Active device shows below warning under Device management -> Traffic groups:

"The traffic group configuration on this device does not match with other devices. Sync the configuration between devices"

There is no functional impact and Device Management -> Overview shows devices are in sync. 

Environment

HA pair

Cause

Port lockdown settings on config sync IPs doesn't match on Active and Standby devices. 

Recommended Actions

1. Checked the port lockdown setting on self IPs used as config sync IP under Network >> self IPs >> click on self IP.
2. Compare the port lockdown setting for config sync self IPs on active and standby.
3. Make sure that it is set to 'Allow default' on both devices.
