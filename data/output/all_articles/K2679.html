Topic

RMON is a remote monitor protocol that allows for an intermediate network element to query a set of devices on its own, and then present summarized statistics to the managing computer through a portion of its own Management Information Base (MIB). The BIG-IP MIB for RMON is Local.Bigip.Snmp.Rmon.

Disabling RMON

To disable RMON from starting upon boot up, perform the following procedure:

  1. Type the following command:

    b db set Local.Bigip.Snmp.Rmon = 0

  2. Restart snmpd, by typing the following command:

    bigstart restart snmpd

RMON should no longer start upon boot up.

Enabling RMON

To enable RMON to start upon boot up, perform the following procedure:

  1. Type the following command:

    b db set Local.Bigip.Snmp.Rmon = 1

  2. Restart snmpd, by typing the following command:

    bigstart restart snmpd

RMON should now start upon boot up.
