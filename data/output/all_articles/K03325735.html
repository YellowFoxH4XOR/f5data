Description

When running tcpdump via CLI and viewing the output, the following error message is noticed

bad udp cksum

Environment

The following conditions must be met for this article to be applicable.

  • The tcpdump is output to the screen and not written to a pcap file.
  • Running the tcpdump on the tmm or management interface.
  • Below is an example of a tcpdump command which will display the error message
tcpdump -nni eth0 -s0 -vv

Cause

This is an expected behavior as tcpdump tool on Linux because the checksum is offloading on your NIC but tcpdump reads IP packets from the Linux kernel right before the actual checksum takes place in the NIC chipset.

Recommended Actions

None

None
