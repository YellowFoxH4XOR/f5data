Known Issue

This is the result of a known issue. The min up members setting (referred to as the Gateway Fail-safe threshold setting in the Configuration utility) specifies the minimum number of gateway pool members that must be available. If the threshold falls below the value, the BIG-IP system triggers the gateway fail-safe action.

The BIG-IP ASM does not allow the min up members setting to be specified for a gateway pool. If you attempt to define min up members for a gateway pool using the bigpipe command, a bigpipe error message similar to the following example will display on the console:

BIGpipe pool operation error:
   01070356:3: HA pool min up members feature not licensed.

Note: This issue only occurs for ASM standalone systems.

F5 Product Development tracked this issue as ID 242815 (formerly CR134938) and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP ASM release notes.
