K21528053: [crit] message in error.log says '24: Too many open files'

Type
Support Solution
Published
2020-01-15
Updated
2025-02-06
Applies to
  • NGINX Products
  • NGINX Plus: R19, R18, R17, R16, R20, R14, R13, R15
Source
https://my.f5.com/manage/s/article/K21528053

Description

Example of the error.log message:

019/07/12 14:32:12 [crit] 29548#29548: *29288033 open() "/some/path/filename.html" failed (24: Too many open files)

Environment

The limit on the maximum number of open files (RLIMIT_NOFILE) for worker processes is set within the worker_rlimit_nofile directive.

Cause

While processing the client's traffic, NGINX reaches the per-worker limit of open files.

Recommended Actions

  1. Increase the per-worker limit by setting worker_rlimit_nofile 65535;
  2. Reload the nginx process by entering the following command:

    sudo nginx -t && sudo service nginx reload
