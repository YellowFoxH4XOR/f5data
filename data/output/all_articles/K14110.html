Topic

You should consider using this procedure under the following conditions:

  • You are using dynamic ratio load balancing mode.
  • You want to use an SNMP DCA or SNMP Data Collection Agent (DCA) Base monitor to collect values for pre-defined or custom SNMP objects.

Description

The Dynamic Ratio load balancing algorithm load balances requests based on a ratio value that is calculated using a set of values collected by an SNMP DCA.

An SNMP DCA is configured as a monitor using one the following two monitor types.

SNMP DCA

  • The SNMP DCA monitor collects SNMP values for a pre-defined set of SNMP objects for CPU, memory, and disk usage statistics.

SNMP DCA Base

  • The SNMP DCA Base monitor type does not have any pre-defined SNMP objects to collect.

The SNMP DCA and SNMP DCA Base monitors use variable name/value pairs to specify a custom SNMP object to be collected, and the associated threshold and coefficient to be used by the Dynamic Ratio load balancing algorithm. This requires a set of three variable name/value pairs to be configured for each object to be collected. You must configure a variable name/value key pair for each the following:

  • The object identifier (OID) to be collected
  • A threshold for the returned value
  • A coefficient to use for the object when calculating the load balancing metrics

These variable name/value pairs use the following naming syntax.

NameValue
<name><numeric OID>
<name>_threshold<integer threshold value>
<name>_coefficient<integer coefficient value>

For more information about these monitors and how the threshold and coefficient values are used to calculate a metric used for the Dynamic Ratio load balancing algorithm, refer to K14114: Overview of the SNMP DCA.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to the Configuration utility.
  • You have an understanding of the SNMP DCA. For information, refer to K14114: Overview of the SNMP DCA.
  • You have an understanding of the Dynamic Ratio load balancing mode and how SNMP values are used to calculate the weight assigned to a pool member for load balancing decisions. For information, refer to K9125: Overview of Dynamic Ratio load balancing.
  • You know the SNMP OIDs, expected values, and thresholds for the specific system objects to be monitored.
  • Each pool member to be monitored will need to allow the BIG-IP systems to poll the SNMP agent using the SNMP version and community string specified in the custom SNMP DCA Base monitor being configured.

Procedures

Creating a custom SNMP DCA or SNMP DCA Base monitor

To watch a video demo of this procedure, go to  Create a custom SNMP DCA or SNMP DCA Base monitor.

To create a new SNMP DCA or SNMP DCA Base monitor with variable name/value pairs that specify an SNMP object to be collected, and the associated threshold and coefficient to be used by the Dynamic Ratio load balancing algorithm, use the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Monitors.
  3. Select Create.
  4. For Name, enter the monitor name.
  5. For Type, select the monitor type (SNMP DCA or SNMP DCA Base).
  6. For Community, enter the SNMP community string used by the node being monitored.
  7. For Version, select the SNMP version used by the node being monitored.

    Note: The default is v1. However, F5 recommends v2c. The SNMP DCA and SNMP DCA Base monitors do not support SNMP v3. The Other version type provides for a custom or proprietary SNMP implementation.

  8. If you are configuring an SNMP DCA Base monitor, proceed with the following steps. If you are configuring an SNMP DCA monitor, steps 9 through 18 are optional, so determine whether you want to collect data from any additional SNMP objects or whether the pre-defined set of SNMP objects for CPU, memory, and disk usage are sufficient.
  9. For Variables Name, enter the name of the SNMP object to be collected.

    For example:

    hrSystemProcess

  10. For Variables Value, enter the SNMP object OID to collect.

    For example:

    .1.3.6.1.2.1.25.1.6.0

  11. Select Add.
  12. For Variables Name, enter the name of the threshold variable to be used with the SNMP object collected.

    For example:

    hrSystemProcess_threshold

  13. For Variables Value, enter the threshold value you want to use.

    For example:

    85

  14. Select Add.
  15. For Variables Name, enter the name of the coefficient variable to be used with the SNMP object collected.

    For example:

    hrSystemProcess_coefficient

  16. For Variables Value, enter the coefficient value you want to use.

    For example:

    2

  17. Select Add.
  18. Repeat steps 9 through 17 for each custom SNMP object to be collected.
  19. Configure other settings as needed.
  20. Select Finished.

The new monitor is now available to associate with nodes.
