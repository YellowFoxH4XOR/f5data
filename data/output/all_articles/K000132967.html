K000132967: QKView on BIG-IQ is failing when generated via GUI

Source

Description

QKViews generated via GUI runs out of disk space and fails

Environment

  • BIG-IQ
  • Generating QKView via GUI fails
  • Out of disk space

Cause

Functioning as designed.

A QKView triggered via BIG-IQ REST API (or BIG-IQ GUI) includes all the DB schema/data to recreate the DB.
A QKView triggered via QKView utility on CLI does not capture that.

Recommended Actions

Increase disk space in /shared to accommodate QKView generation via GUI.

K30902515: Resizing the /var, /var/log, or /shared file system on a BIG-IQ Virtual Edition

None
