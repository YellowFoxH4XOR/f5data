K60025537: APM ''Active Sessions'' the start / end time of the sessions show incorrect time

Type
Support Solution
Published
2022-08-30
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 15.X.X, 15.0.X, 15.1.0, 15.0.1, 15.0.0, 15.1.8, 15.1.7, 15.1.6, 15.1.X, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.5
Source
https://my.f5.com/manage/s/article/K60025537
Description

Overview > Active Sessions, the Start and End time of the sessions show incorrect time.
When you click a specific session and move to the access reports page - the time shows correctly.
Checked with time/date command, again time shows correctly.
Only "Active Sessions" screen shows incorrect time

Environment

  • Overview > Active Sessions
  • Time displayed is different than "actual" time
Cause

Timezone setting has been changed, but the BIG-IP "not" rebooted
A restart of the system is needed to fully apply the timezone change

Recommended Actions

Restart the BIG-IP:
K7369: Shut down and restart the BIG-IP system

Additional Information

None
