K000140114: Syslog stopped working for APM

Type
Support Solution
Published
2024-08-15
Updated
2024-08-15
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000140114

Description

You encountered your APM stopped sending syslog messages.

The BIG-IP and LTM is still sending System logs so it's just the APM that is impacted.

You also noticed that the APM is not logging the TMM logs which shows the typical Session logs.

Your BIG-IP uptime is over 500 days.

 

APM logs show following messages:

Jun 18 04:22:44 BIG-IP.example.com err apmd[14824]: 01490000:3: AccessPolicyProcessor/AccessPolicy.cpp func: "execute()" line: 600 Msg: agent execution error, node=8, agent=0

Jun 18 04:22:44 BIG-IP.example.com err apmd[14824]: 01490000:3: queue.cpp func: "printx()" line: 348 Msg: Thread 7 id 47506554767104 fd 248 queue time 0 work time 33

Jun 18 04:25:08 BIG-IP.example.com err apmd[14824]: 01490000:3: queue.cpp func: "printx()" line: 327 Msg: Queue statistics: work.size() 0, threads 100, running 1

Jun 18 04:25:08 BIG-IP.example.com err apmd[14824]: 01490000:3: queue.cpp func: "printx()" line: 348 Msg: Thread 89 id 47511541679872 fd 248 queue time 0 work time 2

 

LTM logs show following messages:

Jun 18 04:10:09 BIG-IP.example.com err errdefsd[5912]: 01940015:3: errdefs: failure publishing errdefs configuration.

 

Environment

BIG-IP APM module

 

Cause

Issue with the logging framework.

 

Recommended Actions

The only fix is to do a full box reboot using this command:

   # full_box_reboot
