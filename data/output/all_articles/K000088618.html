K000088618: Logging "request_type": "blocked" still logging PASSED requests

Type
Support Solution
Published
2021-03-26
Updated
2026-07-30
Applies to
  • NGINX Products
  • NGINX App Protect WAF: 3.0.0
Source
https://my.f5.com/manage/s/article/K000088618

Description

Edited the JSON File defining App Protect Logging and changed "request_type": "illegal" to "request_type": "blocked" in the filter section. Set a custom log format in the content section.

Requests with outcome PASSED are logged, despite not being blocked.

Environment

  • Logging

Cause

This is a known issue associated with Bot Defense, tracked as WAFMC-3606. It will be fixed in a future release.

Recommended Actions

None

Additional Information

None
