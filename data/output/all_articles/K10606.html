K10606: Synchronization between BIG-IP WebAccelerator systems in a symmetric deployment may fail if NTP is not configured

Topic

A symmetrical BIG-IP WebAccelerator configuration consists of central and remote BIG-IP WebAccelerator systems that have synchronized configurations. If NTP is not configured for the symmetric BIG-IP WebAccelerator systems and the system clocks are not synchronized, the BIG-IP WebAccelerator configurations across the symmetric deployment can be blocked.

Note: For more information about deploying a symmetric BIG-IP WebAccelerator configuration, refer to the Administrator Guide for the BIG-IP WebAccelerator System.

For example, if the BIG-IP WebAccelerator system clocks are out of sync by one hour, and you attempt to edit the configuration of one of the systems in the deployment, the changes appear in the Configuration utility of the local system; however, the changes are not synchronized across the remote BIG-IP WebAccelerator systems.

F5 Networks Product Development tracked a request for enhancement (RFE) as CR118165. Beginning in BIG-IP version 10.1.0, the BIG-IP WebAccelerator checks for clock synchronization in symmetric deployment configurations. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.

Workaround

To ensure that BIG-IP WebAccelerator configurations are synchronized across the symmetric deployment, configure NTP for all systems.

Note: For more information about configuring NTP, refer to K3122: Configuring the BIG-IP system to use an NTP server.
