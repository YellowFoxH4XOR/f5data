Topic

You can configure an XML profile within the BIG-IP ASM security policy to protect XML-based web traffic. When you create the XML profile, you define the validation configuration by importing an XML-based schema file into the profile. You can also define the defense formatting settings which specify the valid properties of the actual XML data or the web services application. The XML profile then protects XML applications by validating whether the incoming traffic complies to the predefined schemas or WSDL documents.

If the security policy processes a request where the XML data does not comply to the defense formatting settings, the following violation will be logged to the /var/log/asm file and to the Reporting screen in the Configuration utility:

XML data does not comply with format settings

For example, the Maximum Name Length defense setting specifies the maximum acceptable length for entity and attribute names in bytes. If the request contains XML data with an attribute name that exceeds the the Maximum Name Length defense setting, the BIG-IP ASM security policy will block the request.
