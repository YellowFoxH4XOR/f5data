Description

ConfigSync operation failed after an upgrade, resulting in a Sync Failed state, with an error similar to the following:

Sync error on bigip1.ltm: Load failed from /Common/bigip2.ltm 01070901:3: Invalid field: password_policy in difok

Environment

  • ConfigSync
  • Source unit running 14.1.4.1 or later
  • Target unit running earlier version (for example, 14.1.4)

Cause

ConfigSync between dissimilar versions failing due to addition of sys db password.difok in 14.1.4.1.

sys db password.difok {
    value "8"
}

Recommended Actions

Avoid syncing between dissimilar versions.

If in the broken sync state after upgrade, upgrade all remaining HA peers to be on equivalent versions, then sync again.

If rolled back source unit to a version without sys db password.difok, and still in the broken sync state, perform a ConfigSync from tmsh with the force-full-load-push option. For example:

tmsh run cm config-sync to-group failover-grp force-full-load-push
