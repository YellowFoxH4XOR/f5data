Topic

The VIPRION 4800 8-slot chassis requires that all blades run BIG-IP 11.3.0 or later.

Description

All blades installed in a VIPRION 4800 8-slot chassis must run BIG-IP 11.3.0 or later. If you insert a blade with a default boot location that is running a BIG-IP version earlier than 11.3.0, the blade is unable to join the cluster and reboots continuously.

Recommendations

When installing a blade into a VIPRION 4800 chassis, you should consider the following factors:

  • Ensure that the blade's default boot location is running BIG-IP 11.3.0 or later.
  • Before moving a blade from a VIPRION 4400 or 4480 4-slot chassis to a VIPRION 4800, ensure that you have moved all pre-11.3.0 versions from all installed boot locations.
