Description
After BIG-IP upgrade to v14.1.0.X Active Directory Authentication breaks.

Environment

  • Upgraded to v14.1.0.3
  • Remote authentication set to Active Directory under 'System  ››  Users : Authentication'.

Cause
Role is not read by the BIG-IP in the process of authentication.

Recommended Actions

Verify the configuration:
Under 'External Users' part of the remote authentication configuration, if a 'Role' is selected for example 'Guest', then the remote user can authenticate and gain access per the role.
If above tested to be correct, then revert by applying the below fix.

Enable the “Check Member Attribute in Group”
  1. Go to 'System  ››  Users : Authentication'.
  2. Check the check-box 'Check Member Attribute in Group'.
  3. Click 'Finish' to save the change.
Now you can verify that the issue is resolved.
