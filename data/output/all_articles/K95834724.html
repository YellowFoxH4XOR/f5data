K95834724: BIG-IP AFM DoS Protection vector supports frame types configuration for IPv6 extension headers

Type
Knowledge
Published
2018-12-11
Updated
2025-02-07
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP AFM: 14.1.0
Source
https://my.f5.com/manage/s/article/K95834724

Issue

Old Behavior

In versions prior to BIG-IP AFM 14.1.0, the IPv6 extension headers on the DoS Protection vector configuration do not support the selection of frame types. Therefore, when the DoS vector is enabled, it matches any packet with IPv6 extension headers.

Note: The DoS vector is label in the Configuration utility is IPv6 Extended Header Frames.

New Behavior

Beginning in BIG-IP 14.1.0, you can configure the DoS Protection vector by specifying the frame types of the IPv6 extension headers that match the ipv6-ext-hdr DoS vector. The following IPv6 extension headers frame types are included by default:

  • auth refers to the Authentication header.
  • dstopt refers to the Destination Options header.
  • esp refers to the Encapsulating Security Payload header.
  • frag refers to the Fragment header.
  • hbh refers to the Hop-by-Hop Options header.
  • mobility refers to the Mobility header.
  • route refers to the Routing header.

Impact

None

Recommended Actions

You can view the IPv6 extension header frame types configured on the BIG-IP AFM system using either the Configuration utility or the TMOS Shell (tmsh):

Viewing IPv6 extension headers using the Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Security > DoS Protection > Device Protection.
  3. Expand the Network list and click IPv6 Extended Header Frames.

Viewing IPv6 extension headers using tmsh

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Type the following command:

    list /security dos ipv6-ext-hdr
