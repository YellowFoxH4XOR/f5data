K000163898: VELOS blade not listed in 'show system diagnostics os-utils docker nodes' after RMA

Description

After a blade replacement (for example, due to RMA), the blade in question is not listed in the controller output of show system diagnostics os-utils docker nodes.

Environment

  • F5OS-C 1.8.x
  • After blade replacement

Cause

  • Bug ID 2564817: Replacement blade does not show up when running "show system diagnostics os-utils docker nodes" on controller

Recommended Actions

As a workaround, restart the utils-agent container on the active controller:

docker container restart utils-agent

Additional Information

The utils-agent service is responsible for two areas:

  • confd 'file' operations: importing, exporting, listing, showing, or deleting files, displaying file transfer status, aborting transfers, adding or removing known-hosts entries.
  • confd 'system diagnostics os-utils docker' operations: listing container status, restarting containers.

The docker operations are only available from F5OS-C 1.8.0.

Restarting the utils-agent container typically takes no more than 1-2 seconds and the operations above may be briefly unavailable during that time. There is no impact to traffic.
