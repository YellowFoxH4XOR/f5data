Description

When trying to load a UCS file you see the following error:
emerg load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all base " - failed. -- 01070710:3: Cannot update_indexes/checkpoint DB object, class:devicegroup_device status:13 - EdbCfgObj.cpp, line 127 Unexpected Error: Loading configuration process failed

Environment

  • BIG-IP 
  • You are loading a UCS archive
  • You see a similar error message on /var/log/ltm:
    emerg load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all base " - failed. -- 01070710:3: Cannot update_indexes/checkpoint DB object, class:devicegroup_device status:13 - EdbCfgObj.cpp, line 127 Unexpected Error: Loading configuration process failed

Cause

Bug ID 636182. The error occurs when loading a saved configuration file for a device in a Device Service Cluster, where the CM Device Name locally differs from that which is in the file.

Recommended Actions

There are two options to resolve this issue:

1. Prior to loading the saved UCS file, run the tmsh command to rename the local CM device name to match that which is in the UCS file:       
  # tmsh mv cm device <current_name> <new_name>
         
For example:
   tmsh mv cm device bigip1.local bigip1.siterequest.com

2. Load an SCF file instead.            
  tmsh load /sys config file <scf_file>
