K50558810: Exporting APM Policy using BIG-IP UI fails silently

Type
Support Solution
Published
2021-04-05
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP APM: 16.0.0, 16.0.X, 16.0.1, 16.X.X, 17.X.X, 17.5.X, 17.5.0, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.X, 16.1.5, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0
Source
https://my.f5.com/manage/s/article/K50558810

Description

When a large APM Policy is exported, the process does not complete.

  • messages similar to the one below appear in webui.log

ERROR [TP-Processor1] files.SamlMetadataDownloader:executeCommand - SamMetadataDownloader: Syscall returned error; 01070734:3: Configuration error: sso-config-saml : Error signing /partition_name/policy_name while exporting. Private key file and corresponding certificate file do not match)

Environment

  • BIG-IP APM
  • APM Policy Export or Import

Cause

This is caused by an internal process timeout. This issue is being tracked as Bug ID 942729.

Recommended Actions

Use the CLI to export or import the APM Policy. For additional information refer to K30575107

None
