Description

The presence of multiple dg-data entries for the same IDs on an SSL Orchestrator device generally indicates that the SSLO dg-data on the box is now unreliable, which results in errors on the SSLO admin GUI pages.

A quick check for the presence of multiple dg-data on an SSL Orchestrator device is to run the following command from the bash shell:

 

restcurl /shared/iapp/blocks | jq '.items[] | select(.name=="f5-ssl-orchestrator-dg-data") | .id'

 

This would print multiple ids if there are multiple dg-data entries.

 

Environment

BIG-IP SSLO


Cause

SSLO block data corruption resulting in multiple dg-data entries with the same id.

 

Recommended Actions

Steps should be taken to recover the SSLO device(s) to a "known good" state if multiple dg-data entries with the same ID are found, eg. by reloading the configuration from a known-good UCS on the box, or if it is a HA pair, simultaneously reloading the configuration on both units from known-good UCSs.
