Description

You can set up the registry check action or verify the existence or absence of certain keys and values in the Windows system registry database.
Both key values or Boolean expressions evaluate the existence or absence of registry entries. 

Environment

  • BIG-IP APM
  • Microsoft Windows Registry Key Check

The following key names are supported:

  • HKEY_CURRENT_USER
  • HKEY_LOCAL_MACHINE
  • HKEY_CLASSES_ROOT
  • HKEY_USERS
  • HKEY_CURRENT_CONFIG

Specifying registry values

Following are examples of registry strings that you can use in the registry check action.

  • Checks for the presence of Google Chrome.
    "HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Google\Update\Clients\{8A69D345-D564-463c-AFF1-A69D9E530F96}"

  • Checks that the Google Chrome version is greater than or equal to the value specified.
    "HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Google\Update\Clients\{8A69D345-D564-463c-AFF1-A69D9E530F96}\pv" >= "120.0.6099.110"

  • Checks for the presence of Google Chrome. With this registry check, the Chrome version must be greater than or equal to 115.0.5790.110, and less than or equal to 120.0.6099.110
    "HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Google\Update\Clients\{8A69D345-D564-463c-AFF1-A69D9E530F96}\pv" >= "115.0.5790.110" AND "HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Google\Update\Clients\{8A69D345-D564-463c-AFF1-A69D9E530F96}\pv" <= "120.0.6099.110"

  • Checks that require one of multiple matches often require explicit grouping with parentheses to evaluate compound conditions correctly, especially with logical operators like 'AND' or 'OR' 
    ("HKEY_LOCAL_MACHINE\SYSTEM\ControlSet001\Software\test"."test"=="1") OR ("HKEY_LOCAL_MACHINE\SYSTEM\ControlSet001\Software\test"."test"=="2")

Recommended Action

Setting up a registry check:
The following example uses the registry checker to check for the presence of a Google Chrome.

  1. Log in to the BIG-IP APM Configuration utility
  2. Navigate to Access  ››  Profiles / Policies : Access Profiles (Per-Session Policies) 
  3. In the profile list, find the access policy you want to edit, then click Edit.
    The visual policy editor opens in a new window or new tab, depending on your browser settings.
  4. On a branch of the access policy, click the plus sign (+) to open the Add Item popup screen.
  5. Click the Endpoint Security (Client-Side) tab.
  6. Select Windows Registry and click Add Item.
    The Registry Checker action popup screen opens.
  7. In the Expression box, type the following:
    "HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Google\Update\Clients\{8A69D345-D564-463c-AFF1-A69D9E530F96}"
  8. Click Save to add the action to the access policy.
  9. Click Apply Access Policy in the visual policy editor to apply the changes.
