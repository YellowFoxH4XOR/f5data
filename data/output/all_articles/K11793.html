Known Issue

This is the result of a known issue. When restoring from a backup, if you clear the Restore Users and Groups Settings check box, users and groups will still be restored. This will overwrite the current user and groups configuration on the FirePass device.

F5 Product Development is tracking this issue as ID 327722 (formerly CR142388) and ID 317783 (formerly CR142388-1).

This issue was fixed in cumulative hotfix HF-70-1 issued for FirePass version 7.0.0, an cumulative hotfix HF-610-3-1 issued for FirePass version 6.1.0. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
