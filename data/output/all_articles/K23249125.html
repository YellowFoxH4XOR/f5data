Description

When migrating your BIG-IP configuration to a new system, you can take backups of your configuration using multiple methods. Using at least one method can provide a useful layer of redundancy. 

Environment

  • Moving the BIG-IP configuration across devices
  • Replacing an RMA system
  • Upgrading to a new BIGIP platform

Cause

While most migrations don't run into difficulty, a BIG-IP configuration can in some cases have a lot of interdependencies which can make moving the configuration difficult. 

Recommended Actions

To help safeguard important configuration elements, we recommend saving your configuration prior to a migration to external storage for safekeeping.

Examples:
  • User Configuration Set (UCS) - This option includes important configuration files, good for loading on the new system for a restore. 
  • Single Configuration Files (SCF) - This option is intended for adding specific selected configuration elements to F5 systems. Not as useful as a UCS but can be edited for use elsewhere.
  • QKview - This option is for sharing diagnostic data regarding a BIGIP system, but taking one prior to a migration is useful as it provides not only useful configuration data but also trending data and output of some useful tmsh and status commands if needed. 
 

Additional Information

When migrating systems, having backups can help if running into difficulties.
F5 recommends using a UCS in conjunction with taking a QKview prior, as this provides multiple backups using multiple methods in case of unexpected behavior.
