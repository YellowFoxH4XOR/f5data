Description
In BIG-IP ASM 13.1.0 and later, the BIG-IP system with ASM-only license supports simple load balancing features, up to 3 pool members. 
The  BIG-IP system with ASM-only license provides the following load balancing methods:
 

  • Ratio (member)
  • Ratio (node)
  • Round Robin

Environment

  • BIG-IP ASM 13.1.0 and later
  • BIG-IP system with ASM-only license

Cause
Change in behavior

None
