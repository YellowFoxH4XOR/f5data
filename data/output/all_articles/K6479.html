Topic

When a client or a local DNS server directs a DNS request to 3-DNS, 3-DNS attempts to probe the local DNS server to obtain path metrics.

In addition, all other F5 Networks devices that are equipped with a big3d agent (currently 3-DNS, BIG-IP, BIG-IP LTM, and BIG-IP GTM) and that are included in the configuration will probe the local DNS server. The metric information collected by the big3d agents is used to make wide area load balancing decisions based on network conditions between the big3d agent and the local DNS.

By default, big3d agents attempt to probe the local DNS in the following order:

Note: Once the 3-DNS successfully probes the local DNS, the 3-DNS does not perform additional probing attempts.

  • DNS_DOT query
  • DNS_REV querying (ICMP echo)
  • TCP port 53 socket connection
  • UDP echo

Because attackers commonly use similar probing techniques when looking for security vulnerabilities, 3-DNS probing may appear to be an attack or a prelude to an attack and may be reported by intrusion detection systems. Administrators that have noticed 3-DNS probing generally report the following symptoms:

  • Local DNS servers are being excessively pinged by the source addresses of F5 Networks devices
  • Border routers are intercepting an unusual number of pings from the source addresses of F5 Networks devices
  • Unusually large numbers of attempted connections to TCP or UDP port 53 appear to be an attack
  • Unusual methods are used to query a DNS server (DNS_REV or DNS_DOT)

The path metrics provided by 3-DNS probing are required to make dynamic load balancing decisions. When the default probing methods are not acceptable to the administrators of destinations that 3-DNS probes, you can try the following strategies to resolve the problem:

  • Change the probing protocol used by big3d agents.
  • Disable probing of specific destinations by creating an access control list.

Change the probing protocol used by big3d agents

The DNS_REV and DNS_DOT probing methods are generally least intrusive. These probing methods perform DNS queries to generate path metrics. These are also the first two methods used in a default configuration. If you have disabled DNS_REV or DNS_DOT as a probing protocol, you may wish to re-enable them temporarily to determine if they help to resolve probing complaints.

DNS_REV is a reverse-name lookup of the local DNS server IP address.

DNS_DOT performs an address lookup for the Internet root nameservers from the local DNS.

Disable the probing of specific destinations by creating an access control list

For more information about creating a probing access control list, refer to K2719: Preventing 3-DNS from probing specific local DNS servers.
