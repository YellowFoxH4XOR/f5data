Published

Applies to

Source

Description

How to find GID for the roles for remote authentication?
 

Environment

  • F5OS-A / F5OS-C
  • rSeries / Velos
  • User role GID

 

Cause

  • Informational

Recommended Actions

To find run confd command (login using "admin")

show system aaa authentication roles

                      REMOTE
ROLENAME        GID   GID     USERS
-------------------------------------
admin           9000  -       -
operator        9001  -       -
resource-admin  9003  -       -
tenant-console  9100  -       -

NOTE: above is the example output from F5OS-A v1.5.0
 

NOTE: below is the example output from F5OS-A v1.8.0

# show system aaa authentication roles
