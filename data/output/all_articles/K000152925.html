Description

  • How do I query virtual server connection counts using snmpget?
  • What are the limitations of connection monitoring using snmpget?

 

Environment

  • BIG-IP LTM
  • Virtual Server Connection monitoring

 

Cause

Have a need to monitor virtual server connection counts with possible additional criteria but don't know the snmpget command to send a bigip or how to facilitate monitoring the virtual server counts.

 

Recommended Actions

This is the command to run to get virtual server connection counts:

snmpget -On -c public <BIG-IP management IP> 'F5-BIGIP-LOCAL-MIB::ltmVirtualServStatClientCurConns."/partition/virtual_server_name"'

 

EXAMPLE QUERY ACTIVE BOX:

[root@ltm-lab-bigip1:Standby:In Sync] config # snmpget -On -c public 10.155.103.197 'F5-BIGIP-LOCAL-MIB::ltmVirtualServStatClientCurConns."/Common/python_http_vs"'

.1.3.6.1.4.1.3375.2.2.10.2.3.1.12.22.47.67.111.109.109.111.110.47.112.121.116.104.111.110.95.104.116.116.112.95.118.115 = Gauge32: 2

 

EXAMPLE QUERY STANDBY BOX:

[root@ltm-lab-bigip1:Standby:In Sync] config # snmpget -On -c public 10.155.103.196 'F5-BIGIP-LOCAL-MIB::ltmVirtualServStatClientCurConns."/Common/python_http_vs"'

.1.3.6.1.4.1.3375.2.2.10.2.3.1.12.22.47.67.111.109.109.111.110.47.112.121.116.104.111.110.95.104.116.116.112.95.118.115 = Gauge32: 0

 

Items to be aware of related to snmpget monitoring:

  • It is possible to monitor virtual server connections with snmpget but these are real-time query counts and can have a CPU impact if the query frequency becomes excessive.
  • A third-party script would need to be utilized to monitor this value as a function of time.
  • It would need to be polled by this third-party script to find periods of time where there are 0 connections or values above certain limits.
  • Example: If you want to look for periods of 0 connections for 5 minutes, you would need to poll at a reasonable connection interval and look for 5 consecutive minutes of 0 connections for a particular virtual server.
