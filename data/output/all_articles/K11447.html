Topic

In an access policy, you have the ability to check for the presence of one or more files that you specify on the client system. If the file is empty (or is a zero-byte file), the MD5 checksum will always be d41d8cd98f00b204e9800998ecf8427e. Entering 0 in the size field will result in an error during file checks on the client systems. In addition, the access policy will not work as you expect.

Configuring a file check action for an empty file

  1. Log in to the BIG-IP APM Configuration utility.
  2. Expand Access Policy.
  3. Click Access Profiles.
  4. Click the Edit link next to the Access Profile you want to check for a specific file.
  5. Click the (+) where you would like the file check to occur.
  6. Under Client Side Checks, select Windows File Check, Mac File Check or Linux File Check.

    A file checker configuration screen will appear.

  7. Click the Add new entry button.
  8. Populate the fields for the file you want to check.
  9. In the MD5 field, enter the following:

    d41d8cd98f00b204e9800998ecf8427e

  10. Click Save.
