Known Issue

The BIG-IP system fails to load the base configuration. This issue occurs when the following condition is met:

  • You configure audit logging for the Traffic Management Shell (tmsh) to Verbose or Debug using the Configuration utility

The configuration for tmsh audit logging is located on the System >> Logs >> Options page in the Configuration utility; it is set to Enable by default. Although this configuration drop-down box allows you to select Verbose or Debug, these values are not available in the tmsh utility and are therefore invalid values.

Impact

The BIG-IP system is unable to process traffic due to a configuration load failure.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system is unable to process traffic after a reboot or a manual configuration load
  • The mcpd process displays the status of the last configuration load attempt as base-config-load-failed:

    # tmsh show sys mcp

    -------------------------------------------------------
    Sys::mcpd State:
    -------------------------------------------------------
    Running Phase platform
    Last Configuration Load Status base-config-load-failed

  • The BIG-IP system fails to load the base configuration and logs an entry to the /var/log/ltm file and command prompt when performing a manual configuration load using the tmsh load sys config command. The entry appears similar to the following example:

    Syntax Error:(at line: 3) "audit" invalid value "description", expected one of the following: "disabled" "enabled"

  • The tmsh audit configuration is missing an assigned value (enabled or disabled). You can determine this value either by entering the tmsh list cli global-settings command or viewing the /config/bigip_base.conf file:

    cli global-settings {
    audit
    description none
    }

    The default tmsh audit configuration that does not trigger this issue should appear similar the following example:

    cli global-settings {
    audit enabled
    description none
    }

Workaround

To recover from this issue, you can reset the tmsh audit configuration to the default setting by removing the tmsh audit configuration stanza from the BIG-IP base configuration through the command line. To do so, perform the following procedure:

Impact of workaround: Perform the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Edit the /config/bigip_base.conf using a text editor of your choice.
  3. Locate the following configuration stanza:

    cli global-settings {
    audit
    description none
    }

  4. Remove the configuration stanza described in Step 3.
  5. Save the modification and exit the text editor.
  6. Load the BIG-IP configuration by entering the following command:

    tmsh load sys config
