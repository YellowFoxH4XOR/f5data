Description
The BIG-IP is sending below error messages after performing the delete action:

“Cannot delete the only accessgate () in use. Please delete the oam server ()”

Environment

  • Removing BIG-IP virtual server
  • APM module is deprovisioned
  • APM AAA Oracle Access Manager profile

Cause

This error occurs when the BIG-IP APM module is deprovisioned, and within the APM configuration, there was a AAA Oracle Access Manager Profile with a F5 Virtual Server attached as accessgate. When APM module is removed, the APM AAA Oracle Access Manager remains in the bigip.conf file causing that BIG-IP to think the virtual server is still in use in the APM AAA Oracle Access Manager profile.

Recommended Actions

In order to fix this error, the bigip.conf file needs to be edited manually and remove the APM AAA Oracle Access Manager profile.
  1. Go to cd /config directory and find the bigip.conf file.
  2. Then create a backup file with below command:

cp bigip.conf bigip-backup.conf.bak

  1. Edit the bigip.conf file from VI using:

vi bigip.conf

  1. Once you are on VI editor search for APM AAA Oracle Access Manager profile and it will show a similar config to this one:

apm aaa oam profilename {
    access-server-hostname
    access-server-name
    access-server-port 6052
    accessgates {
        accessgatename{
            encrypted-password
            vs-names { VS name }
        }
    }
    admin-id
    admin-password
    global-access-protocol-passphrase
    transport-security-mode simple
} 

  1. Hit the Insert to access the edit mode and then remove the apm aaa oam profile config.

Save the bigip.conf file.
type :wq!

  1. Then verify BIG-IP configuration, which should be come without errors:

     #tmsh
    #load sys config verify

  1. And last step load the new config:

load sys config
