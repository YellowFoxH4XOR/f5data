Known Issue

The BIG-IP system may drop packets for a virtual server using a dynamic Bandwidth Control (BWC) policy.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server with a dynamic BWC policy.

    Note: BWC policies are static, by default; the Dynamic setting is disabled.

  • The dynamic bandwidth control policy has a category configured with a Max Category Rate using a percentage value.
  • The category's Max Category Rate percentage is a lower value relative to the Maximum Rate Per User rate of the policy.

Impact

The BIG-IP system may drop packets for connection flows using the BWC policy and category.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Virtual servers that use an affected BWC policy configuration may experience dropped packets.

Workaround

To work around this issue, you can configure the category rate in an absolute value that is a higher value relative to the Maximum Rate Per User value that is configured in the BWC policy.

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.
