Description

You would like to change an admin account password and for some reason you don't have access to GUI. To modify it from CLI you have two options:

  • tmsh
  • bash

Environment

  • BIG IQ
  • BIG IP 

Cause

None

 Recommended Actions 

To modify the admin password with tmsh you can use:

tmsh modify auth user admin prompt-for-password 

To modify the admin password in a bash you can use:

passwd admin

In both cases you will get the prompt to insert a new password.
