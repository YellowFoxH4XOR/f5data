Following is an example of an expected result for a port negotiation between a BIG-IP switch and a third party Layer 2 switch. In this example, the negotiation is for both Port Speed (10/100 Mb/sec) and Duplex (Half/Full).
 
BIG-IP3rd Party SwitchResultSpeed
AUTOAUTOSUCCESSMAX CAPABLE
MANUALMANUALSUCCESSMAX CAPABLE
MANUALAUTOFAILN/A
AUTOMANUALFAILN/A

Note: This example assumes that you are using the appropriate Ethernet cable. Additionally, both the BIG-IP and the 3rd party switch must be configured to use auto-negotiation for both speed and duplex (Half/Full).

The port negotiation result is defined as follows:

Column 1

Specifies the configuration (auto-negotiation or manual configuration) for BIG-IP's port negotiation.

Column 2

Specifies the port negotiation configuration (auto-negotiation or manual configuration) for the 3rd Party switch.

Column 3

Displays the result (success or failure).

Column 4

Displays the best possible speed as a result of the setting.
