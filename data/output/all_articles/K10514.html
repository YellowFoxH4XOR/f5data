K10514: Unable to reload an ARX 4000 after temperature threshold has been exceeded

Type
Known Issue
Published
2009-10-27
Updated
2023-01-05
Status
Legacy Content
Applies to
  • Legacy Products
  • ARX: 5.0.1, 5.0.0
Source
https://my.f5.com/manage/s/article/K10514

This is the result of a known issue. If the internal temperature for an ARX 4000 system has exceeded the 45 degrees Celsius (114 degrees Fahrenheit) threshold, all NSM processors will be marked as Failed if the ARX system reboots. A reload will fail even if the temperature has returned below the threshold. As a result, the ARX system will not reload properly until the system has been power cycled.

Important: The ARX system will continue to operate normally with an exceeded temperature threshold until the system is restarted, as the NSM processors are not marked as Failed.

When the threshold is exceeded, the ARX system will log a message similar to the following in the traplog file:

- tempFail (740) slot 2, proc 0  : Slot temperature too high slot:2 proc:0

Additionally, if the ARX system is configured to send SNMP traps, an SNMP trap message similar to the following is sent:

Group:       chassis
Event:       temperature-failure (ID: 740)
Total Events:1

Time(UTC):   2009-08-06T00:24:48.832

Events:
 Message: Slot temperature too high slot:2 proc:0

If the ARX system is rebooted, the reload will fail and the show processor command will display the NSM processors as Failed similar to the following:

Additionally, when the reload fails, an SB2 Temp Alert message similar to the following is logged to the pxlog.log file:

PXLOG: [cpu2]  HW Status bit 29 (SB2 Temp Alert) is in incorrect state.

F5 Product Development tracked this issue as ARX ID 36114 and it was fixed in ARX version 5.0.5. For information about upgrading, refer to the ARX release notes.

Workaround

Once the temperature threshold has been exceeded, for the ARX system to reload properly, you must ensure the temperature is below the threshold and power cycle the ARX system.

Note: If physical access to the ARX power button is not possible, F5 Networks Technical Support may be able to perform a remote power cycle via a console or network connection to a running ARX-4000. For information contact F5 Technical Support.
