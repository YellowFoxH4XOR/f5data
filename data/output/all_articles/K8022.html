Topic

The X Display Manager Control Protocol (XDMCP) is a network protocol that communicates between an X Display Manager (XDM) and an X server.

Note: Some examples of applications that use XDMCP are Cygwin/X, Exceed, and Reflection X.

XDMCP uses UDP to negotiate X sessions and TCP once sessions are established. Since FirePass Application Tunnels do not support UDP application traffic, Application Tunnels cannot be used to access XDMCP applications.

You can access XDMCP applications through a Network Access connection, but you may need to disable Network Address Port Translation (NAPT) in order to support this. By default, XDMCP is not compatible with Network Address Translation. XDMCP embeds IP address information into the IP datagram payload, but Network Address Translation does not modify payload data. Some XDMCP applications have configuration settings to work around this limitation. If your application does not offer these settings, you will need to disable NAPT on the FirePass controller. You can disable NAPT by clearing the Use NAPT to access LAN check box on the Network Access: Global Settings page. Disabling the NAPT setting will affect all Network Access connections, and also requires additional routing configuration on your network. For more information about disabling NAPT, refer to the FirePass Controller Administrator Guide.

Note: If you are using Reflection X software, you may need to use Direct mode instead of Broadcast mode when connecting to an SDM through the FirePass controller. For more information about these modes, refer to your vendor documentation.
