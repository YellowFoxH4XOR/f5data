Known Issue

The BIG-IP system may fail to preserve the router flag when sending neighbor discovery messages.

This issue occurs when the following condition is met:

  • The BIG-IP system uses a VLAN group configuration.

When the host on one VLAN sends a neighbor advertisement message with the router flag set, the VLAN group code may fail to preserve the flag in the proxied response.

Impact

Certain clients (such as Windows clients) lose router information and may be unable to send traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Certain clients may be unable to send traffic.
  • Packet captures indicate that the BIG-IP system fails to preserve the router flag in the neighbor discovery message.
