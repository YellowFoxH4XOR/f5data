K000139941: Unable to Configure NTP, Timezone, and DNS Settings from CM

Type

Published
2024-06-07
Updated

Status
Legacy Content
Applies to

  • BIG-IP Next LTM: 20.2.0
Source
https://my.f5.com/manage/s/article/K000139941

Description

When you attempt to configure NTP, Timezone, and DNS settings for a tenant deployed from CM, you are unable to configure them.


Environment

  • BIG-IP Next Central Manager


Cause

It is by design for bigip next instance on Rseries/Velos , NTP/DNS option is not available on CM.

It need to be configured from rseries/velos.


Note: The NTP/DNS option is only for BigipNext Instance running on VE.


Recommended Actions

None
