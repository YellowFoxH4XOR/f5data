K241: Known Issue: The standby unit will configure a floating self IP address if it does not have its own self IP address

Known Issue

This is most likely the result of a known issue. An address conflict will result when the following sequence of events occurs:

  • You create a new self IP address and floating self IP address for BIG-IP so that it can access a new network.
  • You add a new monitor for a node on the new network.
  • Before you configure a self IP address for the network on the standby unit, you synchronize the active unit's new configuration to the standby unit.

Under these circumstances, the standby unit will use the floating self IP address as its self IP address for the network, which means that when you run config sync, both units will have the same IP address configured at the same time. This causes a self IP address conflict.

F5 Networks Product Development tracked this issue as CR28124 and CR41777.

Workaround

To avoid this problem, always configure a self IP address for the network on the standby unit before you configure a self IP address on the active unit.
