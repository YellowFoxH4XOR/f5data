K000135343: While Deploying Topology getting Deployment Error [OrchestratorConfigProcessor]

Type
Support Solution
Published
2023-07-01
Updated
2024-04-02
Applies to
  • F5 App Protect
  • F5 SSL Orchestrator: 15.1.X, 15.1.9, 15.1.2, 15.1.1, 15.1.0
Source
https://my.f5.com/manage/s/article/K000135343

Description:

BIG-IP SSLO throws deployment error when modifying topology and directly deploying the changes.
[OrchestratorConfigProcessor] Deployment failed for Error:[BaseHAConfigProcessor(GeneralSettingsHAConfigProcessor)] Error: [SSLOSetupWorker]
 

Environment:

  • BIG-IP SSLO
  • Orchestrator Guided Configuration
  • Configuration Utility


Cause:

BIG-IP SSLO configuration getting error when directly deploying the changes instead of following the full guided configuration.  
 

Recommended Action:

  1. After making changes select Save and Next.
  2. At the end of the topology guided configuration select Deploy. 

Additional Information:

None
