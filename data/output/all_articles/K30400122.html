Description
TMM crash with core file happens after upgrading to 15.1.4.1 or 16.1.x. 
Under certain conditions, TMM may send duplicated SSL alerts while processing encrypted connections.

Environment

  • Fatal SSL error
  • Software Upgrade

Cause
 BUG ID 1065789-1 : TMM may send duplicated alerts while processing SSL connections.

Recommended Actions

It is fixed in 16.1.2.1 and 15.1.5.1.
You may refer this article (K84205182) for BIG-IP update and upgrade guide.
