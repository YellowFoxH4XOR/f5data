Description

Unable to access BIG-IP GUI (Configuration utility) after upgrade. 

  • bigstart status command indicates:
    • tomcat process not running
    • httpd process not running

Environment

  • BIG-IP upgrade from 11.5.3 to 12.1.0

Cause
The tomcat and httpd processes not running

Recommended Actions

Restart the tomcat and httpd services.
  1. Log in to the BIG-IP command line
  2. run the following commands:
    bigstart restart httpd
    bigstart restart tomcat
Additional Information

The 'admin' password may need to be reset. For information, refer to K13121: Changing system maintenance account passwords (11.x - 15.x)
