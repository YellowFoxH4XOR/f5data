K000157268: GTM/DNS may not send probes to monitor destination target

Type
Support Solution
Published
2025-11-03
Updated
2025-11-03
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.5.1, 17.1.1
Source
https://my.f5.com/manage/s/article/K000157268

Description

GTM/DNS may not send probes to monitor destination target.

Environment

  • GTM/DNS
  • Translation addresses

Cause

There are actually only two GTMs at the site, but four GTM devices are configured due to the extra network link on each GTM.

    devices {
        GTM_A_1 {
            addresses {
                192.0.2.1 {
                    translation 10.10.10.10
                }
            }
        }
        GTM_A_2 {
            addresses {
                192.0.2.2 {
                    translation 10.10.10.10
                }
            }
        }
        GTM_B_1 {
            addresses {
                192.0.2.3 {
                    translation 10.10.10.20
                }
            }
        }
        GTM_B_2 {
            addresses {
                192.0.2.4 {
                    translation 10.10.10.20
                }
            }
        }
    }

The misconfiguration will disrupt the GTM matrix and prevent some devices from identifying the GTM as their own box.

If multiple devices are defined for the same box, the code will not work as designed or expected.
With this configuration, gtmd becomes confused and may not send probes to monitor destination target.

Recommended Actions

Correct the configurations that show two devices for each GTM.

    devices {
        GTM_A {
            addresses {
                192.0.2.1 {
                    description GTM_A_LINK_1
                    translation 10.10.10.10
                }
                192.0.2.2 {
                    description GTM_A_LINK_2
                    translation 10.10.10.10
                }
            }
        }
        GTM_B {
            addresses {
                192.0.2.3 {
                    description GTM_B_LINK_1
                    translation 10.10.10.20
                }
                192.0.2.4 {
                    description GTM_B_LINK_2
                    translation 10.10.10.20
                }
            }
        }
    }
