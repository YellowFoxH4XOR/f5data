K15749: Resetting a lost or forgotten admin password on the LineRate system

Topic

You should consider using this procedure under the following condition:

  • You have lost or forgotten the admin password for the LineRate system.

Description

User information on a LineRate system, including the admin account, is stored in the startup-config file, which you can view using the show startup-config command. For example, the line containing the admin account user information would be similar to the following example:

username admin secret encrypted "$2a$04$Ila36O/IVlnNViJ37zJjw.qKQl3idkgx8baGY7me4cbp66K4P/BiS" uid 2000

In the previous example, the second field displays the user account name (admin).  The double-quoted fifth field in the previous example is the encrypted form of the admin user's password. If you have lost or forgotten your password, you need to reboot the LineRate system from a properly formatted flash drive or DVD, mount the LineRate filesystem, and use a text editor to overwrite the current admin user account password.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have physical access to the LineRate system.
  • You have to download the appropriate LineRate software and create a suitable USB flash drive or DVD.

    Note: You may need to modify the BIOS on your LineRate system to boot from the installation media.

  • You have knowledge of either the vi or pico text editors.

Procedures

  • Booting the LineRate system from the USB flash drive or DVD installation media
  • Mounting the LineRate filesystem
  • Editing the startup-config file to modify the admin password

Booting the LineRate system from the USB flash drive or DVD installation media

Note: For information about creating the USB flash drive or DVD installation media, refer to the Installing to a Local Disk on a Dedicated Server section of the Getting Started Guide for your version of LineRate. For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Impact of procedure: This procedure requires you to reboot the LineRate system, which disconnects all active sessions.

  1. Insert the LineRate installation media into your LineRate system.
  2. On your keyboard, use the Ctrl+Alt+Del key combination to gracefully reboot the LineRate system, and boot into the LineRate installation media.

    Note: The device may appear to hang during boot. Allow a few minutes for the boot procedure to complete.

  3. On the first screen, you are presented with choices to: upgrade, install, or run live. Ignore all of the choices, and choose CANCEL on the bottom right of the menu. This takes you to the Bash shell.
  4. Depending on the LineRate version, you may be required to log in. The user name is admin and the password is changeme.

You should now be booted into the installation media, and can proceed to the next section to mount your installed LineRate filesystem and access your startup-config. At this point, you cannot pass traffic, because you are booted into only the installation media.

Note: You can run the same procedures on a VMware virtual environment. Please refer to VMware documentation on relevant products for information about booting from a removable drive or an ISO image file on a host system. To change the boot order, you may need to change the VMware virtual BIOS settings.

Mounting the LineRate filesystem

Impact of procedure: You will access the filesystem that stores your LineRate system and configuration files. Make sure you avoid corrupting system or configuration files.

  1. From the Bash shell, check the name of the LineRate filesystem you need to mount by typing the following command:

    ls /dev/ufs

    For example, you might see output similar to the following:

    LROS73ca226929be4901rootfs

  2. To mount the LineRate filesystem, use the following command syntax:

    mount /dev/ufs/<LineRate filesystem> /mnt

    For example, to mount the filesystem named LROS73ca226929be4901rootfs, type the following command:

    mount /dev/ufs/LROS73ca226929be4901rootfs /mnt

  3. If you do not have, or are already using the mount directory, create another mount point.

    For example, to create a mount point called /tmp/mnt, type the following command:

    mkdir /tmp/mnt

Editing the startup-config file to modify the admin password

Impact of procedure: Incorrect syntax in the startup-config file can prevent the configuration from loading. If that occurs, you must repeat the procedure.

  1. To change the working directory to the directory containing the startup-config file, use the following command syntax:

    cd /mnt/persist/<LineRate version>/home/linerate/data

    For example, on a system running LineRate 2.4.1, type the following command:

    cd /mnt/persist/2.4.1/home/linerate/data

  2. To back up the current startup-config file, type the following command:

    cp startup-config startup-config-SOL15749.save

  3. Using either vi or pico, locate the "username admin" line in the startup-config file. This line should appear similar to the following example:

    username admin secret encrypted "$2a$04$PyXWdbffSXx4aXW9lzd5V.cR4eFdUkbd7ApiBTgfIxNFBCyl2WzZ2" uid 2000

  4. Replace the keyword "encrypted" with the keyword "clear", and then replace the quoted encrypted string with the word "changeme".

    For example, the original line appears similar to the following:

    username admin secret encrypted "$2a$04$PyXWdbffSXx4aXW9lzd5V.cR4eFdUkbd7ApiBTgfIxNFBCyl2WzZ2" uid 2000

    The modified line appears similar to the following:

    username admin secret clear "changeme" uid 2000

    Note: After you reboot the system and log in, the startup-config will still display the clear text password. You must use the write command to save the configuration in encrypted format.

  5. Save your changes and exit the text editor.
  6. To unmount the LineRate filesystem, type the following command:

    cd; umount /mnt

  7. To restart the LineRate system, type the following command:

    reboot

    Note: You may need to change the boot order in your system BIOS to boot from the LineRate system again.

  8. Log in to the LineRate system with the user name admin and the password changeme.
  9. To enter Configuration Mode, type the following command:

    configure

  10. To change the admin password to a secure password, use the following command syntax:

    username admin secret <your password>

    For example, to set the password to the word linerate, type the following command:

    username admin secret linerate

    Note: Remember to change the password to something more secure.

  11. Remove the installation media
