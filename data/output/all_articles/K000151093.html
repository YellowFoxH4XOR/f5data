Description

Viprion blade is offline after upgrade, service mcpd, lind and devmgmtd keep restarting

  • 3 of 4 blades show inoperative or offline after upgrade
  • /config 100% used
  • configuration failed load

 

Environment

  • APM Provisioned
  • Multiple unused EPSEC packages
  • Viprion

 

Cause

Unused EPSEC Packages filled /config, leading to failed config loading.

 

Recommended Actions

Remove unused EPSEC Packages from the current active blade and wait for the changes to propagate to other blades.

None
