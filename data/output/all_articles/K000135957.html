Description

You've set up a new Tenant, deployed it, and configured a network for it. However, it's not reachable via the GUI and CLI.

You can however reach it from F5OS via virtual console using:

bash# virtctl console tenant1

Here, tenant1 is the tenant name you have created. Additionally, the service called system_api_svc_gateway is UP and running. See how to verify its status and steps to follow if it's not running .

Environment

  • F5OS
  • Newly set up tenant unreachable via GUI or CLI, but reachable via virtual console
  • NO LICENSE prompt on tenant via virtual console
  • system_api_svc_gateway is UP

Cause

The likely cause is an incompatibility between the Tenant image you selected and your F5OS platform. Installing an incompatible image leads to the symptoms mentioned above.

Recommended Actions

In order to verify that this is indeed the cause, check the output of the following command in the F5OS CLI:

F5OS CLI# show tenants tenant tenant1

Look for "state image-version" or "state image" - this will show you the version. Now find the model of your device (this is in rXXXX or rXXXXX format, X resembling a number, usually on a sticker on the device) and compare it to F5OS hardware/software support matrix. This article lists the Tenant image versions compatible with various F5OS platforms.

If you find that the version you installed is not listed in compatible images for your platform, delete the tenant and deploy a new one on one of the versions supported.

Additional Information

To check the state of system_api_svc_gateway, you can use this command:

bash# docker ps --filter 'Name=system_api_svc_gateway' --format "{{.Names}}: {{.Status}}"

If the service is in other state than "UP", please check New created Tenant is showing "NO LICENSE"
