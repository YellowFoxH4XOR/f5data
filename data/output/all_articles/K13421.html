Issue

Error Message

0107006a:3: External monitor program /config/monitors/<monitor name> is invalid, cannot be outside of monitor directory

In this error message, note the following:

  • <monitor name> is the name of the external monitor you are attempting to create.

For example:

0107006a:3: External monitor program /config/monitors/sample_monitor is invalid, cannot be outside of monitor directory

Message Location

You may encounter the previous error message in the following location:

  • The BIG-IP GTM external monitor configuration screen of the Configuration utility

Description

This message occurs when the following condition is met:

  • You specify an explicit path to the monitor file when attempting to create an external monitor.

Note: This issue does not apply to BIG-IP LTM monitors.

Impact

The Configuration utility does not allow you to create the monitor until you remove the explicit pathname.

Recommended Actions

F5 recommends that you remove the explicit pathname from your monitor configuration. For example, when attempting to create an external monitor, enter sample_monitor as the path to the monitor file instead of /config/monitors/sample_monitor.
