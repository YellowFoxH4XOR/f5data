Description

NTP servers are configured on the BIG-IP but the time is drifting or not syncing up with NTP servers and is causing other issues such as:

  •     ConfigSync failures
  •     Kerberos Authentication failures
  •     SAML Authentication failures

Environment

  • BIG-IP
  • Network Time Protocol (NTP)

Cause

Root Dispersion is a measure of potential error between the NTP server to the Root NTP Server.

The BIG-IP will only synchronize its timing if the Root Dispersion is less than 1s.

This typically happens because the NTP server offering time has lost connection to its upstream authoritative time servers, or these themselves are offering replies with high dispersion. Dispersion is measure of error and it increases the longer you don't have a reply from a server with good time.

Recommended Actions
  1. Investigate the NTP server and upstream Root NTP server to see why it is handing out poor quality time.
