Current Connection Table

To display the BIG-IP VIP current connections table, type the following command:

For version 3.0 through 4.6.4

bigpipe conn dump

For version 2.0 through 2.1.4

bigpipe dt

This table specifies the client and server IP addresses connected through the VIP in the following format:

client:ip:port > VIP:ip:port > NODE:ip:port

Number of Current Connections

To count the number of current connections, you can type the following command:

Note: The last letter in the command is a lower case L.

For version 3.0 through 4.6.4

bigpipe conn dump | wc -l

For version 2.0 through 2.1.4

bigpipe dt | wc -l

This command sends the output of the bigpipe conn dump or bigpipe dt command to the wc shell utility where wc -l displays the total number of lines in the output. Subtract 1 from this number, as the first line of the output is a heading line.
