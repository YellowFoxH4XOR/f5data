Description

After re-deploying one unit, the Sync errors out with the following message:

Sync error Caught configuration exception (0), Values (/Common/f5-tap-ingress-aws-global) specified for firewall offbox service api (/Common/f5-tap-ingress-aws-global fps): foreign key index (os_FK) do not point at an item that exists in the database

Environment

  • BIG-IP LTM
  • AWS
  • BIG-IP HA

Cause

Unknown at the time of publication.

Recommended Actions
 

Since the only reference to this object (/Common/f5-tap-config-aws-global) is in the mcp_module.xml we need to perform an mcpd forceload on the Active Unit and then (if config sync is still not working) on the Standby Unit. 
  1. To create a null file with the file name forceload in the /service/mcpd directory, enter the following command:

    #touch /service/mcpd/forceload

  2. To restart the BIG-IP system, enter the following command:

    #reboot
