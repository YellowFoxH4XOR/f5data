Security Advisory Description


Use-after-free vulnerability in the skb_segment function in net/core/skbuff.c in the Linux kernel through 3.13.6 allows attackers to obtain sensitive information from kernel memory by leveraging the absence of a certain orphaning operation. (CVE-2014-0131)

Impact

Attackers may be able to obtain sensitive information from kernel memory.

Security Advisory Status

F5 Product Development has assigned IDs 480446, 480687, and 480688 (BIG-IP, BIG-IQ and Enterprise Manager) to this vulnerability, and has evaluated the currently supported releases for potential vulnerability.
