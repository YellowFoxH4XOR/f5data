K11323212: TACACS is not working for BIG IQ, error: User has no roles or group associations

Type
Support Solution
Published
2021-05-11
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K11323212

Description

Authentication to BIG-IQ with  remote TACACS fails with error in GUI:
User has no roles or group associations

Configuration of user group under System> User management> User groups contains strings similar to:
Attribute : F5-LTM-User-Info-1 = admin
Value:  1

Environment

  • BIG-IQ Centralized Management
  • TACACS remote authentication
  • User Groups configured

Cause
Wrong configuration of user group parameter used under System> User management> User groups
 

Recommended Actions

  1. Review configuration of user groups  System> User management> User groups
  2. Set proper Attribute and value   in the configuration of user group
  3. Example strings showuld be changed as following
    Attribute : F5-LTM-User-Info-1 = admin
    Value:  1

    to

    Attribute : F5-LTM-User-Info-1
    Value:  admin
  4. Press Save and close
  5. Test authentication  via remote user by login to the device

Additional Information

NOTE: Do not use the equal sign (=) in the Attribute or Value boxes.
