Known Issue

This is the result of a known issue. When the BIG-IP GTM is configured with pinger monitors, such as the TCP Half-Open, Gateway ICMP, ICMP, and UDP monitors, the system will send the probes multiple times at each probe interval, depending on the value of the Probe Attempts setting. This behavior occurs even if the first probe returns successful. For example, using the default value of 3 for the Probe Attempts setting, three probes will be sent at each probe interval even if the first probe returns successful. This behavior is undesirable as it causes additional load on both the BIG-IP GTM and the probed systems.

F5 Product Development tracked this issue as CR101171, and it was fixed in BIG-IP GTM 9.4.6. For information about upgrading, refer to the BIG-IP GTM release notes.

This issue has been fixed in Hotfix-BIG-IP-9.4.5-HF1 issued for BIG-IP 9.4.5. You may download this hotfix or later versions of this hotfix from the F5 Downloads site.
