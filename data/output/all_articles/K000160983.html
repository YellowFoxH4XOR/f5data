K000160983: Unable to license F5 Insight server

Applies to

Description

Disconnected license activation fails with the error:

"Invalid acknowledgement file: missing signedReport field."

Attempting connected license activation without a proxy may appear to work, but the license remains inactive and the system displays:

License Activation Required. Activate your license to continue using F5 Insight Services.

Environment

  • Product: F5 Insight for ADSP (BIG-IP)
  • Version: 1.x
  • Condition: System does not have internet access (air-gapped environment)
  • Licensing method: Disconnected (offline) mode using the Disconnected Mode Licensing Tool

Cause

The Disconnected Mode Licensing Tool is required to generate the necessary signed report for offline activation. Attempting offline activation without this tool results in a missing signed report, causing the process to fail.

Answer/Recommended Actions

To successfully activate an F5 Insight server license in a disconnected (offline) environment:

  • Generate the License Report:
    • Use the Disconnected Mode Licensing Tool to generate a license report from the F5 Insight server. This report contains required host and license data.
  • Transfer and Submit the Report:
    • Manually transfer the license report to a system with internet access.
    • Submit the license report to the F5 licensing server using a tool such as Postman or cURL. For example,

      Note: Refer to Manage licensing in disconnected (air-gapped) environments on CloudDocs for the latest API information.

      curl -X POST \
      -H "Content-Type: application/json" \
      -H "Authorization: Bearer <JWT_LICENSE_TOKEN>" \
      -d @telemetry-report.json \
      -o license-manifest.json \
      "https://product.apis.f5.com/ee/v1/entitlements/telemetry"

      Parameters:

      • <JWT_LICENSE_TOKEN> — Your F5 license token (JWT format received from F5)
      • @telemetry-report.json — The report downloaded from the F5 Insight UI
      • license-manifest.json — The output file containing the license acknowledgment
  • Obtain the Signed License Report:
    • Download the signed license report returned by the F5 licensing server.
  • Upload the Signed Report:
    • Manually upload the signed license report back to the F5 Insight server to complete the entitlement and activate the license.

Note: The signed report cannot be generated solely with the F5 Insight server and the JWT license file; the Disconnected Mode Licensing Tool is required for this process.

Note: For connected environments, the process is automated if the server has outbound connectivity to F5 licensing endpoints.

Additional Information

  • In connected mode, F5 Insight automatically validates the license and exchanges reports with the F5 licensing server.
  • In disconnected mode, all data transfers (license report and signed report) must be performed manually.
  • If the offline activation process fails, ensure all steps above are followed and the Disconnected Mode Licensing Tool is used.
