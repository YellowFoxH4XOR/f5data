K6082: BIG-IP DNS provides persistence records for a wide IP after a pool or data center is disabled

Topic

If persistence is enabled for a wide IP and the pool or data center is disabled, the Drain Persistent Requests variable causes the BIG-IP DNS (formerly known as BIG-IP GTM) system to provide persistence records for the wide IP until the persistence TTL times out. As a result, the BIG-IP DNS system may provide persistence records for a wide IP after a pool or data center is disabled.

You can disable the Drain Persistent Requests variable to terminate persistent requests immediately after disabling a pool or data center. To do so, perform one of the following procedures:

BIG-IP DNS (12.x and later) and BIG-IP GTM 11.5.0 - 11.6.1)
  1. Log in to the BIG-IP DNS/BIG-IP GTM Configuration utility.
  2. Navigate to DNS > Settings > GSLB > General.
  3. In the GSLB section, clear the Drain Persistent Requests check box.
  4. To save changes, click Update.
BIG-IP GTM 10.x - 11.4.1
  1. Log in to the BIG-IP GTM Configuration utility.
  2. Navigate to System > Configuration > Global Traffic > General.
  3. In the Configuration section, clear the Drain Persistent Requests check box.
  4. To save changes, click Update.
