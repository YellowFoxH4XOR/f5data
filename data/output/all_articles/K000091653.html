K000091653: nginx plus doesn't create configmap with custom config given in values.yaml

Type
Support Solution
Published
2022-07-12
Updated
2026-07-30
Source
https://my.f5.com/manage/s/article/K000091653

Description

  • You are installing Nginx PLUS Ingress controller using Helm following guide Installation with Helm
  • Prior to rolling out the deployment, you define custom config values in values.yaml File. 
  • Such custom config could be to increase 'max-worker-connections' to 4096 and 'client-body-buffer-size' to 500m
  • While the instillation completes successfully, ConfigMap created by Helm for Nginx Ingress has empty data and does not reflect your specified custom config
  • There are no messages to indicate that the instillation completed with the default values as opposed to your custom config

Environment

  • Nginx Ingress controller
  • Helm

Cause

Ingress Nginx Plus value-plus.yaml file has minimal details and when specifying custom values, these custom config needs to be included in certain format as shown below.

 controller:
  nginxplus: true
  image:
    repository: nginx-plus-ingress
    tag: "2.2.2"
https://github.com/nginxinc/kubernetes-ingress/blob/main/deployments/helm-chart/values-plus.yaml

Recommended Actions

  • When one requires helm to configure Nginx Plus Ingress with a custom value, we would need to include "entries" under "config" as shown below.
  • Custom config must also be specified from within curly brackets '{}' and each line must be terminated by comma ',' except the last entry. Please refer the example below

Example 

controller:
  nginxplus: true
  name: ingress-controller
  image:
    repository: <your-masked-container-registry-endpoint>
    tag: "2.2.2"
  replicaCount: 1
  config:                   #   <---   new line config 
    entries: {                                 #    < --  "entries"  and curly bracket
      enable-underscores-in-headers: "true",
      max-worker-connections: "4096",              # <---   comma for each line 
      worker-rlimit-nofile: "4096",
      proxy-buffering: "on",
      proxy-read-timeout: "600",
      proxy-connect-timeout: 60s            # < ---   NO,  comma 
      }                                      #  <----     < --  curly bracket
    serviceAccount:
      imagePullSecretName: simply-secret
