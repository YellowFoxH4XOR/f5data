Known Issue

Certificate Revocation List Distribution Point (CRLDP) authentication may fail for Lightweight Directory Access Protocol (LDAP) type Certificate Revocation List (CRL) entries.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured for CRLDP authentication.
  • LDAP type CRL entries are retrieved from the client's certificate.

Impact

User authentication fails, causing web resources to be inaccessible.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After upgrading your system to BIG-IP 11.6.1 HF1, user authentication fails.
  • In the /var/log/apm file, you observe error messages that appear similar to the following example:

    warning apd[<pid>]: 0149015e:4: <session_id>: CRLDP Auth agent: CRL lookup failed for LDAP url 'ldap::::389//crl.certificate.../..../certificaterevocationlist?certificateRevocationList' reason 'Invalid CRLDP URL

Resolution

Status

F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

There is no workaround for this issue. However, you can configure distribution point types other than LDAP for the client's certificates. If multiple distribution points are present in the client's certificates, ensure that distribution point types other than LDAP are first evaluated.
