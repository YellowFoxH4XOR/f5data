Description

You have an application that sends requests with varying JSON body sizes, ranging from small to large. Some of these requests are flagged as illegal due to violations, while others are not, even though they contain the same violations. Interestingly, as the request body size increases, the violations are no longer triggered, and the requests are passed to the backend as legal.

On further checking the ASM logs, you can see the following occurrences.

Jul 21 11:15:39 bigip.example.local emerg perl[22898]: 01310003:0: ASM out of memory error: event code X262 Exceeded maximum memory assigned for XML/JSON processing
Jul 21 11:15:45 bigip.example.local emerg perl[22898]: 01310003:0: ASM out of memory error: event code X262 Exceeded maximum memory assigned for XML/JSON processing

Environment

  • BIG-IP ASM
  • XML/JSON memory exhaustion 

Cause

This is due to XML processing engine memory exhaustion. 

Recommended Actions

Ensure that sufficient memory is allocated to properly parse XML and JSON requests. The default values are generic and may not suit all environments, so they should be adjusted according to the application's behaviour.

Refer K22526837: Error Message: ASM out of memory error: event code X242/X260 Exceeded maximum memory assigned for XML/JSON processing for more details on this and how to adjust the parameters.
