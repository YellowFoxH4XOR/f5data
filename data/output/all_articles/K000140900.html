Description

After changing the self ip for the GTM device and changed the server IP address in the GTM server configuration as well, you found the old IP was still showing in the monitor result when checking the virtual server in GUI or tmsh show gtm server.

For example, the message like: 

Reason: Monitor /Common/TCP_443_monitor from 10.10.10.10 : connect: success search result true

In the message example, 10.10.10.10 was the previous IP but now has been removed from self IP and server IP list.

Environment

  • BIG-IP DNS
  • GTMD

Cause

The actual IP that performs the monitor task has already changed to the new IP. As the monitor Reason field is only updated when the vs status change (up->down down-up) or system/gtmd restart, thus the display old IP is expected.
