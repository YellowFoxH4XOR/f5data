K000148407: SNMPv3 alerts for SSL certificate expiration monitoring not working

Type
Support Solution
Published
2024-11-27
Updated
2024-11-27
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000148407

Description

Preconfigured SNMPv3 alerts for SSL certificate expiration monitoring are not reaching the specified destination server.

Environment

  • SNMPv3 trap
  • BIG-IP LTM
  • SSL certificate monitoring

Cause

The Engine ID is not set

Recommended Actions

  • Confirm the unique SNMPv3 engine ID on your BIG-IP system.
  • Configure the SNMPv3 trap destination with the unique engine ID.

Additional Information

None
