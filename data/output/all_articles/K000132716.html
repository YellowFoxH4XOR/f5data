K000132716: Remote AD auth does not work on BIG-IQ.

Type
Support Solution
Published
2023-05-25
Updated
2024-07-04
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.2.0, 8.3.0, 8.1.0
Source
https://my.f5.com/manage/s/article/K000132716

Description

You lost the ability to log in to the BIG-IQ device using AD(ldap), the following errors can be seen:

/var/log/secure:

Feb 17 11:03:13 SOMEHOSTNAME err sshd[9183]: error: PAM: Authentication failure for SOME_USER from 192.168.139.244

Feb 17 11:03:47 SOMEHOSTNAME err sshd[9183]: error: PAM: Authentication failure for SOME_USER from 192.168.139.244

Environment

  • BIG-IQ 8.1.0
  • AD remote auth

Cause

Unknown.

Recommended Actions

Switch remote auth method from AD to ldap:

tmsh modify /auth source type ldap

Additional Information

None.
