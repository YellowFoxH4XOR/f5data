Description

You would like to validate the installed SSL Orchestrator RPM on your system.
 

Environment

SSL orchestrator RPM
 

Recommended Actions

To determine the installed RPM version of your SSL Orchestrator system:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

 

1. On the CLI, type the following command:

restcurl -X POST /shared/iapp/package-management-tasks -d '{operation: "QUERY"}'

 

2. Obtain the block id from the response from Step 1, construct it with the following command and type it.

restcurl -X GET /shared/iapp/package-management-tasks/<id from response of above request>

 

The installed SSL Orchestrator RPM displays in the "packageName" attribute and the version displays in the "release" attribute.
