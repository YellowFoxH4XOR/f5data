Issue

Error Message

01070088:3: The requested object name (<name>) is invalid

In this error message, note the following:

  • <name> is the name used when creating a new self IP address

For example:

01070088:3: The requested object name ($elf !P) is invalid.

Message Location

You may encounter this message in the following locations:

  • The Configuration utility
  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You attempt to create a self IP address using the Traffic Management Shell (tmsh) or Configuration utility
  • You include one of the following special characters in the name:

    [space] ! @ # $ % ^ & * ( ) " '

Impact

Users are unable to create a self IP address.

Recommended Actions

Avoid using any of the aforementioned special characters when creating a new self IP address.
