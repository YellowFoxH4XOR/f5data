Known Issue

The Enterprise Manager system may list the BIG-IP 11.x status as impaired.

This issue occurs when the following conditions are met:

  • The target BIG-IP system contains any of the following configuration objects:
    • Request Adapt profiles
    • Response Adapt profiles
    • Diameter Endpoint profiles
    • IPv6 Leasepools
    • SSO SAML
    • LDAP Authentication Certificates

Impact

The Enterprise Manager system is unable to manage the remote device.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H409307 on the Diagnostics > Identified > Medium screen.
  • The Enterprise Manager system is unable to manage the remote device
  • The Enterprise Manager system marks the affected device status as impaired
  • The Enterprise Manager system logs error messages indicating the relevant configuration object to the /var/log/ltm file. For example, the following error message indicates an issue with the Response Adapt profile:

    04010568:3: Error found on device 172.2.2.1 (UID: 2): get change control info: iControl error: 'iControl::OperationFailed - primary code:1(0x1) secondary code: 0(0x0) string: Executing script with args [/Common] [ltm.profile.responseadapt] [/Common/aResponseAdaptProfile] [list] , failed : can't eval proc: "script::run" "responseadapt" unexpected argument while executing "tmsh::list [split $cmd "."] $instance" (procedure "script::run" line 12) invoked from within "script::run" line:1'
