Description

GUI not loading Device Management Overview stuck in receiving configuration

Environment

-After upgrade

-14.1.5.4 - 14.1.5.5

-GUI not loading Device Management Overview

Cause

[WARNING][4529][01 Jan 2023 01:00:00 UTC][8100/tm/shared/bigip-failover-state BigipFailoverStateWorker] Failed to get device-groups from icrd: java.lang.Exception: Unable to process request /tm/cm/device-group. Service is unavailable.

Recommended Actions

Important: The BIG-IP system experiences a temporary traffic interruption as it recovers from the TMM restart, and devices configured as a high-availability (HA) pair may fail over. F5 recommends changing the Management memory size allocation during a scheduled maintenance window.


-Provision memory to LARGE as per K26427018

-Allow restjavad to use extra memory from MGMT


Run the following two commands, in sequence:


  tmsh modify sys db restjavad.useextramb value true


  bigstart restart restjavad
