K3748: Using the First Time Boot/Setup utility on a 3-DNS Controller (or BIG-IP with the 3-DNS module) to make changes to a previous configuration

Topic

The purpose of the Setup utility is to write the initial configuration files.

You can also use the Setup utility to make configuration changes. When used on a system with an existing configuration, the Setup utility rewrites configuration files, thereby deleting the existing configuration.

Before you use the Setup utility on any configured system, make a full backup of the configuration files.

Note: For instructions about how to back up configuration files on BIG-IP 4.5 through 4.6.4, refer to K3135: Backing up and restoring BIG-IP or 3-DNS configuration files.

Important: F5 recommends that you do not use the Setup utility's DNS (D) option on any 3-DNS systems that are already configured, because it overwrites all existing zone files with the default, empty zone files.

Starting in version 4.5.11 and 4.6.3, 3-DNS will display a warning screen if you attempt to use the DNS option; however, prior versions do not display a warning. It is important that you do not inadvertently choose this option.
