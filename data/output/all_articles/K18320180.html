Message Location

You may encounter this message in the following locations:

  • /var/log/audit log file
  • /var/log/webui.log file
  • /var/log/tomcat/catalina.out file
  • Configuration utility

Description

This message may occur when all of the following conditions are met:

  • While attempting to configure the f5.radius iApp in a partition other than the Common partition, you selected different load balancing methods for the radius accounting and authorization pools.

Impact

You would not be able to complete the configuration of the f5.radius iApp using different load balancing methods for the two pools.

Recommended Actions

In order to complete the f5.radius iApp configuration without the error, you should select the same load balancing method for both pools. If you require different load balancing methods for each of the two pools, create the pools before deploying the f5.radius iApp template and select use existing pool from within the template.
