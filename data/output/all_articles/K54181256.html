Description

These are the following secure ways for the requirement below.
  • You want to enable "Check a maximum number of parameters" in  "HTTP protocol compliance failed" for all URLs except specific URLs.
  • Application has some specific URLs that have a huge number of parameters such as 50k.
  • You don't want to increase the value of "Check a maximum number of parameters" to such as 50k.
  • You want to allow the specific URL including a huge number of the parameters over the security setting such as 500 "Check a maximum number of parameters", however, the URL should be configured to detect/block attack signatures. 

Environment

  • BIG-IP ASM
  • HTTP Request including a huge number of the parameters

Cause
None

Recommended Actions

Please attempt to set 'Apply content signatures and detect threat campaigns' from Header-Based Content Profiles for the specific allowed URL.
  1. On the GUI go to Security  >  Application Security > URLs > Allowed URLs
  2. Click on Create button for a New Allowed HTTP URL
  3. Change from Basic to Advanced from the drop-down menu next to Create New Allowed URL
  4. On the Header-Based Content Profiles set, type the header name and value that you want to apply and select "Apply content signatures and detect threat campaigns". 
    • Request Header Name: Content-Type 
    • Request Header Value: *json*
    • On Request Body Handling: Select "Apply content signatures and detect threat campaigns"
  5. Click  Add
  6. Click  Create
  7. Apply changes
