Topic

The BIG-IP APM RADIUS AAA server configuration supports only the Password Authentication Protocol (PAP) encryption method.

If the remote RADIUS server is configured to use a different authentication protocol, authentication fails.

For more information about configuring RADIUS AAA servers for BIG-IP APM systems, refer to the RADIUS Authentication and RADIUS Accounting chapters of the BIG-IP Access Policy Manager: Authentication and Single Sign-On guide (11.5.0).
