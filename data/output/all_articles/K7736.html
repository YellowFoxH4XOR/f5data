K7736: A delay in traffic forwarding may occur when using hardware SYN cookies and full PVA acceleration on BIG-IP 8400 and 8800 platforms

Topic

If you enable Hardware SYN Cookie Protection on a full PVA-accelerated virtual server located on a BIG-IP 8400 or 8800 platform, there may be a delay of three to five seconds before traffic is forwarded.

Note: This behavior is by design. Additionally, only the 8400 and 8800 platforms exhibit this behavior, as they are the only platforms that contain the PVA10, which allows for the use of hardware SYN cookies.

The delay occurs if the server pushes content to the client instead of the client pushing content to the server. The PVA10 expects the client to send the first request with content to establish the TCP window size, which is used to open the connection to the server with the same TCP window size. If the client opens the connection and does not push content to the server, but the application is designed for the server to push content, there is a slight delay before traffic is forwarded since the TCP window size has not been established yet. This configuration causes the server to issue a TCP Zero Window probe to the BIG-IP LTM after a timeout of three seconds, which introduces the delay in establishing the connection.

F5 Networks Product Development introduced an enhancement in BIG-IP version 9.4.7 as CR81797, that allows an administrator to adjust the window size used by PVA10 accelerated virtual servers to speed up the connections.

You can access the new variable through the command line and bigpipe utility. To do so, perform the following procedure:

  1. Log in to the command line.
  2. Use the following bigpipe command syntax:

    bigpipe Pva.SynCookies.ServerWindow = <number>

    Note: The default value for the server window is 0 (zero). The variable supports values from 0 (zero) to 65,000. You should set this variable high enough so that the back-end server tries to send data.

Note: For more information regarding this enhancement and BIG-IP version 9.4.7, refer to the BIG-IP Local Traffic Manager and TMOS version 9.4.7 Release Notes.
