Description

I want to know why the label "app_type" is being added automatically while I am creating an HTTP Load Balancer via API calls.

Environment

  • F5® Distributed Cloud

  • HTTP Load Balancer

Answer/Recommended Actions

The app_type label is automatically assigned to the created LB when enable_api_discovery is included in the object definition. It will take the name and namespace name to create it.

Here is an example:

- name: my-httplb
- namespace: my-ns

The result will be prefix+namespace+name

"ves.io/app_type": "ves-io-my-ns-my-httplb"

 

Additional Information

The corresponding app_type label is added in the same fashion when enabled API Discovery on an HTTP LB via the XC Console.

For more information, see API Endpoint Discovery and Schema Learning.
