Description

You notice that MacOS client devices get a message similar to the following when connecting to VPN via Edge Client:

Software update 7244.2023.828.1 is available. Do you want to download this update?

The version may differ from the one given in this example.

Environment

  • VPN
  • MacOS/OSX
  • BIG-IP APM

Cause

This is cosmetic and it is caused by the setting 'Component Update' set to Yes in the Connectivity Profile.

Recommended Actions

To configure so that BIG-IP Edge Clients do not automatically attempt an upgrade when connecting to a BIG-IP APM, you must set the connectivity profile Component Update settings to No. To configure this, perform the following procedure:
 
  1. Log in to the Configuration Utility.
  2. Go to Access > Connectivity / VPN.
  3. Select the connectivity profile that is associated to your network access virtual server.
  4. Select Edit Profile.
  5. Select Win/Mac Edge Client.
  6. For Component Update, select No.
  7. Select OK.
After this, download again the new Edge Client package for your MacOS by clicking on Customize Package ›› Mac and install it on the affected client. The software update pop-up will not appear anymore.

Note: Even if the Component Update setting in the Connectivity profile is set to No, some components, including Windows ActiveX components such as Host Control, InspectionHost, Machine Certificate Checker, and SuperHost, are updated automatically. For more information see: K15302: Understanding BIG-IP Edge Client Component Update behavior for Windows, macOS, and Linux CLI
