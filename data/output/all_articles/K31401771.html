Topic

You should consider using this procedure under the following condition:

  • You want to restrict access to the BIG-IQ user interface based on the remote client's source IP address.

Description

By default, the BIG-IQ system allows access to the user interface from all IP addresses. You can secure access to the system's user interface by allowing access from one or more trusted IP addresses.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have access to the BIG-IQ system's Advanced shell (bash) for access configuration.
  • You have access to the BIG-IQ system's user interface for access testing.

Procedures

Allowing access for one or more IP addresses

You can use the following procedures to allow user interface access from either a single IP address, a range of IP addresses, or a combination of both.

Note: Allow and deny entries are applied in the order they are defined within the configuration file.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Advanced shell (bash).
  2. Using a text editor, open the /etc/webd/webd.conf file.
  3. Find the section in the file beginning with the following text:

            # static assets
            location /ui {

  4. To allow access from a single IP address, use the following syntax:

    allow <IP address>;
    deny all;

    For example, to allow access from IP address 192.168.10.1, use the following syntax:

    allow 192.168.10.1;
    deny all;

    You can add more single IP address entries. For example, to allow access from IP addresses 192.168.10.1 and 192.168.10.10, use the following syntax:

    allow 192.168.10.1;
    allow 192.168.10.10;
    deny all;

  5. To allow access from a range of IP addresses, use the following syntax:

    allow <IP address>/<mask>;
    deny all;

    For example, to allow access from the range of IP addresses 192.168.20.1 through 192.168.20.254, use the following syntax:

    allow 192.168.10.0/24;
    deny all;

  6. You can allow both single and a range of IP addresses. For example to allow the single IP address 192.168.10.1 and the range of IP addresses 192.168.20.1 through 192.168.20.254, use the following command syntax:

    allow 192.168.10.1;
    allow 192.168.20.0/24;
    deny all;

  7. Save the configuration file.
  8. Restart the webd service by typing the following command:

    tmsh restart sys service webd
