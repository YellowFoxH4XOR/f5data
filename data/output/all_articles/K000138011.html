Description

IP Intelligence is a feature which uses third party database to check the security category of each IP. Once the IP address is detected as malicious in any of the security categories, IP intelligence has capability to alarm (log) or block or alarm (log) and block the IP. 

 

Environment

  • You have at least admin privileges.
  • You have GUI access of BIG-IP Next Central Manager
  • You already know the security policy name for which you would like to perform the changes.

Cause

Malicious traffic

Recommended Actions

Steps to follow:

  1. Login to the GUI of BIG-IP Next Central Manager
  2. Under Manage Security Policies, click on Go to security workspace.
  3. Select policies under WAF and select the policy for which you would like modify the IP Intelligence settings.
  4. Click on General Settings, by default IP Intelligence is enabled, if it is disabled you should enable it first.
  5. On left side of the page, look for Policy Editor at the bottom and click on it. You will see the policy in Json format.
  6. Click on the Json format of the policy and click ctrl+f and enter “ip-intelligence” to search IP Intelligence related configuration. You may also scroll the policy and look for IP Intelligence.
  7. Now let’s disable the alarm for a “Spam Sources” security category and leave block setting unchanged. For that look for below mentioned piece of configuration and change “alarm” from “true” to “false”

    Configuration before change.

    {

        "alarm": true, 

        "block": true,

        "category": "Spam Sources"

      }



Configuration after change.

    {

        "alarm": false,

        "block": true,

        "category": "Spam Sources"

      }



  8.  Once done click on save & deploy. You will see another pop up to add a comment and deploy. Click deploy.

  1. You may verify the changes by repeating step 6.
  2. Once done click on cancel and go back to the main page.
