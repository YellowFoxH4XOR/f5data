Known Issue

This is the result of a known issue. When accessing SharePoint 2007 through a reverse proxy, users may receive multiple error messages. The first error message may appear similar to the following example:

Line: 1, Char: 117, Error: 'Object expected' is displayed.

The user is prompted to click OK to continue, at which point they may receive another error message that appears similar to the following example:

Line: 231, Char: 2, Error: Permission denied

After the second error message, the user will not be able to access anything on the SharePoint 2007 server.

F5 Networks Product Development is tracking this issue as ID 317677 (formerly CR133905) for FirePass version 6.1.0.

This issue does not affect FirePass version 7.0.0.

This issue was fixed in cumulative HF-610-1 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.
