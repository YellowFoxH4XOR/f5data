Known Issue

Note: F5 licenses the SSL MAX TPS module as an add-on to the base BIG-IP system license. When this module is active, the license of the BIG-IP system does not enforce limits on how many SSL transactions per second the system can process. However, even if a BIG-IP system is licensed for the SSL MAX TPS module, the system can only process as many SSL TPS as the hardware platform allows. For example, the BIG-IP 3900 platform can process a maximum of 15 K SSL TPS.

Note: K represents the abbreviation for thousands, and G represents the abbreviation for billions.

This is the result of a known issue. The dashboard of BIG-IP systems licensed for the SSL MAX TPS add-on module reports an SSL TPS license limit of 4 G. For example, the dashboard of a BIG-IP 3900 system, which is licensed for the SSL MAX TPS module reports the following SSL TPS limits:

Platform Limit: 15 K tps
License Limit: 4 G tps

The above output is incorrect, as the dashboard should report that no SSL TPS license limit exists.

This issue is cosmetic; a BIG-IP system licensed for the SSL MAX TPS module will process as many SSL TPS as the hardware platform allows.

F5 Product Development is tracking this issue as ID 337372.
