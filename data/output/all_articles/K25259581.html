K25259581: Configuration error: In Virtual Server an http2 profile with enforce-tls-requirements enabled is incompatible with client ssl profile renegotiation must be disabled only occurs once when you apply multiple ssl profiles

Type
Support Solution
Published
2023-04-06
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K25259581

Description

If you have performed the workaround for Bug ID 794417 by disabling renegotiation for a client SSL profile, and then you add additional ssl profiles with renegotiation enabled to your virtual server, you might encounter a config-sync validation error on the BIG-IP. 

Environment

  • BIG-IP
  • Multiple client SSL profiles with renegotiation enabled
  • HTTP/2 profile
  • Workaround performed for Bug ID 794417

Cause

Cosmetic error

The BIG-IP does allows you to add profiles with renegotiation enabled without throwing an error.

Recommended Actions 

Disable renegotiation on all client SSL profiles.

Additional Information

None
