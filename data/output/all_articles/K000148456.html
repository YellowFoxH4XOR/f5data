K000148456: Error Message: The requested monitor parameter (/Common/Monitor_name 2 SNI_SERVER_NAME=) was not found.

Type
Support Solution
Published
2024-11-12
Updated
2024-11-12
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148456

Description

When creating a GSLB HTTPS monitor using the following REST API and subsequently attempting to add an SNI Server Name via the GUI, the following error may occur:

curl -vk --request POST https://<BIG-IP_HOST>/mgmt/tm/gtm/monitor/https \
-H "Content-type:application/json" -u admin:admin --data-raw '{
    "name": "<monitor_name>",
    "partition": "Common",
    "interval": 5,
    "timeout": 16,
    "sniServerName": ""
}'

01020036:3: The requested monitor parameter (/Common/<monitor_name> SNI_SERVER_NAME=<value>) was not found.

Environment

  • Monitor parameter
  • HTTPS monitor
  • Products and features
  • SNI_SERVER_NAME

Cause

The root cause of the issue is that objects created via the REST API and the GUI are stored differently, leading to inconsistencies when modifying parameters like the SNI Server Name through the GUI for monitors initially created by the API, and the PE team created the ID1701169 to track the issue.

Recommended Actions

To avoid this issue, ensure that the sniServerName field is included in the REST API declaration when creating a GSLB HTTPS monitor, even if it has no value. This allows subsequent modifications through the GUI without encountering errors.

curl -vk --request POST https://<BIG-IP_HOST>/mgmt/tm/gtm/monitor/https \
-H "Content-type:application/json" -u admin:admin --data-raw '{
    "name": "<monitor_name>",
    "partition": "Common",
    "interval": 5,
    "timeout": 16,
    "sniServerName": ""
}'
