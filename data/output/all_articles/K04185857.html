Description:

How to add a BIG-IP device to BIG-IQ using GUI (Graphical User Interface or Configuration Utility).

Since BIG-IQ version 8.3, we added a new configuration section in BIG-IQ "Devices--F5OS--Platform / Devices" where you will add the Host devices for Velos or rSeries, the tenants will be added under "Devices---BIG-IP Devices" as normal.

Note: Updated to include special consideration of the Velos and rSeries platforms.

Environment:

  • BIG-IQ 8.3 and 8.4
  • BIG-IP

Cause:

We need to be clear where we manage each type of BIG-IP within the BIG-IQ.

  • For VE, VCMP, Tenant, iSeries, and Viprion, we use the "Devices---BIG-IP Devices" as normal.
  • For Velos and rSeries hosts, we use the "Devices--F5OS--Platform / Devices" section.

Recommended Actions for VE, VCMP, Tenant, iSeries, and Viprion:

  1. Using GUI from BIG-IQ go to Devices > BIG-IP Devices.
  2. Click on Add Device(s) and fill out the information about:
IP Address
User Name (use Admin)
Password: BIG-IP's Admin password
  1. Finally, click on Add, and then it will ask you what configuration you want to import i.e., LTM, ASM, APM.

Recommended Actions for Velos and rSeries Hosts (not tenants):

  1. Using the GUI from BIG-IQ go to Devices > F5OS > Platform / Devices
  2. Click on Add VELOS / rSeries system and fill out the information about:
Device Name (hostname)Note: Use the F5OS controller floating IP
FQDN or IP Address
Username
Password

Additional Information:

Managing BIG-IP devices in this way (not importing all the configuration) will not have an impact on being able to to manage configuration from each BIG-IP directly.
