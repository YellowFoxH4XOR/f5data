Known Issue

This is the result of a known issue. Configuring a large number of virtual servers (such as 250 or greater) on the BIG-IP ASM system may cause a fatal error in the dcc process. As a result, the BIG-IP ASM bd process may fail to load.

The dcc process forwards security policy updates to the BIG-IP ASM bd process. The dcc process also contains the tsconfd thread, which subscribes to mcpd messages and processes BIG-IP ASM configuration updates. Since the tsconfd thread buffers virtual servers for the add_virtual_server command, it becomes overburdened, which causes the dcc to exit with error messages that appear similar to the following example:

tsconfd[21562]: [FATAL_ERR, Sun Jul 26 08:24:40 2009, 21562, dcc, tsconfd::add_arg_list, ] attempt to add arg past MAX_ARGS=1024 boundary

F5 Product Development tracked this issue as CR125718 and it was fixed in BIG-IP ASM version 10.1.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue was fixed in BIGIP-10.0.1-378.0-HF3 issued for BIG-IP version 10.0.1, and Hotfix-BIGIP-9.4.8-385.0-HF2 issued for BIG-IP version 9.4.8. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.
