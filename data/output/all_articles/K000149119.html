Description

The live update script is crucial for managing and troubleshooting updates in the BIG-IP ASM environment.  The following details are how to locate the live update script (liveupdatedb.script) and associated log (liveupdatedb.log) on a BIG-IP ASM appliance.

Environment

  • BIG-IP ASM

  • Live updates

  • asmqkview

Cause

None

Answer/Recommended Actions

You can view both the liveupdatedb.script and liveupdatedb.log log file from the command line of the BIG-IP appliance go to the /var/lib/hsqldb/live-update/ directory.

cd /var/lib/hsqldb/live-update

1. Look for the liveupdatedb.script file in the directory and view its contents using the following steps:

[root@gallery-big-ip-15-1-10-2:Active:Standalone] live-update # ls -la

total 3924
drwxr--r--. 4 tomcat tomcat  4096 Nov 5 05:52 .
drwxr-xr-x. 5 root  root   4096 Sep 8 2023 ..
-rw-r--r--. 1 tomcat tomcat   16 Nov 5 09:47 liveupdatedb.lck
-rw-r--r--. 1 tomcat tomcat 3976930 Nov 5 09:00 liveupdatedb.log
-rw-r--r--. 1 tomcat tomcat   411 Nov 5 05:52 liveupdatedb.properties
-rw-r--r--. 1 tomcat tomcat  8591 Nov 5 05:52 liveupdatedb.script <<----!!!
-r-xr-xr-x. 1 tomcat tomcat   819 Sep 7 2023 live_update_mark_active_installation.py

==> /var/lib/hsqldb/live-update/liveupdatedb.log <==

2. Use the Linux commands more, less or vi to view the contents of the /var/lib/hsqldb/live-update/liveupdatedb.log file.
