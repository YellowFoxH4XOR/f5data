Known Issue

In BIG-IP versions 4.0 through 4.5.12 and 4.6 through 4.6.4, the kernel is inefficient at loading very large configurations.

F5 Networks Product Development tracked this issue as CR42907 and CR49295. This issue was resolved in BIG-IP version 4.5.13 for the 4.5 software branch. Beginning in BIG-IP version 4.5.13, BIG-IP is optimized to better handle the process of loading very large configurations.

For information about upgrading, refer to the BIG-IP Release Notes.

This issue still exists in the 4.6 software branch.
