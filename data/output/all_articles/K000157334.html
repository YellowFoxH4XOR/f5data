Security Advisory Description

Under certain circumstances, BIND is too lenient when accepting records from answers, allowing an attacker to inject forged data into the cache. This issue affects BIND 9 versions 9.11.0 through 9.16.50, 9.18.0 through 9.18.39, 9.20.0 through 9.20.13, 9.21.0 through 9.21.12, 9.11.3-S1 through 9.16.50-S1, 9.18.11-S1 through 9.18.39-S1, and 9.20.9-S1 through 9.20.13-S1. (CVE-2025-40778)

Impact

A remote unauthenticated attacker can perform cache poisoning on a vulnerable system.

This vulnerability does not affect the following BIG-IP DNS configurations:

  • Listener (virtual server) with the Use BIND Server on BIG-IP setting disabled on the attached DNS profile.
  • Listener (virtual server) with the Use BIND Server on BIG-IP setting enabled on the attached DNS profile. However, the named configuration must include recursion no.

Mitigation

BIG-IP DNS

To mitigate this vulnerability, you can either disable BIND in the DNS profile if it's not required or ensure that recursion is set to no in the named configuration. To do so, perform one of the following procedures:

  • Disable the Use BIND Server on BIG-IP setting in the DNS profile
  • Change the recursion line to no in the named configuration file (recursion is set to no by default)

Disable the Use BIND Server on BIG-IP setting in the DNS profile

Impact of action: Disabling the BIND server can affect DNS configurations that use BIND as a fallback method (return to DNS) for resolution.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > Services > DNS.
  3. Select the applicable DNS profile.
  4. For the Use BIND Server on BIG-IP setting, select Disabled.
  5. Select Finished.

Change the recursion line to no in the named configuration file (recursion is set to no by default)

  1. Log in to the Configuration utility.
  2. Go to DNS > Zones > ZoneRunner > named Configuration.
  3. In the Options box, scroll down to the options section.
  4. Find the recursion yes; statement and replace it with recursion no;.
  5. Select Update.
