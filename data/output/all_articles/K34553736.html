Known Issue

When the system receives a Diameter Experimental-Result AVP response, the server-side flow is disconnected.

This issue occurs when all of the following conditions are met:

  • You have configured the virtual server with a Message Routing Diameter profile.
  • The Diameter server returns an Experimental-Result AVP response and no Result-Code AVP.

Impact

The BIG-IP system disconnects the server-side flow.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the Diameter server returns an answer message with an Experimental-Result AVP, but does not have a Result-Code AVP inside, then the system stops the server-side flow.

Workaround

To work around this issue, you can use an iRule to insert a Result-Code AVP in all Diameter answer messages.

Impact of workaround: The suggested workaround should not have a negative impact on your system.
