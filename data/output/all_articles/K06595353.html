Description

The main /var directory may become 100% full due to temporary TMSH files in /var/system/tmp/tmsh filled with orphaned directories and files.

  • Your BIG-IP system becomes unresponsive and unstable.
  • Output of the command below will display several directories and files similar to the following examples:  
    find /var/ -xdev -type f -exec du {} \; | sort -rn | head -15

    456152	/var/system/tmp/tmsh/KA3Asi/data
455584	/var/system/tmp/tmsh/dfyMMK/data
454928	/var/system/tmp/tmsh/HROX15/data
454560	/var/system/tmp/tmsh/jPDo9R/data
453600	/var/system/tmp/tmsh/gnKIrD/data
...

Environment

  • BIG-IP
  • /var directory
  • ssh sessions

Cause

Issue is due to a Bug ID 969345

Recommended Actions

To work around this issue:

  1. Manually delete the unused directories and files that have been orphaned in the /var/system/tmp/tmsh directories.
    You can use the shell script, /usr/local/bin/clean_tmsh_tmp_dirs that can be run by a root user to clean up excess temporary files in the /var/tmp/tmsh and /var/system/tmp/tmsh directories.

    Note: Performing the suggested workaround should not have a negative impact on your system.

  2. These files can build up if SSH sessions are disconnected while a tmsh command is running. Investigate any automated script and ensure it is not disconnecting from the system before the tmsh commands are completed.

Additional Information

For versions 11 and 12, see Bug ID 598443.
