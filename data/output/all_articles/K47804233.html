Known Issue

TCP handshakes may be delayed or time out when connecting to sockets in a TIME-WAIT state.

This issue occurs when all of the following conditions are met:

  • Your configuration includes one or more TCP virtual servers with an associated FastL4 profile.
  • You are using the SYN cookie protection feature.

    Note: For information about SYN cookies, refer to K14779: Overview of BIG-IP SYN cookie protection (11.3.x - 12.x).

  • An existing connection has finished, and the server side of the connection is currently in the TIME-WAIT state.

    Note: For information about TCP connection management, refer to K8082: Overview of TCP connection setup for BIG-IP LTM virtual server types.

  • A new TCP handshake request is received using the same socket as the one currently in a TIME-WAIT state.

Impact

TCP handshakes may be delayed or may eventually time out.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system continues sending TCP SYN packets when receiving an ACK from the remote client.
  • New TCP handshakes are intermittently delayed or time out.
