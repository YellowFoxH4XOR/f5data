Description

If Protocol Inspection auto update is enabled on BIG-IP which license was assigned from BIG-IQ, Protocol Inspection automatic updates is failing.

Log file output:
ERROR No production key file found.
ERROR No production key file found.
ERROR Command (openssl rsa -in none -out /tmp/tmpXXXXX -passin pass:xxxxxxxxxxx) failed.
ERROR Error: Exception caught in script. Check logs (/var/log/pi_hitless_upgrade) for details

 

Environment

  • BIG-IP license is assigned from BIG-IQ
  • Protocol Inspection automatic updates enabled

Cause

Under investigation

Recommended Actions

To remedy the issue, manually download and install the IPS update on BIG-IP.
