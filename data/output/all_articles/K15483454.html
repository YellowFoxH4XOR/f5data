Known Issue

The system displays unintelligible Tower ID information for BIG-IP PEM sessions.

This issue occurs when all of the following conditions are met:

  • Valid PEM sessions are established through the BIG-IP PEM system.
  • You attempt to view Tower ID information within the PEM session details by using either of the following methods:

    • In the Configuration utility, you navigate to Policy Enforcement > Subscribers > Active Sessions, and then filter the search by the Session-IP address.
    • In the Traffic Management Shell (tmsh), you use the show /pem sessiondb subscriber-id <ID> command syntax.

      Note: In this syntax, <ID> refers to the subscriber ID for the related PEM session.

Impact

Users cannot read the Tower ID information; however, this is a cosmetic issue and the BIG-IP PEM sessions are not affected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the Configuration utility, the system displays the PEM session's Tower column value as unintelligible characters.
  • In the tmsh utility, when using the show /pem sessiondb subscriber-id <ID> command syntax, the tower-id variable displays unintelligible characters.
  • The BIG-IP PEM sessions are not affected.
