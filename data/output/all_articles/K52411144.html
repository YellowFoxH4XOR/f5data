K52411144: Failed to get data from /mgmt/shared/fast/templatesets?userAgent=FASTGUI/NA: 404 Not Found

Type
Support Solution
Published
2022-03-03
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP Platforms
Source
https://my.f5.com/manage/s/article/K52411144

Description

1. Attempt to access to "iApps >> Application Services : Aplications LX -> F5 Application Services Templates" opens up a page with next error:

Error fetching templates: Failed to get data from /mgmt/shared/fast/templatesets?userAgent=FASTGUI/NA: 404 Not Found
{
  "code": 404,
  "message": "",
  "referer": "https://bigip/iapps/f5-appsvcs-templates/index.html",
  "errorStack": []
}


2. There are similar messages in /var/log/restnoded/restnoded.log as below:


/var/log/restnoded/restnoded.log severe: [RestOperationDispatcher] 'shared/fast/templatesets' not found. severe: [ErrorHandlingModule] RestOperation failed: "/shared/fast/templatesets?userAgent=FASTGUI/NA". {"code":404,"message":"","referer":"https://bigip.example.com/iapps/f5-appsvcs-templates/index.html","originalRequestBody":"","errorStack":[]}

Environment
 

  • BIG-IP v15
  • AS3
  • F5 Application Services Templates (FAST)
 

Cause

Possible cause 1:  AS3 is not installed

Possible cause 2:  You may need to restart restjavad and restnoded 



 

Recommended Actions

1. Make sure AS3 has been installed on the device and checking for a successful installation:

Downloading and installing the AS3 package

From GUI navigating to iApps > Package Management LX. Click Import and then select the RPM you downloaded.

After you have installed AS3, you can test for a successful installation by sending a GET request to the /info endpoint. For example, from your RESTful client, after entering your credentials, use GET to send https://(IP address of BIG-IP)/mgmt/shared/appsvcs/info.

You should see a response like the following:

           { "version": "3.8.0", "release": "2", "schemaCurrent": "3.8.0", "schemaMinimum": "3.0.0" }


2. Restart restjavad and restnoded 

          #bigstart restart restjavad restnoded

          
 

Additional Information
