Known Issue

This is the result of a known issue. TMM may core when the BIG-IP WebAccelerator pvac process generates HTTP 304 and 200 responses while retrieving or populating an object in RAM Cache.

The pvac process may generate and send an HTTP 304 response before the RAM Cache is able to intercept the HTTP 304 response and send an HTTP 200 response, serving the content from its cache. This timing issue primarily affects pipelined requests, when the pvac process attempts to process another pipelined request before the RAM Cache has finished with the previous request.

F5 Product Development tracked this issue as CR123497 and it was fixed in BIG-IP WebAccelerator 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

This issue was fixed in Hotfix-BIGIP-10.0.1-342.0-HF1 issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
