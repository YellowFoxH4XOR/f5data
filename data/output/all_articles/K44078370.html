Description

Access to the BIG-IP management port with default supported protocol.
GUI: HTTPS
CLI: SSH

Environment

BIG-IP, BIG-IQ

Cause

By design, BIG-IP and BIG-IQ only allows HTTPS protocol for GUI access and SSH protocol for CLI access.

Recommended Actions

None
