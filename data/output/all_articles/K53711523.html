Issue

Error Message

01140103:5: Watchdog touch enabled with 40 seconds.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The BIG-IP system reboots and the overdog process starts the system's high availability (HA) watchdog process. For example:

    01140100:6: Overdog daemon startup.
    01140103:5: Watchdog touch enabled with 40 seconds.

The overdog process monitors the HA table for failover actions and, when triggered, performs the configured action. 

Impact

None. This message is informational.

Recommended Actions

None
