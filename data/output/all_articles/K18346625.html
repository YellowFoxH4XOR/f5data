Policy Information

Certain forms of ISP link load balancing are no longer available in certain regions.

Please review the associated articles, and contact Support with any questions relating to eligibility or technical assistance.

  • K36385016: Inbound ISP link load balancing will use pool members for only one ISP link per data center
  • K15834: End of Life announcement for inbound and outbound cost-based link load balancing and inbound link path-based load balancing

If links are configured, these will be marked as unavailable (grey) and all resources in the same data center will be unavailable.

If a link is configured, you will need to remove it to access the resources in that data center.

In some instances, QOS LB may revert to a Round Robin behavior. If this occurs, you may re-enable this feature by changing the link cost coefficient to 0, then toggling the load balancing method to Round Robin and reverting back to QOS LB. This may need to occur after any Traffic Management Microkernel (TMM) restart.
