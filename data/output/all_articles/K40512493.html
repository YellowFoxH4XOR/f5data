Description

PROXY protocol will add to the header with additional information such as source IP address, destination IP address and port numbers to VIPs which are not using http protocol.
PROXY protocol is a protocol to transport information such as client's address across multiple layers of NAT or TCP proxies.

Environment

  • BIG-IP
  • PROXY protocol

Cause

None

Recommended Actions

BIG-IP does not have native support for PROXY protocol, which means that protocol profiles cannot read or write the PROXY Protocol data itself without the use of iRules.
BIG-IP can successfully load balance packets even when PROXY Protocol is used, but Client-SSL termination fails if the PROXY Protocol header is present in the TCP data stream.

If you require to read/add/remove PROXY protocol on BIG-IP, you can achieve it by using iRules. Information on this can be found on DevCentral.
