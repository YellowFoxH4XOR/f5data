Description

ASM sending logs to remote logging server with request_status="passed",response_code="0"

Environment

ASM

Remote log

Cause

This will happen when the request did not reach the webserver or we did not receive the response back from webserver.

Recommended Actions

Capturing packets between the F5 and the backend server will help identify the exact cause of the issue
