Known Issue

The virtual server may fail to redirect Citrix sessions through the BIG-IP APM system.

This issue occurs when all of the following conditions are met:

  • The virtual server has Citrix support enabled.
  • The virtual server has an assigned TCP profile.
  • The TCP profile associated with the virtual server has been modified and saved.

An internal system Citrix iRule is attached to the virtual server when Citrix support is enabled. If you modify the TCP profile, the Citrix iRule disconnects from the virtual server. As a result, the Citrix iRule will not rewrite the Citrix ICA file to redirect Citrix traffic through the BIG-IP APM system.

Impact

Users connecting through the BIG-IP APM system are unable to access Citrix.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Users are unable to access Citrix.
  • Analyzing the Citrix ICA file on the client shows the access server address is not pointing to the address of the virtual server.

Workaround

To work around this issue, you can re-establish the Citrix iRule connection to the virtual server. To do so, perform the following procedure:

Impact of workaround: Users that are already authenticated will need to logout and login again for the change to apply.

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Click Virtual Server.
  4. Click the virtual server name that you want to fix.
  5. Clear the Citrix and Java support check box.

    Note: In BIG-IP versions prior to 11.2.0, the check box is named Citrix Support.
  6. Click Update.
  7. Select the Citrix and Java support check box.
  8. Click Update.
  9. Repeat steps to 3 through 6 for each virtual server that is affected.
