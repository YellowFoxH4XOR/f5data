K11653: Persistence profiles compatible with the diameter profile

Topic

The universal inspection engine (UIE) and hash persistence profiles may be used in conjunction with the diameter service profile. You can apply the default universal or hash persistence profiles to a Diameter virtual server with no additional iRules or customizations required. However, you must configure the persistence attribute by selecting the appropriate value from the Persist Attribute menu in the diameter profile applied to the virtual server. The timeout value applied to Diameter connections is defined by the Timeout setting in the persistence profile. If you want to modify this setting, F5 Networks recommends creating a child universal or hash persistence profile and modifying that profile instead of modifying one of the default profiles.
