Description

  • When navigating into the User Management -> Users tab, error 400 (Bad Request) appears as a pop-up in GUI
  • Error messages:

The system returned an unexpected error (400 Bad Request). A pipeline processing error has occurred: ProtocolException (status:400, body:{"error":{"root_cause":[{"type":"illegal_argument_exception","reason":"Fielddata is disabled on text fields by default. Set fielddata=true on [_value.name] in order to load fielddata in memory by uninverting the inverted index. Note that this can however use significant memory. Alternatively use a keyword field instead."}

 

Environment

  • BIG-IQ CM

Cause

  • Under investigation

 Recommended Actions

Impact: Loss of full-text search functionality while the daemon is restarting.

Restart searchd process by executing:

# bigstart restart searchd
