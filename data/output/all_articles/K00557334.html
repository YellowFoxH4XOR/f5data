Topic

You should consider using this procedure under the following conditions:

  • You want to restore the default Advanced Shell (bash) prompt for your BIG-IP system.
  • The BIG-IP bash prompt displays bash-3.2#.
  • The system does not load the custom changes made to ~/.bash_profile.

Description

The default bash prompt for the BIG-IP system appears similar to the following:

[<username>@<hostname>:<traffic_state>:<config-sync_state>] <directory>#

For example, the default prompt appears similar to the following:

[root@MyBigip:Active:Standalone] config # 

When bash is invoked as an interactive login shell, it runs commands from the /etc/profile file, and then reads and runs commands from ~/.bash_profile. If the ~/.bash_profile file was modified or missing, your command prompt may appear similar to the following example:

bash-3.2#

You can change the prompt back to the default bash prompt by performing the following procedure.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have access to the BIG-IP bash.

Procedure

Restoring the default bash prompt for the BIG-IP system

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Regenerate the default ~/.bash_profile using the original skeleton file, by typing the following command:

    cp /etc/skel/.bash_profile ~/.bash_profile

    For the root account, type the following command:

    cp /etc/skel/.bash_profile /root/.bash_profile

  3. Reload the ~/.bash_profile file and restore the default prompt by typing the following command:

    . ~/.bashrc
