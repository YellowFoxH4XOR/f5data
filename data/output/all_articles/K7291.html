Known Issue

This is the result of a known issue. If you attempt to log on to the FirePass controller with a username that contains a non-ASCII or extended ASCII character, the logon will fail if the logon page is not configured to allow a choice of language.

The FirePass controller provides a customization option on the logon page for the user to select the character set for their session. When an administrator checks the Choice of language in logon page check box under the Advanced Customization section of the Device Management: Customization page, you will see a drop-down menu on the logon page, which allows you to select the character set used for your logon. This option allows you to see and enter characters from your native language. Additionally, by checking the Choice of language in logon page box, the administrator can specify a default character set for logons using the Default character set drop-down menu.

When the Choice of language in logon page is unchecked, however, the setting in the Default character set drop-down menu does not take effect. Since you will not be presented with a drop-down menu on the logon page, any characters in the username other than the basic ASCII characters (decimal values below 128) will cause a logon attempt to fail.

F5 Networks Product Development tracked this issue as CR67561 and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass Release Notes.

Additionally, a hotfix has been issued. For feature release version 6.0.0 of FirePass software, this issue was fixed in cumulative hotfix HF-600-11. You may download this hotfix or a later version of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about how to obtain a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

Check the Choice of language in logon page check box under the Advanced Customization section of the Device Management: Customization page, and select the appropriate language when logging in.
