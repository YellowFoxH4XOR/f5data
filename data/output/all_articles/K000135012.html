Description

You may notice that "no-dtlsv1.2" option is not added to client/server SSL profile automatically when direct upgrade to v17.1.0+ from v14/v15
 

Environment

 

・BIG-IP LTM

・Configure client/server ssl profile

・Upgrade to v17.1.0+ directly from v14/v15

 

Cause


This is tracked by ID 1305117 .


Recommended Actions

You can perform either of the followings :

・Manually enable "no-dtlsv1.2" option after upgraded to 17.1.0+

・Upgrade to 16.1.x first, then v17.1.0+

 

Additional Information

K36654540: After upgrade to version 16.x there were warnings: default option no-dtlsv1.2 set
