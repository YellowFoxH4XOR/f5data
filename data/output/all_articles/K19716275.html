Issue

Error Message

01670021:3: [<tmm>] LSN Pool <pool_name> has no usable translation address for DNAT

In this error message, note the following:

  • <tmm> indicates which tmm without a usable translation address
  • <pool_name> is the name of the affected Large Scale Nat (LSN) pool

For example:

01670021:3: [0.3] LSN Pool /Common/LSN_pool has no usable translation address for DNAT

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The /var/log/tmm file
Description

This message occurs when all of the following conditions are met:

  • You enable the carrier-grade network address translation (CGNAT) module on the BIG-IP system.
  • You configure a virtual server with an LSN pool.
  • The deterministic NAT pool on the affected Traffic Management Microkernel (TMM) does not have an available translation address for the connection.

For example, this issue occurs when the LSN pool is configured without enough translation addresses.

Impact

Source address translation for the virtual server using the LSN pool will fail when client connections use the designated TMM.

Recommended Actions

Using translation addresses with a small prefix size may not work well with deterministic NAT configurations on platforms with a large number of TMMs. You may be able to alleviate this issue by increasing the number of available translation addresses in the LSN pool.
