K09120223: Wrong traffic going through VPN tunnel

Type
Support Solution

2020-09-09

  • BIG-IP APM: 14.X.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K09120223

Description

Traffic that is supposed to remain on the local users home network is going across the tunnel

DNS query is forwarded successfully to clients DNS server

However, resolved IP is traversing VPN tunnel

Environment

  • DNS Relay Proxy
  • Edge clients below version 7.2.1
  • Split tunneling
  • APM v14.1.2
     

Cause

If hostname matches exclude domain scope, exclude routes are added for all IP addresses that are received as part of the resolution.
If another resolution for the same hostname results in different set of IP addresses, routes from first set are removed and overwritten with IPs from the second set.
Applications using IPs from 1st set may stop working suddenly.

This is due to ID 904617

Recommended Actions

Upgrade to Edge Client 7.2.1
