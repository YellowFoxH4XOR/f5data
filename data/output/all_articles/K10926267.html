Issue

Error Message

notice mcpd[<PID>]: 01071c6e:5: PKCS11d (re)initialized. Re-connecting to network-HSM PKCS11d.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process

For example:

notice mcpd[7177]: 01071c6e:5: PKCS11d (re)initialized. Re-connecting to network-HSM PKCS11d.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The pkcs11d process is restarting.

Impact

There is no impact. You can safely ignore this error message.

Recommended Actions

None
