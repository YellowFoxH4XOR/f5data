Description

Best Practices for changing/modifying administrative access to https on a Single NIC VE appliance.

Environment

Bigip VE on Azure/AWS deployments with a Single NIC.

Cause

By design a Single NIC deployment works best with administrative port 8443 for https access of the configuration utility. It is not recommended to change administrative access from the default port at this time.

Recommended Actions

Access the Single NIC deployment by port 8443. 

Additional Information-If using ansible, change the ansible playbook instead if reconfiguring port 8443.
-A Single NIC VE appliance's administrative access should only be changed in the case of an immediate security advisory, or as recommended by F5 support.
