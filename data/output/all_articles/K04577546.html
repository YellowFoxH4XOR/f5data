Description

You want to use the BIG-IP system to load balance connection requests across multiple SSH servers.

Environment

BIG-IP LTM

Cause

Expected behavior

Recommended Actions

Creating the SSH load balanced pool in the Configuration Utility/GUI:

  Log in to the Configuration utility.
  Go to Local Traffic > Pools.
  Select Create.
  In the Configuration drop down, select Advanced.
  For Name, enter the name of the pool.
  For Health Monitors, in the Available list, select the tcp_half_open monitor and move it to the Active list.
  Under Resources, for Load Balancing, select the preferred method.
  Note: F5 recommends that you use Least Connections (member).
  Under New Members add each ssh server as a new node, for service port enter the appropriate port or select ssh to use the default port 22.
