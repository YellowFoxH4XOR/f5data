K000149555: After upgrading to F5OS-C 1.8.0, REST API requests on port 8888 no longer work

Type
Support Solution
Published
2025-01-30
Updated
2025-01-30
Applies to
  • F5 Distributed Cloud Services
Source
https://my.f5.com/manage/s/article/K000149555

Description

In versions earlier than F5OS-C 1.8.0, a small set of API endpoints incorrectly functioned on port 8888 when not using the proper URI :8888/restconf/data

Environment

  •  F5OS-C
  •  Upgrade

Cause

ID572137

Recommended Actions

All API requests on port 8888 must now begin with "/restconf" instead of "/api."

For example:

From:

https://<ip-address>:8888/api/data/…

To:

https://<ip-address>:8888/restconf/data/…
