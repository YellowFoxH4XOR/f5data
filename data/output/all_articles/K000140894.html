K000140894: Installation Failed status on license offering from BIG-IQ

Type
Support Solution
Published
2024-08-29
Updated
2026-03-24
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.X, 8.3.0
Source
https://my.f5.com/manage/s/article/K000140894

Description

You recently applied a license to a BIG-IP from a catalog license offering on the BIG-IQ. The license applied successfully to the BIG-IP, but now, on the BIG-IQ, the license status for this BIG-IP reads "Installation Failed".

Environment

  • BIG-IQ
  • Flexible Consumption Program (FCP)
  • Catalog (CAT) key
  • License offering

Cause

The restjavad process on the BIG-IP is unhealthy (stopped, restarting, etc.). BIG-IQ relies on restjavad to communicate with the BIG-IP.

Recommended Actions

Confirm restjavad is up on the BIG-IP.

  1. From the command line of the BIG-IP run "tmsh show sys service restjavad".
    • If it returns a status of "run" proceed to the BIG-IQ for next steps.
    • If it returns a status of "down", start this process "tmsh start sys service restjavad". 
    • If issues persist, investigate further.
      • K000151194: Overview of troubleshooting restjavad memory issues
      • K000133258: Provisioning restjavad memory with provision.restjavad.extramb
      • K15436: Configuring the verbosity for restjavad logs on the BIG-IP system
      • K09827356: What is the amount of memory allocated to restjavad by default

    Reactivate this license offering for the BIG-IP.

    Important: This procedure is traffic impacting as services restart on the BIG-IP as it processes the license. F5 recommends performing this work during a maintenance window.

    1. On the BIG-IQ, navigate to Devices tab > License Management > Licenses
    2. Click on the Catalog key
    3. Click on the license offering
    4. In the Assignments list, check the box to the left of the BIG-IP with the "Installation Failed" License Status
    5. Select Refresh.
