What Happened?

  • We would like to lower that amount and be able to choose from which sites health checks will be performed.
  •  Changing frequency -volume -and site of health checks.

  • sample:

[root@server01 ~]#  cat /var/log/nginx/access.log | grep -i admin\/health.php | grep -i 2023\:11:\15\:[0-9][0-9] | wc -l response: 77

# Sample request:

[root@server01 ~]# cat /var/log/nginx/access.log | grep -i admin\/health.php | grep -i 2023\:11:\15\:[0-9][0-9]
- - - dummy-default-sni.example.com [11/Aug/2023:11:15:01 +0300] "GET /admin/health.php HTTP/1.1" 200 113 "-" "Envoy/HC" "x.x.x.x" CF5-Req-ID: -"
- - - dummy-default-sni.example.com [11/Aug/2023:11:15:01 +0300] "GET /admin/health.php HTTP/1.1" 499 0 "-" "Envoy/HC" "x.x.x.x" CF5-Req-ID: -"

 

Environment

  • Origin Pools
  • F5 Distributed Cloud HTTP Load Balancer
  • Health monitor

Resolution/Answer

Health check configuration would have a time "interval" as well, which decides the interval between two health check requests.
