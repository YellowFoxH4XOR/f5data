Known Issue

Requests or responses may not be delivered to plug-ins in some circumstances.

This issue occurs when all of the following conditions are met:

  • A virtual server is using an enabled plug-in (such as the F5 WebSafe module).
  • The plug-in disables processing for a request or response that should not be processed by the plug-in.

After a plug-in disables processing for a connection, subsequent requests or responses on the same connection may not be fully delivered to the plug-in.

Impact

Client or application connections using the affected plug-in may intermittently fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Client or application connections that use the affected plug-in are failing.
