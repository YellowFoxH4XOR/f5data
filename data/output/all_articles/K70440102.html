Known Issue

Connections with both RAM Cache and Client SSL profile allowing non-Secure Sockets Layer (SSL) traffic connection may stall under certain unusual conditions.

This issue occurs when all of the following conditions are met:

  • You have configured RAM Cache.
  • You have configured a Client SSL profile.
  • The virtual server also allows non-SSL connections.

Impact

The connection stalls until the client resets the connection or the sweeper expires the connection. The client may see an error response from the server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Connections with both RAM Cache and the Client SSL profile allowing a non-SSL traffic connection may stall under certain unusual conditions.
