Known Issue

This is the result of a known issue. The EUD utility may falsely report a Cavium SSL hardware failure even though all subtests report no errors or issues and a PASSED status.

This issue affects the following platforms, if the platform is running EUD version 11.1.0 and contains a Cavium SSL accelerator:

  • 1500
  • 3400
  • 3410
  • 6400
  • 6800
  • 8400
  • 8800

This issue affects the following platforms, if the platform is running EUD version 12.10.0 and contains a Cavium SSL accelerator:

  • 1600
  • 3600
  • 3900
  • 6900
  • 8900
  • 8950
  • 11000
  • 11050

The reported failure appears similar to the following example output:

Test Begin: Cavium SSL

Executing SSL test on device 0...
Soft Reset Test Result: PASSED
Microcode Load Test Result: PASSED
Register Read/Write Test Result: PASSED
Get BIST Reg Val Test Result: PASSED
Random Numbers Test Result: PASSED
RC4 Crypto Test Result: PASSED
HMAC Crypto Test Result: PASSED
3DES Crypto Test Result: PASSED
AES Crypto Test Result: PASSED
Mod Ex Crypto Test Result: PASSED
Key Memory and DMA Test Result: PASSED
Get Unit Enable Reg Val Test Result: PASSED
Get Exec Units Avail Test Result: PASSED
Request Unit Test (16) Result: PASSED
Request Unit Test (17) Result: PASSED
Request Unit Test (18) Result: PASSED
Request Unit Test (19) Result: PASSED
Get Chip CSR: PASSED
Get PCI CSR: PASSED
Get PCI Config Reg: PASSED
Test Complete: Cavium SSL: FAILED

If the report specifies that the Cavium SSL failed, verify the status of the subtests. If all of the subtests report a PASSED status, the Cavium SSL accelerator is not defective; the EUD utility incorrectly reported the accelerator as FAILED. You can safely ignore this issue. If any of the subtests indicate a FAILED status, an issue exists with the Cavium SSL accelerator and you should replace the unit.

F5 Product Development is tracking this issue as ID 413059. For more information, refer to the EUD release notes.
