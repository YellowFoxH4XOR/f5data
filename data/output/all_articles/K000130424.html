K000130424: Memory leak in ImageAgent process in the system_image_agent docker container

Type
Support Solution
Published
2023-01-01
Updated
2023-01-19
Applies to
  • F5OS
  • rSeries Platforms
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000130424

Description

The ImageAgent process in the system_image_agent docker container may encounter memory leak. When the leakage is severe enough it will affect the performance and the stability of the rSeries appliance and its tenants.
The following list of symptom is not exhaustive, and not all of the symptoms are applicable:
  • Tenants encounter unexpected failovers.
  • Multiple of daemons running within the Tenants may unexpectedly restart and may result in the creation of many different core dump files.
  • Different processes on the F5OS-A Host may unexpectedly restart.
  • The manageability of the tenant or the F5OS-A Host may be impacted.

Environment

  • F5OS-A
  • rSeries
  • system_image_agent
  • ImageAgent

Cause

1185577, 1190969

Recommended Actions

Run the following commands from an administrator Bash session:
1. Restart the system_image_agent docker container. 
[root@appliance-1(APPLIANCE-1) ~]# docker restart system_image_agent
2. Determine that the system_image_agent is up: 
[root@appliance-1(APPLIANCE-1) ~]# docker ps --format "{{.Names}} {{.Status}}" | grep system_image_agent
system_image_agent Up 7 minutes
3. Should the appliance or the tenants still encounter performance or stability symptoms, reboot the appliance: 
[root@appliance-1(APPLIANCE-1) ~]# systemctl reboot
