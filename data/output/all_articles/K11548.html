Known Issue

This is the result of a known issue. When the BIG-IP WebAccelerator is processing requests under a moderately heavy load, the test to determine whether a file should be excluded from RAM Cache may fail. As a result, PDF files that have been processed by the BIG-IP WebAccelerator may be inappropriately included in RAM Cache, and other files, such as images, may be inappropriately excluded.

Files should only enter RAM Cache if they have bypassed BIG-IP WebAccelerator processing and have been assigned a pv tag value of S10413, indicating that WebAccelerator processing has been bypassed. When this issue occurs, the BIG-IP WebAccelerator has not assigned the bypass pv tag to the affected requests. 

F5 Networks Product Development tracked this issue as CR137676 and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
