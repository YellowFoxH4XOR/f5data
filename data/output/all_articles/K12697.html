Topic

When you deploy BIG-IP VE, you must associate each virtual network adapter to a network connection on the host machine. The equivalent of this operation on a physical BIG-IP device is connecting a network cable to an interface on the BIG-IP system to a port on a switch or other network device.

As soon as the cable connection is performed on a physical BIG-IP device, the system negotiates a link with the peer device and the status of the relevant Traffic Management Microkernel (TMM) interface changes from down to up.

BIG-IP VE does not behave the same way. After a virtual network adapter has been associated with a network connection on the host, the system will show the corresponding TMM interface as UNINITIALIZED until that interface is assigned to a VLAN. Additionally, at this stage, the Configuration utility will also report that the TMM interface has no active media type associated with it, similar to the following example:

MAC Address         0:50:56:a0:d:f1
Availability        UNINITIALIZED
Active Media Type   none
Media Speed         10000
Active Duplex       half

You can safely ignore this behavior; it is expected. As soon as the interface is associated with a VLAN, the status of the interface changes to up, and the Configuration utility reports that the interface has a media type of 10GbaseT full, similar to the following example:

MAC Address        0:50:56:a0:d:f1
Availability       UP
Active Media Type  10GbaseT full
Media Speed        10000
Active Duplex      full

Note: This is a virtual interface in TMM, and will not reflect the media status of the physical interface on the host system.

Note: When you deploy BIG-IP VE, by default, the virtual machine guest environment will include three virtual network adapters: one for the management interface and two for the TMM interfaces. If your specific needs demand more TMM interfaces, you can add more virtual network adapters to the virtual machine guest environment. For more information, refer to K12149: Adding additional TMM interfaces to BIG-IP Virtual Edition.

Note: On BIG-IP VE, each time TMM starts, the system logs a superfluous error message for each TMM interface. For more information, refer to K12699: Error Message: Unsupported media setting 10000_T/full for interface <interface>.
