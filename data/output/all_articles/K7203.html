Known Issue

This is the result of a known issue. The HTTP::disable iRule command puts HTTP traffic filtering into passthrough mode. This command is useful when using an HTTP profile with an application that proxies data over HTTP. When the HTTP::disable command is issued on the server side of a connection, the client side of the connection is properly disabled, but the server side remains enabled. As a result, the connection will hang.

F5 Networks Product Development tracked this issue as CR75545, and it was fixed in BIG-IP LTM version 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
