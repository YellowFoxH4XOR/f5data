Issue

Error Message

notice mcpd[<PID>]: 010713c0:5: System state ready for hypervisor mgmt settings: (<Status>)

In this error message, note the following:

  • <PID> is the process ID for the mcpd process
  • <Status> is either true or false. 

This log message informs the user whether or not the Virtual Clustered Multiprocessing (vCMP) guest is ready to install the management network and hostname configuration proposed by the vCMP host.

For example:

notice mcpd[5930]: 010713c0:5: System state ready for hypervisor mgmt settings: (true)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The vCMP guest receives a management address or hostname from the vCMP host.

Impact

None

Recommended Actions

None
