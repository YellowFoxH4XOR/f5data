Description

Creating a new Pool with type A through GUI management, there is no Virtual Server shown in the drop-down list selection.

Environment

  • 12.1.5
  • BIG-IP DNS

Cause

The boundary "a thousand of" or "a sufficiently high number of Virtual servers in the configuration (~ 15,000) ".

Recommended Actions

Please use either of these two below Solution 

  1.  Use GUI to Create the Pool without the Virtual Server and then select the respective pool and check members. There click on manage to add the respective VS.   Please follow  the  path    DNS ›› GSLB : Pools : Pool List ›› Members : /Pool_test/ : A
  2. Use Command line , for example    tmsh create gtm pool a Pool_test members add { LTM1:/Common/VS_test1 }
