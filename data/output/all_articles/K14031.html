Topic

You should consider using this procedure under the following condition:

  • You want to import a new SSL certificate and key file using the TMOS Shell (tmsh), and then associate them to an SSL profile.

Description

The SSL certificate and key can establish secure connections when applied to SSL profiles. You can use these procedures to import the SSL certificate and key using the BIG-IP command line.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have command line access to the BIG-IP system.
  • You have the required files to import into the BIG-IP system as the SSL certificate and key.
  • You have the Secure Copy application to transfer files into the BIG-IP system.

Procedures

Importing the SSL certificate and key into the BIG-IP system

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Use the Secure Copy protocol (SCP) to transfer the new SSL certificate and key files to the BIG-IP system.

    Note: For more information about transferring files into the BIG-IP system, refer to K175: Transferring files to or from an F5 system.

    o Install the certificate to the /config/ssl/ssl.crt/ directory

    o Install the key to the /config/ssl/ssl.key/ directory

  2. Log in to tmsh by entering the following command:

    tmsh

  3. To install the SSL certificate, use the following command syntax:

    Note: To install the certificate and key files into a specific partition, run the cd /<partition> command.

    install /sys crypto cert <SSL-certificate-name> from-local-file <path-to-certificate-file>

    For example:

    install /sys crypto cert sol14031cert from-local-file /config/ssl/ssl.crt/sol14031.crt

  4. To install the SSL key, use the following command syntax:

    install /sys crypto key <SSL-key-name> from-local-file <path-to-key-file>

    For example:

    install /sys crypto key sol14031key from-local-file /config/ssl/ssl.key/sol14031.key

    To install the SSL key into FIPS, use the following command syntax:

    install /sys crypto key <SSL-key-name> from-local-file <path-to-key-file> security-type fips

    For example:

    install /sys crypto key sol14031key from-local-file /config/ssl/ssl.key/sol14031.key security-type fips

    To install an SSL key with a passphrase, use the following command syntax:

    install /sys crypto key <SSL-key-name> from-local-file <path-to-key-file> passphrase <passphrase>

    For example:

    install /sys crypto key sol14031key from-local-file /config/ssl/ssl.key/sol14031.key passphrase '%my#passphrase!'

    Note: If the passphrase includes special characters, you must enclose it within quotes.

  5. To verify that the SSL certificate has been successfully installed into the BIG-IP system, use the following command syntax:

    list /sys crypto cert <SSL-certificate-name>

    For example:

    list /sys crypto cert sol14031cert

    Note: If you install the SSL certificate properly, you can view the output of a list of SSL certificate attributes.

  6. To verify that the SSL key has been successfully installed into the BIG-IP system, use the following command syntax:

    list /sys crypto key <SSL-key-name>

    For example:

    list /sys crypto key sol14031key

    Note: If you install the SSL key properly, you can view the output of a list of SSL key attributes.

    To verify that the SSL key has been successfully installed into the FIPS card on the BIG-IP system, use the following command syntax:

    show sys crypto fips

  7. To save the changes, enter the following command:

    save /sys config

  8. To exit tmsh, enter the following command:

    quit

Note: You can either create a new SSL profile or modify an existing SSL to use the newly imported SSL certicate and key.

Creating a new SSL profile using the newly imported SSL certificate and key

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To create a new SSL profile, use the following command syntax:

    create /ltm profile <SSL-Profile-Type> <SSL-Profile-Name> cert-key-chain add { <Name> { cert <SSL-Certificate-Name> key <SSL-Key-Name> } }

    For example, to create a Client SSL profile with the name sol14031_profile, using the certificate and key imported as sol14031cert and sol14031key, enter the following command:

    create /ltm profile client-ssl sol14031_profile cert-key-chain add { sol14031 { cert sol14031cert key sol14031key } }

  3. After you create the required SSL profiles, save the change by entering the following command:

    save /sys config

  4. To exit tmsh, enter the following command:

    quit

Modifying an existing SSL profile using the newly imported SSL certificate and key

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To modify an existing SSL profile, use the following command syntax:

    modify /ltm profile <SSL-Profile-Type> <SSL-Profile-Name> cert-key-chain replace-all-with { <Name> { cert <SSL-Certificate-Name> key <SSL-Key-Name> } }

    For example, to modify a Client SSL profile with the name sol14031_profile, using the certificate and key imported as sol14031certNew and sol14031keyNew, enter the following command:

    modify ltm profile client-ssl sol14031_profile cert-key-chain replace-all-with { sol14031 { cert sol14031certNew key sol14031keyNew } }

  3. To view that the profile is using the new certificate and key then use the following command syntax:

    list /ltm profile <SSL-Profile-Type> <SSL-Profile-Name>

    For example, to list a Client SSL profile with the name sol14031_profile, enter the following command:

    list /ltm profile client-ssl sol14031_profile

  4. After you create the required SSL profiles, save the change by entering the following command:

    save /sys config

  5. To exit tmsh, enter the following command:

    quit
