Description

How to display a condensed list of all virtual servers with corresponding pools and pool member IP addresses on my BIG-IP system? My BIG-IP has hundreds of virtual servers, pools and pool members and I want to view a summarized list, including IP addresses.

Environment

  • Local traffic pool
  • pool members
  • node IP addresses 

Cause

None

Recommended Actions

To obtain a list of all virtual servers with corresponding pools and pool member IP addresses/fqdn names on the BIG-IP system, perform the following procedure:

 

  1. Log into the Advanced Shell (bash) of the BIG-IP system.
  2. Run the following command:

     

        tmsh -c 'cd /; show ltm virtual detail recursive' | grep -E "Ltm::Virtual|Ltm::fqdn|Ltm::Pool|Ltm::Node" 
         
  3. Review the output which may appear similar to the following example:

     

            

    Ltm::Virtual Server: Common/vip1
      | Ltm::Pool: Common/pool1                                
         | Ltm::Pool Member: Common/node4:80      
            | Ltm::Node: Common/node4 (172.16.0.132)

       | Ltm::Pool: Common/TEST-FQDN-Pool
         | Ltm::Pool Member: Common/FQDN-test:80
            | Ltm::Node: Common/FQDN-test (192.168.200.200)
      | Ltm::Virtual Address: Common/192.168.0.142 (192.168.0.142)

       

    Ltm::Virtual Server: Common/vip2
      | Ltm::Pool: Common/pool2                                
         | Ltm::Pool Member: Common/node6:80      
            | Ltm::Node: Common/node6 (172.16.0.134)
         | Ltm::Pool Member: Common/node7:80      
            | Ltm::Node: Common/node7 (172.16.0.135)
      | Ltm::Virtual Address: Common/192.168.0.145 (192.168.0.145)
           

    Ltm::Virtual Server: Common/vip3
      | Ltm::Pool: Common/pool3                                
         | Ltm::Pool Member: Common/node10:80     
            | Ltm::Node: Common/node10 (172.16.0.138)
         | Ltm::Pool Member: Common/node11:80     
            | Ltm::Node: Common/node11 (172.16.0.139)
         | Ltm::Pool Member: Common/node12:80     
            | Ltm::Node: Common/node12 (172.16.0.140)
         | Ltm::Pool Member: Common/node8:80      
            | Ltm::Node: Common/node8 (172.16.0.136)
         | Ltm::Pool Member: Common/node9:80      
            | Ltm::Node: Common/node9 (172.16.0.137)
      | Ltm::Virtual Address: Common/192.168.0.147 (192.168.0.147)

 

 

 

 

       For example, the above output indicates that the virtual server, vip1 (192.168.0.142) in /Common partition, references pool1 with pool member node4 (172.16.0.132) and pool TEST-FQDN-Pool with pool member FQDN-test (192.168.200.200).

 

     4. Should you need the output to be saved to a file due to its size, command below will save output to /var/tmp/List.txt file, which then can be handled as required.

 

tmsh -c 'cd /; show ltm virtual detail recursive' | grep -E "Ltm::Virtual|Ltm::fqdn|Ltm::Pool|Ltm::Node"  >> /var/tmp/List.txt
