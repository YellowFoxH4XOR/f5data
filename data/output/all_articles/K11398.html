Known Issue

This is the result of a known issue. Internet Explorer (IE) memory usage increases while displaying the Dashboard screen in the Configuration utility. This issue occurs because the HTTP responses sent by the Dashboard utility do not specify no-cache directives in the Cache-Control header. As a result, IE stores the dashboard updates in its memory cache.

Note: This issue has been observed with IE versions 6, and 7, but it can likely be observed with all versions of IE. You can observe the increase in IE memory usage by navigating to the Dashboard screen in the Configuration utility, opening the Windows Task Manager application, and watching the memory utilization of the iexplore.exe process.

F5 Product Development tracked this issue as CR127160 and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WOM release notes.

This issue was fixed in Hotfix-BIGIP-10.0.1-402.7-HF4 issued for BIG-IP 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
