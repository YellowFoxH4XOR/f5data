K000130341: Cannot install / replace BIG-IP existing software volume

Type
Support Solution
Published
2022-12-25
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000130341

Description

Customer faced an issue when trying to install / replace existing software volume

Environment

  • BIG-IP
  • Upgrade

Cause

The secondary HA BIG-IP are found have two software volume
Example: 

  1. GUI > System > Software Management > Image List
    Installed Images
    Product
    Version
    Build
    Disk
    Boot Location
    Active
    Default Boot
    Media
    Install Status
    Allowed Version
    BIG-IP15.1.y0.0.xHD1HD1.1YesNohdcompleteYes
    BIG-IP15.1.x0.0.xHD1HD1.2NoYeshdcompleteYes
              
  2. TMOS: # tmsh list sys software volume one-line | grep active
    sys software volume HD1.1 { active basebuild 0.x build 0.x media { HD1.1 { media hd size default } } product BIG-IP status complete version 15.1.y }
    sys software volume HD1.2 { active-requested basebuild 0.x build 0.x media { HD1.2 { default-boot-location media hd size default } } product BIG-IP status complete version 15.1.x } 
 

It seems like the BIG-IP were manually rebooted to another software volume, hence, it is expected to not be able to install any new software into either of the HD1.1 and HD1.2 as both software volume were locked because HD1.1 are set as default boot, while HD1.2 are the current active volume
 

Recommended Actions

Follow KB article "K35030024 " steps to manually change the default boot volume to HD1.2 15.1.x
