Topic

Purpose

You should consider using this procedure under the following condition:

  • You want to use DNS to resolve host names on your BIG-IP system.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have a working DNS server with entries for your hosts.
  • Your BIG-IP system has direct network access to this DNS server.

Description

The BIG-IP system uses two sources of information to resolve host names: the hosts file and DNS. The BIG-IP system first refers to the local /etc/hosts file. If the host name is not found in the /etc/hosts file, the BIG-IP system uses DNS if configured to do so. The following procedures help you configure the BIG-IP system to use DNS.

Note: Beginning in BIG-IP 11.6.0, the BIG-IP system uses DNS to resolve host names for nodes and pool members configured to use fully-qualified domain names (FQDN) and does not consult the /etc/hosts file.

Procedures

To watch a video demo of the Configuration utility procedures, go to  Configure your BIG-IP system to use DNS to resolve host names using the Configuration utility.

  • Use the Configuration utility to configure the BIG-IP system as a DNS client
  • Use tmsh to configure the BIG-IP system as a DNS client
  • Use tmsh to remove configured DNS name servers from the BIG-IP system
  • Use the Configuration utility to configure the BIG-IP system as a DNS search list
  • Use tmsh to configure the BIG-IP system as a DNS search list

Use the Configuration utility to configure the BIG-IP system as a DNS client

Using the Configuration utility is the preferred method of configuring a DNS remote lookup server.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: This change persists reboots and configuration reloads.

  1. Log in to the Configuration utility.
  2. Go to System > Configuration > Device > DNS.
  3. In DNS Lookup Server List, enter the IP address of your remote DNS lookup server.
  4. Select Add.
  5. Select Update.

This same procedure can be used to modify the BIND Forwarder Server List or DNS Search Domain List.

Using tmsh to configure the BIG-IP system as a DNS client

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: Do not attempt to manually edit the /etc/resolv.conf file as such changes do not persist reboots or configuration reloads. It is not necessary to save the TMOS Shell (tmsh) for this change to persist through a restart or configuration re-load.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To add a name server to your /etc/resolv.conf file, use the following command syntax, replacing <IP addresses> with the DNS server(s) IP addresses:

    modify /sys dns name-servers add { <IP addresses> }

    For example:

    modify /sys dns name-servers add { 192.168.1.2 192.168.100.100 192.168.200.200 }

  3. To save the configuration, enter the following command:

    save /sys config

  4. To exit tmsh, enter the following command:

    quit

Use tmsh to remove configured DNS name servers from the BIG-IP system

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: Do not attempt to manually edit the /etc/resolv.conf file as such changes do not persist through restarts or configuration reloads. It is not necessary to save the tmsh configuration for this change to persist through a restart or configuration reload.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To remove one or more of the configured name servers from your /etc/resolv.conf file, use the following command syntax, replacing <IP addresses> with the DNS server IP addresses and separating each IP address with a space:

    modify /sys dns name-servers delete { <IP addresses> }

    For example:

    modify /sys dns name-servers delete { 192.168.1.2 192.168.100.100 192.168.200.200 }

    Alternatively, you can remove all configured name servers by entering the following command:

    modify /sys dns name-servers none

  3. To save the configuration, enter the following command:

    save /sys config

  4. To exit tmsh, enter the following command:

    quit

Use the Configuration utility to configure the BIG-IP system as a DNS search list

Sometimes you may want the BIG-IP system to search within specific domains and subdomains when a fully qualified domain name is not explicitly requested. For example, if you would like the BIG-IP system to automatically choose www.f5.com when you try to resolve the host www, then you would need to add f5.com to your DNS Search Domain List.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to System > Configuration > Device > DNS.
  3. In DNS Search Domain List, enter the domain you want in your search list.
  4. Select Add.
  5. Select Update.

Using tmsh to configure the BIG-IP system as a DNS search list

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To add one or more domains to your DNS search list, use the following command syntax, replacing <domains> with the list of domains you want in your search list:

    modify /sys dns search add { <domains> }

    For example:

    modify /sys dns search add { f5.com foo.com test.com }

  3. To save the configuration, enter the following command:

    save /sys config

  4. To exit tmsh, enter the following command:

    quit
