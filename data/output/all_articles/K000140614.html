Topic

How the BIG-IP system uses the Apache HTTP server (httpd).

Description

The httpd server is third-party software that runs on the Linux host operating system on BIG-IP systems. It is used by the Configuration utility, iControl REST, and iControl SOAP interfaces, to provide management (control plane) access to the BIG-IP system, for tasks such as system configuration.

The data plane handles traffic flow through the BIG-IP system using the Traffic Management Microkernel (TMM) and does not utilize httpd. For more information about the data and control planes, refer to K44525501: Overview of BIG-IP data plane and control plane.

Important: F5 point and hotfix releases may include upgrades and security fixes for third-party software packages. As a result, when evaluating the vulnerability status for third-party software, F5 recommends that you refer to security advisory articles to determine if a BIG-IP release is vulnerable. You should not attempt to upgrade or install third-party software packages apart from BIG-IP software releases.
