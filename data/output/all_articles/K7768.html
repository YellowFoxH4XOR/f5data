Known Issue

This is the result of a known issue. If you enter a name containing square bracket characters in the Network Access Connection name field and then update an internal user's details, the Network Access connection name you just entered disappears.

Note: An internal user is a user whose information, such as name, email address, and password is managed on the FirePass controller.

The Network Access connection name must contain both left and right square bracket characters, and the left square bracket character must precede the right square bracket character.

For example, the following Network Access connection names would be affected by this issue:

  • [abc]
  • abc[abc]abc

However, the following Network Access connection names would not be affected by this issue:

  • [abc
  • abc[
  • ]abc[

Note: The Network Access Connection name field is located on the Network Access : Resources page. Internal users are configured on the Users : User Management page.

F5 Product Development tracked this issue as CR68279 and it is fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

This issue still exists in the FirePass version 5.x branch. To monitor the status of this CR, refer to the FirePass release notes.

Additionally, cumulative hotfix HF-552-10 has been issued for FirePass version 5.5.2, cumulative hotfix HF-600-15 has been issued for FirePass version 6.0.0, and cumulative hotfix HF-601-5 has been issued for FirePass version 6.0.1. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads page.

For information about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.
