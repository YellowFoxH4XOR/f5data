Topic

The BIG-IP system does not cache Set-Cookie headers sent by the origin web server (OWS).

Description

The BIG-IP LTM and WebAccelerator cache features do not cache Set-Cookie or Set-Cookie2 headers.

Set-Cookie headers are sent by the OWS. Set-Cookie headers frequently contain information that is strictly private to an individual session and should not be stored in shared caches. For example, a Set-Cookie header may contain authentication information that is intended for a particular user session. Caching and distributing this information to multiple users would introduce security concerns.
