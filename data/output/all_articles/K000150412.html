K000150412: VELOS clean install may fail if you did not perform on both system controllers concurrently

Type
Support Solution
Published
2025-03-17
Updated
2025-03-25
Applies to
  • F5OS
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000150412

Description

When clean install F5OS-C, you must perform the clean install of both System Controllers concurrently.

If not perform the clean install of both System Controllers concurrently, clean install may be failed.

Environment

When clean install F5OS-C

F5OS-C

Cause

You will probably select the USB device from which you want to install and perform a clean install of the system controller,

but please perform this process concurrently on both controllers.

When the installation is complete, the message "Installation complete. Press return to quit" will be displayed,

so press the Enter key at the same time and restart the system.

Recommended Actions

None

Additional Information

For information about the procedure to perform a clean install on the VELOS system, refer to the Clean installation section under the Install or Upgrade Software chapter of the VELOS Systems: Software Installation and Upgrade guide.
