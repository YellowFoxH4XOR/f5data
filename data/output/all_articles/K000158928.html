Description

Remote authenticated users with operator role are unable to access the Network Map section in the BIG-IP GUI. When attempting to access this feature, users receive the error message "No object in this partition." This issue occurs after a BIG-IP upgrade, even though no configuration changes were made and users previously had access to the Network Map with the same role assignment.

 

Environment

  • BIG-IP LTM 
  • Remote authentication configured for users
  • Affected users assigned operator role
  • Users previously had access to Network Map section with the same role

 

Cause

Bug ID 718796: iControl REST token issue after upgrade. The icontrol-role-migrator component retained incorrect authorization mappings after upgrade, preventing users with operator role from accessing the Network Map section. This caused the GUI to incorrectly evaluate permissions and display "No object in this partition" errors for affected users.

 

Recommended Actions

Execute the following commands on the affected BIG-IP device:

restcurl -X DELETE "shared/storage?key=shared/authz/icontrol-role-migrator"

bigstart restart restjavad

Wait approximately 1 minute for the restjavad service to fully restart.

Have affected users log out and log back into the GUI to verify access to Network Map is restored.

Note: These commands only affect the management plane and will not impact production traffic.
