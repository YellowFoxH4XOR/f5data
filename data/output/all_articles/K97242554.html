Known Issue

The learning_manager.pl process may exit and restart when the Session Awareness feature is enabled and you view the Session Tracking Status screen in the Configuration utility.

This issue occurs when all of the following conditions are met:

  • You have BIG-IP ASM licensed and provisioned on the BIG-IP system.
  • You have Session Awareness enabled.
  • You view the Security > Reporting > Application > Session Tracking Status screen in the Configuration utility.

Impact

The BIG-IP ASM system does not generate learning suggestions until the learning_manager.pl process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe unhandled keyword messages in the /var/log/asm file or the Configuration utility.
  • You observe BIG-IP ASM error messages in the /var/log/asm file.
  • The learning_manager.pl process restarts or is not running.
  • The BIG-IP ASM system does not generate learning suggestions while processing traffic.
