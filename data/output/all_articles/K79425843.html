Description

Script for external monitor is not available on External Program option in the configuration Utility

Environment

  • BIG-IP
  • External Monitor
  • You manually copy a external file to the BIG-IP system using Secure Copy (SCP) protocol or some other means
  • The external file is not available in the configuration utility under Local Traffic ›› Monitors ›› New Monitor >> External Program

Cause
You should import external files to the BIG-IP system using the File Management page or TMSH.
Note: In versions earlier than BIG-IP 11.x, you must manually copy external files to the BIG-IP system using the Secure Copy (SCP) protocol or some other means. You must then place the file in the proper location on the file system.

Recommended Actions

In BIG-IP 11.x and later, F5 recommends that you use the File Management page in the Configuration utility or TMSH to import external file types to the BIG-IP system. To do so, refer to K13423: Importing external files to the BIG-IP system.
