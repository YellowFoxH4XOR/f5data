Description

/var/log/apm shows error logs like below, logged every 30 minutes 
Jan 1 12:00:00 bigip01 err localdbmgr[<PID>]: 01ab0064:3: auth_user_details table has fewer records than auth_user_table (<# of records in auth_user_details table>, <# of records in auth_user_table>)


Environment

  • BIG-IP APM
  • Local User DB  authentication is used


Cause

This error message is logged if the number of records between auth_user_details and auth_user_table is different. This might be caused by numerous factors but 2 most common are
- importing users from a CSV files, which might end up with duplicates
- a custom made (malfunctioning) script that operates on the Local User DB.

 

Recommended Actions

Local User DB (mysql) needs to be inspected for duplicates and/or missing entries.

  1. Please ensure there is enough disk free space (at least 3GB) on the /var/ and /shared/ partitions, see K14403: Maintaining disk space on the BIG-IP system
  2. Open a new case with F5 Support.
