Description

SSH access to BIG-IP management address stopped working.

When running this command from CLI, you receive the following error:

# bigstart restart sshd
Stopping sshd:[FAILED]

cp: cannot create regular file '/var/empty/sshd/etc': No such file or directory
Missing privilege separation directory: /var/empty/sshd
Starting sshd:[FAILED]

Environment

BIG-IP

Cause

The default "empty" directory was renamed "v" as in /var/v/sshd/etc

NOTE: It could have been renamed anything not just "v". 

Recommended Actions

Rename the "v" directory back to "empty"
Restart the ssh daemon by running the following command:
# bigstart restart sshd
