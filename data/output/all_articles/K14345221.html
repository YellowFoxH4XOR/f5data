Description

Clients connecting to BIG-IP APM VPN only receive first DNS Domain suffix configured

Environment

  • Windows 10
  • BIG-IP APM VPN

Cause

Clients must have the 'F5 Networks BIG-IP DNS Relay Proxy Service' installed and running to inherit multiple BIG-IP DNS Domain Suffixes

Recommended Actions

Re-install BIG-IP APM Edge Client using Administrative or elevated privileges.
Confirm within Windows 'Services' control panel that the 'F5 Networks BIG-IP DNS Relay Proxy Service' is installed and running.
