K000132833: Only pools which are defined as default pools under virtual servers can be listed on Network Map

Description

The BIG-IP Configuration utility includes a feature known as the Network Map. 
 

The Network Map provides a hierarchical, visual view of BIG-IP local traffic manager (LTM) components (virtual servers, pools, and pool members), their relationships, and respective statuses on the BIG-IP system. The Network Map also provides additional component information on accompanying panels on the page.

 

Symptoms

Pools which are not assigned to virtual server, are not displayed on network map.

 

Environment

  • LTM
  • Network Map

 

Cause

Network Map only lists pools which are defined as default pools under virtual servers.

If the pool is not assigned to any virtual server, this pool will not be found on the network map.

 

Recommended Actions

This is expected behaviour, because, on Network Map, those pools which are not referenced by any virtual servers are not displayed.
