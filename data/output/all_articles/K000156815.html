K000156815: Use of latest AWS CloudHSM version 5.16.2 result in unsupported GLIBC error

Type
Support Solution
Published
2025-10-08
Updated
2025-10-08
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000156815

Description

F5 support AWS CloudHSM version 5 in v17.5.1, however, when you install the latest AWS HSM, you may get following error when you attempt to run cli commands.

# cd /opt/cloudhsm/bin
# ./cloudhsm-cli
./cloudhsm-cli: /usr/lib64/libc.so.6: version `GLIBC_2.25' not found (required by ./cloudhsm-cli)
./cloudhsm-cli: /usr/lib64/libc.so.6: version `GLIBC_2.18' not found (required by ./cloudhsm-cli)

Environment

  • BIG-IP v17.5.1 on AWS
  • AWS CloudHSM 5.16.2

Cause

When you download the latest AWS CloudHSM client and cli package, the version will be greater than 5.16.2.
The latest AWS CloudHSM version is greater than 5.16.2 requires GLIBC 2.18 at least.
The GLIBC version on BIG-IP 17.5.1 is GLIBC 2.17, that results in the GLIBC version not found error.

Recommended Actions

Install AWS CloudHSM version 5.16.1.

Previous version of AWS CloudHSM  RHEL 8(8.3+) is found at following link.

https://docs.aws.amazon.com/cloudhsm/latest/userguide/client-version-previous.html

To download the client and cli RPMs at BIG-IP, run following command.
# curl -O https://s3.amazonaws.com/cloudhsmv2-software/CloudHsmClient/EL7/cloudhsm-pkcs11-5.16.1-1.el7.x86_64.rpm
# curl -O https://s3.amazonaws.com/cloudhsmv2-software/CloudHsmClient/EL7/cloudhsm-cli-5.16.1-1.el7.x86_64.rpm
