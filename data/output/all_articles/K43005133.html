Known Issue

You may be unable to successfully create a topology record using the iControl REST interface.

This issue occurs when all of the following conditions are met:

  • You use the iControl REST interface to create a topology record on your BIG-IP DNS device.
  • The topology record includes a reference to a state, where the name of the state contains a white space.

    For example:

    state CA/Yukon Territory, state US/Rhode Island

Impact

The system fails to create the topology.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to create the topology, the iControl REST interface returns an error message similar to the following example:

    {"code":400,"message":"Topologies must specify both regions: ldns: server:","errorStack":[],"apiError":26214401}

  • When you specify a state name that does not contain a white space, the system creates the topology.

Workaround

To work around this issue, you can use the TMOS Shell (tmsh) and specify state names that contain white space in quotations. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To create a new topology record with a state name that includes a white space, place the state name in double quotes, as shown in the following syntax:

    create /gtm topology ldns: state "<country/state name>" server: <destination type> <destination reference>

    For example:

    create /gtm topology ldns: state "US/New Jersey" server: "pool" example_pool

  3. Save the new records by typing the following command:

    save /sys config gtm-only

  4. To exit tmsh, type the following command:

    quit
