Description

Login the Configuration Utility, navigate to Statistics  ››  Performance Reports, the graph is intermittently.

On the iHealth, check the Graphs, also see the same graphs.

Environment

  • BIG-IP
  • Performance Report （RRD data)
  • iHealth

Cause

The system clock changed forwards, system cannot generate the performance data for the adjusted period.

Recommended Actions

You can safely ignore this issue.

We suggest to configure the proper NTP servers and make sure the system clock change steps is short, like X seconds only.

Additional Information

If the system clock changed backwards, the new performance data will NOT override the old data.
