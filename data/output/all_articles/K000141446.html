Description

On the iOS client, install the F5 Access and create the on-demand VPN connection, the VPN connection will disconnect before the inactivity timeout.

Environment

  • BIG-IP APM
  • Virtual server
  • Access profile
  • Network Access
  • F5 Access on iOS client

Cause

The on-demand VPN connection will disconnect when reach "On Demand Disconnect Timeout" value. In the connectivity profile configuration, the default value is 2 minutes.

Recommended Actions

Please check the connectivity profile configuration, refer to your requirement, configure the proper value for "On Demand Disconnect Timeout".
