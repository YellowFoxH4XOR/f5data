Description

  • Performing a Config Sync does not create the Virtual Server on the destination device.
  • Other items, such as Pools, are synced.
  • Syncing in the reverse direction works.

Environment

  • HA Sync failover group.

Cause

  • The Virtual Server is on a Virtual Address which is Traffic-Group-Local. This makes the Virtual Server local and it does not sync.
  • In the reverse direction, the Virtual Address is on Traffic-Group-1 and the associated Virtual Server does sync.
  • The Virtual Address may have already existed on Traffic-Group-Local before the Virtual Server was configured.
  • A Virtual Address which shares the address range (more commonly, the address itself) of a Self IP on Traffic-Group-Local, will be created on Traffic-Group-Local.

Recommended Actions

  1. Change the Virtual Server to another Destination address
  2. Or, change the conflicting Self IP and reconfigure the Virtual Address to Traffic-Group-1

Additional Information

  • This is by design. However the effect is only useful in special circumstances
