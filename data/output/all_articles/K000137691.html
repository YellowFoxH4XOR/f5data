Description

Set custom "Maintenance Page" when backend response is 50X

Environment

  • Nginx Plus
  • Nginx Plus Configuration

Cause

There is a no cause, this recommended action is optional.
We can redirect all 5xx errors to one named location using error_page directive

Recommended Actions

...
root         /var/www/html;

error_page 500 502 503 504 =503 @maintenance;

location @maintenance {
  rewrite ^(.*)$ /maintenance.html break;
}
...
