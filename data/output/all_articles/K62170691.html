Description

If an AS3 Application Service is removed manually from BIG-IP, orphaned objects related to the Application Service can be left behind. The BIG-IQ GUI will not let these be modified or deleted and will show a banner for the object similar to the following:

"This belongs to BIG-IQ application Sales_Web443Sales and cannot be changed."

In the above message
  • "Sales" is the tenant
  • "Web443Sales" is the Application Service Name(ASN)

The BIG-IQ rest API must be used to remove these orphaned objects associated with an ASN.

Environment

  • BIG-IQ with orphaned objects from applications that no longer exists

Cause
These orphaned objects may be caused when configuration objects are manually removed on a BIG-IP, and the Application is manually removed from the BIG-IQ

Recommended Actions

Clean up the BIG-IQ configuration by removing objects associated with the ASN

On CLI:

  1. Set Application Service Name name in a variable

    ASN_name=<Application Service Name> 

    Note: Replace <Application Service Name> with the actual ASN name
  2. Make a backup of BIG-IQ(IMPORTANT)
    tmsh save sys ucs b4_clean_ASN_${ASN_name}_objects
  3. Create a file of URIs that will be used to search for related objects:

    restcurl cm/ | grep 'working-config\/ltm' | cut -d '/' -f 5- | tr -d '"' >/var/tmp/search_uris.txt

  4. Create an empty file:

    echo -n > /var/tmp/${ASN_name}_selfLinks.txt

  5.  Delete the orphaned Application Service Name objects:
     Note: This will produce some errors due to some object dependencies and will be run again in step 6 to address the missed objects

    while read LINE ; do restcurl ${LINE} -X DELETE ; done < /var/tmp/${ASN_name}_selfLinks.txt

  6.  Run the command a second time from step 5 to remove the objects that failed the first time
     Note: There will be errors for the object that were deleted in the first run and are now missing

    while read LINE ; do restcurl ${LINE} -X DELETE ; done < /var/tmp/${ASN_name}_selfLinks.txt

     

    At this point, the objects should be removed from the BIG-IQ.
