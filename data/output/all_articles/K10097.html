K10097: Mapping resource groups within individual master groups

Issue

In FirePass versions prior to 6.0.2, dynamic group mapping was handled by a global table for master groups and one for resource groups. Both tables were populated by a common set of mapping methods. These methods can be reviewed and configured by navigating to the Users > Groups > Dynamic Group Mapping > Group Mapping Methods tab.

On this page, you may configure one or more methods used for the purposes of either dynamic master group mapping and/or dynamic resource group mapping. The information returned by these configured mapping methods on this page is then used for matching purposes on either the Master group mapping table tab and/or the Resource group mapping table tab. When a user logs in to FirePass when dynamic group mapping is enabled, and one or more mapping methods are configured, FirePass will fire all configured mapping methods in an attempt to collect the data from all methods before subsequently using this information for the purposes of matching in the Master group mapping table tab and/or Resource group mapping table tab.

For environments that use multiple back-end directory services, such as mapping methods, this behavior may produce the undesired result of having the user's credentials checked against each configured method, even if you specifically do not want this behavior to occur. For example, if you set up a landing URI or VHOST for this requirement.

In FirePass 6.0.2 and later, FirePass offers the ability to map resource groups within each individual master group, rather than on a common global table. However, this feature does not modify the behavior documented in this article. This behavior is required for backward compatibility, and for environments upgrading from an earlier version of FirePass to ensure a running configuration after the upgrade.

F5 recommends customers who are attempting to use dynamic group mapping, which uses various authentication directories, to consider the use of alternate, non-directory based methods, such as RADIUS Attributes, Landing URIs, VHOSTs, Session Variables, Client or Machine Certificate information.
