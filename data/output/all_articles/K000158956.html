Description

This article provides information about BIG-IP's support for establishing TLS sessions when TCP Fast Open is used, allowing the Client Hello message to be included in the initial SYN packet of the TCP three-way handshake.

Environment

  • Product: BIG-IP LTM
  • Versions: All versions supporting TCP Fast Open
  • Feature: TCP Fast Open (RFC 7413)

Overview

What is TCP Fast Open?

TCP Fast Open (TFO) is a mechanism defined in RFC 7413 that allows data to be exchanged during the TCP connection establishment phase. Specifically, it enables:

  • Application data to be sent in the SYN packet (from client)
  • Application data to be sent in the SYN-ACK packet (from server)

This reduces connection latency by eliminating one round-trip time (RTT) for new TCP connections.

 

TLS with TCP Fast Open

BIG-IP fully supports establishing TLS sessions when TCP Fast Open is used. This means:

  • The Client Hello message can be included in the initial SYN packet
  • BIG-IP will process the Client Hello and respond appropriately with Server Hello
  • The complete TLS handshake proceeds normally after the TCP connection is established

Configuration

Enabling TCP Fast Open on BIG-IP:

  1. Navigate to Local Traffic > Profiles > Protocol > TCP
  2. Select the TCP profile used by your virtual server (or create a new one)
  3. Set TCP Fast Open to Enabled
  4. Apply the profile to your virtual server


Additional Information


Requirements:


  • TCP Fast Open must be enabled on both client and server (BIG-IP)
