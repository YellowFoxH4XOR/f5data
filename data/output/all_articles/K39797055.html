Environment

  • BIG-IP APM 
  • OAuth Client / Resource Server
  • SSL ciphers

Cause

This is caused due to a java cipher incompatibility between the provider and the ciphers supported on  java 7 used on BIG-IP APM 

Example of cipher not supported on java 7:
TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256 (ecdh_x25519)

 

Recommended Actions

Configure the provider to accept the ciphers supported on java 7
