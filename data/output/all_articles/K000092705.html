K000092705: traffic-splitting with session-persistence on NGINX Ingress Controller

Type
Support Solution
Published
2022-12-16
Updated
2023-08-07
Source
https://my.f5.com/manage/s/article/K000092705

Description

As background information we are trying to get blue/green deployments working on AKS using Nginx+. We also require persistent sessions to be in place so that there is no interruption to someone using the application during a deployment.

Environment

  • NGINX Ingress Controller
  • traffic-splitting
  • session-persistence

Cause

Requires specific configuration to solve this

Recommended Actions

Create Initial Deployment and Service 
apiVersion: apps/v1
kind: Deployment
metadata:
  name: tea
spec:
  replicas: 2
  selector:
    matchLabels:
      app: tea
  template:
    metadata:
      labels:
        app: tea
    spec:
      containers:
      - name: tea
        image: nginxdemos/nginx-hello:plain-text
        ports:
        - containerPort: 8080
---
apiVersion: v1
kind: Service
metadata:
  name: tea-svc
spec:
  ports:
  - port: 80
    targetPort: 8080
    protocol: TCP
    name: http
  selector:
    app: tea
Create Version 1 Deployment and Service 
apiVersion: apps/v1
kind: Deployment
metadata:
  name: tea-v1
spec:
  replicas: 2
  selector:
    matchLabels:
      app: tea-v1
  template:
    metadata:
      labels:
        app: tea-v1
    spec:
      containers:
      - name: tea-v1
        image: nginxdemos/nginx-hello:plain-text
        ports:
        - containerPort: 8080
---
apiVersion: v1
kind: Service
metadata:
  name: tea-v1-svc
spec:
  ports:
  - port: 80
    targetPort: 8080
    protocol: TCP
    name: http
  selector:
    app: tea-v1
Create Virtual Server Instance 
apiVersion: k8s.nginx.org/v1
kind: VirtualServer
metadata:
  name: cafe
spec:
  host: cafe.example.com
  upstreams:
  - name: tea
    service: tea-svc
    port: 80
    sessionCookie:
      enable: true
      name: srv_id
      path: /tea
      expires: 2h
  - name: tea-v1
    service: tea-v1-svc
    port: 80
    sessionCookie:
      enable: true
      name: srv_id_v1
      path: /tea
      expires: 2h
  routes:
  - path: /tea
    matches:
    - conditions:
      - cookie: srv_id
        value: ~*
      action:
        pass: tea
    - conditions:
      - cookie: srv_id_v1
        value: ~*
      action:
        pass: tea-v1
    splits:
    - weight: 1
      action:
        pass: tea
    - weight: 99
      action:
        pass: tea-v1
