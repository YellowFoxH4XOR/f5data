Description

Modified sshd configuration similar to the following:

sys sshd {
    include "Ciphers aes128-ctr,aes192-ctr,aes256-ctr
             MACs hmac-sha1,hmac-ripemd160,hmac-ripemd160@openssh.com"
}

However, packet capture and sshd -T output shows CBC ciphers are still enabled:

$ sshd -T | grep ciphers
ciphers aes128-gcm@openssh.com,aes256-gcm@openssh.com,aes128-cbc,aes256-cbc,aes128-ctr,aes192-ctr,aes256-ctr,aes192-cbc

Environment

  • sshd

Cause

/config/ssh/sshd_config is a regular file, not a symbolic link to /run/config/sshd_config.

[root@ltm1:Active:Standalone] config # ll /config/ssh/sshd_config
-r--r-----. 1 root root 4018 May  2 04:34 /config/ssh/sshd_config
^___ Not a link

Recommended Actions

Re-create the symlink to /run/config/sshd_config, then restart sshd.

if [ ! -L /config/ssh/sshd_config ]; then
    # Not a link, so create one.
    mv /config/ssh/sshd_config /var/tmp/sshd_config.bak
    ln -sv ../../var/run/config/sshd_config /config/ssh/sshd_config
    tmsh restart sys service sshd
fi

Correct:

[root@ltm1:Active:Standalone] config # ll /config/ssh/sshd_config
lrwxrwxrwx. 1 root root 32 May  2 04:36 /config/ssh/sshd_config -> ../../var/run/config/sshd_config
