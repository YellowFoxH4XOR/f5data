K9877: A policy place-rule fails when it encounters a file protected with Encrypting File System attributes

Topic

The ARX system does not support access to files with Encrypting File System (EFS) attributes. If a policy place-rule encounters a file protected with EFS, the rule fails and the system logs an error message in the system log that appears similar to the following example:

DME-1-3-MSG3:: smbcopy: failed to copy "/projects/F5/ABC-Corp/document.pdf", STATUS_ACCESS_DENIED, 5615 mS elapsed
Attempt [32] encountered an error [The DME was denied access to read or write a file]. Maximum number of attempts is set to [32]. File could not be migrated within the maximum attempts allowed

Note: Access to files with EFS attributes is not supported because the encryption is on a per-user basis. Accessing the files with a single ARX proxy user defeats the primary purpose of the encryption.
