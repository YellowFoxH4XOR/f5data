Description

In certain (though rare) cases, one must replace the network adapter module(s) in a BIG-IP.

Environment

Any BIG-IP appliance that accepts SFP, SFP+, or GBIC network adapters

Cause

The following is not an exhaustive list.

  • The adapter has malfunctioned
  • The adapter is a third-party brand (e.g., Cisco), and is not supported by F5

Recommended Actions

To replace an SFP, take the following steps:

Note: This procedure MUST be taken with only an F5 SFP as per K8153: F5 support of third-party hardware components.

  1. Identify which SFP must be replaced
  2. Unplug the connected network cable from the SFP
  3. Remove the SFP; this may require you to lift a "latch" at the front
  4. Replace with a new SFP, taking care that this must go in the same port on the appliance. 
  5. Plug the network cable back in

Additional Information

Before proceeding with the above steps, it is highly recommended that one open a maintenance window in their organization; as the network must be disconnected, this will very likely disrupt your network until such time that the procedure is complete.  Please also open a proactive service request with us so that we may quickly help you if something goes wrong and you need help.  See K16022: Opening a proactive service request with F5 Support for further information. 

It is recommended that you follow these steps to their completion on only one adapter module at a time, so that you may ensure that the proper interface configurations do not need to be adjusted later.

If an F5 branded module is faulty, you should return it as per instructions from the network support engineer should it require RMA replacement.  For non-F5 branded modules, contact that module's vendor and never place non-F5 modules in the appliance going forward as per K8153: F5 support of third-party hardware components.
