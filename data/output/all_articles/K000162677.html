K000162677: Policy Sync Failure

Type
Support Solution

Updated

Applies to

Source

Description

In BIG-IP APM 21.1.0, APM policy synchronization can fail when a policy includes an object referencing the default Server SSL profile serverssl or any serverssl profile that specifies the f5-default cipher group. The following error appears:

01071b82:3: Cipher rule (/Common/f5-default): the base cipher rules may not be modified

Environment

  • BIG-IP APM peers running version 21.1.0

  • A sync-only device group used for APM policy synchronization

  • The affected policy contains an object that references the default Server SSL profile serverssl or any serverssl profile that specifies the f5-default cipher group

Cause

Product Engineering has opened ID2493401 to track and address this behavior. 

Answer/Recommended Actions

  1. As a workaround, on the source BIG-IP device, go to the object that references the default Server SSL profile serverssl.

  2. Change the selected profile from serverssl to serverssl-legacy, or another serverssl profile that does not reference the f5-default cipher group.

  3. Apply the change.

  4. Retry synchronization of the affected APM policy.
