The custom logging format in a BIG-IP WebAccelerator acceleration policy supports the following format fields:

Format FieldDescription
%aClient IP Address
%bBytes Written to Client
%cObject Type (MIME Type)
%dHostname/IP of Accelerator
%eTime to Process Request (milliseconds)
%f X-Forwarded-For Request Header (introduced in BIG-IP WebAccelerator version 9.4.7)
%gDate and Timestamp
%hSet-Cookie Response Header (introduced in BIG-IP WebAccelerator version 9.4.7)
%mMethod
%nNode matched in policy
%p Port
%rFirst Line of Request
%sHTTP Status Code to Client
%t Timestamp
%v Hostname/IP in HTTP Header
%wCache Action -- mi (SmartCache miss); hd (SmartCache disk hit); hm (SmartCache memory hit); pr (proxied content)
%xHTTP Status Code from Origin Web Server
%yCustom HTTP Error Code
%z Time Zone Offset (for RFC822-conformant dates)
%AUser Agent
%BHostname/IP of Origin Server
%CCookie Data
%DDay (01-31)
%ETime to Process Request (microseconds)
%FPath (requested URL without host or query parameters)
%GTime (hh:mm:ss)
%HSame as %w (deprecated)
%IURL
%MMonth (01-12)
%PProtocol (for example, HTTP/1.1)
%QQuery String
%RReferrer
%SSeconds since Unix Epoch (00:00:00 UTC, January 1, 1970)
%TTime to Process Request (seconds)
%USame as %F (deprecated)
%VAbbr. Month Name
%YYear (4 digits)
%ZTime Zone Name

Note: For information about specifying the logging format for a BIG-IP WebAccelerator policy, refer to the Policy Management Guide for the BIG-IP WebAccelerator System.
