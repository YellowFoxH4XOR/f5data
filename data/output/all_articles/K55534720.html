Description
This message occurs when activating a license key (Base Registration Key or Add-On Key) to the BIG-IP system.

Environment

  • BIG-IP GUI
  • License Reactivation

Cause
The base registration key or the base module was removed or missing during license activation. When adding add-on keys, or changing the license of the BIG-IP,  the base registration key and the base module must be present under System >> License >> Re-activate.

Recommended Actions

  • Make sure you do not remove the base registration key and/or the base module when adding BIG-IP add-on keys. 
  • If you are updating the base registration key, make sure the full key is entered.

None.
