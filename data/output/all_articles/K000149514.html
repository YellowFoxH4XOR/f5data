Description

You are trying to restore configuration from UCS file and you are getting following error:

Syntax Error:(/config/partitions/<partition_name>/bigip.conf at line: nnnn) "user-defined" unknown property

"nnnn" stands for a line present in bigip.conf file. In the following example, it is line 1414, which shows us the last entry named "user-defined"

ltm monitor http /<partition>/<virtual_server>/<monitor_name> {
adaptive disabled
adaptive-limit 1000
adaptive-sampling-timespan 140
defaults-from /Common/http
destination *:*
interval 5
ip-dscp 0
recv <receive_string>
recv-disable none
send <send_string>
time-until-up 0
timeout 16
user-defined CIPHERLIST DEFAULT
} 

There shouldn't be a cipher list in HTTP monitor.

Environment

  • BIG-IP
  • HTTP/HTTPS monitor
  • Restoring configuration from UCS file

Cause

You delete an HTTPS monitor named monitor1, create an HTTP monitor named monitor1, and then synchronize the configuration, the monitor1 configuration object on the peer systems is changed to an HTTP monitor, but may still contain invalid HTTPS monitor parameters. 

Recommended Actions

You can use workaround from K52052082 or:

1) Don't do the deletion of https monitor and creation of the http monitor in the same transaction with the same name. Please delete it in one transaction and create in another transaction with the same name. Synchronize the configuration after you delete the original object and before you create the new object.

2) Use a different name for the new configuration object.
