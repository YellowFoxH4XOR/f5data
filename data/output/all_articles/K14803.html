Summary

The Google Chrome browser does not support split-DNS for devices running the OS X operating system. Mac devices that connect to a BIG-IP APM Virtual Private Network (VPN) with a split-DNS domain do not use the DNS server settings provided by the BIG-IP APM system for VPN resources. Thus, the DNS query does not resolve correctly and returns resolutions based on the system's original DNS configuration.

Description

Mac devices running Google Chrome version 28.0.1500 on the OS X operating system do not have split-DNS VPN capabilities. For more information about this issue, refer to the following Chromium article from Google.

Issue 265970: Built-in DNS resolver does not handle /etc/resolver configuration

Note: This link takes you to a resource outside of AskF5. The third party could remove the document without our knowledge.

Impact

Devices running the Google Chrome browser on the OS X operating system may encounter the following issues:

  • The Google Chrome browser does not use the DNS server settings provided by the BIG-IP APM for VPN sessions.
  • DNS resolutions for VPN resources may not resolve correctly, impacting the ability to access VPN resources.
