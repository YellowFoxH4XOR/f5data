Topic

AJAX is a term that refers to a group of web technologies used for creating interactive web applications. AJAX applications retrieve data using the XMLHttpRequest API, which makes requests over both HTTP and HTTPS. From the BIG-IP ASM perspective, no specific setup should be required, as the requests generated by the AJAX application are treated as normal HTTP requests.

Note: Starting in BIG-IP ASM version 9.4.2, if your AJAX application uses XML to format the data being transferred between the client and server, and you want to protect the XML-based traffic, you can configure an XML profile for the BIG-IP ASM security policy. For more information about configuring an XML profile, refer to the Configuration Guide for BIG-IP Application Security Management.
