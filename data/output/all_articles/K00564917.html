K00564917: VPN connection fails with ''Error: Tunnel Server Cannot Be Started''

Type
Support Solution
Published
2020-05-10
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.1
  • APM Clients
Source
https://my.f5.com/manage/s/article/K00564917

Description

  • When attempting to establish a VPN session, the connection fails with the following error:
    Error: Tunnel Server Cannot Be Started

Environment

  • BIG-IP APM version 13.1.1
  • BIG-IP Edge Client version 7.1.8.0 (7180.2019.0118.1)
  • Mac OS

Cause

None

Recommended Actions

Contact your BIG-IP APM system administrator to upgrade the Mac OS device installed BIG-IP Edge Client to the BIG-IP Edge Client major version 7.1.8.1 or later.

Additional Information

  • K13757: BIG-IP Edge Client version matrix
  • K14947: The BIG-IP Edge Client components for Mac OS X
  • K52547540: Updating BIG-IP Edge Client for the BIG-IP APM system
