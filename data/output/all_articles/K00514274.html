Description

This article describes how to verify the supported ciphers in iQuery connection between gtmd and big3d. 

Environment

  • iQuery
  • big3d/gtmd
  • iqtest

Cause

None

Recommended Actions

You can verify the supported ciphers in iQuery connection by using the iqtest command from local BIG-IP DNS. To do so, perform the following procedure.

Note: The iqtest command applies from BIG-IP DNS 14.1.0.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to bash.

  2. To verify the supported ciphers in the iQuery connection between gtmd and big3d for your local BIG-IP DNS, use the following command syntax:

iqtest -cipher <cipher_string> localhost

For example, to test the iQuery connection with the 'AES' ciphers to big3d in the local BIG-IP DNS, type the following command:

iqtest -cipher 'AES' localhost

The output below indicates the successful verification.

<xml_connection>
<version>14.1.2.6</version>
<big3d>big3d Version 14.1.2.6.0.0.2</big3d>
<connection_id>45</connection_id>
<kernel>linux</kernel

Additional Information

The ECDHE ciphers are currently not supported in the iQuery connection.

You can verify the ECDHE ciphers, by typing the following command in your local BIG-IP DNS:

iqtest -cipher 'ECDHE' localhost
