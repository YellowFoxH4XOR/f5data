Description

After installing EHF to fix connectivity on Mac OS, Clients on Mac OS Ventura timeouts in Windows Info item.

The behavior could be observe on APM log as the following way:

<hostname> info apmd[22736]: 01490007:6: /Common/<access policy name>:Common:<session ID>: Session variable 'session.policy.inspectionhost.status' set to 'agent_endpoint_windows_info_os'
<hostname> info apmd[22736]: 01490007:6: /Common/<access policy name>:Common:<session ID>: Session variable 'session.policy.inspectionhost.timestamp' set to '1683735029'
<hostname> notice tmm1[29649]: 01490502:5: /Common/<access policy name>:Common:<session ID>: Session deleted due to user inactivity. 
<hostname> notice tmm1[29649]: 01490521:5: /Common/<access policy name>:Common:<session ID>: Session statistics - bytes in: 23743, bytes out: 24262

 

Environment

- Access Policy with "Windows info" item
- EHF installed - K000132932
- Mac OS Ventura

Cause

Bug ID 1295333

Recommended Actions

There 2 ways to solve this issue:

1- Skip "Windows info" item if there's no need to identify or distinguish OS

2- Add Client OS check before Windows Info so that MacOS can be detected and go it's own branch.
