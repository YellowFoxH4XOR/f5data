Topic

Error Message

01070712:3: Caught configuration exception (0), Invalid string query key field, too long, length:65522 class:class_string_item key:class_tree field:value - EdbQueryKey.cpp, line 270.

Message Location

You may encounter this message in the following locations:

  • The Configuration utility
  • The /var/log/ltm file
  • The TMOS Shell (tmsh)

Description

This message occurs when the following condition is met:

  • You attempt to load a data group containing an entry that exceeds 65,520 characters.

There is an internal limit of 65,520 characters per internal or external data group list entry. Attempts to load data-group with an entry larger than the limit produce the previous error message, which may be accompanied by the following messages:

01420006:3: 01070712:3: Max string size exceeded during update of attribute:data type:class_string_item max:65520 received:65535
01420001:2: MCP call  'mcpmsg_set_string_item(msg, CID2TAG(m_cid), val.c_str())' failed with error:  16908375, 01020057:3: The string with more than 65535 characters cannot be stored in a message. : msg++/MsgElement.cpp, line 140

Impact

The data group list fails to load, and the system displays the previous error message.

Recommended Actions

  • Reduce the size of the data group list entry to fewer than 65,520 characters. 
  • To reduce the size of the meta data record by 50% or more in the auto-generated data group for the declaration  Set encodeDeclarationMetadata to true using the Settings Endpoint in these situations per the AS3 User Guide https://clouddocs.f5.com/products/extensions/f5-appsvcs-extension/latest/userguide/best-practices.html
