Description

Unable to get show the result of "tmsh show running-config", getting the following error message:

Key management library returned bad status: -7, error:25066067:DSO support routines:DLFCN_LOAD:could not load the shared library

In some cases, you can not access TMOS shell (tmsh), showing with the same error message.

Environment

  • BIG-IP
  • Version 14.1.2
  • Certificates
  • TMOS shell / show running command (tmsh show running-config)

Cause

Missing or incorrectly removed one or more than one certificates from the BIG-IP.

Recommended Actions

  1. Login to BIG-IP CLI.
  2. Check the existing certificate, running the following command:

    ll /config/filestore/files_d/Common_d/certificate_d

    For the example:

    [root@bigip-a:Active:Standalone] config # ll /config/filestore/files_d/Common_d/certificate_d
    total 0
    lrwxrwxrwx. 1 root root 33 Jan 28 22:35 :Common:ca-bundle.crt_30214_1 -> /config/ssl/ssl.crt/ca-bundle.crt
    lrwxrwxrwx. 1 root root 31 Jan 28 22:35 :Common:default.crt_30212_1 -> /config/ssl/ssl.crt/default.crt
    lrwxrwxrwx. 1 root root 36 Jan 28 22:35 :Common:f5-ca-bundle.crt_30210_1 -> /config/ssl/ssl.crt/f5-ca-bundle.crt
    lrwxrwxrwx. 1 root root 32 Jan 28 22:35 :Common:f5-irule.crt_30208_1 -> /config/ssl/ssl.crt/f5-irule.crt
     
  3. Check the certificate on the bigip.conf, running the following command:

    grep 'sys file ssl-cert' /config/bigip.conf -A4

    For the example:

    [root@bigip-a:Active:Standalone] config # grep 'sys file ssl-cert' /config/bigip.conf -A4
    sys file ssl-cert /Common/Test-Cert {
        cache-path /config/filestore/files_d/Common_d/certificate_d/:Common:Test-Cert_81131_1
        revision 1
        source-path /var/run/key_mgmt/IjyoB2/ssl.crt/Test-Cert
    }

    Now we know that the certificate :Common:Test-Cert_81131_1 is missing from the system.
     
  4. Copy one of the existing certificate and name it to the missing certificate, then check if the certificate exists on the system.

    cp /config/filestore/files_d/Common_d/certificate_d/<one_of_the_exitsting_certificate> /config/filestore/files_d/Common_d/certificate_d/<the_missing_certificate>

    For the example:

    [root@bigip-a:Active:Standalone] config # cp /config/filestore/files_d/Common_d/certificate_d/:Common:ca-bundle.crt_30214_1 /config/filestore/files_d/Common_d/certificate_d/:Common:Test-Cert_81131_1

    [root@bigip-a:Active:Standalone] config # grep 'sys file ssl-cert' /config/bigip.conf
    sys file ssl-cert /Common/Test-Cert {

    [root@bigip-a:Active:Standalone] config # ll /config/filestore/files_d/Common_d/certificate_d
    total 4
    lrwxrwxrwx. 1 root root     33 Jan 28 22:35 :Common:ca-bundle.crt_30214_1 -> /config/ssl/ssl.crt/ca-bundle.crt
    lrwxrwxrwx. 1 root root     31 Jan 28 22:35 :Common:default.crt_30212_1 -> /config/ssl/ssl.crt/default.crt
    lrwxrwxrwx. 1 root root     36 Jan 28 22:35 :Common:f5-ca-bundle.crt_30210_1 -> /config/ssl/ssl.crt/f5-ca-bundle.crt
    lrwxrwxrwx. 1 root root     32 Jan 28 22:35 :Common:f5-irule.crt_30208_1 -> /config/ssl/ssl.crt/f5-irule.crt
    -rw-r--r--. 1 root apache 1038 Feb 17 20:13 :Common:Test-Cert_81131_1

    Now you can see the :Common:Test-Cert_81131_1 exists on the system.
     
  5. For now, you can use the TMOS shell or tmsh command.
  6. If you want to remove the certificate properly, run the following command:

    tmsh delete /sys file ssl-cert <Certificate_Name>

    For the example:

    tmsh delete /sys file ssl-cert Test-Cert

    This command will completely remove the certificate from the BIG-IP system.
