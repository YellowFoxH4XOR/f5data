Topic

You should consider using this procedure under the following condition:

  • You want to remove sensitive data from a BIG-IP 6900/8900 FIPS platform before returning it to F5 for a trade-in or a Return Material Authorization (RMA).

Description

This procedure allows you to delete all of the SSL certificates and keys, and clear the internal hardware security module (HSM).

Note: By default the SSL certificates and keys are stored within the HSM.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have SSL certificates and keys stored on an HSM installed in a BIG-IP 6900/8900 FIPS platform.
  • You have administrative access to the Traffic Management Shell (tmsh) and Configuration utility.

Procedures

Removing sensitive data from the HSM

Use the following steps to remove sensitive customer data from an HSM that is installed in a BIG-IP 6900/8900 system, before returning it to F5.

Impact of procedure: All SSL certificates and keys will be removed and the HSM will be initialized. You will be unable to recover the SSL certificates and keys.

  1. Log in to the Configuration utility.
  2. Navigate to System > File Management > SSL Certificate List. The system displays a list of SSL certificates that are installed on the system.

    Note: In versions prior to BIG-IP 11.x, navigate to Local Traffic > SSL Certificates.

  3. Select the SSL certificates that you want to delete.
  4. Click Delete. This removes all the .crt, .exp, and .key files from the system.
  5. Log in to the tmsh utility by typing the following command from the BIG-IP command line:

    tmsh

  6. Initialize the HSM and reconfigure it using a fictitious date, by typing the following command:

    run util fips-util -f init

    Important: This deletes all keys and makes any previously exported keys unusable.

  7. When you see the following prompt, type a security officer (SO) password:

    NFB Initialization Process
    WARNING - all private keys in NFB will be erased after SO password is
    entered!
    Any configuration objects dependent on FIPS keys will cause the
    configuration fail to load.
    Passwords must be at least 7 characters in length.
    Enter no password if you instead wish to cancel.
    New SO Password:
    Re-enter new SO Password:

  8. When the following message displays, type a security domain name.

    Initializing NFB...
    The security domain name must be the same on all FIPS machines.
    Please enter your security domain name:

  9. When the initialization process completes successfully, the system displays the following message:

    The FIPS device has been initialized.
