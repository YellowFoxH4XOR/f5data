Topic

You should consider using this procedure under the following condition:

  • You want to configure the Enterprise Manager system to send logging data to a remote syslog server

Description

You can configure remote syslog logging for the Enterprise Manager system using the tmsh utility. To do so, perform the following procedures:

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have Administrator or Resource Administrator access to the Traffic Management Shell (tmsh)

Procedures

Configuring the Enterprise Manager system to send logging data to one or more remote syslog servers

Impact of procedure: None.

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  2. To configure the remote syslog server, use the following command syntax:

    modify sys syslog remote-servers add { <name> { host <IP address> remote-port <port> }}

    For example, to configure the Enterprise Manager system to send logging information to host 10.0.0.1 on port 514, enter the following command:

    modify /sys syslog remote-servers add { mysyslog { host 10.0.0.1 remote-port 514 }}
  3. Save the change by typing the following command:

    save sys config

Removing the remote syslog server configuration

Impact of procedure: None.

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  2. To remove the remote syslog server configuration, use the following command syntax:

    modify /sys syslog remote-servers none
  3. Save the change by typing the following command:

    save sys config
