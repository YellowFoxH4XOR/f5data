K000161700: F5 Distributed Cloud Web App Scanning (WAS) Recon – Why Some Subdomains Are Not Discovered

Description

When using F5 Distributed Cloud Web App Scanning (WAS) Recon, some subdomains under a corporate domain may not appear in scan results, even if those subdomains are publicly accessible.

Environment

  •  F5 Distributed Cloud Services
  •  Web App Scanning (WAS) – Recon (External Attack Surface Management)

Cause

Recon uses passive OSINT (Open Source Intelligence) discovery methods. Subdomains will not appear in Recon results if they are not indexed or referenced by the third-party data sources that Recon queries. Recon does not perform active probing or DNS brute-forcing.

Reasons a subdomain may be absent from Recon results include:

  • The subdomain is not indexed by public/partner databases, passive DNS datasets, Certificate Transparency logs, or public internet indexing sources.
  • The subdomain has no traceable footprint in public certificate logs.
  • The subdomain is not referenced or linked anywhere on the open web, even if it is technically publicly accessible.
  • The subdomain has never appeared in any OSINT-accessible source.

Answer/Recommended Actions

Understanding Recon's scope and limitations:

  1. Recon simulates what an external passive attacker can discover, mapping externally exposed services using passive discovery only.
  2. Recon does not use active techniques such as aggressive DNS brute-forcing, so subdomains that are public but not broadly referenced or indexed will not appear in results.
  3. No passive OSINT-based tool can guarantee 100% discovery of all assets.

Recommended approach for complete security coverage:

  • Use Recon for continuous monitoring of unintended or unknown public exposure.
  • Manually add known corporate applications (including those not discovered by Recon) directly into the WAS Scan service to ensure they receive full security testing coverage.

If a subdomain is absent from Recon results, it likely means it is not broadly visible through standard OSINT channels, which is generally a positive indicator from an exposure standpoint.

Additional Information

  • Recon is an External Attack Surface Management (EASM) capability, not a comprehensive internal asset inventory tool.
  • The absence of a subdomain from Recon results does not mean the subdomain is unreachable; it means it lacks a discoverable footprint in public data sources.
  • Subdomains intentionally kept low-profile (not linked, not indexed, no public certificates) are less likely to be discovered by external attackers, which is generally a security benefit.
  • For assets that require security scanning coverage regardless of their public visibility, manual addition to the Scan service is recommended.
