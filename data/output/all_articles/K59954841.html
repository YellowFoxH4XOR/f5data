K59954841: How to push a new CA signed certificate to a managed LTM

Type
Support Solution
Published
2022-01-22
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K59954841

Description

To deploy only certificates to a managed devices without creating a new Client or Server SSL Profile and a Virtual Server.

Environment

  • BIG-IQ 
  • BIG-IP LTM
  • SSL Certificates and Keys

Cause
None

Recommended Actions

  1. Import or create the certificate and key on BIG-IQ.
  2. Go to Configuration > LOCAL TRAFFIC > Pinning Policies > Click on the BIG-IP device > Find Local Traffic (LTM) > select
    SSL Certificates and SSL Keys
  3. Choose the Certificate and Key that were created on #1 > Check the box and click on Add Selected
  4. From the Deployment Tab > Evaluate and Deploy > Local Traffic & Network and Create a Deployment:
  5. Leave all the options by default except for the Source Scope and select Partial Changes
  6. Under Source Objects >  Available > select Certificates > check the desired certificate and move it to the right
  7. Select Keys and check the desired key and move it to the right
  8. From the Target Device(s) click on Find Relevant Devices and select the BIG-IP and move it to the right
  9. Deploy and it will only push the certificate and key to the BIG-IP.
