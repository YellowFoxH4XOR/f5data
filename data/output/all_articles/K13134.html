Known Issue

Adaptive compression may select the wrong compression codec.

This issue occurs when the following condition is met:

  • A BIG-IP WOM connection is configured to use adaptive compression.

Impact

Data transfer times are increased through a WOM connection.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Data transfer times are higher than when using a different compression codec.

Workaround

To work around this issue, you can select a different compression codec. To do so, perform the following procedure:

Impact of workaround: None

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Hover mouse over Profiles.
  4. Hover mouse over Services.
  5. Click iSession.
  6. Click the name of the iSession profile of which you are changing the compression setting.
  7. Select the Adaptive check box.
  8. From the Adaptive drop-down menu, select Disabled.
  9. Optional: If want to reduce transfer times over a high bandwidth connection, configure LZO compression by performing the following steps:
    1. Select the Deflate check box.
    2. From the Deflate drop-down menu, select Disabled.
    3. Select the Bzip2 check box.
    4. From the Bzip2 drop-down menu, select Disabled.
    5. Select the LZO check box.
    6. From the LZO drop-down menu, select Enabled.
  10. Optional: If you want to reduce the bandwidth consumed, configure Deflate compression by performing the following steps:
    1. Select the LZO check box.
    2. From the LZO drop-down menu, select Disabled.
    3. Select the Bzip2 check box.
    4. From the Bzip2 drop-down menu, select Disabled.
    5. Select the Deflate check box.
    6. From the Deflate drop-down menu, select Enabled.
    7. Select the Deflate Level check box.
    8. From the Deflate Level drop-down menu, select 4.
  11. Click Update.
