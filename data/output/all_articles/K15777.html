Known Issue

The mcpd service may restart and produce a core file when running the show /sys connection Traffic Management Shell (tmsh) command.

This issue occurs when the following condition is met:

  • The BIG-IP system has more than one million connection references.

Impact

The BIG-IP system temporarily stops processing traffic and may fail over if paired with other BIG-IP systems.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H487655 on the Diagnostics > Identified > Medium screen.
  • When executing the show /sys conn command in the tmsh utility, the BIG-IP system stops processing traffic.
  • Log messages similar to the following example are logged to the /var/log/messages file:

    notice logger: Started writing core file: /var/core/mcpd.bld0.0.110.core.gz for PID 7528
    notice logger: Finished writing 45965794 bytes for core file: /var/core/mcpd.bld0.0.110.core.gz for PID 7528

  • You notice a core file for the mcpd service in the /shared/core directory, with a correlating timestamp to the traffic interruption, similar to the following example:

    -rw-r--r-- 1 root root 45965794 Oct 30 11:37 mcpd.bld0.0.110.core.gz

Workaround

To work around this issue, you can use an alternate tmsh command to show a cumulative display of connections. To do so, perform the following procedure:

Impact of workaround: Command output does not display the actual IP addresses in the connection table.

  1. Log in to the Traffic Management Shell (tmsh).
  2. Type the following command:

    show /sys performance connection

    Command output appears similar to the following example:

    Sys::Performance Connections
    ---------------------------------------------------------------------------
    Active Connections Current Average Max(since 10/30/14 08:59:12)
    ---------------------------------------------------------------------------
    Connections 20 21 28

    ---------------------------------------------------------------------------
    Total New Connections(/sec) Current Average Max(since 10/30/14 08:59:12)
    ---------------------------------------------------------------------------
    Client Connections 2 2 3
    Server Connections 2 2 3

    ---------------------------------------------------------------------------
    HTTP Requests(/sec) Current Average Max(since 10/30/14 08:59:12)
    ---------------------------------------------------------------------------
    HTTP Requests 0 0 0

  3. To exit the tmsh utility, type quit.
