Known Issue

This is the result of a known issue. The collect logs command does not honor the start-time or end-time options. When the start-time and/or end-time option is specified, the time constraint is not enforced and all of the logs are collected.

Note: For information about the collect logs command, refer to the ARX CLI Reference Guide.

F5 Networks Product Development tracked this issue as ARX ID 37579 and it was fixed in ARX version 5.1.5. For information about upgrading, refer to the ARX Release Notes.
