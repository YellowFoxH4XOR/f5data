Description

After upgrade from you cannot re-apply or change the default gateway to the management console.

When you go into System > Platform > Configuration and add 10.10.10.1 to the Management Route you get the error message:

01020037:3: The requested Management Route (/Common/default) already exists.

Environment

  • BIGIP
  • Management 
  • Route
  • Upgrade

Cause

Unknown at the time of creating this article.

Recommended Actions

From CLI ( bash)  rung the following commands

tmsh delete /sys management-route default
tmsh list /sys management-route
tmsh create /sys management-route default gateway 10.10.10.1
tmsh save /sys config
