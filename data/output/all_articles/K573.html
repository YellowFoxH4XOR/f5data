K573: In rare cases, 3-DNS may create a BIG-IP object with an address of 127.0.0.1

Source

Known Issue

This is most likely the result of a known issue. If you use the Configuration utility to add multiple combination BIG-IP/3-DNS systems to a datacenter and you incorrectly specify the self IP address for a BIG-IP system, then correct it, 3-DNS will add a BIG-IP object with a self IP address of 127.0.0.1.

F5 Networks Product Development tracked this issue as CR32755 and CR41844.

Workaround

To fix this issue, remove the data center and configure it again, specifying the correct self IP address.
