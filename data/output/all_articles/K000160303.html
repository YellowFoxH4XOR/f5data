Description

When viewing APM access profile statistics using the command tmsh show apm profile access <profile_name>, we may see different session counters including "current active sessions", "current established sessions" and "current pending sessions".

This article explains the relationship between these session types.

Environment

  • BIG-IP APM (Access Policy Manager) All versions
  • Access Profile statistics

Cause

We need to understand the difference between the following session statistics displayed in the output of tmsh show apm profile access <profile_name>:

    current active sessions
    current established sessions
    current pending sessions

Example output:

--------------------------------------------------------------
ACCESS Profile: example1
--------------------------------------------------------------
    User Session Statistics:
--------------------------------------------------------------
    total sessions: 0
    total established sessions: 0
    current active sessions: 0
    current pending sessions: 0
    current established sessions: 0

 

Answer/Recommended Actions

APM tracks sessions in different states as they progress through the access policy evaluation and authentication process.
Resolution
Session Status Definitions

The relationship between these session types is:

active = established + pending

Where:

    Established sessions: Sessions that have successfully completed the access policy evaluation and authentication process. These sessions are fully authenticated and authorized.

    Pending sessions: Sessions that are currently in progress through the access policy but have not yet completed authentication or policy evaluation.

    Active sessions: The total count of all current sessions, which includes both established sessions and pending sessions.
