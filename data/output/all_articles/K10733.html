Known Issue

This is the result of a known issue. Occasionally, the VIPRION system may log the following warning message to the /var/log/ltm file:

notice chmand[0]: 012a0005:5: FanSpeedUpdate: chassis overheat detected

This warning message is not logged as a result of an overheating chassis, but because some fans are now running at full speed. This message indicates that the temperature inside the VIPRION system has reached the point in which the fans need to run at full speed to keep the system cool. This message is inaccurate and should be ignored; it is normal behavior for the fans to run at full speed and should not be cause for alarm.

Note: You can use the bigpipe platform command to monitor all thermal sensors and fans inside the VIPRION platform.

Note: For more information about the VIPRION system non-operational specification, refer to the Platform Guide: VIPRION.

F5 Product Development tracked this issue as CR129794 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WOM release notes.
