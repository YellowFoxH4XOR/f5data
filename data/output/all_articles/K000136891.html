Description

You've enabled the OIDC funtion in NGINX Ingress Controller and want to customize the OIDC SameSite cookie value to fit your environment. For example, change the SameSite value to 'none' to enable a cross-site request with the cookie via a iframe script.

Environment

  • NGINX Ingress Controller
  • OIDC

Cause

Once OIDC is enabled via the command-line arguments in the nginx-ingress deployment, a default oidc_common.conf file with the OIDC related configurations will be created under /etc/nginx/oidc folder inside the nginx-ingress pod. 

You simply can run the command below to check.

kubectl exec -n nginx-ingress <nginx-ingress-pod-name> -it -- cat /etc/nginx/oidc/oidc_common.conf

You can leverage the ConfigMap resource to create an oidc_common ConfigMap to modify the value and overwrite the default oidc_common.conf file.

Recommended Actions

1. Run the command below and confirm there is no existing oidc-common-config-map

kubectl get cm -n nginx-ingress

2. Run the command below and get the contents of oidc_common.conf from the Github repository and create a configmap called oidc-common-config-map

NOTE: Change 'vX.X.X' in the url to the actual version(v3.7.2 etc) in use.
kubectl create configmap oidc-common-config-map --from-literal=oidc_common.conf="$(curl -k https://raw.githubusercontent.com/nginxinc/kubernetes-ingress/vX.X.X/internal/configs/oidc/oidc_common.conf)" -n nginx-ingress

3. NGINX sets the SameSite value to 'Lax' by default. Run the command below and edit the oidc-common-config-map and change the $oidc_cookie_flags value of SameSite to 'none'.

kubectl edit configmap oidc-common-config-map -n nginx-ingress
....
map $proto $oidc_cookie_flags {
   http "Path=/; SameSite=none;"; # <<<<< Change the SameSite value to 'none'
   https "Path=/; SameSite=none; HttpOnly; Secure;"; # <<<<< Change the SameSite value to 'none'
}
....

4. Run the command below to edit the deployment config of nginx-ingress, and modify the following sections.

kubectl edit deploy nginx-ingress -n nginx-ingress

#spec.template.spec
volumes: # Add this to create a volume for the ConfigMap created in step 2 
- name: oidc-common-volume
  configMap:
    name: oidc-common-config-map # Must match the name of the ConfigMap created in step 2

#spec.template.spec.container
- args:
  - -enable-oidc # Make sure OIDC is enabled.
  volumeMounts: # Add this to mount the volume created above for oidc-common-volume
  - name: oidc-common-volume
    mountPath: /etc/nginx/oidc/oidc_common.conf 
    subPath: oidc_common.conf
    readOnly: true

5. Once applied a new nginx-ingress pod will be re-created automatically, verify oidc_common.conf via the command below and check on the SameSite values.

kubectl exec -it -n nginx-ingress <ingess-ingress-pod-name> -- cat /etc/nginx/oidc/oidc_common.conf
