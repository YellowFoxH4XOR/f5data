K000130386: Intermittent BIG-IP VPN connection dropping with error message : Network event occurred

Type
Support Solution
Published
2022-12-28
Updated
2026-02-15
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000130386

Description:
The VPN is not stable and noticing random disconnection.If in the CTU report generated if you notice below logs:

\URDialer.cpp, 2941, CURDialer::CheckProxyInfo, Different flags (1:5), Resetting Internet connection options
\NetworkAvailabilityMonitor.cpp, 236, CNetworkAvailabilityMonitor::Run, Network event occurred
\NetworkAvailabilityMonitor.cpp, 286, WaitForConnectionToSettle::WaitForConnectionToSettle, Network event occurred while waiting for connection to settle
\URDialerRouting.cpp, 880, CUDialer::OnTimer(), Routing table changed, 16, |Existing records on other adapter have changed
 

Environment:

  • BIG-IP APM 13.X or higher.

Cause:

End user internet stability and reliability would cause network adapter reset which cause the VPN connection to reset. Examples would include poor internet connection, connection switching between wifi/data networks, Client operating system issues/configuration.

Recommended Actions :

  • Refer to your client operating system network logs to identify any network event that may result in network connectivity issues.
  • Troubleshoot by isolating/ruling out issues one at a time. For example, change to a known stable wifi connection from a wifi/data connection.
