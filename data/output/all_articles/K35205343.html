Description

The Management IP changes automatically in Google cloud to a different IP than the one configured.

  • The var/log/cloud/onboard.log shows that the management IP is changed like next:
Fri Apr 30 14:34:20 PDT 2021
Starting custom config
Set TMM networks
command tmsh create sys management-ip 10.10.10.10/32 successfully executed.
 

Environment

  • BIG-IP instance in Google cloud.
  • The startup scripts located in /config/cloud/ have a collect-interface.sh script and an interface.config file.

Cause

The MGMTADDRESS value of the file config/cloud/interface.config is different compared to the management IP that is configured. After a reboot, there is a wait and then the script replaces all the IP information based upon the interface.config file.

Recommended Actions

Modify the MGMTADDRESS value to match the correct management IP.
