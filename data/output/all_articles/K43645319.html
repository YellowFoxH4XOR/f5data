Description

Automatic upgrading of browser helpers ("F5 Endpoint Inspector.app" and "F5 vpn.app") on recent MacOS may fail, because the older versions cannot be deleted in certain situations.
The helper application installer packages are downloaded by browsers automatically when needed, or can be found in the TMUI Admin in the "About" tab under Downloads.

    F5 Endpoint Inspector for Mac OS ( mac_f5epi.pkg )
    F5 VPN for Mac OS ( mac_f5vpn.pkg )

Environment

  • APM Network Access VPN supporting MacOS devices
  • MacOS upgraded to 12.3 (Monterey)
  • edgeclients prior to 7.2.2.2 deployed

Cause

With the Apple upgrade to MacOS 12.3, the System Python has been removed by Apple.
In the older f5epi.app and f5vpn.app installer packages (.pkg) a python script was installed to help with the un-instalation.
Once the MacOS device is upgraded to 12.3 or greater, this python script fails.

Recommended Actions

Follow the actions below for to remove the appropriate Application 
  1. Manually uninstall the complete Browser helper application from the Applications directory (this can also be simply done in Finder)

    sudo rm -r /Applications/F5\ Endpoint\ Inspector.app/
    sudo rm -r /Applications/F5\ VPN.app/
     
  2. Optionally, If these files still exist, then remove the python script from the users Application support directory and the launch-agent from the user Library.

    rm ~/Library/Application\ Support/F5\ EPI/uninstall.py
    rm ~/Library/LaunchAgents/com.f5.f5epihelper.plist

    rm ~/Library/Application\ Support/F5\ VPN/uninstall.py
    rm ~/Library/LaunchAgents/com.f5.f5vpnhelper.plist
     
  3. Manually installing a new package from the apmclients.iso version 7.2.2.2 or 7.2.3 or greater should re-install these helpers correctly.
    Or they should now be able to be automatically installed by connecting from the browser.

     

Additional Information

These new versions of the Helper Applications now install an uninstall.sh script that uses 'bash' rather than python.
