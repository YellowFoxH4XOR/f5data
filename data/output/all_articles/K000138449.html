K000138449: Https redirect not working when defined in the nginx-ingress configmap

Type
Support Solution
Published
2024-02-27
Updated
2024-02-27
Source
https://my.f5.com/manage/s/article/K000138449

Description

You are using VirtualServers and you need to enable TLS/https redirect for all servers.

Environment

3.3

Cause

You can customize the NGINX configuration for VirtualServer and VirtualServerRoutes resources using the ConfigMap. Most of the ConfigMap keys are supported, with the following exceptions:

proxy-hide-headers
proxy-pass-headers
hsts
hsts-max-age
hsts-include-subdomains
hsts-behind-proxy
redirect-to-https
ssl-redirect

Recommended Actions

Add the following entry to your nginx-config configmap:

apiVersion: v1
data:
  ...
  server-snippets: |
    if ($scheme = 'http') {
        return 301 https://$host$request_uri;
    }
kind: ConfigMap
metadata:
  name: nginx-config
  namespace: nginx-ingress

You can also configure this per Virtualserver using TLS-Redirect

Additional Information

After editing the configmap you should see the configuration reflected in the nginx configuration:

server {
    listen 80;
...
    if ($scheme = 'http') {    return 301 https://$host$request_uri;}
