Known Issue

This is the result of a known issue. HTTP hardware compression is unavailable on BIG-IP 8800 platforms running version 9.4.7. If an HTTP virtual server has compression enabled, server responses that qualify for compression will fail to be processed by the BIG-IP system and will not be forwarded on the client side. In addition, the BIG-IP system will periodically log the following error message to the /var/log/tmm file:

co0: Request timed out.

This issue is caused by the Cavium Octeon driver that shipped with BIG-IP version 9.4.7.

Note: HTTP hardware compression is available on only those BIG-IP systems that are licensed for it.

F5 Product Development tracked this issue as CR119245 and it was fixed in BIG-IP version 9.4.8. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue was fixed in an Engineering Hotfix issued for BIG-IP version 9.4.7. To obtain this hotfix, contact F5 Technical Support and reference this Solution.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.
