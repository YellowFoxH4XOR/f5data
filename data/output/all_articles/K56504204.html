Known Issue

The BIG-IP system may stop forwarding server DHCPOFFER and DHCPACK messages to clients.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP system to act as a Dynamic Host Configuration Protocol (DHCP) relay agent.
  • The BIG-IP system incorrectly reaps the connection flow for the DHCP communication.

For example, this issue can occur if the routing table on the DHCP server is configured incorrectly and the DHCP server is unable to respond to unicast requests from the client.  If the client subsequently sends broadcast renewal requests, a new connection is created which may eventually time out.  When the BIG-IP system reaps the connection, the BIG-IP system may stop relaying DHCPOFFER and DHCPACK messages back to DHCP clients.

Impact

Clients stops receiving DHCPOFFER and DHCPACK response messages from the DHCP server.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Clients are unable to renew DHCP leases.
  • Clients are unable to obtain IP addresses using DHCP.

Workaround

If routing problems are preventing the DHCP server from communicating with clients, correct the routing problems before implementing the BIG-IP system as a DHCP relay agent.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
