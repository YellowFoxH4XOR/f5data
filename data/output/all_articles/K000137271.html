K000137271: 01b90026:3: Bot defense profile (/Common/bot-defense-profile) error: whitelist contains empty url and source.

Type
Support Solution
Published
2023-12-04
Updated
2023-12-04
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.1.0
Source
https://my.f5.com/manage/s/article/K000137271

Description

The BIG-IP did not load the configuration after an mcpd forceload when a bot defense profile contains a whitelist with a URL and source as wildcard showing the error 01b90026:3: Bot defense profile (/Common/bot-defense-profile) error: whitelist contains empty url and source.

Normally when you create a bot whitelist with the value of "Any" and wildcard "*", it gives you an error "01b90026:3: Bot defense profile (/Common/bot-defense-profile) error: whitelist contains empty url and source." which is expected behavior, but if you modify an existing whitelist and update the values to Any and *, it allows to save it which is not expected, and after an upgrade or mcpd forceload the unit is not able to load the config due to that error.

Environment

BIG-IP ASM.

Cause

BUG ID 1408281

Recommended Actions

Use vi or nano to delete or hash the invalid lines e.g.

# whitelist_item_3 {
# match-order 3
# source-address ::/32
# url *
# }
