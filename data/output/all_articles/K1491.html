Known Issue

This is the result of a known issue. The Configuration utility appears to allow you to disable a datacenter, but does not actually change the configuration. Currently, you cannot disable a datacenter using the Configuration utility.

F5 Networks Product Development tracked this issue as CR28348 and CR41899.

Workaround

Important: To use the following workaround, you must be running 3-DNS version 4.6.3 or 4.6.4. For information about upgrading, refer to the 3-DNS Release Notes. If upgrading is not an immediate option, refer to K4334: Known Issue: It is not possible to disable a data center associated with a wide IP using 3dpipe.

To disable a datacenter using the command line, perform the following steps:

  1. Log in to the command line.
  2. Disable the datacenter, using the following command syntax:

    3dpipe datacenter <datacenter> disable

    For example:

    3dpipe datacenter Seattle disable

  3. To disable a datacenter for a specified length of time, use the following command syntax:

    3dpipe datacenter <datacenter> disable <seconds>

    For example, to disable the Seattle datacenter for five minutes, you would type the following command:

    3dpipe datacenter Seattle disable 300
