Known Issue

This is the result of a known issue. If you specify an email account for log archival in the Purge Logs section of the Device Management: Maintenance: Logs page, archived logs are not emailed at the scheduled log purge intervals. However, if you select the Click to purge logs right now link in the Purge Logs section, the current logs are archived and sent to the email address.

F5 Product Development tracked this issue as CR117160 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative HF-603-4, which was issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by configuring an FTP or SCP account for log archival. To do so, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Device Management: Maintenance: Logs page.
  3. In the Purge Logs section, select the Create archive check box if it is not already selected, and click the Update button.
  4. Select the FTP or SCP check box.
  5. Click the Update button.
  6. Enter the FTP or SCP account information.
  7. Click the Update button.
