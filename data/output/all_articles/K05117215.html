Description

Zonerunner service not starting.  The following will be logged in the /var/log/daemon.log:

  Nov 18 23:20:23 slot1/hostname.domain.com err named[31303]: /config/named.conf:40: change directory to '/config/namedb' failed: file not found
  Nov 18 23:20:23 slot1/hostname.domain.com err named[31303]: /config/named.conf:40: parsing failed: file not found

 

Environment

  • DNS provisioned
  • BIND configured

Cause

Missing zone database files.
 

Recommended Actions

From the command line (SSH) logged in as root or another administrative user, run the following:

  1.   bigstart stop named
  2.   mkdir -p /var/named/config/namedb
  3.   chown named.named /var/named/config/namedb
  4.   restorecon -R /var/named
  5.   bigstart start named


Note, that if /var/named/config/named.conf has zones set up, there may be other errors and named/zrd daemon restarts until the zone files are put in place.
