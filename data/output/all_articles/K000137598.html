Description

F5OS-C copy or rename of a partition

 

Environment

F5OS-C 1.6.1

RFE

Partition copy

 

Cause

Being able to rename a partition is linked to existing RFE ID 1324957

 

Recommended Actions

To properly copy a partition:

 

To copy a partition. The F5OS-C configuration contains data that includes the following:

 

Portgroups of the assigned slots/nodes/blades

VLANs

Logging setup

Authentication servers

Product license

HA setup

 

 

 

Show running config:

 

syscon-1-active# show running-config partitions partition foobar

partitions partition foobar

config enabled

config iso-version 1.5.1-14085

config mgmt-ip ipv4 address 10.154.81.91

config mgmt-ip ipv4 prefix-length 24

config mgmt-ip ipv4 gateway 10.154.81.254

!

syscon-1-active# config

Entering configuration mode terminal

 

 

Copy of the partition:

 

syscon-1-active(config)# copy partitions partition foobar foobar2

syscon-1-active(config)# show configuration

partitions partition foobar2

config enabled

config iso-version 1.5.1-14085

config mgmt-ip ipv4 address 10.154.81.91

config mgmt-ip ipv4 prefix-length 24

config mgmt-ip ipv4 gateway 10.154.81.254

!

syscon-1-active(config)#

 

 

 

So, the sample copy partition above, was to copy the 'foobar' configuration object, allowing for the copy to have a new name. Not yet a committed change, one would need to change the IP address, and the new partition would be completely fresh. No tenants inside.

 

This is not a renaming. It's the creation of a brand new partition called foobar2, foobar1 still exists.
