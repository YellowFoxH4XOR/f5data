Description

The ConfigSync operation fails on the peer device and the system does not apply the changes.

  • ConfigSync using GUI or CLI, doesn't work
  • Incremental or Full-sync, still the same issue
  • Push or Pull synching, nothing happens
  • Error messages in /var/log/ltm such as: 

    01071488:3: Remote transaction for device group <device_group> to commit id <commit_id> <remote_host> failed with error 01070712:3: Caught configuration exception (0), Invalid monitor rule instance identifier: <instance_id>
     

Environment

  • BIG-IP Platform and Virtual Edition
  • HA with 2 or more devices
     

Cause

This message occurs when the Configuration validation fails on a peer device during a ConfigSync operation.
 

Recommended Actions

  1. Manually re-load the configuration on all devices by typing the following command:
    tmsh load sys config
    Note: Loading the configuration should not impact processing established connections in most configuration environments
  2. Perform the ConfigSync.
If the above steps doesn't resolve the issue, perform the following procedure in the Configuration Utility on the target device:
  1. Delete all Virtual Servers, Pools and Monitors.
  2. Perform the ConfigSync again.
