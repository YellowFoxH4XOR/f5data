Topic

Installation fails when you attempt to install to a sixth boot location on BIG-IP RAID-capable platforms, which also have a compact flash (CF) card. This applies to BIG-IP 6900, 8900, 8950, and 11000 platforms.

Description

On the affected BIG-IP platforms, the boot partition for each installation is held on the CF card. This situation limits the number of installs on these platforms to five. The sixth installation will fail with a generic failed message. You can view this message in the following locations:

  • In the BIG-IP Configuration utility, under System > Software Management > Image List. The Install Status displays a red failed status, and pointing to the error displays the following message:

    slot0: failed (Failed to install)

  • From the Traffic Management Shell (tmsh), if you use the tmsh show /sys software command, the system displays a message similar to the following example:

    Sys::Software Status
    Volume Product Version Build Active Status
    ----------------------------------------------------------------------
    MD1.1 BIG-IP 10.2.0 1707.0 no complete
    MD1.2 BIG-IP 11.6.0 0.0.401 yes complete
    MD1.3 BIG-IP 11.6.0 0.0.401 no complete
    MD1.4 BIG-IP 11.6.0 0.0.401 no complete
    MD1.5 BIG-IP 11.6.0 0.0.401 no complete
    MD1.6 BIG-IP 11.6.0 0.0.401 no failed (Failed to install.)

  • The /var/log/liveinstall.log file displays messages similar to the following example:

    error: copy /mnt/tm_install/1676.2HNtQa/boot/initrd failed; No space left on device
    error: Disk full (boot partition). See SOL#10636
    Terminal error: Failed to install.
    *** Live install end at 2014/09/25 14:29:35: failed (return code 2) ***

Recommendations

When you plan installations on affected platforms, you should consider the following factors:

  • Limit installations to five or fewer.
  • If you need multiple versions for archival purposes, consider creating a UCS backup before removing or overwriting older installations.
