Known Issue

This is the result of a known issue. Active mode FTP data connections may fail when used through a secure network address translation (SNAT).

When two FTP connections from different clients request the same port for a data connection and a SNAT is configured, the second data connection may fail. This behavior occurs when the SNAT reuses the requested port before the node/server clears the TIME_WAIT state for the previous connection used for the same port.

F5 Product Development tracked this issue as CR108290 and it was fixed in BIG-IP LTM 9.4.8 and 10.0.0. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-9.3.1-HF5, which has been issued for BIG-IP 9.3.1 for the BIG-IP 9.3 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
