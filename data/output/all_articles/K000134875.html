K000134875: tomcat/syslog-ng constantly restarting

Type
Support Solution
Published
2023-05-31
Updated
2023-06-13
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.7
Source
https://my.f5.com/manage/s/article/K000134875

Description

Experiencing GUI instability

  • CLI indicates tomcat constantly restarting
  • catalina.out file indicates syslog-ng failing to start

Environment

  • BIG-IP v15.1.7
  • BIG-IP GUI
  • Syslog-ng
  • tomcat

Cause

Syslog-ng was misconfigured and failed to start, thus causing tomcat to continuously restart as well.

Recommended Actions

  1. Correct the missing local-ip from the syslog-ng config.
  2. Restart tomcat
  3. Monitor kern.log for any potential OOM killer actions against the java process that will prevent tomcat from starting.
