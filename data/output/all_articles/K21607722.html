Description

How to check if the Velos / rSeries is using AC / DC PSU?

Environment

  • Velos / rSeries
  • F5OS

Cause

None

Recommended Actions

    Velos

    The VELOS chassis can only be purchased as an AC or DC configuration.

    Important: The power supplies cannot be interchanged.

    Back view of the VELOS CX410 AC chassis (CX1610 is similar)

    1. Power supply controller 1
    2. Power supply controller 2
    3. AC Power supply receptacles (1-4)
    4. Chassis ground terminals
    5. Fan Tray

    Back view of the VELOS CX410 DC chassis (CX1610 is similar)

    1. Power supply controller 1
    2. Power supply controller 2
    3. DC Power supply receptacles (1-4)
    4. Chassis ground terminals
    5. Fan Tray
    TypeParts (Model) NumberImage
    AC PSUSPAFFIV-07 / PWR-0366-xx

    DC PSUSPDFFIV-08 / PWR-0367-xx

    You can verify the PSU parts number from the output of the following F5OS-C CLI command:

    show components component psu-* state

    The command output should look similar to the following example:

    syscon-1-active# show components component psu-* state
    components component psu-1
     state serial-no 19331BPJ0020
     state part-no SPAFFIV-07
     state empty false
    components component psu-2
     state serial-no 19332BPJ0086
     state part-no SPAFFIV-07
     state empty false
    components component psu-3
     state serial-no "Not Available"
     state part-no "Not Available"
     state empty true
    components component psu-4
     state serial-no "Not Available"
     state part-no "Not Available"
     state empty true
    components component psu-controller-1
     state firmware-version 1.02.669.0.1
     state software-version 2.00.781.0.1
     state serial-no  sub0759g002X
     state part-no    "SUB-0759-04 REV A"
     state empty      false
    components component psu-controller-2
     state firmware-version 1.02.669.0.1
     state software-version 2.00.781.0.1
     state serial-no  sub0759g002U
     state part-no    "SUB-0759-04 REV A"
     state empty      false

    Alternatively, you can obtain this information from the F5OS-C webUI page: SYSTEM SETTINGS >> System Inventory
