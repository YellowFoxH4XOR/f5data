Known Issue

When you configure the Mode as Port for the BIG-IP GTM FTP monitor, the BIG-IP GTM system probes the Server or Virtual Server object using passive mode FTP.

This issue occurs when all of the following conditions are met:

  • The BIG-IP GTM FTP monitor is configured with the Mode set to Port
  • The BIG-IP GTM FTP monitor is assigned to the Server or Virtual Server object created for an FTP server

When the FTP monitor Mode setting is configured as Port, the intended behavior is for the BIG-IP GTM system to use active FTP mode (also known as Port mode) when sending the monitor request.

Impact

The BIG-IP GTM may not be able to serve wide IP requests.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Configuration utility displays the status of an FTP server that only supports active mode FTP as green
  • The BIG-IP GTM system indicates that the FTP server that only supports active mode FTP is UP, by logging messages that appear similar to the following example:

    011ae0f2:1: Monitor instance <monitor name> <IP address>:<port> UNKNOWN_MONITOR_STATE --> UP from <GTM IP> (state: success)

    In this error message, note the following:

    • <monitor name> is the monitor that is assigned to the Server or Virtual Server object
    • <IP address> is the IP address of the Server or Virtual Server object to be monitored
    • <port> is the port of the Server or Virtual Server object to be monitored
    • <GTM IP> is the IP address of the GTM system monitoring the Server or Virtual Server object

Workaround

Impact of workaround: None.

To work around this issue for the BIG-IP FTP Virtual Server, you can configure the BIG-IP GTM system to use the BIG-IP monitor for monitoring the BIG-IP LTM system that hosts the BIG-IP FTP Virtual Server. To configure the BIG-IP GTM system to monitor the BIG-IP LTM system with the BIG-IP monitor, refer to the Defining the Physical Network chapter of the Configuration Guide for BIG-IP Global Traffic Manger.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

For generic FTP servers that are not behind the BIG-IP LTM system, you can configure an external active FTP monitor on the GTM system to monitor the generic FTP servers. For a list of sample external monitors, refer to the Advanced Design & Config Code Share Wiki on DevCentral. Alternatively, you can configure the generic FTP servers to include support for passive mode FTP and configure the Mode for the BIG-IP GTM FTP monitor as Passive.
