Description

Starting in BIG-IP 11.2.0, when the BIG-IP system saves a configuration, the system saves the service port as a service number in the configuration file. For example, a pool with the name poolExample is configured with a pool member 192.168.1.1:25. After the poolExample pool configuration is saved to the /config/bigip.conf configuration file, the poolExample pool configuration becomes the following configuration:

ltm pool /Common/poolExample {
    members {
        /Common/192.168.1.100:25 {
            address 192.168.1.100
        }
    }
}

This behavior is by default and is non-configurable.

Additionally the BIG-IP system, by default, displays the service port as a service name in the Traffic Management Shell (tmsh). Using the previous example, the BIG-IP system displays this configuration snippet similar to the following example in the tmsh utility:

ltm pool /Common/poolExample {
    members {
        /Common/192.168.1.100:smtp {
            address 192.168.1.100
        }
    }
}

You can configure this by modifying the service option for the global-settings component within the cli module in the tmsh utility.

For example, if you want the BIG-IP system to display the service port instead of service name in the tmsh utility, you would type in the following command in the tmsh utility:

modify /cli global-settings service number

To revert back to the default behavior of displaying the service port as a service name, you would type in the following command in the tmsh utility:

modify /cli global-settings service name

Save your changes if you want the change to persist in the next configuration reload by typing the following command in the tmsh utility:

save /sys config
