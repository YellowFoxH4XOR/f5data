Description

In some environments it will be necessary to insert APM variables into HTTP Headers to send backend application servers.

Environment

  • BIG-IP APM
  • iRules
  • HTTP Headers

Cause

None

Recommended Actions

To insert BIG-IP APM variables as HTTP headers when sending traffic to a destination HTTP server you can craft a custom iRule as explained in the following procedure.
Note: Ensure that you have configured an AD or LDAP Query in the access policy to populate the session variables referenced in the iRule.
Create iRule to assign variables.

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. Click iRules.
  4. Click iRule List.
  5. Click Create to create a new iRule.
  6. In the Name field, enter a name for the iRule.
For Example:
http_header_attributes
  1. In the Definition field, enter the iRule with the proper values.
    Note: Check your session variable attributes and ensure they are populated to assign them.
when HTTP_REQUEST_SEND {
    clientside {
        HTTP::header replace NAME [ACCESS::session data get session.ad.last.attr.displayName]
        HTTP::header replace GROUPS [ACCESS::session data get session.ad.last.attr.memberOf]
        HTTP::header replace EMAIL [ACCESS::session data get session.ad.last.attr.mail] 
        HTTP::header replace USERID [ACCESS::session data get session.ad.last.attr.sAMAccountName]
    }
}  
  1. Click the Finished button to save the iRule.
  2. Under Local Traffic, click Virtual Servers.
  3. Click the name of the virtual server to which the access policy will be applied.
  4. Select the Resources tab.
  5. Next to iRules, click Manage.
  6. In the Available box, highlight the name of the iRule you just created.
  7. Click the << button.

    The iRule moves to the Enabled box.

  8. Click Finished.

    Additional Information

    When testing the iRule, you can apply the following iRule to log the HTTP Headers:

    when HTTP_REQUEST {
        log local0. "---- Request URI = [HTTP::uri] ----"
        foreach x [HTTP::header names] {
           log local0. "Request header($x) = [HTTP::header $x]"
        }
    }
    when HTTP_REQUEST_RELEASE {
        log local0. "[IP::client_addr]:[TCP::client_port]: [HTTP::method] to [HTTP::host][HTTP::uri] using pool [LB::server]"
        foreach x [HTTP::header names] {
            log local0. "Request header($x) = [HTTP::header $x]"
        }
        log local0. "-------"
    }
