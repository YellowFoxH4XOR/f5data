Description

SSLO resets inline L2 service with cause code "Failed to find Sync Data""

Environment

  • BIG-IP licensed and configured for SSLO

  • SSLO service "generic inline L2" deployed
  • Service device changing L3/4 attributes (eg: TCP port)

Cause

Misconfiured service..  L2 configured services should not modify upper layer attributes

Recommended Actions

Convert the "generic inline L2" service to become "generic inline L3"

Additional Information

Making this change will probably require making some changes to the network addresses on the inline device.
