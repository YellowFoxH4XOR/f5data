Description
IPI blocking IPv6 Link Local neighbor discovery protocol (FE08) 

For example:
config # iprep_lookup fe80::xxxx:xxxx:xxxx:xxxx
opening database in /var/IpRep/F5IpRep.dat, /var/IpRep/F5IpV6Rep.dat
size of IP reputation database = 27006021, 893836
iprep threats list for ip = fe80::xxxx:xxxx:xxxx:xxxx is:
    bit 1 - Windows Exploits
    bit 7 - Phishing

Environment

  • Big-IP
  • AFM
  • IP Intellegence

Cause

Brightclould has updated the database and should reflect the correct one

config # iprep_lookup fe80::xxxx:xxxx:xxxx:xxxx
opening database in /var/IpRep/F5IpRep.dat, /var/IpRep/F5IpV6Rep.dat
size of IP reputation database = 26905571, 895299
iprep_lookup not found for ip = fe80::xxxx:xxxx:xxxx:xxxx

Recommended Actions

Make sure IPI database is set to autoupdate 

Manual Chapter : Enabling IP Address Intelligence
