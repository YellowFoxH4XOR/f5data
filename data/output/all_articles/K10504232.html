Description

In some scenarios, where a client certificate authentication is involved, there may be a need for the BIG-IP system to verify the client certificate revocation status using Online Certificate Status Protocol (OCSP) by connecting to an OCSP responder.  If the OCSP responder is on the Internet, access to the Internet may need to go through internal proxy servers in many environments. For the described use case, the BIG-IP system does not support connecting to an OCSP responder via a proxy server.  This use case applies to both BIG-IP LTM OCSP Responder profile and BIG-IP APM (OCSP Auth agent).

Note: The BIG-IP LTM OCSP stapling profile however does support the use of a proxy server.

Environment

  • client certificate authentication configured AND
  • client certificate revocation status checking using OCSP is required AND
  • BIG-IP needs to connect to an OCSP responder via a proxy server to check client certificate revocation status using OCSP
