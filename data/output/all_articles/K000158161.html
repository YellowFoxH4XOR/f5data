Description

This article describes a possible cause of encountering the following log message located in the ltm log file:

  • err guestagentd[]: 01810004:3: Proxy process: XXXX exited with status: 256. Respawning.

Environment

  • BIG-IP LTM
  • vCMP Guest

Cause

The log can appear when the VMchannel cannot be established between the vCMP host and guest successfully, when the VCMP host needs to poll the guest status periodically. It is also noted that VMchannel will attempt to establish a connection most likely every 3 seconds. This error can be related to the issues with the device Certificate and Key pair being invalid. 

Recommended Actions

Review logs in /var/log/httpd/httpd_errors to see if the following errors appear:

emerg httpd[31963]: [ssl:emerg] [pid 31963] AH02238: Unable to configure RSA server private key
emerg httpd[31963]: [ssl:emerg] [pid 31963] SSL Library Error: error:0B080074:x509 certificate routines:X509_check_private_key:key values mismatch

If so, please follow the steps described in this article to check the md5sum and, if needed, create a new pair by following: K46055636

Additional Information

If the mentioned logs related to the certificate and key pair do not appear in the logs and httpd on the VCMP guest is not functioning, restarting httpd may help with this.
