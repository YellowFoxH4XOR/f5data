K000156784: Windows App on iOS/iPadOS and MacOS access the RDP on the webtop, get the Error code 0x300006c

Type
Support Solution
Published
2025-10-03
Updated
2025-10-03
Applies to
  • BIG-IP
  • BIG-IP APM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000156784

Description

Launching Native RDP resources from the BIG-IP APM webtop may result in error code 0x300006c when using the Windows App on iOS/iPadOS and MacOS. This error prevents successful establishment of RDP sessions after updating to certain recent versions of the Windows App.

Environment

  • BIG-IP APM
  • Virtual server
  • Access profile
  • Native RDP
  • Windows APP Mobile 11.2.0 on iOS
  • Windows APP 11.2.3 on Mac OS

Cause

A bug in specific versions of the Windows App for iOS/iPadOS and MacOS causes failure to launch Native RDP resources via BIG-IP APM webtop, resulting in error code 0x300006c.

Recommended Actions

  • Upgrade the Windows App to the latest version available in the app store for your platform.
    • Confirm that installed version is newer than those affected (e.g., at least version 11.2.1 for mobile, or version 11.2.4 for MacOS).
  • If upgrading does not resolve the issue, use "Help > Submit Feedback" within the Windows App to report errors directly to Microsoft
