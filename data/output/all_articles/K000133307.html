K000133307: [F5OS] After changing interface configuration, reseiving " alarm: ERROR - Fault detected in the AOM.", and can not see the components on GUI/CLI

Type
Support Solution
Published
2024-05-08
Updated
2024-05-08
Applies to
  • F5OS
  • F5OS-A: 1.2.X, 1.2.0
Source
https://my.f5.com/manage/s/article/K000133307

Description

Since the interfaces configuration was changed from 25 Gb to 10 Gb, receive an error alarm: ERROR - Fault detected in the AOM.

 

  • cannot see the components on GUI: Server Error(s), An internal error ocurred.
  • An error message using the CLI (show components -> Error: application error)

 

Environment

  • F5OS
  • rSeries 5000
  • v1.2.0 (End of techsupport)

Cause

Unknown

There is missing config in the system

e.g.

lacp config system-priority 32768
lacp interfaces interface Sync
config name Sync
config interval SLOW
config lacp-mode ACTIVE
!

 

Recommended Actions

Recreate the lacp config is reqruired

  1. log in to CLI as admin
  2. run the below commands in order
config
lacp interfaces interface Sync config name Sync; commit and-quit

 Please check the LAG interface status again

show running-config lacp interfaces

This should be resolved the issue.

 

Additional Information

v1.2 is already end of techinical support, and there is no similar issues reported at the moment for supported version.

Not able to reproduce the issue either.

Upgrade system to supported version is required.
