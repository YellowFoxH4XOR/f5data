Topic

For BIG-IP 9.x - 11.x, refer to K7227: Using tcpdump to view traffic on a tagged VLAN.

Note: On certain platforms, prior to version 4.2, tcpdump does not capture packets for VLAN-tagged frames.

By default in BIG-IP version 4.2 and later, while capturing data tcpdump will always look for VLAN and non-VLAN tagged packets and will remove the VLAN information from the packet. If you would like to collect and view specific VLAN information, use the -V flag when running the tcpdump command.

Sample output with the -V tag:

19:35:40.097303 802.1Q vlan#300 P0 10.20.254.254 > 10.20.6.254: icmp: echo reply 
19:35:40.246405 802.1Q vlan#300 P0 10.20.8.254 > 10.20.254.254: icmp: echo request 
19:35:40.246435 802.1Q vlan#300 P0 10.20.254.254 > 10.20.8.254: icmp: echo reply 
19:35:40.399886 802.1Q vlan#400 P0 10.30.9.254 > 10.30.254.254: icmp: echo request 
19:35:40.399922 802.1Q vlan#400 P0 10.30.254.254 > 10.30.9.254: icmp: echo reply
