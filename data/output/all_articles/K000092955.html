K000092955: After F5OS-A upgrade from 1.1.1 to 1.2.0 flannel pod won't start due to wrong tag

Description

After F5OS-A upgrade from 1.1.1 to 1.2.0 flannel pod won't start due to wrong tag

 

 

Environment

Platform: r5900

Software: F5OS-A 1.2.0 (upgrade from 1.1.1)

 

 

Cause

The pod is using a wrong tag :message instead of :0.13.0 tag. The root cause of this is currently undetermined.

 

Troubleshooting

 

From "critcl images" output on the device we can see that flannel pod is present in the repo on port 2000 and has tag 0.13.0 :

localhost:2000/rancher/coredns-coredns     1.8.3         3885a5b7f138c    12.9MB

 

Observe the /tmp/omd/scripts/kube-flannel.yml file to see the :message tag for flannel:

 - name: install-cni

    image: localhost:2000/appliance-flannel:message                 <<<<<<<<<<<<<< Wrong tag

Recommended Actions

Apply the following workaround:

 

Edit /tmp/omd/scripts/kube-flannel.yml and replace :message tag to 0.13.0 in DaemonSet section of the file:


Use command:

kubectl edit ds kube-flannel-ds -n kube-system


----------

   initContainers:

   - name: install-cni

    image: localhost:2000/appliance-flannel:0.13.0      <<<<<<< Observe corrected tag

    command:

    - cp

    args:

    - -f

    - /etc/kube-flannel/cni-conf.json

    - /etc/cni/net.d/10-flannel.conflist

    volumeMounts:

    - name: cni

     mountPath: /etc/cni/net.d

    - name: flannel-cfg

     mountPath: /etc/kube-flannel/

   containers:

   - name: kube-flannel

    image: localhost:2000/appliance-flannel:0.13.0         <<<<<<< Observe corrected tag

    command:

 

Save corrected file and reboot the device.
