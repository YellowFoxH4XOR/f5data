Description

  • When upgrading to version 16.1.x you may encounter memory issues with Java that may include a core.
  • Configuration may fail to load, a java core file may occur, SSLO and other interactive Guided Configuration GUIs may fail to work.
  • Error messages may be seen in /var/log/tomcat/catalina.out similar to the following...
    # java.lang.OutOfMemoryError: Java heap space
    # -XX:OnOutOfMemoryError="/usr/bin/restart_tomcat"
    #   Executing /bin/sh -c "/usr/bin/restart_tomcat"...
    Tue Aug 03 00:28:59 GMT 2021: START... [Ljava.lang.String;@157fe3d
    Tue Aug 03 00:28:59 GMT 2021: Calling command 1 with args: " restart tomcat"
    Tue Aug 03 00:29:09 GMT 2021: DONE: com.f5.util.ContainerManager$Result@53c1d4
    ---------------------------------------------

    2021-08-03 00:34:15,690 ERROR [ajp-bio-127.0.0.1-8009-exec-11] util.HttpJSONClient:<init>     - Error in HttpJSONClient:
    java.net.ConnectException: Connection refused (Connection refused)
        at java.net.PlainSocketImpl.socketConnect(Native Method)

Environment

  • Upgrade to 16.1.x
  • Memory settings
  • Graphical User Interface (GUI), Restjavad, Java

Cause

To deal with frequent Restjavad restarts an upgrade was done to OpenJDK 8. As part of this upgrade Java 8 now consumes more memory. Due to that added memory requirement restjavad JVM heap size was increased from 96MB to 384MB.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. If the BIG-IP has cored open a Support Case and provide the following...
    1. Run this command to create an MD5 checksum of the core file...md5sum /var/core/<name-of-core-file> > /var/core/<name-of-core-file>.md5
      1. Example: md5sum /var/core/java.bld0.0.19.core.gz > /var/core/java.bld0.0.19.core.gz.md5
    2. Retrieve the core and the MD5 Checksum and upload both to F5 Support files.
    3. Create and upload a qkivew.
  2. If there has been no core it would be a good idea to still open a case. You can as a preemptive step prior to the upgrade, or as a workaround once the upgrade has occurred, follow the steps in this article to add additional memory to the tomcat process...K9719: Error Message: java.lang.OutOfMemoryError
