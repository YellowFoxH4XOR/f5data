K000132541: Unable to remove certificates containing special characters in name

Type
Support Solution
Published
2023-04-26
Updated
2024-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000132541

Description

Facing issue removing the wildcard (*) certificate on BIG-IP via GUI (Configuration Utility) with below error:

/bin/tar: files_d/Common_d/certificate_d/\:Common\:*.example.com.crt_xxxxx_1: Cannot stat: No such file or directory

If the steps followed on KB article attached and is not working.
K65541558: Unable to delete certificate indexed with * from GUI

Below are the tmsh command followed as per KB article K65541558 steps, which doesn't helps.

# tmsh
# delete sys crypto cert *\.example.com.crt
# delete sys crypto cert *.example.com.crt
# list sys crypto cert *.example.com.crt

Error message:

01070712:3: failed in syscall link(/config/filestore/files_d/Common_d/certificate_d/:Common:*.example.com.crt_xxxxx_1, /config/filestore/.trash_bin_d/.current_d/Common_d/certificate_d/:Common:*.example.com.crt_xxxxx_1) errno=(No such file or directory)

 

Environment

BIG-IP
Wildcard (*) Certificates
CLI
 

Cause

This maybe owning to BIG-IP systems with alphabetic characters to ensure compatibility and avoid errors. Using numerals or special characters as the first character can lead to configuration failures and potential system impairment during operations such as reloads, synchronization, restores, reboots, or system resets.
 

Recommended Actions

Steps 1:

# tmsh
# delete sys crypto cert \*.example.com.crt
# list sys crypto cert \*.example.com.crt
# save sys config

 

Important: if you were prompted with error as below, please follow steps 2.

01070712:3: failed in syscall link(/config/filestore/files_d/Common_d/certificate_d/:Common:*.example.com.crt_xxxxx_1, /config/filestore/.trash_bin_d/.current_d/Common_d/certificate_d/:Common:*.example.com.crt_xxxxx_1) errno=(No such file or directory)

Steps 2:

# touch /config/filestore/files_d/Common_d/certificate_d/:Common:*.example.com.crt_xxxxx_1
# ls /config/filestore/files_d/Common_d/certificate_d/\:Common\:\*.example.com.crt_xxxxx_1
# tmsh
# delete sys crypto cert \*.example.com.crt
# list sys crypto cert \*.example.com.crt
# save sys config
