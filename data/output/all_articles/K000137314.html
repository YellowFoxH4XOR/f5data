Description

Changing hostname on a BIG-IP which is in an HA cluster may cause systems in the cluster to become Active/Active if device trust is reset without additional steps to prevent Active/Active state.

Environment

Viprion/vCMP system.

System in an HA cluster.

Customer changing device name which requires breaking and rebuild device trust.

Cause

Resetting device trust on any device in HA cluster will render it a Standalone device which will make it Active.

On Viprion based systems setting "min-up-members" and "min-up-members-enabled yes” is invalid configuration on a standalone device and will not prevent device becoming active.
Setting "min-up-members" and "min-up-members-enabled yes” is only recommended to ensure device does not become active once brought back into cluster and forceoffline has been released.

 

Recommended Actions

If device trust is going to be broken then you MUST force system offline.

K40832524: Rebuilding device trust using tmsh

K42161405: Rebuilding device trust using the Configuration utility
