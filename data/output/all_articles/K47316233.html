Known Issue

The Configuration utility may not display the Hardware SYN Cookie Protection option.

This issue occurs when all of the following conditions are met:

  • You attempt to configure the Hardware SYN Cookie Protection option in the TCP, FastL4, or FastHTTP profiles.
  • You access the Configuration utility on a Virtual Clustered Multiprocessing (vCMP) guest and on one of the following platforms:
     
    • BIG-IP 5000/5200 (C109)
    • BIG-IP i5600 (C119)
    • BIG-IP i5800 (C119)
    • BIG-IP i7600 (C118)
    • BIG-IP i7800 (C118)
    • BIG-IP 10350N (D112)
    • BIG-IP i10600 (C116)
    • BIG-IP i10800 (C116)
    • VIPRION B4450 and B4450N blades (A114)

Note: The hardware-syn-cookie option is disabled in the FastHTTP profile, and the system uses the software-syn-cookie option by default.

Impact

You cannot configure the Hardware SYN Cookie Protection option using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Configuration utility does not display the Hardware SYN Cookie Protection option, despite hardware support on the affected platforms.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to enable the Hardware SYN Cookie Protection option in the TCP and FastL4 profiles. To do so, perform the following procedure:

Note: The Hardware SYN Cookie Protection option is enabled by default in the TCP and FastL4 profiles.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To enable the Hardware SYN Cookie Protection option for the Fast HTTP profile, use the following command syntax:

    modify /ltm profile <protocol_profile> <profile_name> hardware-syn-cookie enabled

  3. Save the configuration by typing the following command:

    save /sys config
