Description

After attempting a software upgrade on an F5OS-A system and rebooting, the system does not come back online. The GUI is unavailable. You cannot log into the console, the console may print gibberish characters, and only the AOM menu is available. The result is that any boot errors that are being written to the console are unreadable.

Environment

  • F5OS-A on rSeries (encountered initially on an R5600)
  • Conducting an upgrade (encountered when upgrading from version 1.1)

Cause

Serial console baud rate not set to 9600.

Note: The default serial console baud rate is 19200 but attempting other common baud rates might get the serial connection working so you can determine what error is being printed.

Recommended Actions

Change the serial console baud rate to 9600 and reboot the system. If the baud rate was the cause, the gibberish characters will no longer be printed to the terminal and you will be able to read the boot errors. You may still need to perform other procedures to correct the actual error.
