K72546531: Regenerating SSL certificate for the discovery address on a BIG-IQ system

Topic

You should consider using this procedure under the following condition:

  • You want to replace the expired SSL certificate for the discovery address with a newly generated one.
  • The discovery address is changed after the BIG-IQ initial setup.

Note: Changing the discovery address invalidates the SSL certificate. The certificate is always tied to the original assigned discovery address until the certificate is manually regenerated with the new discovery address.

Important: You should not change the discovery address after the BIG-IQ system has discovered or added BIG-IP devices.

Description

Beginning in BIG-IQ 7.1.0, SSL certificates are generated for the Postgres database during the BIG-IQ initial system setup. These certificates are used by the discovery services and are bound to the discovery addresses. The SSL certificate and key are generated in the /var/lib/pgsql/config/ directory and named server.crt and server.key on the BIG-IQ system. Under a certain conditions in which you want a new certificate, such as in the case when the old SSL certificate is expired or the discovery address is changed, you can use the BIG-IQ ha_generate_certs utility to regenerate a new pair of SSL certificate and key. 

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IQ system.

Procedures

Regenerating SSL certificate for the discovery address

You can regenerate SSL certificate and key for the discovery address on a BIG-IQ system. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ command line.
  2. To generate a new SSL certificate and key, use the following command syntax:

    ha_generate_certs -f <discovery_address>

    For example, to generate the SSL certificate and key for discovery address 10.10.10.1, enter the following command:

    ha_generate_certs -f 10.10.10.1
