Description

A previously working vCMP guest doesn't start.

Messages similar to the following are observed in /var/log/ltm on the vCMP host:

01510007:6: Guest (DC_PROD_GUEST): VS_STARTING->VS_FAILED
01510004:3: Guest (DC_PROD_GUEST): Failure - Error starting VM.
01510000:3: <unknown> failed on <unknown>.<unknown>: 01020036:3: The requested virtual disk (1 <guest_image_name>.img) was not found.

Environment

  • vCMP

Cause

  • Bug ID 651432

Recommended Actions

Restart vcmpd on the vCMP Host

  1. SSH to log into the vCMP Host
  2. Restart vCMP on all slots:
    clsh bigstart restart vcmpd

Additional Information

This issue can occur when the mcpd process restarts, but vcmpd does not restart.

Due to a behavior change starting in version 11.6, vcmpd will also restart when mcpd restarts, avoiding this issue.
