Known Issue

DNS Express may incorrectly include the NS resource records (RR) for the parent zone in response to a query for a CNAME record that references a child domain.

This issue occurs when the following conditions are met:

  • The BIG-IP configuration contains at least one DNS Express zone.
  • The DNS Express zone contains a CNAME RR and NS RR that reference a child domain.
  • A Local Domain Name System (LDNS) server queries the DNS express zone for a CNAME RR.

For example, when an LDNS requests a CNAME record that targets the child domain, DNS Express returns the CNAME record and NS RRs for the child zone, as expected. However, DNS Express also incorrectly returns the NS RRs for the parent domain in the AUTHORITY section of the response.

Impact

Name resolution requests for CNAME RRs may fail.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The LDNS server drops the BIG-IP DNS response and logs an error message that appears similar to the following example:

    DNS format error from <ldns_ip>:<port> resolving <domain>/A for client <client_ip>:<port>: multiple NS RRsets in authority section

  • The client receives a SERVFAIL response from the LDNS server.
