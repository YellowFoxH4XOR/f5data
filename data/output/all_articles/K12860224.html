Description

BIG-IP BGP config allows maximum 32 neighbors in one peer-group.

Below is the example when more than 32 neighbors were attempted to add in a peer-group:
(config-router)#neighbor 10.10.10.27 peer-group ISP1
(config-router)#neighbor 10.10.10.28 peer-group ISP1
(config-router)#neighbor 10.10.10.29 peer-group ISP1
(config-router)#neighbor 10.10.10.30 peer-group ISP1
(config-router)#neighbor 10.10.10.31 peer-group ISP1
(config-router)#neighbor 10.10.10.32 peer-group ISP1      --> 32nd member successfully added.
(config-router)#neighbor 10.10.10.33 peer-group ISP1      --> Attempt to add 33rd member to peer-group fails with error.
% Neighbor not available
(config-router)#neighbor 10.10.10.34 peer-group ISP1
% Neighbor not available

Environment

  • BIG-IP provisioned with Advance Routing Module
  • BGP
  • ZebOs
     

Cause

There is a limitation by design in Zebos module of BIG-IP which allows only 32 neighbors in one peer-group.

Recommended Actions

Create new peer-group if current peer-group has reached the limit of 32.

None
