Description

TCP timestamp is one of the fields in TCP headers which helps to measure RTT between two endpoints.
In BIG-IP client side  and server side TCP timestamp negotiates independently, and there are few TCP profile settings which impacts BIG-IP TCP timestamp negotiation with pool members.
Sometimes we need to force use TCP timestamp option at BIG-IP server side regradless if client side has or doesn't has it.

Environment

  • Virtual Server
  • TCP profile

Cause

None

Recommended Actions

To force use TCP timestamp option at BIG-IP server side, we need to 

  1. Keep proxy-options in tcp profile disabled (by default, it's disabled)
  2. Change the proxy-mss in tcp profile to be disabled (by default, it's enabled)

The final TCP profile could be like this:

ltm profile tcp exampleforceTCPtimestamp {
    app-service none
    defaults-from tcp
    deferred-accept disabled
    fast-open enabled
    fast-open-cookie-expiration 21600
    proxy-mss disabled
    proxy-options disabled
    verified-accept disabled
}
