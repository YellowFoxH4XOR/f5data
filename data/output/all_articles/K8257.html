Issue

Note: The iqdump utility is a troubleshooting tool to view communication traffic between BIG-IP LTM and BIG-IP GTM systems. For more information, refer to K8187: Troubleshooting BIG-IP LTM and GTM device certificates.

In BIG-IP LTM versions previous to 9.3.1 and 9.4.2, the iqdump utility could not use signed third party certificates on a BIG-IP LTM system. If a signed third party Secure Sockets Layer (SSL) certificate was encountered, the BIG-IP LTM system would report an error message.

BIG-IP LTM 9.3.1, 9.4.2, and later may use signed third party SSL certificates with the iqdump utility.

F5 Product Development tracked this enhancement as CR80921 and it was included in BIG-IP LTM 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Installing a third party signed SSL certificate and the corresponding root certificate on your BIG-IP system

To install a third party signed SSL certificate and the corresponding root certificate, perform the following three procedures:

Note: The following procedures assume you have already obtained a signed SSL certificate, root CA certificates, and have the original SSL key.

  • Setting the Certificate Depth variable from the command line
  • Importing the root certificate to the system
  • Importing the third party signed SSL device certificate to the system

Setting the Certificate Depth variable from the command line

This option specifies the Certificate Depth or the number of certificate levels the system will traverse when validating the signed SSL certificate against the root CA certificates. To set the Certificate Depth variable from the command line, type the following command:

bigpipe db Big3d.CertificateDepth 3

Note: The value can be between 0 and 9. It should be set to the level required by the root CA. For example, if a root CA contains two certificates that are used for validation, this value should be set to 2. Setting it higher will not affect performance, as once the certificate is validated it will not attempt to look for other certificates.

Importing the root certificate to the system

  1. Log in to the Configuration utility.
  2. Navigate to System > Device Certificates > Trusted Server Certificates.
  3. Click Import.
  4. From the Import Method list, select Replace.
  5. In the Certificate Source box, select the Upload File option.
  6. Use the Browse button to navigate and select the root certificate file.
  7. Click Import.

Importing the third party signed SSL device certificate to the system

  1. Log in to the Configuration utility.
  2. Navigate to System > Device Certificates > Import.
  3. From the Import Type list, select Certificate and Key.
  4. In the Certificate Source box, select the Upload File option.
  5. Use the Browse button to navigate and select the device certificate file.
  6. In the Key Source box, select the Upload File option.
  7. Use the Browse button to navigate and select the device key file.
  8. Click Import.
