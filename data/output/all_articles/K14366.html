Known Issue

The Enterprise Manager email alert notification may fail.

This issue occurs when all of the following conditions are met:

  • At least one device alert with an action to send email containing alert details is configured.
  • An SMTP server is configured in the Configuration utility under System > Configuration > Device > SMTP.
  • The Enterprise Manager is not properly configured to use the SMTP server configuration for alerts.

When configuring the Enterprise Manager system to send alert notifications through email, you must first configure the SMTP server configuration on the System > Configuration > Device > SMTP page. You must then configure the Enterprise Manager system to use the configured SMTP server for alert notification by navigating to the Enterprise Manager > Options > Servers page and selecting the SMTP server from the SMTP Configuration Name menu.

Impact

The Enterprise Manager system does not send alerts that use email action.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Enterprise Manager system does not dispatch alert events with email action.

Workaround

To work around this issue, you can create an SMTP server configuration and select the SMTP server to be used by the Enterprise Manager for email alert notification. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > Configuration > Device > SMTP.
  3. To create a new SMTP server, click Create.
  4. Configure a valid SMTP server available in your environment.
  5. Save the SMTP server configuration, and click Finish.
  6. Navigate to Enterprise Management > Options > Servers.
  7. From the SMTP Configuration Name menu, select the SMTP server name configured in step 4.
  8. Click Save Changes.
