Known Issue

The End-User Diagnostics (EUD) sensor test may erroneously fail on some BIG-IP platforms.

This issue occurs when all of the following conditions are met:

  • You have a BIG-IP 10000 series (D113) platform.
  • Your BIG-IP host is powered by a DC power supply.
  • You are running EUD_T version 2.4.0.

Impact

The EUD sensor test may falsely indicate a possible hardware failure.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H451946 on the Diagnostics > Identified > Medium screen.
  • When executing the EUD sensor test, you may view the following message:

    Executing Sensor Test ...
    Test Begin: Sensor Test
    Comparing against file: /tmp/D113.limits
    ERROR: return code 1, cmd: "/tmp/lbh_cmd -t getpwr | grep 'fault byte AC OK flag'", output:
    Test Complete: Sensor Test: FAILED
