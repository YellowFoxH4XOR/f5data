Topic

The Real Time Streaming Protocol (RTSP) profile provides the ability to manage RTSP traffic. RTSP is defined in RFC2326 as a protocol used by streaming media systems that allow a client system to remotely control the streaming media server, such as pausing or playing a media (audio/video) stream.

RTSP opens a control channel over TCP for setting up and controlling the streaming session, and one or more separate data channels (typically performed using User Datagram Protocol (UDP) unicast or multicast, although TCP can be used) for the media streams.

The RTSP profile is located in the Configuration utility under Local Traffic > Profiles > Services > RTSP.

Note: F5 recommends that you create a custom RTSP profile to use when changing the various options and values. This profile allows the use of multiple custom RTSP profiles with different virtual servers, without affecting one another.

The following table displays the various settings and values for your RTSP profile:

SettingValueDescription
Idle Timeout300 (Default)This setting specifies the number of seconds that a UDP connection is idle before the connection is eligible for deletion.
Maximum Header Size4096 (Default)This setting specifies the largest RTSP request or response header, in bytes, that the BIG-IP system allows before terminating the connection.
Maximum Queued Data32768 (Default)This setting specifies the maximum amount of data, in bytes, that the BIG-IP system buffers, before considering the connection to be unusable, subsequently terminating the connection.
Unicast RedirectDisabled (Not Selected)If unicast streams are used and this option is selected, this setting allows permission for the client to supply a different destination IP address for the streamed data.
Multicast RedirectDisabled (Not Selected)If multicast streams are used and this option is selected, this setting allows permission for the client to supply a different destination IP address for the streamed data.
Session ReconnectDisabled (Not Selected)When enabled, this setting allows a disconnected control connection to resume, and the BIG-IP system persists the resumed control connection to the correct server.

Note: Most clients to not support this behavior.

Real HTTP PersistenceEnabledWhen enabled, this setting allows the BIG-IP system to automatically persist Real Networks tunneled RTSP data over HTTP, which uses the default RTSP port 554. The default value is Enabled. If this setting is disabled, an administrator can overwrite the default behavior with an iRule.
Check SourceEnabledWhen enabled, specifies that the system examines the origin of the message to determine whether the message came from the client or the server. The default value is Enabled. Introduced in BIG-IP version 10.0.1, for more information refer to K10869: The Check Source option is enabled by default in the RTSP profile.
Proxy

None (Default)

Options:

External: Specifies that the RTSP profile is associated with an external proxy configuration.

Internal: Specifies that the RTSP profile is associated with an internal proxy configuration.

This setting specifies whether the RTSP profile is associated with an RTSP proxy configuration.

Note: RTSP proxies are typically used for handling authentication and permissions, once established communication is configured with the RTSP servers for media delivery.

Proxy HeaderBlank (Default)

This setting specifies the value of a header that the BIG-IP system inserts into a SETUP request. The value of this header is typically information about the client IP address, and is read by another RTSP profile.

Note: The BIG-IP system removes this header from the request prior to sending the request to the media server for processing.

RTP Port0 (Default)This setting specifies the port number that a Microsoft Media Services server uses. By default, Microsoft Media Services uses a fixed Real Time Transport Protocol (RTP) port number. This setting allows you to specify an alternative port number instead of using the fixed RTP port number.
RTCP Port0 (Default)This setting specifies the RTCP port companion of the RTP Port value. By default, Microsoft Media Servers uses a fixed Real Time Control Protocol (RTCP) port number. This setting allows you to specify an alternative port number instead of using the fixed RTCP port number.

Note: For more information about RTP and RTCP, refer to RFC3550 - RTP: A Transport Protocol for Real-Time Applications.
