Description

After installing a new or RMA blade, the blade doesn't become part of cluster.

  • It's stuck with "waiting for cleanup; multiple base builds found (BIG-IP 14.x.x)".
  • The blade doesn't join the cluster.
  • The same error message can be seen in /var/log/ltm as well

Environment

  • A blade was inserted in VIPRION chassis
  • BIG-IP

Cause

This can happen if there are multiple images of same software ISO file under /shared/images in the host.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Find the primary blade and SSH into that using. In this case assume Slot2 is primary.
    # ssh slot2
  2. Run the command to find the duplicate ISO:
    # tmsh list sys software
    Ex:
    sys software image 13.1.3.6.iso {
        build 0.0.4
        build-date "Fri Jan 29 02 32 44 PST 2021"
        checksum b4af0c0f4629fbad50a8b832c94ec6d4
        file-size "2097 MB"
        last-modified "Wed Mar 10 09:43:59 2021"
        product BIG-IP
        verified yes
        version 13.1.3.6
    }
    sys software image 13.1.3.6-test.iso {
        build 0.0.4
        build-date "Fri Jan 29 02 32 44 PST 2021"
        checksum b4af0c0f4629fbad50a8b832c94ec6d4
        file-size "2097 MB"
        last-modified "Wed Mar 10 09:43:59 2021"
        product BIG-IP
        verified yes
        version 13.1.3.6
    }
  3. Under /shared/images/ find and delete the duplicate ISO. In our example it's 13.1.3.6-test.iso which is duplicate.
  4. You may have to repeat deleting the ISO file to other blades as well.
  5. This should fix the issue. If it doesn't restart the lind daemon using the command below:
    # clsh bigstart restart lind
