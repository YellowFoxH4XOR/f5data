Source

Description 

An F5 partition experienced unavailability issues related to internet access.

The specific error messages included "Liveness probe failed waiting for real qemu startup" and "Not ready containers with unready status."

Environment

Unable to Start Tenant on F5OS-A (rSeries) 1.7.0.

Cause

 Bug ID 1567945 

 

Recommended Actions

To resolve the problem, follow these steps:

  1. Stop all tenants 
  2. Stop or Shut down a tenant by changing its state from Deployed to Provisioned. This is the only available method to stop or shut down a tenant.
  3.  Remove the damaged file using the command 

    rm /var/F5/system/qat-devs.json

  4. Reboot the system or restart the platform layer.
  5. Deploy the tenants again.

For a long-term fix, it is recommended to:

Apply the provided mitigation steps to get the system running again.
Upgrade to version 1.8.0-A where the issue has been fixed.
Alternatively, apply the hotfix on top of version 1.7.x if an upgrade is not immediately possible.
