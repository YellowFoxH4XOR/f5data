Known Issue

The BIG-IP system may incorrectly reset a TCP connection with an RST-ACK when the system receives a FIN-ACK in a SYN-RECEIVED state.

This issue occurs when the following condition is met:

  • The BIG-IP system receives a FIN-ACK when in a SYN-RECEIVED state.

Impact

The BIG-IP system resets the TCP connection resulting in unexpected application behavior.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • From a traffic capture, in a TCP 3-way handshake, you observe that the BIG-IP system responds with an RST-ACK after receiving a FIN-ACK from the client, similar to the following example:

    1 0.000000    10.0.0.100          10.0.0.1           TCP         60746 -> 443 [SYN]
    2 1.000592    10.0.0.1            10.0.0.100         TCP         443 -> 60746 [SYN, ACK]
    3 1.999963    10.0.0.100          10.0.0.1           TCP         60746 -> 443 [FIN, ACK]
    4 2.000307    10.0.0.1            10.0.0.100         TCP         443 > 60746  [RST, ACK]

  • When you run the tmsh show /net rst-cause command, you notice from the command output that the TCP early FIN count increases with time.

    The command and output may appear similar to the following example:

    tmsh show /net rst-cause

    --------------------------------------------
    TCP/IP Reset Cause
    RST Cause:                             Count
    --------------------------------------------
    Flow expired (sweeper)                  548
    No flow found for ACK                   234
    RST from BIG-IP internal Linux host     163
    TCP 3WHS rejected                       25
    TCP early FIN                           1819
    handshake timeout                       838

  • If TCP RST cause logging is enabled, messages similar to the following example appear in the /var/log/ltm file:

    01230140:3: RST sent from 10.0.0.1:443 to 10.0.0.100:60746, [0x226cd9a:8853] TCP early FIN

    Note: For more information about TCP RST cause logging, refer to K13223: Configuring the BIG-IP system to log TCP RST packets.
