Known Issue

This is the result of a known issue. TMM memory miscalculation in MCP creates a race condition in which free memory pages may decrement. For configurations that depend on TMM memory being a certain size, such as RAM cache, the miscalculated value prevents the configuration from loading.

When the race condition occurs, error messages that appear similar to the following example are logged to the /var/log/ltm file when attempting to load the configuration:

01070668:3: The amount of ramcache memory assigned to HTTP profiles exceeds the maximum amount (22MB) defined by Ramcache.MaxMemoryPercent
01070425:3: Full configuration load failed.

F5 Product Development is tracking this issue as CR132156.

This issue has been fixed in Hotfix-BIGIP-9.4.8-407.0-HF4, which has been issued for BIG-IP version 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
