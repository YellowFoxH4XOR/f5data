Issue

Description
This article describes methods for decoding Security Assertion Markup Language (SAML) Requests for troubleshooting or analyzing SAML authentication.

Environment

  • BIG-IP APM configured for SAML as either Service Provider (SP) or Identity Provider (IdP).
  • SAML Decode utility or website. In this use case we are using https://www.samltool.com/url.php
  • HTTP traffic capture utility such as HTTPWatch or Fiddler.

Cause
You need to decode SAML Requests for troubleshooting or analysis.

Recommended Actions
The following steps detail how to decode SAML Requests.

Capturing the SAML Request using an HTTP capture utility:

  1. Launch the HTTP capture utility and navigate to the SP URL (SP initiated) or IdP URL (IdP initiated).

  2. Locate the SAML Request.
    Redirect binding the SAML Request will be in the URL.
    Post Binding POST the SAML Request will be found in the HTTP message body.

Obtaining the SAML Request from the APM log:

You can observe the SAML Request in /var/log/apm:
<bigip_hostname> info apmd[13848]: 01490007:6: /Common/<access_policy_name>:Common:<session_ID>: Session variable 'saml./Common/<access_policy>_act_saml_auth_ag.SAMLRequest' set to 'fZLLTsMwEEV%2FJfK%2BeTUJqdVECq0QlQpEbWDBBhlnQi05dvA4Bf6eNOVRFnR975yZuTNzZK3saNHbndrAaw9onfdWKqSjkJHeKKoZCqSKtYDUcrotbtY0dH3aGW0115I4BSIYK7RaaIV9C2YLZi843G%2FWGdlZ2yH1POxc1rVp6tZsD67UnEnv0GUQvAHVCAlep9F6jCNxlsMoQrED9Bch6v8Yg%2FIDMVALA9xqM%2BIQNXFWy4w88ShkTRP4MSRNEkZ1NE3ipE6bOoi536T1rImn8cVgRuxhpdAyZTMS%2BsFs4keTIKmCGZ2GNIhd3w8fiXOlDYcxu4w0TCIQp%2FzK5FKoWqiX8wE%2BH01Ir6uqnJR324o4D2Bw3HkwkHx%2BWI6O85iTw5zHsu9rkPxM9nPvhH1s1NHbAbZalloK%2FuEUUuq3hQFmISPW9EC8%2FFj192PyTw%3D%3D'

Decoding the SAML Request (Redirect binding):

  1. Locate the SAML Request in the URL.
    For example:
    https://idp.apm.f5.local/saml/idp/profile/redirectorpost/sso?SAMLRequest=fZLLTsMwEEV%2FxfK%2BedKSWk2k0ApRqUDUBhZskOtMqCXHDh6nwN%2BTpjzKgq7vnTMzd2aGvFEtyzu302t47QAdeW%2BURjYIKe2sZoajRKZ5A8icYJv8dsUiL2CtNc4IoyjJEcE6afTcaOwasBuweyngYb1K6c65FpnvY%2BvxtkkSr%2BJ78JQRXPmHLr3g96haKvBbg87nAilZ9KNIzQ%2FQX4Ss%2FmP0yg%2FEQiUtCGfsgEM0lCwXKX1OuOA1BCJMYHoZVzyporgej%2BttWG0jEU0nYS0mdW9G7GCp0XHtUhoF4XQUXIzCSRlOWRyyeOwFQfREybWxAobsUlpzhUBJ8ZXJldSV1C%2FnA9weTchuyrIYFfebkpJHsDjs3BtoNjssx4Z57MlhzmP59zVodib7mX%2FCPjZq2V0PWy4Ko6T4ILlS5m1ugTtIqbMdUD87Vv39mOwT           

  2. From the SAML Request, copy from the beginning of the request to the last ampersand (&).
    For example: 
    fZLLTsMwEEV/xfK+edKSWk2k0ApRqUDUBhZskOtMqCXHDh6nwN+TpjzKgq7vnTMzd2aGvFEtyzu302t47QAdeW+URjYIKe2sZoajRKZ5A8icYJv8dsUiL2CtNc4IoyjJEcE6afTcaOwasBuweyngYb1K6c65FpnvY+vxtkkSr+J78JQRXPmHLr3g96haKvBbg87nAilZ9KNIzQ/QX4Ss/mP0yg/EQiUtCGfsgEM0lCwXKX1OuOA1BCJMYHoZVzyporgej+ttWG0jEU0nYS0mdW9G7GCp0XHtUhoF4XQUXIzCSRlOWRyyeOwFQfREybWxAobsUlpzhUBJ8ZXJldSV1C/nA9weTchuyrIYFfebkpJHsDjs3BtoNjssx4Z57MlhzmP59zVodib7mX/CPjZq2V0PWy4Ko6T4ILlS5m1ugTtIqbMdUD87Vv39mOwT

  3. Navigate to the site https://www.samltool.com/url.php.

  4. Click on Code/Decode.

  5. Click on URL Encode/Decode.

  6. Enter the SAML Request in the URL Decode field.

  7. Copy the decoded URL.

  8. Click on Base 64 Decode+Inflate.

  9. Enter the decoded URL in the Deflated and Encoded XML field.

  10. Click Decode and Inflate XML.
    You will see the following XML output:
    <samlp:AuthnRequest xmlns:samlp="urn:oasis:names:tc:SAML:2.0:protocol" AssertionConsumerServiceURL="https://sp.apm.f5.local/saml/sp/profile/post/acs" Destination="https://idp.apm.f5.local/saml/idp/profile/redirectorpost/sso" ID="_8acafe0c18e973da8d23f55fb1db2c2961fc6f" IssueInstant="2019-04-16T19:31:35.002Z" ForceAuthn="false" ProtocolBinding="urn:oasis:names:tc:SAML:2.0:bindings:HTTP-POST" Version="2.0"><saml:Issuer xmlns:saml="urn:oasis:names:tc:SAML:2.0:assertion">https://sp.apm.f5.local</saml:Issuer><samlp:NameIDPolicy AllowCreate="true"/></samlp:AuthnRequest>

  2. Copy the SAML Request value.
    For example:
    PHNhbWxwOkF1dGhuUmVxdWVzdCB4bWxuczpzYW1scD0idXJuOm9hc2lzOm5hbWVzOnRjOlNBTUw6Mi4wOnByb3RvY29sIiBBc3NlcnRpb25Db25zdW1lclNlcnZpY2VVUkw9Imh0dHBzOi8vc3AuYXBtODguZGF2ZS5sb2NhbC9zYW1sL3NwL3Byb2ZpbGUvcG9zdC9hY3MiIERlc3RpbmF0aW9uPSJodHRwczovL2lkcC5hcG04OC5kYXZlLmxvY2FsL3NhbWwvaWRwL3Byb2ZpbGUvcmVkaXJlY3RvcnBvc3Qvc3NvIiBJRD0iX2VhYWFjMjU1NDBmNjI1ZGI3NzZmNDkxMzRiOTNkMjQ4Yzc1ODFkIiBJc3N1ZUluc3RhbnQ9IjIwMTktMDQtMTZUMTk6MjM6NDQuMDAyWiIgRm9yY2VBdXRobj0iZmFsc2UiIFByb3RvY29sQmluZGluZz0idXJuOm9hc2lzOm5hbWVzOnRjOlNBTUw6Mi4wOmJpbmRpbmdzOkhUVFAtUE9TVCIgVmVyc2lvbj0iMi4wIj48c2FtbDpJc3N1ZXIgeG1sbnM6c2FtbD0idXJuOm9hc2lzOm5hbWVzOnRjOlNBTUw6Mi4wOmFzc2VydGlvbiI+aHR0cHM6Ly9zcC5hcG04OC5kYXZlLmxvY2FsPC9zYW1sOklzc3Vlcj48c2FtbHA6TmFtZUlEUG9saWN5IEFsbG93Q3JlYXRlPSJ0cnVlIi8+PC9zYW1scDpBdXRoblJlcXVlc3Q+

  3. Navigate to the site https://www.samltool.com/url.php.

  4. Click on Base 64 Decode+Inflate.

  5. Enter the decoded URL in the Deflated and Encoded XML field.

  6. Click Decode and Inflate XML.
    You will see the following Deflated XML output:
    <samlp:AuthnRequest xmlns:samlp="urn:oasis:names:tc:SAML:2.0:protocol" AssertionConsumerServiceURL="https://sp.apm.f5.local/saml/sp/profile/post/acs" Destination="https://idp.apm.f5.local/saml/idp/profile/redirectorpost/sso" ID="_eaaac25540f625db776f49134b93d248c7581d" IssueInstant="2019-04-16T19:23:44.002Z" ForceAuthn="false" ProtocolBinding="urn:oasis:names:tc:SAML:2.0:bindings:HTTP-POST" Version="2.0"><saml:Issuer xmlns:saml="urn:oasis:names:tc:SAML:2.0:assertion">https://sp.apm.f5.local</saml:Issuer><samlp:NameIDPolicy AllowCreate="true"/></samlp:AuthnRequest>
