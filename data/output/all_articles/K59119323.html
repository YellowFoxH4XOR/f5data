Known Issue

Statistics for the avrd process use large amounts of memory.

This issue occurs when all of the following conditions are met:

  • You have enabled the DoS profile for Layer 7 (L7), Layer 3 (L3), and Layer 4 (L4).
  • You have attached the BIG-IP ASM policy.
  • You have enabled the Analytics profile with traffic capture with a remote logger profile.
  • You have enabled off system processing.

Impact

The BIG-IP system is using more tmstat memory.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the ltm.log/avrd.log file on a B4450 blade, the avrd log receives constant error messages similar to the following example:

    err merged[40445]: 011b0900:3: TMSTAT error tmstat_create_scripts: Resource temporarily unavailable.
