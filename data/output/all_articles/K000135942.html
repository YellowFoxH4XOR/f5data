K000135942: How to force F5OS-A to sync to a specific NTP server

Type
Support Solution
Published
2023-08-24
Updated
2024-02-08
Applies to
  • F5OS Products
  • F5OS-A: 1.5.0, 1.4.0, 1.3.2, 1.3.1, 1.3.0
Source
https://my.f5.com/manage/s/article/K000135942

Description

  • This is a guide on how to force F5OS-A platform (F5 rSeries system) to sync its time to a specific NTP server

Environment

  • F5OS-A
  • NTP server (NTP has to be network reachable)

Cause

None.

 

 Recommended Actions

All commands executed from bash.

 

1. Check ntp config and status:

 

# docker exec system_manager /confd/scripts/f5_confd_run_cmd show system ntp

 

# show system ntp

3. Before you can force it to sync, chronyd must be stopped:

 

# systemctl stop chronyd.service

 

4. Force using command: chronyd -q 'server <ntpserver>'

 

# chronyd -q 'server 10.1.1.1'

(6) Start chronyd again:

 

# systemctl start chronyd.service
