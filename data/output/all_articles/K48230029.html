K48230029: Slowness or connection issues when using Apache server as pool member

Type
Support Solution
Published
2020-11-02
Updated
2023-01-27
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K48230029

Description

On the Apache server, the following error message is noticed:

[info] [client 120.x.x.x] Request header exceeds LimitRequestFieldSize: Cookie, referer: https://www.<website>

Environment
  • Big-IP
  • Apache Server as a pool member

Cause

The issue is related to the Apache server limiting the HTTP request header sent by the BIG-IP. This is an Apache configuration issue and not an issue with the BIG-IP.

Recommended Actions

To resolve the issue, you will need to change the LimitRequestFieldSize value at the Apache server configuration. The default value is 8190 and the maximum value is 32768.

Important: Please consult with the Apache administrator before making changes to the Apache server configuration. F5 will not take responsibility for any unexpected outcome.
