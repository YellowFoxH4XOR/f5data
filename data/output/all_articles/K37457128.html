Issue

Error Message

info sod[<PID>]: 010c007b:6: Deleted unicast failover address <IP address> port <port> for device /<partition>/<hostname>.

In this error message, note the following:

  • <PID> is the process ID of the sod process.
  • <IP address> is the unicast failover IP address that you are attempting to delete.
  • <port> is the port number that the system uses for failover operations. The default value is 1026.
  • <partition> is the administrative partition for the centralized management infrastructure (CMI) local device object. The default partition is Common.
  • <hostname> is the hostname of the BIG-IP system where you performed the delete operation.

For example:

info sod[7254]: 010c007b:6: Deleted unicast failover address 192.0.2.2 port 1026 for device /Common/example_hostname.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following conditions is met:

  • You attempt to delete the specified IP address from the network failover unicast configuration.

Impact

The requested operation is successful and the sod process no longer listens for network failover heartbeat packets on the noted IP address.

Recommended Actions

The unicast failover configuration uses the defined IP address to communicate failover packets between each BIG-IP system. To ensure the most stable network failover configuration, F5 recommends that you configure both the management address and a Traffic Management Microkernel (TMM) network address for network failover.
