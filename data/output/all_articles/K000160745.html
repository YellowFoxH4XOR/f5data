Description

The BIG-IP APM session cookies will only traverse the frontend or client side of the BIG-IP for session tracking.

Environment

BIG-IP APM

Cause

This is expected behavior.

Answer/Recommended Actions

If you seek for the BIG-IP to traverse to the backend for any reason, you will need to utilize an iRule to pass it to the backend.
Note: This will not maintain backend session, this is strictly for tracking purposes and may be need to be modified for specific scenarios - use at your own risk.

when HTTP_REQUEST {
    set all_cookies [HTTP::header value "Cookie"]

    if { [HTTP::cookie exists "MRHSession"] } {

        # Optionally validate APM session exists
        set sid [HTTP::cookie value "MRHSession"]

        if { [ACCESS::session exists $sid] } {
            # Pass cookies through unchanged
            HTTP::header replace "Cookie" $all_cookies
        } else {
            # Invalid session → force re-auth
            HTTP::respond 401 content "Invalid APM session"
            return
        }
    }

    pool my_backend_pool
}
