Known Issue

The BIG-IP ASM system may include an incorrect field in the logging format sent to a remote Splunk logging server (Splunk for F5 Security). This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM system is configured with a remote logging profile.
  • The Remote Storage Type option for the remote logging profile is configured with Reporting Server.

When this issue occurs, the BIG-IP ASM system includes the http_class_name field and omits the web_application_name field while logging to the remote Splunk logging server. The remote Splunk logging server acts as if the logs from the BIG-IP ASM system include the web_application_name field.

Impact

The remote Splunk logging server fails to display data from the affected BIG-IP ASM system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The remote Splunk logging server displays an empty dashboard.
  • In a traffic capture, in the logs that the affected BIG-IP ASM system sent, you may see the http_class_name field instead of the web_application_name field.
