Topic

BIG-IP i2000 and i4000 series platforms are shipped with BIG-IP 12.1.1 HF2 and include the compatible End-User Diagnostics (EUD) version, which is SF_EUD v3.0.2. If you perform a full wipe and re-installation of your system using BIG-IP 12.1.1 HF2, an incorrect version of the EUD is installed.

Description

BIG-IP 12.1.1 includes EUD version SF_EUD v3.0.0 for the i5000, i7000, and i10000 platforms. In BIG-IP 12.1.1 HF2, support for the i2000 and i4000 platforms was added. Because EUD updates are not included with hotfix releases, i2000 and i4000 platforms with a re-installation of BIG-IP 12.1.1 will have an incorrect EUD version.

After BIG-IP 12.1.1 HF2 has been re-installed on the i2000 and i4000 platforms, you should install SF_EUD v3.0.2. You can download EUD version SF_EUD v3.0.2 from F5 Downloads.

For information about installing the EUD, refer to Field Testing F5 Hardware: iSeries Platforms.
