K82039535: Error: Failed to update user when log in to BIG-IQ 7.1 with Radius user

Type
Support Solution
Published
2020-10-30
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K82039535

Description

"Error: Failed to update user" when trying to access GUI with Radius User 


/var/log/restjavad.0.log:

[ERROR][<date> CEST][ PgRequestProcessor] Failed update of: cm/system/authn/providers/radius/b04bdd6f-49e6-496b-87ca-fa168a8b15c4/users/aaffb458-8883-3750-89d8-bfe5cbd96b4f - org.postgresql.util.PSQLException: ERROR: unsupported Unicode escape sequence
  Detail: \u0000 cannot be converted to text.

Environment

  • Remote user configuration with Radius
  • BIG-IQ 7.1
  • Radius returning \u0000 characters

Cause

ID930569 
PostgeSQL does not support \u0000 characters

Recommended Actions

  1. Verify Configuration  in  Radius Server what  values of Filter-Id are returned.

Additional Information

Troubleshooting  issue with Radius and \u0000:

  1. Collect pcap on BIG-IQ while trying to access GUI with radius user:
    From CLI:
    tcpdump -s0 -nni eth0 port 1812 -w /var/tmp/radius_failure.pcap -v
     
  2. Review Radius response in pcaps:
    Example of resonse which is causing issue:
    AVP: l=24 t=Filter-Id(11): role:TESTSuperAdmin\000
    AVP: l=23 t=Filter-Id(11): role:TESTUserAdmin\000
    AVP: l=23 t=Filter-Id(11): role:TESTViewAdmin\000
    AVP: l=19 t=Filter-Id(11): role:TESTAdmin\000
