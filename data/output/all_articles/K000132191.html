Description

When trying to install a certificate via tmsh you receive the following error:

 

Key management library returned bad status: -28, Bad password

 

Environment

BIG-IP

Cause

This error can happen if your password contains special characters but do not escape them in the shell.

Recommended Actions

Make sure to escape special characters.

 

For example here is a command that will fail due to the special characters ! and $ not being escaped:

 

# tmsh install sys crypto pkcs12 abc.p12 from-local-file /shared/tmp/abc.p12 passphrase Password!$2324

 

Key management library returned bad status: -28, Bad password

 

When we escape the special characters ! and $ the command succeed:

 

# tmsh install sys crypto pkcs12 abc.p12 from-local-file /shared/tmp/abc.p12 passphrase Password\!\$2324
