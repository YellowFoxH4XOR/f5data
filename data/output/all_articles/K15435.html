Topic

You should consider using this procedure under the following condition:

  • You want to configure your BIG-IP system to send SNMP alerts in the Nokia NetAct format.

Description

You can configure the BIG-IP system to send SNMP alerts formatted for Nokia NetAct. The following procedure describes the steps required to implement Nokia NetAct formatting of the SNMP alerts sent by the BIG-IP system.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Your BIG-IP system is established on the local network.
  • You have the Nokia NetAct destination IP address, SNMP version, and community string (if required).

Procedures

Enabling the Nokia NetAct SNMP alert format

To enable the BIG-IP system to send SNMP alerts/traps compatible with the Nokia NetAct product, perform the following procedure:

Impact of procedure: SNMP alerts sent by the BIG-IP system will now be formatted according to Nokia NetAct requirements. This may impact the ability to interpret SNMP alerts/traps for non-Nokia NetAct destinations.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Enable Nokia NetAct formatting of SNMP alerts by typing the following command:

    modify /sys db alertd.nokia.alarm value enable

  3. Restart the BIG-IP system SNMP service by typing the following command:

    restart /sys service snmpd

    Note: Restarting the snmpd process temporarily interrupts the SNMP service and the ability to send alert notifications.

  4. To verify that the BIG-IP system SNMP service has restarted, type the following command:

    show /sys service nokiasnmpd

  5. Restart the alertd service by typing the following command:

    restart /sys service alertd

    Note: Restarting the alertd process temporarily interrupts the ability to send SNMP alert notifications.

  6. Configure the Nokia NetAct SNMP trap destination using the following command syntax:

    modify /sys snmp traps add { my_trap_destination { host <Nokia NetAct IP address> community <community name> version <SNMP version> } }

    For example:

    modify /sys snmp traps add { my_trap_destination { host 172.30.18.25 community net-act version 2c } }

  7. Save the change by typing the following command:

    save /sys config

  8. To exit the tmsh utility, type the following command:

    quit
