Topic

This article applies to the BIG-IP i800, i2000, i4000, i5000, i7000, and i10000 series platforms. For information about other versions, refer to the following article:

  • K14595: Configuring AOM network access (2000, 4000, 5000, 7000, and 10000 series platforms)
  • K9608: Configuring AOM network access (800, 1600, 3600, 3900, 6900, 89XX, 11000, and 11050 series platforms)

You should consider using this procedure under the following condition:

  • You want to configure Always-On-Management (AOM) so that it can be accessed over the network for one of the following platforms:
    • BIG-IP i800, i2000, i4000, i5000, i7000, and i10000 series platforms

Description

The AOM system is a separate subsystem that provides lights-out management for the BIG-IP system. You can configure AOM so that it can be accessed over the network by an authorized user through the use of a secure shell (SSH) utility by performing all of the following procedures.

  • Creating an AOM administrative account
  • Configuring AOM network access

Note: To gain access to the AOM menu over the network, the Intelligent Plaform Management Interface (IPMI) option does not need to be enabled from the Traffic Management Shell (tmsh).

Important: F5 recommends disabling Intelligent Platform Management Interface (IPMI) if it is not needed. If you must use IPMI, use a separate management LAN or Virtual Local Area Network (VLAN), Access Control Lists (ACLs), or Virtual Private Network (VPN) to limit and restrict access to the BIG-IP management interface. For more information, refer to K16846: IPMI vulnerability CVE-2013-4786.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have physical serial console access to the BIG-IP system.
  • You have an available IP address that is on the same subnet as the BIG-IP management address.

Procedures

    Creating an AOM administrative account

    By default, you can use the physical serial console method to gain access to the AOM menu. If you need to access the AOM menu via the network, you can create an AOM administrative account on the AOM subsystem for this purpose. To do so, perform the following procedure:

    Note: This is a separate account that is created on the AOM subsystem, and does not exist in the BIG-IP configuration. This account does not exist on the AOM subsystem by default.

    Impact of procedure: Performing the following procedure should not have a negative impact on your system.

    1. Log in to the command line of the BIG-IP system.
    2. To create an AOM administrative account, use one of the following command options:
      • On a newly deployed BIG-IP device, type the following command:

        aom_setup_user

      • On an existing BIG-IP device, you can override the existing AOM administrative account, by typing the following command:

        aom_setup_user -o

    3. Enter a desired username.
    4. Enter the desired password.
    5. Enter the password again to confirm. If the AOM administrative account gets created successfully, the command output will appear similar to the following example:

      AOM username  new_aom_admin successfully set and enabled.  Note that the AOM network must be configured via the AOM menu.

    6. To verify if the AOM administrative account has been created and enabled successfully, type the following command:

      aom_setup_user -l

      The command output should appear similar to the following example:

      Current AOM username: new_aom_admin (enabled)

    Configuring AOM network access

    To configure the AOM network on the BIG-IP system, perform the following procedure:

    Impact of procedure: Performing the following procedure should not have a negative impact on your system.

    1. Connect the serial console to the CONSOLE port.
    2. Display the AOM command menu by typing the following key sequence:

      Esc (

      The AOM command menu displays as follows:

      AOM Command Menu:
      B --- Set console baud rate
      I --- Display platform information
      P --- Power on/off host subsystem
      R --- Reset host subsystem
      N --- Configure AOM network
      S --- Configure SSH Server
      A --- Reset AOM
      Q --- Quit menu and return to console

    3. To configure network access, press the N key.

      The AOM management network configurator screen appears.

    4. Complete the network configurator screens.

      Important: The AOM IP address must be different than the BIG-IP management address, but on the same IP subnet.

    5. (Optional) To disable the network configuration if you no longer requires AOM access over the network, re-run the N ---Configure AOM network option, and enter 0.0.0.0 for the IP address.
