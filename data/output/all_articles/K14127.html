Topic

This article applies to BIG-IP 11.x through 16.x. For information about other versions, refer to the following article:

  • K6529: Enabling and disabling monitor logging for SNMP DCA and SNMP DCA Base monitors (9.x - 10.x)

You should consider using this procedure under the following condition:

  • To enable or disable monitor logging for SNMP DCA and SNMP DCA Base monitors.

For information about SNMP DCA monitors, refer to K14114: Overview of the SNMP DCA.

Description

To view detailed information collected by SNMP DCA and SNMP DCA Base monitors, you can enable SNMP DCA logging on the BIG-IP system. When SNMP DCA logging is enabled, and an SNMP DCA monitor or an SNMP DCA Base monitor is configured to monitor a node, the collected information is logged to the /shared/tmp/snmpdca.log file. Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have administrative access to the TMOS Shell (tmsh).

Procedures

To enable or disable monitor logging for SNMP DCA and SNMP DCA Base monitors, perform one the following procedures:

  • Enable monitor logging
  • Disable monitor logging

Enable monitor logging

To enable logging for SNMP DCA and SNMP DCA Base monitors, perform the following procedure:

Impact of procedure: Depending on the number of monitors, number of nodes being monitored, number of objects being collected, and the monitor frequency, the /shared/tmp/snmpdca.log file could grow excessively large. F5 recommends that you enable logging for SNMP DCA and SNMP DCA Base monitors for only long enough to collect the information you are looking for, and then disable it.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To enable monitor logging for SNMP DCA and SNMP DCA Base monitors, enter the following command:

    modify /sys db snmp.snmpdca.log value true

Disable monitor logging

To disable logging for SNMP DCA and SNMP DCA Base monitors, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To disable monitor logging for SNMP DCA and SNMP DCA Base monitors, enter the following command:

    modify /sys db snmp.snmpdca.log value false
