Known Issue

BIG-IP APM Remote Desktop sessions may disconnect randomly.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for VMware View (PCoIP) Remote Desktop Application Access.
  • The BIG-IP APM configuration uses two or more TMMs.

Impact

Remote Desktop sessions using VMware View are disconnected and you must restart them.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H453741 on the Diagnostics > Identified > Low|High screen.
  • The BIG-IP APM session inactivity counter is not reset, even though the remote sessions are not inactive.
  • The session Bytes In and Bytes Out counters are not incremented by the active connection.
  • In the /var/log/apm file, you may observe error messages similar to the following example:

    notice tmm8[15775]: 01490502:5: <session id>: Session deleted due to user inactivity or errors.

Workaround

To work around this issue, you can increase the Inactivity Timeout for the Access Profile. To do so, perform the following procedure:

Impact of workaround: Increasing the Inactivity Timeout may increase the total concurrent users.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Click Access Policy.
  3. Click Access Profiles.
  4. Click the affected profile name.
  5. Increase the value for the Inactivity Timeout.
  6. Click Update.
  7. Click the Apply Access Policy link, and to apply the change, click Apply Access Policy.
