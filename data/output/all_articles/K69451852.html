Known Issue

In rare circumstances, the LCD panel on iSeries platforms erroneously displays the 'Sensor 0 type 0 event 2 asserted' message and sets the Alarm LED to amber.

This issue occurs when the following condition is met:

  • You are using one of the following iSeries platforms: i2600, i2800, i4600, i4800, i5600, i5800, i7600, i7800, i10600, i10800z.

Impact

There is no impact; this issue is cosmetic and does not affect the functionality of the hardware.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The LCD panel displays a message that appears similar to the following example:

    Sensor 0 type 0 event 2 asserted

  • The Alarm LED is set to amber and remains illuminated until it is cleared.
  • The tmsh show /sys alert command output appears similar to the following example:

    # tmsh show sys alert
    -------------------------------------------------------------------------------
    Sys::LCDAlerts
    Slot          Priority         Id                        Description
    -------------------------------------------------------------------------------
    0             warning          0x12a0022       Sensor 0 type 0 event 2 asserted

Workaround

To work around this issue, you can ignore the message clear the alert by using the touchscreen LCD. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Touch the touchscreen LCD to activate the LCD menus.
  2. To display the Alerts screen, tap Alerts.
  3. On the Alerts screen, you can either clear all alerts or alerts of a specific priority:
    • To clear all alerts, tap Clear All.
    • To clear only alerts of a specific priority, tap the priority name to view alerts with that priority, and tap Clear.

      For more information, refer to the Platform Overview chapter of your BIG-IP LTM Platform Guide manual for your hardware.

      Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.
