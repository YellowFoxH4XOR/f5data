Description

This KB explains the possible reason for issue for APM  F5 Access vpn application for Windows. The error is:

Can't connect to VPN-EXAMPLE
The connection was terminated by the remote computer before it could be established.

Environment

  • APM

  • F5 Access vpn
  • Windows

Cause

Incorrect value under "Server Name or Address"

Answer/Recommended Actions

Make sure that you define the fqdn of vpn server under "Server and Network Name" setting. For example:

vpn.example.com <<< CORRECT

https://vpn.example.com <<< NOT CORRECT
