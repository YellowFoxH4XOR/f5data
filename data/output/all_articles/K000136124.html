K000136124: F5OS powers a tenant back on if tenant is shutdown from the tenant itself

Type
Support Solution
Published
2023-09-07
Updated
2023-09-07
Applies to
  • F5OS
  • F5OS-C
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000136124

Description

When powering off a tenant from the tenant itself, it results in the tenant being powered back on immediately by the F5OS system.

Environment

Shutting down a Tenant from the Tenant itself as opposed to underlying F5OS host.

Cause

The official recommendation to power off a Tenant is to do so from the F5OS host by changing the tenant's state from Deployed to Provisioned, as documented in K21121803: Shut down and restart a tenant on the VELOS and F5 rSeries systems . Attempting to power off the tenant from the tenant itself, using a command such as shutdown -h, results in the tenant being powered back on immediately by the F5OS and it is soon back to being in a running state.

Recommended Actions

There's a log file in /var/F5/system/log/k3s_events.log within the rSeries system that contains info about the tenant when it is shutdown from the tenant itself.
