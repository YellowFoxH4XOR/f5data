Issue

During the first successful authentication against an RSA ACE server, a node secret is automatically created and shared between the BIG-IP APM system and the Agent Host on the RSA server. In the event that the IP address of the RSA server is changed, you may receive the following error message when attempting to authenticate against the server with the new IP address:

Node verification failed

Recommended Actions

To resolve this error message, you must clear the node secret on the RSA server and the BIG-IP system. To do so, perform the following tasks:

  • On the RSA Security Console:
    Clear the Node Secret Created check box. For directions about clearing the node secret, review your vendor's documentation.
    Ensure that you have a copy of the SecurID Configuration File, it will be needed later (Available to download under "Access / Authentication Agents / Generate Configuration File").
  • On BIG-IP:
    Go to "Access / Authentication / SecurID"
    Click on the name of the server that you want to modify.
    On the entry "SecurID Configuration File", select "Upload New File".
    Click on "Choose file" and select the corresponding Securid configuration file (sdconf.rec) which you obtained from the RSA SecurID Security Console.
    Click "Update".
    Apply the Access Policy.
    Using "securidtest" from BIG-IP command-line or connecting to BIP-IP VS as a test user, trigger a successful SecurID authentication. This will create a shared secret between RSA server and BIG-IP.
    If you have an Active-Standby (HA) pair of BIG-IP devices configured with Manual sync, you must now sync the changes to the other member of the cluster.
