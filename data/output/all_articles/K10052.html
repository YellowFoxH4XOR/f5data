Known Issue

This is the result of a known issue. The qkview utility may cause the switchboard of the 6900 platform to hang when it is run.

This behavior occurs when the qkview utlity runs the hsb_snapshot command that gathers information from the high speed bridge (HSB). The HSB is responsible for moving information between the switchboard and the CPUs on the system. On the 6900 platform, the hsb_snapshot command causes the high speed bridge to hang. As a result, the switchboot cannot communicate with the CPUs, which prevents the device from passing traffic until the unit is rebooted.

F5 Product Development tracked this issue as CR120591 and it was fixed in BIG-IP version 9.4.8 and BIG-IP version 10.0.1. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WOM, or WebAccelerator release notes.

Workaround

You can work around this issue by preventing the qkview utility from executing the hsb_snapshot command on the 6900 platform. To do so, log in to the command line and rename the hsb_snapshot file using the following syntax:

mv /usr/sbin/hsb_snapshot /usr/sbin/not_hsb_snapshot
