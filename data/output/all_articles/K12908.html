Known Issue

Creating a user account that has the same user name as the user account currently logged in to the system causes the mcpd process to crash.

This issue occurs when all of the following conditions are met:

  • A user account is created from the Configuration utility
  • The User Name specified for the new account is a duplicate of an existing account on the system.
  • The user name you are trying to create is identical to the user name you used to log in

For example, if the user account User1 is logged into the BIG-IP system, and that user tries to create a new user account with the user name User1, the mcpd process will crash.

Impact

The BIG-IP may experience a brief service interruption while the mcpd process restarts.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The mcpd process dumps core, creating files that are named similarly to the following example in the /var/core/ directory:

    mcpd.bld355.0.core.gz
  • Messages similar to the following examples written to the /var/log/ltm file:

    01070418:5: connection 0xaa1c868 (user User1) was closed with active requests
    0107082a:3: Disconnecting user User1
    010c0009:6: Lost connection to mcpd - reestablishing.
    01060110:5: Lost connection to mcpd with error 16908291, will reinit connection.
    logger: Re-starting mcpd
  • Messages similar to the following example written to the Configuration utility:

    General database error
