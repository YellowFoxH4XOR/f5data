Known Issue

When various events occur on the BIG-IP WebAccelerator system, for example when a hit log is rotated, content is invalidated, or stats are reset, mcpd sends an incorrect message sequence to the Traffic Management Microkernel (TMM). As a result, the following error message displays in the /var/log/ltm file:

01070718:4: Unexpected proxy reply from %TMM.

This error message does not indicate failure or negative system performance; the desired functions perform as expected.

F5 Product Development tracked this issue as CR87279 and CR101885, and it was fixed in BIG-IP 9.4.6 and 10.0.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, some of these issues (for example, when content is invalidated and BIG-IP WebAccelerator stats are reset) have been fixed in Hotfix-BIG-IP-9.4.5-HF2, issued for BIG-IP 9.4.5. You may download this hotfix or a later version of the hotfix from the F5 Downloads site.
