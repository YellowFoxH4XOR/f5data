Known Issue

The BIG-IP APM Session Variable Report may fail to render.

This issue occurs when the following condition is met:

  • A session variable value of an active session contains the percentage character (%).

Impact

The BIG-IP APM Even logs fail to render.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to run the Session Variable Report, the BIG-IP APM system displays an error message similar to the following example:

    URLDecoder: Illegal hex characters in escape (%) pattern..

Resolution

Workaround

There is no work around for this issue. However, you can alternatively use the sessiondump command line utility to display session variables information.
