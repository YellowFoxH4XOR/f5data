Description

License reactivation for BIG-IP may trigger a reboot in FPGA-capable BIG-IP platforms

Below message appear on LTM logs:
Aug 18 21:25:53 testf5.bigip.com warning mprov.postcommit[29042]: Reboot is required for [ fpga ]

Environment

  • FPGA-capable BIG-IP platforms
  • TurboFlex Profile

Cause

This is due to:

Bug ID 1011217: TurboFlex Profile setting reverts to turboflex-base after upgrade

Recommended Actions

Upgrade to the version that has the fix for 1011217

Additional Information

None
