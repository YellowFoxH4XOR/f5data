Known Issue

A BIG-IP UDP virtual server may not send an ICMP Destination Unreachable message Code 3 (port unreachable).

This issue occurs when the following condition is met:

  • All pool members for the UDP virtual server are unavailable.

Impact

Hosts connecting to the BIG-IP system will not receive the necessary diagnostic data, ICMP Type 3 / Code 3, indicating the UDP virtual server's port is unavailable.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Client applications may not respond or appear to hang.
  • When attempting to troubleshoot the connectivity issue from remote devices, no ICMP diagnostic data is available from the BIG-IP system.
