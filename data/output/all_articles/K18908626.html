Description

Important: The BIG-IP Image Generator Tool has reached end of software development (EoSD) and is no longer supported with active updates. F5 will not provide software fixes (hotfixes) or consulting services for a version that has reached the EoSD milestone.

You want to create a custom BIG-IP image for a public cloud environment using a version that is not provided in the Cloud Marketplace. For example, BIG-IP images with a built-in engineering hotfix. You can use the F5 BIG-IP Image Generator Tool to create custom images for F5 BIG-IP Virtual Edition (VE), which include engineering hotfixes for Bring Your Own License (BYOL) or BIG-IQ deployments, or create clones of Public Cloud Marketplace images for any licensing type.

The following describes the high level steps for creating a custom BIG-IP image for Public Cloud.

Environment

Either:

  • BYOL or BIG-IQ licensing
  • Public Cloud environment supported by the BIG-IP Image Generator Tool
    • Alibaba
    • Amazon AWS
    • Microsoft Azure
    • Google Cloud Platform (GCE)

Or:

  • Any licensing type, including Pay-As-You-Go (PAYG)
  • BIG-IP version currently available in Public Cloud Marketplace

Cause

None.

Recommended Actions

For BYOL or BIG-IQ licensed deployments, consider using the BIG-IP Image Generator Tool. This can be used with any supported release and produces a ready-to-use image in a single step:

  1. Follow the instructions published in the README for F5 BIG-IP Image Generator Tool.

For PAYG images, you can create cloned images which will still be tied to your Public Cloud Marketplace subscription. These steps work with BYOL images as well, but is more involved than the above process:

  1. Launch a standalone instance from the Public Cloud Marketplace using the Public Cloud's console, Cloud Template, Terraform or other tools.

    Important: You MUST select the license level you plan to use and select a "2 boot" image.

  2. Upload the ISOs for the desired BIG-IP version to the system. For information about uploading ISOs, refer to K167: Downloading software and firmware from F5.

    Note: If you are creating a hotfixed or engineering hotfixed image, you need to upload both the base ISO and the HF ISO to the system.

  3. Install the desired version or hotfix to the second boot location (slot HD1.2) using the Live Install process. Review K84205182: BIG-IP update and upgrade guide for assistance with this process.
  4. After you have logged into the new version, follow the steps from K44134742: Considerations when cloning a BIG-IP virtual edition instance to prepare for cloning.
  5. After shutting down the instance, clone the instance. See your Public Cloud provider for specific instructions on creating the clone.
