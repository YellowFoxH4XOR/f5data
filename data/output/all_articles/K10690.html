In a RADIUS Access-Request packet, the NAS-IP-Address attribute (RADIUS attribute 4) provides the identifying IP Address of the requesting Network Access Server (NAS). You can change the default value used for the NAS-IP-Address attribute by selecting a different IP address in the NAS IP Address for RADIUS Requests menu. This menu is located on the Device Management : Configuration : Network Configuration page under the Misc tab. After changing the NAS IP Address for RADIUS Requests setting, you must finalize the change under the Finalize tab.

Changing the NAS IP Address for RADIUS Requests setting does not change the source IP address of the packets sent from the FirePass controller to the RADIUS server. The source IP address of those packets are set to the IP address of the egress interface on the FirePass controller. Currently, there is no configuration option to specify an alternate source IP address for RADIUS requests.

Note: In a failover pair (high availability) configuration, FirePass sets the source IP address of RADIUS packets to the physical IP address of the egress interface, not the virtual IP address of the egress interface.

Note: For more information about the NAS-IP-Address attribute, refer to section 5.4 of RFC2865.
