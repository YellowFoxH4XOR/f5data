Topic

BIG-IP 4.6.x

BIG-IP contains a script to automate core capturing. By default, this script is enabled. When it runs, it creates the /var/crash directory on the primary drive for the core capture. If the swap partition on the primary drive is not large enough to capture the core file, BIG-IP will look for another unused partition for the core capture.

To disable automatic core capturing, type the following command:

config_savecore -disable

To enable automatic core capturing functionality, type the following command:

config_savecore -enable

Note: When the core capture functionality is enabled, you will see the following message during boot up: savecore: no core dump.

BIG-IP 4.5.x

To configure a BIG-IP Controller to capture a core dump on a server appliance or a switch appliance with a hard drive, type following commands:

mkdir /var/crash
cp /etc/rc /etc/rc.bak
sed -e '/savecore \/var\/crash/s/savecore/savecore -z/' /etc/rc.bak >
/etc/rc

To disable core dump, type the following command:

rm -r /var/crash

For information about enabling a TFTP core dump on switch appliances without a hard drive, refer to solution K2226: Configuring a BIG-IP IP Application Switch or BIG-IP Link Controller to send core files to a remote TFTP server.

Testing the Configuration

To test the new configuration, force the BIG-IP Controller to crash by typing the following command:

Important: This command will reboot the BIG-IP Controller, interrupting traffic.

bigpipe wd panic
