K3637: Configuring BIG-IP to generate SNMP traps that are compatible with the HP OpenView Network Node Manager

Topic

BIG-IP sends SNMP version 1 traps. HP OpenView Network Node Manager accepts only SNMP version 2 traps.

When HP OpenView Network Node Manager receives an SNMP version 1 trap from BIG-IP, it maps the trap to an SNMP version 2 trap PDU, in accordance with RFC1452, and links an extra .0 between the enterprise OID and the specific trap number. This change prevents the HP OpenView's Network Node Manager from matching the default BIG-IP MIB definitions, because the MIB definitions do not contain the additional .0.

Starting in version 4.6.2, BIG-IP includes a feature that allows it to send SNMP version 2 compatible traps.

Note: For information about upgrading, refer to the BIG-IP Release Notes.

To enable this feature, perform the following steps:

  1. Log in to the command line.
  2. Enable the feature, by typing the following command:

    bigpipe db set Common.Bigip.SNMP.UseV1 = "false"

  3. Restart checktrap.pl, by typing the following command:

    kill -HUP `pidof checktrap.pl`

  4. Restart syslogd, by typing the following command:

    kill -HUP `pidof syslogd`

BIG-IP will now send SNMP version 2 traps.
