K9283: Using a local user when the CIFS proxy user cannot be a domain user

Important: For ARX versions prior to 5.0.0, the CIFS proxy users only use NTLM authentication to access the back-end filers. Kerberos and NTLMv2 authentication are not supported. Beginning in ARX version 5.0.0, the proxy user can use Kerberos or NTLM authentication; NTLMv2 authentication is not supported. For more information, refer to K10214: Change in Behavior: CIFS proxy user authentication.

The ARX CIFS proxy user cannot be a domain user in either of the following two scenarios:

  • For ARX versions prior to 5.0.0, if the domain controller prevents NTLM authentication and enforces only Kerberos or NTLMv2 authentication
  • For ARX versions 5.0.0 and later, if the domain controller prevents NTLM and Kerberos authentication and enforces only NTLMv2 authentication

If the ARX proxy user cannot be a domain user, you can create a local user on each of the filers. Using a local user includes the following requirements:

Important: All of the filers in the namespace associated with this CIFS proxy user must support the CIFS proxy user authentication method supported by the ARX. For example, ARX versions 5.0.0 and later support NTLM or Kerberos. ARX versions prior to 5.0.0 support NTLM only.

  • Create a local user on each of the back-end filers with identical credentials
  • Add the local user to the local Backup Operators group on on each back-end filer

    Note: For information about adding this user account to your filer, and adding it into the local group Backup Operators, refer to the documentation for your specific file storage device.
     
  • Create the CIFS proxy user on the ARX system and do not specify a domain

    Note: You cannot perform this procedure in the GUI. For more information, refer to K9290: ARX Manager GUI requires Windows Domain for CIFS Proxy User.

    Note: For information about adding a CIFS proxy user, refer to the Preparing for CIFS Authentication chapter in the ARX CLI Storage Guide.

    Important: You do not need to perform the Specifying the Windows Domain procedure.

Note: For information about associating the new CIFS proxy user with your namespace, refer to the Configuring a Namespace chapter in the ARX CLI Storage Guide.
