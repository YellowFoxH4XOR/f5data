Description

/var partition have a lack of space due to ASM sync files such as below: 

/var/ts/var/sync/sync_xxxxxxxxxx_xxxxxxxxxxxxxxxxx_full_update
/var/ts/var/sync/ts_db.save_dir_6420.cstmp/ts_db.data.PLC.PL_POLICY_NEGSIG_SIGNATURES.cstmp     
/var/ts/var/sync/ts_db.save_dir_6420.cstmp/ts_db.data.DCC.ACCOUNT_NEGSIG_SIGNATURE_PROPERTIES.cstmp

Some ASM sync files remain on disk (/var/ts/var/sync/*) after config sync finishes, it would remain until periodic clean-up tasks are activated.

Environment

  • BIG-IP ASM
  • BIG-IP devices are in a sync group
  • /var partition has space issue 

Cause

Bug ID 956373

Recommended Actions

To resolve the issue, delete the files by running the below command: 
rm -rf /var/ts/var/sync/<file> 

For example: 
rm -rf var/ts/var/sync/sync_*_full_update

Additional Information
To avoid this issue where the file remains in /var causing lack of space, you can consider creating a cron job to delete contents of /var/ts/var/cluster/send directory more frequently. You may refer to K17344 on how to do so.
