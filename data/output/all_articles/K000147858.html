Working with AAAA records

  • An AAAA record maps a domain name (e.g., www.example.com) to an IPv6 address (e.g., 2001:db8:ffff:ffff:ffff:ffff:ffff:ffff).
  • This mapping enables a user to connect with and load a website without memorizing an IP address.
  • It is common to have one AAAA record per domain name, but it is possible to have several.
  • When an AAAA record has several different IP addresses as values, the DNS service will use round-robin load balancing to return one of the IP addresses.
  • If a record has an IPv4 address, use an A record.
