K000135139: Verifying Tripo session capacity

Type
Support Solution
Published
2023-06-25
Updated
2024-10-01
Applies to
  • Traffix SDC: 5.2.X, 5.2.0, 5.1.0
Source
https://my.f5.com/manage/s/article/K000135139

Description

  • There are instances where in you need to know what is the limit of the sessions stored in Tripo.

Environment

  • Traffix SDC 5.x

Cause

By design.

 Recommended Actions

  1. We can verify this value by going to go to /srv/traffix and view the topology.xml, under the topology.xml there is a section for tripo and it will have the maxSessions. 

    <tripo>

      <secondSiteIP1>1.1.1.1</secondSiteIP1>

      <secondSiteIP2>1.1.1.1</secondSiteIP2>

      <maxSessions>1000</maxSessions>

      <tripoVersion>latest</tripoVersion>

      <srrInterface>IC-eth1</srrInterface>

      <srrListenPort>43211</srrListenPort>

<secondSiteSrrPort>43211</secondSiteSrrPort>

 

Additional Information

None.
