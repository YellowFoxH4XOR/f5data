Known Issue

This is the result of a known issue. Using the LB::detach iRule command in the LB_FAILED event may cause TMM to core.

When detaching the server-side connection in the LB_FAILED event, the server-side connection is closed and the server-side flow is removed from the connection table. The client-side flow is left open, but inaccurately marked free. If TMM allocates the flow for a new connection, TMM may core.

F5 Product Development tracked this issue as CR109351 and it was fixed in BIG-IP version 10.0.0. For information about upgrading, refer to the BIG-IP LTM or ASM release notes.
