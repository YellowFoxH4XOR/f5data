Issue

Old Behavior

In versions prior to 11.4.0, the BIG-IP ASM system applies attack signatures to cookie values through header attack signature checks.

New Behavior

Beginning in version 11.4.0, the BIG-IP ASM system applies attack signatures to cookie values through parameter attack signature checks.

Impact

Cookie violations are now enforced and logged as parameter violations. For example, a cookie with a value of /etc triggers an attack violation similar to the following:

BIG-IP ASM 11.3.0 and earlier:

"/etc" execution attempt(Headers) (sig_id:200003055)

BIG-IP ASM 11.4.0 and later:

"/etc" execution attempt(Parameters) (sig_id:200003054)
