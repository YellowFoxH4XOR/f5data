K18528891: CPU spike on Virtual Server with Source Address Address List running BIG-IP LTM 15.1.3.1

Type
Support Solution
Published
2021-09-27
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 15.1.3
Source
https://my.f5.com/manage/s/article/K18528891

Description

You are experiencing CPU spike on BIG-IP 15.1.3.1.

It is noticed that the CPU spikes are related to tmm which is traffic related.

You have Virtual Server(s) which has Source Address configured with Address List.

The Address List will contain multiple IP addresses and also subnets.

Environment

  • BIG-IP 15.1.3
  • CPU spike related to tmm
  • Virtual Server(s) has Source Address configured with Address List
  • Multiple IP addresses and subnets in address Address List

Cause

The Address List configured on the Source Address is causing the CPU spike.

The root cause of this issue is still under investigation.

Recommended Actions

Removing the Address List from the Source Address of the Virtual Server would resolve the CPU spike. You can use iRule to limit access to the Virtual Server.

  1. Login to the BIG-IP Configuration Terminal
  2. Navigate to Local Traffic > Virtual Servers > Virtual Server List
  3. Click the mentioned Virtual Server
  4. Under Source Address change to Host
  5. Click Update
  6. Refer to K42075438 or K73554344 to limit access to the Virtual Server using iRule
