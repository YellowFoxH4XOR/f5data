Topic

You can configure the system authentication for administrative users to use a remote LDAP server and to have only a single remote authentication host entry.

For system authentication, F5 recommends that you configure a high availability (HA) LDAP authentication by referencing a locally hosted LTM virtual server.

Each LDAP server is actively monitored using the built-in BIG-IP LDAP monitor, and its status is reported as available (green/up), unavailable (red/down), or unknown (blue) based on the server's response. When a pool member is marked down, the Traffic Management Microkernel (TMM) sends an RST (reset) back to the host process, which results in a much faster failover management than a simple timeout event. Pool members can be administratively disabled for maintenance.

F5 recommends that you use Secure Sockets Layer (SSL) to encrypt LDAP communications (ldaps) between BIG-IP and the LDAP servers, as in the following example, since all LDAP queries are in plain text. When using a serverssl profile, the clientssl transactions that would otherwise be delegated to the host are offloaded to the more efficient, higher capacity crypto hardware.

Configuring HA authentication for administrative access

To configure HA authentication for administrative access to the BIG-IP system, specify a locally hosted LDAP virtual server as the Host. When configuring Remote - LDAP as the User Directory for BIG-IP system user authentication, refer to the following article:

  • K11072: Configuring LDAP remote authentication for Active Directory

Configuring HA authentication for virtual servers

To configure HA authentication for virtual servers, you must first license and provision the BIG-IP APM module. Using BIG-IP APM, you can create an access profile and policy that, when specified in the virtual server configuration, prompts users accessing the virtual server for their LDAP credentials and permits successfully authenticated users access to the virtual server. To configure the BIG-IP APM for virtual server authentication, refer to the following articles.

  • K34150119:  Creating a TACACS+ authentication profile and policy for virtual server authentication
  • K41837805:  Creating a RADIUS authentication profile and policy for virtual server authentication
  • K52354366:  Creating a LDAP authentication profile and policy for virtual server authentication
