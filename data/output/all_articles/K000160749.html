K000160749: HA daemon_heartbeat bd fails

Type
Support Solution
Published
2026-05-07
Updated
2026-05-07
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.5.X, 17.5.1, 17.5.0
Source
https://my.f5.com/manage/s/article/K000160749

Description

A production vCMP guest running BIG-IP ASM repeatedly showed an OFFLINE status after reboot, with the ASM module constantly restarting and the bd process crashing. The issue is triggered on every vCMP reboot.

Environment

  • ASM restart loop
  • bd process

Cause

Bug ID 2139921: Invalid Length PCRE Expression Was Allowed Through REST API

Answer/Recommended Actions

Upgrade to the one of the fixed version 17.5.1.6 or 17.1.3.2.

Additional Information

None
