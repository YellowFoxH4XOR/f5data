Known Issue

Special characters may display incorrectly in the Event Logs.

This issue occurs when the following condition is met:

  • Multi-byte non-ASCII characters are received in an input field.

Impact

Access System Logs (Access Policy > Event Logs > Access System Logs) display special characters as non-readable content.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Access System Logs display special characters as non-readable content.
