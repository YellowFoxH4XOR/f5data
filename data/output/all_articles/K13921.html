Known Issue

Web scraping detection may interfere with web resources that contain JavaScript.

This issue occurs when all of the following conditions are met:

  • Web scraping detection is enabled.
  • A response from the origin web server contains a single quotation mark ( ' ) within a comment field and a JavaScript function.

    For example, an HTTP response containing the following code excerpt is susceptible to this issue:

    // This is a comment that has a ' character
    document_print.document.write<ht' + 'ml><he' + 'ad><tit' + 'le></tit' + 'le></he' + 'ad><ht'+ 'ml>')

The BIG-IP ASM system injects JavaScript tokens into server responses in order to enable web scraping detection. As a result of this issue, the comment may be incorrectly interpreted and the BIG-IP ASM specific JavaScript may be injected at an incorrect location, which may impact the JavaScript already present in the response.

Impact

This issue may result in irregular rendering or non-rendering of web resources.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • JavaScript in HTTP responses may not function correctly.
  • BIG-IP ASM web scraping detection JavaScript may be injected in the middle of existing JavaScript code from the origin web server.

    Note: A network inspection or HTTP debugging tool, such as Wireshark or Fiddler, is required to inspect the HTTP response returned by the BIG-IP ASM system before it is executed by the browser.

Workaround

You may be able to work around this issue by removing all single quotation marks from all comment strings in your web application.
