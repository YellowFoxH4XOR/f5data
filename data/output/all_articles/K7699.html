Known Issue

This is the result of a known issue. If you disable HTTP pipelining within the HTTP profile, when HTTP pipelining is used in conjunction with the client-side SSL profile, TMM may crash.

This issue occurs with clients that use pipelining over an SSL connection and are slow to accept responses from the BIG-IP LTM. This behavior is caused by the HTTP filter incorrectly handling the data that the client sent.

F5 Product Development tracked this issue as CR50764 and it was fixed in BIG-IP LTM version 9.3.1. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

F5 recommends that you do not disable pipelining within the HTTP profile.
