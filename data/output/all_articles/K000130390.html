Description

Warning message:
platform_agent[<PID>]: 01d50005:4: Unable to Notify Tenant stats. Retrying...

In this warning message, note the following:

  • <PID> is the process ID
  • This warning message shows every 10 seconds in the /var/log/ltm log

Environment

  • BIG-IP Tenant(Using F5OS)
  • Version 15.1.8

Cause

ID1182613

 Recommended Actions

There is no impact on your system, but it will consume some of your disk space. As per the publication of this article, there is an EHF on top of 15.1.8. If you have a newer version, please check the release notes for the fix information, for how to find the release notes, please refer to K55201922: Locating product release notes. If you want a fix on top of the 15.1.8 please open a Support Service Request, for how to open a service request please refer to K76100544: Information required when opening a support case for VELOS and rSeries systems.
