Known Issue

Enterprise Manager may fail to import a security policy from a managed device. This issue occurs when all of the following conditions are met:

  • Enterprise Manager has either previously or currently managed BIG-IP devices running BIG-IP ASM 10.x.
  • You attempt to import security policy from a BIG-IP ASM-managed device running 11.3.0 or later on the Enterprise Manager Configuration utility Policy Import page (Security > Application Security > Policies).

The security policy import feature was introduced in Enterprise Manager 3.1.0 and it supports importing security policy from BIG-IP ASM 11.3.0 and later.

Impact

You cannot use Enterprise Manager to import a security policy from a BIG-IP ASM-managed device.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you attempt to import the security policy on the Security > Application Security > Policies > Policy Import page, the Enterprise Manager Configuration utility fails to list the managed device in the Import Security Policies from Device list.
