Known Issue

This is the result of a known issue. Virtual servers referencing an iRule with the HTTP::respond, or HTTP::redirect command on the server-side of the connection can cause a memory leak. For example, if either the HTTP::respond, or HTTP::redirect command are called using an iRule event such as HTTP_RESPONSE, the BIG-IP LTM will leak an empty xbuf.

F5 Product Development tracked this issue as CR76613, and it was fixed in BIG-IP LTM 9.1.3 and 9.3. For information about upgrading, refer to the BIG-IP LTM Release Notes.
