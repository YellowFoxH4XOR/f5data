Known Issue

The BIG-IP system reports an error message when specifying a ratio weight value greater than 100 for a pool member.

This issue occurs when the following conditions are met:

  • The pool is configured to use the Ratio (member), or Ratio (node) load balancing methods.
  • You attempt to set the ratio weight to a value greater than 100.

Impact

You are unable to create or update the load balancing pool.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H436976 on the Diagnostics > Identified > Low screen.
  • You are unable to create or update the load balancing pool.
  • When you attempt to specify a ratio weight value greater than 100, the system logs an error message similar to the following example to the /var/log/ltm file:

    mcpd[6024]: 01070081:3: The requested ratio for the pool member (<pool_member_ip>) is invalid. [1..100].

Workaround

To work around this issue, you can specify a ratio weight value of 100 or less when using the Ratio (member), or Ratio (node) load balancing methods.
