Topic

The BIG-IP system does not reply to an Echo Request with an incorrect IP checksum. This behavior is by design and should not affect system performance.

Some operating systems do not send a valid IP checksum when they generate ICMP Echo Requests, such as in traceroute or ping operations. The BIG-IP LTM system drops the received packet if the checksum is invalid, which results in a lack of response from the BIG-IP LTM system.

The purpose of the IP checksum is for simple error detection, in order to prevent the transmission of corrupt packets. The best method to determine if the IP checksums are incorrect or being generated incorrectly is to run the tcpdump utility on the BIG-IP LTM system while attempting to issue an ICMP Echo Request. You can then view the results in an analyzer to see the checksum information.

For information about using the tcpdump utility, refer to K411: Overview of packet tracing with the tcpdump utility and K1893: Best Practice: Packet trace analysis.
