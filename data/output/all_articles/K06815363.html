Description

Pinners Rule does not work properly.
In URL Category Lookup, searching for a known categorized URL results "Uncategorized".

Some errors will be logged in /var/log/apm similar to the following examples:

err urldbmgrd[17307]: 01770068:3: 00000000: Category create/modify failed with return code 16908390
err urldbmgrd[17307]: 01770021:3: 00000000: Category create/modify error: result { result_code 16908390 result_message "01020066:3: The requested URL Category (/Common/Financial_Data_and_Services) already exists in partition Common." }

Environment

  • BIG-IP ASM 

  • BIG-IP SSL Orchestrator

Cause

URLDB failure due to any reason.

Recommended Actions

1) Stop urldbmgrd
    bigstart stop urldb urldbmgrd

2) Delete databases
    rm -rf /var/urldb/master/
    rm -rf /var/urldb/rtu/

3) Perform mcpd forceload as per K13030:
    touch /service/mcpd/forceload
    reboot

After the reboot, urldbmgrd will re-download and implement new databases.
