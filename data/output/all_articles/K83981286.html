Description

System reported a dataplane error on TMM and went offline during normal operation. No core file created.

/var/log/ltm showed the following logs:

01140029:4: HA dataplane_inoperable_t tmm fails action is go offline and down links.
01010025:2: Device error: hsbe2 hsb_lbb0 tre1_crc_errs count

Environment

  • This issue occurs on hardware appliances using High Speed Bus (hsb)

Cause

This message can be seen in two cases: either as a result of a hardware failure due to an unknown cause related to ID 762073: Continuous TMM restarts when HSB drops off the PCI bus

Recommended Actions

  1. The system should be rebooted to restore service if it didn't reboot on it's own
  2. Upgrade to Version 14.1.2.5  or 15.1.0 or later to address the possible ID related cause
  3. If the system continues log this message to fault it may be defective
