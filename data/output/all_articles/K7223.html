K7223: Nessus scan indicates one or more Apache format string vulnerabilities

Topic



The Nessus application vulnerability scanner, specifically Nessus Plugin ID's 11801 and 15640, may incorrectly report that the FirePass controller is vulnerable to one or more Apache format string vulnerabilities when a scan is run. Subsequent investigation by F5 Networks indicates that FirePass is not vulnerable to the attacks these Plugins represent, which indicates that the Plugins are generating false positives. F5 Networks recommends that you investigate before considering these reports as accurate indications of vulnerabilities in the FirePass software.

The Nessus application vulnerability scanner is available as a public domain version and a commercial version from Tenable Security. Nessus uses the NASL programming language to allow developers to write Plugins to attempt to detect each vulnerability. In the case of Plugin ID's 11801 and 15640, the NASL code sends the following strings to a web server:

  • Plugin ID 11801, "Format string on HTTP method name":

    %s

%08x

%#0123456x%08x%x%s%p%n%d%o%u%c%h%l%q%j%z%Z%t%i%e%g%f%a%C
%S%08x%%#0123456x%%x%%s%%p%%n%%d%%o%%u%%c%%h%%l%%q%%j%%z
%%Z%%t%%i%%e%%g%%f%%a%%C%%S%%08x

  • Plugin ID 15640, "Format string on URI":

    <method> %s

<method> %08x

<method> %#0123456x%08x%x%s%p%n%d%o%u%c%h%l%q%j%z%Z%t%i%e%g%f%a%C%
S%08x%%#0123456x%%x%%s%%p%%n%%d%%o%%u%%c%%h%%l%%q%%j
%%z%%Z%%t%%i%%e%%g%%f%%a%%C%%S%%08x

In the strings for Plugin ID 15640, method is one of the valid HTTP request methods, such as GET, PUT, HEAD, OPTIONS, TRACE, MOVE, INDEX, MKDIR, RMDIR and DELETE.

Once these requests are sent, Nessus reads the web server response and searches both the HTTP header and data for one or more strings that match the following regular expression:

[0-9a-fA-F]{8}

This regular expression matches any string consisting of eight or greater consecutive digits, or letters a through f (the hex numbers 10 through 15), in any order of digits or letters.

This matching criterion is broad, and can easily yield false positives. For example, in the case of FirePass, typically a page with an HTTP 400-series response code (errors) will be returned. This does not represent a vulnerable response, but because of the presence of an ETag in the error page's HTTP header, the regular expression matches, and FirePass is incorrectly flagged as vulnerable to the attack.

Other strings in a non-vulnerable response can be matched as well.

Plugin ID's 11801 and 15640 have been removed from Nessus's Plugin update feeds.

For additional information and analysis of any Nessus results, consult the Tenable Technical Support, the Nessus mailing list (if you are using the free version of Nessus without a support contract), or F5 Networks Technical Support.
