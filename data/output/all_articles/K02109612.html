Description

  • How to lookup an IP and verify if it is correctly inherited through the feed list

Environment

  • AFM IP intelligence
  • Feed list

Cause

None.

Recommended Actions

You can use the following tmsh commands to query the IP:

  • If the ip-intelligence policy is applied to the Global context, use the following command replacing <ip address> for the required IP:

    tmsh show security ip-intelligence info address <ip address>

  • If the ip-intelligence policy is applied to the virtual server context, use the following command replacing <ip address> for the required IP and <vs name> for the virtual server in question:

    tmsh show security ip-intelligence info address <ip address> virtual-server <vs name>

  • If the ip-intelligence policy is applied to the route domain context, use the following command replacing <ip address> for the required IP and <route domain> for the route domain in question:

    tmsh show security ip-intelligence info address <ip address> route-domain <route domain>

Additional Information

None.
