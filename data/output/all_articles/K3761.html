Topic

You can configure the Configuration utility to display the advanced menu options for all pages by default. When you change the Advanced by Default setting from Default to Advanced, the system presents all configurable settings for a feature.

Configuring the BIG-IP system to display the advanced Configuration utility options for all pages by default

BIG-IP 11.x

  1. Log in to the Configuration utility.
  2. Navigate to System > Preferences.
  3. Click the down arrow next to Default System Settings.
  4. Click Advanced.
  5. Click Update.

BIG-IP 9.x through 10.x

  1. Log in to the Configuration utility.
  2. Naviagate to System > Preferences.
  3. Click the down arrow next to Advanced by Default.
  4. Click Advanced.
  5. Click Update.
