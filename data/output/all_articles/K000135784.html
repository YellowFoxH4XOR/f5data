Description

While deploying an API you are unable to do so and encounter the following error.
[/cm/access/reports/saml-log-node-task-creator SamlLogNodeTaskCreatorWorker] All lognodes seem busy. Start task on node X.X.X.X
7 Aug 2023 08:01:19 GMT - severe: [appsvcs] {"message":"Error: POST http://undefined:XXXXXX@localhost:8100/mgmt/cm/global/tasks/deploy-app-service post AS3 declaration


Environment

BIG-IQ version 8.x
AS3 deployment


Cause

Only one instance of the same type of task is allowed to run. If the pervious AS3 declaration has not finished yet then a new declaration will be rejected until the previous task reaches the "finished" state.


Recommended Actions

If you have lots of frequent updates, then, it's possible that a new task can be conflict with an existing task not finished yet. Usually the error will disappear when you try it again.

If you are still having issues after letting some time between updates, gather new qkview archives and open a case with F5 support.
