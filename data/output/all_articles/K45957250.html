Description

When trying to sync configuration, the following error occurs and sync fail:
Sync error on ltm2.f5.com: Load failed from /Common/ltm1.f5.com 01071769:3: Decryption of the field (factory_rule) for object (/Common/DiffBot) failed while loading configuration that is encrypted with a different master key.

You may find it also, while showing Sync-Status with the following tmsh command:
show cm sync-status

--------------------------------------------------------------------------------
CM::Sync Status
--------------------------------------------------------------------------------
Color    red
Status   Sync Failed
Mode     high-availability
Summary  A validation error occurred while syncing to a remote device
Details
         ltm2.f5.com: connected
         HA (Sync Failed): A validation error occurred while syncing to a remote device
          - Sync error on ltm2.f5.com: Load failed from /Common/ltm1.f5.com 01071769:3: Decryption of the field (factory_rule) for object (/Common/DiffBot) failed while loading configuration that is encrypted with a different master key.
          - Recommended action: Review the error message and determine corrective action on the device
 

Environment

  • BIG-IP HA environment
  • Master key on one unit was changed

Cause

Master Key on one of the HA devices was modified and while attempting to sync configuration, the sync operation failed

Recommended Actions

  1. Take a ucs back of ltm1.f5.com
  2. Export the master key from ltm2.f5.com:
    # f5mku -K
  3. Import the master key to ltm1.f5.com:
    # f5mku -r <key from #2>
  4. Confirm master key imported successfully:
    # f5mku -K (output should be identical to ltm2.f5.com's master key)
  5. Re-sync the devices

Additional Information

The following is an example for fetching the current master key from device A and importing it to device B.
Run the following command to pull out current Master Key:
Fetching master key from device A:
# f5mku -K
The command's output is the current master key. e.g:
8DvmOw7o3HtrX3rO1kT4Mg==

Note: master key must be identical on both devices in the HA

Importing the master key from device A to device B:
# f5mku -r 8DvmOw7o3HtrX3rO1kT4Mg==
