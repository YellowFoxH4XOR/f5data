Topic

You should consider using this procedure under the following condition:

  • You want to reallocate the available disk resource to provision multiple licensed modules on the BIG-IP Virtual Edition (VE) system or a BIG-IP Virtual Clustered Multiprocessing (vCMP) guest.

Description

In versions prior to BIG-IP 11.5.0, when you attempt to provision multiple licensed modules, which requires intense disk resource allocation on a BIG-IP VE system or a BIG-IP vCMP guest, the system may experience a provisioning error that reports a disk space limitation similar to the following example:

01071008:3: Provisioning failed with error 1 - 'Disk limit exceeded. 40088 MB are required to provision these modules, but only 32660 MB are available.'

For example, if you attempt to provision AFM, AAM, ASM and AVR modules on a BIG-IP VE system, the system does not provision these modules and reports the error previously described.

This error occurs because the system allocates a certain amount of the disk space (typically about 20 GB) to the vg_reserved volume, and the disk space is not available for other modules to use. This behavior is by design. However, you can resize the vg_reserved volume to free up disk space for other modules to use. F5 recommends that you set the minimum size for the vg_reserved volume at 10,000 MB or more. You can perform the following procedures to determine the size of, and resize, the vg_reserved volume on your BIG-IP system.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You can access the Traffic Management Shell (tmsh).

Procedures

  • Determining the size of the vg_reserved volume
  • Resizing the vg_reserved volume

Determining the size of the vg_reserved volume

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Use the following command syntax to display the disk properties on the BIG-IP system:

    list /sys disk logical-disk <logical disk name> all-properties

    For example, the BIG-IP system returns the properties of its disk HD1 when you type the following command:

    list /sys disk logical-disk HD1 all-properties

    The following output example shows the vg_reserved volume is currently allocated with 20,480 MB:

    sys disk logical-disk HD1/1 {
    mode mixed
    size 102400
    vg-free 33052
    vg-in-use 68084
    vg-reserved 20480
    }

Resizing the vg_reserved volume

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Use the following command syntax to resize the vg_reserved volume:

    Important: Do not resize the vg_reserved volume to a value less than 10,000 MB.

    modify /sys disk logical-disk <storage name> vg-reserved <new size>

    For example, type the following command to resize the vg_reserved volume to 10,000 MB on the HD1 disk:

    modify /sys disk logical-disk HD1 vg-reserved 10000

    Note: The system automatically saves any modifications that this command initiates, and the modifications take effect immediately.

  3. Optional: Verify that the system has resized the vg_reserved volume by performing the previous procedure.
  4. Provision the multiple modules.
