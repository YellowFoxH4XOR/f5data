Issue

Error Message

Error 51134, F5 registration key is not compatible with the detected version - This software version, "y.y.y" cannot be activated with this registration key "xxxxxxx-xxxxxxx".

In this error message, note the following:

  • <y.y.y> is the upgraded version you attempt to activate.
  • <xxxxxxx-xxxxxxx> is your BIG-IP license registration key.

For example:

Error 51134, F5 registration key is not compatible with the detected version - This software version, "15.1.0" cannot be activated with this registration key "B123456-7654321".

Message Location

You may encounter this message in the following location:

  • The System > License > Re-activate page in the Configuration utility

Description

This message occurs when all of the following conditions are met:

  • You are using Version Plus licensing.
  • You attempt to activate a BIG-IP version that is higher than what you are licensed for.

Version Plus licenses enable you to use BIG-IP Virtual Editions (VEs) with perpetual usage. However, upgrades are limited to software versions within a pre-established range of software releases, as documented in K15643: BIG-IP VE license offerings. The BIG-IP system allows you to install versions that are not compatible with the installed Version Plus license. 

For example, a V12 Version Plus license does not support BIG-IP 15.0.1, but the system allows you to install and restart into this version in another slot without error. The BIG-IP system displays a banner indicating that the license is invalid. Upon reactivation, the system displays this error message from the license server.

Impact

You cannot activate the BIG-IP system, and the system does not pass traffic.

Recommended Actions

You should purchase a new Version Plus license that supports the BIG-IP version you want to install, or you can restart into a BIG-IP slot that has a BIG-IP version that is supported by your license. For more information about supported versions, refer to K15643: BIG-IP VE license offerings.
