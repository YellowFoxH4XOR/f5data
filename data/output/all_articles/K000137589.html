K000137589: No signature id in event log

Type
Support Solution
Published
2023-11-15
Updated
2024-11-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.X, 17.1.1, 17.1.0
Source
https://my.f5.com/manage/s/article/K000137589

Description

  • There is "Attack signature detected" violation in event log.

  • While click on the Occurrences next to "Attack signature detected" violation to see the "Attack signature detected" violation details, you can see only signature name, there is not relevant signature id.

Environment

  • BIG-IP ASM, AWAF

  • Security >> Event Logs: Application: Requests

  • Attack signature detected

Cause

This is ID1036289, missing the signature id in "Attack signature detected" violation details.

Recommended Actions

Currently, you can only see the associated signature ID by clicking "See More" next to the attack signature name and then clicking the "Documentation" link (this will take you to the specific signature entry in the Security  ››  Options : Application Security : Attack Signatures : Attack Signatures List).

Additional Information

None
