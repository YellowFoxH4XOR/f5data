Description

When we login to SSH with root account & from there if we try to login to admin account with the command 'su admin' not works. 

Environment

  • rSeries appliance
  • SSH access

Cause

This issue can be faced when someone modifies the content at /etc/passwd file.

Recommended Actions

Please edit the /etc/passwd file & make sure it has the below default values. Post changes please test the access to admin account again.

root:x:0:0:root:/root:/bin/bash

tcpdump:x:72:72::/:/sbin/nologin

admin:x:1000:9000::/var/F5/system:/var/lib/controller/f5_confd_cli

Additional Information

You may use vi editor tool or any other preferred tool to make the above suggested changes.
