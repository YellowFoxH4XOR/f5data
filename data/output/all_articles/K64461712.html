Known Issue

The BIG-IP system reuses ephemeral ports when you use the source port change option.

This issue occurs when the following condition is met:

  • You select the Change option for the Source Port setting within a virtual server.

Impact

If server connections are in the TIME_WAIT state and you have not configured connection recycling, the server may reset the connection and reuse ports.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the BIG-IP system selects server-side source ports, the system favors ephemeral ports in the upper range, which may result in the system reusing ephemeral ports.

Workaround

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

To work around this issue, you can revert back to or leave the Source Port option in the default setting of Preserve. For more information on setting the Source Port option to Preserve, refer to K11003: Configuring source port preservation for virtual servers.
