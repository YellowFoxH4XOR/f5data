K000146651: Are custom roles and custom role bindings supported on virtual Kubernetes (vk8s)?

Published

Updated
2024-11-08
Applies to

  • F5 Distributed Cloud
Source

Description

You want to know if custom roles and custom role bindings are supported on virtual Kubernetes (vk8s).

Environment

  • F5® Distributed Cloud App Stack (XC App Stack)

Cause

You want to know if custom roles and custom role bindings are supported on virtual Kubernetes (vk8s).

Answer/Recommended Actions

  • No, they are not
  • ClusterRole and ClusterRoleBinding have to be handled via managed Kubernetes (k8s)

Workaround

  • You need to provision your XC App Stack site with k8s_object and then use virtual Kubernetes (vk8s) on top of it

 

Additional Information

  • None
