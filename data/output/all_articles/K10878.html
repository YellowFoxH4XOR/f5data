Topic

After a Web Application favorite has launched, a mini browser pops up for the application. Some users may prefer a full browser rather than a mini browser. To configure a full browser, perform the following procedure:

  1. Navigate to Application Access: App Tunnels: Resources from the Administrative Console.
  2. Click on the Web Application Tunnels tab.
  3. Click on the Web Application tunnel that you want to launch a full browser.
  4. Clear the check box next to Locked Browser.
  5. Click the Update button.

Note: This change will affect all users connecting to that Web Application favorite.
