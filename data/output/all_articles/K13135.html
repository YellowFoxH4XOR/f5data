Known Issue

The Deflate compression codec may exhibit poor performance when BIG-IP WOM is configured with a single external connection.

This issue occurs when all of the following conditions are met:

  • BIG-IP WOM is configured with a single external connection
  • Deflate compression is enabled with a level of 3 or less

BIG-IP WOM uses hardware compression when the Deflate compression algorithm is set to a level of 3 or less. This behavior may cause degraded transfer rates.

Impact

Data transfer rates through BIG-IP WOM are degraded.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Data transfers through the BIG-IP WOM connection take more time to complete than when using a compression codec that is not hardware enabled.

Workaround

To work around this issue, you can change the compression method used. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Hover mouse over Profiles.
  4. Hover mouse over Services.
  5. Click iSession.
  6. Click the name of the iSession profile of which you are changing the compression setting.
  7. Select the Deflate check box.
  8. From the Deflate drop-down menu, select Enabled.
  9. Select the Deflate Level check box.
  10. From the Deflate Level drop-down menu, select 4.
  11. Click the Update button.
