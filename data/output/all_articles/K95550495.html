Description

  • You configure Data-group on the BIG-IP under  System  ››  File Management : Data Group File List
  • You may have configured iRule that uses configured Data-Group/s to verify/authenticate users on the APM
  • Working on the BIG-IQ, you have discovered and Imported BIG-IP LTM and APM configuration onto BIG-IQ
  • You notice these configured Data Groups were not imported

Environment

  • iRule
  • Data-Group
  • BIG-IQ
  • BIG-IP
  • APM

Cause

  • Currently, the BIG-IQ does not support the importation of Data-Group from the BIG-IP

Recommended Actions

  • None. This feature is not available on the BIG-IQ at the moment

Additional Information

  • None
