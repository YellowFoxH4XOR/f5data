Description

ASM Behavioral DoS enabled, but not detecting DoS attacks.

Logs similar to the following are repeating in /var/log/adm/admd.log

admd: tmstat_open_read: open: /var/tmstat/cluster/blade0-performance: No such file or directory
admd: tmstat_read: open: /var/tmstat/cluster/blade0-performance: No such file or directory
ADMD.Daemon0 140659021305600 Sep 27 08:03:42 [error] bool CTMStatTable::waitUpdate() : Failed to open table <adm_stats> path: </var/tmstat/cluster/blade0-performance>
ADMD.Daemon0 140659021305600 Sep 27 08:03:42 [warning] bool CTMStatTable::listRows() : Failed to get the tmstat update - skip measure cycle.

Environment

  • DoS Profile
  • Behavioral DoS

Cause

This happens when sys db merged.method is set to slow_merge.

sys db merged.method {
    default-value "fast_merge"
    scf-config "false"
    value "slow_merge"                 <---
    value-range "fast_merge slow_merge"
}

ID1361041 tracks this issue with admd. This bug is not fixed at the time of this article's publication.

Recommended Actions

Re-enable the default merged behaviour of fast_merge:

tmsh mod sys db merged.method value reset-to-default

tmsh restart sys service merged
