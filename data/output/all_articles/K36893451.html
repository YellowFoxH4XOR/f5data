Known Issue

The Traffic Management Microkernel (TMM) may restart when processing an FTP connection with request logging configured.

This issue occurs when all of the following conditions are met:

  • Your configuration includes a virtual server with an associated FTP and Request Logging profile.
  • The FTP profile has the Inherit Parent Profile option enabled. The default setting is disabled.
  • The BIG-IP system processes an FTP connection's control channel and data channel on different TMMs.

Impact

Traffic processing is interrupted while TMM restarts and a failover event will occur if the BIG-IP system is in a high availability (HA) configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system may fail to process traffic for a brief period.
  • The BIG-IP system may fail over to another host in the device group.
  • TMM has produced a core file in the /var/core directory.

Workaround

To work around this issue, you can disable the Inherit Parent Profile option in the FTP profile.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
