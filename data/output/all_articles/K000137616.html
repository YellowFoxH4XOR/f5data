Description

Manually deleting the pool members from the pool are not rediscovered by AS3 Service discovery.

Environment

  • AS3
  • Service Discovery

Cause

When deleting the pool member, NOT the node, so Service Discovery doesn't see any differences since it's only comparing nodes on the BIG-IP vs nodes in the cloud. The pool members only get updated when a differences between nodes is detected. Service Discovery can make this assumption because it should be the only entity modifying that resource and it only does that when a change in the underlying nodes is detected.

It never checks the pool members for any differences because it doesn't expect the pool to be modified outside of its control. This is tracked under the BUG ID1328097.

 

Recommended Actions

Restart restnoded service.

tmsh restart sys service restnoded
