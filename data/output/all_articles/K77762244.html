Description

After upgrade to version 16.0.1, F5 is not responding to SNMP requests

Logs similar to the following may be found in /var/log/snmpd.log:

/config/snmp/snmpd.conf: Permission denied
/config/snmp/snmpd.conf: Permission denied

Environment

  • SNMP
  • After upgrade

Cause

Unknown at the time of publication

Recommended Actions

Run to following commands from CLI to reset the security context of the SNMP config file:

# restorecon -rF /config/snmp/snmpd.conf
# bigstart restart snmpd

None
