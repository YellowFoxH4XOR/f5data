Description

Analytics profile is not logging traffic to remote destinations

Environment

Relevant environmental factors specific to the topic

  • BIG-IP Analytics (AVR)
  • HTTP Analytics Profile

Cause

AVR has been provisioned to Minimum

Recommended Actions

Provision AVR from Minimal to Nominal

Impact of procedure: F5 recommends that you perform this procedure during a maintenance window. Reprovisioning involves restarting system processes and rebooting. These actions interrupt traffic. Additionally, when the BIG-IP system is in a device group, it fails over to the next available member.

  1. Log in to the Configuration utility.
  2. Go to System > Resource Provisioning.
  3. In the Provisioning column, select the check box for each licensed module and select either Minimum or Nominal.

    Note: For BIG-IP versions prior to 11.3.0, select Minimum or Nominal for each licensed module.

  4. Select Submit.

    Note: For BIG-IP versions prior to 11.3.0, select Update.

  5. The system warns you about the reprovisioning impact. Select OK to proceed.
  6. After you make the necessary provisioning changes, go to System > Configuration > Device.
  7. To restart the system, for Operations, select Reboot.
  8. When prompted, select OK to confirm restart.
