This article applies to BIG-IP 11.x - 21.x. For information about other versions, refer to the following article:

  • K8436: Overview of UNIX configuration files (9.x - 10.x)

Additionally, this article covers third-party configuration files that are included in the BIG-IP system. For information about BIG-IP native configuration files, which are produced by F5, refer to the following article:

  • K26582310: Overview of BIG-IP configuration files

You can configure most UNIX daemons on the BIG-IP system using the Configuration utility. However, there are occasions when you may need to add a custom configuration or change the functionality of a daemon beyond what is possible using the Configuration utility. You can configure many daemons on the BIG-IP system using the TMOS Shell (tmsh) command, and the system saves changes to the daemons to the appropriate system file.

You can perform custom UNIX configurations on the BIG-IP system using tmsh, and the system saves the changes you make to the daemons to the appropriate system file. With the SCF feature, most UNIX-based files on the BIG-IP system are considered template files, and you do not directly edit them. Instead, when you add a custom UNIX configuration to the BIG-IP system, you must use the corresponding tmsh command. Use a tmsh command to add custom UNIX configurations to the BIG-IP system and use the tmsh save sys config command to save the custom UNIX configurations to the BIG-IP system file and to the UNIX-based template file.

For example, to configure DNS nameservers on the BIG-IP system, use the tmsh /sys dns command followed by the tmsh save sys config command. The nameserver configuration is saved to the /var/run/config/resolv.conf UNIX configuration file and to the /config/bigip_base.conf BIG-IP system file.

Recommendations

When performing custom UNIX configurations, you should consider the following:

  • Use tmsh to modify most UNIX-based configuration on your BIG-IP system. If you edit UNIX-based files directly, the changes are lost when the system is restarted.
  • Certain BIG-IP system files are considered to be common in a device group setup and are synchronized during a configuration synchronization (ConfigSync) operation, and other BIG-IP system files are considered to be local to one system in a redundant setup and are not synchronized during a ConfigSync operation.
