Description

Legitimate requests from Googlebot and Bingbot may be incorrectly blocked by BIG-IP ASM Bot Defense, being classified as “Malicious Bot” or “Suspicious Browser.”

This behavior is typically the result of inaccurate or incomplete bot classification. There are multiple factors that can contribute to this issue. This article focuses on one specific scenario where other related scenarios mentioned in the Related Content section.

Environment

  • BIG-IP advanced WAF Bot-Defense
  • Bot Defense profile with:
    • Trusted Bots mitigation set to "None" 
    • Malicious Bots mitigation set to "Block"
  • DNS resolvers configured

Cause

In the Bot Profile Configuration > Bot Mitigation Settings: Mitigation Settings, Trusted Bots mitigation setting configured to "None". When set to "None", all signatures of this class are disabled and are not checked,  the system does not perform trusted bot classification, leading to legitimate search engine bots being misidentified as malicious or suspicious and subsequently blocked. 

Answer/Recommended Actions

Set the Trusted Bots mitigation setting in the Bot Defense profile to "Alarm" to ensure proper classification and allowlisting of legitimate search engine bots.
