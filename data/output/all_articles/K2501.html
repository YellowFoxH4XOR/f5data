Issue

You may receive the following error after running the 3dpipe command:

User exception `ITCMCommon::InvalidUser'

You can receive this error if the remote access information for the current user is missing or incomplete.

You can test 3dpipe using a Web Configuration utility account that you know is working properly, by typing the following command:

3dpipe -u <username>:<password>@<IP address> <3dpipe command>

For example:

3dpipe -u admin:admin@172.16.102.50 stats summary

If this does not work, perform the following steps:

  1. From the command line, type the following command:

    config

  2. From the menu, select Remote Access.
  3. Enter the user data for the host name or IP address.
  4. Re-test 3dpipe against the loopback address.

    For example:

    3dpipe -u admin:admin@127.0.0.1 stats summary

  5. If this does not work, repeat steps 1 - 4.

This process should add the necessary remote access information for the BIG-IP host and loopback addresses and resolve the problem.
