Topic

You should consider using this procedure under the following condition:

  • You want to change the level of information of the log messages forwarded by the rsyslog utility to the VELOS system local log files.

Description

The VELOS system uses the rsyslog utility to support logging. The rsyslogd process runs in one container for the VELOS system controller and one container for each of the VELOS partition. The rsyslogd container for the VELOS system controller sends the log messages to the /var/log_controller/velos.log file while the rsyslogd container for a VELOS partition sends the log messages to the /var/F5/partition<ID>/log/velos.log file where <ID> is the partition-specific identification number.

Facilities

At the time of publication of this article, the VELOS system only supports the LOCAL0 logging facility. All of the containers and system component logs are directed to this facility.

Levels

The VELOS system supports the following severity levels as described in the table. By default, most components have their log levels set at INFORMATIONAL.

ValueSeverityDescription
0EMERGENCYSystem is unusable. Note that this level is not used for errors at the individual components.
1ALERTSerious errors that need to be corrected immediately. For example, no network connectivity.
2CRITICALCritical errors such as non-recoverable failures in the system’s main components.
3ERRORErrors that could cause major problems. For example, storage has exhausted its resource.
4WARNINGIndicates that an error will occur if no action is taken. For example, storage is low on resource.
5NOTICEEvents that are unusual but not error prone. For example, a component restarted unexpectedly.
6INFORMATIONALNormal operational messages that require no action. For example, a component has started, paused or ended successfully.
7DEBUGMessages useful for debugging purposes. For example, debug data for Digital Diagnostics Monitoring.

Log rotation

By default, the log files are rotated based on size. Depending on the log file, some log files are rotated when their file size exceeds 100 MB while others are rotated when their file size exceeds 1 GB. There is no user interface for configuring log rotation. You must perform configuration change in the logrotate configuration file of the respective rsyslogd container. The logrotate configuration has been optimized for most use cases. F5 does not recommend customers modify the logrotate configuration.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • To perform the procedures on a system controller, you should have chassis administrator access to either the webUI or the CLI of the chassis floating management IP address. Likewise, to perform the procedures on a partition, you should have partition administrator access to either the webUI or the CLI of the partition's floating management IP address.

Procedures

  • Display the level of information logged for a component
  • Configure the level of information logged for a component

Display the level of information logged for a component

Before you change the logging level for a component, you may want to determine its current level. The procedure to determine the log level for a component is the same for both system controller level and partition level. To do so, perform any of the following procedures:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • webUI
  • CLI

webUI

  1. To perform this procedure at the system controller level, log in to the webUI of the VELOS chassis as the chassis administrator. To perform this procedure at the partition level, log in to the webUI of the partition as the partition administrator.
  2. Go to SYSTEM SETTINGS > Log Settings. The log level for each component displays under the Software Component Log Levels section.

CLI

  1. To perform this procedure at the system controller level, log in to the CLI of the floating management IP address as the chassis administrator. To perform this procedure at the partition level, log in to the CLI of the partition’s floating management IP address as the partition administrator.
  2. List the logging level for a component using the following command syntax:

    show running-config system logging sw-components sw-component <component name>

    Note: You can use the tab key to list the available components after the sw-component command option.

    For example, to list the logging level for the Alert service (alert-service) component, enter the following command:

    show running-config system logging sw-components sw-component alert-service

    The command output appears similar to the following example, with the logging level listed as INFORMATIONAL:

    system logging sw-components sw-component alert-service
     config name alert-service
     config description "Alert service"
     config severity INFORMATIONAL
    !

Configure the level of information logged for a component

To configure the logging level for a component, perform any of the following procedures:

Impact of procedure: Performing the following procedure should not have a negative impact on your system. However, F5 recommends using the default logging level values. Increasing the verbosity increases the amount of information logged, but may also increase system resource utilization. Decreasing the verbosity reduces the amount of information logged, but may make troubleshooting issues more difficult as the necessary diagnostic information may not be logged.

  • webUI
  • CLI

webUI

  1. To perform this procedure at the system controller level, log in to the webUI of the VELOS chassis as the chassis administrator. To perform this procedure at the partition level, log in to the webUI of the partition as the partition administrator.
  2. Go to SYSTEM SETTINGS > Log Settings.
  3. Under the Software Component Log Levels section, select the log level desired for the component you want to change. For example, select DEBUG under alert-service if you want to change the alert-service log level to debug.
  4. To save the change, select Save.

CLI

  1. To perform this procedure at the system controller level, log in to the CLI of the floating management IP address as the chassis administrator. To perform this procedure at the partition level, log in to the CLI of the partition’s floating management IP address as the partition administrator.
  2. Enter the configuration mode terminal by entering the following command:

    config

  3. Modify the logging level for a component using the following command syntax:

    system logging sw-components sw-component <component name> config severity <log levels>

    Note: To list the available components, you can enter the command system logging sw-components sw-component.

    For example, to set the log level of alert-service to DEBUG, enter the following command:

    system logging sw-components sw-component alert-service config severity DEBUG

  4. Save the change by entering the following command:

    commit

  5. Exit the configuration mode terminal by entering the following command twice:

    exit
