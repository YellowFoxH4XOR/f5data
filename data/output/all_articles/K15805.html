Known Issue

Secure network address translation (SNAT) still occurs after all Virtual Local Area Networks (VLANs) are removed from the Enabled on setting VLAN/Tunnel list.

This issue occurs when all of the following conditions are met:

  • A new SNAT object is created, and the Enabled on setting is used to target a specific VLAN.
  • The BIG-IP system successfully creates new connections using the SNAT object on the chosen VLAN.
  • All VLANs are removed from the SNAT object's Enabled on setting VLAN/Tunnel list.
  • The BIG-IP system still uses the SNAT object to modify egress traffic with an empty Enabled on setting VLAN/Tunnel list.

Impact

Traffic is still translated after all VLANs are removed from the Enabled on setting VLAN/Tunnel list.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You notice that a SNAT object has an empty Enabled on setting VLAN/Tunnel list.
  • The BIG-IP system uses the SNAT object to modify egress traffic.

Workaround

To work around this issue, you can disable the list of VLANs using the SNAT object's Disabled on setting.
