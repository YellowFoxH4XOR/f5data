Issue

Old Behavior

In BIG-IP 14.0.0 and earlier, the dig utility does not send a DNS cookie by default.

DNS cookies are a security feature implemented as an EDNS option. The technology is defined in Internet Engineering Task Force RFC 7873.

Note: This link takes you to a resource outside of AskF5. The third party could remove the document without our knowledge.

New Behavior

Beginning in BIG-IP 14.1.0, the dig utility now sends a DNS cookie by default.

This change in behavior is due to BIG-IP using version 9.11.4-P1 of bind-utils, a third-party package.

Impact

Performing a basic DNS lookup with the utility in BIG-IP 14.1.0 may result in a FORMERR response from the DNS server and no answer.

For example, running the dig www.example.com command results in the following response:

; <<>> DiG 9.11.4-P1 <<>> www.example.com
;; global options: +cmd
;; Got answer:
;; ->>HEADER<<- opcode: QUERY, status: FORMERR, id: 43174
;; flags: qr rd; QUERY: 1, ANSWER: 0, AUTHORITY: 0, ADDITIONAL: 1
;; WARNING: recursion requested but not available

;; OPT PSEUDOSECTION:
; EDNS: version: 0, flags:; udp: 4096
; COOKIE: b3f2499da7cb77dd (echoed)
;; QUESTION SECTION:
;www.example.com. IN A

;; Query time: 1 msec
;; SERVER: 172.24.1.241#53(172.24.1.241)
;; WHEN: Wed Dec 12 14:59:49 PST 2018
;; MSG SIZE rcvd: 56

Recommended Actions

To prevent the dig utility from sending a DNS cookie, you can include the +nocookie query option to the command string. For example:

Impact of action: The DNS transaction is not protected by the DNS cookie security mechanism.

dig +nocookie www.example.com

Alternatively, you can include the query option in a ~/.digrc file you create. The contents of the file need only to contain +nocookie. For example:

Impact of action: The DNS transaction is not protected by the DNS cookie security mechanism.

# cat ~/.digrc
+nocookie

You can then run the command without including that option. For example:

dig www.example.com

; <<>> DiG 9.11.4-P1 <<>> www.example.com
;; global options: +cmd
;; Got answer:
;; ->>HEADER<<- opcode: QUERY, status: NOERROR, id: 5927
;; flags: qr rd ra; QUERY: 1, ANSWER: 1, AUTHORITY: 0, ADDITIONAL: 1

;; OPT PSEUDOSECTION:
; EDNS: version: 0, flags:; udp: 4000
;; QUESTION SECTION:
;www.example.com.               IN      A

;; ANSWER SECTION:
www.example.com.        66050   IN      A       93.184.216.34

;; Query time: 1 msec
;; SERVER: 172.24.1.241#53(172.24.1.241)
;; WHEN: Wed Dec 12 15:31:02 PST 2018
;; MSG SIZE  rcvd: 60

To send a cookie, add +cookie to the command string, which overrides the ~/.digrc file. For example:

dig +cookie www.example.com
