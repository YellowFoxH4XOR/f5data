K000134976: Application may show a 609 code after enabling Page Load Time

Type
Support Solution
Published
2023-06-08
Updated
2023-06-08
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000134976

Description

 You may have a 609 code on your application when using an AVR profile with Page Load Time enabled.


Environment

BIGIP LTM

BIGIP AVR


Cause

The CSPM script injection happens in odd location when HTTP responses are chunked.


Recommended Actions

You can inject CSPM script after head:


#tmsh modify sys db avr.cspm.inject.location { value after_head }


Additional Information

K13849: Overview of BIG-IP Analytics CSPM injection
