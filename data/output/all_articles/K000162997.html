Description

When attempting to load the APM Visual Policy Editor (VPE), the following error message is displayed:

"Unable to load accessPolicy '/Common/<access-policy-name>' from source. 
Unable to load accessPolicy '/Common/<access-policy-name>-<agent-name>' from source. 
Branch rule expression must start with
'expr {. Invalid expression: 'Expression: expr { <TCL_expression> } contains'
Loading is stopped, please refresh."

Environment

  • BIG-IP APM
  • Visual Policy Editor (VPE)

Cause

Following the implementation of ID1710805, a change in behavior has been introduced. This change in behavior has  been later reverted and tracked under 2448441.

Recommended Actions

You can either upgrade to a version where ID2448441 is fixed, or follow the workaround below:

Since the VPE is inaccessible, it is not possible to modify the affected expression within the policy editor. Please proceed with the steps below:

1. Log in to the BIG-IP CLI
2. From the /config directory, make a back up the configuration file using the following command:

cp bigip.conf bigip.conf.K000162997

3. Edit the configuration file using a text editor of your choice.
4. Locate the referenced policy item block and prefix TCL expressions with "expr". The corrected expression entry should appear as:

expression "expr { <TCL_expression> }"

5. Save the file and quit the text editor.
6. Load the configuration:
7. Now, confirm the affected policy opens in the VPE.
