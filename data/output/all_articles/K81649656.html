Topic

Beginning in BIG-IP 13.1.0, BIG-IP APM administrators can update the VPN software version on the BIG-IP system without needing to upgrade the entire BIG-IP system. You can download the APM Clients software package from the F5 Downloads, upload the ISO image to the BIG-IP system, and perform the installation. For more information on the procedure to do so, refer to K52547540: Updating BIG-IP Edge Client for the BIG-IP APM system

Description

This section provides guidance on the following tasks as you update your APM Clients:

  • Select an APM Clients version to upgrade to
  • Verify the APM Clients version and BIG-IP system upgrade or update
  • Update the APM Client VPN software on client and BIG-IP APM server side

Select an APM Clients version to update to

The BIG-IP APM system is shipped with a specific APM Clients version. For more information on the APM Clients version that is shipped with your BIG-IP version, refer to K13757: BIG-IP Edge Client version matrix. 

You can update the APM Clients within the same major version or later. Refer to the following table for some examples.

APM Clients version before upgrade
(examples)		Supported target version
7.2.17.2.1.1 or later
7.1.9.77.1.9.8, 7.2.1.1 or later
7.1.8.17.1.8.5, 7.1.9.8, 7.2.1.1 or later

Downgrading the APM Clients version software is not supported. When you do so, the BIG-IP system may not trigger the automatic Component Update on client side systems.

Verify the APM Clients version and BIG-IP system upgrade or update

When you upgrade or update the BIG-IP system, the version of the APM Clients ISO file that is shipped with the BIG-IP software ISO file automatically becomes the active APM Clients version. You should therefore verify the active APM Clients version after a BIG-IP software upgrade and update your APM Clients version as appropriate.

For example, when you upgrade a system running BIG-IP 15.1.1 with APM Clients 7.2.1 active to BIG-IP 15.1.2, the active APM Clients version after the upgrade automatically becomes 7.1.8.4, the version that is shipped with BIG-IP 15.1.2. In this case, you must update to APM Clients 7.2.1 or a later version. Updating to APM clients 7.1.8.5 or 7.1.9.8 when your original APM Clients version is 7.2.1 is a downgrade and not supported.

Before you upgrade or update the BIG-IP system, note the APM Clients version on the system. You can do so by going to System > Software Management > APM Clients on the Configuration utility. After upgrading or updating the BIG-IP system, verify the APM Clients version. 

Update the APM Client VPN software on client and BIG-IP APM server side

The APM Clients software package contains VPN software code and fixes for both the BIG-IP APM system and all VPN users’ client-side systems. After updating APM Clients on the BIG-IP system, you should update the client-side systems as well. You can do so by performing one of the following procedures:

Note: In a high-availability (HA) environment, you must update each BIG-IP system with the new client version. In a multi-blade cluster environment on a chassis system, the system automatically replicates the update to each blade.
  • Configure Component Update in the connectivity profile of the virtual server
  • Deploy and install the required VPN software packages on VPN users’ client systems

Configure Component Update in the connectivity profile of the virtual server

When a VPN user initializes a BIG-IP APM access session to start a VPN session, the BIG-IP APM system can check the software version of the VPN Components on the client system and automatically updates the components based on the BIG-IP Edge Client application version and required components of the connectivity profile. For more information on this behavior, refer to K15302: Understanding BIG-IP Edge Client Component Update behavior for Windows, macOS, and Linux CLI.

To do so, you must configure the Component Update setting as follows:

Note: The automatic update behavior does not apply to the Linux Client f5fpc client. For browsers, browser VPN helper components are updated regardless of the Component Update setting. Similar to browsers, components like Windows ActiveX, Host Control, InspectionHost, Machine Certificate Checker, and SuperHost, are updated automatically regardless of the Component Update setting.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Access > Connectivity / VPN.

    Note: For BIG-IP 12.x and earlier, go to Access Policy > Secure Connectivity.

  3. Select the connectivity profile that is associated to your network access virtual server.
  4. Select Edit Profile.
  5. Select Win/Mac Edge Client.
  6. For Component Update, select Yes.
  7. Select OK.

Deploy and install the required VPN software packages on VPN users’ client system

You can also download the required VPN software packages from the BIG-IP system and deploy and install the required VPN software packages on VPN users’ client systems. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Download the BIG-IP Edge Client package from the BIG-IP APM system by completing the following steps:

  1. Log in to the Configuration utility.
  2. Go to Access > Connectivity / VPN > Connectivity > Profiles.

    Note: For BIG-IP 12.x and earlier, go to Access Policy > Secure Connectivity.

  3. Select the name of the connectivity profile associated with the network access virtual server.
  4. Select the arrow next to Customize Package.
  5. Select the appropriate operating system.
  6. For Windows: Select the components that you require. For example, if you want to update VPN Helper Applications for browsers, ensure that the Web Browser Add-ons for BIG-IP Edge Client check box is selected.
  7. For Windows: Select any other components you require.
  8. Select Download.

After you perform the procedure, distribute and install the BIG-IP Edge Client package on every users' client machines. For example, you can do so through the Windows Group policy, or K05816648: Enabling end user access to download the BIG-IP Edge Client for BIG-IP APM.
