Policy Information

iRules LX is a feature that allows for programmatic logic to extend the capabilities of BIG-IP TMOS using JavaScript in the Node.js runtime environment.

Node.js versions

The Node.js versions for the BIG-IP system include the following:

BIG-IPNode.js
13.1.0 - 17.5.00.12.15
6.9.1
12.1.2 - 13.0.00.12.15
12.1.0 - 12.1.10.12.9

Node.js API support

F5 provides an API for using Node.js with the f5-nodejs module located in the node_modules folder in each extension folder. F5 recommends that you use only this method Node.js in iRules LX. Using Node.js outside of the provided API may lead to major performance degradations, such as binding ports on the management plane with the net.Server module.

Important: F5 does not provide support for iRules LX Node.js outside of the F5-provided API.

Data transfer limitations

The ILX::call and ILX::notify Tcl commands make RPC to Node.js have a limitation of 64 KB of total data that can be sent or received. This includes a small amount of overhead for packaging the data that can range depending on the complexity of the RPC call. Allowing 500 to 1 KB of margin on the RPC should grant enough margin for the RPC call overhead.

File access

The Node.js instances of iRules LX allow for access to the file system. However, F5 recommends that you refrain from using file system read/writes for the following reasons:

  • Excessive file system I/O to disk may lead to performance degradation of the whole BIG-IP system.
  • Most directories on the BIG-IP system are not preserved for system upgrades and restoration from a UCS.
  • Directories are not synced across DSC clusters.
