Description

vCMP hosts will show memory allocated to guests as in use, even if the guest isn't making use of those resources. If the host system has enough guests provisioned, this can cause the system to show limited or no free memory resources, even though the actual hardware resources aren't taxed by the guests.

Environment

  • vCMP Host
  • Memory Usage Alerts
  • High Memory Usage

Cause

Memory allocated to guests is unavailable for other purposes, meaning that it will be counted as in use. However, unless the guest itself is encountering memory exhaustion the actual hardware resources aren't being overtaxed.  This is expected behavior, and is no cause for alarm.

Recommended Actions

  1. Monitor memory usage in the vCMP guests more closely than the vCMP host. While the host will show all available memory allocated to a guest as in use, the guest itself may be holding much of that memory as idle
  2. Evaluate whether vCMP instances can be scaled down to reclaim resources for other guests, or if guests need more memory resources to handle the relevant load.
