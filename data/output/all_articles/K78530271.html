K78530271: F5 DNS Cloud Service - ERROR ''Failed to get zone file: DNS server xx.xx.xx.xx is unreachable.'' when attempting initial configuration or zone transfer

Type
Support Solution
Published
2019-10-30
Updated
2023-02-21
Applies to
  • F5 Cloud Services
  • F5 DNS Cloud Service
Source
https://my.f5.com/manage/s/article/K78530271

Description

  • Setting up F5 DNS Cloud Service.  When attempting to deploy a new zone, the following error is returned:
    • Failed to get zone file: DNS server xx.xx.xx.xx is unreachable.
  • Zone transfer unsuccessful and initial deployment unsuccessful.

Environment

  • F5 DNS Cloud Service 
  • Using F5 DNS Cloud Service as a Secondary Name Service
  • Customer is using their own Primary DNS Server/Service
  • Zone Transfer from Primary name server(s) to F5 Cloud Bases Secondary DNS

Cause

  • The IP address for the primary DNS server is incorrect
  • The primary DNS server needs a TSIG for zone transfers, and the TSIG is either missing or incorrect.
  • An access control list (ACL) for the network or on the primary DNS server prevents the DNS Cloud Service from communicating with the primary DNS server.
  • Zone transfers are disabled on the primary DNS server.
  • A firewall is preventing communications

Recommended Actions

  1. Verify ACL rules UDP and TCP port 53 to F5 DNS Cloud Service IPs. ( https://clouddocs.f5.com/cloud-services/latest/f5-cloud-services-GS-DNS.html#configure-the-dns-cloud-service)
  2. Verify Primary DNS has all the F5 DNS Cloud Service Whitelist IPs set up to allow for a Zone Transfers (AXFR).
  3. Verify the TSIG key, if used, is provided.

Additional Information

Setup procedures documented at https://clouddocs.f5.com/cloud-services/latest/f5-cloud-services-GS-DNS.html
