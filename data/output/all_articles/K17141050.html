Description

If your BIG-IP system is licensed for the ZebOS set of advanced routing modules (ARM), you must enable the appropriate routing protocol before you can use the ZebOS VTY shell to add entries into the ZebOS.conf file. 

When the F5 is configured with the Zebos or dynamic routing, you need to delete the dynamic routing configuration as seen on the example below:

Example:
# delete net routing all route-domain 0
# modify net route-domain 0 routing-protocol delete { OSPFv2 }

After running the above commands if you enter imish shell you will encounter the error below:

Example:
# run util imish
% Can't set FD_CLOEXEC to IMI socket: Bad file descriptor
 

Environment

  • BIG-IP LTM 
  • ARM Licensed 
  • Device in online state
  • Dynamic Routing Configured

Cause

Many services has not been started in sync

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Reboot the device
Note : This will disrupt the production environment so plan in maintenance window

Additional Information


1. There will be no config in Zebos after removing the config. Below is the example for the logs from qkview 

Example:   
zebos -a cmd show running-config === route domain: 0 ===
zebos -a cmd show ip ospf === route domain: 0 ===
zebos -a check === route domain: 0 ===

2. Services are not in sync as per below
  
Example:
#tmipsecd run (pid 16601) 229 days, 1 start
#tmm run (pid 16603) 229 days, 1 start
#tmrouted run (pid 6354) 229 days
