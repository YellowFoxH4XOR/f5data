Topic

This Solution details setting up an example landing Uniform Resource Identifier (URI) and creating a pre-logon sequence to confirm that the user is accessing the FirePass controller with the correct URI, which is the link that users insert into their browser to access the logon page for the FirePass Controller. To set up a landing URI and create a pre-logon sequence, perform the following procedures:

Note: The following procedures are only examples to serve as a guide for creating a pre-logon sequence.

  • Creating a landing URI
  • Creating a master group
  • Associating the landing URI with the master group
  • Adding a resource group to the master group
  • Creating a test user in the master group
  • Creating a pre-logon sequence to check for the landing URI
  • Activating the pre-logon sequence check

Creating a landing URI  

You must first create the URI that you want your users to apply, which is the extension after the fully qualified domain name in the URL.

For this example, the URL is https://example.com/monkeys

  1. Log in to the FirePass Administrative Console.
  2. Click on the Customization link.
  3. Click on the URI-based Customization tab.
  4. Enter the name of the landing URI in the Create Landing URI field.

    For example:

    Monkeys  

    Note    : The name you create in this Step will be the name in the URI that users apply to access the logon page.
  5. Leave the default value of Form-Based Authentication selected.
  6. Click the Apply button.

    The next page will allow you to configure the look of the landing URI. If you want to change the appearance of the landing page, make the appropriate changes from this page.


Creating a master group

To create a specific master group for this landing URI, perform the following procedure:

  1. From the Administrative Console, click on the Users link.
  2. Click on the Groups link.
  3. Click on the Master Groups link that appears under Groups.
  4. Click the Create new group button.
  5. In the New group name field, enter the name of your master group.

    For example:

    landuri-monkey

    For this example, leave the other values at their default setting. If you are creating your own master group, use the values that are approriate for your environment.
  6. Click the Create button.


Associating the landing URI with the master group

To associate the master group with the landing URI, you must configure the FirePass controller to allow access. To do so, perform the following procedure:

  1. From the Administrative Console, click on the Users link.
  2. Click on the Groups link.
  3. Click on the Master Groups link that appears under Groups.
  4. Click on the master group that you want to configure under Group Name.

    For example:

    landuri-monkey
  5. On the General tab under Landing URI, select your landing URI from the Access allowed from drop-down menu.
  6. Click the Update button.


Adding a resource group to the master group

You must tell the FirePass controller what the user can access once they have logged in successfully, by adding a resource group to the master group. To do so, perform the following procedure:

  1. From the Administrative Console, click on the Users link.
  2. Click on the Groups link.
  3. Click on the Master Groups link that appears under Groups.
  4. Click on the master group that you want to configure under Group Name.

    For example:

    landuri-monkey
  5. Click on the Resource Groups tab.
  6. Select the resource group that you want the user to access in the Available box.
  7. Click the Add button to move the selected resource group to the Selected box.
  8. Click the Update button.


Creating a test user in the master group

For testing purposes, you may create an individual user to add to the master group. To do so, perform the following procedure:

  1. From the Administrative Console, click on the Users link.
  2. Under User Management, next to the Create users accounts by option, select Individual entry from the drop-down menu.
  3. Click the Go button.
  4. Populate the applicable fields under New User.
  5. Select the master group you created under Master Group on the right-side panel.
  6. Click the Add User button.


Creating a pre-logon sequence to check for the landing URI

You must create a rule that confirms the landing URI is the same landing URI you created in the Creating a landing URI procedure. To do so, perform the following procedure:

  1. From the Administrative Console, click on the Users link.
  2. Click on the Endpoint Security link.
  3. Click on the Pre-logon Sequence link that appears under the Endpoint Security link.
  4. Under the New Sequence section, populate the Create new sequence field with the name you want to call this inspector.

    For example:

    landing-uri
  5. Select template: Empty from the Based on drop-down menu.
  6. Click on the Create button.
  7. Select landing-uri under the Select Sequence to Use section.
  8. Click the edit link next to landing-uri.
  9. Click on the ( + ) sign between the Sequence Start and Logon Allowed Page boxes.
  10. On the right hand panel, select New Action from the Using drop-down menu.
  11. Click Apply Changes.
  12. Under the Action detail section, put Check URI in the Name box.
  13. Put Confirm User's URI in the Description box.
  14. Click the Update details button.
  15. Click on the ( + ) sign that appears between the Check URI box and the fallback action.
  16. Under the Update Rule section on the right-hand panel, name the rule check session var.
  17. In the next box, add the variable that you want to check for.

    For example:

    session.network.server.land_uri=="monkeys"
  18. Click the Update button.
  19. Click on the downward arrow in the Logon Denied Page to switch places with the Logon Allowed Page box.
  20. Click on the Back to Console link in the upper right-hand corner to exit rule editing.


Activating the pre-logon sequence

You must activate the rule in order for it to take affect. To do so, perform the following procedure:

  1. From the Administrative Console, click on the Users link.
  2. Click on the Endpoint Security link.
  3. Click on the pre-logon sequence link that appears under the Endpoint Security link.
  4. Select landing-uri under the Select Sequence to Use section.
  5. Click the Apply button.

You can now apply the newly created user to confirm that you can log in with the correct URI. You will receive a logon denied page if you use a different URI.
