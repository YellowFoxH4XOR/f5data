Issue

Error Message

java.net.ProtocolException: Bad Set-Cookie header:<cookie name> path=/; Httponly No '=' found for token starting at position <token position>

In this error message, note the following:

  • <cookie name> is the name of the cookie header.
  • <token position> is position of the cookie token and attribute that could not be parsed.

For example:

java.net.ProtocolException: Bad Set-Cookie header: Production-Pool-11gR2-pool=3506573484.16415.0000; path=/; Httponly No '=' found for token starting at position 13

Message Location

You may encounter this message in the following locations:

  • The browser that is accessing the resource through the BIG-IP system.

Description

This message occurs when all of the following conditions are met:

  • You attempt to access a virtual server with cookie persistence enabled.
  • The pool member's Java implementation does not support the HTTPOnly attribute.

The HttpOnly attribute is defined in RFC 6265, but some customer implementations may not support this attribute. Starting in BIG-IP 12.0.0, BIG-IP cookie persistence profiles have the HttpOnly option enabled by default, as it is generally more secure. This error may result when the BIG-IP profile has this attribute enabled but the Java implementation on the pool member does not.

Note: This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

Impact

The Java error displays in the browser and you cannot access the requested resource.

Recommended Actions

  • Edit the cookie persistence profile and set the HTTPOnly Attribute to Disabled.
