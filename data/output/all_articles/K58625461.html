Description

Whenever you use OID iso.3.6.1.2.1.1.2, you get this value 'enterprises.3375.2.1.3.4.1000', which is incorrect.
In 12600 devices, the correct value should be 'enterprises.3375.2.1.3.4.104'.
This is caused because the platform name is missing.

tmsh show /sys hardware

Platform
  Name           none  <<=============== Mising!!!!!!!!!!!!!!!!
  BIOS Revision  OBJ-0614-xx BIOS: 2.04.228.0 ME: 3.0.3.27 03/30/2017
  Base MAC       0:94:a1:2a:ce:80

System Information
  Type                       C117
  Chassis Serial             f5-xxxx-yyyy
  Level 200/400 Part         203-0393-05 REV F
  Switchboard Serial         none
  Switchboard Part Revision  none
  Host Board Serial          pca0000g00fy
  Host Board Part Revision   none

Environment

This is present in newer i2600 devices, and some others of the 'i' family.

Cause

This is caused because of newer revision numbers in some BIG-IPs.
Some newer i2600 devices, and others, come with a revision number that is missing in the /etc/hal/MARKETING-NAMES.

Recommended Actions

To fix this condition you'll need to add the missing string in /etc/hal/MARKETING-NAMES.

  1. Look for the missing string.
    tmsh show /sys hardware

    Platform
      Name           none
      BIOS Revision  OBJ-0614-xx BIOS: 2.04.228.0 ME: 3.0.3.27 03/30/2017
      Base MAC       0:94:a1:2a:ce:80

    System Information
      Type                       C117
      Chassis Serial             f5-xxxx-yyyy
      Level 200/400 Part         203-0393-05 REV F  <<==== Copy this line
      Switchboard Serial         none
      Switchboard Part Revision  none
      Host Board Serial          pca0000g00fy
      Host Board Part Revision   none

  2. Backup the MARKETING-NAMES file.
    cp /etc/hal/MARKETING-NAMES /etc/hal/MARKETING-NAMES.bak

  3. Add the missing line
    vi /etc/hal/MARKETING-NAMES

  4. Press in your keyboard.
    Shift+G  <<== Takes you to the end of the file
    Shift+o  <<== Enters into 'Insert' mode and add a new line at the bottom

  5. Copy/paste or type this string.
    BIG-IP i2000=203-0393-05

  6. Press in your keyboard.
    ESC   <<== Exits 'Insert' mode
    :wq!  <<== Save and exit (forced mode)

  7. Restart the chmand daemon.
    bigstart restart chmand

  8. Run these snmpwalk commands:
    snmpwalk -Os -c public -v 2c localhost iso.3.6.1.2.1.1.2
    snmpwalk -Os -c public -v 2c localhost 1.3.6.1.4.1.3375.2.1.3.5.2

  9. If only one of the OIDs brings the correct value, reboot the BIG-IP.
    reboot
