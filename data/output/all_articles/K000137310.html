K000137310: How to transfer local logs of a BIG-IP system to a remote syslog server

Published

Updated

Applies to

Source

Description:

This section describes how to transfer local logs of a BIG-IP system to a remote syslog server

Environment:

  • BIG-IP
  • remote syslog is used

Cause:

Some log files on BIG-IP system are not generated by syslog_pipe, but write to the linux file system directly.
So that kind of logs will not be transfered to the remote syslog servers with the common remote logging settings.

Recommended Actions:

Add the following source and log sections into the include option of syslog:

sys syslog {
    include "
    source s_<log_file_name> {
        file(/var/log/<log_file_name> follow-freq(1));
    };
    destination d_remote_loghost {
        udp(\"<syslog_server_address>\" port(514));
    };
    ...
    log {
        source(s_<log_file_name>);
        destination(d_remote_loghost);
    };”

These sections will read logs from local files and transfer to the remote syslog destination.
