K000150893: The Re-activate... button is missing on System -> License page of the Configuration utility of the F5OS Tenant

Support Solution

Description

The Reactivate button is missing from the System -> License page of the Configuration utility on the F5OS Tenant guest device. You are unable to reactivate the license for the Tenant guest in its configuration utility.

Environment

  • F5OS
  • Tenant Guest
  • Licensing

Cause

You are attempting to reactivate the license on an F5OS Tenant guest rather than the F5OS host. Tenant guests inherit the license from the F5OS host. The F5OS host license must include all BIG-IP modules that you plan to provision on Tenant guest instances.

Recommended Actions

  1. Navigate to the F5OS Host device.
  2. Go to the Licensing screen under SYSTEM SETTINGS to install or update the license.
  3. Ensure the host license includes all required BIG-IP modules to support Tenant guest instances.
