Description
Unexpected error when assigning a license from the FCP catalog license to an unmanaged BIG-IP device

Error on server request.
1. The system returned an unexpected error (400 Bad request). Error while assigning license to unmanaged device

This does not happen with “managed” devices

Procedure to reproduce issue:

  1. Log into BIG-IQ (Devices—License Management—Licenses)
  2. Click on the FCP Catalog “Name”
  3. Click on desired Offering name
  4. Click license devices button
  5. In Unit of measure select “Yearly”
  6. In “Unmanaged Devices” fill in IP, username and Password
  7. Click on assign
  8. “Confirm Assignment” Review and click on “OK”
  9. See error message below
     

Environment

  • BIG-IQ v8.X
  • FCP

Cause

F5 is tracking this as ID 1035093
This has been fixed in BIG-IQ v8.1.0.1 (Release Notes)

Recommended Actions

Update the BIG-IQ to v8.1.0.1
K51342220: Upgrading the BIG-IQ videos and procedures
