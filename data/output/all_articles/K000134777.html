K000134777: Error: "err sSMTP[xxxxx]: Unable to connect to "localhost" port 25" logged every 5 minutes in BIG-IQ mail log

Support Solution
Published
2023-05-25
Updated

Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0
Source
https://my.f5.com/manage/s/article/K000134777

Description

  • The following errors are logged every five minutes in the /var/tmp/maillog file:
          err sSMTP[14101]: Unable to connect to "localhost" port 25.
          err sSMTP[14101]: Cannot open localhost:25

Environment

  • BIG-IQ 8.2.0
  • CM

Cause

A cron job is run every 5 minutes for the ASM log rotate:

*/5 * * * * root nice -n 19 ionice -c 3 /usr/share/ts/bin/asm_logrotate
 

Recommended Actions

  1. This cron job is not needed in the BIG-IQ, to workaround this behavior the cron job needs to be disabled:
            Edit the /etc/cron.d/asm_logrotate.cron file in order to comment out (with a #) the following line:
                  
  • */5 * * * * root nice -n 19 ionice -c 3 /usr/share/ts/bin/asm_logrotate

           The line should now look like:
             
  • #*/5 * * * * root nice -n 19 ionice -c 3 /usr/share/ts/bin/asm_logrotate
 

Additional Information

Bug ID 1005029: Unneeded script on BIG-IQ generates error messages when run by cron.
