Known Issue

This is the result of a known issue. If the time zone configured on the FirePass controller uses Daylight Saving Time (DST), and you configured session timeouts on the Device Management: Security: Timeouts page, the following issues may occur at the end of DST (in the autumn) when the clock on the FirePass controller adjusts back one hour:

  • If the Global inactivity timeout or the Global reauthentication timeout is set to one hour or less, users and administrators cannot logon to the FirePass controller for one hour after the time change. Additionally, users and administrators with active sessions are logged out of the FirePass controller when the time changes.
     
  • If the Separate inactivity timeout or the Separate reauthentication timeout is set to one hour or less for a Master Group, users in that Master Group cannot logon to the FirePass controller for one hour after the time change. Additionally, users in that Master Group with active sessions are logged out of the FirePass controller when the time changes.

Note: You can configure the time zone on the Device Management: Configuration: Time page.

F5 Product Development tracked this issue as CR88358 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

This issue still exists in the FirePass version 5.x branch.

Additionally, cumulative hotfix HF-552-12 has been issued for FirePass version 5.5.2, cumulative hotfix HF-601-12 has been issued for FirePass version 6.0.1, and cumulative hotfix HF-602-6 has been issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by performing the following procedure prior to the end of DST:

  1. Log in to the FirePass Administrative Console.
     
  2. Navigate to the Device Management: Security: Timeouts page.
     
  3. In the Global inactivity timeout drop-down menu, select 2 hours or a longer timeout value.

    Note: The Global inactivity timeout drop-down menu is named Default inactivity timeout in FirePass versions 5.0 through 5.2.1.

  4. In the Global reauthentication timeout drop-down menu, select 2 hours or a longer timeout value.

    Note: The Global reauthentication timeout drop-down menu is named Default reauthentication timeout in FirePass versions 5.0 through 5.2.1.

  5. In the For the group: drop-down menu, select the Master Group you want to configure.
     
  6. In the Separate inactivity timeout drop-down menu, select 2 hours or a longer timeout value.
     
  7. In the Separate reauthentication timeout drop-down menu, select 2 hours or a longer timeout value.

Repeat Steps 5 through 7 for each Master Group.
