Known Issue

The BIG-IP system reports incorrect configuration synchronization (ConfigSync) status in a high availability (HA) pair.

This issue occurs when all of the following conditions are met:

  • You configured your BIG-IP system to perform incremental synchronization for a device group
  • Configuration validation fails during a ConfigSync operation with multiple transactions.
  • A subsequent—or the final—configuration transaction is successful within the same ConfigSync operation.

Impact

The BIG-IP system incorrectly reports that the configuration is In Sync, even when the devices have different configurations. As a result, your BIG-IP system may fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The configurations between the members of the affected device group are not consistent, but the BIG-IP system reports that the group are In Sync.
  • Your BIG-IP system may unexpectedly disrupt traffic.

Workaround

To work around this issue, disable the incremental synchronization for the affected device group, and then perform a ConfigSync. To do so, perform the following procedure:

Impact of workaround: The BIG-IP system may experience a performance impact when ConfigSync performs a full configuration synchronization of a large configuration.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Disable incremental synchronization by typing the following command:

    modify cm device-group <device_group_name> full-load-on-sync true

    For example, you type the following syntax:

    modify cm device-group my_devicegroup full-load-on-sync true

  3. Save the change by typing the following command:

    save /sys config

Subsequent ConfigSync operations will perform a full configuration synchronization.

You can re-enable incremental synchronization for the device group when your systems are in sync. To do so, perform the following procedure:

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Enable incremental synchronization by using the following command:

    modify cm device-group <device_group_name> full-load-on-sync false

    For example, you type the following syntax:

    modify cm device-group my_devicegroup full-load-on-sync false

  3. Save the change by typing the following command:

    save /sys config

Subsequent ConfigSync operations perform an incremental configuration synchronization.
