Description

Changing Session Variables to all lower case in APM Visual Policy Editor (VPE)

Environment

  • BIG-IP APM 
  • Session Variables
  • Visual Policy Editor (VPE)

Cause

When users enter session data into a policy, it is case sensitive and may need to be in lower case and not mixed case for proper session usage.

Recommended Actions

Following example is converting session.logon.last.username to all lower case:

  1. Open the visual policy editor by clicking Edit to the right of the Access Profile name.
    Click the plus sign ( + ) to the right of the Logon Page box.
  2. Select the Assignment tab
    Click Variable Assign 
    Click Add Item
    Click Add new entry
  3. For the newly created empty assignment, click Change
  4. Leave the Custom Variable menu selection at the default setting of Unsecure
  5. In the Custom Variable box, type the following: session.logon.last.logonname
  6. In the Custom Expression box, type the following: string tolower [mcget {session.logon.last.username}]
  7. Click Finished
  8. Click Finished
    Click Save
  9. Click Apply Access Policy in the upper-left corner of the visual policy editor
