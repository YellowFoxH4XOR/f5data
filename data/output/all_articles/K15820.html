Known Issue

Filtering by security policy in the BIG-IP ASM charts page may not affect the results produced by the View Requests link.

This issue occurs when all of the following conditions are met:

  • The Security Policies advanced filter setting is configured with custom security policies.
  • You click the View Requests link in the charts page to view the filtered requests.

Impact

The resulting list of requests is not limited based on the selected security policies.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Clicking the View Request link in the Security > Reporting > Application > Charts page produces a list of unfiltered requests.
