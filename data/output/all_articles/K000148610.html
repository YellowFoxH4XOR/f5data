Description

You might notice a virtual address on the GUI virtual address list that doesn't belong to any virtual server.

Environment

  • GUI
  • Virtual server
  • Virtual address

Cause

F5 is tracking this issue internally from the ID1441549.

Recommended Actions

You may delete the additional virtual address from the tmsh command: #tmsh delete ltm virtual address <Address>, for details, you can read the manual here on F5 Cloud Docs.

Note: Please replace <Address> with the virtual address you want to delete.

For example, the additional IP 192.0.2.1 is in the virtual address that does not belong to any virtual server.

Then you can run this command to delete: # tmsh delete ltm virtual address 192.0.2.1

Additional Information

None.
