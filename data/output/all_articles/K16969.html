Known Issue

Cookie hash persistence fails when the cookie value is set by an iRule.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration includes a virtual server that has an associated cookie persistence profile.
  • The cookie persistence profile's Cookie Method setting uses the Cookie Hash method.
  • The virtual server also has an associated iRule that includes a cookie hash persist command.
  • The virtual server uses the iRules persist command to set persistence for a client connection.

Impact

Client connections do not persist to the same pool member.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H508760 on the Diagnostics > Identified > Medium screen.
  • Client connections are not persisting to the same pool member as expected.
  • When viewing persistence records, you find incorrect cookie hash values.
