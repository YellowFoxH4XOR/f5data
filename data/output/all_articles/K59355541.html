Description

You see repeating error messages similar to the following (truncated) in /var/log/ltm:
err mcpd[6023]: 01020036:3: The requested Certificate Status (/Common/star_example_com_2019.crt) was not found.

Environment

  • BIG-IP
  • 4200 (C113)
  • 13.1.1 - Final 

Cause

The running configuration loaded in the mcpd process from the binary configuration image are out of synchronization.

Recommended Actions

K13030: Forcing the mcpd process to reload the BIG-IP configuration
