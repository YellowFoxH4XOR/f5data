Issue

The ARX system's syslog file may contain STATUS_FILE_CORRUPT_ERROR messages that appear similar to the following example:

: Operation on file '\dir_65529' at filer 10.10.10.1 share 'Share1' returned STATUS_FILE_CORRUPT_ERROR. Error occurred processing NT_CREATE_ANDX from user arx\administrator at 192.168.10.1.

The STATUS_FILE_CORRUPT_ERROR messages are not generated by the ARX system and do not indicate a file system corruption. These messages are generated and returned by a filer as a result of a failed operation, such as a directory creation failure. The filer should be examined for additional information indicating the cause of the failed operation.
