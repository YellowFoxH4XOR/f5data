Topic

This article provides an overview of 2 large, bundled Engineering Hotfixes (EHF) Hotfix-BIGIP-17.5.1.3.0.192.19-ENG and Hotfix-BIGIP-17.1.3.0.210.11-ENG released on top of BIG-IP versions 17.5.1.3 and 17.1.3 respectively. The article covers where to find a list of fixes, installation prerequisites, and references to upgrade guideline documentation to assist you.

Note: Installation of these Engineering Hotfix bundles should only be considered if you are upgrading to BIG-IP version 17.5.1.3 or 17.1.3. Please be aware that the BIG-IP vulnerabilities disclosed in the October 2025 Quarterly Security Notification have already been addressed in BIG-IP versions 17.5.1.3 and 17.1.3. Installing the Engineering Hotfix bundle is not required to address these vulnerabilities.

When planning for an upgrade to BIG-IP version 17.5.1.3 or 17.1.3, consider the following factors:

  • If you are not currently running an Engineering Hotfix, a review of the IDs listed in the applicable Readme file should be done. Once that review is done you can then determine whether it is applicable and apply it as needed or proactively.
  • If you are currently running an Engineering Hotfix:
    •  Review the Release notes for either 17.1.3 or 17.5.1.3 to ascertain the status of the IDs in your current EHF. If you find all the IDs in your current EHF are fixed then you can use just the base image. You should also review the Readme file for the EHF on the Download site and determine whether to install  the EHF as needed or proactively.
    • If you find that not all IDs are fixed in either 17.1.3 or 17.5.1.3 then review the Readme file for the applicable EHF. If you find that the IDs you have are found there then install the EHF.
    • After your review of the IDs in your current EHF if it is shown that an ID from the current EHF is not fixed or is not listed in either the release notes or the EHF Readme open a case with Support. Please provide a clear statement of what you discovered and why you are requesting an Engineering Hotfix for BIG-IP version 17.5.1.3 or 17.1.3. Please include the IDs in question.

Description

The EHFs are delivered as part of F5's commitment to addressing critical customer need and resolves a wide range of known issues across multiple components. Hotfix-BIGIP-17.5.1.3.0.192.19-ENG is designed to build on the 17.5.1.3 base version and Hotfix-BIGIP-17.1.3.0.210.11-ENG is designed to build on the 17.1.3 base version. For a list of issues that the EHFs resolve, refer to the accompanying EHF_ReleaseNotes PDF files for each release on MyF5 Downloads.

Recommendations

You must upload the base BIG-IP version 17.5.1.3 to the system before applying Hotfix-BIGIP-17.5.1.3.0.192.19-ENG. or upload the base version 17.1.3 before applying Hotfix-BIGIP-17.1.3.0.210.11-ENG. The base image and the engineering hotfix must reside on the BIG-IP system and are stored in the default image location, /shared/images so the BIG-IP system can automatically install the image if needed when you perform a hotfix installation. They can be seen in the GUI at System >> Software :: Image or  System >> Software :: Hotfix.

For more information about installing EHFs refer to the following resources:

  • K55025573: BIG-IP engineering hotfix installation overview
  • K13123: Managing BIG-IP product hotfixes (11.x - 17.x)

For more information about upgrading refer to K02693745: Prepare to update or upgrade the BIG-IP system | BIG-IP update and upgrade guide.
