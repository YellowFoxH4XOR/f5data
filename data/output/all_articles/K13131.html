Topic

This article applies to BIG-IP 11.x through 13.x. For information about other versions, refer to the following article:

  • K6346: Recovering from a corrupt drive partition (9.x - 10.x)

You should consider performing this procedure under the following condition:

  • You must clear the Master Boot Record (MBR) and then repartition the drive, due to a corrupt drive partition.

    Note: In general, this process is recommended by another article, an iHealth diagnostic, or at the direction of an F5 Technical Support representative. If you are unsure if this process is appropriate for your system, contact F5 Technical Support for assistance.

Description

You must clear the MBR to recover from a corrupt drive partition. Clearing the MBR allows the BIG-IP system's installation script to correctly repartition the drive during the subsequent re-installation of the BIG-IP software. To clear the MBR, you must first boot the BIG-IP system into the Maintenance Operating System (MOS) using the mosreboot command. You can then clear the MBR by running the diskinit utility.

Prerequisites

You must meet the following prerequisite to perform this procedure:

  • You have command line access using the serial console.

Procedures

To boot the BIG-IP system into the MOS using the mosreboot command and clear the MBR by running the diskinit utility, perform the following procedures:

  • Booting into the MOS using the mosreboot command
  • Clearing the MBR and repartitioning the drive

Booting into the MOS using the mosreboot command

When you initially run the image2disk utility to install the software, the installation process places an updated MOS on the system. The mosreboot command reboots the system to the MOS, which runs in RAM.

Impact of procedure: When booted into the MOS, the BIG-IP system cannot process traffic.

  1. Connect to the command line through the serial console.
  2. Log in as the root user.
  3. To reboot the system into the MOS, type the following command:

    mosreboot

    When the system is booted into the MOS, a message that appears similar to the following example is displayed:

    Terminal type? [vt100]

  4. Confirm the [VT100] terminal type by pressing Enter, or enter an alternate terminal type appropriate to your environment.

Clearing the MBR and repartitioning the drive

After the system is booted into the MOS, the system drives are inactive and you can clear the MBR.

Impact of procedure: This process will re-initialize the system disk, destroying all data.

  1. From the MOS command line prompt, initialize the system disk by typing the following command:

    diskinit -style volumes

    The system returns a message that appears similar to the following example:

    ***
    *** WARNING:
    *** All software and data on this system is about to be destroyed!
    ***
    Ready to reformat. Continue? (y|n) [n] -->

  2. To continue, confirm the reformat operation by pressing Y and Enter.
  3. After the diskinit operation completes, perform a clean installation.
