Known Issue

Host-based secure shell (SSH) authentication may fail after you install a user configuration set (UCS) or move the configuration during an upgrade.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration allows public key SSH authentication.
  • You install a UCS or chose to move the configuration when performing an upgrade. The BIG-IP system installs a UCS to the new Boot Location in this case.

Impact

The BIG-IP system requires a password for command line access.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When attempting to access the command line of the BIG-IP system using SSH, you must manually enter a password.

Workaround

Note: A UCS archive generated after performing the workaround will not include the /var/ssh/<username>/authorized_keys file. If you plan to load the UCS archive on a different unit, such as a replacement unit from a Return Materials Authorization (RMA), first save the file for each affected user.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP system.
  2. To create a new /var/ssh directory, for each affected user, use the following command syntax:

    mkdir -m 755 -p /var/ssh/<username>

    For example, to create a new directory for a user named example, use the following command:

    mkdir -m 755 -p /var/ssh/example

  3. To move the .ssh/authorized_keys file into the new directory, use the following command syntax:

    mv /home/<username>/.ssh/authorized_keys /var/ssh/<username>

    For example, to move the authorized_keys file into the example user's new directory, use the following command:

    mv /home/example/.ssh/authorized_keys /var/ssh/example

  4. To add a link to the moved file, in the new directory, use the following command syntax:

    cd /home/<username>/.ssh && /bin/ln -s /var/ssh/<username>/authorized_keys.

    For example, to add a link to the example user's new directory, use the following command:

    cd /home/example/.ssh && /bin/ln -s /var/ssh/example/authorized_keys.
