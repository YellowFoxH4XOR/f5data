Known Issue

Searching log files may cause the pccd process to produce a core file and SQL to slow down.

This issue occurs when the following condition is met:

  • The network firewall log is large.

Impact

Log searches become slow and may take a long time to display.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you perform searches in the network firewall log, the searches are slow.

Resolution

To work around this issue, you can use custom search filters to speed up the search times.
