Description

The functionality of APM ACL's might be confusing for users that are not familiar about how APM ACL's are applied and how they work.
The following information provides scenarios where BIG-IP APM ACL can be used to filter traffic.

Environment

  • BIG-IP APM
  • ACL's

Cause

The APM ACL can only be applied to VPN client-initiated connection request.

The following scenarios are the expected behavior of BIG-IP APM ACLs:

  1.  VPN to LAN:
    APM ACLs are applied on VPN client initiated connections.
     
  2.  LAN to VPN:
    Server side initiated connections do not have APM ACLs applied to the connection.
    Note: Application of ACLs are triggered only when a CLIENT_ACCEPTED event is triggered.
     
  3.  VPN to VPN:
    ACLs are not applied to connections between VPN tunnel clients.
    As long as, the IP addresses assigned to the clients are not excluded in a split tunneling configuration, inter VPN client or VPN server to client request do not have ACLs applied. 
    Note: As ACLs cannot block VPN to VPN traffic (VPN client to client traffic), you may consider Packet Filters to filter such traffic if necessary.
     

Note:  ACL's are only applied if the traffic is generated from a VPN user that an ACL is applied through an access policy configuration.
