Issue

Description

Configuring the BIG-IP to append a URI to a host header for inbound requests.

Environment

  • Virtual server configured with an HTTP profile applied.
  • If this is encrypted traffic, Client SSL and HTTP profiles are required.

Cause

None

Recommended Actions

Creating an iRule to respond with an HTTP response

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules > iRules List.
  3. Click Create.
  4. Type a name for the iRule.
  5. In the Definition section, type the following syntax, replacing "/appended/uri/" with the URI you wish to append.

    when HTTP_REQUEST {
    if { [HTTP::uri] equals "/"}
     {
        HTTP::redirect "https://[HTTP::host]/appended/uri/"
     }
    }

  6. Click Finished.
  7. Associate the iRule to the desired virtual server.

Additional Information

None
