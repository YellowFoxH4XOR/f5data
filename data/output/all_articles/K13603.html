Issue

Old Behavior

Prior to version 10.2.2, the BIG-IP system automatically installs two software volumes after performing a clean installation.

Performing a clean installation using either image2disk with the format option or the manufacturing installation, the system automatically installs two software volumes, meaning you have two available boot locations with the same version.

New Behavior

Beginning in BIG-IP 10.2.2, the installation process installs only one software volume.

Performing a clean installation using either image2disk with the format option or the manufacturing installation, the system automatically installs only one software volume, meaning you only have one boot location.

F5 Product Development tracked this change as ID 353344.

Impact

You must perform a manual installation for any operations that require that you install more than one software volume.

Recommended Actions

If you need to install a hotfix, you can install it into the next empty software volume. After copying the hotfix ISO image file and the base product ISO image file to the /shared/images directory, you can install a hotfix directly onto the next empty software volume using either the tmsh utility or the Configuration utility.

For example, the following procedure describes how to install a hotfix onto the target volume after you have performed a clean installation of BIG-IP 10.2.2 on the active volume.

  1. Verify that you have the hotfix and base product ISO image file copied onto the system, by typing the following command:

    ls -l /shared/images

    You may see output that appears similar to the following example:

    -rw-r--r-- 1 root root 854675456 May 27 22:35 BIGIP-10.2.2.763.3.iso
    -rw-r--r-- 1 root root 163977216 May 27 23:04 Hotfix-BIGIP-10.2.2-969.0-HF4.iso

  2. Verify that the system has an empty software volume available for the installation of a hotfix, by typing the following tmsh command:

    tmsh show sys software

    You may see output that appears similar to the following example, indicating that HD1.2 and HD1.3 are empty and available:

    Sys::Software Status
    Volume  Product  Version  Build  Active    Status
    -------------------------------------------------
    HD1.1    BIG-IP   10.2.2  763.3     yes  complete
    HD1.2      none     none   none      no  complete
    HD1.3      none     none   none      no  complete

  3. Install the base version and hotfix together, by typing the following tmsh command:

    tmsh install sys software hotfix Hotfix-BIGIP-10.2.2-969.0-HF4.iso volume HD1.2

  4. Verify the installation progress, by typing the following command:

    tmsh show sys software

    You may see results that appear similar to the following example, indicating that the installation of version 10.2.2 hotfix 4 has completed successfully on software volume HD1.2:

    Sys::Software Status
    Volume  Product  Version  Build  Active    Status
    -------------------------------------------------
    HD1.1    BIG-IP   10.2.2  763.3     yes  complete
    HD1.2    BIG-IP   10.2.2  969.0      no  complete
    HD1.3      none     none   none      no  complete
