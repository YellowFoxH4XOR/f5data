Topic

Some common SSL proxy log file errors are defined in the following table:

ErrorPossible Cause

SSL_accept returned =32

This error indicates that there has been an interruption in communication.

The most likely cause for this error is that a client started to load a page and clicked the stop button, or closed the browser, before the connection was completed.

Connecting server socket,fd=1296: errno = 57:

This error indicates that a Socket is not connected.

The most likely cause for this error is that a client started to load a page and clicked the stop button, or closed the browser, before the connection was completed.

Connecting Server Socket, FD = 29:errno = 61

This error indicates that the server to which the BIG-IP is attempting to connect has refused the connection.

There are many possible reasons for this error. Check first to see if the web server is properly functioning.
