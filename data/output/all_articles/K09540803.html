Description

When creating a BIG IQ HA, the following error is seen:

An error occurred while adding the BIG-IQ: Could not connect to host x.x.x.x. Please ensure there are no licensing, firewall, port lockdown or network connectivity issues. Error: status:400, body:{"code":400,"message":"No login provider named tmos.","originalRequestBody":"{\"username\":\"admin\",\"loginProviderName\":\"tmos\",\"generation\":0,\"lastUpdateMicros\":0}","restOperationId":25618289,"errorStack":[],"kind":":resterrorresponse"}


Environment

  • BIG-IQ
  • HA

Cause

Version mismatch

Recommended Actions

Make sure that the version of the BIG-IQ being created as an HA matches.
If version matches, make sure other connectivity requirements is fulfilled.

None
