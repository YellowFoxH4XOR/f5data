Issue

Error Message

notice tmm[<PID>]: 01700001:5: PPTP CALL-START id;<Initiating Call ID> from;<Initiating IP Address> to;<Destination IP Address> nat;<NAT IP Address> ext-id;<Destination Call ID>

In this error message, note the following:

  • <PID> is the process ID for the TMM process
  • <Initiating Call ID> is the ID assigned to the caller initiating the call
  • <Initiating IP Address> is the IP address of the initiating caller
  • <Destination IP Address> is the destination IP address of the end point
  • <NAT IP Address> is the IP address of the NAT
  • <Destination Call ID> is the destination IP address of the end point

For example:

notice tmm[24434]: 01700001:5: PPTP CALL-START id;6881 from;10.0.0.1 to;192.168.1.1 nat;172.16.0.2 ext-id;58289

Message Location

You may encounter this message in the following location:

  • /var/log/ltm
Description

This message occurs when the following condition is met:

  • The server responds with an outgoing call reply indicating that the call was successful.

Impact

There is no impact; this message is informational only.

Recommended Actions

None
