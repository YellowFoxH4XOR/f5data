K10415: Migration of NTFS files and directories containing Alternate Data Stream information to a Microsoft Windows 2003 Server may fail

Topic

Migration of NTFS files containing Alternate Data Streams (ADS) information to a Microsoft Windows 2003 Server using HP PolyServe software for Windows File Serving versions earlier than version 3.6.1 will fail with syslog messages that appear similar to the following example:

:LIBCIFS-0-7-MSG7:: received STATUS_ACCESS_DENIED in response to NT_CREATE_ANDX on <\\10.10.1.11\Share1>
:LIBCIFSEXT-0-7-MSG7:: cannot open destination stream "/Share1/path/RPA IF/RPA staining 1/RPA foci c-abl wt (pics)/2h:AFP_AfpInfo:$DATA" - STATUS_ACCESS_DENIED

The migration fails because HP PolyServe software for Windows File Serving versions prior to 3.6.1 do not support ADS.
