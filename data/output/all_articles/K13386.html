K13386: WebAccelerator no longer uses X-Remote-Addr (11.x)

Type
Knowledge
Published
2013-03-18
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • BIG-IP Edge Gateway: 11.2.0, 11.1.0, 11.0.0, 11.3.0, 11.2.1
  • BIG-IP WebAccelerator: 11.3.0, 11.2.0, 11.1.0, 11.0.0, 11.2.1
Source
https://my.f5.com/manage/s/article/K13386

Issue

Old Behavior

Previously, as outlined in K7441: Using the 'X-Remote-Addr' HTTP header to preserve the original client IP address for traffic being translated by BIG-IP WebAccelerator (9.x - 10.x), the BIG-IP WebAccelerator system inserted an X-Remote-Addr HTTP header to facilitate accurate logging of the original client source IP address into HTTP server logs.

New Behavior

Beginning in BIG-IP WebAccelerator 11.0.0, F5 has removed the X-Remote-Addr HTTP header.  

Impact

Web servers that rely on the X-Remote-Addr HTTP header fail to log the correct client IP addresses.

Recommended Actions

To enable X-Forwarded-For headers for the virtual server that you want to log client IP addresses, refer to K4816: Using the X-Forwarded-For HTTP header to preserve the original client IP address for traffic translated by a SNAT.
