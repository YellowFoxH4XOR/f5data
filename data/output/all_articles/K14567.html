Topic

You should consider using this procedure under the following condition:

  • You would like volume import statistics

Description

For the ARX system to manage a volume, the volume must first go through the import process. The ARX import process is a method for the ARX system to collect all of the filer data to create the ARX metadata. The ARX system uses this data to translate the location of files into one unified volume on the front end to present the information by way of the NFS or CIFS services.
 
The import_rate expect script allows you to gather live statistics from the ARX import process. The output gives you an idea of how quickly the ARX is importing the filer data and how long it may take to complete the import of the volume.

You may locate the expect script import_rate on the ARX system by running the show scripts command.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You are importing a volume into the ARX system
  • You have administrative privileges to the ARX system

Procedures

Checking the import rate of a volume using the import_rate script

Impact of procedure: None.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable

  3. Gather the filer statistics by using the following command syntax:

    expect import_rate <NAMESPACE NAME> /<ARX VOLUME NAME>

    For example:
    expect import_rate ns1 /vol1

                                          Average Interval Interval Interval Interval
     Elapsed  Metadata  Metadata  Import     Scan     Scan   Import   Import     Scan   Scan
Time    Time      Size   Entries    Rate  Entries     Rate  Entries     Rate  Entries   Rate
----    -----    -----   -------  ------  -------   ------  -------   ------  ------- ------
20:36:27  21  292.00Kb    14,745  187.81   16,071   102.43    3,944   187.81    2,151 102.43
20:36:42  36    2.11Mb    17,072  174.19   16,071    59.75    2,327   155.13        0   0.00

    Note: The IMPORT RATE displays the average number of files per second, over the 5 second interval.

    If the import completes while the script is running, the output will appear similar to the following example:

    Import complete for namespace ns1, volume /vol1.
    112200 items in 600 seconds for an import rate of 187 items/sec.
