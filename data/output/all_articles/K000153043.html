K000153043: How to SCP to F5OS by a superuser account

Type
Support Solution
Published
2025-09-08
Updated
2025-09-08
Source
https://my.f5.com/manage/s/article/K000153043

Description

To SCP to F5OS via a user with superuser role, please take note of the followings :

 

  • Secondary role of the user must be either "Admin" or "Operator" or "Rource Admin"
  • Home directory of the user is "/var/F5/system"
  • Add the "-O" option to the SCP command

 

For example :

- F5OS-A :

[root@appliance-1:Active] configs # pwd
/var/F5/system/configs
[root@appliance-1:Active] configs #  ls -la
total 12
drwxrwxr-x.  2 root admin 4096 Aug  7 17:01 .
drwxr-xr-x. 33 root root  4096 Jul 24 16:24 ..
-rw-r--r--.  1 root root    28 Aug  7 17:01 test                  <---- absolute path is "/var/F5/system/configs/"


- SCP client :

scp -O testuser@<IP address>:configs/test .              <---- relative path is "configs/"

Environment

  • F5OS-A
  • SCP to F5OS by a user with superuser role

 

Cause

Bug ID 2008501: SCP does not work for users created with a superuser role

 

Recommended Actions

 

Add the "-O" option to the SCP command.
