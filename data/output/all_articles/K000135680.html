Description

How to obtain and use the serial number for an SSL certificate with an OCSP responder to validate the certificate's revocation status.

Environment

  • BIG-IP APM
  • Client Cert inspection / Machine Cert Inspection
  • OCSP Responder configured with OCSP Auth branch available on Access Policy's VPE.

 

 Recommended Actions

  1. Copy and create the iRule available on Additional Information and apply it to the VS.
  2. Apply this iRule to the Virtual Server
  3. Create a iRule Event agent on the VPE, after the OCSP Auth agent fallback branch.
  4. On the iRule Event agent, the Customer iRule Event ID must be equal to "ocsp_serialnumber".

Additional Information

when ACCESS_POLICY_AGENT_EVENT {

   set serialnumber "[ACCESS::session data get session.ssl.cert.serial]"

   set subject "[ACCESS::session data get session.ssl.cert.subject]"

 

   if { [ACCESS::policy agent_id] eq "ocsp_serialnumber"}

   {

       set status "[ACCESS::session data get session.ocsp.last.result]"

       log local0. "The result is $status for CN: $subject with SN: $serialnumber"

 

       if {$status eq 0}{ log local0. "Certificate Revoked"}

       else { log local0. "Certificate Valid"}

      }

}
