Known Issue

This is the result of a known issue. Address translation and port translation must be enabled for the BIG-IP ASM enabled virtual servers. However, port translation is disabled by default when a wildcard port virtual server is created, and address translation is disabled by default for wildcard IP virtual servers. Both port and address translation are required for the BIG-IP ASM enabled virtual servers to function properly.

F5 Product Development is tracking this issue as CR65341 and CR66193.

Workaround

You can work around this issue by enabling address and port translation for the BIG-IP ASM enabled wildcard virtual servers. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. From the list of virtual servers, select the BIG-IP ASM enabled wildcard port virtual server to be configured.
  4. On the Virtual Sever Properties page, select Advanced from the Configuration menu.
  5. Select the Enabled check box for Address Translation.
  6. Select the Enabled check box for Port Translation.
  7. Click Update.
