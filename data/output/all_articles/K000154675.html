Description

Configuration failed to load, with the following error:

01071485:3: CliShellScript (/Common/f5.app_utils) content does not match the signature.

Where does the /Common/f5.app_utils script reside, and why did the error occur?

Environment

  • Configuration load

Cause

The f5.app_utils CLI script is a system script that contains a set of shared helper functions (procedures) that can be used by the F5 iApp templates.

The script is defined in /defaults/app_template_base.conf. It is signed by F5's f5-irule private key.

During configuration load, the system reads in app_template_base.conf and attempts to verify the integrity of the script by checking its signature against the private key's corresponding public key in the f5-irule.crt certificate.

If the f5-irule.crt is unavailable, the signature cannot be verified, resulting in the configuration load failure.

Recommended Actions

If you have accidentally deleted the f5-irule.crt certificate, you can recover from this problem by loading a UCS file.

You can confirm whether the UCS file contains the certificate, with the following command:

tar tzf <ucs file> | grep f5-irule
