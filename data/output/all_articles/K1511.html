K1511: Configuring BIG-IP to add a header so that BEA WebLogic nodes will generate redirects and links that specify the HTTPS protocol

To ensure that WebLogic serves back the https:// header, use BIG-IP to insert WL-Proxy-SSL: true into the HTTP Header String. You can add this string from the command line or from the Configuration utility.

Inserting WL-Proxy-SSL: true from the command line

BIG-IP versions 4.2 through 4.6.4

In BIG-IP versions 4.2 through 4.6.4, you have the option to set this header per proxy or per pool (per proxy is recommended).

For example:

proxy 10.10.35.100:443 unit 1 {
target virtual 127.0.0.100:80
clientssl enable
clientssl key www.joerulez.com.key
clientssl cert www.joerulez.com.crt
header insert 'WL-Proxy-SSL: true'
}

The resulting HTTP header would look like the following:

GET /index.html HTTP/1.0
WL-Proxy-SSL: true
Host: www.joerulez.com
Connection: Keep-Alive

BIG-IP versions 4.0 through 4.1.1 PTF-06

On versions 4.0 through 4.1.1 PTF-06, insert the HTTP header string globally with the following command:

bigpipe db set Common.Bigip.Proxy.AddHTTPHeader = 'WL-Proxy-SSL: true'

Inserting WL-Proxy-SSL: true from the Configuration utility

For BIG-IP versions 4.0 through 4.6.4, use the following procedure to set the header with the Configuration utility:

  1. Click the Proxy Server address.
  2. Click the Proxy Advanced Properties tab.
  3. Type the following in the Insert HTTP Header String box:

    WL-Proxy-SSL: true
