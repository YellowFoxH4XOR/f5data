K000134880: tcpdump is including packets from devices that are not part of host filter

Type
Support Solution
Published
2023-06-01
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K000134880

Description

  • tcpdump command being run with p parameter and host filters and being run for a significant period of time.
  • The capture file has packets from clients that weren't part of the host filter.


Environment

  • BIG-IP LTM
  • tcpdump running with p parameter specific for a significant period of time.


Cause

This can happen if the Flow ID or Peer ID gets re-used.


 Recommended Actions

Run tcpdump with a stating all possible hosts and without the p parameter.


Additional Information

None.
