K000149023: NGINX Plus R33 AWS Marketplace Unable to Start Service

Type
Support Solution
Published
2024-12-18
Updated
2024-12-18
Applies to
  • NGINX Products
  • NGINX Plus: R33
Source
https://my.f5.com/manage/s/article/K000149023

Description

NGINX Plus R33 is encountering an issue where the service fails to start, and the error log reports:

  • 'connect() failed (13: Permission denied) while checking "aws" license' 

For NGINX Plus R33, license validation is required through either the F5 Licensing Endpoint or the AWS Marketplace Endpoint. However, the service is unable to connect to the external address for license validation, resulting in the nginx.service unable to start.

Environment

  • NGINX Plus R33
  • RHEL 9
  • AWS Marketplace NGINX Subscription

Cause

The SELinux environment of the AWS instance is not allowing connections to external addresses.

 

Recommended Actions

Need to allow NGINX to connect to external addresses by changing the SELinux policy boolean httpd_can_network_connect to 1.

setsebool -P httpd_can_network_connect 1
