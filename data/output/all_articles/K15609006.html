Description

BIG-IP replies to Ping for non-existent IP on self.

When icmp-echo is enabled on wildcard virtual-address (/Common/0.0.0.0).
For example:
# tmsh list ltm virtual-address 0.0.0.0
ltm virtual-address 0.0.0.0 {
    address any
    arp disabled
    icmp-echo all           <-- not "disabled"
    mask any
    traffic-group traffic-group-1
}
 

Environment

  • ICMP (Ping)
  • Wildcard Virtual Address
Cause

It's by design.
 

Recommended Actions

Disable icmp-echo in the "wildcard" Virtual Address if you do not wish the BIG-IP to reply to ping for non-existent IP.

None
