Description

  1. The control plane CPU uitilation is high. While checking which processes are using the CPU resource, you find scriptd consumes resources excessively.
30991 root       1 -19 42.1g 107m  87m S 54.3  0.2  95:16.51 tmm.0
6749 root      20   0  178m 156m  53m S 24.0  0.3  76:25.53 scriptd
7800 root      25   5  127m  39m  32m S 10.7  0.1   8:00.50 mcpd
31445 root      20   0 55324  30m  18m S  8.7  0.1   2:28.50 bigd
  1. You find below logs in /var/log/audit.
AUDIT - user=root action=''periodic handler, run script: /Common/bigiq-analytics-send_stats'' status=''OK''
  1.    This device was once managed by BIG-IQ, but now was removed from BIG-IQ.

Environment

  • BIG-IP LTM
  • BIG-IQ
  • iApps

Cause

The "bigiq-analytics-send_stats" script still runs after removing the BIG-IQ.
 

Recommended Actions

Follow below 2 steps to stop the "bigiq-analytics-send_stats" script running in BIG-IP iAPP.
  1. Navigate to iApps  ››  Application Services : Applications in BIG-IP, detele the "bigiq-analytics" in Application Service List;
  2. Navigate to iApps  ››  Templates : Templates, detele the "f5.bigiq-analytics" in Template List.
