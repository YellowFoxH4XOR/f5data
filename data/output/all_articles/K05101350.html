Known Issue

Connections may stall when a local traffic policy action fails.

This issue occurs when all of the following conditions are met:

  • You associate a local traffic policy that is configured to take an action on an HTTP request or HTTP response with a virtual server.
  • The virtual server receives an HTTP request or HTTP response that matches the associated rule of the local traffic policy.

Impact

Client connections stall until they are reaped by the BIG-IP system when it reaches the idle timeout.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • HTTP traffic to the affected virtual server appears to stall.
  • You may observe messages in the /var/log/ltm file that appear similar to the following example:

    err tmm[1234]: 016e0002:3: Execution of action 'http-header remove policy=/Common/example rule=example_rule action-id=0 name=X-example' failed, error ERR_NOT_FOUND
