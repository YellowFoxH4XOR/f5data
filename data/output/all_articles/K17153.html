Known Issue

The Traffic Management Shell (tmsh) utility does not display outgoing statistics for MAP tunnels.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP system as a border relay (BR) in a MAP deployment.
  • The BIG-IP system processes bidirectional traffic between the MAP tunnel.
  • You view the tunnel statistics using the tmsh show net tunnels command.

Impact

Users are unable to view outgoing statistics for MAP tunnels using the tmsh utility. This is a cosmetic issue and does not impact functionality.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Outgoing statistics for MAP tunnel traffic are not shown in the output of tmsh show net tunnels command.
  • Incoming statistics for MAP tunnel traffic are shown in the output of tmsh show net tunnels command.
