Known Issue

This is the result of a known issue. The BIG-IP ASM system may incorrectly attempt to access uninitialized memory or free memory allocated for a parameter name.

This behavior can result in memory leaks and cause general system instability, if the BIG-IP ASM system attempts to access memory space for a parameter name that has not been allocated or if a pointer to a memory space for a parameter name that is actively being used is removed.

F5 Product Development tracked this issue as ID 336305 and it was fixed in BIG-IP ASM 10.2.2 and 11.0.0. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Additionally, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).
