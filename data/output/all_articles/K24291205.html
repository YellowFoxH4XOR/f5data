Description

When configuring a a pool that is only reachable via a particular partition/route domain, the following error is received in Configuration Utility:
"01070734:3 Configuration error: Pool /[non-Common Partition name]/[gateway failsafe pool] has gateway failsafe option and must reside in Common partition".

Environment

  • You require setting up gateway fail-safe. 
  • You have multiple partitions and route domains. 
  • You are attempting to use a pool that is only reachable via a particular partition/route domain. 


Cause

The gateway pool in non-Common partition is not supported. The gateway pool object has to be in Common partition.
 

Recommended Actions

You can utilize the VLAN failsafe feature as a workaround. 
 

Additional Information

None.
