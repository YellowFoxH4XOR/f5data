K94144094: BIG-IP ASM charts and reporting page in the Configuration Utility doesn't display statistics data

Type
Support Solution
Published
2020-03-06
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.1.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.0
Source
https://my.f5.com/manage/s/article/K94144094

Description
On the Security  ››  Reporting : Application : Charts page in the BIG-IP Application Security Module Configuration Utility, none of the reports show any data. In /var/log/avr/monpd.log you may observe Analytics Visibility and Reporting database error messages similar to the following:

STAT_BRIDGE_THREAD|ERROR|Feb 05 12:34:56.789|23456|../src/loader/monpd_stat.cc:executeAggregationWork:0798| (skipped 17 msgs) Failed to retreive status of removed partitions for fact AVR_STAT_ASM_CPU
DB|ERROR|Feb 05 12:34:56.789|23456|../src/db/MonpdDbAPI.cpp:mysql_query_safe:0209| Error (err-code 1243) executing SQL string :
CALL ValidateNextPartition('AVR_STAT_ASM_CPU_T',1582565940)
Because : Unknown prepared statement handler (stmt_select_need_to_add) given to EXECUTE
DB|ERROR|Feb 05 12:34:56.789|23456|../src/db/MonpdDbAPI.cpp:runStoredProc:0637| Error executing SQL string :
CALL ValidateNextPartition('AVR_STAT_ASM_CPU_T',1582565940)
Because : Unknown prepared statement handler (stmt_select_need_to_add) given to EXECUTE
STAT_BRIDGE_THREAD|ERROR|Feb 05 12:34:56.789|23456|../src/loader/monpd_stat.cc:getBoolUserVar:0409| Failed to retreive information (@is_partition_created) about table AVR_STAT_ASM_CPU_T


Environment

  • BIG-IP ASM
  • No BIG-IQ Data Collection Device which collects these reports remotely
  • monpd and avrd processes are running as expected and not frequently restarting
tmsh show sys service monpd avrd

Output appears similar to the following example:

monpd run (pid 12345) 5 days, 1 start
avrd run (pid 54321) 5 days, 1 start

Cause

AVR database errors

Recommended Actions
Follow the procedure from the article below to reset the AVR database then check the Charts page again. It may take 5-10 minutes to begin populating data in the charts.
K14956: Resetting BIG-IP AVR statistics

Additional Information
This issue can happen even if the BIG-IP Analytics module is not provisioned. Analytics provisioning is not required for ASM reporting functionality.
If there is a BIG-IQ DCD that collects these statistics remotely then they will not be available to view on the local device.
