Known Issue

This is the result of a known issue. HTTP request headers containing a leading newline character (CR/LF) may prevent the BIG-IP WebAccelerator from parsing the header properly. This behavior may cause the BIG-IP WebAccelerator system to generate a 403 Forbidden error.

F5 Product Development tracked this issue as CR133799 and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue has been fixed Hotfix-BIGIP-10.0.1-402.7-HF4 issued for BIG-IP version 10.0.1 and in BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes on systems refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
