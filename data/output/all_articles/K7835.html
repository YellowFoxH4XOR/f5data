Topic

The FirePass controller supports uploading of customer-created web content through WebDAV to an area on the FirePass called the WebDAV sandbox.
 
Note: For more information about WebDAV, refer to K4440: Overview of WebDAV.

The type of web content that can be used in the sandbox includes all static forms of web content, such as HTML, XML and similar markup languages that do not require server-side parsing or server-side dynamic libraries. Additionally, client-side scripting languages such as Javascript can be used. FirePass does not support scripting languages for which a server-side interpreter or processor is required. For example, PHP files are not supported in the WebDAV sandbox.
