K000139309: CRLDP Authentication fails with error "Bad HTTP response status"

Type
Support Solution
Published
2024-04-17
Updated
2024-04-17
Source
https://my.f5.com/manage/s/article/K000139309

Description

This solution will detail possible causes of this error message.

  • CRLDP Authentication fails with error 'Bad HTTP response status'
  • You observe the following log messages in /var/log/apm:


<bigip_hostname> debug apmd[16509]: 01490266:7: <access_policy_name>:Prod_Part:<session_id>: modules/Authentication/Crldp/CrldpAuthModule.cpp: 'crldp_lookup()': 384: Update failed for ci http://<hostname>.crl


<bigip_hostname> warning apmd[16509]: 0149015e:4: (null):Common:<session_id>: CRLDP Auth agent: CRL lookup failed for LDAP url 'http://<hostname>.crl' reason 'Bad HTTP response status'

Environment

  • CRLDP Authentication
  • CRLDP Server configuration
  • APM

Cause

This error is caused when either there is no response from the server of the response is invalid.

Recommended Actions

User the curl command to test connectivity to the server.

  1.  Login to the CLI
  2. Run the following command:

curl -v 'http://fqdn_crl_server.com/CRLs/<file_name>.crl'
