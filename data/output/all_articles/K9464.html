K9464: Running configsync between BIG-IP GTM or Link Controller redundant pairs removes the server.crt file

Known Issue

This is the result of a known issue. The /config/gtm/server.crt file is the trusted server certificate used when the local BIG-IP GTM or Link Controller system authenticates itself to a remote F5 device. For example, the local BIG-IP GTM uses the trusted server certificate when the BIG-IP GTM system's gtmd process or iqdump program attempts to connect to the big3d process on a remote F5 device.

Note: For more information about F5 device certificates, refer to K8187: Troubleshooting BIG-IP LTM and GTM device certificates.

When you perform a configsync operation between BIG-IP GTM or Link Controller redundant pairs, the /config/gtm/server.crt file is removed from the target device.

When the gtmd process is restarted on the target device, iQuery communication fails and an error message that appears similar to the following example is logged to the /var/log/gtm file:

iqmgmt_ssl_connect: SSL error:14090086:SSL routines:SSL3_GET_SERVER_CERTIFICATE:certificate verify failed

For example, if BIG-IP GTM devices GTM1 and GTM2 are configured as a redundant pair, and you perform a configsync operation from GTM1 to GTM2, the /config/gtm/server.crt file is removed from the GTM2 system. If the gtmd process is later restarted on the GTM2 system, iQuery communication fails between GTM2 and other F5 devices.

F5 Product Development tracked this issue as CR111256 and it was fixed in BIG-IP version 9.4.8. For information about upgrading, refer to the BIG-IP GTM or Link Controller release notes.

Workaround

To temporarily work around this issue and restore iQuery functionality, run the bigip_add command from the target BIG-IP GTM or Link Controller device.

Note: This workaround temporarily restores iQuery functionality until the next time the configsync operation is performed. During this time, the /config/gtm/server.crt file will be removed again. To permanently resolve this issue, upgrade to BIG-IP version 9.4.8 or later.
