Description

01070151:3: Rule [<iRule_name>] error: Unable to find value_list (<data_group_name>) referenced at line 250: [findclass <command_variables>]

In this error message, note the following:

  • <iRule_name> is the name of the iRule in question.
  • <data_group_name> is the name of the data group referenced by the iRule.
  • <command_variables> is the list of variables referenced by the iRules findclass command.

For example:

01070151:3: Rule [/Common/ProxyPass] error: Unable to find value_list (ProxyPassSNATs) referenced at line 250: [findclass $newpool ProxyPassSNATs " "]

You may encounter this message in the following locations:

  • TMOS Shell (tmsh)
  • The /var/log/ltm file

Environment

  • Upgraded to BIG-IP 12.1.x or later
  • The system is configured with an iRule containing the findclass command

Cause

The findclass command was deprecated in BIG-IP 10.x in favor of the class command.

Recommended Actions

The class command offers better functionality and performance than the findclass command.

To work around the issue, you may consider replacing the findclass command with class.

  • For example, replace the findclass command in the following iRules command syntax:

set snat [findclass $newpool ProxyPassSNATs " "]

  • With the class command:

set snat [class match -value $newpool equals /Common/ProxyPassSNATs]

  • Similarly, in another example, replace the findclass command in the following iRules command syntax:

set profilename [findclass $pool ProxyPassSSLProfiles " "]

  • With the class command:

set profilename [class match -value $pool equals /Common/ProxyPassSSLProfiles]

Additional Information

The findclass command searches a data group list for a member whose key matches the specified string, and if a match is found, returns the data-group member string.
