K33437445: in-tmm https monitor failed without a specific SSL profile

Type
Support Solution
Published
2022-08-31
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K33437445

Description
when in-tmm monitor is enabled, https monitor may fail when there is not a specific ServerSSL profile assigned to the https profile.

Environment

  • in-tmm monitor is enabled.
  • HTTPS monitors with SSL profile set to None (default) will not use the default ServerSSL profile of "serverssl". 

Symptoms
1. If monitor logging is enabled, you can see error log similar to below in monitor log file.

Cause
BUGID 1019261 has been filed for this issue. 
Please follow bugtracker to the latest status of this bugID. https://cdn.f5.com/product/bugtracker/ID1019261.html 

Recommended Actions

  1. Specify a ServerSSL profile in every HTTPS monitor when using In-TMM monitoring.

Additional Information

1. BigIP does not always send a random  sessionID in "Client Hello" message .
2. Some Server can handle the random sessionID in a new SSL connection "Client Hello" Message.
