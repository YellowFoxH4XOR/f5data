Topic

BIG-IP systems have the option of running in Appliance mode. Appliance mode is designed to limit BIG-IP system administrative access to match that of a typical network appliance and not a multi-user UNIX device.

Note: For information about enabling Appliance mode for BIG-IP tenants deployed on VELOS and rSeries systems, refer to K32730113: Overview of Appliance mode for F5OS on VELOS and rSeries systems.
⚠️ Warning — Appliance Mode is Difficult to Reverse

Before requesting an Appliance mode license, customers must be aware that disabling Appliance mode is not a simple or self-service process:

  • You must contact F5 to have Appliance mode removed from your license file.
  • After relicensing, a clean installation of the BIG-IP software is required to fully disable Appliance mode. An in-place upgrade or configuration change alone is not sufficient.
  • A clean installation will erase all existing configuration. Ensure you have a valid UCS or SCF backup before proceeding.

If you are not prepared to perform a clean installation, do not enable Appliance mode.

Technical restrictions in Appliance mode

  • Access to the Advanced shell (bash) is removed.
  • Administrative access is limited to the Configuration utility and TMOS Shell (tmsh).
  • The root user cannot log in to the device by any means, including the serial console.
  • On platforms that include the Always-On Management (AOM) subsystem, AOM is not able to access the host. AOM is only able to reset the host using a hardware reset command.
  • On VIPRION platforms, SSH access between blades is not allowed by way of the ssh slot<X> command syntax. You can use SSH to access only the management IP address of each blade.

    Note: You do not need an Appliance mode license to enable Appliance mode on a vCMP guest. The Appliance mode for a vCMP guest is determined by the host configuration instead of the license.

Procedures

  • Verify that a device is running in Appliance mode using the Configuration utility
  • Verify that a device is running in Appliance mode using tmsh
  • Verify that a vCMP guest is running in Appliance mode using the Configuration utility
  • Verify that a vCMP guest is running in Appliance mode using tmsh

For devices other than a vCMP guest, you can verify that a device is running in Appliance mode on the License page of the Configuration utility or from tmsh output.

Verify that a device is running in Appliance mode using the Configuration utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to System > License.
  3. A line similar to the following example displays under Active Modules:

    App Mode (TMSH Only, No Root/Bash)

    Note: When the device is not running in Appliance mode, the line displays under Optional Modules.

Verify that a device is running in Appliance mode using tmsh

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To verify a device is running in Appliance mode, use the following command syntax:

    show sys license | grep "App Mode"

    For example, the following command and output verifies a device is running in Appliance mode:

    App Mode (TMSH Only, No Root/Bash)

    Note: show sys license displays active modules only. When a device is not running in Appliance mode, the output is blank.

For vCMP guests, you can verify that a guest Appliance mode is enabled through the vCMP configuration list or tmsh output.

Verify that a vCMP guest is running in Appliance mode using the Configuration utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility of the vCMP host.
  2. Go to vCMP > Guest List.
  3. Select the guest you want to verify.
  4. For properties, select Advanced.
  5. Verify that Enabled is selected for Appliance Mode.

Verify that a vCMP guest is running in Appliance mode using tmsh

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line of the vCMP host.
  2. Log in to tmsh by entering the following command:

    tmsh

  3. To verify a device is running in Appliance mode, use the following command syntax:

    list vcmp guest <guest_name> capabilities { appliance-mode }

    For example:

    list vcmp guest all capabilities { appliance-mode }

    The command output shows MyGuest1 is running in Appliance mode but MyGuest2 is not:

    vcmp guest MyGuest1 {
    capabilities {
    appliance-mode {
    value 0
    }
    }
    }
    vcmp guest MyGuest2 {
    capabilities none
    }

For information about preparing and enabling Appliance mode for vCMP guests, refer to the Additional tasks for isolated guests in Appliance mode chapter of the vCMP for Appliance Models: Administration manual.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Appliance mode is available on all platforms supported by BIG-IP 10.2.1 and later.

F5 licenses the Appliance mode option free of charge upon request. For questions regarding licensing the Appliance mode option, contact your F5 Sales Representative.
