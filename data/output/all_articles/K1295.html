Issue

A parse_http message will appear in the /var/log/bigip log file under the following conditions:

  • TCP data has been retransmitted.
  • There is a non-HTTP header data at the beginning of an HTTP requested method.
  • The client sent more data after the server shut down its side of the connection.

Malformed requests are to be expected; therefore, these errors are benign.

As of BIG-IP version 4.0 PTF-03, these messages include the byte count for the data that was unexpected.
