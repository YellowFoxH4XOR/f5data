K45824351: Silent reboot related to syslog-ng issue with remote logging

Type
Support Solution
Published
2021-11-15
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K45824351

Description
A syslog-ng issue with remote logging to an invalid remote syslog server may lead to an unexpected reboot.

Invalid syslog-ng server configuration or broken connection from BIG-IP toward configured syslog-ng remote server.


The logs visible before and after the reboot:
/var/log/ltm

notice boot_marker
...
warning chmand[7634]: 012a0004:4: Host Watchdog timeout count: 1

var/log/messages
notice syslog-ng[8951]: Syslog connection established; fd='20', server='', local=''
notice syslog-ng[8951]: Syslog connection broken; fd='20', server='', time_reopen='60'
notice syslog-ng[8951]: Syslog connection broken; fd='20', server='', time_reopen='60'

At this time syslog-ng typically spins, using near 100% CPU.
 

Environment

  • BIG-IP
  • Unable to communicate with a remote syslog server
  • Typically high CPU load

Cause

ID1040277
 

Recommended Actions

Ensure syslog-ng server configuration is valid, and that the server is reachable or remove the 'faulty' syslog server from the syslog config.
