K11175: Users connected to an ARX VIP may experience a 5-minute delay when a filer service is moved to a new node in a Windows 2008 cluster

Topic

When the Windows 2008 Firewall feature is enabled on the nodes of a Windows 2008 cluster, users connected to an ARX VIP may experience a 5-minute delay when a filer service is moved to a new node in a Windows 2008 cluster. This delay is a result of the Windows 2008 Firewall feature and is not indicative of a failure on the ARX system.
