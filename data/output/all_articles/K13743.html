Known Issue

Users may be unable to access the SNMP object identifiers (OIDs) related to the bigSystem.sysPlatform.sysCPU branch on their SNMP management station.

This issue occurs when all of the following conditions are met:

  • You are using the SNMP MIB file provided by the affected versions (the products and versions listed in the Applies To box at the top of this article) on an SNMP management system.
  • You attempt to access the SNMP OIDs for sysCpuNumber or sysCpuTable under the bigipSystem.sysPlatform.sysCpu branch.

F5 provides a downloadable SNMP MIB file in an archived file named mibs_f5.tar.gz, which is located on the Configuration utility welcome page. The MIB files can be loaded into SNMP management system to perform SNMP monitoring operations. However, there may be failure to load because the SNMP OID related to sysCpu was not indexed correctly.

Impact

Users cannot access the SNMP OID relating to the bigipSystem.sysPlatform.sysCpu branch.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The SNMP management system may report syntax errors or fail to load the F5-BIGIP-SYSTEM-MIB.txt MIB file.
  • Performing an SNMP operation remotely to browse OIDs relating to bigipSystem.sysPlatform.sysCpu may result in error messages that appear similar to the following example:

    No Such Instance
