Topic

This article applies to BIG-IP systems that use GRUB  2 (GRUB2). For the BIG-IP systems that use GRUB 0.97 on other BIG-IP versions, refer to the following article:

  • K10452: Overview of GRUB 0.97 configuration file

Summary

This is an overview of the configuration file used by GRUB2 that is implemented on BIG-IP systems. The 5000, 7000, 10000, and 12000 series platforms use the GRUB2 bootloader.

To determine the version of the GRUB bootloader, refer to K14658: Determining the GRUB bootloader version on the BIG-IP, BIG-IQ or Enterprise Manager system.

Description

GRUB is a boot loader that is responsible for loading and transferring control to the operating kernel software, such as Linux. The GRUB configuration file contains a list of images and their loading parameters. GRUB reads this information to specify which image should be loaded.

Note: Editing the GRUB configuration file directly can result in damage to the BIG-IP system. For information about how to edit the GRUB configuration file, contact F5 Technical Support.

Viewing the active GRUB2 configuration file

To view the contents of the GRUB configuration file, you can use the grub_default command.

For example, to view the contents of the GRUB configuration, type the following command:

grub_default -d

The GRUB configuration content may appear similar to the following example:

set default=0
set timeout=5

menuentry 'BIG-IP 11.3.0 Build 2806.0 <MD1.1>' {
set root='(lvm/vg--db--cpmirror-dat.boot)'
linux /boot/1/vmlinuz ro root=UUID=7237fa64-e347-4bb7-a755-6e2617bd7c0e console=ttyS0 panic=1 platform=D113 quiet
initrd /boot/1/initrd
# TIC_IMAGE_INDEX: 1
# TIC_VS_PRODUCT: BIG-IP
# TIC_VS_VERSION: 11.3.0
# TIC_VS_BUILD: 2806.0
# TIC_VS_BASEBUILD: 2806.0
}

menuentry 'BIG-IP 11.4.0 Build 2384.0 <MD1.2>' {
set root='(lvm/vg--db--cpmirror-dat.boot)'
linux /boot/2/vmlinuz ro root=UUID=cf8206fd-d6dc-4e1c-8a97-f301d443d23a console=ttyS0 panic=1 platform=D113 quiet
initrd /boot/2/initrd
# TIC_IMAGE_INDEX: 2
# TIC_VS_PRODUCT: BIG-IP
# TIC_VS_VERSION: 11.4.0
# TIC_VS_BUILD: 2384.0
# TIC_VS_BASEBUILD: 2384.0
}

menuentry 'End User Diagnostics' {
set root='(lvm/vg--db--cpmirror-dat.boot)'
linux /vmlinuz.eud root=/dev/ram0 rw console=ttyS0 quiet
initrd /initrd.img.eud
# TIC_STATIC_KEY: st.eud
# TIC_STATIC_VERSION: 2.3.0.35.0
}

menuentry 'TMOS maintenance' {
set root='(lvm/vg--db--cpmirror-dat.boot)'
linux /vmlinuz.mos root=/dev/ram0 rw console=ttyS0 ramdisk_size=224707.5 skip_media
initrd /initrd.img.mos
# TIC_STATIC_KEY: st.mos
# TIC_STATIC_VERSION: 2.8.1-44.0
}

Each menuentry stanza of the GRUB configuration defines a boot option. For the GRUB configuration example above, the following available boot options would display:

BIG-IP 11.3.0 Build 2806.0 <MD1.1>
BIG-IP 11.4.0 Build 2384.0 <MD1.2>
End User Diagnostics
TMOS maintenance

Information contained in the GRUB2 configuration file

The information contained in the configuration file is specific for loading the respective BIG-IP system software slot. The following table describes the components of the example output of the configuration file:

ComponentDescription
set default=<Value>Indicates which entry of the GRUB configuration will be the default software slot for the BIG-IP system to boot. A value of 0 indicates the first entry of the configuration will be the default configuration. A value of 1 indicates the second entry of the configuration will be the default.

Using our example GRUB configuration above, set default=0 indicates the first configuration stanza (BIG-IP 11.3.0 Build 2806.0 <MD1.1>.) will be the default boot option.
set timeout=<Value>The timeout in seconds specifies how long GRUB will wait before automatically booting the default=<Value> entry, according to the configuration file, if there is no user intervention.
menuentry <String>This line specifies a GRUB menu entry title name for the configured software slot. This information appears on the GRUB menu just as it is seen in the menu entry.
set root='<String>'This line specifies the hard disk and partition location where the kernel and initrd files are located.
linux <Filename> <Parameters>This line specifies the kernel file to be used and the parameters to use on load. For example:

linux /boot/1/vmlinuz ro root=UUID=7237fa64-e347-4bb7-a755-6e2617bd7c0e console=ttyS0 panic=1 platform=D110 quiet
initrd <Filename>This line specifies the desired initial ramdisk (initrd) to be used when loading the selected kernel entry. The initrd file loads an initial root file system to assist in the loading of a kernel.

Components of the linux command entry in GRUB2 configuration

The GRUB2 linux command commonly contains a filename that indicates the kernel file and may contain some parameters which will be used when loading the kernel. For example,

linux /boot/vmlinuz panic=1 quiet

The following table describes the components of the linux entry with the kernel specifications used by BIG-IP systems:

Line componentSpecification
/boot/<Value>/vmlinuzSpecifies the kernel filename found on the partition. The value in this component is the boot location number. For example, the kernel file is named /boot/1/vmlinuz.
roSpecifies that the root device is mounted as read-only on boot.
root=UUID=<Value>Indicates to the kernel which device is to be used as the root file system while booting. The UUID value depicts the unique identifier for this file system partition.
console=ttyS0Specifies the serial port to be used for console ttyS0=COM1.
panic=1Specifies the time, in seconds, that will cause the kernel to reboot if it panics.
platform=<Value>Identifies the hardware platform identifier to the kernel.
quietDisables the log messages during the boot process.
