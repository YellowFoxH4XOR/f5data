K11231202: ''Session deleted due to user inactivity.'' is missing in exported Access Report.

Type
Support Solution
Published
2020-05-26
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K11231202

Description

After APM session is terminated, the exported Access Report contains most of the logs which are in /var/log/apm, however, "Session deleted due to user inactivity." and some other logs are missing in the csv file.

Some details are missing from APM Access Report.

You can observe this by executing: Go to Access -> Overview -> Access Reports -> Choose a timeframe so that above session is covered -> Generate the report.
Click the "Export to CSV File", and open up the file. 

Environment

  • BIG-IP APM

Cause

None at time of publication.

Recommended Actions

To export the full logs from /var/log/apm, use external syslog/reporting servers.

BIG-IP Access Policy Manager and Splunk Templates
