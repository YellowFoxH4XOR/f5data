K000135905: unable to launch an app via Microsoft Remote Desktop Workspaces, when connected to the VPN

Source

Description

when connected to the VPN, user is unable to launch an app via Workspaces on the Microsoft Remote Desktop client, getting an error similar to the following:

Environment

  • Microsoft Remote Desktop Workspaces
  • VPN (split-tunnel)

Cause

In the Network Access resource in question, the "default-all" is not selected in the Dynamic LAN Address Spaces setting

 Recommended Actions

  1. Make sure "default-all" is selected for the Network Access resource in use. If not, move the address space from the Available list to the Selected list by clicking the << button


Note: By default, when creating a new Network Access resource, "default-all" is already placed in the 'Selected' list.
