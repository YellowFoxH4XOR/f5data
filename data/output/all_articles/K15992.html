Known Issue

The BIG-IP system may prematurely close SSL Session ID persistent connections.

This issue occurs when all of the following conditions are met:

  • The virtual server is configured with an SSL persistence profile.
  • A slow client side (WAN) connection causes a delay when the system is sending data to the client.

A rare race condition may allow for the BIG-IP system to process an SSL shutdown and close (FIN) an SSL Session ID persistent TCP connection before forwarding all data. A slow client side (WAN) connection can exacerbate this issue.

Impact

The TCP connection may prematurely close, and data will potentially be lost.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Clients who access a virtual sever that is configured to use SSL Session ID persistence may experience premature connection closure and page load failure issues.

Workaround

To work around this issue, you can configure the virtual server to use an alternate form of persistence other than SSL Session ID persistence.

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends that you test any such changes during a maintenance window with consideration to the possible impact on your specific environment.
