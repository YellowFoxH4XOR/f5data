Issue

Error Message

0107172d:3 Policy '<Policy_name>' can't be applied to virtual server 'Virtual_server_name' because it has no rules

In this error message, note the following:

  • <Policy_name> is the name of the policy.
  • <Virtual_server_name> is the name of the virtual server.

For example:

0107172d:3: Policy '/Common/policy_1' can't be applied to virtual server '/Common/vs_1' because it has no rules.

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility
  • The command line interface (CLI)
Description

This message occurs when the following condition is met:

  • You attempt to create or modify a BIG-IP LTM policy without specifying policy rules.

Impact

You are required to specify policy rules when creating or modifying an BIG-IP LTM policy.

Recommended Actions

None
