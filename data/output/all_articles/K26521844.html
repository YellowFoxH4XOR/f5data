Description

Traffic does not pass on tagged VLANs when a BIG-IP Virtual Edition (VE) is deployed on a Hyper-V hypervisor, after the Big-IP system is upgraded to v14.x or v15.x.

This is despite the fact that VLAN tagging worked fine in v13.x and below, and if the same VE is downgraded to v13.x, vlan tagging starts to work again.

Environment
  • BIG-IP VE
  • Microsoft Hyper-V
Cause

Bug ID 882709

Recommended Actions

Visit the BugTracker for Bug ID 882709 to see an explanation for this issue.
