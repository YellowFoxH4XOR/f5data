Topic

BIG-IP will load balance a protocol regardless of the port that it uses. For example, BIG-IP will load balance HTTP on its standard port (port 80) as well as on any other valid port, such as port 8080 or port 81. Additionally, BIG-IP can translate any custom port to port 80, so that clients are not required to specify a port when they connect to the site.

The following example output is from a virtual server that contains HTTP nodes on multiple ports:

pool WebServers {
members 10.90.100.11:80
members 10.90.100.12:80
members 10.90.100.11:81
members 10.90.100.12:81
members 10.90.100.11:8080
members 10.90.100.12:8080
}
virtual VS-A {
   pool WebServers
   destination 172.16.101.20:80
   ip protocol tcp
}

In this example, all clients will connect to the site using the 172.16.101.20 virtual server and port 80. BIG-IP will translate the destination port to 80, 81, or 8080, depending on the member that is selected.
