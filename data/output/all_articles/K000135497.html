K000135497: Security Guided Configuration stuck in deploying state and never completes

Type
Support Solution
Published
2023-10-17
Updated
2023-10-17
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.0.0
Source
https://my.f5.com/manage/s/article/K000135497

Description

Security Guided Configuration (SGC) is stuck in 'deploying' state when uses 'Web Application Protection' deployment. 

  • There is no error message regarding this deployment in restjavad and restnoded logs.
  • Restarting restjavad restnoded tomcat daemons doesn't help.
  • When trying to delete it in iApps ›› Application Services : Applications LX, an error message pops up: "Unable to delete block xxxx with state BINDING" . (xxxx is the name of security guided configuration)

Environment

  • BIG-IP ASM
  • Security Guided Configuration

Cause

This is an expected behavior.

Before a BINDING block can be deleted it must first be patched to ERROR state. All ERROR blocks should then be deleted.

 Recommended Actions

We can use below workaround to delete the Guided Configuration Deployment.

1. Get the id of the affected SGC.
# restcurl -u username:password /shared/iapp/blocks?\$select=name,id,state | grep -i xxxx -A1 -B1 <---replace xxxx with the SGC name
2. After that, try to send a patch command to change the state to ERROR.
# restcurl -u username:password -X PATCH -d '{"state" : "ERROR"}' /shared/iapp/blocks/yyyyyyyy   <--replace yyyyyyyy with the id you get in step 1.
3. If PATCH is successful, please delete the deployment with below command.
# restcurl -u admin:admin -X DELETE /shared/iapp/blocks/yyyyyyyy   <--replace xxxxx with the id you get in step 1.

If you see an error on the first PATCH command, please contact F5 Support to open a support case to troubleshoot the issue.
