Description

  • Upgrade fails to create UCS file during the software upgrade process resulting in a failed upgrade
  • Install is hanging at 99% then failing

    You may notice the log message under /var/log/liveinstall.log

info: Configuration save retries remaining: 1
error: status 256 returned by command: F5_INSTALL_SESSION_TYPE=install tmsh -f save sys ucs /var/tmp/ooMK294m0D.ucs
info: >++++ result:
info: Saving active configuration...
info: Unexpected Error: Can't write temp config file "bigip.conf", in temp dir "/.config.tmp/WgDc5f", No space left on device
info: Error during config save.
info: Unexpected Error: UCS saving process failed.
info: >----
Terminal error: See /var/log/liveinstall.log
*** Live install end at 2018/02/23 20:10:12: failed (return code 9) ***
[LTM1.example.com:INOPERATIVE:Standalone] ~ #
Broadcast message from root (Fri Feb 23 20:12:02 2018):
011d0004: Disk partition _root_ has only 0% free

Environment

  • BIG-IP
  • Software Upgrade
  • UCS
  • Disk Space

Cause

Root partition has not enough space remaining.

Recommended Actions

Clean up old files to free space, or move files to a different directory

Example: /shared/tmp

 For additional information to maintain disk space refer K14403
