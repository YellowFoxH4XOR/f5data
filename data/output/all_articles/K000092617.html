Description

When creating a vCMP guest instance on a BIG-IP system, messages similar to the following may appear on the console:

kvm [22621]: vcpu0 ignored rdmsr: 0x1c9

Environment

  • BIG-IP
  • vCMP

Cause

This issue is tracked in Bug ID761649.

Recommended Actions

These log messages occur only during guest creation. They are benign and can be safely ignored.
