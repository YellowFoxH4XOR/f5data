Issue

Beginning in ARX versions 5.0.6 and later, the number of NFS ACLs supported by an ARX system increased from 512 to 1024.

Note: ARX versions prior to 5.0.6 do not enforce the 512 limit for the number of NFS ACLs. However, these versions have not been tested to support greater than 512 NFS ACLs.

F5 Networks Product Development tracked this change as ID 38739 and it was introduced in ARX version 5.0.6. For information about upgrading, refer to the ARX Release Notes.
