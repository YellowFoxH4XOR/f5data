K51529001: Not able to enable/disable pool members in BIG-IQ due to ''pending import conflicts''

Type
Support Solution
Published
2020-06-02
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.X.X, 6.X.X
Source
https://my.f5.com/manage/s/article/K51529001

Description

Option for enabling and disabling pool members is grayed ( GUI > Configuration > Local traffic > Pool Members )

Information in GUI above pool members :
Device "<device hostname>" has pending import conflicts. Editing is not allowed until they are resolved.
 Each time when Administrator goes to pool members we see information about pending import conflicts.
 Each time when he import device another appears in the warning.

Environment

  • BIG-IQ Centralized Management
  • LTM Configuration imported
  • Disabling/Enabling pool members in Configuration tab

Cause

Conflicts is imported configuration

Recommended Actions

Rediscover and Re-Import configuration from all devices using following procedure:
  1. Go to Devices tab in GUI
  2. Mark all BIG-IPs > More... button  > Rediscover and Re-Import
  3. Wait until it finish
  4. Check Configuration > Local Traffic > Pool members if option to disable/enable is working
Additional Information

None
