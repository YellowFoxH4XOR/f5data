Issue

You may see the following error message in the HTTP logs:

Mon Apr 20 18:29:32 2009     error            [client 172.28.25.230] File does not exist: /usr/local/uroam/firepass/my/favicon.ico

You can safely ignore this error message; no actual error occurred that requires attention. This error message occurs when a user attempts to connect to a FirePass controller or BIG-IP SAM from a new tab in Firefox. The browser sends a GET request for favicon.ico and FirePass logs the above error message because the URL does not exist.
