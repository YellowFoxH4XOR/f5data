K000133151: Session Mirroring cause HA unstable

Type
Support Solution
Published
2025-09-04
Updated
2025-09-04
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.1.3
Source
https://my.f5.com/manage/s/article/K000133151

Description

After implementing Mirroring and persistence on the BIG IP. Noticed repeatedly with the following:

From Standby:

err tmm1[18719]: 01340002:3: HA Connection with peer X.X.X.X:XXXX for traffic-group /Common/traffic-group-1 lost.

err tmm1[18719]: 01340001:5: HA Connection with peer X.X.X.X:XXXX for traffic-group /Common/traffic-group-1 established.

err tmm1[18719]: 01340002:3: HA Connection with peer X.X.X.X:XXXX for traffic-group /Common/traffic-group-1 lost.

err tmm1[18719]: 01340001:5: HA Connection with peer X.X.X.X:XXXX for traffic-group /Common/traffic-group-1 established.

 

From Active:

err tmm1[18719]: 01340001:5: HA Connection with peer X.X.X.X:XXXX for traffic-group /Common/traffic-group-1 established.

err tmm1[18719]: 01340001:5: HA Connection with peer X.X.X.X:XXXX for traffic-group /Common/traffic-group-1 established.

err tmm1[18719]: 01340001:5: HA Connection with peer X.X.X.X:XXXX for traffic-group /Common/traffic-group-1 established.

err tmm1[18719]: 01340001:5: HA Connection with peer X.X.X.X:XXXX for traffic-group /Common/traffic-group-1 established.

err tmm1[18719]: 01340001:5: HA Connection with peer X.X.X.X:XXXX for traffic-group /Common/traffic-group-1 established.

Environment

  • BIG IP
  • Implemented with Mirroring and Persistence
  • 1GB line between Active and Standby
  • Data interfaces is based on LACP with 2 interfaces 40G each

Cause

Found traffic peak in the mirroring port that exceeded the 1GB line.

Recommended Actions

Changing the mirroring port to 10G , the error has stopped .
