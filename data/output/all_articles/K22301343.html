Description

If you have previously increased the size of the /var folder, when you upgrade the size will be reduced back to the default value. 

Note: Beginning in BIG-IP 16.0.0, the logical volume size for the /var partition is increased by 50%. For more information, refer to K53259232: The /var partition size is increased by 50% in BIG-IP 16.0.0 and later.

Environment

  • BIG-IP
  • /var increase

Cause

K41836606: /var folder size decreases automatically after upgrade

Recommended Actions

Prevent the /var folder from being returned to the default 3 GB size on upgrade by creating the global_attributes file in the version being upgraded from. This example increases the /var folder size to 4 GB, you may need to adjust this accordingly.

Procedure:

  1. Create the /shared/.tmi_config directory by entering the following command:
    mkdir /shared/.tmi_config
  2.  Create /shared/.tmi_config/global_attributes with the following line:
    { "TMI_VOLUME_FIX_VAR_MIB" : "<SIZE_IN_MIB>" }

    For example,
    echo '{ "TMI_VOLUME_FIX_VAR_MIB" : "4096" }' > /shared/.tmi_config/global_attributes
  3. Install new software as per normal.
  4. Boot to new volume and confirm /var is updated with the new size.

On multi-blade cluster systems like VIPRION, vCMP guests, and VELOS tenants, the global_attributes file needs to created on every cluster members (blades). Prepend clsh to each command.

  1. Create the /shared/.tmi_config directory by entering the following command:
    clsh mkdir /shared/.tmi_config
  2.  Create /shared/.tmi_config/global_attributes with the following line on all cluster members:
    { "TMI_VOLUME_FIX_VAR_MIB" : "<SIZE_IN_MIB>" }

    For example,
    clsh 'echo { \\\"TMI_VOLUME_FIX_VAR_MIB\\\" : \\\"4096\\\" } > /shared/.tmi_config/global_attributes'
  3. Install new software as per normal.
  4. Boot to new volume and confirm /var is updated with the new size.

Important: Do note that this process has to be performed before every upgrade if the /var/ partition size needs to be retained. The /shared/.tmi_config/global_attributes file will not be transferred to the new OS and will have to be recreated each time by following the process above.

Additional Information

You can use this procedure on the following BIG-IP platforms:

  • Hardware-based appliances and VIPRION systems
  • BIG-IP VE systems
  • BIG-IP vCMP guests
  • F5OS-A/C tenants
