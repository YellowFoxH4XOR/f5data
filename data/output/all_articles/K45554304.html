K45554304: Meta-characters suggestions for HTTP Header differ from URL meta-Characters

Type
Support Solution
Published
2021-01-07
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.X.X, 14.X.X, 16.1.X, 16.0.X, 15.1.X, 15.0.X, 14.1.X, 14.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 15.X.X, 15.0.0, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.0, 14.0.1, 14.0.0, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.1, 16.0.0, 15.0.1
Source
https://my.f5.com/manage/s/article/K45554304

Description

  • Uncommon header names can result in AWAF meta-characters suggestion
  • For example, "Referer" & "User-Agent" of the HTTP-Header may contain meta-characters suggestion from a AWF policy
  • If such meta-characters are Allowed in HTTP-Headers, will these meta-characters be applied to URLs?

Environment

  • ASM
  • HTTP-Header 
  • BIG-IP

Cause

  • Allowing or disallowing such meta-characters relating to HTTP HEADER, has NO bearing to URL meta-characters

Recommended Actions

  • None

Additional Information

  • To check meta-character settings for HTTP-Headers, navigate 
    • Security ›› Application Security : Headers : Character Set
  • To check meta-character settings for URL, navigate
    • Security  ››  Application Security : URLs : Character Set, which is different from Header meta-characters.
