Topic

The default behavior of the BIG-IP ASM is to block and report Request For Comment (RFC) compliance violations in order to prevent improper requests from being sent to the server. The BIG-IP ASM system blocks and reports HTTP requests containing non-RFC compliant cookies. When the BIG-IP ASM system detects a non-RFC compliant cookie in a client HTTP request, the request is blocked and the following error message is logged to the Reporting screen and the /var/log/asm log file:

Not RFC compliant cookie

HTTP cookies containing one or more of the following components will generate this error message:

  • Double quotes in the cookie name.
  • A space in the cookie name.

    Note: A space between the cookie name and the equal sign ( = ), and between the equal sign ( = ) and cookie value is allowed.

  • An equal sign ( = ) before the cookie name.
  • A cookie with or without an equal sign ( = ) and no cookie value.
  • A carriage return (hexadecimal value of 0d) in the cookie name.

Note: A line feed (HEX value of 0a) in a cookie name does not generate the not RFC compliant cookie error message. By default, the BIG-IP ASM system interprets a cookie name containing a line feed character as an HTTP header name with no header value. For more information, refer to K5713: Configuring a Non-RFC enforcement mask.

Adjusting the Cookie not RFC-compliant violation

BIG-IP ASM 12.0.0 and later

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. Select the policy from the Current edited policy menu.
  4. To the right of the General Settings section, select Advanced from the drop-down list.
  5. Click the triangle to the left of the Cookies link to expand the list of subviolations.
  6. Make the appropriate change for the Cookie not RFC-compliant violation.
  7. Click Save.
  8. Click Apply Policy.

BIG-IP ASM 10.0.0 - 11.6.x

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to the Blocking menu page:

    BIG-IP ASM 11.3.0 - 11.6.x

    Security > Application Security > Blocking > Settings

    BIG-IP ASM 10.0.0 - 11.2.1

    Application Security > Policy > Blocking > Settings

  3. Click the Active Security Policy you want to edit.
  4. In the RFC Violations section, make the appropriate change for the Cookie not RFC-compliant violation.
  5. Click Save.
  6. Click Apply Policy.
