K25390406: TMOS upgarde from v12.1.x fails with an error ''Could not access configuration source; sda, X''

  • BIG-IP
Source

Description
You install v12.1.x in a new volume. From the v12.1.x volume, you upgrade the TMOS to v13.1.x or later for the first time.

The upgrade fails with an error message similar to the following:
"Could not access configuration source; sda, X"

A log message similar to the following is logged to /var/log/liveinstall.log:
error: tm_install::VolumeSet::VolumeSet_open -- No volumes exist for sda.3 volume set

Environment

  • BIG-IP
  • Upgrade

Cause
Bug ID 759499

Recommended Actions

As a workaround, you can delete the newly installed volume (v13.1.x and later) and try the installation again.

Additional Information

  • K13600166 Error Message : "failed (Could not access configuration source; sda, 1 )" error during a BIG-IP software upgrade
