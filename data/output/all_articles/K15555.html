Known Issue

The DNS and NTP commands may cause the Traffic Management Shell (tmsh) to exit and produce a core file.

This issue occurs when the following condition is met:

  • You use tmsh to add DNS name servers or NTP servers to the system configuration.

    For example:

    tmsh modify /sys dns name-servers add { <IP address> }

    tmsh modify /sys ntp servers add { <IP address> }

Impact

The tmsh utility becomes temporarily unresponsive.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H477083 on the Diagnostics > Identified > Medium screen.
  • When using the tmsh utility to add DNS name servers or NTP servers to the system configuration, the system displays an error message that appears similar to the following example:

    Segmentation fault (core dumped)

  • The tmsh utility becomes temporarily unresponsive.
  • The tmsh utility core files are located in the /shared/core directory, and appear similar to the following example:

    /shared/core/tmsh.bld635.0.core.gz
