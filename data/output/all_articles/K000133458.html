Description

  • You create following outbound virtual server for the ISP link and expect internal host can visit the Internet through this virtual server.

ltm virtual /Common/vs_outbound {
  destination /Common/0.0.0.0:0
  mask any
  pool /Common/gw_isp
  profiles {
    /Common/fastL4 { }
  }
  source 192.168.11.0/24
  translate-address enabled
  translate-port enabled
  vlans {
    /Common/vlan_internal
  }
  vlans-enabled
}

  • While internal host can not visit the Internet through the outbound virtual server on BIG-IP.
  • It works when you bypass BIG-IP.

Environment

  • BIG-IP LC/LTM
  • ISP link load balancing
  • Outbound visiting for internal hosts

Cause

The translate-address and translate-port are used for destination address and destionation port translation. They are enabled by default, this makes the server side destination address translated to the ISP gateway address, instead of your real Internet destination address.

Recommended Actions

Disable the translate-address and translate-port to resolve this problem.
