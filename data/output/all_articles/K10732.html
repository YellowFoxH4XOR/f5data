Known Issue

This is the result of a known issue. Each BIG-IP platform has a maximum number of VLANs it can be configured with; however, the mcpd process is incorrectly limiting the maximum number of VLANs to one less than the number supported by the platform.

For example, the BIG-IP 1500 platform supports a maximum of 4094 VLANs; however, due to this issue, the mcpd process does not allow the creation of more than 4093 VLANs. If an attempt is made to create one more VLAN, the BIG-IP system returns an error that appears similar to the following example:

BIGpipe VLAN operation error:
   01070085:3: Cannot create VLAN example4094, maximum limit reached

Note: For more information about VLAN limits, refer to K3539: The maximum number of configurable VLANs.

Note: The issue described in this Solution refers to the total count of VLANs that can be configured, not the TAG that can be assigned to them. The actual TAG assigned to a VLAN is irrelevant to this issue.

Important: The BIG-IP system may take a long time to load a configuration that features many VLANs. For more information, refer to K9628: Switchboard failsafe may be triggered when loading a large number of VLANs.

F5 Product Development is tracking this issue as ID 247747 (formerly CR132047).
