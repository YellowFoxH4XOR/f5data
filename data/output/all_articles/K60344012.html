To upgrade the VCMP host and guest via Big IQ

-Upgrade the vCMP host directly from the device

follow K14166297: BIG-IP update and upgrade guide | Chapter 11: Update or upgrade BIG-IP VIPRION systems (vCMP)


-Upgrade the vCMP guests via the BIG-IQ

IMPORTANT (Prerequisites):

Complete the following tasks before you start upgrading your VIPRION systems:

  • Backup UCS of all guest before upgrading the Host. - K13132: Backing up and restoring BIG-IP configuration files with a UCS archive
  • Backup UCS of the host - K13132: Backing up and restoring BIG-IP configuration files with a UCS archive
  • Secure the master key for each guest - K9420: Installing UCS files containing encrypted passwords or passphrases (11.5.x and later)
  • Copy the intended ISO to  /shared/images on each vCMP guest. It is faster that letting BIG-IQ transfer the image from BIG-IQ itself
  • Verify that the management interface for each slot is physically wired to an external switch, so that you can maintain connectivity to the management port if the primary blade designation changes during the update.
  • Consult K9476: The F5 hardware/software compatibility matrix to ensure you upgrade to a BIG-IP version that is compatible with your VIPRION platform.
  • For vCMP systems, consult K14088: vCMP host and compatible guest version matrix to ensure you upgrade your host and guests to BIG-IP versions that are compatible.
  • Consult K13845: Overview of supported BIG-IP upgrade paths and an upgrade planning reference to identify the BIG-IP versions that you can upgrade to from your current version of BIG-IP.
  • Review the release notes for the version you want to install.
  • F5 recommends that you reactivate the host license before you upgrade. However, you can verify the service check date for the license to see if you need to reactivate it. For more information, refer to K7727: License activation may be required before a software upgrade for the BIG-IP or Enterprise Manager system.
  • Consult K02251382: B2250 VIPRION Fails to boot After Upgrade to 13.1.3.3 or 13.1.3.4 if you have a VIPRION B2250 blade and you are upgrading your host to BIG-IP 13.1.3.3 or 13.1.3.4. Note that this only applies to hosts and not guests.



To put the guest in provision mode before we upgrade the Host

NOTE:
BIG-IQ does not act as vCMP Host, you have to configure the state of the vCMP guest from the vCMP host


as per K15930: Overview of vCMP configuration considerations:

Before restarting or upgrading a host system, you should perform a graceful shutdown of all guest systems running on the host. To do so, perform the following procedure:

  • Log in to the host system's Configuration utility.
  • Go to vCMP > Guest List.
  • Select the name of the guest system you want to shut down.
  • For Requested State, select Configured.
  • Select Update.



To check and renew license of Big IP via Big-IQ


as stated in K15930: Overview of vCMP configuration considerations:

  • Guest inherits the license of the vCMP host and the host license must include all BIG-IP modules that you plan to provision on vCMP guest instances.


as stated in K59429712: Impacts of adding/reactivating license to vCMP host:

  • Add/reactivate the license on the host while all the guests are in Standby/Offline status in a maintenance window.
