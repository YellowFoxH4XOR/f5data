Issue

Error Message

tmm [<PID>]: 01010310:3: Incomplete hud chain for listener: <%s>

In this error message, note the following:

  • <PID> is the process ID for the Traffic Management Microkernel (TMM) process.
  • <%s> is name of the listener object.

For example:

tmm7[3073]: 01010310:3: Incomplete hud chain for listener: /Common/My_vs

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file.

Description

This message occurs when one of the following conditions is met:

  • The same client-side and server-side protocol profile is assigned to the virtual server. 
  • The virtual server protocol setting (ip-protocol) does not match the client-side or server-side protocol profile, or the client or server protocol profile assignment is missing from the virtual server configuration. For example, the following virtual server is configured with an ip-protocol of TCP, but the client protocol profile assignment is missing:

    ltm virtual MyVip {
        destination 10.1.1.2:http
        ip-protocol tcp
        mask 255.255.255.255
        profiles {
            request-log { }
        }
        source 0.0.0.0/0
        translate-address enabled
        translate-port enabled
        vs-index 2
    }

Impact

  • The configuration may fail to load.
  • Connections to the virtual server may fail.

Recommended Actions

Review the affected virtual server configuration and verify the following:
  • Make sure the appropriate client-side and server-side protocol profiles are assigned to the virtual server. 
  • Make sure the virtual server protocol setting (ip-protocol) matches the client-side and server-side protocol profiles and that the client or server protocol profile assignment is not missing from the virtual server configuration.
