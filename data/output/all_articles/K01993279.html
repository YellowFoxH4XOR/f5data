Known Issue

Secondary blades may enter a reboot loop when the gateway fail-safe feature is enabled.

This issue occurs when all of the following conditions are met:

  • You have a VIPRION system with multiple blades installed.
  • You have enabled the gateway fail-safe feature.
  • A secondary blade has been shut down.
  • You modify the pool used by the gateway fail-safe object. For example, the applied monitor is changed.
  • The secondary blade is turned on and attempts to join the cluster.

    Note: This issue may also occur if the pool is modified while the secondary blade reboots.

Impact

Cluster redundancy is degraded while the secondary blade remains in a reboot loop.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The secondary blade fails to join the cluster after being turned on.
  • An error message similar to the following example appears in the /var/log/ltm file:

    slot2 err mcpd[6789]: 01070734:3: Configuration error: Configuration from primary failed validation: 01020036:3: The requested monitor instance (/Common/example_gw 192.168.10.10 ltm-pool-member) was not found.

Resolution

Status

F5 Product Development has assigned ID 505037 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. Workaround

To work around this issue, you can remove the gateway pool prior to turning on or rebooting the secondary blade. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > High Availability > Fail-safe > Gateway.
  3. Under the Name column, select the gateway pool object.
  4. Note the selections for the following Configuration settings:
    • Gateway Pool
    • Device
    • Threshold
    • Action
  5. Click Remove.
  6. Turn on the secondary blade.
  7. Navigate to System > High Availability > Fail-safe > Gateway.
  8. Click Add.
  9. Use the Configuration settings noted in step 4 to recreate the gateway pool object.
  10. Click Finished.
