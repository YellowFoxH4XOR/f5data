Description

You currently have both IMDSv1 and IMDSv2 enabled for your BIG-IP VE virtual machine in the AWS EC2 Console and you are planning to use only IMDSv2 in the future. Do any steps need to be taken on the BIG-IP system when disabling IMDSv1 ? For instance, does the BIG-IP system or any of the running daemons need to be restarted?

Environment

  • BIG-IP VE
  • AWS

Cause

None

Recommended Actions

BIG-IP VE version 16.1.2.1 and later can use IMDSv2.

If running a BIG-IP VE system with an appropriate version, you can safely disable IMDSv1 in the AWS EC2 Console during operation. No extra steps are necessary on the BIG-IP VE system to complete the switch from IMDSv1 to IMDSv2.

Additional Information

ID968657 adds full support for IMDSv2 in BIG-IP VE.
