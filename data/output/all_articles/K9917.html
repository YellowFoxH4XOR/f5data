Known Issue

This is the result of a known issue. You can configure the BIG-IP WebAccelerator system to insert the Via HTTP header into an HTTP request or response by modifying the sendProxyViaHeader entry in the pvsystem.conf file.

Note: For more information about configuring the BIG-IP WebAccelerator to insert the Via HTTP header into HTTP requests or responses, refer to K7589: Overview of the Via HTTP header.

If a request already contains a Via header, and the inRequest field is not set to true, the BIG-IP WebAccelerator system will remove the existing header from the client request.

F5 Product Development tracked this issue as CR117407 and it was fixed in BIG-IP 9.4.7 and 10.0.1.  For information about upgrading, refer to the BIG-IP WebAccelerator release notes.
