Issue

Error Message

01070734:3: Configuration error: DB validation exception, unique constraint violation on table (gtm_wideip_alias) object ID (1 <partition_name/wide_IP_name alias_name>). A duplicate value was received for a non-primary key unique index field. DB exception text (Cannot update_indexes/checkpoint DB object, class:gtm_wideip_alias status:13)

In this error message, note the following:

  • <partition_name/wide_IP_name alias_name> is the partition name followed by the wide IP and wide IP alias names.

For example:

01070734:3: Configuration error: DB validation exception, unique constraint violation on table (gtm_wideip_alias) object ID (1 /Common/aaaa.internal.net alias.internal.net). A duplicate value was received for a non-primary key unique index field. DB exception text (Cannot update_indexes/checkpoint DB object, class:gtm_wideip_alias status:13)

Message Location

You may encounter this message in the following location:

  • In the Configuration utility, go to DNS > GSLB > Wide IPs.

Description

This message occurs when the following condition is met:

  • You attempt to define a wide IP alias for a wide IP of a particular record type (for example, A) that matches an alias configured for an existing wide IP of the same type.

Although you cannot define a wide IP alias that matches an alias configured for an existing wide IP of the same type, you can define a wide IP alias for a wide IP that matches an alias configured for an existing wide IP of a different type. However, doing so moves the CNAME record associated with the alias from the existing wide IP to the new wide IP.

Impact

The wide IP alias is not created.

Recommended Actions

None
