Description

When performing a vulnerability scan or connecting to the management IP of a BIG-IP system via SSH or using tools like nmap or telnet on port 22, the SSH version banner is displayed. The banner typically includes information such as:

SSH-2.0-OpenSSH_7.4

This behavior may raise concerns about security and whether it is possible to hide or disable this banner.

Environment

  • Product: BIG-IP
  • Configuration Details: Default SSH configuration with no custom modifications to the SSH daemon (sshd).

Cause

The display of the SSH version banner is mandated by the Secure Shell (SSH) protocol as defined in RFC 4253. Specifically, Section 4.2 of RFC 4253 states :

"When the connection has been established, both sides MUST send an identification string. This identification string MUST be SSH-protoversion-softwareversion SP comments CR LF."

This identification string ensures interoperability between devices from different vendors and is a fundamental requirement for compliance with the protocol standard. As a result, the inclusion of this banner (e.g., SSH-2.0-OpenSSH_7.4) is not optional and cannot be disabled without violating RFC compliance.

Recommendations

Understand that displaying the SSH version banner is required for compliance with RFC 4253 and cannot be customized, hidden, or disabled in F5's implementation of SSH.

If there are concerns about exposing software version details during vulnerability scans:

  • Ensure that access to management interfaces (e.g., management IPs) is restricted using proper network segmentation and firewall rules.
  • Limit access to trusted sources only.
  • Regularly update your BIG-IP system to ensure it runs supported versions with all relevant security patches applied.
