Known Issue

This is the result of a known issue. When you open the Reports: System Logs page in the FirePass Administrative Console, your browser may time out before any information displays on the page. This issue occurs when one or more of the archived system log files from the current month is larger than 16,557,971 bytes.

F5 Product Development tracked this issue as CR68382 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Workaround

You can reduce the occurrence of this issue in FirePass version 6.0.1 by configuring lower log levels in the Logging Options section on the Device Management: Maintenance: Logs page. For example, the Information log level creates the highest volume of logs and CPU utilization, while the Emergency log level creates the lowest volume.

Note: The Logging Options feature was introduced in FirePass version 6.0.1; therefore, you cannot perform this workaround on FirePass software versions prior to 6.0.1.

To determine which log level to use, refer to the descriptions of each log level listed in the FirePass online help on the Device Management: Maintenance: Logs page. Lower log levels are recommended for day-to-day use, while higher log levels can be useful for testing or troubleshooting. For example, you may want to set the Application Access log level to Information while troubleshooting a specific application issue, then set the log level to Critical for day-to-day use.
