Known Issue

The value for current connections differ between the Traffic Management Shell (tmsh) and SNMP output.

This issue occurs when all of the following conditions are met:

  • You have the Multipath TCP (MPTCP) option set in a TCP profile, and the profile is assigned to a virtual server.
  • You compare the output from the tmsh show sys conn command to the returned value from the corresponding SNMP OID .1.3.6.1.4.1.3375.2.1.1.2.1.8.0 for current connections.

Impact

The values returned by way of SNMP may be up to 10 seconds behind the tmsh value.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The SNMP values differ from the tmsh values.
