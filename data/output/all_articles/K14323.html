Known Issue

A Virtual Local Area Network (VLAN) with a name longer than 64 characters when combined with the partition name may cause the Traffic Management Microkernel (TMM) process to dump core files. This issue occurs when one of the following conditions is met:

  • The affected VLAN is configured on an affected version.
  • A BIG-IP 10.x system is upgraded to an affected version.
  • A user configuration set (UCS) archive file that is taken from a BIG-IP 10.x system is installed on an affected version.

For example, a VLAN with the name vlan12345678901234567890123456789012345678901234567890123 residing in the common partition has a total of 65 characters when combined with the partition name (/Common/vlan12345678901234567890123456789012345678901234567890123).

Impact

The BIG-IP system may temporarily fail to process traffic and fail over if configured as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The TMM process terminates with a SIGFPE and restarts, resulting in an interruption of traffic.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system logs a panic string to the /var/log/tmm file that appears similar to the following example:

    panic: ../mcp/db_net.c:1894: Assertion "IFC found" failed.

  • The BIG-IP system fails over to the peer system.

Workaround

To work around this issue, you can delete the affected VLAN name and recreate the VLAN with a name that has 64 characters or less when combined with the partition name. To do so, perform the following procedure:

Impact of workaround: You have to disassociate any objects, such as self IP address, from the affected VLAN before it can be deleted.

  1. Log in to the Configuration utility.
  2. Ensure that no object, such as self IP address, is referencing the affected VLAN.
  3. Navigate to Network > VLANs > VLAN List.
  4. Check on the affected VLAN name.
  5. To initiate the removal, click Delete.
  6. To confirm the removal of the affected VLAN, click Delete.
  7. To recreate the VLAN, click Create.
  8. Enter the desired new name and ensure that it is not more than 64 characters when combined with the partition name.
  9. Configure the remaining options as desired.
  10. To save the changes, click Finished.
