Topic

You should consider using this procedure under the following condition:

  • You want to upgrade the external PostgreSQL 9.5 database deployed for NGINX Controller to PostgreSQL 12.

Description

Starting in NGINX Controller 3.9.0, PostgreSQL 12 is supported in parallel with 9.5. This article explains how to upgrade your external PostgreSQL 9.5 database deployment to PostgreSQL 12 for NGINX Controller 3.9.0 or later.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have command line access to run the helper.sh utility on the NGINX Controller system.
  • You have administrative access to the host system on which you want to upgrade the PostgreSQL database.

Procedures

Upgrading NGINX Controller external PostgreSQL

Before upgrading the linked PostgreSQL, you must stop the NGINX Controller service temporarily. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure involves stopping NGINX Controller, which temporarily interrupts the NGINX Controller services. F5 recommends performing this procedure during a scheduled maintenance window.

  1. Log in to the command line of the NGINX Controller system.
  2. To run the helper.sh utility and stop NGINX Controller, enter the following command:

     /opt/nginx-controller/helper.sh controller stop

  3. To upgrade the external PostgreSQL instance, follow the instructions in the Usage section of the official PostgreSQL 12 upgrade utility guide: pg_upgrade.
  4. After you upgrade the PostgreSQL database, run the helper.sh utility and start NGINX Controller by entering the following command:

    /opt/nginx-controller/helper.sh controller start

    Note: If any of the database configurations change during the upgrade, such as the IP address or service port, apply the change to the NGINX Controller by entering the following command:

    /opt/nginx-controller/helper.sh configdb
