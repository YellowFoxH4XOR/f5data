Known Issue

This is the result of a known issue. The Configuration utility will fail to display the throughput performance graphs if at least one of the following license enumerators has a value of UNLIMITED:

  • perf_SSL_total_TPS
  • perf_SSL_Mbps
  • perf_http_compression_Mbps

When a BIG-IP administrator attempts to display this page (located at Overview > Performance > Throughput), the Configuration utility will return the following error message:

Error trying to access the database.

Additionally, a message that appears similar to the following example will be logged to the /var/log/ltm file:

bigip1 statsd[2043]: 011b030d:3: Graph 'SSLTPSGraph' not found

The following table explains the license enumerators involved in this issue:

EnumeratorDescriptionMeasurement unit
perf_SSL_total_TPSSSL transactions per second (new and resumes)1 UNIT = 1 TPS
perf_SSL_MbpsSSL throughput1 UNIT = 1 Mbit/s
perf_http_compression_MbpsHTTP compression throughput1 UNIT = 1 Mbit/s

Note: To determine the value of the license enumerators mentioned in this article, execute the following command from the BIG-IP command line:

grep "perf_SSL_total_TPS :\|perf_SSL_Mbps :\|perf_http_compression_Mbps :" /config/bigip.license

F5 Product Development tracked this issue as ID 210526 and ID 249349 (formerly CR126195) and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

In November 2009, F5 also fixed this issue by making changes to the license server. If upgrading to BIG-IP 10.1.0 or later is not an immediate option, you can resolve this issue by re-activating the license of the BIG-IP system.

Note: You can re-activate the license of the BIG-IP system at any time by using the System > License screen in the Configuration utility. For more information, refer to the BIG-IP Systems: Getting Started Guide or K7752: Overview of licensing the BIG-IP system.
