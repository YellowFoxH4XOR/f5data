Issue

Error Message

After upgrading a VIPRION chassis that contains B4100 blades to BIG-IP 10.2.4 or later, the system logs messages to the /var/log/ltm file that appear similar to the following example:

chmand[3415]: 012a0005:5: >>>**********CAN PIC - CAN1 PIC **********>>>

chmand[3415]: 012a0006:6: ids: PIC=8, SPR=9 (local blade host pic)

chmand[3415]: 012a0006:6: PIC version is 2.17 (bootloader:1.18)

chmand[3415]: 012a0006:6: Looking for latest bitstream in dir /usr/firmware

chmand[3415]: 012a0006:6: Found disk version 5.02

chmand[3415]: 012a0005:5: CAN1 PIC bootloader (v1.18) is not supported.

chmand[3415]: 012a0005:5: CAN1 PIC bootloader version 1.20 or later is required to upgrade the firmware to v5.02.

These messages are indicative of the CAN PIC firmware-update failing. This issue is due to the bootloader version on the B4100 blade, which is version 1.18. A bootloader version of 1.20 or later is required to update the CAN PIC firmware to the version included with BIG-IP 10.2.4 and later. However, there is no specific requirement to upgrade the firmware on the B4100. You can safely ignore these messages.

Message Location

You may encounter these messages in the following location:

  • /var/log/ltm

Description

These messages occur when the following condition is met:

  • You upgrade a VIPRION chassis that contains B4100 blades to BIG-IP 10.2.4 or later.

Impact

You can safely ignore these messages.

Recommended Actions

None
