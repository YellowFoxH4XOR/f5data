Description

The BIG-IP Configuration utility is a browser-based user interface for the configuration of a BIG-IP system. You can access the BIG-IP Configuration utility through either the management IP address or the self IP address configured for the BIG-IP system from a workstation that has network access to either of these addresses.

Environment

  • A BIG-IP system configured with either a management IP address or a self IP address or both.
  • A workstation with network access to either the BIG-IP management IP address or self IP address or both.
  • Administrative account login to the BIG-IP system.

Cause

None.

Recommended Actions

From the workstation that has network access to either the BIG-IP management IP address or self IP address or both, you should launch a web browser and enter the following URL:

https://<management or self IP address>/

Replace the <management or self IP address> with either the BIG-IP management IP address or the self IP address. Your web browser should display the BIG-IP Configuration utility login screen similar to the following example:
