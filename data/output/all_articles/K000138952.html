Description

Learning suggestions for a centrally managed ASM policy via BIG-IQ are showing up for IP addresses which are in the IP Address Exceptions list and which has been configured with "Ignore in Learning Suggestions".

Environment

  • BIG-IP ASM
  • BIG-IQ CM
  • BIG-IQ DCD
  • Route Domains

Cause

  • The IP address exception configured does not have the necessary route domain suffix for the policy to exclude the client from policy building.

Recommended Actions

Define the IP address or subnet with the correct route domain suffix. For example, the format for IP address 10.10.10.0/30 in route domain 1 should have an entry that looks 10.10.10.0%1 with Netmask 255.255.255.252 in the IP Address Exceptions list.
