Description

During a BIG-IP software upgrade, one or all of the following error messages appears:

  • Configuration utility (GUI)
    The configuration has not yet loaded. If this message persists, it may indicate a configuration problem
  • /var/log/liveinstall.log
    info: Saving active configuration...
    info: Unexpected Error: Configuration cannot be saved unless mcpd is in the running phase. Save was canceled. See "show sys mcp" and "show sys service". If "show sys service" indicates that mcpd is in the run state, but "show sys mcp" is not in phase running, issue the command "load sys config" to further diagnose the problem.
    info: Error during config save.
    info: Unexpected Error: UCS saving process failed.
  • /var/log/ltm
    err mcpd[4394]: 01070712:3: Caught configuration exception (0), Unable to verify key (/Common/f5_api_com.key) is protected by provided passphrase..
    emerg load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all " - failed. -- 01070712:3: Unable to verify key (/Common/f5_api_com.key) is protected by provided passphrase. Unexpected Error: Loading configuration process failed.
  • tmsh load sys config verify
    01070712:3: Unable to verify key (/Common/f5_api_com.key) is protected by provided passphrase.
    Unexpected Error: Loading configuration process failed.

For more information about the f5_api_com certificate and key, refer to K000140246: What is the purpose of the f5_api_com certificate?

Environment

  • BIG-IP
  • Software upgrade
  • f5_api_com certificate and key

Cause

Passphrase for the f5_api_com.key was changed.

Recommended Actions

  1. Edit bigip.conf and comment out the passphrase section using a # character. For example
     | sys file ssl-key /Common/f5_api_com.key {
     |     cache-path /config/filestore/files_d/Common_d/certificate_key_d/:Common:f5_api_com.key_xxxx_x
     |     # passphrase ***scrubbed***                               <---- add a # character to the beginning of this line
     |     revision 1
     |     source-path file:///config/ssl/ssl.key/f5_api_com.key
     | }
  2. Load the configuration by entering the following command:
    tmsh load sys config
  3. Proceed with the upgrade.
  4. Verify a new passphrase has been created for the f5_api_com.key by entering the following command:
    tmsh list sys file ssl-key f5_api_com.key
  5. If necessary, you can re-generate the f5_api_com cert/key pair by re-activating the license using the Automatic method in the GUI. For more information refer to K7752: Licensing the BIG-IP system.
    Important: When re-activating the license, traffic processing is briefly interrupted while the BIG-IP system reloads the configuration.
