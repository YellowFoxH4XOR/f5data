Known Issue

This is the result of a known issue. When an iRule handles the client side of a connection and attempts to bypass the BIG-IP Application Security Module (ASM), the BIG-IP ASM may process the server side of the connection. When this occurs, the BIG-IP system may terminate the connection unexpectedly.

The following error message indicates that this issue has occurred:

 TCL error: Rule <rule name> <HTTP_REQUEST_SEND> - can't read
"<variable name>": no such variable

F5 Product Development tracked this issue as CR67055 and CR67103 and it was fixed in BIG-IP ASM versions 9.2.4, 9.3.0, and 9.4.0. For information about upgrading, refer to the BIG-IP ASM release notes.
