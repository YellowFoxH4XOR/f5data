Description

Fail to save UCS archive with message:

Saving active configuration...
/var/local/ucs/backup.ucs is saved.

Traceback (most recent call last):
  File "/usr/libexec/iAppsLX_save_pre", line 153, in
    taskResult = getFinishedTask(taskUri, 1.0, 60)
  File "/usr/libexec/iAppsLX_save_pre", line 79, in getFinishedTask
    syslog.syslog(syslog.LOG_ERR, "Failed task: %s: %s"%(taskUri, taskResult['message']))
KeyError: 'message'

Environment

  • BIG-IP
  • Create UCS backup

Cause

Bug ID 768085

Recommended Actions

Update Python script /usr/libexec/iAppsLX_save_pre:

Identify this snippet of code:

if taskResult != None and 'status' in taskResult:
        if taskResult['status'] == "FINISHED":
                # Successful finish, meaning RPM was written.
                return taskResult
        elif taskResult['status'] == "FAILED":
                syslog.syslog(syslog.LOG_ERR, "Failed task: %s: %s"%(taskUri, taskResult['message']))
                return None
time.sleep(delay)

And change it to this:

if taskResult != None and 'status' in taskResult:
        if taskResult['status'] == "FINISHED":
                # Successful finish, meaning RPM was written.
                return taskResult
        elif taskResult['status'] == "FAILED":
                if 'message' in taskResult:
                        syslog.syslog(syslog.LOG_ERR, "Failed task: %s: %s"%(taskUri, taskResult['message']))
                elif 'errorMessage' in taskResult:
                        syslog.syslog(syslog.LOG_ERR, "Failed task: %s: %s"%(taskUri, taskResult['errorMessage']))
                else:
                        syslog.syslog(syslog.LOG_ERR, "Failed task: %s: %s"%(taskUri, str(taskResult)))
                return None
time.sleep(delay)

Update the Python Script

  1. SSH to log into the Advanced Shell (bash) with root account.
  2. Remount /usr as Read Write:

    mount /usr -o remount,rw

  3. Edit the /usr/libexec/iAppsLX_save_pre file with a text editor.
  4. Implement the change described above and save your changes before exiting the text editor.
  5. Synchronize changes from memory to disk:

    sync

  6. Remount /usr as Read Only:

    mount /usr -o remount,ro
