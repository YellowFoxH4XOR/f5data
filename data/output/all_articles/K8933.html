Known Issue

This is the result of a known issue. Server-side SSLv3-only connections are aborted when attempting to resume an SSL session.

This issue occurs when all of the following conditions are met:

  • The platform is using a Cavium Nitrox (1500, 1600, 34x0, 6400, 6800, 8400, 8800)
  • The server-side SSL profile is assigned to a virtual server for use
  • The server-side SSL profile is configured with SSLv2 and TLSv1 options disabled (No SSLv2 and No TLSv1 selected in Options List), and server connections are limited to using SSLv3 only.
  • Use of the DES or AES variants block ciphers

Subsequent SSLv3 requests are aborted when the BIG-IP attempts to perform an SSL session resume lookup from the Server SSL profile cache.

F5 Product Development is tracking this issue as CR97928.

Note: This issue does not affect the following versions:

  • BIG-IP version 10.x and later
  • BIG-IP version 9.2.x. This is due to an issue in which ServerSSL information was not stored. For more information, refer to K7276: ServerSSL session information is not stored, preventing SSL sessions from resuming.

Workaround

You can prevent this behavior by performing one of the following two workarounds:

  • Force the server to use TLSv1

    Note: Disabling SSLv3 within the server SSL profile will not work.
  • Disable the SSL session cache within the server SSL profile

    Note: This workaround causes the server SSL profile to behave as it did in BIG-IP LTM 9.2.x.

    You can disable the SSL session cache for the Server SSL profile from the command line or the Configuration utility.

    Command line

    To disable the SSL session cache for the Server SSL profile from the command line, type the following command:

    bigpipe profile <server ssl profile name> serverssl cache size 0

    Configuration utility

    To disable the SSL session cache for the Server SSL profile from the Configuration utility, perform the following procedure:

    1. Select Local Traffic.

    2. Select Server SSL Profiles.

    3. Select the name of the customer Server SSL Profile you want to modify.

    4. Change the value of the Cache Size to 0 (zero).

    5. Click Update.
