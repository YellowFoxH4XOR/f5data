K000151716: BIG-IP vCMP Guest stuck in Starting state after Upgrade

Type
Support Solution
Published
2025-07-03
Updated
2025-07-03
Applies to
  • BIG-IP
  • F5 Distributed Cloud Services
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000151716

Description

After upgrade of vCMP guest, it got stuck in Starting state.  Shortly after, two other guest unexpectedly moved from Running to Starting state

 

Environment

  • LTM
  • vCMP Guest
  • Upgrade

 

Cause

Error: disk partition /appdata has only 0% free

Insufficient disk space due to /appdata partition reaching its file size limit

 

Recommended Actions

Delete decommissioned vCMP guest and its associated vdisk

Delete unused vdisk template

 

Additional Information

None
