Known Issue

The Traffic Management Microkernel (TMM) may produce a core file when attempting to compress content for a connection flow.

This issue occurs when all of the following conditions are met:

  • A full proxy virtual server is configured with compression enabled.
  • TMM attempts to compress content for an expired or aborted connection flow.

Impact

TMM may produce a core file and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H446802 on the Diagnostics > Identified > High screen.
  • The BIG-IP system temporarily fails to process traffic and potentially fails over to the standby host.
  • A TMM core file with a timestamp that matches the time of the crash appears in the /shared/core directory.
  • The following log message appears in /var/log/tmm*:

    <13> localhost notice session_fire_event ERROR: could not send callback to 80.1.1.1:23758 - 10.1.1.1:443 ERR_NOT_FOUND
