Description

Getting the below error when running kubectl get pods command:

Unable to connect to the server: x509: certificate signed by unknown authority (possibly because of "crypto/rsa: verification error" while trying to verify candidate authority certificate "kubernetes")

Environment

  • NGINX Controller Version 3.x
  • Running kubectl get pods command

Cause

  • Possible certificate mismatch
  • $HOME/.kube/config file does not have a valid certificate

Recommended Actions

Verify that the $HOME/.kube/config file contains a valid certificate, and regenerate a certificate if necessary.

If there is a mismatch with certificates under $HOME/.kube/config and /etc/kubernetes/admin.conf file, try to overwrite the existing kubeconfig for the admin user:

  1. Make a backup of your current config file using the following command:

    mv $HOME/.kube/config $HOME/.kube/config.bak

  2. Replace the file in $HOME/.kube/config with the admin.conf file from /etc/kubernetes using the following command:

    sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config

  3. Change the file ownership using the following command:

    sudo chown $(id -u):$(id -g) $HOME/.kube/config

Additional Information

For more information about the kubernetes error, refer to the Troubleshooting kubeadm section of the official Kubernetes documentation.
