Description

BIG-IP APM and BIG-IQ do not log the User ID or Client OS information in Access Reports.

Environment

  • BIG-IP APM
  • v13.0.x

Cause

Bug ID 663377

Recommended Actions

  1. Log on to the command line of the BIG-IP APM device.
  2. Type the following command:
    bigstart restart apmd
    Important: Restarting the ampd service will temporarily impact the processing of BIG-IP APM traffic.
