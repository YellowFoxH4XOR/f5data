Description

OESIS WaDiagnose tool collects comprehensive data about the installed security applications, including their version, status, and configuration. This data can help in troubleshooting compatibility issues, ensuring that the security software is up-to-date and functioning correctly.

Environment

  • APM
  • OPSWAT
  • OESIS
  • WaDiagnose

Cause

As part of troubleshooting with the OPSWAT OESIS Diagnose tool, the BIGIP APM administrator may need to use an additional options during report generation such as specifying directory/file of the output log or specifying the method id.

Answer/Recommended Actions

Here is the example for WaDiagnose tool options for epsec-1.0.0-1727.0.iso extracted on disk E:\

C:\WINDOWS\system32>E:\epsec-1.0.0-1727.0\.Tools\Windows\OESISDiagnose_V4\wadiagnose --help
wadiagnose - MDES SDK V4 diagnostic utility for testing, and data collection

usage: wadiagnose --help
usage: wadiagnose [--log_path path] [--auto_exit [true|false]] [key value]

Options:
  --auto_exit                   automatically exit on completion
  --log_path                    specify directory/file of the output log
  --help                        display help message and exit
  --include_method <id>         add method with method_id=<id> to diagnose method
  --exclude_method <id>         remove method with method_id=<id> from diagnose method
  --custom                      use extra the Nextgen tool's database
  --single_method <json_file>   json input pass to wa_api_invoke to diagnose a single specific method
  --<key> <value>               custom setup key/value pairs to pass to wa_api_setup
                                these are used when no other argument matches known options

Troubleshooting:
  Please ensure that MDES SDK V4 libraries are located in same directory as wadiagnose, including libwacollector library.
  Valid license file (license.cfg) must also be present in the same directory.
