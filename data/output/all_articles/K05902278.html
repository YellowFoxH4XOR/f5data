Description

In the release of BIG-IP TMOS v16.1.0 there is a known behavior where CPU utilization increases by 4-5% for vCMP guests when the vCMP host is upgraded, compared to identical systems running BIG-IP TMOS v15.1.0.

The guest version is not relevant - guests can be upgraded to v16.1.0 without this CPU increase, and guests on earlier versions will still be affected if the host is upgraded.
 
Environment

  • vCMP host running version 16.1.0

Cause

Bug ID 908001

Recommended Actions

When determining whether to upgrade a vCMP host to v16.1.0, you should carefully evaluate the performance and sizing requirements of your specific configuration.

Additional Information

The impact observed is 4-5% increase in CPU utilization for vCMP guests. Under typical conditions there is no impact on TPS due to CPU utilization increases.

However, if CPU use is driven to 100%, F5 estimates a TPS decrease of up to 15% compared to unaffected versions.
