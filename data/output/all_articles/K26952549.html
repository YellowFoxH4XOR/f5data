Issue

Error Message

err get_dossier[<PID>]: 01170021:3: Invalid value (<value>) passed for option (-<arg>).

In this error message, note the following:

  • <PID> is the process ID for the get_dossier process.
  • <value> is the value supplied for the option by the user.
  • <arg> is the option used in the get_dossier utility.

For example:

err get_dossier[23948]: 01170021:3: Invalid value (-v) passed for option (-k).

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • You specify an invalid value for an argument when executing the get_dossier utility.

You can use the get_dossier utility with the base registration key to generate a dossier when licensing the BIG-IP system.  If an invalid value is supplied for an argument when executing the utility, the BIG-IP system logs this message and reports a list of supported arguments on the command line. 

For example:

usage: get_dossier -b "basekey1,basekey2,..." -a "actkey1,actkey2,..." -i "inactkey1,inactkey2,..." -f "certificate-request-file" [-c] [-u] [ -k <kernel_version> ] [ -v "<product> <version> <build>"]

Impact

The get_dossier utility fails to generate the dossier.

Recommended Actions

Review the usage details provided on the command line and correct invalid values in the command.  For more information about using the get_dossier utility, refer to K2595: Activating and installing a license file from the command line.
