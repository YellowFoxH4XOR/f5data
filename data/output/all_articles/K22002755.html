Description

Your BIG-IP  see the message Disk partition /appdata has only 0% free

Environment

  • iSeries v12.1.2 or later
  • VE 13.1.0 or later
  • Multiple modules provisioned

Recommended Actions

Increase the /appdata directory size.

Example command line commands to increase /appdata directory to 30gb:

  1. mount | grep appdata
  2. lvresize -L 30G /dev/mapper/vg--db--vda-dat.appdata
    Note: When resizing a message similar to the following is displayed:
    Size of logical volume vg-db-vda/dat.appdata changed from 24.92 GiB (6379 extents) to 30.00 GiB (7680 extents)
  3. resize2fs /dev/mapper/vg--db--vda-dat.appdata

Additional Information

  • K41812306: The appdata volume on BIG-IP iSeries platforms is now larger
