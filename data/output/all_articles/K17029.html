Known Issue

BIG-IP configurations may fail to load after an upgrade if the TCP profile's Time Wait value is set to 4294967295 (or Indefinite).

Note: In BIG-IP 11.6.0, the TCP profile's Time Wait value range is now 0 to 600000.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system configuration includes a custom TCP profile.
  • The custom TCP profile's Time Wait value is set to 4294967295.
  • You upgrade the system to BIG-IP 11.6.0.

Impact

The BIG-IP system fails to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system command line status is INOPERATIVE and the Configuration utility device status is Offline.
  • When attempting to load the BIG-IP system configuration, by using the Traffic Management Shell (tmsh), an error message similar to the following example appears:

    01070712:3: The value (-1) is outside the acceptable value set [value equal to or less than 600000] for time_wait_timeout in type TCP Profile for item <tcp_profile_name>
    Unexpected Error: Loading configuration process failed.

Workaround

To work around this issue, you can set a value within the 0 to 600000 range prior to upgrading the BIG-IP system. You can also change the time-wait-timeout value after upgrading, and then reload the configuration. To do so, perform the following procedure:

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

  1. After the upgrade is complete, log in to the BIG-IP system command line.
  2. Use a text editor to open the /config/bigip.conf file.
  3. Locate each TCP profile entry that appears as time-wait-timeout 4294967295.
  4. Modify the 4294967295 value to a value within the 0 to 600000 range.
  5. Reload the BIG-IP system configuration by typing the following command:

    tmsh load sys config
