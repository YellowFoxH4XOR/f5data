Description

The virtual server status is displayed in the Configuration utility as a gray circle with hover text that reads as follows:
Available (Disabled Parent) - The virtual server is available

Environment

  • BIG-IP LTM with Virtual Servers configured
  • The virtual server state is reported as "Available (Disabled Parent) - The virtual server is available"

Cause

The Virtual Address in question was disabled.
OR
Bug ID 892801

Recommended Actions

You can view and check the state of a virtual address and make sure it is enabled: 

  1. On the Main tab, click Local Traffic >> Virtual Servers

  2. The Virtual Server List screen displays a list of existing virtual servers.
  3. On the menu bar, click Virtual Address List (this displays the list of virtual addresses)
  4. In the Name column, locate the relevant virtual address and in the State column, view its state.
  5. If it is disabled, select the check box to the left of the virtual address name.
  6. Click the Enable button.
Note: If this is an Internal virtual and virtual-address 0.0.0.0 is missing, you will need to create one.  See Additional Information.

Additional Information

Follow steps if virtual-address 0.0.0.0 is missing:

  1. Create virtual-address 0.0.0.0:
    tmsh create ltm virtual-address 0.0.0.0
    Note: Make any config adjustments as needed via the GUI for this object: Local Traffic  ››  Virtual Servers : Virtual Address List
  2. Modify the affected internal-virtual to update the status.

The Availability should now be "Available (Enabled) - The virtual server is available"
