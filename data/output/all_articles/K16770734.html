K16770734: APM Native RDP failure with error: Client already shutdown

Description

After having implemented Native RDP resources using APM as an RDGateway, users fail to connect to those resources.
The RDP client attempts to connect until it times out.

Errors observed in BIG-IP logs or packet capture if RST cause is enabled (K13223):
Client already shutdown

Error observed if VDI log level is set to Debug:
server-side connection was reset, reason: Client already shutdown

Environment

  • Virtual server has the following profiles:
    • VDI
    • isession {server-side}
  • Virtual server has at least 1 iRule assigned

Cause

When no iRule is assigned to VS, we can observe the following error:
Configuration error: virtual /Common/<VS_NAME> has a serverside iSession profile, but has no pool or irules. In this case it should have 'translate address' disabled.
Unexpected Error: Loading configuration process failed.

This error is the result of a mis-configuration.
iSession serverside should not be assigned to this VS.

Recommended Actions

Remove iSession profile from the virtual server
