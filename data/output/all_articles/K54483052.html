Description
Outlook attachments may take a long time to open if connecting to Exchange 2013 Servers through the f5.microsoft_exchange_2010_2013_cas.vx.x.x iApp. This affects Outlook hard clients. When clicking on attachment either by preview or open file, the file downloads to a temp folder and eventually file can be opened. Users may experience severe latency if Outlook is closed, the temp folder is cleared and the file has to be downloaded again.

Examples of symptoms:

  • pdf and .jpg attachments do not open or take a long time to open
  • Microsoft attachments appear to open much more quickly than .pdf or .jpg files

Environment

  • Outlook
  • Microsoft Exchange server 2013
  • Outlook hard clients
  • iApp

Cause
Http profile applied to the VIP is using default Selective chunking for the Chunked Response.  Selective Chunking specifies that the system processes the HTTP content, and sends the response to the client, unchanged if it is unchunked.  If it is chunked then Rechunk is the same as Selective.

Recommended Actions

Select a different option for Response Chunking :
  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Services > HTTP.
  3. Click the name of the affected HTTP profile.
  4. Select the custom checkbox next to Response Chunking in the Settings
  5. Select a method other than Selective which is the default. 
    For example:
    Rechunk
  6. To save the changes, click Update.
