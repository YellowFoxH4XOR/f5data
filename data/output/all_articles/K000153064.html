Description

Configure a remote logging profile to forward logs to a remote server via Management interface

Environment

  • AFM/ASM Remote logging profile
  • DoSL7 profile
  • BOT profile
  • AFM network Firewall

Cause

None

Recommended Actions

Important: This configuration is for reference and may require adjustments to adapt to your environment. 

1)_ Verify which interface the BIG-IP system is using to reach the remote server. In this example, we are pointing to the MGMT interface.

config # ip r g 10.171.137.211
10.171.137.211 dev mgmt src 10.171.137.210

2)_ Create log destination and select Management Port

3)_ Create a second publisher and select the type of log destination. 

4)_ Create a new publisher

5)_ Create a new logging profile and select your preferred options.

6)_  Associate the new logging profile with the virtual server.
