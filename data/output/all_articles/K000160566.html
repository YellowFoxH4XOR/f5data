K000160566: After upgrading to 17.1.3.1 or 17.5.1.4 or newer version, tmm SSL memory usage increases dramatically

Type
Support Solution
Published
2026-04-01
Updated
2026-08-25
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1, 17.1.3
Source
https://my.f5.com/manage/s/article/K000160566

Description

After upgrading to 17.1.3.1 or 17.5.1.4 or newer version, tmm ssl memory usage can dramatically increase, potentially causing tmm to experience memory pressure and aggressively reaping connections.

Environment

  • BIG-IP upgrade to 17.1.3.1 or 17.5.1.4 or newer versions

  • Using TLS1.3

Cause

ID 1380009 was fixed in 17.1.3.1 and 17.5.1.4. This results in TLS1.3 connections caching session data which includes certificates due to the default settings of "retain certificate" enabled on SSL profiles.  The resulting increase in sessions being cached increases the amount of memory tmm uses for ssl and can result in memory pressure that did not exist prior to upgrade. In extreme cases, the increase in ssl memory can cause aggressive reaper messages and aggressive connection reaping even though traffic patterns did not change.

Answer/Recommended Actions

Disable retain certificates on the SSL profiles that use TLS1.3, in particular the SSL server-side unless absolutely needed.
