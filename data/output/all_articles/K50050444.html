K50050444: BIG-IQ pool license Activation date not updated when reactivated

Type
Support Solution
Published
2021-10-14
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K50050444

Description

When reactivating a pool license or pool license offering managed by BIG-IQ, the Activation Date does not update.

Environment

  • BIG-IQ
  • Pool licenses 

Cause

This is the expected behavior.
The Activation Date is the date the license or offering was first activated. 

Recommended Actions

None

None
