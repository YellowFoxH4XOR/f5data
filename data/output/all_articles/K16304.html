Issue

Old Behavior

In versions prior to BIG-IP 11.6.0, audit logging for BIG-IP configuration changes is disabled by default.

You can enable and disable audit logging by modifying the Config.Auditing database variable.

New Behavior

Beginning in BIG-IP 11.6.0, audit logging for BIG-IP configuration changes is enabled by default.

When enabled, the BIG-IP system records all configuration changes in the /var/log/audit file.

F5 Product Development tracked this change as ID 450990.

Impact

Generally, you should experience minimal impact on system resources. However, audit logging intensity increases with the increase in the frequency and intensity of configuration changes; this may affect system resource usage.

Recommended Actions

If you want to revert to the previous behavior, you can disable audit logging for configuration changes by performing one of the following procedures:

  • Disabling audit logging for configuration changes using the Configuration utility
  • Disabling audit logging for configuration changes using the tmsh utility

Disabling audit logging for configuration changes using the Configuration utility

To disable audit logging for configuration changes using the Configuration utility, perform the following procedure:

Impact of procedure: The system will no longer log changes made to the configuration after performing this procedure.

  1. Log in to the Configuration utility.
  2. Click System.
  3. Click Logs.
  4. Click Configuration.
  5. Click Options.
  6. Under the Audit Logging section, select Disable for the MCP setting.
  7. Save the changes by clicking Update.

To re-enable audit logging for configuration changes, repeat all the steps and select Enable for the MCP setting in step 6.

Disabling audit logging for configuration changes using the tmsh utility

To disable audit logging for configuration changes using the Traffic Management Shell (tmsh) utility, perform the following procedure:

Impact of procedure: The system will no longer log any changes made to the configuration after performing this procedure.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Disable audit logging for configuration changes by typing the following command:

    modify /sys db config.auditing value disable

  3. Save the changes by typing the following command:

    save /sys config

To re-enable audit logging for configuration changes, repeat all the steps and replace disable with enable for the command in step 2.
