Description

SIEM is receiving logs from Self IP address as a source local even though the syslog is configured by Management IP address.
 

  • Mgmt IP: 10.xxx.xxx.4
  • Self-IP : 10.xxx.xxx.250
/run/config/syslog-ng.conf 
options { 
dir_perm(0755); 
perm(0600); 
chain_hostnames(no); 
keep_hostname(no); 
use_fqdn(yes); 
stats_freq(0); 
log_fifo_size(2048); 
}; 

source local { 
systemd_journal(); 
udp(ip(10.xxx.xxx.4) port(514) flags(no-multi-line)); <---------- Source Local IP Address 
udp6(ip("::1") port(514) flags(no-multi-line)); 
internal(); 
};

Environment

  • BIG-IP v13.x - 15.x
  • Changes made to local syslog source address:
    • Configuration change
    • Egress interface change via addition of more specific static route (ie changing traffic flow to mgmt interface versus TMM internal interface)
  • syslog-ng.conf

Cause

Bug ID 784981: Modifying 'local-ip' for a remote syslog requires restarting syslog-ng

Recommended Actions

Restart syslog-ng in order to cause the change to be applied properly.

1. Log in to the BASH Shell
2. Run the command below:

bigstart restart syslog-ng
