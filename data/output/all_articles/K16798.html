Known Issue

Clients may receive an expired Secure Sockets Layer (SSL) certificate warning when the SSL Forward Proxy fails to purge expired SSL certificates from the cache.

This issue occurs when the following condition is met:

  • You have configured the BIG-IP system to use the SSL Forward Proxy feature.

Impact

Clients receive an SSL warning due to receiving an expired SSL certificate.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice expired SSL certificates exist when you view the client-proxy cache.
  • Clients are receiving an Expired Certificate warning when they connect to virtual servers using the SSL Forward Proxy feature.

Workaround

To work around this issue, you can manually delete the expired cached SSL certificates. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure may add moderate additional CPU load as the BIG-IP system rebuilds the cached SSL certificate list.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To view the cached SSL certificates, use the following command syntax:

    show ltm clientssl-proxy cached-certs virtual [name] clientssl-profile [name]

    For example, to view the cached SSL certificates for a virtual server named example_ssl_vip which references a profile named example_ssl_profile, type the following command:

    show ltm clientssl-proxy cached-certs virtual example_ssl_vip clientssl-profile example_ssl_profile

    Cached Certificate 1:
    Certificate:
    Data:
    Version: 3 (0x2)
    Serial Number: 6056755090573039935 (0x540deaaa3125193f)
    Signature Algorithm: sha1WithRSAEncryption
    Issuer: C=US, ST=Seattle, O=F5 Networks, OU=CA Signing Department, CN=CA.f5.com
    Validity
    Not Before: Sep 7 17:43:06 2014 GMT
    Not After : Sep 9 17:43:06 2014 GMT
    Subject: C=US, ST=Seattle, O=f5.com, OU=big-ip, CN=ssl.f5.com

  3. To delete the cached SSL certificates, use the following command syntax:

    delete ltm clientssl-proxy cached-certs virtual [name] clientssl-profile [name]

    For example, to delete the cached SSL certificates for a virtual server named example_ssl_vip which references a profile named example_ssl_profile, type the following command:

    show ltm clientssl-proxy cached-certs virtual example_ssl_vip clientssl-profile example_ssl_profile

  4. To exit the tmsh utility, type the following command:

    quit
