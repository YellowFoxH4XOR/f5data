Topic

You cannot pass bootp protocol through BIG-IP. To use a network boot server from a separate subnet to network boot systems from a subnet attached to BIG-IP, you must provide an alternate path for the bootp traffic.

F5 Product Development tracked this request as CR28346 and CR41790.
