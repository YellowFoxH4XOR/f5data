Known Issue

Note: For information about configuring remote roles on the BIG-IP system, refer to the Configuring access control for BIG-IP system users section in the BIG-IP Local Traffic Manager Implementations Manual.

This is the result of a known issue. The BIG-IP system does not parse a remote role attribute that contains a space character correctly. For example, the BIG-IP system will fail to match the attribute specified in the following configuration:

remoterole {
   role info F5Admins {
         attribute "memberOF=cn=F5Admins,ou=new team,ou=it,dc=example,dc=com"
         console "enable"
         line order 1
         role "administrator"
         user partition "all"
      }
}

As a result, all remote authenticated users will be assigned the default user role.

F5 Product Development tracked this issue as CR134039, and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

This issue has been fixed in an engineering hotfix issued for BIG-IP 10.0.1. Customers affected by this issue should contact F5 Technical Support, referencing this article number and the associated CR number, to request the hotfix.

Workaround

To workaround this issue, you can enclose the attributes in double quotes. For example:

Note: Double quotes need to be escaped with a backslash in order for the bash shell to pass the double quotes to the bigpipe command. If the double quotes are not escaped, the bigpipe command will fail to parse the attribute containing spaces and will return an error. However, the backslash can be omitted if you run the command from within the bigpipe shell (bpsh).

# bigpipe remoterole role info F5Admins { attribute \"memberOF=cn=F5Admins,OU=new team,OU=it,dc=example,dc=com\" console enable line order 1 role administrator user partition all }

Note: The Group Name cannot contain spaces.

To list the remote role configuration, type the following command:

# bigpipe remoterole list

   remoterole {
         role info F5Admins {
         attribute "memberOF=cn=F5Admins,OU=new team,OU=it,dc=example,dc=com"
         console "enable"
         line order 1
         role "administrator"
         user partition "all"
      }
