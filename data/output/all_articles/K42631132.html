Description
BIG-IP does not show its LLDP neighbors, however the neighboring devices are able to see the BIG-IP in their LLDP table.

Environment

  • BIG-IP
  • LLDP is enabled

Cause
By default, the BIG-IP only transmits LLDP packets to its neighbors but does not receive from them. We need to specifically configure it to receive the LLDP packets from its neighbors.

Recommended Actions

To enable from GUI:

  1. Log in to the Configuration utility.
  2. Go to Network > Interface > Interface List > select an interface > change LLDP setting to "Transmit and Receive".


To enable from CLI:
You can enable Transmit & Receive on all interfaces in one go by using the following command:
tmsh modify net interface all lldp-admin txrx

To exclude the Management interface, you can use the "no-mgmt" option, command as shown below:
tmsh modify net interface all lldp-admin txrx no-mgmt
