Description

Central manager may show an instance count on the provider that is different to the number of instances actually running on the provider.

 

Environment

  • BIG-IP Central Manager
  • VELOS, rSeries or other Provider

 

Cause

Central Manager cannot maintain information about Next instances when those instances were created, modified or deleted outside of Central Manager itself.

 

For example, if an instance was deleted via the provider, not via Central Manager, then Central Manager will not be aware that the Next instance is gone. From Central Manager's point of view, the instance may simply be powered off. The instance count will not change as a result.

 

Recommended Actions

Only use CM to deploy, modify and delete instances on a provider.

 

Additional Information

Central Manager is not aware of instances on a provider unless it created them.

The ability to delete a Next instance from Central Manager when it is in an "unknown" state (ie not reachable) is possible from release 20.3.0.
