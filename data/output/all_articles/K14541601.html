Description
An error message similar to the following is generated when saving UCS file from tmsh:

# tmsh save sys ucs <ucs file>.ucs
Saving active configuration...

Error Message:
/root/.tmsh-history-(tmos)#: (at /root/.tmsh-history-(tmos)#) does not exist
Errors during file attribute collection
Operation aborted.

Environment

  • Using tmsh command to save a UCS file
  • File /root/.tmsh-history-<user_id> exist on device
  • Cannot remove the UCS file after deleting it

Cause

Unknown at time of publication.

Recommended Actions

There are 2 ways to resolve this. Use either Procedure 1 or 2.

Procedure 1:

  1. Delete the file that is causing the issue.
    The file is listed in the error message:

    /root/.tmsh-history-(tmos)#: (at /root/.tmsh-history-(tmos)#) does not exist
     
  2. The issue is that the file contains a space at the end of the filename:-

    # ls -laQ .tmsh-history-\(*

    -rw-r--r--. 1 root root 0 Jun  6 17:42 ".tmsh-history-(tmos)# "

    So you can see that there is a space at the end of the filename.

    # rm -f '/root/.tmsh-history-(tmos)# '

    Now you should be able to create a UCS Archive as expected.

Procedure 2:

Perform the following steps to skip saving files for /root/.tmsh-history* for UCS:

  1. Log in to the BIG-IP command line.
  2. To remount the /usr file system in read-write mode, type the following command:
    mount -o remount,rw /usr
     
  3. To back up the file and open/edit it, type the following command:
    $ cp /usr/libdata/configsync/cs.dat /usr/libdata/configsync/cs.dat_backup
    $ vim /usr/libdata/configsync/cs.dat
     
  4. To comment out this line in the file by adding 'hash #' in front of the line.
    #save.<number>.file = /root/.tmsh-history*
     
  5. Save the file and exit the editor.
     
  6. Run ls command to verify if there is no more tmsh history.
    # ls -1a .tmsh-history-*
     
  7. You should be able to save the ucs file by running the command:
    # tmsh save sys ucs /var/tmp/<ucs file>.ucs
    Saving active configuration...
    /var/tmp/<ucs file>.ucs is saved.
