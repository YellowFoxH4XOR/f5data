Description

When performing a Windows specific Access Policy Check on a MacOS device, the VPN connection is now denied when it used to be allowed. 

Environment

  • Edge Client for MacOS or Browser Helper Apps
  • Endpoint Inspector.app
  • Access Policy with Windows Checks

Cause

Since MacOS version 13.3 the Endpoint inspection method has changed to stop using Deprecated Webkit plugins.

The new behaviour is more secure, but may need old Access policies to need to be revised.

 

 Recommended Actions

Administrators should ensure that Access Policies do not try and perform Windows specific checks on MacOS devices. 

This is best achieved by having an OS check that branches, such Windows specific checks (like Windows Info or Registry check) are only run on devices identified as Windows.
