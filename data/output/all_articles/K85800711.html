K85800711: F5 Telemetry Streaming Sending illegal characters to Azure Sentinel

Support Solution
Published

Applies to

  • BIG-IP

Source
https://my.f5.com/manage/s/article/K85800711

Description

Telemetry streaming has been deployed in the BIG-IP with Azure Sentinel as its consumer. The logs are received in Azure Sentinel, however, the "data" portion of the log is showing with unrecognized characters similar to the following:

Environment

  • BIG-IP
  • Azure Sentinel
  • Initial configuration deployed by following devcentral article: Deploying BIG-IP Telemetry Streaming with Azure Sentinel as its consumer

Cause

The initial configuration was not correctly deployed. ASM portions of the deployment were included while the system doesn't have ASM module provisioned.

Recommended Actions

Redeploy the Telemetry Streaming configuration for Azure Sentinel following this clouddoc article: How can I write an Event Listener’s incoming raw data to a trace file? ASM portions of the deployment can be omitted in case the BIG-IP is not provisioned with it.
