K000135161: Unable to send OTP email using SendGrid

Type
Support Solution
Published
2023-06-27
Updated
2023-06-27
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000135161

Description

You are using SendGrid email service or similar. You have Setup Visual Policy Editor Email agent with SMTP server configured with "use authentication" through GUI. You have connected as a user to trigger the email agent and observe that password is not correctly send to the SMTP server. 

Following error can be observed in apm logs:

Email Agent: Message send message send failed

 

Environment

  • APM
  • Access Policy
  • Visual Policy Editor
  • SMTP Server
  • Email Agent
  • OTP
  • SendGrid

Cause

When a BIG-IP administrator tries to set password of length greater than 64 through GUI it gets truncated to 64 characters. which in turn results in failure of Email Agent in access policy.
(Bug ID 1308629)

Recommended Actions

Setting the password via tmsh resolves the issue:

tmsh modify sys smtp-server password

Additional Information

None
