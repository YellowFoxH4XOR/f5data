K60083175: Purpose of do-not-remove-without-replacement server ssl profile

Type
Support Solution
Published
2021-06-22
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K60083175

Description
You may notice that there is a new Server SSL profile named do-not-remove-without-replacement when you upgrade. For instance when upgrading to v15.1.3 or later.
For example:

ltm profile server-ssl /Common/do-not-remove-without-replacement {
    app-service none
}

Environment

  • v15.1.2.1

Cause
This server side ssl-profile was created for the BeWAF (Behavioral WAF - Cloud Security Service).
When ASM is provisioned and the BeWAF feature is enabled and cloud service app is attached to the virtual server, this Server SSL profile may be used.

When ASM is not provisioned, or BeWAF is not enabled or cloud service app is not attached to the virtual server, this Server SSL profile is not used. The do-not-remove-without-replacement profile is created, but not associated to anything. It is not harmful and can be ignored.

Recommended Actions

If you are not using BeWAF, BIG-IQ will identify the do-not-remove-without-replacement server SSL profile as orphaned (unused) in an evaluation and will remove it during a deployment. You can work around this by using one of the following options:

  • For Unused Objects, select Keep Unused Objects and BIG-IQ will ignore do-not-remove-without-replacement; however, BIG-IQ will ignore all other unused objects as well.
  • For Source Scope, change to Partial Changes and select your source objects you want to add to the BIG-IP config.
  • Associate do-not-remove-without-replacement with a dummy virtual server.
Note: If you delete do-not-remove-without-replacement, the BIG-IP will re-generate it upon reboot.
