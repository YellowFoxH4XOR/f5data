Known Issue

Windows users may be unable to establish a network access session.

This issue occurs when all of the following conditions are met:

  • The device is running the Windows operating system version 10, 8.1, 7, or 6 (Vista).
  • The BIG-IP Edge Client software was previously installed.
  • You install the BIG-IP Edge Client software.
  • After uninstalling the BIG-IP Edge Client software, you attempt to establish a network access session.

Impact

The network access session fails to establish.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to establish the network access session, you are automatically logged out of the access session.
  • When attempting to establish the network access session, the BIG-IP Edge Client logs DIALER messages on the device that appear similar to the following example:

    DIALER, 48, \driverstatechecker.cpp, 10, dump, WAN Miniport (SSTP)
    DIALER, 48, \driverstatechecker.cpp, 10, dump, WAN Miniport (SSTP)
    DIALER, 48, \driverstatechecker.cpp, 10, dump, F5 Networks VPN Adapter
    DIALER, 48, \driverstatechecker.cpp, 10, dump, F5 Networks VPN Adapter (7)
    DIALER, 48, \driverstatechecker.cpp, 155, GetVPNDriverRASDeviceName, found device, F5 Networks VPN Adapter
    ....
    DIALER, 1, \urdialer.cpp, 1573, CURDialer::OnRasCallback(), RAS error (state=RASCS_OpenPort, error=633: The modem (or other connecting device) is already in use or is not configured properly.)

  • After rebooting the device, the network access session is successfully established.

Workaround

To work around this issue, you can reboot the affected device prior to attempting to establish an access session.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
