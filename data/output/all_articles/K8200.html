K8200: Link appears with a comf5aboutblank.html filename when viewed through Portal Access

Published

Source

Topic

When a web page contains a link with a blank HREF attribute, the FirePass controller's reverse proxy (Portal Access) will rewrite the HREF to point to a blank web page provided by the FirePass controller.

For example:

<A HREF="">This is a blank link</A>

The HTML source containing the example line will be rewritten by the reverse proxy to appear as follows:

<A HREF="/vdesk/comf5aboutblank.html">This is a blank link</A>

If the user rolls the mouse over the link, the following URL will appear in the browser's status bar:

https://<name or IP address of FirePass controller>/vdesk/comf5aboutblank.html

This substitution ensures consistent behavior in the reverse proxy. Typically, the rewriting of the HREF will not produce negative results. F5 Networks recommends avoiding blank HREF statements, as there is no standard behavior among the various browsers for this construct.
