Known Issue

Configuration synchronization (ConfigSync) may fail when a virtual address exists in a different route domain than the administrative partition.

This issue occurs when all of the following conditions are met:

  • You have multiple BIG-IP systems in a High Availability (HA) configuration.
  • You have created a new administrative partition. The default administrative partition is named Common.
  • You have created a new route domain. The default route domain is 0.
  • You have set the new route domain as the default route domain for new administrative partition.
  • You have created a virtual address in the new administrative partition with an IP address in the default route domain 0. For example, 192.168.10.100%0.
  • You attempt to sync this configuration to a peer device.

Impact

Configuration synchronization fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You are unable to synchronize the configuration between peer devices.
  • In the /var/log/ltm file, you may observe an error message similar to the following example:

    01070734:3: Configuration error: Virtual address /Uncommon/192.168.10.100%0 encodes IP address 192.168.10.100 which differs from supplied address field 192.168.10.100%1
