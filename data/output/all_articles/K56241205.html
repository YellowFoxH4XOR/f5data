Issue

Error Message

info sod[<PID>]: 010c002d:5: Traffic group /<partition>/<traffic_group_name> going standby via targeted failover command.

In this error message, note the following:

  • <PID> is the process ID of the sod process.
  • <partition> is the name of the partition on which the traffic group resides.
  • <traffic_group_name> is the name of the traffic group that you attempt to force to standby.

For example:

sod[6738]: 010c002d:5: Traffic group /Common/example_traffic_group going standby via targeted failover command.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • You issued a force-to-standby command to a traffic group that is active on a BIG-IP system.

This message indicates that the administrator issued a targeted failover command to an active traffic group on the local system.

Impact

The traffic group transits to the standby state on the local system.

Recommended Actions

Verify that the failover operation succeeded by displaying the status of the specified traffic group on each high availability (HA) system. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Display the status of the traffic group on the device by typing the following command:

    show /cm failover-status
