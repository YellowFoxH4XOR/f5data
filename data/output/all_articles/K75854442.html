K75854442: BIG-IQ VE 6.1.0 LDAP authentication does not work using FQDN

Type
Support Solution
Published
2020-06-11
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K75854442

Description
        LDAP authentication returns DNS error when using a Fully Qualified Domain Name for the Authentication Server

Environment

  • BIG-IQ 6.1
  • DHCP providing DNS Server IP addresses

Cause
        DHCP provided DNS Server addresses were disappearing and reappearing. This may have been caused by having a misconfigured DHCP server.

Recommended Actions

  1. Use IP address(es) for the Authentication Server address

Additional Information
        None
