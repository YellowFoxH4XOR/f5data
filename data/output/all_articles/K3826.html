Topic

This article applies to the removal of the FirePass Controller Client (SSL VPN client) for a Mac OS X device. For information about removing the BIG-IP Edge Client, refer to the following article:

  • K15539: Removing the BIG-IP Edge Client from Mac OS X devices

Note: Removing the Mac OS X FirePass Controller Client requires access to system folders in the root directory. To access these folders, you will need to make changes to the Finder to allow these folders to be displayed, or you can use the Terminal. The following instructions are for the Terminal, but can be easily adapted for use through the Finder.

Note: This procedure is designed to cover all versions of Mac OS X. Some steps may not apply to your version of Mac OS X.

Removing SSL VPN components

If all existing SSL VPN components are not removed, upgrading to a newer version will fail. To remove the SSL VPN components, perform one of the following three procedures:

Removing SSL VPN components with Mac OS version 10.6.x

  1. Open the Terminal application.
  2. Start a superuser session by typing the following command:

    su

  3. When prompted, enter the superuser password.
  4. Change directories to the /Library/Internet Plug-Ins/ directory by typing the following command:

    cd /Library/Internet\ Plug-Ins/

  5. Remove the main SSL VPN components by typing the following commands.

    rm -r F5\ SSL\ VPN\ Plugin.plugin
    rm -r f5_sslvpn.bundle
    rm -rf F5\ Inspection\ Host\ Plugin.plugin

  6. Change directories to your home directory's /Internet Plug-Ins subdirectory by typing the following command:    

    cd ~/Library/Internet\ Plug-ins
  7. Remove any SSL VPN components by typing the following command:

    rm -r F5*
    rm -r f5*
  8. Change directories to the /private/tmp/ directory by typing the following command:

    cd /private/tmp/

  9. Identify the SSL VPN client installer package by typing the following command:

    ls f5*

    This command should display one directory with a name that begins with f5 and is followed by 13 digits. This is the name of the installer package.

  10. Remove the SSL VPN client installer package by typing the following command, replacing the question marks with the numerical portion of the file name:

    rm -r f5?????????????

  11. Change directories to the /private/var/db/receipts/ directory by typing the following command:

    cd /private/var/db/receipts/

  12. Remove the SSL VPN client bill of materials by typing the following command:

    rm -rf F5*

  13. Close your superuser session by typing the following command:

    exit

Removing SSL VPN components with Mac OS version 10.5.x or earlier

  1. Open the Terminal application.
  2. Start a superuser session by typing the following command:

    su

  3. When prompted, enter the superuser password.
  4. Change directories to the /Library/Internet Plug-Ins/ directory by typing the following command:

    cd /Library/Internet\ Plug-Ins/

  5. Remove the main SSL VPN components by typing the following commands.

    rm -r F5\ SSL\ VPN\ Plugin.plugin
    rm -r f5_sslvpn.bundle
    rm -rf F5\ Inspection\ Host\ Plugin.plugin

  6. Change directories to your home directory's /Internet Plug-Ins subdirectory by typing the following command:    

    cd ~/Library/Internet\ Plug-ins
  7. Remove any SSL VPN components by typing the following command:

    rm -r F5*
  8. Change directories to the /private/tmp/ directory by typing the following command:

    cd /private/tmp/

  9. Identify the SSL VPN client installer package by typing the following command:

    ls f5*

    This command should display one directory with a name that begins with f5 and is followed by 13 digits. This is the name of the installer package.

  10. Remove the SSL VPN client installer package by typing the following command, replacing the question marks with the numerical portion of the file name:

    rm -r f5?????????????

  11. Change directories to the /Library/Receipts/ directory by typing the following command:

    cd /Library/Receipts/

  12. Remove the SSL VPN client bill of materials by typing the following commands:

    rm -rf SSLVpn.pkg
    rm -rf mac_sslvpn.pkg

  13. Remove the SSL VPN client bill of materials by typing the following command:<

    rm -rf F5*

  14. Close your superuser session by typing the following command:

    exit

Removing SSL VPN components using the Terminal application window 

  1. Open a Terminal application window.
  2. Copy and paste the following lines into the Terminal application window:

    sudo rm -fr /Library/Internet\ Plug-Ins/{F5\ SSL\ VPN\ Plugin.plugin,F5\ Inspection\ Host\ Plugin.plugin,f5_sslvpn.bundle} &&
         rm -fr /Library/Receipts/SSLVpn*.pkg &&
         rm -fr /private/tmp/f5????????????? &&
         echo " Success! " ||
         echo " Failure: Manual removal needed "

    Note: After pasting, you may need to press the Enter key, and you may be prompted for a password. If so, enter the password for the administrative/superuser account.
     

Finding and removing files that were not installed using the default settings

If you performed one of the Removing SSL VPN components procedures, and you receive error messages when trying to upgrade the VPN client, you can remove the necessary files by performing the following procedure:

  1. Log in to the command line.
  2. Files might be located in other locations depending on how the VPN components were installed. To confirm that all copies are deleted, type the following three commands:

    find / -depth -name SSLVpn* -print
    find / -depth -name F5* -print
    find / -depth -name f5* -print

    Note: The commands may take several minutes to complete.

    Output will appear similar to the following example:

    root# find / -depth -name SSLVpn* -print
    /Users/sarah/.Trash/SSLVpn.pkg.tgz
    /Users/sarah/Desktop/SSLVpn.pkg.tgz
     
  3. To remove all copies of the files, use the following command syntax, and replace the path and file name with the complete path and file listed in the find command results:

    rm -rf /Users/sarah/.Trash/SSLVpn.pkg.tgz

    Important: The output of the find command may list files and directories that are not related to the FirePass Network Access client components. Before deleting any file or directory, ensure that they are related to the FirePass Network Access client components. If you are unsure, do not delete the file or directory.
