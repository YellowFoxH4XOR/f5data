Description

Windows Defender (Microsoft Defender Antivirus) detects a threat named "Backdoor:JS/WebShellz.AA" within BIG-IP ISO installation files (versions 17.5.1.4 and 17.5.1.5). The alert references a file path inside the ISO pointing to "alpine__version_2.xml" located within the ASM signature package. This detection occurs after recent Windows Defender definition file updates.

 

Environment

Product: BIG-IP ASM

Version: 17.5.1 (including 17.5.1.4 and 17.5.1.5 ISO files)

Operating System: MAC with Microsoft Defender enabled

Action: Scanning or accessing BIG-IP ISO files on Windows PCs

 

Cause

The detection is triggered by an ASM (Application Security Manager) signature file ("alpine__version_2.xml") included in the BIG-IP ISO. This file contains pattern-matching rules for web application security (specifically signature ID 200103095 for "PgJDBC arbitrary file write" detection) and is not malicious.

 

Answer/Recommended Actions

The detection by Windows Defender is a false positive. The flagged file is an ASM signature used by BIG-IP for security purposes.

It is safe to ignore this alert when handling official BIG-IP ISO files obtained from F5.

There is no threat to Windows PCs from the ISO file itself.

There is no threat to BIG-IP systems installed using the affected ISO files.

If necessary, you may exclude the ISO file or its extraction path from Defender scans to prevent repeated alerts.

 

Additional Information

The "alpine__version_2.xml" file is generated by F5's Signature Workshop and is used for detecting specific web application attacks.

The presence of this file in the ISO is expected and does not indicate compromise or malware.

Similar detections may occur with other security signature files in future ISO releases as antivirus definitions evolve.

Microsoft Defender threat name: Backdoor:JS/WebShellz.AA

Signature details: sig id="200103095" (PgJDBC arbitrary file write)
