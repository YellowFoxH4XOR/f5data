Topic

This article applies to BIG-IP 15.x - 17.x. For information about other versions, refer to the following article:

  • K7405: Overview of the tcp-wan-optimized profile (10.x - 12.x)

The f5-tcp-wan profile is a pre-configured profile type. In cases where the BIG-IP system is load balancing traffic over a WAN link, you can enhance the performance of your wide-area TCP traffic by using the f5-tcp-wan profile.

Description

If you are configuring a virtual server to process traffic that is strictly WAN-based, you can use the f5-tcp-wan profile to enhance WAN-based traffic. For example, in many cases, the client connects to the BIG-IP virtual server over a WAN link, which is generally slower than the connection between the BIG-IP system and the pool member servers. As a result, the BIG-IP system can accept the data more quickly, allowing resources on the pool member servers to remain available. By configuring your virtual server to use the f5-tcp-wan profile, you can increase the amount of data the BIG-IP system will buffer while waiting for a remote client to accept it. Additionally, you can increase network throughput by reducing the number of short TCP segments the BIG-IP system sends on the network.

Optimized settings and definitions in the f5-tcp-wan profile

The following table describes settings of the f5-tcp-wan profile used to optimize WAN traffic that may differ from the parent default TCP profile:

Note: The default values for some settings in the default TCP profile may change between versions. These changes are inherited by the f5-tcp-wan profile. For information about the default TCP profile settings, refer to K50411377: Overview of the TCP profile (16.x and later).

SettingValueDescription
Congestion ControlWoodsideSpecifies that the system uses a TCP algorithm that is especially targeted at high-speed, long-distance networks with enhanced congestion recovery.
Delayed AcksDisabledSpecifies, when checked (enabled), that the system can send fewer than one ACK (acknowledgment) segment per data segment received. By default, this setting is disabled for the TCP WAN optimized profile.
Minimum RTO500 msSpecifies the minimum length of time that the system waits for acknowledgements of data sent, before resending the data. The value must be equal to or less than 5000. If the Packet Loss Ignore Rate and Packet Loss Ignore Burst settings contain values other than 0, this value drops to 203 ms. If MPTCP is enabled, the value drops to 200 ms.
Proxy Buffer Low196608This setting specifies the proxy buffer level at which the receive window was opened. For more information, refer to K3422: Overview of content spooling.
Proxy Buffer High262144This setting specifies the proxy buffer level at which the receive window is no longer advanced. For more information, refer to K3422: Overview of content spooling.
Send Buffer262144This setting causes the BIG-IP system to send the buffer size in bytes. To optimize LAN-based traffic, this setting should be at least 64 K in order to allow the BIG-IP system to output more data at a time, if it is allowed by the congestion window.
Receive Window131072This setting causes the BIG-IP system to receive the window size in bytes. If this setting is set too low in a LAN environment it can cause delays, as some systems inhibit data transfers if the receive window is too small.
Nagle's AlgorithmAutoWhen this setting is enabled, the BIG-IP system applies Nagle's algorithm to reduce the number of short segments on the network by holding data until the peer system acknowledges outstanding segments.

Recommendations

F5 recommends that instead of modifying a default profile, you create a custom profile using the default profile as the parent profile. You can then modify some or all of the values defined in the custom profile, while leaving the parent profile settings at their default values. For information, refer to K14488: Working with profiles.
