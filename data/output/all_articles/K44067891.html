Known Issue

The RADIUS iRules command intermittently fails to create subscribers.

This issue occurs when the following condition is met:

  • You use an iRule and the PEM::subscriber create command to create BIG-IP PEM sessions from Remote Authentication Dial-in User Service (RADIUS) packets.

Impact

Intermittently—a few operations per day—the command silently fails. The system creates neither a session nor a Tool Command Language (Tcl) error. Adding a subscriber requires that you intervene manually.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You are unable to add a subscriber, despite using the same IP address and retrying several times.

    This issue rarely occurs. For example, when your daily average of subscriber additions is approximately 30,000 subscribers, five to six subscribers encounter this problem (0.02%).
