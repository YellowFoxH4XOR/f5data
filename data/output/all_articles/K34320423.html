K34320423: Error when importing iRules LX workspace: ''General database error.''

Source

Description

When a user imports an iRules LX workspace, it fails with an error: "General Database Error".

Important: There are multiple reasons as to why you may see this database error when browsing the GUI. Unless this article fits your case exactly, it is recommended to start with General Database Error Retrieving Information in the BIG-IP Configuration Utility , which helps you discover the right article for you.

Environment

  • iRules LX provisioned

Cause

Incorrect ownership of folder /var/ilx/workspaces/Common.

Recommended Actions

Change ownership and permissions using root privileges:

  1. chown root:sdm /var/ilx/workspaces/Common

  2. chown tomcat:tomcat /var/ilx/workspaces/Common/archive

  3. chmod g+w /var/ilx/workspaces/Common/archive

Additional Information

None.
