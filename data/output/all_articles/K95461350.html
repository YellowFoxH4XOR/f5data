K95461350: HTTP/1.1 403 Forbidden when uploading QKVIEW from BIG IQ for managed BIG IP devices.

Source

Description

when trying to send qkview to ihealth through GUI (Monitoring >> Reports >> Device >> iHealth >> Reports ), the below message appears on GUI and fail.

Unexpected response when testing authentication: HTTP/1.1 403 Forbidden


Environment

  • BIG-IQ
  • v8.x
  • Upload BIG-IP qkview
  • Have specify a web proxy for secure communication on BIG-IQ
  • Test Credentials are successful
     

Cause
Either proxy requires authentication bypass and SSL check bypass.

Recommended Actions

You can manage to resolve this issue by configuring Authentication bypass and SSL check bypass on the proxy for the following 2 domain names:
  • api.f5.com
  • ihealth-api.f5.com
 

Additional Information
None.
