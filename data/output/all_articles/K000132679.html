Description

This document provides step-by-step instructions on how to disable any bot signature on BIG-IP ASM.

Environment

  • BIG-IP ASM with bot signatures enabled.

Cause

None

Recommended Actions

To disable each bot signature, follow the steps below:

  1. Check the bot signature:
  2. Before disabling each signature, check the Bot Class and Bot Category for each bot signature. For example, to disable the bot signature named "Postman", go to Security > Bot Defense > Bot Signatures > Bot Signatures List.
  3. Go to Security > Bot Defense > Bot Defense Profile.
  4. Create a new Bot Profile OR select an existing Bot Profile
  5. Go to Bot Mitigation setting and Click "+ Add Exception" for Mitigation Setting Exception.
  6. Select "Untrusted bot" or ">" and do not check the checkbox.
  7. Select "Http library" or ">" and do not check the checkbox.
  8. Then you can see all bot list Under Http library.
  9. Scroll down and check "Postman-Alarm" and click "Add".
  10. Change the Mitigation Settings Exceptions for "Postman" to "None."

After completing these steps, the bot signature "Postman" will be disabled. Repeat these steps for each bot signature that needs to be disabled.
