Known Issue

The BIG-IP ASM system does not accept the correct definition for the reserved XML namespace xmlns:xml.

This issue occurs when all of the following conditions are met:

  • A BIG-IP ASM security policy is configured with an XML profile.
  • A request specifies the xmlns:xml namespace.

The namespace prefix xml: is bound by definition to the namespace http://www.w3.org/XML/1998/namespace; however, the BIG-IP ASM does not recognize this definition.

Impact

The XML policy will be incorrectly enforced.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Requests that contain the correct namespace declaration xmlns:xml="http://www.w3.org/XML/1998/namespace" will generate violations similar to the following example:

     "Malformed XML data" (Illegal Namespace Violation)
