Description

After a client certificate is parsed, Certificate Revocation List Distribution Point (CRLDP) authentication fails because Certificate Revocation List (CRL) signature can not be verified dumping this error:

CRLDP Auth agent: CRL lookup failed for LDAP url '<CRL URL>' reason 'Could not verify signature'

Environment

  • BIG-IP deployed wih APM.
  • APM using a CRLDP auth agent to validate client certificates.
  • CRLDP object configured to verify CRL signature

Cause

client certificate's issuer and CRL's issuer must match. 

Certificate:
    Data:
        Version: 3 (0x2)
        Issuer: DC = lan, DC = lab, CN = CA
        X509v3 extensions:
            X509v3 Authority Key Identifier:
                48:9E:F1:EF:DE:C6:AE:5C:C4:BF:43:4E:CC:4F:B4:EF:92:EE:26:F7        

Certificate Revocation List (CRL):
        Version 2 (0x1)
        Issuer: DC = lan, DC = lab, CN = CA
        CRL extensions:
            X509v3 Authority Key Identifier:
                48:9E:F1:EF:DE:C6:AE:5C:C4:BF:43:4E:CC:4F:B4:EF:92:EE:26:F7

Note APM uses client certificate's issuer certificate to verify CRL's signature. 
If both issuer do not match, APM will fail to verify CRL signature and will dump that error.

Recommended Actions

You need to modify client certificate or CRL in order both issuer to match.  
Or disabling on APM 'verify CRL signature' feature in the CRLDP object.
