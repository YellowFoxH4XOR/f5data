K53631303: Capturing HTTP headers of a request in a log file

Type

Published
2020-01-14
Updated

Applies to

Source

Description

You may want to capture HTTP headers of a request to a log file.

Environment

  • NGINX Plus

Cause

None

Recommended Actions

To log some particular HTTP header, use $http_variable within the log_format directive. For example, to log the Accept-Encoding HTTP header, add the $http_accept_encoding variable to the existing formatting string:

log_format compression '$remote_addr - $remote_user [$time_local] '
                       '"$request" $status $bytes_sent '
                       '"$http_referer" "$http_user_agent" "$gzip_ratio" '
                       '"$http_accept_encoding"';

Additional Information

All headers are written to the error.log file with the severity level set to debug. For more information about debug level logging, refer to the Debugging NGINX section of the NGINX Plus Admin Guide.
