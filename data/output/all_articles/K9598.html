Known Issue

This is the result of a known issue. When a virtual server targets another virtual server and the SYN Check Activation Threshold is reached, the client connection resets.

This behavior occurs when a virtual server targets another virtual server, typically through the use of an iRule to allow a different profile to handle the traffic, and the SYN Check Activation Threshold is reached on the target virtual server. A SYN cookie is sent to the client, but the connection is reset. This behavior is due to termination of the connection flow within the BIG-IP before the client is able to respond with a SYN/ACK packet, which allows the connection to be established.

Note: For information regarding SYN cookie protection, refer to K7847: Overview of BIG-IP SYN cookie protection.

F5 Product Development is tracking this issue as CR112073.

Note: This issue does not affect the BIG-IP version 10.x software branch.
