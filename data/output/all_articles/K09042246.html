K09042246: ASM Memory Utilization bd swap size graph is incorrect

Type
Support Solution
Published
2020-07-15
Updated
2026-08-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.X.X, 15.1.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 15.0.1, 15.0.0
Source
https://my.f5.com/manage/s/article/K09042246

Description
The units of the bd swap size graph in Security ›› Reporting : ASM Resources : Memory Utilization is displayed in the wrong unit of measurement.

Environment

  • BIG-IP ASM
  • ASM Memory Utilization Graph
  • BD SWAP Memory

Cause
The units of measurement are calculated incorrectly for bd swap size.

Recommended Actions

The units of bd swap size should be read as MB instead of GB.  The following workaround can be applied to fix this issue:

1. Use an editor such as vi or nano and edit the /etc/avr/monpd/monp_asm_memory_info_measures.cfg file, find this section:nano /etc/avr/monpd/monp_asm_memory_info_measures.cfg
#
# BD Swap Size
#
[bd_swap_size]
formula=round(sum(swap_size)/(count(distinct time_stamp)), 2)

And change to this:#
# BD Swap Size
#
[bd_swap_size]
formula=round(sum(swap_size)/(count(distinct time_stamp)*1024), 2)
2. Save the changes and return to the shell and then restart monpd.tmsh restart sys service monpd
This will display the SWAP size with the correct units.
