Known Issue

This is the result of a known issue. The Java version of the Microsoft Terminal Services (Remote Desktop) client cannot connect to Windows 2008 and Windows Vista systems. Users attempting to access Windows 2008 and Windows Vista systems using the Java client receive an error message similar to the following example:

Wrong modulus size! Expected64+8got:264

Note: The Microsoft Terminal Services Java client was introduced in FirePass version 6.0.3. You enable the Java client by selecting the Java client check box in the Terminal Servers favorite configuration.

The ActiveX version of the Microsoft Terminal Services client can connect to Windows 2008 and Windows Vista systems. However, the ActiveX version only supports Microsoft Windows clients.

F5 Product Development tracked this issue as ID 296429 (formerly CR122060) and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally this issue was fixed in cumulative hotfix HF-603-4 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

If the Windows 2008 or Windows Vista system is accessible through a Network Access or Java Application Tunnel favorite, Mac OS X clients can work around this issue by downloading Remote Desktop Connection Client for Mac 2 and then using this utility to access the remote host through the FirePass favorite.

Note: Users can download the Remote Desktop Connection Client for Mac 2 at http://www.microsoft.com/mac/products/remote-desktop/default.mspx.

Alternately, if you do not need to support Linux and Mac OS X clients, you can work around this issue by enabling the ActiveX version of the Microsoft Terminal Services client. To do so, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Application Access: Terminal Servers: Resources page.
  3. Select the name of the Terminal Servers favorite you want to configure.
  4. Clear the Java client check box.
  5. Click the Update button.

When users launch the Terminal Servers favorite, the client system will now use the ActiveX version of the Microsoft Terminal Services client.
