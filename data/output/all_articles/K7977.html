K7977: BIG-IP LTM terminates the connection when an HTTP CONNECT request is followed by pipelined data

Known Issue

This is the result of a known issue. The HTTP CONNECT method is used to establish a proxy tunnel through HTTP. The CONNECT method is often used to enable SSL connections to be established through an HTTP proxy. When an HTTP CONNECT request is followed by pipelined data, the BIG-IP LTM terminates the connection.

F5 Product Development tracked this issue as CR84367 and it was fixed in BIG-IP LTM 9.4.4 and 9.6.1. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

You can work around this issue by configuring the following iRule to disable the BIG-IP HTTP parser after the client detects an HTTP CONNECT request. To do so, perform the following procedure:

  1. Log in to the BIG-IP LTM Configuration utility.
  2. Navigate to Local Traffic > iRules.
  3. Click Create.
  4. Type a name for the iRule.
  5. Enter the following iRule syntax in the Definition field: 
    when HTTP_REQUEST {  if { [HTTP::method] equals "CONNECT" }{   HTTP::disable } }
  6. Click Finished.

You must now associate the iRule with the virtual server.
