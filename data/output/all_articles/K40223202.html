K40223202: How to modify the Cluster Display Name in BIG-IQ for existing devices

Type
Support Solution
Published
2021-05-28
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X, 6.X.X
Source
https://my.f5.com/manage/s/article/K40223202

Description

The Cluster Display Name for a device is not modifiable post-discovery. 

After discovering a device you cannot:

  • Change the Cluster Display Name for a device.
  • Add a managed device to an existing Cluster Display Name.
  • Create a new Cluster Display Name for a discovered device.

Environment

  • BIG-IQ CM with DSC clustered BIG-IPs managed.

Cause
This is the expected behavior.

Recommended Actions

Remove all services and remove the managed devices

To change the cluster display name, you must first remove all discovered services for the device. The procedure then guides you through the path of removing the managed device. Alternatively, after you remove services, you can delete the existing cluster display name, add a new one, then re-discover each service for the devices; however, there are less steps if you simply remove and then re-add the device in the BIG-IQ inventory.

Impact of procedure: Statistics collection will be interrupted and you will lose statistics that have been gathered for the devices. The device configuration will be removed from the BIG-IQ as well as any undeployed changes.

  1. ConfigSync the managed BIG-IPs either from the DSC Groups page on the BIG-IQ or from the manged devices themselves. For more information about ConfigSync on the managed devices refer to K13920: Performing a ConfigSync using the Configuration utility.
  2. Log in to the BIG-IQ User Interface.
  3. Go to Devices > BIG-IP DEVICES.
  4. Select the check box next to the device for which you want to modify the cluster display name.
  5. Select Remove All Services.
  6. If prompted, select Continue. You should now see that services are being removed in the Services column.
  7. Once the services have been removed select the check box next to the device and select Remove Device.
  8. Confirm the device is correct and select Remove. It may take a few minutes for the GUI to update.
  9. Repeat steps 3 through 8 for the peer device.

Re-Add the devices to the inventory and configure a new cluster display name

To re-discover and re-import the configuration and rename the cluster display name in the process you can re-add the BIG-IP devices to the BIG-IQ inventory. The procedure below is a more simplified version of the procedures in K31035272: Discovering multiple BIG-IP devices with your BIG-IQ system and importing the BIG-IP service configurations. Refer to that article for more thorough explanations of all settings.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. From the BIG-IQ User interface go to Devices > BIG-IP DEVICES.
  2. Select Add Devices(s).
  3. On the Add Device page for Discovery Type select the option to add multiple BIG-IP devices, Add BIG-IP device(s) and automatically discover and import services.
  4. Configure the Snapshot and Conflict Resolution as needed.
  5. Select Add Devices in the Devices table.
  6. In the Add Devices to Discovery Task window enter the IP address of the first device.
  7. Select the + button.
  8. Add the IP address of the peer device.
  9. For Cluster Display Name in the drop down list select Create New.
  10. Type in the new cluster display name.
  11. Configure other settings as needed.
  12. Review all settings and select Save & Close.
  13. Review the device list and select Discover & Import.
  14. Select Close in the information window.
    Note: On the BIG-IP Devices page, you can monitor the discovery progress in the Services column and you can verify statistics collection settings by selecting the link in the Stats Collection Status column.
