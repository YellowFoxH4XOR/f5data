Known Issue

The virtual server state may fluctuate when the configured pool contains an FQDN node member.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a monitored pool that contains a single member that is an FQDN node.
  • A virtual server is configured to use the pool.
  • The IP address resolution of the FQDN node changes.

Impact

The virtual server temporarily fluctuates to the down state.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the resolved IP address of the FQDN node changes, the virtual server configured to use the pool fluctuates from available to offline and then back to available.
  • Access to the associated virtual server is temporarily interrupted.

Workaround

To work around this issue, you can configure the affected pool to use a Priority Group specifying a fallback static IP pool member, or configure multiple FQDN node pool members prioritizing the preferred FQDN node.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
