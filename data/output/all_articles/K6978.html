Known Issue

This is the result of a known issue. The BIG-IP ASM MySQL database password is randomly generated upon installation of the BIG-IP ASM. If a MySQL password is manually reset or generated upon installation with certain regular expression metacharacters, such as a plus symbol, the BIG-IP ASM process will restart continuously.

F5 Product Development tracked this issue as CR73337, and it was fixed in BIG-IP ASM 9.4.1. For information about upgrading, refer to the BIG-IP ASM release notes.

Workaround

You can work around this issue by setting a new password for the MySQL database that does not contain a regular expression metacharacter. To do so, perform the following procedure:

  1. Log in to the BIG-IP ASM command line.
  2. Stop the BIG-IP ASM process by typing the following command:

    bigstart stop asm

  3. Set a new password for the MySQL database that does not contain a regular expression metacharacter by typing the following command:

    /usr/share/mysql/mysqlpw -p <newpassword>

  4. Restart the BIG-IP ASM process by typing the following command:

    bigstart start asm
