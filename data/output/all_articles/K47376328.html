Description

When adding a BGP neighbor to the ZebOS(imish) shell an error is returned. 
Neighbor needs to be activated under corresponding address family

You may also notice the following:

  • BGP neighbor configuration is seen in ZebOS
  • No route information is exchanged

Environment

  • Configuring the BIG-IP for BGP dynamic routing

Cause

This issue is caused and being tracked by known issue ID 641376.

Recommended Actions

To workaround this error message you will need to restart the tmrouted process by running the command below:

(tmos)# restart sys service tmrouted

To bypass this issue in the future you can enter the address family configuration mode and then execute the "neighbor activate" command.

(config-router)# address-family ipv4
(config-router-af)# neighbor <x.x.x.x> activate
