K11251: The RADIUS profile setting may disappear when configuring a TCP virtual server

Known Issue

This is the result of a known issue. Currently, RADIUS profiles can only be applied to UDP virtual servers. In certain instances, BIG-IP LTM incorrectly displays the RADIUS Profile setting in the virtual server configuration when Protocol is set to TCP. If you select a profile from the RADIUS Profile menu when configuring a virtual server, and the Protocol setting is set to TCP, the RADIUS Profile setting disappears from the Configuration utility.

This is a cosmetic issue; the profile selected from the RADIUS Profile menu prior to the setting disappearing is not applied to the TCP virtual server.

F5 Networks Product Development is tracking this issue as CR131182.
