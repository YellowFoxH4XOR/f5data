K000153172: Compiling new App protect policy display error: "Failed on insert to PLC.PL_BOT_SIGNATURES (DBD::SQLite::db do failed: NOT NULL constraint failed: PL_BOT_SIGNATURES.bot_signature_id)"

Type
Support Solution
Published
2025-08-27
Updated
2025-08-27
Applies to
  • NGINX Products
  • F5 Distributed Cloud Services
  • NGINX App Protect WAF: 5.0.0
Source
https://my.f5.com/manage/s/article/K000153172

Description

When attempting to deploy a new NGINX App Protect policy, the system displays an error log similar to the following:

ERROR: compiler-controller/compiler.go:380 app protect compiler error: Failed to import policy from '/tmp/nms-policy.json' - Could not add the '/policy/bot-defense/mitigations/policy-bot-signatures' element. Failed on insert to PLC.PL_BOT_SIGNATURES (DBD::SQLite::db do failed: NOT NULL constraint failed: PL_BOT_SIGNATURES.bot_signature_id)

Environment

  • NGINX App protect policy with custom bot signatures
  • NGINX Instance manager

Cause

NGINX App protect does not support custom bot signatures.

Recommended Actions

NGINX App protect does not support custom bot signatures. Proceed to delete the custom bot signature or submit a new case to obtain further information about this topic.

Bot Signature File Details

For reference, the default bot signature file is included_bot_signatures. Starting with NGINX App Protect WAF release 4.7, this file is located at the following path: /opt/app_protect/var/update_files/bot_signatures/included_bot_signatures.

This file is part of the app-protect-bot-signatures package and contains an up-to-date, automatically generated list of all bot signatures. Its format is similar to the README-style text files found in the attack signature directory.

This file contains essential information which includes:

 

  • Bot name
  • Bot type
  • Bot classification/catego

Example:

# cat /opt/app_protect/var/update_files/bot_signatures/included_bot_signatures | head
Included Adidx bot signature, Id: 200099001, Category: Crawler
Included aHrefs bot signature, Id: 200099002, Category: Crawler
Included Alexa bot signature, Id: 200099003, Category: Crawler
Included archive.org bot signature, Id: 200099004, Category: Crawler
Included Artmixx bot signature, Id: 200099005, Category: Crawler
Included Careerbot bot signature, Id: 200099006, Category: Crawler
Included Evri bot signature, Id: 200099007, Category: Crawler
Included ExaBot bot signature, Id: 200099008, Category: Crawler
