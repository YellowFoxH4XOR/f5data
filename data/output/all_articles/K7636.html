Known Issue

This is the result of a known issue. The MCP method used by the BIG-IP GTM to query a BIG-IP LTM for the virtual server and node status, may result in the incorrect virtual server being marked as down.

Note: This issue is a result of a fix introduced in CR65706. For more information about this CR, refer to K7631: The BIG-IP LTM virtual server status is incorrectly reported to the BIG-IP GTM.

The issue occurs when the mcpd process provides a status of the available pools, virtual servers, and members to the BIG-IP GTM. If a virtual server is marked as down due to its members being down, the MCP method incorrectly reports all the virtual servers on the list that come after the down server as down to the BIG-IP GTM.

F5 Product Development tracked this issue as CR66806, CR68184, and CR66814, and it was fixed in BIG-IP LTM 9.1.3, 9.2.4, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM release notes.
