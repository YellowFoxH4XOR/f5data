Overview

F5 Insight is an AI-driven fleet telemetry platform designed to provide centralized visibility and analytics across BIG-IP device fleets. This document describes the software support lifecycle policy that governs all F5 Insight platform releases, including the support windows, update cadence, and End-of-Life (EoL) milestones applicable to each release type.

Note: This policy applies to the F5 Insight platform only and is distinct from the BIG-IP TMOS software support policy. For BIG-IP software support, refer to K5903: BIG-IP software support policy.

Release types

F5 Insight uses a two-tier release model consisting of Major Releases and Feature Releases. These release types differ in scope, delivery cadence, and support duration.

Major Releases (x.0)

F5 publishes Major Releases (for example, 1.0, 2.0, and 3.0) on a quarterly cadence, approximately every three months. A Major Release incorporates:

  • The cumulative content of two preceding Feature Releases.
  • Significant architectural changes or platform enhancements requiring an extended development runway.
  • New integrations, module introductions, or infrastructure-level changes.
  • Security hardening and dependency updates.

Major Releases are the recommended baseline for production deployments. The Standard Support phase for a Major Release begins on the first customer ship date and continues for six (6) months.

Feature Releases (x.1, x.2, x.3)

F5 publishes Feature Releases (for example, 1.1, 1.2, 1.3) on a six-week cadence within a major version stream. Each Feature Release includes:

  • New capabilities and UI/UX improvements developed during a four-week development sprint.
  • Two weeks of integration testing and validation prior to general availability.
  • Bug fixes, performance improvements, and minor security patches.

Feature Releases are cumulative; each Feature Release supersedes the prior one within the same major version stream. The Standard Support phase for a Feature Release begins on its first customer ship date and continues for three (3) months.

Note: F5 Insight does not publish separate hotfix or point releases. This platform delivers security and defect fixes through the next scheduled Feature or Major Release. For critical vulnerabilities, F5 may issue an out-of-band emergency release; F5 will communicate such releases through the F5 Insight changelog and F5 Security Announcements.

Support phases

Each F5 Insight release progresses through the following support phases:

  • Standard Support
  • End of Software Development
  • End of Technical Support

Standard Support

The Standard Support phase is active from the first customer ship date until the release reaches its End of Software Development (EoSD) and End of Technical Support (EoTS) milestone. During this phase:

  • The F5 Insight engineering team actively develops and ships fixes for confirmed defects.
  • Security vulnerability patches are incorporated into the next Feature or Major Release.
  • Technical support cases are accepted and investigated.
  • New capabilities may be added.

End of Software Development

When a release reaches its EoSD milestone, F5 will no longer develop software fixes, hotfixes, or consulting deliverables targeting that release. If you are running an EoSD version, F5 strongly encourages you to upgrade to the current supported Feature or Major Release.

End of Technical Support

The EoTS milestone marks the formal end of the support lifecycle for a given release. After EoTS:

  • F5 Support will not open new cases targeting that release version.
  • The release is considered EoL.
  • You must be on a supported release to receive technical assistance.

Note: For F5 Insight, EoSD and EoTS occur on the same date unless specifically declared otherwise by F5.

Delivery and update model

F5 Insight is delivered as an on-premises platform. The following policies apply to the update model:

  • F5 notifies customers of upcoming releases through the in-product notification system and the F5 Insight changelog.
  • BIG-IP device-side components (iRules, iApps, telemetry agents) are managed through the BIG-IP systems and are versioned independently.

Note: The BIG-IP software support policy governs support for BIG-IP TMOS versions managed by F5 Insight and is independent of the F5 Insight platform support policy described in this document.

Managed device compatibility

F5 Insight supports management of BIG-IP devices running software versions within the Standard Support phase as defined by K5903: BIG-IP software support policy. F5 Insight may provide limited read-only visibility into devices running EoSD versions of BIG-IP TMOS; however, automation, skills execution, and configuration management capabilities require a BIG-IP version within active Standard Support.

For the current BIG-IP software compatibility matrix, refer to K9476: The F5 hardware/software compatibility matrix.
