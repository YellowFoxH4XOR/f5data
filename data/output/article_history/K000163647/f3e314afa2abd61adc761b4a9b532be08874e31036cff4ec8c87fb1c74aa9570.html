K000163647: Generate an F5 Insight License Manifest in a Disconnected Environment

Type
Support Solution
Published
2026-10-29
Updated
2026-10-29
Applies to
  • BIG-IP
  • F5 Insight
Source
https://my.f5.com/manage/s/article/K000163647

Description

Submitting an F5 Insight telemetry report with curl -d can return a ParameterParseJsonError because the API may not parse the report as JSON. Use --data-binary to send the complete JSON payload.

{

"httpCode": 400,

"name": "ParameterParseJsonError",

"message": "Given parameter undefined is invalid. Value (\"<telemetry-report>\") cannot be parsed into JSON."

}

Environment

  • F5 Insight deployed in a disconnected or air-gapped environment
  • Internet-connected system used to submit the telemetry report
  • Telemetry report downloaded from the F5 Insight user interface
  • F5 license token in JWT format
  • F5 telemetry API endpoint:
    https://API_1.example.com/ee/v1/entitlements/telemetry

Cause

The affected curl -d request did not transmit the telemetry report contents in a format accepted by the API. The API therefore received an invalid JSON value and returned ParameterParseJsonError.

Answer/Recommended Actions

  1. Download the telemetry report from the F5 Insight user interface.
  2. Transfer the telemetry report to an internet-connected system.
  3. Ensure that the F5 license token is available on the internet-connected system. Protect the token and do not disclose it in support attachments, logs, or public documentation.
  4. Submit the telemetry report using --data-binary:

<telemetry-report-json> | curl -X POST \
-H "Content-Type: application/json" \
-H "Authorization: Bearer <JWT_LICENSE_TOKEN>" \
--data-binary @telemetry-report.json \
"https://API_1.example.com/ee/v1/entitlements/telemetry"

  1. Confirm that the API response contains a manifest property:

{

"manifest": "<LICENSE_MANIFEST_JWT>"

}

  1. Transfer the returned license manifest to the disconnected F5 Insight environment.
  2. Import the license manifest through the F5 Insight disconnected licensing workflow to complete activation.

Additional Information

  • The telemetry report is submitted from an internet-connected system; the F5 Insight deployment itself does not need direct internet access.
  • The API request must contain the telemetry report as JSON, not the literal report identifier or path.
  • Keep the JWT license token and returned license manifest confidential.
  • A successful submission returns a license manifest in the response.
