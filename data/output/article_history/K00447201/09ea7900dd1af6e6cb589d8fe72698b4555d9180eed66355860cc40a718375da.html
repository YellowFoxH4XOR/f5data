Description

Remote syslog showing incorrect hostname, localhost.localdomain, in /var/log/apm:
localhost.localdomain -notice- apmd[5313]: 014902b4:5: /Common/MY_APM_SAML_SSO_PROD:Common:b03cd0ca: SAML Agent: /Common/MY_APM_SAML_SSO_PROD_act_saml_auth_ag, Matched IdP connector

Environment

  • Remote syslog configured: 
sys syslog {

    include destination DEST_MY_REMOTELOG {udp(192.168.1.10 port (514));};filter FILTER_MY_REMOTELOG {level (notice...emerg) or program(bcm56xxd) or program(lacpd); };log {source(local);filter(FILTER_MY_REMOTELOG);destination(DEST_MY_REMOTELOG);};

}

  • APM provisioned

Cause

Messages which are logged to journald use the configured hostname while sylog-ng uses the hostname (machine name) and truncates it starting at the first FQDN delimiter, '.' .
This issue is being tracked in Bug ID 998649.

Recommended Actions

Re-configure the remote syslog to include the options use_fqdn and keep_hostname:

# tmsh modify sys syslog include "options {use_fqdn(yes); keep_hostname(yes); };"
# tmsh save sys config
