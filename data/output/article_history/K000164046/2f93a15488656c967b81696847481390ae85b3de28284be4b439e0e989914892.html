K000164046: Unable to upgrade the device with new version as the upgrade stops on 10%

Type
Support Solution
Published
2026-10-29
Updated
2026-10-29
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000164046

Description

A standalone BIG-IP Virtual Edition (VE) software upgrade stops at approximately 10% during installation and does not complete. The upgrade fails because the VE virtual disk is smaller than the recommended minimum for the target version. The installation cannot continue without sufficient disk space.

Symptoms and messages:

  • The software installation progress stalls at about 10%.
  • The upgrade does not complete, and the device remains on the previous version.
  • The following warning appears in the logs and can be ignored for this issue:

Environment

  • BIG-IP
  • Upgrade
  • Virtual disk size: 43 GB

Cause

The BIG-IP VE virtual disk is undersized. The available disk space is below the recommended minimum for provision all modules, so the installation process stalls and cannot complete.

Recommended Actions

  1. Verify the current virtual disk size of the BIG-IP VE from Host.
  2. Increase the virtual disk size from the hosting platform.
  3. Confirm that the BIG-IP VE recognizes the expanded disk space.
  4. Retry the software upgrade.
