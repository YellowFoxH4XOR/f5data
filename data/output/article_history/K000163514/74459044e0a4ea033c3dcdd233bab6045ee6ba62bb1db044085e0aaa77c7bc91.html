K000163514: vesctl Does Not Support securemesh_site_v2

Type
Support Solution
Published
2026-10-01
Updated
2026-10-01
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud WAF
Source
https://my.f5.com/manage/s/article/K000163514

Description

The command vesctl configuration get securemesh_site_v2 <site-name> --namespace system returns an unknown-command or unsupported-resource error because securemesh_site_v2 is not included in the available vesctl command set.

Environment

  • F5 Distributed Cloud
  • Resource: securemesh_site_v2
  • Namespace: system
  • CLI: vesctl

Cause

securemesh_site_v2 is supported by the Distributed Cloud API, but it is not supported by the available vesctl binary. vesctl is deprecated and is not expected to be updated with support for this resource.

Recommended Actions

Use the supported Distributed Cloud REST API to retrieve the securemesh_site_v2 object.

  1. Open the securemesh_site_v2 API reference.
  2. Use the documented REST operation to retrieve or list securemesh_site_v2 objects.
  3. Specify the system namespace and the required site name.
  4. Authenticate with credentials that have permission to read the object.
  5. For automation, process the REST API response instead of using vesctl.

If the REST API returns an authorization error, verify the credentials and permissions for the specified namespace. An unknown-resource error from vesctl is expected for securemesh_site_v2.

Additional Information

The absence of securemesh_site_v2 from the vesctl command list does not indicate that the API resource is unavailable. The API documentation is being updated to remove the deprecated vesctl example and retain supported API alternatives.
