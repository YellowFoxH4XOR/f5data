K000164374: Reduce Exposure to CVE-2026-121481 by Configuring Upload Size Limits in BIG-IP ASM/Advanced WAF

Type
Support Solution
Published
2026-11-25
Updated
2026-11-25
Applies to
  • BIG-IP
  • BIG-IP ASM
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000164374

Description

CVE-2026-121481 is an OpenSSL vulnerability where a function EVP_EncodeBlock() is called and the output is converted into text-friendly Base64 data, which increases the size by one-third.  The vulnerability is triggered by a Base64-decoded payload close to INT_MAX (approximately 1.5 GB).

It is unrelated to HTTP/web traffic. Consequently, ASM/Advanced WAF attack signatures do not mitigate it. Limiting the size of uploads accepted by HTTP endpoints reduces exposure.

Environment

  • BIG-IP ASM (Advanced Web Application Firewall), version 17.5.1.8
  • Security policy protecting HTTP endpoints that accept file uploads (multipart/form-data)

Cause

  • CVE-2026-121481 is an OpenSSL flaw, unrelated to HTTP/web traffic.
  • The trigger condition is a Base64-decoded payload of approximately 1.5 GB (close to INT_MAX).

Answer/Recommended Actions

  1. Review all HTTP endpoints that accept uploads. Set the upload size limit to the application's actual maximum upload size. For example, if the application accepts a maximum of 100 MB, set the limit to 100 MB where there is no need to use the approximately 1.5 GB threshold.
  2. Enforce a global limit per file type in the security policy:
    • Navigate to HTTP Message Protection → File Types.
  3. For a per-URL limit on a URL that accepts multipart/form-data uploads:
    1. Create a parameter at the URL level using the upload parameter's name.
    2. Set Parameter Value Type to User-input value.
    3. Set Data Type to File upload.
    4. Set Maximum Length according to the application's requirements.
  4. Optionally, enforce the same limit with the Illegal POST data length violation.

Additional Information

  • Limiting upload size reduces exposure because the trigger cannot be reached when accepted input sizes are capped well below the threshold.
  • ASM/AWAF attack signatures are not applicable to CVE-2026-121481.
