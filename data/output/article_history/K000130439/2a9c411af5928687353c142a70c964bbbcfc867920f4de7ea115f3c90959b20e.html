K000130439: Configuring the Rewrite Control List (RCL) to use Modern JavaScript rewriting for Portal Access

Type
Support Solution
Published
2023-01-03
Updated
2026-10-29
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000130439

Description

BIG-IP APM Portal Access has two JavaScript rewriting modes:

  • Legacy: the original rewriting mode. It supports JavaScript up to ECMAScript 5 (ES5). Legacy is the default mode, so that existing configurations are not changed by an upgrade.

  • Modern: rewriting for ECMAScript 2015 (ES6) and later. For the JavaScript versions that Modern mode supports in each BIG-IP version, refer to K15142093: BIG-IP APM Portal Access - JavaScript compatibility.

You select the mode with the Rewrite Control List (RCL) in the rewrite profile. An application that does not match an RCL entry is rewritten in Legacy mode. The RCL is different from the Rewrite List: the Rewrite List (split tunneling) controls which hosts are rewritten, and the RCL controls how they are rewritten.

If an application uses ES6 or later JavaScript, configure Modern mode for it. Modern mode does not resolve every issue; if the application still fails, refer to the end of Recommended Actions.

Environment

  • BIG-IP APM 17.1.x, 17.5.x, or 21.1.x

  • Portal Access resource and rewrite profile

  • Back-end application that uses ES6 or later JavaScript

Cause

Legacy mode supports JavaScript up to ES5 only. Applications that use ES6 or later must be rewritten in Modern mode.

Answer/Recommended Actions

Impact of procedure: All applications on virtual servers that use this rewrite profile and match the RCL entry are rewritten in Modern mode. To limit the change to one application, use a host-specific entry (step 6).

  1. Log in to the Configuration utility.

  2. Go to Access > Connectivity / VPN > Portal Access > Rewrite.

  3. Click the name of the rewrite profile that is attached to the virtual server, or click Create to create a new one.

  4. Select Enable Split Tunneling. The Rewrite List, Bypass List, and Rewrite Control List settings are shown only when split tunneling is enabled.

  5. In Rewrite List, enter *://* and click Add.

  6. In Rewrite Control List, set the following, and click Add:

    • Mode: Modern

    • Protocol: Any

    • Host Match: Any String

      • To use Modern mode for one application, select a match type and enter the back-end host name in Host, for example application.example.com. To use Modern mode for all applications, select Any String.

    • Path Match: Any String

  7. Click Update (or Create for a new profile).

  8. If you created a new rewrite profile, attach it to the Portal Access virtual server.

If there are multiple RCL entries, the first matching entry is applied. Put host-specific entries before general entries.

Note: If only one application has issues and the others work as expected, add an RCL entry for that application's host only.

If the application still does not work in Modern mode:

  • Upgrade to the latest maintenance release of a supported BIG-IP version. For the JavaScript versions each BIG-IP version supports, refer to K15142093.

  • Try the latest browser-side rewriter file: K000148786: Latest cache-fm-Modern.js file for Portal Access.

  • Open a support case and provide the data listed in the Collect HTTPWatch or HAR files for support section of K14184: Troubleshooting BIG-IP APM Portal Access applications.
