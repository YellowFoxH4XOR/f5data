K000130439: Configuring the Rewrite Control List (RCL) to address ES6/7/next compatibility for Portal resource

Type
Support Solution
Published
2023-01-03
Updated
2024-09-09
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.0, 15.1.9
Source
https://my.f5.com/manage/s/article/K000130439

Description

Due to the compatibility issues between Java Script ES6/7/next and Portal Access rewrite, rewrite may cause the application fail.
To fix compatibility issues between Java Script ES6/7/next and Portal Access, you need to install / upgrade to version v15.1.9,v 16.1.4 or v17.1.0, so the Rewrite Control List (RCL) settings can be configured.

Rewrite Control List, this is different than the rewrite list. The Rewrite Control List will enable the modern JS support, to make the applications work.

Environment

  • BIG-IP APM
  • Virtual Server
  • Access policy
  • Portal Access
  • Rewrite profile
  • ES6/7/next Java script

Cause

  • Bug ID 592353
  • Bug ID 957453

Recommended Actions

You need to install / upgrade to version v15.1.9,v 16.1.4 or v17.1.0, to support RCL feature.
Please configure the rewrite profile, enable Split Tunneling, then you can configure the RCL.
If there are multiple RCL entries, then the first matching entry will be applied.
The RCL can be set it up as follows:

Access ›› Connectivity / VPN : Portal Access : Rewrite 

Rewrite List  -  *://*

Rewrite Control List (RCL):

Mode: Modern

Protocol: Any

Host Match: Any String

Path Match : Any String

Note: all applications on the virtual server with that Rewrite profile attached will use the new modern framework.

If they only want to target a few apps then they need to put more specific entries into the RCL list.

For Example..

Mode: Modern

Protocol: Any

Host Match: internal.corp.app.local

Path Match: Any String

If they only have one application that is having issues and other are working as expected then I would suggest just adding in the one host RCL entry.
