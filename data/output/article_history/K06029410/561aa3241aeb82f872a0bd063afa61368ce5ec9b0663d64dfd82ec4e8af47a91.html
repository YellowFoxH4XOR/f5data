K06029410: BIG-IP ASM not getting attack signature live updates from internet automatically

Type
Support Solution
Published
2020-11-23
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.1.2
Source
https://my.f5.com/manage/s/article/K06029410

Description

  • BIG-IP ASM not getting attack signature updates automatically
  • No errors on logs or GUI

Environment

  • ASM
  • Automatic attack signature updates enable
  • No management route to configured callhome.f5.com - 104.219.104.0/21

Cause

Connection to callhome.f5.com is going through TMM interface instead of management. Routes in the TMM subtable are defined with a lower metric than routes in the management subtable. As a result, if an equally specific route exists as both a TMM route and a management route, the system will prefer the TMM route. This also applies if the only defined management route is a default gateway, the system will prefer the TMM default gateway.

Recommended Actions

Add a static management route to callhome.f5.com - 104.219.104.0/21

  1. Connect to CLI
  2. Add a static route for traffic to use the management network

    tmsh create /sys management-route f5-signatures network 104.219.104.0/255.255.248.0 gateway <gateway_IP>

    Note: Replace <gateway_IP> with your network gateway IP.

  3. Save changes

    tmsh save /sys config
