Description

How to tell if your BIG-IP is experiencing issues related to system resources

Environment

  • BIG-IP
  • Qkview / iHealth

Cause

None

Recommended Actions

The easiest way to investigate potential device resource shortages is to use the analysis tools available in iHealth.
  1. Generate a qkview and upload it to iHealth Note: See related content for details
  2. Start be reviewing the CPU and Memory utilization over the time period of the issue (up to 30 days) using the Graph tab
  3. If you don't find obvious signs of resource shortages in the graphs, you may also review the log files under the Files tab. Resource errors and warnings, relating to traffic processing, would tend to be logged to /var/log/ltm. General system resource issues would be logged to /var/log/kern or /var/log/daemon.
  4. Perform more general log searches for the virtual server name and IP and the related pool to investigate any errors that may be related to a traffic disruption.

Additional Information

None
