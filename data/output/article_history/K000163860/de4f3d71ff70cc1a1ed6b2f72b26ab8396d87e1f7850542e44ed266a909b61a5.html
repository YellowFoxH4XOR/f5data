K000163860: UCS restoration fails when /config/bigip_base.conf contains an incomplete command

Type
Support Solution
Published
2026-10-23
Updated
2026-10-23
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000163860

Description

UCS restoration fails when BIG-IP AWAF cannot load /config/bigip_base.conf. The configuration load reports an incomplete command on line 3, followed by UCS installation failure. ASM XML/JSON processing-memory errors, including event code X131, may also be displayed.

Environment

BIG-IP AWAF 17.5.1 migrated from an iSeries system to an rSeries BIG-IP tenant. The UCS was loaded with no-license no-platform-check platform-migrate.

Cause

The migrated /config/bigip_base.conf contains an incomplete command on line 3, preventing the base configuration from loading and causing UCS installation to abort.

Answer/Recommended Actions 

  1. Restore the valid backup file:
    cp /config/bigip_base.conf.bak /config/bigip_base.conf
  2.  Create the required VLANs on the F5OS appliance. 
  3. Set the BIG-IP tenant to Configured, add the VLANs to the tenant, and set the tenant to Deployed. 
  4. After the tenant boots, reset the master key:
    f5mku -r
  5.  Recreate the required Self IPs.
  6.  Manually remove the invalid static route from bigip.conf.
  7.  Reload and save the BIG-IP configuration.

Additional Information

ASM XML/JSON processing-memory errors, including event code X131, can occur as secondary symptoms during the failed UCS restoration. These errors do not identify the incomplete command in /config/bigip_base.conf as the root cause.
