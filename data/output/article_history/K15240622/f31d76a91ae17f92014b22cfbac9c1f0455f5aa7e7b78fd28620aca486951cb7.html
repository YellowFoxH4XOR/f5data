K15240622: Unable to import ASM policy into BIG-IQ shows network commutation failure

Type
Support Solution
Published
2021-12-08
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X
Source
https://my.f5.com/manage/s/article/K15240622

Description
Unable to import ASM policy into BIG-IQ with the below error

Error querying 'ASM Policy - Parameter' from path '/mgmt/tm/asm/policies/<policyid>/parameters' on device <device_name> (<device_ip>), network communication failed due to protocol error

Environment

  • BIG-IQ running 8.x/7.x
  • BIG-IP ASM provisioned

Cause
Huge ASM policy parameter response. Needs to be pull them in small numbers. 
 

Recommended Actions


1. Use the below command to get the current configuration. 
# restcurl -u admin: /mgmt/cm/asm/preferences/discovery-page-size

2. Modify the ASM_POLICY_PARAMETER value to 10 (Default is 500) from the above output and update the configuration using the below restcurl request. 
# restcurl -u admin: -X PUT '/mgmt/cm/asm/preferences/discovery-page-size' -d '<paste_updated_config>'
