K000163664: Unable to activate, deactivate, or upgrade F5 Insight license after trial expiration

Type
Support Solution
Published
2026-10-12
Updated
2026-10-12
Applies to

  • F5 Insight: 1.2.X, 1.2.2, 1.2.1, 1.2.0
Source

Description

When working with F5 Insight trial/evaluation licenses, you may encounter one of the following symptoms when attempting to reactivate or deactivate an expired trial license or when attempting to replace an expired trial license with a paid license:

  • When attempting to reactivate or deactivate an expired F5 Insight trial license, the local system fails with the following error message:

    Could not initialize product, the provided digitalAssetId is unavailable (code: "data-integrity")

  • On F5 Insight version 1.2.x, when trying to replace an expired trial license with a newly purchased paid license, the activation system fails with the following error message:

    Request body exceeds the maximum allowed

Environment

  • You are running F5 Insight 1.2.x.
  • The F5 Insight trial license has expired.

Cause

Once a trial license has expired for F5 Insight, the F5 license server no longer recognizes the device's digital asset ID. The local system retains the stale activation state, which prevents clean reactivation. Furthermore, on F5 Insight 1.2.x, the upgrade pathway is blocked because the system rejects the new license transaction while the old trial key is still bound locally.

Recommended Actions

If you are currently running 1.2.x and want to continue using your trial license, the recommended course of action is to leave the license configuration as-is. Trial license expiration is not actively enforced on these versions.

If you are trying to upgrade to a paid license and encounter either of the symptoms listed above, F5 Support must perform a backend state reset. Please open a support case with F5 Support and reference this article. Our support engineers will assist in running a cleanup script to reset your local license state and apply your production license.
