Source

Description

APM logs as an excessive number of the following log message

 

1490514:3: (null):Common:00000000: Access encountered error: ERR_NOT_FOUND

 

Environment

  • BIG-IP APM
  • BIG-IP SSLO

Cause

APM requires all virtual addresses to be assigned to the same traffic group. When this message occurs, verify that APM's virtual server addresses are all assigned to the same traffic group.

Recommended Actions

Move the virtual server address to the traffic group used by APM.

None
