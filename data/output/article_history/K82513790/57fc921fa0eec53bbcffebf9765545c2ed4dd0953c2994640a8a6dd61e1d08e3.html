K82513790: All SSL profiles shown on SSL Certificate Instances tab

Type
Support Solution
Published
2022-01-04
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.4
Source
https://my.f5.com/manage/s/article/K82513790

Description

All SSL profiles are shown when navigating to System >> Certificate Management : Traffic Certificate Management: SSL Certificate List >> <Certificate> Instances tab.

 


Certificate in question is not applied to all of the SSL profiles.

Environment

  • GUI
  • SSL certificates

Cause

Bug ID 940177: Certificate instances tab shows incorrect number of instances in certain conditions

Recommended Actions

Upgrade to a fixed version (15.1.5 or later).

Additional Information

This issue only happens when a Certificate is listed without an associated key in the SSL Certificate List. For example, this can be seen with the built-in f5-ca-bundle.
