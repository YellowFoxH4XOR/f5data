Description
Here are the steps to delete ASM signature file from CLI.
 

Environment

  • Login to BIG-IP via CLI
  • BIG-IP ASM

Cause 

None 

Recommended Actions

  1. Login to BIG-IP ASM via CLI
  2. List the ASM signature files, and note the "id" which you would like to delete;
      # restcurl -u admin:admin /mgmt/tm/live-update/asm-attack-signatures/update-files/
  3. Delete the ASM signature file;
     # restcurl -u admin:admin -X DELETE /mgmt/tm/live-update/asm-attack-signatures/update-files/<id>
  4. Confirm that the ASM signature files is deleted;
     # restcurl -u admin:admin /mgmt/tm/live-update/asm-attack-signatures/update-files/<id>
