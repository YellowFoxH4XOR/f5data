Topic

You should consider using this procedure under the following condition:

  • You need to verify the synchronization status (sync status) for a device group.

Description

The ConfigSync feature synchronizes configuration changes from one BIG-IP device to other devices in a device group. Configuration synchronization (ConfigSync) ensures that the BIG-IP device group members maintain the same configuration data and are available to process traffic when a traffic group fails over. You can monitor the sync status for a device group using the Configuration utility or the TMOS Shell (tmsh).

When monitoring the sync status for a device group, you should be aware of the following:

  • The sync status and ConfigSync operation is dependent on the device service clustering (DSC) communication channel; the BIG-IP devices need to communicate over TCP port 4353.
  • You must monitor the sync status for a device group from a device that resides in the device group. Monitoring the sync status for a device group from a device that is not part of that group may display an unexpected sync status. For example, if the BIG-IP system configuration contains multiple devices in different device group combinations such that a device group can be viewed by a device that is not part of that group, attempting to monitor the sync status for the device group from a device that is not a group member may display the sync status as Unknown. (In certain BIG-IP versions the device shows the sync status as Changes Pending, although the actual sync status for the device group is In Sync).

Sync status designations

The BIG-IP system displays the following sync status designations for a device group:

  • In Sync - The device group is synchronized.
  • Awaiting Initial Sync - The device group is awaiting the initial ConfigSync.
  • Changes Pending - There is a possible change conflict between device group members.
  • Not All Devices Synced - Some device group members did not receive the last sync successfully.
  • Sync Failure - A validation error occurred while syncing to a remote device.
  • Unknown (one of the following):
    • You are not logged in to the primary cluster member.
    • The local device is not a member of the selected device group.
    • The peer device is not a member of the selected device group.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have created one or more device groups on the BIG-IP system.
  • You have access to the Configuration utility or tmsh.

Procedures

Verifying the sync status for a device group using the Configuration utility

To verify the sync status for a device group using the Configuration utility, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility of a BIG-IP device that resides in the device group that you want to monitor.
  2. Go to Device Management > Overview.
  3. Under Device Groups, locate the device group name.
  4. View the sync status designation for the device group.

Verifying the sync status for a device group using the Configuration utility (11.0.0 - 11.2.0)

To verify the sync status for a device group using the Configuration utility, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility of a BIG-IP device that resides in the device group that you want to monitor.
  2. Go to Device Management > Device Groups > Group_Name > ConfigSync.
  3. The ConfigSync Properties section displays the ConfigSync status for the device.

Verifying the sync status for a device group using tmsh

To verify the sync status for a device group using tmsh, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh of a BIG-IP device that resides in the device group that you want to monitor by typing the following command:

    tmsh

  2. To display the sync status for a device group, use the following command syntax:

    show /cm sync-status

    For example, the following output displays the sync status for the device groups defined on the system:
