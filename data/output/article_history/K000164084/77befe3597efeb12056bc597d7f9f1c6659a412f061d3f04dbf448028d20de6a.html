K000164084: AFM Default Global Policy Drop Action Not Enforced After Upgrade to BIG-IP 17.5.1.11

Type
Support Solution
Published
2026-11-03
Updated
2026-11-03
Applies to
  • BIG-IP
  • BIG-IP AFM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000164084

Cause

Unknown at time of publication. Upgrading from 17.5.1.8 to 17.5.1.11 with the default action set to reject/drop. 

Answer/Recommended Actions

Workaround: Toggle the Default Global Policy action to restore enforcement.

  1. Confirm the default action on the device with list sys db tm.fw.defaultaction. 
  2. Change the Default Global Policy action from current to any different action (accept/reject/drop).
  3. Change the Default Global Policy action back to original action.
  4. Test access from a client outside the allowlist to confirm the traffic is blocked.
  5. Verify the workaround results with live traffic or using AFM Packet Tracer

Additional Information

  • Expected behavior: With the default action set to drop, traffic that does not match an allow entry is blocked.
  • AFM Packet Tracer may report "allow" for traffic that is not enforced. Use live client tests as the primary validation method.
  • If Packet Tracer results conflict with live traffic, clear the browser cache and retest.
