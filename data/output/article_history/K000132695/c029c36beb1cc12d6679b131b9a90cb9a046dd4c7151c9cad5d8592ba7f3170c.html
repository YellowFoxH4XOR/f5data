Topic

This article applies to BIG-IP Next Service Proxy for Kubernetes (SPK). For information about other products, refer to the following article:

  • K914: Displaying the software version of your F5 product

You should consider using this procedure under the following condition:

  • You want to display the SPK software version.

Description

To determine the software version number for your SPK instance, you must list the container images running in the SPK namespace in your OpenShift cluster and compare those with the Software Releases page on Cloud Docs.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have a valid user account on an OpenShift cluster running BIG-IP Next SPK.

Procedures

List running container images

You can view the container images in your Service Proxy pod by specifying either jsonpath or json output formatting.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the OpenShift cluster.
  2. List the container images running in your Service Proxy pod using the following command syntax:

    oc -n <Service Proxy namespace> get pod -o jsonpath="{.items[*].spec.containers[*].image}" | awk -F "/" -v RS=" " '{print $3}'

    For example, for a Service Proxy namespace named spk-ingress, enter the following command:

    oc -n spk-ingress get pod -o jsonpath="{.items[*].spec.containers[*].image}" | awk -F "/" -v RS=" " '{print $3}'

    The output should appear similar to the following:

    tmm-img:v1.6.5
    f5dr-img:v0.5.8
    tmrouted-img:v0.8.21
    f5-debug-sidecar:v5.55.6
    f5-fluentbit:v0.1.29
    f5ingress:v5.0.29
    f5-license-helper:v0.5.9

    Alternatively, if you have the jq utility installed on your OpenShift cluster, you can use the following command:

    Note: For more information about the jq utility, refer to https://stedolan.github.io/jq/.

    oc -n spk-ingress get pod -o json | jq -r '.items[].spec.containers[] | (.image / "/")[2]'

  3. Compare the output of the command in the previous step to the Software Releases page on Cloud Docs to determine which version of SPK you have installed.
