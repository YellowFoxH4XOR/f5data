K000163655: macOS 27 Firewall Endpoint Check Fails in BIG-IP APM with EPSEC 1.0.0-1915.0

Type
Support Solution
Published
2026-10-12
Updated
2026-10-12
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000163655

Description

On macOS 27, BIG-IP Edge Client may fail the Endpoint Firewall Check even when the endpoint firewall is enabled and functioning. The failure prevents VPN establishment and terminates the BIG-IP APM session with the message: “Session deleted due to user inactivity.”

Environment

  • BIG-IP APM 17.5.x
  • BIG-IP Edge Client on macOS 27
  • Endpoint Firewall Check configured
  • EPSEC 1.0.0-1915.0 or earlier installed
  • Endpoint firewall enabled and functioning

Cause

EPSEC 1.0.0-1915.0 may not correctly detect the endpoint firewall after an upgrade from macOS 26 to macOS 27. This causes endpoint inspection to fail and the VPN session to terminate.

Answer/Recommended Actions

  1. Upgrade EPSEC to epsec-1.0.0-2028.0.iso or a later supported release.
  2. Deploy the updated EPSEC components to affected BIG-IP Edge Client endpoints.
  3. Verify firewall detection and VPN connectivity after the update.
  4. Validate endpoint-inspection behavior after future macOS upgrades before broad deployment.

Additional Information

The same firewall configuration works normally with BIG-IP Edge Client on macOS 26.
