Topic

You should consider using these steps under the following condition:

  • You want to prepare for F5 Harden Releases and Security Notifications.

On July 15, 2026, F5 released Hardened Release 1 (HR1). F5 strongly recommends you promptly update your environment with each hardened release.
On August 13, 2026, F5 announced a change to the frequency of hardened releases. F5 will deliver hardened releases on a six-week cadence instead of a monthly cadence. For more information, please refer to Our first hardened release cycle: What we learned and how we're changing.
F5 is pausing security notifications. We will continue to issue out-of-band security notifications (OOBSN) for actively exploited vulnerabilities or when coordinated disclosure obligations require it. For more information, refer to K000162901: Changes to F5 hardened release cadence.

Description

F5 delivers hardened releases on a six-week cadence and discloses specific vulnerability fixes from the hardened releases. Hardened releases are published in advance so you can take measures to prepare your F5 systems. Refer to the following guidance to help your system:

  • Steps to take before F5 Hardened Release
  • Steps to take after a security notification

Note: To be notified about F5 security advisories related to security notifications and Out-of-Band Security Notifications (OOBSNs), subscribe to F5 Security Announcements. These announcements include links to security advisory articles containing detailed descriptions and steps to address the issue. To learn how to subscribe, refer to K9970: Subscribe to email notifications regarding F5 products and security announcements.

Steps to take after a security notification

F5 recommends taking the steps in the following table after a security notification.

RecommendationDetailsResource
Review the F5 Security Notification overview article for the period.F5 publishes a Security Notification overview article for security notification which contains a summary of all F5 vulnerabilities and security exposures announced.
  • K12201527: Overview of F5 security notifications
Review the security advisory and security exposure articles.
  • Security advisory articles describe the vulnerabilities and include information such as the CVE or VU number, the affected products and versions, and any mitigation information.
  • Security exposure articles describe a security exposure issue and include information such as affected products and versions, any mitigation information, and the ID number tracked by F5 Product Development.
  • Refer to the Security Notification overview article after the security notification announcement for a complete list of security advisory and security exposure articles disclosed in the announcement.
  • K41942608: Overview of MyF5 security advisory articles
Determine if your F5 systems are affected.
  • Review the security advisories and related materials to determine if your F5 systems are affected by vulnerabilities announced in the security notification.
  • Use F5 iHealth to check your BIG-IP system for known vulnerabilities and consider scheduling your audits to align with security notification disclosures.
  • In rare cases, after updating your system with a hardened release, additional steps may be required to address a vulnerability. Review the security advisories and related materials to determine if this is necessary.
  • K12201527: Overview of F5 security notifications
  • K27404821: Using F5 iHealth to diagnose vulnerabilities
