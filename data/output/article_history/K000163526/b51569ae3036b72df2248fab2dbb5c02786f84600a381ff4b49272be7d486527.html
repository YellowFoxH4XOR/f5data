Description

This article covers feedback into the inquiry for ASM signature protection for K000162605: BIG-IP APM vulnerability CVE-2026-94127.

Environment

  • Modules provisioned: BIG-IP ASM / Advanced WAF

Cause

N/A.

Answer/Recommended Actions

A user-defined signature can be created with the following signature rule to help mitigate this APM vulnerability issue:

content:"/f5-oauth2/v1/userinfo"; nocase; content:"Authorization: Bearer "; nocase; re2:"/Authorization\s*:\s*Bearer (?:[^\r\n]{16}){1000}[^\r\n]{634,}/i";

Additional Information

For more information on creating User-Defined Signatures: Manual Chapter : Writing Custom Attack Signatures.
