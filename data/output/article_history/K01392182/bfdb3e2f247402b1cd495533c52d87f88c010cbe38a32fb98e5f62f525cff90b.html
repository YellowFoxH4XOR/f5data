Description

You can see multiple logs similar to the example below in /var/log/messages, /var/log/user.log and you can also see these on the GUI, System > Logs > System:

 notice syslog-ng[<PID>]: Configuration reload request received, reloading configuration;
 notice pendsect[<PID>]: skipping drive -- Model:    HGST HUS722T1TALA604
 notice pendsect[<PID>]: No known drives detected for pending sector check.   Exiting
 notice root[<PID>]: Deleting file /shared/core/*.core.*
 notice root[<PID>]: Deleting file /shared/core/*.core.*
 notice root[<PID>]: Deleting file /shared/core/*.core.*
 notice root[<PID>]: Deleting file /shared/core/*.core.*

Environment

  • Logs showing in /var/log/messages and GUI 

Cause

Bug ID 887505: Coreexpiration script improvement

Recommended Actions

Follow the workaround mentioned in the Bug tracker link. 

For example:

config # cat /usr/bin/coreexpiration

---snip---

for filename in /shared/core/*.core.*; do
+     [ -e "$filename" ] || continue                                   <---- add this line here
    # Time of last modification as seconds since Epoch
    EPOCHAGE=$(stat -c "%Y" $filename)
    if [[ $EPOCHAGE -lt $CUTOFF ]]; then
        if [[ "$WRITELOG" == "yes" ]]; then
            $LOGCMD "Deleting file $filename"
        fi
        rm -f $filename
    fi
done
