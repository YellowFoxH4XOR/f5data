K000135622: Duplicate location error when attempting to update API

Type
Support Solution
Published
2023-07-27
Updated
2023-07-27
Applies to
  • NGINX Products
  • NGINX Controller: 3.19.4-APIM
Source
https://my.f5.com/manage/s/article/K000135622

Description

Attempts to update a published API results in the following error:

Failed testing config before applying: nginx: [emerg] duplicate location "<location_uri>" in /etc/nginx/nginx.conf:<line_number> nginx: configuration file /etc/nginx/nginx.conf test failed

Environment

NGINX Controller - APIM
Instance Groups
Embedded Postgres

Cause

DPM cache corruption 

Recommended Actions

Reset cached deployments

  • Open a bash prompt to the postgres pod 
    $ kubectl exec -it controller-postgres-0 /bin/bash
bash-5.1#
  • Open a psql prompt  
    bash-5.1# psql
psql (12.5)
Type "help" for help.
naas=#
  • Switch to the common database  
    naas=# \c common
You are now connected to database "common" as user "naas".
common=#
  • Clear the instance groups' nginx deployment cache and exit  
    common=# update instance_groups set nginx_deployment='{}';
UPDATE x
common=# exit
bash-5.1# exit
exit
  • Restart the dataplane manager pod (delete it)  
    $ kubectl delete pod -lapp=dataplane-manager
