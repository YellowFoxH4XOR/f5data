Description

I want to redirect my home page to /services.html or /team.html without Redirect Route. 

Environment

  • F5® Distributed Cloud Console

Answer/Recommended Actions


This can be achieved through Request/Response Manipulation by configuring a Simple Route with a Regex pattern and adding the desired prefix.

Example : I want the domain https://example.com to load https://example.com/team.html as the homepage, but without displaying the full path in the URL.

Steps

  1. Create a Simple Route → choose the required HTTP Method, set Path Match to Regex, enter the regex as /, and add the host header for your domain.

  2. Navigate to Advanced Options under the Simple Route → in Request/Response Manipulation, enable Prefix Rewrite, and specify the path as /team.html.

  3. Save the Changes
