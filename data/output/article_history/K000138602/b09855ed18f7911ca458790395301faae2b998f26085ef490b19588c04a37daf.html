Description

New boot volume is in Audited status after installing new software image.

Environment

  • BIG-IP LTM
  • New software installation

Cause

Lind daemon did not finished its audit process correctly.

Recommended Actions

  1. Verify file \"/shared/noupgrade\" don't exists. If yes, delete it (K91155702: Boot Volumes show status ''Audited'').
  2. Restart lind daemon:
    tmsh restart sys service lind

Additional Information

After lind is restart in the GUI you should see Install status as "complete". You can verify the same on via CLI by checking the liveinstall.log. You should see live install succeeded message at the end of the log file.

 less /var/log/liveinstall.log

info: Installation succeeded.
progress: 98/100
*** Live install end at <date and time>: succeeded ***
