K33302139: ''General SSLEngine problem'' error when uploading qkviews to iHealth on a BIG-IQ

Type
Support Solution
Published
2021-09-30
Updated
2023-03-24
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X
Source
https://my.f5.com/manage/s/article/K33302139
Description

When trying to upload qkviews to iHealth from a BIG-IQ the following error is found on GUI:

Error testing authentication: General SSLEngine problem

You may also see similar error in log file /var/log/restjavad.0.log:

..java.lang.Exception: Login failed: General SSLEngine problem

Environment

  • BIG-IQ
  • Using a HTTP proxy to upload files to iHealth or to license the BIG-IQ
  • The proxy server rewrites the SSL certificate for iHealth server or License server

Cause

The rewritten certificate is not loaded in the Big-IQ Java trusted store.

Recommended Actions

Option 1:
Configure "ihealth.f5.com" and "ihealth-api.f5.com" as an exception on the proxy to not rewrite certificates.

Option 2:

Add the proxy SSL CA certificate to Java trusted store on BIG-IQ.

Impact: You have to restart the restjavad process, and BIG-IQ services to all managed devices may be interrupted temporarily. F5 recommends that you perform this procedure during a scheduled maintenance window. 

Important: this method will not survive a BIG-IQ upgrade.

  1. Retrieve the CA (Certificate Authority) certificate from the HTTP proxy. A CA certificate's "Issuer" and "Subject" are same. After the proxy CA certificate is installed in BIG-IQ JAVA trust store, the proxy signed certificate can be validated using the root certificate chain of trust.

  2. Save the CA certificate in a file on the BIG-IQ CM (for instance, in /var/tmp/proxy.cer) and run the below commands in BIG-IQ CLI (Replace the <name-of-cert> with the name you choose):

    • mount /usr -o remount,rw

    • cd /usr/lib/jvm/java-1.8.0-openjdk.x86_64/bin/

    • ./keytool -import -trustcacerts -keystore ../jre/lib/security/cacerts -storepass changeit -alias <name-of-cert> -import -file /var/tmp/proxy.cer

    • mount /usr -o remount,ro

  3. Restart restjavad by entering the following command:

    tmsh restart /sys service restjavad

  4. (Optional) Use the command to display all current installed certificates in JAVA trust store:

    ./keytool -list -v -keystore ../jre/lib/security/cacerts -storepass changeit 

  5. Try to upload qkviews to iHealth.
