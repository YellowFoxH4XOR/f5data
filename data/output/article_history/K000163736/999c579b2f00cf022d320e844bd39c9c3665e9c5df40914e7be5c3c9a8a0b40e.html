K000163736: VELOS controllers fail to PXE boot after using Disk Erase utility: PXE-E18: Server response timeout

Description

After using the Disk Erase utility on startup to wipe the disks of both system controllers, the controllers fail to PXE boot.

>>Checking Media Presence......
>>Media Present......
>>Start PXE over IPv4.
  PXE-E18: Server response timeout.
UEFI Interactive Shell v2.1

Environment

  • VELOS system controllers
  • After Disk Erase
  • PXE boot

Cause

This is expected. A system controller can only PXE boot off another system controller in the chassis that is already online and operational in F5OS.

Recommended Actions

Clean install at least one of the system controllers via USB flash drive to recover from this state.

  • Manual Chapter : Install or Upgrade Software

Another system must be used to prepare the flash drive with the desired F5OS image.
