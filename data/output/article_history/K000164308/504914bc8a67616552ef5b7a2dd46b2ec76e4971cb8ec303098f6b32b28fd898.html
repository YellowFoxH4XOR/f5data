Security Advisory Description

Concurrent Execution using Shared Resource with Improper Synchronization vulnerability in Apache HTTP Server's mod_http2 in assign_headers() can lead to RCE. This issue affects Apache HTTP Server: from 2.4.55 through 2.4.70. Affected releases of mod_h2 from GitHub: from 2.0.8 through 2.0.42. (CVE-2026-119618)

Impact

There is no impact; F5 products are not affected by this vulnerability.

Security Advisory Status

F5 Product Development has evaluated the currently supported releases for potential vulnerability, and no F5 products were found to be vulnerable.

Note: F5 evaluates only software versions that have not yet reached the End of Technical Support (EoTS) phase of their lifecycle. For more information, refer to the Security hotfixes section of K4602: Overview of the F5 security vulnerability response policy.

Security Advisory Recommended Actions

Using BIG-IP Advanced WAF, BIG-IP ASM, F5 WAF for NGINX, and NGINX App Protect WAF signatures

Although F5 products are not vulnerable to this issue, you may use F5 products to mitigate the impact of this vulnerability in your infrastructure.

If you are using BIG-IP Advanced WAF, BIG-IP ASM, F5 WAF for NGINX, or NGINX App Protect WAF to protect your backend pool members, you can mitigate this vulnerability for your backend pool members by using the following attack signature enabled in Blocking mode:

  • 200204121 Apache mod_http2 Remote Code Execution Server-Side Code Injection CVE-2026-119618

This attack signature is part of the newly released attack signature update ASM-AttackSignatures_20261112_185312.im; you must perform a signature file update to ASM-AttackSignatures_20261112_185312.im or later for this signature to be available on your system.
