Description

The BIG-IP system does not allow you to change the name or rename some configuration objects.

If you want to change the name of a configuration object (such as pool names, or virtual server names) you must actually delete and re-create the object.

Environment

  • BIG-IP
  • Configuration objects: (VLANs, self IPs, virtual server name, pool name, and profile names, and so on)

Cause

This is by design.

Recommended Actions

F5 recommends that you delete the old object and re-create a new object with the name you want if you want to change the name of a configuration object.

Additional Information

For configuration objects that do allow you to rename them, it is still recommended that you create a new object with the name you want and then delete the old one.
