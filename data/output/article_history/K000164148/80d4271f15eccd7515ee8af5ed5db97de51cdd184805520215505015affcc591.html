K000164148: F5 Application Services Templates stuck in "In Progress"

Type
Support Solution
Published
2026-11-07
Updated
2026-11-07
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000164148

Description

BIG-IP Application Services Templates (FAST) deployments may remain in an "In Progress" state in the Configuration utility history tab. Analysis of the application's problem details identified a missing certificate. Restarting the GUI services (restjavad and restnoded) cleared the stale "In Progress" entry.

Environment

  • Feature: F5 Application Services Templates (FAST)
  • Template: bigip-fast-templates/http
  • Deployment: High-availability pair; the stuck deployment was observed on the active unit

Cause

There are multiple reason for the task to stuck in the "In Progress" but the most are due the missing objects in config.

Answer/Recommended Actions

  1. Identify the AS3 application ID (_as3Id) for the stuck deployment by running the following command on the BIG-IP and copy it for use for the step 2:
    curl -sk -u admin "https://<MGMT IP>/mgmt/shared/fast/tasks" | jq .
  2. List the problems and their details for that _as3Id by running the following command:
    curl -sk -u admin "https://<MGMT IP>/mgmt/shared/appsvcs/task/<_as3Id from the step1>" | jq .
  3. Confirm the missing object or problem by review the message line
  4. Restart the GUI services on the affected unit to clear the stale "In Progress" entry:
    bigstart restart restjavad restnoded
  5. Correct the missing object and re-run the deployment of the template
