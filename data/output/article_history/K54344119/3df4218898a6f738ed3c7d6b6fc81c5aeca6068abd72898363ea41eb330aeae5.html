Description

Failed to install an Engineering Hotfix on a vCMP guest, and the following error messages is logged in /var/log/liveinstall.log :

info: Basic disk format validation passed. 
error: missing /tmp/lind_util.2aALnh/VERSION.LTM 
error: The hotfix is intended for , not BIG-IP 
error: missing /tmp/lind_util.2aALnh/RPMS 
error: status 256 returned by command: rpm --checksig /tmp/lind_util.2aALnh/0 
info: >++++ result: 
info: error: /tmp/lind_util.2aALnh/0: open failed: No such file or directory 
info: >---- 
error: bad stat (256): rpm --checksig /tmp/lind_util.2aALnh/0: No such file or directory 
Terminal error: Software compatibility tests failed. 
 
The following command show:
tmsh show /sys software status
-----------------------------------------------------------------------------------------
Sys::Software Status

-----------------------------------------------------------------------------------------
HD1.1    BIG-IP  13.1.1.2    0.0.4      no                                       complete

HD1.3    BIG-IP  14.1.2.3  0.290.5      no  failed (Software compatibility tests failed.) ####
Note: The base image has installed successfully.

On GUI: System >> Software Management >> Image List
