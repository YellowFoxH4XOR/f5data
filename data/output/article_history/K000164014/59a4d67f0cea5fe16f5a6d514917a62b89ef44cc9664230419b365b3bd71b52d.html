Description

The save analytics virtual report command generates CSV time-series reports for virtual-server traffic metrics. Reports can be saved locally, automated with a shell script, scheduled through cron, and removed after a defined retention period.

Environment

  • AVR
  • CSV reports

Answer/Recommended Actions

The following commands generate local CSV time-series reports for virtual-server inbound and outbound server-side traffic:

tmsh save analytics virtual report view-by virtual \

measures { server-side-bits-in } \

format csv-time-series \

file YYYYMMDD_hostname_in \

range "now-30d--now" \

limit 1000
tmsh save analytics virtual report view-by virtual \

measures { server-side-bits-out } \

format csv-time-series \

file YYYYMMDD_hostname_out \

range "now-30d--now" \

limit 1000

The range value now-30d--now is supported on BIG-IP 17.1.2 and later, retrieves the previous 30 days through the current time.

Optional shell-script automation

1.Save the following script as /config/avr_report.sh:

#!/bin/bash

DATE=$(date +%Y%m%d)
HOSTNAME=$(hostname -s)

tmsh save analytics virtual report view-by virtual \
measures { server-side-bits-in } \
format csv-time-series \
file ${DATE}_${HOSTNAME}_in \
range "now-30d--now" \
limit 1000

tmsh save analytics virtual report view-by virtual \
measures { server-side-bits-out } \
format csv-time-series \
file ${DATE}_${HOSTNAME}_out \
range "now-30d--now" \
limit 1000

# Clean up CSV files older than 90 days
find /var/tmp/ -name "*.csv" -mtime +90 -delete

2. Make the script executable:

chmod +x /config/avr_report.sh

3. Run the script manually to validate report generation and cleanup:

/bin/bash /config/avr_report.sh

Schedule report generation

Add the following crontab entry to run the script at 02:00 on the first and fifteenth day of each month:

0 2 1,15 * * /bin/bash /config/avr_report.sh >> /var/tmp/avr_report_cron.log 2>&1

Verify the configured entry with:

crontab -l

Additional Information

  • CSV files generated by this workflow are saved in /var/tmp/.
  • The cleanup command removes CSV files older than 90 days to prevent accumulation of old reports.
  • The report filename includes the execution date and short hostname.
  • Crontab entries are not preserved across BIG-IP software upgrades. Re-add the scheduled entry after an upgrade.
