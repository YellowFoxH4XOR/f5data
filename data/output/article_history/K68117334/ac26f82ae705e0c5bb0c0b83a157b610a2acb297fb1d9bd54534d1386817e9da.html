Description

F5 rSeries systems have unique serial numbers. The serial number format for the F5 rSeries system is f5-XXXX-XXXX. The serial number begins with the letters f5, followed by a dash character (-), followed by four alphanumeric characters, followed by a dash, followed by four alphanumeric characters. For example, f5-123a-bc45. The serial number barcode sticker is black with white text and is located on the front of the system, on the left side, below the serial console port.

In addition to the barcode sticker, you can also find the serial number in the rSeries system configuration database. There are different methods to display the serial numbers of the various components in an rSeries system. Select one of the following methods that is most appropriate for your environment:

  • Display the serial numbers from the webUI
  • Display the serial numbers from the CLI
  • Display the serial numbers using a REST API command

If you are looking for the BIG-IP registration key, it is located in the license file. For information about displaying the registration key in an rSeries system, refer to the following:

  • Display the registration key from the webUI
  • Display the registration key from the CLI
  • Display the registration key using a REST API command

Display the serial numbers from the webUI

Note: This method is only available in F5OS-A 1.7.0 and later.

Impact of procedure: Performing this procedure should not have a negative impact on your system.

  1. Log in to the webUI of the rSeries system as the admin user.
  2. Go to SYSTEM SETTINGS > General.
  3. Scroll down to the System Inventory section, you can locate the serial number in the Platform row.

Display the serial numbers from the CLI

Impact of procedure: Performing this procedure should not have a negative impact on your system.

  1. Log in to the CLI of the rSeries system as the admin user.
  2. To display the serial numbers, enter the following command:

    show components component state serial-no

    The command returns an output similar to the following example:

    NAME      SERIAL NO     
    ------------------------
    lcd       sub1234g56es  
    platform  f5-abcd-efgh 
    psu-1     FZ1234Q56789 
    psu-2     FZ9876Q54321 

    The F5 rSeries system's serial number is displayed in the platform row. In this example, the rSeries system serial number is f5-abcd-efgh.

Display the serial numbers using a REST API command

Impact of procedure: Performing this procedure should not have a negative impact on your system.

  1. Log in to the CLI of the rSeries system as the root user. Alternatively, you can log in to a system that has the curl and jq utilities installed.
  2. To obtain the serial numbers, use the following REST API command syntax:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku <username>:<password> "https://<ip address>/api/data/openconfig-platform:components" | /usr/bin/jq '.[][][] | { "name": .name, "serial": .state."serial-no"}'

    Note: Replace <username> and <password> with the administrator username and password to access the rSeries system, and replace <ip address> with either localhost if you are running the command from the system CLI or the management IP address of the rSeries system. This command retrieves the serial numbers in quoted (") format.

    For example, you should enter the following REST API command if you run it from the rSeries system CLI using the admin user:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku admin:admin "https://localhost/api/data/openconfig-platform:components" | /usr/bin/jq '.[][][] | { "name": .name, "serial": .state."serial-no"}'

    The command returns output similar to the following example:

    {
      "name": "lcd",
      "serial": "sub1234g56es"
    }
    {
      "name": "platform",
      "serial": "f5-abcd-efgh"
    }
    {
      "name": "psu-1",
      "serial": "FZ1234Q56789"
    }
    {
      "name": "psu-2",
      "serial": "FZ9876Q54321"
    }

Display the registration key from the webUI

Impact of procedure: Performing this procedure should not have a negative impact on your system.

  1. Log in to the webUI of the rSeries system as the admin user.
  2. Go to SYSTEM SETTINGS > Licensing.
  3. You can locate the registration key in the Base Registration Key row.

Display the registration key from the CLI

Impact of procedure: Performing this procedure should not have a negative impact on your system.

  1. Log in to the CLI of the rSeries system as the admin user.
  2. To display the registration key, enter the following command:

    show system licensing registration-key

    The command returns output similar to the following example:

    appliance-1# show system licensing registration-key
    system licensing registration-key base XXXXX-XXXXX-XXXXX-XXXXX-XXXXXXX

Display the registration key using a REST API command

Impact of procedure: Performing this procedure should not have a negative impact on your system.

  1. Log in to the CLI of the rSeries system as the root user. Alternatively, you can log in to a system that has the curl and jq utilities installed.
  2. To obtain the registration key, use the following REST API command syntax:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku <username>:<password> "https://<ip address>/api/data/openconfig-system:system/f5-system-licensing:licensing/f5-system-licensing:state/f5-system-licensing:registration-key"

    Note: Replace <username> and <password> with the administrator username and password to access the rSeries system, and replace <ip address> with either localhost if you are running the command from the system CLI or the management IP address of the rSeries system. This command retrieves the registration key in quoted (") format.

    For example, you should enter the following REST API command if you run it from the rSeries system CLI using the admin user:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku admin:admin "https://localhost/api/data/openconfig-system:system/f5-system-licensing:licensing/f5-system-licensing:state/f5-system-licensing:registration-key"

    The command returns output similar to the following example:

    {
      "f5-system-licensing:registration-key": {
        "base": "XXXXX-XXXXX-XXXXX-XXXXX-XXXXXXX"
      }
    }
