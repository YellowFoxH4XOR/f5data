K000156769: Apply access policy error after modifying the kerberos_auth_config_default access profile in BIG-IP APM

Type
Support Solution
Published
2025-10-02
Updated
2025-10-02
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000156769

Description


Modifying the "kerberos_auth_config_default" access profile in BIG-IP APM can result in persistent "Apply Access Policy" prompts and replication failures. Attempts to replicate changes or revert modifications may fail, and the system may display a yellow flag indicating pending configuration changes.


Environment


Product: BIG-IP APM

Platform: F5-LTM-200M-PRM-SUB, BIG-IP

Version: 17.1.2 (and earlier versions prior to bug fix)

Affected Object: "kerberos_auth_config_default" access profile (system-managed)

Cause


The "kerberos_auth_config_default" access profile is a system-managed object and is not intended for user modification. Editing or deleting this profile can cause configuration errors, persistent prompts to apply access policy changes, and replication failures. There is no built-in "undo" function for access profile changes in BIG-IP APM.


Recommendations


Do not attempt to edit or delete the "kerberos_auth_config_default" access profile.

If the system is prompting to apply changes or replication is failing due to modifications to this profile, reboot the affected device. This action typically clears the "Apply Access Policy" flag and restores normal operation.

After reboot, check for any pending configuration changes and attempt to apply them if necessary.

If the profile remains stuck or issues persist after reboot, collect a qkview and relevant logs for further analysis.

Upgrade to BIG-IP version 17.5.0 or later, where Bug ID 1691385 removes the ability to edit the "kerberos_auth_config_default" access policy, preventing this issue from occurring.
