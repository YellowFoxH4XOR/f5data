K000164034: New behavior in Hardened Release (HR)/Critical Release (CR) for HTTPS monitor using ssl-profile with Server Authentication enabled

Description

In Hardened Release (HR)/Critical Release (CR), HTTPS monitor will mark the pool down if incorrect certificate is used in Trusted Certificate Authorities with Server Certificate is set to "require" other settings in the Server Authentication are in its default settings.

Environment

  • BIG-IP
  • HTTPS monitor with ssl-profile with Server Authentication enabled

Cause

Bug ID 2333277

Answer/Recommended Actions

Expected behavior. Now bigd does strict checks for HTTPS monitor.
