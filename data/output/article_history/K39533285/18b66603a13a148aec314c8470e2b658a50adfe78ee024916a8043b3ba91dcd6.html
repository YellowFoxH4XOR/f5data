Description

ASM live updates are failing, with an error similar to the following in the Updates Status popup, after clicking Check for Updates:

Check for updates failed for the following modules:
ASM Attack Signatures - Could not retrieve latest file for asm-attack-signatures
Browser Challenges - Could not retrieve latest file for browser-challenges
Server Technologies - Could not retrieve latest file for server-technologies

A message like the following can be found in /var/log/tomcat/liveupdate.log:

curl: (7) Failed to connect to callhome.f5.com port 443: Connection refused

Environment

  • ASM Live Updates

Cause

HTTPS connection to callhome.f5.com cannot be established.

In this example, there is no SYN/ACK response to the SYN sent out to 104.219.110.134:

10.10.10.1 → 104.219.110.134 TCP OUT s1/tmm3 : 49451 → 443 [SYN]
10.10.10.1 → 104.219.110.134 TCP OUT s1/tmm3 : [TCP Retransmission] 49451 → 443 [SYN]
10.10.10.1 → 104.219.110.134 TCP OUT s1/tmm3 : [TCP Retransmission] 49451 → 443 [SYN]
10.10.10.1 → 104.219.110.134 TCP OUT s1/tmm3 : [TCP Retransmission] 49451 → 443 [SYN]
10.10.10.1 → 104.219.110.134 TCP OUT s1/tmm3 : 49451 → 443 [RST, ACK] [F5RST(peer): handshake timeout]

Recommended Actions

Verify that connections to callhome.f5.com are leaving the system via the desired IP and route.

At the time of this article's publication, callhome.f5.com resolves to 104.219.110.134.

Use the ip command to check which source IP and gateway are used. For example:

ip r g 104.219.110.134

You can also take a tcpdump of the live update traffic. For example:

tcpdump -s0 -vnni 0.0:nnn host <ip of callhome.f5.com>

tcpdump -s0 -vnni eth0 host <ip of callhome.f5.com>

If you have confirmed that the TCP connections to callhome.f5.com are leaving via the desired IP and route, investigate any intermediate devices; perhaps there is a firewall blocking the connection.

It is recommended that you allow certain IP ranges for access to F5 services, as detailed in the following article:

  • K15202: IP addresses for F5 hosted services
