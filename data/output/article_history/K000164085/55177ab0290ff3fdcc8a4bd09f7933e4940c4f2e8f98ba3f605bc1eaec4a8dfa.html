Description

 

On BIG-IQ 8.x, clear-rest-storage fails during the Postgres/pgsecrets step and returns the following errors:

Building built-in rbac definitions

/bin/python2.7: No module named bigiq_setup

error: Decrypt pgsecret failed with error code: 1

 

The failure occurs when the command is run from a sudo session instead of a direct root login.

Environment

  • BIG-IQ Centralized Management
  • Commands run by a non-root user using sudo

Cause

  • The sudo session does not include /usr/local/bin in PATH. /etc/sudoers sets Defaults secure_path = /sbin:/bin:/usr/sbin:/usr/bin, and /etc/profile adds only /usr/sbin and /usr/local/sbin.
  • The system has two python2.7 binaries:
    • /bin/python2.7 (6,432 bytes): the operating-system Python. Its library directory /usr/lib/python2.7 exists.
    • /usr/local/bin/python2.7 (8,261,328 bytes): the bundled Python. Its library directory /usr/local/lib/python2.7 contains bigiq_setup.
  • With the sudo PATH, the script resolves python2.7 to /bin/python2.7, which cannot import bigiq_setup.

Answer/Recommended Actions

Run clear-rest-storage as root.
