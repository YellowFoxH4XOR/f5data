K000149666: FQDN Resolution Issues by Case-Sensitive FQDN Name

Type
Support Solution
Published
2025-02-06
Updated
2026-11-24
Applies to
  • BIG-IP
  • F5 Distributed Cloud Services
  • BIG-IP LTM: 16.1.5
Source
https://my.f5.com/manage/s/article/K000149666

Description

An auto-populated FQDN pool member is marked offline in the BIG-IP Configuration utility (GUI). The same condition is logged in /var/log/ltm with message ID 01070639:5.

show /ltm pool members

--------------------------------------------------------------
| Ltm::Pool Member: Test123.FQDN.Name.CaseSensitive.amazonaws.com
--------------------------------------------------------------
| Status
|   Availability  : offline
|   State     : enabled
|   Reason      : The DNS server(s) are unavailable
|   Monitor Status : fqdn-down
|   Session Status : enabled
|   Pool Name   : Pool-Test123
|   IP Address   : ::

/var/log/ltm

notice mcpd[<PID>]: 01070639:5: Pool /<partition>/<name> member /<partition>/<name>:<port> session status <status>

Environment

  • BIG-IP LTM 16.1.5

Cause

The FQDN pool member name is case-sensitive. When the configured name uses different letter case than the DNS record, the DNS response does not match the request, and the pool member is marked down.

Recommended Actions

  1. Confirm the letter case of the FQDN record on the DNS server.
  2. Change the FQDN pool member name so that its letter case matches the DNS record. For example:
    • Pool member FQDN (configured): Test123.FQDN.Name.CaseSensitive.amazonaws.com
    • DNS record FQDN: test123.fqdn.name.casesensitive.amazonaws.com
  3. Verify that the pool member status returns to available.

Additional Information

For general DNS resolution troubleshooting, including debug logging in /var/log/dynconfd.log, see K50130343: DNS resolution failing marks FQDN Pool or Node(s) down.
