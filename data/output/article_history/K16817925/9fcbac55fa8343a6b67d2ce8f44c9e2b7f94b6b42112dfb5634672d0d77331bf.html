Description

Upgrading BIGIP to v14.1.x or later fails to load config with the following error message

01071d27:4: Error parsing SAML assertion consumer service url: <sp_connector_name> in SAML SP connector (Failed to parse URL  https://<single-logout URL> error (1).)

Environment

  • BIGIP v14.1.x or later
  • APM module 
  • Config fails to load
  • SAML

Cause

Additional spacing in front of the URL

Recommended Actions

Remove unwanted spacing by editing the file /config/bigip.conf
Note: Update the configuration file in the maintenance window to avoid traffic impact. 

  1. Log in to the CLI

  2. Backup the configuration file 
    # cp  /config/bigip.conf   /config/bigip.conf_backup

  3. Edit /config/bigip.conf  using text editor, such as pico or vi
    Look for the respective <sp_connector_name> in SAML SP connector and review the those defined URL. The non-working example shown as following
    apm sso saml-sp-connector /Common/<sp_connector_name> {
        assertion-consumer-services {
            {
                is-default true
                uri https://www.Example.com/saml-agent/Acs
            }
        }
        entity-id https://www.Example.com/
        is-authn-request-signed true
        signature-type rsa-sha256
        single-logout-response-uri " https://www.Example.com/saml-agent/Logout"     <---spacing in front of https://
        single-logout-uri " https://www.Example.com/saml-agent/Logout"              <---spacing in front of https://
        sp-certificate /Common/sp_certificate.crt
    }

  4. Remove the spacing that is causing the issue

  5. Save the file, If using vi, select ESC and enter the following command
    :wq

  6. Reload the configuration
    # tmsh load sys config
