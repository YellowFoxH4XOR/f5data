K000130654: Traffic is slower when passing through the BIG-IP

Type
Support Solution
Published
2023-01-18
Updated
2023-02-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000130654

Description

When traffic is going through the BIG-IP, you may experience slowness in downloads and load times.

 

The BIG-IP by its nature shouldn't limit download speeds. However, there are cases in which the network environment requires TCP Content Spooling.

For more information about content spooling, refer to K3422: Overview of content spooling

 

You may notice multiple TCP Zero Window and TCP Window Full messages in a packet capture, and the TCP LAN and WAN profiles: f5-tcp-wan profile / f5-tcp-lan profile are not helping to increase the speed of bandwidth.

 

Environment

  • BIG-IP LTM
  • TCP Profiles

Cause

Generally, the connection between the client and the BIG-IP system is slower than the connection between the BIG-IP system and the pool member servers. Thus, the BIG-IP system can accept the server's data more quickly, allowing valuable resources on the pool member servers to remain available. Increasing the content spooling setting values increases the amount of data the BIG-IP system will buffer while waiting for a given connection to accept it. Increasing these values can substantially reduce the load for pool member servers as they can offload the data more quickly to the BIG-IP system, rather than waiting for the client to be ready to accept and retrieve more data. The feature works symmetrically, in that it can also offload faster clients and slower servers when uploads are occurring.

 

Recommended Actions

Assign the F5-tcp-progressive profile to the client and server tcp profiles, refer to: K15800216: Overview of the f5-tcp-progressive profile

 

Additional Information

When configuring the f5-tcp-progressive profile, you should consider that using the f5-tcp-progressive profile may result in slightly higher CPU utilization when compared to the parent TCP profile. As a result, you should monitor the system CPU utilization for a time after you associate the f5-tcp-progressive profile with a virtual server.

 

F5 recommends that, instead of modifying a default profile, you create a custom profile using the default profile as the parent profile. You can then modify some or all of the values defined in the custom profile, while leaving the parent profile settings at their default value. For information, refer to K14488: Working with profiles.
