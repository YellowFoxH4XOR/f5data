Description

Previously deployed nPath routing config not working after upgrade to BIG-IP version 16.

Note: The previously deployed nPath routing config was manually configured.

Environment

  • Upgraded from BIG-IP version 15 to BIG-IP version 16.
  • The nPath routing config was deployed manually.

Cause

The requirements for nPath routing are here: K11116: Configuring nPath routing

In BIG-IP version 15 it may be possible to configure a system that does not adhere to this and still works. However, on upgrade to BIG-IP version 16 it will not work.

Recommended Actions

Configure nPath routing config according to the following article: K11116: Configuring nPath routing.

Additional Information

nPath routing can be used in conjunction with BGP to implement anycast routing. A separate change to BGP in BIG-IP version 16 requires that peer-ids be unique. Refer to the following Bug Tracker article for additional information:   Bug ID 1031425: Provide a configuration flag to disable BGP peer-id check
