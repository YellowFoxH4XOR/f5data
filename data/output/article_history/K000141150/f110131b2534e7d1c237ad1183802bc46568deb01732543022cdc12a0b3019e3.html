Description

How to add additional interfaces on Azure BIG-IP VE that are running on single NIC without spinning up a new instance?

Environment

  • BIG-IP VE
  • Azure Cloud
  • Single NIC Instance
  • Add Additional NIC
  • CLI
  • Azure Portal

Cause

None

Recommended Actions

Follow steps below:

1. SSH into Azure BIG-IP VE to run below command to confirm "provision.1nic" is enabled.
tmsh list /sys db provision.1nic

2. If it is not enabled, then please run below command to enable it
tmsh modify /sys db provision.1nic value enable
tmsh save /sys config

3. Once done, proceed to shutdown the BIG-IP VE , may use CLI bash command
shutdown now

4. Login to Azure portal and the single nic instance BIG-IP VE status should now show "Stopped" under "Overview: Essential"

Figure: Azure Cloud Portal BIG-IP VE Status 

5. Once confirm the BIG-IP VE are stopped, proceed to press the "Stop button" and you should received a notification "Successfully stopped the virtual machine" and the status now show "Stopped (deallocated)"

Figure: Azure Cloud Portal BIG-IP VE New Status after Stop (deallocated)

6. After that, go to Networking > Network settings and click on the "Attach network interface" and follow the steps to attach the network interface.
   Note: If there are no additional network interface, please add a new network interface

Figure: Azure Cloud Portal Attach Network Interface

7. Once done attached the new network interface, you will be able to choose between two interfaces


Figure: Azure Cloud Portal new NIC attached to the BIG-IP VE

8. Please continue to follow the normal Azure steps to assign a private/public IP to the new attached network interface

9. Once everything is in place, proceed to start up the Azure BIG-IP and the additional network interface will be ready for the Azure BIG-IP VE further configuration.

Additional Information

Note: After changing the number of NICs, check ID 637827 and ensure there is no STP configuration that still uses 1.0, as this may cause the configuration to fail to load, for example, during a relicensing operation.
