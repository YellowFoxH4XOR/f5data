K000163602: Expand an F5OS-C VELOS partition’s tenant-image volume

Type

Published
2026-10-08
Updated
2026-10-08
Source

Description

A chassis partition’s Images Volume Size specifies storage for tenant images. You can increase a configured volume, but you cannot reduce it. The default is 15 GB; the documented range is 5–50 GB, in 1 GB increments.

Environment

  • F5OS-C 
  • Partition Disk Storage for Tenant Images

Cause

Additional storage needed for Tenant images.

Answer/Recommended Actions

Procedure: system controller webUI

  1. Log in to the VELOS system controller webUI with an account that has admin access.
  2. Select CHASSIS PARTITIONS.
  3. Select the partition you want to edit, then click Edit.
  4. In Images Volume Size, enter a larger value within the documented range, in 1 GB increments.
  5. Click Save.

Procedure: F5OS management CLI

These commands run in the system-controller CLI with chassis-administrator access. The documented CLI command specifies the configuration, images, and shared volume sizes together. Retain the existing configured values for the configuration and shared volumes.

  1. Log in to the VELOS system controller CLI with an account that has admin access.
  2. Inspect the partition volumes with show partitions volumes.
  3. Enter configuration mode with config.
  4. Enter the documented volume-size command, replacing each placeholder with the appropriate partition name and size in GB: 
    partitions partition <partition-name> config configuration-volume <current-configuration-size> images-volume <new-images-size> shared-volume <current-shared-size>
  5. Apply the change with commit.
  6. Return to operational mode with end, then run show partitions volumes to inspect the reported sizes.

Note: Increase only the images volume.
