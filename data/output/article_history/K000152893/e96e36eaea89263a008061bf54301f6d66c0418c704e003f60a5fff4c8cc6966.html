Description

On rSeries host, you observe log message relating to RAS MC correctable errors. These messages can be seen in for example in below locations:

 

  • system_manager - /confd/scripts/f5_confd_run_cmd show system events
    65536 appliance hardware-device-fault EVENT NA "RAS MC correctable errors detected, count=101" "2025-07-01 02:20:20.543522 UTC"
    65536 appliance hardware-device-fault EVENT NA "RAS MC correctable errors count within passing limit, count=1" "2025-07-01 03:25:40.97339049 UTC"

 

  • qkview/subpackages/host-qkview/qkview/filesystem/var/F5/system/log/platform.log
    2025-07-01T03:24:41.558504+01:00 rSeriesHostname alert-service[9]: priority="Notice" version=1.0 msgid=0x2201000000000029 msg="Received event." event="65536 appliance hardware-device-fault EVENT NA 'RAS MC correctable errors detected, count=101' '2025-07-01 03:24:41.551139049 UTC".
    2025-07-01T03:265:41.559504+01:00 rSeriesHostname diag-agent[7]: priority="Info" msgid=0x098200000000000b msg="Component Attribute Changed" node="appliance" category="hardware" component="appliance/hardware/memory" attribute="rasdaemon:mc:corrected:event" severity="Info" health="Ok" value="0x00000001" message="RAS MC correctable errors count within passing limit, count=1" interface="diag-controller"
    2025-07-01T03:24:41.559604+01:00 rSeriesHostname alert-service[9]: priority="Notice" version=1.0 msgid=0x2201000000000029 msg="Received event." event="65536 appliance hardware-device-fault EVENT NA 'RAS MC correctable errors count within passing limit, count=1' '2025-07-01 03:24:41.552239049 UTC'".

These messages typically appear with "Notice" or "Info" severity and reference "RAS MC correctable errors." System health checks (such as show system health) report all components as "ok," and no alarms are present.

Environment

  • rSeries Platform

Cause

These log messages are generated when the system detects correctable memory errors (RAS MC correctable errors). These errors are automatically corrected by the hardware and do not indicate a persistent or critical hardware failure. The messages serve as notifications that some memory errors were detected and corrected, with error counts remaining within acceptable limits.

Recommended Actions

  • These messages are informational only and can be safely ignored if overall system health is reported as "ok" and there are no active alarms.
  • Optionally, a system reboot may be performed to see if the messages stop appearing.
  • If these messages persist or increase in frequency after a reboot,
    • Please perform a power-off reboot of the device when possible, and monitor for continuing errors.
    • If errors persist after the reboot; generate a new qkview file and provide it to F5 Support for further analysis.
  • No immediate hardware replacement or intervention is required unless uncorrectable errors or hardware alarms are reported.
