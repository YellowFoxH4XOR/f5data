Description

When attempting to change the traffic group for a specific Virtual Address, the BIG-IP system may prevent the modification and display the following error message:

Configuration error: The virtual address (/Common/<Virtual_Address>) can not be modified because it is in use by application (/Common/<Application_1.app>/<Application_1>) that does not have a matching traffic group

If you subsequently attempt to resolve this by modifying the traffic group directly on the application referenced in the first error, the system may generate a second error message. This occurs if the Virtual Address is shared with other applications:

01070734:3: Configuration error: Unable to modify the traffic group for application (/Common/<Application_1.app>/<Application_1>) because it uses virtual address (/Common/<Virtual_Address>) which is also used by application (/Common/<Application_2.app>/<Application_2>)

Environment

  • BIG-IP LTM

  • iApp-managed application services

Cause

The shared virtual address is referenced by multiple iApp application services whose application folders inherit their traffic-group assignments. Because the associated applications do not have matching traffic-group configurations, BIG-IP rejects the virtual address modification.

Recommended Actions

To resolve this issue and successfully change the traffic group, you must first disable strict updates for the affected application service and then modify the traffic group on the application's configuration folder.

  1. Identify every iApp application service and application folder that uses the affected virtual address.

  2. Disable strict updates for each associated application service:

    tmsh modify sys application service <application-service> strict-updates disabled

  3. Change the traffic group on each associated application folder to the desired one:

    tmsh modify sys folder /Common/<Application_Name.app> traffic-group <target_traffic_group>

    Note: the "inherited-traffic-group true" should automatically change to false after changing traffic group as above.

  4. Repeat the folder update for every application service that shares the virtual address.

  5. Change the virtual address traffic group to the target traffic_group after all associated applications have matching traffic-group assignments.

  6. Save the configuration:

    tmsh save sys config
