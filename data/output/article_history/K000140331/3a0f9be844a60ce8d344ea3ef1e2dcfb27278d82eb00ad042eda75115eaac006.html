Description

This article is for referencing expected value of 'isMaster|isAsmMaster|isDatasyncMaster' variable on multi-blade ASM vcmp guest or Viprion device

Environment

BIG-IP ASM

Multiple blade Viprion or VCMP guest

Cause

Only the primary blade will have this value set to true. The behaviour is expected.

 

Recommended Actions

Run the following command to verify value on each individual blade

 

Ex. Blade 1 is primary

 

# clsh cat /var/log/tomcat/liveupdate.log | egrep 'isMaster|isAsmMaster|isDatasyncMaster|slot'
