Description

Attempts to push configuration fails with the following error, or something similar:

Failed testing config before applying: nginx: [emerg] duplicate directive

Investigation of configuration doesn't reveal a duplicate directive.

Environment

NGINX Controller

Cause

Corrupt dpm database

Recommended Actions

Reset dpm database:

Access the postgres database system. If the postgres pod is used then use the following command, otherwise access the external postgres database:

kubectl exec --stdin --tty controller-postgres-0 -- /bin/bash

Enter into the postgres database command line

bash-5.1# psql

Switch to the common database

naas=# \c common

Clear the dpm deployment configuration from the database

common=# update dpm_nginx_current_state set dpm_deployment='{}';

Exit the postgres database system

common=# \q

bash-5.1# exit

On the NGINX Controller command line, delete the dpm pod

kubectl delete pod -l app=dataplane-manager
