K000164268: Error on metadata import "service provider cert is required when is_authn_request_signed is true."

Description

BIG-IP APM 21.0.0.x rejected SAML metadata import with the error "service provider cert is required when is_authn_request_signed is true," even though the metadata contained AuthnRequestsSigned="true", a KeyDescriptor use="signing" element, and a BIG-IP-generated certificate. The same failure occurred when importing IdP metadata for an external IdP connector. The issue was reproduced in the lab by Engineering Services and did not occur after upgrading to BIG-IP 21.1.0.


 

Environment

BIG-IP APM 21.0.0.x (VE lab instance)

BIG-IP configured as both a SAML Service Provider and a SAML Identity Provider

SAML metadata import used for both SP and IdP federation configurations

Imported SP metadata contains AuthnRequestsSigned="true" and a KeyDescriptor use="signing" element with a BIG-IP-generated public certificate

Authentication-request signing enabled on the local SAML service, with an SP certificate and signing key assigned.


 

Cause

The error was caused by a SAML metadata import defect in BIG-IP APM 21.0.0.x. The defect was reproduced in the lab and does not occur on 21.1.0, the release to which the customer upgraded. The specific defect ID is not recorded in the case. The customer confirmed that the issue was resolved after the upgrade.


 

Answer/Recommended Actions

Upgrade BIG-IP APM from 21.0.0.x to 21.1.0.1 or the latest available GA release, as recommended by ES. Note that 21.0.0.x is EoSD/EoTS per K5903.

After the upgrade, retest the SAML metadata import for both the SP and external IdP connector configurations.

If the error persists on a supported release, open a new Service Request referencing this case and provide the SAML metadata XML and the SAML configuration.


 

Additional Information

KB K5903 (referenced in case notes): Notice of end of software development and end of technical support for BIG-IP 21.0.0.x (August 6, 2026). Cited as the basis for the upgrade recommendation.

Release note: BIG-IP 21.1.0.1 Release Supplement, cited in case notes as listing about a dozen fixed SAML defects.
