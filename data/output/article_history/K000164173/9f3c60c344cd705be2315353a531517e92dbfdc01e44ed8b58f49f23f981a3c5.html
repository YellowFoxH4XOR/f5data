K000164173: Unable to access the firewall policies using the GUI

Type
Support Solution
Published
2026-11-10
Updated
2026-11-11
Applies to
  • BIG-IP
  • BIG-IP AFM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000164173

Description

On a BIG-IP AFM high-availability pair, the Configuration Utility on the active unit does not display firewall policies under Security > Network Firewall : Active Rules tab.

The active unit's Active Rules list is blank for the virtual server and self-IP contexts. The standby unit shows the rules.

The Device Management > Overview tab also fails to load in the GUI on the active unit.

 

/var/log/httpd/httpd_errors file on the active unit contains repeated entries showing that httpd could not get a response from the restjavad REST service on port 8100:

AH01102: error reading status line from remote server localhost:8100

AH00898 error for /mgmt/tm/sys/global-settings, following an AH01102 entry

 

The GUI on the active unit shows Inline Rule Editor option as not enabled, while the standby GUI shows it enabled.

Output of tmsh list sys db afm.inlineruleeditor command returns true on both units.

Environment

  • BIG-IP AFM
  • active/standby HA pair
  • Network Firewall : Active Rules GUI tab
  • Inline Rule Editor

Cause

Unknown at time of publication.

Recommended Actions

Restart the control-plane daemons to restore normal GUI operation:

bigstart restart httpd tomcat restjavad

 

Note: The restart does not affect traffic. However, the GUI and REST API on the restarted unit are unavailable for a few minutes while the services restart.
