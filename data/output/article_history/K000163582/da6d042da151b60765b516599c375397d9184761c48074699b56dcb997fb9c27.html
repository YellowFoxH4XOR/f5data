K000163582: Understanding BIG-IP ASM Violation Severity, Attack Classifications, and Event Log Correlation

Applies to

Description

BIG-IP ASM can classify traffic using Attack types such as HTTP Parser Attack, Detection Evasion, and Information Leakage. Events with the same Attack type may have different Severity levels, such as Error and Informational, because the Attack type does not determine Severity. 

Environment

  • BIG-IP ASM / AWAF
  • ASM security policy evaluating Application Requests and/or Responses
  • ASM Event logs viewed under Security > Event Logs > Application > Requests

Cause

ASM assigns Severity according to the underlying Violation or Sub-violation. For example, different HTTP Parser Attack events can therefore have different severities when they result from different parsing violations or when the Applicable violations have different configured severity levels. 

Answer/Recommended Actions

1) Navigate to Security > Event Logs > Application > Requests, and locate the relevant event and record its Support ID.

2) Review the event’s violation and sub-violation details. For sample HTTP Parser Attack events, you may investigate the specific detection reason. Examples include:

  • Malformed chunking
  • Invalid Content-Length
  • Unknown HTTP method
  • Missing URL
  • Invalid headers
  • Other unparsable content

3) Navigate to Security > Options > Application Security > Advanced Configuration > Violations List., and locate the Applicable violation and review its configured severity.

4) If a transaction contains multiple violations, use the highest-severity violation to determine the transaction’s overall severity.

5) Review the Events through their violation details or sub-violation field. An example detection reason is Evasion technique detected. As another example, for Information Leakage events through its violation details, the sample reasons could be included as following:

  • Illegal method
  • Illegal HTTP status in response

The available violation severity levels are:

  • Emergency
  • Alert
  • Critical
  • Error
  • Warning
  • Notice
  • Informational 

Additional Information

  • HTTP Parser Attack is an Attack-type classification and is not itself a severity level.
  • Severity and violation rating are separate properties:
    • Severity is the configured Impact level of the violation.
    • Violation rating represents the likelihood of an Attack on a scale from 1 to 5.
  • Use the Support ID and ASM Event details to determine the severity of a specific event.
