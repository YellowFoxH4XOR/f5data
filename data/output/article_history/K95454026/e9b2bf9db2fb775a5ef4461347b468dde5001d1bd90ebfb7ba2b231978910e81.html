Description

The tmsh command "modify sys application service <iapp_name.app/iapp_name> execute-action definition" is meant to be the command line equivalent of the iApp "Finished" button in the Configuration Utility (GUI). However, it's not working as expected when deployment is from an Ansible Playbook. As a result, automation of creation and configuration changes is prevented. There is no error generated thus not until the GUI is checked, behavior is not seen. 

Environment

  • BIG-IP
  • iApp
  • Ansible
  • tmsh modify sys application service <iapp_name> execute-action definition

Cause

This has been reported as F5 Ansible bug #1452: Module "bigip_iapp_service" does not update installed iApp.

Recommended Actions

Workaround at the moment is to complete the deployment manually by going to the Configuration Utility (GUI) -> iApps -> Application Services -> click name of deployed app -> Reconfigure -> Finish
