K000164051: BIG-IP GUI Stuck at "Starting web server"

Type
Support Solution
Published
2026-10-29
Updated
2026-10-29
Applies to
  • BIG-IP
  • F5 Distributed Cloud Services
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000164051

Description

The BIG-IP Configuration Utility (GUI) does not load. The browser displays the following message and does not progress:

Please wait while the Configuration Utility Starts.
Starting web server
Please do not reboot your device. The device is starting services required for communication with the configuration utility.
This process takes approximately 1-2 minutes.

Data plane traffic continues to process normally, and CLI access is functional. The issue is limited to the management GUI.

Environment

  • BIG-IP LTM
  • Remote syslog server configured

Cause

This issue is caused by Bug ID 1040277: Syslog-ng issue may cause logging to stop possibly affecting system stability

Memory exhaustion was not the cause in this scenario. Increasing Tomcat or restjavad memory did not resolve the issue

Answer/Recommended Actions

Restart the syslog-ng process to restore the GUI:

 bigstart restart syslog-ng 

Confirm the GUI loads and that logs are being written locally and forwarded to the remote syslog server.
