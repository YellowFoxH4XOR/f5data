Description

You are using a FastL4 Virtual Server and you want to change the MSS (Maximum Segment Size) value for this Virtual Server.

Environment

  • BIG-IP
  • FastL4
  • Change MSS value

Cause

None.

Recommended Actions

The MSS value for a FastL4 is located at the FastL4 Profile. You will need to create a custom FastL4 Profile with the MSS value and associate it with the Virtual Server.

  1. Login to the GUI.
  2. Navigate Local Traffic > Profiles > Protocol > FastL4.
  3. Click Create.
  4. Give a Name to this custom FastL4 profile.
  5. Select Custom for Maximum Segment Size Override.
  6. Under Maximum Segment Size Override change Disabled to Specify.
  7. Specify the MSS value in the box.
  8. Click Finished.
  9. You will need to associate this new FastL4 profile to the FastL4 Virtual Server. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
  10. Click the Virtual Server.
  11. Under Protocol Profile (Client) change to the new created Custom FastL4 Profile.
    Note: Changing to this new Customer FastL4 Profile will impact all applications using this Virtual Server. If that is not desired, create a new FastL4 Virtual Server which which will process the specific application that requires the custom MSS value.
  12. Click Update.

Additional Information

K09948701 on Maximum Segment Size Override.

Indicates a maximum segment size (MSS) override for connections. This setting functions by lowering the MSS set on SYN and SYN/ACK packets if the MSS set value is higher than the configured value. MSS Override cannot increase MSS because doing so is unsafe. The following options are available:

    Disabled: Specifies that the system does not use an MSS override.
    Specify: Specifies, in bytes, the size of the MSS override. You can specify any integer between 256 and 9162.

Note: FastL4 always overrides MSS and sets it to the appropriate value for the next hop, regardless of the MSS Override setting. For example, if an IPv4 SYN is received with an MSS of 1460 and is forwarded on to a VLAN with an MTU of 1280, the MSS is lowered to 1240.

Note: ePVA lacks the ability to change the MSS of a flow that is already accelerated. If the FastL4 profile setting 'PVA TCP Offload State'  is set to the default value of 'SYN' , then the MSS override setting may be ignored. It is recommended to set the 'PVA TCP Offload State'  to 'EST' in this case.
