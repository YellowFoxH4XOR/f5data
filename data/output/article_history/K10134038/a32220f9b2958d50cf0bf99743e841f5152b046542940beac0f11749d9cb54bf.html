The default selection in the Bug State section is all options

To filter your F5 Bug Tracker search results, you select the filters you want to use; there are no filters selected by default. Therefore, if you do not select any filters in a section, your search returns bugs that contain all filtering options in that section.

Though the Bug State section uses buttons instead of check boxes, the default behavior is the same: if you do not select a filter, your search returns bugs in all states. If you select a filter but change your mind and decide to not use any filters, simply click your selection again to clear the button.

About bookmarking Bug IDs

When necessary, bug entries may be removed from the database and republished with updated information. If you attempt to access a Bug ID from a bookmark and receive an error message, try again later.
