Description

After upgrading F5OS from 1.8.x to 2.0.0, administrators may notice that certain configuration entries appear to be missing from show running-config (including FDB entries, VLAN-listener entries, NTP server/pool settings, user account fields, and TLS cipher definitions). 

Environment

  • F5OS-A on an rSeries appliance
  • F5OS 1.8.x upgraded to F5OS 2.0.0
  • Tenant environment using VLAN forwarding, VLAN listeners, and NTP
  • Configuration comparison performed before and after the upgrade

Cause

This is expected behavior resulting from intentional schema and configuration-view changes introduced in F5OS 2.0.0. No configuration data is lost and no rollback is required.

Recommended Actions

No need to roll back. The underlying forwarding, tenant, and network configuration remains intact. No functional impact has been identified from these display changes.

  1. Verify FDB entries are operational:

    show fdb

    Confirm all expected MAC/VLAN entries are present.

  2. Verify VLAN-listener entries are operational:

    show vlan-listeners

    Confirm entries match pre-upgrade expectations.

  3. Verify NTP is functioning:

    show system ntp

    The POOL + iburst true representation in 2.0.0 is the correct post-migration state. NTP synchronization should be active.

  4. Verify tenant state is intact:

    show tenants

    Confirm tenant VLAN list, image version, management IP, memory, storage, and running state are correct.

  5. Compare configurations methodically. If performing a formal pre/post upgrade comparison, use the 2.0.0-specific CLI views (show fdb, show vlan-listeners, show tenants) rather than relying solely on show running-config diff, as system-generated entries have moved out of the running-config view by design.

Additional Information

The F5OS-A and F5OS-C codebases were unified in F5OS 2.0.0. Some configuration-view differences between 1.8.x and 2.0.0 reflect this consolidation. Refer to K000161884
