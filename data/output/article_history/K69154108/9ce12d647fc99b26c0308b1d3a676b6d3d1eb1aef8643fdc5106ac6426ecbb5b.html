K69154108: Unable to change the cert and key on SSLO guided configuration.

Type
Support Solution
Published
2021-02-08
Updated
2023-02-21
Applies to
  • F5 App Protect
  • F5 SSL Orchestrator: 15.X.X, 15.0.X, 15.1.1, 15.1.0, 15.1.X, 15.0.0
Source
https://my.f5.com/manage/s/article/K69154108

Description

When you try to change the SSL certificate and key in "Certificate Key Chain" or "CA Certificate Key Chain" from SSLO Guided Configuration, you may face the error below;

Certificate type mismatch. Cert Key Chain types must match with CA Cert Key Chain types or deploy will fail.
Cert Key Chain holds types ["rsa-public"] and CA Cert Key Chain holds types []

Environment

  • F5 SSL Orchestrator 
  • SSLO Guided Configuration
  • GUI: SSL Orchestrator >> Configuration >> "Click Topologies which you want to modify" >> SSL Configuration
  • Changing certificate and key in "Certificate Key Chain" or "CA Certificate Key Chain"

Cause

It is a cosmetic issue.

Recommended Actions

Once GUI shows errors, please try to change the other certificate and key, then back to correct one.

For example:

 - If You change certificate and key of "Certificate Key Chain", then the error is logged,

The workaround should be;

  1. Change the certificate and key of "CA Certificate Key Chain", and click "Done"
  2. Then the error disappear
  3. Back the certificate and key of "CA Certificate Key Chain" to original one, and click "Done"
Additional Information

None.
