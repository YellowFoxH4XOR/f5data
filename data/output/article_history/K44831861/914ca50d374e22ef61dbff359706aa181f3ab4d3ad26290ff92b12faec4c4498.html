Description

The HTTP status codes allow us to set on the one-connect-status-reuse field of the http profile.
One-connect-status-reuse option renders same behavior "none" and "default".
 

Environment

  • BIG-IP v14.0.0 and later
  • HTTP profile
  • OneConnect Status Reuse 200 206


Cause

Previously, a connection to be reused was the hard-coded pair but now this is configurable to set on the one-connect-status-reuse field of the http profile.


Recommended Actions

One-connect-status-reuse option renders same behavior "none" and "default".
