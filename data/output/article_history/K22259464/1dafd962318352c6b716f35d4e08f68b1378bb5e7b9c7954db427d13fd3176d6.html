Description.

BIG-IP VE configured with 24 CPUs shows only 8 TMMs.
Additional license is assigned to have extra numbers of vCPUs' but actual number of tmm run is less than expected.

/var/log/ltm has similar to below warning/error message:

warning sh.functions[<PID>]: Insufficient memory for * tmm threads; restricting to $ tmm threads.
err sh.functions[<PID>]: TMM count must be 1, 2, or a multiple of 4, so changing it from 10 to 8
 

Sample error message for a device with 8 cores but only 4Gb of RAM:

May 25 13:25:12 devicename.f5.net warning sh.functions[2976]: Insufficient memory for 8 tmm threads; restricting to 2 tmm threads.

Environment

  • BIG-IP Virtual Edition
  • Additional license "High Performance VE, * vCPUs" are assigned and activated to the VE machine.
     

Cause

Memory allocated to guest is insufficient for the number of cores assigned.
The guest should have a minimum of 4 GB of RAM for the initial 2 virtual CPUs. For each additional CPU, you should add an additional 2 GB of RAM. 
To x numbers of tmm to run, the BIG-IP VE need to have 2x GB memory.

For Example:    24 of tmm == 48 GB RAM

IMPORTANT: Allocated memory should be reserved.

Recommended Actions

Increase memory allocation for the Guest.

You can run the following commands to check the allocated cores vs number of TMMs.
  • tmsh show /sys cpu
  • tmsh show /sys tmm-info
