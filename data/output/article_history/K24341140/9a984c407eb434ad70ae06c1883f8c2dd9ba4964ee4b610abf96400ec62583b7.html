Topic

This article covers BIG-IP and BIG-IQ software image verification using signature (SIG) and privacy enhanced mail (PEM) files.  For information about verifying the MD5 checksum, refer to K8337: Verifying the MD5 checksum for the downloaded F5 software file.

You should consider using this procedure under any of the following conditions:

  • You have downloaded an ISO image from the F5 downloads site, and want to verify the image using the downloadable SIG and PEM files that are provided.
  • You want to enable automatic image verification on the BIG-IP or BIG-IQ system using the SIG file provided on the F5 downloads site.

Description

F5 provides as many as five downloadable files to perform image verification of downloaded ISO images:

  • The MD5 sum of the ISO file for BIG-IP systems running versions earlier than 15.0.0 and BIG-IQ systems running versions earlier than 8.1.0.
  • A SHA-256 public key (PEM) and signature file (SIG) for BIG-IP systems running 11.5.0 and later, and BIG-IQ systems running version 4.6.0 and later, that are installed from ISO images.
  • A SHA-384 public key (PEM) and signature file (384.sig) for BIG-IP systems running 12.1.0 and later, and BIG-IQ systems running version 5.2.0 and later, that are installed from ISO images.
  • A SHA-384 public key (PEM) and signature file (384.sig) for BIG-IP Virtual Edition and BIG-IQ Virtual Edition.

    Note: The name of the signature file must have the exact name of the file it verifies, plus either a .sig or .384.sig extension as appropriate.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You are running BIG-IP 11.5.0 or later.
  • You have administrative access to the BIG-IP command line.

Procedures

You can configure the BIG-IP system to perform automatic image verification. Doing so requires that the system use only the SIG file.  Alternatively, you can manually perform image verification; this requires both the PEM file and the SIG file.

Using the SIG file on the BIG-IP system to perform image verification

Note: In this procedure, F5 assumes that you have already downloaded the ISO image you want and have uploaded it to the BIG-IP system.  

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. To enable signature verification on the BIG-IP system, follow the procedure in K15225: Enabling signature verification for BIG-IP ISO image files.
  2. Download the appropriate SIG file from the F5 downloads site that corresponds to the version you are installing.
  3. Upload the SIG file to the BIG-IP system and place the file in the /shared/images/ directory.

    If the signature file is not placed in /shared/images/ on the BIG-IP system, then the install will generate an error. For additional information, refer to K15226: Error Message: failed (Signature file not found - /shared/images/BIGIP-<Version-Build>.iso.sig).

Using the .sig and .pem keys to manually verify the downloaded BIG-IP ISO image file before installing the software

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

You can manually verify the downloaded ISO image using the PEM and SIG files. This a more reliable image verification method than using the MD5 file.

  3. To verify the image, use the appropriate command:

    • For BIG-IP systems running 11.5.0 and later, or BIG-IQ systems running version 4.6.0 and later, enter the appropriate command at the command line to use the SHA-256 hash:

      • openssl dgst -sha256 -verify /shared/images/archive.pubkey.20130729.pem -signature /shared/images/BIGIP-<version>.iso.sig /shared/images/BIGIP-<version>.iso

      • openssl dgst -sha256 -verify /shared/images/archive.pubkey.20130729.pem -signature /shared/images/BIGIQ-<version>.iso.sig /shared/images/BIGIQ-<version>.iso

    • For systems running BIG-IP 12.1.0 and later, or BIG-IQ systems running version 5.2.0 and later, enter the appropriate command at the command line to use the SHA-384 hash:

      • openssl dgst -sha384 -verify /shared/images/archive.pubkey.20160210.pem -signature /shared/images/BIGIP-<version>.iso.384.sig /shared/images/BIGIP-<version>.iso

      • openssl dgst -sha384 -verify /shared/images/archive.pubkey.20160210.pem -signature /shared/images/BIGIQ-<version>.iso.384.sig /shared/images/BIGIQ-<version>.iso

    • For BIG-IP or BIG-IQ Virtual Edition virtual machine images, enter the appropriate command syntax at the command line to use the SHA-384 hash on virtual machine images from a terminal running on your local computer running Linux:

      • openssl dgst -sha384 -verify archive.pubkey.<public_key_date>.pem -signature BIGIP-<version>.<image_type>.384.sig BIGIP-<version>.<image_type>

      • openssl dgst -sha384 -verify archive.pubkey.<public_key_date>.pem -signature BIGIQ-<version>.<image_type>.384.sig BIGIQ-<version>.<image_type>


    The output of this command should read Verification OK, indicating that the image is correct.

 

Additional Information

Note: Both F5OS and BIG-IP Tenant images are verified and authenticated when imported into the F5OS system. There are two different approaches to include the signature verification, but this is always enforced by default and not configurable.

  • BIG-IP-<version>.<size>.qcow2.zip.bundle file embeds a signature, that is used to verify the original qcow2.zip file sha512 hash using a public key present on the F5OS image-agent.
  • BIG-IP-<version>.<size>-F5OS.tar.bundle and F5OS-<version>.<type>.iso files contain an embedded signature, a ca-bundle and a certificate. The ca-bundle and certificate are validated using a CA certificate present on the F5OS; image-agent for the BIG-IP Tenant images, sw-mgmt service for the F5OS images. After successful validation, the embedded signature of the original file is validated using the public key of the certificate included in the bundle.
