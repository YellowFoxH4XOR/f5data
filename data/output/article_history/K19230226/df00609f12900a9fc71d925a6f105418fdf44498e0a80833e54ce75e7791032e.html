Topic

You should consider using these procedures under the following condition:

  • You want to turn off or turn on the VELOS system using the AOM Command Menu.

Description

You can turn off a VELOS system using the AOM menu. The high-level sequence is as follows:

  1. Shut down the running tenants.
  2. Turn off the blades using the system controller’s AOM menu and wait for them to completely shut down.
  3. Turn off the system controllers using their respective AOM menu and wait for them to completely shut down.
  4. Remove all power from the VELOS system.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have serial console access to both system controllers on the VELOS system.

Procedures

  • Shut down the running tenants on the VELOS system
  • Turn off the VELOS blades
  • Turn off the VELOS system controllers
  • Turn on the entire VELOS system
  • Start the tenants

Shut down the running tenants on the VELOS system

You can shut down the running tenants on the VELOS system by setting their running-states to Provisioned and waiting for them to completely shut down. For information about shutting down a running tenant, refer to the Shut down a tenant on the VELOS system procedure in K21121803: Shut down and restart a tenant on the VELOS system.

Note: If you attempt to shut down a tenant by running the clsh shutdown -h now command in its operating system while its running-state is set to Deployed, the VELOS partition restarts the tenant.

Turn off the VELOS blades

You can turn off a VELOS blade using the AOM Command Menu. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Connect to the front panel serial console of the VELOS system.
  2. Open the AOM Command Menu using the following key sequence:

    ESC (

    The AOM Command Menu displays the following:

    Active console : system controller 2
    Physically connected console : system controller 2 serial port

    AOM Command Menu:
    B --- Set baud rate
    C --- Capture blade console
    CC -- Capture system controller console
    I --- Display chassis information
    P --- Power on/off blade
    PC -- Power on/off system controller
    R --- Reset blade CPU
    RC -- Reset system controller CPU
    U --- Front panel USB port
    Q --- Quit menu and return to console

    Enter Command:

  3. To initiate the sequence to turn off a blade, you must first enter P (or p). The AOM Command Menu prompts for the desired blade to turn off, similar to the following:

    Blade to turn on or off (1-8)?

  4. Enter the blade number to turn off. For example, enter 2 if you want to turn off blade 2, similar to the following:

    Blade to turn on or off (1-8)? 2

  5. Enter 0 to turn off the blade, similar to the following example:

    0 -- Turn blade off
    1 -- Turn blade on

    Select power option: 0

  6. Enter y to confirm that you want to turn off the blade, similar to the following example:

    Are you sure you want to power-off the blade in slot 2? (y/n) y

    When the blade is turned off, the AOM Command Menu displays output similar to the following example:

    Powering-off blade in slot 2...done.

  7. Repeat steps 3 through 6 for the remaining blades that are still turned on.

Turn off the VELOS system controllers

You can turn off a VELOS system controller using the AOM Command Menu. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Connect to the front panel serial console of the standby system controller.
  2. Open the AOM Command Menu using the following key sequence:

    ESC (

    The AOM Command Menu displays the following:

    AOM Command Menu:
    B --- Set baud rate
    C --- Capture blade console
    CC -- Capture system controller console
    I --- Display chassis information
    P --- Power on/off blade
    PC -- Power on/off system controller
    R --- Reset blade CPU
    RC -- Reset system controller CPU
    U --- Front panel USB port
    Q --- Quit menu and return to console

    Enter Command:

  3. Enter PC (or pc) to initiate turning off the system controller. The AOM Command Menu prompts whether to turn off or turn on the controller, similar to the following:

    0 -- Turn system controller off
    1 -- Turn system controller on

    Select power option:

  4. Enter 0 to turn off the system controller. The AOM Command Menu prompts for confirmation, similar to the following:

    Are you sure you want to power-off the system controller in slot 1? (y/n)

  5. Enter y to confirm. When the controller is turned off, the system displays output similar to the following example:

    Powering-off system controller in slot 1...done

  6. Connect to the serial console of the active controller.
  7. Repeat steps 2 through 5 to turn off the active system controller.
  8. You can now safely remove power from the VELOS system.

Turn on the entire VELOS system

To turn on a VELOS system, re-connect all power to the VELOS system. Then wait for the system controllers and blades to complete their restart process. You can connect to the front panel serial console of each of the system controllers to monitor their restart progress. You can also use the AOM Command Menu to capture a blade’s console to monitor the blade’s restart progress. When the VELOS system is restarted, proceed to the next procedure to start the tenants.

Start the tenants

To start the tenants, you must change their running-state to Deployed. For information about starting a tenant, refer to the Start up a tenant on the VELOS system procedure in K21121803: Shut down and restart a tenant on the VELOS system.
