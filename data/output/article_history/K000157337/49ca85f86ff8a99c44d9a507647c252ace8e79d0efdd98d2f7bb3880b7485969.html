K000157337: Error message during config-sync: "Virtual Server /Common/vs_name refers to nonexistent Vlan /Common/vlan_name"

Source
https://my.f5.com/manage/s/article/K000157337

Description

The following error message is seen during a config-sync: "Virtual Server /Common/vs_name refers to nonexistent Vlan /Common/vlan_name"

Environment

  • HA pair with different vlans configured
  • Virtual server configuration references vlans

Cause

This is expected behaviour.

Recommended Actions

VLAN configurations are not synced across HA peers. If the virtual server needs to reference a specific VLAN, then the VLAN must be created with the same name on all devices in the device-group.

Alternatively, the vlans can be removed from the virtual server configuration if not needed.
