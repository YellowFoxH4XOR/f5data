K000164146: VELOS partition with mgmt-vlan not reachable over management interface

Description

After configuring a mgmt-vlan on a VELOS partition similar to the following example, it is not reachable:

partitions partition default
 config enabled
 config os-version 1.8.2-34651
 config service-version 1.8.2-34651
 config configuration-volume 10
 config images-volume 15
 config shared-volume 10
 config pxe-server internal
config mgmt-vlans [ 100 ] <--
 config mgmt-ip ipv4 address 192.168.10.100
 config mgmt-ip ipv4 prefix-length 24
 config mgmt-ip ipv4 gateway 192.168.10.1
 config mgmt-ip ipv6 address ::
 config mgmt-ip ipv6 prefix-length 0
 config mgmt-ip ipv6 gateway ::
!

Environment

  • VELOS partition
  • Management VLANs

Cause

There is no management VLAN assigned to the partition itself.

The configured partitions partition default config mgmt-vlans makes the mgmt-vlans available for assigning to tenants within the partition.

Recommended Actions

Configure a management VLAN for the partition itself.

VEL410-active(config)# partitions partition default config mgmt-vlan?
Possible completions:
 mgmt-vlans Allowlist of mgmt-vlan tags for this partition's tenants.

VEL410-active(config)# partitions partition default config mgmt-ip mgmt-vlan?
Possible completions:
 mgmt-vlan The mgmt-vlan for partition mgmt. <-- This is needed
