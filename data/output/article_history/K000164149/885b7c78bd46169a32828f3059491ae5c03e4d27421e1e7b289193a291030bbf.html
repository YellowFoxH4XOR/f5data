K000164149: Telemetry Streaming Fails with "unable to get local issuer certificate" for Publicly Trusted Certificate Chains

Type
Support Solution
Published
2026-11-09
Updated
2026-11-09
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000164149

Description

BIG-IP Telemetry Streaming (TS) cannot send data to an external HTTPS consumer, such as a Splunk HTTP Event Collector (HEC) endpoint, and fails with "unable to get local issuer certificate." The server certificate chain is publicly trusted, and openssl s_client and curl on the BIG-IP validate it successfully. The failure occurs only in the Node.js runtime used by restnoded.

Error messages (from /var/log/restnoded/restnoded.log):

  • Message: HTTP Error: unable to get local issuer certificate

Environment

  • BIG-IP LTM
  • F5 BIG-IP Telemetry Streaming (f5-telemetry package)
  • Publicly issued leaf and root certificate

Cause

The Node.js runtime used by Telemetry Streaming uses its own CA bundle and does not use the system OpenSSL trust store. GlobalSign Root R46 is trusted by the system, but it is not present in the Node.js bundle. As a result, the TLS handshake fails at chain validation even though the server chain is valid.

Answer/Recommended Actions

Add the GlobalSign Root R46 certificate to the Node.js runtime using the NODE_EXTRA_CA_CERTS environment variable. Do not use allowSelfSignedCert: true as a workaround, because the certificate is publicly issued and disabling validation removes server authentication.

1.) Obtain the GlobalSign Root R46 certificate in PEM format from GlobalSign. Save it on the BIG-IP, for example /config/ssl/ssl.crt/globalsign-r46.pem. Verify the file with openssl x509 -in <file> -noout -subject before you proceed.

2.) Back up the restnoded startup script:

cp /etc/bigstart/scripts/restnoded /var/tmp/restnoded.bak


3.) Edit /etc/bigstart/scripts/restnoded and add the following line after the existing export NODE_PATH=/usr/lib/node_modules line:

export NODE_EXTRA_CA_CERTS=/config/ssl/ssl.crt/globalsign-r46.pem

See below:

#!/bin/sh

service=restnoded

# First argument passed to these scripts is the number of starts
start_cnt=$1

# load common functions and clear down indicators
. /usr/lib/bigstart/functions
clear_down ${service}
...
export NODE_PATH=/usr/lib/node_modules
export NODE_EXTRA_CA_CERTS=/config/ssl/ssl.crt/globalsign-r46.pem
...

Additional Information

Edits to files under /etc/bigstart/scripts/ are system-level changes. Re-check the change after any software upgrade, because the file may be overwritten.
