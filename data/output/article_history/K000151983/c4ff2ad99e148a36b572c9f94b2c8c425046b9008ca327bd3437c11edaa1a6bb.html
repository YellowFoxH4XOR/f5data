K000151983: DNS Information/CNAME/IP is not visible in load balancer (LB) details

Published
2025-06-26
Updated
2026-07-12
Applies to

  • F5 Distributed Cloud
Source

Description

When using F5 Distributed Cloud (XC) HTTP Load Balancer (LB) with DNS zone management enabled and "Allow Application Load Balancer Managed Records" option set to True - DNS (ACME challenge), CNAME record and IP for the LB's domain will disappear from LB details.

If external DNS use CNAME to resolve LB IP and you will not update it to point to XC’s authoritative name servers/LB IP, resolution fails because CNAME will no longer be available.

Environment

  • F5 Distributed Cloud (XC)
  • HTTP Load Balancer with DNS zone management
  • DNS zone created in XC for the relevant domain (e.g. *.example.com)
  • "Allow Application Load Balancer Managed Records" enabled in the DNS zone
  • LB domains matching the managed DNS zone (e.g. *.example.com)
  • CNAME
  • ACME Challenge 

Cause

Enabling "Allow Application Load Balancer Managed Records" in the DNS zone causes XC to automatically manage DNS records for all matching LB domains including DNS ACME challenge, IP and CNAME.

When matching LB is updated (in any way, even description change) or created, system removes the DNS/CNAME/IP information from the LB details and creates needed records in the XC DNS zone.

Example:

  1. LB with domain "example.com" were created with automatic certificate - DNS (ACME challenge)/IP/CNAME are visible on LB.
  2. DNS zone "example.com" with "Allow Application Load Balancer Managed Records" was created - - DNS (ACME challenge)/IP/CNAME still visible on LB.
  3. Any change on LBs with domain "example.com" or creation of new one with "*.example.com" will move DNS management to DNS zone and from that point all updated/new LBs with corresponding domain will be manage by or DNS automatically - DNS (ACME challenge)/IP/CNAME will disappear in LB options and will move to DNS zone management.

Recommended Actions

If you use an external DNS provider with LB CNAME record, update it to use A records for LBs (IP) / prepare records in XC DNS and delegate zone/NS to XC DNS resolution..

You can also use DNS zone management with "Allow Application Load Balancer Managed Records" disabled in such case CNAME/IP on LB will be still available.

Additional Information

If you want to disable "Allow Application Load Balancer Managed Records" or remove DNS zone once XC DNS will started managing records automatically, you will see an error similar to:

To do that, you will need to do one of the below:

  • Remove all managed LBs / domain used by DNS zone in question and then remove DNS zone.
  • Ask SOC for help and removal of the DNS zone without changes on LB.
