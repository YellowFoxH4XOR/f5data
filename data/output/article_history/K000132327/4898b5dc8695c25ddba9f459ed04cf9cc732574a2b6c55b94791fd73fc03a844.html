Description

How to Clone Bot defence profile via GUI

Environment

ASM
Bot defence

Cause

As of now , there is no way to clone bot defence profiles via GUI .

Recommended Actions

This can be done by editing the bigip.conf file under /config .
Copy and paste the profile configuration only change the profile name

Note: Before editing the bigip.conf file , it is recommended to take the backup of the file and UCS backup 

 # cp /config/bigip.cong /config/bigip.conf.bak
For example:

Here is the part of existing bot defence configuration 
security bot-defense profile /Common/original {
... configuration ...
}
Copy the above and past it just below
security bot-defense profile /Common/clone1{
... configuration ...
}
security bot-defense profile /Common/clone2{
... configuration ...
}
Save the file
Load the configuration by using below command
# tmsh load sys config
Important: Load configuration during maintenance window. 

Now GUI will show both clone1 ans clone2 bot defence profiles
