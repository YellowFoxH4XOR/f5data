Description

When license is being reactivated on the BIG-IP you a message pop up as "BIG-IP system configuration has changed" in the background there is a banner "The configuration has not yet loaded. If this message persists, it may indicate a configuration problem." 

Environment

  • BIG-IP
  • License re-activation

Cause

None

Answer/Recommended Actions

Expected behavior. During license re-activation configuration gets reloaded. Once license is successfully re-activated, the banner in background should disappear.
