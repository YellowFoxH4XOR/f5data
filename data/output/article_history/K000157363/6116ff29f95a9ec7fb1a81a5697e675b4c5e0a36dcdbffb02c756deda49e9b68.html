Description

The following matrix lists third-party software that runs on the Linux host operating system on BIG-IP systems.

Important: F5 point and hotfix releases may include upgrades and security fixes for the third-party software packages listed in the following table. As a result, when you evaluate vulnerability status for third-party software, F5 recommends that you refer to security advisory articles to determine if a BIG-IP release is vulnerable.

Examples

For example, to find the Tomcat version, enter the following command:

rpm -qa | grep tomcat

The output from a BIG-IP system running BIG-IP 21.0.0 appears similar to the following example:

tomcat-7.0.90-1.0.0.10.noarch

In this example, the numeric value after the first dash ( - ) indicates the Tomcat software version is 7.0.90.

For example, to find the MariaDB version, type the following command:

mysqld -V

The output from a BIG-IP system running BIG-IP 21.0.0 appears similar to the following example:

mysqld Ver 5.5.53-MariaDB for Linux on i686 (MySQL Community Server (GPL))

In this example, the MariaDB version is 5.5.53.
