K52657430: Configuration fails to load with error message : ''ASM is not supported on connection-mirrored virtual servers'' after upgrade

Type
Support Solution
Published
2022-07-30
Updated
2023-11-16
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.X.X, 15.1.7, 16.0.0, 16.0.1, 16.1.0, 16.1.1, 16.1.2, 16.1.3, 15.0.0, 15.0.1, 15.1.0, 15.1.1, 15.1.2, 15.1.3, 15.1.4, 15.1.5, 15.1.6, 15.X.X, 16.1.X, 16.0.X, 15.1.X, 15.0.X, 15.1.8
Source
https://my.f5.com/manage/s/article/K52657430

Description
The BIG-IP Configuration fails to load with error message that appears similar to the following example after upgrade :

/var/log/ltm :
err mcpd[<PID>]: 01070692:3: ASM is not supported on connection-mirrored virtual servers.
err tmsh[<PID>]: 01420006:3: Loading configuration process failed.

Environment

  • BIG-IP ASM
  • Upgrade from v14.1.2.7 and above to v15.x or v16.x
  • Connection mirroring is enabled on BIG-IP ASM-enabled virtual server prior to the upgrade

Cause
Connection mirroring is not currently implemented in BIG-IP 15.x or BIG-IP 16.x

Recommended Actions

Recover after upgrading

  1. Log in to the BIG-IP command line.
  2. Edit /config/bigip.conf to remove connection mirroring on the virtual server.

    For example :
     ltm virtual ASM-vs-01 {
            ---snip---
          mirror enabled                          <----- remove or comment out this line
          policies {
             asm_auto_l7_policy__http_ASM-vs-01 { }
          }
             ---snip---
  3. Reload configuration by entering the following command:
    tmsh load sys config
     
  4. If the BIG-IP remains offline after doing this, then boot back to the previous version and do the steps in "Mitigate before upgrading". Then delete the partition that contains the upgrade, and reinstall the upgrade again.
Mitigate before upgrading
  1. Log in to the BIG-IP configurtion utility.
  2. Uncheck "Connection Mirroring" on the virtual server
  3. Click "Update" button.
