Description

When Attack signatures are not staged and have Learn flag, in Request log Header attack sigs appear with 'staged' flag.

Environment

  • BIG-IP ASM

  • Attack signatures are not staging

  • Attack signatures have Learn flag

  • Attack signatures don't have Alarm,Block flag

Cause

This is by design. 
The learning (Learn enabled) of signature(s) is implemented by the staging mechanism - so a signature that is in learning is reported as staged.

Recommended Actions

None
