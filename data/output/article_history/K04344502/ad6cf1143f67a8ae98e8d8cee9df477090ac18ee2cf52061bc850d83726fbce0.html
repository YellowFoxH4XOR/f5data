Description
Sync status for peer unit is always yellow (pending changes)

Environment

  • Using Bundle Manager

Cause

The keymgmtd and mcpd processes get into a loop that cause constant config changes and if the ca-bundle-manager includes a URL, the BIG-IP system constantly downloads the bundle.

Recommended Actions

  1. In System  ››  Certificate Management : Traffic Certificate Management : Bundle Manager List  ›
  2. Open the bundle configuration. 
  3. Change the 'update interval' to zero
  4. Manually update the bundle when required,

Additional Information

See Bug ID 945413: Loop between keymgmtd and mcpd causes BIG-IP to be out of sync or in constant automatic config sync
