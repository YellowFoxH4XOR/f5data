Description

Vulnerability scans of NGINX products flagged GO-2026-5841 (mapped to CVE-2026-63209) and six TEMP tracking IDs (TEMP-0000000-4EF776, TEMP-0000000-78AC20, TEMP-0000000-BBE297, TEMP-0000000-D1A721, TEMP-1148137-089975, and TEMP-1148137-126A7B). The flagged issues affect libheif and SVT-AV1 libraries, not NGINX products. No F5 article exists for CVE-2026-63209.

Environment

  • NGINX Plus, including NGINX Docker image(s) identified in the scan
  • Scanner output that lists libheif or SVT-AV1 packages in the container image

Cause

The affected components are image and media libraries (libheif and SVT-AV1), not NGINX. The vulnerabilities are therefore not related to NGINX products:

  • libheif (TEMP-1148137-126A7B, TEMP-1148137-089975, TEMP-0000000-BBE297, TEMP-0000000-4EF776): libheif is a HEIF and AVIF image format decoder and encoder. The identified vulnerability is specific to libheif.
  • SVT-AV1 (TEMP-0000000-78AC20): The identified issue is a heap buffer overflow in the SVT-AV1 encoder.
  • Heap buffer overflow in unci mixed-interleave decoding (TEMP-0000000-D1A721): The issue affects unequal chroma bit depth handling in the libheif decoder.

Answer/Recommended Actions

  1. Confirm the packages in your scan results. If the findings list libheif or SVT-AV1, these packages are not used by NGINX.
  2. If you use NGINX Docker images, identify the exact image name and version (for example, the repository and tag) that your scanner flagged.
  3. Provide the NGINX product names and exact versions to F5 Support so the findings can be reviewed further.
  4. Monitor F5 security advisories for NGINX products. F5 will publish an article if a finding is confirmed to affect NGINX.

Additional Information

  • Findings that carry only a TEMP ID, without a formal CVE in NVD, may be reported as suspected issues. Evaluate them through your normal vulnerability management process.
  • The TEMP IDs map to the following GitHub Security Advisories (GHSA) and packages:
    • TEMP-0000000-4EF776: GHSA-9rj8-5mp5-26c9 (libheif-plugin-dav1d)
    • TEMP-0000000-78AC20: GHSA-4jqm-2x34-6f6r (libheif-plugin-dav1d)
    • TEMP-0000000-BBE297: GHSA-w7mc-p8jc-p853 (libheif-plugin-libde265)
    • TEMP-0000000-D1A721: GHSA-x8r2-mggj-j6wr (libheif1)
    • TEMP-1148137-089975: GHSA-xrp2-63fq-jm8q (libheif-plugin-libde265)
    • TEMP-1148137-126A7B: GHSA-vg7w-rp49-4fc2 (libheif1)
