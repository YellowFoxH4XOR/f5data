K000150395: Upgrade to v17 fails with error Provisioning failed with error 1 - 'Disk limit exceeded - F5OS

Type
Support Solution
Published
2025-03-14
Updated
2025-10-25
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.1
Source
https://my.f5.com/manage/s/article/K000150395

Description

When attempting to upgrade from a BIG-IP version prior to version 17.x, the configuration fails to load. Running the command load sys config verify in v17.X produces an error similar to:

 

Provisioning failed with error 1 - 'Disk limit exceeded. 20338 MB are required to provision these modules, but only 20124 MB are available.'

Unexpected Error: Validating configuration process failed.

 

Environment

  • F5OS Tenant
  • Upgrade to v17.X
  • Disk size less than 82GB

 

Cause

The disk space requirement for F5OS tenants increased from 77GB in version 15.x to 82GB in version 17.x. Systems with less than the required disk space fail during provisioning due to insufficient resources.

 

Recommended Actions

  1. Verify the current disk space allocation using the command:
    1. tmsh list sys disk
  2. Increase disk space allocation for F5OS tenants as per documentation guidelines referenced below:
    1. K45191957: Overview of the BIG-IP tenant image types
    2. Follow instructions on expanding disk space provided in relevant documentation.

 

Additional Information

  • Ensure sufficient disk space is allocated based on system requirements for version upgrades.
  • Validate configurations using load sys config verify before proceeding with an upgrade.
