K90570085: Disk space is not freed after deleting files.

Type
Support Solution
Published
2021-09-30
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.2
Source
https://my.f5.com/manage/s/article/K90570085
Description

We removed some files like resetjavad and /monitors file but its still 91%  (we increase that from 97% to 91)

Environment

  • /var/log - almost full, even after deleting files
Cause

Linux systems filenames are just pointers (inodes) that point to the memory where the file resides. The space is physically freed only if there are no links left.

Recommended Actions

Reboot the BIG-IP

Additional Information

Untested options:

  • Best way to free disk space from deleted files that are held open
  • Find and remove large files that are open but have been deleted
