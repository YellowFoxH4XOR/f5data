K000159678: Trying to remove an AWAF Application Security Guided Configuration object, but getting 'application was not found' error.

Type
Support Solution
Published
2026-01-22
Updated
2026-01-22
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K000159678

Description

On BIG-IP AWAF, an Application Security Guided Configuration object (for example, an App Protection Profile) can remain visible in the GUI and appear stuck in an “undeploying” state with a spinning indicator after it has already been deleted, preventing clearing/decommissioning of the Guided Configuration state from the UI.

Environment

  • BIG-IP AWAF
  • Application Security Guided Configuration
  • BIG-IP Configuration utility (GUI)
  • iControl REST services (restjavad/restnoded) and REST storage used by Guided Configuration

Cause

Stale/corrupted iControl REST storage/state causes the GUI to retain a stuck Guided Configuration object state even though the object is removed from the underlying configuration.

Recommended Actions

Important: this procedure is not recommended for BIG-IQ managed devices, as it can cause configuration issues.

  1. Confirm the object is not present in configuration (for example, no remaining references in config files). If the object still exists or is referenced (example: an iRule contains ASM::enable "/Common/my_profile"`), remove the reference before attempting deletion.
  2. Before clearing REST storage, confirm you have no other Guided Configuration objects that must be preserved.
  3. Clear REST storage and restart REST services:

clear-rest-storage

bigstart restart restjavad restnoded

  1. Recheck the GUI to confirm the stuck “undeploying” entry is cleared.
  2. If GUI display issues persist (stale entries remain), restart GUI services:

bigstart restart tomcat httpd

Additional Information

  • Restarting these services may temporarily interrupt GUI access.
  • These actions are expected to be management-plane only, but perform changes in a maintenance window if the system is critical.
