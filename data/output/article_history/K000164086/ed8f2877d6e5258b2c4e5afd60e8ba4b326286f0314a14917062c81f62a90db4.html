Description

After upgrading BIG-IP LTM to 17.5.1.11, the full configuration fails to load at boot. The system logs the following errors:

Data Input Error:(/config/bigip_base.conf at line: 0) Invalid version:16.1.3.1: Supported cli versions: 14.0.0 14.0.1 14.1.0 14.1.1 14.1.2 14.1.3 14.1.4 15.0.0 15.0.1 15.1.0 15.1.1 15.1.10 15.1.2 15.1.3 15.1.4 15.1.5 15.1.6 15.1.7 15.1.8 15.1.9 16.0.0 16.0.1 16.1.0 16.1.1 16.1.2 16.1.3 16.1.4 16.1.5 17.0.0 17.1.0 17.1.1 17.1.2 17.5.0 17.5.1 17.5.1.1 17.5.1.11 17.5.1.2 17.5.1.3 17.5.1.4 17.5.1.5 17.5.1.6 17.5.1.7 17.5.1.8 17.5.1.9

The error reports version stamp 16.1.3.1 in the configuration file, which 17.5.1.11 does not accept.

Environment

  • Product: BIG-IP LTM, version 17.5.1.11
  • Upgrade path to 17.5.1.11

Cause

System has wrong version stamp, however, the cause is unknow at the time of publication.

#TMSH-VERSION: 16.1.3.1

Recommended Actions

The following workaround has been reported as successful. It is not a confirmed supported procedure, and the mechanism is not verified.

  1. Back up all files in the /config directory before making changes.
  2. Open the base, auth, and script configuration files in /config and change the version stamp to the previous release version for example 17.5.1.6. 
    #TMSH-VERSION: 17.5.1.6
  3. Save the files and verify the configuration. 
    tmsh load sys config verify
  4. Confirm they no longer appear. If not, kindly update other configuration file based on error.
  5. Reloading a configuration. 
    tmsh load sys config
  6. Verify that the configuration is present and functioning.

If the error persists, contact F5 Support and provide the upgrade logs, and fresh qkview.

Additional Information

  • The error message lists the supported version stamps for the configuration load. A version stamp outside this list, such as 16.1.3.1, causes the load to fail.
