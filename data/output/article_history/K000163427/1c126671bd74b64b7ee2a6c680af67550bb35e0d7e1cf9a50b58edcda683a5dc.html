Description

After upgrade to BIG-IP 21.0.0.2, 17.5.1.6, 17.1.3.2, when you attempt to create sys file object sourced from local file with two slashes, that results in the error following.

# tmsh create /sys file ifile apache_pb.gif source-path file://localhost/shared/tmp/bigip.gif

Data Input Error: file: URL scheme with two slashes is illegal as it represents a remotely accessible file. Use one slash

Before upgrade, following file URL with two slashes is accepted.

sys file ifile /Common/apache_pb {

    cache-path /config/filestore/files_d/Common_d/ifile_d/:Common:apache_110927_1

    revision 1

    source-path file://localhost/shared/tmp/apache_pb.gif

} 

Environment

BIG-IP 21.0.0.2, 17.5.1.6, 17.1.3.2

Cause

This is change or security fix via ID2227441 Authenticated user can read sensitive files using tmsh create sys ifile command

K000160916: iControl REST vulnerability CVE-2026-41225

Before the fix, the first slash is silently dropped incorrectly, if the source file exist under the second path, file object is created successfully.

Answer/Recommended Actions

Recreate the affected file object with single slash path file:/.
