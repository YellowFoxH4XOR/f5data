Description

Observing connection failure through virtual server configured for QUIC, and messages similar to the following appear when increasing the verbosity of sys db tmm.quic.log.level:

warning tmm[22318]: QUIC [quic_pkt_decrypted] 10.10.10.1:54598 -> 10.10.10.4:443 [] Decryption offload returned error: Traffic rejected.

Environment

  • QUIC
  • Hardware platform with crypto offload

Cause

Hardware Crypto Offload with QUIC or HTTP/3 is not supported on rSeries, VELOS, and iSeries

Recommended Actions

Disable hardware crypto offload:

tmsh modify sys db crypto.hwacceleration value disable

Note: Disabling hardware crypto offload can have performance implications.
