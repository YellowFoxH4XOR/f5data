Description

Deployment of a BIG-IP LTM VE high-availability configuration in Azure using F5 ARM Template v2 fails with the following error:

AccountKindNotSupported

Account Kind Storage is not supported.

Environment

  • Azure

  • BIG-IP LTM

  • F5 ARM Template v2

Cause

Azure General Purpose v1 (GPv1) storage accounts are retired. The ARM template uses the unsupported storage account kind Storage instead of StorageV2.

Answer/Recommended Actions

F5 public cloud ARM templates are unsupported, and no supported template update is available.

If the template must be used, clone the repository locally and update the relevant JSON file to specify the required storage account kind.

Impact of workaround: This workaround is not supported by F5.

Additional Information

The deployment may also report the following errors before displaying the underlying AccountKindNotSupported error:

DeploymentFailed

ResourceDeploymentFailure

Failed
