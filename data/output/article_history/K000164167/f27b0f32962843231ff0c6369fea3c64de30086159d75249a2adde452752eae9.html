Description

On an F5OS-hosted BIG-IP tenant, system-tcam-manager or tcam-manager may log messages containing nse err code: 4 from neuron_client_pva_sc_frs when hardware SYN-cookie programming is already active. Hardware SYN-cookie protection can be applied to only one destination, while other virtual servers use software SYN-cookie protection.

Cause

nse err code: 4 indicates that the hardware (Neuron) SYN-cookie programming is already reserved by another TMM or virtual server. When additional TMMs or virtual servers attempt to program hardware SYN-cookie protection, the request generates the log message and those virtual servers use software SYN-cookie protection instead.

Additional Information

The system-tcam-manager and tcam-manager error messages are expected and benign when hardware SYN-cookie programming is already reserved. They do not affect system performance.

This behavior was observed in an F5OS-hosted BIG-IP tenant with an IP-forwarding virtual server using a FastL4 profile and hardware SYN-cookie protection, while other virtual servers used software SYN-cookie protection.
