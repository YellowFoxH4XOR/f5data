In this video, AskF5 shows you how to block HTTP requests with an unwanted User-Agent header using an iRule.

00:00 Intro and prerequisites
00:55 Create a data group containing a list of unwanted user-agent strings
01:38 Create an iRule to block HTTP requests that contain the unwanted user-agent strings
02:10 Associate the new iRule with your virtual server

iRule syntax

The following iRule blocks requests from unsupported browsers listed in the data group named unsupported_browser:

when HTTP_REQUEST {
    if {[class match [HTTP::header "User-Agent"] contains unsupported_browser]}{
        drop
    }
}

This demo uses BIG-IP 21.1.
