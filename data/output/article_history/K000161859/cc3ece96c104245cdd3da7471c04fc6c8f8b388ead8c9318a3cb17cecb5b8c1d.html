K000161859: BIG-IP configuration fails to load when a client SSL or clientssl-legacy cert-key-chain uses default_0

Type
Support Solution
Published
2026-06-23
Updated
2026-11-10
Applies to
  • BIG-IP
  • BIG-IP LTM: 21.0.X, 21.0.0, 21.1.X, 21.1.0
Source
https://my.f5.com/manage/s/article/K000161859

Description

After upgrading BIG-IP LTM from version 21.0.x to 21.1.x, configuration fails to load with the following error messages:

010717e1:3: Client SSL profile (/Common/clientssl-legacy): cannot contain more than one set of same certificate/key type.

Unexpected Error: Validating configuration process failed.

Additional warnings include deprecated compliance objects in protocol inspection and log-setting attachment advisories.

Environment

  • Product: BIG-IP LTM (Version 21.1.0)
  • Client SSL profile (/Common/clientssl-legacy) with cert-key chain entry using default_0 instead of default
  • Client SSL profile configuration in /config/bigip.conf
  • Client SSL profile with cert-key-chain entry named default_0
  • Recent Action: Upgrade from BIG-IP 21.0 to 21.1.0
  • VELOS or VIPRION systems may require use of clsh on the primary slot

Cause

The cert-key-chain entry in the client SSL profile is named default_0 instead of default. In BIG-IP 21.1.0, this causes the system to interpret the profile as containing multiple sets of the same certificate/key type, resulting in configuration validation and load failure.

Answer/Recommended Actions

To resolve the configuration validation failure:

  1. Search for problematic entries:

    Run: grep -n 'default_0' /config/bigip.conf to locate the faulty cert-key chain.
  2. Backup the Configuration:
    Run: cp /config/bigip.conf /config/bigip.conf.bak.$(date +%Y%m%d%H%M%S)
  3. Replace default_0 with default:
    Run: sed -i 's/default_0/default/g' /config/bigip.conf
  4. Confirm replacement:
    Run: grep -n 'default_0' /config/bigip.conf (should return nothing if replacement succeeded)
  5. Verify Configuration:
    Run: tmsh load sys config verify
  6. Load Configuration:
    Run: tmsh load sys config

For VELOS/VIPRION (primary slot):
Prefix commands with clsh (e.g., clsh grep -n 'default_0' /config/bigip.conf).

Additional Information

  • The error message may also appear as: Unexpected Error: Validating configuration process failed.
  • GUI and SSH access may still be available even if the configuration does not load.
  • The same issue may exist on the peer device in an HA pair.
  • Other warnings, such as deprecated compliance objects, may appear but are not related to this specific failure.
