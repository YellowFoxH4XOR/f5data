K000160658: F5 Insight - Expand VM Disk Space Due to Full or Miss-Provisioned Disk

Type
Support Solution
Published
2026-04-07
Updated
2026-04-07
Applies to
  • BIG-IP
  • F5 Insight: 1.0.0
Source
https://my.f5.com/manage/s/article/K000160658

Description

This article covers situations where the F5 Insight OVA was deployed with the default 80 GB disk or additional disk space is required.

Environment

  • VMWare vSphere
  • F5 Insight OVA

Cause

F5 Insight leverages Rancher's local-path-provisioner as its Storage Class, which employs the primary hard disk for storage. If the primary disk lacks sufficient space to meet the minimum 600 GB requirement for an F5 Insight installation, you can follow these steps to increase the disk space.

Answer/Recommended Actions

The actions or steps required to address the topic covered in the description.

VMWare vSphere

  1. Log into the VMWare vSphere console
  2. Edit the F5 Insight VM Settings
  3. Increase Hard disk 1 to at least 600 GB
  4. Remove Hard disk 2 if you added a secondary disk
  5. Click OK
  6. Do not reboot the VM at this time

F5 Insight VM

  1. sudo rm -rf /opt/f5insight/.first-boot-complete
  2. sudo reboot -h now

 

Additional Information

Example of an F5 Insight OVA deployment where a second disk was added while leaving the primary boot disk (/dev/sda) at 80 GB

After using SSH to connect to the F5 Insight VM, use df, fdisk, or lsblk to see this installation has two disk assigned to this VM

admin@f5-insight:~$ sudo fdisk -l | grep 'sda\|sdb'
Disk /dev/sda: 80 GiB, 85899345920 bytes, 167772160 sectors
/dev/sda1  *       2048   2099199   2097152   1G 83 Linux
/dev/sda2       2099200 167772126 165672927  79G 8e Linux LVM
Disk /dev/sdb: 800 GiB, 858993459200 bytes, 1677721600 sectors

In the VMWare vSphere console the disk labeled Hard Disk 1 was increased to 800 GB and the disk labeled Hard Disk 2 was removed.

Verified the second disk (/dev/sdb) was removed to the VM prior to deleting the .first-boot-complete file and rebooting

admin@f5-insight:~$ sudo fdisk -l | grep 'sda\|sdb'
Disk /dev/sda: 80 GiB, 85899345920 bytes, 167772160 sectors
/dev/sda1  *       2048   2099199   2097152   1G 83 Linux
/dev/sda2       2099200 167772126 165672927  79G 8e Linux LVM

After removing the .first-boot-complete file and rebooting the F5 Insight VM the primary disk has been expanded to 800 GB

sudo fdisk -l | grep 'sda'
Disk /dev/sda: 800 GiB, 858993459200 bytes, 1677721600 sectors
/dev/sda1  *       2048    2099199    2097152    1G 83 Linux
/dev/sda2       2099200 1677721566 1675622367  799G 8e Linux LVM

Through lab testing the existing F5 Insight configuration was maintained through disk expansion of /dev/sda1.
