Topic

You should consider using this procedure under the following condition:

  • You want to restore the BIG-IQ configuration to factory default settings on the currently active volume.

Description

You may occasionally need to remove the current BIG-IQ configuration and restore the system to the factory default setting. The BIG-IQ includes the clear-rest-storage command to perform this task.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Have Advanced Shell (bash) access to the BIG-IQ system command line with Administrator role credential.
  • Have access to the management interface or serial console.

Procedures

Remove the BIG-IQ configuration

To remove the BIG-IQ configuration, which involves clearing the REST framework index and Elasticsearch data and deleting and re-initializing the Postgres BIG-IQ database, or to include the alternative options of keeping the Elasticsearch data, deleting log files, and/or resetting the BIG-IQ system-level configuration to default, perform the following procedure:

Note: UCS archive backup files remain in the /shared/ucs_backups directory after you restore the BIG-IQ system to factory defaults; however, the files do not appear in the BIG-IQ user interface.

Impact of procedure: This procedure deletes all items in the REST framework index and Postgres BIG-IQ database, which includes the discovered devices, imported configurations, and tenant-specific data. Elasticsearch data is deleted as well unless you include the option to keep it. BIG-IQ system-level configuration is reset to default if you include the option to reset it. The procedure is not reversible; consider carefully before proceeding.

  1. Log in to the BIG-IQ system command line.
  2. To reset the BIG-IQ configuration, enter the following command:

    clear-rest-storage

    Note: When executing the command without the -d option, administrative users, the management IP address, the hostname, network configuration, DNS and NTP services, the license, the system personality, and the master key are not reset to default.
    This command's default actions first stop BIG-IQ services, then delete the BIG-IQ configuration and thereafter restarts the BIG-IQ services. You do not have to reboot the BIG-IQ system, as the REST framework index and Postgres BIG-IQ database are rebuilt to a new, clean state when the BIG-IQ services are restarted. You can now add a new configuration on this BIG-IQ system.

    Alternatively, you can append the following options for additional actions to the command's default actions:

    • Append the -es option to keep existing Elasticsearch data, which is deleted by default.
    • Append the -l option to include the deletion of the BIG-IQ system log files.
    • Append the -d option to include the reset of the BIG-IQ system level configuration to default. The script runs tmsh load sys config default and resets specific system files and certificates.

      Note: If you use the -d option, you may be required to restart the BIG-IQ system. Check the command line or the user interface for a notification to restart. Additionally, if you use the -d option the management IP address and license are not removed.
