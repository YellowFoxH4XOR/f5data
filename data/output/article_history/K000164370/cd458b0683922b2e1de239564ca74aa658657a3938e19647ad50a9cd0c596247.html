K000164370: Upgrade failed with "Failed Cluster health is yellow please enable replicas for all indices before proceeding with the upgrade BIG-IQ"

Published

Applies to

Source

Description

BIG-IQ software upgrades may fail on Cluster Managers and Data Collection Devices (DCDs) with the following error:

Failed Cluster health is yellow please enable replicas for all indices before proceeding with the upgrade big-iq

The upgrade cannot proceed while the DCD cluster health is yellow. This occurs when statistics indices do not have replicas enabled, so replica shards cannot be distributed across the cluster nodes.

Environment

  • BIG-IQ Centralized Management
  • Upgrade
  • Cluster Managers (CMs) and a DCD cluster included in the upgrade
  • DCD cluster statistics indices without replicas enabled
  • Cluster health reported as yellow

Cause

Statistics indices on the DCD cluster do not have replicas enabled. Without replicas, the cluster reports yellow health, which blocks the upgrade pre-check.

Answer/Recommended Actions

Enable replicas for all statistics indices, confirm cluster health is green, and then retry the upgrade.

  1. Log in to the primary BIG-IQ for the DCD cluster and open the Statistics Retention Policy screen.
  2. Expand Advanced Settings and select Enable Replicas.
  3. Return to the cluster view and wait for the cluster health status to change from yellow to green. This confirms that data replicas are distributed across nodes.
  4. After the cluster status is green, retry the BIG-IQ or DCD upgrade.

Preventive: Verify that cluster health is green before starting any BIG-IQ upgrade.

Additional Information

  • The upgrade pre-check fails with the yellow-health error until replicas are enabled and cluster health returns to green. This is expected behavior for this check.
