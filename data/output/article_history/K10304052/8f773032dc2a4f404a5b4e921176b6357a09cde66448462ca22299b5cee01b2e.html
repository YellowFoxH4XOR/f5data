Cause

ID 679901

Recommended Actions

One or more of the following can address this issue:
  • Manually run the tmsh load sys config file merge option.
  • Make smaller changes so that they complete within the 60 second timeout.
  • [If pushing out iRule modifications] Optimise iRules so that they call other iRules within their own partition where possible to minimize the validation time.
