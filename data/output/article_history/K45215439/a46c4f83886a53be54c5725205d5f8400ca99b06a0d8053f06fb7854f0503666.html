Description

"Error trying to access database" when accessing ZoneRunner

Environment

  • GTM/DNS
  • DNS Zones
  • ZoneRunner
  • GUI (Configuration Utility)

Causes
This error has been observed under the following conditions:

  • GTM/DNS module is not provisioned.
  • Invalid information in named.conf configuration file.

Recommended Actions

Ensure that the BIG-IP DNS/GTM module is provisioned
To check the provisioning, navigate to: System > Resource Provisioning.
 
Search for the invalid line
This can be done by using the steps outlined in K6963: Managing the BIG-IP BIND configuration file.  Once you have the line, you can then proceed with the next steps.  This can also be done manually by following steps 1-2, below.
  1. open daemon log

    less /var/log/daemon.log
  2. look for error relating to named

    example:
    err named[<pid>]: /config/named.conf:<linenumber>: unknown option '<text value>'
    crit named[<pid>]: loading configuration: failure
    crit named[<pid>]: exiting (due to fatal error)

    In this output, <linenumber> is the line number in named.conf, <text value> is the content causing the error, and <pid> is the process ID of the named daemon. 
Edit named.conf to correct the errorsImportant: While you can manually edit the DNS configuration file on a BIG-IP DNS system, under normal circumstances, F5 recommends using the ZoneRunner utility. Incorrectly editing the DNS configuration files on a BIG-IP DNS system can cause issues, such as the ZoneRunner utility or BIND failing to start.
  1. Stop named and zrd processes.

    bigstart stop named zrd

  2. Back up the configuration file:

    cp /var/named/config/named.conf /var/named/config/named.conf.bak 

  3. Edit the configuration file:

    nano /var/named/config/named.conf 

  4. Locate the reported line and correct the syntax error. 
  5. Save changes
  6. Validate the configuration

    named-checkconf -t /var/named -z -j /config/named.conf 

  7. Verify that ZoneRunner is accessible and the shell prompt no longer shows zrd DOWN.
  8. Start named and zrd processes back

    bigstart start named zrd
Note: Restart of the named process will briefly stop processing DNS bind request, while the process is restarted.
