Description

The APM Client 7.2.7.3 release introduces a refreshed, modern, and visually consistent experience across both the Windows Edge Client and Mac Edge Client. This update focuses on enhancing the appearance of the User Interface while maintaining the existing functionality.

Key updates include:

  • A new set of icons added with modifications to existing icons for improved clarity and alignment with company standards.
  • Updated icons include the Application, Task bar, Menu bar, and Tray icons.
  • For Mac Edge Client:
    • Initial changes were introduced in version 7.2.7.1.
    • Further refinements and updates have been applied in version 7.2.7.3.
  • For Windows Edge Client:
  • All icon updates are introduced in version 7.2.7.3.

The updated icons are available automatically upon upgrading to BIG-IP Edge Client 7.2.7.3, ensuring users benefit from a streamlined and refreshed interface experience.

Tray icons

Tray icons appear in hidden icons menu on the bottom-right of the screen alongside the monitor and speaker icons in Windows and they appear on the top-right of the screen alongside the Control centre, Wifi, Date and Time in MacOS.

The modes of these icons depend on the mode and the background (wallpaper) shade of the device.
