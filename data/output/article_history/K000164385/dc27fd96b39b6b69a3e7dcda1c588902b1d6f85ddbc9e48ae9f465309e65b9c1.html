K000164385: VELOS rolling partition software upgrade not working as expected - all blades reboot at the same time

Type
Support Solution
Published
2026-11-26
Updated
2026-11-26
Applies to
  • F5OS Products
  • F5OS-C: 1.8.X, 1.8.3, 1.8.2, 1.8.1, 1.8.0
  • F5OS: 2.X.X, 2.0.X, 2.0.0
Source
https://my.f5.com/manage/s/article/K000164385

Description

During a rolling partition upgrade, all blades rebooted at the same or similar time, resulting in a tenant outage.

For example:

2026-11-20T13:06:45.886512+00:00 VEL410 /usr/libexec/sw-mgmt/sw-util.sh nodename=controller-1 switch_blade_os 1 2.0.0-30814: priority=Info msgid=0x3501000000000023 msg=Update of partition 1 blade OS to version 2.0.0-30814 in progress.
2026-11-20T13:06:45.928095+00:00 VEL410 /usr/libexec/sw-mgmt/sw-util.sh nodename=controller-1 switch_blade_os 1 2.0.0-30814: priority=Info msgid=0x3501000000000027 msg=Update complete. Reboot required for changes to take effect.
2026-11-20T13:06:50.624214+00:00 VEL410 /usr/libexec/sw-mgmt/sw-util.sh nodename=controller-2 switch_blade_os 1 2.0.0-30814: priority=Info msgid=0x3501000000000023 msg=Update of partition 1 blade OS to version 2.0.0-30814 in progress.
2026-11-20T13:06:50.743410+00:00 VEL410 /usr/libexec/sw-mgmt/sw-util.sh nodename=controller-2 switch_blade_os 1 2.0.0-30814: priority=Info msgid=0x3501000000000027 msg=Update complete. Reboot required for changes to take effect.

2026-11-20T14:10:25+01:00 blade-1.chassis.local partition=1 slot=1 notice boot_marker: ---===[ BOOT-MARKER F5OS blade version 2.0.0-30814 ]===---
2026-11-20T14:10:41+01:00 blade-2.chassis.local partition=1 slot=2 notice boot_marker: ---===[ BOOT-MARKER F5OS blade version 2.0.0-30814 ]===---

Environment

  • VELOS partition upgrade
  • Multiple blades

Cause

This is expected at the time of this article's publication. Blades in a VELOS partition will all reboot at a similar time when a partition upgrade is performed. This will cause a tenant outage.

Recommended Actions

Expect a tenant outage during partition upgrades and plan accordingly, for example by making a HA peer tenant active on another chassis.
