K000163643: ICANN DNS trust anchor rollover impact

Type
Support Solution
Published
2026-10-10
Updated
2026-10-16
Applies to
  • BIG-IP
  • BIG-IP DNS
Source
https://my.f5.com/manage/s/article/K000163643

Description

BIG-IP DNS validating resolvers with manually configured DNSSEC trust anchors may fail DNSSEC validation and return SERVFAIL for queries after the ICANN root KSK rollover on 11 October 2026 if only the KSK-2017 (key tag 20326) trust anchor is present. This occurs when trust anchors are managed under ltm dns cache validating-resolver ... trust-anchors and are not automatically updated to include the new KSK-2024 (key tag 38696).

Environment

  • BIG-IP DNS

  • Validating resolver DNS caches with DNSSEC validation enabled

  • Trust anchors manually configured under ltm dns cache validating-resolver ... trust-anchors

  • Only KSK-2017 (key tag 20326) present as trust anchor

Cause

Manually maintained trust anchors do not include the new root KSK-2024 (key tag 38696), resulting in DNSSEC validation failures after the root KSK rollover.

Answer/Recommended Actions

  • Check the current trust anchors using:
    tmsh list ltm dns cache validating-resolver <resolver_name> trust-anchors

  • If only key tag 20326 is present, obtain the KSK-2024 DS record (key tag 38696) from the IANA root anchors publication.

  • Add the new KSK-2024 DS trust anchor using the add command, not replace-all-with, to ensure both KSK-2017 and KSK-2024 are present until January 2027.

  • Save the configuration and verify both trust anchors are present.

  • Test DNSSEC query handling with a DNSSEC-enabled query.

  • After January 2027, remove the KSK-2017 (key tag 20326) trust anchor.

  • Only the DS record is required as a trust anchor; do not upload a certificate file or add a DNSKEY record.

Additional Information

  • Only the SHA-256 DS digest is required for the new KSK-2024 trust anchor.

  • Forward zones using upstream nameservers are not directly affected, but upstream resolvers should also be checked for rollover readiness.
