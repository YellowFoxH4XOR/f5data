K000140157: ZRD CPU Surge due to Bind setup

Type
Support Solution
Published
2024-07-01
Updated
2024-07-01
Applies to
  • BIG-IP
  • BIG-IP DNS: 16.1.3
Source
https://my.f5.com/manage/s/article/K000140157

Description

This article describe bind configuration that cause cpu surge for ZRD  

  • ZRD cpu surge when there is attempt to add/delete/modify zone(slave zone) configuration via webui
  • add/delete/modify will fail.
  • error message found log - err zrd[12633]: 01150406:3: Update operation refused, displayed each failed action.

Environment

  • Slave zone is configured on Bind 
    • zone "test.zone." {

      type slave; <----- slave

      file "db.external.test.zone.";

      masters {

      10.10.10.1;

      };

Cause

Answer to the question or underlying source of the issue

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1.  Slave zone can only be updated from/on master dns server. Attempt to add/update/delete slave zone via GUI(zonerunner) will result in failure and surge in cpu for ZRD process.
  2. Please perform changes on master dns server and sync across to bind on F5.
