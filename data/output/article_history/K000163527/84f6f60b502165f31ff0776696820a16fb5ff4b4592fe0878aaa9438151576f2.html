K000163527: JSON imports of BIG-IP ASM security policies fail when IP Intelligence is enabled.

Type
Support Solution
Published
2026-10-11
Updated
2026-10-19
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K000163527

Description

Importing a BIG-IP ASM security policy in JSON format fails when IP Intelligence is enabled. The import returns an error similar to:

Could not parse/validate the IpReputation 'IP Intelligence Configuration'. Invalid value 'The Tor Proxies category includes IP addresses acting as exit nodes for the Tor Network. Exit nodes are the last point along the proxy chain and make a direct connection to the originator’s intended destination.' for field 'description'.

Environment

  • BIG-IP ASM
  • IP Intelligence enabled security policy exported and imported in JSON format

Cause

ID2457053 identified in some of the versions causes BIG-IP to incorrectly reject the hardcoded description field in the IP Intelligence configuration during JSON import.

Answer/Recommended Actions

Workaround

  1. Open the exported JSON security policy.
  2. Locate the affected IP Intelligence description, such as the Tor Proxies category description.
  3. Replace the affected text within policy JSON with the escaped representation shown below:
    The Tor Proxies category includes IP addresses acting as exit nodes for the Tor Network. Exit nodes are the last point along the proxy chain and make a direct connection to the originator\u00e2\u0080\u0099s intended destination.
  4. Save the modified JSON policy.
  5. Import the policy and verify that it succeeds.

Permanent Resolution

This issue is fixed in latest the BIG-IP releases, check the ID2457053 and identify version relevant to your big-ip versioning chain and upgrade.
