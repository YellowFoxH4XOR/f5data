What Happened?

I want to know if Distributed Cloud Secondary DNS support DNSSEC.

Environment

  • F5® Distributed Cloud Secondary DNS (XC Secondary DNS)

Resolution/Answer

  • Does F5 XC Secondary DNS supports DNSSEC?
    • Yes, XC Secondary DNS supports Domain Name System Security Extensions (DNSSEC).
  • is there an option to sign DNSSEC on XC side(secondary DNS)? (or hide the NS of the primary)
    • when you transfer zones to XC and use XC DNS as secondary you can "hide" the primary DNS, so XC DNS name servers will be the only name servers that respond to the external DNS query. This will allow you to get the same outcome as the primary name servers will not be exposed to public.
  • When we use XC DNS as secondary DNS and DNSSEC is required, do we need to configure primary DNS to sign DNSSEC?

    • yes, DNSSEC signing must be done on the Primary DNS server, and we'll transfer the DNSSEC records as part of the zone transfers.

      You can sign with XC but as with any other provider, only when zone is configured as Primary.
