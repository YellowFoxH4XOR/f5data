Topic

You should consider using this procedure under the following condition:

  • You want to use an iRule to block HTTP requests with unwanted User-Agent headers.

To block requests with unwanted hosts refer to K000148533: Blocking HTTP requests with unwanted hosts using an iRule

Description

The HTTP User-Agent header contains client information, such as the type and version of web browser, operating system, and platform. You can create an iRule to block requests containing certain elements.

You can use the following key commands to build the iRule:

  • The [HTTP::header "User-Agent"] command returns the user-agent string from the client-request header.
  • The contains operator verifies whether the user-agent string contains the matching element.
  • The drop command discards connections with unwanted user agents.
  • The class match command searches lists of strings in a data group.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP Configuration utility.
  • You have a virtual server configured with an HTTP profile.

Procedures

Creating a data group containing a list of user-agent strings

To create a data group containing a list of unwanted user-agent strings, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules > Data Group List.
  3. Click Create.
  4. For Name, type a name for the data group.
  5. For Type, click String.
  6. Under Records, for String, type appropriate value and leave Value blank.

    For example, to block client requests initiated from Internet Explorer 6 web browsers, for String, use the following unique string which only appears in the Internet Explorer 6 User-Agent header:

    MSIE 6.0

  7. Click Add.
  8. Repeat steps 6 and 7 as needed to add more user-agent strings in the data group.
  9. Click Finished.

Creating an iRule to block HTTP requests containing a specific string in the User-Agent header

To create an iRule blocks client HTTP requests containing unwanted user-agent information in the request header, perform the following procedure:

Impact of procedure: The impact of the suggested procedure depends on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules > iRule List.
  3. Click Create.
  4. For Name, type a name for the iRule.
  5. For Definition, enter the user-agent blocking iRule.

    For example, the following iRule blocks requests from unsupported browsers listed in the data group named unsupported_browser:

    when HTTP_REQUEST {
        if {[class match [HTTP::header "User-Agent"] contains unsupported_browser]}{
            drop
        }
    }

  6. Click Finished.
  7. Associate the iRule with the virtual server.
