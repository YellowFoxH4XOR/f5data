Topic

This article documents the step-by-step procedure to return defective units under a Return Materials Authorization (RMA) event. For a visual guideline of the F5 return process, refer to the F5 Customer Return Instructions video.

Description

Return instructions

Return the defective unit within 10 business days after receipt of your replacement unit. To do so, use the following steps:

  1. Retain all F5 original packaging materials to reuse as return packaging.
  2. Carefully place the parts in the original electrostatic bag and packaging, making sure to package each part separately, as they were shipped to you. Do not consolidate parts into fewer boxes. Each returned unit will be monitored by F5. Any damages sustained during shipping because of insufficient packaging will be invoiced at full list price.
  3. Clearly write the RMA work order number on the outside of the shipping container.

    Note: Shipments that do not have an F5-authorized RMA work order number may be refused at time of delivery and returned to the shipper by way of collect freight.

  4. If there is a return waybill provided with the replacement parts, contact the carrier indicated on the prepaid waybill to arrange collection.
  5. If there is not a return waybill provided with the replacement parts, contact f5return@flashglobal.com to schedule a free pickup by providing following information:
    • RMA work order number
    • Pickup address
    • Contact name and phone number

    Note: If required for pickup, provide the Outbound Shipment ID, Ticket Number, or Approval Code. Note any security requirements for entry and pickup from the location.

  6. Keep a record of the tracking number and ship date; you will need these to track misrouted shipments. Failure to provide F5 with adequate proof of return will result in an invoice at full list price for the suspected defective hardware.

If you need any assistance with returns, contact GSLR@f5.com. For technical questions or concerns, contact F5 Support.
