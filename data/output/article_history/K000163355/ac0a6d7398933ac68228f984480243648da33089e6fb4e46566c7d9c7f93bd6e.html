Description

Server-Sent Event (SSE) responses with the text/event-stream content type are delivered to the client in grouped and delayed batches instead of progressively. Multiple events may appear to have the same timestamp when the response passes through a BIG-IP LTM virtual server with HTTP compression enabled.

Environment

  • BIG-IP LTM virtual server.
  • HTTPS application traffic.
  • Application responses using Content-Type: text/event-stream.
  • HTTP profile with an HTTP compression profile assigned.
  • Traffic path containing one or more BIG-IP virtual servers.

Cause

The HTTP compression profile buffers response data so it can process the response for compression. This buffering is incompatible with applications that require immediate, chunk-by-chunk delivery of SSE responses.

Recommended Actions

Remove the HTTP compression profile from the virtual server.
