Topic

The VELOS and rSeries Always-On Management (AOM) command menu provides multiple options for managing the systems. The following options provide additional hardware details for troubleshooting the VELOS chassis and blades and rSeries systems if they become unavailable or fail to boot properly:

  • The Information command (i)
  • The Diagnostics command (diag) (Only on VELOS, r5000, r10000, and r12000)
  • The Platform Event Log command (pel) (Only on VELOS, r5000, r10000, and r12000)
  • The r2000/r4000 Diagnostics command (d) (Only on r2000 and r4000)

F5 Support may request that you run the diag and pel commands described in this article to verify issues before an Return Materials Authorization (RMA). Their output are for F5 internal use only for hardware diagnostics. F5 does not provide further information or explanation on the output (diag, pel).

Description

The AOM subsystem provides lights-out management for the VELOS system controllers and blades and rSeries systems using the serial console. You can use the following commands in the Always-On Management (AOM) Command Menu to gather additional information about the hardware if either become unresponsive or fail to boot properly.  In these cases, or when an RMA is requested, gather the output of these commands to help diagnose the issue:

Command nameCommandKey sequence to invokeVisibility in AOM Command MenuDescription
Informationii <enter>VisibleThe i command displays chassis information, such as firmware versions and serial numbers. The i command is listed in the AOM Command Menu.
Diagnosticsdiag<esc> diag <enter>HiddenThe diag command displays diagnostic information, such as CPLD registers, reset counts, and sensor readings. The diag command is hidden from the AOM Command Menu and is intended for F5 internal use only.
Platform Event Logpel<esc> pel <enter>HiddenThe pel command displays platform events logged by the system. The pel command is hidden from the AOM Command Menu and is intended for F5 internal use only.
Diagnostics on r2000 / r4000d<esc> d <enter>HiddenThe d command displays diagnostic information on the r2000 and r4000-series appliances and is its equivalent to the diag and pel commands.  The d command is hidden from the AOM Command Menu and is intended for F5 internal use only.

Recommendations

When troubleshooting suspected hardware issues with VELOS systems or rSeries appliances, review the output of the 'i' command and collect the output of the 'diag' and 'pel' commands to send to F5 Support for analysis when experiencing the following conditions:

  • Unresponsive system controllers or blades
  • System controllers or blades that fail to boot properly
  • RMA request for VELOS or rSeries hardware

To invoke the AOM i, diag, and pel commands, perform the following procedure:

Impact: Performing the following procedure should not have a negative impact on your system.

  1. Access the console of your VELOS sytem controller/blade or rSeries system.
  2. In the console, enter the following key sequence to access the AOM Command Menu:

    Esc (

  3. To invoke the i command, type the following command then press Enter:

    i

  4. To invoke the hidden diag command, enter the following key sequence then press Enter:
    Note: On the rSeries r2000/r4000 enter Esc d.

    Esc d i a g

  5. To invoke the hidden pel command, enter the following key sequence then press Enter:
    Note: rSeries r2000/r4000 appliances do not support this command. Use the command described in step 4 which outputs the System Event Logs (SEL) as well.

    Esc p e l

  6. To exit the AOM Command Menu, enter the following command then press Enter:

    q

Additional Information

VELOS System controllers

System controllers provide a front-panel serial port for connection to the console. You can also connect to the system controller console over SSH using the terminal server on the system controllers. From the console, you can access the AOM menu on the system controller by entering the Esc ( key sequence.

VELOS Blades

Blades do not provide front-panel serial ports. To access the blade’s serial console you can use either of the following methods:

  • Connect to the front-panel serial port on the system controller and select the C---Capture blade console option from the system controller’s AOM menu.
  • Connect using the terminal server on the system controller by specifying the system controller's management floating IP address and the port for the blade.

The built-in terminal server on the VELOS system allows you to SSH to the console of any blade using the floating IP address of the system controllers and the port for the blade. If one of the system controllers is unreachable you should still have access to a blade’s AOM menu from the other system controller. The terminal server uses ports 7100 and 7200 to provide console access to system controller 1 and system controller 2 respectively. You can access the console of the chassis blades by specifying the port as the slot number in which the blade resides plus 7000. For example, use port 7001 to connect to the serial console of the blade in slot 1, and use port 7002 to connect to the serial console on the blade in slot 2.
