K000130316: Failed to start sysnlog-ng

Type
Support Solution
Published
2023-03-20
Updated
2023-05-25
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000130316

Description

  • You find the syslog-ng keeps restarting in the BIG-IP CLI.

  • You may see below log messages when executing command journalctl -xelfu syslog-ng on the BIG-IP command shell.

    syslog-ng[<PID>]: WARNING: the match() filter without the use of the value() option is deprecated and hinders performance, please use a more specific filter like message() and/or program() instead.;
    syslog-ng[<PID>]: Error parsing destination, syntax error, unexpected LL_IDENTIFIER, expecting ';' in /etc/syslog-ng/syslog-ng.conf at line xxx, column yy:
    syslog-ng[<PID>]: tcp("192.168.11.11" port (514)) tcp-keep-alive(yes) log_fifo_size(100000);

Environment

  • Syslog include is configured for BIG-IP

  • The include configuration is not the same with what in /etc/syslog-ng/syslog-ng.conf

Cause

As the log messages shows, There is syntax error in /etc/syslog-ng/syslog-ng.conf at the line xxx.

 Recommended Actions

  • For the  log message of "WARNING: the match() filter without the use of the value() option is deprecated and hinders performance, please use a more specific filter like message() and/or program() instead.;", you can refer to K59573442: Error Message: the match() filter without the use of the value() option is deprecated for the workaround.

  • For the rest log messages, you need first locate to the line xxx in /etc/syslog-ng/syslog-ng.conf, and then correct the syntax error for "tcp("192.168.11.11" port (514)) tcp-keep-alive(yes) log_fifo_size(100000);". For example in this case, replace the line xxx with any one of following:

tcp("192.168.11.11" port (514));
tcp("192.168.11.11" port (514) tcp-keep-alive(yes) log_fifo_size(100000));
  • Then execute command "tmsh restart sys service syslog-ng", and syslog-ng will run normally this time. You can use command "tmsh show sys service syslog-ng" to see the status of syslog-ng, it should look like "syslog-ng (pid <pid>) is running...".
