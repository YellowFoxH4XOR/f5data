Description

  • Defined a new static route to send logs to an existing remote log server

  • BIG-IP is still using the source IP address from the previous route  


Environment

  • BIG-IP 

  • Restarting tmrouted not solved the issue:
    bigstart restart tmrouted

  • Using the command below, results with new correct source IP and interface:
    ip route get <IP_address> 

  • Packet capture will show that the connection towards log server is using an old IP address as a source.

Cause

This is caused by a bug ID 760473.
There is no fix for this Bug ID at the time of article's publication.

Recommended Actions

It can be workaround by the following steps:

  1. Set and save temporarily a fake IP address for the log server.

  2. Change it back for the original one.
