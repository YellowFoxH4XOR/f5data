K000150769: F5OS files are not displayed when accessing File Utilities

Type
Support Solution
Published
2025-04-29
Updated
2026-10-26
Applies to
  • F5OS Products
  • F5OS-A: 1.8.X, 1.8.0
Source
https://my.f5.com/manage/s/article/K000150769

Description

Getting errors when trying to access "SYSTEM SETTINGS" -> "File Utilities" over F5OS Configuration Utility

  • GUI Error messages

Failure for data/f5-utils-file-transfer:file/list API. The server or an underlying service is unreachable.
Hide Details
error-message : Failure for data/f5-utils-file-transfer:file/list API. The server or an underlying service is unreachable.
original-error : Request failed with status code 500

Environment

  • F5OS - Appliance
  • Configuration Utility

Cause

Users accidentally created files with an unexpected name. Those file were not supposed to be in the /var/F5/system/configs directory.

Note: Backup files are usually stored in the /var/F5/system/configs directory, for more information refer to K47512994: Back up and restore the F5OS-A configuration on an rSeries system.

The issue may occur when files users accessing "File Utilities" folder.

Example of files with unexpected names:

# cd /var/F5/system/configs/
# ls -al
-rw-r--r--. 1 root root  0 Mar 16 18:39 'foo'.xml
-rw-r--r--. 1 root root 100 Mar 16 21:07 $(echo $HOSTNAME | cut -d'.' -f1)-$(date +%H%M-%m%d%y)

 

Recommended Actions

Using root user, log in to the command line (bash) and check if there are any files with abnormal names. Delete the files.

  1. Log in to bash with root user
  2. Go to related folder
    cd /var/F5/system/configs/
  3. Delete files with unexpected filenames. Use the following syntax:
    rm <file name>
    If the file name has a special character such as $, you will need to surround the filename with single quotes. For example:
    rm '$hostname.file'
