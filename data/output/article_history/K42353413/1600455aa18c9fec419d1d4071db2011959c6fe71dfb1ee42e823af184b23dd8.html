Description

During license activation, the following error occurs even when the license key is confirmed to be supported on the platform:
Error 51133, F5 registration key is not compatible with the detected platform - This platform, "", cannot be activated with this registration key "xxxxxxx-xxxxxxx".

Environment

  • BIG-IP VE
  • KVM
  • Virtual License
  • License Activation

Cause

Missing parameter in KVM setup.

Recommended Actions

During setup, in the virt-install command, add the following parameter: --virt-type kvm

Additional Information

Note that you may need to downgrade the KVM SMBIOS to v2.x (32-bit entry point) per K000139873: BIG-IP under KVM fails to generate license with "Error 51133, F5 registration key is not compatible with the detected platform"

Note that line ordering of the virt-install command parameters can matter. Here is an example of the virt-install command:

sudo virt-install \
  --qemu-commandline='-machine smbios-entry-point-type=32' \
  --name bigip1 \
  --memory 4096 \
  --vcpus 2 \
  --disk /media/user/hdd/pool/BIGIP-17.1.1.3-0.0.5.qcow2 \
  --import \
  --virt-type kvm \
  --network bridge=bri0 \
  --os-variant=rhel6.0
