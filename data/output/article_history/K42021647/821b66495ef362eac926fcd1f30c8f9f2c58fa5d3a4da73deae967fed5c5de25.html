Issue

Error Message

err mcpd[<PID>]: 01b4002b:3: Client SSL profile (/<partition>/<ssl_profile>): the profile has no RSA cert/key pair that can be modified. To add RSA cert/key, please use [cert-key-chain add].

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <partition> is the partition and directory in which the SSL profile is located.
  • <ssl_profile> is the name of the SSL profile.

For example:

err mcpd[8484]: 01b4002b:3: Client SSL profile (/Common/example_ssl): the profile has no RSA cert/key pair that can be modified. To add RSA cert/key, please use [cert-key-chain add].

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility when you update the cert/key pair in a configured iApp Service

Description

This message occurs when one of the following conditions is met:

  • You attempt to modify a Client SSL profile's RSA certificate/key pair that does not exist.
  • You attempt to reconfigure an iApp application that contains a Client SSL profile. This is the result of a known issue. For more information, refer to Bug ID 754541 in F5 Bug Tracker.

Beginning in BIG-IP 14.1.0, the Client SSL profile no longer requires containing at least one RSA certificate and key pair, and you can create a Client SSL profile that contains only non-RSA certificate/key pairs. This error message indicates that a Client SSL profile without an RSA certificate/key pair is being modified or assigned with an RSA certificate/key pair. This typically happens when such modification is done using the TMOS Shell (tmsh) deprecated commands cert and key instead of the preferred command cert-key-chain.

Impact

Creation or changes to the Client SSL profile or iApp Application are not saved.

Recommended Actions

To modify the Client SSL profile certificate and key using tmsh, you should use the cert-key-chain command. To do so, use the following procedure:

Impact of procedure: The following procedure changes the certificate/key pair used in the Client SSL profile, which may impact services. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To modify the Client SSL profile, use the following command syntax:

    modify ltm profile client-ssl <profile_name> cert-key-chain <action> { <set_name> { cert <cert_name> key <key_name> } }

    For example, to add the example cert/key pair to the Client SSL profile, enter the following command:

    modify ltm profile client-ssl example_profile cert-key-chain add { example_pair { cert example key example } }

  3. To save the changes to the system configuration, enter the following command:

    save sys config

To work around the known issue caused by reconfiguring iApps applications, refer to the workaround steps listed in Bug ID 754541 in F5 Bug Tracker.
