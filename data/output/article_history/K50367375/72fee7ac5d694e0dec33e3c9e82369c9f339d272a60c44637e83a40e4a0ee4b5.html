Description

The serial number is located on your system barcode sticker and is also stored in the system configuration database.

Serial number format and barcode sticker

The VELOS chassis (CX410 / CX410-N / CX1610) has a unique serial number. The serial number format for the VELOS chassis is chsXXXXXXs. The serial number begins with the letters chs, followed by six numeric characters, and ends with the letter s. For example, chs123456s. The chassis serial number barcode sticker is black with white wordings and is located on the front of the chassis, to right of the bezel.

The system controller (SX410 / SX1610) has a unique serial number. The serial number format for a VELOS system controller is bldXXXXXXs. The serial number begins with the letters bld, followed by six numeric characters, and ends with the letter s. For example, bld123456s. The system controller serial number barcode sticker is black with white wordings and is located on the front of the controller.

The blade (BX110 / BX520) has a unique serial number. The serial number format for a blade is bldXXXXXXs. The serial number begins with the letters bld, followed by six numeric characters, and ends with the letter s. For example, bld123456s. The blade serial number barcode sticker is black with white wordings and is located on the front of the blade.

There are different methods to display the serial numbers of the various components in a VELOS system. Select a method from the following that is most appropriate for your environment:

  • Display the serial numbers from the CLI
  • Display the serial numbers from the Web UI
  • Display the serial numbers using a REST API command

Display the serial numbers from the CLI

To display the serial numbers of the VELOS chassis and the installed system controllers and blades from the CLI, perform the following procedure:

Impact of procedure: Performing this procedure should not have a negative impact on your system.

  1. Log in to the CLI of the VELOS chassis as the chassis administrator.
  2. To display the serial numbers, enter the following command:

    show components component state serial-no

    The command returns output similar to the following example:

    NAME SERIAL NO
    ---------------------------------
    blade-1 bld012345s
    blade-2 bld123456s
    blade-3 bld543210s
    blade-4 bld654321s
    blade-5 Not Available
    blade-6 Not Available
    blade-7 Not Available
    blade-8 Not Available
    chassis chs123456s
    controller-1 bld234567s
    controller-2 bld765432s
    fantray-1 sub0772g0007
    lcd sub0811g000v
    psu-1 19010BPJ0033
    psu-2 19332BPJ0127
    psu-3 Not Available
    psu-4 Not Available
    psu-controller-1 sub0759g001s
    psu-controller-2 sub0759g000h

    Note: The serial number is displayed as Not Available when there is no component/blade installed at the stated slot.

Display the serial numbers in the VELOS Web UI

To display the serial numbers of the VELOS chassis and the installed system controllers and blades from the Web UI, perform the following procedure:

Impact of procedure: Performing this procedure should not have a negative impact on your system.

  1. Log in to the Web UI of the VELOS chassis as the chassis administrator.
  2. For F5OS 2.0.0 and later, go to System Monitoring > System Inventory. Prior to F5OS 2.0.0, go to System Settings > System Inventory. The Web UI displays a page with the serial numbers of all the components installed in the system.

Display the serial numbers using a REST API command

To display the serial numbers of the VELOS chassis and the installed system controllers and blades using a REST API command, perform the following procedure:

Impact of procedure: Performing this procedure should not have a negative impact on your system.

  1. Log in to the CLI of the VELOS chassis as the root user.

    Alternatively, you can log in to the system you want that has the curl and jq utilities installed.

  2. To obtain the serial numbers, enter the following REST API command syntax:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku <username>:<password> "https://<ip address>/api/data/openconfig-platform:components" | /usr/bin/jq '.[][][] | { "name": .name, "serial": .state."serial-no" }'

    Note: Replace <username> and <password> with the administrative username and password to access the VELOS chassis, and replace <ip address> with either localhost if you are running the command from the chassis CLI or the floating management IP address of the VELOS chassis. This command retrieves the serial numbers in quoted (") format.

    For example, you would enter the following REST API command if you were running it from the VELOS chassis CLI using the admin user:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku admin:admin "https://localhost/api/data/openconfig-platform:components" | /usr/bin/jq '.[][][] | { "name": .name, "serial": .state."serial-no" }'
