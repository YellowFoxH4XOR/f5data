Description

After replacing or renewing the device certificate, the iQuery connection continues to use the old certificate.

Environment

  • BIG-IP GTM
  • Replacing device certificate used by GUI and iQuery (System > Certificate Management > Device Certificate Management > Device Certificate)
  • iQuery connection unknown
  • Required certificates are missing from the GSLB trusted-server certificate list

Cause

The device certificate was not replaced correctly, the trusted-server certificate bundle is invalid or incomplete for iQuery authentication, or the gtmd and big3d services have not been restarted to load the new certificate. A certificate that is not valid for SSL client authentication cannot establish the required iQuery trust.

Recommended Actions

Impact of procedure: Performing the following procedure briefly halts iQuery communication with this DNS sync group peer.

  1. Restart the big3d and gtmd services:
    bigstart restart big3d gtmd
  2. If restarting the services does not resolve the issue, follow the DNS sync group peer procedure in K16951115: Changing the BIG-IP system device certificate using the Configuration utility.
  3. If the trusted-server certificate bundle still does not update, confirm that all required certificates appear in the GSLB trusted-server certificate list and that the device certificate is valid for SSL client authentication.
  4. Create the MCPD force-load marker:
    touch /service/mcpd/forceload
  5. Reboot the affected device:
    reboot
  6. Back up the retained certificate bundle:
    mv /config/gtm/server.crt /config/gtm/server.bak.crt
  7. Copy the valid /config/gtm/server.crt bundle from a working HA peer to the affected device.
  8. Restart the gtmd and big3d services:
    tmsh restart /sys service gtmd big3d
  9. Verify that the device rejoins the DNS sync group and that configuration changes replicate in both directions.

Additional Information

In the observed scenario, running gtm_add to reload the configuration from a working device did not update the retained /config/gtm/server.crt bundle.
