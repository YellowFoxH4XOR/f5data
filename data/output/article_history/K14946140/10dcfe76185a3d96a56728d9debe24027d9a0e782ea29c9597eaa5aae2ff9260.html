Description

When clicking the + icon in the DoS Application Events log, the row does not expand to show the attack details:

Environment

  • DoS Profile
  • DoS Logging

Cause

This is expected when clicking the + for the Attack ended event.

DoS L7 events typically have two rows in the DoS Application Events log:

  • Attack started
  • Attack ended

Both rows should reference the same Attack ID - since they are related to the same attack.

Recommended Actions

Click the + for the Attack started event to see the relevant statistics.

You may also review more detailed statistics in the DoS Dashboard at Security >> Reporting : DoS : Dashboard.

Note: If the device is managed by a BIG-IQ, the statistics may be sent off-box and are therefore not visible on the BIG-IP itself.
