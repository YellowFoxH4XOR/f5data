Description

The automated reports on BIG-IQ generate, but fail to send due to "Error: Report submission failed: curl (35) Unknown SSL protocol error in connection to api.f5.com:443. It occurred at (date / time)".

Environment

  • BIG-IQ
  • Flexible Consumption Plan (FCP)
  • LOAD/Catalog (CAT) license offerings
  • Monthly utilization reports

Cause

Effective October 2, 2026, F5 updated the IP addresses associated with api.f5.com to 185.56.152.6. This can interfere with established firewall rules and impact connectivity between the BIG-IQ and api.f5.com. 

Recommended Actions

Review IP addresses for F5 hosted services to note recent updates then verify the connectivity and secure communications between the BIG-IQ and api.f5.com.

  1. Run "telnet api.f5.com 443". Does it connect? If so, this confirms that port 443 is reachable, but doesn't verify that SSL/TLS negotiation, certificates, or HTTPS are working.
  2. Test the SSL/TLS connectivity. Run "openssl s_client -connect api.f5.com:443". It should display the SSL/TLS handshake and return the peer certificate. If it returns the following results, contact your local network team to allow this traffic. Refer to Troubleshooting connectivity after api.f5.com and callhome.f5.com IP address changes for more details.

    CONNECTED...:ssl handshake failure
    ---
    no peer certificate available
    ---
    No client certificate CA names sent
    ---
    SSL handshake has read 0 bytes and written ### bytes

Once connectivity is restored, test the reporting option again per Send CAT/LOAD utilization report directly from BIG-IQ.
