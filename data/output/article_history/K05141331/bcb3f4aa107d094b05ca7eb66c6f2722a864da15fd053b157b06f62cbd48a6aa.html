Issue

Error Message

01490000:5: AccessPolicyProcessor/AccessPolicyProcessor.cpp func: "runSessionCleaner()" line: <#> Msg: <Message>

In this error message, note the following:

  • <#> is a variable number that indicates a line of code.
  • <Message> is the descriptive message provided by the apmd process.

For example:

  • 01490000:5: AccessPolicyProcessor/AccessPolicyProcessor.cpp func: "runSessionCleaner()" line: 1886 Msg: APD in queue control state for 843 sec.
  • 01490000:5: AccessPolicyProcessor/AccessPolicyProcessor.cpp func: "runSessionCleaner()" line: 1866 Msg: All 80 APD workers are currently busy, dequeued count is 1083442

Message Location

You may encounter this message in the following location:

  • The /var/log/apm file

Description

If the BIG-IP APM system is unable to communicate with a configured authentication, authorization, and accounting (AAA) server, unanswered authentication requests can fill the queue and cause apmd to stop processing the access policy.

This message occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured to communicate with an AAA authentication server.
  • The apmd process has sent multiple authentication requests, without receiving any responses.
  • The apmd process is not able to perform the Authentication query because previous authentication attempts from other sessions are still pending.

Impact

Authentication requests fail, so users cannot connect to the BIG-IP APM system.

Recommended Actions

Determine the cause of the connectivity issues with the AAA server.

To work around this issue, you can restart the apmd process. To do so, perform the following procedure:

Impact of procedure: Restarting the apmd process disconnects users who are currently connected.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the apmd process, type the following command:

    restart /sys service apmd
