K95480875: How to change address family mode for mgmt unicast address

Type
Support Solution
Published
2021-03-19
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K95480875
Description

By default, the address family mode for management failover unicast address is set to both ipv4 and ipv6:
    K12430: IPv4 and IPv6 dual stack support for the management interface

Environment

  • Management Interface config
  • High Availability
  • BIG-IP device
Cause

There is an option to change this setting using Configuration Utility as well as CLI.

Recommended Actions

Using the GUI:
  1. Go to Device Management > Devices > Failover Network
  2. Choose the appropriate option for "Address Family Mode" from "Management Failover Unicast Configuration"
Using the CLI:
  • (tmos)# modify cm device DEVICE_NAME mgmt-unicast-mode <ipv4 | ipv6 | both>
