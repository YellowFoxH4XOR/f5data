Description

This article talks about how to configure 2 types of DNS Caching (Resolver or Validating Resolver).

Environment

  • BIG-IP with DNS provisioned
  • F5 DNS Caching
  • Resolver Cache or Validating Resolver Cache
  • Version: 15, 16 and 17

Cause

N/A, this article is a configuration guide on how to configure F5 DNS Caching (Resolver or Validating Resolver).

Recommended Actions

  1. Create a Cache.
    At the section: “DNS > Cache > Cache List”, put the cache name and the cache type you would like (Resolver or Validating Resolver).

     

    "Root Hints" at the bottom of the page, the BIG-IP has default list of the root DNS servers which is published by InterNIC. For more information, you may refer to "Manual Chapter : Configuring DNS Caching".

  2. Forward Zones (Optional). 
    After you created the Cache. When you click on it, there is a "Forward Zones" tab which allows you to configure a list if DNS server which the the Cache forwards the query for the resolution. 

       

    If you configure "Forward Zones", the cache uses a recursive method to resolve the queries.

  3. Create a DNS profile.
    In the “DNS > Delivery > Profiles > DNS” section, we create a new DNS profile based on the existing default “dns” profile with the additional settings.

      

    Enable "DNS Cache" with select "DNS Cache Name". Also disable BIND to be used in the BIG-IP DNS to improve the caching performance.

  4. Create a DNS Listener.
    At the final step, we configure a new DNS listener with applying the new DNS profile we just created for the DNS Cache. 

Additional Information

  1. The listener address must be routable to the internet or the Forward Zones as when there is no record existed inside the cache, the BIG-IP forwards the traffic externally (Root Hints or Forward Zones) using TMM interface (listener). You should make sure that the interface (TMM) is accessible to the configured Root Hints or Forward Zones. 
  2. This is only a guideline on how to configure DNS Caches (Resolver or Validating Resolver), it may not exactly fit to your implementation. For the best design/implementation, you may reach out to our Professional Services.
