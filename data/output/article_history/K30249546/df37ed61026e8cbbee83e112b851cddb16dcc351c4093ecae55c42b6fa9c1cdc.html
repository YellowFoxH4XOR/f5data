K30249546: BIG-IQ CAT License - Reactivate Button is Greyed Out

Type
Support Solution
Published
2020-08-25
Updated
2026-07-14
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X
Source
https://my.f5.com/manage/s/article/K30249546

Description

If you only activate some of the CAT license offerings and not all of them in BIG-IQ > Devices > License Management > Licenses, the 'Reactivate' button is greyed out.

Environment

  • BIG-IQ
  • Flex Consumption Program (FCP)
  • CAT License offerings
  • Manual Activation

Cause

It is only possible to refresh CAT license's service check date if all its license offerings are activated (green).

Recommended Actions

Perform the following steps to activate all license offerings before you can reactivate the CAT license:

  1. On the BIG-IQ, navigate to Devices tab > License Management > Licenses.
  2. Click on the CAT license name to expand the license offerings.
  3. Click on the license offering name.
  4. Copy dossier from Device Dossier box. 
  5. Paste the dossier into the Enter Your Dossier box, and then click Next.
  6. Copy the license and paste it into License text on BIG-IQ. 
    Note: Each license offering has a unique dossier.
  7. Click on Activate in the bottom right of the screen.

Repeat the above steps for each of the CAT license offerings. 
The 'Reactivate' button will be available when all the offerings' statuses show as Active.

Additional Information

When the Reactivate button is finally available, if possible, use the "automatic" option so all license offerings are available and to avoid the manual activation in the future.
