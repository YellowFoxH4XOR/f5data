Topic

You should consider using this procedure under the following conditions:

  • You want to verify the proper operation of your VELOS system by uploading a QKView file to F5 iHealth.
  • You want to provide a QKView file to F5 Support to aid in troubleshooting an issue with a VELOS system.

Note: In affected F5OS-C versions, when you generate QKViews on your VELOS system, you may encounter connectivity issues. For more information, refer to K000138933: VELOS connectivity issues after generating a partition Qkview in 1.6.x.

Description

You can use the qkview utility on the VELOS system to automatically collect configuration and diagnostic information from VELOS systems. You can run the qkview utility from a system controller or chassis partition to capture diagnostic information from the host system, and optionally from peers, as well as from all associated containers. Running the qkview utility from a system controller captures data from containers related to the controller software, while running the qkview utility from a partition captures container data for the partition software.

Note: The qkview utility on the VELOS system does not capture diagnostic data from tenant BIG-IP systems. To generate diagnostic data for a tenant BIG-IP or BIG-IQ system, log in to the tenant system and perform the relevant procedure in K12878: Generating diagnostic data using the qkview utility

The qkview utility on the VELOS system generates machine-readable JavaScript Object Notation (JSON) diagnostic data and combines the data into a single compressed Tape ARchive (TAR) format file. The single TAR file is comprised of embedded TAR files containing the diagnostic data of individual containers running on the system, as well as diagnostic data from the host and peers. You can upload this file, called a QKView file, to iHealth, or give it to F5 Support to help them troubleshoot any issues.

Note: F5 Support requires a QKView file in all cases in which remote access to the product is not available.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the VELOS system.
  • You have an F5 Support single sign-on (SSO) account to access the iHealth diagnostics server.

Procedures

  • Run the qkview utility from the webUI
  • Download the generated Qkview from webUI
  • Upload a QKView file to iHealth from the webUI
  • Run the qkview utility from the command line
  • Export the QKView diagnostic output from the command line
  • Upload a QKView file to iHealth from the command line

Run the qkview utility from the webUI

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the VELOS system controller webUI.
  2. Go to DIAGNOSTICS > System Reports.
  3. Select Generate QKView at the top-right corner.
  4. Enter a name for Filename.
  5. Enter values for the Timeout Value, Max File Size, and Max Core Size options, or leave them at the defaults.
  6. Select Exclude cores to exclude any core files found on the system from the QKView file.
  7. Select Generate QKView to start the qkview utility.

    The System Reports page shows the status of the QKView file generation process.

Download the generated QKView from the webUI

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to SYSTEM SETTINGS > File Utilities.
  2. From the Base Directory list, select diags/shared.
  3. Under diags/shared, select qkview.
  4. Select the QKView file and select Download.

Upload a QKView file to iHealth from the webUI

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the VELOS system controller webUI.
  2. Go to DIAGNOSTICS > iHealth Credentials.
  3. Enter the username and password used to authenticate to iHealth.
  4. Select Save.
  5. Go to DIAGNOSTICS > System Reports.
  6. Select the QKView file you want to upload.
  7. Select Upload to iHealth.
  8. Enter the F5 Support Case Number and a Description in the fields provided.
  9. Select Upload.

    The System Reports page shows the status of the QKView file upload process.

Run the qkview utility from the command line

The commands for running the qkview utility are the same on a system controller or on a chassis partition.  To run the qkview utility from the command line of a system controller or chassis partition, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the system controller or chassis partition on the VELOS system as the admin user.
  2. Run the qkview utility by entering the following command:

    system diagnostics qkview capture

    Optionally, to specify a filename for the QKView file, add the filename option. For example, to specify the filename controller1.qkview.tar, enter the following command:

    system diagnostics qkview capture filename controller1.qkview.tar

  3. Check the progress of a running qkview by entering the following command:

    system diagnostics qkview status

    When completed, the QKView file is generated in the /var/shared/qkview/ directory if run on a system controller, or in the /var/F5/partition<partition_ID>/shared/qkview/ directory if run on a chassis partition. Within the F5OS CLI, the QKViews are in shared/diags/qkview/.

Export the QKView diagnostic output from the command line

You can export the QKView diagnostic files from the VELOS system to an HTTPS server using the command line. To do so, perform the following procedure:

Note: The HTTPS server must use an SSL certificate signed by a public Certificate Authority (CA) for the transfer to complete properly.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the system controller or chassis partition on the VELOS system as the admin user.
  2. Export a diagnostic file using the following syntax:

    file export local-file diags/shared/qkview/<qkview_filename> remote-host <host_address> remote-file <path/to/remote_file> username <user>

    For example, to export the example_qkview.tar diagnostic file to the /tmp/ directory of the remote host at 10.10.10.100, enter the following command:

    file export local-file diags/shared/qkview/example_qkview.tar remote-host 10.10.10.100 remote-file /tmp/example_qkview.tar username admin

  3. Check the status of the file transfer by entering the following command:

    file transfer-status

    When completed, the output displays similar to the following example:

    result
    S.No.|Operation  |Protocol|Local File Path                                  |Remote Host         |Remote File Path                 |Status
    1    |Export file|HTTPS   |diags/shared/qkview/example_qkview.tar           |10.10.10.100        |/tmp/example_qkview.tar          |Complete

Upload a QKView file to iHealth from the command line

After you obtain the QKView diagnostic file, you can upload the file to iHealth to diagnose the health and proper operation of your VELOS system. To do so, perform the following procedure:

Note: Prior to performing this procedure, you need to configure F5OS with your iHealth credentials if you have not already done so. For more information, refer to the Additional Information section of this article.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the system controller or chassis partition on the VELOS system as the admin user.
  2. Upload a diagnostic file to iHealth using the following syntax:

    system diagnostics ihealth upload qkview-file <name-of-qkview> description <description> service-request-number <case_number>

    For example, to upload the example_qkview.tar file to iHealth specifying service request number c123456, enter the following command:

    system diagnostics ihealth upload qkview-file example_qkview.tar description controller1 service-request-number c123456

  3. Check the iHealth upload status by entering the following command:

    show system diagnostics ihealth upload-status

    Output appears similar to the following example:

    UPLOAD    SR                                                                                        
    ID        NUMBER   STATUS     IHEALTH LINK                                             DESCRIPTION  
    ----------------------------------------------------------------------------------------------------
    zEDUmefo  c123456  Analyzing  https://ihealth.f5.com/qkview-analyzer/qv/10581          controller1

Additional Information

Prior to performing the procedure Upload a QKView file to iHealth from the command line, you need to configure F5OS with your iHealth credentials if you have not already done so. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the system controller or chassis partition on the VELOS system as the admin user.
  2. Enter the configuration mode terminal by entering the following command:

    config

  3. Enter your iHealth credentials by using the following command syntax:

    system diagnostics ihealth config username <email address> password

    For example:

    system diagnostics ihealth config username john@example.com password

  4. You observe an output similar to the following prompting for your password. Enter your iHealth password.

    (<AES encrypted string>): ******

  5. Commit the changes and exit the configuration mode terminal by entering the following command:

    commit and-quit
