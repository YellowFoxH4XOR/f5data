Topic

BIG-IP Edge Client is the client portion of the BIG-IP APM system and is available for Windows, Mac OS X, and Linux systems. Each version of the BIG-IP APM system has its own version of BIG-IP Edge Client. Determining which BIG-IP Edge Client version is installed on the client can be helpful when you troubleshoot or when you support multiple versions of the BIG-IP APM systems.

Note: Only a single version of the BIG-IP Edge Client may be installed on a client system.

Description

The BIG-IP Edge Client version number is defined as follows:

XXXx.yyyy.mm.dd.hhmm

Where:

  • XXX and x are the major and minor versions, respectively.
  • yyyy is the year.
  • mm is the month.
  • dd is the day.
  • hh is the hour.
  • mm is the minute.

Locating the version number of BIG-IP Edge Client

Windows

  1. Log in to the Windows client system.
  2. Open Windows Explorer.
  3. Go to the F5 VPN directory; the default installation is in c:\program files\.
  4. Right-click the f5fpclientW.exe file.
  5. Select Properties.
  6. Select the Details tab.
    The version is shown in the Product version field.

OR

  1. Log in to the Windows client system.
  2. Launch the BIG-IP Edge Client application.
  3. Select View Details.
  4. Select the Miscellaneous tab.

Mac OS X

  1. Log in to the Mac client system.
  2. Launch the BIG-IP Edge Client application.
  3. Go to BIG-IP Edge Client > About BIG-IP Edge Client.

    The version is listed in the pop-up window.

OR

  1. Log in to the command line of the MAC client system.
  2. Use the cd command to change to the installation directory.

    For example, to change to the default installation directory /Library/Internet\ Plug-Ins/F5\ SSL\ VPN\ Plugin.plugin/Contents/Helpers, enter the following command:

    cd /Library/Internet\ Plug-Ins/F5\ SSL\ VPN\ Plugin.plugin/Contents/Helpers.

  3. To view the BIG-IP Edge Client version, enter the following command:

    ./f5fpc --version

Linux

  1. Log in to the command line of the Linux client system.
  2. Change to the installation directory using the cd command. For example, to change to the default installation directory (/usr/local/lib/F5Networks/), enter the following command:

    cd /usr/local/lib/F5Networks/

  3. The BIG-IP Edge Client version is listed in the ~/F5Networks/SSLVPN/etc/version.txt file. To view the version, enter the following command:

    cat ./SSLVPN/etc/version.txt

APM Clients

The BIG-IP APM system comes with the BIG-IP Edge Client. Prior to BIG-IP 13.1.0, you could not upgrade to the latest version of the BIG-IP Edge Client without upgrading your entire BIG-IP APM system. Beginning in BIG-IP 13.1.0, the APM Clients product enables you to update the BIG-IP Edge Client version on your BIG-IP APM system without upgrading the entire system. APM Clients is available for download from the F5 Downloads site.

Although APM Clients is included in BIG-IP APM releases, APM Clients has a separate development and release cycle. F5 provides software fixes and technical support in the current latest major released version and one version prior. For example, with the release of APM Clients 7.2.2, only 7.2.2 and 7.2.1 are supported. APM Clients 7.1.9 and earlier versions have reached End of Software Development and End of Technical Support.

The following table identifies:

  • First column—Available versions of the APM Clients product. The APM Clients product contains Windows, Mac, and Linux versions of the BIG-IP Edge Client. Use it when you want to upgrade your BIG-IP Edge Client versions without upgrading the entire BIG-IP APM system.
  • Second column—The BIG-IP versions that come with that version of the APM clients product.
  • Third and fourth columns—The BIG-IP Edge Client versions in that APM Clients product.

For example, in the following table, the third row shows that the APM Clients product in the first column is included in the BIG-IP versions in the second column. The third and fourth columns display the versions of the BIG-IP Edge client included in that APM Clients product. If you want to upgrade your versions of the BIG-IP Edge Client without upgrading your entire system, you can download the APM Client product 7.1.9 or later and install the versions of the BIG-IP Edge Client that it contains. For more information, refer to K52547540: Updating BIG-IP Edge Client for the BIG-IP APM system.
