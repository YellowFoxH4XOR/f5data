K000162009: Remote users with usernames begin with an underscore cannot access some BIG-IP Configuration Utility pages

Type
Support Solution
Published
2026-07-01
Updated
2026-10-16
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3, 21.0.0, 21.1.0, 17.5.1
Source
https://my.f5.com/manage/s/article/K000162009

Description

After logging in to the BIG-IP Configuration utility (GUI), remotely authenticated users cannot access certain pages, such as Device Management → Overview, Application Security, and System → Support. The GUI displays the message “Error getting auth token from login provider” and the associated requests return HTTP 400 error.

Figure: GUI error on "[Device Management]=>[Overview]" for user "_admingroup_user1"

The restjavad process may log messages similar to the following:

/var/log/restjavad.0.log

[WARNING][187][18 Jun 2026 11:09:07 JST][RestOperationIdentifier] Failed to validate Authentication failed.

/var/log/restjavad-audit.0.log

[I][204][18 Jun 2026 11:09:52 JST][ForwarderPassThroughWorker] {"user":"local/null","method":"POST","uri":"http://localhost:8100/mgmt/shared/authn/login","status":400,"from":"$(GUI client address)"}

The issue is known to affect certain GUI pages and sections, including:

  • Device Management → Overview
  • Device Management → Traffic Groups → [traffic-group-object]
  • Shared Objects
  • iApps → Application Services → Applications LX

Environment

  • BIG-IP versions: v17.1.3.2, v17.5.1.6, v21.0.0.2, v21.1.0
  • Remote authentication is configured, such as Active Directory, LDAP or RADIUS
  • The username starts with underscore '_', for example: _adminuser1

Cause

The issue is tracked under Bug ID2295233.

Answer/Recommended Actions

The fix for ID2295233 is included in the fix for ID2304105, which is currently in progress and will be incorporated into a future maintenance release. In the meantime, you may request an EHF that addresses both ID2295233 and ID2304105.
