Each MyF5 user role corresponds to a set of actions that users with that role can take on a MyF5 account. There are currently six MyF5 user roles. Only the Admin role has permissions to assign roles to others. The role privileges apply to all accounts for which they have access.

About MyF5 account user statuses

There are two user statuses:

  • Active—User has access to a MyF5 account.
  • Pending—User is invited to and has completed registration on MyF5 but still approval needs to be procured from F5 Account Manager or Customer Success Manager.
