Description

When you construct the tcp monitor needed for your remote session host servers there are specific Send and Receive strings needed for each version.

Environment

Relevant environmental factors specific to the topic

  • Pools, TCP monitor, Microsoft Session host servers

Cause

When using the tcp monitor Send and Receive strings in the deployment guide they fail for the Microsoft Remote Desktop Session Host.

Recommended Actions

Use the following Send and Receive strings for the specific Microsoft Server versions.

  1. 2008
    1. Send String: \x03\x00\x00\x13\x0E\xE0\x00\x00\x00\x00\x00\x01\x00\x08\x00\x03\x00\x00\x00
    2. Receive String: \x03\x00\x00\x13\x0E\xD0\x00\x00\x12\x34\x00\x02\x09\x08\x00\x02\x00\x00\x00
  2. 2012
    1. Send String: \x03\x00\x00\x13\x0E\xE0\x00\x00\x00\x00\x00\x01\x00\x08\x00\x03\x00\x00\x00
    2. Receive String: \x03\x00\x00\x13\x0E\xD0\x00\x00\x12\x34\x00\x02\x07\x08\x00\x02\x00\x00\x00
  3. 2012 R2
    1. Send String: \x03\x00\x00\x13\x0E\xE0\x00\x00\x00\x00\x00\x01\x00\x08\x00\x0b\x00\x00\x00
    2. Receive String: \x03\x00\x00\x13\x0E\xD0\x00\x00\x12\x34\x00\x02\x09\x08\x00\x02\x00\x00\x00
  4. 2016
    1. Send String: \x03\x00\x00\x13\x0E\xE0\x00\x00\x00\x00\x00\x01\x00\x08\x00\x0b\x00\x00\x00
    2. Receive String: \x03\x00\x00\x13\x0e\xd0\x00\x00\x124\x00\x02\x1f\x08\x00\x08\x00\x00\x00
  5. 2019
    1. Send String:\x03\x00\x00\x13\x0E\xE0\x00\x00\x00\x00\x00\x01\x00\x08\x00\x0b\x00\x00\x00
    2. Receive String: \x03\x00\x00\x13\x0e\xd0\x00\x00\x12\x34\x00\x03\x00\x08\x00\x02\x00\x00\x00 
  6. 2022
    1. Send String: \x03\x00\x00\x13\x0E\xE0\x00\x00\x00\x00\x00\x01\x00\x08\x00\x0b\x00\x00\x00
    2. Receive String: \x03\x00\x00\x13\x0e\xd0\x00\x00\x124\x00\x02\x1f\x08\x00\x08\x00\x00\x00
  7. 2025
    1. Send String: \x03\x00\x00\x13\x0e\xe0\x00\x00\x00\x00\x00\x01\x00\x08\x00\x0b\x00\x00\x00
    2. Receive String: \x03\x00\x00\x13\x0e\xd0\x00\x00\x12\x34\x00\x02\x2f\x08\x00\x08\x00\x00\x00

Note: Depending on required RDP client option or RDP server settings, send/recv strings may need to be adjusted accordingly.

 

If above send/recv string does not work for you, you can configure TCP monitor send/recv strings from a packet capture of your successful RDP connection.

 

  1. Have a direct RDP access to backend remote session host servers and take packet capture of a successful RDP connection.

  2. From the packet capture, extract TCP data payload of 'Negotiate Request (rdp.neg_type == 0x01)' packet and 'Negotiate Response (rdp.neg_type == 0x02)' packet from successful RDP connection. Convert the output to the TCP monitor string format.
    ## Client Request (Request String) ##
[root@bigipltm1:Active:Standalone] config # tshark -r rdp-direct-access.pcap -Y 'rdp.neg_type == 0x01' -Tfields -e tcp.payload 2>/dev/null | sed 's/../\\x&/g'
\x03\x00\x00\x13\x0e\xe0\x00\x00\x00\x00\x00\x01\x00\x08\x00\x0b\x00\x00\x00
[root@bigipltm1:Active:Standalone] config #

## Server Response (Receive String)  ##
[root@bigipltm1:Active:Standalone] config # tshark -r rdp-direct-access.pcap -Y 'rdp.neg_type == 0x02' -Tfields -e tcp.payload 2>/dev/null | sed 's/../\\x&/g'
\x03\x00\x00\x13\x0e\xd0\x00\x00\x12\x34\x00\x02\x2f\x08\x00\x08\x00\x00\x00
[root@bigipltm1:Active:Standalone] config #
  3. Create TCP monitor with the extracted send/recv strings. 
    [root@bigipltm1:Active:Standalone] config # tmsh create ltm monitor tcp my_rdp_tcp_mon send "\x03\x00\x00\x13\x0e\xe0\x00\x00\x00\x00\x00\x01\x00\x08\x00\x0b\x00\x00\x00" recv "\x03\x00\x00\x13\x0e\xd0\x00\x00\x12\x34\x00\x02\x2f\x08\x00\x08\x00\x00\x00"
[root@bigipltm1:Active:Standalone] config # tmsh modify ltm pool rdp_pool monitor my_rdp_tcp_mon
[root@bigipltm1:Active:Standalone] config # tmsh list ltm monitor tcp my_rdp_tcp_mon send recv
ltm monitor tcp my_rdp_tcp_mon {
    adaptive disabled
    recv \x03\x00\x00\x13\x0e\xd0\x00\x00\x12\x34\x00\x02\x2f\x08\x00\x08\x00\x00\x00
    send \x03\x00\x00\x13\x0e\xe0\x00\x00\x00\x00\x00\x01\x00\x08\x00\x0b\x00\x00\x00
}
[root@bigipltm1:Active:Standalone] config #
