K000164062: Source IP Stickiness on F5 Distributed Cloud uses the Layer 3 source IP, not X-Forwarded-For or True-Client-IP

Type
Support Solution
Published
2026-10-30
Updated
2026-10-30
Source
https://my.f5.com/manage/s/article/K000164062

Description

Source IP Stickiness does not keep a client on the same backend server. Requests from the same client IP are forwarded to different origin servers.

Environment

  • F5 Distributed Cloud (XC) HTTP Load Balancer
  • Load Balancing Algorithm set to Source IP Stickiness, which uses a RING_HASH load-balancing policy
  • Origin pool with multiple origin servers
  • Upstream proxy, firewall, or router that performs NAT
  • Trusted Client IP Headers enabled with X-Forwarded-For

Cause

  • Source IP Stickiness is evaluated on the Layer 3 source IP observed by F5 XC. It is not evaluated on the client IP in an HTTP header.
  • When an upstream device uses NAT, many clients share one observed source IP. 

Answer/Recommended Actions

  1. Confirm the behavior. Source IP Stickiness uses the Layer 3 source IP. Trusted Client IP Headers does not change the hash.
  2. Switch to Cookie persistence.
  3. If cookie persistence is not possible for your application then you can change the load-balancing algorithm to hash on a client-specific header:
    1. In the HTTP Load Balancer, open the load-balancing algorithm settings for the origin pool.
    2. Select Ring Hash Policy.
    3. Select Configure, then select Add.
    4. In the Hash Policy Specifier drop-down menu, select Header Name.
    5. Enter the name of a header whose value is unique to the client. Confirm that the header is inserted correctly in the request logs.
  4. Verify the result. Requests from the same client should reach the same backend while the pool membership, pool order, and health-check state remain unchanged.

Additional Information

  • Trusted Client IP Headers and the Load Balancing Algorithm are separate settings. Trusted Client IP Headers affects which client IP is used for the client. It does not change the Source IP Stickiness hash.
  • Reference: Create HTTP Load Balancer (F5 Distributed Cloud documentation), section 8.1: Configure load balancing algorithm
