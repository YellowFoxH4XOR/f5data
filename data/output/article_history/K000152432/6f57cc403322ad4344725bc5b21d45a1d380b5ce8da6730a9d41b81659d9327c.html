Description

This article describes how to manage multiple custom ports on different HTTP load balancers.

Environment

  • F5® Distributed Cloud LB

Recommended Actions

The customer port can be managed using two options:

  • HTTPS Listen Port
  • Port Ranges

The port range option supports two formats: "-" and ","

  • Dash "-": Used to select a continuous range of ports (with a maximum of 64 ports).
  • Comma ",": Used to specify multiple individual ports that do not need to be consecutive.

Note:

Using a dash creates a single listener for all ports in the specified range, which is exclusive across the entire tenant. This means that if one Load Balancer (LB) is configured with the port range 8000–8020, no other HTTP LB, regardless of namespace, can use a range that overlaps with it (e.g., 7999–8001).

Using commas creates individual listeners for each specified port. This allows multiple Load Balancers to use the same ports, even if they belong to different or the same Load Balancers.

 

If you want to define a specific port range, it will create an exclusive listener that cannot be duplicated. This is suitable for precise control. On the other hand, if you have multiple custom ports for different domains, using the comma format might be a better option for your situation, as it creates a separate listener for each port and Load Balancer.
