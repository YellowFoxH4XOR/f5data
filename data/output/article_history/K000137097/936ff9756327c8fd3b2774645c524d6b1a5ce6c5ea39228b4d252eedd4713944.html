Description

  • ASM/AWAF coverage or protection against CVE-2023-5129

Environment

  • BIG-IP ASM/WAF/AWAF

Cause

This CVE primarily affects clients and not the web servers that BIG-IP ASM/WAF/AWAF is primarily designed to protect.

Recommended Actions

A custom signature can be created in ASM/WAF/AWAF to partly mitigate this CVE. However, please note that this signature merely detects lossless webp files being uploaded. This doesn't analyze if the uploaded webp file is actually malicious or not. As this type of analysis is typically performed by antivirus/endpoint protection solutions. Because of this it can result in high false positives.

 

Steps for creating a custom signature:

  1. Navigate to Security > Options > Application Security : Attack Signatures : Attack Signatures List
  2. Click on Create and use the following details given below.
  3. Then use this in a Custom Signature in the required policy

 Attack Signature Name: WebP Lossless

 Signature Type: Malicious File Upload

 Assigned Systems: Various systems

 Rule (Advanced Mode): valuecontent:"RIFF"; norm; valuecontent:"WEBPVP8L"; norm; distance:4; within:12;

 Accuracy: Low

 Risk: HIGH
