K31906082: Authorization Error: user admin with role admin doesn't have access to ''management-ip-rules''

Type
Support Solution
Published
2026-09-09
Updated
2026-09-09
Applies to

  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K31906082

Description

User not able to delete Platform Firewall rule even using admin or root account and getting error below:

Authorization Error: user admin with role admin doesn't have access to "management-ip-rules"

 

Environment

  • LTM
  • Firewall Rules on LTM

Cause

Not using correct Syntax 
 tmsh delete security firewall management-ip-rules rules  {API_Reject}

Recommended Actions

  1. Use the syntax below to delete Firewall Rules
tmsh modify security firewall management-ip-rules rules delete { API_Reject }
