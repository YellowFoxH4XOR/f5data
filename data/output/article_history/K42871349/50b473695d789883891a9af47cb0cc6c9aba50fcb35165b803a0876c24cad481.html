K42871349: Deploying BIG-IP VE with Azure ARM template requires internet access

Type
Support Solution
Published
2021-10-27
Updated
2023-02-21
Applies to
  • Public Cloud
  • BIG-IP
  • BIG-IP LTM: 16.0.X, 15.1.X, 16.1.0, 16.0.1, 16.0.0, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 16.1.X, 15.1.2, 15.1.1, 15.1.0, 16.1.3, 16.1.2, 16.1.1, 15.1.3
  • Microsoft Azure
Source
https://my.f5.com/manage/s/article/K42871349

Description

Deploying new BIG-IP VE with Azure ARM template may fail with the following message.

{
    "status": "Failed",
    "error": {
        "code": "VMExtensionProvisioningError",
        "message": "VM has reported a failure when processing extension 'start'. Error message: \"Enable failed: processing file downloads failed: failed to download file[0]: failed to download file: http request failed: Get [REDACTED] dial tcp 203.0.113.0:443: i/o timeout\"\r\n\r\nMore information on troubleshooting is available at https://aka.ms/VMExtensionCSELinuxTroubleshoot "
    }
}

Environment

This issue occurs when the following conditions are met.

  • Internet access is not allowed in Azure environment.

  • Deploying new BIG-IP VE with Azure ARM template provided in the following github.

    https://github.com/F5Networks/f5-azure-arm-templates/

Cause

Public Internet access is necessary during initialization in order to retrieve needed cloud libraries.

Recommended Actions

When deploying new BIG-IP VE with Azure ARM template, you need to allow public internet access.
