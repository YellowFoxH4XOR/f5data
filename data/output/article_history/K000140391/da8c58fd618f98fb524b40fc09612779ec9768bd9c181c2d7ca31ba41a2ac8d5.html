Description

Virtual server is marked offline.

there is no default pool for this virtual server.

 

Why does BIG-IP mark virtual server offline? Why not unknown?

 

Environment

  • BIG-IP
  • Virtual server
  • Offline
  • No default pool

 

Cause

Possible cause if irule attached to the virtual server is referring pool, and the pool members are down.

  • K73440174: How referenced pools in iRules affect VIP status

 

Recommended Actions

  • Check the cause of monitor failure for the pool members associated in iRule.

 

Additional Information

  • K81005856: Virtual Server offline while pool used in Local Traffic Policy is up
