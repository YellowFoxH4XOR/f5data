Description

The following restjavad log message indicates that the BIG-IP REST framework initiated an SSL Orchestrator package installation or initialization operation:

[SEVERE][792898][14 Sep 2026 10:08:22 KST][8100/shared/iapp/package-installer-tasks PackageInstallerTaskWorker] move /var/config/rest/tmp.ABCDEF/var/config/rest/iapps/f5-iappslx-ssl-orchestrator -> /var/config/rest/iapps/f5-iappslx-ssl-orchestrator

Opening SSL Orchestrator > Configuration for the first time can automatically initiate SSL Orchestrator package installation.

Environment

  • BIG-IP
  • BIG-IP SSL Orchestrator

Cause

The first access to the SSL Orchestrator Guided Configuration can automatically initialize the required SSL Orchestrator package. 

The PackageInstallerTaskWorker component manages package installation and initialization tasks for iAppLX applications.

This message is commonly generated when the SSL Orchestrator Guided Configuration is accessed and the built-in SSL Orchestrator RPM is initialized. Accessing SSL Orchestrator > Configuration can automatically invoke installation of the built-in RPM; an administrator does not necessarily need to perform a separate manual package-installation operation.

Recommended Actions

The behaviour is expected and by design.
