Description

For a BIG-IP LTM device, you may configure the SNI for the HTTPS monitor by following K65219243: SNI support for HTTPS monitors. If you want to configure the SNI for your DNS HTTPS monitor using your BIG-IP DNS (formerly known as BIG-IP GTM), slightly different steps and requirements apply. The BIG-IP DNS supports the SNI option in the HTTPS monitor starting in BIG-IP DNS 16.x. 

Environment

  • BIG-IP DNS
  • BIG-IP DNS 16.x or later
  • SNI option for DNS (GTM) HTTPS Monitors

Cause

None.

Recommended Actions

You may configure the SNI for your DNS HTTPS monitor by the below steps:

  1. Log in to your Configuration Utility
  2. Go to DNS  ››  GSLB : Monitors, select an existing DNS HTTPS monitor configuration or create a new one
  3. Under the Configuration section, select Advanced for the dropdown menu
  4. Put your SNI name into the SNI Server Name text box
  5. Click Save (or Update if you are editing the existing one)

Additional Information

The BIG-IP DNS prior to BIG-IP 16.x do not support SNI for DNS HTTPS Monitors. If you are running BIG-IP DNS earlier versions that do not support SNI on the DNS HTTPS monitor and if your pool member is configured on a BIG-IP LTM device, you may want to consider using the BIG-IP LTM device to monitor the pool member while associating it to a virtual server and then use the bigip monitor to import its configuration into the BIG-IP DNS.

Unlike LTM HTTPS monitors, you do not need to enable in-tmm monitoring to use SNI in DNS HTTPS monitors.
