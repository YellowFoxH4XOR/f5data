K000163455: Browser Challenges Live Update file cannot be deleted

Applies to

Source

Description

An older Browser Challenges update file remains Pending in Live Update installation history while a newer update is Currently Installed. Attempting to delete the older file through the CLI returns a response containing:

"code":500,"message":"Can not delete the genesis file"

Environment

  • BIG-IP ASM / Advanced WAF
  • Live Update, Browser Challenges

Cause

The update file ban be a genesis file. Deleting a genesis Browser Challenges file is blocked by design even if it is not installed.

This is distinct from K34131289, which describes a deletion failure caused by an installation with status previously-installed. That article shows a different error message: Could not delete the update file, an installation with status previously-installed exists and references this update file.

Recommended Actions

  1. Compare the file’s exact name with the Browser Challenges genesisFileName entry in /etc/live-update-genesis.yaml
  2. If further confirmation is needed, inspect the Browser Challenges Live Update update-file record’s isGenesis field and its linked installation status. K58021531 documents read-only listings of update files and installations. Database and Tomcat logs may also mention the filename, but their historical entries should not replace the genesis YAML when identifying the file.

If the file is confirmed to e genesis, then the behavior is expected. Keep the file in place
