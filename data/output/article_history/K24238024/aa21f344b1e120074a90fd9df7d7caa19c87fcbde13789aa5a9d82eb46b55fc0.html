Description

While using pool members with old Microsoft OWA version (e.g.:Exchange 16 cu19), mixed with new OWA server (e.g.:Exchange 16 cu21), you get connected to OWA but after few seconds it got back to OWA login page.

Environment

  • iApp Exchange 2016 using Microsoft OWA servers
  • OWA servers mixed with cu versions

Cause

This occurs if users are accessing the servers through the BIG-IP, and not all servers in the pool are running the same OWA version.

Microsoft published an article about this issue

Recommended Actions

You can update all the non-updated servers in the pool at one time. You can also update them in batches by removing non-updated servers from the pool, until all pool members updated with the same cu.
