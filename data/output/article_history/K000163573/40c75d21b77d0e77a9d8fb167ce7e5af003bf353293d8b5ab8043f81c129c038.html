K000163573: iRule domain literal causes an undefined procedure error

Type
Support Solution
Published
2026-10-06
Updated
2026-10-06
Source
https://my.f5.com/manage/s/article/K000163573

Description

An attached iRule disrupted traffic forwarding to pool members by invoking a domain string as a procedure during the HTTP_RESPONSE event. The BIG-IP log reported:

01070151:3: Rule [...] error: [...] error: [undefined procedure: Web_1.example.com][Web_1.example.com]

Environment

  • BIG-IP ASM

  • BIG-IP version 17.1.3

  • Virtual server with an iRule processing HTTP_REQUEST and HTTP_RESPONSE events

Cause

A syntax error caused the iRule to interpret the domain string as a procedure during HTTP_RESPONSE processing. This generated an undefined-procedure error and prevented the iRule from executing as intended.

Answer/Recommended Actions

  • Correct the iRule syntax so domain strings are not invoked as procedures.

  • Validate iRule logic after modifications to identify syntax errors.

  • Test iRule changes in a staging environment before production deployment.

  • Monitor LTM logs for iRule errors after deployment.
