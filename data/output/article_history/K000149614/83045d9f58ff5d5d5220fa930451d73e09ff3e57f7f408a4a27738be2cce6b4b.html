Topic

This article applies to the VELOS partition. For information about resetting the configuration for the entire VELOS chassis, refer to the following article:

  • K05531172: Restoring the VELOS configuration data to factory default settings

For information about resetting the configuration for other F5 systems, refer to the list of articles in the Related Content section at the end of this article.

Description

You can reset the configuration of a VELOS partition to the factory default settings using the system database reset-to-default command. When you run the system database reset-to-default command for a VELOS partition, you load the default configuration into the running database for the partition. When the default configuration loads, the existing configuration is removed; this includes (but not limited to) the network settings such as VLANs and LAGs, the SNMP configurations, the Telemetry settings as well as all deployed tenants. Additionally, the partition admin user’s password will be reset to when the partition is initially deployed, i.e. admin. You will be prompted to change the partition admin user’s password upon initial login. Note that the partition’s management IP address remains unchanged during the process.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the VELOS partition command-line interface (CLI).

Procedures

Reset the VELOS partition configuration to default settings

Before you reset the VELOS partition to the default settings, you should back up your current configuration and export the configuration to a remote host. For more information about backing up and exporting the configuration, refer to K50135154: Backing up and restoring F5OS configuration on a VELOS system.

To reset the VELOS partition to the default settings, perform the following procedure:

Impact of procedure: Performing the following procedure removes the current configuration from the VELOS partition including the deployed tenant(s) and loads the default configuration. Traffic processing is disrupted until the tenant(s) are restored or re-configured and re-deployed.

  1. Log in to the VELOS partition CLI as the partition admin user.
  2. Enter the configuration mode terminal by entering the following command:

    config

  3. Reset the partition to the default settings by entering the following command:

    system database reset-to-default

    The system prompts you the following:

    Removing all user configuration will delete all tenants and stop traffic processing.
    Proceed? [yes/no]:

  4. If you wish to proceed, enter yes to confirm you want the partition to load the default settings. When the system completes the process, it returns a message similar to the following example:

    result Database reset-to-default successful.

  5. You can now proceed to perform an initial login to the partition using the webUI to its management IP address with the default admin user credentials. The webUI should prompt you to change the admin user password. If you need to restore a previously backup configuration from a remote host to the partition, refer to K50135154: Backing up and restoring F5OS configuration on a VELOS system. Otherwise proceed to configure the partition as needed.
