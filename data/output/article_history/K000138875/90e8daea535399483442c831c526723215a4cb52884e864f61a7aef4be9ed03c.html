Applies to

Source

Description

UCS creation via REST API appears to do nothing when sending query to /mgmt/tm/sys/ucs

UCS creation via REST API appears to do nothing when sending query to /mgmt/tm/task/sys/ucs

 

Environment

BIG-IP version v13+

REST API

Cause

The synchronous, URI (/mgmt/tm/sys/ucs) request does not get an immediate response when saving large UCS files and waits for a response from iControl REST.

In contrast, sending an asynchronous URI (/mgmt/tm/task/sys/ucs) only create a task with task state of UPDATING. To start the task, modify the value of task state VALIDATING in a PUT request and specify the selfLink as the endpoint.

Recommended Actions

To create the UCS you will need to send the query to the asynchronous uri (/mgmt/tm/task/sys/ucs) which will create the task. You must then validate that task to run otherwise it will time out and nothing will happen.

You can follow these steps:

[root@bigip-device:Active:Disconnected] config # curl -sk -u admin:admin -H "Content-Type: application/json" -X POST https://localhost/mgmt/tm/task/sys/ucs -d '{"command":"save","name":"/var/local/ucs/ucs-filename.ucs"}' | jq

 

You should get back data that is similar to this:

{
"_taskId": 1708800684638206,
"_taskState": "STARTED",
"_taskTimeInStateMs": 0,
"_taskResultLink": "https://localhost/mgmt/tm/task/sys/ucs/1708800684638206/result?ver=16.1.4.2",
"selfLink": "https://localhost/mgmt/tm/task/sys/ucs/1708800684638206?ver=16.1.4.2"
}

The next step is to validate the task so the job will actually run. We accomplish this with the 'taskId': 

[root@bigip-device:Active:Disconnected] config # curl -sk -u admin:admin -H 'Content-Type: application/json' -X PUT -d '{"_taskState":"VALIDATING"}' https://localhost/mgmt/tm/task/sys/ucs/1708800684638206 | jq

{
"code": 202,
"message": "Task will execute asynchronously.",
"errorStack": []
}

Finally, you can check the status the task with this command (This is not a mandatory step):

root@bigip-device:Active:Disconnected] config # curl -sk -u admin:admin https://localhost/mgmt/tm/task/00684638206 | jq

{
"selfLink": "https://localhost/mgmt/tm/task/sys/ucs/1708800684638206?ver=16.1.4.2",
"_taskId": 1708800684638206,
"_taskState": "COMPLETED",
"_taskTimeInStateMs": 74000,
"_taskResultLink": "https://localhost/mgmt/tm/task/sys/ucs/1708800684638206/result?ver=16.1.4.2"
}

Additional Information

The above examples are shown piping the data to 'jq'. While not mandatory, this tool will display the output in a much easier to read format.
