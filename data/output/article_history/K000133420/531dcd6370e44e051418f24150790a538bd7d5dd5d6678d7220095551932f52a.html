K000133420: iControl SOAP API calls is not working after upgrade from v14.1.4 to v15.1.8.1

Support Solution
Published
2023-04-19
Updated
2023-04-19
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.X.X, 14.0.0, 14.0.1, 14.0.X, 14.1.0, 14.1.2, 14.1.3, 14.1.4, 14.1.5, 14.1.X, 15.1.8
Source
https://my.f5.com/manage/s/article/K000133420

Description

Unable to manage the  BIG-IP device using iControl SOAP API. This issue is noted after upgrade of the BIG-IP device from v14.1.4 to v15.1.8.1

 

Environment

Upgrade of BIG-IP device
Managing BIG-IP device using iControl SOAP API 

Cause

None

Recommended Actions

The java library is auto-generated based on the SOAP interface, and it turns out that instead of publishing it online we are shipping it on-box.

1. Download the `/usr/share/java/iControl.jar` from BIG-IP device and use that in tooling.
