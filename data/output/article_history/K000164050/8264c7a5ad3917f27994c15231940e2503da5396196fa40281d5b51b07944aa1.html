Description

On a VIPRION 4800 vCMP host, modifying interface 1/1.0 on a B4400-series blade to a 40G bundle speed with an OPT-0036 (40G QSFP+) optic failed validation. The blade's daemons did not load the configuration, and the secondary slot did not receive it. Logs showed Optic OPT-0036 not valid in Interface 1/1.0 and Unsupported module in use on interface 1/1.0. 

Environment

  •  VIPRION 4800 chassis with B4400-series blades
  • Affected port: interface 1/1.0, a 100GbE port on the blade (ports 1.0 and 2.0 are 100GbE; 3.0 through 8.0 are 40GbE)
  • Interface configuration: bundle enabled, with bundle-speed changed to 40G and media-sfp set to auto
  • Installed optic: OPT-0036 (40G QSFP+ module)

Cause

The 40G bundle-speed configuration on interface 1/1.0 is not supported with OPT-0036. Ports 1.0 and 2.0 on B4400-series blades are 100GbE ports that accept only F5-branded 100GbE QSFP28 transceivers. OPT-0036 is a 40G QSFP+ module, so the blade rejects it.

The bcm56xxd daemon flags the optic as invalid for that port, and the configuration validation fails. When the secondary slot receives the configuration from the primary, validation fails and its daemons do not load the configuration. 

Answer/Recommended Actions

- Do not install OPT-0036 (QSFP+) in ports 1.0 or 2.0 of B4400-series blades. These ports require F5-branded 100GbE QSFP28 transceivers.

- To run 40G on port 1.0 or 2.0, install a 100GbE QSFP28 module, then set the bundle speed.

- To use OPT-0036 (40G), move it to a 40GbE port on the 4450N blades (ports 3.0 through 8.0).
