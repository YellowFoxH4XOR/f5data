A RMA Work Order (WO) number will be created if F5 Support determines that hardware replacement is appropriate. You should then receive the RMA template through this RMA WO number. You must reply directly to the email after completing all of the required fields in both the Hardware Details and Shipping Details sections of the RMA template.

Important: You must provide the data in the Required Information section of this form whether you have been directed to do so by an F5 Support representative or as the result of an iHealth diagnosis critical match.

For complete details on the RMA process, including service levels and shipping information, refer to K12882: Overview of the F5 RMA process.

Hardware details

  • Refer to the following procedures to determine the required information to complete the RMA template sent through the RMA WO number.
  • If the suspected defective unit is offline, you can collect the data (except the serial number) from the high availability (HA) peer of the unit.
  • For additional assistance locating the serial number, refer to K917: Finding the serial number or registration key of your F5 device.

Note: If commands for your product are not listed in the following tables, contact F5 Support for assistance in gathering the required information.

Determining hardware details for BIG-IP products

Type the commands listed below on the BIG-IP command line.

ItemCommand
Serial number (appliance/chassis)tmsh show sys hardware | grep 'Chassis Serial'
Serial number (blade)clsh tmsh show sys hardware | grep 'Host Board Serial'
Memoryphysmem -m
Redundant power supplytmsh show sys hardware | grep -A5 "Power Supply"
Software versiontmsh show sys version

Determining hardware details for ARX products

Type the commands listed below on the ARX command line.

ItemCommand
Serial numbershow chassis chassinfo
Disk detailsshow chassis diskuse
Software versionshow version

Determining hardware details for VELOS/rSeries products

Type the commands listed below on the VELOS/rSeries command line.

ItemCommand
Serial number (VELOS chassis)show components component chassis state serial-no
Serial number (VELOS controller)show components component controller-* state serial-no
Serial number (VELOS blade)show components component blade-* state serial-no
Serial number (rSeries)show components component platform state serial-no
Memory (VELOS/rSeries)show components component state memory
Redundant power supply (VELOS/rSeries)show components component psu-* state
Software versionshow sys version

Note: If the VELOS/rSeries command line is unavailable, you can use the device's AOM to get these information except for memory and software version. For more information, refer to K13428255: Get VELOS and rSeries hardware diagnostics when CLI access is not available.
