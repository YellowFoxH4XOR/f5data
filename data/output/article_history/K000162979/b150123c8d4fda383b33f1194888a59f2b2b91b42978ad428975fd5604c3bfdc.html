K000162979: Portal Access Get Unexpected HTTP response (like HTTP 400) When Query Parameters Contain Special Character Like & =

Type
Support Solution
Published
2026-08-19
Updated
2026-08-19
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.0, 21.0.X, 21.0.0, 17.5.1, 21.X.X, 17.5.X, 21.1.X, 21.1.0, 17.1.3
Source
https://my.f5.com/manage/s/article/K000162979

Description

Portal Access get the unexpected HTTP response like HTTP/1.1 400 Bad Request when URL rewriting converts special character like "&" or "=".

For example: 

= become &#x3D;

& become &amp;

When access the internal server directly, the query parameters is: /f?p=xxx
When access the internal server via portal access, the query parameters become: /f?p&#x3D;xxx

When access the internal server directly, the query parameters is: &filedownload=X 
When access the internal server via portal access, the query parameters become: &amp;filedownload=X

Environment

  • BIG-IP APM 17.1.3.X, 17.5.X, 21.X
  • Portal Access

Cause

It is caused by Bug ID 2137909, Portal Access: unwanted decoding html entities in attribute values of HTML tags.

Recommended Actions

There are 3 solutions for this issue:

A. Check the Bug ID 2137909, find the version which contain the fix, upgrade to the new version. Now it is not fixed yet.

B. Follow the article K16533717: iRule to replace a string in the HTTP URI, convert the string back to the correct character.

For example, apply an iRule to the virtual server to replace &amp; with a literal ampersand only for the affected HTTP requests.

when HTTP_REQUEST {
    if {
        ([HTTP::path] starts_with {/<The path of the query string>}) &&
        ([HTTP::uri] contains "&amp;")
    } {
        HTTP::uri [string map {"&amp;" "&"} [HTTP::uri]]
    }
}

C. Follow the article K000148786: Latest cache-fm-Modern.js file for Portal Access, replace the file cache-fm.js or cache-fm-Modern.js for different BIG-IP version which not impacted by the Bug ID 2137909.

Additional Information

The iRule uses the string-replacement method described in K16533717: iRule to replace a string in the HTTP URI.

A global replacement can modify unrelated requests and cause unexpected application behavior. Restrict the condition to the affected Portal Access download path.
