Description

Uploaded iso image does not display build, version, and it does not let you install.

Below command output shows similar to:

tmsh list sys software 

sys software image BIGIP-12.1.5.3-0.0.5.iso {
    build none
    build-date "none"
    checksum <checksum_value>
    file-size "XXXX MB"
    last-modified "DAY Mmm DD HH:MM:SS YYYY"
    product none
    verified yes
    version none
}
 

Environment

  • BIG-IP
  • Software installation
     

Cause

Bug ID 925357
 

Recommended Actions

To check if you are encountering this issue, run below command
pstree | grep -i loop
if this command output is similar to loopback address are used up

And run
mount
 
This command does not show any mounted iso images, then run the commands in workaround in Bug ID 925357 in order.
for mnt in $(mount | grep -Po "(?<=\.iso on )\S+ (?=.*loop=)"); do umount $mnt; done
for lodev in $(losetup -a|cut -d: -f1); do losetup -d $lodev; done
NOTE: These command should not affect processing traffic, however recommend to run on maintenance window.
 
And then restart lind
bigstart restart lind

If this does not work, then please also do
mv /shared/images/<iso_image_name_in_trouble> /shared/ && mv /shared/<iso_image_name_in_trouble> /shared/images/
