K000164175: iApps packages are not syncing to Standby BIG-IP

Type
Support Solution
Published
2026-11-17
Updated
2026-11-17
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000164175

Description

You imported iApps package for example f5-appsvcs to Active BIG-IP. You sync the configuration but you do not see the AS3 package in the Standby BIG-IP.

When you run "restcurl shared/gossip | grep status", the status is shown as Active on both BIG-IP.

Environment

  • BIG-IP
  • iApps Package Management LX

Cause

Bug ID 650115

Answer/Recommended Actions

Follow workaround mentioned in Bug ID 650115. The workaround mentions to use Management IP address but you may need to use Config Sync IP address.

Additional Information

When the iApps file is being copied to standby BIG-IP, you should seeing a similar log message as below in the Standby device. Also the Standby BIG-IP "restcurl shared/gossip | grep status" output will be in SYNCHRONIZING status.
[I][24864][26 Oct 2026 17:01:50 UTC][8100/shared/gossip GossipWorker] Copying state from https://<Active BIG-IP IP address>:443.

Once completed you should be seeing similar log message as below in Standby BIG-IP. It takes time to complete.
[I][146658][26 Oct 2026 18:11:18 UTC][8100/shared/gossip GossipWorker] Done copying state from https://<Active BIG-IP IP address>:443.
