K000138192: Unable to edit the configuration of an iApp object, error: "template:can't eval proc: "script::run" 01020036:3: The requested module allocation (am)"

Type
Support Solution
Published
2024-01-11
Updated
2024-01-11
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000138192

Description

After attempting to edit the configuration of an iApp object the following error appears.


Error parsing template:can't eval proc: "script::run" 01020036:3: The requested module allocation (am) was not found. while executing "tmsh::get_config sys provision $args" (procedure "iapp_get_provisioned" line 32) invoked from within "iapp_get_provisioned am" invoked from within "tmsh::run_proc f5.iapp.1.1.2.cli:iapp_get_provisioned am" (procedure "script::run" line 3) invoked from within "script::run" line:1


The above error can also appear while trying to create an object.



Environment

  • iApps

Cause

The cause of the above error is that a deprecated iApp template is being used in a bigip version that is not supported anymore.


Recommended Actions

The following solutions can be followed in the above scenario.


  1. If an object already exists, it should be either redeployed using an updated version of the iApp template or "Strict Updates" should be disabled to allow editing from the "Local Traffic" menu.
  2. If a new object is being deployed, the updated iApp template should be used to avoid the error.
