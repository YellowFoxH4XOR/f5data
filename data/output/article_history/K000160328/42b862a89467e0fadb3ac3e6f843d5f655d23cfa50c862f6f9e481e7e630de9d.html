Topic

You should consider using this procedure under the following condition:

  • You want to display the F5 Insight software version information.

Description

To display the F5 Insight software version, you can use the F5 Insight UI.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have a valid user account to access the F5 Insight UI.

Procedures

To display the F5 Insight software version, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Access the F5 Insight UI using HTTPS and the F5 Insight VM IP address. For example, if the F5 Insight VM IP address is 10.10.10.100, then you would use https://10.10.10.100.
    You can view the F5 Insight VM IP address at the following locations depending on your deployment:
    • The OpenStack Horizon instance details page or the instance console after booting the VM.
    • The vSphere Client under the VM’s Summary tab, or the Console tab after booting the VM.
  2. Log in using your user account credentials.
  3. Under Manage, select About. The F5 Insight version is displayed under Version.
