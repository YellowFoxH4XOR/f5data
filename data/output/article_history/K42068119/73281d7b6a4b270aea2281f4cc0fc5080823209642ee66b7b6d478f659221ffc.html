Description

  • Using the tmsh utility to create a SNAT pool

Environment

  • BIG-IP

Cause

None

Recommended Actions

Creating a SNAT Pool using the tmsh utility:
  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Use the following syntax to to create a SNAT pool along with its member:

    create ltm snatpool <name_of_snat> members add { <pool_member_IP_address }

  3. Save the configuration by typing the following command:

    save /sys config
