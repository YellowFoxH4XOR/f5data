Description

  • This solution will describe the Portal Access/Rewrite cache and how to view and delete cache entries.
  • Portal Access configurations display cached content.

Environment

  • APM
  • Portal Access, Rewrite Profile

Cause

The apm-enduser-if-cache caching profile is used for Portal Access/Rewrite. You can define different caching profiles (Web Acceleration profile) and apply them to virtual servers, but the apm-enduser-if-cache profile is used by the internal Virtual Server for Portal Access.

﻿

 Recommended Actions

Displaying Entries:


  1. Login to the CLI.
  2. User the following tmsh command:

tmsh show ltm profile ramcache apm-enduser-if-cache


Deleting Entries:


  1. Login to the CLI
  2. User the following tmsh command to delete a single entry or the entire cache:

tmsh delete ltm profile ramcache apm-enduser-if-cache uri /<uri_object>


tmsh delete ltm profile ramcache apm-enduser-if-cache
