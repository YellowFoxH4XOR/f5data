K000092892: Troubleshooting F5OS network interfaces

Type
Support Solution
Published
2022-11-30
Updated
2026-10-14
Source
https://my.f5.com/manage/s/article/K000092892

Description

You should consider using these procedures under the following condition:

  • You would like to troubleshoot the network interfaces on your rSeries Appliance.
  • You would like to troubleshoot the network interfaces on your VELOS Chassis.

Environment

  • F5OS-A
  • F5OS-C
  • Management CLI

Cause

None

Recommended Actions

The following procedures apply to both rSeries and VELOS Chassis with a single exception stated below.

1. Turn the following logging to DEBUG from the management CLI:
a. fpgamgr ( Except r2x00 and r4x00 )
b. l2-agent
c. optics-mgr
2. Perform the necessary action that would generate the debug logging, for example, disabling and re-enabling of the network interface.
3. The debug logs will appear in /var/F5/system/log/platform.log.

Additional Information

The following shows an example of setting fpgamgr, l2-agent, and optics-mgr logging to DEBUG from management CLI:

Appliance-1# config terminal
Appliance-1(config)# system logging sw-components sw-component fpgamgr config severity DEBUG
Appliance-1(config-sw-component-fpgamgr)# exit
Appliance-1(config)# system logging sw-components sw-component l2-agent config severity DEBUG
Appliance-1(config-sw-component-l2-agent)# exit
Appliance-1(config)# system logging sw-components sw-component optics-mgr config severity DEBUG
Appliance-1(config-sw-component-optics-mgr)# exit
Appliance-1(config)# commit and-quit

Commit complete.


The following shows an example of a DEBUG log:

2022-11-30T07:34:35.387842+00:00 appliance-1 l2-agent[16]: priority="Debug" version=1.0 msgid=0x208000000000005 msg="" text="LagValidationHandler::validate_ifs g_lagswithmembers 0, g_delifs 0".

 

When done, you can return the components to their default logging level of INFORMATIONAL

Appliance-1# config terminal
Appliance-1(config)# system logging sw-components sw-component fpgamgr config severity INFORMATIONAL
Appliance-1(config-sw-component-fpgamgr)# exit
Appliance-1(config)# system logging sw-components sw-component l2-agent config severity INFORMATIONAL
Appliance-1(config-sw-component-l2-agent)# exit
Appliance-1(config)# system logging sw-components sw-component optics-mgr config severity INFORMATIONAL
Appliance-1(config-sw-component-optics-mgr)# exit
Appliance-1(config)# commit and-quit
