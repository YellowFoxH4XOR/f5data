Description

Getting the error below when using an iApp, ID 754541 is fixed since v15.0.0, so the ID is not related.

  • Symptoms: Can not create a new iApp
  • Error messages: the profile has no RSA cert/key pair that can be modified. To add RSA cert/key, please use [cert-key-chain add]

Environment

  • Conditions: Running version 15.0.0 or newer and using old iApps
  • Configuration objects and settings: iApps
  • Products and features: BIG-IP VE running old iApps

Cause

Newest BIG-IP versions requires newer iApps because when it creates an ssl profile now requires "cert-key-chain" option.

Recommended Actions

  1. Upgrade to the latest iApp.
  2. If using custom iApp templates which specify "key" and "cert" variables, manually adjust the template to use "cert-key-chain" variable instead (or remove).
