K000164156: Wrong status on FCP Self Service license keys in the MyF5 portal

Type
Support Solution
Published
2026-11-10
Updated
2026-11-10
Applies to
  • BIG-IP
  • BIG-IP Cloud Edition
Source
https://my.f5.com/manage/s/article/K000164156

Description

A license key in the MyF5 portal shows the incorrect status. 

Environment

  • Flex Consumption Program (FCP)

  • Big-IP Virtual Edition (VE)
  • MyF5 Self Service license keys

Cause

Unconfirmed.

Recommended Actions

Open a ticket with F5 Support and provide the following details.

  • FCP subscription number
  • Impacted license key
  • Current status
  • Expected status
  • Errors encountered
  • Screen shot of the issue

Additional Information

Some examples include:

  • "ready to reassign" but unable to activate it on another BIG-IP due to error 51092
  • "active" but the license was unassigned
  • "terminated" but reads "ready to reassign"
  • "processing" following a recent update on the license key
