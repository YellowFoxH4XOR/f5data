K000161513: Output in two different formats "show interfaces summary" command

Type
Support Solution
Published
2026-10-05
Updated
2026-10-05
Applies to
  • F5OS
  • F5OS-A: 1.8.3
Source
https://my.f5.com/manage/s/article/K000161513

Description

On F5OS (rSeries), the show interfaces summary command may produce two different output formats within the same SSH session, appearing inconsistent to the user. The output is rendered either as a compact table format or as a verbose list format depending on the terminal width at the time the command is executed.

Table format example (when terminal is wide enough):

                                    OPER                   LAG

NAME  TYPE            MTU   ENABLED STATUS  LACP STATE     TYPE  PORT SPEED

-------------------------------------------------------------------------------

1.0   ethernetCsmacd  9600  true    DOWN    LACP_DEFAULTED -     SPEED_10GB

2.0   ethernetCsmacd  9600  true    DOWN    LACP_DEFAULTED -     SPEED_10GB

Non-table (list) format example (when terminal is too narrow):

interfaces interface 1.0

 state type          ethernetCsmacd

 state mtu           9600

 state enabled       true

 state oper-status   UP

 state lacp_state    LACP_DEFAULTED

 ethernet state port-speed SPEED_10GB

interfaces interface 2.0

 state type          ethernetCsmacd

...

Environment

  • F5OS-A (rSeries platforms)
  • F5OS version 1.8.3 and later
  • CLI (SSH session)
  • show interfaces summary command

Cause

The F5OS CLI (confd-based) automatically determines the output format based on the current terminal width of the SSH session. If the terminal width is sufficient to render the table, the output is displayed in table format. If the terminal width is insufficient, the CLI automatically falls back to a non-table (list) format.

Answer/Recommended Actions

Use the | tab or | notab pipe modifiers to force a consistent output format regardless of terminal width.

  • To force table format:

    show interfaces interface summary | tab

    Example output:

                                        OPER                   LAG

    NAME  TYPE            MTU   ENABLED STATUS  LACP STATE     TYPE  PORT SPEED

    -------------------------------------------------------------------------------

    1.0   ethernetCsmacd  9600  true    UP      LACP_DEFAULTED -     SPEED_10GB

    2.0   ethernetCsmacd  9600  true    UP      LACP_DEFAULTED -     SPEED_10GB

  • To force non-table (list) format:

    show interfaces interface summary | notab

    Example output:

    interfaces interface 1.0

     state type          ethernetCsmacd

     state mtu           9600

     state enabled       true

     state oper-status   UP

     state lacp_state    LACP_DEFAULTED

     ethernet state port-speed SPEED_10GB

    interfaces interface 2.0

     state type          ethernetCsmacd

    ...

This behavior applies to other F5OS show commands that produce tabular output as well.
