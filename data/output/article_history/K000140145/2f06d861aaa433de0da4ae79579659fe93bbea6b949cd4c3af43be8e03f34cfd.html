K000140145: When navigating through GUI you see an error: An error occurred

Source

Description:

When navigating through GUI you see an error:  An error occurred



Impact:

Unable to manage settings via GUI

 

Cause:

Not enough memory provisioned for management, Java and/or Tomcat

 

Recommended action:

Verify /var/log/kern.log(s), searching for entries similar to: err kernel: Out of memory: Kill process 31614 (java) 

Apply recommended settings from:

K26427018: Overview of Management provisioning

K63328426: Increase memory for Tomcat and Restjavad when Out of Memory
