Description

BIG-IP ASM security policy Traffic Learning does not include suggestions for non-existing URIs.

Environment

  • BIG-IP ASM
  • Security Policy
  • Server response code 404 for non-existing URI

Cause
The default setting for a BIG-IP ASM security policy when requests receive a 4xx response is to not learn or make policy suggestions.

Recommended Actions

To allow the BIG-IP ASM to learn traffic with HTTP responses code 4XX, do the following:
  1. Browse to Security > Application Security > Policy Building > Learning and Blocking Settings
  2. Locate the section 'Policy Building Process'
  3. Add '4XX' to 'HTTP Response Status Codes used to learn traffic'
  4. Save
  5. Apply Policy
