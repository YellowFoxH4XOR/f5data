Description

We may observe the following logs when deploying large AS3 large declarations:

 

Configuration load fails with errors similar to:

MCPD load failed

  • 01070710:3: Database error (52), Can't write blob data, attribute:script status:52 - EdbBlobData.cpp, line 57.

Environment

BIG-IP systems configured using AS3.

A single AS3 declaration contains a very large number of objects (8000+ create commands in single transaction).

  • All TMSH commands from the AS3 declaration are passed to MCPD in one transaction.

Cause

MCPD enforces an internal limit on the maximum size of configuration transactions. Very large AS3 declarations can exceed this threshold.

This is a platform-level MCPD infrastructure limitation. It is not an AS3 parsing or validation bug.


Recommended Actions

Modularize deployments: Split large AS3 declarations into multiple smaller declarations, grouped logically 

Size guidance: Declarations larger than containing more than 5000 objects may exceed the MCPD transaction limit 

For safety, keep declarations below 2000 to 3000 objects each.
