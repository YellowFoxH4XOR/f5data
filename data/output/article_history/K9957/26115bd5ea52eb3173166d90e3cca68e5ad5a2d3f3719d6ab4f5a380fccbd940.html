Topic

New and updated documents are continually posted to MyF5. To receive the most current information, you can set up a custom RSS feed.

Important: As of Oct 16, 2023, MyF5 has decommissioned legacy APIs for RSS feeds on MyF5. This includes v1 and v2 APIs. MyF5 continues to support v3 and v4 APIs. If you are using v1 and v2 APIs, MyF5 recommends that you upgrade your RSS feeds to use the v4 API, which is the latest API version.

You are using the v1 and v2 APIs when your RSS API URL has a domain name of api-u.f5.com.

Description

Currently, MyF5 RSS feeds are compatible with RSS readers for Chrome, Firefox, Edge, and Safari browsers.

You can update MyF5 RSS feeds up to 12 times per hour. Each of the following actions count against your limit:

  • Creation of a new RSS feed.
  • Manual refresh of an RSS feed from an internet browser.
  • Automated refreshes of RSS feeds from configured subscriptions.

For example, if you create a new RSS feed then manually refresh the feed 11 times, additional refreshes will not return new data until the next hour. After the limit is exceeded, some RSS readers may also display a "code":"quota-exceeded" error message.

To create a custom RSS feed, perform the following procedure:

To watch a video demo of this procedure, go to  Create a custom RSS feed to view new and updated documents.

  1. Go to MyF5.
  2. In the Resources section, select New and Updated Articles.
  3. For Product, select the product you want to generate an RSS feed for.

    Note: Currently, you can create an RSS feed for only one product at a time.

  4. Optional: For Show by a date range, select the period of time you want to use. The default selection is Past seven days.
  5. Optional: For Version, select a software version.

    Note: If you selected a product that does not have the Version menu available in step 4, skip this step.

  6. Optional: For Content Type, select a type of document.
  7. For Document status, select one of the following:
    • New and updated documents
    • Only new documents
    • Only updated documents
  8. For Results per page, select the number you want. For example, the default selection is 10 and displays only ten articles in your RSS feed.
  9. Select Create RSS feed for your selection.

    Note: If you right-click the Create RSS feed for your selection link to copy the URL, the RSS feed is not created correctly. You must select the link and go to the resulting page before copying the URL.

  10. For the resulting page, in your browser's address bar, select the entire URL, then copy and paste it into your preferred RSS feed reader.
