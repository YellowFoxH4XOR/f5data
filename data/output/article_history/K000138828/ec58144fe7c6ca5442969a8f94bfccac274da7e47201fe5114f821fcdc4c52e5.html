Description

When the System Controller is failed over, there is a loss of tenant mgmt IP/partition mgmt IP of about 2 minutes

Environment

F5OS-C Velos

Cause

This issue is caused by Bug ID 1018557 – System Controller Rolling Upgrade/failover: Tenant mgmt ip ping loss is about 2 min

Workaround

On versions where this is not fixed, you can add the following iCall config to the BIG-IP Tenant

sys icall handler periodic do_check_ping {
    interval 5
    script check_ping
}
sys icall script check_ping {
    app-service none
    definition {
        exec /usr/bin/ping -c 2 10.10.10.1
    }
    description none
    events none
}

Where 10.10.10.1 is the default gateway of the Tenant's management network.


This will ping 10.10.10.1 twice every 5 seconds, which ensures the ARP tables have the correct MAC Address for the Tenant.

If you have multiple Tenants, then this script would need to be added to each Tenant.
