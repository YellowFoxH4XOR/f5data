K000161929: [AS3] "01020036:3: The requested policy (<policy>) was not found."

Description

AS3 deployments via BIG-IQ failed with the error "01020036:3: The requested policy (<policy>) was not found" when attempting to create and reference a new Endpoint_Policy in a single deployment. The error only occurred if the policy did not already exist on the BIG-IP; if the policy was pre-created, deployment succeeded.

 

Environment

BIG-IP LTM, version 17.1.3 (later upgraded to 17.5.1.6)
BIG-IQ, version 8.4.1
AS3 schema versions 3.54.0 (BIG-IQ) and 3.56.0 (BIG-IP)
Deployment of Service_HTTP virtual server with Endpoint_Policy using AS3 via BIG-IQ

 

Cause

A software bug (Bug ID 2297441) in AS3 prevented the creation and referencing of a new Endpoint_Policy within the same deployment cycle, resulting in a "policy not found" error if the policy was not already present on the BIG-IP.

Recommended Actions

Upgrade to AS3 3.58.0-11
