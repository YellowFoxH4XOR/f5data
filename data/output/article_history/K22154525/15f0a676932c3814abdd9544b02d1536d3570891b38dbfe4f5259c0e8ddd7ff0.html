Description
In some cases the following log entries may coincide with the status of the guest in the vCMP host GUI failing to resolve. This most often happens after an upgrade of the host and guests. 
Example:
err hostagentd[<pid>]: 01820004:3: Couldn't convert json to expected datastructure (http://127.3.0.1:23035/mgmt/vmchannel/host-hotfixes
warning vcmpd[<pid>]: 01510005:4: Failed to update guest stats from JSON file.

Environment

  • BIG-IP
  • vCMP provisioned
  • vCMP guest/host upgrade

Cause
Bug ID 713183: Malformed JSON files may be present on vCMP host

Recommended Actions

1) On the host: bigstart restart hostagentd

(no impact to traffic)

2) The other possible way to correct this is to force a reload of the guest:  K13030: Forcing the mcpd process to reload the BIG-IP configuration

3) In some cases no issues are seen and the log messages may be filtered out of local logging by use of a sys syslog 'include' filter by filtering remote/external logging using the procedure in K13333: Filtering log messages sent to remote syslog servers.

Note: In some cases either step 1 or 2 will work alone. In other instances both will need to be done.

If the issue persists after attempting these steps please open a case with F5 Support.
