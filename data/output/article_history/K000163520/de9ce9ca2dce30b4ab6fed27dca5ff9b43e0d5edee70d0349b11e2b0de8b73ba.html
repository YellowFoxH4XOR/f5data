K000163520: LDAP authentication failed with the message "Failed to get primary GID".

Type
Support Solution
Published
2026-10-02
Updated
2026-10-02
Applies to
  • F5OS Products
  • F5OS: 2.0.0
Source
https://my.f5.com/manage/s/article/K000163520

Description

The user entry indicates membership in the F5OS admin group via memberOf, but the group object’s member attribute does not list the user. Because F5OS validates authorization by reading the group’s member attribute, this mismatch leads to the GID lookup failure.

You may see confd-auth log messages similar to the following:

2026-09-01T12:09:36.585240+02:00 host.f5.lab confd-auth[304233]: pam_ldap(password-auth:auth): F5 MODIFICATION - Validating user GIDs (user=f5osadmin)
2026-09-01T12:09:36.585245+02:00 host.f5.lab confd-auth[304233]: pam_ldap(password-auth:auth): F5 MODIFICATION - Requesting primary GID (user=f5osadmin)
2026-09-01T12:09:36.744261+02:00 host.f5.lab confd-auth[304233]: pam_ldap(password-auth:auth): F5 MODIFICATION - Failed to get primary GID, rejecting auth (user=f5osadmin)

 

Quick verification (use names from your environment instead of the sample F5OS_admins and f5osadmin)

User entry (confirm memberOf includes your admin group, for example F5OS_admins):
ldapsearch -x -LLL -H ldaps://ldaps.f5.lab -D "cn=adbind,cn=Users,dc=f5,dc=lab" -W -b "CN=f5osadmin,CN=Users,DC=f5,DC=lab"
Look for: memberOf includes CN=F5OS_admins,CN=Users,DC=f5,DC=lab


Group entry (check whether the member attribute include the user's DN):
ldapsearch -x -LLL -H ldaps://ldaps.f5.lab -D "cn=adbind,cn=Users,dc=f5,dc=lab" -W -b "CN=F5OS_admins,CN=Users,DC=f5,DC=lab"
Look for: member contains CN=f5osadmin,CN=Users,DC=f5,DC=lab

Environment

  • F5OS 2.0
  • LDAP

Cause

The LDAP user and group attributes are inconsistent: the user entry shows memberOf for the F5OS admin group, but the group’s member attribute does not include the user’s DN. Since F5OS checks the group’s membership attribute, it cannot resolve the user’s role/primary GID, resulting in authentication failure.

 

Answer/Recommended Actions

Add the user’s DN (for example, CN=f5osadmin,CN=Users,DC=f5,DC=lab) to the member attribute of the F5OS admin group (for example, CN=F5OS_admins,CN=Users,DC=f5,DC=lab).
