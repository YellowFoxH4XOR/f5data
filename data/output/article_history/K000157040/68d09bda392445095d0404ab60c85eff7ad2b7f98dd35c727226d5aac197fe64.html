K000157040: Portal Access: PeopleSoft Application experiencing navigation/loading issues.

Type
Support Solution
Published
2025-10-16
Updated
2026-07-01
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000157040

Description

You are accessing an Oracle Peoplesoft application through BIG-IP APM Portal Access, but a section of the application may fail to load. You might encounter a continuously spinning cursor, and the expected document is not displayed. This issue typically arises when requests containing "PT_WORKER_MIN_" are made in the URL path, causing the page to remain stuck in a loading state.

Environment

  • Product: BIG-IP APM
  • Version: All Versions
  • Platform: F5 BigIP
  • Configuration:
    • Portal Access resource with rewrite profile
    • Oracle Peoplesoft backend application

Cause

Requests with "PT_WORKER_MIN_" in the URL path are not properly handled by BIG-IP APM Portal Access. The application expects a specific JavaScript handler for these requests, which is not provided by default via Portal Access. This results in incomplete page loading and persistent spinner behavior.

Recommended Actions

To resolve this issue, add the following iRule to the relevant BIG-IP virtual server handling the Portal Access resource:

when HTTP_REQUEST {
 if { [HTTP::has_responded] } { return }
 
 if { [HTTP::path] contains "PT_WORKER_MIN_" } {
  HTTP::respond 200 content {
   addEventListener('message', received);function received(e) {
   postMessage(e.data);}
  } Content-Type "application/javascript"
 }
}

This iRule inspects incoming HTTP requests for the "PT_WORKER_MIN_" pattern in the path and responds with a 200 OK status, including a JavaScript snippet that enables proper page loading.
