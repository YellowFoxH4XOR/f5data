Topic

This article applies to BIG-IP Next for Kubernetes. For information about other products, refer to the following article:

  • K914: Displaying the software version of your F5 product

You should consider using this procedure under the following condition:

  • You want to display the BIG-IP for Kubernetes software version.

Description

To determine the software version number for your BIG-IP Next for Kubernetes instance, you must list the container images running in the Kubernetes namespace for your deployment and compare those with the Software Images page on Cloud Docs.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have a valid user account in the Kubernetes environment running BIG-IP Next for Kubernetes.

Procedures

List running container images

You can view the container images in the namespace where you deployed BIG-IP Next for Kubernetes by specifying either jsonpath or json output formatting.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Kubernetes cluster.
  2. List the container images using the following command syntax:

    kubectl -n <namespace> get pod -o jsonpath="{.items[*].spec.containers[*].image}" | awk -F "/" -v RS=" " '{print $3}'

    Note: In the Kubernetes environment, the default namespace serves as the default location for resources if a specific namespace is not created and specified. If you used the default namespace, you can omit the -n <namespace> part of the above command.

    For example, to get the list of container images installed in the default namespace, enter the following command:

    kubectl get pod -o jsonpath="{.items[*].spec.containers[*].image}" | awk -F "/" -v RS=" " '{print $3}'

    The output should appear similar to the following:

    f5ingress:v0.500.3-0.13.59
    f5ing-tmm-pod-manager:v0.17.20-0.1.2
    f5-k8s-event-subscriber:v0.10.2-0.1.7
    f5-l4-controller:v0.4.2-0.2.11
    f5-l7-controller:v0.2.0-0.2.13
    f5-fluentbit:v0.8.11-0.0.12

    Note: The above output is truncated for brevity. Additionally, the output depends on your specific configuration.

    Alternatively, if you have the jq utility installed on your host system, you can use the following command:

    Note: For more information about the jq utility, refer to https://jqlang.org/.

    kubectl get pod -o json | jq -r '.items[].spec.containers[] | (.image / "/")[2]'

  3. Compare the output of the command in the previous step to the Software Images page on Cloud Docs to determine which version of BIG-IP for Kubernetes you have installed.
