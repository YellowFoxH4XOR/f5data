Security Advisory Description

The BIG-IP system uses Secure Vault, a secure SSL-encrypted storage system, to securely store sensitive data such as SSL key passphrases, users, and administrator and services passwords.

However, files transferred from an F5 device (including products listed in the Applies to of this article) may contain sensitive information such as authentication credentials (encrypted or in plaintext), passwords, private IP addresses, cryptographic certificates, and keys. Such files may include, but are not limited to, the following:

  • qkview files
  • UCS archive files
  • SCF files
  • Log files
  • Core files
  • Configuration files

F5 recommends taking necessary precautions when transferring such files across a network and protecting the files in their new location.

Impact

This information does not constitute a defect or security vulnerability.
