Topic

For an environment that uses connection mirroring configuration on the BIG-IP AFM system, the system silently disables the connection-mirroring function for network traffic matching the firewall rule configured in the Classification policy or Protocol Inspection profile or both.

Description

When you attempt to review the connection mirroring statistics on the traffic that matches to the described BIG-IP AFM policy, you may observe the missing connection that should be on the high availability (HA) peer or chassis slot.

Recommended Action

To restore connection mirroring for this situation, you can associate the affected BIG-IP AFM Classification policy or Protocol Inspection profile, or both, to a virtual server with connection mirroring enabled. However, doing this may result in the system using more compute resource to process the BIG-IP AFM policy on all connections that matches the virtual server configuration. The additional resources are consumed by the indiscriminate processing of the associated Classification policy or Protocol Inspection profile or both.
