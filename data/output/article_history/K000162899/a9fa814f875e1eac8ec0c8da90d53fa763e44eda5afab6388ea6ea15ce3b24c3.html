K000162899: Error "Provisioning failed with error 1 - 'Disk limit exceeded. 16188 MB are required to provision these modules, but only 15100 MB are available.' when upgrading F5OS tenant

Source

Description

During an upgrade of a F5OS tenant to v17.1.3.6, v17.5.1.8, v21.1.0.1 or above the configuration does not load and an error message like the one below is logged in /var/log/ltm:

... Provisioning failed with error 1 - 'Disk limit exceeded. 16188 MB are required to provision these modules, but only 15100 MB are available.'

Environment

  • F5OS tenant
  • tenant was deployed with minimum disk size and an earlier software version
  • tenant is being upgraded to later software version

Cause

The minimum required disk size is different for different software versions. When upgrading to a later software version the disk size allocated to a client should be larger than the minimum disk size required for that software version as per K45191957: Overview of the BIG-IP tenant image types.

Answer/Recommended Actions

  1. change the tenant to "Provisioned"
  2. change the disk size allocated to the tenant to a value larger than what is required (see K45191957), save the settings
  3. change the tenant to "Deployed"

Additional Information

K45191957: Overview of the BIG-IP tenant image types
