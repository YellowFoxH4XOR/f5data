K000161362: SSH Hardening: Disable CBC Ciphers, Weak Key Exchange, and Remove CBC Ciphers from Client SSL Profiles

Description 

Security scans identified that the BIG-IP system has SSH CBC-mode ciphers enabled and permits weak SSH key exchange (KEX) algorithms. Additionally, CBC ciphers are advertised by the virtual server through the associated Client SSL profile. These configurations may expose the system to cryptographic vulnerabilities and fail to meet current security best practices. 

Environment

  • BIG-IP
  • SSH
  • CBC
  • KEX

 Cause

The issue occurs because the BIG-IP system is configured with legacy SSH cryptographic settings, including CBC-mode ciphers and weak key exchange (KEX) algorithms. Additionally, CBC ciphers remain enabled in the associated Client SSL profile, causing the virtual server to advertise weak cipher suites during SSL/TLS negotiation.

These configurations may be identified by vulnerability scans as weak or insecure cryptographic settings and may not align with current security best practices.

Recommended Actions 

1. Harden SSH configuration by disabling CBC ciphers and weak KEX algorithms 

  • Edit the SSHD configuration

tmsh edit /sys sshd all-properties

  • Replace the include none line with the following hardened block

include "Ciphers aes128-ctr,aes192-ctr,aes256-ctr
MACs hmac-sha2-256,hmac-sha2-512
KexAlgorithms ecdh-sha2-nistp256,ecdh-sha2-nistp384,ecdh-sha2-nistp521" 

  • Save and persist the configuration

tmsh save /sys config

 

  • Validate changes

sshd -T | grep -i cipher

sshd -T | grep -i kex

 

2. Remove CBC ciphers from the Client SSL profile 

  • Identify the Client SSL profile attached to the affected virtual server

tmsh list ltm virtual <virtual_server_name> profiles

 

  • Update the cipher string on the Client SSL profile to remove CBC suites

tmsh modify ltm profile client-ssl <profile_name> ciphers "ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:AES128-GCM-SHA256:AES256-GCM-SHA384

 

  • Save and persist the configuration 

tmsh save /sys config

 

  • Re-run the scan to confirm full remediation of CBC ciphers on port 443.
