K25623803: Managing the DNS lookup servers on the BIG-IQ system

Topic

You should consider using this procedure under the following condition:

  • You want to manage the DNS lookup servers on your BIG-IQ system.

Description

The BIG-IQ system uses two sources of information to resolve host names: the /etc/hosts file and DNS lookup servers. The BIG-IQ system first refers to the local host file. If the host name is not found in the local host file, the BIG-IQ system uses the configured DNS lookup servers. The following procedures help you manage DNS lookup servers on the BIG-IQ system.

Note: You should not attempt to manually edit the /etc/resolv.conf file as such changes do not persist restarting or configuration reloads.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have a working DNS server with entries for your hosts.
  • Your BIG-IQ system has direct network access to this DNS server.
  • You have administrative access to the BIG-IQ user interface or the TMOS Shell (tmsh).

Procedures

  • Using the BIG-IQ user interface to manage DNS lookup servers
  • Using tmsh to remove the DNS lookup server

Using the BIG-IQ user interface to manage DNS lookup servers

To manage DNS lookup servers on the BIG-IQ system using the BIG-IQ user interface, perform the procedure appropriate for your BIG-IQ version:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

BIG-IQ 5.2.0 and later
BIG-IQ 5.0.0 - 5.1.0
BIG-IQ 4.4.0 - 4.6.0

BIG-IQ 5.2.0 and later

  1. Log in to the Configuration utility as the admin user.
  2. Under BIG-IQ, click the System tab.
  3. Click THIS DEVICE.
  4. Click DNS & NTP.
  5. In the upper-right corner, click Edit.
  6. Under DNS Lookup Servers, add/modify/remove the DNS server IP addresses.
  7. In the lower-right corner, click Save.

BIG-IQ 5.0.0 - 5.1.0

  1. Log in to the Configuration utility as the admin user.
  2. In the upper-left corner, select System Management from the BIG-IQ menu.
  3. Click Local Host Settings.
  4. Click DNS & NTP.
  5. In the upper-right corner, click Edit.
  6. Under DNS Lookup Servers, add/modify/remove the DNS server IP addresses.
  7. In the lower-right corner, click Save.

BIG-IQ 4.4.0 - 4.6.0

  1. Log in to the Configuration utility as the admin user.
  2. On the BIG-IQ Systems panel, click the gear icon next to the group name for which you want to define the DNS server, and click Properties.
  3. Click Services.
  4. Add/modify/remove one or more DNS server IP addresses to the DNS Lookup Servers list.
  5. Click Save.

Using tmsh to manage DNS lookup servers

To manage DNS lookup servers on the BIG-IQ system using tmsh, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To add one or more DNS name servers to your BIG-IQ system, use the following command syntax by replacing <IP addresses> with the desired DNS server(s) IP addresses separated by space:

    modify /sys dns name-servers add { <IP addresses> }

    For example, type the following command to add DNS server IP addresses 192.168.1.1 and 192.168.100.100 to your BIG-IQ system:

    modify /sys dns name-servers add { 192.168.1.1 192.168.100.100 }

  3. To remove one or more of the configured DNS lookup server(s) from your BIG-IQ system, use the following command syntax by replacing <IP addresses> with the desired DNS server(s) IP addresses separated by space:

    modify /sys dns name-servers delete { <IP addresses> }

    For example, type the following command to remove the DNS lookup servers 192.168.2.2 and 192.168.200.200 from your BIG-IQ system:

    modify /sys dns name-servers remove { 192.168.2.2 192.168.200.200 }

  4. Type the following command to save the changes:

    save /sys config

  5. Type the following command to exit tmsh:

    quit
