K000163539: Traffic Fails to Reach Firewall Through BIG-IP Despite Valid Route Configuration

Type
Support Solution
Published

Updated
2026-10-14
Applies to

  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000163539

Description

Traffic from a Source VM using a BIG-IP self IP as its gateway can reach the gateway but cannot reach a firewall destination through BIG-IP when no virtual server matches the destination address, despite reachable routes.

 

Environment

  • BIG-IP LTM Virtual Edition 17.5.1
  • An IPv6 source VM using a BIG-IP self IP as its gateway

Cause

BIG-IP does not process and forward the traffic based on routes alone. A virtual server must match the firewall destination address.

 

Recommended Actions

  • Configure and retain virtual server that matches and forwards traffic destined for the firewall.
  • Verify application behavior directly instead of using firewall reachability through BIG-IP as the application-health indicator.

Additional Information

When BIG-IP is deployed as the default gateway for a host, both a valid route and a matching virtual server are required for traffic forwarding. In scenarios where traffic must be routed to a firewall or another downstream device, an IPv6 Universal Forwarding virtual server can be used to ensure the traffic is properly processed and forwarded by the BIG-IP.
