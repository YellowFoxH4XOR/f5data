K000139350: The host memory usage is growing fast, urldb process occupy too much memory

Support Solution
Published

  • BIG-IP APM: 16.0.X, 16.1.0, 16.1.2, 16.1.1, 16.1.3, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 16.0.1, 16.0.0, 15.0.1, 15.0.0
Source

Description

The host memory usage is growing fast, for example:

When the memory is high, check check the memory usage for each process via top or ps command, the process urldb occupy high memory, for example:

# ps aux | grep urldb

root       18228   8096   0.2   0.1    2.6G   68.3M ?        S    Mar21   12:53:27.87 /usr/sbin/urldb -n 4 

It may cause Out Of Memory issue if memory keep growing.

Environment

  • BIG-IP SWG
  • URLDB

Cause

It is caused by ID 1024437

Recommended Actions

Refer to the ID 1024437, find the Affected version and Fixed Version, upgrade to the version which contain the fix.

Before upgrade, perform the workaround.

Additional Information

None.
