Topic

The rSeries system services perform a variety of functions, such as configuring and controlling switch chips, managing partitions and tenants, and performing high availability (HA) failover actions between system controllers.

Recommendations

To restart a service, perform the following procedure:

F5OS-A 1.8.0 and later

  1. Log in to the rSeries system CLI as the admin user.
  2. Enter into the configuration mode by entering the following command:

    config

  3. Restart the service using the following command syntax:

    Note: F5OS-A 1.8.0 and later does not allow certain services to be restarted. For a list of services that can be restarted, you can enter the tab key after typing the system diagnostics os-utils docker restart node platform service command.

    system diagnostics os-utils docker restart node platform service <service name>

    For example, you would enter the following command to restart the alert-service service:

    system diagnostics os-utils docker restart node platform service alert-service

    The command would prompt you for confirmation to proceed the service restart:

    Restarting container affects configuration and data path. Do you want to proceed? [yes/no]

    Enter yes to proceed. The command would return an output similar to the following example:

    result alert-service restarted successfully

F5OS-A 1.5.x and earlier

  1. Log in to the rSeries system CLI as the root user.
  2. Restart the service using the following command syntax:

    docker restart <service name>

    For example, you would enter the following command to restart the alert-service service:

    docker restart alert-service
