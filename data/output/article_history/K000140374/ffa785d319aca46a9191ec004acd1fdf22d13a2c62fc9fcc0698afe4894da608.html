Description

BIG-IP DNS no longer logs "Connection in progress to <iquery_peer IP address>" starting v14.1.0 when an iQuery connection to a peer goes down or up.

  • BIG-IP DNS will still logs messages at the time the peer connection is lost.
  • BIG-IP DNS sends SNMP traps at the time the iQuery peer connection is lost or established.
  • Alert messages logged for both cases where a peer iQuery connection goes down or up.

Environment

  • BIG-IP DNS Sync group
  • BIG-IP iQuery connections to BIGIP server onjects.
  • iQuery connection goes down or gets established.
  • BIG-IP DNS o longer logs "Connection in progress to <iquery_peer IP address>"

Cause

Change in behaviour. Logging of "011ae020:5: Connection in progress to <iquery_peer>" results in elavated logging of which on a busy device with other issues getting logged negatively impacts operation of gtmd causing problems like gtmd coring or slow in processing requests.

Recommended Actions

  1. Ensure to log messages when peer devices are reported down on a remote system which can analyse and report.
  2. Use an SNMP server to receive traps from the BIG-IP DNS devices.
