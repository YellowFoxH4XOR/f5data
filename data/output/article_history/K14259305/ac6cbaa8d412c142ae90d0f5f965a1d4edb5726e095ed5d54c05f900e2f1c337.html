Description

The DNS resolver is a resolver cache used by the BIG-IP system when the Bot Defense feature needs to perform DNS resolution.
 
When you configure the DNS resolver with Forward Zones, the DNS resolver sends DNS queries that match the forward zone to one server from the list of configured servers for resolution. When no forward zone is configured, the DNS resolver randomly picks a root hints server to resolve DNS queries. A default route is required to reach a root server.
 
In deployments with multiple route domains, Bot Defense will select first the DNS resolver configured on the same route domain associated with incoming traffic. If there is none, it will select the DNS resolver on default route domain.
 
This article describes how to configure a DNS resolver for use with the Bot Defense (Bot Protection) feature

Recommended Actions

DNS resolver configuration steps:

  1. Go to Network > DNS Resolvers  > DNS Resolver List.
  2. Click Create.
  3. Assign a name. For example:
    Resolv
  4. Select a Route Domain Name. This will specify the route domain for outbound traffic of the resolver.
  5. Configure other settings as necessary.
  6. Click Finished. When no forward zone is configured, the DNS resolver randomly picks a root hints server to resolve DNS queries. If this is sufficient for your use of Bot Defense, then you can stop at this step otherwise continue with the following optional steps to configure a forward zone.
  7. Back on the Network > DNS Resolvers > DNS Resolver List page click on the newly created DNS resolver you created.
  8. Click on Forward Zones.
  9. Click Add.
  10. Configure a forward zone by specifying the zone domain name in the Name setting. For example: 
    example.com
    Note: If you have a specific nameserver you want to use for the root zone, you can use "." for the name, otherwise as mentioned previously when no forward zone is configured the system uses the name servers from the root hints file.
  11. Configure the DNS server IP address for the nameserver that will resolve queries for the zone.
  12. Click Add.
  13. Click Finished.
