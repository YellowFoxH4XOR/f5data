Topic

F5 adheres to a strict reconditioning process in which all data from a returned system is removed.

During this reconditioning process, F5 erases all records and deletes all file systems by writing zeros to the hard drive and/or the compact flash device. F5 then writes a new software image to the hard drive and/or the compact flash device.

For more information about the customer data security procedures employed by F5, refer to the Returned Material Data Security Statement.

Note: Contact your F5 Support contract renewal person at services@f5.com for information about purchasing SKU: F5-SVC-RMA-OPT, a support option that allows you to remove hard drives or compact flashes from a failed system before you return the device as a Return Materials Authorization (RMA). This allows you to perform data destruction at levels that meet your specific requirements. For more information, refer to SO/RMA Hardware retention and the SO/RMA Disk Retention Option datasheet.
