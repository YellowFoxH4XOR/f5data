K48035407: No pool in the select dropdown when creating new GSLB wide IP in GUI

Type
Support Solution
Published
2021-07-15
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP DNS: 14.X.X, 14.1.0, 14.0.1, 14.0.0, 14.1.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2
Source
https://my.f5.com/manage/s/article/K48035407

Description

Creating a new wide IP with type A through GUI management, there is no pool shown in the drop-down list selection.
 

Environment

  • v14.1.x
  • Around 2-3 thousand gtm pools configured 


Cause

Known Issue: Bug alias 899253 [GUI] GTM wideip-pool-manage in GUI fails when tens of thousands of pools exist 
The boundary "a thousand of" or "a sufficiently high number of pools (~ 15,000) " noted in ID may vary.
 

Recommended Actions

  1. Use tmsh, for example: 

        tmsh create gtm wideip a www.example.com { pools add { www.example.com_pool } aliases add { www.gslb.example.com } load-balancing-decision-log-verbosity { pool-member-selection pool-member-traversal pool-selection pool-traversal } }

  1. Create wide IP without pool, then manage pool member later.
