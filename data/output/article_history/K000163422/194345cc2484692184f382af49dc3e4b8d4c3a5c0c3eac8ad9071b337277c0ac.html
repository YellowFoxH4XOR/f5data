Topic

This article provides an overview of the Version Select perpetual license offerings for BIG-IP Virtual Edition (VE).

Description

Version Select is the new perpetual licensing model for BIG-IP Virtual Edition (VE) SKUs, replacing the previous Version Plus model. This model provides a more predictable and flexible way to license your BIG-IP VE instances and is available for purchase starting with BIG-IP 22.0.

Depending on your business and technical requirements, BIG-IP VE licenses purchased through the Version Select model may comprise up to three components:

  • Base license (required): These licenses are aligned with a specific major BIG-IP software version (e.g. BIG-IP 22.x, or BIG-IP 23.x). Base licenses entitle you to run all minor and maintenance releases within that major version, while also providing compatibility with all earlier software versions. Major software version upgrades are not included. For example, the V22 Version Select base license will permit usage of BIG-IP 22.x and all prior software versions.
  • Upgrade add-on license (optional): The upgrade add-on license can be attached to a base license and permits one major software version upgrade from the base license. For example, applying an upgrade add-on license to a V22 base license will extend support to also include BIG-IP 23.x. Only one upgrade add-on license can be combined with each base license. To upgrade to a software version two versions above the limits of an existing base license, you will be required to purchase a new base license. For example, if you have a V22 base license - which supports BIG-IP 22.x and earlier - and wish to upgrade to BIG-IP 24.x, you will need to purchase a V24 base license.
  • Extended Support (optional): Any customer with a Version Select license that wishes to continue using a software version beyond its End of Technical Support (EoTS) milestone may purchase up to two years of additional software support for that software version. Because the standard lifecycle for minor (X.1) BIG-IP software versions is three years from release until its EoTS milestone, electing to purchase Extended Support will enable minor BIG-IP software versions to be used for up to five years.

Understanding the Version Select lifecycle

Each major BIG-IP software version has a corresponding set of Version Select base and upgrade SKUs. These SKUs are available for purchase for approximately one year before being replaced by the SKUs for the subsequent major software release and designated as End of Sale (EoS). For example, V22 SKUs become available ahead of the General Availability (GA) of BIG-IP 22.0 and are retired upon the introduction of V23 SKUs prior to the release of BIG-IP 23.0.

The expected support lifecycle and operational lifespan for Version Select license combinations are defined below:

  • Base license: The lifespan of a Version Select base license is approximately three and a half years. This timeline aligns with the period from the initial major release (X.0) through the End of Technical Support (EoTS) milestone of the subsequent minor release (X.1). For instance, the window from the GA of BIG-IP 22.0 to the EoTS of BIG-IP 22.1 is anticipated to be three and a half years. If optional Extended Support is purchased, the total supported lifespan extends up to approximately five and a half years.
  • Base license plus upgrade add-on: The lifespan of a Version Select base license combined with an upgrade add-on license is approximately four and a half years. This duration aligns with the timeframe from the initial major release (X.0) to the EoTS milestone of the minor release associated with the next major version (X+1.1). For example, this covers the period from the release of BIG-IP 22.0 through the EoTS milestone of BIG-IP 23.1. When paired with optional Extended Support, the total supported lifespan extends up to approximately six and a half years.

Note: These lifespans are projected estimates and may vary depending on the official release schedules and GA dates of future BIG-IP major (X.0) and minor (X.1) software releases.
