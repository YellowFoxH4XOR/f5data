Description

The F5OS Image (or initial-image) value differs from the tenant’s current software image after an upgrade. Attempting to change the Image (or initial-image) value after tenant creation returns: “Cannot change image after tenant creation.”

Environment

  • F5OS
  • rSeries F5OS tenant
  • Software image management

Cause

The Image (or initial-image) value is used only during tenant creation and remains unchanged afterward. The current Image Version reflects the tenant’s running software version and changes when the tenant is upgraded. The difference between these values is expected.

Recommended Actions

To upgrade a tenant, use an ISO image and perform the software upgrade from within the running tenant. Do not attempt to modify the F5OS Image (or initial-image) value after tenant creation.

For a redundant tenant pair:

  1. Verify that both devices are synchronized.
  2. If configuration sync is set to AUTO, change it to MANUAL.
  3. Back up the qkview and configuration (UCS) from both devices.
  4. Upload the base image to both devices.
  5. Force the standby device offline.
  6. Install the base image on the standby device.
  7. Apply the required EHF, if applicable.
  8. Reboot into the new software version and verify system status.
  9. Fail over and verify system status.
  10. Repeat the upgrade process on the other device.

The Image (or initial-image) value remains unchanged after tenant creation. This is expected behavior.
