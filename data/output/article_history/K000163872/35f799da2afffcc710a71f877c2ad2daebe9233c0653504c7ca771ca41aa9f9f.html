Description

If you are using BIG-IP Advanced WAF and BIG-IP ASM to protect your backend pool members, you can mitigate this vulnerability for your backend pool members by using the following attack signatures enabled in blocking mode:

  • CVE-2026-109618: PHP Remote Code Execution, ID 200103697 and ID 200204115
    • 200103697 - ASM/Adv WAF Attack Signature Sets: WebSphere signatures, Command Execution Signatures, OS Command Injection Signatures, Low Accuracy Signatures, All Signatures
    • 200204115 - ASM/Adv WAF Attack Signature Sets: WebSphere signatures, Server Side Code Injection Signatures, Low Accuracy Signatures, All Signatures
  • CVE-2026-109619: PHP Remote Code Execution, ID 200204113
    • 200204113 - ASM/Adv WAF Attack Signature Sets: WebSphere signatures, Server Side Code Injection Signatures, Low and Medium Accuracy Signatures, All Signatures

These attack signatures are part of the newly released attack signature update ASM-AttackSignatures_20261022_154742.im; you must perform a signature file update to ASM-AttackSignatures_20261022_154742.im or later for these signatures to be available on your system.

Environment

  • BIG-IP Advanced WAF and BIG-IP ASM system

Cause

Protecting Pool Members Against PHP Vulnerabilities (CVE-2026-109618 & CVE-2026-109619) Across F5 BIG-IP WAF Platforms

Answer/Recommended Actions

1)_ Update Signatures: Perform an ASM attack signature update on the BIG-IP system.  You must perform a signature file update to ASM-AttackSignatures_20261022_154742.im or later for these signatures to be available on your system.

 

2)_ Enable Signature Set: Enable the "OS Command Injection Signatures" set within your target security policy.  Note: 'CVE_PHP' is used as an example policy name in this guide; please select your target security policy.

Note: Selecting a Medium or Low signature set level does not include all signature IDs needed to fully mitigate these CVEs. 

 

3)_ Enforce Signatures: 

  • Navigate to: Security > Application Security > Policy List > [Policy Name] > Attack Signatures
  • Locate and enforce signature IDs: 200103697, 200204115, and 200204113.
  • Save changes: Click "Apply Policy".

 

4)_ Repeat Steps 2 through 4 for any additional security policies that require protection against these vulnerabilities.
