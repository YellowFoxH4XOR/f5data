K000164215: Pool Statistics Show "General database error retrieving information" and GUI Becomes Intermittently Inaccessible After Upgrade to BIG-IP 17.5.1.11

Type
Support Solution
Published
2026-11-12
Updated
2026-11-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000164215

Description

  • After upgrading a BIG-IP LTM system to 17.5.1.11, the Statistics pages for Virtual Servers and Pool Members display "General database error retrieving information." The Configuration Utility (GUI) also becomes intermittently inaccessible. Restarting the httpd service temporarily restores access.

  • The Tomcat log reports 

    java.sql.SQLException: out of memory
    java.lang.OutOfMemoryError

Environment

  • BIG-IP LTM
  • Version 17.5.1.11
  • Large configuration - 5000 objects

Cause

The Tomcat JVM heap is too small for the pool statistics page to query the in-memory HSQLDB database at this configuration scale. With provision.tomcat.extramb set to 0, Tomcat runs out of heap memory. The resulting SQL exception is displayed in the GUI as "General database error retrieving information." Repeated OutOfMemoryError events leave Tomcat unresponsive, which causes the intermittent GUI failures.

Resolution

Increase the Tomcat extra memory allocation. Perform these steps on the Active device, then repeat them on the Standby device.
 

  1. Log in to the BIG-IP command line.
  2. Set the Tomcat extra memory value:
    tmsh modify sys db provision.tomcat.extramb value 50
  3. Restart Tomcat:
    bigstart restart tomcat
  4. Monitor the Tomcat log for recurring OutOfMemoryError entries:
    tailf /var/log/tomcat/catalina.out | grep "OutOfMemoryError"
  5. If the errors continue, increase provision.tomcat.extramb in 50 MB increments, up to a maximum of 256, and repeat steps 3 and 4 after each change until the errors stop.

    Check available memory with cat /proc/meminfo before increasing the value. If the value must exceed 1 GB, contact F5 Support.

  6. Save the configuration:

    tmsh save sys config

  7. Repeat steps 2 through 6 on the Standby device.
