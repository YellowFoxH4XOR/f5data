K000137756: Sending Config Report fails due to corrupted JSON Web Token (JWT)

Type
Support Solution
Published
2023-12-11
Updated
2025-02-07
Applies to
  • BIG-IP Next
  • BIG-IP Next SPK
  • BIG-IP Next CNF
Source
https://my.f5.com/manage/s/article/K000137756

Description

In licensing of the BIG-IP Next CNF or SPK , where sending Config Report, may receive error 

curl -X POST https://product.apis.f5.com/ee/v1/entitlements/telemetry \
-H "Content-Type: application/json" \
-H "F5-DigitalAssetId: b9270cae-5980-4c0e-bb44-f1948ff4b235" \
-H "User-Agent: SPK" \
-H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJwYXlsb2FkIjp7ImRv \
-d '{"report": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJwYXlsb2FkIjp7ImRv"}'

{"errors":[{"id":"7e0-8ced-11ee-9e78-99710bb9669c","code":"bad-request","code2":"","message":"Invalid JWS"}]}

 

Environment

  • BIG-IP Next CNF 
  • BIG-IP Next SPK 

Cause

The received error "Invalid JWS"  indicates corrupted JSON Web Token (JWT) validation

Recommended Actions

  1. Double check JWT, which is populated in curl for Sending Config Report,
  2. Double check DigitalAssetID, which is populated in curl for Sending Config Report,
  3. If sending Config Report still fails, please contact F5 to check JWT or request new one. 

Additional Information

None.
