Environment

  • BIG-IP
  • Generating Qkview

Cause

Possibly RPM database is corrupted

 

 Recommended Actions

1) Take a UCS backup and note down "F5mku -K" output

2) Take RPM backup using:

tar -czf /shared/tmp/${HOSTNAME}-rpm-db.tar.gz --absolute-names /shared/lib/rpm/ /var/config/rest/rpm/

3) Kill the running rpm or processes:

# ps aux | grep -E '[P]ID|[r]pm'

# kill -9 <pid>

3) Executed the below commands to rebuild the rpm db:

# rm -f -v /shared/lib/rpm/* /var/config/rest/rpm/*

# /opt/bin/rpm --dbpath /shared/lib/rpm --rebuilddb

# /opt/bin/rpm --dbpath /var/config/rest/rpm --rebuilddb

4) Verify below command is now running :

/opt/bin/rpm -v -qa --dbpath /var/config/rest/rpm

Qkview generation should now work.
