Description

Subscription add-on keys information is not available when more than one subscription key of the same type (e.g. SWG, IPI) has been applied on the device.


Environment

  • Time-limited module
  • Subscription
  • Add-on key
  • SWG
  • IPI

Cause

When multiple SBS subscription keys are activated on a single device, only one of the add-on keys is displayed in the license file, with a summed duration.
When additional subscription keys are added to a device, it will only show the latest key that is applied but the validity extends to reflect the additional time. 

For Example: 
If more than one subscriptions added at the same time, the system randomly picks one of them to display. The others will remain attached, however, they will not be visible other than the duration of the subscription.
For instance, add-on key AAAAAAA was added on 08-08-2018. BBBBBBB and CCCCCCC were added on 09-10-2019.
After adding the 2 subscription keys, only BBBBBBB is shown with an extended validity. AAAAAAA and CCCCCCC are not displayed. 


Recommended Actions

It is normal to see only one add-on key of the same type. No further action is required.
If add-on key(s)is/are activated on a wrong device, please refer to K21246452: Add-on license key activated on incorrect device.
