Description

You suspect you might be running into Bug ID 978833: Use of CRL-based Certificate Monitoring Causes Memory Leak.

You are using Dynamic CRL validator (for client side certificates) and would like to know if changing to a Static CRL file configuration, would be affected by the Bug ID as well.

Environment

  • Using Dynamic and Static CRL validators on Client SSL profile
  • Affected by Bug ID 978833

Cause

None

Recommended Actions

You can change to use Static CRL validator files, as these are not affected by ID978833.

Additional Information

A dynamic CRL validator configuration, allows to verify the revocation status of the SSL certificate from the client side. The CRL validator object for a client SSL profile will automatically fetch, check, cache, update, and manage the CRL files, based on the CRL URLs on the SSL certificates whenever a certificate is received. With a static file configuration, you need to download, manage, and change the CRL static files yourself.
