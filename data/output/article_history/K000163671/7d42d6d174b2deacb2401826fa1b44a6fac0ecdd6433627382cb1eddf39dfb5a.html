K000163671: list net vlan in vCMP guest do not show interface information

Type
Support Solution
Published
2026-10-12
Updated
2026-10-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000163671

Description

The tmsh list net vlan command on the BIG-IP vCMP guest did not display the physical interface associated with the VLAN.


[root@test:/S1-green-P::Active:Standalone] config # tmsh list net vlan

net vlan external {

  if-index 96

  tag 4093

}


 

Environment

vCMP Systems

vCMP Guest

vCMP Host

VLANs


 

Cause

The physical interface mapping is maintained at the vCMP host level. A vCMP guest sees virtualized networking objects and interface indexes, so tmsh list net vlan run within the guest does not display the underlying physical host interface.


 

Answer/Recommended Actions

1) To identify the physical interface associated with a VLAN, access the vCMP host rather than the vCMP guest.

[root@VIP2400-R9-S10:/S3-green-P::TimeLimitedModules::Active:Standalone] config # tmsh list net vlan

net vlan external {

  fwd-mode l3

  if-index 736

  interfaces {

    1/1.2 {

      tag-mode service

      tagged

    }

  }

  sflow {

    poll-interval-global no

    sampling-rate-global no

  }

  tag 4093

}


or


[root@VIP2400-R9-S10:/S3-green-P::TimeLimitedModules::Active:Standalone] config # tmsh list net trunk

net trunk trunk1 {

  cfg-mbr-count 2

  id 0

  interfaces {

    1/1.3

    1/1.4

  }

  mac-address 00:23:e9:41:48:20

  media 10000

}



2) From the vCMP host, use the relevant tmsh list net vlan output to review the VLAN’s mapped physical interface or trunk.

Use tmsh list net interface and tmsh list net trunk on the host when further interface or trunk details are required.


3) Continue using the guest-level VLAN and interface output for guest-side configuration and interface-index information.
