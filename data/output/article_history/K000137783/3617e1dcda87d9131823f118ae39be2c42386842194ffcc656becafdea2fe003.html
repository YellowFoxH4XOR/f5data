Description

This article describes 4 methods to configure BIND on BIG-IP: Configuration Utility, Zone Runner Shell, SOAP API, and REST API.

Environment

  • BIG-IP DNS

  • Bind is used

Cause

None

Recommended Action

1. Configuration Utility

Login to the GUI of the BIG-IP system as a privileged user.
Navigate to DNS --> Zones --> ZoneRunner.
It allows you to check and config BIND zone data here.
Please note: F5 recommends using Configuration Utility as the first choice to config BIND.

2. Zone Runner Shell

zrsh is a special shell called by ZoneRunner, type zrsh in based on BIG-IP. We will see the zrsh prompt: 
# zrsh
ZoneRunner%
Then we could type help to see the help information of zrsh commands. for example: 
Type help <category, command, or abbreviation> for help on a specific
category of commands or command.

Commands usually have an abbreviation, which is listed in parenthesis
after each command name below.
To run a script, type the less-than sign followed by the file name,
   for example:  <file
The following categories of commands are available:
Category 'builtin' commands:
    help [<command>] (?) : Display this message
    lookup (lkup, apropos) : Display all commands which match a string
                 The search looks at commands, abbreviations and descriptions,
                 and is case sensitive.
    <filename : Run the specified script
    exit (logout, ctrl-D) : Exit the shell

...
After that, we can check and modify the bind config using the commands above.

3. SOAP

zrsh can also be called via SOAP API. The API below will run a program via bash, so it can run the zrsh commands. 
https://<bigip address>/mgmt/tm/util/bash
We could invoke SOAP API as below: 
# curl -sku username:password "https://<bigip address>/mgmt/tm/util/bash" -X POST -H "Content-Type: application/json" -d "{\"command\":\"run\",\"utilCmdArgs\":\"-c 'echo <the zrsh command you want to run> | zrsh'\"}" | jq .
The BIG-IP DNS system will return a JSON format response.

For example:
Request: 
curl -sku root:default "https://127.0.0.1/mgmt/tm/util/bash" -X POST -H "Content-Type: application/json" -d "{\"command\":\"run\",\"utilCmdArgs\":\"-c 'echo dz t.t.t. | zrsh'\"}" | jq .
Response: 
{
  "kind": "tm:util:bash:runstate",
  "command": "run",
  "utilCmdArgs": "-c 'echo dz t.t.t. | zrsh'",
  "commandResult": "zone \"t.t.t.\" {\n    type master;\n    file \"db.external.t.t.t.\";\n    allow-update {\n        localhost;\n    };\n};\n\nt.t.t.                  360     IN      SOA     m.t.t.t. hostmaster.m.t.t.t. 2023120501 10800 3600 604800 86400\nt.t.t.                  125     IN      NS      ns.t.t.t.\nns.t.t.t.               125     IN      A       145.145.145.145\n\n"
}
This JSON format response contains the content stored in zone files.

4. REST

REST uses the same API as SOAP, however, with a different authentication way. It needs to get an access token first via a login API. 
https://<bigip address>/mgmt/shared/authn/login
Request: 
curl --location 'https://<bigip address>/mgmt/shared/authn/login' \
--header 'Content-Type: application/json' \
--data '{
    "username":"username",
    "password":"password",
    "loginProviderName":"tmos"
}'
The response is JSON formatted text content, and we can get the token from it. 
"token": "A****O",
Then we call the bash API with the token as the value of 'X-F5-Auth-Token' header. 
curl --location 'https://<bigip address>/mgmt/tm/util/bash' \
--header 'Content-Type: application/json' \
--header 'X-F5-Auth-Token: A****O' \
--data '{
    "command": "run",
    "utilCmdArgs": "-c ' <the zrsh command you want to run>'"
}'

BIG-IP will return the same content as the SOAP API, for example: 
{
    "kind": "tm:util:bash:runstate",
    "command": "run",
    "utilCmdArgs": "-c 'echo dz t.t.t. | zrsh'",
    "commandResult": "zone \"t.t.t.\" {\n    type master;\n    file \"db.external.t.t.t.\";\n    allow-update {\n        localhost;\n    };\n};\n\nt.t.t.                  360     IN      SOA     m.t.t.t. hostmaster.m.t.t.t. 2023120501 10800 3600 604800 86400\nt.t.t.                  125     IN      NS      ns.t.t.t.\nns.t.t.t.               125     IN      A       145.145.145.145\n\n"
}
