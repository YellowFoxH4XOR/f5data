Description

BIG-IP ASM/AWAF uses bot signatures to classify requests into different bot classes. However setting "None" as a mitigation action disables bot signature detection and classification for a specific bot class.

For example:

  • Trusted/Untrusted bot: all signatures of this class are disabled and are not checked.
  • Suspicious browser/Malicious bot: all signatures and anomalies of this class are disabled and not checked.
  • Unknown class: no action is performed.

Environment

  • BIG-IP ASM/AWAF
  • Bot Defense Profile
  • Bot Signature

Cause

None

Recommended Actions

Select other mitigation options, such as "Alarm". This enables bot signature detection. BIG-IP ASM/AWAF uses bot signatures to scan and match the request traffic and classifies it into the correct bot class.
