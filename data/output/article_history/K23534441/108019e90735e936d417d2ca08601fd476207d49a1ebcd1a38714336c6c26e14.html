Description

When the Exchange Servers are updated with a Microsoft CU update, load balancing does not work as expected.

  • Clients don't get the expected response from the Exchange Virtual Server

Environment

  • Virtual Server configured to Load Balance Exchange CAS Servers
  • Exchange Pool members have different Microsoft updates

Cause

The Exchange requests from a single client are being Load Balanced, so if one request goes to an updated CAS Server, but another request from the same client go to a CAS Server that has not been updated, then the client can get unexpected results, which cause the client to fail.

Recommended Actions

You should only have pool members available that are all on the same Exchange Update.

If you need to stage the update, then make 50% of your Exchange CAS Servers offline, and upgrade these first. Once they have been upgraded, make the Updated Pool Members available, and make the Pool Members that have not been upgraded, offline, and then upgraded these, and they can be made available as each one it updated.
