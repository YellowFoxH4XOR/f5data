K000163034: Azure VE may fail to process traffic after Accelerated Networking VF is rescinded by the platform

Type
Support Solution
Published
2026-08-22
Updated
2026-10-26
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000163034

Description

The Azure platform may rescind and re-present the SR-IOV VF during host maintenance, platform servicing, or other internal Azure events. When this occurs, the BIG-IP VE may encounter all the following symptoms:

  1. You may find similar messages to the following in /var/log/kern.log:
    warning kernel: ACPI: \: failed to evaluate _DSM (0x1001)
    notice kernel: mlx5_core <addr>: no netdev found for vf serial <N>
  2. TMM thread 0 (CPU core 0) consumes high (close to 100%) usage starting from the time of the messages (A) above.
  3. TMM fails to process traffic starting from the time of the messages (A) above. Pool members may be marked down. Configsync status may become "Disconnected".

Environment

  • BIG-IP VE 17.1.x, 17.5.x, 21.0.x, 21.1.x
  • Azure cloud environment
  • Accelerated networking enabled

Note: The Accelerated Networking setting in the Azure portal shows the state selected by the user. The portal allows you to select Disabled even when the VM size requires Accelerated Networking. For VM sizes that require it, Accelerated Networking is enabled at runtime regardless of the portal setting. Accelerated Networking is required for general-purpose VM sizes v5 and higher.

Cause

Bug ID 2355421

Recommended Actions

  1. Verify that the BIG-IP VE runs in Azure environment and has accelerated networking enabled.
    • Check the output of "lspci -[nn]vvv" in qkview (Commands > Unix > Configuration > lspci -[nn]vvv), or run the "lspci -vvv" command on the CLI.
    • If the output contains "Mellanox", the VE has accelerated networking enabled.
    • If the output does not contain "Mellanox", accelerated networking is not enabled on the VE, and this bug does not apply.

  2. Make sure other conditions in Environment match.
  3. Make sure symptoms in Description match.
  4. If all conditions and symptoms match, we can confirm the VE is affected by Bug ID 2355421. To resolve the issue, please open a case with F5 Support and reference this Support Solution to request an Engineering Hotfix.
