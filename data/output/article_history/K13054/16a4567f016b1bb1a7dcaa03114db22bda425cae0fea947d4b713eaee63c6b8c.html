This article documents region-specific procedures required to complete a Return Materials Authorization (RMA). You should perform these procedures only if you have been directed to this article as part of the hardware replacement process. For more information, refer to K12882: Overview of the F5 RMA process.

The following return instructions for suspected defective units apply to devices shipping only from Japan. If you need instructions for a different country, or to ensure that you are viewing the correct RMA instructions, refer to K12883: F5 RMA Return readme instructions, by country.

If you have questions or require assistance with this process, contact an F5 RMA Coordinator by calling F5 Support in your region.

返却手順：

  1. F5への返却用に、オリジナルの箱もしくは代替機の箱を保管しておいてください。不十分な梱包による破損は、交換部品の定価に相当する金額を請求させて頂く事になりますので、厳重に梱包して頂けますようお願いいたします。
  2. 部材はオリジナルの静電気バッグに慎重に入れて梱包してください。部材が複数発送された場合、発送時と同様にそれぞれの箱に梱包してください。一つの箱に複数の部材を入れないでください。部材が返却された時に、F5の管理者により、サービス品質保持のため梱包方法を確認しておりますのでご協力をお願いいたします。
  3.  外箱にRMAステッカーを貼り、以下の内容を明記してください。
    • RMAワークオーダー番号 
    • シリアル番号 F5が提供した箱に入っているRMAステッカー（8x13cm）に明記してください。RMAステッカーは可能な限り外箱に貼り付けてください。RMA番号が明記されていない場合、返却することができませんのでご注意ください。
  4. 故障部品の回収日程を調整するため、F5回収指定業者に連絡し、以下の情報をお知らせください。 
    •  RMAワークオーダー番号
    • シリアル番号 
    • お客様の会社名、お名前、コンタクト先電話番号 
    •  回収先住所 
    • 個数 
    • 回収希望日（翌営業日対応。時間指定・土日祝日の回収は承れません。15時以降のご依頼は最速で翌々営業日以降の回収になります。）

Return instructions

Upon receiving your advanced exchange replacements, return the suspected defective hardware within 10 business days by performing the following procedure:

  1. Retain all packaging materials to reuse as return packaging.
  2. Carefully place the parts in the original electrostatic bag and packaging, making sure to package each part separately as they were shipped to you. Do not consolidate parts into fewer boxes. Each individual unit or part of an RMA will be monitored by the F5 returns management group. Any damages sustained during shipping as a result of insufficient packaging will be invoiced at full list price.
  3. Clearly write the following information on the outside of the shipping container:
    • RMA work order number
    • Serial number

    Write the RMA work order number on the F5-provided 3x5-inch RMA sticker and affix it to the outside of the shipping container (if possible). Shipments that do not have an F5-authorized RMA work order number will be refused at time of delivery.

  4. To schedule a pickup of the suspected defective hardware, contact the F5 return agent and provide the following information:
    • RMA service order number
    • Serial number
    • Contact name and phone number
    • Pickup address
    • Quantity of pickup parts
    • Pickup date (Pickup in Next Business Days only; pickup time cannot be specified. Pickup will be any time during business hours upon the pickup request received by 15:00 JST in the prior business day.)
    • Data center ticket number (if required)

      Note: F5 cannot pick up defective parts without the ticket number in some data centers.

  5. Do not include cables, removable faceplates, XFP/SFPs, GBICs, FIPS card readers, or resource CDs when returning the suspect unit.
  6. Send an email to gslr@f5.com, quoting the RMA work order number and pickup completion time in order for the RMA Coordinator to update case notes and monitor the return shipment.
