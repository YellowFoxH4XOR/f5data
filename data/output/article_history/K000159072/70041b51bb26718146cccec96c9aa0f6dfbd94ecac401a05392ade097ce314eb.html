K000159072: IPv6 Proxy.Host Configurations Prevents Concurrent ASM Live Update and IP Intelligence Updates

Type
Support Solution
Published
2026-01-13
Updated
2026-01-13
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.5.1, 17.1.3, 21.0.0, 21.X.X, 21.0.X
Source
https://my.f5.com/manage/s/article/K000159072

Description

When configuring BIG-IP with an IPv6 proxy server address in the sys db proxy.host value, ASM Live Update and IP Intelligence (IPI) database updates cannot function simultaneously due to conflicting IPv6 address format requirements.

Symptoms:

  • When proxy.host is configured with IPv6 address in square brackets [<IPv6>]:
    • ASM Live Update successfully downloads signatures
    • IPI database updates fail with errors in /var/log/iprep/iprepd.log:

      iprepd|WARNING|Failed to auto-detect Internet Protocol for TCP connections

      iprepd|ERR|Cannot determine Internet Protocol for host api.bcti.brightcloud.com

      iprepd|ERR|SSL error: Broken pipe

      iprepd|ERR|Cannot send to host api.bcti.brightcloud.com: Broken pipe

  • When proxy.host is configured with IPv6 address without brackets <IPv6>:
    • IPI database updates success
    • ASM Live Update fails with error in /var/log/liveupdate.log:

      Curl fail: exit = 5

      curl: (5) Could not resolve proxy

Environment

  • BIG-IP ASM
  • sys db proxy.host configured with IPv6 address
  • ASM Live Update feature enabled
  • IP Intelligence (IPI) feature licensed and enabled

Cause

ID2200405

The proxy.host database key has conflicting IPv6 address format requirements between BIG-IP subsystems. ASM Live Update requires IPv6 addresses enclosed in square brackets [<IPv6>] for proper proxy connection parsing, while the IP Intelligence daemon (iprepd) cannot process IPv6 addresses with brackets, resulting in protocol detection failures.

Recommended Actions

Workaround:

Use an IPv4 proxy address for the sys db proxy.host configuration to avoid the IPv6 bracket formatting conflict:

tmsh modify sys db proxy.host value "<IPv4_address>"

Long-term solution:

Open a support case with F5 Technical Support and check the feasibility of having an engineering hot-fix. 

Additional Information

Even if the iprep.protocol database variable is manually set to ipv6 instead of auto-detect, the issue persists when the IPv6 proxy address in proxy.host is specified using bracket notation. Because the brackets are not accepted by the IP Intelligence update mechanism, forcing IPv6 protocol selection alone is insufficient to restore update functionality.
