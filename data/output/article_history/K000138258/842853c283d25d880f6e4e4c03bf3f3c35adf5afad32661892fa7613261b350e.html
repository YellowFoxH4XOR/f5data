K000138258: Downloading BIGIP ISO files from my.f5.com using Command Line Interface

Description

Sometimes, you may need or prefer to download ISO files directly from the F5 website using a command line tool, such as wget or curl. This can be useful if you have limited bandwidth, want to automate the download process, or encounter issues with the web browser. In this article, we will show you how to download ISO files from my.f5.com using the command line interface (cli) on BIGIP CLI using the curl command.

Environment

  • Have access the software downloads on my.f5.com
  • Have command line access to the BIGIP system
  • Have enough disk space to store the downloaded ISO file

Cause

N/A

Recommended Actions

  1. Log in to your F5 account on my.f5.com and navigate to the software downloads page.
  2. Select the product, version, image type and location that you want to download.
  3. Select "Copy Download Link". The copied link will include authentication token that will be valid for a limited time.
  4. Open your terminal and navigate to the directory where you want to save the ISO file.
  5. Type the following command to download the ISO file using curl: curl --url "Copied HTTPS link" -o <filename>
    1. Note: If the terminal is unstable starting the curl command using nohup, curl will continue downloading even after the terminal disconnects. Example: nohup curl --url "Copied HTTPS link" -o <filename> -s & 
    2. Note: the copied url is enclosed in double quotes
  6. Verify that the downloaded ISO file is not corrupted by comparing its checksum with the one provided on the F5 website. You can use the following command to generate the checksum of the ISO file: sha384sum filename.iso where filename.iso is the name of the downloaded file. For example: sha384sum bigip-16.0.1.1-0.0.6.iso
  7. If the checksum matches, you have successfully downloaded the ISO file from my.f5.com using the command line interface. You can now use the ISO file to install or upgrade your F5 product.
  8. Use TMSH or TMUI to install the Image or Hotfix using normal install methods.
