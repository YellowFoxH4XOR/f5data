Topic

This article applies to BIG-IP Next Cloud-Native Network Functions (CNFs). For information about other products, refer to the following article:

  • K914: Displaying the software version of your F5 product

You should consider using this procedure under the following condition:

  • You want to display the CNFs software version.

Description

To determine the software version number for your CNFs instance, you must list the container images running in the CNFs namespace in your Robin Cloud-Native Platform (CNP) and compare those with the Software Releases page on Cloud Docs.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to a Robin CNP running BIG-IP Next CNFs.

Procedures

List running container images

You can view the container images in your Traffic Management Microkernel (TMM) Proxy pod by specifying either jsonpath or json output formatting.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Robin CNP.
  2. List the container images running in your TMM Proxy pod using the following command syntax:

    kubectl -n <TMM Proxy namespace> get pod -o jsonpath="{.items[*].spec.containers[*].image}" | awk -F "/" -v RS=" " '{print $3}'

    For example, for a TMM Proxy namespace named cnf, enter the following command:

    kubectl -n cnf get pod -o jsonpath="{.items[*].spec.containers[*].image}" | awk -F "/" -v RS=" " '{print $3}'

    The output should appear similar to the following:

    f5ingress:v6.0.32
    f5-l4p-engine:v1.3.48
    tmm-img:v2.0.9
    f5-debug-sidecar:v5.54.3

    Alternatively, if you have the jq utility installed on your Robin CNP, you can use the following command:

    Note: For more information about the jq utility, refer to https://jqlang.org/.

    kubectl -n cnf get pod -o json | jq -r '.items[].spec.containers[] | (.image / "/")[2]'

  3. Compare the output of the command in the previous step to the Software Releases page on Cloud Docs to determine which version of CNFs you have installed.
