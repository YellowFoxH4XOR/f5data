K000092826: BIG-IP sending logs to old IP address of remote logging

Support Solution
Published
2026-06-08

Applies to

  • BIG-IP ASM: 15.1.X, 15.1.10, 15.1.9, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0
Source
https://my.f5.com/manage/s/article/K000092826

Description

BIG-IP is sending logs to an old remote logging server.

Environment

  • BIG-IP with remote logging enabled
  • BIG-IQ or equivalent

Cause

A persistent TCP connection remains established to the old remote logging server on port 8514, as identified by the following command:

netstat -anop | grep "8514"

Example output:

tcp6   0   0   <source_ip>:<source_port>   <old_logging_server_ip>:8514   ESTABLISHED   <PID>/./bd keepalive (90.00/0/0)

Recommended Actions

  1. Run the following command to terminate the persistent TCP connection to the old logging server IP address: 
    tcpkill ip host <old_logging_server_ip>
    This removes the entry from netstat for that IP address.
