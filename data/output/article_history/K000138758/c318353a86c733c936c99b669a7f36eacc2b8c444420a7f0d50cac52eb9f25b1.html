K000138758: NGINX Plus Agent pod does not appear in NIM

Type
Support Solution
Published
2024-02-28
Updated
2024-02-28
Applies to
  • NGINX Products
  • NGINX Instance Manager: 2.14.0
Source
https://my.f5.com/manage/s/article/K000138758

Description

After implementing an NGINX Plus Agent pod into a container management system such as a Kubernetes or an OpenShift cluster the pod instance does not appear in NIM (Instance Manager -> Instances).

Environment

NIM

Agent pod in a container management system

Cause

OneAgent companion process is running on the pod image. For example:

Recommended Actions

Remove the OneAgent companion process from the pod image.

Additional Information

None
