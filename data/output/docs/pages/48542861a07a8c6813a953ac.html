SCTP::rto_max

Description

This command returns the maximum value of SCTP retranmission timeout. Can specify the value on clientside or serverside.

Syntax

SCTP::rto_max [clientside | serverside]

Examples

when CLIENT_ACCEPTED {
        log local0.info "SCTP retransmission timeout maximum value is [SCTP::rto_max]"
}
when SERVER_CONNECTED {
        log local0.info "SCTP retransmission timeout maximum value is [SCTP::rto_max]"
}
