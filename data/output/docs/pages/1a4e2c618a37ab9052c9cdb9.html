X509::pem2der
       Returns an X509 certificate in DER format.

SYNOPSIS
       X509::pem2der 

DESCRIPTION
       Returns the specified X509 certificate, in its entirety, in DER format.

       Syntax

       X509::pem2der 

	    * Returns the specified PEM certificate, in its entirety, in DER
	      format.

RETURN VALUE
       Returns an X509 certificate in DER format.

VALID DURING
       ANY_EVENT

EXAMPLES
	when HTTP_REQUEST {
	    if { [SSL::cert count] > 0 } {
		SSL::c3d cert [X509::pem2der [X509::whole [SSL::cert 0]]]
	    }
	}
	when ACCESS_PER_REQUEST_AGENT_EVENT {
	    if { [SSL::cert count] > 0 } {
		SSL::c3d cert [X509::pem2der [X509::whole [SSL::cert 0]]]
	    }
	}
