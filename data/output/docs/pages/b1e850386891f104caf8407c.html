DIAMETER::retransmit

Description

This iRule command triggers the request in the retransmission queue that is associated with the current answer message for retransmission. This command will fail the current message is a request or if there is not an associated request message in the retransmission queue.

Syntax

DIAMETER::retransmit [disabled | busy | unable | retransmit] [NOTE]

Examples

when DIAMETER_EGRESS {
    if { [DIAMETER::is_response] && ![DIAMETER::is_retransmission] } {
        log local0. "reason [DIAMETER::retransmission_reason]"
        DIAMETER::retransmit
    }
}
