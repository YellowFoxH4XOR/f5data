PEM::policy

Description

This command allows you to check the name of a policy or check if the policy is being evaluated for the first time.
Note: the Policy Enforcement Manager license is required for functionality to work.

Syntax

PEM::policy initial
PEM::policy name

PEM::policy initial

  • returns true or false depending on whether the policy is being evaluated for the first time for the flow, or is being re-evaluated for the flow.

PEM::policy name

  • returns the name of the PEM policy.

Examples

when PEM_POLICY{
    if {[PEM::policy initial]} {
        /* Commands to run during the first time the policy is evaluated. */
    } else {
        /* Commands to run during policy re-evaluation. */
    }
        /* Commands to run during policy eval and re-eval time. */
}
