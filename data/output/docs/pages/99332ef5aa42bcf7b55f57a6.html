DNSMSG::record

Description

DNSMSG::record takes a resource record object, returned either by RESOLVER::summarize or DNSMSG::section, and a field name. It will return that field from the resource record.

Syntax

DNSMSG::record <rr_object> (owner|type|ttl|class|rdata)

Examples

when CLIENT_ACCEPTED {
        set result [RESOLVER::name_lookup "/Common/r1" www.abc.com a]
        set answer [DNSMSG::section $result answer]
        set first_rr [lindex $answer 1]
        set rdata [DNSMSG::record $first_rr rdata]
}
