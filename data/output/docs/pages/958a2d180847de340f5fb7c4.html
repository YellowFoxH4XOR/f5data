NAME
       dns-express-db - Loads the DNS Express data file.

MODULE
       ltm dns

SYNTAX
	load dns-express-db

DESCRIPTION
       The dns-express-db component within the ltm dns module is used to load the DNS Express data file /var/db/tmmdns.bin. The
       file is only loaded if it has been modified.

EXAMPLES
       load dns-express-db

       Loads the DNS Express file from disk into the running configuration.

       load, tmsh
