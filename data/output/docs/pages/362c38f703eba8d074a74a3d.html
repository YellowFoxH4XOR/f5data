NAME
       config-change-log - Configures firewall configuration change log setting.

MODULE
       security firewall

SYNTAX
       Modify the config-change-log component within the security firewall module using the syntax shown in the following
       sections.

   MODIFY
	modify config-change-log log-changes [automatic | on | off]

	modify config-change-log log-publisher [none | [name]]

   DISPLAY
	list config-change-log
	show running-config config-change-log

DESCRIPTION
       You can use the config-change-log component to configure if changes to the firewall rules should be logged or not. The
       default is to automatically determine if log is needed based on the mode of the on-demand-compilation. If the mode of the
       on-demand-compilation is 'enabled', the changes will be logged. If change log is enabled, a publisher need to be configured
       too.

EXAMPLES
	modify config-change-log log-changes on log-publisher local-db-publisher
