DOSL7::profile
       Returns the DOS profile from which the L7-DoS policy is extracted.

SYNOPSIS
       DOSL7::profile

DESCRIPTION
       This command returns the DOS profile from which the L7-DoS policy is extracted.	Note:
	 * in 11.4, default policy returns empty string and if L7-DoS is
	   disabled, the  string is returned.
	 * in 11.5+, default policy returns the one configured with the vip
	   and if L7-DoS is disabled, a null string is returned.

       Syntax

       DOSL7::profile

RETURN VALUE
VALID DURING
       HTTP_REQUEST
