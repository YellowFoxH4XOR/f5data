sys iapp-restricted-key(1)				BIG-IP TMSH Manual				sys iapp-restricted-key(1)

NAME
       iapp-restricted-key - Encryption/decryption master key used for the BIG-IP iAppLx restricted-store.

MODULE
       sys iapp-restricted-key

SYNTAX
       Manage the iapp-restricted-key component within the sys iapp-restricted-key module using the syntax in the following
       section.

   CREATE
	create sys iapp-restricted-key [name]
	   options:
	       restricted-key [string]

   LIST
	list sys iapp-restricted-key
	list sys iapp-restricted-key [name]
	   options:
	       restricted-key
	       partition

DESCRIPTION
       You can use the iapp-restricted-key component to create and list the encryption/decryption master key object  used by the
       iApplx restricted-store. Create operation can only be used by iControl-Rest calls.

EXAMPLES
       create sys iapp-restricted-key [name] restricted-key [string]

       Create a new iapp-restricted-key object with key.

       list sys iapp-restricted-key

       Display the entire iapp-restricted-key component.

OPTIONS
       restricted-key
	    Display the encryption master key used by the iApplx restricted-store.

       For information about the options that you can use with the command list, see help list.

       list, tmsh
