SOCKS::allowed
       This command allows you to change whether the SOCKS request is allowed or not.

SYNOPSIS
       SOCKS::allowed ('0' | '1')?

DESCRIPTION
       This command allows you to reject a SOCKS request during the SOCKS_REQUEST event.

       Details (Syntax): SOCKS::allowed '0' | '1'
	   Sets the state of SOCKS based on the Boolean value.

RETURN VALUE
VALID DURING
       SOCKS_REQUEST

EXAMPLES
	# Reject all SOCKS requests:
	when SOCKS_REQUEST {
	    SOCKS::allowed 0
	}
