AUTH_ERROR
       Triggered when an error occurs during authorization (deprecated in 9.4).

DESCRIPTION
       Note: Deprecated in 9.4. It will still work, but is being phased out. Use AUTH_RESULT instead in 9.4 and up.

       Triggered when an error occurs during authorization. A default handler for this event is associated with each of the
       authentication profiles and causes the system to close the connection. The associated authentication session ID is
       invalidated and, upon receipt of this event, the user should immediately discard the session ID.

Examples
	when AUTH_ERROR {
	    if {$tmm_auth_ssl_ocsp_sid eq [AUTH::last_event_session_id]} {
		SSL::handshake resume
	    }
	}
