APIRef_tm_net_dag-globals

mgmt/tm/net/dag-globals

/tm/net

Global disaggregation settings

REST Endpoints

Collection URI
/mgmt/tm/net/dag-globals
Collection Methods
OPTIONS, GET
Resource URI
/mgmt/tm/net/dag-globals/~resource id
Resource Methods
OPTIONS, GET, PUT, PATCH

Properties

Name Type Default Value Required Access Description
dagIpv6PrefixLen integer 128 optional read/write Specifies whether SPDAG or IPv6 prefix DAG should be used to disaggregate IPv6 traffic when vlan cmp hash is set to src-ip or dst-ip. The default value is 128, using SPDAG.
icmpHash string icmp optional read/write Specifies ICMP hash for ICMP echo request and ICMP echo reply in SW DAG. ICMP echo request and ICMP echo reply can be disaggregated based on ICMP id or ICMP id and IP addresses. The default ICMP hash is ICMP id.
roundRobinMode string global optional read/write Specifies whether the round robin disaggregator (DAG) on a blade can disaggregate packets to all the TMMs in the system or only to the TMMs local to the blade. The default value is global, meaning all TMMs in the system.
