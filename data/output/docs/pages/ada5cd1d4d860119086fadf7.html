SDP
       Namespace SDP

DESCRIPTION
       These commands allow you to get and set various different pieces of information in a Session Description Protocol (SDP)
       session.

       NOTE: The features contained in this namespace are available with a general license only in 9.4.2 and later. Earlier
       releases require an EA (Early Access) license to use these features. These commands will not function if your system does
       not have this license installed.
