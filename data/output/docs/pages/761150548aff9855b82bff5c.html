PROFILE::tcp
       Returns the value of a TCP profile setting.

SYNOPSIS
       PROFILE::tcp ATTR

DESCRIPTION
       Returns the current value of the specified setting in an assigned TCP profile.

RETURN VALUE
       Returns the current value of the specified setting in an assigned TCP profile.

VALID DURING
       ANY_EVENT
