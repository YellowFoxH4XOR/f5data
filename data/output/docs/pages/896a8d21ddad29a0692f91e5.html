DNSMSG::record
       Returns the specified field from a resource record object.

SYNOPSIS
       DNSMSG::record RESOURCE_RECORD ('owner' | 'type' | 'ttl' | 'class' | 'rdata')

DESCRIPTION
       This iRule gets the specified field from a resource record object.

       Syntax

       DNSMSG::record  [ owner | type | ttl | class | rdata ]

RETURN VALUE
       Returns the specified field from the resource record object.

VALID DURING
       ANY_EVENT

EXAMPLES
	when CLIENT_ACCEPTED {
		set result [RESOLVER::name_lookup "/Common/r1" www.abc.com a]
		set answer [DNSMSG::section $result answer]
		set first_rr [lindex $answer 1]
		set rdata [DNSMSG::record $first_rr rdata]
	}
