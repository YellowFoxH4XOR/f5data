L7CHECK_CLIENT_DATA

Description

This iRule event is triggered each time new ingress data is received from client.

Examples

when L7CHECK_CLIENT_DATA {
    # Set the L7 protocol using command L7CHECK::protocol set
    L7CHECK::protocol set "https"
}
