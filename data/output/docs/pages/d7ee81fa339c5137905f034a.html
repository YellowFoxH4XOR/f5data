DIAMETER_EGRESS
       Triggered when the system is ready to send a DIAMETER message.

DESCRIPTION
       An iRule event triggered when the system is ready to send a DIAMETER message. The context of this event shifts based on
       where the message originated.

       If the client sent the message, DIAMETER_EGRESS is a serverside event.  If the server sent the message, DIAMETER_EGRESS is
       a clientside event.

Examples
	when DIAMETER_EGRESS {
	   if {[serverside]} {
	      if { [DIAMETER::command] == "257" } {
		 log local0. "CER sent from [IP::local_addr] to [IP::remote_addr] with origin-host [DIAMETER::host origin]"
	      }
	   }
	}

HINTS
       Note: this event does not apply to CER/CEA messages until 11.3.0-HF3 (and above). If handling these messages is required in
       earlier versions then you\'ll need to perform a binary scan to modify AVPs.
