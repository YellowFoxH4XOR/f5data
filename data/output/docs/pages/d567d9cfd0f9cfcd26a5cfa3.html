FTP::disable

Description

This command disables FTP protocol handler for FTP message processing. This will disable detection of “AUTH TLS/SSL” for FTP.

Syntax

FTP::disable

Examples

when CLIENT_ACCEPTED {
    if { ([IP::addr [IP::client_addr] equals 10.0.0.0/8]) } {
        FTP::disable
    }
}
