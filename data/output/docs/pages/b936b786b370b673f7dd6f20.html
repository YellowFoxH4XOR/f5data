llookup
       Returns a list of values corresponding to the given key.

SYNOPSIS
       llookup MMAP KEY

DESCRIPTION
       This command returns a list of values corresponding to the given key.  In case there is no value for thekey or the [mmap]
       is not a properly structured multimap, the command will return null. Useful for data from ASM::violation details. This is a
       safer shortcut for this tcl code: This sets $ to the list of values corresponding to a given key $key in a multimap $m:

       set r { } foreach pair [lsearch -inline -all $m [concat $key *] {
	 lappend r [lindex $pair 1] }

       Syntax

       llookup  

RETURN VALUE
