WS::release
       Releases the data collected using WS::collect.

SYNOPSIS
       WS::release

DESCRIPTION
       WS::release
	   Releases the data collected via WS::collect. Unless a subsequent WS::collect command was issued, there is no need to
       use the WS::release command inside of the WS_CLIENT_DATA and WS_SERVER_DATA events, since (in these cases) the data is
       implicitly released.

RETURN VALUE
VALID DURING
       WS_CLIENT_DATA WS_SERVER_DATA

EXAMPLES
	when WS_CLIENT_FRAME {
	    WS::collect frame 1000
	    set clen 1000
	}

	when WS_CLIENT_DATA {
	    regsub -all "oursite" [WS::payload] "oursitedev" newdata
	    log local0. "Replacing payload with new data."
	    WS::payload replace 0 $clen $newdata
	    WS::release
	}
