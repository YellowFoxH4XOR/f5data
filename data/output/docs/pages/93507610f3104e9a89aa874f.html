APIRef_tm_sys_disk_logical-disk

mgmt/tm/sys/disk/logical-disk

/tm/sys/disk

Logical Disk Configuration

REST Endpoints

Collection URI
/mgmt/tm/sys/disk/logical-disk
Collection Methods
OPTIONS, GET
Resource URI
/mgmt/tm/sys/disk/logical-disk/~resource id
Resource Methods
OPTIONS, GET, PUT, PATCH
Resource Natural Key
name

Properties

Name Type Default Value Required Access Description
mode string none optional read/write The mode is how the disk is used - it can be dedicated to a specific application or set for multiple uses (mixed mode).
size integer   optional read/write Specifies the size (MiB) of the Logical Disk.
vgFree integer   optional read/write Specifies the usable free space (MiB) available in Logical Disk.
vgInUse integer   optional read/write Specifies the total logical disk space (MiB) in use.
vgReserved integer   optional read/write Specifies the reserved logical disk space (MiB). (Reserved space can only be used by certain system utilities for base OS growth - specifically it will not be included in the disk space available to resource provisioning)
