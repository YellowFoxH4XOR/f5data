DNS::last_act
       Sets the action to perform if no DNS service handles this packet.

SYNOPSIS
       DNS::last_act ('allow' | 'drop' | 'reject' | 'hint' | 'noerror')

DESCRIPTION
       This iRules command sets the action to perform if no DNS service handles this packet

       Note: This command requires the DNS Profile, which is only enabled as part of GTM or the DNS Services add-on.

       Syntax

       DNS::last_act 

	    * Sets the action to perform if no DNS service handles this packet
	      (aka Unhandled Query Action)

RETURN VALUE
VALID DURING
       DNS_REQUEST, DNS_RESPONSE, GLOBAL_GTM

EXAMPLES
	# Drop dns requests that are not handled by a local dns service
	when DNS_REQUEST {
	    DNS::last_act drop
	}
