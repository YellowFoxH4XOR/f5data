ANTIFRAUD::alert_score
       Returns or sets alert severity.

SYNOPSIS
       ANTIFRAUD::alert_score (VALUE)?

DESCRIPTION
       ANTIFRAUD::alert_score ;
	   Returns alert severity.

       ANTIFRAUD::alert_score VALUE ;
	   Sets alert severity.

RETURN VALUE
       ANTIFRAUD::alert_score ;
	   Returns alert severity.

       ANTIFRAUD::alert_score VALUE ;
	   No return value (sets alert severity).

VALID DURING
       ANTIFRAUD_ALERT

EXAMPLES
	when ANTIFRAUD_ALERT {
	    log local0. "original Alert score: [ANTIFRAUD::alert_score]."
	    ANTIFRAUD::alert_score new_value
	    log local0. "new Alert score: [ANTIFRAUD::alert_score]."
	}
