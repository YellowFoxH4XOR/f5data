NAME
       default-config - Loads the default configuration of the BIG-IP(r) system stored in the configuration files to the running
       configuration of the system.

MODULE
       sys

SYNTAX
       Configure the default-config component within the sys module using the following syntax.

   MODIFY
	load default-config

DESCRIPTION
       You can use the default-config component to load the default system configuration to the running configuration. This
       results in the user-defined configuration being removed from the running configuration.

EXAMPLES
       load default-config

       Loads the default configuration stored on the system to the running configuration of the system.

       load, tmsh
