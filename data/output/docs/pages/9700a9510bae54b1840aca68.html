RTSP::method

Description

Returns the method/command (for example, DESCRIBE, PLAY) from the current RTSP request.

Syntax

RTSP::method

RTSP::method

  • Returns the method/command (for example, DESCRIBE, PLAY) from the current RTSP request.

Examples

rule xxx {
    when RTSP_REQUEST {
        puts [RTSP::method]
    }
}
