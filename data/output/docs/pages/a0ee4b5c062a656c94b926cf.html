ltm rule event RADIUS AAA ACCT RESPONSE

iRule(1)						BIG-IP TMSH Manual						  iRule(1)

RADIUS_AAA_ACCT_RESPONSE
       This event is raised when an accounting response arrives.

DESCRIPTION
       This event is raised when an accounting response arrives.

Examples
	when HTTP_REQUEST_DATA {
	    set aaa_result [AAA::acct_result $request_id]
	    if { $acct_result == "INPROGRESS" } {
		after 200
		continue
	    }
	}
	when RADIUS_AAA_ACCT_RESPONSE {
	      log local0, "in RADIUS_AAA_ACCT_RESPONSE"
	}
