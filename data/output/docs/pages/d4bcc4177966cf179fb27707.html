NAME
       traffic - Displays traffic statistics for the Global Traffic Manager(tm).

MODULE
       gtm

SYNTAX
       Configure the traffic component within the gtm module using the syntax in the following section.

   DISPLAY
	show traffic
	  options:
	    (default | exa | gig | kil | meg | peta | raw | tera | yotta | zetta)
	    field-fmt

DESCRIPTION
       You can use the traffic	component to display traffic statistics, including those for IPv4 and IPv6 requests, current Local
       Domain Name System (LDNS) servers, and current paths.

SEE ALSO
       show, sys tmm-traffic, tmsh
