iRule(1)						BIG-IP TMSH Manual						  iRule(1)

CACHE
       Namespace CACHE

DESCRIPTION
       You can use the CACHE commands to make use of the RAM Cache feature of the BIG-IP system.

       Associated Events

	   CACHE_REQUEST - Triggered when the system receives a request for a cached object.
	   CACHE_RESPONSE - Triggered immediately prior to sending a cache response.
	   CACHE_UPDATE - Triggered when a cacheable response is about to be inserted into the cache.
