PSC::imsi
       Get or set the imsi value.

SYNOPSIS
       PSC::imsi (IMSI)?

DESCRIPTION
       The PSC::imsi command gets the imsi or sets the imsi when the optional is given.

       Syntax

       PSC::imsi

	    * Retrieve the imsi value.

       PSC::imsi 

	    * Set the imsi value.

RETURN VALUE
       Return the imsi value when no argument is given.
