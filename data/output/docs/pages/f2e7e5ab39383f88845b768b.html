LB_QUEUED
       Serverside event triggered when a connection limit it hit at the pool or pool member level.

DESCRIPTION
       LB_QUEUED is a serverside event triggered when a connection limit is hit at the pool or pool member level. HTTP redirection
       is permissible in this event, but HTTP::retry is not. If the queue limit is exceeded, LB_FAILED will be triggered.

Examples
	when LB_QUEUED {
	    log local0. "[IP::local_addr] was queued - [LB::queue depth one
		pool1] / [LB::queue limit depth pool1]"
	}

	which with a queue depth of 5 returns:
