HTTP_RESPONSE_CONTINUE

Description

An iRule event triggered whenever the system receives a 100 Continue response from the server.

Examples

when HTTP_RESPONSE_CONTINUE {
  if { [HTTP::version] != 1.1 } {
    log "Buggy server: sent 100-Continue to non-1.1 client!"
  }
}
