CLIENTSSL_HANDSHAKE

Description

Triggered when a client-side SSL handshake is completed. If LTM requests a certificate from the client this event would be triggered after the CLIENTSSL_CLIENTCERT event.

Examples

when CLIENTSSL_HANDSHAKE {
   persist ssl
}
