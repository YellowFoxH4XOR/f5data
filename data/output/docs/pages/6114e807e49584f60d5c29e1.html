APIRef_tm_sys_aom

mgmt/tm/sys/aom

/tm/sys

Always On Management subsystem. Not supported on all platforms.

REST Endpoints

Collection URI
/mgmt/tm/sys/aom
Collection Methods
OPTIONS, GET
Resource URI
/mgmt/tm/sys/aom/~resource id
Resource Methods
OPTIONS, GET, PUT, PATCH

Properties

Name Type Default Value Required Access Description
ipmi string   optional read/write Ipmi access to AOM over LAN.
mediaRedirection string   optional read/write Virtual media server, only allowed when webui is enabled. Not supported on all platforms.
readonly string   optional read/write Reduces the AOM menu to readonly, removing all control functions.
vkvm string   optional read/write Webui Virtual Keyboard, Video and Mouse redirection, only allowed when webui is enabled. Not supported on all platforms.
webui string   optional read/write AOM web services, not supported on all platforms.
