TCP::server_port
       Returns the remote TCP port/service number of the serverside TCP connection.

SYNOPSIS
       TCP::server_port

DESCRIPTION
       Returns the remote TCP port/service number of the serverside TCP connection. This command is equivalent to the
       TCP::remote_port command in a serverside context, and to the BIG-IP 4.x variable server_port.

       Syntax

       TCP::server_port

	    * Returns the remote TCP port/service number of the serverside TCP
	      connection.

RETURN VALUE
VALID DURING
       CLIENT_ACCEPTED, CLIENT_CLOSED, CLIENT_DATA, SERVER_CLOSED, SERVER_CONNECTED, SERVER_DATA, SIP_REQUEST, SIP_REQUEST_SEND,
       SIP_RESPONSE, STREAM_MATCHED, TCP_GTM

EXAMPLES
	when SERVER_CONNECTED {
	   # This logs information about:
	   #  * the clientside part of the client<->LTM connection, and
	   #  * the serverside part of the LTM<->server connection.
	log local0.info "Complete connection: [IP::client_addr]:[TCP::client_port]<->LTM<->[IP::server_addr]:[TCP::server_port]"
	}
