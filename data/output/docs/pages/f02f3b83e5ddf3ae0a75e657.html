NSH::service_index

Description

This command gets/sets the service index for NSH.

Syntax

NSH::service_index (DIRECTION NSH_SERVICE_IDX)?

Examples

  1. Set the service index for NSH.
    when LB_SELECTED {

NSH::service_index serverside_egress 20

set myservice_index [NSH::service_index]

}
