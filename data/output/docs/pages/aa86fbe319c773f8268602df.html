NSH::path_id
       Set/Get the Path ID for NSH.

SYNOPSIS
       NSH::path_id DIRECTION (NSH_PATH_ID)?

DESCRIPTION
       Set: Path ID for NSH.  Get(DIRECTION as the only parameter): path id from NSH.

RETURN VALUE
       None for set, value of path id for get.

VALID DURING
       All

EXAMPLES
	# Set the path ID for NSH.
	when CLIENT_ACCEPTED {
	    NSH::path_id serverside_egress 10
	    set mypath_id [NSH::path_id serverside_egress]
	}
