X509::not_valid_after
       Returns the not-valid-after date of an X509 certificate.

SYNOPSIS
       X509::not_valid_after CERTIFICATE

DESCRIPTION
       Returns the not-valid-after date of the specified X509 certificate.

       Syntax

       X509::not_valid_after 

	    * Returns the not-valid-after date of the specified X509 certificate.

RETURN VALUE
       Returns the not-valid-after date of an X509 certificate.

VALID DURING
       ANY_EVENT

EXAMPLES
	when SERVERSSL_HANDSHAKE {
	  set server_cert [SSL::cert 0]
	  log local0. "Server Certificate Valid Date -
	   [X509::not_valid_before $server_cert] -
	   [X509::not_valid_after $server_cert]"
	}
