SSL::nextproto
       SSL::nextproto

SYNOPSIS
DESCRIPTION
       Get or set the Next Protocol Negotiation (NPN) string.  SSL::nextproto add str
	 Adds str to the list of protocols advertised.	SSL::nextproto
	 Return the negotiated protocol.

RETURN VALUE
       SSL::nextproto add str
	 No return value.  SSL::nextproto
	 The negotiated protocol value.

VALID DURING
       SSL::nextproto add str
	 CLIENTSSL_CLIENTHELLO SSL::nextproto
	 CLIENTSSL_HANDSHAKE

EXAMPLES
	when CLIENTSSL_CLIENTHELLO {
	    SSL::nextproto add "spdy/1"
	    SSL::nextproto add "spdy/2"
	    SSL::nextproto add "http/2"
	}
	when CLIENTSSL_HANDSHAKE {
	    log local0.info "negotiated protocol: [SSL::nextproto]"
	}
