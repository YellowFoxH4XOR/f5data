ANTIFRAUD::alert_min
       Returns or sets variable data from client side, e.g. forbidden added HTML element for the external_sources alert or bait
       signatures for the trojan_bait alert.

SYNOPSIS
       ANTIFRAUD::alert_min (VALUE)?

DESCRIPTION
       ANTIFRAUD::alert_min ;
	   Returns variable data from client side, e.g. forbidden added HTML element for the external_sources alert or bait
       signatures for the trojan_bait alert.

       ANTIFRAUD::alert_min VALUE ;
	   Sets variable data from client side, e.g. forbidden added HTML element for the external_sources alert or bait
       signatures for the trojan_bait alert.

RETURN VALUE
       ANTIFRAUD::alert_min ;
	   Returns variable data from client side, e.g. forbidden added HTML element for the external_sources alert or bait
       signatures for the trojan_bait alert.

       ANTIFRAUD::alert_min VALUE ;
	   No return value (sets variable data from client side, e.g. forbidden added HTML element for the external_sources alert
       or bait signatures for the trojan_bait alert).

VALID DURING
       ANTIFRAUD_ALERT

EXAMPLES
	when ANTIFRAUD_ALERT {
	    if {[ANTIFRAUD::alert_type] eq "js_vhtml"} {
		if {[ANTIFRAUD::alert_component] eq "external_sources"} {
		    log local0. "Alert forbidden added element: [ANTIFRAUD::alert_min]"
		}
		elseif {[ANTIFRAUD::alert_component] eq "trojan_bait"} {
		    log local0. "Alert bait signatures: [ANTIFRAUD::alert_min]"
		}
	    }
	    ANTIFRAUD::alert_min new_value
	    log local0. "new Alert min: [ANTIFRAUD::alert_min]"
	}
