Properties

Name Type Default Value Required Access Description
allProtocolsPass string disabled optional read/write When enabled and PSID is 0, permits passthrough for all IP sub-protocols. If PSID != 0, value have to be disabled. If it is disabled only TCP/UDP/ICMP traffic can pass lw4o6 tunnel. The default value is disabled.
appService string   optional read/write The application service that the object belongs to.
defaultsFrom string   optional read/write The profile from which to inherit settings. The default value is lw4o6.
description string   optional read/write User defined description.
lwtblFile string   optional read/write The name of sys file lwtunneltbl represents lw4o6 configuration table.
tmPartition string Common optional read/write Displays the admin-partition within which this component resides.
psidLength integer 0 optional read/write Specifies Port Set ID (PSID) length of the LW4o6 profile and table. The default is 0.
