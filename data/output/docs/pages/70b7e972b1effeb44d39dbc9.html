AUTH_RESULT
       Replaces AUTH_SUCCESS. AUTH_FAILURE. AUTH_ERROR. and AUTH_WANTCREDENTIAL events.

DESCRIPTION
       This event replaces AUTH_SUCCESS, AUTH_FAILURE, AUTH_ERROR, and AUTH_WANTCREDENTIAL events. These four deprecated events
       will be removed from a future release. The specific result can be obtained using AUTH::status.

Examples
	when AUTH_RESULT {
	    if {[AUTH::status] != 0} {
		HTTP::respond 401
	    } else {
		HTTP::release
	    }
	}
