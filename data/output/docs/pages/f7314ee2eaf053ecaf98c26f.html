OPTIONS, GET
Resource URI

Resource Methods

Resource Natural Key
name, subPath

Properties

Name Type Default Value Required Access Description
appService string   optional read/write The application service that the object belongs to
dataType string none required read/write Specify the data-type of the IPFIX element.
description string   optional read/write User defined description
enterpriseId integer 0 required read/write Specify the IPFIX element enterprise id between 0 and 4294967295.
id integer 1 required read/write Specify the IPFIX element id between 1 and 65535. Values greater than 32767 will be considered NETFLOW-only IEs.
size integer 0 optional read/write Specify the size between 1 and 1900. Used only for octetarray and string data-type. Default is 0, which means variable.
