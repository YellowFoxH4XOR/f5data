PSC::subscriber_id
       Get or set the subscriber id.

SYNOPSIS
       PSC::subscriber_id ((SUBSCRIBER_ID) (e164	    |
						    imsi	    |
						    sip-uri	    |
						    nai 	    |
						    private	    |
						    mac-address     |
						    dhcp	    |
						    mac-dhcp	    |
						    dhcp-custom)?)?

DESCRIPTION
       The PSC::subscriber_id command gets the subscriber id or sets the subscriber_id when the optional value is given.

       Syntax

       PSC::subscriber_id

	   * Retrieve the subscriber id.

       PSC::subscriber_id 

	   * Set the subscriber id.

RETURN VALUE
       Return the subscriber id when no argument is given.
