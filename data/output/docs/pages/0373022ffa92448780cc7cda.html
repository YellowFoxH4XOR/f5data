WS_CLIENT_DATA
       This event is triggered when specified amount of data is collected via the WS::collect command on the client side.

DESCRIPTION
       When the system collects the specified amount of data via the WS::collect command, WS_CLIENT_DATA event is raised. Within
       the context of this event, the collected payload can then be accessed using the WS::payload command.

Examples
	when WS_CLIENT_DATA {
	    regsub -all "oursite" [WS::payload] "oursitedev" newdata
	    log local0. "Replacing payload with new data."
	    WS::payload replace 0 $clen $newdata
	    WS::release
	}
