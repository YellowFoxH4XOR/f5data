LB::context_id

Description

Assign the current connection to a named context.

Syntax

LB::context_id "id_string"

LB::context_id <id_string>

  • Assigns the current connection to a named context. The connections in the same context can be reused later.

Examples

when CLIENT_ACCEPTED {
    LB::context_id foo
}

Related Information

Valid Events:
CLIENT_ACCEPTED
