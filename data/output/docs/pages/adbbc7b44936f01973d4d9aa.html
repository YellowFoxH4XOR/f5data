HTTP::method

Description

Returns the type of HTTP request method. This command replaces the BIG-IP 4.X variable http_method.

Syntax

HTTP::method

HTTP::method

  • Returns the type of HTTP request method. Common HTTP methods are described in RFC2616 Section 5.1.1.

Examples

Log the HTTP request method:
when HTTP_REQUEST {
   log local0. "HTTP Method: [HTTP::method]"
}

Sample log output:
Rule: <HTTP_REQUEST>: HTTP Method: GET

Related Information

Valid Events:
HTTP_REQUEST, HTTP_REQUEST_DATA
