CACHE_UPDATE
       Fires when a new entry is inserted into the cache and when an object is refreshed in the cache by the server after
       expiring.

DESCRIPTION
       This event fires when a new entry is inserted into the cache and when an object is refreshed in the cache by the server
       after expiring.

Examples
	when CACHE_UPDATE {
	    # cached object's headers manipulation
	    # modifications will be seen whenever the object is served from cache
	    CACHE::header replace Server Big-IP-Server
	}
