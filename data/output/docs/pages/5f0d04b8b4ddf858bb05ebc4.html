iRule(1)						BIG-IP TMSH Manual						  iRule(1)

SIP_REQUEST_SEND
       Triggered immediately before a SIP request is sent.

DESCRIPTION
       Triggered immediately before a SIP request is sent.

Examples
	when SIP_REQUEST_SEND {
	    if {[SIP::method] == "BYE"} {
		persist delete sip [SIP::call_id]
	    }
	    else {
		persist add sip [SIP::call_id]
	    }
	}
