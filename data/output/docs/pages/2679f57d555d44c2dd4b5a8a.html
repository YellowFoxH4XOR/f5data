AVR::enable
       Enables the AVR plugin for the current connection.

SYNOPSIS
       AVR::enable

DESCRIPTION
       Enables the AVR plugin for the current connection. AVR will remain enabled on the current connection until it is closed or
       AVR::disable is called.

       Note that enabling AVR alone within the iRule only ensures the message reaches the AVR plugin, it doesn't ensure that
       statistics will be gathered.

       Syntax

       AVR::enable

RETURN VALUE
VALID DURING
       ANY_EVENT
