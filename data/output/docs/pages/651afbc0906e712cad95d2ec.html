ILX::notify
       Calls an ILX method asynchronously.

SYNOPSIS
       ILX::notify HANDLE METHOD (ARGS)*

DESCRIPTION
       Make a call to the plugin extension defined by the handle but do not wait for a response before continuing to process the
       remainder of the iRule. The delivery of the call to the plugin extension is "best effort" and is not guaranteed.

RETURN VALUE
       None

VALID DURING
       ANY_EVENT

EXAMPLES
	when CLIENT_ACCEPTED {
	    # Get a handle to the running extension instance to call into.
	    set RPC_HANDLE [ILX::init my_plugin my_extension]
	    # Make the asynchronous call
	    ILX::notify $RPC_HANDLE my_js_function arg1 arg2
	}
