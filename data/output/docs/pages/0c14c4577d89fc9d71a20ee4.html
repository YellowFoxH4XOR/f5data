use

Description

This is a BIG-IP 4.X statement, provided for backward-compatibility. The use statement must be paired with certain BIG-IP 9.X commands such as node, pool, rateclass, snat, and snatpool.
The use command is not required on BIG-IP 9.X systems.

Syntax

use <object> <object_name>

use <object> <object_name>

  • A BIG-IP 4.X statement, provided for backward-compatibility.

Examples

when HTTP_REQUEST {
  if { [HTTP::uri] contains "aol" } {
     use pool aol_pool
  } else {
     use pool all_pool
 }
}
