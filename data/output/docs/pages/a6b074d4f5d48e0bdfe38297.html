LSN::pool

Description

Explicitly set the LSN pool used for translation.

Syntax

LSN::pool <pool_name>

LSN::pool

  • Set or override the LSN translation pool used for this connection. The LSN translation pool contains the candidate addresses to which a client address may be translated.
  • This command has no effect if the translation type is deterministic.
