CACHE_REQUEST

Description

Triggered when the system receives a request for an object eligible to be cached. Used to override default behavior.

Examples

when CACHE_REQUEST {
  if { [CACHE::age] > 60 } {
    CACHE::expire
    log local0. "Expiring content: Age > 60 seconds"
   }
}
