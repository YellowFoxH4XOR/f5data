PSC::lease_time
       Get the session lease time.

SYNOPSIS
       PSC::lease_time IP_ADDR (LEASE_TIME)?

DESCRIPTION
       The PSC::lease_time command gets the lease time of the session.

       Syntax

       PSC::lease_time

	   * Retrieve the session lease time.

RETURN VALUE
       Return the session lease time.
