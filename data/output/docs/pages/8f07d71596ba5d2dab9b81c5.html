DNS::is_wideip
       Returns status (true/false) if a string is a configured wide IP.

SYNOPSIS
       DNS::is_wideip DNS_STRING

DESCRIPTION
       This iRules command returns status (true/false) if a string is a configured wide IP.

       Note: This command functions only in the context of LTM iRules and requires the DNS Profile, which is only enabled as part
       of GTM or the DNS Services add-on.

       Syntax

	   DNS::is_wideip 

RETURN VALUE
VALID DURING
       DNS_REQUEST, DNS_RESPONSE

EXAMPLES
	when DNS_REQUEST {
	  if { [DNS::is_wideip [DNS::question name]] } {
	    log local0. "[DNS::question name] is a wideIP"
	  } else {
	      log local0. "[DNS::question name] is not a wideIP"
	  }
	}
