DIAMETER::dynamic_route_lookup
       Set whether messages should be routed dynamically.

SYNOPSIS
       DIAMETER::dynamic_route_lookup ( connection | message ) ( BOOLEAN )?

DESCRIPTION
       "message": If status is set to "enabled", previously created dynamic routes will be consulted during the routing of this
       message.

       "connection": The setting will be applied to this and all later messages on this connection.

       The zero-argument form of this command returns whether the setting is enabled on the current message.

       Syntax DIAMETER::dynamic_route_lookup connection enabled DIAMETER::dynamic_route_lookup message disabled

RETURN VALUE
VALID DURING
       DIAMETER_INGRESS

EXAMPLES
	when DIAMETER_INGRESS {
	    if { ([DIAMETER::header appid] equals 666) } {
		DIAMETER::dynamic_route_lookup message disabled
	    }
	}
