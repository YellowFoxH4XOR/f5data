PEM_SUBS_SESS_DELETED

Description

This iRules event is triggered when a subscriber session has been deleted.

Examples

when PEM_SUBS_SESS_DELETED {
        PEM::sesssion info 0.0.0.0 imsi 1223456
        PEM::session info 0.0.0.0 imeisv 2534535
        PEM::session info 0.0.0.0 tower-id 8248249
        PEM::session info 0.0.0.0 user-name 2139449

        log local0.  "imsi: [PEM::session info 0.0.0.0 imsi]"
        log local0.  "imeisv: [PEM::session info 0.0.0.0 imeisv]"
        log local0.  "tower-id: [PEM::session info 0.0.0.0 tower-id]"
        log local0.  "user-name: [PEM::session info 0.0.0.0 user-name]"
    }
