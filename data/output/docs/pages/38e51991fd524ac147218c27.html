AVR::disable
       Disables the AVR plugin for the current connection.

SYNOPSIS
       AVR::disable

DESCRIPTION
       Disables the AVR plugin for the current connection. AVR will remain disabled on the current connection until it is closed
       or AVR::enable is called. This means that the connection will not be counted by AVR and thus excluded from statistics
       gathering.

       Syntax

       AVR::disable

RETURN VALUE
VALID DURING
       ANY_EVENT
