htons
       Converts the unsigned short integer from host byte order to network byte order.

SYNOPSIS
       htons NUMBER

DESCRIPTION
       Convert the unsigned short integer from host byte order to network byte order.

       Syntax

       htons 

	    * Convert the unsigned short integer from host byte order to network
	      byte order.

RETURN VALUE
VALID DURING
       GLOBAL_GTM

EXAMPLES
	when HTTP_REQUEST {
	  set hostshort 1234
	  set netshort [htons $hostshort]
	}
