ANTIFRAUD::alert_expected_value
       Returns or sets expected (verified) value, for example in strong integrity check.

SYNOPSIS
       ANTIFRAUD::alert_expected_value (VALUE)?

DESCRIPTION
       ANTIFRAUD::alert_expected_value ;
	   Returns expected (verified) value, for example in strong integrity check.

       ANTIFRAUD::alert_expected_value VALUE ;
	   Sets expected (verified) value, for example in strong integrity check.

RETURN VALUE
       ANTIFRAUD::alert_expected_value ;
	   Returns expected (verified) value, for example in strong integrity check.

       ANTIFRAUD::alert_expected_value VALUE ;
	   No return value (sets expected (verified) value, for example in strong integrity check).

VALID DURING
       ANTIFRAUD_ALERT

EXAMPLES
	when ANTIFRAUD_ALERT {
	    log local0. "original Alert expected value: [ANTIFRAUD::alert_expected_value]."
	    ANTIFRAUD::alert_expected_value new_value
	    log local0. "new Alert expected value: [ANTIFRAUD::alert_expected_value]."
	}
