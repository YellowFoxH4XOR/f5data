HTML::enable
       Enable the processing of HTML for this transaction.

SYNOPSIS
       HTML::enable

DESCRIPTION
       Enable the processing of HTML for this transaction.

RETURN VALUE
       empty return code.

VALID DURING
       ANY_EVENT

EXAMPLES
	when HTTP_RESPONSE {
	    if {$host == "www.f5.com"} {
		HTML::enable
	    }
	    log local0. "host: $host"
	}
