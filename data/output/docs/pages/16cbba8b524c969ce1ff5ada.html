ANTIFRAUD::alert_additional_info
       Returns or sets a list of keys and values that describes integrity parameters check failure or parameter values too long
       error.

SYNOPSIS
       ANTIFRAUD::alert_additional_info (VALUE)?

DESCRIPTION
       ANTIFRAUD::alert_additional_info ;
	   Returns a list of keys and values that describes integrity parameters check failure or parameter values too long error.

       ANTIFRAUD::alert_additional_info VALUE ;
	   Sets a list of keys and values that describes integrity parameters check failure or parameter values too long error.

RETURN VALUE
       ANTIFRAUD::alert_additional_info ;
	   Returns a list of keys and values that describes integrity parameters check failure or parameter values too long error.

       ANTIFRAUD::alert_additional_info VALUE ;
	   No return value (sets a list of keys and values that describes integrity parameters check failure or parameter values
       too long error).

VALID DURING
       ANTIFRAUD_ALERT

EXAMPLES
	when ANTIFRAUD_ALERT {
	    log local0. "original Alert additional info: [ANTIFRAUD::alert_additional_info]."
	    ANTIFRAUD::alert_additional_info new_value
	    log local0. "new Alert additional info: [ANTIFRAUD::alert_additional_info]."
	}
