X509::pem2der

Description

Returns the specified X509 certificate, in its entirety, in DER format.

Syntax

X509::pem2der <cert-in-pem>

Examples

when HTTP_REQUEST {
    if { [SSL::cert count] > 0 } {
        SSL::c3d cert [X509::pem2der [X509::whole [SSL::cert 0]]]
    }
}
when ACCESS_PER_REQUEST_AGENT_EVENT {
    if { [SSL::cert count] > 0 } {
        SSL::c3d cert [X509::pem2der [X509::whole [SSL::cert 0]]]
    }
}
