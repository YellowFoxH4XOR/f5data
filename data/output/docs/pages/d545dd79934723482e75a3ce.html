DOSL7::slowdown
       Adds source IP extracted from current connection to greylist.

SYNOPSIS
       DOSL7::slowdown RATE TIMEOUT

DESCRIPTION
       Adds source IP extracted from current connection to greylist. TCP slowdown will be applied according to supplied RATE (in
       percents) and TIMEOUT (in seconds).  A RATE represents amount of incoming data packets to be dropped to perform slowdown.

       Syntax

       DOSL7:slowdown RATE TIMEOUT

RETURN VALUE
VALID DURING
       ALL_EVENTS

EXAMPLES
	when HTTP_REQUEST {
	    if { [HTTP::uri] contains "heavy.php" } {
		DOSL7::slowdown 30 60
	    }
	}
