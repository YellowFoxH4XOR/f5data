traffic_group

Description

This command returns the current traffic group. Useful for troubleshooting the partitioning of data in the session table.

Syntax

traffic_group

Examples

when RULE_INIT {
  log local0. "traffic_group name: [traffic_group]"
}
when CLIENT_ACCEPTED {
  log local0. "traffic_group name: [traffic_group]"
}
