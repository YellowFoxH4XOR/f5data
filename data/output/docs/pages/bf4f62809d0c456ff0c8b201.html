APIRef_tm_wom_endpoint-discovery

mgmt/tm/wom/endpoint-discovery

/tm/wom

Configure automatic discovery of remote endpoints

REST Endpoints

Collection URI
/mgmt/tm/wom/endpoint-discovery
Collection Methods
OPTIONS, GET
Resource URI
/mgmt/tm/wom/endpoint-discovery/~resource id
Resource Methods
OPTIONS, GET, PUT, PATCH, POST

Properties

Name Type Default Value Required Access Description
autoSave string enabled optional read/write Specifies whether the system automatically saves remote endpoints that it discovers.
description string   optional read/write User defined description.
discoverable string enabled optional read/write Specifies whether the WAN Optimization Manager responds to probe messages it receives from WAN Optimization Managers on remote BIG-IP systems.
discoveredEndpoint string enabled optional read/write Specifies whether the WAN Optimization Manager sends out probe messages to discover other WAN Optimization Managers on remote BIG-IP systems in the network.
icmpMaxRequests integer 1024 optional read/write Specifies the maximum number of ICMP probe message requests, after which the system stops sending probe message requests until at least one message is cleared from the queue by either a timeout or a response.
icmpMinBackoff integer 5 optional read/write Specifies the maximum number of seconds to wait before abandoning an ICMP probe message request and resending it.
icmpNumRetries integer 10 optional read/write Specifies the maximum number of times the system sends an ICMP probe message request for a single flow.
maxEndpointCount integer 0 optional read/write Specifies the highest number of endpoints for the system to discover before it stops sending probe messages.
mode string enable-all optional read/write Specifies the type of probe messages the system should send.
