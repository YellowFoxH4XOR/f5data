HTTP::close
       Closes the HTTP connection.

SYNOPSIS
       HTTP::close

DESCRIPTION
       Closes the HTTP connection.

       Syntax

       HTTP::close

	    * Closes the HTTP connection. In a RESPONSE event, also inserts a
	      Connection: Close header. Note that OneConnect
	      transformations, if enabled, may modify the inserted header, but
	      the connection will still close.

RETURN VALUE
VALID DURING
       CACHE_REQUEST, CACHE_RESPONSE, HTTP_REQUEST, HTTP_REQUEST_DATA, HTTP_REQUEST_SEND, HTTP_RESPONSE, HTTP_RESPONSE_CONTINUE,
       HTTP_RESPONSE_DATA

EXAMPLES
	when HTTP_REQUEST {
	  set method [HTTP::method]
	}
	when HTTP_RESPONSE {
	  # The current connection will close after a POST reply
	  if { $method eq "POST" } {
	    HTTP::close
	  }
	}
