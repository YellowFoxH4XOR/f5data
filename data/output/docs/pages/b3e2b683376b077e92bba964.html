TCP::naglestate
       Returns current state of Nagle algorithm.

SYNOPSIS
       TCP::naglestate

DESCRIPTION
       If the Nagle mode is "enabled" or "disabled", it returns that mode. If "auto", it returns the current selection of the
       autotuning.

RETURN VALUE
       The string "disabled" or "enabled"

VALID DURING
       ANY_EVENT

EXAMPLES
	# Get the TCP Nagle state of the TCP flow.
	when CLIENT_ACCEPTED {
	    log local0. "TCP Nagle state: [TCP::naglestate]"
	}
