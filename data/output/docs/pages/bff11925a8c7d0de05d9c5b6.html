SSL::sessionsecret
       Return data about SSL handshake master secret.

SYNOPSIS
       SSL::sessionsecret

DESCRIPTION
       Return data about SSL handshake master secret.

RETURN VALUE
       SSL::sessionsecret
	   Returns the current SSL handshake master secret.

VALID DURING
       CLIENTSSL_HANDSHAKE SERVERSSL_HANDSHAKE

EXAMPLES
	when CLIENTSSL_HANDSHAKE {
	    log local0. "ClientSSL: Secret for [SSL::sessionid] is -> [SSL::sessionsecret]"
	}
	when SERVERSSL_HANDSHAKE {
	    log local0. "ServerSSL: Secret for [SSL::sessionid] is -> [SSL::sessionsecret]"
	}
