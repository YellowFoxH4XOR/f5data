http_header
       Returns the value of the specified HTTP header.

SYNOPSIS
       http_header ANY_CHARS

DESCRIPTION
       Evaluates the string following an HTTP header tag that you specify.  This command is a BIG-IP version 4.X variable,
       provided for backward-compatibility. You can use the equivalent 9.X command HTTP::header, instead.

       Syntax

       http_header(header_tag_string)

	    * Evaluates the string following an HTTP header tag that you specify.

RETURN VALUE
