save(1) 						BIG-IP TMSH Manual						   save(1)

NAME
       save - Writes the running configuration of the BIG-IP(r) system to the specified file.

MODULE
       All tmsh modules.

DESCRIPTION
       You can use the save command to write changes that you make to the running configuration of the BIG-IP system to the
       specified file. You can also use this command to save an analytics report to a file on the BIG-IP(r) system or to export an
       ASM policy to a file / standard output.

SEE ALSO
       analytics report, asm policy, load, sys config, sys ucs, tmsh
