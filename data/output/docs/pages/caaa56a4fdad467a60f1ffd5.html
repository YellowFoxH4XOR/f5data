RTSP_REQUEST
       Triggered after a complete request has been received from either the client or the server.

DESCRIPTION
       Triggered after a complete request has been received from either the client or the server. You can use the RTSP::msg_source
       command to determine if the message originated from the client or server.

Examples
	when RTSP_REQUEST {
	    RTSP::collect 10
	}
	when RTSP_REQUEST_DATA {
	    RTSP::release
	}
