COMPRESS::disable
       Disables compression for the current HTTP response.

SYNOPSIS
       COMPRESS::disable (request | response)?

DESCRIPTION
       Disables compression for the current HTTP response. Note that when using this command, you must set the HTTP profile
       setting Compression to Selective.

       COMPRESS::disable
	   Disables compression for the current HTTP response. Note that when using this command, you must set the HTTP profile
       setting Compression to Selective.

RETURN VALUE
VALID DURING
       HTTP_REQUEST HTTP_REQUEST_DATA HTTP_RESPONSE HTTP_RESPONSE_DATA

EXAMPLES
	when HTTP_REQUEST {
	  if { [TCP::mss] >= 1280 } {
	    COMPRESS::disable
	  }
	}
