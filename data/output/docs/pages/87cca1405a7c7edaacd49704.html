PSC::subscriber_id

Description

The PSC::subscriber_id command gets the subscriber id or sets the subscriber_id when the optional value is given.

Syntax

PSC::subscriber_id
PSC::subscriber_id <subscriber_id>

PSC::subscriber_id

  • retrieve the subscriber id

PSC::subscriber_id <subscriber_id>

  • set the subscriber id
