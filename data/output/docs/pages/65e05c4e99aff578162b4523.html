BIG-IP LTM v13.0.0

Warning

HTTP/2 has replaced SPDY, which is now considered deprecated by Google, its creator, and is no longer supported in Chromium. Deprecation: SPDY/2, SPDY/3 and SPDY/3.1 no longer supported. Originally part of the Application Acceleration Manager, SPDY Gateway provided users a method to configure BIG-IP to offer SPDY functionality to HTTP clients for non-SPDY-compliant pool members. Gateway acts as a front-end proxy to allow multiplexed transactions over a single connection. SPDY Gateway has been removed in this release.
