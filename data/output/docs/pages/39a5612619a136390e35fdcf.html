APIRef_tm_net_route-domain

mgmt/tm/net/route-domain

/tm/net

Route domain configuration

REST Endpoints

Collection URI
/mgmt/tm/net/route-domain
Collection Methods
OPTIONS, GET
Resource URI
/mgmt/tm/net/route-domain/~resource id
Resource Methods
OPTIONS, GET, PUT, PATCH, DELETE, POST
Resource Natural Key
name, partition, subPath

Properties

Name Type Default Value Required Access Description
appService string   optional read/write The application service that the object belongs to.
bwcPolicy string   optional read/write The bandwidth control policy used for traffic flow.
connectionLimit integer 0 optional read/write Specifies the maximum number of concurrent connections you want to allow for the route domain.
description string   optional read/write User defined description.
flowEvictionPolicy string   optional read/write Specifies the flow eviction policy for the route domain to use when the connection limit is approached.
fwEnforcedPolicy string   optional read/write Enforced firewall policy.
fwStagedPolicy string   optional read/write Staged firewall policy.
id integer   optional read/write Numerical ID of the route domain
ipIntelligencePolicy string   optional read/write Name of the IP Intelligence (Dynamic White/Black List) policy that is attached.
parent string   optional read/write Specifies the name of the route domain from which this route domainherits settings. The default value is empty, which indicates no parent.
tmPartition string Common optional read/write Displays the administrative partition within which the route-domain resides.
securityNatPolicy string   optional read/write Name of the Security NAT Policy.
servicePolicy string   optional read/write Specifies the service policy to use.
strict string enabled optional read/write Specifies whether the system allows a connection to span route domains.
throughputCapacity uint64   optional read/write Specifies the max throughput capacity of this route domain Mbps.

Lists

Name Type Default Value Required Access Description
undefined array_structure   optional read/write Specifies routing protocols, by name, for the system to use in the route domain. The default value is none. Dynamic routing must be licensed to use this option.
vlans (net/tunnels/tunnel) array_structure   optional read/write Specifies VLANs, by name, for the system to use in the route domain. The default value is none.
