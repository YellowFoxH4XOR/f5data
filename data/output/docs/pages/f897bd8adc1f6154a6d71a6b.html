APIRef_tm_sys_state-mirroring

mgmt/tm/sys/state-mirroring

/tm/sys

Redundant system connection mirroring configuration

REST Endpoints

Collection URI
/mgmt/tm/sys/state-mirroring
Collection Methods
OPTIONS, GET
Resource URI
/mgmt/tm/sys/state-mirroring/~resource id
Resource Methods
OPTIONS, GET, PUT, PATCH

Properties

Name Type Default Value Required Access Description
addr string   optional read/write Specifies the primary self-IP address on this unit to which the peer unit in this redundant pair mirrors its connections. This is a required setting.
peerAddr string   optional read/write Specifies the primary self-IP address on the peer unit to which this unit mirrors its connections. This is a required setting.
secondaryAddr string   optional read/write Specifies another self-IP address on this unit to which the peer unit mirrors its connections when the primary address is unavail able.
secondaryPeerAddr string   optional read/write Specifies another self-IP address on the peer unit to which this unit mirrors its connections when the primary peer address is unavailable.
state string   optional read/write Enables or disables connection mirroring. The default is enabled.
