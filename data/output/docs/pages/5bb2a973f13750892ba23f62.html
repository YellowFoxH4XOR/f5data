LDAP::enable
       Enable LDAP STARTTLS.

SYNOPSIS
       LDAP::enable

DESCRIPTION
       Enable LDAP STARTTLS

RETURN VALUE
VALID DURING
       SERVER_CONNECTED CLIENT_ACCEPTED

EXAMPLES
	when CLIENT_ACCEPTED {
	    if { !([IP::addr [IP::client_addr] equals 10.0.0.0/8]) } {
		LDAP::enable
	    }
	}
