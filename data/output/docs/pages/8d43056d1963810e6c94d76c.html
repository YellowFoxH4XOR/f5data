TDS::session

Description

This command returns TDS session data.

Syntax

TDS::session username
TDS::session dbname
TDS::session loginoption
TDS::session version

TDS::session username

  • returns the username

TDS::session dbname

  • returns the database name

TDS::session loginoption

  • returns the login option

TDS::session version

  • returns the TDS version

Examples

when TDS_REQUEST {
  log local0. "TDS request received from [TDS::session username]."
}

Related Information

Valid Events:
TDS_REQUEST,TDS_RESPONSE
