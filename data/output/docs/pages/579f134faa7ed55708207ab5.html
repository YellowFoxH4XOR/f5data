RTSP::status
       Returns the HTTP style status code from the current RTSP response.

SYNOPSIS
       RTSP::status

DESCRIPTION
       Returns the HTTP style status code (for example, 200 or 401) from the current RTSP response.

       Syntax

       RTSP::status

	    * Returns the HTTP style status code (for example, 200 or 401)
	      from the current RTSP response.

RETURN VALUE
       Returns the HTTP style status code from the current RTSP response.

VALID DURING
EXAMPLES
	rule xxx {
	    when RTSP_RESPONSE {
		puts [RTSP::status]
	    }
	}
