TCP::enhanced_loss_recovery
       Toggles enhanced loss recovery.

SYNOPSIS
       TCP::enhanced_loss_recovery BOOL_VALUE

DESCRIPTION
       Enables or disables enhanced loss recovery which recovers from random packet loss more effectively.

       Syntax

       TCP::enhanced_loss_recovery 

RETURN VALUE
       None.

VALID DURING
       ANY_EVENT.

EXAMPLES
	when CLIENT_ACCEPTED {
	    TCP::enhanced_loss_recovery enable
	}
