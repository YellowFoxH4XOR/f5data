MR_DATA
       Raised when the number of bytes specified by the user in MR::collect command have been collected.

DESCRIPTION
       This event is raised when the number of bytes of message payload collected equals to the number specified by the user in
       MR::collect command.

Examples
	when MR_DATA {
	    log local0. "Payload: [MR::payload]"
	    MR::release
	}
