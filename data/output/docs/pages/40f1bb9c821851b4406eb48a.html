FTP::enforce_tls_session_reuse
       Get or set the state of enforcing TLS session reuse.

SYNOPSIS
       FTP::enforce_tls_session_reuse (enable | disable)?

DESCRIPTION
       Enable or disable enforcing TLS session reuse, when enabled, Bigip rejects the data connection if it fails to reuse existed
       TLS session. Returns the current status if no option is specified.

RETURN VALUE
VALID DURING
       ANY_EVENT

EXAMPLES
	when CLIENT_ACCEPTED {
	    FTP::enforce_tls_session_reuse enable
	}
