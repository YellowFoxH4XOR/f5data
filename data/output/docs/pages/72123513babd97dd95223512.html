MR::prime

Description

This iRule command establishes an outgoing connection to the specified host or hosts using the specified transport. It instructs the Message Routing Framework to establish an outgoing connection to a specified host or pool if one does not exist. The setting of the specified virtual or transport-config will be used to establish the connection. If a pool is provided, outgoing connections will be created to all active pool members of the specified pool.

Syntax

MR::prime virtual <virtual_server_obj>
MR::prime config <transport_config> pool <pool_obj>
MR::prime host <host>

Examples

when CLIENT_ACCEPTED {
    MR::prime config /Common/my_tc pool /Common/default_pool
}
