iRule(1)						BIG-IP TMSH Manual						  iRule(1)

PCP_REQUEST
       Triggered on receipt of a valid PCP request from a client.

DESCRIPTION
       Triggered on receipt of a valid PCP (Port Control Protocol) request from a client.

Examples
	when PCP_REQUEST {
	    if {[PCP::request opcode] == "map" &&
		[PCP::request internal-port] == 22 } {
		    log "Rejecting PCP request to map SSH"
		    PCP::reject 1
		}
	}
