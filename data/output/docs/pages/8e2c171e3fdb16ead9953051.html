POP3

Description

Commands for the POP3 namespace

Commands

  • POP3::activation_mode - gets or sets the activation mode for POP3 STARTTLS
  • POP3::disable - disable STARTTLS for POP3
  • POP3::enable - enable STARTTLS for POP3
