MQTT_SERVER_EGRESS

Description

This iRule event is triggered when an MQTT message is sent to server-side. In case an MQTT message has large payload such as for server PUBLISH message types, this event may trigger before entire payload is sent. In that case, MQTT::collect may be used to obtain the payload.
NOTE: This event is implemented only for Message Routing based MQTT Sessions
