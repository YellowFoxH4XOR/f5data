OFFBOX::request
       Performs a request with a payload to certain service.

SYNOPSIS
       OFFBOX::request SERVICE PAYLOAD (((cache KEY) blocking) | (blocking | (cache KEY)) | (blocking TIMEOUT))?

DESCRIPTION
       Performs a request with a payload to certain service.

       Syntax

       OFFBOX::request   [cache ] [[blocking] [timeout]]

RETURN VALUE
VALID DURING
       ALL_EVENTS

EXAMPLES
	when HTTP_REQUEST {
	    if { [HTTP::uri] eq "login.php" } {
		OFFBOX::request "/Common/offbox::ip_reputation" [TCP::client_addr] cache [TCP::client_addr] blocking
	    }
	}
