Name Type Default Value Required Access Description

description string   optional read/write User defined description.
endpoint string enabled optional read/write Specifies whether the local endpoint is available for initiating and receiving optimized traffic.

serverSsl string   optional read/write Specifies the default server SSL profile the system uses for all encrypted outbound connections.
