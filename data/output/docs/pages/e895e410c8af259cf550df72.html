SSL::sni
       Returns Server Name Indication information.

SYNOPSIS
       SSL::sni (name | required)

DESCRIPTION
       Returns a Server Name Indication name, and require SNI support.

RETURN VALUE
       SSL::sni name
	   Returns the current Server Name Indication as specified in the SSL profile.	SSL::sni required
	   Returns the require SNI support as specified in the SSL profile.

VALID DURING
       ANY_EVENT

EXAMPLES
	when HTTP_REQUEST {
	    log local0.info "SNI name: [SSL::sni name]"
	    log local0.info "SNI required: [SSL::sni required]"
	}

	Sample log output:
	: SNI name: f5.com
	: SNI required: 1
