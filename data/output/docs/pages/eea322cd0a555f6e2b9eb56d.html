POP3::activation_mode
       Set the activation mode.

SYNOPSIS
       POP3::activation_mode (none | allow | require)?

DESCRIPTION
       Sets the activation mode to none (it will never activate), allow (if the POP3 client sends STARTTLS, we will activate TLS),
       or require (all commands will be rejected until STARTTLS is received).

RETURN VALUE
VALID DURING
       SERVER_CONNECTED CLIENT_ACCEPTED

EXAMPLES
	when CLIENT_ACCEPTED {
	    if { !([IP::addr [IP::client_addr] ne 10.0.0.0/8) } {
		POP3::activation_mode require
	    }
	}
