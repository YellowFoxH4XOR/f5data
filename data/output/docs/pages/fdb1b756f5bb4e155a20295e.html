DATAGRAM::l2

Description

This command returns Layer 2 destination address.

Syntax

DATAGRAM::l2 dest

Examples

when FLOW_INIT {
     set l2_dest [ DATAGRAM::l2 dest ]
     log local0. "L2 destination MAC $l2_dest"
}

Related Information

Valid Events:
FLOW_INIT onward
