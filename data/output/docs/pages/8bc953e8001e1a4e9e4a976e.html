APIRef_tm_net_cmetrics

mgmt/tm/net/cmetrics

/tm/net

Route metrics table display

REST Endpoints

Collection URI
/mgmt/tm/net/cmetrics
Collection Methods
OPTIONS, GET
Resource URI
/mgmt/tm/net/cmetrics/~resource id
Resource Methods
OPTIONS, GET, DELETE

Properties

Name Type Default Value Required Access Description
bandwidth integer   optional read/write Displays the size of the channel in kbps. Computed as cwnd/rtt.
destAddr string   optional read/write Specifies the destination IP address of the entry to display or delete.
hwaddress string   optional read/write Displays the MAC address for the route.
mtu integer   optional read/write Displays the maximum transmit unit size (in bytes) on the route.
rtt integer   optional read/write Displays the round-trip time on the route in units of 100ns.
rttvar integer   optional read/write Displays the variation in the round-trip time in units of 100ns.
ssthresh integer   optional read/write Displays the cached slow-start threshold in bytes.
tmm integer   optional read/write Displays the identifying number of the tmm (Traffic Management Microkernel).
