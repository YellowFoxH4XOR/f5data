ISTATS::remove

Description

Removes the given iStat entirely.

Syntax

ISTATS::remove "<key>"

ISTATS::remove “<key>”

  • The “<key>” must be in quotes and identical to the key used to set/incr/get the iStat.

ISTATS::remove is valid in all events/contexts in data plane iRules and control plane iRules.

Examples

ISTATS::remove "ltm.pool /Common/mypool counter some_counter"
