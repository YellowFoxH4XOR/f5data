APIRef_tm_cli_version

mgmt/tm/cli/version

/tm/cli

Manage tmsh’s versions

REST Endpoints

Collection URI
/mgmt/tm/cli/version
Collection Methods
OPTIONS, GET
Resource URI
/mgmt/tm/cli/version/~resource id
Resource Methods
OPTIONS, GET, PUT, PATCH

Properties

Name Type Default Value Required Access Description
active string   optional read/write Specifies the active (running) version of tmsh
imported string   optional read/write  
latest string   optional read/write Displays the latest version of tmsh. This is used as default version.
supported string   optional read/write Displays current supported tmsh versions on the system.
