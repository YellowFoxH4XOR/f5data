NAME
       netflow-tmc-stat - Show netflow protected server's related stats.

MODULE
       security protected-servers

SYNTAX
       show netflow-tmc-stat

DESCRIPTION
       You can use the netflow-tmc-stat component to display Traffic-Matching-Criteria, megabits-per-second, kilo-packets-per-
       second, and "connections per second.

EXAMPLES
       show security protected-servers netflow-tmc-stat
