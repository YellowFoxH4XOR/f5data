load(1) 						BIG-IP TMSH Manual						   load(1)

NAME
       load command - Replaces the running configuration of the BIG-IP(r) system with the configuration in the specified files.
       You can also use this command to import an ASM policy from a file / standard input, and to install the Anti-fraud engine /
       signatures update.

MODULE
       All tmsh modules.

SEE ALSO
       save, tmsh, asm policy, ltm dns dns-express db, sys config, sys geoip, sys ucs
