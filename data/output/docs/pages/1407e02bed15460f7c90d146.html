SDP::media

Description

This command allows you to get or set different aspects of the media information for your SDP connection.

Syntax

SDP::media attr <media-index> <attr-index>
SDP::media count
SDP::media <media-index>
SDP::media type <media-index>
SDP::media port <media-index>
SDP::media port <media-index> “new value"
SDP::media transport <media-index>
SDP::media conn <media-index>
SDP::media conn <media-index> “new value”

SDP::media attr <media-index> <attr-index>

  • Get SDP attribute attr-index of media media-index e.g. SDP::media attr 0 1 will get SDP attribute 1 of media 0

SDP::media count

  • Return the number of medias

SDP::media <media-index>

  • Get SDP media at index media-index

SDP::media type <media-index>

  • Get SDP media type of media media-index

SDP::media port <media-index>

  • Get SDP media port of media media-index

SDP::media port <media-index> “new value”

  • Rewrite SDP media port of media media-index

SDP::media transport <media-index>

  • Get SDP media transport info of media media-index (e.g. RTP/AVP)

SDP::media conn <media-index>

  • Get SDP media connection info of media media-index if its available, else gets connection info of session.

SDP::media conn <media-index> “new value”

  • Rewrite SDP media connection info of media media-index
