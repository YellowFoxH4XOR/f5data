AVR_CSPM_INJECTION

Description

An iRule event triggered when the AVR profile (active on the connection) is about to insert the CSPM javascript to the response payload.

Examples

when AVR_CSPM_INJECTION {
   if {[info exist no_cspm]} {
      AVR::disable_cspm_injection
   }
}

Related Information

See also:
See solution document Overview of BIG-IP Analytics CSPM injection.

Available Commands:

  • AVR::disable_cspm_injection - Disables the injection of CSPM javascript to the response payload
