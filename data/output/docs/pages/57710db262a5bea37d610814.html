RTSP::collect
       Collects the amount of data that you specify.

SYNOPSIS
       RTSP::collect (LENGTH)?

DESCRIPTION
       Collects the amount of data that you specify.

       Syntax

       RTSP::collect [collect_len]

	    * collect_len is the size of data to be collected, optional

RETURN VALUE
VALID DURING
EXAMPLES
	rule xxx {
	    when RTSP_REQUEST {
		RTSP::collect 10
	    }
	    when RTSP_REQUEST_DATA {
		RTSP::release
	    }
	}
