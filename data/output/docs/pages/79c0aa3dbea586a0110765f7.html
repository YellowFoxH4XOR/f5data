PSC::aaa_reporting_interval

Description

The PSC::aaa_reporting_interval command gets or sets AAA reporting interval.

Syntax

PSC::aaa_reporting_interval [value]

PSC::aaa_reporting_interval

  • Retrieve the AAA reporting interval.

PSC::aaa_reporting_interval [value]

  • Set the AAA reporting interval.
