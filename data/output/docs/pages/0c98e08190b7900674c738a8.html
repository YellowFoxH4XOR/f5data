APIRef_tm_analytics_network_stale-rules

mgmt/tm/analytics/network/stale-rules

/tm/analytics/network

Displays a network firewall stale rules report.

REST Endpoints

Collection URI
/mgmt/tm/analytics/network/stale-rules
Collection Methods
OPTIONS, GET
Resource URI
/mgmt/tm/analytics/network/stale-rules/~resource id
Resource Methods
OPTIONS, GET

Properties

Name Type Default Value Required Access Description
drilldown string   optional read/write Specifies specific entities that are used as a filter.
firstRuleNumber integer   optional read/write Specifies the first rule number being displayed. Rules are ordered by hit count in ascending order.
numberOfRules integer   optional read/write Specifies the maximum number of firewall rules displayed in the output result set. The default value is 10.
range string   optional read/write Specifies the time/date range of the analytics information that you want to display. The displayed results reflect the time range specified. The default value is the last hour (now–now-1h).
type string enforced required read/write Specifies the type of rules being displayed: either enforced or staged.
