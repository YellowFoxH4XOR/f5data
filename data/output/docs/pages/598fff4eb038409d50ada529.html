PROFILE::auth
       Returns the value of an authentication profile setting.

SYNOPSIS
       PROFILE::auth PROFILE_AUTH ATTR

DESCRIPTION
       Returns the current value of the specified setting in the assigned authentication profile.

RETURN VALUE
       Returns the current value of the specified setting in the assigned authentication profile.

VALID DURING
       ANY_EVENT
