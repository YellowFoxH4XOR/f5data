APIRef_tm_sys_ntp_restrict

mgmt/tm/sys/ntp/restrict

/tm/sys

A restrict line in the NTP configuration

Collection URI
/mgmt/tm/sys/ntp/restrict
Collection Methods
OPTIONS, GET
Resource URI
/mgmt/tm/sys/ntp/restrict/~resource id
Resource Methods
OPTIONS, GET, PUT, PATCH, DELETE, POST
Resource Natural Key
name

Properties

Name Type Default Value Required Access Description
address string   optional read/write The address for a restrict entry.
defaultEntry string   optional read/write Enable or disable the restrict entry as the default.
description string   optional read/write User defined description.
ignore string   optional read/write Enable or disable denial of all packets.
kod string   optional read/write Enable or disable sending kiss of death packets.
limited string   optional read/write Enable or disable denial of time service.
lowPriorityTrap string   optional read/write Enable or disable declaring traps to be low priority.
mask string   optional read/write The mask for the address in the restrict entry.
noModify string   optional read/write Enable or disable denial of ntpq and ntpdc queries attempting to modify the state of the server.
noPeer string   optional read/write Enable or disable denial of packets mobilizing an association.
noQuery string   optional read/write Enable or disable denial of ntpq and ntpdc queries.
noServePackets string   optional read/write Enable or disable denial of all packets except ntpq and ntpdc.
noTrap string   optional read/write Enable or disable providing mode 6 control message trap service.
noTrust string   optional read/write Enable or disable denial of packets not cryptographically authenticated.
nonNtpPort string   optional read/write Enable or disable matching on the source port in the packet.
ntpPort string   optional read/write Enable or disable matching on the source port in the packet.
version string   optional read/write Enable or disable denial of packets from a different version of NTP.
