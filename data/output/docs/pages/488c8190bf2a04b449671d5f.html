JSON_REQUEST_ERROR

Description

Triggered when an HTTP (or HTTP/2) request message’s body should contain JSON content but it could not be parsed (due to syntax errors or exceeding configurable limits on size and complexity).

Examples

when JSON_REQUEST_ERROR {
    log local0. "Failed to parse JSON content"
}
