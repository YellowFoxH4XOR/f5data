TAP::insight_requested
       TAP requests insight flag.

SYNOPSIS
       TAP::insight_requested

DESCRIPTION
       Command for indication that TAP module wants to get insight from any module. TAP::insight must be invoked if flag is set to
       true.

       Syntax

       TAP::insight_requested

RETURN VALUE
       Return boolean value if TAP modules wants to get an insight from any module.

VALID DURING
       ALL
