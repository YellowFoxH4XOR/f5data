ltm rule event L7CHECK SERVER DATA

iRule(1)						BIG-IP TMSH Manual						  iRule(1)

L7CHECK_SERVER_DATA
       Triggered each time new ingress data is received from server.

DESCRIPTION
       This event is triggered after ingress data has been received from server.

Examples
	when L7CHECK_SERVER_DATA {
	    # Set the L7 protocol using command L7CHECK::protocol set
	    L7CHECK::protocol set "smtps"
	}
