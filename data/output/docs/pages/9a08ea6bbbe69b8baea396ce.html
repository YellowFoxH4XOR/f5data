BIG-IP LTM v15.1.0

Commands Introduced in BIG-IP LTM 15.1.0

  • ACCESS::ephemeral-auth - used either to create or verify a temporary password for ephemeral authentication
  • ASM::conviction - inject conviction honey traps in case of behavioral enforcement is enabled
  • DNSMSG::header - returns a field from header of a DNS message.
  • DNSMSG::record - returns a field from a DNS resource record object.
  • DNSMSG::section - returns a section of a DNS message.
  • RESOLVER::name_lookup - performs a DNS lookup.
  • RESOLVER::summarize - returns a summary of the DNS response.
  • SSL::c3d - Inserts a certificate extension to the C3D certificate, or sets the C3D client certificate
  • TAP::insight - Accumulates or sends key:value pairs to TAP, returns token
  • TAP::insight_requested - TAP requests insight flag
  • X509::pem2der - Returns an X509 certificate in DER format
