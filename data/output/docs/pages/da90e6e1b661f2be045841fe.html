shutdown

shutdown(1)						BIG-IP TMSH Manual					       shutdown(1)

NAME
       shutdown command - Shuts down the system.

MODULE
       All tmsh modules.

SYNTAX
	shutdown
	 options:
	  slot [ [slot number] | all ]

DESCRIPTION
       You can use the command shutdown to power down the system or cluster. If you do not specify an option, the local system
       shuts down.

       For a cluster, you can use the slot option to shut down either a specific slot or all slots.

EXAMPLES
       shutdown

       Immediately shuts down the running system.

OPTIONS
       slot [ [slot number] | all ]
	    Shuts down either a specific slot or all slots in the cluster. This option is only available in a clustered
	    environment.

SEE ALSO
       reboot, install
