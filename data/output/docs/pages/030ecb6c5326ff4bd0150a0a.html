SIP::payload
       Returns the accumulated SIP data content.

SYNOPSIS
       SIP::payload (LENGTH | (OFFSET LENGTH))?

       SIP::payload length

       SIP::payload replace OFFSET LENGTH PAYLOAD

       SIP::payload insert OFFSET PAYLOAD

       SIP::payload delete OFFSET LENGTH

DESCRIPTION
       Returns the accumulated SIP data content.

       Syntax

       SIP::payload

	    * Returns the SIP data accumulated so far

RETURN VALUE
       Returns the SIP data accumulated so far

VALID DURING
       SIP_REQUST, SIP_RESPONSE, SIP_REQUEST_SEND, SIP_RESPONSE_SEND, MR_INGRESS, MR_EGRESS, MR_FAILED

EXAMPLES
	when SIP_REQUEST {
	    log local0. "unmodified request [SIP::payload]"
	}
	when SIP_REQUEST_SEND {
	    log local0. "modified request [SIP::payload]"
	}
