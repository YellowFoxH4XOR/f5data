AVR::disable_cspm_injection

Description

Disables the injection of CSPM javascript to the response payload.

Syntax

AVR::disable_cspm_injection

Examples

when AVR_CSPM_INJECTION {
   if {[info exist no_cspm]} {
      AVR::disable_cspm_injection
   }
}

Related Information

Valid Events:
  • AVR_CSPM_INJECTION - Triggered when the AVR profile is about to insert a CSPM javascript
