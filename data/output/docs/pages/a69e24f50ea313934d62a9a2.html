MESSAGE::type
       Returns the type of the current message.

SYNOPSIS
       MESSAGE::type

DESCRIPTION
       returns the type of the current message. For example, for SIP request, it will return 'request'.  This is valid for
       messages of the following protocols:

	   DIAMETER
	   SIP

RETURN VALUE
       returns the type of the current message. For example, for SIP request, it will return 'request'.

VALID DURING
       MR_INGRESS, MR_EGRESS, and MR_FAILED.

EXAMPLES
	when MR_INGRESS {
	    log local0. "[MESSAGE::proto] [MESSAGE::type]"
	}
