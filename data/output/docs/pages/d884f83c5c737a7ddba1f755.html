L7CHECK::protocol

Description

This command allows you to set or retrieve L7 protocol value.

Syntax

L7CHECK::protocol set <VALUE>
L7CHECK::protocol get

Examples

when L7CHECK_CLIENT_DATA {
    if { [L7CHECK::protocol get] == "https" } {
        pool clients_https
    } else {
        pool clients_non_https
    }
}

Related Information

Valid Events:
CONNECTOR_OPEN (v16.1+ only)
L7CHECK_CLIENT_DATA
L7CHECK_SERVER_DATA

  • Introduced: BIGIP-14.0.0
  • Updated: BIGIP-16.1.0 (added CONNECTOR_OPEN event)
