NAME
       signature-details - List Specified DoS Dynamic or Persistent Signature.

MODULE
       security presentation tmui

SYNTAX
       Configure the signature-details component within the security presentation tmui module using the syntax shown in the
       following sections.

   DISPLAY
	list signature-details [name]

DESCRIPTION
       You can use the signature-details component to display the specified dos dynamic or persistent signature configuration and
       stats info.

EXAMPLES
       list signature-details my_signature

       Displays the properties of the named my_signature configuration and stats info.

OPTIONS
       name Specifies the signature name.

       list, tmsh
