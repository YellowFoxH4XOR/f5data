SCTP::release
       Resumes processing and flushes collected data.

SYNOPSIS
       SCTP::release (RELEASE_BYTES)?

DESCRIPTION
       Causes SCTP to resume processing the connection and flush collected data.

RETURN VALUE
VALID DURING
EXAMPLES
	when CLIENT_ACCEPTED {
	  SCTP::collect 15
	}
	when CLIENT_DATA {
	  if { [SCTP::payload 15] contains "XYZ" } {
	     pool xyz_servers
	  } else {
	     pool web_servers
	 }
	 SCTP::release
	}
