TCP::snd_scale

Description

Returns the receive window scale advertised by the local host.
Syntax
TCP::snd_scale

Syntax

TCP::snd_scale

TCP::snd_scale

Return Value

The bitshift associated with the local host window scale.

Examples

when CLIENT_ACCEPTED {
     # Log snd_scale.
     log local0. "snd_scale: [TCP::snd_scale]"
 }
