TCP::mss
       Returns the Maximum Segment Size (MSS) for a TCP connection.

SYNOPSIS
       TCP::mss

DESCRIPTION
       Returns the initial connection negotiated MSS. It does not deduct bytes for any common TCP options present in data packets
       are not deducted. In other words, it is the minimum of the MSS options in the SYN and SYN-ACK packets, or the MSS default
       of 536 bytes if one packet is missing the option.

       Syntax

       TCP::mss

	    * Returns the MSS for a TCP connection.

RETURN VALUE
       MSS in bytes.

VALID DURING
       CLIENT_ACCEPTED, CLIENT_CLOSED, CLIENT_DATA, SERVER_CLOSED, SERVER_CONNECTED, SERVER_DATA, SIP_REQUEST, SIP_REQUEST_SEND,
       SIP_RESPONSE, STREAM_MATCHED

EXAMPLES
	when HTTP_REQUEST {
	  if { [TCP::mss] >= 1280 } {
	    COMPRESS::disable
	  }
	}
