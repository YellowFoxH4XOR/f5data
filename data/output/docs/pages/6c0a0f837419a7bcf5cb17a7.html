ASM::severity
       Returns the overall severity of the violations found in the transaction (both request and response).

SYNOPSIS
       ASM::severity

DESCRIPTION
       Returns the overall severity of the violations found in the transaction (both request and response). This equals to the
       maximum severity of all these violations

       Syntax

       ASM::severity

	    * Returns one of the following values (or null string in case there
	      was no violation until the time the command is invoked)
		 + Emergency
		 + Alert
		 + Critical
		 + Error
		 + Warning
		 + Notice
		 + Informational

RETURN VALUE
       + Null string (in case there was no violation until the time the command is invoked) + Emergency + Alert + Critical + Error
       + Warning + Notice + Informational

VALID DURING
       ASM_REQUEST_DONE, ASM_REQUEST_VIOLATION, ASM_RESPONSE_VIOLATION

EXAMPLES
	when ASM_REQUEST_DONE {
	   if {[ASM::violation count] > 3 and [ASM::severity] eq "Error"} {
	      ASM::raise VIOLATION_TOO_MANY_VIOLATIONS
	   }
	}
