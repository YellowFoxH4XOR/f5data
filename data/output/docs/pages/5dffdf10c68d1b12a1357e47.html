NAME
       ocsp - Manages the OCSP response of a certificate when it has OCSP validation enabled.

MODULE
       sys crypto cert-validation-response

SYNTAX
       Use the ocsp component within the sys.crypto.cert-validation-response module to manage the cached OCSP response of a given
       certificate.

   DELETE
	delete ocsp
	  options:
	    certificate [name]

DESCRIPTION
       You can use the ocsp component to delete the cached OCSP response of a given certificate. The response is automatically re-
       fetched, and the certificate status is updated subsequently.

OPTIONS
       certificate
	    Specifies the name of the certificate whose OCSP response you want to delete.

SEE ALSO
       delete, tmsh
