ECA::disable

Description

The ECA::disable command disables the plugin the flow.

Syntax

ECA::disable

Examples

when HTTP_REQUEST {
    if { [HTTP::path] starts_with "/protected_uri" } {
        ECA::enable
        ECA::select select_ntlm:/Common/exch_ntlm_auth_config
    } else {
        ECA::disable
    }
}
