PERSIST_DOWN
       Triggered when persistence dictates that a connection would be sent to a pool or a pool member or node which has been
       marked down.

DESCRIPTION
       PERSIST_DOWN is triggered when LTM is ready to send the request to a particular node or pool member via persistence and it
       has been marked down. This is usually because the server has been detected as unreachable (when no route to the target
       exists) or non-responsive (failed to respond to a connection request).

Examples
	when PERSIST_DOWN {
	  pool errorPool
	}

	when PERSIST_DOWN {
	  HTTP::respond 501
	  reject
	}
