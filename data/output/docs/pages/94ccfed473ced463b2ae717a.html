MQTT::message
       Returns the full content of the MQTT message.

SYNOPSIS
       MQTT::message

DESCRIPTION
       The MQTT::message command returns full content of the MQTT message.

       Syntax

       MQTT::message

RETURN VALUE
       Returns content of the current message

VALID DURING
       MR_INGRESS, MR_EGRESS, MR_FAILED, MQTT_CLIENT_INGRESS MQTT_SERVER_INGRESS, MQTT_CLIENT_EGRESS, MQTT_SERVER_EGRESS

EXAMPLES
	when MQTT_CLIENT_INGRESS {
	  log local0. [MQTT::message]
	}
