FLOWTABLE::limit

Description

This iRules command returns configured connection limits

Syntax

FLOWTABLE::limit virtual <virtual-name>
FLOWTABLE::limit route_domain <route-domain>

FLOWTABLE::limit virtual <virtual-name>

  • This command returns the configured connection limit for a given virtual server.

FLOWTABLE::limit route_domain <route-domain>

  • This command returns the configured connection limit for a given route domain.
