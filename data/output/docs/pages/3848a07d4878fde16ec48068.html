Original F5 documentation

imid

Description

Parses the BIG-IP 4.X http_uri variable and the user-agent header field to return an i-mode identifier string that can be used for i-mode session persistence. This is a BIG-IP 4.X function, provided for backward compatibility.
The imid function takes no arguments and simply returns the string representing the i-mode identifier or the empty string, if none is found.
Note: The imid function currently does not work. This issue is tracked by CR96666.
