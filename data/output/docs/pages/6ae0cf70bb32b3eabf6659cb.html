iRule(1)						BIG-IP TMSH Manual						  iRule(1)

ASM
       Namespace ASM

DESCRIPTION
       iRule commands and events relating to the Application Security Manager (ASM) module

       Associated Events
	    * ASM_REQUEST_BLOCKING - Triggered when ASM is generating the reject-response and gives the iRule a chance to modify
       that reject-response before it is sent.
	    * ASM_REQUEST_DONE - triggered after ASM finished processing the request and found all violations of the ASM policy
	    * ASM_REQUEST_VIOLATION - Triggered when ASM detects that a request violates an ASM security policy.
	    * ASM_RESPONSE_VIOLATION - Triggered when ASM detects that a response violates an ASM security policy.
	    * IN_DOSL7_ATTACK - Triggered when ASM detects that a request violates an ASM security policy for Denial of Service
       attacks
