WS::payload_processing
       Enables or disables processing of WebSocket payload via payload protocol filter

SYNOPSIS
       WS::payload_processing ('enable' | 'disable')

DESCRIPTION
       WS::payload_processing enable
	   Enables processing of WebSocket Payload via payload protocol filter WS::payload_processing disable
	   Disables processing of WebSocket Payload via payload protocol filter

RETURN VALUE
VALID DURING
       WS_REQUEST HTTP_REQUEST WS_CLIENT_DATA

EXAMPLES
	when WS_REQUEST {
	    switch [WS::request protocol] {
		mqtt {
		    WS::payload_processing enable
		}
	    }
	}
