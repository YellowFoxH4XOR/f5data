PROFILE::clientssl
       Returns the value of a Client SSL profile setting.

SYNOPSIS
       PROFILE::clientssl ATTR

DESCRIPTION
       Returns the current value of the specified setting in the assigned Client SSL profile.

RETURN VALUE
       Returns the current value of the specified setting in the assigned Client SSL profile.

VALID DURING
       ANY_EVENT
