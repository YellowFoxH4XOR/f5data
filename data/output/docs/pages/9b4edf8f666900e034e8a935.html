APIRef_tm_sys_pptp-call-info

mgmt/tm/sys/pptp-call-info

/tm/sys

Displays or deletes active pptp-calls on the BIG-IP system

REST Endpoints

Collection URI
/mgmt/tm/sys/pptp-call-info
Collection Methods
OPTIONS, GET
Resource URI
/mgmt/tm/sys/pptp-call-info/~resource id
Resource Methods
OPTIONS, GET, DELETE

Properties

Name Type Default Value Required Access Description
clientCallId integer   optional read/write Specifies the client call id of the active pptp-calls
clientIp string   optional read/write Specifies the client address of the active pptp-calls
serverCallId integer   optional read/write Specifies the server call id of the active pptp-calls
serverIp string   optional read/write Specifies the server address of the active pptp-calls
transCallId integer   optional read/write Specifies the translated client call id of the active pptp-calls
transIp string   optional read/write Specifies the translated client address of the active pptp-calls
