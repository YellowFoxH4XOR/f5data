BIGPROTO::enable_fix_reset
       Enable or Disable Reset of FIX Protocol Connections

SYNOPSIS
       BIGPROTO::enable_fix_reset BOOLEAN

DESCRIPTION
       When set to disabled, TCP RST frame will not be sent when BIG-IP detects there is a hash collision on ePVA offloading of
       FIX flows. Instead, it will try to re-offload the connection.

RETURN VALUE
       none

VALID DURING
       ANY_EVENT

EXAMPLES
	when CLIENT_ACCEPTED {
	    BIGPROTO::enable_fix_reset true
	    BIGPROTO::enable_fix_reset false
		    }
