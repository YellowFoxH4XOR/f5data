SIPALG::nonregister_subscriber_listener
       Gets or sets the value of flag enabling creating an ephemeral listener for nonregistered subscribers.

SYNOPSIS
       SIPALG::nonregister_subscriber_listener

       SIPALG::nonregister_subscriber_listener (BOOLEAN)

DESCRIPTION
       Gets or sets the value of flag enabling creating an ephemeral listener for nonregistered subscribers.

RETURN VALUE
       Returns 1, or 0

VALID DURING
       CLIENT_ACCEPTED, SERVER_CONNECTED, SIP_REQUEST, SIP_REQUEST_SEND, SIP_RESPONSE, SIP_RESPONSE_SEND

EXAMPLES
	when SIP_REQUEST {
	    log local0. "nonregister_subscriber_listener is [SIPALG::nonregister_subscriber_listener]"
	}
