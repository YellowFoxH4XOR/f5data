http_uri
       Returns the URI part of the HTTP request.

SYNOPSIS
       http_uri

DESCRIPTION
       Returns a URL, but does not include the protocol and the fully qualified domain name (FQDN). For example, if the URL is
       http://www.mysite.com/buy.asp, then the URI is /buy.asp. This command is a BIG-IP 4.X variable, provided for backward-
       compatibility. You can use the equivalent 9.x command HTTP::uri instead.

       Syntax

       http_uri

	    * Returns a URI, which is a URL that does not include the protocol
	      and the fully qualified domain name (FQDN).
