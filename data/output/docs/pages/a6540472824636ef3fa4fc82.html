http_version
       Returns the HTTP version of the request or response.

SYNOPSIS
       http_version

DESCRIPTION
       Returns the HTTP protocol version. Possible values are "HTTP/1.0" or "HTTP/1.1". This is a BIG-IP version 4.X variable,
       provided for backward compatibility. You can use the equivalent 9.X command, HTTP::version instead.

       Syntax

       http_version

	    * Returns the HTTP protocol version.

RETURN VALUE
