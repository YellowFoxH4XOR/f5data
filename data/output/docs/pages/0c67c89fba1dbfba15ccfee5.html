LB::src_tag
       Sets the source tag for the current request.

SYNOPSIS
DESCRIPTION
       Sets the source tag for the current request

       LB::src_tag 
	   Sets the source tag for the current request. The tag will be recorded as a key to the current connection (to be looked
       up by destination tag next time).

RETURN VALUE
VALID DURING
       ANY_EVENT

EXAMPLES
	when CLIENT_ACCEPTED {
	    LB::src_tag foo_tag
	}
