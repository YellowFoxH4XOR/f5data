COMPRESS
       Namespace COMPRESS

DESCRIPTION
       You can use any of several iRule COMPRESS commands to manage the compression of HTTP responses or, beginning in version 11,
       requests.

       NOTE: The features contained in this namespace require a feature addon module license to be accessed. These commands will
       not function if your system does not have this license installed. For more information, read about the License Details.
