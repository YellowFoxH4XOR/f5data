cname


Description

Causes the specified name to be sent as a CNAME response.

Syntax

cname <cname>

cname <cname>

  • Sends the specified CNAME response

Examples

when DNS_REQUEST {
  if { [wideip name] ends_with ".com" } {
     cname "my.host.org"
 }
}

Related Information

Valid Events:
DNS_REQUEST, GLOBAL_GTM
