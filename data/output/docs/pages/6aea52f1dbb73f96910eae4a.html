AES
       Namespace AES

DESCRIPTION
       These commands allow you to create AES keys, as well as encrypt and decrypt data using AES keys.

       Caution
	  These functions are affected by ID241924 and ID242479, and should not be used in BIG-IP v10.1.x or earlier.
	  These functions are also affected by ID224113, and a workaround is necessary. The workaround is to not use a passphrase,
       but to specify a key directly, in the form of "AES  ", where  is 128, 192, or 256. For
       example, "AES 128 e467128783ea04aba33aded4e6e457a5", would be a valid 128-bit key.
