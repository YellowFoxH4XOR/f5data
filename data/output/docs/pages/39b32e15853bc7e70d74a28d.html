APIRef_tm_wam_policy

mgmt/tm/wam/policy

/tm/wam

Policy configuration.

REST Endpoints

Collection URI
/mgmt/tm/wam/policy
Collection Methods
OPTIONS, GET
Resource URI
/mgmt/tm/wam/policy/~resource id
Resource Methods
OPTIONS, GET, PUT, PATCH, DELETE, POST
Resource Natural Key
name, partition, subPath

Properties

Name Type Default Value Required Access Description
appService string   optional read/write The application service to which the object belongs.
code string   optional read/write Specifies the unique code of the policy that is used for troubleshooting or tuning.
copyFrom string   optional read/write Specifies the name of the existing policy from which to copy all settings. All components of this policy will be replaced with components of the specified policy.
description string   optional read/write Specifies the description of the policy.
hints string 0 optional read/write  
tmPartition string Common optional read/write Specifies the administrative partition associated with the policy.
predefined string no optional read/write Displays if this is a system predefined policy. This property is read-only.
publishBuild integer   optional read/write Specifies the policy build number. The number is auto-incremented when policy is published.
publishComment string   optional read/write The comment supplied when publishing a policy.
publishedOn string   optional read/write Displays the time stamp when this policy was last published. This property is read-only.
state string   optional read/write Displays the published state of the policy. This property is read-only.

Subcollections

Name Type Default Value Required Access Description
nodes array_structure   optional read/write Defines a node in a policy tree.
