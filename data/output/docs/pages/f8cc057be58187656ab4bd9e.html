MR_EGRESS

Description

This event is raised after the route has been selected and processed and the message is delivered to the mr_proxy for forwarding on the new connflow.

Examples

when MR_INGRESS {
  set client_addr “[IP::addr]:[IP::port]"
  MR::store client_addr
}
when MR_EGRESS {
  MR::restore client_addr
}

Related Information

The DIAMETER:: commands are available in MR_EGRESS starting with 13.0.0. Before that, any DIAMETER:: values must be set in a variable in DIAMETER_EGRESS. MR_EGRESS is raised after DIAMETER_EGRESS.


Available Commands:

  • DIAMETER::message - returns the whole Diameter message as a TCL string object.
  • MR::restore - returns the stored variables to the current context tcl variable store
