UDP::release
       Allow client-side ingress to flow following a call to UDP::hold.

SYNOPSIS
       UDP::release

DESCRIPTION
       Called at some point after UDP::hold was called.  Unblock ingress on client side.

       Syntax

       UDP::release

RETURN VALUE
VALID DURING
       LB_SELECTED, SA_PICKED, SERVER_CONNECTED

EXAMPLES
	when CLIENT_ACCEPTED {
	    UDP::hold
	}
	when LB_SELECTED {
	    UDP::release
	}
	when CLIENT_DATA {
	    # Load balancing info available
	}
