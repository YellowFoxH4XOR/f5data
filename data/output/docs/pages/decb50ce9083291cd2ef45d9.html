CACHE::enable

Description

Forces the document to be cached. You can also use this command to cache non-GET requests.

Syntax

CACHE::enable

CACHE::enable

  • Forces the document to be cached.

Examples

when HTTP_REQUEST {
  if { [HTTP::uri] contains "images" } {
    CACHE::enable
  }
}

Related Information

Valid Events:
HTTP_REQUEST, HTTP_RESPONSE
