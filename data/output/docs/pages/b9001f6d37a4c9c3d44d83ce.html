LB::prime
       Prime server connections.

SYNOPSIS
DESCRIPTION
       Prime server connections

       LB::prime
	   Sets up serverside connections before client traffic comes. The connection will be made to the specific pool or the
       default server pool in this virtual server.

RETURN VALUE
VALID DURING
       ANY_EVENT

EXAMPLES
	when CLIENT_ACCEPTED {
	    LB::prime
	}
