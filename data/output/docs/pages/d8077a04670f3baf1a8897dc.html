MR::max_retries
       Returns the number of retries allows for this router instance.

SYNOPSIS
       MR::max_retries

DESCRIPTION
       returns the number of retries allowed

RETURN VALUE
       returns the number of retries allowed

VALID DURING
       ANY_EVENT

EXAMPLES
	when MR_FAILED {
	    if {[MR::message retry_count] < [MR::max_retries]} {
		MR::message nexthop none
		MR::retry
	    }
	}
