HTML_Profile (object)

HTML profile with configurable options

Properties (* = required):

name type(s) default allowed values description
class* string   “HTML_Profile”  
contentDetectionEnabled boolean false true, false Scans initial HTTP payload to look for HTML signatures and enables HTML profile if HTML-like patterns are detected
contentSelection array “text/html”   Matches content-type from response header against a list of the content-types and enables HTML profile if a match is found
label string   “^[^x00-x1fx22#&*<>?x5b-x5d`x7f]*$” Optional friendly name for this object. Allows 0-64 chars, excluding a few likely to cause trouble with string searching, JS, TCL, or HTML
remark string   “^[^x00-x1fx22x5cx7f]*$” Arbitrary (brief) text pertaining to this object. Allows 0-64 chars, excluding only control characters, double-quote, and backslash. This is permissive enough that you should worry about XSS attacks
rules array     HTML Rules followed by the profile
