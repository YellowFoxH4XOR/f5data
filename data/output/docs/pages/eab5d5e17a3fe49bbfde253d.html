NAME
       lacp-globals - configure lacp global settings.

MODULE
       net

SYNTAX
       Configure the lacp-globals component within the net module using the syntax shown in the following sections.

   MODIFY
	modify lacp-globals
	  options:
	    system-priority[integer]
	edit lacp-globals
	  options:
	    all-properties
	    non-default-properties

   DISPLAY
	list lacp-globals
	  options:
	    all-properties
	    non-default-properties
	    one-line

DESCRIPTION
       Provides the ability to configure global LACP settings.

       system-priority
	    Specifies LACP global priority for	BIGIP. The range 1 - 65535. The default value is 32768.

SEE ALSO
       list, modify,  tmsh
