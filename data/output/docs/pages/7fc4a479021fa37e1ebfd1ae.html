RESOLVER

Description

These commands allow you to resolve names and addresses using the DNS subsystem configured on BIG-IP.

Command List

  • DNSMSG - commands allow you process DNS responses
  • RESOLVER::name_lookup - performs a DNS lookup.
  • RESOLVER::summarize - returns a summary of the DNS response.
