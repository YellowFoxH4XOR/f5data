NAME
       update-signatures - Run automatic update for classification signatures.

MODULE
       ltm classification

SYNTAX
       Run the update-signatures component within the ltm classification module using the syntax in the following sections:

   Updated Command
       There has been a new implementation for this command. Please consider using the following command instead,
	run ltm classification updates

   RUN
	run update-signatures

DESCRIPTION
       You can use the update-signatures component to update the classification signatures from F5 download server. Only admins
       can run this command.

SEE ALSO
       ltm classification signature-update-schedule, run, tmsh
