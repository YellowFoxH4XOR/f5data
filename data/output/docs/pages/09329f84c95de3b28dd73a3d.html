PSC::tower_id

Description

The PSC::tower_id command gets the tower id or sets the tower id when the optional is given.

Syntax

PSC::tower_id
PSC::tower_id <value>

PSC::tower_id

  • retrieve the tower id

PSC::tower_id <name>

  • set the tower id
