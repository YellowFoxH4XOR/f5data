HTTP::response

Description

Returns the raw HTTP response header block as a single string.

Syntax

HTTP::response

Examples

when HTTP_RESPONSE {
    # Send response header block to high speed logging
    HSL::send $hsl [HTTP::response]
}

Related Information

Valid Events:
HTTP_RESPONSE, HTTP_RESPONSE_CONTINUE, HTTP_RESPONSE_DATA, NAME_RESOLVED
