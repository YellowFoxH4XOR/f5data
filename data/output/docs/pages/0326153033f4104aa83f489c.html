STATS::get
       Retrieves a setting value from a Statistics profile.

SYNOPSIS
       STATS::get PROFILE_NAME FIELD_NAME

DESCRIPTION
       Retrieves the value of the specified field of the specified Statistics profile.

       STATS::get  

	    * Retrieves the value of the specified field of the specified
	      Statistics profile.

RETURN VALUE
       Returns the value of the specified field of the specified Statistics profile

VALID DURING
EXAMPLES
	when HTTP_REQUEST {
	  if {[string tolower [HTTP::uri]] starts_with "/check"} {
	    STATS::get stats_profile_1 "my_first_field"
	  }
	}
