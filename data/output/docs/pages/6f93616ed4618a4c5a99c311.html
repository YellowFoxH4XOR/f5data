TAP::score
       Returns or updates risk score.

SYNOPSIS
       TAP::score (SCORE)?

DESCRIPTION
       If score specified sets supplied score. Returns previous score.

       Syntax

       TAP::score [score]

RETURN VALUE
       Returns an integer value from (0 to 100). If supplied score to set function returns previous score.

VALID DURING
       TAP_REQUEST

EXAMPLES
	when TAP_REQUEST {
	    if {    ([TAP::score] > 85) } {
		drop
	    }
	}
