AUTH_FAILURE
       Triggered when an unsuccessful authorization operation is completed (deprecated in 9.4).

DESCRIPTION
       Note: Deprecated in 9.4. It will still work, but is being phased out. Use AUTH_RESULT instead in 9.4 and up.

       Triggered when an unsuccessful authorization operation is completed. A default handler for this event is associated with
       each of the authentication profiles and causes the system to close the connection.

Examples
	when AUTH_FAILURE {
	    HTTP::respond 401
	}
