MR::restore
       Returns the stored variables to the current context tcl variable store.

SYNOPSIS
       MR::restore (VAR)*

DESCRIPTION
       The MR::restore command retrieves one or more named Tcl variables previously stored with the message by the MR::store
       command. If no name is provided, it retrieves all stored variables from the current message context.

RETURN VALUE
VALID DURING
       MR_INGRESS MR_EGRESS MR_FAILED

EXAMPLES
	when MR_INGRESS {
	    set client_addr [IP::remote_addr]:[TCP::remote_port]"
	    MR::store client_addr
	}
	when MR_EGRESS {
	    MR::restore client_addr
	}
