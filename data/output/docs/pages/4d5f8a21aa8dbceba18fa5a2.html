md5

Description

Returns the RSA Data Security, Inc. MD5 Message Digest Algorithm (md5) message digest of the specified string, or if an error occurs, an empty string. Used to ensure data integrity.

Syntax

md5 <string>

md5 <string>

  • Returns the RSA Data Security, Inc. MD5 Message Digest Algorithm (md5) message digest of the specified string, or if an error occurs, an empty string.

Examples

when HTTP_REQUEST {
   binary scan [md5 [HTTP::host]] w1 key

   set key [expr {$key & 1}]
   switch $key {
     0 { pool my_pool member 1.2.3.4:80 }
     1 { pool my_pool member 5.6.7.8:80 }
   }
}
