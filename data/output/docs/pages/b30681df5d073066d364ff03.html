pem_dtos

Description

This command is used the TAC (Type Allocation Code) DB. This is available from most of the rule events. It takes the IMEI/IMEISV as the input. The input could be a URL string or an IPV4 address. IPV6 addresses are not currently supported. iRule returns the URL categories returned by the urlcat library.

Syntax

pem_dtos tac lookup <IMEI>

urlcatquery

  • Query the TAC DB for IMEI Details

Examples

when CLIENT_ACCEPTED {
        log local0.info "This is the lookup [pem_dtos tac lookup 012430000000132]”      <<<< Just log a query on a specific IMEI. IMEI can be retrieved from PEM session as well.
    }

Output
Jul 28 02:08:15 vbigip01 info tmm1[8632]: Rule /Common/tacLookup <CLIENT_ACCEPTED>: This is the lookup {Apple-iPhone 4 model MC603KS} iOS
