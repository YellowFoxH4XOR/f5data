and



Description

Performs a logical “and” comparison between two values.

Syntax

<value1> and <value2>

<value1> and <value2>

  • Performs a logical “and” comparison between value1 and value2.

Examples

when HTTP_REQUEST {
  if { ([HTTP::uri] starts_with "/abc") and ([HTTP::host] equals "www.company.com") } {
     pool pool1
  } else {
     pool pool2
 }
}
