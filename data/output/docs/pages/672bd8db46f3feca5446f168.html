MR::store
       Stores a tcl variable with the mr_message object.

SYNOPSIS
       MR::store (VAR)*

DESCRIPTION
       The MR::store command stores one or more named Tcl variables with the message so that they are available on egress even if
       stored on ingress. If no name is provided, it stores all local variables in the current message context. Storing variables
       does not affect the content of the message.

RETURN VALUE
VALID DURING
       MR_INGRESS MR_EGRESS MR_FAILED

EXAMPLES
	when MR_INGRESS {
	    set client_addr [IP::remote_addr]:[TCP::remote_port]"
	    MR::store client_addr
	}
	when MR_EGRESS {
	    MR::restore client_addr
	}
