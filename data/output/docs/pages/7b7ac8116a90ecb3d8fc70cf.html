DSLITE

Description

DS-lite is an IPv6 transition mechanism which addresses operators who want IPv6-only access networks while providing support for IPv4-only nodes.

Command List

  • DSLITE::remote_addr - Returns the remote DS-Lite tunnel endpoint IP address.
