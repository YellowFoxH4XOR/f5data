iRule(1)						BIG-IP TMSH Manual						  iRule(1)

DNS
       Namespace DNS

DESCRIPTION
       The iRules feature includes several commands that are specifically designed to work with DNS queries on GTM and LTM (LTM
       must be running v11+). For most of these commands, a GTM or DNS Services license is required.

       Associated Events
	   GTM & LTM
	       DNS_REQUEST - Triggered when the system receives a DNS request.
	   LTM Only
	       DNS_RESPONSE - Triggered when the system responds to a DNS request.
