Name Type Default Value Required Access Description

minSlots integer 1 optional read/write Specifies the minimum number of slots that the guest must be assigned to.
preferredSlots integer   optional read/write

state string configured optional read/write Specifies the state of the guest: Configured, Provisioned, or Deployed. Each state implies the actions of all states before it.
