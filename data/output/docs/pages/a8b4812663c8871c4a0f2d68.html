Resource Natural Key

Properties

Name Type Default Value Required Access Description
build string   optional read/write The image build number.
buildDate string   optional read/write The date the image was built on.
checksum string   optional read/write The checksum of the image. Used to verify image integrity.
fileSize string   optional read/write The size of the file in megabytes.
lastModified string   optional read/write The date the file was last modified.
product string   optional read/write The F5 product this image contains.
verified string   optional read/write Set to ‘yes’ if the image is an authentic image.
version string   optional read/write The dotted version of the product.
volume string   optional read/write Specifies where the image will be installed.
