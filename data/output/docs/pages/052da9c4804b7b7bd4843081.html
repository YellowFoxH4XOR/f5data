FLOW::priority

Description

This command is used to overwrite the flow’s internal packet priority. Valid priority is any integer value from 0 to 7.

Syntax

FLOW::priority [priority value]
FLOW::priority [clientside [<priority value]]
FLOW::priority [serverside [priority value]]
FLOW::priority [TCL handle [priority value]]

FLOW::priority

* Returns the internal packet priority of current flow.

Flow::priority <priority>

  • Sets the priority of the current flow’s internal packet priority. Exception is thrown if priority is outside the allowed range 0-7.

FLOW::priority clientside

  • Returns the priority of the clientside flow’s internal packet priority.

FLOW::priority serverside

  • Returns the priority of serverside flow’s internal packet priority.

FLOW::priority clientside <priority>

* Sets the priority of the clientside flow’s internal packet priority. Exception is thrown if priority is outside the allowed range 0-7.

FLOW::priority serverside <priority>

* Sets the priority of the serverside flow’s internal packet priority. Exception is thrown if priority is outside the allowed range 0-7.

FLOW::priority <TCL handle>

  • Returns the priority of the internal packet priority.

FLOW::priority <TCL handle> <priority>

  • Sets the priority of internal packet priority. Exception is thrown if priority is outside the allowed range 0-7.

Examples

when CLIENT_ACCEPTED {
  FLOW::priority clientside 2
}
when SERVER_CONNECTED {
  FLOW::priority serverside 4
}


when CLIENT_ACCEPTED {
  FLOW::priority clientside 2

  # Alternate way to use the command using the TCL flow handle.
  # Get priority on the current flow.
  set clientflow [FLOW::this]
  set priority [FLOW::priority $clientflow]
  #OR
  set priority [FLOW::priority [FLOW::this]]

  # Set priority on the current flow.
  FLOW::priority $clientflow 2
  #OR
  FLOW::priority [FLOW::this] 2
}
when SERVER_CONNECTED {
  FLOW::priority serverside 4

  # Alternate way to use the command using the TCL flow handle.
  # Set priority on both client side and server side flow.
  FLOW::priority $clientflow 2
  FLOW::priority [FLOW::this] 2
}

Related Information

Valid Events:
FLOW_INIT, CLIENT_ACCEPTED, SERVER_CONNECTED
