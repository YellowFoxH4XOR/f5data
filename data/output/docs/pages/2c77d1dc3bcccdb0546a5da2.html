BIG-IP LTM v16.1.0

Commands Introduced in BIG-IP LTM 16.1.0

  • CONNECTOR::profile - get connector profile name.
  • CONNECTOR::remap - set client/server IP/Port from connector.
  • HTTP2::header - queries or modifies HTTP/2 pseudo-headers
  • MR::available_for_routing - gets/sets the available_for_routing mode for the current connection.
  • SSL::allow_nonssl - gets/sets state of Non-SSL connections.
  • TCP::keepalive - gets/sets the number of seconds before BIG-IP sends a keep-alive packet on a TCP connection with no traffic
  • UDP::max_buf_pkts - gets/sets the maximum buffer packets value of a UDP connection.

Commands Updated in BIG-IP LTM 16.1.0

  • L7CHECK::protocol - gets/sets L7 protocol value
  • MR::message - gets/sets details in the message routing table
  • SSL::forward_proxy - sets the SSL forward proxy bypass feature to bypass or intercept

Events Introduced in BIG-IP LTM 16.1.0

  • CONNECTOR_OPEN - Triggered when the connector is about to raise the service connect.
