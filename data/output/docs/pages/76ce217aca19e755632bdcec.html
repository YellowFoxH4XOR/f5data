SIP::from
       Returns the value of the From header in a SIP request.

SYNOPSIS
       SIP::from

DESCRIPTION
       Returns the value of the From header in a SIP request.

       Syntax

       SIP::from

	    * Returns the value of the From header in a SIP request.

RETURN VALUE
       Returns the value of the From header in a SIP request

VALID DURING
EXAMPLES
	when SIP_REQUEST {
	    log local0. "SIP Protocol - REQUEST: Values From & To"
	    log local0. "From: [SIP::from] To: [SIP::to]"
	}
