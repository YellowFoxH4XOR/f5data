LSN::pool
       LSN::pool

SYNOPSIS
       LSN::pool LSN_POOL

DESCRIPTION
       Explicitly set the LSN pool used for translation.

       LSN::pool 

RETURN VALUE
       LSN::pool

       Set or override the LSN translation pool used for this connection. The LSN translation pool contains the candidate
       addresses to which a client address may be translated.

VALID DURING
       CLIENT_ACCEPTED, CLIENT_DATA, HTTP_REQUEST, LB_FAILED, LB_SELECTED, RTSP_REQUEST, SIP_REQUEST, MR_INGRESS, SA_PICKED
