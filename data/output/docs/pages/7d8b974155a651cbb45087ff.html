HTML::disable

Description

Disable the processing of HTML for this transaction.

Syntax

HTML::disable

HTML::disable

  • Disable the processing of HTML for this transaction.

Examples

when HTTP_RESPONSE {
  if {$host == "www.f5.com"} {
    HTML::disable
  }
  log local0. "host: $host"
}
