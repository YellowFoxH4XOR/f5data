CATEGORY_MATCHED

Description

This event is triggered when a category match is found during URL filtering. This allows an admin some control over what to do when a category match happens. For example, if a match is in a custom category, it can be logged as such.
Note: Requires URL Filtering/SWG license, only happens when a category match is found in the “Category Lookup Agent” in the per-request policy.

Examples

when CATEGORY_MATCHED {
    CATEGORY::matchtype type_var
    if { $type_var eq “custom” } {
         log local0. “Custom category match was found.”
    }
}

Related Information

Available Commands:

  • CATEGORY::matchtype - stores the match result in the specified variable
