DNS::name

Description

This iRules command gets or sets the resource record name field.
Note: This command requires the DNS Profile, which is only enabled as part of GTM or the DNS Services add-on.

Syntax

DNS::name <rr_obj> [value]

DNS::name <rr_obj> [value]

  • Gets or sets the resource record name field (FQDN, e.g. devcentral.f5.com)
