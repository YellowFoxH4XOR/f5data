ACCESS_SESSION_CLOSED
       This event is triggered when a user session is removed due to a user logging out explicitly. timeout or if terminated
       explicitly by admin.

DESCRIPTION
       This event is triggered when a user session is removed due to a user logging out explicitly, session timeout, session
       terminated by administrator, or session deleted by an iRule.

       In TMOS versions 11.5.1+ you may use "ACCESS::session data get" commands in this event. When the event has concluded
       session data will be expunged.

       This event is a complementary event to the ACCESS_SESSION_STARTED event.

Examples
	when ACCESS_SESSION_CLOSED {
	    log local0.notice "APM: ACCESS_SESSION_CLOSED-User using the session: [ACCESS::session data get "session.logon.last.username"]"
	}

HINTS
       Important: This event is triggerred outside of flow context (similar to RULE_INIT) when a session goes away. The iRule
       commands which require a flow context (for e.g. TCP, HTTP and SSL commands) can not be used in this event.
