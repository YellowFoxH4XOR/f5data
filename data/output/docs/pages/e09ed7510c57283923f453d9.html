ROUTE::cwnd
       Returns the cached congestion window (cwnd) value.

SYNOPSIS
       ROUTE::cwnd DESTINATION_IP_ADDRESS (GATEWAY_IP_ADDRESS)?

DESCRIPTION
       Returns the cached congestion window (cwnd) value for a given destination IP and/or gateway.

       The return value only applies to the TMM executing the command. It does not consider cache entries on other TMMs.

RETURN VALUE
       The cached congestion window in bytes.

VALID DURING
EXAMPLES
	when CLIENT_ACCEPTED {
	    set cwnd [ROUTE::cwnd [IP::remote_addr]]
	    if { $cwnd > 0 } {
		log local0. "Destination found in cache. Initializing cwnd to $cwnd"
	    } else {
		log local0. "Destination not found in cache."
	    }
	}

HINTS
       If no TCP profile has cmetrics cache enabled, there will be no values to return.
