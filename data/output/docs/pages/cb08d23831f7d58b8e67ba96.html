whereami



Description

The whereami command returns the datacenter name for the local GTM.

Syntax

whereami

Examples

  when DNS_REQUEST {
if { [whereami] eq "DC1" } {
    pool pool1 member 10.10.10.10
              log local0. "Sticking [whereami] picks to pool1 member 10.10.10.10"
}
  }

Related Information

Valid Events:
GLOBAL_GTM
