BIG-IP LTM v15.0.0

Commands Introduced in BIG-IP LTM 15.0.0

  • ANTIFRAUD::client_id - Returns client id collected on client side.
  • ANTIFRAUD::device_id - Returns device id generated by BIG-IP.
  • ANTIFRAUD::geo - returns L3 geoIP and geolocation collected by client
  • ANTIFRAUD::guid - returns GUID value, only in context of ANTIFRAUD_LOGIN event
  • ASM::deception - Marks a request as deceptive for further enforcement by ASM.
  • DIAMETER::dynamic_route_insertion - Set whether dynamic route insertion is enabled.
  • DIAMETER::dynamic_route_lookup - Set whether messages should be routed dynamically.
  • IKE::auth_success -
  • IKE::cert -
  • IKE::san_dirname -
  • IKE::san_dns -
  • IKE::san_ediparty -
  • IKE::san_email -
  • IKE::san_ipadd -
  • IKE::san_othername -
  • IKE::san_rid -
  • IKE::san_uri -
  • IKE::san_x400 -
  • IKE::subjectAltName -
  • OFFBOX::request - Performs a request with a payload to certain service.
  • radius_authenticate - creates and sends a RADIUS access request message and returns the result
  • SIPALG::hairpin - Gets or sets the value of hairpin flag for the current message.
  • SIPALG::hairpin_default - Gets or sets the value of hairpin flag for the current connection.
  • SIPALG::nonregister_subscriber_listener - Gets or sets the value of flag enabling creating an ephemeral listener for nonregistered subscribers.
  • TAP::action - Returns or updates security token action.
  • TAP::config - Returns the current value of the specified setting in an assigned TAP Application.
  • TAP::score - Returns or updates risk score.

Commands Updated in BIG-IP LTM 15.0.0

  • MR::message - returns the persistence key being used for the current message
  • SSL::forward_proxy - gets or sets the policy status, or handshake and certificate details for forward proxy connections

Events Introduced in BIG-IP LTM 15.0.0

  • IKE_AUTH - Triggered during IPsec IKE_AUTH for IKEv2 ike-peers
  • PEM_SUBS_SESS_DELETED - triggered when a subscriber session has been deleted.
  • PEM_SUBS_SESS_UPDATED - triggered when a subscriber session attribute has been updated.
  • TAP_REQUEST - Triggered once security token obtained.

Events Updated in BIG-IP LTM 15.0.0

  • PEM_SUBS_SESS_CREATED - triggered when a subscriber session is created

Commands Deprecated or Removed in BIG-IP LTM 15.0.0

  • QOE::enable
  • QOE::video

Events Deprecated or Removed in BIG-IP LTM 15.0.0
