TAP

Description

These commands allows you to manage the Threat Analytics Platform.

Command List

  • TAP::action - Returns or updates security token action.
  • TAP::config - Returns the current value of the specified setting in an assigned TAP Application.
  • TAP::insight - Accumulates or sends key:value pairs to TAP, returns token
  • TAP::insight_requested - TAP requests insight flag
  • TAP::score - Returns or updates risk score.

Event List

  • TAP_REQUEST - Triggered once security token obtained.
