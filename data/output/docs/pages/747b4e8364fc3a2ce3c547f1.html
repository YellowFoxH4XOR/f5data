GTP::parse
       Creates a new GTP message from a byte stream.

SYNOPSIS
       GTP::parse BYTE_STREAM

DESCRIPTION
       Creates a new GTP message from a byte stream.  Returns a TCL object of type "GTP-Message"

RETURN VALUE
       Returns a TCL object of type "GTP-Message"

VALID DURING
EXAMPLES
	when CLIENT_ACCEPTED {
	    set payload [UDP::payload]
	    set t2 [GTP::parse $payload]
	    log local0. "GTP type [GTP::header type -message $t2]"
	    log local0. "GTP teid [GTP::header teid -message $t2]"
	}
