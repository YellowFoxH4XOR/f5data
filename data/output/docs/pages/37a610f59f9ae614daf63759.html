ILX::call
       Calls an ILX method.

SYNOPSIS
       ILX::call HANDLE
		       ((-timeout TIMEOUT)? ('--')?)?
		       METHOD (ARGS)*

DESCRIPTION
       Make a call to a method defined within the plugin extension referenced by the handle.  Provide the method with the
       arguments listed in ARGS, do not continue processing the iRule until a response is received.

RETURN VALUE
       The return value is the argument passed to response.reply() call on the extension side (eg. an array, a string, etc).

VALID DURING
       ANY_EVENT

EXAMPLES
	when CLIENT_ACCEPTED {
	    # Get a handle to the running extension instance to call into.
	    set RPC_HANDLE [ILX::init my_plugin my_extension]
	    # Make the call and store the response in $rpc_response
	    set rpc_response [ILX::call $RPC_HANDLE my_js_function arg1 arg2]
	}
