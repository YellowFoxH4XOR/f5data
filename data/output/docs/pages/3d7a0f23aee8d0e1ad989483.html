DNS::last_act

Description

This iRules command sets the action to perform if no DNS service handles this packet
Note: This command requires the DNS Profile, which is only enabled as part of GTM or the DNS Services add-on.

Syntax

DNS::last_act <allow|drop|reject|hint|noerror>

DNS::last_act <allow|drop|reject|hint|noerror>

  • Sets the action to perform if no DNS service handles this packet (aka Unhandled Query Action)
