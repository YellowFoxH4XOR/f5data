Properties

Name Type Default Value Required Access Description
appService string   optional read/write The application service that the object belongs to.
brPfxIgnore string disabled optional read/write Allow BIGIP to work with non rfc compliant CE devices which ignore BR prefix lengths. The default is to disable.
brPrefix string   optional read/write BR (Border Relay) prefix and netmask for MAP-T domain. The default prefix length is 96.
defaultsFrom string   optional read/write The profile from which to inherit settings. The default value is map-t.
description string   optional read/write User defined description.
draftMode string disabled optional read/write Allow BIGIP to work with non rfc compliant CE devices which map BR prefix at a wrong offset. The default is to disable draft mode.
eaBitsLength integer 32 optional read/write Specifies EA (Embedded Address) length of the MAP-T domain. The default is 32 (IPv4 24 bits + PSID 8 bits).
ip4Prefix string   optional read/write Rule IPv4 prefix and netmask for MAP-T domain CE (Customer Edge) devices. The default prefix length is 8.
ip6Prefix string   optional read/write Rule IPv6 prefix and netmask for MAP-T domain CE (Customer Edge) devices. The default prefix length is 48.
tmPartition string Common optional read/write Displays the admin-partition within which this component resides.
portOffset integer 6 optional read/write Specifies port offset bits length of the MAP-T domain. The default is 6.
psid integer 0 optional read/write Specify PSID value for MAPT. The default is zero.
