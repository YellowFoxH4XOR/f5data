SDP::session_id
       Get the SDP session id.

SYNOPSIS
       SDP::session_id

DESCRIPTION
       This command allows you to get SDP session id for the current connection

       Syntax

       SDP::session_id

	    * Returns the value of the SDP session id

RETURN VALUE
       Returns the value of the SDP session id.

VALID DURING
EXAMPLES
	when SIP_RESPONSE {
	    log local0. "SDP SessionID: [SDP::session_id]"
	}
