CACHE::fresh
       Returns state of freshness flag for request.

SYNOPSIS
DESCRIPTION
       Returns 1 for cached document fresh, 0 otherwise.

       CACHE::fresh

	    * Returns true (1) or false (0) to indicate freshness of request.

RETURN VALUE
       Returns 0 or 1.

VALID DURING
       CACHE_REQUEST

EXAMPLES
	when CACHE_REQUEST {
	    set val [CACHE::fresh]
	    log local0. $val
	}

	when CACHE_RESPONSE {
	    CACHE::header insert X-Example $val
	}
