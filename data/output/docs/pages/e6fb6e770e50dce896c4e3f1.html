SDP

Description

These commands allow you to get and set various different pieces of information in a Session Description Protocol (SDP) session.
NOTE: The features contained in this namespace are available with a general license only in 9.4.2 and later. Earlier releases require an EA (Early Access) license to use these features. These commands will not function if your system does not have this license installed. For more information, read about the LicenseDetails

Command List

  • SDP::field - Returns the value in a given SDP field
  • SDP::media - Get or set SDP media information
  • SDP::session_id - Get the SDP session id

Note: SDP commands behave correctly on MRF framework
