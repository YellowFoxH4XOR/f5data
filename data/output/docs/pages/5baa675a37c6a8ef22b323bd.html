ip_addr

Description

Returns the IP address of a tmm, tmm interface, localhost, etc.

Return Value

The requested IP address.

Valid During

ANY_EVENT

Examples

ip_addr tmm_if 1.2.3.4
 log local0. “TMM interface IP address is [ip_addr tmm_if]
