BWC::debug
       This command is used for troubleshooting a bwc policy instance.

SYNOPSIS
       BWC::debug ('start')
			  ('module' MODULE)?
			  ('level' VALUE)?
			  ('flow' | ('session' (SESSION_STRING)?))

       BWC::debug ('start')
			  ('level' VALUE)?
			  ('module' MODULE)?
			  ('flow' | ('session' (SESSION_STRING)?))

       BWC::debug ('stop')
			  ('module' MODULE)?
			  ('flow' | ('session' (SESSION_STRING)?))

DESCRIPTION
       This command enables debug logs on per policy instance. However the bwc sys db variables for bwc trace need to be enabled
       and appropriate levels needs to be set as required.

RETURN VALUE
VALID DURING
EXAMPLES
	when CLIENT_ACCEPTED {
	    set mycookie [IP::remote_addr]:[TCP::remote_port]
	    BWC::policy attach test_pol $mycookie
	    log  local0. "BWC::policy attach  $mycookie"
	    BWC::debug start session
	}
