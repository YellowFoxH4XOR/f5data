TCP::rexmt_thresh
       This command can be used to set/get the retransmission threshold of a TCP connection.

SYNOPSIS
       TCP::rexmt_thresh (TCP_REXMT_THRESH_VALUE)?

DESCRIPTION
       TCP::rexmt_thresh returns the retransmission threshold of a TCP connection.  TCP::rexmt_thresh TCP_REXMT_THRESH_VALUE sets
       the retransmission threshold to specified value.

RETURN VALUE
       TCP::rexmt_thresh returns the retransmission threshold of a TCP connection.

VALID DURING
       ANY_EVENT

EXAMPLES
	# Get/set the retransmission threshold of the TCP flow.
	when CLIENT_ACCEPTED {
	    log local0. "TCP set rtx thresh: [TCP::rexmt_thresh 100]"
	    log local0. "TCP get rtx thresh: [TCP::rexmt_thresh]"
	}
