SDP::field

Description

This command will return the value of a specific SDP field

Syntax

SDP::field field-name <index>

# introduced in v13
SDP::field field-name <index> <new value>

SDP::field field-name <index>

  • Get SDP field “field-name” at position index, if index is not present, the first field “field-name” will be returned if found

SDP::field field-name <index> <new value>

  • Sets SDP field “field-name” at position index with user defined “new value”

Examples

log local0. "SDP field: [SDP::field connection_address]"

 when SIP_REQUEST {
     log local0. "SDP field b: [SDP::field b]"
     SDP::field c 0 "IN IP4 10.10.1.150"
 }
