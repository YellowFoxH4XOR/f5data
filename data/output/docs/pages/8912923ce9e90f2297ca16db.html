urlcatquery
       Query the URL for URL categorization.

SYNOPSIS
       urlcatquery URL_STRING

DESCRIPTION
       This command is similar in functionality to whereis command of geoip.  This will be available from HTTP_REQUEST irule
       event. It takes the URL as the input. The input could be a URL string or an IPV4 address. IPV6 addresses are not currently
       supported. iRule returns the URL categories returned by the urlcat library.

       Syntax

       urlcatquery INPUT_URL

	    * Query the URL for URL categorization

RETURN VALUE
VALID DURING
       HTTP_REQUEST

EXAMPLES
	when HTTP_REQUEST {
	    set input_url [HTTP::host][HTTP::uri]
	    set urlcat [urlcatquery  $input_url]
	    log local0. "INPUT-URL: $input_url"
	    log local0. "Category - $urlcat"
	    CLASSIFY::urlcat add $urlcat
	}
